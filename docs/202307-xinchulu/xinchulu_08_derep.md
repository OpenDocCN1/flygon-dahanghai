# 年轻人搞钱，真正靠什么？

我孤身到深圳第五年，学校不是名校，手里没技术，家里也没背景。要说梦想情怀，其实有点虚。当年只是东北待腻了，港片看多了，觉得南方人讲普通话好听、做事也文明，便想南下看看。

2015年，家里人不同意，我还是悄悄做微商卖玉石饰品。先把高中、大学通讯录梳理一遍，做了几单，赚了几千块，随后坐绿皮火车从东北到深圳。一个没见过什么世面的男生，从那时起把家里原先那套想法撕开一道口子，心也越来越大。

1、想要的东西，不必都照着别人来

小时候我喜欢汽车和手枪玩具，看见别家孩子有就羡慕。攒了很久零花钱买了一把玩具枪，被我妈狠揍，还逼我退掉，弄得我在玩具店老板面前抬不起头，之后不敢再进店。

小学时学校不强制校服，有同学穿真维斯、佐丹奴，我也想要，却没跟父母开口。我妈买大一件女款宽领露肩衣服，退不了就让我穿。我高高兴兴穿去学校，被同学笑男孩穿女装。那以后我变得孤僻，总觉得在班里低人一头。

初中长痘，我只知道脸要洗干净，不能用皂基香皂，否则会更干更容易爆痘。于是偷用我妈洗面奶，常被发现，没少挨骂。姥姥还专门教育我：男孩子别太在意这些。我妈答应给我买一支，直到高中也没兑现。

从小到大，我想要的几乎都没得到。我妈总说：家里条件不好，你跟别人家孩子不一样，不能别人有什么你就跟我要什么，要听话、要懂事。二十多年里我没觉得这话有问题，直到来了深圳。

2、一个二本生，跑出去折腾什么？

出发前，家里搬出最有威望的舅舅来教育我这个大学生。他的意思很直接：不就是个二本吗，出去显摆什么，心比天高，不知道自己几斤几两，早晚得回来。他说的是实情。但后来我明白，挣钱更看敢不敢干、能不能执行，文凭不是决定项。

3、工作几年后，你或许开始认同前面两点

你可能觉得：家庭带来的限制很难破，学历会划出一个圈子，也是很多人成功起步的底子。我不急着反驳，先说几个人。

01 陆丰小涛：从修手机到二手手机，再到医美

小涛86年，和不少潮汕年轻人一样，高中没读完就来深圳。起初在华强北飞扬学修手机，学成后没做维修师傅，而是盯上二手手机市场：低价收、售后翻新维修，再挂淘宝转卖。赚到一点钱后，他觉得利润不够，又去学医美，专门给人打玻尿酸。去年，他在罗湖和陆丰碧桂园各买了一套房。

02 揭阳嘉伟：淘宝店比总监岗位更稳

嘉伟也是潮汕仔，学历不高，在华强北做淘宝。最早跟小涛做二手手机，后来主营耳机，兼卖手机壳，今年又开新店做电池。店铺运营和刷单都自己上手，姐姐管打包，朋友搭把手做客服。他几家淘宝店每月稳稳定定净落3到5万，放到互联网创业公司，差不多是运营总监的收入。不同的是，疫情来了，很多总监失业，嘉伟几乎不受影响——没人能裁他，命运在自己手里。今年华强北电子生意不算旺，明通转做护肤，嘉伟和表弟也折腾起护肤品，日流水5000到10000，利润率30%，规模还在扩。

03 莆田鞋阿东：开着新宝马请我们吃饭

2016年我在一家上市公司做新媒体运营经理，有个应届生同事分到部门给总监当助理。那时他就搞莆田鞋，自己卖，也招微商分销：一年招了200多个微商，想参与分销得先交600元，发展成他的下线。我们没在意，以为小孩赚点外快交房租，过几天就黄。2017年中旬公司有危机，总监、我、他和大部分同事都离职。那小朋友高高兴兴辞了职，买了台宝马请我们吃饭，席间问要不要一起搞点事，满桌经理总监都成了陪笑的人。

04 94年的小程序玩家：成了半岛城邦业主

今年有位朋友去了国外，我替他打理部分私人账目：手里24张卡，每张卡上都躺着500万；又在蛇口半岛城邦一次性付清1400万，拿下海景大宅。他既是平安银行的大额储户，也是半岛城邦的业主。他怎么挣的？核心就是复制。打法是产品做小做美，不背创业情怀，只当一门小买卖。应用榜单里谁跑出利润，他就研究谁、照着做，再用ASO把榜单位置刷上去；连名称、原型、界面和变现路径都照着做到八成相像。他手上有好几家公司主体，一次铺开多个马甲包，哪个被封就补哪个。

5月27日何鸿燊离世，有位前辈说自己一辈子不认“不行”，不服输，要做就做到“行”，也鼓励年轻人别轻易认输。

我没有具体方法和项目可给，只能分享：别信那些把命、运、风水、积德、读书排成固定顺序的鬼话，也别认定家庭给的眼界就是天花板。多出门、多观察、多试错，靠近积极做事的人，踏踏实实做事，好好做人，别轻易服输。做到这些，你仍可能失败；但只要你靠谱、会做人，别人做成了也会想到你。身边常有几个千万级的人，普通机会一年挣几十万并不稀奇。

文末说下：有带货需求或品牌广告投放，欢迎私信。我们团队做了十多个微商工具类产品、十多个轻量有趣的小工具，其中个别微商工具已经积累数百万用户；另外，面向年轻用户的产品有400多万用户，87%为女性，18到25岁是主力。没多大野心，资源能对接就一起挣点钱。

最后打打气：长期努力不能少，别总看轻自己，人品要正，重情义，记得别人的好，遇到困难别轻易认输。好运气迟早会来敲门。愿我们在深圳都越过越顺。晚安，加油🌙
