# 想从大厂裸辞创业？先看完这6条建议再决定

前两天，生财有术里一位圈友约我见面，他正打算从阿里离职，全职All in创业，还带来了两个自己精心准备的创业方案。

听完他的规划，我给了他几条很实在的建议。

**第一，先用兼职把商业闭环跑通，赚到第一块钱。**

如果兼职状态下连“赚到第一块钱”这个目标都完不成，全职做大概率也难。只有当闭环已经跑通，明显感觉时间不够用、瓶颈卡在投入上时，才值得全职出来。我自己当年出来创业时，兼职收入已经是工资的10倍以上。

**第二，做好至少半年没有收入的准备。**

尤其是做产品的人，没有几个月沉下心打磨，产品基本拿不出手。一旦现金流压力太大，动作就容易变形；动作变形，产品就做不好；产品做不好，又会加剧现金流压力——很容易陷入恶性循环。

**第三，先学会复制别人的模式。**

很多事看着轻松赚钱，自己上手做一遍，才发现没那么简单。但也不用被吓退，专注扎进去一段时间，又会发现其实没那么难。关键是先下场，别光站在岸上看。

**第四，别太迷信所谓的人脉和资源。**

那些张口就说能给你多少资源的人，不一定靠谱。只有当你真正能为对方提供不可或缺的价值时，他们才会长期依赖你。说白了，本质上都是利益交换。

**第五，别迷恋裂变、流量玩法、增长黑客这些概念。**

真正的壁垒，是把一个产品或商业模式从0做到1，再从1推到100的能力。如果只会玩流量，到头来只是在给别人做嫁衣。资本会流向收益率高的地方，流量也一样。

**第六，不要一上来就做平台。**

先搞定某个细分市场的某一边，哪怕是先跟这一边的关键人物建立关系，然后慢慢长大，成为这一边资源的代表，再去拓展另一边，最后长成平台。记住：平台是长出来的，不是规划出来的。

以上，就是那天我和他聊的全部内容。如果你也在纠结要不要从大厂出来创业，希望这些建议能帮你冷静一下。
