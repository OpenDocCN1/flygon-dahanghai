# 3人做菜谱视频，两年500万粉净赚250万

各位朋友好，我是刘易彬，大家平时叫我快快，90年生人，目前全职做互联网创业。这篇复盘写于2021年4月26日，想和正在自媒体路上摸索的朋友聊聊。

2018年下半年，我把全部精力投到以菜谱为核心的美食视频项目。到2019年初，项目逐渐跑顺，运营进入状态。2019到2020这两年，账号在全网积累起500万粉丝，流量收入接近300万，扣掉成本后净赚250万。团队不大，公司连我一共3个人。

刚来生财社区，我的想法很朴素：如果这些经历能给做自媒体的朋友一点参考，某些经验让你得到启发，就很值得。我始终相信，把玫瑰递到别人手里，自己也会沾上余香；分享越多，好运越容易靠近。
