# （精华帖·159赞）流量生意做三年，我挣到500万

作者：小许（专注流量变现）｜2023年1月29日

生财圈的朋友们，大家好，我是小许，经营着一家在流量赛道跑了三年的工作室。今天想把自己做短视频流量时踩过的坑和攒下的经验拿出来聊聊，希望能给圈友带来一些可落地的信息与思路。开讲前要谢谢@凡灵逸尘，他总在背后推着我在生财写东西，是我持续分享的推动者。

做引流最扎心的地方，是平台风控一来就成片封号。没有哪个平台愿意看到用户被导到站外，所以动手做流量前，先得接受账号会批量被封的现实。我们走账号矩阵路线，每位同事会配15到20部手机，靠短视频不断曝光来拉客户；被封号的问题，交给线下地推伙伴协同处理。

我目前在流量变现这条赛道的成绩：
- 打法：用短视频搭账号矩阵
- 获客方式：短视频和图文为主，直播做得少；直播对员工要求高，不容易复制
- 主要阵地：抖音、快手、小红书
- 覆盖赛道：男性粉、女性粉、减重、教辅、丰胸、创业、中医、金融等
- 团队配置：10人，其中3人做转化，7人做获客
- 账号规模：累计230个，现在还在跑84个；春节后有人离职，部分账号停摆
- 变现峰值：最高一天纯利超过8万元

今天重点聊三件事：
1. 流量变现的机会点
2. 内容如何批量生产
3. 引流变现常见的坑
