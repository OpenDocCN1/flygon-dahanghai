# 闲鱼露营装备，一年变现近20W

先做个自我介绍：我是吉良吉颖，大家也叫我蛋蛋。此前在生财社区里，我几乎是个不太冒泡的人。去年，我偶然留意到亦仁分享的露营经济风向，恰好那时自己的闲鱼无货源项目迟迟没有起色，便把精力转向露营装备。

起步阶段，每天利润只有一百来块；后来逐步做到日均一千多；单日净利润最高突破4000元。到这次复盘，正好做满一年，累计变现接近20万元，如今仍能稳定做到每月1.5万元以上，整体月入大致在1万到2万元之间。

露营算得上近两年最火的户外休闲选择之一，围绕它产生的消费需求，也给电商从业者带来了不少盈利机会。眼下又到了露营品类全年最旺、最容易出单的阶段，这个竞争相对不拥挤的小众方向，值得认真看看。
