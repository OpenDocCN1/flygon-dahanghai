# 10.1 小红书官方店铺运营课

做小红书店铺，与其自己摸索，不如直接看官方给的免费课程。商家课堂里把所有干货都整理好了。

目前主要有两个方向：

一是店铺基础运营，适合刚开店的小白，从后台设置到日常打理，帮你把基本功打牢：

[小红书商家课堂 - 店铺基础运营](https://school.xiaohongshu.com/course/list?categoryNo=20210515002)

二是店铺直播运营，专门讲直播间怎么搭、主播怎么播、怎么把流量转化成订单，想靠直播带货的商家可以重点学：

[小红书商家课堂 - 店铺直播运营](https://school.xiaohongshu.com/course/list?categoryNo=37dc2c85ed9844c49cb2b23035f80758)

课程都是官方出品，跟着学就行，省时省力还不容易走弯路。
