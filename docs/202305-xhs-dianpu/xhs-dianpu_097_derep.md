# 8.4.3 买食品前，标签这8项别漏看

下单食品时，别只盯着价格和口味，包装上的标签更值得先看一眼。按规定，食品包装必须带有标签，而且下面这些信息应当写清楚，买之前不妨逐项核对：

1. 产品叫什么、规格多大、净含量是多少，以及生产日期是哪天；
2. 用了哪些成分或配料，配料表要能看明白；
3. 生产厂家的名称、地址和联系方式是否齐全；
4. 保质期到什么时候；
5. 产品标准代号有没有标注；
6. 平时该怎么存放，贮存条件是否写明；
7. 食品添加剂要标出国家标准中的通用名称；
8. 生产许可证编号是否完整。

标签信息越清楚，下单时越安心。遇到关键内容缺失或含糊不清的食品，建议谨慎购买。
