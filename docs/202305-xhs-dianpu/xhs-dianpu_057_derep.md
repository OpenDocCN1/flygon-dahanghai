# 7.3.3 搜索排名，究竟看什么？

在聊📕 SEO 的具体打法之前，有个基础问题得先弄清楚：一篇笔记能不能在搜索结果里排到前面，到底受哪些因素影响？

归根结底，主要看两块：账号权重和单篇笔记的权重。很多人不承认“权重”这个说法，但在实际运营中，这种差异确实能感知到。

账号层面，活跃程度、原创比例、内容是否聚焦，都会影响账号权重；笔记层面，发布时机、点击表现、互动数据等，则决定笔记权重。两者越高，被用户搜到的概率就越大。

不过，真正对搜索排名起更大作用的，是单篇笔记的权重，而不是账号权重。新人账号的权重通常偏低，可只要关键词布局准确、内容质量过硬，第一篇笔记照样有机会跑出爆款。反过来，一旦某篇笔记爆了，其他笔记也可能被一起带起来，账号权重随之上升。

另外，只要账号没有严重违规，正常发布的笔记一般都能被搜索到。当然，有个前提：笔记中必须出现用户会去搜的那些关键词。
