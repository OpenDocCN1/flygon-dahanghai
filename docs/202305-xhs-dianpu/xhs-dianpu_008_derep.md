# 1.4 流量从哪里来？

做📕，流量到底从哪里来？核心其实就两个入口：一个是被动刷到的推荐流量，一个是用户主动搜出来的搜索流量。

1）推荐流量

推荐流量的背后是算法机制。笔记发出去以后，系统会紧盯它在起步阶段的点赞、收藏、评论、转发、关注等数据，并据此打分，其中评论、转发、关注所占的分值权重更高。📕的内部量化体系叫 CES，具体评分公式是：CES 评分 = 点赞数×1 + 收藏数×1 + 评论数×4 + 转发数×4 + 关注数×8。

分数越涨，笔记就越容易被系统一层层推入更大的流量池，慢慢就有了成为爆文的机会。通常情况下，互动量到 1000+ 是小爆款，到 10000+ 就是大爆款（不同细分领域会有差别）。而且一篇爆文还能带动账号里其他笔记的数据跟着涨。当然，这需要满足几个前提：

① 笔记要过审：没有违规，没有被系统删除，也没有被自己删除或隐藏；
② 笔记里要有能对应垂直标签的关键词（比如香水、家具），这样系统才能识别收录，并推荐给感兴趣的人群；
③ 内容本身要能打，让人愿意点赞、收藏、评论和转发。

这里要给新手提个醒：第一篇文章就想成为大爆款，基本不太现实。运营头一个月，阅读量（圈内叫“小眼睛”）停在 100~200 是常态，基础好的会长得快一些。80% 的新手要到第二或第三个月才开始爆发。流量是有酝酿期的，别太焦虑，把内容磨扎实才是正路。

2）搜索流量

📕里也藏着大量“带着问题来”的用户。比如“口红攻略”是很多想买口红的人会搜的，“旅游攻略”则是计划出行的人常搜的。搜索结果里的排位，几乎决定了笔记能拿到多少曝光和关注。这部分流量能占到平台总流量的一半以上，绝不能忽略。

想要吃搜索流量，笔记里必须包含有效关键词，并且已经被系统收录；想要排名更靠前，账号权重和笔记权重也需要持续积累。
