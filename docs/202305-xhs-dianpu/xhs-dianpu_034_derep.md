# 5.1 供应商筛选要点 @seven

想找到靠谱的供应商，重点看这几点：能不能按你的做货要求来，起订量是否合适，单价是否有竞争力，产品质量过不过关，以及对方愿不愿意配合你反复调整、打磨方案。

不过，别急着去询价。在开口之前，你得先把自家产品的底细摸清楚——材质用什么、尺寸多少、功能定位、工艺流程、目标起订量，还有你特别在意的品质要求，全部列明白。这不仅是给供应商信息，更是让对方看到你的态度：你是认真的，不是随便问问就消失。

反过来，如果你连自己要什么都不清楚，供应商问你细节，你支支吾吾答不上来，他心里立马就会有判断——这人八成不会下单。既然觉得你没什么希望，他自然也不会费心帮你挑料、定工艺、找辅料，最后你的产品也就卡在摇篮里了。

所以，选供应商的一半功课，其实在咨询之前就已经开始了。
