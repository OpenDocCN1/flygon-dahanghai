# 5.4 和工厂打交道的关键动作 @郑小焦

想把供应商沟通做得顺，先把几个动作做对。

第一，别一直停在1688站内聊。能加到微信就加微信，能电话讲清楚就别来回打字。第二，直觉不对劲要及时刹车；感觉对方不靠谱，不必抱着“试试看”的心态硬合作。第三，多从工厂视角想问题，遇到分歧先理解对方难处，不要一上来就责怪。第四，认清自己的订单分量：单子不大，就去找规模匹配的中小厂，别用大厂的标准要求小单。

供应商愿意长期打交道的人，通常有三个特点。

一是尊重对方时间。问题东一榔头西一棒子，迟迟问不到关键处，对方只会觉得你在消耗他。

二是信息给得够密、够专业。材质、工艺、术语这些基础信息，自己先弄清楚；别一开口就把本该自己做的功课丢给供应商，让对方替你补课。这样会直接影响对方配合你的意愿。Zev 的例子很说明问题：他的旺旺账号权重高不高，其实不是重点，关键在于他清楚自己要做的产品工艺，甚至把模具雕好交给工厂，最后拿到了很漂亮的开的模价格。

三是拿出真心。你是不是真想把这个产品做出来，对方能感觉到。前面两点其实也汇到了这里：你准备得是否充分、对产品理解是否到位，都会暴露你的诚意；沟通时对自己产品的把握程度，同样会让供应商判断你值不值得认真配合。
