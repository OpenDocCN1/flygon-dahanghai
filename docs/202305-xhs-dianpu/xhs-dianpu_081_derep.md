# 7.5 方法五：官方投流进阶玩法 @张琳达

如果你准备在小红书长期经营市场，聚光平台值得纳入投放工具。投流并不是新手常规操作，更像是店铺运营的进阶路径，品牌型店铺在做流量放大与营销协作时尤其常见。

聚光平台是什么？它是小红书推出的一站式广告投放阵地，广告主可以围绕产品种草、商品成交、客户线索收集、直播引流、赛道占位等不同目标展开营销。

它把搜索与浏览这两个用户做决策的关键入口连接起来，还能按 SPU（产品）粒度进行精准定向与智能投放，形成一体化营销方案，帮助优质产品获得自然曝光。
