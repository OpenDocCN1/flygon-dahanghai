# 3.9 方法九：用“人货场”思维选品 @贾璐 luca

很多人刚开始做快团团帮卖时，最纠结的就是“到底卖什么”。其实答案不在货架上，而在你的微信好友里。所以先别急着挑品，先想清楚：你身边的这群人，究竟是谁？

我长期观察自己微信里的用户，发现画像非常清晰，基本是两类人：

一类是身处中产家庭的全职主妇。她们时间充裕，群里发言活跃，但自己没什么收入，价值感更多依附于家庭。她们花的钱基本都围绕家庭日常，很难为“取悦自己”花大钱。

另一类是一线城市的女白领。她们工作忙碌，个人能力强，情感生活却往往单薄。她们非常愿意为自己投资，而且特别看重消费带来的身份表达。晒单、展示生活时，她们更在意能不能烘托出自己的品味和格调。人设必须是“爱生活、懂生活”，但她们缺时间，所以那些能快速帮她们立住人设的商品，会格外受欢迎。

搞懂了人，再来看“生活方式”这个词。很多人一听就觉得是装，其实没那么肤浅。它源于英文的 life style，本质是生活的格调与风格。而如今社交媒体把这种价值放大了无数倍——一个人过什么样的生活，可以被迅速看见、被羡慕、被认同，转换成实打实的社交资本。

所以，只要选品能踩中“生活方式”的脉搏，消费者就愿意为那份格调买单，甚至主动分享，而不是靠你拿折扣去换晒单。但光有格调也不行，大家愿意为“感觉”花的钱是有限的。真正能引爆的品，是既让买家显得有品位，又让买家觉得“这价钱，值了”。就像大主播卖货，必须先把自己塑造成懂美学、懂生活的形象，等大家信了这个人设，再看到直播间里的折扣价，才会忍不住下单。可如果主播和商品调性不符，或者粉丝压根不信任他，那再便宜也难卖。

说到底，人货场里，“人”永远排在第一位。得先听人说什么、在意什么，才谈得上选什么货、定什么价。我住的小区偏中高端，平时群里聊得多了，对这两类人的消费力和社交心理都有了底，于是选品和定价都有了方向。

水果，就是我的切入点。

原因有四：第一，女性用户对水果有天然好感，这么多年早被市场教育透了；第二，水果颜值普遍在线，拍照发朋友圈很有面子，社交属性拉满；第三，它是高频刚需，隔三差五就要买；第四，水果店线下价格虚高，存在明显的低价击穿空间。

当然，水果也有短板。一个是损耗大，品质、售后问题免不了要赔；另一个是标准化程度低，很难保证每一批都稳定。这两点也决定了它的天花板。

但先看机会。基于对“人”的理解，我这个“场”本身又自带吃货属性，于是把“货”定位成高性价比的水果生鲜。具体选品上，只挑颜值高、品质好、消费欲望强的品种：葡萄、草莓、蓝莓、高端柑橘这些。

快团团对我来说，只是一个工具而已。
