# 5.6 方法六：复购率拉满的“海王模型” @泳怡

聊到复购，我确实有点家底。这套打法我自己跑了两年多，货卖出去了，钱也赚进来了，个人品牌还攒下一批死忠粉。如今“泳怡”两个字，在老顾客心里基本就是块招牌。

我到底怎么做的？核心就一句话：像海王一样，和一大群用户谈一场又浓又长的恋爱。为什么这么说？因为你的对面不止一个人，得同时暖很多人，那不就是海王？还得当中央空调，谁冷暖谁，让用户在你这儿有了依赖，一天不看你的动态就难受。说白了，这是惯性的力量。等她有需求时不过脑子就来找你，不再反复比价、不再反复纠结，这惯性就养成了。我在群里的标签是“无所不能的乐妈百货商店”，所以她们买东西前，总会不自觉地过来问一句，或者私信我。

这套逻辑分四步：先吸引，再接触，接着甜蜜，最后投入。

1）吸引

先靠触发点让人看见你。外部触发好理解：物美价廉的货、朋友的推荐。通过这些，用户认识了你，你也顺势进入她的日常。更值钱的是内部触发：你本人有没有魅力，你发的动态有没有能量和磁场。用户需要情绪价值、需要人陪时，你或你的群能不能接住这份需求，特别关键。

拿我举例：头像是一张海马体写真，笑容很灿烂；签名写“超厉害的女人”。新朋友加进来第一眼，就会觉得这人真、有力量。我平时爱写点小作文，聊人生、聊三观，正到用户忍不住点头，形象就这么立住了。

群里也一样，我不止卖货，也当知心姐姐。产后抑郁、心里难受的妈妈来倾诉，我尽量开解。我一带头，别的妈妈也愿意搭把手，将心比心。慢慢群里的空气就暖了，大家遇到难处，第一反应就是来群里聊几句。

组建这个群的头一天，我就管所有人都叫“姐妹”。寥寥两个字，让原本陌生的用户真的处出了情分。有个姐妹在群里说碰上麻烦事，另一位当检察官的姐妹当场帮她翻了卷宗。事后我去道谢，人家只说：都是姐妹，客气什么。

吸引力一旦形成，你在用户心中就扎下了根。这就是占住心智。

2）接触

吸引只是开始，关键要落到每一步动作。我把它叫服务动作。用户从被吸引、下单，到收到货，这条服务链环环相扣，哪一环没做好，前面全白费。

举个例子：用户想买一条好穿的瑜伽裤，看到你这儿有，就拍下了。货到了，无非两种情况：满意，或者觉得跟宣传不符要退。怎么接？

满意的情况：你估摸着快递该到了，主动去问一句穿着感受。对方说好，你就回“谢谢亲爱的支持”。这时你知道她有练瑜伽的打算，转头去小红书找点注意事项发给她，附上几句叮嘱，再补一句“以后有任何问题，随时找我，售后我肯定处理好”。

不满的情况：对方说不合适，立刻进入售后流程。先问清楚哪里不行，请她拍照、录视频留好证据，同步反馈给上家。这里最容易翻车的是，用户正在气头上，你却急着讲对错。千万别讲，先共情。哪怕你觉得自家货没问题，用户觉得有问题，你就先站她一边，跟着吐槽：“这厂家怎么回事？之前推的品都不错，这瑜伽裤好评也多，我寻思肯定好穿，真对不住啊亲爱的。”再丢几个哭脸表情包。用户一看，反倒觉得团长也不容易，是厂家的锅，怪不到你头上。

然后老老实实走售后：反馈上家，争取退换货。

我有一条售后原则：别被眼前一点小利绑住，眼睛要往长远看。碰上真质量问题，我负责到底。来回运费上家只报6块，用户找到的快递要10块，这差价我来补，再单独发个小红包，让她消消气。要是用户主观不喜欢，上家又不给退，金额不大的话，我就自己扛下来。头回下单、正在建立信任的用户，我肯定这么干；老客户遇到同样的事，我也一样接，毕竟人数很少。我甚至试过一单佣金才10块，售后倒贴100多块原价买下。但我觉得值：跟用户的长期信任，比这点小钱重要太多。只要她愿意一直跟我买，这钱早晚十倍回来。

当然，纯粹薅羊毛、爱挑刺的，我不会给第二次机会。服务要有温度，也得有底线。

说到底，快团团没有独家货源，所有团长卖一样的产品，文案、图片都一样，还有人自降佣金打价格战。这时候拼的就是服务链。你比同行多一分贴心，就是自己的竞争力。

3）甜蜜

前面两步走顺，就等于和用户正式进入热恋阶段。小情侣到了这一步，总少不了情书和小礼物，我们对用户也得给足赏酬。海王嘛，就要广撒网，多结缘。

先别错过用户发的动态。我基本看见就赞。她发自拍、晒娃，我评论“好可爱”“好美”；她过生日，我送上“亲爱的生日快乐”。总之，哪儿都有我。有些用户很久没想起我，偶尔刷到我的评论，顺手点进我主页，又被我吸了一波粉。人人都爱听好话，都渴望被看见，这是人性。

再一个，把感谢说出口。我做群带货这些年，一直感念用户的托举。没有她们，我走不到今天。所以在群里、动态里、私聊里，我总把谢谢挂嘴上。重要VIP还会收到我写的亲笔信，一字一字都是感谢和祝福。用户想：我不过是买了点东西，居然帮到了你，你还一直惦记着谢我。这份真诚，会让她更愿意接着帮你。小窍门：在现在这个年代，亲笔信的真心几乎没人扛得住。

还有，记住用户的节日。对她们来说，重要的日子无非生日、母亲节、孩子生日。重要用户过生日，我发个红包，或者悄悄订一束花送到她手上。孩子生日，我给孩子发红包，也一定给妈妈发一个——孩子的生日是母亲的受难日，大家都顾着祝福小寿星，反而忽略最累的妈妈。我太懂这种感受了，所以总会加一句“妈妈辛苦了”。

母亲节这天，我会让送花的小哥早上9点前把花送到用户家门口，一定要赶在老公的花之前。到了圣诞到跨年那阵，我还会给消费前十的VVVIP备一份大礼：价值500多的大牌彩妆，加点年货，谢谢她们这一整年的陪伴。在送礼这件事上，我把双鱼座的浪漫发挥到极致，海王值拉满。

还有一招，当用户背后的用户。别光想着赚人家的钱，看到哪位姐妹做点小生意、搞点小副业，跟你又不冲突，就去捧个场。对方也会把你当自己的顾客来真心相待。有来有往，关系才长久。这也是利他主义。

再来是专属称呼。这条对女性团长尤其好用。我在群里喊大家姐妹，私聊里喊宝贝，跟谈恋爱似的，每一位用户都是我的宝贝。每次聊天的结尾，固定送一句“爱你哦”加亲亲表情包。不知不觉，用户就享受到一种被你宠着的感觉，习惯一天比一天深，慢慢就离不开了。

最后，让自己渗透进用户的生活。我为什么定位成百货商店？因为我想让用户家里吃的用的、老公的内裤、婆婆的拖鞋、睡衣、小孩子的衣服、玩具、绘本，全都从我这儿买。她只要看到这些，就会想起我。日子一长，她买东西前先找我，连淘宝都懒得逛，还觉得我这儿又好又便宜，去别的团长那儿买反而不顺手。

4）投入

人对一件事或一个人投入的时间和精力越多，就会越看重，越舍不得放手。情侣过了热恋期、进入平淡期，靠的就是彼此的付出和投入。激励机制也是这个道理：在你这儿得到的越多，越想继续投入。所以，要和用户产生真正的互动与共鸣。

第一，给出真正有价值的内容。光把货卖好，撑不起长远的用户关系。除了物质，还要喂饱内心。我从2021年开始做个人IP，录短视频、开直播、写文章，聊产后抑郁、女性成长。很多用户就是那时候喜欢上我的：以前只能隔着屏幕看文字，后来在直播间见到真人，不端着、不装，有什么说什么，就直接从粉丝变成了铁粉。也有人会来找我聊自己的困境，我尽最大努力去鼓励、开导。我自己也在不停学习、变好，这种状态不知不觉推着很多用户往前走。我用我的能量，带她们开启了人生新篇章，她们当然也会打心眼里认可我、亲近我。

第二，让用户真正参与进来。这个群做到第6个月时，我遇到了瓶颈：群活跃度往下走，做母婴快团的同行越来越多。我一直在想，怎么把群做成能长期运转、用户也愿意留下的地方？后来看到一门399块的群运营课，抱着试试看的想法学了，还真被点醒——让用户真正参与进来。这个参与，不只是买货，我更希望她们在群里有收获。那会儿我刚生完孩子半年，正在做产后修复，就灵机一动发起一个盆底肌康复打卡：每天花5分钟，跟着康复视频做收缩运动，做完在小程序打卡，坚持满30天送大奖。群里的妈妈大多和我一样需要，我又自掏腰包准备了不少奖品，报名的人特别多。这个动作，一下子把快散架的群救了回来。那个月，大家不光天天打卡，还互相打气，我也因此收拢了一批铁杆用户。

那之后一年多，我又照方抓药，搞过读书会、早睡早起、早晚护肤变美等打卡。又累又花钱，但我很开心。用户只要在参与中有所得，心里就会埋下一颗关于这个群的种子，慢慢生根发芽。另外，还可以把群运营拆出一部分让用户来做，比如请她们做主题分享、认领一些群内岗位，有了责任感，自然离不开。再配合群货币奖励机制，鼓励大家多参与活动，群就能一直活。

以上，就是我的整套海王模型。

我们别只以销售自居，而要把“你”当成一件产品来经营。你推给用户的不是货，而是值得被信赖的“你”。一旦用户对这个“你”形成依赖，你就拥有了极强的竞争优势。用户不只是用户，你要拿她当朋友、当恋人，交付真心。

很多人问我成交的秘诀，我的答案只有一句话：真诚、利他、长期主义。能从头到尾跑完的人不多，大多数人做着做着就放弃了，或者忘了初心，最后失了用户的信任。

而我还在坚持。我也跟用户说过：就算以后不卖货了，我也要把这个群做到80岁，到时候大家还约着一起跳广场舞、一起玩。这是我的期许，也希望自己一直保有初心。
