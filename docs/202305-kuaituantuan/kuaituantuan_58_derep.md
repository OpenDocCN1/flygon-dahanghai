# 4.2 冷启动两步走：先留记忆，再聚客户

冷启动不是碰运气，它有一套可拆解的动作，核心就两件事：先用能打的引流品让人记住你、愿意替你说好话，形成口碑传播；再把真正有需求的人找出来，沉淀进自己的私域。

其中“记忆点”是绕不开的关键。所谓记忆点，说白了就是靠一款好产品，让客户在心里给你留个位置。也因此，冷启动阶段的引流品格外重要。如今团购竞争激烈，引流品必须做到让人眼前一亮，甚至超过客户原本的期待，让他觉得这东西在别处不容易买到。这里要提醒一句：别拿随处可见的大路货做引流，这类产品很难形成记忆点。

那什么样算合格的引流品？可以看三类：一是带地方特色的农产品；二是不太好买的网红款；三是价格有优势的高端产品。引流品选对了，记忆点和优质客户往往一起到手。

客户被吸引来之后，私域怎么搭？建群主要有两条路：线下活动和线上朋友圈。

先看线下活动。可以借社区里的主题活动切入，摆个摊位做分享，把兴趣相投的人拉进同一个群。比如小区里有喜欢自驾露营的邻居，就可以建一个露营交流群。

再看线上朋友圈。思路是用有吸引力的产品或有价值的内容把群建起来，再逐步扩展。具体做法包括：用前面提到的引流品，让感兴趣的客户进群购买；或者发布免费课程、免费讲座、免费资料等有吸引力的内容，引导有兴趣的人加入🛰️群。举个例子，可以请一位专业的朋友在群里分享“如何低碳饮食”，把关注这个话题的人聚到分享群中。

建群本身不算难，真正考验人的是怎样把群运营好、让群保持活跃。这部分后面再展开。
