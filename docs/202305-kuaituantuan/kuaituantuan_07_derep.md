# 1.2.2 能独立供货的团长，强在哪？

所谓供货大团长（后文简称大团长），指的是能独立跑通选货、上架、发货全链路的团长。

这类团长既能亲自把货卖给消费者，也能设定佣金比例，让其他团长参与帮卖并赚取佣金。更省心的是，当顾客通过帮卖团长下单后，订单归属与货款会由系统自动拆分，大团长不用人工处理，结算环节更轻松。这个角色更适合具备选品眼光、活动策划与团长管理能力的商家；其优势还在于，大团长可以通过快团团沉淀私域客户与帮卖团长资源。

快团团虽定位为私域社群团购小程序，却也在私域体系外布局公域帮卖团长流量池，对应项目名为“明星团长计划”。截至目前，官方已组建60多个官方帮卖群、20多个母婴帮卖群，每日由5至6位明星团长在群内推荐商品，触达TOP20000帮卖团长。

想尽快拿到明星团长身份、吸引帮卖团长，官方设定的基础条件如下：

- 在快团团持续卖货不少于60天；
- 连续月度自卖额不低于20万元，或供货额不低于30万元；
- 团成员数量不少于3000人。

因此，若你的供应链优势突出，同时手握私域便于启动（毕竟明星团长对业绩和成员数都有要求），不妨用快团团承接私域流量，再报名明星团长，对接更多公域帮卖团长。
