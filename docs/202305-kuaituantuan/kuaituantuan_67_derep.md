# 4.8.3 🛰️引流：三条路径与一个钩子 @小野 @李晓飞

想把📕上的用户沉淀到🛰️，可以从三个入口入手。

第一条路，先建一个📕群，把群入口挂在相关笔记下方；用户进群后，安排群内小号在固定时间发出🛰️号。
第二条路，用主账号在个人主页把小号@出来；小号简介里提示大家“去看第一篇笔记”，再把联系方式放在那篇笔记中。
第三条路，针对评论区来的流量，先发私信，请对方把自己的联系方式发过来。这里要记住：别拿同一套话术反复用。

至于吸引点怎么设，有个很省事的思路：找到和你节奏相近的人，结伴做同一件事。

拿备孕来说：
“准备要宝宝了，检查该从哪几项开始？”
“有同样在备孕的姐妹吗？来聊聊。”
“帮我看看，这算两条杠吗？”
……
有些内容在📕不方便直接说，放到🛰️群里聊更合适。

同样的逻辑还能换成：
想找人一起拼单吗？
想找搭子一起减脂吗？
想找同伴一起备考吗？
……

你擅长什么，或者正处在什么阶段，就围绕它建对应的社群。这个阶段先把交流做好，别带着功利心。
