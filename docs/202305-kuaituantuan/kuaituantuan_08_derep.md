# 1.2.3 帮卖团长：不囤货也能开卖

所谓帮卖团长，就是直接服务自己团员的卖货角色。这类团长通常手里没有货，却握着一批私域客户。

他们可以替其他团长分销商品，一边让自家粉丝群保持活跃，一边获得佣金回报。

这些初始客户从哪里来？有的靠线上引流，有的靠线下沉淀。比如做过社区团购、菜鸟驿站、母婴店、美容院等实体业务的人，或者本身在线上有粉丝、常活跃于各类社群的人，都可能已经攒下客户资源。

不少朋友🛰️里加了不少人，却迟迟找不到变现方式，也缺少多渠道收入和日常运营动作。此时借助快团团拓展品类，既能增加变现入口，也能像客户身边的哆啦A梦一样，提供更多选择，增强客户黏性。

总体来看，只要愿意服务C端顾客，大多都能做帮卖团长，区别只在于上手快慢。

对多数人而言，进入快团团最快的方式就是先做帮卖团长，这也是本手册接下来重点关注的方向。后续大量内容都会围绕“如何做好帮卖团长”展开。

当然，大团长、自卖团长等其他角色也能受益。后文所讲的选品、引流、建群、社群运营等方法，底层逻辑彼此相通，同样值得借鉴。
