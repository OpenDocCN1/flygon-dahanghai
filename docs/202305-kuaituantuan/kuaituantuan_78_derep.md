# 5.8 社群内容分享法 @小野

想让团购群保持活跃，先要管好新人进群的第一印象：欢迎语、群介绍和群公告都要提前设计，让成员一进来就清楚这个群的定位和能获得的价值。

接下来，要有节奏地持续输出，或者不定期加餐，为群友提供额外价值。比如母婴群可以分享育儿知识、带娃过程中的真实感受，以及自己用过团品后的体验反馈；美食群则可以教具体做法，像怎样煎出完整的包浆豆腐，也可以讲食材选择，比如进口牛肉该怎么挑。这样群才不会变成只发卖货素材的地方，而会更有温度。刚开始内容储备不足也不用着急，优质产品、订单反馈和买家晒图，本身就能成为不错的内容。

还可以把快团团的红包机制用起来。大家愿意在快团团下单，是因为品质不变的前提下价格更划算。利用大家看重实惠的心理，用红包提升黏性；重点不是微信红包，而是快团团红包——它只能在团购里使用，也只能用于下单，对促进成交更有效。

内容来源：《作为职场宝妈，我如何从小红书引流并做到百万营业额的？》
