# 4.5 不靠公域，精准客户也能自己来 @泳怡

1）先把身边的精准人脉攒起来

我最早一批种子客户，来自月子中心和孕妇瑜伽学院。那时我并没有做社群的打算，只是每次胎教课、瑜伽课结束后，会在大厅和同班妈妈们聊一会儿；学院还建了同届妈妈大群，聊着聊着就熟了。月子中心普遍客单5万元以上，孕妇瑜伽一节课300元，这批人的消费能力并不低。所以，多参加本地线下活动、主动社交，是积累客源的好办法，但重点要准，别什么人都加。

2）进对圈子，别急着推销

后来，瑜伽学院的妈妈群又带出好几个妈妈群。那时我时间比较多，爱分享宝宝日常，讲话也有点搞笑，很快在群里混成了“气氛担当”。加上待人真诚，等我做自己的社群时，几位群主主动帮忙宣传，给我带来一批精准、且已有信任基础的客户。

没有现成群怎么办？先摸清用户平时爱买什么。你知道她常买哪些品牌，就能去这些品牌的会员群里找到同类人。比如我的客户看重安全、品牌和颜值，对价格没那么敏感，喜欢一款设计感强、价格小贵的睡袋，均价400多。我也在淘宝买了一件，拆快递看到卡片上的会员群邀请，进去后发现群里几乎都是精准用户。只要在群里正常聊天、用心互动，总能引流一些人到🛰️。混群的诀窍是：别让人一眼看出你是来“捞人”的。就像狼人杀里玩得好的狼人，先把自己当平民，才容易被信任。说到底，别人经营好的私域，也能变成你的公域流量池。

3）服务做透，转介绍会自己发生

我建群时第一批只有42人，最高到过800人，后来清理到462人。这些人是哪来的？我没做公域引流，也几乎不在朋友圈发二维码喊人，全靠转介绍。转介绍的关键，就是口碑和服务。刚开始人多人少不重要，哪怕只有10个人，把她们服务到极致，这10个人至少能带来10个新用户；再把20个人服务好，继续裂变，用户量会超出想象。能培养出100个铁杆粉丝，基本就不愁生意。真心服务、长期坚持，客户会源源不断。我就靠这462位客户，做到人均复购80次。我不贪多，把这462人变成忠实用户，已经够了。
