# 3.3 方法三：先对齐IP，再找对供货大团长 @102℃De 月亮

选品的第一步，不是盯着爆款，而是先问一句：它和我的账号人设搭不搭？

有个真实教训值得警惕。早前做供应链时，曾给一位头部宝爸团长推荐某大牌健身速食鸡胸肉，却忽略了他一直强调“无添加、给孩子更天然的选择”，从不推含添加剂的产品。结果，这笔合作自然没谈成。

除了人设匹配，还要认真看品牌声量，以及开团价和公域价之间的差距。尤其平台大促时，价格波动会更明显，也可能出现非官方旗舰店低价搅局。这些情况要提前向团友说明：我们的选品由官方旗舰店同仓直发，品质有保障。

遇到品牌临期清货，也不能含糊。要在链接的显眼位置反复标明真实保质期，把售后隐患提前化解。

对帮卖团长来说，还有关键一步：挑一个真正适合自己的大团长，并摸清对方的选品逻辑。若能进一步了解其过往职业背景和资源情况，你评估其供应链会更有的放矢。

建议主动加入大团长的素材群。群里通常会有产品预告、详细讲解、客户反馈和素材分发。你可以从中筛出客户可能关心的信息，先保存下来，开团时发到群里，往往能为团购加分。

那靠谱的供货大团长怎么找？关键在识别真实实力：对方给出的价格是否虚高？出现售后时响应和处理是否顺畅？……把多个因素放在一起看，再判断这个供货大团长是否靠得住。

PS：这次航海要让大家跑得更稳、更安全，赚钱官方已经对接了一批靠谱的供货大团长圈友，为项目供应当下可用的货品，帮助大家更快进入状态。具体名单不会现在公开，等开船后会在航海群里统一发给大家。

手里暂时没货的朋友，不妨先从这些供货方提供的产品里挑选适合自己账号的商品来帮卖，成交后就能获得佣金。

至于之后更丰富的供货渠道，还需要各位自行筛选和拓展。
