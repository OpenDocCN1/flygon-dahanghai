# 1.2.4 自卖团长：自己供货自己卖

所谓自卖团长，就是手里掌握线下货源的一类团长。这样的人不仅能给自己供货，还能把发货、售后等环节一并处理好，同时直接触达自己的顾客，也就是团员。尤其适合多多买菜城市经理、连锁店经营者这类线下用户基础雄厚的人，借助线上渠道打开新增量。

当然，前面说到的供应商、大团长、帮卖团长和自卖团长，这四种角色在实际中往往会有交叉。举个例子，我作为大团长，同样可以帮其他大团长分销货品；而当我以帮卖团长身份出现时，顾客看到的始终是“我在卖”，并且平台支持无痕发货。也正因如此，网络效应会更明显，团长与顾客之间的粘性也会更高。
