# 1.2 五类角色，看懂快团团

快团团是一款面向团长私域经营的小程序工具。它运转的底层逻辑，是围绕“供货大团长—帮卖团长—团员”搭起来的帮卖链路。

这套体系里有五类参与者：

• 供应商
• 供货大团长
• 帮卖团长
• 自卖团长
• 团员

这次航海要解决的重点，是带大家搞清楚怎么成为自卖团长或帮卖团长。对于多数已经攒下私域用户的人来说，这是进入快团团最友好、也最直接的路径。

那供货大团长和帮卖团长到底算什么关系？
很多人熟悉平台代理模式，但快团团里的帮卖团长并不是代理。双方是帮卖关系，靠友情互助往前走。大团长与帮卖团长处于平级位置，彼此支持。也正是在这种良性协作中，不少人的业绩起得很快：拿到合适的好货，就能分享给自己的顾客。

快团团以货为核心。作为团长，你既可以去帮卖别人的货，也可以自己开团、邀请别人来帮卖你。
