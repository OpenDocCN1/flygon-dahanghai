# 0️⃣预习准备阶段：先把项目门道摸清

# 一、项目速览

# 1.1 这门生意在做什么？

红包封面已经连续跑了好几年，每逢春节前夕都会迎来一波稳定需求。它门槛低、上手容易，做完很快就能看到反馈。玩法不复杂：借各类封面的新鲜感、稀缺度以及天然适合在社交平台扩散的特点，铺开多个渠道做裂变，最终把流量导向微店成交（多数人用公众号接流，再把微店入口挂进公众号）。顺带还能给公众号涨粉，多一份流量主的收入。

# 1.2 货源从哪儿来？

1、自己动手做

想上架自制封面，第一步是注册微信红包封面开放平台，有两条入口：公众号或者视频号。

走公众号这条路，账号必须已经认证，订阅号、服务号都可以。

走视频号这条路，账号得攒够 100 个真实粉丝。

此外还能借 AI 生成素材，做出别人没有的个性化款式。

2、挂到总店下面做分销

直接挂总店最省心，对方库里有五千多款封面，选择足够多。

好处很直接：不压货、不必自己搭系统、订单自动发出，挣的是佣金；另外你还能在总店定价之上再加一层，差价归自己。

3、拿批发商资格低价进

开通批发商权限后，进货价能压下来一截。

考虑到新手操作不熟，本期实战营直接配好了现成的总店货源，参与者只需专注引流与成交。

# 1.3 买家怎么拿到封面？

客户在微店下单后，系统会下发一串序列号，凭这串号就能兑换对应封面。兑换流程已经画成图，直接转给买家即可。

# 二、动手前的准备

# 2.1 先弄懂微店的分销机制

新手最适合从代理分销切进来，尤其是微信里已经攒了一批好友、手上没有其他电商店铺的人。整个过程不压货，唯一硬性条件是年满 18 周岁。

扫描下方二维码即可提交总店分销申请。通过之后，你的店铺与总店自动打通：商品同步、新品同步、下单自动发货，价格可以自行调整，也能继续发展下一级代理。

具体开店流程安排在后面的章节。

![](img/c24baf0e4675f6c5169667ba72a8f6e8.png)

# 2.2 要备好哪些账号和设备

提醒一句：起步阶段公众号可以先放一放，先用抖音拉流量，让微信和微店负责承接。但等流量体量上来后，公众号这个承接池还是得建起来。

手机

本期建议就用日常在用的那台。之后若打算多号操作或截流，再补一台二手 iPhone 8 或便宜的安卓设备。

千万别碰工作室淘汰下来的机器，这类机子多半被处理过封号，权重很难看。

微信

用于沉淀私域：朋友圈发封面素材和公众号推文，后面招募代理也靠它。

流量卡

直接去运营商 App 挑低月租套餐即可，没有硬性门槛。

抖音号

准备 2 个为佳：主号发内容，另一个小号专门承担引流任务。

公众号

1 个足够，作为接流的主要阵地，建议提前开通。

# 三、几种适合新手的赚钱方式

下面把常见的变现路径过一遍，帮大家建立整体认知。本期实战营的主角是【裂变营销】。

# 3.1 朋友圈直接发

上手最快的一招，就是先发条朋友圈。

比如写：“快过年啦！这边对接到上千套特别可爱有趣的红包封面，欢迎进店挑选~”

下方挂上商城二维码，熟人顺手点进去的概率不低。一单二十几块，你到手能拿 15 元以上。

# 3.2 微店私域卖

门槛最低：开通全店分销，公众号配好自动回复；没有公众号，就靠朋友圈更新，几乎零投入。

# 3.3 电商平台铺货

也就是去淘宝、拼多多、抖店、小红书开店直接卖。特点是收益高但风险也高，需要压货，再借助阿奇索完成自动发货。

# 3.4 裂变营销✅

眼下不少头部卖家都在打这个方向，本期带队的教练也是这么干的，核心在于引流，细节看项目主逻辑部分。

# 3.5 卖工具、卖会员

批发会员本身也能拿来卖：在各个平台投放招募信息，低价进、高价出，中间再做一层包装。

同理还能卖改价工具，或者提供代改价服务。

再进一步，自己琢磨出能省操作的工具，包装成产品对外出售。

# 3.6 收代理、带徒弟

很多人想进场却卡在第一步，这正是收代理的窗口期。去闲鱼挂条信息，能吸引一批有明确意向的人。把项目重新包装，价格往上抬一点，比如 99/159/199/288，提供一对一开店与运营指导。窍门在于：把附赠权益讲得丰富些，再和自己手上的社群产品组合起来，让对方觉得内容很满——其实投入成本很低，比如批量改价教程、批发会员名额之类。

买家常问的几件事：

1、有效期多长？

答：赠品封面的序列号有效期为 90 天，官方规定最长就是三个月，没有能永久使用的封面。

2、买了之后怎么用？

答：按图里的步骤操作即可。

3、一个序列码只能兑一次吗？

答：序列号属于虚拟商品，具有唯一性。一旦发给买家，除本人使用外无法收回再用，因此发出后概不接受任何理由的退款，请确认清楚再下单，谢谢理解。

4、为什么封面上印着别人的名字？（如下图所示）

![](img/253a2b091f235736e9b3d2c506aeb1e5.png)

答：这类属于企业定制版，官方规则就是所有封面都会带作者署名，全都一样，介意水印的请勿拍~
