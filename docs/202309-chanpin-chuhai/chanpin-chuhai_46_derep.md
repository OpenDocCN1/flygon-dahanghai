# 疫情宅家，美国比基尼为何卖爆了？出海品牌必须读懂的场景逻辑

谁能想到，疫情期间在美国市场，比基尼居然成了抢手货。

Costco开市客的户外用品需求暴涨，其中户外SPA设备尤其走俏。这事儿要是没在海外独立屋社区住过，确实很难琢磨透——老美对在自家后院泡按摩浴缸这件事，那是真爱。Jacuzzi按摩浴缸一般搁在后院角落，能加热，和泳池各司其职互不耽误。手头宽裕的，在泳池边再搭个带按摩加热功能的Jacuzzi；预算有限的，直接搬一台放后院完事。周末下了班，男主人或女主人钻进去泡一泡，度假的松弛感说来就来。

这种生活方式，很多华人或者亚洲朋友一时半会儿真适应不了。拿洛杉矶来说，太阳一落山，和白天的温差拉得特别大，夜里常年十摄氏度上下，在院子里泡SPA，外头其实冷得很。但白人、黑人、墨西哥裔这些群体，日常饮食里芝士和高蛋白管够，身体底子热乎，压根不怵冷。外面凉飕飕的，他们照样端着红酒，在院子里的Jacuzzi里泡得悠哉游哉。

谷歌疫情期间的数据显示了一个让人直呼意外的事实：比基尼产品居然跻身热销榜单。跟我交流的一家大型出海品牌也印证了这个销售情况。问题在于，国内做品牌推广的人往往把比基尼当成情趣类商品，这其实是对真实用户消费场景的严重误读。

Stay Home期间，比基尼的出场背景不是海滩，也不是泳池，而是自家后院的SPA。比起去海滩和泳池，后院泡Jacuzzi这件事频率高得多，也实用得多。

还有个容易被忽略的消费场景：老美泡完SPA，不会像咱们国人那样拿手搓一搓比基尼，找根竹竿晾起来。很多城市压根不允许在室外晒衣服，所以他们的习惯是直接丢进洗衣机，洗完再用烘干机一次性把全部衣物烘干。普通家庭大概一周洗一次衣服，宅家期间泡按摩浴缸的次数多了，比基尼换不过来，线上赶紧多下几单，再正常不过。

选择大于努力。跨境出海，搞清楚海外用户的实际消费场景，是选品、设计产品、推广品牌的前提。（我的公众号：出海品牌战略。里面有一段视频，能让没有海外生活经历的产品经理找到些感觉。）
