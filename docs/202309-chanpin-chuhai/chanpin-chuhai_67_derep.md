# 非洲外贸实操：选品、避坑与落地路径

欧美市场卷得厉害，非洲却对个人背景相当宽容，对想寻找新方向的人来说，确实值得认真看一眼。不过，多数人对非洲生意仍停留在模糊印象：哪些品类真正走得动？和当地商人打交道有什么门道？跟已经熟悉的欧美外贸相比，差异又在哪里？本期专栏请来一位在非洲多国常驻过的实战派，他做过肉类和快消品进口，也操盘过机械、轮胎、空调、化肥等出口，这次重点聊选品。欢迎分享。

感谢鱼丸提供这个交流机会。我在非洲多个国家待过，也亲手做过不少品类的国际贸易，希望这次分享能抛砖引玉，认识更多对非洲市场有兴趣的朋友，一起学习、寻找合作可能。

一、非洲市场的机会与门槛

非洲市场最友好的一点，是不查学历、不问出身。当地人口结构偏年轻，对新玩法接受度高。只要肯下功夫，再把平台、商业模式、商品品类和合作对象这四个变量选对，盈利的门槛并不算高。开发客户时，有针对性地扩大接触面，再让口碑慢慢发酵，往往比较奏效。非洲不少产品天然、污染少，价格也有商量余地；同时国家鼓励进口非洲的优质商品。因此无论做进口还是出口，都有可借力的空间。

二、非洲贸易的风险清单

商机多的地方，坑也不会少。需要提前盘算的包括人身安全、传染病、汇率剧烈波动、商业信用、物流时效以及目的国政局变化。第一次去非洲，有极为信任的人引路最好；若没有，就依托知名度较高、口碑较好、手续正规的企业，签证流程务必合规。随身带些零钱以备安全所需，护照原件妥善保管。起步阶段尽量从自己熟悉的行业入手，专业背景本身就是获得信任的敲门砖。做实货贸易，优先选外汇兑换顺畅且相对安全的国家：南非大部分地区（约翰内斯堡个别区域除外）、博茨瓦纳、纳米比亚；西非的科特迪瓦、加纳、喀麦隆；东非的卢旺达、肯尼亚、坦桑尼亚。电商发展较成熟的有南非、肯尼亚、埃及。安哥拉、莫桑比克等葡语国家换汇难度偏高；苏丹、津巴布韦受西方制裁，小规模实货起步会吃力。治安方面，乍得、马里、布基纳法索（西非和中非），索马里、埃塞俄比亚提格雷州（东非），莫桑比克北部（南部非洲）目前都不理想；各国疫情动态也要持续跟踪。

三、进口品类怎么定

汇率是贸易的晴雨表。当前走势对进口方更友好，所以先从进口选品谈起；等体量做起来，进出口可以同时推进，用汇率敞口做自然对冲。

1. 农产品进口的切入方式

非洲农产品和水果的卖点，说到底是打时间差——国内淡季时正好是非洲的收获季。咖啡看卢旺达、埃塞俄比亚、乌干达（很多日本品牌咖啡的豆子其实来自埃塞俄比亚）；辣椒看卢旺达；大豆看贝宁、埃塞俄比亚、坦桑尼亚；水果看南非的鲜葡萄、苹果、柠檬、葡萄柚、橙、柑橘；苜蓿草也来自南非；冷冻牛油果来自肯尼亚；芝麻来自尼日利亚、莫桑比克、坦桑尼亚、苏丹；马达加斯加的丁香也在其列。

拿非洲大豆走一遍流程：第一步是登录海关网站，调出目标国农产品商家的准入名单。名单里的“商家”未必是工厂，也可能是经销商。能进入这个名单，说明已经过海关（原质量检验检疫总局）审核，具备基础信用。名单上通常附有联系人邮箱，可以逐一发送正式询价函，再根据回复的专业程度和规范程度筛选洽谈对象。顺着邮箱和公司名称，一般也能找到企业官网，第一步尽量先要到样品。当地若有信得过的朋友——尤其是懂行的或律师背景的——最好安排实地考察。对方底细不清楚时，付款方式首选不可转让信用证，少用电汇；合同里要把当地验货标准、包装要求、违约条款写清楚；请当地朋友帮忙监装和发运，同时要求供货方出具SGS等第三方验货报告，并按时提供提单、原产地证等文件。

询价反馈的速度也很关键。坦桑尼亚大豆是个典型例子。当时该国只有一家大豆商家在准入名单上；顺着名单里的外方邮箱找到其网站，发现页面有不少法文、在法国也设有公司，于是托坦桑尼亚的法国朋友第一时间对接，顺利拿到报价。报价到手后，要盯住几个细节：有效期（通常几天到几周不等）、付款方式（信用证）、包装与运输方式（集装箱）。国内买家这边，要找有非洲非转基因大豆使用经验的客户，起步期尽量让客户自行清关。

2. 冷冻肉类的操作要点

冷冻肉主要分牛肉、猪肉、鸡肉三类。非洲目前仅有南非和纳米比亚的厂家拿到了冷冻牛肉输华许可，且量不大。近期冷冻牛肉和鸡肉（以冻鸡爪、冻鸡翅为主）的货源多在南美洲（巴西、阿根廷、乌拉圭、玻利维亚）以及俄罗斯等独联体国家。

冷冻猪肉可以拿一个实操案例来说明：经非洲结识的朋友牵线，对接上一家已获准入的欧洲供应商。先签买卖合同，把各时间节点和违约责任定死，买方支付一定比例定金，外方开始备货并安排发运。发运后，外方先把提单和全套清关文件的草本扫描件发来，审核无误再付尾款，外方随后快递文件正本，货柜到港后由客户自己清关。这个模式前后走了数百吨，合作关系也稳定下来。肉类贸易本身不算复杂，难点在选对合作方；然后根据国内客户需求把对内对外合同拟好，尽量挑畅销部位肉（带骨带皮要留意），紧盯价格变化，所有单据仔细核对，避免到港清关被卡。

眼下南美的冷冻鸡爪和冷冻牛肉性价比尚可，但肉类价格波动剧烈，南美国家政策也经常转向（阿根廷就曾暂停牛肉出口一个月），品质和数量参差不齐，甚至出现过同一票货被卖给多个买家的情况；国内港口冻柜滞留和消杀环节增加也是普遍现象。因此起步阶段最好先和有经验的买家捆绑，把风险敞口控制住。等实力积累到一定程度，可以往冷库等仓储、加工环节延伸，逐步搭建自营销售渠道，特别是在综合保税区内对农产品和肉类做初加工；行情变化时，既可以囤货或借助供应链金融等待价格上行再出手，也可以直接深加工、分装（大包装拆小包装）来提升附加值；猪肉已经推出期货，可以考虑与现货做对冲。

3. 快消品进口的落地步骤

欧洲和非洲的一些知名母婴用品、高端服装、家居品牌正在国内找代理，能不能接得住，主要看你手上有哪些销售渠道。以纸尿裤为例：第一步是和国外厂家谈下国内代理权，能拿独家最好；第二步是借助专业进口代理公司把清关流程和中文标签要求摸透——标签一旦不合规，后续非常麻烦。如果这款产品此前没在国内销售过，要让外方先发足量样品，送到海关指定的危险品中心实验室做检验，拿到合格报告后才能顺利清关。欧洲产品的规格和标准与国内存在差异，必须在标签上标注清楚。

四、出口客户开发与品类选择

出口端，产品和合作对象的选择同样关键，收款环节要确保货款来源正规、清晰。做实货贸易，初次见面的分量很重。每次接触客户之前，我都会通过朋友或网络把功课做足，针对对方关注的重点准备介绍材料或带点特色小礼物；交谈时从对方感兴趣的话题或当下业务的痛点切入，让对方迅速看到双方的互补性和合作胜算，小礼物也能加深印象。初步信任建立起来后，靠快速响应和一个个小项目慢慢累积，后来对方一些集成采购业务也交到了我的团队手上。另一个心得是已售产品的后续配件供应，比如发电机、水泵、车辆（轮胎等）、矿用机械的配件。能帮客户解决燃眉之急，关系自然加深。

以疫情为例，不少非洲国家不仅防疫物资短缺，医用注射器、疫苗冷藏箱、药品储存冰柜更是稀缺；与此同时，居家场景下音响、游戏机颇受欢迎。农业和安防领域，支持当地语言的无人机、高清摄像头市场空间可观。日用品方面，假发之外，煤气罐及配件、蚊帐、驱蚊产品在线上推广效果不错。盲盒、手机游戏、手机音乐、手机叫车（优步之外，尼日利亚、肯尼亚、安哥拉都有中国创业者在做）在非洲也有不错的想象空间。

想把已有外国客户的采购量做大，第一步是把售后服务做扎实，买方出了问题能及时解决，口碑立起来，这主要依靠当地合作伙伴；另外可以请非洲本土明星拍平面广告，投放位置包括车身、机场、公路主干道和大型建筑。疫情期间出国不便，要扩大贸易规模就得用好金融工具。重点提一下中国出口信用保险公司——这是国内唯一的政策性出口信用保险机构，不是商业保险公司——的特险业务，中信保同时可以协助审核海外买方的资信状况。特险的逻辑是：卖方允许外国买方在1到2年内分期付款，但通过投保出口信用保险来保障回款；南部和西部非洲的银行贷款利息普遍在15%以上，所以买方通常愿意承担保费来换取分期条件。卖方拿到保单后，可以在国内商业银行做债权买断，相当于银行在货物发运后先把后续分期款垫付给卖方，之后外方分期还款给银行，一旦逾期，信保公司会代为追讨。信保之外，部分商业银行和保理公司也有进出口贸易资金池、循环授信等产品，前提是海外买方足够优质——财务报表健康、负债率低、在行业里有知名度——并且愿意配合。但这样的优质客户并不好找，因此可以转向在非洲有业务的欧洲和中东客户：安哥拉、莫桑比克等葡语国家，找葡萄牙人合作；科特迪瓦、喀麦隆等法语国家，找法国人合作。此外还要算国内与非洲的利息差和汇率差：南部、西部非洲银行年化利息普遍高于15%，汇率波动幅度也大；国内贷款利息在4%到6%，欧元、美元贷款利息不超过3%，这里面的合作空间相当可观。

如果暂时去不了非洲，电商平台是不错的切入点：阿里巴巴国际站、Shopee（主攻东南亚）、京东出海（印尼、泰国站）、阿联酋的NOON、非洲的KILIMALL（肯尼亚站）、JUMIA（覆盖尼日利亚和肯尼亚）、Takealot（南非）、Zando（南非）、Tospino（加纳）等；不少非洲电商平台对中国商家实行免费入驻。我自己也还在学习摸索，之前在生财看到有人通过Shopee往东南亚卖小金龟，很受启发；踩准时机、选对一个细分领域非常重要，希望大家多交流、抱团发展，电商贸易与实体贸易融合创新会很有前景。

评论区里也有不少补充：有读者说老家有人收旧鞋卖到非洲，具体流程不太清楚；嘉宾回应说这条路造就过一批成功者，后来陆续在非洲建厂，尤其在埃塞俄比亚规模很大。另有读者提到TikTok上的自媒体运营和Facebook营销在非洲很有前景；问及Facebook是否投广告，嘉宾答可以在一些非洲明星的脸书上投广告或做隐形带货。还有读者留言“干货满满”，嘉宾回以“互相交流，共同生财”。

五、成长型代理商的挖掘方法

非洲人谈生意比国内直来直去，但生意的延续性偏弱，所以要持续开发新的优质客户，挖掘成长型代理商是重中之重。这既需要勤奋地扩大接触面，也讲究一点缘分；找得准、处得好、共同成长，回报是长期的。这个逻辑类似知名咨询公司更愿意从优秀毕业生里培养人才，而不是靠猎头去挖。国内一家头部白电企业的非洲负责人分享过：刚进入非洲时，冰箱、电视等品类是日韩和欧美品牌的天下，中国品牌不被认可，只能先联系那些不被日韩品牌重视的当地代理商——尤其是有良好教育背景的年轻代理商——或者日韩品牌代理体系里被边缘化的经理人；用更诚恳的合作态度、更贴近当地需求的产品改良（当然还有价格和售后优势）赢得这批人的支持，再配合适当的广告宣传，逐步打开知名度，之后合资建组装厂、发展工业园区，慢慢成长为非洲排名靠前的白电品牌，海外销售额占到集团总销售的30%到50%。合作过程中要多留意伙伴的需求，主动提共赢方案。比如伙伴参与当地电站或医院的建设与设备供货，可以尝试洽商共同参与电站/医院的运营，以及耗材和用品的供应。手机行业的传音在这方面也做得相当出色。

六、非洲贸易的下一步走向

在非洲办企业，门槛并不高，很多模糊地带可以靠人情往来去消化。过去的传统贸易模式，核心就是不停地跑客户：客户下单、安排发货、到港清关，中间不厌其烦地沟通、解决各种问题，满足客户五花八门的要求，最后慢慢筛出互相信任、能一起成长的重点客户。说到底，适应了语言和文化差异、扛过安全和疾病这些坎之后，前期工作做扎实、合作对象选对了，剩下的低买高卖并没有多复杂。但当前的疫情态势和科技迭代速度，让老经验不再完全适用。下一步应该是电商平台与实体贸易两条腿走路，增加产品附加值，打造有差异化的非洲品牌。进口端，可以多伙伴联合批量采购、分散出货、加工增值；出口端，用电商平台开发新客户，借用各类金融工具把优质客户的贸易额做大，在细分领域打出名气。南非、埃及等经济基础较好的国家有不少扶持创业的基金，在非洲上市也并非遥不可及。期待生财有术非洲创富群。
