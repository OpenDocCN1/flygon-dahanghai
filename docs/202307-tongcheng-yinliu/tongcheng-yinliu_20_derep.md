# 500元起号，半月500客、变现15万

大家好，我是井九。潜水多年，这次冒个泡，分享一个自己正在跑的同城商铺转让与招商账号项目。这个方向眼下还算蓝海，我们从搭建账号到第一单成交，启动成本只花了500块；半个月里沉淀了500位精准客户，回款15万元。真实收入其实不止这个数，只是不想被说成标题党，先按15万来讲；而且手上这批线索后续还会继续转化。完整拆解我放在飞书文档里：https://r4d3nnajkk.feishu.cn/docx/OBjId2g9Goz997xr9dccrL4Annf

留言区里也有不少互动：羔羊不会迷失反馈飞书文档没给权限、打不开，我让他稍等，随后把权限打开了。加英留言说看着挺厉害，但自己只对15万感兴趣，正文有点读不下去；我回她：可能是我表达得不够清楚，凑合看吧。阿强先问：客户由我们自己跟进，还是把微信交给现场招商人员？我说签合同后，对方会安排一个人和我们对接，一起带客户，直到签约，后面就由他们接手。阿强接着确认：加上微信之后，是把人直接转给招商那边安排看盘，还是由我们亲自带去看铺？
