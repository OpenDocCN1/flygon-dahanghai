# 月赚2万，棋牌室也是门小生意

周先生这次复盘的，是一个常被忽略的小项目——棋牌室。案例里的结果很直接：月稳定盈利2万元。项目涉及线下实体、美团和私域流量，这几个关键词放在一起，就能看出它不是单纯靠“开门等客”的买卖。

先说说周先生自己的经历。他16岁入伍，20岁开始创业，至今已连续创业7年。做家电代理时，年营收做到500万元以上；在美团担任操盘手期间，年GMV突破5000万元；作为抖音本地生活最早一批入局者，他在这个领域已经干了三年；共享充电宝项目截至目前也为他带来了50万元左右的“躺赚”收益。除此之外，他还为多家实体店做过线上赋能，帮助对方实现业绩倍增。

他很认同猫叔提出的一个词：践写者。军人出身的他执行力很强，写出来的内容都来自亲自下场实践，并且拿到了结果。他反感那种假大空的理论，也不喜欢所谓专家拿一堆自己都没做过的东西当教程。借用李笑来的话来说：只讲、只写自己做过或者曾经做到过的事。

所以这篇内容继续分享一个少有人关注的小项目——棋牌室。评论区里也有不少真实反馈：有人表示感谢分享，有人曾想开无人棋牌室，也有人提醒其中存在风险；还有读者追问，开棋牌室需要什么资质、会不会被公安查、有没有政策风险。这些问题，恰恰是准备入局的人不能绕开的。

小项目不等于没门槛。看懂盈利案例只是第一步，把资质、合规和政策风险提前弄清楚，才是更稳的做法。
