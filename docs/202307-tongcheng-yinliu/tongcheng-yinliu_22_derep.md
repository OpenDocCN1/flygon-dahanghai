# 小红书获客：3条现成文案

很多人笔记发得不少，咨询却不多。问题常常不在内容数量，而在结尾少了一个自然的下一步。下面这3条文案，分别对应资料领取、问题诊断、模板获取，替换成你的行业词就能用。每条都先给价值，再留动作，语气别太硬。

### 笔记标题：别再乱存资料了

做[你的领域]这段时间，我发现不少人不是不努力，是资料太散：今天存一份，明天收藏一篇，真要用时还是找不到。

我把常用清单整理成了一页版，包含[3—5个核心模块]，照着填就能用。

想要的话，评论区留“清单”，我发你。

（适合资料型账号，先把互动留在评论区，再慢慢聊需求。）

### 笔记标题：这类问题，先别急着报课

如果你最近也在为[具体痛点]发愁，先别急着买一堆课。很多问题不是学得少，而是没找到卡点。

我做了一个简单自查表，把[常见误区]和[调整方向]列清楚了。

想要自查表，私信我“自查”，看到会回。

（适合咨询型账号，用私信承接，不硬推。）

### 笔记标题：模板我放主页了

每次发[主题]内容，都有人问模板。

这次直接整理好了：[模板名称]，包含[使用场景]和[填写示例]，新手也能套。

主页有领取入口，找不到就评论区说“模板”，我指给你。

（适合模板、工具型账号，把用户引到主页，动作更轻。）
