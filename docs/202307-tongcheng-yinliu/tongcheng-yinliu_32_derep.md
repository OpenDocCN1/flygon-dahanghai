# 抖音导私域，几招快速加微信

做同城流量时，把抖音粉丝转到微信私域，有一套比较稳的流程。照这个思路操作，基本不会出现封号问题。

**粉丝群是主要入口**
可以先用助理号在粉丝群里放出自己的微信号，让群成员能直接加上。日常内容上，每天发两条生活类短视频，视频里引导粉丝：想联系你，或者想领取某份资料，就点粉丝群入口进群。如果每条视频收尾都直接喊观众进粉丝群，整条视频可能被限流，新手优先选前一种。

**评论区也能放入口**
评论区同样能操作：把粉丝群链接发在评论里，再做置顶，看到的人就能顺着进来。

**小程序加好友看体量**
还可以通过发送链接、走小程序来添加好友。如果你一天能加上几十号人，可以找作者提供这项技术；人少的话不建议用。数量不多时，直接把自己的微信号发出去也没问题。

**直播同样能导流**
直播里可以挂同城小房子；也可以通过小风车导入表单，再引导加微信；还可以让观众先加粉丝群，完成导流。

评论区有人问：发链接会不会被限制？答案是：不会。想进一步沟通，可以联系作者。
