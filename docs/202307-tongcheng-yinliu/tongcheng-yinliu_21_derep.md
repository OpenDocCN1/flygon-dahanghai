# 1700万条检索词，抖音站内搜索还有空位

2022.11.21

1700万条检索记录能看出什么？我的判断是：抖音站内搜索仍有不少需求没被满足，尤其适合用较轻的投入切进去。前几日，我在赚钱社群做了一次内部分享，聊的是怎样进入一块体量达千万的检索流量池，让生意获得持续访客。现将讲稿整理如下，下面几类经营者尤其值得看：

- 区域服务类：区域家装、置业顾问、整屋柜体定制、家用家具、电器检修、跟团游、理发、车辆改装、婚照、毛发移植、旧车交易。
- 连锁经营类：运动鞋护理、空间整理、衣物清洁、地方小吃联营。
- 知识课程类：技能教学、网店运营课、升学与资格证、项目实操班、兴趣课程。
- 单笔成交金额偏高的生意：高端鞋履、康养、闲置名品、保障规划、海外求学。
