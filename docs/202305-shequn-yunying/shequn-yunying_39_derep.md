# 4.6 增长，未必是解药

这一节要反驳一个常见判断：增长未必能解决所有问题，它并不天然等于解药。

先看社群与消费品的差别。消费品交付时间短，用户体验主要发生在使用阶段，交付和使用彼此分开。社群却不同。以一年期付费社群为例，交付要持续整整一年，交付过程和用户使用过程高度重合。正因为这样，社群做不到谁来都收，也不能停止追问：核心用户到底是谁？成员应当有哪些共性，实际又具备哪些共性？一旦定位发生明显偏移，增长反而会把社群带得越来越偏。

再看内核与规模。两者有时并不兼容。微博上社会热点与网络暴力现象同时出现，背后与移动互联网普及、高等教育普及这两个层面的数量级差距不无关系。很多人怀念知乎早期氛围，原因也不只是官方运营水平下滑。还有一个客观因素：规模扩张越过内核之后，又冲破了潜在用户画像的总人数上限。这与运营好坏无关，是增长超限带来的结果。

实际上，不少垂直社群本来就不大。几千人，往往就能把一个圈子基本装完。2017年以前的中国脱口秀行业就是典型：当时有水准的演员，可能一个微信群就装满了。这个阶段想增长，真正要解决的是从业者基数不足，而不是增长本身。

还有一组矛盾：快增长通常对应浅了解，慢增长往往带来深了解。上规模的社群如果没有能力消化快增长涌入的用户，由此产生的负面影响，可能超过增长带来的短期营收。快增长与消化能力、慢增长与营收压力，是一道每次都要做的二选一。若处理不好，暂时停止增长而不是死盯增长，或许是更合适的选择。

此外，还有几种情形值得注意：当社群规模将要超出自身服务能力时，应当关闭增长来限制规模；当社群意外获得一条增长渠道，判断它并不匹配后，应当果断切断——比如创业者社群在聊新机会时涌进一批炒股大妈，显然不算好事；当社群定位处于转折期，对原有增长渠道也要更谨慎。

这些，都是增长光环背后的另一面。
