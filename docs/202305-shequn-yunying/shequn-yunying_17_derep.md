# 3.1 社群成败，系于信任

先抛个问题给大家：运营一个社群，什么才是那个最根本、最不能出错的根基？

别急着往下看，先在心里给自己一个答案。

我猜，你可能会想到这些：

•社群嘛，最重要就是气氛热闹。

•不对，关键是得有大神坐镇撑场面。

•福利和红包必须给足。

•得不停拉新人，否则群里迟早变成一潭死水。

•群主要够有影响力，影响力一大，社群自然好做。

抱歉，这些通通不是正解。

一个社群最核心、最致命的那件事，说到底只有一个：信任。

只不过，“信任”这个词太常出现在鸡汤文章和空洞说教里了，以至于大家一听到它，就下意识觉得“虚”。觉得它不过是漂亮话、是美好的空气、是看不见摸不着的东西、是讲给别人听的大道理、只在谈论人品时才会被提起，甚至觉得它压根没有实际价值。

但我要说，这些认知全都错了。理由很实在：

•信任能满足人类骨子里对确定性的渴望。

•信任是打通沟通障碍最锋利的工具。

•信任是最划算的策略。

•信任可以直接被量化、被货币化。

•信任不只存在于人与人之间，也存在于人与组织、系统、规律之间。

你可以回想一下：听说过信贷、信用卡、M2、准货币吗？听过“三根大阳线改变信仰”吗？听过共识凝结、零信任系统吗？

在那些高度专业的领域里，信任是可以被度量、被计算，甚至能直接“生钱”的。所以，信任绝不是空荡荡的概念。

再看看我们前面第二块内容里聊过的现金收益、杠杆复利、内容沉淀、关系沉淀、贵人乍现——巧了，它们背后，无一不是信任在托底，充当着最底层的那块基石。

我甚至想说，在人类数十万年的演化史上，面对各种未知与变局时，人类最终采用的最有效策略，就是信任。因为作为高级动物的人，天生迷恋确定性。

比如历史上，游牧民族长期拿农耕民族没办法，一个重要原因就在于：农耕民族敢于在完全搞不清地球和太阳真实关系的时候，依然深信节气背后的规律和周期，敢在正确的时节把种子埋进未知的土壤，然后怀着耐心等上几个月，等待大地的回报。

让我再说一遍：人类天生渴求确定性，而信任，正是我们在面对不确定性时，慢慢积累出来的应对策略。

这里花了这么大力气讲信任，不是为了给大家补一堂概念课，而是想帮所有人重新把“信任”摆回真正属于它的位置——在社群里，它始终处于支配地位。如果把它放错了地方，认知一偏，未来在社群战略上就会反复踩坑、反复犯错。

甚至写到这里我有一个念头：哪怕这份手册最后没能像预期那样教会你具体怎么建社群，但只要你因此换了一个全新的视角去理解和审视“信任”这件事，我就觉得值了，对你来说，应该也不亏。

*

所以，信任同样也是社群的地基。

不过反常识的是：一个社群刚诞生的时候，信任几乎是从零开始的。

信任到底在起什么作用？拿知识付费的大 V 和他的粉丝来举例，你可以这样感受一下：我会不会觉得你有本事？你的审美我认不认可？你的专业技能够不够硬、能不能让我服气？你这个人价值取向靠谱吗？你的判断力可信吗？你跟我讲一个陌生的新概念，我愿不愿意信你？——这些，全都归在“信任”的范围里。

说到底，信任是人类在解决这些需求的过程中，慢慢进化出来的一种策略。

*

如果你能接受这个前提，再去倒推，就会发现社群刚刚起步时，必须做两件事：

第一，招募成员一定要慢；第二，丑话一定要说在前面——这里的丑话，先指退出机制。

一句话总结：进人要慢，踢人要快。

•基于信任的第一条策略：慢以凝核

划重点：这是信任延伸出的第一个策略，叫“慢以凝核”。核心就一个字——慢。社群的成员增长，必须慢慢来。

因为人没法做到“今天刚认识，明天就互相信任”，这几乎不可能。信任既重要，又需要时间。所以我们要做的是，先找一个小小的核心团队，带着清晰的策略和决心，一点点把这个核心凝聚起来。而凝合大家的那股胶水，正是信任——这才是最开始该做的事。

有些社群创建者特别爱坑自己。比如上周刚冒出个念头要建群，启动当天就急吼吼地拉进来100个人。这其实相当糟糕。一群彼此不认识、也没有共识的陌生人，得花多长时间才能攒出一点信任？

不如反过来：从最小规模的核心圈层开始，一圈一圈慢慢把信任的外延扩出去。这样反而更快，也更健康。有些人喜欢社群极速扩张，但扩张越猛的社群，往往死得也越快。

所以在社群初期，“慢以凝核”就是避免社群早夭的第一步。

•基于信任的第二条策略：退出机制

退出机制这词听着就明白，简单说说。

社群在发展过程中，成员其实是“盲选”进来的——你没法百分百保证某个人一定适合留在这儿。选错了，就得让人家体面地离开。可如果你一开始没把丑话讲清楚，到时候这个人大概率退不掉，或者退得鸡飞狗跳。

我们有先见之明，能预判这类情况会来，那就要在对方刚刚入群时，第一时间把退出规则交代明白。否则事情拖到最后，局面只会越来越难看，那时候再想让人走，基本就晚了。

而那些不合适的人如果一直被搁在群里，越积越多，对社群绝对是件坏事。没有一套好用的退出机制，最麻烦的后果就是：成员之间没办法越处越凝聚、越处越亲密。老话说得好，“该走的不走，该来的也就不想来了。”

关于信任，真的值得大书特书。接下来，我们去看这一层架构的第二部分——从下往上数第二层，叫“趋同的目的”，或者叫“趋同的目标”。

把“趋同的目的”再压缩一点，四个字就能概括定位：“趋同目的”——更简洁地说，就是“定位”。
