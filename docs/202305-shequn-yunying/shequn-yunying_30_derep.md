# 4.3 社群渠道，不只是引流

很多人把这件事叫作社群引流，但在我看来，叫“社群渠道建设”更贴切。下面为了方便表达，这两个词我会换着用。

先说说我对社群渠道的理解：用户平时常去的地方——线上社区也好，线下场所也罢——他偶然看到你的内容、听到你的消息，被吸引并被引导进你的社群。从这些日常出没点通向社群的那条路径，就是社群渠道。

如果社群本身已经有足够吸引力，引流和渠道建设自然事半功倍；暂时缺这份吸引力，也不代表可以不做。先动起来，比什么都重要。

正式铺渠道之前，有一件事得先完成：把社群需要的各类物料准备齐全。

我们常在不同平台和渠道发布视频、文字、图片或音频。表面看是在推内容，实质上是在面向公众作答一道证明题：社群确实存在，我们讲的价值确实存在，我们说的优势也确实存在。
