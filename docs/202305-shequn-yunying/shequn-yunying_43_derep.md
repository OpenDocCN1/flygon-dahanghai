# 5.3 社群经营，永远在变

社群难管，就难在它从不停留在一个固定状态。起步时方向选对了，中途未必不会走偏；起步时方向有偏差，也未必不能在后续调整回来。社群运转的常态，本就充满变化。

我们不妨把社群的创建者视为首要负责人。只要创建者不再愿意往社群里投入时间和精力，社群就很容易走上下坡路，甚至迅速失速。同样，当成员普遍觉得继续付出时间和心力并不值得，这个社群几乎注定会消散。

说到底，社群靠的是成员参与、时间与注意力的持续支撑。更关键的是，只要这份投入意愿还在，哪怕一个彼此信任很深、平日极少开口的群体，也可能因为一句话重新集结，让分散各地的人迅速聚拢。

因此，社群运营不存在一次到位、永久省心的方案。日常经营当然可以视情况调整力度和节奏，有时轻一些，有时重一些，但持续关注与动态校准不能停。
