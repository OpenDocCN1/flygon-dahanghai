# 4.5.2 内容传播：别把力气用反了

社群会持续产出内容。若想借内容形成被动传播、跑出自增长，策略其实很清楚：把力气花在“容易传播”的内容上，而不是反过来。

常见误区是，我们总想推“容易转化”的内容。可仔细想想，易转化的内容，传播表现往往并不亮眼。推这类内容，表面看转化来得快，底层仍然是主动增长的打法。

而易传播的内容，只要你愿意投入推力，后续就更可能被陌生读者接棒扩散。换一种说法：先让本身走得动的内容出门，把扩散任务交给那些能传播的内容。

这里顺带推荐两本书：《理解媒介》和《舆论》。

那怎么判断一篇内容是否易传播？我会看另一个指标：读到它的人，有多大意愿把它转给别人，或者主动跟人讨论。

举个例子：某些社会事件让人积压情绪和压力，想表达却说不清楚。这时若有人写出一篇透彻、有说服力、能帮人释放情绪的文章，它就会成为无数同频者的“嘴替”。落到数据上，就是阅读量爆发。

反过来，如果一篇文章会让转发者身上多一个负面标签，哪怕作者并非有意，传播也会受阻。

不妨对比两个标题：

一个是“年中就加薪，教你和老板谈工资，彻底KO老板”；
另一个是“职业成长规划指南，职场无它法，打铁还需自身硬”。

哪个更容易被你的用户发到朋友圈？答案很明显：前一个大概率进收藏夹，后一个才会进朋友圈。
