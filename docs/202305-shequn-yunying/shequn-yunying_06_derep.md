# 1.1 社群到底是什么？

我们要回答的第一个问题，本身就不轻松。

社群并不等于拉一个微信群，也不等于建一个知识星球。它属于一种特定组织，是慢慢长出来的共同体，有内核，也会经历兴起与衰落。

更准确地说，把所有人聚成一个整体，再减去个体简单相加的部分，剩下的那层增量才是社群。

地铁车厢里挤着的乘客，不能算社群；小学教室里坐着的那个班，才算社群。

大型活动散场后，仍留在原地没走开的人，连同他们所在的临时微信群，都不能算社群；同一个群里的人如果聊得足够久，聊到愿意张罗一场线下见面会，那才是社群。

看台上为进球欢呼的观众，大概率不算社群；更衣室里并肩作战的那支队伍，大概率算。

身处社群之中的人，会向内部靠拢，会一起做事，会建立连接，也会发生彼此交换。

所以，社群究竟是什么，确实不容易一句话说清。
