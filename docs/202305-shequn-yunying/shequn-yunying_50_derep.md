# 6.1.4 种草易，变现难

用内容去种草，常被视作一种现成的生意模式，可真要落地，远没有想象中轻松。它先勾起购买欲，再把需求引向消费，从而跑通商业化——这条路不容易，却也不是完全没有样本。

看📕的商业化进程，就能感受到其中的难处：平台负责让人心动，成交却常常流向了淘宝。用户在📕被安利，最后到淘宝完成下单。

社群种草也有可行案例。像绿植、多肉这类越养越上头、拍照又容易出片的品类，很适合建群运营：大家在群里互换养护经验，分享新入手的品种。再比如独立设计师做女包的上新群，成员守着群看一款新包从想法变成实物，还能用早鸟价拿下心仪的款式。

但案例归案例，难度依然很高。种草内容更适合作为原有业务的补充，想让它独立撑起整盘业务，几乎不现实。
