# 3.5 适合建社群的人，先看这三点

换个说法，这一节其实是在回答：什么样的人，能把一个社群从零开始搭起来？

先不纠缠五花八门的概念，也暂时放下运营招数，甚至连社群最底层的认知与逻辑都搁一边，或许更容易把这个问题说清楚。

在我看来，下面这几类人，天然更适合牵头建社群。

第一，真诚的人。  
第二，喜欢分享、愿意交流，同时扛得住冷清、经得起挫折的人。  
第三，愿意主动走近别人，也善于体察人心、理解他人的人。

这些才是更靠前的条件。

至于那些做着做着就慢慢明白的事、可以习得的认知、能够学会的技巧，还有各种运营工具和软件，起初都不必背在身上。它们都藏在后天里，不用一上来就给自己压太重的包袱。实践时多留心，遇到了就试着掌握，就够了。

也正因如此，这一节的标题叫「社群牵头人应有的品质」，而不是「社群牵头人应该懂得的知识」。
