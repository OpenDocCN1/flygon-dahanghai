# 0.2 这些，本手册不教

这本手册不打算手把手带你拉微信群、开 Discord 频道、申请知识星球。它要回答的是：一个社群怎样才算真正立住，如何依靠自身长起来；以及面对一个平台，怎样判断它是否适合承载你的那类社群。

它也不会教你写那种冲着营销去的招募海报，不拆解高转化付费社群的转化文案，更不聊低转高怎么埋点、锁单、冲转化率，也不谈怎么把微信好友当成一波流量去收割。它关心的是另一件事：怎样找到并建立社群真正的价值，又怎样让别人看见这份价值。

分佣合伙人怎么发展、三级以上分佣梯度怎么设计，这里也不会展开。这里要谈的是，如何同你真正期待的人一起共建社群，以及你们应该把注意力放在哪里。

本手册不把社群当成一个特殊运营工种来讨论。它要讲的是：社群怎样成为商业模式的 MVP，甚至直接成为商业模式；社群又怎样改变一个人观察世界的方式。

那些别处反复传的运营招法，本书略过；速朽的知识，也不占篇幅。但如果你把这里的内容吃透，你就有能力看穿别处招法背后的逻辑和破绽。

所以，这本手册会有点不一样，甚至不太按常理出牌。但它足够独特。我还能保证另一件事：书里这些社群知识，五百年后——也许是 2523 年——仍能帮到一个真心想创建社群的入行者。至于内容难不难，我不保证；我只保证逻辑结实。

以上，是启航前你需要知道的事。系好安全带，出发。
