# 1.3 哪种群算不上社群？

平台、App 这类载体，也能装别的东西。可有些群从一开始就不该套用社群思路，否则方向会走偏。

下面这些，都只能算“容器”，称不上社群：

- 大型行业峰会在现场临时拉的交流群；
- 只为完成一次成交而建的群；
- 从低价产品往高价产品引流的群；
- 裂变活动后按编号批量拉起的群；
- 只有流量、没有用户沉淀的群；
- 物业给业主建的群、税务部门给会计们建的群。

这不是在给群分高下，社群未必更好，非社群也未必更差。只不过，社群那套方法，放到这些场景里可以借鉴，不能全套复制。

为何只说“单次成交群”不算社群？因为它值得单独聊一聊。

像低价转高价的训练营、七天的体验营，按我的定义都不算社群。它们的共同点是：服务的是运营方，对业绩指标负责，而不是替用户创造价值。

这并不代表这类群没有价值。相反，设计它们时，更应该从业务优先的立场出发，把运营周期定得短一点。

一个很典型的别扭操作是：

① 目标明明就是转化，却在群里把建群初心说成“让大家多沟通”“做点有用的事”“会时不时请行家来分享”；
② 七天的运营结束之后，业务团队眼里这类群已经没有用了，可运营者又舍不得解散，总想让成员再多得到一点。

于是，群没散，也没了新话题；用户和运营方都找不到留下的理由，这群慢慢就没了活力。

最后，分享一个我做了近十年社群运营的体会🧐：社群刚起步时和中间阶段，最怕群主不露面；偶尔才冒一次泡，社群几乎不可能做成。
