# 6.1.2 电商社群，复购定生死

我把社群这件事做了11年，只见过一个例外：不靠复购，也能把商业化跑通。除此之外，所有电商社群都逃不过一个定律——复购为王。说白了，所谓的电商社群，本质上都是复购社群。没有复购，电商社群无从谈起。

为什么这么绝对？因为一个社群的成交频率上不去，商业化的盘子就很难做大。别说什么养整个团队，现实点，你至少得靠它养得起一个人。这是最基础的门槛。

所以，选品方向从一开始就注定结局。举个例子，同样的资源，你去做女装群，大概率比做男鞋群要顺得多。原因很简单：女装消费频次高，顾客容易反复下单；男鞋属于低频品类，等一次复购往往要等很久。

很多人喜欢在群里搞积分、等级、成长体系，觉得这是运营的核心。但这些玩法能不能奏效，归根结底要看社群本身是否能持续产生复购。没有复购这个地基，再漂亮的体系也只是空中楼阁。

那唯一的例外是怎么玩的？他们叫“线上看房团”，专注跨城市房产投资。具体操作是：线上先组队，线下由领队带着实地看房；看中之后，群主就以中介身份介入，促成签约成交。群费则用来AA食宿开支。整个群从建立到解散通常只有一周，看房行程结束，群也就随之解散。

这种模式，一期一会，没有复购，却靠单笔大额交易把商业化目标完成了。除此之外，我没有见过第二条路。
