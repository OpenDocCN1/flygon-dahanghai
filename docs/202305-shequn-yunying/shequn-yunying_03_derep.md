# 0.1 手册学习路径：三步走，边学边建群

Naval 有句话很值得先放在前面：学会卖，也学会造；两样都拿下，你基本就很难被拦住。会造的人去补销售，往往比会卖的人去补建造更顺；建造者的手艺得一直更新，而销售能力会随着公司成长，越往后越能放大。

我研究社群这件事，从 2012 年算起，已经十一年了。

社群好玩的地方就在于：它没那么难，也没那么容易。像“生财有术”那样，做出一个生命力强、在行业里有分量、商业价值也够的社群，是正确却不容易的事。最难的在于，社群不是货架上的标准品，也不是需求一清二楚的平台，而是一直在变；社群的好坏，又始终跟里面的人绑在一起，剥不开。这一点很不一样。所以做社群不是轻活，挑战多、麻烦多，但成就感也足。

可它又确实容易：你可以从很小的切口起步，一个群主就能开干，不一定先凑齐一个团队。这种拧巴感，正是社群的吸引力。

这本手册想让你在接触社群时先别急着扎进具体玩法，把节奏放慢，从社群的第一性原理进入。它会帮你把“社群”这类组织的关键概念拆开讲透，也让你有勇气：就算前期做废几个群，自己也会因此更强；同时有信心把社群做得比同行更出彩。

具体到学习路径，我这样安排：

- 第一步，先把社群的底层概念与价值吃透，回答“是什么”。
- 第二步，再进一步，从原点出发讲建群的方法论和原理框架，重点放在实践心法，回答“为什么”和“怎么做”。
- 第三步，在前两步之上，聊增长、聊长期存活，再深入社群商业化，给出足够多的变现可能。
- 另外，实践卡点的答疑（会沉淀到手册的百问百答里）和航海活动，会作为伴随状态跟三个阶段并行。

时间安排上，三个阶段落在本次航海的第一周和第二周；“工作坊”式的航海实践——亲手建群——则排在第二周和第三周。航海更准确的路线图，去群里看吧。
