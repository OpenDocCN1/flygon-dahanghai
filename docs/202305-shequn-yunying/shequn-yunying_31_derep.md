# 4.3.1 自有渠道引流：别把“发了”当成“透了”

自有渠道做引流，其实是所有路径里最省事的一种。拿面向职场人的👸号「辉哥奇谭」来说，他的操作就很有代表性——每篇正文底下几乎都会固定出现一张图，展示付费知识星球里正在发生什么。这个位置稳到像在文章里单独辟了个小栏目，长期、持续地把星球亮出来。

但这里藏着一个大家常犯的误区：**“对全部成员可见”不等于“全域曝光”。**

很多人手里都有自己的一点基本盘，👸号、抖音、📕、贴吧、博客、论坛，总归有个能发声的地方。可即便在你影响力最大的阵地上，多数人漏掉的动作恰恰是——持续透出。不少人觉得，我已经专门发过一篇文章或一条视频介绍自己了，这还不够吗？真不够。

拿👸号来算笔账。打开率能到 2%—3% 已经算高了，可这也意味着，哪怕这 3% 的阅读全是你自己的读者，剩下 97% 的人压根不知道你建了个社群。这中间差了多少？33 倍。如果你因为不好意思，只发一次；或者找不到不打扰粉丝的发布方式，就只愿意打扰一次——粗略一算，你等于主动放弃了这条渠道上 32 倍的增长空间。

那多发几遍行不行？同一篇内容反复推，也不可取，因为对那 3% 的人来说就是反复干扰。更稳妥的做法是不断换新形式，长的短的交替来，持续做下去，这样才有可能在单一渠道里实现全量透出。所以，全量透出看的不是你发布时勾没勾“所有人”，而是实际上有多少人真的知道了你在做这件事。这两件事差别很大。

「辉哥奇谭」就是个好例子：他每篇文章都用不一样的短内容去做透出，文章写得好的时候还会突破正常阅读量，触达新的人群。到今天，他的知识星球成员已经超过 1.5 万人，年费 420 元。

再看📕。那边的引流通常比较低调，一般就是在账号主页放上个人🛰️、助理🛰️或者社群对接人。但说实话，📕、B 站、抖音这类账号，和真实世界接触的所有点位里，浏览量最大的绝不是主页。虽然每条作品都会带一部分人点进主页看看，可主页透出只能证明你埋了个入口，体量并不乐观。想想看，用户在 Feed 流里刷到一条更新，顺着视频再点进主页的可能性有多大？转化率通常就在千分之几这个量级。更好的办法或许不是死守主页，而是就地解决——在你当天新增播放量最大的那条作品下面，置顶一条评论，效果可能更直接。

那能不能干脆把“社群招募”本身做成内容发出去引流？可以，但难度不小。你既指望它传播，又指望它招募转化，这两个目标会互相削弱，平衡很难拿捏。一般不推荐，但也不妨一试。

*

说完渠道上的误区，再聊一个关键词：**信念感**。

一旦决定做这件事，你得真心相信自己做的东西是好的、有益的，是从用户需求出发尽了最大努力的，不只是拿来变现，也是别人真正需要的。如果没有“用户很可能需要我的社群，只是还不知道它有多好”这种信念，每次提到自己花心血搭建、花精力运营的社群，你就会觉得自己在打广告。这种心态会严重影响你把宣发渗透进日常内容创作的方方面面，最终拖住社群的增长。

当然，那种极端的、到处见缝插针、广告感拉满的账号确实招人烦，我个人也很反感。但这不代表打广告本身不对，不对的是不厌其烦、不分场合、打断别人话题去刷千篇一律的广告。我们得有个信念：哪怕全方位地讲，也可以和那些像狗皮膏药、像牛皮癣一样无处不在的做法不一样。

我们是在分享自己打造的作品，不是拿社群做流量变现；我们是通过作品创造价值并获得酬劳，不是圈钱割韭菜。用户对我们表达的是认可——他们用脚投票，在社群里活跃；用钱包投票，付费加入。这种信念感会驱动我们更好地思考和实践怎么构建社群，也会支撑我们更坦然、更坦率地推荐别人付费加入。

（顺便说一句：把用户叫“韭菜”的人，在我这儿永远学不会社群的构建和经营。）

*

如果你不想千篇一律地宣发社群，还能怎么办？答案就在社群里。

一个健康的社群，里面发生的事是方方面面的。你完全不必每次都把社群整体搬出来对外展示吸引力。这周可以讲社群里发生的段子；下周可以拿大家共创的好内容去馋人；再下一次可以公开复盘一场线上活动以及它带来的反响；再下一次讲讲用户加入后发生了哪些改变、拿到了什么成果。这些都是社群氛围和社群价值的不同侧面，拿它们当吸铁石、当有吸引力的引流种子，宣发内容自然就丰富了。

我把这招叫“万变不离其宗法”——宗生万变，以万变引人入胜就够了。（读到这里你大概更能明白，前面为什么要花那么大篇幅讲社群的“宗”。道理很朴素：无宗，就生不出万变。）

万变会不会招人反感？其实大家反感的从来不是你做社群或者有个商业化产品，而是你把大家已经知道的信息一遍又一遍地反复透出，像鲁迅笔下极度絮叨的祥林嫂。那潜在用户排斥吗？不排斥。他可能上次讲的已经知道了，也期待加入，但眼下看到的东西还不足以让他做决定。这时候你自然要回答一个问题：你有没有更有力的东西，帮他更好地判断该不该加入这个群体？

*

以上这些，把引流和渠道建设路上最常见的坑、误区以及背后的逻辑都讲清楚了。在渠道归类上，自己的朋友圈、👸号、📕，以及 B 站、抖音、快手、视频号这些短视频账号，都算以自己影响力为辐射半径的自有渠道、自留地。
