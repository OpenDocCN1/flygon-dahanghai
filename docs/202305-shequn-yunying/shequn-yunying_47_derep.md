# 6.1.1 收费，不妨直说

社群想变现，最短的路子就是把价格摆到明面上，不必像互联网常说的那样绕一圈“让羊毛出在猪身上”。只要社群确实能帮到成员，明码标价收取费用就是顺理成章的事。

收款方式上，最轻量的做法是在微信里直接收款或用群收款，操作都顺手。如果帖子和内容在社群里占比较重，知识星球最合适；个人使用由平台代缴20%的税。面向海外的社群要过语言关和文化关，Telegram、Discord都是不错的选择。想离用户近一些，付费QQ群，以及抖音、小红书、快手的主页粉丝群都合适；群本身没有收费入口时，可以在直播间用礼物打赏作为进群门槛。抖音上做课程加社群，用学浪最省事。

当成员愿意掏钱的动力足够大，具体收款形式反而不必看得太重，别在这上面反复纠结。

哪些内容适合明码标价？信息、认知、社交、培训服务、陪跑、陪伴，都是常见的付费点。拿买相机和玩摄影来举例：

- 信息型：把各相机品牌的新品动态和实时报价整理进付费群。
- 认知型：讲清成像质量怎么判断，以及旁轴、全画幅等概念的基本原理，做成付费社群。
- 社交型：跟着知名摄影师同行，并结识一批摄影高手和同好，为入群付费。
- 培训服务型：为接写真单、冲击摄影奖项而设训练营，先付费进群，一周理论加三周实操。
- 陪跑型：照片总出问题，发到群里请教，群友水平相近，年费包含指导100张照片，群主遇到好片还会在群内拆解分析。
- 陪伴型：大家一起研究摄影、折腾器材、互换闲置镜头、淘老相机、约着街拍。

当然，这些类型并非彼此隔绝；同为社群，它们可以混搭，也能互相转化。不同主题往往倾向不同做法，比如减脂、减肥类一般做训练营；营养搭配、宝宝辅餐类通常是培训服务加陪伴式社群，并请一位营养师坐镇。
