# 年入百万的爆款，被一纸投诉截断

做亚马逊那些年，我手里出过一个利润很猛的单品。客单价不低，同行不算多，每单毛利能到近千元；平时每天最少出一单，行情好的时候一天二十几单也跑过。圈里其他卖家原本各做各的，低调挣钱，谁也不声张。

平静是被一个人打破的。他出手把平台上卖同款的卖家大批量投诉到下架。

我顺着投诉信里的专利号去查持有人，发现对方是中国卖家。这款产品怎么来的，我心里有数——他根本不是真正的原创发明人，只是把专利抢先注册了。

我先自己写申诉，没通过；又去找服务商，对方一听涉及专利就摆手，说这种申诉做不了。我没有停，继续往下查，终于看到欧洲外观专利的一个空子。当时美国外观专利大概要花两万元，周期十二到十八个月，还不容易批；欧洲外观专利只要七千左右，一个月就能下证。规则卡的是生效日：证书生效之后上架的产品，一投诉一个准。我的老变体侥幸没事，新变体全军覆没。

局面很难看，可我还是不甘心。仓库里压着几十万的货，总不能一句“平安是福、身体要紧”就认了。平台申诉走不通，我只能试着找对方谈，哪怕只有一线生机。要谈，先得把人挖出来。

怎么找？手上只有投诉信里那个专利号，只能拿现有信息顺藤摸瓜。弯路走过不少，这里只说走通的那条线。

专利号先查出持有人拼音lijianguo（化名），地址在深圳。我回亚马逊搜同款卖家，判断实力最强的那家嫌疑最大。店铺上的公司名和地址通常不可信，深圳挂靠地址注册公司开号太常见了；不过，有一个税号让我上了心。

拿这个税号去谷歌搜，又发现一个eBay店也在用它。eBay店卖家的拼音是chenxiaomei（化名），跟专利人对不上，但两人之间肯定有牵连。我再用天眼查翻法人，按拼音猜汉字，陈小美、陈晓美之类都试了一遍，最后圈定几家深圳电商公司。从这些公司找到招聘广告，摸到联系电话；又去钉钉通讯录对英文名；接着上Facebook翻，果然看到有人晒这款暴利产品，目标范围一下缩得很小。

我想加他微信，第一次没通过。后来在他们公司其他招聘信息里找到另一个人的号码，加过去通过了。翻朋友圈看到对方晒车，借着车牌号再用“召唤术”把他的底细查清。线索拼起来：专利持有人和eBay店持有人是夫妻，亚马逊店铺挂的是亲属。目标就此锁定。

接下来就是谈判。电话打通，我说明来意，对方起初想搪塞；我亮出底牌，他才答应见面。到他公司谈完，结果是还能继续卖，但附带若干条件。后来我还是清货退出了，实在没有安全感。

这事让我总结出三点。

第一，亚马逊的水比想象中深，好产品得先穿好盔甲。辛辛苦苦开发出来的东西被人截走，那种疼只有经历过才懂。有条件就尽早申请专利、做自己的品牌。

第二，我不赞成用阴招攻击别人，人在做天在看。但别把每个人都当软柿子，我这次只想和谈清货；真遇上不要命的，鱼死网破也不是没可能。

第三，一把刀在医生手里能救人，在歹徒手里能伤人，侦查能力也是同样的道理。不去害人，但必须懂得防人，个人隐私也要护好。

后话也得交代。这个产品的供货商跟我合作多年，早年我创业时帮过我。他跟我倒苦水，说不少客户都被那个投诉人搞掉了，工厂快撑不住。我起初有点犹豫，后来还是想明白了：我和投诉人有过节不假，可供货商对我有恩。于是我把投诉人的电话给了供货商，让他自己去争取订单。做人做事，有时难免要用点非常手段，但最后得对得起良心。

评论区里，不少同行说感同身受，也有人追问我查车牌那招到底是什么手段。这个就不公开细说了，留点悬念，线下再聊。
