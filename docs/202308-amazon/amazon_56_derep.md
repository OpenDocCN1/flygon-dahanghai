# 125天做到亚马逊盈利过万，我交了什么学费

我是郑小焦。在生财这个圈子里，我已经待满一年半；身份也从上班族切换成了自由职业者。四个月过去，阶段性的第一站到了，我想把这段复盘和成长摊开来聊聊，也和大家共勉。

这篇被加精的复盘收获了153个赞，讲的是亚马逊从0到盈利1w+的125天。里面既有我因鲁莽付出的代价，也有被现实推着快速成长的部分。完整长文在这里：https://shimo.im/docs/Kdk9xJtpjkxVtrXj ，原复盘发布于2021年2月28日。
