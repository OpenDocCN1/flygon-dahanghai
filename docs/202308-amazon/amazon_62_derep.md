# 从产品创新到垂类品牌站：我的实战复盘

我是FB，人在深圳。在生财待了不短时间，之前多半是默默潜水、看大家分享。这次把自己亲身跑过的一段创业案例整理成一篇复盘，写给圈里两类朋友：做产品的电商人，和做电商的产品人。

这个案例会跨到产品开发，相关篇幅不少。所以，不光电商尤其跨境卖家能借鉴，传统制造企业，以及产品公司里准备下场做2C产品的人，也可以拿来参考。

亦仁提醒过，开头最好先把拿到的成绩摆出来——这次复盘我也按这个思路来。帖子发出后，有圈友留言说“正是我需要的”，也有人觉得厉害；后来亦仁感谢分享并加了精华。评论区还有做亚马逊FBA空运海运的深圳坂田物流同行留言，做亚马逊的朋友如果发货想降运费，可以自行联系。

感谢生财有术。
