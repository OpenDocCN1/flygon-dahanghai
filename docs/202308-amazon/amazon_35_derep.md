# (精华帖)(117赞)如何找到不起眼但有销售空间的小产品

**冷门小产品，利润却藏得深**

做亚马逊七年，我手里管着11个卖家账号，去年一个小号就卖出了65万美元以上。这次想跟大家聊聊我们团队一直在用的类目选品思路——不追热闹，专找那些看着不起眼、却很有销售空间的小产品。

因为文中配图比较多，我把内容整理成了一份文档，希望能给同样在做电商的朋友一点参考。这篇是首发，也冲着龙珠来的。想更深入地聊亚马逊卖家那些事，欢迎加VX：ltx281703。

具体怎么找？先从一个很实用的切口入手：评论数量不少、但评分不太理想的产品。中等资金、百万左右的盘子，可以盯竞争小、市场容量大、非季节性的标品，针对它的差评点做改良，但别把产品搞得太复杂。新品期流量标签清晰，配合测评和广告去打，成功率会高一些。

第三种方法是通过NODE ID选品，这招确实厉害，也最繁琐。要在大量产品里翻出市场机会，重点看星级低、评论少，同时成本低、利润高的那一类。

第四种思路来自网购行为本身：优先做FBA，尽早积累测评，再根据亚马逊的属性框去布局listing。

评论区也有朋友问这套方法能不能搬到淘宝，我觉得电商平台底层逻辑大同小异。还有人追问Node ID数据去哪里下载，这类数据需要自己花时间整理。另有读者提到曾想手动遍历亚马逊四十个大类目、做成Excel表格，后来发现只有类目标题没有数据，工作量太大，暂时没看出太大价值，只搭了个雏形。这些尝试也说明，选品这件事没有捷径，关键还是找到适合自己的筛选路径。
