> **身份**：AI编程创业者，创业刚满一年。之前一直在互联网公司打工，给老板当下属——那种老板喝酒的时候突然想起你没完成的工作，掏出手机一顿语音轰炸的那种。去年正式出来创业，本来计划今年招10来个人，结果今年2月决定不招人类员工了——因为发现数字员工比人类员工稳定太多。目前用OpenAI Codex跑通了一人公司模式：2月出国玩了两三个星期，只开过一次电脑（还是因为Codex坏了修了一下），业务反而还有增长。在生财有术发过一篇"5分钟做一个星座算命产品"的帖子引爆关注，和亦仁因此结缘。开了AI编程付费课程（已售罄），写过一篇200块的付费公众号文章卖了700单十几万。公众号因为发了"今年不招人类员工"被限流，但这件事本身就说明内容击中了痛点。师从傅盛（猎豹移动CEO），傅盛春节滑雪摔断腿后在病床上开始研究Codex，用Codex发公众号阅读量从6000飙到好几万，还做了100多万访问量的趋势页面。

## 道（底层认知）

### AI编程不是让你写代码，是给你几十个不用发工资的员工

你想不想有几十个人天天给你打工，你又不怎么发工资？AI编程就是这么一个手段。所以我把它叫"普通人最后的阶梯"——普通人雇不起几十个人，但AI可以。

很多人心里犯嘀咕，觉得祖上18代都没写过代码，为什么要碰这个东西。我跟你说，AI编程给你的不是代码能力，是一种自由——想干什么干什么，不想干什么不干什么，万事不求人。亦仁昨天也讲了，搞了编程之后觉得自己无所不能，非常膨胀。这种膨胀是对的。

去年3月我在这里问"谁用过AI编程"，大概只有10%的人举手。今年刚才我看，70%了。短短一年，从没人关注到大部分人都用过了，这非常恐怖。

### 快不等于自动化，帮你做不等于替你做

这是过去一年AI编程最大的认知升级。AI做事当然很快，但快不等于自动化。你口喷几句话代码就能出来，效率很高了——但你还是在赛博摆摊，手停口停的生意。

你想想你平时最常用AI做的那件事情，当你不打开电脑的时候，它还在持续产生结果吗？你每天要盯竞品动态、要发小红书、要处理用户——在你不打开电脑的时候，它还在自动产生结果吗？

如果没有，你就还在摆摊。摆摊和自动售货机的区别是：摊主在，生意在；摊主走了，生意就没了。自动售货机不管在写字楼还是在机场，从来没有看到过人，任何时候都能卖东西，说不好比摆摊的小卖部还便宜。

我大概去年五六月开始思考这个问题：你睡觉的时候，AI有没有在帮你赚钱？然后不断把工作流往释放自己时间的方向去规划，现在已经实现了大部分。

### 从操作者变成管理者，核心能力是管理学

经常有人问我AI编程最重要的是什么？其实可能是管理能力。抽象一层你想想——以前叫提示工程，其实就是一种管理学，让你怎么跟员工把话说清楚。后来他们说叫Context Engineering，上下文工程，也是管理学——你跟员工讲事情的时候，要把相关背景交代清楚。本质上，AI编程就是管理学。

### 选择才是你唯一的创造过程

我现在有个新的体会：AI干活，人类只做选择，而做选择就是你的创造过程。以前小时候听人说"小孩才做选择，大人全都要"，现在反过来了——大人才是做选择的。因为Codex可以给你做很多事情，但每一件事你需要去拍板、去决策。你选哪一个都意味着放弃另一个，而放弃就是你的代价。

说实话，这种状态是一种心累。以前你自己做，做完一份自己满意的东西交出去，很踏实。现在有大量的工作等着你做选择，反而累了。所以我后来想明白了：还是要有人类员工，不是因为AI不行，是因为你可以把选择的权利分出去。"这个产品你负责了，你只要不把我的产品干死，赚多赚少我们再讨论。"这样我才能更轻松。

## 法（方法论）

### AI编程的六个阶段：从玩具到全职员工

我非常反对一个对AI编程不了解的小白直接去用Codex。你用不好的，放心。就好比自动驾驶已经非常成熟了，但也没有一个国家取消驾照。Codex就是自动驾驶，前面的AI编程工具是手动驾驶——你得先会开车。计算器100年前就有了，但今天每个国家的教育都有数学课，你还是得背九九乘法表。如果你没有对数学的直觉，你走不远。AI编程也一样。

六个阶段是这样的：

**阶段一：玩具。** 打开一个网页，随便说两句话，做出一个小游戏、小工具。核心是好玩有趣，但不赚钱。2023年就有了，2024年开始流行——v0、Bolt这些产品。我当年在生财有术发帖"5分钟做一个星座算命"，就是这种东西。玩具阶段的价值是入门、是给别人快速展示原型。你跟人吃饭聊到一个项目，掏出手机随便就做了一个原型给他看，大家基于原型来交流。但它的局限是只能做简单demo，上不了复杂度。

**阶段二：工具（Cursor）。** 这时候AI编程成了你的工具，可以做出商业上能打的产品了。我创业第一年用Cursor做了好几个产品，一个月也有几百万的合约。它像手机摄影——直接出来就很好看，9成以上的人够用了。但它明着便宜暗着贵，20美元套餐如果你是熟手小半天就用完了。而且项目太大hold不住，上下文容易丢。

**阶段三：副驾（VS Code + 插件）。** 这是手机升级到单反。VS Code支持插件，你可以根据不同场景选不同的AI编程插件——Claude Code插件、Cursor插件，自由组合。上限极高，可以驾驭复杂项目。但局限是你还得全程盯屏幕，被限制在电脑前面。

**前三个阶段我叫"摆摊区"——不管你效率多高，本质还是手停口停。**

**阶段四：Claude Code（命令行）。** 分水岭来了。IDE消失了，黑乎乎的命令行工具，一行一行文字在滚。它第一次有了一些主动性。我去年七八月那次破圈就是用Claude Code——一个月200美元的套餐，实际可以用到五六万美金的量。复杂任务让它跑一晚上不用管。我有个习惯是睡觉前给它布置任务，让它自己验收，第二天中午起床去验收，有时候甚至还没跑完。而且不只是写代码——公司里除了写代码之外的一切，用户运营、产品宣传、日常管理，都用它。

**阶段五：Claude Code（实习生级）。** 今年1月出来之后更奇怪了——连代码都消失了。你直接用业务语言沟通，它自己选技术方案、自己写代码测试，最后给你的是结果——一个PPT文件、一个Excel文件。一天之内美国上市软件公司蒸发了3000多亿美元。因为甲方自己懂业务，在窗口里喷几句东西就出来了，不需要为第三方软件付钱。我这次演讲的PPT和逐字稿几乎全是它做的。

**阶段六：Codex（全职员工）。** 连电脑都消失了。你手机发完指令就走了，它自己找活干、自己交报告。我以前在前公司，老板喝酒的时候想起什么工作，掏出手机给我发一通语音就继续喝酒去了。我现在跟Codex就是这个关系——突然想到一个什么，掏出手机说完就不管了，等它交付就行。2月出国玩了两三个星期，只开过一次电脑，业务还有增长。

### 选岗位，不选任务——这是搭自动售货机的关键

你想完成第一台自动售货机，要选的是岗位而不是任务。任务是一次性的——"帮我写一个公众号"，这叫任务。岗位是每天早上8点先看什么资讯，然后选题，然后初稿，然后排版，再发布——多个任务串起来，周而复始执行，这叫岗位。

选了岗位之后要写一个SOP——岗位说明书。怎么写？你就假设今天刚招了一个名校毕业的实习生，你怎么教实习生，就怎么教AI。步骤一、步骤二、步骤三，写清楚做什么、怎么做、每一步怎么算做好了、什么时候需要跟老板商量、什么时候需要汇报。用业务语言描述，不需要技术语言。

然后让AI跑一遍，跑的过程你就观察，出了问题就改SOP。一般三五遍就可以了——跟带实习生一模一样。我以前带实习生也是先交代完，坐他旁边跟他干一遍，干错了不着急，哥哥再教你一遍。三五遍之后我就走了，第二天开始验收产出。养Codex的过程就跟带实习生一模一样。持续一周它都能稳定运行，你的某个岗位就被外包出去了。

### 第一个岗位，从图文自媒体开始

如果你想搞自动售货机，找我推荐最简单的行动路线，我真的建议你从图文类自媒体开始。你的第一个岗位就是自动选题、排版、发布的闭环。图文类自媒体要求的每个技能都不高深，产出结果也好验收——看一眼就知道行不行。不管你是小红书、公众号还是推特，都可以试。

傅盛就是个活例子。春节期间滑雪摔断腿，员工都找不着，被迫在病床上研究Codex。用Codex发公众号，阅读量从以前的6000飙到好几万，趋势页面100多万访问量。一个企业家因为偶然的原因腿断了，逼着自己用数字员工，用完觉得真香。

## 术（现在直接用）

- **自动化产品优化**：把用户行为数据、服务器日志、数据库数据全给Codex，让它每天自动发现问题并修复。以前需要运维发现问题→叫醒程序员→产品经理分析→QA测试→运维上线，跨部门协调一周。现在Codex一个"人"把五六个岗位的活干了，全自动。
- **AI写日报**：Codex每天自动写日报，写到飞书文档里。内容包括今日对话摘要、完成的任务（打勾）、配置变化、甚至反思（"被小排总吐槽话太多，反省中"）。比任何人类员工写得好——人类员工发日报1万个不乐意，写了也没几个字。
- **及时通知系统**：通过飞书的及时通知功能，设定监控事件——订单大涨/大跌、服务器异常、负载即将爆掉。如果你在飞书前面直接弹通知，不在的话可以用飞书的接口给你打电话。
- **自动监控竞品**：给Codex一个竞品清单和观察维度。它每天像人一样去体验竞品功能、看社交媒体讨论、搜索热点趋势、查技术蛛丝马迹（比如竞品还没发布的功能藏在代码仓库里）。最后出报告：谁上线了什么、价格变了多少、站点结构变化、运营动作改变、域名权重涨跌。第一次调比较辛苦，调完之后再也不用手动打开这些东西了。做电商的用得比我还勤——盯竞品上了什么新产品、新关键词、谁调价了。
- **自动发公众号**：设定一个岗位，每天根据本人喜好自动选题、写稿、排版，出来的东西"我理论上可以直接复制到公众号发出去，根本看不出来不是我写的，因为语言风格也是我的"。
- **Codex做PPT和演讲稿**：把自己的公众号文章和生财有术帖子全部下载到本地，授权Codex访问文件夹，语音输入演讲大纲和素材要求。一个多小时出了逐字稿+PPT，逐字稿1万多字配截图，几乎不用手动调。
- **用Codex做完整产品**：朋友在Codex聊天界面里，从选择域名→购买域名→写代码→部署上线→接入支付网关→测试→再部署，全程手机操作，人看都不用看一眼，完成一个能收钱的网站。

## 器（知道就行）

- **玩具阶段**：v0、Bolt 等网页端AI编程工具
- **工具阶段**：Cursor（一站式AI编程IDE，20美元/月套餐，熟手小半天用完）
- **副驾阶段**：VS Code + AI编程插件（Claude Code插件、Cursor插件等自由组合）
- **命令行阶段**：Claude Code（命令行工具，200美元/月套餐）
- **实习生阶段**：Claude Code 新版（业务语言沟通，自动选技术方案和写代码）
- **全职员工阶段**：OpenAI Codex（开源，手机端操作，Agent自动找活干）
- **协作工具**：飞书（日报、及时通知、电话提醒）
- **辅助**：语音输入（跟AI沟通用口述方式最快）
