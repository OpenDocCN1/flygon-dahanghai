# 先懂用户，再谈📕种草

在📕做内容，想赢得喜欢、推动转化，第一步不是急着发笔记，而是吃透用户想要什么、怎么想、又如何行动。这个平台的内核是内容驱动种草，但种草并不等于照搬电商式硬广、产品陈列图，也不是靠泛娱乐内容堆热度。

用户来到📕，通常带着两类诉求：一是添置商品或服务，二是获取知识，不论免费还是付费。

他们的行动方式也大致分两种。第一种目标明确，会主动检索、浏览经验帖和攻略，被内容打动后完成下单。比如临时起意想入手某品牌口红，先搜真实体验、评价与攻略，确认合适再购买；这类人往往消费意向很强，属于精准用户。第二种没有明确任务，只是随意浏览；一旦平台推送的分享正合心意，同样可能被说服并下单。

路径其实一致：先由目的或兴趣触发，再被有价值的内容打动，最后才走到下单等消费动作。

那什么叫有价值？当一篇笔记能让人愿意点赞、收藏，甚至直接产生消费，多半是它至少交付了以下两类价值中的一种：情绪价值，或者实用价值。
