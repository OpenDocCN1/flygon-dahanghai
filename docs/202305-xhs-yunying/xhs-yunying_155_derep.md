# 5.2.5 私信别晾着，流量才接得住 @杨星城

小红书和微信的使用习惯完全不同。微信很多人每天都会点开，而小红书往往是用户闲着没事，或者刚好有需求时才刷到内容；至于他们下一次再打开是什么时候，谁也说不准。因此，私信如果回得不够快，很多本来可以转化、可以引流的时机就会悄悄溜走。

还有一种更让人难受的情况：某篇笔记突然火了，私信多到手动回复根本忙不过来。流量是做出来了，却接不住，这比一开始没做出流量还让人心疼。遇到这种局面，就需要借助自动化工具来帮忙，不必时时刻刻守在后台，也能把时间省下来。
