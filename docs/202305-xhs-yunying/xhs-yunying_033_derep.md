# 2.1.2.1 定位的底层逻辑：越窄，越准，越能赚

做定位，说白了就一句话：你到底想吸引谁、你的内容做给谁看。想清楚这个问题，定位就成了一半。

手上已经有产品或服务的人，这件事相对简单——锁定你所在细分赛道的受众就行。举个例子，假如你深耕新中式风格设计，客户集中在三十到五十多岁这个年龄段，那你对外呈现的个人IP就要贴着这群人的审美偏好来打磨，发的内容也要围绕他们关心的、能促使他们主动询单的话题去展开。

但如果你既没有现成的产品，也还没想好做什么方向，不妨从下面两条路径里挑一条走走看：

其一，从自己拿手的领域里，挑一个离变现更近的切口；
其二，从自己感兴趣的领域里找出相对擅长的部分，再从中筛选出离钱更近的那一块。

不管走哪条路，一旦敲定了具体的细分方向，接下来包装IP、规划内容，都必须紧扣这个方向的目标人群来做。拿低卡美食举例，你在这个方向上内容产出能力很强，平台广告变现的反馈也不错，那就把IP形象朝着目标受众喜欢的样子去塑造，发布他们愿意看、也容易被种草的内容。

说到底，在小红书上，无论你有没有产品、选了哪个赛道，定位这件事都得往窄里做、往深里挖。切口越小，触达的人反而越精准，转化和变现也才真正跑得通。
