# 6.3.2 训练营变现记 @蓝子鱼

在演讲机构待了整整三年，培训那套体系、讲课的节奏、用户的需求点，我早就摸得门儿清。所以当想到要变现的时候，我几乎没有犹豫，就直接锁定了这个方向。

亦仁有句话我一直记着：想判断一个产品靠不靠谱，别想太多，先写一段简单的介绍扔出去，看看有没有人愿意掏钱。我就照着做了，把课程内容用文字列了个大概，挂出去卖。结果当天就有4个人付款。那一刻我就明白，这个课程是有真实需求的。

印象最深的是一个会员，她准备面试幼儿园老师，特别紧张。她刚交完钱，我立刻在微信上发语音过去，一步一步教她该怎么讲、怎么表现。这么做有两个目的：一是检验我教的东西到底管不管用；二是把过程记录下来，以后就是现成的案例素材。

训练营里一共放了14节高情商沟通的音频课。那些标题，全是从学员平时问得最多的问题里提炼的；课程框架，是我拿以前积累的东西搭的；具体内容呢，就靠翻书、看文章一点点补全。

关于录音，我多说一句：如果你声音条件好，自己录完全没问题。要是觉得不太满意，可以找配音平台，把文字丢进去，直接生成音频，省下来的时间可不是一星半点。
