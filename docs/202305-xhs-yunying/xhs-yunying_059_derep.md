# 3.1.2 什么内容才算“有用”？

怎样判断一篇笔记有没有实用价值？通俗讲，就是读者刷完之后能感到这篇内容解决了问题、提供了帮助，并让自己有所得。

这类内容通常分成两种：一种帮用户找到值得买的好物或值得去的有趣地点，替他们省下时间、金钱和精力；另一种传递知识，让用户开阔眼界、获得成长。

在📕，只有少部分用户是为了放松娱乐，更多人带着明确需求来寻找对自己有用的信息，消费意愿也比较强。

想挑口红，人们会看种草、测评和选购避坑；想学做饭，会找菜谱、食材与厨具挑选攻略；希望升职加薪，会参考职场进阶方法；准备装修，则会收藏家居好店清单、施工经验和避坑要点……

账号刚起步时，不妨先把实用型笔记放在前面。这类内容操作门槛不高，出现爆款的概率更大，对账号权重的积累也更有利。
