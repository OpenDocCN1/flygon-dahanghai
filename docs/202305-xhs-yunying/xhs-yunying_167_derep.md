# 7.1 技巧一：让账号像个真人 @绅沐 、@包小滚

用户为什么会持续关注一个博主？内容有用当然重要，但另一个原因往往在于，这个账号背后的人本身有吸引力。可能是外形气质让人喜欢，可能是做事认真、学习投入，也可能是价值观让人产生认同感。

所以，真人博主首先要和批量复制内容的营销号拉开距离，让粉丝觉得自己关注的是一个有生活、有情绪、有判断的人，而不是一个只会发内容的账号。

运营小红书真人 IP 时，个人形象要先立起来，营销感则要尽量收住。日常更新可以围绕生活记录、经验总结和知识输出展开，踏踏实实写自己原创且有质量的内容。尤其在起步阶段，不要一上来就频繁推荐产品；带货痕迹太重，平台容易把你判定为营销号，推荐和流量都会受影响。
