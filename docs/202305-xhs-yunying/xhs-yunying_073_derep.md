# 3.3 选题去哪找？

💡

做内容最头疼的，往往不是写不出来，而是压根不知道写什么。其实选题并不靠灵光一闪，它有稳定的来源。下面几条路，走通一条就够你用很久。

第一，去用户的问题里找。评论区、私信、社群聊天、搜索框的下拉词，都是真实需求。谁在为什么发愁，哪里就有现成的题目。

第二，跟热点，但别只凑热闹。热点只是入口，真正要做的是把它和你的领域、用户关心的难题接上。热点会过去，问题会留下。

第三，翻同行，但别照搬。看高赞内容在讲什么，更要看它没讲透什么、评论区还在追问什么。别人漏掉的那一块，可能就是你的机会。

第四，从自己的经历里挖。踩过的坑、解决过的问题、被问过很多次的经验，都是带体温的选题。你熟悉的场景，往往正是别人缺的答案。

第五，用关键词做组合。把主话题加上人群、场景、问题或结果，比如“新手”“第一次”“踩坑”“怎么选”，一个关键词就能拆出一串题目。

第六，建一个选题库。平时随手记，别等要更新了才临时抱佛脚。先从一个渠道开始，每天存三条，一周后再筛，能写的自然就浮出来了。

选题不是一次想十个，而是找到能持续供给的来源。来源稳了，更新就不慌。
