# 3.8.1 让四成笔记直接带来成交

想让用户看完就产生购买动作，请把四成笔记留给“直接导向付费”的内容。别兜圈子，重点就两块。

1）开门见山：把你能提供的产品和服务摆出来

同时要让人一眼看到：你给的东西比同行更足，价格还更低。对，就这么直白。

比如卖包子，可以这样发：

标题：老王包子多少钱、卖什么，一次讲清

正文：我家包子有豆沙、猪肉、牛肉、胡萝卜四种馅。全部由师傅手工包制，皮薄、馅足，吃完心情好，爬六楼都轻松。买包子还送定制环保纸袋，拎着出门很时尚，这一点别家没有。

再配一张截图：你家包子3元一个，同行10元一个。看到笔记来咨询的人，第一句话往往就是：“你好，我想找你买包子。”

• 把真实好评和使用结果晒出来，和同行的差异要讲明白

晒评价时别只贴一句“好吃”。讲一个有起伏的小故事：用户先在别家踩了坑，后来找到我们，终于买到满意的包子。人天生爱看故事，故事也更容易让人相信你。
