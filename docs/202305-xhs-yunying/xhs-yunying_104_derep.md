# 先上手，再规划笔记配比

前期不必急着把账号的内容类型定死。为了尽快摸清📕笔记的写法，建议先动手发起来，做贴合平台表达习惯的内容。等积累到一定数据量、也做出过📕爆款笔记之后，再认真考虑📕IP账号的内容类型布局。

不同笔记承担的任务并不一样：有些负责冲流量、拉曝光和关注；有些则负责承接引流与转化。按这个目标，可以把笔记分成三类：

1. 能引导付费、但不易成为爆款的笔记；
2. 容易成为爆款、却较难触发用户付费的笔记；
3. 既容易成为爆款、又能导向付费的笔记。

日常发布时，要有意识地调节各类笔记的数量，通过合理配比，把引流和转化效果尽量放大。
