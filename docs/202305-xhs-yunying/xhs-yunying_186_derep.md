# 8.2 粉丝500就来广告？我的小红书宝妈起号实录 @Ariel

小红书的主要用户，和我自己的画像很接近：生活在一二线城市、年龄在20—40岁的女性。她们在意审美，有学习的能力和意愿，也具备消费力，这恰好与母婴内容的目标人群高度重合。平时刷小红书时，我关注了不少母婴账号，不同细分方向的内容能帮我解决各种育儿问题。

后来起号时，我选的方向和个人经历有关——母婴知识里的孕期控糖。这个方向恰好是平台上相对空缺的内容，所以几篇笔记发出去后就出现了小爆款，直到现在仍能持续带来流量。

我的长处在于：有一手育儿经验，喜欢学习，也乐于分享，另外还有多年英语教学背景。定赛道时，我想把自身优势串起来，于是去咨询了老师。她建议我先从最贴近自己的母婴方向起步，之后逐步过渡，后期可以转向英语启蒙。

起步阶段时间比较宽裕，我能保持稳定输出，账号数据表现也还可以。粉丝大约五百时，就有广告主动找上门；半年内合作接了不少，报价从几百元到最高两千多元的婴儿车推广都有。
