# 5.1.11 玩法十一：用企业号矩阵铺内容，引流私域 @杨星城

如果目标是把用户引到微信，最划算的方式就是注册多个企业号，批量铺内容。哪怕某个号做废了也无所谓，你要的不是站内好看的数据，而是真实转化到私域。

个人号得花时间养权重，而且私信稍微频繁一点就容易触碰到红线。企业号呢，得给平台交600元的认证费，相对安稳得多。说白了，你给了平台钱，平台也就睁只眼闭只眼。这样的号本身也带有企业或商业属性，而不是纯分享型博主靠爱发电。

很多新手或者自由职业者没有营业执照？办法总比困难多。去淘宝搜“个体户营业执照办理”，花30～46元就能搞定。选海南那边办更便宜，也不一定非得和你的所在地一致，第二天拿证，马上就能开工。

注意，一张营业执照可以认证3个企业号，而个人名下可以办多张执照。这意味着你可以不断复制号，形成矩阵。

可能有人担心：这么粗暴会不会封号？从我实操经验看，一个号回复300～500条私信，尚未出现过违规。超过500条就有一定风险，我曾经因此被提醒过一次。更多时候是笔记爆了，评论区的“1”刷太多，被系统识别出来，随即停止流量。

所以放心大胆操作，一天回复100～200多个关注者完全没问题。唯一要注意的是，私信话术和配图尽量多准备几组不一样的，别让系统一眼识别出重复内容。
