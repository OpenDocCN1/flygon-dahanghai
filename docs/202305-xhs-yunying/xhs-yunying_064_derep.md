# 3.2.1.2 视频笔记：短视频为什么值得发？

不知道你有没有发现，现在的小红书上，视频笔记已经越来越常见了。和图文笔记相比，这种形式有不少肉眼可见的优势。

**第一，更有“面对面”的交流感。**  
用户往往是带着某个问题，或者单纯因为好奇才点开你的笔记。而你在视频里分享经历、表达观点，有画面、有声音，语气又偏口语化，就像在和对方聊天。这样一来，距离感会被明显拉近。

**第二，更容易立住个人IP。**  
视频里有具体的音画，用户能通过一个个场景感受到你是个什么样的人，真实感和立体感都会更强。相比图文，个人风格更容易被记住，人设也会更鲜明。

**第三，平台会给一定的流量扶持。**  
随着短视频越来越主流，小红书对视频笔记也会有一些流量倾斜，所以这类内容往往能获得更多曝光。拿我自己在航海期间的经历来说，之前发图文，几十篇里能上千的也就几篇；后来发了6条视频，其中5条曝光都在500以上。并不是说这数据多厉害，但至少我的小眼睛是实实在在涨上来了。

**第四，同质化风险低，不容易被搬运。**  
图文内容经常会被“像素级”模仿，而视频从策划到制作都需要更高的成本，天然不容易被原样复制。也正因为如此，视频带来的粉丝粘性会更强。

当然，视频笔记也不是没有门槛。它的确有利有弊，下面这几个问题，你需要提前想明白。

1. **时间成本更高。** 视频要做脚本、拍素材、配音、剪辑，每个环节都要花心思，整体耗时和成本自然比图文多。不过这个问题，后面我会分享自己的解决办法。
2. **5秒定律。** 如果开头5秒没抓住用户眼球，很可能直接被划走，完播率也会受影响。所以脚本的开局怎么设计，非常关键。这一点可以借鉴前几天大芝的分享：走差异化路线。
3. **心理卡点。** 有不少人总觉得自己不够好看，或者声音不好听，一边渴望拍视频，一边又忍不住抗拒。但真的不用太担心，因为视频笔记并不等于必须真人出镜。下面这几类不露脸的视频方向，可以给你参考：

对新手来说，最稳妥的路径是先用图文笔记锻炼选题和内容创作能力，等运营经验积累得差不多了，再慢慢向视频笔记过渡。

总的来说，图文在种草这件事上更顺手，视频在立人设方面更占优。至于最终怎么选，还是要回归你自己的实际需求。
