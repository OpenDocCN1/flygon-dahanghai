# 《AI 航海实战手册》

> 面向零基础入门者的 AI 实战指南，从“大模型是什么”到“产品出海与 GEO”，全书 35 章，每章配套小练习，以“出成品”为学习标准。

## 📖 书籍简介

《AI 航海实战手册》是一本面向**只会电脑基础操作的入门者**的 AI 实战手册。全书不假设读者有任何编程、设计、运营背景，用大白话解释核心概念，配 Mermaid 图表与可运行代码，带读者从“听过 AI”走到“用 AI 出成品、拿 AI 接单”。

全书共 **35 章**，分为九个部分，覆盖 AI 认知、文字创作、视觉与绘画、视频制作、应用开发、自动化工作流、AI Agent、商业变现、前沿趋势等方向。

## ✍️ 写作要求（来自 AGENTS.md）

编写每章正文前，须遵守以下规则：

1. **先参考草稿和素材**，保持草稿的章节结构不变，可直接摘抄素材原文，并尽可能多填充内容，使内容更加充实。
2. 如果素材不够，再调用百度搜索，**返回至少 20 条结果**。
3. **面向只会电脑基础操作的入门者**，没有任何其它知识。
4. 语言风格**详细且直白**，重要概念用**大白话**解释，可以添加一些废话，使行文更加自然流畅。
5. 核心概念添加 **Mermaid 图表**来解释。
6. 如果一个操作需要编程实现，附上**完整代码**，添加**详细注释**。
7. 如果需要插入图片，优先从素材中寻找；如果素材没有，可以调用百度搜索；如果再没有，就编写图片描述，**链接位置留空**。
8.  正文中不要出现“对应素材”小节和素材名称

## 📚 学习建议

1. **按章顺序学习**：全书采用“认知 → 工具 → 实战 → 变现 → 前沿”的递进结构，建议从第1章开始顺序阅读。
2. **边读边动手**：每章末尾都有配套小练习，建议完成练习后再进入下一章，以“出成品”为学习标准。
3. **不怕废话**：书中故意保留了大白话解释和过渡性废话，降低阅读门槛，不需要跳过。
4. **遇到不会的概念**：优先回到本章的 Mermaid 图表或“大白话”段落重新阅读。
