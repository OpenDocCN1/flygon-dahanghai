## 🎯 如何使用本书

本书面向**只会电脑基础操作的入门者**，没有任何其它知识背景要求。

**建议学习路径**：
1. 按章顺序阅读，从第一部分开始
2. 每章阅读完成后，务必完成章末的“配套小练习”
3. 以“出成品”为学习标准，每节练习都应有实际产出物
4. 如需深入某个知识点，可参考细纲中标注的素材目录，位于 `../../docs/<素材目录>/README.md`

## 📝 写作要求（来自 AGENTS.md）

1. 编写每章正文之前先参考素材，如果不够再调用百度搜索，返回至少 20 条结果
2. 面向只会电脑基础操作的入门者，没有任何其它知识
3. 语言风格详细且直白，重要概念用大白话解释，可以添加一些废话，使行文更加自然流畅
4. 核心概念添加 Mermaid 图表来解释
5. 如果一个操作需要编程实现，附上完整代码，添加详细注释
6. 如果需要插入图片，优先从素材中寻找，如果素材没有，可以调用百度搜索来寻找，如果再没有，就编写图片描述，链接位置留空
7. 细纲位于 `asset/detail.md`
8. 素材位于 `../*/README.md`
