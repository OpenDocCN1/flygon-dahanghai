# 6.3 两个好用的链游数据工具

想摸清 GameFi 项目的底细，有两个工具值得放进收藏夹。Coingecko 此前已经聊过，它能帮我们查看游戏类项目的排名，以及按市值排列的位置。

Footprint 则更适合观察游戏走势和活跃玩家规模。它的能力不止于链游：这是一个综合型数据分析平台，NFT 以及其他数据也能分析，今天只是拿游戏板块做示例。

在 Footprint 里，能看到整体日成交额。眼下处于熊市，交易额不高，大约 300 多万美元；单日交易数量同样不大，约两千万币。每天的游戏用户数显示为 88 万。和 Web2 游戏相比，这个数字背后的增长想象空间很大。整个游戏板块的体量会随行情起伏：牛市时很高，熊市时明显回落，与大市场环境关系密切。

链游的活跃项目分布也值得留意。从活跃项目数量看，目前规模最大的公链是以太坊；在去中心化公链里，大家对以太坊的共识和信仰最强。币安这条公链流量较大，在链游项目上，币安智能链拿下了最大的市场份额，排在第一位。原因主要有两点：一是游戏对效率极其敏感，交易手续费、处理速度、链容量和性能都要跟得上；二是 BNB 智能链整体性能表现很好，尽管去中心化程度未必比以太坊更强。按公链统计，BNB 链上的游戏用户数量最高，超过 800 万；以太坊则只有 70 多万。这跟以太坊手续费偏高、交易速度不够快有很大关系。

从 Web3 架构看，GameFi 属于应用层。发展至今，链游有两个主要特征：

• 游戏道具 NFT 化。传统游戏里，道具产权实际掌握在发行方手中，平台可以收回你的装备；一旦平台跑路，道具也会一起消失。链游则不同，道具做成 NFT 后，产权归用户所有。

• DeFi 游戏化。当前绝大多数 Web3 游戏，内核仍是 DeFi，只是把各种金融产品放进游戏场景中呈现，核心卖点是让玩家在玩的过程中获得收益。
