# 3.2 钱包怎么挑？先看懂分类

聊钱包，先理清四个常见说法：中心化钱包、去中心化钱包、热钱包、冷钱包。

判断中心化还是去中心化，关键看私钥归谁管。私钥在平台或机构手里的，是中心化钱包；私钥由用户自己保管的，是去中心化钱包。

中心化钱包最典型的用法，就是交易所账户里的钱包。拿币安来说，想在上面买卖数字货币，得先注册账号、设置密码，还要提交 Web2 身份资料，流程和开证券账户差不多。这本质上是把钱包交给交易所代管，前提是你信任它。

从行业现状看，如果资产规模不算大，头部中心化钱包的安全性往往优于去中心化钱包，币安在安全技术上的投入和能力很强。但它也有短板：会受监管影响，个别账号可能因监管措施被冻结资产。

去中心化钱包再往下分，就是冷钱包和热钱包，区别在于私钥存储过程是否联网。冷钱包不触网，常见形态是硬件钱包，类似银行 U 盾；私钥的生成与使用都在离线设备里完成，不接触网络，安全性更高。热钱包则在生成和使用时联网，比如常用的小狐狸钱包，创建和操作过程都离不开网络。

那到底怎么选？比较稳妥的组合是“中心化交易所钱包 + 冷钱包”。热钱包安全性偏弱，也容易遇到钓鱼风险，不适合放较大金额的资产。
