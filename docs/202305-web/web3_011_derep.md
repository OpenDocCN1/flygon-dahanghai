# 1.6 本节复盘：Web3 入门关键点

这一节走到收尾，我们把前面的脉络再捋一遍。

第一节，我们聊了 Web3 为什么值得关注。

第二节，我们说明了 Web3 到底是什么：Web1 是只读型网络，Web2 升级为可读可写，Web3 则被视为价值网络——数据所有权回到用户手中。

第三节，我们站在 Web3 的视角，拆解了 Web2 当前存在的问题，以及 Web3 能对应解决什么。具体包括：用户的数字身份被平台掌控、数字资产并不真正归用户所有、用户本该获得的收益被拿走、平台与内容创作者之间的权利关系明显失衡、支付层面存在限制；同时也梳理了“Web2 有什么问题、Web3 解决了什么问题、Web2 与 Web3 的差异、谷歌与以太坊的对照”。

第四节，我们拿 Web2 和 Web3 中有代表性的生态——谷歌和以太坊——做案例比较，从盈利模式、增长路径、融资手段三个角度，帮助大家理解两者的不同。

第五节，我们给出了一套从资本视角审视 Web3 的方法。

整个第一节的 Web3 概述，不只是帮助大家建立 Web3 的概念，还提供了两项实操方法和五道思考题。

想知道加密资产的历史价格怎么查？可以用 Coingecko 这个网站。

想寻找优质 Web3 项目，或者手里已有项目需要判断？我们给了一个辅助思路：从资本视角出发，借助 Cyberhunter 去观察。

五道思考题是：

1. 哪些使用场景在 Web2 里做不了，只有 Web3 才能承载？
2. 如果存在这样的场景，对应的 Web3 产品会有多大的用户需求？
3. 在这些场景中，Web3 方案解决问题的效率是否更高？
4. 如果你认为并不存在必须依靠 Web3 解决的问题，Web3 还会不会继续发展？原因是什么？
5. Web2 与 Web3 的投资机构、普通投资者各自能得到什么，又要承担哪些风险？

从下一节开始，我们会把 Web3 层层拆开，从底层技术一路讲到热门应用，并带着大家动手实践。
