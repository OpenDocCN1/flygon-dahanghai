# 2.3.3.1 分叉之后，谁在变？

同一次硬分叉，最终走向了两条不同的路。

一条是 ETC。它坚持区块链最原始的不可篡改原则：记录一旦落定，就不该再被回滚，账本形成了什么，就该一直是什么。

另一条则是如今更常见的 ETH。它更强调社区协作：当极端情况出现时，创始团队和社区可以共同推动规则调整。两条链各自拥有代币，原链代币叫 ETC，分叉后的新链代币叫 ETH。从市场表现和实际使用情况看，ETH 显然是当下更主流的选择。

比特币又是另一种样本。它至今可被视为高度去中心化的网络：中本聪的真实身份无人知晓，后来这个网名也从网络世界隐退。没有谁在台前发号施令，网络却依照既定的记账奖励机制自动运行了十多年。

比特币并非没有分叉历史。为了解决支付效率问题，它曾分出 BCH，但新链并没有赢得广泛共识。比特币选择以稳定规则应对变化，简单反而成了力量。它不必靠频繁迭代和效率提升来证明自己，如今已经是 Web3 世界的一个标志性存在。

以太坊则不同。它从诞生起就把效率写进目标，后续的演进也围绕吞吐能力和使用体验持续优化。每一次升级，本质上都在追求更高的效率。

这或许能留下一个值得琢磨的问题：为什么有些事物必须不断进化，而有些事物却能让规则保持不变，以不变应万变？
