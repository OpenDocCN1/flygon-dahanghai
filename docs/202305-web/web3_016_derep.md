# 2.3.1 以太坊到底解决了什么？

学到这里，大家应该已经对以太坊有了一个基本的印象。再重申一遍，以太坊给自己的定位很明确：一个面向智能合约与去中心化应用的平台。如果你还是觉得抽象，不妨先把它想象成一个自带支付系统的安卓操作系统。

那么问题来了——当初创造以太坊的人，究竟看到了什么痛点？

一句话讲透：比特币那套体系，解决的其实只有“转账”这一件事。有了比特币之后，你确实能快速给全球任何角落的人打款，不用管国境线在哪，手续费也低到几乎可以忽略，比起传统国际汇款简直是降维打击。随着区块链被越来越多人关注，大家也开始琢磨：金融、云计算、信息传递，还有各种需要分布式管理的应用，是不是都能用上这个技术？

问题在于，比特币网络从出生那天起，它的设计目标就只是当一套电子现金系统。你要是拿它来做那些更复杂的去中心化应用，开发者会痛不欲生——工具不趁手，限制一大堆。

所以以太坊的想法很简单：你来我这搭台子，我提供一套好用的基础设施，让你能轻松创建去中心化应用。是不是活脱脱一个去中心化的安卓？
