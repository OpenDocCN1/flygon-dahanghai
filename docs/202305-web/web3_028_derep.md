# 3.1 去中心化身份，一文讲透

你有没有想过，在Web2时代，你的数字身份其实不属于你？社交账号、游戏资产，本质上都归平台所有。一旦平台跑路或倒闭，这些“财产”往往跟着消失。Web3则不同——区块链赋予了你对数字身份的产权。这个理念的正式名称是DID，也就是去中心化身份（Decentralized Identifier）。它的目标很明确：让数字身份的所有权、控制权和管理权完全回归个人，而非平台或组织。

链上身份的一个显著特点是“透明”。你在区块链上的每笔操作都会留下记录，可以随时追溯。但这同样是把双刃剑——因为数据公开可查，你的链上资产和交易行为也更容易暴露在别人眼前，隐私问题不容忽视。

去中心化身份当前主要依托两个密码学工具：公钥和私钥，它们都来自区块链通用的密码学算法。先看私钥：它是一串由数字、大小写字母随机拼成的超长字符串，没有规律，几乎没人能硬记下来。但它却是整个身份体系的命门——私钥本身就代表着产权。谁握着私钥，谁就拥有这个私钥名下数字资产的产权。私钥只属于你自己，任何机构、平台都无法触碰。再看公钥：你可以把公钥理解成一个公开的“收款账户”。在链上生成公钥，等于开了一个户头；那串 0x 打头的地址，就是别人给你的账户转账时需要的“卡号”。

钱包是生成和保管私钥的专用工具。交易前，必须先经过你的授权，钱包才会调用存储的私钥去进行数字资产的交易。

很多人在注册钱包时，还会遇到一个叫助记词的东西。它是私钥的“易读版”。毕竟私钥太长，人脑记不住，于是就有了助记词。它用一种近似“数字-单词对照”的方式呈现：比如密码是 12345，单词库里有 apple、orange、tom、june、july，每个数字对应一个词——这样一串单词就好读好记得多了。

由于整个区块链体系共用一套密码学规则，所以即使你使用的钱包公司倒闭了，也不用担心。只要区块链网络还在运行，只要你记得自己的私钥，随时随地都能用一个新的钱包工具恢复并管理资产。这和Web2形成鲜明对比：平台一旦破产或跑路，你存在里面的东西就彻底没了。而Web3把这个风险降到了极低。

最后关于钱包的登录密码。这笔密码只用于解锁钱包应用本身，和Web2服务的登录密码类似。但它有一个特性：同一个私钥可以在不同设备的不同钱包里使用，而且每个设备都能设置各自独立的登录密码，互不冲突。
