# 7.6 DAO：先中心，后去中心？

前文聊过的 DAO 并不是全部。围绕某个具体难题而聚起来的组织，因共同兴趣而组成的社区，也都能归入 DAO 的范畴。

换句话说，在 Web3 里，任何组织形式都可以自称 DAO；连国家政府，理论上也存在转型为 DAO 的可能。正因如此，DAO 才被看作 Web3 建设的底层支撑。

各种组织的机制，很少一开始就严丝合缝，大多是在运行中不断调整出来的，商业组织尤其如此。一家公司从初创走向壮大，本身就会经历机制的持续升级。

很多企业在起步阶段，决策往往由创始人一人完成；等体量变大，创始人会着手设计组织架构、积累组织能力，直到这时，组织才有机会向去中心化靠拢。

上一章提到的 Axie、Stepn 等热门链游，也在白皮书里给出类似路径：社区运转起初由项目团队牵头，等项目进入稳定期，再把项目的全部所有权交到社区手里。

最后留一道思考题：对商业组织而言，究竟是一成立就去中心化更合适，还是先中心化、再慢慢转向去中心化？又或者，始终保持中心化才是更优解？
