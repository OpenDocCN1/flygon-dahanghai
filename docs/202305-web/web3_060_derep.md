# 5.4 从预热到开图：NFT 发售全流程

一个 NFT 项目从酝酿到开卖，再到发售后，每个环节都藏着机会。启动前，项目方通常会先运营一个推特账号做预热，不断放出 NFT 预览图，还会策划白名单发放活动。

白名单可以理解为一张“提前入场券”：拿到它，基本就能确定买到该 NFT；部分白名单还附带免费铸造名额或折扣购买权益。这个机制和港股打新时获得新股申购资格有些相似。

项目推进到一定节点，官方会开设 Discord 服务器。Discord 像🛰️与论坛的结合体，单个服务器里可建多个类似🛰️群的频道，是海外最常用的聊天工具，也几乎成了 NFT 项目运营的标配。服务器内常设综合聊天、公告、灌水、粉丝作品、地区语言交流等频道。用户若想拿白名单，就要完成官方布置的任务——拉人、提高聊天等级、提交美术作品等，以此争取资格。

接下来进入预售与公售。预售阶段，白名单持有者可优先铸造 NFT。白名单规模通常为发行总量的八分之一至四分之一；比如总量一万个，通常会留出两千个以上名额给白名单。

![](img/ab96f6fcb620881f23ccf7c8a9dc84dc.png)

预售通常会在 24 小时内收尾，甚至更短，随后开放公售。此时面向公众，人人可买；热门项目可能出现几万人争抢几百个 NFT 的场面，拼的就是手速。现阶段多数项目卖出的是盲盒形态 NFT。公售过后一段时间，官方会公布盲盒揭秘时间，也就是“开图”。NFT 自带稀有度设定，越稀有越值钱，限量款甚至能冲到价格顶部。开图当天往往交易量最高：普通持有者挂出自己认为普通的 NFT，鲸鱼玩家则扫入稀有款。之后，项目会依照官方 ROADMAP（路线图）推进，走向可能大不相同——运营不及预期会价格暴跌，发展顺利则可能成长为新一代蓝筹 NFT。
