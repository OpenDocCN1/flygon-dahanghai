# 7.5.6 BanklessDAO——靠知识变现跑通的去中心化样本

在 DAO 的众多案例里，BanklessDAO 堪称教科书级别。它最初从付费订阅切入，一步步把“赚钱—分钱”的闭环打通了；随后又借“去中心化银行”的核心理念，用知识付费的方式把社区越做越大，也实打实地让不少人从中获得了可观收益。

后来 RichDAO 在运营打法上，就明显借鉴了 Bankless 的成熟路径。如果你想完整了解这个组织，推荐阅读这篇深度拆解：[《进化速度恐怖，社区规模最大的 DAO：BanklessDAO》](https://mp.weixin.qq.com/s/XxaUvovroow_Gzmq3fNexA)
