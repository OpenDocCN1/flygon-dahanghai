# 5.1.2 读懂 NFT

NFT 这个词，你可能早已见过，却未必能一句话讲清它是什么。它的英文全称是 Non-Fungible Token，中文通常叫“非同质化代币”。从技术上看，它搭建在区块链之上，依照 ERC-721、ERC-1155 等通用标准生成，是一种不可复制、不可篡改、也不可拆分的加密数字权益证明。

每一个 NFT 都对应一份独特的数字资料，充当数字商品所有权的电子认证或证书。它能承载的资产类型不少：画作、艺术品、音乐、视频、游戏中的项目，以及其他形式的创意作品，都可以通过 NFT 来代表。

需要说明的是，作品本身可以被无限次复制，但代表它的 NFT 会在底层区块链上留下完整追踪记录，为买家提供所有权证明。

通俗地说，NFT 就是一份去中心化的权益凭证，用来证明你对某项数字资产或实物资产的所有权；放在区块链世界里，它类似一张“房产证”。借助区块链不可篡改的特性，NFT 能把资产归属记录得公开透明、可追溯，而且这份所有权独一无二。

正因如此，NFT 有两个明显优势：

- 每个 NFT 都绑定持有者的某类收藏品，并且无法复制，稀缺性便自然成立；
- NFT 如同一个公共账本，任何人都可以核验资产是否真实、归属是否属实。
