# 9.3.5 找工作，先想明白这几点

方法层面的内容前面已经聊过，这次说说求职里的“道”。

不管身处 Web 几，查理·芒格给出的几条原则都值得拿来用：

1. 别去卖自己提不起兴趣的东西  
2. 别跟合不来的人共事  
3. 别替自己不服气的老板做事  

如果一时说不清兴趣在哪，不妨反过来列出自己反感的方向，再逐个排除；要是你把打工看作单纯谋生、兴趣并非重点，那就优先选自己擅长的事；若连擅长什么都模糊，就请身边熟悉你的人帮你判断。

这套思路，能帮你更接近理想的工作。
