# 5.1.3 NFT 的价值到底怎么看？

看过前面的案例和定义，很多人自然会追问：NFT 究竟算不算一种资产？它到底有没有价值？对于“能不能算资产”这件事，市场其实早已用行动给出了明确答案。

从本质上看，NFT 是一种带有特殊属性的 Token，也就是代币。

在区块链网络诞生之前，世界上并没有一个不可篡改的平台，能够全天候、跨地域、零门槛地完成交易。这个特性非常关键。

正是依托这样的流动性，全球参与者可以随时进入同一市场，让有限的资金和资产在同一个池子里定价与博弈，NFT 因而带上了金融资产的特征。

那它的“价值”该怎么理解？

外行人常拿“右键另存”打趣：库里花 18 万美元买下无聊猿头像，有人就说，我也能存一张当头像。确实，你可以轻松拿到一部分使用权。但要注意，你存下来的图片并不等于 NFT，它只是整个 NFT 资产里的一部分信息。你拿不到所有权，也拿不到所有权带来的收益。

你能否把另存的小图拿去卖？不能，没人会买。

所以库里买的并不是一张小图的使用价值，而是这份资产的所有权。假设他花 18 万美元买入，未来市场价涨到 180 万美元，很多人依然可以另存图片，但只有他这样的真正所有者才能卖出并拿到这笔收益。

NFT 的要害，是让数字内容成为可确权资产；其中关键的一环，是把使用权与所有权拆开。以无聊猿为例，图片可以被无数人复制，但真正持有无聊猿的人，全球只有几千个。

再想想房产这类典型资产：最重要的是使用权吗？其实不是。你可以自住，也可以空置，还可以出租让别人使用。真正关键的是，你握着这份资产的所有权，对吧？

在区块链世界里，数字资产的所有权会被清楚记录，公开可查且全程可追溯。交易资格只属于真正的持有人，也只有他们能从中获得资产收益。

理解越深，你越可能会发现，这种理念更接近资产的本质。

回到最初的问题：NFT 有没有价值？你可以自己判断。今天仍有很多人怀疑，但事实是，NFT 已经发展成百亿美元规模的市场，并获得越来越多人的认可。作为投资者，这一点值得关注。
