# 10.5 最后想说的话

进入 Web3 之前，除了看得见的方法和资源，真正决定你能走多远的，往往是心态。这几条心法，希望你能慢慢养成。

**1. 先选对方向，再努力做对事**

我非常认同段永平的那句话：先做正确的事，再想着把事情做对。说白了，就是选择比蛮干更重要。可惜大多数人把力气都花在“怎么执行”上，很少花时间问“该选什么”。而做好选择的前提，是让自己知道有哪些选项，这就需要保持开放的心态，大量吸收新鲜信息。

**2. 输出，才是最有效的学习**

很多概念，你以为懂了，其实未必。费曼学习法早就告诉过我们：如果能把一个知识讲到 8 岁小孩都听得懂，那才算真明白了。所以不要只顾着学，也要多写、多讲、多与人交流。输出不是在消耗，而是在帮自己梳理和消化。

**3. 悲观者也许有理，但成功者往往是乐观的**

聊 Web3 的时候，总有人爱强调风险、波动和不确定性。可这些本来就是任何新生事物自带的属性，个人再担心也无法改变。我们能做的，是提升认知，尽量规避风险，然后在一个有潜力的赛道里，把属于自己的机会抓住。悲观者或许有道理，但最终跑出来的，往往是乐观者。
