# 启程：为什么现在要认识 Web3？

嗨，欢迎来到 5 月航海 Web3 实战手册。接下来的日子里，我们会在这片海域频繁碰面。

这次航行的核心，是带大家一起认识 Web3。这个赛道到今天依然藏着 10 倍以上的增长空间，但前提是你得先理解它，未来的机会才可能属于你。

不少朋友也许还在困惑：Web3 到底是什么？也有些人了解过一些概念，但网上的信息太嘈杂，很难形成一套自己的认知体系。所以这趟航行的目的，就是用结构化的信息整理，帮你搭建起对 Web3 的系统理解——包括它的基本概念和行业特性。

先声明一点：本次航海和手册中，我们不会给出任何投资建议。

手册会通过“信息结构化 + 案例分析”的方式，带大家推开 Web3 的大门。主要内容包括：

- Web3 是什么，它要解决怎样的问题，商业模式是怎样的，目前发展到什么阶段；
- 核心底层技术区块链，以及 Web3 的基础设施现状；
- 在 Web3 的世界里，你的身份由什么决定、资产由谁保管；
- Web3 的代表性应用：去中心化金融、数字藏品 NFT、链游 GameFi；
- 去中心化组织 DAO 到底是什么样的存在；
- Web3 在世界各地的监管情况；
- 如何树立理性的投资理财观念；
- ……

Web2 的“卷”早已人尽皆知，互联网大厂无论是市场空间还是监管层面，都触碰到了增长天花板。而 Web3，在我们看来仍然是一个充满朝气的行业，潜藏着无限可能。

所以，这次手册特别邀请了业内前辈提供内容支持，共同打造一份 Web3 快速入门指南。不管你是想基于 Web3 创业、做投资，还是寻找 Web3 方向的工作，我们都希望这次航行结束后，你能对各类 Web3 项目具备基础判断力。

本手册由 11 月航海和 2 月航海的「Web3 入门」实战手册迭代而来，还加入了不少航行期高手的经验分享，希望你能收获更多新内容。

在这里，大家可以抱团取暖——前有 Web3 的探路者，身边有并肩学习的小伙伴。遇到任何问题都可以随时抛出来，能帮你少走很多弯路，也少踩很多坑。
