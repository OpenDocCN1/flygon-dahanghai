# 4.2.2.2 稳定币的另一种玩法：拿加密资产抵押

**抵押模式：用加密资产来背书**

比特币和以太坊虽然价格波动很大，但并不意味着它们完全不能充当抵押品。只要先把币价换算成美元，再乘上一个安全折扣，照样能支撑起稳定币的发行。

DAI 就是这套思路的代表。它由运行在以太坊网络上的去中心化组织 MakerDAO 发行。用户如果想借出价值 1000 美金的 DAI，就需要先在里面质押价值 1500 美金的 ETH 或 BTC。市场平稳时，一切相安无事；可一旦质押资产的价格从 1500 美金跌到 1000 美金，这些质押品就会被系统没收。正是靠着这种超额抵押机制，才能保证用户手中的 DAI 不会因为加密资产暴跌而跟着缩水。

这种模式的优点是：具备一定程度的去中心化，并且整个过程公开透明。

它的问题也很突出：智能合约一旦存在漏洞，资金安全就可能受到威胁。
