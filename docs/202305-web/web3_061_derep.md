# 5.5 NFT 怎么赚钱？一文讲透

在当下的 NFT 圈子里，大家最常采用的赚钱路子，就是去一级市场抢首发，然后在开盲盒之前挑个合适的时机卖掉。这个玩法其实和港股打新非常像，每一个 NFT 项目都可以看成一只准备上市的股票，我们靠拿到白名单来拥有买入资格，等项目正式“挂牌”后再脱手，赚取差价。

现阶段，凡是比较优质的项目，在一级市场的命中率都还挺高，收益也比较稳。所以为了拿下这些热门项目的白名单，大家可以说是使尽了浑身解数。

最早的时候，白名单主要靠玩家自己花时间花精力去“肝”。由于热门项目实在太多人抢，官方只能抬高门槛，比如要求你拉来足够多的新用户，或者在 Discord 里把等级水到一定程度，短则三五天，长则一两周，必须熬够时间。达到要求后还得主动提交申请，官方审核通过，白名单才算到手。

后来玩法慢慢变了，肝白名单不再是一枝独秀，抽奖和填表开始大行其道。抽奖平台像 Premint、Alphabot、Superful 这些，用户只需要绑定自己的 Discord、推特和钱包，再完成一些指定的交互任务，就有机会抽中某个项目的白名单。而填表申请也很常见，特别是一些热门项目，官方通过这种方式能更精准地筛选出高质量用户，控制白名单的含金量。

除此之外，也有人选择花钱请人代劳这些繁琐又费神的活儿。通常是在时薪比较低的地区，雇一些兼职人员帮自己完成各种任务，成本不高，效率却挺高。

另外还有一种路子，就是成为项目方的编外人员，比如去做 Discord 管理员。这类角色几乎百分之百能拿到白名单作为奖励，相当于官方直接发福利。

最后一条路，就是直接花钱收购别人手里的白名单，把购买权买过来。不过这条路风险也最大，买价高不高、对方会不会反悔、中间会不会出什么幺蛾子，都可能影响最终收益。

拿到白名单后，在预售阶段你其实是进退自如的。因为这时候项目方通常已经在 Opensea 上挂出了对应的 NFT 合集，也就是说二级市场已经可以交易了。只要市场价格扣掉手续费之后还高于你的铸造价格，那就有赚头。

举个例子，市场价 1 个以太，铸造价 0.3 个以太，假设 Opensea 收 10% 的费用，那你的收益就是 1 × 0.9 - 0.3 = 0.6 个以太，差不多 400 美元。

当然，你也可以直接把白名单转手卖给别人。热门项目的白名单相当值钱，比如前阵子 KPR 的白名单能卖到 1000 美元，第二天发售的公鸡 NFT 白名单也能卖到 300 美元以上。只要白名单有人要，卖掉就是稳赚，不过你也放弃了搏一个更大收益的机会。

反过来，如果市场价格扣掉手续费后比铸造价还低，那就跟港股打新一样，进入“破发”状态。这种局面可能持续一阵子，也可能随着行情回暖而扭转，全看项目后续的表现。

说到底，无论打新还是炒 NFT，选对项目才是关键。这行里藏着巨大的信息差，有些项目热得发烫，但白名单成本太高，最后算下来收益也就一般般。反而是一些没那么火爆的项目，白名单容易拿，只要市场价差足够，反倒能拿到不错的回报。

•NFT 还能怎么玩？衍生赚钱路子也不少

上面聊的是 NFT 市场最基础的赚钱逻辑，也就是一级市场打新。那除了这个，还有没有别的机会？当然有。

第一个是二级市场捡漏。总有那么些 NFT 会被低估，比如开盲盒之后，有些稀有度不低的 NFT，卖家自己没意识到它的价值，就挂了个低价。这时候你用低价接过来，再转手卖出去，差价就到手了。另外在牛熊切换的时候，一些蓝筹 NFT 也可能被市场低估，熊市入手、牛市出货，同样能吃到一截可观的利润。

第二个是信息差红利。如果某个项目本身质量很高，但知道的人不多，或者看好的人很少，那你就可以趁早重金投入，等大家反应过来的时候，收益自然就丰厚了。

第三个是劳力差机会。前面讲的白名单获取，就是典型的劳力差——通过规模化操作，把劳动成本压下去，收益就能放大。圈子里很多人时间宝贵，与其自己花几个小时去拉人、聊天、画画，不如掏钱找人代劳。而这些基础活儿门槛并不高，所以催生了代肝、代邀请一整条产业链。

连对应的 Discord 账号、推特账号都能批量生产再卖掉。有些项目为了提高门槛，还会限时开放 Discord 服务器，于是连进服务器的账号都能卖出几百块钱的价。

第四个是流量变现。这个领域里，流量同样金贵，尤其是精准的 NFT 用户流量，价值更是不得了。所以你会看到很多专门在推特上做 NFT 项目推广的账号，靠的就是这碗饭。

第五个是社群价值。通过给成员提供项目资讯、深度分析，帮大家提高命中率，这也是一门好生意。毕竟这个行业每天都有几十个新项目冒出来，哪些值得投？怎么投才划算？都是大家最关心的问题。再加上怎么批量养号、提高收益，都是硬需求。如果一个社群能把这些价值都提供到位，自然会得到大家的认可和追捧。

最后一个是自己当项目方。当然，这主要针对海外市场，这里就先不过多展开了。
