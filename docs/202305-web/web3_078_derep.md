# 6.4.1.3 它凭什么跑成头部？

回看阿谢的崛起，我倾向于把原因拆成三条。

第一，所处方向的天花板足够高。  
个人再强，也离不开行业大势。传统游戏在全球拥有接近30亿玩家，而链游在2021年走红前，全球玩家规模或许只有数万人。按用户数量对比，这里蕴藏的不是十倍，而是万倍级扩容机会。Axie便是其中基本面相当扎实的领跑者；2021年那轮行情里，多个链游项目的游戏经济规模实现数十倍乃至上百倍扩张。

第二，团队价值观正，且具备把事做成的执行力。  
一位投资人提过，不管投什么，团队都应排在第一位。我对此颇为认同，创业公司更是如此。怎样的团队更容易成事？我的概括只有两条：价值观正，且能把事情落地。  
价值观正，来自投资人与团队接触时感受到的氛围和行事准则。阿谢也不是突然起飞：项目2018年便已启动，到2020年初，100万美元融资仍迟迟谈不下来。可团队在低迷周期里没有停手，最终走出寒冬、等来转机。  
能落地，看的是团队的基本面、基本功和底层素质。判断方法很直接：成员是否在相关领域拿到过成绩和结果。

第三，切中了大家的副业收入需求，游戏公会因此迅速铺开。  
新冠疫情冲击下，菲律宾大量民众失业，收入来源中断。有人告诉他们，参与游戏每月能赚数百美元，约为当地工资的2至3倍。于是，各类游戏公会快速起盘。公会里由团长牵头，把一批玩家组织起来，靠游戏获取收益。这个阶段，靠打游戏赚钱的形态，与滴滴司机、美团骑手有几分相似。

这三点叠加，才让阿谢跑成了头部。
