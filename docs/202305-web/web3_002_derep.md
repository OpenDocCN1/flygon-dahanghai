# 一、Web3 黑话听不懂？别慌 @可达 Koda

💡 本节导读

别人说“去 Mint 一个 NFT”，你心里是不是只剩问号？身边那些自称玩 Web3 的人一开口，大饼、以太、币安、智能合约、无聊猿、阿谢、跑鞋、公链，再加上 DID、DeFi、NFT、GameFi、DAO……每个字都认识，凑在一起却像另一门语言。你甚至可能怀疑：明明自己也长在互联网时代，怎么突然就掉线了？

别紧张，这太正常了。多数人第一次接触 Web3，都是从一头雾水开始的。

原因并不复杂：新领域里的老玩家，常会默认你已经懂了那些基础概念。一个陌生词没铺垫就冒出来，谁都不可能瞬间理解。

所以不用焦虑。接下来会按这些方向，带你把概念一个个捋清楚：

- 为什么要了解 Web3？
- Web3 究竟是什么？
- 它真正要解决的问题是什么？
- 它的商业模式怎么运转？
- 当下发展到了哪一步？
- Web3 与 Web2 有哪些不同？
- ……

来吧，推开 Web3 世界的第一道门。
