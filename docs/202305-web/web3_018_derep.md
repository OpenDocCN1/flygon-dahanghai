# 2.3.3 当漏洞击穿规则

区块链最吸引人的地方之一，是规则一旦写进代码就难以随意更改。以太坊也正因此支持开发者搭建形形色色的去中心化应用：先把规则公开说清，再让程序自动执行，约定之后理论上就不能被篡改。去中心化组织，便是其中一种应用形态。

DAO 由 Slock.It 打造，团队技术实力不俗，成员中还包括曾参与以太坊创始工作的人。按照 Slock.It 的设想，DAO 要让社区共同为项目提供资金，模式类似一个众筹式投资组织。它的核心逻辑是：先由社区筛选项目，提案若获得通过，便向以太坊社区投资者募集资金；项目成功后，出资者可以分到一部分利润。

DAO 也是以太坊生态中一次重要的实验。参与者并不是直接拿 ETH 去资助项目，而是先把 ETH 兑换成 DAO 代币；有了这种代币，就能对项目投票，当然也可以再换回 ETH。

2016 年 4 月，DAO 代币启动众筹，不到一个月便募集到约 1.5 亿美元，占当时以太坊存款总额的近 14%。

然而，只要规则由语言写成，就可能留下缝隙。

树大招风，体量如此庞大的众筹项目很快被 Web3 世界的黑客盯上。6 月，黑客抓住项目合约中的漏洞，盗走 360 万枚 ETH，约为募资总额的三分之一。

这有点像一份合同在拟定之初，没有预判到某种特殊情形，结果一方竟能借此反复套利。类似某些彩票奖池，也因为规则设计不周，被人钻空子掏空。

面对这次盗币事件，以太坊创始团队经过社区讨论，在“坚持不可篡改”和“追回被盗资产”之间选择了让平台方介入，把被盗资金退回去。这个处理方式就是硬分叉：在原有规则基础上强行改写规则，另做一条新链。

这一决定引发了巨大争议。有人认为，规则就是规则，区块链的精神正是去中心化与不可篡改，哪怕资产被盗也不该改。另一部分人则认为，社区需要正义的力量，不能让作恶者得逞，违法行为就该打击，同时也不应让投资者白白承受损失。

最终，以太坊社区关于分叉的决定获得了 85% 以上的票数支持，V 神也站在了社区正义一边。也正因这次事件，以太坊衍生出了两种代币。
