# 7.4 NFT 与 token：DAO 价值的双载体

万象区块链董事长此前给出判断：当区块链应用进入大爆发阶段，DAO 很可能成为一种分量很重的商业组织形式。

在 DAO 内部，需要两类价值标识物来承载其价值。

第一类是 NFT。成员在 DAO 中做过什么、贡献了多少、拥有哪些产权，都可以通过 NFT 留下记录。

第二类是 token。在 NFT 记录的基础上，DAO 再发行代币，用 token 完成经济激励。

一句话概括：成员先通过 NFT 积累行为与贡献，再据此获得 token 回报。也就是 Play NFT Earn Token。

NFT 与 token 并非彼此割裂，而是一起构成 DAO 的价值模型，共同承载 DAO 的价值。
