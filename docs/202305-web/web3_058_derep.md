# 5.2 走进 NFT 交易市场与藏品

这一节咱们来实际看看 NFT 交易市场长什么样，再挑一个具体藏品，带大家搞懂收藏 NFT 前必须掌握的核心数据。这些都属于 NFT 入门路上绕不开的基本功。

前面已经提过，OpenSea 是目前全球规模最大的 NFT 交易市场。作为新手手册，你只需要认识这一个平台就够用了。

OpenSea 的官网地址是：https://opensea.io/

打开之后就是 OpenSea 首页。这里每天会展示一批 NFT 项目，最上方是搜索框，你可以直接输入关键词来找想要的 NFT。

点击右侧的 “STATS” 按钮，会进入一个排名页面。OpenSea 会根据交易额、销售增长、地板价等几项关键指标，对平台内所有 NFT 做动态排名。当前排在榜首的是 Bored Ape Yacht Club，也就是大名鼎鼎的无聊猿，之前提到库里花 18 万美金买的就是这个系列。

点进去，能看到一系列重要数据，这些是评估一个 NFT 项目时必须留意的：

- Items 10K：意思是无聊猿系列总共发行了 10000 个 NFT。
- Creator fee 2.5%：表示创作者收益为 2.5%。每当你卖出一个该系列 NFT，创作者都会从这笔交易中抽取 2.5% 的费用，而且每一笔都会收。
- Total Volume：指的是这个 NFT 系列从上线到现在累计产生的交易总额。
- Floor price：也就是我们常说的地板价，即当前所有正在挂单出售的藏品中，价格最低的那一个。目前显示的地板价是 XX 个以太坊，折合约 XXX 美金。无聊猿如今已经是整个 NFT 市场里的蓝筹项目，不少明星都在持有，所以价格自然不低。不过最初铸造时——2021 年 5 月——无聊猿的铸造价只有 0.08 个以太坊，按现在的地板价来算，涨了接近 1000 倍。
- Listed：上架比例是 7%，意思是 10000 个无聊猿里有大约 700 个正在挂单出售。这个比例能在一定程度上反映持有人的信心。如果上架比例很高，说明不少人都想抛售；如果比例低，则说明大多数人更愿意继续拿着，不是特别想卖，因此从侧面表明价格可能更稳。当然，这只是参考指标之一，NFT 的价格还会受到很多其他因素影响。
- Owners：这个数字表示该 NFT 系列的独立持有者数量。通常来说，持有者越多，说明认可这个项目的人越多，相对而言它的价值也会更高。

如果点开其中一个具体的 NFT，还能看到一些对买家来说至关重要的信息。

比如某一号无聊猿，当前标价是 XX 个以太坊。往下滚动，能看到这个 NFT 在 OpenSea 上的历史成交价格走势。再往下是 Offers，也就是目前市场里其他人给出的报价。如果你持有这个 NFT，就可以从这些报价里挑一个接受，交易随即完成。

然后要注意一个模块叫 “Properties”，也就是特征属性。每个 NFT 都拥有一套独特的特征组合，不同组合决定了它的稀有度。通常情况下，越稀有的 NFT，价值也越高。

以无聊猿为例，它的特征包括背景、衣服、耳环、眼睛、毛发、帽子等等。每个特征下面都有一个百分比，代表拥有该特征的无聊猿在总共 10000 个里面占的比例。这个比例越小，意味着该特征越稀缺。

不过问题来了：不同特征各自的稀有度不一样，那怎么综合这些特征，算出一个 NFT 的总体稀有度呢？

其实有现成的工具可以用。一个是 NFTGO，它查询 NFT 时给出的信息比 OpenSea 更完整，比如你可以查看无聊猿系列从诞生至今的完整价格走势，这在 OpenSea 上是看不到的。另一个是 BlockProbe，用来查询具体 NFT 的稀有度排名等信息，也很常用。

再往下是 “Details” 模块，这里面包含这个 NFT 在区块链上的最关键信息：合约地址、Token ID（这个 NFT 的编号），以及它遵循的协议标准 —— ERC-721。

继续往下，就是该 NFT 的历史交易记录。你能看到谁给出过什么报价、什么时候以什么价格成交、从哪个钱包转移到了哪个钱包。这也是区块链资产的一个重要特点：公开、可溯源、不可篡改。这件资产过去的所有变动，都在链上清清楚楚，任何人都可以随时查看。

以上就是对全球最大 NFT 市场 OpenSea 的实际体验，也带大家看了一个具体 NFT 藏品长什么样。

接下来聊聊海外 NFT 和国内数字藏品的区别。

海外 NFT 一般建立在以太坊等公链上，可以通过虚拟货币在二级市场直接交易，所以带有一定的金融属性。而国内的数字藏品，本质上可以理解为 NFT 的“阉割版”。它们大多建在联盟链上，比如腾讯幻核发布的作品基于至信链，这些作品目前无法转移到其他平台，也就是说，不同平台发行的数字藏品之间是无法互相流转的。

此外，国内数字藏品通常不允许二次交易，一般只用于收藏或者转赠，金融属性非常弱。因此现阶段国内围绕数字藏品的二级交易，要么不合法，要么是在打擦边球。还有一个很明显的区别是：国内的很多数字藏品，一份图片往往卖出几百份甚至几千份；而海外 NFT 除了 PASS 卡这类特殊类别，大多数藏品每个形象都是独一无二的。

综合来看，海外 NFT 孕育的机会相对更多。当然国内数字藏品也不是完全没有可能性，只是接下来到底怎么走，还得看政策方向、正规军如何布局，以及最终能否找到真正落地的应用场景。
