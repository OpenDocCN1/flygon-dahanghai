# 10.3 杨涛：作息一团乱，先从这三件事下手

作息乱，不一定是你意志力差。真正能把生活节奏稳住的，还是三件很朴素的事：睡够、吃对、动起来。市面上再花哨的调整办法，多半也是从这三件事上演化出来的，只是给你几个具体动作，让心里更有底。

有些人不是不想睡，而是身体那阵困意来得短，抓不住就过去了。先说生理层面的难入睡，有几个建议：

1. 睡前泡脚、喝红酒、热牛奶这类仪式感，对入睡帮助有限；褪黑素反而更管用，建议选品质好、价格高一些的。
2. 床品别省。人一生有三分之一时间在床上，可不少人在这一块投入少得可怜。好床垫、好四件套，是最能提升日常幸福感的投入之一。
3. 枕头要单独说，因为挑到合适的太难，而且每个人情况不同。我今年已经换了五个，邓禄普、睡眠博士、慕思都试过，出差住酒店还买过两次枕头。目前没有特别想强推的，但我越来越确定：枕头的本职，就是把脖子托好。
4. 床单可以试试深蓝或紫色，窗帘尽量做到一点光都不透，这两样对睡得更沉有帮助。

心理上的难睡，也可以换个思路：

1. 别把晚睡当成“赚到了”。那是一种错觉，每天睡眠总时长其实差不多：十点睡五点起，和两点睡九点起，长度一样。你打游戏我也不拦，但早起打游戏，确实会多出一种奇怪的满足感。
2. 卧室里别放任何电子设备。头两天会很难受，第三天开始往往就顺了；关键是别破例，破一次代价很大。
3. 回想一下，第二天有重要安排时，你是不是更容易早睡早起？既然做得到，为什么不把日子好好过？
4. 冥想可以试试，我自己体验过，有效。

最后分享几个老司机的偏方：

偏方一：想硬掰生物钟，如果翻来覆去睡不着，干脆撑到天亮，别补觉。洗漱、吃顿有能量的早餐，白天照常干活；中午再困也顶住。晚上早点洗漱睡下，第二天把闹钟定在六点。

偏方二：给伴侣转一万块，让她每天早上叫你。你起来并完成洗漱，就奖励自己一千；当天没起，钱就没了。她要是忘了叫，也扣她一千。双重幸福。

偏方三：饮食上，早餐固定在七点，晚上通常更容易睡踏实。

偏方四：95%的人一天连一分钟刻意运动都做不到。你想做那最优秀的5%吗？

偏方五：糖尽量少碰。有个说法是，人一辈子大约只能吃800公斤糖，谁先吃完谁先走。
