# 3.1.3 第三步：给计划留点余地

职场里，谁没遇到过计划外的事？一边是原本能估算的日常任务，另一边是随时冒出来的新任务，夹在中间，时间很容易失控。

日常任务就算自认为准备得很充分，也可能一开工就在第一步卡住，接着不得不额外花大量时间补救，原来的安排被彻底搅乱。新任务更麻烦：一件接一件插进来，原计划被反复打断，最后可能连一半都推进不了。

这时不妨借用时间管理里的墨菲定律：凡是有可能出岔子的事，哪怕概率微乎其微，也终会冒出来。换句话说，面对陌生任务，再周全的设想也可能有疏漏。所以，遇到新任务、不熟悉的领域，或者要动用新技术时，务必给自己多留缓冲。

我自己的做法是，按3到5倍来预留时间；同时不会把大量精力耗在前期准备上，因为未来本就不可知，不如先动手，在推进中不断修正。有人会觉得3到5倍太夸张。确实，若能只用1到2倍就搞定最好，但为了给未知风险留出预判空间，3到5倍更稳妥。

此外，每天最好把40%的时间留给意外。以8小时工作为例，可以先空出2到3小时不安排。如果当天运气好，没有突发状况，就把第二天的事项提前处理，或者拿这段时间学习充电。

安排得密不透风，并不等于效率更高。主动留出机动时间，为突发和未知留一份盈余，才能心里有底、遇事不慌。
