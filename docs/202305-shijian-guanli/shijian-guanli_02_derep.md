# 时间管理实战手册：从掌控时间到掌控人生

欢迎来到5月航海｜时间管理｜实战手册。接下来的这段日子，我们会在这里频繁碰面。

先做一个说明：这份手册是在2月航海｜时间管理｜实战手册基础上迭代而来。新增的内容主要来自上一期航海的高手分享，集中在第三、八、九、十部分。所以阅读时如果发现与旧版有较多重合，不必意外，这属于正常情况。

时间管理几乎是所有人的必修课。工作、生活、自我提升，哪一样都堆着做不完的事。可同样是24小时，差距却很明显：有人工作能交付、技能能精进、家人能陪伴，休息也够用；有人天天熬到深夜，成果拿不出，身体先报警。

但先别焦虑。大多数低效，并不是你做事能力不行，而是你对时间正在流逝这件事缺乏真实感知，也没有对宝贵时间做出像样的安排。

如果你正被时间管理困扰，不妨就从这次航海起步，把基础技能练起来，一点点把对时间的掌控权拿回来。

我们的学习路径是这样展开的：先理解时间管理本质上是管理自己、让自己更会用时间；接着学会记录时间并做复盘；在这个基础上，对基础时间、蓄能时间和创造时间做合理规划与调整；然后进一步掌握系统提升时间利用效率的方法；最后处理很多人眼中的硬骨头——拖延症，以及如何与情绪相处。

时间管理的完整流程，手册里都拆成了详细步骤。最后一章还整理了圈友的时间管理案例，供你参考。

航行结束后，这份手册依然可以当作你的实操教材。航行期间我们也会请教练从不同角度做分享，帮大家解决可能冒出的各类问题，也欢迎你一起交流自己的时间管理心得。
