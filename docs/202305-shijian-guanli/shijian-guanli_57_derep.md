# 9.2 别靠焦虑，靠愿景

拿减肥这件常见事来说，两种思维会走出完全不同的路径。

若用问题思维减肥，过程往往是这样：你对自己的体重不满意，越看越焦虑，于是下决心管住嘴、迈开腿，连着三个晚上不吃晚饭。到了第四天，你感觉似乎轻了一些，焦虑随之下降，便不再控制饮食，开始放开吃喝。随后又后悔，第二天重新节食。如此循环，体重没减下来，对自己的信心反而越来越少。

换成创造思维，画风就变了：先承认自己眼下是60公斤，这是事实，不分好坏，我全然接纳；再把55公斤视为理想状态。为了靠近它，我选择少量多餐，并且每天记录体重。因为真心想抵达新目标，所以无论吃饭还是运动，我都会围绕这个目标做决定。

创造思维并不复杂，只包含两个动作：第一步，看清当下；第二步，规划愿景。然后以现实与愿景之间的落差为起点去设计行动，持续做下去，直到两者重合。再看两个例子：

• 眼下两个月才读完一本书，期待每周读完一本，那就从今天开始每天留出一小时阅读。
• 现在经常踩点迟到，希望提前10分钟到公司，方案是每天早起半小时。

这两种思维最大的不同在于：问题思维由困扰和不安推动，里面常伴着自责与无力；创造思维由目标和愿景推动，带来的是信心与渴望。

之前担心“21天航海”收官后，自己还能不能把时间管理坚持下去，这就是典型的问题思维——事情还没发生，先堆了一串负面假设，对自己也没什么信心。

若用创造思维重新看：我已经摸到时间管理的门槛，也为自己配好了一套合适的方案。接下来要做的，是继续优化时间分配，那就再来一个21天日复盘。这样一转念，焦虑会明显下降，取而代之的是对后续行动的期待和把握。

陈海贤在《了不起的自己》里写道，人生是一个创造过程，是把心里钟爱的理念变成现实，而不是解决问题的过程。当然，问题仍要处理，只是别让处理问题成为唯一动力；真正推着我们往前走的，应是那些热爱的、想实现的东西。所以不必害怕某天停下时间管理。它只是工具，关键是你想做成什么。目标清晰时，你会更愿意把时间管理用起来；就算中断，重新开始就好，长期累积比机械连续更重要。你始终在成长的路上。

回到源头再问一句：我们为什么要学时间管理？刘擎在《西方现代思想讲义》中谈到，人类痛苦的两大根源是死亡与贪欲，因为每个人都得在有限生命里面对无限欲望。学习时间管理，能让我们更正视人生有限的事实，主动追逐自己认可的价值；也能理解并接纳自己的欲望，听见内心，找到真正让自己愉悦的事。

珍惜有限时光，同时勇敢追梦——这大概是时间管理能给我们最重要的提醒。
