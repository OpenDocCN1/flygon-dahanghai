# 四、基础时间，先求规律

很多人一提时间管理，第一反应就是提高效率、挤出更多产出。但按时间管理三分法来看，一天24小时其实可以归成三类：基础时间、蓄能时间和创造时间。三者当中，最该优先安排好的，恰恰是基础时间。

它涵盖睡眠、饮食、休息、清洁打理，以及陪伴家人。这些事看似平常，却是支撑整个人生运转的根基，而且每天都要面对。因此，规划基础时间时，目标不该是“越多越好”，而应当是“尽可能规律”，再围绕这个方向做细致安排。

这一节会具体讲基础时间规划的四步：记录、调整、固定和优化；同时也会介绍番茄钟这一非常经典的时间管理工具，帮助大家把它用得更好。
