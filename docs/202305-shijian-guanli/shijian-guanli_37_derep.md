# 七、走出拖延困局

几乎人人都爱给自己贴上“拖延症”的标签，它似乎成了现代人负面情绪的最大来源之一。但先别急着给自己下定义——拖延症本质上并不是心理疾病或精神障碍，它更接近一种自我管理失灵的表现。那些总说自己拖延的人，明知把该做的事往后拖只会带来内疚、焦虑和更少的成果，却依然难以迈出第一步。

因此，拖延说到底只是一个外在结果，真正要解决它，我们必须回头审视触发它的深层原因。这里提供两个实用方法，供你尝试：✅第一种，善用积极语言的力量；✅第二种，采用“if then”（如果……就……）的策略。

除此之外，还有两个关于拖延的关键点需要你特别留意：✅对那些没有截止日期的任务保持警惕；✅学会把积极拖延变成你的助力。
