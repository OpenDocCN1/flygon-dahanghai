# 3.2 规划工具推荐

做计划时最怕找不到合适的工具，这里整理了两款不错的选择，供你参考。

如果你大部分时间都在办公室工作，Excel 表格会很顺手。它的优势在于界面直观、信息一目了然，数据也方便长久保存，日常管理事务相当省心。

要是你的工作节奏比较灵活，常常出差或跑客户，那可以试试“日事清”App。它能以周为单位安排整周的任务，条理清楚，而且手机、电脑、网页端都能同步使用，随时随地都能查看和调整计划，特别适应移动办公的需求。

说到底，工具本身没有高下之分，关键还是看你怎么用。现在就挑一个顺手的，从今天开始把规划落到实处吧。
