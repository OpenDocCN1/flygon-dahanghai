# 6.2 怎样才能让时间预估更精准

所谓“精准化”，说白了就是我们对一件事所花时间的预测，和真实消耗之间的差距尽量缩小。

那为什么平时我们的预估总是不靠谱？回顾日常就会发现，我们做的事情大体归为两类：一类是基本可控的，另一类是很难控住的。只要属于相对可控的范畴，要做到精准预估是完全有可能的。

举个例子，一本18万字、主题你也不陌生的书，读完全程要多久？也许很多圈友压根没算过。不过，照着下面四步来操作，你就能得到自己的答案。

第一步，先读15分钟，数一数这段时间读了多少字。

第二步，推算出阅读速度，比如每分钟能读500字。

第三步，据此换算出每小时大约能读多少字，差不多是3万。

第四步，答案自然就出来了：18万字、主题熟悉的书，读完需要6个钟头。

读书这事儿相对稳定，所以数据一旦跑出来，以后再拿到新书，扫一眼总字数，心里大概就有数了。

这种精准估算还能用到别处。比如说，你每天雷打不动要做的那项任务，耗时大概多少？基础时间里的各类事项，又各自占了多久？因为这类事每次做起来差别不大，算清楚之后，你就能更准确地把握时间去向。

至于那些相对不可控的事情，就要请出霍夫施塔特定律了：一件事实际花掉的时间，永远比你预想的要多。哪怕你早就知道这条规律，面对复杂项目拍截止日期时，照样容易高估自己。

这里给个参考线：把你最惨情况下耗用的时间再翻一倍，当作理想期限。这和之前聊过的“留出3到5倍机动时间”其实是一回事。

知道了这个定律，心态上就得提前调整。你可以给自己设一个硬性期限，但别期待所有内容都能按原计划完成，最终结果往往比理想预期要打些折扣。所以，时间精准化的核心就是回归事件本身：可控的，尽力算准；不可控的，主动降低期望、多备余量。这样，计划落地的可能性才会大大增加。
