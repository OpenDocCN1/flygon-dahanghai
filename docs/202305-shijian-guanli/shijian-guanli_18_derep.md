# 3.1.2 第二步：估算耗时

待办清单列好了，可一天就24小时，每件事到底该分配多少时间？这确实是个难题。

我们常有这样的经历：一早看到日程上只有两件事，心里还挺轻松，觉得今天应该很从容。可到了晚上，却发现这两件事几乎占满了整整一天，其他什么都没做成。时间都去哪儿了？

这就不得不提管理学上那个著名的帕金森定律：“工作会自动膨胀，直到填满所有可用的时间。”换句话说，你给它留多大的空间，它就能长多大。你以为多留些余裕是体贴自己，实际是在喂大一件事的耗时，反而拖垮了效率。

好在办法总比问题多。借助之前养成记录和复盘的习惯，我们就能慢慢校准自己独立完成各类重复性任务的真实耗时。拿我自己来说，每天花5分钟做日复盘；一篇2000字左右的文章，大约要写2小时；看一本领域熟悉的书，速度稳定在每小时3万字上下。

这些基于复盘得出来的数据，让我们心里有了底。时间给得刚刚好，就不会纵容自己慢悠悠地耗下去，自然也就不会让光阴虚掷在无意识的状态里了。
