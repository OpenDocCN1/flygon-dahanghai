# 5.1 蓄能，为什么要先排时间？

别把蓄能当成“有空再说”的事。它其实由几块时间拼成：学习、运动、娱乐、爱好，以及人际往来。

学习能让我们积累知识与认知，面对复杂、未知的问题时更有解法。

运动一方面让身体状态更扎实，另一方面也是释放压力最有效的方式之一。

娱乐本身就是正常而积极的需要；主动把娱乐排进日程，才能不带负担地享受其中。

爱好装着我们对世界的好奇，也让我们多一个理解世界的角度。

经营人际关系则类似储蓄：平时一点一滴投入、长期累积，等到需要时才有可支取的部分。因此，这部分时间同样需要预先安排。

可见，蓄能不是临时补课，而是提前给学习、运动、娱乐、爱好和人际留出位置。
