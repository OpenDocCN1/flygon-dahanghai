# 10.5 金侣Lydia：宝妈多份副业怎么排？

不少妈妈想同时经营几份副业，真正卡住她们的，往往是时间与精力都有限。金侣Lydia 的做法是：别把不同副业硬塞进同一时段，而是按状态、场景和回报来安排。她的四个对策如下：

1. 把可自主安排的大块时间留给高产出任务。她清晨产出偏低，夜里环境安静反而更专注；所以会把精力最足的时段，用来处理更费脑、更高效的工作。

2. 让零散时段也发挥作用。做饭时听课，通勤坐车时做不需要高度集中的副业，比如在社群里做产品推荐。先分清：哪些副业需要整块时间（如自媒体内容写作），哪些可以拆碎做（如社群带货），哪些还能并行推进（她经常几个群同时开会）。

3. 给副业排轻重缓急。副业再多，也有主次差异，要按自己的节奏有效安排；特别耗时的项目可以果断舍掉。她去年做了不少短期训练营课程，今年基本停掉，把时间投向更能产生复利收益的事情。

4. 精力管理优先于时间管理。有些宝妈并非没时间，而是提不起劲启动。学会管理精力，在状态好的时段高效推进，本身就是省时间的秘诀。

内容参考自《无专业，无定位，无爱好的全职妈妈，20 个月，变现 170 万+的经历分享》
