# 二、时间到底花在哪了

想管好时间，先别急着排日程，而要弄清眼下每一分钟流向何处。我们会用“记录”加“复盘”两件事，帮你看见自己做了哪些事、各自耗了多少时间。

这一节还会介绍两种思路：一是经典的“时间管理四象限分配法”，二是圈友 @车纯的高效人生 提出的“NOW 主义时间三分法”。方法之外，更重要的是把24小时当作一整块来审视：工作、生活、休闲以及其他所有需要投入时间的事项，都摊开来逐一列出，再做通盘安排。

记录工具并不复杂，我们推荐的手机 App 可以用，Excel 表格也完全可以。别等了，就从今天开始，把每天的事项与花费时间记下来吧。
