# 公众号阅读量猛涨，流量到底从哪来？

2023年6月5日

我是张柯 Ker。这回被亦仁拉来做个分享。原本它是一份快闪付费内容，现在直接公开；不建群、不卖课，纯交流。

这段时间，围绕公众号流量主变现的玩法一个接一个冒出来：生财的爆文写作航海、AI 绘画热点，都有人在做。它们的共同点很明确——某篇文章的阅读数会毫无预兆地冲高，可流量来源常常让人摸不着头脑。本质上，平台在公域推荐上放出了更大的量，也出现了新的获流通道；真正要弄明白的是，推荐流量为什么偏偏落到某篇文章上。常见操作并不复杂：保持更新，然后等平台自然分发。市面上同类玩法收费不低，这次权当交个朋友，把底层逻辑摊开讲，其实内核相通。
