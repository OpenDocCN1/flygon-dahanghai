# 把资料交给 ChatGPT 前，先看这份清单

作者：黄小刀🔪｜2023-05-25

想让 ChatGPT 变成顺手工具，先要弄明白“怎么喂料”。下面这些场景，新手也能直接照着操作：

- 上传一份 PDF，请它压缩出摘要、梳理重点；
- 发一个网页链接，让它帮你查最新动态；
- 交给它一张数据表，让它读出数字背后的起伏和变化；
- 贴一段文字，让它先归纳，再仿照相近风格写；
- 把聊天记录发给它，让它给联系人分组、打标签；
- 丢一本书过去，让它快速消化后讲清全书内容；
- 把亦仁的公众号交给它，问它亦仁对某个议题是什么看法……
