## 2. 一个网站由什么搭成

# 1. 本章概要

本章要讲清两件事：建站的知识框架，以及借助AI动手开发的落地方法，让完全没有基础的人也能搭起一套完整的建站能力。

第一部分：网站的底层构成
- 三个要素：域名（全网上唯一的门牌）、服务器（代码安放之处）、代码（一切功能的来源）
- 网页分两类：静态页上手简单，适合新手；动态页能力更全，实现起来更麻烦
- 三种语言各司其职：HTML管结构，CSS管样式，JavaScript管交互

第二部分：写代码用的软件怎么配
- 编程类：Claude Code、Augment、Cursor
- 原型类：v0、Lovable、bolt.new
- 大模型：Claude、GPT、Gemini可以搭配着用

第三部分：用AI写代码的实践
- 需求怎么提：口头描述行，结构化提示词也行，混着用
- 代码怎么测：HTML丢进浏览器就能看效果，复杂项目交给AI排查
- 报错怎么排：把报错原文、预期结果、手头现有代码一并交给AI

核心思路：让网站尽快上线，在反复实战中攒经验，边做边学。

### 1. 域名：它是什么，去哪里买

域名说白了就是网站的门牌号。百度的门牌是baidu.com，别人输入它才找得到你。

换个角度想：外人总得先知道你家地址，才摸得到门吧？

每个域名在全网只此一份，它指向你、也只指向你。买域名我建议去cf（Cloudflare），卖域名的商家市面上不少，但cf对做站的人最省事。不必急着下单，等网站成型再买也来得及。

### 2. 服务器：云端部署是怎么回事，免费托管平台有哪些

服务器就是替你存放网站代码的那块地方。门牌有了，总还得有间屋子。

如今送免费托管的平台一抓一把，比如Vercel、Cloudflare、Netlify。它们的流程基本一个套路：

- 先注册账号
- 再把网站文件传上去，或者关联GitHub仓库
- 点一下部署，就能拿到访问地址
- 若手里有自定义域名，去后台绑上即可

### 3. 代码：网站的魂，静态页与动态页差在哪

网站最终长什么样、能有哪些交互，全看代码怎么写。拿做饭打比方，代码就是那份菜谱，成品什么味道由它说了算。

静态网页：
- 谁来看都是同一副样子，跟印好的报纸类似
- 快、稳、部署省事、花钱少
- 个人博客、作品集、公司官网用它正合适

动态网页：
- 会随用户的操作和登录状态变，类似聊天窗口的实时刷新
- 能力多，登录、评论、购物车这类功能都做得出来
- 代价是要配数据库和后端，开发难度上一个台阶
- 电商、社媒这类需要用户体系的站点适合它

头一回建站，不妨先用静态页把流程走一遍，熟了再上动态功能。

### 4. 编程语言入门科普

#### HTML / CSS / JavaScript

拿人体来类比：
- HTML是骨架，页面上有哪些东西——标题、段落、图、链接、按钮——由它定，绕不开标签、属性、嵌套这几个概念
- CSS是外观，元素怎么排、什么色、多大字，它说了算，核心是选择器、属性、值
- JavaScript是神经中枢，负责让页面动起来：点一下弹出提示、填表时检查对错、播放动画，都是它在干活

#### 前端与后端怎么分

前端：浏览者眼睛看得到、手上点得着的部分，包括排版、视觉和交互，主要靠HTML、CSS、JavaScript撑起来，相当于餐厅里客人坐的大堂和手里的菜单。

后端：藏在服务器那一侧，管数据存储、用户身份核验、业务规则，常用PHP、Python、Node.js这类语言写，好比后厨与仓库。

### 5. 把AI软件装起来

眼下用得最多的，是Claude Code、Augment、Cursor这几种写代码的助手。

这类东西摸得越久越顺手，但真正的重点在于尽早走上建站这条路——让你想要的页面被AI写出来，买好域名，部署上线。新人只要把这一整套流程跑通一次，往后顺着走就行。

刚装好不会用很正常，可一旦看到自己的站真的挂到了网上，你自然会常常点开瞅瞅，琢磨着改老站、开新站。

#### Claude / ChatGPT / Gemini：怎么跟大模型对话，把需求说清楚

区别简要概括：Claude Opus 4.1、GPT5、Gemini 2.5 Pro，眼下都属于代码能力第一梯队的模型。

自己注册不下来，去淘宝买个共享号或独享号也能用。渠道不是关键，关键是早点用上这些成本极低、智商极高的模型。

### 6. 本地环境：Node.js、npm、Git 简单装一下

三者的角色简要概括：
- Node.js：好比JavaScript的播放器。过去JS只能活在浏览器里，装了这个，你的电脑直接就能执行JS
- npm：软件超市，别人写好的代码包从这一键下载，省得自己从头造轮子
- Git：给代码配的录像机，每次改动都留档，写坏了可以倒回去，几个人同时改也不打架

三者的关系：Node.js提供运行环境，npm是在这个环境里取工具的路子，Git负责把代码变化的历史存下来。

我自己不是程序员，这些到现在也没正经用过——顶多是AI让我复制粘贴命令时碰过，谈不上熟悉。所以非科班的新人不必在这上面纠缠，眼下要做的是让站尽快上线。

只有不停地上新站，才能碰到需求、吃下需求。工具、环境、模型终归是帮手，别在它们身上沉迷。

### 8. 怎么让AI替你写代码、改代码

结果老不合心意时，不妨先让它把问题梳理一遍，然后开一个新会话，重新把症结描述清楚再问；也可以换模型，Gemini 2.5 Pro、Claude 4、ChatGPT、DeepSeek都行，让几个模型互相看看，交叉比对。

### 9. 向AI提需求，提示词该怎么写

- 口语化：别束缚自己，想做什么张口就来，哪怕说得七零八落、前后打架也无所谓。来回几轮之后，你的想法会越来越清楚，提示词也跟着一轮比一轮完整、有条理。
- 结构化：不少圈友偏爱有固定格式的提示词，里面带上技术架构、角色背景、目标输出。自己磨出一套模板，跟AI沟通会顺很多。

### 10. AI给回代码后，本地怎么简单验一下

HTML这一类，双击丢进浏览器就能看效果、看源码，改动用Notepad++这种轻量编辑器就成，或者干脆在GitHub仓库里直接改文件。

Next.js这种带后端、组件多的项目，我很少在本地跑——没基础容易弄岔，只能靠不断截图发问，再把它给的代码拿来试。

### 11. 碰上报错，怎么让AI精准修

第一步，手边得有一份持续更新的网站地图，作为背景资料喂给AI，隔一段时间还要给它做一次校正。
第二步，把出错的画面截下来，有报错文字的连文字一起复制发过去，把你的处境讲明白：想达到什么结果 + 现在报的什么错 + 已经试过什么（连同代码）。
第三步，让AI把可能的原因列全，再一条条给方案，自己上手验证。

大部分问题这样就能解决。剩下那些特别刁钻、提问时漏了某块代码知识的，可以丢到航海群里请技术大佬出手。

前面提到的Cursor、Windsurf、bolt.new这些，底层调的都是Claude 4、GPT之类的大模型接口。所以刚开始用的时候，直接开Claude官方平台跟用这些软件差不了多少。下面这些案例，同样能在Claude官方平台上做。当然，你若有更顺手的，随便用。

# 2. 游戏站是什么，靠什么赚钱

# 2.1 定义与变现路径

我们不去开发游戏。要做的是盯住可能爆的新游戏名，围绕它建站，把流量接过来。

网上现成的游戏多得很，拿来就能用。

怎么拿？关键在iframe：

iframe的作用，是在一个页面里再嵌一个页面或一段内容。相当于在当前页面上开一扇窗、搭一个框，透过它把别处的网页、视频、地图乃至在线游戏展示出来，访客无需跳走。人还在你的站里，就能看、能玩。

这类站的长处：
- 不用会开发：HTML5游戏都是现成的，你只做聚合
- 用户留得住：好玩的东西自然让人多待一会儿
- 维护便宜：隔阵子补几个新游戏链接，内容就不显旧

变现的路子：
- 广告：接Google AdSense或别的广告联盟，在游戏页上挂广告位。这里首推AdSense——拿一张境内招商银行的储蓄卡就能绑定收美元，五万美金以内不走人工审核，系统自动入账；入账申报同样自动放行，之后把美元换成人民币就能提出来。
- 会员：卖无广告体验，或卖独家游戏内容的付费资格
- 内购分成：跟游戏开发者合作，从玩家内购里分一杯
- 推广佣金：给别的游戏平台导流，按效果拿提成
- 定制：给企业客户做带品牌元素的游戏站

# 2.2 网页小游戏去哪找、怎么嵌进来

HTML5游戏的几个来源：
- 开源项目：GitHub上这类项目一搜一大把
- 游戏平台：itch.io、Kongregate上有不少可以嵌的成品
- 开发者社区：在HTML5游戏论坛里找愿意分享或授权的人

嵌入靠的还是IFRAME：

IFRAME好比在你家墙上开的一扇"传送窗"，玩家在你的站里就能玩到别处的游戏，丝毫不会觉得已经离开了你的网站。于是这些点击与浏览都算在你头上，访客瞥见你挂的AdSense广告，收益就一天二十四小时不停地往你账上走。

1. 进阶：从单页小游戏到多页面游戏站
上一节我们已把一个单页小游戏跑通，也走完了域名购买、托管和配置的完整链路。若想把站点做大、拿到持续流量，就不能停在单页：要增加网页和游戏，逐步形成有规模的游戏站。下面沿用前面的方法，拆解多页面游戏站怎么搭：结构怎么规划、游戏如何批量加入、互动功能怎样补上。

1. 先把骨架搭好：网站结构与分类
当单页变多页，结构就是导航系统。清晰的层级既方便玩家找游戏，也方便搜索引擎读懂站点。可从三方面入手：
- 游戏分类与归纳：按类型分（动作、射击、益智、策略、体育等），也可按主题分（恐怖、二次元、像素风等）。首页或主菜单放“游戏分类”入口，让玩家按兴趣进入。
- 导航与菜单：顶部做全局导航，列出主要分类/频道；首页放搜索框，支持按游戏名或关键词查找。
- 数据库或页面管理：用 WordPress 等 CMS 时，可建“游戏”自定义文章类型（Custom Post Type），每篇承载介绍、截图、IFrame 嵌入；用静态生成器或手写 HTML 时，可按类型分目录保存，保证文件名和 URL 可读、有层次。
这样每个新游戏都能有简洁美观的 URL，分享方便，也利于收录和排名。
![](img/427f491b4985a550d5a4319914db09b6.png)

1. 批量上新：模板化与自动化
多页面游戏站最耗时的就是加游戏。每款都手写 HTML、改样式、写介绍、配图片，工作量大且容易重复出错。可用这些方法提速：
- 通用模板页面：先做一套游戏页模板，包含 H1 标题、一句话简介、IFrame 容器、操作说明/玩法提示。新增时复制模板，只改游戏名、IFrame 链接、缩略图等少数元素。
- IFrame 标准化：统一宽高或做响应式，保证手机端也正常显示。例如统一用 CSS 类 .game-iframe { width: 100%; height: 600px; }，让嵌入游戏布局一致。
- 自动化脚本：有编程基础可用 Python、Node.js 等读取游戏名称、描述、IFrame URL，自动生成 HTML；用 WordPress 可通过 CSV 导入或插件批量创建游戏文章。
模板化和自动化能让你用更短时间上线更多游戏，覆盖更多元的用户。
![](img/9028f47a90899547dea4a423f61e1f67.png)

1. 单页别单薄：把游戏内容做厚
每款游戏页面不要只放一个 IFrame。增加以下内容，更容易吸引并留住玩家：
- 亮点与玩法介绍：几句话讲清特色和怎么开始；操作复杂时用简短文字或图示说明移动、射击、躲避。
- 截图与预览：加载前放一张或多张截图，让玩家先了解内容；分享到社交平台时也能当预览图。
- 攻略、技巧或开发者介绍：热门或深度游戏可写短攻略；有特别背景或开发者故事，可做小版块满足好奇心。
- 相关推荐或“你可能喜欢的游戏”：玩家通关后链接到同类型其他游戏，提升黏性和页面浏览量。

1. 让玩家留下来：互动与社区
成功游戏站不只有游戏，还要让玩家感到能参与社区。可以考虑：
- 评分和评论：给每款游戏加打分，支持“喜欢”或五星评分；评论区让玩家分享体验、提问，卡关时也能交流。
- 热度排行和最新游戏：首页或侧边栏放“最受欢迎游戏 TOP 5”“本周新上架游戏”，按数据或更新时间排序。排行榜容易带来点击循环，拉高平均访问时长和访问深度。
- 社交分享按钮：游戏页放一键分享到 Twitter、Facebook、Reddit 等平台的按钮。社交口碑是新用户的重要来源，好游戏会被快速传播。

1. 多页站的优化推广：让流量持续增长
结构和内容具备后，下一步是让更多人知道并访问。要综合 SEO、社交媒体推广和数据分析，持续迭代调整，网站才能持续增长。

1. SEO 优化：让搜索更愿意收录你
- 层级与 URL：搜索引擎偏爱清晰导航和结构。分类目录、URL 命名要可读；每个游戏页设置合适的 title、meta description，并用恰当文本描述游戏。
- 高质量内容与元信息：除了 IFrame，页面文字也很重要。给每款游戏写独特介绍和亮点，不要复制官方简介或其他网站内容，这样更利于原创度判断、收录和排名。
- 加载速度与移动端：游戏站图片和动态内容多，加载慢会影响体验。做好图片压缩、开启缓存或用 CDN 加速，移动端保持简洁布局。
- 站点地图与收录：生成 XML 站点地图并提交到 Google Search Console，让搜索引擎尽快发现每个游戏页；定期查看收录和错误报告，及时修复 404 或重复页面。
![](img/14f0c3351c3aea617ef3259c22144ce3.png)

1. 推广与流量：多渠道获客
- 社交媒体及视频平台：挑几款人气或特色游戏，拍简单演示视频发到 YouTube、TikTok，附上网站链接引导体验；在 Twitter、Facebook 定期分享新上架游戏，积极与玩家互动。
- 内容营销与玩家社区：写攻略、游戏排行榜甚至行业新闻，建立专业形象，吸引玩家持续关注；在 Reddit、游戏论坛适度推广，避免明显广告式发帖，用攻略、心得、经验等有价值内容吸引自然流量。
- 外链建设。

# 1. 本章速览

这一章的主线，是用新词和热词给游戏站抢流量的打法。

关键词可以从三组来切：新词vs老词、热词vs冷词、种子词vs长尾词。

最值得押注的组合：新词+热词——短期没人跟你抢，需求又实实在在摆在那里。

重点观察对象：一周内才露面、搜索量还在往上爬的词。

实战中从哪里挖？盯源头：AI大V、游戏平台、Hugging Face、Replicate 这些地方出词最快。平时也要攒种子词，generator、maker、creator、calculator 这类高频词根是很好的底料。

游戏这个领域，每个季度都会冒出一些新词，按整年算，机会是百万级的。

怎么判断能不能做？打开 Google Trends，看最近 7 到 30 天的曲线是不是一路向上；再去搜索结果页看，没有图片、没有大站、也没人抢跑；最后查一下，域名还能注册，就值得试。

把这些标准吃透，趁新词刚露面的窗口期进场卡位，就能吃下流量红利。

# 2. 词与需求的分类框架

下面这套框架，是我自己一路实践总结出来的，大家带着批判的眼光看就好。

我习惯把关键词拆成三对：新词对老词、热词对冷词、种子词对长尾词。

做游戏站时，我尤其偏爱新词+热词这个组合，效果非常直接。

种子词和长尾词更多是贴着需求来讲的：做 SaaS 时，长尾词更容易拿到访问，竞争不算凶，但用户要什么、用在什么场景，都写得明明白白。

## 1. 新词和热词，先理清顺序

从来没人用过的词，是新词。

最近正被疯狂刷屏的词，是热词。

两者叠在一起，就是短期里少人抢、需求足的机会窗口。这也正是刘小排老师说的：想赚钱，你得做 first one。

## 1. 游戏词和需求词

游戏词没有太多弯弯绕，基本都跟游戏站直接相关。

之前直播分享里，我讲过一套验证过好用的路子：找月访问量破百万甚至破千万的站点，把站名收进自己的种子词库，然后反复去 Google Trends 里翻，常常能逮到刚起势的相关热词。

需求词则更多地出现在 AI SaaS 方向。一个特别省事的方法：用 aitdk 或 similarweb 去查它们的搜索词来源，扒出来的大多是需求词。

需求词再往下分，是信息类和功能类。信息类的，导航站或直接问 AI 就能满足，商业价值不高；功能类的得真把功能做出来，尤其是 AI 类产品，用户付费的意愿相当强。

1. GSC 与 GA 快速认知

# 1.1 Google Search Console（GSC）监控

GSC 最核心的作用，就是告诉谷歌“你的网站存在着”，让你的站点有资格出现在谷歌搜索结果里。

https://search.google.com/search-console/about

GSC 能反映站点在搜索结果中的表现——排名、点击、曝光，并把技术隐患摆到台面上，比如手机端体验故障、蜘蛛抓取异常。

# 1.2 GA：读懂访客足迹

GA（Google Analytics）主要回答两个问题：访客从哪来、有多少；进站后做了什么。工具入口：https://marketingplatform.google.com/about/analytics/ 。借 GA 或类似分析工具，盯住日访问量、停留时间、跳出率等指标，筛出最受欢迎的页面。若某类目点击特别集中，就围绕它继续加料；碰到跳出率偏高的页面，则回头查加载速度与内容吸引力。

更新节奏同样关键。玩家口味变得快，站点长期不添新东西，回访就很难维持。排一张周更或月更表：持续上架新游戏，给热门游戏做延伸页，让全站保持新鲜与黏性。

1. 申请门槛与驳回情形

AdSense 的准入条件，官方页面写得很细，可直接查阅。Google 采用 AI 加人工双重审核，以下六点要盯紧：

1. 有 Gmail 账户。
1. 内容原创且对用户有用。
1. 不同页面不重复，保持独有。
1. 站内浏览顺畅，有分类与菜单，结构清晰。
1. 日 UV 500 以上。
1. 申请人满 18 岁。

若被退回，按原因逐项改，比如：

1. 站点所有权未确认；照引导做即可避开。

# 1. 付费订阅与增值服务：SaaS/工具站常见定价思路

在小众市场里，价格本身就是产品价值的直接信号，定高一点往往能拉升用户预期。我尝试把价格从$1.99、$4.99、$6.99一路提到$9.99，结果用户留存数据好得超出我的认知。对Shopify Product Scraper也做了类似的提价测试：$4.95→$6.99→$9.99，图中标注的时间就是涨价节点。

![](img/9be392d45ee30b42c369b0d68c7f7ddb.png)

用户并没有因为提价而明显流失，反倒是高价位的留存比例表现更优。回头看，真后悔没早点这么干。不用做任何产品优化，单靠提价利润就涨了。有付费用户主动发来邮件（下图就是其中一封），这种正反馈比赚钱更让人满足，说明产品确实切中了对方的痛点。几次调价过程中，我不断把自己从技术、产品和运营层面抽离出来，重新复盘价格与小众市场的关系，最后总结成一句话：为价值定价。

# 定价看用户价值，不是看自己的成本

做公司项目或接外包时，我们习惯性盯着成本：想利润最大化，要么压缩成本，要么靠商务谈判能力。做副业时这种思维也很容易带过来——先算自己花了多少成本，报价必须高于成本才有得赚。

但在小众市场里，我们直接面对用户，定价反而成了难题，因为你做的东西，目标用户未必是你自己。比如我做YouTube Comment Bot，一开始只定$1.99，理由很简单：这东西对我来说价值不大，开发成本也不高。

后来才彻底想明白，应该按用户获得的价值来定价，而不是按成本。大胆把价格标出来，谈钱并不伤感情。

![](img/286bd4de87b3eeb8f147bb25d766171a.png)

# 优先服务好那20%的用户

当一款产品放在小众市场中，要想最快、最直接地传递期望价值，靠的是什么？不是一长串功能说明、FAQ、7天免费试用、24小时客服、安装量或评分，而是一个清晰具体、看得见的价格。看到这个数字，用户自然会形成对产品的价值预期。

高预期固然会筛掉一部分潜在付费用户，但换个角度想：80/20法则告诉我们，20%的用户往往贡献80%的利润，所以更好的选择是优先满足这20%的人。真心认可产品价值的用户，后续也会带来更多有价值的建议，对产品迭代帮助更大。

# 设置价格锚点

所谓价格锚点，就是商品定价时用到的对比参照物。营销中，商家常借助锚点机制、对比和暗示，来影响你对货币价值的判断。消费者判断一个商品贵不贵，其实没有绝对标准，完全依赖参照系。价格锚点就是商家有意设置的参照。

比如99元/年就是一个典型锚点，有了它，后面的价格看起来就更划算。

# 1. 佣金/推广分成：接入Affiliate系统

Affiliate联盟营销，相当于海外版淘宝客。像知乎好物、抖音书单、外卖淘客、美团地推，本质都是同一类玩法：帮商家推广产品，赚取佣金。

入门第一步是理解Offer，主流类型是CPS和CPA。

CPS按商品销售额分成，不只是实物商品，软件类产品同样适用。SaaS工具这几年特别多，而且订阅制往往能持续产生收益，所以这类产品的提成普遍给得很高，综合下来不一定输给实物CPS。比如亚马逊年末促销季，提成最高到9.5%，卖一台300美金的冰箱，你就能拿28.5美金。

如果是专门推广某个品牌独立站的Offer，提成普遍更高，保健品类甚至可能超过50%，可以去https://fanfuel.co看看。当然，高佣金也意味着竞争激烈。

另一类CPA，是用户完成某个指定动作后才付费，比如下载App、填写注册表等。常见CPA佣金在2到10美金之间；保健品这类高客单价领域，单个动作的佣金可以到六七十美金。

新人选方向时，别光凭感觉。更务实的办法是找一个比自己弱的对手，去研究他、超越他，以免流量好不容易做起来，却找不到合适的产品变现。

怎么选品？一方面可以直接看竞争对手在推什么，跟着申请；也可以在谷歌搜“关键词+Affiliate”；还可以与Affiliate Network合作，或者直接对接广告主。联盟会抽一部分中介费，但好处是帮你对接大量广告主，省去很多麻烦；直接和广告主谈，佣金自然更高，但对方对你的要求也更高。这就好比房产中介（Affiliate Network）、你、卖房者（广告主）之间的关系。合作时间长了，这些条件都可以谈，比如提高佣金比例、减少扣量。

还可以在https://www.Offervault.com/和https://odigger.com/里按关键词搜索，找到符合自身niche的Offer。要注意，同一个Offer在不同联盟中的转化率很可能不一样，需要实际测试，毕竟每家平台的运营策略（或者说底线）都不同。

确定要推广某个产品后，通常得先申请推广资格。国外大多数软件/工具类网站，底部都会放一个联盟计划入口；即便没有，谷歌搜“产品名+Affiliate”也能找到。注册流程不复杂，放心申请即可。新人的话，资料最好填真实信息，免得最后拿到了佣金却提不了现。

# Firstbase注册与开户全流程

我找的是一家口碑挺好的全流程服务商Firstbase，从公司注册、地址公证到银行开户都有清晰指引。说实话，淘宝找代理更省事，但我更喜欢能直接看到dashboard的SaaS服务。

公司注册州选的是Wyoming，类型是LLC，很适合个人开发者。

接下来租用邮箱（私人地址），通过Notarize做远程视频公证，表格是1583 Form。要提前准备驾驶证翻译件（淘宝几十元），并确保证件照片和地址在同一页展示，建议合并后打成A4纸。视频公证时需要简单的英文沟通，工作人员会让你展示翻译件，确认是否本人意愿并签名。

地址公证弄完后，Firstbase会继续代理申请EIN。我是在第10个工作日收到国税局信件。

之后开Mercury银行账户，通过Firstbase关联提交EIN和护照审核，1个工作日内就能通过。

私人地址用处很多：可以当账单地址、申请实体银行卡转寄回国内、接收Google AdSense验证信件。

Mercury支持免费无限量发行虚拟卡，还能限制交易商户和额度，比如A卡只在Google用，B卡只在OpenAI用。万一遇到不给退订入口的流氓服务，直接注销卡号就完事。

Mercury虚拟卡还能绑支付宝消费，200元以下免3%手续费。

有了银行卡、账单地址和手机号，基本就能正常使用各类海外服务；进阶玩法还可以申请ITIN和个人信用卡。

Wise余额可以直接结汇成人民币，提现到国内银行卡、🛰️或支付宝。整体手续费比“香港银行卡汇款再结汇”划算，汇率通常也比国内结汇高。
