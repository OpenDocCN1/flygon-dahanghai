# 零、先看清这个项目

# 💡

# 本节要点

女装、日用、小配饰这些低价位赛道，挤进了📕约九成商家；大家拼价格、拼款式，单笔利润常低于30%。手工银饰、中古家具、户外装备等高价小众类目则供给少于搜索需求，平台流量池还在扩张，供需缺口带来溢价机会。

# 0.1 高价小众类目为何值得切入

📕电商发展数年后，大品类饱和、竞争激烈，但不少细分方向仍是可挖的金矿。本期教练古辛靠淘宝蓝海起家，他认为📕蓝海优于淘宝蓝海：用户偏女性，客单价承受力更强，利润更厚。

📕推荐与搜索两套机制并行，创新产品更容易起量；创新产品持续出现，只要流量机制不变，蓝海方向就能长期做，选题不会枯竭。

与红海相比，这类生意离成交更近，正反馈更快；选对产品，出单并不难。

其特点可归纳为：反馈来得快；竞争者少，做结果更容易，价格战概率低；项目周期长，寿命取决于📕流量机制，机制不变就能持续，而淘宝蓝海后来变难，核心是流量机制改变；产品不愁，掌握选品方法后蓝海货品会不断出现。

门槛不高，无电商经验的新人也能较快获得正反馈。竞争小，选对品后出单相对轻松；真正难点是持续稳定出单，既看产品稳定性，也看获取流量能力。

# 0.2 起步路径：先跑通最小闭环

1. 最小可行路径

执行顺序：注册账号并开店 → 选品（关键） → 找笔记素材 → 发笔记测品（关键） → 出单后对接供应商 → 上架商品并安排发货 → 有稳定流量后买样品 → 自己实拍并发笔记 → 持续做店铺运营管理。

节奏安排：前3天开通店铺并完成选品，第一周至少发5篇笔记，边选边测，目标3周内出首单，再转向实拍。

2. 核心关键

选品约占七成权重，直接决定成败。

前期不必强求实拍，先跑通“蓝海选品—混剪笔记—卖出首单”的最小闭环。

内容提效：航海会教用智能写作工具辅助创作，例如 Deepseek 搭配多维表格生成爆款文案。

轻资产启动：启动时主要支出是单店约千元保证金，也可选择提现时补交；后续每次样品采购约数百元，还可与商家协商寄样免单。

3. 航海目标

选品需反复练，选品能力几乎决定店铺能走多远。新手21天没赚到钱很正常，不必焦虑；这是长周期项目，应把眼光放到长期回报。

# 1.1 账号、手机与电话卡准备

# 1.1.1 先备两套账号

通常新手先做个人店；两个个人店就要两套账号，至少准备：

1. 两部手机；不建议一部手机多开，存在限流风险。

2. 两张电话卡；两个📕号需要两个实名，对应两张卡。

3. 至少2个身份证信息，可用家人的。

电话卡方案：移动、联通、电信都能办副卡，一个身份证可注册认证5个号码，一拖四，副号月租约10元；移动有一款副卡月租10元，一张身份证可领2张，首张与第二张需间隔90天，营业厅和App都能办，营业厅还可争取免首年月租；电信App搜“无忧卡”，5元/月，通常次日上门；移动另有8元保号套餐。

手机建议：手机既登录账号也拍视频。拍摄优先 iPhone XR 及以上机型，成片效果更好；后续做直播，iPhone 稳定性更佳，但 iPhone 不能双开。

![](img/a8b97223f46ffa095cd1ced3edfe46b9.png)

# 1.1.2 登号、实名和前期养号

登录方式：同时运营两个号，能否只用一部手机？可以，但有风险。若手机自带📕应用分身，例如部分红米等安卓机型，可一部手机登两个号；目前这样操作，账号暂未异常。

![](img/6701bdfb0fb9b93a5e9206ea5c8331c3.png)

若手机没有分身功能，不要装第三方分身软件，封号风险高；此时再备一部手机登录账号即可，闲鱼或拼多多三百至四百元档的二手设备就能满足日常。

实名认证：一个身份证只能认证一个账号，认证后只有注销账号才能解绑。操作路径：打开“我”页，点左上角菜单（三条横线），进创作中心，在更多服务里找专业身份申请入口，选个人并提交实名信息。

![](img/c8678464754e3ae9b107c6ef04436b9d.png)

![](img/b17e857d13853d6b1ec8feaa631fe6d2.png)

养号：新注册账号每天刷30分钟以上，提升权重；按所选赛道刷对标笔记，一般持续1-3天。别刚注册就挂商品链接。

![](img/e834c5ab0a6bcb986018cb35e79f3705.png)

# 1.1.3 店铺入驻操作

# 1.1.3.1 店铺类别先辨清

入驻前先分清店铺类型，不同类型权益不同。大类上分个人店铺和企业店铺。

无论开哪种店，都要先完成专业号认证。刚注册的账号默认没有专业身份，不能参与商业行为，包括薯条投放和开店。因此变现第一步，是把账号升级为专业号。专业号分个人专业号和企业专业号。

个人型：个人专业号的身份标识是“昵称+博主”，如时尚博主、美食博主等兴趣类博主，基本申请即通过且不收费。认证流程：从创作中心的服务入口进入，选个人身份，提交实名信息即可。个人专业号可申请个人店铺或个体工商店；名称格式为“昵称+的店”；保证金最低1000元；平台按类目收2%-5%技术服务费。

企业型：企业专业号需上传营业执照并缴600元，身份标识为品牌名。流程：创作中心—更多服务—专业号申请—我是企业—填写基础信息—填写主体信息—上传资质公函—填写运营人信息—缴600元—等待审核。填写注意事项见下图：

![](img/b277349499d8ae71d876b27202ecb5b0.png)

提交后注意：申请有效期30天，30天内未完成申请，费用不退；通过后每年需年审并续费600元。企业专业号可开普通企业店、专卖店或旗舰店。旗舰店以品牌名开头，专卖店后缀“专卖店”，集合店则用“海外店”后缀；普通企业店保证金最低2000元，详见《📕类目保证金明细》；月营业额低于1万元时平台免收技术服务费，超出1万元的部分按5%收取。2023年9月10日之后，同一营业执照最多申请2个专业号、2家店铺。

![](img/a1ba5be88e0c62ffe222986706c338de.png)

同品牌只能开一家旗舰店，但可并行开其他类型，如旗舰店+专卖店，或旗舰店+普通企业店。企业专业号营销权益多于个人专业号，二者只能选其一，按需求定。新手一般开个人店即可，门槛低；企业店多用于放大矩阵，平台对账号的宽容度也更高。

![](img/dea0fdad0aee7699494cf99d2d436b40.png)

# 1.1.3.2 个人店：门槛与办理步骤

入驻条件：个人型店铺分个人店和个体工商户店。个人店只支持服装、百货等常见类目；个体工商户店除常见类目外，还可经营奢侈品、珠宝等。

![](img/f4534f142c091ecbb38cf2760b2b03a2.png)

各店铺类型可经营类目不同，图中打勾项即可经营类目，具体可在平台学习中心里的规则/经营总览页查阅：

![](img/2cb4b46c9a59b456406648cbade2d977.png)

开店需缴保证金：个人店和个体工商户店均为1000元；保健品、奢侈品等特殊类目会更高。

![](img/63b879fe1792fefa7e92b2934bc3163f.png)

客服模式：个人店铺可选平台代运营或自主客服，平台代运营收费，按自身情况选。平台佣金即技术服务费，按类目收2%-5%，细则看官方规则页。为降低个人店和个体工商户开店负担，目前入驻后不缴保证金也能发布商品上架售卖；店铺累计交易额超过1万元后，下个月月初才需补缴保证金，基本实现近乎零押金启动。

开店步骤：选择个人店铺并选经营类目，然后提交姓名、身份证号、手机号，完成人脸识别，验证通过即可开通。

![](img/f0c82be4f18aa77984f0c7b33e7f18ef.png)

个体工商户店需提前准备：营业执照照片、公司名称、统一社会信用代码、经营地址、营业执照有效期；以及店铺运营授权书。操作上同样先选经营类目，再按提示上传资料。

![](img/951b312b2c9d64268f86dc89aa339493.png)

个体工商户店审核一般2-3天，期间可登录入驻系统自查；遇到无法解决的问题，可在9:00-24:00联系人工客服。

![](img/bad39147a2f1a22c626b644192ce26c9.png)

# 1.1.3.3 企业店：门槛与办理步骤

入驻条件：企业型店铺包括普通企业店、旗舰店、专卖店和集合店。

普通企业店命名同个人店，为“账号昵称+的店”；企业专业号取名须与商标对应，否则无法开店。

旗舰店为品牌名+“旗舰店”，专卖店为品牌名+“专卖店”，集合店为品牌名+“海外店”。

企业店可经营大部分类目，含保健品、医药等特殊类目。

平台佣金：1万元以下不收费，超出部分按5%收取。

保证金按类目有差异，一般境内最低2万元，境外3500美元。

不确定选哪种，可看下图快速判断：

![](img/4fbb50923fc52cab0ac3be873dd9ecad.png)

开店步骤：企业店材料较多，建议在电脑端操作，入口为官方商家入驻后台。先说普通企业店，登录后大致6步。

第一步，店铺类型选“普通企业店”。第二步，填公司信息并上传营业执照，照片要清晰完整，避免扫描出错。

![](img/d25e8edf0d28dd679228997bf82a5c5a.png)

接着填写法人或店铺运营人信息，联系人须与营业执照上的法人一致。

![](img/ff2c2249d66b7b6408e6d8358dbb0917.png)

第三步，店铺名称由系统自动抓取，格式为“昵称+的店”，与昵称直接绑定；要改名称，需先去专业号中心修改昵称。

![](img/4069cc23357cb21c581e2971bde75a5b.png)

第四步，选经营类目，类目须落在商标注册证范围内。第五步，等待审核，一般3个工作日内完成；失败会通过电话或邮件通知，期间可联系在线客服。审核通过后，最后一步缴店铺保证金，注意开卡账户为对公账户，开户人须与入驻时填写的经营人姓名一致。

![](img/2af29c7976ea9082f7b1c25d393c83c3.png)

再说旗舰店和专卖店，步骤与普通企业店大体相同，重点有四点：

第一，填写品牌信息。系统里没有品牌名时，点“新增品牌”添加；上传的品牌标识图须与商标注册证完全一致。

![](img/9893b155beec2d26a421a86ad40dad49.png)

![](img/226264644a74560ef3a1ca23a08c815e.png)

第二，分清自有品牌和代理品牌。代理品牌须有完整授权链路，公司名称选营业执照上的名称。

![](img/7aa72df426d8840886a6dbd2ae2c4b06.png)

自有品牌指商标持有者是本公司或公司法人，注册类型分 R 标和 TM 标：R 标为注册商标，TM 标为商标注册申请受理通知书。

![](img/0f581a82eb17a82ada362e48e7a48321.png)

若为个人型 R 标，需上传商标注册证，以及商标权利人的身份证或护照复印件/扫描件。

![](img/3ea64f2446539c46c9aaa96a5ef048f1.png)

个人型 TM 标同样要上传商标注册申请受理通知书，以及权利人身份证或护照复印件/扫描件。

![](img/daf13c2be116bdc58731cea6d3010ae5.png)

若申请企业型 R 标或 TM 标，只需提供商标注册证或商标受理通知书。

第三，选售卖品类时，谨慎选择“定制”类目。

![](img/ae42e944f75d120af1a3db6f03d2680d.png)

第四，审核通过后还要签合同，合同以线上邮件形式发送，通过电话或验证码确认签署。

![](img/f1ae4f21141a603c71552871a6c2deeb.png)

# 开店收尾：押金与集合店

押金还需要再办一回，规则与前面讲过的企业店铺完全一致。

所有审批流程走完，就可以传商品开业了。账号首页会直接列出店铺和商品两处入口。

# 1.1.4 账号定位

# 1.1.4.1 赛道定位

选赛道的方法给你五种，付费免费都有。论效果，前三项付费方案更优；新手前期也可以直接走后两项免费路线，没必要纠结：

1.

看行业大盘（付费，可免费试用）

打开灰豚数据 → 数据大盘 → 行业流量大盘。选定行业后，看爆文数量、预计阅读、点赞、收藏等指标。如果这些数据整体抬升，说明用户正在渴求此类内容，赛道值得蹲守，选品也能往这里靠。

（关联笔记数量下降一点无妨）

![](img/cad24afb938fea46de665554e7dee2d7.png)

2.

看飙升热词（付费，可免费试用）

灰豚数据 → 热门内容 → 搜索飙升榜。重点找搜索量骤增、且与产品有关的关键词。以美甲为例：2025 年开春，美甲需求明显回暖，穿戴甲自然而然就有了市场。

3.

看商品销量榜（付费，可免费试用）

# 3.1 测品的逻辑

测品的本质：对选品做验证。

选品阶段通过分析同行链接的数据，能大致判断该品在📕的竞争烈度、月毛利、流量水位。可这些数据终归是纸面推演。选出来的品到底赚不赚钱，还是得用测品来检验。

选品靠的是理论和经验，测品玩的是实操。一个品能不能做，最终要用实测来验证。在📕测品，说白了就是在测大家获取流量的本事。细分品类带来的访客通常很精准，只要商品页面的转化设计没问题，流量一稳，成交自然就来了。

测品周期设定为一周。📕的蓝海生意走精品路线，不需要像店群那样铺大量链接。同类目的产品可以集中在同一家店，没必要一个店铺只挂一个品，太浪费；一家店放不到20个品完全没问题。我们实操下来，比较稳的节奏是一个一个来，上一个测一个。当然把所有商品都上架也可以，但开测时要从选品数据里表现最好的那个入手。每天发3到5条内容，不要集中轰炸，一周下来，能不能出单基本就清楚了。

平台上的成交通常来得不慢，品类切得够细，来看的人也就够准。只要链接的转化数据正常，一周内还没动静，就该考虑换品。如果一周内有单，就继续做下去，重点练捕获流量的内功；新人往往要花2-3个月，才能把流量和订单都稳住。

有些产品自带流量高峰，玄学类就是典型。中考、高考、考研、考公这些节点之前，搜索和热度会明显上涨。选品时就要通过数据发现这类时间窗口，把测品节奏卡进去；如果完全没察觉，完美避开高峰期，做起来会非常吃力。玄学品利润虽高，但操作有难度、容易违规，对新人不太友好，刚入行的朋友还是先挑别的类目拿正反馈。这里只是拿它举例，不是推荐大家入局。

# 3.2.1.2 定价别太想当然

有人觉得从拼多多拿货到📕翻三倍就能卖，但📕的用户并不好糊弄。我专门问过50多个女大学生，她们多数还是习惯在淘宝、拼多多、得物下单，而且比价意识很强。我的定价方法是：去淘宝和拼多多找销量靠前的同类店铺，把价格定在这两个平台的区间之内。这样用户比完价，发现我这里略微便宜一点，再加上视频是原创拍摄、强调真实感，基本就不会跑到别的平台买了。

举个例子：拼多多榜单上一条牛仔裤卖39元，去淘宝搜同款按销量排，月销1000+的大多在70-90元，也有40多的。这时候可以考虑定在59-69元，再算自己的利润空间。
![](img/677716eb253a551e6177a9a627e4c685.png)
![](img/e9355ef037549cc39657882587517a54.png)
![](img/2890550628a9dc0489ef3d61afe41f20.png)
女装从浏览到下单的转化率通常在4%-7%，低于4%就得琢磨是不是价格有问题；其他类目我没有数据。定价前也可以多刷📕，看同行爆文左下角挂的商品累计卖了多少。

实操里，定价极其重要，尤其低客单产品。常见两个坑：一是觉得📕用户消费力强就拼命加价；二是照搬其他平台价格，不肯动态调整。圈友@V小刀在星球发过一篇《📕电商系列细节篇》，讲定价讲得更细，建议去看看。

# 3.2.2 六招优化链接转化率

正式开测前，一定要确认链接的转化表现不拖后腿。下面六个方法是我们实操沉淀下来的，照着做基本能提升店铺的转化数据。

1. 给链接补评价
新链接最好补5条以上图文评价，人为补评价对转化很有用，图文形式效果更佳，5条基本是性价比最高的量。补评价的渠道：亲友能解决最好；不好开口就找老客户；没客户积累就找🛰️好友；还不想欠人情，就去闲鱼发个任务。

2. 用SKU名称做引导
链接里的SKU数量一多，用户容易挑花眼，转化反而下降。可以在SKU命名里加一点从众心理的钩子，让客户按你的意图选。拿脐橙来说：
![](img/c2bc1b39c91fc5ee55bf65332b93e517.png)
第一种只有数字参数，没有任何营销语言，客户看不出区别，效果很差。
![](img/d3a5d3439f70c741a55cfdcc8e8eea73.png)
第二种稍微好一点，在最底下那条SKU名前加了“好评最多”，但问题不少：主推款不该排在最后；应该推利润最高的，而不是最小果；话术也有优化空间。
![](img/99f89abe32e101c41d2cfdba5046fe33.png)
第三种才算合格：主推款放在靠前位置，其实放第二位更理想；第一位放店铺客单最高的SKU做价格锚点，客户先看到100元，再看主推的80元，自然不觉得贵。除主推外，其他SKU都配了营销话术。主推前的“好评最多”还可以升级成“千人好评”“万人好评”，前提是销量撑得住；销量不够就继续用“好评最多”。这个话术的本质是告诉客户：大家都买这个，你跟着选准没错。

3. 用优惠券制造划算感
初始价标高一点，再发一张明显面额的优惠券，客户会觉得捡了便宜。非标品尤其吃这一套，因为没有同行可比价，你自己就是价格标准。

4. 模特颜值要高
需要模特展示的产品，比如祛痘、美白类，前后对比图里的模特一定要好看。效果图可以网上找，也能让美工合成。模特越漂亮，用户越容易代入自己，转化自然越高；模特不好看反而劝退。人都爱美，女性用户更希望自己变美。

5. 调动恐惧心理
很多情绪都能促进下单，我们最常用、效果也最好的是恐惧。卖儿童用品可以说“坏习惯现在不改，以后就晚了”“别的孩子都在用，你家孩子不用就掉队”；卖护肤保养品可以说“现在舍不得花钱保养，省下的钱早晚被别人花掉来保养”。必须记住：用恐惧是为了成交，不是为了吓人。

6. 用相似性包装账号
店铺、笔记、账号是三位一体的，拆开来看没有意义。📕本质是种草社区，不是传统电商：用户因为有需求买了东西，用着不错，真诚地分享出来，其他用户被这份真诚打动，跟着下单。所以做号时别把自己当卖家，当成产品爱好者或使用者更合适。如果定位成卖家，和用户就是买卖关系；定位成某个问题的解决者、某类产品的同好，就天然和用户有共鸣，关系从交易变成朋友。用户更愿意相信与自己相似的人，而不是一个商人。

要做到这点，得清楚目标用户的画像和他们圈子里的常用话术，这些从📕搜关键词、翻笔记和评论就能摸清。看看账号性别是不是填了女性？笔记有没有以使用者的口吻去讲产品？记住，你要做的是客户的朋友，不是商家。比如一个卖儿童用品的账号，人设是成长型宝妈，日常聊育儿经验，很容易被其他宝妈当成“自己人”。
![](img/93e3039c9f95e727a11d2ccb4fbb913a.png)
链接转化没问题后，测品时只要专心测流量就行。

# 4.1 筛选供货方要看哪些条件？

选合作商，主要看四个维度：

1.

价格

供货价和我们的售价之间，要留出足够的利润空间（30%以上）。如果商家价格太高，和同行比没有优势，转化率会受影响。

2.

款式与质量

款式、质量可以让商家发图确认，或自己买样品来检查质量，选出品质过关的商品，为长期合作打底。

3.

单量大能不能走ERP

单量到100+时，可以走ERP系统，发货效率更高，不用自己重新导单下单。商家直接在ERP里看到订单，直接打单发货，省去中间环节，还能避免系统判定店铺无货源，同时也能打印📕面单。

我们一般用店铺管理工具关联商家的店铺ERP，下面是操作步骤：

（A店=商家店铺，B店=自己的店铺）

第一步：先用店铺管理工具登录B店（子店铺），点“关联店铺”，复制关联代码。

![](img/617730777b1b5a30a2f275d65c7fdbec.png)

第二步：让商家登录店铺管理工具，打开A店的“关联店铺”，点“立即关联”，选择关联平台，粘贴B店的关联代码，完成添加。

![](img/8fa122cdfe42b84e853db83f3cae4e84.png)

第三步：关联成功后，A店能看到B店的订单数量，商家可直接打📕面单发货。

![](img/7f0c59869c58f03775c9b1bc73c5b896.png)

4.

能不能走手工单，不走第三方平台面单

前期单量少，可以不接ERP，但一定要和商家确认能打手工单，避免被平台识别成无货源，保证店铺安全。

当然，去询价前可以表明自己是长期做电商的，手里还有好几家店铺，这样商家更愿意合作，也会觉得你是正经下单的人，而不是问问就不买的。

![](img/b8465fad1f038a1bf6b09574dbf2c6a5.png)

# 4.2 快速锁定货源的方法

找货时，有几个动作可以反复用。① 用图片反查 1688 虽然省力，但不保证次次有结果：图片发虚，或者产品是 A+B 组合在一起分不开，平台就认不出来。如果只需要其中一个，先把组合件拆开再搜。② 关键词要换着花样试：名称、卖点、功能、工艺，都行。③ 到竞品链接里挖信息：详情页能看尺寸、重量、包装，评论区往往有更真实、更细节的图片，还能看到买家解锁的不同用法。④ 不确定工艺时，直接问 1688 的厂家。我之前找一款产品，实在说不清工艺，问了十几家都说不做定制；后来挑了一个回复比较详细的商家问：“您觉得我得找哪类厂家？”对方给了几个关键词，我一下子找到一批同类供应商。⑤ 找工艺相似的产品图再反搜。比如有一款瓶子现在几乎见不到，厂家说基本没人买来装礼品，都是买去装榨菜；我拿装好礼品的罐子去搜，一无所获，换成空瓶照片后，满屏都是同款。

# 4.4 和供应商沟通的心法

沟通原则：尽量把对话从 1688 转到🛰️，能电话就不要只打字。直觉觉得不靠谱，就别勉强合作。多站在工厂角度想，少一点指责。单量小，就老老实实找中小型厂家。

供应商愿意跟谁做生意？
第一，珍惜对方时间。问题一堆却抓不住重点，对方只会觉得你在浪费他时间。
第二，信息密度要够。材质、工艺、术语这些功课自己先做好；不要开口就把该了解的信息甩给供应商。Zev 是个好例子——旺旺账号权重不高，但他清楚自己要做的工艺，连模具都刻好交给供应商，所以拿到了非常低的开模价。
第三，带着真心诚意。你对某款产品投入了多少心思，对方能感知到。这一点也融合了前两条：你准备得越充分、对产品越了解，诚意自然摆在台面上。![](img/852334387174611543aad777b4349917.png)

# 4.6 供应商避坑指南

要是你还没从代拍模式转为货源合作或自有货源模式，下面几条可以帮你少踩坑。

1）怎么防止淘宝、拼多多给客户发短信？
三种常用办法：
① 客户手机号不写真实的，把真实号码放在收件地址后面。比如真实电话是 1894263109，下单时填 18900001339，并在地址最后写“到货打 1894263109”。单量大了客户仍可能收到短信，那就改用第二种。
② 把号码里的数字替换成字母，比如 1 换成 I、2 换成 z、6 换成 b。平台不会把“I8942b3I09”识别成完整号码，快递员却看得懂。
③ 用中转仓。下单地址填中转仓，由中转仓改贴客户真实地址的面单再发出，短信问题就完全绕开了，代价是多花一至两天。

2）上家拖延发货，或者货明显不行呢？
优先去找 1688 商家。拼多多上做代发的人最多，成本最低，有人能同时开几十上百家店；你下单后他可能找不到货或觉得亏本，就拖着不发货，或用次品充数。
在拼多多（其他平台同理）进货时，学会看这几点：
① 别看总成交件数，尤其 10W+ 的，要看评论数和最近评论。
② 看发货时效，标了“多少小时发货”的商家通常出货快。
③ 看店铺商品数量，多到离谱（图书食品类除外）的，多半是二道贩子或转手商。
④ 看店铺评分，不到四星半的直接放弃。
⑤ 看店铺资质。点开店铺首图可以看到开店主体；如果你的品类容易被打假，尽量选公司主体的店。

# 五、店铺运营

售前售后是决定转化和复购的关键环节，也连着店铺权重和经营风险。本章围绕售前、售中、售后整理了一些实用的方法和话术，并提醒了销售过程中的注意点，帮你把店铺做得更好。

学完这一章并做完实操，就能推进航线图第五阶段：【运营】学会运营管理📕店铺（4天）
1. 完成售前客服管理（约 1 小时）
2. 掌握发货等售中管理（约 1 小时）
3. 掌握退换货/差评等售后管理（约 0.5 小时）
4. 复盘优化笔记与选品，单账号日更≥5 条笔记（约 2 小时/天）

# 5.1 售前管理

# 5.1.1 客服管理与回复率

把商家 App 的声音提醒打开，客户来咨询就能马上听到。平台会盯客服回复率，回复太慢会拉低店铺评分。

考核细则：
- 效率指标：周回复率≥85%
- 考核时段：自然日 0-24 点
- 考核周期：自然周（每周二考核）
- 处罚方式：扣 50 元违约金；限制店铺及专业号公域流量 3 天，不支持申诉
- 考核门槛：周会话量≥5

每周二平台会通过商家运营系统站内信、商家版 App 消息、用户版 App 消息三个渠道推送通知。
客服考核之外，📕官方还会抽检服务行为，出现违规同样有惩罚，具体条款见《📕商家自主客服服务管理规则》第七条。

怎么把回复率做上去？
1）提前备好快捷话术。📕用户可能关注很多人、加很多群，你没及时回复，消息容易被淹没。把发货、库存等高频问题做成快捷话术，比如把物流问题统一编成快捷词，下次直接调用。回复后客户一直没动静，可以记下昵称，去评论区或新增关注里找找，也可以搜私信，但同名太多，找到的概率不高，还费时间。![](img/7b8edce6eeafb4b9d90311ec5a74e4b8.png)
2）设自动回复。商家 App 支持按关键词触发自动回复，把常见问题做成话术和视频。鞋服类可以针对尺码、款式、有没有货、是否正品、能不能退换等提前设计；实在不会写，就扮成买家去同行店里套话，把对方的话术拿回来改成自己的。![](img/b695d2b209464e55cfe530a77483da05.png)
3）刷回复率。手里有其他账号，就用自己的号假装客户来聊几句，回复率自然就高了；没有多余账号，可以请群友互相捧场。

# 5.2 售中管理

# 5.2.1 不同商品的发货话术

📕后台支持自定义发货时效：当日发货、24 小时发货、48 小时发货、时段预售（拍下后 xx 天内发）、定时预售（xx 日前发）。

正常发货时可以直接说：能拍下就能发；或者告诉客户店铺正常发货、确认对方能不能正常收货、通常 48 小时内发出。
没法按时发货时，话术要分情况：
库存不够：最近单量涨得快，暂时缺货，正在补货；
疫情、大型会议等不可抗力：真诚说明因为***原因暂时发不出，如果客户着急用，可以建议先看看别家，并诚恳道歉。

# 5.2.2 超期发货：报备与处罚

如果因为不可抗力（如疫情、灾害、大型会议）赶不上发货时间，可以在商家后台做延迟发货报备，这样既避免平台处罚，也减少买家投诉。操作手册见《📕商家延迟发货报备操作指南》。

超期处罚规则：![](img/1e46311c3ba40cee9714916dd2b5e5fe.png)
- 一笔订单同时被判定为超期发货和虚假发货，只对消费者赔付一次；
- 被判定为缺货的，可以和超期发货/虚假发货赔付同时发起；
- 赔付上限：同一买家和卖家、同一自然日内付款的多笔订单，上述情形合并赔付最高不超过 500 元。

# 5.2.3 物流对接与打单发货

自有货源模式里，物流对接和打包发货是基本功。
平台现在提供两条物流对接路径：
1. 自己找顺丰、中通、圆通等快递公司谈价，然后在千帆开通对应快递，开通后就能直接打单，单号自动回传，不用手填。
2. 开通📕官方对接的快递，比如京东快递每月超过 300 单可享 3.5 元/单起。具体流程看《官方直送操作手册》。千帆后台能看到各家快递报价，按需开通：![](img/3502441396f52dddce04fd674c0f6f60.png)

怎么联系到物流负责人？
① 地图 App 搜快递网点，找最近的门店上门谈；
② 平时收快递多留意快递员，通过他要到负责人电话或🛰️。

谈价技巧：
① 先摸清所在城市快递价格，这直接影响谈判空间；
② 首重、超重多少钱，第一次就要谈清楚；
③ 让快递公司相信你每月能发几千单（如果还没到这个量，只能靠沟通能力补）。

打单发货流程：打开📕千帆后台，按「订单-电子面单」操作。
第一步：申请电子面单，选好谈妥的合作快递网点/已开通的官方对接快递；
第二步：配置面单模板，下载运行📕打印组件（免费）；
第三步：选择订单打印。![](img/6b76a34098fee57292f82210a2c48722.png)

1. 第二步：配置面单模板，下载运行📕打印组件（免费）。![](img/690a66e084bdedc721be32bd0d99f5aa.png)
1. 第三步：选择订单打印。
第四步：回传单号。上面步骤做完，打出的物流单号就会自动回传到订单，不需要人工填写。
第五步：当面检查揽收情况。建议让快递员当面把物流单全部揽收，确认揽收数量和我们发货打单数量一致，不一致就马上找原因；如果快递员拿回站点再统一打包，数量容易对不上，后续合作也会不顺。

# 5.3 售后管理

# 5.3.1 退换货处理

买家申请退货后，商家要在 72 小时内给出审核结果，具体时限可参考「退换货审核表」和「商家收货表」。

退换货怎么降低伤害？
1）买家反馈商品有问题：第一时间索要证明图片，同时反馈给上家。比如卖生鲜的遇到顾客说水果坏了，如果没当场让顾客把坏果和快递面单拍在一起，等第三天再来找，可能已经超过 24 小时售后时效，上家很可能会拒赔。遇到这类情况，可以优先问买家能不能接受补发，接受补发能减少部分损失。强调一下：质量问题一定要先要图，确认商品情况后再和上家沟通。
2）普通商品退换货：📕售后审核时效一般是 48/72 小时，淘系和拼多多通常更短，但都要及时向上家申请，并主动向买家确认商品有没有拆封、使用过、是否完好，再判断是否符合退换货标准。商家后台可以设置未发货前的自动退换货。![](img/8ff543a1776fba0788b8fdaa8db337a1.png)

普通商品下单时建议勾选运费险（拼多多自带），📕可以在后台开通运费宝。就算发生退换货，也能从上家退还的运费里获得一点收益。开通路径：【电脑端】商家管理后台-交易-售后管理-运费宝 ![](img/a0b79d475cdd5e2c754bd73cb2c06c41.png)![](img/751c195304a16a3eb9280df4b1c6ce71.png)；【手机端】商家 App-首页-全部工具-运费宝。

做实物电商还可以用快递售后卡引流。售后卡通常是引流话术+二维码，设计风格可参考同行，淘宝和拼多多上也有很多专门做售后卡的店铺。

# 5.3.2 差评应对

差评直接影响店铺服务分：分值高有流量加权，分值低可能被清退；更直接的是影响商品转化。📕用户收到货后一般不会主动评价，除非有质量问题，所以可能卖几百单都没有一条评价；而一旦出现带图差评，就会直接挂在商品购买页。爆款尤其要重视售后，把差评风险压到最低（我亲测卖过 500+ 单、零评价）。

平台对负面点评回复率也有考核：每 14 天为一个审核周期，如果负面点评回复率低于 80%，每次扣一般违规积分 2 分。建议在用户点评后 24 小时内认真回复，并且真正解决对方的问题。

如果差评已经产生，可以试着在后台提交申诉，按自己遇到的情况选择类型：![](img/9283dfd1a7f6ed86cd96d270124611df.png)
一般违规行为，要在平台发出违规通知之日起 7 日内确认调查单或发起违规申诉；超过 7 天没操作，系统会自动视为商家认可违规，处理随即生效。

# 📕开店：避雷、复盘与放量实战

线上申诉的机会，每个商家对单次违规最多只有三轮。想提升通过概率，提交申诉时就得依照平台规范，把佐证材料备得齐全、可信、能用，包括聊天截图、页面链接、实拍照片、通话录音以及快递面单等。具体条款可查阅《📕违规申诉管理规则》。另外，别在商品宣传上过度吹嘘；必要时还能打电话请买家协助删除评论。

### 5.4.2 商品命名不能碰的词

商品描述里一旦用了“最高级”“国家级”“最佳”“顶级”这类绝对化字眼，每出现一次扣25分；情形恶劣的，店铺会被冻结。与买家交流时若带嘲讽、贬损、辱骂或不文明措辞，被对方投诉后同样一次扣25分。更全的禁用词清单，可参考“电商违禁词整理”。

### 5.4.3 食品类下单要留意的地方

食品外包装必须附标签，且标签上要写清以下几项：

一、品名、规格、净含量、生产日期；
二、成分或配料清单；
三、生产厂家的名称、地址与联系电话；
四、保质期限；
五、产品执行的标准编号；
六、存放条件；
七、所用食品添加剂在国标中的通用名称；
八、生产许可证编号。

### 5.4.4 流程要提早摸熟

即便不是团队作战，有些环节也得提前练手。拿拍单软件来说，单量少时靠手工还能应付，一旦订单猛增，人就容易手忙脚乱，整体效率也跟着掉下来。

### 5.4.5 商品质量要一直盯

走无货源路线的话，当上架商品开始零零星星出单，最好买一件回来验货，自己心里有底，售后压力也会小些；同时和上游供货方搭上线，把沟通成本压下来。

### 5.4.6 识别并应对打假人

打假人可归为三类：“要饭的”“坐班的”“职业玩家”。

**要饭的**：这一档多是刚入行、专挑毛病的角色。他们惯用的第一招是找平台规则的缝隙——比如听说平台正在严查无货源，便顺手举报，再私下找你谈钱。本质上是讹一笔，往往给点钱就能送走。第二招是向工商部门投诉。这类人有的想走偏门，也有卖家自己被人整过，转头又去整别人。碰上工商投诉，先听工商工作人员的意见；只要不是产品本身存在质量缺陷，任何赔偿都不要答应。可以向工商递交一份情况说明，把起因、经过写明白，结尾明确表态拒绝赔付。与此同时再和对方谈方案，通常都能比较顺利地收尾。

**坐班的**：他们每天的工作就是批量下单、批量写材料、批量投诉，把这门营生当正职，投入时间和精力，多数是全职在做。他们通常会盯住某类近期容易出问题的商品。举例来说，某段时间监管部门明确禁止辣条中添加谷氨酸钠，这批人就会集中攻击这类产品——思路和我们追热点选品颇有几分相似。如果对方没在客服对话里提索赔，而是直接走起诉，那你的商品大概率确实有毛病。他们常用的两条路径是：向工商投诉，或发律师函。应对上，可以联合同行一起交涉。这些人除了不断更换投诉身份，在工商系统里通常也积累了不少记录。换言之，各地政策不同，即便商品确有瑕疵，工商在面对职业打假人时也往往会酌情从轻。再把上游源头找出来，拿到资质和质检报告交给工商，最终处罚一般不会太重。

**职业玩家**：这一档最为专业，一旦遇上，基本可以断定商品百分百有问题。他们只走一条路——起诉，索赔金额通常一万元起步；若标的在五千元以内，不必应诉，电话里谈好赔偿即可。应对办法是请一位办过电商类案件的律师出面应诉，他会用管辖权异议、申请破产清算等策略，帮你把损失压到最低。当然，能被这类人起诉，说明你店铺近期生意不错——对方动手之前，多半已经掂量过你的赔付能力。

## 5.5 笔记和选品的复盘工作

### 5.5.1 笔记层面的复盘

#### 5.5.1.1 先读笔记数据

1. 阅读量

发布后两三个小时表现不佳，或长期徘徊在一两百、甚至不足一百，通常离不开这几种原因：

- 账号处于起步期，权重偏低，属于正常；
- 笔记触规、踩到敏感词，或内容本身不在平台推荐范围内；
- 选题、标题或首图缺乏吸引力，尤其要回头检查选题切口与封面。

2. 点赞、收藏与评论

1）点赞加收藏超过10、评论却是0，或者只有点赞、没有收藏和评论：

说明内容还在持续获得推送，只是转化偏弱，可以在评论区引导下单。

评论区的运营技巧：

用小号把用户往购物车引，例如发“惊喜盒子”，或留言“已买”并附上购买截图。

2）收藏数超过点赞：

意味着干货偏多、种草偏少，内容需要调整。

调整方向：

补足产品的使用场景，或用文字补充商品相关信息。

看完这些数据若仍不理想，那就逐项往下排查：

#### 5.5.1.2 检查笔记内容本身

- 有没有做到对标爆款笔记的1:1程度，可参照【章节3.2】的爆款笔记部分自查；
- 是否混入违禁词，可借助“零克查词”工具：http://ci.lingke.pro/；
- 同一款商品的测品笔记之间差异够不够。通常五条笔记为一轮分析，选题与标题必须有区分；若五条高度雷同，就得重新调整。

### 5.5.2 选品结果的复盘

#### 5.5.2.1 先判断是否达到爆品标准

第一步，看销量。

月销过万、且多家店铺同时在做，可判为爆品，相关爆款笔记也多；
近期销量在100到500之间、在售店铺不足五家，属于近期爆品，少数商家发笔记就能吃到流量；
月销1000至3000、在售店铺不超过三家，则多为自有货源有限，或是投流品。

拿裤子举例：

在商城搜“裤子”，挑出高销量商品，点同款跳到对标账号的店铺看笔记发布时间，再进主页翻爆款笔记的时间周期来分析。

![](img/1c28d4afa17515843b2e9054dc082ce6.png)

第二步，拆解该品的笔记数据。

按上述标准点进店铺，再转到账号笔记数据里分析。下面这组数据来自选品实测，可供参考：

近七天发布，销量1000+，爆品率80%；
近三十天发布，销量10000+，爆品率50%；
近九十天发布，销量10000+，爆品率20%。

怎样找到爆品并跟进？仍以裤子为例：

在📕商城搜“裤子”，若某店铺销量破万、近期加购超过1000（24小时加购最佳），就可以跟进发笔记，出单概率较高。

#### 5.5.2.2 借对标账号的爆款做选品

找对标账号时要盯住选品周期，处在三到九十天窗口内的爆款，要尽快跟上。

选品周期指什么？

三到七天内，对标账号的高销商品属于实时爆品；
三十到九十天内的高销商品，是平台上的需求型产品，生命周期更长，仍有再爆机会。

若赶上当季产品，参考周期要相应压缩。

## 6.1 下单样品（物流1—4天）

商品能持续出单后，新手第一批不妨下3到5个品的样品，专门用来拍实拍图。

下样品的流程：

第一步，敲定要下单的选品。

第二步，找供应商谈“借样品”，先把货款转过去，快递费同样自理，并留好货品清单。【前期若借不到样品，直接跳到下一步】

第三步，请身边朋友从你的店铺下单，由上家发货。这一步是给数据打底，对后续出单很关键，建议都做；尽量让朋友下单寄到你家，别用自己的账号，主要是怕没有IP隔离。

第三步，收到货后照常拍摄，多拍live图和视频，不同场景各来几组。

第四步，用朋友账号确认收货、给好评，再以你拍的素材发一篇晒单笔记。

几点提醒：

1. 下样品时，直接在自己店铺拍单就行；
2. 若打算与供应商长期合作，可以问清对接方式：是加🛰️下单，还是走ERP。

两种下单方式的差别，这里补充一下：

🛰️下单，是为了避开二次面单被平台判定无货源；
ERP下单，则方便单量变大后商家直接看到店铺后台订单并发货；
新手前期单量少，走🛰️下单就够了。

# 6.3 后期制作

# 6.3.1 图片后期制作

图片后期不用搞太复杂，重点就三件事：

1. 调色：和打光的目的一样，都是为了把肉眼看到的颜色还原出来。没有固定参数，不同图不同调。去📕搜“调色参数、暗调调色、ins调色、清透感调色”这类关键词，自己多试，调到和你眼睛看到的差不多就行。

2. 滤镜：建议能不加就不加。如果手机自带的美颜/滤镜太重，可以适当回调。

3. 花字：实拍图上的花字越少越好。实在要用，就选一两个很简短的词。字太抢眼，反而会盖过产品本身，大图看的就是主体。

# 6.3.3 如何提升拍摄素材的利用率

同一张图，📕不能反复发，否则会触发“大量发布低质/重复交易笔记行为”的处罚。但辛苦拍出来的素材，总得物尽其用，下面两个不重复利用的思路分享给大家：

1. 拍 live 图，转静态图

苹果手机的 live 图会记录按下快门前后约3秒的内容，然后默认选一帧作为封面。如果画面动态幅度够大，你可以在相册里手动换另一帧当封面——这不就相当于换了一张新图吗？一个 live 图，能拆成多张图来发。

不过要注意，如果画面几乎没动，📕还是可能判定为同一张。图1是原图，图2只是换了另一帧，多了一只鸭子，看起来就像另一张照片了，但它们的来源其实是同一个 live 图。

![](img/d9edc341548019eba3443200e228920d.png)

2. 拍 live 图，转视频

live 图本身就是一段3秒的小视频，直接把它转成视频文件就行。转好之后，把多个素材重新剪辑拼在一起，做一个全新的片子——原理和混剪一样，只是素材全是自己拍的，原创度更高。或者丢进一键成片/营销视频里重剪一遍，也能直接用。

# 6.4 注意事项

# 6.4.1 评论区运营

📕上，挂了产品链接的笔记，流量普遍比不挂链接的低。原因是挂链后，系统会把笔记优先推给“电商消费人群”，这些人购物意愿强，转化率自然更高；而不挂链接的笔记，会按普通内容分发给所有用户，浏览量通常更大。

所以如果你发笔记时没有挂车，一定要记得在评论区置顶链接、放产品购买引导图，或者直接在评论里回复购买链接。

# 6.5 如何筛选长期合作的供应商

前期先用一件代发做起来，等单量涨上去了，再谈长期合作。筛供应商主要看两个方向：

# 6.5.1 配合度

供应商不配合，发货、售后会特别累。重点确认这四点：

1. 是否配合电子面单。当日订单超过10单，就可以找供应商谈绑定电子面单，之后下单和发货都能在线完成。前期单量少时人家不一定答应，建议出单后再聊。

![](img/af53041eb52e2f4370b8925ec48ab41a.png)

2. 售后咨询回复是否及时。前期你还不够熟悉自己的一件代发产品时，用户问的问题都需要供应商帮忙解答。一个问题半天等不到回复，大概率会影响店铺成交。而且回复慢往往说明对方没有专门的客服团队，属于小供应商，稳定性差，说不定哪天公司就没了。

3. 发货是否及时。📕对发货时间有要求，一般是24小时或48小时内。找供应商务必确认发货时效，最长不能超过48小时。超时平台会扣延迟发货费用，通常一单3块。另外，如果个别订单实在没办法按时发，要主动和客户沟通，千万不要提前填快递单号——填了但物流不更新，会被视作无效，一样扣钱。

4. 是否支持退换货。这一点不强求，要看原因。用户个人喜好导致的退换货，很多产品不支持，比如服装类大多数供应商不退。但如果产品本身有质量问题，一定要支持退换。连这都不支持，这家供应商可以直接放弃了。

# 6.5.2 产品方面

1. 价格。刚开始一件代发，量小，没有议价权。等日订单稳定在50单以上，就可以谈更低的价格。同时要确认自己的价格在同行里有没有优势。如果自己的成本价已经等于别人的卖价，而且是一模一样的产品，说明供应商没给你好价；这种还不肯降价，那就换。

2. 款式。有些品类更新换代特别快，比如手机壳、穿戴甲，要看供应商能不能及时上新品，有没有开品能力。一些小众蓝海品对开品要求很高，尤其是设计师出品的珍珠项链、饰品这类，如果款式不更新、不开发新品，不适合长期合作。

3. 质量。这是最核心的，不用多说。质量不行，售后会大量爆发，处理起来麻烦还不赚钱。

4. 补货时效。供应商有工厂和门店之分，门店货一卖完，短时间内可能补不上，就得等补货。靠谱的供应商补货时间一般不超过48小时，这样才不会耽误📕的发货时限。要是长期补不了货，也不值得长期合作。

# 7.1 📕站内选品

# 7.1.1 低粉爆款选品法

什么是低粉爆款？简单说，就是带货账号粉丝低于200，最近7天内发的单篇带货笔记点赞过100，而且这款商品销量大于100。这种品，通常就是站内正在被验证、有潜力的爆品，找到的目的就是为了第一时间跟进截流。

相比抖音创意中心，这个方法更适合做女性产品类目的人——毕竟雪莉枚U型枕、发箍、帽子这些爆款，都是先在📕爆起来的。具体操作方法有两个：一个用灰豚数据，一个手动刷。不同品类实际用起来有差异，前期建议两个搭配着用，多维度观察。

# 7.1.1.1 灰豚数据低粉爆款选品法步骤

工具只是手段，按自己的习惯来就行：

第一步：打开灰豚数据。

第二步：点击笔记查找，选择笔记搜索。

第三步：勾选【带货笔记：是】。

第四步：勾选【低粉爆文】。

第五步：搜索你要做的对标品类，比如想做连衣裙，就搜“连衣裙”。

就算用了灰豚数据，筛选标准也不能变：对标账号粉丝要200以下，7天内点赞大于100，带货笔记里的商品销量大于100，才符合低粉爆款选品的条件。

# 7.1.1.2 在📕内手动刷

确定好品类（比如帽子）之后，可以拿一个小号，持续搜索帽子相关内容。系统会慢慢给小号打上“对帽子感兴趣”的标签，然后持续推送帽子的内容。

刷到推送笔记时，点进作者主页看一眼，如果粉丝很少（尽量小于200），就顺手关注、点赞、评论一下。系统会记住你喜欢这类低粉账号的内容，后面就会优先给你推更多低粉爆款帽子笔记。

这样每天用小号刷一刷，你就能第一时间知道最近出了什么新款、什么文案和封面跑得更好。这个方法看起来花时间，但刷的过程本身就是在培养品感和网感。

# 7.1.2 对标帐号选品法（截品）

定了品类之后，用小号关注一堆同行账号——同行就是最好的老师。每天花20分钟把他们当天上新的商品浏览一遍，重点盯那些跟你差不多时间发布、但数据更好的品，像下面红框标出来的那样。

# 7.3 不同选手的选品侧重点参考

# 7.3.1 新手选品：跟最新爆品

新手别一上来就只卖自己想卖的东西，要紧跟近期热度高的产品，越新爆起来的越好。

在1.0阶段，有个基础判断方法：去做抖音创意中心爆款榜上的产品。注意别太纠结数据的绝对值——什么销量必须大于多少、点赞必须大于多少，没必要。能在创意中心榜单上出现，就已经是好产品了。

新手阶段最怕贪多，想去学一套特别复杂的选品方法。其实把创意中心选品法用透，足够让你跑通正反馈。跑通以后，再考虑进阶的差异化能力。

# 7.3.2 进阶型选手：同步跟📕站内爆品

进阶选手一般指：素材制作能力强、封面做得好、已经跑通正反馈的人。

到了这个阶段，可以同步去关注📕站内的爆品，也就是低粉爆款选品。和1.0阶段的关键区别在于：如果这个品在📕站内也爆了，说明它不仅能在抖音爆，在📕同样受欢迎，这也就进一步验证了它在这个平台的适配性。

但同步跟品的问题也同样明显：别人已经爆了，说明竞争已经存在。你就需要更快的跟品速度和更强的素材制作能力，才能脱颖而出。

# 7.3.3 更天赋的选手：提前挖掘需求产品 / 高爆品

如果你能力更强，能预判爆品，当然要走挖掘这条路。

一方面，可以提前布局：秋冬天之前，陆续上一些季节性产品，比如手膜、脚膜、暖手袋；节假日之前，布局出行产品，比如化妆收纳包、高铁搭子（毛毯、U型枕之类）；夏天之前，布局拖鞋、减肥运动器材，比如滚腿神器。

另一方面，可以针对爆品发力：爆过的产品一定还能再爆。如果你的技能更强，不靠抄别人的爆款素材和封面，而是能自己创造爆款封面和素材，那你就会成为新手模仿的对象。每一个爆款，本质上都是天赋选手对之前爆款内容的再加工。

# 八、📕 SEO

# 8.1 📕 SEO 的底层逻辑

SEO全称Search Engine Optimization，也就是搜索引擎优化。📕SEO，就是通过优化笔记里的关键词，来提升笔记在搜索结果里的排名。

现在很多用户已经把📕当成“百度”来用了——数据显示，70%的用户喜欢用📕的搜索功能，吃喝玩乐之前都会先搜一搜攻略。

举个例子，圣诞节想送朋友礼物，很多人会打开📕搜“圣诞礼物”，然后挨个点开相关笔记，尤其是排在前面的。如果内容打动了他，就会跟着博主买同款，完成从种草到拔草的闭环。

所以搜索入口来的用户，消费意愿通常非常强。搜索流量就是超精准流量，也可以说是一种“躺着赚钱”的流量。

某个搜索词下，你的笔记排名越靠前，用户看到你产品的机会就越大，你也越容易主导用户的消费决策。

这就是📕SEO的底层逻辑。

![](img/7c98d53b6bbdb6d8e027bee0b2a9c618.png)

# 8.2 📕 SEO 流量介绍

明白底层逻辑之后，我们再来看做📕SEO的三个好处。

1）流量精准，用户转化率高

不管你是纯博主还是商家博主，核心关注点无非两个：流量和变现。流量是变现的前提，所以怎么拿捏流量，是每个博主的必修课。

📕最主要的流量入口有三个：首页推荐页、关注页和搜索页。

![](img/d13eb1ff58e9df68c4e7d4c700d1c074.png)

首页推荐页是打开App的默认页面，流量最大，竞争也最激烈。普通人想上首页推荐，难度不小，需要足够优质的内容。关注页大家打开频率不高，尤其你关注的人多时，很容易就被刷没了。

剩下的搜索页，更适合普通人突围。只要你有一篇笔记能排到前面，整个账号就能持续获得流量。前面说过，搜索流量属于主动种草型，用户带着明确目的而来，精准度高，转化率也高。我们很多账号，来自搜索端的粉丝占比都超过了一半。

2）免费流量，不拿白不拿

一般来说，一篇笔记的自然推荐周期只有3-7天。即便是爆款，随着时间推移，系统在首页推荐页给它的流量也会逐渐减少。平台要留住用户，就必须不断补充新鲜内容。想继续在首页占位置，只能靠广告投放来维持。

但搜索流量不一样。只要你的关键词布局到位、笔记没有违规，它就能一直被用户搜到。两三个月前的笔记，甚至一年前的笔记，都还能给你带人。这相当于在平台放了一个长期有效的广告，而且不花钱。这么香的流量，不拿白不拿。

3）矩阵运营，占领赛道流量

给学员做分享时，我总会反复提醒：多号矩阵这件事值得认真布局，做生意的商家型博主更该如此。

我通常从两个角度来解释。

其一，分散账号风险。商家类博主往往有把外部流量引走的需求，可平台出于生态秩序和自身利益的考虑，对导流行为是全面禁止的。对这类有引流诉求的博主而言，长期做擦边动作，很难一直不踩线。违规尚可补救，真正致命的是封号；若把所有筹码押在一个账号上，风险实在过高。

其二，每增加一个账号，就多一个让用户发现你的入口，也顺势接住了大家爱比价的心态。账号铺得足够密，用户来回比较几轮，最后落脚点大概率仍在你自己的账号矩阵里。

不过有个前提：关键词必须布准。用户若压根搜不到你的内容，账号数量再多也等于白铺。所以，📕 SEO 这件事，确实得重视起来。

![](img/98d1fd8cc919898949984f1616704a56.png)

# 8.3 哪些因素左右 SEO 排名

在聊📕 SEO 的具体打法前，先要弄明白：一篇笔记的搜索排名，到底会被哪些变量左右。

总体来看，真正能施加影响的无非两类：账号层面的权重，以及单篇笔记的权重。

“权重”这个说法常被质疑，可在实操中，它造成的差别是可以被清晰感知的。账号是否活跃、原创比例高不高、内容够不够垂直，都会作用于账号权重；笔记的发布时机、点击表现与互动数据，则会影响单篇笔记的权重。权重越高，在搜索场景里被用户遇见的概率越大。

相比之下，笔记权重对最终排名的拉动，通常比账号权重更直接。

举个例子，新号初始权重往往偏低，可只要关键词布得精准、内容本身够硬，首篇笔记跑出高流量并非天方夜谭。并且，只要有一篇内容跑成爆款，剩余笔记往往也会被顺势托起，账号整体权重同样会往上走。

只要账号没踩严重违规的红线，常规笔记基本都能进入搜索结果的覆盖范围。当然，这一切仍有个大前提：笔记中必须出现用户真正会搜的那些词。
