# 2023小生意风向：八个值得盯的切口

近期，一场聚焦小本经营者的年度讨论会公布了八条值得注意的生意信号。这些判断来自若干个平台的后台数据与问卷走访，拼出了一幅小商户生存状态的图景。下面逐条看。

**其一：晚间消费撑起大块蛋糕**
2022年，做晚间生意的整体盘子，比上一年大了16.7%以上。长沙一地，晚间花销能占全天总额的六成以上。最新走访还发现，超过一半受访餐饮个体户准备把收摊时间推到21点后，主动接住晚归客流。

**其二：县城开播跑出更快速度**
一条宽带配一台智能手机，就能把城乡之间的数字落差拉平。货就在产地，不少小微把开播当成创业起点。2022年，在主要短视频与直播渠道上，县级卖家增幅超过150%，是整体水平的三倍。

**其三：几人小团队把货卖向海外**
Temu、Shopee与速卖通等渠道逐渐成熟，让小商户走向海外更容易。只有三到五人的小团队，已成中国商品走向海外的一股关键力量，并在逆势中扩张。线上跨境零售体量五年内翻倍，参与者里七成以上是小微；仅速卖通一家，今年服务的小微卖家数量较疫情前多出八成。

**其四：科创小厂也有硬实力**
在政策扶持之下，由工业和信息化部评定的专业化、精细化、特色化、新颖化企业，三年间数量扩张三倍，其中56%属于中小企业和微型经营主体。这些科技型小厂的收入增幅、利润水平，都是普通中小型经营者的两倍；平均每家握有15.7件专利。

**其五：短途出游带火周边小城**
做旅游生意的小店，接待的客人里八成来自本省；不用远行、花费不高的短途玩法更受欢迎，例如到淄博吃烧烤住两晚、去鹤岗低成本歇几天。飞猪平台上，今年销售额涨幅前20的目的地，有13席被海北、鄂州等新面孔拿下。

**其六：毛孩子生意，诊疗美容冒头**
猫狗被当成家人，相关开销持续冒出新需求。这个围绕伴侣动物的市场，每年平均增长超过18%。除了口粮，诊疗与美容护理正在冒头，已占近四成份额；街边小店的这类开销同比涨幅超过六成，值得小本创业者关注。

**其七：长者消费升级，适老产品有机会**
上了年纪的人花钱意愿明显增强。过去三年，这一人群开销的年均增幅为20.9%，比80后、90后还快。以淘宝美妆个护板块为例，年长用户的增长速度为整体水平的三倍；面向他们的出游、智能硬件同样升温。把服务与产品针对长者做适配，是小店可切入的方向。

**其八：男性颜值消费不容忽视**
打扮自己，早已不只是女性的事。在淘宝，主打男性需求的品牌与店铺，销售额同比涨了六成；走进轻医美机构的男性也多了起来，单人花费达到女性的2.75倍。面向男性的颜值消费，整体增幅超过200%。
