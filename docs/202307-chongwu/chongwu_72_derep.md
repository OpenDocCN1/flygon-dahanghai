# 宠物外卖小店：低成本、低门槛，跑通后再深入

如果你正考虑进入宠物行业，又不想一开始就砸太多钱，那宠物用品外卖店可能是个很合适的切入点。

我之前专门研究过线下宠物店的加盟模式。一个五十平米左右的门店，房租、洗护设备、宠物周边货品、员工工资，一年算下来差不多要20万。要是自己不会洗护，还得专门培训、实操，这些时间精力也是一笔不小的成本。

相比之下，宠物用品外卖店就轻便多了：主卖宠物周边商品，不需要背太重的房租和设备压力，启动资金有限也能做，操作还不复杂。同时，它采用同城配送的方式，顾客下单后很快就能收到货，解决了普通快递时效性差的问题。很适合先试水，边做边学，等摸清了门路再进一步深入。

和实体重投入相比，这种小成本起步的方式更灵活，风险也更低。
