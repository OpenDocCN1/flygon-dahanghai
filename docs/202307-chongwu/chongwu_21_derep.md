# 闲鱼买猫，意外挖到一条宠物导购的“泛CPS”生意

作者：  空想错视

日期：2022-11-24

前段时间想养猫，我就在闲鱼和淘宝上翻了好几家本地的猫舍。多数操作都差不多：先加🛰️，然后对方让你看朋友圈，里面全是各种猫咪视频，有的视频画质都模糊得不行了，还催着人去店里选猫。看起来挺正常对吧？我特意空出一天，准备把这几个地方一块儿跑一遍。结果联系之前那些“猫舍客服”时，口径出奇一致：我今天不在店里，你留个电话，我让店里的人联系你。

到这儿我也没多想。直到逛完三家，终于看中一只小猫，砍价时我顺嘴提到“你们线上销售说XXX”，店员直接回了一句：以我们店里的为准，线上那帮人说白了就是网上的串串——大概就是拉客黄牛的意思。

这时候我才彻底想明白他们的玩法：先在闲鱼这类平台铺一堆好看的宠物图片，把人引到🛰️；朋友圈早就备好了各个品种猫狗的素材视频；等买家约线下看猫，就把人带到合作猫舍，成交后拿提成。

更意外的是，我发现其中一个🛰️号居然还在打广告收闲鱼号。这说明这个套路确实能赚钱。做宠物相关生意的朋友可以借鉴一下。某种程度上，这也能算是一种“泛CPS”吧。
