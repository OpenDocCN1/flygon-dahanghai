# 半个月干到10万GMV，我的小红书起店复盘

说实话，和圈里那些动辄百万的大佬们比，这点成绩确实拿不出手。但对我自己而言，总算是在小红书这个赛道上有了一个能让自己点头的阶段性答卷[OK]。趁着今天午休的空档，简单聊聊我从0到1跑通小店过程中的几点心得。先说明一下：这不是手把手的操作手册，航海课程里的基础内容和流程已经足够详细了，我更多是分享一些实操层面的感受。

另外评论区里有朋友问了不少细节，我顺手整理一下自己的看法：

有圈友问我，单个账号测品是不是必须锁定同一个赛道，还是说跨类目也可以随便上？比如做宠物类的号，是不是最好别碰其他类目的产品去测试。我的建议是尽量做垂直。我自己是三个号对应三个赛道，另外单独留了一个号做杂乱测试。

关于“1V1复制”到底怎么理解，需不需要自己实拍。我的经验是，即便做混剪，你也要精确到每一秒去对标别人用的素材类型，然后找同类型的素材来拼，越细越好。

还有人问三个店是不是三台手机一机一号物理隔离，电脑端操作后台时网络有没有分开。说实话，一机一号这事儿已经被说烂了，这种基础问题真没必要纠结。后台我并没有做网络隔离——就目前这点体量，平台还犯不着对你的网络环境做风控。

最后有朋友提到剪辑模板的问题：是不是直接照搬爆款视频就行，素材要不要也从爆款里找。他觉得自己剪片子没什么思路，老是被素材带着跑，账号风格也不够统一。这个问题其实挺典型的，核心还是在于你要先想清楚自己的账号调性，再去挑素材和模板，而不是反过来让素材牵着你的节奏走。
