# 小红书电商红利期：三步跑通选品到出单

文/小毛

熟悉我的朋友都知道，我常在生财发帖，不过这回就跳过自我介绍了。我们团队今年才正式切入小红书电商赛道，运气不错，赶上了一波红利，也做出了些实打实的成绩。

先聊聊我们做这件事最直观的三点感受：其一，红利确实存在，这一点不用怀疑；其二，门槛并不高，上手不难；其三，执行跟不上、遇到问题不会灵活调整的人，想做好就没那么容易了。

我们把小红书电商的运营逻辑拆得很简单，关键就三步：**选品、测品、打爆品**。下面逐一说说每个环节我们是怎么做的，大家可以结合其他老师分享的内容参考着看。
