# 📕选品，别漏了社区热搜词

做📕店铺选品，找灵感的渠道不只有蝉小红这类付费工具。商家版App里还有一个容易被忽略的入口——社区热搜词。打开后，你不仅能翻看热搜词榜单，还能找到曝光量、点击量、成交量都表现亮眼的笔记。把这些榜单和高表现笔记结合起来看，选品方向会更清楚。
