# 3.3.5 问得清楚，答得才准

这类问题，其实正适合直接交给 ChatGPT。下面是它给出的建议。

当你向我提问时，可以试试下面这些做法：

• 把问题或需求说清楚，让我能准确领会你的意图

• 尽量短而聚焦，无关信息和冗余表述能省则省

• 少用随意的口头表达，尽量用通顺、规范的语言和语法，这样我更不容易理解偏

正面示例：

问：请用通俗的话说明一下，机器学习是什么？

这个提问目标明确，需求一眼就能看懂；表达也够简洁，没有夹带多余内容，语言同样规范。

反面示例：

问：我也不太确定能不能麻烦你。我有个事想请教，就是那个叫“机器学习”的东西，听说挺复杂，想问你能不能给我讲讲它到底是什么，要是可以的话真的非常感谢。

这个提问绕得比较远，重点不够突出，还塞进了不少无关信息；口头表达偏多，读起来容易让人抓不住核心。

提问时，也可以尽量多补充一些背景信息，这样我更容易理解你的问题，给出的回答也会更准确。另外，如果你对我的回答还有疑惑，或者需要我进一步说明，随时可以继续问。

ChatGPT 能答多好，很大程度上取决于你怎么问。想用好 ChatGPT，第一步不是学操作，而是先学会把问题问好。
