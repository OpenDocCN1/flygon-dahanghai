# 7.3.2 从想法到可拍脚本

想写脚本，却不知道从哪里落笔？别急着堆台词，先把“拍什么、给谁看、看完做什么”想清楚。目标明确了，后面的内容才有方向。

接下来，用一句话概括核心：这条内容最想传递什么。再把结构拆成“开头抓注意—中段讲清楚—结尾给行动”，让观众顺着你的节奏往下看。写的时候尽量具体：谁在什么场景里做什么、说什么，镜头能拍到，执行才不费劲。台词不必多，能推动信息就够了；节奏也不必满，留一点呼吸感，成片会更舒服。

初稿完成后，别急着开拍。读一遍、删一遍、补一遍：有没有废话？重点够不够突出？结尾有没有让人知道下一步做什么？反复打磨，脚本才会从“想法”变成真正能落地的拍摄方案。

这次分享参考了 @陈思成 @AI 训练师小凡 的经验。脚本创作没有唯一答案，但把目标、结构、场景和打磨做好，至少能让每一步都更稳。
