# 7.2.1.2 实操应用：把创意做成图

这一节用几个真实操作场景，演示如何让 ChatGPT 配合 Midjourney、D-ID 等工具，把脑海里的点子一步步落成可用的图、菜单、海报甚至数字人视频。

• 马克杯定制：先简单提示词，再上组合模板

假设你只想到一个画面：“马克杯设计，绿色帆船，金箔纹路”，其他细节暂时没思路，那就先让 ChatGPT 当设计助手。第一轮不加太多限制，让它用英文写一条不超过 50 字的提示词，在原场景上补充优质描述词。

![](img/156d59633e2e5e8cdfb72859add26d32.png)

![](img/d8e8ea75a125539cb16aa5471a50cb30.png)

初版效果已经挺漂亮。接着可以换上更复杂的提示词玩法：让 ChatGPT 扮演 Midjourney 的提示词生成器，先向你询问主题概念，再围绕主题、载体、场景、光线、色调、情绪、构图、画家风格等维度做优化组合，而不是机械照抄关键词。它要一次给出 5 条同主题提示词，每条不超过 50 个词，并翻译成英文，最后还要问你是结束当前任务还是继续下一个提示。

![](img/fda152975c3a54c955653ed82d3e0ac1.png)

![](img/9d2ee879a8b3aff698ed8f5aa7836f3c.png)

![](img/7c2f617e89feca3e6eb2c395b883586d.png)

![](img/510098123552bb487f4c58b55b9e9be4.png)

![](img/8412fab32ac8a5f89cb1c5fdb2a9906e.png)

![](img/61cca78a8fc9e34b113d3af50d68e272.png)

把主题设为“绿色帆船图案、金箔纹理的马克杯设计”后，很快就得到 5 款不同风格方案。挑中喜欢的那款，按左上到右下顺序点 U1-4，再优化成一张细节更丰富的单图。

![](img/f50d8ccff57e014c4e9535a4ca201d5b.png)

• 海报制作：AI 出图，再加字排版

海报也可以走类似流程。继续沿用上面的提示词生成器模板，把主题定为“酷炫个人全身形象海报，赛博朋克风格，色彩鲜艳，霓虹灯闪烁的高层建筑作背景”，并要求输出英文提示词。

• 菜品研发：从菜名到菜单图

这个玩法挺有意思：菜品研发和菜单制作也能交给 AI 辅助。先让 ChatGPT 模拟五星级酒店主厨，设计一款“虾球”，要求口感细腻、好吃；再让它把这款虾球做成菜单，想象用专业摄像机拍摄桌上这盘虾球，并把照片用文字描述出来，后面加上“逼真、现实、高清”等词，翻译成英文，控制在 50 个字以内。

![](img/ab982e31e20064a6949183293f8397ea.png)

![](img/8a0b064139a51d152124a7943dbfb4b7.png)

![](img/d95f85a30203f108a32e59bce578dd40.png)

看这效果，是不是有点想吃了？第二条提示词其实还能继续打磨。最初的思路是把菜品研究出来、真实制作再品尝，但没机会实践，于是改成先画出来。第一步写制作方法比较简单，关键在于第二步：怎样把菜品变成提示词放进 Midjourney 生成图片。起初想让工具模拟提示器或人工智能绘图，直接给关键词，效果略差；后来换了个角度，描述拍摄场景，让它用文本描述画面，再加逼真类词组，成品就顺眼多了。国外已有餐厅用 Midjourney 制作菜单图，可以看看下面的截图。

![](img/e50eedfbc308af31cf05dae52785287a.png)

菜单制作之外，这套方法也能用于📕图文：先写文案，再把文案里的画面转成图片描述，最后让 AI 绘画。

• 定制数字人视频：文案、图片、视频三步走

工具组合是：ChatGPT 生成文案 + Midjourney 生成人物图片 + D-ID 生成视频。前两步前面已经讲过，这里直接进入 D-ID 环节。

D-ID 网站：[`studio.d-id.com/editor`](https://studio.d-id.com/editor)
