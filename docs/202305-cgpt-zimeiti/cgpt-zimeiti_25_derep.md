# 4.1.3 角色指令这样用

操作并不复杂：先开一个全新对话，把角色设定作为第一条消息发出去。此后 ChatGPT 就会按照你指定的身份持续回应；只要没有超出记忆上限，这个设定能维持相当长的时间。

要注意，每个对话的记忆长度都有限。经过多轮、较长篇幅的交流后，最好检查一下输出是否仍符合最初的设定。若偏离明显，就另开一个新对话，重新写入角色身份。

如果你想创作不同主题的内容，建议分别使用独立对话，防止上下文互相干扰，导致结果出现偏差。

如果你是在搭建自己的 ChatGPT 应用，只需把角色指令填入系统前置的指令描述字段即可。
