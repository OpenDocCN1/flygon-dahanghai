# 5步让ChatGPT帮你起个好标题

很多人做小红书内容，最头疼的就是起标题，其实这件事完全可以交给ChatGPT来搞定。接下来就以小红书为例，拆解一套实用的五步操作流程：

**1. 设定身份**  
先告诉ChatGPT你是什么类型的博主，比如美妆、职场、读书，给它一个明确的角色定位。

**2. 说明方法**  
把你内容的核心方法或观点告诉它，让它清楚你要传递什么价值。

**3. 提供案例**  
给出一两个你喜欢的标题范例，帮它理解你偏好的风格和调性。

**4. 批量生成**  
让它基于前面的信息，一次性产出多个备选标题，供你挑选。

**5. 关键词优化**  
如果生成的标题不够精准，可以补充或替换关键词，让它反复调整，直到满意为止。

当然，每个平台的标题风格差异很大，这套方法不止适用于小红书，你在实际使用时，记得根据目标平台的调性去修改提示词，灵活调整才能发挥最大效果。
