# 7.4.4 你的 Prompt 库，得自己攒

往后真正能脱颖而出的博主，往往是复合型选手：既握有出色的内容制作方法，又能熟练调教 GPT。这样的人，内容能力和提示词驾驭能力缺一不可。

所以，务必搭建属于自己的 prompt 库，重点可覆盖这几项：

1. 如何发出学习指令，让 ChatGPT 更有效地学。

2. 用什么知识结构组织内容，才能让它更快领会。

3. 搭建范文库。实测下来，投喂数据的要害是推动它自主归纳；能归纳，才代表真正掌握。有时它梳理出的知识点，甚至能给你带来新启发。

4. 持续修正。很多圈友都做过类似动作：告诉它某处哪里不足、该朝哪个方向改。

内容来源：《如何用 ChatGPT 无脑复制抖音热门口播视频》
