# 1.2.2 总忍不住做的事，可能正是你的优势线索

你有没有发现，有些事你就是控制不住会去做，哪怕在别人眼里毫无意义。这往往不是单纯的习惯，而是某种内在动力在悄悄牵引着你。一个人愿意长期重复某个动作，多半因为能从其中得到满足，这份满足里，也许就藏着你的优势。

举个例子。我认识一位朋友 A，她特别爱往外跑，参加各种活动、认识陌生人。就算深夜十一点，只要活动还没散场，她也愿意赶到；如果连续一阵子没社交，整个人都会提不起劲。遇到麻烦时，她的第一反应不是独自消化，而是出门找人聊聊，听听别人的经验。她的“取悦、行动、积极”三项才干非常明显。对她来说，接触新人、体验新鲜事不是消耗，而是充电。她在场时气氛总是很好，大家聊得热络（取悦+积极），听到好建议就马上行动并快速获得反馈，于是不断调整和成长。

不过，“重复”并不总带来正面评价。就拿我自己来说，我总是忍不住刷各种资讯、看商业报道、发朋友圈，结果就是特别容易分心。还有朋友沉迷报课，家里堆满各种收集来的小物件，常被调侃“不干正事”；也有朋友话不多，但每次开口就直接指出问题、给出方案，被当成爱挑刺。

这些行为在这类人身上，都曾被怀疑过“是不是跑偏了”。但换个角度看，那些“忍不住”，恰恰暴露了底层的思维、理念、搜集、学习、取悦等才干。比如我自己，写作变现早已超过七位数，但我从未正经上过写作课。为什么能持续写？因为我搜集了大量素材，理念总能冒出新点子，思维再把它们加工成文字。不是刻意练出来的，只是顺着才干走。

所以，如果你也有某件总是想做、不做就难受的事，无论别人怎么看，它都值得你重视。那背后很大概率是一个未被满足的才干需求。关键不在于急着否定或压抑它，而是找到适合它发挥的场景，学会把它放大成优势。
