# 二十九、前瞻才干：看见未来的人

你有没有遇到过这样的人？大家还在处理眼下的问题，他们的思绪已经跑到了明天、下个月，甚至更远的以后。他们总在捕捉“事情会变得更好”的线索，也很容易被一个还没实现的好想法点燃热情。对他们来说，未来不是虚的，而是一种可以提前感受到的画面。

这种人才往往自带“梦想家”气质。只要看见某个方向有变好的可能性，他们就会忍不住兴奋，并且特别愿意讲给身边的人听。他们描述起以后的好日子来，绘声绘色，很多原本犹豫的人也会被说得心动，觉得跟着走有希望。所以，他们常常是团队里那个给人打气、让人看到奔头的人。

日常里，他们会不自觉留意那些指向未来的东西——可能爆发的趋势、关于明天的预测、能让自己变得更好的人或资源。至于什么样的未来最让他们着迷，那就看每个人自己的兴趣和优势在哪了。

不过，任何才干在不知不觉中都可能变成盲点。对这类人来说，最需要留意的是别只顾着向往远方，反而忘了今天的生活也有值得珍惜的部分。他们可能脑子里全是明年的大计划，却没注意到眼前这顿饭、身边这个人。

另一个难题是：不是所有人都能像他们一样“看见”未来。他们心里明明有一幅清晰的图，别人却可能什么都摸不着。如果能借助合适的语言、工具、草图，把那个未来一点一点摊开，让身边的人明白“为什么值得一起去”，事情就会顺利很多。可惜的是，很多人在兴奋中忘了做这一步。

更隐蔽的问题是，他们总想找到那个“最正确”的未来，却迟迟不肯行动。但未来不是坐在那里想出来的，它是在一步步行动中被验证、被修正、被塑造出来的。再好的蓝图，也要从现实里踏出一只脚。

当这项才干发展成真正的优势，它就非常有力量。这类人会本能地捕捉到关于未来的各种细节，也乐于吸收和分享与美好明天有关的信息。他们常常能让停在原地的人看到出口，在充满不确定的当下找到方向。他们甚至能提前感知到某些事情可能会发生，或者应该发生。

如果你身边有这样一个“未来型”的朋友，不妨多听听他们在说什么。如果你自己就是这种人，记得偶尔把目光收回来，看看脚下的路，也学会把那个你想去的远方，讲成别人也能看见的样子。
