# 十二、会表达，更会连接

拥有“沟通”这项才干的人，身上常常带着一种自然的表达冲动。他们愿意开口，也容易让旁人心甘情愿地听下去。心里往往有个声音：我讲的内容，值得被听见。也正因如此，他们会反复琢磨更鲜活、更有趣、更能打动人的说法，努力把话讲得漂亮。

这类人通常不怵解释、描述、主持或演讲。他们擅长把抽象想法变得可感：一个念头，能转化成一段故事、一幅画面、一个例子，甚至一个恰到好处的比喻。

不过，表达欲一旦过满，也可能变成沟通的阻力。话匣子打开后，容易一个人讲到底，别人插不上嘴；注意力全放在“我要怎么说”，却忘了“对方在说什么”；甚至会错过他人话里的重点，以及那些没说出口的部分。

当这份才干被用对地方，它会成为很强的优势。他们往往能迅速找到贴切的词句，谈吐生动，趣味自然流露，听众的注意力会被牢牢抓住。借助形象而有画面感的表达，他们更容易说服人、鼓舞人，推动别人向前走。尤其在不同场景中，他们能把表达调整得恰到好处，这种能力非常突出。
