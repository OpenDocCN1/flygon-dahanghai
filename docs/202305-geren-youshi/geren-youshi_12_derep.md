# 2.3 盖洛普用在哪儿？

盖洛普发源于职场测评与学术研究，以积极心理学为理论基础，是一套综合性的评估工具，既能帮助个人看清自己，也能帮助组织理解成员。它适用于员工、管理层、学生、家庭以及个人成长等多种对象。在实际运用中，主要体现在以下几个方面：

**个人成长**：想要真正改变自己、持续进步，第一步是知道该从哪里入手。盖洛普能够反映一个人长期稳定的行为模式，而我们之所以总用相似的方式做事，背后其实是优势才干在驱动。通过测评，可以更清晰地看见自己的内在需要，进而接纳自己、欣赏自己，逐步建立自信。

**职业发展**：借助盖洛普，个人能识别自身的优势与成长空间。当优势与岗位要求相匹配时，工作胜任力会明显增强，做事更高效，产出也更有价值——相当于给自己装上了一个职业加速器。

**团队建设**：对管理者而言，盖洛普是识人用人的实用工具。它能帮助管理者看到每位成员的优势和潜力，为搭建高效团队提供依据，最终带动整体绩效提升。同时，成员之间通过了解各自的才干特点，也能更包容彼此的差异，形成多元共融的团队文化。

**人际关系**：每个人天生擅长的事情不同，所以我们很容易拿自己的尺子去衡量别人。比如，有人喜欢随性自由，有人偏爱按部就班，结果谁看谁都不顺眼。如果双方都能借助盖洛普去理解彼此的出发点，很多误会可以消除，关系也会变得更融洽，尤其是在伴侣和亲子之间。
