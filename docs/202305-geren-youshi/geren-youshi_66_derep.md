# 4.2.1 他总泼冷水，未必是在否定你 @叶叶在觉

这对情侣从少年时代就相识，相伴了二十年，彼此都明白这份感情的分量，却常常吵得不可开交。

Linda一直想不通：自己每次提出新计划，男友为什么总先泼冷水？比如她准备运营📕账号，觉得这段经历能给履历加分、提升竞争力。可男友听完并不兴奋，反而把“可能遭遇网暴”说得挺严重。

后来看两人的盖洛普优势报告，答案才浮出来：男友的「排难」排在第一，Linda的「积极」位列第五。她习惯先捕捉机会和光亮面，他则本能地扫描隐患、风险与漏洞。

我在解读时告诉Linda：“他不是在给你拆台，而是希望你把变量都摆上桌面，先备好预案。”她男友很认同，并说出心里话：他知道Linda对负面评价格外敏感，担心她真去做📕后，看到难听的评论会情绪受挫，所以故意拿“网暴”这个更刺耳的词来敲警钟，让她想清楚再行动。

听完这些，Linda很感动。她终于读懂男友的思考方式，也不再觉得两个人不合适。

感情再深，也别把“聊不到一块儿、相处太累”当成分手的理由，冲动做决定前先停一停。借助盖洛普看清对方思维怎样运转，许多原本会冒出来的冲突和误会，其实都能被化解。亲密关系里的障碍，往往不是不爱，而是还没读懂彼此。
