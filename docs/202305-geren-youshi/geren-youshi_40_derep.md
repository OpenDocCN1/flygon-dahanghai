# 十七、把陌生人聊成朋友

拥有“取悦”才干的人，很在意人脉铺得够不够宽。他们热衷认识新面孔，和陌生人打交道毫不发怵；人越多、生面孔越密，越容易主动开口，几句寒暄就能打开局面，让对方迅速卸下心防，进入自在的交谈状态。在他们看来，陌生人并不存在，只是朋友还没登场。

这种特质也有暗面。新朋友一个接一个，老朋友却容易被晾在一旁，旁人可能因此觉得他们只爱新面孔、不够真心，对旧交不上心。另一重盲点在于，他们习惯快速拉近距离，却未必留意每个人的社交半径和节奏并不相同——有人慢热，也有人偏谨慎。

当这份才干被用好，他们与人相处自然松弛，还能带动周围人聊起来，给聚会注入热度与活力，让场子不容易冷，也不会让人感到隔阂。这样的社交高手，常能撬动旁人不容易拿到的资源，抓住不易碰上的机会。
