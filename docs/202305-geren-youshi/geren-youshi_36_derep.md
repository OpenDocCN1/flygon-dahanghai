# 十三、骨子里就想赢

有一种人，天生对“比赛”两个字敏感。他们待在有竞争感的环境里会更来劲，争胜心很强，对“拿第一”这件事有执念。他们会主动找参照对象，给自己摆一把看得见的尺子——业绩、分数、排名，都可以拿来衡量进展。

在他们眼里，头名只有一个。拿不到第一，就说明前面还站着人，也说明自己还没真正赢。为了把局面翻过来，他们愿意多扛很多辛苦，一路把自己推到最高处。可一旦没赢，心里的落差也会很重，甚至会觉得自己此前拿到的东西都失去了分量。

**下意识表现**

- 对竞赛氛围有天然好感，胜负心被点燃得很快。
- 会锁定可追赶的人，并用业绩、分数、排名等硬指标校准自己。
- 极度渴望第一，会尽力做到最好；不是第一，就等于还没赢。
- 为了胜利肯加码付出，直到站上顶峰。
- 失败后容易心理失衡，觉得成绩变得空洞。

**容易踩的坑**

- 争胜心太强时，容易把关系也处理成对抗，最后把关系弄僵。
- 会把自己的求胜欲套到别人身上，忘了不是所有人都想争第一；只盯着输赢，可能冒犯别人、伤到感情。
- 为了赢，可能做出冲动的举动，事后又后悔。越是想赢，越要守住原则和理智。

**用对了会怎样**

- 内驱力足，不愿混日子，也总能发现值得追赶的标杆。
- 能把“想赢”的氛围带起来，让团队更渴望第一，从而抬高整体成就水平。
