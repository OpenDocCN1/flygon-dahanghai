# 二十二、让共识成为团队的黏合剂

**本能反应**

这类人天然地追求一致性，擅长从不同观点中找出大家都能接受的共同点。他们非常在意团队氛围是否平稳和谐，排斥对立与争执，认为冲突只会带来消耗，没什么实际价值，因此会想方设法绕开对抗。当意见出现分歧时，他们不会死磕差异，而是主动引导对话聚焦于双方都能认可、有继续合作基础的部分，在分歧中搭建桥梁。

**盲区与代价**

然而，这种对和平的执念也有另一面。为了避开冲突，他们可能不断让步，甚至放弃自己的原则和底线，到头来不仅自己受了委屈，合作关系也未必能真正稳固，甚至可能为后续更大的矛盾埋下伏笔。同时，过度追求表面上的和气，也会让他们有意无意地压制别人公开表达真实感受和想法，让问题得不到及时暴露。

**优势的展现**

当和谐才干得到充分施展时，它就成了团队的润滑剂。它能显著降低内部摩擦，让合作更顺畅，也更有凝聚力。尤其在各方争论不休、陷入僵局时，这类人能够主动避开那些容易引爆对抗的互动方式，引导大家求同存异，最终推动团队形成共识，让所有人朝着同一个方向前进。
