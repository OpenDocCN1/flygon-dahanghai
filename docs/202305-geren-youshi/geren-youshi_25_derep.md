# 三、信仰才干：认准了，就不轻易松手

拥有“信仰”才干的人，心里往往有一套很稳的准则。他们不一定会天天把信念挂在嘴边，但一旦认定什么是对的，就很难被外界带偏。遇到难题、困惑，甚至一次次受挫，他们通常也不会轻易丢下自己的坚持，反而更能靠韧性和毅力继续往前走。

当一件事与他们的价值观同频，他们会拿出很强的热情、行动力和推进到底的决心；可如果某件事触碰了他们的底线，或者与内心信念相悖，他们也很容易产生抗拒、排斥，甚至直接说“不”。比起金钱、名望和外在光环，真正能点燃他们的，往往是这件事有没有使命感、有没有意义。

这种才干还会给其他才干加上一层“信念加固”。一旦认准，就不太容易被改变。比如“个别”才干突出的人，本来就相信每个人都有独特性；再叠加信仰，他们会更反感“一刀切”，更坚持“人生而不同”。又比如“伯乐”才干强的人，天然觉得人人都有潜力；加上信仰后，他们更愿意相信“人生而有用”，也格外讨厌别人漠视、低估或无视一个人的才能与可能。

当然，稳定也可能带来盲点。因为价值体系不容易改变，旁人有时会觉得他们固执、只按自己的方式来、不够灵活；面对不符合自身信念的事，他们也容易表现出批判和排斥。

可当这份才干被用在优势位置，画面就完全不同：他们会凭借清晰、坚定且稳定的价值观，朝着理想目标持续前进，不轻易偏移，也能把这种笃定传递给身边的人。
