# 二十八、回顾才干：向过往借一束光

有一种人，天生带着“后视镜”般的敏锐。他们不太容易被喧嚣的当下牵着走，反倒对“事情是怎么开始的”充满好奇。无论是某项决策的来龙去脉，还是一个人行为的深层动因，他们都想追根溯源。在他们眼里，今天的一切都不是凭空出现的，历史上的每个片段都藏着可参照的答案——所谓“太阳底下无新鲜事”，正是他们内心的笃定。

这种才干最典型的体现，是他们对“来路”的天然敏感。他们喜欢阅读带有时间脉络的材料，比如历史典籍、人物传记，甚至自己的旧日记。记录和复盘对他们来说不是任务，而是一种本能。他们擅长从零散往事中提炼经验，别人眼里平平无奇的旧事，他们却能看出规律与线索。他们仿佛随身带着一台时光机，随时可以回到过去寻找解释当下的钥匙。

然而，如果没有觉察这份才干的“滤镜效应”，也可能陷入一些困境。因为太信任过去的经验，他们可能忽视环境已经发生的变化，把旧地图当作新导航，从而在面对全新局面时显得僵化。过度沉浸在往昔，也容易给外界留下“守旧”“不愿改变”的印象，让人误以为他们抗拒向前看。更棘手的是，一旦遇到从未有过的经历，他们可能感到心里没底，仿佛失去支撑。此外，他们自己对旧事津津有味，却未必意识到别人早已对陈年旧账兴味索然。

但一旦将这份才干打磨成优势，力量便不可小觑。回顾者能够以史为鉴，从过往中提取可复用的原则，用来预判和应对未来的挑战。他们不轻易被一时的流行声音带偏，总能找准事物的源头，洞察其演变的轨迹，因此常能给出别具一格的视角和灵感。更重要的是，他们还擅长帮助身边人找回初心——当团队迷失方向时，他们能把大家带回最初的那份承诺与热忱。

如果你拥有回顾才干，不必把它藏起来。它不是你前进的包袱，而是你独有的一盏探照灯。学会带上它，一边回望，一边向前，你便能在变化的世界里走出自己的从容。
