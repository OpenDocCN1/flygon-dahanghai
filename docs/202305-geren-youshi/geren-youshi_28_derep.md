# 六、纪律才干：把秩序用成优势

有纪律才干的人，常常在不知不觉中流露出对规则、步骤与统一性的偏好。他们乐于把做事方法理清楚，偏爱明确的标准作业程序（SOP），也希望推进过程有稳定节拍。相比最终拿到什么成果，他们往往先看过程有没有走对、环节是否排列有序；他们更容易先思考“这件事该怎样做”，而不是一上来就追问“要做什么”。

这种习惯若不加觉察，也会变成盲点。对既定规范和秩序看得过重时，一旦外部条件变化，他们可能仍沿着旧轨道走，调整不够快、变通不够及时；把流程是否严密、步骤是否规范盯得太紧，又容易冲淡对结果的检验；同时，他们总希望周围环境井井有条，却可能忽略另一些人只有在自由、宽松、鼓励创新的空间里才更能施展。

当纪律才干被发挥成优势，个人层面会表现为做事有章法、安排有条理，推进效率稳定而有序；在团队中，则能把秩序感带给伙伴，让项目节奏清楚顺畅，也让事情更可预测、更易协同。
