# 二十四、别把所有人当成同款

拥有“个别才干”的人，天生相信人与人大不相同。他们的注意力总会落在个体之间的差异上，反感一刀切、粗暴归类。越独特的人越能勾起他们的兴趣：风格、动机、思考路径、交往方式、潜力所在，都值得花时间琢磨。他们像在为一场戏挑选演员，研究每个人的长处，期待每个人都能拿出自己的看家本领，而不是被塞进同一个模子，做同样的事、长成同样的人。

不过，这副“看见差异”的滤镜也有盲区。当团队整体利益更关键时，他们可能仍把目光锁在个体身上，忽略集体需要。另一个常见误会是：你研究别人往往比对方研究你更细，于是容易默认“我懂你，你也该懂我”。若不主动说出自己的偏好，失望就可能悄悄累积——比如觉得对方不够上心。牵涉他人的决定时，他们习惯把多方利益都摆上桌面，决策因此偏慢；面对通用规则和流程，他们也容易先去找例外，反而轻视规则本身的有效性，甚至被误解为区别对待。

当这份才干被用对地方，它会成为很实在的优势：能识别不同人的特质，把他们安排到合适位置，搭出能力互补、运转高效的小组；也有识人的眼力，因材施教，优化人员配置，让潜能被充分利用。做个性化、量身定制的服务，更是他们的拿手戏。
