# 盖洛普报告怎么读？

这一章要解决的问题很明确：拿到盖洛普结果后，怎样把它读明白。如果还没完成测评，建议先转到「附录一：如何进行盖洛普测评」做测试，再回来往下看会更顺。

打开报告后，先别急着逐条抠才干。第一步是看盖洛普的四大维度，判断自己的优势落在哪一类。盖洛普把优势分成执行力、影响力、关系建立、战略思维四组。顺着这四个方向看，认识自己会更快。就算某一维度看起来不突出，也不用灰心——这不代表你没有对应的能力。

第二步是弄清自己的天赋才干排序。34项才干的详细说明篇幅较长，为了阅读顺畅，放在本章末尾「3.4 了解34项基础才干」，需要时翻过去查即可。

刚开始接触的人，先把注意力放在前5项才干上，优势往往就藏在这里。结合报告里的“才干特质”“报告详解”“盲点”等部分，看清这些才干在什么场景下发挥得好、什么场景下容易出问题，再去找适合它的环境。环境对了，生活和事业的价值感、意义感都会更强。

排序靠后的才干，很可能对应我们的“弱点”。盖洛普所说的弱点有两种：一是把靠前的才干用错了，得到负面反馈；二是动用了靠后的才干，同样带来负面反馈。盖洛普主张用优势补劣势，借助目标拆解、优势互补等办法，不少困难也能找到解法。

如果你不清楚某个才干需要哪些具体动作才能被满足，可以看「3.2.3 拓展：34项才干的需求清单」，那里有一份需求清单。

才干组合也是盖洛普很有意思的地方。单项才干只反映你身上的某个特质，34项才干放在一起，才拼出独一无二的你。关于才干组合的多种表现，会在「3.3 了解组合才干的应用」里展开。

不过初学者别一上来就钻组合，很容易把自己绕晕。更稳的路子是先从单个才干学起，弄明白后再做两两组合练习，熟练度会慢慢上来。

⚠️ 当然，前言里也说过，这本手册更像一本盖洛普工具书，帮你先对盖洛普和自己有个初步认识，这一章也是如此。若想得到更专业的建议，最好联系教练做更深入的解读。
