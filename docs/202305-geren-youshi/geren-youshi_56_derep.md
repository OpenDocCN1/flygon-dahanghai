# 三十一、走到哪都在攒资源的人

• 下意识的样子
这类人好奇心旺盛、脑子活、办法多，生活里常反复做同一件事：把信息、人、物品等有用的东西不断收进来，再归类存放，仿佛天生就是一座资源仓库。很多内容未必马上派得上用场，他们却常有一种直觉：先留着，说不定以后能用到。因为涉猎广，他们对不少事情都能说上几句。只要存下的东西被调用——自己受益也好，帮到别人也好——内心就会很满足。在他们眼里，资源没有“没用”这一说，只是“暂时还没轮到它上场”。

• 滤镜没调好时
好奇心一旦过载，收集就容易变成堆积：信息攒得太多，真要用时反而翻不出来；不断搜罗新内容，也容易忘记时间和原本目标，效率被拖慢、注意力被分散。再加上手头资料丰富，如果不先筛选就转给别人，参考信息可能过量，本想帮忙，结果反而添乱。

• 变成优势以后
当这份才干用顺了，他们就像一个随取随用的资源站，常靠分享积累的东西帮到旁人；也能把合适的工具带进团队，推动增长和业绩。他们足智多谋，愿意给出具体、落地的有形支持。别人忽略掉的日常信息，他们往往会在不经意间默默存下来。
