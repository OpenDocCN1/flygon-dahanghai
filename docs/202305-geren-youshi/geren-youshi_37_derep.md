# 十四、把优秀做到极致

有一类人，做事时心里常有一条更高的线：明明已经过关，仍会琢磨怎样再精一点、再好一点、再值一点。这正是“完美才干”的底色——不是被动抠细节，而是本能地想提升质量，让每一分投入都换来更大的产出。

他们通常先看长处，而不是死盯缺口。只要发现有价值的人、事或资源，就希望把作用发挥到最大；比起费力补弱项，更愿意把长板拉长。对结果，他们有自己的门槛：普通水准很难令其满意，事情不仅要“很好”，还要从“很好”继续往“更好”走，从出色推向顶尖。他们也偏爱和高手合作，能敏锐看出自己、他人与任务之间的契合度，也乐于帮优秀的人再上一层楼；反过来，对自认平庸、不愿精进的对象，往往不太愿意共事。

不过，这种驱动力也会带来“滤镜”。因为太在意高质量和优势发挥，有时容易被旁人理解成不能一视同仁，或者只偏爱强者。他们可能渴望穷尽所有可能，把团队里每个人都推到更优秀的位置；但并非所有人都追求极致，有人觉得“够用就好”。这时，接受“足够好”也是一种成熟。另一个容易踩的点是反馈方式：他们给出的常常是挑问题、提要求，比如“还能更好”“这里仍有优化空间”，本意是推动进步，却可能让伙伴感到标准太高、压力很大。

当这份才干真正变成优势，画面会很不一样：他们不断抬高成功标尺、重设目标线，交出让人眼前一亮的结果；把精力压在长项上，绕开弱项，让投入产出更高效；也懂得用优势激励个人和团队——看见每个人的强项，让每个人做最擅长的事，个人、团队和集体便一起往上走。更关键的是，他们擅长搭出能力互补的队伍，把各自的长板拼在一起，做出真正出色的产品。
