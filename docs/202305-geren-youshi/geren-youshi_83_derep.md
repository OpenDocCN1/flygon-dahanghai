# ③ 盖洛普测试操作指南

如果你是从教练那里买的测评码，可以参考下面这套流程。其实在官网自己购买也一样，差异只在于第二步变成登录已有账号，不需要重新注册。

第一步：拿到测评码。先去购买时留下的邮箱里找一封来自“Gallup”的邮件，看到后点邮件里的“开始使用”。

第二步：创建新账户。跟着页面提示完成注册，填信息时用真实资料或化名都行，一路点“下一步”，直到注册成功。

第三步：进入克利夫顿优势评估。当页面出现评估入口时，说明你马上要开始测试了，点击“参加克利夫顿优势评估”，再点“继续”。

第四步：答题。按照「② 盖洛普测评注意事项」里的要求作答，做完 177 道题目就好。

第五步：导出“34 项才干优势报告”。

1）测完以后，点“菜单”，再选“克利夫顿优势”，报告就在眼前。

2）往下滚动页面，随便点一个“查看我的报告”（红色框里的那个）。以“醒醒”为例，左侧彩色图是她 34 项才干的分布，右侧红框里的“查看我的报告”则通向完整版优势报告。

3）点“下载报告”。

4）点右上角的“下载按钮”，保存文件。

5）下载完毕，你会拿到一份 24 页的优势报告，这份报告相当于一个入门级解读。
