# 八、责任才干：答应就做到

**藏不住的本能**
责任才干突出的人，常会不知不觉把担子往自己身上放。他们很在意别人是否觉得自己可靠、值得托付；承诺一旦出口，就会在心里记成必须完成的事项。正因如此，没把握的事他们很少随口答应，宁可先想清楚再点头。只要应承下来，事情再小也会认真到底，亲自跟进、全力兑现。对他们来说，“说出口的话要算数”不是口号，而是骨子里的准则；万一没能做到，愧疚感会推着他们不断想办法补救。

**被责任滤镜遮住的角落**
问题也常出在这里。别人开口求助时，他们不太会拒绝，哪怕事情已超出能力范围，也容易把锅接过来。还有些本不属于自己的责任，他们也会默默扛下，时间、精力被切走，人也会越来越累。更隐蔽的一点是，看到别人不像自己那样愿意付出、说到做到，他们可能给对方贴上“不够负责”的标签；可事实未必如此，对方也许只是更相信“先做再想”，或者更看重“及时止损”。

**当这份才干长成优势**
一旦责任才干发挥得好，新项目要找人托付时，他们通常最先被想起——过去的交付记录摆在那里，让人形成“交给他放心”的印象。因为长期守信，个人口碑往往很稳，别人会自然产生信任和依赖。这样的特质还会向上影响团队，让所在团队的整体道德标准也跟着抬高。
