# 二十、看见潜力的天赋

有些人好像天生就能捕捉到别人身上的光亮：谁正在悄悄变好，谁身上还藏着尚未释放的可能，哪怕变化很小，他们也能第一时间察觉。这种本事往往不是刻意训练出来的，而是下意识就发生了。

**下意识：总想推人向前**
在日常相处中，这类人常常不自觉地想拉对方一把，帮人成长、助人成功，而且显得很有耐心。他们会主动琢磨办法，让身边的人尝到成功的滋味。一旦确认自己确实推动了对方的进步，内心就会涌上满足感——这既是他们拿手的路径，也是价值感的重要来源。

**盲点：热心别变成催促**
不过，这份热心也有容易踩空的地方。有时他们会把心力投到并不合适的人身上，结果偏离目标、消耗自己；有时明明看见了对方的潜力，却容易不自觉地催促对方加速。可每个人都有自己的步调，过早介入反而可能让对方感到被推着走。还有一种情况常被忽略：把注意力都放在别人身上，却冷落了自己的提升。先把自己的本事练足，伸手相助时才会更从容。

**优势：把潜力变成看得见的希望**
当这份才干真正长成优势，他们会很自然地捕捉到旁人向前迈进的痕迹与尚未释放的能量，并把助人放在很靠前的位置。在团队中，他们能带动后备成员把能力练起来，使成员与团队都能看见前景中更多的可能性；面对一时看不见自己优点的人，他们也愿意耐心鼓励，帮对方对未来生出希望。更重要的是，他们不只停留在口头打气，还能把支持落到实处的资源和行动上。
