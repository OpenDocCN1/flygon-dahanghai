# 四、公平才干：守规则，也要看见人

拥有公平才干的人，往往对规则是否公开、过程是否透明、标准是否前后一致格外敏感。他们本能地希望同一套规则对所有人成立，机会和资源不该因身份不同而倾斜；遇到特殊照顾、托关系、靠裙带上位，会尤其反感。这类人常把自己看作公正与正直的守护者，做判断时未必先顾个人得失，反而更容易把集体需要摆在前面。他们坚信，只有规则清晰、对每个人都一样，环境稳定，个体潜能才可能充分释放；无论对方社会地位高低，都该被平等对待。也正因如此，他们对“哪里不公平”往往十分敏感。

但这份敏感也有阴影。若把一致性看得过重，就容易忽视人的差异与独特处境，最后变成简单粗暴的一刀切。太执着于“公平”二字，也可能忘记世上并无绝对公平，所谓公平未必等于最合理的资源配置；有时为了形式上的均等，反而压住了表现突出者的积极性。

当公平才干被用对地方，它会成为明显优势。团队中有这样的人，成员更容易感到氛围公正，不必担心遭遇不公，执行效率与相互信任都会随之提升；他们自己也更容易让人信服，积累公信力和威望，赢得伙伴认可。在标准化流程建设上，这类人往往很有一套：从反复出现的工作里梳理出可共用的流程，让大家使用同一套 SOP，会给他们带来实实在在的成就感。
