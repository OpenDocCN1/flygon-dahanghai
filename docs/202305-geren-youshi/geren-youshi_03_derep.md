# 一、把力气花在擅长处 @醒醒同学

做事总往后拖、想法很多行动很少，嫌自己脑子不够灵、待人冷淡、性子太软，或者又过于强势——这些标签常常拖累一个人的职业发展和人际相处。可换个角度：拖延也许是因为做了不擅长的事，效率自然低；冷淡可能出于理性；软弱可能源于善良；强势可能是果决。任何负面评价的背面，往往都藏着正向资源。当你习惯先看有利的一面，而不是只盯着缺陷，转变就会悄悄发生。

在我有限的职场经历中，越觉得自己不如别人，越容易去比较，拿自己的弱项硬碰别人的强项，结果常常越做越差；反倒是相信直觉、去做擅长的事时，结果会超出预期。以前我列过一堆毛病要改，也常把成绩归因于运气；可越是想改，越容易被旧习惯拽回原点。哪怕外界给再多肯定，我仍会觉得自己差一截。直到接触盖洛普，它像一台显微镜，把我的天赋与不足放大给我看，再结合过往经历，我才逐渐看懂自己。

我明白了为什么互联网比国企更适合我：我的关系建立和战略思维很突出，成就才干排在第九，喜欢灵活变动的环境。国企那种朝九晚五的固定节奏，我待着会很难受；想法越多、越努力，反而越觉得被压住。而我的纪律才干排在末位，在强调规矩和流程的环境里也会格外别扭。也明白了为什么之前能连续拿下销售冠军，不少同事在危机时刻会来找我帮忙。体谅和个别才干突出，让我对情绪敏感，和用户聊几句就能捕捉到对方的需求；理念突出，点子多、办法多；战略突出，总能给出解决方案并赢得信任；适应才干突出，越遇到突发情况越兴奋，越能发挥得好。客户信任建立起来，成交就成了水到渠成的事。

做优势教练近两年，我发现一个规律：在职场和生活中能认清自己天赋与优势的人，往往越过越顺。盖洛普的研究也发现，做出成绩的人大多懂得把优势用足、避开不擅长的战场。天赋就像一路升级打怪时握在手里的独门武器，而盖洛普是那本使用秘籍；明明有一身武器却不会用，实在可惜。

希望越来越多人加入“唤醒天赋的旅程”。懂得欣赏并接纳自己，才是终身幸福的起点。
