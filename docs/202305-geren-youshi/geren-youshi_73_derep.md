# 4.4.1 应用方向一：管理内耗，先找卡点 @叶叶在觉

不少团队管理中的消耗，并不是能力不足，而是没看清真正卡住自己的地方。下面两个真实场景，或许能带来启发。

**案例六：不忍辞退绩效垫底的主管**

一位团队主管卡在“要不要辞退某位不胜任员工”上。对方屡次出错，多次提醒仍无改进，团队业绩被拖累，士气也受影响。可她始终下不了手走辞退流程：一方面想再给机会，另一方面怕对方受打击、担心其求职受挫。她的盖洛普才干测评显示「和谐」与「审慎」靠前，这解释了她为何不愿在人际关系中当“坏人”，也会反复权衡负面后果。

找到这个卡点后，我帮她松动了“辞退=做恶人”的念头：越早告别一份不合心意的工作，反而越有机会更早去做真正热爱的事。

**案例七：总说团队带不动的微商团长**

另一位微商团长的「学习」和「成就」两项才干很突出，自己每天能量满满，于是很难理解别人为何“卷不动”，一度把下属的状态归因于懒。可真实情况也许是对方精力本就不如她，或者对工作的重视程度不同。过去她常挥着“小皮鞭”催大家更拼，结果团队难受，她自己也累。

针对这种情况，有两条建议：一是筛选与自己同样高投入、高驱动力的人；二是接纳并非人人都像她那样强烈渴望赚钱，去看见成员真正的动力来源，再用匹配的方式激发他们。

想通之后，她很少再因“带不动团队”而内耗：带得动的人认真带，团队反而发展得不错。
