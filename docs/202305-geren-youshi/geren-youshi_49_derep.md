# 二十五、自带光的人

有些人一出现，场子就松了；他们像随身带着光源，走到哪里都能把气氛点亮。这说的，就是“积极”才干。

## 本能反应：先看见亮面

他们通常外向、爱笑，脸上常挂着让人放松的神情；夸人不小气，也愿意在别人需要时递上鼓励和支持，像团队里天生的打气者。遇到事情，他们习惯先找可取之处，乐观是底色，整个人经常处在电量充足的状态。在团队中，他们往往是气氛担当和欢乐来源，能把沉闷的场子炒热，也把干劲传给同伴。夸人几乎成了条件反射，因为他们很容易捕捉到旁人的长处。

## 滤镜过重时，容易踩的坑

乐观一旦过量，就容易把现实中的风险与阻碍看轻。面对别人的难过，他们有时共情不到位，也不太能长期陪着低落；看到痛苦，第一反应是赶紧把人拉出情绪，可有些人需要先沉一沉、缓一缓，才能自己走出来。还有，如果夸人成了统一话术，不看对象也不分场合，对方可能会觉得这是套路式表扬，缺少真心。

## 用对了，会成为怎样的力量

这份感染力很强，能让身边的人感到日常多了亮色。他们热情足、精力旺，当旁人卡在原地或不敢迈步时，他们乐观的那一面常能递上一份继续向前的勇气。他们也擅长看见并肯定别人，把正向反馈和继续行动的力量送到对方心里。

积极才干最动人的地方，不是永远开心，而是能把光递给别人；同时也要记得，允许阴影存在，赞美落到具体处，这份光才会更暖、更可信。
