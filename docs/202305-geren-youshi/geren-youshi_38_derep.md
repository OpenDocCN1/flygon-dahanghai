# 十五、有底气的人，敢为选择买单

拥有“自信才干”的人，往往不用刻意证明什么，就能让人感到一种稳定的底气。他们清楚自己的长处，也相信自己的能力：该提要求时敢开口，该冒险时不退缩，面对新挑战愿意接住，并且有把握把事情推进到位。对自己的判断，他们通常相当笃定，也愿意为判断带来的风险与结果负责。

这种底气更像心底的一根定海针。他们认定了方向和决定，就不容易被外界噪音带偏；像船体的龙骨一样，能扛住压力、稳住航向，在风浪里继续向前。与此同时，他们不喜欢被条条框框捆住，也反感别人替自己下定义，希望能拥有充分的自主空间。

不过，当自主需求过强时，盲点也会冒出来：可能显得不服管、爱走自己的路，甚至有些特立独行；一旦拍板，容易变得固执，对旁人的提醒和劝告接纳度偏低。

如果这份才干被用对地方，它会变成很强的优势。这样的人高度信任自己的直觉，面对挑战不轻易退场，能够成为很能带路的角色。哪怕前路艰难，他们也会持续开拓，把信心带给同伴，并在关键时刻主动扛事。
