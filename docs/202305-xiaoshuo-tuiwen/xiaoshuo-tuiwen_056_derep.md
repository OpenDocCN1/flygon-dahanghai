# 3.3.3.1 账号资料这样设

先弄清账号要满足什么需求，再围绕目标逐项打磨资料项：头像、名称、简介、背景图，以及性别、年龄、学校与地区。

1）头像：和定位同频
头像最好与账号定位保持一致。做甜文推广，可以用清晰的小女孩图片或动漫女性角色；做虐文内容，则更适合黑白动漫头像。

2）名称：好记又有辨识度
名字要辨识度高、容易记住，还要带点趣味。能加上专业身份标签就更好，辨识度和可信度都会更强。别堆复杂符号，也别用生僻的特殊表达；直接拿小说男、女主角的名字来用也未尝不可。

起名可套用四种组合方式：
• 昵称后接个性特征，像“大鹅的七七八八”；
• 昵称搭配所在地，如“姚老板在北京”；
• 昵称结合专业方向，比如“跟着拆哥看房”，放到小说号可写成“跟着文哥读小说”；
• 昵称承载价值主张，例如“阿鱼爱学习”，小说号则可用“阿木爱小说”。

3）简介：说清你是谁、能给什么
简介要交代自己的身份、在做的事，以及能为读者提供什么价值。把领域、身份等标签融进去，文字简洁，可搭配适量 emoji。比如：
• 我是推书匠，日常不定时安利小说；
• 作为重度小说迷，我每天花 3 小时挑书，就想把每个故事讲好；
• 我们都是书外人，却偏偏爱上书里人。

P.S. 账号定位在简介里写清楚后，别频繁改动，变来变去容易违规。

4）背景图：贴着人设和内容走
只要与人设或内容场景相关，都能拿来当背景图。主打甜文的账号，可选高清风景图或情侣画面。

5）性别、年龄、学校与地区：按需填写
性别填女性，年龄落在 18—28 岁；学校和地区属于选填项，按需补充即可。
