# 方法四：盯榜选书

想给推文选书，不妨先去知乎、番茄这类小说平台翻翻排行榜。比如[《番茄小说热播榜》](https://fanqienovel.com/rank/1?enter_from=menu)，就是一个现成的找书入口。选书时别只盯着热度，更要结合账号定位和受众类型，从榜单里挑出真正匹配的作品。好故事放到别的平台，往往照样能跑出成绩。

按题材找榜也很直接：做爽文方向，可以去起点中文网看排行榜；做言情方向，则到晋江文学城翻榜单，找调性合适的书。

内容参考自《小说推文进阶玩法，精细化运营所带来的稳定出单》《起底小说推文整体逻辑，一个月实操分享》。
