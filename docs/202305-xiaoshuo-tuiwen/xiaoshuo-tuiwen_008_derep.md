# 小说推文怎么起步？

想靠小说推文变现，先把平台和玩法摸清。眼下常见的阵地包括知乎、番茄小说、起点、晋江，以及 UC 浏览器、飞卢、七猫、夸克浏览器、快看、红袖等。各家推广逻辑差别不大，佣金主要来自 CPS 和 CPA 两种模式。

- CPS：指会员开通后的分销返佣，像知乎、最右、书旗小说、UC 故事会等属于这类。
- CPA：则是帮平台拉新，番茄小说、起点、🐧 阅读、夸克浏览器等采用这类。

整个项目可以拆成四步：先挑书，再设关键词（别名），接着发布作品，最后填写回传。

关键词说白了就是平台内的一串搜索口令。同一本小说往往有多个推广者，推广前要给作品设置一个只属于你的搜索词。用户到平台搜这个词，页面会跳出对应小说；凡是经这个口令进入并阅读的人，平台就认作你带来的用户。

回传则像一份合规拉新证明。现在平台普遍要求推广者只能通过在媒体平台发布内容来获客，因此需要提交回传，说明流量不是靠刷量等违规手段拿到的。

推文形式没有固定限制，只要能促使用户前往第三方平台看小说即可。你可以结合各平台特点挑选主阵地，也可以多平台同时铺开，一鱼多吃。零基础起号，更建议从📕入手，优先做知乎、番茄小说这两个平台，内容质量更容易做高，成交也更快。

还有一点：多数小说平台不直接对接达人。想把项目跑通，得找到靠谱的服务商机构。本期航海邀请了圈友@seven 帮忙，通过他的服务商机构「乐推联盟」与小说平台建立对接，具体合作流程看「2.1 合作须知」。

另外，本章还会逐一说明 4 个平台的合作细节：✅知乎 ✅番茄小说 ✅起点 ✅抖音。在「2.8 链接汇总」里，也整理了可能用到的资源链接。推广对应平台小说时，记得多留意流程～
