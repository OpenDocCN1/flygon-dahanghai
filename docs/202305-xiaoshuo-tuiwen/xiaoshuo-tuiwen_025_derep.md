# 方法二：牵手乐推联盟，推广更省力

想借助服务商把推广跑得更顺？可以看看这种合作方式。它的合作流程和知乎「2.4.1 如何申请推广合作」相近，这里就不再重复展开；小说链接的获取办法，与方法一完全一致。

至于关键词申请怎么走，请参考「2.3 平台使用流程」。提交之前，先把下面几条要求确认清楚：

**关键词规则**
- 字数限定在3～8个字；
- 标点、数字等特殊符号都不能出现；
- 漫画内容只能推广指定书单内的作品，并且更新比例最高30%。

**提审与审核**
- 提审时段为周一至周六11:00、16:00，周日不处理；
- 审核结果在对应审核点结束后的30分钟内查询。

**有效期与回传**
- 关键词可用6个月，到期后原来的词案还能再次申请；
- 每条发布的可追踪期限是28天；若28天内没有回传新的发布，系统将不再拉取相关数据；
- 一个统计周期为上周五至本周四；
- 作品当天发布，需在当天24:00前提交回传，发布完马上回传同样可以；
- 订单拉新数据在每周二更新，数据区间为「上上周五至上周四」。例如4月25日更新的是4月14日到4月20日的拉新情况。
