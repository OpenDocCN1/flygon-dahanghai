# 2.2 小说平台怎么选？

小说推广可选的平台不少，常见的有知乎、番茄小说、起点、晋江、UC浏览器、飞卢、七猫、夸克浏览器、快看、红袖等，各家侧重点并不一样。先看各平台能提供什么：

- 知乎：内容质量在线，适合养号，后面会单独展开说。
- 番茄小说：字节系产品，资源倾斜明显，主推力度大。
- 抖音短故事：抖音自家阵地，合规顾虑相对少，转化表现不错。
- QQ阅读：阅文旗下排名第一的小说应用。
- 起点：同样属于阅文系小说应用。
- 书旗、UC：能提供热门书目，合作单价较高，对拉新有帮助。
- 最右：内容质量不错，适合养号。
- 夸克：全网小说基本都能搜到，耽美品类也齐全。

其中知乎的差异比较明显：平台上中篇和短篇作品更多，新手操作门槛低一些；推文体量在目前属于头部，出现爆款的概率更高。

其他平台则有不少相似点：作品以中长篇为主，小说开头往往要大幅调整，不太容易快速上手；不过视频一旦跑起来，就能持续更新内容。免费阅读模式也让读者接受度更高。关键词并非永久有效，比如番茄小说的有效期是六个月，到期后要重新提交审核。

多数人做小说推广，第一步会选知乎；如果还有余力，也可以同时布局其他平台，按自己的节奏量力而行。
