# 8.3.3 批量投放开通指南

想解锁批量投放？操作入口在创作者服务中心：先点上热门，再进入账号信息，找到个人权益升级并完成升级，随后即可进行批量投放。

不过，如果你做的是长视频，投放策略要收一收：建议一次只投一集，不要选择批量投放，单集试投更合适。
