# 3.1 平台怎么选？@seven

做小说推文，其实不用把自己限制在某个平台里。抖音、小红书、快手这些渠道，都能成为入口；同一套内容还能多平台铺开，把“一鱼多吃”真正跑起来。

若只看转化效率，抖音眼下是排头兵，其他平台还很难追上。快手更容易把流量做起来，但转化端偏弱。小红书的内容数据同样能打，用户黏性也高。所以这轮航海，我们会把重心放在抖音和小红书的起号与内容制作上，带大家把小说推广完整跑一遍。

等抖音、小红书跑顺了，若还想试水快手等渠道，只需把已验证的方法搬过去，再按平台特点略作调整即可。

内容来源：《起底小说推文整体逻辑，一个月实操分享》
