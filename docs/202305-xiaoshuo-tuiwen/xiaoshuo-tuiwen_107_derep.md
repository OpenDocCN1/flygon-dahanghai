# 7.2.2 热评区巧引导

别只顾着埋头发内容，评论区的热度同样值得盯紧。有些留言本身就带话题性，容易招来围观和回复；而用户点进评论区后，视线往往也会先落到这些高互动内容上。正好可以借大家爱看热闹、爱参与的心理，在热门评论下方用“关键词+表情包”做引导。除此之外，还能用一个小号以普通路人的身份出现，在评论区留下引导性的话，让互动显得更自然。
