# 新手做副业，不妨从小说推文试起

大家好，欢迎来到这次分享。接下来我们会有不少机会在这里碰面。

不少刚接触副业的人，第一步往往想找一个投入不高、能尽快开始的项目，小说推文正好符合这个思路。

所谓小说推文，就是在抖音、小红书等平台发布小说类视频，把用户引到小说平台去看书。它上手门槛不高，对新手比较友好，不需要多强的技术能力，只要持续发布符合规范的推广视频，收益就能慢慢积累起来。

目前这个项目主要有两条变现路径：一是让用户到小说平台充值消费；二是引导用户下载小说平台，并搜索你推荐的作品，完成拉新。说到底，就是把公域流量导入小说平台，再从中获得平台佣金。

平台方面，眼下比较建议优先考虑抖音和小红书。抖音的算法机制更成熟，转化效果突出，更适合进阶玩家；小红书女性用户集中，对小说内容需求旺盛，规则相对简单，反馈也来得更快。所以这次的手册里，专门补充了小红书的操作玩法。

哪些人更适合做小说推文？✅平时看网络小说、熟悉网络表达的人；✅每天能抽出两小时做副业的人；✅自控力较强、能在短时间内熟悉小说内容的人；✅执行力强、能长期稳定输出作品的人。

如果你也想在抖音、小红书拿到一些结果，小说推广确实值得试一次。

不过，想确保自己拿到应得收益，执行中的每个对接环节都不能马虎。比如申请关键词后要确认是否通过，视频链接要按时回填，才能保障后续结算……具体怎么做，我们在「二、选择适合的小说平台」里会展开说明。大家一定要留意对接步骤和时间节点～

过去航海中，有不少爆款图文视频本来有机会出单，却因为评论区引导没跟上而错过了。所以实操时记得及时回复评论、多做引导，别让爆款流量白白溜走。怎样更安全地进行评论引导？这部分会在「七、评论维护与引导」中详细讲。

小说推文门槛相对低，入门不难，但想进阶并不轻松。若希望长期获得正反馈，就要投入更多精力，更主动，也更有耐心。

另外很关键的一点是：多问、多交流。这里解决不了的问题，不妨多提出来，我们一起找更多解法。
