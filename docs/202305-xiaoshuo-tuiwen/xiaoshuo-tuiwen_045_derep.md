# 3.2.1.2 账号注册的关键提醒

准备注册账号时，手机号最好用新办理的。同一家运营商，个人最多能开5张卡，移动、联通、电信三家加起来就是15张。移动的“和多号”和联通的“沃小号”不太建议使用，存在一定的封号风险；其实15张实体卡已经够用了。

注册过程中，有几个细节值得留意：

- 新卡启用后别急着注册，先拿它打几个电话、发几条短信、用掉一点流量，让号码看起来更“正常”，降低触发风控的概率。
- 注册时尽量做到一部手机只登一个号，不建议用双开应用来操作。
- 新账号刚建好，不必马上做实名认证；等后期账号开始起量后，再根据情况选择是否实名。
- 如果手机之前登录过被封的抖音号，最好先刷机，然后再注册新账号。
- 批量注册的话，要控制同一WiFi下连接的账号数量，或者干脆用手机流量来注册，避免被风控盯上。
