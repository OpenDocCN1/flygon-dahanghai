# 第四步：视频剪辑入门

小说推文对剪辑的门槛并不高，你只需具备最基础的视频处理能力就行。如果还不太熟悉剪辑操作，可以看这份参考教程：[《如何剪辑视频和制作视频模板》](https://shengcaiyoushu01.feishu.cn/docx/doxcnA72uVU4Aq4TYuApGrPLaxb)

做剪辑时，有四个底线要守住：配音必须流畅，不能出现卡顿；画面素材要精致，且不能重复使用；字幕要跟得上，不留空白间隙；内容导向要正面，绝不能触碰违规红线。除了这些基本功，还要懂得“求新”——不光文章要追热点，素材也得跟紧新鲜度。越新奇的点子、越少见的故事，越能吸引娱乐平台上的用户目光。
