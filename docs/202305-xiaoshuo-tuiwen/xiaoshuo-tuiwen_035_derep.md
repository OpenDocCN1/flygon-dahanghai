# 2.7.5 挂锚点前必看的几条提醒

打 3 月 13 日开始，单条视频所挂的锚点会持续有效、不设期限，不再按固定周期结算；打款和数据反馈的节奏跟“番茄小说”对齐。

报名走问卷，按天登记达人资料：粉丝规模、发布账号、对应抖音账号及其 uid、did。工作日（周一到周五）每天 16:00 截止收集，当天 20:00 之后，已提交账号的「故事」这一标签预计就能点亮。

挑书有两个入口：在抖音端直接挂，或者进入[达人选书库](https://bytedance.feishu.cn/sheets/shtcndcoSv3hTWu8CiR1MEDkNRe?from=from_copylink)检索。

这里要特别提醒：作品里必须安排提醒观众点开锚点的口播、字幕或贴纸之类的小提示。少了这一步，播放量再漂亮，也大概率拿不到钱。

作品一发出，锚点就随之启动，但平台会对作品和所挂书籍做匹配校验，也就是大家常说的“货对版”。一旦内容跟所挂书籍对不上，锚点会被摘除，且不能再次挂回，收入也就跟着泡汤。

要是锚点莫名不见了，记得第一时间找对接同学处理。

另外，提交的发布账号和回款账户务必核对无误，不然锚点和回款都可能落空。

还有一点：别把“位置”与“标签”一起挂。系统会优先识别位置，锚点会被它顶掉。
