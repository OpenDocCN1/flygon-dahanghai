# 8.4 运营技巧三：追热点别只盯着热点宝 @小千

追抖音热点，很多人的第一反应是打开热点宝这类数据平台。但实际操作中还有另一种更直接的方式：把账号刷垂直。关注足够多的对标账号，再靠“推荐”页去捕捉最新热点。

两种路径对比一下：一种是借助热点宝等数据平台；另一种是刷垂直度、刷推荐流。我更推荐第二种。理由是热点宝的收录并不完整，不少还在时效期内的爆款作品根本没被抓取到；而抖音的推荐算法本身很强，新热点往往会被快速分发和迭代。

具体怎么执行？

先参考「3.2.2 寻找对标账号」，找到一批同类型账号并关注。然后去主页看他们的作品和点赞情况。一个账号不用看太多，挑主页上的 1-2 条作品，但一定要从头看到尾。基本上关注六七个对标账号之后，推荐页就会开始出现相关内容。

刷到相关内容时，别急着划走。耐心看完，或者至少看一半。点赞评不评论不重要，真正关键的是阅读时长。

当你的账号被刷得足够垂直，你才会意识到之前错过了多少追爆款的机会。我们选爆款有个标准：3 天前的作品基本不考虑。如果连 3 天内的爆款都没刷到，那只能说明一个问题——你刷得还不够多。

最后给个参考线：3 天内点赞超过 5000 的作品，都值得跟。

内容来源：3 月 3 日《从零开始，如何在抖音上做小说推文？》@小千
