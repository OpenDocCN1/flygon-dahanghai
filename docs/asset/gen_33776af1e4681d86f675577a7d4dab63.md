# 亚马逊新品前90天：备货如何不断货、少压货？

先报个名字：蓝噗噗。

2019年下半年，我开始做亚马逊，从零基础起步，三个月后能独立运营产品；到第六个月，已经比较熟练地把产品推上BS。2020年，产品撞上疫情红利，销量一路走高，后来全部产品都逐步稳在BS前10以内，其中3到4款常驻BS前5，日常占据BS1，月销约140万美元。

加入生财之后，我回头复盘这段经历。那次小幸运让我意识到：能从大品牌长期垄断的类目里借势突围、拿下BS1，稳定且持续的库存供给是重要原因之一。

这套思路适合三种场景：新品阶段销量还看不清时；产品进入成长期、销量有起伏时；想把产品做成偏爆款、瞄准BS10时。
