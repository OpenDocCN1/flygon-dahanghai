# 1.3 📕内容推荐机制

# 1.3.1 笔记审核机制

笔记发布后，平台会先经过一轮“黑盒审核”。系统根据规则（具体规则可参考📕官方账号“薯管家”）检查笔记里有没有敏感词、违规词，以及图片质量是否过低。

如果被系统检测出违规，笔记会直接审核失败，无法获得曝光。还有一些内容机器无法准确判断，会被标记为疑似违规，再进入人工审核。这类没通过的笔记，就相当于被关进“小黑屋”，表现就是限流——别人在个人主页看不到你的这条笔记。你可以尝试把笔记分享到🛰️等平台，看看是不是被限流了。

正常情况下，黑盒审核只需几分钟到十几分钟；但如果刚好碰上发布高峰，审核时间变长，可能说明正在走人工审核流程。

# 1.3.2 笔记推送机制

审核通过后，系统会根据笔记初始获得的点赞、收藏、评论、转发和转粉数据来打分，其中评论、转发和转粉的权重更高。

与此同时，算法会把发布的内容做拆分，目的是给内容分类、打上兴趣标签，并收录关键词。

这里需要提到📕两个最核心的流量入口：【推荐流量】和【搜索流量】。

1）推荐流量

推荐流量会把你的笔记推送给粉丝和其他用户的信息流。📕内部有一套评分公式：

CSS = 点赞数（1分）+ 收藏数（1分）+ 评论数（4分）+ 关注数（8分）

这个公式是衡量互动量和转化率的关键指标，计算结果会持续影响首页推荐频率。当笔记分数越来越高，系统就会一级级把你推进更大的流量池，最终成为爆文（小爆款互动量1000+，大爆款10000+，不同类目会有差异）。

所以，笔记发布后前100个精准用户的点击和互动非常重要，发布后18-24小时内的互动数据，也会决定后续能拿到多少流量。

成为爆文后，还会带动账号其他笔记的数据一起上涨，不过需要满足几个前提：

① 笔记没有违规、没有被系统删除，也没被你自己删除或隐藏；  
② 笔记里有关键词（比如穿搭、衬衫），能对应垂直标签，能被系统识别并收录，推给对应目标人群；  
③ 内容质量本身足够好，能吸引用户点赞、收藏、评论。

特别提醒：0基础新手很难第一篇笔记就成大爆款。运营7-15天时，笔记小眼睛（阅读量）停在200-1000都是正常的。80%的新手要到第二或第三个月才开始爆发，中间是酝酿期，不用太焦虑，耐心把内容磨好。

2）搜索流量

📕用户除了逛信息流，还会通过搜索找内容。想买口红时会搜“口红攻略”，想出门旅行时会搜“旅游攻略”。搜索结果里排名靠前的笔记，能获得明显更多的曝光和关注。这部分流量几乎占到平台总流量的50%以上，不能忽视。

想要拿到搜索流量，笔记里首先要有关键词，并且被系统成功收录；想让排名更靠前，账号权重和笔记权重都要持续提升。

# 1.3.3 笔记权重

📕的笔记权重，可以归纳成三点：

1. 原创度：原创度低于60%时，权重会下降，还可能被限流。  
2. 转化率：转化率是笔记曝光率和互动率的比值。互动行为的权重排序是：转发＞评论＞收藏＞点赞。  
3. 内容：内容方面有两个重点。第一，关键词标签要和内容本身强相关；如果关联度太低，可能被认定为恶意引流，从而降低权重。

# 1.3.4 笔记排名机制

笔记排名，就是用户搜索某个关键词后，笔记在搜索结果页的展示顺序。排名越靠前，被点击的概率就越高。

聊排名之前，先得知道一个词——收录。收录是搜索引擎把笔记内容抓取并存入数据库的过程。通常审核通过的笔记都会被收录，但下面这些情况可能导致无法收录：

1. 账号问题：账号多次违规后，整个账号受到限制，笔记也会无法被收录。  
2. 抄袭问题：笔记被系统识别为高重复率或非原创，将不被平台支持。  
3. 营销问题：笔记里出现大量广告或营销词汇，会被当成推广内容。  
4. 多次修改：每一次修改都会触发重新审核，改来改去容易导致失去收录资格。

# 2.1.2.1 账号登录

同时操作2个账号，能不能用1部手机登录？可以，但有风险。

如果你的手机本身带应用分身功能（部分安卓手机有，比如红米），就可以用一部手机登录两个📕号。我自己目前就是这么操作的，账号还没出过问题。

[PRE11]

但如果手机没有这个功能，千万别去下载第三方的分身神器，很容易被封号。这时候还是老老实实再准备一部手机，去闲鱼或者拼多多买二手机，三四百块钱的就能满足日常使用。

# 2.1.2.2 实名认证

这里要注意：📕实名认证时，一个身份证只能认一个账号。一旦认证成功，只有把账号注销才能解绑。

认证路径：我 → 左上角三条杠 → 创作中心 → 创作服务里的更多服务 → 开通专业号 → 成为专业号 → 选“个人”并点击“立刻申请” → 填写实名认证信息，完成。
