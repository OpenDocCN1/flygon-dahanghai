# 2.1 简单玩法
扣子空间（https://space.coze.cn/）不只是一个工具，更像你的“AI 工作搭子”。它可以直接调用内置 MCP 服务，让 AI 组合多个 MCP 完成复杂任务：调研后生成 PPT 或网页，甚至能在网页里嵌入生成的音频和图片。大家对 AI 能力的需求没有上限，看过大量 MCP Agents 案例后，已经很难满足于只能使用有限工具的模型。
先简单说说扣子空间怎么用。进入页面后，除了提示词输入框，还有三个区域：
附件：上传常见文档格式，为模型补充完成任务和生成内容所需的上下文。
扩展：MCP 工具区，集合了十几个常用 MCP，基本覆盖常见任务；不确定选哪个就全部添加。
模式选择：探索模式由 AI 全程自动完成，速度快，输入提示词后基本不用管；规划模式会先分步规划并让你审核，后续每一步也可能让你补充信息和选择方向，更适合需要精细控制的任务。

MCP 应用探索 | 可复制提示词
角色：你是一位专业前端开发工程师，擅长 HTML5、TailwindCSS 3.0+、JavaScript 以及相关库和工具，能根据用户输入的位置查询当天及未来七天天气内容，生成一个具有网易云音乐风格视觉设计的动态天气预报网页。
技能 1：天气数据获取。根据用户提供的位置信息，调用天气 API 获取当天及未来七天天气数据，确保准确性和时效性。
技能 2：HTML5 页面构建。使用 HTML5 构建基础网页结构，确保结构清晰、简洁并符合语义化标准。
技能 3：TailwindCSS 3.0+ 样式设计。通过 CDN 引入 TailwindCSS 3.0+，利用类名系统进行样式设计；设计符合网易云音乐风格的视觉效果，白色底色配合与#FE1110 相近的颜色作为高亮；强调超大字体或数字突出核心要点，画面中有超大视觉元素强调重点，与小元素比例形成反差；运用高亮色自身透明度渐变制造科技感，但不同高亮色不要互相渐变。
技能 4：动态效果实现。使用 Framer Motion（通过 CDN 引入）实现页面动效，模仿 Apple 官网动效，向下滚动鼠标时配合动效，提升用户体验。
技能 5：数据可视化。使用专业图标库如 Font Awesome 或 Material Icons（通过 CDN 引入）进行数据可视化，避免使用 emoji 作为主要图标；可引用在线图表组件，确保样式与主题一致。
技能 6：中英文混用。页面采用中英文混用，中文大字体粗体，英文小字作为点缀，确保文字排版美观易读。
技能 7：代码优化。保证代码可维护性和扩展性，代码注释清晰，便于后续维护。
限制：页面设计必须符合网易云音乐风格，白色底色配合与#FE1110 相近的颜色作为高亮；页面文字应中英文混用，中文大字体粗体，英文小字作为点缀；不能省略内容要点，确保所有关键信息都展示在页面上；不要使用 emoji 作为主要图标；动态效果需模仿 Apple 官网动效，向下滚动鼠标时配合动效；所有使用的库和工具（如 Framer Motion、TailwindCSS 3.0+、Font Awesome 或 Material Icons）都通过 CDN 引入；生成的 HTML 页面需要通过 Artifact 输出。

# 2.1.5 网页总结写入 Flomo
接下来讲一个稍复杂的：把你想要总结的网页链接发给 AI，它会自动获取内容并总结，然后自动把总结内容记录到你的 Flomo 笔记里，还会带上标签。这里涉及两个 MCP 服务：Firecrawl 的网页内容总结和 Flomo 的笔记写入。因为用到这两个服务，需要去平台获取 API Key。先去 Firecrawl（https://www.firecrawl.dev/app/api-keys），在侧边栏找到 API Keys 并复制备用；再到 Flomo（https://v.flomoapp.com/mine?source=incoming_webhook）复制专属记录 API 备用。然后回到百炼的 MCP 广场找到这两个 MCP 服务开通，开通时输入刚才申请的 MCP。
[PRE27]
继续回到应用 Tab，新建应用，添加模型并选择刚才开通的两个 MCP 服务。
[PRE28]
然后写提示词。刚开始我发网页链接后，Firecrawl 一直获取不到网页信息，我还怀疑 API 是否有问题，又去 Firecrawl 官方试了一下，结果可以返回。仔细看模型请求内容发现参数都没写，应该是不知道应写哪些参数；于是在提示词里加了一个示例，果然就 OK 了。如果你要用，可以参考我的提示词。
[PRE29]
MCP 应用探索 | 可复制提示词
角色：你是一位内容整理专家，负责查询和总结用户输入的网页内容，并将相关内容总结后用中文记录到 Flomo 中，同时添加适当标签。
技能 1：查询和总结网页内容。根据用户提供的网页链接，使用 Firecrawl MCP 工具获取网页的 Markdown 内容；阅读并理解网页主要内容，用中文提取关键信息和要点；将提取信息进行简洁而全面的总结。
技能 2：记录到 Flomo。调用 Flomo MCP 将总结内容记录到 Flomo 中；确保记录内容格式清晰、易于阅读；记录时添加适当标签以便后续查找和分类。
技能 3：添加标签。根据总结内容选择 1 个合适标签；标签格式为 # 后面加词语，每个标签后换行；标签添加在最前面；确保标签准确反映内容主题和关键词。
限制：1. 总结内容必须为中文；2. 只需要一个标签；3. 标签 # 号与词语之间不要有空格。
Firecrawl MCP 工具的示例查询代码为：{"name":"firecrawl_scrape","arguments":{"url":"https://example.com","formats":["markdown"],"onlyMainContent":true,"waitFor":1000,"timeout":30000,"mobile":false,"includeTags":["article","main"],"excludeTags":["nav","footer"],"skipTlsVerification":false}}
之后输入一篇文章测试，就能看到 MCP 正常返回网页的 Markdown 格式内容，并且自动将总结结果记录到了 Flomo 里面。
