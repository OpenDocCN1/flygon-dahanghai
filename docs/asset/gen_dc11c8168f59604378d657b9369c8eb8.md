**6. 各类 Agent 的关注重点不一样**

不同类型的 Agent，关注的重点会有所不同。

可以对照你的 Agent 属于哪一类，重点补充对应的信息。

**6.1 文档型 Agent**

（内容创作、会议纪要、报告生成等）重点关注：

• 输入材料的读取顺序和优先级；

• 输出格式、风格、长度等规范；

• 内容质量检查标准（如事实核查、格式检查、是否遗漏关键信息）；

• 引用来源、敏感内容等处理规则。

**6.2 表格型 Agent**

（数据整理、报表汇总、信息统计等）重点关注：

• 字段之间的映射关系；

• 数据更新规则（新增、覆盖还是合并）；

• 缺失值、重复值、异常值如何处理；

• 哪些情况需要报警或人工确认。

**6.3 消息型 Agent**

（客服回复、通知推送、私聊助手等）重点关注：

• 什么事件触发执行；

• 回复边界（哪些能答、哪些不能答）；

• 不同场景的回复策略；

• 哪些情况必须暂停并转人工处理。

**6.4 流程自动化 Agent**

（审批、文件流转、多工具协同等）重点关注：

• 每一步调用哪个工具；

• 工具失败后的重试策略；

• 上下游数据如何传递；

• 哪些步骤必须等待结果，哪些可以并行执行；

• 中断后如何恢复执行。

每个 Agent 都有自己的特点，可能兼具多个类型的部分特点。没有一套规则适用于所有场景。

根据你的实际业务不断完善这份工作流，比一开始追求面面俱到更重要。
