# 2.1.2 收购公司，先看这几条

想收一家现成公司，别急着签。先按下面几项筛一遍，能省不少后续麻烦。

**公司名称怎么选**：优先盯住“商贸、网络、科技、电子商务”这类字样；像“教育、建筑、物流”这种跟业务不搭的行业公司，尽量避开。

**必须满足的硬条件**：公司注册时间要满一年；注册资本填50万元，认缴即可；经营范围可参照下方模板；名称则尽量做变更。这里提醒一句：除“注册满一年”外，其余资质要求都能在工商行政审批大厅通过变更办到。

**经营范围模板**：一般项目：互联网销售（除销售需要许可的商品）；服装服饰零售；化妆品零售；家用电器销售；电子产品销售；家居用品销售；服装服饰批发；日用百货销售；汽车装饰用品销售；箱包销售；日用木制品销售；鞋帽批发；鞋帽零售；美发饰品销售；五金产品批发；化妆品批发；五金产品零售；信息咨询服务（不含许可类信息咨询服务）；工艺美术品及收藏品零售（象牙及其制品除外）；玩具销售；母婴用品销售；体育用品及器材零售；针纺织品销售；眼镜销售（不含隐形眼镜）；钟表销售；珠宝首饰零售；礼品花卉销售；食用农产品零售；广告设计、代理；家政服务；广告发布（非广播电台、电视台、报刊出版单位）；摄像及视频制作服务；摄影扩印服务；个人商务服务；宠物食品及用品零售；灯具销售；乐器零售；家具销售；人工智能硬件销售。（除依法须经批准的项目外，凭营业执照依法自主开展经营活动）；食品销售（仅销售预包装食品）

**公司类型怎么定**：金税四期已经上线，后续对企业合规经营的监管只会更严。依法纳税是每个公民应尽的义务，而合理避税也是草根创业者必须掌握的技能之一。这次航海不涉及财税专题，就不展开讲，大家直接选“小规模”即可。具体政策可以问当地财税三方，也就是代记账公司。

1）推荐：小规模。有免税额度，普票等其他票据可抵，100万以下无票按2.5%。
2）不推荐：一般纳税人。资金进入公户就涉及13%的税，而且必须用专票抵扣。
