# 3.3.3.2 按爆款样本做视频内容

情形一：手里没有实物，只能靠网络素材做二次创作，这时要注意降低素材重复度。

❗想避开违规，最好不要从平台站内找素材，尤其是百货类。现在平台上的很多素材其实来自抖音：一方面，被频繁使用的素材画质差；另一方面，也更容易被系统判定重复。

去抖音找素材的3个办法：

1. 直接搜产品关键字，看相关视频；
2. 打开创意中心，找到爆品后拉到页面底部，有“关联达人秀”；
3. 搜到带这款产品的博主，进入主页看看还有没有更多素材。

1.

混剪视频

1）找视频素材

素材可以从抖音或平台站内收集热门视频做记录，通常是3:4或9:16画幅；

2）混剪降重

降重手段主要有：换背景音乐、切分片段、加转场、叠加画中画等。

具体的混剪手法，可以参考文档《如何剪辑视频和制作剪辑模板》。

2.

做封面

视频封面直接用爆款的封面，但图片要先降重再放上去。

3.

拟题目

把5个参考视频的题目都记下来，按前文【章节3.3.2.2】里的爆款题目重合法来拟。

如果还想学更细的剪辑，可以看【6月航海手册 - 3.2.4 第四步：进行混剪】。

# 3.3.5 发帖避坑要点

电商号的内容尽量围绕商品来做，这样引来的流量才够精准。行业知识科普、避雷类内容也可以，流量相对精准。跟商品无关的东西尽量别发，流量再大也很难转化。

电商要的是能成交的流量，不能转化的流量再多都是白搭。

有些帖子只有几百浏览量，照样能成交，因为流量足够精准。

1）博眼球

比如市面上有些所谓的“种草标题模板”，真的，这对于开店的人没有任何营养价值。

[PRE21]

就像“朋友来我家吃饭，居然说我家里寒碜”，点进去却满桌好菜、豪宅亮堂。用户只会觉得你在骗他，把他骗进来是为了秀优越，从而反感这篇内容。

再比如“SOS，快来种草这个无广的国货！”，结果点进去是天天打广告的某护肤品牌，观众会极其不适。

2）调性混乱，定位不清

爆款标题模板、吸睛标题，得先搞清楚适合什么内容。平台上的店铺变现、引流变现、IP变现，最好不要混着来。

很多账号今天发生活日常，明天发挂车帖；封面一会儿纯色底大字，一会儿自拍，一会儿四宫格对比，一会儿又是毫无特色的产品图……什么类型都有，关键是封面还不美观，显得很low。

# 4.1 筛选供货方要看哪些条件？

选合作商，主要看四个维度：

1.

价格

供货价和我们的售价之间，要留出足够的利润空间（30%以上）。如果商家价格太高，和同行比没有优势，转化率会受影响。

2.

款式与质量

款式、质量可以让商家发图确认，或自己买样品来检查质量，选出品质过关的商品，为长期合作打底。

3.

单量大能不能走ERP

单量到100+时，可以走ERP系统，发货效率更高，不用自己重新导单下单。商家直接在ERP里看到订单，直接打单发货，省去中间环节，还能避免系统判定店铺无货源，同时也能打印📕面单。

我们一般用店铺管理工具关联商家的店铺ERP，下面是操作步骤：

（A店=商家店铺，B店=自己的店铺）

第一步：先用店铺管理工具登录B店（子店铺），点“关联店铺”，复制关联代码。

[PRE26]

第二步：让商家登录店铺管理工具，打开A店的“关联店铺”，点“立即关联”，选择关联平台，粘贴B店的关联代码，完成添加。

[PRE27]

第三步：关联成功后，A店能看到B店的订单数量，商家可直接打📕面单发货。

[PRE28]

4.

能不能走手工单，不走第三方平台面单

前期单量少，可以不接ERP，但一定要和商家确认能打手工单，避免被平台识别成无货源，保证店铺安全。

当然，去询价前可以表明自己是长期做电商的，手里还有好几家店铺，这样商家更愿意合作，也会觉得你是正经下单的人，而不是问问就不买的。
