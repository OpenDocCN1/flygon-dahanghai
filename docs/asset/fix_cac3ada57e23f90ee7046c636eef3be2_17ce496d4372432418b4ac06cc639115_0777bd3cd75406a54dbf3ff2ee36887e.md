# 美团门店运营：先算投产，再谈放量

从展位逻辑看，信息流“智选”不是所有店都该开。满足两类情形才值得投入：一是套餐本身具备冲动消费属性，像抖音团购里那些容易即兴下单的爆款；二是门店确实要扩大品牌声量。智选属于信息流竞价，单次点击常见在1—2元，相比用户目的明确的搜索流量，投产比并不占优。手里没有能打的引流款，别急着开智选。它的长处是能圈定更多用户属性，相比推广通，人群筛选更细，找目标客群更准。

单图位展示门店图，多图位则露出门店首图前三张。由此可拆出影响点击的八项：星级、金银铜牌、自荐语、系统词条、团购名与价格、距离、客单价、销量。其中前五项是门店能主动优化的。

### 1、星级评分
分数只跟优质点评量有关，五星好评以及系统认定的优质评论，对评分拉动明显。所以不少代运营的大量精力其实花在评论维护上。要注意：用户最好先有同类门店的搜索行为，再到店消费并核销；否则点评量一多，容易触发风控，反而带来负面。我们手上有达人资源，会安排达人线上下单并完成评价，因此评分起得较快。另一个办法是引导顾客在大众点评打卡。直接索要好评不合规，打卡收藏却没问题，所以不少店在做打卡活动；收藏量上去，评分提高，平台会倾向认为门店质量不错。
[PRE9]

### 2、金银铜牌等级
[PRE10] 等级规则不复杂，按后台清单把该设置的项补齐，就能先拿到基础50分。[PRE11] 关键在流量与交易表现，这与交易额、门店访客数直接相关。所以尽量让顾客线上成交，别为了省20%服务费改走线下；该给平台的费用有时就是“入场券”，不然平台很难判断你是优质商户并持续分配流量。只要推广稳定在开，访客项加10分并不难，银牌压力不大；金牌则可能要靠智选再推一把。[PRE12]

### 3、自荐语
[PRE13] 这块没有太多花样，找到编辑入口，把最有说服力的卖点填进去即可。

### 4、系统词条
这一项较难左右，但并非完全无能为力。如果能较多影响评论内容，高频出现的词就会被系统抓取成词条，挂在门店下方。

### 5、团购名与价格
名称里放“全国金奖”“杭州首发”“招牌”等词，看似平常，却能在用户心里形成轻微暗示；虽是自卖自夸，仍有一定效果。

### 6、榜单进入
美团休闲娱乐榜单分“销量榜”和“人气榜”。销量榜按过去180天商户销量排序，销量够高就能进，不看评价等其他条件，所以可以通过人工方式较快冲进去。团单设计上，可加低价团单拉销量。案例1：增加特价饮料兑换团单，用醒目KT板贴在冰箱门上，鼓励顾客购买，每账号限购3瓶。[PRE14] 案例2：设置单人体验活动，可先临时上线，进销量榜后再视情况决定是否下架。[PRE15] 人气榜按过去7天商户热度排序，提升思路可参考冲金牌的方法。[PRE16]

## 第四步 提高点击后的成交意愿

最后这部分最关键：曝光靠投放，点击靠首图，这两步可操作空间相对有限；用户点进来后愿不愿意成交，才是门店优化真正的核心。顾客在意的点并不复杂：环境怎么样、剧本类型合不合口味、评价如何、预期时段有没有正在拼的场次（拼车），或者有没有空场可开（车头）。当环境、剧本、评价这些基础项大家都做得不差时（做得太差的早被淘汰），亮点怎么呈现就变得格外重要。装修好看、演绎不错、评价一致，打开美团前十家店基本都这样；这些不会成为用户选你的理由，但没有它们，用户会把你筛掉。基础建设完善后，最要紧的是提炼差异点与亮点，并在装修各处做强引导、强曝光。详情页描述、门店照片布置、优质评论布局，如果只停留在“好看”，门店只是过了第一关，进入备选池；真正推动用户下决定并成交的点，才是页面设计要反复传达的。

### 3.2.5 避坑点 @怡伶 78667：三类雷区，越早绕开越省钱

雷区1：套餐没吸引力，一上来就砸钱。最初上架的是油画体验类产品，早期访客每天只有30—40。急了乱投医，听大众工作人员建议充值开推广通，平均每小时烧掉不少预算，前后花了一万多，转化率几乎为0；来的要么不是精准客，要么对产品没兴趣。复盘看，套餐不吸引、店铺初期评分又低时，砸多少钱都难见效。大众是帮用户找好吃好喝好玩好去处的平台，也提供优惠套餐和活动价；用户主要比谁价格低、哪家好评多。上架产品没吸引力，运营动作再多也难有客户。雷区2：好评差评要维护。大众用户做消费决策前会看评分。我起初没太管，因为基本在私域或到店成交，也没让顾客写点评。生意火起来后，同行来恶意差评，平台帮忙拦截过几次，但评分仍明显下滑，影响店铺形象，接下来得靠运营手段优化。雷区3：图片太精致反而劝退。小红书对艺术类精致度要求高，图片要高颜值；大众更需要真实用户体验封面，过于精致美好容易被当成广告。发大众的图尽量不修，保留真实感，文案软一点、客观一些，更有机会爆。内容来源：《千粉不到月入10W，我如何通过小红书救回濒临倒闭的艺术体验门店？》

## 3.3 同城流量从哪里来

### 3.3.1 线上同城流量怎么抓
线下门店消费受地域限制，主要流量还是来自周边或本地，因此同城群、活动平台等更聚焦本地流量的渠道，很值得用。常见的线上同城获客方式有：✅客户朋友圈：从老用户的朋友圈里找新用户；✅本地生活群：企微群、QQ群、豆瓣群组等，比如快递群、团购群、连锁店群；✅本地公众号：类似杭州美食、联联周边游杭州站等；✅同城活动平台：豆瓣、QQ、本地生活团购平台等。按自身需要挑合适的平台引流。
[PRE21]

#### 3.3.1.1 让老客发朋友圈 @乔合、@Mage
很多获客方式最后都能落到朋友圈转发上，这也是比较好用的一种宣传方式；但硬要求客户转发，容易引起抗拒。通常两种做法：第一，客户预订时想要优惠，就事先谈好——所有人转发朋友圈12小时且不屏蔽，给优惠打折，直接省事；第二，每场给客户拍短视频记录，最后带上宣传二维码。运营数据显示：平台用户忠诚度不高、选择多，私域效果最好，平均复购率可达10—15%（指二次复购），部分喜欢风格的客人来过3次以上。也可找网红到店打卡，发朋友圈加定位。内容来源：《从亏损8000到盈收3W+，轰趴别墅通过精细化运营实现转介绍率70%》、《00后实体店创业者：用互联网思维破局疫情影响》
[PRE22]

#### 3.3.1.2 本地社群推广 @乔合、@封伟-自动化变现、@尹基跃
最多的是企微群、QQ群、豆瓣群组，找到后进去引流。重点说开放式的同城微信群，可直接找到并100%进群。常见有：银行（招商银行等）、出行平台（高德、滴滴等）、连锁门店（瑞幸、唯品会等）、本地生活（罗森、哈罗等）、商超（沃尔玛、永辉等）、商场公众号、社区团购（美团等）、快递驿站、餐厅点餐码（有些会设置关注进群）、业主群等，按用户画像找社群。如何一个码加多个群：企微群多用活码，用多个号多次扫码会扫出不同当地群，获得群数量远大于二维码数量。举例：滴滴同城群、瑞幸同城群、永辉同城群。

#### 3.3.1.3 本地公众号投放 @芷蓝
新店可用这招做冷启动。以我的舞蹈室为例：在望京开店，就在微信公众号搜【望京】，找几家本地自媒体，看文章阅读率，平均能到3000—5000以上，说明粉丝质量还可以。然后设置新店活动，比如开业大礼包：199元=10节课+新人大礼包（水杯、舞蹈鞋、速干毛巾等）。注意：新店启动不建议加裂变机制，容易招羊毛党；你需要快速积累第一批学员的上课素材和成功案例，再发到大众点评，所以用户精准度和质量很重要。精准用户是想学跳舞的人，不是来拿礼品的人；不要搞免费领取，一定要付费。推广费用看头条还是次条，像我的舞蹈室推一次头条约4500元。投放时注意：①和本地媒体沟通时，问清是否给相同定位商家做过推广、效果如何，最好有达到率或后台转化率数据；②索取公众号后台用户画像，按性别、地域等判断是否适合本行业；③投放时间尽量选周二到周四晚上8—10点，最大概率触达用户。内容来源：《门店私域运营 | 小航海学习手册》

### 3.3.2 线下同城流量的入口
多数实体店的主要客流来自周围3—5公里，这部分人更容易到店体验和消费，所以线下引流不能轻视。线下获客常见有：✅线下海报张贴；✅和其他商家异业合作；✅发传单；✅找代理分销。下面看具体操作。
[PRE32]

#### 3.3.2.1 地面海报张贴 @Mage
在距离周边0—8公里的写字楼楼下/高校张贴海报，一般和老板谈100—150元/3个月。好位置一周能被动添加3—5人，主动扫码添加的用户意向度较高。再根据添加客户位置优化，好位置继续续费。内容来源：《从亏损8000到盈收3W+，轰趴别墅通过精细化运营实现转介绍率70%》
[PRE33]
[PRE34]

#### 3.3.2.2 商户联盟合作 @芷蓝、@乔合、@尹基跃
联盟合作分同业联盟和异业联盟。异业联盟：联合不同业态商家设计一张权益卡，对外销售98元/张，可包含洗车店几次免费洗车、家政公司几次免费擦玻璃、餐饮门店折扣、教培体验课等，合计价值大几千，所有给优惠的门店都会帮忙导流。参加商家先付费5000元采购权益卡（有优惠，可给120张卡），只要推出去就能回本，所有商家有推广动力。好处是可在一个城市快速引爆全城；不好处是需要联合足够多商家才能跑起来。同业联盟：主要针对教培行业，不同品牌联合，如篮球、油画、音乐等细分品类各出引流套餐课程。比如联合20家机构，联盟卡对外298元/张，可任选5家机构课程，家长能以最低成本试错，给孩子多报几家。找商家时直接在大众点评按位置搜索，合作要找业务不冲突但消费人群一致的商家。沟通时注意：①在大众点评查看商家星级及最近半年产品销售量，判断客流量；②选择用户画像一致但产品服务不同的商家，比如我的舞蹈室消费者是20—35岁女性，她们也有美甲美睫、咖啡西点需求；③第一次沟通说明工作室就在附近，最好邀请商家来查看，必要时赠送自己的服务或产品，保证合作顺利。若找不到多个商家合作，还有两种方式：方式一，互换商品体验券——互换体验券放在自己门店，客户消费就搭赠一张；简单，但无法监督和捆绑利益。方式二，固定合作伙伴——找2—3家固定伙伴，制作类似【29.9元=美甲一次+中国舞体验课一次+xxx】的通券，用户会觉得更有价值感。
