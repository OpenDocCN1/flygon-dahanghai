常见问题解答和注意事项

# 1. 飞书权限开通与凭证获取

在飞书开放平台开通多维表格权限，并拿到 app id 和 app secret。

步骤一：登录飞书开放平台 https://open.feishu.cn/app?lang=zh-CN，创建企业自建应用。

[PRE10]

填写应用名称和应用描述，点击“创建”。

[PRE11]

在“基础信息-凭证与基础信息”中获取应用凭证 app id 和 app secret，复制下来保存到文件，后面会用到。

[PRE12]

在“开发配置-权限管理”中点击开通权限。

[PRE13]

在打开的页面里先开通应用身份权限 tenant_access_token；下滑左侧菜单找到“多维表格”，在权限名称前打勾，全部勾选，然后点右下方确认开通权限。

[PRE14]

按同样方式，把用户身份权限 user_access_token 的多维表格权限也全部开通。

1. 发布飞书应用

在“应用发布”-“版本管理与发布”中，填写应用版本号（需符合 1.0.0 的样式）和更新说明，点击保存，确认发布。会弹出此次发布免审确认窗口，点确认即发布成功。

[PRE15]

# 3. 新建多维表格并获取关键参数

在飞书云文档主页选择云盘，然后在云盘里新建一个多维表格。

注意：一定要在云盘里新建多维表格，这样地址格式才是 https://f7vsb1brbs.feishu.cn/base/S7JqbAzy7aO5dLsAQehchmLyngf?table=tbl6l8zc0BHSgIkY&view=vewgb3vMSP 这种。云盘建的多维表格链接第二节是 base，务必注意。如果从飞书文档主页新建，链接第二节是 wiki，对接方式会不一样。所以务必保证链接第二节是 base。

[PRE16]

通过多维表格地址，还能得到两个重要参数：app token 和 table id。以上面的地址为例：

https://f7vsb1brbs.feishu.cn/base/S7JqbAzy7aO5dLsAQehchmLyngf?table=tbl6l8zc0BHSgIkY&view=vewgb3vMSP

App token 就是 S7JqbAzy7aO5dLsAQehchmLyngf，截取第三节到？号前的一串字符。

Table id 就是 tbl6l8zc0BHSgIkY，截取 table= 后面直到 &view 前面的一串字符。

至此拿到四个重要信息：

app id：飞书开放后台“凭证与基础信息”中获取

app secret：飞书开放后台“凭证与基础信息”中获取

app token：多维表格地址中获取

table id：多维表格地址中获取

# 4. 给多维表格添加应用

在这个多维表格中，点击右上角...符号，依次选择“更多”-“添加文档应用”。

[PRE17]

如果第二步发布应用成功，在弹出的对话框里搜索应用名字即可找到，选择添加，确保应用具备“可编辑”权限。这样应用才能访问多维表格，并往里传数据。

[PRE18]

[PRE19]

# 5. 安装篡改猴并写入脚本

打开 Chrome 应用商店（https://chromewebstore.google.com/），需魔法才能访问。搜索 tampermonkey，安装此扩展程序，添加至 Chrome。

【更新】没有魔法上网的圈友可以下载这个本地版后，把文件直接拖到 Chrome 插件管理页面 chrome://extensions/ 中。

[PRE20]

tampermonkey_stable.crx

Tampermonkey 是一款 Chrome 浏览器插件，用于管理和运行用户自定义脚本，实现网页自动化和功能增强。

[PRE21]

[PRE22]

添加成功后，可以把篡改猴插件固定在浏览器上，方便查找和操作。

[PRE23]

需要打开篡改猴执行脚本的权限：点击扩展程序-篡改猴旁边的三个点-管理扩展程序，打开“允许用户运行脚本”的开关。

[PRE24]

点击篡改猴插件，选择添加新脚本。

在脚本编辑页面清空原有信息，保持空白，并粘贴对应脚本代码到编辑器中。这段代码的作用是在某个小红书账号的主页增加一个采集按钮，点击按钮就能采集该账号信息，并以 JSON 方式呈现（代码是 AI 写的，正常可直接用；若存在问题，可以贴给 AI 修改完善）。Ctrl+S 保存后退出。
