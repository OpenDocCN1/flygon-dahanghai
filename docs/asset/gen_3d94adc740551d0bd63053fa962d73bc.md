# 3.1 胜算高的产品方向，需过三关 @刘小排

在我看来，一个产品构想想要大幅提高跑通概率，至少得同时满足三条：第一，背后存在真实需求；第二，你在这个赛道足够专业，哪怕正面竞争，也有把握比同行做得更出色；第三，你能长期扛住，尤其在起步阶段迟迟收不到正反馈的时候。

沿着这三条，我梳理出五种寻找产品方向的做法。按我的个人判断，它们的成功概率依次降低：

1）原生 idea ★★★★★

2）参考已经跑通的竞品，再做出差异化价值 ★★★★

3）拆解搜索关键词，定位仍未被满足的需求 ★★★

4）先有客户愿意预付费用请你定制某项需求，随后把这项定制能力产品化 ★★★

5）硬憋出来的 idea ★
