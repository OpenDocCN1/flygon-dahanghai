# 三、竞品调查

# 💡

本章导读：为何要研究同行？

在小红书靠资料变现，有一条朴素法则：谁已经跑通，就向谁看齐。

因此，研究同行的目的很明确：找出谁的产品卖得动、卖点是什么、流量入口在哪、成交环节又是怎样设计的。

在锁定模仿对象之前，先定一个主推品。它可以是付费资料包，也可以是和机构联合开发的视频课。若做小学方向，主推付费资料更合适；若做考公考研，则更适合选机构合作课程。

# 3.1 如何拆解一百位同行

挑选参考对象时，优先找与自己条件接近、稍微努力一把就能追上的账号。

所谓条件接近，指业务链条相似：卖的是付费资料，获客靠小红书，最终在微信里完成交易。

所谓稍微努力就能追上，就是选择处在自己学习区里的动作。人的能力圈可以分为舒适区、学习区和恐慌区。假如你从未做过图文，第一次不妨用资料截图加贴纸的形式，只需掌握截图和贴纸；不必一上来就追求复杂背景、耗时数小时的高原创图文。

分析同行并不需要花哨技巧。认真拆够一百个样本，账号主页如何布置、微信端成交话术怎么设计，基本就能摸清。

[PRE3]

样本拆完后，接着要核算收益。做生意先算亏盈，若连账都没算清就开干，一旦亏了很难收场。

怎样估算一位同行的营收？可以观察其朋友圈群成员截图，或快团团的成交方式。假设对方快团团每天约有十人下单，客单价五十元，那么日销售额就是五百元。虚拟资料几乎没有边际成本，因此这五百元基本可视为日利润。

用同样方法推算一批同行的利润，再做正态分布。例如两成同行月入十万，六成月入一万，另两成月入五千。

把同行的账算明白后，自己下场大概率能做到月入一万。若你在学习或执行上本就属于前百分之二十，月入十万也并非没有可能。

随后从调研表里挑出前十名，照着他们的路径走，甚至可以一比一复刻：小红书昵称头像、微信头像昵称，乃至朋友圈内容，都可以先模仿再优化。

3. 第三，拆分目标：产品、流量、转化三个环节要串成完整链路，并延伸到交付与售后，形成闭环。

# 4.1.2 养号方法

哪些情况需要养号？
- 刚注册的新号；
- 被平台警告过，例如禁言24小时、3天、7天，或权重被降低的号；
- 注册已久、准备开始发笔记的老号。

1）养号第一天
1. 注册完成后，确保一机一卡一号。若批量起号，超过三个账号时，每个账号注册间隔至少四小时。
2. 注册时选择兴趣内容，要与自己的赛道相关。比如做小学教师资料，就选育儿、学习类。
3. 其他设置先不动，进入首页刷推荐内容，自然浏览，适度点赞、评论、收藏，避开敏感内容。
4. 像平时刷抖音、B站那样，累计刷一个半小时以上，可分段也可连续。第一天把自己当成普通用户，点开的笔记要看完，再适度互动。

⚠️ 重点提醒：注册时务必用流量，别连无线网。否则多个账号共用一个IP，容易被判定为营销号，流量起不来。我们团队的工作机从不连WiFi，还会偶尔带出门使用，尽量表现得像正常手机。

2）养号第二天
5. 确定账号定位，完善头像和昵称。
6. 延续前一天的操作，在首页和同城页刷推荐内容两小时以上，自然浏览，适度互动，不碰敏感内容。

3）养号第三天
7. 在搜索框输入同领域关键词。做小学教师资料，可搜“小学一年级语文”“新手班主任”“小学班主任”；做绝版书，可搜“书籍推荐”“古书推荐”“绝版书”；做小吃配方，可搜“配方分享”“摆摊小吃配方”“各种小吃技术配方”。早、中、晚各刷三十分钟。优先关注粉丝量大的账号，多点赞收藏互动，后续更容易获得系统推荐。
8. 继续浏览同领域对标内容，早中晚各三十分钟，不要刷得太快。
9. 也可以在小红书买点东西，比如搜“9.9r一箱”找些便宜又不错的水果。购买行为能增强账号真实感、提升权重，不做也不影响。

4）养号第四天
10. 继续看同领域账号和笔记，早中晚各三十分钟，节奏放慢。
11. 按人设修改签名，切记别留联系方式。
12. 提前编辑好次日要发的图文。养号结束后的一个月内尽量每天更新，保证内容质量，更利于系统推荐。

5）发布首篇笔记
发布后连续三到五天保持浏览作品的动作，每天一小时。

⚠️ 注意：发布后别频繁点开自己的作品，也不要过度解读数据。

在小红书养号、提升权重并争取更多流量，可关注以下要点：

1. 注册初期别急着完善资料，只填性别、年龄和兴趣领域。头像、简介等可等到发布前一天再改。
2. 养号周期通常至少三到五天，有些领域要十天到半个月。我们这个方向养三到四天即可，不要拖过一周。
3. 坚持一卡一机一号。一个账号对应独立手机号和设备，不要在同一台手机切换账号，也别在同一局域网登录多个号，以免触发风控限流。
4. 每天至少活跃三十分钟，时间分散，模仿正常用户，避免集中操作。
5. 互动量要适度。比如每天点赞不超过五个，收藏五到十个，评论不超过六条，关注两到五个，保持自然节奏。
6. 浏览内容要贴合账号定位，提升垂直度，便于平台推荐更精准。
7. 养号过程中，可在第三或第四天完善昵称、头像、背景、简介等资料，让账号更专业、更贴合定位。
8. 不要参与互粉互赞群或刷量，这类行为会被视为恶意营销，可能导致账号受限。
9. 养号期间不必急着发内容。开始发布后要保证质量与定位一致，每天一到三篇，可带定位增强真实感。
10. 熟悉并遵守小红书社区规范和运营规则，不发违禁内容、不用违禁词，确保账号安全。
