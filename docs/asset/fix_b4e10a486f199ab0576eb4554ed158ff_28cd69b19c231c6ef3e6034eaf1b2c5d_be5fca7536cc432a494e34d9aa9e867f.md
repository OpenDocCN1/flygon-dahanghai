# 10.4 场地管理

1. 起步阶段：办公室能省则省

很多年轻人东拼西凑几十万，事情没做成，钱却花在了办公室上。办公室再好看也不是自己的，而且好看和业绩没有关系。创业初期省钱才是王道，别为了面子。把钱花在搞流量上，才是最重要的。建议先改造自己家、租居民楼或商业公寓，用最低成本运作起来，只要一条网线就能开干。

2. 业务起量后再考虑写字楼

找写字楼怎么避免踩坑？

1. 办公楼租赁按月计费，但一般至少签1年，也不能长签3年以上，业主通常不会同意，或者会要求一定幅度递增。价格常见“包票”和“净到手”两种：包票是租金里已含租赁税发票，净到手是不含。要问：起租期多长？租金含不含税？增长幅度多少？

2. 还有管理费（物业费，按每平方米每月算），要主动问。行业里20元以下的多数没有中央空调，或者中央空调费另计；20元以上的多为中央空调。管理费通常包含公共部分水电维修保养、清洁卫生等。要问：物业费多少？是否含空调费用？电费多少一度？网络费一个月或一年多少？联合办公的租金一般包含物业费、水电费等所有费用。

5. 每栋写字楼的中央空调开放时间不一样，很多有时间限制和月份限制。极少24小时供应，大部分只在上班时间供应（多为8:30-18:30），加班可能要付加班空调费。少部分可以自己装独立空调，如需加班或不想用中央空调，可以问能否安装独立空调。要问：空调时长多少？能否自己调控？能否安装独立空调？

6. 互联网公司经常通宵，但写字楼内不可以住宿（有商务公寓的除外），也不可以明火煮食，微波炉可以用。也有复式写字楼可以居住或商住两用，这些都可以主动问。要问：是否能住人？

7. 停车场怎么收费也要了解，老板和员工一般办月卡，主要问月卡多少钱一个月。承租面积大的客户，有送1-2个免费停车位，记得争取（个人业主除外）。要问：停车费一个月或一年多少？按年有没有优惠？临停多少一小时？日封顶多少钱？

8. 如果是毛坯办公楼，记得向业主要免租期，1-3个月不等，具体看面积和装修风格需要的时间，可以商议。哪怕是带装修的，也会有1周左右免租期，搬办公室也需要时间。要问：免租期多长？

9. 租赁期递增：租期超过一年以上，一般会有不同程度递增，通常从第二或第三年开始月租金递增5%-8%，个别大厦连管理费也一起递增。要问：租金涨幅多少？

10. 合同签订：以上都了解清楚并谈妥后，预约时间签合同。要弄清楚是跟业主签，还是跟二房东公司签。一般来说，大业主和二房东都比较好说话，很多事情可以找他们帮忙。要问：你们是大业主、二房东还是小业主？

11. 办公楼租赁还有定金环节。很多情况不允许直接签合同，下定金是最好的折衷办法。一般定金下了以后，业主反悔需要双倍返还。

签约前把下面18项问清：

1. 最短租期多久？
2. 租金开票吗？
3. 每年涨幅多少？
4. 物业管理费多少？
5. 空调费是否另收？
6. 每度电单价多少？
7. 宽带月费或年费多少？
8. 空调供应时段多长？
9. 温度或开关能否自行调节？
10. 能否加装独立空调？
11. 可否住人？
12. 车位月费或年费多少？
13. 年付有无折扣？
14. 临时停车单价多少？
15. 每日停车封顶多少？
16. 结算方式怎么定？
17. 装修免租期多久？
18. 签约方是业主、二房东还是小业主？

# 十一、投流放大：先算账再花钱

虚拟店铺投流主要看两个入口：乘风更偏成交，适合商品推广、直播预热、笔记加热；聚光更偏信息流和搜索触达，适合种草和后续收集客咨。投流有成本，不是必修，预算足、有经验再试。

# 11.1 乘风

乘风在2024年9月开放全量公测，早期产品较粗，像把聚光的电商投放模块拆出来单做，效果不理想。根子在小红书电商成交体量小，用户电商行为少、数据积累不足、人群画像不细，所以转化一般。2025年比初版有改善，但仍不算亮眼。等平台电商成交做到抖音的十分之一，乘风效果可能才明显。新手不必急着投。

# 11.2 聚光

# 11.2.1 先算投放成本

投聚光前先算投入产出比。想拿到私信豁免，日耗要过100元，且投流第三天起才生效，并要持续投放。以小学资料为例，期末阶段转化率20%-30%，按20%、客单49元算：每天来15个咨询，15×0.2×49=147元，高于100元日耗；来100个，100×0.2×49-100=880元。要不要投，取决于内容制作和引流能力。投放可直接发微信，免费流量会折损、吞微信吞图，100人问可能只来20-30；用聚光私信通自动发微信，100人问可来80-100。按此，小学资料在不封号前提下，免费流量每天能来6人以上，开聚光大概率回本。这个账要按自己客单和转化率算。聚光的信息流投放适合高客单，获客几十元一人；我们做小学教辅虚拟资料，主要拿私信豁免，信息流不必太关注。

# 11.2.2 投放渠道

官方渠道要求5000元起充，可以找官方渠道：小红书聚光平台。

# 11.2.3 投放门槛

做聚光投放需要蓝V号，也就是说要注册一个个体户营业执照，然后花600元开通蓝V，才可以投放。个人账户现在做不了聚光投放。做小学教辅，需要办理出版物经营许可证，认证图书号，出版物经营许可证在淘宝上办理大约1800元。成本大家自己核算，有预算的伙伴可以尝试。

# 11.2.4 私信通开通条件

针对做引流的人，这个功能最大的帮助是：消费者打开与你的私信对话框后，会自动弹出一段话，这段话可以设置为你的微信，比如“这里发不了电子版资料，加我微信：xxxx”。这个需要消耗满1000元，然后每周二会自动开通，叫私信通。

# 11.2.5 投放策略

一个广告账户只能绑定一个蓝V账户，也就是说其他矩阵账号获得不了私信豁免。我们可以做1个广告账号，矩阵操作几个普通号，比如5个普通号，在这些普通号的简介上填：需要资料@（蓝V号）。这些矩阵号不回复任何私信，不评论任何评论区，只在个性简介处写一句“需要资料的找@（蓝V号）”，这样能把投聚光的蓝V号最大化利用。
