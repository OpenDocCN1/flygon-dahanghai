# 3月赚到3.4万，我悟出10条赚钱心法

我叫咏舍，在设计行业做了十三年，如今自己带项目、做自媒体。

2022年，我花了一整年测试自媒体。成绩算不上炸裂，但把内容付费从获客到交付完整走了一遍，也让我重新理解“钱到底是怎么来的”。

那一年，我在公司被裁。心里很拧巴：一边想回职场，一边又羡慕那些能把赚钱模式跑起来的人。市场偏冷，年龄也不占优势，合适的机会并不多。

四月，我参加大航海直播，开始做内容付费：写稿、开播、找定位。期间也拿过一些亮点——👸号阅读冲到自己历史峰值，📕单篇破十万，被平台转载，也接受过媒体访问。但变现方向始终没找准。

当时我以为，全网一万多关注，卖点东西总不至于太难。结果连9.9元的引流品都难转化，我很受挫。课程定价也不敢往上走，带过11位学员，交付疲惫，效果也一般。两个月后，我收手，回公司上班。

复盘下去年卡在三处：一是把自己关起来，指望死磕就能翻盘；二是没弄清真正想要什么，动作里全是焦躁和内耗；三是对自身价值低估，配得感弱，总觉得知识不值钱。

2023年，我第二次启程，把主要精力押在0到1自媒体创业。三月总营收3.4万，已经高过之前公司主业的到手工资。走到这里，我更加笃定当初的选择。

职场上升空间已经到顶，拖下去没有更优解，迟早要面对终局。认清现实、尽早把心力投到目标上，才能更早拿到结果，接住趋势带来的机会。

突破卡点的关键是花钱学习、投资自己。每天吸收的新信息，不断冲击旧认知。那阵子我精力旺盛，学习密度很高，但学完无处释放，于是把沉寂数年的粉丝群重新盘活，每日分享、每日输出，连续六十多天。

一开始没想清怎么变现、做什么产品，只知道脑里东西太满，必须倒出来。两个多月后，群从140人增至340人，知识星球从240人涨到900人。

状态和能量起来后，吸引的私教客户也高能，行动力强。有位学员一个月通过内容付费做到两万营收。

我更加确信：输出时若对方感到你不是只盯着钱包，而是真心想帮忙，再加上你亲自做过，诚意会被看见，信任会累积。

三月能起量，我归为五条：一，花钱换到更优秀的圈子；二，抬高自我价值感与势能，先让自己变好，成交自然顺；三，只分享亲自做过并验证的内容；四，把服务做给喜欢自己的人；五，用价格筛客户，不靠低价冲量。

下面，是我从这段经历里拆出的10点思考。

**1、圈子会悄悄改写你**

《富爸爸穷爸爸》点破一件事：家境普通的人可能忙一辈子、拼命挣钱，收获仍有限；家境优渥的人就算不精明，也更容易拿到赢家剧本。

我以前也做过不少表面功夫：刻意改想法、刻意做动作。可认知没真正翻新，只是数量堆高。真正的开关在潜意识。

工薪家庭的孩子，从小被长辈念叨“找份工作、好好打工”。至于为什么打工、这一生要做什么，很多人没细想。富人家庭的孩子则很少把打工当默认选项，他们更早琢磨怎样放大价值、怎样买别人的时间。

关于钱，贫穷家庭也会传递限制性念头：“你赚不到一百万”“日子难，要省”“这事太难”。你月薪五千，周围聊的多是五千的事；进了每月十万的圈子，大家谈商业模式，旧念头就开始松动。

赚钱难的根子，在于潜意识束缚行为。表面再拼，也未必有实质改变。要紧的是拆掉限制，把“我做不到”改成“我可以做到”。路径是：先看见，再意识到，最后相信自己能办到。

在龙哥盟，很多人从零到一拿到第一桶金，做出第一个百万，做到每月十万。身处这样的环境，潜意识会被重写。归根结底，圈子会悄悄改写你。

**2、学习在找答案，赚钱在交方案**

不少人总说还在学，却迟迟拿不出结果。学习更像弄懂某个知识点，把知识体系越堆越大；若不能融会贯通、拿去实践，它只是多一条信息。

比如，三十五岁上下、岗位偏基础的设计师，公司为什么会请他们走？学习型思路是列原因：压缩成本、提高效率；工作重复、容易被替换；投入产出不划算……像做1+1=？核心在答对题。

赚钱型思路则是交方案：这类设计师离开公司后，路在哪？答案是挖核心优势，用流量放大个人价值，转化目标客户，做到一定营收。这个方案就是产品：有人群、有需求、能收钱。

可落地的商业路径是：先找用户需求，再按需求做产品或服务；随后找到有支付能力的目标人群并让他们知道；最后完成成交，形成收入。

**3、动作再多，也要看结果**

普通人常拿战术勤快遮住战略懒惰。努力只是动作，动作不自动变成结果。有人低效勤奋：没目标地堆量，日复一日硬扛，迷信大力出奇迹。

普通路径是：行动—坚持—拼数量。商人世界只认一个检验：赚到多少钱。检验努力的不是数量，而是数据结果，比如百万、千万。

更优的做法是循环：先试水拿初步反馈；再复盘为什么不够好，列出原因并优化、补内容，拿新一轮结果；然后继续复盘—优化—结果。一轮不行，就再走行动、反思、学习、优化、验证，直到结果达标。

努力没换来钱，常见症结在执行效率，或者一开始路就选错了。

**4、认知有围墙，收入就有上限**

常听一句：人赚不到超出认知的钱。认知是什么？是你所在圈层、经历与经验塑造出的判断和行动。圈层会框住认知。

多数人在行当里待太久，思维会固化。设计师多属技能执行层，很多人只琢磨技法、创意、视觉冲击，却少想作品只是商业链条的一环：给谁看？要达成什么？怎样帮卖货？

所以设计师在职场最直接的跃迁，是从执行层往管理走。视野抬升，高度才抬升。

打工赚钱和创业赚钱是两套思路。想提高创业赚钱能力，得跳出打工人视角，进入商人圈子，按商人方式想：卖什么、卖给谁、怎样增利、怎样降本提效。

提升认知，需要把原有圈子撬开一道缝，离开舒适区，向外接触信息，再用行动改掉旧习惯。

**5、机会先被看见，才会被抓住**

赚钱并非越来越难，而是没找到入口。机会散落在各处。世界比想象大，许多未知领域哪怕旁观学习，也能收获不少。

为什么要开眼？因为见识会变成判断力。对赚钱信息接触足够多，敏感度会起来；信息、思考、结果积累久了，会沉淀成经验直觉，提高成功概率。

像老司机遇前方追尾，经历多、见得多，大脑形成条件反射，能更快控制风险。

拓宽信息入口：多拆赚钱案例，看底层逻辑；多认识做出结果的人，观察他们怎么想、怎么做；进入更会赚钱的圈子，尽量跟有结果的人学。

**6、普通人可用的杠杆：圈层差**

赚钱常见三条路：靠信息差、靠资源、靠技术。多数普通人缺本金、缺背景、缺亮眼身份和光环，最顺手的便是信息差。它不是抄近道，而是让不同圈层的需求与价值流动起来。

所以信息差的底色是圈层差。A圈里习以为常的东西，换到B圈可能正好有人需要；把两边接通，价值就流动了。

设计师的视觉审美，在设计圈很常见；到了自媒体博主圈，很多人懂内容营销，却缺视觉美感。博主圈便有需求：怎样让内容更有质感、提升播放？怎样做高赞封面模板、提高产出效率？跨圈价值就这样流通。

**7、想快见效，别怕为高价值买单**

很多人把赚钱想复杂了。一层是自信不足，老想埋头积累，时间成本巨大；另一层是认知与能力不够。

比如有人只顾自己讲得爽，对真实需求迟钝；有人关起门来自己琢磨，方向早偏。2022年的我就困在狭小世界里，踩了致命变现坑：不学习、不向专业者求助，只凭旧认知硬解问题，结果越陷越深。

同一个道理，由高势能、真付费的人讲出来，你才掂得出分量。这也是为什么常说：别免费做内容、别卖低价，太容易得到的东西不被珍惜。

跟有结果的人付费学习，好处明确：少交试错学费；时间花在刀刃上；方向更笃定；对方验证过模式，你相信可成便能先动起来；过程中有人反馈，一轮轮优化，效率更高。

**8、越难被替代，越有定价权**

可口可乐配方曾被视为绝密，如今早不算秘密。个人IP也一样，知识和课程随处可得，盗版一堆。真正值钱的是这个IP的势能、资源与关系，这些别人拿不走。

越独特越珍贵；同质化竞品一多，价格就往下掉。2022年楼市降温，不代表所有房子难卖。稀缺房源依旧抢手，万柳书院的房子，有钱人排着队也未必买得到。

如今买房的逻辑看地段、楼盘品质、户型、物业、楼层、学区、资源、圈层等；这些条件同时凑齐极难，价值空间自然高。

商业市场同理，要尽量把自己的稀缺性做高，价格空间才会打开。职场也是，能力与技能越少人具备，不可替代性越强。

**9、先把价格定住，再倒推产品**

过去我不敢报高价，根子是不自信，总以为先做出厉害课程或产品，才有资格谈价格。这就是“先产品后价格”的误区。

可万一产品卖不动呢？投入的时间精力是不是又要推倒重来？加入龙哥盟航海后，看大家密集输出、频频报喜，我才明白：问题不在价格高低，而在我对迭代执行、优化调整理解太浅。

先有好价格，才会反过来想：我服务谁？怎样提供溢价？怎样让对方觉得值？以前我总想把九十九元的课卖出一万份，却没想过把一万元产品卖给99人。把99位客户服务透，才是收入增长的关键。

这也是靠谱常说的：去挣有钱人的零花钱，别去动穷人的保命钱。价格不对，动作全错。穷人把花钱看成抠出来、省出来，九十九元也怕被收割；有钱人则想，花出去的钱怎样把价值再放大。所以先定价格，再匹配配得上价格的好产品与优质用户。

**10、赚大钱，要借别人的力放大时间**

一个人不可能包办整条生产链，也不可能把每处细节都亲自做完。有积累或代表作后，要学会把其他环节交给别人。

比如联合他人做更大的产品，借力站上更大的舞台。关键前提是：自己在某个领域足够深，而其他方面没精力也没能力兼顾。

用户到一千人，客服忙不过来，就该找助手、付费请人补位。流量触到自己的上限，就要借更大平台或更强的人曝光；先提供自己的价值，再让对方推你一把，完成更大的目标。

回头看，收入增长靠的不是把力气越使越大，而是换环境、换看法、换打法。愿这些经历给你一点参考。
