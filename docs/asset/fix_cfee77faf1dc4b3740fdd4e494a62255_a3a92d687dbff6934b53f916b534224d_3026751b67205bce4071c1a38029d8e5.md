# 社恐单兵做小程序：从首月六千到峰值百万

> 先自我介绍：郭东超，i人，口头表达一般，大家听得出。没有技术背景，也没有团队，产品自己磨，销售自己跑。去年8月，我上线了一款练表达的小程序；半年时间，运营收入从首月6000元做到2月突破100万元，付费用户接近3万。
>
> 双仔和秀儿两个月前邀我分享，我起初想逃——平时不爱见人。理性劝我突破一下，别被“i人”标签困住。少年时上台朗诵，我脸红、身子抖，脚趾也抖。一周前稿子写完，秀儿评价“离上台还差90%”，我急得怕拖累大家，又花20小时反复改。今天站到这里，算我新的起点。
>
> 接下来，我把做流量的整条路径拆开讲，希望能给你一点参考。

## 一、道：为什么做这件事

### 1.1 需求先来自自己

这款小程序的起点，不是追风口，也不是研究赛道，而是我自己确实需要提升表达。市面上的工具我翻了不少，始终没遇到一款既合心意、又能让我轻松坚持的。这个念头压了很久，技术却一直把我挡在门外。去年4月，我报了刘小白老师的AIP课程，学会用AI搭产品，才终于把想法落地。当时我没做市场验证，只觉得先解决自己的问题。后来有次刷小红书，看到英语学习资料帖下面大量留言在求资料、说“想要”，我凭直觉判断：这款小程序可能机会很大。

### 1.2 只看两层：有没有人需要、愿不愿意行动

判断时我没搞复杂数据，只盯两层。第一层看需求面：帖子下那么多人求资料，说明想学的人群很大，他们希望从帖子里直接拿到方案。第二层看行动面：光有资料不够。以我自己的体会，资料囤着也学不进去；学习本来就反人性，得有个产品把门槛降下来，让人愿意轻松学。两层叠在一起，结论很清楚：不做资料仓库，而做一款“把资料装进去、让用户学得轻松”的产品。这就是初心。

### 1.3 先做分享者，别急着卖

冷启动时，最重要的转变是角色。上线头十天，几乎没什么流量反馈，只卖出两三单2.9元体验会员，还挨了骂：“你这款水平有什么用？我去买本书不一样吗？”我一度怀疑产品不行。后来才想通：我先前照着爆款笔记的标题、封面、结构去仿，发英语资料清单，直接挂产品链接，系统推来的人根本不是目标用户。他们有需求，但看完笔记感受不到产品能帮什么。用户心智不能硬掰，得让产品借笔记去筛人。于是我把自己放回分享者的位置：讲经历、讲困扰、讲怎么解决。推广时不抱着“一定要卖”的念头，而是让用户在内容里照见自己。这个认知一立住，笔记、短视频、直播话术就都顺了。

### 1.4 投流买的是速度，不是订单

不少新手怕投流，总想着投100块就得出单，没出单马上关掉。这个思路不健康，既耗时间，也学不会优化。投流不是拿钱换订单，而是拿钱换速度、换确定性，是长期投资。不投流，一篇笔记可能一个月都没动静，你连往哪调都不知道；投了，后台会给点击率、跑量、转化率这些反馈，优化才有依据。没有数据，就是摸黑走路。我建议先给自己定个“敢亏”目标：今天能接受亏100块不出单，明天能接受亏200块。慢慢找到感觉，理解平台推荐逻辑，再用数据反推内容。比如花200块投流卖出3单，账面像亏；可若不花这200块，笔记一个月没响应，你连优化方向都找不到。

### 1.5 流量冲上来时，先按住产品

2月爆发，单月流水破七位数。我却做了个反直觉决定：3月主动降速。不降，我怕被流量反噬。2月的大流量把产品问题照了出来：小程序一出bug，客服就爆，说明日活不小。这时更该抓产品稳定和迭代，也该抓用户，把客服、运营体系搭起来。若还像2月那样猛追流量，不做这些，反噬一定来。能走长久，靠的就是这一步。3月流量虽一般，卖得其实还可以。

### 1.6 过去摔的跤，都是人力账户存款

大家现在看我站在这儿，好像运营收入能过百万，但过去我也摔过很多跟头，焦虑、失败没少经历。我在生财有术待了6年，参加过很多航海：小红书、小猪店铺、视频号直播带货，数不过来，大多没成。可正是这些经历教会我：写笔记来自小红书航海，投流来自投流航海，分销来自分销航海，私域运营来自私域航海，拍短视频来自视频号航海。单看像散招，生财里都能找到；我把它们一根根串起来，才成了这款产品的完整路径。这些不是临时抱佛脚，是过去在生财焦虑、失败时攒下的能力。就像往人力账户里存钱，先存着；当时没遇到合适机会，一旦机会来了，这些能力就能推着你快速做出大进展。所以，过往没有一段是白走的，成功失败，都是往人力账户里存钱。

## 二、法：怎么思考和决策

### 2.1 小红书点火，抖音放量

现场有多少朋友在做小程序？做完后第一反应是去哪推广？选小红书的举个手——我发现大家第一印象常是小红书。我的看法：小红书负责点火验证。它用户质量高、数据也不差，但体量小，涨得慢；我在小红书花了4个月才到1万用户。产品要真正放量，必须跳出小红书。抖音负责放大规模：我在抖音不到1个月，从几百用户涨到2万多。那里用户盘子大，短视频加直播的组合拳比图文猛得多，生态也成熟，精选联盟、达人分销都完善。所以路径是：先在小红书验证产品、打磨内容方法，方向确认后再去抖音放大。

### 2.2 离用户越近，成交越顺

做抖音时我体会很深：用户越能感到真实的我，越肯掏钱。人天生更信能看到脸的人。图文笔记只有字，冷，信任感最低；短视频能看见表情、语气，信任往上走一层；直播面对面互动，信任最强，转化最高。就像平时说的，能打电话就别只发文字，能视频就别只打电话。这个逻辑决定行动顺序：在抖音要从图文转到真人出镜短视频；短视频爆了，立刻开直播。

### 2.3 三类数据，反推笔记优化

小红书投流会给我三类反馈，我拿它们反过来调笔记。A类，点击率高：标题抓人，用户愿意点，说明标题策略成，但正文或转化可能有问题；方向是保住标题，优化正文和转化路径。B类，曝光高：系统愿意推，量大，但转化可能不高，说明内容合平台逻辑，却不够匹配目标用户；方向是在曝光基础上做精准。C类，转化率高：看的人少，成交却猛，说明内容和需求对得上，但标题没拉来足够点击；方向是借高点击笔记的标题思路，给这类内容换个更好的入口。我把三类笔记都下载，用AI拆各维度表现，再让AI整合出兼具三种优势的笔记。靠这个，店铺ROI做到2.2——12万投流，卖26万。优质笔记长尾也很好，1月、2月有一个月没发新笔记，投放还在跑，每天出单。

## 三、术：具体怎么做

### 3.1 一周做出最小可用版，首页只留一个键

产品一周就搭出来了。看当时的样子很糙，首页只有一个按钮，完全不像成品，但最基础的功能有了：资料能放进去，能学，有数据反馈。我没多想，直接上线小红书验证。基础功能既然有了，再一个人闷头想怎么完善，肯定想不全；不如让小红书给答案。这个阶段不用纠结太多，产品行不行，用户会说话。半年迭代下来，它成了更成熟的软件，每天有不少忠实用户反复使用；可起点，就是那个只有一个按钮的首页。

### 3.2 头十天碰壁，靠原创翻盘

上线头十天，零反馈。我照着常见做法，仿爆款标题、封面、结构，发英语资料清单，直接挂产品。流量惨淡，几乎没转化，只卖出两三单2.9元体验会员，还挨骂。转折点是放弃模仿，改原创。我从产品出发，用场景描绘、痛点共鸣、带出方案的路子写笔记。调整后，出单从零到43单；第30天，第100个付费用户来了。这100人对我很关键。不少用户私信说：“我一直在找这款软件，终于找到了，很喜欢，谢谢你做出来。”正反馈一多，我就判断：这产品肯定有大机会。

### 3.3 三步内容法：先还原情境，再共情，最后摆方案

这套内容结构，我在小红书和抖音都反复验证过。它其实也是富贵老师讲的痛点营销，感兴趣可以去翻富贵老师的帖子，我从中受益不少。第一步，把具体画面还原出来：开头给一个很具体的画面，让用户一秒代入。同一个需求下，每个人经历的场景不同；开头写中他过去经历过的场景，他马上会被吸住。比如我有篇笔记开头是“每次开会轮到我发言，脑子明明有想法，但一上台就一片空白”。这篇在小红书爆了好几条。为什么？很多职场朋友对这个场景有真切体会。这个场景我自己都没料到量这么大，后来在抖音也爆了。评论区有人直接说“和我一模一样”，这就是场景写到位了。第二步，把自己放低去共情：我不说“你有什么痛点，你要这么做”。我讲自己因为什么困扰，做了什么事，用什么方法解决。人天生会对自己经历过、焦虑过的事共情；看到别人也有类似经历，自然冒出一句“他跟我一样”。共情一建立，用户就站到你这边，愿意信这个方法对自己也有用。第三步，亮出自己用过的解法：因为我经历过，自己用什么方法解决了这个困扰。用户的反应是“这个人这么做了，我也想试试”。产品是作为“我的解决方案”出现，不是作为“你该买的东西”出现。用户被带进情绪里，生出“我也想试试”的冲动。核心就一句：让用户在内容里看到自己，而不是看到你的产品。

### 3.4 五个维度交叉，撬出74万种选题

笔记方法有了，但我不想只覆盖职场人，得拓更广人群。于是我做了个五维交叉选题法，用来开笔记方向。一个痛点下面，其实有很多人群、职业、场景都有同样需求；人对跟自己相关的东西特别敏感。全国十几亿人，经历、年龄、情绪各不相同，触发点也落在不同场景。我列了五个维度：人群，如职场人、学生、宝妈、教师、销售；场景，如开会发言、面试、相亲、家长会、述职；痛点表现，如脑子空白、说话结巴、逻辑混乱、紧张发抖；情绪，如焦虑、自卑、愤怒、无奈、羞耻；触发时刻，如被领导批评后、错过升职后、社交场合丢脸后。每个维度下面再列六七种具体选项。今天写笔记，每个维度各挑一个组合；明天换一组，后天再换。光这些维度就能算出74万种组合方向。所以我不愁没内容、没方向，也不用再去模仿别人。

### 3.5 让Claude成批出稿

有了矩阵，我用Claude成批生产内容。操作不复杂：先让Claude把每个维度下尽可能多的具体选项整理出来，放进文档；再让它检查文档里的文件和命名，按组合写笔记，直接以文档形式输出到文件夹。我再去翻、筛、微调，然后发布。一个账号一天发4篇，几个账号加起来一天12篇。12篇发下去，大概二十几天能爆一条，浏览几万到二十几万；一个月能爆15篇左右。小红书我没找到特别好用的自动发布工具，基本靠手动。核心逻辑是：发得越多，筛网铺得越广；哪个人群被触达，就可能爆。不追求篇篇爆，追求覆盖面，用概率取胜。

### 3.6 抖音第9条，播放冲到900万

从小红书转抖音，我起初直接把图文搬过去，流量很一般，起不来。后来我干脆怼脸拍：一台手机、一个提词器，就能开拍。拍了大概10条，第9条爆了——788万播放，现在涨到900多万，还在跑。制作很糙，但内容还是那套：场景引入、痛点共情、带出产品。抖音系统给了个最高评价：“你的视频分享真实的经历和使用方法，让观众愿意花更多时间观看。”“你的视频能引发观众共鸣，比如用什么便捷的工具让大家感觉很有用。”这等于平台替我验证了内容方法。不需要专业设备、精美制作、表演技巧；真实经历、具体场景、真诚分享，就是最好的内容。我以前刚拍短视频很害怕，发一条要重录上百遍；现在无所谓，直接发。这也是6年积累。

### 3.7 半小时开播，单日最高133万

视频爆了，我直觉是：必须马上直播。为什么？视频还在跑量，用户刚看过我，有印象；得趁这波流量去接触。而且直播比短视频信任感再进一步，面对面互动。我没怎么犹豫，半个小时收拾设备，在家里粗糙搭个直播间就开播。没准备直播框架、流程、话术、报数，就是简单分享心得和产品。直播间很简陋，数据却很好。最高单日销售133万；其中短视频带来6万多，直播带来66.7万。那天花了13万广告费，一天卖出2000多个付费会员。

### 3.8 代理佣金给七成，只挑长期做事的人

小红书爆了后，代理陆续找上门。我不是谁都接。很多代理做短期甚至违规虚拟产品，我都拒了；这款产品我想长期做。我收的代理以有互联网经验的宝妈为主，偏长期主义，愿意认真做事。佣金我直接给70%。为什么这么高？这样他们会把事当成自己的事，认真坚持；高佣金也留出了投流空间，花钱投流还有利润。有个宝妈代理，第一个月几乎没出单，但每天坚持发笔记；第二个月突然爆发，一个月带来1500多个付费用户。她还认真维护用户、回答问题，攒下忠实粉丝；粉丝又介绍朋友、组团购买，形成口碑裂变。所以代理不能随便找，要找准人，佣金要狠。引入代理这个阶段，我从几百付费用户涨到8000多。

### 3.9 素人出镜：身边人拍真实使用

为什么做素人打造？我自己就是素人，拍得也不算好，却能拍出900万播放。素人自己用产品、讲痛点，比专业达人更让人感同身受。我拉身边的人——拍过短视频的、做过互联网的，通过公司给佣金；扣掉广告费后还给40%。拍短视频坚持下来不容易，所以我把佣金体系给高些，让他们能每天拍。有个素人一个月带来4万销售额，投流成本只花16000；一条视频爆了14万播放，转化很高，ROI到2.46。视频内容很简单，就是开着视频展示产品怎么用。

### 3.10 达人分销：精选联盟加高佣筛选

抖音达人分销体系成熟。我在精选联盟挂40%佣金，同时筛选一些主动找来的达人，给他们更高佣金。产品爆了后，抖音上确实能遇到不少志同道合的达人；其中两三个达人一天能带来两三百个付费用户。

### 3.11 别漏掉溢出流量

有个容易漏掉的增长点：溢出流量。我很庆幸，小程序上线第二个月就申请了微信虚拟支付。用户不管在小红书还是抖音看到产品，都会自己去微信搜小程序名，然后直接在微信里付费。这些人不经过任何推广渠道。最高峰时，微信小程序每天有300多个用户直接搜索付费；公众号也攒了7000多关注。做抖音后，我发现抖音溢出流量也大。很多抖音用户私信我：“我怎么在抖音搜索不到这款小程序？”我才意识到，之前注意力都放在微信小程序，抖音小程序也该做。你想，我在抖音卖微信小程序，微信端搜索付费都日均300个了，抖音小程序的量可能更大。所以做小程序，一定尽快加虚拟支付，别漏掉溢出流量。这些都是“免费的”——不用额外广告费，用户自己会找过来。

### 3.12 私域是意外之喜

在抖音卖货时，虚拟产品不能直接上架，我就用发货形式卖会员：做一张引导卡片，用户收到实物后扫码使用。这个方式意外带来私域流量。很多用户到货就加微信，最高峰一天两三百人，我手动都加不过来。我会抽时间跟他们聊，解答困惑，真诚讲我为什么做这款产品、我的理念。他们认可我，就主动推荐给身边人，甚至组团购买。不过发货也有缺点：退货率不低——用户知道是软件，却要等三四天才收货，激情一降就退。接下来我在试课程形式附带小程序：先讲使用方法，再开通会员，退货率能低一些。
