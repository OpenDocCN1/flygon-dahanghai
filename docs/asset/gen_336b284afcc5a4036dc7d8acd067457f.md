# 4.1.1 门店个人号：先让顾客记住“人”，再记住店 @尹基跃

门店做个人号，最怕只挂一块“店招牌”。如果头像、昵称都只有门店名，顾客会觉得是在跟一个冷冰冰的店铺对话，心理距离很难拉近。更有效的做法，是把门店和创始人或门店负责人绑在一起经营：顾客先认识一个可信的人，再通过这个人理解门店。下面从形象、人设、话术、互动和标签五个方面拆解。

1. 微信门脸四件套：让头像昵称先有“人味”

个人号是门店在微信里持续触达顾客的阵地，也是顾客观察门店的第一窗口。四件套要围绕“人”来设计。

**头像**：别用单纯的店铺照片或风景照。建议用负责人、创始人的生活照或写真，而且画面里最好能带出产品，比如在农场拍的生活照，让顾客一眼看到你和产品的关系。

**昵称**：只写品牌名，顾客能记住店，却不容易产生需求联想。更推荐“名字+门店”的组合。名字不必是真实姓名，简单好记即可；如果真实姓名已有知名度，也可以继续用。

**个性签名**：把个人发展和门店品牌放在一起表达。比如“北欧慢城创始人，健康餐饮，放心肉食品牌开创者”，一句话交代身份与价值。

**主页背景墙**：这是顾客了解个人号的展示入口，至少要有品牌名称、个人简介和产品照片。

2. 人设定位：先定标签，再定内容

门店个人号也需要像公司、产品一样做定位，也就是人设定位。要明确主标签、副标签，规划朋友圈文案内容以及日常发布内容，让顾客知道你是谁、能提供什么。

3. 加粉与回访话术：让顾客愿意通过、愿意回复

**加微信话术参考**：可以这样表达——您好，我们门店创始人很重视服务与产品品质，所以每张桌子上都放了他的私人微信号。添加创始人微信，可以立即获得 XXX 优惠；他还会邀请您进入门店家人群，以后订餐还有优惠。

**回访跟进话术参考**：您好，感谢您来北欧慢城品尝我们自有农场直供的生鲜肉食品。我是北欧慢城品牌创始人。我们很看重每位用户的体验和真实反馈，每一条意见都是我们进步的动力。想问问您，对餐厅服务和菜品有什么意见或建议吗？

收到反馈后可以继续回复：感谢您的反馈。我们一直专注健康、安全食品的制作，也希望您多了解我们。除了餐饮，或许我还能为您提供其他服务。回复关键字1了解我，回复关键字2了解门店，回复关键字3了解我们的养殖场。

4. 互动与标签：别上来就卖，学会分层

朋友圈互动包括点赞、评论和私信。互动不是机械点赞，也不是逢帖就评论，而要结合对方朋友圈内容，聊他可能感兴趣的话题。不要一上来就推产品。

**标签化管理**：按关键维度给用户分类打标签，帮助判断关系深浅，做精细化运营。以餐饮店为例，可以这样打标：
- 购买：购买1次、购买2次、购买3次以上；
- 未购买：未聊天、未购买；
- 添加好友日期：按月份打标签；
- 用户生日：按月份打标签，具体生日写进备注；
- 用户属性：附近小区、附近写字楼、其他。

根据到店时间标签群发，引导再次到店：
- 未到店用户：重点发新用户到店可享受的服务；
- 未交流用户：尽快沟通反馈；
- 消费过一次的用户：重点向会员转化；
- 已是会员的用户：重点向超级用户、门店大使转化。会员与超级用户的转化，主要靠朋友圈内容，经常发布只有会员才能享受的福利，以及超级用户的高级体验；
- 未到店的新用户：朋友圈多发店内火爆程度和新用户到店优惠活动，并增加评论点赞互动。比如点赞本条朋友圈，将抽取一人送霸王餐，第几人；点赞时可以用小号参与，把霸王餐名额拿走。
