# 5.10.1 案例一：一万个像素头像，开启NFT先河

在NFT的发展历程中，CryptoPunks是一个无法绕开的名字，本身便是一座里程碑。业内普遍将它看作全球首个真正具备系列化意义的NFT项目。打开OpenSea上Punks的展示页，映入眼帘的是一排排像素风小头像。

[PRE0]

2017年6月，这批头像被部署到以太坊上，总量1万枚，全部由不规则的像素图形构成，且每一枚都带有独有属性。项目把头像分成男性、女性、僵尸、猿猴、外星人等不同族群，再依据族群与特征组合出稀缺等级。

因为头顶“历史第一”的光环，Punks在NFT市场备受追逐，持有者常被视为加密圈资深OG。

行情最热时，其地板价一度冲上100枚以太坊；即便系列中最便宜的头像，也要40万美元，折合人民币200余万元。单笔成交最高的CryptoPunk #3100，卖到4200枚以太坊，约1600万美元，人民币接近亿元，价格之高令人惊叹。能拿下这类资产的人，显然非富即贵。

图中编号5822的Punk，就是迄今成交价最高的外星人头像。

[PRE1]

2022年2月12日，这枚Punk以8000枚以太坊易手，价值约2300万美元。而五年前它第一次成交时，价格只有8枚以太坊；若按美元计，涨幅超过14000倍。
