# 群买买谢幕，我复盘了两年

作者：老胡｜2023年4月13日

4月4日，群买买👸号发出一则公告，宣布将分阶段关停群买买的运营服务。走到这一步，这个项目算是正式落下帷幕。

其实早在3月22日，拼多多要关掉群买买的风声就已经在小范围内传开。只是官方没有正式通知我，我也就没有对外发声。那段时间，来问我的团队长和朋友不少，我的回复都一样：等官方通知，我这边不掌握具体情况。

直到3月26日上午，群买买官方运营人员来到杭州，当面告诉我项目即将关停。说实话，我个人并不意外，但对旗下团队长来说，这个消息确实来得太突然，很多人完全没有准备。

从我入局群买买到现在，快两年了。两年里，我们团队累计做了1.5亿元GMV，给旗下团队长发出去的佣金超过2400万元，而我们自己在这个项目上只赚了几百万元，远低于我当初的预期。账面上看，收益接近730万元，但其中有大团队长的收入是由我们代发的，占比超过70%。再扣掉税务成本和人力成本，真正落到我们手里的利润并不多。

这两年发生了太多事，正好借这个机会做一次复盘，也算给过去两年一个交代。也希望这篇文章，能给正在做社交电商平台的创业者、正在参与社交电商的团队长们一些参考，让大家以后少踩坑。先说明一点：本文只从事实出发，尽量客观陈述，不带情绪化表达，也不做抹黑。

2021年5月，我们内部在测试一些新项目，当时我测了两个平台，一个是快团团，一个是群买买，两个都是拼多多推出的产品。

我先测的是快团团。当时从朋友那里拿了一款无线耳机，产品上架后发了一条朋友圈，卖出了1.7万元，毛利接近7000元，初步感觉确实不错。但快团团需要我们自己处理售后，这就比较麻烦了。过去这些年我们虽然做电商相关的事，但主要是给淘宝、京东这类大平台导流，卖货、对接供应链、处理售后这些并没有真正做过，所以觉得模式偏重，后来就没有继续深入。

到了2021年6月，群买买的负责人找到我，希望我帮忙推广群买买，并讲了拼多多对这个产品的规划和期望。我听完后做了一次测试，从群买买里挑了一款女士手表发到朋友圈，同样是一条朋友圈，卖了1.5万元，佣金收益近5000元，而且不需要我们处理售后。

两边对比下来，我认为群买买的参与度更轻，也更适合我们这批过去做电商导购的人。为此我还专门去上海拼多多总部聊过几次。最开始谈的是我帮他们推广、他们支付广告费；测试完并深入了解运营逻辑后，我最终决定不做单次广告推广，而是深度参与这个项目。

2021年7月，我没有做额外推广，只是通过朋友圈招募一些团队长，自己也卖一卖，第一个月就做到了500万元GMV。同时我写了一篇👸号文章推荐这个项目，老粉丝应该看过，标题是《群买买，拼多多的社交电商野心有多大？》。这篇文章被28家自媒体转载，全网浏览量超过30万，很快传播开来。那段时间，群买买在🛰️里的搜索热度超过了其他几家社交电商平台的总和。

借着这股东风，我们旗下的代理店主数量达到35万，团队业绩从每月500万元一路升到2021年11月的每月1800万元，增长势头很好，正朝着我当初设定的月GMV一亿元目标奔跑。

但天有不测风云。2021年11月29日，我突然接到群买买官方通知：从12月1日起，代理政策要调整。通知来得太突然，只给我们两天时间向下传达。正是这次代理政策突变，直接导致我们整体崩盘。

改的是什么呢？核心是代理分佣政策。原先群买买规定，店主加入平台后，只要达到298元销售额，就可以长期拿旗下以及店主15%的佣金抽成；达到1000元，就可以长期拿25%的佣金抽成。但12月1日以后，规则变成每月动态清零：每个月必须卖到298元，才能拿旗下以及店主15%的抽成；每个月必须卖到3000元，才能拿25%的抽成，而且每月都从零开始计算。

这样一改，我们整个店主团队流失超过60%。那段时间，分销店主们都在骂拼多多野蛮粗暴、随意改动，先把人骗过来做，做起来以后马上收割，言而无信、毫无诚意，所谓的本分就是空话。

经历2021年12月那次大改动后，业绩从每月1800万元直接腰斩到1000万元。后来又过了年，到2022年初回落到每月800万元，相比高峰下滑超过50%。

即便如此，出于对团队负责，我们还是坚持继续合作，月会、周会照常开，带着团队继续冲。但2022年4月发生的另一件事，让我从那之后彻底不再重点推群买买。

什么事呢？合作之初，双方约定每月从总GMV中拿出1%作为我们服务商的额外奖励。之前几个月都正常发放，比如每月1800万元时，我们可以拿到18万元额外奖励。但到了2022年4月，群买买没有做任何沟通，直接把1%改成0.1%，几乎等于砍掉。

我知道后非常恼火，找他们沟通。他们给的说法是：当初说这个1%每月可能会有浮动。浮动我能理解，1%浮动到0.8%、0.9%甚至0.7%，我都能接受，前提是提前沟通。但一声不吭直接浮动到0.1%，这让我每个月支付给第三方的手续费都不够，甚至还要自己贴钱。

沟通中，官方态度始终强硬。实在讲不过，就是那句万年不变的话：“领导要这样调整，我们也没办法，只能执行。”我听完非常无语，完全被动，任人拿捏。

面对这种情况，我直接告诉官方，我不会再重点做这个项目了，因为精力投入非常不值得，你们说收割就收割。更让人不舒服的是，官方觉得我们不做之后，赶紧联系我们下面的团队长，让我们团队内部形成斗争，让下面的团队长从我们团队脱离出去。

这套操作到现在想起来仍让人反胃。他们到底怎么做的？本来这段我不想说，但很多团长不明真相，一直很不解。去年很多人问过我，我都没有说。今天项目结束了，我的气也早消了，可以心平气和地把来龙去脉讲清楚。

当时官方找我们合作，我们以经销商身份参与，会根据每月总销售额给我们1.5%到3%的经销商返点。这是给公司的利润，他们要求严格保密，不许向任何外部第三方透露，我们也一直遵守。后来，在他们判断我们不想继续参与这个项目后，就开始通过一些不为人知的方式，把“我们每月拿经销商返点”这件事传达给我们下面的人。

后来果然在一个偶然契机下，下面的团队长借机闹事，目的就是让我们把每月的经销商返点也分给她们。在此之前，我们每月都会给旗下团队长制定业绩标准，再根据完成度给额外奖励。但这次她们要求不考核业绩，直接按比例分配。这样一来，后续团队运营管理就没办法做了。

如果我们不同意，官方就会安排旗下团队长脱离我们、独立出去。这种事情我绝对不能同意。社交电商的核心是关系链绑定，如果官方可以因为某些事情，或者刻意安排，就让团队脱离，那以后谁还敢做这个平台？

当时这件事闹得挺大。2022年4月到5月，我因为群买买平台的这些操作痛苦了两个多月，感觉被平台坑了、被欺骗和恶心了。从那以后，我就没怎么推广过这个平台，只是放在那里，安排同事做常规维护。所有不爽我自己默默承受，从未对外公开说过。

对于当初闹独立的团队长，我们最终也达成约定：每月分一部分经销商返点给她们，至于她们是否往下分配、怎么分配，我们一概不管。一直到今天，只要每月能拿到经销商返点，我们都会准时打给她们。

所以自从去年那件事发生后，我的精力就不在群买买项目上了，也没怎么关心他们的发展，和官方沟通很少。直到3月底他们决定关闭平台，我才算真正从这个项目退出。

最后说一下善后。官方安排是把群买买的运营团队合并到快团团，把我们旗下所有用户迁移到快团团。但这是两个不同产品类型，真的很难迁移。快团团只有二级帮卖分销，而群买买属于社交电商多级分销模型，靠团队裂变赚钱，所以这种合并迁移注定没有效果。

现在，团队旗下一些人愿意做新平台，我们已经介绍他们去做别的社交电商平台；当然，也有很多人已经流失了。

参与群买买近两年，我有很多总结和启示：

1、社交电商平台从启盘那一刻起，就要想清楚整套代理分销机制。千万别为了短期业绩疯狂补贴，后面觉得亏大了、不可持续再调整。这样做会损害很多团队长利益，一定引起巨大反弹，甚至带来崩盘风险。很多平台做不下去，都是这个问题导致的。

2、大公司，尤其是上市公司，最好不要做社交电商项目。无数例子已经证明了这一点。这里面牵涉很多法律法规问题，大公司的操盘者都是打工的，他们自己既不愿意也不敢承担这种责任。谁愿意为了一份工作把自己送进去？创业公司之所以能做，是因为CEO自己在承担最大风险，法务、财务等人员都会围绕CEO的目标想办法配合。而大公司内部互相掣肘，项目很难推进，最终往往流产。

3、项目操盘团队最好是成熟稳重、久经沙场的老兵。他们经历足够多、了解足够深，不会轻易为了短期绩效胡来。很多年轻操盘手经验不足，自认为了解这套体系就能操盘社交电商平台，打法和节奏毫无章法，随意更改，最后葬送整个项目。他自己拍拍屁股走人，公司交了大量学费，最终受伤的还是当初相信他们的团队长和合作伙伴，因为大家所有的努力都付诸东流，很多人还靠这个生活。

4、运营社交电商平台，就算需要调整，也要按计划逐步实施。不要一会儿猛给激励，觉得不行又马上停止，政策反复绝对不行。这样所有人都会没有安全感，对平台信任度不够。过程中一定要及时跟合作伙伴传达和沟通，并留出足够调整时间逐步消化，而不是从宣布到调整只给几天，这就是胡来。

5、就算平台停止运营，也要妥善处理善后。不要短时间内强行关闭，要给旗下团队长一个可靠的新出口。如果大家愿意做其他平台，最好支持关系链平移。格局要大，不要认为自己不做了，也要这波团队长陪葬。在江湖上留下好口碑比什么都重要，也许未来某一天，你还需要这些合作伙伴。

6、官方操盘手和运营团队要能听进去合作伙伴的建议，不要一味坐在办公室里拍脑袋做决策，最后把一盘好棋打得稀巴烂。过程中最好发动自己的家人也参与体验，这样接收到的信息会更客观公正。因为团队长们反映的问题，你可能只觉得他们站在自己角度考虑。

7、团队长们选择社交电商平台时也要多擦亮眼睛，多了解平台背景和操盘手、创始人。最好不要轻易参与那种看起来是大公司搞的社交电商项目，因为他们的主业不是这个，可能只是想测试一下，最终关闭的可能性非常高。咱们进去陪太子读书，时间精力付出和收获完全不匹配，最后什么也没获得，什么沉淀也没有，团队还会在一波波转移中不断流失。如果你实在拿不准哪个平台靠不靠谱，可以问我，我会把知道的毫无保留告诉你。

8、不要轻易进入社交电商的坑。一入深似海，进去容易出来难，尤其是多级代理分销平台。没进去之前你是爷，进去之后就是孙子。团队进去了很难带出来，平台想怎么调整就怎么调整，想怎么割你就怎么割你。作为团队长，几乎毫无话语权，要做好完全被动、任人拿捏的心理准备。

关于群买买的总结，我就写到这里。第一，是对我自己过去两年做个复盘；第二，也希望给正在做和准备做社交电商的朋友们一个参考。
