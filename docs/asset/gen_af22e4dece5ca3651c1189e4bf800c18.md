# 一、项目概览：看懂数字人视频号带货

所谓数字人视频号带货，就是先用数字人生成带货内容，再通过挂车、商品橱窗或直播完成成交。本期重点放在橱窗自然出单；如果短视频跑出爆款，再开直播承接订单。下面这条短视频展示的就是引导用户去橱窗下单的路径；直播收单场景可看：[PRE3]

数字人带货主要解决两件事：
1. 补主播表现力短板。多数人并不具备稳定镜头表现力，而短期提升很难；用数字人，即使没有表现力也能完成口播带货。
2. 提高内容产出效率。既可以用公模数字人，也能录制自己的数字人形象，顺畅批量产出带货视频，不必反复实拍口播，省时省力。上手门槛不高，会基础剪辑即可。

也要看到难点：视频号平台审核有自己的特点，哪怕是中低风险文案，也较容易触碰违规线。因此账号要提前多备，至少4个，并做好部分账号被限流的心理准备。

# 二、实操第一步（1/3）：备好 4 个账号

## 2.1 四张电话卡与对应手机

1. 去营业厅办副卡，每月约10元；想快的话现场能秒办2张，流量和话费与主卡共享。
2. 京东下单电信无忧卡，月租5元；下单时付30元充作话费，通常次日送达，每月可办1张。
[PRE5]
3. 也可领取团队福利低月租卡，免费包邮到家，激活就能用。推荐其中的19元卡，和普通营业厅卡一样，只是从优惠入口办理：低价三大运营商月租卡。
4. 淘宝可买第三方运营商卡：搜“手机卡”，下单前问客服能否注册微信；卡费几元，收到后按提示充几元话费，总成本十来元即可包年，无月租。保存图片去淘宝扫码，每人可办70张。注册微信尽量优先三大运营商，第三方卡作为备选。
[PRE6]
5. 电话卡备好后，要配对应手机。最好一机一卡；部分手机系统支持双卡和微信双开，也可行。手机可去“转转”买；闲鱼上工作室用废、被拉黑的设备较多，需留意。

## 2.3 注册四个微信号

1. 微信号可先用自己常登的老号；老号不够再新注册。一个身份证可开5个微信号。老号无需养号，直接进入下一步注册视频号。
2. 新注册的微信号别马上开视频号，先花2天养号。流程：完善头像和名称；按“微信-我-服务-钱包-实名认证”完成实名；添加3个好友，互发几条消息、通1分钟电话，并各收/发一次转账；关注“生财有术”“生财有术服务号”；每天在视频号刷5分钟视频、挂10分钟直播；发1条朋友圈。
3. 微信实名认证要做：线上带货佣金需提现到微信零钱，提现前提是实名。一个实名信息可认证5个微信号。路径：“我-服务-右上角【···】-实名认证”。

#### 2.4.2.1 账号名

先看官方对【账号名称】的提醒：
[PRE12]
名字要围绕账号类型来定。好名字本身能带来搜索流量。常见做法是组合相关关键词，例如国学、书籍、认知等；别人搜这些词时更容易找到你。像“xx女性思维”“xx智慧说”这类名字，看起来像普通用户，不像专业营销号。切记别用“好物推荐”“好物分享”“**百货”这类明显带货名。顺口好记的名字很多已被注册，多准备几个备选逐个试。账号名一年最多改5次；没思路时参考各平台同赛道账号，也可用通用名，如【xx-同款在橱窗】。

#### 2.4.2.2 头像

头像能帮别人更快记住账号。花朵、风景、莲花荷花等生活化图片，或妈妈群体常用风格都可以，没有硬性标准；但别用好物推荐图、暴露身体/胸/背的图、产品主图等容易踩雷的素材。头像可用纯文字（名字缩写），也可图文结合。拿不准时，去看同定位大V怎么设置。制作可用图怪兽 https://818ps.com/ 、可画 https://canva.com/ 、创客贴 https://www.chuangkit.com/ 。注意别用易侵权商标图，也不建议用个人照片，容易和账号定位不搭。

#### 2.4.2.3 简介

简介随时能改，要围绕账号定位写，可参考成熟大号。注意不要出现“点击”“购买”“私信我”等词。PS：账号前期别做太多营销动作；等视频爆了，再考虑换头像、做评论互动。

### 2.4.3 完成实名认证

视频号注册好后，打开“微信-我-视频号-发起直播”，系统会提示实名认证，按步骤完成即可。一张身份证只能实名2个视频号。
方式一：用自己的微信，让家人帮忙扫脸实名。原因是和外人沟通信任成本高；同时让该号发起第一次直播，并随便添加一个商品进橱窗。
方式二：用别人的微信注册并实名视频号，同样发起第一次直播、随便添加一个商品进橱窗；之后在PC端视频号助手后台把你绑定为运营者，你就能用电脑登录发布视频和直播，对方可用手机看数据流速，或你直接在电脑端观察。入口：视频号助手官网-设置-人员设置-绑定运营者。
[PRE14]
现在平台管控趋严，微信实名和视频号实名最好为同一人；实在不方便，也不必强求。

# 视频号带货权限说明 @旋子

橱窗带货0粉即可开通，它是视频带货和直播带货的必要前置。直播带货指直播时挂小黄车，开通条件满足其一即可：1. 粉丝数达到100；2. 账号带货身份为商家（开小店）；3. 商家授权号（供应链授权，不建议，非必要不用）。推荐第一条，100粉很容易；如果是直播起号，可考虑第二条。视频带货需满足两项：1. 有效关注数1000以上，或带货中心账号身份为商家；2. 符合内容规范。
[PRE20]
1000粉通常要靠几条爆款视频来涨；想更快开通视频带货，也可开小店。内容规范方面，只要不发布违规视频，一般会自动开通。

# 2.6 开通原创功能 @斌斌 @旋子

养号并开通“原创功能”：注册后每天刷几分钟视频号短视频，同时用手机发一些流量视频。一般两三条视频播放过千，就会开通原创；发布视频时会出现“原创”选项，这样才能一拖五。注意有一点玄学：有的账号一条就开通，少数账号三五条还没开；多发几条通常会自动开通。
1. 用老微信开视频号，权重通常更高，抗违规能力更强；新账号一般有流量扶持期，但权重偏低。各有优劣，总之账号越多越稳。
2. 新注册视频号先刷10分钟视频、看10分钟直播，隔几小时再发流量视频。通常2-3条播放过千，原创功能会自动开通。
