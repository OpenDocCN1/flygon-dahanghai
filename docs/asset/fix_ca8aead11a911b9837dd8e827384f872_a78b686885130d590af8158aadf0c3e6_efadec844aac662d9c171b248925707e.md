# 合伙人不靠谱，创业基本就废了

在今年生财有术的全国见面会上，一位创业的年轻朋友找到我，讲了他的困惑：公司收入其实挺可观，但忙活一年，细算之下到手利润薄得可怜。而团队成员的表现也让他心里发毛——产出下滑、沟通变少，隐隐透出躺平的信号。他忍不住问我：是不是团队出了问题，是不是当初挑人选就犯了错？

继续聊下去，细节更耐人寻味。队伍里有些人是从他上一个项目一路追随的，曾经个个朝气蓬勃、业绩突出，怎么如今面目全非？还有几位是他亲手招募的，刚加入时眼里满是热忱，现在那股劲儿也不知去哪了。

事实上，创业初期团队出状况，并不必然意味着人出了差错。常见的有以下三种情形：

其一，团队本身没问题，问题藏在产品逻辑上——商业闭环尚未跑通，却误把经营压力归咎于团队；
其二，合伙人角色缺席，创始人孤军奋战，业务、管理、技术三头兼顾，一个人充当了好几个角色，最终局面失控；
其三，选人环节确实走偏了——招进来的人不合适，甚至混入了一群小白兔型的成员，团队自然弱不经风。

那位年轻朋友所遭遇的，正是第二种——独自一人撑起公司，什么都自己揽。

在当前的市场环境下，单枪匹马打天下的模式早就过时了。创业本身是一项庞杂的系统工程，做产品也好、做服务也罢，个人能力再突出，也需要一群能一起扛事儿的搭档，通力协作去实现同一个愿景。

比较通行的合伙人配置是三人铁三角，上限建议不超过五名。

挑选合伙人绝不能轻率，要当作头等大事对待，宁可少不可多。我亲眼见过太多创业团队折在合伙人内耗上——最坚固的堡垒从来都是被内部撬开的。

许多创始人在组建合伙人班子时非常随意，心想手头有好项目，谁来搭伙就点头，甚至更倾向于从亲戚、同窗、好友、旧同事圈子里找“放心人”。

实际上，交情是不是朋友并不关键，是不是靠兄弟情谊来维系也不关键，遴选合伙人应当围绕如下维度展开：

（**1**）方向认知是否统一

古人讲得好，道不同不相为谋。志同道合是共事的基础。

合伙人对于公司前进路线必须步调一致，一同仰望星辰大海，才有可能并肩远航。

一个立志做长期事业的人，跟一个满足于小日子的人，注定无法共事。

做事手法与道德红线上的判断也得一致，价值观必须契合。

一个坚持合规经营的人，跟一个琢磨歪门邪道的人，同样走不到一块。

（**2**）品行必须靠得住

初次创业者遴选合伙人时常常深陷一个盲区——只盯着能力强不强。对方本事大就热烈欢迎。

这种思路风险极高。挑合伙人务必考量品行，品行低下的人比能力平庸但正直的人更加危险——他们会把才智用在盘算搭档、盘算客户，甚至侵占你的奋斗果实，甚至拉你不明不白地卷入违法行为。

合伙人必须诚实守信，是认同并敬畏规则的人。

（**3**）能力互补且各自都是本领域的好手

荒野上几个背包客遭遇狼群，正确策略是背靠着背，分头盯守不同方位，才能形成全方位防守；若所有目光锁定同一处，大概率沦为狼群猎物。合伙人迎战白热化市场竞争，道理相通。

合伙人组合必须由不同方向的专才构成，拼合起来才能搭建出完整无短板的能力版图。

有人擅长获客、流量，有人擅长产品打磨、技术，有人擅长组织管理、充当政委角色。

各个方向的高手通力协作、彼此补位，才能最大限度拉升创业胜算，让企业行得稳、走得远。

（**4**）性情互补

不少客户问过我，遴选合伙人应当找性情相似的还是互补的？

我的回答是：互补的。

假设一位合伙人冲劲足、执行力爆表、属于开路先锋型，那身边就需要一位谨慎周全、深思熟虑的人；

假设一位合伙人火气旺、情绪随时爆发，那身边就需要一位脾气温和、能接纳每个人的人；

假设一位合伙人容易偏听偏信、身边红人走马灯般轮换，那身边就需要一位心志笃定、能沉下心做事的人。

你能设想合伙人全是倔脾气吗？那公司就沦为角斗场了，生意还如何推进。

我曾担任过一家企业的顾问，其创始人是艺术家脾性，乐见公司内部上演各种权谋戏码，每位“亲信”都觊觎着合伙人的位置、想坐上第二把交椅，但公司居然跌跌撞撞活了下来，眼下已拿到E轮融资。这跟合伙人恰巧在性情上与创始人互补密切关联。

以上就是遴选合伙人需要关注的若干维度。这些道理或许大家多少有所耳闻。

我还要补充一个鲜有人提及的要点：金钱认知必须一致。

什么叫金钱认知一致？先说我一位客户的亲身经历。

互联网洗衣这门生意（国内最早入局的团队正是我一位客户），也是行业中首个拿到天使投资的团队，比e袋洗早了接近一年，且自建了线下洗衣厂。

该厂系其中一位联合创始人的个人资产，长期为酒店提供布草清洗服务。

我的客户正是那位拥有洗衣厂的联合创始人，他察觉到互联网洗衣的风口后，拉着多年好友共同入场，甚至把CEO的位置让给了对方。

两家人相交十几年，亲密到不分彼此。是不是很多人都是这样找合伙人的？拉上铁哥们就开干，觉得这样最保险？

谁知首轮几百万（2013年）天使资金到账之日，剧情急转直下。担任CEO的一方认为这笔钱数目可观，理应分红；而联合创始人一方认为几百万根本不算什么，分了毫无价值，不如投入运营，日后做更大的盘子。

两人因此爆发剧烈冲突，争执到不可收拾，最后担任CEO的一方甚至扬言要绑架对方的孩子来泄愤。

团队就此瓦解，项目也难以为继。倘若当时能走下去，或许e袋洗的故事就要改写。

这是价值观不合吗？若价值观不合，两人不可能做了十几年朋友。

说到底是金钱认知不一致——同一笔几百万人民币，在两人心中的分量天差地别。

所以遴选合伙人，除前述所有维度外，还必须考量双方对金钱数量的感知是否接近。

另外，我再列举几个遴选合伙人时的常见陷阱：

（**1**）把短期能救急的朋友拉为合伙人

合伙人必须能在长周期内持续为公司输出价值。若只是需要朋友解决眼下的问题，按项目付酬即可。

（**2**）把在精神上支持你创业的亲友拉为合伙人

创业早期格外艰辛，一些亲友看好你、鼓励你，创始人一感动出于报答心理就把大家伙拉进来当合伙人，共享将来的好日子。这种做法极为错误，遴选合伙人务必以上述维度为标尺。

（**3**）把纯出资方拉为合伙人

不少创业者在起步阶段资金紧张，就随便找个纯财务投资人当合伙人，这同样极不妥当。

合伙人必须选择能为公司导入资源或具备运营经验的人。若确实需要带资金入场的人，也得找既有资源或某领域专长、同时携带资金的人，或者另行设计财务回报方案。

（**4**）把大厂背景的职业经理人拉为合伙人

每位创始人心里都藏着一个美好愿景：挖一位大公司出来的职业经理人，自带耀眼光环，能摆平创业途中的所有障碍——定方向、搭班子、融资金。但这真的只是愿景而已。

多数职业经理人不肯从底层做起，更难以接受创业企业那套薪酬结构。他们习惯按程序办事，过度拘泥于流程规范，过分倚仗相关部门的配合，而这些恰恰是创业公司最致命的雷区。

清楚了该找什么样的人，那通常通过哪些途径去物色合适的合伙人呢？

（**1**）向上破圈：接触比自己层次更高的圈子，向这些人宣讲你打算启动的创业项目。交往面广了，自然会遇到愿意与你搭档的人，或者对方能引荐合适的人选。

这类人视野开阔、阅历深厚，哪怕不加入也能给出不同角度的建议，甚至协助你完善项目。

将来你做出成绩、谋求更大发展时，他们同样能助你一臂之力。无论怎么看，对创业者本人都益处多多。

比如你在生财有术社群里结识的各位大佬，就是这类人的典型。

（**2**）平层拓展：从同窗、友人、亲属、昔日同事，或者你加入的各类社群、创业者圈子中，物色志趣相投的合伙人。

这些人跟你的段位大体相当，多向他们讲述你的创业构想，交流的人多了，合伙人自然会浮现。这也是多数创业者采用的路线。

仍旧以生财有术为例，社群里不少与你节奏相合、水平相近、同样怀揣创业念头的小伙伴，就是这类人的典型。

（**3**）向下挖掘：从层次稍低于自己的人群中遴选合伙人，例如你过去职场中的下属、关注你的粉丝、你的学弟学妹等。这类人相对容易接触，因为你的综合实力优于他们。这和向上破圈是一个逻辑——人都倾向于靠拢比自己更强的人。

但有一点务必注意：你得确认他们能够达到你创业项目对合伙人的专业水准要求。

物色的核心只有一句话：尽可能多地传播你的创业构想。

讲得越频繁，知晓的人越广，遇到合伙人的几率就越高。不过要拿捏分寸，在广泛撒网阶段无需把全部方案细节和底牌都和盘托出，该守住的商业机密还是要守。

物色合伙人的过程可能旷日持久，也可能说来就来。一旦你脑海里冒出初步的创业念头，这件事就可以着手推进了。

创业构想从萌芽到真正落地是需要周期的，在这段时间里边打磨项目边物色合伙人，最终遇到的人选也会更贴近现实，而非你脑中“拍脑袋”想象出来的理想型。

已经物色到几位有意向的候选合伙人，对方也都声称完全认同你的全部构想、自认为符合你遴选合伙人的所有标准，是不是就能立刻携手开干？

不，还不能。合伙人必须经历筛选流程——口头表态不作数，过往的实际案例和真实行为才是评判的准绳。

关键的事重复三次。

面试是所有识人方式中相对周全、相对靠谱的一种。

如果嫌“面试”二字太正式，不妨以“闲聊”的方式推进。借聊天淡化面试的压迫感，把面试的技法融入对话，不动声色地达成考察目的。

从他的职业轨迹和项目履历去判断知识储备、专业技能能否匹配你的创业需求；从他的兴趣爱好或对某些话题的见解去判断价值观、金钱认知是否与你合拍。同时还能借“闲聊”打探你想知道的各类信息。

面试完毕还得做背景调查。通过他先前任职的企业、共同的朋友、共同的社交圈，不带八卦心态、真诚地去核实他所说的情况是否属实、为人是否靠谱。

但在背调启动之前，务必先跟候选人打招呼，征得对方许可。

读到这里，是不是不少人感觉这样做未免太苛刻、太不近人情？

千万、务必不要因为怕尴尬而“拉不下脸”。你早期碍于情面不好意思开口的事，后期都会变成你要承受的隐患；你早期的Be nice，后期真就成了你的耐撕。
