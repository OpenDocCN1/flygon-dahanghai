# 7.2 群体为何会“上头”

别把“群体非理性”当成书斋里的学术名词。它每天都在社群里真实上演。

微信群里那些排队刷“保持队形”、拿“人类本质是复读机”玩梗的场面，就是群体情绪互相带动的痕迹。

看见别的群友已经下单，原本还在盘算“这东西到底适不适合我”的人，很容易被推着一起买；这种来自同伴的怂恿，往往比独自权衡更有冲击力。

还有一层更微妙：只要意识到有人在看——哪怕观众只在屏幕另一端——一个人维护自己错误判断的执拗，也会明显强过私下对话时。围观搬到了线上，效果却没打折。

有些事，单枪匹马时不会碰，放进人群里却显得顺理成章。

群体还能替一件事镀上意义；而个体独自面对同一件事时，往往没那么多底气，彻底相信自己给它下的定义。

所以，群体中的非理性，以及个体进入群体后生出的非理性，不必急着打成“坏事”或“失了智”。有时候，勇气恰恰需要一点不按纯理性出牌。

对社群运营者来说，理解并善用这种客观存在的群体情绪，能释放的能量，会远大于另一个版本：把每位成员都当成绝对理性人的自己。

不过，这股力量往哪走，全看使用者怎么选；用于善还是用于恶，也只在掌舵者的一念之间。
