# 1.5.2 用淘宝账号养出选品池

找虚拟资料时，把淘宝当作日常信息流来刷：多搜、多看、多存。碰到销量顺眼的铺子，顺手记进收藏夹。账号行为越集中，平台越懂你想看什么，之后首页和搜索页会持续冒出同类资料与店铺，货源线索就会自己找上门。拼多多可以照搬这套动作。

关键判断：在淘宝表现好的资料，放到小红书通常也不弱，这一点很关键。

# 💡 快速验品三步法

淘宝上成交不错的资料，不必做复杂分析，按下面顺序过一遍：

先去小红书检索同类内容，观察帖子互动是否密集；高赞内容多，代表关注度够。接着看小红书店铺里同类商品卖得怎样：如果成交规模明显小于淘宝，就说明这块供给没吃透，值得试。最后对需求周期：产品只在特定月份走俏，就要卡准窗口。比如期末类 K12 资料，需求集中在五月、六月、十二月和一月，其他时段偏淡。

三步走完就够，选品时不必来回纠结。
