# 零、项目是什么：边做边分享，和用户一起成长

所谓“养成系 IP 从 0 到 1”，说到底就是先给自己定好位，选准一个赛道，然后在这个赛道里做社群 IP，从零开始，和用户一路陪伴、一起成长。

这种 IP 的好处是真实感强，离用户更近，也更容易把 IP 和用户之间的粘性做起来。

这次我们请来了“赚钱大师兄”杨涛，带大家一起拆解：一个养成系 IP 到底该怎么学、怎么做。

杨涛说过，自己四十岁那年写下过一条人生新战略，一共十六个字：“保持健康，做好私域，我们有人，他们有钱。”

凯文·凯利提出过一个很有冲击力的理念——「1000 个铁杆粉丝」。大意是：这个时代的创业者未必需要千万粉、百万粉，只要手里有 1000 个忠实粉丝，就足以支撑个人的生活与事业。因为这些铁杆粉丝不只是会反复购买产品，还会持续关注创业者的动态，既构成销售基本盘，也会自发帮你传播。

信息越丰盈，注意力越稀缺。注意力在哪里，钱就在哪里；钱在哪里，注意力也就在哪里。所以，我们必须开始搭建属于自己的铁杆粉丝群。它是最宝贵的生产要素，也是确定性更强、能陪你穿越周期的生产要素。这正是本次航海要教大家从 0 到 1 打造养成系 IP 的意义。

# 1.1 为什么要做养成系IP

先看一个大背景：知识付费的基本盘还在扩大，越来越多领域有人进场，过去免费的内容，现在越来越多人愿意付费，为知识买单的意愿在上升。

知识付费本身就是一件很有价值的事。道理不复杂：如果没有人传道、授业、解惑，大家怎么获得知识？几千年前需要知识付费，几千年后依然需要，这是真正能穿越周期的事。

对圈友来说，现在正是发挥自己特长的时候。用自己的知识和经验，帮更多朋友提效降本，拿回生活的掌控感，找到人生的确定性。

可以做的领域很多：变美赛道里的护肤、穿搭、形体，情感领域，成人技能，健康养生，中老年，兴趣，家长，各种行业领域，工具使用领域……都很香，也都很缺人。

而且，做养成系 IP 社群，还能全面训练人生技能，也就是常说的「确定性三件套」：

1. 内容能力：听说读写，驾驭文字的能力；
2. 流量能力：全域、全平台获客的能力；
3. 销售能力：建立和维护社会关系、私域运维、销转的能力。

这些能力，才是真正能陪你穿越周期的东西。

# 1.2 适不适合，先做一次自查

接下来先自我诊断：你现在有什么、缺什么，适不适合做这件事。

可以对照下面几道门槛自查：

1. 有没有「一技之长」。  
这很微妙。现在问你：你的「一技之长」是什么？能马上答出来，就是有；答不出来，就是没有。

2. 粉丝数量。  
各平台读者过万，🛰️好友过万，并且你自我感觉良好。这个也很微妙：如果你做的是吃播、泛娱乐类的泛粉，大概率不会自我感觉良好。

3. 行业影响力是否过硬。  
行业资深专家，沉淀多年，或者出过书。有些朋友其实很厉害，对行业理解和洞察极深，只是自己没意识到。

4. 是否热爱分享。  
分寸可以这样判断：别人来请教你时，你感受到的是滋养，还是消耗？如果这种场景让你疲惫、厌倦，那就不合适。

5. 是否有可支配时间。  
企业、业务、收入稳定，有属于自己的时间，能把「一技之长」发扬光大。于是你可以去探索、去钻研、去输出、去发出声音，让人听见、让人看见、让人说好、让人喜欢、让人信任、让人付费、让人到处说、让人喊人来……

接下来是第二关：填一填下面的问题。没有固定答案，非常有趣。你只要能诚实面对自己，坦然笃定地填完，就一定能在这条路上走得很远。

# 1.3 人设与定位：别急着给自己贴标签

对普通玩家来说，先别着急。不要有定位焦虑，也不要盲目定位，自己都还没搞明白的时候，硬定也没意义。

对我们要做的这件事来说，定位就是：在你覆盖的众多圈子里，借助相对优势、差异化策略和积累的正面声量，聚焦用户需求，塑造出你的不可替代属性和价值标签，成为某种需求下的最优、第一或唯一选择。

比如：搞钱社群=龙哥盟，高端手机=苹果，电车=特斯拉，咖啡=星巴克。

人设则由很多标签组成。你日常传递的信息，被人们感知到，就变成了人们给你打的标签；众多标签弹回来，构成了你的人设。

比如：一个很会写作、能唱会跳、身材好的海归高学历，从事跨境电商的二宝妈……这里面的每个细节，都是你日常想让人感知到的，再通过内容传递，慢慢塑造成标签。

假人设、硬造出来的人设，都有系统性风险。时间轴一拉长，要么迎来崩坏点，要么需要耗费巨大能量去维持。也就是人们说的：德不配位，必有灾殃。

对了，我们常听到“IP”这个词。在我心里，IP 是结果，是内容的结果，是业务的结果，是结果的结果。IP 给你带来的「知识社群」，其实也一样。

它们都需要思考两个问题：

- 你在为谁，解决什么问题？
- 你在为谁，提供什么价值？

细品，别上头，冷静一些。如果你还觉得自己符合条件，那就把它当作人生的「第二曲线」，一起来吧。

我们一起盘清楚：做什么、为什么、怎么做。包括但不限于：目标用户需求、社群定位、视觉相关建议（名字、slogan、封面、亮点、海报）、定价策略、涨价策略、新人手册、推广方案、渠道、分享模式、激励机制、社群运维、内容板块设计、线上和线下活动的设计与运营、裂变机制、增值服务、资源调配、续费率提升、低转高路径设计……这些问题都值得提前想。

# 1.3.1 养成系IP差异在哪：真实、共创、从0到1@七天

养成系 IP 的人设有几个明显特点：真实、不完美、共创、从 0 到 1。

和专家人设相比，养成系 IP 往往处在“自己也在边学边分享”的阶段。它的差异化，首先在于真实。

比如做一个“AI+IP”的成长社群，你不必是 AI 领域高手，也不必熟背 IP 人设定位几步法。更重要的是，把自己学 AI、学 IP 打造的过程记录下来，包括心得和避坑经验，让同样关注这件事的用户产生一种共鸣：你在慢慢成长进步，那我也可以。

IP 的本质是塑造信任。专家角色是为了塑造信任；但如果你还不是专家，真实同样可以塑造信任。

第二个差异点是共创。

过去📕上就有不少养成系 IP 案例，比如“小艾同学”“听劝的延安苹果”。小艾同学在网友建议下开启听劝改造，从减肥到穿搭，一步步变瘦，找到女友，直到恋爱结婚。

“听劝的延安苹果”则是延安果业中心想把当地特产苹果推广出去，但缺乏营销经验，就直接注册了📕账号。结果真的有人在评论区认真为延安苹果列营销策略，也有人直接上手帮他们写文案。

在过往专业 IP 打造中，更多是凸显专业、引领、权威，用户被动接受品牌的产品和分享。而养成系 IP 则是和用户并肩，甚至主动邀请用户参与自己 IP 的共创过程：一边帮自己出谋划策，一边成为自己的核心用户。

在供应过多的当下，很多专业人设的表达已经变得稀疏平常，用户反而更在意：你是否足够尊重我的建议，是否看见我、听见我。于是，围绕需求共创的解决方案，就成了 IP 与用户共同沉淀的资产。

当养成系 IP 把用户当作一个个具体的人去对待，用户才会觉得：你是真的在为我的需求寻找解决方案。

第三个差异点，是从 0 到 1。

很多赚钱圈友应该都发现了：从 0 到 1 是赚钱内容里的高频词。不少圈友还处在探索尝试阶段，需要的不是已经成熟的方法论，而是手把手、分步骤的拆解，最好具体到每个动作都能截图分享的详细 SOP。

这正是养成系 IP 的特质：因为还处在 MVP 过程中，所以遇到的大多数问题、探索出来的解决方案，都是用户现阶段需要的，而不只是一套完整理论——看完觉得高深专业，却无法下手。

因此，养成系 IP 的内容定位也会更清晰：把自己探索某个业务的过程，比如如何做 AI 职场提效中的 100 个常见问题积累下来，找到答案。这个百问百答素材库，就是最好的冷启动内容库。

比如目前我在做“AI+IP”的成长社群，那么我就会把“如何做 IP 定位”“如何用腾讯的 ima 知识库”“如何用 DeepSeek 做爆款📕标题收集”等新手常见问题加思路分享出来，这就能满足用户对这个社群的刚需。

# 1.4 社群定位：先想清楚它在你业务里的位置

每天都要问自己两个问题：这个群到底在帮群友解决什么问题、提供什么价值？

这里头很微妙。一句话概括：社群对你究竟意味着什么？是你业务的全部，还是业务的一部分？

比如，付费社群如果没有后端高阶产品，精力就可以全部放在交付上：高价、做精、做深、做续费。比如，有后端高价产品，就可以前置一个破冰社群：低价、轻交付、做规模、扩大池子。

付费是一种习惯，像一个漏斗，长期筛出更契合的用户。当然，知识付费并不是全部。好物分享也是一种很强的价值输出，帮人提效降本，同样是一门大生意。

另外，知识付费的升华版，是行为改变付费。这块人人都可以做，而且交付极轻、售后极少，对情绪价值的需求大于实际价值，尤其对爱立 flag 的女生来说更是如此。

再同步一个概念：我们为什么要做社群？知识付费社群、好物社群、陪伴社群，一个很重要的原因是「边际成本」为零，或者说极低。

举个例子：你做一门课，从做出来那一秒开始，边际成本就是零，卖一份和卖一万份，并不增加你的成本。你做一个收费陪伴群，群里 30 个人还是 500 个人，交付成本并没有增加太多，但收入翻了 17 倍。你开一个付费群，还是两百个付费群，交付成本轻微增加了一些，但收入翻了两百倍。

这种模型是不是很性感？实操的话，本次参与的同学大致分两种。

# 1.4.1 还没方向，也能开群

没有方向一点问题都没有。我们可以通过开这样的社群，输出倒逼输入，别人付费，我们学习，一起精进。

比如开网赚类的群：创业项目交流群、搞钱副业风向标群；  
比如开自律类的群：跑步群、各种打卡群、减肥群；  
比如开学习类的群：共读群、共创群、写作群、表达群；  
比如开分享类的群：好物群、优质信息共创群、羊毛群；  
比如开陪伴类的群：脱单群、话术群、哈哈群……

每种群都可以展开讲实操。赚钱有个圈友做跑步群，多年前就年入百万了。

# 1.4.2 已有方向，把优势放大

比如你本身就是相关从业者：律师、老师、财务、烘焙师、黄牛、📕玩家、电商人、设计师、主播、创作者、程序员、搭配师……

你已经很清楚自己能给他人创造什么价值、解决什么问题。

这类朋友可以从群开始尝试：第一波百人群收集一线体感，更清晰地知道用户需求，跑完闭环，再扩大规模。

也可以在过程中设计高阶产品，比如知识星球、训练营、自己的课……还可以通过群发展自己的业务，比如保险、代购、设计、财税……当然，也可以带货。

有了基本的用户池子，就有了无限的可能性。

常说选择大于努力。如果有得选，该怎么选？

「基本面大、系统性稳定、上升趋势明显」，这是黄金三角。

比如，要选基本面大的领域，也就是受众更大的领域。所谓垂直，是需要在大的基本盘里头去垂直。举例，圈里有人勤勤恳恳卖 AI 课，两年做了快两亿，到手几千万；可英语雪梨老师，一个暑假就做了两亿。

再做个测试：假设你开一门工具出海的课，市场盘子可能很窄；如果这门课是抖音直播，盘子就大了不少；如果是电商，盘子又更大；那有没有比电商更大的？有，英语。有没有比英语更大的？有，写作、表达。有没有比写作表达更大的？聪明的你一定想到了：成长。泛成长领域其实包含身心灵、情感，甚至读书会等在内的一切。

还没完。你选择小基本面的电商课，很好，但这时候你需要保持敏锐、保持机动、保持对抗，还要拥抱变化。可以说，你半年前的课不迭代，半年后就过时了。

如果你是英语，比如音标课，英语就那么 48 个音标，200 年后大概率还是这 48 个；发音课也是一样，不需要频繁迭代。做一门课，卖五年、十年，不香吗？写作和表达也是一样。

如果你是成长领域，你知道最早的鸡汤文是什么吗？没错，是荀子的《劝学》。你去看看全文完整版，会大大感慨。

落到实操，刚才说过，按“一技之长”来分，大概可以分成两类：有一技之长的人，和暂时没有一技之长的人。

# 2.1 有拿手本事的人

有自己技术或专长的人，可以根据专长马上做出一个产品，然后马上开始卖。比如：销冠群、写作群、表达提升群、恋爱技巧群、纠音群、艺术签名、改错题群、练书法、康复群、健身群、母婴群、创业实验室、项目快闪群。

标准模式就是内容输出+答疑。不管你处在行业的什么段位，都可以快速成为普惠行业的高手。

比如，任何行业里人们关注的最热的 200 个问题，几乎是恒定不变的。我们可以通过 5118（闲鱼租号就可以）和其他极客工具，也可以通过 AI，收集这 200 个问题并获取答案，然后改写成自己的风格，配上案例详解。

这样，你就有了一个行业百问百答。如果有心深挖，还可以变成“想做保险，看我就够了”，或者行业圣经，比如《白话区块链》。我们不好高骛远，但也可以画个饼：你整理完，如果心里有一丝笃定，是可以考虑出书的。

也比如，我们可以在学浪、网易云、荔枝、小鹅通、混沌、得到、腾讯课堂等任何课程平台，找到你这个行业的相关课程。无需购买课程，只需要看课程表，糅合多家的课程表，再结合你的舒适区，就能有一堂非常系统的课。

作为基本交付，你可以分一个月讲完，也可以半个月讲完，剩下的就是交互：日常答疑解惑，收集最一线的需求，再迭代到你的行业圣经里头。

慢慢地，传播到位了，你的江湖地位就有了。这就不算画饼了。你们现在扪心自问：你行业里有人出过这样的内容吗？我想是没有的。如果能够通过这次航海，让大家整理出这样一份内容，我觉得是极好的。

是吧，有生物老师专门整理了不同风格的课件，赚得盆满钵满，生物老师服务全国生物老师。

# 2.2 暂时没有拿手本事的人

如果你没有什么技术专长，也可以开始做起来，可以选择有共性需求的群。

比如：日更群、跑步群、读书会、减肥群、背单词群、英语角、创业项目交流群、资料群、网赚群、好物分享群、风向标分享群、哈哈群、冥想群、抄经群。

这类就更轻松了，交付的东西只有一种，就是内容。你可以称之为信息，也可以称之为知识。

# 2.3 定价怎么定 @七天

所有定价的终极目标，是找到跟自己的同类人。而寻找同类人的过程，对养成系 IP 来说，需要一些试用装；但为了锁定高潜用户，也需要正装，甚至定制装。

所以做定价有两个重要点：一是尽可能覆盖潜在用户，二是深度挖掘高潜用户价值。给大家的建议是阶梯制收费。阶梯制包含时间的阶梯，以及加入时间的阶梯。

# 2.3.2 阶梯收费怎么跑

阶梯制收费的核心，是用低门槛吸引用户，再逐步引导他们升级到更高价值的服务，从而实现用户留存和收入增长。

低门槛入口：设置一个极低的入门价格，比如 9.9 元/周或 19.9 元/月，降低用户的决策成本。这个阶段的目标，是让用户快速体验社群的核心价值，建立初步信任。此时，社群的核心交付可以是基础内容、轻量答疑或简单的陪伴服务。

中端产品承接：用户初步体验后，提供中端产品，比如 99 元/季或 199 元/年。内容和服务可以更深入，比如增加专项答疑、定期直播、行业资源资料分享等。这个阶段的目标，是让用户感受到社群的持续价值，并愿意为更长期的陪伴和深度内容付费。

高端 1v1 产品：针对高意愿用户，提供更系统化、更定制化的服务，比如深度陪跑、个性化答疑、资源对接等。这个阶段的目标，是锁定高价值用户，建立长期关系。

总结来说，阶梯制收费的核心逻辑是：低门槛吸引→中端承接→高端锁定→升单激励→持续迭代。通过这种模式，既能最大化用户覆盖，又能深度挖掘用户价值，实现社群的可持续增长。
