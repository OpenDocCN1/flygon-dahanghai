# 6.1.6 撮合型社群，先想清楚“谁和谁”

撮合类社群能做的方向很多，但最常见的翻车方式，是一上来就搭一个泛泛的“资源对接群”，群名甚至直接叫“资源对接”。真正该先想清楚的，是这次撮合发生在哪个具体场景、牵线的是哪两端。供需双方一变，运营方法往往就完全换了一套。

相亲是强需求。尤其当社群已经形成较实的共同价值观，再顺势做相亲并不突兀。若想把相亲单独做成付费群，收费点别设在“能否约到”，而要放在进群门槛：用户买的是可能遇见的机会，不是某次约会本身。

招聘也是典型。更靠谱的做法是内推机会加简历指导；不管社群收不收费，只要能促成一次到面、一次入职，内推金就可能相当可观。若聚集的是某类精准人才，而行业缺口大、招聘急、鉴别人才成本又高，这批人的聚合价值会更高，和用人方谈合作时也更有底气。

再往上看，投资人与创业者、找合伙人的人、体量相近想找伙伴或做异业合作的人，直接撮合路径会偏长。商学院、MBA 的最大价值，可能恰在这里——不是课堂上学到了多少，而是把人放进了可连接的场里。

业务型撮合也很多：供应链与品牌方、品牌方与营销方、方案需求方与落地实施方（TP、DP），都能做成以成交为目标的社群。被撮合的事再小，也有空间：00 后扩列、Z 世代换表情包、微信读书组队、拼多多帮砍一刀、蚂蚁森林合种……事情轻，需求却硬，用户规模还能做得很大。体验过的朋友，不妨到航海群里讲讲。

派单和接单，同样是标准撮合型社群。它的收费点，一方面在降低促成合作的交易成本，另一方面在提供机会的机会成本——关键看群里能聚起多少单子。设计外部群、技术外包群、垂直细分翻译社，以及抢茅台、抢潮玩、抢门票并提供刚性兑付的群，都是常见形态。放单、进单、接单会成为社群的底色或背景音，活动围着它长出来，价值观也会在“什么单值得接、单子怎么做”的讨论里慢慢成形。

从相亲到招聘，从投资关系到合作搭子，从上下游到异业联手，甚至生活里需要搭把手的小事，都是撮合型社群能发挥的舞台。做这类社群的人，建议读一读《中间人经济》，算是创建者的必读书目。

说到底，商业化社群的形态非常多样，行业和经济变迁还会不断催生新类型。多数时候，社群本身就是平台型商业模式极好的 MVP。2018 年由腾讯领投、估值约 1 亿美元的多抓鱼，最早验证模式时没有开发产品，只有社群；交易没有订单，也没有商城 SaaS，全靠 Excel 表格在群里穿梭。无论是把社群当作第一款变现产品，还是用它给原有业务营收做加法，都各有优势。

当然还要再强调一次：社群不止是一门业务，它也可能成为一部分人的生活方式。
