# 1.2 项目核心玩法

# 1.2.1 最小 MVP 路径 & 关键步骤

公众号爆文玩法简单说就是：

账号粉丝满500后，可以开通流量主变现功能。之后每发布一篇文章，就能在文中插入广告获得收益，微信会把收益直接打到你绑定的银行卡。

因此，公众号爆文0-1的最小MVP可以总结为：

确定赛道 - 搭建账号 - 开流量主 - 找对标（关键） - 写文章（关键） - 插广告获取收益。

其中，找到合适的对标账号和文章，并写出优质文章，是项目的关键步骤。

当然，完成最小MVP后，核心是提高写作质量和效率，所以搭建素材库对拿到结果也非常重要。

# 1.2.2 变现方式概要

公众号变现方式主要有两种：广告变现和打赏变现。

广告变现是公众号变现的主要方式，也是本期航海的重点。

广告变现还可分为以下几种（但公众号爆文项目不涉及）：

自主接广告

商家找我们接广告

文内带货

文末贴片广告

私域转高客单变现。微信公众号IP最大的价值，就是私域转高客单，本期航海第六章、第七章会着重讲解。

打赏变现通常出现在IP属性较强的公众号里（尤其是情感陪伴类），需要深耕至少3个月以上，才更可能出现高粘性打赏读者。一般单个读者打赏几十元不等，一篇收益稳定后打赏预估几百元；只有大爆款+高粘性作品，才可能一篇赞赏收益上千。

# 1.2.3 三种主流玩法

目前公众号不同人有不同玩法，甚至每个教练的方法都不一样，因此本次加了这部分内容。

# 1.2.3.1 玩法一：基础法

1、基础法主要是AI和人共创，以人工为主、AI为辅，比较适合找不到太多账号、没有IP追求、时间相对充足的人。

2、基础法处在中间位置。只要学会：结合RPA就是速通法玩法；增加人力就是进阶法玩法。这是一种进可攻、退可守的方法。

3、这种方法也比较消耗时间，各种步骤自己还是需要知道，基本要学完全部手册必修内容，比较适合有耐心的人学习。

4、速通法出现问题，也需要这个方法做基础，一步步分析；没有基础，自己也分析不出问题。

# 1.2.3.2 玩法二：进阶法 -IP 方向

1、进阶法致力于打造个人IP，AI使用程度低于20%，人员介入为80%以上。很多人都希望把自己的公众号打造成IP账号，引流到私域变现。

2、一旦账号养成，基本就能摆脱流量主的生命周期。

3、需要个人能够长时间输出自己的观点。很多人欣赏或认可一个IP，一定是被内容某一方面吸引住了。

4、文章质量需要消耗大量人力，而且变现周期较长，普通人大概在3年左右，还有人在5年左右，比较适合能坚持的人。

推荐学习内容：初阶篇（必修）整个章节

# 1.2.3.3 玩法三：速通法-自动化（选修）

1、速通法是当前比较热门的方法，AI使用程度在80%以上，人员介入低于20%，就是很多人说的“AI工具+RPA”批量化操作。

2、因为内容质量取决于AI工具，这类玩法需要大量账号，多账号多文章发布，拼的是概率。但好处是人工介入很少。

3、该方法人工介入很少，适合账号比较多的人，以及不希望投入大量时间的人。

4、这种玩法的风险：现在平台对纯AI产出内容是打压态度，也就是说这个玩法是用数量搏爆款，10个账号里能有1-2个已经算很不错了，随着人数增加，这个比例还会降低。

推荐学习内容：选修篇 整个章节

# 1.3 推荐机制

# 1.3.1 排序模型

在推荐系统中，系统会计算用户最近一段时间的累计值。这个累计值有两个关键要素：一个是统计时间周期，又称时间窗口；另一个是用户标签。

时间周期会随时间变化，因此时间窗口是动态变化的。根据动态变化情况，会有许多细分窗口类型，用来解决不同场景的问题。推荐系统模型会计算读者和公众号+文章的匹配度，专业术语叫排序模型。这个算法适用于最近一段时间，比如最近x时/天/周/月/年。

最近一段时间的实时阅读量、点击率、点赞率等等

最近一段时间的实时新增用户数、点击率、在看率、完读率等等

# 1.3.2 赛马机制

# 1.3.2.1 什么是赛马机制

赛马机制是推荐系统比较通用的机制，不仅适用于公众号，也适用于抖音、快手、视频号等等，建议大家看看。

1、为什么会出现赛马机制？

公众号、抖音、快手、视频号等平台都是过亿平台，每天估计有数千万创作者上传作品，这些作品有些优质，有些很差劲。

而作为平台，对优质作品肯定非常渴望。

因为优质作品可以吸引更多人把时间投入到平台，增加平台活跃度，促进平台正向发展。

平台想在每天上亿作品里筛选出优质作品，必然需要各种高效机制来筛选，赛马机制就是其中之一，也被自媒体作者广泛认可。

2、赛马机制底层原理

以公众号平台为例，当我们发布一篇或多篇文章到平台，会进行去重检测、机审、原创检测。其中任何一个环节出现问题，文章都会被打入低流量池，最终导致文章可能几十个阅读量就不动了。甚至检测出来太严重，直接就发不出去。

等上面的环节都通过以后，你发布的文章将进行分发，而此时别人的文章也在分发。你们的赛道相近、目标人群相似，比如大家都发情感类文章，系统肯定想把优质文章推到用户面前，这样才能吸引用户注意力。

那么，大家发的都是类似文章，系统怎么确定哪篇文章更好？

系统会把不同文章发送到目标人群，最开始曝光人群最多几百人，相当于让这几百人给文章打分。

这个打分就体现在文章数据上，比如完读率、点赞数、转发、评论区讨论等等。

完读率更高，说明用户看得更仔细认真。

点赞数高，说明很多人喜欢你的文章。

评论区讨论激烈，说明文章有争议、有话题。

那么，你的文章必然胜出。胜出的文章将进入下一个更大的流量池，再与下一个流量池的文章重复上面的数据对比。如果失败，就停留在当前流量池；如果胜出，继续进入下一个流量池，使文章被重复推荐，从而让阅读量不断达到5万、10万、100万、1000万。

这个过程就像多匹马赛跑，因此这种机制被形象地称为赛马机制。

# 1.3.3.1 如何利用赛马机制

我们已经清楚认识赛马机制，那它对我们有什么作用？主要从四个角度思考。

第一、少跟随主流，积极寻找蓝海领域。

即使小众也无所谓。因为这些领域意味着发文章的人少，只要你把文章写出来，和你竞争的文章会更少，文章就能一次次胜出，不断进入下一个更大的流量池。

中国有14亿人口，再小众的领域也有极为庞大的目标群体。只要你爆起来，十万加没问题。

第二、选择好发布时间，可能带来帮助。

正如大家所见，你发出的文章需要和其他人的文章赛马。那么错开别人的发布时间，有没有可能提高爆的概率？

所以，找到对标后，和对标时间稍微错开就行。比如对标是晚上8点发，你就晚上7点发。

当然，你也可以尝试其他时间发布测试，然后到微信公众号网页后台进入内容分析模块，多分析数据多复盘，看看自己账号哪个时间发布比较好。

第三、加强文章完读率等数据，因为赛马时会看这些数据判断文章是否优质。

标题吸引用户点击进来后，大家就着力提升这些数据。

比如，960多字起步，文章中就可以有两条广告，那么大家没必要写太多字，让用户更快看完全文，完读率相比长文必然更高。

文章开幕雷击也要运用好，并在文章中间、结尾等地方留下钩子，吸引用户不停往下看，从而提升完读率。

同时，文章里也稍微引导用户点赞、收藏、转发，这和短视频一样，许多博主都会在结尾让用户点赞收藏，都是同一个道理。

第四、学会与对标爆款文章差异化。

既然是赛马，写文章时就要仔细分析对标账号文章，做到人无我有、人有我优。

具体说，对标如果笼统写，你就写详细点；对标素材模糊，你就搞清晰点。

对标爆款文章论证一个观点只给三个角度分析，你就给五个角度，而且每个角度写得比他还生动。

对标标题写得不怎么样也爆了，那你就把那几个标题的起名方式利用起来，爆的几率也会更大。

如果你搞过视频，会发现这种方式也能适用，因为赛马机制是最通用的机制。

# 收尾提醒

写公众号时要守住底线，不要涉党涉政、不要造谣诽谤他人。否则轻则违规封号，重则被请去喝茶。

通常来说，选择一个领域，按照对标的选题、文章风格去写，除非自己飘了，基本不会出现严重违规。毕竟他们文章选题发出去、文章没被删除，说明还是可以发的。

对新手来说，目前违规最多的大概是滥用原创。出现这个问题，大多是洗稿导致，尤其是AI洗稿。

这里建议具备一种能力：在理解原文意思的基础上，用自己的话写出来，并尽可能写详细点，通常不会碰到这个问题。

通常保持上面几点，违规概率会少很多。
