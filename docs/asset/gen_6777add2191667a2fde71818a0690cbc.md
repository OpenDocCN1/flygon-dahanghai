# 4.2.1 AI头像壁纸号的三条变现路

目前常见的有三条：挂载平台、私人定制头像、收徒卖课。

# 4.2.1.1 挂载平台分收益

只要发布的头像足够抓眼，观众看到后就会想保存原图。这时可以在评论区或主页做引流，注意用各平台安全的引流方式：让用户搜索某某小程序、输入某某口令，就能保存原图。人被引到小程序后，下载图片需要看一次广告，每一次广告观看都会带来收益。
[PRE12]
这种方式最简单：作品有流量、有人下载，就有收益。不过单号收益通常偏低；如果精力和时间允许，可以同时运营几个号，去搏爆款概率。

# 4.2.1.2 接私人定制头像单

内容足够吸引人时，观众会产生定制头像的需求，这时就可以接单。可以在平台店铺挂商品等客户下单，也可以引流到微信、闲鱼、淘宝等渠道成交。拿到客户照片和要求后，制作个性化头像。

这类客单价跨度很大：可以做1元引流产品，顺带把流量导入私域；也可以定9.9元走薄利多销；还可以标更高价格，但相应地要提供更多、更好的服务。

# 4.2.2 AI头像壁纸号精准起号法

起号方法就两个字：
1.抄
2.量

# 4.2.2.1 巧用“抄”与异常值

1）爆款往往是重复出现的。与其自己闷头琢磨，不如“抄”爆款见效快。这里的“抄”不是盗图搬运，而是找到别人的爆款笔记，拆解其关键词，再复刻出同风格头像。

2）异常值，就是普通数据里冒出来的不普通表现。
[PRE17]
比如一个平时笔记平均只有20—30赞的博主，突然有一条冲到2000赞。博主本人可能没留意，但你要意识到：这是宝藏。这条内容能跑出来，一定做对了某些平时没做对的点。把它挖出来、复制到位，成功概率就会明显提高。

# 4.2.2.2 靠数量取胜

爆款本身有概率。同样的内容，别人发能火，你发可能就凉。这时用数量去对冲概率，相当于用数学思维对抗不确定性。只要作品类型和质量都向爆款看齐，发布量又足够大，长期来看不可能起不来。
[PRE18]

# 4.2.4 私人定制头像怎么操作？

笔记有流量后，可能会有观众来找你定制头像。做法就是用“图生图”：给AI一张照片，让它在照片基础上继续创作。

想做出更好的定制效果，对照片有要求：
1.正脸照片；
2.图片尽量高清；
3.背景尽量干净。

下面分享两种不同风格的定制头像，操作步骤一致，只是部分关键词不同。
具体流程：
1.把图片发送到Midjourney；
2.写关键词；
3.多刷新图片。

# 4.2.4.1.2 写入关键词

关键词由三部分组成：原图链接＋原图描述＋出图风格。

# 4.2.5 让AI头像更贴近本人的方法

在Midjourney里，即使已经给AI喂了图，生成的人物仍可能过于随机，经常不像本人。这时可以用InsightFace换脸插件，换脸后的图片会更接近本人。

具体步骤：
1.用图生图的方法先生成一张照片；
2.把换脸机器人邀请到自己的频道；
3.上传人脸照片；
4.进行人脸替换。

# 4.2.5.1 在Midjourney里垫图出图

这一步和第五部分一样，不再展示具体操作。目的是先得到一张风格符合预期、外形也比较像本人的照片。

# 4.2.5.2 邀请换脸机器人

这个换脸机器人不是Midjourney自带插件，不能直接在MJ里搜索。点击下面链接，可以把机器人邀请到自己的服务器：
https://discord.com/api/oauth2/authorize?client_id=1090660574196674713&permissions=274877945856&scope=bot
邀请完成后回到Midjourney，点击右上角的人形图标，就能看到换脸机器人已经进来了。

# 4.2.5.3 上传人脸照

接下来上传要替换的人脸照片，最好是正脸、无遮挡、高清的照片。在最下面的文本框输入“/”，点击左侧换脸机器人图标，选择“/saveid”命令。
[PRE37]
把照片拖进来，在“idname”里输入这张照片的名字，按回车发送。
[PRE38]
看到机器人回复“idname hg created”，就说明人脸上传成功了。

# 4.2.5.4 完成换脸

接着就可以替换人脸了。输入“/swapid”指令（它和上传人脸的“/saveid”有点像，别搞混）。

上传一张需要换脸的照片，在下面输入刚刚上传的人脸名字，回车发送。
