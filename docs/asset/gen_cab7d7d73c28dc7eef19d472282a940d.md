# 新加坡凭什么吸引Web3创业者

在区块链与加密资产领域，新加坡的规则相对清晰，对Web3释放开放信号，也是较早行动的先行者。全球Web3创业者因此向此地聚集，其中不少团队来自中国。

2022年4月，新加坡金融管理局局长表态，希望把新加坡打造成负责任的全球加密货币枢纽：既接纳有创新能力的参与者，也要求具备过硬的风险管控实力，后续还会持续加码相关风险治理。

**代币如何归类**
当地依据数字资产的类型来划分代币，包括证券型代币、支付型代币和实用型代币三类。

**牌照与金融监管**
新加坡金融管理局会向达到监管门槛的企业核发牌照；获批之后，合规的数字加密货币业务方可开展。

**税务安排**
当地对商品和服务税实行免征。

从代币分类、持牌经营到税务优惠，新加坡为Web3企业提供了一套相对可预期的落地环境。
