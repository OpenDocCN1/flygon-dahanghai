# 1.2.1 用成就事件挖出你的优势动力

前面我们聊过，优势可以理解成：同样一件事，你总比别人做得更轻松、更出色。当天赋被充分施展时，心里会升起一种踏实的成就感。所以，不妨把这些让你兴奋、有成就感的时刻记录下来，然后回头看看——这些时刻是否共享着某种相似的模式？如果有，那个反复出现的“模式”，很可能就是藏在你身上的天赋线索。

想从成就事件里找优势，这是最轻松的起点。你只需问问自己：我真正做成过哪些事？在这些事里，我是靠什么特质拿到结果的？

拿我朋友 L 来举例。她是一位做投资的人。

她从小对数字和底层规则就格外敏感，数学成绩一直名列前茅（成就一）。

上大学时，她爸一次性转给她四年的学费。她没有按部就班地花，而是拿这笔钱去做投资，结果日子过得相当宽裕，对她来说赚钱好像只是一场数字推演的游戏（成就二）。

工作以后，她把重心放在炒股上。每次打开盘面，她都能很快捕捉到买点和卖点的信号，整体收益一直挺稳定（成就三）。

平时大家聊起投资，她扫几眼数据，就能立刻解读出每个数字背后的逻辑，并顺势推断出什么时候该出手。她也不怕别人质疑，反而很享受用逻辑去验证自己的判断，靠着这份专业度吸引了不少客户（成就四）。

从小到大，她对数据、逻辑和因果关系的敏锐度始终没变，分析能力一直很强，而她的每一次成就，几乎都是靠这种能力换来的。

把她的这种特质放进盖洛普体系里，对应的正是“分析”才干：对数字高度敏感，喜欢追根究底，没法接受没有证据的结论，相信逻辑而非感觉，常常能一眼看穿事物的本质。

你可以像这样，列出自己人生中 3 到 5 个让你有成就感的具体事件，然后找出它们的共通点。你会发现，在这些与“做成事”有关的人和事里，我们总会用某种特定的方式去取得一个个阶段性的胜利。那个一次次自动浮现的“方式”，往往就是你的优势所在。
