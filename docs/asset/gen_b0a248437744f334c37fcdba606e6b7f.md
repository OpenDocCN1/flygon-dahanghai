# 4.2 把优势视角带进关系

盖洛普的优势方法，不只在团队管理里有用，放到人与人的相处中同样成立。它提醒我们：每个人都有自己顺手的才干组合，关系里的很多别扭，未必是谁故意为难谁，而是彼此的行为方式和需求重点不一样。

真正把这套思路用起来，第一步是看清自己的优势如何影响沟通、决策和协作；第二步是理解对方在意什么、擅长什么，不急着用自己的标准评判。与其盯着“你怎么跟我不一样”，不如换一种问法：“你的优势能补上我的哪块短板？”当双方能用优势语言描述彼此，标签和抱怨就会少很多，理解与信任更容易长出来。

在合作中，还可以主动做优势互补：让擅长统筹的人理清方向，让善于共情的人照顾感受，让行动力强的人推动落地。盖洛普在关系里的价值，不是给人分高低，而是把差异看成资源，让相处更省力、协作更顺畅。
