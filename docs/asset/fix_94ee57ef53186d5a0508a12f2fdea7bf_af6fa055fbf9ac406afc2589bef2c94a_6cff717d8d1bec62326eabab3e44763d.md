# 3.1.5 容易出爆款的选题，通常有三个特征@开卷🌀

找选题的办法不少，手册里已经写了很多。这里补几条我自己的体会：入池率能做到百分之百，靠的就是在选题阶段多留心。

刚做号时，我也试过不少账号和方向。时间精力有限，必须判断哪些题更值得做、更有机会冲爆。这个问题让我头疼了好几天。后来我总结出，能大概率进流量池、阅读也不差的选题，往往具备三个特征。

# 3.1.5.1 选题里要藏着反常

新闻圈有句老话：平常的狗伤了人，算不上新闻；反过来才抓眼球。

带反常属性的选题，本身就有新闻感，自带流量密码。写得稳，阅读量不会差。

比如：“有人做内容号每月进账五万，却动了回公司打卡的念头。”

你可能会说，这和“开幕雷击”里的金钱元素有关。但我也观察过，带钱元素的不一定爆；而我写过的方向里，只要内容有反常点、有看点、正文也过关，基本都爆了。这就是反常的魅力。

后来我发现，我的百万爆款也有人仿写，但数据大多不理想。原因很简单：这些作者把最重要的反常点改掉了，文章一下子“顺拐”了，本来有看点的内容，变成了廉价的鸡汤。

看看下面三个标题，你觉得哪个选题会爆：

1、寒心！男子三次遭犬伤，围观者竟无人伸手！
2、震惊！同一名男子三度被犬所伤，居然在街头做出离谱举动……
3、怒了！男子三度遭犬伤，反被犬主索赔五千……

答案先不说。选题看多了，大家可以自己琢磨。

# 3.1.5.2 同赛道里出现三篇以上十万加，成功率更高

我突破百万的那个爆款，就是因为看到多个账号都出了十万加。后面的五十万加、二十万加和十万加文章，选题也至少有三个爆款样本托底。

有一次，某个选题我只搜到两个十万加样本，但我自己非常感兴趣，还是写了。最后阅读量停在五万附近，有点遗憾。

为什么要把十万加当成目标？

因为同样的工时，做出一篇十万加，胜过两篇五万加，投入产出比更漂亮。这也是手工打磨内容的人，靠质量实现弯道超车的方式。

# 3.1.5.3 选题不必显得高级，关键是让读者有话可讲

这个规律，在抖音、小红书、公号上都通用。

头部玩家的百万爆款，可能来自博主独到的观点；普通人的百万爆款，往往只是关注到了一个大家都能各抒己见的话题。

比如：

高考成绩只比重点线高十来分，选普通重点院校，还是去稍好的普通本科？
手头三百万，是买城中心老旧小户型，还是城郊大房子？

这类见仁见智、大众又关心的话题，讨论热度一高，很容易出爆款。

我的公号航海项目跑得比较顺，很大一部分原因，是项目初期我把八成时间花在了选题上。

说到找选题，常见疑问是：数据网站的付费会员是不是非买不可？

至少刚入门时，我的答案是不是。

不管是抖音、小红书、公号还是其他平台，新人入场做内容，第一步都是熟悉平台的内容生态。如果不去亲自刷文章，就不知道哪些好、哪些不够好、哪些很糟糕。

数据网站的好处是能快速找到数据好的内容，缺点也在这里：好坏是相对的。新人如果只看“数据好”的内容，就分辨不出它的相对优势在哪里，也判断不了它是偶发爆款、账号权重高，还是内容真有价值。

所以，打基础的阶段，我的内容全部手工做，选题也全部手工刷。这是新人到任何平台，只要眼光稍微放长远一点，都必须做的事。我也相信，这是准备深耕内容的人必须具备的基础能力。

未来我会不会用数据平台？可能会。因为我现在明显感觉到，纯手工刷选题、写文章，即使全职做，一个人打理五个号，体力和脑力也已经到极限。如果想更轻松地运营更多号，在对平台内容有了真切理解之后，确实需要外部工具辅助扩规模、提效率。

# 3.2 正文怎么写：套模板

# 💡

**内容提要**

一般来说，文章正文都有套路可循，也有现成模板可以模仿。我们要做的，就是按模板搜集素材，再做润色填充。

这次训练涉及五类稿件，爆款骨架分别如下：

工作故事：题目＋主线＋评论区吵点＋收束建议
热点评论：题目＋事件本身＋立场/看法＋收尾
剧评：题目＋情节＋观点/解读＋收尾
法律新闻：地点＋冲突＋新闻＋网友观点＋法条＋应对＋互动
历史故事：先抛问题＋再答问题
情感故事：题目＋主角＋主干＋收尾

下面具体讲，不同类型爆文可以用哪些模板。

# 3.2.1 职场类：爆款模板@枫宇翔

职场故事文的公式是：题目＋主线＋评论区吵点＋收束建议。

在我看来，职场爆文七成以上的功夫都在题目上。题目写得好，进入流量池后，内容怎么写，阅读量都不会太差。

如果一定要固定一个模板，可以记住这个简单版本：

第一，先确定选题，把主题截图放到文章顶部，围绕它展开讨论、分析原因。

第二，把评论区网友的不同观点放进文章，最好挑争论比较激烈的，做对比解析，再给出自己的看法。

这里给大家一个对标号：早先名字带“程序员”，后来改成“职场故事”相关。他很会编故事，偷懒的时候就用一张图，或者几张网友评论截图来讨论。

另外，分析原因、展开讨论时，最好学会讲故事。比起干巴巴的分析，故事更有吸引力。多看看这个号，你就有感觉了。

[PRE3]

# 3.2.2 热点类：爆款模板

热点类文章的公式可以总结为：题目＋事件本身＋立场/看法＋收尾。

# 3.2.2.1 案例一：骨架与鳞片

一篇完整的文章像一条龙。文章的梗概，也就是事情本身，是骨架；散落在文中的金句、观点、细节、态度，是鳞片。

骨架的要求很简单：把事情讲明白。如果事件太复杂，需要很长篇幅才能说清，那就只花笔墨讲清一个侧面，千万别追求全面描述。事情讲复杂了，篇幅会被拖长，完读率也会受严重影响。

鳞片则用来点明态度和观点。以前写故事时，鳞片都用来表达故事细节，让故事更真实可信。但写热点文时，素材都是真实发生的热点事件，不需要再靠细节证明真实性。加了反而可能引发不好的效果，比如“二更食堂”那次负面事件。

在热点文里，鳞片只负责站队、表达态度、写清观点，其余作用一概不要有。

以上就是热点文的写法，其实很简单。陈述事件时，一旦情绪上来了，就用词句把它写出来，用它争取和你共鸣的读者。记住这一句话就够了。

# 3.2.2.2 案例二：两种难度的热点文公式@妞妞💋

一篇简单的热点文＝题目＋开头＋事件陈述＋结论（对标：泡哥看世界）

一篇有深度的热点文＝题目＋开头＋事件陈述＋对比论证（可省略）＋结论（对标：桌子的生活观）

拆解公式：

1）题目：记得要有“开幕雷击”，控制在五十字以内。

比如：突发！“中石油牵手门”男女主再曝大料，这背后可不简单

2）文章开头：一百字左右。

可以写自己对这件事的领悟，也可以直接开始写事。

比如：

① 生活经常给我们惊喜。就像成都一个摄影师小哥玩个街拍，居然拍出了国企大领导“牵手门”丑闻。

② 某月某日，一个话题冲上热搜。“宝妈因孩子吃了同学生日蛋糕发飙”，很快引发网友热议。怎么回事呢？

③ 万万没想到，珠穆朗玛峰也会发生这样的事。近日，#珠峰攀登者放弃登顶救起濒死女子#，话题冲上热搜第一。

④ 大家还记得十天前武汉教师碾压学生致死事件吗？没想到，学生竟然在学校被自己的老师碾死。然而事情刚过去几天，悲痛消息再次传来：被撞孩子的母亲，在孩子去世十天后，也从二十四楼一跃而下。

等等……按自己习惯和擅长的来就好。

3）事件陈述：五百字左右。

把整件事发生的时间、人物、地点、经过讲一遍，配上事件相关图片。

4）对比论证：三百字左右。

这一步可有可无。热点事件正火爆、热度很高时，可以省略；反之，加上更好。做法是去网上搜一两个相似类型事件，和这个事件作比对，再加几句点评。

5）给出论点并激发读者情绪：三百字左右。

这里写出对事件的看法和论点，可以带点情绪，愤青一点。

例文：

例文1：某负责人带女员工在太古里逛街被拍！女方外貌普通但胜在身材肤色——这是不做对比论证的直给写法

例文2：“我儿子被投毒了！”家长群聊天记录流出后，我看得好窒息……有对比论证有深度的写法

我们对照前面说的“拆解公式”，看例文2的具体构成：

① 题目：要有“开幕雷击”，五十字以内。

“我儿子被投毒了！”家长群聊天记录流出后，我看得好窒息……

② 文章开头：一百字左右。

六月六日，一个话题冲上热搜。“宝妈因孩子吃了同学生日蛋糕发飙”，很快引发网友热议。怎么回事呢？

③ 事件陈述：六百字左右。

从“有网友发帖分享了一段家长群中的对话，从聊天截图我们得知：六一儿童节，有位家长带了蛋糕，给孩子们集体分享”，到“再毒的奶油蛋糕，其危害性也比心灵的终极污染小得多”。

具体内容大家去看原文：“我儿子被投毒了！”家长群聊天记录流出后，我看得好窒息……

④ 对比论证：三百字左右。

论证1：某知乎写手讲过自己的经历。
论证2：有网友说，妈妈的一个同事因为孩子吃了辣条，逼孩子吃了成人两倍剂量的泻药。
论证3：主持人倪萍分享过一个故事，让我十分感触。

具体内容大家去看原文：“我儿子被投毒了！”家长群聊天记录流出后，我看得好窒息……

⑤ 给出论点并激发读者情绪：三百字左右。

从“只有自己的内心得到过满足，才不会匮乏”，到“没有人一生都在吃标准的食物，也没有人一生都在走正确的道路。对孩子和家长来说，适当保持一点松弛感和容错率，或许我们都能活得更轻松”。

# 3.2.3 剧评类：爆款模板

写剧评的公式是：题目＋情节＋观点/解读＋收尾＝剧评。

1）观点文样式的剧评，无论情节还是细节，都要有一个落脚点，这个落脚点就是你的观点。

比如：某古装剧里，两位男子求娶同一女子，目的看似相同。读者会好奇，到底哪个目的？

剧情是：一位男主算计求娶女主。他明知女主与另一位公子即将订婚，故意把那位公子的青梅表妹送到京城。果然，表妹请求给公子做妾，公子心动了，故意等女主妥协。双方僵持时，男主求娶女主。

观点：适合！对公子来说，无论女主的手段还是家世，都比较适合他；对男主来说，同样合适，不过不是家世，而是品行和手段。毕竟男主心中谨记父亲的话：“娶妻娶贤。”女主各方面都合适，有主意有手段，还能与继婆婆抗衡。

收尾：婚姻的本质不是爱情，而是适合。互相扶持的婚姻，比单纯的爱情强得多。

就像女主所言：“婚姻里未必一定需要爱情，作为女人也不应该把眼光放在儿女情长上，要实现经济和精神的独立，去看看更广阔的世界。”

这篇跑到3.8万阅读，带来两百多元。

再比如：某剧四姐妹里，行苟且之事的那位反而嫁得最好。读者会好奇，为什么她做了如此不光彩的事，还是嫁得最好？

剧情：她身为家中女儿，为嫁入高门，不顾家族名声，与伯爵府公子苟且，逼着全家成全她，帮她嫁入梁家。为什么说她嫁得最好？虽然她以不光彩手段嫁入梁家，但丈夫宠爱、婆婆和善，这一切都符合她高嫁的期待。

观点：嫁得好，不代表过得好。

细节说明：她明明是正房，却把全部心思放在与妾室争宠上，还给丈夫主动纳妾，以至于家中每天鸡飞狗跳。

收尾：她原本在四姐妹中嫁得最好，可她却把日子过得一地鸡毛。反观其他三个姐妹，无论用手段还是计谋，都把不如意的婚姻过成了想要的生活。

这篇阅读四万加，带来两百八十多。

这两篇都是题目＋细节＋观点＋总结，构成完整剧评。

2）还可以单纯解析剧情，从剧情引申出暗线以及主角的命运。

比如：某剧里，曹姓女子胸口半敞求欢，才懂贺家为什么不要女主。

剧情是：曹姓女子如愿成了表哥的妾室，可生活没有想象中快乐。只能说吃喝不愁，其他什么都没有。贺家祖母还总拿捏她，表哥对她也没多少怜惜。她借口生病诓骗表哥，有了主动求欢的场景。

解析：她不懂，自己成为贺家妾室，才更容易被贺家拿捏。一来妾室地位低，说白了比丫鬟高不了多少；二来当家主母打罚妾室名正言顺，不用顾忌情面。

收尾：她的得寸进尺，让表哥心中那点情谊和愧疚早就磨灭了。果然，人在选择时会衡量，但付出感情被欺骗时，就会心灰意冷。

这篇采用剧情描述＋解析＋收尾，阅读十万加，带来八百多。

但有一点要注意：不要为了博眼球自己编剧情，很伤账号。

# 3.2.4 法律类：爆款模板

新闻爆款模板，口诀是“说地名＋列冲突＋讲新闻＋网友看＋说法律＋怎么做＋引互动”。全文一千二到两千字，不得超过两千字。

下面进入这个七步模板。

说地名：一定要列出省市，具体到地级市。这是第一个断句要做到的事，字数简明扼要，一般写成“近日X省X市”。

列冲突：等同于“开幕雷击”，位置在第一自然段前五十到一百字，紧随“说地名”之后。新闻的核心冲突是什么？换位思考一下，如何用短短几十字，让读者和你一样血压上升？这就是“列冲突”要完成的任务。

分享一个展现千万的爆款例子：

“近日某地，一女子去加油，加满后一看傻了眼：加注量远超车辆标注容积，并且原来还有余油。面对质疑，加油站的人竟说没有问题。女子一气之下，去4S店做了疯狂的举动。”

开头除了常规的“近日X省X市”发生了什么事，还可以直接用情绪化词语吸引读者，比如：“令人发指！太残忍了！严惩不贷！太坑人了！太猖狂了！”

[PRE5]

这样的开头如果使用“残忍”等词语，可能会有一定风险。

接下来是“讲新闻”：用四百到八百字，把新闻来龙去脉讲清楚。这里可以放慢节奏，语言要朴实生动，像日常和熟人侃大山一样，千万别用官方书面语。

另外注意：这里不允许用插叙、倒叙，否则读者看不懂，直接跳出，后面篇幅就全浪费了。

新闻叙述过程中，尽量增加一些有波折、吸引眼球的词语，让读者愿意跟着节奏往下走。比如文章中的“酝酿着一个疯狂的想法、目不转睛”，以及女子联系记者、联系相关计量部门、咨询汽车专家等各个角度，让读者跟着你的思路走。

下面是“网友看”，篇幅两百到三百字。可以从网上新闻账号评论区找高赞评论，放几条进去即可，这个很简单。

关于网友看法，一方面可以寻找爆款中评论多的观点来引用；另一方面，如果你写的数量足够多，其实心里已经有很多种观点，也可以自己编写。反正都是“网友说的”，对错无从查证，只代表网友个人观点。可以从正面、反面或中立面分析，最后再加一小段自己的观点。这样“网友看”就比较全面，既有别人的观点，也有自己简短看法。

然后就是“说法律”。特别强调一句：就算你没有法律资质，只要援引的法律条文没问题，照样可以出爆款。

这需要平时了解一些法律知识，多刷知乎上的热点问题，他们会代替你列出法律条文，省得自己找；也可以存一些电子版法律资料，到时候按关键词检索，找对应条文。这一步看似很难，但在信息时代，掌握最基础的关键词检索技巧，就一点问题都没有。这段篇幅也是四百到八百字。

简述完法律条文后，要跟上具体到本案、本事件的分析看法，以及根据相关法律条文如何处罚。

然后是怎么做：告诉读者遇到类似窘境时应该做些什么。放在倒数第二自然段，有几句话就行。如果觉得前面叙述不够，或者字数不够，这里还可以增加自己的亲身经历，分享自己遇到类似事情时怎样处理。如果没有发生，可以自行编撰，目的就是引发读者共鸣。

最后是引互动：留几个问题诱发评论区互动。放在倒数第一自然段，两三个问题就行。
