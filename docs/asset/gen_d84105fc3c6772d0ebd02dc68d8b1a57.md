# 1.2 时间管理的三大坑

误区一：以为时间管理，就是“管住时间”

静下心来想想，时间其实有四个无法回避的特点：它从来不停下脚步；没有人能真正掌控它；无论做什么事，都离不开它；一旦过去，就再也回不来。

这样一想就明白了——时间根本管不住。但好消息是，时间也是世界上唯一对所有人都公平的东西。哪怕身家过亿的富豪，想要一副好身材，也得老老实实花时间去健身房流汗。所以说，时间管理的对象从来不是时间，而是我们自己。把自己管好了，才能用好时间，去做真正想做的事。

误区二：以为时间管理，是从列计划开始的

你是不是也这样：认认真真做了一张特别完美的计划表，结果一天下来，现实却完全是另一副模样？更崩溃的是，这种“计划很美、执行很废”的循环反复上演，最后你开始怀疑自己：是不是我天生就不是自律的料？

为什么那些看似无懈可击的计划，总是活不过三天？底层原因在于，惯性才是我们行为的主导者。

研究表明，一个人每天95%以上的行为都来自惯性。那些看起来高度自律的高手，其实不过是早就把该做的事情变成了习惯。你指望一天之内，就走完别人花了一年甚至几年才走完的路，这怎么可能呢？真正可持续的改变，只能靠一点点优化自己的时间分配——这正是长期自律的人一直在做的事。

还记得网上流传过的那张清华学霸时间表吗？主人是特等奖学金得主马东涵。表上从周一到周日，从早上6点到凌晨1点，排得满满当当。很多人第一眼都以为那是计划表，但马东涵后来专门澄清过：那其实是记录表。

[PRE1]

所以，开启时间管理的正确姿势不是列计划，而是先记录。

这方法的源头，可以追溯到时间管理大师柳比歇夫。他一生写了70多部专著、12500页论文，自学了3门外语，收集了13000只地蚤标本，还留下大量通信和回忆录。更让人吃惊的是，他每天还能睡满10个小时。

是不是觉得不可思议？再看看普通人和高手的差别：普通人习惯“先计划，再执行”，但因为缺少记录和反馈，往往坚持不了几天就没了下文。高手则反过来——“先记录，再复盘”，看清自己真实的时间去向，找出可优化的空间，再设定计划并执行，然后继续记录、复盘、优化。如此循环往复。

[PRE2]

而高手中的高手柳比歇夫，把这套循环坚持了整整56年。可见，哪怕天赋再高，想在时间管理上有所成就，也离不开日复一日地下笨功夫。普通人想要掌控自己的时间，同样需要按照“记录—复盘—计划—执行”的节奏反复打磨，日拱一卒，才能真正做出价值。

换个角度理解：人生就像一条河，从出生起就一直向前奔流。你不可能把长江直接改道成黄河。真正能落地的做法，是先搞清楚自己现在身在何处，再朝想要的方向，一点点挖出新的河道。所以，别再迷信那些漂亮的计划表了，正确的时间管理，从记录和复盘开始。

误区三：以为计划中断了，就是不自律

现在各种打卡活动特别流行，而且大多要求“一天都不能断”。受这种风气影响，很多人觉得高手就是那些风雨无阻、每天读书锻炼的人。可现实真是这样吗？

高手也是普通人，也会有突发状况，也会身体不适。除了极少数意志力超强、条件也允许的人，绝大多数人根本做不到天天坚持。所以，真正拉开我们和高手距离的，不是坚持的连续性，而是对“自律”的理解。

普通人辛辛苦苦坚持了7天，第8天因为有事断了一次，立马陷入强烈的自责和愧疚，然后索性彻底放弃。而高手遇到同样的情况，会坦然接受这一天的中断，第二天接着继续。把时间拉长看，断断续续地积累，远比三天打鱼两天晒网式地冲刺强得多。

打个比方：每坚持做一次，你就往家里搬了一块金砖。哪怕第二天没搬，前一天的金砖也不会消失，对不对？所以，中断不可怕，可怕的是中断之后不再开始。我们付出的每一点努力都没有白费，都会沉淀成属于我们自己的财富。

别再纠结连续打卡了。真正的时间管理，积累比连续更重要。
