# 引言：先看懂这趟 21 天航程

## 开船前第一课：方向比工具更重要

### 项目全貌：用垂直小号 + 内容自动化跑闭环

1. 这个项目究竟在做什么

“垂直小号-内容自动化”聚焦👸号垂直内容号，借助 WorkBuddy 与 Skill 提升内容生产效率，把发布、变现等基础环节跑成闭环。

它并不只是教人“让 AI 代写文章”。真正的做法是：先选定清晰的垂直赛道，准备 1—3 个👸号小号，再围绕热点选题和内容 Skill 持续产出符合账号定位的文章，并完成发布、流量主设置、商品挂载等动作。新手要完整走一遍“选题 → 成文 → 发布 → 变现设置 → 数据反馈”的流程。

为什么选👸号垂直小号？原因有两层：

短期看，👸号依然适合承接垂直内容、搜索流量和私域信任。对第一次做内容项目的新手来说，从👸号小号入手，比一上来就搭复杂矩阵、做复杂产品更容易进入实操状态。

长期看，垂直小号不是发一两篇文章就结束，而是围绕细分人群持续输出，逐步积累账号资产，再延展到流量主收益、商品挂载、带货等变现路径。

因此，本期航海的核心玩法是：先围绕垂直赛道完成账号准备与定位；再借助热点库、WorkBuddy 和内容 Skill 快速生成并发布文章，建立稳定节奏；后续根据数据反馈，继续学习爆款拆解、运营调整和变现拓展，把这套方法长期用下去。

21 天内，在航海专属工具和手册的指引下，船员以 1 个👸号小号为基础，按每天发布 2 篇内容的节奏推进，累计完成约 40 篇垂直内容，并完成流量主、橱窗带货等基础变现设置，最终拿到可复盘的发布记录和数据反馈。

3. 学习节奏：边学边做，分段推进

这次不要求你先刷完所有课程、摸透所有工具再开号，而是围绕 3 份阶段作业，每完成一个关键结果，就进入下一阶段。

21 天要跑通的路径是：

账号定位与配置 → 首篇文章发布 → 连续更新 → 数据复盘与下一轮计划

建议每天投入 1—2 小时：一部分时间学当天方法，一部分时间操作自己的账号，最后留几分钟记录结果和问题。学习的结果不是“课程看完了”，而是账号多向前走了一步，手里多了一份能复用的记录。

3.1 账号启动：先定位再动手

学习重点：明确方向、搭好基础、学会使用工具。

刚开始别急着写文章。先回答三个问题：这个账号服务谁？持续写什么？读者为什么要关注？想清楚后，再完成👸号主页配置，让头像、昵称、简介等信息能体现内容方向。

接着安装或登录 WorkBuddy，导入同赛道 Skill，做一次简单写作测试。测试不是为了产出正式文章，而是确认工具能否理解你的账号定位，Skill 的输出是否符合赛道和用户需求。

这一阶段的学习顺序是：

1. 了解垂直小号的基本玩法，选一个自己愿意持续投入的细分方向；
2. 观察同赛道账号，初步理解目标用户和常见内容类型；
3. 完成账号名称、头像、简介等基础设置；
4. 写出一句话账号定位；
5. 导入同赛道 Skill，发起一次写作测试；
6. 根据提交模板整理截图和文字，完成作业。

完成这一关，说明你已经从“想做一个👸号”进入“知道这个号写给谁、准备写什么，并且可以开始生产内容”的状态。

3.2 首篇文章：从热点到发布走一遍

学习重点：从热点中找选题，用 Skill 生成文章，并完成发布前检查。

完成账号准备后，马上进入真实内容生产。此时不要同时测试太多赛道和工具，先围绕一个与账号定位相关的热点选题，完整走一遍文章生产流程。

你需要逐步掌握：如何判断一个热点是否适合自己的账号，如何把选题交给 Skill 生成初稿，如何对初稿进行人工修改，以及如何完成👸号发布前的关键设置。

这一阶段的学习顺序是：

1. 从热点库、对标账号或用户问题中选择一个合适的选题；
2. 使用 WorkBuddy + Skill 生成文章初稿；
3. 重点修改标题、开头、人设表达、观点补充或同质化表达中的 1—2 处；
4. 完成配图、排版、原创、广告、封面图、赞赏或带货商品等适用设置；
5. 发布文章，检查文章页面和设置是否正常；
6. 记录这次人工修改的原因，提交作业。

这一关的重点不是证明 Skill 可以代替你写文章，而是学会把 Skill 变成自己的生产工具：机器负责提高效率，你负责选题判断、内容取舍和最终审核。

完成这一关，说明你已经跑通了一次“选题—成文—修改—发布”的完整流程。

3.3 连续更新：把发布变成节奏

学习重点：保持发布节奏，建立记录，开始看数据。

首篇文章发布后，学习重点就从“能不能发出来”转向“能不能持续发、哪些内容值得继续做”。这一阶段按照每天 2 篇的节奏推进，边发布边积累自己的选题库、文章记录和数据样本。

你需要逐步掌握：如何记录每篇文章的发布时间、标题、内容方向和链接，如何查看后台可见数据，如何通过不同文章之间的表现差异，判断下一轮内容应该怎么调整。

这一阶段的学习顺序是：

1. 持续从热点、对标账号和用户需求中寻找选题；
2. 按照每天 2 篇的节奏生产和发布内容；
3. 用一张表记录已发布文章，逐步形成连续发布记录；
4. 定期查看阅读、推荐、关注、互动、流量主收入或商品订单等数据；
5. 对表现较好的文章，拆解其选题、标题、开头和内容结构；
6. 对表现较弱的文章，判断问题出在选题、标题、内容匹配还是发布设置；
7. 写出下一轮要保留、调整和暂停的内容方向，完成作业。

完成这一关，说明你已经不再只依赖感觉写文章，而是开始用真实发布和数据反馈决定下一步怎么做。

3.4 让方法延续到航海之后

完成作业不是航海的终点，而是从“跟着任务做”进入“自己运营账号”的起点。后续继续保持发布节奏，同时把前面形成的记录和复盘结论用于下一轮选题。

建议重点做好三件事：

• 保留表现较好的选题类型，继续做相近主题和系列内容；  
• 根据数据调整标题、开头、文章结构和发布节奏；  
• 检查流量主、橱窗和商品挂载等基础变现设置是否适合账号当前阶段。

21 天结束时，你应该拿到的不是一篇孤立的文章，而是一个已经完成基础定位、跑通过内容生产流程、留下连续发布记录，并且知道下一步如何调整的👸号垂直小号。

3.5 每个阶段都按这套学习法推进

每一阶段都按照“先学方法、再做操作、最后交作业”的顺序推进：

1. **先学方法**：只学习当前阶段需要的内容；
2. **马上做操作**：把方法用到自己的账号上；
3. **留下结果**：保存截图、文章链接、数据或文字记录；
4. **完成提交**：按作业模板提交，不遗漏必填项；
5. **带着反馈前进**：把这一阶段遇到的问题，带到下一阶段解决。

如果某天时间不足，优先完成当前阶段对应的核心结果。先让账号向前推进，再利用后续时间优化文章、补充记录和完善工具流程。

第一步：打开🛰️，进入“👸号盒子”。[PRE27]
