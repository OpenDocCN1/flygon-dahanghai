# 6个月14万+：朋友圈成交复盘

我是小鹿，生财圈友。早期做分销，后来逐步找到自己的方向，也有了属于自己的产品。这次想复盘的是：怎样在朋友圈做精准触达与成交，并在六个月里累计变现14万+。

今年5月航海期间，官方邀请我登上“朋友圈运营航海”船做嘉宾，分享的主题是“朋友圈广告这么发，用户不反感还想追着看”。那场我重点讲了广告应该怎么发，才能让人愿意看下去。

在之前分享的基础上，这次我把实操拆成六个板块：一是朋友圈变现分三步怎么走；二是朋友圈整体内容框架如何安排；三是借故事带动内容与成交的方法；四是一套可复用的文案写作公式；五是广告内容怎样发得更自然；六是避免长文被折叠的小细节。六个方面合在一起，完整复盘我从分销起步，到明确个人定位、做出产品，再靠朋友圈精准成交，六个月实现14万+变现的路径。
