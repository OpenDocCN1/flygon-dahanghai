# 自带的文件夹不顺手？试试给笔记搭个“目录页”

如果你觉得笔记软件自带的文件夹收纳方式不太顺手，完全可以用一张多维表格充当自定义目录。像飞书里那个云文档文件夹，风格就比较传统；反倒是知识库提供的页面树，用起来更趁手。

先说清楚做资料整理的底层目标：一切为了方便随时调用。归类、打标、编号、命名、搜索这些操作，都是为了把散落的信息从“乱”变成“有点序”，或者说，乱而有序。

注意，是乱而有序，不是极度整齐。

资料完全无组织，找东西就会很痛苦；资料被管理得过于极致，比如每份文件都要塞进表格、每个文件夹都无一处遗漏，那维护成本会高到让人放弃。

最好的状态就是容忍一部分乱。分类、标签、编码、命名、检索混着用，哪个好用就用哪个——这才是性价比最高的整理策略。

### 3.3.2 多个基本点：各子资料库

#### 3.3.2.1 云盘类工具的配合使用 @洛羽

飞书个人账号的云存储空间只有 10G，如果你的本地图片和文件特别多，空间很快就不够用了。这种情况可以在移动端配一个中转站，我比较常用的是跟微信打通的 flomo（浮墨笔记）。刷到有价值的内容，或者灵感突然冒出来，先快速转存进去，等晚上或闲下来再统一归档到飞书知识库。

#### 3.3.2.3 本地文件夹的配合使用 @洛羽

虽然我一直主张把所有本地文件尽量收进云端知识库，但那些高频使用的资料，还是有保留一份本地文件夹的价值。否则每次用到都要去云盘或知识库下载，太折腾了。

我习惯在桌面放 1—2 个文件夹，里面只装常用内容，其他的要么马上归档，要么直接删掉，桌面始终保持干净清爽。

## 2. 实战表现

GPT 的回答里提到了资料管理的各个步骤。但在我看来，资料整理真正核心的动作只有两个：信息的收集，以及信息的分类/打标签。这两件事 ChatGPT 也能帮上忙，具体用法如下。

1）信息的高效收集（直接版）

直接版就是现场提问、当即获得答案。分享一个我亲身经历的场景，能直观感受“几小时快速入门一个现实领域”的效率。之前和朋友去逛汽车城，我本人对汽车完全不了解，平时只关心我的两轮小电驴。朋友一下午给我讲保时捷、法拉利、兰博基尼、宝马、奥迪，讲得相当专业，但信息量太大又不成体系，我越听越懵。于是我就边逛边让 AI 帮我补课，直接问它：保时捷有哪些车型？不同车型各有什么特点？价格区间大概是多少？

[PRE38]

后来我还问了买车有哪些专业名词必须了解，买二手车有哪些注意事项才能避开坑……身临其境遇到不懂的问题，直接向 GPT 发问，哪里不懂问哪里，学习的效率真的非常高。往大了说，用这种方式自学，任何领域用一个下午就能达到入门级认知，甚至比请老师傅带还高效。
