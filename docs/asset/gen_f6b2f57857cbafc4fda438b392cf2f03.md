# 4.2 搭建承接流量的微信号

# 4.2.1 微信号实用冷知识

做这个项目，最好新建一个微信号来承接引来的流量。流量涨起来后，还要继续增加微信号。账号包装得怎么样，会直接影响成交概率，尤其是朋友圈运营：一个认真打理的盆友圈，能快速拉高信任感，也会给别人留下不错的第一印象。

1）一个微信号能加多少人？

刚注册的账号，好友容量通常不大，可能只有几百人；随着使用时间变长、活跃度提高，上限会慢慢增加。长期正常使用且信誉良好的号，好友数可能达到5000人左右，目前测试最多能到1万以上。每天加好友、被加好友并没有次数限制，但短时间频繁操作会触发异常提示。

所以，当作品突然爆了，别让客户一股脑全加进来，最好分时段放人，比如每小时通过一部分，否则容易遇到“好友添加频繁”的提示，客户反而加不进来。

# 4.3 如何快速包装微信号

# 4.3.1 微信号名字

微信号一年只能改一次，务必慎重！！！

建议先把想好的微信号写在纸上，最好写10个以上，再一个个去试。为了方便客户搜索到我们：

1、尽量不要带特殊符号；

2、尽量不要有大小写。

一个容易记住的微信号，关键在简短、有规律、个性化，而且方便口头讲清楚。微信号通常是字母和数字的组合，用来唯一标识账户。下面这些策略，可以帮你设计得既独特又好记：

1. 结合名字缩写：用姓名拼音首字母或英文名缩写，既有个人特色又容易识别。比如李华，可以用“lh”。

2. 融入生日或特殊日期：在缩写前后加上有意义的日期，比如生日、纪念日，会更个性化，也方便记忆。例如“lh1985”或“lh1688”。

3. 使用易记数字：挑简单或有规律的数字串，比如重复数字“888”、连续数字“123”，或者对你有意义的幸运数字。比如“lh888”或“lh2021”。

4. 保持简洁：尽量控制在6～10位字符以内，太长不好记也不好输入。

5. 避免复杂符号：虽然有些平台允许特殊字符，但为了通用和方便口头告知，最好只用字母和数字。

6. 测试可读性和唯一性：定下来前先念几遍，看看顺不顺口；再去微信平台查一下是否已被占用，确保唯一。

按这些原则，如果一个人叫张伟，生日是1990年1月1日，他的微信号可以设计成“zw900101”“zhangwei901”。

如果看完原则还是不会，也可以按九宫格键盘来想。国内很多人习惯九宫格输入，微信号最好设置成3～4个字母加3～4个数字，比如adgm1234、mpt220。

注意点：

1、字母和数字要避开i、1、0、o、u等容易看混的字符，难区分的一律不要。

2、设置字母时，可以优先用九宫格的首字母，比如ABC格用A，DEF格用D。

3、字母能小写就不要大写，很多人不知道大小写不影响加微信。

4、如果做矩阵，微信号也可以矩阵化，比如mpt220、mpt221、mpt222。万一mpt221被封，用户着急时会自行加1或减1，去加mpt220或mpt222。

5、发微信号时不要发手机号。原因很简单：你都不一定记得住另一半的手机号，更别指望用户记住你的手机号。

# 5.1 第一步：筛选对标账号

# 5.1.1 哪些账号值得对标？

在任何平台创作时，模仿对标账号都是很有效的方法。对标账号，就是和自己同行业或同类型的其他账号。创作时，可以从它们的图文/视频内容、话题选择等方面进行模仿。

对标账号的选择标准：

⭕ 优先看粉丝量一万以内的低粉账号，更高的先不看。

⭕ 要高赞账号：获赞数大于粉丝数，内容有质量、有价值。

⭕ 看最近一个月的表现；周末看的人多，只选一周的数据没有参考意义。

⭕ 主页多次出现：刷主页时，如果某个封面反复冒出来，说明这个账号值得对标，照着拆解就对了。

爆款笔记的四组密码：爆款选题心法 + 爆款封面做法 + 爆款标题起法 + 爆款内容写法。

⭕ 小爆款：赞、藏、评总数≥200

⭕ 中等爆款：赞、藏、评总数≥1000+

⭕ 大爆款：赞、藏、评总数≥1w+

⭕ 超级爆款：赞、藏、评总数≥10w+
