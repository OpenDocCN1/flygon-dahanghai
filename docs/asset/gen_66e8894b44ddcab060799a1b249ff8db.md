# 2.7.2 四步挂载故事锚点

想让抖音视频里的锚点把观众引到小说页面，推广系统的绑定可以按以下流程完成。上一节提到的操作暂时用不上，直接照这四步做即可。

**第一步：登记抖音账号和相关资料**

先把你的抖音号等信息提交报备：

报备入口：`docs.qq.com/form/page/DSER0VHptVEpZc0RN`

同时注意：抖音必须更新到最新版本2430。查看抖音uid/did的方式是：打开抖音→“我的”→右上角→“设置”→在页面最下方空白区域连续点击。

提交后，当天20:00前后（最晚次日早上10:00前）可通过以下链接查看审核进度：

`jinshuju.net/f/G4wvqb/s/hjnHdn`

审核通过后，你就拥有了给视频添加故事标签的权限。

**第二步：报名成功后发布视频并添加书籍标签**

收到报名成功的反馈后，在抖音点“+”进入发布页，依次选择“添加标签”—“故事”—“搜索书籍”，找到要推广的短故事（可用bookid、书名或作者名检索）。

这里有个关键提醒：别同时加“位置”和“标签”。系统会优先保留“位置”，一旦选择位置，故事锚点就会被覆盖。

**第三步：确认标签后发布**

视频发出前请再检查一遍，确保对应书籍标签已经加好。发布成功后，观众会在视频左下角看到故事锚点。

**第四步：在视频里引导观众点锚点**

只有让粉丝真正去点锚点，才更可能拿到收益。如果视频里没有任何点击引导，订单收益很可能拿不到，这次引流也就白做了。可以从这些位置入手：

1. 画面提示：在视频画面里加箭头或醒目标识，提醒观众点锚点；
2. 口播引导：相关话术后续更新补充 ing；
3. 标题引导：在视频标题里提醒观众点击锚点，例如“看后文快点击上方链接直接阅读吧”；
4. 置顶评论：用表情包或文字等方式，引导大家点开锚点。
