# 八月复盘：设计师创业者的50条实战札记

作者：Sky🏹（表哥）｜2021.9.9

生财圈的朋友们，上月我在这里聊过设计师创业者关于设计、生活、品牌、成长与创业的体会。亦仁建议我每月做一次回看，八月这份如约而至。也提醒各位圈友，再忙也抽空迭代自己、常复盘。顺手点个赞即可。

## 设计：先把参考吃透

[PRE0]

1、不少刚入行的设计师，原创能力并非天生，审美与眼界都要靠持续训练。动手前先锁定优秀参考，把其中的图形、色彩、字体、构图、质感拆出来吸收；有参照和没参照硬憋，成品差距会非常明显。

2、自律确实不容易。分享一个“十分钟起步法”：原本计划练一小时，想着就头大；先只做十分钟，门槛是不是低多了？十分钟虽短，也好过练几分钟就撂挑子。通常开了头，往往会顺到十五、二十分钟；中途不想继续也没关系，歇一歇再来十分钟。我最近写作也用这招。若实在难自律，可以试试Forest，它把番茄钟做成种树游戏，中途放弃树会枯，仪式感更强。

3、判断设计师是否还有创造力，看好奇心就够了：愿不愿意每天碰点新东西，会不会主动研究新工具、新趋势，比如Figma这类产品。

4、入职阿里后的头一个月，主管布置了一项任务：先默写全球电商的交互与视觉框架，再谈需求。当时我不理解，后来很感谢那段痛苦经历——只有这样，才能借巨人的视角去想问题。

5、商业由设计来驱动，这说法我一直存疑。资源与信息并不对称，很多公司只把设计师当资源方，甚至是产品执行末端。想驱动很难，可设计师又得主动去争业务活；否则晋升时被问“这个项目成了，哪些地方因你而不同”，不少人就卡在这里。国内真正偏设计驱动的公司，曾出现过锤子。

6、找灵感时，Dribbble和Behance我看得少了，更常去 https://mobbin.design/ 。那里不只有完整截图，看中了还能下载体验，落地性更强，更值得参考。

7、最近发现一个“韩国鲁班” https://www.miricanvas.com/design ，比国内一些搞定设计类工具顺手，模板质量高、效果也强。国内不少花花绿绿的模板看久了很累。

8、NFT突然火起来，我相信它未来会大力推动艺术创作。原阿里设计总监善牧老师说的一句话我很认同：设计师的创作需要保护，未来的启发性不来自组织，而来自社群。

9、别只崇拜设计大神，而要研究是什么让这个人变厉害。抓住他成长的关键路径和本质，去模仿、去学习，按这条路径走，你也能成为高手，而不是只做高手的粉丝。

10、专业上必须有自己的长板，而且长板要与时俱进。大家还在争论金属质感还是玻璃质感更好时，这些风格可能已经被扫进历史垃圾堆。身边人都在聊趋势和技术，你却听不懂，这很危险。

11、马云讲课也会被挑战，也有人不听，老板们会说“你不在一线，我在一线”。终身学习很重要，但怎么学更重要；以伴为师，向身边真正优秀的设计师学习。

12、设计师要换学习方法。罗胖在得到训练课里说过，传统案例学习已经过时，应结合真实场景，从用户问题出发给方案。时代变化太快，设计师要随时警醒，从后视镜转向前视镜头；创业也一样，常想公司明天会挂，今天该怎么做？

13、努力做U盘型、钉耙型人才：一专多能。培养多元综合能力很重要，设计师要多了解新趋势、新技术，技不压身。

14、很多人觉得技多不压身，囤了一堆免费课却从不看，慢慢成了收藏家。今天互联网知识都能检索，输入关键词就能找到答案；真正核心是如何学习，却没几个人做到。那句话很对：当你开始做，已经跑赢90%的人。

15、别玻璃心。作品发到网上或交给业务方，收到负反馈就容易反弹，其实没必要。把时间花在让自己变强的行动上，用结果说话。当然，如果你确实正确，该捍卫的还是要捍卫。

16、设计师常犯一个毛病：凡事追求完美。很多事大可不必，房子都没盖起来就纠结地板铺什么瓷砖，没有意义。做完优先于做到完美。宫崎骏那句话大意是：遇见皆天意，拥有皆幸运，不完美又何妨；万物都有裂痕，光正从那里照进来。

## 品牌：用户记住的是价值

[PRE1]

17、没有骤然爆红的品牌，背后都是长期付出和积累，只是等风口来了才被看见。做个人IP、做社群也一样，要珍惜自己的羽毛。

18、品牌到底是什么？本质是让获得用户更简单。设计日记这个品牌是什么？用户记住的是什么？颜色和LOGO只是很小一部分，用户最终记住的是价值。能帮用户解决某个领域的问题，才是品牌内核。产品也有阶段：先不断曝光让更多人知道，目标是获得用户；但品牌终极如可口可乐，已不只是曝光，而是社会价值和用户好感度。劳斯莱斯普通人少见，因为它的广告出现在私人飞机、高端会所，是精细化投放。

19、现在一提品牌，大家想到图形、视觉、色彩，却忽略了两点：文案和音效。苹果的文字仔细看有苹果味；淘宝早年用“亲”打招呼，支付宝则不会照搬，仍用“你好”，不同品牌文案不同。音效也是，QQ提示音、微博刷新声，在地铁里听见就知道是哪个品牌；早年摩托罗拉开机音、诺基亚铃声也有辨识度。只是这两点正被一些企业忽略。

20、之前在支付宝做高端理财项目，目标用户是存款七位数以上的人。我想当然以为他们喜欢奢侈风，把深色、玫瑰金堆满界面，结果被总裁批了一顿。他讲了迪拜见闻：当地女性戴黑色面纱，怎么判断谁有钱？他遇到一位，面纱边缘有一抹飘逸的红，整体气质立刻不同。他财务自由的朋友，平时衣服也没有LOGO，更看重裁剪。所以品牌表达不一定靠大标志、大色块，小细节也能传递品牌。

21、体验好的品牌，我们接触得还不够多。说几个百元级能提升生活品质的品牌产品：音乐软件我常用Spotify，界面、使用感、曲库授权都不错，无损音质尤其明显，用完会觉得以前音乐白听了；另一个是Netflix，能看很多优质电影资源，对生活品质提升很大。

22、用户在每个领域能记住的品牌不多，通常只记第一、第二：碳酸饮料记得可口与雪碧，服装会想到无印、优衣库，大卖场记得家乐福、沃尔玛，运营商记得联通、移动。第三第四也有，但人天性懒。所以做产品、尤其创业，SKU不是越多越好，而是越聚焦越好，能不能磨尖很重要。

23、品牌旗下有很多子品牌，怎么保证和母品牌统一又有自己的个性？可参考谷歌、阿里和腾讯。以腾讯为例，旗下有QQ、QQ音乐、腾讯视频、腾讯游戏、微信、浏览器等。统一方式：一是色彩，腾讯产品大致用蓝、绿、黄搭配，色相有区别；二是图形Q，QQ浏览器、腾讯地图、全民K歌的图形里都有Q的轮廓；三是企鹅元素的运用。不过我觉得做得最好的是Google，统一感极强，一眼看出谷歌家族；阿里主要靠字体维系，相对一般。

[PRE2]

24、如何快速打造新牌子？只要产品不差，设计做得洋气些，去抖音、小红书找达人推一推，最好上几次李佳琦、薇娅、老罗直播间。投产比转正后，再做全网投放。

25、苹果的产品生态确实好。拿我每天用得最多的AirPods来说，电脑上听着歌，打开手机刷抖音，耳机自动连过去，它会围绕苹果设备的声音场景来设计，很贴心。但苹果也有体验差的产品：前几天买了新款MagSafe移动电源，七百多块，携带方便，可给手机基本充不满，充电还慢，一边补电一边使用，电量反而往下掉，很鸡肋。

26、百度的品牌体验越来越难用。前两天想下载苹果字体文件，连翻三页仍是推广位。我能理解广告位要维持技术更新、公司盈利，但凡事要有度，否则用户习惯转移很可怕。

27、竹子前四年只长3厘米，第五年开始每年蹿30厘米，六周长到15米。今天很多产品看起来骤然爆红，背后其实是默默付出。以我熟悉的生财有术为例，用户爆发也是在第四年，前三年亦仁一直低调打磨内容、做好服务。所以真没什么速成，该走的坑一个少不了。产品如此，品牌也是；市场上还没有你之前，你谈不上品牌，唯一竞争力就是服务和内容产品。

## 成长：把时间用对顺序

[PRE3]

28、每个月都要定好规划，个人成长和公司经营都一样。总觉得自己还年轻、时间还多，减肥、见重要朋友都往后拖：下月吧，来年吧。把自己弄得很忙，其实浪费了不少时间，本质是没规划好。时间用错、顺序用错，都是损失。

29、今天去朋友公司分享，有同学问我：创业这么苦，离开阿里后悔吗？我一点都不后悔。因为我不想每天努力的目标就是成为主管那样的人：没有生活，只有工作，被资本蒙蔽，每天如履薄冰。当然，有人喜欢那样的工作，体面、高薪。公司没法改变，但我能改变自己的选择。试想，如果全世界工作工资都一样，你会选什么？有时候没法选择时，就听从内心。

30、怎么提升格局？我认同猫叔说的：敢花钱、会花钱。现在很多优质大佬都在圈子里，付费加入就能快速链接；有机会进他的群，发红包暖场，大家就容易记住你。前提是你要有价值，有值得别人学的地方。很多人说见大佬会怂，这时候可以用田忌赛马：大佬也有不懂的，你完全可以用长处弥补。比如我微信里有很多大公司设计总监，专业能力我肯定不如他们，但运营能力、个人品牌能力他们未必比我强，所以一些合适契机，我帮他们解决运营和团队影响力问题，彼此帮助、互相成就。早期见亦仁我也怂，后来他找我当设计顾问，慢慢就熟了。所以要学会主动利他。

31、抱怨当下很爽，长远看并不爽。漫威英雄最后能解决问题，靠的绝不是牢骚，而是不断行动，事情才慢慢得到解决。

32、请把“及时止损”写进人生信条。辞掉不合适的工作，退出不合群的圈子，告别不合适的感情，离开不合适的人；不要过度怀念沉没成本。上错车不可怕，别因为已经投币上车就舍不得下去。生活中，不做毫无意义的内耗，是大智慧。身处沼泽，待得越久陷得越深；一些小事，越纠结输得越多。

33、最近教培行业收缩，字节也传出调整，哪有什么大厂关怀？资本快速变化中，没有稀缺能力就会被淘汰。让自己掌握稀缺能力，并在某个领域不断叠加增长，才是竞争力。

34、之前看过一句讲竞争力的话：“人无我有，人有我优，人优我全，人全我不要命。”虽然有点段子味，但还是有启发。每个人都要给自己构建护城河，工作如此，生活也如此。还好工作期间我找到了写作这个点，逐步把它建成护城河。设计师普遍不擅长、也比较排斥写作，我刚好把这一点放大，慢慢变成优势。

35、职场里做自媒体要低调。这个世界上，除了父母，没几个人真正希望你过得比他好。我在阿里做自媒体时像做贼，天天怕同事看见我写文章。企业永远是企业，只考虑公司利益第一。同样两个人，一个每天只给公司工作，一个经常写文章，你是老板会重用谁？所以大家想做副业或写作，记住，一定屏蔽那些爱议论的同事。

36、今天和几个朋友吃饭，聊到一个话题：这个时代有哪些能力很重要，但大多数人没有？最后总结了几点：
让人相处舒服的本事。和某人相处很舒服，什么梗都能接，无话不谈，你以为遇到知己，其实不是，是他情商高，在向下兼容你。
读懂人的本事。不是看他说了什么，而是看他的行为，以此判断这个人。
坚持做事的本事。没背景没资源的人，坚持做一件事能让你超越90%的同龄人。我很认同，正是坚持写作，才有了现在做的事。
坚持早睡早起。大佬说，清晨一碗白粥，胜过深夜一杯酒。
执行力强。未来大家接受知识的能力差不多，核心是执行力，商业敏感度和长期执行力才是拉开差距的关键。
接受自己的平庸，接受无法改变的现实。很多痛苦来自预期和现实差太多，遇到这些痛苦，接受就好了。无论企业家还是明星，追求的其实也就那几样：赚钱，过想要的生活；明星赚钱也是买大房子，和普通人都一样。我们都是带着灵魂的灵长类，没必要觉得自己不如别人。

37、陆奇当年在百度给智能驾驶团队打气时打过比方：前进路上，要选一条跑得快的高速路；在快赛道上，再选一个好的交通方式。我们现在做的业务，就是一条高速路、一条快赛道。

38、人生有几个阶段：第一，靠聪明才智；第二，拼关系网络和赛道，关系网络决定你走多高多远；第三，在过程中创造价值，不在乎年纪高低。

39、设计师到了30岁，怎么提升竞争力？先建立自己的网状体系，不断打破舒适圈，了解新技能。别人用技术和你竞争，你有设计思维；别人用设计思维和你竞争，你有数据思维；别人用数据思维和你竞争，你有商业思维。你手上是多维能力网，对方只有单线，哪个会赢？

40、稻盛和夫谈人是怎么废掉的：假装努力，持续幻想，做言语上的巨人、行动上的矮子；睡前给自己打鸡血，醒来还是老样子。总感觉自己年轻、时间多，每天找理由拖延：晚点做吧、明天做吧、下月吧、来年吧。每天把自己弄得很忙，告诉自己没虚度，却很少分析工作是否值得，很少做职业规划。80%的时间都用错了。改掉浪费时间的习惯，获取正向反馈，明确做事顺序，才能离成功越来越近。

41、延迟享乐的能力，我一直在锻炼。想做成某些事，就必须先追求目标，再享受成果。身边诱惑不少，但你要有能力拒绝，并保持自律、专注目标，直到实现理想。就像写作和考试，考前该专心读书，先拒绝朋友约会，考完再一起玩。凡事以长远利益为重，只有做别人不愿做的，才能有他们没有的成就。

42、什么是活得真实？不再害怕别人评价，好的是你，坏的也是你，你比任何人都了解自己的优缺点。也没必要因为片面的评价否定自己。只要心中有光，觉得方向正确，坚持就对了。拉长时间看，所有人都只有三万个日夜，在宇宙面前我们只是一粒微尘，做好自己很重要。

## 生活：先管好能量，再谈成长

[PRE4]

43、束缚大家的不是认知不足，决定认知的其实是心力不足。需要管理身体能量，心力衰竭；左晖的遭遇令人唏嘘，看起来是繁忙压力大，但那只是表象。学习之余去锻炼身体，给自己充能、保证续航，很多事就不会发生。

44、在这样的政策下，很多人都觉得难：上班觉得不稳定、辛苦，创业觉得政策变化快，都难。随便走在街上看看，身边每个人谁不难？学习嫌难不想吃苦，就只能吃生活的苦；创业不想吃苦，就只能吃失败的苦。说到底，这是长期修炼。建议大家看看俞敏洪之前的采访，看他如何看待人生的大起大落。

45、改变自己很难，那能不能每个月改掉一项坏习惯？比如熬夜、刷抖音、饮食懒散不控制、肥肉乱飞、周末死宅，像把世界的一扇门关上了。改掉这些，就能收获早睡早起、热爱读书、健康身体和热爱生活。只可惜难度有点大，下月复盘再来看看。

46、珍惜身边的人。人很容易对朋友特别好，对父母爱人脾气却很差，因为内心觉得他们不会离开你，这其实是自私。

47、这几年我喝水特别少，天天喝咖啡对身体很不好。前几天在老罗直播间买了一个带刻度的超大容量水杯，上面有水位线，几点该喝到哪儿都标着，喝水频率就高了很多。人性都是懒的，很多成功产品就是充分抓住了这些需求，比如小罐茶、三顿半、小仙炖。

48、爱商，是我们这代人最需要补上的一课。

49、要学会和自己的心灵对话、做复盘。最近在复旦读书，老师分享的《灵魂11问》复盘方法很受用。拿纸笔，把下面这些问题写下来：
过去几天里，你发生了哪些变化？
人生旅途中，谁源源不断给你力量？
在当前工作中，你感觉自己的未来在哪里？
