# 105赞精华帖：用Google关键词找出海需求

2022年10月21日，三林发布了一篇原创文章，主题是“如何用Google关键词挖需求”。此前一周，这篇文章还在“英文工具站小航海”社群里做过分享。

做海外产品，最先绕不开的是方向题：到底做什么？三林的思路是，先锁定某个细分领域或平台，把关键词找出来，再用数据验证一轮，产品机会往往就会浮出水面。先做用户会搜的东西——Make Something People Search For。不过他也提醒，关键词分析只是开场，文末还整理了Ahrefs博客里的看法（见图2）。

这次分享让不少人觉得有收获。有读者反馈，学会从关键词里找需求，“感觉像赚到了”。三林也欢迎大家继续交流，一起进步。完整内容见飞书文档：
