# 企业店入驻：审核、保证金与品牌资质全解析

资料递交完成后，平台会先做核验，正常三个工作日内出结论。万一没通过，会有人打电话或发邮件说明原因；等待期间若有疑问，直接找在线客服即可。

核验一过，最后一步就是交店铺保证金。这里有个关键点：扣款账户得是企业对公户，开户姓名还必须和入驻登记的经营人一致。

接着看旗舰店、专卖店的申请。总体框架和普通企业店类似，但有四处需要特别注意：

第一，品牌信息录入。系统里查不到你的品牌时，点“新增品牌”补录；上传logo时，图案要和商标注册证保持完全一致。

[PRE0]

[PRE1]

第二，先分清自有品牌还是代理品牌。代理品牌要保证授权链路完整，公司名称直接填营业执照上的名称。

[PRE2]

自有品牌指商标归本公司或公司法人所有。注册类型分两种：R标是已注册商标；TM标是商标注册申请受理通知书。

若商标为个人型R标，需提交商标注册证，外加商标权利人的身份证或护照复印件/扫描件。

[PRE3]

个人型TM标也一样，要交商标注册申请受理通知书，以及权利人的身份证或护照复印件/扫描件。

[PRE4]

企业型R标或TM标则省事，提供商标注册证或商标受理通知书其中一项即可。

第三，挑选售卖品类时多留个心眼，尤其“定制”类目，别急着选。

[PRE5]

第四，核验通过后还有签约环节。合同通过线上邮件发出，用电话或验证码确认签署。

[PRE6]

签完同样要交保证金，注意点和前面普通企业店一致。

再讲集合店。它只接受平台邀约，收到邀请后，流程与旗舰店、专卖店相同。

全部申请通过，就能上架商品正式开店；账号首页会显示店铺和商品入口。

[PRE7]

整体来看，企业型店铺拿到的商业权益比个人店多，但维护成本也更高，按自身情况选即可。

入驻类目、审核等环节有不清楚的，建议第一时间找“人工服务”；商家客服回复较快，通常能迅速帮你解决。

# 2.1 蓝海品怎么筛⭐

1.

什么叫蓝海产品

无论传统货架电商淘宝，还是兴趣电商小红书，蓝海只有一条判断：自己做得过就是蓝海，做不过就是红海。结合自身情况判断即可。

蓝海电商的市场容量通常不会太大，也就是销量不会特别猛。因此挑品时尽量偏向高客单、高利润，利润更稳，操作也轻松些。

蓝海电商产品分标品和非标品。

标品通常在小红书能找到同行参考，好处是上手容易，坏处是容易被跟，从蓝海转红海很快；

非标品在小红书没有同行参考，你就是第一个做的人。它的优点是生命周期长，缺点是起步更难。

因此，本次航海主要分享【小红书电商蓝海标品打法】，帮大家尽快拿到正反馈、建立信心、走上正轨。

# 2.2 蓝海选品怎么想

在讲具体方法之前，先梳理一下小红书选品的思路。

选品方法很多，整体来讲不外乎三个大方向：

1、日常多刷小红书站内爆款选品

在小红书卖东西，肯定要了解平台最近哪些品好卖。多刷多看，有条件的也可以通过灰豚看数据、找低分爆款来选品。

不过新手一般不建议直接上工具，平台多刷就够了，还能培养下网感。

2、从传统电商平台-淘宝选品（推荐⭐）

也就是从淘宝找合适的品。淘宝的分类页面有目前国内所有主流搜索电商平台里最全面的类目，而且淘宝作为电商平台相对最成熟，也不需要用到任何付费工具。

常用方法有：淘宝分类页面选品、淘宝神店榜选品、淘宝榜单选品、天猫榜单选品。

3、从其他兴趣电商平台-抖音选品

也就是从跟小红书一样靠内容带货的平台找品，目前建议从抖音找合适的产品。

常用方法有：考古加选品法、蝉妈妈选品法、抖音精选联盟的创意中心选品法等。

所以在正式选品前，建议大家先刷至少2小时小红书，对平台当前爆品增加些体感。

# 选品方法二：抖音找品

抖音创意中心是抖音自己的数据统计，实时更新，相比考古加能更快知道新爆款。

其中建议百货等大众品类注重一下【抖音创意中心选品法】。

抖音流量和玩家更多，这类大众品在抖音先爆起来的概率更大。

小红书有时候很慢热，这类大众产品基本都是混剪、素材同质化严重。等到小红书已经爆起来你再去做素材，可选度会很低，所以不如直接在抖音开始爆的时候就搞过来。

我们的爆品如硅胶保湿袜、雪地靴刷子、钢丝抹布等，都是通过抖音创意中心选品法选到的。
