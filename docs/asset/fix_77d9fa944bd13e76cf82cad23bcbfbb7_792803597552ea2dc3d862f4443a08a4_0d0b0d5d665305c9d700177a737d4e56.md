5. 模拟按键
[PRE2]
这个模块的添加可以按“挑、放、调”来走：
找它有两类路径——从菜单逐级进入“鼠标键盘 → 键盘 → 模拟按键”；或者用搜索框，动作词敲“模拟”，目标词敲“按键”，都能筛出“模拟按键”。
落位时双击模块，或把它拖进摆放区。
参数上，Enter 键由系统预先带好。

第 8 步：视频进时间线
1. 移动到目标上
[PRE4]
添加这个模块同样分三步：先挑、再放、后调。
挑模块：沿“鼠标键盘 → 鼠标 → 移动到目标上”逐级展开；搜动作词“移动”或目标词“目标”，也能找到它。
放到摆放区：双击即可，也可拖入。
调参数：目标指定完成后，【目标设置】由系统补全。
[PRE5]
2. 点击目标
[PRE6]
添加流程还是挑、放、调。
挑模块：从“鼠标键盘 → 鼠标 → 点击目标”进入；搜索时动作词用“点击”、目标词用“目标”，同样能定位。
放：双击或拖进摆放区。
调：目标设好后，【目标设置】自动出现。
