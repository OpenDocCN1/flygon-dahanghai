# 渠道三：系统化课程平台

以前我总琢磨一件事：教材已经把知识写清楚了，为什么还要配老师、建学校？

后来才慢慢明白，“读书”并不是对所有人都管用。有的人更适合看视频、听讲解，也有人光看文字就是学不进去，非得有人带着梳理、答疑，才能真正吃透。这时候，老师和成体系的课程就显得格外关键。

所以这里也整理几个值得关注的课程学习平台，覆盖 K12 学科、高校专业，以及商科和跨学科内容：

•慕课网：[`www.icourse163.org/`](https://www.icourse163.org/)  
•学堂在线：[`www.xuetangx.com/`](https://www.xuetangx.com/)  
•网易公开课：[`open.163.com/`](https://open.163.com/)  
•国家智慧教育公共服务平台：[`www.smartedu.cn/`](https://www.smartedu.cn/)
