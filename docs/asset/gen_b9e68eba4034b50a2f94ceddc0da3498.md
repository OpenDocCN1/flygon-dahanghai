# 辞职后，我在美团开家政店做到月入过万

入场一个月就把赚钱门票钱赚了回来，三个月把月利润从0做到10921。这个成绩不算惊天动地，但对我这种普通小白来说，已经足够让我坐下来认真复盘一次。

一、先交代一下我的起点

我不是什么行业大牛，在赚钱里也长期潜水。福建一所二本院校毕业后，家里安排我进了泉州一家单位，月薪两千出头，工作清闲。2021年7月，因为个人原因，我辞职了。

2021年4月我就加入了赚钱，当时刷到刘总那篇讲无货源月入过万的文章，看完很受触动，但迟迟没有行动。真正让我动起来的，是离职时请保洁来打扫出租房。跟上门阿姨闲聊时，我忽然想起那篇帖子，翻出来又读了几遍。8月下旬，我加入云嘉，后半年业务开始快速起量。

二、什么是家政电商

说白了，就是在美团上开一家家政店，以虚拟店为主。自己不养阿姨，而是以中介身份帮客户匹配能解决问题的人。服务范围包括日常保洁、深度保洁、开荒保洁、家电清洗、家居清洗、除甲醛、三嫂业务等。我们要做的，是等客户找过来，然后把他面临的问题解决掉。

整个流程可以拆成：客户下单—联系我们—确认需求—在阿姨群里按需求找人—阿姨上门服务—服务完成—售后—评价。

三、为什么是家政电商

刚开始你问我为什么选这个方向，我其实说不出太多道理。只是看完刘总那篇帖子，觉得这事有搞头，加上刚失业，就去试了，没想到真跑通了。

现在再问我，理由就清楚多了。

1. 赛道够不够大

做事之前，先看赛道。这个行业首先盘子要大，蛋糕够大，才轮得到我这样的人分一口。

其次，从业者整体年龄偏大。90%的家政店是夫妻店，老板们对电商不熟，很难跟我们在线上竞争。

第三，政策面有支持。去年领导多次提到家政行业，杭州创业补贴刷屏时，三大行业里也有家政。

[PRE1]

2. 投入成本低

一家美团店的费用在3800到5800元不等。对大多数人来说，也就是一两个月工资。跟那些动辄十万八万的红海项目比，这个启动成本算很友好了。

3. 轻资产

一个人、一台安卓手机就能干。不用租办公室，不用被上班时间绑住，也不用请阿姨。总资产基本就是一家美团店的成本，属于典型的轻资产创业。我看过不少帖子，自己对重资产项目一直很发怵。

4. 流量便宜

除了北上广深竞争激烈，其他城市美团的广告单次点击大概3到8元。按我们自己的测算，广告抢第一名时转化率能到10%到20%。跟其他平台比，这个获客成本算合适。

四、利润点在哪

1. 以最常见的深度保洁三小时为例，现在收费65元/小时，厦门派单价大概30到35元。按35元算，每小时有30元利润，三小时就是90元，利润率46%。

[PRE2]

2. 家电清洗里，挂机空调是高频项目。我们挂牌价129元/台，厦门派单价60到80元，夏天正是挂机空调清洗旺季。按一台算，利润49元，利润率37%。一般家庭有2到3台空调，可以给客户打9折或8折。按三台算：3×129×0.8=309.6元，派单成本可以做到180元/3台，利润129.6元，利润率41%。

[PRE3]

3. 开荒分粗开荒和精开荒，粗开荒10元/平，精开荒12元/平。厦门派单价粗开荒能给到6到8元，精开荒8到10元。第一档6元比较难找，需要有常合作的阿姨或小家政公司；第二档7元是市场行情价；第三档8元相当于全包全托管，赚的是信息差。具体能谈到哪一档，取决于你跑不跑现场、跟阿姨熟不熟、对行情了解多少。

4. 除甲醛也分类型，普通甲醛挂牌34元/平，母婴级65元/平。派单价格会根据城市、药水、施工程度不同，有多档报价。利润率能到30%以上，胆子大一点可以做到50%。

五、具体怎么落地

1. 选址

位置选得好，广告费都能省下不少。选址前先搞清楚用户画像：后台数据显示，50%以上的客户是20到35岁女性，购买的是团购套餐。所以优先考虑大型商超、写字楼、高档住宅附近。老破小这类本地居民区尽量避开，小区尽量以新小区为主。

2. 营业执照

现在做美团家政电商，主要是混合类门店。混合类要求有营业执照，还要美团人员上门签到。这意味着得有实际地址，可以是你家，也可以是朋友家，或者其他真实存在的地址。另外要有铁质门头牌。

[PRE5]

要注意，我们主要在美团和大众点评卖团购套餐。美团客户偏爱便宜，但量大；大众点评客户更看重评价，客单价也高。两个平台的团购套餐要同步。

3. 🛰️号

🛰️号最好准备两个。手机选安卓，官方自带双开，更稳妥。新号要按赚钱里大佬总结的方法养一养，千万别刚注册就疯狂加好友。一来容易封号，二来客户跟你聊天时会出现官方提醒，信任感下降，客户可能就跑了。

🛰️号1：阿姨号，也就是派单号，专门在群里派单。
🛰️号2：个人号，也就是接单号，专门承接客户。

4. 阿姨群获取

大家都说这一步最难，我把自己试过的方法列出来。

第一，在地图上找当地家政公司，打电话或加🛰️，跟对方聊行情，顺便进群。这个可以付费，一个群大概2到15元，群人数300以上比较理想。

第二，在美团下一单保洁，等阿姨上门后跟她聊，让阿姨拉你进群。

第三，进群后继续跟群里阿姨聊，让她们再拉你进群。

第四，等手里群足够多，可以找群里派单的人聊，互相换群。

5. 开美团店

根据上门材料，自己在大众点评建店，然后联系大众点评销售。对方会告诉你需要准备哪些材料，也就是上面那些。约好时间上门签到，就能上团购套餐了。

6. 补单

找自己的朋友补单。注意控制转化率，比如店铺浏览人数只有3个，你补三单，那就太夸张了。可以用家人朋友的手机多点点店铺，每天补一两单，递增着来，一直补到评分出来为止。

7. 广告

评分出来以后，可以适当开广告拉营业额。开广告的标准就是抢第一，第一名转化率会高很多。广告要算ROI，也就是投入产出比：营业额÷广告费用。举个例子，11月30日我的投入产出比是1507÷58.47=25.7。做过电商的人应该明白，ROI做到25.7有多可观。

8. 坚持

不断坚持，不断学习，才能走到最后。

六、一些思考

新手做家政电商，先模仿就行。前面有巨人开路，跟着走就能做得不错。会抄作业，就有利润。

但2021年越来越多年轻人涌入这个行业，新进来的朋友更需要精细化运营。
