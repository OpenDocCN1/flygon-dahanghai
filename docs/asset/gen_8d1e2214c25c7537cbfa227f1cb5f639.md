# 30条知识整理避坑心得

这30条经验，来自圈友实际做完资料整理后的复盘，一共30条。其中不少点值得参考，提前看看能帮你绕开一些坑。

[PRE0]

在航海过程中，我发现不少人跟从前的我一样，被“形式”困住，总想照着模板一板一眼地做。可知识管理真正的目标，是让自己用起来顺手，并不存在什么标准答案。下面这30条，大多来自我观察到的问题，也参考了群友的讨论，希望能帮到你。

1）暂时不知道归到哪儿的资料或文章，先建一个叫“杂学”的文件夹统一丢进去，每周再归类一次；攒到一定数量，自然就清楚该放哪里。

2）一份文件能进多个分类时，用标签和关联功能，让它同时挂到几个文件夹下。

3）按“输入—加工—输出—归档”的流程走，写得好的内容就归档到对应分类。

4）某一学科的知识，书本学来的和实操攒下的经验不要分开存放；整理是为自己方便，别为了形式折腾。

5）照片可以用云软件整理，比如iCloud、谷歌云、腾讯/百度/阿里云；听说Billfish这个软件也很好用。

6）别人的架构可以参考，但别照搬；最清楚你需要什么信息的人，只有你自己。

7）信息整理不是为了好看，也不是为了满足虚荣心，而是为了用起来方便。

8）平时摘抄金句如果涉及多个方面，就给它打多个标签，再定期整理。

9）信息和知识整理最终都是为了“用”，不是为了“收”。打标签是为了更顺手地使用；定期规整能让你把相似信息聚在一起，也能更新和内化。不整理的话，下次碰到类似内容，可能还会再收一遍，反复循环。

10）该记录什么？一个办法是盯住你眼下遇到的问题，围绕问题去找知识，而不是总等灵感上门。

11）很多资料其实未必需要收集，因为它们时效性较强。这时要追问本源是什么，把本源概念弄懂后放进知识库就行——像种树，别盯着叶子，要看树干和树枝。

12）不必纠结只用一种工具，可以让多个工具各司其职：飞书、印象笔记或Notion用来沉淀内容，flomo随手记想法，云盘存大量视频文件。

13）工具本身不重要，先想清楚自己要解决什么问题才重要。

14）桌面堆满文件时，整理前先定好分类和框架，把常用的挑出来，剩下的再慢慢归到对应分类。

15）沉淀一个学科的知识，要按初阶、进阶、高阶分阶段学习、记录，并配合实践。

16）整理过的知识并不真正属于你；只有经过回顾、记忆、实践和输出，才会慢慢变成你自己的知识。

17）不必硬把工作资料归工作、学习资料归学习；更该问的是：在你的知识结构里，这份资料应该沉淀到哪里？

18）“All in one”听起来很美，做不到也没关系，在多个平台分别建好分类即可。

19）以前积累的资料现在整理起来很痛苦，这不可避免，但越早动手越好。捷径是在整理时断舍离掉不需要的内容：新资料统一放一个平台；其他平台资料按优先级排序，先搬最高优先级且自己常用的，其余留在原平台——这样至少50%的内容不用动。平时偶尔想起来可以去搜，有用就搬过来，每周固定整理一个文件夹。过段时间你会发现，以前收藏的很多有用内容都搬走了，剩下多是边角料，不动也罢。不信看看你三年前的微信收藏夹。

20）恰当的知识管理过程，本身也是自我进化的过程。

21）群聊里想收藏的信息，可以专门建一个微信群，把各群消息转发过去，每天整理一次。

22）一份资料能放多个分类、这也想放那也想放时，用多标签解决；或者先放一边，去整理别的。

23）听书或听播客遇到不错的点，先用手机录音，再借助飞书转成文字。

24）flomo可以随手记想法，定时回顾，需要时取用。

25）长资料想放进知识库，不必全文复制；挑最有启发的一点总结后放进去，长文可以附上链接。

26）一个分区小工具：在微信或百度搜“电脑分区桌面壁纸”，能找到分区工具。

27）觉得微信收藏不好用，可以直接用cubox，用过就知道好；它能把各大平台的收藏集中起来处理。

28）信息越爆炸，越要会舍弃，敢于断舍离。

29）不用怕错过重要信息；真正重要的迟早会再出现，如果一直没出现，可能也没那么重要。

30）知识整理的最终目的，是让人过得更好。

内容来源：《30个知识管理技巧》
