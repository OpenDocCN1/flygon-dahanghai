# 选对平台，推广不绕路

账号准备好之后，下一步就是挑一个合适的推广平台。如今各平台对新手创作者的门槛更低了，不再像过去那样必须先授权绑定账号。

为了让大家少花时间到处找平台，这里直接推荐两个渠道：
• 3.1 麻雀 Matrix
• 3.2 创作猫

选定短剧推广平台后，下载相应的APP，就能在里面查看该平台的剧场内容、视频素材、推广教程、信息通知和推广收益等。推广过程中会碰到的各个环节，对应APP里基本都有解决办法。

同一个账号可以同时推广多个平台的剧场；你也可以多开几个号，多试几个平台。唯一要避开的是：别在不同平台推广同一个剧场。举个例子，渠道一有ABCD四个剧场，渠道二有DEFGH五个剧场，其中D剧场是重合的。你完全可以在渠道一和渠道二同时推广不同剧场，只要别把D剧场在两个平台重复推广，就不会冲突。

说得再直接一点：你可以同时参与「麻雀 Matrix」和「创作猫」的推广任务，只要不用同一个账号同时推广这两个渠道里的同一个剧场就行。

⚠️注意，这里的“剧场”和“剧”不是一回事。剧场可以理解成一个频道，里面包含很多各类剧目，比如九州小剧场、九天剧场等；剧则是具体的剧目，也就是我们短剧推广要推的内容。

现在就开始认识平台吧。当你看到琳琅满目的素材时，才算真正踏进「短剧 CPS」的大门。
