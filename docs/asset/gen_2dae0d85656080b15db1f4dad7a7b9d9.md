# 裸辞一年半，3000私域好友带来半月近六位数

大家好，我是 AI 君，95 后，曾是大厂产品经理。做个人 IP 已有两年，离开大厂一年半，现在以职场个人 IP 孵化教练的身份工作。

刚起步时，我没资源、没背景，也没经营过业余自媒体账号；微信里只有 1000 个好友，朋友圈半年不更新，几乎是个没什么存在感的人。

到了上个月，我依托 3000 位私域好友、一个 1000 粉的公众号和 4000 粉的小红书账号，在半个月里获得接近六位数的净收入，而且属于被动变现。多数客户从初次认识到成交，间隔一到两个月，过程里几乎不需要反复沟通。

这种模式对普通职场人来说很舒服：不必养大量好友、铺很多产品，也无需把大量精力花在销售话术上，更不用组团队、管人；单人时间和精力就足以运转。

这篇内容，我想认真聊聊：普通上班族怎样走通个人 IP，把副业做到五位数收入。主要包括：

1. 职场遇到瓶颈和迷茫时，如何确认未来方向，找到自己的优势与竞争力？

3. 怎样设计一套内外自洽的 IP 模式，让自我价值与商业回报同时成立？
4. 怎样借私域内容、成交路径和自媒体运营，让收入跨级并超过主业？
5. 上班族转型常踩哪些坑？卡点怎么破、效果如何稳？
