# 两天随手搭的站，半年没管，居然躺赚了848美元

因为公司有一个主要项目需要引流，我们顺手搭了个展示海外促销商品的网站，说白了就三个页面：首页、分类列表、产品详情，界面也没怎么打磨，两天就上线了。

那个站没有任何会员注册、邮箱留资、折扣码发放功能，纯粹就是商品陈列。后来觉得扔着也是浪费，就申请了亚马逊联盟，把联盟ID塞进每个产品的购买链接里——用户点过去下单，我们拿佣金。再后来自己公司的商品站忙得团团转，这个促销小站基本就彻底放养了。

那阵子大约挣了百来美元。2019年提现流程挺麻烦，也没心思研究，亚马逊直接把钱折成礼品卡兑换码给我们了。当时心想：钱又提不出来，更没必要花精力管它。过了一段时间收到一封邮件，说联盟账号被封了——大概是多少天没达到销售额门槛，具体记不清了，而且其他国家站也连带全封了，我们也没重新申请，等于到今天少赚了一些，哈哈。

后来换了个新的亚马逊美国站联盟ID，继续没管。

一直到了今年2022年2月底，我鬼使神差登录亚马逊联盟美国站看了一眼，竟然趴着848美元（见图）。

这才认真研究怎么提现。好在时代和技术都进步了，亚马逊联盟支持派安盈P卡了。我赶紧注册账号、配好提现通道，2022年2月28日完成了人生第一笔亚马逊联盟提现。

# 误打误撞的需求：促销打折是门大众生意

[PRE5]

这个站纯属瞎撞做出来的。但聊“挖掘需求”，我能想到的就是：促销打折算大众化需求，总有人要，尤其现在经济环境紧，老外也手头紧，能省一点是一点。拼多多海外版TEMU上线几个月有多火？但大众需求也意味着竞争激烈，大大小小的促销站确实很多。

好在促销站日常维护不算重：定期尽可能多地更新产品（基本可以一键操作），不断优化就行。新手有精力的话可以试试，它看着像内容站，实际更像工具站，内容添加能用很多自动化方法。SEO搞流量的同时，有精力多花点精力搞海外社媒也行。后期流量大了，如果有一键代发的自己的产品、赚头更多，搞搞谷歌等广告投放应该也可以，纯畅想，哈哈。另外流量大了还能给卖家放站外单挣个中介费，之前看龙哥盟里也提过。
