# 4.5.1 用对方式，影响力自然来 @叶叶在觉

想建立影响力、获得流量，重点不是照搬别人的打法，而是找到与自己性格、优势相匹配的路径。

善于经营关系、跟人打交道有手感的人，社群往往能成为你的引流场；反过来，若你不爱频繁社交，也不想和用户靠得太近，那更适合去公域平台持续发布内容，让内容替你吸引同频的人。

而且，性格优势不同，内容风格也不必雷同。

有位客户曾说自己拿不出有深度的文字，因此不好意思动笔。聊过之后我发现，她特别爱搜罗能让日常生活更舒服的好物。对她而言，硬走深度路线没必要，接地气反而更合适。我给她的方向是：先观察大家在生活中卡在哪儿，再针对这些卡点挑选产品做实测分享，这同样是在帮别人解决问题、提供价值。

另一些人则是一聊起来就有源源不断的话题。我会建议她约一位朋友，每期定一个主题对谈，用对话体来输出，不少播客里的两人、三人圆桌就是这种形式。

说到底，找到适合自己的表达和获客方式，才能把影响力做起来，也让流量来得更稳。
