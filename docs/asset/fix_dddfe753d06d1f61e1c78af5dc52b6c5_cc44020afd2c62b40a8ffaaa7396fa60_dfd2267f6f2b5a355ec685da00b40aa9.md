# AI优势分析，顺序和窗口别做错

想让模型把你的优势看明白，操作链路要顺：先把 MBTI 结果交给它，再补上盖洛普信息，接着上传你的长板资料，最后让它把三块内容交叉汇总。这样做，它才容易拼出相对完整的你。

还有一个容易踩的坑：别另开新会话。整套动作放在同一个聊天窗口里，模型才会把前后材料认成同一个人；频繁换窗口，它很可能接不上前文。

**问题 2：盖洛普报告先传哪份？**

手头通常会有两份材料：一份是“34 项才干排序”，另一份是“五大优势·伯乐版”。建议两份都传，顺序上先放“五大优势”，再放“34 项排序”。

这样安排的理由是：五大优势版更集中地呈现你的核心性格与偏好；34 项排序版则能补出盲区和后备力量。上传完可以补一句：“请把这两份报告放在一起看，分析我的性格长板，以及更适合往哪些方向发展。”

**问题 3：只报 MBTI 类型，AI 就下结论，准吗？**

这属于正常机制。MBTI 是标准化人格类型模型，模型看到 ENFP 这类类型，会直接调用常见画像来回答。想更细，可以把报告原文一起给它，并说明：“我是 ENFP，请结合下面这份报告原文，分析我的沟通方式、理想工作节奏，以及适合的内容方向。”这样它参考的是测评细节，而不是只凭四个字母判断。

**问题 4：这些材料是在一个窗口做完，还是分开更好？**

推荐做法：所有动作都留在同一个会话里。先完成向内探索、MBTI 测评、盖洛普测评；打开模型后输入 MBTI 类型并提取分析；同一窗口内输入盖洛普提示语并上传报告；最后上传长板资料，让它把前两部分合起来，产出一份优势总结。适合想一次跑通、方便汇总的人。

不建议的做法：每做一部分就新开一个窗口。这样也能操作，但模型容易忘掉前文，内容被切碎，整合起来困难，你自己还要反复复制粘贴，流程更乱。

**问题 5：MBTI 和盖洛普必须都做吗？**

不是强制二选一，也不是必须凑齐。看你手上有什么：两者都有，优先用盖洛普做分析，因为它更聚焦优势，也更适合职业与定位；只有一个，比如只有 MBTI，也先用它推进，不影响后续。一句话：手上有什么先用什么，不必等材料齐全；盖洛普优先级更高，MBTI 也能提供方向线索。

**问题 6：AI 工具选哪个？**

ChatGPT：生成稳定、总结能力强，但使用门槛是需要外网。DeepSeek：中文理解好、逻辑清晰，门槛低且免费。腾讯元宝：DeepSeek 卡顿时可作备选，在国内工具里算顺手。优先次序建议：ChatGPT 第一，DeepSeek 第二，腾讯元宝第三。设备能上外网，首选 ChatGPT，体验会更顺。

# 2.3 找到自己的独特卖点

如果模型给出的初步定位还不够独特，可以加入独特卖点（UPS）法，作为打造 IP 和内容创作的起点与框架。不要从“我要讲什么”出发，而要从“用户的卡点加我独有的解法”出发，才能建立差异化表达：世界上有一个问题或痛点；我有一个解题思路；我的思路有哪些差异化优势。

具体可从三个维度，结合长板档案自问自答：
- 别人难做到的：你会什么特别的？你独有的资源、经历、能力是什么？例如我能做 AI 设计，有设计加私域运营加营销的复合能力。
- 别人讲不清的：你能讲简单吗？别人没讲好、你可以说得更简单。例如我能把复杂知识讲得很接地气，有很强的内容输出能力。
- 别人做不细的：你能更用心吗？细节能比别人更极致吗？例如我做的视觉更高级，私域服务更贴心。

输出你的独特卖点（USP），参考句式：“我帮助【某类用户】解决【具体问题】，通过我独有的【某种方法/视角/能力】，让他们能【获得怎样的结果】，这是别人很难复制的，因为我拥有【特别的资源/经历/表达方式/复合能力】。”填空时记住三个原则：目标群体要具体；问题要痛点明确；表述要简单直接。
