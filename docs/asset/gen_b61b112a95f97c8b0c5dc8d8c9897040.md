# 案例一：@沙拉如何让私房面包店日营收破3000

开店前，我经营家庭烘焙工作室已经三年，积累了一个150人的初始客户群。平时大家会在群里用小程序接龙的方式下单买面包。疫情封城那段时间，人们的关注点大量迁移到线上，我也趁势做了一轮拓客动作：

[PRE0]

因为面包品质确实过硬，封城期间不少顾客主动帮我做口碑传播，把朋友邀请进群。每推荐一位朋友、每邀请一位新朋友入群，我都会把推荐人的名字记下来，附赠一个面包礼包。同时，我把产品品质卡得很严，做到让顾客愿意主动介绍，这份推荐名单也就不断变长。

[PRE1]

靠这套转介绍机制，社群从最早的1个扩展到5个，日订单从十几单涨到六七十单，线上日营收由200多元提升到3000多元。线下客单价大约20元，而线上顾客的客单价能达到40至50元，客户质量更高。

拓展线上客户时，我总结了三个小方法：
第一，找美食群主合作。主动送上面包和蛋糕，和对方商量，在她的美食群里发起我们的面包、蛋糕接龙。
第二，找到客户中的“超级链接者”。这类人往往是情商高、人缘好、人脉广的宝妈。我的客户群里就有一位这样的邻居宝妈，经她介绍来买产品的熟人不少。
第三，找到真正懂面包、会拍照摆盘、生活有仪式感和格调的美食达人顾客。他们常会主动在群里晒出拍得很有质感的实拍图，其他顾客看了更容易产生兴趣并下单。

**朋友圈内容怎么发**
朋友圈的内容，我大致分四类：
一是专业内容：分享烘焙知识、行业资讯、自己的观察与思考，以及帮面包学员处理问题的成功案例；
二是生活内容：陪孩子阅读的日常、育儿中的小趣事；
三是个人成长：健身记录、读书感悟、冥想练习的分享，也会记录与高能量圈层朋友交流的互动，呈现自信、坚韧、勇气、真诚、用心、努力这些正向状态；
四是好评素材：经顾客同意后，把头像和昵称遮掉，发他们的产品好评截图，也会写顾客下单背后的小故事。
另外，我会主动和顾客的朋友圈互动：给他们点赞，留下真诚的评论和夸赞。

**给顾客打标签**
每位顾客我都会打标签，写在微信好友备注里：姓名、居住区域、孩子数量、偏爱的面包类型，以及其它兴趣和特点。把顾客情况摸透，关系更容易拉近，服务也能更贴合他们的需求。
