步骤二：三件工具把 PRD 变成原型

接下来进入步骤二。这里会用到三样东西。

**stitch**：Google 推出的前端代码生成工具，擅长把创意快速落成好看的 UI 界面。官网：https://stitch.withgoogle.com/

**web-design-guidelines**：一套网页设计准则，为 AI 明确审美与排版应遵循的标准。

**doc-coauthoring**：一项文档协作技能，协助我们更顺畅地读取、利用前面生成的 PRD 文档。

准备就绪，开始实操。
