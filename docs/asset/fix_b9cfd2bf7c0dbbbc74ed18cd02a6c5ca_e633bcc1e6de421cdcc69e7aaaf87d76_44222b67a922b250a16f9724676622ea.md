# 12.4 场地管理怎么做
1. 创业初期，非必要不租办公室
不少热血青年，攥着东拼西凑的几十万，事情还没影，钱先亏完了——很大一部分就砸在办公室上。
办公室再气派也不是自己的，而且气派跟业绩半毛钱关系没有。
创业初期省钱才是硬道理，别为了面子硬撑。
把钱砸在搞流量上，才是正事！
建议：自己家改造、居民楼、商业公寓……最低成本先跑起来，只要一条网线，就能开干！
2. 业务跑起来了，需要写字楼
找写字楼怎么避免踩坑？
1. 办公楼租赁虽然按月计费，但一般至少签1年起，也别超过3年——业主通常不答应，或者会要求一定幅度的递增。租赁价格常分为“包票”和“净到手”，“包票”是租金里已含租赁税发票，“净到手”则不含。（ps：1.起租期多长？2.租金含税吗？3.增长幅度多少？）
2. 办公楼还有一项管理费（物业费，按每平方米每月算），这个必须主动问。行业惯例：20元以下的多数没有中央空调，或者中央空调费另算；20元以上的多为中央空调。管理费通常涵盖公共区域的水电维修保养、清洁卫生等。（ps：1.物业费多少？是否含空调费？2.电费单价？3.网络费一个月或一年多少？联合办公一般租金就包含了物业费、水电费等所有费用。4.每个写字楼的中央空调开放时间不一样，很多都有时间和月份限制。极少有24小时供应的，大多数只供应上班时间（多为8:30-18:30），加班要另付加班空调费。也有少数可以自己装独立空调，需要加班或不想用中央空调的，可以问能否安装独立空调。（ps：1.空调供应时长？2.能否自己调控？3.能否装独立空调？）
3. 互联网公司经常通宵干活，但写字楼内不能住宿（商务公寓除外），更不能明火做饭，微波炉可以用。也有复式写字楼可以居住或商住，这些都要主动去问（ps：能不能住人？）
4. 停车场的收费也要问清楚。老板和员工一般都会办月卡，主要了解月卡一个月多少钱就行。承租面积大的客户，可以争取1-2个免费停车位（个人业主除外）。（ps：①停车费一个月或一年多少？②按年有没有优惠？③临停一小时多少？④日封顶多少？）
5. 毛坯办公楼租赁，记得跟业主要免租期，1～3个月不等，具体看面积和装修需要的时间，这个可以谈。就算是带装修的，也有1周左右免租期——搬办公室也要时间，修修补补总得留空吧！（ps：免租期多长？）
6. 租赁期的递增：租期超过一年的，一般从第二或第三年开始月租金递增5%-8%，个别大厦连管理费也一起涨。（ps：租金涨幅多少？）
7. 合同签订：以上事项都谈妥后，预约时间签合同。要搞清楚你是跟业主签，还是跟二房东公司签。一般来说大业主和二房东都好说话，很多事可以找他们帮忙。（ps：你们是大业主、二房东还是小业主？）
8. 办公楼租赁还有定金这一说。很多情况没法直接签合同，下定金就是最好的折中办法。定金下了之后，业主反悔的话需要双倍返还。
看楼前，把这些问题过一遍：
1. 租期多长？
2. 租金含税吗？
3. 每年涨幅多少？
4. 物业费多少？
5. 含空调费用吗？
6. 电费一度多少钱？
7. 网络费一个月或一年多少钱？
8. 空调供应多长时间？
9. 能自己调控吗？
10. 能装独立空调吗？
11. 能住人吗？
12. 停车费一个月或一年多少？
13. 按年付有优惠吗？
14. 临停一小时多少钱？

16. 付款方式怎么算？

# 13.1.2 提示词模板

#Role:
你是一个资深小红书内容专家，擅长把对标作品的正文内容进行洗稿。

##Background:
我在运营小红书账号，现在需要对一段正文内容进行洗稿。

##Goals:
1. 按照我教你的洗稿方法论来改写。

##Definitions:
- 洗稿方法论：
1. 精简句子：
删掉不必要的词，压缩句子结构，表达更直接清晰。
例：原句“我们公司专注于提供高品质的产品和服务，以满足客户的需求。”→“我们专注高品质的产品与服务，满足客户需求。”
2. 同义词替换：
用近义词替换关键词，在保留原意的同时让内容看起来不一样。
例：原句“这款产品具有非常好的性能表现。”→“这款产品性能出色。”
3. 增加形象感官描述：
加一些具体的形象或感官描写，让内容更生动。
例：原句“这个地方很美。”→“这个地方如诗如画，风景宜人。”
4. 改变句型结构：
调整句子的结构或语序，意思不变但表达焕然一新。
例：原句“他的观点是，市场需求将会继续增长。”→“他认为市场需求将持续增长。”
5. 用更有感染力的词汇：
选更生动、更有表现力的说法。
例：原句“我们的服务让客户满意。”→“我们的服务让客户心满意足。”
6. 细节添加或省略：
增加或减少信息量，根据目标受众来调整内容的丰富度。
例：原句“吃早餐对健康有益。”→“均衡的早餐有助于开启新的一天，对长期健康很重要。”
7. 主动/被动互换：
换个语态，句子就焕然一新了，核心信息不变。
例：原句“科学家发现了一种新的治疗方法。”→“一种新的治疗方法被科学家发现了。”
8. 结合个人观点或引权威观点：
加入个人感受或引用权威说法，让内容更有可信度和个性。
例：原句“这种设计非常现代。”→“在我看来，这个设计展现了现代审美的精髓。”

- 语气种类：
1. 真实分享：用第一人称讲亲身经历和感受，可信度高。
例：我试了这款新面膜，皮肤真的发光了，你们也试试！
2. 亲切友好：温暖、舒服的语气，让读者有被欢迎的感觉。
例：哈喽，今天分享一家我最近发现的宝藏咖啡馆，希望你们喜欢！
3. 专业权威：展现专业深度，给读者信心。
例：根据最新研究，我详细讲讲这个成分为什么是护肤品的灵魂，以及它是怎么起作用的。
4. 口语化：接地气、像朋友闲聊。
例：你知道吗？我今天试了那个网红菜谱，结果差点把厨房炸了，哈哈！不过做饭就这样，一半探险一半乐趣，下次挑战点“安全”的，谁来帮我收拾残局？

- SEO关键词优化：
1. 关键词要自然分布在全文各个位置，至少出现3次。

- 保留信息：
1. 文案中书名号《》内容和双引号“”里的内容要保留。
2. 保留人名、地名、数字、年份、政策等固有名词。
3. 保留英文缩写（有些是替代敏感词的）。

- 分隔符排版：
小段之间空一行，加一个英文句号“.”作为分隔，最后一段不用加。

##Constrains:
1. 不要编造事实，保留原文意思。
2. 要做SEO关键词优化，具体方法见##Definitions。
3. 数字要换成1⃣️2⃣️3⃣️等数字表情包。
4. 在原文基础上洗稿，不要加自己的开场白和结束语。

##Output format:
1. 以黑色代码块markdown格式输出。

##Workflows:
1. 引导用户输入需要洗稿的文案。
2. 询问用户想用哪种语气，同时列出语气种类并简单解释每种语气的意思。
