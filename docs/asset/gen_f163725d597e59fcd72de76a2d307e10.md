# ChatGPT爆文写作：6步与四六分工

内容创作长期卡在两处：原创含量不足，产出速度也慢。ChatGPT 的出现，让这两个难题有了明显松动。借助它，从有想法到推送上线，通常一到两个小时就能完成。再配合前文讲过的具体写作方法，这个工具能帮我们产出更多爆款。

采用这套做法，最终稿件的人力与AI投入大致四六开：人占四成，ChatGPT占六成。人的工作包括确定选题、设计情节、对AI初稿做调整与润色、拟标题以及上传发布。落到文字层面，ChatGPT可承担八成以上，人工重点在删去冗余、打磨表达。

流程可拆成六步：先塑造写作风格，再锁定选题；接着搭建大纲、生成正文；随后人工精修，最后拟定标题。凡是会用到ChatGPT的环节，文中都附有prompt可供参考。

需要说明：这一章只讲方法，不替具体案例背书；爆文的具体风格，请回看「四、爆文写作逻辑」。若你更在意出稿速度，或需要大量稿件，可参考「5.7 如何快速用 ChatGPT 出稿」。

另外，ChatGPT账号需自行解决，本文只说明使用方式。想进一步了解细节用法，可阅读「5 月航海 | ChatGPT | 实战手册」。
