# 7.1 个人主页带货：橱窗上架指南

个人主页可以展示商品橱窗，而且粉丝量没有门槛；不过前提是，先到选品中心把想带的商品加进橱窗。入口这样走：

[PRE0]

1. 打开创作者中心，进入「带货中心」；
2. 在「带货中心」里点「去选品」；
3. 到选品中心搜索目标商品，点「加橱窗」即可加入。

但只在选品中心往橱窗里添商品，往往会碰到这些麻烦：

- 搜不到心仪商品：想带的东西选品中心没有，收益机会白白错过；
- 佣金比例偏低：替别的商家卖货，赚头有限；
- 僵尸商品：对方随手挂品，后续可能根本不发货；
- 商品被选品中心下架：已发布的带货视频会失效，订单也难再产生；
- 转化不理想：从商品进来的咨询，其他商家未必及时处理；
- 退货率偏高：对方发货慢，客户等不了就退。

所以更稳妥的思路，是把商品放到你信得过的人的小商店里（后文会讲“信得过”有多重要）。操作如下：

[PRE1]

1. 让小商店管理员发来关联视频号的邀请；
2. 进入选品中心，点右上角「橱窗管理」（选品中心路径：创作者中心 → 带货中心 → 去选品）；
3. 选中已绑定的小店；
4. 挑好要带的商品，点「添加橱窗」；
5. 完成。（截图里的店铺仅作演示，商品不代表带货建议）

为什么强调“信得过”？因为小商店管理员能改商品佣金率。一旦带货起量，不靠谱的商家可能把佣金调到 0，结果你从第二天起的订单一分钱都拿不到。这个心眼必须留。

还要特别留意：按 7 月 21 日的新规，新视频号不能再绑定小商店，也就无法把小商店商品加入橱窗。想把橱窗运营得更安全、更稳，建议先看这些官方规则合集：

[《视频号橱窗带货规则总则》](https://support.weixin.qq.com/cgi-bin/mmsupportacctnodeweb-bin/pages/axzzmpdhcPsqWfJB)

[《【视频号橱窗】管理规则合集（可对外）》](https://docs.qq.com/doc/DTnVBdlZYRFJKTXJi)

[《视频号橱窗达人违规管理规则》](https://support.weixin.qq.com/cgi-bin/mmsupportacctnodeweb-bin/pages/GnthDa5G3By6vyDL)
