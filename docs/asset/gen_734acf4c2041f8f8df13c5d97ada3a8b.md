# 3.9 搜索后的用户动作，会左右排名

结论先摆出来：会。

当用户搜完一个词，随后给作品点没点赞、有没有收藏、是否关注、留没留言，这些动作都会影响搜索结果。原因在于，搜索排序并不是只看一个维度。

账号分与内容分，首先看长期沉淀——粉丝体量、领域是否聚焦、过往内容互动表现等，都属于历史积累。另一块评分则来自当下：一批用户在近期搜到并接触你的作品后，做出了哪些即时动作；平台会更看重这段时间里的反馈。

所以，平台在给搜索场景中的作品打分时，会把过往沉淀和近期互动合并考量。近期行为主要看什么？

以短视频为例：点开观看的比例、赞、藏、关注、留言等常见互动都算；还有一个很关键的指标叫“问题解决率”。用户看完你的视频后，是否还会转去点开别人的内容。如果这种情况频繁出现，往往说明他的需求没被真正满足；这类信号积累多了，排名也会被拉低。

直播场景里，进入直播间的点击率、停留多久、留言、送礼物、加粉丝团、关注、下单购买等，都会形成反馈。

商品场景里，则包括商品点击比例、下单转化、停留与收藏等动作。

一句话：搜索后的反馈越正向、正向动作越密集，作品得分就越高。

归根结底，根基要稳，细节要做透。
