# 6.5 如何筛选长期合作的供应商

前期先用一件代发做起来，等单量涨上去了，再谈长期合作。筛供应商主要看两个方向：

# 6.5.1 配合度

供应商不配合，发货、售后会特别累。重点确认这四点：

1. 是否配合电子面单。当日订单超过10单，就可以找供应商谈绑定电子面单，之后下单和发货都能在线完成。前期单量少时人家不一定答应，建议出单后再聊。

[PRE17]

2. 售后咨询回复是否及时。前期你还不够熟悉自己的一件代发产品时，用户问的问题都需要供应商帮忙解答。一个问题半天等不到回复，大概率会影响店铺成交。而且回复慢往往说明对方没有专门的客服团队，属于小供应商，稳定性差，说不定哪天公司就没了。

3. 发货是否及时。📕对发货时间有要求，一般是24小时或48小时内。找供应商务必确认发货时效，最长不能超过48小时。超时平台会扣延迟发货费用，通常一单3块。另外，如果个别订单实在没办法按时发，要主动和客户沟通，千万不要提前填快递单号——填了但物流不更新，会被视作无效，一样扣钱。

4. 是否支持退换货。这一点不强求，要看原因。用户个人喜好导致的退换货，很多产品不支持，比如服装类大多数供应商不退。但如果产品本身有质量问题，一定要支持退换。连这都不支持，这家供应商可以直接放弃了。

# 6.5.2 产品方面

1. 价格。刚开始一件代发，量小，没有议价权。等日订单稳定在50单以上，就可以谈更低的价格。同时要确认自己的价格在同行里有没有优势。如果自己的成本价已经等于别人的卖价，而且是一模一样的产品，说明供应商没给你好价；这种还不肯降价，那就换。

2. 款式。有些品类更新换代特别快，比如手机壳、穿戴甲，要看供应商能不能及时上新品，有没有开品能力。一些小众蓝海品对开品要求很高，尤其是设计师出品的珍珠项链、饰品这类，如果款式不更新、不开发新品，不适合长期合作。

3. 质量。这是最核心的，不用多说。质量不行，售后会大量爆发，处理起来麻烦还不赚钱。

4. 补货时效。供应商有工厂和门店之分，门店货一卖完，短时间内可能补不上，就得等补货。靠谱的供应商补货时间一般不超过48小时，这样才不会耽误📕的发货时限。要是长期补不了货，也不值得长期合作。

# 7.1 📕站内选品

# 7.1.1 低粉爆款选品法

什么是低粉爆款？简单说，就是带货账号粉丝低于200，最近7天内发的单篇带货笔记点赞过100，而且这款商品销量大于100。这种品，通常就是站内正在被验证、有潜力的爆品，找到的目的就是为了第一时间跟进截流。

相比抖音创意中心，这个方法更适合做女性产品类目的人——毕竟雪莉枚U型枕、发箍、帽子这些爆款，都是先在📕爆起来的。具体操作方法有两个：一个用灰豚数据，一个手动刷。不同品类实际用起来有差异，前期建议两个搭配着用，多维度观察。

# 7.1.1.1 灰豚数据低粉爆款选品法步骤

工具只是手段，按自己的习惯来就行：

第一步：打开灰豚数据。

第二步：点击笔记查找，选择笔记搜索。

第三步：勾选【带货笔记：是】。

第四步：勾选【低粉爆文】。

第五步：搜索你要做的对标品类，比如想做连衣裙，就搜“连衣裙”。

就算用了灰豚数据，筛选标准也不能变：对标账号粉丝要200以下，7天内点赞大于100，带货笔记里的商品销量大于100，才符合低粉爆款选品的条件。

# 7.1.1.2 在📕内手动刷

确定好品类（比如帽子）之后，可以拿一个小号，持续搜索帽子相关内容。系统会慢慢给小号打上“对帽子感兴趣”的标签，然后持续推送帽子的内容。

刷到推送笔记时，点进作者主页看一眼，如果粉丝很少（尽量小于200），就顺手关注、点赞、评论一下。系统会记住你喜欢这类低粉账号的内容，后面就会优先给你推更多低粉爆款帽子笔记。

这样每天用小号刷一刷，你就能第一时间知道最近出了什么新款、什么文案和封面跑得更好。这个方法看起来花时间，但刷的过程本身就是在培养品感和网感。

# 7.1.2 对标帐号选品法（截品）

# 7.3 不同选手的选品侧重点参考

# 7.3.1 新手选品：跟最新爆品

新手别一上来就只卖自己想卖的东西，要紧跟近期热度高的产品，越新爆起来的越好。

在1.0阶段，有个基础判断方法：去做抖音创意中心爆款榜上的产品。注意别太纠结数据的绝对值——什么销量必须大于多少、点赞必须大于多少，没必要。能在创意中心榜单上出现，就已经是好产品了。

新手阶段最怕贪多，想去学一套特别复杂的选品方法。其实把创意中心选品法用透，足够让你跑通正反馈。跑通以后，再考虑进阶的差异化能力。

# 7.3.2 进阶型选手：同步跟📕站内爆品

进阶选手一般指：素材制作能力强、封面做得好、已经跑通正反馈的人。

到了这个阶段，可以同步去关注📕站内的爆品，也就是低粉爆款选品。和1.0阶段的关键区别在于：如果这个品在📕站内也爆了，说明它不仅能在抖音爆，在📕同样受欢迎，这也就进一步验证了它在这个平台的适配性。

但同步跟品的问题也同样明显：别人已经爆了，说明竞争已经存在。你就需要更快的跟品速度和更强的素材制作能力，才能脱颖而出。

# 7.3.3 更天赋的选手：提前挖掘需求产品 / 高爆品

如果你能力更强，能预判爆品，当然要走挖掘这条路。

一方面，可以提前布局：秋冬天之前，陆续上一些季节性产品，比如手膜、脚膜、暖手袋；节假日之前，布局出行产品，比如化妆收纳包、高铁搭子（毛毯、U型枕之类）；夏天之前，布局拖鞋、减肥运动器材，比如滚腿神器。

另一方面，可以针对爆品发力：爆过的产品一定还能再爆。如果你的技能更强，不靠抄别人的爆款素材和封面，而是能自己创造爆款封面和素材，那你就会成为新手模仿的对象。每一个爆款，本质上都是天赋选手对之前爆款内容的再加工。

# 八、📕 SEO

# 8.1 📕 SEO 的底层逻辑

SEO全称Search Engine Optimization，也就是搜索引擎优化。📕SEO，就是通过优化笔记里的关键词，来提升笔记在搜索结果里的排名。

现在很多用户已经把📕当成“百度”来用了——数据显示，70%的用户喜欢用📕的搜索功能，吃喝玩乐之前都会先搜一搜攻略。

举个例子，圣诞节想送朋友礼物，很多人会打开📕搜“圣诞礼物”，然后挨个点开相关笔记，尤其是排在前面的。如果内容打动了他，就会跟着博主买同款，完成从种草到拔草的闭环。

所以搜索入口来的用户，消费意愿通常非常强。搜索流量就是超精准流量，也可以说是一种“躺着赚钱”的流量。

某个搜索词下，你的笔记排名越靠前，用户看到你产品的机会就越大，你也越容易主导用户的消费决策。

这就是📕SEO的底层逻辑。

# 8.2 📕 SEO 流量介绍

明白底层逻辑之后，我们再来看做📕SEO的三个好处。

1）流量精准，用户转化率高

不管你是纯博主还是商家博主，核心关注点无非两个：流量和变现。流量是变现的前提，所以怎么拿捏流量，是每个博主的必修课。

📕最主要的流量入口有三个：首页推荐页、关注页和搜索页。

[PRE25]

首页推荐页是打开App的默认页面，流量最大，竞争也最激烈。普通人想上首页推荐，难度不小，需要足够优质的内容。关注页大家打开频率不高，尤其你关注的人多时，很容易就被刷没了。

剩下的搜索页，更适合普通人突围。只要你有一篇笔记能排到前面，整个账号就能持续获得流量。前面说过，搜索流量属于主动种草型，用户带着明确目的而来，精准度高，转化率也高。我们很多账号，来自搜索端的粉丝占比都超过了一半。

2）免费流量，不拿白不拿

一般来说，一篇笔记的自然推荐周期只有3-7天。即便是爆款，随着时间推移，系统在首页推荐页给它的流量也会逐渐减少。平台要留住用户，就必须不断补充新鲜内容。想继续在首页占位置，只能靠广告投放来维持。

但搜索流量不一样。只要你的关键词布局到位、笔记没有违规，它就能一直被用户搜到。两三个月前的笔记，甚至一年前的笔记，都还能给你带人。这相当于在平台放了一个长期有效的广告，而且不花钱。这么香的流量，不拿白不拿。

3）矩阵运营，占领赛道流量
