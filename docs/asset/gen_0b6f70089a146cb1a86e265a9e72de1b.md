# 体制内破圈：副业年入20万+的实战复盘

不少在体制内、公务员岗位或特殊行业的朋友，一提到副业就先被各种顾虑绊住：朋友圈发条动态都怕被领导和同事刷到；微商不愿沾，觉得卖货不体面；短视频不敢出镜，担心露脸不合适……这些包袱越背越重，脚步自然迈不开。如果你也卡在这种状态里，下面这份复盘或许能给你一点新思路。

## 我跑过的几条副业线

**1、进口母婴海淘**

2012年怀孕时开始尝试，本意只是给自己囤货，在朋友圈找熟人拼单，靠口碑慢慢扩散。我自己从海外网站采购、在国内销售，边买边卖赚到第一桶金，孩子养育开销基本由海淘覆盖，具体赚了多少倒没仔细算过。18年前后因为一些原因逐步停掉全部业务，现在回看，当时解散一个300多人、复购率很高的精准客户🛰️群，实在可惜。

**2、民宿个人房东**

我是斜杠的民宿房东，手上最多时运营4套房，目前2套在运营，属于个人小房东。把自家郊区房和40平学区房盘活后，租金收入实现翻倍。过去三年很难，民宿圈淘汰了不少人，尤其过去一年格外不易，好在熬过来了，从2022年12月开始慢慢恢复。2023年3月最近20天，单一个平台的房租收入已有7000+。

**3、家居社群创始人**

2021年6月开工装修自住二手房，同时开通装修围观群；2023年2月把群从免费升级为付费社群，有了第一笔社群付费收入。一周拉新30+，目前社群成员120+，199限时优惠中。

**4、一对一咨询**

2022年年底开始尝试私人咨询，主要围绕房产购买、学区规划、装修建议等。从一开始不收费，到红包随意，再到199/h，最近涨到单次999/3h，把自己的时间和精力越卖越贵。前几天还接到紫菜大神圈友关于房产、装修方面的咨询，体制内怕啥，跨领域的知识付费真的可以。

## 破圈的底层逻辑

**1、先接受本职工作的边界**

首先，不要试着在底线附近摩擦。事业单位若有明文规定，比如不能做直播带货、不能涉及与学校相关产业的资金交易，那就主动避开。

**2、给自己划一条底线**

我给自己定的标准是：不做工作范围内同事、家长的生意，尤其是家长，哪怕孩子已经毕业，也不动用家长资源。虽然每年经手上百个家庭的详细资料，但我不想利用。工作范围内的学区咨询、购房建议等内容，全部免费解答。这是我给自己的底线。

**3、从兴趣爱好里找切口**

想破圈，兴趣是很好的起点。我曾尝试用折纸手工做成礼盒出售来变现；现在则靠对家的热爱、对装修家居的喜好输出内容来变现。生活类领域每个普通人都绕不开，体制内想破圈完全可以从生活入手：警察可以分享每日健身，老师可以分享育娃小妙招，医生可以分享营养减脂餐。把下班后的生活分享出来，包袱会少很多，每个人都有下班后的8小时。

我自己靠什么赚钱？就是下班后倒腾自家房子。赚点房租跟我的工作有什么关系？领导会来干涉吗？不会，那就大大方方折腾。

**4、技能不够，行动来补**

副业想赚钱，光靠为爱发电不够，还需要一些基础技能。直播不能干，可以拍视频；视频不想露脸，可以做图文；图文不方便，起个笔名只写文章也行，鲁迅、巴金、冰心，笔名随便取，别再喊“我不行”。关键还是那句话：得行动起来，先把0-1跑通。

比如星球里的各种训练营、陪跑营，紧跟步伐试一试，说不定就跑通了，先挣到第一块钱。我从2020年入龙哥盟，到22年加入玩赚星球，尝试过TIKTOK、知乎好物、📕等，虽然变现不多，但都算跑通了。积累的网感、图文编辑能力、视频剪辑能力、写作能力，都是提升核心竞争力的东西，每一秒、每一天的努力都不会白费。

**5、提前接受孤独感**

突破舒适圈，有个逃不开的困扰：体制内一成不变的思想会腐化一个人的心智，桎梏行动的脚步。我曾一度怀疑，自己的世界观、人生观、价值观怎么如此格格不入。

在体制内单位，不需要多努力，每天固定时间上下班，基本一眼能望到退休。耳边同事聊的内容，无非家长里短、油盐酱醋，老公、婆婆、孩子、衣服包包化妆品……常有人问我：又买房了？又装修了？花20W租房住？你太折腾了吧。

工作中，同事聊的话题我不想参与。比如有同事名下不少拆迁房，却一套也不愿卖，把全家老小困在一套小户型里，还要吐槽公婆这不好那不好；我想帮一把，但人家不愿意折腾。而我感兴趣的话题——房屋买卖置换、装修提升租售比、社群运营、ChatGPT、知识付费，她们一个名词都听不懂，那就不开口好了。

现在的我，工作中只聊工作，不再内耗，甚至尽量减少午餐、午休时与同事唠嗑的时间，避开人群找个角落看看社群消息，学点想看的课程，写点副业心得，一个人挺好的。

## 破圈实操技巧

**1、把别人坚持不了的小事做久，关注自然会来**

不管哪种形式，坚持都是破圈赚钱的核心：坚持写作、坚持发朋友圈、坚持健身、坚持输出图文笔记、坚持拍vlog……没方向时，就选一个简单行动，坚持做就对了。

土豆妈是怎么破圈，让@梁靠谱 关注到我，多次在群里、直播中提起我，甚至还单独发朋友圈介绍我？其实我只做了一件小事：写每日复盘，少则20字，多则2000字，坚持600多天，二胎生娃当天也没断更。靠谱就是一路围观我这600多天，看我如何买卖房子、装修房子，顺便生了个二胎。

**2、愿意分享：流量、影响力与收入往往同路**

想扩大收入或影响力，就把自己的点滴收获分享出来，告诉别人。多输出，才有收获。

比如我写的一篇五年买卖6次学区房赚百万的经验，帮我引流了好几个付费私人咨询。紫菜大神也来加好友，做房产买卖、装修相关的个人咨询。前几天我发现龙哥老大家里也在装修，就毛遂自荐，分享了一下我的社群思路，也得到龙哥肯定。最近一个月社群运营特别有干劲，方向对了，跑得更顺畅。

**3、别把自己看得太重，赚钱可以坦坦荡荡**

体制内的朋友，大多有这样那样的思想包袱。今天这篇复盘也想鼓励更多体制内朋友：别太把自己当回事，赚钱这件事不羞耻，大大方方干就对了。

朋友圈不敢发？把所有人一个个拉出来做备注标签，只分两类：【看广告】和【不看广告】。就像物品断舍离一样，但凡犹豫的，都暂时归到【不看广告】。分类清楚之后，还有什么不敢发的？

**4、边学边干，边干边调**

体制内的朋友常说：我啥也不会，也不知道能干什么。进了赚钱还怕没项目吗？每月都有各类大大小小的航海活动，先挑自己感兴趣的，跟着学起来，慢慢就有赚钱的感觉。

芷蓝一再提醒我，自媒体赚钱终究要有自己的IP定位和后端变现产品，而最基础的产品是什么？付费社群就是一个很不错的入门产品。

于是今年一月底过年期间，我马不停蹄地把搞了一年半的免费社群转成付费社群。一开始定价99/年时，我是怀疑的、不确定的；一步步优化、完善后，甚至觉得这么有内容、有价值的社群值得更高定价。

这种从0-1的尝试，失败了无非浪费点自己刷手机、刷剧、买买买的时间，损失成本接近于零，大胆去试就对了。

不管体制内还是体制外，在职还是裸辞，先放下过多的包袱和顾虑，行动一下吧。

说到底，今天你折腾了吗？
