# 案例一：刷小红书，我挖到 ChatGPT 工具机会 @AUDI

航海项目收尾后，我保留了一个习惯：有空就刷小红书。浏览轨迹一路延伸，从虚拟资料、转码、论文神器、效率工具，最后落到 Python 作业和 ChatGPT。

那时 ChatGPT 还没真正出圈，但长期泡在生财有术风向标共创群，我隐约感到这里藏着不小的信息差，大概率会火。于是暂时放下手上的工具站，转而琢磨怎样借势 ChatGPT，做一个能解决实际问题的产品。

小红书里 Python 作业相关内容很多：求改 bug、找代做、求代码指导的帖子不断出现。我由此想到，能不能做一款帮学生学代码、处理作业的工具？AICodeHelper 的雏形就这样出现了。

**1）冷启动：先验证需求，再快速上线**

17 年我曾做成小程序开发者论坛，沉淀过一套 SOP，这次便先拿它来试需求。

我先翻小红书 Python 作业帖子下的留言，和用户互动、私信，用“还接吗”“我能接，私信聊”之类的话术试探是不是伪需求。私信过去后，有人直接问做一单多少钱；联系我的人不少，这让我判断需求并非臆想。

验证之后，我在评论区做引流，打出免费代做 Python 作业的钩子，确实有不少人加过来，发来作业，还主动问怎么收费。我用 ChatGPT 把作业做出来，并发了篇带调侃意味的帖子——大意是“被 Python 作业难住？师兄来帮你”，同时挂上群聊。

产品形态我比较过 APP、小程序、网页和 Chrome 插件，最后认定网页单页上线最快，于是决定元旦当天用 ChatGPT 调教出前后端，直接完成上线，网址是 https://aicodehelper.com 。具体调教思路可参考《0 编程基础搭建属于自己的 AI 产品》：https://m.okjike.com/originalPosts/63bedf6b5b351a0c1425c368 。

产品上线后，我第一时间接入谷歌统计、百度统计，并向谷歌、百度提交网址收录；随后在即刻完成第一波冷启动推广。选即刻，是因为发帖可带图片或链接，而且它有按兴趣划分的圈子，天然适合冷启动。

围绕主产品词做 SEO 与外链铺设：在 CSDN、简书、博客园发博客，标题直接用产品名，正文做介绍并附上网站链接。这样以后用户搜索时，有内容能承接流量，也能通过文内链接跳转到 AICodeHelper。这段经验可参考我 17 年写的《小程序开发者论坛复盘》：https://mp.weixin.qq.com/s/phE1dQY5ZzklHmFAYQlNjQ 。

我的建议是：产品一上线，就该同步做 SEO 铺量。实测百度、谷歌通常要一周多才收录，不铺量的话，产品很难被搜到。

**4）借势热点：抓住 ChatGPT 出圈窗口**

这一阶段，我仍以小红书和即刻发帖为主：在自己的帖子里引流，在评论区置顶产品名而不是裸链接，也会去别人的帖子下截流。用户来源则靠两种方式判断：直接问来的人，以及看百度统计里的访客来源。验证下来，这些渠道确实有效。

2 月 10 日之后，ChatGPT 热度突然飙升，朋友圈和公众号推文都在刷屏。我注意到这个异常值，又发现同类网站还很少，于是复制页面，迅速做出 ChatGPTHelper。它主要解决一类需求：很多人不知道 ChatGPT 是什么，却想先尝鲜。随后我在即刻发帖推广，借了一波热度。

**5）流量变现：广告费之外的多路尝试**

流量稳步上涨，但体量偏小，一开始我没太大动力设计变现，只想着自动赚点谷歌广告费，算作为爱发电。后来流量变大，网站经常卡，需要更多服务器和账号，成本上来了，我也希望网站能帮到更多人。于是开始把注意力放到更有利于变现的内容和思路上。

我试过这些路子：①推广别家产品拿分佣；②分销别人的 AI 内容专栏拿分佣；③自己写专栏做知识付费；④私域变现；⑤出售源码。

成绩上，单日最高变现 1k+。但现在这套不太行了：热度下降，ChatGPT 应用产品越来越多，能直接上官网用 ChatGPT 的人也越来越多，泛流量需求被更多竞品和官网分流承接。

**6）回归长线：细分产品与流量基建**

基于 ChatGPT 的应用逐渐增多，同质化产品不少，但细分场景仍然不多，这就是机会。

①继续做细分产品，例如基于 ChatGPT 能力的翻译、口语练习、语法润色、周公解梦、生成情侣昵称、起名、周报生成器、自动化测试脚本生成器、SQL 生成器、一键总结视频概要、智能客服 SOP 机器人等；②关注细分产品的用户群体；③持续做 SEO 基建，流量依旧是命脉。

**7）踩过的坑：产品形态、变现、专栏与流量**

①产品形态：我曾纠结做 APP、小程序、谷歌插件还是网站，最后认定【完成大于完美】，先快速上线再说。

②变现：流量变现和分销专栏前期效果不错，后期变差；网站新老访客都在，需要测试并定期换品。

③专栏：自己写专栏我不太建议，容易陷入交付牢笼，还会占用大量精力做售前售后维护；可以考虑分销别人的专栏。

④流量：目前只做了主要关键词的 SEO 基建，长尾词流量一直没铺，后面还得持续补。
