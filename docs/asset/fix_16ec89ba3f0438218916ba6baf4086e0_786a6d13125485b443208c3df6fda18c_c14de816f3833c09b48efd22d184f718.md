# 做号十年：复盘、教训与给新人的实话

各位好，我是 Crossin，主理“Crossin 的编程教室”，平时产出 Python 教程和实战案例。小灰老师约我写点自媒体运营心得，于是有了这篇。

先交代一句：此刻做总结，时机并不完美。图文账号的阅读比前两年逊色不少，个人事务缠身，运营近乎半停；镜头内容才刚上手，流程和方法都未成型。所以它既不是赢家模板，也谈不上败局复盘，更像一份路上随手记下的账本。下面按六块展开：经历、热门作品、收入、做对之处、踩坑之处、给新人的话。

## 一、时间线：从兼职试水到全职转型

2013 年，我开了个公号，把 Python 入门内容做成系列更新；知乎那边，也顺手回答编程类提问。

那时公号新鲜又小众，没有成熟商业路径，“自媒体”这个概念都还模糊。好处是竞争少：内容扎实且稳定更新，大号愿意转荐，号主也爱搜集好号。知乎正处上升期，用户多是学生和初入职场者，偏知识技能；平台对导流宽容，回答里贴二维码没人管，百度收录也给权重。技能分享加导流公号，是难得的窗口。

之后几年，我本职在游戏行业，公号只当兼职，更新很少，粉丝却一直涨。期间接过两次广告，大约 1k/次，其中一家尾款没结，但总算破了零。

2016 年，我全职做自媒体，年中上付费服务，下半年注册公司、组队、参与孵化。知识付费刚起，移动支付普及，大家线上付费意愿强，机构还没大规模入场，公号广告也少，只能自己设计课程、训练营。知识星球当时还叫小密圈，生财有术也刚出现，我是早期用户，从生财有术学到不少。第一版会员连课都没有，只做 QQ 群答疑，几十个名额瞬间抢空，给了我很大信心。

2017 年，我开始搭团队，想做“内容吸引—培训收费”的闭环。经验不足，团队效能没出来，我的产出反被拖累，两头不理想。总体没大亏，用户也涨，但状态别扭，2018 年初散伙。

2018 年，我试短视频。抖音刚火，一周做出千万播放，可惜与编程无关，也没找到结合点。同期公号广告投放爆发，重心回到图文，抖音搁下。

2019 年，我想转视频但不够重视。公号广告市场好，商单多，是图文舒服期；找了几位远程兼职帮忙。B 站从二次元破圈，我是老用户，更早混 A 站，却没认真把编程内容放上去，又成“早醒晚出门”。有几期播放不错，仍未当主渠道。

2020 年，我正式把自己当“自媒体”。疫情对公号主冲击不大，线上流量反而增，我多卖网课；一月初退掉办公室，变成单干自由职业，意外避开损失。但金主日子渐难，2021 下半年广告明显缩水；视频压过图文，知乎转向故事化，我的数据难看，于是半躺平，学指弹吉他、打鼓、攀岩，偶尔去公园抖空竹。

2022 年中，我下决心转短视频，做编程教学，主攻抖音和 B 站，同步视频号、小红书。数据不算炸，但稳步向上，暂以内容为主继续。

## 三、收入这笔账

很多人关心。但参考性有限：自媒体收入差距极大，也不跟曝光成正比。

我头几年几乎没钱；最高峰年入百万，但那是营收，要扣课程研发和运营成本，且未持续。把 2013—2022 当完整周期，总收入约两百万；2023 之后短期回不到那个数。

绝对值看，接近上班族工资；若去大厂写代码，大概率更高。可我性格不爱管人也不爱被管，做自媒体至少给了这种自由。能否比上班赚多，随缘。

## 四、做对的事

1. 赶上红利：公号、知乎、知识付费几波我都碰上了。运气占大头，但前提是我先伸手试了，否则风从眼前过也抓不住。

2. 没断更：红利也要等几年才起量。期间频率不高，但一直有输出，这是后来接住红利的基础。热门作品是概率游戏，更新越多、基数越大，撞上的机会才多。我的运营不猛，内容也不算稀奇，靠的是写得够久。

3. 起步期借力：很多人死在零粉阶段，发一篇只有个位数阅读，很难熬。早期大 V 推荐、虎扑导流让我跳过这段，几乎从 500 粉开始，创作体验好很多。

4. 站读者视角：公号、视频都是给人看的，不是朋友圈自嗨。我会看不同作品的数据，也做问卷，据此调方向。最后定位在偏入门、短篇幅，要么有趣，要么有用。

5. 专业加热点：现在蹭热点是基本功，早年没多少人懂，我起初也不懂，后来自己摸出门道，做出几篇还行。

6. 变现链路自己控：我会开发，早早就搭教程站，后来加付费课和学员系统。内容里埋钩子，公号文章承接，再到课程服务，全流程自己说了算。大环境差时，也有可靠收入。

## 五、踩坑与错过

1. 内容、流量、服务、变现全想抓：完整闭环是优势，也拖了增长。一个人精力有限，事事自己来，等于拿速度换稳。若把那些时间全砸创作，可能更划算，曝光也许再上一阶。

2. 团队化太早：不是团队不行，是不适合我。和上一条一样，耗了大量精力，结果不达预期。可能缺一个互补搭档。

3. 视频转晚了：我早知道视频会吃图文份额，却没像当年冲公号、知乎那样果断。也得承认，视频门槛更高，习惯写字的人面对镜头需要跨过很大心理关。

## 六、给后来者的实话

[PRE7]

以下围绕这些选择说。

1. 先问为什么做。方向不同，打法不同。自媒体门槛低、上限高，但通往上限的路很挤，且越来越挤。若你因工作不爽想裸辞赚大钱，我劝冷静：好窗口已过，没有突出天赋很难冒头。若当副业试水，我强烈支持。我这两年就间接帮朋友转成了自媒体。但记住：别辞职，别辞职，别辞职。先做，立刻做，今天做。若说上班没时间，辞职后大概率也难稳定更。等能稳定输出，再考虑全职。就算没做成赚钱副业，用自媒体输出专业知识和独家观点，对职业也有帮助，常带来意外机会。另有现成生意的人很适合：用自媒体宣传获客。如今纯做网红大 V 难，但做专业展示渠道有机会，平台流量也在倾斜。比如开饭店，纯靠账号养家不易，认真做美食内容，把店里销量翻倍不难；业务能线上完成，如培训、咨询、保险，效果更好。当然，纯兴趣为爱发电，开心就好。

2. 视频多平台发，但风格有主次。新手优先在 B 站、抖音、小红书里挑最合自己调性的。它们有推荐机制，起步期坚持一段，通常有反馈；也有 IP 效应，做得好会被关注追更，形成正循环。头条重内容轻 IP，适合批量营销号。公号我归为私域，无公共推荐流，现在机制有变，也开始推荐，但图文是过去式，除非文字功底强或实在做不了视频，否则只把公号当最终承接变现的渠道。

3. 内容要跟方向和变现匹配。搞笑短剧受众广、流量大，但多半靠激励或直播带货；专业内容流量小，却精准，客单价能更高。有自己生意的人最轻松，吸引潜在客户即可。若想在抖音卖课，却天天跟风拍段子，爆了也白爆。做垂直的人别羡慕别人十万播放只赚几十块，你的十个播放可能带来一个高价值客户。

4. 从观众需求出发，也别太委屈自己。理想是用户需求、自己擅长、自己不讨厌三者交集；不能全占，就取可接受平衡。

5. 新手心态：先开干，然后坚持、脸皮厚、坚持脸皮厚。不需要万事俱备，今天想做就做；不放心先用小号试，边做边调。若总想“等我怎样再开始”，多半是借口。很多事预想和实际差很远，不动手体会不到。完美主义者别卡住：永远在下一条改进。做好就发，发出去就是胜利。坚持是第一位，量不够，方法论没机会上场；同时别低估坚持难度，初期没反馈最容易断，今天加班、明天聚餐，号就停了。我说“脸皮厚”不是搞低俗，而是正常写文、拍视频也会怕镜头、觉得尴尬，再配上惨淡播放，新手容易崩。这时只能硬着头皮继续更。我们受的教育常让人以为机会只有一次，出错就完蛋；自媒体对新手不是这样，只要不违法违规，尽管试，持续更新，感觉是更出来的，不是想出来的。
