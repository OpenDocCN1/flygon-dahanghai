装 ComfyUI 前，先按硬盘空间挑安装包，能少走很多弯路。

想省事，直接选官方桌面版（105M），模型和第三方节点会自动下载。
硬盘容量很紧张，就用官方纯净版（1.46G），里面不含模型和第三方节点。
硬盘空间一般，可选 Liblib 整合版（2.84G），已整合部分模型和第三方节点。
硬盘空间很充裕，建议上秋叶整合版（3.7G），模型、第三方节点和工作流都整合得比较多。

# 5.2.1 硬件配置建议

系统方面，Windows 10 或 Windows 11 更推荐；MAC 不建议做 ComfyUI 本地安装。
内存最低 6G，8G 或 16G 更稳妥。
显卡要求显存 4G 以上，最低 Nvidia 10 系列独立显卡，30/40 系列 Nvidia 独显更推荐。
显卡品牌效果排序：N 卡（英伟达）最好，A 卡（AMD）其次，I 卡（英特尔）支持较弱。
硬盘至少留 100G，空间越大越从容。
电源大概 400~600 瓦起步。
CPU 和主板没有硬性要求。

# 5.4 Linux 系统本地安装（适合有本地使用需求的 Linux 系统用户）

# 💡

Linux 系统比较适合 AMD GPU、Intel GPU、Mac M1 芯片或 M2 用户。

# 💡

方法链接：https://comfyui-wiki.com/zh-CN/install/install-comfyui/install-comfyui-on-linux

原作者：comfyui-wiki.com

1.

克隆仓库

首先通过 Git 把 ComfyUI 仓库克隆到本地。打开终端并运行：

git clone https://github.com/comfyanonymous/ComfyUI.git

2.

放置模型文件

把 Stable Diffusion 模型（ckpt/safetensors 文件）放进 models/checkpoints 目录。

3.

安装 PyTorch

根据你的 GPU 类型安装 PyTorch。

对于 AMD GPU，可以安装 PyTorch 稳定版或 pytorch nightly：

pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/rocm6.0

pip install --pre torch torchvision torchaudio --index-url https://download.pytorch.org/whl/nightly/rocm6.1

对于 NVIDIA GPU，使用以下命令安装 PyTorch 稳定版或 pytorch nightly：

pip install torch torchvision torchaudio --extra-index-url https://download.pytorch.org/whl/cu121

pip install --pre torch torchvision torchaudio --index-url https://download.pytorch.org/whl/nightly/cu124

4.

安装依赖

在 ComfyUI 目录中打开终端，运行以下命令安装所有必需依赖：

pip install -r requirements.txt

5.

运行 ComfyUI

安装完成后，通过以下 Python 命令启动 ComfyUI：

python main.py

6.

AMD GPU 用户

如果你用的是 AMD GPU，且型号不在 ROCm 官方支持范围内，可能需要设置环境变量覆盖 GPU 版本：

HSA_OVERRIDE_GFX_VERSION=10.3.0 python main.py

对于 RDNA3 架构的卡，如 7600，执行下面命令：

HSA_OVERRIDE_GFX_VERSION=11.0.0 python main.py

7.

Intel GPU 用户

如果你使用的是 Intel GPU，需要根据 Intel 的 Extension for Pytorch（IPEX）安装页面安装相应驱动、Basekit 和 IPEX 包，然后按照 Linux 手动安装说明运行 ComfyUI。

8.

Mac M1 芯片或 M2 用户

如果你使用的是 Apple 的 M1 或 M2 芯片，需要安装最新的 PyTorch nightly 版本，并按照 Linux 手动安装说明操作。

# 6.1 ComfyUI 版本更新

# 📌

安装包分为 4 种，所以更新方式会略有区别。

# 6.1.1 官方桌面版如何更新

自动更新，无需人为干预。如果 ComfyUI 没有自动更新，打开设置，选中左侧 comfyui-desktop，勾选右侧的自动更新即可。

# 6.1.2 官方纯净版如何更新

在“ComfyUI_windows_portable\update”文件夹中找到“update_comfyui”文件。使用“update_comfyui”更新 ComfyUI，等到出现“按任意键继续”，就表示更新成功。

# 📌

好处：简单方便。

缺点：

1》只能升级不能降级，一旦更新后出现兼容性问题，只能重新下载并安装旧版本。

2》无法直观获得本次升级的相关信息。
