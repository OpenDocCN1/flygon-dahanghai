# 3.3.5 亚文化：社群里的共同语言

亚文化往往处在讨论框架的边缘。它究竟是什么，又能带来什么价值？这一节就聊聊这件事。

亚文化这个词不够直观，拿实例看会更清楚。

先看B站。国内弹幕玩法由哔哩哔哩率先带起，后来别的平台也上线弹幕，可弹幕氛围最浓的仍数B站。一个平台独有的互动方式或标志性功能，常常能沉淀成该平台的文化土壤；“空降”“前方高能”这类说法，就是从弹幕场景里长出来的。

表情包同样是鲜活例证。一个“→_→”颜文字，竟能催生“最右”这个段子App；一串“233333”被用来表达爆笑，其源头则在猫扑社区。猫扑回帖时能输入表情编号直接显示表情图片，第233号正是大笑捶地的表情。于是，凡是在其他场合看到这串数字、既好奇又不明所以的人，都会顺着符号的线索被引回猫扑。

B站很懂自己的社区文化。它围绕社区热梗持续制作官方表情包，并持续更新。在我见过的平台中，这样做的仅此一家。

梗也值得单说。好的社群一定会有自己的梗，梗就是社群成员共享的语言，还能让成员在别的场合彼此认出对方。刚才提到的B站，正是把“梗”和“表情包”这两样亚文化利器合在一起用的典型。

一个社群若长出鲜明、与主流文化有差异的亚文化，通常显得生机盎然；亚文化由小到大的过程，也对应着社群共同体由小到大的过程。由此形成的共同话语体系，会自然而然地把人拢在一起，让成员生出亲近感与认同感。

离乡在外，忽然听见熟悉乡音便多出几分信任——有过这种体验的人，一定明白共同话语体系有多大力量。那么，这种力量究竟从哪里生长出来？

图中，亚文化与稳定的活动、舒心的体验并列，原因在于三者彼此伴生。亚文化位于正反馈之上，也说明它同样靠正反馈打底。答案其实不复杂：在稳定的活动与舒心的体验中，人们积累起共有的经历与记忆，随后一点点长出绰号、共识、段子、表情包和梗；这些都是文化符号。

脱口秀演员李诞常说，不主张在《脱口秀大会》里使用内部梗。原因在于，脱口秀演员本身会不可避免地形成一个共同体，共同体内部的梗被高度认可，圈外人却难以理解；内部梗一旦过多，这个共同体想破圈就会变难。看到这里我会心一笑：李诞确实摸透了群体、圈子与话语体系的门道。

最后想强调的结论是：亚文化能反向滋养社群、凝聚共识，但它对社群而言是加分项，不是决定项。
