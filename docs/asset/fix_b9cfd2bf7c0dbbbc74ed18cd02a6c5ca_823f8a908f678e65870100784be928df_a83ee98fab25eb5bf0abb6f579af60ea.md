# 11.5.1 会员模式
办会员后，所有资料都走会员价；跟一份份单买相比，整体更省钱。
# 11.5.2 老带新，滚起来
想让做副业的会员帮你拉人，就把现成话术和朋友圈素材给到她们。每成功带来一位新会员，按实际情况给20%分佣。话术、裂变海报每天备好，会员只管往朋友圈发。
# 11.5.3 开卖前先点火
正式开售前，先做一轮预热，把气氛烘起来，让更多人注意到这场活动。拿小学教师这条线举例：8月10日晚上8点启动宣传倒计时，在朋友圈造势。这段时间从公域大量往私域引，朋友圈按必修课要求发，甚至可以多发。别人点进你朋友圈，划两下就见底，很容易被看成刚入行的新手，信任感一低，会员自然难成交。怎么办？内容少就设三天可见；内容足够多、划好几下都划不完，就设一个月可见。自己的成交图、团队的成交图，都要大量往外发。

# 12.4 场地怎么选
1. 创业，非必要不租办公室
不少热血青年，拿着东拼西凑的几十万资金，事情没做成，钱亏完了，很大一部分就砸在办公室上。
办公室再好看也不是自己的，而且好看和业绩一点关系都没有。
创业初期省钱才是王道，别为了所谓的面子。
把钱花在搞流量上，才是最重要的！
建议：自己家改造、居民楼、商业公寓……先用最低成本运作起来，只要一条网线，咱们就能开干！
2. 业务起来了，需要写字楼
找写字楼，怎么避免踩坑？
1. 办公楼租赁虽然按月计费，但一般至少签1年起步，也不能长签3年以上，通常业主不会同意，或者需要一定幅度递增。办公楼租赁价格很多时候分“包票”与“净到手”。“包票”是租金里已含租赁税发票，“净到手”则不含。（ps：1.起租期多长？2.租金含税吗？3.增长幅度多少？）
2. 办公楼租赁还有一项管理费（物业费，按每平每月）支出，这个要主动问、主动咨询。按行业来说，20元以下的多数没有中央空调，或者中央空调费另计；20元以上的多为中央空调。管理费通常包含公共部分的水电维修保养、清洁卫生等。（ps：1.物业费多少？是否含空调费用？3.电费多少一度？4.网络费多少一个月或一年？一般来说联合办公的租金就包含了物业费、水电费等所有费用。5.还有每个写字楼的中央空调开放时间不一样，很多都有时间限制和月份限制。极少写字楼会24小时供应，大部分只在上班时间供应（多为8:30-18:30），加班需要支付一定的加班空调费。也有少部分可以自己安装独立空调，如需加班或不想使用中央空调，可以问是否可装独立空调。（ps：1.空调时长多少？2.是否可自己调控？3.是否可安装独立空调？）
6. 互联网公司经常通宵，但写字楼内不可以住宿（有商务公寓的除外），更不可以明火煮食，微波炉还是可以用的。不过也有复式写字楼可以居住或者可商住，这些都可以主动问。（ps：是否能住人？）
7. 另外就是停车场怎么收费，一般老板和员工都会办月卡，所以主要了解月卡多少钱一个月就ok。承租面积比较大的客户，有送1-2个免费停车位的，记得争取（个人业主除外）。（ps：①停车费多少一个月或一年？②按年有没有优惠？③临停多少一小时？④日封顶多少1小时）
8. 如果租的是毛坯办公楼，记得跟业主要免租期，1～3个月不等，具体看面积和装修风格需要的时间，这个也可以商议。哪怕是带装修的，也会有1周左右免租期，搬办公室也需要时间，修修补补总要时间吧！（ps：免租期多长？）
9. 租赁期的递增：一般租期超过一年以上的租赁期都会有不同程度递增，一般从第二或第三年开始月租金递增5%-8%，个别大厦连管理费也一起递增。（ps：1.租金涨幅度多少？）
10. 合同签订：以上都了解清楚并谈妥后，预约时间签合同。要弄清楚你是跟业主签还是跟二房东公司签。一般来说大业主和二房东都好说话，很多事情都可以找他们帮忙。（ps：你们是大业主还是二房东还是小业主？）
11. 办公楼租赁还有一个定金交付使用，有很多情况不允许直接签合同，下定金则是最好的折中方法，一般定金下了以后，业主反悔的话需要双倍返还。

# 13.1.2 提示词模板
下面这份提示词在保留原意的基础上做了改写，可以直接复制使用：
#Role:
你是小红书内容老手，专门把对标正文改写成新版本。
##Background:
我在运营小红书，需要对一段正文做洗稿。
##Goals:
1. 按下面这套方法完成改写。
##Definitions:
- 改写方法：
1. 删繁就简：去掉多余词，让句子更短、更直接。
例：原句“我们公司致力于为客户提供高品质的产品与服务。”可改成“我们专注高品质产品与服务，满足客户需求。”
2. 换词：用近义词替换关键词。
例：“这款产品性能非常好。”→“这款产品性能出色。”
3. 加画面感：补上具体形象或感官描写。
例：“这里风景很美。”→“这里山水如画，让人舒服。”
4. 调语序：改变句子结构或顺序。
例：“他认为市场需求会继续增长。”→“市场需求还会继续增长，这是他的判断。”
5. 换更有感染力的说法。
例：“客户对我们的服务很满意。”→“客户对我们的服务赞不绝口。”
6. 增删细节：根据受众调整信息密度。
例：“早餐很重要。”→“一顿搭配合理的早餐，是开启一天活力的关键。”
7. 主动被动互换。
例：“科学家发现了一种新疗法。”→“一种新疗法被科学家发现了。”
8. 加个人感受或引权威观点。
例：“这个设计很现代。”→“在我看来，这个设计把现代审美拿捏得很准。”
- 语气类型：
1. 真实分享：用第一人称讲经历。
例：我用了这款面膜，皮肤状态真的好了不少，你们可以试试。
2. 亲切友好：温暖得像朋友聊天。
例：嗨，今天想跟你们聊聊我最近常去的一家小店，真的很舒服。
3. 专业权威：显得懂行。
例：根据最新研究，这个成分在护肤里很关键，下面我拆开讲。
4. 口语化：像闲聊。
例：你知道吗？我昨天照着网红菜谱做菜，差点把厨房点了，哈哈，做饭真是又刺激又好玩。
- SEO：关键词至少自然出现3次。
- 保留信息：书名号内容、双引号里的例子、人名地名数字年份政策、英文缩写。
- 分隔符排版：小段之间空一行，加一个英文句号“。”作为分隔，最后一段不加。
##Constraints:
1. 不编造事实，保留原意。
2. 做SEO关键词优化，方法见##Definitions。
3. 数字换成1⃣️2⃣️3⃣️等表情数字。
4. 只改写，不加开场白和结束语。
