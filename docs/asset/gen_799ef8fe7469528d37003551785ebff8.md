做竖屏导图，细心和耐心是底色。排版是否清爽、信息归类是否清楚、内容是否准确完整，都靠这两点撑起来；编辑和美化也需要投入时间，成品才会既好看又好读。

### 2.1 挑一款顺手的导图工具

市面上多数思维导图软件都能用来制作竖屏思维导图。目前较主流的选择是 Xmind 和 MindMaster（亿图脑图）。按常见使用场景，以收费最新版本的功能为例，大致对比如下：

- 跨平台支持：Xmind 支持 macOS、Windows、Linux 等操作系统；本地使用，不支持云同步，也不支持多人协作制图。亿图脑图支持全平台（macOS、Windows、Linux、iPadOS、iOS、安卓、网页版）；有云空间，但个人模板和社区导图都需要联网使用。
- 对比表还涉及模板情况、分享功能、收费情况等项目。

结合自己常用的场景，我主要选择 Xmind，原因有六点：

1. 界面简洁美观，操作简单，容易上手。
2. 大多数常用功能免费，做竖屏导图用免费功能基本够用。
3. 有桌面端应用，不联网也能使用。
4. 可跨平台一键分享，方便别人查看。
5. 能导出 PDF 等多种格式，打印方便，清晰度也高。
6. 产品成立时间较久，稳定性更好一些。

本次课程也主要使用 Xmind。
