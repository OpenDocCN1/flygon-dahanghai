# 3.2.1 环境准备

要想让 MCP Server 正常运行，下面几个环境需要提前准备好：

- npx：依赖 Node.js，版本不能低于 18。
- uvx：基于 Python 的快速执行工具，必须手动安装。
- Docker（按需）：容器化平台，用于隔离和运行应用，需根据系统版本选择对应安装包。如果要用 GitHub MCP Server，Docker 是必需的。

## 3.2.1.1 安装 Node.js

先到 Node.js 官网下载 18 或更高版本并安装。装好后在终端里执行下面两条命令确认：

可复制：
```bash
node -v
npx -v
```

能看到类似 `v18.19.0`、`10.2.0` 的版本信息，就说明安装成功。接着重启 Trae IDE，让 Node.js 生效。

Mac 用户可以在终端里先检查 brew 仓库有没有现成的包：

```bash
brew search node
```

返回结果见下。

[PRE2]

有的话直接安装：

```bash
brew install node
```

如果 brew 下载速度太慢，也可以走官网安装：

```bash
curl -o node-installer.pkg https://nodejs.org/dist/v20.14.0/node-v20.14.0.pkg && open node-installer.pkg
```

之后按图形界面提示操作：点“继续”，同意许可协议，点“安装”，需要时输入管理员密码。装完后关闭当前终端并新开一个，让环境变量生效。最后用这条命令整体验证：

```bash
node --version && npm --version && which node && which npm
```

能输出版本号就算成功了。

## 3.2.1.2 安装 uvx（Python 工具）

uvx 是 uv 自带的命令行工具，用来快速运行 Python 脚本。先到 Python 官网下载并安装 Python 3.8 或更高版本，然后在终端里执行：

```bash
python --version
```

能显示版本号即可。

接下来安装 uv（包含 uvx），安装脚本会自动下载并放到系统默认路径。macOS / Linux 执行：

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

也可以用 pip 系工具：

```bash
pipx install uv
# 或
pip install uv
```

Windows 用户在 PowerShell 里执行：

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

最后验证：

```bash
uvx --version
```

输出版本号就说明搞定了。

## 3.2.1.3 （可选）安装 Docker

只有使用 GitHub MCP Server 时才需要 Docker。安装 Docker Desktop 的方式：

- macOS：到 Docker 官网或商店下载对应芯片的 `.dmg` 安装包手动安装；也可以使用 Homebrew Cask，执行 `brew install --cask docker`。
- Windows：去 Docker 官网下载安装程序并运行，按向导操作，注意勾选“Use the WSL 2 based engine”。

验证方法：终端里执行 `docker --version` 能看到版本；执行 `docker info` 能显示详细信息，说明安装并启动成功。
