## 第 3 步：资料别乱囤，整理成能调用的笔记

先给结论：现成文章原样收进库就行，AI 读得懂；真正需要加工的是视频、课程、播客的口语转写稿，得先让 AI 做成精读笔记。

拿 B 站「第一性原理」视频走一遍：

1. 复制视频链接，上传到 Get 笔记。
2. 从 Get 笔记里把视频逐字稿复制出来。[PRE1][PRE2]
3. 粘进 DeepSeek 或 Gemini（更推荐 Gemini），并把 2.3 节的精读笔记提示词一起带上。[PRE3][PRE4]
4. AI 会返回一份有结构的精读笔记，通常包括：核心要点（3～5 条，一句话讲清）、主体内容（按小标题重新分段）、金句（1～3 句）、适用场景。[PRE5]
5. 在文档里手动补上来源（书或视频链接）；整篇归入「思维模型库」，文件名写成：第一性原理｜为什么你越努力，越焦虑。

一份乱糟糟的逐字稿，就这样变成随时能翻用的精读笔记。照这个套路处理 5～10 条素材，思维模型库的基本盘就立住了。[PRE6]

## 第 4 步：让知识库真正被调用

进入飞书「知识问答」，拿你的思维模型库当底稿来提问。[PRE7]

直接问也可以，飞书会检索你全部文档来作答；但资料越乱，答案越不精准。更稳的办法是新建一个专门的知识问答知识库，让 AI 只从指定库里找答案，准确率会高很多。

1. 点「+」新建知识库。[PRE8]
2. 设置权限。想对外出售，就设成付费或兑换码；想自己私用，就改成私密，别人看不到。[PRE9]
3. 添加资料。先点添加资料，再选「迁入已有云文档」，把之前建好的库整体搬进来。[PRE10][PRE11][PRE12]
4. 测试提问。在库里直接发问，AI 会依据库中内容作答。比如：我正纠结要不要📕和👸号一起做，精力却不够，能不能结合知识库帮我判断？[PRE13]

这四步落地后，知识库才算真正运转起来。搭建挺费时间；想先体验调用，可去官网【赚钱问答】——整理好的赚钱知识库：https://scys.com/AI

### 4.1 飞书知识问答：第一次使用先避坑

按顺序操作，第一次可能会碰到下面这种提示。[PRE14]

先别急。个人版飞书刚搭好就直接调用，系统连接 AI 本身要花时间。此时别在原地反复问，先退出飞书，再重新启动。

重启完成后，再次进入「飞书知识问答」，新建对话，点右上角三个点，把企业知识库打开。[PRE15]

随后提一个问题，系统会调用 AI 去对接这个知识库；首次对接比较久，约 30 分钟。[PRE16]

对接完成后，后面的问答就恢复正常，无论用新建库还是新开对话，都能从知识库取答案。个人版每天仅 3 次免费问答，想加次数需升级 AI 会员，约 69/月。[PRE17]

### 4.2 飞书知识库 + codex：把操作交给 AI

飞书 AI 功能没法免费；若你有 codex，可以让 codex 连上飞书，代你操作知识库。这需要飞书官方出的 CLI，教程：https://www.feishu.cn/feishu-cli

配置完成后，codex 可读取你的飞书文档、知识库、表格和日历，也能写入、修改文档。

安装方式：打开 Claude Code 或 codex，输入安装命令。[PRE18]

接下来它会逐步完成安装。结束后确认一下 skill 是否全部到位，偶尔会缺；缺了就让 AI 补齐。

走 codex app 安装的话，先把权限开到【完全访问权限】，这样 AI 才能调用浏览器等能力；权限不足会提示你回终端补装。[PRE19]

装好后需要登录，一般会给出两个链接。第一个是创建应用：点「飞书 CLI 配置授权」，浏览器会跳到飞书开放平台并建应用。首次运行只会出现第一个链接，直接点。[PRE20]

头像随意挑，名字按自己喜好填，然后点创建。[PRE21]

看到创建成功提示后，切回 codex，第二个链接「飞书 CLI 用户登录授权」会出现，点开它。[PRE22]

随后会跳到飞书 CLI 授权页，保持默认权限，直接开通即可。[PRE23]

授权完成会弹出飞书 CLI 的登录信息，确认账号没错，就代表 codex 和飞书已经打通。此时也顺手确认 skill 是否齐全，通常安装过程会一并处理。[PRE24]

安装若卡住，把报错信息或截图发给 AI，让它给出处理办法。安装结束后，直接向 codex 发问即可，它会依据飞书知识库里的内容回应。[PRE25][PRE26]

另外，codex 还能帮你把文章和收集来的资料搬进飞书文档，只要用日常语言告诉它：「帮我把这篇文章上传到飞书文档」；有指定目录，就把具体目录说清楚。

进阶玩法：自动化 agent 更新

前面四步属于基础版，适合入门。若你 AI 基础不错，想更自动，可以研究 Obsidian + Claude Code 方案：

• 生成可直接发布的内容
• 还能让 agent 按周期抓取指定👸号 / YouTube 频道的新内容，自动归档进库

[这套方案有一定工具配置门槛，适合愿意折腾的人。](https://my.feishu.cn/docx/MqiDdFBAEobGfHxOagbcV7bHnjc)拆解链接：Obsidian + Claude Code，它们正在替我赚钱丨我的 AI 知识库拆解

另外，当知识库攒到一定体量，它自己也能成为产品。通过飞书 AI 知识库把内容开放给别人付费使用，就是一种方式。

## 5. 小结与作业

### 5.1 总结

积累能力，本质是把零散信息收成一个能持续调用的系统。

四个关键动作：判断该收什么 → 收进来 → 整理成可用的结构 → 随时调用。

对应三个核心技能和实操步骤：

1. 需求判断：先想清楚知识库给哪个场景用、主题聚焦在哪、边界划到哪里。别一上来就猛存，方向错了，越努力越乱。
2. 信息搜集：让 AI 先给你列搜索关键词，再带着词主动找内容；值不值得留，用三个问题过一遍；留下的统一进飞书知识库。
3. 内容整理：文章原样存；视频、课程先让 AI 做成精读笔记再存；最后用飞书知识问答随时调用。

知识库不可能一天建成。今天先存第一条，哪怕只有 5 条、10 条，也比一直躺在收藏夹里积灰强得多。

学完这一章，到了第三章表达能力、内容生产环节，就能把素材库喂给 AI 当参考，产出质量更稳的文章内容。
