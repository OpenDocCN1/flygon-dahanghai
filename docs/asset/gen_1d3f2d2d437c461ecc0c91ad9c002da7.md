# 写在前面

欢迎来到3月航海 | 闲鱼二手书 | 实战手册。接下来的日子，我们会在这里多次碰面。

动手前，先把几个问题说清楚：

1）闲鱼二手书是什么？现在入场还有没有机会？

国家鼓励资源回收再利用，高校教材采购也逐渐放开，不少大学生会买二手教材；同时消费降级让更多人愿意选择旧书。闲鱼在2022年12月开放了图书类目商家入驻，目前算平台内比较热的小赛道。本次航海重点讲“闲鱼无货源二手书”：去各大图书网站、或对标闲鱼同行挑书，把商品挂到闲鱼，日常运营出单后，再到孔夫子下单，由那边直接发到闲鱼买家手里。相比有货源模式，这种做法门槛更低，也更容易拿到正反馈。

需要重点提醒：做这个项目必须办「出版物许可证」。无证经营很容易违规，甚至被封号。办证通常要1-2周，建议尽早启动，给后续上架经营留足时间。具体流程可看2.1。

2）哪些人适合做闲鱼二手书？

① 想找第一份副业的新手：闲鱼二手书还在红利期，相对容易出结果；

② 想把项目做稳的工作室：出版物许可证形成了一定门槛，预估2-3年内不会过度拥挤。

如果能把运营做细，这个项目可以长期做：不用每天重复选品，人工操作压力可控，不必总担心封号，已上架的链接也能持续使用。

不过红利期不代表没有限制，开始前要明白：

1、天花板比较明显，别指望一夜暴富；

2、客单价不高，上架要手动，整体效率不会特别高；客服也忙，回复用户会占不少时间。

最后，希望大家这次不仅拿到成果，也能认识一群同行伙伴。

### 1.1 先认识闲鱼这个平台

#### 1.1.1 闲鱼市场走势

闲鱼注册用户超过4亿，月活突破1亿，2021年全年交易额达到5000亿。用户年龄非常年轻：90后超过60%，95后超过36%，95后折算超过3300万。这让闲鱼成为年轻用户占比最高的主流APP之一。

现在的闲鱼在扶持职业卖家，既保证货源稳定，也给消费者更多商品选择，推动平台标准化。它从早期单一C2C闲置交易平台，发展为C2B2C全链条模式的闲置经济生态。近两年，平台上的职业卖家持续增长，说明闲鱼需要更多有实力的商户入驻，带动交易和市场。

电商也从城市向农村延伸，普及度高、使用方便、成本更低。闲鱼在电商里成本更低，市场状态有点像早期淘宝。总体有几个优势：

1. 制度相对宽松
2. 可做类目较多
3. 容易上手，完善资料就能操作
4. 不强制交保证金

目前闲鱼推广7天无理由退货和描述不符退货，分别需要500元和200元保证金，但不是强制。如果不需要这两项退货服务，可以不交。上架期间如果闲管家提示“不开通7天无理由，无法上架”，再开通即可。保证金后续关闭服务可提现退回。

5. 闲鱼给各卖家的流量相对稳定

不同账号之间流量差别不大，有时这个号出单多，过一阵另一个号出单多一点，流量分发比较公平。

### 1.2 为什么值得做闲鱼二手书项目 @老瞿 Qu

一方面，闲鱼平台操作门槛低；另一方面，二手书的市场需求也在变大，可以从以下几点感受到：

（1）80%以上高校教材开放

据不完整统计，在国家鼓励资源回收利用的大政策影响下，目前80%以上高校已放开教材预订。也就是说，大学生可以在学校订教材，也可以自己解决，学校不干预。这为大学生购买二手书提供了可能。

（2）大学生对二手书接受度提高

高校学生对二手书的接受度越来越高，且每年递增。主要原因是教材在大学使用率较低，大家越来越接受二手书。同时，国家对盗版打击力度较大，也给二手书带来利好。二手书价格优势明显，通常是标价的1-4折。

（3）大环境下消费降级对二手的利好

近几年经济环境大家都有感受。经营闲鱼二手书店铺时有个明显体会：随着消费降级，越来越多家长开始给孩子买二手字典，二手字典在闲鱼成了小爆款，供不应求。

（4）学校周边二手书店倒闭，电商模式优势突出

学校周边开二手书店的老板通常年纪较大。疫情3年里，绝大多数店倒闭了，因为学生无法出校，哪怕只隔一道校门。同时，经营者年纪偏大，电商运营能力较弱，难以通过电商突破业绩。随着网购普及，学生网购二手书的习惯已经形成。

在二手书的几种玩法里，闲鱼无货源二手书项目是目前最推荐的。闲鱼平台处于红利期；在淘宝、拼多多做二手书相对更难，不建议轻易入场。

如果一个人做，建议用家人身份证一起办2个出版物许可证，开6个账号。管理6个账号基本是一个人的极限，精细化运营下来，预估一年利润能达到20-50万。

比如开学季，单账号每天销售额在1000-2000元，平时在500元左右，利润率在30%-50%。

[PRE10]

闲鱼可发布的商品数量为500本，只适合挑爆款书卖，所以更适合做无货源，避免压货。

另外，官方可能在开学季发布活动，可以关注动态，及时放大。比如之前有过活动：上架满500本书，同时开通7天无理由退货和不符合描述退货，就能获得上架3000本的权限。

闲鱼二手书无货源玩法有5点优势：

（1）目前处于红利期

一般人在闲鱼只能发布5本书。2020年9月之前，网上有一个能突破发布数量的bug，现在已修复。闲鱼官方在2021年邀请200多个商家测试，认证出版物许可证后可以发布3000本书；2022年申请通道一直关闭，直到2022年12月才重新开放测试。目前闲鱼APP已支持申请出版物许可证认证，可以确定这个类目市场可做。变化是：一个号开了鱼小铺，最多发布500本书籍。

（2）书籍一旦上架，无需重复选品

闲鱼最畅销的是大学教材+小说。一般大学教材至少3-5年才换版本，小说使用年限更久。所以商品上架成功后，后续这部分精力可以省掉，不用每天忙着选品。

（3）售后较少

图书商品属性和偏低价格，使售后问题基本低于10%。我们实操下来，基本低于5%的订单会有售后。之前看到圈友在闲鱼卖投影仪，这类商品售后问题会多很多。

（4）成本低

具备无货源的所有优势，不需要垫资，没有资金压力和库存风险。

（5）起号难度低

目前商家数量相对较少，起号比较容易。一个人第一个月做到5K利润，第二个月利润过万，只要执行力在，问题不大（带人实测结果）。

但项目没有十全十美。讲完优势，也说说劣势：

（1）前期上书需要时间积累，要有耐心

这个项目推荐精细化运营。首图用实拍图效果更好，文案每个账号尽量标准化又有差异，每天上架20-30本书。强烈不建议用群控软件，效果较差。所以前期上架书籍有个积累过程。一般上架300-500本书后，账号就能相对稳定出单。

（2）不能躺赢

平均客单价较低，大概20-30元。订单多了以后，需要花不少精力买书、发货，相比短视频带货等项目更琐碎。

（3）不能搬运内容

不能直接搬运别人的账号，被举报后容易封号。

（4）单账号天花板较低

目前跑得最好的账号，旺季利润在1-2万/月；淡季平均每个账号每月利润在5000元左右。跟短视频带货那种爆一条视频赚几十万没法比，赚的是辛苦钱。

### 1.3 单号三种盈利路径@亦萌

闲鱼二手书单号主要有三种盈利模式：

低利润爆单：利润空间不高，但爆单后量大，单品一天能出5-10单。

套装高利润：同类书籍、教材+习题、小说套装、书单等，多品组合，利润更高。

垂类高利润：只做细分高利润赛道，出单量不多，但一本利润能做到30-50。

这三点，做好一项就够吃。如果一项都不占，这次航海就要选一项来优化。如果已经做好一项，后面要考虑的就是如何放大。

### 2.1 先把出版物许可证办下来 @老瞿 Qu @一游

营业执照和出版物许可证，是开通闲鱼图书店铺的必备条件，也可以说是入局该领域的资格证，所以这是个有门槛的领域。凡是有门槛的领域，必然能减少一半或一半以上竞争者。

做这个项目的第一步，就是办理出版物许可证，注册闲鱼账号。一个人可以办理3个支付宝账号，对应3个闲鱼账号；要求出版物许可证、支付宝、闲鱼三者的主体一致。目前在淘宝办证价格大多在1100-5000元不等，也有更贵的，通常含一个个体户+一个出版物许可。

线下办理无疑最靠谱，但线下办理很难。个体户办理较简单，有商业地址即可；但出版物对商铺面积、消防有要求，而且有些大城市已经不再办理，导致线下周期特别长，费用基本大几千，有些地址还需要每年再给几千。所以不太推荐线下办理，很多人试过，最后基本都放弃。

网络办证周期大概2-7天。后期需要营业执照每年年报50元，出版物年检150元；如需注销，费用150元。

注意：要鉴别真假。淘宝有假证，拿到证后去官网验证，或者打电话给工商局验证后再确认收货。不要相信对方发给你的官网。他们的主要套路是建一个网站给你查询，所以要通过百度核实是不是真的政府官网。
