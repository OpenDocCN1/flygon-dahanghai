# 4.1.3 文案放大个人IP

“个人IP”这四个字，每个人心里的定义都不太一样。我的理解很直接：经营个人IP，本质上就是不断把自己的影响力做大，让更多人看见你、记住你、信任你。

我把自己做个人IP的方法，整理成了一套完整闭环：

1. 先把定位想清楚；
2. 明确要服务哪一类人；
3. 提炼个人品牌的内核主张；
4. 搭起一套完整系统，内容、引流、变现三条线都要有；
5. 让公域和私域互相配合、彼此反哺；
6. 形成别人难以替代的差异点；
7. 长期稳定输出，并让IP在迭代中不断升级。

在公域，短视频、直播、文章都可以承载IP；到了私域，朋友圈里最能立住人设的工具，非文案莫属。

我一直坚持写原创，一年下来累计输出超过一百万字。小红书上有不少关注我的人，正是先被我的文字打动。因此，我给自己这套文案取名「心金文案」——既希望写进人心里，也希望能带来吸金效果。巧的是，“心”加“金（今）”合起来就是“念”，正好和我的名字相扣。

那我是怎样借文案提升个人IP的吸引力，并让成交更自动地发生？这正是接下来要展开的内容。
