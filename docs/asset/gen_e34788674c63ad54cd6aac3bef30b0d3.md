# 03\. 不同选手的选品侧重点参考

# 1\. 新手选品：跟最新爆品

新手别上来就只选自己想卖的东西，要追近期热度高的产品，越新爆起来越好。在1.0阶段，一个基础判断方法是：看抖音创意中心爆款榜上的产品（可以复习抖音创意中心选品法）。不用太纠结数据绝对值，比如非要销量多少、点赞多少，能登上这个榜单就已经说明产品表现很不错了。

新手阶段别贪多，别想着一口气掌握很复杂的选品方法。把创意中心选品法用好，就足够跑通正反馈了。跑通之后，再慢慢进阶自己的选品能力，做出差异化。

# 2\. 进阶型选手：同步跟小红书站内爆品

进阶型选手，指的是：素材制作能力强、封面制作能力不错，并且已经跑通正反馈的朋友。

这个阶段，可以同步关注小红书站内爆品（低粉爆款选品）。和1.0阶段的区别在于：如果一个品在小红书站内已经开始爆了，说明这个品不仅在抖音能爆，在小红书也能爆，进一步验证了爆品在小红书的适配性。

但同步的代价是：别人已经爆了，意味着平台内已经有竞争。这时候就要求你跟品速度更快、素材制作能力更过关，才更容易脱颖而出。

# 3\. 更天赋的选手：提前挖掘需求产品/高爆品

能力更强、能预判爆品的人，当然要去挖掘产品。

一方面可以提前布局：比如秋冬天之前，陆续布局季节产品，像手膜、脚膜、暖手袋；节假日之前，布局出行类产品，像化妆收纳包、高铁搭子（毛毯、U型枕之类）；夏天之前，布局拖鞋、减肥运动器材（比如滚腿神器）等。

另一方面可以针对爆品发力：爆过的产品一定还能再爆。如果你的技能更高，可以不依赖别人的爆款素材和封面，而是自己创造爆款封面和素材，那你就成了新手模仿的对象。每一个爆款，都是天赋选手对之前爆款内容进行加工而成的。

2. 拍摄模版规划

找对标模板，主要盯这几类素材：

最火的爆款封面：同行全在发的那类，像服装的上身实拍、水果的精美摆盘、日用百货的使用场景，这种常规爆款直接跟、直接测。

最新的爆款封面：一周内赞数超过20，一个月内超过100赞，越新越优先，模仿拍摄也优先。

跨类目的爆款封面：除了同行，还可以看别的类目。像小红书卖得很好的三角荞麦枕头，参考的就是养生博主、健身博主的爆款内容，比如怎么消除富贵包、怎么养成直角肩。

怎么找这些素材？我一般靠关键词搜，产品词、人群词、场景词、痛点词都试。刷到能对标的封面，顺手存进手机，然后开始规划自己的模板。每个产品最好备齐三类图片素材：

真实场景图：把对标图放旁边，拆解这张图的重点是什么——是角度、构图、场景、灯光，还是脚本动作？爆点在哪？每个SKU准备3-5个不同场景模板，角度、道具、背景都得有变化。用第一视角展现亲手使用感，还是第三视角的偷窥感？用哪个道具把人带进场景？背景放在哪？比如拍小风扇，就要卫生间、厨房、床头这些场景，相关背景和道具一律按对标布置。把产品放进快递箱模拟收快递，让人感觉收到货后超出预期，特别真实。再拍收货发货场景：产品堆一块，拍打包发货，制造一种“很多人买”的氛围。

氛围感摆拍图：图片什么风格？ins风、奶油风还是中古风？直接1:1复刻。搁大托盘里、放篮子里，或者摆床上、沙发上拍合集。

细节图：拍材质、功能、用法、特写，可以学对标笔记的镜头。

3. 确定笔记构成&拍摄数量

每条笔记6张图，通常组合是2张真实场景+2张氛围感摆拍+2张细节图。算总量：每天发20条、每条6张、连发7天，一共840张。再分配：4个场景每个拍210张；20个模板、不同SKU、N个角度和道具互相组合，比如A产品配B角度、C场景、D道具，按这个思路摊到每个素材上。

4. 安排拍摄顺序（逻辑+效率兼顾）

建议顺序：先拍氛围感产品图（最容易），再拍合集和细节，最后拍真实场景、外景（最耗时，还要找地方）。头天晚上把所有器材、背景、产品都检查到位，第二天照着流程走。

# 第二步：拍摄执行

1. 拍摄技巧与流程

桌拍打光时，先把光布好、道具摆好，试拍几张，用手机确认构图、清晰度、滤镜、背景道具和整体氛围，没问题再批量拍。按计划里的流程走。

拍真实场景要提前看天气，准备好所有角度、道具、SKU，规划好路线一口气拍完。后期精细化运营时，把产品融入生活场景，看到合适的马上拍：酒店大堂、优衣库、咖啡馆、图书馆、餐厅、柏油路、树荫、公园都可以。

模仿对标笔记时，把爆款图打开放旁边，1:1复刻，尽量还原构图、色调和道具氛围。

2. 拍摄心态建议

心态上记住：选品比素材重要。测品期只拍到60-70分，为的是更高效测款。测出能稳定出单的90分好品，再制定精细计划，把拍摄质量慢慢抬到80、90分。

另外，测品比选品重要。批量拍的目的就是测品，测多了自然会出现数据好的款。别押注在某一两个品上，要广撒网，行就继续，不行换下一个，别内耗。

1.  小红书 SEO 的规则

# 1\. 小红书 SEO 的底层逻辑

SEO，即Search Engine Optimization，中文叫搜索引擎优化。小红书SEO就是优化笔记里的关键词，让笔记搜索排名更靠前。

小红书现在几乎成了大家眼里的“百度”，七成用户习惯在站内搜索，出门吃喝玩乐前都会先翻翻攻略。比如圣诞节想送朋友礼物，我会去搜“圣诞礼物”，然后挨个点开，特别是前几篇吸引人的。只要内容打动我，就会跟博主买同款，从种草一路走到拔草。

因此从搜索入口进来的人，购买意愿普遍很强。搜索流量，就是超精准流量，也是能“躺着赚”的流量。在某个搜索词下面，你的笔记排名越靠前，产品被看见的概率越大，也就越容易影响用户的购买决定。小红书SEO的底层逻辑，说白了就是这个。

# 2\. 小红书 SEO 流量介绍

搞清楚底层逻辑后，再来看看做小红书SEO能带来什么好处，主要有三点。

1）流量精准，用户转化率高

不管纯博主还是商家号，大家关心的就两件事：流量和变现。流量是变现的前提，所以怎么抓住流量，是每个博主都必须面对的命题。

小红书的流量主要来自三个入口：首页推荐、关注页和搜索页。

[PRE24]

首页推荐是默认打开的，流量最大，竞争也最卷。普通人想上推荐，内容得足够强。关注页呢，大家平时打开频率不高，如果关注的人多，你早就被淹没在信息流里了。搜索页反而是普通人突围的好地方，只要有一篇笔记排到前排，整个账号都能持续拿到流量。

而且前面说了，搜索流量是用户主动来找内容，目的明确，所以更精准，转化也更高。我们不少账号，搜索端带来的粉丝都超过了一半。

[PRE25]

2）免费流量，不拿白不拿

一篇笔记的自然推荐周期一般也就3-7天，哪怕是爆款，热度一过，首页推荐的流量也会慢慢降下来。平台要留住用户，就得不停推新内容。你想继续霸占首页，只能花钱投广告。

但搜索流量不一样，只要关键词铺对了，笔记没违规，它就能一直被用户搜到。两三个月前，甚至一年前的笔记，现在还能给你带来新用户。

[PRE26]

这等于在平台长期放了广告，而且不用花钱，这么香能不拿吗？

3）矩阵运营，占领赛道流量

我老跟学员讲，要做矩阵号，特别是商家博主。

原因有二。一是降低风险。商家博主大多有引流需求，但平台为了生态和利益，不允许导流。有引流需求就免不了“湿鞋”，违规还好，封号才麻烦。如果把所有筹码压在一个号上，风险太大了。

二是多一个号就多一个流量入口，还能满足用户比价的心理。账号铺得多，用户货比三家后发现，转一圈还是回到你的号里。当然前提是关键词铺对，要是用户压根搜不到你的笔记，账号再多也是白搭。

所以说，小红书SEO非常有必要做。

# 3\. 影响 SEO 排名的因素

讲方法论之前，得先知道什么因素影响搜索排名。大方向上主要是两个：账号权重和笔记权重。

很多人不承认有权重，但它是真实存在的。账号的活跃度、原创率、垂直度影响账号权重；笔记的发布时间、点击率、互动率影响笔记权重。权重越高，被搜到的机会越大。而且笔记权重对排名的影响比账号权重更大。

比如新号权重低，但只要关键词铺对、内容能打，第一篇文章就可能爆。而且只要爆了一篇，其他笔记也会跟着被带起来，整个账号权重都会上升。
