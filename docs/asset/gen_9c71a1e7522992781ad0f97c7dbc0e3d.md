# AI绘图：电商只是起点

文：阿袁｜2023年5月16日

用 Stable Diffusion 自行训练 LoRA，光靠一张 3090 显卡把模型跑起来，前后折腾了整整一个半小时。AI 绘画给电商模特行业带来的冲击很直接：想用哪类人物模特都能自行生成，版权风险也绕开了；衣服款式可以按需求切换，成图速度控制在十秒以内。

而它的用武之地远不止电商。从动漫设计到室内设计、网页设计、平面设计、工业设计，这些领域都能训练专属模型，背后的商业价值相当可观。
