# 3.2.1 企业型店铺怎么选

企业身份开店，店铺形态不止一种，常见的有普通企业店、旗舰店、专卖店和集合店四类。

普通企业店的取名方式与个人店相同，依然是“专业号账号名称+的店”。这里有个关键点：企业专业号起名要能和商标对应，否则店铺可能无法开通。

其余三类各有命名规则：旗舰店写成“XXX（品牌名）旗舰店”；专卖店为“XXX专卖店”；集合店则采用“XXX的海外店”的形式。

企业型店铺能经营的类目相当广，保健品、医药等特殊类目也在支持范围内。

佣金规则和个人店一致：成交额1万元以下不收费，超出1万元的部分按5%收取。保证金会随类目变化，金额略有不同，通常境内最低2万元，境外最低3500美金。
