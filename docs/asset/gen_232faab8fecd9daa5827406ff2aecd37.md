# 2.3.2 别让工作吞掉生活：NOW主义时间三分法

很多朋友已经在用经典的四象限法安排日程，也确实尝到了甜头。但也有人在实际操作中犯难——事情轻重缓急老是拿不准，待办清单越拉越长，没完没了。如果你也有这种困扰，不妨试试圈友 @车纯的高效人生 提出的另一套思路：NOW主义时间三分法。

先说四象限法的问题出在哪。它以“事件”为管理单位，用着用着就会发现，四个格子永远塞得进新东西。可事情是无限的，时间却是有限的。一天就24小时，列清单时如果不把这条硬约束考虑进去，很容易写下一堆根本没空去做的事。

再说“重要不紧急”这个分类。读书、运动都归在这里，但“不紧急”三个字给人的暗示就是“今天不做也没关系”。拖着拖着，就变成天天不做，最后彻底不做了——这种经历想必大家都不陌生。

反过来看娱乐和放松，四象限把它们归入“不重要也不紧急”。可这恰恰是人的本能啊。想想看，几乎没人能做到一天不读书，但绝对没人能做到一天不碰手机。

还有“不重要但紧急”的事，四象限建议授权给别人。可不是人人都有这个条件，很多事别人也真替不了你。

下面这张图列出了一个职场人的典型一天。你会发现，真正算得上“重要且紧急”的事，基本都扎堆在上班场景里。久而久之，吃饭给工作让路，娱乐给工作让路，睡觉给工作让路，休息也给工作让路。结果就是工作不断蚕食你的时间，人越来越焦虑，越来越累。

所以说，四象限法本身很棒，但它更适合只用来打理工作相关的事项。如今工作和生活的边界越来越模糊，单靠四象限，很容易把两者摆到对立面，互相抢时间，制造内耗和焦虑。

察觉到这一点后，我换了个角度想问题：与其纠结那些永远做不完的事，不如从有限的时间倒推，认真盘一盘一天的24小时究竟花在了哪里。

不盘不知道，一盘吓一跳。刷牙洗脸、吃饭通勤、上班午休、刷手机，可能还要运动看书、见朋友、陪家人聊天、做点自己喜欢的事。顺着这个思路，一天24小时按用途其实可以分成三类：

第一类：睡觉、吃饭、清洁、休息——这是生存的底座，叫基础时间。

第二类：学习、运动、娱乐、爱好——让身体和精神充电回血，叫蓄能时间。

第三类：主业、副业、公益——本质上都在输出价值，叫创造时间。

人毕竟是社会动物，还有些事需要和别人协作：基础部分对应关爱家庭，蓄能部分对应经营人际关系，创造部分对应与人合作。

我把这套分类命名为NOW主义时间三分法：基础时间是生而为人的必需；蓄能时间是给身心充电；创造时间是产出价值、与社会交换。这样分还有一个好处——帮你更清楚地看到每件事的意义，少一些无谓的精神内耗。

比如休息属于基础时间，它本来就是人的基本需求。不必因为想歇一会儿就焦虑或羞愧，更不该为了别的事拼命挤压休息时间。

家庭是情感的根基。无论谁都需要在家庭上投入时间，这是底层的心理需求，也是幸福的源头，一句“太忙没空”骗不了自己。

娱乐可能是被误解最深的一件事。主动娱乐是健康正向的，也是人非常基本的需求。所以刷短视频不必愧疚——你完全可以主动设定每天刷多久，在那段时间里痛快享受这份快乐。

接下来问题来了：基础、蓄能、创造这三项，从时间管理的角度排重要性，你会怎么排？

[PRE2]

不少圈友可能脱口而出选“创造时间”——毕竟是用来工作赚钱的，赚钱难道不是头等大事？

但仔细想想：要赚钱，先得有一副精力充沛的好身体和健康的心态。所以基础时间里的吃饭、睡觉、清洁和家庭，才是最基本的生存条件，才是真正排第一的。

排第二的其实是蓄能时间。因为到了创造时间，你已经得直接交成果了。没有哪个老板招人是让你来他那儿学习的，他们指望你直接给公司产出价值。可现实中很多人恰恰忽略了专门留时间学习、运动、给自己充电、持续提升专业能力的重要性。

于是我们常看到这样的情形：一个人工作五年后，身体疲惫不堪，知识储备几乎见底，很难支撑下一步的职业发展。根子就在于把这三者的优先级搞反了——从基础到蓄能再到创造，是一个赋能的过程；倒过来，就变成了透支的反馈链。

[PRE3]

一个高效能人士的一天，必然符合这样的次序。但我们往往只看到外部的部分结果，误以为他把全部精力都扑在工作上。

再回头看前面笨笨和大明的例子，答案就很清楚了：笨笨的基础时间太少，撑不住好精力；蓄能时间又非常单一；低效工作和娱乐还占掉了他太多时间。

而大明有充足的基础时间保持精力旺盛，蓄能安排得丰富多样，工作时间牢牢压在8小时以内。相信即便大明偶尔加班，也能很快自我调整，回到自己满意的工作生活平衡状态。

这里也给大家准备了几种不同情况下的时间分配参考。比如同为高效职场人，单身和已婚在基础时间的大部分以及创造时间上差别不大，关键差异在蓄能时间的安排：单身人士会拿更多时间发展社交和爱好，已婚人士则可能把一部分蓄能时间分给家庭。

同样，创业者把创造时间比8小时再多出3小时也很正常。但无论创业多忙，一定要留时间陪家人。缺失亲密关系的人生，赚再多钱也难有真正的幸福。高效的学生通常也比别人花更多时间学习，此外还会安排社交和娱乐等。

[PRE6]

再看全职父母这个群体，他们大部分时间都投在经营家庭上。我特意把基础部分中购物1小时单列出来——这同样是全职父母在家很重要的一项工作。相比之下，做兼职的宝爸宝妈为了挤出足够的工作和学习时间，可能会和家人协调缩短家务时间，也会主动压缩自己的娱乐。

[PRE7]

每一张高效人士时间表的背后，都是一个用心经营自己工作与生活的人。

每个人一天都是24小时。处在人生不同阶段，分配比例有所差异再正常不过，关键在于有觉知地主动安排和协调。
