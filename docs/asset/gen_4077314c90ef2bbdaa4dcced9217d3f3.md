# 3）你手里的资源，就是起点 @子渝

做内容之前，先别急着向外看。你身边已经存在的东西，往往就是可用的资源。它可能是看得见摸得着的物品，也可能是拿货的门路；可能是一手信息与认知差，还可能就是你每天身处的生活环境。

举例来说：
- 家里布置得很有味道，又攒了不少好用物件，这本身就是资源，做家居类博主正好能派上用场。
- 如果你经营踢脚线工厂，能承接家装材料的批发和零售，这就是现成的行业优势。
- 要是你擅长安排学习桌，对各类桌面好物也下过功夫研究，那完全能转型为分享桌面好物的学习型博主。
- 再比如，你掌握了一些同学难以找到的信息渠道、学习资料和靠谱教程，这些同样能成为你的内容资本。
