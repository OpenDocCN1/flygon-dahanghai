在ComfyUI的日常使用中，版本更新是绕不开的话题。有几个要点值得记住：升级过程既直观又方便；不仅支持升级，也能降级——如果更新后遇到兼容性问题，可以迅速切回旧版本；每次升级带来的相关信息，都能直接看到。稳定版是每个大版本中相对稳健的更新，更推荐初学者使用；想体验最新功能，切到开发版就能更新到最新。

# 6.2 ComfyUI模型管理指南

尽管安装包共有4种，但模型该从哪里下载、该放进哪个目录，规则完全统一。

# 6.2.1 模型从哪里下载

# 📌

**1. Civitai**

访问 https://civitai.com/models ，完成注册和登录后，点击右上角那个漏斗状筛选图标，挑好自己需要的那类模型，直接下载就行。

**2. Huggingface**

前往 https://huggingface.co/stabilityai ，里面汇集了多个版本的Stable Diffusion官方模型，是获取官方模型的首选站点。

**3. LIBLIB**

打开 https://www.liblib.art/ 首页，在右侧点击筛选，即可按类型浏览和下载模型。

# 6.2.2 模型安装位置

不同类型的模型，要分别放入ComfyUI对应的目录：

1. 大模型 → `ComfyUI\models\checkpoints`
2. ControlNet模型 → `ComfyUI\models\controlnet`
3. Embedding嵌入模型 → `ComfyUI\models\embeddings`
4. 超网络模型 → `ComfyUI\models\hypernetworks`
5. LoRA模型 → `ComfyUI\models\loras`
6. 视频模型 → `ComfyUI\models\svd`
7. 放大模型 → `ComfyUI\models\upscale_models`
8. VAE模型 → `ComfyUI\models\vae`

# 6.2.3 模型分类与整理

# 💡

模型可以从两个维度归类：按用途，或按版本。

**1. 按用途分类**

以LoRA模型为例，可以在LoRA文件夹下建立多个中文命名的子文件夹，把不同用途的LoRA整理得井井有条；其他模型也沿用同样方式。

[PRE2]

**2. 按版本分类**

也可以根据模型版本或研发公司来区分。因为不同版本的大模型，对辅助模型（LoRA、ControlNet、Embedding等）的版本有严格对应要求，所以特别建议在安装时新建一个文件夹来区分版本，比如下面这样的结构：

📁ComfyUI_windows_portable_nvidia
├── 📁ComfyUI
│   ├──📁 models
│   │   └── 📁 checkpoints
│   │       ├── 📁 SD1.5
│   │       ├── 📁 SD2.0
│   │       ├── 📁 SDXL
│   │       ├── 📁 FLUX
│   │       ├── 📁 可图
│   │       └── 📁 混元

# 6.2.4 与WebUI共用模型

# 📌

如果电脑上已经装过WebUI，模型文件通常放在webui目录下的models文件夹里。把相同模型再复制一份到ComfyUI，会白白浪费大量硬盘空间。为此，ComfyUI作者提供了共用方案，让ComfyUI与WebUI可以共享模型，免去重复拷贝。

具体操作如下（没有装过WebUI可跳过）：

1. 进入ComfyUI目录，找到 `extra_model_paths.yaml.example` 文件，把后缀的 `.example` 去掉。

[PRE3]

2. 用记事本打开 `extra_model_paths.yaml`，将里面的 `base_path` 改成你本机WebUI的路径，例如 `F:/AIGC/TOOL/SD/`。下方还可以把VAE、LoRA、Embedding等模型在WebUI中的路径补上，注意路径要使用 `/` 斜杠。

[PRE4]

3. 重新启动ComfyUI，就能在模型栏里看到本机的模型了。

# 6.3 ComfyUI节点管理攻略

# 📌

因为安装包分为4种，节点安装与更新的方式也会有些不同。

# 6.3.1 安装新节点

# 📌

ComfyUI的节点，类似于WebUI中的插件。每个节点内含多个子节点，用于实现特定功能；所谓工作流，其实就是把若干子节点串联起来。

# 💡

安装ComfyUI节点共有5种途径：官方纯净版、手动安装、ComfyUI管理器（推荐）、秋叶启动器（推荐）、Liblib整合包（推荐）。

# 6.3.1.1 官方纯净版如何安装新节点

# 💡

温馨提醒：官方桌面版、秋叶整合版、LIBLIB整合版都已内置ComfyUI管理器，无需执行本节步骤。官方纯净版只有内置的核心节点，想装第三方节点，第一步得先装好ComfyUI管理器。

1. 打开ComfyUI管理器的GitHub主页：https://github.com/ltdrdata/ComfyUI-Manager ，页面上通常有安装说明，照着操作即可。

2. 下载并安装Git：https://git-scm.com/downloads/win 。安装时只有一个选项需要改动，其他默认即可。

[PRE6]

3. 下载页面下方的批处理文件 `install-manager-for-portable-version.bat`，放到ComfyUI的安装根目录。

[PRE7]

4. 双击这个文件，运行安装。

[PRE8]

5. 待右侧出现 `Manager`，就说明ComfyUI管理器节点已经装好。

# 6.3.1.2 手动安装节点

有些节点太新，ComfyUI管理器尚未收录，没法通过管理器安装；也有一类节点，即便用管理器也装不上，这时可以改用压缩包手动安装。但要记住，手动安装并非对每个节点都百分之百有效。

以常用的ComfyUI汉化节点为例，打开：https://github.com/AIGODLIKE/AIGODLIKE-ComfyUI-Translation

[PRE9]

1. 点击页面上的绿色 `<> Code` 按钮，在弹窗中选择 `Download ZIP`。

2. 下载完成后解压压缩包，将解压出的文件夹复制到 `comfyui/custom_nodes` 插件目录下。

[PRE10]

3. 记得去掉文件夹名的 `-main` 后缀，压缩包也可以一并删除。

4. 重启ComfyUI，如果右侧队列区域出现了中文，说明汉化节点已生效。

# 6.3.1.3 用ComfyUI管理器安装新节点（推荐）

首先，确保已经装好ComfyUI Manager。旧版ComfyUI界面里，点击 `Manager` 就能进入管理器。

[PRE11]

新版ComfyUI界面则点击右上角进入管理器。

[PRE12]

弹出窗口中能看到“节点管理”和“安装缺失节点”两个选项。安装新节点，选第一项即可。

[PRE13]

在搜索框查找或直接浏览列表，找到目标节点后点击 `Install` 即可完成安装。

如果搜不到，还可以通过ComfyUI菜单里的“通过GIT URL安装节点”功能来安装。

[PRE14]

# 6.3.1.4 秋叶启动器装节点（推荐）

# 7.2 智谱：CogVideoX

# 7.2.1 CogVideoX模型介绍

CogVideoX是智谱开放平台最新上线的视频模型，目前支持文生视频、图生视频等多种能力，用户可通过开放平台直接调用。体验中心提供文本生成视频、图片生成视频等生成方式，可应用于广告制作、电影剪辑、短视频创作等领域。

CogVideoX-5B属于质量较高的视频生成模型，在画质与视觉表现上均有提升，适合对生成效果要求更高的用户。相比入门级的CogVideoX-2B，它的规模更大，支持更高精度的推理和优化，既保持高生成质量，又减少了资源消耗。

针对内容连贯性问题，智谱AI研发出高效的三维变分自编码器（3D VAE），可把原始视频数据压缩到原始大小的2%，明显降低视频扩散模型的训练成本与难度。配合3D RoPE位置编码模块，该技术能提升时间维度上的帧间关系捕捉能力，从而建立视频中的长期依赖关系。

在可控性方面，智谱AI打造了端到端的视频理解模型，能为大量视频数据生成精确且内容相关的描述。这一创新让模型更理解文本、更好地遵循指令，确保生成的视频贴近用户需求，还能处理超长且复杂的prompt指令。

模型架构将文本、时间、空间三个维度融合进Transformer，不再使用传统cross attention模块，而是设计了Expert Block来完成文本与视频两种模态的空间对齐，并通过Full Attention机制优化模态间的交互。
