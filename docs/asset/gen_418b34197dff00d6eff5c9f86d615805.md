# 案例十二：用内容农场接住海量关键词 @阿杰

小排老师曾分享过《0 资源，做出 3 个日 UV 过十万、7-8 个日 UV 过万的网站，分享我获得无限网站流量的秘籍》，链接：https://t.zsxq.com/BeiemMB 。文章探讨的是如何创造无限流量。还没看过的圈友，建议找时间读一读，很有启发。

我认为，一个网站的流量上限，本质上取决于它能获取多少关键词，以及这些关键词分别有多少流量。“总流量＝关键字数量×个别关键字潜在流量”。所以，要做无限流量的网站，挑战就在于：能瞄准多少关键词，以及如何产出满足这些关键词需求的内容。

下面介绍两个无限流量型网站。注意：大家可以参考“概念”，不一定非要去爬别人的资料，毕竟你抓取别人内容时，对方很可能不允许。

网站一：kknews，网址 https://kknews.cc/ ，成绩是月流量破千万 PV 的内容农场。

[PRE8]

简单拆一下 kknews 成功的关键：

1、用爬虫抓取🛰️👸号文章。🛰️有防爬机制，所以一般来说搜不到🛰️文章。

2、把文章内容从简体转成繁体再发布。对搜索引擎来说，这就是最原创的内容。

3、文章与文章之间关联做得好，内部链接充分，而且不少文章质量不错，图文丰富。

4、主题覆盖量大，能接住各种关键词。

网站二：批踢踢（PTT）相关网站，网址 https://www.ptt.cc/bbs/index.html ，总系列流量破千万。

PTT 由台湾大学管理，从数十年前发迹，现在依旧是台湾最大的线上论坛之一，类似美国的 Reddit。大量网民在各个分类版块发文，比如篮球、韩综、美妆等，里面汇集了各主题下的各种问答。

而做 SEO 也好，做所有网站也好，本质上大多是为了服务“问答”。所以 PTT 的内容是非常精华的存在。于是就有了这些操作：

1、按分类把 PTT 内容分别爬出来，让内容聚焦在特定主题，对 SEO 有利。

2、爬取文章后，重新优化原先 PTT 的标题、描述等。

3、强化文章之间的关联，做好内部链接。

最后，市面上出现了许多不同 PTT 复制站，由不同人持有，其中不少复制站流量都破了百万 PV。

# 案例十三：多语言工具站，把小工具做成大流量 @阿杰

网站名称：工具邦，网址 https://www.piliapp.com/ ，成绩是月流量破千万 PV 的多语系工具站。

[PRE10]

我个人认为，做工具网站有几个优势：

1、关键词竞争强度比纯文字内容低，因为会写程序又懂 SEO 的人相对少。

2、有机会通过多语系拓展流量，很多工具全世界通用。

3、比较不容易受到 Google zero-click 策略影响。Google 会把搜索答案直接抓出来，导致用户不点进页面。

4、工具网站有机会拿到比内容站更高的广告单价，因为页面有更多点击和操作，广告摆放位置也会产生影响。

说到工具站，我最喜欢的例子就是 piliapp.com（工具邦）。这个网站每月 PV 也是好几千万，而且工具站往往有机会比一般内容站创造更高收入。页面上点击和操作多，用户更有可能点到广告。

虽然工具邦的流量令人羡慕，但最重要的重点是：这样的结果不是一蹴而就的。我其实几年前就开始陆续观察工具邦，那时候它的流量已经非常高了。但最近我发现，它竟然还在持续改版自己的网站，比如外观和架构。

很多工具站做起来后就放着不管了。我猜这个网站的开发者一个月收入绝对破十万美金，因为有不少欧美流量，单价较高。但他还是不停开发，甚至一些比较小、冷僻的字也持续在做，比如台湾捷运工具、数字大小写转换。

# 案例十四：海外促销折扣站的低维护玩法 @比浪 Belone

实际就三个代码网页：首页、产品分类列表页、产品详情页。界面也是简单结合了几个促销网站的设计，比如 slickdeals.net、myvipon.com，没有专门做页面设计。
