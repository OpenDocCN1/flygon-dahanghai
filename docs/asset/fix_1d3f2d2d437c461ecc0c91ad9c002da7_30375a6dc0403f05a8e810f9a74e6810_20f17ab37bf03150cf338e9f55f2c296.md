# 开篇先聊几句

欢迎来到3月航海 | 闲鱼旧书 | 操作手册。接下来这段日子，咱们大概率会在这里反复碰面。

动手之前，先把两个关键问题捋顺：

1）这门旧书生意到底指什么？眼下进场还有没有窗口？

国家一直在鼓励资源回收再利用，高校教材采购也逐步放开，不少学生会选择买旧教材；再加上消费端更看重性价比，愿意接受旧书的人越来越多。闲鱼在2022年12月放开了图书类目商家入驻，如今算是平台里比较热的小方向。这次航海重点讲“无货源旧书玩法”：去各大图书网站挑货，或者对标闲鱼上的同行选品，把书挂到闲鱼；日常运营出单后，再到孔夫子下单，让那边直接寄给闲鱼买家。跟有货源相比，这种打法起步更轻，也更容易较快拿到正反馈。

有一件事必须先说透：做这个类目，出版物许可证是硬门槛。没有证就开卖，违规风险很高，账号也很可能保不住。办证一般要1-2周，建议尽早动手，别等链接都准备好了才卡在资质上。具体流程看2.1。

2）哪些人适合做这门生意？

① 想找第一份副业的新手：闲鱼旧书还在红利窗口，相对容易做出结果；

② 想把生意做稳的工作室：许可证把一部分人挡在门外，预估2-3年内不会过分拥挤。

如果把运营做细，这门生意可以长期做：不必天天重复选品，人工操作压力可控，不用总担心账号被封，已经挂上去的链接也能持续用。

不过红利归红利，限制也要提前看见：

1、天花板比较明显，别幻想一夜暴富；

2、客单价不高，发布商品要手动，整体效率不会特别高；客服也占时间，回复买家会消耗不少精力。

最后，希望大家这趟不仅拿到成果，也能结识一批同路人。

### 1.1 摸清闲鱼这个平台

#### 1.1.1 平台大盘与用户画像

闲鱼的盘子有多大？注册量已经超过四亿，月活迈过一亿，2021年成交规模约五千亿元。用户结构非常年轻：90后占六成以上，95后逾三成六，折算下来95后约三千三百万。这使闲鱼成为年轻用户占比最高的主流APP之一。

现在的闲鱼在扶持有实力的卖家，一边稳住货源，一边给消费者更丰富的选择，也在推动平台走向标准化。它从早期单一的C2C闲置交易场，逐步长成C2B2C全链条的闲置经济生态。近两年职业卖家不断增多，说明平台需要更多有实力的商户进来，把交易和市场一起带起来。

电商也从城市往农村延伸，普及度高、使用方便、成本更低。闲鱼在电商里成本算低的，市场状态有点像早期淘宝。总体看有几个长处：

1. 规则相对宽松
2. 能做的类目比较多
3. 上手快，资料完善后就能操作
4. 保证金不是硬性门槛

目前闲鱼在推7天无理由退货和描述不符退货，分别要500元和200元保证金，但并非强制。你若暂时不提供这两项服务，可以先不缴。上架期间如果闲管家提示“不开通7天无理由，无法上架”，再去开通即可。保证金后续关闭服务可提现退回。

5. 平台给各卖家的流量相对平稳

不同账号之间曝光差距不算夸张，有时这个号出单多，过一阵另一个号起量，整体分发比较均衡。

### 1.2 旧书生意值不值得入场 @老瞿 Qu

一方面，闲鱼操作门槛低；另一方面，旧书的市场需求也在往上走，可以从几个侧面感受到：

（1）八成以上高校教材开放

据不完整统计，在国家鼓励资源回收利用的大政策影响下，目前80%以上高校已经放开教材预订。也就是说，大学生可以在学校订教材，也可以自己想办法解决，学校不干预。这给买旧书留下了空间。

（2）大学生对旧书接受度提高

高校学生对旧书的接受度越来越高，而且每年都在涨。主要原因是教材在大学里的使用率偏低，大家越来越能接受旧书这种形式。同时，国家对盗版打击力度大，也给旧书带来一波利好。旧书价格优势明显，通常是标价的1-4折。

（3）消费降级带来的机会

这几年的经济环境大家都有感受。经营闲鱼旧书店铺时有个明显体会：随着消费降级，越来越多家长开始给孩子买旧字典，旧字典在闲鱼成了小爆款，供不应求。

（4）学校周边旧书店倒闭，电商优势凸显

学校周边开旧书店的老板通常年纪偏大。疫情三年，绝大多数店倒了，因为学生无法出校，哪怕只隔一道校门。同时，经营者年纪偏大，电商运营能力较弱，很难通过线上突破业绩。随着网购普及，学生网购旧书的习惯已经形成。

在旧书的几种玩法里，闲鱼无货源是目前最推荐的方向。闲鱼还在红利期；在淘宝、拼多多做旧书相对更难，不建议轻易入场。

若你单枪匹马做，建议借家人的身份证一起办2个出版物许可证，开6个账号。管6个账号基本是单人极限，精细化运营下来，预估一年利润能达到20-50万。

比如开学季，单账号每天销售额在1000-2000元，平时在500元左右，利润率在30%-50%。

[PRE10]
闲鱼可发布的商品数量为500本，只适合挑爆款书来卖，所以更适合做无货源，避免压货。

另外，官方可能在开学季出活动，可以盯住动态，及时放大。比如之前有过活动：上架满500本书，同时开通7天无理由退货和不符合描述退货，就能拿到上架3000本的权限。

闲鱼旧书无货源玩法有5点优势：

（1）正处在红利期

普通账号在闲鱼只能发5本书。2020年9月之前，网上有个能突破发布数量的bug，现在已经修复。闲鱼官方在2021年邀请200多个商家做测试，认证出版物许可证后可以发布3000本书；2022年申请通道一直关着，直到2022年12月才重新开放测试。目前闲鱼APP已支持申请出版物许可证认证，可以确定这个类目市场能做。变化是：单个账号开通鱼小铺后，最多发布500本书籍。

（2）书一旦挂上去，不用反复选品

闲鱼最畅销的是大学教材加小说。一般大学教材至少3-5年才换版本，小说的使用年限更久。所以商品上架成功后，后续这部分精力就能省下来，不用每天忙着选品。

（3）售后偏少

图书的商品属性加上偏低价格，使售后问题基本低于10%。我们实操下来，低于5%的订单会有售后。之前看到圈友在闲鱼卖投影仪，那类商品售后会多很多。

（4）成本低

无货源的优势它都有，不需要垫资，没有资金压力和库存风险。

（5）起号难度低

目前商家数量相对少，起号比较容易。单人首月做到5K利润，次月利润过万，只要执行力在，问题不大（带人实测结果）。

但生意没有十全十美。讲完长处，也说说短板：

（1）前期铺书需要时间积累，要有耐心

这个方向推荐精细化运营。首图用实拍图效果更好，文案每个账号尽量标准化又有差异，每天上架20-30本书。强烈不建议用群控软件，效果较差。所以前期铺书有个积累过程。一般上架300-500本书后，账号就能相对稳定出单。

（2）不能躺赢

平均客单价较低，大概20-30元。订单多了以后，需要花不少精力买书、发货，相比短视频带货等项目更琐碎。

（3）不能搬运内容

不能直接搬运别人的账号，被举报后容易封号。

（4）单账号天花板较低

目前跑得最好的账号，旺季利润在1-2万/月；淡季平均每个账号每月利润在5000元左右。跟短视频带货那种爆一条视频赚几十万没法比，赚的是辛苦钱。

### 1.3 单号变现的三条路径 @亦萌

闲鱼旧书单号主要有三种赚钱模式：

低利润爆单：利润空间不高，但爆单后量大，单品一天能出5-10单。

套装高利润：同类书籍、教材加习题、小说套装、书单等，多品组合，利润更高。

垂类高利润：只做细分高利润赛道，出单量不多，但一本利润能做到30-50。

这三条路，做好一条就够吃。如果一条都不占，这次航海就要选一条来优化。如果已经做好一条，后面要考虑的就是如何放大。

很多闲鱼玩家都好奇：怎么增加曝光？这里专门说说，闲鱼高排名、高曝光背后的底层逻辑。

### 2.1 许可证先办，别急着上架 @老瞿 Qu @一游

营业执照和出版物许可证，是开通闲鱼图书店铺的必备条件，也可以说是入局这个领域的资格证，所以它是个有门槛的方向。凡是有门槛的方向，必然能挡掉一半甚至更多竞争者。

做这个项目的第一步，就是办理出版物许可证，注册闲鱼账号。一个人可以办理3个支付宝账号，对应3个闲鱼账号；要求出版物许可证、支付宝、闲鱼三者的主体一致。目前在淘宝办证的价格大多在1100-5000元不等，也有更贵的，通常含一个个体户加一个出版物许可。

线下办理无疑最靠谱，但线下办理很难。个体户办理较简单，有商业地址就行。但出版物对商铺面积、消防有要求，而且有些大城市已经不再办理，导致线下周期特别长，费用基本大几千，有些地址还需要每年再给几千。所以不太推荐线下办理，很多人试过，最后基本都放弃了。

网络办证周期大概2-7天。后期需要营业执照每年年报50元，出版物年检150元；如需注销，费用150元。

注意：要鉴别真假。淘宝有假证，拿到证后去官网验证，或者打电话给工商局验证后再确认收货。不要相信对方发给你的官网。他们的主要套路是建一个网站给你查询，所以要通过百度核实是不是真的政府官网。
