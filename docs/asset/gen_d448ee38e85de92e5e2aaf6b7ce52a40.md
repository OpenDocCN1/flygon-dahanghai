## 3.4 为 ChatGPT 提供引导 @森林

前文说过，ChatGPT 回答得好不好，取决于你提问的方式和内容。引导得当，答案会完全不同。同时，ChatGPT 的特性之一是能理解上下文。也就是说，若想得到一个好用的 ChatBot，可以持续“喂数据”，为它建立基础数据库；这样它就能结合你喂入的内容和已有数据库，给出更精准的答案。

比如想要“赛博风”风格，可以先提供“赛博风”的定义，再喂一些“赛博风”案例，持续引导 ChatGPT 学习模仿，最终让它写出无限接近“赛博风”的内容。第七章节会用具体文章创作案例展示这项能力。

# 四、【拓展】ChatGPT 程序端玩法

3 月 1 日，OpenAI 官方宣布正式开放 ChatGPT API。这意味着开发者可以通过 API 把 ChatGPT 和 Whisper 模型集成到自己的应用程序和产品中。换句话说，企业或个人开发者无需自研类 ChatGPT，就能直接使用这类模型做二次应用和开发。

更重要的是，ChatGPT API 的价格远低于现有语言模型——每输出 100 万个单词仅 2.7 美元（约 18 元人民币），相比之前的 GPT-3.5，成本直降 90%。无论对企业还是个人开发者，这都是重大利好；人手一个 ChatGPT 的 AIGC 时代，或许真的要到来了。

## 5.2 通过简单的方向提示引出选题

输入一个简单提示或问题，例如“健康饮食的话题”或“如何提升写作技巧”等，点击生成按钮，ChatGPT 会自动生成一些与提示或问题相关的文章选题。

## 5.4 根据社交媒体、网站上的相关信息挖掘选题

联合网站和社交媒体是获取选题的另一种好方法。这些网站和平台经常汇集大量用户产品的内容和话题，比如在知乎寻找与选题相关的问题和回答，看微博、抖音、Youtube 等国内外不同社交媒体平台的热搜榜，关注和选题方向相关的主题网站、论坛等等。

你可以通过浏览和分析这些内容和话题来获取更多选题。

如果你用的是免费版 ChatGPT，它无法直接联网找到最新信息，因此需要你从网站拿到相关内容给 ChatGPT，以文字形式让它学习，再帮你生成选题。如果你的是 ChatGPT Plus 版，可以使用 ChatGPT 4.0 中的联网插件，让它查找并提炼你想要的信息。

确定选题后，你就可以根据选题完成标题创作；当然，也可以创作完具体内容后再创作标题。每个自媒体平台的风格并不相同，实际应用中需要针对自己要做的平台进行修改调整。

给 ChatGPT 设定一个对应的内容专家身份，让它给出更准确的回答。

如需要起一个小红书笔记的标题，设定身份的提示词如下，同时可以约定后续流程：

下面我需要你扮演一名专业的小红书标题党专家，我会以“请学习”为开头传授你一些给小红书取标题的技巧，如果你学会了，就跟我回复“学会了”。（给予学习的设定）

在我给你传授完技巧后，我会以“请根据以下内容帮我取个标题：”为开头，给你一份我要在小红书上发布的内容，请你根据你学到的知识，帮我取 2-3 个标题。OK 吗？如果 OK，请回复“好的，没问题，我已经准备好学习新知识，并且会在学习后根据你提供的正文内容帮你取标题。”（给予取标题的设定）

## 6.2 第二步：给方法

为了让 ChatGPT 生成更符合要求的标题，最好在让它输出之前，先给它一些起标题乃至爆款标题的方法进行学习。

提示词：

下面我将传授你二极管标题法，请学习：

2、标题公式- 正面刺激：产品或方法+只需 1 秒（短期）+便可开挂（逆天效果）- 负面刺激：你不 XXX+绝对会后悔（天大损失）+（紧迫感）

其实就是利用人们厌恶损失和负面偏误的心理（毕竟在原始社会得到一个机会可能只是多吃几口肉，但是一个失误可能葬身虎口，自然进化让我们在面对负面消息时更加敏感）
