# 投流先算账，放量才有底

投流这件事，最怕一上来就猛花钱。先想清楚：做到什么投产，这个项目才算可行？以某个产品为例，盈亏ROI是1.26，那我希望把投产做到1.5以上；如果有赔付托底，这个结果我能接受。把这些前提定下来，再开投。

投放时建议借助第三方辅助工具，我目前用的是诸葛智投。还要记住：数据量不够时，投产和转化都看不出真实水平；测品阶段要先把视频数据推到一定量级。假设每小时花100元，客单价30元，正常一小时出5单，投产就是1.5；少1单或2单，投产会掉到0.9或1.2。整体转化率被影响太大，投产就不稳，数据准确度也低，参考价值有限。

### 6.2.5.4 流量速度到底意味着什么

做投放的人都知道流速重要，但流速到底有什么用，值得想清楚。

什么是流速？从花钱的素材、视频播放量能大致判断，最直观的还是看花了多少钱。流速代表视频热度；想爆单，素材必须跑出高流速，因为付费买量速度越快，说明视频热度越高，出单也越快。

流速对ROI和订单的影响，类似正态分布。一个产品投放时，流速增加，投产通常逐渐稳定；到达峰值后继续加流速，投产会逐步下降。原因是流速过高，素材的转化能力跟不上更泛的流量增长，投产自然被拉低。

### 6.2.5.5 投放六阶段

投放大致可以分为六个阶段，供参考。赔付难度降低后，中低客单价产品可以在放量阶段就开始用卡赔付计划起量。

1. 测品阶段：通常建3到5条计划测产品ROI；我个人会多拉一些，如果对素材有把握，也愿意多给试错预算。
2. 放量阶段：根据预算来。投产在预期内时，重点看小时级消耗和ROI，可以放开拉计划，暂时不用纠结空耗。
3. 压价阶段：放量阶段如果投产逐渐下滑，可以适当压价，把ROI提上来，但量级还要保住。比如50元一个成交的投产撑不住，就试45元；45元能出数据且投产可接受，就批量复制45元计划，而且要多拉。原因是50元计划退下后，相同计划数下，50元流速通常仍高于45元。
4. 卡赔付阶段：不少产品可以直接用卡赔付计划放量，3单触发赔付。只要流速够、能消耗，就可以全量卡赔付：高投产计划赚钱，低投产计划靠赔付兜底，整体更稳。但出价要能出数据，且赔付ROI要高于盈亏ROI。
5. 定向保投产阶段：投放后期增加一些定向，把ROI往上拉。
6. 异常情况：测品阶段不出数据，可以尝试智能出价、定向人群、定向作者，快速跑出数据。目前测试下来，定向作者加智能出价经常能跑正；如果智能仍不出，可以开双智能（智能出价+智能投放），用来判断账号是否存在问题。

这些操作的前提，是你清楚自己的盈亏ROI，并且用第三方工具盯住小时级ROI和花费来做调整。

内容出自两场分享：《视频号短视频挂车投流常见问题和解决方案》，以及7月11日@Never 主讲的《视频号短视频投放分享》。

**重点：别逐条盯计划，盯每小时综合投产**

投放时通常会拉很多计划，几百条都有可能。一条条看投产不现实，要用第三方工具盯每小时的综合投产。如果每小时综合投产在预期内，放量阶段不必调整单条计划；如果连续几个小时投产和流速都有问题，才需要动手调整。

低投产、只花钱不出单的计划怎么处理？

1. 放量阶段可以先不管。这类计划在帮你拉视频热度；大量关闭会让视频热度下降，放量就失去意义。
2. 卡赔付阶段要重点看它有没有卡赔付希望。能卡到赔付，跑得再差也可以先不处理，只要能消耗就OK。
3. 保投产阶段别放太大量级，可以适当调整、关闭计划，把投产和流速控制在预期范围内。

### 6.2.6 短视频投放避坑要点

#### 6.2.6.1 品和素材怎么选

视频号生意的命门，一是品，二是素材。

二流产品搭一流素材，照样可能爆；一流产品配二流素材，却未必能起。因此素材的权重甚至高于选品。

1）爆款素材的底层逻辑

什么样的素材算一流？我们复盘大量爆款后，内部提出“三级信任”。用户看完视频后下单，最核心的推动力是什么？痛点、产品效果、话术？研究后的结论是信任。

换成亲友推荐，你会不会更容易下单？本质也是信任。视频号用户先信平台，再认可内容。

有些素材一发，评论区就有人说不好用、骗人，问题就在于信任被破坏。信任是地基，地基没了，效果展示再猛也难成交。

一级信任：常规展示产品，讲优点、效果、实用性，大多数素材属于这一类。
二级信任：真人出镜直接上手使用，让用户直观看到效果，比如美妆素材。
三级信任：做人设，用场景、服装、造型和口播塑造身份。例如“我做化妆师十年，发现很多人连口红都涂不对”，或“我们家的草原牛肉千层肉，都是风干晾晒出来的”。这一层能把信任拉满。

好素材先建立放心感，再展示购买理由：前者解释为何选你，后者解释为何现在买。

抓住这个逻辑，挑素材时爆的概率更高，不必只靠运气，这才是关键。

2）什么样的素材适合挂车投流

按爆品素材的共同特征，挂车素材有几个基本要素：

1. 画面清晰、语言流畅。画面不清晰不仅影响转化，甚至影响消耗。
2. 有字幕，字体要大。字体太小，老年人看不清，甚至看着难受。
3. 有讲解，声音有亲和力，语速放慢。有讲解的素材，转化通常比没讲解高很多。
4. 广告属性要明确，别做成泛娱乐内容。泛娱乐更适合自然流，付费流不匹配。
5. 卖点要密集，使用效果展示要明显，甚至适度夸张。最关键的一点最好能打破用户认知，比如“手电筒居然能这么亮”“去油污能夸张到这个程度”。

这些只是基础门槛，想进一步优化，仍要回到前面的信任逻辑。

#### 6.2.6.2 混剪过审别踩雷

视频素材可以原创、混剪或半原创，但审核绕不开。有些视频在助手发布、不加热时能进社区（内容）流量池；一旦加热，就会走商业化流量审核，目前尺度较严。建议注意以下失败原因：

1. 过度营销：逼单话术太多，删掉类似“工厂直销”“今天不买，明天没活动又嫌贵”这类表达。
2. 疗效营销：功效类产品要删减功效承诺，比如“效果明显”“价值很高”“明显看到效果”。
3. 混剪博眼球：镜头里背景、人物频繁切换、换镜头，减少不同背景和人物出现次数。
4. 预计无法覆盖去重问题：做深度去重；这类报错通常不影响账号，而且离过审已经很近。
5. 后端产品和视频产品不相关：找供应链时找不到视频同款，若差距不大，可在视频右下角长期放一张缩小版产品主图。

## 6.3 直播间投流

### 6.3.1 直播投流的核心逻辑

投放的最终目的，是让直播间持续获得稳定、精准的流量，把成交层级推上去，做到更大量级，同时争取更高综合ROI、更好利润。付费投放后，人群更精准，转化更顺，成交更容易提升。

通俗说，投放就是在共享用户池里抢与直播间目标匹配的精准客户。它一边受账号标签权重影响，比如成交GMV、订单量、人群画像、标签和行为；另一边受投放策略、出价、人群设置和直播间人货场影响。比如投互动、出价80，直播间要设计互动动作；投点击、出价40，主播要引导用户点商品。投放比的是出价是否合理、人群标签是否准确、人货场是否更能留人。最后看关键指标，UV价值和GPM越大，越容易拿到平台算法的精准流量，ROI也越好。

这里UV价值=销售额/访客数，即每个访客带来多少销售额；GPM是千次曝光成交金额，越高说明流量越精准。

### 6.3.2 直播投放有哪些类型

视频号分短视频和直播两大块，短视频有MCN机构，直播有服务商体系；直播类型又分为秀场、游戏、带货三种。因此视频号投放分两类：一类是短视频投放，另一类是直播间直投，也叫加热直播间或红点投放，这也是本节重点。

短视频投放可以针对挂商品视频进行，投放后呈现在短视频广场；用户刷短视频时，会看到商品链接入口。

#### 6.3.4.1 投前先做调研

创建计划前，先了解直播账号。可以从几个维度入手。

第一，目标人群画像：性别、年龄、地域、兴趣。获取方式有三种：
1. 看投放账号后台关注粉丝画像，能了解粉丝性别、年龄、地域分布等。
2. 按小店历史订单收货地址，以省市区统计，得出主要目标人群地域。
3. 参考其他平台用户画像，如抖快、猫狗用户画像，再结合视频号主要人群画像做交叉，重合部分作为投放人群画像。

第二，了解直播间客单价和毛利润。这决定地域选择和投放目标出价。高客单只能选一二三线城市；利润率高，出价空间也更大。

第三，明确投放预算。预算决定能建多少条计划，以及采用什么投放策略。

第四，确认账号开播时间和直播时长。这决定投放时长，也决定是叠投还是一次性投。比如直播时段在19:00～24:00，流量竞争激烈，出价要更高，才可能拿到流量。

#### 6.3.4.2 如何排投放计划

前期调研完成后，开始做投放规划。

先定策略：一次性批量建计划，还是按节奏叠投，每隔多久加一轮。
再定目标：以成交为主，还是成交+互动+涨粉+商品点击的组合，各目标占多少。
接着出价：根据品类和客单价定投放目标出价。利润空间决定出价上限，出价过高会压缩利润，所以要结合品类、客单价和利润来定。
然后定时长：根据直播时长和直播间流速来定。计划组里既要有短时长计划，保证开播后持续进流量；也要有长时长计划，保证整场直播都有流量。
最后是用户兴趣画像：按前面收集的信息设置性别、年龄、地域、兴趣，先严后松测投，再根据数据优化。

一条新计划创建好后，如果是在开播前建的，开播后会自动执行。开播后要及时检查每条计划是否正常运行，看有没有失败或不通过的计划。失败通常是因为开播前没把商品加到直播间小黄车，所以直播前要先挂商品再开播。

开播半小时后，再看计划是否正常。开播两小时后，观察计划能不能跑动、是否开始起量。跑不动或消耗很少，属于空跑；消耗很快但场观不涨或ROI很低，属于跑飞或空烧。要及时终止这类计划，重新投放，也可以调整标签、兴趣等条件。

整个投放过程中，要关注每条计划的详细数据，决定终止还是叠加，以此保证较好的ROI。
