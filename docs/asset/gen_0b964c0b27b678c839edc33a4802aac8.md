# 4.3.5 历史爆文：四个模板直接套

写历史类公众号，底层逻辑和头条的微头条、问答、文章没差：先把问题抛出来，再把它讲透。真正拉开差距的地方，往往在标题。头条更看重标题的深度和概括力，读完要让人觉得有启发；公众号则要抓眼球、带点猎奇，用夸张的悬念制造新鲜感，让读者忍不住点进去。

1）从人物结局切入：写遗憾，写反转，写读者想不到的收场。结构上顺着人物的人生线走——出生、青年、中年、晚年与最终结局，每个阶段塞进一两段关键事迹。尤其晚年部分要写得锋利一些，因为这里承担点题任务。

2）从人物性格和事迹切入：走“令人震惊”路线。整体仍是人物生平，但挑一两件事集中放大性格的另一面。比如善良之人的恶行、明君的糊涂操作。主体可以先讲大众熟悉的故事，再拿一小半篇幅揭开此人不为人知的一面。

[PRE3]

3）从事件原委切入：把来龙去脉梳理清楚，让读者生出敬服感。这类写法接近追热点，可以从多个角度拆解清代保密措施。也可以换题：各朝代的传位故事、皇帝没有继承人时怎么办、继承人选长还是选贤、孩子多究竟是福是祸，围绕一个方向把一个问题讲明白。

[PRE4]

4）用盘点方式切入：专门盘点那些打破固有印象的人物。可以盘有功绩的皇帝、战神级武将、过得幸福的女人、命运悲惨的女人等等。盘点类不追求多深的讲义，一个人物配一个小故事，只要言之有理即可。
