# 7.2.2 别急着翻三倍

不少人以为，从拼多多选品后搬到小红书，价格直接乘三也能卖得动。可小红书买家并不好糊弄。我和五十多位女大学生聊过，多数人的下单阵地仍是淘宝、拼多多和得物；如今大学生比价很普遍。

所以定价时，我会先查淘宝、拼多多销量靠前的店铺，把价格放进这两个平台形成的区间里。很多顾客比完价，发现我们比淘宝还略低一点；再加上视频是原创实拍、主打“所见即所得”，她们基本就不会再去别处下单。

举个例子：在拼多多榜单里随手看到一条牛仔裤标价39元，再去淘宝搜同款、按销量排序，月销1000+的款式大多落在70—90元，当然也有四十多的。这时我可能把价格定在59—69元，再结合自己的利润率细算。
