# 2.4.2 电脑端发布：比例时长对了，流量才不白费

先进入编辑页面，重点核对视频的尺寸和长度是否达标：片子长度别超过 60 秒，画幅用 9:16 竖屏，分辨率建议拉到 1080×1920 的高清档。画面要干净清楚，背景音乐别太突兀，开头前 3 秒尤其要抓人——观众留不留，基本就看这一下。

编辑界面里其他几个模块，也顺手优化一下，对播放量有辅助作用：

- **标题**：短、有钩子，最好埋进关键词。比如：10 秒学会超酷舞步！🔥 #Shorts
- **描述**：简单说清视频讲什么，再补上话题、频道链接等信息；适当放几个相关关键词，搜索排名会更好看。
- **标签（Tags）**：加与内容强相关的主题标签，如 #Shorts、#DIY、#Fitness。别为了蹭流量硬塞不相关的词，误导性标签反而坏事。
- **缩略图**：系统自动配的不满意，就自己传一张。清晰、色彩对比明显，从“让人想点”的角度去设计。

[PRE0]

电脑端的发布流程，跟发普通长视频基本一致：

1. 登录 YouTube Studio。
2. 点右上角“创建”，选“上传视频”。
3. 把文件拖进上传框，系统会根据时长和比例自动识别是不是 Shorts。

但有个关键动作别忘：为了让视频确实落进 Shorts 板块，标题栏或说明栏里要带一个“#Shorts”标签，同时长度和尺寸必须符合 Shorts 规范。

另外，发布前后别当“发完就跑”的工具人。像正常用户一样刷一刷 YouTube，让平台觉得你是真实使用者。实测下来，发前发后多刷视频，对账号信任度有帮助，推荐也可能更积极；直接退出的话，平台容易警惕，流量分配更谨慎，0 播的概率也会上去。

# 3.1.1.3 参考头部 YouTube 博主的方法 @浅笑

YouTuber@老高与小茉 的赛道选择方法论，做 Shorts 还是长视频频道都能参考：

1. 做你想做的
选你愿意长期坚持的内容，参考类似频道，学怎么扩展。横向扩展是关联题材，纵向扩展是深挖题材。
2. 做你擅长的
选你比一般人做得好的内容。擅长的事更容易出量，失败概率也小。
3. 做你喜欢看的内容
如果没有想做或擅长的，就选你感兴趣的，模仿你喜欢的内容，也许能发现新兴趣点。
4. 做播放量大的内容
前三个都定不下来，再选播放量大的。但要注意，播放量高不一定适合你。

# 3.1.1.4 根据通用定位方法做调整 @一页书

通用定位方法大致是：

- 采集市场当前和历史数据，做初筛
- 分析数据：这是一群什么用户？数量多大？他们有什么需求或待解决的问题？愿意为解决问题付费吗？付费能力如何？供应者怎么满足需求、解决得怎样？如果我来做，能不能一样好甚至更好？我讨厌做这件事吗？
- 整合、筛选、排序数据，得到几个适合自己的定位

放到 YouTube 平台，要做些调整：

数据采集：生财@钱塘江鲤 擅长 RPA 自动抓取和分析，早期可以直接用他做好的数据（1 万个 YouTube AI Shorts 对标账号），后面再学他的方法自己做。

根据 Shorts 特点调整：

- 早期不用死磕清晰用户画像，把用户和需求并到一起，关注需求是什么（往往是精神/心理层面的），以及为什么某些需求量很大。
- 早期可以忽略用户付费意愿和能力（因为 Shorts 共享广告收益池），专心做爆款内容就行。

总结：根据高手的 Shorts 数据，重点分析几个问题（前三个最重要）：

需求层面：播放量大的，满足了什么需求？有这种需求的用户多吗？
供给层面：玩家多吗？他们怎么满足需求的？还有创新空间吗？
实现层面：需要哪些技能？我能做吗？能做得更好吗？
我讨厌做这个事吗？

最后把数据汇总整理，得出适合自己起步的定位。

那么会出现几种可能：

1. 三个全绿：

2. 货币化开启或关闭但非原创，有广告/无广告：

音乐版权分走了一部分。

第三步：判断收尾。

货币化查完，肯定优先选“三绿”内容的赛道。有了大概判断，再去看它的天花板：爆款内容是否平稳，最热门视频前几排的掉量是不是很快。

Shorts 的特殊性就在于吃爆款。别指望每天靠 1W、2W 播放慢慢养老，后期收益号往往日落西山。所以得知道自己感兴趣赛道的爆款上限。

# 3.1.2.3 不能选择的对标频道

同样是千万播放的频道，最热门排序之间的差距可能很大。这种频道，不管选题、画面还是文案，都不是首选。如果这个赛道只有极个别频道这样，那还可以继续选——只能说这个做得不好，不能说整个赛道不行。

不能选的原因有很多：可能是赛道饱和度太高，YPP 不好过；也可能因为大量侵权素材，被判非原创而过不了。一个账号成功开通 YPP 的周期大概 1—3 个月，好不容易达标却因为某种原因不让过收益，那就真哭了。所以先选好路更重要。
