# 8.1.2 主号@辅助号

1.

用一个辅助号直接发微信号截图。（路径：微信 → 我 → 设置 → 账号与安全 → 进入微信号截图，或者拿另一台手机拍下来）

2.

在主号简介里@辅助号，这样能避开大部分风险；即使辅助号被封，也能马上换号承接。

3.

辅助号的名字最好和主号有联系，比如“xx助手”“xx助理”，用户容易理解记忆，主号在评论区@它也方便。

# 💡

总结：

获客的核心，是在和客户建立连接时，把对方引到我们提前做好的承接内容上。路径无非三种：私聊、群聊，或者客户主动看到引导后来联系你。不要主动提微信，谐音也尽量别用，最好通过作品、图片等方式让对方来加，做到隐晦但看得懂。

其次，承接图片要多准备。辅助号做好的作品可以不换，但如果是图片或表情包，比如“笔尖处找我”这类图，就要多做几张，一直发同一张容易被平台识别。

最后，多种动作要组合使用，别只盯一招。为了让主号运营更久，要主号辅助号配合，以辅助号为主。

另外，群聊里不要来一个客户就发一次图，频率太高账号活不久，偶尔发一次就够了，切记！！！

# 8.2 成交沟通脚本

# 8.2.1 通用沟通五步法

① 好感建立 — 破冰

加到客户后先别急着报价，第一件事是破冰。初次接触，先简单了解一下对方。

参考话术：

您好，我是米杰，日常专注整理各类资料，很高兴和您认识。方便说下您想要哪一类吗？

② 放大需求 — 诊断

了解基础情况后，下一步是挖出对方的需求并放大，推动成交。

参考话术：

您是不是在网上找过，却担心内容不完整、不敢直接买？

您是不是也在别人那里买过，结果资料参差不齐，白白浪费了时间？

③ 成交铺垫 — 方案

了解需求后，接着给解决方案，让客户清楚你能帮他解决什么具体问题。

参考话术：

拼多多上也有盗版资源，但找起来耗时，价格也未必划算，您说是不是？

谢谢您愿意和我聊这么多。如果不帮到您，我都觉得过意不去，必须让您拿到结果。（造梦）

大家时间都宝贵，您肯定也想找齐全、收费合理的课件，对吧？

④ 突破抗拒 — 信任

这一步不能松懈，否则辛苦聊来的客户很容易跑单。

给出方案后，怎么突破对方心里的抗拒？怎么卸下客户的防御？

最好的办法是晒客户付款截图，以及对方的反馈和感谢。（朋友圈布局很关键）

⑤ 引导下单 — 成交

最后一步，客户的问题都解决了，如果她还不付款，可以用下面三种方式推动：

1.

送限时赠品或限时低价

2.

零风险承诺

3.

明确的下单指令

参考话术

方法一：限时赠品/限时低价

1.

对了，我们买课件正好有活动，可以赠送**资料一份，只有5份，下单后我发给您。（限时赠品）

2.

对了，这两天正好在搞活动，限时xxx元，过两天涨价，错过了就得拍大腿啦。（限时低价）

方法二：零风险承诺

您放心下单，资料如果不是您需要的，两天内都可以找我退款，不辜负您的信任～（零风险承诺）

方法三：明确的下单指令

您可以通过链接下单，下单成功后把支付截图发给我哦，我来邀请您进群。（清晰的指令）

话术只是参考，要结合实际情况调整，能成交的话术就是好话术。

销售的几个核心原则：

热情大方，但不是没有原则和底线

利他思维，方便客户而不是只方便自己。

回复客人要及时，否则很容易流失客户。

整个销售过程尽量标准化、流程化，常用话术收藏起来，减少沟通成本。

不要跟客人抬杠。面对难缠的客户、骂我们的客户、要求退款的客户，先挽回：“感谢您对我们提出宝贵的意见，有您的监督，相信我们会做得更好，您先使用一段时间，实在不行再说好吗？”挽回不了的该退款就退款。
