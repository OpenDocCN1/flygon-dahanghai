# 陪伴式社群运营，关键在哪？

精华帖｜112 赞  
作者：敏敏是个小太阳🔆  
日期：2021-07-15

各位圈友，大家好，我是敏敏，97 年生，水瓶座。平时混迹在赚钱 CP 女团，也是赚钱线上志愿者。周末我常泡在活动里，既参加也张罗：自己独立策划过 50 多场青年成长类线下活动，也协助落地过 5 场百人以上的商务活动。目前我担任北辰 YES GO 行动广州校友理事会副会长；此前做过北辰青年 YES GO 行动第九期广州营的运营志愿者、三节课校园合伙人，也是公益职涯项目 Jobinn 的营员。

作为长期关注社群活动的人，今天我想拆解陪伴式成长社群「**YES GO 行动**」的运营方式，也聊聊这套模式能给赚钱带来哪些参考。这篇文章有幸得到 @杨涛、@杨星城、@丽丽曾 的提点，在此感谢。

## 一、YES GO 行动介绍

1. 定位与发展脉络  
2. 创新性  
3. 价值倡导  
L1 打破  
L2 探索  
L3 重建  
4. 内容交付  
5. 运营团队  
6. 用户画像  

这一部分先把 YES GO 行动的基本盘讲清楚：它如何定位、一路怎样成长，创新点在哪里，价值主张又怎样落在“L1 打破、L2 探索、L3 重建”三个层次上；同时交代内容如何交付、运营团队如何构成、主要服务哪类用户。

## 二、YES GO 行动的亮点拆解

1. 终身学校概念  
2. 重品控  
3. 由浅入深建立关系  

在亮点层面，文章提炼了三点：一是“终身学校”的理念；二是对品质控制的高度重视；三是关系不是一上来就求深，而是由浅入深地建立。

## 三、YES GO 行动运营模式对龙哥盟的参考意义

1. 扩大会员基数的手段  
1.1 加强分销物料支持  
1.2 加大对夜话官的培育  
1.3 设计线下宣传物料  
2. 管理用户期待  
3. 打造社群黏性的方法  
4. 增加品牌曝光  
4.1 增加品牌投放  
4.2 设计便于传播的物料  
4.3 邀请龙珠圈友给赚钱打 call  
4.4 增加圈友发朋友圈的动机  
5. 官方与民间有机结合  
6. 官方资源协助项目孵化  
7. 里程碑事件记录  
8. 关于新手村的探索  

落到龙哥盟，文章给出了八个方向的思考：怎样扩大会员规模，具体包括给分销物料更多支持、加大对夜话官的培育、设计线下宣传物料；怎样管理用户预期；怎样提升社群黏性；怎样让品牌获得更多曝光，包括增加品牌投放、设计便于传播的物料、邀请龙珠圈友给赚钱打 call、增加圈友发朋友圈的动机；此外还有官方与民间力量如何协同、官方资源怎样助推项目孵化、里程碑事件如何记录，以及新手村可以怎样探索。
