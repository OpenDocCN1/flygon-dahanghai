# 3.5.6 直接运行 Python

在 Cherry 做数据分析，除了 MCP，还可以用它的 Python 能力。没错，它可以直接执行 Python 代码。

过去，AI 给出代码后，我们还得复制到编辑器里运行；现在在 Cherry 里就能直接跑。操作上，比如先让它“按月统计每个月的订单数量，给我 python 代码即可”。

此时 AI 的回复里还看不到运行 Python 的位置，需要先做配置。

[PRE9]

进入左侧“设置”里的代码块设置，启用“代码执行”以及下方相关功能。这样代码块右边就会出现运行按钮。

需要注意：Python 跑在 Cherry 的沙盒环境里，与本地电脑并不互通。因此，直接让 Python 处理本地文件其实跑不通😓，但运行其他 Python 代码没问题。毕竟这是新功能，想真正实现本地文件交互，还得等 Cherry 后续迭代。

# 3.6.1 过去与现在：订票体验大不同

# 3.7 用 MCP 办一场名人聊天 @成峰

翻旧书时看到《人类简史》里一句话：“农业革命是历史上最大的骗局”。我停下来，脑子里冒出一个念头：如果能有人一起探讨这个观点，比如马斯克、孔子和尼采坐在一起讨论，该多好。

[PRE26]

这个想法很合理。我们读书时，常常被困在作者那套思维里，划了一堆线，结果只是被动接收信息，没有真正的思想碰撞，太单调了。很多时候，最深刻的洞见来自不同视角的碰撞。等等，我好像可以用 AI 实现这个想法。

是的，我要让历史名人一起读我的书。只需要微信读书 MCP 加 Trae 就能实现。想象一下：你在读书、划重点，然后马斯克、孔子、尼采和萨特突然围坐在你身边，对你划的那句话热烈讨论起来，是不是有点小激动？😏

我试着让他们讨论“人类是唯一会相信故事的动物”，结果很精彩：孔子认为此论甚妙，人之所以为人，正在于能以礼乐传承智慧，这是故事的本源；马斯克把故事看作人类第一个虚拟现实，从进化角度看，这是构建火箭和殖民火星的认知基础；尼采说故事即权力，弱者用故事安慰自己，强者用故事塑造世界，这是超人崛起的起点。看完这些观点，我的第一反应是：这比 AI 单纯总结书籍内容高到哪里去了。每个视角都带来全新启发，像真的参加了一场跨时空头脑风暴。

别担心，这个“思想派对”很容易举办。我已经踩过坑，现在教你 0 基础复制操作。三步搞定跨时空读书会：1. 获取微信读书划线；2. 设置名人辩论阵容；3. 享受多维度思想碰撞。读再多的书，不如与思想者一起思考一本书。
