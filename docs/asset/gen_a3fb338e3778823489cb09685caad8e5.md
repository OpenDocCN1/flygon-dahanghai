# 3.2.1.2 本地门店抖音获客指南 @宋威

想把抖音本地生活的线上流量变成到店顾客，第一步不是急着发视频，而是先把门店认领下来。商家要先确认自家门店是否属于平台允许认领的行业，餐饮、住宿、游玩、休闲娱乐等通常在范围内，但最终仍以平台审核结果为准。

第一步，本地经营生活服务的单点实体商家，如果公司或门店主体还没有在抖音企业号开通团购功能，就可以通过抖音来客APP提交入驻申请，并认领门店。

第二步，认领门店。电脑端打开抖音来客官网（life.douyin.com/），手机端下载抖音来客APP。注册登录后，先看清入驻需要准备哪些材料和信息，再点击入驻抖音门店、认领门店，搜索目标门店并核对信息。

[PRE0]

选中门店后，页面会进入资质提交环节，按提示上传资料等待审核即可。通常需要企业法人营业执照、《公共场所卫生许可证》以及法人身份证照片。

第三步，门店认领完成后，把收款账户和抖音号关联好，再创建团购商品。商家在抖音上架团餐链接，逻辑和入驻美团相似：顾客在抖音下单后获得二维码或券码，到店核销用餐。

那顾客怎样才能看到并购买你上架的团餐？目前有四个流量入口：

第一个，短视频作品挂门店POI定位带来的流量。也就是靠抖音内容给门店POI曝光，商家自己发作品或找达人发作品都行；用户被内容种草后点进POI，就能看到团餐并下单消费。这个入口需要商家主动运营，但上手不难，而且本地团购达人数量充足，能承接推广需求。目前它大约占我总GMV的40%，也是约九成商家重点运营的流量来源。

[PRE1]

第二个，商家主页加搜索流量。这部分来自品牌自身声量、粉丝以及线下门店的引导：有人主动在抖音搜品牌号，或被线下门店引导到主页，再购买抖音套餐完成成交。现阶段占比不算大，加上门店引导的量，大约占我总GMV的15%。

[PRE2]

所以，如果你是加盟商或做特许经营，可以拿品牌授权书去认证账号，借官方影响力和搜索流量。举个例子：某品牌在抖音的排名里，一个个体户能做到全国第三。

[PRE3]

第三个，直播时挂本地团购小房子带来的流量（小程序场景里叫小雪花）。它包含品牌自播和达人直播两块，同样需要商家强运营；主播在直播间引导成交，转化率明显高于短视频端。相比短视频，直播门槛更高，对商家能力要求也更高，而且市面上本地直播达人还很少，官方头部达人不到5个，且集中在北京，其他城市才刚起步。不过这个入口潜力很大，目前我的达人直播和品牌自播合计约占总GMV的54%。

[PRE4]

第四个，抖音本地同城页流量。这是平台同城生态自带的入口，页面逻辑类似美团点评：用户想找吃的，会习惯去美团点评逛；如果抖音把同城消费习惯养起来，用户也可能在抖音同城找美食，流量空间不小，毕竟同城页本来就是抖音三大推荐入口之一。只是眼下流量一直不大，同城页下还在内测学习商城等子页面，流量更被分散。简单说，这个入口要等用户习惯养成才有潜力，现阶段几乎可以忽略，占我GMV最多也就1%。
