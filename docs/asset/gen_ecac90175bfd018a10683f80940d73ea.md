# 13条准则，一家咨询公司的经营底线

1月21日到22日，小马宋团队把年会开到了北京古北水镇，主题定为“慢慢变大”。《原则》一直是我很喜欢的书，今年我想给自己和公司各立一套准则，再随着实践不断补充。年会上，我讲了公司已经沉淀的和今年新提出的价值观与准则，今天也一并分享给各位。

**不欺瞒、不伪造、不陪跑比稿、不碰商业贿赂。**
这是做咨询业务起步时就定下的铁律，最早受华杉老师影响。骗人的代价极高，一个谎要靠更多谎去圆。我见过不少公司在阅读量等数据上注水，对行业这种风气很反感，所以我们绝不干。比稿也本末倒置：把最强的人才和团队耗在比稿上，签约后反而用更弱的团队去服务。我们不比稿，把精力和好人才留给已经付费的客户；2020年初全公司只剩一个客户，也拒掉了所有比稿邀请。早期业务少，可以少收些钱，但不接比稿。

**把客户获得的价值放在公司赚钱之前。**
营销说到底，是先给顾客创造价值，再从中获得回报。我们交给客户的价值，就是有效的咨询方案。公司能赚钱，是因为替客户创造了价值；若整天盘算怎样让客户多掏钱，而不是怎样把价值做出来，路就走反了。结果就是客户离开、口碑受损、生意萎缩；越盯着钱，钱越不来。把价值交付好，是我们工作的唯一目标，其他都不该分散注意力。

**敢于承认自己会错。**
没有人完美，谁都会出错，我也一样。若在同事和客户面前不肯认错，人就会一直困在原有的认知与能力边界里。认错很需要勇气，可这种复盘会把员工和公司往前推一大步。公司墙上印着一句话：老板的判断不一定就是好判断。

**别把讨好上司当本事。**
公司评价人，看能力和结果，不看谁更会察言观色。一旦讨好上级成了风气，小马宋这公司就危险了；这样的地方也不值得你耗着。

**工资的源头是客户，不是老板。**
有个道理要一直清楚：大家的收入来自客户。客户丢了、服务做砸了，收入也就断了。讨好老板不解决问题，把价值交给客户才解决问题。

**一天真正高效四小时，已经很好。**
这话听着反直觉，毕竟公司每天也上八小时班。可知识工作和流水线不一样，不能按件算工时。中午吃饭午休两小时，再加上微信、抖音这些分神的东西，一天能真正高效四小时，已经相当不错。

**效率优先于堆加班。**
加班本身我不反对，我反对的是演给别人看的无效加班。上司没走不代表你也不能走；效率够高，就不必耗着。公司有哺乳期妈妈，我们允许她们早来早走。我见过不少国际广告公司和互联网大厂，加班看着猛，效率并不高。熬到半夜十二点，第二天十一点后才到公司，坐下也没状态，晃到午饭，下午两点才开工，晚上继续加班。循环下去，就是起不来、也停不下加班。不少人加班还冲着免费晚饭、补贴和打车报销，顺便做给上司看，久而久之，加班文化就变味了。

**身体和家庭，比加班重要。**
前面讲效率、讲少加班，落脚点都是希望同事身体好、家庭顺。拼命工作，最终还是为了过好生活、家里和睦。身体垮了、家里吵了，加班还有什么意义？轻重得拎清。

**别为多赚钱把员工榨干。**
员工是公司的本钱。别为眼前利益，接一堆根本交不了货的项目。客户确实不少，可服务能力有边界；不能为了多赚点就让同事拼命熬。后果有两个：交付质量下滑，员工身体吃不消。年会主题“慢慢变大”说的就是这个：要有质量地长，不透支未来。

**察觉不对，就早点停手。**
项目里常有这种时刻：主题定了、设计方向也确认了，却突然觉得哪里不对。停不停？不少同事会犹豫，毕竟设计部已经做了很多。这时别犹豫。察觉不对就马上停，找上级或老板一起复盘；真有毛病就立刻返工。总比临近提案才发现全盘错了强。

**同等条件下，先买客户的东西。**
做咨询、做乙方，得有这个自觉。服务客户，就得站在客户那边，把客户利益放前面。条件相当的时候，鼓励同事优先买客户的产品。

**做事敞亮，账目干净。**
这条不展开。

**内部沟通，少绕情商的弯子。**
以前写过《低情商沟通的好处》，这里不多说。

这13条不保证跑得最快，但求走得稳、走得久。
