# 企业做大，买量是必修课

文 / 七对  
2023.7.11

不少创业者判断一个项目能不能长期赚钱，先盯盈利结构，却把“花钱买客户”漏掉了。总想着平台自然流量能省就省，可企业要上规模，投放采买带来的增长更接近完整的商业打法，也能让团队更早握住主动权。

项目想持续盈利，买量和盈利结构不能分开设计。我们公司从产品成交、服务兑现，到口碑和品牌，背后都有投放支撑。2022年疫情冲击业务后，我们对这点的体会更深。下面展开聊聊。

一、我的来路

2003—2009年，我在南京大学读本硕；校招进阿里做产品经理；2015—2018年在原湖畔大学工作。2018年离开阿里，进入在线教育，以负责人身份创业。到今年是第六年，主营公务员考试培训。

我是生财424号，2021年在南京见面会分享过《三年团队从0到160人的总结与反思》。2022年疫情让业务受影响，但公司活了下来，也逼着我们把商业想得更透。先说明：我们流量能力不是顶级，免费付费都不最强，优势在综合，尤其在买量与盈利结构结合上，攒了一些踩坑经验。

二、什么生意模型算成立

我拿六道关检查：替谁解决什么？怎么触达目标客群？来了如何成交？成交后服务能否满意？班子能否承接？能否持续赚钱？六关都过才成立。

（1）用户价值：先定人群和好处

价值不成立，营销再多也没用。没明确需求、给客户的好处不足，很难做。

我们提供线上公务员考试课，以及部分省份地面课。线上目标：时间紧、有预算、自控弱或理解慢的考生。服务包括排学习计划、强督学、微信一对一答疑、抓学习管理保效果。与普通录播网课不同，履约很重，老师和班主任投入大，平台自研。

公考线上很卷，我们定位清楚，定价偏高，口碑不错，命中部分需求。第一步必须界定：为哪类人创造什么不同好处。

（2）客户来源

不地推，只线上。自然流量和付费买量。平台红利期能白拿流量是本事，但不稳定、不确定；付费采买才有稳定预期。

创业初想用刷题工具App切，已有头部，没做成。后来各平台找流量，赶上抖音红利，入局早，用简单素材在抖音小店卖书，峰值一天四千五百套。很快红利消退，同行涌入，内容再细流量也下滑。自然流量让起步快，但波动大。

抖音直播刚兴起我们也做，还被平台内部当案例分享，结果更多人进场，我们又淹没。自然流量获取方式一旦人多就被摊薄，抖音去中心化更明显。

2019起做巨量引擎投放，2020高峰一年广告费超千万。自然流量退潮，付费采买撑住基本盘。20、21年快速发展，团队到159人，学生多，服务靠老师和班主任，履约重。

买量玩家增多，线索价格趋稳并上涨；有进有退，最终成本稳定。付费的好处是确定，成本高低看团队本事。我们坚持自己投，不交给代运营；买客能力是核心竞争力，不能外包，第三方同时服务多家难帮你形成优势。

（3）成交转化

流量来了如何成交绕不开。公务员考试线上转化偏低。低价课直播、短视频可直接卖；高价课难直播卖，多进私域建信任再成交。

影响因素四点：

1. 用户价值匹配。价值认可加支付力。我们强督学、一对一答疑的网课与直播大班定位不同。有人觉得网课应便宜，同价选地面课，这部分成交低；在职忙、自控弱、有支付力的人成交高。精准匹配很关键。

2. 竞争。行业分散、供给多、选择多、线上获客门槛低，竞争加剧成交下滑。刚推出独特性强、选择少，成交高；抖音涌入后，即便差异明确也被价格比较稀释。去中心化加低门槛带来激烈竞争。

3. 口碑。长期发展必须维护学员口碑。线上推广口碑差会砸牌子，线上用户更爱查信息比较。不可能人人满意，但要认真处理反馈，持续改产品服务，这直接影响成交；好口碑很难保持。

4. 私域承接力。要建信任、匹配需求、做规划，还要有业务意识；不同团队承接力差异大。

竞争环境改不了；产品定位品类、口碑积累、团队本事可改，但每个环节都难，行业不同打法不同。

公务员考试每年新增首次考生，品牌粘性弱；教育培训分散，20多年无一家通吃。好处是新玩家有机会，坏处是竞争多、品牌溢价弱、每年要拉新。

2018起我们推强督学、一对一答疑、个性化全程陪伴。当时市面多是大班直播，后来机构跟进，用同名“全程陪伴”，价格更低，也喊一对一督学答疑，但履约质量差很多：有人问一句学没学就算督学；我们看后台学习时长、做题正确率来盯；一对一答疑用专业授课老师，很多机构群答疑或非授课老师答。学员难分辨价值差异，加上价格差，客户流失成交下降。

我们增加产品类型想提转化，做几百到小几千低价课，想用价格参战。结果不理想：供给端产品变多，课程研发、教材印刷、班次都增成本；买客成本没降，低价课反而拉低整体投产比。

总结：低价多元迎合市场，后端成本增加，前端客户数和营收没等比涨。

同时我们做更高价产品，增加一对一诊断、一对一直播、线下集训等价值。这个方向增强竞争力，因为很多机构交付不了，我们老师多优势发挥。学生数未爆发，但满足高品质需求，竞争力更强，靠全职老师班主任和深服务。后端更重，用户价值更明显，硬实力体现。

围绕深度服务，公司产品设计、成交、课程履约、团队都要变，拥抱变化；短板补齐不易。围绕成交我们试了很多，运营和供给都试，最后找到匹配团队能力的方向，能力还动态变化。成交难，真难。

（4）服务兑现

成交客户带着信任，履约关键。价格是锚，高价必须值，必须重服务。

做网课体会深：学生多怎么督学？要不要自研督学系统看进度和正确率？市面软件解决不了。督学还要班主任每天派任务追进度，班主任怎么培养、流程怎么保障？微信一对一答疑是核心竞争力，学生不会怎么办？老师答疑专业度和答疑量怎么保障？

履约重，后端投入大。我们想长期做，服务端不能出问题。承诺做不到，负面口碑增加，生意不可持续。

（5）投产比

线上每个精准流量都有成本。自然流量也有人力成本，只是摊薄便宜；付费买量成本明确。

要算：流量进来，扣成交率和履约成本，企业是否赚钱？行业线上课分低价录播、大班直播和高价小班直播或学习计划强督学一对一答疑。买量贵，低价网课撑不住。

假设一个客户50元，课程卖200元，账算不过来；成交率不高，课程有成本，我们还有系统开发、老师答疑、督学，成本更大。必须看投产比，健康持续，不能靠亏损买量再成交做大，否则总有爆雷。

行业有退费致资金链断裂案例，本质模式有问题，投产比算不过来，变成金融周转游戏。为转化推大量考不过退款甚至学完任务退款，不顾投产比，不出事才怪。

（6）组织力

每块业务靠人落地，对应团队本事。运营、成交、履约老师、技术、班主任都是门槛。有些可借外力，核心竞争力必须自建。

团队能力非一日之功，人越多越要打造支撑业务的组织，持续选人、建体系、优化、培养。

三、为什么必须谈买量

（1）确定

有产品和用户价值后，客户来源关键。抖音微信商业化成熟，对需要流量的项目是好事，花钱至少有确定流量，怎么投控成本另说。

（2）可复制

确定性强，复制性强，跨行业正常。见过电商公司从卖一个品到另一个无关联品，核心是电商运营能力，不断拓行业复制新品类，碰风口起飞，卖打底裤转卖口罩案例。

（3）不靠堆人

素材加投放，人要精不要多，不依赖大量人力。能力够，一人可兼顾多行业。人力是重成本，人一多管理难。

（4）关键

买量应是团队核心能力。买客成本不同团队差异大，我不认可外包。K12投放热时，一家服务商服务同行业多个客户，大家买客成本难形成优势。

四、买量打开哪些可能

买量解决客户来源，是很多项目前提，不用愁客户从哪来。从用户价值、算账、成交、生命周期看，复制新项目快。懂买量玩法，掌握很多项目主动权。

通常三角度论证测试：第一，供应端给客户什么价值；第二，成交，一个客户生命周期贡献多少利润；第三，履约能否支撑、是否可持续。小团队可快速跑最小单元测试。三环节充分论证，成功失败并存，论证好再行动。

案例：22年帮朋友公司试模式，他们用买量拓客户池，跨度到工业品。公司做电子元器件分销，代理施耐德、西门子等标准工业品，客户是工业客户和小批发商。通过买量找到更多客户，专业销售跟进成交。

模型基于原供应链跑通，销售毛利不高但货值不低，客单价几千到几万，单笔毛利不高，企业客户可持续产生毛利，放生命周期看可盈利。前提原体系是基础，线上只是拓宽来源、放大流量端。

核心：

1. 有竞争力供应链是基础，产品全价格优发货快，原业务价值一直在。客户来了，他在乎的点原供应链能否满足，与旧供应商比价格发货服务有无优势。

2. 精准客户和买客成本是线上精准获客能力，企业端尤其难，如何在线上找精准企业客户、成本多少很现实。我的看法：抖音小红书推荐逻辑主导时，线上能找到企业客户。企业客户有固定供应商，但背后是人，也刷短视频，推业务相关信息不排斥，线上能精准找到。

3. 账算清：成交率、生命周期、一年毛利、回本周期。意向客户来了能否持续成交，工业品销售专业性强，企业端与消费者端差异大，销售水平决定模型成败，测试期销售弱容易偏差。成交端决定生死，多因素，但成交跑通模型易跑通。

项目我们是服务方，主要做流量获取，成交和后端供应难介入。现在线上来的客户每月稳定产生毛利，挑战也多：企业端生意客户做久需线下维护、账期等，又回归线下模式。所以原商业模式成立，线上只是放大。

五、未来买量如何赋能商业

买量跟自然流量、个人IP一样只是获客手段，本质是商业。原业务有问题，买量放大后问题加速暴露。

我越来越觉得买量是核心能力，伴随创业可拓展更多业务。所以更关注产品：产品创造足够用户价值，产品立住，买量可放大。产品选择打磨依赖专业行业背景，有竞争力产品有壁垒，选品重要是基础。

听过同程分享，流量加中台能力复制孵化很多项目，成功失败都有；具备类似能力，商业拓展空间更大。

买量找项目结合有简单维度：什么行业容易被线上赋能，上下游分散度重要。线上更适合上下游分散行业，具体看行业判断，成功失败必然。得试，用最小模型验证。我相信一旦一个项目成功，能支撑很久生意。

以上一家之言，期待发掘更多机会，与生财同学一起生财；有优势供应链欢迎讨论。
