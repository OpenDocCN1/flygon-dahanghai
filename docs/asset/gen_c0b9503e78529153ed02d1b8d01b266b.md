# 2.5.2 到账与提现，一次看懂

**直接对接官方**
- 数据按周汇总，通常周二能看到结果，周三或周四完成付款；如遇特殊情形，另行处理。
- 推广平台不受限制，订单一律从抖音钱包提取；单日最多1万元，单月最多15万元。

**通过「乐推联盟」合作**
- 通常周二生成数据，周四安排付款；如遇特殊情况，会另行安排。
- 收款主体可为企业或个人，支持微信、支付宝、银行卡，可提额度就是页面展示的佣金金额。
- 新增收款方式请查看「2.3 平台使用流程」。

**视频有效期与回传规则**
- 一条视频最多参与四轮结算，跨度四周。提交一次回传链接后，系统会在后台持续采集四周内的订单，满四周便不再采集。
- 想让同一关键词继续产生可结算数据，需要围绕该关键词再拍一条新视频并上线，等同于把这本书对应的这个关键词重新推广一遍。
- 回传链接的填写与提交，必须在每周五早上7点前完成。若超时，导致某周汇总时某个关键词被漏掉，下一周不会补录，该关键词漏报那一周的佣金也无法结算。
