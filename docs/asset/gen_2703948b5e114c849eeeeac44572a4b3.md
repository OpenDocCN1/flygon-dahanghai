# 3.4 新闻稿写作实战 @掩体@海盐芝士
新闻稿写作先要弄清三件事：新闻主题、新闻格式（各新闻网站有各自要求）、时效性。可先借助搜索引擎建立基本认识，再比对优秀案例和客户模板，拆出结构。以“年轻人把五星级酒店当食堂”为例：先明确题目与分析方向；再按1500字搭骨架，正文设3个分析维度，每维度约400字，引言约100字，结尾约200字；每个维度可含多个段落或子标题，段落字数控制在250—500字。写作前用秘塔等工具检索主流媒体资料，整理成文档供AI学习，并要求按固定格式提炼“某新闻能得出什么结论”，每条不少于200字。进入执行阶段后，用“角色—任务—模板—素材”式提示词让AI按骨架输出，再人工核验事实与口径。
