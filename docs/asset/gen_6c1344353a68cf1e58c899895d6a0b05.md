# 7.5 DAO 有哪些类型？生态全景速览

从 Web3 兴起到现在，围绕各异的目标，DAO 已经演化出多种形态。

下图对这些类别做了归纳：运营类 DAO、投资类 DAO、社交类 DAO、媒体类 DAO、NFT 收藏类 DAO，以及服务类 DAO。

从理论上说，Web2 中的各类组织，都能借助区块链技术转型为 DAO，也就是去中心化组织。

眼下大多数 DAO，本质上仍是一群人围绕某个具体议题聚集起来。不同之处在于，组织协作的框架交由自动化程序执行，资金也由加密货币来承担。

规则越简约，越便于程序化；规则越繁复，程序化落地时遇到的问题就越多。
