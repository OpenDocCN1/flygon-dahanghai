# 二、朋友圈，要“做”不要“堆”

不少人觉得，发朋友圈不过是随手一点。可真正耐看的内容，往往在按下发送前就已经想清楚了：这条动态给谁看、想传递什么、图片和文字该怎么配合。

先定主题。生活记录、专业分享、态度表达可以轮换着来，但一条动态只讲一件事，别把情绪、广告和日常全塞在一起。图片也别贪多，九宫格不是标配，三张、四张甚至一张，只要主次分明、色调协调，就比杂乱拼图更舒服。文案同样不必写满，留一点空白，反而更容易让人想评论；多写具体细节，少用空泛感叹。

发布节奏也要稳。一天连发多条容易打扰别人，长期不更新又会被慢慢遗忘。保持固定频率，偶尔来点小惊喜，刚刚好。发完之后别急着消失，回一回评论、接一接话题，朋友圈才会从单向展示变成双向交流。

说到底，制作朋友圈，也是在经营别人对你的印象。少一点套路，多一点真实；少一点堆砌，多一点编辑感。这样发出去的内容，才更容易被看见，也更容易被记住。
