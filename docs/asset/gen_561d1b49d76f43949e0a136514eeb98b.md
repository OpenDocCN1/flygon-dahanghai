# 2.2.1 何谓“整体性管理”

所谓资料的整体性管理，本质上就是把“全部”资料都纳入管理范围。那“全部”又是什么意思？简单说，就是你目光所及的一切，统统算在内。

光是在脑子里过一遍这些庞大的数量，就足够让人头疼了，更别说还要把它们打理得有条不紊——这绝对是个不小的挑战。

正因为难度摆在那里，所以在动手管理所有东西之前，我们首先得搞清楚一件事：我们为什么非要去管理它们？最终想达到的效果又是什么？

根据我这些年的实战体会，一个人想要管理所有东西，背后最核心的诉求通常是：让世间万物都能随时为我所用。

说得更直白一些：当你遇到不错的资料、信息、知识，甚至某个人的时候，可以立刻把它们保存下来（没错，人也能“收藏”，只不过收藏的是和TA相关的信息与材料）；而当你对某些事有了自己的理解和经验，同样可以迅速沉淀起来，等将来需要时，随时能快速调出来参考。这样做的最终目的，就是让自己一天比一天更聪明、更有力量。
