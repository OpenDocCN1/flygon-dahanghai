# 四、新手如何选择合适平台@陈bu懂

# 4.1 淘宝平台分析

高盛的报告指出，淘宝天猫的市场份额从2019年的66%一路降到2022年的44%左右，四年间掉了三分之一。2024年淘宝还能保住多少份额，谁也说不准。但这两年，拼多多和抖音的势头越来越猛，视频号、小红书、快手等内容平台也在分食电商这块蛋糕。

传统电商的老板们正把获客渠道往新媒体和自媒体方向搬。短视频和直播电商快速崛起，大批年轻消费者涌向抖音、快手，消费习惯也跟着往自媒体赛道偏移。

淘宝整体流量近年是往下走的，现在想在淘宝店铺拿到结果，得有专业的老牌操盘手靠付费投流来运营。身边做淘宝文案写作店铺几年的朋友，也在抱怨获客成本越来越高、投流越来越难打正。数据打正之后，虽然GMV看着漂亮，但扣掉投流、客服、写手成本，忙活一个月剩下的净利润少得可怜。不少老同行已经退出淘宝，转去闲鱼等平台和其他自媒体渠道。

# 4.2 拼多多平台分析

拼多多相比淘宝竞争压力小一些，肯花钱推广的话流量还不错，但在AI写作变现这个行业里，它并不是首选平台，原因有几个：

1.投入成本高（1000元押金，闭店才能退）

2.需要付费投流推广。推广费花出去，运营得当确实会有客资，但关键在于能不能承接住，这对谈单能力要求很高。拼多多的客户属性决定了客单价偏低，基本在千字10-30元，和闲鱼比投入产出比不划算。

3.客单价低意味着流量、客服、写手只能自己一条龙全包，几乎没法分工分钱合作，得全职投入才玩得转。说到底，还是和闲鱼比投入产出比低。

# 4.3 小红书为主的自媒体平台分析

起号周期比较长。相比电商平台直接发布商品，还多了一层运营内容的操作——要靠干货、留钩子来吸引粉丝转化到私域。经常遇到的情况是，粉丝不是直接来买写作服务，而是来免费领资料白嫖的，相比电商平台不够直接。

付费投流玩法需要资金成本，对小白入局不友好。正反馈速度也比闲鱼慢，素人小白更适合先在闲鱼上以更高概率、更短周期拿到正反馈。

# 4.4 闲鱼平台分析

1.闲鱼简介

闲鱼是阿里巴巴集团旗下的闲置交易APP，既是一个闲置物品交易平台，也是一个基于新生活方式的社区平台。用户可以在这里分享自己的私人时间、技能、兴趣爱好和经验。

平台功能涵盖商品发布与管理、搜索与浏览、交流与协商、支付与物流、社区互动以及安全保障等。用户通过简单操作就能快速发布闲置物品，并用平台内置的私聊功能和买家沟通协商。

2023年11月，闲鱼和1688一起被提升为淘天集团一级业务，两者在淘天电商生态中各占一席。2024年1月4日，闲鱼用户数突破5亿。截至2024年4月，闲鱼月活跃用户达到1.62亿，同比增长19.1%，日均交易额突破10亿；超过1亿人在平台上发布闲置宝贝，人均赚取金额高达2700元。经济下行时期，二手市场的潜力不容小觑。

闲鱼用户以年轻人为主，95后占比超过四成，女性用户居多，二次元爱好者活跃，在年轻群体中很受欢迎。

作为一个二手物品交易平台，闲鱼无需押金和广告费用，规则也相对宽松，对入门小白来说是个很友好的卖货平台。

2.平台抽成

注册闲鱼账号不需要缴纳保证金。2024年9月1日起闲鱼正式实行新规，向全体卖家收取0.6%的基础软件服务费（单笔最多60元），同时对一个月内产生的成交订单收取软件服务费（单笔最多60元）。

另外，仅针对同一自然月内成交订单数大于10件且累计成交金额大于10000元的卖家，超出部分的每一笔订单按实际成交额的1%收取软件服务费。

# 5.2 账号注册

注册闲鱼号至少要准备1张身份证、1个手机、1张手机卡（1个网络）。

1张身份证可以实名3个支付宝，1个实名支付宝可以绑定1个闲鱼账号，所以1张身份证最多能注册3个已实名的闲鱼账号。

每个闲鱼账号要确保1机1卡1号（1个手机、1张手机卡、1个闲鱼账号、1个网络）。

如果某个闲鱼账号因违规被封，后续用这张手机卡注册的新号会被限流，那就只能换一张手机卡重新注册了。

如果有3台手机，全部操作完，最后就有3个闲鱼店铺啦~

# 5.3 闲鱼养号

闲鱼养号是发布商品之前的必做动作。一上来不养号就直接发商品，容易被平台判定为机器人，不给推流。

所以，新注册的闲鱼账号别急着装修店铺、设置个人简介，先老老实实养号。

# 💡

养号不到位可能带来的问题：

1.

影响商品曝光。账号权重不足会直接导致商品曝光量减少，平台可能不会优先推荐你的商品。

2.

上架商品受严格监管。账号没养充分，上架的商品会受到平台更严格的监控，审核通过难度加大。

3.

账号权重低，商品容易被下架。权重低的账号发布的商品更容易被平台下架，尤其被同行举报时，违规风险更高。

闲鱼新号可以多时间段、多频率地模拟真人动作。具体来说，推荐每天上午8点到晚上9点之间养号，每次10-30分钟，养号周期3天左右就够了。

# 5.4.3 个人简介

尽量跟专业写作相关，体现账号的专业性。

简介里注意不要留任何联系方式，同时避开平台规定的违规词。

权威背书：可以通过巧妙的描述突出专业背景和经验。比如：

研究生在读、博士在读
