# 3.1.2 案例一：用逻辑线写用户反馈，更抓人

[PRE0]

这次先聊一个由用户反馈引发的事件型案例。

事情的起点，是一位学员完成了续费。她跟着我学习了整整一年，我几乎一路见证并陪着她成长，因此朋友圈里可呈现的内容比较充足。

那这条内容该怎么按逻辑推进呢？

可以先梳理她的成长轨迹，把这部分做成成果呈现：她每天都很投入地做流量，而且状态轻松愉快，还运营起了自己的流量工作室。

当然，她并非只学引流，文案能力同样提升明显，落笔很有力量。于是我把她的这些变化当成朋友圈素材，从多个角度完整呈现学员的成长。

这条发出去后，我原本并没有计划继续跟进。不过，这类有逻辑线的内容有一个明显优势：很能抓住注意力。没想到刚发布不久，一位新学员就来告诉我，自己看到前辈学员的成果很受鼓舞，也要加把劲，希望有一天也能被我晒出来。于是我又补发了最后一条。

这样一来，当天朋友圈的内容链条就很完整：既展示了我这边能带学员做出的成果，也让大家看到学员们整体积极的状态，容易被这种向上的氛围带动。

这也是我晒反馈时常用的一招：我不会只孤零零发一条反馈，而是把它组织成一个完整事件来呈现，前因、过程、结果、后续都尽量齐全。

中间环节不必太死板，要结合实际情况灵活处理。若当天碰巧出现一个能和主线衔接的临时事件，不妨把它并入同一条内容一起发。
