# 8.1 先懂插画，再用 AI

想用 AI 做插画，先别急着输入提示词。把插画的概念、类别和风格脉络理清，后面的选择会清晰很多。

插画设计，说白了就是借助手工绘制或电脑绘图产出的视觉作品，出版物、宣传广告、漫画、游戏、动画等场景里都能见到它。按制作手段和用途来分，常见有六类：

1. 手绘插画：以铅笔、彩铅、水彩、油画等传统材料创作，往下还能分为油画插画、水彩插画、铅笔插画和彩铅插画。

2. 数字插画：精准度高、便于编辑修改，常见形态包括平面数字插画、2D 动画数字插画，以及主要用于电影特效、游戏制作的 3D 数字插画，能做出接近真实的立体感。

3. 平面插画：服务印刷物料和线上平面广告等场景，覆盖平面设计、网络平面广告、商业插画、图标设计等方向。

4. 三维插画：强调立体呈现，常见于游戏和动画领域，涉及三维建模、三维渲染、三维动画。

5. 角色插画：聚焦人物形象塑造，可按写实、卡通、漫画等风格来设计，细分包括写实风格角色插画、卡通风格角色插画、漫画风格角色插画。

6. 商业插画：面向广告宣传等商业用途，通常按客户需求定制，常见有广告插画、包装插画、儿童插画、漫画插画、科技插画。

放到插画场景里，AI 绘画的长处和包装领域大体相通：

- 批量出图快：短时间内能产出大量插画方案，人工绘制的时间和成本随之下降。
- 提效并压低试错：围绕需求迅速给出设计方向，缩短周期，也减少人工失误和重复劳动。
- 风格选择多：在风格、色彩、线条等维度能生成不同变化。
- 可定制：能依据客户需求调整，产出更贴合要求的插画。
- 打开创意面：提供多种设计风格，给设计师补充灵感。
- 内容选择丰富：按需求生成大量设计内容，让客户有更多备选。

短板也比较集中，和包装领域的局限大体接近：复杂画面不容易应对，生成效果受训练数据牵制，创意和个人特色偏弱；其中最需要警惕的是版权问题。

接商业项目时，若把知名艺术家的名字写进生成条件，务必先厘清版权，防止侵权与纠纷；更稳妥的做法，是尽量不要触碰版权风险。
