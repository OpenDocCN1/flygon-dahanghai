# 一年铺出180个洗护网点，净赚200万：我的完整复盘

先自我介绍一下：老钱，94年生，女性，南方小城普通家庭出身；北漂期间在互联网公司做过产品。我的原则是轻投入、快验证。过去12个月，我把线上洗护铺到美团、点评、口碑等渠道，合计180多个网点，月流水四十余万元，利润率六成以上，累计到手200万元。今天把过程完整拆一遍。

先说明业务边界。它不是临街社区干洗铺。流程是：客户在平台下单，顺丰或京东按预约上门揽件，送至浙江集中洗护基地，清洗护理熨烫后由物流送回。客户全程不出门，接近点外卖。定价还故意低于线下门店均价，以形成优势。

这套形态脱胎于早年的前店后厂。过去门店后面就是洗涤间；租金、人工不断上涨，疫情又推了一把，连锁品牌把清洗环节集中到自建基地，门店只留收件功能。近两年，懂线上玩法的一批年轻人把获客搬到电商平台，用物流收送完成闭环，于是形成现在这套形态。

如今在一线、新一线城市打开美团或大众点评搜洗护服务，约半数商家采用这种揽收加集中清洗方式。平台多年教育后，消费者接受度上来了。对有干洗习惯的人，这是高频刚需；供给端仍在增长，远未饱和。传统门店线上运营弱、接单容量有限，转型困难，所以平台端仍有大量订单空间。京东本年也推出自营洗护，说明方向被验证。下面拆流程。同行可能不爱听，但能推动行业升级，我觉得值得。

## 一、从平台代运营到找到方向

我早年在北京大厂做产品，2018年与朋友在天津投了两家私人影院。靠线上运营，影院长期占据点评热门榜第一；我也摸索出平台获客方法，陆续帮商家朋友做美团、点评代运营，收入超过影院和工资。2019年我辞职，专职做代运营。

但我真正想做的，是能长期稳定面向消费者的买卖，把增长经验用足。代运营让我接触大量实体项目，于是一直在找标的。

[PRE3]

美业、盲人按摩、展览等一路看，也测过几个小项目，总觉得不够合适。转机在2020年一场暴雨。

我新买的一双价格不低的鞋被雨淋透，自己不想动手，又怕护理不当洗坏。我在美团挑了家洗衣商家，买完团购致电问地址，对方说无需到店，顺丰上门揽收，且包邮。不到六十分钟，揽件员把鞋取走。之后能在👸号看清洗与物流进度，比传统店排队、催老板舒服。五天后寄回，洁净度和门店洗护没差别。

那次之后，我把全国同类品牌几乎摸遍。判断很直接：清洗交付只要找到可靠基地，剩下就是铺渠道、抢线上流量。最早一批玩家已跑三年多，一线、新一线仍有人进场，盈利性不用多说。

更巧的是，几天后苏州一位连锁洗衣老板找我做代运营。我把他平台端订单从两天一单拉到日均九单。聊深后确认：这行毛利高、复购强。重度客户单月洗五六次，连内衣袜子都不愿手洗；轻度客户换季也会送三四次；家庭主妇常把全家衣物攒一批洗。维护熟客的成本远低于拉新，这行尤其明显。

后台数据还显示，各电商平台竞争不算激烈。很多同行连美团都没运营明白，但凭低价和包邮，已在线上压过传统门店。传统店靠附近人流，夫妻店居多，线上能力弱，正好留下空白。没有铺面租金压力，还能把店挂到核心商圈抢流量，这生意值得做。

我的判断分三层。

第一，需求。对已有洗衣消费认知的人群，这是硬需求。秋冬旺季，只要口碑不崩，订单就会涌来。普通衣物洗护效果差异不大，客户容易形成黏性。我有个朋友在上海普陀较偏的位置开干洗店，一位高价值熟客一年贡献两万多元营业额；懒人秋冬单月到店五六回很常见。

第二，账本。单件收费从几十到几百元；最常洗的羽绒服平均四十元上下，而水电、洗涤剂、包装、人工合计单件一两元，毛利空间很大。平台年开户费1080至3080元，新一线城市约2080元。线上单通常包含多件，客单价100至130元，比线下单笔高。按我的数据经验，自然流量即可回本。物流成本占每单销售额两到三成，量越大越便宜。整体毛利超过六成——做过生意的人明白，三成毛利已算不错。

第三，竞争。美团业务员透露，生意较好的同行普遍依赖推广通买流量，每月数万元，一停广告订单就掉。我多年练的恰是不烧推广也能把曝光和权重做起来。给苏州客户操盘时，我没开推广通。把这项能力用在自己的项目上，利润空间会明显优于竞品。

行业摸清后，开始执行。

## 二、外包试跑，先把流程跑通

自建洗护基地属于重投入，所以我先找现成洗衣店合作，把清洗外包，花30天验证数据、跑通链路。

平台端先开美团/点评店，南京开户费2080元/年。后来链路跑通，我搭起多平台电商矩阵，平台端不再是唯一重心，这里不展开。

我和团队向合作店老板补行业课：面料识别、洗涤原理、常见洗护事故处理。老板和客服都得学。很多利润来自售前沟通：客户要洗运动鞋，我们看出鞋面掉色、磨痕重，可以建议加价补色，这需要专业储备和话术。线上沟通还有个特点：隔着屏幕，客户比面对面更直接、更挑剔。售后纠纷难免，处理原则是稳住情绪、顺着客户。老板和客服都要好脾气。实体店更甚，小区里名声坏了，生意就难做。

系统方面，我请以前的同事花5000元做了下单系统，打通京东、顺丰接口，订单生成后自动向物流派单。硬件买了两台行业打印机4000元，清洗端配二手收银一体机800元。营业执照我原本就有；没有的话，代账公司每年一两千元，注册地址可用民宅，但要先查所在区政策，不行就借朋友地址。

包材先控成本，不买贵纸盒，花600元进防尘袋，先跑通。

线上转化很吃图片卖点、详情页和视觉质感。我找设计师朋友花300元做了几张图，简单素材用创客贴自己补。淘宝找设计师别贪便宜，800至1000元档位更靠谱，营销预算不能省。卖点要做出差异，让客户一眼看懂你和别家的不同。

平台流量与选址强相关。首店我放在南京新街口，效果不错。多开几家后才明白，不能只盯大商圈，还要结合周边小区密度和客群结构找平衡。后来我沉淀了一套成功率较高的选址SOP。

7月首店上线，星级从0起步。第一天四个咨询，成交三单。刚需的爆发力超出预期。美业休闲类客户会反复比评价、比价格；刚需生意不同，平台运营到位，曝光和转化就是关键。就像饿着走进一条餐饮巷，家家都是盖饭面馆，谁离路口近谁先被选中。

首月星级逐步上升，日均五单。不到两个月，消费额和转化率做到同区榜首。单店每月贡献6000至7000元利润。模型成立后，动作只剩复制和扩张。

## 三、出错率逼我自建基地

事情不会一直顺。洗衣有个客观规律：任何店都有固定出错率，技术、管理、责任心决定高低。我第一家外包伙伴首月出错率12%，高于行业均值。差评能靠好评补救，但数量多了会拖转化，后期维护成本越来越高。

我当时不懂洗护技术，但直觉告诉我，对方流程或能力有问题。我想做长期刚需生意，不赚快钱。为了品牌和品质，我调研30天后，决定自建洗护中心，把质量握在自己手里，这也成了后来的壁垒。

随后90天找场地、添设备、做装修、管工人，踩坑不断，血泪史三天讲不完。熬过来后，我算有了厂房落地经验，也更理解实业的不易。

10月，洗护中心投运，出错率降到1%，在行业里属于优秀水平。

## 四、扩规模与做延伸

基地在浙江，江浙沪皖物流次日达，所以线上店覆盖这四地，进入41个城市、180多个网点。品牌已注册商标，也招募城市合伙人，单人可管多家店。

我积累了四个满员客服🛰️。这些高价值客户还能延伸价值：一是二手奢侈品和奢侈品养护，每月已有稳定收入；说实话，奢侈品养护也值得用同样模式重做。二是卖货，化妆品、零食、鲜花都行，女性客户占一半以上。三是围绕高价值家庭做保洁、收纳等服务，自营或合作均可。

常见问题统一答。

1、异地能做吗？可以。客户不见面，线上代下单，京东与顺丰上门，所以你人在济南，店挂上海也成立。有的合伙人在外地管理接单，勤快的跑企业客户；没时间的在家带娃，电脑手机就能处理，平台订单足够。

2、和传统店比，优劣在哪？

优势：

1）不受门店半径限制。以前只做周边1.5公里，现在全市、全国可接，顺丰与京东覆盖区补运费即可。店可挂一线城市核心商圈，流量最大化。我目前以每月约10家速度扩店。

2）素人也能做。有手机就能接单，人在哪都行，适合宝妈、学生、自由职业者。刚需行业，服务到位就有持续收益。稳稳赚钱更实在。

3）投入低。资金少就把清洗外包，省房租人力，主要成本是平台开户费，可理解成线上项目。

4）收益稳定可观。没送洗习惯的人可能无感，问问城里干洗店老板，秋冬家家爆单。高价值人群最缺时间，对洗护依赖深。电商获客还弥补了实体店夏季淡季。单人可运营5至8家线上店。

5）抗疫情风险。这也是疫情期间该模式加速的原因。

适合哪些人？宝妈、学生、事业单位副业人群；喜欢居家办公的自由职业者；工作清闲、方便接电话的人。

劣势：

1）售价要低于实体门店，这行仍在建立性价比认知。

2）运营和客服话术要求高。不擅长运营可以交流；服务业需要好脾气、耐心和责任心，愿意持续帮客户解决问题。性格不合硬做会痛苦。当然，有钱雇客服也行。

希望这份复盘对需要的人有帮助。感兴趣可以交流。
