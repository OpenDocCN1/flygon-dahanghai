# 创业需要理想主义，这不是虚的

作者：光合 | 日期：2020-11-14

龙珠见面会结束后，我歇了好几个晚上才觉得缓过来。嘴上说自己还年轻，身体倒是很诚实地交代了疲惫，心里也攒下不少感触。

这篇文章我拖了很久，脑海中翻来覆去想了很久。这类话题容易被误解成装逼、扯淡、太虚，但我还是想给自己一个交代，让内心的逻辑能够自洽——否则，跟咸鱼有什么两样？

孔子说：“仁者不忧，知者不惑，勇者不惧。”最好的创业状态，大概就是仁、知、勇都具备：没有忧虑，没有疑惑，也没有恐惧。可现实往往是另一回事。商业环境波诡云谲，创业要闯过九九八十一难，最后也未必能取到真经，大多数时候我们泡在忧虑、疑惑和恐惧当中。有个段子调侃：创业成功上市的概率，大概跟连续两次被雷劈差不多。创业之难，堪比上青天，一将功成万骨枯。既然选了这条路，怎么才能做到不忧、不惑、不惧？

华杉老师给过一个十六字总原则：始终服务于最终目的，随时回到原理思考。我把这句话结合自己的体会，展开说一说。

**一、创业，最终要创的业，到底是什么？**

我的答案是：事业。

中国人讲成家立业，这个“业”就是事业，也叫基业。古人说“先帝创业未半而……”后半句不吉利，就不念了。在现代商业社会，事业的载体是企业。所谓的创业，基本上就是创建出一个企业，并由此拥有自己的事业。事业做没做大，通常看企业规模和市值，这就是“事业有成”。

再往深问一层：企业到底是什么？想通这个问题，就摸到了企业的第一性原理，也理解了创业的终极意义。

德鲁克有一个著名判断：企业相当于社会的一个器官，它存在的最终目的就是为社会解决问题。一个巨大的社会问题，背后就是一个巨大的商业机会。解决得好，企业能够长久发展；解决不好，就会被淘汰。马老师也表达过类似观点：你解决的问题越大，公司市值就越高。如果觉得“社会问题”太宏大，可以把它理解成“社会痛点”——找到痛点，解决它。

扎克伯格在中美创业论坛上说过一席话，大意是：别总问他怎么创办的Facebook，应该问他为什么创办Facebook。很多人还没想清楚要解决什么问题，就把公司开了，他自己觉得这非常疯狂。

那么，企业和解决社会问题之间是怎么连起来的？德鲁克给出的路径是：企业战略的源头，就是找到社会问题，并把解决这个问题定义为自己的经营使命。企业提供的产品和服务，就是解决这个问题的方案，最好是比所有人都更好的方案。所以，想创业，先去找一个社会问题，再想办法做出扎实的产品和服务去解决它，给用户创造更大的价值。人们愿意为解决问题买单，你自然就能赚到钱。

创业的原点和初心，本来就是利他的，是“先天下之忧而忧”。这不是务虚，更不是扯淡，而是最终目的。你先帮别人、帮社会解决一个问题，这是企业的经营使命；赚钱只是顺手的事，是系统给的正反馈。

当你在真正解决一个社会问题时，只要这个问题长期存在，你的赛道就不会出大问题。复利、长期主义，也由此有了蓬勃生长的土壤。所以，创业最终创的，是创建一家解决某一社会问题的企业；如果加个期限，那就是比同行更高效、更低成本地把这个问题解决掉的企业。只有做到这一点，我们才能活下来，并且活得更好。

**二、理想主义，到底是个什么东西？**

要聊理想主义，得先把这个词洗干净。维特根斯坦说过，词语的游戏规则在语言游戏中建立，也在语言游戏中修改。他经常想把词语从交流里拽出来，送去清洗，洗干净再放回去。意思是说，沟通的时候，大家嘴里的词一样，脑子里想的却未必一样。所以才会出现“语言相通，词语不通”的情况，说来说去也说不明白。

理想主义，先看“理想”。字典里的定义是：对未来事物的想象或希望，多指有根据的、合理的，跟空想、幻想不同。你看，这个定义其实讲得很清楚。

小时候老师问我们的理想是什么，答案不是当老师，就是当科学家。为什么当老师？教书育人，长大后我就成了你。为什么当科学家？为国家做贡献，改变人类命运。老师那时候反复强调：一定要做个对社会有用的人。而我们不懂、不屑，更不去做。

为什么要做对社会有用的人？前面讲了，企业的本质是解决社会问题。对个人来讲也一样，你对社会有用，社会才会给你一碗饭。这不就是利他主义、长期主义吗？原来小时候的老师早就想明白了。

所谓“愿你出走半生，归来仍是少年”，大抵就是如此：过了半生，依旧像年少时那样，心里存着理想，想做个对社会有用的人。

但大多数人理解的理想，不是眼前的苟且，而是诗和远方。我以前很喜欢郝云的《活着》，慢慢开始不认同那种带着挣扎的情绪。歌里唱着“慌慌张张，匆匆忙忙……难道说我的理想，就是这样渡过一生的时光”。年轻人总想着诗和远方，中年人开始寻找意义。我的理想从来不是闲云野鹤，也不是诗和远方，恰恰就是眼前的苟且。我也不觉得这是苟且，在我看来，它就是我的诗和远方，是我想要的自由——自由地去选择长期利他，自由地践行我认为有价值的事。

我认同的理想主义，说白了就是长期利他：持续做一个被社会需要的好人，并且乐此不疲，快快乐乐地生活。听起来很虚？以前我也这么觉得。后来真正感受到，才发现它特别实在。理想主义不是假大空，它恰恰是最接地气的姿态——脚踏实地，跟世界、跟他人紧密相连。

至于结果，因上努力，果上随缘，只问耕耘，不问收获。剧作家哈维尔说过：理想不是乐观，不是相信某件事一定会成功，而是相信某件事有意义，无论结果如何。这不是装清高，也不是不在乎结果。恰恰相反，如果眼睛只盯着结果和收获去行动，往往事与愿违；把注意力放在过程和耕耘上，收获会自己跑来找你，只是你无法预知它是什么，也不知道它什么时候会来。

成甲老师就是这样。他最初研究思考力，并不知道未来能做什么，只是觉得这件事很有价值，然后就做了。后来那些收获，没有一件在他意料之中。

三十而立，现在常被理解成三十岁要有成就。这话出自《论语》：“吾十有五而志于学，三十而立。”原意是人在三十岁前后建立自己的人生价值观，就此立住。立在什么地方？立在理想主义上，立在长期利他上。

**三、创业为什么需要理想主义？**

华杉老师有一句话：能够基业长青的企业，骨子里一定是理想主义的；只讲实用的企业，注定走不远。这部分内容，出自《华与华方法》一书。

企业的本质是社会器官，为社会解决问题。企业经营，说到底是一种志向、抱负、使命感，是一种对社会、对人类、对用户的感情。正是这种感情，把企业与五个市场——顾客市场、人才市场、资本市场、政策市场、公民社会——连接在一起，获得他们感情上的关注和共鸣，以及行动上的支持和推动。

我们的成功，从来不是因为自己多厉害，而是因为有人在背后推我们。一路上会遇到贵人，但这些贵人不是我们靠手段争取来的，而是被我们的理想和事业吸引来的。他们认同我们在做的事，于是把帮助我们当成一种乐趣。真正的大事业，都是大家帮出来的。到后来，你不是在带领大家走，而是被大家推着往前走。

就像亦仁说曹大是他的贵人。曹大却说，自己只是在恰当的时机看到了他们、挖掘了他们，这其实是自己的幸运。

2016年6月，《财经》杂志做了一期《百度的冬天》封面报道。谈到百度与谷歌的区别，李彦宏坦言：“我们是实用主义者，不是理想主义者。”被问到这是否让百度在一些决策上变得保守时，他说自己这些年来的理念产生了一些怀疑，也许不应该那么实用主义，也许应该加入一点理想主义色彩，这样大家会更喜欢他。

华杉觉得李彦宏的反思是对的。不过，理想主义并不是为了让大家喜欢，它的价值也远远不止“被喜欢”这么一点。

理想，是一种感情：对社会的感情，对用户的感情，对员工的感情，对历史和未来的感情。熊彼特说过，企业家都有一种情怀——创造一个属于自己的理想王国，照顾好王国里的国民。这就叫理想，叫情怀。

企业家情怀，不是有点小资情调就配叫情怀。它是为社会、为用户、为员工付出的胸怀，是带头解决问题、开创未来的担当。华杉也感叹，现在大家把“企业家会写诗”就当情怀，这个词已经被用滥了。

心里装的是理想主义还是实用主义，眼界完全不一样。实用主义看着眼前，趋利避害；理想主义望向远方，想着怎么解决问题。高下立判。

我的理想主义，是长期利他，做对社会有用的人；创业，则是去创建一家解决社会问题的企业。所以，创业的原点本来就是理想主义，这是底层逻辑。

龙珠会上，亦仁讲到生财有术的使命，是“让普通人赚钱不难”。他说，在年富力强的时候找到使命，是一种幸运，他真真切切感受到了那种feel。黄亮说，自己也被亦仁点燃了。没错，我第一次见亦仁，聊的也不是别的，就是生财有术的使命。

企业的战略，不是企业自己拍脑袋定的战略，而是企业为了解决某个社会问题，替社会制定的战略。生财有术的战略，也不是它自己的战略，而是“让普通人赚钱不难”的战略，这是它的使命。生财有术的业务、产品和服务，最终目的都是解决“普通人赚钱不难”这个问题。不是我们想做哪块业务，而是用户需要哪些业务，我们就要去做，并且真正帮到大家赚到钱、有成长。和用户一起生财有术，活在他人想象之外。

那我们会赚到钱、养活公司和自己吗？一定会的，我毫不怀疑。但赚钱不是终点。正如《基业长青》所说，高瞻远瞩公司的理念核心，就是务实的理想主义。利润只是活下去的必要条件，是达成更高目标的手段，绝不是目的。利润就像人体需要的氧气、食物、水和血液，这些东西本身不是生命的终极意义。一群人选择以公司的形式聚在一起，是为了合力完成一己之力做不到的事——为社会作出贡献。

有了这样的初心和使命，有了这种长期利他的理想主义，我们才不会被风口裹挟，不会弄丢创业、工作乃至人生的意义，并且乐在其中。心有猛虎，细嗅蔷薇。

**四、创业的理想，其实就是个人的理想**

先说一个前提：个人的力量非常渺小。如何成为对社会有用的人？如何放大自己的价值？《基业长青》已经给了路径：把自己放进企业里，借助企业把个人力量汇聚起来、放大出去，以企业为容器，参与解决社会问题的洪流。所以，企业的使命就是团队的使命，也是个人的使命；企业的理想主义，就是个人的理想主义。和一群优秀的伙伴，一起把理想进行到底。

说到底，也许不一定是创业需要理想主义，活着就需要理想主义——活得更有意义，也活得更开心。这样的创业，本质上是一种享受生活的方式，一种度过人生的方式，而不是一份工作。

当年我从华与华裸辞，很多朋友问我想去哪个行业。我说，如果碰到好机会，想选教育或医疗。不是这两个行业多赚钱，事实上它们并没有那么赚钱，而是这两个行业里的弯路太多了，我在里面走过太多弯路、踩过太多坑，深有感触。而且，这两个行业里的每一条弯路，代价都不小，都可能改变一个人的命运。如果我能用自己的踩坑经历，帮别人避开一些弯路，甚至改变他的人生，那得多有成就感。

这个念头在大学时候就有了。我本科加研究生读了七年，靠着懒惰和无知，荒废了大把青春，走了太多弯路。一度想去考博，就为了毕业后回学校当老师，让学弟学妹们少走弯路。毕业后，我又困在自己的信息茧房里，按部就班地上班、存钱，继续错下去。直到加入生财有术，一切才开始变化。说实话，早些年我并没有这些感悟，是生财和圈友们唤醒了我，把我推到了现在这个位置。

如果能帮大家在赚钱和事业上少走一些弯路，由此改变一个人的命运，让他拥有喜悦的人生，那是一件多么令人开心又有成就感的事。然后顺带着，我们也赚到了钱，夫复何求。

对公司内部的团队也是一样：帮他们成长，让他们赚到钱，持续为用户创造更多价值。成就团队里的每一个小伙伴，也让他们拥有喜悦的人生。己所欲，施于人。

我每天的工作动力都来源于此，像滔滔江水一样延绵不绝，不会因为赚了多少钱、吹了什么风、公司发展到什么阶段而变化。听上去很像在装逼，但自己特别脚踏实地。

王阳明在《传习录》里讲：持志如心痛。一心在痛，哪里还有工夫说闲话、管闲事？保持志向就像心口在痛，注意力全被它吸引了，自然没空去说无意义的话、管无意义的事，更不会从众追逐所谓风口。

务虚这种事，悟到了才知道它所言非虚，悟不到就会觉得你在装。我不鼓吹，也不引导，只是平平淡淡、真真切切地分享自己的感受。

以上。

写这篇文章，是想系统梳理自己脑中的想法，让自己更确信心中的答案，顺便分享给大家。一个人选择某种价值观，往往是因为他本来就是那样的人。每个人的世界不同，不必强求一样。开心就好。

我理解中的理想主义，就是长期利他主义。它既是创业出发的地方，也是创业要抵达的地方。把“创业”换成“人生”，同样成立。

看清终局之后，再抬头看天，低头赶路。每一步都算数，行走在世，贡献于人。不忧、不惑、不惧，做一个务实的理想主义者。

让普通人赚钱不难——虽千万人，吾往矣。
