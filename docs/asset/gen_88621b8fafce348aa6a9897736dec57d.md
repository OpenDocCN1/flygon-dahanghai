# 小红书无货源选品：0粉也能出单的实战参考

作者：曜文

最近有不少朋友问我，上回分享的小红书无货源操作流程之后，关于“到底该卖什么”这件事，很多人在选品上卡住了。于是我干脆花了整整一天，把自己整理的一部分案例、选品思路和内容输出的方法都翻了出来，统一放在飞书文档里，方便大家直接查看。

说实话，小红书能卖的东西种类实在太多，不过目前跑得比较好的，基本还是集中在女性用品和儿童用品这两大类。这也是平台用户画像决定的。

很多人可能不知道，在小红书做电商，粉丝量真的没那么重要。哪怕你一个粉丝都没有，照样有机会出单。店铺装修也不用搞得花里胡哨，省下那些精力和成本。你需要做的其实就四件事：挑对产品、把商品上架、把关键词布局做好、然后每天稳定地发内容，单子自然就来了。
