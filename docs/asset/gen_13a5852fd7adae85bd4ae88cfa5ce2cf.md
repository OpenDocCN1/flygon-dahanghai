# 11.5 推广避坑：花钱之前先看懂这些

从产品到流量，中间隔着一条不小的河。

先说渠道。虚拟产品（尤其是 Chrome 插件）有一个特殊玩法：直接把插件商店的地址丢给 Google 搜索广告是可行的，但联盟广告不认这一套——它要求跳转落地页，所以你得额外搭一个独立站。有意思的是，PDF 这类工具属性极强的产品，恰恰非常适合联盟广告，特别是当你把预算集中在垂直网站上的时候。

实际跑过的渠道包括：native ads（试了 Zeropark 和 PropellerAds）、Google Ads（用插件商店页直接投搜索广告和智能广告）。另外两个被直接否决的选项是 Bing 和 Quora，原因不多说，试过就懂。

目前整个投放还处于盲试状态，连统计代码都没装（插件的分析接入方式和网页不一样，可以参考 Chrome 官方的 analytics 文档）。Google Ads 这边只做了最基础的几项调整：地域精确到城市，设备剔除非 PC 端，关键词全部改成精确匹配。

即便只是这种粗放式的跑法，数据也已经露出了苗头：新加坡是当前表现最好的区域，一个安装的成本大概在 0.5~0.7 美金。如果后面做精细化调整——人群、时段、素材——成本至少还有一半以上的下降空间。

再看产品侧的数据。当前约有三成用户安装后选择了卸载（不过样本量还不算大）；同类竞品里，功能差不多的基本都是免费提供，所以 PDFXYZ 这个工具在性能上还得再打磨。亮点在于安装率：100 个人点进来，大约 45 个人会完成安装，差不多 2 次访问就能换 1 个安装。这说明需求是真实存在的，进来的流量也足够精准。

这里有一份 2020 年的海外统计数据，可以回答一个关键问题：Chrome 插件冷启动阶段，预算要准备多少才够。它的结论是——用户数跑到 1000 左右，基本就算在同类产品里冒头了。当然，现在来看这个基线的门槛比当时又高了一截。但按前面最简单的投放方式、单安装 0.5~0.7 美金的成本来算，你只需要准备大约 500 美金的试错预算，就能跑完整个验证周期。

换句话说，这件事的门槛没有想象中那么高。500 美金，试一次，值不值？答案其实挺明显的。

内容来源：《Chrome 插件从 0 到 1 的试错经验》
