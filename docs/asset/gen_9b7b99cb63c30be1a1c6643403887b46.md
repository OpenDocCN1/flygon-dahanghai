# 闲鱼写作号起号：先养号，再装修，后发品

发品之前，先把账号养一养——这一步省不得。新号刚注册就急着上架，平台很容易把你当成机器人，流量自然不给。刚注册的闲鱼号，别忙着装修店铺、写个人简介，先把养号放在前面。

# 💡 养号不到位，会先吃这三类亏

1. 商品曝光受影响  
账号权重不够，商品曝光量会直接变少，平台也可能不会优先推荐你的商品。

2. 上架商品被盯得更紧  
养号不充分时，平台对你发布商品的监控会更严格，审核通过的难度也会加大。

3. 权重低，商品更容易被下架  
低权重账号发布的商品更容易被平台下架，尤其被同行举报时，违规风险更高。

新号可以多时段、多频次地模拟真人动作。建议在每天 8:00—21:00 之间分段操作，每轮 10—30 分钟，连续 3 天左右即可。

养号阶段核心动作有三件：浏览商品、闲鱼签到、闲鱼小游戏。下面逐个说。

# 4.3.2 闲鱼签到：给账号加活跃分

每天签到可以增加账号活跃度和权重。点击闲鱼 APP 左上角的签到按钮进入签到页面，点“赚骰子”按钮，会看到签到按钮，每天养号时顺手签一下就好。

# 4.3.3 闲鱼小游戏：顺手把活跃度做起来

小游戏页面和签到页面在同一个地方。进去后主要玩扔骰子和赚骰子两个小游戏。赚骰子下面会有大量闲鱼任务，有些任务可以选择性不做，例如“发布一件新宝贝”和“邀请小伙伴来签到赚闲鱼币”；其他任务可以下载相关 APP 来完成，包括淘特、菜鸟裹裹、手机天猫、淘宝、饿了么等应用。尽量把能完成的任务都做掉，以此提高账号活跃度和权重，顺便赚闲鱼币（闲鱼币的作用后面会讲到）。

# 5.3 发布时间、频率及下架时机

一般闲鱼号最多可以上 50 个商品。不用一次性把 50 个商品上满，前 3 天可以每天上 3—5 个，每天不要上太多；熟练后可以每天上 10 个品，大力出奇迹。也不要一次性把一天内的作品全部上了，要有间隔地上，可以 1 小时或 2 小时上一次。商品发布时间一般选择上午或者下午。

可以把这个过程想成种地：一个闲鱼账号，平台给这块地的流量就是肥料，发的品就像农作物，这块地种的东西越多，流量分配给每个农作物获取的养料就越少。所以要不断定期迭代商品，数据不好的品就下掉换成新的。

# 六、运营与推广：让商品多曝光多咨询@陈 bu 懂

单品发布完之后，进入闲鱼运营流程。这里也会介绍如何更好地给已上的品增加曝光度和咨询量。

先普及几个需要时刻关注的数据字段。商品页面有三个参数：曝光、浏览、想要。

曝光：你的某个商品展现给别人手机页面的次数。  
浏览：别人看到你的商品之后点进去的次数。  
想要：别人看到你的商品之后点进去，点击了“我想要”或者“聊一聊”的咨询次数。

通过以下运营动作，可以一定程度提升商品曝光次数，增加被客户浏览和咨询的几率。

# 6.1 公益宝贝（可选操作）

新上的商品可以在第一时间开启公益宝贝，能起到增加曝光的效果。在主页商品页面依次点击：加入卖场——>开启捐赠——>我同意，继续捐赠。

[PRE18]

# 💡 Tips

什么样的商品适合开启公益宝贝？  
开启公益宝贝一般需要设置捐赠额度，捐赠比例不建议太高，1% 就可以了。新上的 1—2 天商品可以开启这个选项，后面成交时其实可以把这个公益宝贝关掉。

商品无法开启公益宝贝怎么办？  
公益宝贝的作用只在新上品有推自然流的情况。如果想直接上公益宝贝，可以直接“发布公益宝贝”。实测下来，公益宝贝是个加分项，但实际权重不会那么高，因此是可选操作。做好后续运营操作才是最重要的。

# 6.2 闲鱼币抵扣

新上的商品可以在第一时间开启闲鱼币抵扣，抵扣额度为 5%，该操作可以起到增加曝光的效果。

[PRE19]

# 💡 Tips

什么样的商品适合开启闲鱼币抵扣？  
开启闲鱼币抵扣一般需要设置抵扣比例，比例不建议设置太高，5% 就可以。新上的 1—2 天商品可以开启这个选项。闲鱼币抵扣只适用于前期推自然流的时候，当某个商品流量起来之后可以提前关闭，后面推流就可以使用“急速卖”或者“用曝光”来进行推流。当然，有商品成交时其实可以把这个闲鱼币抵扣关掉，否则客户就可以使用闲鱼币抵扣相应金额了。
