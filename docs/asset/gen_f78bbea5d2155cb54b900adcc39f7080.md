# 1.3.1.2 广告变现先过YPP这关

想靠广告赚钱，第一道门是加入 YouTube 合作伙伴计划（YPP）。申请门槛分两档：

**基础YPP（门槛较低）**
- 订阅者约500以上；
- 累计观看时长或Shorts播放量要求更低，例如3000小时观看时长，或300万次Shorts播放等。
达到后先解锁粉丝打赏类能力：超级感谢、超级留言、频道会员等。

**完整YPP（门槛更高）**
- 订阅者通常1000以上；
- 观看时长或Shorts播放要求更高，例如4000小时观看时长，或1000订阅+近90天1000万次Shorts播放等。
达标后可开通广告收益分成、高级会员等更完整变现选项。

[PRE1]
此外还需：有可关联的AdSense账号，直接注册关联；账号所属国家/地区在可获利范围，中国大陆账号无法获利，需修改所在国家或地区；频道无违规记录，遵守社区准则和广告友好政策，远离敏感违法内容；视频内容适合广告展示，不含暴力、成人等限制话题。

提醒：别买粉、别刷观看时长。这类流量不能带来真实变现，被YouTube查出还会降低频道评级。

建议看官方文档及时更新信息：《YouTube 合作伙伴计划》《YouTube 合作伙伴计划概览与资格要求》《YouTube Shorts 创收政策》。

# 1.3.2 会员收益怎么来
2023年6月中旬起，YouTube扩展YPP，让更多创作者提前体验粉丝赞助和部分购物功能，也就是频道会员收益与电商变现。符合国家/地区条件的创作者，满足以下任一资格即可申请扩展后的YPP：
- 过去90天上传3个有效公开视频、获得500位订阅者，且过去12个月有效公开视频观看时长达到3000小时；
- 或者过去90天上传3个有效公开视频、获得500位订阅者，且过去90天有效公开Shorts观看次数达到300万次。
官方文档可查支持国家与可开通功能：《拓展后的 YouTube 合作伙伴计划概览》。

# 1.3.2.1 频道会员怎么收费
在免费订阅之外，创作者可增设频道会员（Channel Membership）。加入的粉丝按月付费，获得创作者提供的专属福利；创作者可设置不同会员等级和对应福利，费用由创作者定，从几百到上千不等。YouTube抽会员费30%作为平台佣金，创作者拿70%。例如观众月付$10，创作者实收$7。
[PRE11]
# 1.3.2.2 Premium观众也能带来收益
订阅YouTube Premium的用户可跳过广告等，体验更好；当他们观看你的视频时，创作者也能获得YouTube赞助的额外收益，并按观看时长参与会费分成。注意：开启付费会员服务的条件与1.3.1.2广告变现规则一致。
[PRE12]
# 1.3.2.3 会员收益案例
经典案例「老高与小茉」：开通会员后成为YouTube“频道会员增长速度全球最快”的频道。当时总订阅刚破130万，如今已过600万，会员只会更多。

从评论区看会员比例不低：ID旁有头像的多为会员，头像由频道主制作或平台提供，并按会员时长显示不同等级。

YouTube不公开具体量化数据，这里借一位博主分析推测老高频道会员收入：
1. 会员人数估算：普通视频评论/粉丝比0.0677%，会员视频平均评论430。按评论数据推算会员63.5万；考虑会员评论活跃度更高（假设5倍），实际会员约12.7万。点赞数据也支持接近10万的推测。
2. 收入测算：会员价按5美元、平台分成30%，月收入=12.7万×5×70%=44.45万美元，年收入约533万美元。这是2022年底推测，现在只会更高。

# 1.3.3 电商变现路径
除广告和会员，还能卖自己的商品变现。YouTube正在增强直播电商和商品货架功能，方便创作者在平台内完成销售。展示售卖主要有两种：
1. YouTube小黄车：可在视频下方展示自家商品（需加入1.3.2会员收益中提到的YPP）。
2. 独立电商平台：如Shopify、Etsy等，通过外链导流销售；平台会审核导流商品，确保符合规则。
更多ShopPINg功能可看官方内容：《YouTube ShopPINg：从您的商店中添加链接商品并展示》《在 YouTube 上管理、关联和解除关联您的商店》。

# 1.3.4 其他变现方式
# 1.3.4.1 品牌广告合作
创作者与品牌合作，在视频中直接推广产品，按视频条数收费或按销售提成。常见形式：测评与推荐、使用场景展示、特别优惠推广（如限时折扣码）。YouTube广告价码没有正式标准，国外有按粉丝数参考的平均行情：超过1万订阅，每条广告可报200美元；超过10万订阅，可报2000美元；破百万订阅，最低报价2万美元。这种方式门槛偏高，对订阅数有要求；账号刚起步、粉丝不多时，建议先选不看重粉丝量的变现方式。
[PRE17]
# 1.3.4.2 联盟CPS
没有自己的商品却想在YouTube做电商，可在视频描述或固定评论嵌入商品链接，观众点击购买后创作者拿销售佣金，不用囤货或垫付货款，只需引导购买。支持平台有亚马逊联盟、CJ Affiliate、ShareASale、乐天等。常见内容形式：产品开箱与评测、实用教程（操作视频）、排名推荐。
[PRE18]
# 1.3.4.3 知识付费变现
知识付费变现指分享专业技能或知识内容，吸引观众购买课程、咨询或专属服务，从而获得收入。相比传统广告和联盟营销，它核心是用价值吸引付费，尤其适合拥有专业领域知识或经验的创作者。主要形式：
1. 在线课程销售：课程上传到第三方平台（如Teachable、Udemy）或自己的独立网站，通过视频引流观众购买。
2. 会员专属内容：使用YouTube会员订阅功能，观众支付月费可观看独家内容。
3. 一对一咨询或服务：通过描述栏引导观众预约个人咨询（如Zoom、Google Meet），按小时或项目收费。
4. 知识电子书或工具销售：通过视频推广电子书、模板或工具包，观众通过链接购买下载。

# 1.4 开干前先看这些提醒
接下来进入实操。开始前，希望你有长期主义、持续经营的心态。
1. 不要急于求成。YouTube创作是长期过程，以前长视频开通YPP平均周期是2年；现在认真输出优质内容，可能3-6个月可开通。专注提升内容质量和与观众互动，而非只盯数据增长。
2. 前期内容可能不够完美，但别怕失败，重要的是持续创作与学习。最初一个月甚至几个月观看量或订阅数少，很正常。定期查看YouTube分析数据（如观看时长、受众数据等），从数据中学习，逐步调整优化。
3. 选择真正感兴趣的领域，否则遇到困难很难坚持。
4. 理解版权法的重要性。YouTube对版权非常敏感。上传他人内容（如音乐、影视片段、图像）可能导致视频被删除、账号被警告，甚至失去变现资格。
5. 规避常见版权雷区：
- 音乐：避免使用受版权保护的歌曲，除非获得许可；可选择YouTube音频库中的免费音乐和音效。
- 图片和素材：使用无版权限制的图片或视频（如Unsplash、Pixabay或Pexels），或确保拥有商业使用权。
- 影视、游戏片段：即使只用几秒，也可能触发版权警告，特别是热门影视和游戏内容。

# 2.1 账号类型怎么选
# 2.1.1 个人账号
用个人谷歌账号创建，需要单独设置用户名和密码。
# 2.1.2 品牌账号
品牌账号相当于企业账号，可展示企业信息、产品等。这类用企业信息创建的账号，可通过「Google+」或「Google我的商家」等方式创建，无需单独设置用户名和密码，可以有多个所有者和管理员。
[PRE22]
# 2.2 注册账号流程
Step1：国内无法访问YouTube，需要使用可查看外部信息的网络工具。风险原因本次不展开，请先自行搞定网络，确保能正常访问。
Step2：注册一个谷歌邮箱账号。下载手机版🐧邮箱，点击添加帐户，选择Gmail邮箱，创建账号，依次填写相关资料，输入+86的电话号码即可成功注册。（近期有电话无法使用的情况，换一个号码试一下，或用接码平台尝试注册）
Step3：打开YouTube官网，用刚注册的Gmail账号登录。也可参考这个视频尝试注册：https://www.YouTube.com/watch?v=8hk5V2P_72U
注册完后，就可以以正常用户状态使用YouTube：大量浏览、点赞、评论等互动，让YouTube感知到你是真人在使用账号。建议先养号几天再发视频，账号会更稳定。另外，记得把位置设置为支持获利的国家，包括美国、欧洲大部分国家、日本、韩国、印度和南美主要国家。但不用太纠结，因为YouTube流量推送机制并不取决于这个，而是基于频道内容的目标受众。
[PRE23]
# 2.3 开通频道
Step1：点击官网首页右上角Create a Channel选项。
Step2：选择创建个人频道或品牌频道。
Step3：为频道命名，一般使用公司/品牌/产品名称，完成创建后就可以发布新视频。
完整的频道装修由多个元素构成：频道头像、频道名称、频道横幅、宣传片、播放列表、封面图、频道简介等。点击右上角头像进入“YouTube工作室”，在右侧导航栏找到“自定义”就能修改频道个人资料。
[PRE24]
这一步，圈友@方波妮的心态值得学习：不要被“头像怎么弄？封面怎么制作？我做的视频好丑？我怎么这么笨？”卡住进度。头像不会制作，手机相册找一张宠物的、风景照，或用MJ制作一张，先完成再优化；封面同理。停止“我觉得xxx”，模仿爆款让市场检验——非常好的原创，也可能打不过丑丑的模仿爆款，事实证明丑的东西也有人喜欢。放下这种念头，接纳刚开始的不完美，视频发起来，技术都是慢慢优化起来的。

# 2.3.1 频道头像
头像尺寸：98x98px，大小不超过4MB的png或gif图。头像类型：人物照、萌宠、风景、品牌logo、卡通等。头像风格：清晰，最好使用真人形象。制作方式：不会做图可通过做图网站制作头像，或找无版权图片。图怪兽：https://818ps.com/；可画：https://canva.com/；创客贴：https://www.chuangkit.com/；AI工具创作头像可参考AI特效直播实战手册：AI头像壁纸号。注意事项：避免使用容易侵权的商标类图片。
[PRE26]
# 2.3.2 频道名称与标识名
尽量简洁好记；突出视频内容特色或行业特征；可以是个人名字的延伸；中文+英文（注解）；标识名也可作为YouTube URL链接后缀，方便用户查找。注意这两项每14天只可更改2次。
[PRE27]
# 2.3.3 频道横幅
横幅尺寸不低于2048*1152px，大小不能超过6MB。海外很多人通过电视观看YouTube，所以清晰度一定要足够高，横幅内容要明确显示频道主题。可引导订阅；可添加简洁的频道介绍；可加平台链接。
# 2.3.4 播放列表
有一定视频数量后，一定要分类，比如创建播放列表。设置名称时，建议使用和用户搜索意图相关的短语或问句，建议创建多个播放列表。播放列表中的视频自动播放，可引导用户观看更多视频，有助于增加浏览量，还能吸引潜在目标用户。
# 2.3.5 封面图
封面图会在频道显眼位置出现，一定要用心做，因为很多时候人靠第一感觉点击，好的封面有利于增加打开率。优化建议：大众熟悉的东西+制造悬念，熟悉能产生信任感，悬念能引发好奇心；尽量用图片、表情、数字等元素；文字标题内容不宜过多，避免干扰主题；腾出放频道链接的位置（封面图右下角）。推荐工具：Canva https://www.canva.cn/；稿定设计 https://www.gaoding.com/；AI工具创作封面：《3月航海 | AI绘画特训 | 实战手册》。
# 2.3.6 频道简介
一句简洁又能概括频道的标语；介绍自己的基本信息、能给大家带来什么，以及更新频率；建议双语版本；可加其他社交媒体的链接。内容来源：《航海实战 | YouTube - 视频创作 | 实战手册》。
