# 5.2 找源头厂家，5个办法够用 @郑小焦

想锁定真正的生产商，别只盯着一种方式，下面这几条路径可以轮番上阵。

1）用图片反向检索。这个办法经常能派上用场，但也会遇到搜不到的情况：图片边缘不够清晰，或者产品本身是常规 A 与 B 组合在一起，1688 难以识别。如果你只需要其中的 A 或 B，可以先把组合拆开，再拿单件去搜。

2）直接拿关键词去搜。可以从产品名称、特点、用途、制作工艺等角度组合词来查。

3）去竞品的商品链接里挖信息。详情页通常会写尺寸、重量、包装等内容；买家评价里则可能藏着更真实、更清楚、更放大的图片，甚至有人会告诉你，这件东西除了卖家宣传的功能，还能被聪明买家拿去做别的用途。

4）向 1688 上的商家请教。之前我找一款产品，始终搞不清它用什么工艺，问了十几家，对方都说做不了、没法定制。后来我挑了一家回复字数比较多的商家，问：“您能不能告诉我，这类东西该去找哪类工厂？”他给了我几个关键词，我顺着就找到了一批对得上的厂家。

5）先找工艺相近的产品图，再拿图去反向搜。比如有款瓶子市面上很难见到，原因是现在基本卖不动，厂家说大家买回去多用来装榨菜，而我需要它装礼品。我先把装着礼品的罐子拿去搜，结果一个都没有；后来把瓶里的东西清空，只放一张空瓶图去搜，出来一大片全是这个瓶子。
