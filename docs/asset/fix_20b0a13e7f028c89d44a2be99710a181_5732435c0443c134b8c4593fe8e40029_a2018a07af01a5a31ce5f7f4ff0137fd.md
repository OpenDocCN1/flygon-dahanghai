# 辞掉工作后，我把宠物知识做成账号，月流水抵过去整年薪水

文｜虾饼  
2023年6月21日

宠物内容越来越拥挤，头部大号之外，普通新人还有没有机会？

很多人容易忽略一点：红海赛道一旦切得足够细，往往会冒出一块新的蓝海。我在📕做宠物科普之前，完全是零基础，最初只是喜欢分享。起号阶段，我用碎片时间套热门标题试水，大约三十天攒到近千关注。后来转成全职宠物科普博主，靠广告推广变现。如今单月入账超过从前上班整年的薪资，这在当初根本不敢想。

对素人来说，宠物科普的机会更大。和萌宠、吃播相比，它门槛更低，适合新手；账号跑起来后，也不只能做科普，还能做同类矩阵引流卖货。下面分享我做📕宠物科普的经验和实操。

一、先认识一下我

大家好，我是虾饼，加入赚钱圈第三年，跟着谢无敌团队学习红书两年。2021年底辞职后开始经营📕，选了宠物里的细分方向——宠物科普，单月最高收入抵得上过去上班整年。

📕对素人比较友好，上手门槛低，推荐机制也相对友善，普通人有机会从打工人转成全职博主。

宠物行业近年走势不错。相比养娃，不少年轻人更愿意养养育成本低、陪伴价值高的宠物，把宠物当家庭成员，也愿意为它们花时间和钱。

我选这个方向其实偶然性很大，没有做很科学的调研分析，更多是从自身长处出发。我是铲屎官，很爱自家毛孩子，平时逛论坛取经、学科学养宠、淘好物，也爱把知道的安利给朋友。所以我的优势是：有知识储备（多少不论）+爱分享。于是大类选宠物，细分选科普。误打误撞，这恰好是适合新人入场的赛道之一。

起号情况：2021.10 利用通勤时间发简单科普笔记+萌宠日常，后来发现科普笔记流量更好，靠蹭爆款标题攒到近千关注。零散接广，单品报价小几百。2022.2 用了一个爆款模板，一周涨粉3W，广告邀约不断，报价四位数。

二、宠物赛道拆解

宠物赛道大致分：萌宠、吃播、科普。

（1）萌宠 难度：5星
1. 门槛：宠物本身有辨识度，或号主擅长包装
2. 加分项：故事讲得好、拍摄剪辑会
3. 长处：流量池大，跑出大V概率高
4. 局限：泛粉偏多，画像不精准，商单价格低，难以复制

3、素人入场分析

去年📕对宠物赛道很友好，经常给流量扶持，还拉作者群运营。今年砍掉了宠物赛道大部分流量扶持，活动减少，类目仅限萌宠和异宠，大部分作者群也解散了。现在整体环境对新号较友好，新号能拿较多自然流量，老号基本靠推流。品牌和机构入场会挤压素人空间，质量不够高或自然流量不够好的素人，接广概率比之前低。但对素人来说，宠物科普仍是机会较大的蓝海类目。所以建议小白多考虑宠物科普：先套爆款模板起号，再决定做同类矩阵引流卖货，还是精耕内容转型更有深度的科普博主。

三、实操流程

（1）账号装修

1. 号设路线：科普号若以真人出镜，IP价值更高；若让宠物当IP，最好搭配萌宠内容，效果才稳
2. 昵称：带上搜索关键词更易被找到，例如“某某养猫”“铲屎官某某”“某某聊宠物”
3. 头像：真人照片更易建立亲近感，人物形象也更立体

（2）内容来源

1. 豆瓣、贴吧、知乎：适合查选题资料，高质量经验帖较多
2. PetMD、ASPCA、icatcare：用英文关键词在谷歌检索，可找到不少同类站点；资料要自己翻译，但有专家把关，比中文论坛素人发帖更严谨
3. 谷歌学术：适合找文献，宠物相关研究国外更先进、资料更丰富
4. 📕：内容质量参差，主要用来模仿呈现方式，如标题、封面、排版等

（2）推广合作流程

① 合作形式

合作形式分报备笔记和非报备笔记。报备笔记是官方认可的品牌合作，要被收取“保护费”；非报备是私下合作，悄悄打暗广。非报备又分单品和合集：单品是一篇笔记只含这个品的广告；合集是多个品给广告费同时出现在笔记里。单品里还有伪合集：一篇笔记看似出现多个产品，真正给广告费的只有一家，用来最大程度避免被判定私自推广。

和PR聊时还要问清：

1. 档期：出初稿、终稿和最终发布的日期
2. 授权转发：能否授权品牌在电商/内容平台发布，是否免费，授权周期多长。尾部博主一般免费授权，周期一般三个月到半年
3. 授权投流：能否授权品牌在📕投流，是否免费，周期多长。投流能帮博主涨数据，但如果品牌爆出丑闻还继续拿笔记投流，会影响账号形象，所以最好定周期，比如一年内免费授权投流，一年后看情况是否继续授权、是否加费用
4. 笔记发布后的保留周期：一般一年或永久
5. 排竞：发布这篇笔记前几天到后几天，不能再发该品牌竞品相关笔记
6. 活动出席：美妆和穿搭类品牌可能邀请达人出席产品发布会等

② 如何报价

推广分无费和有费。无费是置换，把东西送你，你帮忙出一篇笔记，和📕好物体验差不多；有费是给一定报酬。大原则报价一般按粉丝量的10%～20%，具体看账号情况，如果近期流量好、账号定位与品牌契合度高，可再往上。

还要看是否注重长期合作。一种情况：笔记报价较高但效果不好，品牌可能不考虑二次合作；另一种：原价2000一篇，按预算一个月只够合作一次，如果谈到1500一篇，或许一个月会找你合作两次。

再看是跟品牌直接对接还是跟机构对接。机构一般要返点，返点是收推广费后返一部分给机构。20%左右较合理，35%以上我觉得离谱。图文报价一般低一些，约视频报价的60%～70%；但如果本身偏图文博主，图文报价可与视频相当。报备笔记报价要高于非报备，因为不仅被品牌收服务费，还要接受更严格审核，可能需要更高配合，到手比非报备低就太亏。

有一点很重要，一定要跟PR讲：现在给的价格是几月份的价格，是否必须在当月发布，如果延迟到下月发布，是否要涨价（保价概念）。

然后修改次数：特别是视频，脚本接受几次修改，后期接受几次修改，大改是否加钱。

有些合作不按固定价格结算，可能按周期内互动量阶梯付费，比如7天内到100赞多少钱，到1000赞多少钱；也有按带货佣金，给基础费用后，带多少货额外给多少钱，或者没有基础费用按纯佣计算。

寄样品有两个概念：寄拍和送拍。寄拍主要用于单价较高产品，拍完照片要寄回给品牌；送拍是东西完全送给你。

③ 结款

最后结款，要问清是否需要发票。跟机构对接他们会帮你开票，不用担心；跟品牌对接可能要你提供替票或上诺诺网代开发票。替票是你去外面消费，要求开发票，用合作公司抬头，再把发票给他们报销；代开发票可上某宝搜发票管家，里面有代开选项，是诺诺网提供的服务，选一个税点低的城市，开票给品牌方。

还要问清结款周期：发布后就打款，还是要等多久。结款方式是直接打私人账户，还是要注册类似人力家这种第三方平台；这类平台会帮你交税和解决品牌发票问题，很省心。

现在也不止接推广变现，发笔记带商品链接也能挣佣金，类似抖音小黄车，>1000粉后可开通。此外还可以开📕店铺，自己给自己带货，无粉丝要求，找得到货源即可。
