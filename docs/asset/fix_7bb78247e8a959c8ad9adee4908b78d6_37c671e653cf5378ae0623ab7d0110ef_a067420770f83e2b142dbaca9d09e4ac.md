4. 三屏顺序怎么定

- **首屏那张：**选主体最明确、信息最直给的一幅，先让刷到的人停一下。
- **中间部分：**补动作、补局部，或换个观察角度，别让后面的图重复前面的图。
- **收尾那张：**落到结果、做个小结，也可以抛一个选项，让评论区接话。

💡

**20分钟还没定下来，就先停手。**第一条内容凑齐1—3幅达标画面就够了，素材库以后慢慢补。

**这一轮做完，手里应当有：**

• 已定下一个具体话题。
• 存好了1—3幅同话题画面。
• 每幅画面的出处、授权范围都核过，必要记录也留着。

💡

**提醒：**没拿到许可，别直接搬别人的单幅照片或整组图文。优先用自己拍且能发布的画面；若用授权图，授权范围要匹配当前用途；商用图要明确可商用，生成图则先确认工具规则允许。

5. 画面先过及格线：可辨、清爽、成组、对题

| 判断项 | 手机端怎么自查 |
| --- | --- |
| 可辨 | 缩成小图后，主体和关键大字仍能认出来，不能发虚、失焦。 |
| 清爽 | 不要出现大块水印、广告角标、错别字，也别堆一堆抢眼杂物。 |
| 成组 | 同组画面的比例、字体、边距、主色保持一致，别突然变大变小、变红变绿。 |
| 对题 | 画面要能证明或补充眼前的话题，不要仅仅因为好看就硬塞进去。 |

**一秒测试：**把画面缩到手机屏大小，只看一秒；如果主体是什么、想表达什么都说不清，就删掉或重做。

真实生活感：让细节自己说话

不是故意拍虚，也不是把房间弄乱。画面里同时有可感知的时间、地点、动作和一个可信细节，人才会相信这件事真发生过。人物不出镜也可以。

比如旧物掉漆、桌面磨损；饭菜的锅气、焦痕和正在翻动的手；宠物毛发与抓痕；中年日常里的钟表、账单、剩饭、改过很多遍的文件名。聊天记录、订单、证件、人像要脱敏；不属于自己的经历，别写成亲历。

每多划一屏，都该多拿到一点

后一幅画面要带来前面没有的场景、细节、证据、对照或选择。试着遮住其中一幅，如果整条内容毫无损失，那它大概率只是陪衬。

拿煎土豆举例：首屏放成品并抛出疑问；第二屏讲切块厚薄和翻面动作；第三屏给焦边、调味与最后结果。三屏不是重复同一盘土豆，而是各回答一个新问题。

6. 三条制作路线，按手里有什么来挑

💡先问画面来源，再问这一幅承担什么职责：有自己拍或已授权的原图，走路线一；没有可用原图、但允许画面示意，走路线二；底图已经成立、只差一句解释，走路线三。别因为某个赛道流行某种样式，就把所有题目套成同一模板。

6.1 路线一｜原图优先：自己拍或拿到授权

1. 至少找一个画面核心：人、物，或那个不寻常的点。
2. **每个角色拍两版：**擦净镜头，靠近窗边或主光源；一版近景，一版带环境稍远。画面本身已能说明问题，就别预留叠字区；确认要加字，再选不压主体的位置。
3. **只做基础处理：**拉正、裁掉杂物、稍微提亮、统一色温，别用重滤镜把真实质感磨没。
4. **按角色筛图：**同一个细节只留最清晰的那幅，并检查隐私信息。

**实拍参考：首屏爆点从哪里来**

实拍不必像摄影作品。有效首屏的判断标准是：缩到手机大小后，一秒看见主体，两秒说出哪里不寻常，顺手还能问出一个问题。下面这些截图只作选图练习，重点看它们为什么让人停下来。

💡

**选图四问：**主体能否一眼识别？反常点能否一句话说明？有没有近景作证？能不能自然问出“你见过吗、你们那里怎么做、这到底是什么”？四问里答不满三问，就不适合当首屏。

6.2 路线二｜没有原图就做纪实示意：学规律，不冒充现场

参考图不能直接变成发布图。没有授权时，只提取主体占比、动作、环境、光线、生活痕迹和第一眼爆点，再围绕新话题重做。

参考图只放内部分析区，不进发布文件夹。

1. **先确认素材能不能直接用：**自己拍或明确授权的画面可进发布流程；只有参考价值、没有授权的图，只能用来分析题材与构图，不能改一改就发。
2. **重做时只学规律：**记录主体占比、动作、环境、光线、生活痕迹和第一眼吸引力，再换成新主体、新场景、新细节。
3. **生成先出无字底图：**写清主体、一个动作、普通环境和一个可见细节；明确不要中文、数字、Logo和水印。
4. **完成后做事实检查：**人物、手部、物件不能畸形；生成图要标明“画面示意”，关掉参考图后仍能独立表达才算完成。

6.3 路线三｜无字底图＋准确叠字：画面不够再加标题

工具可用 Canva可画、稿定、醒图，也可以让 Skill 先生成无字底图，再交给排版工具叠中文。关键是把底图和文字分开处理，避免生图时直接出现乱码。记住四个动作：

1. **新建3:4竖版画布：**可用1080×1440；同组保持同一尺寸。
2. **导入底图并裁切：**先保住主体，再找上方、下方或侧边的留白。
3. **封面只放一个重点：**标题1—3行，只用两档字号和一个强调色；背景复杂用白底条，背景干净可用描边大字。
4. **复制封面做正文页：**每幅只讲一点，统一字体、主色和边距；缩到手机大小预览，确认可读后导出高清PNG。

**轻量交付：**第一条先做1张封面＋0—2张补充图。字体不超过2种，主色不超过3种；字太多先删字，不要先缩字。素材确实有更多信息时，再增加画面。

7. 版式怎么挑：看画面，也看标题

风格差异不取决于谁更高级，而取决于四件事：原图留白在哪、标题多长、这一屏要让读者做什么、内容本身什么气质。

| 常用样式 | 适合什么素材 | 怎么做 |
| --- | --- | --- |
| 白底条标题 | 单幅生活照、背景稍乱 | 用白色实底托住1—3行标题，阅读最稳。 |
| 顶部描边大字 | 主体在下、上方留白干净 | 标题放上方，不遮人脸、食物和关键物件。 |
| 四宫格＋超大字 | 多幅细节、清单或前后对比 | 先让人看出“内容很多或差别明显”，标题必须短。 |
| 叠放标签 | 三个短判断、步骤或原则 | 每条只写一个重点，不把长段正文塞进标签。 |

8. 发布前五项自检

首屏在手机上1秒能看懂，主体、标题和账号方向一致。

画面可辨、清爽，比例、字体和色调基本一致，没有大水印或错字。

后一幅提供了前一幅没有的新信息，没有重复图和纯装饰图。

至少有一个真实场景或可信细节，同时没有隐私、版权和错误信息。

正文不重复图上文字，结尾问题具体、自然、好回答。

### 04. 【数据复盘】先看清数据，再决定改什么

💡

**本章概要**

发完要留记录，但各账号能看的数据不同：没开通流量主，先盯阅读、来源、互动；开通了流量主，再看广告曝光、收入和eCPM。内容曝光不等于广告曝光，别混为一谈。

📌

**未开通流量主：**记录发布时间、话题、阅读、流量来源和评论。等后台出现广告收入入口，再补看广告曝光、收入和eCPM。

开通流量主：进入广告收入明细。

广告曝光量指广告实际展示次数；eCPM可理解为每千次展示带来的有效收入，会随广告需求、用户和时间变化，不是固定单价，也不能单独判断内容好坏。

[PRE29]

**先看自己现在能看到哪些数据**

📌

**看图顺序：**先确认话题、受众、信息增量和版权安全；再同方向连发3—5条，每次只改选题、首屏、文案或节奏中的一个变量；最后看连续表现，别用一条数据定账号方向。

**“进池”是什么**

“进池”是运营者口头说法，不是后台官方开关，也没有固定阅读门槛。更实用的判断是：流量来源里开始出现推荐、搜索等非订阅入口，而且不只出现在一条内容上。

**单条突出：**某条内容的推荐或搜索流量明显高于账号其他内容，可记为一条较好样本，但不能据此认定账号稳定。

**账号持续获推荐：**连续多条都从相似入口获得分发，且讨论仍围绕同一人群和主题，才说明账号方向开始形成较稳定信号。

一条数据说明不了整个方向。先同方向连发3—5条，再看类似反馈是否重复出现，然后决定接下来改什么。

进入推荐池后，再按5项连续判断决定接下来怎么调。
