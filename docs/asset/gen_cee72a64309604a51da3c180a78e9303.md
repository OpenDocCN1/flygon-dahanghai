# 欧盟为何力挺Web3创新？

2020年9月，瑞士议会通过《区块链法》，加密资产买卖、交易平台运营等Web3业务由此在法律上获得认可。自治市卢加诺走得更远：比特币、USDT等稳定币，以及当地自行发行的代币，都能像法定货币一样用于日常生活消费。

瑞士的先行探索，也带动欧盟整体对Web3和加密资产采取欢迎姿态，政策环境相对宽松。

目前，欧盟的整体政策大致落在三个层面：

**法律定性**：代币享有合法财产地位。

**金融监管**：加密资产可能被归入证券、货币、基金或虚拟货币四类，每一类都有对应法规约束；不同国家和地区还设有相应的金融牌照要求。

**税务安排**：加密资产与法币互换属于应税行为，不过眼下暂被列入免税优惠范围；挖矿等服务的规则由各成员国分别制定，彼此存在差异。

从财产认定到金融、税务规则，欧盟为Web3留出了相对清晰的发展空间。
