# 开篇先聊几句

欢迎加入这场三月航海，这次要啃的是📕百货店铺。往后一段日子，我们会在这儿碰面很多回。

正式动笔前，先把三个绕不开的疑问说清楚：

1）它到底是个什么项目？前景如何？

不少人下单之前，会先去📕做功课——想吃什么、要添置什么、假期去哪儿，习惯性搜上一搜。这个平台天然离交易很近，可站内的电商链条，长期以来并不完整。

转机出现在几个节点：2020年10月，店铺功能正式开放；2021年8月，入驻门槛被调低；2022年10月，个人主页多了购物入口，看过的主页与笔记里的商品，都能在这里找到；2023年3月底，【笔记带货】上线，靠达人合作笔记撬动电商成交；到了2024年，平台又牵手春晚、提前铺开"年货节"，做商业化的态度很明确。

放到📕电商的各条赛道里比一比，百货的上游供货商密集、可剪辑的素材充裕、新品更迭频繁、买家需求旺盛，属于风险相对可控、回报又比较可观的方向，对刚入门的人格外友好。

2）开店有哪几种做法？

手里有货的，走自营；手里没货的，去对接货源方合作。至于既无合作、又靠代拍的无货源玩法，如今不建议碰——平台已经明确了处罚口径。

无货源的好处是启动资金少、转身灵活；隐患在于笔记一旦爆了，订单跟着暴涨，合作的供货方未必接得住。走这条路的人，平时要额外留心储备几家能备用的货源。

提醒：平台正在集中整治无货源代拍，官方发过《关于无货源代拍的专项治理公告》，蝉小红也做过分析。如果你正这么做，尽快与可靠的货源方签约，或者直接向工厂订货，把身份转成有货源经营。

3）什么人适合入局？

电商项目的门槛它同样有：要么手上有产品，要么能找到握有产品的搭档。若既找不到稳定货源，又急着赚第一笔钱，最好别贸然下场。

#### 1.1.1 用户是谁

年龄层主要落在18至34岁，女性约占七成。居住地多为一、二线城市，身份以都市白领、职场骨干为主。"年轻""偏女性""消费力强"依旧是三个显眼标签。这群人精力充沛、愿意尝鲜、爱交流爱分享。另外，31至40岁的人群逐年变多，他们更在意生活质感，也乐于聊自己的购物心得与日常。

用户聚集在经济更发达的一、二线城市，消费能力更高，对品质与体验的要求也更高。

六类核心人群：

1）Z 世代：以兴趣为纽带社交，紧跟潮流，玩网游、打卡学习、关注竞技体育
2）新锐白领：财务独立，热爱本职工作，性格积极外向，个性鲜明
3）都市潮人：看重时尚与自身形象，精神独立，有自己的主张
4）单身贵族：经济自主，注重享受，讲究品质，消费轻量化
5）精致妈妈：在意生活品质与外在形象，消费偏高端，重视护肤保养
6）享乐一族：以娱乐为先，为兴趣买单，追求体验与享受

这恰好印证了📕社交电商的底色——需求清楚，品质意识强。

从职业看，上班族与学生占比最大，他们讲究生活品质、爱尝新、喜欢晒购物心得；自由职业者与全职主妇更看重实用与性价比，关心商品用起来到底怎么样。

还有一点值得注意：男性用户正快速涌入，在这里分享日常。平台也在给男性博主资源倾斜，内容多元化之下，美食、旅行这类中性题材，以及科技数码、体育赛事这类偏男性的题材都在升温，男性用户随之增长。

#### 1.1.3 社区什么调性

看口号就明白——"标记我的生活/你的生活指南"。它是一个生活方式内容社区，也是一个种草平台。用户一边记录自己的日子，一边给别人种草，或者被别人的内容种草。

不管哪一种，落点都是"内容"。你可以展示真实的自己，越接地气越好，但它既不是🧣，也不是朋友圈。哪怕是真实生活，内容依然要被筛选——同时过了平台和用户这两关，才有出圈的机会。

[PRE10]

#### 1.1.4 流量怎么分

两个最重要的入口：【推荐流量】+【搜索流量】

1）推荐流量

和多数公域平台类似，这里也有一套算法推荐。系统会依据笔记初始阶段的点赞、收藏、评论、转发分享、涨粉情况打分，其中评论、转发、涨粉的权重更高。

CES 评分 = 点赞×1 + 收藏×1 + 评论×4 + 转发×4 + 关注×8

PS：CES 是📕内部的评分体系。

分数往上走，笔记就会被一层层推进更大的流量池，最终成为爆文（小爆款互动量1000+，大爆款10000+，各类目标准略有差别）。一篇爆文还会把同账号其他笔记的数据一起带起来。当然，前提得满足：

① 笔记通过了系统审核，没有违规，也没被系统删除，或你自己删掉、隐藏；
② 笔记里带着关键词（比如香水、家具），能对上垂直标签，被系统识别收录，进而推给对该标签感兴趣的人；
③ 内容本身质量过硬，能勾住用户来点赞、收藏、评论。

特别说一句：

零基础的新手，第一篇就出大爆款的情况很少见；运营头一个月，阅读量（小眼睛）卡在100-200很正常，底子好的见效会快些。

八成新手要到第二或第三个月才迎来爆发，前面是酝酿期，不必焦虑，把内容磨好就行。

2）搜索流量

用户不只是逛首页，也会主动搜索想要的东西。想买口红就搜口红攻略，计划旅行就搜旅游攻略。

搜索结果里排在前面的笔记，曝光和关注自然更多。这块流量几乎占总量的半数以上，千万别小看。

#### 1.2.1 前景怎么看 @谢无敌

📕已经成了很多人的消费决策工具，吃什么、买什么、去哪儿玩，先搜一搜。它离钱很近，可长期以来，大部分人的成交动作还是发生在某宝、某东。为了补上闭环，📕两头下手：一边严打导流，一边把自家电商系统补齐。

2021年8月，官方推行"号店一体化"，把账号体系化简为专业号与非专业号，开店所需的粉丝数从1000降到0。唯一条件是开通专业号，而这一步几乎是申请即过（医疗等特殊身份除外）。

2022年10月，有博主留意到个人主页多了购物入口，之前浏览过的企业号或笔记里的商品会在这里出现（该功能尚在内测，并非人人都有）。

3、成本可控：成交效果可追踪，出了单才付佣金。博主卖出商品后，商家按实际销售额结佣，转化能力看得清，成本也压得住。

#### 1.2.4 无货源还能不能玩 @表弟、@云端行走

平台目前不认可无货源代拍，但找供应商代发是可以的，代拍和代发这两件事要分清楚。

下面几点能最大限度帮你避坑，其中第四点是关键，也正是代发与代拍的分水岭：

无货源代拍的做法是先大批铺货，等出了单再去找货，找不到就下架。一两次平台和买家不会追究，次数一多就可能被判定为无货源。

如果某个品确实好、当下却没货源，可以挂15天预售，给供货方留足备货时间，自己的风险也小一些。中国制造几乎没有15天造不出来的东西，真要是卖爆了，自己联系工厂做也不是不行。另外建议做一张选品表，提前把利润算清楚，参考同行定好价再上架，方便后续复盘和下单。
