#### 1.1 应用模式究竟是什么

多维表格应用模式（Base App）是飞书多维表格新推出的能力，它提供了一种新的业务系统搭建方式：不用写代码，靠简单拖拽就能搭出专业级业务系统。即便没有技术背景，业务人员也能较快做出贴合实际需求的交互界面和流程。

💡

**应用与多维表格是什么关系？**

应用负责给终端用户提供简单易用的操作界面；多维表格则充当应用的数据库与运行引擎。一个应用能关联多张多维表格的数据，二者配合，才能组成完整业务系统。

### 2. 工作流 AI Agent 说明

工作流 AI Agent 也是多维表格的新能力，本节理论内容参考飞书官方文档。

多维表格工作流中的 AI Agent 节点，是飞书多维表格推出的强 AI 节点。把它放进工作流后，就能借助 AI 高效处理复杂业务。

AI Agent 节点能理解并使用多种工具，比如发消息、新增记录、抽签、生成随机数等。你还可以自定义 MCP（模型上下文协议）工具，为 Agent 节点扩展更多可用工具。

Agent 节点会结合实际任务要求做智能规划，主动调用工具完成工作。它还具备记忆能力，可读取群聊、单聊上下文，从而更清楚任务背景。

当任务需要依据上下文动态决策，并调用多种工具协同完成时，AI Agent 节点就很合适。你可以用它轻松搭出以下工作流：

+ 能智能查询多维表格数据的飞书消息机器人
+ 可自动、定时汇总今日所有项目任务进展的机器人
+ 自动创建任务的机器人
+ 自动提取并格式化处理数据的机器人

[PRE17]

AI Agent 以大模型为核心，同时具备记忆与多工具调用能力。在 AI Agent 节点中需要配置：

**AI Agent 主节点：** 在这里写给模型的指令，输入中可以引用工作流产生的数据，还能定义节点输出内容的格式。

**大模型子节点：** 选择模型，并设置生成随机性、最大回复长度等参数。

**记忆子节点：** 若以收到飞书 Lark 消息作为触发条件，可通过该子节点设置传给模型的历史对话轮数。

**工具子节点：** 可添加多种类型的工具节点，包括自定义 MCP 工具。

执行时，模型会按主节点中的指令自主规划、调用工具节点提供的工具来完成任务，最后按指定格式输出。AI Agent 节点还提供较丰富的配置项和日志能力，便于保证流程可控、可审计。

#### 2.2 开始前的准备

在搭建自动化工作流前，先要在多维表格中设置好三类字段：接收输入、触发流程、存储输出。下面会指导你完成三个核心字段的标准化配置。

**2.2.1 字段一：创意输入区**

这是文本字段，用来存用户输入的创意或提示词，也是后续 AI 处理的数据来源。选择文本类型，是因为它不受字符格式限制，中英文、数字、标点都能兼容，也能容纳从短关键词到长描述的各类内容，符合 Prompt 多样化输入需求。

**字段配置操作**

点击新建多维表格，在字段类型列表里选“文本”。这样做是为了设定数据存储格式，确保交给 AI 模型读取的是基础字符串。

把第一列字段标题改为“动物”。这样做是给该列数据赋予明确业务含义，方便后续工作流引用变量时快速认出它是输入端。

其他选项保持默认，点确认保存。这一步完成字段初始化，使其立即生效、可输入，主要用于写入创意。

[PRE24]

**2.2.2 字段二：触发按钮配置**

这是按钮字段，用于手动启动自动化工作流，把每一行数据的处理权交给用户。之所以选按钮，是因为视频生成服务通常有 API 成本和较长耗时；若自动触发，用户输入时修改内容可能误触，造成资源浪费。按钮能确保用户确认信息无误后，才显式发起请求，实现按需执行。

**字段配置操作**

点击表格第二列列头图标，在字段类型列表中选“按钮”。这一步引入交互控件，让表格除存储静态数据外还能执行功能。

在按钮文字框填入“生成”，再选一个醒目颜色。这样做是通过视觉标识告诉用户按钮用途，并区分操作区与数据区。
