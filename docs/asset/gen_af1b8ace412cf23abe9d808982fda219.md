# 3.1.4 案例三：逻辑发圈，三步带出付费转化 ②

[PRE0]

三条内容，就能搭起一条引导用户付费加入我星球的完整路径。

第一步，我先发了一条观点型文案，聊风口上的创业者：有人在红利期赚到了钱，可风一停就失去方向，反复回味旧日成绩，最后什么也没留下。这条内容发出去后点赞很多，也能明显感觉到，不少创业者被戳中了。

趁着这个热度，我很快围绕同一主题写了《如何成为创业常胜将军》，并把文章放在付费星球里，只有付费才能阅读。朋友圈的推进分两步：先晒出文章的半屏截图，用内容价值做间接引导；再晒一张加入星球的成交订单，做直接引导。

这套小逻辑并不复杂：先输出观点，再展示价值做间接引导，最后介绍产品做直接引导。大家推广自己的产品时，都可以照着用。

想在朋友圈促成成交，别一上来就生硬发广告。你没有先给到别人价值，谁会停下来被你吸引？

比如你卖减肥产品，可以先围绕相关知识点写：哪些减肥方法容易踩坑，正确的减肥方式是什么，再说明你是怎样帮助用户减下来的，最后自然提到产品并引导成交。

内容来源：《巧用「逻辑线」发圈法，让用户越看越上瘾》
