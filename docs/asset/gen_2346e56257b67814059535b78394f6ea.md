# 3.1 前端入门

平时用电脑或手机浏览器，看到最多的就是网页内容，比如百度页面、各种搜索结果页；常用 App 也往往有网页版，比如🧣、📕、淘宝等。

做网页必须用到前端技术。前端可以理解为页面视觉层，也就是用户能直接看到的部分。比如整页背景图、某个按钮、某个输入框，凡是网页上看到的内容，都用到了前端技术。

前端技术主要由 HTML、CSS、JavaScript 三部分组成。这三样不需要安装任何类库，所有浏览器都能识别。所以纯前端应用怎么运行？直接用浏览器打开就行。

看看这三种语言分别是什么、又如何协同做出网页：

HTML：页面上看到的元素都由它呈现，比如图片、链接、按钮等。

CSS：负责页面样式，比如按钮放在什么位置、背景颜色、字体大小和字体类型等。

JavaScript：可以简单理解为让网页动起来的语言。只有前两种的话，网页不能交互，比如点击按钮没反应、输入的数据不能发送。可以说，它是网页与人互动的灵魂。前两种语言都比较简单，这一种会复杂些，和 Python 类似，属于高级程序语言。

这三种语言通常同时出现，也可以同时保存在同一个 .htm 格式文件里。所以我们让 AI 生成一个 HTML 源码，就表示这三种语言都会被涵盖进去。浏览器会自动识别 .html 格式文件，保存后双击这个文件，就会打开浏览器窗口并展示网页内容。
