# 1.2 Web3：下一代价值网络？

如今，“Web3”几乎成了一个什么都能装的词，它承载着人们对“更好互联网”的想象。往深处看，它想借助区块链、加密货币与 NFT，把所有权交回给用户，让权力不再集中在平台手里。

不过，这个行业还处在很早的阶段，想给 Web3 下一个毫无争议的定义并不容易。好在有几条原则一直在指引它：去中心化、无需许可、原生支付、无需信任。

所谓去中心化，是指网络不归某个中心化机构所有和控制，而由建设者和使用者共同拥有。无需许可，意味着人人都有平等进入的机会，不会被挡在门外。原生支付，指人们可以直接用加密货币付款、汇款，绕开传统银行和那些承担类银行职能的中介。无需信任，则是指系统靠一套激励与经济规则自行运转，不必把信任托付给某个可信第三方。

看到这里如果还有点模糊，没关系，我们继续往下拆。

要理解 Web3，不妨先把它和 Web1、Web2 放在一起看：Web1 只能读，Web2 能读也能写，Web3 则是能读、能写，还能拥有——所以它也被叫作“价值网络”。

从演进过程看，1989 年，Tim Berners-Lee 在日内瓦的 CERN 着手开发后来成为万维网的协议。他希望做出开放、分散的协议，让信息可以从世界任何角落被共享。

这套后来被称为 Web 1.0 的形态，大致存在于 1990 年到 2004 年。那时的网站多是公司持有的静态页面，用户之间几乎不互动，个人也很少生产内容，因此它被概括为“只读网络”。

到了 2004 年，社交媒体平台兴起，Web 2.0 拉开帷幕。网络不再只是只读，而变成了可读可写。平台不再只由公司向用户单向输出内容，而是让用户生成内容、彼此互动。

随着上网人数增加，少数头部公司逐渐掌握了网络上不成比例的流量与价值。Web 2.0 还带来了广告驱动的收入模式。用户虽然能生产内容，却不拥有这些内容，也无法从内容变现中获益。

[PRE1]

Web3 这个概念，则在 2014 年由 Gavin Wood 提出。他既是 Polkadot 创始人，也是以太坊联合创始人，背后关联着两家头部区块链公司。他们关注的问题是：当下的 Web2 需要太多信任。换句话说，人们今天熟悉的大多数网络，都建立在信任少数私营公司的基础上。Web3 想解决的，正是用户能否拥有网络信息所有权的问题。

[PRE2]

所以，Web3 是什么？它是一个价值网络，让用户真正拥有自己信息的所有权。

用几个例子更容易看清 Web1、Web2、Web3 的差别。

Web1 的代表，是 PC 互联网时代的巨头：海外有雅虎、谷歌，国内有搜狐、网易等门户。它们主要做信息聚合，用户进入网站后点击、浏览内容。

移动互联网到来后，信息生产不再只由门户完成。全球数亿用户成了信息生产节点，大家既能获取信息，也能自己生成信息。国外的 Facebook、Twitter，国内的微信、抖音，都是 Web2 时代的代表产品。这些平台一端连接大量用户，另一端对接商家，通过广告形成商业闭环，是典型的平台型经济。其本质是：平台用免费服务聚拢海量用户，再在未经用户允许的情况下，把用户信息卖给商家来赚钱。

那 Web3 呢？它把互联网信息产权交到用户手中。内容一经用户创造，权利便立即归属用户。Web3 运行的是一种“所有者经济”。如今用户不必先把身份绑在各大平台的账号上；只要创建自己的钱包，就能在 Web3 各类应用里自由通行。钱包的概念和使用方式，后面还会解释。理论上，你的钱包只属于你，不属于任何公司或组织。在 Web2 里，如果游戏账号被封，或者游戏公司倒闭，你的虚拟资产可能就没了；在 Web3 里不会这样——归你的东西依旧归你，即使公司倒闭，各类信息资产仍留在你的钱包中。这就是 Web3 的特点：归根结底，它突出的是用户对信息的所有权，是一种原生的价值网络。
