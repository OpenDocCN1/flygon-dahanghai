# AI绘画，线下也能收钱？

AI绘画热了不短时间，但眼下能看到的赚钱路径大多还停在线上，真正落到线下场景的玩法并不多。

我脑海里冒出一个画面：门店里放一块AI绘画展示屏，路人可以免费试几轮提示词，等画面生成得满意，再按张付费打印。因为图里带着自己的输入和选择，顾客掏钱时往往更爽快。

抖音上就刷到过相似案例：有人把设备铺到线下，靠卖照片收钱。还有传闻说，福田插画馆一台机器单月能做出10万元营收。传闻归传闻，至少说明线下并非没有空间。

那ChatGPT有没有可能也长出线下生意？不妨一起开开脑洞。

评论区里还冒出一个思路：街头不少店专门帮人题诗、写字、题词，如果接上GPT，或许能变成一套可售卖的服务。这个点子能不能跑通？
