# 4.1.3 金融到底在解决什么问题？

聊金融之前，先看看传统金融都干了些什么。

支付、储蓄、借贷、投资、保险、外汇，这些是金融活动的主要类型；对应的产品则是货币、股票、债券、保险、黄金，以及各种带金融属性的东西；而银行、证券交易所、保险公司、理财机构、第三方支付平台，就是从事这些业务的机构。

我的理解是：金融的核心，是提升整个社会的资源配置效率。

但这里有个很特别的地方——金融里最核心的“钱”，本质上只是一个大家共同认可的概念。所以那些围绕钱设计的各种产品，说到底也是围绕“共识”在运转。

这就是金融和实业最大的区别。实业能造出看得见摸得着的东西：大楼、机器、飞机、火箭。而金融解决的更多是共识层面的问题，你看不见它，但它真实存在。

不过金融有个特点：它是顺着人性走的。也正因为如此，金融一旦出现，就很难从世界上消失。

判断一个行业能不能活得久，我有个很简单的标准：看它是顺应人性，还是违背人性。

比如白酒和香烟，它们就是利用了人性的弱点，所以生命力极强。政策再严，也只能阶段性限制，没法让行业彻底消失。

再看教育，它天然是反人性的。要是没有考试，没几个人愿意主动学习。所以做教育这类生意，政策风险就是必须认真掂量的因素。

还有那些互联网提效工具，绝大多数并不是人性的刚需。人嘛，能躺着就不坐着，本能地抗拒改变。这也是为什么很多看似“高效”的产品，推广起来总是很费劲。
