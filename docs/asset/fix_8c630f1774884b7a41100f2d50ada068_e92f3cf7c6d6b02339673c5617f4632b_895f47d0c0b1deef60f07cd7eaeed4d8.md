# 1.2 长篇与短篇怎么分

在这行，长短篇更多看读者习惯和商业模式，字数界线比较松：

1.

字数标准

短篇：1万～5万字，比如知乎盐言故事、🧣连载短篇。

长篇：主流在50万字以上，超长篇能到数百万字，比如《斗破苍穹》超过500万字。

2.

发布形式与更新节奏

短篇：

单次发布：一次完结，适合碎片化阅读。

微连载：拆成3-5章更新，比如豆瓣阅读的“三日完结”计划。

长篇：

日更模式：每天2000-6000字，用来维持读者黏性，比如起点中文网。

IP衍生导向：长期连载，为影视、游戏改编攒内容库。

# 2.4 写出具体章节

# 2.4.1 爆款短篇的共性

（1）导语（50-200字）

必须写出虐点或爽点。

✅经典套路：男主偏袒女配，让女主去死；女主真死后，男主却疯了。（这里以都市情感小说为例。）

（2）正文（10000字）

第0-2000字：把爆点亮出来。比如男主和女配暧昧/亲密，女主被女配欺负，男主却偏袒女配、虐女主。

第2000-4000字：拉情绪，末尾卡在女主死。比如女主要死了，女配还在挑衅；男主陪着女配一起虐女主，女主心灰意冷，死。情绪要拉起来，怎么让读者生气怎么来，中途给点追妻火葬场的暗示，勾住读者。

第4000-9000字：高潮，后悔。写男主爱而不得，发现自己爱的是女主，可女主已经死了。

📒总结：

👉男主先不信，以为是女主的把戏，不放在心上；

👉男主知道女主死了，开始疯狂找女主；

👉男主发现处处都是女主深爱自己的痕迹，后悔不已；女配继续作死；

👉女配被男主警告/报复/抛弃；男主后悔想弥补，却于事无补，痛哭流涕。

第9000-10000字：让读者解气。男主悲惨结局：把男主往死里写，怎么惨怎么来，疯狂虐男主，提高爽度。

（3）总结：
