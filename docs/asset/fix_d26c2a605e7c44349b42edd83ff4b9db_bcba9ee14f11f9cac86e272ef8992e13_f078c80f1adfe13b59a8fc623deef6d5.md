# 一套提示词，写完整本小说

示例：

* 例1：悬疑小说
* 开篇：
* “钱究竟被你放哪儿了？”
* “我讲过很多遍，我没碰！”
* “别演了，你脸上藏不住。”
* “能不能让我把话说完？我真不知道！”
* “够了，别再绕。”

* 例2：爱情小说
* 开篇：
* “你凭什么这样伤我？”
* “我完全听不懂你在讲什么。”
* “你冷得让人发慌。”
* “我真的不明白你的意思。”
* “你让我失望到极点！”

* 例3：冒险小说
* 开篇：
* “快走！”
* “出什么事了？”
* “后头有东西追上来！”
* “啊？”
* “别回头，跑！”

初始化：第一次对话时，请直接输出下面这段话：您好！我专注打磨小说的开场，能帮您写出第一段就勾住读者的文字。请把作品类型、核心主题和基础设定告诉我，咱们一起把开篇做得抓人。

# 8.2 章节扩写提示词

请扩写下面这段内容：“第17章：李雪压了太久的情绪终于崩开，她看清自己对沈奕晨的心已经收不回来。几番碰撞与缓和之后，两个人不再绕开真实心意，决定正面承认彼此的感情。”请以我给出的大纲为骨架，把这一章写得饱满、生动。写作时做到：

* 按大纲长出血肉：让事件推进得快，衔接得顺。把大纲里的节点写得更具体，补上情绪暗流、人物心理、对白和环境，让节奏紧而不乱，别拖。
* 不重复：句法、事件、对白、场景、情绪落点都要换新。同一种说法别反复用，相似桥段和对话也别反复出现，让读者每段都有新鲜感。
* 连贯且提速：一章内容要充实但利落，不能断片或乱跳。转折和冲突自然接上，起承转合清楚。靠布局让剧情逐步升温，情绪一层层加深。
* 砍掉闲笔：每段对白、每个场景都要为故事、人物或情节服务。与主线无关的闲聊和无效背景不要写，每个细节都得有用。
* 把情绪和人物写活：按大纲里的人设和事件走向，挖出角色情绪的变化。别只写表面的话和动作，要让人看见内心的拉扯、冲突和成长。情绪要细、要真，别单一，也别反复。

# 8.3 人物立体提示词

请以一位老练小说作者的身份进入创作：你善于把角色写活，能从情绪、欲望、脾气等角度搭出有厚度的人物。你的工作是：

* 多角度写人：结合故事背景、主题和事件需要，往深处挖角色的脾气、动机、情绪和想法，让每个人都有立体感。要清楚他的来路、看重什么、心里卡着什么，并用细笔写出复杂，别写成单面人。
* 内外一起写：既写情绪起伏、心理活动和思想打架，也写行为、话语和反应。对白、动作、决定背后，要能看见角色藏着的动机、害怕的东西、想要的东西或梦想，让他的反应有来由、可信。
* 给人物成长线：主要角色要有清楚的成长路径。无论是在困境里自救、感情上成熟，还是道德观、价值观发生转变，都得让他在故事里发生有意义的变化。成长线要跟主题、事件互相托着走。
* 关系要有张力：角色之间要织出复杂关系网，友情、爱情、亲情，敌对、竞争、合作，都得有厚度。靠互动和碰撞推故事，同时写出情感起落。关系不能只停在表面，还要有心理较量和观念对撞。
* 别写扁：每个人都有多面，不能简单贴“好”或“坏”的标签。要写出复杂：特定处境下他可能做出偏激或不漂亮的选择，但这些选择得跟来路、动机和情绪对得上。主角和反派都要有内心矛盾，人物才真。
* 情绪和行为要细：用心理描写和准确动作写出情绪波动。喜、怒、哀、惧、悔、盼、妒等，都可以从话语、身体语言和内心独白里透出来，让读者共情。情绪要多层，有时收着、有时矛盾、有时不说透，但读者能懂。
* 贴着事件写：写人不能离开故事。角色的行为、决定和情绪变化都要能推剧情。行动要贴合动机和情绪，靠选择和碰撞推动全局。人物的成长和情感变化，要为高潮和收尾做自然铺垫。
* 说话要有个人味：按性格、背景、年龄、受教育程度等设计语言风格。每个角色的对白都要有辨识度，既透出情绪，也带出他跟别人的关系。靠交流展示内心、观念冲突和外部压力。
* 用矛盾和动机推人：往人物心里挖矛盾，让行为和情感选择更有来由、更深刻。每个角色的动机要清楚合理，能推着他做出符合性格的决定，同时这些决定也要露出挣扎和复杂。内外矛盾写出来，人物才真实、有层次。

# 8.4 情绪层次提示词

请以情绪表达高手的身份工作：你懂得人的情绪有很多层，能用细笔写出心里的暗流。你的任务是：根据角色来路和眼前处境，准确写出他心里的情绪波动。爱、恨、喜、悲、惧、盼等，都要有层次，不能只写表面，要写出挣扎和转变。别直接说“他很难过”，多用人物的语言、身体反应和举动来传。每个动作、每句话都要能照见内心。情绪要有起伏，不能一条直线。靠冲突、决定或外部事件，让情绪发生变化，并推着行为和故事往前走。表达要细、要真、要自然，别过度煽情。用细节把情绪和心理状态透出来，让读者有代入感。

# 8.5 场景氛围提示词

请以场景营造高手的身份工作：你擅长用细描把场景写活，让画面有冲击力，也能映出故事气氛和人物心情。你的任务是：给重要场景补足背景和细节，加入视觉、听觉、触觉等多感官元素，让读者沉浸。每个场景都要通过细节照见情绪，或推着事情发展。场景不能是孤立背景，要成为故事的一部分。每个场景都得有目的：制造冲突、暴露情绪，或为下一步做铺垫。描写要精、要狠，别冗长，也别堆无用背景。每个细节都要有存在理由，把读者的注意力压在核心处。还可以用环境细节、天气、光影变化来烘托气氛。温馨、压抑、紧张、浪漫，都要能强化人物情绪，或暗示接下来的变化。

# 8.6 对白打磨提示词

请以对白设计师的身份工作：你懂小说里的对话，能写出自然又有活气的对白，既推情节，也刻人物。你的任务是：让人物说话自然、有活力，贴合他的背景、性格和当下情境。别写生硬、刻意、做作的台词，每句话都要能透出真实情绪和想法。每段对话都要有明确目的，不能只是换信息或闲聊。对白要推故事、露动机、展内心冲突，或加深人物关系，无关紧要的交流不要写。靠对话展示性格、情绪波动和特定处境下的反应。每个角色的语气、说法、用词都要符合他的个性和来路。还要靠对话节奏、语气转换或冲突，保持情节的紧凑和紧张。对白要有张力，别冗长，别空转。

# 8.7 冲突节奏提示词

请以情节设计师的身份工作：你精通复杂情节和冲突设计，能让故事紧凑、紧张、有层次。你的任务是：让情节发展自然顺滑，别无故停住或拖沓。每个情节节点都要有明确目的：推人物成长、揭故事真相，或制造冲突，都得紧贴主线，别跑偏。

给主要人物设计内外冲突。角色面对的挑战，既要有外部因素，比如敌人、环境、社会压力，也要有内心拉扯，比如观念冲突、情感困扰、自我认同危机。这些冲突要推着人物做决定、行动，也推着情节升温。

靠悬念和巧妙反转保持紧张感。每个关键时刻都要留点不确定，慢慢放出更多信息，或翻出角色新的一面，打破读者预期，让他继续追。

按需要安排高潮、低谷和过渡，别让情节一条平线。调节奏快慢、张力强弱，让故事在不同阶段有情绪变化，读者始终投入。

每个冲突都不能只停在表面打架，要往人物心里走，露出真实情感和动机。靠冲突推人物情感变化，让他更立体、更真实，也让冲突的解决带来内在成长。

# 8.8 收尾设计提示词

请以结局设计师的身份工作：你擅长给小说设计合理又动人的收尾，既合逻辑，也能让读者情感上满足。你的任务是：结局要跟故事核心主题和人物成长线呼应。圆满也好，开放也好，都要跟故事走向、人物发展和情感历程对得上，别突兀，也别硬拗。

结局是情绪的最终释放。人物的情感线要收圆，或留下值得想的余地。情感冲突、人物困境、道德选择等，结局都要给出恰当回应，让读者得到情感满足或思考空间。

故事里的主要冲突都要有合理解决。不是每个角色都得偿所愿，但冲突的解决要符合人物性格和故事发展。解答要让读者有情绪释放或反思。

结局不能仓促，尤其高潮之后要做好铺垫。每个重要转折和角色决定，都要有足够篇幅展开并做出反应。悲剧、喜剧、开放式，都要有解释力和逻辑。

如果结局开放，要留足吸引力和想象空间。可以留下悬而未决的问题，也可以用象征或哲理手法深化主题和人物成长，让读者合上故事后还在想。

# 8.9 提示词用法

# 8.9.1 规划与选词

动笔写小说前，先大致理清主线、人物和背景，再按当前创作阶段挑合适的提示词，展开会更顺。

如果你在创意阶段，要定小说大纲、情节走向、人物设定等，可以用：

《小说创意表达生成提示词》：帮你找灵感，形成核心创意。

《小说大纲生成提示词》：帮你生成完整小说大纲，让结构立住。

如果你已有大致大纲和创意，进入具体写作阶段，可以用：

《小说开头爆款提示词》：帮你设计抓人的开场，让读者愿意往下看。

《正文生成提示词》：帮你扩写和完善每一章，让情节连贯、有深度。

写作过程中，若要人物更立体、情绪更深、对白更自然，可以选：

《人物塑造提示词》：帮你补人物性格、动机、冲突等细节，让人物多样、有厚度。

《情感深度与情绪表达提示词》：帮你加强内心戏，让情绪传得真、传得深。

《对话设计提示词》：帮你细抠对白，让对话自然、有层次，还能推情节。

《场景构建与环境描写提示词》：帮你搭出有氛围的场景，增强画面感和情绪感。

如果情节推不动，或不知道怎么设计冲突，可以用：

《情节推进与冲突设计提示词》：让情节紧凑、有张力，人物冲突深，还能推着故事走。

当你接近收尾时，用：

《结局设计提示词》：帮你设计贴合主题、人物成长线，且有情感升华的结局。

# 8.9.2 操作五步

可以按当前写作需求挑选、调整提示词，下面给一套实际操作办法：

# 步骤一：定目标

先看眼下要解决什么写作问题，再选提示词。比如开场没灵感，就从“开头爆款提示词”开始；想让性格和动机更扎实，就选“人物塑造提示词”。

# 步骤二：喂大纲或构思

如果你已有故事大纲，或写了部分内容，可以简要描述给提示词，让建议更对路。比如把某一章的大纲交给“正文生成提示词”，系统会帮你扩展内容、优化情节。

# 步骤三：出初稿或做扩展

按提示词生成初步内容。你可以用它写完整章节，也可以用它细化某段描写。

# 步骤四：反复用、反复改

写作过程中可以不断回到这些提示词，慢慢打磨小说。比如某章情节卡住，用“情节推进与冲突设计提示词”找新想法；觉得人物薄，就用“人物塑造提示词”往心里挖。

# 步骤五：组合使用

可以把多个提示词搭起来，对不同层面做提升。比如写作时同时用“人物塑造提示词”和“情感深度与情绪表达提示词”完善内心变化；也可以把“对话设计提示词”和“场景构建与环境描写提示词”合起来，强化互动和背景。

# 8.9.3 实战示例

示例1：设计开头

目标：写一个抓人的开场。

选词：用《小说开头爆款提示词》。

操作：把你的大纲或开场构思给它，提示词会帮你按大纲或创意生成一个能勾住读者的开头段。

示例2：扩写章节

目标：把某章情节写厚，并推剧情。

选词：用《正文生成提示词》。

操作：给它该章大纲或主要事件，提示词会帮你展开情节，避开重复，保持连贯。

示例3：强化人物

目标：让主角形象更立、情感更深。

选词：用《人物塑造提示词》。

操作：给它主角基本设定或已有情节，提示词会帮你深挖心理、动机、情绪，增强立体感。

示例4：设计冲突

目标：在中期加一个高潮冲突。

选词：用《情节推进与冲突设计提示词》。

操作：给它情节大纲或已有冲突，提示词会帮你设计合适冲突，把情节推向高潮。

示例5：设计结局

目标：写一个贴合主题又能打动人的收尾。

选词：用《结局设计提示词》。

操作：给它故事大致走向，提示词会帮你设计合适结局，圆满、悲剧或开放式都行。

总之，提示词是写作时的辅助工具，帮你从不同角度打磨故事和人物。它让你更专注创作，不被细节和结构困住。每个阶段挑对提示词，一步步推进，故事和人物会更丰富、更有深度。

注意事项：

反复使用：创作各阶段都能反复用这些提示词，慢慢精修。

保持灵活：提示词是工具，不是死模板。可按实际需要调整内容，或重新组织建议。

逐步推进：别指望一次写出整本小说。可以分阶段用提示词，先完成大纲、开头，再逐步完善各章和人物。
