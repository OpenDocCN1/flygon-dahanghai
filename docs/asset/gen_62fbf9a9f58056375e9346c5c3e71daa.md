产品体积偏大，布景范围也要跟着放大；如果是香薰、相框这类小件，有一张书桌或一块地毯就足够。

# 3.3.5 实拍四大关键点

1. 图片清晰度：实拍素材够不够高清很关键。苹果手机可参考上面的参数调整；非苹果手机拍摄时，应关闭自动美颜等功能。在保证清晰度的前提下，不必过度迷信爆款模板——大多数产品图都走简洁路线，模板越花哨，出货量反而往往越低。

2. 突出功能性：也就是直接回应用户的痛点，在内容里解决他们的疑问。比如光腿神器，用户会担心褶皱和肤色问题，拍摄时就可以同步展示产品不褶皱、肤色自然的特点，从而提升顾客信任。

# 6.3.3 如何提升实拍素材利用率

同一张图片不能在小红书反复发布多次，否则会触发「大量发布低质/重复交易笔记行为」的处罚。

但既然拍了，当然希望素材能多用几次。下面是一些提升使用率、又不容易重复的方式：

1. 拍live图转静态图
苹果手机的live图通常会记录拍照前后共3秒的视频，然后选其中一帧作为主要展示画面。
如果画面幅度较大，可以在相册里选另一帧做封面，这样静态图就相当于换了一张图。
一个live图可以拆成N张图片发布。
不过，如果画面浮动不大，小红书仍可能判定为同一张图片。
图1是原图，图2是换了另一帧的画面，多了一只鸭子，看起来就像另一张图，但它们都来自同一个live图。

[PRE25]
2. 拍live图转视频
live图本身是3秒视频，可以把图片转换成视频。
转成视频后，用多个素材重新剪辑在一起，做成一个全新素材，思路和混剪一样，但这些素材是自己拍的，原创度很高。
也可以用一键成片、营销视频重新剪一遍，同样能用。

# 6.4 注意事项

# 6.4.1 评论区运营

小红书挂产品链接的笔记，流量通常比不挂链接的低。

原因是挂了商品链接后，平台更倾向于推荐给「电商消费人群」，这类用户在小红书有较强购物习惯，好处是产品转化率更高。
不挂车的笔记会被当成普通笔记推荐，按算法分发给所有用户，好处是浏览量可能更多。

如果发布笔记时没有挂链接，一定要在评论区置顶链接、产品购买引导图，或者直接在评论里回复产品链接。

# 6.4.2 封面测试

实拍非常依赖封面点击率。前期不要自己随意发挥创意，应严格参考同行的爆文去拍图。

看同一产品下哪一类封面出现次数最多、爆文最多，就说明这类封面点击率最高，也最受用户喜欢。

比如光腿神器，下面这些相似角度的封面，不同账号发都能出爆文，说明这个封面的点击率不错。

拍摄封面时，就可以针对这个角度多拍几张，用来测试封面点击率。
多找几个「爆款封面」拍，看哪个角度更适合自己。

# 6.4.3 拒绝“杂货铺思维”

小红书高客单蓝海跟无货源电商不完全一样，经营的类目和产品要更垂直。

比如可以专注“户外美学”，而不是泛家居用品，这样能避免人群标签混乱。
再比如「盖个帽儿总店」这个账号，虽然不是高客单，但她专注大头围帽子这个赛道，做单品类蓝海，也卖爆了几个产品。

# 6.5 如何筛选长期合作供应商

前期先用一件代发，等单量多起来，再考虑长期合作。

筛选长期合作供应商主要看两个方向：

# 6.5.1 配合度

如果供应商不配合，后面发货、售后会非常吃力。

1. 是否配合电子面单
每日订单超过10单，就可以跟供应商沟通绑定「电子面单」，之后下单、发货都能直接在这里完成。
但前期直接沟通绑定面单，供应商不一定同意，建议出单后再聊。

[PRE31]
2. 售后咨询回复是否及时
一件代发前期对产品会有很多问题，自己还不熟悉产品时，需要供应商协助解答。
如果一个问题半天才回复，大概率会影响小红书店铺的成交率。
而且这类供应商很可能没有自己的客服团队，属于比较小的供应商，通常不太稳定，说不定什么时候公司就没了。

3. 发货是否及时
小红书店铺对发货时间有要求，通常是24小时、48小时，越快发货越好。
确认供应商时，要确保他们的发货时间最长48小时内能发出。拖太久不发，小红书后台会扣推迟发货费用，一般是3块钱。
另外，如果个别情况无法按时发货，要及时跟客户沟通，不要提前填快递单号！提前填了单号但物流不更新，属于无效，还是会扣钱。

4. 是否支持退换货
这个不强求，主要看退换货原因。如果是用户喜好问题导致的退换货，部分产品不支持，比如服装类，大部分供应商都不支持退货。
但如果是产品本身原因，是可以退换的；连这个都不支持退换货的话，这家供应商就不值得合作。

# 6.5.2 产品方面

1. 价格
刚开始谈一件代发，量小，一般没什么价格话语权。当每日订单稳定在50+，可以跟供应商沟通更低价格合作。
同时要确保自己的价格在同行中有优势。如果自己的成本价就是其他同行的卖价，且产品一模一样，说明供应商没给你低价；这还不肯降价的话，可以换了。

2. 款式
有些产品更新迭代很快，比如手机壳、穿戴甲等，要看供应商是否能及时更新新款，以及有没有开品能力。
有些小众蓝海品对供应商的开品能力要求非常高，尤其是「设计师出品」的珍珠项链、饰品等。没有很好的款式，也不开发新品，这类供应商不太适合长久合作。

3. 质量
质量一定是最关键的。产品如果质量不好，一定会产生大量售后，处理售后非常麻烦，而且不赚钱。

4. 补货实效
供应商也有工厂、销售、门店的区别。门店的货发完后，短期内可能无法及时发货，就需要补货。
一般好一些的供应商补发≤48小时，这不会影响小红书的发货时限。
如果长时间不补货，这种也不值得长期合作。

# 七、更多选品方法

选品方法有很多，整体不外乎4种：

1、从小红书站内选品

常用方法有：考古加选品法、蝉妈妈选品法、抖音精选联盟的创意中心选品法等。

3、从传统电商平台选品

4、SEO搜索词选品

# 7.1 小红书站内选品

# 7.1.1 低粉爆款选品法

什么叫低粉爆款？
一般指带货的小红书账号低于200粉丝，同时最近7天发布的单篇带货笔记点赞超过100，且该带货笔记商品销量大于100，这样的产品就是低粉爆款品。

这个选品方法的真正目的，是找到小红书站内正在推、且有潜力的爆品，第一时间跟品截流。

相比抖音创意中心选品法，这个方法更建议做女性产品类目（更容易在小红书上先爆起来）的小伙伴重视，比如雪莉枚U型枕、发箍、帽子等爆款素材，首发都在小红书。

小红书站内找低粉爆款主要有2个方法：一个是用灰豚数据；一个是手动刷。不同品类具体应用时，要观察选择更合适的方法。前期建议2个搭配使用，多维度观察。

# 7.1.1.1 灰豚数据低粉爆款选品法步骤

工具只是实现诉求的手段，大家可以按喜好使用：

第一步：打开灰豚数据
第二步：点击笔记查找，选择笔记搜索
第三步：勾选【带货笔记：是】
第四步：勾选【低粉爆文】
第五步：搜索你要对标的品类，比如想做连衣裙，就搜索连衣裙。

即使使用灰豚数据，找对标账号也应选择粉丝在200以下、点赞在7天内大于100的笔记，同时该带货笔记商品需要销量大于100，才可以选这个品。同样使用低粉爆款法。

# 7.1.1.2 在小红书内手动刷

确定要做某个品类后（比如帽子），可以找一个小号，持续搜索这个帽子相关的内容。
系统会给这个号打上“帽子感兴趣”的标签，继续推送帽子相关内容。

在看系统推送内容时，点进笔记主页，看是否是低粉丝（尽量小于200）。如果是，记得点个关注、点个赞、评论一下。
这样系统会慢慢记录你喜欢低粉丝账号的帽子，后续第一时间给你推送更多帽子的【低粉爆款】内容。

这样就可以每天刷小号，第一时间知道最近什么款式又出来了、什么样的文案和封面更容易有数据。
这个方式看起来需要花点时间，但不停刷笔记的过程，也是在不断培养品感和网感。
