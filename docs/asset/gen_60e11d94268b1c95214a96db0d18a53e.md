# 十年创业血泪史：几千万买来的教训

各位圈友，见字如面。今年实在太忙，产出不多，最近抽了半个月时间，把过去十年的创业经历整理成一篇长文分享出来。这些经验是用几千万的代价换来的，希望对你有帮助。

## 一、前言

其实去年我就动了写总结的念头，当时创业刚满九年，想着索性等十周年再动笔，当作给自己的复盘，也能给后来人一点参考。到今年7月1日，我正式离开返利网创业满十年。原本打算6月底写完、7月1日发出来，结果那阵子心绪不宁，具体原因就不提了，总之静不下心。

这一拖就拖到了九月。再不写，这个选题估计真要流产——它已经被我一而再、再而三地往后延期。

前几天看到曹大（caoz）一篇关于创业的十万加爆文，感触很深。曹大在文章开头说，十年前他鼓动别人创业；五年前他开始分辨什么人适合、什么人不适合；现在他基本劝退每一个想创业的人。为什么？因为时代的机会窗口越来越小，创业的机会成本越来越高。没看过的朋友可以去找他那篇《还在做创业梦？醒醒！》。

我自己走了十年创业路，也算是个老油条。这些年做过不少项目，前前后后砸了几千万进去。身边常有老朋友、年轻朋友来咨询，说想出来创业，让我给点建议。绝大多数情况我都劝退，只有极少数人——我真心觉得他强、有资源、有积累、时机也合适——才会鼓励。劝退的时候，有人不理解，以为我不希望他们“暴富”。等他们真的投身创业、被市场毒打一顿，又跑来跟我聊：“老胡，你当时说得对，但我当时听不进去，有点后悔了。”

我的回答是：很多事没亲身经历过，确实无法感同身受。把这段经历当成人生修炼也挺好。“创业”两个字听起来很风光，真正扎进去才知道它意味着什么。它不是一路从天使轮到A轮B轮C轮，然后IPO、买大别墅、迎娶白富美、走上人生巅峰。不是这样的。不管你以前的职场履历多精彩，从创业那天起，你就进入了一个茫茫未知领域，只能趴在地上匍匐前进。随时可能踩到雷区，直接挂掉。战战兢兢、如临深渊、如履薄冰、时常焦虑、彻夜失眠，都会成为你的生活常态。而且大概率是创业一场空，输掉全部，包括自信心，严重的甚至妻离子散。

这些话，真正独立创业过五年以上、亲自操盘过从0到1的人，应该深有体会。

所以这篇文章没有华丽辞藻，不会为了转发量写煽动你创业的激情文字，更不吹牛装逼。只是把十年里实实在在的经历和心得拿出来分享。内容比较多，我分成六个模块：前言；和电商结缘及三次小型创业；返利邦时期；玩好货时期；兔子优选时期；后记。下面正式开始。

## 二、我和电商的结缘及3次小型创业经历

正式讲十年创业之前，先说说我和电商怎么结缘的，以及三次小打小闹的创业。因为这些经历对我的认知提升也起了很大作用。

2004年，我在北京，刚从学校出来，到一个私人小企业老板家里做网站，主业是卖牧羊犬。老板家住在朝阳区楼梓庄，养了200多条牧羊犬。最贵的一条叫“威士忌”，从德国进口，花了300万。2004年的300万，对我来说就是天文数字。这条“威士忌”住在老板家别墅车库里，每天24小时有专人伺候。为什么这么贵？因为它爷爷、奶奶、外祖父、外祖母都拿过国际大奖。我也是那时候才知道，狗也讲究血缘。

我负责网站的运营和维护。简单说，就是摄影师给狗拍完照片，我来处理并传到网站上，然后维护论坛。买家和需要配种的人都是通过网站了解信息、在论坛留言交流。平时事情少得有点无聊，但日子过得很舒服。办公室就在老板家别墅里，衣服有保姆顺手洗，吃饭有专门厨师做。最大的缺点是极度无聊——整天就我一个人，没什么交流和学习氛围。

没事我就上网看新闻。2004年12月底，我看到马云当选“中国经济年度人物”，听他讲话真是热血沸腾。他说：“如果马云可以成功，那么80%的年轻人都可以成功”“蚂蚁雄兵可以战胜大象”“男人的长相和他的才华往往成反比”“今天你不电子商务，未来你将无商可务”“平凡人也可以干非凡事”“今天很残酷，明天更残酷，但是后天很美好。只要永不放弃，过了明天，我们也许就能见到后天的太阳。”看完之后，我整个人像被点燃了，特别想加入阿里巴巴。但当时远在北京，身上也没什么钱，一个人突然跑去杭州不现实，就没行动。

北京太孤独，跟我一起来的同学大部分都回家了，加上我也不适应干燥气候，2004年底我就离职了。

回家过完年，我去了上海。其实我本来想一个人去深圳闯荡，那时候有点天不怕地不怕。但家里人坚持让我去上海，因为很多亲戚在那边，吃住都有照应，找工作也方便。

到上海后，第一份工作是在培训学校当计算机老师，第二份是广告设计制作。虽然不是电商，但我一直关注电商动态，每天看“电子商务世界”“艾瑞网”这些网站。2005年10月，我入职一家垂直B2B网站做网站设计，后来转岗做运营。业余时间还开了一个淘宝店，卖高仿大牌运动鞋，货从阿里巴巴B2B网站（也就是今天的1688）上进，然后在淘宝卖——就是今天大家熟悉的一件代发、无货源店铺模式。

开店第三天，我通过网络赚到了人生第一笔钱：20块。这个客户是湖南怀化的，没有支付宝，特意去邮政银行给我汇款。交易结束，我兴奋了一整周。原来通过网络真的可以空手套白狼、赚到真金白银。就是这20块钱，让我对电子商务产生浓厚兴趣，也改变了我后来的人生轨迹。

2005到2008年，我一直兼职开淘宝店。2008年之前只卖运动鞋，2008年又开了女装店，也是一件代发。两个店每个月能帮我赚几千块，加上工资，日子还过得去。我出身农村贫苦家庭，平时很节省，不乱花钱。

开女装店时，我发现一个需求：大量女性用户每天通过旺旺问我，买了衣服怎么搭配。我一个钢铁直男哪懂这个，只能复制过去问供应商，他们回答后我再复制发给客户。说白了就是Ctrl+C、Ctrl+V。但问的人越来越多，我就想：如果做一个教女性穿衣搭配的网站，应该很有前景。毕竟一个女装店每天都有这么多人咨询。

后来，我和一个做技术开发的朋友一起做了个女性资讯+购物网站，叫“女性部落”（ladybolo）。内容都是从各大门户搬来的，但网站右侧会配上文章里介绍的相似服饰鞋包进行售卖，供应链来自阿里巴巴B2B和淘宝上的一些大卖家。

当时我们没多少钱，不做付费推广，也根本不知道SEO这类免费流量方法。唯一能做的就是去各个论坛发帖，还有自己录视频传到优酷，在视频里加网站广告。流量有一点，但非常少，始终没起色。做了半年就关掉了。这就是我第一次创业做平台的经历。

虽然关了，但在2008年初，这个网站还拿到了上海互联网站长大会颁发的“最佳草根创业之星”奖。评委是原新浪创始人王志东、大众点评CEO张涛、艾瑞网CEO杨伟庆、百姓网创始人王建硕等大佬。评选理由是我们把资讯和购物很好地结合在了一起，创业方向不错，也算是虽败犹荣。

后来蘑菇街和美丽说诞生，我才意识到，我们当时不应该选图文内容导购，应该选读图导购。但那时候淘宝卖家图片普遍拍得很一般，没模特、没专业摄影，观赏感差，读图模式也做不起来。而蘑菇街美丽说出现时，淘宝商品图已经精美多了，大量店家请模特和专业摄影师拍图，图片导购模式就非常合适。所以，一个商业模式大方向对了，落地解决方案和天时地利人和也非常关键。做过产品的人应该深有体会。

“女性部落”关掉后，2008年初，我和一个朋友去了广州，在淘宝开店卖二手笔记本电脑。广州那边产业链很发达，很多国外淘汰的电脑运进来，更换硬件、修一修，就能变成七八成新的样子。我们判断，中国网民会随着互联网发展大幅增加，以前在网吧上网的人，迟早要自己买电脑在家上。笔记本需求肯定很大，要抓住这波机会。

事实也像我们想的那样，生意每天都不错，一天能发几十台。但问题也很突出：淘宝竞争激烈，没有付费推广手段，只能压低价格，让消费者按价格筛选时排前面。一台电脑平均利润两三百。可每次发货要买保价，又增加几十块成本。还经常有客户收到货后纠缠：为什么说好的硬盘100G，他那里显示只有80多G？为什么内存512M，显示只有475M？懂的人知道这都正常，但客户不懂，只能补偿几十上百块去安抚。这么一算，一单利润只剩100块左右。

这还不是最严重的。最怕的是退货——退回来的货，要么电脑被摔坏，要么干脆是个空包，里面电脑丢了，损失很大。再加上库存压力，拿货多单价低，可库存占比也大，很多时候货堆在手里卖不掉，全是成本。整体一算账，这个生意模型不成立，根本赚不到钱。干了半年多，我们又停了。

然后我回了上海，7月份到的，真正感受到什么叫“创业不成一场空”。身上只有几千块现金，租完房子只剩几百块当生活费，连件像样的衣服都不敢买。后来找同学借了几千块才挺过去。我那个朋友后来也回了上海，转型卖女鞋，做得一直不错，一年能赚几百万。

而我没再去开店卖货，去了朋友公司干半年多。2009年初，经另一个朋友介绍，我认识了返利网创始人Gary，加盟返利网一起创业，回到职场发展。

这三次小型创业，能总结的其实很多。最早做的淘宝店模式就很不错，完全可以规模化复制放大，而且很轻。比如搞店群——在淘宝开几百家运动鞋店、几百家女装店，赶上中国电商和淘宝的快速发展，一年赚几千万、上亿都有可能。后面天猫起来，注册个品牌搞天猫店也是个好路子。这些年很多赚大钱的人，都是做淘宝无货源店群和大卖家。而我却偏偏选去搞平台，那是九死一生的事。就这样错过了一波随淘宝壮大的机会，直到现在我都觉得那是最赚钱的机会之一。可惜当时认知太局限，虽然嗅觉灵敏、入局早，但根本没想到可以这么放大干，只是当副业玩。说到底，还是小农思维，没有认知。

卖笔记本电脑的经历，也让我这么多年一直对直接卖货有恐惧，不敢碰货，只做比较轻的流量型项目。其实有时候是品类选择的问题。最近认识一些朋友在抖音上卖货，没什么售后问题，毛利润还能做到50%以上。

## 三、创业干“返利邦”时期

经历三次小创业后，我停了创业的念头，老老实实在职场积累了三年的经验。那几年的事情，大家可以看我之前写的返利网上市背后的几个小故事。

2011年6月30日，是我在返利网的最后一天。7月1日，我搬到上海宝山顾村的海宝创业园区，开始了新项目——一个专注淘宝返利的网站，叫“返利邦”。

初心很简单：看好淘宝返利这个大市场。我在返利网那几年，主要做京东、凡客、唯品会、当当、亚马逊这些B2C的返利导购。而当时占据电商90%市场的淘宝没有开放数据接口，所以淘宝返利做不了。但我一直知道，一旦淘宝开放接口，那将是个巨大的市场，也一直在关注。

为了验证想法，我做了一次小试验：自己建了个网站，调用淘宝联盟相关频道，告诉用户通过这个网站去淘宝购物，成功后提交订单编号就能拿返利。本质上，返利全靠我人工操作。

冷启动靠的是百度贴吧发帖。我发了一个帖子，说淘宝购物居然还能拿返利，配了几张返利到账截图，简单介绍了网站。靠着这个帖子，我第一次发展了几百个种子用户。每个用户注册后，我都单独人肉发邮件；每笔返利到账，也人工发邮件通知，精心维护。后来还开了邀请好友奖励的功能。就这么踏踏实实干了两个多月，月佣金轻松破了5万。

模式验证后，我没急着融资，想再测试一段时间，看有没有低成本、规模化放大的可能和增长方法。

2011年一个周末的下午，我正在办公室加班。一个认识多年的朋友在QQ上问我：“老胡，你要不要出来创业？我给你介绍投资人。”两周后，我们在上海中山公园附近和那个投资人吃了饭。天使投资人信任我，一周后就签了一份两页纸的简单投资协议，投资款直接打进了我的个人银行卡。

说实话，当时出来创业还是很纠结的，因为返利网刚完成A轮千万美金融资，我的薪资和福利也都涨了不少。我纠结了两天，最终还是选择出来。当时想的是：就算创业失败，大不了回去上班，也许经过创业磨练后的我，能力会更强。

就这样，我带着投资人给的69万现金，加上自己投的5万块，一共74万启动资金，带着一个技术、一个客服，三个人开始了草根创业之路。

为什么把办公室设在宝山顾村那么偏远的地方？因为技术开发住那边。我为了照顾他，就在附近的创业园区租了个小办公室。办公室很小，只能坐四个人，房租也便宜，每月1200元。在那个小办公室里，我们干了3个月，之后换到了能坐8个人的办公室。当时的目标是一年后进城，至少搬到地铁站附近，方便以后的同事上下班。

我们用一周时间开发好新网站，把之前种子用户的信息导入，然后开始推广。一开始只是增强邀请好友功能，靠这个实现了前期的裂变增长。

后来经一个朋友介绍，我找到了微博草根大V合作推广。本来只是试试，没想到那天中午博主广告一发出来，流量太大，直接把服务器搞崩了，太吓人。等访问量降下来，我们看数据：一个注册用户成本才2毛钱；一周后看购买数据，一个产生购买的用户成本才2块钱，基本一周就能回本，太划算了。

这次推广直接刷新了我的三观——一个微博草根大V的能量都这么大。之后我调整投放策略，暂停所有其他付费推广渠道，集中精力做微博推广。但那时我们有个最大的技术问题一直解决不了：每次微博推广带来的高并发，服务器都扛不住，流量一冲，就崩了。我们的技术对高并发始终找不到解决方案，导致每次投放都不敢大力推。可以说，技术瓶颈直接影响着网站发展。

我们找到了低成本、规模化增长的方法，却被技术卡住，没法放开手脚。我陆陆续续找了好几个PHP技术人员，始终没找到特别合适的技术负责人，团队整体实力还是薄弱。之后一年里，也没能找到能扛起重任的技术负责人。

于是只能慢慢发展。这个项目初期一年内，只投入了15万，却获得了1000万+的年佣金收入。
