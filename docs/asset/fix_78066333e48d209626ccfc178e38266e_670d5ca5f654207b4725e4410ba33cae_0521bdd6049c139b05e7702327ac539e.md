# 2.1 工具怎么挑？ @小鹅

说到用 AI 写字，大家最先想到的工具就是无人不知、无人不晓的 ChatGPT。我猜在座的圈友对它应该都不陌生。不过今天还是要科普一下，让大家对这个工具有更全面的认识。理解工具原理，能提高我们后续写作的效率。

[PRE8]

它究竟是什么工具？

OpenAI 先把海量互联网语料灌给模型，让它学会模仿语言规律，你能在网上看到的信息，都可能成为学习材料。

当你向它提问时，它就像一个随问随答的资料员，可以回答它知道的一切。

ChatGPT 的主要功能

它的主要功能是理解和生成人类语言。

它可以在许多不同场景中应用，包括但不限于以下几种：

问答：你可以向 ChatGPT 提问，它会根据训练数据生成答案。比如问科学、历史、文化等主题，它会尽力给出准确答案。

文本生成：你可以让 ChatGPT 帮你写文章、故事、诗歌等。只要给出开头或主题，它就能生成相应文字。

对话：ChatGPT 可以模拟人类对话，因此可用于客服、教育、娱乐等领域，帮助人们进行模拟对话或角色扮演。

编程：ChatGPT 也能理解编程语言，你可以向它提问编程相关问题，或者让它帮你写代码。

学习：ChatGPT 可以作为学习工具，帮助人们学习新知识和技能。比如让它解释一个复杂概念，或帮你学习一门新语言。

以上只是 ChatGPT 能做的一些基本事情。它的应用场景非常广泛，只要涉及理解和生成人类语言的地方，都能用到 ChatGPT。

ChatGPT 核心原理

ChatGPT 并不具有人类的思维和逻辑，它无法真正知晓一篇文章中上下文的逻辑。

它是在自己“脑子”里的知识库中，通过一定算法猜测这个字后面更大概率会出现哪个字，这样一个字接一个字地生成一篇文章或一个回答给你。

ChatGPT 的核心原理是“下一个字更大概率出现”，它不具备真正意义上的上下文记忆。也就是说，你和它对话的历史聊天记录，它实际上并不真的理解，而是靠算法推算，所以这叫伪上下文记忆。

这个原理很重要，大家下场实践时会感受到。

# 2.2.2 提问的实用策略

# 2.2.2.1 说清楚，别留歧义

确保提问清晰明了，不含歧义。比如，人类说话时会有一些大家都知道的“行话”，但 AI 有时候并不知道，一定要清楚地告诉它。你让它猜的次数越少，越容易拿到想要的结果。

# 2.2.2.2 砍掉废话

多余的文字会让 GPT 混淆视听，不能清楚地 get 到你的核心问题。它和小孩一样，你说多了，它的注意力会跑偏。

需要注意的是，较长的输入文本和回答都可能影响 GPT 的响应时间和生成质量。为了获得更好的结果，保持问题简洁明了，并尽量避免过长的输入。

反例：有人把牛顿的生平、早年经历、教育背景、科学成就、对物理和数学的贡献、自然哲学观点、对现代物理的影响全塞进去，还要求尽可能详细。

正例：只问“牛顿简要生平、科学成就、对现代物理的影响”。

# 2.2.2.3 把需求写具体

在言简意赅的前提下，可以让指令更加具体，来更好地表达需求。

AI 学习到的知识非常多。如果你的问题很泛化，它就会从广泛的知识海洋中找适合大多数场景的答案。但如果问题更具体，AI 就会明确去找你要的那一颗具体的银色贝壳。

你让它猜的次数越少，越容易得到心里想要的结果。
