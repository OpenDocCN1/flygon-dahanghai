# 4.1.3 剧评素材不难找

写剧评有一个特别省心的地方：你几乎不用为“写什么”发愁。只要提前做好三步准备，素材就会自己冒出来。

第一，追剧时碰到让你心动、扎心或者眼前一亮的台词和桥段，马上截图，收进自己的素材库；第二，回头拆解剧集里的高光场面，看看它为什么好看、为什么能打动人；第三，把电视剧和原著放在一起对照，找出改编后的差异，连那些狗血处理也一并写透。

拿《知否》和《甄嬛传》这类热度和口碑都拿得出手的剧来说，可写的点实在不少。盛家祖母对明兰的殷切教诲、明兰对日子的体悟，都能变成一篇篇稿子的切入点。单是《知否》里淑兰和离这个高光段落，就足够撑起三篇甚至更多文章。

先给没看过的朋友补一下前情：淑兰出生在经商的盛家大房，带着丰厚嫁妆嫁给穷秀才孙志高。婚后，婆家一边花着她的嫁妆，一边百般刁难她。等到孙秀才打算把风尘女子领回家做妾，盛家大房彻底被激怒，和离的事才被摆上台面。

那么，这个段落能往哪三个方向写呢？往下看。

① 淑兰能顺利和离，真正靠的是什么？在古代男权社会里，孙秀才并没有犯下什么特别出格的事，淑兰想和离其实很难占住理。这里可以往深处挖：一是淑兰娘家愿意为她撑腰，不惜承担名声受损的代价，只求把她拉出苦海；二是从淑兰自身反思，女性若自己立不住会有什么后果——她带着丰厚嫁妆养着孙家，却被折磨得像老妪一般，说到底还是性子太软。

② 孙秀才为什么敢跟盛家叫板，根本原因在哪里？一方面，商贾出身的盛家，社会地位比读书人孙家低；另一方面，孙家一无所有，真撕破脸，没什么可失去的一方反倒更敢闹。再加上两家决裂不只是小家庭的事，更会演变成两个宗族的交恶，在宗族利益优先的环境里，盛家即便要和离，也不能不顾孙家宗族的态度。

③ 明兰帮淑兰和离后，祖母那番话暗示了她与小公爷的结局。这个方向能写的就更多了：齐衡和盛明兰私下有情，但两人注定走不到一处。先是家世悬殊，齐家是国公府门第，齐衡还是独子，身上压着母亲平宁郡主的期盼；盛家不过五品小官，明兰也只是庶女。再者，齐衡虽有意，却没有为这段感情奋力一争的胆量，不敢违抗平宁郡主。最后，平宁郡主瞧不上明兰，若真要为难她，办法多得很。

你看，一个高光场面就能拆出三篇乃至更多稿子。对爱追剧的人来说，可写素材几乎随手可捡。
