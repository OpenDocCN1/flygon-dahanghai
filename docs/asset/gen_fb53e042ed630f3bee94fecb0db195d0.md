# 2.1.2 新手怎么挑赛道？

新手选赛道，建议从“感兴趣”和“擅长”两个方向入手，能叠加更好：

1. 感兴趣：有热情才愿意日更，哪怕暂时没收益也能坚持。
2. 擅长的技能和工作经历：你愿意反复琢磨复盘，越复盘越精进。
3. 市场需要：看目前是供大于求还是供不应求，卷不卷可以自己感受，也可以多刷对标。
4. 是否愿意改变输出习惯：以前没有的习惯，现在愿不愿意培养。

四项各25分，给自己打分。

比如我选娱乐领域的剧评：感兴趣15分，还没到狂热，带娃写作也没太多时间追剧；技能经验15分，按知道、了解、熟练、精通四阶段评估，从10分提升到15分，知道娱乐领域能做，但还要深入了解，流程熟练后才算精通；市场需求20分以上，电视剧电影剧评仍是刚需，未饱和；输出习惯20分，这个习惯很重要，没有就要培养，像写作能力一样。合计80分，可以做。

0到100分：40分以下考虑换；40到60分看四项里哪项要克服；60分以上可以入手。分数越高，主观能动性越强。

1. 建对标账号库

2. 找对标账号

• 用关键词或话题在社交平台搜索，找到同领域热门文章和账号，也可通过其他渠道补充。
• 这样能积累更多素材来源，持续获得新灵感和信息。
• 账号库要常更新，保留最有价值的账号。

3. 对标账号要丰富

• A类：领域内粉丝多、互动率高。
• B类：短期内出过10w+爆文。
• C类：数据稳定，比如阅读量2w左右。
• D类：一直起不来的账号。
• A、B、C类常发受欢迎内容，可作灵感来源，帮助了解受众需求和趋势；D类要避开，别重蹈覆辙。
• 关注对标账号，及时看最新文章、发布时间、封面呈现和描述写法。

4. 刷对标

• 建库后要多读，了解趋势和内容受众性，让内容更有吸引力。
• 刷对标要定期做，持续掌握领域动态。

# 3.1.1 通用选题法：用“微信搜一搜”找爆款对标 @枫宇翔

新手最高效、最快出成绩的选题方法，就是找对标爆款文章。怎么找？最常用的是在微信搜一搜里，用领域关键词找要模仿的爆款文章。用过搜一搜后，微信算法会持续推荐相关文章，文章会越来越多，这是眼下最快的方法。

# 3.1.1.1 搜索词怎么定？

看到这里，应该已经看过2.1确定赛道和写作方向。

第一，确定第一个关键词。选好赛道后，比如三农、军事、情感、法律等，要凭经验和常识想赛道第一个关键词。写情感领域，我首先想到婆婆、婆媳，搜一下一定有爆款。之前也推荐过大厂裁员系列，关键词就是裁员、毕业、失业、降薪、减薪等。实在想不到，就把三农、情感等直接当关键词去微信搜一搜，也能找到第一篇爆款，只是费点时间；关键词越精准，搜索越快。

例如写这个问题回答时，我在微信搜一搜输入“裁员”两个字。

大家看，马上能检索到10万+爆款文章。找到第一个爆款，就能获取第一个对标账号。这一步别偷懒，这是从0到1必须经历的。

# 3.1.1.2 怎么挑对标爆文？

判断哪篇是对标爆款，看几个指标即可：

第一，搜一搜搜到文章后，首选10万+，其次七八万阅读量。

第二，发布时间在最近三个月内，越早越好。道理很朴素：爆过的内容还会爆，最近发布且爆了，说明有流量，你写大概率还会爆。

第三，看发布账号最近注册时间，最好也是最近三个月注册。有的账号注册久、粉丝多、原创多，高阅读可能是粉丝带起的；我们要的是低粉爆款，这些账号和我们同一层次，它爆，你也有很大机会爆。

# 3.1.1.3 爆文模板怎么拆？

很简单：找到爆款后通读一遍，确定核心意思，按开头、中间、结尾用自己的话写出来。

比如“职场辣评”号两篇文章：《地产已死，国企央企也逃不过房企大面积裁员，欠薪》《某大厂裁员还在继续，大晚上突然被毕业！》。通读后核心观点就是突然被裁员。模板是：①开头简单介绍这些企业；②深度分析为什么被认为不可能裁员的企业也裁员；③结尾总结并给建议。

通读时注意转折点，比如“但是”“为何、为什么”“不过”“然而”，这些通常表示作者开始转折，下面和上面内容有区别；把上下内容浓缩，就是爆文模板。其他领域也有表示递进、深化的词。这也是中国人说话写文章的习惯，要表达另一段内容，需要转折词，不然突兀，读起来难受。

特定领域可能有具体模板，但手册面向所有人，每个人领域不同，模板也不同；掌握这种思考方式，根据自己领域手动分析拆解爆款文章。对标账号和爆款文章已提供并做案例分析。如果还不理解，就先抄起来，写着写着自己会开悟。
