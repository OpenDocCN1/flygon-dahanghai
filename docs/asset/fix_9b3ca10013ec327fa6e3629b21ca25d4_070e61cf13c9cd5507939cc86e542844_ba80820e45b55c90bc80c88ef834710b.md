# 8.3 售前沟通&成交

客户到了私域，就可以开始聊需求了。

# 8.3.1沟通思路

# 📌

做AI写作这行，客服得是加强版写手。不懂后端交付的销售，算不上好销售；不会写、摸不透写作门道的人，客服也做不精。真正厉害的客服，往往是从写手堆里长出来的。

报价、谈单、成单，牵扯的变量一大堆：沟通、谈判、说服、销售、用户心理、预期管理、专业展示、情绪价值……

AI写作这个市场，没有统一价目表，品类全是非标品，而只有非标品才有溢价余地。最后一单成交多少钱，要看稿件类型、用途、字数、时间要求、同行竞争、客户预算、谈单话术等因素。

1. 客服第一目标是成交，但别为了成交乱承诺，奔着长期合作去。
2. 站客户角度想问题，拿出同理心，让客户感觉到你在替他考虑，用信任打底。
3. 用专业话术、成功案例、实力背景，把专业度亮出来，让客户信你。
4. 谈价的时候以价值为锚，让客户明白一味压价会拖累写作质量，别被客户带进讨价还价的节奏。

# 8.3.2客户沟通流程

# 8.3.2.1 接待客户

第一步：问候与自我介绍

话术示例：“宝子你好，我是xx方向的专业老师，方便说说你的写作需求吗？”

同时摸一摸客户底细、判断付费能力。可以问专业、学历、学校层级，也可以翻闲鱼IP、发品和成交记录、朋友圈。

第二步：了解客户需求

摸清学历、学校、专业、行业、公司、职业。

引导客户把需求说细：稿件类型、具体用途、谁来审核或汇报。

话术示例：“这份商业计划书是交作业、参赛，还是融资用？”、“这份教案是日常授课还是比赛使用？”

第三步：问题探询

问清楚字数、语言风格、交付节点。

引导客户补信息，比如要不要加数据图表、设计图，这样估算写作难度和工作量更准，报价也更稳，不容易踩坑。

话术示例：“这篇调研报告除了七千字以上，还需要问卷和数据分析吗？”

# 💡

P.S.如果看不懂客户需求，怎么办？

可以借AI先摸个大概，用自己的话捋一遍，再跟GPT聊。提示词这么写：“有个客户要写一篇初中英语教学中情景短剧作用的教师征文，6000字，请你扮演专业的教师征文写作老师，跟客户聊写作思路和架构，让他觉得你很专业、愿意信任你。”

也可以把自己放进客户的位置，去闲鱼、淘宝问同行。

问客户有没有参考样稿或对标范文，据此判断工作量；没有的话，去Meta搜同类文章，先粗估一下。

# 8.3.2.2 介绍服务与报价

报价与费用说明：

根据客户需求给阶梯价，分成“正常质量XXX”和“高质量XXX”，让客户看清不同档位的价格区间。

把收费逻辑讲明白，指出加急、内容复杂度、特殊要求等都会影响报价，让客户理解钱花在哪。

折扣与优惠信息：防失联+MM188166M（李李）长期更新

预算吃紧的客户，为了促单可以给5%~10%的小折扣，但别让太多，否则客户会觉得你利润空间大、还能再砍。

议价时强调价格和质量绑在一起，引导客户理解：不影响质量标准的前提下，可以适当减字数、少做一两个图表、限制修改次数，用这些方式把价格降下来。让客户感觉每次调价都有成本依据。

# 💡

AI写作定价公式

价格=工作量(基础工作量+复杂工作量+修改量)+质量要求+时间紧急程度

拿调研报告举例

基础工作量，就是字数要求。

复杂工作量，看领域冷不冷门、要不要特定专业知识、是否涉及数据、表格、设计图、代码、公式、仿真、建模等，这些对写手要求高。

修改量，看会不会反复改，或者动核心内容。

质量要求，看客户自己的目标和需要。

时间紧急程度，时间紧就加收急费。

根据客户信息和需求报价，按交付质量、写手资质、修改次数等维度做阶梯式报价，给客户几种选择；小单子直接一口价也没问题。

演讲稿谈单案例

1.需求沟通&收集：稿件类型、字数、用途、交付时间

2.报价：按质量要求、修改次数，给客户几套方案

# 8.4 售后问题解决方法

# 8.4.1 如何规避售后问题

一个专业的客服，能在售前就把售后隐患清干净。比如跟客户敲定需求和规则，要来评分标准、参考样例，搞清楚这份稿子是奔着获奖还是应付领导，把需求指标掰开揉碎分析，用各种售前动作提前把纠纷苗头掐掉。

售前做完，接下来就看交付质量。客服谈得再漂亮、价格再理想，写手不靠谱、稿子质量差，一样能把事情搞砸、把客户信任败光。

靠谱的写手，能靠一份对路的稿子让客户满意。市场上找人代写文案的客户，八成对质量要求不会太苛刻，把航海手册里的海盐大法（方法论）用上，已经能应付大部分需求了。

99%来找代写的客户，不是想白嫖，而是想要质量过得去、能达标的东西。我们扒了大量售后案例，原因就两类：

1.谈单的客服不专业

客户自己需求模糊，客服又挖不出、理不清真实需求，只能把残缺的、甚至被曲解的信息丢给写手。写手接到活儿不知道写成什么样才算对，结果交稿后被要求重写。半懂不懂的客户还是说不清想要什么效果，稿子改来改去，最后给你扣一顶“不专业、不靠谱、瞎写”的帽子。

2.写手的水平不达标

写手交的稿子AI味重、内容空、结构乱，多半是没吃透客户需求，或者缺相关经验和背景知识。客户拿到手只有一个念头：“不专业、不靠谱，还能不能信你？”改了几次还是有问题，旧坑没填又冒新坑。客户直接开喷：“退款吧，写的什么东西，骗子，改这么多次浪费我时间，没空跟你磨叽。”

我们拆了大量实战订单、反复优化后可以确定：95%的售后问题，靠售前就能解决。专业客服+靠谱高质量写手，基本能通吃。

当然，小白阶段还在练手，成长需要过程。前面教的沟通思路和技巧还没完全消化，难免有一小部分退款。没关系，技术不够硬的时候，态度可以顶上——记住【市场、客户是最好的老师】。认真改、负责到底，多查资料、多改几遍；实在满足不了，再心平气和地退款，别让客户跑到评论区留差评，影响后面新客户对你的信任。

小白刚起步，吃亏是福。有搞不定的单子和客户很正常，这些都是最值钱的成长经验。

要是没cover住客户，又实在不想退款，可以看看下面的退款纠纷话术，说不定能帮到还在小白阶段的宝子。

能不惊动闲鱼官方就别惊动。这一单的钱真没那么重要，时间才金贵，把钱退给客户。你跟客户撕逼battle的聊天记录，99%的客户会截取对自己有利的部分去给差评，而评论区的差评是永久挂着的。你再占理，有些客户看到差评和互撕记录，心里也会犯嘀咕，不想冒这个险找你写。理智的人不多，看见你撕逼，很多人下意识会想：找他写，没准哪天也跟我撕。

这年头节奏快，差评多的店铺，客户可能连点开看原因的兴趣都没有，店铺那么多，手指一划就走了。

非100%好评的店铺，在闲鱼平台的权重也会掉，拿不到100%好评标签，商品推流也跟着受影响。

# 九、常见问题QA@小虎牙@陈bu懂

# 9.1 闲鱼基础答疑

提问1：手机实名账号数量上限，是否可以使用朋友或家人注册认证新账号后，到我的手机正常运营?

答1：可以，但平台可能半个月到一个月要求一次人脸识别。

提问2：注册支付宝和闲鱼账号需要在新手机注册吗

答2：不需要，但运营时要守一卡一号一机，即一张卡、一个号、一台机。

提问3：闲鱼哪里可以解绑淘宝？

答3：设置→账号与安全→授权管理

提问4：鱼小铺的领域选择是否在首页推荐权重更高，推荐开吗？

答4：影响不大。新手前期别急着开鱼小铺，等账号询单起来了再开才有效果。

提问5：三个账号头像名字相关信息是否要不一致

答5：头像、姓名这些信息要错开，防同行恶意举报。但店铺商品风格可以统一，统一风格能显出专业性。

提问6：手机同时开启流量和wifi，闲鱼设置使用流量，是否可行，闲鱼平台是检测设备ip、流量ip还是wifi的ip？

答6：风控规则一直在变，设备ip和流量ip都会查。老老实实一卡一号一机就没事。

提问7：背景图可以用同行的不？

答7：可以，但直接搬要注意水印，去小红书搬也一样。另外看清图上有没有违禁词，记得避开。

提问8：我三个支付宝号都在同一个手机登录过，是否有问题？

答8：没问题，后面正常分开运营就行。

提问9：背景图和头像有相关写作敏感词可以吗？

答9：不行，有违规概率。图片不用放敏感词，文字和seo搜索才用得上。背景图和头像最好能体现专业度。

提问10：支付宝绑同一张银行卡会影响流量吗？

答10：不会。

提问11：创建简历开启副业模块需要打开吗？

答11：不需要。

提问12：不同的手机用同一个苹果id下载闲鱼app会不会有影响呢？

答12：不会，IP和设备都是各自独立的。

提问13：手机上设置双开闲鱼登录两个闲鱼账号是否有影响？

答13：会，两个号同IP会影响流量。

提问14：可以在其他人的商品下面留言截留吗？

答14：别频繁在别人商品下留言，人家会删你留言还举报你。在留言里留微信，同样算违规。

答10：对，这个看养号。

提问11：短时间内关注评论点赞过多，被系统提示操作频繁，20多分钟以后再操作，这个会影响后面流量吗？

答11：账号权重不够、评论截流又多，就触发风控了。慢慢养号、后续正常交易就好。

提问12：初期上品曝光都很低，是不是号没有养好？

答12：正常。刚发的品要过审核，观察一两天。后面还低，就继续上品养号。

提问13：账号在养号阶段需要关闭个性化推荐吗？

答13：要。关掉个性化推荐，养个两三天，直到主页开始出现写作相关的商品。

提问14：发品阶段，日常运营包括哪些。

答14：日常任务和小游戏差不多，保持养号动作。养号不光是保活跃，更重要的是发现异常值、找到更好的对标素材。

提问15：个性化推荐什么时候开，什么时候关？

答15：刚养号的时候关掉。后面如果关了养好几天都刷不到写作商品，再打开。

# 9.3 商品发布答疑

提问1：每天都需要上新品吗？除了被提示的那种违规，还有什么因素会导致账号流量突然哑火。

答1：前期一天发三个品，后面一天一个就够。闲鱼流量池起起落落，标准动作坚持下去，总会有爆的一天。

提问2：类目的需求有明显的季节性吗，我们是不是对应时间点上品。

答2：有季节性。卡着学生的时间点上品，效果会更好。
