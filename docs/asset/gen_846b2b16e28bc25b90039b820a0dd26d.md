# 6.4.1 抖音发布全攻略：预热、话题与活跃 @鲸鱼 @seven @某人周

别把抖音只当成一个“上传视频”的入口。每条内容发出去之前，最好提前5—15分钟打开抖音，先进入同行内容里逛一逛：给视频点点赞，在评论区留下互动，同时观察对方怎么引导用户、评论区有哪些高质量表达值得借鉴。

接着打开热点宝，在“热点宝-视频”里搜推文，重点看最近三天跑出来的爆款文章，判断它是否适合放进自己的选文库；再翻一翻评论区，把互动率高的热门评论记下来，后面做互动时可以借鉴。

上传前再核对一遍：视频是否完整、有没有违禁词、画面是否符合要求。作品上传后记得加话题，话题分常用、垂直两类，按所推账号类型来选即可。

常用话题：#小说、#番茄小说、#小说推荐、#小说推文、#文荒推荐等；
垂直话题：#悬疑小说、#言情小说、#都市爽文、#言情、#女频等。

另外，关闭作品同步，并在高级设置里关掉“保存本地”“允许下载”。发布完成后别马上退出抖音，等上传结束，自己先点赞、评论、转发，再让账号活跃15分钟，把活跃度维持住。

2）视频爆发的正常周期

先建立一个认知：一条视频从开始到上热门、再到小爆，花15天到30天都属于正常范围，不用过度焦虑。建议保持每天更新，让账号热度不断档。

3）作品合集

单条作品播放量达到15W后，就可以创建合集。同类型合集能把用户留在账号里更久；如果是分集作品，用户即使刷到其中一条，也能被引导去看后续，从而抬高整体播放量。

4）作品违规相关问题

作品审核没通过时，可以按抖音内容公约准备理由进行申诉。如果申诉没有成功，就等作品彻底没流量后，把它隐藏起来。
