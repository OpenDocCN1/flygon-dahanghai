# 7.4.2 达人怎么找？先分清类型再下手

做达人合作，别一上来就到处要名单。更有效的顺序是：先明确这次投放要解决什么问题，再反推需要哪几类创作者。不同平台、不同内容风格、不同粉丝量级的达人，触达的人群和带来的效果往往差别很大。

第一步，把需求拆成“类型标签”。比如按平台分、按内容领域分、按粉丝规模分、按合作形式分；也可以按带货型、种草型、测评型、剧情型等角色来划分。标签越清楚，后续搜索和筛选越不容易跑偏。

第二步，从平台内部找。用行业词、产品词、场景词、痛点词组合搜索，别只搜一个大词；同时看话题页、热榜、相关推荐和评论区，常能顺藤摸瓜发现同类型但还没被大量合作的达人。

第三步，借竞品和同行做参照。翻看同类品牌近期合作过谁、哪些内容互动表现好，把候选账号记下来；再通过平台榜单、数据工具和行业社群补充名单。人工推荐也很重要，尤其是垂直领域的中小达人，往往藏在圈子里。

第四步，边看数据边验人。粉丝量只是门槛，更要多看内容调性、近期更新频率、互动质量、受众匹配度和历史合作口碑。先小规模测试，再逐步放量，比一次性押注更稳。

最后，把接触过的达人按类型、平台、报价、效果和合作状态沉淀成自己的达人库。找不同类型达人的关键，不是广撒网，而是先分类、再搜索、后验证，让每一次合作都对应明确的目标。
