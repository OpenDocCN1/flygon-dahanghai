GSC 能反映站点在搜索结果中的表现——排名、点击、曝光，并把技术隐患摆到台面上，比如手机端体验故障、蜘蛛抓取异常。

# 1.2 GA：读懂访客足迹

GA（Google Analytics）主要回答两个问题：访客从哪来、有多少；进站后做了什么。工具入口：https://marketingplatform.google.com/about/analytics/ 。借 GA 或类似分析工具，盯住日访问量、停留时间、跳出率等指标，筛出最受欢迎的页面。若某类目点击特别集中，就围绕它继续加料；碰到跳出率偏高的页面，则回头查加载速度与内容吸引力。

更新节奏同样关键。玩家口味变得快，站点长期不添新东西，回访就很难维持。排一张周更或月更表：持续上架新游戏，给热门游戏做延伸页，让全站保持新鲜与黏性。

1. 申请流程拆解 @ 哥飞

# 第一步：注册并进入 AdSense

AdSense 账号绑定 Gmail，先备好邮箱。打开以下两个网址都能到官网，点右上角 Sign in 或 Get started：

https://adsense.com/

https://www.google.com/adsense/

随后在新界面添加一个待审核站点。若还没网站，别急着注册 AdSense，先把站做出来。[PRE29]

# 第二步：接入站点并验明归属

https://www.google.com/adsense/ 是 AdSense 申请入口。

⚠️账号资料要填全，否则所有站点都过不了审。我在这上面栽过跟头，好几个号、几个站一直卡在审核中没动静。

送审站点要有一定流量；流量偏小还会附带条件，例如域名注册满 3 个月、站内有一定内容。

还没站的话，建议先搭 WordPress，写原创博客，不必多，一天一到两篇，坚持半月到一月再申请，通过率会高不少。[PRE30]

站点填顶级域名，不带 https，也不加路径，别勾“我目前还没有网站”。想让 AdSense 作用更大，选第一项。国家地区如实选；人在中国就选中国，因为后续要验真实地址才能收款。若不在中国，选所在地即可。按下“开始使用 AdSense”后，出现如下页面。[PRE31]

接着填真实资料，并取广告代码部署到站点，然后进入审核。个人信息里账号类型选个人，姓名地址按真实情况用中文填，不必拼音或英文翻译，提交即可。[PRE32]

# 第三步：部署广告代码

去拿广告代码，复制后放进网站。审核期间广告不会真展示，设置项保持默认就好，不必勾太复杂。[PRE33]

之后还有一步：关联网站，按“我们开始吧”。[PRE34]

新页面会再显示一次广告代码。若上一步已复制并埋好，这里不用重复复制。但注意两种验证方式不是二选一；按哥飞经验，两边都要做：广告代码进站，同时根目录放 ads.txt 文件。两项齐了，点“我已放置代码”，再点“下一页”，在新页面按“申请审核”。[PRE35]

首次审核耗时较长。通常蜘蛛先查广告代码与 ads.txt，再统计一段时间流量，还会抓页面看内容量，之后才转人工。人工先看数据；若流量少、内容薄，大概率打回，让你补内容或等流量上来。网上常说域名要满 3 个月才能申请 AdSense，其实主要针对内容少、流量小的情况。账号与站点都过审后，广告开始展示，后台也能看到数据报告。[PRE36]
