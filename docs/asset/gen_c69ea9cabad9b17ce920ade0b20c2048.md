# 选修篇：从独立 Agent 迈向协作团队与商业化服务

## 关卡 7：看清上下游，决定要不要连接

### 00. 本关任务概览

🎯任务目标：以关卡 6 已经验收通过的 Agent 为起点，找出它的上游和下游，理清各个环节分别由谁负责，并判断当下是否有一段关系值得优先连接。

🗒️任务描述

• 明确当前 Agent 的输入入口、处理过程和最终交付物。
• 向前追踪：输入从哪里产生，又是如何进入当前 Agent 的。
• 向后追踪：谁将继续使用输出，还需要完成哪些环节。
• 分辨每个环节由谁执行：人 / Agent / 工具 / 固定流程 / 业务系统。
• 判断环节之间的关系：独立运行、资源共享、前后交接，还是需要先判断再分流。
• 若存在合适的关系，只挑选一段进入关卡 8；若暂时没有，就说明“本轮暂不连接”的缘由。

💡新手提醒

从本关开始进入选修篇，这里是进阶学习内容，不再设置必须提交的作业。你只需对照任务目标和任务描述，跟着步骤完成练习。

这个关卡的重点不在于你连接了多少 Agent，而在于判断本身是否得当。

若业务中暂时没有稳定的交接点，直接写“本轮暂不连接”即可。不必为了交差而硬造新的 Agent 或交接关系，默认案例也照样能带你走完关卡 8。

[PRE30]

### 01. 本关核心要点

前六关帮你跑通了一个 Agent 的独立工作闭环。

它已经搞清楚：

• 自己的职责边界；
• 输入来自哪里；
• 执行流程是什么；
• 可用工具包括哪些；
• 最终要交出什么；
• 何种情况下必须中断并求助人工。

但在实际工作里，一个 Agent 通常只负责整条链路中的一段。

它的输入是谁给的？做完之后成果由谁接管？前后还有哪些参与者？

关卡 7 的任务，就是把这个 Agent 摆回完整的工作全局，看清它的来源与去向。

不妨先用下面这条线索辅助理解：

• **上游**：为当前 Agent 提供输入的工作环节；
• **下游**：继续使用当前 Agent 结果的工作环节。
