# Claude Code 与 Codex 怎么选？环境安装全流程

Codex 对 ChatGPT 会员开放，直接就能用。它的用量比 Claude Code 更宽裕，每月 20 美元的 Plus 会员基本够用；再加上 gpt-5-hign 在排查和修复 bug 方面表现非常突出。它的短板主要在速度：一个任务经常要跑半小时甚至更久，工具成熟度也比 Claude Code 稍弱一些。

整体看，Claude Code 仍是当下最强的 AI 命令行编程工具。它的工具成熟度最高，使用体验顺畅，不论是 subagent、自定义 slash、hook，还是各类工具和细节能力，都比目前的 Codex 更有优势。不过近段时间 Claude Code 经常出现能力下滑，高峰时段会切到低成本模型；官方也多次确认过模型问题，但从社区反馈和实际体感来看，跟早先的 CC 相比还是差了一截。

**选择建议**：预算够就两个都上；更看重质量选 Codex，更看重速度和平衡选 Claude Code。可以让 Claude Code 从 0 到 1 写代码，再用 Codex 做审查、解决 bug，通过这种互补方式把两者的优势尽量放大。

## 02. 准备开发环境并安装 Claude Code/Codex

写代码之前，先把开发工具、Node.js 基础环境，以及 Claude Code（或 OpenAI Codex）的配置准备好。

### 1. 开发环境介绍

#### 1.1 VS Code 是什么

VS Code 是微软在 2015 年发布的免费开源、跨平台现代代码编辑器。Windows 和 macOS 都能用，不管换哪台电脑，开发体验都保持一致。

它最大的特点是轻量但能力强。主流编程语言基本都能覆盖，包括 TypeScript、Python、Java 等数十种语言；安装包通常只有几十兆，启动速度很快，功能却不输专业级 IDE。尤其值得一提的是扩展生态，可以根据需要安装各种扩展。这次用到的 Claude Code 和 Codex 也都有对应的 VS Code 插件，能帮助我们快速上手。

VS Code 是目前最受欢迎的开发工具。像大家熟悉的 Cursor、Trae 等 AI IDE，也都是基于 VS Code 深度定制出来的。

#### 1.2 Node.js 是什么

先补一个背景：JavaScript 最早只服务于浏览器，代码只能在网页里运行。Node.js 改变了这一点，让 JavaScript 能脱离浏览器，直接在服务器上执行。

Node.js 是一个基于 Chrome V8 引擎的 JavaScript 运行时环境。简单说，它就是一个可以在自己电脑上执行 JavaScript 代码的平台。

那为什么需要 Node.js？

这次学习中，Node.js 承担着多个关键角色。

首先，它是运行 Next.js 项目的必需环境。Next.js 本身就是基于 Node.js 构建的 React 框架，没有 Node.js，项目无法启动。

另外，Node.js 自带的包管理工具（npm 或 yarn）是安装和管理项目依赖的核心工具。几乎所有第三方库、框架、开发工具都通过它来安装和更新，比如这次用到的 Claude Code 和 Codex。可以说，Node.js 是整个前端开发工具链的基石。

**Node.js 的核心优势**

Node.js 采用事件驱动、非阻塞 I/O 模型，特别适合处理高并发场景。学习阶段可能感受不深，但这种特性让它在真实生产环境中能够高效处理大量用户请求。Node.js 还有一个优势是生态系统繁荣。npm 是世界上最大的软件注册表，拥有超过两百万个开源包。这意味着几乎任何功能需求都能找到现成方案，大大提高开发效率。

VS Code 和 Node.js 构成了开发环境的两大支柱。VS Code 是我们写代码的地方，提供舒适高效的编辑体验；Node.js 则是代码运行的引擎，提供执行环境和工具支持。掌握这两个工具，就为后续学习打下了坚实基础。下面的章节会详细介绍如何安装和配置这些工具，让开发环境真正运转起来。

```bash
node -v
npm -v
```
