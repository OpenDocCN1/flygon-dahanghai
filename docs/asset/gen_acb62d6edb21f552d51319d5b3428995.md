### 01. 本期航程总览

1. 这个项目到底在做什么

过去，社区里的很多人靠写精华帖来分享项目经验、踩过的坑和做事的方法论。精华帖解决的是“让别人看懂你是怎么做的”。

但在 AI 时代，更高级的能力是：不仅让人看懂，还要让 AI 能执行、让别人能调用、让经验能复用。

这正是 AI Skill 的价值所在。

有些人用 AI，还停留在一次次的对话里：今天让 AI 写周报，明天让 AI 写销售话术，后天让 AI 做复盘。每次都要重新交代背景、标准、流程和注意事项。同样的经验反复讲，同样的 SOP 反复输入，看似在用 AI，实际上并没有把自己的经验沉淀下来。

Skill 要做的，就是把你做业务的经验、做项目的方法和工作的 SOP，提炼成一个可复制、可调用、可共享的 AI 能力包。

举个例子，一个做小红书获客的人，可以把选题、封面、标题、正文、挂品和发布检查流程，全都打包成一个 Skill；

一个销售，可以把客户判断、异议处理和成交话术封装成 Skill；

一个运营，可以把活动复盘、数据分析和下一轮优化建议封装成 Skill。

以后无论你自己还是别人需要做同类任务时，不用再从零开始解释，直接调用 Skill，就能按照这套经验完成输出。

也有一部分人已经有做 Skill 的意识，想做出一个 Skill，却不知道从哪入手、做什么内容、怎么判断效果好不好。

所以本期航程会带着你从“先用起来”开始，先体验几个好用的 Skill，再跟着案例一步步搭出你的第一个 Skill。随着案例逐渐升级，你会慢慢看懂 Skill 的结构和用法，最后做出一个能解决自己真实问题的 Skill。

航程结束时，你带走的不仅是一个 Skill 文件，更是一种把经验产品化的能力：把“我会做”变成“AI 能按我的方法做”“别人也能调用我的方法做”。

如果你还有余力，可以继续优化调用说明、测试更多样例、补充模板和示例文件，参加 Skill 黑客松，把它打磨成一个能被别人看懂、愿意调用、甚至未来有机会出售的 Skill 作品。

### 01. 本关重点

你可能收藏过一堆链接，或者装了一堆 Skill，然后觉得“我的 AI 变强了”。但装完以后，不知道哪个适合自己，不知道怎么触发，也不知道到底有没有生效。

Skill 一多，很容易变成另一个收藏夹。

真正拉开差距的不是装了多少 skills，而是能不能把几个核心 Skills 组合成自己的工作流……

别贪多，把 3-5 个用熟，比浅尝 50 个更有价值。

这一关看的不是数量，而是体验，是带你亲手把一条 Skill 工作流完整跑通。

当你真正跑过一遍，自然会知道每个 Skill 是干什么的、为什么要这么组合、以后怎么迁移到自己的工作里。

我们准备给你体验的 3 个 Skill，并不是随手挑的，它们刚好能串成一条流程：

### 02. 安装这 3 个 Skill

1. 为什么先装这 3 个

你可能已经刷到过很多“十大必装 Skill”“50 个 Skills 跑赢 90% 的人”之类的帖子。

但这一关，我们只准备了 3 个 Skill。

1.1 别急着跟着推荐帖装

网上关于 Skill 的笔记和帖子很多，动不动就几千几万赞。

下面是其中一篇，5886 赞、8975 收藏（用户信息已打码）：

[PRE12]

看着挺专业：彩色编号、排名、每个都配了一句功能说明。

但我们把榜单里的十个 Skill 都去核实了一遍，结果发现：7 个完全找不到，剩下 3 个也只有零散来源，跟榜单描述对不上，很可能是 AI 生成的，也可能是后来有人照着名字创建的。

这就是让 AI 生成一份“十大高级技能榜”会出现的东西。

其实，就算这 10 个都是真的，“必装”这两个字也站不住脚。

Skill 是要结合人和具体场景来用的。

做电商、写代码、做运营，需求完全不同，需要的 Skill 也不一样，根本不存在“所有人都该装”的十个 Skill，就像不存在“所有人都该买”的十件衣服一样。

这一关让你装这 3 个，不是因为它们“最好用”，而是因为它们刚好能组成一条完整的工作流。先把这条流程跑通，比装几十个 Skill 重要得多。

1.2 怎么判断一个 Skill 值不值得装

以后在网上看到别人推荐，花 30 秒走完这五步，能省下大量时间。

你也可以把这张表直接截图**给 AI**，让它帮你判断这个 Skill 值不值得装

| 第几步 | 做什么 | 不合格的信号 |

| --- | --- | --- |

| 1 | 搜索时**加上** SKILL.md，在 GitHub 搜 技能名 filename:SKILL.md | 完全搜不到 |

| 2 | 点进去看描述，跟推荐里说的是不是同一个东西 | 名字一样但干的是别的事 |

| 3 | 看 star 数和最近提交时间 | 一年没更新了 |

| 4 | 看有没有 License | 自己用没关系；要拿来赚钱或再分发，就得仔细看 |

| 5 | 打开 README 读第一行 | 写着 deprecated（已弃用）或 archived（已归档） |

1.3 为什么是这 3 个？

不同的 AI 编程工具，背后接的模型不一样，能力也参差不齐。

这 3 个 Skill 最适合第一次体验。

它们满足这几个条件：

• **装完就能用。**不需要接生图 API、绑定账号或充值。

• **几乎所有 AI 编程工具都能跑。**不依赖生图、读图等特殊能力，只要模型能生成文本就行。

• **环境要求低。**不需要装一堆依赖，大多数人直接就能开始。（Windows 用户装其中一个 Skill 前，需要先装一次 Python。不用担心，交给 AI 工具，它会帮你装好）

• **中文场景可用。**不只是把英文 Skill 翻译过来，而是真的能在中文环境里跑通。

市面上有不少热门 Skill，有的依赖复杂，有的配置繁琐，有的看起来很火，实际并不稳定。

我们已经帮你把真正能跑通的 3 个 Skill 筛出来了。
