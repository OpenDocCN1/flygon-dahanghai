# 5.4.1 爆款节奏法则

一条视频想跑出爆款，底层就三句话：前五秒必须抓人，中段只留高能，收尾要突然停住。不是把故事讲完整，而是把观众的注意力一路牵到最后一刻。

开头：黄金五秒就是生死线。把最反常、最出乎意料、最有话题点、最能勾起疑问的内容顶到最前面。这几秒里可以顺手交代主角身份、所处场景和故事缘起，同时把核心矛盾摆出来。

中段：只留有碰撞的戏份，反转、对抗、争执都可以，让人物不断撞上难题。到了高潮处，冲突要顶到最紧，往往也是故事转向的节点。中间情绪要么让人痛快，要么让人揪心，起伏要密；配角的支线和拖沓情节能删就删。

结尾：不要把话说完。停在观众最想知道“然后呢”的位置，把他们引到小程序付费解锁全剧。女频短剧里，男主得知女主受伤后会不会悔恨，可以吊着，但悔恨画面先不播。男频短剧里，炮灰来挑衅，观众已经等着男主反击打脸，偏偏不把反击剪出来，引导大家去看正版短剧，看男主如何花式碾压对手，爽感自然就来了。或者某个情节让观众迫切想知道后续，就把那一步放在结尾，后续按下不表。

一次压抑配一次反转，就构成一个情绪循环：先把观众情绪压下去，再在反转将出未出时收住，引他们追后续。这里的“虐”只是代称，并不专指虐剧；任何类型的剧，剪辑时都能套这个循环。

顺着这个思路，常见的爆款剧情可以归为三类。

男频方向：男主藏锋扮猪吃虎，随后反转打脸、复仇，再以悬念收尾；或者穿越设定加YY，把爽点密集堆起来，末尾留钩子。

女频方向：女主先被狠狠虐，甚至三观冲击很强。比如开场就是暴力或暧昧的强刺激，接着男女主虐恋、反派搅局，最后留悬念；也可以是真相揭开型，女主被女配冒名顶替，女配从猖狂到崩溃，但结尾仍扣住一点悬念。

真正剪视频时，还能把主线拆得更细。以“女主被虐”为例，可以分成：男主正面伤害女主，两人直接对撞；女二设局陷害，矛盾升级；婆媳冲突；借孩子博取同情，等等。每条线都能独立成片，也能几条线交织推进，关键是衔接过渡要顺。
