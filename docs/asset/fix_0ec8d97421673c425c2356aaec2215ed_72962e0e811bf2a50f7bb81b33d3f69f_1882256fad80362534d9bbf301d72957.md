# 1.1 机器替手：智能流程到底在做什么？ @钱塘江鲤

说白了，自动化就是让程序接手重复动作，人退到判断、创意和决策的位置。再叠加 AI，团队就像多了一个随时在线的虚拟帮手，业务杠杆会被拉长。

常见方案可以分成五类：

- 第一类，低代码集成平台：Zapier、n8n、Make
- 第二类，传统 RPA：影刀、八爪鱼
- 第三类，在线 AI 流程编排：Coze、Dify、fastgpt
- 第四类，用代码或脚本搭流程：playwright、puppeteer、pygui
- 第五类，通用自主智能体（Agent）

拿选题场景举例：以某个关键词或竞品账号为起点，让程序去小红书、抖音扫一圈，把高互动素材挑出来，转成文字存进飞书表格；飞书 AI 负责配图；成品再分发到小红书、飞书、抖音公众号等位置。人只做最后质检。链路自动推进，试错成本低，获客回报却可能很高。

下面把工具全貌扫一遍。

**类型一：低代码集成平台**

[PRE1]

Zapier、Make、n8n 这一类，思路是“某件事发生，就接着做另一件事”，于是两个原本独立的软件被接上了。比如你在 Notion 存下一篇笔记，Twitter 那边就能自动同步一条。优势是门槛低、很少碰代码，个人或小团队做跨平台小联动很顺手；短板是海外产品对国内服务覆盖不全，业务一复杂，模板不一定扛得住。选不选，还是回到场景。

**类型二：传统 RPA**

[PRE2]

影刀、八爪鱼走的是另一条路：把操作过程做成可视化拖拽，再让本机程序接管键鼠、模仿真人点击输入。半天左右能入门。麻烦在于部分环节不够稳，想定制调度不轻松，接入现有办公系统也要花心思。综合看，属于比较折中的选择。

**类型三：AI 流程平台**

[PRE3]

这类平台靠在线拖拽，把几个处理环节拼起来。丢进链接或文章，它能输出不同口吻的文本，再交给下一步继续加工。内容生产场景很顺手；可一旦要深度定制，成本就上来了，复杂分支、多流程协同和并发稳定性都偏弱，所以更适合轻量入门。

**类型四：AI 编程**

用 Cursor 这类 AI IDE 写脚本，把自动化做成脚本化或产品化能力。它的可塑性很强，复杂链路可以按需求拼，比如同时采集多个平台、判断趋势、生成内容再分发。代价是需要编程底子，新手会吃力；好处是能支撑大规模并行，短时间内高强度跑任务。

**类型五：通用自主 Agent（以 manus 为例）**

在讲师看来，终点可能是 manus 这样的通用自主智能体：用户只提目标，它自行拆解、调用工具、交付结果。比如让它整理一份 RPA 调研 PPT，它很快能给出成品，不必事先编排，还会跨平台找信息。目前可控性和成熟度还欠火候，但随着模型和产品迭代，这些问题有机会被解决。

五类方案各有长处，按需求取用。

# 1.2 商业视角：AI 自动化怎么变现 @龙菲

前面那节已经铺过概念和分类。这里，龙菲老师从“怎么变现”切入，结合两年多商业营销增长自动化的实操，谈谈怎样把低代码平台和工作流软件拼成一套能接商业需求的本事，顺便打开大家的认知边界。

欢迎登上这趟零代码自动化航海。这个新领域值得花时间，掌握它，职业机会和成长空间都会多出一些可能。

最近半年，国内同行才开始把注意力放到 AI 营销自动化上，而且不少人只盯 Coze 国内版。相比之下，Make、Zapier、n8n 这类低代码平台，以及 Dify、FastGPT、LobeChat 等工作流工具，在国内的讨论量和用户盘子都明显小于海外。

讲师最早从 Make、Zapier 入手，后来陆续试了不少平台。每家都有长板和短板，他算是陪着这个领域一步步变化过来的。

所以他的建议很直接：学 AI 别只靠兴趣，要结合自己的情况选方向。不然很容易变成“什么都摸一点”——这个试两天，那个搞两下，兜兜转转很久，离赚钱还是很远。

学习路径要能接到变现上，要明白一门有商业价值的技能有多重要。

和老板们打交道多了，讲师发现：企业并不缺花哨流程，缺的是能省钱、提效、真正解决问题的工具。比如：带来客户；让客服少背压力；让订单、发票处理不再靠人盯。

所谓商业营销自动化，说到底就是替企业和自媒体人接手那些重复、琐碎、产出低的事。

所以选对方向，掌握有商业价值的工具技能，往往能事半功倍。

国外有个产品叫 Glean，做企业内部资料管理，估值已经到 46 亿美金。功能听起来不复杂：把各部门资料、各类 SaaS 系统、ERP 数据汇到一起，员工用自然语言就能和企业知识库对话。

效果呢？以前找老板要一份客户报价单，翻一两个小时很常见，隐性浪费很大；现在问一句就能定位，所以有人叫它“企业内部的 Google”。

它解决的是很朴素的企业需求，客户一旦用上就难离开，粘性很强。

这个例子想说明：得先弄懂自动化到底在解决什么。能接住真实客户需求，才值得学。不是拍个噱头视频、发几张图文就算在做自动化——同质化内容很快会被平台压流量。商业目标要清楚。

现在有 AI 帮忙，怎么把它真正用到工作里？讲师在这条路上踩过坑，也攒下一些实操经验，这次航海会拿出来分享。

有句老话：工具顺手，事才好办。人类能走到今天，善用工具是很关键的一环。可面对层出不穷的 AI 技术和快速迭代的 LLM 平台，选择困难几乎是必然：这么多工具，到底学哪个？

讲师的态度是：没有万能平台，只有适合你当前需求的平台。

所以第一步不是急着上手，而是先建立一张“商业化地图”：当前商业自动化发展到哪，各工具能做什么、不能做什么。看清这些，选择才不会偏。

接下来的内容不堆名词，而是从实用角度，用功能对比、真实体验和具体场景来分析。

先看大模型应用生态。n8n 和 Make 都属于流程驱动的 LLM 平台；另外还有 FastGPT、ragflow、Dify、Coze 等玩家。

n8n：强在通用流程编排，近年也把大模型节点塞进复杂业务链路。

Coze（扣子）：字节系产品，用低代码/无代码方式搭对话式 Agent，主打快建快发。新手练手可以；但模型不能自选，高级用户会被平台模型限制；知识库只给 6000 token 的额度，长文或大数据场景会明显吃紧。

FastGPT：开源 Agent 搭建平台，重心在问答型知识库，涵盖数据处理、模型调用、可视化编排。

Dify：开源 LLM 应用开发底座，把 BaaS 与 LLMOps 揉在一起，提供 Agent 流程、RAG Pipeline 等从开发到运营的打包式能力。

RAGFlow：开源 RAG 引擎，靠深文档解析吃饭，擅长从复杂格式里抽知识、做高质量问答。

Make：在线流程工具，需要网络条件，且是付费产品；接了 4000 多个海外工具 API，节点覆盖 Canvas、YouTube、TikTok 等，能快速搭流程，把内容发到短视频平台。优点是节点多、操作顺手、限制少、上下文 token 宽松；免费版每月 1000 次执行，重度用户可能不够。讲师现在主要拿它做商业营销自动化。

注意：Coze 现在不是免费午餐，整体花费不算低。

落到企业场景，可以这样选：

- 想做跨境业务的多语种客服系统，Dify 更对路，能定制、可私有化；
- 要把现有 ERP 或 SaaS 与数据库做同步和告警，优先 n8n；
- 要做轻量内部知识库，比如客服或内训，FastGPT 部署快，但大体积知识库不建议上它；
- 海外营销推广可以用 Make 和 Zapier 定时产内容、自动发布，国内不少平台同样能接。

影刀、八爪鱼、UIBOT 这类 RPA 也能跑流程，只是第三方 API 调用有限。

Coze 对新手很友好，能快速做出成果；但讲师不认为它能扛商业需求，原因放在后面讲。

[PRE6]

别把学习卡在入门层。要有点前瞻性，要学就学未来用得上、天花板更高的技能。

Coze 作为入门工具是有价值的，尤其适合新手快速上手。但想在商业应用里走远，就得看清各工具的限制与适用边界。

在讲师看来，Coze 现在更适合做偏玩具性质的小流程，不太适合长期扛高阶商业场景。根子在于它是封闭系统，部署在云端，不能本地化，企业数据私密性难保证；也调不了 OpenAI、Claude 这类第三方优质模型，只能用插件绕。国内多数平台不会开放 API、免费让别人调数据，于是很多人靠做小插件赚钱。凡是在 Coze 流程里稍微有用的节点，都可能被包装成付费插件，比如抓小红书标题、正文、赞和评论。

最近很火的火柴人视频，里面火柴人的调用也要付费插件会员才允许复制流程。这些插件大多由个人或小公司写，稳定性和寿命都难说，哪天停更也正常。再算上大模型费用，Coze 对新手的成本其实在快速上涨。

按讲师自己的定位，他要的是能扛事、能复用、不被一个平台绑住的工具。他的思路是把多个工具和工作流软件拼成一支“自动化小队”一起干活，这也接近 AI Agent 的终点形态。

有人会提 manus、lovart。可现阶段这些 Agent 工具还在早期，接不住完整商业需求，自主程度和灵活度都不够。所以讲师建议：先自己把各类工具的工作流打通、调稳，再按客户需求组合，这是眼下更靠谱的打法。

比如用 Make 按客户需求搭具体流程，把指定要求跑完。判断调通的标准很实在：看节点上还有没有提示点。这一点很关键。

要真刀真枪面对客户需求。海量场景等人挖：线下门店怎么和 AI 搭上，LBS 广告投放怎么接 AI，客服机器人怎样边看聊天记录边抓关键词，判断要不要发券，等等。红杉在最近一场会上也提到，未来 AI Agent 是靠结果换钱，不是卖工具、卖流程，而是用实打实的结果换钱，这个趋势躲不开。

方向清楚了，接下来就是从新手往高手走。现在网上初级教程一抓一大把，可市场真需要那么多“小白课”吗？中高级应用的学习需求其实更急。很多人学到的只是皮毛，撑不起商业变现。讲师想做的，是一趟贴近中级成长需求的航海：不只让你知道是什么，还要知道怎么做，别学成夹生状态——客户不买单，自己往下研究又没人带，卡在中间最难受。要做既明白 What，也掌握 How 的从业者。

# 章节概要

前面已经铺过底：概念、价值、工具路线都过了一遍。无论你选低代码平台、传统 RPA，还是流程平台、自主 Agent，目标都一样——把人力解放出来，把时间留给更值钱的创造。

接下来要做的，是把这套认知落到日常最费时的一块：内容生产。

本章会用一组实战案例，带你搭出真正能跑、能解决痛点的流程。具体包括：火柴人科普视频怎么自动出片，公众号摘要怎么智能提取并定时推送，公众号文章怎么自动排版发布，小红书爆款图文怎么自动生成，以及更复杂的 AI 视频流程、口播短视频二创改写。

每个案例不只给步骤，还会拆背后的思路和问题处理方式。学完你不仅能照做，还能把这些方法搬到别的创作场景，让 AI 成为内容流水线上的帮手。现在一起动手，做一个自己的“内容永动机”。
