# 公司要长大，付费获客别缺席

作者：七对  
日期：2023-07-11

不少团队复盘项目能不能长期赚钱时，习惯先翻商业模式，却把“投放买量”这一页跳过去。大家总想着能省就省，免费流量薅到就是赚到。可真正把生意推上规模，付费采买带来的增长更接近完整的商业思维，也能让团队更早握住主动权。

项目要持续盈利，付费获客和商业模式不是二选一，而是一套增长系统里相互咬合的两块。我们公司从产品变现、交付，到口碑和品牌，背后都靠付费投放托着。2022年疫情冲击业务之后，我们对这件事体会更深。下面就把这层关系展开聊聊。

一、先交代我的来路

2003年到2009年，我在南京大学读本硕；后来通过校招进入阿里巴巴做产品经理，2015年到2018年在原湖畔大学工作。2018年离开阿里，进入在线教育行业，以负责人身份创业。到今年是第六个年头，主营公务员考试培训。

我是生财424号，2021年在生财南京见面会做过一次复盘分享，题目是《三年团队从0到160人的总结与反思》。2022年疫情让整体业务受了影响，但公司活了下来，也逼着我们把商业想得更透。先说清楚，我们不是流量能力顶尖的公司，免费和付费都不算最强，优势在综合能力，尤其在付费获客与商业模式结合上，攒了一些踩坑后的经验。

二、什么样的商业模式才算跑得通

我判断一个模式成不成立，会拿六把尺子量：第一，到底替客户创造了什么价值？第二，产品怎么送到目标客户面前？第三，客户来了怎么转为付费用户？第四，付费之后的交付能不能让人满意？第五，团队能力撑不撑得住？第六，企业能不能持续盈利？六项都过关，模式才立得住。

（1）客户价值：先想清楚替谁解决什么

这是一切的地基。产品价值站不住，营销添再多0也没意义。没有明确需求，或者客户价值不足的产品，我觉得很难做。

我们主要提供线上公务员考试课程，以及部分省份的地面课程。线上课的目标对象比较明确：平时忙、有一定预算、学习不够自律，或者理解力偏弱的学生。我们帮学生制定课程计划，强盯学，做1对1微信答疑，把学习管理抓起来，保障学习效果。这跟市场上很多网课不一样，交付特别重，老师和班主任投入大，学习平台也是自己研发的。

线上公考培训已经很卷，但我们定位清晰，价格在行业里偏高，口碑也做得不错，精准满足了不少学生的需求。所以第一步必须界定清楚：到底为哪类人创造了什么不一样的价值。

（2）流量来源

我们不做地面推广，流量全在线上。线上流量分免费和付费。平台有红利期，能拿到免费流量是强能力，但持续性和不确定性是问题。真正能给出稳定预期的，是付费投放。

创业时我们也想过用刷题工具App切入，但那时已经有头部玩家，我们没做出来。后来一直在各平台找流量，幸运的是抓住了抖音红利，跟平台发展周期比较匹配。入局早，做一些简单素材通过抖音小店带货，最高峰一天能带四五千套书。但没多久红利就没了，入局的人越来越多，内容做得再精致，流量也少了。免费流量确实让我们起步快，但不稳定，数据经常波动。

抖音直播刚火时我们也做，还被头条内部当作分享案例。结果更多人看到机会涌进来，我们又沉下去了。任何一种免费流量获取方式，做的人一多就会被稀释，尤其抖音这种去中心化机制。

我们在免费流量上沾过光，但真正稳定的还是付费流量。2019年我们就开始做巨量引擎投放，2020年高峰期一年广告投入在1000万以上。免费流量没了，付费流量还能托住，持续稳定。这也是20、21年快速发展的直接原因。那一年人数到了159人，因为服务的学生越来越多，每个学生都依赖老师和班主任，交付比较重。做付费流量后，规模起来了，确定性也强了。

不过，付费流量的玩家增多后，获客成本会趋于一个稳定值，我们也切身感到单个线索成本在上升。有新进入的，也有退出的，最后成本稳定下来。付费流量的好处是确定，关键点之一是成本高低很依赖团队水平。所以我们一直坚持自己公司做投放，不依赖第三方服务商。我始终认为，付费流量获取也是团队的核心竞争力，不能外包；第三方同时服务多家客户，很难帮你形成优势。

（3）产品转化

流量来了怎么转，绕不开。公务员考试线上培训的转化率，我觉得偏低。

低价课可以在直播间或视频里直接成交，很多个人老师在直播；高价课直播带货很难，往往要加私域、建立信任再成交。影响转化的因素，我归纳为四点：

1. 客户价值匹配度。客户价值能多大程度满足需求，一方面看价值认可，另一方面看付费能力。我们做线上强盯学、1对1答疑的网课，跟其他机构的直播网课定位完全不同。有些用户觉得网课就该便宜，同样价格不如选地面课，这部分转化率就低；在职、平时忙、自律不够又有付费能力的人，转化率就高。是不是匹配精准用户，直接影响转化。

2. 竞争环境。行业本来分散，供应端产品多，用户选择多，流量获取门槛又低，竞争会越来越大，转化会越来越低。我们刚推出时产品有独特性，用户选择没那么多，转化比较高；很多人进入抖音等平台后，哪怕我们的价值点有明确差异，还是会被稀释，毕竟别人价格摆在那里，用户看完价格也会综合比较。抖音是机会，但去中心化机制和低门槛进入，也容易带来激烈竞争。

3. 产品口碑。一个产品、一家公司要长期发展，学生端的口碑必须保持。线上推广尤其如此，口碑不好反而砸招牌，线上用户更会搜集信息、综合比较。不可能每个用户都说好，但一定要积极对待反馈，不断改进产品和服务，这很实际地影响转化，而保持好口碑又恰恰很难。

4. 私域团队转化能力。要跟学生建立信任，很好匹配学生需求，帮助学生做指导规划，同时还要有业务意识。不同私域团队转化能力不一样，这对转化很关键。

有些不能改变，比如竞争环境；有些能改变，比如产品定位和品类、客户口碑积累、团队能力提升。但每个环节都不容易，不同行业办法也不一样。

公务员考试培训每年新增很多第一次参加考试的学生，对品牌粘性没那么强；教育培训又比较分散，经过20多年发展，也没出现一家通吃的格局。好处是进入者有机会，坏处是竞争太多，品牌溢价能力没那么强，每年都要面临拉新。

我们从2018年起推强盯学、1对1答疑、个性化全程陪伴课程。当时市面网课主要是大班直播，后来涌入线上的机构越来越多，很多机构用一样的名字，也叫全程陪伴，价格更低，也强调1对1盯学、答疑。但背后的交付千差万别：有人简单问一句学生学没学，也算盯学；我们基于学生学习时长、做题正确率等后台学习数据进行盯学；1对1答疑我们一直做专业授课老师答疑，很多机构做群答疑，或者非授课老师答疑。学生未必能完全识别价值差异，加上价格差，我们的客户出现流失，转化率明显下降。

我们花大量精力给用户提供更多类型产品和服务，想提升转化率。价格梯度上开始做低价，推出几百到小几千的课，希望用价格参与竞争。实际结果没想象中好：供应端多了很多产品，课程研发、教材印刷、上课班次都增加成本；更核心的是获客成本没降，低价课程反而拉低整体ROI。

总结一下，就是想用更低价、更多元的产品迎合市场变化，结果后端供应成本增加，前端客户数和营收并没有等比例增长。

同时我们也提供更高价位产品，增加更多产品价值，比如1对1诊断、1对1直播授课、线下集训等。这个方向反而增强了竞争力，因为我们提供的1对1直播、线下集训，很多机构做不了，交付太重，我们老师多的优势才发挥出来。这类产品虽然在学生数量上没有爆发式增长，但确实满足了部分追求更高品质的学生，竞争力更强，因为这依赖公司有较多全职老师和班主任，服务和教学做得深。后端交付更重，客户价值反而更明显，硬实力能得到体现。

要围绕更深服务学生的客户价值出发，整个公司从产品设计到客户转化、课程交付，团队都要改变、适应、拥抱变化。团队能力短板补齐不容易，围绕转化我们尝试过太多，无论运营还是产品供应，最后才慢慢找到适合团队能力的方向，而这个能力又是动态变化的。所以说，转化难，是真难。

（4）产品交付

好不容易转化的客户，承载着信任，交付尤其重要。价格是锚点，高价必须物有所值，必须对应很重的交付。

做网课我们体会很深：这么多学生怎么盯学？是不是要开发自己的盯学系统，看学习进度如何、做题正确率如何？这些不是市面软件能解决的。盯学还需要班主任老师每天布置任务、追着学习进度，班主任怎么培养，流程怎么保障到位？学习过程中1对1微信答疑是核心竞争力之一，学生不会了怎么办？老师1对1答疑，专业度怎么保障，答疑量怎么保障？

所以交付很重，后端投入比较大。我们想长长久久做，交付端就不能出问题。承诺做不到，负面口碑就会多，也就不具备持续性。

（5）投入产出比

互联网上，每个精准流量都有成本。免费流量背后也有人力成本，只是折合下来便宜；付费流量则是明确的流量成本。

要算清楚的账是：流量来了，算上转化率和交付成本，企业能不能盈利？在我们行业，线上课程分低价和高价。低价主要是录播或大班直播，高价要么小班直播，要么就是我们这种学习计划、强盯学、1对1答疑模式。如果流量获取成本高，低价网课撑不住。

假设获取一个客户50元，卖的课程是200元，这个账算不过来。转化率没那么高，课程本身有成本，像我们还有系统开发、老师1对1答疑、盯学，成本更大。所以必须考虑投入产出比，健康持续发展，不能靠亏损买量再转化做大，因为总会有爆雷那一刻。

行业里也出现过退费导致资金链断裂的案例，本质上还是模式有问题，ROI算不过来，变成金融游戏玩资金周转。为了把付费流量客户转化，推大量不过退费课程，甚至学完一定任务就退费，根本不考虑投入产出比，不出问题才奇怪。

（6）团队能力

企业里每块业务都需要人落地，都对应团队能力。从运营到转化，再到交付老师、技术、班主任团队，都是门槛。有些可以借外力，但核心竞争力层面必须依赖自己团队。

团队能力不是一朝一夕出来的，尤其人员越来越多时，怎么把团队打造成能支撑业务发展的能力，需要不断选人、建体系、优化、培养。

三、为什么必须谈付费获客？

（1）确定性更强

有了产品和客户价值之后，很关键的是解决客户来源。抖音、微信等平台商业化成熟后，对需要流量的创业项目其实是好事：至少在流量上，花了钱，一定能有确定性保障。当然，怎么投、怎么控制成本是另一回事。

（2）复制性更强

确定性强之后，复制性就比较强，从一个行业复制到另一个行业也很正常。我见过做淘宝等电商的公司，从卖一个产品到卖另一个产品，产品和产品之间没有关联度，但核心能力一样，就是团队的电商运营能力，不断拓展行业、复制到新品类，碰到一次风口就起飞了。就像之前听说卖打底裤的公司，过去几年卖口罩的案例。

（3）不依赖人

付费流量还有个好处：素材加投放，对人员的要求是精，不是多，不依赖大量的人。一个人能力够，可以同时做多个行业。做企业很多时候人力是很重的成本，人员增加，管理也有难度。

（4）关键点

我再三强调，付费流量应该是团队的核心能力。获客成本上，不同团队做出来不一样，我不认可这个能力外包。举个简单例子，当年K12投放很多时，一家服务商可以同时服务同行业多个客户，获客成本上大家都很难形成优势。

四、付费获客打开了哪些可能

付费流量解决了客户从哪里来的问题，这是很多项目的前提之一，不用担心客户来源了。有了这些好处，对我们来说，从客户价值、商业算账、产品转化、生命周期角度算，复制一个新项目就很快。我一直觉得，懂得和掌握付费流量玩法，就掌握了很多项目的主动权。

一般从三个角度论证并测试：第一，搞定供应端，到底给客户创造什么价值？第二，转化，一个客户在生命周期中能产生多少利润？第三，交付是不是能支撑，有没有可持续性？很小的团队组合，也能快速完成项目最小单元测试。当然，这三个环节要充分论证，成功和失败并存。论证好，就可以行动。

举个跨行业尝试的案例。2022年我帮朋友公司做过尝试，对我来说就是想试验这种模式。对他们来说，是基于付费流量拓展客户池，行业跨度非常大，直接到了工业品领域。公司做电子元器件分销，主要代理施耐德、西门子等国内外标准工业品，客户主要是工业客户或小型批发商。他们通过付费流量找到更多客户群体，再给专业销售跟进转化。

模型测试下来，基于原来的供应链是跑得通的。销售毛利虽然不高，但货值不低，客单价从几千到几万，单笔毛利额不高，但客户是企业客户，可以持续产生毛利。把周期放到企业生命周期看，会发现这个模式在原业务基础上可以盈利。前提是原来的体系是基础，线上只是拓宽客户来源，在流量端放大。

这里很核心的点：

1. 有竞争力的供应链是基础。他们公司产品全、价格有优势、发货快，原来业务的客户价值一直存在。所以客户价值是基础，客户来了之后，他在乎的点，原来的供应链能不能满足？跟客户之前的供应商比，价格、发货速度、服务有没有优势？这就是客户价值。

2. 如何找到精准客户，获取每个客户成本多少，这是互联网线上的精准获客能力。尤其客户是B端时，怎么在线上找到精准B端客户，获客成本多少，都是很现实的因素。我的观点是，当抖音、小红书等平台已经是推荐逻辑占主导时，是可以在线上找到B端客户的。B端客户往往有固定供应商，但背后还是个人，也会刷短视频平台，突然推送跟自己业务相关的信息，B端客户也不会排斥。线上是可以精准找到B端客户的。

3. 账一定要计算清楚：客户转化率、生命周期多久、一年毛利多少、回本周期多久。意向客户来了之后，很关键的是能不能持续产生销售转化。工业品销售专业性比较强，尤其涉及2B，跟C端业务差异明显，销售人员水平高低直接决定业务模型成败。特别在测试阶段，如果销售人员很弱，模型很容易偏差。转化端决定生死，而转化又由多种因素决定。但确实只要转化端跑通了，整个模型更容易跑通。

这个项目我们是服务方，主要是在流量获取层面，转化和后端供应很难介入。现在通过线上流量来的这批客户，还在每个月稳定给他们公司产生毛利。但挑战也比较多，比如这是2B生意，虽然线上通过付费流量找来了客户，但客户做久了之后，会存在需要线下维护、账期等问题，又回归到线下生意模式。所以很重要的就是，原来的商业模式本来就成立，线上只是进行了放大。

五、往后看，付费获客如何继续放大商业

付费流量跟免费流量、个人IP一样，只是获取流量的手段，本质上还是商业。如果原来的业务模式就有问题，付费流量扩大后，只会加速问题暴露。

但我也越来越觉得，付费流量是一种核心能力，这个能力伴随着创业，可以有更多业务拓展。所以我会越来越关注产品：产品能创造足够的客户价值，产品立住了，付费流量就可以放大。而产品的选择、打磨，往往依赖专业行业背景，特别是有竞争力的产品，有一定壁垒，选择产品很重要，是基础。

之前听过同程集团的分享，他们的流量能力加中台能力，复制孵化了很多项目，有成功也有失败。但具备了类似能力，商业拓展空间也更大。

付费流量在找商业项目结合时，会有一些简单维度。到底什么样的行业容易被线上流量赋能，上游、下游的分散度是很重要的维度。线上更适合上游、下游比较分散的行业，但具体还是要基于行业判断，这个过程中也必然会出现成功和失败的项目。

所以得试，用最小单位的模型去验证。但我始终相信，一旦能有一个项目成功，那就是能支撑未来很久的生意。
