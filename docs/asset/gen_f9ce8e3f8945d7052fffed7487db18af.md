# 8.5 负面情绪处理实战：做一次情绪拆解练习

请你想一想：最近哪一次负面情绪明显过了头？它背后可能藏着哪种思维误区？接着用“情绪修炼四步法”拆解，并把应对办法写下来。

1、事件：
2、思维误区：
3、处理方式：
1）觉知：
2）接纳：
3）分析：

最后，再送自己一句打气的话：

示范案例：
1、事件：航海打卡一拖再拖，心里满是负罪感，连在群里露面都觉得不好意思。
2、思维误区：一是恐怖化——觉得没跟上进度，后果会非常严重；二是应该化——认为自己必须把每次打卡都完美完成。
3、处理方式：
1）觉知：察觉到此刻自己正被过度内疚的负面情绪裹住。
2）接纳：事情已经这样，先承认并允许这份情绪存在。
3）分析：由于没有按时参加航海学习和打卡，我落入“应该化”思维，产生自责与内疚；而这些情绪又让我继续拖延，不愿完成任务，甚至直接从群里消失。
4）处理：大航海还剩一周多，完全可以立刻行动，先完成今天的打卡。
