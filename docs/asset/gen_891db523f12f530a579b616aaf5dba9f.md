# 3.5 技巧五：让朋友愿意评论的朋友圈 @王子冯

发朋友圈，最怕写成“通知”：自己讲完了，别人不知道接什么。所谓用户互动体，不是硬邦邦地求赞求评论，而是在发布前先替读者想好——他看到这条内容，能接哪句话、能分享什么经验、能做什么选择。

具体可以这样做：

第一，把问题问具体。别泛泛来一句“大家怎么看”，而是给出场景，比如“加班到九点，你们靠什么快速回血？我试了热水澡加十分钟散步，居然有效”。

第二，给读者留一个容易接话的入口。可以是二选一，可以是征集经验，也可以是请人补充细节。门槛越低，回应越自然。

第三，发完之后别消失。有人评论，就认真接住，把评论区变成聊天场，而不是展示墙。

第四，别为了互动而互动。先提供一点有用的信息、真实的感受或有趣的细节，再邀请别人参与。价值在前，互动在后，朋友圈才不会显得刻意。

写一条让人有话可接的朋友圈，比单纯等点赞更有效。@王子冯
