# 章节概要

想知道别的工具站背后用了哪些技术？怎么看竞品的流量情况？一个工具站的定价策略该怎么琢磨？把这些摸清楚，对自己网站的流量和定价分析多少都有帮助。

流量分析这块，主要聊了流量、流量来源、跳出率和转化率四个概念。

所谓流量，就是用户访问网站的情况；

流量来源一共分四类：搜索流量、直接流量、引荐流量和社交流量；

跳出率说的是用户打开网页后没做任何操作就关掉的比率；

转化率则指用户从进站到完成设定目标占全部访客的比率。

定价分析部分分享了 5 条思路，它们之间没有先后逻辑，只是给大家参考的注意事项：

按用户价值定价，而不是盯着自己的成本；

把 20% 的用户服务好；

给自己定一个价格锚点；

订阅模式，其实有一点点“套路”；

涨价，往往是最好的增长方式。

要提醒的是，这些都是圈友的个人经验，实际用的时候还是得看具体情况，具体问题具体分析。毕竟数据分析和定价分析从来不止一种思路。

# 7.2 分析其他网站流量 @Leevege

衡量网页表现，大体可以从四个维度看：流量、流量来源、跳出率和转化率。更细的维度或指标基本都由这四个衍生出来，下面一个个拆开说。

# 7.2.1 流量

流量一般分 PV（页面访问量）和 UV（独立访客量）。如果用户在多页面间浏览，数据会记成多个 PV 和一个 UV，所以任何时候 PV 都大于等于 UV。similar web 里看到的页面平均访问量（每次访问页数）就是 PV/UV，这个数值和平均页面访问时长一样，是衡量用户粘性的可选指标，越大越好。

[PRE14]

Similar Web 对 Google 的分析显示，用户浏览谷歌通常目的性很强。和一般认知相反的是，作为社交媒体的 Facebook，无论访问量、平均访问时长、每次访问页数还是跳出率，跟 Google 比都有差异。做竞品分析时同样可以对比这些维度，如果类似维度能做得比竞品好，流量就只剩推广投放的问题了。

如果要做精细化运营分析，还可以看各时间段的流量数据统计。不过因为时差，通常要把统计时间做对应时区转换，结果才符合出海网站目标用户所在时区的浏览趋势。流量数据也能看页面详情，有的页面被同一用户多次浏览（PV 高），就能知道用户更偏爱这个页面。

[PRE15]

某网站用户浏览量，这里取的是美国时间，X 轴是开始浏览到 1 小时以内的时间点，20 表示晚上 8 点到 9 点。可以看到，用户比较活跃的时间是美国时间下午 5 点之后到晚上 10 点之间。如果做内容站，在这段时间引流推广，效果显然比早上好。

[PRE16]

# 7.2.2 流量来源 @阿彪

来源的分类维度和需求相关，这个维度需要开发和运营网站的管理者积极监控、复盘数据，一旦发现异常值就分析原因。如果异常值让流量涨了，就可以利用导致异常的特性加大相关投入，大概率能让流量爆发。

首先得清楚四个主要流量概念：搜索流量、直接流量、引荐流量和社交流量。搞清楚不同流量的定义，搞清楚竞品主要靠哪种流量，才能有针对性地研究和确定自己的营销策略。

# 7.2.2.1 搜索流量

搜索流量，简单说就是从搜索引擎搜过来的流量。它分两种：自然搜索和付费搜索。

[PRE17]

大家看到红色柱子 77.28%，这是搜索流量占比，但别想当然以为这 77.28% 全是自然搜索，里面很可能有相当一部分是付费搜索流量。

理论上，别人能靠付费搜索排上去，你也可以。因为大家都没用过这个产品，用之前都是盲盒，理论上 ROI 能打平，你也有机会。

举个例子，PDFfiller 是做在线 PDF 编辑的，一个月流量 13.7M，搜索流量占比 77.28%。

再看右下角，它的 organic traffic（自然流量）占 60%，剩下 39% 是 paid traffic（付费流量），也就是说付费搜索流量占了 39%。

这个比例非常高。算一下，假如 14M，1400 万流量一个月，70% 就是将近 1000 万。1000 万搜索流量里付费搜索占 40%，也就是 400 万付费搜索流量，这个量级非常大。

这就提醒我们，人家投了广告，我们也要注意好好利用广告。如果只会做广告，也能在这里面分一杯羹，400 万里分到 100 万，足够养活自己了。这就是做分析的价值。

另一个网站 Top10.com，流量 3M，90% 都来自搜索，基本可以认为全靠搜索。搜索里 60% 来自付费，也就是说这个网站主要靠广告。对这个领域感兴趣的朋友可以看看，它其实就是一个广告套利网站。

什么意思呢？它自己做一个列表榜单，比如 10 个最好的域名服务商、主机或其他产品，然后从谷歌买广告，通过销售自己代理的产品拿佣金。只要佣金大于付费搜索成本，就能赚钱。

就是这么个生意。毫无疑问它做得不小，一个月流量 3M，付费广告 180 多万，一个流量进来至少 0.5 美金，一个月就是大几十万美金广告费，是个比较大的生意。

再看另一个产品 PDF editor online，流量 180k，60% 都是付费。如果我们做一个类似网站，有这么一个功能，直接靠广告投放就能赚钱。其实只要 ROI 能打平，就是非常好的事，因为广告投放确定性很高，而且即时响应。

当然，目前在线 PDF 编辑还是比较难的，如果能做出来，直接靠广告投放打平，这个生意还是不错，毕竟产品研发投入也没那么难。

# 7.2.2.2 直接流量

直接流量，第一种是直接输入 URL，或者点收藏夹、插件进去的。英国人或美国人本身就有输入 URL 的习惯。不像中国人，我们的文字是象形文字，而互联网世界都是英文，英文字母本来就是他们的语言，所以很多人直接输 google.com 就进去了。中国人很多不会输 google.com，而是输 Google 或 Apple 再进去。

第二种是谷歌浏览器判断不出来源的流量，都归为直接流量。这里有好几种情况，比如其他桌面软件；比如视频编辑软件、图片编辑软件、文档编辑软件；比如 App 通讯工具；比如在 telegram 或 WhatsApp 里有个链接，点过去其实相当于直接输入 URL。

为什么呢？比如在 adobe 的桌面软件里点一个链接直接过去了。对浏览器来说，这就跟你直接输 URL 一样，它不知道你是从 A 页面还是 B 页面过来的，压根没有 A 页面。B 页面是两个孤岛，一个叫 adobe，一个叫 Chrome，完全不一样，直接是从 adobe 过去的。adobe 不是网站，是桌面软件，从桌面软件过去就相当于直接输入 URL，所以浏览器把这种归为直接流量。

所以很多桌面软件或 App 公司，他们的 web 端网站流量很大，很可能这些直接流量都来自桌面软件或 App。

还有一种情况，很多 web3 工具或区块链相关工具，直接流量都非常高。因为它们很多通过社群传播，telegram 上很多链接，点一下就进了网页。

这种如果看到流量很高，就说要做 SEO，对不起，你可能压根没找对方向，人家根本没做 SEO，主要做社群。链接在社群里分享，大家都点过去，就带来很多流量。

比如我是个 PDF 作品，免费或付费的，里面有很多链接链到我的网站，这些流量也是直接流量。当然这里的 PDF 是在 adobe 或其他 PDF 桌面软件里，不是指 web 端。

第三种是加了 noreferral 标签的，也会归为直接流量。很多广告跳转链接会比较多，比如很多网盟过来的，这种链接很多都带 noreferral，或者是一些弹窗广告。

# 7.2.2.3 引荐流量

引荐流量，大概就是从其他非社交网站点击引流过来的流量。引荐流量如果比较高，通常有这几种情况：

主网站的马甲站、子工具站、子品牌站，或者自己收购的站。这些引荐流量高的，很可能就是它下一个潜在收购对象。马甲站就是换个壳，颜色不一样，功能都一样；子工具站，以视频编辑为例，里面有很多小工具，每个小工具做一个子站，子站只有一个小功能，全部引流给主站；子品牌站，就是一个子品牌。

多语言站点，就是后缀不一样。

Affiliate 代理商网站。很多主品牌网站会发展代理商业务，如果看到它引荐流量比较高，很可能是它自己的代理商。

付费做的高质量高流量软文。

支付通道服务商。比如我是 PayPal，很多人用我的支付，要到我网站来支付对吧？会跳到 paypal.com，后面带一个 URL 后缀。如果我的网站用了 PayPal 支付，最后就会给 PayPal 导流。
