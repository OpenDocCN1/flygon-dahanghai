# 6.4.2.2 暴涨之后，回本越拖越久

这个项目确实制造过惊人的财富效应，回看它的价格轨迹，就能感受到当时的狂热。二级市场上，代币在2022年3月还只有约0.15美元，短短三个月便冲到接近4美元，涨幅达到几十倍。到了一级市场，币安开盘价仅为0.01美元。涨的不只是币，NFT鞋同样被炒高，一双鞋能卖到上万元。

行情最快的时候，买入一双鞋，几天就能收回成本。于是人群蜂拥而入，连此前完全没接触过Web3的老板也一掷几十万甚至上百万。围绕“帮人走”还冒出了专门的跑腿生意，有人像外卖骑手一样接单代走，一天能挣几百元。

可那些在最高潮时冲进来的人，结局并不难想象：入场之后，规则就变成了“先给你利息，再拿走你的本金”。回本周期起初是一周，两天后变成一个月；有人想着再熬一个月就能回本，结果又拉长到一年。等待回本的时间，越来越长。
