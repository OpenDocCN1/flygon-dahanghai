# 6.1 聊天记录日报到底是什么

通常来说，就是把某个群聊在某段时间里的聊天记录，以txt文本或富文本形式提取出来，再交给大模型归纳整理。

# 8.1 提示词究竟是什么？

绝大部分情况下，提示词=说人话。

而且随着AI发展，以前需要提示词来约束大模型生成想要结果的情况，会越来越只需要说人话就能解决。

绝大部分低频需求，都不太需要打磨提示词来实现预期结果，往往通过多轮AI对话即可实现。

而需要打磨提示词的，往往是高频可复用的场景，比如个人介绍、知识卡片、AI速读等。

所以本章只是以AI可视化作为切入点，实操演练一遍：

一个看起来复杂的提示词，怎样从0到1生成。

学完本章后，你可以把这套流程运用到生成📕爆款标题、👸号爆文、小说创作等场景下的提示词。
