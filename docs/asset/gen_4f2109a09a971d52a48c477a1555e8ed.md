# 4.2.3.1 小红书图文笔记怎么写？一篇全搞定（防失联+MM188166M（李李）长期更新）

这篇主要讲小红书图文笔记的正文怎么写。其实公众号、即刻、朋友圈也一个套路，学会了处处通用。直接上方法论：

内容框架：引发共鸣 → 激起好奇 → 给出方案 → 呈现效果 → 引导互动

① 引发共鸣：开头就讲真实痛点。用具体场景或烦恼，让读者觉得“这不就是我嘛”。比如：

“每次写文案都像难产，憋了一下午也写不出一句能看的，焦虑到整夜失眠。”

“封面改了一整天，发出去依然没人看，感觉自己就是个透明人。”

② 激起好奇：让读者想知道你发现了什么。告诉他们你找到了一个好东西，能快速解决他们的困扰。比如：

“后来我发现一个AI工具，写文案突然就轻松了，5分钟搞定一篇。”

“用了这个AI神器，封面3分钟做好，效果比之前自己折腾的强太多。”

③ 给出方案：简单清晰地告诉读者怎么做。一步一步教，强调容易上手。比如：

“打开ChatGPT，输入主题，一键生成，再随手改改，5分钟搞定一篇文案。”

“用Midjourney做封面，几个关键词就能出图，不满意还能继续调，非常省事。”

④ 呈现效果：用实际成果证明有效。这样才有人信。比如：

“用这个方法，我现在每天轻轻松松产出3篇文案，效率翻倍。”

“AI做的封面让点击率直接翻了倍，数据肉眼可见地好。”

⑤ 引导互动：结尾别忘了和读者聊起来。鼓励他们尝试、留言、关注。比如：

“你也赶紧试试，有效果来评论区告诉我一声。”

“觉得有用就点个关注，后面还有更多干货。”

# 4.2.3.2 一条视频是怎么拍出来的（案例复盘）@汤姆 CC

起步阶段（2024年7月）
去年我就觉得AI是风口，但一直不知道怎么切入。后来想，干脆做视频算了，哪怕做不成，倒逼自己学AI技能也不亏——这就是费曼学习法。用AI的过程中攒了一堆经验和坑，藏着不如分享出来，帮人少走弯路。

我的AI账号始于2024年7月28日，那天发了第一个作品。当时没进生财，纯靠自己瞎折腾，模仿别人，完全不懂定位、选题、封面这些。现在回看自己的旧作品都想笑。那时候就觉得这事能做，一腔热血，先发了再说。坚持一周没什么水花，开学后时间紧、收益约等于零，就慢慢搁置了。

转折期（2024年10月）
10月15日，亦仁老大的第一条超级标发出来，我再一次认定这个赛道有大机会。那时进生财一个多月，学了不少做账号的门道，于是我把生财和网上的各种自媒体经验帖翻了个底朝天，疯狂学习怎么找选题、怎么做爆款封面，粉丝慢慢过了一千。期间各种尝试，学着赛文乔伊那种手机拍法，失败了很多次。

后来快到期末考试，又停了一段时间，但我没放弃研究AI自媒体。我开始研究喜欢博主的剪辑风格，做像素级拆解，做笔记慢慢分析。到了寒假，把学到的个性化背景设计和剪辑技巧都用上，数据还是平平。

突破期（2025年春节）
临近过年，我更新了一期DeepSeek的视频，没什么反应。但除夕那天，我的小红书突然爆了。我判断DeepSeek有得做，于是除夕夜加班剪了一期关于DeepSeek本地部署的，初二发布，火了。

过年要去亲戚家拜年，我就背着电脑，跟家里人说我去写作业，其实在偷偷更新DeepSeek相关视频。流量一直不错，我不敢断更，坚持一天发一个，涨了2000粉。后来全网都在讲怎么流畅使用DeepSeek，我过年那阵也发了不少，但同行大量涌入，那类教程已经成了红海。反过来，专门讲DeepSeek怎么具体用的人很少，于是我转向做具体使用技巧，做有实操价值的教程，结果做出了一个千万播放、三个百万播放。

# ① 账号定位（防失联+MM188166M（李李）长期更新）

做账号最重要是定位。怎么结合自身优势找到合适的定位？

我的思路来自七天姐的方法：借助AI帮你思考。你可以对AI说：“你是生财有术的亦仁，你帮我做AI自媒体定位。”然后整理出10个身份标签。这些标签对应的是未来可能购买你产品/服务的人，本质上就是你为谁提供什么服务、收多少钱。

AI会基于你的身份给建议，但你要结合自己的情况判断建议合不合理。

（1）靠网感——刷视频、刷帖子。抖音、小红书、公众号都能搜关键词，比如“AI工具”“AI绘画”等，选最近一周的爆款。爆过的内容大概率还会再爆，你可以参考它并结合自己的特色，加上创新点或感受。但如果只是洗稿，我不建议。

# ④ 文案

有了选题之后，用AI做头脑风暴、找灵感。我一般先把自己的思路喂给AI，让它帮我分析、优化，再润色文案。
文案开头3秒必须足够抓人，用户才有兴趣往下看。内容要有价值，别人才会点赞、转发。

标题文案库（供参考）：

- 技能提升型：“一晚上搞定 Midjourney，小白必学的3个赚钱技巧” —— 卖点：速成、赚钱；情感触发：焦虑、机会；适用：AI绘画教程

# 4.2.3.2 怎么做数据复盘？

① 两秒跳出率：这个指标越高，说明视频开头没抓住用户注意力。

优化建议：
- 开场画面：第一帧要有视觉冲击力，可以用鲜艳色彩、动态效果或悬疑设计。
- 开场话术：用疑问句、悬念或情感共鸣开场，在前3秒传达核心价值。
- 节奏把控：开头节奏要快而有力，别做太长的铺垫。

② 完播率：反映用户看完视频的程度，是内容质量的重要指标。

优化建议：
- 视频时长是否符合平台属性和用户习惯？
- 内容结构是否紧凑、不拖沓？
- 有没有在关键节点设置悬念，维持观看兴趣？
- 画面和声音质量是否专业？

③ 互动数据：包括点赞、评论、转发等用户参与行为，互动高说明内容有共鸣点和话题性。

优化建议：
- 设置互动话题或悬念引导评论。
- 在视频中设置互动环节。
