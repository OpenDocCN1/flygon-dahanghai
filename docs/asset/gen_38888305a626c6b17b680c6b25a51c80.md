# 一、航海说明：目标与方法论

# 章节概览：

本章明确了这次航行的核心目标：

用21天从零基础到发布首个iOS App，并尝试通过付费下载或订阅模式获得收入。

选择iOS市场的原因非常明确：审核效率高、用户更愿意为应用付费、无需繁琐的备案流程、成本结构清晰。

借助AI开发的核心优势是：不需要懂一行代码，就能大幅缩短开发周期，

让你把精力集中在理解用户需求和产品设计上。

开发过程中建议采用小步迭代、分模块开发、AI+人工结合的方式，

AI只是辅助工具，关键判断依然要由人来把控。

# 2.1 域名服务器准备

如果想做 iOS APP 的前端+后端+数据库管理，就需要额外准备域名和服务器，而且域名要做 ICP 备案才能访问国内服务器（海外服务器，比如香港、新加坡，不需要 ICP 备案）。不同地区备案要求不同，时间上也不确定：快的话一周内，慢的话可能 2-3 周。

海外和国内服务器的区别：

（1）海外服务器：同样配置价格通常比国内贵，比如阿里云/腾讯云的国内服务器新用户优惠价 99 元/年左右，同等配置的香港云服务器可能要 2000-3000 元。

（2）国内服务器：域名需要 ICP 备案才能访问，海外服务器则不需要。如果只是实现前端+后端+数据库，国内服务器性价比更高。

# 2.1.1 域名注册

（1）阿里云 / 腾讯云注册。com 和 .cn 域名 30-55 元/年，其他后缀 10 元左右

（2）如果只是做 iOS APP 前端+后端+数据库访问，任何后缀都行

# 2.1.2 域名 ICP 备案注意事项

备案流程：阿里云 / 腾讯云都有备案入口，按网页提示提交资料，个人也能独立完成备案

（1）个人备案时，需要填写网站类型和备注，建议写“个人学习使用，用于建设个人网站，记录工作和生活”，不要涉及商业用途。

（2）如果个人备案后，域名被用于明显的商业用途，比如搭建了海外站点，并且不需要登录就能看到完整内容，那么备案可能被服务商强制注销。如果有这种用途，建议用个体 / 企业执照备案。

（3）备案时最好在购买服务器的服务商处操作，因为备案需要备案号，买服务器通常会送 2 个。如果没有，可以到淘宝搜“阿里云 icp 备”，10 元左右买一个填进去。

（4）提交备案后，24 小时内注意接听服务商电话，会核实个人信息，有问题也会驳回并给修改建议。

# 2.4 心态预期

# 2.4.1 AI 能降低门槛，但不代表没有门槛

如果你不懂编程、怕学代码，完全可以在不懂一行代码的情况下，靠 AI 做出自己的第一个 iOS App。但过程中你可能会遇到下面这些坎，这也是我自己开发 iOS App 时踩过的坑：

1.

英文基础不好，看不懂 Xcode、Apple 开发者后台的界面，前期只能靠截图翻译、沉浸式翻译插件来熟悉操作

2.

iOS App 开发和 web 开发不太一样，虽然不用装运行环境和依赖，但也没法像 web 那样用一两句提示词就快速做出应用。大部分时间都在处理编译报错，需要多轮对话不断调整。

3.

一开始不要尝试做太复杂的应用，最好循序渐进。我前前后后试过六七次做玄学类应用，但有些业务逻辑太复杂，AI 也理解不了业务场景，就算让它写四五千行代码也很难实现核心功能。所以开发要从简单到复杂，一点一点深入。

# 2.4.2 开发过程中一定会有大小 bug 和构建报错

过了编译报错只是第一关，说明应用能装到手机上了，但不代表开发结束。因为就算编译成功，功能也不一定能正常跑，还是要不断调试。调试过程中可能会遇到“控制台报错、内存泄漏、运行线程报错、代码警告”等各种类型的问题。

所以，App 开发中测试和调试非常耗时。一个 App 版本经历几十次打包编译也不奇怪。1-2 小时确实能做出一个简单的 iOS App，但很难做出一个成熟、完整的产品。开发时间上别太追求速度，好产品即使有 AI 辅助，也要耐得住性子慢慢磨。
