# 1.3 Web3 到底补上了哪些缺口？

上一篇把 Web3 是什么、互联网怎样从 Web1 走到 Web3 讲清楚了。这一篇换个镜头：站在 Web3 一侧，看看为什么需要它，以及它能修补 Web2 留下的哪些毛病。先说明，这只是 Web3 视角；你完全可以保留自己的观察角度。

在 Web2 里，目前暴露出五个明显问题：

**1. 数字身份被平台握住**

在 Web2 世界做任何线上活动，几乎都绕不开注册账号：聊天要用微信、QQ，玩网易游戏要开游戏账号，到了海外，用社交媒体还得注册 Twitter、Facebook。也就是说，你的数字身份从一开始就诞生在平台体系里；从创建账号那一刻起，身份信息就被交到了平台手中。

Web3 不一样。你生成自己的数字地址后，就拥有了属于自己的数字身份，凭这个地址可以访问各类 Web3 应用。

**2. 数字资产不归用户**

顺着上面的逻辑，你在各平台积累的数字资产，同样不属于你。比如玩游戏时，账号可能因为各种原因被封，或者游戏公司直接跑路，你的数字资产也随之被带走，原本属于你的东西被平台拿走。

这里有个广为人知的段子：Web3 当前最大的生态公司以太坊，其创始人 V 神出生于 1994 年，13 岁就开始玩《魔兽世界》。2010 年某一天，暴雪的一次升级改动了他角色的特性，这位小神童十分难过，直接删掉了《魔兽世界》。这或许也为他后来创办以太坊埋下了一颗思考的种子。

**3. 数字回报被平台截走**

数字资产不归用户，它带来的收入自然也不归用户。很多人还没弄明白数字资产是什么意思。其实每个人的微信就是自己的数字资产，微信和房产在本质上没有区别，对做自媒体的人尤其如此。大家在各大平台产出内容，平台一边出售你的数字资产，或者收取你的数字资产“租金”，一边却不给你任何直接收益。这是典型的白嫖，但用户往往并不自知。

**4. 平台与创作者话语权失衡**

这一点显而易见。如今各大 Web2 平台，哪个不是说封就封。

前阵子，我们 RichDAO 的小助理用一个微信工作新号加 Web3 好友。某天突然有将近 200 人加小助理微信，小助理又要在群里组织活动，结果微信直接把号封了，直到现在也没能找回。小助理做了什么过分的事吗？没有。但他却失去了和新朋友连接的权利。背后反映的，就是垄断型平台与用户之间严重失衡的权利关系。

还有知识星球。我们为了给社区成员沉淀内容，把部分 Web3 内容放到了免费的知识星球上。但在申请成为正式星球时，平台因为内容涉及 Web3，就不给审核通过，而内容本身就是正常的学习资料。所以 Web3 的人认为，这个世界需要 Web3 的理念和精神，现有平台的权力需要被制衡了。

**5. 支付通道受约束**

我们经常能看到，各个国家比如美国，动不动就制裁某个国家或个体，冻结其银行资产等。Web3 的出现，理论上可以减少这种限制问题。

说了这么多，简单来说，Web3 要解决的核心，就是用户数字资产究竟归谁所有的问题。

今年 6 月底、7 月初的时候，有一篇叫《Web3 三问》的文章，一度在 Web3 圈子里广为流传。这篇文章提出了三个问题：

• 什么场景是在 Web2 不能完成，必须在 Web3 才能完成？
• 如果有，那这个场景下的 Web3 产品有多少人需要？
• 这个场景下 Web3 的产品解决问题的效率会更好么？

这三个问题的提出框架，主要还是从生产创造价值的角度去出发，有一定的局限性。除了这三个问题，我想再补充一个问题：

• 如果你觉得，没有什么问题一定需要用 Web3 来解决，那 Web3 还会发生么？为什么？

以上 Web3 四问，大家可以结合自己的认知与经验，尝试回答。
