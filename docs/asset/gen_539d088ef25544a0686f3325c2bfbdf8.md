# 社群两个月收200+付费会员、进账9900+，普通人怎么做

（精华帖 · 64赞）

先自我介绍一下：我叫新侠，在一家苹果供应链上市公司做中层，平时带着20多人的工程师团队和50多人的普工团队，工作里长期跟数据分析、企业团队管理打交道；互联网副业则是折腾些小项目。

年初，我正式把精力投向互联网项目。一路先照搬、再模仿、后加入自己的改造，最后搭起了一个围绕互联网项目的付费社群。

社群门槛从19.9元逐步上调到199元，两个月里累计进来200多位付费会员，合计变现9900+。

几个月里虽然磕磕碰碰，但总算走通了一条能落地的互联网路径；而且已经验证，这套方法对普通人也同样适用。

这篇就当作一次过程记录：踩过哪些坑、怎么处理、当时怎么想，我都整理出来；也希望能给读到的人一点启发。
