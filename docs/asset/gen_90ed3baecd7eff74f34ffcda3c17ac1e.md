# 4.1.1 宝宝达人变身秀实操步骤 @小芬

# 4.1.1.1 第一步：拆解爆款爆点

分人物爆点和画面爆点。爆点即使不特意做，视频做久了也会有体感，知道什么样的内容更吸引人、数据更好；多看几个同赛道爆款，大概就能总结出来。

# 4.1.1.1.1 人物爆点

可以刷评论区。做过宝宝类的会发现，评论区大部分夸可爱，adorable、cute 等。可爱就是大爆点，还可以细分到表情、动作、服装：微笑的比没表情的数据更好；动作丰富，观众不容易无聊，看得更爽；服装颜色鲜艳，更能凸显可爱。

[PRE13]

# 4.1.1.1.2 画面爆点

场景：整体舞台要明亮；画质：越清晰越好；主体：最好平视镜头，位于画面中间。记住这些分析出的爆点，再开始找灵感迭代视频。

# 4.1.1.2 第二步：抓住异常值

想做创新，在还没做出爆款前，不要随便无脑创新。先找爆款视频，最好最近一个月千万、最低百万。不要局限在自己赛道：想做宝宝走秀创新，优先刷这个赛道的同行，看流量下滑时有没有人先站出来迭代；如果有且数据不错，直接模仿他的形式去迭代。如果没有，就刷同类型赛道：宝宝走秀多在舞台，慢慢迁移到户外，就看相同场景性质的达人秀舞台表演赛道。同赛道跟着大哥迭代。

复刻案例思路：先找到同赛道爆款，形式是宝宝和萌宠走秀出场，中间两者融合，完成宝宝变装，再加变装后的走秀。1.mp4【在线播放】。提示词模板核心（对应有色块部分可自行更换）：全身、面向镜头、街头风，一个非常胖的 2 岁宝宝、皮肤很白、卷发、微笑、涂红唇，穿红白碎花低领迷你裙，配精致珍珠耳饰和银链手链，可加动作如拥抱；旁边一只大狗，行走中，强视觉冲击，时尚优雅；画质参数 best quality、4k、8k、highres、masterpiece:1.2，ultra-detailed、realistic、photorealistic:1.37，vivid colors、sharp focus、studio lighting、glamorous runway setting；--no sexy --ar 9:16 --personalize ih7hzco --v 6.1。分析下来和达人秀做法大差不差：把美女换成 baby，动作换成走秀、拥抱，改改就能做。制作视频的提示词可参考 4.1.4 AI 怪兽合成部分的图生视频板块。

# 4.1.1.4 宝宝赛道被判“面向儿童可见”怎么办

做宝宝类赛道，很容易遇到一个问题：被判仅面向儿童可见。只要视频被判仅面向儿童可见，流量瞬间就会被掐断。

[PRE18]

# 4.1.1.4.1 处理办法

💡 把带有 baby 的标签全部去掉。发视频时如果带了这些 baby 标签，全部去掉即可。使用这个方案到现在，没有出现被判儿童的问题。

# 4.1.1.4.2 申诉模板

以前视频被判儿童可见，想着申诉成功会不会继续推流。为了验证，先把以前视频里带 baby 的标签全部去掉，再发起申诉。一开始试着申诉一个，过了；又申诉一个，也过了；想批量一次性把之前几个都申诉一遍，却被拒绝。所以如果也被判了，想申诉的话，可以试试一天一个地去申诉；申诉只有一次机会。流量图显示：直线就是被判期间，流量丝毫不动；申诉后流量继续跑起来，也验证了申诉成功会继续推流。申诉文案参考：
