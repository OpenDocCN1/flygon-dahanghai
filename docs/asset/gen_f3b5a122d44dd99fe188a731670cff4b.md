# 6.1 爆款内容这样用，ChatGPT帮你搞定选题 @木白

很多人在做选题的时候容易想破头，其实有一个省力的路径：别急着凭空想，先在你准备发文的平台上，找一篇已经验证过效果的爆款内容，把里面的核心情节和结构拆出来，交给ChatGPT作为参考案例。

接着，请AI基于这个案例生成一批选题方向，通常会给出好几种不同的角度。如果第一轮结果不符合预期，不用怕，直接告诉它你想怎么改，比如调整切入点、换个人群、优化语气，让它重新生成。如此反复，直到出现一个比较理想的候选。最后，还需要人工介入，对这个候选进行修改和完善，才能最终敲定真正适合发布的选题。
