# 4.4.3 管理风格没有标准答案，先认清自己 @醒醒同学

有人从写代码起步，还没正式走上管理岗，就已经在做管理的事：碰到团队没做过的项目，她会主动牵头，拉上同事一起试，最后常常交出超出预期的成果。也正因如此，公司里几乎人人都知道她。她更像赋能型领导——愿意把机会交给下属，也愿意鼓励大家去尝试，所以团队氛围一直不错。

从四个维度看，战略思维、关系建立、影响力、执行力四条线长度相近；其中战略思维稍高，关系建立紧随其后，影响力和执行力也不弱。她既能推动人，也能推动事，没有明显短板。整体上，她对事情很在意，对人则相对温和。

她的前十才干依次是：积极、搜集、成就、学习、取悦、沟通、行动、统筹、体谅、专注。

🔥盖洛普视角下，部分才干这样看：

- 积极与沟通：她做事主动，喜欢轻松愉快的工作环境；也常能看到团队成员的长处，并当面表达肯定来激励对方。这样的领导带团队，下属往往更开心，团队也更有凝聚力。
- 取悦与沟通：她能在公司内部打通各个部门，维护好关系，为团队争取资源。
- 成就与专注：任务能不能完成，是她非常在意的事；同时她本人勤勉，愿意以身作则。这样的领导带出的团队，绩效通常不会差，因为她不会把活丢给下面就不管。
- 统筹、取悦、行动、沟通、积极五项叠加：她擅长对外协调，平日里会留意哪些跨部门伙伴能搭把手；任务一多，她能快速调动公司内部的人来推进，而且大家也愿意配合她。
- 成就、行动、专注三项叠加：她看重下属能否准时交付，对习惯拖延的人比较难接受。她判断下属行不行，核心就是看能不能把事做好并及时完成：做不到，她会难受；做得到，就会得到重视。
- 统率29、完美25、排难18、追求27：她不是强势压人的领导，有一定的容错空间，也愿意把功劳和舞台分给下属。

总的来说，性格不同，领导风格自然不同。这位管理者的风格可以概括为：性情温和、结果导向、善于激励下属并及时给反馈、重视团队氛围、容错率不低、对外低调。

另一种领导风格则几乎相反：对下属要求高，只想招优秀的人，容错率低，有野心，能持续带团队拿到结果。比起团队关系是否融洽，这类领导更在意问题有没有解决、结果有没有拿到，说话也可能更直接。跟着这样的领导，心态不能太玻璃心。
