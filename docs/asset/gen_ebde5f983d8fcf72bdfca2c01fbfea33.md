# 3.1 借助 AI 学习编程 @乔帮主

使用 AI 的核心在于提示词。哪块知识不懂，就可以通过提示词驱动 AI 为你答疑解惑，直到把你教会、教懂为止。

提示词的质量，决定了 AI 能不能有效辅助我们学习。所以我们要求提示词写得精准。下面给大家一个好用的提示词模板。除了学习 Python 编程知识，也可以借助这个模板学习其他学科知识（点【附件页面】进入复制提示词内容）：

# 📌

背景：说明背景，提供充足信息，帮助 AI 更好地理解问题背后的意图和情境。

角色：让 AI 扮演某种特定角色，如“资深产品经理”“Python 老师”等，这有助于让 AI 知道自己的能力边界和职责所在。

目标：描述你要 AI 做的事情，让 AI 知道实现目标所需的具体、可衡量的内容。

结果：对 AI 输出的回答在风格、格式、内容等方面提出要求，让 AI 输出的内容更符合我们的期待。

比如，按照上面的提示词模板，我们可以用以下提示词快速学习 Python 知识（点【附件页面】进入复制提示词内容）：

# 📌

背景：我是一个 0 基础、完全不懂编程的普通人，

角色：请你担任经验丰富的 Python 老师，

目标：我要你教会我学习 Python 基础语法，

结果：请你以通俗易懂的语言跟我描述什么是变量？

注意，为了方便大家理解提示词模板，以上提示词加了注释解释。拷贝给 AI 的时候需要用以下版本，否则一些不必要的额外信息可能影响 AI 回答内容的准确性（点【附件页面】进入复制提示词内容）：

# 📌

我是一个 0 基础、完全不懂编程的普通人，

请你担任经验丰富的 Python 老师，

我要你教会我学习 Python 基础语法，

请你以通俗易懂的语言跟我描述什么是变量？

除了用 AI 辅助学习 Python 编程知识，我们也可以借助 AI 帮我们写产品工具代码，这是对 AI 的进一步深度使用。比如项目实战案例中的爬虫应用提示词（点【附件页面】进入复制提示词内容）：

# 📌

1.  写一个爬虫程序，按下面的要求在我的 Windows 电脑上帮我抓取微信公众号文章。使用 python3 和最新版的 selenium。目标网站：https://weixin.sogou.com/。输入关键字[ AI ]，点击[ 搜文章 ]按钮。爬取内容：爬取标题、摘要、链接、来源。爬取后的内容保存到 Excel 文件中，Excel 文件命名为 AI_微信_时间。爬取前 5 页，每爬完 1 页休眠 5s。请给我完整可运行的程序，让我看到浏览器中操作的过程，并指导我安装程序依赖的所有库。你可以先执行步骤 2 和步骤 3 了解网页的结构，然后再生成代码。

生成的代码可以自己拷贝到本地运行。如果代码报错，只需把报错明细拷贝给 AI，它就能帮你改成正确的代码。

但值得注意的是，AI 是一个遇强则强、遇弱则弱的人工智能工具。如果想用 AI 对某一领域知识进行深度学习及辅助，需要我们对这个领域的知识熟悉甚至精通，这样才能进一步深度使用 AI 替我们做事。

否则，你跟 AI 之间的对话也许只有一轮，因为你没有对应的知识转换成提示词去驱动它。比如上面的爬虫提示词，需要你对爬虫整体专业知识有所了解，甚至很熟悉。要不然你就没办法从 0 到 1 写出对应的提示词，更没办法驱动 AI 帮忙写爬虫代码。

当然大家也不必担心，很多参加本航海项目的可能都是 0 基础小白。通过本章学习，会让大家掌握代码的基础知识使用，也会让大家掌握怎么用 AI 写出产品工具程序！
