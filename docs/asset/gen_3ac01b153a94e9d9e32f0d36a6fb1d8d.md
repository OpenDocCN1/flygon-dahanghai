# 从不到两万启动，她把线上美业做到七位数

文｜夕子　　2022年11月7日

我是夕子，1993 年出生。没有背景可依靠，启动资金不到两万元，后来在线上美业这条路上，把收入做到了百万元级别。

跟行业里的大佬相比，这个数字当然不算什么。我更在意的是：今天的自己有没有比昨天更会思考，认知有没有再打开一点，心态有没有更稳，收入有没有再往上走。

大学毕业后第一次做生意，我没有亏钱，反而赚到了钱，并且跑出了一条相对稳定的现金流。下面把我觉得重要的经验整理出来，分享给有缘看到的人，希望能带来一点启发。

我把过程拆成这几个节点：

一：因为自身有皮肤病，我选择了从医方向
一：离开校园后，我把那份不合心意的工作放下了
二：第一笔订单只带来 2 元收入，我的生意从那里开始
三：曾遭遇店铺封禁，放弃的念头一度冒出来
四：把利润从一万推到五万，我靠的是这个动作
五：让利润从五万增长到十万以上，我做了这件事
六：接下来，我想这样走
