# 两个机器人，先各自叫通

动手前，只需核对三项：

- 群聊里能否单独召唤这两个机器人；
- 成员列表里能不能找到它们，并且可以选中为有效提及对象；
- 测试群是否专供本关使用，不碰现有生产群。

3.4 让 Codex 配置并验收自动点名

验收表满足上述判定，才算过关；仅配置文件正确不算，必须有真实飞书群消息作证。具体提示词和排查动作见实操工具包第 06 节。

6.2 什么时候可以作为日常方式

第一次自动接力通过后，继续完成几次稳定性测试。满足下面条件，再把它作为日常方式：

- 上游 Agent 连续几次都能输出相同结构的交付消息；
- 下游 Agent 能稳定读取上游结果；
- 下游 Agent 能明确回复接收通过或退回；
- 没有出现重复点名和循环触发；
- 权限和结果链接保持稳定；
- 异常情况能够暂停并通知人。
