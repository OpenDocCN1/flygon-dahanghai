# 4.4.2 先稳住心态，再谈增长

做账号时，情绪和心态往往比技巧更早影响结果。比如你刚发了三五篇笔记，一看数据很冷清，就怀疑自己——这其实不必。对新号来说，内容刚上线时观看人数偏少，本来就是常见且正常的状态。

你又不是已经有知名度的博主。那些十万粉甚至更多粉丝的账号，每次发布都有固定受众撑着，浏览量高并不奇怪。

所以，先把心态放平，再一步步完成每个阶段的小目标。

而阶段目标能不能落地，背后离不开选题框架。搭选题时，重点要做观察：

第一，去看小红书站内已经跑出来的爆款，也看自己所在领域的爆款；还可以延伸到知乎、抖音等平台，找那些表现突出的内容。说到底，这些爆款就是你的选题来源。
