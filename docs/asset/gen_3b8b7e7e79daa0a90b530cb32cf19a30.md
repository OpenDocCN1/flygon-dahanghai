# 2.3 情绪价值朋友圈，如何让人有共鸣？ @王子冯

先回答上一节的思考题：那张可爱的熊猫图其实只是配图，真正的主角是文字。文字并没有提醒大家去看图，而是借一个故事讲清了一个观点。因此，这条文案提供的不是“好看”的观赏价值，而是能引发共鸣的情绪价值。

接下来进入本节主题：怎样做出能提供情绪价值的朋友圈？

若想让内容传递喜怒哀乐、价值观等情绪导向，可以结合前文提到的素材来源，找到不少切入方向。比如，用一段经历托出你的看法；晒出日常切片，缩短与读者之间的距离；推荐一本书、一首歌或一句打动你的话，再顺势聊聊自己的体会和立场……这些都值得尝试。

至于如何提升这类内容的质量，在「三、如何提高朋友圈质量」中，已经针对不同展现形式的朋友圈做过案例与技巧拆解。所以这一小节，我们重点聊情绪价值朋友圈的常见误区与注意事项。
