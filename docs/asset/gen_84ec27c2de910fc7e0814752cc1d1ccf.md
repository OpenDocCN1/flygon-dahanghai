# 七、专注才干：把专注变成优势

拥有这种特质的人，做事往往带着一条清晰的主线：天然会把注意力放到成果和速度上，先判断哪一步最要紧、什么该排在前面。一旦方向明确，就会主动收拢心思，尽量屏蔽外界杂音，按计划一步步向终点推进。

在日常生活中，这类人会不断为自己寻找可奔赴的目标，也会本能地衡量：眼前这个动作，是否真的有助于把事情做成？在多个选项里，通常会更倾向那个更高效、更直达结果的方案。团队里一旦有人跑偏，他们往往第一时间察觉，并且有能力把大家拉回正确路线，少走弯路、少耗时间。

**无意识发挥时容易出现的盲点**

因为心思高度集中在任务本身，目标之外的需要有时会被放到视线之外，比如同伴的情绪感受、对试错空间的期待。这样一来，关系里可能冒出一些摩擦，甚至不得不暂停脚步先处理这些干扰。另一种情况是：当目标需要调整、甚至非变不可时，仍容易抓着旧方向不放，不愿转向，这可能带来损失。还有，短时间没达到预期时，压力会迅速上升，偶尔也需要给自己松松绑。

**当专注沉淀为优势**

这时，他们很擅长定方向、立目标，并且从头到尾保持投入；能主动绕开干扰，持续向目标靠近。在排列轻重缓急、设定目标以及高效推进工作方面，能力格外突出，也常常是带动团队提升效率与质量的能手。
