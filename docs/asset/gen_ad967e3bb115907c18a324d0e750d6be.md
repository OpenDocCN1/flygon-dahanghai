# 三条轻量视频变现路

表情包不只是聊天工具，它同样能带来收入。直接靠表情包获得收益只是其中一种方式；除此以外，还能给他人供应表情包、做定制、带人学做表情，甚至教别人制作表情包视频。对这块感兴趣的人，确实值得认真研究。

## 表情包视频：先跑通最简单的流程

这一节先聚焦表情包视频。它的制作门槛不高，流程熟练后，准备齐素材，几分钟就能产出一条。

表情包内容方向也不少：早安祝福、情感语录、音乐类都能做。也可以参考其他领域的玩法，去找对应文案。文案来源无非几种：学习同行的表达，去淘宝拼多多找现成内容；文笔好就自己写；专业网站和APP里也能找到素材。核心是挑受众感兴趣的话题。

配音方面，如果自己的声音条件不错，可以亲自录；找人配音也行，但成本偏高，而且后期存在隐患——对方可能不再配合，或者在音频里植入广告，处理起来麻烦。

可以直接在剪映里挑一个喜欢的背景，也可以自己做好背景再导入。

第二：导入音频

音频可以借助第三方工具提取后导入，也可以直接使用原视频的声音。把视频和背景分放在不同轨道。如果使用别人的视频，先导入原视频，选中视频后点击“分离视频”。

[PRE5]

分离后删掉原视频画面，音频就保留下来了。

第三：导入表情

把需要使用的表情下载好，再导入剪映。手机端可以用贴纸添加，也可以直接导入；电脑端能把表情拖进剪映，或者通过添加功能导入。

导入时要注意细节：表情本身带有动作和时间长度，必须完整导入，否则成品看起来会不协调。

[PRE6]

另外，不同表情大小不一，最好统一尺寸，视觉上更舒服。处理好这些，就可以给视频配字幕了。

表情出现的位置最好与音频节奏对应，可以观察音频的起伏来插入表情，这样成品效果更佳。

第四：视频配字幕

如果只有文案、没有音频，直接添加文字做标题即可；如果有音频或歌词，按住音频，点击“识别字幕”，就能生成字幕。再对字幕做调整，调成自己喜欢的样子，最后加上标题。

#### 6.4.11 中老年祝福：顺着长辈审美做内容 @黄岛主

视频号的用户属性里，中老年人群占比相对较高，所以早安祝福类视频很多。如果你留意亲人群，会发现老人大概率转发过类似内容。这本身就是一个思路：多看看老人朋友圈转发什么、群里转发什么，就能知道他们喜欢哪类内容。

这种视频如果用年轻人的审美去看，可能看不下去。千万不要按我们自己的想法做，而要做中老年人愿意看、愿意转发和收藏的视频。

第一步：获取素材

制作早安祝福相关视频，素材可以是随拍视频，也可以是其他平台下载的，但下载素材要经过二创处理。

更推荐用随拍视频，或者一张图片。图片可以在各大平台搜索，但很多平台上的图片都被使用过，很难过原创。这里有个技巧：可以用AI绘画制作图片。

随拍素材很好获取。大家平时出门时，可以拿手机随手拍一些风景视频，或者用行车记录仪视频，这类素材原创度很高。刚开始开通权限时，最好不要用搬运、剪辑拼凑的视频，否则难以开通创作分成计划权限。

第二步：文案获取

文案比较简单，参考并提取同行的即可。

这类文案非常多，去百度、抖音、小红书、快手随便搜一下就有很多，提取视频文字即可。

比如打开抖音或视频号，搜索“儿女祝福”，随便找一个数据较好的视频文案。有的视频标题就是文案，可以直接复制；如果没有文案，可以借助提取文案工具。比如使用小程序“轻抖”，点击文案提取，把复制的链接粘进去，点一键提取文案，复制文字即可。

如果是图文类内容，直接截图，提取文字即可。目前提取文案工具很多，我使用比较多的是配音神器上的工具。

第四步：创作视频

视频制作目前常用两种方法：一是用视频背景制作，二是用图片制作视频。

制作软件推荐剪映（官网：https://www.capcut.cn/），比较方便，剪辑效果也不错，手机端、电脑端都能用，制作相对简单。

类型一：实拍素材制作视频

拍摄视频时，一定不要静态拍摄，而要移动手机拍。最好在拍摄时运用远近变化，这样拍出来的画面更有感觉、更有动态感，做出来的视频效果也更好。如果一直盯着一个地方拍，成品效果会差一些。

这就需要大家在拍摄时注意细节，不然制作出来效果不行。

拍摄时，视频尺寸最好是9:16格式，这样拍完可以直接使用，不需要再调整视频比例。

视频可以拍长一点，再用切割软件切分成十秒左右的片段。切割软件可以在软件库里找，里面会提供一些我们常用的工具。

① 打开剪映，点击开始创作（以手机端操作为例）。

导入拍摄好的视频素材，15秒左右就可以，不用太长。然后点击左下角“高清”，点击添加，关掉视频原声。

[PRE36]

② 点击“添加音频”，然后点击“提取音乐”。

找到配好的配音后，点击“仅导入视频的声音”，然后把它拉到最前面；视频比例调到9:16，双指按住稍微拉大一点。
