# 创业认知的5个真相

创业这件事，真正的分水岭往往不在资源，而在认知。今天这篇合集，浓缩了5个关键的创业认知，帮你避开隐藏的坑。

01 认知比努力更稀缺  
努力决定底线，认知决定上限。同一个风口，有人看到机会，有人看到风险，差别就在思维框架。

02 规模不等于安全  
很多项目不是死于太慢，而是死于太快。盲目扩张会让团队和现金流同时承压，稳得住，才能走得远。

03 用户需求高于个人想象  
创业最容易踩的陷阱，是自嗨。真正的好产品不一定惊艳，但一定切中需求。多听用户的抱怨，才找得到答案。

04 团队默契胜过单打独斗  
一个人可以走得很快，一群人才能走得更远。创业路上，靠谱的伙伴就是最好的弹药。

05 复盘让失败产生复利  
失败不可怕，可怕的是白败。每次跌倒后认真复盘，错误就会变成别人没有的经验。

这5个认知，不是什么高深理论，而是无数创业者用真金白银换来的教训。看完之后，不妨对照自己，看看哪一个最值得先补上。
