# 3.3.1.3 注意事项

1. 黑箱设置要留意：教程里演示用的是处理过的字段，实操时记得加上“屏蔽”提示，手机号、金额、地址这类信息不能直接展示给用户。

2. 字段命名要统一：团队协作时，表格字段建议按“查询_内容”或“写入_内容”来命名，方便识别和调用，不要随意起名。

3. 上传前先清洗数据：用 Excel、Python 或大模型把表格处理干净，去重、补全字段名，否则后面操作容易反复出问题。

4. 接口调用要盯用量：飞书、Coze 每天有免费额度，大模型超额会产生费用。图片、视频等高成本插件，建议设置预警，或按账号分开使用。

5. 功能别一口气做满：前期先聚焦一个角色/场景，把流程跑通。功能越少越聚焦，反而更容易见效。

6. 权限和版本要控好：飞书表格建议限制字段编辑权限，开启版本管理，防止误删或难以回退。

7. 有对接需求要提前考虑：未来如果要联动企业🛰️、邮件等，字段名现在就统一好，避免二次改接口。

8. 数据调取要记得节流：表格行数过多时，启用分页或条件查询，别让前台卡死或超时。

# 3.3.2 企业培训知识库应用 @飞掌柜

现在有不少企业，或者企业里的部分部门，又或者部门里的少数同事，都有知识库建设需求，主要希望实现三个目标：

1. 历史资料沉淀：工作时间越久，部门里积累的资料越多，经常想不起哪个是最新版，找不到某份具体资料，甚至忘了曾经有过这份资料。所以需要有地方统一储存和整理。

2. 信息快速调用：员工有时需要查资料来回复客户问题、解答合作方疑问，或者用于内部培训学习。能针对资料快速提问、快速拿到答案，是非常实在的刚需。

3. 沟通分享便捷：不少老板跟我说过，公司数据太多，尤其是 PDF 这类文件，出门在外常要手机打开看，🛰️发给同事又容易过期，还得麻烦对方再发一次。如果有个地方能一键找到，沟通效率会大幅度提升。

以上这些痛点，都可以通过搭建企业知识库来解决。

# 3.3.2.1 企业培训知识库常见类型

企业知识库在不同行业有不同的搭建方式，网上也有一堆操作教程。据掌柜观察，常见类型大概有这几种：

1. 做进某个专业的 IT 系统里：系统自带完整的知识库全流程管理，包括增删改查、目录树等，方便灵活查询。

2. 借助企业🛰️、钉钉、飞书等平台搭建：比如企业🛰️里的微盘、钉钉里的 HelpLook 知识库工具、飞书的知识问答，都属于专业 B 端知识库，能做权限管控，数据安全有保障。

3. 用 Coze + 飞书多维表格搭建：这种常见于小型公司和团队，或者本身就用飞书的企业。他们的知识大量沉淀在飞书上，通过 Coze 工作流能延伸出更多应用场景。

4. 借助网盘类工具存储：比如微盘（企业🛰️中）、百度网盘、夸克网盘、阿里云盘、迅雷网盘等。优点是空间大、转发方便，缺点是容易信息泄露。

5. 使用公开 AI 知识库工具：比如 ima、get 笔记、飞书知识问答、知乎直答、纳米 AI 知识库等。这类工具更面向小企业和 C 端用户，适合对数据安全要求不高的公司。
