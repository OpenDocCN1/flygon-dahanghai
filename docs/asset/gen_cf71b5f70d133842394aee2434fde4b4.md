# 让 DeepSeek 更懂你：从提示词到海报自动化

想让 DeepSeek 准确接住需求，别急着堆形容词，先把指令写清楚。结构化提示词框架能把模糊想法拆成可执行细节，常见的就有 RTGO 和 CO-STAR。

**RTGO 框架**：先定角色（Role），再定任务（Task），接着写目标（Goal），最后补操作要求（Objective）。

- 角色：设计师、艺术指导等。
- 任务：生成科技感、未来感的海报设计。
- 目标：抓住年轻受众，突出科技创新。
- 操作要求：排版简洁，加入赛博朋克元素。

**CO-STAR 框架**：另一套经典结构，适合生成更有创意、更多样化的设计方案。

- R：想要的回应类型，比如图像、海报设计、样式效果。
- C：上下文背景，比如品牌背景、产品信息。
- O：设计目标，比如品牌宣传、吸引目标受众。
- S：风格要求，比如现代、复古、科技感。
- T：语调，比如正式、轻松、活泼。
- A：受众，比如年轻群体、科技爱好者。

例如清华大学公开的一套提示词方案，可以这样拆：

- 角色：海报辅助设计 AI。
- 功能：根据用户给出的产品名称、海报主题、风格要求，自动生成高质量提示语，帮助 AI 工具做出吸引用户的海报。
- 技能：熟悉海报构图、色彩搭配、字体风格等视觉要素；能围绕不同主题产出有创意的提示语，覆盖风格、细节、灯光等描述；理解市场营销、品牌定位和用户心理，让海报既吸睛又贴合品牌调性；适配极简、高端、赛博朋克、国潮、手绘、复古等多种风格。
- 约束：提示语要清楚表达设计要求，避免模糊和歧义；必须包含产品名称或海报主题的中文字符；避免冗余，保证高效精准；考虑目标用户，确保风格匹配品牌或产品定位。
- 工作流程：1、询问用户的产品名称或海报主题；2、收集用户对风格、色彩、构图、背景等的具体需求；3、结合需求生成精准提示语，覆盖设计要素；4、确保提示语适用于 AI 生成工具即梦；5、给出最终优化后的提示语，保证可读性和可操作性。
- 输出格式：完整的提示语内容，包含海报构图、色彩、风格、细节描述。

示例：产品名《未来都市》时，提示语可以这样组织：“未来都市”四个大字放画面正中，科技氛围拉满；高楼用赛博朋克语言处理，霓虹交错，深蓝、紫色打底，叠金属质感，营造未来世界的沉浸感；背景再加入漂浮全息广告牌、空中交通、赛博战士等元素。

**选风格：给设计定调**

在给出文字描述后，DeepSeek 可以让用户挑一种设计风格。风格会直接左右画面观感和情绪表达。它内置了多种预设，按设计需求选最合适的即可：

- 简约风格：强调清晰排版和简单元素，适合高端、现代感强的设计。
- 复古风格：强调怀旧和历史感，常用经典字体与柔和色调。
- 赛博朋克风格：典型的未来科技风，包含霓虹灯、金属质感和复杂图形，适合科技、未来感相关设计。

**自动生成：DeepSeek 怎么把描述变成海报提示词**

用户输入文字描述并选好风格后，DeepSeek 会基于这些输入自动生成海报设计提示词。过程大致分三步：

- 图像生成：根据“未来城市”“科技感高楼”“霓虹灯”等关键元素生成图像内容。
- 排版调整：按用户要求自动调整字体样式、大小和布局，让信息传达清晰，并贴合设计风格。
- 颜色搭配：自动选择与用户要求一致的配色，并应用到设计中，保证色调统一。

**拿到初稿后：用反馈把设计调到位**

初步设计出来后，用户可以查看 AI 生成的海报，并按需要反馈。DeepSeek 会根据反馈继续优化，直到用户满意。常见调整包括：

- 调整字体：按需求改变字体大小、风格和颜色。
- 修改图像元素：调整背景亮度、对比度，或替换部分图像。
- 重新排版：按反馈调整布局，让信息更突出。

这些反馈不只看视觉，也能微调情感和品牌调性。比如某品牌海报需要更强的“创新感”或“现代感”，用户可以根据生成结果调整整体设计，使其更符合品牌定位。
