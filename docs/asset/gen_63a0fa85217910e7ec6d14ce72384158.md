（二）用 AnythingLLM 在本地部署知识库

AnythingLLM 是一款全栈应用，它能借助现成的商业大模型或开源大模型，配合向量数据库，把任意文档变成一个私有 ChatGPT。它支持完全本地运行，也能远程托管，既不受制于人，又可以跟你手里的任何资料对话。

在 AnythingLLM 中，文档都放在“工作区（workspace）”里。工作区有点像线程，但多了一层“文档容器”的概念。不同工作区可以共享文档，彼此之间互不干扰，这样每个工作区都能保持独立的上下文环境。

你可以把它想象成一个私人“资料库”：所有文档和笔记都存进来，再配上内置 AI 文档引擎，它就能直接基于库里的内容作答。引擎可以接入 ChatGPT 等大模型 API，也可以在本地部署开源模型。

这次我们要用的，正是 AnythingLLM 对外开放的知识库 API。

2. 用 OpenClaw 给你的企业做一套对外 AI 客服

这一节，我们学习如何把企业微信客服接入 AI。设置好之后，客户扫码就能和你的 AI 知识库自动对话。

**先花两分钟看懂运行原理**

先别急着动手，把整条链路搞清楚，后面就不会卡壳。

[PRE69]

有三个词后面会反复出现，可以先混个脸熟：

| 名词 | 一句话解释 | 打个比方 |
| --- | --- | --- |
| 微信客服 | 企业微信里的功能模块，专门服务外部微信用户 | 相当于淘宝店的“在线客服”入口 |
| 回调 | 企微收到消息后，主动推送到你服务器上的指定网址 | 你留了地址，快递员直接送货上门 |
| OpenClaw | 开源 AI Agent 平台，你的 AI 客服跑在上面 | 一个“AI 调度中心” |

接下来要分清两个后台，不然特别容易配错地方：

1. 企业微信管理后台：https://work.weixin.qq.com/wework_admin/frame
   主要用来创建自建应用，后面补可信 IP。

2. 微信客服后台：https://kf.weixin.qq.com/
   这才是本教程的主力场地。创建客服账号、找 openKfId、配置回调 URL、生成 Token 和 EncodingAESKey、拿 corpSecret，都优先在这里操作。

你需要收集 5 个值。以微信客服后台为主，收齐下面 5 项，再填到 OpenClaw 里：

| 序号 | 配置项 | 值 | 建议获取位置 |
| --- | --- | --- | --- |
| 1 | 企业 ID（corpId） | 待填 | 微信客服后台 → 企业信息 |
| 2 | 客服账号 ID（openKfId） | 待填 | 微信客服后台 → 客服详情；页面没显示就用接口兜底查 |
| 3 | 回调 Token | 待填 | 微信客服后台 → API 配置 |
| 4 | 回调 EncodingAESKey | 待填 | 微信客服后台 → API 配置 |
| 5 | 微信客服 Secret（corpSecret） | 待填 | 微信客服后台 → API 管理，回调验证通过后获取 |

这里有两个坑要提醒：

1. 第 5 个 Secret 不是自建应用的 Secret，而是“微信客服”自己的 Secret。
2. openKfId 有时候页面里显示不明显，甚至一时找不到。别卡在这里，后面可以通过接口查出来。
