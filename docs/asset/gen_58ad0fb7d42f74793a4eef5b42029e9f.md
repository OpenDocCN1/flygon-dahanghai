# 流浪猫猫屋申请刷屏养宠群，这件事真值得聊聊

最近，小区里有人递交了流浪猫猫屋的申请。消息很快就在各个养宠物的社群里传开了，大家你一言我一语，讨论得非常热闹。说实话，我觉得这是一件特别有价值的事情。

点开评论区，也能看到不少走心的回应。有人提到，每次看到流浪猫都觉得一阵心酸，自己帮不了太多，最多就是随手留一点猫粮，真心希望有更多实实在在的救助能落到它们身上；也有人抱着观望的态度，认为眼下还看不清这件事最终会长成什么样子，但在现阶段，通过提供相关的配套服务来赚钱，或许也是一个方向；还有人直接给出了“中标”的评价，相当于给这个项目加了一点术值。

另外，有一条留言让我印象深刻：“只要没有人去伤害它们，流浪猫同样在享受绝对的自由。”这话带着点哲理，但无论说法如何，为它们多建一个猫屋，总意味着多一份安身的可能。
