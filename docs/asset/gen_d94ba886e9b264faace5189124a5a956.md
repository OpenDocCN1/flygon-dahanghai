# 14.3 关键词公式与大师彩蛋

老规矩，先复习一个关键词公式：设计类型 + 主体 + 主体设定 + 风格设定 + 质量词，质感词可作为补充项。设计类型指生成对象的类别，例如室内、建筑、椅子、餐桌、沙发等设计方向；主体设定负责描述材质、形状、颜色等细节；风格设定可以选北欧、包豪斯、现代、田园、复古、地中海、阿拉伯、工业、波斯等；质感词如坚硬、柔软、粗糙，有时会带来额外惊喜。

再分享一个秘诀：用谷歌搜索一些著名的室内设计师、建筑设计师，把他们的名字放进MidJourney提示词中，结果往往会出人意料。下面几位值得收进你的提示词库：

- 菲利普·斯塔克：法国设计大师，产品、家具、室内设计都有涉及，代表作包括皇家度假村酒店、法拉利车间等，风格简洁而实用。

- 扎哈·哈迪德：伊拉克裔英国女建筑设计师，人称“女王建筑师”，作品以流线型与前卫夸张著称，代表作包括广州歌剧院、阿联酋摩天大楼。

- 彼得·马里诺：美国建筑师与设计师，专注高端奢华风格，服务过路易威登、香奈儿、迪奥等品牌，在纽约、巴黎、东京、米兰等城市都有作品。

- 潘妮露·琼斯（Patricia Urquiola）：西班牙室内设计师，擅长把简洁大方和温馨惬意融为一体，曾为意大利品牌Moroso、德国品牌Walter Knoll等设计产品和空间。

- 罗斯·班斯纳（Ross Lovegrove）：英国设计师，既做室内也做建筑，作品强调流畅感和强大功能性，代表项目有伦敦queens大酒店和德国汉诺威体育场。

- 阿曼达·莱文达尔（Amanda Levete）：英国建筑设计师，风格简洁且富有创新精神，曾是FOA建筑设计事务所的合伙人之一，代表作包括伦敦V&A博物馆外立面、葛兰者广场。

- 大卫·芝兰（David Chipperfield）：英国当代建筑大师，设计风格讲究简洁素雅，代表作包括柏林新博物馆、伦敦爱乐音乐厅翻新工程等。

话说回来，AI绘画在室内装饰领域目前还没有体系化的变现路径，但也意味着机会。不妨做一个先驱者，亲自下场探索。
