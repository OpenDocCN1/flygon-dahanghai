# 3-4人小团队，亚马逊精铺利润翻倍怎么做？

冰箱里那只鸡蛋收纳盒能成为电商选品，蔬菜、水果置物盒是否也能复制？再往厨房其他物件上想，是否同样成立？

我目前操盘亚马逊，走的就是这条思路，月销售额大概60万美元。下面结合自己的实践，从选品、团队搭建等方面聊聊怎样用精铺模式把亚马逊做好。

一、我的经历

我的经历大致是：2018年用几千元试水国内一件代发；2019年销售规模超过800万元；2020年国内业务走低，同时把精力转向亚马逊；2021年亚马逊做到60万美元，2022年上升到380万美元，2023年当前月销售额在60万美元左右。

亚马逊常见的玩法有精品、精铺和铺货。精品偏向红海爆款，精铺面向小爆款或需求较低的市场，铺货则是靠海量产品博概率。我们现在做的是精铺。

刚接触亚马逊那会儿，我并不知道这三种模式，只是从自己能切入的方式开始试。店铺数据跑出来后，才搭建团队、解决供应链；随着产品、经验和供应链不断积累，销售数据也逐渐起来。

二、精铺模式的机会与选品

相比国内电商，亚马逊竞争系数更低，加上汇率因素，整体ROI更高。入行以来，美元兑人民币汇率最低6.4、最高7.3，目前ROI能做到3左右。

精铺模式的核心在选品和跟品。选品不要求一上来就爆，日销几单就能切入，客单价20美元上下；积累一段时间后，有些产品也能做到月销800单左右。

选品灵感来自熟悉的产品、能触达的供应链和身边随处可见的东西。比如厨房里的鸡蛋收纳盒，通过反查亚马逊数据，发现竞争不大，或者能找到优化空间，1688工厂也能配合，就值得试。

以egg holder为例：前台调研发现某款月销9000件，亚马逊配送费5.69美元，15%佣金1.5美元，回款为9.99-5.69-1.5=2.8美元；1688拿货成本9.26元人民币，折合不到1.5美元，头程海运约1美元，回款只剩2.8-1.5-1=0.3美元，还没算退货和广告。毛利率只有3%。不过在不断找品、验证中，选品技能、供应商沟通能力和产品分析能力都会积累。

三、团队搭建

① 合伙人：

现货测试跑通数据后，找身边价值观一致、有信任基础的朋友一起做。跨界小白不需要电商经验，也不需要资金投入，前提是彼此信任、尊重；价值观不合、工作不闭环的不考虑合作，避免后期内耗。如果喜欢自己打造，也可以招人，更可控。

② 运营：

新人进公司会分到1个有业绩的老店铺和1个新店铺，业绩提成按3%-10%阶梯式。有运营基础后，再多配1个新店铺，为下一位小伙伴做准备。

新伙伴加入时，老员工要贡献一个老店铺给新人，这算一种传承。老店铺交出去后，老员工只负责指导新人、协助完成销售，但这个店铺的提成会降50%。等新人成长起来，老员工基本不用再管该店铺，可以把时间精力放回自己的店铺，享受被动收入。

新员工再培养下一位时，第三位员工的业绩只和第二位员工挂钩，被动收入只享受第二层级。员工培养下一位时底薪增加1000，但贡献出去的店铺提成降低50%（原本每月拿6%，共享后只拿3%）。每位员工的业绩提成比例一致，层级也一致，大家都可以培养更多员工；不喜欢带人的，也可以专心做好自己的店铺。

③ 协议：

针对性拟定合作协议、退出机制、持股比例等。

④ 选品：

上架测试过的产品，并横向延伸同类产品，最好来自同一个供应商。

⑤ 文案：

打造listing，向供应商要素材图，淘宝协助修图；在文案可读的前提下埋入部分关键词。卖家精灵有listing生成器，前期学习可以参考。

⑦ 分红：

合伙人模式前期由公司投入，当总回款大于总投入+预留资金时，超出的部分按比例在次月分红。比如创始至今总投入20万元，亚马逊回款50万元后，预留20万元用于公司周转，另外10万元可以拿出来分红；预留资金随库存和周转资金可商讨调整。

无论合伙人模式还是招人，前期有测试过的产品加持、各流程已跑通，能少走摸索弯路，提高成功率。团队合作前期，尽量让问题出现得更多、更快，有助于磨合和建立信任。

四、亚马逊的切入机会

亚马逊模式分为铺货、精铺、精品。测算逻辑是售价-佣金-尾程-成本-头程。佣金按类目收取，参考：
https://sellercentral.amazon.com/help/hub/reference/GTG4BAWSY39Z98Z3
尾程按体积、重量、长宽高等维度判断，参考：
https://sellercentral.amazon.com/help/hub/reference/GABBX6GZPA8MSZGW
头程海运按体积、重量计算，20公斤起，目前慢船美西时效约40天；空运也看体积重量，一件也能发，时效5-7天。

尾程和头程都有重量体积参考维度，所以轻小商品更有优势。可以借软件工具选品，比如卖家精灵：
https://www.sellersprite.com/
它的选市场功能能按自身情况筛选条件。

举个例子：选市场-月销量小于800-售价大于16$-毛利率大于50%-新品数量大于20%（软件里有很多视频可学）。筛选后发现Executive Desk Toys（办公桌玩具），前台搜索结果数量532。
