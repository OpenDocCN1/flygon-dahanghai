**1.2 认识 Obsidian**
Obsidian 是一款本地知识管理与笔记软件，特别适合习惯 Markdown 写作、想搭建个人知识库的人。它本质上仍是 Markdown 编辑器，但亮点在于双向链接：用 [[]] 语法把笔记连起来，形成知识网络；关系图谱还能把所有关联可视化。
核心优势：
- 数据留在本地：笔记就是纯 Markdown 文件，存在自己电脑里，不靠云服务，隐私更稳，也不怕服务商停运。
- 双向链接 + 知识图谱：这是它和普通笔记工具拉开差距的地方，能把零散内容织成体系。
- 插件生态很丰富：社区插件上千，日历、看板、数据库视图、思维导图、服务集成等几乎都有。
- 可定制程度高：主题、快捷键、工作区布局都能按自己的习惯调。
适合人群：想搭“第二大脑”或个人知识库的人；喜欢 Markdown 写作的人；学生、研究者、写作者、程序员；以及在意数据隐私、不愿把笔记放云端的人。
费用方面：个人使用免费；官方多设备同步 Obsidian Sync 和发布功能 Obsidian Publish 收费，但也能用 iCloud、Git 等免费方案自行同步。
对比来看：Notion 更偏在线协作和数据库；Logseq 理念接近，不过 Obsidian 插件生态更成熟，而 Logseq 默认用大纲模式组织内容。
上手建议：先别追求完美体系，随手记，慢慢用双向链接把相关内容串起来，知识网络会自然生长。可以从 Daily Notes、Templates、Outliner 等核心插件开始了解。
一句话，Obsidian 起点简单、上限很高，值得一试。

**1.3 安装 Obsidian**
官网：https://obsidian.md/
Windows：打开下载页 https://obsidian.md/download，下载安装包 [PRE14]，开始安装 [PRE15]，权限提示选“是” [PRE16]，选择路径 [PRE17]，等待完成 [PRE18]，点“完成” [PRE19]，桌面会出现 Obsidian 快捷方式 [PRE20]。后续设置继续看下一节。
Mac：同样访问下载页，直接点下载 [PRE21]，双击打开 DMG [PRE22]，拖到 Applications 文件夹 [PRE23]，安装完成；在启动台就能看到图标 [PRE24]。

**1.4 初始设置**
Obsidian 的文档都要放在“仓库”里，所以先建仓库。点“创建” [PRE25]，进入下一步 [PRE26]，浏览时建一个专门存放 Obsidian 文件的目录 [PRE27]，之后会进入默认首页 [PRE28]。

**1.5 基础操作**
新建笔记：在左侧列表右键，点新建笔记 [PRE29]，默认界面如下 [PRE30]，接着直接改内容 [PRE31]。
修改笔记：直接输入即可。
插件安装：按图操作，第一次进插件要先关安全模式 [PRE32]，点“浏览” [PRE33] 查看社区插件 [PRE34]。

**2. Claude Code 与 Obsidian 的实操准备**
重头戏来了。Obsidian 负责知识库管理，Claude Code 充当 AI 助手，辅助你更好地管理知识库，让 Obsidian 成为你的大脑。💡Claude Code + Obsidian 的组织方式很多，下面讲一种多数人最容易接受的。灵活运用的关键点：一是 Obsidian 的 canvas 画图、base 数据库等特性；二是把 Obsidian 仓库当成项目交给 Claude Code，原理和方法与前面一致。

**2.1 准备仓库模板**
为了更好上手，先准备一个新的 Obsidian vault 仓库。这里有一个别人做好的知识库管理模板，没有自己知识管理体系的可以基于它搭建，熟练后再调整成自己的目录；也可以选别的模板，关键是用起来。如果已有大量 Obsidian 文件，可让 Claude Code 结合知识管理、卡片管理等理论，帮你梳理并重排知识体系的层次目录。
模板地址：https://github.com/MarsWang42/OrbitOS/blob/main/README_CN.md
在电脑上找好目录存放模板，地址栏输入“powershell”打开终端 [PRE35]，因为后续操作要在终端执行；Mac 可在目录右键选择终端打开，若没有该选项，可安装 iRightMouse。

**2.1.1 Windows 操作**
Windows 下命令操作可能失效，所以采用下载后直接解压的方式。访问 https://github.com/MarsWang42/OrbitOS，点击下载按钮 [PRE36]，下载完成后 [PRE37]，拷贝 CN 目录，它就是最终的 Obsidian 仓库目录 [PRE38]；我把它重命名为 orbitos-vault [PRE39]，你也可以命名成自己想要的名字，目录名最好用英文。
