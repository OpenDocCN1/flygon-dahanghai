# 2.1.7 来源七：故事就在身边

很多素材，最初都藏在闲谈和八卦里，哈哈。

我写下的故事都有真实原型。比如后面那篇《一个丰乳肥臀的女人的一生》，写的就是我亲戚家的经历。旁人听到那些不合伦理的旧事，往往只当八卦，甚至觉得听完纯属浪费时间；可在我眼里，它们都是可用的写作材料。

小人物身上，同样能照见大道理。所以我的笔下多是普通人的故事，而不是人人皆知的大人物。

如果你还没写过人物故事，不妨先翻翻前文那几个范例，照着模仿，上手并不难。要是你本来就常写故事，那就建议给自己加点难度，试试人物更多、主题更深、带有连载感的故事。
