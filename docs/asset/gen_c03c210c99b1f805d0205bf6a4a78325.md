# 非洲外贸，机会怎么抓？

欧美市场卷得厉害，非洲外贸对个人背景要求没那么高，其实是条值得留意的掘金路。可对多数人来说，非洲生意仍显得神秘：什么货好做？怎么和当地人打交道？跟熟悉的欧美外贸有啥不同？本期「一起赚美元」请来常驻非洲多国、操盘过进口肉类、进口快消品、出口机械设备、轮胎、空调、化肥等品类的“非洲生意通”外贸人老师，重点聊聊选品。欢迎分享。

---正文---

感谢鱼丸给我在生财有术和大家交流的机会。我常驻过非洲多个国家，也实操过多种产品的国际贸易，希望这次分享能抛砖引玉，认识更多对非洲贸易感兴趣的朋友，互相学习、合作共赢。

一、非洲贸易的优势盘点

非洲贸易不挑个人背景，当地年轻人多、愿意尝新。只要肯干，平台、模式、商品、伙伴选对了，赚钱相对容易。开发客户时，有针对性广撒网，再加上口碑传播，效果会很不错。非洲产品原生态、污染少、议价空间大，国家也鼓励进口当地好货，所以无论进口还是出口，都有不错的贸易优势。

二、非洲贸易的风险与注意事项

非洲商机多，但不规范、骗子也不少。安全、疾病、汇率、信用、物流以及所在国政治等风险都要防。第一次去，最好有非常信任的人带路；没有的话，尽量选知名度高、评价好、正规的企业做平台，签证手续也要规范。出门随身备零钱，护照原件一定收好。起步尽量从自己熟悉的领域切入，专业是取得信任的第一步。做实体贸易，优先选外汇容易兑换且相对安全的国家：南非大部分地区（约翰内斯堡部分区域除外）、博茨瓦纳、纳米比亚；西非的科特迪瓦、加纳、喀麦隆；东非的卢旺达、肯尼亚、坦桑尼亚等。电商发展较好的则是南非、肯尼亚和埃及。安哥拉、莫桑比克等葡语国家外汇兑换难度较大；苏丹、津巴布韦受西方制裁，小规模实体贸易起步会更难。西非和中非的乍得、马里、布基纳法索，东非的索马里、埃塞俄比亚提格雷州，南部非洲的莫桑比克北部，目前治安都不好；同时也要关注各国疫情防控状况。

三、进口贸易怎么选品

做贸易要时刻盯汇率。近期汇率走势对进口有利，所以先谈进口选品；等规模起来，进出口可以同时做，在汇率上形成对冲。

1. 进口农产品怎么挑

非洲农产品和水果有时效性，主要打国内反季节销售。比如卢旺达、埃塞俄比亚、乌干达的咖啡（不少日本品牌咖啡其实原产于埃塞俄比亚），卢旺达的辣椒，贝宁、埃塞俄比亚、坦桑尼亚的大豆，南非的鲜葡萄、苹果、柠檬、葡萄柚、橙、柑橘等水果，南非的苜蓿草，肯尼亚的冷冻牛油果，尼日利亚、莫桑比克、坦桑尼亚、苏丹的芝麻，马达加斯加的丁香等。

以非洲大豆为例：先到海关网站查该国农产品商家准入名录（名单里的商家未必都是厂家，也可能是经销商）。进入名单的商家一般经过海关（原质量检验检疫总局）审核，有初步信誉；名录上有联系人邮箱，可以逐一发正式询价邮件，对比后挑回复专业、正规的商家深入谈。通过邮箱和公司名也能查到网站，最好先要些样品。当地有可信朋友（尤其是业内或律师朋友）的话，最好实地考察。不熟悉对方时，付款首选不可转让信用证，尽量不选电汇；合同里写清当地验货标准、包装方式、违约条款；请当地朋友帮忙监装和发运，同时要求供货商出具SGS等权威第三方验货报告，并及时提供提单、原产地证等资料。

报价及时性很重要。以坦桑尼亚大豆为例，目前当地只有一家大豆商家获得准入；从准入名单的外方邮箱查到商家网站，发现网站有很多法文、在法国也有公司，于是第一时间通过坦桑尼亚的法国朋友联系上对方，拿到大豆报价。拿到报价后注意看有效期（一般几天到几周）、付款方式（信用证）、包装和运输方式（集装箱运输）。国内买家要找使用过非洲非转基因大豆的客户，起步期尽量让客户自己负责清关。

2. 进口冷冻肉类怎么挑

冷冻肉类分牛肉、猪肉、鸡肉。非洲目前只有南非和纳米比亚有厂家获得冷冻牛肉输华许可，但量不大。冷冻牛肉、鸡肉（主要是冻鸡爪和冻鸡翅）近期主要来自南美洲（巴西、阿根廷、乌拉圭、玻利维亚）以及俄罗斯等独联体国家。

以冷冻猪肉为例：曾通过非洲认识的朋友联系到获得准入的欧洲商家，先签买卖合同，约定好各个时间点和违约责任，买家预付一定比例定金，外方备货并发运。发运后外方先把提单及全套清关文件草本扫描发来，审核无误后买家付尾款，外方快递文件正本，集装箱到港后客户自行清关。曾先后成功进口数百吨，并建立稳定合作。肉类贸易本身难度不大，关键是选好靠谱合作方，再根据国内客户需要拟好对内对外合同，尽量选畅销部位肉（注意是否带骨带皮），盯紧价格波动，仔细审所有单据，避免到港清关延误。

现在南美洲的冷冻鸡爪和冷冻牛肉有一定性价比，但肉类价格波动大，南美国家政策变化也频繁（阿根廷曾禁止出口牛肉一个月），品质、数量参差不齐，还出现过厂家把同一票货卖给多个买家的情况；国内港口也普遍存在冷冻货柜滞港和增加消杀环节。因此起步期先和有经验的买家合作，控制好风险。等有一定实力，可逐步介入存储（如冷库）、加工环节，拓展自营销售渠道，尤其在综合保税区内对农产品和肉类做初加工；价格变化时，可以存储或借助供应链金融等升值再出售，也可直接深加工/分装（大包装变小包装）实现增值；猪肉已有期货，可以考虑与现货对冲。

3. 进口快消品怎么挑

欧洲、非洲有知名母婴用品、高端服装、家居用品在找国内代理商，关键看个人对哪些销售渠道熟悉。以母婴用品里的纸尿裤为例：先和国外厂家就国内（最好独家）代理权达成协议；再通过专业进口代理公司弄清清关流程和中文标签要求（标签一旦不合规，会很耽误事）。如果产品此前没在国内销售过，要让外方先发足够样品，事先到海关指定的危险品中心实验室拿到检验报告，检验合格才能顺利完成进口清关。欧洲产品的规格、相关标准和国内略有不同，需要在标签中写清楚。

四、出口贸易的客户开发与选品

出口要选好产品和合作伙伴，收款时注意货款来源正规清晰。做实体贸易，第一次见面很重要。每次接触前，我都通过朋友或互联网做足功课，按每个客户不同的侧重点准备介绍材料或特色随手礼；聊天时从对方感兴趣的事，或对方当下业务的痛点、难点切入，快速让对方看到双方互补性和成功可能，特色随手礼也能让对方记住自己。建立初步信任后，用积极快速的反应和一个个小项目累积信任，后来对方一些集成采购业务都委托给我的团队。另一个经验是已售产品的后续配件服务，比如发电机配件、水泵配件、车辆配件（轮胎等）、矿用机械配件等。能解决客户急需的问题，利于加深友谊。比如不少非洲国家疫情严重，不仅缺防疫物资，更缺医用注射器、疫苗冷藏箱、储存药品的冰柜；同时居家普遍喜欢音响、游戏机等。农业和安防方面，支持当地语言的无人机、高清摄像头都有广阔市场。日常用品中，除了假发，煤气罐及配件、蚊帐、驱蚊产品在网上营销效果不错。盲盒、手机游戏、手机音乐、手机叫车（除优步外，尼日利亚、肯尼亚、安哥拉都有国人在开拓）在非洲应有不错前景。

要扩大已有外国客户的采购量，先做好售后服务，保证买方问题能及时解决，树立好口碑，这主要靠和当地合作伙伴配合；也可考虑聘请非洲本土明星做平面广告（如流动车辆、机场、公路主干路、大型建筑）。疫情期间出国难度加大，扩大贸易规模要注意用好金融工具。这里重点说中国出口信用保险公司（国内唯一政策性出口信用保险机构，并非商业保险公司）的特险服务，中信保也能帮助审核外国客户资信。特险本质是卖方允许外国买方1—2年内分期付款，但通过投保出口信用保险来保障及时收款；南部、西部非洲银行贷款利息普遍高于15%，所以外国买方往往愿意承担保费换取分期付款。卖方拿到保单后，可凭保单在国内商业银行做债权买断，等于银行在货物发运后先把后续分期款垫付给卖方，之后外方分期还国内商业银行，一旦逾期，出口信用保险公司会代为追讨。除信保外，一些商业银行、保理公司也推出进出口贸易资金池、循环授信等业务，前提是外国买方足够优质（财务报表较好、负债率低、有一定行业知名度）并积极配合。优质客户并不容易找，因此可与在非洲有业务的欧洲、中东客户合作：在安哥拉、莫桑比克等葡语国家做贸易，可找葡萄牙人合作；在科特迪瓦、喀麦隆等法语国家，可找法国人合作。还要考虑国内与非洲的利息差、汇率差：南部和西部非洲银行利息年化普遍高于15%，汇率波动非常大；国内贷款利息4—6%，欧元、美元贷款利息不高于3%，合作空间很大。

一时去不了非洲，电商平台是很好的入手选择：阿里巴巴国际站、虾皮（重点东南亚）、京东出海（印尼、泰国站）、阿联酋NOON、非洲KILIMALL（肯尼亚）、JUMIA（尼日利亚&肯尼亚）、Takealot（南非）、Zando（南非）、Tospino（加纳）等；不少非洲电商平台对中国商家实行免费入驻开店政策。这些我也在学习和摸索中，之前在生财看到有人通过虾皮往东南亚卖小金龟很受启发；利用好时机、选好细分领域很重要，希望大家多交流、抱团发展，电商贸易和实体贸易融合创新会很有前景。评论区也有读者提到旧鞋出口非洲、后来在埃塞建厂，以及TikTok自媒体和Facebook营销值得关注；嘉宾回应可在非洲明星脸书投广告或做隐形带货。

五、如何找到潜力代理商或合作方

非洲谈生意比国内简单直接，但可持续性差，所以要不停开发新的优质客户，找到成长型代理商很重要。这需要勤奋广撒网，也讲点缘分；找准找好、共同发展，会得到长远收益。道理类似知名咨询公司更愿意培养有潜质的优秀毕业生，而不是靠猎头挖人。国内一个知名白电厂家非洲负责人曾分享经验：刚进非洲时，冰箱、电视机等都是日韩和欧美品牌的天下，当地不认可我们的品牌，只能联络不受日韩品牌重视的当地代理商（尤其有优秀教育背景的年轻代理商），或日韩品牌代理商中被边缘化的经理人；通过更好的合作态度、更贴近客户的产品改良（当然还有更好的价格和售后服务）赢得这批代理商支持，再辅以合适广告宣传，逐步扩大知名度，之后合资设立组装厂、发展工业园区，渐渐成长为非洲知名度名列前茅的白电品牌，海外销售额占集团总销售额30%—50%。合作期间多留意伙伴需求，提出共赢建议。比如合作伙伴参与当地电站/医院建设及设备供货，可尝试洽商共同参与电站/医院运营，参与耗材和用品供应。手机中的传音在这方面也做得很好。

六、非洲贸易的前景展望

在非洲创办企业不难，很多模糊地带可以人情化处理。过去传统贸易主要靠不停跑客户，客户下单后安排发货，到港后跑清关，不厌其烦地交流、解决各种问题，满足客户五花八门的要求，逐步筛选出互相信任、共同成长的重点客户。其实适应语言、文化习惯差异，克服安全、疾病等问题后，把前期工作做扎实、选好合作对象，剩下的低买高卖并不复杂。但眼下非洲疫情态势和科技日新月异的发展，让过去经验已不完全适用。未来应是电商平台与实体贸易结合，增加产品附加值，打造差异化的非洲品牌。进口方面，可多个伙伴合作批量采购、分散出货、加工增值；出口方面，利用电商平台开拓新客户，并运用各种金融工具做大与优质客户的贸易额，在细分领域做出名气。南非、埃及等经济较好的国家有不少支持创业的基金，在非洲上市也可望可及。期待生财有术非洲创富群。
