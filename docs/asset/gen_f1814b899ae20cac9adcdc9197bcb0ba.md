# 2.1.8.2 价值观输出，素材从哪里找？

做价值观输出，最常被问到的就是“没素材怎么办”。其实只要你愿意留意，生活里到处都是。

先说文字类平台。微博、公众号、朋友圈，基本以文字为主。遇到让你心头一动的观点，别只是点赞收藏，直接截图转出来，再补上几句你自己的看法，一段有态度的输出就完成了。

再说短视频。刷视频这件事，本身就是灵感来源。很多时候刷着刷着，脑子里就会冒出“这话我也想聊聊”的冲动。别小看这种冲动，它往往就是价值观输出的起点。

然后是阅读。比如猫叔那本《一年顶十年》，书里不少话本身就是价值观输出。挑一段让你有感觉的句子摘下来，配一个自己的亲身经历，别人读起来既有共鸣，也有启发。得到上不少老师的书，也是同样道理。

最后是聊天。我差不多每天都会找十个人聊上几句，这个习惯保持了六年多。说实话，我的很多价值判断并不是自己闷头想出来的，而是在与人交流中逐渐清晰的。不管是私聊还是群聊，聊着聊着，观点就出来了。

所以，别怕没素材。文字、视频、书本、对话，只要愿意输入、敢于表达，价值观输出随时都可以开始。
