# 杭州这家升学E网通，凭什么闷声月入过亿？

你可能没怎么听过杭州的“升学E网通”，但这确实是一家低调到不像话的赚钱机器。

它的App和网站主要提供四块服务：高考志愿填报、网课、心理FM、中学生社区。据说目前月流水已经接近一个亿。

玩流量的人看到这个数字，第一反应大多是：这类产品线上能卖得动？答案是，放在线上还真卖不动。

真正的玩法在线下：公司养着几百号销售人员，把全国各地的学校和教育局发展成代理渠道，再通过他们向学生销售。学生最终掏360元就能拿下，而软件内标价却是六百多，学生一看“挺划算”。要知道，早期只卖200元，后来大概觉得太好赚，直接提了价。

这家公司原本靠高考志愿填报系统起家，这几年又拓展了更多在线教育板块。有意思的是，面向学校领导的销售远比面向普通用户容易做，于是营业额一路暴涨。
