# 社交的底层，是能量互换

小蚁有篇精华帖，题目大意是：销售能频频成交，底层靠能量流动。文章本身也扎实，例子鲜活有趣。借这个意思，我想补一句：优质社交，底层同样是能量在人与人之间流动。

## 2. 先离开消耗你的圈子

早些年我换过两次东家。每个阶段目标不同，我总在找下一步出口。

前一家：班表长得吓人，学习时间被榨干；周围同事大多一脸倦，打不起精神。清早七点钟离家，洗漱、换上正装、化妆都像走流程，下楼坐公司班车，被送到工位后不停转，直到深夜十一点才回住处，循环往复。

人在那种连轴转的氛围里，单靠意志很难不被拖住；越是这样，越要主动给自己换土壤。后来逮到机会离开，我去了后一家：人员配比科学，职责边界清楚，一般晚上七点前后收尾；食堂吃完晚餐，八点回公司给的珠江边公寓，条件不错。歇脚、健身、翻书、上课都有余量。更关键的是，擅长谈单的人一抓一把，我暗中观察同事，学他们怎样把客户的不合理要求挡回去，还不让场面难看。可我也发现，大家普遍松弛，享受现状，不少人盘算着一直干到退休。我不想。因为我的主管、以及主管上面的那位，他们现在的样子，基本就是我五年、十年后的模板……

还在后一家公司时，我偶然撞见生财，像多出一块新地图。过去那股“说不清却很确定”的野心，终于有了回声；那种迷茫、不知去哪找答案的卡顿，也一点点松动。旧圈子里总有人嘀咕：你折腾这些图啥？我一度以为身边没人同频，结果在生财碰到一群聊得来的人。去年我再度离开那家公司，改成自由职业，把日常社交圈换成生财圈友。走到现在，我才有种归位感。

## 3. 找到长板，把自己磨成一道激光

光合在线下见面会那次，我第一次把这件事听进心里。他在一篇讲破圈成长的文章里也写过（链接：https://t.zsxq.com/nmUFYNb）。大意是：成功绕不开时间复利，成长急不得。挑一个自己拿手的方向，把时间狠狠压进去，每天只往前挪一点，像激光那样持续打穿，圈层会被打开。人容易把一年看得很重，却把十年看得很轻；一束能坚持十年的激光，力量难以想象。

当时我听完，体会很朴素：别东张西望，只盯一件事，像激光一样打穿，做那个领域里最扎眼的人。如今再读，我有了新一层体会：选对拿手领域是第一步，也是最难的一步。有人终其一生也未必找得到；我就是例子，到现在还没锁定。

亚马逊算我在生财试过的又一个方向，也是关键拐点；靠它我才攒到人生第一笔像样的钱（顺利的话，大概七位数）。可这个领域未必是我的长板。反观光合，更像老天赏饭：短短几年自己蹚出一套避开红海的打法，带着队伍做到年利润千万级。他聊产品时，你像在看一段电影，那个平日寡言内向的人忽然有了光，眼里只有产品，像换了个灵魂。我这边几乎没有电商直觉，靠死磕和红利运气，才险险拿到一点结果。

社群里不少人和光合，已经把自己打磨成生财里辨识度极高的一束光。聊起某个领域的行家，大家总会把名字落到同一个人身上。这就是激光的威力。找到拿手的事，开心深挖，顺手领先，这大概就是值得追的方向。

最后，如果你也像我当初那样焦虑，送你一段我一直收着的话。是光合早年转给我的（@李晨 分享），很受用，一起共勉：

努力和成功之间不画等号，但肯下功夫的人更容易得到援手；这是从慢慢积累跨到跃迁的一道坎。你的投入被人认可，有人肯拽你一下，跃迁就出现了。

个人奋斗是立足的底牌，也是别人愿意信你、帮你的记号。

另外，越早攒出自己的代表作越好。做成过事，你会更敢做下一件，旁人也更有理由把事交给你；这是成事的地基。

不断向上走，到了顶上，遇见的多半也是顶上的人；眼界、看问题的角度、做事方式都会升级，这就是格局。无论代表作是大是小、靠实力还是靠运气，它都有用，真的。

人若无名，专心练剑。

感谢你愿意读到最后。愿我这段生财故事，能给你一点点推动。
