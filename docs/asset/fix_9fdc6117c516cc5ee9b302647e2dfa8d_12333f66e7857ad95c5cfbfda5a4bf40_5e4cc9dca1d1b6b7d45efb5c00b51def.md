# 微商团队，从靠人带到靠系统转

你好，我是小王子。微商做到第二个年头，我做了个决定：把组织架构推倒重来——不再沿用“谁招的人谁从头盯到尾”的手工作坊式管理，转而搭建一套能复制的标准流程。

旧模式是这样的：新人进来后，从文案培训到复购升级，全压在引荐人肩上。能力够不够、时间有没有，都得硬扛。有责任心的会认真带，没责任心的收完钱就玩消失，而且后者居多。

有一年，我们前后衍生出三十来支微商团队；可第二年再看，大半都垮了。复盘之后，原因归为四类：

头一条，从原团队分出去的负责人未必抽得出时间带人，本职工作忙、家里出状况，精力说断就断。  
第二条，自己卖货和带一支销售队伍完全是两码事，不少人原创能力跟不上，社群运营不会做，也鼓动不起大家的干劲。  
第三条，有些负责人只想挣快钱，收一波就走，压根没有长远打算。  
第四条，负责人硬生生活成了勤杂工，海报、课程、讲课、社群全自己上，时间一长累得够呛。

看清这些弊端后，我着手推行标准化、流程化。讲白了：代理只管把人引进来，剩下的统一送进微商学院这套“培训＋运营”系统里过一遍，出来就是能打的微商人。培训交给专人做，代理不必再把精力耗在带人上。

微商学院每期招 ninety 人上下，成员从团队里级别靠前的代理中选，专门为微商团队服务。（运营地图见图1。）

我让他们参与线上运营，一来卖货之外多学一门本事，二来团队不是我一人的，盼着大家拿出主人翁的姿态，一起把盘子做大。

微商学院底下分三个学院：

**导师学院**（两位院长牵头）：销售培训组，管新人培训、销售实战、朋友圈特训、故事课这些；产品知识组，负责讲产品知识，也承担招商会上的产品答疑；朋友圈组，做朋友圈培训、大型活动文案模板，还会点评代理们的朋友圈。

**运营学院**（两位院长牵头）：公众号组，把大群和大型活动的内容更新上去，基本做到日更；海报设计组，包揽日常分享和大型活动的海报设计；统计组，等同于财务，管活动经费的账；社群运营组，各大群、培训群、线上招商会群全归他们运营。

**流量学院**（我自己带）：教流量获取的法子，让代理们去学。

微商学院的人基本来自团队最高两个级别，对团队黏性更强、更忠诚，既练了技能，也对业绩有好处。这套体系跑了一年半，一直在迭代；每三个月招一次，新人有机会，老人也能带新人。团队实现了自动化运转，我也被解放出来，能去做更高层面的事。

它还是团队扩张的承接器：代理只要敢招人，后面随时接得住。去年下半年我越发强烈地感觉到，没有标准流程，大流量来了也接不住；大IP通常不会亲手带微商新人，我们把这块兜住，合作就没有后顾之忧。

## 2. 社群拆开，每个群只管自己的事

**基础群**共五个，所有级别的用户都在里头。目标是让大家产品用得开心、放心、有信心；每天有课程排着，大家在氛围带动下会自动升级、复购，促单的压力也小了。社群运营组会提前一周把下一周的课程排好，方便大家拿去做朋友圈宣传。

**代理群**只有一个，只聊销售与财商，最高两个级别才能进。作用是让基础群的人往代理升级；销售的疑难杂症都能在群里互相支招，出单就打卡，彼此刺激，让金钱和能量流动起来。每半年，我会请专业财商老师带大家做一次基金定投。微商手里现金流多，我希望他们别当验钞机，而是让钱经过思维过滤后真正变成自己的，而不是买豪车豪宅糟蹋掉。（代理群海报见图2。）

**全国总代群**也只有一个，成员是对团队忠诚、业绩漂亮的最高级别代理。有些话对外讲容易引起误会，我会在这里讲；这里也是做价值观教育的地方，一两周启用一次。

每个群功能分明、职责分明，免得混乱。当时的考虑是：有人只想当用户，不想看见销售内容；群里一发销售信息，他们会觉得被推销了，心里不舒服。所以干脆分开：基础群不碰销售，代理群只聊销售与财商。

这么多社群谁来运营？就是微商学院的社群运营组。他们内部也分工明确，每周有人提前安排。

各种训练营群也有流程：先由统筹发起项目，招募运营官和小助手，安排好导师与课程；海报组做海报，社群运营组负责运营，各司其职，一起把训练营项目完成。

## 3. 培训像课程表一样排好，新人和老人都有着落

针对新人，也就是最低级别代理，我们提供新人培训，内容包括：价值观教育（我亲自讲）、产品知识、资料库建立、出道文怎么发、如何加人、怎么开口讲产品、微商常用APP使用等。

作业按课程内容布置，文字、图片类提交到打卡小程序，导师打分。开口讲产品这项作业，是让代理跟自己的上级模拟一段买卖对话。新人培训一月一次，滚动开班。

针对最高两个级别，提供销售实战培训和价值观输出特训。他们就是冲着赚钱来的，所以要有文案训练、销售实战训练；大家去实战，导师点评，在线共同学习。

此外还有日进斗金训练营、瘦身营、美妆营等。训练营收的押金比较高，在五百到一千五之间，目的是保证完成质量。

我做过六年英语老师，其中三年半在机构做培训，写过成千上万份教案、教学计划、作业设计，所以会参与团队课程设置。我受不了稀烂的培训，也知道什么课程适合什么样的学员、学完会有什么结果。

## 4. 线上招商会：越短越有劲

我们两三个月办一次线上招商会。一般由导师学院年初做好规划，提前半个月准备：先找统筹人，也就是项目经理，再由她牵头成立工作组，宣传、海报、审核、统计、答疑、故事、场控、公众号等各就各位。

正式开始前，我们会彩排一到三次，看时间卡点和配合度。以前搞过三天、两天，最近两次尝试一小时快闪，我发现大家更喜欢快闪式。最近线上招商会成交的客户，基本是被我们的运营吸引来的。

内容设置上，如果是一小时场，就不单独做产品介绍。正式开始前，先在群里接龙产品疑问，答疑组迅速写下答案，留到答疑环节用。开场由团队长讲团队规模、业绩、价值观；接着两三个人讲故事；再是产品答疑；最后促单。

我们会提前定制很多礼物。快闪式招商会，一个群一小时成交额在三十六万左右，这是最近的数据。

招商会结束后，会有很多新人进来。接下来一周，我们会办新人培训，大约一周时间；新人往往学会朋友圈框架、怎么开口谈单、如何整理资料、如何加人，也会出货，于是开始考虑升级。再过一周，办销售实战培训，专门练硬核技能，也就是出货。从招商会到最后两次升级，基本不需要邀请人操心，微商学院运营团队全搞定。

## 5. 心法：让九十多号人愿意持续把事做好

看到这里，你会发现所有活动都是运营团队在做。组建这样一支队伍不难，难的是让九十多名运营成员除了卖货之外，还愿意义务做事，并且做得很好。

### 01｜价值观教育

我们有个十二字价值观：克制务实、极致利他、长期主义。它像公司的企业文化，把心聚在一起，做事才不累，也更容易出成果。

微商现金流多，一不小心就去赚能力圈外的钱，P2P、各种盘，倾家荡产的不在少数。我不希望代理们碰这些，所以必须克制务实，克制贪欲。同时，也不要链接不靠谱的人，万一哪天爆雷，容易受牵连。

我一直提倡做个人影响力，这是长期过程，要耐得住寂寞，每日耕耘。打造个人品牌的核心，就是长期持续做一个靠谱的人。我们的项目也不错，是快消品，一直做一直有复购，其实是一本万利。我不希望他们今天做这个、明天做那个，做一辈子还是低层销售。

另外，大家要团结一致、互帮互助，比如一起做线上运营，共同运营团队。我们的价值观就是这么来的。

如果你也带销售团队，一定要有价值观。不管是公司的还是自己的，要挂在嘴上，从上到下知行合一，团队凝聚力才会越来越强。

### 02｜招募环节：竞争上岗

我们的运营成员是竞争来的，这样大家会更珍惜。

提前半个月发招募通知，并做一张表格，内容包括：八个工作组你愿意进哪个？你曾经有什么成就？你愿意在这件事上花多长时间？为了做好，你愿意付出哪些努力，不低于三点？

通过这些问题，我们能大致了解他们的想法和行动力。第一轮挑积极认真填问卷的人；第二轮筛掉平时不在群里出现的人，因为我们对他的才华不了解，也不清楚为什么这次冒出来。

名单确定后，四位院长分别通知自己的队员，告知被录取，并附一张精美录取海报，上面有团队公众号二维码。大家一定会发圈，开心得到这来之不易的运营机会，公众号也就传播出去了。

### 03｜开营、结营仪式

仪式感很重要。

作为团队长，我不参与这些细节。开营、结营仪式属于社群运营组的工作范畴，全部交给他们策划。

开营仪式上，最先出场的是我。我会隆重介绍四位院长，他们是我的左膀右臂，在团队改革中立下汗马功劳。一一介绍，一方面是让他们和所有人看到：我这个团队长没有居功自傲，也没有夺取劳动果实，我是发自内心欣赏并尊重他们；另一方面，也侧面暗示新一期运营成员：请尊重他们，配合他们的工作。该给的情绪价值，要给到位。

接下来是四位院长出场，然后各工作组组长出场介绍自己。

开营仪式和其他社群活动里，我总能发现团队中的运营奇才。所以，如果你觉得自己团队没有可用的人，一般来说只是你没发现。

结营仪式上，对功臣大赏，物质和情绪价值都不会少。

### 04｜每月一次分享

这个分享不是培训。在运营上他们比我更厉害，轮不到我培训。我主要讲成长类内容。

招募前我们许诺过：进微商学院，第一可以获得技能，比如公众号编辑、销售培训、社群运营等，我愿意给万人团队背书，方便他们出去卖技能；第二可以优先获得我的成长经验，我今年的学费差不多有四十五万；第三，如果他们愿意转型，我会对接一些微商团队代运营项目，在这里做得好，我可以推荐出去帮别人做运营赚钱。

### 05｜团队长的角色

我一年多没参与群里任何运营，都是在一旁静悄悄地看。我想要什么效果，运营团队去帮我实现。

团队里的定海神针。说起来我只是团队的吉祥物，也是他们说的定海神针：随便怎么折腾，有我顶着。

团队长是引领者。我坚决不做服务员、老妈子，坚决不养巨婴。我在前面走，愿意跟着的人就一起走。

我愿意让优秀的人更优秀，让牛逼的人更牛逼，而不是把精力放在末端。

团队长要出圈学习，链接圈外人脉。我曾经组团大约四十人去学习社群运营课，回来之后一个眼神大家都懂了，工作效率极大提高，质量也更高。同时，作为团队长，也要花钱出圈学习，不要把自己框死在微商领域。

一年前，我在这里只分享了做法，那时运营体系还不太成熟；一年后的今天，我分享的是背后逻辑和心法，因为这个体系目前非常完整、运营流畅，希望能给大家带来不一样的视角。

道理听来终觉浅，真正落地还得自己练。如果我的分享对你有用，那就去练起来吧。
