# 11.2 流量主如何缴税

## 11.2.1 个人主体缴税说明

### 1、个税基本规则

以个人身份运营的流量主，不需要邮寄发票。个人账户所得属于个人劳务报酬，依据《中华人民共和国税收征收管理法》及相关实施细则，腾讯公司从2019年11月1日起受税务机关委托，为个人流量主代征增值税及附加税费。

### 2、增值税与附加税费如何算

单次劳务收入达到500元（含500元）以上时，腾讯会代征3%增值税，并按增值税应纳税额代征附加税费，综合税率为6%（一般综合税率12%，减半征收）。若因税法或税局征管要求需调整规则，腾讯将另行通知。

增值税应纳税额 = 劳务报酬（≥500元）÷（1+3%）× 3%

附加税费应纳税额 = 增值税应纳税额 × 6%

### 3、个人所得税怎么算

**1）应纳税所得额**

劳务报酬所得按个人当月同一项目多次收入合并为一次收入，定额或定率减除规定费用后的余额为应纳税所得额。

每次收入不超过4000元：定额减除800元；
每次收入超过4000元：定率减除20%。

应纳税所得额 = 劳务报酬（＜4000元）− 800元

应纳税所得额 = 劳务报酬（＞4000元）×（1 − 20%）

**2）应纳税额**

应纳税额 = 应纳税所得额 × 适用税率 − 速算扣除数

劳务报酬所得适用超额累进税率，分别为20%、30%、40%：应纳税所得额不超过20000元的部分按20%；20000元至50000元的部分按30%；超过50000元的部分按40%。

**案例一：** A流量主当月收入400元。收入不足500元，腾讯不代征增值税及附加税费；收入扣减800元后，个税应纳税所得额为0，腾讯不代扣代缴个税。

**案例二：** A流量主当月收入800元。增值税 = 800 ÷（1+3%）× 3% = 23.3元；附加税费 = 23.3 × 6% = 1.4元；扣除增值税、附加税费及800元后，个税应纳税所得额为0，腾讯不代扣代缴个税。因此腾讯代征增值税23.3元、附加税费1.4元。

**案例三：** B流量主当月收入3090元。增值税 = 3090 ÷（1+3%）× 3% = 90元；附加税费 = 90 × 6% = 5.4元；个税应纳税所得额 = 3090 − 90 − 5.4 − 800 = 2194.6元；个税 = 2194.6 × 20% = 438.92元。腾讯代征增值税90元、附加税费5.4元，代扣代缴个税438.92元。

**案例四：** C流量主当月收入10300元。增值税 = 10300 ÷（1+3%）× 3% = 300元；附加税费 = 300 × 6% = 18元；个税应纳税所得额 =（10300 − 300 − 18）×（1 − 20%）= 7985.6元；个税 = 7985.6 × 20% = 1597.12元。腾讯代征增值税300元、附加税费18元，代扣代缴个税1597.12元。

**案例五：** D流量主当月收入82400元。增值税 = 82400 ÷（1+3%）× 3% = 2400元；附加税费 = 2400 × 6% = 144元；个税应纳税所得额 =（82400 − 2400 − 144）×（1 − 20%）= 63884.8元；个税 = 63884.8 × 40% − 7000 = 18553.92元。腾讯代征增值税2400元、附加税费144元，代扣代缴个税18553.92元。

这种情况下，由于腾讯仅代扣，你仍需自行完成年底个人所得税综合申报义务，并自行承担个税多退少补。

## 11.2.2 企业代收方式

个体户只要有对公账号，且后续能开具增值税专用发票，都可以作为代收企业。

根据国家税务政策调整，小规模纳税人增值税纳税义务发生时间在2023年1月1日至2027年12月31日期间的，原适用3%征收率的应税销售收入，可免征增值税或适用1%征收率。若纳税人放弃免税，则适用3%征收率。

因此，2023年1月至2027年12月期间开具的发票，腾讯接受1%或3%税率的增值税专用发票，或免税的增值税普通发票。请流量主收到结算单后及时开票给我司结算。

# 11.3 如何启用无纸化结算功能

流量主使用电子专票进行无纸化结算的流程及条件如下：

1. 结算主体为对公账户；
2. 在当地税局申请开具电子发票（非纸质发票的电子版）；
3. 开通流量主服务助手（开通方法见：开通流量主财务助手）；
4. 使用收款企业法人的注册微信号扫码进入微信公众平台即可看到上传入口；
5. 电子发票上传步骤：进入电子发票上传页 → 正确上传电子发票 → 查询电子发票处理状态 → 付款审核【无需上传结算单】；
6. 提现流程：电子发票审核通过后，请登录微信小程序“流量主服务助手”自助操作提现。操作申请后，平台将在10个工作日内完成支付。

## 条件二：在当地税局申请开具电子发票

办好公户后，还有一步是去税务登记。这一步我起初在网上找入口，找到入口但无法用企业身份登录，后来才知道新注册的个体户没有进行信息确认的话，无法直接登录。问了一个在税务局的同学，说最好去窗口办理，于是我就去窗口办理了。

大概你给工作人员说清楚诉求，他会带你去操作。我去了现场问工作人员，他说其实也可以自己在线上操作，但要先用个人身份登录，然后绑定企业，再同步信息，再切换成企业登录。（入口比较难找，找不到的话去窗口问问也很快，基本没人。）

第一项和第三项业务大概半小时就办理成功了。定期定额征收核定定额的业务，工作人员说是15天内，实际审核通过也差不多花了2个星期。

重要补充：

之前也是摸着石头过河，这两天收到税务电话让我报税改报表（之前去税务大厅开户申请时，工作人员也提醒过我，但我当时没完全理解）。我说主要用途是开增值税专票，工作人员告知其实完全没必要开双定户，而且只要开了专票，双定户一般也会取消，因为系统无法自动申报，你还得改报表。

双定户就是税务局给你估一个预计未到起征点的销售额，设定好之后就不用再改报表，可以开免税普票，只要不超限额就行。比如我的审核结果是每月4万（不知道依据是什么，我自己申请时报的是1万），这样系统会自动申报，也不用交税。

当时纠结是不是双定户才有30万免税政策，但其实只要是个体户都有那个政策。我们用这个作为公众号收款，主要是开电子专票，就不适用这种，因为电子专票不是0税率，最低也有1%，到时候要根据实际销售额补交这部分税。系统无法自动扣，所以不适用。

所以，如果只是拿来公众号收款用，就不要申请双定户了，直接查账征收，之后开了多少专票就报多少。
