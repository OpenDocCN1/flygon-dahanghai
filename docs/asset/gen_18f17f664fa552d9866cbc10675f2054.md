# 3.1.1 高客单蓝海怎么挑

这次闲鱼航海更推荐大家做高客单商品，所以下面聊聊高客单的挑货思路。

它和普通选品差别不算大，主要就两点：

1. 先卡价格区间，太低的不看，比如低于100元的品可以直接跳过；
2. 判断能不能跟时，同行单天卖出件数、想要数这类门槛可以适当放宽，因为高客单商品本来单量就普遍少于低客单。

挑货时先把自己放回买家位置：想想自己会搜什么、会关注什么；平时看到高客单产品，也可以顺手打开闲鱼查一查。把选品融进生活，慢慢养成习惯。

接着再去闲鱼用数据验证：这个品到底要不要上架。闲鱼不像淘宝有生意参谋，也不像📕、抖音有蝉妈妈这类数据平台，选品时更多要借助平台本身露出的数据来判断。

一般来说，高客单挑货主要看这几个点：

应季、卡价格、想要数、同行动态、多家情况。

一个不错的选品，通常长这样：

# 3.1.1.1 应季

应季是第一个判断维度，要先从大方向看这个产品眼下是否贴合用户需求。

比如露营车，开年、开春、入夏都合适，到了秋冬需求自然会降；再比如夏天卖电热毯、暖风机，冬天卖落地扇、吊扇、空调扇，显然不合时宜。

当然，电脑显示屏、货架这类四季都能卖的产品例外。

# 3.1.1.2 卡价格

既然要做高客单，价格筛选就很重要。除了露营车、空调扇这类一眼看出的大件，也要从常见热销品里筛出高客单规格。

搜索产品时，可以点“筛选”里的“价格”，填一个合适的最低价再查看。比如手机壳通常几块、几十块，但筛完价格后，就能看到不少具体规格的高客单手机壳。

[PRE3]

之后再把应季、想要数、同行动态、多家情况放在一起评。

# 3.1.1.2 想要数

“想要数”能反映市场热度：有多少用户咨询过这个产品。数值越高，通常说明需求越大。但能不能做，还要结合下面两个依据一起看。

补充一点：有时页面不直接露出想要数，可能和主图展示、系统提示或闲鱼币抵扣设置有关，点进详情仍可查看。

[PRE4]

想要数:浏览数 ≥ 1:10

点进产品后，如果看到想要数:浏览数 ≥ 1:10，或者接近这个比例，说明需求相对更旺，操作空间也更大。相当于十次浏览里约有一次咨询，后面还可能带来付款。

[PRE5]

这时一定要搭配看动态出售情况。如果卖得不错，这类品成为蓝海的机会通常更大。再结合多家情况看：只要多家都基本满足指标，动态出售也不差，就偏蓝海，市场更好，可以优先做。

# 3.1.1.3 同行动态

“同行动态”看的是这个产品近期卖得怎么样，也就是转化数据。近期卖得越多自然越好，挑货时要重点看。

[PRE6]

同行“单天出售大于 3 件”

判断市场行不行，一般同行“2、3 天都能做到单天卖出超过 3 件”，就算不错，越多越好。但还要看下一个标准——多家情况。如果至少 2、3 家也都能超过 3 件，这个品就可以选。

如果单天卖得太少，少于 2 件，多家看下来也是如此，一般可以放弃。

同行动态不可见时怎么判断？

有些想要数高的店铺会设置动态不可见，这种情况怎么评？

[PRE7]

[PRE8]

可以借店铺露出的其他数据补充判断，通常按这个顺序：

1）鱼小铺等级L3以上：这个等级靠买家好评累积而来，L3通常说明近期卖得不少、口碑也不差，可以作为第一个小参考。暂时没有鱼小铺，但后面几项表现不错，也可以选。

2）下方留言时间：能反映近期咨询热度。7天内如果有2条以上新的产品咨询，说明近期还可以。

3）回复率90%以上：回复率越高，往往说明店铺整体盈利情况不错，值得花时间做；低于80%一般可以跳过。

4）卖出产品数：自然越高越好。如果只有个位数，且多家都这样，说明这个品可能没什么市场；但也不排除新上就爆单，这时要结合上面几项综合看。

# 3.1.1.4 多家情况

单个案例容易有偶然性，所以要把前面的方法合起来看：多家想要数都不错，动态出售也稳。

2、3 家同行单天出售都大于 3 件

如果有多家都满足“同行动态”里说的条件，2、3 家出售都超过 3 件，这个品就可以选。

以上就是高客单闲鱼挑货的方法论。讲完方法，大家也知道怎么判断一个产品是否达到上架要求了。

# 3.2 如何在闲鱼平台上架商品

# 本章要点

高客单商品的上架方法和普通品类一样。上架前先去拼多多找货源商家，参考商家的产品标题和图片，再结合闲鱼平台做优化上架。

商品上架的核心就一句话：尽量让市场里需要这个产品的用户，都进到咱们店铺浏览，并最终下单付款。

那怎么让上架商品被更多人看到并成交？关键在编辑上架这一步。最重要的四个点是：

商品标题

商品主图

商品介绍内容

如何定价

另外还整理了一些编辑小技巧和注意事项，帮你更顺地完成上架。这些模块具体怎么带来更多流量，下面继续看。

# 本章行动路线

完成本章节的学习和实操，就能走完航线图第二阶段：选品并上架销售，每天约4小时。

1. 每天上新8个产品链接，约2—3小时/天；

# 3.2.1 先去拼多多找货源商家

上架前，建议先去拼多多找到目标货源商家，确保出单后有货可发；同时也能参考货源商家的标题和图片来做上架素材。拼多多比较常用方便，也可以去淘特、1688等平台，流程一样。

怎么看商家是否达到优质货源标准？主要看4点：

1. 销量——上1000就可以，部分新店几十、几百也可以；
2. 好评——看近期动态，10个里面7个以上好评就算不错；
3. 利润——前期保证有利润就能选；后期熟悉流程、单天稳定6单以上，再选利润率≥20%的商家；
4. 商家产品数量——少于100个产品，正规商家通常几个或几十个；几千几万个产品的店铺，很可能是其他平台做无货源。

怎么快速在拼多多找到低价质优的商家货源？推荐两个最直接的方法：

方法一：借助搜索框，用图片搜索货源。

方法二：观察平台推荐，找到货源。

这里以“滚轴”举例，看看怎么找拼多多优质货源，原理都一样：

# 3.2.1.1 借助搜索框，用图片搜索货源

第一步：按3.3.1的高客单挑货方法，在闲鱼找到“滚轴”动态出售多的产品，点进链接，保存主图。

[PRE13]

第二步：打开拼多多，点右上角“拍照”，选取上一步保存的图片。

[PRE14]

第三步：在搜索结果页按销量排序，找销量靠前的几家店铺。如果识别出的不是目标产品，就按截图里的“产品类型”筛选，或者回到第一步换一张产品图再搜。

[PRE15]

第四步：打开第一步保存的闲鱼店铺链接，对比它家不同规格滚轴的价格，和拼多多上同款产品的价格差。

[PRE16]

第五步：只要拼多多价格低于闲鱼价格，就可以当作意向货源。多看几家后，再按前面说的“货源判断标准”，就能找到适合的货源。

# 3.2.1.2 观察平台推荐，找到目标货源

第一步：和方法一一样用图片搜货源，不同的是这次借平台算法，在搜索结果页下面找“相似商品”“猜你喜欢”。不同平台叫法不一样，但都是和搜索结果强关联、相似的产品。

[PRE17]

第二步：查看这些推荐产品的出售规格和价格，看是否满足开头说的“货源判断标准”。不断重复这个过程，最终找到合适货源。

以上就是找货源渠道的方法，操作不复杂，找起来也快，同样能用于淘特、1688等平台。

# 3.2.1.3 价格注意事项

不管是用图搜产品，还是找相似产品，结合“货源判断标准”，最终都会找到一些合适货源。初步找到一批后，要特别注意价格筛选：

1. 低于市场价格的商家至少准备2家，避免一家涨价后手忙脚乱。
2. 如果闲鱼同行标注的产品规格较多，多个规格不好找商家怎么办？

同行规格多时，只看同行最低规格的最低价，确保我们找到的货源价格低于市场卖得最好的闲鱼同行即可。其他规格一般单个产品上架3—5个就够，价格可以和闲鱼市场一样，或者小范围起伏。

例如滚轴：

# 3.2.2 编辑上架发布商品

# 3.2.2.1 快速出单的上架重点

编辑上架的核心：尽可能让市场里需要这个产品的用户进店，并最终下单付款。

换句话说，就是让上架商品拿到更多平台流量，被更多人看到并成交。上架这一步很重要，其中最关键的是这三点：

标题：复制拼多多或淘宝标题后，一定调整产品词语顺序，控制在30个字、一行半左右。

主图：用1:1或3:4比例的实拍图，图片可以从拼多多或淘宝评论区找。

内容：把转手原因、产品卖点、产品价格、发货售后补充清楚。

另外，也可以按单个产品要求，换标题、换主图、上传多个链接，增加单品曝光机会，获取更多流量。单品建议上传4个左右链接即可。

# 3.2.2.2 一个好的主图怎么制作

好主图要第一眼抓住闲鱼客户眼球，特点通常是：

清晰

干净

能体现产品特点，直接告诉用户你卖的是什么

如果做二手手机类目，产品图可以直接从产品相册获取，一个链接8—9张。二手手机产品相册需下载微商相册APP，扫码即可获取。

二手手机比较特殊，不同产品成色差异大。产品图要突出外观成色细节，比如划痕、磕碰、透图等。第一张主图通常选亮屏开机后的主页面。

好主图长什么样？

以“商用冰柜”为例，排名靠前的商品主图一般是产品放在正中央，款式和细节突出，让人想点进去。而一些想要数相对少的商品，图片不清晰，给用户的感觉差，对比下来肯定优先点上方。所以主图尽量按上面的要求来做。内容里的其他照片，参考动态出售好的商品图即可。

好主图图片去哪里找？

一个成本较低的方法：直接去淘宝、1688、拼多多、淘特等电商平台搜产品，从产品介绍和用户评价里找符合要求的图。

# 3.2.2.3 一个好的标题怎么制作

好标题长什么样？

能拿到较多流量的标题，通常会把产品关键词堆积起来，让用户不管搜产品哪个名称，都尽可能出现自家店铺产品。

比如“商用冰箱”，也叫冰柜、冷藏冰柜、卧式冰柜、冰箱，就可以把这些词，再加上用户可能搜的词，如厂家直发、厨房、个人出、商超倒闭、全新等组合起来。

标题参考：全新包邮商用冰柜冷藏冰箱厂家直发厨房商超使用卧式冰柜大容量（尽量用30个字符占满）。

再比如“二手手机”，要考虑买家想了解什么，第一印象就给出答案。结合二手手机特点，就是机型+颜色+内存+成色，卡住关键字，简单明了。

一开始找不到感觉，最好的方法就是借鉴同行标题，把手机型号参数直接修改后拿来用。

[PRE22]

如何快速制作优质标题？

更省事的做法：参考闲鱼同类产品销量好的标题，再加淘宝同类产品销量好的标题。销量偏好的标题通常经过优化，借鉴后简单修改，就能变成自家产品标题。

# 3.2.2.4 一个好的产品介绍怎么制作

图片内容上面已经说过，参考闲鱼市场动态出售好的其他图片即可。这里主要讲产品文字介绍怎么写。

好产品介绍长什么样？

先介绍产品为什么出售，给用户一个理由，再简单介绍产品；然后写清具体规格和价格；最后补充售后情况。

好产品介绍怎么制作？

有一个万能公式：

第一段：告诉用户为什么出售这个产品，外加产品特点；

第二段：规格和出售价格分别是多少；

第三段：发货时间、发货快递，以及售后安排。

产品介绍足够详细，用户想知道的都看到了，就能减少客服工作，降低时间成本。同时介绍简单明了，用户一眼看到想要的信息，能降低决策成本，也有助于提高转化率。

像下图这样即可，简单明了。规格最多按3—5个来，不要给客户太多选择，最后犹豫跑单。规格必须很多的，精简即可。

# 3.2.2.5 产品如何在闲鱼上发布

按上面要求准备好图片、标题、产品介绍，接下来就可以发布产品。

1. 打开闲鱼主页，点击中间“卖闲置”按键。
