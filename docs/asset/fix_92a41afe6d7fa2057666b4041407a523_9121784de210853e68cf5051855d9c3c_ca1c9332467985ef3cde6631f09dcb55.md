提醒：完整矩阵运营还涉及逆向、写代码、IP 代理池、设备唯一编码、验证码等，绝非靠 AI 编程就能搞定；目前最顶级的 AI 也做不到。新手别轻易走这条路，否则会花大量时间验证这句话。

# 4. 常见问题与解决方案

# 4.1 API 限制问题

把视频生成任务错开，别在同一时间集中调用。

# 4.2 视频质量波动

用 VL 视觉模型对基础图片做质检，保证人物一致性；设定最低合格线，不达标直接丢弃。

# 4.3 YouTube 自动上传可能导致流量减少

这个现象目前比较玄学，没有确定解法，可能与上传地区有关。n8n 里 YouTube 上传可调的参数不少，地区、视频分区等都会影响。

# 4.4 CORS 本地跨域请求资源问题

本地打开项目网站时，浏览器通常会拦截跨域请求，也就是限制你访问网络资源。按这篇教程设置，再用关闭安全模式的浏览器打开项目网址：https://juejin.cn/post/7165138128938893343
