# 2.2 🔥快团团帮卖基础流程，照着做就行

想在快团团上开启帮卖，却不知道从哪一步下手？其实基础流程并不复杂，把下面几个环节走顺，就能快速进入状态。

先完成账号准备。用微信登录快团团，按提示完善个人信息，完成帮卖身份的相关设置。只有身份确认后，才能正常查看可帮卖商品和后续佣金。

接着挑选商品。进入帮卖市场或团长分享的团购页，浏览正在开团的商品，结合自己的受众需求选择适合推广的品。选好后点击“帮卖”，系统会自动生成属于你的分享页面或海报。

然后进行分享推广。把生成的链接、海报发到朋友圈、社群或私聊给目标用户，附上简短真实的推荐理由。顾客通过你的分享进入并下单，订单就会记录在你的帮卖名下。

最后关注订单与收益。在帮卖后台查看订单状态和佣金明细，顾客确认收货后，按平台规则结算佣金，达到条件即可提现。

整体来看，快团团帮卖的基础流程就是：准备账号、选品帮卖、分享推广、查看订单与佣金。先把这套流程跑通，再逐步优化选品和分享方式，帮卖效率会越来越高。
