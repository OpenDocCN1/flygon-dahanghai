# 错峰卖水杯：先攒人，夏天再集中爆单

这个号能跑出来，靠的不是运气，而是节奏。

它做的是杯具品类。二月里，大家对买杯子的兴致并不高，硬推转化基本没戏，所以前期它只做一件事：把有设计感的图文铺出去，用颜值把关注留住。等入夏之后暑气一起，杯子进入消费高峰，先前攒下的这批人就成了第一波订单。

记忆点也很清晰——通体撞色，货架上一眼就能认出来。更关键的是“蹲蹲”两个字，从起号那天起作者就在内容里反复提醒，等于提前替用户排好了队。

开号到现在接近半年，三十几篇图文换来 2.2 万关注。留言区里“太好看了”“哪里能买”这类高意向评论随处可见，十个社群个个满员，出货量已经破万。

手上真有设计功底的人，可以琢磨琢磨这种“先蓄客、再收单”的节奏。
