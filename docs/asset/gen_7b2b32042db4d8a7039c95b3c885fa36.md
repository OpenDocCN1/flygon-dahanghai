# 这份团队管理范本，别只让老板看

2020年6月22日，白一喵在生财合伙人栏目聊过团队管理与公司文化之后，一直想找一份真正可参考的样板。后来他找到一份英文材料，亲自做了意译——不是专业英翻，重点在把意思讲清楚——并把中英对照整理进了附件。文档作者的情况，放在文末附录里。

即便你并非老板，这份材料也有几种读法。

如果你仍在职场打工：发现直属上级的行事方式与文档描述接近，说明你遇到了值得跟的人，要珍惜，也要尽可能从他身上学；如果老板不靠谱，那就把自己放到老板的位置上，用这份文档的标准要求自己，慢慢练出能当老板的实力。

如果你刚开始带人，又有上进心：不妨看看更高层的领导在关注什么。但有个前提：你所在的组织不能官僚气太重。

如果你已经管理多个管理者，属于资深主管：可以拿这份文档去要求团队，避免平庸的中层带出平庸的一线，也避免一线人才被埋没。

如果你是CEO：公司文化和团队文化太大，不知从哪儿下手？那就把写出这样一份文档当作一个最小可行产品（MVP），从你自己开始动手。别嫌麻烦，照着样子写，两个小时可以完成。问题不在能不能，而在愿不愿。

如果你只是对人的差异性感到好奇：文档作者MBTI类型是INTJ，DISC类型是CS，可以把他当作一个研究样本，和你自己对比看看：相似点有哪些、不同处在哪里、为什么会不同。
