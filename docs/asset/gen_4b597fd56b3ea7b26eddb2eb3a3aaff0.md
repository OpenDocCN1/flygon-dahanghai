# 6.3.2.2 手把手搭好去重模板

想让自己剪出来的视频更耐查重，提前做一个能反复套用的模板会省不少事。下面按步骤操作，做完后就能把半成品视频往模板里替换。

Step1：先找一段4到5分钟的视频当占位素材，导入剪映；再把它复制一份放到副轨道1。这个副轨道1后面要换成真正需要去重的半成品视频。接着去掉副轨道1的声音：选中素材后右键执行“分离音频”，再把分离出来的音频删掉。

Step2：处理背景模糊效果。给主轨道画面加模糊特效；副轨道画面添加矩形蒙版，调整蒙版范围，让大部分画面露出来。

Step3：做扫光效果。把扫光素材放入副轨道2，裁剪成9:16；在“画面-基础-混合模式”里选择“滤色”，右上角“倍速”调到0.5。

Step4：加一层画中画干扰。找一段无关素材导入副轨道3，先删除声音，再把“画面-混合-不透明度”设成2%。

Step5：用贴纸增加变化。打开剪映左上角的贴纸入口，挑2到3个贴纸放进轨道，贴纸时长要与主轨道视频一致。

Step6：制作结尾引导。对主轨道和副轨道1分别做定格：选中主轨道或副轨道1，把进度条拖到副轨道1末尾，按下定格。然后选一个箭头贴纸，调整大小和朝向，让它指向左下角——在抖音观众视角里，这个位置就是付费跳转链接。再输入“点击观看精彩后续”，点开文本后在剪映右上角找到“朗读”，选好音色并开始朗读；把生成的音频放到定格画面下方，最后删掉原文字。这样做是因为文字引导容易触发营销判定，导致视频被限流。

Step7（可选）：在剪映左上角进入“音频-音效素材”，搜索“咚”，挑一个合适音效放在定格画面开始的位置。

具体操作可对照视频演示，遇到不明白的步骤，建议多看几遍：

完成以上操作后，去重模板就搭好了。以后混剪出一条半成品视频，把它导入模板，替换Step1里主轨道和副轨道1上的占位素材，就能对该视频完成去重处理。
