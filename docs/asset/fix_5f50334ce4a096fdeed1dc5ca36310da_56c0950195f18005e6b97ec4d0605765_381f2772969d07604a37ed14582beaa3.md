# 十四、AI 绘画在 IP 定制中的用法 @饼公子

## 14.1 玩法概览

IP 定制，是把知名影视、漫画、游戏等 IP 做二次开发，再应用到文化创意、广告、游戏等领域，从而创造新的商业价值。

流程一般有这几步：

IP 评估：看目标 IP 的品牌价值、市场影响力、知名度等，判断适不适合做定制。

品牌授权：与 IP 持有方谈判，拿到授权，并确定授权方式和费用等。

形象设计：结合 IP 特点和定制需求做形象设计，包括角色形象、场景设计、配色方案等。

周边产品开发：依据形象设计和定制需求开发周边，比如文化衫、手机壳、玩具等。

推广营销：根据定制需求和推广目标制定方案，包括线上推广、线下活动、广告投放等。

迭代优化：根据市场反馈和用户需求，对定制方案做优化和迭代。

举 10 个知名 IP 定制角色：Hello Kitty、Pikachu、Doraemon、Snoopy、Mario、Mickey Mouse、Minions、SpongeBob SquarePants、KAWS 的 Companion、BT21 的角色。

AI 绘画在 IP 定制领域的优势跟前几种玩法类似，这里不再展开，主要有这几点：风格多变且新颖；支持高效定制、降低成本；创意空间大；支持更个性化的定制。尤其在追求个性化和新颖的年轻群体中，AI 定制 IP 的潜力和吸引力很大。

与之相对，AI 绘画在 IP 定制领域也有局限：缺乏人文关怀——AI 生成的作品可能缺少人文精神和情感体验，达不到人工绘画的情感影响力；风格相近且重复——如果 AI 模型训练和学习不够丰富，生成作品风格可能单一重复，无法持续输出新颖效果，会降低客户的新鲜感和购买欲望；要素失真和不协调——AI 生成复杂绘画作品时，对图像要素可能处理不当，造成局部失真或要素间不协调，影响视觉体验；个性化体验差——与人工定制相比，AI 定制的个性化体验可能相对差一些，达不到人工定制的精细和贴身。这也是一大挑战，需要通过更强的客户参与和人工精修来改善。

# 十五、AI 绘画在 LOGO 设计中的用法 @木木|终身成长践行者

## 15.1 玩法概览

LOGO 是企业、组织、品牌等在商业活动中使用的标志和标识，是品牌身份的重要组成部分。LOGO 设计需要兼顾品牌特点和定位，借助图形、文字、色彩等元素的组合与运用，表达品牌理念、特点和形象，从而实现品牌宣传和市场推广的目的。

LOGO 设计的类型有：

字形 LOGO：只用文字或字母来传达品牌形象和价值；图形 LOGO：用图形或图案来传达品牌形象和价值；

组合 LOGO：把文字和图形组合在一起，形成更复杂、更丰富的品牌形象；

徽标 LOGO：类似图章或徽章。

风格主要有：

扁平化风格：简化图形和色彩，强调简洁和现代感；立体化风格：使用阴影和渐变等效果，增强图形的立体感和质感；

手绘风格：以手绘方式表现图形和文字，增强品牌形象的个性与亲和力，适用于比较轻松有趣的品牌形象；

经典风格：使用传统设计元素和技巧，强调品牌的历史和传统，适用于有丰富历史和传统的品牌；未来主义风格：使用未来感十足的图形和色彩，强调品牌的科技感和先进性，适用于科技和创新型品牌。

AI 绘画在 LOGO 设计领域的优势与插画设计基本相似，这里不重复赘述。

局限性上，AI 绘画在 LOGO 设计领域还多两条：

文字/字母无法完美体现

只能提供思路，不能完全当成品图

[PRE32]

而且，AI 缺乏情感意识，设计出来的 logo 不够有趣，没有灵魂。对商单来说，AI 绘画只能提供一个灵感、一个基础图形，而 LOGO 需要矢量图形或者分层图层等，这些都得靠设计师二次创作。
