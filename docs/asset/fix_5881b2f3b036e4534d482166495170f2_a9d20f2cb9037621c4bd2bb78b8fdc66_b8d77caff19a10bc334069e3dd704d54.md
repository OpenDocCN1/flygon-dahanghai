# 必修篇

# 一、AI工作流的入门课 @黄小刀

# 1.1 工作流到底指什么？

所谓Workflow，就是围绕一个目标，将若干操作按顺序组织成链条，核心落在计算机场景里的自动运转。  
你可以把它看成一站式产线：大任务被切成若干小环节，每个环节都有清晰目的和操作规范。

[PRE3]

拿一家包子店来打比方：流程标准、动作重复，很能体现工作流的特征。大致环节包括：

原料采购与准备：买齐并备好材料。  
揉面：把面团做出来。  
调馅：准备好包子馅。  
擀皮：擀出包子皮。  
包制：把包子包好。  
上锅蒸熟：蒸制包子。  
包装出售：包装并卖出。

这些动作要依序推进，并不断重复，才能让每个包子达标。工作流追求的是把每一步规范化，使整个过程高效、稳定地完成。  
输入与输出是工作流的重要概念：上一步的信息从哪里来、生成的内容接下来送到哪里，都是关键节点。比如“揉面”这一环，面粉来自前一步“原料采购与准备”的输出；揉好的面又会成为下一步“擀皮”的起点。  
当“包子店”工作流搭好，你只需点一下开始，系统便会自动跑完每一步，直到包子售罄。你需要的只是一个好想法，再用工作流把它串起来。

# 1.2 工作流为何值得用？

# 💡

在AI领域，AI智能体（AI Agent）热度很高，不少圈友也动手搭过智能体。那么智能体和工作流究竟差在哪，为什么我们更该用工作流而不是智能体？

先看两者的定位差异：

智能体（AI Agent）  
是什么：它是一个自动化“助手”，负责执行特定任务。好比定时器，到点提醒你。  
能做什么：适合具体、重复的事情，比如客服聊天、商品推荐、订单处理等。  
短板：只能按预设规则和任务行事，一旦遇到范围外的情况，就不知道该怎么处理。

工作流（Workflow）  
是什么：它是一组任务流程，规定每一步该做什么，像一本操作指南，从头到尾告诉你如何推进。  
能做什么：可以覆盖完整过程，例如客户下单、付款、发货、售后，把所有步骤和环节都纳入其中。  
优势：更灵活，能适应变化。你可以调整步骤和规则来应对不同情况，不必一开始就全部固定。

区别总结  
智能体是执行特定任务的“工具”或“助手”。  
工作流是指导整个任务的“计划”或“路线图”。  
简单说，工作流看全局，智能体管局部。

实际业务中，我们更需要工作流而不是智能体，因为流程设计往往更关键：重点不在于用几个智能体，而在于把解决问题的步骤设计好。好比下厨，锅具贵不贵不是核心，按工序把每道菜做出来才重要。  
土豆丝切得再细、再快，也只是土豆丝；工作流则要把清洗、切配、翻炒、装盘、上桌、收款串成一条线，从买土豆一路走到赚钱。  
工作流才是解决问题的关键，它能帮你理清思路、优化流程。设计好工作流，才是提升效率的王道。因此，手册结尾也专门用一章教大家如何“拆解”自己的工作流。

# 1.3 哪些业务适合交给工作流？

适合工作流化的业务通常有两个特点：重复性工作多、业务流程固定。  
以自媒体工作者的日常为例，其任务是更新内容、获取播放量、得到关注和客户线索。流程一般包括：选题策划（调研+点子）、内容生产（找素材+撰写/制作）、编辑加工（初编+设计排版）、审核、发布、互动、复盘、优化。  
这类工作既有大量重复任务（如内容生产、编辑、发布），又有固定业务链路（如策划、生产、审核、发布）。借助AI把这些步骤标准化，再用工具自动执行，效率就能明显提高。  
如果你是这位自媒体工作者，你会发现自己多出了时间和精力去思考、去创造。比如把时间放在打磨高质量内容上，或者研究工作流之上更好的变现方式，而不是天天惦记什么时候蹭热点、怎么剪辑这些琐事，因为琐事已经由工作流替你干完了。它让你释放创造力，更专注核心业务。  
不妨用老板心态大胆设想：把目前赚钱手段中能AI工作流化的部分外包给AI，你接下来要做什么？

# 1.4 狭义工作流与广义工作流

狭义与广义工作流对比：

通常，狭义工作流解决某个局部场景，广义工作流则面向整个业务流程。  
用电商和自媒体两个领域举例：

电商：  
狭义：帮助改写商品标题、优化电商详情。  
广义：商品发布、上架、客服、发货自动化一条龙。

自媒体：  
狭义：生成一篇👸号文章。  
广义：自动上号、自动内容（写、排版）、自动发布、留言回复。

广义工作流，实际上就是业务流的自动化。在这个过程中，除了agent，通常也会涉及RPA、知识库、Python等工具。选修篇最后一部分有更详细的说明。

# 2.3.2 插件能力

Coze内置60余款插件，涉及新闻阅读、旅行计划、生产力工具、图像理解API、多模态模型等领域。借助这些插件，用户能轻松给机器人补充各种能力。  
平台也支持自定义插件；没有的功能可自行创建。

# 2.3.2.1 插件怎么用

插件相当于工作流里的一个个工具，每个工具完成不同任务：有的能读取网页内容，有的能搜索，有的能创建飞书文档。用法如下：

1、添加插件：在工作流编辑页左侧选择添加插件，可搜索所需插件，也可下拉选择。  
2、连接插件：在画布上把插件拖到合适位置，连接前后节点。

[PRE22]

3、配置参数：不同插件参数不同，红色星号是必填项，未标记的是选填项。

[PRE23]

参数输入有两种方式：  
引用：在右侧选择栏引用前面节点需要的内容，属于动态值，会随前面节点生成内容变化。  
输入：手动填写固定内容，属于静态值，不会变化。

[PRE24]

点击插件右上角三个点可查看详情，通常每个参数都有详细说明。

[PRE25]

4、试运行：所有节点参数设置完成后，点击画布右上角试运行，查看效果。

[PRE26]
