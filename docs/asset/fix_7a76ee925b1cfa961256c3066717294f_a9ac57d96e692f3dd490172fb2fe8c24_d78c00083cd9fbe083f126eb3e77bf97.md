# 3.2.2 自动化思维：让程序代劳

自动化思维，可以理解为把原先靠人一步步操作的事，改由程序或机器执行。放到工作和生活里，它至少带来五种好处：

1. 重复任务处理更快。数据整理、报表输出交给工具后，耗时和人力都会降下来。

2. 人为失误更少。手工操作难免闪失；只要自动化脚本设计合理，出错概率会明显压低。自动测试每次执行都保持一致，不会像人工那样漏步骤。

3. 时间被释放。杂事由程序接管，人就能把精力放到需要创意和判断的工作上。

4. 产出更稳定。流程每次按同一套规则跑，结果自然一致；例如标准报告自动生成，数据和版式更可靠。

5. 追踪更方便。自动化系统常配日志与监控，管理起来有据可查；自动备份会留下时间和状态记录，事后核对更省力。

这些好处不只在编程里成立，日常事务同样适用。学会把重复、低价值的环节交出去，人就能更专注地做有创造性和策略性的部分，任务完成得又快又稳，工作和生活质量也会随之提高。

# 3.2.3 批量化思维：把多项任务打包处理

批量化思维，重点在找共同点和规律，然后把许多任务收拢到一起处理。它带来的价值包括：

1. 一次操作覆盖多项，重复动作减少，效率随之提高。邮件群发、文件名统一修改都是常见场景。

2. 大量任务能在较短时间内完成，时间成本下降。报告成批生成、数据成批导入都属于这一类。

3. 手工处理越多越容易出错，批量处理借工具降低失误率，数据校验可一次性检查整批记录是否合规。

4. 统一标准执行，产出的一致性更有保障。批量生成的文档在格式和内容上更容易保持规范。

5. 资源调度更合理。生产订单成批安排，可以优化计划、提升设备使用率。

概括来说，批量化思维就是先识别任务或数据中的共性，再一次性处理多个对象，从而提效、省时、少错，并守住结果的一致性和质量。它不只服务编程，日常工作中同样好用。

可以这样区分：自动化思维像让程序替一双手干活；批量化思维则像让程序带着一支队伍同时推进。

# 3.2.4 模块化思维：把系统切成可复用单元

模块化思维，是把庞大系统或棘手问题拆成若干独立、可重复使用的小块。它的好处体现在：

1. 维护更省力。不同功能各自封装，改动某个模块时不必牵动全局，理解和排错都更轻松。

2. 复用更自然。常用能力做成独立模块后，可在多个项目中直接调用，重复代码减少，开发速度提升。

3. 扩展更从容。系统要加新功能，只需新增模块或替换局部，不必整体推倒重来。

4. 复杂度被压低。一个大问题拆成多个小问题，每个模块只管一件事，调试和测试都更简单。

5. 协作更顺。团队成员分头负责不同模块，彼此依赖和干扰减少，配合效率提高。

模块化思维让我们用独立、可复用的小块来组织复杂系统：可维护性、可复用性、可扩展性都会增强，问题复杂度下降，团队协作也更顺畅。它不仅适用于编程，项目管理、产品设计等领域同样能借力。

常被称作“地表最强”的结构化提示词，底层思路正是函数方法论，也就是编程中的模块化思维。懂编程的人用起结构化提示词会更得心应手。

import os

import time

import requests

from selenium import webdriver

from selenium.webdriver.common.by import By

from selenium.webdriver.common.keys import Keys

from selenium.webdriver.support.ui import WebDriverWait

from selenium.webdriver.support import expected_conditions as EC

from selenium.webdriver.chrome.service import Service

# 设置 Chrome WebDriver 路径

driver_path = r'c:\chromedriver.exe'  # 替换为您自己的 chromedriver 路径

save_folder = 'AIGC'

# 创建保存图片的文件夹

if not os.path.exists(save_folder):

    os.makedirs(save_folder)

# 启动浏览器

options = webdriver.ChromeOptions()

options.add_argument('--start-maximized')

service = Service(executable_path=driver_path)

driver = webdriver.Chrome(service=service, options=options)

try:

    # 打开百度图片搜索页面

    driver.get('https://image.baidu.com/')

    # 等待搜索框加载

    wait = WebDriverWait(driver, 10)

    search_box = wait.until(EC.presence_of_element_located((By.NAME, 'word')))

    # 输入关键字并搜索

    search_box.send_keys('AIGC')

    search_box.send_keys(Keys.RETURN)

    # 等待页面加载

    time.sleep(3)

    # 爬取图片

    image_count = 0

    while image_count < 100:

        # 找到所有图片元素

        images = driver.find_elements(By.CSS_SELECTOR, 'img.main_img')

        for img in images[image_count:]:

            if image_count >= 100:

                break

            src = img.get_attribute('src')

            if src:

                try:

                    # 下载图片

                    image_data = requests.get(src).content

                    with open(f'{save_folder}/{image_count + 1}.jpg', 'wb') as f:

                        f.write(image_data)

                    image_count += 1

                    print(f'下载第 {image_count} 张图片')

                except Exception as e:

                    print(f'下载图片失败: {e}')

        # 下滑页面以加载更多图片

        driver.execute_script('window.scrollTo(0, document.body.scrollHeight);')

        time.sleep(3)

finally:

    # 关闭浏览器

    driver.quit()
