### SD 做艺术二维码：参数怎么配

模型选用 cbfba64e66，即 CounterfeitV30_v30 这款动漫插画小清新模型。模型方向不妨多换几种试试，从我自己跑下来的结果看，动漫类模型效果普遍在线。

先看第一路 ControlNet，编号 ControlNet 1：预处理器 tile_resample，模型 control_v11f1e_sd15_tile [a371b31b]。用 tile 的用意，是让生成早期先对画面局部施加约束，别让算法一上来就彻底放飞。好比培育一棵树，想让它长成你心中的模样，就得在几个关键生长期动手修剪；出图同理，想收获预期结果，过程中就得不断校正。tile 能干的事挺多：放大画幅时补细节，形状控制也拿手。这里换成 Brightness 模型也能用，但个人体验 tile 更稳。

这一路权重 weight: 0.4。tile 的作用太抢眼，必须把权重压下来，免得它把画面带偏。

起止时间 starting/ending: (0, 0.25)。这相当于树苗早期，也就是出图流程的前四分之一，这个窗口很要紧。介入不一定要从第零步开始，自己拿捏就行：起始 0 到 0.1 均可，结束 0.2 到 0.3 也都行，总体区间建议别超过 0 到 0.3。得给第二路留足戏份。

[PRE1]

接着是第二路 ControlNet 0：预处理器 inpaint_global_harmonious，模型 control_v1p_sd15_qrcode_monster [a6e58995]。这一路分量很重，出图的大部分时段都得由它来把守。qrcode_monster 负责让二维码的形变显得更自然。

权重给到 weight: 1.6。这里有个规律：权重压低，码就不好扫；权重拉高，码更容易被识别。反过来，低权重下画面颜值更高，高权重则牺牲一些美感。

起止时间 starting/ending: (0.25, 1)。前段已有别的模型把关，后段便交给 qrcode_monster 接手。若希望算法还能自由发挥一下，介入点可放在 0.25 到 0.4 之间；一旦越过 0.4，码的扫描难度就会上升。收尾时间可落在 0.8 到 1 之间，也可以提前收手，给 AI 留点自主空间。

高清修复方面：Hires upscale: 2，Hires upscaler: R-ESRGAN 4x+。照上面这套参数走，一般能产出可扫的二维码。若想再放大画幅，就打开高清修复：倍数保持默认 2，算法挑 R-ESRGAN 4x+，重绘幅度设 0.4，千万别调高。
