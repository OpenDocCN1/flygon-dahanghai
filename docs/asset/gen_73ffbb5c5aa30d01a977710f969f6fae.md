# 第四步：笔记封面与内页怎么做

## 4.4.1 排版先守住基本盘

### 4.4.1.1 三个关键点

✅ 给零基础作图的朋友划重点：封面排版先记牢三件事。

要点一，尺寸别乱来。
竖屏用3:4，方形用1:1，横屏用4:3。
竖版在屏幕上更占地方，眼睛自然多停几秒；能塞的信息更多，滑走的可能性也更小！

要点二，配图要准。
高颜值、强冲击的图很吃香（AI也能生成）；
手写类图简洁直观，适合简单手写；
合集、美食、旅游攻略等也适合这种思路。

要点三，文字要少而狠。
小红书笔记标题最多20个字符，emoji会占1～3个字符。
想补充信息，就得把封面用足！
刷发现页的人常常漫无目的，所以封面大字得抢到足够画面，信息要一眼懂，直接回答：这条内容对你有什么用！点开的欲望自然就来了。

### 4.4.1.2 少变+少用，两个原则

核心就两条：少变、少用。

先说少变：封面版式别频繁换。尽量做成模板化、可替换的结构，排版、字体、风格保持一致（颜色可以在同色系里变），主页看起来才整齐，粉丝也更容易认出你。

再说少用：不相干的贴纸能不用就不用，别让它们抢戏，把用户注意力打散。
