# Chrome 插件从 0 到 1：需求先于代码

大家好，我是帆，做前端开发，也是这趟 Google 插件航海的一员。航海群里不少圈友已经上线了自己的插件，我也算其中之一。平时我在群里话比较多，这次受阿蓝邀请，聊聊自己找方向、挖需求的过程，以及插件上线后的一些体会。今天重点放在“选方向和找需求”，也会带一些开发、上线、推广的细节，以及上线后如何继续发现新需求。全文约五千字，大概十分钟读完。

## 一、先定方向，再挖需求

这次航海给我最大的认知是：想把一件事做成，写代码反而是最轻松的一步。能不能赚钱、用户买不买单，关键不在代码写得多漂亮、功能堆得多丰富，而在功能有没有对准用户需求。项目启动前，最该反复确认的是需求本身靠不靠谱。

为什么用户会为一个看似简单的东西付费？Google 插件有一条硬性要求：单一功能（Single Purpose）。通俗说，一个插件只专注做好一件事，而且容易理解；功能太复杂，审核不会放行。在这个前提下，插件本质上就是辅助用户的工具。比如挖需求常用的 Keywords Everywhere、亚马逊卖家常用的 Keepa，都属于这类工具。工具替用户省了时间，用户自然愿意掏钱；而且这类用户多半是为了赚更多钱，付费也更干脆。

[PRE0]

从零挖需求，建议先围着大平台做周边。

虽然目标是做辅助工具，但我不建议第一个插件就冲着工具类去。第一个插件应该尽量简单，目的是快速走完开发流程：怎么开发、怎么上架、上架要准备什么、流量从哪里来。我航海时的计划就是先做一个简单的免费插件，把整个流程跑一遍，等做付费插件时心里才有底，不至于摸黑乱跑。

找需求时，建议认真读航海实战｜Google | 付费插件｜实战手册。手册对常用方法和细节讲得很细，有不清楚的地方反复翻几遍，再动手实操，基本就明白了。刚开始可以按手册的方向找，也就是 Facebook、Instagram、YouTube 这些平台。它们用户量巨大，再小的需求，哪怕只覆盖 0.001% 的用户，也是至少五位数的体量；而且需求好调研（用 Google 搜索），SEO 也方便。想挑战自己、第一个插件就盈利，可以从 Amazon、Ebay、Etsy、Shopify 这些电商平台入手。除了第一个用来熟悉流程的插件，其他插件在开发前最好反复确认、做好调研。

壹树说过一句话：找到一个需求后，别急着开发，过一周再回来看；如果还觉得不错，再过一个月来确定。这句话要记牢。开发要投入时间，开始前反复确认需求有没有潜力，否则时间成本太大：开发投入、审核上线时间、Bug 修复和编辑审核时间、SEO 推广，还有开发完成后的倦怠期。

用工具判断市场和竞争强度：航海群里问一个需求能不能做，最可能收到壹树哥一句“问搜索引擎，搜索引擎比我们靠谱多了”。一个需求行不行，答案都在搜索引擎数据里。通过搜索加工具，可以得到：

1. 相关词与关键词的每月搜索量、广告花费；
2. 这个需求对应的竞争对手数量；
3. 相关长尾词有哪些；
4. 每月通过该词进入目标网站的流量，以及网站月总流量。

[PRE1]

流量（Traf/mo）为预估值。关键词搜索量、费用、竞争强度等数据，调研来源是 Google 关键词规划师（比较准）。这里用到 Keywords Everywhere 扩展，功能是：搜索关键词，获取关键词及相关词的搜索量、通过关键词进入网站的流量，主要用来分析需求量和竞争强度。

用工具挖需求：上面提到 Keywords Everywhere 能查关键词及相关词的市场容量、竞争难度，反过来也能用它挖需求。航海手册里有一个方法：用关键词 + a-z 检索需求。

[PRE2]

A-Z 走一遍，就能筛出大多数平台的高流量搜索词。英文好的圈友，大概一眼能看出下拉词是什么；英文不好的，点进去看看结果，评估内容和搜索量，再考虑要不要深挖。基本就是按选定的方向，比如 Facebook、Amazon、Gmail、Ebay 这些词做 a-z 搜索。找到方向后，去搜索引擎找长尾词，看看当前解决方案，例如 how to xxxx in xxxx。这类词最能显示需求量。

[PRE3]

模仿竞品做插件：除了搜关键词挖需求，另一个办法是模仿竞品，这应该是见效最快的方式。这里需要一份圈友分享的商店扩展列表：Google 插件市场 15w 条完整数据 | 圈友基于此做的筛选工具。用这份数据表，可以按插件评分、用户量初步筛选，再人工过滤一遍结果，挑出近一两个月有新评价、但评分比较低的产品，然后用 Keywords Everywhere 做长尾词调研。

[PRE4]

这样搜出来的内容，基本都有需求（近一个月有评价）。用工具研究长尾词，主要是分析需求、市场规模和竞争情况。例如插件 Ali Invoice，便是通过这套筛选从数据表中找到的。

[PRE5]

它的功能很简单：获取速卖通订单信息，生成一份可打印的发票 PDF。实现不复杂，基础版价格却是 20 美金。目前这个插件已经很久没人维护，翻看 Rate 里大部分竞品，评论里很多“not working”，说明有需求但没被解决。直接对标开发、一比一复刻，很容易推广。这个需求比较小众（问过做速卖通的朋友，对方说没这个需求），所以我没深入调研，但感觉挺适合刚入手开发插件的圈友练手。

关于免费插件怎么盈利：挖需求时一定会注意到很多插件是免费的。不用猜它们怎么赚钱，大部分就是凭兴趣用爱发电（可能出于爱好、展示技术，或觉得这点收入不值一提），所以商店里才有不少停更插件。当然，免费插件也不是完全没法盈利，只是方式更复杂：

1. 把流量引到自家站点，再用其他产品承接转化（有开发商专做免费插件，给自家小游戏导流）；
2. 用流量卖货（宠物标签页 Tabby Cat 就在独立站卖周边贴纸赚钱）；
3. 提供增值服务（例如把插件获得的数据做云端同步）；
4. 赚联盟佣金（挖需求时看到一款免费插件，评论区都说它会自动打开天猫超市，作者估计是淘客）；
5. 引导用户点广告（这类插件通常会挨骂）。

做好心理预期：刚开始做插件的圈友一定要有准备，你的第一个插件可能因为各种奇怪问题被审核拒绝、开发完发现版本不能上架（MV2 版本不能上架了）、网上搜到解决方案却没效果、上线了却没用户等等。这也是我建议先做一个简单免费插件、完整跑一遍流程的原因。遇到了也别气馁，事后复盘，争取下一次更好。这种事就像做亚马逊遇到刷单被抓、投 Facebook 广告遇到账户被封一样，没经历过都不好意思说自己是插件掘金人吧。

## 二、别被技术绑住，先做出 MVP

开发插件是为了帮用户解决问题，怎么解决不重要。挖需求时，我习惯在确定需求可行后，先简单研究实现：看有没有能直接拿来用的库；如果没有，再评估自己实现复不复杂。比如下面这个插件：

看到它的第一反应，是可以用 FFMPEG 做一个一模一样甚至更强的工具，比如叫 Media Converter，音视频、图片都能转，连视频抽帧、图片转视频也不难；自己只做界面，预设好转码参数就能上架。开发前建议列个 todo list，把要开发的功能逐条写下，再逐行删减，只留最核心部分，先完成一个 MVP，让自己有东西可以推广；表现不错再补充细节。

补充一点：不用太在意用什么技术做插件，插件就是最简单的网页程序（HTML+JS+CSS）。会开发就用自己熟悉的技术栈；不会开发，可以和圈友合作生财。打算自己研究开发，简单学一下前端三剑客就能直接上手。

## 三、把扩展推上线

开发完成，上线扩展第一个问题是开发者账户。直接注册账户、绑定信用卡、支付费用，你很可能会遇到支付失败。这大概是 Google 内部问题：绑定支付卡后，关闭并重新打开页面，问题就解决了。当时查了一下，没有看到银行拒绝交易的提示，大部分都是重进页面就能解决，我也是这样绑好卡、关闭重开就支付了。实在解决不了，可以在万能的某宝多花点钱解决。

之后可能遇到的第二个问题是插件版本不对。Google 扩展分为 v2 和 v3，目前商店已经不允许 v2 版本上线，而网上很多教程还是 v2 版本。这次航海就有圈友踩到了这个小坑。

[PRE7]

因为版本问题被拒绝。遇到版本错误无法发布不用太紧张，升级版本并不复杂。只要没有使用被取消的功能（比如引用外部 JS），基本没有多大问题。

上线扩展最后一项是审核。审核需要描述大致程序功能（也就是前面说的单一功能），为什么需要某些权限（每一项权限都要单独说明）；如果需要收集用户数据，还要提供隐私声明。申请了权限却没使用、需要却没有提供某些内容，都会被拒绝。

[PRE8]

圈友插件因为权限问题被拒绝。插件审核通常要 2-3 天，期间无法撤回（插件上新、插件编辑都是这个时长，哪怕只编辑了一个字）。所以开发完成后一定要检查一遍：有没有申请多余权限，有没有影响功能的 Bug，免得因为这些影响上线，或者上线后收到不必要的差评。

## 四、上线后的推广

插件上线后，只靠自然流量获取用户还是比较慢。我的插件上线半个月才 100+ 用户 🤣。如果你的扩展修复了某个失效竞品，可以在它的 review 里留言，引导用户去自己的扩展页面下载。很多失效插件下面有模板，保存几个随时用就好。再就是搜索相关长尾词和关键词，在相关帖子里留下自己扩展（或官网）的地址。

获取免费流量的最后一个办法是制作视频发到 YouTube，标题用相关长尾词名称，很容易跑到 Google 搜索结果前面（可以认为大站点有加权）。付费流量就是 Facebook 广告、YouTube 广告，这一块展开又是一个超级大的板块。不过还是建议从免费流量开始。

插件上线后开始有用户了，可以用 Vercel 搭一个小站点，用来承接各渠道带来的流量，顺便赚点广告费，也可以做插件优化，提供一份使用指南。

## 五、做自己真正喜欢的事

亦仁有一段话我觉得很好：如果总开心指数是正的，那就值得做；如果总开心指数是负的，那就不值得做。也就是做自己喜欢的事。

今年应该是我加入生财的第四年，期间加入过多个航海，尝试过各种副业：视频号、抖音、TK、好物、小红书。这种 UGC 平台，每次内容发出去，自己都会陷入各种自我怀疑。这次尝试开发这个方向，却觉得一切自然又舒适。

之前尝试的副业虽然有一些收获，可总是坚持不下去。现在琢磨过来，大概是因为：尝试那些副业都是为了赚到钱，每次输出却没有结果，都在一点点消耗行动力。但做自己喜欢的事，每天都能保持行动力满满的状态。

现在上线的第一个插件用户 100+ 啦，每天都有自然增加（计划做 SEO 但一直没落实😂）。虽然用户不多，但还是很开心。
