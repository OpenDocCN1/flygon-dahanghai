# 二胎宝妈推团长，日均多赚两百+

我是云端，刚加入生财不久。2023年5月4日，我把这段经历整理成复盘；帖子发出后拿到173个赞，还被标为精华。

在微信群卖货这件事上，快团团几乎是团长们最顺手的工具。生财已经连着做了几期快团团航海训练营，这个动作本身就在释放信号：接下来加入微信带货的团长，数量大概率会快速上涨。

人一多，机会不一定只在“自己卖货”这一头。换个站位，在入口处给团长递工具，也能让双方都受益——进场的人越多，工具越不缺需求。我说的“工具”，就是把大团长推荐给需要的人，自己从中拿佣金。这个模式跑通后，一天多赚两百多块是可以期待的，而且对下班后时间零碎的上班族、需要照顾孩子的宝妈都比较友好。
