# 6.1 一文读懂 GameFi

GameFi 这个词乍看起来很陌生，其实拆开就很好理解了。它由 game 和 fi 两部分组成，其中“fi”来自 DeFi，也就是去中心化金融。由于 GameFi 从诞生之初就建立在价值网络之上，所以天然带有金融属性。

在当下的 Web3 世界里，GameFi 主要表现出两个核心特征：

一个是 DeFi 的游戏化。目前市面上大多数 Web3 游戏，本质上都是把去中心化金融逻辑放进游戏场景里，再呈现给玩家。玩家在游玩过程中可以赚到钱，比如通过质押代币、质押 NFT，或者购买 NFT 来获取收益。这些金融玩法只是被披上了游戏的外壳，让参与方式看起来更轻松、更有趣。

另一个是游戏装备的 NFT 化。和传统游戏不同，GameFi 游戏里的所有装备都是 NFT。既然是 NFT，就说明这些资产真正属于玩家自己。

之前我们在讲传统游戏的时候提到过一个问题：游戏公司如果想把你的装备收走，或者封掉你的账号，你身上那些道具和装备就会直接消失。换句话说，你根本不拥有这些游戏装备的产权；就算游戏公司经营不下去跑路了，你的装备也会跟着一起不见。

但在 Web3 世界里，游戏装备本身就归你所有。哪怕游戏公司哪天跑路了，也不影响你的资产，因为这些装备一直存放在你自己的钱包里，谁都拿不走。
