# 3.5.6 让 Python 直接跑起来

在 Cherry 做数据分析，除了 MCP，还有一条路：用它内置的 Python 执行能力。是的，它能直接运行 Python 脚本，不用再复制到编辑器里手动跑。

操作例子：先让它“按月统计订单数量，只给 Python 代码”。

这时回复里还看不到运行入口，需要先配置。

[PRE9]

到左侧“设置”里的代码块设置，把“代码执行”以及下方相关开关打开。完成后，代码块旁边就会出现运行按钮。

要提醒的是：Python 跑在 Cherry 的沙盒里，和本机并不互通。所以直接让它处理本地文件是行不通的😓；纯计算类脚本没问题。这个能力刚上线，想真正打通本地文件交互，还得等后续版本继续迭代。

# 3.6 用 MCP 订高铁票 @成峰

旅行计划里最烦人的环节是什么？订票。高铁、飞机、不同 App 来回切，路线、价格、时间混成一团；旁边还有人不断问“票看了没”。每次都幻想：要是有个助手，把线路、票价、时刻整理清楚，再给点靠谱建议，那该多省心。

# 3.7 用 MCP 办一场名人聊天 @成峰

翻旧书时看到《人类简史》里一句：“农业革命是历史上最大的骗局”。我停了下来，脑子里冒出一个念头：要是能找几个人一起聊这个判断，比如让马斯克、孔子、尼采同场讨论，那该多有意思。

[PRE26]

这个念头并不荒唐。平时读书，我们很容易被作者的思路带着走，划了一堆线，本质上还是单向接收，缺少真正的观点交锋，难免单调。很多时候，深刻的洞见恰恰来自不同视角的碰撞。等等，我好像可以用 AI 把这个想法做出来。

对，我要让历史人物一起读我的书。只需要微信读书 MCP 加 Trae。想象一下：你一边读、一边划线，忽然马斯克、孔子、尼采和萨特围过来，就你划出的那句话热烈讨论，是不是有点小激动？😏

我让他们聊“人类是唯一会相信故事的动物”，结果很精彩：孔子说此论甚妙，人之所以为人，正在于能以礼乐传承智慧，这是故事的本源；马斯克把故事看作人类第一个虚拟现实，从进化角度看，这是造火箭、殖民火星的认知基础；尼采说故事即权力，弱者用故事安慰自己，强者用故事塑造世界，这是超人崛起的起点。看完这些观点，我的第一反应是：这比 AI 单纯总结书籍内容高太多了。每个视角都带来新启发，像真的参加了一场跨时空头脑风暴。

别担心，这个“思想派对”很好办。我已经踩过坑，现在教你零基础复制操作。三步搞定跨时空读书会：一、拿到微信读书划线；二、设置名人辩论阵容；三、享受多维度思想碰撞。读再多的书，不如和思想者一起思考一本书。
