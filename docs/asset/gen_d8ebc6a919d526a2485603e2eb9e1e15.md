# 4.2.1 情感类爆文，选题这样抓

情感类内容想跑出爆款，第一步不是急着动笔，而是找到真正有爆款潜力的素材。多去各大平台翻一翻、看一看，把那些具备潜力的案例收进自己的灵感库。

[PRE0]

什么样的素材值得留意？大致可以归为几类：能让人产生共鸣的、足够打动人的、容易引发讨论的、事情本身透着反常的。再往细里拆，有八个方向值得重点关注：

1）情节有起伏转折；
2）能调动情绪；
3）能提供新的信息；
4）贴近民生议题；
5）涉及明星或名人；
6）包含性相关元素；
7）带有暴力冲突；
8）与金钱利益相关。

判断一个故事能不能写，不妨用这个标准：上述八个要素里，至少要占到三个，越多越有爆款相。
