# 知识付费创业心法（11-37）：年入百万的实战复盘

之前写完1-10条知识付费心法后，这段时间又陆续有了不少新体会。今天把后面的内容整理出来，都是亲身验证过的感受，希望能给你带来一些启发。这个系列后面还会继续更新。

11、我这些年试过的新玩法、新项目不算少，其中80%都黄了，真正让我赚到钱的，其实是剩下那20%跑通了的。创业本来就失败居多，成功才是小概率事件。知识付费最大的好处，就是把试错成本压到很低。既然失败了也不会伤筋动骨，不妨多给自己几次尝试的机会。

12、做知识付费一定要有边界感，最核心的一条边界是：这单我不接，这个用户我不收。别小看劝退，它本身就是一种营销动作。大大方方告诉别人你做什么生意、不做什么生意，服务哪类客户、拒绝哪类客户，喜欢你的人会更喜欢你，然后来找你付费；不喜欢你的人也会自动走开，省得你浪费精力。守住边界，既赚钱，也省心。

13、永远记住：除了阅读、搭建知识体系和生产内容这三件事必须亲自动手，其他事情尽量外包出去。没团队的时候，我也习惯什么都自己上，聊用户、拉群、活跃气氛……结果时间全耗在这些重复琐事上，根本没机会成长。长期不成长，业务体量就会被困在很小的范围里。该分钱给别人赚就分，花钱买别人的时间，买得越多，你的盘子就越大，赚到更多的钱后，你又能拿钱去买更多人的时间。

14、真正高质量的交付，反而是“暴力”的。很多人觉得好交付就是不停陪用户聊、带用户实操、随时回答问题，如果你这么想，其实已经错了。错在两层：第一层，你选错了客户。没有最好的交付，只有更合适的用户。你的精力应该放在生产内容上，用户看完内容，交付就已经完成了；他付费，是为节省自己的时间买单。营销的重点在“营”，销售只是水到渠成的结果。我常和合伙人说，用户没成交，先别想怎么逼单，要看看你的内容够不够。内容到位，随便聊几句都能成交；靠套路拿到钱，说难听点就是变相忽悠。第二层，错在交付方式。越是优质的用户，越喜欢简单直接。比如有人付费就是想看看我的产品体系和交付模式，进来瞄一眼，或打个电话，就明白了，交付到此结束；有人就是想借我的流量推产品、做冷启动，我做完，交付也完了。如果还要你陪着他答疑、答各种基础问题，那八成是你收错人了。

15、每一款产品卖完，结果都要变成下一款产品的营销素材。举个例子，我把“产品见证群”跑通后，沉淀出一套SOP，它可以从0到1帮你搭一个新产品的预售方案。往底层看，产品见证群本质上就是在给产品发售制造销售素材。你本来不是大V，没有势能、没有流量、没有成功案例，直接做新品预售当然没底气。那就拉个群，在里面分享产品制作的细节，让用户参与进来，再把过程和反馈传播出去，这不就是现成的营销素材吗？这就像“平地抠饼”，你做的每一件事，都是在为后面的收入铺路。

16、知识付费创业，一定要懂得借势：借风口的势、借行业的势、借人脉的势。像我们团队这次发售《ChatGPT大师课》，就是踩中了风口，光小鹅通就卖了60多万，其他渠道还不算，预计这一年下来能做到300万。风口的势能转瞬即逝，抓不住就没了。紧接着，把ChatGPT和健身、医美、写作等行业结合，帮用户节省营销成本，这就是借行业势。会借势的人，才能在一段时间里快速积累财富。细水长流没错，但有暴富的机会，也一定要抓住。

17、复制自己，是知识付费创业者最后的杀手锏。它能帮你赚到更多钱，也能让业务体系更完整。比如我的定位是帮助自媒体创业者通过IP营销提升商业价值，在这个定位下，我可以帮不同垂直行业的IP搭建底层营销框架，也就是“个人品牌十字盾牌”。如果你想做更高客单价的产品、赚更多钱，就应该做一个“教别人复制自己”的业务：在我熟悉的领域，再造出一个芷蓝，培养更多和我一样的人。这些人会成为你生态的一部分，帮你一起交付、一起赚钱、一起产出内容。

18、社群生态里的每一笔交易，哪怕你直接拿不到钱，也要全力支持。财富来自交易。农夫用小提琴换了音乐家的斧头，表面上看物品总量没有增加，但那个小镇因此获得了更高的生产力，这就是价值的增量。你的社群用户之间成交，你没收到钱，但社群的势能提升了，你可以利用这个势能吸引更多新人进来，这就是新的增长。看看淘宝的C2C模式就明白了，平台先让买卖双方自由交易，最后自己靠直通车赚钱。

19、公众号现在对新媒体新手可能不太友好，但它是每个知识付费KOL必须有的一块阵地。为什么？因为你得把成交过的用户、从公域引来的用户“困”在公众号里。他们在小红书、知乎、抖音上看到的只是内容碎片，所以也用碎片化时间消费。但你想让用户买高客单价产品、想让他复购，就必须给他一个能沉浸式阅读、和你深度链接的地方，公众号正好承担这个角色。你只需要把之前输出的碎片化内容，按逻辑整理一下，放到知识星球上，就能支撑起这块阵地。

20、别动不动就扩团队。你的收入是有周期的，不稳定，还会受大环境影响；可一旦扩团队，成本每个月都在那儿。我见过太多工作室，就是因为团队越扩越大，最后撑不下去关门的。更好的做法，是把核心学员培养成“模块化”交付团队，随用随取、也可以外包，就像U盘一样即插即拔。这些核心用户和你沟通成本低，配合起来反而更顺。

21、“懒”对知识付费创业者来说是一把双刃剑。从0到1的阶段你要是懒，连第一个正反馈都拿不到，后面更不可能有故事。但从1到10，如果你还像从前一样，把自己当成系统里的关键零件，整天琢磨怎么提高效率，那就走进误区了。这个阶段你要想办法让自己“变懒”，用资源和钱去雇别人的时间。做每件事之前，先问一句：这件事我能不能不做？能不能通过一个系统或机制让别人去做，我在旁边获利？所以，0到1要勤奋，拼的是体力和心力；1到10要懒人思维，用最少的时间精力去复制、放大0到1的成果。创业者永远不该是系统里的零件，而要是设计系统的人。

22、先赚目标客户的钱，再赚同行的钱；顺序要是反了，人设就塌了。我是先靠朋友圈卖付费社群，卖了几千个，赚到100万之后，才教别人做朋友圈营销。我见过很多人，自己小红书连一个万粉账号都没有，就开始做小红书陪跑，这个逻辑一听就矛盾，只要被质疑就反驳不了。所以，先成为行业KOL，你才有资格把自己的营销方案传给同行，去赚他们的钱。

23、只要你的产品在私域有复购场景，或者能走矩阵模式，付费流量一定要试一试。这里面的逻辑是：哪怕付费推广的成本和后端转化利润正好打平，也没关系，因为用户一旦进入私域，你还可以继续推复购、推其他产品，后续的这些触达都没有额外推广成本。拿我的舞蹈室来说，每个月在大众点评投5000元左右，只要客户到店转化，之后再卖她化妆品、舞蹈服装、课程包，全都是0成本。能更轻松地拿到精准流量，比什么花架子都强。

24、路径依赖对知识付费创业者来说太可怕了。我赚第一桶金是靠付费社群，后来看什么商业模式，都会不自觉地先用社群玩法去验证一遍，结果白白错失很多机会。很多人都是这样：成于某种路径，最后也可能败于同一种路径。后来我花了一年时间，刻意练习“二维思考法”：先把固有的思考路径清空，再看问题，这时你常常会发现很多新可能；然后再把之前的路径拿回来，和这些可能做对比，用成本原则判断哪个方案最优。这样才能跳出惯性。

25、能做咨询，就别做代运营。做代运营的，到最后很少有客户能满意。道理很简单：每个人的认知边界和执行力不一样。我自己做IP营销咨询，太清楚这一点了。同一套方法论，有人拿回去马上就能出正反馈，有人过了一年还是老样子。你收几万块钱的咨询费，对方只要觉得方法论有用，就算最后没做成，也不会埋怨你；可如果你收人家几十万做代运营，最后因为他自己执行力不够没做出结果，他一定会骂你，还会找你退费。再说，咨询的成本也低：做个圈子，每月定时电话沟通，或者线下聚几次做分享，这事就完成了。代运营可要组团队，成本高不说，做不成口碑就全砸了。

26、你想把业务做大，就必须接纳比你牛的人进圈子，甚至愿意让出一部分利益，想尽办法把他们变成合伙人。真正的牛人，不是专门搞定事，而是搞定人。搞定了他，他自然会替你搞定大事。韩信点兵，刘邦带将。创业初期，你可能要多带兵，甚至把自己也当兵用，跑通商业闭环；可到了后期，你的时间和精力一定会不够用，那时候就得学会带将。这也是为什么大公司都采用合伙人制——不搞合伙人，公司根本做不大。

27、别把时间先花在闷头做产品、做流量上，要先研究“怎么模仿”。你模仿谁？他做的产品，你能不能做？他发在某个平台上的内容，你能不能发？制作这些内容的门槛高不高？能不能持续做下去？这几个问题想明白了，接下来才算轮到执行力。我看了不少自媒体创业者，真正赚到钱的人，一开始就有明确的模仿对象；那些没赚到钱的人，多半是先凭自己想象做起来，做一段没有正反馈，自然就放弃了。

28、关键词逻辑一定要重视。从你的定位，到你发的每一篇文章、每一条视频，本质上都是在回答某个用户关心的关键词；甚至你的用户身份，也是一串关键词。我给合伙人做定位时，会刻意帮他们建立关键词思维，比如社会热点关键词对应流量，用户身份关键词对应画像，痛点关键词对应精准流量。定位确定以后，把所有和用户本人、用户需求相关的关键词都列出来，然后做内容营销时，一个个铺进去。

29、你一定要有一条“静默成交”的用户路径，因为你不可能每个用户都聊一遍，有些用户也不需要聊完再买。公众号就是一个很好的静默成交工具。把你在小红书、知乎、抖音上发过的碎片内容，在公众号上按逻辑重新整理一遍，就是一篇深度好文。文章里放上课程购买链接，再去引导用户持续转发公众号文章，产品曝光越来越大，静默成交的用户自然越来越多。

30、做营销之前，一定要想清楚自己到底擅长什么。比如我，不擅长做产品，也不太擅长做流量，真正擅长的是做圈子、做资源整合。知识付费领域，你可以根据自身情况选三个方向：如果你精力不够、不愿社交、情商还偏低，那就安心做产品，做出来以后找到有流量的人，给他们极高的分销佣金比例，让他们帮你卖，你在后端持续更新维护。如果你网感很好又有精力，那就去做流量，不管做文章视频还是混圈子，只要流量在手，垂直方向上你想跟谁合作都行。第三种就像我这样，擅长资源整合，那就做社群：先舍弃一部分自己的资源，给社群注入原始价值，然后不断找各个领域的KOL谈合作，用社群价值换他们的势能或产品。圈子势能越来越大，最后就成了你的王牌产品。

31、不管用户现在买不买，你都要第一时间告诉他你有什么产品，并且经常在朋友圈或所有已知渠道展示自己的付费产品。我翻过不少知识付费人的朋友圈，基本就两种：一种疯狂刷产品加出单截图；还有一种，一个月也不发一次产品，每天做干货分享，听着都对，但就是不知道他是干嘛的。用户只有知道你卖什么、做什么生意，才能在自己有需要的时候想到你，然后联系你、买你的东西，甚至直接在朋友圈就成交。不知道就等于想不起，想不起就不会买。

32、引流要做加法，服务交付要做减法。帮付费用户科学做决策，才是服务的重点。引流端的加法怎么理解？我用《100个朋友圈营销技巧》和《100个个人IP营销技巧》来做引流，目的就是多写内容，尽可能覆盖更多用户需求关键词，在标准答案上多铺一些内容。有部分用户通过平台搜索，在文章里看到一段内容，觉得和自己定位一样，说得有道理，但内容偏标准，没有他想要的具体场景，于是他会加你微信，来问具体问题，这时候你就可以收费了。收费的理由是什么？我来帮你做减法：给你更垂直、更深度的场景化回答，并且能根据对话快速反馈。所以，引流时用加法让更多人看到你、找到你；用户付费后，服务上多做减法，帮他节省时间、精准决策、快速反馈，他自然会觉得值。

33、大客户和好客户不是一回事。大客户愿意付费，好客户不仅付费，还认同你的观点，甚至愿意帮你做口碑传播。我经常和学员说一个词——“关键裂变人”，关键裂变人就是典型的好客户。他们会到各个圈子替你宣传，传播你的产品和理念，这种人一定要加倍呵护，给两样东西：一个是“精神爽点”，一个是“物质激励”，说白了就是名和利。只有这样，他们才会持续帮你传播。至于大客户，按约定做好服务就行，别在情绪上过多投入，也许他们本来和你不同频，你太热情反而让人不舒服。

34、关系也能变成一种财富，而且能帮你降低超级个体的运营成本。很多人问我，一个人运营5000人的付费社群、500人的合伙人团队，怎么忙得过来？成本是不是很高？其实我这边只有2个固定员工和1个兼职，靠的就是“关系财富”。比如我有一个合伙人在小红书领域非常牛，产品和服务也好，就是不擅长引流，那我就可以持续给他推荐优质流量，让他不用为流量转化发愁。这种合作关系沉淀下来，就是财富。以后我需要小红书方面更深度的内容和交付，拉上他就能干。这种深度捆绑，随着时间推移，协作效率会越来越高，成本比雇一个专职员工还低。大家互相都能赚到钱，这是关系财富沉淀的基础逻辑。想低成本做自媒体创业，你就要架构出这么一套产品体系，让关系财富可以在体系里不断沉淀。

35、学会低成本试错，是知识付费创业者最基本的一项认知。你看到我跑通的玩法，看到我赚钱的业务，那只是结果，都是试错之后定下来的。这个过程中我放弃过很多，比如之前想做的一个针对会员的“小红书云创作”项目，简单说就是大家一起去创作小红书内容，变现后再分钱。这个没成。为什么？第一，普通会员群用户之间关系不够紧密，协作成本太高，没办法像工厂一样统一管理、流水线生产；第二，后端利润分配太复杂，大家积极性不高，没有合理利润驱动，自然没干劲；第三，原创内容版权不好分配。这个项目我们试了1个月就淘汰了。但好在成本可控。后来“云创作”在普通会员群里没跑通，却在合伙人这个关系更紧密、门槛更高的社群里成功了。没有前面的试错，我不可能有这种快速迁移模式的能力，也不会在后面赚到钱。所以，试错是必要的。一味守旧是稳定，但当风口来了，你根本捂不住红利，更别说什么短期利润最大化了。

36、知识付费创业确实需要线下更深度的连接，但我建议初期不要搞大活动，最好是各区域的小规模线下见面。原因有三个：第一，大型活动需要专门团队支撑，协调酒店、签到、物料、流程，这些事一个人干不了，成本太高；而超级个体最大的优势就是机动灵活，没必要背这种负担。第二，线下聚会人一旦太多，基本聊不出有价值的信息。上次我们在北京的合伙人聚会，一个屋子里小30个人，聊完发现什么都没聊出来。第三，还没起势的时候，要保持核心凝聚力，也就是点对点的深度链接，千万别急着去中心化；否则小圈子一形成，个人品牌势能增长就会被拖慢。当然，后期用户量大了就不用担心这些，反而要去赋能，多捧几个社群KOL出来，帮他们做流量曝光、产品曝光，他们以后会反哺你。

37、如果你实在不擅长去公域平台做内容引流，别硬逼自己，不如多花点钱去别人的付费圈子里认真做分享，结识优质用户。但前提是，你的后端必须有一个超高客单价的产品。因为在私域混圈子引流，本质上是拿你的单位时间价值去换连接，你今天干活，今天就有人来找你；今天不干，就没人来。
