# 3.2.3.2 每日养号：先把账号养活跃

账号到底要不要养？这个问题不少人都在纠结。先给结论：如果账号本来就是自己在用，而且平时经常刷小说类短视频，那通常不必专门养号；除此之外，无论新号还是老号，都建议做养号处理，把账号的基础权重维持住。养号最核心的目的，就是让账号更容易获得自然流量。

想快速找到同行，其实有个很省事的办法：打开抖音，点右上角放大镜，在搜索栏输入“小说”“小说推荐”“推文”等关键词，页面很快就会推来大量同类型视频。找到同行账号后进入主页，点开“私信”旁边的小三角，还能看到更多同类账号，信息源一下就拓宽了。

新号注册后，一般用3天左右来模拟真实用户行为。每天尽量凑够两小时活跃时间：刷到同行作品时别急着划走，停下来看看对方选了什么文、开头有没有改、评论区怎么引导，顺手点个赞、收个藏，活跃时长自然就有了。观看时间越长越好，理想状态是养到一打开抖音，首页就能刷到同行的视频。

抖音不只是发布视频的工具，也是一个记录、分享的平台。就算平时不太爱刷短视频，也可以每天时不时打开划一划，进直播间挂一会儿，偶尔点点赞，让平台知道这个账号不是机器人。

开始发布作品之后，养号同样不能停，要维持账号较高的活跃度。尽量保持日更，内容才能保持新鲜和丰富，粉丝也更有机会刷到我们的视频；这既能维护老粉的忠诚度，也能吸引更多潜在粉丝关注，同时不断提高账号权重。

日更还是一种态度，说明我们对项目认真投入，愿意每天花时间和精力去满足观众需求，也满足自己的目标。不要短时间没看到成绩就跑了，前期的付出要变成经验，而不是沉没成本。

再给大家一些参考数据：前期不够熟练时，产出一条视频大约需要1小时；后期熟练后，大约只需15分钟。如果只做一个号，并且每天能保证更新一条以上，通常14天内就能做出万播作品；坚持实践一个月，出单率可以达到40%-80%。如果前期还不熟练，做不到日更产出视频，那就尽力多更，后续再逐渐提速、提升更新频率。

任何项目的结果，都离不开持续实践。
