# 5.4.3 台词拆解

简单来说，就是把原来的剧情顺序打乱重组。比如原本有 A、B 两个情节，A 在前，B 在后，但在剪辑时你发现先放 B 再放 A，观众也完全看得懂，那就放心大胆地把 B 挪到前面。

放到一句话里也是同样的道理。一句台词由 A、B 两部分组成，顺序对调后意思不变，那就随便换。

除了调顺序，还能做减法——把那些不太要紧、可有可无的话删掉。

举个例子：某段剧情里，男主角一边夸女配，一边贬低女主。原始台词是：“我从高中就喜欢你，那时候的你，天真善良，像天使一样反倒那个顾安然娇蛮任性，让人吵闹。”

第一版，原封不动保留。

第二版，省掉“像天使一样”和“让人吵闹”：“我从高中就喜欢你，那时候的你，天真善良，反倒那个顾安然娇蛮任性。”

第三版，连“反倒那个顾安然娇蛮任性”也不要了：“我从高中就喜欢你，那时候的你，天真善良。”

第四版，只留最核心的一句：“我从高中就喜欢你。”

换句话说，只要不破坏剧情逻辑、不影响观众理解，台词怎么调整都随你。这就是“分割台词”的真正价值。
