# 微缩美食视频：从分镜提示词到成片

首图的关键词可以这样定：微缩景观里，一群穿着汉服的小人跑到这道菜所需食材的生长地采集，食材的尺寸远远大于人物。你按照这个格式与思路，写出场景 1-7 的画面详细描述词，重点聚焦主体。注意，固定短语【微缩景观，一群穿着汉服的可爱小人】不要改动。画面要求有四条：第一，食物相对小人要显得巨大；第二，做菜场景放在古风厨房里；第三，收尾吃饭画面要出现一只巨大的碗，穿汉服的小人们围着做好的巨大食物开吃；第四，镜头之间保持连贯，不要堆太多其他元素。

# 6.5 视频号还有哪些变现路子 @郭耀天

视频号的变现模式很多，下面只是目前最常见的一部分，我把它整理出来供大家参考。

# 6.5.1 内容全网同步，一鱼多吃

视频号目前制作内容比较简单，而这些内容不只能发视频号，还可以同步到抖音、快手、小红书。在抖音、快手能涨粉，有的领域还能直接带货，尤其是小红书。粉丝达到 1000 后，可以申请小红书商单接广告，收益也比较可观。所以做出来的内容别只发视频号，它还有更多用途。粉丝量起来后，账号也可以直接转手出售。现在的内容还可以发布到今日头条、百家号，收益都不错。核心思路是让内容价值最大化，不浪费素材：东边不亮西边亮，这个平台不火，其他渠道可能就火了。同步更新只是分把钟的事，一个平台赚几百，多个平台加起来收益就高了。

# 6.5.2 视频号生态内的其他玩法

以下具体玩法不详细展开，只提供思路。感兴趣的朋友可以在生财有术索引站（👉索引站首页）检索关键词，查看更详细的玩法。

**游戏任务**：如果视频选题偏娱乐、游戏相关，可以在“创作者服务>视频变现任务”路径里挑选可参与的游戏任务，通过任务入口发布视频。这样发布的视频可以挂载游戏任务链接，新用户点击链接进入游戏后，在游戏内看广告或充值，产生的收入会按平台规则结算给创作者。

**广告变现**：视频号流量好，尤其是一些细分领域，会有人主动找你做相关广告。很多广告其实很软，我们未必看得出来。平台也提供视频号互选广告，但需要达到 10000 粉丝才有资格；粉丝不达标，可以私下接单，比如做工具号，就会有不少单子可接。

**IP 变现**：玩法和抖系很像——自己做人格化账号，在视频号更新干货，把人引到私域，做自己的产品服务，围绕 IP 提供相关服务。现在做的人很多；如果能真人出镜，或者在某一方面持续提供价值，真的可以干。

**短视频带货**：视频号粉丝起来后，发布短视频时就可以植入产品，直接带货。目前带货有要求，按规则完成即可开启。做这件事的人很多，尤其是做书相关的视频，直接带货很常见。

**直播带货**：现在打开视频号就能看到直播，很多都在带货。如果自己有粉丝，或者掌握一些玩法、有直播人才资源，真的可以干。

**课程变现**：这个方向很多，基本做账号的都会开发自己的课程，或者卖一些课，比如英语口语、驾照考试、创业培训，都是课程变现。

**实体门店变现**：视频号已经开始玩同城了。你可以拍自己店里火爆的场景，下方带上门店链接，直接引流同城客户。

**CPS 变现**：主要用在游戏或小说内容。前端输出小说的某个章节，让人看得心痒痒，点击下方购买付费阅读，就能赚到钱。

**会员服务变现**：以前做社群的，可以直接在短视频里输出干货，吸引感兴趣的人；想继续学习，就加入付费社群。

**视频号打赏变现**：目前有一群语录主播靠打赏赚钱，我看到一个主播一天就赚百万以上。如果真有才艺、有口才、有能力，可以尝试。

**音乐推广变现**：版权方每月都会发放任务，每条能赚 200 到 2500 不等。做音乐号的可以通过这种方式变现，是个不错的模式。目前可推广的渠道也不少，可以尝试。
