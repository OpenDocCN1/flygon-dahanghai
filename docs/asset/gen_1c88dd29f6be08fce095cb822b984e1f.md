### 02. OpenClaw 实战：把知识库变成智囊团

**1. 用 OpenClaw 搭建你的专属知识库，让作者替你出主意**

设想一下：梁宁、刘润、华杉同时坐在你面前，围绕你眼下的难题争论半小时，会是什么体验？

过去这只能想想，如今靠一个专属知识库就能做到。

在 OpenClaw 的运作方式里，你读过的书、收藏的干货，都不是静止的文字，而是能随时开口的数字分身。你抛出一个品牌问题：华杉会讲**超级符号**；刘润会从底层逻辑出发**拆解成本**；梁宁则会提醒你关注用户的**确定性依赖**。你不再是在翻笔记，而像在主持一场顶级智囊团的圆桌讨论。

这一章要教你的，就是用 30 分钟，把收藏夹里那些作者“唤醒”，让他们 24 小时待命，随时为你辩论。

搭建时间：**30 分钟**。一次搭好，长期可用。

**开始前要准备什么？**

动手之前，先确认三件事：

- 一台腾讯云轻量应用服务器，并且已经装好 OpenClaw。
- OpenClaw 已经配好模型，能和 AI 正常对话。这里演示用飞书和小龙虾交流，你换成其他 IM 也可以。
- 一个微信公众号，个人订阅号即可，用来登录文章导出工具。

不需要编程基础。下面每一步都有完整操作说明，照着做就行。

**第一部分：配置 OpenClaw 模型**

如果你的 OpenClaw 还没配置模型，先完成这一步；已经配好的可以跳过。

**1.1 购买 MiniMax Coding Plan**

OpenClaw 需要 AI 模型来驱动对话。这里选 MiniMax，属于国产模型里性价比较高的产品。

1. 在浏览器里访问 MiniMax 开放平台，注册并登录。
2. 进入「套餐管理 → Coding Plan」，购买 Starter 月度套餐，29 元/月。每 5 小时 40 次对话，日常知识库问答足够用。
3. 购买完成后，在同一页面找到 **API Key**，它以 sk-cp- 开头，点击复制。

[PRE0]

**1.2 在 OpenClaw 中配置模型**

1. 打开腾讯云轻量应用服务器的 OpenClaw 管理页面。
2. 在「模型 （Models）」区域，第一个下拉框选择：MiniMax（国内-Coding Plan）。
3. 第二个下拉框选择：**MiniMax M2.5**，这是最新旗舰模型，质量最好。
4. 填入刚才复制的 API Key。
5. 点击添加。

**1.3 配置飞书通道**

1. 在「通道 （Channels）」区域选择飞书。
2. 按提示完成飞书机器人的创建和绑定。

**1.4 验证**

在飞书里找到刚创建的机器人，发一句“你好”。如果它回复了，说明配置成功。

**第三部分：搭建知识库**

这一部分是核心。但别紧张，你不需要懂任何技术，全部交给 AI 来做，你只需要复制粘贴几段话。

**为什么不能直接让 AI 读文章回答问题？**

想象你有一书柜的书。你不可能每次问问题，都让 AI 从第一页翻到最后一页。所以我们先给这些文章建一套“索引”，就像图书馆的编目系统。

AI 会把文章切成小段，给每段做一个“语义指纹”，存进数据库。以后你提问时，AI 拿你的问题去比对指纹，几秒钟就能找到最相关的那几段。不是关键词匹配，而是理解意思的匹配。

效果就是：你问“小公司怎么跟巨头竞争”，它能找到讲“破坏性创新”的那段，虽然原文里压根没出现“小公司”三个字。

**3.3 注册硅基流动，获取 API Key**

AI 执行到第 5 步时会停下来，问你要硅基流动的 API Key。这个 Key 用来做向量化，把文字翻译成 AI 能理解的数字。

我们用硅基流动（SiliconFlow），原因很简单：国内直连、注册只需手机号。

1. 打开浏览器，访问 cloud.siliconflow.cn。
2. 用手机号注册并登录。
3. **完成身份认证（重要！）**：进入「账号管理」→「实名认证」，完成实名认证。未认证的账号有严格的请求频率限制，向量化过程会报错 RPM limit exceeded。
4. 登录后，点击左侧「API 密钥」→「创建新的 API 密钥」。
5. 名称随便填，比如“知识库”，点创建。
6. 复制生成的 Key，它以 sk- 开头。

[PRE14]

这个 Key 非常重要，丢了就得重新创建。建议先存到备忘录里。
