# 提示词没效果？别只怪模型

逆向提示词能不能出效果，确实跟所用模型有关。如果你暂时用不了国外模型，后面会附一套豆包专用提示词，专门用来生成文章。

**第二：任务说明（30%）：把“要什么、不要什么”讲明白**

别把AI当成自由创作者，它更像按指令办事的执行者，方向得由你来定。所以，思路要交代清楚，不能只甩一个主题过去。

重点说清四件事：

**第一，明确产出物。** 是标题、开篇，还是短视频脚本？任务要具体，别只丢一句“帮我写篇文章”。

**第二，锁定读者。** 受众不同，语气和用词就完全不同。你只需要说明读者是谁、有什么特征，AI自会调整措辞，这方面它往往比人更敏感。

**第三，设定目的。** 想让人点开、收藏、关注，还是读完继续往下滑？目标不同，写法就不同。

**第四，划出禁区。** 提前说明不要什么，比如不要空泛、不要太官腔、不要写成总结汇报。很多时候，把“不要什么”讲清楚，比只讲“要什么”更管用。

**第三：提示词运用（10%）：先会表达，再谈技巧**

前两步做到位，技巧只是加分项。提示词本质上是把需求结构化地表达出来。前两步扎实，效果能再上一截；前两步没做好，光堆技巧也没用。

真正好用的提示词框架，通常是在和AI反复对话中磨出来的，最后沉淀成你自己的skills或正式prompt。

把下面这个框架套到日常需求描述里，产出质量通常会有明显差别。

不必全盘掌握。先借最小结构说明，了解以下几项就够用。

**【目标】一句话讲清你要的结果。** 写📕文案、优化一段话、列个计划都行，不必解释原因，直接说要什么。

**【背景】交代任务发生的场景。** 不然AI不知道你在做什么生意、处在什么阶段。背景越具体，输出越准。

**【对象】说明内容给谁看。** 读者有什么特点？比如给完全不懂运营的新手看，就不能有专业术语。AI知道受众后，才能调整说话方式和深度。

**【任务步骤】告诉AI按什么顺序推进。** 别让它一股脑直接输出。写长文时，可以先要框架，你确认后再逐段展开，中途能及时踩刹车。

**【约束要求】提前讲清红线和要求。** 风格是口语化还是正式，字数多少，哪些词不能用、哪些方向不能走，哪件事必须重点体现。

**【输出格式】明确最后交付的样子。** 用1）2）3）分点输出，直接给正文不要解释，还是先结论再理由？不说格式，AI可能给你一大坨，还得自己整理。
