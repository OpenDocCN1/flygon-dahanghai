# 文案能吸金，培训要有格局

很多人认识我李思念，是因为我会写文案。创业九年，文案力几乎成了我最醒目的个人标签：朋友圈长期更新，码过的字累计过百万；这些内容在微商圈、创业圈被大量转发；小红书上也靠文案聚起不少粉丝，累计变现七位数以上。

有时候我会觉得，文案真是一件能改写人生轨迹的利器。

当你自己动手写原创文案，就会在遣词造句中训练思考，慢慢形成自己的核心观点。观点借文案扩散出去，把同频的人吸引过来、影响他们、打动他们；而这种影响力又会反过来给个人品牌加码，直接体现在事业结果上。

写了很久之后，去年我终于给自己的文案风格定了名字——“心金文案”，意思是既具备赚钱能力，又能走进读者心里。文案和普通文章不一样，它天然带着商业目标，所以能带来收益很关键；同时它又要装得下情绪、让人有感触，因此写得走心也少不了。

作者：黄勤文｜日期：2023-01-03

我是黄勤文，第九公社联合创始人。此前两篇《视频号三天千粉、内容规范、违规、官方认证等技巧分享》和《互联网小白上岸避坑指南》在圈友中反响不错，这回写下第三篇《互联网项目培训从业者保姆级教程》，从知识付费培训老师的视角聊心得。全文约1.2万字，篇幅不短，感谢大家耐心读完。

2019年我读大二时开始带队做抖音培训，连续四年深耕互联网项目培训。目前团队积累了几千名学员，项目交付好评率达到97.8%，也帮不少普通人在互联网上稳定赚到了钱，见证了许多人从新手成长为老手。

培训本身不是讨喜的职业，容易背骂名，被看成“割韭菜”的“镰刀手”；做得不好，既损阴德，也可能赔上职业生涯。但与此同时，知识付费成了热赛道，不少行业大佬亲自下场卖课程、做社群。分众传媒的江南春、新消费领域的王岑等老师都入局了，这说明培训行业得到了强者的肯定，也成为普通人向上管理和晋升的重要途径。

我从业四年，谈不上多大成绩，但愿意把一些培训心得分享出来，给培训新手做个参考，也期待更多有格局、有职业素养的培训老师出现。

### 一、培训行业为什么越来越火

越来越多行业大佬进入知识付费领域，卖自己的课程和社群，比如江南春、王岑等。强者纷纷肯定培训行业，也让它成为普通人向上管理和晋升的重要路径。
