# 3.3 粉丝量 vs 话题权重，哪个该排第一？

先问一个做账号时常碰到的问题：粉丝数量和话题权重，究竟应该把谁放在前面？
A：优先粉丝数
B：优先话题权重

[PRE0]

正确答案：B。

我的判断是：话题权重在前，粉丝规模在后。

原因并不复杂：关注者越多，内容覆盖的领域通常越杂。所谓“略懂”和“专业”的差距，就像一个停在珠穆朗玛峰半山腰，另一个已经站上峰顶。换句话说，在同一话题下，你获得的赞同越多，在该话题里的排名就越高。

当然，粉丝量同样不能轻视。关注者数量本身也体现用户对博主的喜爱程度。只是两相比较，话题权重比粉丝数更关键。所以看到别人粉丝多，不必先慌；只要你在垂直领域持续输出，对方很难在专业赛道上压过你。

另外，如果你的产品走泛流量路线，比如鞋服这类消费品，又依赖直播间成交，那么直接入手一个几十万粉的账号，也不失为性价比较高的选择。
