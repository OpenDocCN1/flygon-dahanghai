# 2.2 时间管理，先记录再复盘

很多人一想到提升效率，第一反应是找工具、列计划、排日程，却忽略了一个更靠前的动作：先弄清楚自己的时间到底去了哪里。时间管理真正该迈出的第一步，不是急着安排未来，而是如实记录当下，再定期回看分析。

记录的意义，在于给时间留下痕迹。你可以把一天中做过的事、花费的时长简单记下来，不必追求完美格式，也不用刻意美化。只有拿到这份真实的“时间账单”，你才会发现：哪些事情占用了大块精力，哪些碎片被悄悄浪费，哪些拖延反复出现。没有记录，所谓时间管理很容易变成凭感觉做计划。

复盘则是在记录之后追问原因。每隔一段时间，回看自己的时间去向：哪些安排值得保留，哪些环节效率偏低，哪些任务其实可以删减、合并或延后。复盘不是责备自己，而是用事实校准行动，找到更适合自己的节奏。

记录让你看见问题，复盘帮你调整方向。把“记录—回看—调整”变成习惯，时间管理才有了可靠依据。别急着追求复杂方法，先从认真记下一天、周末做一次复盘开始。
