# 3.9 方式八：先接定制，再产品化 ★★ @刘小排

当客户肯先掏钱、请你围绕他的具体需求来做开发，这本身就是一条很值得重视的生意路径。

码叔在生财有术分享过自己的打法，靠的正是这条路。他从6月开始自学Google插件开发，仅用半年就变现了几十万元；这套方法可复制。他的习惯是先接定制需求，而不是自己凭空造一个idea。

流程也不复杂：有人知道码叔懂编程，带着明确需求来找他，付费请他开发；等这个需求被做出来，他再琢磨怎么把它变成可复制的产品，卖给更多有类似需要的人。

十年前，我在一家做软件外包的公司待过。公司主要接欧美客户的软件外包项目，但老板很有眼光，很早就看透了一层：既然客户肯掏钱让我们开发，为什么不把其中共通的部分做成标准方案，再卖给其他客户？后来公司也陆续推出过一些小型SaaS产品，其中有的还做出了小成绩。这家公司叫重庆诺怀软件科技有限公司，至今仍在经营，我本人也是小股东之一。

国际上更有名的例子是Typeform和Basecamp。它们最早都做软件外包，后来从客户委托里提炼出共同需求，再把解决方案产品化。两位创始人的原话如下。

生财有术里有很多独立开发者，常常会收到付费定制的开发请求。完全可以把这些力量组织起来，从中寻找可以产品化的机会。

注意事项：凭空造需求，往往是坑。

这不是一套值得推荐的方法论。靠生造idea做成的公司，少之又少。

把它放在这里，是想给各位提个醒。

下次你脑子里突然蹦出一个“天外飞仙”式的绝妙点子时，先多问自己几句：用户在哪里？谁愿意为它付钱？

最容易骗过的人，其实是自己。一个凭空想出来的idea，很容易让我们越看越兴奋。千万别轻易爱上自己的想法。
