# 情况一：售后违规避坑清单

做视频号橱窗，下面五类问题最容易触发处罚。提前看懂规则、该报备就报备，很多麻烦其实可以避开。

**1）承诺不兑现：延迟发货或无法发货**
商家没有按平台规则或事先约定给用户发货，也没有提供承诺的服务，就属于这一类。平台通常会停用橱窗功能三天，同时下架相关商品。

应对上，如果确实因为各种原因发不了货，要尽快向平台报备，或者主动和客户沟通取消订单。操作有两条路：一是在小店后台直接提交报备（可参考下方图示）；二是向平台官方邮箱 weixinlive-JF@tencent.com 发送报备邮件。只要报备及时、理由正当，万一后续被误判，再联系官方小二说明情况，通常有机会撤销处罚并恢复开播。

[PRE0]

要留意：单次报备最长覆盖15天，到期后必须重新报备；若超期未续报，仍会按承诺未履行处理。

规则原文可点开查看：[《视频号橱窗商家【违背承诺】实施细则》](https://support.weixin.qq.com/cgi-bin/mmsupportacctnodeweb-bin/pages/nkTpiypd1bKfg6Xz)、[《关于延迟、无法发货报备的指引公告》](https://support.weixin.qq.com/cgi-bin/mmsupportacctnodeweb-bin/pages/IUPaL12CZdMSb1YQ)。

**2）越界带货：推广超范围商品**
橱窗达人把平台明令不得销售的商品类型放上橱窗推广，就踩了这条线。它既包括平台禁售商品，也包括商家没有对应资质却开通类目来卖的商品，超低价商品同样在内。

比如，皮色料属于珠宝玉石禁售范围；没有相应资质还把手表作为赠品送出；莫桑钻属于平台限制出售的商品；低价珍珠饰品也在平台禁售清单里。

应对时，先弄清平台哪些类目开放、哪些不开放、哪些属于定向准入，并掌握部分定向准入商品的销售底价。常规情况下，直播间只能上架与绑定小店已开通类目一致的商品；如果想卖其他类目，或把它当赠品送出去，都应先查规则文档，确认不在禁售范围内。

细则查询入口：[《相关商品橱窗类目准入规则》](https://docs.qq.com/sheet/DTURoVFZiVXdRQlJj?tab=BB08J2)、[《视频号橱窗类目、商品资质总览》](https://developers.weixin.qq.com/doc/channels/Operating_Specifications/Category_Product_Qualification.html)。

**3）发布违禁信息：别碰法律红线**
所发布的信息或商品触犯《中华人民共和国广告法》等法律法规，就会归入此类。常见有两类：一是食药同源、滋补类产品在直播中容易被说成有治疗功效；二是主播或直播团队本身已被全网拉黑，或涉及违法违规团体。

例如，口播称亚麻籽油能疏通血管、养护大脑，把普通食品功效说大而被罚；拍A发B销售“幸福小丸子”（壮阳物品）被罚；主播使用“男人加油站”“懂得懂，一个小时打底”等话术被罚；古玺堂精油炙疗宣称缓解腿疼、颈椎膝盖不适，把护肤品说成有医疗作用而被罚。出现这些情形，处理结果是禁播15天。

应对时，主播话术要避开极限词、虚假文案和欺骗性表述，同时熟悉平台列出的违规场景。

相关规范可查看：[《视频号橱窗达人【发布违禁信息】实施细则》](https://support.weixin.qq.com/cgi-bin/mmsupportacctnodeweb-bin/pages/DfeesuVilkvupzuI)。

**4）虚假宣传信息：话术和货品都要真**
达人在橱窗推广中使用极限词、编造限时紧迫文案，或以欺骗、误导方式影响用户，都属于虚假宣传信息。平台判罚时主要看几类信号：货不对板、质量问题、用户投诉、纠纷单量偏高、物流异常。

比如，商品与描述不符、出现少件，消费者体验差，举报投诉数据较多；品质与描述不一致，还叠加物流异常，同样会引发大量投诉；主播宣称商品能祛斑，但提供的特殊化妆品证明名称与商品名称对不上，无法证明该证明对应此商品，也会被罚。

应对上要记住，虚假宣传是高发判罚，核心往往是直播间展示的货品和实际到手货品质量不一致，进而引发投诉或纠纷。另一个容易踩的点，是承诺物流很快或几天内送达，最终没做到而被举报。因此要把产品品质放在前面，直播样品与正品保持一致；主播逼单时别给出过多承诺；售后必须跟上，客服要及时响应咨询并处理售后问题。

处罚判责标准见：[《视频号橱窗描述不符/虚假宣传纠纷处理判责标准》](https://support.weixin.qq.com/cgi-bin/mmsupportacctnodeweb-bin/pages/pHLzoZgWNYFLH19M)、[《视频号橱窗交易纠纷处理规则》](https://support.weixin.qq.com/cgi-bin/mmsupportacctnodeweb-bin/pages/i7p71W687JAavsYw)。

**5）信息不合规：别缺项、别错挂类目**
这一类主要集中在商品重要信息缺失和类目乱挂。比如商品名称没写重量，或玉石、镶嵌类商品缺少品牌、重量信息；商品标题漏掉品牌；翡翠手绳被错放到翡翠手镯、翡翠吊坠类目；正红菇干货本应归入食品饮料>粮油调味>南北干货>类目，却被挂到生鲜-蔬菜-根茎类等。

应对时要注意，这类问题多出现在定向准入商品或较特殊的商品上，产地、品牌、重量等关键信息缺一不可，缺失就可能被判定为发布不合规信息。

细则可查阅：[《视频号橱窗达人【发布不合规信息】实施细则》](https://support.weixin.qq.com/cgi-bin/mmsupportacctnodeweb-bin/pages/LymgRTubihsg7ElD)。
