# 「当前行」如何驱动循环读取？

循环中，变量“当前行”决定每轮读取哪条内容。它会从循环的“起始行”开始，逐次取到“结束行”。比如起始行填 2、结束行填 10，第一轮循环时“当前行”的值就是 2，此时 `"B"&当前行` 就相当于 `"B2"`。

**为什么要加“延时”？** 延时能让机器人跑得更稳。提升稳定性的办法不少，延时算是最直接、最简单的一种，但多数情况下确实好用。这里点完“图文”后，小红书笔记需要时间加载，加一段延时可让新数据充分出来，避免数据没加载完就抓取导致结果不正确。

毫秒和秒的换算是：1000 毫秒 = 1 秒。这里延时 5000 毫秒（也就是 5 秒），实际可按需求调整。

“数据抓取”在顶部菜单栏区域。它是抓取结构化数据最常用的功能模块，主流 RPA 软件（包括 UiBot）一般都把它放在顶端菜单栏。

**为什么“数据抓取”要放在下拉计数循环里面？**

[PRE35]

如果把它放在计数循环外，就意味着循环结束后才执行抓取，可以一次性把所有已加载的数据抓下来。大多数情况下，确实应该这样用。

但小红书平台的数据加载有特殊性：多次加载之后再执行数据抓取，只能抓到最后一次加载出来的数据。所以这里要循环一次就抓一次。循环 N 次，也同步完成 N 次抓取，才能确保数据不遗漏。
