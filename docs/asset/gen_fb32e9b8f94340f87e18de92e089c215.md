# 单干也能赚美金：三个海外互联网项目拆解

大家好，我是静水流深。承蒙生财有术邀请，今天聊聊海外互联网掘金这件事。

我踏入互联网广告这行的时候，很多人连互联网是什么都还没概念。王通当年从我这儿拿了一本我翻译的《Google Cash》，才第一次知道SEM是怎么回事——那会儿百度竞价都还没影子。基本上搞海外网赚的80后，多少都听过我的名字。

但我今天不是来吹牛的，恰恰相反，我想先泼一盆冷水：互联网赚钱说容易是真容易，说难也是真难。你要是连真实情况都没摸清，那钱一定落不到你口袋里。很多时候你看到的只是表面，真相只有当事人自己清楚。

就拿跨境电商来说，培训课程铺天盖地，真正赚钱的不到一成，而且这少数人里，要么有供应链优势，要么有流量优势，两样都不沾的话，赚钱跟你没什么关系。那些动不动吹嘘一年赚多少的，你看看各家跨境电商公司年终给员工发多少，再看看裁员的消息，心里就有数了。

再说Mediabuy，头部玩家能比普通人多拿10%-20%的佣金，广告费那边还能多5%-10%的返点。你就算100%照搬人家的案例，结果大概率是：人家怎么做都赚，你怎么做都亏。更何况现在拼的是谁能上广告、谁有隐性资源，这些成本人家根本不会往外说。

游戏出海也是同样的逻辑。不是说你做一款牛逼游戏翻译成多语言版本就完事了，而是去模仿国内4399上那些小游戏，源代码容易搞到手，只要国外还没人上架，就换成英语或其他语言挂上去，刷榜做到前面看数据表现，不行就换下一款。“三消”类游戏就是这么起来的，早期竞争少确实赚钱，后来谁做谁亏。

上面这些话可能跟外面讲的不太一样，见谅。今天我分享几个小项目，抛砖引玉就够了。我从不吹嘘能赚多少，但这些项目足以让任何一个普通人告别打工。

案例三：手机解锁

利用国外平台做无本生意，才是新手最需要的方向。

手机解锁这事，有海外生活经历的朋友应该明白。国外买手机可以签合约，中国也有，但区别很大：中国是返话费，机器插任意支持制式的卡都能用；国外是低价给你用，但得签一般两年的合同，每月话费有最低要求，而且只能用签约公司的SIM卡，插别的卡直接变砖。两年后提交IMEI，官方解锁，你才能随便插任何电信公司的卡，或者转网、结束合同、签新约换新机继续循环。

当年iPhone4出来时，有人说老美只要99美元中国却要五千块，纯属断章取义。背后合同一般是每月50美元左右最低消费，24个月起步，最后算下来谁便宜？

你只要把解锁服务作为商品，配上相关关键词做标题发布上去，就能自然获客，一分钱不用花。接到老外的解锁请求，找国内提供解锁服务的商家处理，赚差价。解锁不了退钱即可，你也没损失。多数时候利润率超过100%。

国内找哪家？咸鱼、淘宝多看看，包括找果科技，前提是你一定要亲手去试。任何项目不动手就是零，项目再好也一样。

这里只是揭开水货手机行业的冰山一角。真正最赚钱的是淘宝或威锋论坛上说的美版iPhone、日版iPhone，这些机器真实成本超级低。

美版iPhone基本上全是合约机。更早几年，美国根本买不到无锁iPhone，全是跟电信公司合作，签约形式，用户2-3年合约，低价用手机高价付话费。这也催生了很多美国人跑到加拿大Apple store买无锁版，也让sim unlock、phone unlock、iphone unlock这些关键词有巨大流量。

这里面又有一个新生意：不少留学生打算回国时，拼命在各电信公司低价签约手机然后卖掉，这些手机流向全世界包括中国。老外也有专业团队直接批量化，找一些无视信用分数的人——签约手机往往不要求多好的信用记录，只要不是破产状态，理论上都能用后付费手机。这个就不展开了。

**—04—**

最后的话

国外互联网赚钱最大的特点是可以one man完成，很小的小公司或个人一年很容易有很高的利润。有人问怎么发现这些利润空间？上面的案例都属于不告诉你你一辈子不会知道，告诉你你会恍然大悟。

怎么自己发现这些东西？我个人觉得，首先你不能是个打工人，上班会占用大量时间，导致你每天没有自己的时间去思考和学习。读万本书不如行万里路，多经历生活，多看看世界，你才会发现商机。

做国外这块，说难也难，说简单也简单。难的是你必须有自己的想法才能赚钱，简单的是没有国内这么多条条框框，往往一个人几个人就能做一个生意——这就是国外有种生意叫Small Business的原因。
