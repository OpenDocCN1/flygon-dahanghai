# 八月复盘：设计师创业者的50条实战心得

作者：Sky🏹（表哥）｜2021年9月9日

生财圈的各位好。上月我在这里分享过设计师创业者关于设计、品牌、成长与创业的体会，亦仁建议我把复盘做成月度习惯，于是有了八月这一篇。也想提醒大家：忙碌不该成为停止迭代的理由，常回看，常更新。顺手点个赞，手留余香。

这次按八个维度整理：
1、设计维度
2、品牌维度
3、成长维度
4、生活维度
5、产品维度
6、运营维度
7、创业维度
8、杂项维度

## 1、设计复盘

[PRE0]

1、刚入行的同学往往还谈不上独立原创，先要喂养审美和眼界。动笔前锁定一个靠谱样板，把其中的形状、配色、字型、版式、材质逐项拆解；有没有参照物，最终成色会差出好几个档。

2、自律这件事，硬扛很难。我常用一个“先做十分钟”的启动法：原本要求练满六十分钟，想起来就抗拒；只承诺十分钟，心理门槛立刻低。哪怕十分钟很短，也比练两下就放弃强。多数时候十分钟后会自然延长到一刻钟、二十分钟；如果不想继续，休息后再来一个十分钟。最近写东西我也这么干。若仍难坚持，可试 Forest，它把番茄计时变成种树游戏，中途退出树会枯，仪式感能把人拉回桌前。

3、看一个设计师还有没有创造力，我观察他是否对新鲜事保持兴奋：愿不愿意每天试一点没碰过的东西，会不会主动研究新工具、新趋势，例如 Figma 这类协作设计软件。

4、进阿里的第一个月，主管让我先把全球电商的交互骨架和视觉骨架默写一遍，再谈需求。当时觉得折腾，后来才明白这份痛苦很值：只有拆到骨子里，才能借巨人的视角思考。

5、“设计驱动商业”在我眼里一直像个漂亮口号。资源与信息并不对等，不少公司把设计团队放在资源位，甚至当成产品的延伸手。想真正驱动很难，可设计师还得主动争取业务参与；不然晋升答辩时，评委一句“这个项目成了，哪些变化是你带来的”，很多人就答不上来。国内曾有一家偏设计驱动的公司，叫锤子。

6、找灵感时，Dribbble、Behance 我打开得少了，更愿意逛 Mobbin（mobbin.design）。它不只给完整界面截图，看到喜欢的还能下载下来亲手体验；案例更偏落地，参考价值高。

7、前阵子发现一个被我叫作“韩国鲁班”的工具：Miricanvas（miricanvas.com/design）。它比国内一些同类模板站更顺手，模板完成度高，视觉效果也强。国内不少平台的花哨配色，看久了确实累。

8、NFT 忽然热起来，我认为它对艺术创作会有不小推动。原阿里设计总监善牧老师有句话我很认同：设计师的创作需要被保护，未来的启发更多来自社群，而不是组织。

9、不要只做设计大神的粉丝。更值得研究的是：什么事让他变强？抓住关键路径与底层原因，照着练、照着走，你也有机会成为高手。

10、专业上得有一块足够长的板，而且这块板要跟着时代更新。大家还在争金属质感与玻璃质感谁更高级时，那些风格可能早已过期。身边人聊新技术、新趋势，你却接不上话，这才是危险信号。

11、马云讲课也会被老板们挑战，有人会直接说“你不在一线，我在一线”。终身学习重要，但怎么学更重要。我的体会是：把身边真正优秀的同行当老师，边合作边学。

12、设计师的学习方式该换了。罗胖在得到训练课里提过，传统案例式学习已经不够用，要从真实场景和用户问题出发找方案。时代翻页太快，设计师得从看后视镜转为看前路；创业同样如此，常问自己：如果公司明天就危险，今天该做什么？

13、把自己练成 U 盘式、钉耙式的人：一门精，多门通。多元综合能力要刻意培养，设计师尤其要多接触新趋势、新工具，本事不嫌多。

14、很多人嘴上说技多不压身，结果囤了一堆免费课，从不打开，硬生生把自己变成收藏家。互联网时代，知识大多可检索，输入关键词就有答案；真正稀缺的是学习行动力。那句话没错：一旦你开始做，已经甩开九成人。

15、别太玻璃心。作品发到网上或交给业务方，听到负面反馈就炸毛，没必要。把精力拿去变强，用行动和结果说话；当然，若你判断自己是对的，该坚持的也要坚持。

16、设计师容易掉进完美主义陷阱。很多事情不必死磕，房子还没立起来，就纠结地板用什么砖，意义不大。先完成，再完美。宫崎骏那句话我记了很久：遇见都是天意，拥有都是幸运，不完美也没关系；万物有裂痕，光才照得进来。

## 2、品牌复盘

[PRE1]

17、品牌没有一夜成名这回事，背后都是长期投入与沉淀，风口来了才被看见。做个人 IP、做社群也一样，要爱惜自己的羽毛。

18、品牌究竟是什么？我的理解是：让用户找到你、信任你这件事变简单。设计日记这个品牌，用户到底记住了什么？颜色和标识只占很小一块，真正留下的是价值——你能在某个领域帮他解决问题，这才是品牌内核。产品会经历阶段：先靠曝光让更多人知道，目标是把用户拉进来；而成熟品牌如可口可乐，追求的不再只是曝光，而是社会价值与好感。劳斯莱斯普通人少见，因为广告放在私人飞机、高端会所，是精细投放。

19、如今谈品牌，大家先想到图形、视觉和颜色，却常漏掉文案与声音。苹果的文案细看有苹果味；淘宝早期一句“亲”成了记忆点，支付宝却不会照搬，仍用“你好”，品牌不同，措辞就不同。声音也一样，腾讯消息提示、微博刷新音，地铁里一响就知是谁；早年摩托罗拉、诺基亚的开机声也有辨识度。只是这两块正被不少企业忽视。

20、在支付宝时我参与过一个高端理财项目，面向存款百万以上的用户。我想当然地堆了深色和玫瑰金，觉得奢侈风准没错，结果被总裁批评。他讲迪拜见闻：当地女性蒙黑纱，怎么分辨财富？他遇到一位，面纱边有一缕飘逸红线，整个人的气质就不同。他那位财务自由的朋友，衣服也几乎不露标识，更看重剪裁。品牌表达未必靠大标志、大色块，一个小细节也能传递态度。

21、我们接触过的优质品牌还不够多。说几个百元级能明显提升生活感的产品：音乐软件我常用 Spotify，设计、体验、版权都稳，无损音质尤其明显，听过之后会觉得以前亏了；另一个是 Netflix，优质片源多，生活品质能上一个台阶。

22、用户在每个品类里能记住的品牌很少，通常只放得下第一、第二：碳酸饮料想到可乐和雪碧，服装想到无印良品、优衣库，大卖场想到家乐福、沃尔玛，运营商想到联通、移动。第三第四当然存在，但人的大脑天生偷懒。所以做产品、尤其创业，不是产品线越多越好，而是越聚焦越好，关键看能不能把尖磨出来。

23、一个母品牌带多个子品牌，怎么做到既统一又各有性格？可以看谷歌、阿里、腾讯。以腾讯为例，即时通讯、音乐、视频、游戏、社交、浏览器等业务，统一感来自三处：色彩上以蓝绿黄为家族基调，色相略有区分；图形上共享某个符号轮廓；再叠加吉祥物元素。不过我认为谷歌做得最好，家族感极强，一眼能认出来；阿里更多靠字体维系，相对弱一些。

[PRE2]

24、怎样较快立起一个新品牌？前提是产品别拉胯，视觉做得有质感，再去抖音、小红书找合适达人种草，争取进李佳琦、薇娅、老罗的直播间。投产比跑正之后，再做全网投放。

25、苹果生态确实顺滑。我每天用得最多的是 AirPods：电脑上放着歌，拿起手机刷抖音，耳机自动切过去，它围绕苹果设备的声音场景做设计，很贴心。但苹果也有翻车产品。前几天我买了新款 MagSafe 外接电池，七百多，携带方便，可给手机补不了多少电，速度还慢；边充边用，手机电量反而往下掉，挺鸡肋。

26、百度的使用体验越来越劝退。前两天想下个苹果字体文件，连翻三页都是推广。我理解广告位要养技术、养公司，但凡事得有边界，否则用户习惯一旦迁移，很难拉回来。

27、竹子前四年只冒三厘米，第五年每年能蹿三十厘米，六周长到十五米。很多产品看似突然爆红，背后都是长期蹲苗。我熟悉的生财有术也是第四年才迎来用户爆发，前三年亦仁一直在默默打磨内容和服务。真没有速成，该踩的坑一个都躲不过。产品这样，品牌也这样；市场上还没人认识你时，你唯一能拿出的竞争力就是服务与内容。

## 3、成长复盘

[PRE3]

28、每个月都得给自己定个盘。个人成长和公司经营都一样。人总觉得自己年轻、时间充裕，减肥、见重要朋友都能往后推：下个月吧，明年吧。结果看起来忙得团团转，实际浪费不少，本质是缺规划。时间用错地方、事情顺序排错，都是损耗。

29、去朋友公司做分享，有人问我：创业这么苦，离开阿里后悔吗？我不后悔。我不希望自己每天努力的目标，是变成主管那样的人——生活被工作吞掉，被资本逻辑蒙住，天天如履薄冰。当然，有人就喜欢那种体面和高薪。公司改变不了，但我能改自己的选择。试想，如果所有工作收入一样，你会选什么？在没法两全时，至少听听内心的声音。

30、怎么把格局撑大？我认同猫叔说的：敢花钱，也会花钱。很多优质人脉在圈子里，付费入场能快速建立连接；进群后大方发几个红包，别人更容易记住你。但前提是你得有价值，有值得别人学习的地方。有人见大佬会发怵，我的办法是田忌赛马：大佬也有盲区，你拿自己的长处去补。比如我微信里不少大公司设计总监，专业上我不如他们，但运营、个人品牌他们未必比我强，于是合适的时候我帮他们处理运营和团队影响力问题，彼此成就。早期见亦仁我也紧张，后来他请我做设计顾问，慢慢熟了。主动利他，是破局的好办法。

31、抱怨当下很解气，拉长时间看并不划算。漫威英雄能收场，靠的从来不是牢骚，而是一次次行动，事情才被推动。

32、把“及时止损”写进人生原则。不合适的工作，辞；不合拍的圈子，退；不合适的感情，断；不对的人，离开。别被沉没成本绑住。坐错车不可怕，怕的是因为投了币就硬坐到底。生活里，少做没有意义的内耗，是大智慧。人在沼泽里，待得越久陷得越深；小事上越纠缠，输得越多。

33、教培行业收缩，字节也有调整，哪有什么永远的大厂关怀？资本变化很快，没有稀缺能力就会被筛掉。让自己拥有稀缺本事，并在某个领域持续叠加增长，才是竞争力。

34、以前看过一句讲竞争力的话：“人无我有，人有我优，人优我全，人全我不要命。”听着像段子，但有启发。每个人都得给自己修护城河，工作如此，生活也如此。工作期间我找到了写作这个点，慢慢把它修成护城河。设计师普遍不擅长、也排斥写作，我恰好把这块放大，逐渐变成优势。

35、在职场做自媒体，低调为上。除了父母，真心盼你过得比他好的人不多。我在阿里写文章时像做贼，天天怕同事刷到。企业永远先看公司利益：同样两个人，一个只给公司干活，一个常写文章，老板会重用谁？所以想做副业或写作，记得把爱议论的同事屏蔽掉。

36、和几个朋友吃饭，聊到一个话题：这个时代哪些能力很重要，但多数人没有？我们最后归了六条：
第一，让别人舒服的能力。和某人相处如沐春风，什么梗都接得住，你以为遇到知己，其实对方情商高，在向下兼容你。
第二，读懂人的能力。别只听他说什么，要看他怎么做，再判断这个人。
第三，长期坚持一件事的能力。没背景、没资源的人，靠坚持就能超过九成同龄人。我很认同，写作这件事坚持下来，才有了今天做的事。
第四，早睡早起的能力。一位大佬说，清晨的白粥胜过深夜的酒。
第五，执行力。未来大家获取知识的能力差不多，真正拉开差距的是执行、商业敏感度和长期行动。
第六，接受自己的普通，接受改不了现实。很多痛苦来自预期和现实错位，遇上了先接受。企业家、明星追求的东西也差不多：赚钱，过想要的生活；明星赚钱也买大房子，和我们没两样。大家都是带灵魂的灵长类，不必觉得自己低人一等。

37、陆奇在百度时这样激励智能驾驶团队：前进要选一条跑得快的高速路，在快路上再挑更高效的交通工具。我们现在的业务，就在一条快车道、一条高速路上。

38、人生大致分几段：第一段拼聪明才智；第二段拼关系网络和赛道，网络决定你能走多高多远；第三段是在过程中创造价值，这时年龄高低没那么重要。

39、设计师到三十岁，竞争力怎么提？先织自己的网状能力，持续走出舒适区，补新技能。别人拿技术和你比，你有设计思维；别人拿设计思维和你比，你有数据思维；别人拿数据思维和你比，你有商业思维。你脑子里是一张网，对方只有一根线，谁更稳？

40、稻盛和夫讲过人是怎么废掉的：假装努力，持续幻想，嘴上巨人、行动矮子；睡前给自己打鸡血，醒来还是原样。总觉得自己年轻、时间多，天天找理由拖：晚点做、明天做、下月做、明年做。把自己弄得特别忙，仿佛没虚度，却很少想工作值不值得、职业怎么规划。八成时间用错了地方。改掉浪费习惯，拿到正向反馈，理清做事顺序，才会离成功近一点。

41、延迟满足这项能力，我一直在练。想做成事，就得先盯目标，再谈享受。身边诱惑很多，你要能拒绝，保持自律和专注，直到理想落地。就像备考，先把书读透，朋友的邀约先放一放，考完再聚。凡事看长远利益；别人不愿做的，你做了，才可能拿到他们没有的结果。

42、什么叫活得真实？不再怕别人评价。好的是你，坏的也是你，你比谁都清楚自己的长处和短板。也别因为几句片面之词就否定自己。只要心里有光，认定方向对，就坚持。拉长看，人一辈子不过三万个日夜，在宇宙面前只是一粒尘，把自己做好最重要。

## 4、生活复盘

[PRE4]

43、真正困住人的，往往不是认知不够，而是心力不够。身体能量需要管理，心力也会枯竭。左晖的遭遇让人唏嘘，表面看是繁忙和压力，往深里看是能量被透支。学习之外要锻炼，给自己充电，保证续航，很多悲剧才可能避开。

44、政策变化下，很多人都觉得难：上班怕不稳、怕辛苦，创业怕风向变，左右都难。随便上街看看，谁不难？学习嫌苦不肯吃，就只能吃生活的苦；创业不肯吃苦，就只能吃失败的苦。说到底，这是一场修行。建议看看俞敏洪早年的采访，看他怎么面对人生起落。

45、改变自己很难，那能不能每个月只戒一个坏习惯？比如熬夜、刷短视频、饮食放任、体重失控、周末宅到不出门，像把世界的一扇门关上。戒掉这些，换来的是早睡早起、爱读书、身体好、对生活有热情。只是难度不小，下个月复盘再看结果。

46、珍惜身边人。很多人对朋友客客气气，对父母和伴侣却没耐心，因为潜意识觉得他们不会走。说白了，这是一种自私。

47、这几年我水喝得少，咖啡倒灌得多，对身体不友好。前些天在老罗直播间买了个带刻度的大水壶，几点该喝到哪条线都标着，喝水频率一下上来了。人天性偷懒，很多成功产品就是抓住了这种懒：小罐茶、三顿半、小仙炖都是例子。

48、爱商，是我们这代人很需要补的一课。

49、要学会和自己的内心对话、做复盘。最近在复旦读书，老师分享了一套《灵魂11问》，很好用。拿张纸，把下面这些问题写下来：
过去几天，你身上发生了哪些变化？
人生路上，谁在持续给你力量？
当前工作里，你感觉自己的未来在哪里？
工作与生活中，什么事最让你纠结、最耗能量？
目前工作中，你最大的快乐来源是什么？
坐上时光机，回到十岁、十八岁，那时的你会对现在的你说什么？
继续穿越，假设即将离开世界，此刻你想给当下的自己什么建议？
回到当下，未来三到五年，你的愿景是什么？如果画成一幅画，会有哪些元素？越具体越好。
