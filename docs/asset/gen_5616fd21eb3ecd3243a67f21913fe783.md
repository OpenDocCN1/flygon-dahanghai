# 从零搭一个 AI 图片视频站：后端、登录、模型、存储与上线全流程

想做一个 AI 图片/视频站，却容易被后端、登录、模型调用和文件存储这几块绊住？这篇内容会把整条配置链路拆开讲清楚。先认识一下核心后端——Supabase。

Supabase 是一个开源 BaaS（后端即服务）平台，也常被看作 Firebase 的开源替代方案。它把 PostgreSQL 数据库封装起来，提供身份认证、消息传递、边缘函数、对象存储等能力，还能依据数据库结构自动生成 REST API 和 GraphQL API。它的目标很明确：给开发者一套一站式后端方案，减少后端开发与维护的负担，把更多时间留给前端和用户体验。在 PostgreSQL 生态中，Supabase 人气很高，很多初创企业都在用；免费起步，上手也方便。

它的优点主要有：
- 开源免费，底层是流行的 PostgreSQL，数据可自由迁移，不容易被供应商锁定。
- 后端功能集成度高，开发和维护工作量更小。
- 社区支持不错，项目也在持续更新。
- 支持自建，能获得更高控制权，也有机会优化成本。

## AI 模型接入：Replicate

### 1. 接入 Replicate

因为网站是 AI 图片/视频站，所以需要 AI 生成能力。这里推荐 Replicate：模型覆盖比较全，稳定性也不错。

Replicate 是什么？

它是一个 AI 模型运行和微调平台。用户可以通过简单的 API 调用，运行开源人工智能模型，任务范围包括生成图像、文本、视频、音乐和语音等。它把机器学习模型的部署和使用过程做了简化，开发者不需要深入理解复杂的 AI 技术细节，也能快速集成和使用各种模型，从而提升开发效率、降低成本。

为什么要用 Replicate？
- 降低 AI 技术门槛，普通开发者也能方便调用。
- 提高开发效率，把精力放在产品上，而不是模型训练上。
- 按调用量计费，避免高昂的基础设施费用。
- 支持多语言客户端库，集成起来比较轻松。

### 1. 获取 Webhook 秘钥

AI 图片或视频生成耗时较长。用户等待过程中，可能因为各种原因关闭页面或与服务断开连接，这样最终生成结果就可能拿不到。

这时就需要 Webhook。视频生成完成后，Replicate 会自动发送一条成功通知以及结果 URL。我们收到通知后，把结果存入数据库。这样即使用户在生成过程中退出网站，之后回到结果页面，也能拿到最终结果。

Webhook 是什么？

Webhook 是一种基于 HTTP 的回调机制。当某个应用发生特定事件时，它可以自动向另一个应用指定的 URL 发送实时通知和数据。和传统 API 需要客户端频繁请求数据不同，Webhook 是事件驱动的，只有事件发生时才推送数据，因此更高效、更实时。它通过 HTTP POST 请求把事件相关信息（通常是 JSON 格式）发送给接收方，方便对方及时处理。

AI 图片视频网站设置 Webhook 的原因：
- 实时通知：用户上传、生成或处理图片完成时，后台能通过 Webhook 实时通知相关系统或服务，做到即时响应。
- 自动化流程：通过 Webhook 自动触发后续动作，比如图片压缩、分类、审核、推送用户等，提高自动化程度和处理效率。
- 资源节省：不需要网站或第三方服务持续轮询状态，减少重复请求和服务器压力，提升性能。
- 可靠的事件传递：保证图片处理完成等关键事件及时通知，增强用户体验和系统稳定性。

Replicate 设置 Webhook 并不复杂。

## 接入 Cloudflare R2

### 1. 开通 Cloudflare R2 服务

生成的图片和视频需要存储，这里要用对象存储服务，也就是 Cloudflare R2。

Cloudflare R2 是什么？

Cloudflare R2 是 Cloudflare 推出的对象存储服务，兼容 Amazon S3 API。它最大的特点是零出口流量费用，也就是不收取数据传输费用，这在传统云存储里是很明显的成本优势。R2 依托 Cloudflare 全球 350 多个数据中心，能提供低延迟、高吞吐量的存储和访问体验，并且与 Cloudflare Workers 无缝集成，支持边缘计算和自动化处理复杂业务流程。

Cloudflare R2 的主要优点：
- 零出口费用：数据传出多少流量都不另收费，成本明显降低。
- S3 兼容 API：已有基于 S3 的应用迁移和集成更方便。
- 全球分布式网络：访问速度快、延迟低，适合全球业务。
- 与 Cloudflare Workers 集成：支持边缘计算和自动化，功能扩展更灵活。
- 安全性高：静态数据采用 AES-256 加密，传输使用 TLS/SSL 加密。
- 透明计费：只对存储空间和操作次数收费，没有隐藏费用。
- 免费额度：提供 10GB 存储和高达千万级别的免费请求次数，适合开发测试和中小规模应用。

什么情况下免费？
- 每月 10GB 免费存储空间。
- 每月 100 万次上传/列表操作免费额度。
- 每月 1000 万次下载/读取操作免费额度。
- 出口流量完全免费，不论传出多少数据都不收费。
- 只有超过免费额度的存储和操作次数才会收费，标准透明且较低，适合降低整体云存储成本。
