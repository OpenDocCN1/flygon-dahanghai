# 闲鱼新号先养后卖：从养号到推流的实操笔记

很多新手一注册就急着挂商品，结果往往不理想。养号不到位，麻烦主要有三类：

1. 商品曝光被拖累。账号权重不够，平台不会优先推荐，曝光量自然少。
2. 上架审核更严。没养透的号发商品，会被平台盯得更紧，审核通过难度上升。
3. 权重低，商品更容易被下架。尤其被同行举报时，违规风险更高。

所以新号别急。比较稳的做法，是分时段、多频次地模仿真人操作。建议每天上午8点到晚上9点之间养号，每次10—30分钟，连续3天左右。

养号阶段重点做三件事：看商品、闲鱼签到、玩闲鱼小游戏。下面逐个说。

# 七、闲鱼运营与推广技巧@陈bu懂
单品发布完，接下来是闲鱼运营流程教学，也会介绍如何更好地给商品增加曝光和咨询量。先普及几个要时刻关注的数据字段。商品页面有三个参数：曝光、浏览、想要。
曝光：你的某个商品展现给别人手机页面的次数。
浏览：别人看到商品后点进去的次数。
想要：别人看到商品后点进去，并点击“我想要”或“聊一聊”的咨询次数。
通过以下运营动作，可以在一定程度上提升商品曝光次数，增加被客户浏览和咨询的几率。
# 7.1 公益宝贝（可选操作）
新上的商品可以在第一时间开启公益宝贝，有助于增加曝光。在主页商品页面依次点击：加入卖场→开启捐赠→我同意，继续捐赠。
[PRE17]
# 💡 Tips
什么商品适合开启公益宝贝？开启公益宝贝一般要设置捐赠额度，捐赠比例不建议太高，1%就可以。新上的1—2天商品可以开启这个选项，后面成交时其实可以把公益宝贝关掉。
商品无法开启公益宝贝怎么办？公益宝贝的作用只在新上品时有推自然流的效果；如果想直接上公益宝贝，可以直接“发布公益宝贝”。实测下来，公益宝贝是个加分项，但权重不会那么高，因此是可选操作。做好后续运营操作才是最重要的。
# 7.2 闲鱼币抵扣
新上的商品可以在第一时间开启闲鱼币抵扣，抵扣额度为5%，该操作可以增加曝光。
# 💡 Tips
什么商品适合开启闲鱼币抵扣？抵扣比例不建议设置太高，5%就可以。新上的1—2天商品可以开启这个选项。闲鱼币抵扣只适用于前期推自然流；当某个商品流量起来后可以提前关闭，后面推流可以用“急速卖”或者“用曝光”。当然，有商品成交时也可以把闲鱼币抵扣关掉，否则客户就能用闲鱼币抵扣相应金额了。
