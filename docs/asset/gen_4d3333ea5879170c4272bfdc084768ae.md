# 中高考营养餐，刚需新机会

文 / 石头 2023年3月8日（少儿探索科学实验室共创·风向标）

老大今年要冲中考，同时还想着控制体重，这就让吃饭这件事变得很纠结：吃少了怕状态跟不上，吃多了又担心体重。正是这个矛盾，让我开始认真琢磨备考家庭的营养餐问题。抱着试试看的心态，我把问题交给ChatGPT，它给出了图1、图2里的方案。看完之后我觉得还真挺靠谱，水平不输不少所谓的营养师。

顺着这个思路往下想，中考临近，很多家庭都会遇到同一道题：哪怕孩子不减肥，备考期间怎么吃才能更健康、更有营养？这个需求显然不是小众人群才有。家里有中考生、高考生的，孩子都是全家的心头肉，家长在这件事上痛点很强，需求急、刚需足、市场空间大。很多家长的心态是，只要对孩子好，在能力范围内更愿意为贵一点的方案买单，而不是反复比价挑最便宜的。

产品上可以设计三类。第一，给每个孩子单独做食谱方案；这块还能往外延伸，比如和健身俱乐部合作，由我们提供营养食谱，帮他们省掉专职营养师的人力成本。第二，面向中考、高考家庭的营养食谱课程，用在线陪跑的方式交付，做成付费社群，见图3。第三，针对高净值家庭，提供一对一指导。

流量和转化可以分几条线走。一是用抖音、快手和视频号开直播拉新，家长打赏一杯奶茶的钱，就能拿到一份定制食谱，主要面向家长人群。二是在小红书做内容引流，提供营养食谱，触达有营养餐需求的年轻群体。三是把前期从社群沉淀下来的家长群经营好，这批人比较精准，后续可以筛选做二次开发，比如高考志愿填报、高一辅导班、教辅材料售卖，以及大学生相关产品。
