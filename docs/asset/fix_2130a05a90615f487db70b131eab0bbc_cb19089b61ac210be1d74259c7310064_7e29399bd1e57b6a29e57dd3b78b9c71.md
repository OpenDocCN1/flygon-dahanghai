# （精华帖）（878赞）八个月，千万营收：我的生财复盘

作者：李鲆
日期：2022-07-18

这是我第二次在生财发帖。加入一年多，我性格偏内向，习惯安静看帖、自己琢磨、闷头做事，群里很少冒泡，线下聚会也没参加过。前阵子把账一算，最近八个月进账超过一千万（知识星球财富周榜上常出现的“抖音内参”，运营者就是我）。总觉得光拿不分享说不过去，于是发了第一篇帖，向生财和@亦仁道谢。亦仁让我讲讲心得，近来事务缠身，先写个简版。

——————————
【摘要】

1、生意方向：想挣钱的人，本身就是值得服务的群体。
2、生财怎么用：拓宽视野、筛选项目、学习方法，别把心思放在蹭流量上。
3、轻量创业：远离重资产和实物，靠分销、线上项目与流量运营，年入七位数并非遥不可及。
4、放大十倍：选边际成本接近零的供给，再把流量做到极致。
5、流量是命门：谁能把获客成本压下来，谁就握住了大多数项目的钥匙。
6、组合优势：流量、个人品牌、课程、社群、多平台一起打，我很难遇到正面竞争者。

————————
【序章】先交的学费，交给了山寨号

先谢两位引路人：@大程、@临西。

2021年初，我在郑州办活动，大程做东，极力劝我进生财。我说应该早加了，临西以前提过，但当时没看出价值，到期便没续。说着我掏出手机一查，才发现自己付钱的是“生财有道”——名字相近的山寨组织。赶紧补上正版会员，进去刷了半天帖子，兴奋得差点爆粗口：这地方简直像矿脉，到处藏着机会。回头又骂自己：山寨号太可恨，钱还是小事，耽误的时间才真亏。

————————
【序章之前】亏损七百万的那一年

我2014年开始创业，最初做出版。此前在《中国图书商报》任职，出过《畅销书浅规则》系列，在出版培训圈里收费不低。沿着熟悉的赛道走，前期确实顺利：先后策划几百种图书，其中电商、微商题材的不少，在细分市场颇有代表性。

出版也让我更懂创业。2016年我切入微商文案培训，四个月进账两百万，在彼时算靠前的位置。

2019年风向突变。我投的一部电影受政策影响迟迟上不了院线；出版板块同样被政策推高成本，坏账增多。两项合计，那一年亏掉七百万。那是我最难熬的阶段，也逼着我把“怎么挣钱”这件事重新想了一遍。

————————
【第一章】先把利润做厚

2019年，我一边复盘一边写《多赚一倍》。落笔时思路已经清晰：把公司规模压小，把利润率抬上去。后来替临西做《轻创业》、替大鹏做《就想做个小公司》，内核与这条线一致。

书里收录了一百多种提升利润的方法。此前我做过上千个创业个案咨询，不少人只改两三个关键动作，收益就能翻番。可“翻一倍”并不能让我满足，我开始追问：怎样才能翻十倍？

————————
【第二章】十倍从哪来

这个追问耗了我两年。答案最后并不复杂：找一种边际成本几乎为零的供给，然后把流量灌进去。

拆成两块看：

第一，供给形态。实物尽量别碰，十倍扩张时供应链、仓储物流、团队管理都容易掉链子；纯人工的单人服务也别做，咨询、策划这类很难规模化。剩下的方向，是虚拟型产品配批量服务，客单价较高的课程恰好符合。

第二，获客能力。谁能让流量成本足够低，谁就具备把多数生意做成的条件。

2020年，我花了一百二十来天，把微博从四万粉做到八十四万，全部靠内容自然增长，没投一分钱。近半年我也试了付费投放，把它当内容增长的助推器。如今我是微博教育类十大博主之一，粉丝过百万，这些流量足以支撑我启动新项目。

————————
【第三章】我怎样使用生财

创业通常有两条路径：一条是先有产品，再找流量做销售；另一条是先握住流量，再反向匹配产品。两种我都实践过，但现阶段我更认可后者——更稳，成功率更高，也更容易放大。

手里已有流量，我便做了几门课，比如微博爆款写作课、吸金文案课，销售和反馈都不错。2020年还运营过创读会社群，年费约千余元至两千元，招到近千人。

因此我进生财的目标很明确：物色更合适的知识产品。我的使用方式概括为：打开视野、筛选项目、学习打法，不在圈里蹭流量。研究了一圈后，我选定抖音短视频卖货培训，之后升级成“短视频带货训练营”；“抖音内参”是配套资料库，两者一体，覆盖抖音、快手、视频号。

————————
【第四章】单人也能年入百万

知识产品赛道里，多数人挤在写作、读书、时间管理、自媒体培训上。我也试过，但兴趣有限。我更关注创业、副业与增收，也就是“超级个体”。

所谓超级个体，指单个人能抵得上一家运转良好的小公司，单人也可能年入百万。按我的经验，这类模式收入上限约三百万；再往上走，需要团队补位，不过团队可以极小。

方向有两个：

1、知识产品。擅长内容、有个人品牌、能教人，就能做。
2、分销卖货。不必自己做内容或品牌，会搞流量即可，去和有货的人合作。

知识产品是完整闭环；分销卖货门槛更低。普通人想年入百万，较稳妥的路径是单枪匹马，不急着开公司，做超级个体。少碰重资产，少做实物，把精力放在线上项目、分销和流量上。

抖音、视频号卖货正是生财近两年重点推荐的方向，很符合超级个体逻辑，普通人也够得着。

————————
【第五章】内容打法遇上卖货打法

项目定下后，我拉了个小团队试水。市面上的相关课程几乎报了个遍，我带着同事听课、拍视频。

前三四个月很难看：不仅没订单，连破万播放都费劲。我开始拆解：爆款视频到底靠什么？

市面课程多由电商背景的人主讲，而我的长项是内容。我在微博做过大量爆款，单条最高阅读四千两百万。我判断，社交平台的传播规律大体相通。于是把微博爆款的方法拆成动作，让团队照着做短视频，很快有人跑出百万播放。

播放起来后，成交顺理成章。有同事靠一条视频挣了四五万元。我把这套流程产品化，做成短视频带货训练营，在微博招生，如今开到第九期，累计五千多名学员；学员单条最高播放两千七百万，单月最高收入六十万元。

课程特点可以概括为：重内容、只吃免费流量，把自媒体爆款逻辑和电商爆品逻辑拼在一起，更适合没有电商底子的普通人。

————————
【第六章】不给自己制造对手

短视频卖货培训市面上不少，生财里也有能人。我不觉得彼此构成竞争。更准确地说，这些年每做一个项目，我都守着一条原则：不给自己留下同行。这个说法由张有为提出，我把它当成策略：主动把自己做成难以对标的样子。

没有可类比者，竞争自然弱。怎么做到？用组合拳。

在短视频卖货培训上，我的组合是：多平台+流量+品牌+课程+社群。

1、别人多在抖音卖课，我偏在微博卖短视频卖货课，跨平台打法很少见。
2、微博粉丝过百万，个人辨识度高，单月阅读一点五亿，获客不愁。
3、我交付的不是普通课程，而是训练营：课程、社群、逐人辅导一起上，盯学员结果。
4、底层方法是自媒体爆款逻辑，这是我的强项，也是多数电商人不熟的部分。

几项能力叠在一起，就形成了组合优势。所以我不必盯着同行，把手里的事做扎实即可。

————————
【第七章】课程之后，训练营才是终局

下面这部分算硬货。我犹豫了几天要不要公开，最后还是写出来，当作对生财的回礼。

培训本身是专业活。很多实战派讲课，恨不得把知道的全部倒给学员，心意很好，可基础薄的人消化不了。

我交付的形态叫训练营，目标就是让零基础的人也能跟上。

1、小鹅通承载录播。课程放在小鹅通，随时可看，难度逐级抬升。
2、知识星球做答疑。经验帖和问答沉淀在“抖音内参”，学员随时提问。目前已积累一千多篇经验帖，学员能自行检索，运营压力越来越小。
3、微信群做服务。通知、互动、重要资料都放在群里，也在一定程度上抑制盗版扩散。
4、助教逐人辅导与诊断。这是关键。我培养了一支助教队伍，成员自己都出过爆单成绩，再统一按SOP服务。不仅做到有问必答，还会主动跟进，推着学员出单。

我们敢承诺“照做就有单”，因为流程跑得通。对肯投入的学员，还会继续加码，帮他们从出单走向持续爆单。

课程形态的终点，是训练营。它更容易出结果，也更难被复制盗卖。

————————
【第八章】让盗版替我拉客

知识产品最怕盗版。我的盗版课在拼多多同类里卖到第一。

我的态度是：既然堵不住，就让它反过来给我导流。不少学员先看了盗版，觉得有用，但操作到某一步卡住，最后还是来报正版训练营。

具体做法有几条：

1、课程持续迭代。每期改掉约三成，重新讲。
2、有些内容故意不放进课程。只投放到星球和社群。
3、更关键的资料不公开。助教按学员进度逐步给——做得越深，拿到的越多。只盗课不行动的人，永远碰不到核心。
4、助教逐人诊断答疑。很多卡单学员被诊断后很快开单；已爆单的再给二次爆发方案，通常还能多挣三成左右。只看盗版的人，只能自己摸索。
5、给学员专属高佣链接。我申请了抖音团长身份，以团长去和商家谈，筛出佣金高、风险低、容易出单的货给学员带。比如某品牌，达人自己带佣金一成，用我们的链接能到两成。有学员爆单时没用链接，少挣几万元，后悔不已。
6、课程里留联系方式。常规动作，不必展开。

————————
【第九章】黑帖也能变成广告位

知乎上有人黑生财，也有人黑我，数量不算多。我不清楚亦仁怎么想，我自己并不在意。有人黑，等于替我传播；黑得越多，说明关注度越高——说实话，我还有点羡慕生财的讨论度。

黑子的逻辑常常很奇特：

有人说：“不是每个学员都能爆单赚几万！得特别努力才行！”我看完差点笑出声：当然得努力。不努力就想挣大钱，那得把我当神仙。

还有帖子说，我们“保证出单”是靠自己人下单。这个我还真难反驳，因为理论上确实可能发生。

但那些挣了几万、十几万的学员不乐意了，跑去晒收益截图——“这也是鲆叔买的？他收我几千学费，买我几十万上百万元货，他图什么？”后来真有人顺着黑帖找过来付费。黑我的人若知道，估计要气坏。

当然，也会有人看完黑帖决定不买。那说明他本来就不是我的客户。世上确实有一类人：没打算付费，只想白拿；花几块钱都心疼，更别说几千；既想挣钱又怕被骗，舍不得投入。他们看黑料，只是给自己不花钱找个理由。

这样的人，最好别成为你的客户，后续太耗神。

————————
【第十章】成交之前，先学会拒绝

做知识产品，关键动作不是说服，而是筛选；不是把成交率往上推，而是敢于往下压。

成交率越高，越可能把不适合的人拉进来。后面交付痛苦，口碑也会被拖累。

学习能力弱、行动力差、经不起挫折、根本不动手、情绪起伏大、交几千元就肉疼、负债缠身、幻想一夜暴富——这些人都不是理想客户。卖给他们，等于给自己埋隐患。

拒绝的工具是门槛。我专门写过一篇帖子，说明哪些人不适合报短视频带货训练营，写完之后麻烦少了很多。

成交不是靠嘴说服，而是双向挑选：客户挑我们，我们也挑客户。

训练营刚起步时，每期都会遇到十几个难缠学员；后来把门槛立起来，这类人几乎不见了。

当然，敢拒绝的前提是客户池够大。我微博单月阅读约一点五亿，这给了我筛选的底气。

————————
【第十一章】为什么有人在生财挣不到钱

挣钱是能力、投入和运气的乘积。

能力不足、投入不够，运气来了也接不住，最后却怪别人不给机会、怪别人割韭菜。

能力强的人，挣钱概率自然高；能力弱的人，往往要交更多学费——我每年在学习上的支出也有几十万。

没人天生全会。学任何东西都有成本，创业和挣钱同样如此。

成本有两种。一种是花钱向人学：买书、买课、做咨询、进社群，金额其实可控。另一种是自己不懂还硬折腾，赔了钱、耗了时间，才换来一点教训，这种成本没有上限。

捷径是找到已经拿到结果的人，跟着学，别闭门乱撞。

总想白拿、不愿为价值付费的人，最后往往付得更多。

我自己有流量、有品牌、有执行力，来生财只是为了找项目，所以挣钱相对轻松。若你什么都不会、也不肯下功夫，交几千元就指望轻松年入百万——这种需求，只有骗子能接。

所以，别急着进生财，也别急着报我的课。

————————
【第十二章】把学习当成长期投资

学习像风险投资。

别指望每次学习都立刻回本，能听到几句真正有用的话，就值了；有时候，几句话足以改变轨迹。

多学，让学习成为习惯；多做，在试错里前进，这才是要紧的。

学得越多、做得越勤，能力越强，运气也越容易靠近，收入自然往上走。

时代一直在奖励愿意学习的人。

今年我给公司同事都买了生财，打算让他们分头测试圈里推荐的项目，跑通后再放大。只是最近太忙——说直白点，训练营业务太好，大家抽不开身，我也不太擅长管理，这事暂时搁置，后面会补上。

我已经确认，事实也证明：生财是一座矿。会做事、肯做事的人，能从这里挖到不小的财富。

————————
【第十三章】做想增收者的生意

想挣钱的人，本身就是好客户。

生财做这门生意，我也做这门生意，只是生财盘子大，我盘子小；生财做社群，我做训练营；生财覆盖面广，我只切一个细分领域，做到足够深。

你掌握一种挣钱方法，亲自下场能挣到钱；若把它教给别人，可能挣得更多。

要点有四条：

1、自己先拿到结果；
2、有稳定的流量入口；
3、懂成交；
4、会教，能带学员出成绩。

说句不太谦虚的话，这四条我恰好都占。所以训练营能连开九期，而且一期比一期顺。

我想多挣钱，就得让学员先挣到钱。学员挣钱和我挣钱，方向一致；他们拿到结果，我才可能持续获益。

聪明、肯干、诚实、可靠，才是能长期挣钱的底层素质。

————————
【第十四章】流量必须死磕

谁能把获客成本压下来，谁就几乎能把任何生意跑通。

无论实体、电商还是知识产品，流量都是绕不过去的关口。没有流量，收入无从谈起；流量越充足，挣钱空间越大。

生财里的项目，你学会一个，再用流量去放大，就能变现，逻辑就这么直接。

关于流量，我的看法可能和不少人相反：我更建议做公域，而不是只守着私域。

公域像海，私域像池。

有些知识产品从业者，某段时间轻松挣了一两百万，之后突然熄火，原因就是流量枯竭，没有新水进来。

我早些年也做私域，同样撞过墙。后来认真经营微博，拿到持续不断的公域流量，局面才轻松起来。

————————
【第十五章】微博值不值得做

公域平台很多。我当初选微博，是因为观察到微博上的大V似乎并不怎么挣钱，于是判断那里流量便宜、值得下场。后来证明判断没错。

但我不建议所有人都去做微博，原因有两个：

1、微博不适合割韭菜。它像公开广场，也像斗兽场，用户很容易把你扒个底朝天。产品和服务不够硬，随时可能翻车。
2、再好的培训，也无法让所有人满意。学员的基础、投入度、收入水平、预期，甚至家庭关系和精神状态，都会影响评价。一个环节没处理好，在微博上就可能被放大。

我在微博做了两年多知识产品，训练营开了九期，负面至今不多——直说就是口碑还不错。但我每天仍然谨慎，像踩薄冰一样。

当然，产品和服务足够硬，微博完全能做，而且很利于积累口碑。学员会晒单、晒经验，这是很有力的客户见证。客户说你好，胜过自己夸一百句。

【第十六章】快钱与长期主义

到2022年7月，短视频带货训练营已开到第九期。还能开多久？我不知道。我能做的是尽量把它做扎实、做长久。

我向蒋晖请教过——他的《怎样做好淘宝》也是我出版的。他给了几条很实在的建议，比如继续深耕微博、把爆单营做好。他也提到，电商培训不如从前好做，因为注意力都去了抖音、快手。

所以我的训练营能跑出来，也吃了时代红利。

做超级个体，不论是知识产品还是分销卖货，挣的多是红利期、风口期的钱。说白了，就是要抓快钱。

总有人问：短视频卖货的红利期过去了怎么办？

这问题有点奇怪：好不容易赶上窗口期，不该抓紧拼命挣吗？等窗口关上，再找下一个就是了。

当然也有另一种极端：一直追快钱，做的都是碎活，频繁换项目，累得半死却放不大。

快钱和长期主义冲突吗？我的答案是：不冲突。

先挣到快钱，活下来，才有资格谈长期。其次，要有一个贡献八成以上收入的主项目，同时不断测试、储备新项目。最后，也是更重要的：持续学习、死磕流量、经营个人品牌。

“我”才是最值得打磨的产品。

不断投资自己，让自己更聪明、更能干、更有影响力，这就是最好的长期主义。
