# 0.1 为什么做 IP 定位要借 AI 的力

# 个人 IP 到底是什么？

一句话说，IP 就是那个让别人记住你、信任你、愿意把钱交给你的“标签”。

提到某个人，大家能立刻知道他在哪个领域很能打。例如“龙哥：龙哥盟创始人、杨涛：赚钱全能大师兄”。

不少人一听到“IP”，就以为那是大博主、网红、明星才需要做的事。其实，只要你想靠内容影响别人、实现变现、建立信任，你就需要有自己的个人 IP。

说得直白些：

你是谁？
你在帮谁解决问题？
别人凭什么信任你、关注你？

这三个问题回答清楚，IP 的雏形就出来了。

比如你是宝妈，擅长亲子早教，个人 IP 可以是“陪娃不焦虑的早教妈妈”。
比如你做设计，懂品牌和商业思维，个人 IP 可以是“用设计帮中小老板赚钱的品牌顾问”。

个人 IP 不是把人设包装出来，而是把真实的你放大。所以定位的起点不是“我想成为谁”，而是“我本来是谁”。不要只向外看别人做什么，更要向内看：把过去做过的事、擅长的事找出来、讲明白、放大它。

⚠️ 注意：定位并非一锤定音，它会随着阶段变化而调整。

# 为什么 IP 定位是绕不过去的一步？

因为面目模糊的人，很难被记住！！

再举个例子：
如果你打开📕，看到“花花老师”什么都发，今天穿搭、明天鸡汤、后天创业，内容看着还行——你会关注吗？
大概率不会。因为你不知道她是谁、擅长什么、能帮你什么。

IP 定位就像盖房子的地基。没有定位，相当于在沙地上起高楼，越往上越容易塌。只要在一个垂直领域打透，在一个小圈子里被信任，你就会拥有内容闭环、信任闭环和变现闭环。

做内容营销，不是要当“十万个为什么”，什么都聊；而是让别人一看到你，就知道你是解决“某类问题”的专家。

记住：
方向模糊，汗水容易打水漂；目标清楚，投入才会放大回报。

# AI 在定位里能帮什么忙？

过去做定位，很多人第一步就卡住：不知道自己擅长什么，不会查用户需求，也不懂怎么梳理差异化。
AI 的价值不在于直接给你答案，而在于把脑子里的信息结构化、显性化、对比化。

AI 就是你很强的定位合伙人。比如：
你输入自己的经历，AI 能帮你提炼可能的优势标签；
你说出一个方向，AI 能帮你拆解用户痛点、平台适配和变现方式；
你有几个方向拿不定主意，AI 能帮你做可行性评估。

所以，AI 不会替你决定定位，它更像一面镜子，帮你把自己照清楚。当你看见自己的特长、资源、喜好和市场机会，定位就不难了。

起步不必完美，但方向必须清楚。

# 0.3 搭建个人定位的四个支点 @sky

做定位前，先整体看一遍：个人 IP 定位可以怎样一步步搭起来。

创业过程中，找到高价值定位非常关键。想做好个人定位，可以从四个关键维度构建：

兴趣领域：你真正热衷的业务方向或行业；
内驱动力：能让你熬夜也不觉得累、持续投入的核心动机；
成果证明：你已经取得的成功经验和业绩，不论大小；
核心能力：别人经常向你求助的领域，也是你的差异化技能。

这四个维度的交叉点，往往就是最有战略价值的定位所在。

清晰定位像创业路上的指南针：资源有限时，知道精力该投向哪里；竞争激烈时，找到自己的差异化优势；市场变化时，守住核心而不是盲目跟风；决策困难时，有明确的取舍标准。

没有定位的创业，像没有目的地的航行，再努力也难到达理想彼岸。

具体怎么构建个人定位？

第一步：战略资产盘点。
拿纸笔，诚实回答：
我真正喜欢做什么？
哪些工作让我觉得时间过得飞快？
即使不赚钱，我也愿意长期投入什么？
我过去在哪些方面取得过成果？
朋友、同事或客户经常因为什么问题来找我？
我解决过哪些他人难以解决的问题？
不要急着下结论，这一步是全面了解自己的资源禀赋。

第二步：寻找战略交叉点。
把第一步收集的信息可视化，找出重叠区域：
哪些领域同时满足兴趣和内驱力？
这些领域中，你有哪些已验证的成果？
你的核心能力如何与上述领域匹配？
交叉点越多，定位潜力越大。但最佳定位不一定是最显眼的选择，而是最具差异化竞争力的组合。

第三步：市场验证与迭代。
定位再完美，也要接受市场检验：
设计小规模测试，为 5-10 个潜在客户提供服务；
收集直接反馈：他们愿意为这个价值付费吗？
分析竞争格局：在这个定位上，你比对手强在哪里？
评估增长潜力：这个定位能支撑长期发展吗？
根据验证结果，持续调整定位表述和价值主张。

第四：定位动态调整机制。
定位不是一成不变，要建立定期评估机制：
每季度回顾市场反馈是否支持当前定位；
每半年检查核心能力是否得到强化；
每年评估定位是否需要升级或转型；
持续学习，关注行业趋势和客户需求变化。
成功的创业者懂得坚持核心，同时灵活调整战术。

找到定位只是第一步，有效执行同样重要：
把 80% 的时间和精力投入定位相关的核心活动；
持续深化定位领域的专业知识和人脉；
用简洁有力的语言表达定位和价值主张；
通过客户反馈和市场数据不断检验定位有效性。

创业是长周期竞赛。正确的位置不仅能帮你赢在起点，也能让你在漫长路上保持方向和动力。最有价值的定位不是模仿别人，而是找到那个只有你能胜任的独特位置。在那里，热情、能力和市场需求刚好契合，形成难以复制的竞争优势。

# 1.2 向内探索——自我评估

当你回忆高光时刻、记录心流体验、分析朋友的夸奖，其实是在整理一张“非学历版简历”。这张简历记录的是你做事的动机和风格。

下面的内容，建议用飞书文档或备忘录记录下来，边看边写。每当看到反复出现的关键词、情绪或购买偏好，就记下来，越多越好。不用担心写得乱，后面投喂给 AI 都能识别处理。

# 方法一：成就事件复盘法

这是我很喜欢的方法。

拿张白纸，把特别有成就感的事情写下来（比如：我爱干什么？别人夸我什么？有什么特别经历？），可以写 10 个或 20 个，然后分析自己用了哪些能力，最后汇总重复出现的能力。

让我特别有成就感的事 | 我用了哪些能力 | 重复出现的能力

如果多个事件里“表达、设计”反复出现，说明这可能就是你的核心能力。

# 方法四：精准提问法

不要泛泛地问“你觉得我好吗？”，可以这样问身边的朋友、客户、同学、同事：

“我们合作的时候，哪一刻你觉得我最靠谱？”
“你觉得我最适合负责哪类任务？”
“你跟别人介绍我，通常怎么形容我？”

这些具体场景下的反馈，才是有用信息。

留意这些线索：
同事总让你处理什么问题？比如“你帮我理一理这件事的逻辑”；
朋友会说你“一看就像个特别有条理/特别能安抚人的人”。

# 方法五：刷手机痕迹分析法

刷手机痕迹分析：抖音喜欢 + 淘宝订单 + 🛰️吐槽 = 真实兴趣图谱。

这个方法简单到什么程度？不用写作业，不用冥想，只要回看手机记录。

为什么要看手机？
因为手机是你最真实的“兴趣雷达”。你点了什么、买了什么、吐槽了什么，都在说明：你对什么感兴趣，注意力在哪里。

# A 抖音喜欢记录

翻开抖音、📕、视频号，看看你点赞最多的内容。

你疯狂点赞“装修干货”？可能对空间美学、动手整理感兴趣。
你天天收藏“情绪类鸡汤”？可能有很强的共情力，适合做陪伴型 IP。
你爱刷猫猫狗狗？很可能在真实世界也特别会和宠物相处。

你喜欢看的内容，就是兴趣地图。你关注的，就是你想成为的。

# B 淘宝订单记录

很多人不知道，你买过的东西，就是价值观的实物体现。

你爱买文具、笔记本？可能是一个规划控、系统型人格。
你爱买“看起来没啥用但特别美”的东西？可能有很强的审美表达力，做生活方式博主很有潜力。
你经常买 AI 工具、线上课程？就是一个天生的学习者+效率型人格。

看懂你“为啥花钱”，就是看懂你“为啥被打动”。

（PS：同理，可以去看看小鹅通/视频号小店等后台）

# C 🛰️吐槽/朋友圈发言记录

这一条很多人会忽略，但它超级真实！

回头看看你过去发过的朋友圈，或者和好朋友聊天时常常吐槽的点：

“我真的受不了领导沟通不清楚！” 👉 你可能是天生的结构控，很适合做知识型输出。
“为什么这些广告都这么土！看得我好焦躁！” 👉 你可能是有审美洁癖的品牌型选手。
“我最烦那种讲话不带重点的人！” 👉 你可能是“表达高效”型人格。

这些反感、偏好、碎碎念，都是你“价值锚点”的线索。AI 可以辅助你整合成一张「认知地图」，但第一步，得你自己先打开。

# 方法六：“过往数字资产”投喂法

适合谁？
👉 如果你觉得“我也不懂自己擅长啥”，但之前发过内容、写过笔记、做过简历，那一定要试试这个方法。要做的就是：把你“做过”的扔进 AI，让 AI 帮你找出连自己都忽略的闪光点。

✅ 可以丢给 AI 的素材有哪些？这里列一份清单，直接照着找：

# A 你写过的内容类素材

👸号文章（特别是讲经历/感悟/成长/复盘的）
📕笔记 / 🧣长文
知识星球发过的内容 / 社群内分享记录
视频脚本或提词稿（有内容沉淀的也行）
知乎回答、B站文案、豆瓣日记等
任何你写过的“年度总结”“30 岁前想做的事”之类的内容

然后请 AI 提取信息，提示词：

# 💡

“请阅读下面这些文字，帮我总结：我擅长什么、常用什么表达风格、适合做哪些内容方向。”

# B 你准备过的职业资料

简历（重点看工作经历/技能部分）
面试自我介绍稿
作品集或案例集（不管是设计、写作、项目类都行）

然后请 AI 提取信息，提示词：

# 💡

“请根据我的简历和作品集，分析其中体现的技能，并提炼我的专业优势。”

# C 你跟别人的聊天记录（只要你愿意整理）

朋友圈留言/评论记录
和朋友/前同事聊职业发展的语音稿
接私活过程中的咨询、报价、交流（可提炼你的服务能力）

然后请 AI 提取信息，提示词：

# 💡

“请从下面的对话里，找出我提得最多的关键词、用户认可我的地方，以及我最擅长解决的问题。”

我擅长：设计、表达、结构化思考
我的风格：逻辑清晰、通俗易懂、热心分享
我的内容方向：AI+设计、IP 定位、实战案例
