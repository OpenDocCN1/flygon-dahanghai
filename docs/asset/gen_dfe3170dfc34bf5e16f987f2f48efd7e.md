# 知乎安全引流：日均 50+ 怎么做？

大家好，我是星城。希望这个名字能给你带去一点好彩头，愿你无论做什么，都能心（星）想事成（城）[呲牙]。

今天想聊聊知乎引流，重点不在“引”，而在“安全地引”。这件事看似简单，真要做稳，里面的门道不少。之前有位朋友问我：“知乎粉丝重要吗？”我的回答是：重要，但更关键的是，能不能把这些流量沉淀到自己的私域池里。说到底，谁掌握了流量，谁就掌握了主动权。

按照生财的习惯，先把成绩摆出来，再谈方法，会更实在：

① 我自己有一个线上记忆力课程，靠知乎往公众号导流，日均大约 20~40；

② 此前运营机构号做引流，日均能往私域导入 50+；

③ 高考填报志愿项目，13 天把公众号从 0 做到 5000，日均引流约 400+。
