# 3.3 微信私域获客四招

💡 本节速览

公域平台之外，微信同样是值得重点经营的引流阵地。微信天然适合社交传播，熟人之间的连接更紧密；群聊和公众号又能把兴趣、需求相近的人聚到一起，触达对象更精准。更关键的是，微信用户规模已超过12亿，大多数人日常都在使用，这为沉淀私域流量打下了良好基础。

为此，我们盘点了微信生态内几种主流玩法，供你参考：

✅ 活动裂变：以活动配合海报，撬动用户在微信里主动转发；
✅ 朋友圈传播：用优惠做激励，引导用户替品牌和口碑做宣传；
✅ 本地生活群渗透：先锁定潜在客户聚集的社群，再进群推广；方法掌握得好，这类群完全可以成为长期引流的“鱼塘”；
✅ 本地公众号合作：挑选粉丝画像贴近目标客户的公众号，联合开展宣传。
