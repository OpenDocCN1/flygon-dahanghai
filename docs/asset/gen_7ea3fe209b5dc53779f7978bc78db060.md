# 4.3 读懂仓库 Readme，再装 MCP 服务

MCP 服务目前主流配置有两种：stdio 和 sse，手册 1.3.2 部分有写，这里简述。

1. stdio 协议：通常部署本地，本地起 server、本地 client 调用，不能并发，可理解成 1 对 1 专属客服。
2. sse 协议：一般部署云端，通过 IP 或 URL 访问，支持并发，可理解成服务台。
