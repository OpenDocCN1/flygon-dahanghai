# 3天拉新1000人：训练营裂变实操拆解

作者：莲子丨Jeen ｜ 写于2020年9月11日

在星球潜水五个月，帖子一直没敢发，只是每天翻看前辈们的实战复盘，学到不少。这次鼓起勇气，把我亲自操盘的一个线上项目从裂变到成交的路径拆开讲讲。它更适合手上已有一定用户底子的伙伴参考。

项目背景：外部大环境碰上黑天鹅事件  
首轮裂变用时：6天  
项目代号：暂定“女神成长计划”

一、启动池怎么搭

首批力量分三路：
1. 重点培养的高价值学员约七十多人，预估四十人愿意加入裂变；
2. 向外招募约四十人，真正参与分销的约十五人；
3. 公司内部同事，实际下场约五人。

复盘看，如果外部分销社群更早开动、诱饵再加码，这组数字还能往上走一截。

二、怎么让更多人看见

我们用了四条线：直播预热、朋友圈、公众号、已有社群。

直播选在“XX秀”——成都本地一个新平台，自带流量并不大。加上是头一回和它签约，如果当时把首播放在小鹅通或我们原本就有粉丝的渠道，引流结果大概率会更好。所以做曝光时，渠道和合作方不妨多铺几条。

朋友圈：提前打磨公开发布话术、一对一沟通话术以及配套方案。  
公众号：发软文。  
已有社群：海报配文案推送，再做小分享和活动群内发售。

提醒一句：分销推进中，要反复给用户加一把火，让她们愿意继续带人。做法可以是晒成交、发红包、给荣誉、叠加后端权益。同时，尽量把能量强的人拉进来一起推课。你让一位有影响力的人往前多走一步，比推一个完全没基础的人省力十倍。

后来我还看到类似打法：某个“520”节点做发售，放出520元现金、会员卡、签名书以及价格不低的个人咨询。启动时参与人数并不多，但借推手之力，新品牌还是在线上完成了第一场漂亮仗。

一句话：主动靠近有影响力的人，你先给对方价值，对方也会回馈你价值，彼此认同，一起往前走。

三、让学员带来下一批学员

课程里埋了变现测试，第一期学员在“学习—演练—反馈—竞赛”的闭环里完成了第二轮扩散。表现好的学员会被请来分享，大家的参与热情又被抬了一截。

从我自己经手的项目看，这种循环扩散会让训练营口碑传得更快，也更容易被用户接受。原因不复杂：学员交作业时得到公开肯定，荣誉感会推着她主动替这个品类说话，她个人的影响力也随之上扬。

真正的钩子，是奖章上刻着她的姓名和头像，那种被专门对待的感觉很难替代。想让别人转发，先让她感到自己的价值被看见。

四、层层递进的发售设计

价格带从29.9到499；随后追销999元的“女神大学”，补差额就能升级。整体成交率做到33%，当时所有999档的学员都由我这边跟进。

高转化不是靠运气，而是每一步都接住下一步。当然现场也要随机应变。活动前我们正在跑“新年七天乐”免费打卡，等七天打卡收尾，第八天结营就被拿来做了首轮测试发售。

第一段：七天免费打卡。  
第二段：第八天结营，安排学员上台分享。当晚参与七天心得分享的人，全部买下了引流课。  
第三段：抛出重磅引流品。第一批抢到的人拿到超值价，还叠加喜马拉雅等赠品。  
第四段：告诉大家，名义上的三天营实际交付五天内容，而且每一段都能拆开，线上线下都能直接拿去用。  
第五段（重点）：学习过程跟踪。开营有仪式，结营也有仪式，穿插优秀学员点评与分享；导师和班主任全程一对一陪跑，把学习、演练、反馈、竞赛跑成闭环。  
营期里，既要让学员玩得开心、学得扎实，也要让她们有机会拿奖励、甚至赚到钱。每次做复盘拆解的学员，能领6.6元、66元或100元现金红包，也可能拿到周大福小金猪这类实物奖。我们还会引导她们在复盘里带上平台名和创始人名，于是脑图、简书、朋友圈内容就自然长出来了。  
第六段：成交。课程最后一天加结营当天，推XXX课程（价格接近原价一半），再送价值699元的配套产品，限疫情期间。  
第七段：追销。买过成交产品的学员，再补XXX元就能升为白金会员，解锁六大权益，总价值接近四千元。

以上只是引流营的骨架。后面针对买了后端产品的人，我们又做了第三轮扩散。昨天就有一位学员靠成交分享，在三十三人的小群里卖出了二十六单。更细的第八段、第九段以及每期复盘、线上线下沟通，这里先不展开。

SOP能把社群运营变轻，但真正托底的是运营团队。团队配合不到位、训练营不迭代，SOP写得再漂亮也落不了地。

【关于用户沉淀：分层触达】

我的经验是沉淀三到四次比较好，最少三次，目前还在测。

第一层，客服先接触并筛选：做倒计时提醒、拉群、系统答疑。  
第二层，班主任跟进：我要求班主任在建班群当天把每位学员都加上，做简短自我介绍、聊几句，再带班级做预热、发入营提醒。班主任要像家里长辈一样，给足陪伴感。  
第三层，导师加专业度：点评作业、解答问题。温暖给完，再上干货；加餐和额外奖励是刺激点，但不提前说。  
第四层，大咖露脸：营长或专业大咖翻作业时发现你，在群里点名点评，再顺势引导添加。学员会觉得，原来高手也能这么随和，被偏爱的感觉一下就上来了。学员加到大咖往往很开心，我们偶尔会做这类引导。

这样跑下来，营期里只要存在可能性的学员，几乎都能百分百接收到我们的信息，形成包围。结营后没成交的人，也还会持续刷到我们的内容；信息密度足够高，兴趣就可能被重新点燃。确实有好几位是在结营后一周内才付款的。

客服负责打消顾虑，班主任夜里送问候，导师耐心答疑，大咖在群里制造爆点。

还有一点很关键：老客户的价值，可能是泛流量新客的百倍甚至千倍。对方已经跨过一次信任门槛，继续同行会容易得多。前提是，成交不是销售句号，而是服务开场。
