# 3.2.3.2 同城达人置换，引流更省力 @Mage

[PRE0]

我经营的是轰趴别墅，平时会在小红书物色同城探店达人做资源互换：邀请他们免费到店体验，交换条件是发一篇小红书笔记帮忙宣传。

我的同城达人置换流程，大致分这几步：

1. 先进入小红书，把位置切到同城，持续刷推荐内容。重点找18到35岁、平时爱分享和打卡的本地用户。点开主页后，我主要核查四项。

第一，看粉丝规模。量太小，置换基本不划算；量太大又通常不接免费合作，而是收推广费，大致在500到1万元。因此我通常只筛5000至3万粉的账号。

第二，再看内容是否集中在同城吃喝玩乐。如果主页清一色美妆、护肤，那多半是泛粉，同城精准受众偏少。

第三，然后看拍摄和文案能力。标准很直接：我自己刷到时愿意点进去，而不是一眼就觉得是随手拍。

第四，最关键的一项是粉赞比。优质账号的粉丝与点赞收藏总量，最好在1:20以上；也就是说，5000粉的账号，点赞收藏合计至少要有10万，才算比较能打。

2. 第二步是私信沟通。我的开场一般这样写：“你好呀博主，我一直在看你的笔记。我们是XX地区XX别墅轰趴馆，觉得你发的内容和照片挺不错，想请你和朋友来免费体验，唯一的要求是帮我们在小红书发一篇宣传笔记。”

之后用账号批量私信同城达人。对方有意向时，再发场地照片、地址和可体验时段，随后加微信约探店。通常私信10位，会有3到4位答应，最终到店的是1到2位；剩下的人多半说近期没空，或想等朋友过生日再来。

达人到店时，我会花10元左右定制一条横幅，写上“欢迎XXX到店体验”。这个动作不复杂，却能明显提升对方的好感，让达人感到被重视，后续拍照和宣传也更愿意用心。

3. 第三步，体验结束后要及时跟进稿件。最好在1到2天内发到小红书，同时和达人约定尽量保留至少一个月。若你积累了大量同城达人资源，还可以拓展品牌推广、门店营销等变现方式。

另外，私信太频繁容易被平台封号。我通常每天发10到20条，并分散到多个账号上操作。等认识的本地达人多了，同城往往会有交流群或组织，想办法加入后，做置换会顺手很多。
