# 两年35万：猫繁育这门慢副业，普通人能做吗

我是Cecilia，先跟这里的朋友问声好。养猫的人不少，但把猫当成一门小生意来做，很多人还没接触过。它当然没法跟互联网项目比规模，可有个实在好处：陪着猫，也能把第二份收入慢慢做起来。今天把我走过的路摊开讲讲，或许能给你多一个看副业的角度。

0）先聊一个看似无关的问题

欧洲一些国家为什么给人“悠着干”的感觉？拿法国来说，罢工和休假多到夸张，很多国家工时不算长，福利却覆盖全民。再看中日韩，甚至美国，假期紧、强度高，多数人忙得脚不沾地，日子未必比欧洲轻松。

差别在产业选择。欧洲占住的多是“高溢价、慢积累”的行当：精密机械、仪器、奢侈品、畜牧。它们靠时间垒门槛，后来者砸钱也难一夜追平，这是“慢积累”；年头久了又长出品牌溢价，丹麦奶、瑞士表、意大利包，这是“高溢价”。于是他们工时短也能撑福利，因为追赶者需要几代人的功夫。

中日韩和美国多是后发者，在欧洲的老牌强项上落后太多，硬追不划算，于是挤进IT、互联网这类“高溢价、快迭代”的赛道，大家起跑线接近，还有超车机会。诺基亚被冲击就是例子。代价是全员卷在竞争里，不加班就可能被新玩家顶掉。

说回猫。家养猫繁育恰好偏“高溢价、慢积累”：要耗时间，但成品能卖出溢价。下面不藏私，讲我这两年的做法。

1）从单猫养起，两年做出35万

2018年我买下第一只猫，本来只是添个宠物。挑猫时发现价格跨度极大：几百到十几万，都是猫，差距怎么能拉出几百倍？我做了十年战略市场，职业病上来，开始查资料、混猫贩群、找繁育者聊，把市场摸了一遍。结论很直接：这门生意有利润空间。于是我把目标从“养”改成“繁育”。

当时我已付2000元定金订了只幼猫，可幼猫至少还得等十个月才可能配种。我选择放弃定金，另找卖家，花4000元接回一只成年矮脚母猫，取名“尿尿”。用钱换时间，后来看是对的：在闲鱼找到公猫借配，两个月后第一胎产下四只，最终三只站住。其中矮脚长毛成交2.2万元，长腿长毛卖了3500元，剩下那只矮脚短毛母猫留作种猫。本金四千，回收两万五千五，再加一只种母，日常粮砂开销不大，两个月回报率超过600%。

这波高收益，靠的是押中当时的银白花色和矮脚品种，它也成了高产母猫，一年多带来十万以上收入。但这不是我的平均线。我也碰过不会配种的公猫，也遇到过会伤崽的母猫。随着对花色遗传和繁育细节更熟，收入才慢慢稳下来。第一年只有2只母猫、1只公猫，出栏约20只小猫，按品相和花色，贵的两万+，便宜的2000+，全年大约12万。第二年扩到5母2公，有自繁也有外购，因为像“尿尿”这种能生又好看的种母并不好遇，第二年进账二十多万。

两年35万，跟网上那些“百万副业”比不刺激，但成本端确实省心：吃方面，家里9只成猫（十几只奶猫还在吃奶，先不计）一年猫粮约8000元，用的是中端粮，想压成本还能再低；猫砂一年约2500元，选的是较贵的豆腐砂，换膨润土会更省。空间上，做繁育不必像养宠物那样精细伺候，分笼分层即可，八平米的小次卧塞下二十只并不难，白天放出来活动，夜里回笼。这行不用通勤，圈里有人干脆在远郊租便宜别墅全职做。我认识一位杭州的年轻男生，租400平方米别墅养猫，四五年下来稳定年入200万到300万，今年除了特斯拉又添了保时捷；他毕业不久，原生家庭复杂，还得替父亲还债。精力上，猫少时自己动手，每天抽出十分钟添水、加粮、清猫砂；猫多后请保洁阿姨顺手处理，反正屋子要打扫，多不了多少，人工这块一年算四千块。够勤快当然能省，但我们更愿意把这点时间拿来躺沙发打几局游戏。

今年我打算继续扩群，同时淘汰低产母猫，培养或外购更多高产种母，目标十只母猫、两只公猫，先把稳定收入做到70万，再往百万够一够。

2）做好这门小生意，我靠五个抓手

a. 用数据判断行业是不是往上走

要不要进一个新行当，先看趋势。只有上升期的行业，才给后来者留缝隙。买猫前我翻了不少行业报告，发现猫市场总量虽小于狗市场，增速却快得多；再叠加大城市养狗门槛升高、独居年轻人变多、养猫耗精力低于养狗这些证据，我判断猫经济的上行不是短潮，而是长趋势。

b. 提前押品种和花色

猫的品种上百，踩中流行周期时能卖几万，不在周期里可能三百都没人接。我第一只就选到高产“尿尿”，靠的是线上观察。那时我在🧣注意到老牌宠物博主“郭斯特”，他养了银白矮脚“馒头”和一只布偶。社交平台的审美常常会传导到市场，于是我把目光放到矮脚和布偶上。布偶当时已经在风口，三五万甚至十几万，盛极容易转衰，我判断它离降温不远；矮脚则刚借“馒头”进入大众视野，很多人还叫不出品种名，繁育者更少。于是这个“已被验证会火、但尚未全面铺开”的矮脚，被我锁定。我还刻意往“馒头”那种银白方向配，接回了银色“尿尿”。

矮脚带来回报后，我又去找下一波可能起来的品种：赛尔凯克羊毛猫和德文猫。羊毛猫掉毛少，长相像洋娃娃，还能和现有矮脚搭血，所以我先押羊毛猫。现在看，这两个品种确实热起来，价格也在往上走。

3）先选生态位：卖给谁、做哪档

猫繁育盘子不算大，但生态已经分层。

渠道上，有人直接卖终端客户，是2C；也有人对接猫贩，是2B。猫贩相当于中间人，一头连繁育者，一头连买家，赚中间差价。通常终端价会比渠道价高约一倍。档次上，有做协会认证血线的，种猫几代祖先可查，甚至带奖，一只能卖十几万到几十万；也有像我这样在家做、不带证书但保品相、单价几千到上万的中端繁育间；还有在农村租大厂房、养上百只种猫、等猫贩整窝收走的，均价一只一两百。另外就是猫贩本身，我的合作方里有位东北大哥，书读得不多，只在🛰️上倒猫，一年能做到200万+，在猫贩里算头部。

所以入行前得先想清楚自己站哪一层。我判断2C前期沟通和售后太耗人，作为副业不合适，于是主做2B，出手就结束；我是新人，高端人脉有限，高端猫未必有人买单；再加上人在北京，租金贵，附近很难找到又大又便宜的场地做“流水线”，最后选了中端猫房。

4）繁育与医疗：利润背后的硬功夫

想多赚，选对品种花色只是第一步，真正决定利润的是成活率。我经历过一窝6只全没的惨状，也碰到过养到四十多天突然便血、很快断气的怪事，还见过猫砂盆里流产的小肉团，吓得直掉眼泪。两年下来，说半个兽医不算吹牛。家里制氧机、雾化器、保温箱和常用药都备着，给猫打针我能上手，小毛病也能做个初步判断。

同时我花了不少时间啃繁育知识：不同协会对各品种品相的标准是什么，想要某个花色该拿什么猫去搭。这些内容看着专业，认真学、反复练，大多能拿下。举两个场景：母猫自然分娩可能难产，一尸多命；或者母猫不会带崽，死一半甚至全窝覆没，没经验的人只能干看着。懂行的人知道什么时候打催产针、怎么接生、怎么剥胎衣、甩羊水、用负压球清口鼻、擦干保温，以及怎么做母猫产后护理。有了这些本事，别人拿几百、偶尔上千的猫赌运气时，你能让每窝稳定出几只上万的苗；别人一窝折一半、长期担心团灭时，你能尽量把小猫带大。这不只是利润率翻几倍，也是对生命的敬畏。

5）运营与成交：把信任变成订单

运营跟互联网那套相通：获客、转化、复购与转介绍。

a. 获客。渠道无非🧣、闲鱼、朋友圈、🛰️群。多抓机会加同行和猫贩，这行不是标准品，同行竞争没那么硬，大家都愿意互相扩采购和出货的路子。不过这是“看脸”的生意，获客效果九成多取决于照片和视频，拍摄技巧、设备不能省。

b. 转化。也就是成交过程。不管2B还是2C，核心是“有温度”和“够专业”。猫是活物，虐猫新闻不少，有些繁育者对待猫很粗暴，买家只有觉得你有爱心，才敢放心掏钱、不背心理负担，这是温度；专业则是你能回答养猫疑问，能保证猫健康、交付不出岔子。朋友圈是转化主阵地：日常养猫、小知识、粮的档次、买家返图视频，都能让形象既专业又有人情味。成交靠信任累加，别人刷到你的朋友圈，未必当天找你，但心里的信任分已经涨了。

c. 复购与转介绍。要分C端和B端。卖C端，回头客和转介绍来自售后与医疗指导，客户觉得猫靠谱、人也靠谱，才愿意再来或带朋友；卖B端，售后不是重点，关键看猫的质量、健康状况、花色是否和照片一致。信任攒够了，你成了B端眼里最稳的供货方，采购需求就会持续找上门。

6）两年猫舍，给我补上的三堂课

做繁育两年，我从零进入一个陌生行当，也卖到了行业前10%的价格（九成繁育者卖不到万元）。最大的收获有三点：

1. 门槛低的行业，反而容易做出头。因为不少从业者是“没别的选择才干这个”，你稍微用点方法，就能跑到前面，这大概就是降维打击。

2. “慢积累、高溢价”的行业适合做副业。它不靠人天天盯，更多是生产资料随时间自动产出，竞争也没那么凶。网上很多热门副业，其实要投入大量精力，搞不好主业也被拖累。

3. 再简单的生意，也不一定拼体力，但一定要有主动学习和攒经验的意识。这种行业拼的是细节处解决问题的能力，谁能解决，谁就能在利润率和成功率上领先。

最后，给后来者的三条提醒

1. 从最小可行模型开始。我有猫友一上来就打高端局，几十万买一堆带证带奖的种猫，可协会标准跟大众审美有偏差，上家不指导就容易踩大坑（这样的上家不少）。建议先看流行趋势，小规模试，跑通一轮最小模型再谈扩张。

2. 找懂行且靠谱的卖家带路。与其自己蒙眼踩坑，不如找人品过关、专业够硬、能判断市场的上家。上家要给你技术支持和培训，第一个上家基本决定你的起点。比如找到前50%的上家，你的起点约70%；找到前10%的上家，起点可能在20%。这行靠时间攒经验，好老师能让你少走至少一半弯路。

3. 主动学繁育和兽医知识。医生培养慢，是因为人命关天、实战机会少；猫不一样，只要肯学肯练，打针、配药、接生都能较快上手。我可以分享一些自己验证过的学习渠道。

再补几句：加我的人很多，有些看完文章觉得养猫能赚钱，立刻想袖子一撸开干。先别急，我泼盆冷水。

1. 繁育是在“玩命”。猫生产真没想象中轻松，不是配了就自动生。为护理早产儿，我四天四夜几乎没合眼；呛羊水的幼崽要持续雾化、每两小时下一次胃管；乳腺炎母猫要反复热敷消炎。这些“挨打”的场面文中没细写，可能是我把吃肉写得太轻巧，给了误导。请谨慎看待繁育，若只是一时上头，没有心理准备和学习耐心，别盲目跟风。也别刷几条短视频就以为自己是猫界神医，所有行业都一样：能公开讲的多是皮毛，核心竞争力不会白送，只能自己交学费摸索（跟对上家可能教你）。

2. 入行第一大坑，是不负责的上家（卖你猫的人）。我观察两年，不夸张地说，国内繁育人里九成不懂猫毛色遗传、不懂医疗，连颜色斑纹都分不清（包括闲鱼上家里两只猫随便配一配的那种）。不少人加我说准备在闲鱼、🛰️、58买只便宜猫试试繁育，我问“品相如何”就答不上来，再问对方是猫贩、猫舍还是家庭繁殖，又卡住。这种客户卖猫的最喜欢，因为就是鲜嫩韭菜。遇到那九成上家，你只能自己把所有坑趟一遍，先把避坑指南多看几遍。

3. 猫好不好，跟价格没有绝对关系；但只看价格买猫，大概率下场难看。矮脚从300到30万都有，你不做前期调研、不多聊几家猫舍猫贩、不研究协会品相标准、不翻贴吧里那些被坑到裤衩都不剩的帖子，就敢下手？文章里写了我买第一只猫前做的事，别只盯结果，前面的铺垫才是重点。

啰嗦这么多，就是非常不希望大家因为一篇帖子就冲动买猫。只看到赚钱，忽略前期调研和繁育里的坑，以为能躺赚，最后发现幺蛾子一堆，活下来的还只能送亲戚。我完全可以忽悠你们“养猫很赚，来买我的猫”，但那违背我的价值观，所以还是要反复提醒：谨慎。

最后，猫圈有行规，核心技术只传下家，做生意的人应该能理解；大而泛的问题我不回，比如“如何做猫舍”“如何选种猫”“如何卖猫”，这种跟“如何赚钱”一样的空问题，统统略过。技术问题不教外人，只教下家。谢谢读到这里，感谢龙哥盟。养猫副业交流VX：celiagissing912。
