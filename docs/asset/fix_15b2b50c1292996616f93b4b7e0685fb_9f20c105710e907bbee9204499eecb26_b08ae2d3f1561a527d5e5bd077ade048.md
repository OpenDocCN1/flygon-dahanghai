# 日本高税品，跨境价差还在

跨境生意越来越挤，这点从业者都有体感：买量成本往上抬，售价却不断被压低，一个新品刚有点起色，跟卖和低价就围上来。国家层面持续鼓励出海，新卖家还在成批进入，早年那种少投入、快见钱的窗口已经变窄。美国站更明显，国内常用的包邮、低价螺旋、重仓冲量等打法搬过去后，原本偏空白的细分带也很快被打成苦生意。大家常说的“机会里的机会”，正在变成硬碰硬的消耗战。

不过，市场并没有完全封死。小语种站点有语言和本地化门槛，竞争密度相对低，仍可能藏着靠认知落差赚钱的品。日本值得重点看，特别是当地高关税门槛下的某些商品，价差空间比较可观。

-01- 跨境最早赚的是价差

我2009年入行，那时行业才起步没几年。eBay上跑得动的代表品包括3C小配件、婚纱、假发、角色扮演服饰、仿品等。做法很轻：不压库存，不设海外仓，左手拿货右手卖出，成本多少元就标多少美元，国际直邮自发货，把传统外贸里的进出口公司和层层分销商绕开。比如成本400元左右的偏高端婚纱，卖到400美元，在美国原有价格体系里仍只是零头。模式更新、价格更低，利润却很厚，对旧体系形成降维打击。

所以，跨境生意因差价模式而兴起，本质就是赚价差。

后来从业者变多，轻投入快回本的空间被压缩。很多玩法不再是套利，而是先烧钱、再图盈利的“盈利模式”。从套利到盈利，一字之差，门槛上去了，赚钱效应却下来了。

那还能去哪找轻投入的价差机会？我通常看三点：投入要轻；掌握别人没看到的信息落差；结果要有确定性。

投入轻，一件代发就是典型，运营上不用大规模囤货，也不必亏钱亏货去刷单刷评价拉排名。信息落差，是低竞争品类的底色——知道的人少，抢的人就少。但单纯的产品信息差越来越薄，选品思路要从“追热点、看热卖榜、铺货、跟卖”升级成“找新模式”，从赚产品差转向赚模式差。比如高关税品类，选品不是追爆款，而是翻海关税表找高税商品，再用邮政包裹单票自发货合法避开关税，把税差变成利润。这是行业里少见的选品方式，也是新的模式信息差。

确定性，指的是盈利和转化可预期。绝对成本优势是一种确定性：你能做到只有你便宜，别人便宜不了。复制别人已经跑通的模式、抄经过验证的作业，也是一种确定性——少交试错成本，而且这个方法最好还只有少数人知道。

能赚钱的选品思维，通常要同时满足这三点。

-02- 日本市场的数据面

过去两年，我们服务过1200多个自建站卖家，绝大多数做欧美。把日本和美国摆在一起，有几组数字很直观。

人口上，美国三亿多，日本一亿多，规模约3比1。人均收入两国接近，但日本贫富差距远小于美国。卖家分布上，1200多个自建站样本里，做日本的不到10个。网购渗透率美国高于日本，但疫情后日本增长很快；从2020年年中开始，卡组织收单数据显示日本单单量迅速上涨。

收入相近、网购率逐渐靠近，市场规模是三比一，卖家规模却不到100比1。仅这一项，就说明日本那边的竞争烈度远低于美国。尤其在乐天这类准入门槛较高的平台，即使铺货模式，也还有一定红利期，而这在美国早已不存在。

实际做下来，日本有四大优势：竞争弱、客单高、物流快、纠纷少。

竞争弱方面，日本主流的亚马逊和乐天两大平台，铺货模式仍有红利，上架产品不刷单、不刷评价，也能靠正常运营把搜索排名做上去，避开了大量卖家遭遇的封号风险。自建站方面，某些垂直品类长期没有竞品站和对手，谷歌投放成本最多能比欧美便宜一半。我们的谷歌广告CPC单价大多在17到23日元，约0.2美元，这个价格欧美卖家很难想象；脸书跑点击量，CPC也能控制在12到18日元。

客单高方面，垂直品类、认知差品类、高税品类客单价较高，毛利空间更大。

物流快方面，自发货2到3天清关派送，旺季时效也有保证，不会像欧美自发货商家那样遇到物流积压、卖得越多亏得越多。

纠纷少方面，只要产品性价比和质量过关，绝大部分交易是静默交易。即使自发货，客服和售后成本也很小，自建站几乎没有拒付；欧美自建站长期被拒付党、撸货党困扰，这部分低素质人群在日本基本没有。

-03- 从税表里找品

我们的做法有点反常识：不追爆款，先看税表。通过货代统计各品类在海关的关税税率，从高到低排序，从税率最高的开始选品，再通过邮政渠道单票自发货合法避开关税，把原本要交的税转化为利润空间。

这套方法不只适用于日本。中美贸易战背景下，美国的高税品类也值得调研和尝试。

日本主要的高税品类是真皮类，其中真皮皮鞋关税最重；食品和糖果类也属于高关税品类，税率与真皮制品差不多。

以真皮皮鞋为例，每双在日本海关的关税是4300日元，约300元，经常远远超过货值。正常贸易公司进出口无法规避，大货清关、亚马逊大货和货柜也避不开，只能通过邮政渠道单票自发货、以私人件清关来规避，这是合法的。

食品糖果除了高关税，还有市场准入壁垒，平台无法上架，这反而给自建站卖家创造了可能垄断的机会。只要能找到20个左右符合海外买家口味的网红食品，就能搭起一个自建站。具体打法以后有机会再分享。

-04- 真皮鞋靴的价差清单

真皮不是单一品类，而是一种材料，这给选品留了很大空间。高关税导致市场售价普遍不低，基本不会低于500到600元。通过邮政自发货避开关税后，即使按市场价一半出售，单件净利也能接近100元。对做欧美的跨境人来说，这样的利润空间并不常见。

真皮支持一件代发，符合投入轻的逻辑；高关税这个信息落差，在我们对接过的客户中几乎没人知道，符合认知差的逻辑；避开关税形成的成本优势，又带来转化和模式成功的确定性。因此，这是一个很好的选品方向。

真皮制品品类多，建议分优先级：先从自己更专业、有供应链优势的品类入手，比如我们选鞋类；也可以从自己感兴趣、喜欢或有相关资源的品类优先做。

可套利的真皮鞋靴不少。成本越低的真皮鞋，在日本套利空间往往越大，因为不管鞋子多贵，日本海关都收约300元关税。中国工厂本身有成本优势，真皮皮鞋也不例外。一些凉鞋、包头软木拖鞋、单鞋，出厂价最低30到50元就能做，所用皮料多为牛二层皮、牛绒皮，这些低成本皮料也是真皮，在SKU标题和详情里可以直接标明真皮。

根据多年售卖经验，以下真皮鞋靴套利空间较大：包头凉拖、凉鞋、户外鞋、登山鞋、马丁靴、工装靴、雪地靴、豆豆鞋、休闲鞋。

品质性价比兼顾的拿货成本与零售标价，可以这样参考：

软木底包头拖鞋：拿货30到60元，标价1980到3980日元，单件净利50到100元。  
经典基础凉鞋，如玛丽珍一类：拿货40到70元，标价2980到3980日元，单件净利50到100元。  
户外鞋，含户外凉鞋和登山鞋：拿货55到125元，标价3980到7980日元，单件净利100到200元。  
马丁靴：拿货60到180元，标价3980到9980日元，单件净利100到200元。  
工装靴：拿货90到120元，标价5980日元，单件净利100元。  
雪地靴：拿货50到160元，标价3980到8980日元，单件净利100到200元。  
豆豆鞋：拿货35到55元，标价2980日元，单件净利70到100元。

补充一点：同为真皮材质，具体用料和款型不同，价格差异很大。有些单品成本和利润平衡更好，利润最大化空间更大。比如雪地靴，最贵最好的材质是羊皮毛一体、真皮真毛，出厂价一般在150元以上；同为真皮真毛，羊剪绒款只有90元左右，针织羊毛款最低不到70元，套利空间就比羊皮毛一体款更大。引流时还可以按“皮毛一体、真皮真毛、兼顾保暖与透气”的特性做营销，用同样的关键词获取自然流量和推广流量，再以极具性价比的价格提高转化。

-05- 把本土化、质检和仓配做细

日本消费者对细节敏感，运营动作要更细。做欧美市场，标题、详情、广告文案用词不准或不地道，对转化率影响未必很大；日本不同，用语是否地道、本土化是否到位要求更高。客户一旦觉得日语不标准，怀疑店主是外国人在卖货，就会产生防备，转化率明显下滑。因此，产品标题和详情要翻译准确，推广文案要使用商务敬语。

即使做欧美市场，也有不少本土化不到位的机器翻译错误。比如飞织鞋，很多标题直接按字面翻译，老外看了会犯迷糊，更地道的表达应当落在“鞋面针织”这个意思上。雪地靴也常被用错词，大量标题写snow boots，但这个词实际指滑雪、踩雪的靴子；通常意义上的皮毛一体雪地靴不防水，不适合踩雪，对应英文应是mouton boots或sheepskin boots，在澳洲也可以叫ugg boots，因为澳洲豁免ugg品牌词侵权，当地ugg boots是雪地靴统称，不是某个具体品牌。

日语关键词也是同样道理，很多日语叫法只是英语的片假名读音外来词。用错词会浪费大量广告费，流量不精准，转化低下，离赚钱越来越远。这就是本土化和精准文案、精准关键词的重要性。

做日本，虽然有低竞争空间、低竞争品类和低竞争模式，但客户对质量和快递时效要求较高，运营能力也要相应提高。

一般来说，真皮鞋类我们会选择100元左右的拿货档次，这是质量、性价比、终端定价和净利比较平衡的区间。一些低档便宜货可以在东南亚电商平台和速卖通做，却不适合日本，这类产品在日本退货率极高，会造成巨额亏损。

为了降低退货率，即使做一件代发，也必须设置质检仓，把所有货自己检查一遍，比如毛头剪一剪，及时挑出次品。这些事情交给中国工厂，即使叮嘱再到位也不行，因为一件代发的供应商有很多在品控上不稳定、不靠谱、不负责。比如我们在南京设置了质检仓，所有代发货先到南京检查一遍再发出。一些爆款产品，也统一由我们检查后送往上海前端周转仓或日本亚马逊仓。

前端周转仓是介于海外仓和国际直邮之间的解决方案。日本足够近，上海的前端周转仓一般可以做到当天发货、次日清关，最慢3到4天。这样既节省海外仓成本，也避免店铺关停后货退不回来、全部亏掉的风险。前端周转仓相对灵活可控，但质检也不能完全交给它，除非自己安排人去检查。

真皮制品由于大货无法避开关税清关，一般都走自发货；但通过EMS大件，也可以部分进入亚马逊仓并避开关税。我们通常会把好卖的尺码或爆款，通过EMS大件少量压到亚马逊仓，其他尺码和款式自发货。这样好卖的SKU能获得亚马逊Prime标志，在流量权重上得到提升，同时兼顾成本和海关风险。

最后说几句

我们从2009年开始做日本，从日本雅虎起步，后来逐步入驻乐天、日本亚马逊，2012年开始自建站，既是日本电商平台中第一代中国卖家，也是自建站玩家里最早布局的一批。对日本跨境的选品、建站、物流、支付、推广、本土化等全业务链条，我们积累了较深经验。

随着国家不断提倡发展跨境，我们一边感受到竞争加剧，一边也看到跨境服务市场正在成为新的机会池。2019年开始，我们增加了出海日本服务业务线，主要对接比较成熟的欧美跨境卖家，尤其是自建站卖家。目前，我们是国内唯一面向跨境中小卖家布局日本、品牌出海日本的专业且资深服务商，也与服务上市公司级的品牌出海服务商在日本板块保持合作。

今天分享的高关税品类选品思维，是我们多年实操总结的四大选品思维之一，比较适合日本。其他选品思维则不限于日本，也不限于平台或自建站，都是通用的选品思路，都具备套利底层逻辑。未来有机会，再与大家逐个分享。
