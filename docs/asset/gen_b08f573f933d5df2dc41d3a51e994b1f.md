# 6.3 私域售后，抓住这三点

售后做得好，客户对你的信任会越来越稳；做得糟，人可能转身就走。私域跟tb、jd上那种流程化、冷冰冰的客服售后不是一回事，它更依赖人与人之间的信任。

我踩过坑、交过学费，最后把做团购售后最不能忽略的三件事归纳了出来：

第一，预期要提前管。碰到预售或者发货偏慢的团品，别等客户来问，先在群里或私聊里说清楚，让大家对到货时间有心理准备。以前我反复解释过快团为什么发货慢，通常48到72小时内发出；时间久了，大家也就理解并习惯了。

第二，态度要主动、真诚。出现售后别回避，私域客户很珍贵，处理得敷衍，客户很可能立刻流失，转头去李佳琦直播间或隔壁团购群下单。

第三，兜底赔付要舍得。别怕吃亏，否则客户对赔付结果不满意，信任马上崩掉。不如爽快一点：换货邮费我包，质量问题不管供货团长赔不赔，我都负责到底。
