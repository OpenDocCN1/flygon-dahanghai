# 2.3.2 专项管理：资料体系怎么搭？

面对某个细分领域，哪些材料才算关键？这些材料又该依据什么逻辑，拼成一个可用的资料架构？若这两个问题没弄清，常常会陷入一种低效循环：时间投了不少，精力也耗了很多，最终攒下来的内容，对学习成长和商业转化却起不到作用。

这里提供一个分类思路：道—法—术—器—用。前四者出自《道德经》，“用”则来自一线实操经验。借助这个框架，能够较快为垂直领域搭起资料体系。

“道”这一层，主要收录概念、定义、核心理念、运行规律以及目标。它要说明的是：该领域究竟“是什么”，人们研究它“图什么”，以及这个领域为何存在、价值体现在哪里。

“法”这一层，更偏向在追寻“道”的过程中，通过实践思考与归纳总结形成的规则框架、方法准则。它比具体方法更抽象，是高度提炼后的规律。

“术”这一层，对应可执行的操作方法，即为研究该领域所采取的环节、路径、手段与技术。若再细拆，还会包含问题刻画、前提假设、适用边界等。

“器”这一层，指在验证“法”、追求“道”时，为了让“术”真正落地而使用的一整套工具。

“用”这一层，则是一些实际应用场景，以及能够参考的各类案例。

按这个方式去收集、整理细分领域资料：往深里说，足以写出专业且详实的学术论文、科研报告；往浅里说，任意维度下的任一模块，稍作打包，也能服务于商业引流或变现。
