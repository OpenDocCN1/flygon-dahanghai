# 8.3.2.1 我为什么选定职场号

[PRE0]

标红说明：这个方向离变现更近。

定小红书创作方向时，我按自己的履历把可选赛道捋了一遍，最后发现职场领域最贴合我：它既更贴近商业回报，也是我最有把握切进去的方向。原因有两个：

第一，我做过业务面试官；

第二，我曾在半年内换过四家公司，完整走过并拿到不同规模企业的面试结果。

花爷讲过，做IP的关键是找到自己的“势能差”：90分的人带80分的人，80分带70分，70分带不及格的人。专业选手有专业打法，新手也有新手路径。我的职场履历放在大厂HR面前不算什么，但拿去帮刚入场的大学生，够用。给真实客户做咨询时我发现，很多害怕求职的人，实际面试次数不到三次。就像第一次恋爱分手哭得死去活来，多经历几回，心态自然会稳。
