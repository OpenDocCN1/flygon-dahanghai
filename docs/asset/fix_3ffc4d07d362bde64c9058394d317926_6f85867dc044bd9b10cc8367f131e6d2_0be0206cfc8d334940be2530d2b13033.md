# 五、玩法升级：批量混剪的学与用

初阶和进阶剪辑都会了以后，短视频制作你已经能独立跑通。不过，如果你要同时维护多个账号、持续稳定地输出作品，一条一条剪的效率明显跟不上，这就要靠「批量混剪」。

想掌握它，先要理解混剪的底层逻辑。建议先读《剪辑基础决定上层建筑，了解混剪逻辑和去重设计》，把混剪与批量混剪的差异、去重怎么设计都搞清楚。
