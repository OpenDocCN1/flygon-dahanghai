拆解爆款并不复杂。你先锁定一篇已经跑出数据的文章，从头到尾读一遍，抓住它真正想表达的中心，再按“起笔—主体—收束”的顺序，用自己的话复述出来。比如前面提到的职场辣评账号，我挑了两篇：《地产已死，国企央企也逃不过房企大面积裁员，欠薪》《某大厂裁员还在继续，大晚上突然被毕业！》。读完会发现，两篇的落点都指向“裁员来得突然”。它们的结构大致是：开头交代企业背景；中段追问这些看似稳当的企业为什么也裁员；结尾总结并给出建议。读的时候要盯住转折信号——出现“但是”“为何”“为什么”“不过”“然而”这类词，往往意味着作者要换角度、往深处走。把转折前后的内容压一压，一个爆款模板就出来了。其他领域也一样，都有表示递进、深化的词。中国人说话写文章本来就有这个习惯：要转另一层意思，需要过渡词，不然会突兀，读者也难受。具体领域会有具体模板，但这套手册面向所有人，每个人做的领域不同，模板也不同。关键不是背模板，而是掌握这种思考方式，回到自己的领域手动拆解爆款。对标账号和爆款文章已经给了，先做案例分析。如果还没完全理解，就先照着写，写着写着就通了。

# 3.1.2 六条赛道，选题思路一次讲透

# 💡 提醒：平台和市场一直在变，下面这些赛道未必长久；本章真正要学的是底层逻辑，能迁移到别的赛道。

# 3.1.2.1 职场类：裁员和薪资爆料怎么选 @枫宇翔

职场赛道可以再细分，这里重点说大厂裁员和薪资泄露系列怎么找题。这个方向我去年在直播和多个场合都强推过：大环境在降本增效，企业持续优化人员，很多人天然关注裁员、优化。这批人又喜欢在职场应用里吐槽、分享经历，选题就藏在那里。最典型的是脉脉。下载注册登录后，刷大厂信息，或者直接搜公司名，就能看到大量员工爆料。

[PRE1]

只要是大厂消息，网友通常都爱看，公司本身自带热点。搜出来后，把主题截图和评论区截图放进文章，再结合自己的观点解读现象。裁员消息、薪资泄露是验证过的爆款方向；手册 7.7 职场裁员&薪资泄露系列给过对标账号，那个号 2023 年 12 月 19 日开始更新职场信息，涵盖裁员、薪资泄露等，数据一直不错。脉脉里互联网企业多，也可以迁移到公务员、设计师、房地产等行业，去头条、百家号、抖音、快手搜索。如果你就在这些行业，更方便，专业网站或 App 里就有消息。我自己是程序员，所以更关注互联网企业。注意几点：第一，裁员、薪资泄露只是众多消息中的一种，脉脉还能挖出更多方向。第二，这类信息受关注，也容易被大厂公关盯上，写的时候只讨论网友评论，别自我脑补，尤其别造谣或引导攻击公司，保持客观，用信息表达职场态度。看看对标账号怎么写。第三，除了脉脉，知乎、豆瓣、BOSS 直聘也能获取职场信息；裁员社会新闻、老板公开谈裁员的观点，也可以写进文章。对标账号的核心是职场+裁员，但形式会变。

# 3.1.2.2 热点类：热榜里的选题门道

热点选题优先看热榜，我常用微博和知乎。不同热点亚种，选题方向有差别。

“指点江山类”主要抨击社会不公，读者多为中老年男性。做这类选题，知乎热榜比微博更合适：知乎对负面新闻曝光力度更大，微博热榜粉饰痕迹较重。还要注意，知乎有些爆款回答有流量却上不了热榜，它们往往比热榜内容更尖锐，更容易爆，因为是一个赞一个赞投出来的，已经撩起读者情绪。选题就该选这种刀刀见血的内容。所以思路是：知乎自然爆款 > 知乎热榜 > 微博热榜。

[PRE2]

“娱乐热点类”追当下娱乐热点，读者多为中青年女性。多数作者应把微博热榜放首位，一天多刷几次。看到“热”字可挑，看到“沸”字优先，看到“爆”字不仅要优先，最好当天尽快出文，否则流量会掉。所以思路是：饭圈小道消息 > 微博热榜 > 知乎热榜。

[PRE3]

“养生热点类”做科普知识，读者不分性别，多为中老年人。这里的“养生”和常识里的不太一样，常来自古话，比如“立春三不吃两不喝”。老年人死亡焦虑、疾病焦虑重，这类内容容易带来阅读量。做法是结合农历节气和热榜里的健康内容，但落笔只能往古代习俗靠，不要给医学建议，否则容易严重违规。所以思路是：节气 ≥ 微博等平台的健康类选题。

[PRE4]

其余热点亚种我接触少，留待以后探索。

# 3.1.2.3 剧评类：两条选题路线

剧评选题有两条路。第一条是“热点+剧评”。比如《满江红》正火、评价褒贬不一，这时写五六七八篇角度新奇的影评，能吃到流量。第二条是“经典老剧”，比如《知否》《甄嬛传》《大明王朝1566》。老剧流量大、信息量大，随便一个细节都能挖出内容，写来写去不缺题，给一部剧写几百篇都不夸张。两个方向都能作为选题方向。

# 3.1.2.4 法律类：民生新闻怎么挑

写新闻尽量选官媒报道过的，这样被投诉概率低。记住：新闻不涉政涉军，最好全是蹬鞋踩袜子、家常里短这类民生新闻，必须和老百姓生活密切。能爆的新闻内容几乎都是这一类。所以我不建议去微博知乎找，各地新闻节目也能当素材。看到哪条新闻让你血压上来，就选哪条；没感觉就不选。理智一点，对照“开幕雷击七要素”选，占两条以上要素的新闻优先用，只占一条不建议，一条不占绝对不用。后面的法律条文直接百度检索，关键词抓新闻故事本质。比如一个人把另一个人的头打破，就搜“把人打成轻伤怎么判刑和赔偿”，能拿到大量资料，再汇编到模块里。

[PRE5]

# 3.1.2.5 历史类：追热点与稳写

历史选题可以追热点，也可以按自己想法稳写。

1、追热点要时刻关注动向。比如“胡歌生女，众人震惊”，可以找重要人物出生或生子引发巨大反响的案例。但这种热点需要很高契合度，经验不足不建议写。类似地，“县长贪污”新闻可以借来写古代官员贪污如何处罚；“明星和粉丝”可以写古代追星狂热，比如《大宅门》里白玉婷嫁给尚筱菊照片的事就有历史原型。

[PRE6]

注意：追热点历史必须契合度非常高，还要从今观古，需要作者有较强写作功底，大家可以在以后写作中慢慢加分。

2、中规中矩写作，就是按自己的想法写喜欢的历史人物和事件。写作最重要的是写得高兴，可以选敬佩、讨厌、惋惜、让人落泪的人物。找到人物后确定基调，包括事迹，给人物一个基本概括：是敬佩、同情、值得肯定还是毁誉参半，全文按一个基本思想写，就不会有大问题。比如写隋炀帝，基本绕不开劳民伤财、暴政、急躁等缺点；写唐太宗，可以用虚心纳谏、宽厚爱民等角度打光。对一些记载很少但很喜欢的人物，可以从他的前人后人、身边人角度写，也可以适当编撰，但别太虚假，始终保证假故事为真性格服务。再推荐圈友@一来 试过的近代史领域：如果你写历史，也可以涉及近代史。近代史起号相对难，常要一个月甚至更久，但账号进入流量池后阅读量比较稳。可参考“飞扬说史”，基本每天有大小爆款，不好的地方是文中经常没有广告。内容来源：6月8日《公众号流量主的经验分享》@一来。

# 3.1.2.6 情感类：找有爆款相的素材

情感爆文要选有爆款潜质的素材，可以去各大平台找灵感。

[PRE7]

比如：能引起共鸣、感人至深、有争议、事出异常的素材。包括：1）有曲折性；2）有情绪；3）有信息增量；4）有关民生问题；5）明星名人；6）性；7）暴力；8）金钱。一个故事至少包含上面8个要素中的3个以上。

# 3.1.3 选题避坑：别踩这些线 @半糖梦呓

公众号是公域流量，措辞必须注意。题材踩坑，写得再好也难爆，有时用了违禁词也会被平台打压。主要避三类坑。

# 3.1.3.1 政治红线不能碰

平台每月封几千上万个账号，大部分是很黄很暴力的号，还有相当一部分踩了政治红线。什么是政治红线？记住两个词：党史、军史。写文史内容的作者尤其注意。党和军队是正面形象，写作只能选正面内容，其他别写。想足够安全，1840年以后和中国有关的任何事最好都别写。民国人物和历史，半糖建议慎写，新手最好不碰。文史领域敏感，自媒体人要牢记使命、不忘初心；不该说的话一个字不多说，敏感历史事件、人物一根头发丝都别碰。有人问：就喜欢历史怎么办？建议新手从古代史入手，最好中国古代史，一来安全，二来受众广、话题多，容易出爆款。

# 3.1.3.2 热点别吃人血馒头

追热点是自媒体天职，但有一类热点在公域平台绝对不建议碰：吃人血馒头。什么叫吃人血馒头？第一个例子二更食堂。这个号曾是百万粉丝大号，后来被封。原因是滴滴空姐被害事件后，二更食堂利用大众关注，编造许多无中生有的情节，用词情色、猥琐，侮辱死者。这就是吃人血馒头，后果是百万粉丝大号说封就封，一点余地没有。

[PRE9]

第二个例子今夜90后。一个孩子和母亲吵架后跳桥，今夜90后虚构许多不存在的细节，事后证明是杜撰，只为博眼球。这个账号同样被封。

[PRE10]

利用逝者大做文章，甚至编造不存在的细节，用夸张、性暗示语言描述事件，吃相难看。网络不是法外之地，也不是道德禁区。中国人向来认为死者为大，谁拿逝者做文章，会激起众怒。有人问：碰到这种热点，不吃人血馒头、不脑补造谣，就站小老百姓角度评判社会行不行？不行。因为一不小心就会挑起社会对立、煽动仇恨。那么多正面事件看不见，专盯社会负面写，不封你封谁？

# 3.1.3.3 财经健康要资质

有小伙伴问半糖：昨天发微头条竟被官方删除？

[PRE11]

问清楚后发现，他没有财经资质却写财经内容。财经、健康都属于需要职业认证才能写的领域。没认证的作者写这两个领域，要么限流，要么删文，总之做不大。头条官方对财经和健康领域作者门槛有明确规定，需要职业认证：财经领域要满足以下22种职业中任意一种并提交证明资料——经济学者、财经评论员、财经媒体人、市场研究员、特许财富管理师、金融风险管理师、财经/投资分析师、特许金融分析师、投资经理、基金经理、交易员、银行行长、精算师、注册会计师、注册税务师、私募投资人、证券投资顾问、保险经纪人、保险代理人、理财规划师、黄金投资分析师、证券经纪人。健康领域要满足以下10种情况中任意一种并提交证明资料——医生、护士、药剂师、康复治疗师、放射/检验技师、医院院长、营养师、医药研究员、医药工程师、心理咨询师。更具体内容可去头条职业认证标准处查看，此处不赘述。

[PRE12]

如果以上情况都不满足，财经和健康这两个领域就别碰，这是非专业人士的禁区。以上三个禁区是明面上不能写的内容，在任何公域流量平台都共通。避开违禁内容后，还有细节要注意。首先查违禁词。可用句易网微信公众号，把内容粘贴进去查询，系统会自动过滤违禁词。查后可能意外：这不是天天挂嘴上的词吗？怎么也成违禁词了？具体自己试。若没违禁词仍被限流，就找找是否有标题党嫌疑。怎么找？举个例子：上周一个小伙伴问半糖，这篇微头条被警告了该怎么改？她原开头是：“闺蜜和前夫打来电话，要我退还1000000给他，我把他爆骂一顿之后拒绝了。他又发来一张照片和一条信息：晚上8点来我家。我呆呆的看着照片，眼泪夺眶而出，恨不得打死我自己。”系统警告理由是“刻意隐瞒关键信息”。

[PRE13]

这个“隐瞒关键信息”通俗讲就是标题党。曾被全网戏谑的UC震惊体就是标题党里的“翘楚”，套路是故弄玄虚、小事夸大、隐藏主语；读者被标题吸引进去，一看内容感觉智商被按在地上摩擦，有被强奸的感觉。读者纷纷取关拉黑，连带平台也被骂。平台不傻，有UC扑街史在前，现在谁还做一锤子买卖？于是加大对标题党的打压力度。学员这个开头里“一条信息和一张照片”就是典型故弄玄虚，也是被限流警告的原因。半糖建议改成：“他发来一条信息说：你看看这张照片，看你还敢不还钱？”这样意思一样，但没有刻意隐瞒关键信息，该表达的都表达了。

[PRE14]

4小时后，这篇微头条爆了63万+。很多时候，扑街文改成爆款，就一句话的事。但大部分小伙伴稀里糊涂，文章静悄悄扑了，想破脑袋也不知道问题在哪，其实就是某句话甚至某个词踩坑了。总结几类避坑题材：1. 有关政治的不能写：包括党史军史、时政热点、国家领导，除非你有互联网新闻信息服务许可证；2. 追热点不吃人血馒头：就算不造谣，站小老百姓角度评判社会也不行；3. 财经、健康需要资质才能写。其他避坑题材还有：4. 公务员、体制内题材也不要写，非常容易违规；5. 黄赌毒一定不要碰；6. 一些媚外内容尽量不要碰；7. 娱乐领域一些负能量事件和艺人尽量不碰，除非官方发话。内容来源：《今日头条七大变现方式，我只用一种，半年赚80000》。

# 3.1.4 选题技巧：做出差异化 @张波

选题一定要有差异化。大家内容差异化太低，千篇一律，就很难脱颖而出、拿到更多流量。很多写情感方向的现在还在写那些事，殊不知看这类文章的读者，对以前的所谓爆款已没新鲜感，除了自嗨，看的人越来越少。选题要分析，下面两个例子可能不太准确，希望能给启发：千篇一律的东西看得越来越少，一个人顿顿大鱼大肉也会吃腻，要学会找差异化。

观点+情绪

[PRE16]

分析领域内账号的写作角度。比如以观点+情绪为导向，很多账号写正观点+正情绪，而且特别拥挤；这时你可以写不同观点+正情绪，也可以写正观点+不同情绪。这样就有差异。
