# 案例二：代码站中英文营收反差 @哥飞

[PRE0]

流量大，未必更赚钱。Code4App 这个案例，最值得回看的恰恰是两套流量与广告收入之间的反差。

把时间拨回 2012 年。秋玉米上线才满一个月，4 月 6 日，Code4App.com 就正式出现了。这个站能起步，和搭档的背景分不开：他原本在 Oracle 做 JAVA 相关开发，后来一边学一边做 iOS。学习过程中，他手里攒下了一百多份源代码，其中有实现具体功能的，也有做界面特效的。可找代码这件事并不轻松——开发者通常只能靠搜索引擎，或者到各个论坛里翻找；更麻烦的是，下载之前很难判断这段代码到底有没有用、适合哪个系统，拿到手后还得花时间摸索怎么用。

于是他冒出一个念头：要是有人先把每份代码跑一遍，再用自己的话说明它能做什么、怎么使用，并附上运行效果截图，对其他开发者一定很有帮助，至少能省下不少时间。

几个人很快分好工：他负责整理代码，逐份测试、截图、写说明；我负责开发网站；当时来实习的设计师姑娘做了第一版界面。前后两周多，网站就搭好了，那一百多份代码也全部放了上去，Code4App 由此有了初始内容。随后我们在 V2EX 发帖宣传，反馈很不错，站长 Livid 还帮我们在 Twitter 上做了推荐。

到了 7 月，我们又上线了英文版 Code4App.net。这次没有做任何宣传，只在中文版底部放了一个英文站链接。过了一段时间，Google 慢慢开始收录，陆续有 iOS 开发者通过搜索引擎找过来；觉得好用的人成了常客，还会在 StackOverflow 回答问题时把英文站链接贴上去。外链越积越多，英文站在搜索引擎里的权重越来越高，流量也随之增长。

中文版这边，我们为了体验一直比较克制，只短暂放过一段时间广告，用来测试点击情况；发现广告收入不多后，就把广告代码撤掉了。后来有人想收购 Code4App，报价我们也能接受，就把这个站卖掉了。当时我们没有认真分析英文版的广告数据，结果把 .net 英文站也一并送给了买家。

回头看数据，反差很清楚：中文站那轮广告测试，累计 PV 大约 530 万，广告费只有 1250 美元；英文站从上线到易手，总流量约 480 万 PV，广告费却达到 4670 美元。
