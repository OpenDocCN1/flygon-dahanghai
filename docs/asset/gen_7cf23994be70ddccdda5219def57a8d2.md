# 二十三、不让人落单

有一种才干，会让人本能地留意团队里谁被晾在一边。它关心的不是小团体的热闹，而是整个队伍是否有人被遗忘、被排除，最好谁也别成为那个掉队的人。拥有这种特质的人，天然欢迎差异，愿意让不同背景、不同性格的人都有位置，不会把人分成高低几档，也期待团队像一幅拼图，由多种颜色和形状组成。他们反感抱团和私下划圈子，目光常落在边缘角色、弱势成员身上，并愿意主动递出援手。

但这份善意也有走偏的时候。因为太想让各类人都进来，团队里的声音可能变得又多又杂，分歧不容易收拢，摩擦和争论也会增加。又因为特别在意那个独来独往的人，容易急着把人拉进群体，却忘了对方也许并不需要这种热闹，独处正是他的舒适区。还有，对“小圈子”和“抱团”的反感一旦过头，言语和态度就可能带上批评甚至攻击，忽视了不同人本来就有不同的需求与相处方式。

当它被用对地方，就会变成团队的黏合剂。成员不必担心被冷落、被排斥，能真切感到自己被接住、被欢迎；团队也会因此更丰富，更多想法、视角、做法都有机会被听见和容纳。
