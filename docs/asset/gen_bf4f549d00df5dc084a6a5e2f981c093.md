# 推文视频：挑对玩法再动手

小说推文这个赛道，已经反复升级过好多轮，最直观的变化就体现在视频呈现方式上。

早期，图文类视频也具备不错的出爆款机会；后来，视频类内容更抓眼球，像游戏画面、解压素材、美食画面搭配小说配音，更容易激起讨论，也更能拉高爆款概率。

最近平台封号比较频繁，AI配音搭配素材的玩法风险有所上升。若还想继续走这条路，素材端建议优先选游戏类，比如蛋仔派对、地铁跑酷等，目前粉丝体量较大的游戏素材号大多还比较稳。若还有余力，真人出镜和AI绘画的视频形式原创度更高，也更容易存活。

当然，没有哪种玩法是绝对最优的，结合自身实际情况，挑适合自己的就行。

做出选择后，可以按本章给出的流程动手：先找视频素材，再完成配音与配乐，接着填充视频字幕，最后剪辑并导出。

作品发布后，别忘了及时在评论区互动或做引导，把用户引向小说平台，形成闭环。这部分内容会在「七、评论区维护与引导」中详细展开。

另外，本章「拓展工具：创作猫 APP」还介绍了一个新的视频创作工具——创作猫 APP，它可以结合AI绘画产出视频，希望能帮一部分创作者解决制作上的难题。

最后，祝你做出属于自己的爆款视频～
