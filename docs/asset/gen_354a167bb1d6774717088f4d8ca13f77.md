# 创业六年，从烧光5000万到月入十万，我悟到了这些

大家好，我是令狐峰，也是龙哥的小迷弟。特别开心能收到赚钱团队的邀请，今天想跟大家聊聊我连续创业六年的一些亲身感受。

先简单交代下背景。我大学一毕业，就跟另外两位校友一头扎进了高校领域的创业。当时野心不小，前五年基本是奔着“铺规模、冲上市”去的，打法也简单粗暴——拿投资、烧钱。前后烧了差不多5000万现金，绝大部分花在人力工资和各地分公司的开销上。可问题是，公司业绩始终没有迎来想象中的爆发。高校市场每年有800万用户的流失，让我意识到不管怎么努力，这个死结都解不开。加上团队内部对公司发展方向的分歧越来越大，长期996和高密度的周末会议让我身心俱疲。于是去年10月底，我放下了过去所有的头衔和光环，决心从零开始，做一家小公司。

说实话，一开始我并没有想清楚要做什么，属于典型的冲动创业，我不建议大家模仿。不过冲动归冲动，我给自己定了三条做业务的原则：高筑墙、广积粮、无边界。

先说“高筑墙”。简单说，就是要做那种做得越久、壁垒越高的项目，别人想抄也抄不走。如果一件事随便培训几个月就能上手，那市场很快会从蓝海打成红海。真正值得做的，是找到一个蓝海，然后持续往下深耕。

再说“广积粮”。核心就是赚钱，现金为王。我当时的想法很朴实：一个月能赚100万现金，不香吗？之所以这么想，是因为前一次创业总想着靠资本做大做强、敲钟走向人生巅峰，结果被社会狠狠教育了一顿。我这才认清自己，说到底就是个普通人，处于金字塔底端。所以别整天想着改变世界，先改变自己和身边的人，等真正赚到钱了，再谈改变世界也不迟。

最后是“无边界”。就是先不给自己定什么使命，凡是能赚钱又有趣的事情，都可以做。为什么不设边界？因为现在的市场机会太多了，选择的重要性很多时候大于努力，每年风口一个接一个，死死盯住一个方向反而容易错过。不要先设限，等遇到合适的项目再确定使命，公司的存活率会高很多。说白了就是：先生存，再发展。

去年11月20日，我的公司正式注册成立。

这里有个背景要先说一下。第一次创业时，我在公司同时管产品和技术，但运营不归我管。懂行的人都知道，产品和运营是分不开的，单靠产品差异想甩开竞争对手其实很难。因为长期缺少运营经验，我心里一直有个执念：要把“流量”这件事彻底搞明白。

我自己偏产品和技术，当时发现SEO其实是一种技术驱动的增长方式，于是花了两个半月，做了一套SEO系统。投入市场后，发现这个方向天花板很低，竞争又激烈，所以开始找新机会。不过那套系统每个月能带来2到4万的稳定利润，算是个不错的现金流。

4月份，我在朋友圈看到了龙哥盟的宣传，之前只是听说过但没深入了解。于是4月18号，在价格最便宜的时候加入了。加入的第二天，我就看到一篇《讲一个千万级流量的套利机会》，当时真的被震碎了世界观——原来流量还可以这么玩。我做了深刻的自我检讨，为什么自己没想到？最后得到的结论是：我缺少跨界思维。从那以后，我每天刷赚钱的内容成了习惯，也因此结识了不少圈友，比如擅长👸号和视频号引流的郭耀天，技术型引流选手痴海，还有很多热心帮我的朋友。

世界观被重塑后，我开始琢磨：能不能自己做一款和流量相关的工具？原因很简单，流量是每一家公司都绕不开的话题，小到街边门店，大到阿里这种巨头，全都有需求。粗算一下，至少有2000万人群对获取流量有需求，市场空间很大。加上疫情的影响，越来越多人意识到流量的重要性。而赚钱里的信息，通常有3到6个月的时间差，市面上还没有类似的工具，如果我们做出来，那就是第一家。

正好这时候，我上家公司的同事佩奇找到我，说准备离职，问我能不能一起干，做什么都行。佩奇当年是我面试进前公司的，当时我从十个产品经理里选中了他，又在一起共事过很长时间，对他的人品和能力都信得过。于是我们搭伙创业，他成了我的合伙人。

因为有产品和技术底子，产品设计加开发我一个人就能搞定，试错成本很低，这个方向值得一试。我们花了大概两个月，把工具做了出来，包含🛰️👸号SEO、百度+知乎、无吧主贴吧等引流模块。这款工具就是后来的「极客增长」。

起初我和佩奇没敢抱太高期望，觉得第一个月能卖30份会员就够了。结果我们把文章《我们做了款千万级的流量工具》发到龙哥盟星球后，一晚上就完成了原来一个月的KPI，第二天直接突破了100份。当时忍不住感慨：我们对龙哥的力量一无所知。

我和佩奇都是产品经理出身，特别看重用户口碑，口头禅一直是“一定要给会员十倍的价值回报”。到上周为止，工具会员卖了550份，星球会员卖了650份，9月和10月扣除成本后，每个月利润都超过10万，11月预计也能保持。

很多人好奇，这期间我们具体做了什么？我总结了7点。

第一，给所有帮助过我们的大佬，都送了工具一年的会员。比如郭耀天和另一位老师，各自帮我们推荐了10多个朋友购买，还有不少圈友也帮了忙，这里就不一一感谢了。

第二，不能只靠卖工具，工具早晚会被抄袭，得两条腿走路。我们在工具热度不错的时候，推出了“增长内参”知识星球。

第三，把用户当朋友。用户在群里提的问题，我们基本都会回答；不知道的，就去请教懂行的朋友，再回来答。群里互动氛围就这么被带起来了。

第四，鼓励大家互相链接加好友。陌生人通常不愿意在陌生群聊里说话，但如果群里有很多认识的人，聊的又都是最新的引流知识，大家自然愿意留下来。

第五，不定期发福利。9月中秋节，我们花了一万块，给200位群友送了月饼；整个10月，在群里发红包差不多发了近两万。

第六，前期以社群为核心，而不是以星球为核心。社群是集思广益的地方，你一言我一语，信息差就出来了。我们再把群里的优质内容沉淀到星球，让没时间爬楼的朋友也能看到精华。这里特别感谢一位朋友，每天帮我们整理群精华。

第七，龙哥的无私帮助。我们正好在杭州，见龙哥比较方便。见完面后，他可能觉得我们挺靠谱，很慷慨地帮我们背书，推荐了我的工具，真的非常感恩。

我们大量研究了龙哥盟的运营方法，作为国内Top1的社群，确实有太多值得学习的地方。我和佩奇基本上就是疯狂“抄”龙哥作业：各种运营技巧、真诚利他、超预期交付、对人性的理解，都拿过来用。

接下来聊聊我开公司的一些心得，先说说怎么在早期快速做对决策。

一个人做公司，拥有全部话语权，确实很爽。独裁的好处是速度快，但坏处是容易出错。所以我给自己定了一个简单的决策机制：用Swot分析法的简化版——只做利弊分析。想做一件事，我就把利弊分别列出来，看看哪边更重。

拿我们当时要不要做“增长内参”星球来举例。利处包括：有龙哥的作业可以抄，降低试错成本；能沉淀群精华，方便错过消息的人回看；能带动工具销售，增加收入；可能拿到知识星球的官方推荐流量；能单独成为一条业务线，加速团队成长；做越久壁垒越高；工具和星球打包卖，价格更好。弊端有：需要花将近一个月读1700篇引流文章、精选200篇打标签；会耽误我的开发时间；要额外开发PC端和小程序的文章分类系统；可能卖不出去；一年内有持续的运营和内容成本，但这点同时也是好事，能倒逼团队成长。

对比下来7利5弊，明显值得做。后来的结果也证明判断没错：不到一个月，光星球收入就超过了10万，还不算因为买了星球了解我们、最后又买工具的人。

很多时候合伙人因为观点不同吵架，甚至觉得对方是傻X，其实只是看事情的角度不一样。有人看到好处，有人看到风险，而这两者都是真实存在的。这时不是去说服对方“这件事没弊端”，而是把Swot分析认真做完，用数据说话。这个道理，是我在前公司开了无数次讨论会后悟出来的，虽然简单，但价值千金。很多巨头倒下，就是因为在关键决策上没有做好充分分析。比如优酷当年面临广告和会员业务的冲突时，轻率地砍掉了会员业务，最后丢掉了行业第一的位置。

再说说，早期怎么判断一件事能不能做成。

产品经理圈子里，大家最佩服的是张小龙，其实还有一位齐名的人物叫俞军，北俞军、南小龙。俞军老师有一条著名的产品经理军规，我一直牢牢记着：

产品真实价值 =（新产品价值 - 旧产品价值）- 用户迁移成本

这句话的意思是，判断一个产品有没有价值，不能只看你自己提供了什么，还要看市面上已有的产品，更要看用户从老产品迁移到你的产品要付出多大成本。

我们事后诸葛亮地分析一下，为什么老罗的“子弹短信”一出生就注定失败，而拼多多却能在阿里眼皮底下虎口夺食。

子弹短信想挑战🛰️的熟人社交，核心问题出在关系链迁移上——这几乎是不可能的。按公式拆解：子弹短信的价值是优化沟通细节、提升聊天效率；旧产品🛰️的价值是巨无霸级别的，不仅满足沟通，还覆盖了大量线上线下需求；而用户的迁移成本，是需要把整个熟人关系链搬过去，有时候少一个人都不行。迁移成本已经高到天际，价值差再大也填不平。当年马云和丁磊联手推“来往”，马爸爸亲自站台，照样无力回天。所以我认为，熟人社交领域目前就是一片死海。

再看拼多多。它的价值是让普通人用很便宜的价格买到大量商品；旧产品阿里有最全的SKU、支付系统和成熟的卖家体系；但拼多多把用户迁移成本降得非常低——通过拼团、砍一刀、领100块红包，引流到小程序和H5，购买时还能用🛰️支付。这样一来，用户从🛰️到拼多多的路径极其顺畅。拼多多确实做了消费分级，可光靠这一手还不够，真正让它起飞的是精准踩中了🛰️生态的红利，用“农村包围城市”的打法，拼命下沉抢阿里没有触及的用户。🛰️在网民里普及后，用户是靠着亲戚朋友的“砍一刀”更快接触拼多多，还是自己摸索去用淘宝？答案不言而喻。

早期我一直以为🛰️给了拼多多免死金牌，后来才知道，拼多多挖了大量🛰️团队的产品经理，这些人对🛰️生态的规则和漏洞了如指掌，知道怎么做才能既不违反引流规则，又能最大化利用流量。一个熟人甩来一条链接，说“是兄弟就来砍我”，你一点就进去了。迁移成本降到极致，又赶上🛰️支付崛起，打通了支付环节。真是时势造英雄。手握流量，就能兴风作浪。

那公司早期要不要找合伙人呢？我的看法是，别急着找。先看看找合伙人的利弊。

好处是：事情可以分工，省心一些；做决策有人能商量；也可能看到更多机会。但坏处也很明显：找到合适的人可能就要花很久；合伙人之间需要磨合，磨合期很费时间；早期合伙人股份占比往往很大，利益分得太随意，容易给以后埋雷；虽然决策有人讨论，但早期独裁效率反而更高，因为每个人的认知不同，说服人改变想法太难；人一多开销大，就会看不上赚小钱的事，一心只想着搞大事业，可前期对中小公司来说，“活着”才是第一位的，得从小钱赚起；还有，合伙人也有掉链子的可能，创业有木桶理论，一旦某块短板，业务可能就断了。

所以我的建议是：能不找就不找，后面把表现优秀的员工提升为合伙人也未尝不可，比如龙哥老师找的合伙人，就是从普通员工里一步步提拔起来的。

如果你还是拿不定主意，记住一句话：花钱容易，赚钱难。人越多，花钱速度越快，但赚钱速度不一定跟得上。如果赚钱速度能跟上，找合伙人没问题；如果还不确定，就先自己干。只要赚钱速度始终大于花钱速度，公司不死，坚持做有复利的事，总有柳暗花明的一天。

创业早期，尽量不要一上来就做那种需要三个人以上协同的事。人力成本太贵了，先从一两个人就能搞定的事情做起，自己拼一点，一个人完全能撑住。比如现在的知乎好物、TikTok训练营，一个人做得好，月入5万完全可能。等你赚到钱了，再招人，不香吗？这里强烈推荐龙哥老师的《裂变式创新》那篇文章，有时候人比事还重要。一流的战略配三流的执行，和三流的战略配一流的执行，马云会选后者。

最后，再分享一些零散的小心得。

关于面试。面试绝对是低投入、高产出的事。我给自己定了一条规矩：所有入职员工，我都要亲自面试，这是学张一鸣的。乔布斯说过，优秀的人和平庸的人差不是一两倍，而是五十倍。你花几个小时，可能就能找到一位跟你并肩工作几年的同事，这时间太值了。但创业早期也别太执着于招“最优秀”的人，毕竟优秀的人选择也多，招不到反而耽误业务进度。找到适合自己公司、匹配当前阶段的人，才是关键。

关于部门总监给员工赋能。我们常说“老人做新事，新人做老事”，本质上是老人把事情的逻辑跑通，做成SOP，降低新人的上手成本，也就是老人给新人赋能。赋能有多重要？按我目前的测试，一个优秀的、善于赋能的总监，至少能让员工效率提高50%。我们公司现在涉及销售、运营、客服、技术四个岗位，每个岗位在做什么、遇到了什么问题，我都会花时间去了解和追问，然后用我的经验帮他提高效率。

关于降低离职率。每个员工离职，都意味着公司在他身上的培养和积累全部付诸东流。员工离职的主要原因无非是：学不到东西、领导无能心累、工资不够、发展空间受限。而赋能恰好能解决这些问题：能学到东西，不会遇到困难只能干着急，公司发展好了待遇自然提升，空间也更大。目前我们公司成立一年，离职率为零。我在上一家公司时，我所在部门的离职率也是全公司最低的。人心齐，泰山移。

关于控制成本。对很多早期公司来说，省钱非常重要。以我们项目为例，如果不是我一个人同时干了产品、前端、后端、爬虫、测试这些活，而是每个岗位都招一个人，光是招齐人马可能就要一个月，公司支出会疯狂飙高，9月和10月很可能只能勉强保本。让一个人兼任多个岗位，而不是一个人只做一件事，对早期公司降低开销很有帮助。

关于碎片化时间。很多人觉得不可思议，一个人怎么可能干那么多事？我的秘诀就是充分利用碎片时间。吃饭、洗澡、上厕所时，我脑子里都在想公司的事，很多灵感和解决方案就是这么冒出来的。另外，要敢于拒绝一些不必要的事情。

关于认识自己。别总想着一下子改变世界，承认自己平庸很重要，这不是消极，而是脚踏实地。我们大多数人都在金字塔底端，比我做得好的有龙哥盟，比赚钱做得好的有知识星球，比知识星球做得好的有🛰️，比🛰️做得好的有苹果。认清自己的位置，一步一个脚印，向顶尖的人学习，不断前进就好。

关于抱紧贵人的大腿。据统计，人这一生大概只会遇到七次贵人，绝大多数时候我们都会因为认知和能力不够而错过。当认知到位后，一定要抓住每次机会。努力固然重要，但贵人一句话、一次随手相助，可能就会改变你的一生。而龙哥盟就是聚集了大量贵人的地方。提升认知和能力，准备好付出，抱紧赚钱的大腿，抱紧龙哥的大腿。

最后一条，锻炼自己的执行力。想得再多，不如干起来。没有执行力，前面说的全是空话。

以上就是我一个连续创业六年的老兵，最想跟大家分享的东西。希望对你有一点点启发。
