# 60赞案例：卡带买卖一天二三十单

今天聊一个在闲鱼上跑得不错的品类：Switch游戏卡带。这个产品在平台上的热度不低，日均能出20到30单。它确实有些门槛，但正因如此，做起来反而没那么难，竞争也少；把门道摸透，收益自然就出来了。

先看它的交易逻辑。我的判断是：这个链接一边卖货，一边也在收卡带。有玩家想出手，找到他后，他大概率会帮对方挂卖；等买家下单，再让原玩家直接发货。另一头，买家把游戏通关后，也可能把卡带再卖回给商家。

商品信息：名称Switch游戏卡带；售价235—280元；394人想要；累计售出1832件；最近3天卖出65件；每单利润大约9到20元；店铺叫藤原的店。简评：不同卡带的利润并不固定，这个类目的长期可持续性不错。
