## 3.2.6 从日报 Skill 晋级为日报 Agent（进阶选项）

做到这个节点，你手上的其实还只是一个「日报 Skill」：你塞给它内容，它吐给你结构化分析。可是每次都要动手复制结果，那份重复劳动最后还是压在你肩上。

我们前面讲过两者的分野：Skill 意味着"这件事能做"，Agent 才意味着"这件事每天自动做完"。

如果给分析流程接上"自动存档"，链条就会从 Skill 一跃成为最简 Agent：输入内容 → 自行解析 → 自动写入指定位置 → 给你一句回执。

接下来只需让 Codex 把自动保存嫁接到 skill 尾部。存在哪里没有标准答案，选一个你日常必定会打开的入口就好：

• 桌面上的日报.txt：最省心的兜底方案，先跑起来再说
• 飞书文档 / Notion：适合爱记笔记、经常复盘的朋友
• Obsidian：适合已有本地知识库的人，可以直接和笔记网络联动
• 桌面 .md 文件 + 本地 HTML 页面：适合坚持纯本地、不想登录任何平台的人（下方演示走的就是这条路）

## 3.3 重点回顾

走到这里，一套紧凑而完整的日报 Agent 已经立在眼前：对话框输入 → 自动分析 → 自动落入你每天都会打开的地方。

回溯一下这条链路是如何成型的：

1. 拆解需求：让 AI 反过来追问，把模糊的构想聊到透亮
2. 收束 Demo：把发散对话钉成一张清晰的施工图
3. 固化 Skill：把分析动作沉淀成可重复调用的能力
4. 接上自动存储：让 Skill 脱胎为 Agent

跑通之后，也建议大家顺着自己的需要继续延展。各人的日报内容、工作节奏和展示口味都不一样，这个 Agent 理应长成你的模样，而不是书本的克隆体。

不妨从这些方向试起：

• 更换存储形态：从 html 切换为飞书 / Obsidian，对比哪种用着最惬意
• 调整分析口径：请它顺带标出"今日卡点""明日优先级""本周累计推进"
• 接入更多来源：比如自动抓取🛰️消息、会议录音转写文本
• 编排更长的链路：日报 → 周报 → 月度复盘，让 AI 替你层层汇总

## 4. 小结与作业

### 4.1 总结

执行能力说白了，就是把重复的工作托管给 AI，让一个人也能顶一支部队。

动作总共四个：启动提问 → 梳理维度 → 收敛 Demo → 生成 Agent。

这几步背后真正要练的关键内功，是需求定义能力——这才是重中之重。

做 Agent 并非技术活。你的价值不在敲代码，而是学会翻转提问权：让 AI 像顾问一样向你发问，把解决什么问题、先推进哪一段、输入输出各是什么这几件事聊得明明白白。方向跑偏了，AI 写得再快也只是白费力气。

祝贺你！走到这里，你拿到的不仅是一款日报 Agent，更是一套跟 AI 对话、把需求聊清楚并落地成 Agent 的完整方法，日后可以随时迁移到任何新任务上。

掌握这项底层能力后，第三章的"表达能力"（如自动生成文案）和第四章的"积累能力"（如搭建知识库），也都能够被打包成你的专属技能，再组合成更耐打的 Agent。到那一刻，你便不再是内容的操练者，而是工作流的总设计师。

**第一步：锁定场景**

回想日常工作里最缠人、最重复的那件事，就拿它下手。

头脑一片空白的话，下面几个模板可以参考：

• 文风转写 Agent：把别人的好文改写成你的味道
• 会议摘要 Agent：把杂乱会议记录收拾成结构化纪要
• 客户追踪 Agent：把聊天窗口里的信息浓缩成跟进记录
• 统计报表 Agent：把零散的数字汇编成固定版式的报告

**第二步：拆解需求**

唤出 Codex，沿用第二部分的方法，请 AI 连环发问，直到你彻底想明白自己要什么。

**第三步：收束 + 固化**

请 AI 把交流成果收敛成最小 Demo，再固化成一套可复用的 skill。

**第四步：验证**

拿一段你自己的真实输入试跑一次，确认输出与预期是否吻合。

**完成标准：**

1. 你能讲明白这个 Agent 要解决什么痛点
2. 你握有一份收敛妥当的最小 Demo 定义
3. 你沉淀出了一个能反复利用的 skill
4. 你用真实输入完整跑通过至少一轮
