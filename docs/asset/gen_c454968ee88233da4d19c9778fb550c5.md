# 平台三：小红书素材怎么批量抓

安装包获取入口：[`pan.baidu.com/s/16SuOCxzf9SFMMqUsBTyvbg?pwd=nacu`](https://pan.baidu.com/s/16SuOCxzf9SFMMqUsBTyvbg?pwd=nacu)

先提醒一个硬性条件：微信版本别乱用。这套采集并不是脱离微信单独跑，而是借微信客户端里的小红书小程序接口来取数据，所以软件必须和微信配合使用。再加上微信小程序后续升级，新版微信反而拿不到采集所需参数，因此要换成安装包里附带的 3.4.5.27 版微信。

[PRE1]

它可能会改动浏览器的代理设置。要是浏览器上网出现异常，就去确认代理服务器相关配置，并把它关闭。

2）软件配置

• 在“关于软件”里选择微信账号扫码登录。

• AuthorId 设置：这一步是让软件和微信客户端中小红书小程序里的接口对应起来。先点“基本操作”，再点 AuthorId 这一行右侧的“抓取”。

[PRE3]

接着打开微信客户端，从小程序面板进入，点击放大镜搜索图标：

[PRE4]

输入关键词“小红书 app”，然后点进去：

[PRE5]

看到下面这个提示，就说明配置成功了：

[PRE6]

• 用户 ID 号设置：只有需要采集某个指定小红书账号时才填这一项；如果只采单条链接，或者按关键词搜索内容，可以直接跳过。

操作时先打开小红书 APP，在账号主页右上角点“...”，取得要采集账号的主页链接。获取方式和前面拿抖音账号主页链接一样。

示例：

[`www.xiaohongshu.com/user/profile/`](https://www.xiaohongshu.com/user/profile/)5db58c4a0000000001006eb7?xhsshare=CopyLink&appuid=639cdccc000000002501cd79&apptime=1682491137

问号前那一段就是用户 ID。把它填进软件后点“搜索”，就能把这个用户全部小红书笔记、图片和视频导出并采集。
