# 5.10.2 案例二：BAYC，猿猴头像如何长成超级IP

BAYC全称Bored Ape Yacht Club，中文常被简称为“无聊猿”。这个系列的操盘公司Yuga Labs，目前称得上是NFT行业最头部的力量；之前出场的CryptoPunks，也是被该公司纳入旗下的。

2017年4月上线以太坊时，该系列共放出1万只猿猴头像。每一只的外观由7类特征随机组合而成，组合结果决定了各自的稀有度。

[PRE0]

这批头像很快超越普通数字藏品的范畴。一个名为“无聊猿游艇俱乐部”的大型社群由此诞生，NFT便成了俱乐部会员的VIP钥匙。

最直观的推手是明星买家：库里曾为一只身着粗花呢西装的猿猴支付55ETH，折合约18万美元；电视主持人吉米·法伦去年11月买下一只戴心形墨镜、穿条纹T恤的猿猴，价格约22万美元；说唱歌手Eminem近期大约花费46万美元，收藏了一只与自己神态相近的猿猴。此外，比伯、麦当娜、内马尔、周杰伦、林俊杰、余文乐、陈柏霖、吴建豪等艺人同样是该系列的持有者。

[PRE1]

长期持有BAYC，还意味着持续获得新权益。2022年3月，项目方启动APE代币发行，一问世就有数十亿美元流通市值；凡是持有无聊猿的用户，都在发币时收到了可售出的空投。有位玩家笑称，这体验就像天降保时捷。

品牌合作同样值得一说：adidas拿它做联名，打造通往元宇宙的钥匙；团队还在尝试影视、综艺、音乐与游戏等新媒介；环球音乐组建了Kingship虚拟组合，成员是一只变异猿与三只无聊猿角色。许多新项目上线时，也会直接邀请BAYC持有者优先参与，相当于发了一张VIP名单入场券。

今年4月，李宁与BAYC联手，用120ETH（约240万元人民币）拿下编号4102的无聊猿，之后围绕它展开产品和营销动作，给IP借势打开了新思路。NFT的想象空间，显然不只是一张像素图片。

[PRE2]

从价格轨迹看，2021年公开发售时，每只无聊猿的定价为0.08ETH，约190美元；如今系列地板价约80ETH，市值涨幅超过500倍。

它因何火爆？核心在于社区共识。不少用户将猿猴头像当作社交账号标识，看到同款头像的人会立刻相认，互相视为“家人”。满屏猴子头像因此成为一种圈层信号，持有本身也成了身份与品味的象征，同类人群聚合后更容易擦出火花。

[PRE3]

BAYC内部按不同属性划分出大量频道，玩家还会在外部搭建私人社群。一个足够热闹、持续生长的社区，正是加密世界用户最渴望的东西，而该系列几乎把这种理想社区落到了实处。

最特殊的是版权归属：项目方把BAYC作品的授权完全交给持有者。他们可以基于自己的猿猴创作周边产品，如艺术画作、服装、扑克牌，销售收入全部归自己，不需要给项目方分成。
