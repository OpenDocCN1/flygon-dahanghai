# 公众号变现全流程：结算、带货、提现与素材库复盘

## 第四，结算环节不用慌

先聊最让人关心的钱款结算。这里走的是官方结算通道，流量主的收入有保障，佣金到账效率也高，基本不需要额外担心。用户下单、确认收货、结算带货佣金，创作者在后台就能看到佣金数据，后续由官方打款，整个链路在后台都有记录。

具体操作可以按这个顺序来：第一步，注册公众号并入驻平台；第二步，把粉丝量做到500以上，确认好财务结算资料，再提交流量主开通申请；第三步，等待审核，周期一般是3到5个工作日，材料正常提交的话，通常当天就能通过。流量主开通后，接着开通返佣商品广告，进入推广商品，在文章里植入返佣商品广告，发布并分享文章，就能赚取收益。

公众号带货和头条带货的逻辑相似：文章里出现商品关键词，就把相关商品插进去。

[PRE0]

单篇推文最多可以插入10款商品。读者阅读时点击商品卡片，会直达小程序，一键下单购买；产生实际成交后，流量主就能拿到对应的销售分成。

另外，不管什么时候带货，也不管带的是书、日用品还是水果，都可以套用这个模板：第一部分用故事切入，第二部分把故事过渡到话题，第三部分介绍商品内容，第四部分引导下单。具体带货文案怎么写，可以去看这篇高手分享：3月6日《如何在公众号带货》@徐胖子。

# 4.2.2 打赏变现（次要）

开通流量主之后，记得先挂着原创群发3篇文章，之后就能获得打赏权限。账号名字、头像和打赏的名字、头像，尽量保持一致，这样人设看起来更真实。

打赏变现往往集中在IP属性强、人设过硬的账号里，这类文章下面可能出现高额打赏。所以对我们来说，它只是一个变现渠道，并不是主流方式。不过开通之后，偶尔也能加个鸡腿。

[PRE3]

# 4.3 公众号提现

公众号不需要自己手动提现。每个月的收益会自动打到开通流量主时绑定的银行卡里，每月打两次，分别是1号和15号，这个月打上个月的。

就算收益只有一分钱，也会准时到账。每月1号和15号可以进手机银行查看，偶尔会有延迟，但不会不到账。到账金额是税后金额，已经扣了20%的个税。

# 5.1 如何搭建素材库，提升写作效率

做自媒体的都知道，想日更，最大的问题之一就是：天天写，哪里来那么多素材？没有素材库的伙伴，写一篇故事已经要绞尽脑汁想半天，连续更新一个月就更难了。

素材库不仅能提供灵感来源，更能大大提升写作效率。接下来就学习素材库的来源和搭建方法。

# 5.1.1 素材来源：职场类@枫宇翔

职场素材的来源很多，这里最推荐脉脉。脉脉是面向职场的APP，里面有大量职场人吐槽、分享，很容易引起共鸣，多刷刷很有用。

比如下面这个例子：入职SHEIN后，终于知道为什么大家都劝退。这个标题一下就能抓住人。除了职场人吐槽，还有一些喜欢搞氛围的人在里面发争议话题，讨论往往很激烈。

[PRE5]

除了脉脉，BOSS直聘等各大招聘APP的评论区，豆瓣、知乎、微头条等平台也都有职场内容，全都是素材库。抖音、快手等短视频平台上，职场高赞视频的评论区也藏着一大堆素材。公众号平台本身也有大量相关信息，直接搜“职场”关键词就能找到。

到底要不要用某个素材，看点赞数、评论数等数据就行。数据好就发；即使你自己对素材没感觉，也要发。要相信数据，这些都是经过市场验证的。

[PRE6]

# 5.1.2 素材来源：热点类

热点素材无非来自那几个热榜：微博热榜、今日头条热榜、知乎热榜等。这些地方往往有很多可选的选题。

[PRE7]

[PRE8]

但另一方面，这些热榜往往经过粉饰，所以也要留个心眼，认真想想大众到底关心什么。很多知乎爆款回答明明有流量，却和热榜没什么缘分。这类内容往往比热榜内容更值得关注，写出来也更容易爆。因为这些内容是一个赞一个赞票选出来的，就算没有热榜加持，还有那么多人关注，证明大家就是想看。我们要选的，就是这种刀刀见血的好内容。

[PRE9]

# 5.1.3 素材来源：剧评类

剧评的优点在于，完全不用担心素材来源。只需要做三个准备：

1）看剧时，把感兴趣的地方或打动你的话截图，添加到素材库；
2）分析电视剧的高光时刻；
3）把电视剧与原著进行对比。很多时候两者不一样，可以把差距和狗血的地方写出来。

[PRE10]

就拿《知否》或《甄嬛传》举例。这两部剧口碑和热度都不错，无论是盛祖母对明兰的敦敦教导，还是明兰对生活的有感而发，都能带来很多写点。

比如《知否》中淑兰和离的高光时刻，可以写的文章就能达到三篇甚至更多。

先给没看过剧的朋友介绍一下背景：淑兰出生在经商的盛家大房，带着丰厚嫁妆嫁给穷秀才孙志高。婚后婆婆一家花着她的嫁妆，还各种磋磨她。最终在孙秀才要带风尘女子回家做妾时，盛家大房大怒，这才有了和离的一幕。

那么，三个方向可以从哪里展开？

①淑兰能顺利和离的真相。古代男权社会里，孙秀才没有太过分的行为，淑兰和离完全不占优势。可以深挖淑兰和离的关键：可以是娘家对她的维护，不在乎名声受损，只要淑兰脱离苦海；也可以从淑兰引申到女人自己立不起来的后果。毕竟淑兰有丰厚嫁妆，养着孙家一家，还被磋磨成老妪般，只能说她自己太懦弱。

②孙秀才为什么敢与盛家叫板，最根本的原因是什么？可以从经商的盛家不如读书人孙家地位高来写；另外孙家什么都没有，真要闹翻，光脚的不怕穿鞋的；还有两家闹翻不只是两个家庭，而是两个家族交恶。家族为上的社会里，盛家就算与孙家和离，也要顾及孙家家族。

③明兰帮助淑兰和离后，祖母的一番话暗示她与小公爷的结局。这个可以写的点更多。齐衡与盛明兰私下相爱，只是注定无法在一起。首先是家世差距：齐家是国公爷，齐衡又是独子，承载着母亲平宁郡主的希望；盛家只是小小的五品，盛明兰又只是庶女。其次，齐衡虽然喜欢盛明兰，但没有魄力为这段感情努力争取，不敢忤逆母亲平宁郡主。最后，平宁郡主看不上盛明兰，她想对付盛明兰，手段有的是。

你看，电视剧的一个高光时刻就能写出三篇甚至更多文章。对于爱看电视剧的同胞来说，素材是不是信手拈来？

第二类来源是头条新闻热榜及地方热榜。

# 5.1.5 素材来源：历史类

历史素材的来源也很容易。大家从小就学这门课程，肯定能找到很多新奇有趣的故事。从帝王将相到平民百姓，从将军出征到女子出嫁，可以写的地方太多了。况且人们喜欢听故事，用一个惊险、紧张、圆满、愤怒或搞笑的故事吸引大家看，是很好的方向。

素材来源也是多方面的，比如看过的电影电视剧、听过的历史节目《百家讲坛》、一些历史大V的人物讲解。甚至看到某个历史人物素材时，可以深挖他以后的命运，这也是一种方向：人们只看到他在历史中的一瞬间，我们需要把他的整个人生经历呈现出来。

[PRE17]

# 5.1.6 素材来源：情感类

情感素材来源有很多途径：比如生活中自己身边发生的，亲朋好友、邻居身上的事；还有网络上的知乎、抖音、百度、头条等平台。

当你在生活中遇到或听到一些能触动自己的事情或话语；在网上到处逛时，看到一些有意思的事情，随手记下来。累积到一定读者后，可以设置自动留言，留下微信号，让读者来倾诉，从读者身上获取素材。平日看书读报时遇到的好词好句、新奇故事，以及影视剧、小说里的情节等，也都是素材。总之，哪里都有宝藏，难的是怎么发现。

如果不是亲戚说的，我听到这种故事基本不会信。一直以为这种狗血情节只会在电视剧、小说或新闻里出现，没想到离自己这么近。于是我突然想到，每次看抖音时，一些情感纠纷新闻下面就会有网友评论，讲自己亲身经历或身边的故事。我就想着，能不能把这些故事拿来用？这就是第二个来源。

2）短视频平台的情感故事和评论区故事

# 5.1.7 搭建素材库

当你有了很多素材来源后，就有了源源不断的素材。这个时候就可以把这些素材分门别类整理成一份素材库。后期写作时，只需要在素材库里挑选合适的素材进行整合写作即可。

下面以情感类素材库举例。先给大家几个对标号：写故事的刘小念、陈若鱼、猪小浅。她们都是写故事的，写法略有不同，大家可以像她们那样写，也可以从她们的号中获取很多故事素材、爆款标题。

在「3.2.6 情感类：爆文模板」里，会讲情感类的正文模板：一个故事=标题+主人公+故事的主干+结局。

展开来说就是：一个故事=标题+主人公+故事的主干（包含梦想或目标，挫折、阻碍或意外，和惊喜或反转）+结局。

拆开来说就是：一个故事=谁～想做什么事～为什么做或怎么做～做的过程遇到了什么～结果怎么样。

接下来，先想好要写一个什么主题的故事，再把标题写好，然后围绕主题，把故事顺着写下去。

主人公：我是谁，多少岁，来自哪里，做什么的……就是简单介绍一下主人公的基本情况。
