# 第4.3节 售后处理：摆正中间人位置

做售后其实只要牢记一个身份定位就够了——咱们是桥梁，是中间人，心态摆正就行。

所以遇到问题，没必要在闲鱼上跟买家来回拉扯。正确的做法是：让买家把快递面单和损坏的商品拍在同一张照片里发过来。这一步有两个作用，一是确认这东西确实是咱们店里卖出去的，二是后面找上家沟通时手里有凭据。拿到照片后直接转给商家，商家给出什么处理方案，咱们原样传达给买家；买家回复了什么，再转回去给商家。整个流程就这么简单，不需要自己额外发挥。

另外，平台购物一般自带运费险。闲鱼买家如果是因为自己的原因要退货，运费由他们自己出。换个角度想，这运费险最后反倒成了咱们的额外收益。如果是质量问题，那就按上面说的，把消息转给商家去处理就行。

个人经验之谈：能少一桩事就少一桩事，在利润空间内协商解决，该赔就赔，把省下来的时间和精力投到拉高利润上更划算。
