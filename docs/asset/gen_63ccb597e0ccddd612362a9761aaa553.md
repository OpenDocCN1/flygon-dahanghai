3.4 终端（Terminal）到底是什么

终端可以看作电脑最基础的文字命令窗口，靠敲字与系统交流。日常我们习惯用鼠标打开软件，而开发者更常通过终端创建目录、安装程序、运行项目。它比图形界面出现得更早，是进入系统底层的入口。

学习 Claude Code 时，终端就是你与 AI 交互的场地。Claude Code 属于命令行工具，没有可视化面板，所以安装、启动、登录乃至对话，都要在终端里输入命令完成。可以把终端想成“AI 的传声通道”：你在这里下指令，它就在这里回应。

各系统都会自带终端：macOS 有 Terminal，Windows 有 PowerShell 或 CMD。掌握少量基础命令，就能开始操控编程世界。

**终端（Terminal）**

本质是命令行界面（Command Line Interface，简称 CLI），用于直接和操作系统交互。通过输入命令，可以完成：

- 新建文件夹
- 启动服务器
- 安装软件
- 查看系统信息

它不靠鼠标点击图形界面（GUI），而是用文字命令驱动系统。

| --- | --- |
| macOS | Terminal、iTerm2、Warp |
| Windows | PowerShell、Windows Terminal、CMD |
| Linux | GNOME Terminal、Konsole、Alacritty |

3.5 命令行（Command Line）究竟指什么

命令行不是某个软件，而是一种操作方式：用文字告诉电脑要做什么。比如输入 node -v 查看 Node.js 版本，输入 cd project 进入某个文件夹。

它的核心优势是精准、快速、可自动化，尤其适合开发环境里的批量操作。

Claude Code 的所有操作都建立在命令行之上：安装、登录、调用 AI、运行项目，甚至创建文件，都离不开命令行。刚接触时可能觉得有点“原始”，但掌握几个常用命令后，你会发现它比图形界面更自由、更高效。

换句话说，终端相当于房间，命令行就是你在房间里说出的语句。学会这门“语言”，Claude Code 才能听懂你的请求。

3.6 GitHub 到底是什么

GitHub 是基于 Git 的云端代码仓库平台，也是全球最大的开发者社区。Git 可以理解为本地保存系统，GitHub 则是放在云端的备份库。

它不仅能远程存代码，还能让全球开发者协作、开源和复用。Claude Code 也能直接读取 GitHub 上的仓库内容，比如“分析一个开源项目结构”“帮我修改某个仓库里的文件”。

使用 Claude Code 时，如果你想保存、共享或部署代码，GitHub 是更安全、更标准的选择。如果把 Git 比作随身笔记本，GitHub 就是云端保险箱。

详细内容可看：https://docs.github.com/zh

**Git 与 GitHub 的关系**

可以这样理解：Git 是一套工具，GitHub 是一个网站。

Git 是本地操作的版本控制引擎；GitHub 是把代码放到云端、与他人协作的仓库平台。Claude Code 既能在本地配合 Git，也能和 GitHub 云端仓库交互。

它们类似 Word 和百度网盘：一个负责编辑，一个负责存放；两者结合，才构成现代开发的完整工作流。

3.7 Node.js 是什么角色

Node.js 是让电脑运行 JavaScript 代码的环境。过去 JavaScript 主要跑在浏览器里，Node.js 把它带到电脑上，使 JavaScript 能用于服务器、桌面程序、命令行工具等。

Claude Code 是用 Node.js 构建、需要在命令行中运行的开发工具。如果电脑没装 Node.js，Claude Code 就会像缺少发动机的车辆，无法启动。

[PRE4]

💡Claude Code 的运行可以看成一场配合演出：终端提供舞台，命令行是你发出的指令；Node.js 是发动机，为 Claude Code 提供动力；Claude Code 是登台的执行者，负责理解需求、生成和修改代码；VS Code 是后台工作间，用来查看、编辑和测试代码；Git / GitHub 负责记录，保存每次修改，让项目可追溯、可协作；MiniMax2.5/GLM 5 / Claude 模型则提供思考与编程能力。

把整条链路串起来：你在终端发出命令 → Claude Code 依托 Node.js 启动 → 调用 AI 模型产出代码 → 在 VS Code 中查看和调整 → 最后交给 Git/GitHub 存档与协作。

0. 安装前先补课：电脑基础知识

这一节主要讲一些电脑常识，比如怎样识别自己电脑的 CPU 型号，以及操作系统的基本概念。

**电脑分类**

目前电脑大致分为家用电脑和服务器。家用电脑就是常用的笔记本、家里的台式机，属于个人使用，也包括公司里用的笔记本。服务器通常放在机房机柜里，一般人看不到；做过运维、进过机房的人会比较熟悉。服务器需要 24 小时工作，对能耗和稳定性要求很高。

**操作系统**

有了电脑硬件后，要安装🛰️、🐧、浏览器等日常应用。硬件和这些应用之间还有一层软件，通常叫操作系统。

操作系统分类很多：日常用得最多的是 Windows，还有 Mac 苹果系统；服务器上则大多使用 Linux。

一般来说，买的台式机、联想电脑基本是 Windows 系统；苹果电脑是 macOS；如果装的是虚拟机，比如 Ubuntu，以及服务器上常见的 SUSE，都属于 Linux 系统。

**Linux 系统**

Linux 是一个很复杂的分支，源于 UNIX。UNIX 是商业收费系统，Linux 的作者 Linus Torvalds 出于开源精神写了 Linux。我们常说的 Linux 通常只是 Linux 内核，可以理解成基础 SDK 工具。为了支撑上层的🛰️、🐧 等软件，还需要图形化界面等组件，于是有了 Ubuntu、CentOS、Red Hat Linux 等分支。

**CPU**

这里要重点说的是电脑硬件里的“大脑”——CPU。CPU 属于硬件，发展过程中有两大指令类型：x86 和 ARM。上层软件需要先与操作系统配合，再和底层 CPU 打交道。因为 CPU 负责计算和指挥，所以 CPU 指令类型也会影响下载的软件类型。

常见的 Intel 处理器属于 x86 指令类型，这类 CPU 下载的安装包基本是 x86_64 类型。现在 macOS 使用的 M 芯片属于 ARM 指令系列，鸿蒙操作系统使用的也是 ARM 芯片，因此需要下载 ARM 安装包。

怎么确定自己的 CPU 类型？

💡辨别电脑 CPU 是 ARM 芯片还是 X86_64 芯片很重要，会涉及安装包选择。如果这里没看懂也不用担心，后面需要选择安装包类型时，再回到这一小节确认即可。

1.1.1 Windows 版本

💡Q：为什么需要安装 Git？

A：

1. Claude Code 在所有系统上都需要识别、管理、保存代码项目的版本记录，这项能力由 Git 提供。Windows 默认没有 Git，必须手动安装，否则 Claude Code 无法识别项目的版本信息。
2. 后面代码的存档管理也需要 Git，它是开发基础环境必备。有了 Git，Claude Code 才能安全、完整地理解并管理你的项目。

PS：注意，装 Git 时按默认路径安装，不要自行改安装目录，一旦改了，后面可能报错。
