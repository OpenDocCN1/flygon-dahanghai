# 6.4.1.2 认识 Axie：玩赚一体的宠物链游

按官方说法，Axie 是一款链游：玩家拥有属于自己的宠物 NFT，这些宠物能够养成、繁育、对战，甚至用来建立王国；游戏社区保持开放，并采用 Play-to-Earn 的经济机制。

它的使命，是围绕社区与玩家自有资产，打造出有趣的游戏体验；愿景则更宏大——让这里成长为全球玩家都愿意来娱乐、盈利和生活的数字国家。

用大家熟悉的产品打比方，它有点像 QQ 宠物和宝可梦游戏的结合体。

商业闭环也不难理解：想参与，先付费购入宠物；随后宠物能在游戏里像打工一样，替你持续产出收益。

再细看治理代币模型：整个系统由游戏、玩家、社区和代币持有者组成，可以分别类比为国家、百姓、政治家和资本家。

“政府”负责制定规则：入场门票是先花代币买 3 只宠物；繁育后代需要付费；在体系内做买卖则要缴纳 4.25% 的交易税。代币用于奖励居民在体系内付出劳动；资本方通过锁仓赚取代币利息，从而推高代币价格，形成正向价值循环。

项目还特别强调：资产所有权归居民，社区治理权也归居民。
