# 亚马逊FBM：不囤货的精品自发货打法

过去很长一段时间，我主要做FBA精品模式，也很认可这套打法。想把亚马逊做好，FBA依然是稳妥选项：订单发货、售后客服等琐事交给平台，卖家把精力集中在选品和运营上。

但今天不聊FBA，聊**FBM自发货精品模式**。

原因很直接：FBM对新手更友好，门槛低，不用一开始就把大批库存压到亚马逊仓库，启动资金少，试错风险也相对小。很多人一听FBM就想到铺货、无脑上架、又累又不赚钱，觉得早被淘汰了。可在我看来，FBA和FBM只是两种不同的配送方式，真正决定成败的是产品。你的产品能不能解决消费者更深层的需求，能不能在同类竞品里实现价值超越，让买家愿意忽略物流时效，排除万难也要买，这才是重点。

我一直想传递一个观点：把平台意识放低，把用户视角抬高。多花心思感知消费者真正需要什么，买家自然能感受到产品的温度。那什么叫更深层的需求？可以借用冰山理论：露在水面上的显性需求，大多数人都看得见；价值超越，则要继续往下探，找到藏在水下的隐形需求。它不容易被发现，可一旦你解决了它，买家会有一种“原来我要的是这个”的恍然。汽车发明前，人们说自己想要一匹更快的马，但本质不是马，是“快”。产品迭代不能只靠收集显性反馈，得抓住更底层的需求。

每次分享，我也喜欢把平时学到的思维融进去，用输出倒逼输入。只有把学到的东西讲给别人听，才算真正掌握，这也是我愿意分享的原因。下面不会事无巨细地写，毕竟这套方法我还在用来赚钱，只聊一些思维碎片和重点，能整合的人自然会深入研究。

**1.关于店铺问题**

店铺是最基础的一环。我当时只想测试FBM自发货精品模式这套方法论是否可行，权衡自己注册和直接购买店铺的时间成本后，选择了买店铺，毕竟只是拿来当小号试水。这两个店铺找号商购买，成本约2800元/个，已经过了视频认证和明信片地址认证。但我不鼓励买店铺，里面的坑太多，不可控因素很难规避。除非你经验足够、能接受各种风险，否则还是老老实实注册。注册并不难，社群里不少人分享过，可以搜一搜。我只是为了省时间才这么做，也衡量过风险；新手完全不懂就去买，很可能成为最大的韭菜。最坏的情况是店铺和资金都拿不回来，如果你能坦然接受，那再去尝试。相关资源千万别找我，我不希望和社群里任何人产生利益交集，只是单纯分享内容。

**2.如何选品才能更快的出单**

a. 这种模式有前提：做垂直细分类目。先确定目标用户群体是谁，再选择和打造产品，满足这部分人的需求，进行错位竞争，做到价值超越。

b. FBM要充分利用自发货的好处：不用入仓囤货。我们正好借这个优势和FBA卖家竞争。要尽可能细分，把用户需求切到极致。可以从颜色、尺寸、场景、功能、型号、用途等维度细分；单款产品尽量多做变体，全部绑在同一个父体下，几十个甚至上百个子体都可以。这样能覆盖用户大部分需求，每个子体也能在长尾细分关键词里最匹配真实需求，转化率自然更高。

c. 所有变体绑在一起后，review共享，出单后整条链接权重也能累加。新品期可以快速冲排名，关键词排名越高，后期自然流量越多。

d. FBA入仓模式如果也这么做，子变体太多就意味着大量库存，风险大、效率也不高。FBM不用囤货，变体再多也没关系。只要FBM卖家用好这一点，就算和FBA卖家竞争，也很有机会。单个子变体出单可能不多，但整条链接所有变体加起来，单量会很可观，排名也会更理想。

e. 在细分领域满足一部分用户的深层需求，把调研过的需求做极致细分，再以变体形式聚合。子变体在垂直细分领域点击率更高，所有子变体聚合到同一个详情页，买家进来后能闭环，转化率也会提升。

核心思维：基础爆款（从亚马逊平台上找）**+**热点爆款元素（调研背后用户群体的需求）**+**极致细分多变体聚合。

基础爆款可以直接去亚马逊前台找。先确定想做的类目，优先选那些容易把热点元素附加到基础款上的产品，只要能印图案，基本都可以挑来试。还是用NBA球队元素的杯子举例：你在榜单上发现某种杯子很畅销，这就是基础爆款；但不要直接照抄做一模一样的产品，否则很可能一单都卖不出。畅销榜上的基础款往往价格压得很低、评论很多，小卖家拼不过，何况你还是FBM自发货。这时要在基础爆款上附加热点爆款元素。热点元素也不是随便印个图案，我一般先确定目标用户群体，再挑爆款产品，所以调研要前置。可以看亚马逊QA和review，也可以逛社交媒体、国外论坛，先弄清这群用户喜欢什么，再匹配基础爆款，把用户喜欢的元素加上去。比如你一直研究运动爱好者，就可以把篮球、足球、棒球、橄榄球等运动元素加到杯子上。最后一步是做极致细分：用关键词调研工具分析，发现篮球里NBA热度最高、搜索流量最大，那就可以用NBA球队来细分。PS：这里只是举例，不是让大家做这款产品，请不要误解，底层逻辑相同。选品有两个重点：第一，基础爆款确定后，同步查专利和侵权风险，很多热卖产品可能有专利；第二，热点爆款元素确定后，也要查知识产权隐患，提前排除。

**3.新手产品上架问题**

关键提醒：《卖家大学》！《卖家大学》！《卖家大学》！如果真不懂，就去看亚马逊后台的卖家大学。它基本是手把手免费教学，比市面上很多培训机构都强。花点时间耐心看，跟着步骤操作，能解决90%的问题；剩下10%再去问搜索引擎。

**4.listing页面如何打造**

虽然是FBM自发货，每个产品的listing页面也要按精品来打造。图片要把卖点呈现出来，文案可以精简，但一定要突出卖点。

a.图片。挑完基础爆款后，就可以去找货源，阿里巴巴或拼多多都可以。找到同款后私聊店主，表明自己是做亚马逊的，加微信要产品原图。多问几家，很多做批发的人愿意合作，这就看沟通能力。这几年跨境热度高，批发商也知道亚马逊订单量大，通常愿意给图。拿到原图后做微调：做美国站就把图片风格调成欧美风，文案换成英文，会基础PS基本能搞定，最好模仿同类优秀产品的图片风格。最后把每个子变体对应的爆款元素P到产品合适位置。

b.标题、卖点、描述。这里涉及运营。可以用第三方软件或竞品页面，通过JS、卖家精灵反查对手的核心出单关键词，再把爆款元素词埋进文案。每个变体的长尾关键词都要调研出来，图片和文案围绕这个长尾词布局。这样在细分领域里，买家一搜这个词，你的产品匹配度最高。这一步对运营能力有一点要求。

c.每个子变体的listing页面，都要按调研过的长尾关键词优化。务必保证买家搜长尾词时，这个子变体是页面上最符合需求的产品。图片、标题、卖点、描述都要体现独特性，最好用专属定制类词语突出个性化和唯一性，才能做到价值超越。

d.上架后要有节奏地做QA，还要上传QA视频。不需要测评，只要详情页足够优秀、QA引导到位，没有评论裸奔也能出不少单，这点不用太担心。

e.主图非常重要，尽量保证点击率够高。后期用广告的长尾词测试，在点击率有保障的前提下，用广告推广，不测评也能把产品打爆。

**5.产品推广问题**

目前推广上，我做QA、拍摄并上传QA视频，不做真人测评。平台政策松的时候，也会考虑上几个直评，费用便宜：QA大概3—5元一组，直评10—15元一个。不过最近直评上得慢、不太稳定，基本只做QA和QA视频。

重点还是站内广告。按这套模式，单纯用广告推广成功率也不低。前提是前期选品不错，运营方法和模式对了，一般不会太难。这也侧面说明选品的重要性，后期运营方式要根据产品特性来规划。

站内广告逻辑：

a.假设一款产品有4种颜色、50个元素，那就有4×50=100个变体。我一般会创建50个广告活动，相当于每个子变体的50个元素各建一个广告活动，每个活动里加入这个元素的4种颜色，让它跑。

b.选词一般选两种：一种是50个爆款元素的长尾词、大词，分别加入刚才创建的50个广告活动，用广泛匹配跑；有一点权重后，再加精准匹配，提升长尾大词的自然排名。另一种是基础爆款的核心词，可以用软件调研，找到核心词后，在前面加上50个元素的词拼在一起，各自放到对应的广告活动里。

c.我开的都是手动广告，选的词比较精准，流量也精准，所以点击率非常重要。前几天要持续测试点击率，不满意就及时优化；点击率可以的话，慢慢会有转化，因为产品在这个长尾词下已经是最匹配的，成交是大概率的事。只要点击率不错，就继续给预算，每天看前一天的实际花费，ROAS不错的广告活动就持续递增预算。

d.这样开广告，花费会比较多，因为变体多；好处也明显：点击率不错时，每天持续有大量点击，产品排名会上升得很快，后期自然排名也会跟着涨。等自然排名到比较理想的状态，就可以降低广告竞价，去吃后面的流量，利润率会大大提高。

e.还要注意，尽量在目标销售国家的白天多花钱，尤其是转化率高的时候。比如做北美站，我会在中国时间下午4点（美国晚上12点）把预算全部调为1美金，到中国时间晚上9点多再恢复正常，同时加大竞价，尽量在白天转化高的时候把广告预算花完，性价比更高。

f.通过广告把产品推起来后，后期要不断点击亚马逊后台的请求评论按钮邀评，有些插件可以批量操作。也可以在包装里放售后小卡片（你懂的）。自发货亚马逊查不到我们的包裹，因为我们不入亚马逊仓库，直接发给买家，只要买家不举报，基本没事。一般做有利于买家的事，正常不会举报；如果你比较保守，就不要搞这个。

**6.订单批量管理**

订单批量管理有很多不错的ERP系统。我一直用店小秘，免费，效果也挺好，功能适合自发货：订单来不及发时可以虚拟发货，避免ODR超标；还能做订单管理、打印订单，基本都能解决，关键还免费。市场上类似ERP不少，按自己实际情况选就行，不一定非用这个。

**7.小包分拣配送**

小包配送分拣和仓库打包，可以找大学生兼职。先培训好一个能力较强的人，再让那个人带着其他几个学生做。每个产品最好设一个编码，按编码操作，防止打包打错。自发货发错货很麻烦，买家退货基本就亏了。

**8.物流运输问题**

小包物流渠道不少，递四方、云途、燕文时效都不错；邮政比较慢，尤其E邮宝很不稳定，所以一般选前面几家。美国通常2周左右买家能签收。详情可以去官网查，加客户经理微信让对方指导。也可以考虑亚马逊的购买配送，能解决ODR问题，亚马逊推出一段时间了，效果很好；云途、燕文都支持亚马逊线上购买配送，对FBM自发货挺友好。

**9.退货和售后问题**

最重要的是控制好ODR，不要超标。注意几点：第一，选时效稳定的物流商，最好用亚马逊合作购买配送的物流商，更有保证。第二，一定要用ERP系统，可以虚拟发货，规避迟发率问题。第三，外国骗子一定存在，只能尽量沟通、多让利，不要给差评或争议，不然店铺绩效容易出问题；目前来说，U1S1，这种情况还比较少。第四，尽量别做客单价太贵的产品，资金压力大，售后严重会侵蚀大部分利润，要权衡自己能接受的价格段；也不要太重、体积太大，物流费太贵，不适合国内发货的自发货，除非是海外仓模式。
