# 4.1.4 闲鱼上书实操流程 @老瞿 Qu

想在闲鱼上架书籍，推荐用电脑操作。手机也能弄，但得扫ISBN，远不如网页端来得高效。官方后台叫闲管家，网址是：www.goofish.pro/product/all。

新店或新链接还没起流量时，加价幅度别贪，10%-20%就够了，等有了订单再慢慢提价，这样前期更容易把权重做起来。等流量稳定后，日常上架直接参考孔夫子或淘宝的价格，加价30%-50%即可。

具体操作如下：

第一步：登录闲鱼，进入商品管理，新建一个商品。

[PRE0]

第二步：商品类型选“一口价”，分类选“图书”——要是卖教材，就选“学习考试”类目。

[PRE1]

第三步：在“发布的闲鱼号”那里，选择你打算用的账号。

[PRE2]

第四步：把基本信息填完整。

[PRE3]

注意事项：
• 商品图片：去孔夫子或淘宝找没水印的实拍图。
• 商品标题：格式建议“正版二手/二手正版 + 书名 + 作者 + 出版社”，尽量把字数写满。
• 商品描述：可以参考同行在闲鱼上的模板，但每个号最好固定用一套，避免内容同质化，记得自己改一改。类似下面这种，注意要自己修改调整下。

[PRE4]

第五步：在“价格库存”部分，填好价格、改好库存就行。价格怎么定？参考孔夫子商家的售价（书本价格+运费），在此基础上加40%，这样能确保利润率在30%以上。

[PRE5]

举个例子：像《毛泽东思想和中国特色社会主义理论体系概论（2018版）》这本书，可以在孔夫子按价格排序，选总价从低到高，品相筛八五品以上，然后拿商家的售价做参考，加上40%来定价。

[PRE6]

[PRE7]

填好后点“立即发布”，再点“确定”，这本书就上架成功了。

[PRE8]

这套流程跑熟以后，一小时上架20个链接毫无压力。

内容来源：《深耕行业 2 年后，分享咸鱼二手书无货源、绝版二手书等 5 种项目玩法》
