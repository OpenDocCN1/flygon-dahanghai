# 不囤货、照样赚：我靠几百个亚马逊店铺日入一万

大家好，我是龙哥。每周一固定邀请一位圈友来聊一聊自己的搞钱心得，这期也不例外。之前有人在星球里问“亚马逊零库存怎么玩”，我自己没接触过，搜了一圈发现丁晓峰有实战经验，就把他请来了。

丁晓峰的经历很有意思：07年还在工地搬砖，08年开始转行做网络贸易，到现在已经有十年外贸经验，年收入破百万。他手上管着几百个亚马逊店铺，每天利润一万，而且基本零库存。他这些店铺，不是大家理解的那种精心打磨的精品店，更像淘宝店群、拼多多店群，拼的是数量。每个店铺就是一个长尾流量入口，单店订单不多，但店多，加起来流量就很可观。

下面是他这次分享的内容。

很多人觉得亚马逊不做精品店就做不下去，甚至看不起铺货模式。但如果你做过淘宝铺货、速卖通铺货、Shopee铺货，或者体验过阿里巴巴批量传产品、用机器人助手获取询盘，就容易理解这套逻辑。说白了，原理就是长尾理论：靠软件批量上架，赚信息差的钱。总会有人在你店铺里下单，哪怕单个店单量少，店铺多了，收益自然会累积。

这就像顾小北老师提过的“批量思维”。精品店走的是“以质取胜”，我们走的是“以量取胜”，各有利弊，选适合自己的就好。

具体怎么玩零库存亚马逊？几个要点。

第一，多语言多国家铺货。亚马逊各国站点能自动翻译，一件产品可以铺到多个国家站点。

第二，多产品。持续从各种渠道找货上架，不断扩充产品库。

第三，先进的管理工具。要有一键代发、自动结算、一键刊登、一键抓取、供应链分销这些功能。市面上很多系统都把重点放在订单处理上，但我觉得，先保证出单才是关键，有了单，总有办法运出去。亚马逊后台如果没有ERP，用起来会非常崩溃，多语种、变体、多店铺叠在一起，分分钟让人想放弃。

第四，物流怎么办？我们把亚马逊的配送时间设置为最长，大约20到40天。这个时间足够操作发货了。海淘的人本来就愿意等，所以不用担心。其实我的自发货和别人的自发货没什么本质区别，反而因为利润率高，还能选更好、更贵的物流。

第五，售后。客服自己处理就行。

第六，FBA。我们也做FBA，但我们的FBA产品不是靠猜的，而是卖出来的。先铺货，跑出自然排名和流量的产品，再转FBA，风险会小很多。铺货本身就是一种选品。

第七，分销。做贸易的人最懂分销倒卖的价值，产品越多，资源越多，销售额越高。

有人会问，亚马逊和谷歌都在鼓励精品和快速物流，为什么我们不做精品也能赚钱？因为我们做到别人做不到、看不上、看不懂的事，这部分钱没人抢，自然归我们。何况目前也没有精力做精品。

这种“铺货思维”不止在亚马逊有效，连APP都有人这么玩。你去App Store搜“时间管理”，能看到两个模板一样、用马甲包抢流量的APP。电商的玩法无非刷单、精品、铺货，怎么玩得转，就看各自本事了。

再说一句，零库存模式必须靠软件工具打底，再用长尾理论和经验去驱动。没有工具提效，光人力成本就够受的，赚的钱可能还不抵人工费。

既然来了龙哥盟，我也聊聊对赚钱的看法。

普通人能不能年入百万？我觉得人人都可以，只不过很多人没摸清规律。我做了十一年外贸，见过太多迷茫的业务员，就像当年工地上搬砖的自己，没人指点就容易走错路。

那时候我定的目标很简单：十年后赚到100万。但现在回头看，100万在杭州连首付都不够。就当它是个数字吧，不是天花板。2015年遇到我的外贸老师，他说“遍地都是钱，遍地都是机会”。我想，不用做到他那样，模仿10%也行。这有点像电视剧《将夜》里的修行者，境界不同，看到的层面和赚到的钱自然不同。

查理·芒格说：“如果你想要得到某样东西，你就先得让自己配得上拥有它。”反过来用他的话：“如果知道自己会死在哪个地方，就不会去那个地方。”想得到100万，先让自己配得上，然后避开那些得不到100万的坑。

这几年我总结了普通人最容易踩的七个坑，想赚钱的人可以对照一下。

第一，没有目标，频繁换工作。很多人做两年没起色就换公司、换行业，换了一轮，几年后还在原地。冰冻三尺非一日之寒，深耕一个行业很重要。换行业之后，你面对的是更年轻的人，后面可能会发现自己已经没有换的资格了。我做外贸第一年一个订单都没有，采购还嘲笑我。但我没怀疑自己，先接1000块的单也行，别人赚100万，我先赚10万。第三年我成了公司TOP，当然也可能是别人都走了，只剩我。这里不是劝人死守，如果真不合适，换也行，但不能频繁变道。变道变多了，就会迷路、打转。

第二，没有自知之明，眼高手低。我在工地干过，腰都扭伤了，后来被辞退，换了工地也看不到出路。尤其我还是个钢铁直男，工地上没几个女人，连繁衍后代都成问题。我有自知之明，所以转行了。想进好公司，先放低姿态，带着学习心态去。比如我入职时第一个月工资500，老板主动加到600，当时行业平均800。我不在乎，因为就算给6000也发不了财，只有匹配得上，钱才会自己跑过来。有个同事要求加薪，老板说钱就在那里，你凭本事拿。能力强了，自然有人给你钱。

第三，用心不专，什么都学。厉害的人都在专注一件事，即使学很多，也是一件一件来。很多人买了课、参加了培训，还是什么都不会。我也买过爬虫课，但发现不适合自己，不过没关系，我认识“明白”老师和他的学生，以后可以花钱请他们帮忙抓数据。我也加了很多星球，但我会一次性看完一个星球的内容，做好摘记，有个星球的供应商信息已经让我赚了几万块。反观有些人，听说速卖通赚钱就做速卖通，听说独立站赚钱就做独立站，听说Facebook赚钱就去学Facebook，到头来全是半桶水。义乌有个按脚师，以前是理发师，学了一个星期按摩，按了十几年，现在预约才能排上，年收入两三百万。龙港有个推拿师，手指少了几根，但脊柱整形很厉害，也要预约，年收入几百万。普通人把一门技能练到极致，就会成为别人离不开的人。

第四，不学习。厉害的人都有一个共同爱好：读书。书是最好的朋友。给我开窍的是《秘密》，总结起来就是积极、让自己配得上，这个结论和《原则》也是一致的。前几天我为了找一个盒子供应商，花了几周都没找到。后来做梦梦到一个漂亮的盒子，醒来一场空，就发了个朋友圈感慨。纸箱厂老板娘看到后笑了，直接答应帮我做。积极的心态会把困难慢慢化解，消极懒惰只会让问题越来越麻烦。抱怨就像搅拌一坨屎，越搅越臭；开心就像搅拌咖啡或巧克力，越搅越香。所以多想想自己正在搅拌什么。知识星球上也有古典、采铜这些优秀作者，尤其应届生读采铜的书，能少走不少弯路。

第五，不自律。自律和专注是相通的，管不住自己，业务很难精进。廖凡的电影《师父》里有一句话：“每日挥刀500下，这个数字管住了我，让我不胡思乱想。”给自己设定一个约束，才有定力走远。

第六，不明白为谁工作。我去阿里巴巴总部培训时，老师Andy杨问“你为谁而工作”。我的回答是：为自己工作，也为公司工作。我的理想在自己心里，公司的事就是我的事，做的是公司的事，学的是自己的经验。很多年轻人老板吩咐一下动一下，不吩咐就闲着，等出来自己干才发现什么都不会。没有老板思维的人，能力很难提高。

第七，圈子太小。十年前就听说有扫地阿姨在房地产老板家干活，只听懂“买房子会赚钱”，但我当时只想着温饱，没当回事。1998年，深圳外贸工资2000，老家普通工作300，厨师800到1000。城市虽然“吸血”，但机会也多。知识星球能让你找到行业老师，付费学习，认识更多朋友。我原本想回老家做点外贸小生意，但想想还年轻，不如再打拼几年。多动笔，多认识朋友，多赚钱，去不同地方学习新东西。

以上这些毛病，就像堵在河道里的石头，搬开它们，河水自然流通。赚钱只是时间问题，赚多赚少，机会大小问题。很多人看了、听了，但不动手，所以还是老样子。思想上想通，行动上做足，年入百万就不远了。

我自己也践行了这套方法论。看到“明白”老师那里提到龙哥盟，我灵光一闪，为什么不自己做一个星球？既能帮别人，又能增加收入。于是我创建了“外贸小酒馆”，核心是帮外贸老板降低客户管理成本、提高效率。我做了十一年外贸，知道客户管理有多痛。国内CRM系统又老又贵，起价一万，大多数人只拿它存客户。而我比CRM软件工程师更懂外贸需求。这个市场很大，外贸公司创业超过三年、在客户管理上花了几万块的都有潜在需求。只要有2000人加入，每人付费一点，我就能赚到100万。我不坑人，还帮人，利人利己。

目前三个多月，星球有287人，收入6万多，主要是熟悉的朋友，因为没怎么推广。现在只是业余更新，如果全职运营，百万也是可以实现的。一个人如果不踏实，机会来了也抓不住；相反，养成好的成事习惯，遵守做事原则，一切会越来越顺利。
