# ③ 方法三：提交 weekly

这是用于冷启动、外链推广或用户获取的小思路，灵感来自阮一峰老师的网络日志。

1. 去 GitHub 用 weekly in:title 搜 weekly；
2. 主动提交收录，能拿到访问量、外链和权重；
3. 提交后如果加了统计代码，可以对比每个 weekly 带来的访问量，为后续产品运营迭代提供数据；
4. 每个 weekly 都有默认用户群，其中有人会写文章、主动分享，形成稳定扩散。

你能得到：冷启动、扩散渠道、一批稳定外链和权重。

## 推广开闸：先让产品见人

一切就绪，就从你熟悉的渠道开始，把能影响的渠道都发一遍，先拿到第一批用户。哪怕不是海外用户也行，因为第一批人能帮你找出问题、修掉问题。

接着投周刊，比如阮一峰每周五科技周刊、ahhhhfs.com、小众软件、不死鸟博客等，这些都有投稿或发帖入口。

然后把产品提交到 ProductHunt，能带来真正意义上的第一波海外用户。

这些渠道常出现新产品，其他导航站的爬虫会自动抓链接。假设产品是 AI 工具，各 AI 导航爬虫会从 PH 自动抓取收录，又能带来一批导航站用户。

再提交到不会自动抓取、需要手动提交的导航站；付费的也可以量力而行，太贵先不碰。

用户进来后，观察使用情况：工具能否正常用，是否愿意分享，老用户有没有带新用户。

# 玩法一：TikTok 引流

TikTok 是巨大的流量入口，做好引流，产品冷启动基本不愁。

新手怎么在 TikTok 引流？以圈友 @Harvey 推广一款海外交友平台产品的案例，来看完整过程：

1、注册账号，包装成美女账号

名字、头像、简介都往美女人设走，再搬 3—6 条美女视频提升真实感，不用追求播放量。

2、找到对应地区的美女账号

美女账号下的男粉丝就是目标用户。我测过台湾、欧美、中东、东南亚几个地区，看账号文案或简介语言就能初步判断地区。目前欧美充值率最高，仅作参考。

分享两种无限裂变采集对标账号的方法：

第一种：
① 关注一个对应地区的美女账号；
② 点“Follow”右边的小箭头，会弹出相似推荐；
③ 点“See all”，得到一批相似博主；
④ 持续重复前三步，就能无限裂变。

第二种：
① 关注一个对应地区的美女账号；
② 进粉丝列表，基本都是男粉丝；
③ 看这些男粉丝关注了谁，就能发现一大片新大陆；
④ 最后做好筛选即可。

3、关注对标账号的粉丝

老外本身有爱回关的习惯，加上美女人设包装，整体回关率大约三成。

4、私信引流

私信发已编辑好的话术，引导对方点链接下载 APP，之后用户在 APP 消费就能分佣。

除了私信链接，还可以把用户导到 WhatsApp 精聊转化。话术到位，转化效果不错，缺点是效率偏低。账号有了一点权重后，可以转商业账号，主页直接挂链接，多一个触达入口。

为什么不用追求播放量？这是主动流量和被动流量之间的取舍。

以往基金、带货都靠优质视频冲高播放和粉丝再变现，这种路径受环境影响大，流量被动不可控。爆视频当然爽，但很多人也尝过长期 0 播低播的煎熬。

关注回关法不用花精力做优质视频，还能忽略环境导致的 0 播低播，把流量主动权握在手里。稳定才是王道。
