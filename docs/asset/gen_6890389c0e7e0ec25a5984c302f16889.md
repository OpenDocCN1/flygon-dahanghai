💡引言

欢迎来到 12 月航海的📕运营实战手册。接下来的日子里，我们大概会在这里反复碰面。

正式动手前，先把三个问题说清楚：

1）现在入局📕，机会还有多大？

QuestMobile 2020 年数据显示，📕平均带货转化率是 21.4%；同期抖音、快手、🧣分别为 8.1%、2.7%、9.1%。原因不难理解：平台聚集了大量爱“买买买”的用户，又自带“种草”社区基因，所以带货转化表现强于不少公域平台。

同时，📕具备客户质量较高、鼓励种草、转化率高、离赚钱更近等特点，很适合在这里打造 IP、形成私域闭环。对商家来说，这里适合引流和投放，能触达精准客户；对博主来说，即使是素人，也有更多变现机会。

2）哪些人适合做📕？

最理想的情况，是你有自己的产品或服务 IP，能通过📕放大原有生意。

如果你没有产品，也可以问：还能入局吗？

答案是能。只要你有某项专业技能或特长，就可以尝试做纯博主 IP：先积累粉丝，再打磨笔记，通过接广告变现。

那如果既没有专业技能，也没有明显特长呢？

可以选一个自己感兴趣、愿意长期深耕的领域，持续分享自己精进的过程与经验感受。这类内容同样受欢迎。

最后，希望这趟航行不只让你拿到成果，也能认识一群同行伙伴。

# 一、【项目概述】了解📕

💡章节纲要

本次航海的重点，是教大家如何从 0 到 1 做出一个📕账号。

想做出成功账号，先了解平台是基础。

说到📕，很多人的传统印象是“做美妆穿搭的”“只有女生才看才用”“都是 00 后”。但事实上，📕早就不是单一的美妆穿搭社区，如今内容非常多元。

这一部分，我们会从用户画像、热门类目、社区属性、流量机制四个方面介绍平台，帮助你更好地理解📕。

[PRE6]

## 1.1 用户画像

截至 2021 年下半年，📕用户主要集中在 18—34 岁，以女性为主，占比约 70%。其中不少是一线和新一线城市的都市白领、职场精英。“年轻”“女性化”“有钱”仍是这个平台用户的三大标签。

值得注意的是，越来越多男性也开始在这里分享生活。相比 2020 年，2021 年男性用户占比从 20% 上升到约 30%。

从需求看，用户关注度前三仍是彩妆、护肤、穿搭。但追求品质生活的都市精英，正在衍生更多需求：不做黄脸婆做辣妈、追求生活仪式感、培养多个兴趣爱好、打造自律又治愈的人生……这些也是他们的日常。

[PRE7]

用户需求变多，平台内容板块也随之扩容，覆盖衣、食、住、行、玩、学习等多个方面。

## 1.2 热门类目

需求焦点排在前三的依旧是彩妆、护肤、穿搭，但都市精英的需求正越来越宽：辣妈生活、仪式感、兴趣爱好、自律治愈等主题都有受众。

[PRE8]

如今，家居家装、母婴、美食、运动健身、知识学习、旅游出行、绘画摄影手工、萌宠等，都是新兴热门板块，流量并不少。

## 1.3 社区属性

📕的定位从口号里就能看出——“标记我的生活/你的生活指南”。它是一个生活方式内容社区，同时也是内容种草平台。用户一边分享自己的生活方式，一边“给别人种草”，或者“被别人种草”。

不管哪种属性，核心都离不开“内容”。你可以分享真实的自己，越接地气越好，但它不是🧣，也不是朋友圈。即便分享真实生活，内容也会被筛选；只有同时被平台和用户认可的内容，才有出圈机会。

## 1.4 流量机制

📕有两个核心流量来源：【推荐流量】和【搜索流量】。

### 1.4.1 推荐流量

和很多公域平台一样，📕有算法推荐机制。系统会根据笔记初始的点赞、收藏、评论、转发分享、转粉数据打分，其中评论、转发和转粉三项占分较高。

CES 评分 = 点赞数 ×1 分 + 收藏数 ×1 分 + 评论数 ×4 分 + 转发数 ×4 分 + 关注数 ×8 分

PS：CES 是📕内部评分体系。

当笔记分数逐步提高，就会被系统一级一级推荐到更大的流量池，成为爆文（小爆款互动量 1000+，大爆款 10000+，不同类目会有差异）。爆文还会带动其他笔记整体数据增长。当然，前提是：

① 笔记通过系统审核，没有违规，没有被系统删除，也没有被你删除或隐藏。

② 笔记包含关键词（比如香水、家具），能对应垂直标签，能被系统识别收录，并推荐给喜欢相应标签的目标人群。

③ 内容质量本身不错，能吸引用户点赞、收藏、评论等互动。

特别提醒：

0 基础新手很难第一篇就出大爆款；运营第一个月，新手笔记的小眼睛（阅读量）停在 100—200 都很正常，基础好的人出效果会快一些。

80% 新手是在第二或第三个月才开始爆发，有酝酿期，所以不用太焦虑，耐心打磨内容。

### 1.4.2 搜索流量

📕用户除了逛主页，也会通过搜索找自己需要的内容。比如想买口红会搜口红攻略，想去旅游会搜旅游攻略。

搜索结果排名靠前的笔记，会获得更多曝光和关注。这部分流量几乎占平台总流量 50% 以上，不容忽视。

想拿到搜索流量，首先笔记要包含有效关键词，且被系统成功收录；想让搜索结果排名靠前，还要持续提升账号权重和笔记权重。

# 二、【项目实操 1/3】明确个人定位，搭建📕账号

💡章节纲要

刚开始做📕，定位是第一个要解决的问题，也是之后整个账号的主线，后续内容都围绕它展开。

在📕，你可以分享各种好物和知识，也可以给别人种草某种“生活方式”。但种草不等于像淘宝那样发硬广，除非你是企业号。用户普遍更喜欢真实感强、接地气的 IP 和内容。

所以，想在📕建立 IP，良好的人设定位必不可少。建议给自己 2—3 天，认真完成人设定位。

💡本章航线图

完成本章学习和实操，就能完成航线图第一阶段：明确个人定位，完成账号搭建（约 2—3 天）。

1. 了解📕平台规则（约 20 分钟）
2. 找到并拆解 3—5 个对标账号（约 2—3 小时）
3. 注册账号，完成个人定位和包装（约 30—60 分钟）

## 2.1 如何进行账号定位

### 2.1.1 人设定位为何重要 @梨云

📕里受用户欢迎的 IP 人设，往往都有人情味。除了找细分领域，还要挖掘自己身上的各种标签，这些标签同样关键。圈友 @梨云 的经历，能帮我们理解人设的重要性：

就在我每天以千粉速度增长时，碰到了一个抄袭者。对方连名字都和我一样叫“学习方法”，每篇原图搬运，搬了 30 篇，涨了 3 千粉。

我本来觉得无所谓，但粉丝看不下去，拉着其他人组队去刷屏他的评论区，逼得他关闭评论区，后面还举报到账号限流。

这件事让我突然意识到：我不能像个营销号，只分享干货；我得注入自己的人设。粉丝喜欢的不是内容，而是我这个人。内容谁都能写，但我独一无二。

于是我做了两件事：加入人设、强化人设。

加入人设怎么做？比如把账号名改成“云云讲学习方法”；图片里不写“我”，而说“云云”；为了提高搬运成本，还在封面上小标题的英文处打上自己的文字水印。

强化人设，其实就是做粉丝运营。比如每条评论都回复，而且不管粉丝留言好坏，都给予最正面的反馈，只有鼓励，没有批判，在评论区提供情绪价值，粉丝粘性就会很高。

写内容时，要做最懂粉丝的人。你理解他们的痛，那种痛不是挠痒痒的痛，是痛到不能再痛、会呼吸的痛，是长期的痛，是中华上下五千年的痛。

方法就是多泡评论区，看粉丝说的话，尤其是抱怨。于是，在高频出现的词里，我深深理解了他们的处境：学习很无聊、上课老走神、背书记不住……

只要围绕这些点写解决方法，提供价值干货，就一定能深受粉丝喜爱。

没有站在粉丝立场思考，只为博取流量而写，就无法创作出打动人心的内容，也没办法赢得人心。

我现在越来越觉得这句话太牛了：从群众中来，到群众中去。

### 2.1.3 从自身优势出发，完成定位 @吴一村 @许义

做任何平台的 IP，做号前都得先想清楚目的：是纯兴趣分享为爱发电，还是为了搞钱？搞钱是想短期还是长期，小钱还是大钱，副业还是终生事业？这些都会影响方向选择。

先想好目的，定好大方向和赛道，再从自身优势出发，做出差异化定位。

注意：“优势”未必一定是专家学者。普遍来看，📕对普通人更友好，用户也更喜欢接地气的博主。

“差异化”也未必指别人都没有、全世界独一无二。在别人基础上做出优化，比如图片比别人美，或者内容比别人有趣，对很多用户来说就是差异化。

可以考虑这几个维度：你是谁？你干什么的？为什么关注你？对我有什么用？再展开就是：

我很独特，eg：去过 80 个国家

很厉害（有背书、我很专业），eg：携程签约摄影师

我是谁、做什么的、我能提供什么，eg：90 后川西旅拍领队

我和别人有什么不一样，eg：90 后的年轻组织、纯玩小团旅行

为什么关注我：需要一目了然 + 定位 + 内容垂直且专一不发散 + 关注理由

为了更深度挖掘自己的优势、做出差异化，可以从以下几个方面出发：

1.自身具备的、符合用户需求的兴趣、技能 @吴一村

[PRE12]

[PRE13]

喜欢是好事，但不代表你能胜任内容输出。所以还要在“自己有能力干”和“用户需求”之间找到一个聚焦点，这个点才是好定位。

很多新人定位时直接找自己喜欢做的事，觉得别人做这事能成功，自己肯定也能成功。但做完后发现数据反馈很差，这是因为用户只关心她自己，你喜欢的不代表别人也喜欢。所以我们一定不能自嗨，一定要关注用户需求。

除了挖掘自己喜欢、有能力干、用户需求的事情外，最重要的是要以此定技能。

什么叫定技能？就是你会的、你擅长的一项东西，你可以很轻松容易地分享给他人。比如：摄影技能、美食营养技能、健身、赚钱技能等等。

2.自身的外观优势 @子渝

你长得好看、身材很棒、成功减脂后特别美瘦、很会穿搭等等，都是你的优势点。

3.自身的资源优势 @子渝

资源优势可以是物品、货源渠道，也可以是虚拟的信息差，还可以是身边的环境。

比如：你家特别好看，囤了特别多好物，这是一种资源，家居博主就能用到。

比如：你本身就是踢脚线厂家，可以提供家装材料的批发、零售，这是一种优势。

比如：你很懂得如何布置学习桌面，还研究过超多桌面好物，那你可以当个桌面好物学习博主。

比如：你能找到别的学生党找不到的信息渠道、学习资料、靠谱教程等等。

4.自身的特色优势 @子渝

什么是特色优势？独特口音、地域优势、奇特发型、想被别人借走的一双巧手，这些都可以成为特色优势点。

建议优先考虑能提供价值、且用户有需求的点（擅长点 + 用户需求），再去考虑兴趣爱好和其他方面。

做📕是一个不断发现自己优势的过程。不论是在职工作还是全职宝妈，都能找到自己有特点的地方深挖。可以列出自己热爱的、自己擅长的和用户需要的，找到交集，大概率就能找到自己的亮点。

### 2.2.2 怎样判断对标账号是否适合你
