# 2.3.3.2 BTC与ETH：共识之外，路线各异 🔥

最后，把Web3领域最有代表性的两套系统摆在一起对照，也顺带复盘前两节的重点。

比特币在2008年由匿名网友中本聪推出；以太坊则在2013年由被称为计算机天才的Vitalik创建。BTC不依附任何组织；ETH虽是当下Web3规模最大的去中心化平台，却仍会受到社区与创始人的影响。

方向也有差异：BTC主张让数字现金在用户之间直接转账；ETH在区块链底层之上引入智能合约，并把自身定位为去中心化应用的开发平台，让链上技术延伸到更多行业。

启动路径同样不同。BTC诞生时没有走融资路线，参与者形成共识后就能加入网络承担记账角色，并因此获得比特币奖励；ETH则是先凭方案募到资金，再着手搭建网络。

激励层面，BTC采用PoW，也就是工作量证明。ETH起初同样运行PoW，今年9月完成全网升级后切到PoS权益证明。通俗讲，你持有该网络代币越多，参与记账能拿到的奖励也越高。

两者共享区块链与激励思路，却在组织方式、应用定位和共识机制上走出了不同路线。
