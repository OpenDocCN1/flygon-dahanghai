# 5.3 版权与法律规范

# 5.3.1 配置版权信息

# 5.3.1.1 基本说明

版权信息是 App 知识产权保护的重要一环。把它填准确，既是法律上的要求，也是对自己创作成果的一种保护。

# 5.3.1.2 确定版权归属方

# 5.3.1.2.1 个人开发者的情况

如果你以个人身份开发，直接写法定姓名即可。中文名、英文名或拼音都可以，但最好和注册 Apple 开发者账号时填写的名字一致。比如“张三”“Zhang San”或者“Sanford Zhang”。

# 5.3.1.2.2 公司或团队的情况

如果是公司开发，就写公司注册时的法定全称。如果是没有注册公司的团队，可以使用团队名称，不过建议先查一下这个名称有没有被注册成商标。

# 5.3.1.3 如何在 Xcode 中填写版权信息

1. 打开 Xcode，进入你的工程。
2. 在项目导航器里选中项目文件。
3. 点击主项目 target。
4. 切到“Info”标签页。
5. 找到下面两个位置进行修改：项目设置里的 Copyright 字段，以及 Info.plist 中的 NSHumanReadableCopyright 键。

[PRE1]

# 5.3.2 版权声明的写法

# 5.3.2.1 标准版权格式

通用的版权声明可以写成这样：

Copyright © [年份] [版权所有者名称]。 All rights reserved.

示例：

个人：Copyright © 2025 Zhang San。 All rights reserved.

公司：Copyright © 2025 科技有限公司。 All rights reserved.

# 5.3.2.2 年份怎么写

第一次发布时，使用首发年份，比如 Copyright © 2025。有持续更新的话，可以写成年份范围，比如 Copyright © 2020-2025。每次有比较大的版本更新，记得把年份信息同步更新。

# 5.3.2.3 在 App 里展示版权信息

1. 在 App 的“关于”页面放上完整的版权声明。
2. 可以在启动画面底部加一行简短的版权说明，这个看需求。
3. 应用商店描述的最底下，也尽量带上版权声明。

# 5.3.2.4 App Store Connect 中的设置

1. 登录 App Store Connect。
2. 选定你的应用。
3. 在“App 信息”部分，确认“版权”字段和应用内展示的版权信息保持一致。

# 5.3.3 法律层面需要留意的点

版权信息要真实准确，不建议用化名或没有经过注册的商业名称。如果项目中用了第三方库或资源，记得在 App 里的合适位置标注它们的版权信息。版权注册不是强制要求，但在一些国家或地区，正式登记能带来额外的法律保护。

[PRE2]

# 5.3.4 关于版权的常见问答

问：只填拼音可以吗？

答：可以。但建议和开发者账号名称保持一致，也要确保这是你法律文件里使用的名字。

问：需要去注册版权吗？

答：软件版权在创作完成的时候就会自动产生。不过在某些国家或地区，正式注册可以带来更多的法律保护和诉讼权利。

问：版权年份需要更新吗？

答：需要。每次有实质性更新时，就应该改年份，也可以使用范围写法，比如 2020-2025。
