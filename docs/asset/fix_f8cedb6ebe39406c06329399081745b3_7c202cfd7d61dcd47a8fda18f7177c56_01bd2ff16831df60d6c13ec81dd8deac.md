# 丁真：名字还我

他们说，这份差事该接。旅游大使，签的还是国企的约，月薪三千五，保险和公积金都配齐，放牧的营生照旧。那阵子他真以为，这是老天爷递来的饭碗。

直到抢注函像纸片一样涌来。他的名字被印在马桶刷的包装上，还有人拿去申请避孕套的商标。网上都在说：丁真是大家的。可他心里头那点位置，一匹小马、一座雪山就填满了。

理塘文旅一口气替他注册了217项商标，对外称是防抢。网友骂他们吸血，他却撞见过董事长大半夜在办公室抽烟，眼圈乌青。董事长把转让协议推过来，讲了句：珍珠，这名儿该还给你了。后来，112项商标落进他工作室名下。

有人说这是资本的游戏。但他清楚，那些连夜开会的人，不过是想给一个连汉字都认不全的放牛娃，留住最后一点体面。

资本把他塞进藏袍，又让他把普通话练起来，再送去综艺现场。主持人问，你的梦想是什么？他说，骑马比赛拿第一。台下一阵哄笑，这段到播出时被剪了。后来他说，想请大伙儿去他的家乡走一走。那边要的是一尊圣洁符号，不是一个会闹肚子、怕黑、偷摸吃泡面的丁真。

最难熬的是舅舅摊上事那段日子。热搜把他的名字和“睡粉”绑在一起，理塘的民宿外头全是记者。经纪人把烟头一摁：你发条微博，就说舅舅不过是个牧民。他攥着手机，忽然想起小时候舅舅教他驯马——骑在马上的男人，不作兴胡说。最后，他一个字也没发。

在流量的规则里，真话反而金贵。那之后他夜夜失眠。

有人告诉他，有个作家跟他同名。真巧。迷糊中他总看见那条灰扑扑的鲸鱼，驮着他往一座孤岛漂。岛上堆着合同、商标、证书，还有没拆开的私信。耳边两种声音轮流响：你变了。快凉了。鲸鱼接话说：你看上去，活像个怕太阳的雪人。

转机来得没预兆。某个工作室推动驳回了“丁真”商标的注册，他看着那纸结果，反而松了口气。再拍那支宣传片时，镜头里没有磨皮滤镜，只有被高原的风吹红的脸、裂了口子的手，还有阿妈额上深深浅浅的皱纹。弹幕有人感叹：理塘的风，原来真能割人。

那年年底，仓央书房已经盖到第五座，他用版税买来三千本书捐出去。有一天，一个孩子抱着《小王子》跑过来问：哥哥，你的那朵玫瑰花藏在哪儿？他指了指窗外那匹正在撒欢的栗色小马。

如今他还在理塘住着，文旅公司的熟人得空会来坐坐，聊的是今年虫草的收成，几乎没人再提流量。当初抢他名字的那拨人，几个反倒成了他的分销商，剩下的，慢慢在热搜的浪头里没了影。

昨天夜里，那条鲸鱼又来了。它没驮着他往孤岛漂，而是一个猛子从冰面下钻出来，后背驮着一群裹藏袍的小娃娃。天刚亮，珍珠拿鼻子拱他的脸。手机屏幕上跳出一条推送，讲他过气了，又在牧场露面。他笑笑，把页面划走。

草原尽头，第一缕晨光正把雪山镀成金色。

这，才是他要的顶流。

# 简单拆一下这些账号的受众，可以分成这么几类：

# 1. 年轻女性，尤其Z世代

年龄多在18到30岁，以Z世代（1995-2009年间出生）为主。小红书自身就是年轻女性居多，拟人化内容又自带可爱、疗愈的视觉气质，天然容易圈粉。对她们而言，让无生命的东西拥有情绪与个性，能填补陪伴感和情感投射的需求。比如药材被画成“暖男”或“萌妹”，既把健康信息讲出去，又靠人设制造亲近感。

# 2. 二次元与泛ACG文化爱好者

这批人常看日漫、国创和同人创作，对“兽人”“异形头”这类拟人设定很熟。蔬菜和器官做成日系画风或萌系画风，正好踩中他们的审美。他们中间还有不少手工达人、插画师或AIGC玩家，要么拿Midjourney生成虚拟形象，要么做毛绒玩偶、痛包之类的实体周边，等于帮内容做了二次传播。

# 3. 关注养生和健康科普的人

药材、蔬菜一旦拟人，很容易搭上中药功效、食物搭配等知识点，吸引那些正在研究养生的人。角色扮演降低了理解门槛，也更容易被记牢。同时，这类内容还可以给家长用——拿卡通形象教小孩好好吃饭，或者补位学校的健康教育。

# 4. 城市青年与“孤独经济”人群

城市节奏快、压力大，拟人化内容刚好给情绪一个出口。把器官画成苦哈哈的上班族，用搞笑对白讲当代人的健康焦虑，一不小心就引发共鸣。这群人习惯用短视频和图文吸收信息，喜欢轻量内容；拟人视频既有意思又有信息含量，正对碎片化浏览的口味。

# 5. 品牌方和商业化操盘手眼中的目标人群

品牌把拟人形象当成IP来推产品，比如“胡萝卜战士”“枸杞小姐姐”，吸引那些在意趣味性和故事感的消费者。做健康食品的品牌，可以用角色去讲“科学配方”“天然原料”，精准拿捏成分党。药材拟人可以攻中医药年轻化的市场，蔬菜拟人则更适合亲子家庭或有机食品消费者。
