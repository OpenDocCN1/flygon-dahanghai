# 启航前，先说清楚这几件事

欢迎来到 3 月航海 | 出海第一站 | 实战手册。接下来的日子里，我们大概率会在这里反复碰面。

这趟航行的目标很明确：做出你的第一个海外静态网站，并给它装上一个能变现的入口。

原因也很简单——用英文工具站赚钱，本来就是一个需要长期投入的事情。与其一上来就花大量精力寻找完美需求、打磨理想工具，不如先完整走一遍项目流程，把每个环节都摸清楚，在这个过程中逐步建立 MVP 意识和 SEO 思维。

这也是本次航海必修篇的核心内容。必修篇会展示一个网站从需求挖掘到尝试变现的全过程。

等你跑完这一遍，后面再遇到第二、第三个需求，就能更快出手，尽可能早地拿到更多流量，再借这些工具站赚到更多钱。

那么，在正式动手做第一个海外工具站之前，先回答几个问题：

1）为什么要做海外工具站？

先看竞争。相比国内，海外的竞争压力小不少，流量池也更大。再看壁垒。海外工具站不是小个体或小团队随便就能复制的，活得比较滋润；做得好的工具站，一年利润上亿也有可能。往前一步，可以融资做成 SaaS 独角兽；往后一步，也能低调赚钱、闷声发财。想象空间很大。

另外，海外目前仍然很依赖谷歌搜索流量，短期内看不到大的危机。工具站做好之后，这套能力还能迁移到下一个工具需求上，再来一遍。

亦仁在星球里不止一次建议有产品开发、搞流量能力的圈友去做海外产品，还说过：如果自己不做生财有术，就会去做英文工具站。

需要特别说明的是，做海外工具站没法一步到位。想快速验证需求、拿到用户真实反馈，从挖需求到网站上线宣传的整个过程，都得带着 MVP 意识和 SEO 思维。

2）什么样的人适合做海外工具站？

① 具备一定产品设计、开发和营销能力的人；

② 对海外市场感兴趣，有耐心试错，并且对挖掘用户需求和开发工具有一定了解的人。

如果做出来的工具站有稳定流量，可以考虑长期做下去，日常花一点时间运营，就有机会实现“躺赚”。但这个项目也有门槛和挑战：

1、开发容易推广难。网站上线后，要持续关注流量并做优化；

2、存在一定技术门槛。如果开发能力不足，建议自学、用工具辅助，或者找合作伙伴一起解决。

#### 1.1.3 为什么首选英文工具站 @刘小排 @哥飞

为什么从海外网站，也就是英文工具站开始？

因为做海外网站最快，比其他形态的产品快很多。

做 iOS、Android 的 App 很慢。

首先，App 的编码过程比做网页复杂，编码能力要求也更高；其次，上线还得打包、提交审核，审核还可能不通过，时间成本很高。

如果你做的是国内 App，那就更慢。你得先花 3 个月拿到软件著作权证书，才能上架国内应用商店。更麻烦的是，想修一个小 bug，也不得不重新发版，用户还得升级安装 App 才能用，这会严重拖慢你发布 bugfix 的效率。

做国内网站也慢，因为需要域名备案。备案周期大约 1～3 周。如果所在城市要求特别严格，比如北京，备案还经常被打回。

做微信小程序比上面两个略好，但也慢。问题在于微信小程序的开源生态不够大，很多轮子要自己造，难以直接引入开源代码来加速编码过程。

做海外网站是最快的。它不需要软件著作权证书、不需要域名备案、不需要应用商店审核；软件有更新时，用户也不用重新下载 App。代码放到 Github 仓库里，通过 Github Action 做 CI/CD，就能实现一提交代码立即自动上线的效果，开发体验很爽。

等工具站做好、排名上去，几乎可以吃十年二十年收益。只要还有互联网、还有搜索引擎、还有互联网广告，你就还会有收入。而且一个网站存活得越久，在互联网上留下的外链就越多，排名也会越稳固。

当然，这有一个前提：不能做垃圾站。赚钱的前提，一定是你做的工具能切切实实帮到别人，用户才会愿意自发帮你传播。

种一棵树最好的时间是十年前，其次是现在。做网站属于长期积累的事情，所以不要想着等以后再做，而应该立即开始。做好之后放在那里，不去更新，只要你的工具站还有人使用，权重就会日积月累，越来越高。

尤其今年一整年，大家对 AI 的热情都很高涨。只要你做的工具跟 AI 相关，用户就会自发帮我们传播。

所以可以说，现在是最好的下场时期。

可以做的方向有很多：有些需求是短期的，有些是长期的；有些 for fun，为了好玩；有些是真的工作生活需要用到的。

对大多数新手来说，可以先做短期或者 for fun 的需求练练手。在这个过程中，学习如何挖掘需求、如何做 SEO、如何获取流量、如何宣传推广、如何把流量变现。

之后就可以布局长期的、工作生活需要的工具。参考竞争对手，争取在某些方面超过他们，比如做得更好用、更漂亮、处理速度更快等等。

需要指出的是，“从网站开始”，不意味着你的产品永远都是一个网站。

只不过 MVP 阶段是网站而已。当你接收到足够多的用户数据反馈之后，再去为它做微信小程序、iOS App，永远都不迟。

#### 1.1.4 中国工具出海二十年时间线 @非洲水手

恰逢看过吴晓波的《激荡四十年》，有些感触，今天先和大家复习一下中国工具出海的时间线。这激荡二十年，大致可以分为 4 个时期：萌芽期、起始期、扩张期、转型期。

1、萌芽期

首先是萌芽期。1998—2007 年是中国互联网发展早期，那时还是 Copy to China 的时代。在中国工具出海第一人周奕的带领下，以 MP3 CD Maker 为开始，中国互联网出海迎来第一波曙光。

[PRE10]

2、起始期

也是在这个时候，大家开始意识到：工具出海可以抹平中西方文化差异。随着 2007 年 iPhone 初代及 Apple App Store 发布，移动互联网时代开启，中国工具出海进入起始期。久邦、百度、360、UC、金山等国内玩家开始在海外“低调地”攻城略地，闷声发大财。

3、扩张期

接着到了 2011—2016 年，移动互联网出海正式进入扩张期。工具出海渐渐形成细分领域：手机管理类，如 Clean Master；相机图片类，如美图秀秀；桌面类，如 Solo Launcher、Go Launcher；浏览器类，如 UC、海豚浏览器等。不到 0.01 美金的买量成本，动辄数亿数十亿的安装量，迎来了出海资本的明媚春天。

这个时代也催生了众多广告代理公司，比如 Yeahmobi、Mobvista、Avazu 等，或者像猎豹 CM 这样自己开辟广告代理业务。很幸运，我也是在这个时代入行，服务过很多当时的明星产品，有幸见证了出海行业的辉煌时代。

[PRE11]

[PRE12]

4、转型期

时间很快来到 2017 年。工具出海经过几年黄金窗口后，增长方式越来越多元，变现方式越来越成（kua）熟（zhang）。与此同时，海外人口红利越来越少，产品同质化越来越严重，平台规则（主要指 Facebook 和 Google）越来越收紧。

久邦股价腰斩而退市，Google、Facebook 相继禁止锁屏广告，Facebook 更是暂停了中国区工具广告主的广告投放，Google 相继下架了 iHandy、猎豹等开发者的总计几百款工具产品。看空工具出海的声音不绝于耳，利益空间不断被压缩，工具出海行业被迫转型。

#### 1.2.3 广告+付费订阅变现 @亦仁

随着 Google play 政策收紧，广告加付费订阅慢慢在全球范围内成为趋势。其核心本质，就是找到那批愿意付费的用户，让他们掏钱付费；让不愿意付费的用户看广告。

如果早期没有用户画像，不知道什么类型的用户才乐意付费，那就粗暴一点：让所有用户都走一遍付费流程，拒绝付费的用户再走一遍广告流程。当然，这会在一定程度上伤害用户体验，再通过 ABtest 测试不断调优，最终达到 LTV 最大值。

广告方面，可以通过聚合工具找到最合适的广告来源，来进行广告调优。

聚合的作用，是把收益最高的广告挑选出来推送给用户，为每次展示选择最优 eCPM，以此增加广告填充，获取更高的广告收益。
