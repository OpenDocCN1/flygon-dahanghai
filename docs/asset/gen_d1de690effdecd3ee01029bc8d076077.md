## 2、小白救急单：低需求场景

这类客户可理解为“职场PPT急救人群”。比如干了二十年的车间老师傅，突然要用PPT汇报技术经验，平时连电脑开关机都不熟，更别说做PPT。他只能向外求助，可能找淘宝代做，也可能用AI自动生成；但不少人对AIPPT也不熟，这就是信息差，新手可以捡漏。

# Part 1 新手黑榜单

## 1、急单：时间越短雷越大

风险点：客户要求几小时完成。表面时间短、报酬高，有加急费，实际不确定性很大。  
具体问题：AI生成初稿后，常发现某些页面要手动调，比如特殊图表、复杂排版。若PPT基础操作不熟，光调字体对齐就半小时，更别说客户中途新增要求。对软件基础不扎实的人不友好。

## 2、纯美化：改到你怀疑人生

风险点：客户发来的PPT已有完整内容和模板，要求“优化得更高大上”。客户常误以为“不就是调颜色换图”，实际可能涉及：重做20页图标体系、统一全文档字体间距、调整50处图文混排对齐。收费也难：客户看到成品常说“和原来差不多”，尤其原稿不差时，他们意识不到背后200多处细节调整，最后钱和时间都没了。

## 3、复杂动画：AI的短板

[PRE20]

为什么AI工具搞不定？AI动画只有“淡入淡出”“左右飞入”等基础动作。客户想要“用动画画出建筑结构”，AI只能让整张图突然出现，做不到“地基→墙体→屋顶”分层建造。  
踩坑案例：接过儿童教育PPT，客户要求“字母A变成苹果的动画”。AI只能让字母消失、苹果出现；客户要的是字母A横杆慢慢弯曲成苹果轮廓。结果花3小时研究动画路径工具，最后客户退钱。  
避坑：客户发参考视频说“就要这种效果”时，视频里的动画可能是专业影视软件做的，一定提前问清动画细节。

## 4、数据分析：别把AI当统计师

案例：问卷结果300份，要统计成饼图柱状图。为什么进黑榜？  
1 AI变“复读机”：客户发含678条销售记录的Excel，AI只会转成文字：“7月销量最高达230万，环比增长12%”。实际需要：整理数据删除无效条目、用折线图对比6-7月趋势、在图表旁标注重点数据。  
2 客户预期错位：客户觉得“你不是AI生成很快吗”，实际数据有误时，比如合计金额≠明细相加，AI不会提示；要做组合图，比如柱状图+折线图双坐标，AI只会生成分开两个图；客户中途改数据源，所有图表都要手动重调。

# 三、新手该把店开在哪个平台@陈 bu 懂

# 3.1 淘宝：流量红利退潮

高盛报告显示，淘宝天猫市场份额从2019年66%降至2022年约44%，四年降三分之一。2024年淘宝份额还剩多少难说清，但这两年拼多多、抖音势头更猛，视频号、小红书、快手等也在抢电商蛋糕。传统电商老板正把获客渠道转向新媒体和自媒体；短视频、直播电商迅速崛起，大量年轻消费者涌向抖音、快手，消费习惯逐步向自媒体赛道倾斜。淘宝整体流量下行，需要专业老牌操盘手靠付费投流运营店铺才能拿到结果。身边做淘宝文案写作店铺几年的朋友，也遇到获客成本越来越高、投流越来越难打正；数据打正后，获客成本仍高，GMV看着高，扣掉投流、客服、写手成本，忙一个月净利润很少。很多老牌同行已退出淘宝，转向闲鱼等电商平台和其他自媒体平台。

# 3.2 拼多多：押金与低客单

拼多多竞争比淘宝小，肯花钱推广流量还不错，但在AI写作变现行业不是首选，原因：1.投入成本高，1000押金，闭店才能拿回；2.需要付费投流推广，推广费花了、运营得当会有客资，但重点要把客户承接住，对谈单能力要求高；拼多多客户属性导致客单价低，基本千字10-30，和闲鱼比投入产出比低；3.客单价低，只能自己流量、客服、写手一条龙，几乎无法分工分钱合作，要全职做才玩得转，和闲鱼比投入产出比低。

# 3.3 小红书：慢热内容场

起号周期较久。相比电商平台，除了直接发布卖的宝贝，还多了运营做内容的操作，通过干货、留钩子吸引粉丝转化进私域。常见情况是粉丝不是直接买写作服务，而是来免费领资料白嫖，不如电商平台直接。付费投流玩法需要资金成本，对小白入局不友好；正反馈比闲鱼慢。素人小白更适合先通过闲鱼，以更大概率、更短周期获得正反馈。

# 3.5 淘宝新手村刷法@海盐芝士

# 3.5.1 先把心态摆正

1.实习者心态，不求赚多少钱  
为什么把淘宝叫刷新手村？就像入职新公司，前期派单的人不了解你的能力，你也没经验。所以前10单到20单或30单，以新人练手的方式去练，不要把能不能拿到稿费看得太重，把真正写实际单子、实操、踩坑作为第一目标。有实操机会都很可贵，大概率还有稿费；就算经验不足踩坑没拿到钱，也无所谓。实战经验非常重要，就去练，把淘宝当新手村。  
2.可能拿不到稿费的原因  
淘宝和外部一些同行，绝大多数客服和客户没经过专业培训，不专业、不太靠谱。他们的谈单客服在售前售后有时没和客户谈好收款条件，客户耍无赖要退款，他们就直接退款，写手就可能拿不到钱。你了解就好，自己留个心眼；发现对方说得不对，主动沟通。他们并不权威，哪怕是错的，你和客户说清你的建议；他认知不到位、不专业，非要那么写，就按他需求写。写手职责是根据客户已确认的需求写文案；过程中发现不合理提醒他，决定让客户做。他决策错了，你该提醒都提醒了，不听，咱们也没责任。真拿不到稿费，不是咱们的问题，不要内耗。外部行业情况如此，你只需知道第一目标是实习生式实操、涨经验。有钱拿更好，没有也没关系；价格很低也没关系，经验是自己的。  
3.扩大分母，提升新手应聘淘宝成功率  
无脑多去应聘几十家，成功进入至少10家店铺，你在他们接单群也能看见很多单子。什么样的单单价高？你发现“这需求我大概能看懂”，去网上快速找对标，再用咱们讲的方法论套下来，就能写，能力就提升了。  
4.有一些经验，再去天猫店应聘  
前期至少10单不要去天猫。等你有了写10-20个真实客单的体感，包括客户沟通、和对方客服沟通的经验，再去应聘一波天猫店，再扩展几十个淘宝店铺。这时要好好包装简历，比如写文学硕士、什么专业，拿自己搜到的优质稿件重写一遍，当作自己之前写过的真实稿件去应聘。相当于拿好简历去新公司。  
5.尽可能展示能力，等待飞轮效应  
前期大概2周甚至3周，是淘宝客服和你互相试探。前期单子可能不多，一旦有几个客服给你发单，或你主动抢到一些单子，让他们发现你靠谱、能写类型多、质量好、效率快，一个客服会推荐好几个客服给你，也会把单价相对高的单子给你。
