# 6. 跑一遍📕账号采集

先挑一个📕账号主页，实际跑一次看看效果。在 Chrome 里打开龙哥盟的📕主页，会发现和之前页面相比有两处变化：第一，篡改猴插件图标上多了一个红色数字“1”，说明当前页面有一个脚本可以运行；第二，页面上出现了一个蓝色按钮“采集作者信息”，这是篡改猴给页面增强出来的功能。

点一下“采集作者信息”，账号数据就会被抓取下来，并以 JSON 格式展示。之所以用 JSON，是为了后面传给多维表格时更容易解析，AI 读取 JSON 也更省事。

采集到的内容覆盖以下 10 项：
user_id
name：账号名称
xiaohongshu_id
avatar_url：头像地址
ip_location
description：描述
following_count：关注数量
followers_count：粉丝数量
total_likes_collections：获赞与收藏数量
collected_at：采集信息的时间

# 7. 把采集数据送进飞书多维表格

沿用前面的做法，在篡改猴里再新建一个脚本，用来把刚采集的账号信息一键发送到多维表格。

依然是新建篡改猴脚本，清空默认内容后粘贴代码。这里要特别留意两点：

第一，代码块里的以下信息要换成你自己的四个参数，也就是前面（二）和（四）拿到的四项信息：

APP_ID: '替换成你的 app id',
APP_SECRET: '替换成你的 app secret',
APP_TOKEN: '替换成你的app token',
TABLE_ID: '替换成你的table id'

第二，要对（三）里创建的多维表格列字段做命名和格式设置，确保字段名称与类型跟 JSON 中提取出来的一模一样（最后一个字段在 JSON 中是 collected_at，到了表格里命名为 collected_at_bjt，相当于加了一个小尾巴）。总共 10 个字段，名称和格式如下：

user_id：文本
name：文本
xiaohongshu_id：文本
avatar_url ：文本
ip_location：文本
description ：文本
following_count ：数字（整数）
followers_count ：数字（整数）
total_likes_collections ：数字（整数）
collected_at_bjt：文本 【注意这个字段，是 collected_at_bjt】
