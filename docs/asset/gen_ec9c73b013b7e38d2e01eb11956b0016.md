# 精华帖｜程序员，别在生财有术拼体力

我常看到一种挺可惜的情况：有人在头部互联网公司写代码、做产品，年包已经百万，却在生财有术里挑那些靠熬时间、拼执行、杠杆很低的副业，忙上一个月只多挣一两千块。

每回听到这种选择，我都替他们惋惜。

会写程序的人，可以用接近零的边际成本让机器替自己批量干活，这本来就是极少数人才握着的强杠杆。既然如此，为什么还要拿血肉之躯去和普通人堆工时？那可是杠杆最低的玩法。天赋闲置，才是对人生最贵的挥霍。

我自己也是技术出身，所以想跟同行聊几条实在路径。程序员在生财有术里，怎样把能力用在刀刃上？我认为至少有四个方向：

1. 把低端劳动自动化
2. 做个人IP，卖课
3. 把软件做成生意
4. 盯住 Enabling Technologies，改造现有产业

先从门槛最低的说起。

## 一、把低端劳动交给程序

盗坤那套电商思路里，有个很值得学的点：先把账算透，也就是财务逻辑。

举个例子。要做抖音号，月薪6000元请个普通人，不要求他懂专业拍摄剪辑，只做二次剪辑、不许乱加创意。20分钟出一条，一天20条，一个月600条；摊下来，每条成本10元。

抖音的推荐机制里，账号过了风控，单条通常至少能跑500次播放；偶尔有爆款，标签越养越准，出爆款的概率也会上升。实测若剪辑认真，约一个月后平均每条能到2000次播放。

这样算，10元就兜底换来约2000次较精准曝光。账号持续开播时，这2000人里大概有200个高意向用户会点进直播间，直播间就是承接和成交的收银台。等于10元换来200个精准进店用户，而且平台还会顺着粉丝关系继续给直播导流。和千川买量相比，这个投产比是不是高出几十倍？

普通人到这里可能已经想开干了；程序员会继续想：每条10元还是贵。二次剪辑可以脚本化，成本还能再砍一到两个数量级。

## 二、做个人IP，卖录播课

不少技术人有个误区：觉得得先成为技术大神，才有资格做IP。其实未必。

阿里P8以上的技术大拿圈里，你听过 @突围一只鹰 吗？大概率没有。他技术到底多强我不清楚，但这个人做出了势能。靠录播课，他每月有5万元被动收入。详见：

## 四、盯住 Enabling Technologies

最后是难度最高、天花板也最高的一块：关注 Enabling Technologies。中文常译“使能技术”。

这也是我自己的日常：大量时间泡在 Hacker News 和 Github，盯新技术，推演它们可能打开什么。enable 在词典里是“使能够、使成为可能”。所以使能技术可以理解为：某项新技术的出现，让过去做不到的事变得可做。

比如4G加GPS定位，才让Uber式打车成立；十年前没有这两样，滴滴和Uber都无从谈起。

我的方法有三步：
1. 持续追踪新技术；
2. 持续看生财有术的帖子，知道别人在做什么；
3. 把两者对上，判断哪些新技术属于使能技术，再拿去改造旧做法。

举个例子。一边是新技术的进展：2021年起直播换脸逐步成熟，更早能做视频换脸，但直播换脸更难。另一边是旧产业的变化：从生财有术能看到，2020、2021年前后，中国人开始去TikTok直播，出海做老外生意，相关训练营也热起来。

两者一碰，直播换脸就成了使能技术：它让中国人把自己的脸换成外国人，在TikTok开播成为可能。过去要请既懂中文又懂英文的外国人上镜，现在招英语专业的中国大学生也能顶上，成本明显下降。

[PRE4]

有了这个洞见，程序员能做的事不少。比如：
- 提供换脸直播教程，定向卖给在中国做TikTok生意的公司；
- 降低使用门槛。用户是技术小白，只有一台手机、没有强显卡电脑，能不能换脸直播？能——做成云端方案，就能让新技术走进千家万户；
- 做直播换脸的垂类社区；
- 打造直播换脸技术的IP。据我所知，国内这块还挺蓝海。

生财有术帮你找需求，新技术尤其 Enabling Technologies 帮你解决技术问题；你负责连接两端，把产品和变现跑通。

## 总结

1. 把天赋用不起来，才是人生最大的浪费。程序员别跟小白比体力，多想怎么把能力变成杠杆。
2. 在生财有术，程序员至少能走四条路：低端劳动自动化、卖工具软件、做IP卖课、关注 Enabling Technologies，并把它们接到各行各业。
3. 第三和第四门槛偏高；经验不足时，先从第一、第二做起。

评论区里也有几句值得记下。有人回忆2020年，生财里一位程序员负责产品、一位负责引流，一周卖 Clubhouse 邀请码赚了60万；他自己手工找码只赚200，差距就在杠杆和分工。也有人问“现在学编程晚不晚”，我的看法和评论里一样：不晚，最好的起点就是现在。还有人质疑，程序员懂商业还用来吗？恰恰相反，很多技术人正是发现自己缺商业训练，才来生财有术补课。
