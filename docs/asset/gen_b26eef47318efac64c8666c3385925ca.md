# 总觉得自己不够好？也许是你的才干排错了队

自信这件事，跟能力强不强并不总是挂钩。才干排序靠前的人里，未必有“自信”的身影。

如果你习惯性地拿自己和别人比，很可能是因为成长路上收到的肯定太少了——总被家长拎去跟别人家孩子对照，或者动不动就被打击。久而久之，你形成了一种信念：只有变得更强，才配得到认可。于是你只盯着比自己厉害的人看，却忽略了自己其实也有比别人做得好的地方。一旦遇到反驳，第一反应就是怀疑自己。

## ① 哪些才干突出的人容易踩这个坑？

竞争、思维、排难。

## ② 问题背后的才干逻辑

**竞争**：控制不住地跟人比较，而且专挑比自己强的人当参照物，想借此逼自己进步。可一旦比不过，心里就难受。

**完美**：对自己标准极高，总觉得还能更好，同时习惯性地盯着别人的“长处”看。高标准之下，对自己很难满意。

**排难**：总能发现问题，也总想解决问题，时不时就掉进“补短板”的模式里。一对比发现自己不如人，就容易拿自己的弱项去碰别人的强项，还一心想着把这个差距补上。

**成就**：非常拼，渴望做出成绩。但如果使了很大劲，结果还是不如别人，就会有种被泼冷水的感觉。

## ③ 可以试试这样破局（仅供参考）

竞争才干要格外留心。适度的比较能帮你找到“偶像”，给你成长的动力；但过度比较，会悄悄耗掉你的心力。当你又惯性似的开始比了，不妨停下来问自己三句话：“我比的到底是什么？”“怎样才算赢？”“跟谁比才合适？”——直到你找到一种让自己舒服的比较方式。

举个例子。我曾遇到一位来访者，他总跟朋友们比谁挣得多，可他内心其实很抗拒天天加班。聊下去才发现，他脑子里有个声音在说：只有成为朋友圈里赚钱最多的那个，生活才算越过越好。

可当他想到自己已经一个月没陪过伴侣和孩子，又会懊恼，开始怀疑自己做的事到底值不值。那一刻他忽然意识到，之前的比较根本没有意义——不仅没让家庭更幸福，反而制造了矛盾，也让朋友觉得跟他相处很别扭。

等他理清了内心真正想要的东西，减少了无意义的攀比，更多拿今天的自己和过去的自己对照，注意力回到自己身上，攻击性少了，日子也顺了。在关系里，其实从来就没有真正的输赢。

**完美才干**：试着修炼一种心态——不是所有事都得做到100分才算好。去找那些能让你充分发挥优势、而不是暴露弱点的环境。

**排难才干**：练习把视角从“补不足”切换到“是什么在阻碍我发挥优势”。关注并管理靠前才干的盲点，而不是拼命补靠后的才干。去找那些靠解决问题就能获得回报的环境。

**成就才干**：学会给自己建立一套衡量“生产力”的标准。找那种工作强度跟你的能力比较匹配、并且能看到你贡献的环境。否则在对比之下，你越努力越痛苦，因为总有人比你更卷。

挑选对标对象时，选那些你有希望超过的人，而不是差距大到遥不可及的人。这不是脆弱，恰恰是一种“策略”。

多花点时间研究：你为什么会取得某些“胜利”？从成功里，更容易找到你比别人做得好的地方。

# 4.1.6 情绪管理

# 4.1.6.1 讨好型人格：一直憋着，最后炸了

## ① 哪些才干突出的人容易这样？

和谐、体谅、审慎（关系建立维度突出）。

## ② 问题背后的才干逻辑

**和谐**：总想让关系保持一团和气，遇到不爽的事倾向于息事宁人，希望团队/大家庭更好，宁可牺牲自己的利益。直到实在憋不住了，爆发。

**体谅**：擅长感知别人的情绪和需求，属于高敏感类型。别人一句话，就能让体谅强的人内心翻江倒海，但又觉得说出自己的感受可能会让对方难受。

**审慎**：总担心拒绝别人会让关系出现裂痕，说话谨小慎微。不满堆积久了，忍无可忍，就炸了。

## ③ 可以试试这样破局（仅供参考）

推荐读一读《被讨厌的勇气》，或者加入氛围轻松、相处融洽的团队，多和“积极+沟通+取悦+交往+体谅”类型的朋友待在一起。她们总能看到你的好，而且很可能更喜欢你“有话直说”，而不是“憋着”。

# 4.1.6.2 容易过度解读别人的意思，陷入自我内耗

过度解读，往往源于相处中别人的行为恰好踩中了你不喜欢的那一面，让你产生一种“受伤的感觉”。但因为种种原因，你没去确认、或者没法确认对方到底什么意思，只能靠过往经验去推测对方的意图。委屈、愤怒、难过都表达不出来。

这类人通常关系建立维度靠前、沟通才干靠后，遇事更习惯替别人考虑，而不是通过沟通去解开误会。时间一长，内耗就形成了。

## ① 哪些才干突出的人容易这样？

思维、和谐、个别、体谅。

## ② 问题背后的才干逻辑

**思维**：习惯自我反省和思考，有时候会在脑子里反复加工别人的意图。如果加工出来的答案是自己不喜欢的，内耗就开始了。

**和谐**：喜欢友好和谐的人际关系，讨厌冲突和摩擦。有时候会把别人的“不同意见”当成一种分歧甚至攻击，不敢说出自己的看法，怕影响关系，于是内耗。

**个别**：擅长发现人与人之间的差异，可能更喜欢“猜”别人为什么这样做/这样说，而不是直接去问。猜错了就产生误会，也容易内耗。

**体谅**：擅长体会别人的情绪和需求，高敏感类型。别人一句话就能让内心翻江倒海，但又觉得说出自己的想法和感受可能会让对方难受。

## ③ 可以试试这样破局（仅供参考）

持续练习觉察并表达自己的需求，或者通过记录心情、想法的方式把情绪写出来，而不是全憋在心里。当你想知道对方怎么想，直接问当事人是最有效的——当然，要讲究问的技巧。

也许让你直接去问对方有点难，但可以慢慢练习如何表达需求、如何拒绝别人的请求。

举个例子：同事问你能不能帮他做件事，你不想接，但怕拒绝会影响关系，还是应了下来。这里可能就存在过度解读——对方也许只是顺嘴一问，你帮不帮都没关系。

学好盖洛普这个工具，它能帮你更好地理解对方的行为模式，管理自己的行为，减少误会和猜测，用好自己和他人，尽量和让自己舒服的人合作。

尽可能把时间花在自我提升上，做一些让自己开心、觉得有价值的事。人际关系中的很多内耗，都可以靠越来越有能力、越来越有话语权来解决。

# 4.1.7 职场问题

不管是刚入职场的新人，还是摸爬滚打多年的老手，多多少少都会碰到一些职场上的困扰。

最常见的，莫过于不喜欢自己的工作、觉得工作没意义。有人刚上班就发现这份工作不适合自己，也有人做了三五年渐渐进入职业倦怠期——很少有打工人能绕开这个问题。

与此同时，在职场上不懂得表现自己，眼睁睁看着升职加薪的机会溜走，也是很多人的心病。酒香也怕巷子深，怎么把自己的工作成果完整地展示给上级？或许「4.7.2 不擅长邀功，埋头干了很多活，但升职加薪没自己」能给你答案。

# 4.1.7.1 不喜欢自己的工作，觉得没有意义

不喜欢自己的工作，是很常见的现象，什么才干都有可能。

如果你想知道“没意义”这种感觉从何而来，可以拿出你排在前十的才干，对照醒醒制作的才干卡，专门看“我需要”那一栏（航海群内领取，小程序无法发在航海手册里）。

当“我需要”那一栏被满足时，才干往往用得不错。比如：取悦才干需要不断认识新朋友，从社交中获得能量，做那些需要和新朋友打交道的事，会比较得心应手。如果一个人总被憋在家里，不能认识新朋友、得不到关注，自然就会觉得工作没劲、没意义。

# 4.1.7.2 不擅长邀功，埋头干了很多活，但升职加薪没自己

很多人在职场里喜欢埋头苦干，不懂得、或者不愿意把自己的工作成果展示给上级，最后升职加薪的名单上无名——只有苦劳，没有功劳。

## ① 这类人的才干是怎么分布的？

关系建立、执行力维度靠前，影响力维度靠后。

## ② 问题背后的才干逻辑

关系建立靠前的人，可能因为在意别人的感受、不想起冲突，即便面对不公也不一定会去“争”。

执行力靠前的人，更在意把事情做成，或者用结果说话，觉得不用刻意争取什么。

影响力靠前的人，更愿意展现自己，也更容易被领导注意到。

## ③ 可以试试这样破局（仅供参考）

积极主动交好运。别把“表现自己”等同于“邀功”。站在领导的角度想想：他们不是执行端的人，很可能根本不知道你都做了哪些事。主动同步信息，让领导看到你的“苦劳”，其实是在提升沟通效率。可以学一些汇报技巧，让自己的汇报更有重点，也更能为自己争取福利。

# 4.2.2 第二步：向外看，了解不同的职业特点

这里再分享一个我原创的工具——「职业匹配罗盘」。

为什么很多时候我们觉得方向太多、无从选择？

除了不了解自己的优势，另一个重要原因是：我们对这些职业方向缺少清晰的分类标准。我们只看到各行各业优秀的人做得风生水起，却不知道不同行业对人优势的要求是什么。结果就是这也想学、那也想试，最后不知道选什么好。

当你学会用职业匹配罗盘这个工具给职业方向分类，就能清晰判断自己适不适合。

职业匹配罗盘把职业/副业大概分成6大类：技术专家类、流程管理类、创意策划类、服务助人类、思维分析类、影响表现类。

[PRE10]

详细说说这6个类别：

**技术专家类**：
这里的技术专家不是指编程技术。这里的技术包含工艺类、动作操作类，总之是看得见摸得着的具体技术。比如摄影剪辑、收纳师、化妆师、建筑设计师、做手术的外科医生，都属于走技术专家路线。

适合走技术专家类的人，一般能静下心钻研具体事务，对事物观察能力强，不需要太多跟人交流。对应的盖洛普优势通常是执行力主导。

**流程管理类**：
也偏向跟事情打交道，但跟技术专家类不同——他们不喜欢盯着一个东西反复研究钻研，而是协调统筹各种资源、项目，安排不同的人做不同的事，或者说喜欢按照某种流程和规则把事做好。

这类工作比如项目管理、商业操盘手、电商运营、产品运营等等。对人的综合要求比较高，既需要懂跟人沟通，也需要有一定的事物管理能力。所以他们的盖洛普优势往往分布在3～4个象限——战略思维、执行力、关系建立、影响力，每个维度下可能都有一些才干。

**创意策划类**：
对创意要求比较高，比如广告创意、婚礼策划、活动策划等。如果你平时爱天马行空、各种想象，有很多奇思妙想，追求各种好玩有趣的体验，可以考虑这个方向。

对应的盖洛普优势一般是战略思维，尤其是「理念」这个才干的排序一定要很靠前。如果还有一些关系建立才干，比如「个别」，就比较适合做私人定制化的产品和服务。

**服务助人类**：
天生很有服务精神，喜欢倾听、支持、关心他人，乐于帮助他人成长、解决困惑。对应的盖洛普优势一般是关系建立才干主导。

**思维分析类**：
跟技术专家类有些类似，都可以成为垂直领域的专家。不同之处在于：技术专家面对的是具体事物，思维分析类更偏向跟抽象事物打交道，喜欢研究理论、概念、数据、信息。比如数据分析、咨询顾问、产品经理、律师、程序员……都属于这一类。对应的盖洛普优势往往是战略思维主导。

思维分析类还可以细分成2类：一类偏人文社科的思维研究，一类偏数学物理方面的分析。所以如果你数据分析能力不行，就不建议做大量跟数据打交道的工作，比如金融分析师，否则会做得很吃力。

**影响表现类**：
指喜欢也善于获得他人目光和关注，有分享欲、表现欲，能调动他人对某事的关注度和参与积极性。比如主持人、模特、配音演员、主播、博主、自媒体……对应的盖洛普优势往往是影响力主导。

要注意，不同人有不同的表现方式，不是一定站在舞台上、聚光灯下才算。有人用文字，有人用口头表达，有人用穿搭，有人用美食——这取决于你其他的优势是什么。

这么一分类，是不是感觉找到了一个清晰的规律，可以判断某个职业适不适合自己？

当然，我也猜到可能有小伙伴会问：我好像感兴趣的、或者适合的不止一个类别，怎么选？

[PRE11]

比如，我对服务助人类和思维分析类都感兴趣——这没关系。有些职业会同时具备两三种甚至更多类别特点，比如课程讲师就是思维分析类、服务助人类、影响表现类的综合体。所以以上类别可以随意组合叠加，不必拘泥于一个类别。

可能有人问：为什么没有销售类别？

因为我认为，除了一些基本底层特质，不同行业对销售的要求是不一样的。不是性格外向就一定能做好销售。像一些对技术背景要求比较高的行业，就需要你具备技术专家或思维分析类的优势。所以如果做销售，一定要考虑自己的优势是否跟行业要求匹配。

# 4.2.3 第三步：做匹配，筛选出合适和不合适的领域

根据前面的优劣势360°画像和职业匹配罗盘，整理出自己适合和不适合的领域。

[PRE12]

筛选出一些范围之后，如果需要更明确到某一个职业，就要结合自己的专业、技能、经验等其他信息综合选择。也可以去招聘网站搜索相关职业信息，看岗位的工作内容是不是自己喜欢的、技能要求有哪些。

确定自己要提升的能力，再通过报班或看书学习相关知识技能，尝试做一些这个领域的作品，同时加入相关行业的圈子，积累行业人脉资源——说不定就会被人赏识，得到一份工作机会。

很多零经验成功转行的人，往往都是有贵人带你入行。所以学习技能的同时，别忘了加入圈子的重要性！龙哥盟就是一个很好的圈子，航海又是一个个细分的小圈子，找自己感兴趣的去参加～

这里也提醒一下，做职业匹配时要注意3个核心原则：

1. 核心匹配：你的优势最好能匹配岗位所要求
2. 避免对立：避免做跟自己优势完全对立的职业
3. 创业多元：创业需要多元优势

接下来分享一个案例。这是我曾经的一个学员，他原来是头部教育公司的运营，去年转型做了OKR课程产品经理。

[PRE14]

他工作几年，一直没做出让自己满意的成绩，长期的自责让他越来越只会否定自己、否定自己做的一切。

尽管身边的朋友同事都说他很多方面做得不错，在团队里是比较受欢迎的一个人，但他始终用完全负面的态度评价自己。

比如，他会把自己能很敏感地感受他人情绪当作一种病态，也觉得自己整天琢磨一些概念、想一些似乎不着边际的东西是对现实的逃避，认为自己做事一点都不踏实，只知道空想、没有好的执行力和行动力。

经过测评、仔细研究了自己的优势之后，他才明白：原来这些他嫌弃的特点，正是他拥有的“天赋”。他的主导优势是：战略思维+关系建立。

[PRE15]

他对人的敏感，来源于「体谅」这个天赋。他也理解了为什么自己会成为团队里比较受欢迎的人——因为他总是很会关心照顾同事的感受，经常开导同事。

而他觉得自己总想太多，其实是来自战略思维的天赋。他也想起来，自己经常在团队里提出一些好想法。于是他开始逐渐正面看待自己的特质，比如好奇心特别强、喜欢搜集各种信息。

他认为工作中比较享受的是讲课的过程，跟家长、孩子沟通的时候，最让他开心。
