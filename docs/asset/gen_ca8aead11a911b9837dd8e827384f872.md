# 找对合伙人，创业就成功了一半

今年龙哥盟的全国见面会上，一个创业小伙儿跑来找我聊他的困境。他说公司营收其实不低，可年底一算账，兜里愣是没剩下什么钱。团队成员呢，干活没劲头、不爱交流、隐隐约约有种躺平的苗头。他怀疑是不是团队出了毛病，是不是自己当初选错了人。

细问下去，情况就更有意思了。团队里有几个人是从他上一个项目一路跟过来的，曾经个个干劲冲天、业绩亮眼，如今怎么就变了样？还有几个是他亲自招进来的，入职时激情满满、眼里有光，现在那道光也熄了。

其实，初创团队暴露出问题，未必就是人的错。通常有三种可能：

第一，团队没问题，问题出在产品逻辑上，商业闭环没跑通，却把锅甩给了团队能力；
第二，缺合伙人，创始人一个人既抓业务又管团队还得盯技术，又当爹又当妈，最后乱成一锅粥；
第三，人选确实错了，招进来的是错误的人，甚至是一群小白兔，战斗力自然上不去。

这小伙子撞上的就是第二种情况——单枪匹马创业，里里外外一把抓。

如今的创业环境，一个人包打天下的日子早就翻篇了。创业是项复杂的系统工程，无论做产品还是做服务，再厉害的人也得有个团队，得有几个能同甘共苦的伙伴，紧密配合去完成同一个目标。

比较常见的合伙人架构是三人铁三角，最好别超过五个人。

挑合伙人是重中之重，必须极其慎重，宁缺毋滥。我见过太多创业公司栽在合伙人问题上——堡垒从来都是从内部被攻破的。

不少创始人选合伙人时相当随意，觉得手上有好业务，谁愿意来就一起干，尤其爱优先拉亲戚、同学、朋友、老同事这些所谓“靠谱”的人。

其实是不是朋友不重要，是不是以哥们儿义气为基础也不重要，选合伙人得从这几个维度考量：

（**1**）志向是否一致

古人说得好，道不同不相为谋。志同道合是前提。

合伙人对公司发展方向必须看法一致，都向往星辰大海，才能同船共渡。

一个想做百年老店的人，跟一个小富即安的人，没法搭伙。

做事方法和道德底线也要一致，价值观得合拍。

一个想走正道经营的人，跟一个想捞偏门的人，同样没法合作。

（**2**）人品必须过关

头一回创业的人，选合伙人常掉进一个坑——只看能力。对方能力强就鼓掌欢迎。

这非常危险。选合伙人一定要看人品，德行差的人比没能力但德行好的人更可怕。这种人会把聪明才智用在算计合伙人、算计客户，甚至窃取你的胜利果实上，严重的还会连累你在不知情中成为犯罪同谋。

合伙人必须是讲诚信的人，是认可并尊重游戏规则的人。

（**3**）优势互补，每个人都是自己领域的高手

几个背包客在荒野遇上狼群，正确做法是背靠背，各自盯一个方向，才能全面防御；要是全朝一边看，大概率就成了狼群的口粮。合伙人面对激烈市场竞争也是同理。

合伙人团队必须由不同领域的专才组成，拼在一起才能形成完整无缺的能力圈。

有人擅长销售、流量，有人擅长产品设计、技术，有人擅长管理、能当政委。

各有所长的人齐心协力、互相配合，才能最大程度提高创业成功率，让公司走得更稳、更远。

（**4**）性格互补

常有客户问我，选合伙人该找性格相似的还是互补的？

我的答案是：互补的。

如果一个合伙人干劲十足、行动力超强、属于冲锋型，那就需要另一个审慎细致、三思而行的人；

如果一个合伙人脾气火爆、情绪说来就来，那就需要另一个性情温和、眼里容得下每个人的人；

如果一个合伙人耳根子软、身边红人换个不停，那就需要另一个心性坚定、专注做事的人。

你能想象合伙人都是一群牛脾气吗？那公司不成斗牛场了，业务还怎么开展。

我做过顾问的一家公司，创始人是艺术家性格，乐得坐看公司各种宫斗戏码，每个“宠臣”都想取代合伙人坐上第二把交椅，可公司还是磕磕绊绊活下来了，如今已经融到E轮。这跟合伙人恰好与创始人性格互补有很大关系。

以上是选合伙人要关注的几个问题。这些可能大家或多或少都听过一些。

我还要提一个很少有人讲到的点：金钱观要一致。

什么叫金钱观一致？先讲一个客户的真实案例。

互联网洗衣这个业务，国内最早做的团队是我一个客户，也是业内第一家拿到天使轮的团队，比e袋洗早了将近一年，还拥有自己的线下洗衣厂。

这个厂是其中一位联合创始人的自有产业，一直承接酒店布草清洗业务。

我的客户就是那位有洗衣厂的联合创始人。他发现互联网洗衣这个机会后，拉上好朋友一起干，还把CEO的位子让给了朋友。

两家人是十几年的交情，好到能穿一条裤子。是不是很多人找合伙人都这样？拉上好兄弟一起干，觉得万无一失？

结果第一笔几百万（2013年）天使轮融资到账时，大戏开演了。创始人觉得这笔钱不小，应该分一分；联合创始人觉得几百万不算啥，分了没意思，不如投进发展，以后做更大的生意。

两人因此闹得不可开交，最后创始人甚至放话要绑架对方孩子泄愤。

团队散了，业务也黄了。要是能走下去，可能就没e袋洗什么事了。

是价值观不一致吗？不一致的话做不了十几年朋友。

其实是金钱观不一致——两人眼里几百万人民币的分量完全不同。

所以合伙人在考虑所有因素之外，一定还要看彼此对金钱数量的认知是否一致或相差不大。

此外，还有几个常见的选择合伙人误区：

（**1**）让短期能帮上忙的朋友当合伙人

合伙人必须是长期、持续为公司做贡献的人。需要朋友解决短期问题，按业务付费就好。

（**2**）让思想上支持创业的亲朋好友当合伙人

创业期艰难，有些亲朋好友看好你、支持你，创始人一激动出于感恩就把人拉进来做合伙人，共享未来的荣华富贵。这种做法大错特错，选合伙人一定要以上面提到的因素为标准。

（**3**）让单纯的财务投资人当合伙人

很多创业者前期启动资金不足，就找单纯的财务投资人做合伙人，这也很不合适。

合伙人一定要选能给公司带来资源或有经营经验的人。需要带资进组的，也要找有资源或某方面专才同时带资的人，或者设置其他财务回报方式。

（**4**）选大公司出身的职业经理人当合伙人

每个创始人都有个美好愿望：找个大厂出来的职业经理人，自带光环，能解决创业路上所有难题——找方向、找人、找钱。这真的只是个美好愿望。

大多数职业经理人不愿意从基层干起，尤其不接受创业公司的薪酬体系。他们追求程序正确，过分讲究流程制度，过度依赖相关部门支援，这些恰恰是创业公司的大忌。

知道了选什么样的人，一般从哪些渠道去找合适的合伙人呢？

（**1**）向上求：找到比自己更厉害的圈层，到这些人中间讲自己准备创业的项目。接触多了，就能碰到愿意一起干的人，或者他们能帮你推荐合适的人选。

这些人有远见、有丰富经历，即使不参与也能提出不同意见，甚至帮你打磨项目。

日后你做成功了想有更大发展，这类人也能帮上忙。无论从哪个角度看，对创业者本人都大有好处。

比如你在龙哥盟里接触到的大佬们，就是典型代表。

（**2**）横向求：从自己的同学、朋友、亲戚、共事过的同事，或参加的各种社群、创业圈子里，找志同道合的合伙人。

这些人可能跟你水平相当，多跟他们聊你的创业计划，聊的人多了，合伙人自然就到位了。这也是大部分创业者选择的路径。

还是拿龙哥盟举例，里面很多和你同频、水平相近、同样想创业的圈友，就是典型代表。

（**3**）向下求：从比自己圈层稍低的人群里选合伙人，比如你职场上的下属、追随你的粉丝、你的学弟学妹等。这类人比较好找，因为你的综合能力比他们强。这跟向上求一个道理，人都喜欢向比自己强的人靠拢。

要注意一点：你得确保他们能满足你创业中对合伙人专业度的要求。

找人的核心就一条：多多宣扬自己的创业计划。

讲得越多，知道的人越多，找到合伙人的概率就越大。但要注意度，广撒网阶段不必把全部计划细节和底牌都亮出来，该保留的核心商业秘密还是要保护好。

找合伙人的过程可能漫长，也可能很快。有了初步创业想法时，就可以启动这件事了。

创业想法从出现到真正落地需要时间，这段时间边打磨项目边找合伙人，找到的人也会更贴合实际，而不是你脑海里“想当然”设想出来的那种。

已经找到几个意向合伙人，他们都表示完全赞同你的所有想法、具备你考虑的全部条件，是不是就可以一拍即合一起干了？

不，不是的。合伙人必须经过筛选。他说的不算数，他过往的案例和表现过的行为才是判断基准。

重要的事说三遍。

面试是所有判断人的手段里相对全面、相对准确的方法。

如果觉得“面试”太正式，可以“闲聊”。通过聊天弱化面试感，把面试技巧套进聊天里，隐晦地实现面试目的。

通过他的职业和项目经历判断知识、技能等专业度是否满足你的项目需要；通过他的爱好或对某些事情的看法判断价值观、金钱观是否和你一致。还能通过“闲聊”了解你想了解的一切信息。

面试之后还要做背调。从他以前就职的公司、共同好友、共同圈子，不八卦地、真诚地核实他的表述是否真实、人品是否过关。

但背调前要跟候选合伙人打好招呼，取得他的同意。

看到这里，是不是很多人觉得太苛刻、不近人情？

千万、一定不要觉得不好意思、“磨不开面子”。前期你不好意思开口的，后期都是你要背的核炸弹；前期你的Be nice，后期真就成了你的耐撕。
