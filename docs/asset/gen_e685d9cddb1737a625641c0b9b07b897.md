# 2.4.4 Layer1 与 Layer2：自建，还是外包

为方便理解，下面从各公链网络中挑出较有代表性的项目，分门别类讲清楚。

[PRE0]

如果只看这张图，背后的解决思路其实可以归为两类：自营与外包。

L1 的做法是：现有网络不够好用，那就自己做一个体验更顺手的网络来替代。L2 则与侧链思路相近，本质上属于外包——我甘当以太坊的“小弟”，负责对接，把繁重琐碎的活揽下来，让以太坊继续做它的“贵族链”；费用与速度的短板由我补齐，处理完再把关键数据交回以太坊验证。

在 L1 这一层，比如：

Binance Smart Chain（币安智能链）由全球最大加密货币交易所打造。它在去中心化上做了适度让步，以安全为前提换来网络性能的大幅提升；用户交易手续费几乎为零，速度也很快。

Solana 则创新采用 PoH（Proof of History）共识机制，交易速度明显加快，手续费较以太坊大幅下降。

再比如，以太坊联合创始人、Web3 概念提出者之一 Gavin Wood 出走创办了 Polkadot（波卡）。这个网络瞄准区块链架构的可扩展难题，希望把不同链条连接起来。可以这样理解：波卡出现前，各链就像移动、联通、电信——各自能用，却无法互通；波卡要做的，就是打通链与链之间的通信，同时改善用户体验。Cosmos 也走类似路线，目标同样是“万链互联”。

在 L2 这一层：

AXIE 侧链因一款经典链游而生。当时玩家规模太大，以太坊难以承接这款游戏的需求，于是团队另建一条新链，再与以太坊对接。

今年热度很高的以太坊二层方案 OP 和 ZK，思路也相近，区别主要在数据打包与认证机制。这里不展开具体机制，感兴趣可以自行查资料。
