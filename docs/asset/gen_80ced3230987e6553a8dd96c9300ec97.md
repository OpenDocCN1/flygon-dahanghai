# 8.3.2.2 做号的时间和门槛，实测给你看

做号这件事，到底要投入多少精力？门槛又在哪儿？我的实际数据是：从第一篇笔记发出到最终停更，累计写了30多篇，基本维持1-2天更新一篇的节奏。单篇花费大约45-60分钟，大头都耗在选题和文字创作上。刚起步时，能写的方向其实挺多；再加上我习惯在文末埋钩子，引导读者留言提问，选题根本不缺。航海实战笔记中也给出过不少挖掘选题的技巧，照着实践，把账号从0到1跑通并不算难。

至于做号的门槛，职场这个大方向底下还有各种细分：求职技巧、职场成长、工作技能……单说求职，又能分成校招、社招；社招还能按岗位继续拆成程序员、产品、运营……所以，并不存在一条放之四海而皆准的标准，告诉你到底适不适合做这个领域。我的建议是，先从变现方式这个最重要的问题切入：想清楚你能提供的变现产品，目标客群是谁，再倒推笔记方向。而不是看到自己似乎有内容可写，就埋头开工，等流量起来后才发现，根本没法转化成实际的收益。
