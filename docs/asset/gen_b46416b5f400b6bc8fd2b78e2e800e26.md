# 10.1 书单号还能怎么做 @若虚

书单带货从抖音兴起就一直火到了现在，既稳定又能赚钱，是个可以长期做下去的低成本方向。如今这股风也吹向了微信视频号、快手等平台，虽然各平台的规则一直在变，但核心玩法始终没变。

这个项目能延展的领域相当广，国学、育儿、职场、励志都能做，变现路子多得很。

抖音的书单打法已经很成熟了，素材现成，直接照着做就行；而视频号目前跑得最顺的品类，就是英语和读书这两大块。——群响创始人刘思毅

每个新平台在扩张期都需要扶持创作者、打造典型案例，所以总能捧出一批涨粉飞快、一夜爆红的账号。现在的视频号可能连红利期都还算不上，顶多处于探索期，平台自己都还在反复迭代优化，这时候抢先入场，优势反而更明显。
