刚接触选品时，别急着堆方法、追复杂模型。先把“创意中心选品法”用扎实，让账号先跑出正反馈；等闭环稳定了，再逐步升级选品能力，慢慢做出自己的差异化。

# 7.3.2 进阶型选手：同步跟小红书站内爆品

所谓进阶型选手，一般具备这些特点：素材制作能力较强、封面做得不错，而且已经跑通过正反馈。到了这个阶段，可以同步观察小红书站内的低粉爆款选品。

它和 1.0 阶段的不同点在于：某个品若已在站内起量，说明它不只是在抖音有爆发力，在小红书同样能跑，这等于又验证了一次它在小红书的适配度。

不过，同步跟品也有代价：别人已经先爆，平台内自然有竞争。想后来居上，跟品速度要快，素材制作能力也要更硬。

# 7.3.3 更天赋的选手：提前挖掘需求产品 / 高爆品

能力更强、能预判爆品的人，当然要主动挖产品。

一方面可以提前卡位：秋冬到来前，陆续铺手膜、脚膜、暖手袋；节假日前，布局出行类产品，比如化妆收纳包、高铁搭子里的毛毯和 U 型枕；夏天之前，提前做拖鞋、减肥运动器材，如滚腿神器。

另一方面可以围绕爆品发力：爆过的产品，往往还能再爆。如果技能更高，不靠别人的爆款素材和封面，而是能自己造出爆款封面与素材，那你就会成为新手模仿的对象。每一个爆款，都是天赋选手对之前爆款内容再加工的结果。

# 八、小红书 SEO

# 8.1 小红书 SEO 的底层逻辑

SEO 全称 Search Engine Optimization，即搜索引擎优化。

小红书 SEO，说白了就是优化笔记里的关键词，让笔记在搜索结果里排得更靠前。

现在很多人把小红书当成“百度”来用：70% 的用户习惯用搜索功能，吃喝玩乐前先查攻略。比如圣诞节想送朋友礼物，就会去搜“圣诞礼物”，再依次点开相关笔记。前面几篇如果足够吸引人，内容又打动人，用户就会跟着博主买同款，完成从内容种草到产品拔草的过程。

所以，从搜索入口来的用户，消费意愿通常更强。搜索流量就是超精准流量，也是能带来持续转化的流量。某个搜索词下，你的笔记排名越靠前，产品越容易被看到，也更容易影响用户的消费决策。这就是小红书 SEO 的底层逻辑所在。

# 8.2 小红书 SEO 流量介绍

明白了底层逻辑，再看做小红书 SEO 的三个好处。

1）流量精准，用户转化率高

不管你是纯博主还是商家博主，关注点无非流量和变现。流量是变现的前提，所以拿捏流量是每位博主的必修课。小红书最主要的流量入口有三个：首页推荐页、关注页和搜索页。

[PRE1]

首页推荐页默认打开，流量最大，竞争也最激烈。普通人想上这个页面并不容易，内容必须足够优质。关注页大家打开频率普遍不高，尤其关注人数一多，你的笔记很容易被淹没。搜索页则更适合普通人突围：只要有一篇笔记排得靠前，就能给整个账号带来持续流量。

而且前面讲过，搜索用户属于主动种草型，大多带着明确目的而来，流量更精准，转化率也更高。我们很多账号，搜索端来的粉丝能占一半以上。

[PRE2]

2）免费流量，不拿白不拿

通常一篇笔记的自然推荐周期在 3 到 7 天左右。即便是爆款，随着时间推移，系统在首页推荐页给的流量也会慢慢减少。平台要留住用户，就得不断补充新鲜内容；想在首页继续占位，往往只能靠广告投放维持。

搜索流量则不同：只要关键词铺对，笔记又没有违规，用户就能一直搜到你。两三个月前，甚至一年前的笔记，仍然可能带来用户。

[PRE3]

这相当于在平台里放了一个个长期有效的广告，而且还不收费。这么香的流量，不拿白不拿。

3）矩阵运营，占领赛道流量

我常跟学员说，建议做矩阵号运营，尤其是商家博主。原因有两点：

第一，降低账号风险。商家博主很多都有引流需求，但平台为了生态和自身利益，禁止一切导流。对有引流需求的人来说，常在河边走，难免会湿鞋。违规还是小事，最怕账号被封；如果 all in 一个账号，风险系数太大。

第二，多一个号就多一个流量入口，也能满足用户的“比价”心理。账号铺得够多，用户货比三家之后，进的其实还是你的账号。

当然，前提是关键词要铺对。用户搜不到你的笔记，账号再多也没用。所以，做小红书 SEO 很有必要。

# 8.3 影响 SEO 排名的因素

讲 SEO 方法论之前，先要明白哪些因素会影响笔记搜索排名。

大方向上看，影响因素主要有两个：账号权重和笔记权重。很多人不承认“权重”这个词，但它确实能被感知到。账号的活跃度、原创率、垂直率等会影响账号权重；笔记的发布时间、点击率、互动率等会影响笔记权重。权重越高，越容易被用户搜到。

而笔记权重对排名的影响，比账号权重更大。比如新人账号权重相对低，但只要关键词铺对、内容质量过关，第一篇笔记完全可能写爆。当你有一篇笔记爆了，其他笔记也会被带动，整个账号权重也会提升。

只要账号没有严重违规，正常笔记都可以被搜索到。当然，前提是笔记里要包含用户会搜的那些关键词。那么，哪些词搜得多？又该去哪里找？

# 8.4 挖掘高热度行业搜索词

用户的搜索行为虽然主观，但并非没有规律。先看看常见的搜索词类型。

# 8.4.1 选词策略

1）必要项：核心关键词

核心关键词是产品和笔记的核心，通常是产品词或类目词。以护肤品为例，核心词可以是洗面奶、面霜、乳液。你要写洗面奶种草笔记，标题、图片、脚本或正文里，至少有一处要出现“洗面奶”。

2）蓝海词

选少量蓝海词，数量控制在 100 个以内。关键词月搜索量平均在几万左右，发布内容始终围绕这些词来做。做完一轮，可以再起一个账号重做一遍，实现关键词霸屏效果。

3）关联关键词

也就是与核心关键词相关的词，结构是“核心关键词+关联标签”，有时也叫长尾关键词。比如洗面奶的关联词有：氨基酸洗面奶、敏感肌洗面奶、洗面奶测评等。

4）高转化词

高转化词就是购买意向强烈的词，比如平价洗面奶推荐、洗面奶怎么买、某款洗面奶好不好用。

5）热搜词

热搜词分热点类热搜词和行业热搜词。热点类热度更高，但不一定符合定位，比如“阳了”“小阳人”。我们通常要找行业热搜词，一般和节日、人群、功效相关。仍以洗面奶为例，可能是学生党洗面奶、某品牌洗面奶。它的特点是流量不稳定，一直会变化。

# 8.4.2 关键词挖掘方式

1）聚光平台关键词规划工具

聚光平台的关键词规划工具很好用，可以从笔记推词、以词推词、上下游推词、行业推词等五个维度选词。比如以词推词，输入目标关键词后，它会推荐蓝海词、同行买词、黑马词和高点击词，其中蓝海词和黑马词竞争力小、需求大。因为是官方平台，数据相对精准有效。缺点是只有企业号，并且已经认证开通广告功能的企业号，才能登录使用。

# 8.5 如何布局关键词

关键词布局不只体现在标题和文案里，还可以从多个维度展开。

# 8.5.1 昵称和简介

最常见的是“行业关键词+IP”的取名方式。起名时不要用生僻字和复杂英文名，一定要过目不忘、简单易记，这样别人下次想找你时记得住、搜得出，但也不能同名太多。

性别最好设为女性，以闺蜜人设更容易吸引姐妹来购物。名字能带产品就带上，这样的名字自带搜索流量。比如卖水果可以叫“xx 果园水果”，卖衣服可以叫“xxx 穿搭服饰”。

比如化妆师 Sisi。当大家搜索化妆相关博主时，只要她的粉丝量和近期互动不错，就很容易排在搜索前排。

[PRE23]

注册店铺时，记得先去小红书搜索用户名，名字一定不要重复。如果重复了，要看同名的人有没有开店。如果有人已经用这个名字开了店铺，你就不能用它开店铺；而且改名要等 7 天，非常浪费时间。

# 8.5.2 图片上的文字

图片上的文字也能被系统识别，所以别忘这个通道。一般放核心关键词+关联词，比如“养生零食”“营养师补充剂”。

# 8.5.3 评论区

评论区里的文字也参与权重搜索。用千瓜搜索热门笔记时，就有专门按评论搜索的入口。

# 8.5.4 话题标题

每篇笔记文案末端添加相关话题标签，一般是关联关键词。不需要太多，10 个以内足够，也不要加完全不相关的话题。

# 8.5.5 笔记内容

正文布局关键词，记住一个原则：有层次地铺词，切忌堆砌。同样的关键词要隔行、分段分布。每篇笔记里，核心词、关联词、高转化词和热搜词可以组合使用，但一定要自然，不要密集堆砌，否则会影响阅读体验。阅读体验不好，完读率就差，会直接影响笔记数据和权重。

# 8.5.6 标题

标题放在最后讲，是因为它最重要。标题有三个主要作用：一是概括笔记内容，让用户迅速抓住重点；二是影响点击率，好标题懂得抓住用户需求，吸引点击；三是有利于搜索，正确的标题关键词布局，有利于系统给笔记分类，推送给精准人群。

标题的关键词布局，通常需要四种搜索词中至少一种，比如：

核心词：迷你披萨❤️君君辅食记

转化词：闭口黑头怎么办？看看李佳琦是怎么做的吧

热搜词：小🐑人亲测有效！！喉咙的刀片取出来了！！

关联词：不夸张的彩色睫毛大测评！心机又特别！

也可以用核心关键词和其他词搭配，比如：

场景词：提升幸福感❗️100 个办公室养生好物🌟

人群词：梨形👭进｜请收下今日份敷衍痩腿运动✅

价格词：均 10💰好物合集‼️清洁/提亮/润唇/卸妆

品牌词：MAC 眼影盘平替！天王老子来了都说是亲姐妹

功效词：10 元冬季国货护手霜太🐂了！保湿防开裂！

本地词：杭州拱墅店的小猫求抱抱太可爱了

需要注意的是，不能为了搜索流量、为了吸引眼球，去铺和产品或笔记内容不相关的搜索词。题文不符会让用户觉得被欺骗，也是平台不鼓励的。

前期的挖掘和布局可能要花一些时间和精力，但做好之后，真的能最大化利用小红书的免费流量，让用户源源不断地找上门来。
