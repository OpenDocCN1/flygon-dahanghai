### 03. 本关回顾

所谓Hermes Agent Profile，通俗点说，就是把岗位卡和工作流写进Agent的“大脑”，让它每次开工前都自觉读一遍说明书。

前面三关，你已经做完了“招聘”和“培训材料准备”：关卡1跑通了一个最小可用Agent，关卡2明确了它的岗位，关卡3拆出了它该按什么步骤干活。到了这一关，相当于正式入职培训：要把岗位、流程、判断规则、质量标准、异常处理和人工兜底全部写进Hermes Agent Profile，让Agent不仅知道自己要干什么，还清楚该按什么标准去干。

Profile不需要第一版就完美。它更像一份会持续更新的岗位手册：先保证Agent能拿下第一轮真实任务，再根据实际输出持续补充规则、标准和异常处理。先跑起来、再迭代，永远比一开始就死磕100分更重要。

核心四个动作：

1. 创建Hermes Profile：用关卡2的一句话岗位定义，先建一个独立Profile，让Agent有自己的身份入口。
2. 写清Agent身份：把岗位卡里的“你是谁、你做什么、你不做什么、你的标准是什么”写进去。
3. 补充流程和判断标准：把关卡3的工作流、MUST/SHOULD/MAY规则、失败处理和人工兜底一并写进Profile。
4. 检查并补齐Profile：让Codex帮你检查是否缺了质量标准、自检规则、异常处理规则，先补关键项，别追求一次写完。

完成这一关之后，Agent手里就有了自己的“岗位说明书+工作SOP+判断规则”。

下一关，Agent会在这个Profile的基础上继续进化：接上工具和执行环境，从“知道该怎么做”真正变成“能自己动手做”。
