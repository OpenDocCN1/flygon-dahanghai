# 结构化提示词看着唬人，三步就能学会

很多朋友第一次见到结构化提示词，满屏英文标签加符号，第一反应就是"这跟代码有什么区别？"先稳住，别慌。一个标准的结构化提示词，通常由几个固定板块拼成：

##Constrains: 限制条件
##Workflows: 工作流程（按 1. 2. 3. 顺序执行）
##Output format: 输出格式
##Example: 参考示例
##Initialization: 初始化——让AI以某个角色身份，在[Background]背景之下，深入理解设定、严格遵守规则、使用默认参数，按既定顺序与用户对话

搞懂它其实不需要费多大力气，抓住三个要点就行：

①先整体扫一遍。别盯着细节死磕，先把结构从头到尾过目一次，混个脸熟。

②补一个小常识。Markdown语法里，#是一级标题，##是二级标题，靠"#"的数量区分层级。你只需要知道这是标题分级的标记，具体原理不用深究。

③浏览英文标签后面的中文注释。每个单词旁边都跟着解释，扫一眼、心里有数——看到这个词就知道它管哪块，对「做课」来说这就完全够用了。

# 5.2 制定课程主题

# 5.2.1 课程定位

接着来聊「课程定位」。

什么叫课程定位？一句话就能讲清：你靠出售某类产品/服务，去满足某一类人的某种需求。

拿我自己的定位举例：帮助自媒体创业者、想做副业的伙伴，用AI工具+提示词，把知识付费产品的制作和上架效率提上去。

这句话可千万别小瞧。往后的朋友圈签名、👸号简介、📕介绍——凡是自媒体上最显眼的位置，都要放它。陌生人见你第一面，问你是做什么的，你连一句话都交代不清，对方立马会觉得你：不！专！业！

定位有了，再配一个自带流量的课程名，就能正式开工做课了。

那定位到底怎么找？

对每个人来说，做什么样的课，才能让爱好、擅长、赚钱这三角色都满意？确实值得好好琢磨。

🚬 我建议你找一个安静的晚上，半夜也行，自己待在书房，或者窝在沙发里，电脑前也行，捧着手机也行，点支烟、抿两口小酒，静下心来，按①到⑤的顺序，一层层往深里想：

# 💡

① 我喜欢什么？

② 我擅长什么？

③ 我想学什么？

④ 研究对标博主，看看这条赛道有没有人已经走通，走得怎么样？

⑤ 求同存异，做出差异化

⬆️前四点不难理解，主课里有详细讲解和实例。这里单独展开说说第⑤点【和而不同➕差异化】。

举个我自己的例子。当初我做市场调研，想看看【课程制作】这条路能不能走，于是去抖音、📕、视频号、知识星球转了一圈，发现做这行的人真不少，有些规模还做得挺大。我要是不管不顾闷头冲进去，跟一堆人挤【做课】这条赛道，怕是猴年马月才能跟各位见面。我的妙招在于：切了一个特别刁钻的小角度——【AI+做课】。这下就岔开了——我还是那个做课的人，但我做的是AI做课，这就是不同，这就是差异化。所以，找刁钻的角度去切市场，太重要了，聪明人一定会这么做。

那【和】而不同又是怎么回事？不同，就是差异化，上面已经讲过了。为什么前面还要加个【和】？

还是拿我自己举例。看过我课程海报的朋友（这里不贴图了，免得有引流嫌疑）应该有印象：乍眼一看，我的自拍照、海报的色调、整体风格，就是一个老师的样子，一看就是搞知识付费、卖课的人。这一点很重要——你的形象、海报、朋友圈，看起来一定要像这行的人。如果我穿得花里胡哨，朋友圈嘻嘻哈哈，话里话外满嘴跑火车，大家还会来买我的课吗？让自己一眼看上去就是干这行的，太重要了。在【和】同行站在同一条线上的基础上，再叠一层差异化的buff，这样的差异化才是有源之水，后面才有源源不断的可能。

# 5.2.2 课程取名

课名起得好，流量跟着跑。

想清楚了做什么课，也确认了市场有机会（同行已经卖得不错），就可以正式进入做课环节。头一件事，就是起一个【自带流量】的课名。那课名怎么取才有流量？有什么诀窍？AI能帮上忙吗？

1. 四个取课名原则

# 💡

① 课程名称字数限制

② 课名中最好包含你这个行业的关键词

③ 多包含数字

④ 多体现结果、成果、效果

⬆️后三条很好懂，主课里有详细讲解和例举，我在这里重点展开第一条【课程名称字数限制】。

☞ 课名可以分为两种：

● 短课名（5-7个字）：比如《AI·7天做课营》。短课名一般用在海报、宣传图、文章标题等地方，短小精悍，好放好推广，长了确实放不下🤭

● 长课名（12-21个字）：也叫【课名的副标题】。拿我这门课来说，副标题就是《知识付费2.0爆款课速成秘籍》。长标题的作用是进一步说明课程主题，通常搭配“秘籍、手册”等词，用来吸引客户，一般放在主标题下方，比如⬇️

● 当然，直接把长标题当主标题用，也一样常见。

● 但我的观点是：小孩子才做选择，成熟稳重经验丰富的老师，当然【长短课名都要】！

● 海报、宣传图、文章题目需要贴课程名时，用短课名；上传课程平台，或者其他不限制字数的地方，就放长标题。长标题字数多，塞得下更多关键词，对引流是有好处的。

拿同行大纲做对标，主要是为了查漏补缺，力争做到【人无我有，人有我优】。比同行好一点、再好一点，客户自然买你的单，道理就这么朴素。

还有【实操】这件事。课里讲的关键步骤，只有你真正上手做课，才会意识到课程内容有多重要。举个例子，有位学员学完一遍课程，还是忍不住犯了前面说的【上来就硬想】➕【急着对标】的毛病——跑去📕找痛点灵感。

实际上，去📕找灵感属于对标案例查漏补缺的环节，应该放在最后。放到最后，对课程核心要点的形成、独家卖点的打磨、区别于同行的亮点的塑造，都大有好处。但在前期，还是建议从自己的从业经验、真实接触的案例出发，硬想。

【课程大纲】这件事，绝对马虎不得。它撑起课程的整体骨架，也是最直面客户的第一件作品，值得反复推敲！

# 5.3.2 课程大纲的「3个原则」

# 5.3.2.1 原则一：想尽办法，把课程最亮的卖点都写进大纲里

所以，第一条：课程卖点，使尽浑身解数，也要在大纲里给它最显眼的位置。
