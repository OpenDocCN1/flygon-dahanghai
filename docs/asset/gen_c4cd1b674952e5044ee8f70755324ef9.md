很多人好奇：为什么总有人主动加我微信？答案不在什么神秘话术，而在我平时怎么在群里做人、怎么经营朋友圈。

我在群里挺活跃，也愿意跟大家交朋友。时间一长，不少人愿意加我好友；加上我爱聊天，朋友圈也一直认真打理，慢慢地，有人开始为我付费，还有人把我推荐进他们自己的圈子。我的微信好友大约两万人，其中不少于十分之一，是网友自发推荐来的。这部分人特别精准：要么长期关注我、愿意帮我推荐，要么直接成了我的付费用户。

生财有术本身就是一个付费社群。在里面你会发现，很多人加的付费群不止一个。你在这里认识了朋友，又得知他们还待在其他你感兴趣的付费群里，很可能就会跟过去；到了新群，再认识更多朋友。所以，只要迈进第一个付费群，后面的付费群往往就在那儿等你。

加入付费社群时，我建议把这三类圈子都装进自己的社交版图：

第一类，老师圈子。老师们的能量往往远超我们。比如我加入的生财有术私董会，论营收我是垫底的，身边个个都是我的老师。我要做的，就是泡在群里虚心学习。

第二类，同学圈子。大家水平相近，可以互相帮忙、彼此成就。

第三类，你能成就的圈子。你在里面是大神，大家想跟你学，也愿意被你成交。

绝大多数人会把所有群都当成第三类圈子，所以一加好友就聊自己的产品。其实不对。我们要有感知力，分得清谁是老师、谁是同学、谁是我们可以降维帮助的人。机灵一点，有界限感，大家才愿意喜欢你、信任你，进而靠近你、成就你。三类圈子都要进，你才可能像一棵树苗，吸收多方养分，越长越壮。

那怎么提高别人帮你推荐的概率？我分享几点心得。

一是做事体面。朋友圈认真经营，是体面的第一步。

二是别人加我微信后，我不会上来就提产品。这能给对方安全感，至少他会觉得：把我推荐给朋友，我不会对他的朋友暴力推销，他在朋友面前也好做人。这是体面的第二步。

三是我给学员讲课时会直接说：老师缺用户，如果你跟着我学有收获，一定要帮我推荐。我这边没有推荐佣金，至今也没开通。我希望和用户的关系纯粹一些。当然，如果你判断自己的圈子可以直接谈钱，想用佣金提高推荐概率，也完全可以。

好好做人、体面做事，带来的附加值就是别人愿意帮你推荐。这部分人看起来不多，却非常精准，很值得深耕。

提醒一句：以上方法更适合小而美的模式，需要耐心、感知力和同理心。如果你追求巨大规模而不看营收，这套打法不一定适用。

案例四：售后类问题。

过了大约一年，客户主动找到我，说非常不好意思，这三盒掉在柜子里了，这次搬家才扫出来。真实情况就是她描述的那样——我确实是发了，我这边出去的货，每一笔都有记录。

# 五、怎样把朋友圈做成个人 IP 阵地

IP朋友圈是针对私域的精细化运营，也是做好个人IP变现必备的重要环节。经营朋友圈不是简单地发发广告。如今早已不是粗暴刷屏就能解决成交问题的时代，越来越多人开始意识到“卖自己”的重要性，打造个人IP也成了大势所趋。

我们邀请了一些老师，请他们剖析自己的朋友圈体系，主要是知识付费类IP。通过学习，帮大家了解成功IP的核心要点，并获得一些值得参考的技巧。

@李思念 老师，更偏向在朋友圈塑造有温度的高级感私域IP形象；@理白 老师，更偏向打造个性化、自动成交的朋友圈系统；@梁靠谱 老师，更偏向多维度、多元化地展现自己的IP定位；@宋老师 和@小鹿 老师，更偏向高成交转化、高信任度、高粘性的IP，但实现方式有所不同。

我们可以根据自己的IP定位，参考老师们的朋友圈架构和具体实操方法。

## 5.1 朋友圈如何塑造有温度的高级感私域 IP @李思念

### 5.1.1 高级感朋友圈的打造方法

先重塑一个认识：“跟谁买”比“买什么”更重要。

很多朋友会问：我直接在朋友圈发产品宣传，不也可以吗？或者以一个客服、工作室的形象经营，不也能卖出去吗？为什么一定要打造个人IP？

在多年以前，私域卖货刚刚出现的时候，朋友圈确实是随便刷刷屏就有成交，也不太讲技巧。但随着暴力刷屏增多、用户心智提高、产品同质化严重，用户对硬广告的免疫力越来越强。当下如果还是纯粹刷屏宣传产品，“自嗨”式地一味夸自己产品好，换来的只会是用户的删除和屏蔽。

如果你把自己定位成客服身份，想一想，你和用户是什么关系？是“亲，你好”“亲亲，还有什么需要我帮您的吗”，是服务与被服务的关系。这个过程里，用户只在乎产品和价格，并不在乎是谁卖给他。这其实等于在私域里又重复了一遍电商流程。而私域营销与电商最大的区别是，私域具备社交属性，是人与人之间近距离的链接。

以个人IP的形式发朋友圈，更容易拉近你和用户之间的距离，也能让你的个人形象变得可视化。用户会明白，背后是一个生动活泼、有血有肉的人，能感知你的喜怒哀乐，能共情你的生活瞬间，能理解你的创业意义。这些点的呈现，会让用户在做出购买决策时，多一层情感因素。

我们一定要想明白：对用户来说，同样的产品，去淘宝买也是买，去同行那里买也是买，为什么偏偏要通过你的私域朋友圈买？因为跟你买，产品有温度。因为你卖的不仅是一个产品，还有产品背后的情感、用户对你的信任，以及用户能从你这里获得的附加值。

像东方甄选的主播董宇辉，我之前也写过文章讲他的个人IP打造。他就很会为产品附加更多温度和意义感，也能把自己的才华体现在售卖过程中，所以很多用户会冲着他的个人魅力和即时情绪价值去消费。我们做私域个人IP的最高境界，其实也是这样：当有一天用户没那么需要这个产品，也会因为喜欢你而购买、因为你在卖而买，那你就成功了。

想通过朋友圈打造出有温度的高级感私域IP，首先要做好私域的IP定位。系统性的IP定位比较复杂，很多朋友可能因为定位卡住很久，导致难以启动。分享一个我创的“私域IP定位齿轮”，简单好理解，只要想明白四个问题，就能驱动齿轮运转，让发圈方向更明确。

[PRE6]

齿轮一：我是谁？

私域的个人IP与公域呈现有些不同。做公域时，我们需要垂直精准地呈现一个身份，让别人更快记住你。但做私域、发朋友圈，则需要立体化呈现。一个平面的人是缺乏温度的，只有立体起来才足够真实。把自己身上的多重身份都呈现出来，让用户认识到你的丰富多彩。

这里建议大家用“主定位+辅定位”结合的形式，去确定“我是谁”。

主定位，也是第一印象定位，让别人看你朋友圈时立刻能得知你的身份。这个定位要选一个记忆点鲜明、能跟你的变现产品挂钩、还能呈现你专业度的。这样别人才会在需要某类产品的时候直接想到你。

辅定位，可以尽可能多地呈现，因为我们每个人都是各种标签的集合体。大家可以先思考、列举自己都有哪些身份，再筛选出想呈现在朋友圈里的，在日常发圈过程中陆续展示。

举个例子。一位学员是宝妈，主业是会计师，副业卖减肥产品，这也是她朋友圈的主营变现产品。她曾从150斤瘦到100斤，擅长营养学，自考了国家营养师证书，同时喜欢烹饪，日常会晒很多自己做的美食。她原本的定位是“XX产品经销商”，这个身份呈现得有点硬，别人一看就觉得是个卖货的，因此好友单删率非常高。我帮她把私域IP定位改成“成功瘦身50斤的国家营养师”，先把记忆点和专业度呈现出来，新用户加好友后对她的印象就不一样了。其他点作为辅定位，在日常朋友圈里慢慢呈现，比如偶尔晒晒自己烹饪的减脂餐，点赞率都会疯狂拉升，带货变现也就变成顺其自然的事。

齿轮二：我能为你提供什么？

这个齿轮的关键点有两个：第一个是“你”，第二个是“提供什么”。

“你”是谁，也就是用户是谁。你要明白自己面向的微信好友都是什么样的人群。这里需要对自己的微信好友有详尽的了解，可以做一下用户分类管理，针对不同类型的用户设置不同的分组标签，方便未来针对性地发圈。

而“提供什么”，则是明确你所售卖的产品和附加服务。还是延续上面营养师学员的例子：她卖的是减肥产品，能带大家健康瘦身，这就是她能为用户提供的。除了产品之外，私域卖货还讲温度，所以要体现附加价值，比如能为用户量身定制减肥方案，能一对一陪伴用户减肥。这些点会增加用户选择从你这里购买的概率。

齿轮三：我为什么值得信任？

信任是成交的基础。信任在朋友圈的构建中，可以从专业度、经历、真实生活三方面展开。

继续上面的例子。通过展示她的国家营养师证书，同时在朋友圈多输出一些对减肥、健康、营养学的认知和看法，来佐证专业度。还要讲经历，比如创业经历、从150斤瘦到100斤的经历、减肥过程中的挣扎和心态。这些东西呈现出来非常容易打动人，因为同样的经历可能很多人正在经受，一篇这样的内容出来，会让对方觉得“这不就是曾经的我吗”，自然就会对你产生信任。还有就是要展示真实生活，不能让别人觉得你是假人。可以讲讲你生活里的故事，今天上班发生了什么，今天带娃又有什么趣事，等等。

齿轮四：为什么你要喜欢我？

最后一个齿轮，是你该呈现哪些点，才能让用户喜欢你。

一个人之所以被大家喜欢，身上一定有一些世间通行的品质，也就是人见人爱的品质，比如真诚、靠谱、对事业的热爱。也有一些属于个性的东西，比如你的性格、你的价值观。人各有异，这方面不要强求所有人都认同你，那样会让自己很累。

需要明白：我们注定只能吸引到与我们同频的那一部分人。我也是做了很久创业之后才发现，我吸引来的用户群体，其实都是跟我很像的，特别是三观方面很一致。这一点我觉得很好，因为同频才能共鸣，大家沟通起来才更畅通。遇到不同频的，真的是话不投机半句多，白白浪费时间和情绪。所以在做定位时，大家也要有针对性地根据自己的性格和目标用户群体来做规划。不去强求吸引所有人，才能吸引最精准的那部分人。

增添色彩：做“有颜有料”的私域IP呈现。

前面讲到了定位，但在实际运用中，很多时候你以为自己做了个高大上的定位、列了个响亮的身份标签，用户对你的认知却依旧停留在“卖货的人”。这是为什么？这其实关乎朋友圈的呈现。要如何在朋友圈里呈现个人IP呢？答案是“有颜有料”。

朋友圈如何有颜？

先讲“有颜”，它包含真实人物、生活呈现、个性表达、文案水平、整体美感度。

真实的人物，就是指你要以真实的人物形象呈现在朋友圈里，而不是一个营销号或者工作室的形象。最好有你的真实照片作为头像，朋友圈里也可以多晒晒照。配合照片，还要有生活的呈现，你的吃喝玩乐、生活琐碎，都可以分享到朋友圈里。

很多人会说自己没什么生活可晒，其实并不是这样。我们要学会聚焦目光。比如聚焦到一个小家庭里，你可以分享今天跟爸妈、老公或者孩子的某段对话，分享买了什么东西、做了什么好吃的饭，分享最近在看什么剧，等等。并非高大上的才是生活，往往越是接地气的，越能引起普通大众的共鸣。
