# 1.5.3 案例：旅游计划生成

先安装几个 MCP Server。

# 1.5.3.1 MCP 服务安装

本例需要 Excel、高德地图和 filesystem 三类服务。

# ① Excel 服务安装

下载 Excel 服务源码：GitHub - haris-musa/excel-MCP-server: A Model Context Protocol server for Excel file manipulation。有 git 可以直接 clone；也可以下载 zip 后解压到本地。

打开终端，进入项目目录：

```bash
cd 你的项目目录
```

[PRE7]

安装依赖前，请确认 UVX 已可用，然后执行：

```bash
uv venv
uv pip install -e .
```

启动 excel-mcp-server：

```bash
uv run excel-mcp-server sse
```

[PRE8]

如果要自定义端口，按操作系统选择命令：

```bash
# Bash/Linux/macOS
export FASTMCP_PORT=8080 && uv run excel-mcp-server sse

# Windows PowerShell
$env:FASTMCP_PORT = "8080"; uv run excel-mcp-server sse
```

[PRE9]

回到 Trae，添加这个 MCP 服务。

[PRE10]

粘贴下面的配置，并把 url 与 env 改成你的实际值：

```json
{
  "mcpServers": {
    "excel": {
      "url": "你的服务地址：http://localhost:8000/sse"，
      "env": {
        "EXCEL_FILES_PATH": "你的授权目录：/path/to/excel/files"
      }
    }
  }
}
```

[PRE11]

确认之后，就能看到 MCP 的运行状态以及可用功能。

[PRE12]

可以再做一次连通性测试。

[PRE13]

从测试结果就能判断这个工具能否正常调用。注意：excel-mcp-server 若以 sse 方式启动，终端需要一直挂在后台。手册现已补充 stdio 启动方案，可查看 3.4 节。

# ② 高德地图服务

打开高德地图 MCP Server 文档：概述-MCP Server | 高德地图 API。

[PRE14]

登录高德平台，然后注册成为开发者：注册成为开发者。

[PRE15]

进入应用管理 https://console.amap.com/dev/key/app，创建新应用并添加 key。

[PRE16]

复制 key，填入以下配置：

```json
{
  "MCPServers": {
    "amap-amap-sse": {
      "url": "https://MCP.amap.com/sse?key=您在高德官网上申请的 key"
    }
  }
}
```

再打开 Trae，添加高德地图 MCP 服务，粘贴代码后查看状态。

# ③ filesystem 服务

Trae 已内置该服务，可以跳过。若使用其他客户端且没有内置，可参考以下做法：在 Trae 的 MCP 市场搜索。

[PRE17]

打开预览页后向下滑动，就能找到对应代码。这里选择 npx 方式，复制后按系统选择写法。

macOS：

```json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-filesystem",
        "/Users/username/Desktop",
        "/path/to/other/allowed/dir"
      ]
    }
  }
}
```

Windows：

```json
{
  "mcpServers": {
    "filesystem": {
      "command": "cmd",
      "args": [
        "/c",
        "npx",
        "-y",
        "@modelcontextprotocol/server-filesystem",
        "C:\\code\\MCP\\MCP-test"
      ]
    }
  }
}
```

记得把目录路径换成自己的授权位置。

[PRE18]

把配置粘贴进去后，案例所需服务就齐了。
