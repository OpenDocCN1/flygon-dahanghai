# 1.1 快团团，究竟是什么？

快团团是拼多多旗下的一款私域社群团购工具小程序，能让你快速发起团购、在线统计订单并收款。

具体来说，它是为团长私域提供服务的工具，把商品和团员连在一起。不收入驻费，一键开团，服务费率低，还配有一套订单管理系统。团购、报名、帮卖、直播、订单管理、店铺等特色功能都齐了，而且入驻完全免费。

[PRE0]

快团团的本质，就是把社群和私域的能量放大。熟人经济中，每一位团长都堪称小型意见领袖。

相比拼多多、淘宝、京东等电商平台上的商家销售行为，快团团团长更像是身边的好物推荐官。它看重的，是用户建立信任后带来的超长粘性和复购率。在微信生态里，它就像是一个“直播间”——你扮演的，就相当于公域直播间里的“李佳琦”，帮团员选好品、服好务，同时也让社群的经济价值最大化。

对手里有私域流量沉淀的朋友来说，快团团能高效盘活这些存量，开团之后就能发到朋友圈和微信群里传播分享。

•快团团收费吗？

快团团小程序的所有功能对团长“完全免费”，不收年费也不抽佣。不过顾客付款时，微信官方会按交易额的0.6%收手续费，这笔费用由供货大团长承担。

电脑端操作的话，发团购、建新商品、导入导出各类订单、录入快递单号、打印电子面单并快速发货，效率都更高。PS：如果你是帮卖团长，用不用PC后台都无所谓。

•顾客下单后，钱多久到达账户？

帮卖团长卖出商品后，佣金到底会不会直接进自己腰包？还是说会在供货团长那里躺一阵？又或者要按周期结算？

这得看具体团的设置。有些大团长会设置为手动发放，如果不设置，默认就是自动发放，佣金会自动进到帮卖团长的快团团账户。

如果是默认自动发放，顾客一下单，钱就立刻到帮卖团长的快团团账户，马上就能提现，提到微信零钱或银行卡都可以，提现不收费。

提现时间和限额：

• 提到微信零钱：每天限额3000元，实时到账；
• 提到银行卡：每天限额5万，每天9:00-23:00之间，5万以下秒到账，其他时间T+1到账。
