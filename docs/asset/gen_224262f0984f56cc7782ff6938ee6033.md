# Skill Creator 安装与规划实战

Skill Creator 自身也属于 Skill，只不过它的职责是辅助你生成其他 Skill。把它看成一座“Skill 工厂”也可以：标准结构怎么搭、参数如何配、API 服务怎样接入，它都心里有数。

用 Skill Creator 能带来这些便利：

• 不用手工建文件夹和配置文件，标准目录结构会由它自动生成

• 不必从零写代码，它会依据你的需求给出代码模板

• 配置错误不用太担心，它会按最佳实践完成设置

• 支持增量更新与版本管理，迭代修改更快

此处提前安装 Exa 和 Tavily 这两个 MCP

这两个 MCP 是 Skill 获取外部信息的关键，后面运行 skills 时会用到，所以先装好。核心逻辑是：先到各自官网注册账号并拿到 API Key，再把配置指令发给 Claude Code，让它帮你自动修改配置文件。

**科普介绍**

**关于 MCP**

MCP 的全称是 Model Context Protocol（模型上下文协议），它是一种让 AI 模型能够访问外部工具和数据源的标准协议。可以把 MCP 理解为 AI 的“插件系统”：浏览器可以安装扩展插件，Claude Code 也能通过 MCP 扩展能力。

默认情况下，Claude Code 只能处理你直接提供给它的信息，无法主动去互联网上搜索资料。但安装 MCP 后，Claude Code 就可以调用外部搜索服务、数据库、API 等，获取实时的、最新的信息。

在我们这个 Skill 中，MCP 的作用是让 Claude Code 能够搜索 24 小时内的 AI 热点资讯。没有 MCP，Claude Code 只能根据训练数据来生成文章，无法获取最新新闻和动态。有了 MCP，Claude Code 就能实时搜索互联网，拿到最新资讯，生成的文章内容才会更新、更相关。

如果不使用 MCP，我们只能手动搜索资料，再把搜索结果复制粘贴给 Claude Code，让它基于这些资料生成文章。这样非常耗时，也无法实现自动化。使用 MCP 后，这些工作都可以自动完成。你只需要告诉 Skill 一个主题关键词，它就会自动搜索、筛选、整理资料，然后生成文章，整个过程完全自动化。

**关于 Exa 和 Tavily**

Exa 和 Tavily 都是专业的 AI 搜索工具，但各有特点和优势。

**Exa 的特点**

Exa 擅长深度搜索和内容理解。它不只是简单匹配关键词，而是能够理解搜索意图，找到真正相关的内容。Exa 还擅长内容质量评估，会自动过滤低质量内容（如广告、垃圾信息、重复内容等），只返回高质量的、有价值的内容。这样可以确保生成的文章基于可靠的信息源，而不是基于不准确或误导性的信息。

**Tavily 的特点**

Tavily 擅长实时热点追踪。它专门针对新闻和热点事件进行优化，可以快速找到 24 小时内的最新动态。比如搜索“AI 最新新闻”，Tavily 会优先返回最近几小时或几天内发布的新闻，而不是几个月前的旧新闻。

Tavily 还擅长多源整合。它会从多个新闻网站、社交媒体、技术博客等渠道采集信息，然后整合成一个完整的视图。这样可以确保你获取的信息是全面的，不会遗漏重要动态。

**为什么需要两个搜索工具？**

因为它们的优势是互补的。Exa 擅长深度搜索，可以找到高质量的、有深度的内容，但可能不够实时。Tavily 擅长实时追踪，可以找到最新动态，但可能深度不够。

同时使用两个工具，可以结合它们的优势：用 Tavily 找到最新的热点新闻，用 Exa 找到相关的深度分析文章。这样生成的文章既有时效性（基于最新新闻），又有深度（基于专业分析）。

**可以只用一个吗？**

可以。如果预算有限，或者觉得配置两个 MCP 太麻烦，也可以只使用其中一个。建议优先使用 Tavily，因为它更适合追踪 AI 热点。但如果只用一个，生成的文章质量可能会略有下降，因为信息来源会更单一。

**安装 Tavily MCP**

步骤 1：访问 Tavily 官网并注册

先打开浏览器，在地址栏输入 https://tavily.com 并按回车键访问 Tavily 官网，进入注册登录页面。

[PRE1]

页面打开后，点右上角的【Sign up】或【Get Started】按钮，开始注册流程。

在注册页面中，可以选择 Google 账号快速注册（推荐）：点【Sign up with Google】，在弹出的窗口中选择 Google 账号并授权登录即可，不用填写复杂表单。

如果没有 Google 账号或不想用 Google 账号，也可以用邮箱注册：输入邮箱地址和密码，点【Sign up】按钮。

注册成功后，系统可能会发送一封验证邮件到你的邮箱。打开邮箱找到这封邮件，点击邮件中的验证链接完成邮箱验证，确认邮箱地址真实有效。

[PRE2]

**步骤 2：获取 API Key**

验证完成后，登录 Tavily，页面会自动跳转到 Dashboard（仪表板）页面，进入 Tavily 的管理后台。

在 Dashboard 页面中，找到【API Key】或【API Keys】选项，通常在页面左侧菜单或顶部导航栏中，点击进入 API 密钥管理页面。

在 API 密钥管理页面中，你会看到一个默认的 API Key（Tavily 在注册时会自动生成一个），这个 API Key 通常以“tvly-”开头，比如“tvly-abc123def456”。找到后，点击旁边的【Copy】按钮复制到剪贴板，再粘贴到安全的地方保存好。

**注意：**

Tavily 提供免费额度，通常每月可以免费调用 1000 次左右（具体额度以 Tavily 官方为准）。如果免费额度用完了，需要升级到付费计划。对于测试和初期使用，免费额度通常足够。

**（三）常见安装问题和解决方案**

问题 1：安装完成但在 Skill 列表中找不到

这可能是因为安装路径配置错误，或者 Claude Code 没有刷新 Skill 列表。解决方案是：重启 Claude Code，让它重新扫描已安装的 Skill；在 Claude Code 中输入 /skills refresh 命令刷新 Skill 列表；检查 Claude Code 的配置文件，确认 Skill 安装路径是否正确。

**问题 2：提示“权限不足”**

这可能是因为当前用户没有足够的权限在系统目录中创建文件。解决方案是：在 Mac 或 Linux 系统中，尝试使用 sudo 命令提升权限；在 Windows 系统中，以管理员身份运行 Claude Code；或者将 Skill 安装到用户目录而不是系统目录。

1.3 和 Claude Code 捋清楚思路

在开始创建 Skill 之前，我们需要先把需求告诉 Claude Code，让它思考如何实现我们的需求。这一步非常重要，因为复杂需求如果不先梳理清楚，直接让 Claude Code 创建 Skill 容易出错，可能会导致 Skill 功能不完整、逻辑混乱，或者根本无法运行。

**（一）为什么要先梳理思路？**

你可能会想，为什么不直接告诉 Claude Code“帮我做一个👸号自动发布 Skill”就可以了？为什么还要花时间梳理思路？

这是因为“👸号自动发布”这个需求其实非常复杂，它包含多个子功能：搜索热点、生成文章、配图、上传、发布等。如果直接让 Claude Code 实现，它可能会：

设计一个过于复杂的方案，包含很多你不需要的功能，导致开发时间长、调试困难；或者设计一个过于简单的方案，缺少关键功能，导致 Skill 无法满足实际需求；或者没有考虑技术限制，设计的方案在实际中无法实现；或者没有考虑成本问题，设计的方案调用 API 的成本过高。

所以我们需要先和 Claude Code 一起梳理思路，明确需求的边界，确定技术方案的可行性，然后再开始实际开发。这个过程就像建房子之前先画设计图，虽然多花了一些时间，但可以避免后期返工，最终反而更快。

步骤 2：查看 Claude Code 给出的初步方案

Claude Code 会进入深度思考模式，分析你的需求，然后给出一个详细的解决方案。这个方案可能会非常详细，包含多个模块和复杂的架构设计。

比如 Claude Code 可能会提出这样的方案：

**核心架构设计**

核心架构设计四大核心模块：

热点发现引擎——多源数据采集 + 智能评估

内容生成引擎——结构化写作 + 质量控制

配图生成引擎——AI 图片生成 + 风格统一

多平台发布引擎——差异化适配 + 自动发布

关键质量保证点

热点筛选质量：多维度评估（热度趋势、时效性、受众匹配）；内容过滤（避免低俗、重复、过时内容）；智能去重（避免同质化热点重复处理）。

内容生成质量：结构化模板（标题优化、逻辑框架、SEO 布局）；深度控制（背景补充、多角度分析、数据支撑）；原创性保证（事实核查、语言润色、重复度检测）。

系统可靠性：微服务架构 + 事件驱动；多层审核机制（AI 初审 + 人工抽检）；风险控制（法律、平台、技术风险管理）。

实施路径建议

MVP 阶段：单源抓取 → 基础生成 → 简单配图 → 单平台发布。优化阶段：多源整合 → 质量提升 → 高质量配图 → 多平台适配。高级阶段：智能预测 → 个性化生成 → 互动功能 → 商业化。
