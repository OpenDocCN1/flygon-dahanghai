# 10.2 私钥守不住，资产就守不住

进入正题前，先把被骗、被盗的底层逻辑捋清楚。前面已经讲过：Web3 里的资产归私钥管，别人想骗走或偷走你的资产，最终都只能打私钥的主意。

现实中，围绕私钥下手常见两条路：

一是直接把私钥骗到手。比如把助记词记在联网记事本里，或者设备中了病毒，都可能让私钥信息落到别人手里。

二是借智能合约拿到私钥使用权。对方会诱导你在钱包里不知不觉点下授权，随后把资产全部转走。

所以，下面五条钱包安全底线，务必记牢：

- 无论何时，私钥和助记词都要牢牢看住，绝不让它们接触网络。
- 来源不明的链接不要随手点开，也别随意让钱包建立连接；不贪小利，白捡的便宜往往藏着陷阱。
- Discord 和 Twitter 上的私信同样要绷紧神经，其中夹带的链接大多是诈骗。
- 别把自己困成信息孤岛，一旦有疑问，立刻向身边朋友或社群求助。
- 主钱包的助记词要用物理方式备份并妥善留存。
