# 海外工具类应用：增长与投放实战

圈里人习惯叫我非洲水手。2019年我进入龙哥盟社区，这些年看到不少圈友在这里找到新机会，赚到起步资金，再把业务滚大。我自己在海外市场摸爬了八年，主要做工具类、游戏类应用的流量采买，现在在一家头部Web3公司负责海外用户增长。因为常年扎在移动互联网海外增长圈里，所以这次重点聊应用类产品，也期待能带来一些不同的视角。

这次我准备讲两个话题：先回顾中国工具类产品走向海外的时间线，再结合今年1月非游戏收入榜看看产品方向；后半部分拆解工具类应用的投放流程，以及数据该怎么看。

前阵子读完吴晓波的《激荡四十年》，有些感触，所以先从这二十年的行业变化说起。大致可以划成四个阶段：萌芽、起步、扩张、转型。

1998到2007年，国内互联网尚在早期，Copy to China 是常见路径。周奕被很多人视为中国工具出海的先行者，MP3 CD Maker 是最早的尝试之一，也让行业看到了第一束光。

[PRE0]

也是从那时起，大家开始意识到：工具类产品对文化差异没那么敏感。2007年，第一代iPhone和App Store发布，移动互联网时代开启，中国工具类产品出海进入起步阶段。久邦、百度、360、UC、金山等国内公司纷纷去海外布局，打法低调，赚钱却不少。

2011至2016年，行业进入扩张阶段，工具类产品逐渐分出门类：清理工具如Clean Master，影像工具如美图秀秀，桌面工具有Solo Launcher、Go Launcher，浏览器则有UC、海豚浏览器等。当时获客单价不足0.01美元，装机规模却常以亿计甚至十亿计，资本也迎来好年景。

那段时间还长出一批广告代理公司，如Yeahmobi、Mobvista、Avazu；也有猎豹CM这样自己开展代理业务的。我正好在这一阶段入行，服务过一些当年的热门产品，也见证了行业的高光。

2017年，情况开始变化。经过几年黄金窗口，增长方式更多元，变现模式也成熟得有些夸张；与此同时，海外流量红利收窄，产品同质化加重，Facebook与Google的规则持续收紧。

久邦股价大幅下滑后从资本市场退出；Google和Facebook先后禁止锁屏广告；Facebook曾一度叫停面向中国区工具类广告主的投放；Google则把iHandy、猎豹等开发者手里的数百款工具应用撤下。看衰的声音越来越多，利润空间被挤压，转型成为必然。

中国工具出海真的就此停住吗？

到如今，冲击仍未完全结束。抖音、快手、今日头条等内容平台分走了大量用户时长；个别国家政府用各种理由对中国开发者应用设限，让东方开发者遭遇不公。沉寂数年后，行业带着成长代价，转向挖掘海外用户的刚性需求。

如果要做长期品牌，可以多条线并进：官网SEO与SEM把关键词入口握在自己手中；红人合作与社群运营强化品牌认知；再视情况叠加效果广告推动商品出单，通过组合测试逐步跑出适合自己的媒体矩阵。

不过对大多数中小团队来说，性价比最高的路径还是效果类投放，核心落在搜索广告（SEM）和社交平台广告上；商业模型一旦跑通，采量就能成为放大器。

国内常见渠道包括百度、腾讯、头条；做海外则更常接触全球流量渠道。大媒体主要是Google与Meta（Facebook），TikTok如今也常被归入大媒体；Twitter、Reddit等渠道则要结合产品类型来匹配。
