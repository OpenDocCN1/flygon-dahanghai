# 💡 引流小结

引流这件事，说到底就是在和客户建立连接时，把对方引到我们提前做好的引流内容上。路径无非三类：一对一私聊、社群沟通，或者客户自己看到引导后主动来找你。我们不要主动把“🛰️”两个字挂在嘴边，谐音也尽量别用，最好借助作品、图片等内容让客户主动来加，做到隐晦但又能看懂。

另外，引流图片要多准备。小号做好的引流作品可以不频繁更换，但如果是图片或表情类引导，比如“笔尖出找我”这种图，就要多做几版。长期只发同一张，容易被平台识别。

最后，多套引流动作要一起用，别只盯着一个动作。为了大号能更稳定地运营，大小号要配合，并以小号为主。群聊引流也要注意，不要来一个客户就发一次引流图，这种高频操作会让账号活不久，偶尔发一次就够了，切记！

# 8.2 聊单转化话术

# 8.2.1 通用成交五步法

① 好感建立——破冰

客户刚加过来，第一件事不是急着报价，而是先破冰，做个简单了解。

参考话术：

你好呀，我是XX，平时喜欢搜集和整理资料，认识你很高兴。想先问一句：你现在更缺哪类资料？

② 放大需求——诊断

了解基础信息后，下一步是挖掘客户需求，并把需求放大，让成交更顺。

参考话术：

你是不是也在网上找过，担心资料不全所以迟迟没下手？或者在别人那儿买过，结果内容东拼西凑，白耗了时间？

③ 成交铺垫——方案

摸清需求后，接着给出解决方案，让客户清楚你能帮他解决什么具体问题。

参考话术：

其实一些平台也有盗版资源，但找起来费时，算下来也不便宜，你说是不是？聊了这么多，真的很感谢你。要是不帮你把问题解决，我都过意不去，一定得让你拿到结果。大家时间都金贵，你肯定也想找到一套齐全、价格又合理的课件，对吧？

④ 突破抗拒——信任

这一步不能掉以轻心，不然辛苦聊来的客户很容易跑单。客户听完方案后，心里还会有防御，怎么突破？最好的办法就是晒客户付款截图，以及对方的反馈和感谢。朋友圈的布置非常关键。

⑤ 引导下单——成交

客户的问题都解决得差不多了，如果还没付款，可以用下面3个方法推进：

1. 送限时赠品或限时低价
2. 做零风险承诺
3. 给出明确的下单指令

参考话术：

方法一：利用限时赠品/限时低价

对了，现在下单课件正好赶上活动，会额外送一份**资料，名额只有5个，下单后我发你。

还有，这两天有活动价，限时xxx元，过两天就恢复原价，错过真的会后悔。

方法二：零风险承诺

你放心拍，如果资料不是你需要的，两天内随时来找我退款，不让你承担风险。

方法三：明确的下单指令

点这个链接就能下单，拍好后把支付截图发我，我来拉你进群。

# 💡 话术原则

话术只是参考，要结合实际情况调整，能促成成交的话术就是好话术。

销售有几个核心原则：

热情大方，但也要有原则和底线。

保持利他思维，多想着方便客户，而不是只图自己方便。

回复客户要及时，不然很容易流失。

整个销售过程尽量标准化、流程化，常用话术收藏起来，减少沟通成本。

不要跟客户抬杠。遇到难缠的客户、骂人的客户、要求退款的客户，先挽回：“感谢您对我们提出宝贵意见，有您的监督，相信我们会做得更好，您先使用一段时间，实在不行再说好吗？”实在挽回不了，该退款就退款。

# 8.3.2 发圈时间怎么选

每个时间段，客户的状态都不一样：可能在发呆，也可能在工作、挤地铁，或者在聚餐。虽然不能百分百猜中对方在做什么，但同一时间段里，大多数人往往在做相似的事。比如早上起床就是吃早餐，下午茶时间就是摸鱼玩手机。所以发圈时间很关键，会直接影响转化率。

发朋友圈的七个黄金时间段：

| 编号 | 时间段 | 什么圈 | 发什么具体内容 |
|---|---|---|---|
| ① | 07:30-09:00 | 早安圈 | 一天刚开始，大家多在早起或吃早餐。 |
| ② | 10:00-12:00 | 产品圈 | 工作一阵后会休息看看圈。适合发高级感产品摄影图（养眼又养心），以及故事感软广文案（引发共鸣的小故事）。 |
| ③ | 12:30-13:00 | 反馈 | 午休时大家会大量翻圈看热闹。适合发客户好评晒单图、美图，并配上以客户对话开头的走心文案。 |
| ④ | 15:00-17:00 | 价值圈 | 工作间隙休息、喝下午茶。适合发原创感悟类文案，纯文字或图文都可以。 |
| ⑤ | 18:00-18:30 | 产品圈 | 下班吃完饭会休闲一会儿。适合以顾客角度写产品软广，结合自己对产品的理解。 |
| ⑥ | 19:00-20:30 | 生活圈 | 吃饭或聚会的黄金时间。适合发生活摄影图展示品味，写走心的生活场景文案。 |
| ⑦ | 21:00-23:00 | 复盘圈 | 睡前很多人会复盘今天白天发生的事。 |

以上就是发朋友圈的黄金时间，按这个节奏发一般不会错。
