# 半年近十万：小红书水果团购从零起步复盘

跟着盗坤老师的分享走，新手也有机会把副业跑出结果。

先交代成绩：这个项目做了半年多，累计流水四十多万，净赚接近十万；其中五月单月做到十六万流水，已经从一个尝试变成相对稳定的副业。当然，这点成绩跟大佬没法比，但对我这种此前没在工作之外赚到钱的新手来说，算是跌跌撞撞迈出了第一步。

项目起点是盗坤老师去年十一月在生财发的一篇帖子，讲的是批发市场水果团购这个蓝海方向，原帖链接：https://articles.zsxq.com/id_rsdp0lrfz4mp.html 。它投入低、容易模仿，特别适合当时还没跑通过副业的我。

补充一句：快团团后台只能截取最近三个月的记录，所以截图覆盖不了完整周期。

接下来我会用八千字左右、大概十五分钟，讲讲这个项目怎么启动、怎么从零走到一、踩过哪些坑，以及后面还有哪些困惑。如果你也是新手，我的经历或许能给你一点参照：起步艰难、中途调整、小有成绩、又纠结困惑，这些阶段大概率都会遇到。也欢迎你在其他城市实践这个项目，尽量别选北京，大家多交流；如果你经验丰富，也很期待你针对我最后的困惑不吝赐教。

我是许老师，在少儿编程行业做了六年教育人。这个行业从概念变成细分市场，我陪着一家创业公司从二十来人做到年营收接近十亿的头部，也旁观了创业从零起步的过程，职场上拿到过不少回报。但双减之后，行业前景明显不乐观，公司还能维持，增长却极其困难，我开始琢磨下一步路怎么走。加入生财以后，我一直在留意有没有能尝试的副业，最好能慢慢做成一个小业务，赚到钱再逐步做大。

在生财看了不少帖子，中间短暂试过知乎好物，也想过做小红书IP，但都没坚持下来。看到盗坤老师那篇帖子时，我确实很激动：普通人零门槛、竞争还不算拥挤、能较快见到钱，太适合我这种新手了。评论区还有不少建设性讨论，把项目关键点都点出来了。

我正好在北京，新发地又是亚洲最大的批发市场，这事能不能干？我决定一边调研一边跑市场。

调研时，我在小红书搜“新发地”“批发市场”“草莓”“车厘子”这些关键词，发现不少卖水果的账号粉丝不多，帖子互动却很好，点进去一看，评论区清一色是“怎么买”“求团购群”。这说明需求很强，也说明从小红书往私域导流是条靠谱的路。

[PRE4]
[PRE5]

这些账号里很多留了微信号，我看到就加。其中一个人从2020年4月就开始做，新发地出疫情之后一直坚持，到现在每天开团，每次稳定一百单以上，按客单价一百元估算，一个月营业额二三十万；而且她的私域并不大，三千人就撑起了这个量。有人已经跑起来，说明方向更靠谱，也让我有了抄作业的对象。

[PRE6]

线上调研的同时，我开始跑新发地。十一月中下旬，丹东99红颜草莓刚上市，新发地批发价48元一斤，同期水果店或抖音普遍卖到八十多一斤，价差里有利润空间。草莓又很娇嫩，网上不好买，水果店太贵，小红书上想买的人呼声很高，所以它很适合做批发市场团购。调研一个礼拜后，我决定从团购草莓开始。

[PRE7]

这个阶段我更加确认项目可行，也找到了可对标的优秀同行，还选定了草莓作为第一个品。

准备开干，流量从哪来是首要问题。原帖讨论里说得很清楚，不能只靠朋友、邻居那点熟人流量，一定要从外部引流，所以我直接放弃了社区宣传。另一方面，我不熟视频剪辑，又有主业，没时间做直播，于是把抖音也pass掉了。调研时发现小红书上问水果的人很多，我很快决定用小红书引流到私域。

小红书怎么发帖、怎么造人设、怎么取标题、怎么找对标、怎么打造爆款，生财里的精华帖很多，我大部分都看了，然后每天刷小红书、浏览水果相关帖子、模仿着发。到现在我仍是入门水平，这里就不班门弄斧了。

比较幸运的是，发到第三篇帖子时，那篇有了1万观看、第一次99+，前前后后加了两三百个微信，建了第一个群。那篇帖子内容非常直接：我要从批发市场团草莓，想跟团的快上车。所以来的流量很精准，都是想买草莓的人。

[PRE8]

有了第一个群，我开始发布团购。这里也吸收了帖子下面的讨论：尽量把水果卖成标品，不给客户太多选择。第一次开团卖2斤装丹东99红颜草莓，标价120元，进价48元一斤。第一次就出了50单，流量到购买的转化率20%左右，营业额7000元，毛利润1000元。从流量到转化，算是走出了一大步。

[PRE9]
[PRE10]

但团完发完货，麻烦很快来了，碰到了水果生意最常见的问题：售后。草莓太娇嫩，有快递后磕碰坏一部分的，也有说缺斤短两要补差价的——批发市场算毛重2斤，我们没特别标注，顾客按净重2斤算；还有整盒草莓被暴力快递摔全坏的。我们本着做回头生意的原则都赔到位，最后这1000元利润赔了一半。第一次真切感受到水果行业不容易。

副业就这么开始了：一周开1到2次草莓团，隔天去批发市场发货。第一个月卖了三百多盒草莓，4万营业额，利润七千块左右，小红书引流的私域四五百人，快团团转化率稳定在10%左右。

[PRE11]

团了几次后，客户开始问有没有其他水果，蓝莓、车厘子之类。当时我们对新发地还很不熟，对水果行情也完全蒙圈：哪些水果什么时候应季、怎么和批发商打交道，一点经验没有。批发商看我们面生又外行，询价时把我们当散客，报出来的价格和零售价价差并不高，导致我们迟迟上不了其他水果。品类太单一，顾客开始流失。

屋漏偏逢连夜雨。在品类单一的情况下，我的小红书因为引流时回复私信直接问客户微信号，可能触发了审核机制，也可能被竞品举报，直接被限流一个月。十二月中旬到一月底，一方面老客户流失，另一方面没有新客户来源，经营非常惨淡，营业额才一万多，基本没利润，转化率也明显下降，一度让我想放弃。

[PRE12]
[PRE13]

但当时手上也没有其他项目，同时这个项目还没整明白。如果放弃，下次再搞其他项目还是会碰到波折，总不能每次都浅尝辄止。所以过年期间痛定思痛，开始想怎么调整。

主要问题就两个：一端是后端供应链没搞好，供应商资源太少，品类太单一；另一端是流量端，需要持续有更多新流量进来。

货源方面，我们仔细研究其他同行的快团团链接，然后根据他们上架的品“反编译”，去批发市场对应找供货商。既然同行上了这个品，就证明提供这些品的商家对社群、社区团购模式比较认可。想通这点后，找货源就有方向了，不再是无头苍蝇一家家问有什么货、价格多少，而是拿着这个货去找对应商家，问她怎么供货。

打交道过程中我发现一个小窍门，能避免被当成散客：我去了会直接问老板“有没有快团团链接”。一般听懂这句话的老板就知道你是团长，直接拉群甩链接看货，订货也是快团团下单。如果没有链接但供货，就让老板拉入群。这相当于一句暗号，让老板知道你是拿货的，不是散客问价，省了很多口舌。就这样密集跑了一个月，货源整得差不多了，基本上同行有的我们也有。当然，有些供货商比较坑，后面再说怎么避坑。

[PRE14]

另一端是流量。前面踩的坑是引流时被小红书关禁闭，所以不能再私信，一定要在主页上放联系方式。后面我采用置顶笔记放微信号的方式，从一月用到了六月。中间有几次被关七天禁闭，但影响不大；前段时间这篇置顶帖子被小红书判定违规隐藏了。所以小红书引流私域怎么更安全可靠，我还在探索。这次参加小红书航海，里面提到11种方法，我还会再尝试，但这注定是和小红书平台打游击，方法需要常换常新。

[PRE15]

引流方式稍微安全点后，剩下的就是怎么发帖搞到更多流量。我感觉自己没发过质量太高的笔记，都是简单直接粗暴，告诉大家我从新发地给大家团水果。后面的帖子最多的时候1万多小眼睛、几百个互动，陆陆续续发了十几篇，总浏览量加起来可能在5万左右，引流了1500个新流量到私域。不过就是这两千个私域流量，由于我们定价比较实在、售后也靠谱，复购还可以，营业额逐渐上升，五月做了16万营业额。所以小红书流量一来很精准，都是冲着买水果来的；另一方面消费能力也确实不错。

[PRE16]

小红书引流私域，实话说我还很初阶。虽然把关于小红书的精华帖都看了，但纸上得来终觉浅，还需要在实战中积累更多经验。这里我想提一点：坚持发，根据反馈调整发帖方向，一定会有突破；如果还是没有提升，那就把小红书精华帖再看一遍照着做。另外算是个好消息，我自己稀里糊涂有了些流量，而且是本地同城精准流量，帖子质量也不咋高，但就是有人加你，可能说明这个路子还是有一定对的地方。我一直相信：在你觉得还没怎么做好就有成效的情况下，说明路子走对了；如果你已经做得很优秀但还不来流量，那可能这个方向就不太对。

流量和货源一前一后两个环节调整完，最后讲讲中间的转化环节。这里面我们经验不多，花的心思也最少，副业毕竟精力有限，大头都花在流量、选品和交付上。目前转化方面做的就是：每次开团时在群里营造大家都在跟团的氛围，开团第二天引导晒图发好评，日常发朋友圈，包括新品预告、我们吃得好的水果安利、客户好评等。这些工作在这个项目里花的精力不到5%。可能和我认为当前阶段这个环节不宜过重有关：如果选品不好、质量把关不严、售后不行，大家买完一次就不会再跟团了，运营做得再出色也没用。

这里值得一提的是，一定要怼住一个优秀竞品抄她的各种运营细节：什么时间点开团、群里发什么内容、怎么发朋友圈、选品选什么、用什么快递、水果怎么包装。只要自己能做到的先抄。这个我们也踩了坑，前面自己做了很多所谓“探索”，最后发现竞品的才是最优解，做到后面动作又和竞品保持一致了。

我认为这个项目前期启动的核心，一个是流量，一定要有找流量的能力；另一个是交付，一定要把售后率降下来，一定要能找到好水果、做好交付，这样自然而然会有好的复购。即使有些客户一开始不下单，后面看大家持续在买、看你越做越好，他也会慢慢对你产生信任，去下单尝试。目前我们转化率大概在10%左右，应该还有不小提升空间，但在此之前，我们会持续优化交付。

下面花比较大篇幅讲讲交付，因为这个项目和其他轻量化项目不太一样：其他项目解决了流量和转化基本就跑通了，而水果团购后端交付很重，又累又难标准化，各环节都有坑点。交付环节有很多琐碎日常运营，包括经常跑批发市场、找更多货源、每天关注价格行情、把控选品、和客户售后等等。但就是这些琐碎，构成了客户是否复购的关键因素。水果生意复购极高，留住一个流量，比去找一个新流量重要得多；只要留存做得好，几千个私域也可以活得很滋润。这里说说日常运营中最容易碰到的坑，每个坑踩到了都得用钱去填。

水果这个行业看着毛利润高，但不咋赚钱，最大的问题是损耗和售后。损耗这块，一旦有库存就有损耗，所以我们坚持预订制，客户先下单再去找批发商订货。这也是很多团长价格能优于水果店的原因，毕竟店租和损耗这两个成本大头没了。除此之外，我们目前只做整箱发货，不做分装。虽然这样会劝退一些客户，那些水果消耗量小的小女生基本都被pass掉了，但由于我们是副业，必须做取舍。这样做一方面减轻发货流程，另一方面也能减少损耗，毕竟批发市场都是整件拿货，拆开卖总会有零的剩下，要么自己吃，要么得有地方保存。目前我们的损耗率可以忽略不计。

主要说说售后。做水果生意，售后真是心累，什么样的客户都会碰到，什么样的售后也都会碰到，尤其我们一开始经验不足，售后概率更大。

第一种售后最致命：拿到了烂货，也就是拿货时水果品质就不行。你可能好奇，为啥会拿到烂货，检查不出来吗？批发市场里有句话：没有卖不出去的水果，只有卖不出去的价格。意思是再烂的货，只要价格够低都能卖。比如怡科莓蓝莓限量版，大家平时买三四十元一盒，批发市场正常货一箱12盒240元，三到五月有些大团长的供货价是一箱150元。觉得捡到便宜了吧？其实这个货品质不行，很多时候是蓝莓放久了，有部分已经发霉。大团长低价收回去，找几个工人把发霉坏果挑出来，把好的重新整合成一箱，当好货接着卖。这个从外表不太容易看出来坏，但客户吃的时候会觉得硬度不够或者新鲜度不够。新团长经验不足，分辨不出好货坏货，一看价格拿回去卖，一些注重品质的客户就可能找来售后。即使你售后到位，这个客户大概率也流失了，因为你的水果没达到她想要的品质标准。上面还是轻一点的拿到烂货，毕竟很多客户也吃不出来好坏，只有经常买该种水果的才能对比出来。

还有另一种情况：水果本身已经快到腐烂临界点，批发商直接低价倾销。水果都是整箱封好的，拿货时我们只能抽检，正好抽检出的那几箱是好的，就把货发出去了。但这些快坏掉的水果经过快递在常温下一折腾，到客户手上都烂了。这种情况我们发生了一两次，售后全赔的同时，还流失了很多口碑。

怎么尽量避免？第一，对水果行情一定要很熟悉，对便宜货本身抱有警惕。一分钱一分货在批发市场是非常硬的道理。这里一定要多加几家供货商，对同一货源的价格多方对比。一般来讲，差不多品质的货，几个大团长的供货价不会差太多，5%以内；如果明显低价，尽量避开。第二，对出烂货的批发商坚决剔除。因为出了一次后还会再出，他不会只卖一次烂货。我售后频繁的几次，都是在同一个大团长那边。但由于那个大团长水果品类非常全，价格也比其他家低一点，是我初期很重要的拿货渠道，出了烂货的售后后没下定决心换掉，后面果然又出了事情。这里关键点也是要有多家供货商，只有手上有足够可替代的供货商，你把她剔除的时候才不会犹豫；不然没有足够货源，剔除一个供货商可能很多水果就得下架。另外就是看平时的售后态度，如果售后推诿，一般出问题概率也大，要多加留心。第三，一定要检查。即使再熟悉的批发商，也一定要当他面检查水果，尤其是对新鲜度要求高的水果，比如樱桃、蓝莓，都是每天新到货，一定当面检查新鲜度。如果货不好，宁愿退款给客户也不要拿，这样磨合下来，批发商也知道你要什么样的货。

第二种售后是运损：发出时是好的，客户收到时是坏的。这种售后只有像我们做同城快递发货的才会碰到，那些做社区团购模式的不存在这个问题。目前的生鲜快递运输还很初级，没有冷链，快递员也很少轻拿轻放。很多水果很娇嫩，不适合快递运输，比如草莓、蓝莓、桃子、葡萄，运输过程的磕碰、晃动很容易导致水果受伤；另外就是快递配送延迟导致水果腐烂。要避免这个问题，一定在选品时就考虑是否适合快递运输，或者能不能通过包装改进让它适配快递运输。如果不行，坚决不要上，不然最后客户收到一堆被摔烂的水果，后果还是得你承担，而且这个成本大多数只能自己扛，因为快递只看外包装是否破损去定是否售后，很多时候表面包装很完整，但里面被摔得稀烂。这里我以自己的惨痛经验劝告大家，不要对快递抱有侥幸心理，一定要想象他们拿着这箱水果是各种扔，看看你的包装能不能扛得住。

还是以怡科莓蓝莓举例，它本身的包装不适合快递运输。我们前期抱有侥幸心理，只在上面加盖纸壳就发出了，没出大问题。

但有一次做活动，正赶上北京疫情爆发、快递爆单，由于包装不到位，我们发出去的60箱蓝莓最后35盒都有不同程度损伤，有的全被摔烂，有的烂的加起来2到3盒。那次光售后赔了3000多块，把利润全赔进去了，还对口碑和信心打击很大，差点emo了。你想想，一天三十几个人来找你售后，语气都不会太好，真的很考验心态。这里的解法也很简单：改进包装，把怡科莓里面每一小盒蓝莓都垫上海绵垫，让蓝莓在小盒里不要来回动；然后把这12盒蓝莓从原包装拿出来，放到泡沫箱里再发货，这样能避免蓝莓受到外部挤压。举这个例子只是说明，拿货的时候一定要考虑怎么发货：要么水果本身适合发快递，要么想办法改进包装，不然这个水果宁可不上。

第三种售后是缺货发不出货。由于我们是预订制，客户先下单我们再去找批发商订货，所以很难避免缺货。大部分批发商以批发为主，走货很快，上午这货还有，下午就没了。还有批发商给很多团长供货，有些库存管理不行，货经常卖出超量，然后先到先得，后面的就退款处理。批发商是100%保险了，但团长就尴尬了，得和客户解释为什么又缺货了，还要安排退款。这个问题我们到现在还没完全解决，只能说一下我们怎么做：一来开团时会再和各个供货商重新确认一遍库存，尽量选库存多的上架；二来团购页面会写清楚，如遇个别缺货会默认退款，让客户有心理预期；三者如果缺货量比较大，我们也会安排下次补发，然后给客户补偿一次运费，这样下次客户跟团可以省一点运费，心理稍微好受一点。

回头看，这个项目让我最深的体会是：前端要能持续找到流量，后端要把交付和售后压住，中间再用对标同行的运营细节去提升转化。小红书更安全的引流方法我还在探索，也欢迎其他城市的朋友实践交流，尽量别选北京；更期待有经验的大佬针对我的困惑多给建议。
