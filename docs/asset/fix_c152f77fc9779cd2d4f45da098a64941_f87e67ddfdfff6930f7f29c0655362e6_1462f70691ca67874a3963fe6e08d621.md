**开播先看后台：这几项指标决定流量走向**

打开直播后台，先把视线放到“内容力”里的有效进房率。这个数值一旦走高，说明曝光之后愿意点进来的人更多，平台继续给直播间分发流量的可能性也会更大。

2、观众停留时长分布（30秒/60秒/180秒）

这一项看的是观众在直播间停留了多久，以及不同停留档位各自占多大比例。平台会把观看行为拆成30秒以内、60秒、180秒等区间，再结合推荐规则判断直播内容有没有吸引力、运营能力处在什么水平，并据此分配权重层级。观众待得越久、有效观看占比越好看，直播间被推荐的概率和流量规模往往也会被放大。

3、互动率、关注率

观众和主播之间产生交流的行为都算互动，包括问答、评论、送礼、连麦；点赞、转发、分享也归在互动动作里。关注率或转粉率，体现的是主播人气上升和粉丝增长；用户点关注后能收到开播提醒，这意味着关系更深一层。两项指标越高，通常说明主播和内容更受认可、用户黏性更强，后面转化成交也会更顺。

4、礼物热度

视频号开播时，界面左上方是场观，右上方是“热度”。热度本身也是互动数据，能反映直播间当下的活跃程度，而礼物贡献在热度值里占的权重不低。引导观众送粉丝灯牌、加入粉丝团，就是很典型的拉热度动作。愿意进粉丝团的人，基本已经是账号的铁粉，后续可以长期维护、做转化和裂变，也可以请他们转发到朋友圈、社群等渠道，帮直播间继续引流。

# 5.1.1.2 成交权重：订单密度与点击转化

1、成交密度：单位时段内完成的订单量

视频号的公域推荐逻辑，主要看“成交密度+互动密度”这两股力量，它们能带动自然流量推荐；其中成交密度的分量又高于互动密度。所以想把公域流量做起来，核心是把单位时间里的成交频次做上去。

[PRE1]

成交密度对自然推荐的拉动非常直接。可以按在线人数的10%来估算目标单量：比如直播间有100人在线，就尽量做出10单。客单价是1元还是100元并不是重点，关键是争取每5分钟成交一波，连续三波5分钟成交密度叠在一起，就有机会触发平台继续推流。

2、商品点击成交率

商品点击成交率=成功下单量÷商品链接点击人数。这个比值越高，说明商品越能打，对平台扩大曝光也有帮助。可以按不同货品角色设定标准：福利品做到七成以上，承接品做到四成以上，利润品做到两成以上，以此让整体商品点击成交率维持在30%左右。若数据不达标，就要回头优化主播表达、商品链接，以及选品和排品，后文会继续展开。

# 5.1.1.3 公私域联动（重点关注）：私域带人，公域加推

视频号和抖音的一大差异，在于视频号可以经营私域，并且能用私域流量去撬动公域流量；平台也会对“把私域用户带进直播间”这件事，配套给一定的公域流量奖励。具体说，每把一个私域用户通过私域渠道引进自己的视频号直播间，平台就会按一定额度把直播间推荐给公域新用户，引导更多人进来。但如果只是拉人头、没有质量，比如进来的人不是受众、不消费、秒退，撬动效果就会很弱；反过来，私域用户进来后愿意停留、愿意互动、愿意下单，平台给的公域流量“奖励”就会更足。

1、分享

视频号直播可以转发到朋友圈，也可以让用户把直播间转到自己的朋友圈、群聊和好友那里。分享在互动动作里优先级很高。每一次转发都可能带来新增流量：比如亦仁把直播间转到朋友圈，他的朋友刷到后可能就点进来看。分享者越精准，带来的流量越大；物以类聚、人以群分，他是你的用户群体，他朋友圈里也藏着不少潜在用户。分享要全程主动争取，也要用策略去引导，但必须结合直播间找到自然的方式，切忌生硬、尴尬、强硬或机械地索要。直播间做互动有个原则：让用户做一点事情时，也要给ta一点什么，形成等价交换。

2、预约

视频号直播间可以通过左下角弹出预约，把下一场直播的预约提醒推送给当前观众，为下一次开播提前蓄水。

# 5.1.1.4 不同阶段的考核维度：起号、成长、变现三关

1、冷启动期：0-2000场观

这个阶段更看人气数据，关键是曝光进入和停留。系统会重点观察直播间的“内容消费表现”，也就是依据“曝光进入率”“直播间有效观看占比”去寻找对这类内容感兴趣的人，并在后续推荐里持续放大。如果这些指标偏弱，直播间可能很难持续获得自然流量。内容力相关数据，可以在直播间数据大屏的内容力部分看到。

2、数据增长期：2000场观-10000场观

这个阶段更看流量精准度，关键是商品点击率和支付转化率。账号核心考核“商品点击成交率”，即有多少用户点开商品、其中多少人点击后成功下单；它和下单金额关系不大，主要看下单人数和下单单量。此时用户开始从单纯看内容转向产生支付行为，平台也会给直播账号打上更精准的标签，从而把更匹配的人群推进来。

3、成交转化期：10000场观以上

这个阶段更看直播间利用率，关键是GMV、观转率、GPM千次观看成交金额。有了相对精准的人群后，平台考核会转向“流量利用率”：同样的流量，你能卖出多少，同行能卖出多少；谁给平台带来的利益更大，平台就把更多流量倾斜给谁，这就是平台的赛马机制。重点看成交金额GMV、整体观看成交转化率，也就是平台给你这些精准流量，你能转化多少订单；还有GPM千次观看成交金额，也就是推荐一千个进入直播间，你能卖出多少钱。这些都是同行竞争的关键指标，做直播就是要在关键数据上跑赢对手，才能拿到更多流量。

# 5.1.2 直播场景：用户看得见，转化才发生

行话说，场景搭不好，直播难出彩；场景搭得妙，流量跑不了。场景可以理解为用户能看到的全部画面，包括直播封面、直播画面、主播、产品包装等；凡是能让用户看见的，都算场景。外场景是直播封面加实时缩小画面，点进去后就是直播实时画面。好看、吸引人、有差异化的场景，能抬高曝光点击率、延长用户停留，也就能拉动平台更多推流。

# 5.1.2.1 直播封面、画面：第一眼抓住点击

用户从直播广场还没点进直播间时，先看到的是静止封面，再看到动态的直播实时画面。此时听不到主播声音，只能读取文字信息和画面内容。封面相当于一张海报，要装下最重要的信息，简洁明了，让人一眼知道你在做什么，把每个展示位都用起来。比如：“泰国进口乳胶枕，睡到自然醒”。直播广场里的动态场景，就是直播实时画面；画面会直接影响曝光进入率，画面有没有吸引力、能不能让人愿意点进来，非常关键。官方也明确强调过“曝光进入率”的重要性。画面里的标题可以像“一觉到天亮”“谁适合乳胶枕”这样直给。

# 5.1.2.2 直播画面中的文案特点：短、准、勾人

文案要简洁、讲主题、说重点、一目了然、有吸引力。吸引力型文案如“福利直接贴一米”“布鞋九块九”“奥莱正品撤柜”；品牌宣传型如“回力官方直播”；痛点卖点型如“三分钟搞定素颜出门”；信用背书型如某官方指定供货商、某工艺大师等。

# 5.1.2.3 场景搭建的依据因素：把货放回使用现场

同一个产品，换一个场景，传递的信息就不同，好场景自己就能卖货。要给购买者一个想象空间，让他能想到拥有产品之后的改变。说白了，就是把产品放回用户真正使用它的地方，让用户感受到使用时的状态，想象到效果。

产品视角：展示时以产品为视觉中心，例如手播卖西洋参，镜头就对准产品，突出卖点、功能和细节。重点在于：不要只拍精美包装或原始状态，而要重点呈现产品在使用场景里的鲜活状态。卖生鲜水果，就把最新鲜、洗过的水果摆出来，展示果肉；卖护肤品，就把瓶瓶罐罐从盒子里拿出来，展示质地和形态；卖电风扇，就让它一直开着、转着；卖食品饮品，就煮好、泡好，以能吃的状态展示。

整体氛围感：在茶室里卖茶叶突出高端，在仓库里卖茶叶突出性价比，做出仓播感，让人有下单冲动；在茶园里卖茶叶突出原产地正宗，在大卖场里卖茶叶突出热闹氛围。不同客单价、不同类目的产品，都要用匹配的场景塑造不同感觉：塑造科技实力就放在实验室；塑造家庭氛围就放在卧室、客厅；塑造新鲜采摘、原生态就放在果园、菜地。每个场景都要贴合人群购买偏好和产品实际使用氛围。

原产地：如果是真实且不好复制的原产地，就用最真实的场景说话，走出室内，更容易让用户产生信任。比如在新疆葡萄园里卖葡萄干，和在房间里卖葡萄干，差别很明显，吸引力和信任度都不一样。

产品的包装：卖产品还是卖包装？用户是通过镜头感知产品价值感的，视觉效果很重要，很多产品包装比产品本身还贵。

产品的摆放：一个陶瓷杯放在普通桌面上、放在木制盒子里、放在打着灯光的玻璃柜里，呈现出的价值感完全不同。

# 5.1.3 直播话术：留人、建信、促成单

# 5.1.3.1 拉流话术：让门外想进、门内不走

目的：要数据、破层级、做权重。简单解释一下拉流：进直播间的人就是流量，用一两句简短且和对方有关的话吸引他们，把人留在直播间；外面没进来的人听到有福利，也可能进来看看。进来的人不出去，持续留人，在线人数就会越来越高；留下的人多于离开的人，在线被拉高，就说明拉流成功了。

示例口径：欢迎刚进来的姐妹，这里是专业某品类直播间，主播手上这顶帽子专柜价899，今天只收邮费，想要的打1；丝绸面料，适合某类姐妹，名额已经报了一些，还剩一些，两分钟后上架，后面还有福利给大家。

执行要点：简单清晰告诉观众你在卖什么，并给出留下的理由，比如马上发券、仅限今天、马上改价、稍后还有福利。

# 5.1.3.2 立人设：用背景换信任

有背书、做信任，本质是回答“为什么你要听我的”。重点在于摆事实、拿证据、讲故事，让人信服。

示例口径：我们家是帽子工厂，有3000平方厂房、100多个工人，一天能生产一批帽子，长期给品牌做代加工；这款帽子贴上商标就是大几百，你看这个款式在某宝某猫上卖多少（配合道具做价格对比）。

执行要点：说明产品靠谱，再给理由，比如技术背景、源头工厂、全网热卖、口碑好评等。

# 5.1.3.3 讲主题：把今日活动讲清楚

有主题、有逻辑，说明我来干什么、为什么这样做。

示例口径：我们家一直做线下，最近刚来线上，准备做自己的品牌。大家都知道，开店也好、做直播也好，先得有人；我们也不太会直播，所以准备拿一批礼物出来，姐姐们啥也不用做，待着领礼物，帮我捧捧人场、热闹热闹，稍后2分钟一轮安排，不耽误大家时间，今天的福利还有不少。

执行要点：增强信任，讲清楚今天为什么做活动，给出让人信服的理由，也让后面的活动和利益点顺理成章。

# 5.1.3.4 点对点：读公屏做成交

体现专业度、容易成交、有故事感。可以请水军带动没有互动的人。示例：某位姐妹打了1，给她留一单。

# 5.1.3.5 塑品话术：抬高产品价值感

从更高维度塑造产品。不是只围绕材质、工艺打转，而是从更高角度把产品和价值关联起来，常用词包括大牌同款、纯手工制作、明星同款、进出口等。

1. 痛点需求：引起共鸣

2. 产品卖点：为什么买？能解决什么问题。

3. 价值塑造：讲故事塑品、类比品牌

示例口径：（手工款）这个版型出自京派旗袍非遗匠人之手，京味十足，上身更显女性气质。想了解的话，北京大栅栏有这位匠人的店，去逛能看到同款。

# 5.1.3.6 转品话术：自然过渡下一款

无中生有、顺其自然、利他口吻。示例：刚才有人问眼镜还有吗？这副是回馈老粉的，昨天答应过，新朋友先等等，这波结束再给新朋友安排福利。

# 5.1.3.7 催单逼单：给今天下单的理由

为什么今天买？今天不买会损失什么？开价后可以多留一点时间让用户拍，但要营造紧迫感。示例：大家手太快，库存没了，后面也补不了。还有占着单没付的吗？再留一会儿，超时不付就把名额放给真正要的人。

# 5.1.3.8 保障话术：把顾虑提前打消

买了后悔怎么办？看了没用怎么办？不满意怎么办？要给出承诺。示例：我在这承诺，全部正品，假一赔十。质量检测报告和相关部门认证都摆在这。收到货不满意，七天无理由退换。老客户反馈一直不错，已经帮上万名客户处理过问题，放心下单。

# 5.1.4 直播间货品攻略：选、组、排、测

# 5.1.4.1 选品：货盘定胜负

产品会影响打法、主播、场景和人群。视频号选品可参考几个维度：优先爆品，其他平台跑得好的品可以搬到视频号再卖，借助蝉妈妈、抖查查、飞瓜看各品类销量榜；有货源优势，电商最终拼供应链，供应链强是硬优势，优先考虑；贴合视频号人群，平台以40岁以上二三线女性为主，她们没被其他直播电商反复教育，不太比价，退货率也低；推荐品类包括服饰箱包、滋补食疗、零食特产、美容护肤、日用百货。

# 5.1.4.2 组品：搭配出更高价值

组品要因品而异，要有组合思维，为抬某个产品的销量可以设计搭配。关联组合：搭周边，比如防晒霜配隔离霜和面膜，鞋子配袜子。拆分组合：把整体拆开，比如眼镜配镜盒和镜布。

# 5.1.4.3 排品：安排上架顺序

排品要依据直播脚本，符合价格从低到高、成交难度从易到难的逻辑，提前设定好主播表达。钩子品：负责开播拉流量、做互动和停留数据；特点是用价值感高的标品低价挂车，比如苹果手机1000块、四个哈密瓜1块钱。福利品：负责做成交密度；以标品为主，大家对价格有认知，而且你的价格确实比心理价位更划算，下单门槛和决策成本小；价格相对低，比如5包纸巾1块钱、一袋洗衣液2块钱。承接品：负责承上启下、丰富直播间品类；中间价位，比如几十块钱的东西，可以有微利。利润品：可以是几十也可以是几百，利润率高、毛利率高，能带来较高收益。形象品：直播间做形象的价位，比如3980不卖，用来衬托其他利润品便宜。

# 5.1.4.4 测品：用数据决定换不换

任何产品都有生命周期，产品也要拿到直播间检验，用户行为是判断是否更换的标准。测试产品受欢迎度，主要看销量。通过弹购物车观察用户点击率：曝光点击率高，说明用户对这款品感兴趣，所以后台要经常盯数据，随时做好换品准备。让主播在后半场介绍产品做测试；也可以把产品放进直播场景或让主播佩戴，引出话题讨论，比如水军带节奏：主播你带的项链很好看，多少钱？主播你身上的衣服卖不卖？

# 5.2 【新增】图书/百货直播案例分享

# 5.2.1 图书直播：低门槛的长期赛道

书籍类目包括：国学、中医、养生、当代经典文学、中小学生课外书、人物传记。视频号图书类目直播带货，这个项目在视频号平台已经跑了两年多，在抖音平台有四五年历史，因为从抖音有直播带货开始就有了，现在仍有很多账号在播；仓播卖图书一直有不少号在做，销量也不错。它适合普通个体入手，从侧面也能看出这是一个可以长期做的赛道，主要方式就是直播卖各种图书赚佣金，无需自己发货，找后端的微信小店挂到橱窗，开播前上架到小黄车即可。

目前视频号图书类目直播有两种形式：一种是露手开播，也就是俗称的手播，不需要真人出镜，目前在视频号依旧能跑，也适合新手最快拿到正反馈；另一种是真人出镜，需要布置吸引人的场景，比如仓库背景或书架背景，也就是俗称的仓播，近期还有更简单的做法，买一块实景画布即可。下面介绍两个项目的概况和完整操作方法。

# 5.2.1.1 模式一 露手直播 无需真人出镜

第一种模式是图书手播直播间，也可称为单品图书主推直播间，因为这种模式全场主要推一本书，一般以历史国学或中医类书籍为主。在视频号直播广场搜索图书，就能找到很多类似的对标直播间。账号一：六个多月卖了四千多单，单价也挺高，利润不错。
