# 提示词越清楚，文章越对路

先看一个很基础的指令：只给主题，不限定文风、结构，AI 也能写出像样的文章。再换成更细致的指令，成稿往往更理想。原因不复杂——要求越明确，模型越能读懂我们到底想要什么。

这套示例让 AI 扮演擅长捕捉内心情感的小说家。动笔前先确定主要人物和情感主线，再沿主线展开情节，适时加入戏剧冲突和转折，让情绪有起伏、有升华。人物要往深处写：喜怒哀乐、心理波动，遭遇之后如何自我怀疑、挣扎、成长，都得让读者跟着揪心。细节也不能少，小动作、神情变化、环境烘托，能把场景撑起来，但别堆得太满，以免拖慢节奏。语言要细腻委婉，准确传递情绪；比喻、拟人可以适量用，别华丽到抢戏。最终目标是让读者身临其境，和人物一起悲喜，读完还能产生共鸣和思考。行文可以带点真人写作的松散感，适当引用流行语、典故、梗，增强时代感和真实感。开头要“开幕雷击”，第一眼就把读者抓住。

这套提示词还要求：先构思再创作，人物刻画要有深度，细节描写要服务情感。这些正是一篇情感故事能否打动人的关键。示例还提出围绕 # 💡 提示词解析写一篇两千字以上的文章。下面换个提示词，对比同一主题下的出文效果。

# 7.1.4 不同内容方向的写法

不同赛道有不同写法，但从创作逻辑看，可归为两类：时事类和非时事类。时事类指近期发生、AI 知识库尚未收录的内容，比如某款汽车的参数、爆发的战争、明星八卦等。这类内容若直接仿照范文来写，成品多半不符合事实，发布后可能涉及造谣、捏造，所以不能靠模仿范文解决。非时事类就好理解得多：AI 库里已有，或者不依赖新信息也能写，比如情感故事、心灵疗愈、职场心得、生肖星座等。这类内容可以模仿范文，因为它们多为虚构内容或文化总结，不包含时事信息。

时事类怎么写？思路很简单：AI 不知道的，我们先告诉它。比如要写《全红婵夺冠》，先搜索相关文章，找几篇信息较全、彼此有差异、有信息增量的，整理成文档上传给 AI，让它先学习。若涉及争议，要把事情来龙去脉理清楚，也可以整理评论区内容，尽量让 AI 了解全貌，表达更客观。之后再用提示词创作。不同赛道需要不同风格，可按喜好选择。提示词重点抓两个方向：一是写作风格，比如风趣幽默、通俗易懂、生动有趣、言辞犀利、口语化表达；二是文章结构，开头写什么、正文写什么、结尾写什么，分别指定。约束到位，文章就更合口味。

# 小结

利用 AI 的模仿能力，找优质文章当范本投喂，可以快速写出不错的稿子；再配上好提示词，质量还能更上一层楼。这样做不需要事先复杂调教，新建聊天后直接对话就能创作，能省下不少时间。复杂赛道，比如社会热点、娱乐八卦，除了好提示词，还要把相关事件素材喂给 AI 先学习，再让它产出优质文章。

# 7.2.1.3 列故事大纲

让 ChatGPT 按选题写大纲，不满意就改到满意。指令大意是：根据选题写一个 1500 字短篇故事，采用线性叙述、以时间顺序为主线；带一点现实主义倾向，语言平实生动，容易引起共鸣；内容要像真实发生的事，让人感兴趣、有读下去的欲望，情节曲折，有“开屏雷击”效果，贴近普通人生活，最好写家长里短、婆媳之间、家庭伦理；先给出故事大纲。

这里有个提效小技巧：用不同指令建立多种大纲模型，以后写某类文章时就能直接调用。比如指令一，让敏感且熟练的作家写一个情感深度和人性探索兼具的故事，第一人称，开头介绍主角家庭背景和个人简介，给角色取名，让读者感同身受并思考类似问题，1300 字以内保持紧凑。示例里，主角是 28 岁男子杰克，父亲是出租车司机，母亲是医务工作者，他在小公司做市场专员；另一主角是 49 岁房东艾米，离异多年，儿子在外地工作，她做会计。发展部分写两人从房东房客到互生情愫，以及杰克表白；冲突部分写艾米拒绝后两人的尴尬和矛盾，以及心理变化；解决部分写电视机故障事件让两人感受到关心和陪伴，艾米在酒意下接受爱情；结局写艾米提出结婚，双方家人反对，但他们仍决定领证，展现爱情的力量和年龄在爱情面前的无关紧要。指令二，让作家围绕“爱情迷阵：丈夫异地工作，我却无法抵挡公司领导的温柔陷阱”写情感纠葛和道德冲突故事。先交代女主个人与职业背景、与丈夫的关系、丈夫异地工作的原因，以及她和公司领导关系的初步轮廓；再写丈夫离开后她的生活变化，尤其与领导不正当关系的发展，准确写出心理挣扎、内疚和恐惧；然后设计危机，比如丈夫突然回家或同事发现秘密，促使她反思并寻找解决办法；最后安排反转，可以是忏悔坦白，也可以是接受自己的行为并面对后果，让读者理解人性并对未来有所期待。故事用第一人称，开头介绍家庭背景和个人简介，给角色取名，让读者感同身受，1300 字以内，节奏紧凑。

# 7.2.1.4 分块写正文

ChatGPT 生成的文章有范式，常见“1、2、3”或“首先、其次、然后”，机械又程序化。别指望全自动或批量生成就能质量很高。与其一次产整篇，不如分部分详写，提出重点描写内容、字数限制和其他要求，完成后合并，原创度大概能到 60%。指令大意是：写事件开端，占 30% 篇幅，限 400 字以内；在“风格 A”基础上采用第一人称口述，语言平实；生动、易共鸣；多写行为、动作、语言，少写内心想法；不要扩展其他内容。
