# 从踏空百倍到稳定吃肉：我的BRC20实战笔记

有一阵子我专门盯大额买单的地址流向，注意到一个规律：这些单子大多砸向刚冒头的新项目，而进场的人画像高度雷同——全是怕错过、刚入场的新手。当时我带着偏见没去mint，结果眼睁睁看它被市场炒到百倍。这之后我换了打法：碰上热点炒作标的，直接把gas拉到50～100去抢，到手立刻在二级市场甩掉，锁定十倍以上收益。按这套逻辑，我又在insc上投了500美元打新，最后落袋1万美元。

#### 12.3.1.4 Gate进场阶段：从欢呼到反目

五月初，Gate放出消息要上ordi、pepe、meme这些主流标的。BRC20圈子一度沸腾，大伙以为“正规军”总算来了。ordi上线前那一晚，uni的二级市场和OTC撮合热得发烫，meme一度摸到1000美元一张。等ordi真正开盘，半天不到，单张价格就飙到29000美元。

可惜好景不长，Gate紧接着把bank这类垃圾标的也推上台面，众人这才回过味来：来的哪是正规军，分明是一茬接一茬的收割机。提现受阻、疯狂上币等操作轮番上演，骂声迅速蔓延。短短五天，Gate在圈内的名声跌穿地心，社区里甚至冒出“反Gate联盟”，把它的罪状一条条列出来。平台价与链上价之间的裂口，最夸张时拉到20～30%。

链上gas向来是fomo情绪的体温计。被这一通折腾之后，亏了钱的人不再死磕打新和二级接盘，gas重新跌回30聪。收割的、狩猎的、新来的，全都安静下来，盯着下一次出手的窗口。

这一阶段我的做法与思考：「在情绪里找机会」——守住初心，落袋为安；行情向上是卖方市场，囤货为先；行情向下是买方市场，现金为王。ordi到28美元时我出掉半仓，等它回落到7～12美元再补回来；顺手零成本撸了100张pepe、300张meme。当情绪把uni和Gate的价差推到30%时，我搬了约2万美元的砖，赚了30%。

#### 12.3.1.5 土狗乱舞阶段：机会越多，越要会挑

五月中旬，各路角色粉墨登场。

协议层面，orc20、ltc20、drc20、brc721等接连冒头；项目方这边，圈内老炮、精英创业者、群友自创项目轮番上阵。机会数量暴涨，反倒让不少人挑花了眼。

更微妙的是，BRC20给推特大V装上了“喊单即变现”的引擎。一个新热点只要被大V点名、社群一转，有时半小时就抢光。面对良莠不齐的推荐和真假难辨的信息源，跟风成了常态。

这一阶段我的做法与思考：「看情绪、评项目、提炼打法」。我只打头矿，坚决不接二级的盘。靠着ltc、orc、brc721等头矿打新，加上oxbt这类质地不错的新标的，我手里攒下了好几个百倍币。

#### 12.3.2 新老标的的入手逻辑（DYOR）

下面聊聊BRC20当下，新人该具备哪些基本功，才能用小本金撬动机会。

第一梯队：ordi。第二梯队：pepe、meme、$OG$。第三梯队：SHIB、wzrd、domo、rssc、vmpx。第四梯队：其余标的，逢高兑现，换到前三梯队。

先把自己的目标刻在脑子里：其一，尽快变现、让生活变好；其二，尽快回本，之后拿利润继续玩，别让投资反噬日常。

挑选时看这几点：1）部署越早越占优。2）老外占比越高越加分。3）背后有项目方且越硬越好，比如rssc、wzrd、vmpx。4）持币地址数越多越稳，底线是1000人。5）按眼下流量，代币分配数量的门槛大约在2.1万份。6）有无庄家运作、能否形成热点炒作，比如OXBT、nals、piza。

#### 12.3.3 新人上手的正确路线

1）把unisat和xverse两个钱包用熟，能收发btc和铭文。2）掌握至少两种Mint工具，完整走一遍Mint流程。3）会看链上gas，依据拥堵程度设好参数，并能在链上确认交易状态。4）结合自身情况，配老标的、等打新、玩链游，或者参与tw的代币抽奖。5）路子有千万条，安全永远第一条。
