# 挖到一家小红书宝藏手机壳店，低粉也能爆单

作者：  落落

日期：2023-05-10

小而美店铺观察第4期——这家小清新手机壳店，真藏不住了

入榜条件挺特别：粉丝量不算多，销量却高得离谱；选品在线，不靠复杂带货套路，也不用出镜露脸。

先看带货表现：粉丝不到2万，销量竟然冲到十几万，确实让人惊叹。店里价格带大概在15到30元；同类型在拼多多上零售价能低到5到10元。

选品方向也很清晰：以iPhone手机壳和AirPods硅胶立体保护壳为主，走清新、可爱、时尚路线，客单价比安卓手机壳高出一截。毕竟手机和耳机都舍得买，配个质感好点的保护壳也顺理成章。

带货方式：用视频展示，一只装饰感很强的手动态呈现产品，把质感拉满；视频封面做得精致，第一眼就有点击欲。

它的特点在于氛围统一：店铺风格、视频风格和布景彼此呼应，心思都藏在细节里。

标题写法也很标准：适用机型加风格描述，流量基本靠视频封面扛。
