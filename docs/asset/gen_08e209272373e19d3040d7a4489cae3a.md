# 8.3.2 关注+点赞，小V更易回粉

在社交媒体上做账号，主动关注别人是冷启动阶段最直接的一种涨粉方式。这个方法与前面提到的批量账号引流思路一脉相承：只要你关注了某人，对方就会收到通知，自然注意到你。但与那种撒网式的大规模关注不同，用精心运营的账号去关注别人时，重点在于 follow back 的比率，而不是数量。也就是说，要尽量精准地找到那些对你的产品或内容真正有需求的受众，才能提高对方回粉的可能。

那么，该去哪里找这些受众呢？我的经验是，先锁定同类账号中粉丝数还没到五万、帖子互动特别活跃的小V，然后从他们的粉丝入手。这类用户相对容易回粉。可能有人会疑惑：为什么不直接找那些几十万甚至几百万粉丝的大V？说实话，我也试过，但结果回过来的，基本都是自动回复的机器人，以及一堆营销推广号，真实用户屈指可数。后来翻了不少同行前辈的经验帖，才慢慢搞清楚其中的门道。所以，最稳妥的做法，还是从中小V甚至小小V的粉丝入手，别去大V那里浪费时间。

另外，关注完之后，还有一个值得一试的小技巧：翻出他一个月前发的帖子，认真点上几个赞。这样对方会觉得你认真看过他的主页，而不是随手一点就划走，对方愿意回关的可能性也会高出不少。
