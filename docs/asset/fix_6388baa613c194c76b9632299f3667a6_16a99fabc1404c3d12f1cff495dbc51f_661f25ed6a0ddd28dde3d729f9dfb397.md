# 3.5.6 直接运行 Python

在 Cherry 里做数据分析，MCP 之外还有一条路径——调用它内置的 Python 执行能力。没错，它能在本地直接跑 Python 脚本。

以往 AI 写完代码，我们得手动搬到编辑器里执行；如今在 Cherry 界面内就能一键运行。操作方式举例：先让它“按月统计订单数量，输出 python 代码即可”。

不过此时 AI 的回复中并不会出现代码运行入口，还需要完成一步配置。

[PRE9]

前往左侧“设置”面板中的代码块设置区域，启用“代码执行”及下方相关选项。完成之后，代码块旁边便会浮现运行按钮。

这里有个前提需要说明：Python 运行在 Cherry 的沙盒环境中，与本地机器并不连通。所以想直接让 Python 处理本地文件是行不通的😓，但执行其他纯计算类 Python 脚本没有问题。毕竟这属于新上线的能力，真正打通本地文件交互，还需要等待 Cherry 后续版本迭代。

# 3.6 用 MCP 订高铁票 @成峰

出门旅行，最让人头疼的是哪一步？订票。高铁票、机票、各类 App 轮番切换，线路、票价、时刻混作一团；家里人还不停追问“票查了没”。每次都想：要是能有个帮手，把路线、价格、时间统统捋清楚，再附上几点专业参考，那可就轻松了。

# 3.6.1 过去与现在：订票体验大不同

从前订票的流程是：先开 12306 搜高铁，再转到飞常准查航班，然后折回来比价格、看时刻，反反复复让人头晕😵‍💫。偶尔还会漏掉某些线路，或者与更划算的搭配擦肩而过。

# 3.7 用 MCP 办一场名人聊天 @成峰

整理旧书时翻到《人类简史》里的一句话：“农业革命是历史上最大的骗局”。我停下来，脑海里冒出一个设想：要是能找几个人一道聊聊这个论断，比如让马斯克、孔子、尼采同席而坐，那该多有意思。

[PRE26]

这个设想站得住脚。平日里读书，我们往往被作者的思路框住，划了满篇重点，说到底还是在单向接收信息，缺少真正的观点交锋，未免太单薄了。很多时候，最深刻的洞见恰恰来自不同视角的碰撞。等等，我似乎可以用 AI 把这个设想落地。

没错，我要让历史人物一起读我的书。只需要微信读书 MCP 加 Trae 就能实现。试想一下：你正读书、划重点，忽然马斯克、孔子、尼采和萨特围到你身旁，就你划出的那句话展开热烈讨论，是不是有点小激动？😏

我试着让他们讨论“人类是唯一会相信故事的动物”，结果很精彩：孔子认为此论甚妙，人之所以为人，正在于能以礼乐传承智慧，这是故事的本源；马斯克把故事看作人类第一个虚拟现实，从进化角度看，这是构建火箭和殖民火星的认知基础；尼采说故事即权力，弱者用故事安慰自己，强者用故事塑造世界，这是超人崛起的起点。看完这些观点，我的第一反应是：这比 AI 单纯总结书籍内容高到哪里去了。每个视角都带来全新启发，像真的参加了一场跨时空头脑风暴。

别担心，这个“思想派对”很容易举办。我已经踩过坑，现在教你 0 基础复制操作。三步搞定跨时空读书会：1. 获取微信读书划线；2. 设置名人辩论阵容；3. 享受多维度思想碰撞。读再多的书，不如与思想者一起思考一本书。
