# 10.2.3 案例三：别在 Discord 踩坑

Discord 上潜伏着不少骗子，盯上的往往是刚接触 Web3 的新手。常见套路主要有两类。

第一类，你加入的所谓项目群本身就是假的，群里的一切内容都是为了设局。有人曾误信这类假项目方，花重金买了一堆假 NFT。第二类，群是真的，但会有人冒充管理员来私聊你。

面对这两种情况，关键做法是：进群链接只认官方发布渠道，先确认自己加入的是真群。寻找官方渠道时同样不能放松警惕。骗子伪造官方身份的花样很多，假官网、假 OpenSea 官方认证都很常见。比如配图图1里那个蓝V认证，并不是平台授予的，而是有人自己P到头像上的。

遇到第二种情况，不妨先给自己定条规矩：凡是主动来私聊你的，统统先当骗子看。Discord 里有安全私信设置，开启后可以屏蔽掉一部分主动私聊的骗子。
