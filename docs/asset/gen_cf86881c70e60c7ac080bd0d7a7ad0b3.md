# 6.1.3 门店拉群，入口不止一个

实体店想把顾客沉淀到🛰️群里，其实没有想象中那么费劲，关键在于把入群入口铺得足够多。

下面几种做法可以直接参考。

店员在接待、导购或收银时，可以顺口邀请顾客进群。连锁品牌还能把入群按钮放到🛰️、支付宝的支付成功页，让顾客付完款顺手就加群。店门外摆易拉宝或立牌，顾客扫物料上的二维码，也能直接进群。

如果顾客是买完东西带包装回家，包装里的卡片同样能承担邀请入群的功能。

餐饮门店也不例外，等位排号的时候，排号本身就能顺势建群。

说个挺有意思的事：在排号这个细分领域，除了各家小门店自己，真正有垄断级体量的团队叫美味不用等——很多人用过，却未必记得名字。

截至2020年6月，这家公司已覆盖全国352座城市，为超过30万家餐厅提供智慧餐饮一体化解决方案，每年服务的消费者接近10亿人次。

规模有多夸张？翻出我手机里的🛰️截图就明白了——留意那一排绿色的“xx个朋友关注”。

这家公司早年扩张很快，融资也接连不断，但商业化路径一直没真正跑通。眼下我观察到的打法是：把等位排号群和同城美食营销结合起来，比如在群里发优惠券，用庞大的群规模继续往前推。

聊到这里，就不得不提瑞幸和蜜雪冰城的社群营销。

赚钱圈里加过这两个品牌消费者群的人应该不少。很多人好奇它们的群运营思路，最后往往只剩一个疑问：难道就是反复发优惠券，没有别的招了？坦白讲，确实没有。

那群里是不是没什么社群氛围？确实如此。

这类门店数量庞大的品牌群，本质上还是为业务服务。只要把“线上发券、到店核销”这一件事做扎实，再依靠足够大的规模实现薄利多销，价值就已经很足了。

在这个体量下，如果往群里硬塞太多环节，为了氛围而氛围，反而会加重直接运营社群的门店或城市运营中心的负担，也容易重蹈前面提过的覆辙：只从舒服的体验出发去设计社群。

当然，规模这么大，如果能做加法、并且加准地方，对社群在意的业绩和体验也会有提升。这很考验对社群的直觉和理解，不妨留作一道开放题，供大家在航海过程中一起探讨。
