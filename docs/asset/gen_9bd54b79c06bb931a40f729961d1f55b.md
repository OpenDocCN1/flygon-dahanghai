# 3.1 怎么找对标账号

# 3.1.1 对标账号得满足哪些条件

做视频号、视频带货，对标账号一般要符合这么几条：

专攻单一品类的达人（有没有这类账号，决定我们能不能找到下载视频的来源；数量多不多，决定我们能不能挑出最好的）

某个达人的视频数量够不够多（决定我们能参考多长时间。要是只有 10 条，那肯定远远不够用）

达人的点赞数据、销量数据（看看他们在抖音上做得怎么样）

要提醒的是：二次剪辑、混剪类的账号尽量别选真人露脸的视频，很容易被作者投诉，导致视频下架甚至账号被封。

1、热点思维

# 3.2.5 基础剪辑与原创内容

建议的视频处理方式：混剪、二创、原创，不要直接搬运。

短期来说，可以通过更精细的混剪来规避审核。但如果想长期获得稳定收益，原创是更被鼓励、也更应该走的路。

建议学习下面的剪辑方法，在实际剪辑过程中把部分内容——比如产品展示、书籍展示、部分画面或背景——替换成自己实拍的素材，用来通过平台的原创审核。

比如视频的脚本结构是：

黄金开场+产品介绍+使用展示+同行对比+优惠活动+引导购买

其中“产品展示”可以用自己实拍的素材，或者其他平台的产品好评图、好评视频素材来替换。

选题拆文案：参考近期爆款

爆款视频证明平台算法有流量倾斜，原创爆款非常困难。所谓“创意都是老元素的新组合”，建议新手先从复制爆款开始。

通过逐渐积累素材库和拆解，找到爆款文案的感觉之后，再去组合创作自己的爆款。

下载对标视频，用飞书秒记或者其他转文案小程序，把口播视频文案扒下来转存为文档

内容拆画面：把握前五秒

视频前 3 秒和 5 秒完播率很重要，做短视频要在开头吸引大家的注意力。吸引注意力后，还要及时引导用户点赞、评论、转发、关注。

场景拆卖点：激发购买欲

通过产品场景化的介绍，把功能、特性、价格优势等讲清楚，引导客户认同产品，拉高购买欲望。

促单拆话术：引导购买/进直播间/预约直播

视频号用户很多不会购买，或者不知道如何买，需要有引导；但平台不断监管优化，强引导会被限流甚至封禁，建议适当增加互动引导。

比如“你觉得好不好，评论区聊聊吧”，评论区放评论置顶，引导到主页橱窗购买。

可以在视频爆量的时候开播，并在视频挂直播预约组件，这个功能非常好用——账号开播时，用户🛰️会有强提示“你关注的主播已经开播了”，预约进入率非常高。
