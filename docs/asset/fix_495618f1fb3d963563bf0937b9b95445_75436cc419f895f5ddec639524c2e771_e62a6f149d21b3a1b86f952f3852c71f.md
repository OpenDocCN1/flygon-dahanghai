# 中老年内容付费：普通人的新窗口

先说判断：银发人群的内容生意，近两年正在打开一个难得的缺口。

圈内就有人把简谱教学搬进直播间，带着学员认谱、唱谱，边教边转化；没有音乐底子也不耽误换方向，书法、国画等都能试。

我从2019年起扎进中老年内容项目。两年时间里，投入不算重，营收和用户数据却都往上走，还延伸出多个中老年内容付费与电商项目。围绕银发内容生意，我积累了一些实战感受。下面用四个问题，聊聊普通人做中老年高客单内容付费时，新的流量入口和机会在哪。

一、为何押注银发内容生意？
二、中老年消费者有哪些偏好？
三、近两年市场发生了什么变化？
四、2023年普通人还有多大空间？

先自我介绍一下：渔火，创业者，仍在路上。很久没输出，先交代近况：2021年，我参与联合创办的项目拿到真格领投的千万级融资；我主导的中老年项目则起步于2019年。

最近不少生财的朋友来问中老年方向。我和银发用户打了四五年交道，一位83岁老人也买过单，多少有些心得。我也真心觉得，这群人很可爱，只要认真交付价值和服务，就会有回响。

回到2019年：我为什么选银发方向？当时找细分口子，我先看行业演进逻辑，我认为这是赚钱的关键。以内容付费为例，成人领域从知乎时代，到罗辑思维会员、樊登听书、付费问答、订阅课，再到课堂专区、圈子；对应教培，则从线下、线上、一对一、大班小班、社群、AI课、训练营、行动营一路变化。能看出来，行业是随用户习惯和认知升级而演进的。

K12巨头的竞争强度大家都知道。普通人得找更好切的路。拿银发方向一对比就发现，中老年内容付费还处在很早期，像未开垦的地。可以预判，随着时间推移，内容和形态会越来越丰富，这就是机会。人上了年纪，反而更有钱、更有闲为兴趣买单。

只看兴趣生活类，琴棋书画、诗词歌赋、针灸养生、摄影朗诵、茶文化、手机技巧、花艺园艺等，调研下来都有小团队在低调赚钱。我看准后便入场，一直做到现在。

再补一组官方数据：2022年收官时，全国60岁以上者约3亿，占总人口19.8%。45岁以上人群规模有多大，可想而知。

[PRE2]

今年我明显感到，银发方向的关注度和入场者都多了不少。但很多朋友并不了解这批人，所以我先聊他们的行为习惯。

这几个月我蹲守各平台银发内容评论区，观察高频词，常看到“老人不网购”“银发人群手机都搞不定”“我开养老院亏了”之类说法。看完我意识到，很多人对这批人的行为和消费习惯存在严重误判。

都市银发是抖音八大人群之一，我原以为不少人会了解；小镇银发确实难做，但都市银发是有钱有闲的群体。我的项目把有效用户定在一二三线城市40—75岁，效果不错。

觉得中老年人玩不转手机？移动互联网发展这么多年，山沟里都有WiFi。看看我母亲，1968年生，我帮她搭了个视频号，三十来天粉丝到1.6万。

她每天直播加橱窗，能卖800—1000元货。她用的是红米手机，现在还是红米。前两年手机都不熟的人，如今也能上手。所以别低估中老年的学习力，也别小看下沉市场。

你以为中老年只买便宜货？分享我的数据：课程单价500—2000元不等，用户平均复购3门以上。书画类用户每年在笔墨纸砚和印章上花约2000元；艾灸等健康方向客单更高。很多中老年退休后，有人随子女在国外生活，有人在大城市带孙，有人回老家，但这不妨碍他们追求兴趣和生活。

结合我的经历，这几年大致分三段，只谈内容付费为主的方向，硬件、APP、电商等今天不展开。

2008—2015年是萌芽期。那时很多人不知道银发方向怎么做，平台偏流量打法，后期变现也弱。糖豆广场舞等垂直APP在那几年吸了大量流量。

2015—2019年是野蛮生长期。美篇等社交平台，墨客、墨池、快乐50等垂直机构，养老家政、健康睡眠等项目兴起，线下老年大学名额难抢，音乐相册、天气工具快速发展，吃到一波红利。

2020—2023年是高速增长期。大厂开始入场：红松短时间内拿到蓝驰、经纬两笔数千万美元投资；知乎合伙人出来做老年项目；尚德、大鹏（已倒闭）、高途等也入局。我体会很深，2015到2018年，中老年内容付费相当野蛮。

分享一个数据：早期公众号投放不需要技巧，书法、国画课的ROI能到20，复购率也高。什么概念？月投5万元，能卖100万元，客单轻松拉到2000元。关键是获客便宜，当时进群用户成本约5元，还是垂直兴趣粉，不是泛流量。

同期，幼教和K12打得火热，优质母婴流量从几十元一个涨到一两百元。我的项目启动资金只有小鹅通平台费、老师录体验课的费用（最早卖期货，有体验课和长期课大纲就开卖），再加首月投放，总成本不到5万元，第一年营收滚到200多万元。

我总结，这得益于此前做幼儿赛道的经验。做过K12或幼教的人进入老年方向，做课、服务、营销几乎是降维。近两年，大厂进场教育用户，更多垂直内容付费机会更大。

[PRE7]

别一提银发方向就只想到养老院、高毛利保健品、送鸡蛋、广场舞。现在的银发族和前几年不一样了，移动互联网发展这么多年，大部分赛道都值得用银发人群重做。社交、健康、衣食住行、兴趣、线上工具等维度，都藏着机会。

随手举几个最近较火的例子：老年Keep、老红书、老年家政、老年睡眠、老年文娱、营养健康管理、科学带孙课程等，太多了。

从我的角度看，原因有几点：

（1）流量侧：触达形式更多元，视频号等中老年聚集的短视频平台，加上美篇这类垂直平台兴起，带来更多机会。

（2）用户侧：大公司进场，用户认知和习惯被逐渐培养；中老年对服务的感知和认可超过品牌加持。哪怕是大公司的课，只要服务好、更贴近需求，一样能卖。在他们眼里，大公司和你没区别。而且都市银发已经能熟练下载APP、转发评论、打开小程序，各种支付也玩得溜。

（3）产品侧：中老年方向产品匮乏。别的赛道做到120分才有机会，这里做到60分就可能有机会。曾经音乐相册、天气软件几个月就能获取几百万流量。

不过要注意，流量阵地和产品形态要选好。说实话，我测过很多主流渠道，有用户后也测试过多种打法。测下来，微信体系内和视频号路径最顺，抖音和线下也还可以，这里不含电商玩法。

[PRE8]

（班级群作业圈，大字手机也爱分享）

对普通人、个体来说，搞流量或做课程，机会都很大。如果你没有产品技术能力，我更推荐个体去做课，真的香。

我现在从生活、兴趣两个大维度，大范围做轻课测试。有朋友觉得这需要专业技能。说实话，我最初完全不懂书法国画，只懂用户和流量。课程找对应专业的人录，老师出大纲，我结合用户需求修改审核；很多方向找个大学生，极低成本就能产出专业课程。

拿最近做的电子琴课举例。之前有朋友说，一听电子琴，还是老年人学，觉得小众，能有人买单吗？我告诉你，音乐方向在银发内容付费里市场不小，快乐50、红松学堂等规模不小的公司都在做，客单很高。

需求挖掘这里不多说，可以看我之前在生财分享的文章：https://articles.zsxq.com/id_pt1urnv5g4ah.html 。挖掘好需求后，要快速做MVP验证，解决流量和产品问题，因为变现靠卖课。于是我用视频号测老年人音乐方向，比如老歌混剪、乐谱、唱谱、乐器，测了一圈，引流效果不错，前期流量基本能按这个跑。

产品是重点：做银发内容付费，最重要的是懂用户。不同课程大纲，售卖结果可能天壤之别。我累计和几千名用户深聊过。起初我追求详情页优美、小鹅通装修美观、海报精致，后来发现这批人根本不在乎。他们报名最看重体验课内容、老师水平是否认可、服务是否满意，以及长期课能否下载、永久回看。有几次AB测试，淘宝花1000元设计的详情页，居然没打过我用懒设计10分钟做的绿背景、大字堆叠长图。

（相对品牌，很多用户更在乎可下载和时效）

[PRE9]

所以切记，产品不必华丽。多和用户沟通、了解需求、定好课程形式——录播加直播，还是全直播、全录播——然后定价、售卖，大体思路就顺，剩下在执行中优化调整。

除了常规内容付费类目，再举几个我最近见到团队在做的例子，也是我深度调研的方向。

① 老年家政
家政市场很大，这几年发展也好，圈友里有做得优秀的。目前老年家政多是子女给父母下单，服务包括打扫卫生、做营养餐、测血糖、擦湿疹药膏、陪同散步聊天、陪同看病煎药等。

[PRE10]

打法类似云家政，只是获客模式和方向有差别。可以看看天鹅到家上老人服务，订单量已经很多，只是服务项还偏单一。

② 中老年睡眠
前段看数据，《国民睡眠健康白皮书》显示40岁以上人群睡眠问题大且逐渐加重。我了解数字睡眠市场，已有好睡眠、享睡等APP，还有音乐助眠结合的白噪音产品。睡眠问题很复杂，原因多元。

[PRE11]

普通人可切三个方向：一是教程类，用超低价课教大家使用各种助眠产品；二是心理、情绪疏导课程；三是身体健康管理，比如请营养师规划晚餐，或教夜间运动改善睡眠。

③ 中老年旅游
数据看，中老年旅游增速很猛。年轻人常做攻略，中老年怕被骗，我妈一提旅游就怕被宰。普通人能否做中老年定制旅行攻略，收一点服务费？同时给靠谱旅行社引流赚佣金？视频号里旅游、风景类视频有多火，去看看就知道。

④ 中老年电商
中老年电商不用多说，星球不少书友做得好，还有卖图书的书单号。和几个团队聊过，目前卖得最好的是女装和鞋，尤其鞋利润率高。这块不多分享，有资源的朋友可考虑。

④ 中老年宠物
宠物方向这两年发展快，我觉得幼教有的，都能在宠物方向重做。之前看报告，全国每年新生儿约1000万，宠物猫5000万、宠物狗3000万左右。我调研发现，养狗人平均年龄比养猫人大10岁，约37岁。发现没？平均年龄已靠近中老年，可想而知中老年养宠人多，养狗更多。

宠物打法可以试试。我给我妈做的就是宠物账号，她1968年生，自己出镜公信力更强，目前运营约一个月粉丝1.7万。

（上面是1.6万，这里1.7万，因为写稿期间涨了1000粉）

商品橱窗加直播——我妈直播纯聊天，没技巧，人在老家——每天能卖800—1000元宠物用品，佣金30%左右。每天私信多，几乎都问养宠问题，其实百度就有，但他们不会，也没这习惯。这里需求和想象空间很大。下一步我可能不让她直播卖货了，毕竟直播需要能力，她学起来难。可能走直播引流，到私域卖产品再扩展。如果接入AI，能否做个性化问答，“中老年的私人宠物医生”？能否出针对中老年养宠经验的课程？篇幅问题不展开。
