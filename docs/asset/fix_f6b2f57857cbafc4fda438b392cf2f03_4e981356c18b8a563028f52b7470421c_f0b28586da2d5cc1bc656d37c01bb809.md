# 4.2 用新微信号接住流量

# 4.2.1 微信账号的冷门常识

做这个项目时，最好单独注册一个微信号来接收引来的粉丝。随着粉丝量变大，微信号的数量也要跟着增加。账号的外在形象同样重要，包装质量直接影响成交率——尤其是朋友圈，把朋友圈当门面来经营，信任感会快速建立，第一印象也会很加分。

1）一个微信账号能加多少人？

刚注册的新号，好友容量通常不大，也许只有几百人。使用时间越长、活跃度越高，上限就会逐步放宽。长期正常使用且信誉良好的账号，一般能加到5000人左右，目前实测最多能破万。每天加好友和被加好友没有次数限制，但短时间大量操作会触发异常提醒。

所以作品爆了以后，别让用户一窝蜂涌进来，最好分时段放人，一小时放一批，否则对方会被“操作频繁”卡在外面。

# 4.3 微信号快速包装法

# 4.3.1 怎么起一个好记的微信号

微信号一年只能改一次，下手前一定要想清楚。

建议先把候选名字写在纸上，至少写10个，再一个一个地去试。为了客户容易搜到你，也注意两点：别带特殊符号；别用大写字母。

一个让人过目不忘的微信号，核心就四个字：短、好读、有规律、有个性。微信号一般是字母加数字的组合，相当于你的账户专属ID。下面是六条实用设计法：

1. 用名字缩写：姓名的拼音首字母或英文名缩写，比如李华可以用“lh”，个人色彩浓又好认。
2. 加入生日或纪念日：在缩写前后添加对你有意义的日期，比如“lh1985”或“lh1688”，故事感一下就出来了。
3. 挑好记的数字：重复数字（“888”）、连续数字（“123”）、幸运数字（“2021”）都行，如“lh888”“lh2021”。
4. 控制长度：不超过10位，6～10位最理想，短了别人好记，长了别人嫌麻烦。
5. 避开复杂符号：有些平台虽然允许特殊字符，但为了报号方便，最好只用字母和数字。
6. 先读再查：定稿前多念几遍，顺不顺口；再去微信里搜一下是否被占用。

按这个逻辑，张伟（生日1990年1月1日）的微信号可以设成“zw900101”或“zhangwei901”。

要是看了原则还是没灵感，就靠九宫格键盘凑。国内用户大多习惯九宫格，微信号按3～4个字母+3～4个数字来，比如adgm1234、mpt220。

注意几个容易踩的坑：

1. 容易混淆的字母和数字别用，比如i和1、0和O、u和U，这类不好区分的直接放弃。
2. 取字母时，优先用九宫格键盘上每个格子的首字母，比如ABC格的A、DEF格的D。
3. 能小写就别大写。大小写其实不影响加微信，但小写更省事。
4. 如果做矩阵账号，微信号也可以排排队，比如mpt220、mpt221、mpt222。万一mpt221被封了，用户着急时可能会自己往旁边试，去加mpt220或mpt222。
5. 别把手机号当微信号发给用户。你连另一半的手机号都未必背得出，就别指望用户记住你的号码。

# 5.1 步骤一：找到值得对标的账号

# 5.1.1 什么样的账号值得对标？

在任何一个内容平台上，先模仿同行的成功账号，都是高效做内容的方法。所谓对标账号，就是跟你处于同领域、同类型的账号。创作时，可以从它们的图文/视频形式、话题切入点等方面学习。

判断标准如下：

⭕ 粉丝数要少：1万以内，超过1万的暂时不看；
⭕ 点赞数要高：赞数大于粉丝数，说明内容有干货、有价值；
⭕ 时间窗口选最近一个月：周末流量大，只看一周的数据没有参考价值；
⭕ 主页频繁出现：刷主页时总能看到同一个封面，说明这个账号值得对标，直接抄作业就行。

想要做出爆款，核心就四块：选题心法、封面做法、标题起法、内容写法。

按数据体量，爆款可以分为：

⭕ 小爆款：点赞+收藏+评论总数≥200
⭕ 中等爆款：点赞+收藏+评论总数≥1000+
⭕ 大爆款：点赞+收藏+评论总数≥1w+
⭕ 超级爆款：点赞+收藏+评论总数≥10w+
