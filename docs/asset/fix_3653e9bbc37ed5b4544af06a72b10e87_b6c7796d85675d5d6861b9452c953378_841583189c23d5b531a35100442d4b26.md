# 3公里500人起步，本地小店靠短视频拿下132W次观看

各位生财的朋友，我叫大芽。前一年，我两次以志愿者身份参与生财活动，既开了眼界，也做出了一点小结果。先向商业IP小航海、生财大航海台前幕后的伙伴们说声谢谢。

2018年我注册并养过一批抖音号；2019年踩中带货机会，赚到第一笔像样的钱。模式很朴素：镜头里摆产品，购物车挂淘宝链接。两个人全年跑出三百多万营业额，毛利率约一半。那阵子还运营过一个搞笑号，最高一条作品被看了四千多万次。

后来疫情冲击，行业里高手云集，带货推荐量明显缩水，我不得不寻找新方向。判断很明确：未来仍要看短视频平台，所以新尝试也围绕它展开。

去年四月我加入生财，目的就是找方向。恰逢商业IP小航海招募，我以志愿者身份深度参与。生财的机制给我的感受是不断打磨、逐步完善。

航海中我做了首个商业类主页，分享平台玩法和网赚项目。孤狼老师的方法确实奏效，关注数很快过千。但那时平台审核严格，我因文案里诱导性措辞过多，主页被限制。

老师建议另起新号。我评估后放弃：同类内容已经扎堆，我很难做出差异。

但我没离开这个平台，而是一边找可匹配的项目，一边补认知。于是又报名大航海志愿者，在助人中反哺自己。

如今我把主要精力放在一家实体餐厅。借本地门店号，这家店曾冲到我们当地热门榜首位。下面复盘这几个月的实操。

**—01—**

项目缘起

2019年我做的是短视频卖货，当时平台免费推荐量非常可观，购物车挂着也可能获得千万级自然观看。那是名副其实的窗口期，也让我更懂平台逻辑。

再后来，卖货作品推荐量一路下滑。刚好有朋友介绍了一个餐饮项目。

这家餐厅由我出资并参与打理，品牌不是我自己创的；在此之前，我没干过餐饮。

我挑餐饮项目时，会看三件事，供参考。

第一，味道过关。这是普通顾客的底线，有复购，店才活得久。

第二，能否和我的长处嫁接。直白说，就是适不适合拍短视频。这里借蛋蛋老师提到的三个可视化：出品、空间、服务，都得能拍出来。

第三，复制难度。产品是否过度依赖某位厨师，换个人能不能顶上；跑通后，我能不能迅速再开第二、第三家。

这个品类本身不差，我又懂短视频，于是判断用线上给线下引流可行，便转去开店。

**—02—**

主页定位与规划

短视频平台底层是内容，电商、广告、本地生活都依附于此。主页要跑起来，事先规划不能少。

筹备期间，我约了几位做短视频的朋友聊。我的店是实体餐饮，如果只拍菜品，内容会单薄且重复，很可能停在五百次观看左右。

考虑第一次开店，我最终选“开店手记”：把筹备过程同步发到平台。店还没营业，号先动起来。

通常说做号要先定方向、做垂类、圈人群。但做本地曝光，未必一开始就锁死人群。

我的餐厅主打18至30岁年轻人，可内容不必只围他们转；我要的是更大范围的同城触达。这跟把店开在人流旺的街区一个道理：人流够大，目标客自然会来。

所以本地号别太纠结内容垂直，先把本地注意力抓住，思考哪些题材能勾起本地人兴趣，从而拿到同城推荐。

我用的是新注册的号。首条作品只有一句话：终于决定开家小店，给我一点鼓励。文案就这么简单。

前期规划帮了忙，开局顺：首条作品留言不少，观看量破万；之后按第一天、第二天连载，基本都能冲出基础推荐池。试营业时，本地展示量已有二十多万。

接下来要做的，是持续在同城露脸，让更多本地人记住这家店和它的业务。

**—03—**

运营做法

十月接手铺面后，我发出第一条作品，之后把装潢到营业全过程都记录下来。

这类内容有连续性，平台观众也吃这一套，比如家装、店装过程。它能带来一部分关注，而我更想要的是以店为中心、三公里内的本地人。

我的底线是：每发一条，周围三公里至少五百人看见，就够用了。

具体分四步：

**1.** 拍摄素材

做本地生意，画面得让观众觉得是附近人拍的。所以多收街道、铺面镜头，制造熟悉感；再掺一些日常片段，不必精雕细琢，随手记录即可，但别拖沓冗长。

**2.** 剪辑

短视频平台节奏快，没名气时内容不能贪多。

我的作品基本控制在一分钟内。一天事很多，不必全塞进去；起号阶段一条只讲一个点，十几秒交代完，再用剪映串起来。

封面直接打上“在惠州开店第几天”，同城页里有人看到本地字眼，更愿意点开。

[PRE4]

**3.** 发布前的几个小细节

⑴. 挂POI：起号时一定带位置。店还没门牌，可以先借周边小区、酒店等热点。我最初挂的是离店约五百米的一家酒店，也没问题。有地标，同城推荐才更准。

[PRE5]

⑵. 选合适的热门BGM：配乐和话题都影响分发。这靠平时养出的网感，我在大航海日更群聊过。办法是刷自己号的作品，把反复听到的配乐记下来；若某段时间同一段音乐频繁出现，多半正热门。点进去看使用人数，几十万人在用就试。首条作品就是靠这招选到上升期配乐，之后一直沿用；同一段音乐也会变成观众的记忆点。

[PRE6]

[PRE7]

⑶. 话题：本地号要挂本地话题。我在惠州做餐饮，通常带#惠州 #惠州美食 等标签。

⑷. 标题：我会埋问题，比如“你能想象它长什么样吗？”“惠州哪里有冻品市场？”“店里要招人，你来不来？”从留言能看出来，只要抛出问题，观众就愿意接话；交流数据一好，推荐也会增加。

**4.** 发布后的动作

前期每条留言尽量回，多和观众聊，才能把人引到店。

个别作品我会投一点Dou+，但整个号至今只花了二百五十元。投过的作品大多有几万观看；那些十几万观看的，全是自然推荐，没投。Dou+只是添头，内容才是根本，交流数据好，系统照样会给量。

[PRE8]

**—04—**

转化与收益

上面这些细节，给餐厅带来了累计一百五十多万次展示，而我只付出二百五十元Dou+成本，等于省下大笔推广费。

做本地号，最终要把人引到店里。现在堂食和外卖都还行。

营业后常有客人说，一个月前就刷到过我的作品。短视频确实能提前种草；店离顾客不远，刷到后心里留个印象，哪天一馋就来了。

基础动作做好，同时尽量日更，让店持续在同城出现。一天、两天，甚至三五天，附近的人总能刷到。有人看完短视频，还会顺手去大众点评查评分和菜单；这个动作又帮我们在点评端维持热度。本地大众点评西餐热门榜，我们连续两个多月排在第一。

到今天，店里生意还不错，第二家店已在筹备。偶尔在外吃饭会被人认出：“这不是福记老板娘吗？”号持续经营，观众会记住你，生意差不到哪去。

接下来我准备开直播卖店内团购套餐。平台工具越来越全，实体商家做推广和增收都方便。

**—05—**

给后来者的建议

**1.** 做有持续性的事情

看我首条作品，刚发时只有几千观看；随着后续更新，新观众会往回翻，一直翻到第一条，如今它已积累九万六千次观看。

这正是我当初选开店手记的原因：和只展示菜品的餐饮号相比，这个号在生长；内容有连续性，数据会越滚越好，可操作空间也更大。

[PRE12]

**2.** 主动下场做短视频

这几年我在这个平台试过不少项目。整体判断：它值得长期投入。大玩家有大玩家的打法，普通人也能找到自己的位置。

如果你有实体店，我强烈建议开个号，性价比很高，值得长期做。若还没想好做什么，不妨先规划一门小生意，卖什么都行，先想清楚怎么赚钱，再进场做起来。
