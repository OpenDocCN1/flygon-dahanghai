# 日本跨境还有套利窗口：关税壁垒里的蓝海品类

作者：跨境杨少  
日期：2021-12-14

跨境电商这几年越来越卷。国家连续在两会提到大力发展跨境电商，新人加速入场，行业从少数人知道的暴利场，变成竞争激烈的红海。很多新卖家来自国内红海电商，也带来了9.9包邮、低价螺旋、“吴三柜”等降维玩法。美国亚马逊已经很难再叫蓝海，蓝海品类快速减少，即使冒出来，也很快被价格战打到无利可图。原本的“蓝中蓝”行业，正在滑向“难中难”。

这时，小语种市场因为语言门槛和本地化门槛，仍保留着一些蓝海特征，也藏着信息差品类和套利空间。本文重点看日本市场，以及日本海关壁垒下的一个类目套利机会。

-01-

**跨境电商的起点和本质是套利**

2009年我入行时，这个行业才发展没几年。早期代表性品类有3C小商品，比如手机壳、贴膜、挂绳，还有婚纱、假发、cosplay、高仿等，主要平台是ebay。常见做法是不压货、不建海外仓，人民币进、美元卖，国际直邮自发货，把传统国际贸易里的进出口公司和层层代理分销挤掉。

举例来说，400元人民币的偏高端的婚纱，卖400美元，仍只是美国市场原价格体系的零头。模式先进，价格虽低却利润厚，对旧体系形成降维打击。可以说，跨境电商因套利模式兴起，本质就是“套利”二字。

近几年从业者变多，低成本、低投入、快速盈利不再普遍。很多打法变成先投入、先烧钱、再图盈利，套利模式转成盈利模式，一字之差，门槛升了，赚钱效应降了。

那还能去哪找低门槛、低投入的套利？我判断三个特征：投入轻、有信息差、结果确定。

投入轻：无货源、dropshipping就是典型，不大量压货、不亏钱亏货刷单刷评拉排名。信息差：蓝海品类就是信息差品类，知道的人少、竞争小。现在蓝海品类减少，要更新追热点、查热卖榜、铺货、跟卖的老方法，从赚产品信息差升级到赚模式信息差。海关壁垒产品就是一例：选品不追热点，而从海关关税清单找高壁垒产品，用邮政包裹单票自发货合法规避关税，形成套利空间。这是行业里少见的选品方式，也是模式信息差。

确定性：盈利和转化可预期。绝对成本优势是一种确定性，只有你能便宜，别人便宜不了；复制别人已经跑通的模式、抄作业也是确定性，少交试错成本，选品运营尽量用被验证且少数人知道的方法。

好的、能赚钱的选品思维，应同时满足这三点。

-02-

**日本市场和美国市场的几组数据**

过去两年，我们服务对接了1200多个独立站卖家，绝大多数做欧美市场。对比美国，日本有几组数据值得看：

人口上，美国3亿多，日本1亿多，约3:1；人均收入接近，日本贫富差距远小于美国；1200多个样本里，做日本市场的不到10个；网购渗透率美国高于日本，但疫情推动日本快速增长；信用卡收单机构数据看，2020年中起日本单量迅速增长。

收入接近、网购率趋近，市场规模3:1，而卖家规模不到100:1，说明日本竞争激烈程度远低于美国。尤其日本乐天这类准入门槛较高的平台，铺货模式仍有红利，美国早已没有。

我们实操总结，日本有四大优势：竞争压力小、客单价高、物流快、纠纷少。

1）竞争压力小：亚马逊日本和乐天铺货仍有红利，不刷单不刷评，正常运营也能把搜索排名做上去，避开大量封号风险。独立站某些垂直品类长期没有竞品站和对手，有的长达几年；Google广告投放成本最多比欧美便宜一半。我们Google广告CPC大多在17～23日元，约0.2美元，欧美卖家难想象；Facebook跑点击量，CPC可控制在12～18日元。

2）客单价高：垂直品类、信息差品类、海关壁垒品类客单高，毛利空间大。

3）物流快：自发货2～3天清关派送，旺季时效有保证，不像欧美自发货旺季积压、卖越多亏越多。

4）纠纷少：产品性价比和质量过关时，绝大多数交易静默完成；自发货客服售后成本也小，独立站几乎无拒付，欧美常见的拒付党、撸货党在日本很少。

-03-

**信息差：海关壁垒品类怎么选、套利在哪**

海关壁垒是我们的选品思路之一：通过货代统计各品类海关关税税率，从高到低排，从税率最高开始选，再用邮政渠道单票自发货合法规避关税，把关税变成利润空间。

日本可以操作，中美贸易战下，美国海关壁垒品类也值得调研一试。

日本主要海关壁垒品类是真皮类，真皮皮鞋关税最重；食品糖果也是高关税，税率与真皮制品接近。比如真皮皮鞋，每双日本海关关税4300日元，约300人民币，常远超货值。正常贸易公司进出口、大货清关、FBA大货和货柜都绕不开，只有邮政渠道单票自发货、按私人件清关可合法规避。

食品糖果还有市场准入壁垒，平台无法上架，反而给独立站卖家创造了垄断机会：找到20个左右符合国外买家口味的网红食品，就能搭起一个独立站。具体打法以后另讲。

-04-

**真皮材质选品方向与套利空间**

真皮制品关税高，市场售价普遍高，基本不低于500～600人民币；用邮政自发货规避关税后，即使按市场价一半卖，客单净利也能接近100人民币，这在欧美跨境里不常见。

真皮是材质不是品类，可做的品类多，且支持无货源dropshipping，符合投入轻；海关壁垒信息差在我们对接客户中几乎没人知道，符合信息差；规避关税带来的成本优势，让转化和模式成功更有确定性，符合第三点。因此这是很好的选品方向。

真皮品类多，建议分优先级：先做自己专业、有供应链优势的品类，比如我们选鞋类；也可从感兴趣、喜欢或有资源的品类入手。

**A）可套利的真皮鞋靴**

成本越低的真皮鞋，在日本套利空间越大，因为不管鞋多贵，日本海关都收约300人民币关税。中国工厂本来有成本优势，真皮皮鞋也一样：凉鞋、包头软木拖鞋、单鞋出厂最低30～50元可做，多用牛二层皮、牛绒皮，也是真皮，SKU标题详情可直接标真皮。

多年售卖经验看，套利空间较大的有：包头凉拖、凉鞋、户外鞋、登山鞋、马丁靴、工装靴、雪地靴、豆豆鞋、休闲鞋。

**B）成本区间与零售定价**

以下为兼顾品质性价比的建议进货成本和零售价：

包头软木凉拖：进30～60元，售1980～3980日元，利润50～100元；  
凉鞋（玛丽珍等经典基础款）：进40～70元，售2980～3980日元，利润50～100元；  
户外鞋（户外凉鞋、登山鞋）：进55～125元，售3980～7980日元，利润100～200元；  
马丁靴：进60～180元，售3980～9980日元，利润100～200元；  
工装靴：进90～120元，售5980日元，利润100元；  
雪地靴：进50～160元，售3980～8980日元，利润100～200元；  
豆豆鞋：进35～55元，售2980日元，利润70～100元。

补充：同为真皮，用料和款型不同，成本利润差异大。成本和利润平衡好的单品更值得做。雪地靴里最贵最好的是羊皮毛一体、真皮真毛，出厂常150元以上；羊剪绒款约90元，针织羊毛款最低不到70元，后两者套利空间更大。引流时可按皮毛一体、真皮真毛、兼具保暖透气来营销，用同样关键词拿自然流量和推广，再靠高性价比价格提高转化。

**C）本地化：翻译、用词、文案**

做欧美市场，标题详情广告词不准确、不地道，对转化影响没那么大；日本不同，用语地道与否要求高。客户一旦觉得日语不标准、是外国店主卖货，会不安不信任，转化明显下降。所以日本市场标题详情要翻译准确，推广文案用商业敬语。

欧美卖家里也常见本地化不到位和机器翻译错误：比如飞织鞋大量标题写flying weaving shoes，这是很低级的错误甚至笑话，正确应为upper neat sneaker。再如雪地靴，欧美卖家也常写错，大量标题用snow boots，但这个词实际指滑雪、踩雪类靴子；通常说的皮毛一体雪地靴不防水，不适合踩雪，对应英文应是mouton boots或sheepskin boots，在澳洲也可叫ugg boots（澳洲豁免ugg品牌词侵权，因为ugg boots在澳洲是雪地靴统称，不是某个品牌）。

日语关键词也同理，很多日语叫法只是英语的片假名外来词。用错词会浪费广告费，流量不精准，转化低，离赚钱更远。本地化和精准文案、精准关键词很重要。

**D）检品仓、前置仓、FBA与FBM**

日本市场有蓝海空间、蓝海品类和蓝海模式，但客户对质量和快递时效要求高，运营能力也要跟上。

真皮鞋我们一般选进货成本100元左右的，质量、性价比、终端定价和净利较平衡。低档便宜货可在东南亚电商平台和速卖通做，却不适合日本，退货率极高，容易巨额亏损。

为降低退货率，即使无货源dropshipping也要设检品仓，所有货自己检查一遍，比如剪毛头、挑次品。交给中国工厂做，叮嘱再到位也不稳，因为dropshipping供应商品控常不稳定、不靠谱、不负责。

我们在南京设检品仓，所有dropshipping货先到南京检品再发；爆款统一检品后送上海前置仓或日本FBA仓库。前置仓介于海外仓和国际直邮之间：日本近，上海前置仓一般当天发货、次日清关，最慢3～4日，省海外仓成本，也避免店铺关停后货退不回全亏的风险，相对灵活可控；但检品不能完全交给前置仓，除非自己安排人去。

真皮制品大货无法规避关税，一般自发货；通过EMS大件也可部分进FBA并规避关税。我们通常把好卖尺码或爆款用EMS大件少量压FBA，其他尺码款式自发货，让好卖SKU拿到亚马逊Prime标志、提升流量权重，同时兼顾成本和海关风险。

-05-

**结语**

我们2009年开始做日本市场，从日本雅虎起步，后来进入日本乐天、日本亚马逊，2012年自建独立站；既是日本电商平台第一代中国卖家，也是独立站最早布局的一批。对日本跨境的选品、建站、物流、支付、推广、本地化等全业务链条有资深经验。

国家持续提倡发展跨境电商，我们既感受到竞争加剧，也看到跨境服务市场成为新蓝海。2019年起，我们增加出海日本服务线，对接较成熟的欧美跨境电商卖家，尤其独立站卖家。目前我们是国内唯一面向跨境电商中小卖家布局日本市场、品牌出海日本的专业资深服务商，也与服务上市公司级的品牌出海服务商在日本市场板块保持合作。

今天分享的海关壁垒蓝海选品思维，是我们多年实操总结的四大选品思维之一，比较适合日本市场；其他选品思维不限于日本、不限于平台或独立站，都是通用且具备套利底层逻辑的蓝海选品模式，未来有机会再逐个分享。
