# 用AI做表情包，上架就能卖

最近有个挺实在的玩法：拿Midjourney生成Line贴图，直接上架销售；提示词也不用自己硬想，交给ChatGPT来写。整套流程跑通后，已经有人短短几天就入账一万多日元。挂上架之后，基本就是持续出单的状态，比起在百度文库那类平台慢慢攒收益，顺手很多。

同样的思路放到NFT上也成立。AI绘画特别适合这种需要大量发散创意的内容生产。要是把成品搬到🛰️表情包，还能顺带做引流。

评论区里也有不同声音。有人算了一笔账：一万日元折合五百元人民币左右，算不上暴利，而且做Line表情包得懂当地文化，可能更适合台湾本地人。分享者的回应是：这个方向确实不是一夜暴富型，但它胜在细水长流。一套表情包几天卖出600，提示词大多由GPT生成，批量输入就能跑起来。如果认真做，一天产出5套，后面持续收入过万也不是没可能。关键是效率：别人要磨一个月的事，自己半天就能完成。能变现的领域都能照这个思路做，比如文库、头条、投稿，本质都是搬砖活，只是工具把效率抬高了很多。
