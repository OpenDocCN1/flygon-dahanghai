# 踏空百倍后，我的BRC20翻身笔记

有段时间，我常盯着大额成交地址看资金去向。看多了发现一个规律：钱大多涌向刚冒头的项目，参与者画像也很统一——都是怕错过、刚入场的新手。那时我带着成见没去mint，后来看着它被炒到百倍，只能干瞪眼。此后我换了方法：遇到热点炒作标的，把gas抬到50～100去抢，成交后立刻在二级市场卖出，锁定十倍以上利润。靠这套打法，我又在insc上花500美元打新，最后变现1万美元。

#### 12.3.1.4 Gate入场：期待变失望

五月初，Gate放话要上线ordi、pepe、meme等主流币。BRC20圈子里的人一度很兴奋，觉得“正规军”终于来了。ordi上线前夜，uni二级市场和OTC交易热到发烫，meme最高成交价冲到1000美元/张。ordi正式开盘后，不到半天，单张价格最高摸到29000美元。

然而Gate随后把bank这类垃圾币也摆上货架，大家才意识到：来的不是正规军，而是比豺狼更凶的虎豹。不能提现、频繁上币等操作接连出现，质疑声迅速发酵。短短五天，Gate口碑跌到谷底，社区甚至拉起“反Gate联盟”，细数它的十宗罪。Gate与链上交易的价差，一度高达20～30%。

链上gas就像情绪的镜子。经过这一轮折腾，亏钱的人不再追打新，也不愿在二级接盘，gas重新降到30聪。各路玩家暂时收手，盯着下一个机会。

这个阶段我的做法与思考：「在情绪中找机会」——不忘初心，及时变现；上涨行情是卖方市场，囤货优先；下跌行情是买方市场，现金流优先。ordi到28美元时我卖掉一半仓位，7～12美元又抄底回来；同时零成本拿到100张pepe、300张meme。当市场情绪把uni与Gate的价差推到30%时，我搬砖约2万美元，赚了30%。

#### 12.3.1.5 土狗乱斗：越热闹越要会筛

五月中旬，群魔乱舞。

协议越来越多：orc20、ltc20、drc20、brc721等接连亮相；项目方也五花八门：圈内大佬、精英创业者、群友自创项目纷纷登场。新机会数量猛增，很多人反而不知道从哪下手。

更微妙的是，BRC20让推特大V有了“喊单变现”的能力。一个新热点经大V推荐、社群转发，有时半小时就售罄。面对良莠不齐的推荐和真假难辨的信息源，盲目跟风成了常态。

这个阶段我的做法与思考：「观察情绪、评估项目、总结打法」。我只参加头矿，拒绝二级接盘。通过ltc、orc、brc721等头矿打新，以及oxbt等优质新币，我拿到多个百倍币。

#### 12.3.2 新老标的怎么挑（DYOR）

接下来聊聊BRC20现阶段，新人该掌握哪些基础认知，才能用小资金博大机会。

梯队划分：一梯队ordi；二梯队pepe、meme、$OG$；三梯队SHIB、wzrd、domo、rssc、vmpx；四梯队其他币，高位变现后换到前三梯队。

记住两个目的：1）及时变现，改善生活；2）及时回本，用利润继续玩，别影响生活。

挑选时看六点：1）部署时间越早越好；2）老外含量越高越好；3）有项目方且越牛越好，如rssc、wzrd、vmpx；4）持仓人数越多越好，最低门槛1000人；5）按当前流量，代币数量分配最低门槛约2.1万份；6）是否有庄家、能否形成热点炒作，如OXBT、nals、piza。

#### 12.3.3 新人上手的正确路线

1）熟练使用unisat和xverse钱包，能接收并发送btc/铭文；2）熟练使用两种Mint工具，至少完整走一遍Mint流程；3）学会查看链上gas，根据拥堵情况合理设置gas，并能在链上确认交易；4）根据自身情况，配置老币、等待打新、参与游戏项目，或参与tw的代币抽奖；5）道路千万条，安全第一条。
