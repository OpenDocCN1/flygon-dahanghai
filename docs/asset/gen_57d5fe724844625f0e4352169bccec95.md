# 3.4.4 校核

到这里还没完。这是一篇硬核解读，事实错误不能出现，尤其是关键数据和论据，必须核实。关键数据最好做三源验证，金额、日期、人名尤其要盯紧。读者可能原谅你的观点，但不会原谅你的错误。

比如文中有一句：推理速度提升 11.6 倍，处理同长度文本所需计算资源不到原来的十分之一。我就去原 PDF 里 Ctrl F 搜“11.6”，再用沉浸式翻译检查核对。关键词找对了，核实起来很快，10 分钟足够。但这一步我不会省。

一句话总结：给文章上最后一道保险。

收尾

我大概算过，让 DeepSeek 写作，再加上自己编辑修改，那篇文章一共花了一个小时。但今天写这篇复盘，却花了一整天。这篇完全是手搓，写得有些琐碎，主要是想尽量还原写作时的心路，让大家能代入这个过程，有所思、有所想，才能有所收获。

最后说点掏心窝子的。

AI 进化的终极意义，是让每个会使用它的普通人突破肉身限制，拥有百倍于过往的能力半径。这篇知乎热榜文章就是一个典型例子。但越是在这种时候，越要握紧人类作者的三大权杖：对选题的新闻敏感性，知道什么时候该说话；对文字的鉴赏能力，明白该用什么方式说话；以及最重要的，对输出内容负全责的态度，清楚为什么必须由自己来说话。

感谢每位读者，希望这篇复盘对你有用。
