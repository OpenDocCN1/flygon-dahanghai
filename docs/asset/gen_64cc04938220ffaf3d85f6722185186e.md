# 11.2.1 用公式快速出LOGO

想快速做出LOGO初稿，不用一上来就硬憋关键词。有个很好记的拼法：先写“LOGO 设计”，再选“LOGO 风格”，最后补上“画面主体”。三块一组合，就能迅速拆出多组可用提示词。

比如要给“生财”做一个帆船图标，套用这个思路，很快就能写出不同风格的方案。下面这些图都由 MidJourney 生成；具体工具用法可回看章节【四、学会用 MidJourney 完成 AI 绘画】。
