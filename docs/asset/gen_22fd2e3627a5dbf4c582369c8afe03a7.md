# 每天 8 点，让 AI 新闻自动进飞书

这次用到的是 NewsAPI 和 GNewsAPI。通俗讲，它们都属于把新闻源聚合起来的 API 服务：开发者只要发一个 HTTP 请求，就能拿到全球各地媒体发布的文章和头条。它们能提供 70 多个国家、数千个新闻源的实时资讯；支持按关键词搜索、按分类筛选、按日期范围查询；返回的是结构化 JSON 数据，里面包含标题、描述、URL、发布时间等字段。

# 1.1.1 接口入口

NewsAPI 网址：https://newsapi.org/

GNewsAPI 网址：https://gnews.io/

更推荐 NewsAPI，因为发 HTTP 请求时，它能筛选的参数更全一些。

注：这两个网址使用时都需要科学上网环境。

# 1.1.2 注册与密钥

先打开 NewsAPI 网址完成注册，再点 login 登录；GNewsAPI 的获取流程也一样。

登录之后，页面上能看到 Account 和 Usage。

Account 里会有一个 API key，这就是可以直接拿来用的 NewsAPI 密钥。别把这个 Key 暴露在公开环境里，否则别人也能调用你的接口，从而消耗你的 Usage；其他 API 也是同样的道理。把这个 API 保存好，后面会用到。

# 2.2.4 切到 settings 页面

[PRE27]

测试这个 API 接口时，出现过服务器离线、无法获取新闻的情况。为了让工作流运行得更稳定，我补充了一个分支：当 NewsAPI 运行失败时，就去请求 GNewsAPI，用两个不同的 API 服务来保证新闻获取稳定。

为了某个节点出错时工作流仍能流转到下一个节点，这里做了两个设置：

Always Output Data

On Error：Continue(using error output)

[PRE28]

Settings 输入 作用

On Error Continue(using error output) 当节点出错时，程序不终止运行，输出 error output 继续运行到下一个节点

Always Output Data 打开 始终输出数据，如果请求失败、数据为空，也输出空值
