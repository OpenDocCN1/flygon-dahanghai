# (精华帖)(29 赞)3天裂变1000人：训练营操盘全复盘

作者：莲子丨Jeen  
日期：2020-09-11

加入这个星球已经有5个月，一直没敢发帖，每天默默刷着大佬们的案例和经验，收获很多。今天终于鼓足勇气，来拆解一个我亲自操盘的线上项目裂变成交全过程。这个玩法更适合已经有了一定基础用户的伙伴。

项目背景：黑天鹅事件  
第一次裂变时长：6天  
项目名称：暂且叫她“女神XX计划”吧。

一、种子用户

种子用户主要来自三方面：
1. 核心高价值学员约70余人，预计有40人会参与裂变；
2. 外部招募约40人，实际参与分销的只有约15人；
3. 公司员工实际参与约5人。

如果外部分销社群能更早启动，诱饵再丰富一些，这一块的数据大概率还能明显提升。

二、宣传触达

主要渠道包括预热直播、朋友圈、公众号和原有社群。

- 预热直播选的是“XX秀”这个新兴成都直播平台，原本流量不大。由于是第一次签约该平台，如果当时换成小鹅通或者其他原有渠道来做首次直播引流，效果应该更好。所以宣传触达上，可以多尝试更多渠道和合作方。
- 朋友圈需要提前准备好话术、私聊话术和方案。
- 公众号以软文推送为主。
- 原有社群则用“海报+文案”推送，配合小分享和活动群发售。

有一点必须提醒：分销过程中，一定要多次刺激用户进行裂变，比如晒单、现金奖励、荣誉激励、后端其他激励等；同时，尽量寻找更多有能量的人来推动课程。你去推动一个有影响力的人，会比推动一个什么都不会的人轻松10倍。

后续我还见过类似案例：一个“520”启动的发售，承诺了520元现金奖励、会员卡、签名书籍以及价值不菲的个人咨询。虽然启动的种子用户不多，但依靠这些推手，依然让一个新品牌在线上拿到了首次成功。

靠近更有影响力的人——你赋予他们价值，他们也会赋予你价值，彼此认可，携手前行。

三、二次裂变

课程内部设置了变现测试，一期学员在“学-练-评-赛”的闭环学习模式中完成了二次裂变。优秀学员会被邀请来做分享，学员积极性再次提升。

从我目前操盘的多个案例来看，二次裂变的循环体系，能让训练营的名声扩散得更快，也更容易获得用户认可。原因是：学员在完成作业的同时，获得了大众的认可，这种荣誉感会让她更愿意为这个品类做自传播，她自身的影响力也在不断提升。

关键就是：奖章上有她的名字、她的头像，那种专属尊享感无可替代。

想让别人主动分享，就要先给她价值认可。

四、阶梯式方案

定价从29.9元到499元不等；后续追销999元的“女神大学”，学员补差价即可升级，整体转化率达到33%，所有完成999转化的学员都是我这边负责的。

转化率这么高，核心在于每个环节都设计得环环相扣。当然，中间也有很多灵活应变。当时我们正在做“新年七天乐”免费打卡活动，于是在七天打卡结束后，把第八天结营活动作为第一次测试发售。

第一环：免费7天打卡活动。
第二环：第八天结营活动（让学员参加分享）。当天晚上，凡是参与了七天感悟分享的学员，全部成交了引流课程。
第三环：推出重磅引流产品。第一波抢到的人非常超值，还赠送喜马拉雅等优惠。
第四环：告诉大家，这个3天营实际有5天课程，而且每一环都可以拆解，线上线下方方面面都能落地使用。
第五环（重点）：课程跟踪。从开营仪式感到结营仪式感，包括优秀学员点评和分享，全程有导师、班主任一对一地点评陪伴，落地“学练评赛”模式。
课程期间，要让学员玩得好、学得好，还能赚到钱、赢取大奖品。每次复盘拆解的学员，可以直接获得6.6元、66元或100元的现金红包，或者其他超值大奖（比如周大福小金猪）。同时引导学员在复盘时写上我们的平台名字和创始人名字，他们就会去做脑图、写简书、发朋友圈等等。
第六环：转化。在课程最后一天和结营当天，转化课程XXX（原价几乎半价），同时赠送699元其他产品，仅限疫情期间。
第七环：追销。购买转化产品后，补XXX元，可直接升为白金会员，享受从未有过的6大福利，合计价值接近4000元。

以上只是引流营涉及到的简要环节。在后续过程中，针对参与后端产品的学员，我们做了三次裂变。其中有一位学员，昨天通过成交分享，在她只有33人的小群里，成功转化了26人。更多环节这里就不展开了，包括第八环、第九环等，也包含后续每期复盘和线上线下会议沟通。

SOP能让社群运营更简单，但好的运营团队才是社群成功的基石。没有好团队配合和训练营的持续迭代，再完美的SOP也是一句空话。

【用户沉淀逻辑】

用户沉淀建议做3到4次，至少3次，目前我们还在测试。

第一层：客服触达和筛选。客服是第一个接触学员的人，负责专业倒计时提醒、拉群、系统答疑等。
第二层：班主任沉淀。我要求每位班主任在拉班级群当天，就添加每一位学员，做简单的自我介绍、沟通，并带领班级做预热活动和入营提醒。班主任要像老母亲一样，给学员绝对的温暖陪伴。
第三层：导师沉淀。导师负责专业点评和答疑。在给温暖之后，还要给专业干货，刺激点在于加餐和其他奖励，这些都不会提前告知。
第四层：大咖链接。营长、专业大咖会翻作业发现你，或者在群里艾特你点评，之后还可能通过添加好友来打招呼。学员的感受往往是：原来大神也可以这么亲切，简直是绝对宠爱感。学员能加到大咖就会很开心，我们偶尔会做这种引导。

这样一来，训练营期间，只要有可能转化的学员，100%都会收到我们的信息，被全方位包围。哪怕结营后没有转化，他们依然会持续看到我们的信息，铺天盖地，很可能再次激起兴趣。事实上，有好几个学员都是在结营后第1到第7天才付款转化的。

客服让学员没有顾虑，班主任晚上贴心问候，导师贴心答疑，大咖在社群跑爆点。

这里非常重要的一点是：老客户很可能比你的新客户（泛客户）重要100倍，甚至1000倍。已经为你的产品付过一次费、突破信任高山的那个人，很容易再跟着你继续走下去。付过一次费，再付费就变得相对容易了。前提是：你要把付款当作服务的开始，而不是销售的结束。
