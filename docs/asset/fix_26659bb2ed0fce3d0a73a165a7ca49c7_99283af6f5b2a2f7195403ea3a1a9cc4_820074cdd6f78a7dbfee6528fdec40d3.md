有个提醒：这份清单不是让你逐项填写的问卷。把AI切到“顾问模式”后，它会顺着你的回答继续追问，把该确认的细节一个个挖出来。

**为什么非得让AI先开口？**

大多数AI默认是“你问、它答”的模式。你提问的角度，会直接框定它输出的范围。方向一旦跑偏——比如你只问“怎么追热点”——它就会在错误的前提里拼命输出，最后给你一份看着完整、实际很难用的方案。

把提问权交给AI，局面就反过来了。原因有三条：

- **你是新手，它见过大量案例**：你第一次提这个需求，但AI的训练数据里已有许多相似场景，它知道常见坑和关键判断点。
- **经验只有在“被问”时才会被调用**：在“你问它答”里，AI的经验是沉默的；只有让它来问你，它才会顺着经验追问那些你容易漏掉的细节，比如“你数据表现最好的内容类型是什么？”
- **追问能把隐性想法拽出来**：每个问题都像一次探测，把你脑中已有、但没整理过的念头抽出来。很多需求不是你不知道，而是你压根没想到要说。比如AI问“灵感通常从哪来”，你才反应过来“我都是刷笔记时顺手记的”，这会直接影响Agent的输入来源。

第三步：和AI聊起来，在它的追问里把Agent的核心维度定清楚。

AI开始提问后，你只需要如实回答。它追问的方向，基本覆盖了搭Agent必须想明白的五个维度。你会在对话中不知不觉把它们定下来：

1. 难点在哪：真正要解决的痛点是什么，先定清楚，免得白忙。
2. 先做哪段：当前最值得动手的最小切口是什么，确保能收尾。
3. 原料从哪来：Agent需要哪些信息、从哪儿取得，别让它空转。
4. 中间怎么走：流程要经过哪些环节，保证逻辑不断线。
5. 结果放哪：最终产物落在哪里、长什么样，保证拿来就能用。

换句话说，和AI聊需求，其实就是在给Agent做设计。把需求拆明白的同时，搭建所需的要点也被一并问了出来。

至于输入输出、处理流程、结果落在哪里，这些并不是你要另外补的课。它们会在对话和拆解中自然浮现。需求拆得够细，这些内容自然就齐了。

聊到这一步，很多新手心里会打鼓：“然后呢？技术细节我搞不定啊。”

请把这句话记牢：

技术门槛不用你扛。

- 你站的是需求方/产品负责人的位置，交付物是一份清晰的需求定义，也就是上面那五个维度。
- AI负责技术落地，把你的需求翻译成可执行方案，并生成Agent。

等聊得差不多了，你只需让AI把方案收束到最小，再让它去开发Agent。

AI会结合完整聊天记录理解你的意图，直接给出包含工具、步骤、配置方法的方案。那些“输入输出”“处理流程”的技术实现，由AI根据你的描述自动完成，不需要你另学。

**整条路径可以概括为：AI提问确认需求 → 梳理核心维度 → 产出Demo → AI生成Agent。**

第四步：把讨论收束成一个最小Demo

聊完以后，你手里可能攒了一堆功能点。别全都做——功能越多，Agent越容易在流程里卡壳。

必须做减法：把聊过的功能砍到只剩最核心的一条链路，先让它跑通。

这就是“最小Demo”：它不是最终产品，而是能验证想法、可以运行的最简版本。先搭一间能住人的小屋，确认地基稳了，再往上加。

第五步：让AI把Agent做出来

把Demo交给AI（比如Codex、Coze）去搭建——这里有一个关键的认知转变：你不需要亲手写一行代码去“搭建”。

拿到Demo后，你只需要做三件事：

1. 打开你的AI编程工具（如Codex、Coze、Claude等）。
2. 把这份“最小Demo定义”文档丢给它。
3. 给出明确指令：“请根据这份需求文档，帮我搭建/实现这个Agent。请生成完整的代码/配置/工作流。”

AI编程工具会理解你的需求，自动生成代码、配置技能（Skill）、串联工作流，把这个Agent给你“搭”出来。你可能需要和它进行几轮调试和微调，但核心生产力是它，不是你。

## 2.3 Agent与Skill是什么关系（拓展内容）

后面的章节会反复出现两个词：Skill和Agent。它们长得很像，但并不是同一回事。先把区别说清楚，后面就不容易绕晕。

**Skill = 单项能力**

比如“把今天的日报总结成结构化要点”，这就是一个Skill。它只负责一件事，做得稳定，可以被反复调用。你可以把Skill看成一项“专项技能”：分析日报是一个Skill，提取📕爆款标题是一个Skill，把网页正文转成Markdown也是一个Skill。

**Agent = 把多个Skill串起来自动运转的“员工”**

比如：每天定时读取日报.txt → 调用“日报分析”Skill → 把结果写到汇总文档 → 同步到飞书。整条链路不用你点“继续”，它自己从头跑到尾。

在接下来的日报案例里，两者大约有90%是重合的——一个Skill自己也能“分析总结”。

Agent多出来的那10%，恰恰是关键部分：

- 自动喂料：文件、网页、数据由它自己去取，不用你手动递。
- 自动开跑：定时执行或监听变化，省掉每次手动点开。
- 多步衔接：上一步的输出直接变成下一步的输入，跨工具、跨平台连成流水线。

先有Skill，再有Agent，这是搭智能体最自然的顺序。
