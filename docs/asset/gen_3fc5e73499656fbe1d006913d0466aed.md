# 7.3.3.1 数字人：未来做IP的新路径

不想真人出镜拍视频，却仍希望打造个人IP？可以试试用 ChatGPT、Midjourney 与 D-ID 组合出一个基础版数字人。操作逻辑分三步：先让 ChatGPT 写视频脚本；再让 ChatGPT 产出给 Midjourney 的画面描述词，由 Midjourney 生成数字人形象图；最后把脚本与图片交给 D-ID，合成数字人视频。

需要说明的是，这套方案目前呈现的真实感有限，成片效果只能算普通，因此本手册暂不深入展开。不过星球中已有不少圈友把流程拆解得很清楚，若你想进一步了解，可以翻阅这篇帖子：《如何用 ChatGPT 批量生成工业级提示词，并在 MJ 里面生成 AI 图片》。
