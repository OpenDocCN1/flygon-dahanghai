小红书主流图片比例有三种：1:1、3:4 和 4:3。截图区域可以直接选 1:1，也可以自定义。

[PRE5]

如果要做 3:4 或 4:3 的导图，建议先找一张小红书标准尺寸图片当参照物，再在导图里做调整。

[PRE6]

接下来聊聊小红书思维导图比较常见的内容形式，你可以根据选题灵活挑一种来用。

合集型

胜在数量多，内容越丰富越显价值。

[PRE7]

测评型

针对某个物品或景点做测评，把好坏优劣逐条摆出来。

[PRE8]

科普型

相当于给新手整理某个领域的知识点，帮人入门扫盲。比如咱们的航海手册，就是一份很全面的科普手册，是什么、为什么、怎么做，都写得清清楚楚。

[PRE9]

避坑型

把完成一件复杂事情过程中容易遇到的坑都列出来，让即将进入的新人能提前避开。

[PRE10]

教程型

从多个维度总结一件事，每个维度都要讲得全面清晰，具体怎么做、要注意什么，用思维导图来罗列再合适不过。

[PRE11]

以上这些是小蓝书上比较受欢迎的几类笔记，都属于密集型干货，很适合用思维导图呈现，帮用户理清问题、找到解决办法。

## 5.3 思维导图账号案例拆解

思维导图本质上只是一个工具，关键看怎么用它来承载知识。这一节就结合真实案例，聊聊如何借助思维导图打造自己的专属 IP，希望对你有启发。

案例一：读书博主

很多人都有这种困扰：书看完就忘。思维导图正好能解决这个痛点——边读边梳理，记忆会更深刻。把导图笔记分享出来，还能帮别人省时间：不确定一本书值不值得读，看笔记就知道；没空读书的，也能快速了解精华。具体怎么做呢？

定位：用思维导图形式分享读书笔记，这里只做概括性的说明。

封面：长期使用同一款模板，提前设计好，之后每次打开文件改文字就行，很像用 PPT 模板，省心省力。

内容输出形式：
- 一条笔记放多张图文，都和封面保持同款模板。
- 一本书输出几张笔记，可以合成一条发布，也可以拆成多条笔记。
- 结合内容关键词找一些爆款标题，把导图往爆款标题上靠，会更有吸引力。比如读完《洋葱阅读》后，把阅读步骤提炼成导图，标题写成“7 步骤高效阅读法”。

[PRE13]

变现形式：
- 开一家小店，卖导图模板。
- 接广告，结合粉丝人群来选合适类型。
- 把粉丝引到私域，做读书会，带大家一起拆书、做笔记。
- 提供思维导图代做服务。
- 推出思维导图训练营产品。

适合人群：
- 阅读速度快、擅长做笔记的人。
- 私域里已有学习或读书类产品的人。
- 逻辑清晰、会熟练使用思维导图的人。

读书博主做导图的要点：
- 封面：单张导图或整本书的导图，最好带一个爆款话题。
- 内页：每张图只呈现一个知识点，不要照搬书籍目录或章节标题，要站在自媒体人的角度来写导图标题。比如读《早起的奇迹》，可以把早起的 7 个步骤整理成一张导图，取名叫“7 步戒掉熬夜，学会早起自律”。然后围绕这个点展开：为什么要早起、早起七步骤、坚持早起后的改变或案例，这样能带着粉丝落地实践，干货感更强，而不只是搬运作者观点。

我之前做过一个分享“思维模型”的号，每次都会在最后放一个实际案例，真正让人明白模型怎么用的，往往就是那个案例。说再多是什么、为什么，不如直接教他怎么做。所以我特别建议读书博主从书里延伸出应用案例。

小红书标题也很关键。很多书籍在小红书上没什么搜索量，如果你直接把书名当作标题，很容易沉没。这时就要用爆款标题的思路来写。我自己最常用的方法：搜想分享的关键词，找到几个爆款标题，随便挑 3 个重新组合成自己的标题，简单好用。

定位精准、输出精准、风格统一，涨粉就比较顺利。对你感兴趣的粉丝进主页一看，觉得“这个博主有货”，自然就关注了。

案例二：技能类博主（复盘、英语教学、早教启蒙等）

[PRE15]

这里分享一位用思维导图做复盘的博主：他为自己设计了一套思维导图复盘模板，每周复盘、每月复盘，或者针对特别的大事件复盘并分享出来。

定位：用思维导图呈现自己的技能。

封面：做复盘内容集合，比如本周完成了四页复盘，就把这四页拼在一起作为封面。对复盘感兴趣的人会好奇里面到底复盘了什么，也想学习借鉴，还会觉得博主很自律、值得学习，整体来看非常吸睛。

内容输出形式：导图色调比较丰富，符合生活的调性。

[PRE16]

变现形式：
- 引流到私域，做复盘/成长类知识付费产品。
- 引流到私域，做其他转化。
- 售卖个人复盘模板。

适合人群：
- 拥有相应知识付费产品的人。
- 掌握一项技能，且能帮别人解决某个问题的人。
- 会用思维导图把技能呈现出来的人。

技能博主的导图做法和注意点：
- 封面：把技能成果亮出来。比如做复盘，就把复盘结果展示出来，让人感受到复盘带来的美好感和充实感。
- 内页：主要展示技能运用的过程。比如有些宝妈用思维导图教孩子阅读，那我们就把思维导图如何一步步引导孩子、带他进入阅读状态的过程呈现出来。

[PRE17]

小红书标题：继续使用前面说的爆款标题思路，但一定要带上技能关键词。格式就是“思维导图 + 技能关键词（读绘本/学英语/复盘）”。

[PRE18]

案例三：私域引流类博主

定位：用思维导图呈现某个领域/行业的专业知识。

封面：做资料/方法合集，对导图技能要求不算太高，能整洁表达内容即可，重点还是内容本身。比如“7 大引流获客方法”“加微信的 51 个钩子”等等。

[PRE19]

内容输出形式：
- 方法一：把封面里的内容一点点放大呈现，凑成 4-5 张图。
- 方法二：推荐副业项目或生财赚钱案例，一张卡片介绍项目、一张收入截图、一张思维导图拆解、一个用户证明。

变现形式：
- 引流到私域，做付费咨询。
- 引流到私域，卖副业项目训练营。
- 引流到私域，卖生财类门票等。

[PRE20]

适合人群：
- 某个领域的操盘手，或有成功经验的人。
- 有知识付费产品，或者可以分销可靠产品的人。
- 副业第一步，想分享副业赚钱项目的人。

私域引流博主的导图做法和注意点：
- 封面：一定要用大字突出导图信息量大、够全面，能帮目标人群解决对应痛点，比如“100 个引流技巧”“50 个打造 IP 的技巧”“80 个朋友圈发圈技巧”。这一步决定了粉丝会不会点进来、会不会主动找你。说白了，私域引流博主用思维导图的目的，就是把用户引到私域来领取这份资料。
- 内容：把技巧逐条罗列在思维导图上，不要求颜色多漂亮，只要层级一致、每个分支宽度统一就行。每个技巧讲基本做法和简单操作即可，不用展开案例，让想要资料的人觉得拥有这些资料后，自己也能轻松实现目标。
- 标题：数字天然有诱惑力，标题里带数字能体现资料集合感，跟封面的思路差不多。

以上是用思维导图打造垂直 IP 的案例拆解，包括但不仅限于此。你可以观察现有博主在做什么，继续发散，也可以想想怎么把思维导图和自己擅长的技能结合起来，让自己的能力放大十倍、百倍。
