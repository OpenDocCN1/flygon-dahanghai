# 陪诊师：月入过万的新职业

最近看到一个真实案例：一位教舞蹈的老师改行做陪诊，月收入能到五位数。这个行当其实早有人提起，只是外界讨论不多。借这个例子，聊聊陪诊师到底做什么、怎么入局。

陪诊师的核心工作，是陪行动不便的长者、孕期女性、害怕独自就医的人等去医院完成就诊流程。一次陪诊结束后，还要整理一份纸面清单，把当天的检查结论、医生的关键嘱咐、后续用药方法和注意事项都写清楚，并提醒客户复诊要做的项目、交通怎么安排。

最需要这类服务的人群主要有四类：子女不在身边的长辈、跨城求医的患者、孕期和带娃的妈妈，以及不愿独自面对医院流程的社恐者。

起步阶段最容易碰到信任问题，别人可能把你当成医托或号贩子。破局办法是做本地同城账号，持续发布陪诊过程短视频。拍摄前先征得客户同意，隐私信息必须做好处理。早期没有真实客户，可以请亲友配合演示，把服务环节完整呈现出来。

这件事既能个人做，也能团队化、标准化复制。过程中把客户沉淀到私域，平时做好回访和关怀，后续还能在私域里延展其他产品。
