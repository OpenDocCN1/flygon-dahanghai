# 小雪后，这4样少碰

先分享一个很实用的思路：流量段和卖货段可以拆开重组。某个素材当天跑爆了，就把其中的流量部分单独拎出来，再拼上转化率更高的商品卖货素材去推。下面这段示范里，前半段是大家爱听的干货流量，后半段接卖货内容；这类流量段还能接八宝茶、七白饮等养生相关产品。

小雪一到，有四类食物真得少碰，你知道是哪四类吗？以前的小雪你可以不放在心上，但今年的小雪有点不一样。要是你刷到这儿直接划走，回头多半会后悔没听完。能认真看到最后的人，2024年通常会越来越顺，不妨点个爱心、点个关注，听我慢慢讲。今年小雪落在11月22日凌晨3点56分46秒。老话讲，小雪在上午偏冷、在下午偏暖。按民间经验，今年属于上午小雪，也就是说这个冬天可能偏冷，小雪之后的“冬藏”黄金期也就到了。但有4种食物，最好别再吃，每一样都是大忌。小雪后四类食物少碰，寒湿才不容易缠身。现在很多人一到冬天就怕冷，说到底，是不少老习俗慢慢失传了。家里有老人孩子的务必留意，尤其白天睡不醒、晚上睡不着，上面热下面凉、怎么都不暖和的人，一入冬就容易留下根源性的问题。再加上今年是甲辰青龙无春年，小雪以后可能意味着寒和湿会格外重，对年纪大的人不太友好。老祖宗传下来的传统习俗，希望你认真了解一下，别不当回事。接下来就说说是哪四不吃。

第一，鸭肉、兔肉以及海鲜等少碰。入冬后天气转凉，很多人喜欢炖肉补一补，但这几类肉偏性寒，吃多了容易让体内寒气加重，也会影响小脾小胃的功能，伤害可能是平时的两倍。实在想吃，尝个鲜就够了。第二，冬瓜少碰。冬瓜是秋冬常见蔬菜，营养也不差，很受欢迎，但它属于性寒蔬菜，不适合冬天经常吃，尤其本来就怕冷的人。第三，太甜的食物和水果少碰。秋冬大量水果成熟，经过霜降后糖分沉淀，吃起来更甜；可甜食容易让体内湿气聚集，影响身体运化能力。第四，辣椒要少吃。很多人觉得吃辣椒能驱寒，而且吃饭离不开辣椒，但辣椒属于辛辣食物。小雪前后秋燥快到顶点，容易出现皮肤干燥、口干舌燥、心情烦躁等不适，辣椒会助长秋燥，等于火上浇油。这个季节最重要的是“润”，要多吃滋阴润燥的食物。今年是青龙无春年，冬天会比往年更冷、更干，这一冷一燥对上了岁数的人是大考验。身上不润，就难抵挡外来的考验；整个身体状态不好，就像缺了油的汽车只能干烧，烧到空了，冬天就非常容易中招。小雪越来越近，阳气潜藏、阴气渐生，应当以养阴为主。正如中医四时养生所说，春夏养阳，秋冬养阴。饮食上适当多吃滋阴润燥的食物，这个冬天就能少遭点罪。

如果家里条件允许，小雪过后可以开始多吃这8种食物，为下半年的健康打基础。特别是女性朋友，用好这段时间，状态会朝越来越好的方向走，错过了肯定会后悔。第一个是淮山药。俗话说，立冬多吃山药白，一年安稳祸不来。《本草纲目》把它称为“神仙之食”。为什么经常觉得累的人更要多吃淮山药？因为它含钙量是牛奶的6倍，含铁量是红枣的20倍。但能吃到真正淮山药的人，连1%都没有，多数人买成了菜市场那种很直、很光滑的菜山药，吃了没什么用。只有产自古代怀庆府、也就是如今河南焦作垆土产的铁棍山药，才能叫怀山药，自古就是四大怀药之首，也是历朝供品。第二个是茯苓。老话讲，少吃鸡鸭，少吃糖，多吃茯苓和粗粮。古代有条件的大户人家，包括乾隆和慈禧，立冬过后就会用茯苓，加上淮山药、莲子、猴头菇、薏米、芡实、陈皮和白扁豆这八种食材一起研磨成粉，老祖宗称之为八珍粉。古时候还有“宁要八珍三克，不要黄金万两”的美誉。所以小雪前后，有条件的家庭可以点赞收藏做起来，能解决每家每户的大麻烦。每天早上用开水冲上3勺，也可以倒在汤里一起喝，香味浓郁、营养丰富，打成粉后更容易吸收，非常适合老人小孩喝。一口下去，暖意从内而外散发，整个身体都仿佛被阳光包围，帮咱们去去凉、压一压湿、把状态往上提一提。大家可以自己制作；嫌麻烦的，可以点击左下角我的头像，主页橱窗里就有我自己和家人一直在喝的八珍粉，配料干净，入口香浓顺滑。从今天开始，就用它好好爱自己、爱家人。

# 4.4.2.4 带货文案怎么写

带货文案会直接影响转化，关键看塑品片段有没有吸引力，包括文案和画面。短视频可以通过各种混剪、特效增加吸引力，提高转化；直播只能口播，塑品空间非常有限。所以直播推流来的用户，可以引导他们先看短视频，再回直播间下单。价格低的商品，引导用户进橱窗商品详情页；有些商品SKU自带升单属性，比如5块钱1个、10块钱3个。限量促销等营销手段也可以用上，如果打开链接看不到了，就说明活动已经结束，趁着还有库存，抓紧带回去试试。核心还是通过文案和视频去塑造产品价值，促进转化。就像前面4.4.2.3的示范，卖货部分先说明天气寒冷，大家需要多吃这8种食物，再塑造每种食物的价值，比如含钙量是牛奶的6倍、含铁量是红枣的20倍等等。人性就是怕麻烦，也不想一种一种分别去买，那图省事、图便宜，直接买这里的八珍糕就好了，顺理成章，很自然地完成卖货。

# 4.5 做不起来的9个共性

在本次航海之前，已经在100人左右的小范围市场测试过，大概有30%+的变现率。总结下来，没变现的伙伴大致有下面这些共性，大家可以自查，增加成功率。

1、没有快速的正反馈。坚持下来的人，大部分都是短期快速拿到了正反馈。最好的方式当然是大家都短期拿到正反馈，但这又怎么可能呢？先把正反馈拆开、切细：不是只有赚大钱才算正反馈，原创功能开通了、流量视频数据好了一点、剪辑速度快了一点、变现了几块钱，都是正反馈。一个又一个小反馈叠加起来，就是大反馈的自然结果。加速正反馈的小技巧：带货视频数据不行，就先把其中的流量素材部分拆出来发布；口播流量文案可以考虑对应年龄、性别、气质的数字人；哪怕只是开通了原创功能，也是一个里程碑。

2、问题思维。有些人是问题思维，提出问题和困难，然后心安理得地放弃，而且理由充分。还有些人是方案思维，只想着如何解决问题，解决问题了不断前进，才有可能完成一个项目的最小闭环进行变现。比如A说：我两个账号都停止推荐了，没办法做了。B说：那就去弄更多账号呀，我以前做抖音也是找亲戚朋友弄了很多账号。A说：你以为别人会帮你呀，现在的人可自私了。满脑子问题，一个问题衍生出另一个问题，却从不想办法解决，这就是很多人的现状。就拿上面的例子说，别人怎么可能无缘无故帮你？但是用爸妈兄弟姐妹的实名行不行？朋友的账号进行分润、买些东西给他行不行？关键是是否有解决问题的思考模式。还有些人喜欢预设困难：如果违规了怎么办？如果没有结果怎么办？如果侵权惹官司了怎么办？问题思维害人不浅，不要老想着问题，而要聚焦在如何解决问题。

3、预期不符实际。老话讲三年入行，十年称王。开实体店不会指望一个月回本，打工入职都要3—6个月试用期才开始创造正价值，为什么到了做副业、做项目上却指望几天呢？其实就是对项目的预期有点不符实际。大部分人的持久力其实保持不了一个月，不是钟点工、不是打工，怎么可能一做就有结果？如果你只有三分钟热度，就需要三分钟结束战斗，否则等待的就是心力受损、执行力不足，然后放弃。调整好对项目的合理预期很重要，能很大程度保护心力，否则就会陷入反复内耗和自我怀疑。给自己定一个期限：每天投入多少时间，坚持多少天，然后再问结果，这很重要。还有些人连续好几天出单甚至爆单，遇到两天不出单就开始焦虑，也是不合理预期。毕竟在短视频领域：不爆是常态，爆单是变态。也许直播一场赚三五千元，不要局限在这场直播来看，把时间线拉长到一周甚至一个月来看，是有了前面量的积累，才有这一个爆的视频，不能说因为吃了第3个馒头饱了，所以前面2个馒头白吃了。

4、没有基础执行量。有的小伙伴不停寻找捷径，却没有脚踏实地的基础执行量。看见广场上一个视频爆了就问这个是怎么做到的？或者想入非非：我从抖音直接搬运会不会好点？群里的素材用的人太多了，我要自己原创。不按目前验证有效的方法执行，也不去验证测试自己的想法，就空想。投机者日复一日地寻找捷径，有结果的人都在日拱一卒。以前我觉得坚持、持久是成功者的谎言和借口，他们不想告诉我们秘诀和捷径，就编织了这么个借口来托辞和敷衍。奇怪的是，几乎所有的成功者都喜欢用这个借口。自己做项目、带项目了才发现，这是朴素真实的道理。先做100条视频再说，很简单朴素的道理：做了才可能有结果。任何项目都需要有基础的执行量，否则成了也是运气，不具备可持续性的结果反而容易蒙蔽双眼。基础执行量的0—1路上太需要互相鼓励了，因为我们是迷茫的，看不清前方，黑黝黝的一片，恐惧、害怕、无助、无力。李超鹏老师的寄语希望也能给你力量：“我带出来的几乎所有的口播IP，不乏现在月销几百万的大佬，成功之前都深深地怀疑自己不适合这条路，无一例外。”一起抱团前行，互相鼓励。

5、没有复盘优化。有些人有基础执行量了，还是没结果，就是因为没有复盘优化。每做十几二十条视频没出单，可以深度复盘优化一下，说明可能问题比较大。太多人每天做着同样的行动，却期待不一样的结果。

6、没大量测试。赚钱和市场是不确定的，需要大量测试，铺号铺素材。有的人就自己两个号发发，也不一拖五分发，一天也做不了2条，有正反馈才是一件奇怪的事。大量铺号，每天大量做素材，拉满分发，一天不超过10条都会推流，大量测号测素材，没有魔法攻击，都是物理攻击。

7、不信，充满质疑。有的小伙伴充满质疑，我说用A方法有效，她问B方法行不行，过了2天又问C方法行不行，然后又问DEF方法行不行。先抄再超，抄作业还没做好，又谈什么创新创造呢？还有的小伙伴充满质疑，总希望别人能随时跟TA证明承诺些什么，给TA解决所有的问题，例如到底啥时能变现、变现多少钱？我没电脑进行剪辑怎么办？即创卡了怎么办？这平台到底行不行？我去哪搞那么多账号？狠狠相信有结果的人，因为结果不会骗人。就像有些时候感觉一个项目混混沌沌的，一会觉得能赚钱，一会又觉得不行，反反复复、纠结、忐忑、迷茫。这个时候就找一个有结果、值得信任的人，狠狠信他，听话照做大量执行就够了。

8、忙、没时间。有些人上班996，确实没有时间和心力做别的，没办法，不能什么都想要，老天是公平的，尤其是给每个人的时间。忙，是因为觉得有更重要的事、更重要的项目。换句话说，忙，是因为觉得这件事不重要。为什么2000块保证金的航海几乎100%上岸率？因为不打卡2000块就没了，能变现最好，不然拿回2000保证金也是很重要的事。

9、真的不适合。没电脑，岁数大了不会用电脑，剪辑很费劲根本无法进行；网感极差，商品不挂橱窗，哼哧哼哧带货；带货视频不引导橱窗下单；做出来的视频有噪音，前言不搭后语。没办法，没有一个项目适合所有人，也没有一个人适合所有的项目。

现在大部分账号24个小时内只给10个视频推流，24小时是自然滚动的，从现在往前数24个小时。看看是不是发超过10个视频了。24小时内已经发了10个视频，并且在直播，就把现有视频的流量榨干，然后在下播。如果24小时内没超过10个视频，按下面的方法检查。1.检查账号私信，看看视频号团队有没有给你下发违规通知，如果违规了，则按照违规手册去申诉。2.检查账号有没有掉加热，如果掉加热了，则按照违规手册去申诉。点作品的转发按钮，有一个上热门按钮，如果显示“暂时无法加热视频”，就说明账号掉加热了，需要去申诉。3.把下面这个链接复制下来，发给账号出现问题的微信，看看账号有没有被减少推荐：https://channels.weixin.qq.com/pandora/pages/appeal/index#account-detail 4.部分视频存在文案违规会隐形限流，发布下一条作品流量数据自动正常，把隐形限流视频删除就可以。注意：如果像下图这样显示，说明账号是正常的，只是发布的内容少，千万不要去申诉！

# 4.7 真人出镜口播

这个时代是表达者的红利，真人出镜口播也一直是平台鼓励的方向。这个方向持久，且能给自己的脸在平台上积累复利。难点是对表现力要求较高，口播视频拍摄比较花费时间，正反馈获取的时间相对较长。表现力锻炼需要刻意练习，最好找一些表现力好的同学或者教练来分析自己的口播视频，不同的观察角度更容易发现问题，也更容易找到可以提高的方面；或者把自己当成局外人、陌生人，来看自己的口播短视频。新手常见的四个表现力问题，可以对照着优化：1、目光呆滞。因为现在一般是看提词器录制短视频，很多小伙伴看提词器时就会目光呆滞，盯着提词器一动不动，很容易给观众一种目光呆滞的感觉。一般可以看看提词器，然后看看别的地方，自然一点，像平时交流沟通一样。2、面无表情。很多稿子在读的时候往往没注意力去做表情管理，会导致面无表情，全是技巧，毫无感情。不是自己想说，不是自己真实的想法，自然口播的时候也没有什么感情，甚至面无表情，这是非常没有感染力、影响视频流量的。需要熟读稿子，最好转化成自己平时会说的口语，在拍口播短视频的时候进行演绎，想象自己是一个演员。3、四肢僵硬。这些表现力问题都需要刻意练，口播是长期复利，慢慢把状态打磨出来。
