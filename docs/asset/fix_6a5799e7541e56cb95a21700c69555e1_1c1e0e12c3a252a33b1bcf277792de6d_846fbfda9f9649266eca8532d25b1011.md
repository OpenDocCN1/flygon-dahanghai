# 书画课答疑＋矩阵号复盘：报名与放大一次说清

不管你在挑选书画课程，还是已经跑通视频号知识付费的最小闭环，下面分两部分讲清楚：先解决课程报名疑问，再把复盘、矩阵号运营的做法拆开。

**课程答疑：报名前最常遇到的几个问题**

**家里有人一起学，怎么报名？**
一个学习名额就能覆盖两位学员，不必重复付费；两个人同堂上课、一起练习完全可行。

**孩子能跟着学吗？**
课程按成人学习节奏设计。年龄偏小的孩子，更稳妥的方式是家长陪同共学。

**录播课价格是不是偏高？**
实际上定价已经压到同类课程里很低的位置。主讲老师出自中央美院，央美在美术院校中属于顶尖阵营，常被拿来与综合名校里的清华作类比；央美书法专业每年仅招10名。老师本身的专业能力和书法天赋都很突出。课程还含班级群、老师陪伴、一对一指导，价值接近一对一辅导。同样配置放到其他书院，常见报价几千到上万。能压到这个价位，是老师主动让利，想让零基础学员更容易入门，也希望把传统文化传播出去。市面上有些“江湖老师”容易把初学者带偏方向，跟真正专业的老师，路才走得远。

**想学，但纠结别家是直播课？**
关键是选老师：你想跟谁学，比直播还是录播更重要。我们采用录播，原因有三：主讲要腾出整块时间备课；要定期外出写生提升；直播时边看评论边回复，容易打断授课节奏，甚至被弹幕带跑。表面播两小时，有效讲解可能只有四十分钟，错过直播再看回放的人往往更费劲、效率更低。录播能把每节一小时都用于干货和知识点，注意力也更集中。真做直播，价格不会停留在现在这个档位。想交流，我们安排定期直播互动；作业提交后老师会看并点评。

**助教水平怎么样？**
助教来自八大美院研究生层级，与主讲在同一团队，批改和辅导作业足以胜任。

**暂时没空，想往后拖，甚至退休后再学？**
时间可以自己定，推迟报名没问题。但对普通人来说，书画既是爱好，也是一项可用的技能，越早掌握越早受益。这一期同好不少，等别人能独立出作品了，再羡慕就有点可惜。课程随时能打开，也可以先报名、先听讲、先学方法，等腾出时间再动笔。最终由你拿主意。

**书法课到底讲哪些内容？**
看老师大纲图即可。内容覆盖篆书铁线篆、褚遂良《雁塔圣教序》和二王行书；重心是把楷书打牢，再带着学员从楷书平稳过渡到行书，最终能轻松写行书。安排上先学褚遂良楷书；如果楷书一结束就直奔行书，很多人会接不上，这也是不少书友卡在“楷转行”的原因。为此课程加入铁线篆做基础训练，基础扎实后再进行书，会顺手很多。

**国画课讲哪些内容？**
同样先看大纲图。老师准备得很完整：瓜果、虫草、花卉、动物、松石、翠鸟都会带画。课程最关键的是传授学习方法，而且是一门写生课。春天出游多，看到好风景、小动物，如何取景、如何构图、如何调色、如何把眼前所见落到纸上，都是课程要训练的能力。报名后，生活中的景物可以随手画下来。还有一点必须提醒：无论在哪家机构报国画课，都要认真挑老师。国画属于艺术，老师的审美和造诣越高，越能带学员走得更远。

#### 5.1.2 零播放的排查与处理
播放挂零，原因可能很多，建议逐项排除。

**用实拍风景测账号行不行？**
除非成片质量足够高，否则别这么试。低质量内容即使实拍也可能零播；账号发实拍仍旧零播，可能说明实拍本身质量不过关。

**收到平台判定搬运的违规通知，账号是不是废了？**
多数零播账号并没有收到通知。反过来看，收到通知至少说明账号还在平台提醒范围内。通常删除违规视频，再继续发新内容即可。

有的圈友会突然全部账号零播，也有的只是个别账号中招。我们的推测是：单个账号若被频繁识别出低质量或搬运内容，容易零播；同一设备、同一网络、同一IP下大批量上传，且这些账号又集中发布低质量或搬运视频，容易被批量判零播。

**批量上传软件会不会踩违规线？**
被判违规通常看两个条件：账号集中出现低质量或搬运内容，以及操作是批量的。如果批量上传的是高质量、非搬运视频，问题应该不大。所以我们不把批量工具一棍子打死；但账号不多时，它节省的时间有限，没必要为这点效率给自己增加不确定性。

**被大规模零播的IP、设备还能继续用吗？**
据我们掌握的信息和圈友反馈，暂未遇到封设备、封IP的情况。也就是说，碰到零播不必急着换IP或换手机，注册新号继续发即可。

零播后的处理：账号问题就注销，立刻启用备用新号继续发；内容问题就提升选片能力。

**注销后就是全新账号吗？能马上发吗？**
提交注销申请后，第一次要等7天完成注销并注册新号，第二次是10天。注册好的新号就是全新账号，可以马上发布。建议多备账号：旧号一提交注销，就启用新号，绕开7天等待。

**怎么准备足够多的账号？**
每人可注册5个微信号、5个视频号；三大运营商各能申请5个手机号，另外还能申请注朋卡。用自己或亲友的手机号注册新微信号、视频号，请亲友协助认证，做到15—20个账号并不难。

**账号要注销，佣金来不及提现怎么办？**
可以把多个账号的带货佣金合并结算到同一个微信号。具体做法见星球贴《微信小商店带货佣金集中的操作》（感谢圈友@未来的分享）。

避免零播：手机尽量一机一号，用流量登录微信，避免同一IP下批量操作触发批量零播处罚。

### 6.3 引流与转化的思路

1. 用一个微信号承接流量。矩阵号引流时，建议所有用户都加到同一个微信号。几个账号同时引流，能大大加快成群速度。一般一个人3—4个账号，确保每天发笔记数量，一周可以开1—2期课程，统一转化。
2. 一个用户可以多次转化多个课程。注册成为分销员后，系统内课程都可以分销。航海期间为了不混乱，只放了2个商品，先让大家集中精力完成至少一次转化；航海结束后会开启所有商品的分销权限。这样在必修部分书法、国画转化课的基础上，还能增加其他课程，做二次甚至多次转化。比如开隶属体验营，转化隶书课程；开莫骨画训练营，转化莫骨画课程。首次没购买的用户，可以二次邀请他参加其他体验营尝试其他转化；首次购买的用户，学期结束后也可以二次邀请他参加其他体验营尝试其他转化。
3. 可以尝试自己做课程，打造自己的课程体系。做课程没大家想得那么难，不需要你具备专业知识，找到书法和国画专业的大学生合作做课即可。你需要做的是了解、参考市面上热门书法国画课，调研用户需求，确定课程形式和要讲的内容，专业部分交给老师制作。可以先从简单的单门课做起，比如楷书课、隶书课、写意画课程。做成一个课，就能提高一部分利润，再逐渐完善课程体系。缺老师资源，可以联系前面说过的分配点评老师的助理微信【4.2.1 正式开课前准备-5.获得点评老师】，他能推荐一些老师资源。当然，如果你有课程研发经验，做起来会更容易。等流量稳定了，也完全可以找有相关能力的人一起合作。
