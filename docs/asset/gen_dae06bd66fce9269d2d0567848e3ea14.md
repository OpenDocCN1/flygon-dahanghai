第四步：确定经营类目。这里先提醒一句，所选类目必须落在商标注册证写明的范围之内。

第五步：等待平台审核。通常 3 个工作日内会有结果；若未通过，平台会通过电话或邮件通知。期间遇到任何疑问，都可以找在线客服咨询。

审核放行后，最后一步是缴纳店铺保证金。要注意，开卡账户需为对公账户，并且开户人姓名要与入驻时填写的经营人保持一致。

接着看旗舰店和专卖店的申请流程。整体与普通企业店接近，但下面四点需要特别注意：

第一点，填写品牌相关信息。如果系统里搜不到你的品牌名称，就点“新增品牌”进行添加；上传 logo 图片时，务必保证与商标注册证上的图案完全一致。

[PRE2]

[PRE3]

第二点，分清自有品牌和代理品牌。若是代理品牌，要确保授权链路完整，公司名称选择营业执照上的名称即可。

[PRE4]

若是自有品牌，也就是商标持有人为自己公司或公司法人，注册类型通常分 R 标和 TM 标：R 标指注册商标，TM 标指商标注册申请受理通知书。

[PRE5]

其中，个人型 R 标需要上传商标注册证，以及商标权利人的身份证或护照复印件/扫描件。

[PRE6]

个人型 TM 标同样要上传商标注册申请受理通知书，并附上权利人的身份证或护照复印件/扫描件。

[PRE7]

如果申请的是企业型 R 标或 TM 标，则只需提供商标注册证或商标受理通知书即可。

第三点，选择售卖品类时要谨慎勾选“定制”品类。

第四点，审核通过后还要签署合同。合同会以线上邮件形式发送，并通过电话或验证码确认签署。

之后就进入缴纳保证金环节，注意事项与前面的普通企业型店铺相同。

最后再说集合店。集合店仅接受平台邀约入驻；收到邀约后，入驻流程与旗舰店、专卖店一致。

全部申请通过后，就可以上传商品开店了。进入账号首页，能直接看到店铺和商品入口。

总体来看，企业型店铺的商业权益会比个人店铺更多，但维护费用也更高，大家结合自身情况选择即可。

另外，入驻类目、审核等环节如有不明白的地方，建议第一时间联系“人工服务”咨询。商家客服回复比较及时，能快速帮你解决问题。

# 2. 什么是蓝海产品

不管是传统货架电商淘宝，还是兴趣电商小红书，蓝海的定义只有一条：自己干得过的就叫蓝海，自己干不过的就是红海。大家可以结合自己的情况来判断。

蓝海电商的市场容量一般不会很大，也就是说销量不会太猛。所以选品时尽量选高客单、高利润的品，这样利润更有保障，做起来也会轻松一些。

蓝海电商的产品可以分为标品和非标品。

标品一般在小红书都有同行参考，优点是做起来容易些，缺点是容易被跟，从蓝海到红海的周期很短；

非标品是指在小红书没有同行参考，你就是第一个做这个品的人。非标品的优点是生命周期较长，缺点是做起来比较困难。

鉴于此，本次航海主要给大家介绍【小红书电商蓝海标品的打法】，帮助大家尽快拿到正反馈、树立信心，早日步上正轨。

# 1. 蓝海选品思路

在讲具体方法之前，先梳理一下小红书选品的思路。选品方法有很多，整体不外乎三个大方向：

1、日常多刷小红书站内爆款选品。我们在小红书卖东西，肯定要了解平台最近哪些品比较好卖。多刷多看，有条件的也可以通过灰豚看数据、找低分爆款来选品。不过新手一般不建议直接上工具，平台多刷就够了，还能培养网感。

2、从传统电商平台——淘宝选品（推荐⭐）。即从淘宝找合适的品。淘宝的分类页面，有目前国内所有主流搜索电商平台里最全面的类目；而且淘宝作为电商平台相对最成熟，也不需要用到任何付费工具。常用方法有：淘宝分类页面选品、淘宝神店榜选品、淘宝榜单选品、天猫榜单选品。

3、从其他兴趣电商平台——抖音选品。即从跟小红书一样靠内容带货的平台找品，目前建议从抖音找合适的产品。常用方法有：考古加选品法、蝉妈妈选品法、抖音精选联盟的创意中心选品法等。

所以，在正式选品前，建议大家先刷至少 2 小时小红书，对平台当前爆品增加一些体感。
