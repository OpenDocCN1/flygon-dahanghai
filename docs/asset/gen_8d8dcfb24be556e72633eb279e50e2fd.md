# 编剧签约避坑与漫剧剧本实操

签合同、交稿、写漫剧，这三件事都别靠“想当然”。下面把合同里的坑、履约时的动作，以及漫剧剧本特别是“金手指”的写法，一次讲清楚。

甲方超时不反馈怎么办？合同里提前写明白：超过约定天数没回复，就视为验收通过。甲方如果要推翻重写，比如调整整体方向、世界观、人设体系、叙事结构，这属于整体重写，费用和工期需要双方重新确认。参考写法可以这样：当甲方要求对整体方向、世界观、人设体系或叙事结构做推倒式调整时，双方应就报酬和交期另行协商并书面确认。

④ 明确版权归属

版权归甲方时，可以参考这种写法：甲方付清全部报酬之后，剧本著作权才转移到甲方；在此之前，甲方拥有审核权，并可通过微信或邮件沟通，将剧本用于商业用途、备案或对外披露，乙方保留署名权。

要确认的关键信息有三个：版权到底什么时候转移，正确时点应是全款结清后，而不是一签约就转移；自己有没有署名权；付款之前，甲方能不能使用剧本。

⑤ 明确协议终止条款

参考条款可以写成：如果甲方提出提前终止合作，应按乙方已完成内容的分钟数结算，单价150元/分钟，不能以“整本还没完成”为理由拒付报酬；如果乙方需要提前解除协议，必须至少提前7日书面告知甲方。

这里要确认：项目中途取消时，已完成部分怎么结算；自己想退出时，要提前多久说；违约责任怎么划分。

2.2.2 如何和甲方沟通争取权益

很多新手会觉得“人家给我机会就不错了，条款就这样吧”，这个心态要改。合同是可以谈的，合理争取权益不会让对方看低你，反而会显得你专业。

拿实际例子说：最初合同写的是税后到账，但6%税费要自己承担；经过三次修改，把这条改成税后净额到账、所有税费由甲方承担。版权和署名权也一样，都可以先争取。

可以谈的点包括：修改次数上限，合同没写就一定加上，否则对方能无限让你改，时间成本控制不住，建议约定每集修改不超过3次；审核反馈时限，合同没写甲方反馈时间就补进去，不然你交了稿对方拖两周不看，排期全乱；整体重写另计费，这是最重要的保护条款，“微调”和“推翻重来”是两回事，后者必须另行计费；到账金额确认，一定写清是“税后到账”还是“税前”，差别可能有几千块；版权、署名权、纠纷由哪一方所在地法院管辖等内容也要写。

修改后的合同，记得用另一种颜色标注，沟通时告诉甲方你为什么这样改，态度温和且专业；不会表达，可以让AI帮忙润色。

3. 签完合同还不算完——盯紧甲方履约

合同签了不代表万事大吉，后续执行阶段也要主动管理，全方位保护自己的权益。

交付阶段：每次交稿后用微信或邮件留痕确认，比如“XX总，第X至第X集已提交，请查收审核。”如果甲方超过约定时间没反馈，主动跟进：“按合同约定，审核时间为1天，目前已超过X天，请问是否有修改意见？如无意见，我按流程进入下一阶段创作。”

打款阶段：到了打款节点，主动确认：“按合同约定，本周应打第X笔款，麻烦安排。”收到款后核对金额是否正确，保留转账截图。如果打款延迟，先礼貌催一次；超过3天没到账，正式书面沟通，用微信文字，不要只打电话。

留证意识：所有沟通尽量在微信文字或邮件里留痕，不要只靠电话；每次交稿、每次确认修改意见、每次打款，都保留截图；合同原件或电子版妥善保存。

最坏情况的处理：如果甲方明确拖欠不付款，你手上有合同、交付记录、聊天记录，可以走法律途径。金额不大的话，直接去法院走小额诉讼程序，成本很低，震慑效果很强。当然，最好别出现最坏情况。

### 03. 制作流程：AI 漫剧剧本怎么写

1. 先认识剧本

1.1 剧本不是小说

别把漫剧剧本当小说写。小说是让读者“脑补画面”的，可以写心理活动、大段描写环境，节奏慢一点也没关系。漫剧剧本是给制作团队看的“施工图纸”，你写的每一句话都得能变成画面或声音，无法视觉化、听觉化的内容不要出现；它像执行文件一样，要明确“做什么、怎么做、做成什么样”。公式就是：剧本=画面+台词+动作。

小说式写法：他暗想，这个女人太可恨，前世就是她害死我，这一世必须报仇……
剧本式写法：▲林浩盯住面前的女人，眼神阴沉。林浩（咬牙）：苏婉，这笔账该算了。

剧本的格式

常规短剧剧本格式，新人可以参考：第x集标注集数；夜/日标明晚上或白天；外/内标明室外或室内；地点写广场、车站、酒店等；场1-1、场1-2表示场次；▲后面放除对话外的内容，一般是人物动作；括号里写说话时的语气、神态、动作；回忆镜头用【闪回】开始、【闪出】结束。

短剧的“爽文基因”，写作注意事项

漫剧短剧本质上是“视频版爽文”。观众打开漫剧图什么？图爽。主角被欺负，爽在等他反击；主角开挂，爽在代入感；反派被打脸，爽在出了口气。写漫剧剧本，核心就一件事：让观众爽，而且要快。一集只有1-2分钟，没时间铺垫、酝酿、慢慢来。观众3秒钟不爽，手指一滑就走了。

搞清楚“金手指”

这个词会经常看到，先解释：金手指就是主角获得的超能力、系统或外挂。比如签到系统每天签到领奖励，透视眼能看穿一切，读心术能听到别人心里想什么。金手指是爽文的核心驱动力。没有金手指，主角凭什么逆袭？靠努力吗？观众没那个耐心。

设计金手指：剧本核心卖点

金手指是短剧、漫剧的“流量密码”，直接影响观众前30秒是否停留、有没有追更意愿，也是剧本差异化竞争的核心。好的金手指要满足：低理解成本、高爽点反馈、强题材适配、有成长空间，同时贴合“短平快、强冲突”的行业要求，避免冗余设定。

金手指六大原则（短剧/漫剧行业实操）

原则一：立刻见效，别让观众动脑

短剧漫剧观众多在通勤、休息时刷，注意力很短：前3秒得抓眼，30秒内要看到爽点。所以金手指规则要一句话说清，不能让人记设定；触发后10秒内要出现翻盘或收益。最忌收集、消耗、惩罚类设定堆太多，观众一算规则就烦，爽点一慢就划走。

反例：时空回溯系统，要攒10片时空碎片才能回1分钟，回溯耗精神力，精神力不够做隐藏执念任务补，每天限3次，超2次还时空紊乱，周末额外1次……规则多、限制多、任务模糊，观众不知道能得什么，追更动力没了。

正例：后悔就重来系统，选错、被欺负、错过机会，默念“重来”回到10秒前，每天5次，没额外限制；一句话懂，触发简单，效果马上来。

进阶做法：触发动作直接给画面，比如握拳、眼神变冷，不用台词，适合漫剧和快剪短剧。

原则二：跟题材咬合，别当外挂

金手指是推剧情的工具，不是剧本外的外挂。别为了爽硬塞无关能力，否则剧情违和、观众出戏。先定题材，再按核心冲突设计：宅斗要辨诡计，就做鉴伪、读心；甜宠要拉近距离，就做共情、默契。

反例：宅斗给美食制作系统，做菜得食材、解锁菜谱、靠厨艺受宠步步高升——宅斗看的是权谋、人际博弈、防陷害，美食系统推不动主线，显得跑题。

正例：宅斗给读心鉴伪系统，碰人读心声识破诡计，碰物鉴真伪识破假证据、毒食、伪善面具，用后休息1炷香。贴合防陷害辨真伪，能推进剧情，轻微限制还能造悬念，避免金手指太强让剧情平淡。

原则三：让金手指跟着主角升级

连载剧常规10-100集，竖屏短剧常见50-100集，赚钱靠观众追更解锁。开局就把金手指拉满、主角无敌，悬念没了，第一集看完就弃。金手指要有成长线，伴随主角变强，同时留1-2个轻微限制造冲突。成长逻辑是：解锁新能力→遇到更强反派或更难任务→爽点升级、冲突升级，观众才有期待。

反例：都市逆袭开局全能首富系统，无限财富、顶级人脉、绝世武功，出场秒一切，第一集人生巅峰，后面没法推进。

正例：废柴逆袭系统分三段：1-10集给基础技能，比如快速赚钱、简单格斗，目标是脱贫、教训小反派，完成后解锁中级；11-30集给中级技能，比如优质人脉、核心技术，目标是创业起步、打败中层反派，完成后解锁高级；31集以后给高级技能，比如行业垄断、顶级实力，目标是登顶、打败终极反派。每次升级都触发更强反派，高级技能每天限3次，避免无敌。小目标有即时奖励，大反派留长期悬念，追更钩子就有了。

原则四：反套路，给点新鲜感

市场同质化严重，签到、打卡、刷题变强、首富系统太多，金手指雷同也留不住人。要反套路、有脑洞、门槛低：不用复杂设定，就能打破老认知，最好自带话题或笑点。

反例：学霸系统每天刷题背书攒buff，提成绩、解锁解题技巧、考顶尖学府——套路化，看开头知结尾，没记忆点。

正例：摆烂就变强系统，越摆烂越强：上课睡觉得过目不忘，作业不写有解题秒杀buff，拒绝内卷反升身体素质；摆烂越久奖励越厚，但不能主动伤人，轻微限制防崩。反套路、搞笑、踩中年轻人拒绝内卷的情绪，容易引话题，能成核心卖点。爆款《摆烂后我靠系统杀疯了》单集播放破千万，就是这个路数。

原则五：金手指要长在人设上

金手指要贴合主角性格和身份。性格、身份决定触发方式和使用场景；贴人设，观众才觉得这能力就该是他的，可信度才高。别硬配：软萌内向女主无铺垫配暴力格斗系统，憨厚男主配阴谋算计系统，都出戏。

反例：软萌胆小职场实习生配霸气怼人系统，触发方式是大吼对手，怼赢得晋升buff——人设和触发方式矛盾，没铺垫，突兀，爽感打折。

正例：同一人设配无声反击系统，触发方式是在心里默念反击话术，反击成功得勇气buff，逐步克服胆小，再解锁职场自保技能。不用逼角色突破性格，爽感有了，成长线也有了，代入感更强。

原则六：别把爽点用滥

用得太滥，观众会爽点麻木；用得太少，又不够爽。频率要跟短剧漫剧节奏走，还要卡剧情冲突：反派挑衅、主角陷入危机时触发，别没事就触发。多集连载按高潮低谷调频率，高潮多、低谷少，节奏才有起伏。

反例：透视神医系统单集2分钟触发7次，走路喝水对视都触发，奖励只是轻微视力提升、普通创可贴，没反派、没危机，纯为触发而触发；题材虽热，但频率超标、无意义，观众1分钟就麻木，也推不动神医逆袭打脸主线，弃剧率高。

正例：透视神医系统单集2分钟精准触发3次，每次都贴冲突：1.同行嘲笑他连小病都治不好，触发透视看穿病因，初步打脸，开头30秒抓眼；2.患者急症昏迷、众人无策，触发系统得专属药方，救回患者，翻盘爽点推剧情；3.反派拿假药材陷害，触发透视当场戳穿，彻底打脸，高光爽点留记忆。

总口诀：四大核心+两大辅助。核心顺序是即时爽感→题材适配→梯度成长→反套路破局；辅助是贴合人设→控制频率；六个字：爽、贴、梯、新、合、度。四个坑要避开：规则繁琐，一句话说清，别堆冗余；脱离剧情人设，围着题材核心冲突和主角人设转；同质化，反套路、加脑洞，绑题材或情绪；频率失衡，单集触发3-5次，卡冲突时机。轻微限制1-2个最合适：无限制=无敌=弃剧，限制太多=爽点被稀释=弃剧，平衡才既爽又能追更。触发效果尽量做成画面，技能视觉化，少用台词解释，适配短剧漫剧传播。六条一起用，吸睛和落地都能兼顾，爆款概率才高。
