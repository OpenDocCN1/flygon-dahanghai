# 2.1 蓝海品筛选标准⭐

1.

蓝海产品的定义

无论传统货架电商淘宝，还是兴趣电商小红书，蓝海的判定标准只有一条：自己能干得过的就是蓝海，干不过的就是红海。具体怎么判断，要结合自身条件来定。

通常来说，蓝海电商的市场容量不会太大，销量也不会特别猛。因此选品时应优先考虑高客单价、高利润的产品，利润空间有保障，操作起来也更从容。

蓝海电商产品分为标品和非标品两类。

标品在小红书上通常能找到同行参考，优势在于上手相对容易，劣势是容易被跟进，从蓝海滑向红海的周期很短；

非标品则在小红书上找不到同行参考，你就是第一个吃螃蟹的人。其优势是生命周期较长，劣势是起步难度更大。

基于以上特点，本次航海重点介绍【小红书电商蓝海标品的打法】，帮助大家尽快获得正反馈，建立信心，早日步入正轨。

2.

什么样的产品才算合适？选品不能凭感觉，最好挑选已经爆过或正在爆的产品，这样爆率才有保障。

# 2.2 蓝海选品思路

在展开具体方法之前，先梳理一下小红书选品的整体思路。

选品方法虽多，归纳起来不外乎三大方向：

1、日常多刷小红书站内爆款选品

在小红书卖货，首先要了解平台近期哪些品好卖。多刷多看，有条件的也可通过灰豚查看数据、寻找低分爆款来辅助选品。

不过新手不建议一上来就用工具，平台多刷就够了，顺便还能培养网感。

2、从传统电商平台-淘宝选品（推荐⭐）

即从淘宝寻找合适的产品。淘宝分类页面拥有目前国内主流搜索电商平台中最全面的类目体系；同时淘宝作为电商平台成熟度最高，且无需任何付费工具。

常用方法包括：淘宝分类页面选品、淘宝神店榜选品、淘宝榜单选品、天猫榜单选品。

3、从其他兴趣电商平台-抖音选品

即从与小红书一样靠内容带货的平台寻找合适产品，目前建议从抖音入手。

常用方法有：考古加选品法、蝉妈妈选品法、抖音精选联盟创意中心选品法等。

因此，正式选品前，建议先刷至少 2 小时小红书，对平台当前爆品建立基本体感。

# 3.1 测品的逻辑

测品的本质：选品的验证。

测品是对选品的验证。选品阶段通过分析同行链接数据，大致能判断出该品目前在小红书平台的竞争程度、月毛利润、流量水平等指标，但这些数据仅停留在纸面分析层面。我们选的品究竟能否赚钱，最终还要靠测品来检验。
