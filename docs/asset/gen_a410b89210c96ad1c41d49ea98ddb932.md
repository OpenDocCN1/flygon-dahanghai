# 3.14 同一个词，为何每个人搜出的排序不同？

抖音搜索并非所有人看到同一套排序，而是呈现出“千人千面”的特点。越是竞争激烈的关键词，尤其本地生活类词，不同用户搜索后得到的结果往往存在差异；这一特性也可以用来观察和测试数据表现。

所谓千人千面，并不是每个人看到的内容完全不同，而是展示顺序会有区别，整体结果仍大体一致。举个例子：同一条视频，有人看到它排第一，有人看到它排第五，出现先后会变；但被展示的视频基本还是那一批，变化主要集中在排序上。

为什么会出现这种情况？

1）灰测（灰度测试）机制。平台可能先让你的作品以靠前甚至第一的位置出现，观察数据反馈：表现不理想，排名会往下走；反馈较好，排名会继续上升，直到趋于稳定。于是就会出现有人搜到第一、有人搜到第十的情况。

2）个性化推荐。每个抖音账号都带着地域、兴趣、年龄、性别等标签。用户搜索关键词时，平台会参考内容本身的排名，再叠加用户标签与行为数据，把更匹配的内容推到前面。比如搜索团购类关键词，距离用户更近的结果会获得优先展示：
