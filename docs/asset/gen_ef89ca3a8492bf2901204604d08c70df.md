# 3.6 方式五：抓准平台的一个限制，小工具年入 200 万美元 ★★★ @Seep

前几天读到亦仁老师那篇《通过 Google 挖掘细分市场的一个案例》，觉得思路很有意思，就跟着实操了一次，结果真让我挖到一个围绕 Instagram 生态赚钱的典型案例。

这个案例的主角是 linktr.ee，创始人叫 Alex Zaccaria。这个网站本身极其简单，但据说每年能带来约 200 万美元的收入。更让人意外的是，创始人透露，这个项目冷启动时没有花过一分钱做推广，用户完全是靠自然增长滚起来的。

背后的逻辑其实很清晰。Instagram 长期有一个“一个链接”规则：用户没法在帖子或日常内容里随意放链接，唯一的链接入口，就是个人资料页那一栏。这样一来，如果你希望粉丝通过不同链接分别跳转到不同页面，基本上无法实现（除非借助 FB 广告投放）。这对依靠 IG 变现的网红和商家来说相当头疼——商家通常既有 Amazon 店铺又有独立站，网红要给不同品牌带货或宣传，他们都希望粉丝能自由跳转到对应的页面，可 IG 的政策正好把这条路堵死了。

linktr.ee 恰好充当了那个“中间页”。本质上，它就是一个落地页生成工具：用户创建后，可以把多个站外链接集中放在同一个页面上，粉丝点进来后想去哪里去哪里。免费版已经能满足基本需求，PRO 版则额外提供数据追踪和页面装饰功能，让用户清楚看到每个链接的表现，也能把中间页打理得更有个人特色，强化品牌辨识度。

这门生意最特别的一点在于，它没有任何复杂变现模式，不靠广告、不靠电商，所有收入都来自 PRO 版的订阅。一个简单工具，精准切中平台规则带来的需求缝隙，就足够撑起一门年入两百万美元的生意。

内容出处：《围绕 Instagram 赚美元的案例》
