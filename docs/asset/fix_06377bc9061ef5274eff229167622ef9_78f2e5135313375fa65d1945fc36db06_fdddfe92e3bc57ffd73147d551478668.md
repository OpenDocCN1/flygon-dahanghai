# 合伙先分清：谁在干活，谁在分钱

我是刘宁培，常驻深圳，家里有一对龙凤胎，平日做企业咨询，主要碰股权架构、经营治理和商业模式。写于2023年2月17日。

前些天，邻居领来三位刚走出校门的年轻人。他们不想再打工，打算合做亚马逊电商，先来问股权怎么摆。现在的情况是：三人共同出钱，分红均分；工商登记先挂两人名字，比例六四开。其中一位明白这样埋雷，也预感将来会各奔东西，却找不到调整的切口。住得不远，我便约她们夜里到家里坐坐，把常规做法拆开讲，能补一点是一点，免得日后撕破脸。

控制权怎么放、入伙怎么进、分配怎么定、退出怎么走，以及十六个常见坑，我此前专门写过，这里不重复。但有一个点必须再敲一遍：一起做事，先看这个人是不是合格的经营参与者，再谈他作为出资人怎么分钱。

亲友同事一起做生意，结局常常不美。我常被问到的情形包括：只出钱不干活、出钱又出力、全职但不出资、出资相同却有人不参与经营、管理岗拿工资同时又要按股分红；还有服装店、饭店、便利店、音乐餐吧、电商等不同业态下，工资与股比怎么摆。问题花样多，底层是一件事：把劳动身份和资本身份搅在一起。

过去我说九成以上早期团队会踩这个坑，后来发现说轻了。从正月初十复工到现在，我接的每个小咨询案，无一例外都把劳动身份与资本身份混着谈。

接下来分三步拆。

**一、先立框架：劳动侧与资本侧不能混**

[PRE3]

1、几位彼此信任、能力与资源能互补的人共同设立公司，推进一个项目；

2、账上先备足一年零营收也能撑住的现金，别让第一年资金链断掉，至少扛满一年；

3、把组织架构画出来，在图上明确岗位、职责、薪酬包（底薪、提成、绩效等）；

4、把公司一年的进账拆成两块：一块支付经营侧员工薪酬，一块留下作为资本侧股东利润。示意图中标蓝的剩余利润，才是股东可分配部分。若A既出资又在公司任职，先按员工看，再按股东看。

作为员工，第一件事是职责：在哪个岗就担哪个岗的责，按岗位说明完成任务；A是来干活的，不是来摆老板派头、对同事发号施令。核心位置若不胜任，不能继续占着；有自觉就主动退下，别拖累团队，等年底按股分红；没自觉，其他出资人应把他换掉。核心位置不换人，项目要么一直收不了尾，要么直接泡汤。

第二件事是权利：按岗位领底薪、提成或绩效，销售岗尤其按规则拿。大股东不领业务提成，后患不小。大股东一“高风亮节”，小股东就难办：小股东有行业资源，一年能拉百万订单，提成政策一成，普通销售拿十万；大股东不拿，小股东怎么好意思拿？结果可能把订单转给同行，先赚十万提成。久而久之，小股东热情消退，陆续退股。

作为股东，公司进账先覆盖经营侧全部薪酬提成等支出，余下利润再由股东按持股或约定比例分。

**二、三组情形，拆开看就明白**

情形1：两人共同投30万开便利店，股比对半。A在店当店长，B另有项目不参与。劳动侧：A按当地店长行情领工资和提成；B不干活，劳动报酬为零。资本侧：扣除店长年薪等经营开销后的利润，两人各半。

情形2：L和M是好友，讲交情，各出一半开苏宁易购门店，两人每天守店十小时卖电器。起初约定都不拿固定工资和业务奖金，每月营收减产品成本、房租水电等杂费，净利一人一半。前几个月顺，第九个月L抱怨：自己扛了九成销售，M越来越松只贡献一成，干多干少分一样，不如单干，想拆伙。调整：劳动侧仍不设固定工资，但按业绩提成，比例事先谈妥；L做九成业绩就拿九成提成，M做一成拿一成。资本侧：营收减经营支出（含销售提成）后的利润，仍对半。

情形3：某客户ABC分别管产品、销售、运营，模式跑通后年利润几百万，三人开始争“我的岗位更值钱”，想多拿股或多分红。若创业初期没设计股权随业绩调整的规则，后面改股比非常困难。股权在成立时已定，分红按股比；岗位薪酬和提成也在成立时定，按制度执行，日常只会在平均线附近浮动，不会大起大落。若是新项目，可另设公司或事业部，独立核算、按约定分；若是老项目已年赚几百万，三人都嫌自己拿少，只能说姿态不好看。

小结：类似情形不少。别以为成了合伙人就亲密无间；夫妻之间还会因为“谁对家贡献大”吵到离婚。都是普通人，不是圣人，熙熙攘攘多为利。合作前把规则讲清，别拿利益去考验人性。老话有理：丑话在前，后面更容易做君子；情面在前，最后常成小人。

**三、收口：劳动身份在前，资本身份在后**

（1）劳动侧：坐哪个位置，就扛哪份责任；拿哪份职责，就尽哪份本分。能干就好好干，别动不动给老板甩脸色。“老板”过去可以摆谱，但在00后眼里，老板不合约就离职很常见；不能干就体面离开。公司少一个不称职的员工（哪怕他也是股东），项目反而跑得更快。

（2）资本侧：营收先支付员工报酬等经营支出，剩余利润按持股或约定比例分。

别把劳动身份和资本身份混着谈，否则分配必出问题，最后散伙；若还没散，多半是利润还小。

文末有读者留言。长青一剑说深有体悟，我回问是不是经历过；嘉达想听“股权随业绩浮动”在创立时怎么落地；晓崎建议预留10%作奖励池或预备金；亦仁兄加精，我致谢。我的回复是：可以约定业绩对赌式调整，比如A与B谈好，做到1000万年业绩，A持股从30%升到40%；做到2000万，升到50%，依次类推。资源型股东和高管可用，合计预留上限一般30%；资金型股东通过增资扩股进入，所有股东同比例稀释。
