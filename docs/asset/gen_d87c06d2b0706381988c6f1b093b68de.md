# 1.4.1 爆款笔记是怎样被算法推出来的

和多数公域内容平台相似，小红书的内容分发同样由算法推荐驱动。笔记刚发布时，系统会重点观察它的初始互动表现——点赞、收藏、评论、转发分享以及转粉情况，并据此打分。其中，评论、转发分享和转粉的权重更高。

这套内部评分常被称为 CES，计算方式是：点赞、收藏各计 1 分；评论、转发各计 4 分；新增关注计 8 分。需要说明的是，CES 属于小红书内部的评分体系。

当分数不断上升，笔记就会被系统逐层送入更大的推荐范围，进而成为爆款。一般来说，互动量到 1000 以上可算小爆款，到 10000 以上则进入大爆款区间，具体门槛会因类目不同而有差异。一篇爆款还会带动账号里其他笔记的整体数据上涨。不过，想进入推荐正循环，至少要满足几个条件：

① 笔记已通过平台审核，没有违规，也没有被平台删除，或被作者删除、隐藏。
② 笔记包含明确关键词，例如香水、家具，能够归入对应的垂直标签，被系统识别收录，并推荐给关注这类标签的目标人群。
③ 内容质量本身过硬，足以吸引用户点赞、收藏、评论等互动。

还有几点要提醒：

零基础新手很难靠第一篇笔记就做出大爆款；运营第一个月，小眼睛（阅读量）停留在 100—200 很常见，基础较好的账号见效会快一些。约 80% 的新手要到第二或第三个月才会迎来爆发，前面存在蓄力阶段，所以不必太焦虑，耐心把内容打磨好即可。
