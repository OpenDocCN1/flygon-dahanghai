# 1.5.3 案例：旅游计划生成

先装好下面要用的几个 MCP Server。

# 1.5.3.1 MCP 服务安装

本例涉及 Excel、高德地图与 filesystem 三项能力。

# ① Excel 服务安装

先从 GitHub 获取 Excel 服务代码：GitHub - haris-musa/excel-MCP-server: A Model Context Protocol server for Excel file manipulation。熟悉 git 的可以直接 clone；不熟悉也可以下载 zip，解压到本机。

接着开一个终端，切到源码所在目录：

```bash
cd 你的项目目录
```

[PRE7]

装依赖之前，请确认 UVX 已经可用，然后依次执行：

```bash
uv venv
uv pip install -e .
```

启动 excel-mcp-server：

```bash
uv run excel-mcp-server sse
```

[PRE8]

若要换端口，按操作系统二选一：

```bash
# Bash/Linux/macOS
export FASTMCP_PORT=8080 && uv run excel-mcp-server sse

# Windows PowerShell
$env:FASTMCP_PORT = "8080"; uv run excel-mcp-server sse
```

[PRE9]

回到 Trae，把该服务加入配置。

[PRE10]

将下面的配置粘贴进去，并替换 url、env 为实际值：

```json
{
  "mcpServers": {
    "excel": {
      "url": "http://localhost:8000/sse",
      "env": {
        "EXCEL_FILES_PATH": "/path/to/excel/files"
      }
    }
  }
}
```

其中 `http://localhost:8000/sse` 换成你的服务地址，`/path/to/excel/files` 换成授权目录。

[PRE11]

确认之后，MCP 的运行状态与可用功能都会显示出来。

[PRE12]

接着可做一次连通性测试。

[PRE13]

通过测试结果，就能判断这个工具是否真的能调用。

提醒：若 excel-mcp-server 采用 sse 方式启动，终端窗口不能关，要保持在后台。手册现已补充该服务的 stdio 启动方式，详见 3.4 节。

# ② 高德地图服务

先查阅高德地图 MCP Server 文档：概述-MCP Server | 高德地图 API。

[PRE14]

在高德开放平台完成账号登录，再申请开发者身份：注册成为开发者。

[PRE15]

进入控制台的应用管理页 https://console.amap.com/dev/key/app，新建应用并添加 key。

[PRE16]

把 key 复制出来，填到以下配置里：

```json
{
  "mcpServers": {
    "amap-amap-sse": {
      "url": "https://MCP.amap.com/sse?key=您在高德官网上申请的 key"
    }
  }
}
```

再切到 Trae，将高德地图 MCP 服务加入，粘贴代码后检查状态。

# ③ filesystem 服务

该服务 Trae 已经内置，因此可以直接略过。若你换用别的客户端且没有内置，可照下面思路操作：在 Trae 的 MCP 市场搜索它。

[PRE17]

打开详情预览，往下翻即可看到对应配置。此处采用 npx 方案，复制代码后按系统选择写法。

macOS：

```json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-filesystem",
        "/Users/username/Desktop",
        "/path/to/other/allowed/dir"
      ]
    }
  }
}
```

Windows：

```json
{
  "mcpServers": {
    "filesystem": {
      "command": "cmd",
      "args": [
        "/c",
        "npx",
        "-y",
        "@modelcontextprotocol/server-filesystem",
        "C:\\code\\MCP\\MCP-test"
      ]
    }
  }
}
```

注意把目录路径替换成你准备授权的实际位置。

[PRE18]

将配置贴入后，案例所需服务就齐了。
