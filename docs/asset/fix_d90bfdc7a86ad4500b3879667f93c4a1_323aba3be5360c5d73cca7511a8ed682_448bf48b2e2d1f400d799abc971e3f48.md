# 5.1 Windows 系统本地安装

# 💡

在本地部署 ComfyUI 的好处很直接：能装自己需要的节点，能随意换模型，还能识别本机目录。坏处也摆在明面上——显卡要够劲，安装步骤得自己走一遍。

安装包分四种，官方版和整合版两大路线，选一种就好。

想省事，官方桌面版（105M）最合适，它会自动获取模型与第三方组件。硬盘吃紧，就选官方纯净版（1.46G），什么都不带。硬盘不大不小，Liblib 整合版（2.84G）把一部分常用组件和模型整合了进去。硬盘宽裕，果断秋叶整合版（3.7G），模型、组件、工作流都包好了。

# 5.1.1 硬件准备

操作系统建议 Windows 10/11，Mac 就别折腾本地安装了。内存至少 6G，想流畅一些尽量上 8G 或 16G。显卡方面，显存要大于 4G，最低能用 Nvidia 10 系独显，有条件直接上 30/40 系。品牌排行牢记 N 卡 > A 卡 > I 卡，N 卡（英伟达）效果最佳，A 卡（AMD）排第二，I 卡（Intel）的支持相对薄弱。硬盘最少留出 100G，越大越好。电源额定 400～600 瓦即可。CPU 和主板没有要求。

# 5.2.3 手动安装方法

参考教程：https://zhuanlan.zhihu.com/p/666047912（原作者：MarKA）

针对 Apple Silicon Mac（M1/M2/M3）的手动安装流程，下面步骤已做到最简，无需 conda。

1. 键入 Shift+Cmd+U 进入“实用工具”目录，打开“终端”。

2. 初始化环境（Homebrew 与相关依赖）：

```bash
cd ~
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
brew install cmake protobuf rust python@3.10 git wget
```

3. 生成安装脚本。将下面整段内容复制进终端，回车即可：

```bash
cat > cfinstall.sh << 'EOF'
#!/bin/bash
# 创建虚拟环境
cd ~
python3 -m venv cf
# 激活虚拟环境
source cf/bin/activate
# 升级 pip
pip install --upgrade pip
# 安装相关依赖
pip install torch torchvision torchaudio
# 克隆 ComfyUI 代码并安装依赖
git clone https://github.com/comfyanonymous/ComfyUI
cd ComfyUI
pip install -r requirements.txt
pip uninstall numpy
pip install numpy==1.26.4
# 安装插件管理器及汉化插件
cd ~/ComfyUI/custom_nodes
git clone https://github.com/ltdrdata/ComfyUI-Manager.git
cd ComfyUI-Manager && pip install -r requirements.txt
pip install setuptools
cd ..
git clone https://github.com/AIGODLIKE/AIGODLIKE-ComfyUI-TRANSLATION.git
echo "ComfyUI 部署完成！"
EOF
```

4. 运行脚本：

```bash
bash cfinstall.sh
```

[PRE31]

5. 拉取模型（镜像地址，适配国内网络）：

```bash
wget -P ~/ComfyUI/models/checkpoints https://hf-mirror.com/LarryAIDraw/v1-5-pruned-emaonly/resolve/main/v1-5-pruned-emaonly.ckpt
```

[PRE32]

[注] 若已有 SD-WebUI，模型无需再下，让 ComfyUI 直接调用 SD-WebUI 的模型库即可（前提：stable-diffusion-webui 位于 home 目录）。

```bash
mv ~/ComfyUI/extra_model_paths.yaml.example extra_model_paths.yaml
sed -i '' 's#path/to/stable-diffusion-webui#~/stable-diffusion-webui#g' ~/ComfyUI/extra_model_paths.yaml
```

6. 启动 ComfyUI（自动打开浏览器，输出目录指向桌面）：

```bash
cd ~
source cf/bin/activate && cd ComfyUI && python main.py --auto-launch --listen --dont-upcast-attention --output-directory ~/Desktop
```

7. 退出时回到终端按 Ctrl+C 即可。

# 5.3 Linux 系统本地安装

# 💡

Linux 更适合 AMD GPU、Intel GPU 和 Mac M1/M2 用户。

参考教程：https://ComfyUI-wiki.com/zh-CN/install/install-ComfyUI/install-ComfyUI-on-linux（原作者：ComfyUI-wiki.com）

1. 克隆仓库。终端中执行：

```bash
git clone https://github.com/comfyanonymous/ComfyUI.git
```

2. 把 ckpt 或 safetensors 格式的模型放进 models/checkpoints 目录。

3. PyTorch 要按 GPU 类型选择安装命令。

AMD GPU（稳定版或 nightly）：

```bash
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/rocm6.0
pip install --pre torch torchvision torchaudio --index-url https://download.pytorch.org/whl/nightly/rocm6.1
```

NVIDIA GPU（稳定版或 nightly）：

```bash
pip install torch torchvision torchaudio --extra-index-url https://download.pytorch.org/whl/cu121
pip install --pre torch torchvision torchaudio --index-url https://download.pytorch.org/whl/nightly/cu124
```

4. 安装所需依赖。在 ComfyUI 根目录执行：

```bash
pip install -r requirements.txt
```

5. 运行：

```bash
python main.py
```

6. AMD GPU 用户注意：如果显卡不在 ROCm 官方支持列表内，可能需要设置环境变量来覆盖 GPU 版本。
