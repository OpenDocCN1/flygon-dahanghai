## （三）飞书一键部署 OpenClaw

💡这个方案的关键就一个字：快。点一下，全部环境连同飞书机器人权限都配置好，剩下基本不用动手。等安装完成通知，就能直接使用 OpenClaw。不过要留意额度，可能聊几个问题就用完了。

飞书官方推出了“妙搭”平台，支持一键部署 OpenClaw：不用买服务器、不用装环境、不用去开放平台配权限，点几下按钮，就能在飞书里和智能体对话。

部署完成后，飞书里会多出一个机器人联系人。给它发条消息试试，能收到回复，就说明你的第一只“虾”养好了，如图 3-7。

[PRE34]
最省心的是权限配置。过去手动接飞书，要在开放平台创建应用、配一堆权限、走发布审批；现在这些都跳过了，妙搭会在聊天框里直接引导授权。手机端操作也差不多：在飞书“工作台”搜“妙搭”，进去点“一键部署 OpenClaw”，后面步骤和电脑端接近。

**2. 免费额度**

妙搭自带内置模型，每天免费 100 万 token，注册首日发放 400 万 token 免费额度。日常体验和轻度使用完全够用。云主机配置是单核 CPU、4GB 内存、1TB 硬盘，跑一只“虾”绰绰有余。目前这项服务限时免费，截止时间以飞书官方公告为准。

**3. 边界与限制**

• 模型不能自由选。它用的是妙搭自带模型，无法换成 DeepSeek、Claude 或 GPT；如果你对模型有偏好，或者需要在不同模型间切换，这个方案就不太够。
• 绑定飞书生态。只能在飞书里和智能体对话，想同时接钉钉、企业微信、QQ？做不到；想通过 Dashboard 直接管理，也不方便。
• 扩展性有限。自定义 workspace 文件、安装 Skill、配置多智能体等高级玩法，在妙搭上的灵活度不如自建方案。
• 数据放在飞书平台。对话记录和配置不在你自己的硬盘里，而是托管在飞书服务上。

所以，妙搭适合回答一个问题：OpenClaw 到底值不值得我花时间认真搭？体验几天，如果觉得“够用了”，继续用完全没问题；但如果你开始想换更聪明的模型、想在钉钉里也能用、想要更大的自定义空间，那就是时候正式搭一套自己的了。

| 流程 | 比方 | 做什么 |

### （三）避坑提醒

**安全：** 安全风险不能轻视（相关说明：http://X.com）。一方面是“小龙虾”自身权限很大，能操作本地文件，存在误删硬盘文件的风险，此前就发生过它删掉 X.com 高管邮件的事情；另一方面来自外部，很多人装好后没给服务器做基本防护，容易被黑客入侵，而“小龙虾”里又配置了各种 API Key，之前也有公司 Key 被盗刷数万美元的案例。所以更推荐把运行环境和工作环境隔离，比如用服务器部署或虚拟机部署，后面会展开讲。

**成本：** 给 API 调用设置权限和消耗上限，优先使用缓存与本地模型，持续监控 Token 消耗。接入时优先考虑编程套餐，性价比更高。
