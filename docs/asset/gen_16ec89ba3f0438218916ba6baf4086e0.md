# 十年自媒体：风口、教训与建议

大家好，我是 Crossin，运营的账号叫“Crossin 的编程教室”，主要内容围绕 Python 教程、案例等展开。这篇文章是应小灰老师邀请，聊聊我做自媒体这些年的经历和体会。

说实话，现在并不是一个特别适合做总结的时间点。👸号流量比前两年差了不少，加上个人原因，运营上基本处于半躺平状态；视频方向刚开始尝试，还没跑出稳定流程，也谈不上方法论。所以站在今天看，这既不像成功案例分享，也不像失败案例复盘。不过既然要聊，就索性把踩过的路、吃过的亏和攒下的一点经验都摊开说说。

下面分六块：我的经历、爆款复盘、收入情况、做对了什么、做错了什么，以及对新人的建议。

## 一、从 2013 到 2022：我的时间线

2013 年，我注册了👸号，开始连载 Python 入门教程；同时在知乎回答 Python 和编程相关问题。

那会儿👸号刚出来不久，还算小众，商业模式更谈不上，“自媒体”这个词都没怎么普及。但小众也有好处：只要内容质量在线、更新持续，很容易被大号推荐，不少号主也会主动搜罗优质账号。知乎当时正处在上升期，用户以大学生和刚毕业的职场人为主，内容氛围偏知识技能；早期对作者引流限制很少，回答里放👸号二维码基本没人管，百度对知乎答案的收录权重也高。所以那段时间，在知乎做技能分享、再把流量导到👸号，确实是一个很大的红利窗口。

之后几年，我本职在游戏行业，👸号只是兼职，更新频率很低，但粉丝一直在涨。期间接过两次广告，费用差不多 1k/次，其中一家还有一期没结清，不过也算从零到一了。

2016 年，我开始全职做自媒体，年中推出付费服务，下半年注册公司、组团队，还参与了创业孵化。那时知识付费刚兴起，移动支付普及，大家线上付费意愿明显增强，机构还没大规模杀进来，👸号广告投放也少，只能自己琢磨课程、训练营这类变现方式。知识星球当时还叫小密圈，龙哥盟也刚出现，我算是最早期用户之一，从龙哥盟里学到不少。最早一版付费会员甚至没有课程，只提供 🐧 群答疑，几十个名额放出来就被抢光，这给了我继续做下去的信心。

后来觉得有戏，就开始开公司、搭团队。2017 年一直在尝试团队化运营，想做一个从内容引流到培训服务的闭环。但个人经验不足，团队作用没发挥出来，我自己的内容输出反而受影响，两边都没做好。整体没怎么亏，用户也在增长，但状态很拧巴，对团队小伙伴和我自己都不算好，最终在 2018 年初把团队解散了。

2018 年，我试着做视频。抖音兴起，我一周内做出过一个千万播放的爆款，但那个视频跟编程无关，短期也没找到能跟编程结合的方向。与此同时，👸号甲方投放开始井喷，重心自然还是放在图文上，抖音就搁置了。

2019 年，我有意识地向视频转，但重视程度不够。那段时间👸号广告市场很繁荣，商单不断，算是做👸号很舒服的时期，于是又找了几个小伙伴帮忙，大部分是远程兼职。B 站也从二次元逐渐出圈，我本人是 B 站老用户，准确说更早是 A 站用户，但之前没想过 B 站也能发编程内容，结果又是起个大早赶个晚集。虽然有几期播放量不错，但始终没把 B 站当主渠道。

2020 年，我正式转成“自媒体”。疫情对👸号主影响不算大，甚至还有促进：很多线下事做不了，线上流量增加，我也多卖了不少网课。加上一月初阴差阳错退掉办公室，彻底回到单打独斗的自由职业状态，反倒躲过一波损失。

但时间一长，培训机构类金主的日子也不好过。到 2021 年下半年，广告量明显不如从前；视频取代图文，知乎转型“故事会”，👸号数据跌得很难看。那阵子我干脆有点躺平，过起半退休生活，学了指弹吉他、打鼓、攀岩，有时还去公园跟大爷大妈抖空竹。

2022 年中，我下定决心转型，做编程教学短视频，主战场放在抖音和 B 站，同步视频号和📕。目前数据不算爆，但在稳步上升，暂时还是以内容创作为主继续做下去。

## 三、收入水平

这可能是很多人关心的问题。但说实话，参考价值不大，因为自媒体收益千差万别，而且并不和流量完全正相关。

就我个人来说，最初几年几乎没有收益。后来最顶峰的时候能做到年入百万。但这个百万是营收，里面还要算课程研发和运营成本，而且后来也没能持续。

如果把 2013 到 2022 看成一个完整项目周期，整体收入大约两百万。但从 2023 年往后看，我短期可能还恢复不到这个水平。

单看绝对值，也差不多相当于一个打工人的薪资。但如果我老老实实去大厂做程序员，显然可以更高。不过以我的性格，既不喜欢领导别人，也不喜欢被人领导。做自媒体最起码给了我这样一个机会；至于能不能比上班赚更多，只能说看缘分。

## 四、我做对了哪些

能靠一个自媒体账号做到不上班，我觉得中间还是做对一些事情的。

### 1. 踩中了风口

👸号、知乎，包括知识付费的风口，我都赶上了。这里面有很大运气成分，但运气偏爱有准备的人。如果当时没有积极去试，风口也只会从面前吹过。

### 2. 持续输出

虽说是风口，也还是等了好几年才起飞。这期间不管频率高低，我始终在更新输出，这也是后来能吃到红利的重要保证。另外，出爆款其实是概率事件，只有不停更、基数够大，才更有机会撞上。说实话，我的👸号运营算不上激进，内容也不是多独特，主要还是写得久。

### 3. 冷启动时借了外部助力

很多人做自媒体，都卡在冷启动阶段：辛辛苦苦写完发出去，只有个位数阅读，很难坚持。早期的大 V 推荐，加上虎扑引流，让我很快跳过了这个阶段，基本算是从 500 粉丝起步，创作体验就好多了。

### 4. 从用户角度想内容

写👸号也好，做视频也好，是给别人看的，跟自己发朋友圈不一样。我会比较注意不同内容的数据表现，也会做问卷，据此调整方向。最终我把内容定位在偏初级、短篇幅，要么有趣、要么实用这个方向上。

### 5. 专业内容结合热点

现在“蹭热点”几乎是自媒体基本功，但早年其实没多少人意识到这个概念，至少我一开始是不知道的。运营过程中，我自己慢慢摸到了门道，也做出过几篇还不错的内容。

### 6. 完整的变现闭环

因为我自带开发能力，最开始就自己搭了教程网站，后来又在上面做付费课程和学员系统。所以从内容里的钩子导流，到👸号文章转化，再到后续课程服务，整个流程我能自己掌握。即使市场大环境不好，也依然有靠谱的变现途径。

## 五、我做错了哪些

讲完做对的，再谈谈做错的或者错过的。当然，所谓做错也只是假设，真那样做也未必一定更好。

### 1. 流量、内容、变现、服务都想自己抓

前面说完整闭环是做对的事，但反过来看，这个闭环也在一定程度上阻碍了我的增长。个人做自媒体精力有限，什么都想自己来，相当于牺牲增速换稳健。如果把这部分时间省下来投入内容创作，性价比可能更高，说不定流量还能再上一个台阶。

### 2. 过早谋求团队化

团队化运作不是不行，只是不适合我的情况。跟上面一点类似，这方面牵扯了大量精力，最后效果却不及预期。也许是因为缺一个互补的合伙人。

### 3. 没有尽早转型视频

我很早意识到视频会替代图文，却没有像当初积极尝试👸号、知乎那样去积极转视频。不过必须承认，视频门槛确实高于图文，尤其对习惯文字写作的人来说，面对镜头需要很大勇气去克服。

## 六、对新入局者的建议

下面几条建议，基本围绕这些选择展开。

### 1. 先想清楚为什么做自媒体

大方向不同，策略就不同。做自媒体门槛很低，天花板又很高。听上去不错，但通往天花板的路非常拥挤，而且越来越挤。

如果你是本职工作干得不爽，想裸辞全职做自媒体赚大钱，那我得泼盆冷水。目前来说，好做的时间窗口已经过去了，如果没有过人天分，很难出头。

但如果你是想开拓副业、多一种尝试，那我强烈推荐。我这两年就间接帮助一位朋友成功转型自媒体。不过请记住：先别急着辞职——重要的事重复三遍：先别辞、先别辞、先别辞。想做就先做起来，立刻做，今天就开始。如果你说不辞职就没时间做，那相信我，辞职了很可能也更不了几期。等你做到稳定更新，再考虑要不要全职。

就算不能做成赚钱的副业，通过自媒体输出个人专业知识和独家观点，对职业发展也很有帮助，往往会带来意想不到的机会。

还有一种很适合做自媒体的情况：有现成生意，通过自媒体宣传和获客。当下这个阶段，做纯网红大 V 很难，但把自媒体作为专业性展示渠道很有机会，很多平台的流量机制也在往这个方向倾斜。举个例子，你开了家饭店，再做自媒体，想纯靠自媒体养家可能不容易，但认真做点美食内容，把店里销量翻一倍并不是难事。如果你的业务可以线上进行，比如培训、咨询、卖保险，效果会更好。

当然，也有人做自媒体纯粹出于兴趣，为爱发电，那就不需要我给建议了，做得开心就行。

### 2. 视频多平台同步，但风格要有侧重

发布视频肯定是几个平台都同步更新，但风格上要有所侧重。新手建议优先从 B 站、抖音、📕里选最适合自己风格的。这几个平台都有用户推荐机制，即使冷启动，坚持更新一段时间，通常都会得到反馈。而且它们有 IP 概念，你做得好，别人会关注、追更，慢慢积累粉丝，形成良性循环。

头条这种重内容轻 IP 的平台，适合批量做营销号。👸号我把它归到“私域”，这个说法不严谨，但我想表达的是，它没有公共推荐流量。不过目前👸号机制似乎有些改变，也开始重推荐了。只是图文毕竟是过去式，除非你文字功底真的很强，或者实在无法做视频，才考虑👸号。现在的👸号，因为平台规则相对宽松，更多是作为最终变现渠道。

### 3. 内容要和方向、变现模式一致

如果你拍搞笑短剧，受众广，流量可以做得很大，但多半只能靠内容激励或直播带货变现。如果你做专业内容，比如像我一样的编程教学，那注定流量不会很大，但来的都是垂直细分用户，给他们提供需要的服务，可以做到更高客单价。

还有前面说到的，如果你有自己的生意，那就容易多了，只要吸引到潜在客户就 OK，他们会主动联系你。

如果你想在抖音卖课，却天天跟风拍搞笑段子，那即使出了爆款也没有价值。做垂直内容的人不用羡慕别人的爆款：他的十万播放可能只带来几十块钱收入，你的十个播放说不定就给你带来一个高价值客户。

### 4. 从观众角度选内容，也别完全委屈自己

前面说了，做内容要从观众角度选择。但我还是要反过来说一句：如果自己都不喜欢自己做的内容，也很难做下去，至少得不讨厌。所以一个理想方向，是用户需求（可能是爱看，也可能是实用）、自己擅长、自己喜欢这三者的综合。如果不能兼顾，至少取一个可接受的平衡。

### 5. 新手心态：先做起来，然后坚持、不要脸、坚持不要脸

做自媒体不需要什么准备，你今天想做就可以立刻去做。如果不放心，就先拿个小号试水，边做边想边调整。如果你觉得“我要怎样怎样之后再开始”，那要么你的想法有问题，要么你就是在给自己找借口拖延。很多事情，预先设想的和实际情况差别很大，不亲自动手做，不会体会到其中的细节。

有人会完美主义，觉得这个视频做得不够好，不想发，要继续改，甚至重新拍、换选题。对此我送一句话：永远在下一条视频里改进。一条视频做好了就发，发出去就是最大的成功。

坚持不必多说，大家都懂。但很多人会在潜意识里忽略坚持的作用，更多归因到能力、环境、运气上。可在自媒体这条路上，坚持是第一位的，是其他各种因素的先决条件。如果你没有做够一定的量，其他的方法论都没有展现的机会。另一方面，人们又会低估坚持的难度。在初期缺少正向反馈的阶段，放弃实在太容易了，可能今天加个班，明天朋友喊你吃个饭，你就彻底断更了。

我之前跟一位想尝试自媒体的朋友说“你得不要脸”，她不出意料地想歪了。现在网上确实有大量“不要脸”的内容，但我说的不是那种，而是即便你正常写文章表达观点、拍视频做节目效果，也难免会面临镜头恐惧，感到尴尬。这种尴尬再配合寥寥无几的播放数据，对新手的打击几乎是毁灭性的。这时候你就得硬着头皮上，别管那么多，继续更。

我们过去接受的教育，容易给人一种凡事只有一次机会的错觉，觉得一旦出错就可能带来很大问题。但在自媒体上，我觉得不存在，至少对新手不存在。只要别做违法违规的内容，尽管放手去试，不停更新。你会在更新中不断找到感觉，而不是在纸面的学习和思考中。
