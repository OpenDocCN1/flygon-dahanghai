# 第四步：二次润色的关键技巧

把背景铺垫统统丢掉，直接从主角当下的处境落笔。

给主角贴上标签——一个投简历屡屡受挫的普通学生。

悬念要尽早抛出，比如那通来历不明的电话。

把主角的情绪波动和应激反应写出来。

结尾留一个更强的钩子——他压根没登记过简历。

这就是我们在第二轮修改中所做的事。

# 第五步：最终润色

我们再把语言磨得更细，让画面感和情绪张力更足。

周五午后，李明盯着手机屏幕上那封写着“很遗憾”的邮件——这是第二十三封拒信。他机械地划掉通知。

数据分析实习生、市场助理、程序员见习。

所有打着“高薪”“前景好”旗号的岗位，都用一套模板回绝了这个GPA勉强3.0的普通大三学生。

“该死的内卷。”他把手机塞进口袋，往宿舍走。

周末又是躲进宿舍的两天。

游戏、外卖，还有甩不掉的求职焦虑。

就在他盘算晚餐点麻辣烫还是炸鸡时，手机响了。铃声划破校园的安静。

陌生号码。

他盯着屏幕三秒，心想“也许是哪家公司想通了”，于是接起。

“是李明同学吗？”一个温和但不失专业的女声传来，“我是就业指导中心的王老师。有个实习机会，觉得挺适合你。”

李明脚步一顿，眉头不自觉地拧起来。

他非常确定，自己从没在就业中心留过联系方式，更别说交简历。

“什么样的实习？”他握紧手机，声音里既有警惕，也藏着一丝期待。

# 改稿要点总结

借这个例子，能看到改稿的几个关键动作：

1. 诊断分析：找出初稿的核心毛病，确认哪些元素必须保留。
2. 大刀阔斧调整：删掉没用的内容（本例砍了近一半），重组信息顺序（把悬念往前挪），重塑人物（给主角加困境）。
3. 精细打磨：加入感官描写和细节，用行为、对话展现性格，注入情绪。
4. 最终润色：检查节奏和语言，确保每一句都有作用，强化开头和结尾的吸引力。

这个过程，就是把一个平淡的开头变成更有吸引力的故事入口。同样原则适用于任何写作——砍冗余、抓重点、加细节、始终想着读者体验。

改稿很累，但很必要，它能让作品从平庸变出色。记住以下几条：

1. 足够重视：给改稿留出充分的时间和精力。
2. 冷却期：先放一放，别急着下手，让自己换个角色再看。
3. 有的放矢：按照框架有目的地审视。
4. 勇于删减：别舍不得自己写下的字。
5. 结构调整：为了节奏敢于动大手术。
6. 重点抓开头和结尾：这是读者最在意的地方。

“不要让故事在读者目光中裸泳，也别偷懒把初稿直接丢给编辑。竭尽全力，不留遗憾，这样你会有一种自信：无论结果如何，短时间内我也写不出比这更好的了。这种自信，对每个创作者都很宝贵。”

大家不妨拿自己的一篇旧作试试。确认主线，梳理人物设定和主角任务，找到亮点和不足，对照最初构想看有哪些变化和提升空间。

# 💡

商业计划书的定义、作用、目标

定方向 · 定动作 · 以盈利为目标

BP（Business Plan）商业计划书，是一份把企业目标、战略、市场分析、运营计划和财务预测等核心信息讲清楚的文档。不管是初创公司、寻求融资的企业，还是要调整战略的成熟公司，都离不开它。

常见使用场景有：对外参加论坛宣讲、融资路演；对内用于股东会议讲战略、销售策略宣讲、内部培训。

BP 的作用

融资路演
向投资人展示企业价值，撬动投资。帮助创业者与投资人沟通，让对方理解商业模式、市场前景、竞争优势，从而决定是否投钱。

战略规划
帮助企业高层定目标、定策略、规划未来。可以据此制定长短期战略，保证企业稳步发展。

运营管理
为日常运营提供方向和依据。帮助制定经营计划、管理流程和制度规范，让企业高效有序转。

市场营销
帮企业看懂市场需求、分析对手、定营销策略。确定目标市场、产品定位、价格、渠道，更好满足客户，实现销售目标。

培训管理
作为员工培训的参考资料。让员工了解企业目标、战略、文化、制度，拉齐基层与高层的认知，缩小信息差。

③ 主营业务有两块：一是 ToG 业务，有政府背景资源，做软件系统研发、数据服务；二是 ToB 业务，为本地科技孵化园区建软件管理服务平台，再横向复制卖给其他科技园区。

这些是核心信息。从数据挖掘角度，下一步要针对③展开，尽量获取更多信息或资料。
