# 六、不囤货，也能把单跑通

选品完成、上传并过审上架后，商品会逐步在平台上架。和传统电商先压货再卖不同，这套做法不需要提前备库存：顾客下单后，我们去淘宝等平台代拍采购就行。淘宝那边拍下后，等上游卖家发出货，我们再回到美团店铺里操作发货；买家确认收货，这一单就算走完。

借助工具，采购环节会省力很多。比较过几款软件后，极速下单在售前、售后以及采购发货上的效率更突出。它的使用主要落在两块：一是拍单采购，二是发货。下面就用极速下单采购软件做示范，带大家看一遍实际操作流程。
