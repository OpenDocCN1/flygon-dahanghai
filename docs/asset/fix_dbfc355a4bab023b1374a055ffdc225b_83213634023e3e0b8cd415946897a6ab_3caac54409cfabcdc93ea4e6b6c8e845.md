# 5.3.1 退换货怎么办
如果买家把退货理由写成“质量差”，要尽快联系对方，发一张优惠券，请她把退货理由改一下，否则账号容易限流。

# 5.3.2 差评怎么应对
差评目前只影响店铺服务分：分高能获得流量加权，分低甚至会被清退。差评对转化影响更大。小红书和其他电商平台不一样，用户收到货后，只要没有质量问题，通常不会主动评价；有时卖了几百件都没人留评。要是差评带图，图片会直接展示在购买页面。爆款产品尤其要重视售后，尽量降低差评风险（亲测销售 500+ 零评价）。
平台对点评回复率也有要求：每两个自然周考核一次，如果在一个审核周期（两个自然周）内，负面点评回复率低于 80%，每次扣一般违规积分 2 分。所以建议在用户点评后 24 小时内认真回复，并帮消费者真正解决问题。
差评已经出现了，可以尝试下面这些方法：
1）到后台提交申诉。进入申诉入口后，根据自己遇到的问题填写申诉信息。
[PRE6]
一般违规行为，商家需要在违规通知发出之日起 7 天内，确认调查单或发起违规申诉。超过 7 天没操作，平台会视为认可违规处理，处罚自动生效。同一项违规最多有三次线上申诉机会。想提高申诉成功率，就按小红书平台要求提供完整、真实、有效的材料，比如聊天记录、截图、链接、照片、录音、快递单凭证等。具体可以参考小红书违规申诉管理规则。
2）不要夸大宣传产品。
3）也可以致电消费者，请对方把差评删掉或修改。

# 6.1 怎样压低女装退货率？
1. 选品：避开特定人群才能穿的款式，比如新中式、国风这类，很挑人，退货率可能到 70%—80% 甚至更高（详细可回看【2.2.1 女装赛道选品思路】）。
2. 运费险：开通运费险会让退货率上升。新手前期可以先不开，等有用户咨询再决定；如果已经开了，要经常关注退货率，超过 40% 就及时关掉，降低损失。
3. 售后：客服接到售后问题时要尽快回复，必要时可以创建店铺优惠券补偿客户（可回看【5.3.1 退换货怎么办】）。

# 6.2 笔记和选品，如何自查复盘

# 6.2.1 内容复盘怎么做

# 6.2.1.1 先看笔记数据
1. 阅读量
笔记发布后 2—3 小时内，阅读量就很差，或长期只有 100—200，甚至不到 100，很可能是这几种情况：账号刚起步，权重太低；内容违规或撞了敏感词，平台不给推荐；选题、标题、首图不够吸引人，尤其要重点检查选题角度和首图。
2. 点赞收藏和评论
1）点赞收藏合计高于 10，评论却是 0，或者只有点赞没有收藏和评论：说明内容在持续被推荐，但转化不行，需要通过评论区引导用户下单。可以用其他账号在评论区带节奏，比如发“惊喜盒子”，或者说“已买”并发购买截图。
2）收藏高于点赞：说明内容干货属性强，种草属性不足，需要优化。可以从产品使用场景切入，或补充更多产品信息。
这些数据看完后，如果表现不理想，再继续做下面几项检查。

# 6.2.1.2 检查笔记整体
看笔记有没有做到爆款笔记 1:1 的程度（可对照【章节 3.2】的爆款笔记内容自检）。
看笔记有没有违禁词，可以用零克查词：http://ci.lingke.pro/。
看同一款产品的测品笔记内容差异度。一般一轮数据分析需要 5 条笔记，5 条笔记的选题和标题文案要尽量不同；如果同质化严重，就要改成有区分的版本。

# 6.2.1.3 封面和标题怎么查
先看有没有参考爆款做优化。爆款内容可以参考这个判断标准：评论数接近点赞收藏数的 1:1～1:2，评论越多越好，而且评论里能看出强烈的求购意愿。

然后对照爆款，检查封面+标题。

爆款的封面和标题经常具备再次爆发的潜力，做法是提取标题关键词，并 1:1 模仿爆款封面。把产品关键词、适用季节和热门关键词放在一起，比如“夏季/秋冬”“衬衫”“牛仔裤/产品亮点”，就能组合出一批新标题。

# 6.2.2 选品复盘要点

# 6.2.2.1 先判断是不是爆品
第一步：看销量。
月销超过 1w，并且很多店铺都在卖，基本可以判定为爆品，对应的爆款笔记也会很多。
近期销量 100—500，在售店铺少于 5 家，属于近期爆品，现在只有少量商家在发笔记抢流量。
月销 1000—3000，在售店铺不超过 3 家，很可能是少量自有货源品，或者投流产品。
以裤子为例：在商城搜索“裤子”，按销量筛选出爆款，点“同款”进入对标店铺看笔记时间，再进账号主页看爆款笔记的时间周期。
[PRE15]
第二步：看笔记数据。
按上面的标准点进店铺，再看账号的笔记数据。以下数据可以当作选品参考：
近 7 天笔记销量 1000+，爆品率 80%；
近 30 天笔记销量 10000+，爆品率 50%；
近 90 天笔记销量 10000+，爆品率 20%。
怎么找爆品跟品？还是用裤子举例：在小红书商城搜“裤子”，找到店铺销量 1w+，近期加购 1000+（最好是 24 小时加购）的款，就可以直接跟品发笔记，大概率能出单。
[PRE16]

# 6.2.2.2 用对标账号的爆款来选品
找对标账号时，重点看它的选品周期，3—90 天以内的爆款要及时跟上。
什么是选品周期？3—7 天内的高销量品，是实时爆品；30—90 天内的高销量品，属于小红书需求品，生命周期比较长，之后还有再爆的可能。如果产品是应季款，参考周期要相应缩短。

# 6.2.2.3 看垂直账号的发现页爆款
账号垂直后，小红书会在发现页推你同类目的爆款。点进笔记看发布日期，判断是否在 3—90 天周期内。
[PRE17]
如果在周期内，再去搜小红书同款，看做的人多不多。
如果做的人还少，说明有机会。可以去淘宝等电商平台查同款；如果其他平台销量不错，小红书评论区求链接的人很多，那就跟品。
[PRE18]
[PRE19]

# 6.2.2.4 借鉴电商平台热销款
在淘宝、抖音、拼多多上，找销量高、评价好的产品，我一般直接对标店铺里销量最高的那款。再回到小红书看，如果没人上同款，或者上的人很少，就抓紧上款，并收集素材做笔记。
