# 开篇寄语

欢迎来到三月航海·小红书百货店铺实战手册。接下来的日子里，我们会有很多次交流的机会。

正式学习之前，先回答几个大家关心的问题：

1）这个项目是什么？有前景吗？

小红书是大量用户做消费决策的核心阵地——吃什么、买什么、去哪儿玩，大家习惯先上小红书搜一搜。平台离消费很近，但内部电商体系曾经很长一段时间缺位。

2020年10月，小红书开放店铺功能；2021年8月，开店门槛下调；2022年10月，个人主页增设购物入口，用户浏览过的账号和笔记中的商品都能在这里找到。2023年3月底，平台推出【笔记带货】，借助KOL合作笔记拉动电商交易。2024年小红书与春晚合作，并早早启动“年货节”，商业化决心可见一斑。

百货赛道相比其他类目，供应商资源丰富、剪辑素材充足、产品迭代快、用户需求旺盛，在小红书电商里属于风险偏低、收益可观的赛道，格外适合新手入局。

2）项目的运营模式有哪些？

在小红书开店，有产品可做自营；没有产品可以找货源方合作。不建议做无合作关系的无货源代拍——平台对此已有处罚规则。

无货源模式好处是投入少、灵活，风险在于笔记爆发可能导致订单激增，合作货源方可能供应不上。选择无货源模式的朋友，平时要留心储备其他可合作的货源方作为备选。

注意：小红书平台正在查处无货源代拍模式，详见官方公告《关于无货源代拍的专项治理公告》及蝉小红的分析。如果你正在做无货源，建议尽快签约可合作的货源商家，或向厂商订货，转型为有货源模式。

3）哪些人适合做？

和其他电商项目一样，门槛是存在的：需要有自己的产品，或找到有产品的合作伙伴。如果找不到靠谱货源又急于赚第一桶金，建议谨慎入场。

#### 1.1.1 用户群体画像

小红书用户集中在18-34岁，女性约占70%，多数分布在一线和新一线城市，以都市白领、职场精英为主。“年轻”“女性化”“有钱”仍是三大标签。这部分人群充满活力、对新鲜事物好奇、热衷分享交流。31-40岁群体也在逐年增长，他们更注重品质生活，乐于分享购物经验和日常点滴。

用户主要集中在一二线经济发达地区，消费水平更高，更看重消费品质和体验。

小红书六大人群标签：
1）Z世代：兴趣社交、追逐潮流、网络游戏、学习打卡、竞技体育
2）新锐白领：经济独立、热爱工作、积极活泼、充满个性
3）都市潮人：时尚、注重形象、独立精神、有观点
4）单身贵族：经济独立、注重享受、追求品质、轻量消费
5）精致妈妈：注重生活品质和形象、高端消费、护肤保养
6）享乐一族：娱乐至上、兴趣消费、追求体验和享受

这反映出小红书作为社交电商平台的定位——用户需求明确、品质意识强。

职业方面，上班族和学生占大多数，注重生活品质、喜欢尝新、乐于分享购物心得。自由职业者和家庭主妇更看重实用性和性价比，关注商品实际效果和使用体验。

值得留意的是，越来越多男性也开始在这里分享生活。官方也在扶持男性博主，多元化趋势下，美食、旅行等中性内容以及科技数码、体育赛事等偏男性内容快速发展，男性用户增长迅速。

#### 1.1.3 社区属性定位

小红书的定位从口号就能看出——“标记我的生活/你的生活指南”。它是生活方式内容社区，也是内容种草平台。用户一边分享生活方式，一边给别人种草，或者被别人种草。

无论哪种属性，都离不开“内容”。你可以分享真实的自己，越接地气越好，但它不是微博也不是朋友圈。即便分享真实生活，内容也会被筛选——同时被平台和用户认可的内容才有出圈机会。

[PRE10]

#### 1.1.4 流量分配机制

小红书两大核心流量来源：【推荐流量】+【搜索流量】

1）推荐流量
和其他公域平台一样，小红书有算法推荐机制。系统根据笔记初始点赞、收藏、评论、转发分享、转粉数据打分，其中评论、转发、转粉权重较高。

CES评分 = 点赞×1 + 收藏×1 + 评论×4 + 转发×4 + 关注×8
（注：CES为小红书内部评分体系）

笔记分数越高，就会被逐级推荐到更大的流量池，成为爆文（小爆款互动量1000+，大爆款10000+，不同类目有差异）。爆文还会带动其他笔记整体数据增长。当然需要满足以下前提：
① 笔记通过系统审核，无违规，未被删除或隐藏
② 笔记包含关键词（如香水、家具），对应垂直标签，能被系统识别收录并推荐给目标人群
③ 内容质量过关，能吸引用户点赞收藏评论互动

特别提醒：0基础新手很难第一篇就出大爆款；运营第一个月阅读量停留在100-200很正常，基础好的会快一些。80%新手在第二或第三个月才迎来爆发，有酝酿期，不用太焦虑，耐心打磨内容。

2）搜索流量
用户除了逛主页，也会通过搜索找内容。想买口红搜口红攻略，想去旅游搜旅游攻略。搜索结果排名靠前的笔记获得更多曝光和关注。这部分流量近乎占总流量50%以上，不容忽视。

#### 1.2.1 行业前景展望 @谢无敌

小红书已是很多用户的消费决策工具，吃什么、买什么、去哪儿玩都会来搜一搜。虽然离钱近，但很长一段时间大部分人的消费习惯仍是去某宝某东下单。为打造商业闭环，小红书多方面尝试：一方面严厉打击导流行为，另一方面不断完善内部电商系统。

2021年8月官方推出“号店一体化”制度，简化账号体系，统一为专业号和非专业号，开店门槛从1000粉降为0粉。唯一条件是开通专业号，而专业号申请非常简单，基本申请就能过（医疗等特殊身份除外）。

2022年10月，有博主发现小红书个人主页增加了购物入口，之前浏览过的企业号或笔记中的商品都会出现在这里（该功能还在内测，并非所有账号都有）。
