# 资料总找不到？分类、编码、命名一次讲清

大多数人囤素材、学东西，并不指望自己变成一本活百科。所以经验层面的积累，只要跟眼前的工作、要啃的书、平常的日子和自己真正着迷的事有关，就够了。

**③ 哲科性认知，到底指什么？**

如果给人类知识排个序，哲科性认知大约处在金字塔靠近顶端的位置。科学靠“可验证”立足，能对客观事物做出预测，且已沉淀为系统化、公式化的知识体系。掌握这类认知的人，放到任何行业都算“高人”。这类内容更适合做学术、做科研的朋友来收集，比如本科生、研究生、老师、教授、各领域科学家。

至于哲科领域怎么划分，目前没有统一标准。有说分为自然科学和社会科学的，有再加一类形式科学的，把逻辑、数学、计算机科学这些抽象内容放进去；现在还有复杂性科学，比如人工智能、机器识别。

想系统了解，可以看中国的学科门类设置。2011年3月，国务院学位委员会与教育部联合发布了修订版《学位授予和人才培养学科目录（2011年）》，把学科划为14个门类：哲学、经济学、法学、教育学、文学、历史学、理学、工学、农学、医学、军事学、管理学、艺术学、交叉学科。

另一套依据是《中华人民共和国国家标准学科分类与代码》，设5个学术门类：A自然科学（代码110～190）、B农业科学（210～240）、C医药科学（310～360）、D工程与技术科学（410～630）、E人文与社会科学（710～910）。两套体系的用途差别很大：前者管学位授予和人才培养，后者管国家宏观管理和科技统计。

**④ 智慧性认知，又是什么？**

智慧性认知，是比哲科性认知更靠上的存在，几乎触及人类认知的天花板。本能是人和动物都有的天性，经验是实践后沉淀的方法，哲科是被公式化的知识；可有些东西，人和动物从未经历过，人类也没实践过，既无法写进公式，甚至无法用语言描述，该归到哪里？哲学上的“可知论”和“不可知论”就在讨论这个问题，有兴趣可以自己查。我把智慧性认知列出来，不是劝大家钻研，那是个高维世界，知道有这回事就够了。我自己会把偏宗教、灵修、临在觉察的内容放在这里，当闲时读物。

看到这里，你多半会发现：自己手里的资料，可能连“经验性认知”都凑不齐，东一点西一点，构不成体系。这很正常，历史上也没出过几个全才。何况资料不只“认知”一类，往下还有决策类、操作类，咱们接着聊。

**方法二｜FBBMS 富爸爸模式 @七小**

这是一个通用的整理逻辑，电脑本地文件、云笔记都能套用。我给它起名 FBBMS。

[PRE7]

FBBMS 取自“富爸爸模式”的拼音首字母，五个字母分别对应五个动作：分类、编码、标签、命名、搜索。需要强调的是，这五个要素在不同软件、不同人手里，权重完全不同。分类做得好，标签可以不贴；标签做得好，分类可以不做；命名做得好，前面两者都可以省略；有的软件标签筛选特别强，分类就没那么关键。整理资料的最终目标是1分钟内找到任何一份归档，要素只是辅助手段，别倒过来被手段绑住。

**1、分类规则**

分类的本质，是给每份文件安排一个专属的收纳位置——文件夹。前提是先把分类规则定清楚，否则文件无处安放。常见规则有四类：

第一类，按完成情况。已完成、进行中、待启动、取消、延后。这套规则特别适合工作，分完后精力会自动聚焦到“进行中”和“待启动”的事项上。

第二类，按时间、地点、对象。时间可以按年月日，也可以按人生阶段，比如“2021.5月度复盘”“相册：初中/高中/大学”“19年实习项目打包”；地点常与时期绑定，比如“深圳时期的日记”“广州时期的日记”；对象可以是人或组织，比如“朋友A文件夹”“复盘群文件夹”“公司通知群文件夹”。

第三类，按已有规则。书籍、课程本来怎么分类，直接借鉴。

第四类，自定义规则。比如文件夹设为“学习/工作/生活”，或者“修身、齐家、治国、平天下”。我自己的规则是“学习/人/事/财”四类，再往下拆：学习包括思维模型、知识体系搭建、阅读方法、信息整理；人包括性格心理、两性关系、自我探索、社交策略；事包括目标管理、时间管理、精力管理、做事工具；财包括保险、股票、基金、债券、互联网项目。数字分类可以学杜威十进制。

[PRE8]

我用“字母+数字”，A学习、B人、C事、D财，比如A1思维框架、A2知识体系。编码分两种：低级编码是纯数字，作用是美观和记忆，比如先看到标题，再看到编号66，下次直接搜66；高级编码能体现分类，适合从多个主题各取一两篇混在一起的研究场景，A1、B2、C3一看就知道出处。如果很少做这种混合，用低级编码排序就行。

**3、标签规则**

标签规则说到底只有两个关键词：符号和含义。对文字类文档尤其好用。想把类型分细一点，可以用#关键词、@相关人、T时间、P地点；不想分那么细，统一用#也可以。担心以后想不起来，就在归档时多贴几个标签，打十几个都不亏。甚至可以设一个“#想不起来”标签，专门标记那些总被忘掉的文件。

**4、命名规则**

命名上，我常用的公式是：概括标题 + 关键词。关键词里记得带上时间、地点、相关人、记忆点。例：打造知识体系的矩阵#L先生#九宫格；知识体系四步法#七小#学习金字塔#55字口诀。核心原则是看到名字就大概知道里面装了什么。反之，“草稿”“待处理”“1”“新建文件资料”“资料”“#2021年7月31日今日心得”这类标题，看了也白看，是大忌。

**方法三｜贴标签建索引 @乔帮主**

**1、规范概要**

贴标签是常用的索引手段，但得守规矩。总结几条：先设计标签体系，数量和种类尽量精简，层级和关联要清晰；相同内容用相同标签，大小写、单复数、缩写都要统一；标签别贪多，否则只会增加负担；标签要具体，比如电影内容，别用“娱乐”“影视”，要用“动作电影”“科幻电影”；定期检查标签库，有错漏及时修；还能用机器学习、自然语言处理自动抽关键词当标签。

**2、方法技巧**

可以按分类体系贴：先给资料分好行业、内容类型，再逐一打上所属分类的标签。可以用关键字贴：从内容里提炼关键词，这是最常用也最顺手的方式。可以贴描述性标签：比如概念、颜色、方向、时间、地点，按素材属性来。还能用工具辅助：Evernote、Onenote、Zotero 能自动提取标签信息。

**3、关键字的实践**

脑子里蹦出好点子时，本质上就是提取了关键字，然后拿关键字去检索资料，把灵感落地。提取关键字也是阅读的核心能力，很多人读书慢，卡在逐字逐句；一眼扫过却能抓住重点的人，靠的就是提取关键字。现在流行的 AI 绘画、ChatGPT，想用好它们，底层也是关键字：会搜、会问、会训练。从阅读和写作的角度看，关键字能力有几大用处：快速知道文章主题；把信息组织成知识框架；需要时快速定位；把笔记做精炼；写东西时梳理思路。

**4、没有标签功能的平台怎么办**

印象笔记、为知笔记都有标签，但飞书没有，本地磁盘文件也没有。这时可以用“文件夹分类+文件命名+文件描述”来建索引。打个比方：文件夹是书的章，文件命名是节的标题，文件描述就是正文。把提取的关键字放进这三处，之后搜关键字就能直接命中。飞书和本地磁盘底层用全文索引，所以只要关键字整理到位，搜起来照样快。

做法上，可以在文件夹名、文件名里加入关键字和特殊字符，比如用下划线、连字符分隔，或用方括号、大括号括起来。本地文件还可以用 Everything、Agent Ransack 这类索引软件，快速扫硬盘、支持多条件筛选。文件描述一般指文本内容；图片、音视频没法改，如果正文没覆盖关键字，就在文首文尾补一段标签。

**3）适用情况与注意点**

这套玩法适合：放资料合集，比如课程导航页，或社群、训练营的资料包；不好分类的资料，先把链接和标签放进表格，再把原始文件挪到“杂物堆”文件夹，以后从表格找；文件夹太乱、主题又多的笔记，与其一份份挪走，不如表格贴标签，从此只打开表格，不碰文件夹。

说到底，整理资料并不是要当人肉背诵机，而是让每份资料有位置、有名字、能被搜到。把这些基本功练好，资料库再大，也能在你需要时乖乖现身。
