# 新号别急着卖，先把账号养顺

货还没上，养号这一步别省。新注册的账号如果直接挂链接，系统容易把你当成机器操作，推流效果往往不理想。刚开号时，先别折腾店铺装潢和个人简介，把养号放在前面更稳妥。

# 💡 养号没做足，容易踩三个坑

1. 曝光被压  
账号权重偏弱，货品被看到的概率会下降，平台也未必愿意优先推荐。

2. 审核更紧  
养号不充分时，平台对发布内容的盯防会更严，审核通过的难度也会增加。

3. 低权重更容易被下架  
权重不高的号发出去的链接，本身就更容易被平台下掉；若再遇到同行举报，违规风险还会更高。

新号可以把动作分散到多个时段，模拟真人节奏。建议在上午 8 点到晚上 9 点之间分几轮做，每轮 10—30 分钟，连续 3 天左右即可。

养号阶段主要做三件事：翻商品、签到、玩小游戏。下面逐项说。

# 4.3.1 先搜后逛，让系统认你是真人

①关键词搜索  
在搜索框里轮换试这些词：写作、文章、文章撰写、文章攥写、演讲稿、PPT、述职报告、军训总结、简历等，先把同行的在售链接翻出来。

②浏览商品  
搜到同行的货之后，上下滑动页面慢慢看。底层逻辑是别像机器一样刷，要装成正常用户：挑一些链接留言、收藏、点“我想要”、发咨询，也可以进同行店铺翻一翻、顺手关注。

- 一天翻 20 条商品

- 收藏 5 条
- 进店看 3 家
- 关注 3 个号

# 4.3.2 每日签到，把活跃度抬起来

每天签到能增加账号活跃度和权重。打开闲鱼 APP，点左上角签到入口进页面，再点“赚骰子”，就能看到签到按钮；养号时顺手点一下即可。

# 4.3.3 小游戏顺手做，活跃与闲鱼币一起拿

小游戏和签到在同一个入口附近。进去后主要玩“扔骰子”和“赚骰子”两个。赚骰子下面会冒出一堆闲鱼任务，有些可以跳过，比如“发布一件新宝贝”和“邀请小伙伴来签到赚闲鱼币”；其余任务可以靠下载相关 APP 完成，像淘特、菜鸟裹裹、手机天猫、淘宝、饿了么等。能做的尽量做掉，账号活跃度和权重会更好看，顺便还能攒闲鱼币（闲鱼币后面会讲）。

# 4.3.4 养号到什么程度算过关？

看一个信号就行：当你连刷 20 条商品，首页前五屏里相关商品大约占一半，就说明养得差不多了。一半只是大概数，多点少点无妨。最关键的是首屏 4 个位置，最好有 2 个及以上是写作类商品。

# 4.4 账号设置：把写作号的人设立住

卖什么，店铺气质就该往什么方向走，写作号的人设很重要。下面直接讲操作。

# 4.4.2 名称

闲鱼昵称 7 天/30 天（看账号情况）只能改一次。发帖前或者养号还没结束时，可以先不动。真要写，可以用“XX 写作”“XX 写手”“XX 学长/姐”这类格式，最好让人一眼知道你能写。还是那句：多拆对标账号。

[PRE8]

# 4.4.3 个人简介

简介尽量往专业写作上靠，体现账号的专业性。注意别留任何联系方式，也别用违反平台规定的词。

权威背书：可以巧妙写自己的专业背景和经验，比如“X 年写手经验”“研究生在读、博士在读”“XX 行业 8 年从业者”。

专业加成：尽量写和商品相关的职业，比如论文与研究生、商业计划书与市场分析师、教案与教师。

性别加成：借职业刻板印象增加亲切感和可信度，比如女教师、女学生。

多参考同行，等于拿到现成参照。

# 4.4.4 主页背景图

背景图可以放写作相关图片，也可以放毕业证书高清图、职业证书高清图、比赛奖状高清图、学校或工作场景高清图。

# 5.2.2 商品文案怎么二改

商品文案可以直接拿同行内容做二改。关键词不动，后面的描述重新写一遍。

同行文案一般会堆这些服务词：演讲稿撰写、简历、读后感、发言稿、征文、格式修改、文章润色、个人成长、写文章、文章服务、文章写作服务、文章撰写等；再列写稿类型：演讲稿、简历、征文、新闻稿、事迹材料、申请、诗歌、影评、发言稿、宣讲稿、文案、心得等；末尾强调保证原创、保证质量、按时交稿、全程保密，不接违反平台规定的内容。

二改时，前半段关键词保留，后半段换成：985 硕博执笔、多年文章工作室、全程一对一服务、各种文章均可咨询、保证原创、包修改到满意、支持加急。提醒：咨询时别发敏感词，违规单不接。

发布商品时，有些词要特别小心，比如“代写”“论文”以及和党政沾边的词，都是高风险词，容易触发平台检测。若看到同行标题里出现“代写”等敏感词，别直接复制；复制后要换成更安全的说法，如“写作”“撰写”“文章定制”等，降低违规风险。

# 5.3 发布节奏、频率与下架时机

普通闲鱼号最多能上 50 个商品。不用一口气把 50 个铺满，前 3 天每天上 3—5 个即可，别一天堆太多；熟练后可以每天上 10 个品，大力出奇迹。也别把一天的量一次性全发完，要拉开间隔，1 小时或 2 小时发一次。发布时间一般放在上午或下午。

可以把账号想成一块地：平台给的流量是肥料，你发的品是作物。地里种得越密，每棵作物分到的养料就越少。所以要定期换品，数据不行的就下掉，补新的上去。

# 六、运营推广：把曝光和咨询拉起来

单品发完后，就进入闲鱼运营流程。这里也会讲怎么让已上的品多曝光、多咨询。

先认识几个要天天盯的数据。商品页面有三个参数：曝光、浏览、想要。

曝光：你的商品出现在别人手机页面上的次数。  
浏览：别人看到商品后点进去的次数。  
想要：别人点进去后，点“我想要”或“聊一聊”的咨询次数。

下面这些动作，可以在一定程度上抬商品曝光，增加被浏览和咨询的机会。

# 6.1 公益宝贝（可选操作）

新上的商品可以第一时间开公益宝贝，对增加曝光有帮助。在主页商品页面依次点：加入卖场——>开启捐赠——>我同意，继续捐赠。

[PRE18]

# 💡 Tips

什么商品适合开公益宝贝？  
开公益宝贝要设捐赠额度，比例别太高，1% 就够。新上 1—2 天的商品可以开，后面成交时其实可以关掉。

商品开不了公益宝贝怎么办？  
公益宝贝主要作用在新品推自然流的时候。想直接上公益宝贝，也可以“发布公益宝贝”。实测下来它是个加分项，但实际权重没那么高，所以算可选操作。后面把运营动作做好才是重点。

# 6.2 闲鱼币抵扣

新上的商品可以第一时间开闲鱼币抵扣，抵扣额度设 5%，对曝光有帮助。

[PRE19]

# 💡 Tips

什么商品适合开闲鱼币抵扣？  
开抵扣要设比例，别设太高，5% 就行。新上 1—2 天的商品可以开。闲鱼币抵扣只适合前期推自然流；某个商品流量起来后，可以提前关掉，后面推流再用“急速卖”或“用曝光”。当然，有成交时也可以把抵扣关掉，否则客户会用闲鱼币抵掉相应金额。

# 6.3.1 每日擦亮

每天一键擦亮能增加可用曝光数量，记得天天点。“用曝光”怎么用，下一小节讲。

# 6.3.2 用曝光

还记得一键擦亮拿到的曝光值吗？在同一个页面点“用曝光”，就能给对应商品加曝光推流。注意每天名额有限，尽量第一时间抢，目前是早上 8 点后。

什么商品适合用曝光？  
新商品上架 1—3 天后，挑自然流相对不错的品去“用曝光”。判断标准看点击率：浏览/曝光 > 5%。
