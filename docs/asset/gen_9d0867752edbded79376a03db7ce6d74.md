# 1.2.3.2 整理资料，也能成为赚钱技能

亦仁曾在星球里聊过一个选题：为什么要把“资料整理”纳入航海计划。他的判断很直接：不少圈友手里并没有真正的专业知识，也缺乏输出专业内容的能力，更像是只见过别人操作、自己没真正上手的那类人。

他举了个例子：让你设计一套社群运营课，你大概率做不出来；但让你去搜集互联网上优质的社群运营文章，再分门别类、清清楚楚地整理好交出来，这件事你大概率能完成。这样的成果他愿不愿意付费？当然愿意——因为能帮他省下大量筛选和时间成本。

所以，没有专业知识的人，如果学会资料收集与整理，反而会有不少人愿意买单。原因也很简单：太多人懒得自己去整理。

资料管理能变现的路子，还有这些：

1）把嘉宾分享的音频、视频、现场内容转成逐字稿，再打磨成干货文章，交付给有需求的平台。我曾通过这种方式与笔记侠、腾讯学堂合作。

2）把专业人士分享的内容汇编成电子书或实体书。比如生财圈友七小，就为不少有IP的圈友整理过电子书，这里面存在合作空间。

3）将课程或书籍的文字内容提炼成思维导图、视觉笔记等。这类成果可以与樊登读书会、得到以及商业书籍出版社合作。

4）把自己整理资料的方法论沉淀下来，通过技能教学实现商业变现。
