# 3.1.1 个人号，几步就能开

想顶着“XX博主”的身份做内容，比如走时尚、美食这类兴趣方向？个人专业号申请起来并不复杂：通常提交后就能通过，而且不用掏任何费用。

具体开通路径是：先点【创作中心】，进入【更多服务】，找到【开通专业号】；随后选择【我是个人】，完成【实名认证】；证件类型选身份证，按页面提示把资料填好即可。

不过，医生、律师等特殊职业另有要求：需要补充上传相关资质，并支付300元认证费用。

[PRE1]

开通个人型专业号后，还可以申请个人店铺或个体工商户店铺。店名会显示为“XXX（昵称）的店”；入驻保证金至少1000元。月营业额不足1万元时，平台不收技术服务费；超出1万元的部分，平台按5%收取技术服务费。
