# 小红书选品，先避开热闹款

做小红书选品，可以用蝉小红来辅助判断。进入商品板块后，按自己的方向挑类目，再把价格区间、销量表现和相关笔记数量设成想要的筛选条件，就能快速缩小范围。

重点看一个反差：某个品类销售额很亮眼，但关联笔记并不多，这种就值得优先尝试；反过来，销量虽然高、相关笔记也很密集，说明竞争已经不轻，别急着跟。

这套思路不只是选品时能用，上架前也可以拿来对照竞争强度，帮你少做拍脑袋的决定，降低决策失误。
