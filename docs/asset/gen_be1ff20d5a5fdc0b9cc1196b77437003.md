# 1.2 社群建在哪？先过六项检查

能做社群的 App 和平台非常多，新工具还在不断冒出来。与其一个个试，不如先拿一套标准来判断：手上的平台究竟适不适合承载社群。下面六条，可以逐项对照。

1）成员要能方便、经常地使用这个平台。
• 如果发起人的主阵地和社群成员所在行业都不在抖音，就没必要硬去抖音建群，微信群往往更省事。
• 若成员遍布全球，微信群在便利性上通常比不上 Discord、Facebook、Telegram。
• 微信里的 H5 与小程序，内容呈现不如原生 App（如知识星球），即时沟通又不如微信群，一般不算优选。

2）平台要能帮你放大这类社群的核心优势。
• 若社群以主题、帖子等内容为根基，并希望持续积累，知识星球、飞书配合飞书文档，可能比微信群更合适。
• 若社群经常要面向大量成员做直播，钉钉目前可能更占优。

3）平台要贴近潜在成员的实际工作与生活。
• 在阿里内部做社群，钉钉群通常比微信群合适；在腾讯内部则反过来。
• 游戏部落若在游戏内已有频道，效果通常比另去知识星球开群好得多。

4）用户“特意跑来”的群，往往不如“顺手进来”的群。
• 这恰是微信群的长处。
• 影视剧爱好者的社群，豆瓣小组可能比微信群更有优势。
• 若在知识星球开免费群，面向该平台已有付费用户招人，通常比去站外拉新更省力。

5）选了哪个平台，就要接受它的规则与潜规则。
• 各平台都有内容监管压力，稍不注意就可能收到“网络并非法外之地”的提醒。
• 若确实无法遵守，换平台是更稳妥的选择。

6）社群价值足够硬，成员就愿意克服障碍使用你选的平台。
• 有些圈友在知识星球只加入一个生财有术，打开知识星球就是为了进生财有术。
• 有条件自行开发并上架专属社群 App，也未尝不可。
• 但要让社群价值足够硬，并不容易。
