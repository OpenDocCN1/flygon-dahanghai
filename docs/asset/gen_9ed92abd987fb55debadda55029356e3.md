# 先抓住20%的关键用户

小众市场里的产品，怎样最快、最直接地让用户形成预期价值？答案不是功能清单，不是常见问题解答，不是7天免费试用，也不是全天候客服、装机量或评分，而是一个清清楚楚的价格数字。价格一旦明确，用户就会用与之匹配的价值尺度来看待产品。

高预期价值当然会筛掉一部分潜在付费者，但换个角度想：按80/20法则，20%的用户带来80%的利润，所以优先把20%的人服务好更划算。真正理解产品价值的人，往往会提出更有价值的想法，也能在产品迭代中帮上更大的忙。

价格锚点，说白了就是给商品价格找一个对比标杆。营销中常通过锚点、对比和暗示来影响人们对货币价值的判断。消费者判断一件商品值不值，并非绝对，而是相对的：需要一个参照标准。这个参照标准，往往由商家来设定。

以99元/年为例，它本身就可以充当价格锚点：先有这个价格，后面的价格才会显得实惠。

# 6.2.2 联盟分佣：接入Affiliate推广体系

Affiliate联盟营销，可以理解为海外版淘宝客，也和知乎好物、抖音书单、外卖淘客、美团地推同类：帮商家推广商品，按结果拿佣金。

入门先从Offer看起，主流类型是CPS和CPA。

CPS按商品销售额分成，不局限于实物，软件程序也能做。现在SaaS工具多，加上“一次投入长期收益”的特点，这类提成通常不低，一些软件的综合收入并不比传统货物CPS差。亚马逊年末促销时提成最高到9.5%，卖出一台300美金的冰箱，佣金就是28.5美金。

如果你专门推广某个品牌商品的独立站Offer，提成通常更高；保健类产品高的可能超过50%，可以看看https://fanfuel.co，不过佣金高，竞争也激烈。

另一类是CPA：用户完成某个行为后付费，这个行为可以是下载软件、填写注册表等。常见CPA佣金在2—10美金之间；如果是保健品领域，可能高达六七十美金。

国外线上产品丰富，可选对象多，佣金也高。可以结合自己的工具站方向，分析访问用户画像，再选择合适的联盟营销对象，了解对应佣金政策，判断是否值得推广。

新人选行业尽量不要凭感觉走，最好找到一个较弱的对手去超越，别等流量做起来了却找不到合适的产品推。可以观察竞争对手在推什么，你也去申请；也可以用“关键词+Affiliate”到谷歌搜；还可以和Affiliate Network合作，或直接对接广告主。

联盟会扣一部分中介费，但它帮你对接了各种广告主，运作起来更方便；直接和广告主合作佣金更高，不过对你的要求也更高。这有点像房产中介（Affiliate Network）—你—卖房者（广告主）的关系。

合作久了，也可以和他们谈条件，比如提高佣金、减少扣量等。

你也可以在https://www.Offervault.com/、https://odigger.com/里搜索关键词，找到贴合自己niche的Offer。值得一提的是，同一个Offer在不同联盟的转化率可能不一样，需要测试；每家公司的运营策略（甚至道德水准）都不同。

选定要推广的产品后，一般先申请推广资格。国外大多数软件和工具类产品，首页底部都会有推广联盟的加入链接，或者直接谷歌“产品名+Affiliate”就能找到入口。注册过程不复杂，新人多数情况下最好填写真实资料，避免拿到佣金却提不了现。

付费订阅这块：工具站要推出付费订阅，就得有收款渠道。个人可以用LemonSqueezy；Stripe最好用公司名义注册，而且最好是海外公司名义。

把海外公司、银行账户、Stripe都注册下来，无论美元还是USDT，都能实现全球收款、国内到账。银行账户发行的员工卡可以绑定支付宝消费，也能无障碍使用海外服务，再也不用担心OpenAI扣费失败。

需要准备护照、驾驶证。注意不要填假信息，避免封号。

为什么要注册海外公司？

稳定的收付款渠道和银行账户；许多海外服务不对中国大陆开放，或对中国大陆身份有更严格的风控策略；海外手机号也有用。

英国手机号可以选择giffgaff，每180天发一条短信保号（0.3英镑）。美国手机号选择Ultra Mobile PayGo，月租$3。giffgaff官网可以免费申请。以上都可以在淘宝、京东购买。

海外公司注册地怎么选？

常见选择是英国或美国公司。注册英国公司更简单、更便宜（1st Formations），开户用Wise企业账号即可。我这次注册的是美国公司，看业务需要也可以都注册。

Firstbase注册开户流程：

我选择了一家口碑不错的一站式公司服务代理Firstbase，从公司注册到地址公证，再到银行开户都有明确指引和服务支持。从效率来说，淘宝找代理最省事，但我更喜欢能看到dashboard的SaaS服务。

公司注册州选了Wyoming，公司类型是LLC，比较适合个人开发者。租用邮箱（私人地址），通过Notarize远程视频公证（1583 Form）。这里需要提前准备驾驶证翻译件（淘宝几十块钱），注意证件照片和地址需要同一页展示（建议合并打印成A4纸）。视频公证过程需要简单英文沟通，工作人员会让你拍摄翻译件，询问是否本人意愿、确认签名。

雇主身份识别号码（EIN）：地址公证之后，Firstbase会继续代理申请EIN，我在第10个工作日收到了国税局信件。

Mercury银行开户：通过Firstbase关联提交EIN、护照审核，1个工作日内就能审核通过。

到这里，你已经有了公司主体、EIN、私人地址、银行账户、手机号。私人地址还有很多用处，比如账单地址、申请实体银行卡转寄回国内、接收Google AdSense验证信件。

Mercury支持免费发行无限量虚拟卡，还可以限制交易商户和额度，比如A卡只能在Google使用，B卡只能在OpenAI使用；遇到不给退订入口的流氓服务，直接注销卡号就可以了。Mercury虚拟卡可以绑定支付宝消费，200元以下免3%手续费。

有了银行卡、账单地址、手机号，就可以正常注册使用各种海外服务了；进阶还能申请ITIN、个人信用卡。

Stripe企业账号：

拿到EIN之后注册Stripe就很简单了。网站语言切换到中文，填中文信息；个人信息验证使用护照，提现账户关联Mercury即可。

除了Stripe，还可以把Lemon Squeezy、Paddle都注册了。注意这两家都需要验证产品网站。

Wise个人收汇款：

注册Wise可以使用大陆身份和护照，比较麻烦的是入金激活。如果Mercury有余额，可以快速入金；不然还是淘宝找代充比较省事。

Wise实体卡（附带3张虚拟卡）不支持大陆地区申请，但可以激活后修改个人地址再申请，费用$9，需要地址证明。

Wise余额可以直接兑换人民币提现到国内银行卡，以及微信、支付宝账号，手续费算下来比香港银行卡汇款再结汇要划算，通常Wise汇率比国内结汇高。还有更稳妥的结汇方式：
https://twitter.com/zhufengme/status/1706971107885265405

Payoneer也有同类服务，建议一并注册了。

Kraken交易所提现到Wise：

注册Kraken也是使用大陆身份和护照。充值USDT后，通过订单簿买入欧元（注意不是兑换，兑换的手续费很贵），选择SEPA汇款可以1个工作日内提现到Wise欧元账户。没有通过美元提现，是因为大陆身份注册没有ACH汇款选项，而且欧元SEPA提现手续费更低，只收1欧元。

注册与维护成本：

1. 美国手机号每年$36
2. Firstbase注册费用$399
3. Firstbase地址邮箱每年$350
4. Firstbase公司代理（含年报、税务申报工具）每年$299

美国公司注册代理有很多，Firstbase并不算便宜。以上公司注册、地址公证、EIN申请、公司代理、报税、银行开户，都可以分别找代理或自助，自行选择。
