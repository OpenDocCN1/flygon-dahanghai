# 5.4 方法四：用私域活动，炒热社群团购

1）提前放风，锁住注意力
活动方案定下来后，先在朋友圈和社群里放消息，把具体时间（几月几号几点）讲明白，并告诉大家届时会有红包雨和优惠。提前告知，一方面让用户形成预期，另一方面也方便把更多人引到活动群里。

2）红包暖场＋气氛助推
开场前10分钟，就可以陆续发红包，把大家的注意力拉回群里，免得有人一忙就忘了这回事。到了正式开场，连续发5个红包，金额一波比一波大。单个红包别太抠，数量也别铺得太散，要让抢到的人觉得值，没抢到的人愿意继续等。5个红包发完，安排小号在群里带节奏，比如“群主今天真大方”“第一次抢到这么大的红包”。同时提醒一句：成本要控住。

3）亮出活动，用话题带节奏
等群里热闹起来，再把活动或团购商品亮出来。多数情况下，活动一公布，用户会先沉默观察，卖货社群尤其如此，需要有人先站出来带动情绪。这时小号可以出场。根据参与人数，准备2—3个甚至更多小号，从不同角度提问，但别太刻意。小号不要连着说话：A问完，先停一停，看有没有真实用户咨询；如果没有，等群主回答后，B再接着问。要注意，小号千万别发这些话：“这活动太划算了，我赶紧买一个”“真的假的，比之前便宜这么多”“我能多买几份吗，便宜得离谱”。这种话用户一眼看穿，马上会怀疑活动，甚至退群，或者在群里直接说“有托”。正确方式是围绕流程或产品细节提问，比如：“问下群主，xxx在这次活动范围内吗？”“如果我买xx份，还能在xx基础上再打折吗？”“截止日期之后我再买，是什么价格？”

4）及时答疑，推动晒单接龙
群里有人提问，尽量用@对方的方式回答。这样既能让他持续关注群消息，也能避免问题一多，大家不知道你在回复谁。这时如果有人点开商品链接，可以鼓励他晒单并接龙，用真实订单刺激其他人的购买情绪。想让用户愿意晒单，可以额外给点福利，具体看活动设置和成本控制。常见做法有：晒单多送一个超值赠品；买x个并晒单，在原有优惠上再打折；晒单送商品会员，之后买其他商品还能打折。

5）更新余量，制造倒计时压力
活动一定要限时、限量，不然群里很难制造稀缺感；没有稀缺感，订单接龙的意义也会大打折扣。当接龙数量超过限量的一半，或者活动时间已经过半，群主就可以提醒：“还剩XX个名额”“距离活动结束还有XX小时，想买的朋友抓紧”。

6）关键提醒
最后记住几个重点：第一，提前预告，留足时间触达用户，并把大家引导进活动群。第二，快闪群的小号要提前准备好；如果群里人多，最好多备几个话题引导，否则一旦冷场，后面很难救回来。第三，操作顺序别乱：发红包→发布商品/活动→小号引导→用户下单→群接龙晒单→实时公布库存和活动时间。
