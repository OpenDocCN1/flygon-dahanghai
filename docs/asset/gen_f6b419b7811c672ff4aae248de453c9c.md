# 4.3.2 借势引流：让对的人先看见你

一旦离开自己的影响圈，我们很容易变成“小透明”。想让别人注意到你，一句话就能概括：挑一个合适且有分量的载体，把自己的内容装进去。

好载体很关键。行业里常拿追风口、搭飞机、乘电梯来打比方，说的就是借载体。热点能当载体，不过载体并非只有热点这一种。真正会表达的人，哪怕对方聊的是别的事，也能绕回自己擅长的话题，把它接上、融进去——对他来说，万事万物都能成为表达自己的入口。

这里有个坑：有人蹭热点蹭出大曝光、大播放，可内容里没有“他自己”。追着热点跑，却把价值观、判断、存在感、产品全丢了，一点没装进载体。这样的数据再漂亮，也缺意义。

怎么避免？拿“服务行业新手”的社群做个通用示范。

- 先盘点新手会在哪些公共空间聚集、交流，线上线下都算；
- 再搜集他们最常冒出来的问题，可以调研、搜索，也可以直接打电话问典型用户；
- 从中挑出你最有感觉的100个问题，交给典型种子用户投票，看他们最想知道哪些答案；
- 把票数最高的20个问题拿出来，认真备内容，先以文字稿为主，用新手读得进去、有共鸣的话写；
- 去公域里找讨论这些问题的地方，把准备好的内容贴过去，按场景选图文、视频、短视频、语音等合适形式；
- 每天巡一遍，盯数据反馈，在数据表现好的地方把渠道建起来。

谁掌握新手的全部常见问题（FAQ），谁就真正懂新手；懂新手，才拿得到信任，才让新手愿意靠近。

如果你还记得自己当新手时的细节，能真诚讲讲自己怎么一路走出来，这也是极适合放在主页置顶的内容。

还有取巧空间。很多服务技能型入行小白的人，只是老老实实去生产力软件（Pr、Ps、剪映、达芬奇、Anaconda等）的官网或手册里翻FAQ，去用户论坛找常见问题，再做成视频，就能解决小白八成左右的困惑，成为能帮到他们、一年赚几十万打底的大V。

当然，误区仍在。找常见问题时，我们以为最重要的问题，常常和用户心里的最重要不一致。别想当然。要把姿态放低，再低一点，扎进用户里，看他们最爱问、最常问、最关心什么。哪怕问题看起来很傻，你帮他解了惑，他也会感激你、认可你。更进一步，如果他没提示，你却说中那个让他辗转反侧的问题，还给出漂亮解答，那对他的冲击会非常大。

读到这儿，恭喜你。留个作业：如果你已经大致想好未来要做什么社群，请逐条回答——你的潜在用户是谁？调研一下，他们最常问的20个问题是什么？为什么是这20个，证据在哪里？

说到底，常见问题就是走近用户的载体；你的回答，就是你把独特内容融进问题的方式。这样的载体为什么有力？因为那是用户最关心的东西。这就是关于“外部渠道”如何建立的思考与举例。

体量还小时，建外部渠道最常用的策略，就是我说的“当风轻借力”。但借力时，别把自己弄丢。侯蒙《临江仙·未遇行藏谁肯信》写得好：“未遇行藏谁肯信，如今方表名踪。无端良匠画形容。当风轻借力，一举入高空。 才得吹嘘身渐稳，只疑远赴蟾宫。雨馀时候夕阳红。几人平地上，看我碧霄中。”

以知乎为例。2017年我做知乎那个知识星球时，在知乎只回答了4个问题，答完就没再管，那四个回答当年帮我带来六位数收入。回答用户关心的问题，比回答自己关心的问题，更能关心用户；响应用户关切的话题，比创造自己关切的话题，更能关切用户。查理·芒格说过，钓鱼的技巧很简单：去有鱼的地方钓。反过来，先把鱼竿放下去、再等鱼游过来，是以自我为中心的思路，未必对。

知乎建渠道的机会在于：那里还有大量用户当下关切、尚未被商业化的问题，而且每天都有新的阅读量。

怎么知道问题热不热？如果问题在百度知道，可以通过简单原生接口拿到浏览数据的每日增量；也可以用百度指数看对应关键词热度的年度周期性。如果是在微博热搜发现，要记住不是每条都真热，有买的也有真热。当时一个简单测法：把你关心的热搜词完整包含进一条微博，造个句子发出去，看浏览量能到多少；每个关心的词都能测，浏览量很轻松就冒上去的，才是真热词。
