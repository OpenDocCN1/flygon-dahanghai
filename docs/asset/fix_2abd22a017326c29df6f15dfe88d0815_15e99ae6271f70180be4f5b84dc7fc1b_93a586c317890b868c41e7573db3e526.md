# 11.3 视频的保存、录制与发布：实用链接合集

做内容的人经常要和“下载、录屏、发布”打交道。这里把亲测可用的工具和入口整理成三类，需要哪个直接看哪一段。

## 素材保存

- 想抓取某个博主的全部作品，可以试试付费方案“用户视频采集王”，购买入口在百淘平台：

  https://www.baitao6.com/shop_product-1-10.html?payok=2814

- 抖音视频要成批免费保存，用夸克分享里的资源包，打开后输入暗号 5Ubq：

  https://pan.quark.cn/s/292e98ab87a4

- 只想存单条抖音内容，可以用 ouotool 在线解析，不带水印：

  https://ouotool.com/dy

- 🛰️视频号里的内容怎么存？这份飞书文档写得挺清楚：

  https://w63nbfedzw.feishu.cn/docs/doccnYwjIy8xtyQzwub5WeEsWLh

- 抖音视频想去掉水印后成批保存，或者录制直播回放，用这两个小助手：

  https://lazyman.lanzouo.com/b0112ascf
  访问暗号 2nkd

## 屏幕录制

- 录屏方面，推荐万彩办公大师和 FastStoneCapturecn。
