# 98年专科生裸辞后，靠抖音和社群一年赚到100万

我叫钱南，98年生人，专科毕业刚满一年，目前算是一个刚起步的互联网创业者。很多人觉得专科生出身，起点低，路子就窄。但去年我直接从公司裸辞，把全部时间押在了抖音项目和社群运营上，用了一整年，赚到了人生的第一个100万。

当初辞职时，我其实没有多牛的背景，也没有现成的资源。只是很清楚，再按原来的模式走下去，只会越混越迷茫。于是我先从抖音项目切入，快速验证需求，同时把社群一点点做起来，让认同我的人有一个可以长期交流的地方。可以说，我的第一桶金，靠的正是把抖音项目和社群结合起来做。

也有朋友提醒过我：短期项目只是赚快钱，能解决眼下的难题，但一直追着项目换，人会很累。这句话我认。所以后来我刻意把社群和个人IP当成一个长期项目来打磨。有了这个长期阵地，哪怕风口换了一个又一个，我依然有稳定的基本盘。

我写这篇文章，不只是记录自己的历程，更想给刚毕业或正准备转行的新人一些启发。普通学历、普通背景不可怕，找准一个方向，做完一个闭环，再耐心积累，你也能等到属于自己的机会。

如果你也在探索属于自己的路，欢迎在评论区说说你的故事。
