# 九、投放

想在小红书长期做市场的人，可以用聚光平台做付费推广。“投流”属于店铺运营的进阶打法，品牌店铺做流量和营销合作时经常用到。

聚光平台是什么？它是小红书营销推出的一站式广告投放工具，广告主想实现产品种草、拉动商品销量、收集客资、推广直播、抢占赛道等目标，都可以在上面完成。它把搜索和浏览这两大决策场景连在一起，还能按 SPU（单品）做精准定向和智能投放，为广告主提供整合方案，让好产品自己冒出来。

具体怎么投，可以看这两篇延伸材料：《聚光平台投流方法》《3 月航海 | 聚光投放 | 实战手册》。

# 十、矩阵

# 10.1 一个人怎样管多个号

做账号矩阵，能把收益放大。起步阶段建议先注册 3 个企业号。

❗提醒：一定要一机一卡一网络，防止账号被关联。否则一个号出事，可能全部遭殃。矩阵号之间也别互点赞，隔离要到位。

如果准备批量做矩阵，就要把“生产”成本压下来，因为后面要“放大”。所以内容形式要够轻，这里面有一些运营技巧。

但别忘了，笔记有没有阅读量，根基还是内容。不能为了数量把质量丢了。

[PRE5]

# 10.2 如何批量做内容

低成本做出优质内容，关键是找对标：学封面形式，攒爆款选题和标题。先找你的对标账号，看对方哪些选题爆了，再顺着这个方向做新内容。

第一步，列选题计划：

挑 3～5 个对标号，粉丝量在 3-5 万以下；每个号找 3-5 个爆款选题，加起来差不多就有 10-20 个题目。

然后汇总成自己的选题、标题库，随时取用。

[PRE6]

选题方向有了，接下来解决批量生产。

先讲重点：各平台规则不一样，小红书对内容重合、查重相对宽松。所以可以去各大平台、论坛或垂直领域找优质内容、爆款内容，重新组合成一篇“新”笔记。

大致操作：

确定选题关键词后，去 xxxx 搜索。如果高赞内容是视频，就用视频转文字工具提取文字，再按自己的口语习惯改一遍。

这个 XX 包括但不限于：

抖音、小红书站内、知乎、5118、百度、微信、必应、垂直网站/论坛……

也可以让 ChatGPT 帮忙：把优质内容或爆款内容喂给它，让它批量改写出相似内容，我们再人工润色。（小红书对 ChatGPT 直接生成的内容可能限流，建议一定要手动改。）

掌握这个思路，基本不缺选题，甚至能找大学生实习生来写。就算对方不是本专业，也能产出内容。

封面模板准备：

写完一篇笔记，不代表只能发一次。

笔记完成后，还能套不同风格的小红书封面。如果这篇爆了，说明选题和内容都过关，那就换一种“展现风格”，大概率还能再爆。

方法一：

在小红书搜你所在类目的关键词，多搜几个，点“最热”，再点“图文”，看点赞高的笔记。

收集几个你能模仿的封面模板。看发布时间，尽量选近期的；再进主页，看整个账号是不是统一封面风格。

如果是，就存下来，作为一个对标模板，交给一个企业号去测。再用同样办法给其他企业号找模板。

如果类目词太小，“最热”里的笔记数据都不好，就换相近行业的词去找。这里不用卡太死，相似行业的爆文封面也有参考价值。同样挑一个数据好、你又模仿得来的，拿去做封面模板测试。

[PRE7]

方法二：

用工具或手动导出类目关键词下的笔记 Excel 表，按点赞数和时间排序，挑近期高赞笔记，打开链接收集封面，再按前面的方法找对标模板。

方法三：

在小红书搜类目词，点“用户”标签，只看粉丝多的企业号。

进主页翻一翻，看有没有规律性封面模板；没有也没事，看高赞笔记。如果好几篇高赞都是相似封面，那这个模板也可以借鉴。

[PRE8]

给一个号选好封面模板后，再用同样方式给另外两个号选模板。不同矩阵号用不同排版风格。

这样同一个选题能分给 3 个号用，低成本复制，提高出爆概率。

每个号单独做封面、单独选标题。平台对图片查重没那么严，标题和正文稍微改一改，一般不会出问题。

[PRE9]

所以很多爆款内容，其实是重复加工的段落组合：把三四篇文章拼一拼、改一改，拆成十几篇笔记，照样有流量，也不违规。

注意：

不是让同一个号频繁换封面，而是同一篇内容换不同风格，发到不同号上。有时这个号没流量，另一个号就起来了。

持续增加笔记数量：

所有企业号都配上各自的爆文封面模板后，用近期爆款选题做封面，再照标题库写标题，这条笔记的基础数据就不会差，具备爆文潜力。

坚持发，一天 2-3 条，不出几天大概率有账号出爆文，引流数据也不会差。

所以这个阶段就是：做好前两步，每天铺量不断更，再根据每篇笔记的数据反馈，调整封面和内容。

还可以在原封面基础上吸收其他优秀封面的长处，结合数据反馈和近期平台热点，跟进调整选题。

企业号起号有成功率，同行经验约 50%，供参考。

所以不用强求每个号都数据好，3 个号里有 1 个不错就算成功。

数据好的号多花精力优化，每天发布量也可以加；数据差的号保持更新、继续优化。

如果 1-2 个月还起不来，就注销重开新的企业号，继续上面的流程。

所以一个健康的企业号矩阵，就是不断起号、测新号、注销重来、循环积累成功账号。

只要起号流程顺，不断有新号跑出来，就不怕违规封号和数据波动。

# 十一、直播

有直播带货经验的人，可以结合小红书客户画像和货源优势选品。目前平台直播风格偏平缓，准备物料和话术时，可以往“视觉体验更好”和“产品介绍更详细、更真诚”两个方向优化。

# 11.1 小红书直播的机会

先看入口，今年直播入口更多样。除了关注博主开播会收到系统提醒，还有三个常见入口：

一是关注页面会出现直播字样；
二是推荐页和搜索页，正在直播的博主头像会带一圈红色+直播标识；
三是发现页顶部工具栏有独立直播入口，点进去就是直播广场。

[PRE11]

直播广场里的主题非常杂，几乎什么都有：服饰带货、沉浸式学习、家居展示、助眠冥想，甚至有人开摄像头请网友帮忙看宠物。

[PRE12]

其次，官方给了流量支持，今年直播场观明显上涨。

下面是我某个周五中午随手截的带货榜单。即便在工作时间，直播间观看量也很可观，不少直播间客单价还偏高。

[PRE13]

说实话，跟其他平台比，小红书直播起步算晚。但靠高净值用户，它跑出了别人羡慕的“三高一低”：转化率高、客单价高、复购率高、退货率低。

对普通人来说，平台助推、用户质量高、用户习惯已经养成，这三件事凑在一起，等于天时地利人和。所以今年小红书直播很值得试。

# 11.2 直播底层逻辑

直播离不开三要素：人、货、场。小红书直播在这三方面都有自己的特点。

# 11.2.1 【人】以人带品，人设统一

目前小红书出圈的主播，都有鲜明标签，而且和推荐的产品高度匹配。比如章小蕙优雅贵气，主推优质护肤和美妆；董洁温柔恬淡，主推舒适时尚单品和实用家居好物。

[PRE15]

用户多半是被她们的生活方式和品味种草，所以是“人带货”，货跟着人走。其他平台往往相反，是“货带人”，用户更盯商品本身，对博主黏性偏低。

# 11.2.2 【货】重品质，客单价高

董洁、章小蕙推的很多是小众品牌和设计师作品，价格不低，但卖点独特，强调高级感、实用性和质感，正好对上小红书用户想过高品质生活的需求。

传统直播间最常打低价，用户更在意性价比，结果客单价低，用户也留不住。

# 11.2.3 【场】聊天式分享，信任感强

“不吵不闹，很舒服”
“花钱花得有被尊重的感觉”
……

这是董洁直播出圈时很多人的评价。她的风格不同于传统叫卖式直播，更贴合小红书主流用户。不是硬卖，而是真诚地自用分享。用户体验好，信任感自然强。

所以想做好小红书直播，要做到：人设差异化、垂直细分；货品小众、实用、有创新；场景符合小红书审美，并且真诚分享。

比如做穿搭，你是小个子、极简风还是微胖型，定位越清楚，越能吸引审美和身材相近的用户，粉丝更精准，转化也更高。

在蝉小红近七天直播数据里，有个珠宝博主粉丝只有 200 多，销售额却做到 300 万+。

# 11.3 提升直播间流量

前面说了，直播主要有三个入口：关注页、推荐/搜索页头像、直播广场。那这三个入口怎么提流量？

# 11.3.1 关注页流量

1）发直播预告

开播前发预告，尤其是首播，让粉丝知道你要播。一般提前 2-3 天发，讲清楚主题、时间、福利活动，引导大家预约。

预约进来的这波人，对留存、互动和转化都很关键。

[PRE18]

2）固定直播时间

熟练之后，可以固定开播时间，并写进个人简介。比如每周三晚 8 点播，慢慢培养粉丝观看习惯。

# 11.3.2 推荐/搜索页流量

1）打磨笔记质量

小红书首页信息流暂时没有单独直播间推荐，只在博主头像上显示直播标记。点头像才能进直播间。

所以推荐/搜索页的直播流量，很大程度取决于笔记质量，平时要把笔记打磨好。

2）关键词布局

搜索页是重要的笔记流量入口。搜索页里，头像同样会带直播标记，所以搜索页也是直播流量入口。

提升搜索流量的关键是关键词布局。想提高搜索页直播流量，日常笔记就要重视关键词布置。

具体方法回看 8.5 如何布局关键词。

# 11.3.3 直播广场流量

1）封面和标题设计

直播广场的展现方式类似普通笔记，也是封面加标题。

[PRE19]

所以封面、标题非常关键。要从用户痛点和需求出发，挖掘亮点和吸睛点。但注意，封面必须和直播内容相关，否则会被判违规。

2）做好冷启动

直播广场的推送逻辑也像笔记：先推给一小波用户试水。反馈好，系统就认为你直播间内容优质，继续推给更多人；反馈差，就停止推送。

所以把人吸引进来后，下一步是做好冷启动。冷启动看点赞、评论、关注率、停留时长、下单转化等指标。

做好冷启动的核心，是符合小红书直播底层逻辑：在人、货、场三方面找到适合自己的风格，并贴合平台调性。

[PRE20]

3）蹭平台直播话题

为了扶持直播，小红书官方会定期推出直播计划和活动。逻辑跟写笔记带话题一样，有适合你的话题就积极参加，提升曝光。

# 11.4 直播避坑指南

新人做小红书直播，容易踩雷，下面这些坑要避开。

① 不要盲目造数据

很多新人怕没流量，就拉亲朋好友来撑场。但系统会给每个直播间打标签。如果引来的人标签很乱，直播间标签也会被带乱，系统就不知道该把直播推给谁。

② 禁止站外导流

和普通笔记一样，直播间不允许站外导流。微信、淘宝链接、二维码、手机号都算敏感信息。一旦被系统检测到，轻则警告，重则停播，甚至限制开播权限。

③ 没必要讨好所有人

有些博主为了流量，用跟自身领域无关的福利吸引眼球。但这样引来的人很可能不精准，也会影响直播间标签。

我们只要吸引并留下目标人群。只有精准人群，才能带来更高转化。

④ 场观少也别摆烂

直播间用户流动性很大，随时有人进来。新人进来时，不一定知道在线人数，他们先感受到的是主播状态和直播氛围。

如果能留住他们，系统会识别留存率和互动率，再推给相似人群，慢慢形成正循环；反之就是负循环，人越来越少。

所以不管场观多少，都要拿出最好状态，保持自己的节奏。

总之，小红书直播有挑战，但更多是机会。有开播想法的人可以尽快安排，期待好消息。

⑤ 笔记越垂直越好

比如穿搭博主卖女装，而不是发各种生活照、自拍去卖杂七杂八的东西。直播带货定位要和笔记挂钩。

⑥ 蓄水期越长，对 GMV 越有帮助

什么是蓄水期？

蓄水，就是小红书的直播预约功能。提前把预约发出去，直播前持续预热，比如发笔记、粉丝群互动。

这个蓄水和抖音有区别。同样主播、团队、账号运营内容，在抖音播爆款时，200 人在线可能瞬间冲到几千再到几万；小红书 200 人在线可能只是 500、600，再到 1000 这样。

小红书爆发性偏弱。我们也测过一些数据：同样风格、货盘、量级、时长，小红书 15 万，抖音 45 万，抖音是小红书的 2-5 倍。

如果在小红书每天开播，大约每天 2 万，一周加起来 14 万；但周蓄水一次，一周只播一次也是 14 万，不过需要多预热。这样，7 份精力换来的回馈，和一次集中精力差不多。

直播带货这块，小红书在粘性上比抖音强很多。小红书的用户常常买了一件后，把小黄车产品全买遍；抖音这类用户很少。

⑦ 新手不要一上来就直播带货

如果是新手，建议先把笔记运营好，等粉丝涨到几千，再研究直播带货最稳。

或者过万再做直播带货、测数据。几百粉丝就开始播，不仅煎熬，推流效果也不大。
