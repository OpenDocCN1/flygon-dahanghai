# 8.2 剪顺之后，把创作方向调一调 @思蒙

当视频做到一定数量，大家对剪辑工具的操控会越来越得心应手，手头攒下的素材和创作套路也会越来越多。到了这个阶段，就可以给作品适当增添细节，再结合自己的实际情况，逐步调整并形成更贴合个人的风格。

平时要多拆解同行的作品，也别错过群里分享的爆款案例，重点观察哪类内容的转化表现更突出。比如：开头安排了什么情节，能不能吸引你、勾起继续看的好奇心？中段铺了什么内容？收尾又是怎样把观众引向转化的？还有，视频过程中有没有穿插其他素材？

与此同时，也可以多回顾本手册「五、重组素材剧情，提升爆款概率」和「六、剪辑视频」里的内容，把创作与剪辑能力一起提上去。

内容来源：《目前为止最详细的【短剧推广实操手册】，没有之一！》
