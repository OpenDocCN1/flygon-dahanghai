# 2.2.2 复盘：三问看清一天

记录，让我们知道自己此刻站在哪里；复盘，则帮我们判断下一步该往哪走。

说到复盘，形式其实很多：有人喜欢做贴纸手账，有人偏爱流行的九宫格晨间日记。但它们有个共同问题——流程太繁琐，认真填完往往要花上小半个小时，时间一长就很难坚持。

那复盘方式该怎么简化？先别急着换模板，而要回到一个更根本的问题：复盘究竟要盘什么？

真正需要落笔的，其实就三件事：

• 当天有哪些成果
• 次日要推进什么
• 今天有什么值得反思

把这三个问题回答清楚，就能快速、清楚地审视自己的一天。

从今天起，不妨就按这个思路做日复盘打卡。初次尝试大约花十分钟；等熟悉了这个结构，五分钟上下就能写出一份既完整、又能反过来指导行动的日复盘与日计划。

单看一天的复盘，也许看不出多大变化。可连续做满一周，你这周做了哪些事、拿到了哪些成果，心里就会非常有数，也不会再觉得时间白白流走。坚持一个月，你还能得到一份细致的月度复盘表，这个月做了什么、收获了什么，都会摆在眼前。

[PRE1]

若把时间拉长到十年，成长轨迹会越来越清晰。我每年都会留下年度复盘与计划表，因此每年完成了什么、哪里进步了、哪里还要补课，都能看明白；新一年的目标与执行路径，也能定得清楚。说实话，日子过得有安排、有产出、也有盼头，这种感觉很棒。

[PRE2]

每个人走的路都不一样，而复盘会指出该调整的地方，让我们慢慢靠近更好的自己。这就是复盘的价值。

看到这里，你大概已经留意起自己眼下使用时间的习惯了。请把记录与复盘继续做下去，你会越来越懂自己的时间流向，也更有底气管理时间。沿着记录—复盘—计划—执行这条路径，下一步就来聊聊怎样做计划，让时间利用更高效。
