# 中老年内容机会，别只盯年轻人

作者：Luke 王子｜2023-04-11

中国中老年群体的市场空间有多大，其实不用多说。更难的问题是：怎么真正摸清他们的想法和需求？

我上周去了一趟离退休办公楼，收获不小。原来离退休中心会统一给老人订中老年杂志，具体书目我放在附录里。

其中特别值得研究的是《老干部之家》。它每月出上下两刊。

上刊偏生活和表达：老人摄影、文学投稿、类似《意林》的故事，以及老年人关心的专题内容。
下刊主打养生知识——看到这里，做内容的人应该能品出机会。

还有一点值得注意：在互联网冲击这么强的情况下，《老干部之家》依然能盈利，说明它确实抓住了中老年读者的喜好。

离退休中老年人有消费能力，也有学习热情，这部分人群的价值不小。

评论区也补充了几个关键信息：

- 有人问货源，作者明确回复：没有。
- 有读者认为，不少老干部确实爱看文件类刊物；但这类机关报社未必以盈利为目标。
- 作者提醒，能看到年费标价的刊物，基本都要靠订阅才能拿到。
- 另有人指出，离退休老干部的报刊杂志往往带有订阅任务和考核指标，说白了有摊派成分。
- 渠道方面，可以关注政府机关的老干部局（办）、国企的老干部办（中心）。
- 还有读者提到，朋友在hn老干部局，这类杂志由其下属二级机构运营，各单位同样有订阅任务。
- 作者最后仍建议：不妨翻翻《老干部之家》，挺有意思。

所以，想研究中老年内容，不妨从这些容易被忽略的杂志和订阅渠道入手；同时也要把“订阅任务”这一现实因素考虑进去。
