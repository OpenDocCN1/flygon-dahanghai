# 6.3 带货变现（直播带货或小清单带货）@谢无敌

📕带货主要有两种：直播带货和小清单带货，本质都是卖别人的货、赚自己的佣金。前提是完成专业号认证，并且粉丝达到 1000 以上。

选品中心里商品按类目分好，每件商品旁边都标着佣金比例，点进去还能看到具体合作细则。

笔记带货模式 @木子蟹

最近📕企业认证店铺上线了店铺邀约达人带货功能，玩法类似抖音的精选联盟。

对有商品网感、擅长写爆文的圈友来说，这是个利好——不用自己垫钱进货、发货、售后，省去一堆麻烦事。

只要和商家谈妥佣金比例、领到免费样品，等样品到手后拍图、拆箱、测评、写好笔记，剩下就等着笔记爆了分佣金。建议多账号矩阵起号来带货，佣金能拿得更多。

# 6.6 直播变现 @谢无敌

董洁、章小蕙、伊能静等明星陆续入驻后，📕直播又迎来了一波爆发式增长，越来越多普通人也开始加入直播大军。那问题来了：不是明星、不是达人，还能靠📕直播赚钱吗？

我的回答是：当然可以。

几个月前📕公布了一组数据，晒出了平台上的“百大买手”榜单。有意思的是，榜上除了少数大牌博主，不少人的粉丝量只有千粉甚至万粉级别。

我自己也孵化过一位烘焙博主，她去年开始在📕直播，起步时粉丝并不多。但靠着坚持和不断优化内容，慢慢突破了粉丝和观看量的瓶颈。现在她每场直播人均观看稳定在 3000+，最近一场的预估销量更是冲破了 300+ 份！

这说明一件事：📕直播不是明星和大 V 的专属舞台，只要你有热情、有内容，普通博主一样能靠直播变现，实现自己的商业价值。
