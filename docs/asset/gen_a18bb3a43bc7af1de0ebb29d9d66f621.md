# 03.表达能力：把想法做成可发布内容

## 0.本章概要

💡 表达能力，就是用AI把想法变成文字、图片、视频，让更多人看见。

怎么学？可以按这个顺序来：

1. 先判断方向：内容给谁看、要解决什么问题、和别人哪里不一样；
2. 找对标内容：看同类好内容怎么选题、怎么表达、怎么吸引人；
3. 让AI出初稿：把你的想法、受众、风格和参考内容告诉它，先搭出文章或脚本；
4. 人来打磨成品：AI给的是初稿，不是终稿，逻辑、表达和细节都要你检查、修改、补充；
5. 做成能发布的内容：基础任务是完成一篇图文和封面图，有余力再试AI视频。

⚠️ 注意事项：

• AI初稿通常只有60–70分，这很正常。想质量更高，必须加入个人经历、观点和具体要求，再经过多轮修改，别指望一次成稿。
• 模型会影响质量，但不是唯一关键。长文写作目前Claude效果较强；没有网络环境，国内豆包模型也能胜任。更重要的，是你给AI的背景信息够不够清楚。
• 不要一上来就追求复杂形式。本章核心是把一篇👸号文章和封面图跑通；有余力再挑战AI视频。

希望学完这章，你能用AI协助做出一篇可以发布的内容。更重要的是，你会开始理解：AI不是替你表达，而是帮你把已经想清楚的东西，更快、更好地做出来。

## 1.表达能力：让积累被看见

当你学会积累、有了素材，接下来想把想法变成别人愿意看的内容，这就是表达能力。

文章、图片、视频，形式不同，本质都是把想法传递出去。AI降低了门槛——过去要会写、会拍、会剪、会设计，现在普通人也能快速把想法做出来。

| 形式 | 典型产出 | AI能帮什么 |
| --- | --- | --- |
| 文字 | 文章、脚本、文案 | 生成初稿、改写润色、去AI味 |
| 图片 | 封面、海报、插图 | 文生图、风格迁移、批量出图 |
| 视频 | 短视频、AI影片 | 从脚本到分镜、画面、配音、剪辑 |

AI只打辅助，内容质量高低仍要靠人工修改，不能依赖纯自动化；平台也会治理低质内容。

**表达能力和你有什么关系？**

• 有业务想推广的人：做内容比投广告成本更低，转化也更自然；
• 想打造个人影响力的人：内容是最低成本的长期积累方式；
• 想做内容变现的人：文章、图片、视频都是可以直接变现的产出物。

## 2.三项核心能力

### 2.1 先判断内容方向

当脑子里冒出一个想法，想围绕某个主题做内容，却不确定做成什么形式、往哪个方向走——这时候就需要做内容方向判断。

选题是判断的产物。好选题比写作更重要，它决定内容流量的天花板。

对标是判断的依据。它用真实市场数据告诉你：这个方向值不值得做、能做到什么程度。

很多人一上来就让AI写文章、想选题、做脚本，结果内容空泛、没有核心价值。问题不在AI，而在于跳过了方向判断，直接进入执行。

让AI动笔之前，先和它聊清楚三件事：

1. 这篇内容给谁看？
2. 他们为什么看？有什么问题或需求，你能解决？
3. 这个选题别人做过吗？做得怎么样？

前两个是向内问自己，第三个是向外看市场——也就是找对标。如果同类内容有人做过还做得不错，说明这个方向有市场需求；同时你能看到别人做到什么程度，知道自己该往哪里提升。

好的对标，能直接把你的起点拉高一截。

下面拆解怎么判断内容方向，找到你的选题。

**第1步：想清楚三个问题**

可以和AI对话，帮自己思考清楚。

• 给谁看？→ 具体到一类人，不是所有人。

AI会给你很多内容，可以多轮沟通得出方向。不要回答“给所有人看”，有用的答案要具体到一类人，帮助这类人解决某些特定问题。

你给谁看越清楚，后面的内容就越容易具体。

• 他们为什么看？→ 有用、有趣、有共鸣，选一个点主打。

大多数内容一般都会包含这三个点，比如：
**有用**（看完能解决问题）；
有趣（看完有新鲜感、反差感、故事感）；
**有共鸣**（有情绪价值）。

• 我希望他们看完做什么？→ 点赞收藏、关注、点击、购买。

比如希望点赞收藏，内容就要偏清单、方法、干货；希望用户关注，内容就要让人觉得你后面还有东西。

别小看这一步，重点是学会倒推：从结果和目标反推内容。最后想让用户干什么，会反过来决定你前面怎么写。

**第2步：找对标内容，确认方向**

**（1）何为对标？对标能做什么？**

很多人理解的对标，就是抄一个标题、改几个词，或者换个说法重新表述。

其实核心不是抄，而是拆解：拆账号框架、拆内容、拆爆款因素。

对标＝找一条你能看懂它为什么有效、并且自己也能模仿的内容。

看到一条爆款，不要只看数据，按四个维度问自己：

1. **它在吸引谁？**人群画像要清晰，否则数据再高也跟你没关系。
2. **它为什么被点开？**标题够狠？封面够强？选题戳中问题？还是情绪、利益、身份认同拉满？
3. **它怎么把内容讲下去？**开头怎么钩人？中间怎么展开？哪里给结果，哪里给案例，哪里做转折？
4. **它最后把用户带去哪里？**收藏、评论、关注，还是点击链接？目标动作都没看懂，就学不到重点。

**（2）怎么判断一条内容值不值得对标？**

最重要一点：这条内容对我来说是不是能做出来。

**看作者是谁。**大V的爆款靠粉丝基础、团队、资源，你学不来。

重点找素人的爆款——粉丝不多但数据很好的内容，说明内容本身有力量，这才是你能复制的。

看内容结构：结构清晰，容易模仿。比如👸号某类内容：
• 开头钩子（吸引、引发兴趣，让人往下看）；
• 主体内容（做信任，有点内容，意犹未尽）；
• 结尾升华（让读者认可，加强共鸣）。

结构越清晰，你越容易模仿。

另外两个因素和人群画像、内容目标有关，可以作为次要参考。

**1️⃣ 这条内容的人群，和我要做的人群画像是否一致？**

不一致，对标没价值。比如别人写给职场女性，你写给副业新手；别人写给母婴人群，你写给AI工具党，哪怕它爆了也不一定适合你。

方法一：把素材发给AI，让它做详细用户画像分析。
方法二：用第三方数据查对标账号画像，比如抖音用抖查查、📕用千瓜数据；第三方平台要会员，可以去闲鱼买一天会员。

**2️⃣ 这条内容的目标和我内容的最终目标是否一致？**

别人那条为了卖货，你的目的是涨粉——目标不同，内容结构完全不一样，照搬意义不大。

方法：看内容风格判断——营销型还是转化型，不同风格代表不同目标；看文末引导关注或商品链接——目标是关注还是卖货。

**（3）确定对标方向以后，去对的地方找对标**

你要写文章/文案 → 去👸号和📕。

• **👸号看长文表达**：重点学怎么开头、怎么把一个主题讲完整、怎么起承转合。优先找细分领域账号，重点关注低粉爆文（平时阅读几十，突然出一篇10万+），这种最值得拆，说明选题够大众，标题和内容都有可借鉴处。
• **📕看短文表达**：重点看标题怎么写、首屏怎么抓人、短句怎么排、图和文字怎么配合。📕学短内容怎么抓眼球，重点看标题写法和首屏排版。

你要做封面/图片 → 去📕。📕点击全靠图＋标题，是学封面设计最好的地方。看三件事：画面有没有重点、标题和图配不配、信息排列清不清楚。

### 2.2 让AI产出更高质量内容

核心价值：把你脑子里模糊的想法，变成AI能读懂的清晰指令，减少AI瞎输出，少改很多次。

核心认知：决定AI输出质量的三个要素。

**第一：对标素材（60%）**。AI的本质是模仿，给它看什么风格，它就往那个方向走。

1. **先喂案例，再提需求**。不要上来就让AI写，先把对标内容发给它，让它照着这个风格来。案例可以来自别人，也可以来自自己往期内容。案例查找可以参考知识库搭建内容。
2. **拆解你想要的结构感**。光扔案例不够，把你看中它哪里也说清楚：开头怎么起（提问？场景？金句？）；中间怎么铺（总分总？故事流？清单体？）；结尾怎么收（呼吁行动？升华观点？留白？）。
3. **素材要一眼能懂**。复杂、绕、需要琢磨的案例，AI抓不住重点；越直白、越典型的素材，模仿效果越好。

怎么从一篇喜欢的文章里提炼风格？可以用《逆向提示词》＋文章内容，让AI提取风格提示词。

什么是逆向提示词？拿现成好结果（图/文），让AI反推用什么提示词能生成这样的结果。先有别人做好的成品，再倒着猜当初用了什么命令、什么要求才做出这个东西。就像别人端上一道好菜，你觉得好吃却不知道用了什么食材，就让AI告诉你菜谱，以后照着做。
