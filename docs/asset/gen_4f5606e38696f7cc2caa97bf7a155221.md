# 2. 测品的底层逻辑

测品到底是什么？一句话：它是选品的验证环节。选品阶段通过拆解同行链接数据，大致能判断这个品在📕的竞争大小、月毛利润、流量多少等，但这些都只是纸面分析，具体选的品能不能赚钱，还得靠测品来检验。选品偏重理论分析和经验判断，测品偏重实操，是检验选品是否正确的唯一方法。

📕测品，本质是在测大家搞流量的能力。因为产品足够细分，搞来的流量一般都比较精准，只要流量稳定，基本就能出单。当然，前提是【链接页面的转化率】已经优化好。

测品的周期：一周。

📕高客单蓝海电商走的是精品路线，不像店群要上很多链接；同时一个类目的品可以都放在一个店铺，所以也不需要一个📕店铺对应一个品，太浪费。一般来说，一个📕店铺里放<20 个品都可以。

我们的实操经验是，一个品一个品地测，最好上一个品就测一个；把品全部上到店铺也可以，但要从选品数据显示最好的那个品开始测。

每天发布 3-5 条笔记，尽量不要集中发布，一般测一周，能出单的品也就出单了。

📕蓝海电商出单通常比较快，因为产品足够细分，引来的流量也足够精准。在链接页面转化率没问题的情况下，如果一周内没有出单，就要考虑换品。

只要一周能出单，就继续做，提升搞流量的能力。一般来说，新人需要 2-3 个月才能保证流量稳定、稳定出单。

当然，有些产品有流量高峰，比如玄学产品，各类考试日前夕——中考、高考、考研、考公等前夕会迎来流量小高峰。这需要大家在选品时通过分析数据发现，然后选好测品时间；如果在选品时没发现这种时间节点，完美避开了流量小高峰，做起来就会很辛苦。

（玄学产品虽然利润高，但做起来有难度，容易违规，对新人不够友好。新入行的圈友还是挑其他类目做，更容易拿到正反馈。这里只是拿它举例，不代表推荐大家都去做这个类目。）

1. 拉高商品链接转化率

测品之前，需要确保产品链接在转化率方面不拉胯。以下这些方法是我们经过实操总结出来的，可以从这些方面提升店铺链接的转化率：

# 4.1 发晒单笔记

上架商品链接后，第一时间找身边朋友从自己店铺下单，再找产品供货商（上家）发货。这一步做数据对后面出单很重要，建议都去做，尽量找朋友下单（下单到你自己家），避免用自己的号下单，主要担心没有 IP 隔离。收到产品后正常拍摄，多拍 live 图和视频，不同场景多拍几个，然后让朋友账号确认收货、好评，并发布一条晒单笔记（用你自己拍摄的素材）。

# 4.2 给链接补评论

📕店铺的新链接补 5 条及以上图文评价。想要提升链接转化，人为补评价是有必要的，最好是图文评价，至少补 5 条，5 条图文评价能达到边际最大化。

📕补单主要补的是评价，流量还是得靠笔记来带。5 条图文评价，找亲朋好友就能搞定；不想麻烦亲朋好友的，就找以前的客户；没有客户积累的，就找🛰️好友；🛰️好友也不想麻烦，那就闲鱼发布任务。

# 4.3 SKU 巧引导

咱们做的链接大多数都是多 SKU 的，有时候 SKU 一多，会让用户有选择困难症，反而可能降低转化率。在 SKU 名称设置上，我们也能利用从众效应，让客户选择我们想让他们选的那个 SKU。

以脐橙为例：

[PRE27]

上图这个 SKU 设置是很原始的，只有数据参数，没有任何营销性术语，很多时候客户一眼看过去，并不知道哪个更好，所以这条链接的 SKU 设置在我看来很差。

[PRE28]

上图这条链接的 SKU 稍微设置了一下，最底下那条 SKU 名称前面加了“好评最多”，比上面那条稍微好一点，但在我看来设置得也不够好。

虽然客户看完所有 SKU 后，目光被最底下那条 SKU 吸引，但也有不少问题。

首先是排序问题，主推的 SKU 应该放前排，放最后排，是害怕让客户看到吗？

其次，主推的 SKU 肯定要推利润高的呀，推尺寸最小的果算怎么回事？

最后，营销话术还有改进空间。

[PRE29]

我们再来看第三条链接，这条链接的 SKU 设置算合格：

首先，主推链接放在前排，方便客户优先锁定，店主放在第三位，其实把主推链接放第二位会更好。第一位放店铺客单最高的，锚定价格，客户看完第一条 SKU 价格 100，再看第二条主推 SKU 价格 80，觉得 80 不算贵，因为有 100 这个最高价做衬托。

其次，营销术语不错，除了主推 SKU 外，其他 SKU 都有营销话术。

最后，主推 SKU 前面的“好评最多”可以优化成“千人好评”“万人好评”，前提是销量够；销量不够，就用“好评最多”。用这种话术的目的，就是告诉客户大家都选这条 SKU，没问题的，闭着眼睛付款就行。

# 4.4 设好优惠券

设置一个高的初始价，再设置一个高的优惠券，可以让客户有捡到便宜的感觉，特别是对于非标品来说非常好使，因为非标品没有同行参考价，你的标准就是唯一的标准。

# 4.5 选好看的模特

有些产品需要用到模特来展示效果，尽量用漂亮的模特，越漂亮越好。

比如：

祛痘产品、美白产品，需要用到模特来展示前后的效果对比图，效果图可以网上选，也可以让美工合成。

用来展示对比效果图的模特越漂亮，转化率越高，因为客户会自我带入。所以，如果用来展示效果对比的模特比较丑，会起到反面效果。

人天生偏爱好看的事物，女性尤其希望自己更美、更精致。

# 4.6 用恐惧情绪拉转化

人的情绪里，有不少都能拿来助推转化，我们用得效果最好的、目前使用最多的，就是利用客户的恐惧情绪来提升转化率。

比如：

卖儿童用品，会用“如果你不及时纠正孩子的某某行为，以后就会如何如何”“孩子的同学们都在使用这种方法，你的孩子如果不用就会落后”等等类似的话术。

卖美容护肤产品，会用“如果你不舍得花钱来保养，你节省的钱就会被小三姐花掉来保养”等等会让用户感到害怕的话术。

需要记住的是，我们利用客户恐惧情绪的最终目的，是为了转化、为了卖产品，一定是为了成交而使用恐惧，千万不要单纯为了吓唬客户而使用恐惧。

# 4.7 用相似性包装账号

📕的账号、店铺和笔记彼此成就，不能割裂来看。

首先，📕的本质不是一个纯正的电商平台，而是一个种草平台。种草平台的意思是：我有某项需求，买了某个产品，使用之后觉得这个产品很棒，分享给了📕姐妹，📕的姐妹被我真诚的分享打动，去下单了这个产品。

所以，大家在做📕的时候，给自己📕的定位不能是卖家，而是要定位成产品的爱好者或者使用者。

因为如果你定位成卖家，那其他📕的姐妹就是买家，你们之间的关系就是买卖关系；如果你定位成某个问题的解决者、某类产品的爱好者，你就跟有同样需求的姐妹们具有相似性，你们就能成为朋友，你们之间的关系就是朋友关系，而不是买卖关系。

📕的姐妹，会更相信和自己具有相似性的朋友推荐的产品，还是相信一个商人卖的产品呢？

其次，用相似性来包装📕账号，需要你清楚目标用户群体大概的画像，以及圈子内使用的特定术语。

这些都可以通过在📕搜索关键词、去看笔记和评论来得到相关信息。

所以，大家的📕账号，在性别一栏里有没有设置为女性？大家的📕笔记，有没有从产品使用者的口吻去推荐产品？记住，你在📕的定位不是一个商人，而是你的客户的朋友，你们是具有相似性的。

[PRE30]

比如，这个📕号卖的是儿童用品，她的人设定位就是成长型宝妈，分享育儿经验，很容易获得📕上宝妈们的信任，📕上的宝妈会认为她是“自己人”，因为她们之间具有相似性。

以上，当店铺链接转化率没有问题之后，我们在测品时只需要专心测流量即可。

1. 图文还是视频，怎么定？

由于不同的品适合的内容展现形式不同，得到的效果也会不同。

这个小节我会先跟大家举例说明，什么样的品适合图文，什么样的品更适合视频笔记，大家可以根据自己的选品自行选择图文或视频内容形式。

比如百货赛道，大部分产品都需要把功能和应用场景展示出来，让消费者发现这个产品可以解决自己的需求，因此大部分百货产品更适合视频笔记。
