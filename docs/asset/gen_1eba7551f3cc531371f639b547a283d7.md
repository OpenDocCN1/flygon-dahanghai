提醒：市场与规则持续变化，下面提到的赛道未必一直有效，甚至可能慢慢走弱。因此本章重点不在“押赛道”，而在给方法：把底层逻辑吃透，再迁移到别的领域。

# 3.1.2.1 职场类：怎样挖大厂裁员与薪酬爆料 @枫宇翔

职场这个方向，我想再拆细一点，专门讲讲“大厂裁员、薪资泄露”这类题怎么选。去年直播和各类分享中，我多次强推这条线。原因不复杂：大环境讲降本增效，企业持续优化人员，很多人自然紧盯裁员、优化消息。这类人更爱在职场社区吐槽、讲自己的经历，选题就藏在这些内容里，脉脉尤其明显。

操作上，先下载脉脉，注册登录，刷大厂相关消息；也可以直接搜某家大厂，会跳出一堆员工爆料。只要与大厂有关，网友通常愿意看，因为这些公司本身有热度。搜到后，把主题截图和评论区截图放进文章，再结合自己的判断解读现象即可。

其中，裁员、薪资泄露等方向已被验证能出爆款。手册7.7“职场裁员&薪资泄露系列”里给过对标账号：该号2023年12月19日开始更新职场信息，覆盖裁员、薪资泄露等，到现在数据都不错。

脉脉里互联网公司较多，但也能换行业，公务员、设计师、房地产等同样有类似信息；去头条、百家号、抖音、快手也能搜。若你本身就在这些行业，更好——专业网站或App里往往就有消息。我是程序员，所以更关注互联网企业。

这里注意三点：
① 裁员、薪资泄露只是众多消息中的一类，顺着脉脉还能挖出更多方向。
② 这类大厂消息关注度高，也容易引起大厂公关注意。写的时候只围绕网友评论讨论，别自行脑补，更不能造谣或带节奏攻击公司；保持客观，借信息表达自己的职场态度。多观摩对标账号，看别人怎么落笔。
③ 除了脉脉，知乎、豆瓣、BOSS直聘等也能找到职场信息；裁员社会新闻、老板公开谈裁员的观点，同样可写进文章。对标账号的核心是“职场+裁员”，但形式会逐渐变化。

# 3.1.2.2 热点类：怎样从热榜挑题

热点选题优先看各类热榜。我常用微博热榜和知乎热榜，但热点亚种不同，选题方向也有差别。

“指点江山型”专门抨击社会不公，主要读者是中老年男性。这个方向做选题，知乎热榜明显比微博热榜更合适：知乎对社会负面新闻曝光力度更大，微博热榜修饰痕迹较强，力度弱一些。

还要注意：不少知乎爆款回答有流量，却和热榜无缘。这类内容往往比热榜更尖锐，写出来也更容易爆，因为它们是读者一个个赞票选出来的，已经成功挑动情绪。选题要选的，就是这种刀刀见血的内容。所以“指点江山型”的思路是：知乎自然爆款 > 知乎热榜 > 微博热榜。

[PRE0]

“娱乐热点型”专门追当下娱乐热点，主要读者是中青年女性。这个方向对多数作者来说，微博热榜作用最大。一天多刷几次微博，看到“热”字可以挑，有“沸”字优先选，有“爆”字不仅要优先，还要当天尽快出文，否则流量会明显衰减。所以“娱乐热点型”的思路是：饭圈小道消息 > 微博热榜 > 知乎热榜。

[PRE1]

“养生热点型”专门做科普知识，主要读者是不分性别的中老年人。特别提醒：这里的“养生”和通常认知不太一样，多来自古话，比如“立春三不吃两不喝”。老年人死亡焦虑、疾病焦虑较重，这类内容容易贡献阅读量。做法是结合农历节气，在热榜里挑健康相关内容，但落笔只能往古代习俗上靠，不要给医学建议，否则容易严重违规。所以“养生热点型”的思路是：节气≥微博等平台的健康类选题。

其余热点亚种我接触较少，留待以后探索。

# 3.1.2.3 剧评类：怎样找评剧切入点

剧评选题有两个思路。

一是“热点+剧评”。比如电影《满江红》正火，评价褒贬不一。此时若能写出五六七八篇角度新奇的影评，就能接住它的流量。

二是“经典老剧”。比如《知否》《甄嬛传》《大明王朝1566》等。老剧本身流量大、信息量足，随便抠一个细节都能延展出很多内容，写来写去不太缺选题。夸张点说，一部剧写出几百篇也不难。两个方向都能作为选题方向。

# 3.1.2.4 法律类：怎样选民生新闻

写新闻尽量选官媒报道过的，被投诉的概率会小很多。要记住：新闻不涉政、不涉军，最好是蹬鞋踩袜子、家常里短之类的民生新闻，与老百姓生活紧密相关。能爆的新闻类内容，几乎都落在这个范围。

[PRE2]

所以这次我没建议去微博、知乎找，原因就在这里。各地新闻节目也能当素材。看到哪条新闻让你血压上来，就选它；没感觉就放弃。理智一点的做法，是对照“开幕雷击七要素”筛选：占2条以上要素的新闻优先用；只占1条不建议；一条都不占绝对不能用。后面的法律条文，直接百度检索，关键词抓新闻故事的本质。比如有人把别人头打破，就搜“把人打成轻伤怎么判刑和赔偿”，会得到大量资料，再汇编到对应模块。

# 3.1.2.5 历史类：怎样定历史选题

历史选题可以追热点，也可以按自己想法中规中矩地写。

1、追热点要时刻盯热点动向。比如“胡歌生女，众人震惊”，也可以找重要人物出生或生子引发巨大反响的事件。当然，这种热点需要非常高的契合度，经验不足时不建议写。类似的还能借“县长贪污”新闻，写古代官员贪污会受什么处罚；借“明星和粉丝”，写古代追星族的狂热，比如《大宅门》里白玉婷嫁给尚筱菊照片的事就有历史原型。

[PRE4]

注意：追热点历史必须契合度非常高，而且要从今观古，对作者写作功底要求相对高，可以在以后写作中慢慢给自己加分。

2、中规中矩写作，就是按自己的想法，写自己喜欢的历史人物和事件。写作最重要的是写得高兴，可以选敬佩的人物、讨厌的人物、觉得惋惜的人物、让人落泪的人物。找到人物后确定基调，包括人物事迹，大致给人物一个基本概括：是敬佩、同情、值得肯定，还是毁誉参半？全文按一个基本思想写，就不会有大问题。比如写隋炀帝，基本绕不开劳民伤财、暴政、急躁等缺点；写唐太宗，可以用虚心纳谏、宽厚爱民等角度为他打光。

[PRE5]

对记载很少但非常喜欢的人物，可以从他的前人、后人、身边人等角度写，也可以适当编撰，但别太虚假，始终保证假故事为真性格服务。

再推荐圈友@一来 试过的近代史领域选题。写历史类可以涉及近代史：这个领域起号相对难，常要一个月，甚至还有不确定因素；但账号进入流量池后，阅读量比较稳定。可参考“飞扬说史”，基本每天都有大小爆款，不好的地方是文中经常没有广告。

# 3.1.2.6 情感类：怎样挑有爆款相的素材

情感类爆文要挑有爆款潜质的素材。可以去各大平台找灵感。

# 3.1.3 选题避坑：这些雷区别踩 @半糖梦呓

公众号也是公域流量，措辞必须格外小心。题材踩坑时，写得再好也难爆；有时用了某个违禁词，也会被平台打压。具体要避开三类坑：

# 3.1.3.1 政治红线别碰

内容平台每月封禁几千上万个账号。这些账号里，大部分是很黄很暴力的号，还有相当一部分踩了政治红线。什么叫政治红线？记住两个词：党史、军史。准备写文史类内容的作者尤其要注意。党和军队都是正面形象，写作时只能选正面内容，其他不要写。想要足够安全，1840年以后与中国有关的任何事情，最好都别写。民国的人物和历史，半糖的建议是慎写，新手最好不碰。文史领域本身敏感，自媒体人更要牢记使命、不忘初心：不该说的话一个字别多说；敏感历史事件、人物一根头发丝都不要提。那喜欢历史怎么办？建议新手从古代史入手，最好是中国古代史：一来安全，二来受众广、话题多，容易出爆款。

# 3.1.3.2 追热点别吃人血馒头

追热点是自媒体人的天职，但有一类热点在公域平台绝对不建议碰，那就是吃人血馒头。什么叫吃人血馒头？第一个例子是二更食堂。这个号曾是百万粉丝大号，如今已被封号。原因是滴滴空姐被害事件后，二更食堂利用大众关注度，编造许多无中生有的情节，用词情色、猥琐，对死者是一种侮辱。这种行为就是吃人血馒头，后果是百万粉丝大号说封就封，一点余地没有。

[PRE8]

第二个例子是今夜90后。一个孩子和母亲吵架后跳桥，今夜90后虚构了许多不存在的细节，事后证明是杜撰，只是博主为博眼球。这个账号同样被封禁。

[PRE9]

利用逝者大做文章，甚至编造不存在的细节，用夸张、性暗示语言描述事件，吃相实在难看。网络不是法外之地，更不是道德禁区。中国人向来认为死者为大，谁想拿逝者做文章，都会激起众怒。有人会问：碰到这种热点，我不吃人血馒头，也不脑补造谣，就站在小老百姓角度评判社会行不行？不行。因为这样一不小心就会挑起社会对立、煽动仇恨情绪。那么多正面事件看不见，专盯社会负面写，不封你封谁？

# 3.1.3.3 财经健康要资质

最近有小伙伴问半糖：“我昨天发了个微头条，竟然被官方删除了？”

[PRE10]

问清楚后发现，他没有财经资质，却写了财经内容。财经、健康领域都需要完成职业认证才能写。没有认证的作者写这两个领域，要么被限流，要么被删文，总之想做大是万万不能。头条官方对财经和健康领域作者门槛有明确规定，需要职业认证，具体如下：

财经领域——要满足以下22种职业中任意一种并提交证明资料，才可以进行职业认证：经济学者、财经评论员、财经媒体人、市场研究员、特许财富管理师、金融风险管理师、财经/投资分析师、特许金融分析师、投资经理、基金经理、交易员、银行行长、精算师、注册会计师、注册税务师、私募投资人、证券投资顾问、保险经纪人、保险代理人、理财规划师、黄金投资分析师、证券经纪人。

健康领域——以下十种情况中任意一种并提交证明资料进行职业认证：医生、护士、药剂师、康复治疗师、放射/检验技师、医院院长、营养师、医药研究员、医药工程师、心理咨询师。

更具体内容可去头条职业认证的认证标准处查看，此处不赘述。如果以上都不满足，财经和健康这两个领域就别碰，这是非专业人士的禁区。以上三个禁区属于摆在明面上不能写的内容，在任何公域流量平台都共通。

避开违禁内容后，还有一些细节要注意。首先是查询违禁词。关于违禁词，可以使用句易网微信公众号，把写好的内容粘贴进去查询，系统会自动过滤出违禁词。查了之后你可能会意外：这不是天天挂嘴上的词吗？怎么也算违禁词？具体大家自己试，半糖不举例。如果没有违禁词却依然被限流，那就要找找是否有标题党嫌疑。怎么找？举个例子：上周，一个小伙伴问半糖老师，这篇微头条被警告了该怎么改。她原来的开头是：“闺蜜和前夫打来电话，要我退还1000000给他，我把他爆骂一顿之后拒绝了。他又发来一张照片和一条信息：晚上8点来我家。我呆呆的看着照片，眼泪夺眶而出，恨不得打死我自己。”系统警告理由是“刻意隐瞒关键信息”。

[PRE11]

“隐瞒关键信息”通俗讲就是标题党。曾被全网戏谑的UC震惊体，就是标题党中的“翘楚”：套路是故弄玄虚、小事夸大、隐藏主语；读者被标题吸引进去后，发现后面的内容简直把智商按在地上摩擦，会有被戏弄的强烈反感。读者纷纷取关、拉黑，连平台也一起骂。平台不傻，有UC的扑街史在前，现在谁还做一锤子买卖？于是加大了对标题党的打压力度。学员这个开头里的“一条信息和一张照片”，就是典型故弄玄虚，也是被限流警告的原因。半糖建议她改成：“他发来一条信息说：你看看这张照片，看你还敢不还钱？”这样改后意思一样，但没有刻意隐瞒关键信息，该表达的都表达了。

[PRE12]

4个小时后，这篇微头条爆了63万+。

[PRE13]

很多时候，扑街文改成爆款，就一句话的事。但大部分小伙伴稀里糊涂，文章静悄悄就扑了，想破脑袋也不知道问题出在哪，其实就是某句话甚至某个词踩坑了。给大家总结几类避坑题材：
1. 有关政治的不能写：包括党史军史军、时政热点、国家领导，除非你有互联网新闻信息服务许可证；
2. 追热点不吃人血馒头：就算不造谣，站在小老百姓角度评判社会也不行；
3. 财经、健康需要资质才能写。
其他避坑题材还有：
4. 公务员、体制内题材也不要写，非常容易违规；
5. 黄赌毒一定不要碰；
6. 一些媚外内容也尽量不碰；
7. 娱乐领域一些负能量事件和艺人尽量不碰，除非官方发话。

内容来源：《今日头条七大变现方式，我只用一种，半年赚80000》

# 3.1.4 选题技巧：做出差异 @张波

选题一定要有差异化。大家内容差异化太低、千篇一律，就很难脱颖而出，拿到较多流量。很多写情感方向的作者还在写那些事，殊不知看这类文章的人，看到以前的所谓爆款已经没新鲜感了，除了自嗨，看的人越来越少。选题一定要分析。下面两个例子可能不太准确，希望能给大家启发：千篇一律的东西看的人越来越少；一个人顿顿大鱼大肉也会吃腻，要学会找差异化。

观点+情绪

[PRE15]

分析领域内账号的写作角度。比如以观点+情绪为导向，很多账号写正观点+正情绪；在特别拥挤的情况下，你可以写不同观点+正情绪，也可以写正观点+不同情绪。举例：2024年养老金调整——
正观点+正情绪：《2024年退休金调整新规：工龄超30年上涨10%，年金最高可达到8万元？真相来了！》
反观点+正情绪：《可能85%的人都还不知道！养老金今年按工龄进行调整了：满30年工龄，每年多涨240元。这三种人有福了！》《坏消息传来？中央定调：2024年3类人将被取消养老金，社保缴满15年也没用！赶紧看看！》
正观点+反情绪：《2024年养老金“20连涨”？3651元以下，按10%上调；6400元以上，停涨！这样行吗？》

热点+领域

[PRE16]

分析领域内账号的写作角度。比如以热点+领域为导向，很多账号写热点+领域；在特别拥挤的情况下，你可以写不太热+领域，也可以写热点+其他领域。举例：
热点+娱乐：《众人惋惜娃哈哈创始人宗庆后逝世，只有王力宏说得一针见血！》《嫌王力宏老，买百万名表，她是42岁的娃哈哈新掌门》
热点+情感：《又上热搜了，娃哈哈宗馥莉谈恋爱啦，知道对方是谁后，我想哭了……》
热点+业务：《来了！不给娃哈哈设计大厦，我都对不起宗庆后和全国人民的热情！》

# 3.1.5 好选题的三个要点 @开卷🌀

常见的找选题方法，在航海手册里都有。这里只补充一点：我能把入池率做到100%，在选题上还有另外注意的细节点。
