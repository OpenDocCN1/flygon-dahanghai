# 九、更多资料方向

# 9.1 优质赛道的挑选方法

# 💡
方向清晰的小伙伴：  
1. 本身在教育行业摸爬滚打多年，有经验积累，清楚客户是谁、痛点在哪，能迅速匹配产品。  
2. 会看行业数据，能判断哪些领域正在往上走。  
3. 网感不错。比如前段时间“高考志愿填报”相关服务和产品，就是很典型的风口。  

# 💡
还在迷茫的小伙伴：  
1. 以前没接触过教育行业，也没实际做过。  
2. 不太擅长看行业分析报告。  
3. 网感一般。  

但没关系，没有人天生就什么都会。好在我们在生财有术，能接触一线的互联网信息源，这一点已经比 90% 的普通玩家更靠前。  
找赛道前，先弄明白什么算优质赛道：  
- 市场规模要足够大。比如带闲鱼项目，如果叫“闲鱼数码项目”，能收的学徒就只限对数码感兴趣的人；如果叫“闲鱼高客单价项目”，那想做高客单价产品变现的人都能来。鱼多的地方，才更容易钓到鱼。  
- 消费频次要高，也就是复购率要强。像 K12 教育，每个新学期都要学新内容，补习机构就能获得成倍增长。  
- 可持续性要强。有些项目只是昙花一现，短期吃一波流量红利就没了；优质赛道往往有稳定流量。  

下面分享几个挑赛道的方法。

# 方法一：跟着热点周期挑赛道
在我们航海期间，会有一批热门教育活动，这些活动背后往往藏着大量资料需求，大家可以从中选择参考。  
[PRE13]
[PRE14]

# 方法二：借助官方数据筛赛道
看看国内头部教育企业在做什么，比如新东方、好未来等，跟着资本市场的大方向走，通常不会偏太多。  
优先考虑需求大的领域，切入教育行业里热门、主流的赛道。  
[PRE15]

也可以查官方数据，了解人群需求，比如每年考研人数、微信搜索指数等。  
[PRE16]

还可以留意身边的广告。无论公司大小，只要持续投放广告、频繁出现在你视野里，就说明这个行业有市场需求。

# 方法三：用差异化切需求
怎样靠差异化找到蓝海？  
可以把“教”和“育”拆开看：“教”以老师为中心，“育”以学生为中心。  
比如大家都盯 K12 学生市场，那能不能转向教师群体？可以用赛道对比表做市场定位分析，想清楚后再推进后续工作。类似例子不少：大家都在教育孩子，那能不能改成“教家长怎么教育孩子”？希望你能挖到属于自己的蓝海。  
[PRE17]

# 方法四：从专业和兴趣出发
兴趣是最好的老师。  
把兴趣和市场需求结合起来：找到两者的交集，选一个既让自己有兴趣、又有市场需求的赛道。  

1）从成就事件里找优势  
举个例子，我的朋友 L 做投资。  
她天生对数字、原理敏感，从小数学成绩好（成就一）；  
大学时爸爸一次性给了四年学费，她拿这笔钱做投资，日子过得很滋润，赚钱对她像数字游戏（成就二）；  
工作后专注炒股，常能从盘面里看出买卖点，收益总体不错（成就三）；  
每次聊投资，她看几眼就能说出不同数字代表什么，并推导买卖时机。她不怕质疑，甚至享受逻辑验证，靠专业度吸引了不少客户（成就四）。  
从小到大，她对数据、逻辑、原理都很敏锐，分析能力强，也一直靠这个方式取得阶段性成果。  
放到盖洛普语境里，这就是“分析”才干：对数字敏感，喜欢追根究底，不接受未经证实的结论，相信科学而非直觉，能看透事物本质。  
像这样列出 3—5 个成就事件，找共同点。你会发现，在那些带来成就的人和事里，我们总在用某种方式拿到结果，这个“经常出现的方式”往往就是优势。  

2）从重复行为里找优势  
一个人愿意花大量时间反复做同一件事，大概率是因为这件事吸引他，而其中就可能藏着优势动力。  
举个例子，朋友 A 爱出门、爱参加活动、爱交新朋友。她会不断参加活动，哪怕晚上 11 点也准时到场；隔一段时间不社交就无聊。生活里遇到难事，她第一反应也是出门见人，听听朋友的经历和建议。  
A 的“取悦+行动+积极”才干很突出。认识新朋友、尝试新体验，对她来说是充电；有她在的场子不会冷，大家也开心（取悦+积极）。听到好建议马上行动、拿到反馈，又会推动她持续迭代。  
当然，重复行为不一定总有正反馈。  
比如我忍不住到处看消息、看商业报道、发朋友圈，也容易溜号；另一个朋友忍不住学各种课程、收集各种小东西放房间，可能被人说不务正业；还有朋友平时话不多，一开口就指出问题并给方案，容易被认为是挑刺。  
我们都会在人生某个时刻怀疑自己走的路不对，但没意识到这些忍不住去做的事，背后体现的是思维、理念、搜集、学习、取悦等才干。就像我几乎不缺朋友圈素材：搜集才干帮我攒素材，理念才干带来灵感，思维才干加工成文字，靠持续写变现了七位数，可我从未系统学过写作。  
所以，如果你有忍不住想做的事，不管身边人支持还是否定，这件事大概率对应着你底层才干的需求。关键是找到这个才干适合应用的场景，不断放大优势。  
不过，选赛道的前提一定是以市场需求为第一原则。否则容易陷入虚无主义，最后变成为爱发电。

# 避坑提醒
1. 不要没有准确的赛道定位。  
反面例子：本来想打造考研老师人设，正常该卖考研资料，结果跑去卖小学作文素材。  
2. 不要赛道多而杂。  
别做成大杂烩，要做精品店、专卖店。一个账号又小学又初中又考研又教师资格证，太杂太乱，没有明确定位，别人一眼就觉得不专业、不靠谱。做项目和账号定位时，专业性最重要，尤其教育领域，大家最看重的就是你的专业度。  
3. 不要坚持到一半就放弃。  
别三分钟热度，今天搞 K12 教育资料，明天做考研资料，后天又做法考资料。短期看不到结果，一定有问题；不及时改正，换下一个赛道还会遇到同样的问题，无法根治。认准一个赛道后，尽量跑到闭环。  
如果中途发现赛道市场体量或天花板达不到预期，再考虑换赛道。但在大教育赛道面前，卖资料这件事其实不用太担心，它可能只是整个教育赛道里的冰山一角。
