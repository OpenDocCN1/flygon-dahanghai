# 2.4.1 合并的必要性
清洗后的数据需要合到一起。此前虽然分成两条分支，但并不会同时产出两套数据，实际始终只有一套。原因在于 NewsAPI 只有成功或失败两种结果：成功时直接给出数据，不经过 GNews 模块；失败时内容为空，流程才进入 GNews 模块并取得结果。只是 NewsAPI 与 GNewsAPI 的结果在 n8n 里属于两套不同字段，为了让它们归并为同一套字段，才需要 Merge 模块。
