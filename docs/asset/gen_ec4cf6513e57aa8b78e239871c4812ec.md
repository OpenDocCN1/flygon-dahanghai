## 发票文字，一键变 JSON

做财务自动化、表格同步或入库时，最麻烦的往往不是发票本身，而是把票面文字整理成可用的数据。这个“发票信息抽取器”就是为此准备的：输入一段发票文字——OCR 结果、邮件正文、聊天窗口粘贴的内容都行；输出一份可被严格解析的 JSON，能直接写进数据库或 Google Sheets。

### 它怎么工作

收到文本后，识别并抽取字段，最终只返回一个 JSON 对象，放在标记代码块里。最终回复里只保留这个 JSON 代码块，不夹带说明文字。若某个值不存在或无法确定，统一填 null。日期用 YYYY-MM-DD；金额、数量等数值用数字类型，保留精度，但不要货币符号和千分位；税率给小数（1% 写成 0.01），同时提供展示字段（如 "1%"）；items 数组必须存在，没有行项目就输出 []。

### 字段结构

```json
{
  "invoice": {
    "title": "string|null",
    "number": "string|null",
    "issue_date": "YYYY-MM-DD|null",
    "currency": "string|null",
    "buyer": {
      "name": "string|null",
      "tax_id": "string|null",
      "note": "string|null"
    },
    "seller": {
      "name": "string|null",
      "tax_id": "string|null"
    },
    "items": [
      {
        "name": "string|null",
        "spec": "string|null",
        "unit": "string|null",
        "quantity": "number|null",
        "unit_price": "number|null",
        "amount_without_tax": "number|null",
        "tax_rate": "number|null",
        "tax_rate_display": "string|null",
        "tax_amount": "number|null"
      }
    ],
    "totals": {
      "amount_without_tax": "number|null",
      "tax_total": "number|null",
      "amount_with_tax": "number|null"
    },
    "issuer": "string|null"
  }
}
```

### 角色判定要严格

模型配置可以用 gpt-4o、temperature 0。系统提示里最关键的一条是：买卖方只能按票面中文标签判断。看到“购方/购买方/购货单位/购买单位/Buyer”才映射到 buyer；看到“销方/销售方/销售单位/卖方/开票单位/Seller”才映射到 seller。不能根据公司类型或主观印象猜角色。没有明确标签时，对应一侧填 null，并在 meta.role_source 标注 unknown。输出必须是一个可严格解析的 JSON 代码块 [PRE2]，不能有额外文字。

用户侧请求则要求从发票图像抽取结构化信息：日期、数值、税率、items 按上面的规则；buyer/seller 只依据票面标签，任一侧无明确标签就把 name/tax_id 置 null；同时输出 meta.role_source，取值 labels、heuristic 或 unknown，本任务只允许 labels 或 unknown。仍然只返回一个 JSON 代码块。schema 中额外包含 meta.role_source，图片地址用 {{ $json.data.url }} 传入。

[PRE3]
```javascript
// n8n Code 节点：发票解析
// 读取模型返回内容（兼容字符串）
const rawOutput = $input.first().json.choices[0].message.content;

// 若为字符串，先转成 JSON
let parsed;
if (typeof rawOutput === 'string') {
  // 清除可能附带的 markdown 代码块标记
  const cleaned = rawOutput.replace(/^[PRE4]$/, '').trim();
  parsed = JSON.parse(cleaned);
} else {
  parsed = rawOutput;
}

// 取出 invoice 节点
const inv = parsed.invoice;

// 扁平化输出，便于写库/写表
return [{
  json: {
    title: inv.title,
    invoiceNumber: inv.number,
    issueDate: inv.issue_date,
    currency: inv.currency,
    issuer: inv.issuer,
    buyerName: inv.buyer.name,
    buyerTaxId: inv.buyer.tax_id,
    buyerNote: inv.buyer.note,
    sellerName: inv.seller.name,
    sellerTaxId: inv.seller.tax_id,
    itemName: inv.items[0].name,
    itemSpec: inv.items[0].spec,
    itemUnit: inv.items[0].unit,
    quantity: inv.items[0].quantity,
    unitPrice: inv.items[0].unit_price,
    amountWithoutTax: inv.items[0].amount_without_tax,
    taxRate: inv.items[0].tax_rate,
    taxRateDisplay: inv.items[0].tax_rate_display,
    taxAmount: inv.items[0].tax_amount,
    subtotal: inv.totals.amount_without_tax,
    totalTax: inv.totals.tax_total,
    grandTotal: inv.totals.amount_with_tax
  }
}];
```
