# 邀约达人：每天把额度用满

人工一个个精细对接之外，每天那点批量邀约的额度也别浪费，坚持做下去，效果常常超出预期。

工具上我们用的是至尊宝插件，服务市场就能买到，选好达人直接批量发邀约，纯佣模式，比例大概五到八成。筛选达人这一步要下功夫，关键词词根和出单渠道属性都得用起来，比如这个品可以围绕【2K22】【篮球】【体育】【游戏】【手游】【科比】【库里】【詹姆斯】这些词去捞人，顺着词根筛出匹配的达人，再批量发邀约。

邀约文案同样关键，佣金、产品、团队优势三言两语讲明白，最重要的是把联系方式留清楚。说到底，达人邀约就是靠量砸，每天额度务必清零。后台给的邀约数量跟店铺经营情况挂钩，起步每天50个，做起来后能涨到几百个。

额度用完了还不够怎么办？达人广场后台、达人预留的电话和微信、抖音私信，这些渠道都能补上，继续触达继续聊。

# 话术怎么设，私域怎么玩

自家产品的卖点、店铺的优势，要跟同行摆在一起比，提炼出产品和交付服务真正强在哪，达人看了才容易动心，尤其是前期销量还没起来的时候。

[PRE5]

对接达人，本质上就是在做私域。

达人流是起量最快的方式，没有之一。初期比自己去磕图文、短视频和直播要直接粗暴得多。对接最好用专门的工作微信，响应最及时。

达人一定要分类，按抖音账号、出单量、出单风格、佣金比例这些维度把通讯录标签打好。加上好友之后多聊，尽量处成朋友，合作稳定了甚至可以照着达人的需求去开发产品。

核心就是私域思维，拿运营私域的方式经营达人群体。我自己的微信里躺着近两千个达人，全部分门别类标好，一有新品就精准通知到对口的达人。平时我还爱给合作达人发发红包，今年家里荔枝就送出去一百多份，都是给关系铁的达人。

佣金和产品都一样的情况下，同行想撬走跟你合作紧密的达人应该很难；要是随便就被人挖走，那说明你功夫还没下够。有时候同样的品，我们给的佣金甚至比同行低几个点，但服务做得扎实、售后率压得低，了解我们的达人照样愿意跟我们走。所以得花心思占住达人的心智，让他们清楚并认可我们团队的实力。

心里要有个概念：他们不只是达人，是一起赚钱的家人。

**③**无人直播：能出单，但小心封号

这个品我们算是最早一批试水无人直播的，峰值同时在线破400，当时一分钱没投。

玩法是电脑对电脑打，录超高清素材，录制时挂中文解说包，再加点娱乐效果，比如画面里人物忽然变大变小，看着很有戏剧性。

录视频和跑无人直播都吃电脑配置，设置好之后基本好几天不用管，流量和成交自己就来了。目前来看无人直播对这个品算是相当不错的出单方式，但平台稽查系统在升级，封号风险实打实存在，要玩得谨慎。

**④**店铺运营：评分就是命

这个产品的缺点得说清楚：

1）买家以中学生为主，白嫖党不少，退款率比别的品偏高。

2）同行倒卖：有些同行自己账号不够用、拿不到货，就直接转卖我们的号，毫无底线，一个号卖给一堆客户，一旦触发风控，所有用这个号的人一起遭殃。

3）后端交付重：产品国内没上架，得用美区苹果ID，账号容易不稳定甚至失效，客户操作也繁琐。

这些毛病摆在这，店铺体验分很容易往下掉，新版CCR尤其敏感。但评分还是得拼命保，最好稳在4.8以上，掉到4.6以下投流受限，跌破4.0精选就没了。

这个品的售后比我们其他品都难搞，客服大多是女生，对手机电脑这些设置不太熟，最好配一个技术宅组长，专门啃疑难杂症，把售后撑住。

能尽快过新手期最好，新手期单日上限1000单，回款T+10；过了新手期回款缩到T+4。

体验分怎么维护？找对标杆达人，聊深聊透，佣金给到位，基本不会出大问题。要拉分一般找第三方代办，上福利产品冲评分，价格三五块到十块不等，看对接的资源。

**6.** 小结：能赚，但别跟平台硬刚

这个品多少带点擦边，平台不待见，隔三差五就敲打一下。凡是跟平台对着干的产品都逃不掉，所以虚拟类目坑特别多，我自己就被封了二十多个店。

前期起量快、有钱赚，做起来确实爽。不过我们早过了做这类品的阶段，棱角也被平台磨平了。对个人或小团队来说，这个品其实挺友好，每个环节都有流量入口，天花板虽然不高，但一年弄几十个W不难。

我们团队方向已经定了，22年初就不再做这个品。虚拟市场盘子很大，当初产品池里类似的品不少，以后有机会再聊。这类产品，挑几个垂直方向扎下去，年入几十万完全没问题。

抖音上的爆款课程大多走学浪交付，学浪是抖音亲儿子，平台明显在扶持。也有不少店铺把客户往微信私域、小鹅通、公众号、APP里引，但抖音正在收紧站外引流。顺着趋势走，尽量在学浪里完成交付最稳妥，跟着平台方向走很重要。

**2.** 学浪交付好在哪

1）订单和抖音小店同步，订单页直接能打开，买家下单就能看到。

2）课程存在学浪服务器上，店铺后面什么状态都不影响，课程一直能看。

3）订单页没有退款入口，下单即签收，回款速度非常快。

4）学浪交付的课程售后和品质退货指标天生偏低，店铺评分更稳。

5）课程只能缓存在学浪APP里，不能下载，设置禁止录屏后同行想抄也抄不走。

6）学浪是抖音官方APP，自带信任背书，客户买完在抖音后台就能直接看课，这两点对转化帮助很大。

**3.** 小结：天花板高，适合公司化作战

这个案例天花板高、稳定性强，我认为适合公司化运作。

产品研发这一关就筛掉了大部分虚拟类目选手，想做这件事得做好打持久战的准备。IP打造和做号同样需要稳定专业的团队持续产出，对直播、剪辑、投流团队的要求都不低。

不过抖音知识付费赛道机会还非常多，很多垂直小赛道没人碰，一个选题就能撑起一门课去卖。刚开始不必盯着大类目大咖，从更垂直的选题切入就行。技能、知识都能包装成课，往上K12教育，往下个人兴趣，甚至价值观输出，都能做成课程。我们最近也在跟机构合作，借助抖音把行业老师多年积累的知识传递给更多需要的人。

六、避坑指南：这几条红线要记牢

**1.** 法律红线别碰

产品如果涉及盗版或侵权，必须格外小心。这类擦边货能赚钱，但心里不踏实，不知道哪天平台就找上门。所以不建议都走擦边路线，我们多数违规只停留在平台层面，尽量别踩到法律这条线。

**2.** 资质要备齐

证照要齐全，营业执照经营范围、特定类目许可、ICP、出版物经营许可、各类报白这些都得备好。执照注册、ICP这些别自己瞎琢磨，会就自己办，不会就花钱解决，把精力留给真正重要的事。

**3.** 交付与售后：心态要稳

客服三分钟内回复，盯住品质退货CCR指标，各种售后疑难杂症及时处理。

品质退货是抖店圈公认最头疼的，吐槽的人一大片，虚拟类目也一样，只能靠客服提前引导消费者按流程走售后。做虚拟类目心态要稳，实物退款率三到五成，虚拟一般只有5%到15%，好接受得多，售后也简单。高频问题直接做视频或图片教程，能砍掉一大半售后。遇到难缠的，能退就退，别浪费时间掰扯，今天不给他退，明天换个问题照样来烦你。

**4.** 平台政策：别对着干

别跟平台硬碰，虚拟类目最大的变数就是政策打压。

我们踩过的处罚大概是这样：抖音规则越来越完善，虚拟产品的处罚力度一天一个样，有直接扣12分罚5000的，刚开店就被关联处罚，好几个店一起搭进去。坑踩多了，对规则也就慢慢摸清，现在能坦然接受。
