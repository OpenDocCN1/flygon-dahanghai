# 售后减损：证据、时效与运费险

顾客反映商品异常时，动作要快：先请对方把瑕疵部位拍清楚，最好把外箱、面单一起入镜；照片到手后立刻转给上游供货方。举个例子，生鲜店卖出五斤橙子，收货时约半数已坏；客服当时没追要“坏果与面单同框”的凭证，顾客隔了两三天才重新上线，此时已越过签收起 24 小时的售后窗口，回头找上游，对方就可能以超期为由拒赔。遇到这类情况，可以先问顾客是否接受补发；若愿意补发，损失往往能压下一部分。ps：质量异常的照片越早拿到越好，既能掌握真实情况，也方便同上游交涉。

非生鲜类售后，同样要抢时间。小红书审核通常给 48 或 72 小时，淘系、拼多多的窗口往往更短；不管平台给多久，都应尽早向上游递交申请，同时先向买家核实：包装有没有开封、是否使用过、整体是否完整。确认这些后，再问供货方是否符合退换条件。小红书商家后台还能配置简易自动售后，例如未发货订单自动同意退换。

# 5.3.2 差评的后果与止损

现阶段，差评直接作用于店铺服务分：分数高可获得流量扶持，分数低则面临清退风险。更现实的影响在商品转化。小红书用户收货后，除非遇到质量问题，通常不会主动评价；没人引导的话，卖几百单也未必换来一条评价。带图差评更扎眼，图片会直接出现在商品购买页。爆款尤其要把售后做扎实，把差评概率压下去（亲测销售 500+ 零评价）。

平台还看点评回复率：每两个自然周考核一次，负面点评回复率若低于 80%，每次扣一般违规积分 2 分。建议在用户点评后的 24 小时内认真回复，并真正解决对方反馈的问题。

已有差评产生，可以这样降低伤害：
1）后台申诉。按遇到的问题选择对应入口。

[PRE6]
一般违规，商家要在平台发出违规通知之日起 7 天内确认调查单或发起申诉；7 天内不操作，就视为认可处理，处罚自动生效。同一项违规，线上申诉最多三次。想提高成功率，证明材料要完整、真实、有效：聊天记录、截图、链接、照片、录音、快递单凭证等。细则见《小红书违规申诉管理规则》。
2）商品宣传别过度夸大。
3）可致电消费者，请对方补删评论。

# 5.4.2 商品名称禁止使用的词语

商品描述里若出现“最高级”“国家级”“最佳”“顶级”等绝对化说法，每次扣 25 分；情节严重的，店铺会被冻结。与顾客沟通时，嘲讽、诽谤、谩骂或使用不文明语言，被举报后同样每次扣 25 分。更多违禁词可查“电商违禁词整理”。

# 5.4.3 食品类产品下单需注意

食品包装必须有标签，标签应写明：一、名称、规格、净含量、生产日期；二、成分或配料表；三、生产者名称、地址、联系方式；四、保质期；五、产品标准代号；六、贮存条件；七、食品添加剂在国家标准中的通用名称；八、生产许可证编号。

# 5.4.4 尽早熟悉流程

非团队作战，有些流程越早摸熟越好。比如拍单软件：单量少时手动打单尚可，订单一多就容易手忙脚乱，效率也低。

# 5.4.5 持续关注产品质量

做无货源时，商品开始零散出单后，建议买回样品看看实物，自己心里有底，售后率也会低一些；同时主动和供货商家建立联系，减少沟通成本。

# 5.4.6 如何辨别和应对打假人

打假人可分三种：要饭的、坐班的、职业玩家。

要饭的：这类多是刚入行或专门找茬的人。套路一，钻平台规则空子：比如平台近期严查无货源，他就举报你，再私下要钱协商；这种通常给点钱就能打发。套路二，走工商举报：有人想捞偏门，甚至卖家被整过之后又去整别人。真遇到工商举报，先听工商工作人员的建议；除非确实是自家产品质量问题，否则不要轻易赔付。可向工商提交情况说明，写清起因、经过，末尾明确拒绝赔付；同时与打假人谈处理方案，一般不难解决。

坐班的：这类人每天批量下单、批量写材料、批量投诉，多数全职靠这行吃饭。他们常盯近期有问题的品类：比如某段时间有关部门明确辣条中不得含谷氨酸钠，他们就集中打这个品，逻辑跟我们追选品热点很像。遇到这种人，如果对方没在客服端提索赔就直接起诉，大概率说明产品真有问题。其投诉方式通常是走工商或发律师函。应对上，可联合同行一起谈；这类人除了换投诉身份，在工商往往留下不少记录。各地政策不同，即便产品有问题，工商面对职业打假人也会考虑从轻处理。再顺着上游源头拿到资质和质检报告交给工商，最终处罚通常不会太重。

职业玩家：这类更专业，一旦遇上，基本意味着产品百分百有问题。他们只走起诉，索赔一般 1 万元起；若起诉金额在 5000 元以内，不必应诉，直接电话协商赔偿即可。应对方式是找处理过电商案件的律师应诉，律师会教你怎么用管辖权异议、申请破产清算等办法把损失降到最低。当然，能被这类人盯上起诉，说明店铺最近生意不错，他在动手前肯定看过你的资产足够赔付。

# 5.5 笔记&选品复盘

# 5.5.1 笔记复盘

# 5.5.1.1 看笔记数据

1. 阅读量
发布后 2-3 小时内阅读量差，或长期卡在 100-200 甚至不足 100，通常有几种可能：账号处于运营初期，权重偏低；笔记违规、踩到敏感词，或内容本身不是平台会大力推荐的类型；选题、标题文案、首图不够抓人，尤其要回头检查选题角度和首图。

2. 赞藏和评论
1）点赞收藏合计超过 10、评论却为 0，或只有点赞没有收藏评论：说明内容还在被推送，但转化弱。可在评论区引导下单。评论区优化：用其他账号引导购物车，比如刷“惊喜盒子”，或评论“已买”并附购买截图。
2）收藏高于点赞：说明干货偏多、种草偏少，需要调整。优化方向：补充产品使用场景，或用文字完善产品相关信息。

# 5.5.2 选品复盘

# 5.5.2.1 先看选品是否符合爆品标准

先看销量。月销大于 1w，且多家店铺都在卖，说明是爆品，相关爆款笔记也多。近期销量 100-500，在售店铺少于 5 家，说明是近期爆品，少量商家发笔记就能拿流量。月销 1000-3000，在售店铺不超过 3 家，说明是少量自有货源品，或投流产品。以裤子为例：在商城搜“裤子”，筛出高销量产品，点同款进对标账号店铺看笔记时间，再进账号主页看爆款笔记的时间周期做分析。

[PRE15]
接着分析该品的笔记数据。按上面的标准点进店铺，再看账号笔记数据。以下是选品实测参考：笔记发送数据近 7 天，销量 1000+，爆品率 80%；近 30 天，销量 10000+，爆品率 50%；近 90 天，销量 10000+，爆品率 20%。怎么找爆品跟品？还是以裤子为例：小红书商城搜“裤子”，看到店铺销量 1w+，且近期加购 1000+（最好看 24 小时加购），就可以跟品发笔记，出单概率较大。

# 5.5.2.2 结合对标账号爆款进行选品分析

找对标账号时，重点看选品周期。3-90 天内的爆款，要及时跟款。什么是选品周期？3-7 天内，对标账号的高销量品属于实时爆品；30-90 天内，对标账号的高销量品属于小红书需求品，生命周期更长，还会再爆。若是当下应季类产品，参考周期要相应缩短。

# 5.5.2.3 分析垂直账号发现页爆款

账号主页垂直后，小红书会在发现页直接推送你同类目的爆款。点进笔记看发布日期，判断是否落在 3-90 天周期内。

# 章节概要

当你对选品有一定体感、订单也能持续，想再提升笔记质量，就可以开始实拍。实拍没想象中难：新手前期用低成本布景加苹果手机拍摄，后期制作也很简单。接下来，进入实拍环节。

# 本章航线图

完成本章学习和实操，就能完成航线图中的：

· 首次下单 1 个样品，拍图（约 3-4 天）
· 模仿 5 个爆款笔记，拍出 ≥15 张图（约 3-4 天）
· 保持日更 ≥5 篇原创种草笔记（约 2 小时/天）

# 6.1 下单货品（物流 1-4 天）：样品与借样

产品持续出单后，新手第一批可下单 3-5 个品的样品，用来拍实拍图。下单样品步骤：
先确定要下单的选品。
接着跟供应商沟通“借样品”，先转账付货款（快递费也自己承担），并留好货品清单【如果前期借不到样品，跳到下一步】。
然后找身边朋友从自己店铺下单，再由上游发货；这一步做数据对后续出单很重要，建议都做。尽量让朋友下单并寄到你家，别用自己的账号下单，主要担心没有 IP 隔离。
收到货后正常拍摄，多拍 live 图和视频，不同场景多拍几条。
最后，让朋友账号确认收货、好评，并用你拍摄的素材发一条晒单笔记。

注意事项：
1. 样品下单环节，直接在自己店铺拍单即可；
2. 供应商那边，若想长期合作，可确认对接流程：是加微信下单，还是走 ERP 下单。两种方式区别：微信下单可避免二次面单被平台判无货源；ERP 下单适合单量多时，商家能看到你店铺后台订单后直接发货。新手前期单量少，直接走微信下单即可。
