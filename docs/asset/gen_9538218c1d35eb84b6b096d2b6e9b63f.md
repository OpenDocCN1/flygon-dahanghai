# 2.4.1 软广怎么写才不招烦

软广最难的地方，在于它既要完成商业表达，又不能让读者一眼识破“这就是广告”。真正有效的植入，不是把产品硬塞进文字里，而是先让内容本身站得住，再让品牌顺理成章地出现。

动笔前先想清楚：读者为什么愿意点开？他想解决什么问题、获取什么信息，或者得到什么情绪？把产品放进这条需求链里，它才有被提到的理由。

具体落笔时，可以抓住几个关键点：开头别急着亮品牌，先用场景、问题或故事把人带进来；中段让产品成为解决方案的一部分，而不是突然插播；语气保持日常，少用夸张承诺和推销腔；卖点要具体，最好落到使用细节和真实感受上；结尾的引导轻一点，给读者留出选择空间，别急着催下单。

同时，软广要控制“广告浓度”。通篇都是产品名，读者会警惕；完全不提产品，又失去了商业价值。更合适的做法，是让干货、故事和品牌信息彼此咬合，比例根据平台和受众来调整。发布前不妨自查：如果删掉品牌名，这篇内容还成立吗？成立，说明内容底子有了；再加上品牌后是否自然，则决定了它像不像一则软广。

说到底，软广的高级感来自克制与可信。先尊重读者的阅读体验，再完成表达目的。让广告藏在有价值的内容里，而不是让内容给广告让路，读者才更愿意看完，也更可能记住你。
