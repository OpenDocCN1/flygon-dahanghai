# 4.1.2.2 第二步：把故事拆成可画的分镜

先用提示词让 GPT 写出五个儿童绘本故事，主角是一只可爱小猫咪，去帮助其他物种。故事结构要包括：因为动物落难而相遇，获救后展现一起生活的画面，比如回家吃饭、睡觉；高潮部分要设计自然界危险，包括灾害、天敌等，用来突出猫咪为友情勇敢出手；结尾要表现两个生命之间的友情。

注意事项也很明确：动物落难要尽量能用画面直接表现，不要靠气氛、声音去交代，最好一眼就能看懂；友情可以用两个生命贴在一起来呈现；语言描述要方便画面化，可以夸张一些；剧情要让孩子容易理解，并能被友情打动。

# 4.1.2.3 第三步：让 AI 把分镜画出来

画图用的是 DALL-E3。Midjourney、SD 我也测试过，但 DALL-E3 的语义理解能力最强，其他工具很难比。它不需要你单独写一套提示词，只要把想画的内容告诉它，就能直接出图。这也是我前面要先做 25 张分镜的原因：方便把脚本直接转成 AI 图片。

入口是登录网页版 ChatGPT，在“探索 GPTs”里找到 DALL-E3；也可以直接复制这个链接：https://chatgpt.com/g/g-2fkFE8rbu-dall-e 。

角色一致性怎么解决？我原来也很头疼，后来看到卡兹克的文章提到，OpenAI 自带绘画工具 DALL-E3 的图片其实有 gen_id，可以利用它来控制角色一致。但在实际生成故事分镜时，gen_id 并不是一直管用，有时会失效，关键还是让角色外观尽量用不同颜色。比如两只猫的故事，就分别用橘猫和狸花猫，角色更容易区分。

所以我的办法是：优先给角色设计不同外观，再用 gen_id 辅助。要注意，gen_id 只在同一个聊天窗口里有效，不能跨窗口使用；如果用 DALL-E3 API 绘图，也没法靠 gen_id 控制角色一致，因为 API 每次对话都是一次性数据。所以我没走写代码调 API 的路，而是直接用网页版。

gen_id 还可以在 GPT 里配合这类提示词使用：核心目标是保持角色一致，必须沿用上一张图的提示和 gen_id 来制作同一角色的新图，让角色能适配更多表情、动态、服装和场景；做得好就给 1000 美元小费，明白请回复明白。提示词可参考：https://gitee.com/tudoujunha/rpa-gpt/blob/master/prompt_genid.txt 。

当然，像当前这种场景，两个主体都是差异较大的动物，如果一致性要求没那么高，直接用国内中转的 DALL-E3 API 生图也可以。

# 4.1.3.1 对标：一段时间只盯一个频道

关键经验：一段时间内仅对标一个频道。

这是我在之后的 YouTube 实战陪跑时期问的第一个问题：到底是对标一个频道的爆款，还是多个频道的爆款？我们有那么多对标，他们的爆款都拿来复刻，有的流量好，有的不好，而且一直等不到自己频道的爆款，这是为什么？

[PRE17]

[PRE18]

方波妮和 Gary 曹淦两位教练诊断分析后，我顿时有了新知：一段时间内只能对标一个频道。因为这个频道能持续做出爆款，就一定有特定受众群；不同频道受众群不同，如果多头对标，YouTube 算法就没法快速明确你的频道该推给哪些受众，这样等不到 YouTube 的第一次大推流。我的频道迟迟没爆款，这是个很大的战败因子。

按发布时间降序排列，可以看到前期（最下面）我的内容五花八门，有孕猫的、亲子的，还有我原创的僵尸、科幻内容，每次都陷入今天要复刻什么的困惑。近期改成了“A 动物救 B 动物—美好相处—A 动物危机—B 动物报恩”的爆款公式，数据相对来说就比较稳定，内容也更容易改编。

# 4.1.3.2 制作：少用图生图，但可作补充

关键经验：尽量不要图生图；但有时图生图是很好的补充。

继续进入 AI 内容工作流的搭建和提效版块。做过 AI 猫咪故事赛道的圈友会知道，这个赛道做起来繁琐、复杂，如果涉及微创新和故事改编，用时会更长。一开始一天做一条内容很正常，练熟了考虑到各大平台的生成速度和反复抽卡，也得 3—4 小时一条，我一直苦恼于怎么提效。所以我灵机一动，把原来的工作流做了修改，然后收到了 YouTube 机审的自动移除。尽管我做了动物角色改编，但复现程度还是太高了。大家可能会发现，有些爆款有很多搬运大量存在，而且也是爆款（可能我那个对标爆款被抄得太多了），但还是谨慎为好。

原流程是：对标爆款关键帧截取 → AI 图生脚本（这里可以改编）→ AI 文生图 → AI 图生视频 → 视频剪辑。新流程是：对标爆款关键帧截取 → AI 图生图 → AI 图生视频 → 视频剪辑。

但图生图是一个很好的提效补充。比如当我们拥有一个爆款场景，可以直接把狗换成浣熊，做主体替换；并且利用原图还可以生成新场景：找到其中一个关键帧，加一个漂亮女生在旁边看着浣熊，得到一张图，再通过图生视频让女生和浣熊互动，这样就完成了动物救援最后的视频部分，这里仅仅只需要一句话的想象。再比如蜂窝原图，通过文生图抽卡很难达到效果，用图生图就很容易做得比较接近，是个提效和补充的好方式，但不建议全片都使用。
