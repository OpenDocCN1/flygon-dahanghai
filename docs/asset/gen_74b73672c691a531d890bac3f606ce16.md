# 1）敏感词先查一遍

敏感词会让笔记进入更严厉的机器审核，导致审核延迟甚至限流。大段文案编辑好后，用零克查词 https://www.lingkechaci.com 检测一遍，把敏感或违规词换成谐音字、拼音。

# 3）提前布局SEO搜索流量

在笔记文案里提前铺关键词，可以让一条笔记持续吃到精准流量。SEO 的意思是：比如你做小学教师资料赛道，用户在小红书搜“小学期末评语”相关字眼，就能看到你的笔记。而且主动搜索的人，消费需求和付费意愿都很强，属于非常精准的粉丝，成交率也高。

所以标题和文案里一定要布局关键词。小吃配方赛道可以用“夏日摆摊爆款”“xx（产品）配方”；创业比赛赛道可以用“互联网+”“三创赛”“xx（项目）计划书”“计划书完整版”。这样能明显提升笔记的搜索排名和曝光量。

# 3）笔记排版要清爽

小红书很看重精致感，排版占很大优势。用户多在碎片时间刷小红书，清晰排版能大幅提升阅读体验，让人一眼看到关键信息。最重要的两个点：

1. 封面标题提炼。封面一定要打上笔记的主要内容，让用户第一时间判断这篇笔记对他有没有用，才会点进来。
2. 文案分段。一大段文字必须空行分段，并适当插入表情，用户读起来才轻松。

# 4）添加#话题

在正文文末插入与笔记主题相关的热门话题。话题要选和主题关联高、浏览量大的。比如发一篇小学期末评语资料，在文末点“#话题”输入期末评语，会出现一串相关话题，挑上面最火的几个即可。另外可以带上细分赛道关键词话题，例如 #二年级期末评语 #低年级期末评语 等。

# 6）3个动作判断笔记是否被限流

以下三个动作，在没有阅读量或阅读量不正常时再操作。所谓不正常，指新笔记发布后 24 小时内，浏览量（小眼睛👀）还持续低于 100，或者连续几篇笔记的浏览量都在 100 以内。

1. 看能否做薯条推广。点进笔记 ➥ 点右上角“···” ➥ 点下方“薯条推广” ➥ 看能否通过推广审核；能出现付款选择界面，就说明这条笔记正常。
2. 看笔记检测里有无违规。点左上角“≡” ➥ 点“帮助与客服” ➥ 点“笔记申诉” ➥ 查看是否有违规笔记记录；没有记录就说明正常。
3. 看能否搜到你的笔记。用第三小号到搜索栏搜笔记标题 ➥ 能搜到就说明正常。

如果整个账号整体性限流，大概率是“硬广告”发多了，或者账号权重不到位。这时可以发一些有价值的干货内容，或者讨论帖，提升互动，逐步恢复账号权重和流量表现。

# 8）做好小红书的10个建议

① 干货笔记引流，单条笔记承接交易。不必所有笔记都带货，也不是所有笔记都要有高曝光，笔记的目的很重要。

② 怎么写是战术，写什么是战略。每篇笔记都要有目的，从目的出发、结果导向，中间用手段和方法填充，否则越做越迷茫，浪费时间。

③ 先模仿再创新，模仿能解决 70% 的问题。

④ 100 篇平庸，不如 1 篇精雕细琢。

⑤ 小红书不是用来展现自己的。

⑥ 发一条就认真发一条，做一个品类就把一个品类尽量垄断。

⑦ 建立热点敏感性、流量敏锐度，遇到搜索热点赶紧上。

⑧ 笔记不到 500 就是选题和封面的问题；流量有多大，要看互动指数的流量开关有没有被打开。

⑨ 爆款都是重复的，重复做爆款：第一是选题和模仿，第二是高效率做内容。

⑩ 认真尚不能一定成功，不加思考的随意开始注定失败。

# 5.1 笔记挂商品链接的正确时机

先明确一点：商品链接要在发布的时候就挂，不要先不挂、等流量起来再挂。挂商品链接会影响流量，但不一定是负面影响。商品笔记的流量，是我们能拿到的除付费流量之外最精准的流量。

现在有两个位置可以挂商品链接：笔记标签最后面，以及评论区置顶。上面这个位置，手机和电脑都能挂；下面评论区置顶的商品链接，电脑不能挂，只能手机操作。一般来说，用电脑发布笔记效率更高，但只能挂上面这个链接，不过也够用。建议先用电脑发布，后面有数据不错的笔记，再用手机重新编辑，在评论区挂商品链接。

[PRE25]
# 5.2 一个店铺多个账号怎么协同

可以把小红书账号理解成放笔记的载体。一个账号每天发太多笔记容易违规，所以用“1 个专业号 + 3 个主理人账号”的模式，把笔记量分摊到多个账号，不把鸡蛋放在一个篮子里，降低违规可能性。

建议采用这样的运营方式：绑定店铺的专业号不发或少发笔记。虽然我们是正规玩法，但违规风险仍然存在，平台时不时会抽风。主要用主理人发笔记，挂商品链接。

[PRE26]
# 5.3 发货与售后避坑

小红书从过完年开始整顿店铺端运营。以前只要做好前端笔记，店铺不用怎么运营；现在店铺运营也很重要，尤其售后，用户负反馈率太高会直接限制流量。

发货常见问题：物流设置不对。编辑商品时注意物流类型，要选有“无物流配送”几个字的，否则没法自动发货。如果忘了选但已经有人拍，就去拼多多用买家的物流信息拍一单礼品单，再用礼品单的快递单号去小红书发货，千万不要随便乱填单号。运费模板一定要选全国包邮模板；默认是非偏远地区不包邮，会导致新疆、甘肃、海南等省份拍不了。我们是虚拟产品又不发货，选全国包邮就行。

[PRE27]
售后常见问题：网盘链接打不开。很多用户其实不会用网盘，尤其是大文件，不保存就直接用手机下载。最好提前录个视频，给用户展示怎么使用百度网盘。用户没开会员，文件数量太多一次性转存不下，可以告诉用户只转存一部分马上要用的资料，其它资料随用随取，链接永久有效，不用全部转存。遇到用户要退款，态度一定要好，直接让对方退就行；引导用户选择退款原因时，选拍错/多拍/不喜欢，或者其它。用户如果选择不利于我们的退款理由，会被计入负反馈率，次数多了会被限流；此外，如果用户发起退款选择的原因不利于我们，就算修改了也没用，只计算首次。

# 5.4 店铺运营与优化细节

好评返送其它资料。用户拍下后自动发货，同时可以有一段话术，引导用户好评并赠送其它资料，可以直接参考淘宝/拼多多同行的话术。这样在刷好评的同时，还能让用户确认收货，更快拿到货款。

[PRE28]
在千帆后台可以设置自动回复，把用户常问的问题提前写好答案，能立马回答、打消顾虑，大大提高转化率。用户一般比较关心：怎么发货？能不能立马发货？资料有没有答案？资料能不能打印？能不能试看？是不是 word 能不能编辑？这些比较通用。某些特定资料有特定关心的问题，需要在当客服的过程中和用户多沟通、总结出来。同时，自动回复对客服三分钟回复率的考核也有一定提升作用。

七天无理由退款一定要开。不开七天无理由没有任何意义，该被退款的订单依然会被退款；此外，很多用户在下单界面看到醒目的“不支持七天无理由”几个大字，会因此没有下单。
