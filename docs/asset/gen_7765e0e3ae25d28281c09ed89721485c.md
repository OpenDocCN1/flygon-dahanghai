# 💡 开场：AI视频的新机会

这一章会带你了解AI视频制作的前沿动态和潜在机会，同时学会使用相关工具。可以按照下面这条路线开始：

先用大约1天时间，认识AI视频生态和主流工具（Runway、可灵等）各自的特点。

现在就出发吧。

最近几年，AI技术突飞猛进，视频内容创作迎来了翻天覆地的变化。从最初用AI辅助剪辑、自动生成字幕，到如今模型可以直接产出视频画面，AI在视频生态里的角色越来越重要。

这种技术演进把视频创作的门槛拉低了很多，效率也大幅提升。哪怕你没有专业的拍摄和剪辑经验，也能靠AI工具快速把想法变成画面。当脚本、拍摄、剪辑都不再是障碍，作品能走多远，反而更取决于创意本身。

从内容生产来看，AIGC（AI生成内容）正在重新塑造短视频行业。2024年，抖音等UGC平台上冒出了一大批AI特效视频，用户传一张图或输入一句话，就能得到有趣的视频内容。比如Remini的“黏土动画”特效曾刷遍全网，吸引了几百万用户参与。

需要留意的是，AI视频生成技术虽然发展很快，但目前仍有不少限制，做这个项目也存在一些“坑”。下面给大家列出来，希望提前注意：

- 纯AI生成的视频通常比较短（多数工具一次只能生成几秒到几十秒），画质和精细度跟专业拍摄相比还有距离。
- 复杂场景、多角色互动等内容，目前仍然可能出现瑕疵。
- 生成内容的可控性和一致性也是挑战，比如视频帧的连续性、角色形象在不同场景里能否保持一致。
- 别盲目追求高级软件，先把一个工具用透，再考虑扩展。
- 别忽视版权问题，商用时要确认素材授权。
- 别过度依赖AI，创意才是核心竞争力。
- 千万记得备份工程文件，否则突然崩溃可能白干一场。

好在这些问题正在被技术逐步解决——新模型不断出现，支持更长时长、更高分辨率的视频生成，也允许在生成时加入参考图像或预设风格来提升一致性。总的来说，AI视频生态正从早期探索走向实用化：创作者拥抱新工具，内容形态更丰富，但也要清楚技术的短板，才能更好地驾驭AI去创作。

## 2. 创作思路

了解完账号的基础信息后，我们就可以来构思创作思路了。这些账号有这些共通之处：

- **营造理想化体验**：不管是现实的田园风光、精心布置的家居，还是AI生成的梦幻场景，都透着宁静、温馨、梦幻或古朴的氛围。田园风光追求自然和谐，梦想之家追求精致或梦幻，古风音乐疗愈则追求典雅意境。它们展示的往往是现实的提纯和美化，过滤掉不完美，呈现出一种理想状态，可以总结为“向往的生活”。
- **引导性标题**：使用能引发用户共鸣、思考或向往的文字，比如“这样的生活你喜欢吗？”、“当你老了会选择怎样的生活？”、“治愈你的心灵”等。
- **舒缓的BGM**：选择与画面风格和情感基调高度匹配的背景音乐。音乐疗愈类视频更是以音乐为核心，通过特定的旋律、节奏和音色来舒缓情绪、疗愈心灵。
- **内容垂直**：每个账号都有相对明确的主题定位，比如“蜗居”的隐逸山居，“一方净土”的田园诗意，“媛媛美景”的理想小家。这有助于吸引特定偏好的用户并建立粉丝粘性。
- **追求“疗愈”与“美好”**：无论哪种形式，最终都是为观众提供精神上的慰藉、放松和对美好事物的向往，都属于“情绪消费品”。
- **关键词**：“治愈”“宁静”“放松”“美好”“诗意”“梦想”。
- **叙事手法**：往往不过多解释，而是通过画面和音乐引导观众自行感受和解读，留下想象空间。

经过上面的分析，你已经知道这些视频的受众是谁、她们爱看什么内容。接下来就好办了，甚至有了对标账号做参考，我们是不是就可以针对性地做内容了？当你带着这些思路去做账号，相信会游刃有余得多。

## 3. 视频拆解

接下来我们详细拆解它们的制作手法。

乡村生活和梦想小家的制作难度只有一颗星，你只需要三步：生成图像、图转视频、制作视频。

有圈友可能会问：现在的AI视频不是能直接文生视频吗？为什么还要先生成图像？

这里其实是出于两点考虑：生成成本和时间成本。如果用文生视频去产出完全符合自己想法的视频，需要大量抽卡。每次抽卡都要消耗金钱，对新手来说不是最佳选择。如果先生成想要的场景，也就是图像抽卡，这个成本可以尽可能压缩到接近0。有了符合预期的场景之后，再去生成视频，抽卡的成本和时间都会大大降低。
