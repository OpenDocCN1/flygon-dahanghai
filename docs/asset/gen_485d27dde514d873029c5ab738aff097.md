# 中国Web3路线：链可扶，币严管

Web3通常包含两块内容：一块是区块链底层技术，另一块是去中心化金融。国内监管态度已经相当明确——底层链技术获得鼓励，DeFi相关业务则被划出红线。

在政策定位上，区块链已经进入“十四五”七大数字经济重点产业名单，并被看作发展数字经济、建设数字中国的重要支撑。围绕这一产业，创新并不只落在技术一端，而是覆盖技术、平台、应用和监管四个层面。智能合约、共识算法、加密算法、分布式系统等方向，都被明确为需要持续攻关的重点。从各部委发布的相关文件也能看出，区块链、元宇宙等技术应被积极引入，用来推动产业升级和数字化转型。

落到具体形态，联盟链和数字人民币是当前可见的主要载体。

从已经出台的法规条文看，创新背后的边界同样清晰：

**Token如何定性**
它不被视为货币，也不享有与法定货币同等的法律地位。

**金融活动怎么管**
交易、ICO被归入非法金融活动，相关业务全面禁止。挖矿不符合节能减排和碳中和的战略方向，同样在禁止之列。即使主体注册在境外，只要在境内开展相关业务，也可依法追究责任。个人参与加密货币交易，财产安全不受法律保护。若借Web3之名从事洗钱、赌博、传销、非法集资、网络诈骗等传统金融违法违规行为，将依法处理。另一个现实问题是，Token定性尚不充分，部分落地案例中涉及加密资产的纠纷，不同地方法院出现过不同裁判：有的将其认定为合法标的物，有的则认定不合法。

**税收关注什么**
税收监管目前主要面向联盟链相关业务，暂未涉及加密货币。

整体来看，中国对Web3的选择不是全盘接受，也不是一概否定，而是把“链”的技术价值留下来，把“币”的金融风险挡在外面。
