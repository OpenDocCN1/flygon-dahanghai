# (精华帖)(92 赞)创业故事：从流量玩家到亚马逊大卖，再到跨境服务商

作者：亦仁
日期：2018-12-12

按惯例，每周三我们都会请来一位新的生财合伙人，坐下来聊聊。

前不久我发了条朋友圈：每个做成事的人背后，都曾有过勇敢而孤独的决定。这句话戳中了不少人，也包括我自己。我接触过的大多数生财合伙人，哪怕是创业多年的老手，在面对未知时也会迷茫，甚至害怕。有人整夜睡不着，有人压力大到几个月白了头发。

但很多时候，光想全是问题，动手做才有解。如果因为害怕就原地不动，那真的什么都做不了。创业嘛，就是要学着一边害怕，一边往前走。

今天这位生财合伙人，就属于那种不断在害怕中向前走的人。他做过很多大胆且只能自己扛的选择，未必到了人生巅峰，但在自己深耕的领域已经相当有成绩。

他做海外流量时，一个niche站就能月入5万美金；做亚马逊卖家时，旺季单月销售额冲上500万美金；做资源整合时，又打造过亚马逊圈子里规模最大的Review公司，日均刷单上万。现在，他是一名新媒体创业者。一个擅长玩流量的人，怎么把能力复制到媒体赛道上？

欢迎「侃侃网」创始人Moss。

生财有术的朋友们，大家好，我是Moss，来自侃侃网。感谢亦仁的邀请，来这儿跟大家聊聊我的事业和生活。

先简单交代下背景：我的本科和硕士分别在新西兰和澳大利亚完成，读的是电子商务与计算机科学。毕业后，我一个人跑去美国闯荡，做出一点小成绩后又回到国内继续创业，现在依然在路上。

回国这几年，我先后在合肥、杭州、重庆、深圳这几个城市待过。眼下公司设在重庆和深圳，所以今年基本是在两地之间往返。这两个地方的朋友，以后有机会可以多聚聚。

如果正儿八经写自传，这些年的经历恐怕太长，大家也未必有兴趣。我总觉得，人生是由一个个阶段组成的：有事业阶段，也有感情阶段、身体阶段。既然咱们这个圈子聊的是“生财有术”，不是情感频道，也不是人生哲学，那我就只聊事业上的几个阶段。

作为连续创业者，我每个阶段都拿到了一些结果，主要体现在财务上。准确地说，我做过的所有项目都扎根在同一个大行业里，没有跳到太远的地方。而且每一段经历都在积累经验和人脉，对下一个项目帮助很大。上一个项目为下一个项目铺路，新项目启动时，旧项目还能在我不用太操心的情况下，持续提供现金流。所以，我算是个幸运儿，同时也是一个谨慎的创业者。

接下来，我按四个创业阶段来讲讲这些年的故事，希望能给大家一点启发，也欢迎交流讨论。

第一个阶段：玩转海外流量

大学时，我修过一门课，主要内容是社交媒体、SEO和SNS。课程不算深，基本是介绍性的，但老师讲得不错，给了我很多启发。我也算从那里入了流量的坑。

刚开始还是在读书，什么都不太懂，纯粹瞎折腾。我自己建站，主要做产品测评，把亚马逊的Review拿过来改写一遍，再挂上Google AdSense，想靠流量变现。结果可想而知：网站做得像模像样，却没有多少访问量，很快就失败了。

但我这人比较倔，不会轻易认输，一直在学习和找原因。有两件事影响很大。第一，我读了两本书，《长尾理论》和Zac的《SEO实战密码》。前者让我放下了一门心思做一两个大站的执念，开始去做长尾站群、玩niche站点；后者帮我搭起了完整的SEO思路和框架。同时，我的变现方向也从AdSense的CPM模式，转向了Amazon Affiliate的CPA模式。

第二，我加了不少黑客群、SEO群，认识一群莆田的“大神”。机缘巧合下，我找到一个高中生，也是莆田人，在百度和Google上把黑五类玩得风生水起。我咬咬牙，花了一万块钱拜师学艺，他答应线上给我上课。几个月里，我学会了很多黑帽玩法，比如流量点击脚本、流量劫持、抓RJ等等。我本来就是计算机专业，这些东西只要知道个大概方向，自己钻研一下就能融会贯通。所以说，有人带路，有时候真的比自己埋头努力更重要。

学了一段时间后，事情就开始顺了。最巅峰的时候，我一个人同时养着150个niche站，其中最大的一个站，月收入超过5万美金。那会儿，我还是一名学生。

第二个阶段：做亚马逊卖家

临近毕业，我开始觉得流量这事不能长久，想找一个更稳定的方向，能当成事业来做。那会儿黑科技玩得有点猛，还碰过黑五类，暴利归暴利，风险也大。Google陆陆续续K掉了我不少站，收入大幅缩水。

当时我一直在做Amazon Affiliate，心里就盘算：做联盟都能赚这么多，如果直接去亚马逊卖货，是不是能赚更多？但卖货对我来说确实是陌生领域。而且那会儿亚马逊还没有“全球开店”，中国团队也没建起来，要开店只能拿目的国的公司或者个人身份。我想来想去，决定毕业后去美国找机会，看能不能抓住这波红利。

到了美国，我注册了一家公司，找了一位有身份的华人合伙人，就开始干了。货源很简单，直接用速卖通做Dropshipping。那时候FBA还不普及，主流是FBM自发货。现在回头看，做亚马逊确实是踩中了风口：平台上大多是老外卖家，流量成本极低，刷单也基本没人查。

我的玩法是：用虚拟机建镜像系统，再加VPN，批量养了1000多个买家号。产品一上架就开刷，广告不投，再配合直评，新品一上架Review数量就能冲到大几百条，关键词也直接做到首页，然后等着收割。基本上每刷一个品，就能打爆一个品。后来订单量太大，速卖通Dropshipping扛不住了，就转用阿里巴巴国际站做B2B采购。最巅峰的时候，黑五旺季一个月销售额破了500万美金。

开头很美好，后续却很残酷。物流和供应链我完全没有主动权，说实话也不够懂，毕竟我是流量出身，产品这块底子比较薄。结果大量发货延迟、退货不断，最后亚马逊直接关停了我的账户，损失惨重。不过，我依然看好这个行业。跨境电商是国家外贸出口的全新方向，外贸又是拉动经济增长的三驾马车之一，而中国又高度依赖外贸出口。所以我的判断是：亚马逊可以作为长期事业来做，但供应链在中国，还是得回去才有更好的出路。

第三个阶段：建起亚马逊最大的刷单公司

回国后，我开始整合供应链资源，谈了很多工厂。亚马逊卖货的生意一直在做，后来还开展了独立站业务，主要是Shopify+Facebook的模式，也按情况接了一些代运营。整个卖家体量维持在不大不小的水平，最高峰是2016年，销售额差不多1.5个亿。

但随着中国卖家越来越多，竞争压力越来越大。FBA又需要提前压货到美国，资金链被拖得很不健康：利润全滚进库存，看不到现金，一旦封号，可能连之前的利润都没了。所以我需要找新的现金流业务。正好2016年底，亚马逊出了新政策，禁止激励性评价，获取Review一下子变成大难题。我们抓住这个点，开始搭建刷单团队。

当时我们从几个方向入手：一是美国线下拉人头派单，主要面向华人；二是Facebook广告加群控拉人头，最终落到Facebook私密Group派单；三是用短信和邮件轰炸拉人；四是通过WhatsApp群控买数据加人；五是跟北美机房合作，再加家庭IP渠道，自养账号刷单，这部分机器号可以在系统里全自动完成。

对亚马逊卖家来说，为了拿评价，产品基本是白送的，只要留评就行，所以很有吸引力。很快，我们就拉起了一支庞大的刷单团队，真人是主力，机器号做补充，迅速做到了行业头部。

但这种事只能补现金流，毕竟上不了台面。后来亚马逊打击力度越来越大，红利期一过，这个业务就慢慢走下坡路了。

第四个阶段：跨境电商新媒体一站式服务平台

我们看准的下一个风口，是跨境电商行业的新媒体平台，也就是公司目前在做的事。B2B外贸出口逐年下滑，跨境电商异军突起，已经成为外贸出口里的新力量。政府越来越重视，国内大型外贸工厂、传统品牌商也陆续进场，品牌出海越来越热。

严格算起来，这个项目是今年年初才启动的。最开始，我们只想把流量盘子尽量撑大。平台取名为“跨境电商侃侃网”。不到一年，它就成了整个跨境电商圈子里流量最猛的媒体。半年之内，我们用社群玩法、分销裂变等方式，让三个微信公众号粉丝全部突破五万，其中最大的“Moss的精神家园”已经破了10万粉；同时有2000多个微信社群，覆盖跨境电商卖家及从业者大约20万人，付费会员人数破万。这个规模放在大众行业可能不算什么，但在垂直行业的新媒体里，已经是很可观的量级。

前期我们主要押注公众号和微信社群矩阵，先把微信生态吃透；下一步则是把网站流量做大，把论坛、资讯、直播、小程序、APP和微信社群全部串起来，做成一个完整的跨境电商媒体生态。

线上之外，线下也跑得不错。半年内，我们办了一场大型千人跨境电商选品大会，五场千人跨境电商干货分享会。同时模仿樊登读书会的模式，在全国五个主要跨境电商城市都建了线下社群，定期聚会交流。这样，线上和线下流量互相导流，形成了良性循环。

不少朋友好奇，我们为什么能起来得这么快。核心有两点：一是我们在这个行业泡了很久，卖家业务和代运营业务还在跑，能持续输出选品干货和一手资讯，内容方面天然占优；二是我们大量使用社群裂变、增长黑客的打法，没有靠传统广告买量。更细的就不展开了，想了解的朋友可以私下找我聊。

还有一点，以前做海外流量的那套打法和思考方式，被我直接套到国内新媒体流量上，两边无缝衔接，这也是我们能跑这么快的原因之一。刚接触新媒体时，《流量池》这本书给了我很大启发，建议看看。

所以，今天侃侃网要做的事情，说白了就是围绕跨境电商的一站式新媒体服务，帮中国品牌顺利走出去。面向卖家和出海品牌，我们提供行业资讯、实操干货、咨询、代运营和推广落地，以及工厂/品牌转型出海的整体方案。如果你正准备出海，或者想做跨境的传统B2B工厂、国内电商卖家，欢迎随时联系、交流。
