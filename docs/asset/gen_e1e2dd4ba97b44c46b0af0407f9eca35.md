这一思路跟追热点有些相似，可以从不同角度去解读清代的保密制度；也可以围绕历代皇位传承、皇帝无嗣时各朝怎么选人、立长还是立贤、孩子多到底是好是坏等问题展开，把同一个话题讲透。历史类文章还有一种常见写法，就是人物盘点。4）历史文可以用盘点人物的方式写。操作起来很简单：盘点那些颠覆大众固有认知的历史人物，也可以列数有作为的皇帝、战神级武将、幸福的女人、悲惨的女人等。这类文章不需要太深的理论，基本一个人物配一个小故事，自圆其说即可。

# 3.2.6 情感类爆文的写作公式

写情感故事类文章，有一个固定套路：标题+主人公+故事主干+结尾，也就是一篇完整的故事。展开来说，故事的主干里要包含梦想或目标、挫折或阻碍或意外，以及惊喜或反转。再直白一点，就是谁想做成什么事，为什么做或怎么做，过程中遇到什么，最后结果如何。

动笔之前，先确定要写什么主题，拟好标题，然后顺着主题把故事写下去。主人公这部分，要交代清楚“我是谁、多大年纪、从哪来、做什么的”，简单介绍基本身份；接着再介绍与主人公相关的人或物——和主人公什么关系、怎么认识的、做什么的，也简要说明一下。故事主干要写清楚目标或梦想，以及遇到的挫折、阻碍或意外。结局则要写出这件事对主人公的影响，主人公做了什么或应该怎么做，最终结果是什么。这样一来，一个完整的故事就成立了。

需要注意，爆款优质故事通常要满足五个条件：标题足够好、内容原创、有信息增量、不重复新闻、不传播负能量。满足这五点，才有大爆的可能。写故事一般用第一人称，方便读者代入，当然这不是硬性规定，看个人习惯就好。

故事的情节要有详有略：跟主题无关的，一笔带过；能体现人物性格、推动故事发展的，要写足笔墨。结尾最好反套路，让读者产生“意料之外、情理之中”的情感体验。举个例子：某个女人结婚要太多彩礼，男方家要退婚，读者预期的结果多半是分手，但我们把结局写成他们还是结婚了。至于为什么能结婚，就要靠我们自己编排出反转的故事情节。

故事可以虚构，也可以取自自己或朋友的真实经历，但必须正向引导，不能违背伦理道德，不能传递负能量。

示例标题：
《除夕夜公公给我们100万，本是高兴的事，可被老公闹得家里鸡飞狗跳》
《我69岁，发现40岁保姆偷我钱，我要求她“肉偿”，她的反应吓傻我》
《我33岁阳了，老公连夜带着孩子逃了，半夜有人压在我身上，睁开眼我吓傻了》
《公公病危，儿媳献身，公公舒服，婆婆支持，老公发飙，结局意外》
《我51岁，二婚老婆夜班，继女爬上我的床，说难受让我帮帮她，我让她愉悦，老婆夸我真棒》

# 3.3 给文章起个好标题

# 💡

# 本节概要

对写作来说，标题决定了文章打开率，也就是阅读量。阅读量又直接关系到收益，所以标题的重要性不言而喻。好在标题是有套路可循的，核心就是「开幕雷击」：让用户第一眼看到的内容，就有让他震惊的言论或画面，仿佛被雷劈了一下，从而产生点开文章继续读下去的欲望。下面我们会用大量案例，来教大家怎么用好这个技巧。

[PRE1]

# 3.3.1 开幕雷击

每一篇文章，想要阅读量高、收益高，都需要一个高打开率的标题，第一时间抓住用户的眼球，引起他的注意，让他有点开文章的欲望。抓住读者注意力的秘诀，就是把读者最在意的内容写进标题，唤起欲望与好奇心。标题的好坏，决定了读者会不会点进来看。如果读者完全没有点开的冲动，没有兴趣一探究竟，那你文章内容再精彩也没人能看到，文章等于白写——因为没有人打开，就没有收益。

而写好标题的核心，就是用好「开幕雷击」。这个技巧最早由圈友@半塘梦呓 在星球分享，当时他拿微头条的写作方式作为切入点，讲了怎么写出开篇就能吸引人点击的文章。感兴趣的可以看原文《半塘梦呓：如何用好开幕雷击》。

所谓开幕雷击，就是你第一眼看到的内容，出现了令你震惊的言论或画面，仿佛被雷击一样。经过我反复测试，我把爆款标题的“开幕雷击”要素总结为7个：1）金钱、数字；2）性暗示；3）暴力；4）死亡；5）捷径；6）异常、悬念；7）民族主义。这7个要素里，“异常”是屡试不爽的套路。而且这7个要素不只适用于公众号，在各平台短视频、百家、头条的图文、问答、微头条等自媒体里都能用。在不违反平台规则的前提下，要尽量把多个要素揉进标题里。

很多同学文章写得不错，但开幕雷击没用好；还有的同学把雷击误解成狗血、暴力、血腥，其实不是的。那样只会让读者不舒服，还可能被限流，甚至被读者投诉举报，最终被平台删除或封号。真正的雷击，只需要有让人震惊的言论或画面、能引起好奇心就行，核心是让人感觉异常，和正常思维相反。但注意，不是直接写“很震惊”“惊呆了”，更不是写“某某一刀砍下去，血溅满身”“倒在血泊中”，而是用委婉的字眼，让读者自己联想出来。

比如，某人的家人病逝，本应该伤心才对，他却很高兴。这就是异常，让人忍不住想点进去看看，他为什么反而开心？再比如，某小店矿泉水3元1瓶、10元3瓶，大家都说老板傻，所以分开一瓶瓶买，3瓶只要9元，没想到老板却乐了。这个标题结合了金钱和异常——金钱很直观，异常就是老板为什么乐？如果是你，你是不是也想点进去看看，老板明明亏了，为什么反而高兴？

切记：不要直接写暴力、血腥、涉黄的场面，更不要写小黄文。要隔着一层纱，字面意思不要带出来，让读者自己联想。不要为了流量去挑战平台规则，那样只会得不偿失。标题里只要包含开幕雷击7要素中的2个，基本打开率就有保证了，当然包含的要素越多越好。

# 3.3.2 标题技巧 @张波

a. 爆款标题的要素：
1. 调动情绪：让读者产生喜悦、悲伤、愤怒、好奇等情绪。
2. 使用数字和数据：具体、真实，给人明确的感知。
3. 使用极端或夸张的词汇：增强标题的冲击力。
4. 保持简洁清晰：让读者一眼看到重点，快速吸引点击。

b. 爆款标题的公式：突出主题 + 矛盾冲突 + 引发悬念。比如：
- 47岁的我，搬进了丈夫的工地宿舍，被一群硬汉包围，晚上燃烧起了期待的火焰。
- 35岁新郎的一番话，让26岁新娘哭了：“你这二手货有什么好疼的？”

c. 标题润色技巧：
1. 植入流量热词，比如“疲惫不堪”“心满意足，笑容满面”等。
2. 用具体、生动的语言营造情境，展现角色，反转情节或制造悬念，让标题更有吸引力。例如：
原标题：50岁单身汉，被46岁寡妇骗进家，干完体力活后偷偷跑回了家
改后：50岁单身汉，被46岁寡妇骗进家，干完体力活后寡妇却笑容满面。
又比如：新娘缺席婚宴，丈夫报复性分居十几年，妻子的态度坚定，一直未变
改后：新娘缺席婚宴，丈夫报复性分居十几年，妻子晚上却笑容满面等着隔壁老汉的反击。
再比如：怀孕的妻子被婆婆安排去旅游，丈夫一招架醒她，却引发了一场结局
改后：怀孕了，婆婆安排去旅游，丈夫一巴掌把我扇醒，结局却让我如愿以偿。
还有：45岁美女房东求助28岁小伙修水管，修好后却有了意外收获
改后：45岁美女房东晚上求助28岁小伙修水管，修好后虽疲惫不堪却体验了不寻常的快乐。

# 3.3.3 标题示例 @张波

这里汇总几种常见的标题公式。

1. 提出疑问：人物+为什么+具体事件；人物+经历+凭什么。例如《千聊、荔枝有那么多的育儿课，凭什么李老师的课卖得最爆？》《14岁辍学，29岁身价过亿，这个90后女孩凭什么》。

2. 制造悬念，话说到一半：如何/为什么+事实+反转。比如《如何用10秒钟，把堵塞的鼻子变通畅？用它喷一喷，舒服一整天！》《为什么孩子越大越不愿意和你交流？99%的家长都不知道》。

3. 利用数字与数据：数字+事实+奖励。比如《我这里有200页重磅PPT，20个压箱底文案小技巧等你来领取》。

4. 蹭热点：把热点话题放进标题。比如《杭州亚运会开幕，但你还记得33年前在北京唱亚洲雄风的刘欢如今苍老成这样？》。

5. 作比较：形成反差和对比。比如《真正聪明的人，往往很少交朋友》《35岁月薪3500，你拿什么安身立命》《为什么方便面都有大品牌，挂面却没有》《总是踩点进办公室的人，一年后和提前5分钟进办公室的人差在哪》。

6. 权威稀缺：提供独家信息。例如《人民日报》：人之所以要努力，是为了当自己遇到喜欢的人和事的时候，除了一片真心，还有拿得出手的东西；《张小龙首次公开演讲，官方无删减版》；《离职前，我把运营黄埔军校阿狸的干货都供了出来》。总之，一个能吸引点击的标题，往往看起来特别low、特别口语化，写标题不需要你多有文采，只需要让自己换个表达方式。

7. 金钱、悬念、异常组合的标题：
1）《我65岁，再婚老伴每月退休金9000，直到外孙生日，才发现老伴骗了我》——对应金钱、悬念，爆了40万+阅读，收益3000多块；分发到头条，也爆了35万。

5）《年薪80万，坐标北京，金融气质女，29岁，主动表白。竟然被年薪30万的二本男给拒绝了》——对应金钱、异常。

8. 异常、悬念组合：
1）《知否：梁晗娶墨兰为妻，不是盛祖母面子大，而是因把柄太大》——对应悬念，阅读量3.6W，收益180+。

9. 性暗示+悬念：

# 3.3.4.2 根据经验改写

前面说的是“如果你觉得对方的标题还不错”，但新手最难判断的，往往是“什么样的标题才算不错”。我以前做小红书，发现有朋友把好好的爆款标题改得平平无奇，因为她觉得“这样才是原创，和别人不一样”。没错，标题可以原创，但原创一定要加入自己的思考。比如我会想：标题里有没有“开幕雷击七要素”中的至少两个？如果我发现一个选题不错，但标题还有优化空间，就会按照【开幕雷击的元素+爆款标题的套路】去改写标题。

当然，这里的经验来自多刷对标，不光是公众号的对标，抖音和小红书这个方向的爆款也都可以多刷。这里也有一个常见问题：既然选题定生死，那标题是不是就无所谓了，内容好就行？真的是这样吗？你面前站着两个女生，一个从头发丝精致到脚后跟，一个头发毛躁、邋里邋遢，你会先和谁搭讪？一样的道理。标题和封面就是我们的门面，像一个人的外表；而选题，是一个人的灵魂。有句话你肯定很熟悉：没有人有义务透过你平庸的外表，看到你精致的灵魂。好的标题和配图有多大的威力，刷过小红书的朋友一定见识过——精致和高级，本身就是一种魅力。

# 章节概要

公众号的收益按阅读量计算，本质上是一门流量生意。而且公众号的流量长尾很长，哪怕过去很久，也能源源不断地收获流量。建议文章写到1200字以上，这样可以插入两条广告，增加收益。

目前公众号爆文主要有两种变现方式：广告变现和打赏变现。前者是主要收入来源，后者更像是偶尔加个鸡腿。本章会详细讲这两种方式，供大家参考。另外，本章主要介绍公众号变现，所以不设置航线图任务。

# 4.1 公众号变现原理

公众号的收益按阅读量计算，也就是大家常说的流量。流量越高，收入越高，而且公众号的流量长尾很长。不过，单价受很多因素影响，比如文中和文末广告的展示量、点击量，还有完读率等等。需要注意的是，文章最好写到1200字以上，这样文中可以插入2条广告，有助于增加收益；因为800字左右只能插入1条广告。

1. 广告变现（主要）

# 4.2.1 广告变现（主要）

# 方式二：商家找我们发广告

商家通常会在后台留言“商务合作”，然后加微信谈价钱。一般要我们自己出价，对方出文案，我们复制粘贴就行。费用分头条、二条、三条，头条价格最高，一般2000以上一篇。这种广告要慎接，要看他们提供的文案涉及哪方面内容。如果涉黄、涉赌、封建迷信的，不要接，有可能会封号。价格一般如下表，具体要求、实际价格，以自己跟商家谈的为准。

# 方式三：自己在文章中带货 @徐胖子

公众号带货在十年前是非常火爆的项目，但近几年视频带货兴起，文字带货的效率越来越低。不过也要看到，公众号带货依然有前景。为什么还能做？主要有以下几点优势。

第一，公众号流量大。圈友@渭水徐公 的公众号训练营开到第七期，十万加以上的爆款累计1000篇以上，更不用说阅读量过万的小爆款有多少了。一个账号每天发8篇文章，每篇最多可以植入10款产品，8篇就能植入80款产品。只要你的推文里有一款产品爆了，收益都会很可观。

第二，公众号创作灵活，图文和货物的相关性要求低。比如你写情感领域，学习类、励志类、文学类、情感类书籍都可以带；像吃的、用的，也都能通过公众号带货。

第三，公众号佣金高。我们带的商品可以自己找商家谈佣金，书籍佣金最高能到50%，水果和蜂蜜的佣金也不低于20%。
