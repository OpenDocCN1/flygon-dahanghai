很多新手或自由职业者没有营业执照，但办法总比困难多。去淘宝搜“个体户营业执照办理”，个人营业执照 30～46 元就能搞定；注册在海南或者自己所在地都行，海南目前最便宜。第二天拿证就能开干！一张执照能挂 3 个企业号的认证，一个人名下还可以办多本执照，矩阵后期想铺多大铺多大。
