# 五年咨询路：让飞轮转动的7条原则

2021年2月28日，对旁人来说只是普通一天，对我们团队却有个特别的意义：从2016年2月29日走到这天，公司满五岁了。每年这个时候，我都会把过去一年的思考写下来。

早些年自媒体正热，有朋友替我惋惜，觉得我的名气没有换成相应的收入，挺亏。他说得不是没道理，当时不少公众号大V确实有很多变现办法，而我一个都没做。不是我不想，原因有三：一是我并不擅长，比如收费社群；二是我觉得自己提供的价值还不够，比如新媒体培训；三是我判断有些事不长久，比如公众号广告，那时我就感觉公众号在走下坡路，我也没能力把它越做越好。

所以2016年，我把方向转到了企业咨询。为什么选这行？此前我已经陆续给几家企业做过顾问，有一点业务底子，起步不算太难。更重要的是，咨询这门生意寿命长。从个人顾问算起，它已有千年历史；在我能看到的未来上百年里，它大概率还会存在。做公众号、抖音，我不知道它们哪天会消失，但咨询行业肯定比这些平台命长。既然命长，就可以慢慢做，试着留下一个百年企业。还有一点，这行不靠强运营、强效率驱动，不用像外卖那样把送餐时间抠到分钟，也不用像制造业管理大量员工，更不用像餐饮处理各种琐碎杂事。不是别的行业不好，是我不会、不擅长。行业当然有缺点：很难快速做大，优质咨询师供给稀缺。但这些都是我能接受的代价——不能快，就慢一点；人才少，就慢慢找，把优秀的人留住，公司自然会慢慢长大。选行业没有对错，只有合不合适。

2020年，咨询、广告、公关行业都不好过。我们却受到的影响不大，实际营业只有7个月的情况下，依然实现了50%以上的增长。而且这个增长还有个前提：公司个人顾问业务在2020年清零了，2019年我个人顾问业务占公司业务的三成，去年全部都是企业营销咨询。

是因为我们更有名了吗？并没有。我看微信搜索指数，“小马宋”这个指数没多大变化；公众号阅读量稳定中略有下降；我还放弃了半年时间在抖音攒下的20多万粉丝，不再更新。从对外制造影响力看，我们似乎没大进步，但确实逆势增长了，也没有倒卖口罩。

今年公司年会上，我分享过对业务的思考：从业务量看我们依然是小公司，但我们比较确定地找到了咨询公司业务增长的飞轮。

飞轮的逻辑不复杂：方案真正有效，客户就能拿到结果；客户拿到结果，就有了标杆案例；标杆案例会带来更多客户；客户更多，又会沉淀更多成功案例。同时，服务客户越多，我们在咨询中积累的知识、经验和工具就越厚，这又会增强我们做出成功案例的能力。好案例不仅吸引优质品牌客户，也会让优秀人才愿意加入，这又反过来提升我们交付有效方案的能力。于是，新一轮飞轮开始转动。

道理听起来简单，做起来却很难，跟控制体重一样朴素：管住嘴、迈开腿，真正做到的人并不多。明白这个道理，并且相信它正确、可行、通向必然，公司所有经营动作就都服务于这个最终理念。我们因此采用了和不少咨询公司不一样的做法，这些做法都围绕这个信念建立。

一，客户利益放在第一位。我们相信，为客户提供真正有效的方案最重要，所以前三年能抵住很多业务诱惑。人力不够、能力不够时，即使利润很好，也不接。

二，招人极其谨慎。我们有个原则：哪怕没人做业务，宁愿推掉客户，也不降低招人标准，因为人是这行做出好方案的根本。新员工三个月试用期内，我们会尽量考察思考能力、主动性、协作能力等；觉得不合适，就补偿一个月薪水请他离开。

三，新创业公司或客户的新项目找上门，我们会凭经验判断项目问题。成功率很低时，会诚实告诉客户最好别做，免得浪费钱。过去一年，大约四分之一找上门的客户被我们劝退，甚至放弃了项目。主动不要送上门来的业务，核心考虑是永远站在客户利益角度想问题：即使这次不成交，客户以后有新业务，还会回来找我们。

四，人员配置上，公司只有咨询师和设计师，没有客服人员，也没有业务人员。产出方案的是咨询师，不是客服和业务，我们不需要把精力耗在客勤关系和找业务上。很多公司把核心精力放在跑业务上，我们相反，把核心精力放在服务客户上，靠好口碑自动带来更多业务。我们获取业务的模型不同，省下来的人员成本，就用来雇佣更优秀的咨询师和设计师。

五，从不参加比稿，即使在公司最弱势、最困难的时候也不。比稿的逻辑是几家公司竞争一个业务，但准备提案要花太多精力，而调研和提案本身是咨询工作里最重、最耗神的部分。我们为什么要把精力押在一个不确定的项目上？所以不比稿，把精力全花在现有客户身上。我们也不曾行贿、不给回扣。比稿是很多公司的大成本，行贿和回扣也是成本；我们靠工作付出获得回报，不靠商业贿赂拿业务，这又省下不少成本。

六，业务要求能拍板的高层，最好是大老板来对接确认。有些广告公司一年忙到头，回头看却没做成什么事，很多时候就是来回修改返工太多：市场经理、总监、营销VP每人提一次意见，反复改，到了老板那里又要重做。我们要求对方能拍板的高层第一次提案就参加，并主要由高层决策，这样效率最高、最有效。省下来的精力，用在更好服务客户上。

七，员工培训上大量投入，还外请了不少顾问来辅导员工。员工成长是公司成长的基础。我们也关注新技术在营销行业的应用，相信未来大数据、人工智能以及各种新技术会对营销产生巨大影响，所以时刻关注，并尝试把这些技术用到咨询服务中。

我们也不做假。行业里不少营销案例的传播数据有很大水分，甚至一些大公司市场部与乙方合谋刷数据，因为大家都要背KPI。但我跟同事反复讲过：方案做完，即使销售额为零、阅读量为零，也接受现实，再找原因重新做，而不是找水军刷个数糊弄客户。对客户极度真诚，才能赢得信任。

更多细节不展开。核心原则就是在“为客户提供有效解决方案”这件事上投入重兵，所有事都围绕它展开，不要有多余动作，也不要把精力浪费在别处。

这听起来也简单，做起来很难。比如业务找上门，你却没人做，只能放弃。这时你会不会降低门槛，找个不太合格的员工？这个口子一开，公司立刻进入负增强状态：客户方案做不好，口碑下降，来找你的人越来越少。据我观察，不少同行就犯了这个错误：公司名声显赫时，找上门的业务来者不拒，不管自己能不能做好，结果好多年都在吃一个经典案例的老本，再也做不出更好的案例。

我们在2020年还能增长，是因为2020年做得好吗？其实不是。是因为过去三年做得不错，过去的客户案例攒下了口碑，更多客户才找过来。我个人觉得，2020年我们也做了不少不错的案例，但这些案例还在实施过程中，不能对外讲，有些客户也需要时间才能成功。所以2020年做得好，是为了未来几年能有更多业务。

今天的成功，是过去做对了一些事带来的；未来的成功，则要靠今天做对的一些事。这就是这一年做咨询公司的一些思考，希望对你也有帮助。
