# 8.3.2 差评来了怎么办

一条差评最先牵动的是店铺的服务评分：分数漂亮，平台往往愿意多给曝光；分数掉下去，严重时店铺会被清退。

更疼的地方在转化。小红书买家的习惯是：签收后只要东西没毛病，基本懒得回来写评价；有些链接卖了几百单，评价区依旧空空。可一旦出现带图差评，图片会直接挂在商品页的购买区域。若是主推款，售后更得盯紧，把差评概率压下去。（实测：卖出 500 多件，一条评价都没有）

平台还会盯商家的负评回应比例。考核窗口按自然周计算，每两周汇总一次；同一窗口里，若差评回应比例低于 80%，每发生一次扣 2 分，计入一般违规。最好在评价出现后的 24 小时内给出真诚回应，并把买家反映的事真正处理掉。

已经吃到差评，怎么把损失压下来？

1）走后台申诉流程碰碰运气

入口不难找：按你实际遇到的场景选择对应申诉项即可。

[PRE0]

•收到平台的处理提醒起七天内，要确认调查单，或者提出申诉。
•超过七天不处理，系统会默认你接受该处理，处罚随即生效。
•同一条违规，线上申诉最多给三次机会。
•想让申诉更容易过，证据得按平台要求备齐：截图、聊天记录、照片、录音、链接、快递单等，且要全、要真、要能说明问题。
