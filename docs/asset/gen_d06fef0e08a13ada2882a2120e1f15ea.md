1）为什么要做抖音直播（教育）？

通俗讲，这个项目就是在直播间讲学科知识，把有学习需求的人吸引过来，再通过直播挂车销售课程相关产品、课程或图书。即便普通人没有课程后端，也能靠直播转化小课包，为教育机构提供线索，从而赚取佣金。

《2022 教育行业研究白皮书》显示，抖音知识直播的看播时长增长了 165%；同时，超过 55% 的抖音教育兴趣用户会产生相关购买行为，其中小课包占比最高。由此可见，这个赛道的需求空间相当可观。

官方数据也释放了另一个信号：升学赛道正在逐步增长，属于蓝海市场。当前行业最大的短板是规划师严重不足，暑期高峰尤其明显；而一位规划师能服务的学员数量有限，所以这个赛道天然弱内卷。再加上内容端重服务、轻产品，对刚入场的人比较友好，也还没有形成强势头部品牌效应。

也就是说，这是一个尚有空白、且相对容易做出个人 IP 的市场。

2）哪些人适合现在开始做抖音直播（教育）？

① 适合新手当作副业选项之一。目前项目仍有入场空间，不需要自己拥有后端课程，只要认真准备话术和直播，起号不会太难。

② 愿意在抖音做知识类内容直播，或者对抖音直播、知识付费感兴趣的朋友，这个方向值得一试。

而且，如果直播流量能够稳定增长，引流课转化效果也不错，后续还可以朝升学规划师方向发展，把它做成长期的个人主业项目。

不过，项目虽有入场空间，也有一些限制，开始操作前最好了解清楚：

① 这是高中升学的细分赛道，需要学习不少升学相关专业知识。如果你有高中以上学历，掌握这些知识会更容易。

② 抖音直播起号阶段，直播稳定性很重要。建议每天能留出 1—2 小时以上用于直播和做项目，这样更容易跑通。

建议你做好持续学习专业知识的准备，不断精进直播内容，在一次又一次直播和复盘中熟练直播技能。

先当好学生，再当好老师，最后才当好主播。对新手来说，周期可能会长一些，但每个节点都能直观感受到自己的成长。

## 1.1 抖音教育直播的市场空间有多大？

抖音日活用户已达到 7 个亿，全球有 32 亿人在刷抖音。这意味着每天都有大量用户在使用抖音，流量大，商业空间自然大。

而《2022 教育行业研究白皮书》显示，抖音知识直播的看播时长增长了 165%，且超过 55% 的抖音教育兴趣用户有相关购买行为，其中小课包占比最高。可见这个赛道需求空间之大。

抖音教育直播，通俗讲就是在直播间讲解课程知识，吸引有学习相关知识需求的人群，再通过直播挂车售卖课程相关课程或图书产品。像我们在抖音上刷到的学而思、高途、网易有道等教育机构直播，以及一些升学规划、成长规划老师账号，都是这样的直播间形式。

那么作为个人，我们怎么通过这个项目赚到钱呢？

可以采取【直播间镜头展示专业知识内容，通过手上拿笔划重点】的形式（即下图“手播”），把对应知识点讲明白。

通过这种直播形式吸引目标用户，再和前面提到的教育机构合作，在直播后半段销售知识关联课程或图书产品。比如直播时带机构的低价引流小课，把购买小课的客户线索给到机构，赚取分销佣金。

本次航海，我们主要带大家做升学赛道。升学赛道赚钱机会大不大，值不值得深耕？

先看官方数据：

教育部数据显示，2023 年高考报名人数达到 1291 万人，比去年增加 98 万人，创历史新高。这是竞争空前激烈的一届，同时也是求学过程格外曲折的一届：他们经历了中考延期，高中三年大部分时间都在疫情中度过，与他们同期毕业的高校学生就业困难。

伴随这些背景，“高考志愿规划师”（以下简称“规划师”）成为热门职业。根据我们的采访，今年高考志愿报考的市场人均单价基本已达到 5000 元或以上。根据艾媒咨询今年 6 月 8 日发布的相关报告，2022 年中国高考志愿填报市场付费规模达 8.8 亿元，预计 2023 年高考志愿填报市场付费规模达 9.5 亿元。

至少从官方数据来看，升学赛道是一个逐步增长的蓝海市场。目前整个行业的问题就是规划师严重不足，尤其是暑期高峰期；而一个规划师能服务的学员有限，所以这个赛道天然弱内卷。内容上重服务轻产品，对初入者相对友好，也没有头部品牌效应。

确定整个市场是蓝海市场后，下一步就要看线上能不能做？有没有头部 IP？线上的发力点在哪？

整个升学规划行业都集中在线下市场，自 2012 年逐步向上发展至今，新高考改革可以算是行业的一个爆发点。

线上业务的现状是：只有头部 IP 张雪峰，没有头部机构。张雪峰也是从考研转入升学行业。可见这是一个巨大的空白市场，而且是一个非常好做个人 IP 的市场。

上面也说了，这个行业的交付内容重服务轻产品，内容知识面广。张雪峰的 IP 不管流量多大，他的公司能服务的人数终究有限。这个内容对个性化要求非常高，因此头部 IP 和机构带来的压力很小。从教育行业来说，这是一个可持续做高价续费和转介绍的项目。

目前升学规划行业都集中在线下业务，线上凤毛麟角。再基于内容的属性，线上就大有可为：

个性化＋内容深度，两个因素决定了线上可批量复制，并且可以深耕。足够的深度代表有门槛、可持续；个性化则意味着不同风格的规划师都有自己的受众群体，用户的个性化也给规划师 IP 塑造和变现提供了抓手。

## 1.2 如何做抖音教育直播项目？

### 1.2.1 第一步：把开播前的基础筹备做扎实

别急，别急，在开始第一场直播之前，其实有一系列事项要准备。前期准备充分，后续直播也能更加游刃有余。

在这个阶段，我们需要做的准备有：

1.

直播用的实名抖音账号准备

更建议你用一个没有直播过的抖音账号。直播过的账号有可能已经被系统打上了其他内容标签，想要再洗对标签是有一定难度的。

如果是新号，建议先进行 3—5 天的养号，能让你的抖音账号更加健康。

2.

直播设备准备，包括直播支架和闪光灯等

3.

学习课程专业知识，完成直播话术准备（重点环节）

抖音教育直播间需要靠教育相关的专业知识来吸引目标用户，学习升学考试、所带课程的相关知识至关重要。我们要先做好一个好学生，其次是好老师，最后才是好主播。

### 1.2.2 第二步：起号，突破流量

流量是成交的前提，在项目操作中占据绝对关键位置。要知道，流量是 1，其他都是 0。

因此在刚开始直播时，我们并不需要马上关注是否变现，而是先通过稳定的直播，突破抖音的流量池，让我们的直播间被更多用户看到。

这个环节需要注意：

1.

直播先不要挂车，否则抖音官方容易认为这个账号是一个带货账号，会影响流量突破的速度；

2.

注重互动量、粉丝灯牌、加团转粉等数据的提升。通过一些互动技巧来辅助流量突破。

### 1.2.3 第三步：成交转化

当我们突破了一定的流量池，至少连续两场直播的场观连续两场 1500+ 后，就可以开始挂车带货了。

这里相较于之前突破流量环节的直播，有明显不同的操作有两个：

1.

挂车：1000 粉以上就可以挂小黄车。为了达到这个要求，我们在第二步就需要有一些引导转粉的动作；暂时没达到但想带货转化的小伙伴也不要着急，可以先挂小雪花来带货，等到达 1000 粉后再换成小黄车即可。

2.

话术调整：在直播话术中加入所带产品的信息和转化话术，促使目标用户在直播间完成下单。

## 1.3 🎯引流课包的合作渠道与佣金结算

通常情况下，账号直播起量后，会有商务在抖音主动找过来，也会有一些渠道商（二道贩子）找上门，寻求合作。如果有这样的合作请求，建议提前了解以下主要风险：

1.

渠道商跑路的情况时常发生。如果自己对接，建议直接对接甲方商务；如果是个人直接对接甲方商务，需要有公司主体才可以合作，一般次月结算，不过年底可能结算会慢一些；

2.

自己对接甲方，在引流数量不稳定的情况下，这批流量的后续转化情况也会变得不稳定，有可能出现 ROI 不满足标准、佣金结算单价比较低，甚至没有佣金的情况。

为了避免以上两个风险，航海期间我们也为大家提供了渠道，以下是该渠道的相关信息：

1.

目前我们对接的渠道是高途 19 元课包，有高一、高二、高三 3 个 SKU，都是升学提分引流课，对应不同的用户人群。

2.

大家出的订单会合并到一起来算，这样可以和甲方谈更高一些的佣金价格，且 ROI 的稳定性上有一定保障。当然，每个人的带货链接都是定向的，哪个客资完成转化，都会明确到人。

这里的“客资”，指的是在你的直播间购买了 19 元课包的用户；一个拿到了收货地址和手机号的用户，即为一个有效客资。

“客资完成转化”，指的是这个用户在体验了 19 元课包后，在甲方处购买了后续的高客单课程。

3.

一般单个客资的佣金在 60—100 元不等，保底（即有客资没有后续转化）在 60 元左右。具体实际单价也会根据订单的转化情况（即 ROI）来确定，达到一定转化，佣金会在这个范围内浮动。

4.

我们会在每月月初对账，15 号左右为大家结算上一个月的佣金。

5.

如果选择该渠道，我们会在航海期间提供定向的商品链接，明确每一个引流客资的来源，方便结算。

当然，当你准备挂车时，我们的渠道可以作为其中一个考虑，其他渠道也可以考虑选择。无论是哪个渠道，可以结算的客资一定是真实的目标用户，禁止刷单，否则很容易被判定为无效订单，无法结算。

最终如何合作对接和带货，大家谨慎分析，自行选择即可。
