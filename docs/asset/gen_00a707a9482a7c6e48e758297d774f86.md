# 企业店铺入驻全流程：审核、保证金与品牌资质填写指南

提交完资料后就进入审核环节了，平台通常会在3个工作日内给出结果。如果没通过，会通过电话或邮件通知你；审核期间遇到任何疑问，随时可以找在线客服咨询。

审核一过，接下来就是缴纳店铺保证金。这里要特别留意：开卡账户必须是企业对公账户，而且开户人姓名要和入驻时填写的经营人保持一致。

接着聊聊旗舰店和专卖店的申请流程。整体框架跟普通企业店差别不大，但有四个细节需要留心：

第一，品牌信息怎么填。如果系统里搜不到你的品牌名，点"新增品牌"手动添加就行。上传logo时务必保证图片和商标注册证上的图案完全一致。

[PRE0]

[PRE1]

第二，分清自有品牌还是代理品牌。代理品牌要保证授权链路完整，公司名称直接选营业执照上的名称即可。

[PRE2]

自有品牌指的是商标归自己公司或公司法人所有。注册类型分R标和TM标两种——R标是注册商标，TM标是商标注册申请受理通知书。

假如你的商标属于个人型R标，需要上传商标注册证，外加商标权利人的身份证或护照复印件/扫描件。

[PRE3]

个人型TM标同理，要提供商标注册申请受理通知书，以及权利人的身份证或护照复印件/扫描件。

[PRE4]

如果是企业型R标或TM标，那就简单了，只需要商标注册证或商标受理通知书其中一样。

第三，选售卖品类时要多留个心眼，特别是"定制"类目，谨慎选择。

[PRE5]

第四，审核通过后还有签合同这一步。合同会通过线上邮件发送，用电话或验证码确认签署。

[PRE6]

签完合同同样要缴纳保证金，注意事项和前面普通企业店一样。

再说说集合店。集合店只能通过平台邀约入驻，收到邀约后，流程跟旗舰店、专卖店完全一致。

所有申请都通过之后，就能上传商品正式开店了。你的账号首页会直接展示店铺和商品入口。

[PRE7]

总体来看，企业型店铺的商业权益比个人店铺更丰富，但维护成本也相应更高，大家结合自身实际情况做选择就好。

另外，入驻类目、审核之类搞不清楚的地方，建议第一时间联系"人工服务"咨询，商家客服响应速度挺快，能迅速帮你解决问题。

# 2.1 蓝海品筛选标准⭐

1.

蓝海产品的定义

不管是传统货架电商淘宝，还是兴趣电商小红书，对蓝海的定义就一条：自己干得过的就叫蓝海，自己干不过的就是红海。大家结合自己的情况来判断就行。

蓝海电商一般来说市场容量不会很大，也就是销量不会太猛。所以选品的时候尽量挑高客单、高利润的品来做，利润有保障，做起来也轻松一些。

蓝海电商的产品分为标品和非标品。

标品一般在小红书都有同行参考，好处是做起来容易些，坏处是容易被跟，从蓝海变红海的时间周期很短；

非标品是指小红书上没有同行参考，你就是第一个做这个品的人。非标品的优点是生命周期长，缺点是做起来比较难。

基于这个情况，本次航海主要给大家介绍【小红书电商蓝海标品的打法】，帮助大家尽快拿到正反馈，树立信心，早日步入正轨。

# 2.2 蓝海选品思路

在讲具体方法之前，先梳理一下小红书选品的思路。

选品方法很多，整体来讲不外乎三个大方向：

1、日常多刷小红书站内爆款选品

在小红书卖东西，肯定要了解平台最近哪些品好卖。多刷多看，有条件的也可以通过灰豚看数据、找低分爆款来选品。

不过新手一般不建议直接上工具，平台多刷就够了，还能培养网感。

2、从传统电商平台-淘宝选品（推荐⭐）

也就是从淘宝找合适的品。淘宝的分类页面有目前国内所有主流搜索电商平台里最全面的类目，而且淘宝作为电商平台相对最成熟，也不需要用到任何付费工具。

常用方法有：淘宝分类页面选品、淘宝神店榜选品、淘宝榜单选品、天猫榜单选品。

3、从其他兴趣电商平台-抖音选品

也就是从跟小红书一样靠内容带货的平台找品，目前建议从抖音找合适的产品。

常用方法有：考古加选品法、蝉妈妈选品法、抖音精选联盟的创意中心选品法等。

所以在正式选品前，建议大家先刷至少2小时小红书，对平台当前爆品增加些体感。

# 选品方法二：从其他兴趣电商平台-抖音选品

抖音创意中心是抖音自己的数据统计，实时更新，相比考古加能更快知道新爆款。

其中建议百货等大众品类注重一下【抖音创意中心选品法】。

抖音流量和玩家更多，这类大众品在抖音先爆起来的概率更大。

小红书有时候很慢热，这类大众产品基本都是混剪、素材同质化严重。等到小红书已经爆起来你再去做素材，可选度会很低，所以不如直接在抖音开始爆的时候就搞过来。

我们的爆品如硅胶保湿袜、雪地靴刷子、钢丝抹布等，都是通过抖音创意中心选品法选到的。
