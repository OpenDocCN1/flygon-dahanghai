# 卡了十一个月，年底找到方向

2019年翻到最后一页时，我盘了盘账：三年前离开检察院，手里的积蓄已经快见底。这一年，我在“钱从哪里来”这件事上兜了十一个月的圈子，直到十二月才看见缝隙里透进来的光。

先交代二月的决定：我跟阿里文学那边结束了独家合作。2018年初，我签进它旗下一个应用写拆书稿。凭阅读和码字的手感，我拿到独家约，单篇稿酬六千到九千，属于平台给出的上限档。但好报价没转化成收入，稿子从一八年拖到一九年，最后只落了几万块。根子上，是我不认可这件事。

还没签独家时，我投过稿，也谈过一单：一个月交二十五篇，每篇四千。二十五篇是我故意凑的数，目标十万元。三十一天里，我啃完二十五本书、写出二十五篇，钱确实到手了。可钱一到账，我心里已经不想再干。

外人听到我一个月挣到十万，很容易脑补我全年百万。那个月真实怎么过，只有我知道：交完稿，我随后躺了半个月。那种输出是一次透支式爆发，不能当常态。我算过，即便把这种状态硬撑一年，扣完税也就刚刚越过百万，代价是随时可能倒在工作桌前。有人笑我心大，说百万都嫌少；但纸面上的极限值不等于现实，连理想上限都走不通，就说明这条路本身有问题。

那时我认定：当一只只搬货的工蚁，没前景。拿同一段时间反复换钱，不划算。那些稿子换不来知名度，也换不来明显的能力跃迁，只是纯卖时间。更麻烦的是，读写任务会占满我整块专注带宽，我腾不出心力看外面，也做不了让自己升值的事。

当然，明白归明白，我那时确实没真正拿过大钱。我又磨蹭了半年多，实在找不到治拖延的招，才决定解约。到二月，我承认：如果只剩钱这一个理由，没有别的自我说服，这件事我干不下去。六月，这个结论又验证了一次。

三月我状态很差：刚丢掉一份有收入的工作，新路子却没影，压力堆得很高。身边不少声音让我去求职，我想再顶一阵——先以存款换喘息，再以喘息换空间，以空间换新方向。一个人的当下，是过去认知结出的果。那些劝我的人，他们的当下并不是我想要的，所以我不能照着他们的建议走。我未必知道什么一定对，但照他们的路走，大概率不对。总有一条路能通，只是我还没摸到。

四月十八号，我付费成了龙哥盟的一员。进去先集中刷精华区，眼界被撑开。说实话，我后悔。一七年就在曹大星球见过它，心里动过念头，舍不得几百元；一八年又碰见，价格更高，还是没舍得。拖到一九年，退路少了，我才付款。里面不少东西，正是我苦想很久都找不到门道的。要是早进，可能早把几百倍的会员费挣回来了。为高价值信息付费，回报比多数投入都高；这个道理，十一月我又懂了一遍。

六月，母亲确诊恶性肿瘤，治疗费用像突然撕开的口子。五月末我去了一场圈子的线下见面，轮流介绍自己，认识了一些同圈朋友。一位网名夜息的朋友很厉害，聊过后说也许能合作，约我到南京聊聊。那时母亲在老家被怀疑患癌，正在同济医院等复查结论。我急需钱，任何像收入希望的东西都想攥住。阿里方面的编辑又来找我约稿，我接了；夜息一邀，我当即订了车票。

和夜息沟通很顺。他擅长视频、批量化运营和搜索优化，短板是内容；我刚好能写，别的偏弱。他起初想让我先从法律赛道开始，碰了几轮思路，后来改到备考与考试方向。我考试有一套，也做过几年免费辅导，带人应对高考、研考、法考、公考等大型考试，成绩还过得去。夜息大方，也信任我，待遇给得厚道。我们当场拍定：我先出大纲，对方认可后，再按条目产出内容并录制。

可回家动手做提纲，麻烦来了。我高考是二〇〇四，研考二〇〇八，法考二〇〇九，公考二〇一一，最近一场距今已八年。考试的外壳和内核都翻新了：报名、备考、作答从电脑端挪到手机端，出题偏好、复习路径、辅助工具也换了几轮。若只是我下场考，还能临时适应；可要教人，就会夹带不少未经实战检验的判断，这跟骗人没区别。

犹豫数日，母亲的诊断出来了，我先赶回武汉陪诊，与医生敲定治疗计划。从武汉回来，提纲依旧搁着。我心里不愿做，却又舍不得挣钱窗口。隔了约一月，夜息来催。我还是不愿丢机会，答应再冲一次。我把担忧摊开，他说只做有把握的部分。我给了交稿日期。

重新研究真题后，我依然无法落笔。症结躲不过：新题型我没亲自考过，无法确认方法是否仍管用；旧经验框架可保留，可一展开就会牵出许多细节和新考点。我能稳住的存量，只够讲两小时长视频，撑不起几百条短内容。想了很久，我最终硬着头皮向夜息致歉，坦白无法交付。对方没有再回，合作就此停住。

我自责了挺久：挣钱心切，机会一来就仓促点头，发现不对又没及时刹车。若唯一理由是钱，没有额外信念支撑，我无法长期做自己都不信的事。那回我给自己立规矩：承诺就兑现；情况变化要立刻说明，不能把合作方晾着。人一旦不可靠，任何合作都难持久。

从六月到十月，差不多半年，我仍没找到北。👸号运营数月不见起色，我反而变得心浮，幸亏大黄哥、马哥及时提醒，我才稳住节奏。今日头条、B站、抖音也琢磨过，依旧不得法。我觉得自己还是不太会挣钱。

在龙哥盟读了大量精华内容，学了不少新东西，对挣钱的理解比先前深，可也看见缺口更大。我慢慢摸到：挣钱背后是一套思考方式、一套系统，还有流程和颗粒度。没有这些，机会摆在面前也会漏掉；旁人点破，自己仍不知从哪下手；哪怕有人带着做，处理完一个，后面还有一串。从不会到会，要补的是整条链路，不是案例里那几根钉子。我能做的，只有持续学、动手做、再调整，朝想要的方向挪，等某天把任督二脉打通。

到十一月，账户余粮不多。若再没有进项，我只能去求职，把探索按下暂停。就在这时，局面松动了。

股市先给了回报。我在市场里摸爬几年，长期亏损，如今回看，才知道当初多糊涂：选股、择时这两样本就不是我的天赋，也不该硬求。我的长处是判断人。我找到一位靠谱且实力强的操盘者：朋友的朋友，过往成绩亮眼，投资观我也认同。我把判断权交给他，跟买他看中的标的，拿稳；不贪不慌，赚亏自担。有些事不必用自己的脑力硬解。行家眼界胜我百倍，若人品过关、愿意交底，跟着做远胜自己闭门研究。承认不懂，事情会简单许多。靠这招，年底两波行情里，我先收获约八成涨幅，再拿到约两成半。

可这终究不是长期方案。等本金够了，我还是委托专业人士管理。这个市场不是我的战场，我该回到自己的长处。

十一月下旬，我另外报了一个付费圈子，里面有条新变现路径，落地性很强。其中部分做法踩线，细节我就不展开。既然机会露头，我果断借资加杠杆，十二月几乎连轴转。

月底还有一场龙哥盟曹大闭门会，我到场了。连听七小时，信息量很大。大黄哥谈快手，半佛谈区域税收优惠，这两块我都能马上用，也能发展成盈利线。之前整整一年没靠谱项目，劲没处使；忽然间可做的事一起冒出来，只嫌日程塞不下。那种状态让人太开心。

二〇二〇年，我准备先让能快速回款的项目跑顺，争取进账三十至五十万。有余力就早点做快手；区域税收这条线，可能排到二〇二一年。只要知道世上存在这类窗口，迟早能找到切口；这条走不通，还有下一条。

这些说到底只是变现手段。我不想让它们占满全部精力，只想靠它们换来收入，再去供养真正想做、眼下还不挣钱的事。我骨子里爱的仍是阅读和写作；自我成长、影响别人，都能让我真心高兴。只是这块还欠火候：既没找到巧妙的变现方式，也没积累到能自然变现的程度。两样都靠时间，而我挣钱，就是为了买回时间。

偶尔也信一点天意：仿佛上天鼓励我继续试，每当账上快空，就递来一次续命机会。

往后还会继续摸索，等某天走出一条合脚的路，能愉快地挣钱，按自己喜欢的方式过日子。

谢谢龙哥盟。在这里结识不少良师益友，也得到许多珍贵信息与经验。评论区为我加油的朋友，一并感谢。

新一年，我仍会使劲。慢点没关系，路远也总会走到。
