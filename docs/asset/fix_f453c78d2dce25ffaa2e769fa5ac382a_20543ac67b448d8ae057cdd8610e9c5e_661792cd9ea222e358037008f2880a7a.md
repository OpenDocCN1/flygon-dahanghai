# 私域从1到100：规模怎么真正做大

各位好，我是郭威。我的主战场是母婴与大健康私域，目前一线销售五百多人，后台支撑五十多人，零售端一年流水过亿。

私域想要长期赚钱，管理是根基。团队跑通0-1之后，1-10、10-100怎么扩，是很多操盘手绕不过去的坎。

0-1阶段，关键是把团队模型跑顺：流量花费、人员开支、杂项支出都要算清，利润空间才能拉起来。到了1-10，就要贴业务实际去立规矩、做筛选和优化，比如把带人流程和业务运转流程都做成可复制的标准模板。

下面我分两块讲：一是跑通0-1后怎样少交学费，二是1-10、10-100怎样把盘子做大。希望能给做私域管理的朋友一点参考。

一、我的经历

我人在湖北武汉。2013年毕业就开始折腾，SEO、淘宝、淘客、竞价单页都碰过；2014年集中做竞价加单页，再结合QQ运营。2015年转直营，做过大健康保健品、护肤品等七八个细分方向。2017年队伍五十人上下，单日投放十万以上，年营收约三四千万。年底因政策变化，原项目停掉、人员裁撤，转去更合规的赛道继续直营，先后投产两家食品加工厂，做特殊膳食营养补充剂、片剂、膏剂、固体饮料等功能性保健食品，厂房合计万平。

二、私域经营的基本盘

我的判断是：在公域里抢流量，私域屯粉的稳定性与持久性更好，价值也大，所以我们一直在这块深耕。手里有客户、有流量的朋友，精准客户能囤就多囤，先把0-1做扎实；还没动手的，尽快开始；已经在囤的，只要获客成本扛得住，就放大力度去囤。

（1）赛道选择很要命。同样的时间和精力，换一个行业，结果可能天差地别。判断赛道，可以看流量好不好拿、流量值不值钱。有的赛道单粉成本三五百也能做，重点不是死盯成本，而是看客户价值和流量能否稳定获取。比如我们工厂客户，三五百的获客成本可以接受，那就猛上1688店群、超级工厂等渠道，成本在承受范围内就大胆干。

（2）选品盯两件事：毛利要高、复购要强。毛利不够高，客单价足够高也能成立。若是一锤子买卖，就围绕这批客户继续挖需求，提供更多产品和服务，把客户价值做深。

（3）微信囤积。前期先做微创新，流量便宜或利润尚可时，要敢于大量囤资源。资源就是钱。资源在手，后面再逐步挖需求也来得及。小团队多加同行、多看同行，先复制再微创新；等团队有规模了，再结合项目组建文案、策划、供应链等专职服务团队。

三、团队放大的三个杠杆与标准化

0-1拼的是赛道判断和执行力，多看同行标杆。今天分享有个前提：流量得自己能解决。我一直认为，私域做大的瓶颈在流量，流量有多大，队伍才可能有多大；其余问题相对可以在内部消化。

1-10这段，我在2014到2016年踩过坑：当时社群少、交流少，埋头干活，也没受过系统训练。现在有分享平台能学东西，比当年少走很多弯路。

团队放大的过程，本质是加杠杆。我常用三个杠杆：信息差、人才资源、资本资源。

最直接的是信息差。0-1靠它，1-10也靠它，资源差同样重要。把信息差放一边，0-1跨出去的关键是人。个人时间精力有上限，要尽早学会花钱买时间、买方案、买结果。先算账：如果请人做，投入产出比如何。自己单干月利润只有三千，那只能先请兼职；兼职花一千、自己留两千，十个兼职就是两万。若自己干能有两万利润，花五六千请十个人，理想状态利润能到十万以上。这只是类比，管理、财务控制都有要求，但完全靠自己，天花板一定有限。

这就是人才资本。第一步是大量面试、持续招人。花钱买结果，在人身上敢投入。人进来后给时间周期，初期算单人投产，该断就断：有利润或未来能产生利润的留下，没利润甚至拖后腿的及时清理，持续筛人，把人均利润抬上去。这个阶段是在打团队模型，对个人是1-10，对团队其实也是0-1。通过反复优化人和项目细节，让人均产出往上走；到后面，有些能赚钱的人也可能被换掉，因为产出比仍不够，资源有限，要把资源放到更能出结果的地方。

最后是资本资源。不少人模型很好，却卡在现金流：广告费、账期一压，团队没及时放大。尤其是模型跑顺、流量渠道又优质便宜时，因为现金周转没跟上规模。这时就要动用资本资源，自己先想办法拆借、协调资金。若项目模型过硬，也可以找投资方，开放心态看这件事，资金永远在找好项目。以资金为前提，找能给项目赋能的团队来投，效果更好，也能少走弯路、及时放大。

很多项目都有红利窗口和周期，抓住时机很关键。0-1、1-10相对简单：模型OK、流量需求不夸张、舍得花钱就行。到10-100，就得具备后台支撑能力，在两条线上做机制：一是带人流程的规范模板（SOP），二是业务运转的规范模板。

带人SOP，从入职、培训到进一线销售队伍，学什么、练什么、成长路径怎么走，不同阶段的内容要跟着团队情况持续调整。这段话看着轻，做起来很重，但每个团队放大都要过这一关，看似投入大，回报更大。

业务运转的规范模板，说白就是把要做的事合理拆开，专人负责，常态推进，也就是把后台支撑搭起来。上面一条管人，一条管事，缺一条都不行，合起来威力很大。

私域标准化，重点说几块：

（1）销售动作标准化：客户加进微信后，主要从三到四个板块做营销——朋友圈、群（有的项目没有）、私聊跟进、客户的朋友圈。所谓标准，就是新人进来照基础动作做，也能拿到保底数据。核心是：做不到就淘汰、洗人。举例：未成交客户、不同意向客户、已成交客户、已知高净值客户等标签要统一设计，不同类型客户用不同维护标准，朋友圈内容也要针对性区分。私聊这块，从进粉打招呼，到人设背书、产品背书，公司都要提前设计好；怎么报价、怎么逼单也要有流程。团队放量时，不能让普通员工自由发挥，先模仿再超越，慢慢让一部分优秀的人试新方法，再把好方法提炼成模板标准。公司负责设计流程、准备工具，培训员工按规范执行，并结合实际及时复盘、调整标准内容。

（2）员工培训标准化：从入职、培训到成长计划，进销售队伍后的前中期学习内容、考核内容、淘汰标准，都提前做流程设计，并与前面的营销要求对齐。

（3）还有一个核心：按资源总量做分配，保护强者。人均成本、人均产出要算清楚，再根据产出比优化资源分配和人才筛选。

团队再往上走，说到底就是分蛋糕。独行快、众行远，把利润分好，才能让优秀的人愿意长期干。利润分配永远给能持续提供价值的人，本质是价值交换。私域核心人员常常是一线销售负责人；走到10-100，就要把公司平台化。

四、利润分配思路

仅供参考：按团队独立核算，销售核心负责人可分自己团队利润的一部分；也可以定目标分红，不同目标、不同阶段给不同比例。比较独立自主的，可以前期直接固定一个比例份额。结合后台支撑，把销售和后台分开核算。分红、虚拟股权、实股、超额分红等玩法很多。具体还得看项目模型，我们团队也有不少要优化的地方。核心原则是：价值越大，越要逐步放利，以增量利益分配为主。

回顾一下：0-1重点是模型，算清流量成本、人工成本、其他成本和利润产出。1-10结合业务做标准化，批量上人，筛选优化。最后公司平台化，拆分业务单元，设计合伙人体系放大。
