# AI当笔，你当脑：内容创作实操手册

AI在写作这件事上有几处绕不过去的短板：独到的原创判断、最新的行业一手数据、带着个人体温的情绪表达，以及层层嵌套的因果推演——这些它都接不住。更聪明的分工是：观点和洞察由你出，搭骨架、磨措辞、顺逻辑这类活儿交给它。

# 原则五：把“提示词工程”练成手上功夫

你写下的那几行字，几乎直接决定了它交出来的东西是什么水准。这门手艺值得反复练。

一条好提示词，四块料不能少：

1. 任务说清楚：写什么、给谁读、要什么效果；
2. 背景补齐全：行业情况、读者画像、投放渠道；
3. 边界划明白：文风、篇幅、格式；
4. 结构给方向：框架思路、段落铺排、视觉呈现。

一句话公式：基础指令 + 背景上下文 + 约束条件 + 结构引导 = 高质量输出

# 原则六：让AI“入戏”，专业感立刻不同

给它安一个具体身份，出来的内容专业度和可信度都会往上走一截。

怎么用：

+ 让它以某领域老手自居，比如“你是有二十年从业经验的营养学专家”；
+ 一次请出几位不同背景的专家，观点自然多元；
+ 再挂上成熟的分析工具，例如“用SWOT模型拆一遍”。

角色模板可以这样写：

请你以[专业角色]的身份，借助[分析框架]，就[问题/主题]展开分析。行文需体现[专业特征]，同时兼顾[受众诉求]。

# 原则七：把大任务拆成“指令楼梯”

[PRE0]

复杂创作别一口气丢过去，分层下指令，每个环节才不会被草草带过。

三层怎么分：

1. 战略层——总目标、核心定位、关键成果；
2. 战术层——内容架构、论点顺序、表达策略；
3. 执行层——具体用词、句式变化、修辞手法。

落地做法：战略层先要个框架，战术层把结构补厚，执行层再抠字句。

# 原则八：攒一个自己的“提示词仓库”

[PRE1]

用过一段时间，就该有意识地把好用的提示词存下来、反复迭代，慢慢长成你专属的写作系统。

仓库里放这几类：

+ 常见稿件类型的模板；
+ 针对不同平台的风格说明；
+ 润色优化专用的指令；
+ 成功案例的完整记录。

进阶路线：从通用模板起步 → 按需调整 → 记录实际效果 → 提炼规律 → 沉淀成个人提示词库。

这套手册用下来，希望你能真把AI这个创作搭子用出价值，一点点垒起自己的内容护城河。

最要紧的一句：AI放大的是你的创意，代替不了你的创造力。这些方法熟了，省下的时间就能投进真正的思考里，让内容创作回到它本来的样子——连接、影响、启发。

# 4.2 让AI帮你画图

# 4.2.1 动手前先弄明白的几件事

所谓提示词，就是一小段话、一句自然语言描述，你把它交给AI，它照着画出来。操作本身并不难。

正式开工前，有几个点先过一遍。

写提示词时的注意事项：

1. 凡是你在意的背景和细节，尽量写进去；
2. 眼睛盯着“想要什么”，别老写“不要什么”；
3. 碰上AI听不懂的专有名词，换成大白话解释一遍。

通用公式：

# 💡

Subject + Style + Setting + Composition + Lighting + Additional Info

对应中文：主题 + 风格 + 环境 + 构图 + 光照 + 附加信息

（打头的三项最要紧）

+ 风格：你想要的画风或年代感。
+ 主题：画面中心是什么——人、物还是动物，长什么样、什么颜色、有什么特别之处。
+ 环境：在哪儿（室内、室外还是虚构空间）、周围有什么（自然景物或城市街景）、什么时间、什么天气。
+ 构图：从什么视角看（特写、广角、航拍）、什么角度、怎么取景。
+ 光照：光线是亮是暗还是自然光，情绪是愉快还是神秘，要不要氛围效果。
+ 附加信息：次要角色、其他动物或物件，它们和主体怎么互动、站在哪个位置。

# 4.2.2 给文章配图

# 4.2.2.1 怎么操作

Step 1：开工前的准备

进入即梦AI官网，或下载它的APP（https://jimeng.jianying.com）
完成账号注册与登录（手机号、微信等都能用）
看一眼账户里的绘图点数够不够（新用户一般有赠送，也可以开会员或充值）

Step 2：认清界面和参数

界面分两块：左边输入提示词，右边看生成结果
几个关键参数要认识：

画面比例：1:1、3:4、4:3、9:16、16:9等都有
生成数量：一次1到4张
模型选择：按想要的风格挑
采样方法：影响成图的细腻程度和风格走向

Step 3：提示词的写法

按“风格+主体+背景”的顺序搭起来
风格可以写：水彩、插画、浮世绘、赛博朋克……
主体尽量具体：长什么样、在做什么、穿什么
背景补足：场景、时间、光线、气氛

Step 4：真正配一张图

进入即梦AI，点“图像生成”
按文章内容定下配图主题与风格
挑一个合适的比例（文章配图一般用16:9或3:4）
把想好的提示词填进去，比如：

# 💡

水彩风格,一只橙色猫咪坐在咖啡店窗边,阳光透过窗户洒在桌面上,桌上有一本打开的书和一杯冒着热气的咖啡,温馨氛围,高清细节

按下生成键，等它出图，通常半分钟以内

[PRE4]

Step 5：挑图与微调

几版结果里选一张最合心意的
用即梦的编辑工具做微调：

局部重绘：把不满意的局部修掉
改提示词：让某些元素更突出或更收敛
放大：把分辨率提上去

调舒服了，以PNG或JPG格式存下来

[PRE5]

Step 6：放进文章里

先把图下载到本地
按平台要求改尺寸（系统自带工具或在线编辑器都行）
传进文章编辑器
配一句合适的图注或小标题
再核一遍：这张图和内容对得上吗

进阶玩法

好用的提示词别丢，存进自己的库，下次直接调
要给长文配一系列图，就批量生成，保持风格统一

“文字周围有光晕效果”

“文字在半透明白色背景上”

1. 整张海报过一遍：内容全不全、准不准
2. 字不理想，就把字体样式在提示词里写得更细

4. 想更清晰，用即梦的高清修复功能提一提

# 4.2.4 做个人IP形象

# 4.2.4.1 怎么操作

Step 1：开工前的准备

1. 想清定位

这个IP落在哪个领域（美妆、财经、教育、美食……）
面向谁（年龄、性别、兴趣）
你身上有什么特质值得放大（专业、幽默、温暖、前卫……）

2. 攒参考

看同领域做得好的IP长什么样（多数走写实路线）
准备几张自己的照片，方便参考五官
收藏一些你喜欢的人像摄影风格

Step 2：搞定账号，摸熟工具（流程同上）

3. 进入官网或下载APP
4. 完成注册与登录（手机号、微信、邮箱都行）
5. 了解账户额度（新用户一般有赠送，也可开会员）
6. 逛一圈功能区，重点是“图像生成”

Step 3：先把形象设计想好

7. 风格定下来（以写实为主）

首选：摄影写实风格，最适合做专业IP
风格描述写具体，比如“专业人像摄影风格”“高清商业人像风格”

8. 形象特征列清单

性别、年龄段、体型
发型、面部特征（这些要保持一致）
服装风格、配色（贴合行业气质）
记忆点（眼镜、发型等一眼能认出的元素）

9. 环境和光线也先规划

背景选什么（纯色，或虚化的职业场景）
光线类型（自然光、影棚光、侧光……）

Step 4：先出一张底图

10. 进入即梦AI，点“图像生成”
11. 模型选“图片2.0”

[PRE15]

12. 导入参考图
13. 参考项选“人物长相”，点保存

[PRE16]

14. 比例选1:1或3:4，适合做头像
15. 写一段详细的写实提示词，例如：

专业人像摄影风格，35岁亚洲女性，肩长黑发，自然专业妆容，戴黑框眼镜，穿深蓝色西装配白衬衫，表情自信专业，微微微笑，半身构图，柔和工作室灯光，浅灰色纯色背景，画面清晰锐利，高品质人像效果

16. 按下生成键，等十几二十秒
17. 多张结果里挑最接近理想的那张

另外记住：把这组成功的提示词存下来，当作后续的底模板

Step 5：让形象保持统一

1. 在底模板上迭代

年龄、性别、发型这些核心描述不动
摄影风格描述不动（保证一致性）
光线和背景描述不动

2. 用变体功能换表情（如果有）

核心不动，只调表情那一句
比如“表情自信专业”换成“表情温和亲切”

3. 验收一致性

不同表情、不同场景下，还能认出是同一个人吗
不满意就继续调提示词

进阶技巧

4. 写实风格怎么写

用摄影术语：“人像摄影”“商业人像”“自然光人像”
光线写细：“侧光”“蝴蝶光”“轮廓光”
设备也能提：“类似85mm人像镜头效果”“浅景深效果”

5. 一致性三条优先级

第一：人物特征一致（发型、脸型、记忆点）
第二：摄影风格一致（色调、光线、质感）
第三：背景处理方式一致（场景可换，手法相近）

6. 迭代方法

完整记录每次成功的提示词
只改需要变的那部分，其余照抄
新图出来，和基础形象并排比一比
