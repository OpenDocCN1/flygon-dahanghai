# 5.1 Windows 端本地安装

本地部署的好处是：能够自己安装缺失的节点，随意使用各种模型，也能直接读取本地文件夹。
本地部署的不足是：必须准备性能较好的独立显卡，还要手动安装 ComfyUI、模型和节点。

ComfyUI 的安装包总共四种，选择其中一种即可，官方版和整合版两大类。

想要省事，推荐官方桌面版（105M），它会自动下载模型和第三方节点。
硬盘比较小，就用官方纯净版（1.46G），不含任何模型和第三方节点。
硬盘中等容量，可以选 Liblib 整合版（2.84G），已经集成部分模型和第三方节点。
硬盘足够大，直接下载秋叶整合版（3.7G），里面整合了大量模型、第三方节点以及工作流。

# 5.1.1 硬件配置要求

- 系统：建议 Windows 10 或 Windows 11；Mac 系统不推荐本地安装 ComfyUI。
- 内存：最低 6G，建议 8G 或 16G。
- 显卡：显存 4G 以上，最低要求 10 系列 Nvidia 独立显卡，更推荐 30/40 系列 Nvidia 独显。
- 显卡品牌排序：N 卡 > A 卡 > I 卡，N 卡（英伟达）效果最佳，A 卡（AMD）次之，I 卡（Intel）支持较不理想。
- 硬盘：至少需要 100G 可用空间，容量越大越好。
- 电源：最低 400～600 瓦左右。
- CPU 和主板：没有特殊要求。
