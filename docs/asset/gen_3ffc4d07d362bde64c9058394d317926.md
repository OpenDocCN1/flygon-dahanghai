# 五、拓展玩法：批量混剪怎么学、怎么用

掌握初阶和进阶剪辑后，短视频制作的基本路径你已经很熟悉了。但如果你运营的是多账号矩阵，需要持续不断地产出视频，这时就得靠「批量混剪」来提升效率。

所谓批量混剪，简单说就是在混剪的基础上加入批量化的生产流程，一次处理大量素材，批量得到成片。正式动手之前，先理解混剪的逻辑很重要，建议先读一读《剪辑基础决定上层建筑，了解混剪逻辑和去重设计》。
