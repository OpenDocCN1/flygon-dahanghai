# 3.2.1.4 同城号起号，6个细节别漏 @大芽

想把同城号做起来，拍摄只是其中一环。下面这六件事，发布前后都值得逐一对照。

1. 单条内容只突出一个卖点

拍视频时，别把全部优势一次性塞进同一条内容里，一条只讲一个亮点就够了。介绍产品或卖点时，用大白话、贴近日常的说法，别堆“生而强悍”这类空泛形容词。只讲一个点，用户才容易记住；信息绕来绕去，反而留不下印象。

2. 发之前挂好 POI 定位

新号起步，地标要带。门店若还没录入地址，可以借周边小区、酒店等位置。我最初挂的就是离店约五百米的一家酒店，也没问题。定位挂上，系统才更容易把内容推给附近的人。

3. 背景音乐要选对热门

音乐和话题同样关键，这靠平时攒下的网感。刷自己账号视频时，把重点音乐标出来；如果某段时间同一 BGM 反复出现，大概率正热，点进去看看使用人数，几十万人用就试试。我发第一条视频就靠这招选到上升期 BGM，之后一直用；长期用同一 BGM，也能成为用户的记忆点。

4. 本地话题别落下

做同城号，当地话题肯定要带。我在惠州做餐饮，视频通常挂 #惠州 #惠州美食。

5. 标题里放个问题

比如“能想象出来是什么样的吗？”“大家知道惠州哪里有冻品市场吗”“我们要招人啦，大家要来吗”。评论区很明显，只要提问，用户就愿意来留言；互动数据变好，推荐也会更多。

6. 发完要经营评论区

前期评论尽量逐条回复，多和用户交流，才更容易把顾客引到店。个别视频会适当投 Dou+，但账号到现在只花了 250 元；投过的基本都有几万播放，而十几万播放的视频全靠自然流量，没有投 Dou+。Dou+ 只是锦上添花，内容才是核心，互动数据好，系统照样会给推荐。
