# 9.9元“九连环”，一条短视频竟赚了30万？

最近刷到一个很猛的带货案例：有人在抖音发了一条玩九连环的短视频，直接把这款益智小玩具卖爆了，销量冲到9W+。客单价只有9.9元，但每单佣金接近4元，这么一算，光靠这一条视频就已经入账30多万，而且数据还在持续跑，收益似乎没有停下来的意思。

这个选品思路，放到小红书店铺上也很有搞头。评论区里大家也有不少讨论：有人觉得是付费投流的效果，要看千川烧了多少；也有人提醒，益智玩具容易踩专利侵权的坑，建议找那种已经过了专利保护期的经典款；还有人好奇这个销量到底是整个链接的总销量，还是单条视频带出来的，结果有人回复——就是这条视频的销量。
