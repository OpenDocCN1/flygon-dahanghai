# 6.4 玩法四：1V1陪跑，把学员带上岸 @劲猫

如果你已经在某个领域做出过成绩，并且愿意给新手一些切实的指导，1V1陪跑是一条值得尝试的路。这个玩法不仅能让别人受益，等你跑通整个流程、验证了方法论，还能为后续做课程变现埋下伏笔。

劲猫就是靠着这套玩法，在3个月内从零赚到了5万元。他最初把价格定为999元，陪跑周期设定为180天，目标很明确：帮学员运营出一个能真正变现的账号。当时没有复杂的权益说明，也没有现成课程，他用的是最朴素的笨办法——先帮学员确定账号方向，再优化主页的整体形象，接下来逐篇跟进笔记的选题和修改。可以说，差不多是替学员把账号做起来了。

辛苦归辛苦，反馈却很直接：减肥主题的学员，两个月涨粉1万；育儿主题的学员，一个月涨粉6000，变现接近1万；同城摄影服务方向的学员，业绩做到了20万。看到这些结果，劲猫对小红书的逻辑更加笃定。

之后，他拿出两个月时间，把个人做号和带学员的经验整理成一门课程。有了课程加持，陪跑价格水涨船高，现在已是3899元。再叠加账号诊断、课程与陪跑这套组合，三个月时间，他的收入从0做到了5万元。

内容来源：《自媒体新手做小红书 3 个月，从 0 涨粉 8000 粉，变现 5 万》
