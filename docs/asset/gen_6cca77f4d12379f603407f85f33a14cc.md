# 12.5.2 关于DAO的几点再思考

除了前面提到的案例，还有各种围绕特定问题或兴趣建立的DAO。说到底，Web3里的任何组织形式都可以自称DAO，甚至各国的政府，理论上也能变成DAO。DAO是Web3建设的重要基石。

各类组织的机制，大多不是一开始就完美，而是在实践中逐步迭代，商业组织尤其如此。公司从小到大的过程，本来就伴随着机制升级。很多公司创业初期是老板一个人拍板；规模变大后，才开始搭组织架构、沉淀组织能力，这时组织才可能慢慢走向去中心化。上一章提到的Axie、StepN等热门链游，白皮书里也写过：社区运转初期由项目团队主导，等项目逐步平稳，再把项目所有权全部转交给社区。

这里留一道思考题：一个商业组织，是一上来就去中心化更好，还是从中心化过渡到去中心化更好？又或者一直中心化更好？

进入这个赛道，就要去感受它、了解它、多方参与它。无论最后你的结论是庞氏骗局还是财富机会，只有参与过，你对赛道的判断才更有说服力。不能什么都没参与，就说这个赛道是骗局、这个项目是垃圾，这种论断不负责任。当你在行业里有了反馈，不管是正向赚钱还是负向亏钱，这时候你才算真正进了行业的大门。
