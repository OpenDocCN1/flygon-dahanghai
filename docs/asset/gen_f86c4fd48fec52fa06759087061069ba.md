# 一、社群到底指什么？

很多人一听到“社群”，第一反应就是微信群、论坛或者粉丝聚集地。但把人拉进同一个群，并不等于就有了社群。

真正意义上的社群，是一群人因为共同的目标、兴趣或价值认同走到一起，在一定的规则和互动中形成持续连接，并对这个群体产生归属感。它可以在线上，也可以在线下；可以是几十人的小圈子，也可以是规模更大的组织。

判断一个群体能不能称为社群，关键不看人数，也不看平台，而看成员之间有没有稳定的交流、共同的认同，以及愿意遵守的基本共识。如果一个群只剩广告、沉默和陌生感，那它更像一个联系人列表，而不是社群。

简单说，社群不是“把人聚在一起”这么简单，而是让一群人因为共同的东西，真正连接起来。
