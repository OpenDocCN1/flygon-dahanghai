# 从神话巨人到电子大脑

在克里特岛流通过的古银币上，刻着一位神话机械巨人——塔洛斯。它常被看作“智能造物”最早的图像雏形。把有灵性的机器写进故事，是古人由来已久的习惯：玛丽·雪莱的《弗兰肯斯坦》、卡雷尔·恰佩克的《R.U.R.》都属此列[16][17]。这些虚构角色所遭遇的困境，与当下AI伦理讨论的议题几乎重合[18]。

至于“形式推理”能否交给机器，哲学家和数学家很早便开始琢磨。数理逻辑日益成熟，最终催生出图灵的计算理论——机器只要对“0”“1”这类极简符号做变换，就足以模仿任何可设想的数学推演。数字计算机能够模拟一切形式推理过程，这一判断后来被称为丘奇-图灵论题[19]。几乎同一时期，神经生物学、信息论、控制论也接连取得突破，几股力量汇合，让研究者开始认真设想“电子大脑”的可能[20]。如今学界公认的AI开山之作，是1943年麦卡洛克与皮茨为图灵提交的“人工神经元”形式化设计[21]。

时间来到1950年代，实现机器智能的道路分出两支。一支是符号AI，又叫GOFAI：先让计算机为世界建立一套符号表示，再让系统在此基础上推理，纽厄尔、赫伯特·西蒙、明斯基是主要旗手。与它关系密切的“启发式搜索”，则把智能视为在可能性空间中探寻出路的过程。
