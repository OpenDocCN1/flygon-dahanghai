# 2.2 开干前，软件和账号先配齐 @老瞿 Qu @小嵩

前期要备好的应用和网站包括：闲鱼、孔夫子网（优先）、淘宝、拼多多、淘特等。

平台优先级建议这样排：孔夫子网第一，淘宝第二，拼多多最后。拼多多盗版书偏多，而且会向用户发送消息；淘宝近期也会推送含价格的信息，这对项目运营并不友好。

闲鱼当前风控偏紧，尽量做到一部手机只登一个号。若要备二手设备，可直接在闲鱼找两百元上下的红米 7/8，或配置相当的机型。

闲鱼号关联的支付宝，必须与执照持有人一致。

一张出版物许可证能够支撑三个闲鱼号开店，每店绑定一个支付宝；同一身份证最多可注册三个支付宝。所以，全程只用本人资料操作时，办一张出版物许可证就够了，无需重复申请。

还要守住“一店一机”：若拿一部手机频繁切换闲鱼号，账号极易出现异常，而异常后闲鱼币将无法使用。为稳妥起见，还是一部手机固定一个号。
