关于人群定向的误区，这里值得展开说说。如果你是卖珠宝的，直接圈珠宝类目，覆盖到的多半已有珠宝购买经验，想在视频号这个新盘子里收割这些人并不容易。更聪明的做法，是把目光投向知识付费或高档家居的人群，他们有购买意向但还没真正下单，这类“准客户”反而更好转化。

人群定向里还有两个特殊选项：一个是锁定竞品直播间的粉丝，圈出他们的受众来投放；另一个是粉丝群定向，最多能选10个微信群，把广告打给群里的人。当然，前提是你的主播承接力要强过竞品主播，否则人拉来了也留不住。

# 【加热时长怎么选】

可选档位有0.5、1、1.5、2、2.5、3、3.5、4、4.5、5、5.5、6、12、14小时。关键要搞清楚：投放时长不等于直播时长。投放时长决定的是流量进场的速度和预算消耗速度。根据过往经验，投放时长越长，整体效果越好，这也是为什么大家常说，要用拉长投放时长来提升整体ROI。

# 7.3.5 直播间投放注意事项

1. 在整个直播项目里，投放只是锦上添花的放大器，人货场才是扭转乾坤的关键。人货场跑通之后，投放才能放大效果；脱离人货场，再厉害的投手也投不出好成绩。

2. 投放不是出价越高就烧得越快、越容易抢量。合适的出价+合适的人货场，才能把ROI做到最大。

# 7.4 【附】视频号投放赔付规则

投放赔付也叫成本保障计划，是平台为了帮商家控制加热成本而设的保障机制。平台会按照你的加热目标，确保加热成本不会过分超出预期。

当总实际消耗微信豆/总预期消耗微信豆 > 120% 时，平台会以成本保障流量券的形式，返还超出总预期消耗的部分。返还上限为总预期消耗的2倍，且不超过下单金额。

# 7.4.1 赔付三大关键因素

实际消耗微信豆要大于预期消耗微信豆的120%。预期消耗=目标出价×转化数，所以出价会影响赔付概率和赔付金额。赔付金额=实际消耗额-预期消耗额，但不超过预期消耗的2倍，且最高不超过订单下单金额。

实际转化数要大于等于标值，且上限有一定范围。不同目标的标值不同：成交为新增大于3个订单，涨粉为新增大于2个粉丝，互动为新增大于6条评论，商品点击为新增大于10次点击。上限转化数由出价决定：出价越高，上限转化数越小；出价越低，上限转化数越大。

实际加热时长要大于等于1小时。有效直播一般要2小时以上，投放时长通常超过1小时，太短基本投不出效果。

# 7.4.2 卡赔付的逻辑及关键技巧点

卡赔付的逻辑，是通过控制转化数落在某个区间，让计划满足平台赔付条件，从而获得赔付。

计划首先要跑出量，有一定消耗；其次要控制转化数，下限要达标（比如成交至少3单）。上限则看出价，让实际消耗/预期消耗的比率超过120%，就能触发赔付。在消耗额恒定的情况下，转化数越少，赔付越多。

那么，有哪些关键技巧？

1）转化数要控制在一定区间

不同投放目标的要求不同。以成交为例，订单数至少要3单。上限阀值用公式算：上限阀值<实际消耗额/（出价×120%）。

举例：投成交，出价500，实际消耗12000，订单数在3-20单区间就能获赔。如果出价300，订单数区间就在3-33单。出价不同，即便转化数相同，赔付金额也不一样。其他目标同理，把转化数换成对应目标数据即可。

2）卡赔付的小技巧+MM188166M（李李）长期更新

如果计划里转化数不足，怎么补？投成交的计划，可以在直播间放低价福利品促单；投互动的，就引导观众发评论；投涨粉的，就引导加关注。目标变了，动作跟着换就行。

投放计划的支付金额越大，赔付概率越大。因为按赔付规则，消耗越多才越可能获赔。而且现在大额计划更容易抢到量、更容易消耗出去。同等出价和转化数下，消耗金额越大，赔付概率越大。所以不必建一堆小额计划，直接建几条大额计划，赔付概率更高。

投放目标出价越低，赔付金额可能越大，转化数区间也会更广。赔付金额=实际消耗-预估消耗，预估消耗=出价×转化数。转化数和实际消耗相同的情况下，出价越低，赔付金额越大。相应地，低出价时，可获赔的转化数区间也更宽。

卡赔付在某种程度上能有效提升ROI。比如消耗1000、成交2000，ROI是2；如果赔付了600，ROI就变成5，提升了2.5倍。但如果直播间承接力很强，强行卡赔付反而坏事。因为转化数被卡在区间内，超过就没赔付了。比如计划本来能转化50单，区间是3-30，你非在30单时中止，后面20单的利润大概率比赔付金额高，得不偿失。所以卡赔付也要看情况，是否要强行中止要综合判断。合理利用卡赔付是一门技术活，得权衡多方面因素。
