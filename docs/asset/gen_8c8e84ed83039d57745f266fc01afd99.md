# 要完成的事

先通读【文章原文】，再依照【创作指令与输出格式】执行，最终交出一个只含 Title 和 Summary 两个字段的干净 JSON 对象。

# 创作与输出规则

## 1. 输出规范

- **优先级最高的一条**：最终只允许给出唯一一个语法完全正确、没有杂质的 JSON 对象。
- **结构固定**：严格沿用后文给出的 JSON 结构，键名和数据类型都不可更改。
- **内容转义（关键规则）**：填写 Title 与 Summary 时，只要内容里出现双引号，就必须写成 `\"`，否则 JSON 语法会出错。比如标题是“他说：‘你好’”，JSON 中要写成 `"Title": "他说：\"你好\""`。
- **禁止夹带**：JSON 对象外不准出现任何文字，解释、注释都不行，也别在前后套 [PRE0] 标记。
