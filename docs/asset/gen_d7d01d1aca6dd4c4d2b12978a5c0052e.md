# 6.2 电脑端上架商品，两种方式任选

在电脑上发布商品时，商家可以借助工具批量搬家，也可以逐条手动上架。

1）用搬家工具批量上架

先进入店铺后台的“服务”，在服务市场里挑一款搬家软件。这类工具通常支持在后台试用，商家可以按自己的需求选择顺手的软件来完成商品迁移。
