# 13.1 头像壁纸还能这样玩

大家对头像和壁纸都不陌生。AI 绘画刚火起来时，已经有不少人靠生成头像壁纸、运营图文账号赚到了收益；如今，这一方向的玩法比早期更丰富。

AI 绘画搭配头像壁纸的长处，和前面提到的其他模式相近，这里就不重复展开。

不过，优点之外也有短板。AI 的算法受数据集与模型限制，产出的图片未必够有创意，艺术感也可能不足；遇到复杂主题和细腻情感时，它往往难以达到人类创作者的水准，作品容易显得平淡，或者表达得不够到位。

版权同样不能忽视。AI 生成内容通常建立在已有数据和模型之上，因此有可能和别人的作品撞车。使用和传播时，需要多一分谨慎，也要注意保护版权。
