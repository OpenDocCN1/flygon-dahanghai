# 9.3 打工入局：Web3 有哪些工作机会？

Web2 的上升空间基本见顶，越来越多朋友开始琢磨：Web3 里到底能做什么工作？

其实 Web3 的门槛常常被外界高估了。站在 Web2 从业者的角度看，现在的 Web3 无论产品体验还是市场体量，都还处于被 Web2 全面压制的状态。但换个角度看，打工这件事，底层能力是通用的，Web2 和 Web3 的岗位要求并没有那么不同。

也因此，Web3 的岗位版图和 Web2 大同小异，依旧离不开投融资、技术研发、产品策划、数据分析、运营推广、设计这些方向。

想找 Web3 工作，信息渠道也很清晰，主要有四条路：

一是目标项目的官网，招聘信息往往最先挂在那里；二是专门的 Web3 招聘网站，信息集中且分类清楚；三是社交媒体上的招聘帖；四是 Web3 领域的猎头，能帮你做更精准的对接。

整体看，从 Web2 转 Web3 并没有想象中那么难，关键是先把通用能力迁移过来，再顺着渠道找到合适的机会。
