# 4款产品撑起500万年销：选品与运营实战笔记

大家好，我是惊涛，做电商已经6年，主战场在天猫和淘宝。2018年以前，我和团队主要卖生日礼物，年销售额大概在千万级。2018年后我离开原团队，现在把重心放在宠物用品和生日礼物上，一年销售额约500万。说实话，今年行情有下滑，估计会掉三成左右，不知道其他淘系同行感受如何。这是我第一次做分享，也希望分享越多，运气越好。

一、选品怎么做？

1. 优先找月销1000单左右的头部产品

我为什么把目标放在这个量级？因为月销1000单，是我踮踮脚能够得着的数字。算一笔账：每天补10单，直通车付费推广10单，自然搜索再卖10单，一个月差不多就是1000单。

落地时，补单这块我一般交给放单主持操作，淘系单笔成本大约10块，补的量按转化率来，贴着行业均值走，不要冒进。

[PRE0]

新品刚上架没有权重，可以直接用全标题搜索进入；一般一周左右开始有权重，就可以改半标题进入；等产品权重完全起来，再补有自然成交的关键词和搜索量更大的关键词。查词路径在生意参谋里的品类—商品360—流量来源。

[PRE1]

直通车推广，我通常选精准关键词和蓝海词。比如卖狗窝，“狗窝”这个词太大，就把它放到生意参谋—市场行情—搜索分析，按30天排序，找出“狗窝可拆洗”这类更精准的词，再放进直通车。蓝海词则是把“狗窝”输入进去，勾选相关选项，按30天排序。

[PRE2]

然后把数据复制到表格里，用搜索人气除以在线商品数，得到蓝海值，再按蓝海值降序排列。

[PRE3]

像超大号拖鞋狗窝、巨型大拖鞋狗窝、洞洞鞋狗窝这类词，搜索人气高、在线商品数少，就很优质，无论放标题还是直通车都合适。把这些词放进直通车，以7天或14天为周期测试，转化好的留下，表现差的删掉。主图也要测，至少达到行业平均，否则质量分上不去。前期只要不亏本，可以不限额去推，先把销量冲上去；后期再以投产比为核心优化，降低表现差的关键词出价，提高优质词出价，慢慢测试。

[PRE4]

有两个坑要避开：第一，前期别碰大词。新品销量和评价都不占优，推大词转化不好，还容易烧钱。第二，如果点击率达不到行业平均，质量得分涨不上去，点击单价就降不下来。所以一旦发现点击率不达标，要及时更换直通车图。

2. 把利润空间留在30%-50%

原因很直接：后期需要靠付费推广拉动免费流量，如果利润率低于30%，推广做起来会比较吃力。留足利润空间，电商不是做慈善，不挣钱是可耻的；人工、水电、房租都是成本。

落地方法上，可以拿着样品去附近找能生产的厂家，最好是小作坊，小批量也能做，直接问“一次做1000个是什么价格”。也可以在阿里巴巴上找厂家，先问1000个的报价，数量别报太少，否则拿不到低价，多问几家。拼多多也可以问，有些产品拼多多和淘宝的差价已经有30%，可以拿样品回来看看质量，质量合适直接从拼多多进货也行。

3. 能找工厂代工，或自己能二次加工

什么叫二次加工？比如前几年做生日礼物时，木刻画就是二次加工产品：我们把木板、木框等材料买回来，自己设计、雕刻。

核心原因是提升竞争门槛。产品需要二次加工，或者对手找不到工厂生产，就能甩开大部分竞争对手。落地时，找附近生产厂家，该画饼就画饼：我们店铺一年销售额500万，现在准备主推这款产品，第一批先做最少的生产量测试，后面效果好，一年可能在1万件左右。核心是体现自己的价值，用最低价格、最少生产量，先拿一批货测试。阿里巴巴、拼多多的操作方式也一样，不再重复。

4. 挑视觉较弱的竞品

柿子挑软的捏，选品也一样：优先找主图、详情页做得比较粗糙的对手。这类店铺和产品，拍摄、运营通常偏弱，我们后期自己拍产品主图和视频，就能把竞争力提上来。比如1和2就是视觉做得较差的，如果是我们，会往图3的方向做。

样品出来后，我会自己拍照、设计详情页和视频，保证视觉上超过对手。我以前一直做摄影和设计，所以全部自己制作。如果你不会，有两条路：一是自己学美工拍摄，自学慢一些，大概3个月能简单制作；二是等后期产品数据好了，直接找人拍摄制作详情页，淘宝上有很多帮设计详情页和主图的，大约500元一个产品。

二、运营怎么做？

1. 上架后适当降价，比对手低5-10元

原因是新品销量不如对手，评价也没对手多，需要给消费者一个买我们的理由，便宜一点最直接。但不建议便宜太多，便宜太多容易扰乱市场，后面市场做乱，大家都挣不到钱。价格有优势后，再通过直通车和人工干预，超过对手单量和坑产，拿到排名。落地时，上架直接把价格设低一点，或者用打折软件打折都可以。

2. 持续优化主图、详情页和直通车

原因是一次就达成月销目标不太现实。刚做一个产品时，对产品市场和对手的了解都不充分，所以必须不断优化。落地时，详情页一般改动不大，重点在主图。做多了会发现，有些产品天生主图点击率高，随便做做就很高；有些产品天生点击率低，怎么做都低。主图优化思路是尽量贴合产品场景，再突出卖点。比如两个美容院毛巾：第一张只是简单放在一起，缺少场景带入；第二张让一个女生躺在床上，一眼就能看出是女士美容院用的，目标客户肯定更愿意点第二张。其次要突出卖点，有的主打夏天专用，有的主打四季通用，看你希望突出什么。最后一个办法是模仿对手，卖得好的产品点击率一般不会差，照着对手的场景摆设去模仿，效果最快。

三、一路做下来的经验

一定要重视选品。我们这几年上架了大约40款产品，但真正带来利润的就4款。理论上，如果我能多做出几个这样的小爆款，收入会翻很多倍。我今年30岁，人说三十而立，今年刚好加入生财有术，看到很多圈友年纪轻轻就能做出很好的战绩，也希望多沟通链接。今年对我来说，是人生新的开始。

评论区补充：有读者问，当下拼多多打压无货源，拿货还方便吗？作者回复：拼多多目前退款比较严重，如果拼多多号多，可以一件代发；号不多，建议把卖得好的款备10天左右的货自己发，或者找阿里巴巴的货源。也有人留言，做宠物私域，想找宠物用品代发合作。
