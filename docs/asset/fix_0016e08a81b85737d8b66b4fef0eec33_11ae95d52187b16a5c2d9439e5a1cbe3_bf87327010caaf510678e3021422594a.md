# 7.4.3 橱窗带货：费用与品类速查 @李诚

在视频号里开带货橱窗，先把两笔账弄明白：要准备哪些费用，以及你的货属于哪一类、该走哪套准入流程。

费用门槛其实不算高。基础保证金从100元起步；成交额往上走，浮动保证金也会按档位上浮。如果货源来自小程序联盟、小商店联盟或微信小商店，商家端、达人端还需额外准备3万元的小商店管理保证金。
