# 让 AI 新闻每天早 8 点自动同步到飞书

这次我用的新闻数据源是 NewsAPI 和 GNewsAPI。简单讲，它们都是把新闻聚合起来的接口服务：客户端发送一个 HTTP 请求，就能拿到来自世界各地媒体的文章与头条。它们都很能打：

- 覆盖 70 多个国家、几千个新闻站的实时资讯；
- 检索方式支持关键词、分类、日期区间等条件；
- 返回统一 JSON 结构，标题、简介、URL、发布时间等信息都在里面。

# 1.1.1 接口地址

两个平台的地址如下：

- NewsAPI：https://newsapi.org/
- GNewsAPI：https://gnews.io/

我更偏向于用 NewsAPI。原因很简单：同样发起 HTTP 请求，它能提供的筛选字段更细致。另外提醒一下，访问这两个地址都需要挂代理。

# 1.1.2 注册与密钥

先到 NewsAPI 站点注册账号，注册完点 login 登录；GNewsAPI 的取 key 流程也差不多。

登录后界面会展示 Account 与 Usage 两个部分。Account 里放着 API key，它就是日后调用 NewsAPI 的通行证。这条 Key 不要放到任何公开的地方，比如公开仓库、评论区、文档源码里都不行，万一被别人拿到，对方就能用你的身份发请求，扣的都是你的 Usage 配额。其他 API 的密钥也要同样小心。把 Key 事先保存到一个安全位置，后面配置时要用。

# 1.2 安装飞书社区节点

先在本地把 n8n 跑起来，随后进入 n8n 主界面：从左下角的“...”菜单点进 Settings。在设置面板中打开 Community nodes，并点一下 Install。

接着切到 Browser 标签页，在社区商店搜“feishu”，找到 n8n-nodes-feishu-lite 这个包，复制包名，再回到 n8n 的安装弹窗。

把包名粘贴到 npm package name 输入框，勾选同意协议，按下 install 按钮。等安装进度条走完，飞书节点就会出现在 n8n 节点库里。

# 1.3 创建飞书自建应用

先打开飞书开放平台（https://open.feishu.cn/），如果尚未登录飞书账号就登一下，然后进入开发者后台。

点击“创建企业自建应用”，名称和描述随意填，但应用名称后续还会用到，建议写到记事本里，然后点创建。

应用创建完之后，还需要开通权限并发一个版本：

先到左侧的“权限管理”里点“开通权限”，在搜索框输入“多维表格”，勾选“获取多维表格信息”“更新多维表格”“查看、评论、编辑和管理多维表格”三项，再确认。

注意：权限够用就行，不要贪多；飞书个人免费版每个月总共只有 10000 次调用额度。

发版时进入左侧“版本管理与发布”，版本号填 1.0.0，更新说明随便写，保存后确认发布。

发布通过后，到“凭证与基础信息”里复制 AppID 和 AppSecret，同样保存好，稍后就用。

# 1.4 准备飞书多维表格

先建一张表：依次进入“云文档”→“新建”→“多维表格”，从左上角把保存位置选成“我的文件夹”。建表时务必确认不要落进“知识库”，只能放在我的文件夹下。

如果表格是在飞书桌面客户端里创建的，先在客户端右上角用“在浏览器中打开”。

检查一下地址栏里的链接：只要 feishu.cn 后面跟的是 base，说明位置正确；如果是 wiki，就得手工把表从知识库移进云盘。

再调整字段：进入“修改字段”后，把 5 个字段全部设为“文本”，按顺序改名为“新闻链接”“标题”“新闻简要”“发布日期”“作者”。

最后将应用挂到表上：点右上角“···”→“更多”→“添加文档应用”，选刚建好的应用，权限设为“可编辑”，点“添加”。

这样准备工作就全部完成了。

# 2.2.3 参数细节解析

Method 之所以选 get，是因为新闻数据在服务器端，必须用 GET 方式读取。

URL 的出处是 NewsAPI 官网：进入 https://newsapi.org/ 后点 Get Started，页面会列出测试 URL 与一个 Example request。

[PRE25]

查阅官方文档 https://newsapi.org/docs/endpoints/top-headlines 后，可以看到查询参数有两种指定方式：

第一种，直接在 URL 后缀里拼。q=AI 用来锁定 AI 内容，sortBy=relevancy 用来按相关性返回。

第二种，走 specify query parameters，以 JSON 格式传参。比如 [PRE26] 处的示例，就是在 Send Query Parameters 里提交的。

这组 JSON 要做三件事：取前一天的新闻、用 pagesize 限制条数、page 用默认值 1。语言则是英语。

这段 JSON 是 Claude 生成的，我当时给它的提示词是：

“我想通过 newsapi 接口，在 n8n 中用 HTTP Request 获取 AI 新闻，有几点要求：1、只要前一天的新闻；2、内容语言为英文；3、返回 20 条即可。请问在 Send Query Parameters 的请求 JSON 中该怎么填？”

# 2.2.4 Settings 页配置

[PRE27]

实际测试时我遇到过 NewsAPI 服务器离线，导致请求失败、拿不到新闻。为增加稳定性，我做了个备份方案：NewsAPI 出错后自动改请求 GNewsAPI，用两个 API 互相兜底。

同时要保证单个节点报错不阻塞整个流程，于是我在 Settings 页开启了两项：

- On Error：Continue(using error output)——出错时不中断，把 error output 传给下一个节点继续跑；
- Always Output Data：ON——无论请求成功与否都输出数据，失败时输出空值。
