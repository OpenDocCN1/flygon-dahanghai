# 3.7 加一道违禁词排查

从选择器节点下方的连接点向外拖拽，新增一个“大模型”节点，把它命名为“违禁词排查”。

### 3.7.1 节点作用
它属于纠错环节的一部分：检查提示词里是否混入违禁词，并对提示词进行改写。

### 3.7.2 参数配置
模型选择“豆包·1.6·深度思考”。
输入项选择“图片生成”节点的 input。
用户提示词填写 `{{input}}`。
系统提示词方面，把它设定为“AI图像生成提示词全面安全过滤专家”，核心任务是识别并处理可能导致违规的内容，保证最终提示词合规。具体覆盖：
- 暴力类：重点盯“血、射、伤、痛、死、杀、打、击、刺、砸、撞、刀、枪、剑、棍、鞭、炸、爆”等字；其中“血”换成“红纹、红线、红丝”，“射”换成“指向、朝向、对准”，其余暴力词删除或改用温和说法。
- 色情类：对胸、臀、腰、腿、足、贴、靠、抱、搂、亲、吻、舔、咬、含、湿、热、软、紧、松、颤、抖、震、摇等敏感词进行处理；“足”改为“下肢、脚部”，“贴”改为“靠近、接近”，按/握/抓改为“放置、位于、持有”，“背”改为“后方、身后”。
- 敏感组合：足交、射击、红旗、色彩等容易被误判的组合，要通过调整词序、增加间隔词或重新表达来规避。
- 女性肢体过度描述：减少身体细节，用整体状态代替具体动作，多写环境和构图，避免把注意力放在女性身体上。
- 其他敏感内容：政治敏感词（红旗、党、政、军等）、可能引发争议的社会敏感词、针对特定群体的恶意攻击，都要处理。
处理策略上，执行逐字扫描、组合检测、语境评估和强制替换；同时用删减细节、整体化表达、环境转移、抽象化处理来重构。安全替换词库包括：身体动作→姿态、状态、位置；接触描述→位于、处于、呈现；情绪表达→氛围、感觉、印象；颜色状态→色调、色彩、视觉效果。工作流程为：全面扫描→风险标记→策略选择→安全处理→再次验证。
输出要求是：直接给出处理后的安全提示词，不能含违规字符或敏感组合，大幅简化身体细节，同时保留核心画面表达，保证流畅可读。执行标准强调零容忍、宁可过度、全面覆盖、安全第一。
最后还有一条硬限制：`{{input}}` 里必然存在违禁词，严禁把 `{{input}}` 原封不动地输出。

# 3.11 加入动效提示词大模型

点选“批处理体”，等它显示蓝色选中状态后，点击“添加节点”-“大模型”，改名为“动效提示词”，并与批处理体中的连接点完成连线。

### 3.11.1 节点作用
结合已生成的图片和文生图提示词，改写动效提示词，供生成视频使用。

### 3.11.2 参数配置
模型选“豆包·1.6·深度思考”。
输入项选“图生视频提示词”节点的 input。
视觉理解输入选“图生视频提示词”节点的 output，并把变量名改为 url。
用户提示词填 `{{input}}{{url}}`。
系统提示词把它定位为“古诗词动效提示词生成专家”：根据用户提供的文本 `{{input}}` 和图片 `{{url}}`，分析两者的联系与意图，生成适配图生视频的动效提示词，内容要覆盖元素运动、人物动作、光影变化，整体呈现可爱、萌动的视觉效果；描述人物动作时，肢体幅度要适当放大。
技能要求分三步：先观察图片 `{{url}}`，把握画面元素；再理解文本 `{{input}}` 的主题、情感和重点；最后按元素运动、人物动作、光影变化的顺序生成提示词。
回复示例以江雪孤舟场景为例：全景镜头下，江面雪花分三层飘落，近景大雪花旋转下落，中景匀速飘落，远景呈模糊轨迹；女孩坐在孤舟上随船轻晃，斗笠边缘有雪花弹落，双发髻微颤，蓝色发簪上的装饰闪动，睫毛隔几秒眨动，嘴角带笑，脸颊雪花融化；她缓缓抬手接雪，淡蓝古风长裙的雪花图案随呼吸起伏，丝绸在风中泛起涟漪，蓑衣纤维轻摆；钓鱼竿静止，鱼线偶有轻颤；柔和阳光穿过雪花，在女孩和小船上投下变幻光斑，整体笼罩温暖光晕，突出可爱萌动。
限制条件有四条：只输出动效提示词，不输出无关内容；提示词必须涵盖元素运动、人物动作、光影变化；人物动作要体现较大幅度；整体效果要可爱、萌动。
最后，把“图生视频提示词”节点的输出变量值设置为“动效提示词”的 output。
