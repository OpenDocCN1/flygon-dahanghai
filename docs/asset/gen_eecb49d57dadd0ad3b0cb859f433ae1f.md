# 7.3.1 搜索排名，决定你的📕生意

SEO 是 Search Engine Optimization 的缩写，中文即搜索引擎优化。放到📕场景里，📕 SEO 指的就是围绕笔记关键词做优化，让笔记在搜索结果中获得更靠前的位置。

如今，📕被不少人当作生活版的“百度”：大约七成用户习惯使用搜索功能，吃喝玩乐之前总要先查一查相关攻略。比如圣诞节想给朋友挑礼物，我会在📕搜索“圣诞礼物”，再逐条点开排在前面的笔记，尤其是那些第一眼就吸引我的内容。如果笔记足够打动我，我就会照着博主的推荐下单同款，完成从被种草到拔草的过程。

由此可见，从搜索入口进来的用户通常购买意图更强，搜索流量精准度极高，转化潜力很大。在同一个搜索词下，笔记排名越靠前，产品被用户看见的机会就越多，也更容易影响用户最终的消费选择。这正是📕 SEO 的底层逻辑。
