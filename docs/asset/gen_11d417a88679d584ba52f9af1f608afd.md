# 小程序流量主：广告位怎么摆更有效

面向流量主，🛰️广告准备了12套基础模板，覆盖全屏、横版/竖版卡片、横幅、格子等5类场景。素材类型、边距、颜色、圆角都能自己调，让广告组件更贴合页面场景，用户体验和转化效果一起往上走。

拿『下厨房』小程序举例，它把原生模板的竖版卡片放进了首页信息流：

先看差别：常规Banner是通栏单图；横幅广告则是组合模块，通常由图片或视频、标题、来源、行动按钮组成，而且高度比Banner更窄。原生模板里的横版广告高度更大，既可以通栏也能留边距，信息流类内容小程序更合适；工具型小程序用它就会比较占地，打扰感更强。

[PRE1]

在小程序里，可以先调用 wx.preloadAd 预取广告数据；之后创建 ad、ad-custom 标签时，会自动复用这份数据，创建标签时就不用再拉一次，省掉一段等待。创建广告位时还能传 ad-intervals 做定时刷新，这个参数是数字，单位秒；注意刷新间隔不得少于30秒，所以传值必须大于或等于30。

原生模板上线后，小程序广告样式更丰富。把页面里原有的常规Banner或视频广告换成原生模板，广告与内容更贴合，体验更好，点击率通常也会跟着涨，收入自然有机会提高。不过这不是铁律：我们有的工具型小程序换完后，eCPM反而降了 😭。所以原生模板更偏向内容型小程序。

如果之前已经接入原生模板广告组件，之后在小程序后台改样式不用重新发版；编辑完成后，新广告位样式大约十分钟就能在线上生效。线上调样式很方便，拿来做 A/B Test 检验广告设计效果很合适。

## 2.6 技术层优化：提前加载与按间隔刷新

这两件事可以交给前端同学：一是广告预加载，减少创建广告标签时再次请求的耗时，让页面打开更快；二是广告定时刷新，多刷一次就多一次曝光，也能让用户看到不同广告，这一点挺重要。

## 2.7 别滥用：停掉低收益广告位

每次广告曝光能带来多少收入，和广告平台的 eCPM 正相关。大盘上，用户结构值得优化，但产品定位摆在那里，并非想调就调；平台 eCPM 又和广告转化率正相关。落到单个广告位，要守住整体转化率，不能把组件铺太满，拖累整体效果。后台用来反映转化率的指标是点击率；广告位加得太多，曝光上去了，点击率却可能很惨，比如低于1%，这种低收益广告位就该关掉。

## 五、流量主变现还需弄清的几件事

**Q：我手里有流量，能不能不接流量主，自己放广告？**
A：可以，但🛰️内不能接入其他广告联盟。你可以接第三方广告，价格按点击或授权来谈，需单独拉报表。不走流量主，第三方广告的收益就得更可观。这类合作通常发生在小程序受众相近、流量更精准、想卖出更高价格的情况下；但第三方广告要有专门渠道，对接合作也得投入人力。相比之下，流量主广告的优势很清楚：有保底收入，运维也省心。

**Q：小程序广告位设计由开发者掌控，万一违规审核被拒会怎样？**
A：每次小程序审核，广告位都要一起审，被拒的后果不轻——只要广告位审核没通过，在下一个版本广告位审核通过之前，线上小程序会整体不展示广告。也就是说，一旦被拒，当前广告位立刻看不到，得重新提审小程序，等广告位审核通过后才能恢复展示。

**Q：广告位常见的驳回原因有哪些？**
A：接入广告位时，主流机型适配其实不难，关键是别动歪心思：用文案引导用户，或者故意让按钮挡住广告位，让用户点击/误触 Banner 广告；再或者改 Banner 组件样式，做欺骗诱导点击。这些都很容易被驳。还有，拿“升级 VIP 会员可免广告”做诱导，也是不允许的~

**Q：哪些广告会出现在「我的小程序」？**
A：从广告主端创建广告、选择推广目标来看，🛰️广告目前有8种推广目标：推广品牌活动、推广我的门店、推广我的应用、推广我的商品、推广我的👸号、派发优惠券、收集销售线索、推广我的小游戏。小程序里最常见的是标黄底色的几类：品牌活动、应用（尤其安卓端）、商品、👸号、小游戏。
