1. 上线优先：先完成第一个网站，把域名注册到部署的整条链路走熟。

# 1.1 项目背景与机会

# 1.1.1 为什么选择“AI + Web 开发”？@彩笺

网站是产品的一种形态。我对出海做网站的理解可概括为八个字：找到需求，满足需求。

过去，做网站很难。大家的注意力更多放在“满足需求”上，而满足需求需要特定且有难度的技能——写代码。所以程序员群体过去过得不错，因为他们掌握了多数人没有的技能。

大公司有多个部门、多条产品线，它们怎么做产品？简单说：产品经理负责前半句“找到需求”，程序员负责后半句“满足需求”。

时间来到 25 年春，随着 AI 能力提升，“满足需求”这后半部分变得越来越容易。小排老师此前也说过：只靠想法就能赚钱的时代到来了！

# 1.1.2 收益空间有多大？@彩笺

开始第一站前，先真实描述赚钱前景。

我见过只靠流量广告费月入近 $5w 的网站；也见过靠满足用户付费需求、通过订阅日入 $1 千的 AI 工具站。出海几乎是变现天花板最高的领域，甚至可能没有之一。

我们赚钱就有很低调的大佬，0 编程经验，去年月入万刀。想赚到这些钱，你只需要：找到需求，满足需求。

不断上线网站的过程，就是不停找到需求、满足需求。

对新手来说，找到需求稍难，更考验产品经理和用户调研相关能力。AI 能辅助找需求，但核心动作仍靠你洞察，取决于你对需求的敏感度；产品经理、用户调研的认知和经验会有帮助。

AI 现在几乎能帮你完成“满足需求”，即做出 MVP 快速验证需求是否真实。AI 写的代码很初级但基本可用，在 AI 帮助下，有基本识字能力的人就能做出网站或 APP。对新手而言，第一个要跨的门槛是把网站做上线，并且越熟练越好。

新手要破除对代码的恐惧，因为无需看懂，让 AI 给你复述即可。

新手初期重点任务是熟悉如何把网站上线，即域名注册、网站托管、代码托管这三类平台。可选项和方法很多，这里只举例最简单的一种。

如何找到需求并满足需求？很多人以为是不停调研或一直打磨产品，但真实可行路线是在不断上线产品中验证：是否找到需求，需求是否为真？是否满足需求，能否通过收费满足需求？

所以“找到需求，满足需求”的含义可能就是快速上线网站。只有通过大量 MVP 验证，才能尽快找到并满足需求。

干耗着读实战手册，或在互联网随便乱看，也许有助于找需求，但不执行、不上站、没有 MVP，就无法验证需求，也就没有钱赚。

对什么都不懂的新手来说，可按手册里粗糙的示例网站，零基础快速上线第一个 Web 网站。提一句：找到需求并满足需求时，哪怕网站很简陋也能赚很多钱，比如 diskprices.com，这也是我的亲身经历。

写下这句话的我，零基础编程经验，用 AI 构建的简陋网站快速满足需求时赚的钱，远比我花几万块找外包团队优化精美网站赚得多。

# 2.1 网站由什么组成

# 2.1.1 域名（Domain）：是什么、去哪买？@彩笺

域名就是大家口中的网站，baidu.com 是百度的域名，也是网站的外部入口。想一想，别人得知道你的地址才能找到你。域名全球唯一，通过这个名字能找到你，也只能找到你的“地址”。

推荐去 cf（Cloudflare）购买。市面上卖域名的很多，cf 对开发网站最方便。域名可以等网站实现后再买，不急。

# 2.1.2 服务器（Hosting）：云端部署与常见免费托管平台

服务器就是放你运行代码的地方。你自己家有地址，也得有对应房子。现在很多免费地方可部署代码（即托管网站），如 Vercel、Cloudflare、Netlify 等。

大多数平台部署步骤相似：

1. 注册账号；
2. 上传网站文件，或关联 GitHub 仓库；
3. 一键部署后获得访问网址；
4. 如有自定义域名，可在平台后台绑定。

# 2.1.3 代码（Code）：网站的核心“灵魂”，静态与动态网页的区别

网站最终样子和交互由代码决定。可以把它想成菜谱，决定你做出的美食味道。

静态网页：所有人看到同样内容，像已印刷好的报纸；优点是速度快、相对安全、部署简单、成本低；适合个人博客、作品集或公司官网。

动态网页：能根据用户不同操作或登录状态改变内容，像聊天软件时刻更新；优点是功能丰富，可实现登录、评论、购物车等；缺点是需要数据库和后端支持，开发相对复杂；适合电商、社交媒体等需要用户系统的网站。

如果你是第一次做网站，可以先从静态网站上手，熟悉流程后再尝试动态功能。

# 2.2 编程语言入门科普

# 2.2.1 HTML/CSS/JavaScript：零基础该掌握哪些关键点？

可以把网页想象成一个人：HTML 是“骨架”，决定页面上有什么元素（标题、段落、图片、链接、按钮等），核心概念包括“标签”“属性”“嵌套”；CSS 是“外表”，决定元素如何排版、配色、调整大小和字体等，核心是“选择器”“属性”“值”；JavaScript 是“大脑”，让页面可交互和动态响应，比如点击按钮出现提示、填写表单时验证、播放动画等。

# 2.2.2 前端与后端怎么区分

前端：用户在浏览器里能看到和操作的部分，包括页面布局、视觉效果和交互逻辑，主要用 HTML、CSS、JavaScript，像餐厅的大堂和菜单。

后端：网站在服务器上运行的部分，用于处理数据存储、用户认证和业务逻辑，常见语言有 PHP、Python、Node.js 等，像餐厅的厨房和仓库。

# 2.3 AI 工具准备

AI 工具不是重点。最简单的做法也是我一直在用的：用 Claude 共享账号。单买太贵、用得不多又容易封号，而且不需要安装软件；更重要的是我需要问很多非代码问题，Cursor / Windsurf 主要针对编程问题写代码。

# 2.3.2 Gemini / Claude / ChatGPT：如何高效对话并提出精准编程需求

一句话理解区别：Gemini 2.5 Pro 和 Claude 4 公认代码能力最强，ChatGPT 算低配版本，可用但不够强。

如无法自行注册，可直接在淘宝使用共享/独享成品号。获取渠道没那么重要，尽快用上世界上成本最低、智慧最高的 AI 工具模型更重要。

# 2.3.3 其他 AI 工具：bolt.new、trickle.so、GitHub Copilot 等

一句话理解区别：bolt.new 非常适合无代码新人，可自动部署直接查看网页内容，但无法回退代码版本；trickle.so 类似，但提供一些模板；GitHub Copilot 更适合程序员在 IDE 代码编辑器上操作。

bolt.new 和 trickle.so 的域名后缀都不常见，所以没办法直接点击进入网站，需要复制跳转或输入浏览器网址栏回车进入；使用邮箱登录即可使用，有免费次数。

结合刘小排这篇帖子食用更佳：5 分钟做个网站，人人都能学会。视频版本：不懂编程，1 分钟让 AI 做一个星座运势网站。

# 2.3.4 本地环境配置：Node.js、npm、Git 简单安装

一句话理解区别：

1. Node.js 像专门用来“播放”JavaScript 代码的工具。以前通常只能在浏览器里运行 JavaScript，有了 Node.js，你的电脑就能直接执行 JavaScript 程序。
2. npm 是装软件的“应用商店”，帮你下载别人写好的代码模块，不用自己重新造轮子。
3. Git 是代码的“时光机”，记录所有修改历史，出错可回退，多人协作不冲突。

三者关系：Node.js 是环境，npm 是在 Node 环境中获取工具的方式，Git 负责记录代码变化历史。

我不是程序员，目前还没用过这类；除非跟 AI 沟通时，它让我复制粘贴代码操作过，也不熟悉这些。所以非程序员新人可以不必太过关注，我们只需要尽快上线网站即可。只有尽快不断上线网站，才能快速找到需求、满足需求；其他工具、环境、模型都只是辅助，不可沉迷。
