# 8.3.2 追投还是换号？

视频表现亮眼时，DOU+并非不能加码，但要有选择地追投，而且总次数别超过3次。后续新发作品若能较轻松突破3000到1万播放量，便算初步起号成功；可要是账号运作满一个月，播放量还没越过15万，建议放弃当前号，重新起号。

可按常规视频的互动基准来判断是否投放：点赞率5%、评论率1%、转发率1%、5秒完播率60%、整体完播率20%。

**Day1**：数据没到基准，就换小说方向；数据达到基准，可以考虑追加投放；若视频冲上热门，投放目标选点赞评论量，人群定向女性、18—30岁，投放12小时。

**Day2**：上午10点、下午2点、下午5点各发一条，共发布3条视频。数据未达标仍可酌情追投；数据达标后，推流会逐步精准，也可按需投放，通常到第三天播放量能破万。

**Day3**：指标不理想就先别投，检查画面声音是否有问题、账号日常是否保持活跃等；指标达标则不必再投DOU+，稳定日更即可。

**Day4**：只要有一项数据过线，就继续日更。

**Day5**：哪怕数据突然走低，也别中断日更。

**Day6**：发布一条新视频，同时隐藏前一天表现较差的那条，循序渐进完成内容替换。

**Day7**：数据理想的话，可选择投放，单次投入200元以上。
