# 《忠犬八公》热映，携宠观影团如何在小红书引流变现

2023年4月3日，老孙说经济分享了一个同城活动案例：相关小红书笔记已收获33个赞，曝光表现相当亮眼。

《忠犬八公》上映期间，有人在小红书发布同城携宠观影团的笔记，借此吸引流量。这个玩法不挑城市，各地都能复制；同时可以对接赞助商，分摊活动成本。现场还能安排摄影服务，把“加微信领照片”作为入口，并向有需求的参与者收取拍照费用。按每场100人、每人88元计算，单场收入可达8800元。活动结束后，再把参与者沉淀到微信私域，形成同城养宠精准人群；随后引导他们关注公众号，做长期触达和持续转化。
