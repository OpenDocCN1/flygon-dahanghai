# 八年跨境复盘：亚马逊三条路线怎么选

我是胖海豚Arron，做跨境满八年，公司年营收做到九位数。今天不摆成功学，只把真金白银换来的教训摊开讲。成功各有各的路径，踩坑却常常惊人相似。

我本科读国贸，毕业后在上市公司管北美销售。干了几年，看周围同事的状态，就知道自己再待下去天花板在哪，于是找了个理由离开。那段经历我很感激：早期就有海外出差、和全球客户谈合作的机会；但也明白，舞台给的光环不等于个人本事。后来入行跨境，偶然里也有必然。我把自己看作还在路上的创业者：爱学习、愿分享、能扛起伏，也经历过开心、无奈和落泪，和普通人的日子没太大差别。

今天分五块聊：平台怎么挑；亚马逊还有没有机会；三条路线及各自的坑；实操心得；品牌出海。

一、平台怎么挑

我们实际跑过的平台不算多：速卖通、Lazada、eBay、新蛋、美客多、沃尔玛、亚马逊。全球平台上百个，哪个平台都有人赚钱，关键不在平台本身，而在你手里有什么条件。平台没有绝对好坏，只有哪张牌适合先打。跑过一圈后，我用钱和人投票，押亚马逊。原因在于它容得下不同角色：个人、小团队、成熟团队，都能按自己的目的经营——卖货、做品牌，或把团队做得更值钱。个人可以从一款货、一个站点起步；小团队有过结果且能复制，会顺一些；成熟团队有外部资金或供应商深度合作，也适合。

二、亚马逊还有没有机会

经历野蛮生长，尤其2021年封号潮之后，我反而认为现在可以进。好时机不是无脑冲，而是在风险可控的前提下拿到属于自己的结果：利润、品牌积累，或团队练兵。先回答三个问题：目标是什么、底牌有哪些、想借平台实现什么价值。意愿够强，方法自然会冒出来。很多人对市面上的大卖发家史如数家珍，但别人的故事知道再多也帮不了你。真下场，得盘自己。容易成事的三样底牌：钱、班底、路子，资源可以近似看成方向。平台生存路线无非铺货、精铺、精品；底牌决定选哪条，三样都空就别急着进。

三、三条路线与对应的坑

1）铺货

铺货的逻辑是广度优先：多货、多店、多平台，把同款尽快铺到不同国家。产品知识不用很深，靠工具挖当下热卖或有竞争力的信息，再用ERP快速上架；出单后能采购多SKU、顺利发出并回款，闭环就跑通了。钱和资源门槛不算高，人手可以随订单增加，适合轻资产、低风险起步。

最大的坑是多站点、多品类同时开花。人的精力有限，面面俱到很难；只看别人成功，容易盲目自信，最后哪个平台都浅尝。还有隐形开销：计划开50家店，正规注册一年维护50家公司至少15万，再加ERP、选品软件、英欧税号注册申报、网络、合规等，至少20万，而这时还没开卖。买店的话，50个北美店铺约15万，其他费用相近，但二次审核、链接审核申诉不回来等风险更伤。实际运营后，最贵的是决策：选什么品类、备多少货、谁来卖、交付周期多长、走哪条物流，一步错可能连锁反应，甚至店铺关门。无经验者不建议贸然碰。

2）精铺

精铺的SKU比铺货少、账号不必多，可以守一个平台做少量精品SKU，也可以深耕一两个优势品类。对钱和班底要求更高：要懂流量怎么分发、转化怎么发生，后端供应链在品质和时效上跟得上。难点是不断淘汰旧品、寻找下一款，同时培养人、复制梯队。

我们2014年起步只做速卖通，半年后加Lazada，再半年加eBay；经验少、平台不完善，问题多，团队疲于应付。后来几位熟识卖家砍掉eBay团队转亚马逊，我们体量小，选择相信他们的判断，清库存、关平台、转亚马逊。刚进时也不知道开发什么，就做熟不做生，从老品类切入并提高品质标准；以前客户多来自新兴市场或收入偏低人群，亚马逊中产更多，要求更高。八年过去，我们仍是精铺团队，只是专注亚马逊，多店、多站、多类目。选它，是因为平台操作简单、相对公平、购买力强、流量大，大蛋糕上分份额更现实。

精铺难，钱、人、资源都要够；但不经过它，很难从铺货直接跳精品。它是练兵场：开发、运营、品控、供应链，从单兵到团队管理，都要从达标磨到精细，代价免不了。省时少踩坑的办法很明确：拉有结果的人进团队。不这么走也能成，只是更花时间金钱，可能错过窗口。个人预算少，边学边做会难，但并非做不好。

精铺的坑，是没想清靠什么赢却追求完美。测款、多SKU时，每个SKU每个站点都压库存，又想省运费走长周期普船；外部市场或推广一变，库存、仓租、回款三座山就可能压崩。优点是试错便宜、能快速试错，单个SKU备货控住，风险就降。我们在这条路吃过亏：SKU多时备货过猛，货没到手就当成已卖出；市场一变现金流吃紧，供应商和物流回款变慢，又拖累备货，形成恶性循环。好消息是，创始人不必全能，发挥一项长处就有机会：供应链、产品开发预测、运营水平，或财务对备货发货的把控。

3）精品

精品SKU少、账号少，对人和产品要求最高。做得好的精品卖家常见两类：单店死磕少量SKU，或多店打造少量SKU；没在这种路线拿到结果的人，做出爆款很难。选品前功课要做足，产品要经得住市场和消费者挑。它还考宏观把控和应变：库存周转、销售计划、推广节奏。我熟悉的一些年销5—10亿卖家，没人一上来就精品，也没人从零几何级冲到几亿；通常先铺货或精铺，再转精品。

新入局有机会吗？有资金，人、方向可以用钱解决，再搭模式；没资金，团队和方向最关键，先评估适合哪种冷启动，低风险边做边学。

精品的坑，不是喊口号，也不是嘴上精品、实际不是；没有拿到结果的人操盘，胜算低。像登珠峰却请没登顶的人带队。我认识的操盘手走这条路，坦白说难复制，我知道但做不到。它比前两条更吃领头人的全局思维和体力：做产品前要大量数据调研，定排名目标、备货量、每周各渠道发多少、生命周期亏损与盈利节点，都要预演。

四、实操心得

1）把视线抬到平台之外。平台属性和政策导向决定未来。亚马逊很包容：可卖货、可推品牌（赚不赚钱另说）、可做流水增公司价值；先定目的，找对标店铺或同行，先学再超。

2）想清最贵的两项开销。一是时间，二是决策失误。目标不清就陷进细节，忘了初心，时间最贵；决策错可能全盘崩，包括路线、备货、选品、团队。

3）先解决钱，再搭班子，最后定方向，次序别反。资金决定模式，后面的团队和方向可以顺势解决。

4）长期经营要筑护城河。域名、品牌、专利等，最好开店前或产品上市前布局，花钱不多但长期值钱；快速试错就别计较一时得失，快试快换。

5）对标行业前列。以结果为导向，看他们怎么控风险、稳增长、长期不掉队。

6）HR与财务别边缘化。HR管人才入口，财务参与决策，用数据指导销售。

五、品牌出海

在亚马逊做成知名品牌是很多人的梦，官方也多次表示能助力商家出海。我创业前经历过：老东家在五个国家设分公司，派总部销售常驻，做本土化渠道，赋能经销商开拓代理，做本地社媒广播电视传播；几年下来每国花千万级，最终还是失败。现在TikTok、Facebook等短视频社媒发展快，品牌出海的可能性和速度都提升了。但我的看法是：先赚到钱，再拿部分利润投品牌；不赚钱硬投会耗掉团队信心。品牌是长跑，短期难见效，要持续投入，也要有坚定信心。
