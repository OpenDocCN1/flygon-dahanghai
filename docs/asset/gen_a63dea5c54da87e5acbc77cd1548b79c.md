# 两年副业30万：宝妈的📕获客与🛰️成交复盘

文/小野 2023-02-08

我是小野，在一家医药公司负责互联网医疗运营，早些年也在医疗互联网公司做过运营和产品经理。同时，我是个新手妈妈，家里有个2岁的宝宝。2020年底生完孩子后，我本以为自己会在工作和育儿之间连轴转，没想到竟用业余时间打通了📕获客和🛰️私域成交，累计利润30多万元。

我知道，这个数字在龙哥盟里不算什么，但对不少人来说，已经相当于一份全职工作一年的收入。既然拿到了结果，就说明有些动作做对了；把它们沉淀下来，一是给圈里贡献一些可复制的实操方法，二是给自己留一份记录和复盘。

一、互联网启蒙期：大牛们给了我流量思维

毕业后第一份工作，我在一家互联网医疗公司做产品经理和运营。从那时起，“先攒流量，再运营流量，最后把流量变成收入”就扎进了我的思路里。只不过当时是为了公司业务攒流量：每周给业务相关👸号写行业分析、追热点，吸引行业关注，再为互联网产品的B端销售打基础。

更大的影响来自「个人IP」。这里要感谢龙哥盟的嘉宾大辉和二爷。很多年前，我看着大辉做「小道消息」、二爷做「二爷鉴书」，于是8年前也开了「小野食堂」。本来想认真做内容，后来工作太忙（也是借口），从月更变年更，最后断更。

不过没关系，👸号没做起来，但🛰️好友我一直在积累。

二、私域引流期：把加好友变成日常动作

1、泛流量：任何加🛰️的机会都别放过

到2021年真正开始🛰️私域变现时，我的🛰️里已经躺着约4000个好友。我一直很清楚，🛰️私域迟早能变现，只是不知道是哪天；所以我要持续加很多很多好友，不放过工作中任何一个增加好友的机会。

我做过医药医疗行业投资经理，每次出差都要主动认识行业里的人，主动加🛰️。一开始很不习惯，后来想到未来很多年这些好友可能为私域变现打基础，我就大胆去做了。

从那以后，我干脆关掉了好友验证，这样通过速度更快。后来证明泛流量思路没错：当时加的行业人，有人成了我的代理，有人成了VIP客户。

2、精准流量：同经历的人最同频

每个妈妈都经历过备孕、怀孕，那期间很多迷茫和疑问，第一反应就是去📕搜一搜、问一问。我起初加过一个备孕群，后来转念一想：我也可以自己建群当群主。于是我开始在📕记录备孕、怀孕和生娃的真实过程，几乎不用刻意找选题，只要把生活记录加工成对别人有用的内容就行。从备孕到怀孕到生孩子，📕粉丝只有600多，但导到🛰️的妈妈大约有1000到2000人，这批流量也是我现在副业的主要客户来源。

值得一提的是，我在南京鼓楼医院生产，产检时发现这家医院居然没有官方孕妈交流群。我决定自己建一个，可流量从哪来？生产前我发了一篇📕笔记，题目是「南京鼓楼医院助产士才会告诉你的待产注意事项」。就靠这一篇，聚起近500人的鼓楼医院孕妈群。其实内容就是助产士门诊会给的注意事项，我只是做了整理和编辑。

[PRE3]

同经历的人，最同频、最精准。这个道理放哪个领域都适用。

3、🛰️标签：私域精准靠手动标记

这几年“精准推送”听得太多，但🛰️私域里的精准，最原始也最有效的办法就是手动打标签，包括分组标签和名字备注标签。

分组标签：分组本质上是为了发朋友圈方便。我按工作单位、城市、职能、认识来源等维度给好友分组，发圈时筛选合适标签，既能屏蔽不相干的人，也能精准触达。比如刚开始做母婴社群招募，我不想打扰其他好友，就做分组发圈，很快引来100人入群。

[PRE4]

名字备注标签：主要为了必要时群发，以及触达同一类客户。

（1）把好友/客户大致分4类：已成交用1表示，后面写成交类别（美食/母婴/减脂）；已沟通咨询但未成交用2表示，后面写咨询类别；未沟通触达但未来有机会用3表示；未沟通触达但朋友圈屏蔽了我用4表示。

（2）备注好友基本情况：身高体重、认识来源、孩子性别及生日等，信息再多就写进🛰️好友描述里。记录客户信息是销售基本功，🛰️本身就是强大的CRM库，用好它，私域变现事半功倍。

三、零售定位与变现期：产假也能成为赚钱窗口

妈妈们都知道，产假不是放假休息。孩子呱呱落地后，要开始学习做妈妈，短时间内学会关于人类幼崽的一切知识；从此失去完整的一夜睡眠，黑夜中随时醒来喂奶、换尿布、哄睡；产假里只有很少的基本工资，房贷和生活开销却照转甚至更多。

所以休了2个月产假后，我意识到该做副业了，生活里多一个收入进项总是好的。成为妈妈后，我没法每样都给娃最好的，但不希望因为经济压力，每样好东西都只能看看，却要给孩子找平替。

回头看，很有成就感。别人的产假可能是不停奶娃，我的产假倒成了🛰️私域变现的窗口期。

1、从美食经济起步：吃货的热情

这个阶段思路很简单：有啥卖啥、喜欢啥卖啥，好吃的谁不爱？前面引来的妈妈流量不少，但开始卖货时我没有母婴货源，于是先选自己最有热情的领域——美食。

我是云南昆明人，超级热爱家乡美食，8年前就做「小野食堂」美食👸号，这也一直是我的热情所在。恰好闺蜜有云南包浆豆腐货源，云南人都知道这个小吃很有特色、很好吃，利润虽然不高，但产品力很能打。于是我建了「小野食堂」美食群，注册快团团，也发了第一条卖货朋友圈。

[PRE6]

我选快团团，是因为自己一直在小区团购群买买买，使用体验觉得这个小程序很好用；同时了解到快团团是2021年才兴起的工具，也是拼多多旗下，凭拼多多的实力，这个小平台应该也会很好。没想到误打误撞，快团团后来成了私域里发展很迅速的工具之一。

有了工具，除了包浆豆腐，我开始用家乡云南的资源到处找货源：大家知道的《去有风的地方》里很火的鲜花饼、米线、乳扇，还有沃柑、普洱茶、云南咖啡、版纳小玉米、饵丝……总之围绕云南美食的一切。当时恰逢过年前，加上好朋友支持，第一个月利润仔细核算后有7000+，很开心。

那段时间，我自己找货源、自己编辑团购文案和图片、自己导订单、发货、上传单号、处理售后，其实很累很辛苦。每天连上传物流单号，都是抱着2个月的娃哄睡后完成的；经常因为抱着娃睡觉，操作电脑时手脚并用（又心酸又好笑）。

后来有一段时间，我执着于自己找货源、自己开团，非常费时间，效率不高。仔细反思后我得出结论：供应链不是我的强项（议价能力不强、利润不高，作为副业时间也有限）。于是我决定扩大界限，不仅做云南美食，也做全国美食；不仅自己开团，也在快团里帮卖。

当然，做美食类产品，品控是第一位，如何选品是另一个话题。

2、母婴经济：妈妈身份带来的必选项

做了2个月美食团购后，我的产假只剩不到一个月。看着自己群里的宝妈开始在其他团购里买买买，我很焦虑。于是想办法找到母婴货源后，我下定决心新注册一个母婴团购号，也新建了一个母婴好物团购群。

[PRE8]

母婴产品是刚需，不用卷很多文案来创造需求。尤其在0～1岁这个阶段，只要把孩子吃喝玩乐货源找齐，价格有一定优势，社群姐妹有信任，服务做好，就有订单。运营一年后，母婴社群人数将近500人，母婴团购月利润也有大幅增长，也是我目前每月利润的主要来源之一。

3、变美经济：瘦了20斤后的选择

为什么选「营养私教减脂和大健康」？从个人角度，我生完孩子胖了20斤，自己花2万多上了半年多瑜伽课，丝毫没瘦下来……实在忍无可忍，抓住最后一根稻草想试试。我是药学硕士+执业药师，医药专业背景让我不接受节食、代餐等减肥方法，所以选了一个科学的大健康营养私教方案。一边减肥一边分享，也遵循了“自用-分享-成交”的生意底层逻辑。

[PRE9]

从客户需求看，我既然做了母婴社群，大多数客户都是妈妈，大部分人应该跟我有同样的减肥烦恼和需求吧？我既要满足妈妈给孩子买东西的需求，也要满足妈妈本身的变美需求。我真心觉得，每个妈妈都值得好好瘦一次。后来8个月时间，我服务了30多个客户成功减肥。很开心，我做到了初心，也交付了结果。

从利润看，做大健康和服务交付类产品，利润也更高。做了8个月，每月利润都在1万元以上，营业额最高的一个月在6万+。

四、私域进阶期：朋友圈、销售力与榜样感

1、发好朋友圈：做有温度的货架

做私域的基本功之一，就是发好朋友圈。什么是发好朋友圈？我简单总结3点：

（1）保持日更。做自媒体要日更，做私域也一样。发1条也行，发10条也好，总之得露面；一旦长期不冒泡，客户容易觉得你三天打鱼两天晒网，甚至以为你不做了，信任就会流失。

（2）除了货，还要有活生生的自己。你挑的产品、提供的服务，其实都在传递你的价值观和生活方式。因此朋友圈别只剩商品，也要有情绪、有观点、有态度，让别人看到一个真实的人。

（3）自己没用过就不推荐，自己没体验就不推广。大多数团购美食我都会自己买来吃一吃、尝一尝，并且自己拍照，为此还买了一个比较贵的镜头。育儿过程里，我自己大多数需要用到的东西也都会在团购里下单，然后在社群里分享。减肥也是自己体验瘦了20斤，才去分享和推荐。我相信，最好的零售生意方式，是通过自己体验过、思考过且擅长的方式满足客户需求，同时创造价值。

2、做个好销售：点燃客户自己的小火苗

当我开始做变美经济，发现营养私教减脂和大健康这类服务类产品，并不像团购那样随意聊2句就能成交。后来我慢慢学会洞察和挖掘客户需求。原来销售是一件以人为中心的事，满足客户本身存在的需求，而不是以产品为中心，只会一味介绍产品。

有句话我很喜欢：没人能靠别人说服，好销售只是把客户心里那点小火苗点起来。

除了满足客户需求，好销售还必须学会如何跟客户保持粘性。服务客户过程中，有很多话题和触点可以持续跟客户产生链接，挖掘更多需求，从而达成更多生意机会。

私域里，客户一点点攒起来的信任和持续复购，特别珍贵。

3、成为好榜样：推别人赚钱也快乐

在我还没有正式加入龙哥盟时，就发圈吸引了2个🛰️好友想加入赚钱（后来都加入了哈哈哈）。

加入赚钱参加📕航海后，我跟闺蜜聊到📕，并且不厌其烦做她赚钱的推土机，推了很久。就在今晚，她顺利导来十几个好友，还成交了5单。

在我跑通📕获客和私域卖货后，也有不少同样是新手妈妈的好友来问我如何做副业。我发现大家原来是一样的境遇：一样在有孩子后想给孩子更好的生活，一样不甘于现有状态，想通过副业实现经济增项和自我价值。不止一个人跟我说：小野，你的朋友圈很有力量，我想跟着你赚钱。于是我开始当她们赚钱路上的推土机，分享龙哥盟、分享赚钱思路，她们也陆续拿到了实战第一步的小成绩。

原来我也能成为给别人力量的人；推着别人一起赚钱，同样快乐。

五、往后怎么走：生活工作平衡，真诚最打动人

1、育儿、主业、副业如何兼顾？

我问过自己，一边上班、一边带娃还要一边做副业，累不累？说不累是假的。做副业意味着做好本职工作、做好妈妈的同时，要投入更多时间和精力。多数夜晚，等孩子睡熟，我才拿起手机继续处理副业。如何提高效率就成了必修课。我自己总结了一些提高效率、平衡生活的小分享。

（1）善用工具。工具本身是用来提高效率的。比如「讯飞输入法」可以把通用话术或产品介绍都整理好，跟客户聊天效率很高；比如团购产品素材很多时，做好相册夹的图片分类，就不怕找不到实拍图、好评反馈图，快速取用……

[PRE12]

（2）善用人。当利润有一定积累，招个助理吧。我是在去年5月份招了一个大学生助理，负责管理团购素材、售后沟通和需要花时间的素材整理工作。这样极大地解放了我的碎片时间，让我有更多时间拓展客户或者思考生意如何优化。

2、真诚是永远的底牌

当懂得很多销售技巧、运营技巧、文案技巧以后，我仍然吃了一些亏：经历过一个退款后拉黑删除的客户，也经历过一个高复购客户退群的窘境。然后我悟了，只有真诚才是永远的必杀技。于是，我在2022年底给50多个客户手写了新年卡片、寄了礼物。在这个时代，手写信息弥足珍贵。相信客户会感受到我的真诚，只有真诚，副业和生意才能走得更远。

写在最后

这是我副业的经验复盘和总结。很庆幸自己一直在努力往前走，即使会有点累，但看着孩子一天天长大，这两年通过自己努力给孩子提供了更好的生活条件，育儿、主业、副业都没耽误，自认为这份投入非常值得。孩子从来不是阻碍我们追求梦想的障碍；相反，我认为作为妈妈，恰恰是有这个努力的状态，一定可以给孩子更多正向鼓励，成为孩子的榜样。

真要说做对了什么，也许只有一条：像龙哥说的那样，做实战的高手。能出发的时候就动身，心动的时候就放手干，别让想要的东西只停在梦里。
