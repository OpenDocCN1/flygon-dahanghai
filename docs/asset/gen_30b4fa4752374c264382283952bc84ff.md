# 4.3 让创作提速的实用心法

写东西慢，不一定是手笨，很多时候是流程没理顺。想让自己产出更快、更稳，可以从下面几个方向着手调整。

先说素材积累。别等坐下来才想“今天写什么”，平时就把看到的好句子、有意思的观点、能用上的数据随手扔进一个固定地方。攒得多了，真到动笔时，翻一翻就有原料，省掉大量空想的时间。

再就是别追求一次成型。初稿的任务是把想法先倒出来，哪怕句子糙一点、逻辑跳一点都没关系。先把框架搭完，再回头修修补补，比边写边改快得多，也轻松得多。

还有一个容易被忽略的点：把重复动作模板化。开头怎么引入、结尾怎么收、常用的小标题怎么排，提前定好一套固定格式。下次写同类内容，直接往里填，不用每次从头设计版式，省下的精力全留给内容本身。

另外，给自己设时间边界也很有用。比如规定四十分钟只写不查资料，或者一小时必须出初稿。有截止感压着，注意力反而更集中，拖拖拉拉的毛病会少很多。

最后，减少切换。写稿时挂着聊天软件、时不时刷一下消息，思路断掉再捡回来，成本比想象中高。集中一个时间段把干扰关掉，写完再统一处理其他事，整体效率会明显不一样。

说到底，创作效率不是靠硬熬时长，而是靠把流程里的摩擦一点点磨平。方法对了，速度自然上来。
