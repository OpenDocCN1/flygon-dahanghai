**为什么非要让AI先提问？**

因为大多数AI默认处在“你问、它答”的状态。你给出的问题角度，会直接限制它思考的范围。方向一旦跑偏，比如你只问“怎么追热点”，它就会在错误前提里拼命输出，最后给你一份看着完整、实际很难用的方案。

而把提问权交给AI，局面就反过来了，理由有三：

- **你第一次做，AI见过很多次**：你是新手，但AI的训练数据里已有大量相似案例，它知道常见坑和关键判断点。
- **经验要在“被提问”时才会被调用**：在“你问它答”里，AI的经验是沉默的；只有让它来问你，它才会顺着经验追问那些你容易漏掉的细节，比如“你数据表现最好的内容类型是什么？”
- **追问能把隐性想法拽出来**：每个问题都像一次探测，把你脑中已有、但没整理过的念头抽出来。很多需求不是你不知道，而是你压根没想到要说。比如AI问“灵感通常从哪来”，你才反应过来“我都是刷笔记时顺手记的”，这会直接影响Agent的输入来源。

第三步：和AI聊起来，在它的追问里把Agent的核心维度定清楚。

AI开始提问后，你只需要如实回答。它追问的方向，基本覆盖了搭Agent必须想明白的五个维度。你会在对话中不知不觉把它们定下来：

1. 核心痛点：究竟要解决什么问题？别做无用功。
2. 最小范围：眼下最值得先做哪一段？保证能完成。
3. 输入数据：需要哪些信息，从哪里获取？让Agent有材料可处理。
4. 处理流程：中间要经过哪些步骤？让逻辑跑得通。
5. 输出位置：结果最终落到哪里、以什么形式呈现？让结果能直接用。

所以，和AI聊需求的过程，本身就是在设计Agent方案。拆需求这个动作，会把搭建所需的关键信息一并问出来。

输入输出、处理流程、输出位置，并不是你额外要补的能力，它们会在交流与拆解中自然长出来。需求拆得足够清楚，这些内容也就齐了。

走到这里，不少新手会犯嘀咕：“聊完了，然后呢？技术细节我不会啊。”

请记住这个认知：

技术门槛不用你扛。

- 你扮演的是需求方/产品负责人，核心产出是一份清晰的需求定义，也就是上面五个维度。
- AI承担技术落地，负责把你的需求翻译成可执行方案，并生成Agent。

聊得差不多时，你只需要让AI收束成最小方案，再让它去开发Agent即可。

因为AI会结合完整聊天记录理解你的意图，直接给出包含工具、步骤、配置方法的方案。那些“输入输出”“处理流程”的技术实现，由AI根据你的描述自动完成，不需要你另学。

**整套流程可以串成一条线：让AI提问（确认需求）——梳理核心维度——产出Demo——由AI生成Agent**

第四步：把话题收束成最小Demo

聊完后，你可能会得到一堆功能点。但别全做，功能堆得越多，Agent越容易在流程里卡住。

必须收束：把聊过的功能砍到最少，只留最核心的一条链路，先让它跑通。

这就是“最小Demo”：不是最终产品，而是能验证想法、可以运行的最简版本。先做一台能跑起来的样机，确认关键环节没问题，再往上加。

第五步：生成Agent

把Demo交给AI（如Codex、Coze）去搭建，这是最关键的认知转变：你不需要自己动手写一行代码去“搭建”。

拿到Demo后，你只需要：

1. 打开AI编程工具（如Codex、Coze、Claude等）。
2. 把这份“最小Demo定义”文档丢给它。
3. 给出明确指令：“请根据这份需求文档，帮我搭建/实现这个Agent。请生成完整的代码/配置/工作流。”

AI编程工具会理解你的需求，自动生成代码、配置技能（Skill）、串联工作流，把这个Agent给你“搭”出来。你可能需要和它进行几轮调试和微调，但核心生产力是它，不是你。

## 2.3 Agent与Skill是什么关系（拓展内容）

后面章节会出现两个词：Skill和Agent。它们很像，但不是一回事。先说清楚，后面就不绕。

**Skill = 一个单一能力**

比如“把今天的日报总结成结构化要点”，这就是一个Skill。它只做一件事，做得稳定，可以被反复调用。你可以把Skill理解为一个“专项技能”：分析日报是一个Skill，提取小红书爆款标题是一个Skill，把网页正文转成Markdown也是一个Skill。

**Agent = 把多个Skill串起来自动跑的“员工”**

比如：每天定时读取日报.txt → 调用“日报分析”Skill → 把结果写到汇总文档 → 同步到飞书。整条链路不用你点“继续”，它自己从头跑到尾。

在接下来的日报案例中，两者大约有90%是重合的——一个Skill自己也能“分析总结”。

Agent多出来的那10%，恰恰是关键部分：

- 自动输入：自己去读文件/抓网页/拉数据，不用你手动喂。
- 自动触发：定时跑、监听变化跑，不用你每次点开。
- 多步联动：上一步结果自动接到下一步，跨工具跨平台串成一条流水线。

先有Skill，再有Agent，这是搭智能体最自然的顺序。
