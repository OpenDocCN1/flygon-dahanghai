# 7.2 大团队：分工与激励是关键

管理大团队，最棘手的地方通常有两处：任务怎么分、进度怎么控。人数多不等于战斗力强；若职责边界模糊、分工不清，成员就容易抱着“吃大锅饭”的心态，遇事互相推责。

因此，团队规模一旦超过三人，起步阶段就该把项目分工理清，把每项任务落到具体负责人，同时把利润怎么分、激励怎么做提前定清楚。这样，成员既清楚自己该干什么，也有持续行动的动力。

激励上可参考这样的做法：设置部门奖金池，按季度或年度发放；个人奖励沿着从一线员工到部门负责人的业绩链条展开，并且方案要细化到每个人。对一线社群销售，可采用底薪加提成的方式，让其在社群销售中更有积极性。

搭建路径可覆盖团队组建与管理、职责分工、IP 打造、朋友圈经营，以及社群、内容、活动三类运营和商城建设。大团队人员相对齐备、体系更完整，早期就能把内容赋能做起来，这对提高转化率和人效都有帮助。

私域诉求不同，体系搭建方式也会不同，这与团队自身禀赋关系很大。流量见长的团队，应把流量优势充分转化为 ROI 投产表现，重点盯获客成本与转化成本；增长能力强的团队，要设计好裂变诱饵，关注裂变成本，并围绕客户转化设计活动；运营功底好的团队，则要把客户运营做细，深挖长期价值，把客户生命周期管理放在重要位置。
