# 退换货降损：从反馈到差评的应对手册

买家一说商品有问题，先别急着解释，第一步是把证据拿到手：请对方拍清楚问题部位，最好连同外包装、运单面单一起入镜，然后立刻转给供货的上家。举个例子，生鲜店卖出5斤橙子，到货后坏掉近一半；客服当时没马上要“坏果和运单同框”的照片，顾客隔了两三天才重新上线找客服，此时已经超过生鲜签收后24小时售后时效，回头再找上家，对方就可能拿超时当挡箭牌拒绝赔付。碰到这类情况，可以先问顾客愿不愿意接受补发；愿意补发，往往能把损失压下来一部分。ps：质量问题商品图片必须第一时间拿到，才能掌握真实情况，方便和上家交涉。

常规商品的退换，同样要卡时间。📕售后审核一般给48或72小时，淘系、拼多多的审核窗口往往更短；不管平台给多久，都要尽早向上家递交申请，同时先和买家核对清楚：包装拆没拆、有没有用过、成色是否完整。确认这些，再去问供货方能不能退换。📕商家后台还能配置简易自动售后，例如未发货订单自动同意退换。

# 5.3.2 差评：影响与补救

差评目前主要拉低店铺服务分：分高能拿流量加权，分低则可能被清退。更现实的影响在商品转化。📕用户收货后，除非遇到质量问题，通常懒得主动评价；没人引导的话，卖几百单也未必换来一条评价。带图差评更扎眼，图片会直接出现在商品购买页。爆款尤其要把售后做扎实，把差评概率压下去（亲测销售500+零评价）。

平台还看点评回复率：每两个自然周考核一次，负面点评回复率若低于80%，每次扣一般违规积分2分。建议在用户点评后的24小时内认真回复，并真正解决对方反馈的问题。

已有差评产生，可以这样降低伤害：
1）后台申诉。按遇到的问题选择对应入口。
[PRE6]
一般违规，商家要在平台发出违规通知之日起7天内确认调查单或发起申诉；7天内不操作，就视为认可处理，处罚自动生效。同一项违规，线上申诉最多三次。想提高成功率，证明材料要完整、真实、有效：聊天记录、截图、链接、照片、录音、快递单凭证等。细则见《📕违规申诉管理规则》。
2）商品宣传别过度夸大。
3）可致电消费者，请对方补删评论。

# 5.4.2 商品名称禁止使用的词语

商品描述里若出现“最高级”“国家级”“最佳”“顶级”等绝对化说法，每次扣25分；情节严重的，店铺会被冻结。与顾客沟通时，嘲讽、诽谤、谩骂或使用不文明语言，被举报后同样每次扣25分。更多违禁词可查“电商违禁词整理”。

# 5.4.3 食品类产品下单需注意

食品包装必须有标签，标签应写明：一、名称、规格、净含量、生产日期；二、成分或配料表；三、生产者名称、地址、联系方式；四、保质期；五、产品标准代号；六、贮存条件；七、食品添加剂在国家标准中的通用名称；八、生产许可证编号。

# 5.4.4 尽早熟悉流程

非团队作战，有些流程越早摸熟越好。比如拍单软件：单量少时手动打单尚可，订单一多就容易手忙脚乱，效率也低。

# 5.4.5 持续关注产品质量

做无货源时，商品开始零散出单后，建议买回样品看看实物，自己心里有底，售后率也会低一些；同时主动和供货商家建立联系，减少沟通成本。

# 5.4.6 如何辨别和应对打假人

打假人可分三种：要饭的、坐班的、职业玩家。

要饭的：这类多是刚入行或专门找茬的人。套路一，钻平台规则空子：比如平台近期严查无货源，他就举报你，再私下要钱协商；这种通常给点钱就能打发。套路二，走工商举报：有人想捞偏门，甚至卖家被整过之后又去整别人。真遇到工商举报，先听工商工作人员的建议；除非确实是自家产品质量问题，否则不要轻易赔付。可向工商提交情况说明，写清起因、经过，末尾明确拒绝赔付；同时与打假人谈处理方案，一般不难解决。

坐班的：这类人每天批量下单、批量写材料、批量投诉，多数全职靠这行吃饭。他们常盯近期有问题的品类：比如某段时间有关部门明确辣条中不得含谷氨酸钠，他们就集中打这个品，逻辑跟我们追选品热点很像。遇到这种人，如果对方没在客服端提索赔就直接起诉，大概率说明产品真有问题。其投诉方式通常是走工商或发律师函。应对上，可联合同行一起谈；这类人除了换投诉身份，在工商往往留下不少记录。各地政策不同，即便产品有问题，工商面对职业打假人也会考虑从轻处理。再顺着上家源头拿到资质和质检报告交给工商，最终处罚通常不会太重。

职业玩家：这类更专业，一旦遇上，基本意味着产品百分百有问题。他们只走起诉，索赔一般1万元起；若起诉金额在5000元以内，不必应诉，直接电话协商赔偿即可。应对方式是找处理过电商案件的律师应诉，律师会教你怎么用管辖权异议、申请破产清算等办法把损失降到最低。当然，能被这类人盯上起诉，说明店铺最近生意不错，他在动手前肯定看过你的资产足够赔付。

# 5.5 笔记&选品复盘

# 5.5.1 笔记复盘

# 5.5.1.1 看笔记数据

1. 阅读量
发布后2-3小时内阅读量差，或长期卡在100-200甚至不足100，通常有几种可能：账号处于运营初期，权重偏低；笔记违规、踩到敏感词，或内容本身不是平台会大力推荐的类型；选题、标题文案、首图不够抓人，尤其要回头检查选题角度和首图。

2. 赞藏和评论
1）点赞收藏合计超过10、评论却为0，或只有点赞没有收藏评论：说明内容还在被推送，但转化弱。可在评论区引导下单。评论区优化：用其他账号引导购物车，比如刷“惊喜盒子”，或评论“已买”并附购买截图。
2）收藏高于点赞：说明干货偏多、种草偏少，需要调整。优化方向：补充产品使用场景，或用文字完善产品相关信息。

# 5.5.2 选品复盘

# 5.5.2.1 先看选品是否符合爆品标准

第一步：看销量。月销大于1w，且多家店铺都在卖，说明是爆品，相关爆款笔记也多。近期销量100-500，在售店铺少于5家，说明是近期爆品，少量商家发笔记就能拿流量。月销1000-3000，在售店铺不超过3家，说明是少量自有货源品，或投流产品。以裤子为例：在商城搜“裤子”，筛出高销量产品，点同款进对标账号店铺看笔记时间，再进账号主页看爆款笔记的时间周期做分析。
[PRE15]
第二步：分析该品的笔记数据。按上面的标准点进店铺，再看账号笔记数据。以下是选品实测参考：笔记发送数据近7天，销量1000+，爆品率80%；近30天，销量10000+，爆品率50%；近90天，销量10000+，爆品率20%。怎么找爆品跟品？还是以裤子为例：📕商城搜“裤子”，看到店铺销量1w+，且近期加购1000+（最好看24小时加购），就可以跟品发笔记，出单概率较大。

# 5.5.2.2 结合对标账号爆款进行选品分析

找对标账号时，重点看选品周期。3-90天内的爆款，要及时跟款。什么是选品周期？3-7天内，对标账号的高销量品属于实时爆品；30-90天内，对标账号的高销量品属于📕需求品，生命周期更长，还会再爆。若是当下应季类产品，参考周期要相应缩短。

# 章节概要

当你对选品有一定体感、订单也能持续，想再提升笔记质量，就可以开始实拍。实拍没想象中难：新手前期用低成本布景加苹果手机拍摄，后期制作也很简单。接下来，进入实拍环节。

# 本章航线图

完成本章学习和实操，就能完成航线图中的：
第五阶段：【实拍】有持续流量后开始实拍（7天）
1. 首次下单1个样品，拍图（约3-4天）
2. 模仿5个爆款笔记，拍出≥15张图（约3-4天）

# 6.1 下单货品（物流1-4天）：样品与借样

产品持续出单后，新手第一批可下单3-5个品的样品，用来拍实拍图。下单样品步骤：
第一步，确定要下单的选品。
第二步，跟供应商沟通“借样品”，先转账付货款（快递费也自己承担），并留好货品清单【如果前期借不到样品，跳到下一步】。
第三步，找身边朋友从自己店铺下单，再由上家发货；这一步做数据对后续出单很重要，建议都做。尽量让朋友下单并寄到你家，别用自己的账号下单，主要担心没有IP隔离。
收到货后正常拍摄，多拍live图和视频，不同场景多拍几条。
最后，让朋友账号确认收货、好评，并用你拍摄的素材发一条晒单笔记。

注意事项：
1. 样品下单环节，直接在自己店铺拍单即可；
2. 供应商那边，若想长期合作，可确认对接流程：是加🛰️下单，还是走ERP下单。两种方式区别：🛰️下单可避免二次面单被平台判无货源；ERP下单适合单量多时，商家能看到你店铺后台订单后直接发货。新手前期单量少，直接走🛰️下单即可。
