# 朋友圈，不只是相册

朋友圈不是随手一发的图片仓库，它更像一张会说话的个人名片。你想让别人记住什么，就要有意识地放大什么。

有人靠细节控出圈，有人用严谨建立信任，有人传递温暖的生活态度，也有人走高级酷拽路线。风格没有优劣，关键是别飘忽不定。总要有一个清晰的主色调，别人才能迅速识别你、理解你。

[PRE0]

在这个基础上，整体观感不能丢。别把未经筛选的图片一股脑往外发，适当修饰，让画面干净、清楚、有质感，朋友圈才会显得高级。

排版也要替读者考虑。一段话尽量别超过三行，句子长了就在舒服的位置断开，段落之间留点空白，读起来才不费劲。

表情符号同理，适量就好。我自己一天的朋友圈通常只放一两个表情，多了容易乱；偶尔用一下，反而能调气氛。

但也别走极端。为了统一对齐，或者每条都硬塞一个符号，本质上是另一种强迫症。整体给人简约、不浮躁的感觉，就已经很好。

最后拼的还是文案力。真正能打动人的文字，是高质量朋友圈的标配。少发复制粘贴的广告，多练原创表达。坚持写下去，你的文案能力会一点点长出来。

想做“有料”的朋友圈，先弄清楚料从哪里来。硬知识、可落地的方案、行业动态、个人判断、亲身经历，都是好素材。持续输出，你在这个领域里的专业形象才会立起来。

一个专业 IP 往往自带意见领袖气质。别人先信你说的话，成交才会顺理成章。

再往深一层，光有知识还不够，还要能给方案。用户真正关心的是：你能不能解决我的问题。所以围着痛点发圈，是必备动作。

这类内容可以用麦肯锡的 SCQA 模型来搭：
S 是 Scene，先把痛点发生的场景描出来；
C 是 Conflict，再点出这个场景里的冲突；
Q 是 Question，抛出疑问，让用户想知道怎么破；
A 是 Answer，给出解法，顺势把产品带进去。

这样写，用户愿意往下看，购买欲也容易被激活，成交自然更顺。

行业动态也要跟上。多留意领域热点、大事件，或者跟你产品相关的新新闻，这些都值得发。比如我教📕，平台规则和玩法一有变化，我会第一时间分享到朋友圈，大家自然知道你在这块是专业的。

时事热点、热门资讯也可以聊，大众娱乐同样能发。任何一种观点表达，都会透出你的判断力。

再往下一层，是故事。个人品牌故事一定要写，讲讲自己一路创业的酸甜苦辣，别人能更快认识你、欣赏你。也可以写合作伙伴、客户的故事。人都爱听故事，故事能迅速拉高朋友圈的可读性，也会让用户更立体地感受到你的 IP 温度。

趋向高级：从卖产品，到卖生活方式

产品越来越同质，价格也越来越接近，想站稳脚，营销思路就得换。不能还像过去那样，朋友圈里只有产品、早晚安和使用感受，那种不痛不痒的刷屏很难起作用。要站在用户视角，改卖“生活方式”。

什么是生活方式？官方说法里，它约等于生活形态，包括社会关系模式、消费模式、娱乐模式和穿着模式，也反映一个人的态度、价值观和世界观。

放回私域营销里，说白了就是：你是谁，你在做什么，你持什么态度，你过着怎样的生活。而这种状态，恰好是消费者期待和向往的。

怎么做出有“生活方式”的朋友圈？

1）展示生活状态。多分享生活，让用户看到自己向往的状态，引发情感共鸣。卖香薰精油，可以呈现和爱人在香气里听音乐的片刻；做收纳师，可以展示日常里的“断舍离”；全职创业者，可以呈现咖啡馆办公、居家工作的自在感，吸引想一起做事业的人。

[PRE3]

2）把产品宣传嵌进生活方式。呈现生活时，巧妙带出产品，宣传就不生硬。记住一个公式：生活场景+人物+故事+产品在其中的作用。多写产品在这个场景里帮了什么忙，用故事化表达让人身临其境。我不少学员靠这招在私域爆单。比如卖梨膏的学员，常发孩子生病咳嗽的场景：本来哭着不肯吃药，尝到甜甜的梨膏后不哭不闹，还追着要吃。很多妈妈被触动，意识到家里该备一瓶润肺梨膏，订单就来了。

3）生活方式不等于一味“美”。有人把生活方式理解得太窄，以为只有小资、岁月静好才算，于是刻意发美图、营造美好，反而容易显得“一眼假”。生活方式可以很丰富：有人偏爱轻奢，有人喜欢田园；有人自律积极，有人就爱懒散度日。关键是真实，并且能长期一致地呈现，这样才能吸引同频的人。

4）真诚永不过时。朋友圈是连接你和顾客的纽带，真诚永远是最有效的武器。一条走心分享，一句肺腑之言，通常比随手复制粘贴更打动人。多写原创，那些素未谋面的客户，也会从文字和图片里感受到你的真诚，慢慢对 IP 建立信任。

2023 年的私域营销，不再是产品为王，而是以“你”为王。这个“你”，对用户来说，要真实、生动、亲切，像朋友，也像他们喜欢和向往的理想自己。学会在朋友圈呈现生活方式，就是让赚钱这件事变简单的财富密码。

### 5.1.2 高级 IP 朋友圈的底层公式

我理解的“高级”，不是高高在上，也不是让人够不着的仰望。它应该让受众看到 IP 的权威与实力，感受到有思想、有个性的态度，同时又能体会到亲近用户的温度和人格魅力。

公式可以写成：高级 IP 朋友圈＝权威+实力+态度+温度+人格魅力。发圈时围绕这几块发力，吸粉力和成交力都会上来。

权威：资质方向的内容。权威是告诉大家：你有什么背书，有什么经验，为什么在这个话题上有发言权。用户不会平白无故相信一个陌生人，除非你确实做出过成绩。所以先让人知道：你有资格说。可以多分享自身经历、做出的结果，也可以多发专业相关信息，证明你的权威和专业度。适合发：个人经历、成绩、奖项荣誉、行业资讯。

参考案例里，个人经历建议都写一写，整理成一篇个人品牌故事，用户认识你会快很多。

自己亲手做出来的成绩，更要多晒。亲身实践就是最好的证明。我做个人 IP 创业综合指导，其中包含📕教学，所以朋友圈也会分享📕后台精准咨询的成绩。

实力：专业方向的内容。朋友圈要展示实力，这类内容也最容易带来成交变现，建议占到朋友圈的一半左右。但注意，不是一味夸自己多牛，而是要展示：在你的帮助下，用户变得有多好。别自嗨，多从价值出发，借用户的口说出你的厉害，而不是自卖自夸。适合发：成交晒单、交付过程、用户反馈、结果展示。

## 5.2 怎样做出「有个性」又能「自动成交」的朋友圈？@理白

所谓“有个性”的“自动成交”朋友圈，得有足够的内容水准、充分的情绪价值，还要有鲜明的个人特点。这样的朋友圈有自己的内在逻辑，不容易被抄袭模仿，一眼就能看出强烈的个人风格，也更容易实现“自动成交”。

做到这一步，发完朋友圈就可以把精力放到交付、公域引流或开辟新赛道上，等用户自己转账付费，形成成交闭环。

想打造这样的朋友圈，需要几个基础条件：表达欲够强，有持续输出的欲望；内容力达标，具备基本的观点表述力；肯暴露缺点，因为有个性的代价之一就是被误解；前期有时间，愿意花一段时间打磨。

以“理白”这个 IP 的朋友圈设计为例，从三个方面讲讲怎么做。

### 5.2.1 谋篇：讨喜的人设怎么搭

主人设是价值人设。它指的是：你能给别人提供什么价值。这个价值可以是内容价值、干货价值、专业价值，甚至陪伴价值。它是你能卖出去、能给自己标价的重要基础。

有些职业自带人设，比如律师、医生、教师，专业背书就是权威 BUFF。有些身份也有人设，比如打工人、宝妈、程序员，他们代表某个群体，群体背景就是共情 BUFF。

比如我把主人设凝练成两部分：一是自媒体变现成就，二是精力管理成就。两者合在一起，就是个人品牌传达出的“乐活创富”概念。朋友圈里，就要持续给出这样的人设价值。

### 5.2.2 布局：让内容不单调

布局要分宏观和微观两层看。宏观上要有大局观，微观上要有颗粒感。所谓大局观，就是技术和艺术都要具备；所谓颗粒感，就是粗放和细节能够共存。

大局观，说到底就是技术和艺术皆备。
