# 4.1.2.1 搜索流量≠免费流量

用户通过搜索引擎进入网站，这类访问构成了搜索流量。它通常分成两块：自然搜索与付费搜索。

[PRE0]

图中红色柱体显示77.28%，它代表搜索渠道在总流量中的占比。别急着把这个份额全部归到自然搜索头上，里面很可能有相当一部分来自付费搜索。

换个角度想：别人能通过付费方式把排名做上去，你同样可以尝试；用户第一次接触产品前，体验就像拆盲盒，只要ROI能做到不亏，你也有机会跑通。

以在线PDF编辑工具PDFfiller为例，它每月访问量达到13.7M，搜索渠道贡献77.28%。其中自然流量占60%，付费流量占39%。这个付费占比很高。拿14M月流量粗算，搜索部分若接近七成，约1000万；这1000万里付费搜索按四成计，约400万付费访问，体量相当惊人。

[PRE1]

对方在投广告，这恰恰提醒我们别忽视广告；即便只擅长投放，也有机会从这块市场切走一块。400万里拿下100万，足以支撑一个团队。这就是分析数据能带来的实际收益。

另一个站点Top10.com月流量3M，约九成来自搜索，基本可视为搜索驱动；其中六成是付费，说明它主要靠广告盈利。感兴趣的朋友不妨看看，它本质上是一个广告套利站点。

[PRE2]

它的做法是：自己整理榜单，比如十个最佳域名服务商、主机或其他产品；再从谷歌购买广告，把流量导向代理产品，成交后赚佣金。只要佣金超过付费搜索成本，就能盈利。这门生意规模不小：月流量3M，付费广告流量超180万；按单次访问至少0.5美元估算，单月广告支出达数十万美元。

再看PDF editor online，月流量180k，其中60%为付费。若做一个具备类似功能的站点，直接靠广告投放就能变现。ROI若能打平，已经非常理想，因为广告投放确定性较高、反馈即时。当然，在线PDF编辑目前仍有难度；一旦做出来并能靠广告打平，这门生意值得做，产品研发投入也没有想象中那么高。
