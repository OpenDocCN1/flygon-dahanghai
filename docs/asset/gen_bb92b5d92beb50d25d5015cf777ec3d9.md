# 9.3.2 渠道 2：去 Web3 招聘站找机会

想高效收集 Web3 岗位，聚合型招聘站点值得常逛。这类平台把分散的招聘信息汇总到一起，是获取机会的有效入口。以 Web3.career（web3.career）为例，进入首页即可浏览近期新增职位，其中不少岗位明确支持远程办公。

[PRE0]

职位分类上，技术岗、非技术岗和兼职岗都有覆盖。页面还会突出薪资较高或关注度高的机会，比如排在前面的开发岗，年薪可达 70 万至 75 万美元，竞争力很强。

非技术方向则包括市场拓展、社群运营、增长、HR、战略、营销等，年薪大致在十几万美元到几十万美元之间。设计类岗位涵盖产品设计、基金设计等，许多同样允许远程，年薪从几万美元到 20 万美元不等。

这些岗位的要求，基本可归为两类：岗位能力与行业能力。岗位能力指底层工作素质，和 Web 几没有直接关系；不论你做商业拓展、增长，还是产品、运营、营销，这类能力都能迁移。行业能力则是对赛道的理解。学完本手册，你应已建立初步认知。Web3 仍处早期，入行门槛没有想象中那么高，学习能力强的人有望较快进入。

我身边就有朋友在 2021 年入行，2022 年其所在 Web3 项目成功上市，这正是新兴行业给个人带来的机会。之后，你可以通过加入团队、参与项目、持续学习，不断提升行业认知。
