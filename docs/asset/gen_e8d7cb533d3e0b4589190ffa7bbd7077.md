# 配置不绕路：Claude Code 快速启用指南

先记一句话：模型换了，ANTHROPIC_BASE_URL 也要跟着换。推荐用终端工具 zcf 来配置；刚上手别自己手动改配置文件。

在终端执行 [PRE1]，敲 y 并回车，就会进入终端配置器。语言选 1 简体中文，用上下键切换，选定后回车。[PRE2]

先只做一件事：配置 API。输入 3 回车。按一次⬇️，切到“使用 API Key”，回车。[PRE3]

把刚拿到的 BASE_URL 粘贴进去，回车；再填 API_KEY，回车。配置完成后按 n 回车，退出 zcf。重新打开终端，输入 claude 回车。

关键提醒：走 API 的话，要把选项切成 Yes，否则你配的 APIKEY 不会生效。[PRE4]

对话框出现，就说明 claudecode 已经成功打开，可以开始用了。

# 1.关于充值Claude的方法说明

如果你能搞定网络（静态 IP 或住宅 IP，不推荐🪜），支付方式这里也讲一下：国内银联信用卡/visa/运通卡，以及香港卡（汇丰/众安/天星等），直接在 claude 网页上不行，需要美国卡或其他地区的卡。

# 方式一：安卓+google play（礼品卡）

条件：安卓机（推荐 google pixel）。家里的荣耀反正不行，我海鲜市场买了 pixel 2，大概 250，原生谷歌系统，可以用。群友验证：一加可以。国内其他机型没测试，不敢保证 google play 服务好用。注意支付时谷歌邮箱可能需要开 2FA、绑电话等，留意这些事项。

支付方法一：google play 支付。我绑的是香港众安卡、天星银行等卡（肉身去香港就能开，很方便）。群友也有绑国内银行 visa 卡或运通卡成功的，支付应该也没问题。国内银联卡没试过，基本可能不会成功；谷歌苹果这些国际服务基本认 visa/运通，银联是国内服务，可能别人不太友好。

支付方法二：礼品卡。也可以去买礼品卡，我之前用过的网站可以买：https://www.seagm.com 。注意绑定礼品卡兑换时仍需要电话验证，谨慎购买，避免兑换不成功。

# 方式二：IOS+礼品卡

条件：苹果手机、美区 Apple 账号（自己注册或咸鱼搞定）。

支付方法二：礼品卡（推荐）。也可以去买礼品卡：https://www.seagm.com ，也可以支付宝购买，网上搜索就能找到。

支付方法一：apple 支付。美区的 apple 支付不直接支持国内银联/visa 卡和香港卡。绕个弯：使用美区 apple 账号，绑定美区 paypal，美区 paypal 可以验证香港众安银行卡。注意美区 paypal 需要使用美国电话卡（实体电话卡），不然很容易封号。经群友验证，美区 apple 账号绑定美区 paypal 时国内卡验证不通过，可以联系苹果客服解锁。

上面讲的都是 claude app 上的订阅（也就是安卓手机和苹果手机上走 claude app 订阅）。收费情况：max 套餐会多收 25% 的税，20 刀套餐无税，实际支付 20 刀；100 刀套餐实际支付 125 刀；200 刀套餐实际支付 250 刀。所以官方网页方式虽然 max 不收税，但支付比较难；claude app 目前是可以跑通支付的方式。网页支付要么海鲜市场代付（风险高、虚拟卡等、跑路风险），要么找自己朋友有卡的支付。另外提醒：AI 产品更新迭代速度太快，不太建议年订阅，除非你有钱；不然建议月订阅（最近应该很多退订 Cursor 年订阅的用户吧）。

# 方式三：虚拟卡

目前野卡不能使用，还可以使用的是飞扬卡和 bybit 虚拟卡，可以直接网页支付。优点：不用交 25% 的税。缺点：流程比较长，对网络环境要求比较严格，还涉及 USDT 的购买，此处略掉万字，自行斟酌。各方面考虑，此处不宜写很详细的方案，需要探索性很强的同学尝试。
