冷启动阶段最缺的就是第一批用户。有一个取巧的办法：把产品的访问数据公开晒一晒，能吸引一批好奇的人搜过来。这些人未必是你的目标用户，但用来填满500个启动用户足够了。比如可以发一条：“刚上线的应用，怎么一点自然访问都没有？有没有有经验的同行帮我看看原因？”只要有人去搜索你的产品，微信就会注意到这个动作，可能帮你推送一些自然访问。不过，等产品做起来之后，别再把收益和指标到处晒；就算要晒，也不要暴露产品细节，否则被同行看红眼了，抄走你的创意只是一晚上的事。

把公域访问者变成自己的资产，要从建群开始。公号、小红书、抖音，都能建群。建群不等于一定要导流到个人微信，在各平台建自有用户池也行。关键在于要有这个意识：尽早把用户圈进来，深入了解他们的反馈。这样你才能判断产品是不是真的被需要、能不能长期留住人、还有哪些需求没被满足。更直接的手法是在应用内放群号文档，或者用客服引导用户加群。

### 02. 微信内推广：双号组合拳

产品做完只是走完一半，另一半是让人用起来。在微信平台上做推广，不需要贪多，抓住两个号就够了：图文号承担轻量的日常触达，公号承担深度的种草和信任建设。两个号分工不同，节奏咬合，就能构成完整获客闭环。下面按执行顺序讲。

[PRE0]

1.图文号：把应用做成一组“种草卡片”

图文号就是微信里的图文推荐流。它不需要粉丝基础，每篇笔记就是一张独立门票——发出去就进入公共推荐池，能被多少人看见，完全取决于内容本身。

[PRE1]

1.1 先搞清楚：访问者凭什么停下来

推荐流里，一分钟可以刷过几十条内容。你的那条凭什么让人停手？唯一的答案是：和他有关。不是和你有关，不是和功能有关，而是和此刻正在刷手机的人有关。他正为某件事发愁，或者对某件事好奇，你的内容刚好撞上他的状态。所以写图文号时，不必想“所有用户”，而要想着某个具体的人——一个在真实场景里遇到了具体问题的普通人。

1.2 五种内容路数，拿来就用

下面用一款“猫咪喂养管家”来举例，你可以替换成自己的产品。

第一种：替用户说出“好烦”。先把麻烦讲得让人感同身受，再亮出解决方案。

“去宠物店买猫粮，看到配料表直接懵：粗蛋白、粗脂肪、灰分……到底多少算好？后来发现有款工具，拍一下配料表就出分，不达标的成分标得清清楚楚。选粮终于不用靠猜了。”示例截图放拍照识别界面和评分结果页，关键数据圈出来。

第二种：抛个反直觉结论，让用户忍不住自己验证。

“我家猫的喂食克数竟然一直多了30%，难怪越来越圆……不信你试试，填上品种和重量就能算出来。”示例截图放超标的数据对比。看到别人家的结果，下意识会想“我家的呢？”

第三种：时间线记录。用时间维度展示持续使用的效果。

“用喂养管家调食谱两周了。左边是之前的体检数据，右边是复查结果，变化最大的是毛色和精神状态。”示例截图做一张前后对比拼图。这种内容的说服力比任何广告都强。

第四种：清单盘点。用“你可能不知道的N件事”制造信息差。

“养猫第一年才搞懂的4件事：①猫粮不是越贵越好，看前三位原料就行；②每天喝多少水可以推算；③成长各阶段的营养需要差别很大；④驱虫日期靠记性肯定忘。这些事我现在交给一个小工具。”每张图对应一条知识，末尾放应用界面截图。

第五种：评论区互动型。把用户拉进对话，用评论量撬动更多曝光。

“做了一张猫咪分阶段营养需求表，你家猫现在在哪个阶段？评论区留品种和年龄，我帮你查建议食谱。”这篇笔记的核心不是直接导流，而是先把评论区养起来。回复的时候顺带说一句“用XX管家可以一键生成食谱”，比在正文里硬推自然得多。

[PRE3]

1.3 首图决定生死

图文号里，首图就是门面。用户决定是否点开，只有零点几秒。首图要一眼看懂在讲什么。如果是一张密密麻麻的截图，用户看不清就会划走。要么放大关键区域，要么做一张带大字标题的图。手机自带的标注工具就能画箭头、加文字。颜色也要跳出来。推荐流的背景是白色，浅色系的图会被吞掉。用饱和度高的颜色做底色或边框，制造视觉冲击。不要用纯文字当首图。带图的封面点击率远高于纯文字，哪怕是一张截图配三个字，也好过一段文字配白底。

1.4 话题标记怎么选

话题标记的作用是帮平台理解该把内容推给谁。用两层结构选：一层是品类词（“养猫”“猫粮”“宠物”），一层是内容类型（“实用工具”“生活技巧”“经验分享”）。两层交叉，平台就能精准匹配到感兴趣的人群。每篇笔记配三个话题标记，不多不少。太少匹配不准，太多让平台困惑。

1.5 节奏比灵感重要

不要等想出了“好内容”才更新。把上面五种路数排成一张轮换表，周一套路一，周二套路二，周三套路三……循环使用。素材不够时，同一个套路换个数据、换组截图就是新内容。固定时间发布也有好处，算法对有规律的创作者会给更稳定的基础推荐，而不是让你的流量忽高忽低。

2.公号：用长文建立信任，把信任变成转化

图文号解决的是“让人看见”，但看见不等于信任，更不等于持续使用。公号要做的是完成从“知道”到“信赖”的转变。用户可能已经在图文号里看过你的应用，觉得有点意思，但还没下定决心深度体验。这时如果他再看到你公号里一篇长文，把产品的来龙去脉和应用价值讲清楚，他大概率会认真试一次。而且公号自带变现能力——阅读量上去后，文内的广告分成本身就是一个收入来源。推广产品的同时，内容也在赚钱。

2.1 选题核心：写用户愿意主动搜索的问题

公号文章和图文号内容的区别在于，公号文章更容易被搜索。优质文章不只是发布那天有阅读，以后还会被反复发现；用户关注后，你每次更新都会出现在他面前。所以选题要瞄准“用户愿意主动搜索的问题”。继续拿猫咪喂养管家举例：

• 幼猫每天到底喂几顿？按月龄对照
• 怎样快速看懂猫粮配料表？三步避开劣质粮
• 猫咪体重超标没？一张对照表帮你判断

这些题目本身就是搜索词。用户遇到类似困惑，第一反应是去微信的搜一搜里找答案，你的文章精准命中，点进来的概率自然高。

2.2 文章结构：三段式就够

开头段：触发共鸣（100字内）。不要写“很多人不知道怎么养猫”，要写“上周抱回来一只两个月大的英短，站在宠物店猫粮货架前完全愣住了——二十多个牌子，价格从30到500，到底该买哪个？”主体段：给出方案。用清晰逻辑把干货讲完，并在关键步骤处自然插入应用卡片。比如讲到“按体重算每天喂养量”时，直接插卡片，写一句“点一下，填上体重自动算”。用户读到这里，逻辑是通的，点卡片是顺手的事。收尾段：留出开放式结尾。结尾抛个问题或预告下期，让用户留言或关注。“你家猫平时吃哪款粮？踩过坑的评论区聊聊，下期我细说避坑经验。”全文800字左右。微信会统计读完率，800字是大多数人能耐心读完的长度。写太长读完率下降，推荐算法对文章的评价也会变差。

[PRE4]

2.3 题目决定成败

推荐流里，用户只能看到题目和首图。题目不行，后面再好也没人知道。几个经过验证的结构：

数字+具体问题：“猫粮配料表里的5个关键指标，看懂不再被忽悠”——数字给人确定感，具体问题让人判断与自己是否有关。

反常识：“兽医说90%的猫主人都在过度喂食”——挑战既有认知，让人产生“我会不会也这样”的冲动。

时间+承诺：“3分钟看懂猫粮配料表”——降低阅读心理门槛。

避坑/排雷：“新手养猫最容易犯的喂养误区，我全部踩过”——人对避免损失的兴趣天然大于获得收益。

题目里尽量包含目标用户会搜索的关键词。这不仅帮助算法理解主题，也能让文章在微信的搜一搜里拥有更长的生命周期。

2.4 曝光规模怎么放大

微信的推荐机制是分轮筛选：先给一批基础曝光，看点击和互动；数据好了，放进更大的池子，再看一轮；如此递进。你能控制的有三个环节：

打开率：靠题目和首图。首图建议横版16:9，内容与题目呼应。比如题目讲“怎么看猫粮配料表”，首图就放配料表特写加标注，不要放一张可爱的猫咪照片——好看但不相关。

读完率：靠内容密度。开头别铺垫太久，前两段就要给出干货。用户的耐心是递减的，你越早兑现题目的承诺，他越愿意读到最后。

互动表现：靠结尾设计。单纯说“觉得有用就点赞”效果一般。更好的方式是抛一个让用户有表达欲的问题。“你家猫最爱吃什么粮？”比“觉得好就转发”能带来更多讨论。有讨论就有互动数据，就有更大的曝光。

3.双号协同：互相输血

图文号和公号分开做是两个渠道，合起来就是一套有飞轮效应的系统。

3.1 图文号当公号的选题测试。不确定某个话题能不能火？先在图文号发一则轻量笔记试水。如果收藏和互动明显高于平时，说明这个方向击中了需求，围绕它写一篇公号长文，大概率也不会差。这比拍脑袋选题高效得多。图文号就是你的AB测试场，这些笔记都是不花钱的调研。

3.2 公号当图文号的素材库。一篇公号长文的信息量，足够拆出四五条图文号内容。一篇“猫粮选购指南”，讲蛋白质的那段拆出来是一条，讲添加剂的那段拆出来又是一条。同一套知识，长文在公号发一次，碎片在图文号发五次，覆盖的人群不重叠。

3.3 互相引流的操作。图文号结尾加一句：“完整的选粮方法我写成了一篇长文，在公号里搜索‘养猫指南’就能找到。”公号结尾加一句：“我每天在图文号分享养猫小知识，关注XX就能看到。”不是硬推，而是用户在已经对你产生兴趣时，告诉他还有另一个入口。

4.首月执行排期

进入稳定期后：图文号保持日更，公号保持周更。别追求单条爆款，重点是持续出现在推荐流里，用时间换覆盖面。

5.执行的几个认知校准

内容不必完美了才发。你花两小时磨一条和花十五分钟随手写一条，在算法面前可能得到差不多的结果。算法看的是用户反应，不是你的制作精度。先发出去，再逐步提升。

同一卖点可以反复讲。你觉得重复了，但每天刷到你的用户是不同的人。对他们来说，每一次都是第一次。别怕重复，就怕你自己先腻了。

数据有滞后性。今天发的内容，可能三天后才开始起量。不要因为当天没反应就否定它。一周后再回头看，可能有惊喜。

推广了很久还是没人用，先检查产品。推广解决的是“没被看到”，解决不了“看到了却不想用”。后者是产品层面的问题。当你确认曝光足够但转化始终上不去，与其继续放量，不如回头审视产品是否真正解决了真实存在的问题。

最后一句：推广没有捷径，只有积累。你今天发的所有内容，都在为未来的某个用户铺路。路铺得越长，护城河越深。

## 关卡 7：反馈决策：用数据判断下一步

### 00. 本章任务

目标：基于真实数据和用户反馈，判断这个应用要继续做、迭代、换推广方式、换方向，还是先放一放。

任务：
1. 接入或查看数据分析工具，比如官方数据分析能力、后台数据或用户反馈记录。
2. 重点关注新增用户、用户来源、留存/复访。
3. 判断有无自然搜索流量：如果很弱，回去检查名称、关键词和用户搜索习惯是否匹配。
4. 判断有无自来水传播：如果分享来源很弱，思考产品里有没有值得转发的场景。
5. 判断用户是否真的需要：有人打开但留不住，要分清是推广不够还是需求不强。
6. 最后给出明确结论：继续、迭代、换推广、换方向或暂停。

PS：这一关是选修，不用交作业。它更像一次产品复盘，帮你从“我觉得还行”切换到“数据和反馈说明了什么”。

### 01. 具体步骤

在微信里接入官方数据分析工具，手机上就能实时看数据。重点关注三个数字：每天新增多少用户；新增用户来自群聊、搜索还是单聊；用户进来之后有没有留下。拿这几个数字做三个判断：

1. 有没有自然搜索流量。如果没有搜索，说明产品可能吃不到搜一搜的红利。可以结合微信的搜索热度参考，找一些搜索量高的关键词，把它们放进应用名称或题目里，提高与用户搜索词的匹配度。

2. 有没有自来水传播。如果群聊、单聊等渠道的分享很少，就要设计任务机制或强化分享按钮。比如用户完成核心功能后，把分享提示弹出来；或者设置任务卡点，转发后才能解锁。用分享带来裂变。

3. 是不是高频刚需。如果产品是工具型、留存不高，就必须持续找新流量；如果用户经常回来打开，广告收入就有保障，重点是拉新和借助老用户推广。可以运营活跃社群，和粘性用户建立关系，设计一些福利奖励，让他们主动帮你做增长。

## 关卡 8：变现闭环：开通收入路径

### 00. 本章任务

目标：根据产品类型、用户规模、主体资质和当前反馈，选一条适合现阶段的变现路径。

任务：
1. 先判断现在适不适合变现：已经有人用，还是继续验证需求。
2. 如果适合靠流量赚钱，优先了解微信的广告分成功能，确认是否满足开通条件。
3. 如果适合会员、订阅、付费功能、课程、工具额度或服务交易，再判断主体资质和支付合规是否支持。
4. 变现入口放在用户感受到价值之后，不要一打开就打断核心体验。
5. 最后明确下一步：现在开通、先补资质、先继续攒用户，还是暂时不变现。

PS：这一关不是要求所有人都开广告分成，也不是要求所有人都做订阅。新手从试错成本最低的路径开始，关键是选对适合自己产品的收入方式。

### 01. 微信流量主（新手推荐）

为什么新手先选流量主：试错成本最低，不需要企业资质。跑通后想加付费功能，再把个人号升级为个体户/企业号，之前的认证费不会白花。开通条件也简单：累计独立访客数达到500，且无违规记录。满足后在后台的“推广-流量主”里申请。

**1. 广告类型和收益**

[PRE5]

开通后你会看到好几种广告形式，重点关注这三种：

开屏广告：用户启动应用时看到的全屏广告。这是收益大头，单次展示约0.5元。很多新手不知道开屏广告要单独开启，白白少赚了不少——开通后第一时间确认开屏广告已打开。这一点要反复强调，因为踩坑的人真的很多。

视频激励广告：用户主动点开15-30秒的视频广告，看完后获得某个功能或奖励。单次约0.2元。适合放在解锁高级功能、查看完整结果这类节点——用户已经体验到了价值，愿意用看广告换更多功能。

页面切换时弹出的半屏广告：单价不高，但胜在自然，不需要用户主动触发，适合做补充收入。

横幅广告收入最低（一次只有几厘钱），如果影响美观可以不开。

**2. 两种接入方式**

2.1 免开发智能接入（新手首选）

2.1.1 开通后会弹出广告接入方式。首个应用直接选“智能接入”即可，不用改代码，广告就能直接展示。

[PRE6]

2.1.2 扫描弹出的应用码。扫描后手机上会打开应用，并自动计算广告位的位置。

[PRE7]

2.1.3 在手机上调整广告位和样式。选好位置和样式，点击确认使用，再点击完成。

[PRE8]

2.1.4 确认广告位。点击下一步后会出现刚创建的广告位，确认没问题就开启。

[PRE9]
