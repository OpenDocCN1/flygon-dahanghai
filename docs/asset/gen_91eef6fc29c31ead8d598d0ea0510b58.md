# 8.6.4 投后数据，重点看什么？

广告上线只是开头，接下来真正要盯的是数据。我通常抓两块：投放监控和竞品分析。

**1、投放监控：先盯这些数**

有几个指标平时不常翻，但不能忽略。

1）展示频率。公式是 Frequency＝Impression/Reach，意思是同一用户平均看了几次广告。当点击率下滑或消耗变慢时，就该回头查这个数。通常 2.5、3.5 以内都还能接受；一旦超过 5，别舍不得，关掉或换素材。

[PRE0]

2）点击率（CTR）和转化率（CVR）。有代投的话，可以问他们该品类的平均水准，拿来衡量自己的投放结果。

- 点击率高、转化率低：点击率高说明素材抓人，立刻收进素材库作为方向。先确认 CPM 是否正常；CPM 明显异常，多半是投放跑偏了。CPM 正常但转化率仍低，就按性别、年龄、版位等维度拆分，判断问题是否不只是素材在诱导。若还是看不出原因，复制一条计划，换兴趣或出价再对比。
- 点击率低、转化率高：看最终成本。成本合适的话，0.05% 的点击率也可以是好素材。
- 点击率低、转化率也低：人群不匹配、素材不给力、Frequency 偏高，皆有可能，建议重新寻找投放方向。

3）版位。Facebook 通常分 Facebook、Instagram、Messenger、Audience Network 四大版位，更细的版位可以自行探索。除 AN 外，其余都是 Facebook 自有流量；AN 是 FB 的三方开发者流量（比如通过 Facebook 做广告变现）。成本和消耗异常时，来这儿看看。

[PRE1]

4）广告质量排名。参考一下即可。FB 会结合广告质量、转化率排名和参与度排名，决定给你加量提速还是缩量降速；真想解决，直接抬高出价就行。

[PRE2]

再说日常监控。核心指标是花费（Costs）、主要 App Events 和收入，并用收入算 ROAS。数据来源可以是 MMP（如 Appsflyer）、广告平台直接导出，或者自建 BI。收入比较敏感，未必愿意交给 MMP，那就自己搭个 BI 看数据（听我的，代码让 ChatGPT 写，行不行？）。

[PRE3]

如果嫌折腾，也可以直接用 Google Data Studio。它支持自定义数据源，所以这块看板不只能盯广告，SEO、产品用户漏斗等同样能用 DS 搭出来。

**2、竞品分析：亲自刷广告**

竞品分析怎么做，星球里的相关帖子不少，我就不铺开讲。今天只推一个笨但特别管用的招：自己动手刷广告。

别嫌刷广告效率低。再贵的广告 Spy 工具，也比不上你亲手刷到的 Facebook 广告及时，尤其是点赞、评论都多的那种。遇到就多留个心眼：点赞、评论、收藏一个别落，顺手再把商品加进购物车。等对方下次投 LAL，说不定预算就落到你头上了～

从今天起，备一台干净手机，挂好干净节点，装齐 Facebook、Instagram、TikTok，再去 Google Play 免费榜挑几个评论区全是“广告太多、别下”的“垃圾 App”。这，就是你的最强 Spy 工具！
