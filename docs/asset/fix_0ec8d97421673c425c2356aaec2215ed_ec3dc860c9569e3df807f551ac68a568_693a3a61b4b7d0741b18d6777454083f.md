# 1.1 让机器接手机械活：自动化到底在做什么？ @钱塘江鲤

把技术当成替手，机械环节交给程序，人负责判断、创意和决策——这是自动化最朴素的逻辑。若再叠加 AI，团队就像多了一位全天候的数字同事，产出会被成倍放大。

路线大致分五支：

- 应用串联型低代码平台：Zapier、n8n、Make
- 传统 RPA：影刀 RPA、八爪鱼 RPA
- AI 流程平台：Dify、Coze、fastgpt
- 自定义多流程协作：pygui、playwright、puppeteer
- 全自主通用 Agent

举个常见例子：围绕关键词或竞品账号，进入📕、抖音抓取热门内容，筛出数据最好的素材，把视频文案存进飞书表格，调用飞书 AI 配图，最后分发到📕、飞书、抖音👸号等渠道。人只需在关键节点抽检质量。整条流水线自动推进，运营便能用小成本测试换回超预期获客。

下面把工具全貌扫一遍。

**第一类：低代码应用集成平台**

[PRE1]

Zapier、n8n、Make 用触发器和动作把应用串起来，比如 Notion 写完笔记自动同步 Twitter。上手快、几乎零代码，个人和小团队做简单跨平台联动很顺手；但海外产品对国内生态覆盖不完整，复杂业务仅靠模板很难撑住。选型要看场景。

**第二类：传统 RPA**

[PRE2]

八爪鱼 RPA、影刀 RPA 用可视化拖拽搭流程，本机运行，能接管键鼠模拟人工，半天可入门。某些场景不够稳，调度定制麻烦，接入既有办公系统不轻松；整体比较均衡。

**第三类：AI 工作流平台**

[PRE3]

在线拖拽连接环节，输入链接或文章即可生成不同风格文案并接后续步骤。内容创作场景适用；个性化成本高，复杂逻辑、多流程协同和并发稳定性都偏弱，适合轻量入门。

**第四类：AI 编程**

用 AI 编程做脚本化或产品化自动化，如 Cursor AI IDE 写脚本。灵活度高，可定制复杂链路，如多平台采集、AI 分析趋势、生成内容并分发；需编程基础，新手不友好。关键长处是能稳定支撑大规模并行，短时间高强度执行。

**第五类：全自主 Agent，如 manus**

在讲师看来，manus 这类全自主 Agent 可能是终局：下指令后自动拆任务、调工具、交结果。让它做 RPA 调研 PPT，很快能交付，无需预编排，还会自行跨平台找信息。当前可控性与成熟度不足，但随着模型和产品迭代有望改善。

五条路线各有地盘和边界，按真实需求选。

# 1.2 AI 自动化的商业分析 @龙菲

上一节把流派和基础名词讲清了。这一节，讲师结合两年多做商业营销增长自动化的体会，从赚钱角度聊：怎样把低代码平台和工作流软件组合起来，形成自己的商业营销自动化能力，也帮大家打开视野。

欢迎来到这次零代码自动化航海。这个新兴领域值得投入和探索，掌握相关技能会带来新的职业机会与成长空间。

近半年，国内同行才开始关注 AI 营销自动化，而且大多盯着 Coze 扣子国内版。相比之下，Make、Zapier、n8n 这类低代码平台，以及 Dify、FastGPT、LobeChat 等工作流工具，在国内的用户基数和讨论热度都远不及海外。

讲师从 Make 和 Zapier 起步，陆续体验了不少平台和工具。每家都有长处和短板，也算一路见证了零代码自动化的发展。

基于这些经验，讲师强烈建议：学 AI 别只凭兴趣，要结合自身情况选方向。否则容易陷入“样样试一点”的状态——这个摸一下、那个搞两下，折腾很久，离赚钱仍很远。

学习路线要和变现挂钩，要清楚掌握一门有商业价值的技能有多重要。

从一线接触企业方得到的反馈是：老板并不需要花哨的流程，他们要的是能真正解决问题、省钱提效的工具，例如：

- 获取流量
- 减轻客服压力
- 自动处理订单和发票

真正的商业营销自动化，是替企业方和自媒体从业者处理重复、繁琐、低价值的事。

所以，选对学习方向，掌握有商业价值的工具技能，往往能事半功倍。

国外有个产品叫 Glean，专门管理企业内部资料，估值已达 46 亿美金。它的功能听着简单：把企业各部门资料以及各种 SaaS 系统、ERP 数据整合起来，让员工用自然语言与企业知识库对话。

效果如何？过去员工找老板要的一份客户报价单，可能要翻一两个小时，隐性浪费巨大；现在一句话就能找到，因此被称为“企业内部的 Google”。

它朴素地解决了企业真实需求，客户用了就离不开，粘性极强。

讲这个例子是想说明：要真正理解自动化。能解决真实客户需求，才是学习和努力的方向。不是简单做个噱头视频和图文就以为在搞自动化，同质化内容很快会被平台打压，拿不到流量。这个商业目标务必想清楚。

有了 AI 助力，怎样真正用它解决实际工作中的问题？讲师在这条路上走过弯路，也攒了一些实操经验，这次航海会分享心得。

“工欲善其事，必先利其器。”人类善用工具，是我们成为万物之灵的重要抓手。面对日新月异的 AI 技术和快速发展的各类 LLM 平台，很容易患选择困难症：这么多工具，该怎么选？

讲师的观点是：每个平台各有优势，按自身需求选择即可。

因此，先要对琳琅满目的工具和平台建立商业化认知。只有真正了解当前商业自动化的发展情况，对各工具的商业能力有充分了解，才能做出正确选择。

接下来不讲技术名词，而是从实用角度出发，通过详细功能对比、真实使用体验和具体应用场景来分析。

先看第一大类的 LLM 应用平台：Dify、Coze、Fastgpt、ragflow、Make 等。其中 n8n 和 Make 都是基于工作流的 LLM 平台。

n8n：以强大的通用工作流自动化能力著称，近年来积极拥抱 AI，允许用户把 LLM 节点嵌入复杂自动化流程。

Coze（扣子）：由字节跳动推出，主打低代码/无代码的 AI Agent 开发，强调快速构建和部署对话式 AI 应用。适合新手练习工作流搭建，但不支持自定义模型，限制了部分高级用户，用户必须依赖平台提供的模型。另外，Coze 处理知识库时有 token 数量限制，仅支持 6000 个 token，对需要长文本或大量数据的用户来说是明显短板。

FastGPT：一个开源的 AI Agent 构建平台，专注知识库问答系统构建，提供数据处理、模型调用和可视化工作流编排能力。

Dify：开源的 LLM 应用开发平台，融合 BaaS 和 LLMOps 理念，旨在提供一站式 AI 应用快速开发与运营能力，包括 Agent 工作流、RAG Pipeline 等。

RAGFlow：基于深度文档理解的开源 RAG 引擎，专注解决复杂格式文档的知识提取与高质量问答。

Make：一种在线工作流软件，需要🪜才能使用，属于收费软件，集成了 4000 多个海外各类软件工具网站的 API。它提供 Canvas、YouTube、TikTok 等丰富节点，用户可以快速创建工作流，把内容轻松发布到不同短视频平台。Make 的优势是节点丰富、使用便捷、限制较少，上下文 token 限制也比较松。不足是免费计划每月仅支持 1000 次执行，对大规模工作流用户来说可能不够。不过它目前是讲师做商业营销自动化的主要工具。

企业实际应用场景举例：

- 想做“跨境电商”七国语言智能客服系统，Dify 更合适，可定制、可私有化部署；
- 想完成“企业现有 ERP 或 SaaS 系统与数据库之间的数据同步与报警通知”，n8n 是首选；
- 想定制轻量级企业知识库，用于智能客服或企业内部培训知识库，FastGPT 很适合快速部署，但大体量企业内部知识库不建议用它；
- 要做海外营销推广，可以用 Make 和 Zapier 实现定时生产内容和平台自动发布，实际上国内很多平台也可以用。

其他类似 RPA 工具，如影刀、八爪鱼、UIBOT 等，也能做一些自动化工作流，但不能调用很多第三方系统的 API，功能有限。

Coze 适合刚接触 AI 应用开发、希望快速看到成果的新手，是最容易上手的选择。但讲师并不认可它是真正能解决商业需求的好工具，后面会介绍原因。

[PRE6]

学习不能永远停在初级阶段，要有前瞻性，要学就学有前景、未来应用更广的技能。

Coze 作为入门工具有它的价值，特别适合新手快速上手。但若想在商业应用上走得更远，就需要了解不同工具的局限性和适用场景。

在讲师看来，Coze 现阶段只能做一些初级玩具性质的工作流，并不适合持续用在高阶商业场景。核心原因是 Coze 属于封闭系统，而且部署在云端，无法本地部署，企业数据私密性难以保障，更没法调用很多第三方优质大模型，比如 OpenAI、Claude，只能通过插件方式解决。实际上，国内大多数平台并不会开放 API、免费让别人调用平台数据，因此出现了很多人做小插件盈利的现象。凡是 Coze 工作流中稍微有点用的节点需求，都被人做成插件收费，比如抓取📕标题、内容、点赞、评论等。

这些都被包装成插件收费。最近很火的火柴人视频，里面的火柴人调用也需要付费插件会员才允许复制工作流。这些插件大多由个人或小公司编写，不够稳定和长久，说不准哪天就不在了。再加上各种大模型费用，Coze 对新手上手的成本也在急剧上升。

所以基于自身定位，讲师需要的是一个能打、能扛、能多用途的工具，不局限在一个平台，而是追求把多个工具和工作流软件组合成“自动化军团”一起做事，这也接近 AI Agent 的终极形态。

有人会提到 manus、lovart，但现阶段这些 AI Agent 工具还处于初级阶段，不能完全接住商业化需求，自主性和灵活性都不够。因此讲师建议：自己学会把各类工具的工作流打通、调试好，再组合起来满足客户具体需求，这是现阶段最好的打法。

我们要真刀真枪拿结果，面对客户需求。海量需求等着挖掘，比如实体店如何与 AI 结合，LBS 广告投放如何与 AI 结合，智能回复机器人如何实时根据客户聊天记录捕捉关键词，判断该不该发优惠券，等等。红杉资本最近一次会议也强调，未来 AI Agent 是拿结果去换钱，而不是卖工具、卖工作流，是要用实实在在的结果换钱，这个趋势不可避免。

方向路径搞清楚后，就要开始从小白到高手的成长之路。现在满大街都是小白初级教程，实际上并不对：哪有那么多小白需求？中高级应用的学习需求同样有市场，甚至更紧迫。很多人学的皮毛知识支撑不起商业变现。讲师希望打造一个贴近中级成长需求的航海，让大家知其然更知其所以然，避免成为半吊子，陷入客户不要、自己研究又无法深入、没人带的尴尬境地。要做一个知道 What、更知道 How 的从业者。

# 章节概要

上一章系统梳理了自动化的基本概念、核心价值以及多种主流工具与技术路径，帮大家建立了全景认知。

相信大家已经认识到，无论是低代码平台、传统 RPA，还是新兴的流程平台与自主 Agent，最终目的都是解放生产力，让人专注于更高价值的创造性工作。

现在，是时候从理论走向实践，把这些理念应用到日常工作中最核心、最耗时的环节之一：内容创作。

本章聚焦“内容创作”自动化，通过一系列具体实战案例，带你一步步搭建能实际运行、解决真实痛点的工作流。

你将学习如何利用 Coze 等工具，结合 AI 能力，实现火柴人科普视频自动生成、👸号文章摘要智能提取与定时推送、👸号文章自动排版与发布、📕爆款图文笔记自动化生成，以及更复杂的 AI 视频自动化工作流和口播短视频二创改写。

这些案例不仅拆解工作流搭建步骤，也会深入剖析背后的自动化思维和问题解决策略。

学完本章，你不仅能掌握几种热门内容创作场景下的自动化技巧，更重要的是能够举一反三，把这些方法迁移到更多元的创作需求中，真正让 AI 成为内容生产线上的得力助手。让我们一起亲手打造属于自己的“内容永动机”。
