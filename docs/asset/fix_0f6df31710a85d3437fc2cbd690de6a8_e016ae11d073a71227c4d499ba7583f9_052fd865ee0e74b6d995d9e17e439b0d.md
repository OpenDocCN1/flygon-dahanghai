# 三线城市高考咨询：8年把人均业绩做到50万

目录：
**1.** 赛道怎么选
**2.** 愿意付费的家长从哪来
**3.** 团队如何组建并快速复制

分享人：鹏哥｜2022年2月22日

我是鹏哥，在一座三线城市做新高考升学咨询，到今年整八年。2014年起步，服务过的学生超过三千名，公司一年营收五百万以上，团队人均业绩做到五十万元GMV。双减让不少教培机构受挫，可高考赛道仍然被社会与家庭高度重视，哪怕只做单一市场，体量也不小。这个领域专业门槛高、出结果快、从业者压力大，反而把很多竞争者挡在门外；再加上家庭经济条件改善、家长受教育水平提升，肯花钱买咨询服务的家庭越来越多。在我看来，这个行业的好日子才刚开头。

下面，我从赛道判断、产品体系、获客打法、团队与文化赋能几个方面，拆解我们是怎么做的。

—01— 先选对赛道

一、双减之后，机会在哪

2021年教育部落地双减，对象是义务教育阶段学生，校内作业和校外培训两头减负，整个行业随即大洗牌。中小机构九成以上关门或者转行，新东方、学而思也退出了义务教育培训市场。事实上，双减之前，低龄兴趣班和义务教育学科辅导就已经在利润驱动下跑偏，离以孩子为本的初心越来越远。成人培训需求虽然多样，但在三线地级市很难规模化组织，利润也分散。高中段不一样：结果导向非常明显，高考的唯一性决定了社会与家庭的高度关注，单一市场也有足够体量。此外，这一行专业要求高、离出结果的时间近、从业压力大，竞争反而小得多，许多公司和个人不愿意接这种高风险。我们愿意做难而正确的事，这跟我们深耕细作的风格一致。

2022年元旦，《家庭教育促进法》正式施行，国家以立法形式强调家庭教育的重要性。孩子是家庭的未来，教育承载着未来。高考升学规划能把孩子、家长、学校三方的意愿统筹考虑。我们希望每年复读的人数能少一些，九月开学后因为专业或学校不合适而退学休学的情况能少一些，家庭更和睦，社会更和谐。政策支持加上几年积累，让我们更坚定地做下去。

二、产品体系怎么搭

三线城市的家长往往希望一个平台把升学规划、语言培训、学科辅导甚至心理疏导都解决掉。需求本身是变化且多层的，这就决定了我们的交付偏重，但口碑传播也会更好。我们的咨询服务包括高中学业规划、选科指导、背景提升、综合评价等多元升学渠道的选择，高考志愿填报反而是最后一环。

[PRE0]

一名全职员工服务五十个VIP学生（覆盖高一到高三）完全可行。我们老师带的学生横跨三个年级，大致比例是四成、两成、四成。高一家长普遍迷茫，意识强的付费意愿高，还常常成群结队来咨询；高三家长临近高考容易焦虑，掏钱决策更干脆，占比同样不低；高二一直是个洼地——有想法的早来了，意识不强的在这个阶段很难下决心，尤其到了付款环节。

全流程规划咨询费的中位数是八千元，我们每个月通过线上或线下沟通继续挖掘家长的多元需求。举个例子，学生想用宁波大学的分数进浙大，可以走浙江省内三位一体渠道，同一个学生就多出一个收费项目；有的学生要走中外合作院校、强基计划或者港澳院校，每个渠道收费在四千五到三万元之间，而且可以叠加。高考出分后填报时，孩子能比旁人多出两三项选择，所有付出就都值了。这样一年下来，人均业绩做到五十万元GMV也就顺理成章。

—02— 怎么找到愿意付费的家长

这一行对场地和硬件要求不高，靠的是知识密度。升学规划师解决家长问题的专业能力最为关键。家长和学生叫我们老师，所以打电话、发传单这种打法不合适，不能做得太low。正因如此，我没有设专职销售。优秀的规划师在沟通中就能把销售自然嵌入服务里。几年下来，转介绍比例超过八成，口碑帮我们带来了更精准的客户。

一、把服务做成定制化

新高考的节奏是：高一下开始学考，高二选科，高三小高考和高考，环环相扣。三位一体、强基计划、综合评价、中外合作院校等渠道，给学生的个性化升学规划留出了空间。升学规划是我们的入口产品，把一个学生服务好，后续会带出更多需求。

高考分数不再是唯一标尺，多元升学渠道才是新高考的特色。英语强的可以选中外合作大学或4+0项目；数理化突出的可以走强基计划（36所A类985院校本硕博连读）和综合评价；有军校梦的可以报军校或警校；家庭条件允许的可以考虑港澳院校或出国留学。一个孩子可能有一项或多项需求。高考出分后，面前摆着好几种选择，家长和学生能优中选优，这就是我们工作的价值。提前规划，录取时降二十到五十分，这样的成功案例每年身边都有不少。

本地一中的徐同学就是例子。团队从职业性格测评入手，帮他找到兴趣与优势匹配的专业方向，也帮他找到了学习节奏、确立了目标、调整了状态。他从原来的迷茫变成自己“要”学，年级排名从五百多名冲到第一次选考后的九十多名，最后进了心仪的西南交通大学（211院校）。

二、靠微信群做裂变扩张

做了几年，运营上最深的一点体会是：必须跟家长直接建立联系，沟通才有效。以前我们也走过弯路，发DM单页、上电台打广告、托校领导或班主任进校宣传，效果都很一般。2018年以后，我们把运营重心放到了微信群。

拿桐乡校区一个月的启动期来说：

第一步，先通过身边的家长和朋友拉一个五十人的小群，只要是高中家长就行，不分年级。接着每周二、周四安排两场群直播，按顺序系统讲升学规划、高考选考、三位一体、综合评价等内容，每次结尾埋个钩子，吸引更多家长进群。四周下来，群人数基本能到两三百。

第二步，一个月后解散该群。解散前三天，引导家长进入高一、高二、高三的大群，告诉他们年级群会定期分享更精准的内容。这样我们的群就分成两类：一个月的引流群和长期的年级大群。

第三步，不同年级需求不一样，我们看成交机会拉临时小群，筛选精准用户。专题群收完单立刻解散，只留年级大群。比如高一下的学考选考做专题转化，高三的三位一体做专题转化，全年级的升学规划也做专题转化，挑准时机循环操作。

三、用线下讲座推动成交

我们的客单价偏高，卖的又是咨询类虚拟产品，线上直接成交的比例不大，多数家长还是要转到线下才能转化。

线下讲座的操作思路差别不大，但我守住一条原则：面访率不到三成，就不开线下招生讲座。比如一场讲座计划来三十组家长，我会在讲座前一周先做到十组左右上门面访，把信任建立起来，这样才控得住会场节奏和成交。2019年5月19日那场是我做得最好的一次，到场三十二组家长，成交接近五十三万元。

四、把转介绍做成业务闭环

测评要回答几个问题：孩子感兴趣且有优势的专业，偏文科还是理工科？思维偏左脑理性还是右脑跳跃？当前学习节奏是良性还是不够努力？

我们一直在探索让转介绍系统化。按学生升学渠道方向，赠送相关行业或报考要求的书籍，引导家长参加讲座，持续提升认知。对已经做过转介绍的家长，给予一定费用优惠，并把他转介绍的家长一起约来茶话会或聚餐。根据孩子目标院校，送大学校徽、定制大学logo书签，不断提升个性化服务体验。这些做法让冗余资源得到更好利用，也增强了家长和我们的粘性。很多家长慢慢成了朋友，甚至有毕业三年的家长还在给我们转介绍。

判断一个家长认不认可我们，我只看一个指标：有没有给我们转介绍。当然，能让家长主动转介绍，本身就充分说明我们的专业能力。

升学规划的第一步是测评。很多家长选大学、定专业靠感觉，或者听身边老师、同学、亲友的意见，结果常常和预想的不一样。所以我们要通过测评了解学生：

有了数据作参考，才能帮父母和学生结合日常实际做判断、做对比，帮孩子找到感兴趣且有优势的学科方向。这解决的是教育中一个很大的痛点。面访解读时还能了解家长的受教育程度和经济能力，为后续多元规划打基础。专业的解读能走进家长和学生的内心，建立深度互信。

转介绍这块，我的心法很简单：比同行多做一两步。同类产品多往前走一步就有机会赶超，多走两步就能领先。比方说，家长来问选科，我不只告诉他怎么选，还会告诉他这种选法将来在长三角就业有什么优势。选科本身是家长的目标吗？不是。选科是为了上好大学，上好大学是为了好就业。那我就告诉你，哪种选科更契合特定区域的就业需求。再比如，家长带孩子来问英语怎么学，我不只讲听力怎么提、阅读理解和作文怎么做，还会告诉他：语数英三科里，英语相对容易提分。英语学好了，可能就是孩子总分快速上升的引爆点；英语提上来，总分就高，排名跟着上去，孩子的状态和节奏也会进入良性循环。你说，这英语该不该学好？

—01— 团队怎么搭、怎么快速复制

一、用合伙人的心态招人

教育培训是知识密集型行业，团队小而精，从业者学历高、能力强。尤其在三四线城市，优秀人才本来就少，员工水平直接制约公司发展的速度和深度。我们的员工全是80后、90后，这个年龄段的人除了看重收入，也在意自我价值的实现。怎么激发员工的自驱力，是当下老板们的一道考题。

第一，我们设置了有竞争力的薪酬和晋升通道。普通规划师升资深规划师，收入提高五成；资深规划师升项目合伙人，收入能到二十万，同时获得带徒弟的资格，有机会独当一面，做一方“封疆大吏”。

普通规划师是最基层岗位，经三个月基础培训和实践后能独立服务客户，每单升学规划服务费八百元，另外参与会销业绩分成。资深规划师在普通规划师基础上，每单服务费提高到一千二百元，还能根据客户积累量整合公司资源，开个人专场会销。项目合伙人拿资深规划师的薪资，同时可以带徒弟拿管理奖金，还能参股新开的分公司。要在高考咨询行业真正站稳，至少得沉淀两年。

第二，每周开例会。常规工作用文字汇报，重点讨论非常规事项，比如案例分析：从工作里梳理新案例，一起探讨解决办法，再把解决步骤和流程整理成百问百答，沉淀为基本方法论。非常规问题逐步变成常规问题，团队解决问题的能力就不断优化，员工专业水平也跟着提升。

第三，日常不打卡。上班时间统一，下班按工作需要自行安排，请假只要提前安排好工作即可；周末加班可以把孩子带到公司，小食堂备好午餐，让员工更好平衡工作与生活；节假日给员工父母送礼物，关怀延伸到家人，老家在外地的就邮寄过去。

二、师徒搭档干活

师徒制背后有深厚的信任基础。有了信任，为共同目标加班加点也愿意，负面情绪自然少。师徒搭档更容易在实践中发现问题、解决问题。我们跟家长签的是握手合同，既要守原则，又要做有温度的高考咨询，这个分寸感——也就是“火候”——很重要。师傅能更好地言传身教，把企业价值观传下去。

姚老师入职两年，现在是桐乡校区负责人，也成了合伙人。他之前做纺织品销售，进来后积极主动、学习能力强，第一年由我亲自带。一年时间他就能独立做高考志愿填报——这是行业里技术含量最高的项目；2021年开始带徒弟，像模像样；下半年已经当讲师开专场讲座，当地电视台给他做了专访，年底顺利晋升合伙人。两年间，他从行业小白变成家长认可的专家，收入翻了两番。

三、牵头组建升学规划联盟，整合资源

教育、医疗、养老是眼下家庭最关心的三件事，教育更是承载着家庭的未来。

新高考改革把人才培养从“分层选拔”转向“分类培养”。过去高分上好学校、低分去差学校；现在通过中本一体化、嵌入式培养、三位一体、强基计划等招生培养模式，充分照顾人才的个性化发展。2021年多所职业技术学院升格为职业技术大学，国家引导的教育方向已经很清楚。多数家长和学生并不了解这些变化对升大学和就业意味着什么，所以高考咨询在双减之后反而迎来更好的机会。

我牵头成立了“浙江升学规划联盟”，让不同地级市的同行共享资源。初衷很简单：一起把蛋糕做大，既帮到更多学生，也让从业者成就一番事业。2019年联盟成立后，每季度选一个地级市开经营分析会，大家一起商量解决招聘、产品研发、市场推广、法律风险规避等问题。这个虚拟联盟已经成了我们共同的百宝箱，谁有问题、有困难，大家都会搭把手。通过抖音大航海，我有幸认识了几位外省同行，以后既能在专业深度上合作，也能在行业广度上拓展。

教育承载着一个家庭的未来。作为从业者，我们要始终以学生为中心，帮他们在高考这个人生关键点上未雨绸缪，把握更好的未来。

附名词解释：
**1.** 中本一体化：三年中专加四年本科联合培养，不用读高中，通过单招定向模式选拔。
**2.** 嵌入式培养：计算机软件行业常见的校企联合培养方式，就业起点较高。
**3.** 三位一体：高考占六成、高校综合测试占三成（笔试和面试）、学考（毕业会考）占一成，三项加权综合录取。它打破了老高考唯分数选拔的模式，表达能力强就能拿到实实在在的降分。
**4.** 强基计划：2020年起，36所A类985院校针对基础学科和尖端行业（卡脖子领域）新增的录取渠道。采用3+1+X模式（本科三年加一年研究生预备课程，再进入硕博阶段），本硕博贯通培养。高考分占85%，学校综合测试占15%，最低达到高考所在省份一本线就有机会被清北复交等名校录取。
