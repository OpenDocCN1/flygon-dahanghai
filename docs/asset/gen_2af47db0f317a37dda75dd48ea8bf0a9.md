# 5.2 会员体系设计：从储值到锁客的关键打法

顾客在收银台准备买单的那一刻，其实是门店推会员、做长期关系的最佳窗口。但在推出会员活动之前，建议先做一轮小调研，看看用户对哪种方式更买账，再决定怎么落地。

会员体系的重点，不外乎储值方案设计、储值会员权益、会员卡设计以及配套权益。以快消品门店为例，一个店往往沉淀了10000个🛰️好友、10个社群和1000名会员。高客单价产品的门店，社群和会员数量可能会少一些，但这并不影响设计基础会员产品。比如手机店可以推出49元/年、全年10次贴膜服务；珠宝店可以做99元/年、全年12次礼品权益。具体玩法要根据行业和自身产品来定。

充值诱饵说白了就是要给用户一个“现在就想充”的理由，可以考虑这些形式：

- 充值金额达到本次消费金额的200%以上，就可以享本次店内免单，且充入金额依然可正常使用；
- 充值后享受更低折扣；
- 充值即送实物奖励；
- 充值可参与现场抽奖；
- 会员能享受某款产品超低价体验，例如原价68元的生排，会员每次只需9.9元。

再来看会员权益怎么设置。可以参考这个思路：充值299元成为终身会员，每月可到店自提一份价值68元的牛排，当月有效，不可累积；同时享受店内产品会员折扣价、新品优先体验价和专属VIP服务；如果会员再推荐一位VIP，还能拿到50%返佣。这样的设计，本质上是把普通门店逐步转型为会员制电商门店，把更多精力放在服务好付费会员上。

会员充值的日常引导也有讲究。首先，可以做一本会员手册，把权益介绍清楚；哪怕顾客当场没办，之后看到手册也可能会被刺激转化。其次，要学会观察用户：如果对方是商务宴请、结账时比较匆忙，就先简短介绍充值福利，再把会员手册递过去。最后，门店还要准备自然的话术，让店员能够顺畅地推广充值会员；毕竟现在很多消费者对“办卡”“充值”本身比较排斥，越自然越有效。
