# 第四步：锁定对标账号

在视频号和视频带货的语境下，真正值得参考的账号通常要具备这几个特征：

- 达人是否只深耕某一个品类——有这类账号，我们的视频素材才有处可寻；数量越充足，越有利于筛选出更出色的模仿对象。
- 达人的视频数量是否足够丰富——这直接关系到我们能借鉴的时间跨度。如果总共只有10条内容，那就远远不够用。
- 达人的点赞和销量数据——这些指标能帮我们评估他们在抖音平台上的真实成绩。

起步阶段，核心目标应该是先跑起来，尽快找到合适的账号，让正反馈早日出现。换句话说，如果你是新手，先掌握手册里“找对标账号”的入门方法就足够了；如果还有余力，再逐步了解进阶玩法。

具体内容可查阅手册：《通用能力｜怎么寻找对标账号》

另外要特别提醒：做二次剪辑或混剪时，尽量避免使用真人露脸的素材，否则容易遭到原作者投诉，最终导致视频被下架甚至封号。
