# 3.1.1 蓝海高客单价怎么挑

这期闲鱼航海让大家做高客单，所以重点说这类的挑法。高客单和普通选品思路差不多，就两点差别：

1. 先卡价格区间，太便宜（比如不到100块）的不用看；
2. 能不能跟，看同行日销件数、想要人数时门槛可以放低，因为高客单本来单量就比低客单少。

挑的时候，先把自己当成买二手的用户，想想自己会搜什么、关注什么。平时撞见高客单商品，顺手掏出闲鱼查一查，把挑货变成习以为常的动作。

之后再用闲鱼上的数据验证该不该发布。闲鱼不像淘宝有生意参谋，也不像小红书、抖音有蝉妈妈这类工具，挑货只能靠平台展示的数据来估。通常看这几点：应季、卡价、想买人数、同行近况、多家情况。

先讲讲一个不错的选品长什么样：

# 3.1.1.1 应季

应季是第一个要看的维度，先判断这个货眼下是不是符合用户需求。比如露营车，开春到夏天都合适，一入秋冬量自然就掉；再比如夏天卖电热毯、暖风机，冬天卖落地扇、空调扇，明显不对路。电脑显示屏、货架这类四季常青的除外。

# 3.1.1.2 卡价格

既然要做高客单，价格这关必须卡。除了露营车、空调扇这种一眼就知道是大件的，还得从畅销货里挑出高客单规格。搜商品时，点“筛选”里的“价格”，填个最低价再看。比如手机壳平时几块、几十块，把价格一提，就能看到不少高客单规格。

[PRE3]

接着再结合应季、想买人数、同行近况、多家情况一起评。

# 3.1.1.2 想买人数

“想买人数”（也就是点“想要”的人数）反映市场热度，数值越高说明咨询越多、需求越旺。但到底行不行，还要搭下面两招判断。补充一句：有的商品首页没直接露想买人数，可能和主图、系统提示或闲鱼币抵扣有关，点进去照样能看到。

[PRE4]

想要数:浏览数 ≥ 1:10

点进详情后，如果想要数:浏览数≥1:10，或者大致接近，就说明需求比较猛，操作余地也大。等于每10个人来看就有1个人表示想要，其中还有可能掏钱。

[PRE5]

这时候必须搭配“查看动态出售情况”。如果近期出手不错，这个商品是蓝海的概率就大。再结合多家情况，想买人数和出手动态都达标，基本就可认定为蓝海品，优先上。

# 3.1.1.3 同行近况

同行近况看的是转手情况，也就是转化数据。最近卖得越勤，越值得参考。

[PRE6]

同行“单天出售大于 3 件”

判断市场行不行，一般同行能连着两三天每日卖出3件以上就算不错，自然是多多益善。但还得看下一关：多家情况。如果有至少2、3家也都能每天卖出3件以上，这个货就能选。如果一天卖不到2件，看几家都这样，基本可以放弃。

同行把动态藏起来了咋办？

有的店铺想买人数很高，但动态不可见，这时可以看店铺露出的其他数据来补判，按顺序来：

1）鱼小铺等级L3以上：这个等级是靠买家好评堆出来的，L3通常说明近期出货不少、口碑也OK，可当第一个参考。没有鱼小铺，但后几项都不错的，也可以考虑。

2）下方留言时间：能看出最近的咨询热度。7天里有2条以上新留言，就算近期还行。

3）回复率90%以上：回复率高一般代表店铺整体运转得不错，值得投入精力。低于80%就直接跳过。

4）卖出产品数：当然是越高越好。如果只有个位数，且同行也都这样，说明这货可能没市场。当然也不排除新发布突然爆单，这时要结合上面几项综合判断。

# 3.1.1.4 多家情况

单看一家容易碰上偶然，所以要把前面的标准组合起来，看多家想买人数都不错、出手动态也稳。

2、3 家同行单天出售都大于 3 件

只要有多家满足“同行近况”里的条件，2、3家每天都能售出3件以上，这个品就能挑。

以上是闲鱼高客单挑货的方法。方法讲完，大家也清楚怎么评定一个货能不能上了。

# 章节要点

高客单商品的发布手法和一般商品一样。发布前先去拼多多找好货源商家，参考对方的标题和图片，再按闲鱼的调性优化。发布的核心是：让想买这个货的用户都能逛到咱家店，然后下单付款。

那怎么让商品被更多人看到并成交？关键在编辑发布。最重要的四个点：标题、首图、介绍文案、定价。另外还准备了几个编辑小技巧和注意事项，帮你少走弯路。这些部分怎么帮你拿流量？往下看。

# 3.2.1 先去拼多多找货源商家

发布前，最好先在拼多多锁定目标货源，保证一有单就能发货，同时也能借商家的标题和图片来用。拼多多最常用，淘特、1688也行，流程没差。怎么判断商家是不是优质货源？看4点：

1. 销量——过1000就行，新店几十、几百也可以；
2. 好评——看近期评价，10个里7个以上好评就算不错；
3. 利润——前期有得赚就行，等流程熟了、日销稳定过6单，再挑利润率≥20%的；
4. 商品数量——少于100个的靠谱；几千几万个的很可能是别家平台做无货源的。

怎么快速在拼多多挖到低价好货？推荐两个最直接的路子：

方法一：用搜索框的图片搜索来找货源
方法二：刷平台推荐找货源

# 3.2.1.1 用图片搜货源

第一步：按3.3.1的挑货方法，在闲鱼找到动态出售多的“滚轴”商品，点进链接保存主图。

第二步：打开拼多多，点右上角“相机”，选刚保存的图片。

第三步：结果页按销量排序，挑销量靠前的几家店。如果识别出来的不是目标商品，就按截图里的“产品类型”筛选，或者回第一步换一张图重来。

第四步：回到刚才的闲鱼店铺，对比它家不同规格滚轴的价格，和拼多多同款的价格差。

第五步：只要拼多多价格比闲鱼低，就能当意向货源。多看几家，再按上面“货源判断标准”来筛，就能找到合适的。

# 3.2.1.2 靠平台推荐找货源

第一步：跟方法一同样用图搜，但这次多留意算法推荐。搜索结果页下方一般有“相似商品”“猜你喜欢”（各平台叫法不同，意思一样），都是强相关的相似款。

第二步：看这些推荐商品，重点看规格和价格有没有达到“货源判断标准”。来回刷，直到找到合适的。

货源渠道就这些，操作简单也快，淘特、1688等平台都能通用。

# 3.2.1.3 价格注意事项

不管是用图搜还是看推荐，按货源标准筛，最后都会找到一批候选。初步圈定后，价格上要特别注意：

1. 至少备2家价格低于市场价的商家，免得一家涨价就手忙脚乱。
2. 如果闲鱼同行挂的规格很多，对应货源不好找，怎么办？

同行规格多时，只盯它最低规格的最低价，确保我们的拿货价比市场卖得最好的同行低即可。其他规格，单个商品挂3-5个就行，价格可以和闲鱼市场一样或小有浮动。

# 3.2.2 编辑发布商品

# 3.2.2.1 快速出单的发布重点

编辑发布的核心：让有需求的用户都进到店铺，并最终下单付款。换句话说，就是让商品拿到更多流量，被更多的人看到。发布环节最最要紧的是这三样：

标题：复制拼多多或淘宝的标题，一定要改一下词语顺序，30个字、一行半左右。
首图：用1:1或3:4的实拍图，从拼多多或淘宝评论区找。
内容：把转手原因、卖点、价格、发货售后补全。

此外，还可以按单品要求，换标题、换首图、发多个链接，增加曝光机会。一个单品建议发4个左右链接就行。

# 3.2.2.2 好的首图怎么做

好首图要第一眼就钩住闲鱼买家，特点就是：清晰、干净、直接把卖点甩在脸上。如果是二手手机，产品图可以从微商相册里取，一个链接放8-9张。微商相册要下载APP扫码进。二手手机成色差异大，图片重点突出外观细节，比如划痕、磕碰、透图。第一张首图选亮屏开机后的主页。

好首图长什么样？拿“商用冰柜”举例，排名靠前的图都是商品居中、款式细节醒目，让人忍不住点。而想买人数少的，图片模糊，观感差，对比之下大家肯定都点前者。所以首图尽量按上面的标准来。至于其他图，可以参考动态出售好的商品图。

首图去哪里找？低成本的办法：去淘宝、1688、拼多多、淘特搜商品，从介绍和评论区挑合用的。

# 3.2.2.3 好的标题怎么做

好标题一般由大量关键词堆出来，让用户不管搜哪个名字都能看到你。比如“商用冰箱”，也叫冰柜、冷藏冰柜、卧式冰柜、冰箱，把这些词，再加“厂家直发”“厨房”“个人出”“商超倒闭”“全新”等用户会搜的词组合起来。参考：全新包邮商用冰柜冷藏冰箱厂家直发厨房商超使用卧式冰柜大容量（尽量把30个字符占满）。

再比如二手手机，买家关心的无非是机型、颜色、内存、成色，把这些关键词卡进去，明明白白。没灵感的话，直接借鉴同行标题，把型号参数改一改就能用。

[PRE22]

怎么快速做优质标题？最省事的就是参考闲鱼和淘宝销量好的同类标题，别人优化过的，拿来改改就是自己的。

# 3.2.2.4 好的商品介绍怎么做

图片怎么放上面说过了，照动态好的来。这里专门说文字介绍。好介绍长什么样？就是先给一个“为什么卖”的理由，再简单说下货的情况，接着列规格和价格，最后交代售后。

[PRE23]

做介绍有个万能公式：

第一段：讲为什么卖这个货，顺带说卖点；
第二段：写规格和价格；
第三段：写发货时间、快递和售后安排。

介绍写得够细，用户想问的都看见了，客服工作量自然就小，省时间。同时介绍清楚明了，用户一眼扫到关键信息，决策快，转化率也高。像下图那样就很好，规格按3-5个来，别给太多选择，免得用户纠结到跑单。规格确实特别多的，精简一下就行。
