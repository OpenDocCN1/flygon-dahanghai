# 4.1.1 通用方法：用数据挖出下一部爆款短剧 @猫柠 @惟乔 @清欢

短视频创作里有一条很实用的规律：曾经火过的内容，之后大概率还会再火一次。想找到值得做的短剧，不用靠灵感瞎猜，打开平台看数据就行。

在抖音等短视频平台输入“短剧”“九州小剧场”“抖音短剧”“抖音短剧新番计划”“触摸短剧”“超爽短剧”这些关键词，再分别按“最多点赞”“一周内”“综合排序”刷一遍，最近哪些剧在起量，基本就清楚了。

[PRE0]

数据亮眼的剧，重点拆解这几个细节：剪的是哪部剧、视频时长多少、开头和结尾怎么设计。另外，如果某个账号粉丝量很少，作品却成了爆款，那这条视频的参考价值会比大号爆款更高，值得优先研究。

还有两个判断热门剧的指标：点赞量越高，说明热度越强；相关视频在搜索结果里的占比越多，说明关注度越高。

[PRE1]

比如上面这组数据里，《慕总的隐婚罪妻》和《医王龙婿》点赞量和视频数量都比较靠前，女频赛道可以优先剪前者，男频赛道则重点做后者。

再看搜索《顾少的隐婚罪妻》的结果，成千上万点赞的作品到处都是，这类剧已经是被市场反复验证过的爆款，选它们基本不会出错。剪辑的时候，开头和结尾可以直接一比一复刻，中间剧情根据自己的节奏适当调整就好。
