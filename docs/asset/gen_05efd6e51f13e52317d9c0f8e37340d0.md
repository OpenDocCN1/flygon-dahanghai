# 3.9 淘宝“新手村”怎么刷：一条可复制的接单路径@海盐芝士

# 3.9.1 先把心态摆正

1.用实习者的心态，不急着赚多少钱。  
为什么把淘宝叫刷新手村？就像刚进一家新公司，派单的人前期并不了解你的能力，你也还没什么经验。所以前10单到20单、30单，就是新人练手，不要把能不能拿到稿费看得最重要，而是把真正写实际单子、实操、踩坑放在第一位。有实操机会已经很可贵，还大概率有稿费；就算经验不足踩了坑、没拿到钱，也无所谓。实战经验非常重要，就去练，把淘宝当新手村。

2.可能拿不到稿费的原因。  
淘宝和外部一些同行里，绝大多数客服和客户没有经过专业性培训，不太专业，也不太靠谱。谈单客服在售前售后有时没和客户谈好收款条件，客户耍无赖要退款，他们就直接退款，写手就有拿不到钱的可能。了解这个情况就好，自己留个心眼。发现对方说得不对，主动沟通；他们并不权威，哪怕是错的，你也可以和客户说清楚你的建议。如果他认知不到位、不专业，非要那么写，就按他的需求写。写手的职责是根据客户已经确认的需求写文案，过程中发现不合理就提醒，决定权交给客户；他决策错了，你该提醒的都提醒了，他不听，我们也没有责任。真拿不到稿费，不是咱们的问题，也不要内耗。外部行业情况就是这样，你只需要知道第一目标是实习实操、涨经验。有钱拿更好，没有也没关系；价格很低也没关系，经验是自己的。

3.扩大分母，提升新手应聘淘宝的成功率。  
无脑多去应聘几十家，成功进入至少10家店铺，你在接单群里就能看到很多单子。什么样的单子单价高？你发现某个需求自己大概能看懂，就去网上快速找对标，然后用我们讲的方法论套下来，就能写，能力也就提升了。

4.有一些经验了，再去天猫店应聘。  
前期至少10单不要去天猫。等你写了10到20个真实客单，有了客户沟通、客服沟通的体感之后，再去应聘一波天猫店，同时再扩展几十个淘宝店铺。这个时候要好好包装简历，比如写什么文学硕士、什么专业，再拿自己搜到的优质稿件重写一遍，当作自己之前写过的真实稿件去应聘。这样相当于拿一份很好的简历去新公司面试。

5.尽可能展示自己的能力，等待飞轮效应。  
前期大概2周甚至3周，是淘宝客服和你互相试探的阶段，单子可能不会太多。一旦有几个客服给你发单，或者你主动抢到一些单子，让他们发现你靠谱、能写的类型多、质量好、效率快，一个客服就会推荐好几个客服给你，也会把单价相对高的单子给你。大多数普通人还是要积极主动抢单、接单，客服才能发现你，你才能把能力值体现出来。底层市场需求是：淘宝里非常缺靠谱、质量高的写手。最大的店铺有3000个写手，里面不到50个抗打、能写中高端品类且靠谱的。所以前期2到3周，快的话1周，有的同学面试后客服直接就给高单价单子开始写了。这看写作能力和一部分运气，就像去公司面试碰到好领导也有概率，所以扩大分母。

6.仅做写手，在淘宝上接单，靠谱加质量好，月入过万没问题。  
我们一个朋友的妈妈，被裁员后没事干，来做AI写作项目。她只有高中学历，也没什么突出能力，没有系统学习，就自己闲着没事去淘宝接单，在网上找素材、找资料，用AI给客户写。第3个月赚了3000+，从第3个月开始月均3到5万，现在做了几个淘宝店铺，成了顶尖写手。

# 3.9.2.6 主动抢单，别怕

咱们团队的宝子们，目前很多小白，只要单子能看懂，用我们教程讲的内容去套，都可以写，不要怕。

虽然我们是作为写手去刷新手村的，但一定不要用写手的思维局限自己的视野和格局。每个学员都有自己独立操盘项目、或者成长为一名超级写手的可能。所以大家都要从全局视野去考虑，看品、看价、看量，多思考规律，多总结经验和市场现状，从中找机会、找高单价、不断试错，甚至在淘宝店铺中沉淀出优质合作伙伴。

# 3.9.2.8 先守店铺规则

每个店铺都有自己的规则，在群公告里，或者直接问和你联系的人。先遵守对方的规则，能写单子、接触真实单子，目的就达到了。前期不需要管价格是否合理、客户是否不讲理、客服是否不讲理。不要和不理性的人较劲，别让这种人拉低你的格局。

# 3.9.2.9 服务态度要稳

全程用谦虚学习、做好服务的态度对待客户。以善意的假设去想，以温柔的态度去说。如遇到对方不讲道理，直接找海盐一起分析是哪一方的问题。只要不是我们的问题，这一单钱不要了，都无所谓。
