# 4.2.3 先读懂，再相爱 @醒醒同学

这对情侣是在热恋阶段完成解读的。两人并没有明显的大卡点，但多少有些话还没对彼此说出口，甚至双方都未必知道对方原来是这么想的。借助才干报告提前看清彼此，能减少摩擦，也能找到更合拍的相处方式。

**两人的才干分布**

理白四大维度：影响力＞关系建立＞战略思维＞执行力

比比四大维度：关系建立＞执行力＞影响力＞战略思维

理白前十才干：成就、理念、个别、关联、沟通、交往、追求、完美、战略、专注

比比前十才干：和谐、搜集、个别、取悦、沟通、排难、伯乐、统筹、适应、思维

**盖洛普视角：互补、相似与差异**

从互补来看，在确定关系之前和热恋初期，理白的影响力更突出，关系建立紧随其后；比比则是关系建立在前，执行在后。整体看，理白更主动。理白容易觉得比比温和好相处、很会体谅人（个别、和谐、取悦、沟通）；比比则会被理白的点子与事业心吸引（战略、理念、成就、专注）。比比越不吝赞美，理白越感到自己被看见（追求）。一个偏事业、一个偏生活，这样的搭配其实很落地。

从相似来看，双方关系建立都排得靠前，说明都看重关系；个别才干也靠前，天然能注意到对方的不同，容易生出“我懂你”的感觉；沟通与取悦同样靠前，交流频率高、嘴也甜，甜蜜度容易上去，小别扭很少拖到第二天。

从差异来看，理白成就1、专注10、完美8，比比成就20、专注27、完美31。理白会把不少精力投到事业里，标准也高；比比未必把工作视为人生头等大事。两人步调能否一致，或能否尊重彼此不干涉，很关键。比比排难、和谐、审慎、适应略靠前，自信、积极、交往靠后，整体更被动。理白交往、专注、成就、追求靠前，一旦认定对方值得，就会主动推进关系；可比比可能本能地琢磨：理白为什么对我这么好？我凭什么得到关注和爱？（排难会让他习惯性思考问题）理白追求、成就、交往靠前，越亲近越愿意付出，同时本能渴望被认可（追求）；他也很在意事情有没有完成，完不成会难受（成就），没得到及时回应会受挫，甚至怀疑对方是否同样在乎自己。一个还在犹豫要不要开始，另一个已经觉得受伤，误会很容易发生。理白相对更高调，也享受向全世界宣告；比比可能有点不好意思或不适应，这点要留意。

**关系里值得关注的三件事**

第一，沟通＋个别。两人愿意交流是好事。解读后，他们试着用了解自己的方式去了解对方，有意识探听对方想法，并给到对方真正想要的东西。比如比比更多向理白表达爱意，理白也尊重比比的节奏，争吵少了，理解多了。

第二，维度互补。理白对未来规划、对关系重视、实现规划的渴望都强，能让比比感到被重视、被支持；比比耐心、随性，常能接住理白的各种念头，让理白感到自己很好。只要节奏差得不太远，不拿自己的标准逼对方改变，意识到彼此不同并愿意互相理解，双方都能在这段关系里看到更好的自己，也能看到世界尚未了解的那一面。

第三，后期复盘。我曾问他们为什么互相喜欢，也帮他们翻译了不少心里话。话匣子打开后，双方知道了更多对方的想法，也更理解彼此的不同；看见了，就更愿意尊重。两人还设定了定期关系复盘会，现在越来越默契。关系里真正可怕的，不是差异本身，而是带着误解以为对方不在意，明明努力很多却仍走不到一起。先了解、再看见、一起走向未来，才是高质量关系的起点。
