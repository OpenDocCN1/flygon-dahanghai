# 7.3 电商遇打假，先稳住 @不语

做电商，碰到打假并不稀奇。先别慌，按流程配合处理，这类事一般不会沾上刑事问题。

**为什么会被打假？**
公司或个体户执照都有被盯上的可能，因为后台能查到资质归属地。相比之下，个人资质开的淘宝店没有对应的监管归属局，也就缺少被投诉的监管入口，过去不少个人店即便用了极限词，也没收到打假通知。但这不代表可以乱写，规则该守还得守。

**先分清：投诉和举报**
如果是投诉，一般能看到投诉人联系方式，可以试着联系对方撤销。多数人奔着赔偿来，金额较小的话可考虑赔付；不过赔完之后，也可能引来更职业的打假人继续投诉，具体怎么处理要结合自己情况判断。
如果是举报，举报人信息是保密的，不能私下联系，只能通过工商协商解决，通常赔钱也能推动事情了结。

**美团常见情形**
较常见的一类是宣传夸大或失实，比如“最好、最大、最优、十大品牌、纯棉、304、除斑、减肥、祛湿”等表述，都容易踩线；另一类是经营类目超出许可范围，像百货店卖食品、医疗器械、情趣用品、图书等，往往需要专门证件。
广告法层面的过度宣传，处理结果多为警告、教育、责令修改，就目前了解尚未出现罚款。但超范围经营要重点警惕，尤其没有医疗器械资质却销售相关产品，一旦被打假，大额罚款风险更高。

**这些词要重点排查**
选品和运营时，建议把易打假词分成三类排查：
功能类：服装写“保暖”、止血贴写“止血”、石膏产品写“摔伤”等，都属于功能性表述。
疾病相关类：涉及“祛湿、驱寒、活血化瘀、宫寒、风湿、专治、治疗、止鼾、增高、益智、美白、无痛、富贵包、雾化药、药液、生理盐水、氯化钠、速效、无毒、安全、无毒副作用、毒副作用小”等，以及其他与疾病挂钩的词，都要谨慎。
失实承诺类：“无效退款、保险公司保险、抢购、试用、名牌”等难以证明的说法，也容易出问题。

**几个容易被忽略的坑**
玩具等商品常需要3C证件，平台也会要求。有人把商品错放到其他类目，想绕过证件录入，这同样有风险。3C类打假人相对少，处罚也偏轻，常见口头警告或500元以内罚款。
进口商品要贴中文标签，一般贸易进口尤其如此。建议尽量别碰进口产品，因为上游可能漏贴或根本没贴；一旦缺中文标签，常被起诉，按规定可能要赔十倍。真遇到这种情况可考虑私了，价格有商量空间，也说明其中弹性不小。所以不论哪个类目，进口产品都别轻易销售。
还有经营地址异常：客户下单后投诉实际经营地址与执照不符，监管局可能上门核实。电话一定要接，否则公司可能被列入异常。若现场不便查看，可说明已经搬家但地址没来得及变更，后续配合改址即可。
日常选品运营中，不妨把容易被打假的词收集成清单，从选品这一步就避开风险。

**收到打假通知后怎么做**
相关部门通常先电话通知。第一通电话要问清是哪个店铺、哪些产品中招，第一时间整改；也可以向监管说明店内已无商品、店铺已关闭、早就不做电商了。
需要到辖区管理地址处理的，积极配合，按要求整改。多数情况是警告整改，严重才会涉及罚款，而且罚款属于少数。重要提醒说三遍：不要硬碰硬，不要硬碰硬，不要硬碰硬。
其实打假没那么可怕，只要积极配合、别和管理人员起冲突，我了解到多数赔偿在几千元以内。遇到问题解决问题就好，别让心态先垮。
