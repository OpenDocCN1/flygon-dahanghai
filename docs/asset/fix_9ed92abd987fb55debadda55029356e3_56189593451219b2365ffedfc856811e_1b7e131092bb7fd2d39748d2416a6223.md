# 先锚定那20%肯买单的人

一个小众产品摆在货架上，想让人迅速掂量出它值多少钱，最利落的办法是什么？

不是把功能罗列一遍，不是做一份问答手册，不是送来七天白嫖，也不是随叫随到的客服、装机数字或者五星好评——而是明明白白标出一个价格。价签一旦清楚，用户心里的预期就会自动对齐到那个量级。

门槛抬高了，自然会挡掉一部分还在犹豫的潜在买家。但换个角度看：80/20法则摆在那儿，八成利润通常由两成人撑起，把力气花在这两成人身上显然更划算。真正吃透产品的人，往往能给出更有分量的反馈，在迭代方向上帮上大忙。

# 6.2.2 佣金与推广分成：接入Affiliate体系

Affiliate（联盟营销）可以理解成海外版的淘宝客，跟知乎好物、抖音书单、外卖返利、美团地推属于同一路数：你替商家带客，成交后抽成。

入门先得认识Offer，其中CPS和CPA最常见。

CPS按成交金额抽成，卖实物行，卖软件程序也行。眼下SaaS产品一抓一把，又带着"配一次长期见效"的属性，提成往往不低，做得好的收入不比传统商品差。亚马逊年末大促时，佣金比例最高摸到9.5%——一台300美金的冰箱卖出去，你到手28.5美金。

若是盯准某个品牌的独立站Offer做专门投放，分成通常更可观；保健品这类高毛利赛道，比例能冲到50%以上，https://fanfuel.co 上有实例可看，当然高佣也意味着红海厮杀。

另一头是CPA：用户完成指定动作才结算，动作可以是装个软件、填张注册表。这类佣金常见区间在2—10美金；落到保健品赛道，一单六七十美金也不稀奇。

海外线上产品线丰富，可挑的标的极多，佣金水平也高。结合自家工具站的定位，把访客画像摸清楚，再去匹配联盟对象、研究对应的分成规则，判断这门生意做不做。

新手挑赛道别凭手感，最好找一个比你弱的对手先超过去；否则流量养起来了，才发现没有合适的产品可推，白忙一场。观察同行在推什么，照着去申请；用"关键词+Affiliate"丢进谷歌搜；找Affiliate Network谈合作；或者直接对接广告主。

联盟要抽一笔中介费，换来的是帮你把各家广告主串起来、省去对接功夫；直接找广告主谈，分成高，可对你的门槛也高。三者的关系有点像：房产中介（Affiliate Network）——你——卖房的人（广告主）。

合作时间长了，佣金比例、扣量这些都有得谈。

https://www.Offervault.com/ 和 https://odigger.com/ 也能按关键词翻出贴合自己niche的Offer。要留意：同一个Offer放在不同联盟，转化表现可能差很远，必须实测；各家运营打法（乃至底线）都不一样。

选定标的后，通常先申请推广资格。海外多数软件与工具类产品，页脚都挂着联盟加入入口；或者谷歌搜"产品名+Affiliate"直达。注册流程不复杂，新手大多情况下如实填写资料，免得佣金到手却卡在提现那一步。

付费订阅：工具站想上订阅制，先得有收款通道。个人身份可以用LemonSqueezy；Stripe这条线，用公司主体注册更稳，最好是海外公司。

把海外公司、银行账户、Stripe一并办下来，美元也好、USDT也好，全球的钱都能收，落回国内。银行配发的员工卡能绑支付宝花，海外服务也不再卡壳，OpenAI扣费失败的糟心事就少了。

准备护照和驾驶证。切记别填虚假信息，账号被封不值当。

为什么要搞一家海外公司？

答：收付款链路和银行账户更稳定；相当一部分海外服务对大陆不开放，或对大陆身份设了更严的风控；另外海外手机号也用得上。

英国号可选giffgaff，每180天发一条短信续命（0.3英镑）。美国号用Ultra Mobile PayGo，月租$3。giffgaff在官网能免费申领。这些淘宝、京东都有卖。

注册地选英国还是美国？

常见就这两个选项。英国公司办起来更省事、更便宜（1st Formations），开户配个Wise企业账号就够。我这次注册的是美国公司，业务需要的话两边都办也行。

Firstbase开户实测：

我挑了口碑不错的一站式代理Firstbase，从公司注册、地址公证到银行开户，指引都很清楚。论省事，淘宝找代办最快；但我更偏好能看dashboard的SaaS式服务。

注册州选Wyoming，类型LLC，对个人开发者比较友好。租一个邮箱地址（私人地址），通过Notarize视频完成1583 Form公证。事先得备好驾驶证翻译件（淘宝几十块），注意证件照和地址要出现在同一页（建议合成A4打印）。视频公证时用简单英文沟通，对方会让你出示翻译件，确认是否本人意愿、核对签名。

EIN（雇主身份识别号）：公证办好后，Firstbase继续代办，我在第10个工作日收到了国税局的信。

Mercury开户：经Firstbase关联提交EIN和护照，1个工作日内过审。

到这一步，公司主体、EIN、私人地址、银行账户、手机号都齐了。私人地址的用途不止于此：可以当账单地址、收实体卡再转寄回国、接Google AdSense验证信。

Mercury能免费开无限张虚拟卡，还能限定商户与额度——A卡只在Google刷，B卡只给OpenAI用；碰上取消无门的流氓服务，直接注销卡号了事。Mercury虚拟卡可绑支付宝，200元以下免3%手续费。

银行卡、账单地址、手机号齐备，各类海外服务就能正常注册使用了；进阶玩法还能申ITIN和个人信用卡。

Stripe企业账号：

拿到EIN后注册Stripe就很顺。把网站切成中文、填中文资料；身份验证用护照，提现账户挂Mercury。

除Stripe外，Lemon Squeezy和Paddle也一并开好。注意后两家要验产品站。

Wise个人收汇款：

Wise支持大陆身份加护照注册，麻烦的是入金激活。Mercury里有钱就快，不然淘宝代充更省心。

Wise实体卡（含3张虚拟卡）不对大陆开放申请，但激活后改个人地址再申就行，费用$9，需地址证明。

Wise余额能直接换人民币打到国内银行卡，也能进微信、支付宝，手续费比"香港银行卡汇款再结汇"更划算，汇率通常还比国内结汇高。更稳妥的结汇路子见：
https://twitter.com/zhufengme/status/1706971107885265405

Payoneer有同类服务，建议顺手也注册。

Kraken提现到Wise：

Kraken同样用大陆身份加护照注册。充USDT进去，在订单簿里买欧元（别用兑换，手续费贵得多），走SEPA汇款，1个工作日内到Wise欧元账户。没走美元，是因为大陆身份没有ACH选项，而且欧元SEPA手续费更低，只收1欧元。

成本明细：

1. 美国手机号 $36/年
2. Firstbase注册费 $399
3. Firstbase地址邮箱 $350/年
4. Firstbase公司代理（含年报、税务申报工具） $299/年

美国公司注册代理不止一家，Firstbase不算便宜。上述注册、公证、EIN、代理、报税、开户，都能拆开找不同代理或自己动手，按需选择。
