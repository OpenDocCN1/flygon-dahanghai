# 1.1 项目现状与前景

# 1.1.1 Shein电商当前现状

Shein 成立于 2008 年，2023 年销售额达 450 亿，业务覆盖 150 个国家和地区。平台最初以服饰独立站起家，在法国市场已超越 H&M 和普力马克，成为第二大服饰品牌。全球快时尚零售市场预计 2027 年将达 1850 亿美元规模，Shein 正处在领先位置。

截至 2023 年，Shein 活跃用户数为 8880 万，其中美国占 40-50%，加拿大 4.25%，欧洲方面意大利 10%、法国 10%、西班牙 5%。用户以女性为主，占比至少 70%，男性不足 30%。

典型用户画像：20-35 岁，多为职场白领，收入中等，注重休闲生活，会安排短途旅行、聚会、节庆派对等。推品时可留意价格区间和品类匹配。

机会点：Shein 如同高速行驶的列车，但因服饰起家，其他品类空白较多，供小于求。

优势：入驻门槛不高，供应链管理成熟，库存未售出率仅 2%，远低于行业平均的 30%。相比其他平台，Shein 会先审核商品能否上架，帮我们降低库存风险。

# 1.1.2 Shein全托管模式介绍

全托管模式适合只想专注供货、或运营经验不足的卖家，只需把货供到国内 Shein 仓库即可。对新手最友好、团队最省心、操作也最简单。

注意：该模式下我们的角色是供货商，向 Shein 供货，Shein 才是卖家。我们上传的是供货价，不是前端售价。

优势：运营成本低，不用操心推广、海外发货、清关等事项，只需提供商品信息和销售计划。

风险点：产品质检、急采等环节可能产生罚款。

做 Shein 客单价偏低，几十块钱一单，需要持续上品、增加爆品数量来拉高销量，才能获得不错的收益。从选品到爆品通常需要 1-2 个月周期，前期收益不会太多，具体也看个人经验。

# 1.2 项目核心玩法

1、怎么找到 Shein 想要的产品？平台会对每个上传商品进行审核，小善团队摸索出了一些规律，能提高推品成功率。

2、十倍效率选出爆款且供应稳定的产品。Shein 对每个产品设有测试期，一般 14 天，若 14 天后仍卖不动就会下架。

4.跟卖季节性产品，注意上架时间

季节性产品对上架时间节点要求极高，别人已经卖起来的季节性产品再去跟卖，很难起量。

比如返校季饭盒9月已大卖，卖起来的链接基本是7月上架的，9月平台发布需求，即使跟卖，卖起来概率也很低。所谓大势已去。即便平台发布了需求，季节品上架时间已过，上架无用（已测试返校季、万圣节30个品）。

[PRE20]

[PRE21]

后上架的还有断货风险。因为先上架的能拿到量，会提前向工厂下单；等你抢到订单，也只是小订单，工厂不会优先给你发货，会有长期发不出货的风险。

急采不发货，罚款是售价的5倍*订单数

5.跨境平台没有需求的品

不要凭自己想法异想天开，觉得好卖就去选品，要用特殊网络环境先看国外需求。国内外文化差异很大，产品需求差异也非常大。不要“我觉得”，要“平台觉得”（已测试20个淘宝爆品、30个抖音爆品，全军覆没）。

去亚马逊或temu搜一下，看同款最近销量。

[PRE22]

如果是季节性产品，同款页面最近销量都不高，再找一个相对销量最高的链接，看往期销量，可能只是还没到卖起来的时候。

[PRE23]

6.侵权产品

上架终审也会驳回，没驳回的若被抓到也要罚款，所以明显侵权的产品一律不上。例如迪士尼周边、美国电影周边相关的。专利侵权——罚款，图片侵权——下架，一次申诉机会。

所以侵权产品不要去上，上了也是浪费时间。

7.毛利低于10%，组合采购价低于3块钱的产品

① 亏损或毛利低于10%的产品不开发。至少需留10%的成本用于发货、贴标、运费等。若最终核价利润不足10%甚至亏损，就不要做。钱留着自己花，别给平台做贡献！

② 总采购价低于3块，哪怕后期可优化，优化空间也很低，采购价过低的低利润产品不开发。

我们的成本计算方式：采购价+运费（1688显示的运费/3）+贴标算5毛

贴标不一定每家都能贴，要提前问好

8.易坏易破损的产品/平台评价差的产品

① 易损坏破损的产品很容易出现质量问题。希音是一个会把控价格和质量的平台，每个产品都有质量评级，质量等级差会被限流下架。所以已知有质量风险的产品就不要开发，卖起来也会被下架。

② 跟卖时，若同款评价评分低于4.0（平均数大于50，只有一两个评论没有参考意义），就不要跟卖，这种后期也会被平台下架。
