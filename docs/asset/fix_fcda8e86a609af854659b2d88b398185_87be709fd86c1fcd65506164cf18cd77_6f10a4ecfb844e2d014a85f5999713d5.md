欢迎来到6月航海｜小红书蓝海实拍｜实战手册。接下来的日子里，我们会在同一份手册里反复见面。

正式学习高客单蓝海打法前，先把两个基础问题讲明白：

1）高客单蓝海在小红书是什么项目？值不值得做？

2025年，小红书店铺生意还在红利窗口，也处在放量阶段。平台用户有较强购买力，主动搜索的习惯已经养成，因此高客单蓝海产品很适配：利润空间大、对手相对少，新手获得正向反馈的速度也更快。

本次航海顺势而为，把重点放在高客单、高利润、能长期做的模式上：

起步阶段用一件代发降低压力：先锁定高利润蓝海品，再通过混剪二创快速验证；

等到单个链接有稳定销量，再升级为实拍，同时与供应链做更深合作，压风险、提利润。

和过去低客单混剪相比，这套打法要学的技能更多，投入时间也更长。新手前期能零散成交，但若想收入持续稳定，通常要扎进去2-3个月。建议提前有心理预期。

2）哪些人更适合做高客单蓝海？

有电商选品底子、对爆款敏感，或者会做图文/视频、有一定审美，跑通概率会更高。

当然，肯下功夫同样重要。本期更考验耐心；要拿到稳定收入，新手大致要花2-3个月练技能，但从0到1跑通会快一些。

# 零、项目介绍

# 章节概要

眼下小红书上约九成商家集中在女装、日用、小配饰等低客单领域，拼价格、拼款式，单笔利润往往不足30%；

反观高客单蓝海类目，例如手工银饰、中古家具、户外装备，供给量低于搜索量，平台流量池还在扩张——供需缺口，就是溢价来源。

本章会结合平台走向，说明为何选择高客单蓝海，以及具体怎么做，为后续操作打底。

# 0.1 为什么建议做小红书蓝海电商

# 小红书电商趋势

经过几年发展，小红书一些大类目已经拥挤，竞争很凶；但不少细分方向仍像未开采的矿。本期教练之一古辛最早做淘宝蓝海，对比之下，小红书蓝海更占优：用户偏女性，客单接受度高，利润也更厚。

平台同时有推荐和搜索两套机制，所以像创新产品这类品类，在小红书更容易起量。创新产品不会断档，只要流量机制不变，蓝海方向就能持续做，因为总有新东西可卖。

再者，相较红海类目，小红书蓝海离成交更近，正向反馈来得快。产品选对了，开单并不难。

# 蓝海电商的特点

正反馈来得快：这是小红书蓝海最突出的地方。

竞争相对温和：因此更容易做出成绩，陷入价格战的概率也低。

项目周期长：能走多久，关键看平台流量机制；机制稳定，蓝海就能持续。淘宝蓝海后来难做，核心原因就是流量机制变了。

产品供给不用愁：选品方法正确，蓝海品会不断出现。

# 成功案例

小红书蓝海门槛不高，新人上手不难，哪怕没有电商经历，也可能较快拿到正反馈。

品选对了，出单会顺，因为竞争不激烈。真正难的是长期稳定成交，这既看产品是否稳，也看获取流量的能力。

# 0.2 玩法说明

1. 最小MVP路径

a. 操作顺序：注册账号并开店 > 选品（关键） > 找笔记素材 > 发笔记测品（关键） > 出单后找供应商 > 上架商品并发货 > 有持续流量后下样品 > 实拍并发布笔记 > 做好店铺运营管理

b. 时间安排：前3天完成开店＋选品，第一周至少发5篇笔记，持续选品测品，争取第3周出首单，再转实拍

2. 项目核心关键点

a. 选品权重：70%决定成败

b. 最小MVP思路：前期不急着实拍，先跑通蓝海选品—混剪笔记—卖出首单

c. 内容效率：航海会教大家借助AI工具提效（Deepseek＋多维表格写爆款文案）

d. 轻资产投入：初期约1000元/店铺保证金（也可等提现时再交），后期采购样品每次预估几百元（也可与老板谈免费拿样）

3. 航海目标

a. 选品需要反复练，电商选品定生死。新手21天未必赚钱，这很正常，不必焦虑。项目寿命长，要盯长期收益。

# 1.1 准备账号

# 1.1.1 准备至少2个账号

新手通常建议开个人店铺，2个个人店铺对应2个账号，具体要准备：

1. 至少2部手机（不建议一部手机多开，可能被限流）

2. 至少2张电话卡（2个小红书号需2个实名，对应2张卡）

3. 至少2张身份证（可用家人的）

电话卡推荐：

三大运营商都能办副卡，一人可注册认证5个号码，一拖四，副号月租10元；

移动万能副卡，每张10元/月，一个身份证可领2张，第一张与第二张需间隔90天，营业厅能办，App也能办，但营业厅可争取免首年月租；

中国电信App搜无忧卡，5元/月，通常第二天上门；

移动可办8元保号套餐。

手机推荐：

手机既用于登录账号，也用于视频拍摄。

拍摄建议用iPhone，XR以上机型效果更好；

后续放大做直播，iPhone稳定性也更佳，但iPhone无法双开。

# 1.1.2 账号登录&养号

账号登录：

同时运营2个账号，有人会问：能用一部手机登录吗？

可以，但有风险。

若手机自带小红书应用分身（部分安卓机型有，比如红米），可一部手机登两个号；我目前这样操作，账号还没出问题。

[PRE11]

但手机没有分身功能时，别去下载分身神器，容易封号。这种情况只能再备一部手机登账号，去闲鱼或拼多多买二手，三四百元就能满足日常。

实名认证：

注意：小红书实名认证中，一张身份证只能认证一个账号，认证成功后只有注销才能解绑。

认证路径：我 - 左上角三条杠 - 创作中心 - 创作服务的更多服务 - 开通专业号 - 成为专业号 - 选择个人点击立刻申请 - 输入实名认证信息即可。

# 1.1.3 开通店铺

# 1.1.3.1 小红书店铺分类

入驻前先弄清店铺种类，因为不同类型权益不同。

大方向分两种：个人店铺、企业店铺。

无论哪种，都要先认证专业号，因为新注册账号默认非专业号，而非专业号不能做商业行为，包括薯条投放、开店铺等。

所以，想在小红书变现，第一步是升级专业号。

专业号也分个人专业号和企业专业号。

个人型：

个人专业号身份标识为XX博主，比如时尚博主、美食博主等兴趣类博主，基本申请即过，且不收费。

认证流程：

点击【创作中心】—【更多服务】—【开通专业号】—【我是个人】-【实名认证】-选择身份证，填写相关信息即可。

[PRE18]

个人专业号可申请开个人店铺或个体工商店。

名称为XXX（昵称）的店；

店铺保证金最低1000元；

按类目不同，平台收取2-5%技术服务费。

企业型：

申请企业专业号需上传营业执照，并缴纳600元费用，身份标识为XX品牌。

申请流程：

点击【创作中心】—【更多服务】—【开通专业号】—【我是企业】-【填写基础信息】-【填写主体信息】-【资质公函上传】-【运营人信息填写】-缴纳600元费用，等待审核。

填写注意事项见下图：

申请后要多留意，因为申请有效期为30天。30天内未完成，费用不退。通过后每年年审，并续费600元。

企业专业号可开普通企业店和专卖店/旗舰店。

名称为XXX专卖店/旗舰店；

普通企业店保证金最低2000元（详见《小红书类目保证金明细》）；

月营业额＜1万，平台免收技术服务费；

超过1万的部分，平台收取5%作为技术服务费。

2023年9月10日起，一个营业执照最多申请2个专业号、2家店铺。

[PRE20]

同一品牌只能开一家旗舰店，但可同时开不同类型店铺，比如一家旗舰店+一家专卖店，或一家旗舰店+一家普通企业店。

企业专业号营销权益比个人专业号更多，但两者只能二选一，可按需选择。

一般来说，新手开【个人店】即可，门槛较低；企业店主要用于放大做矩阵，平台对账号宽容度也更高。

# 1.1.3.2 【个人店】入驻门槛与流程

入驻门槛：

个人型店铺又分【个人店】和【个体工商户店】。

个人店仅支持服装、百货等常见类目；个体工商户店除常见类目外，还支持奢侈品、珠宝等。

[PRE22]

每个店铺类型可经营类目不同，打勾部分就是可经营类目，具体可在小红书学习中心-规则中心-经营总览中查阅。

开店要缴保证金。个人店和个体工商户均为1000元，但保健品、奢侈品等特殊类目会贵一些。

[PRE23]

客服接待角色，个人店铺可选平台代运营和自主客服两种模式。注意平台代运营要收费，大家按自身情况选择。

平台佣金又叫技术服务费，按类目不同收取2-5%服务费，收费准则详见：https://school.xiaohongshu.com/rule/detail/27/2585?jumpFrom=school

目前小红书为减轻个人店和个体工商户开店负担，店铺入驻后无需缴纳保证金即可发布商品上架售卖。若该店铺累计交易额超过1万元，下个月月初才需补缴保证金，真正实现“无门槛”开店。

入驻流程：

选择个人店铺后，需选择经营类目，之后只需提供姓名、身份证号、手机号，并进行人脸识别，验证成功后店铺开通。

[PRE24]

个体工商户店铺需提前准备：

（1）公司信息的营业执照照片、公司名称、统一社会信用代码、经营地址以及营业执照有效期；

（2）店铺运营授权书。

同样先选店铺经营类目，再按提示上传资料。

与个人店铺不同，个体工商户店审核时间通常为两到三天。

期间可自行登录入驻系统查询。若入驻中遇到无法解决的问题，可在9点到24点直接联系人工客服咨询。

# 1.1.3.3 【企业店】入驻门槛与流程

入驻门槛：

企业型店铺分普通企业店、旗舰店、专卖店以及集合店。

普通企业店铺与个人店铺命名格式一样，“专业号账号名称+的店”。注意企业专业号取名要和商标对应，否则会开不了店铺。

旗舰店名称为xxx（品牌名）旗舰店，专卖店为xxx专卖店，集合店铺为xxx的海外店。

企业型店铺支持经营大部分类目，包括保健品、医药等特殊类目。

平台佣金与个人店铺一样，1w以下不收费，超过部分按5%收取。

保证金根据类目不同略有差异，一般境内最低2万，境外3500美金。
