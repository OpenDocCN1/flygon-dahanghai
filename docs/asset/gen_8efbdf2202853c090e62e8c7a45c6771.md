# 宠物托运，仍是一片服务空白

朋友最近遇到一个实际需求：要把宠物送到另一个城市。他上网一搜，发现市面上确实有专门做宠物运输的团队，而且看起来挺专业。

不过，这类服务目前并不常见。更明显的是，在淘宝检索“宠物托运”“宠物运输”，页面里出现的依然以商品为主，真正提供服务的商家几乎看不到。
