# 3.1 锁定对标账号

# 3.1.1 对标账号的筛选标准

做视频号、视频带货时，对标账号通常要满足几类条件：

第一，专门做单一品类的达人。有没有这类账号，决定我们能不能找到下载视频的来源；这类账号多不多，决定我们能不能筛出最好的样本。

第二，某个达人的视频数量是否足够多。视频多，能参考的时间才长；如果只有 10 条，肯定远远不够。

第三，看达人的点赞数据和销量数据，研究他们在抖音平台做得怎么样。

需要注意：二次剪辑、混剪类内容尽量避开真人露脸视频。这类视频容易被作者投诉，导致下架甚至封号。

# 3.2 做出爆款视频

# 3.2.1 爆款短视频的底层思路 @李诚

1、热点意识

为什么要重视热点？一是平台会给流量倾斜，二是粉丝爱看。实在不知道怎么追热点，就看抖音热榜，什么热就追什么。

2、爆点密度

什么是爆点？爆点就是让视频火起来的元素。一个视频里的爆点越多，火的概率就越大。

3、开篇三秒

一定要重视视频最初的三秒。做短视频，必须在最初三秒抓住注意力；最初三秒留不住人，用户很难把整个视频看完。过了三秒之后，故事要能吸引人持续看下去，最后几秒再让情绪爆发，促使用户转发、评论。

4、爆款视频自评表

新手如果对自己做的视频没把握，可以参考表格给自己的视频打分。得分越高，视频爆的概率通常越大。

# 3.2.3 爆款视频拆解 @李诚

选题与用户思考：

人性共振：聚焦情感共鸣，比如孤独、焦虑、怕生病；或者利益驱动，比如省钱；也可以利用猎奇心理，比如反差。
热点嫁接：结合平台实时热词，比如“旅游旺季攻略”，用工具分析评论高频词，提炼痛点。

结构拆解：

四段式模型：
0—3 秒：高潮前置，比如“户外钓鱼最值得买 5 个必备好物”，或者用金句开头；
3—15 秒：快速戳痛点，比如“洗碗海绵细菌超马桶”；
核心内容：可用平行结构，多角度展示产品；也可用递进结构，让情绪逐渐升温；
结尾：引导互动，比如点赞、评论；或者引导进直播间，完成直播销售转化。

爆点元素分析：

看选题方向、脚本结构、画面节奏（转场、特效）、BGM 情绪、文案话术。比如母婴类视频在 0:15 秒加入婴儿哭声，增强共情。

# 3.2.4 模仿并搭建爆款素材库

以我自己的素材库为例：使用过程中，【场景演示】和【使用效果】可以根据实际情况仿拍替换。

第一步：确定目标和主题

开始搭建短视频素材库之前，先明确自己的目标类目和产品，针对性选择适合自己的素材源，提高素材库的实用性。

第二步：分类整理

把素材按类型、场景、风格等分类整理，方便快速查找和使用。可以用文件夹、标签来分类。

具体操作上：
第一步，根据画面素材搜集，比如需要什么画面、背景、场合、物品、行为等多个角度；
第二步，把收集到的各种素材画面分割成小段，建议 3—5 秒一段，每个画面准备多段；
第三步，把切好的素材放进专用文件夹。准备素材只是前期辛苦，处理好的素材可以长期反复使用；
第四步，找完视频后做爆点拆分，分成 A（前 3 秒，痛点、话题、提出问题等）+B（产品介绍、卖点、解决问题）+C（引导转化），再测试素材、迭代优化。

第三步：收集高质量素材

尽量收集高质量素材，包括高清图片、视频片段等。高质量素材能提升短视频观感，吸引更多观众。部分产品和素材可以从产品评价里搜集。

素材可以在 pdd、淘宝多搜一些素材库。

第四步：持续更新

定期更新素材库，添加新素材，保持新鲜度。每天观察同行、同品爆款素材，有合适的就下载、拆分，放进素材库。

# 3.2.5 基础剪辑与原创处理

建议的视频处理方式是：混剪、二创、原创，不要直接搬运。

短期来看，可以通过更精细的混剪规避审核；但如果想长期获得稳定收益，原创更被鼓励，也更应该走。

建议学习下面的剪辑方法。实际剪辑时，把部分内容，比如产品展示、书籍展示、部分画面或背景，替换成自己实拍的素材，用来通过平台对视频的原创审核。

比如视频脚本结构是：

黄金开场+产品介绍+使用展示+同行对比+优惠活动+引导购买

其中“产品展示”可以用自己实拍素材，或者其他平台的产品好评图、好评视频素材替换。

视频二创流程可以总结为：

拆解爆款视频素材—批量混搭组合或套视频模板—视频去重

第一步：拆解爆款视频素材

第二步：批量混搭组合或套视频模板

软件：剪映（电脑端）。

素材混搭：分析爆款视频片段，针对不同片段排列组合，填入新的素材内容。

……以此类推。
