# 💡 变现地图：先把路看清

账号慢慢有了起色之后，收入就不必只靠一条腿走路了。接商单、拿平台分成、卖知识产品、橱窗带货、做定制服务，这些路子做 AI 内容的人基本都会接触。但顺序别搞反：内容得先过硬，粉丝得先稳定，否则谈认可和持续赚钱都太早。

先把常见路径过一遍：

广告合作：通过星图、蒲公英这类官方渠道接单，也有人直接找品牌私聊，见效相对快。

流量分成：加入平台给创作者的激励项目，播放表现越好，拿到的钱越多。

知识付费与专业服务：开训练营、做付费课，或者替粉丝定制 AI 方案，用自己的专业度和社群信任来换收入。

建议大家先读一遍、心里有个谱，后面真到变现时再动手也不迟。

# 5.1 广告合作：新手最容易启动的入口 @Anny

在变现这件事上，广告合作常常是大家迈出的第一步。知识付费要靠长期专业积累，直播带货背后得有供应链，比较下来，接广告的门槛确实低一些，也更容易先跑通。

不过真开始接之前，各平台的规矩得先弄明白。平台是我们吃饭的地方，按规则来，才能做得久。

① 抖音的广告生态

抖音商业化程度高，品牌和创作者之间的合作大多通过星图来走。粉丝过 1 万，就可以去申请开通星图权限。

星图网址：https://www.xingtu.cn/

星图上的合作大致有两种。第一种是一口价：品牌给一个固定数，比如一条视频 1000 元，你按约拍完发出去，最终数据怎么样都不影响这笔钱。新手很适合这种，没有业绩压力。我第一条星图广告就是一口价，金额也是 1000 元，但那种被认可的感觉，到现在还记得。

第二种是效果付费：通常会给一笔保底，再按下载、注册等实际结果追加。去年我和某款 AI 工具合作，没有保底，结果视频跑爆了，光下载分成就有两万多，比普通一口价高不少。当然，数据不理想时收入也会很难看。有些大品牌的星广广告会带保底，相对稳一些。

官方渠道之外，还有一些品牌会走“水下交易”，也就是私下合作。它确实灵活，品牌方也能省平台服务费，但风险得自己扛。水下结算方式很杂，有的按点赞算，一个赞 0.2 元或 0.5 元，视频发出一周后按实际点赞结。听着公平，可数据一旦不好，可能还不如一口价。

我自己就在水下交易上吃过亏。说好发布后一周结款，结果拖了四个月。对方还是知名品牌，换成小品牌，钱可能直接没影。所以现在除非是长期合作的老客户，否则我都坚持走官方平台。

# 5.2.2 星图接单全流程【新增】@Anny

# 5.2.2.1 第一单星图广告从哪开始？

先开通星图权限。满足条件后（比如粉丝数、视频数量等），到「创作者服务中心」找到星图入口申请开通。开通后记得设置报价，并留下微信或邮箱，方便广告主找到你。抖音报价可以参考粉丝量的 10%～20%。

✅ 星图开通条件：目前是【粉丝数≥1 万】，但平台有时会放宽，建议多留意后台提示。

报价建议：第一次可以比市场价略低，重点是积累案例，但别压得太狠，后面想抬价会很被动。

广告主联系你：一般会通过微信或邮箱找你，加好友后自我介绍，说明自己是广告代理还是品牌方，有没有星图下单链接、任务要求文档等。

# 第一步：确认合作（接单）

1. 核实对方身份：确认是不是走星图下单、是不是正规合作。非星图的线下单要谨慎，尤其是预付费、诱导挂链接的情况。

2. 把需求看清楚：对方会给一份文档（brief）或者口头说明。下面几项一定要确认：

• 品牌主是谁
• 有没有竞品冲突
• 是否需要口播
• 拍摄时长、发布时间、参考内容
• 封面、话题、标签有没有指定要求
• 敏感画面能不能用马赛克代替删减

# 第二步：写脚本、找对标

1. 找对标参考：对方给的 brief 里经常附参考视频，也可以自己找风格相近的爆款。多数广告视频本质上就是“模仿加改造”。

2. 脚本先过审：别一拍脑袋直接拍，先把脚本写好发给对方确认，免得白忙一场。

# 第三步：拍摄 → 送审 → 调整

1. 拍完发给媒介审核：对方看后会提修改意见，大多是封面、节奏、字幕或打码之类的小问题。

2. 修改别嫌烦：这是合作流程的一部分。只要脚本过了，视频大方向一般不会让你重拍。

[PRE3]

# 第四步：提交星图任务

1. 通过合作码扫码提交：审核通过后，媒介会给你合作码或邀请链接，扫码进任务，填好价格、上传视频即可。

注意❗有的合作是先下单再创作，有的则是视频先过审再下单，取决于对方习惯。比如我常合作的品牌媒介，确定每周有任务后，任务码还没下来，我们就先把视频备好了。

第一次合作的话，建议先接受任务码并提交报价，等对方下单后再创作，这样更稳妥。

1. 上传注意事项：

• 视频内容要和脚本一致
• 封面图别乱选，避免违规
• 发布后不要私自删视频

# 第五步：定时发布与成果确认

1. 广告主安排发布时间：你上传后，对方会再审核一遍，和你确认发布时间后定时发布。

[PRE4]

# 第六步：结算收益

1. 到账时间：一般发布后 3 个工作日左右，T+3 抖音会自动结算。

2. 星图平台会收服务费：目前约为任务金额的 5%（平台手续费）。

其他补充事项：

有一点必须重点提醒：尽量不要走水下交易！哪怕对方是你听过的大品牌，哪怕媒介把“结款快”说得天花乱坠，也建议一律走星图或星广。平台虽然收一点服务费，但至少安全有保障。

我自己就遇到过一次：合作方是个人尽皆知的品牌，说水下结款一周到账。结果呢？一周拖成一个月，再拖到两个多月，最后足足四个月才被迫结清，还是撕破脸才拿到的。

总之，私下交易一定要慎重。

合作笔记怎么提交？在小红书 APP 编辑好笔记内容后，点「高级选项-品牌合作」绑定订单，选中对应的合作订单，再回到发布笔记页面就能提交合作笔记。

这时笔记还没有正式公开，其他用户看不到。提交后会进入平台和品牌的审核确认流程。

如果审核没通过，消息通知和蒲公英后台都会收到提醒，按要求修改即可。审核没过可以联系商家重新提供素材，然后重复「第二步：创作笔记」的流程。

如果改的是图文内容，直接在编辑页修改后重新发布合作笔记；如果要改视频内容，得先解除笔记与订单的关联：进入笔记编辑页，在高级选项里取消关联，回到发布页重新发布时再绑定订单。

如果连续 3 次审核都没过，建议这条广告就别接了，直接取消合作。在后台找到该订单取消即可，平台不会处罚。当然，即使取消，也要维护好和商家或 PR 的关系，以后说不定还有合作机会。

# 第四步：发布笔记，等待订单完成

审核通过后就能发布笔记了。在和品牌方约定的时间，点击 APP「消息通知」里的“前往发布笔记”，或者点笔记详情页左上角的「合作品牌已确认」，就能正式发布。

# 第五步：收益到账，完成提现

品牌确认订单完成后，合作款项会到账。如果品牌方没有主动确认，7 天后系统也会自动确认，收益照常到账。

如果对接的是商家，直接结算订单收益；如果对接的是 PR，对方可能会要抽佣。一般加微信后，PR 会聊广告内容和返点比例，抽成通常在 20～40 元之间。能接受就合作，接受不了就拒绝。

当然不是所有 PR 都抽佣，只有想额外赚一笔的才会。等笔记发布完、收益到账，按谈好的分成私下转给 PR 即可。

提现方面：订单确认后，7 天后可在小红书钱包统一提现，提现会扣 10% 的税。

# 5.2.3 广告怎么筛 @皮皮酱

我的账号十条里有九条是广告，但涨粉和变现一点没耽误。原因有两个：一是笔记数据一直很好很稳，二是我很挑，对广告尤其挑。

# 5.2.4 值得接的广告

1. 有预算投流的品牌
可以提前找 PR 确认，或者搜一下这个产品已发广告的数据表现。投流就是品牌方花钱给你的笔记做推广，非常香！！原本数据一般的笔记，很可能被推到千赞以上。

2. 大品牌
a. 母婴类如帮宝适、飞鹤
b. 美妆护肤类如欧莱雅、兰蔻
c. 家居类如美的、戴森、3M

大品牌自带流量，不仅能提高搜索曝光的概率，还能让更多大品牌的 PR 注意到你。

# 5.2.5 最好别接的广告

接一条一万元的广告，比接十条一千元的划算得多。下面这些我都是直接 pass 的：

没几家店铺在卖的杂牌、小牌子；
图文直发（伤账号，还容易违规）；
医药类（专业门槛太高）；
不符合自己消费观的（比如十几块钱一瓶的婴儿水，纯智商税）；
差评多的（会让路人转黑）；
日系品牌（没别的原因，就是不喜欢！！）；
脚本已经写好，品牌方却硬要修改里面提到的缺点的（看个人接受度）；
返点要求离谱的（只有那种很水的买来的号才会给出 30% 到 40% 甚至 50% 的高返点）。

我们大大方方做内容，宁缺毋滥。

# 5.2.6 合作前要谈妥的细节 @虾饼

合作形式分报备笔记和非报备笔记两种。报备笔记就是前面说的官方认可的品牌合作，平台会收取“保护费”；非报备则是私下合作，悄悄打暗广。

非报备又分单品和合集：单品指一篇笔记里只含这一个产品的广告；合集指多个产品同时付费，出现在同一篇笔记里。

单品里还有个“伪合集”的概念：笔记里看似出现了多个产品，真正付费的只有一家，这样能最大程度避免被判定为私自推广。

和 PR 沟通时，下面几个问题要聊清楚：

档期：包括初稿、终稿和最终发布的日期。

授权转发：是否授权品牌方在电商或内容平台发布，是否免费，授权周期多长。尾部博主一般给免费授权，周期在三个月到半年。

授权投流：是否授权品牌方在小红书投流，是否免费，周期多长。投流虽然能帮博主涨数据，但万一品牌爆出丑闻，笔记还被拿去投流，会影响账号形象。所以最好约定一个周期，比如一年内免费授权投流，一年后再看是否继续、是否加钱。

笔记发布后的保留周期：通常是一年或永久。

排竞：笔记发布前后几天内，不能发该品牌竞品的相关笔记。

活动出席：美妆和穿搭类品牌可能会邀请达人参加产品发布会等活动。

# 5.2.1 流量分成（平台奖励、中视频伙伴计划等）

核心逻辑：
借助平台的流量分成计划，把内容播放量变成收入。

中视频伙伴计划：比如 B 站的中视频计划，按视频播放时长和互动数据发放奖励。

举个例子：
抖音流量变现——加入抖音创作者激励计划，每万次播放能拿到一定金额的分成。
