# 4.2.6 选题三雷区：踩中，爆款也难救

👸号面对的是公共流量场，遣词造句和选题方向都得多留个心眼。题材一旦触雷，文章质量再硬也未必能起量；要是不慎带上违禁词，平台还可能限流、压制。

归纳下来，最该躲开的有三类：政治底线、拿逝者做文章的热点，以及借热点挑动对立。

1、政治底线，绝不能越

各大内容平台每个月都会清理成千上万个账号。被处理的大多数是涉黄涉暴内容，还有相当一部分是触碰了政治红线。政治红线怎么记？抓住两个词：党史、军史。打算写文史类内容的作者，尤其要把这根弦绷紧。党和军队的形象始终是正面的，落笔时只能选正面素材，别的内容不要涉足。若想更保险，1840年以后涉及中国的题目，最好统统绕开。民国时期的人和事，建议谨慎对待，新手更不要轻易下笔。文史领域天然带着敏感属性，做自媒体更要牢记责任与初心：不该讲的一个字也不多讲；敏感的历史事件和人物，一点都别沾。那偏爱历史怎么办？新手不妨把目光放到古代史，优先中国古代史：风险低，读者面宽，可写的话题也多，更容易做出爆款。

2、追热点也要有底线：人血馒头吃不得

热点当然要追，这是自媒体人的日常功课；但有一类热点，在公域平台最好连碰都别碰——拿别人的悲剧换流量。比如“二更食堂”，原本粉丝过百万，后来账号被封。滴滴空姐遇害事件发生后，这个号借着大众关注，硬编出许多子虚乌有的桥段，措辞低俗、带色情意味，对逝者极不尊重。这就是吃人血馒头，结果百万粉大号说没就没，没有商量余地。

另一个例子是“今夜90后”。一名孩子和母亲争吵后跳桥，该号捏造了不少根本不存在的细节，后来被证实纯属瞎编，只是为了吸引眼球。账号同样被封。

把逝者当作写作素材，甚至虚构情节，再用夸张、带性暗示的表达去渲染事件，这种做法实在难看。网络空间既有法律约束，也有道德边界。中国人向来认为逝者为大，谁想借死者做文章，很容易引发众怒。有人会问：碰到这类热点，我不吃人血馒头，也不编造谣言，仅仅以普通人的视角点评社会，难道也不行？不行。原因在于，这样做很容易制造群体对立、点燃仇视情绪。社会上那么多正面事件不去关注，偏偏只盯负面题材写，平台不处理这样的账号处理谁？
