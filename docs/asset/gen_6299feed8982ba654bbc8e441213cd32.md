# 7.2.2 联盟分佣：接入 Affiliate 系统

Affiliate，说白了就是海外版的“淘客”玩法：你帮商家把商品或服务推出去，成交后商家按结果给你返佣。知乎好物、抖音书单、外卖返利、美团地推，底层逻辑都相通。

想正式入门，先从 Offer 入手。主流 Offer 里，CPS 和 CPA 最常见。

CPS 按成交金额分佣，卖实物可以，卖软件、程序也可以。SaaS 工具尤其值得留意：产品往往一次配置长期运转，佣金比例不低，有些软件推起来收入并不输传统商品 CPS。比如亚马逊年末促销期间，最高佣金曾到 9.5%；一台 300 美元的冰箱成交，你能拿到 28.5 美元。若专门推某个品牌的独立站 Offer，点数通常更香，保健品类甚至可能超过 50%，可以到 https://fanfuel.co 看看；当然，高佣背后竞争也更凶。

[PRE0]

另一类是 CPA：用户完成指定动作才计费，比如下载一个软件、填一张注册表。普通 CPA 佣金多落在 2—10 美元，若碰到保健品方向，单笔可到六七十美元。

海外线上产品线很宽，可推的标的极多，佣金也普遍可观。选品时别拍脑袋，要结合自己的工具站定位和访客画像，去匹配联盟对象，弄清佣金规则，再决定要不要推。新人入行，不建议只凭感觉找方向；更稳的做法是先找一个比你弱的对手，想办法超过他。否则流量做起来了，却没有合适产品承接，会很尴尬。

对手在推什么，你可以跟着申请；也可以拿“关键词+Affiliate”去谷歌搜；还可以通过 Affiliate Network 合作，或直接联系广告主。联盟会抽一笔中介费，但它帮你把广告主对接好，省去不少运作成本。直接和广告主合作，佣金通常更高，可门槛也更高。三者关系可以类比成：房产中介（Affiliate Network）—你—卖房人（广告主）。

合作时间长了，佣金比例、扣量规则都可以谈。你还能在 https://www.Offervault.com/ 和 https://odigger.com/ 里按关键词搜符合自己 niche 的 Offer。要注意，同一个 Offer 放在不同联盟，转化率可能不同，必须实测；每家公司的运营策略和底线也不一样。

选好产品后，先申请推广资格。多数海外软件、工具类产品会在官网底部放联盟申请入口；也可以直接谷歌“产品名+Affiliate”。注册流程一般不复杂，新人尽量填真实资料，免得佣金到账却提不出来。

付费订阅方面，工具站想推订阅，先要解决收款。个人可以先用 LemonSqueezy；Stripe 最好以公司名义注册，而且优先用海外公司主体。

把海外公司、银行账户、Stripe 配齐后，美元也好，USDT 也好，都能走向“全球收款、国内到账”。银行账户附带的员工卡可绑支付宝消费，海外服务也能顺畅使用，不用再担心 OpenAI 扣费失败。

准备材料包括护照、驾驶证。信息务必真实，别填假资料，避免封号。

为什么要注册海外公司？核心是拿到稳定的收付款通道和银行账户。很多海外服务不对中国大陆开放，或对大陆身份风控更严。海外手机号也能补上：英国号用 giffgaff，每 180 天发一条短信保号（0.3 英镑）；美国号用 Ultra Mobile PayGo，月租 $3。giffgaff 官网可免费申请。以上号码淘宝、京东都能买。

注册地常见英国或美国。英国公司更简单、便宜（1st Formations），开户用 Wise 企业账号即可。我这次注册的是美国公司；业务需要的话，两边都注册也行。

Firstbase 注册开户流程：我选了一站式代理 Firstbase，口碑不错，从公司注册、地址公证到银行开户都有明确指引和服务。论效率，淘宝找代理最省事；但我更偏好能看到 dashboard 的 SaaS 服务。

公司注册州选 Wyoming，类型 LLC，比较适合个人开发者。

租用邮箱（私人地址），通过 Notarize 远程视频公证（1583 Form）。提前准备驾驶证翻译件（淘宝几十块钱），注意证件照片和地址要在同一页展示，建议合并打印成 A4 纸。视频公证需要简单英文沟通，工作人员会让你拍翻译件，询问是否本人意愿，并确认签名。

雇主身份识别号码（EIN）：地址公证后，Firstbase 会继续代理申请 EIN。我在第 10 个工作日收到国税局信件。

Mercury 银行开户：通过 Firstbase 关联提交 EIN、护照审核，1 个工作日内通过。

到这里，公司主体、EIN、私人地址、银行账户、手机号就齐了。私人地址还有不少用途：当账单地址、申请实体银行卡后转寄回国、接收 Google AdSense 验证信件。

Mercury 支持免费开无限量虚拟卡，还能限制交易商户和额度。比如 A 卡只给 Google 用，B 卡只给 OpenAI 用；遇到不给退订入口的流氓服务，直接注销卡号即可。Mercury 虚拟卡能绑支付宝消费，200 元以下免 3% 手续费。

有了银行卡、账单地址和手机号，各种海外服务基本都能正常注册使用；进阶还能申请 ITIN、个人信用卡。

Stripe 企业账号：拿到 EIN 后注册 Stripe 就简单了。网站语言切中文，填中文信息；个人验证用护照；提现账户关联 Mercury 即可。除 Stripe 外，Lemon Squeezy、Paddle 也建议注册，注意这两家都要验证产品网站。

Wise 个人收汇款：注册 Wise 可用大陆身份和护照，麻烦在入金激活。如果 Mercury 有余额，入金很快；否则淘宝找代充更省事。Wise 实体卡（附 3 张虚拟卡）不支持大陆地区申请，但激活后修改个人地址再申请，费用 $9，需要地址证明。Wise 余额可直接兑成人民币，提到国内银行卡、🛰️、支付宝；手续费比“香港银行卡汇款再结汇”更划算，且 Wise 汇率通常高于国内结汇。

更稳妥的结汇方式：
https://twitter.com/zhufengme/status/1706971107885265405

Payoneer 也有同类服务，建议一并注册。

Kraken 交易所提现到 Wise：注册 Kraken 同样用大陆身份和护照。充值 USDT 后，通过订单簿买入欧元（注意不是“兑换”，兑换手续费很贵），选 SEPA 汇款，1 个工作日内可到 Wise 欧元账户。没走美元提现，是因为大陆身份注册没有 ACH 汇款选项，且欧元 SEPA 提现手续费更低，只收 1 欧元。

注册与维护成本：
1. 美国手机号每年 $36
2. Firstbase 注册费用 $399
3. Firstbase 地址邮箱每年 $350
4. Firstbase 公司代理（含年报、税务申报工具）每年 $299
美国公司注册代理很多，Firstbase 不算便宜。以上公司注册、地址公证、EIN 申请、公司代理、报税、银行开户，都可以分别找代理或自助，按自己情况选。
