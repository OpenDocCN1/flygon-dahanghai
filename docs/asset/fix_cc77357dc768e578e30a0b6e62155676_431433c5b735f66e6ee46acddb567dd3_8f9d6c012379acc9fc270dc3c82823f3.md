5.3.3 九格拼图，批量出分镜

分镜脚本已经就绪，接下来要把它变成一张张画面。建议用 Nano banana Pro，它的九格拼图模式能在同一张画布里排出9个分镜；换成即梦，就只能逐张出图。

具体操作：把6.3.2环节产出的分镜描述，按1—9的编号依次贴进出图窗口底部；再把前文资产开发阶段得到的角色图当参考素材，传进 Nano banana Pro。

九格拼图时，每条描述里涉及的人物、道具与环境，尽可能替换成“图1/图2/图N”这种指代。
