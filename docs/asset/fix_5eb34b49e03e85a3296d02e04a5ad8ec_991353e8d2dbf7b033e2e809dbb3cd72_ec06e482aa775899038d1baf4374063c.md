2. 为什么要押注图像/视频方向？
AI 站点种类很多，图像与视频类凭什么更值得做？可以从下面几方面看。

2.1 需求盘子足够大
无论是社媒配图、TikTok 短内容，还是电商展示、品牌物料，图像和视频都是刚需。需求持续增长，能切的机会自然更多。

2.2 生成质量进入交付级
如今的图像与视频生成，已经不只是“演示效果”，而是能真正拿去交付。细节、稳定度、风格控制都达到了实用水平，海报、商品图、短片、广告素材都能覆盖。

2.3 上线成本明显下降
过去做网站要补不少编程知识；现在借助 AI 与成熟模板，完全不懂技术的人也能较快把站点跑起来。图像/视频类尤其如此，可选的模板非常多。

2.4 已有可参考的样本
刘小排老师单枪匹马做出过百万访问量的图像站；林悦己也是从零基础起步，后来靠海外产品获得了实际收入。

2.5 海外付费环境更友好
这里有两个天然优势：一是汇率杠杆，收美元再换回人民币本身就多一层空间；二是付费习惯，海外用户更愿意为顺手的工具买单。

概括一下：需求旺、门槛低、变现路径清楚，眼下正是值得切入的窗口期。

3. 收入模型：这类站点怎么赚钱？

3.1 会员订阅（主流方式）
图像与视频生成要调用模型，天然有成本，因此按周期收费最合理，也最符合用户习惯。用户按月或按年付费后获得使用额度。过去大家担心收境外款项麻烦、需要海外主体，如今操作比想象中简单：境外可用 Stripe、Paddle，境内开发者也可通过 Airwallex、Payoneer 结算，个人也能较快跑通。

3.2 广告补充（形成底层现金流）
除了会员费，不少站点还会接入 Google AdSense，在订阅之外再获得一部分广告收入。单个访客带来的广告收益不算高，但流量放大后可以覆盖不少开支。广告未必有订阅那么可观，却能让站点在早期不至于空转。

3.3 整站转让（一次性回款）
这个思路很有意思。很多独立开发者并不打算长期运营，而是走“做出 MVP → 用数据验证 → 打包出售”的路线。境外有 Flippa、MicroAcquire 等平台，境内也有少量交易渠道。只要站点能跑通付费、用户有增长，就可以作为成型产品转手。对国内开发者来说，这条路压力更小：不必背着长期运营包袱，专注快速迭代，找到 PMF（产品市场契合）后套现离场。

1. 域名：网站在互联网上的地址
通俗地说，域名就是站点在网络上的名字与入口，例如 scys.com 就是生财有术的域名。它全球唯一，别人只有通过它才能找到你的站点。
购买渠道：常见注册商不少，本次航海推荐 Cloudflare（管理方便、解析稳定，但价格略高）。
购买时机：可以等站点接近上线时再买，不必提前占用资金。
想更深入了解域名，可以查看相关传送门。

1. 托管空间：程序与数据的落脚处
有了地址，还需要一个地方放置程序和数据，这就是托管空间。
推荐平台：Vercel、Cloudflare、Netlify 等。
本次航海推荐 Vercel（与 Next.js 兼容度高，部署流程最顺）。
部署流程：
- 注册 GitHub，再用 GitHub 登录 Vercel。
- 上传源码或连接仓库。
- 一键部署，自动生成访问链接。
- 如有自己的域名，可在 Vercel 后台绑定。
后面会手把手带大家完成部署。

1. 源码：决定站点外观与能力
站点的功能和外观，全部由源码决定。它就像房屋里的装修与家具，直接影响使用体验和舒适度。
静态网页：所有访客看到的内容一致（类似样板间）。
优点：加载快、安全、成本低。
适合：个人博客、作品集、公司官网。
动态网页：不同用户有不同体验（类似智能公寓）。
优点：功能丰富，可实现登录、评论、购物车等交互。
缺点：需要数据库与后端支持，开发更复杂。
适合：电商、社区、社交平台。

1. Next.js 框架：前后端一体，快速上线
Next.js 是当前主流的开发框架，可以理解为一套成熟的装修方案。
一体化：前端页面、后端接口、路由系统等都包含在一个框架内。
极速上线：与 Vercel 天然适配，推送源码后几乎可一键部署。
SEO 友好：支持 SSR（服务端渲染），网页内容更容易被搜索引擎收录。
功能全面：既能做静态站点，也能做动态应用，还能便捷接入数据库与 API。

总结
域名像地址：没有地址，别人找不到你。域名让用户能在网络上轻松访问你的站点。
托管空间像房屋：房屋提供实际空间，承载家具与电器；托管空间则是站点的居所，程序和数据都存放在那里。没有它，站点就无处运行。
源码像装修与家具：空房子不能住人，只有装修和家具才能让人真正使用并感到舒适。源码决定站点的外观与功能，是真正的灵魂。
Next.js 像一体化装修方案：普通装修要找不同工种分别完成，而一体化方案把设计、施工、水电、软装打包完成，既快又省心。Next.js 也是如此：前端、后端、SEO、部署全部集成在一起，让建站更高效，也方便后期扩展。
建站如同盖房：先有地址（域名），别人才找得到；再有房屋（托管空间），东西才有地方放；然后加上装修家具（源码），房子才能用；最后用一体化方案（Next.js），让整个过程更快更省心，也便于未来维护。

1. 本地环境配置
要在自己电脑上写代码，除了 AI 编辑器，还需要先配置好开发环境。主要包括：
Node.js：跨平台、开源的 JavaScript 运行环境，可在 Windows、Linux、macOS 等系统上运行。换句话说，想在电脑上运行 JavaScript，就需要安装它（就像给电脑装一个“播放器”，用来播放 JavaScript 程序）。
NPM：NPM（Node Package Manager）是 JavaScript 包管理工具，也是 Node.js 的默认包管理器。它允许开发者下载、安装、共享、管理项目依赖库与工具，就像“应用商店”，帮你安装别人写好的功能模块。
Git：代码的“时光机”，记录所有修改历史，随时回退到旧版本，还能多人协作不冲突。
三者关系：Node.js 是运行环境 → npm 是在这个环境中获取工具的方式 → Git 负责记录和管理源码变化。
