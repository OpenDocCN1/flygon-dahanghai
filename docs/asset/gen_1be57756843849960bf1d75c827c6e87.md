别把视线锁在自己正在做的赛道里。拿宝宝走秀来说，想做点新意，第一步不是闷头拍，而是先去刷同行的内容，尤其留意流量下滑时，有没有人已经先站出来改玩法。

如果刷到有人改过、数据还不错，别犹豫，直接拆解他的形式，照着框架迭代；如果没人动，就把目光移到同类型赛道：宝宝走秀大多在舞台，慢慢会延伸到户外，那就去看场景性质接近的达人秀舞台表演赛道。一句话，同赛道跟着头部账号迭代。

这里分享一个复刻爆款的案例。按上面的思路，先找到同赛道的爆款视频。它的形式是：宝宝和萌宠一起走秀出场，中段两个形象融合，完成宝宝变装，再接一段变装后的走秀。
1.mp4【在线播放】

提示词模板里，彩色块位置都可以自行替换。核心思路是：全身、正对镜头、街拍风；白皙胖乎乎的2岁宝宝，卷发、微笑、红唇，红白碎花低领小裙子，配珍珠耳饰和银链手链；可按需要加动作，比如拥抱；旁边站一只大狗，抓拍行走瞬间；强视觉冲击、时尚感、优雅迷人；再叠加高画质、写实、色彩鲜明、对焦清晰、棚拍灯光、舞台感，竖屏并规避性感。具体参数按自己使用的工具版本调整。

这套形式分析下来，和达人秀的做法差不多：把美女换成宝宝，把动作换成走秀、拥抱，改一改就能落地。制作视频的提示词，可参考 4.1.4 中 AI 怪兽合成部分的图生视频板块。

# 4.1.1.3 第三步：让爆点继续生长

怎么在自己赛道里参考同类型赛道的爆款视频？当你对视频没灵感、不知道怎么做时，这是一个很实用的参照路径：从别的赛道借灵感，再拿回自己的内容里用。

刷的时候也要带着自己赛道的关键词。比如做萌娃萌宠融合，就重点看人与动物同框、融合的内容。

这次参考的对标账号走达人秀方向，三个场景很清楚：原视频里动物是兔子，美女先在兔子旁边跳舞；接着把兔子抱起来；最后美女变成兔兔装。参考视频是：美女与猫.mp4【在线播放】。看视频时，动物跳起来、美女双手抱动物那一刻让我觉得很惊喜，于是我把这个动作搬进了自己的视频。

拿前面的提示词骨架改一下：动作写成 Holding a hedgehog in both hands，背景换成达人秀舞台，服装换成粉色亮片吊带裙，珍珠耳饰和银手链保留。原本设想是宝宝双手抱动物，可能 MJ 理解有差异，出图时抽到一张宝宝一手一只小动物的图，看着特别可爱，就直接用了，没有死守原动作。抽卡偶尔会带来惊喜，只要惊喜点对、又踩中爆点，就好好抓住。

融合后的图没有继续做宝宝变装，而是参考 Gary 教练分享的达人秀视频，让动物穿着衣服跳舞。结合这一点，我把融合后的图从“宝宝变装走秀”改成“动物跳舞”，舞台效果更强。想着动物可爱一点更吸引人，于是把动物生成成幼儿形态，把宝宝的萌感迁移到动物身上。提示词大方向是：全身、正对镜头、街拍风，胖乎乎的2岁小刺猬，行走抓拍，达人秀舞台背景，强视觉冲击、时尚感、优雅迷人，高画质写实，竖屏，规避性感。

这套思路可以简称为“控制变量法”：先迭代一版测试流量，再确定后续创新方向；每次只动 1-2 个地方，其他保持不变；没跑出好数据前，继续按当前模式产视频。比如 12 月 31 日发布的视频，一周内播放量就超过了旧模式视频，之后才上新模式。

# 4.1.2.3 第三步：把分镜变成AI图

画图使用的是 DALL-E3。MJ、SD 我都测试过，但 DALL-E3 的语义理解能力最强，其他画图工具完全比不上；它不需要你单独写提示词，只要把想画的内容告诉它，就能直接画出来。这也是我前面要生成 25 张分镜图的原因：为了把脚本直接转为 AI 图片。

DALL-E3 的入口是网页版 ChatGPT，在探索 GPTs 里找到 DALL-E3，也可以直接复制这个链接：https://chatgpt.com/g/g-2fkFE8rbu-dall-e

怎么解决角色一致性？我原来也遇到这个问题，很头疼。后面看到卡兹克的文章提到，OpenAI 自带的绘画工具 DALL-E3 图片其实都有个 gen_id，利用这个 gen_id 可以控制角色一致性。但实际生成故事分镜时，gen_id 也不是一直管用，有时候会失效，关键还是要保证角色外观尽量使用不同颜色。比如两只猫的故事，就分别使用橘猫和狸花猫，这样就便于区分角色。因此，我的角色一致性办法是：优先选择使用不同角色的外观，再用 gen_id 辅助。

但要注意，这个 gen_id 只在一个聊天窗口中有效，不能跨窗口使用。而且，如果使用 DALL-E3 API 来绘图，也没有办法用 gen_id 控制角色一致性，因为每次 API 的对话就是一次性数据。所以我没有采取写代码调用 API 的方式来生图，而是直接用的网页版。

gen_id 的用法，还可以在 GPT 中尝试使用这段提示词：从现在开始，你的核心目标就是保持角色一致性。必须使用与上一张图像相同的提示和 gen_id 来制作相同角色的新图像，以保证人物一致，且能适配更多的表情、动态、服装与场景。做得好，我给你 1000 美元小费。明白的话请回复明白。提示词复制👉 https://gitee.com/tudoujunha/rpa-gpt/blob/master/prompt_genid.txt
