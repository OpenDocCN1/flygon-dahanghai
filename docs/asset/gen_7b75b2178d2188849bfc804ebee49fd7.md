# 3.4 发布视频

# 3.4.1 怎么发布视频

发视频主要走两条路：

- 手机App端
- 视频号助手网页端（https://channels.weixin.qq.com/）

下面重点讲手机端操作；网页端整体流程差别不大，可以自己再摸索。

# 3.4.2 手机端发布视频+MM188166M（李李）长期更新

手机端发布流程不复杂，几个容易忽略的细节放在后面说。

[PRE5]

- 描述：填写与商品有关的文案。
- 话题：挂流量更高的话题。比如卖芒果，既可以加垂直的#芒果，也可以加类目话题#水果。
- 提到：我们一般不加。做带货时暂时没找到合适使用场景。
- 所在位置：可以加附近位置，位置对内容分发也会有一定帮助。
- 活动：我们通常不加。发起活动后，可以在活动里编辑信息，比如直播活动、私域引导等；每条视频都能挂这个活动，用来增加曝光。
- 链接：前一篇内容提过，带货链接主要在这里添加。

# 3.4.3 电脑端发布视频

除了手机App，也可以用视频号助手网页端：https://channels.weixin.qq.com/。网页端有几个明显优势：

1. 可以定时发布视频。
2. 可以绑定视频号运营者。
3. 管理视频评论更方便。

**定时发布视频**

[PRE6]

比如一个账号要发10条视频，按1小时1条来排。账号一多，用手机逐条发既累又容易出错；一个账号传10条视频时，用定时发布就省事很多。

定期、少量地定时发布，不会影响视频分发，也不会影响流量。

注意几点：

- 网页端和App端发视频效果一样，不会影响流量。
- 话题千万别漏，重要的事情说三遍：话题很重要。
- 一个账号每天建议发10条左右，不要发太多，间隔时间也别太短。

# 3.4.4 如何发布多账号视频

如果你有5个视频号要发，哪怕手上有2台手机，来回切换也很麻烦。这时可以用“绑定运营者”：把B、C、D、E、F这5个账号都绑定到A账号为运营者，A登录视频号助手后，就能统一操作这5个账号的视频发布、评论管理等功能。

[PRE7]

1、评论、私信、打招呼消息回复 @麦洛

这些消息一定要回，回复的目的在于引导用户下单。内容要围绕对方的问题展开，不要只顾自说自话。

[PRE8]

不要因为一两条“不好评论”影响心情，更没必要跟人吵起来，实在不值得。吵架不会让你赚钱，持续做事、持续进步才会。遇到这类评论，可以完全不理，也可以删除；还能在视频号助手里做“精选评论”，让不好的评论不显示出来。内容来源：《视频号直播建议指南》。

2、如何管理多账号评论 @麦洛

手机正在直播，或者几个账号来回切换太麻烦，但又想通过评论回复引导大家去橱窗下单，这时就可以用“绑定视频号运营者”，把几个账号的评论统一管理起来。

如果评论区出现大量“不好的声音”，也可以打开“精选评论”，只放出希望其他浏览者看到的内容。视频号助手的其他功能，可以自行摸索。

发视频时把间隔时间拉长一些，一般就不会有问题。

如果视频没有流量，也就是0播放，原因可能不少，比如：

- 账号被判定为营销号
- 视频内容已经被搬运过

可以一步步排查：

- 如果这个视频号发其他内容有流量，说明是视频内容的问题，换内容即可。
- 如果账号发什么内容都没流量，可能是账号本身的问题。用其他账号测试发布相同内容，如果有流量，就可以考虑注销这个视频号。

从目前的反馈和实际操作看，官方对搬运视频的打击越来越严，这一点后面“5.1 视频零播诊断和解决方案”会展开讲。内容来源：《视频号直播建议指南》。

# 3.4.5 视频发布注意事项

发布视频后，还有一点要留心：新手要保护好自己的品、自己发现的品，尽量不要让微信好友知道，避免增加竞争者。所以下面两件事值得注意：

1. 朋友圈里有同行时，不要给自己的视频点赞，也不要分享到朋友圈，否则容易暴露自己选的品。
2. 不要关注自己的其他视频号，也不要关注自己对标的视频号，因为关注的视频号也会分发给自己的微信好友。

# 四、【实操 3/3】挂商品，测商品

**章节概要**

前面已经完成选品和内容发布。接下来要判断：自己选的品到底合不合适？多数新手一开始并不清楚某个品的效果，前期可以多发流量视频，等视频爆了，再挂商品去测。要是带货视频爆了，记得尽快开直播，成交转化会明显提高。

这一章整理了几种高效测品方式，可按需选择。建议重点关注：

✅交叉测品法：既能看出多个账号的优劣，也能同时判断多个产品中哪个受众更好，再据此优化产品素材和视频细节。

其他方法也可以按需使用：

✅集中测品法：每个品类每天10条视频，集中发在同一个号上。

✅分布式测品法：人群已定，但品类或具体品还没定，可以同时发不同品类视频，哪个爆了继续发，其他删掉。

✅暴力测品法：把对标视频直接拿来发布，3天0播就换；如果爆了，马上精耕细作。

✅带货/流量视频比例：带货视频和内容流量视频可以按一定比例搭配发布。

✅137法则：看1天、3天、7天的账号数据，出问题就果断放弃该品。

**本章航线图**

完成本章学习和实操，就能完成航线图第三阶段：挂商品，测商品，大约需要3—5天。

1、把选中的商品挂到主页橱窗、挂到视频里、挂进直播间购物车，约0.5小时。
2、发布至少10条带货视频，或者直播3次，进行单品测品，约3天，每天2小时。

# 4.1 挂商品

先看视频号带货的最新规则：需要1000粉丝，才能挂小黄车和直播带货；低于1000粉，只能把产品挂在主页橱窗。满1000粉后，可以自己申请开通，也可以等官方自动开通，通常自己申请更快。

注意：如果内容搬运或违规太多，即使粉丝满了1000，也可能开不了小黄车和直播带货。

另外，官方新规计划在2024年3月13日把直播挂商品权限从1000粉调整为100粉。

**千粉的解决办法：**

1. 个体户开店，可免除1000粉要求。几十元成本可以开5个店铺，1个号对应1个店，账号只能带自己店铺上架的产品。
2. 发祝福视频涨粉后，再隐藏这些视频。

建议刚开始不用死磕千粉：先把内容做好，把产品挂到主页橱窗，引导用户去橱窗购买；整个流程跑通后，第二、第三个账号再考虑先开千粉。

现在发视频挂商品，主要靠购物车，所以第一步是拿到购物车权限。

随着5月16日新规《视频号短视频商品分享权益、加热商品功能调整公告》实施，过去0粉强挂车的玩法已经行不通了。现在要挂车，必须先开通购物车权限。

[PRE13]

开通购物车权限，要求如下：

1. 有1000粉丝，或者开通小店。新手不建议一上来就开小店。
2. 符合内容规范。
3. 完成微信支付实名认证。

经过最近大量测试，圈友@纸壳总结了一套开通购物车权限的方法。

对于第一条，如果没达到1000粉，有两种方案：

1. 通过发布好运祝福、婆媳关系、社会百态等内容涨粉。
2. 开一个个体店，只点击开店，不填写资料，也不交店铺保证金。注意，这里说的是店铺保证金，不是达人带货保证金。

第二条符合内容规范，其实比较简单。测试下来，用手机版视频号拍摄，借助系统自带贴纸、特效等功能，拍摄并发布不少于10条内容，连续发两天，大概率能通过审核。

基本完成以上两点，就足以满足开通购物车权限的条件。

此外，市场上也能直接买到带购物车的视频号账号，目前价格大约400—800元一个。如果想快速入局、先上手试试手感，可以通过购买方式获得购物车。

# 4.1.2 挂商品注意事项

在“选品中心”把商品添加到橱窗时，可能会碰到这些问题：

- 没有想要的商品：选品中心找不到想带的品，等于看着钱溜走。
- 佣金率低：帮其他商家带货，赚不到什么钱。
- 僵尸商品：其他商家随便挂的商品，已经不会发货。
- 商品被选品中心下架：其他商家的商品被下架后，已经发出的带货视频会作废，无法再出单。
- 转化率低：其他商家不太会处理从商品入口进来的咨询。
- 退货率高：其他商家发货慢，客户等不及就退货。

所以更建议把商品上在你信得过的人的小商店里。后面会解释为什么“值得信任”很重要。

操作方式如下：

1. 小商店管理员给你发送关联视频号邀请。
2. 在选品中心点击右上角“橱窗管理”。进入选品中心的路径是：创作者中心 → 带货中心 → 去选品。
3. 选择我们绑定的小店。
4. 选择要带货的商品，点击“添加橱窗”。
5. 完成。截图里的店铺只作演示，其中商品不构成带货建议。

为什么要找值得信任的人？因为小商店管理员可以控制商品佣金率。如果带货爆了，无良商家可能把佣金率改成0，导致你第二天之后出的单拿不到一分钱。大家多留个心眼。

同时要特别注意：目前新的视频号已经无法再绑定小商店，也无法把小商店商品添加进橱窗。

# 4.2 高效测品

# 4.2.1 交叉测品法 @李诚

多数新手并不确定一个品到底有没有效果。前期可以多发流量视频，等视频爆了，再去测品。

交叉测品是我测试下来比较好用、也容易快速出效果的方法，推荐新手优先用。

这里用3个账号举例，方便理解交叉测品模式。如果账号数量有限、精力有限、制作的视频少，就把测试时间同步拉长。比如每天发6个，就要测3天；每天发4个，就要测5天。

3个账号测3个商品的方法：

每个账号每天发“2+1”，也就是2条流量视频加1条带货硬视频；精力足够就做2组。测试账号的基本播放和视频内容的基础播放，两个账号同步对比，并记录数据结果。

举例：

A账号发X产品：2条流量视频+1条带货视频；再发Y产品：2条流量视频+1条带货视频，持续三天观察数据。
B账号发Y产品：2条流量视频+1条带货视频；再发Z产品：2条流量视频+1条带货视频，持续三天观察数据。
C账号发Z产品：2条流量视频+1条带货视频；再发X产品：2条流量视频+1条带货视频，持续三天观察数据。

通过3个账号、3天的观察，可以判断A、B、C三个账号的优劣，同时确定X、Y、Z三个产品中哪个受众更好，再据此优化产品素材和视频细节。

如果发布的带货视频爆了，这时赶紧直播，可以大大提高成交。直播方法可以查看“6.1 开启直播带货”。

# 4.2.2 其他测品法 @兰心

# 4.2.2.1 集中测品法

假设有5个号，也选定了5个品类，常见做法是每个品类每天做10条视频，集中发在同一个号上，也可以同时测品。

举例：每个品类搬运10条视频，共50条视频。5个品类各拿两条视频，同时发布到5个号上；哪条视频爆了，就把这个号定位成该品类，继续发该品类视频，其他4个号继续测试。如果第一天50条视频发出去没反应，就每天继续发50条，连续测2—3天。

# 4.2.2.2 分布式测品法

人群定了，但品类或具体品还没定，可以同时发不同品类的视频，哪个爆了继续发，其他删掉。

如果号不多，又在几个品类之间纠结，不知道选哪个，就可以同时发布不同品类视频。哪个先爆，就做哪个品。

举例：想做宝妈市场，但在育儿书籍、育儿好物、婴儿服饰之间犹豫，而且三个品类的视频都已经找好了，就可以同时发布这三类视频，哪个先爆就做哪个品。

# 4.2.2.3 暴力测品法

把对标视频直接搬运后发布，3天0播就直接换；如果爆了，马上精耕细作。

这种方式适合账号多的人。虽然完全不去重，爆款概率偏低，但省下来的时间可以多做几个账号。

# 4.2.2.4 带货 / 流量视频的比例

市面上有说七三比的，也有说五五开的。

其实没有绝对标准，比例跟账号本身、选品经验都有关系。比如账号多，就可以按不同比例去编排，哪种效率高就重点做哪种；如果选品很有把握，可以大部分发带货视频，夹带一两条流量视频；如果不知道这个品效果如何，前期就多发流量视频，爆了之后再测品。

# 4.2.2.5 137 法则

第1天：播放破300，账号正常、视频正常，继续。

第3天：还能破300播放，一切正常，继续；如果没有，可以考虑换对标视频，把原来的隐藏。也可以试试拍窗外风景配音乐，看看有没有播放。如果有，说明号正常，可能是去重做得不够。

第7天：如果能过去重，但视频上不了推荐，就果断注销重来。这样循环反复，直到每个号都稳定播放、稳定出单。

内容来源：《如何高效测品》。
