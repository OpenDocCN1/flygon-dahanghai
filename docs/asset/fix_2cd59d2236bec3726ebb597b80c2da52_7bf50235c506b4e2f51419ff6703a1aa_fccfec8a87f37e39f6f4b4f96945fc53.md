# 十则真实操盘记录：从新客到老客的完整闭环

做生意的难点，从来不只在“把东西卖出去”。流量从哪来、来了怎么接住、成交之后如何让人反复回头，每一步都有门道。下面十个案例来自不同行业的真实操盘复盘，主线始终是同一件事：先找对渠道把客引进来，再用体验和机制把一次交易变成长期关系。

## 轰趴别墅：约三分之二订单靠微信推荐

先拆客源结构。公司团建要找场地，拍板的多半是HR或老板。早期我们把附近写字楼的物业群、HR招聘群加了个遍，隔三差五发条广告，再跟一个红包。家庭聚会这条路一直没有太顺的切入口，目前基本靠团购平台和熟人介绍撑着。游客方向的做法是入驻各类平台、多挂房源，让线上曝光面足够大；学生市场则在校园里设代理，和社团部门合作。多渠道负责把人带进来，细节负责把人留住，现在约三分之二的订单来自微信好友推荐。[PRE0]

轰趴这门生意，本质是按服务收费，不是按场地收费。除了场地预订，我们也接订餐。一单套餐的毛利能有15%到20%。有时场地费才两千出头，客人通过我们订餐、再点些酒水，利润能做到一千多。[PRE1]

后续能提供什么服务，取决于你对客人的了解到什么程度：今天是什么类型的聚会、食材酒水有没有备好。如果没备，顺势推出自家的套餐和酒水就很自然。同行之间也能互相帮衬：比如周六场地已经布置好，客户又急着订周六，把客人推荐给同行，一般能拿10%到15%的返佣。[PRE2]

### 【案例四】儿童卡丁车@后山人：一条尚待开发的细分赛道

1. 选择儿童卡丁车的理由

成人卡丁车很多人都开过，不算新鲜。但行业现实是：场馆占地大、租金和车辆成本高，除少数一二线城市外，大多数场馆很难盈利。经过前期调研，我们判断儿童卡丁车属于细分领域，行业里还没有出现寡头；几家入场较早、规模较大的公司，基本没有自产能力，车辆设备全都依赖代工厂，整体运营水平也一般。可市场需求明摆着，说是蓝海并不夸张。[PRE3]

## 7.3 个护产康行业 @椰子青青：高客单价的拓客与升单

关键词：客单高、充值升单、导购激励和培训、用户转介绍裂变。

这类门店客单价高，拓客是长期刚需。短期活动中，社群邀请、任务宝、分享卡等手段效果不错，因此市面上也有公司专门把“帮门店拓客”当成合作业务来做。客单价越高的生意，越要及时把导购动员起来做销售，激励跟上，后期升单的空间和效果才会好（这招谁用谁知道）。不过门店导购的文化水平参差不齐，活动方案必须提前培训，把操作方法一步步讲清楚。拓客裂变说到底是在利用人性，贪婪、虚荣、炫耀这些情绪很容易驱动人分享和转介绍。做方案时多站在人的心理去想，设身处地问自己：这个活动换成我，愿不愿意参加？这个关键点想通了，方案基本不会差。方案里最重要的，是把门店现有的资源用足；如果手头没有资源，再通过地推、线上投放等方式去补流量，同时推动用户做二次分享和裂变。[PRE4]

长期做产康社群，重点在IP人设：服务要做好，态度要到位，顾问要有温度。每次和客户接触，都是打标签的机会；框架方案里把这些细节写进去，执行时才不会跑偏。[PRE5]

## 7.4 珠宝丽人行业：DR把“爱情承诺”做成体验闭环

【案例五】DR 珠宝@李宏

DR的渠道布局几乎全部押在线上，品牌传播和营销推广都不碰线下，微博、公众号、小红书、B站玩得风生水起。多年前从微博起家时，珠宝行业正在疯狂砸钱开线下门店，DR却把预算集中到买热搜上，在微博把“一生只爱一人”的话题营销做到极致。官微下面质疑声很多，但争议本身就是热度，是品牌营销想要的东西。所以无论外界持什么观点，官微始终不动摇。更难能可贵的是，官微几乎逐条回复粉丝留言，认真互动。这一来，品牌不再是高冷的广告牌，而像一个随时会回应你、@你的朋友。交流机制建立起来之后，珠宝这种靠情感驱动的行业，慢慢在用户心里有了温度。其他平台崛起后，DR转向小红书做理念种草：刻意不谈产品，反复强化“一生只爱一人”，把忠贞的观念种进用户心里。有用户写下这样的体验：23岁收到男友送的DR，问男友知不知道含义，男友结结巴巴地说，这表示这辈子只宠她一个人；还有人说，拒绝表白后的第二天收下DR，对方让她先留着，说这是认定要共度一生的承诺。这分明是锁定了女生的心。把最难揣测的喜好研究透了，变成最懂女人心的品牌，销售自然水到渠成。在抖音和B站，DR活成了翻版农夫山泉——用第三方视角讲故事。一个镜头里，年迈夫妻白发苍苍、重病缠身仍不离不弃，病床前双手紧握，回想着年轻时白头偕老的誓言；另一个故事里，二十多岁的素人男孩出镜，拍摄云南深山里一位耄耋老人，因为生活拮据，没送过爱人别的，只修好了百年之后的居所，要和爱人葬在一起。DR为老人戴上象征一生的婚戒，配上文案：“你敢不敢牵了一个人的手，一辈子都不放开。”这类视频的目的只有一个：我们不生产钻戒，我们只是爱情的搬运工。

理念要落地，就得让用户看得到、摸得到、感受得到。带用户走进线下门店，是品牌和产品最好的体验方式。那线下体验的核心是什么？仪式感。和情感挂钩的东西，不能吃不能喝，更要靠仪式感来烘托。想想追女孩时送花、送巧克力、当众表白，为的是什么？就是制造氛围，让她沉浸式地感受到你对她的好。DR的线下店，一切设计都围绕仪式感展开。男生来取戒指，必须和女生一起，还要带上身份证原件；销售顾问在系统中核查完身份信息，会通过区块链技术打印一张永久信息留存表，让用户签字。双方还要签署真爱宣言——一本又大又厚的册子，签字、摁手印；店里备着拍立得，现场拍照，装裱进册子里，并要求两人发朋友圈向世界宣布爱情。最后，在征得用户同意后，销售顾问会采访两人的相识相爱过程，写成粉丝故事上传官网；公司后台挑选经历独特的故事，进行多次采访，撰写成普通人的爱情故事，再做成文案和vlog，发布到各大平台，让粉丝看到真实的普通人。整个链条用仪式感串起来，线上线下完全打通，新零售的终极目标也就实现了。[PRE7]

## 7.5 B端：自动化设备如何用短视频IP找客户

前面讲到，我们有4000多位宝妈进群、1000多名宝妈加了微信，符合条件的人会到店领礼品。基于这个基础，做三个动作：1、在群里售卖66元定金卡，买卡的人再去裂变；2、给新加微信的人推66元定金卡，买卡的人再去裂变；3、到店领小凳子的人，也推66元定金卡，买卡的人再去裂变。

通过公域同城群流量、抖音流量、自有私域流量以及私域裂变，66元定金卡一共卖出624张。接下来要做的，就是把624张卡消化掉，把到店流量转化掉。这时候门店要造节促销：现场氛围要做出节日感；成单速度上设计紧迫的支付节奏，用老用户带动新用户，所以做群接龙，谁成交谁接龙，互相影响；方案上做阶梯成交，价格有阶梯、礼品有阶梯，早买的客户优先挑礼品、享受更低价格。三步走完，20多天收款160万。这套方案适合瑜伽、水育、教培、医美等行业，把逻辑复制过去，做出几十万问题不大。[PRE15]

把流量引到私域，好处很明显：产品可以持续种草、活动能直接触达用户；短保产品能做预售，提高周转率，减轻库存压力。

4. 会员体系

会员可以做月费、年费或永久会员，但一定要收费。收费能提高粘性，人都有损失厌恶心理。办会员卡时的权益要够丰厚：会员永久95折、88折，首次办卡送50元无门槛代金券，会员永久享受xx服务等，权益写得越有分量越好。平时还可以不定期准备会员小惊喜，刺激一下活跃度。整套会员体系不用搞得太复杂，积分体系视情况可加可不加，折扣和福利给足就够了。员工培训要做好，尤其是服务环节：不要和顾客争辩，不管谁对谁错，有则改之，无则加勉。如果要做私域和会员，收银员的培训、激励机制也要提前规划好，确保每个结账的顾客都会被“推销”一次，把人引导到私域、会员体系或会员群里。
