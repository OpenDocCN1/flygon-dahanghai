## 五、NFT 入门：定义、交易与风险 @可达 Koda @焦波｜水镜

这一节把 NFT 作为加密资产的重要板块来认识。过去一年，NFT 相关新闻不断，国内数字藏品平台和产品也明显增多。但很多人仍不清楚：它为什么能火？价值支撑在哪里？和数字藏品有什么不同？对赚钱人来说，更关心的是市场里有没有赚钱机会。下面会讲 NFT 工具、操作流程、普通人参与的最佳姿势；新兴市场有机会也有风险。最低限度：可以不赚钱，但一定不要亏钱。

### 5.1 NFT 到底是什么？

#### 5.1.1 NFT 的定义与边界

NFT 全称 Non-Fungible Token（非同质化代币），是构建在区块链上的加密数字权益证明，遵循 ERC-721、ERC-1155 等通用标准，具有不可复制、不可篡改、不可分割的特点。每个 NFT 对应一份独特的数字资料，充当数字商品所有权的电子认证或证书，可代表画作、艺术品、音乐、视频、游戏项目以及其他创意作品。作品本身可以无限复制，但代表它的 NFT 在底层链上能被完整追踪，从而为买家提供所有权证明。简单说，NFT 是去中心化的“数字资产或实物资产的数字所有权益书”，类似区块链世界里的“房产证”。由于链上记录难以篡改，NFT 所承载的资产或权益归属公开透明、可追溯，且所有权独一无二。基于这些特性，NFT 也延伸出两方面优势。

#### 5.1.2 NFT 的价值从哪里来？

看到前面的案例和定义，自然会问：NFT 作为一种资产，是否具备价值？甚至能不能算资产？它和传统资产有区别，但市场已经给出直接回应。NFT 本质上是具有特殊属性的 Token，也就是代币。区块链网络出现之前，世界上没有一个不可篡改的平台，能 24 小时不间断、跨越国界、无门槛地完成交易，这一点非常关键。正是这种流动性，让全球参与者随时随地进入同一市场，有限资金和资产在同一场域博弈，使 NFT 具备金融资产属性。外行常调侃“右键保存”：库里花 18 万美金买的无聊猿，有人说我也能保存当头像。没错，你可以获得部分使用权，但你保存的图片并不是 NFT，只是完整 NFT 资产中的一部分信息；你拿不到所有权，也拿不到所有权带来的收益。右键保存的小图能卖吗？不能，没人买。库里买的不是小图的使用价值，而是资产所有权。若以后市场价变成 180 万，很多人仍可右键保存，但只有库里能卖出并获得 180 万。NFT 的核心是数字内容资产化，关键理念是使用权与所有权分离。无聊猿可被无数人复制，真正拥有者全世界只有几千个。想想房产：最重要的不是使用权，你可以自住、空置或出租，最关键的是所有权。区块链世界里，数字资产所有权被清晰记录，公开透明可追溯，只有真正所有者才能交易并获取资产收益。理解越深越会发现，这种理念更接近资产本质。NFT 有没有价值，你可以自己判断。今天仍有很多人怀疑，但现实是 NFT 已是百亿美金市场，正被越来越多人认可，作为投资者值得关注。

### 5.2 NFT 交易市场与藏品实操

这一节看看 NFT 交易市场长什么样，再拿具体藏品讲清楚收藏前必须掌握的关键信息，都是入门最基础的知识。全球最大 NFT 交易市场是 OpenSea，入门知道它就够用。网址：https://opensea.io/ 。进入首页后，每天会展示一些 NFT 项目，顶部搜索框可搜目标 NFT。点击右侧“STATS”可看到排名列表，OpenSea 会按交易额、销售增长、地板价等指标持续更新排名。排第一的是 Bored Ape Yacht Club，也就是著名无聊猿，库里花 18 万美金买的就是它。点开后有些关键信息，投资 NFT 时必须关注。点开具体 NFT，还有重要信息，购买前必须知道。比如某号无聊猿，当前价格是 XX 个以太坊。往下可看该 NFT 在 OpenSea 的历史成交价走势；下方 offers 是市场报价，若 NFT 属于你，可选择接受某个报价完成交易。重点看“Properties”，即 NFT 特征。每个 NFT 都有独一无二的特征组合，不同组合构成稀有度，一般越稀有越值钱。无聊猿有背景、衣服、耳环、眼睛、毛发、帽子等特征，每项后有百分比，表示具备该特征的无聊猿在总数 10000 个中的占比，比例越小越稀有。问题来了：不同特征稀有度不同，如何综合评估整体稀有度？有办法：NFTGO 可查询 NFT，信息比 OpenSea 更全面，比如查无聊猿系列创建以来全部价格走势，OpenSea 做不到；BlockProbe 可查具体 NFT 稀有度排名等，也常用。再往下“Details”模块是链上关键信息：合约地址、Token ID（NFT 编号）、协议标准 ERC-721。再往下是历史交易记录，可看到谁报价、何时何价成交、从哪个钱包转到哪个钱包。这也是链上资产的重要特点：公开可溯源且不可篡改，资产过去每一步变化都清晰可见。以上就是在全球最大 NFT 市场 OpenSea 体验真实市场和具体藏品。海外 NFT 一般建立在以太坊等公链上，可通过虚拟货币在二级市场交易，具备一定金融属性。国内数字藏品可理解为 NFT 的阉割版，多建在联盟链上，比如腾讯幻核作品基于至信链，目前无法转送到其他平台，不同平台铸造的数字藏品也无法流转。另外，数字藏品不支持二次交易，一般用于收藏或转赠，金融属性较弱；国内数字藏品的二级交易，目前多是不合法或偷换概念的方式。还有明显区别：国内数字藏品大部分是一张图卖几百份几千份，海外 NFT 除 PASS 卡类别外，大部分形象各不相同。综合看，NFT 海外原生机会更多；国内数字藏品也不是完全没有机会，但接下来要看政策走向、正规军打法以及实际落地应用方式。

### 5.3 NFT 的盈利路径

现在 NFT 项目最常见的获利方式，是在一级市场铸造，并在开盲盒前择时卖出。这很像港股打新：每个 NFT 项目像一只准备上市的股票，先获取白名单取得购买资格，再在上市阶段抛出获利。目前大部分好项目在一级市场胜率不错，属于相对确定性的收益，因此围绕好项目购买资格的白名单竞争很激烈。最早是靠时间和精力去“肝”白名单。热门项目门槛高，比如要邀请较多人，或在服务器聊天达到一定等级，可能花数天甚至数周；达标后向官方申请，审核通过才拿到白名单。后来演变为抽奖和填表申请结合。抽奖平台有 Premint、Alphabot、Superful 等，绑定 Discord、推特和钱包，完成交互条件后抽取某项目白名单。填表申请常见于热门项目，官方可通过审核机制控制白名单质量。也有人雇佣他人完成繁琐耗力工作，常见于经济水平较低地区，找时薪不高又能完成任务的兼职。另一种是成为项目方半官方人员，比如 Discord 管理员，通常基本能获得白名单奖励。最后是收购别人获得的白名单资格，但风险最大：购买价格、对方是否履约、中途突发情况都会影响最终收益。预售阶段拿到白名单可进可退。此时官方一般会在二级市场 OpenSea 公开对应 NFT 合集，可以买卖。若市场价格扣除手续费后高于铸造价，就有盈利空间。例如市场价 1 个以太，铸造价 0.3 以太，扣除 OpenSea 税费（假设 10%）后，获利为 1×0.9−0.3=0.6 以太，约 400 美元。拿到白名单也可以出售给想要的人。热门项目白名单价值可观，比如前一个月 KPR 白名单价值 1000 美元，明天要发售的公鸡 NFT 也能卖到 300 美元以上；只要白名单有价值，出售就是稳赚方案，当然可能失去博取更大收益的机会。若市场价扣手续费后低于铸造价，项目就进入“破发”阶段，港股打新也有类似情况；可能持续，也可能因市场价格提升而摆脱。和港股打新一样，选对项目、投入后获得较好收益是共同目标，所以标的选择很重要，这里存在巨大信息差。很多热门项目白名单获取成本太高，最终收益可能一般；一些人气没那么高的项目，白名单较容易，只要市场价差足够，反而可能收益不错。除了打新，还有哪些机会？首先是二级市场买卖。总有一些 NFT 可能被低估，比如开盲盒后，有些稀有度不错的 NFT 因卖家不了解价值而低价出售，低价买入再出手可赚差价；牛熊转换间，蓝筹 NFT 也可能被低估，熊市买入、牛市卖出，收益较可观。然后是信息差机会：一个好项目知道的人不多，或坚定看好的人不多，通过大量投入资金或成本，可能获得巨大收益。接着是劳力差机会：白名单获取就是可通过劳动力差规模放大的机会。圈内人时间宝贵，比起自己花时间邀请人、聊天、画画，更愿意请人代做；这些基础工作门槛不高，于是产生代肝、代邀请等产业链。对应 Discord 账号、推特账号也可批量生产出售；一些项目为提门槛限时开放 Discord 服务器，甚至进入这些 Discord 的账号也能卖几百元。然后是流量机会：这个领域流量很有价值，精准流量更值钱，所以有专门在推特做 NFT 项目推广的账号来获利。社群机会：提供项目资讯、分析，提高参与者命中率，也相当有价值。项目太多，每天十几个新项目冒出来，哪些值得投入、怎么投入性价比高、如何批量做号，都是大家关心的；社群若能提供这些价值，会受认可和欢迎。最后是 NFT 项目方的机会，前提是海外市场，这里暂不多说。

### 5.4 NFT 市场的风险与适配人群

这个领域不可避免存在风险。

1）安全风险：黑客横行，骗局不少，缺乏警惕和安全防范很容易上当；一些官方自我保护意识或技术水平不足，Discord 服务器被黑，粉丝接连受骗。身边有赚了不少财富却因安全问题一夜失去的案例，必须重视。

2）二级市场风险：和股票市场一样，追涨杀跌常见，但 NFT 市场变化更快，价格可能短时间翻倍或腰斩；高位进入，多数最后只能割肉。

3）流动性风险：流动性不足时，再低价格也没人买，形成有价无市；没有价值的 NFT 只会变成卖不出去的图片。

4）交易摩擦成本：玩以太坊项目，铸造费之外还要付不菲 GAS；GAS 高峰期铸造可能多花数十甚至数百美元，频繁出手未必增加收益，成本却大幅增加。

5）项目方作恶风险：发行门槛不高，一些项目方只想捞一波就走，并非真正耕耘，常做虚假承诺和宣传，买完后发现只是无价值图片。

6）项目辨别能力不足风险：看不懂项目，别人说什么好就跟着玩，没有足够了解和判断；差项目自然没收益，好项目遇风险也容易恐慌性抛出导致亏损。

7）假货风险：人人都能铸造和上架 NFT，OpenSea 上充斥非官方假 NFT，辨别不了可能花大价钱买假。

所以不是所有人都玩得转。哪些人不适合？

1）把 NFT 当成一夜暴富捷径的人。市场有暴富故事，但存在幸存者偏差：赚大钱的人才宣传，亏钱的人默默承受。不要天天指望暴富，看到别人赚钱就患得患失、心态失衡；应在过程中不断迭代认知，才可能抓住大机会。

2）执行力不足的人。只看信息、很少实操，觉得这也麻烦那也麻烦，不愿琢磨；捡钱机会来时，可能因条件和经验不足抓不住。

3）缺少独立思考的人。见风就是雨，别人说什么就信什么，不思考背后原因和逻辑，也不深入了解项目；一有风吹草动就恐慌放弃。

4）基础问题解决能力偏弱的人。很多问题百度一下就能找到答案，或多尝试几种可能也能解决；若基础问题都等别人解答，效率低且成长慢。

5）安全意识薄弱的人。从不做防护，高风险项目也不用小号钱包尝试。

6）辨别能力不足的人。明显骗局也分辨不出，容易被利益诱惑，一冲动就上头。

7）赌性过强的人。常不分析就 ALL IN 某些项目，指望运气获得高收益。

相反特质的人更容易如鱼得水：有学习能力、有执行力，能在实践中复盘迭代，提高认知，从而提升项目胜率。

### 6.1 GameFi 的含义

看到 GameFi 这个词，我们基本就能猜到它大致在讲什么。
