# BitBrowser 本地接口：窗口管理完整示例

这段脚本演示如何通过 BitBrowser 的本地服务接口，完成浏览器窗口的创建、打开、信息更新、关闭与删除；同时开头还带了一个把图片地址整理成 JSON 的小工具函数。下面按功能拆开看。

## 图片信息辅助函数

先把图片的原始地址、ID 和 imgloc 查看页地址装进字典，序列化后打印出来；如果处理过程中出现异常，就打印错误信息并返回空字符串。

```python
import json

def make_image_info(image_url, image_id):
    info = {
        "url": image_url,
        "id": image_id,
        "viewer_url": f"https://imgloc.com/image/{image_id}"
    }
    try:
        result = json.dumps(info, ensure_ascii=False)
        print(f"图片信息: {result}")
        return result
    except Exception as e:
        error_msg = f"错误: {str(e)}"
        print(error_msg)
        return ""
```

## BitBrowser 本地接口调用

接口服务地址是 `http://127.0.0.1:54345`，请求头统一使用 JSON。下面这个示例只列了部分指纹参数，完整字段请以官方文档为准：https://doc2.bitbrowser.cn/jiekou/ben-di-fu-wu-zhi-nan.html

```python
BASE_URL = "http://127.0.0.1:54345"
HEADERS = {"Content-Type": "application/json"}

def create_window():
    payload = {
        "name": "google",
        "remark": "",
        "proxyMethod": 2,  # 2 自定义代理，3 提取 IP
        "proxyType": "noproxy",  # 可选 noproxy/http/https/socks5/ssh
        "host": "",
        "port": "",
        "proxyUserName": "",
        "browserFingerPrint": {
            "coreVersion": "124"  # Win7/Win8/WinServer 2012 不支持 112 及以上内核
        }
    }
    res = requests.post(f"{BASE_URL}/browser/update",
                        data=json.dumps(payload), headers=HEADERS).json()
    browser_id = res["data"]["id"]
    print(browser_id)
    return browser_id
```

创建窗口时如果对指纹没有特殊要求，通常指定内核版本即可；需要更多指纹参数时再查文档。这个接口既用于新建，也用于更新窗口。需要留意，Win7、Win8 和 WinServer 2012 无法使用 112 及以上内核，窗口会打不开。

更新窗口支持批量，也支持按需修改。`ids` 传数组；只改一个窗口就传一个 ID。想改哪个字段就传哪个字段，比如只改备注；如果不动指纹对象，`browserFingerPrint` 可以不传。

```python
def update_window():
    payload = {
        "ids": ["93672cf112a044f08b653cab691216f0"],
        "remark": "我是一个备注",
        "browserFingerPrint": {}
    }
    res = requests.post(f"{BASE_URL}/browser/update/partial",
                        data=json.dumps(payload), headers=HEADERS).json()
    print(res)
```

打开窗口可以直接使用创建接口返回的 ID，也可以自己指定已有窗口的 ID：

```python
def open_window(browser_id):
    payload = {"id": f"{browser_id}"}
    return requests.post(f"{BASE_URL}/browser/open",
                         data=json.dumps(payload), headers=HEADERS).json()
```

关闭和删除窗口也按 ID 操作：

```python
def close_window(browser_id):
    payload = {"id": f"{browser_id}"}
    requests.post(f"{BASE_URL}/browser/close",
                  data=json.dumps(payload), headers=HEADERS).json()

def delete_window(browser_id):
    payload = {"id": f"{browser_id}"}
    print(requests.post(f"{BASE_URL}/browser/delete",
                        data=json.dumps(payload), headers=HEADERS).json())
```

## 完整执行流程

主流程依次完成：创建窗口、打开窗口、等待 10 秒后关闭、再等待 10 秒后删除。这样可以把窗口的完整生命周期跑一遍。

```python
if __name__ == "__main__":
    browser_id = create_window()
    open_window(browser_id)
    time.sleep(10)  # 等待 10 秒后关闭窗口
    close_window(browser_id)
    time.sleep(10)  # 再等 10 秒后删除窗口
    delete_window(browser_id)
```
