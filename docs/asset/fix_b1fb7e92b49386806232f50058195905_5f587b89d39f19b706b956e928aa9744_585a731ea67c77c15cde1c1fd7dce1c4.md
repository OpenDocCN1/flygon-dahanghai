### 1.3 该选哪个工具？

给新手的建议：国内的产品优先，比如小程序或网页；其次是 MidJourney；再次才是 SD。

国内的工具有助于你建立对出图逻辑的直觉。等认知和经验攒起来，再去碰 MidJourney 或 SD，过程会顺滑得多。要是开局就硬啃 MidJourney 或 SD，被劝退的概率相当高。

1.3.1.3 Stable Diffuison

Stable diffuison 走的是另一条路：开源大模型打底，再叠加若干特化的小模型。它的定制空间极大，谁都能借助这套代码，自己训一个想要的模型，或者开发插件。

代价是，它对描述词很挑剔。同一句话配上不同模型，成品风格能相差十万八千里。举个直观的对照：【1girl】挂上动漫向的模型，产出的是二次元少女；换成真人向的模型，得到的就是 3D 写实人像。

### 2.1 认识 MidJourney 与前期准备

动手之前，先认识一下这款软件，也讲讲它的使用门槛。熟悉了这些，你上手会更快。

#### 2.1.1 它靠什么吃饭？

MidJourney 是一款能打的绘图工具，核心本领大致如下：

1. 按文字提示出图：用户写下一段描述性文字（Prompt Text），AI 据此生成画面。这是它最基础、也最关键的一项。
2. 用参数控制：宽高比、选用的生成模型、放大器等，都可以靠参数来改，从而左右生成结果。
3. 挂载图片地址：把图片的地址写进提示词里，能进一步约束生成效果；该地址需以 .png、.gif 或 .jpg 结尾。
4. 输出高清图：能从最初的毛坯状态一路放大到 8K 级别的清晰度。
5. 反复修改：第一版不满意，就改描述再跑一遍，直到效果合意。
