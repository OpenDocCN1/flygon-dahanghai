# 3.3.3.2 照爆款做视频

情形一：手头没有实物。

那就用网络素材二创混剪，素材去重是重中之重。

❗还是那句提醒：小红书站内素材尽量别用，百货类尤其要小心。站内素材大多源自抖音，用过的素材清晰度不高，被系统查到重复的几率也更大。

抖音找素材的 3 个渠道照旧：

1. 直接搜产品关键词，找视频内容；

2. 进创意中心，找到爆品后，最下方有关联达人秀；

3. 搜到带该产品的博主，点进主页看有没有更多素材。

1.

混剪视频

1）找视频素材

素材可以从小红书或抖音收集爆款视频，一般是 3:4 或 9:16 格式；

2）混剪去重

去重可以用这些办法：换音频、做分割、加转场、叠画中画等剪辑功能。

做封面

3.

写标题

情形二：实物在手。

直接对着爆款实拍。

1.

先收集同领域的爆款素材做记录，挑出自己能实现的拍法，再 1:1 参考实拍。

2.

拍摄时手机一直举着拍就行，不用太担心哪里拍得不好。

3.

拍完导入剪映剪辑，边对照爆款笔记边优化调整。

视频笔记制作要点：

4.

混剪必须给素材去重：搜集爆款素材来混剪时，最好拿 5 个以上的爆款视频一起剪，单个素材重复太多会被判违规；

5.

新手前期建议先做混剪，难度低；长期来看还是要做实拍——找到爆款对标笔记后，先判断自己的条件能不能做到 1:1 模仿，能就实拍；

6.

单款产品的混剪视频发 5 条以内，然后换其他款来测。如果混剪笔记 24 小时曝光低于 200，建议直接删掉，避免后期被举报，删掉后还能继续测款。

# 3.3.5 笔记避坑提醒

电商号的笔记，尽量围绕产品来发，带来的流量才精准。行业知识科普、避坑类的内容也可以发，流量相对精准。其他跟产品无关的东西就别放进账号了，流量或许大，但转化不了。

电商要的是精准流量，能转化的流量才算数，转化不了的弄再多也没用。

有的笔记可能只有几百曝光，照样能出单，就是因为流量精准。

看几个典型的反面案例：

1）博眼球行为

所谓博眼球，说白了就是标题党玩过头。

市面上很多“标题党模板”，比如那张所谓的吸睛标题图，对我们做店铺的来说，真的一点价值都没有。

就像“朋友来我家吃饭，居然说我家很寒颤”，点进去却是菜品丰盛、屋子金碧辉煌，观众只会觉得你在骗人，故意让他进来看你炫富，于是产生抵触，连带反感这篇笔记。

再比如“sos，快来种草这个无广的国货！”结果一看，是天天投广告的某护肤品牌，观众会非常不适。

2）调性不统一，定位不明确

爆款标题模板、吸睛标题这些，要搞清楚它们适合什么样的内容。小红书上的定位可以是店铺变现、引流变现、IP 变现，但三者别混为一谈。

很多人是这样的：有时发生活日常，有时发挂车笔记；封面一会儿纯色底配大字，一会儿自拍照，一会儿四宫格对比图，一会儿又是平平无奇的产品图……封面形式乱七八糟，而且看上去还很 low，没有美感。

3）价格跟目标人群不匹配

产品明摆着面向大学生，价格却贵得离谱，你觉得真有人买吗？

文案拼命强调原材料贵，商品价格却低得夸张，你觉得会有人信吗？

时间有限，运营层面的内容就先说这些。再补充一个团队方面的注意点。
