先找买家，再开工

条件允许，直接去找那些可能掏钱的人，告诉他们你手上有什么服务，把最早愿意尝试的一批人聚起来。再往前一步：先收一笔订金，用真金白银试探市场是否买账。

（2）课程付费渠道：拆同行的卖法

千聊、有讲、荔枝微课、维库、腾讯课堂、网易云课堂、得到、喜马拉雅、混沌大学、小鹅通、十点课程、凯叔讲故事、樊登读书等，都可以看。

如今大家为知识买单的习惯已经养成。手里有拿手本领，不妨试做一门课。无从下手时，去这些渠道输入搜索词，一定有人做过相似内容。重点观察对方怎样搭建内容、怎样打磨、怎样促成下单、售后如何跟进，以及整套盈利方式。听一门不够就多听几门。花点小钱换来一套清楚的服务路径，划算。

你会发现，同类课的骨架大同小异。摸清骨架后，再盘自己的长处，补上额外服务，或加入能打消顾虑的内容。常翻课程销量榜，你会感叹：原来这也能包装成教程。买课的人多，说明需求足够旺。换个切口延展一下。被前人归纳过、又被真实购买检验过的方向，基本靠谱。

（3）电商渠道：盯住成交记录

淘宝、闲鱼、京东、1688、拼多多、小红书、速卖通、亚马逊……都值得翻一翻。

看到淘宝、闲鱼，别只联想手机、衣服和图书。那里除了实物，也流通虚拟商品与服务。你在前面内容渠道试过的词，可以原样搬到淘宝再查一次，说不定有意外收获。电商留下的付款痕迹最真实，也更能照出需求。重点盯：月售、评价条数、标价等。

六、一个需求，百条财路

前面聊的都是借数据摸市场、找需求。案例落在课程上，换别的品类同样成立。

以跨境电商选品为例。怎样挑出用户愿意买的东西？人被打动、准备下单时，真正勾住他的通常不是货本身，而是文案描绘出的那种向往。于是，你可以拆解已经卖爆的商品，看它们怎样写卖点，把高频词记下来。接着去海外常用的内容社区，逐个用数据检验这些词：哪条内容赞多、留言多，就说明这种表达对胃口，可以借鉴，也能化用。拿数据当尺子，比拍脑袋胜算大得多。

同样的思路，放到工具、站点、内容选题上，也能估出需求冷暖。一旦锁定方向、确认需求真实存在，再往下追问：

1. 受众能不能扩？
2. 使用情境能不能扩？
3. 需求本身能不能扩？

具体思路见这里。

最后收个尾：

1. 动手前先摸市场，胜率更高。
2. 只靠熟人圈问一圈，靠不住。
3. 从最基础的搜索词起步，到内容社区等地方筛出那些真正起作用的表达，再借数据读懂偏好。
4. 挖掘时留意用户偏爱的功能点、措辞、故事，划重点：这些是真实感受。
5. 照着研究出的打动点去开发。
6. 把情境、受众、需求向外延展，复制到别的品类。

凡是让人心动的东西，背后都堆着扎实的用户功课。凭空冒出的灵感，多半只是自我感动。说到底，做东西拼的是笨功夫。

举个例子，跨渠道扒数据时，一个词能带出许多结果；有些结果并非按顺序排，你只能一条条归拢。更麻烦的是，查着查着又会蹦出新词，于是搜索、归档来回好几轮。

样本越厚，你越能分辨：哪个功能最招人喜欢，哪句话最戳心，哪种内容形态最能把人说服。也能借助采集工具——八爪鱼、火车头、后羿采集器之类，或者我的课程——让归整资料省力不少。

试想同一个词：1000条结果，旁人耗一小时，你一分钟搞定；10000条结果，旁人要十小时，你仍旧一分钟。取数快、样本多，你自然更摸得准人心，做出来的东西更容易被喜欢，钱也就跟着来了。
