# 5.3.6 入池技巧五：提升“数量”

经常有人问：为什么账号更新了 1 个月还没入池？更新了 2 个月还没入池？

我觉得最好的办法就是多开账号、多发优质文章。矩阵，就是对抗不确定性的最佳方式。

为什么需要多个账号？因为账号是有随机性的。

举个例子：家里三个孩子，同父同母同吃同住，为什么只有其中一个经常生病？很多人会想，是不是这个孩子体质差？但父母能决定孩子的先天体质吗？其实很难。

账号也一样。同一个作者，同样的写作手法，有的账号 2 天就入池，有的 15 天，有的怎么等都等不来。所以我认为，对抗这种不确定性的办法就是多开账号。

这一期航海都建议大家至少 2 个账号起步。如果掌握基本发文能力，还有余力可以再多开几个。

要是发现自己 2 个账号都没入池，就要考虑是不是文章质量出了问题，回到质量上继续打磨就行。

为什么还要多发文章？这里的“多”是多练习、熟能生巧。写得越多，提升越快，能快速摸清一个领域。多写多看，多踩坑，成长自然快。

# 5.4.1 措辞踩坑

很多小伙伴发文前已经习惯查违禁词了，查完也确定没有，但还有一些容易被忽略的地方。

# 5.4.1.1 改违禁词导致行文质量低

前面提到过，很多违禁词是我们完全想不到的。查出来之后，你可能会一脸问号：这居然也是违禁词？

但没办法，平台有平台的规则，大平台为了安全，限制非常严格。有些人会把违禁词中间加空格，或者用拼音、错别字来代替，少量用没问题，但不要在文章开头这样操作，全文也别用太多次。

# 5.4.1.2 带竞品平台的关键字

不要写竞品平台的关键词。比如写着写着不自觉就出来“还花呗”“看🧣”这类字眼，一旦措辞显得有营销意味，就容易被限流。

# 5.4.1.3 带企业名称

很多人会不经意写到“去中国移动上班”“去电信营业厅办事”“去中石化加油”，但这些企业名都不要直接带出来。非写不可的话，就用“某通讯公司”“某银行”来代替。

引用名言时，也不要说是某企业 CEO 说的。

给主角起名字也要当心。之前有个同学一直找不到限流原因，我一看，他主角名字叫“大华”——大华也是知名企业，还上过美国制裁名单。主角叫“小米”之类也一样危险。

甚至不要写“门铃叮咚一声响了”，因为叮咚买菜……

# 5.4.1.4 主人公的名字不要瞎起

你说那避开企业名，找个像人名的总行了吧？那就叫“王强”吧，够像人名了吧？不好意思，“王强”在句易网里也算敏感词。这种很大众的名字，很容易撞上某位官员或者某个穷凶极恶的罪犯。

所以起名别这么指名道姓，可以叫小王、小强、阿强、强强，太实名的都容易踩雷。

但主角叫“小王”就安全了吗？“小王刚刚吃好饭”，有没有问题？不好意思，“王刚”也是敏感词。“小李刚刚洗好澡”——“李刚”也是敏感词。

所以大家一定要多留意，发文前养成过句易网的习惯，要刻进 DNA 里。

# 5.4.1.5 标点符号的运用

标点方面，全文都是逗号、一逗到底不行，动不动就感叹号更不行。那样会被认定是“马景涛体”，文章显得很低质，读者不喜欢，审核也不喜欢！（你们感受到了吗）

# 5.4.1.6 专业领域词汇

不要使用专业领域词汇。比如没有医学资质认证，就不能在文中写“主人公急得乳腺增生”。“增生”“结节”这类词属于医学用语，没有医生资质，写出来可能被判定为误导读者。

# 5.4.1.7 其他查不出的词汇

还有一些句易网可能查不出来的违禁词，同样要小心：

暴力血腥类：割腕、脑浆

封建特色类：占卜、卜卦、风水、当铺

性暗示类：小姨子（句易网里“姐夫”是敏感词）、黑丝（“蕾丝”是敏感词）、情趣、袭胸

这些在句易网中可能查不到，需要靠自己平时积累。

建议收藏，句易网查不出的隐形雷区：

1、渣男、渣女、高富帅、白富美、富二代、官二代、男神、情侣套房、打情骂俏、试管婴儿、代孕

2、首付、房住不炒，以及宣扬房价上涨的内容都会被打压

3、支付宝、信用卡、保险、银行卡

4、投资、炒房、炒股、赌博

5、人格侮辱、干了见不得人的事、好吃懒做、三观不合

6、辞职、离职、资料、空降、投资

7、奥运、抗洪、三胎等话题都受限

8、热点别瞎蹭，很多都是坑。不管写得多正能量，舆论不可测，一样会被限。没有金 V 护身，就老老实实写稳妥的内容，才能长久。

9、叮咚买菜是品牌名，“叮咚”最好别用。

10、涉及其他软件、商品品牌名称的，基本都不提最保险。

这些没什么固定规律，全靠敏感度和日常积累了。

# 5.4.2 图片踩坑

查违禁词大家可能已经很熟练了，但限流原因常常出在图片上。配图也要谨慎，常见错误有这些：

# 5.4.2.1 图片暴露个人信息

生活场景的图片，尽量不要露脸。非要露脸的话，一定要打马赛克，尤其是孩子。

手机号、车牌号等信息也要打码。

明星图片慎用，尤其是负面新闻缠身的明星。

# 5.4.2.2 图片上有营销信息

选图时稍不注意就容易拍到品牌 logo 或公司名字，这类信息很敏感。

大家容易忽略的是品牌标识和品牌文化。比如苹果的电脑标识；美团外卖就算给袋鼠打了马赛克，黄色头盔和工作服也一样能认出来。

再比如育儿领域无意中拍到奶粉罐，罐上的 logo 也会出问题。

图片中的支付宝、🛰️二维码也要打码。

# 5.4.2.3 图片比较负面或敏感的

抽烟、酗酒、娱乐场所等配图属于负面；

大面积裸露肉体属于敏感类型，比如光膀子的大爷，或者给宝宝洗澡的图，甚至小孩子裸露大面积身体，都在敏感范围内。

# 5.4.2.4 图片会引起他人不适的

恐怖图片、车祸现场、某人被打得鼻青脸肿这类都不行。

之前有位学员写过一篇关于蛇的文章，放真实蛇的图片也不行，最后换成卡通蛇才过关。

平时找图时，这些规则都要放在心上。

# 5.4.2.5 图片与内容不符的

文里写的是中国人，配图却是外国人；

文里写婆婆，配图却是两个不同的人在超市和做饭；

文里写车头相撞，配图却是车尾被撞；

写别人的事却用明星照片（除非是写某部影视剧时用剧照，或者追娱乐热点时用明星图）。
