2.2.5.5 参数大全

下面把 MidJourney 里可能会用到的参数都整理出来了，先浏览一遍有个印象，以后需要时直接翻回来查就行。

《MidJourney 参数大全》

1.纵横比（--ar, --aspect）：设定生成图像的长宽比例。
2.变化程度（--chaos）：取值 0 到 100，控制生成结果的多样性，数值越大越独特、越出人意料。
3.快速模式（--fast）：在当前任务中临时切到快速模式，让出图过程提速。
4.图像权重（--iw）：取值 0 到 2，决定图像提示相对文本描述的分量，默认为 1，数值越高图像对结果的影响越强。
5.排除元素（--no）：比如“--no plants”会尽量在生成的图中去掉植物。
6.渲染质量（--quality, --q）：可选 .25、.5 或 1，影响图像渲染质量和耗时，数值高则质量更好但更费时。
7.随机风格（--style random）：自动往提示里加入随机风格代码，从 16、64 或 128 种风格中选一种，增添创意元素。
8.放松模式（--relax）：在当前任务中临时切到放松模式，生成更慢但资源消耗更少。
9.重复任务（--repeat, --r）：取值 1 到 40，用同一提示多次创建任务，适合快速试出多种结果。
10.种子（--seed）：取值 0 到 4294967295，指定生成图像的起始随机因素，相同的种子和提示会产出相似的图像。
11.提前终止（--stop）：取值 10 到 100，提前结束生成过程，数值越小图像越模糊、细节越少。
12.风格（--style）：切换不同版本的 MidJourney 模型，如不同的 5.x 版本或 Niji 模型，从而改变图像风格。
13.风格化（--stylize, --s）：控制 MidJourney 默认美学风格对图像的影响程度。
14.图块（--tile）：生成可当作重复图案使用的图像，用于制作连续图案效果。
15.Turbo 模式（--turbo）：在当前任务中临时切到 Turbo 模式，加快图像生成速度。
16.怪异（--weird, --w）：取值 0 到 3000，探索不同寻常和创新的美学风格。
17.视频（--video）：生成图像生成过程的短视频，适用于部分模型版本。
18.提示变体：用大括号 {} 创建多个提示变体，例如 {red, green, yellow} 会分别生成红、绿、黄三种颜色的不同图像。

第一步：写壁纸提示词

这里我给大家总结了一个提示词公式：[主体] + [风格] + [特定要求] + [附加描述]

只要在公式对应位置填上相应内容，AI 就能帮我们完成壁纸制作。那“主体”“风格”“附加描述”“特定要求”分别指什么？举个例子你就明白了。

比如现在我想要一幅美少女油画，直接用大白话说出来就是“一幅美少女油画”。这里的“美少女”是[主体]，“油画”是[风格]。

如果想让美少女更具体，可以多加描述：猫耳、洛丽塔。

想让她出现在指定场景，可以加入森林、小河、树枝、石头等元素。

猫耳、洛丽塔、森林、小河、树枝、石头，这些就是[特定要求]。

我还想让画面更有质感，可以加入柔和的光线、耶稣光，这就是[附加描述]。
