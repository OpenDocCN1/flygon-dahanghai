# 七、短视频投流：从现状到实操
# 7.2.1 短视频投放现状（@Never）
所谓视频号短视频投放，就是仅通过短视频购物车出单。当前仍以🛰️豆投放为主。下面简单说说🛰️豆图文投放的特点，供参考：

1）优势
- 不用开直播，这恰好是我的短板；
- 单人或不大的小团队就能干；
- 利润率还算可以；
- 稳定性比自然流更强；
- 对短视频能力的提升很快。

2）劣势
- 对资金要求高；
- 需要一定网感，对产品和视频要有判断力；
- 单兵作战对综合能力要求高，选品、视频框架、混剪过审、投放、供应链、售后都要能把控；
- 利润率要求高，长期品很难打。

3）行业问题
目前微豆短视频投放容易掉购物车。如果现在想进场，建议准备多个手机号、实名🛰️；我这边以买号为主，自己养号时间成本太高。今年618起，视频号对短视频投放要求提高不少，视频过审后也容易触发人审，混剪投放因此变难，我之前总结的低客单价投放打法现在也很难跑。

4）为什么还能做
短视频投放利润率这么高还能做，本质是吃了视频号人群红利：平台用户对价格不敏感，溢价容易；用户不太会退款、不太会比价，质量一般的产品也能保持较低退货率；平台尚不成熟，小店客服短缺、店铺管理不严，拒绝用户退款问题不大，店铺分低也能提款，商家有恃无恐。

# 7.2.2 投放的底层逻辑
不少刚接触短视频平台的同学对投放陌生，甚至对投放素材没感知，根源是不熟悉平台流量机制。每个短视频平台的流量大致分两类：内容流量和商业化流量，二者实时流转。短视频平台按兴趣推荐推送流量，而兴趣推荐的底层，是用户和视频各自携带的标签；标签又来自数据表现，包括用户行为数据，以及视频播放和成交数据。

[PRE2]
商业化流量和日常社区流量不太一样，通常有较明确的购买需求，平台清洗商业化流量的主要工具是购物车。投放时一般很少有自然流量推荐进入，只有部分回流和转发流量订单；商业化流量重成交密度，完播、点赞等浅层数据相对弱。

# 7.2.3 投放前要准备什么
新入门短视频投放，可以做这几项准备：
1. 准备带购物车权限的账号。一个账号可以投不同产品，也可以同一时期只投一类产品；投放期间没有账号标签，只有视频的成交人群标签，且不特别重浅层数据，核心指标是成交密度。
2. 选适合视频号投放的产品。
3. 制作对应视频素材，原创、混剪、半原创都可以。
4. 开好视频号小店。平台越来越规范，尽量别选差评很多的产品，容易废店。
5. 其他准备：选品/素材工具（蝉妈妈、有米有术等）、投放辅助工具（诸葛、魔力、火星）、个体工商户/企业执照（开对公）、一定流动资金。

# 7.2.5 投放实操说明
# 7.2.5.1 产品怎么选：低客单与中高客单
投放只是短视频投放项目中的一环，而且不是特别重要的一环，胆大心细即可。出单后要联系供应链、处理店铺售后，这些都不复杂。这里主要说不同客单价产品的特性。

1、低客单价
低客单价产品很香，别被表面迷惑，它有以下几个绝对优势：
- 成交密度高，更容易把视频热度拉起来；
- 用户购买决策难度低，所以对素材要求更低。让用户只凭一个视频掏200块，要求就高了，尤其在视频号上，老年人会计较细节，比如材质、工艺、是否纯天然、是否健康无害、发货速度、收到货是否一样等。所以低客单价产品非常适合刚入门的投手。
- 产品多。新奇特、极具性价比的低客单价产品很多，不缺，而且可以反复打、按周期打。
- 投放出价更低。单次投放费用更低，可以全量卡赔付，且不太影响资金利用率。
- 退货率低。低客单价产品用户付出价值不高，产品就算一般，也懒得退；售后再加点技巧（后面细述），退货可以做到很低。

拿我打过的一个低客单产品举例：高尔夫马桶刷。
[PRE6]
[PRE7]
只卖2只装和3只装，1只装售罄。产品利润率83%，2只装售价29.9，用户也完全能接受；含退货的盈亏ROI在1.25，出价18块的赔付ROI能做到1.66-1.99。这个品当时投放ROI 1.55，全量卡赔付状态下，回流5%，赔付20%以上，GMV利润率30%以上。这个品当时这个店买了1300多套，因为购物车掉了，只打了一天，销售额4万2，利润1.3万-1.5万。

劣势点：
这种品能一直打当然香，但现在视频号整体行情不行，劣势也凸显了。
- 视频素材烂大街。这类视频一般比较短，搬运的人太多，审核收紧后，投放时想撑过30万播放非常难，疑似搬运的提示很多。
- 投产不稳定。很多人对素材完全不处理，拿个10来秒的视频就上，偶尔跑出投产，偶尔跑亏。这类产品客单价低，投放时很考验心理承受能力，有时候跑到1左右很正常，需要抗住；视频标签稳定、各方面细节做好，才能有稳定投产去承接流量。

2、中高客单价
中高客单价很吸引人，我也一直在挑战。有的品确实暴力，优劣势简单说下。
优势：
- 销售额大。这个说法不完全对，低客单价销售额也能很大；只是高客单价产品如果受众面够广，销售额能拉到很恐怖的程度。我目前还没打过高客单价万单产品，这是我一直追求的。
- 有些产品利润率恐怖。美妆、带功效类的食品，利润率非常恐怖；其他高客单价产品利润率会相对低，直接导致货款压力很大。
- 找对方法能撑得更久。高客单价意味着做的人少、搬运也少，只要通过一定技巧，可以撑过更多人审，拿到更多流量，稳定性更强。
劣势：
- 对视频素材要求高；
- 退货率相对较高。用户花了这么多钱，想劝退不满用户，难度高很多；
- 有些品货款压力大，资金利用率低；
- 不好全量卡赔付。出价比较高，如果全部卡赔付，资金利用率会很低（有足够资本的忽略）。

3、总结
低客单价产品适合新手操作。目前比较稳妥的方式是起新号、自己原创拍摄，拍摄难度也比较低，可以尝试部分原创或全部原创。我身边有做低客单原创的朋友，能撑过人审，突破200万播放，利润非常可观。
有很强视频素材制作能力的内容团队或个人，可以多尝试中高客单价。

# 7.2.5.2 投放前先算账
投放前一定先把账算清楚。和自然流选品中心佣金带货不同，投放要把全链路把控在自己手中，账算明白，投放才能有的放矢。
[PRE8]
以高尔夫马桶刷为例。2个装的SKU，代发价2.9元，售价29.9元；在没有退货和平台扣点的情况下，理想ROI是1.2，ROI=售价/毛利。算上平台扣点和预估售前售后，盈亏ROI=1.26。也就是说，产品算上平台扣点、售前售后退货后，盈亏ROI是1.26，这是投放时的重要指标；如果投放ROI正好等于1.26，投放端利润为0。再简单点，买126元GMV（卖≈4.2件），产品成本是4.2*4.9=20.6，平台扣点+退货≈5.4，毛利是100块。投放时，投放投产ROI=GMV/投放金额；投放端投产>1.26就有利润。比如下面这笔计划，预算100元，GMV99.8，投产为1左右；如果都这个投产，就是亏钱。

# 7.2.5.3 投放的三个核心问题
投放前要清楚几件事：
1. 投放预算。也就是我有多少钱来投，根据这个规划一天预算以及每小时大致花费。
2. 投放目标。想投到什么投产，你觉得项目可行、目标利润率是多少。比如上面产品盈亏ROI是1.26，那我就想投产在1.5以上，并且有赔付的情况下可以接受；确定这些再投。投放最好用第三方辅助工具，我目前在用诸葛智投。
3. 放大数据。有一定数据体量，看投产、看转化才有意义。测品阶段要把视频数据推到一定量级。比如每小时花100块，客单价30元，正常一小时出5单，就能达到1.5投产；如果少1单或2单，投产直接掉到0.9和1.2，对整体率影响过大，导致投产不稳定，数据准确度太低，没有参考意义。

# 7.2.5.4 如何理解流速
讲投放实操前，先分享我对投放端流量的理解。做过投放的人都知道流速重要，但流速具体有什么作用，值得想一想。
首先，什么是流速？主要看我们花钱的素材，或者看视频播放量，大约能看出流速大小；但从花多少钱，可以很直观看到流速大小和变化。
其次，流速代表什么？代表视频热度。想爆单，素材一定要有高流速，因为你是花钱买量，花钱速度越快，代表视频热度越高，出单速度也越快。
最后，流速对ROI和订单的影响。学过统计学的知道正态分布，流速也是这个规律。一个产品投放过程中，一般随着流速增加，投产逐渐趋于稳定；达到峰值后继续增加流速，投产会逐步下降。这是因为流速过高，视频素材的转化能力跟不上更泛流量的增加，导致投产降低。

# 7.2.5.5 投放的六个阶段
投放大致分这几个阶段，供参考。目前赔付难度降低，中低客单价可以在放量阶段就开始用卡赔付计划放量：
1. 测品阶段。一般3～5条计划，测试产品ROI；我一般拉得比较多，对素材有信心的话，可以多给点试错成本。
2. 放量阶段。看投放预算定，投产在预期范围内，看小时级消耗速度和ROI，可以无限拉计划，无视空耗。
3. 压价阶段。放量阶段投产如果逐渐下滑，可以适当压价提升ROI，但还是要保量级。比如50块一个成交投产Hold不住，可以尝试45；45能出数据且投产OK，就批量拉45。要多拉，因为50的退下来之后，相同计划数下50的流速会大于45。
4. 卡赔付阶段。现在很多产品可以上来直接卡赔付计划放量，3单出赔付；全量卡赔付，只要流速够、能消耗，基本可以做到高投产计划赚、低投产计划赔，稳赚。当然出价要能出数据，且赔付ROI大于盈亏ROI。
5. 定向保投产阶段。投放后期可以加一些定向，去拉升ROI。
6. 异常情况。测品阶段不出数据，可以尝试智能出价、定向人群、作者，快速出数据；目前测试下来，定向作者+智能出价经常能跑正。如果智能还是不出，可以开双智能（智能出价+智能投放）测账号是否存在问题。

以上所有阶段，都建立在清楚自己的盈亏ROI，并通过三方工具的小时级ROI和花费来调整。

重点：
投放时一般会拉很多计划，可能几百条，一条条盯投产不现实。要通过三方工具盯每小时综合投产；如果每小时综合投产在预期内，放量阶段可以不用调整单条计划；如果连续几个小时投产和流速有问题，就需要调整。
低投产、光花钱不出单的计划怎么处理：
1. 放量阶段可以不用管，这些计划在帮你拉视频热度；大量关闭会让视频热度降低，放量就没意义。
2. 卡赔付阶段重点关注这类计划有没有卡赔付希望；如果能卡到赔付，跑得再差也可以不处理，只要能消耗就OK。
3. 保投产阶段不要太大量级，可以适当调整、关闭计划，把投产和流速控制到预期范围内。

# 7.2.6.1 选品与素材：信任是成交起点
做视频号，最核心的部分是品和素材。二流的品+一流的素材，依然能打爆；但一流的品+二流的素材，却不一定能爆。从这个角度看，素材的重要性要高过品。

1）爆款素材的底层逻辑
到底什么样的素材是一流素材？根据过往经验和对市面上爆款素材的研究，我们内部提出了“三级信任”的概念。
用户看完视频后，促使用户下单的最核心因素是什么？痛点？产品效果？话术？研究大量素材后，我们得出结论：促使用户下单的最核心因素是信任。
想象一下，亲朋好友向你推销一样产品，你是不是更容易下单？为什么？就是基于信任。视频号用户下单，首先基于对平台的信任，然后才是对内容的认可。
为什么现在有些品的素材发出去，很多人评论不好用、骗人之类？因为信任被破坏了。其他因素都建立在信任基础上；没有信任，效果展示再厉害，用户也不会下单。
为了从信任角度出发，我们对素材进行了分级：
一级信任：普通展示介绍产品，包括产品优点、效果、实用性等。大多数素材都属于这个级别。
