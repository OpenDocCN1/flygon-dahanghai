# 月销200万到500万：知识博主转型带货的破局复盘
（精华帖·51赞）

#抖音

在生财潜水满一年，今天第一次冒泡。先抛个提醒：文末会聊一个让我至少赔掉五百万的直播带货深坑。

我是骏昌小叔儿，早期网名叫申老板。当年和现在大家熟知的“海参哥”算是同期产物，可惜没干过他，后来转向短视频IP孵化、直播带货运营和IP操盘。接下来大概半小时，我会把自己从知识博主月销200万GMV，到半年后带货月销500万GMV的转型路径完整拆解；也会聊聊电商公司月总营收怎么做到3000万以上，以及为什么如今把百余人团队解散、准备重新搭班子再出发。

转型动因、落地方法、踩过的坑、交过的学费、沉淀的经验，今天一次讲透，也希望能激发更多思考与讨论。

## 创业五年，知识博主月销稳定200万，为何还要转带货？

原因一：做知识博主，最初并非经过严谨商业推演的选择。

我此前在上市公司做管理，心里一直揣着创业梦，也想多赚钱。最早的逻辑很直接：从当下能立刻变现的方式切入，卖自己的时间。咨询费从每小时500元涨到2000元，后来带大班课到每小时5000元，再后来做录播课，把时间变成可复利的产品。月稳定变现到60万左右时，我和当时的同事出来创业。18年开始碰直播带货，21年初又赶上抖音知识付费爆发。2021年我们从零起号，四个合伙人的账号都做到20万粉上下，我也很快实现单月稳定GMV 200万+。

做了两年，我发现一个很可怕的事实：20年、21年、22年营收每年增长200%以上，利润却没有明显增加，人反而越来越累。我去看同行，结果更吓人——我们已经是赛道里少数还在赚钱的公司，同行比我们更累，有的烧着投资人的钱，至今没盈利。这个赛道似乎没人能轻松赚钱。

同一年，有件事启发了我。21年我们孵化一个账号，对方原本想做玩具类目的拆箱IP。起号过程中我们发现，用户的核心诉求是“看到好东西就想要”。于是直接把他定位成带货达人，主带高端玩具，定向高消费男士人群。后来接入优质供应链，账号越做越好。21年底刚起步时，一场GMV三万，一个月播20场就是60万，当时没人注意。到22年像滚雪球一样，618当天几十万，双11当天做到百万级。更关键的是，他越做越轻松：单月千万级时团队只有5个人；而我们公司月销300万时已经接近50人。

知识博主和带货达人的商业模式，差在三个关键点。

第一，复购。除K12外，知识付费复购率普遍低，成人教育整体不超过20%。这注定我们想增长就得抢流量，而流量越来越贵、新人越来越少，赛道越来越卷。电商如果选对赛道，比如高端产品，复购率能做到70%以上。用户相信博主，产品用了有结果，就会持续复购，甚至长期认准你。

第二，可复制。知识付费增长最难的是IP不可复制。很多公司就是围绕一两个IP的个体户，再复制很难，因为用户买的是你这个人，信任建立周期长；IP不在，用户就不买单。电商更多拼货，货足够好，人的权重会下降。我们孵化的带货博主双11一天播16小时，他自己8小时，副播8小时。培养一个带货主播上手约一个月，培养知识博主至少要半年。可复制性决定公司天花板。

第三，团队配置。那位朋友双11单日百万时，团队只有5人：1个负责人、2个跟播、1个私域、1个剪辑。我们知识付费全年3000多万时，团队一度到70人，后文也提到50人的规模作对比。人多意味着业务重、支出高、风险大。换句话说，朋友想休息，付5个人工资；我们要付50个人的，自己简直成了给几十号人打工的苦力。我还整理过一张对照表，电商和知识付费在这三点上的差异很清楚。

这三个原因，让我21年末下决心带全公司转型。

## 半年做到月销500万：我做了哪些实操动作？

### 第一件事：选品

这是最重要、也是新手最容易犯错的环节。

我转型时看过不少账号尝试带货，他们最大的问题是把“自己见过的带货”当成带货：找销量高的品，看起来好卖的先卖，把人攒起来再说。结果上了一堆9.9、29.9、99，辛苦几天卖不了几千块。

错在哪？我们常刷到明星直播间：明星扭一扭说9块9，直播间10万+，销量疯涨，一天几千万几个亿。但普通人不能选这条路。带货已进入后半场，你如果不是自带流量的人，不是张柏芝，就别想9块9打法。那需要强流量支撑和极热闹的直播间。

普通人能选的，一定是明星直播间卖不了或不愿卖的货。平台像一个大商场，中间几个大舞台卖大众货；你要在侧边开一家精品专柜，把有付费能力、对品类感兴趣的人分流进来。所以第一个经验：放弃低价品，只选“三高”——高客单、高口碑、高复购。

高客单：精品店要活下去，必须锁定高付费人群。平均客单价3000以上，GPM做到1万以上，也就是平台推来1000人，至少完成1万元销售额。有人会说这种品卖不动，那是小看平台了。很多人在抖音买过几千元客单的产品，平台覆盖一半中国人，有消费力的人不少。一单3000，一晚30人付款就是9万GMV，一个月接近300万。适合的方向包括保健品、电子产品、首饰、高端女装、精品家居家具等，这类店才是真正闷声发财。还有人问：先卖9.9攒人气，再卖高客单行不行？绝对不行。直播间靠标签推荐，卖便宜货就来买便宜货的人，卖贵货才能推来有消费力的人。所以一开始就要用高客单起号。

高口碑：不少主播起来又塌房，根子是不爱惜羽毛，把用户当韭菜。都卖保健品、都喊抗衰，有的产品做不到，有的真有用；有的主播自己不懂，看品牌方热情、佣金高就选。差产品可能第一波让你赚钱，后面没水花，口碑分被拉低，用户一波波失去信任。高口碑和高客单是连着的：做高客单，必须有行业专家认知。卖可乐不需要认知，卖3000元保健品需要极强认知，产品必须有用，否则用户买完骂你，号也做不久。我们和供应链深度合作，也因机缘拿到不少业内信息，深度绑定了一个品牌，后来不仅做达播，还帮它把店铺自播起盘。一句话，高口碑就是主播别想着赚快钱，别觉得差不多、试两天就上。

高复购：这是三高里最有难度的一点。很多人带货难，第一步就栽在选品。大家可以拿三高原则审视自己的货盘：高客单、高口碑、高复购能不能做到？能做到，只要人不傻、团队不傻，直播就能起来。我们团队顺利，不是因为直播能力多强，而是选品上PK掉99.99%的人：直接选保健品赛道，高端保健品，抗衰类保健品，而且是真正有用的抗衰类保健品。选难走的路，会越走越简单；选简单的路，会越走越难。最后强调：好选品是成功的一半，没选好品，永远不要贸然转型。

### 第二件事：专家人设

选品和达人人设天然相连。选了三高产品，主播就应该是专家型人设。这也是知识博主转型的优势：知识博主天然有专家感，空气都能卖，好产品更能卖。

什么是好的专家人设？卖保健品，可以是营养学专家、院校博士、中医世家、健康达人。没有这么专业怎么办？和赛道、品牌建立联系。我转型保健品，本身不是营养学专家，就直接说自己是品牌在国内合作运营公司的老板，和品牌深度合作多年，全家人都在吃，这也是一种信任背书。同理，品牌推广大使、营销负责人、长期重度用户、测评过多种产品的人，都是专家人设。总之，给用户一个相信你的理由。再举例：英语老师转带货护肤品，可以说自己在高校任教多年，因为皮肤问题研究测评过多种护肤品，最终选择某个产品，甚至和小众品牌建立合作、帮助做市场推广（举例参考，以真实情况为准）。知识博主的表达力是天然优势，人设稍到位，加上专业讲解，用户信任很快建立。转型要学新行业知识，这对知识博主不算难。再补一点：知识博主转电商，一定要把自己收拾得精致些，看起来像在用好东西。很多知识博主很朴素，但我们卖高客单，得让人相信你用得起。发型、妆容、衣服都要精心搭配，低调贵气越好。

### 第三件事：直播起号

选品、人设完成后，最关键的是直播。这句话价值一百万：新人起号，要做好一个月非常寂寞的准备，每天4小时直播只干一件事——打标签。

我们期待开播就百人千人在线，互动高，刷礼物抢福袋，转化顺畅。但99.99%的直播间只有10人在线，甚至没人提问。大部分电商直播间非常寂寞，要有心理准备。不要盲目追求在线人数，我们要的是能买三高产品的精准用户。

我毫无保留分享当时数据：转电商起小号，用私域宣传完成启动，第一场20万GMV，第二场只有6万，因为私域用户下单基本结束。第三场开始，每晚直播约1万GMV，整晚可能只有三四个人付款；播三小时，一小时可能连两个互动都没有，在线十几人。就这样每天播。到第二个月，单日约3~5万GMV；之后5~7万；再之后7~10万；三八节做到单场百万。现在在线也就50人。为什么能稳定增长？三高产品靠高复购滚雪球，最难是冷启动。第一个月不是拉流量，而是耐住寂寞打标签：让系统知道什么样的人喜欢你、你想吸引什么用户。年龄、性别、城市、兴趣、消费能力、关注品牌，都是标签。平台标签和匹配策略做得很好。新人开播在线少，一场推流不到500人，怎么打标签？三招：福袋、画面、短视频。

福袋成本最低。标签的关键衡量之一是直播间评论互动，看评论区是不是很多人提到关键词，这就是标签。蝉妈妈后台也有关键词数据。举例，今天卖XX小熊，福袋可以设置“XX小熊真的太神奇了”“XX小熊真的太好吃了”“XX小熊真的太好用了”，用户进来点福袋，就帮你做了一遍标签。第二，画面要突出产品。好产品自带流量，把产品放在直播画面黄金位置，对品牌感兴趣的人会从广场点进来。进入语也可加品牌关键词，比如“XX小熊到货了，拼手速”，天然筛选人群。第三，短视频。今天不展开，简单说：不要什么都拍，拍精准的、和产品及人设有关的。初期短视频很重要，内容越聚焦越好。给大家看我当时的选题。电商冷启动要有一个月耐心，只要标签打上，稳定单日变现2~3万，后面就是日常优化人货场。我们用这套框架冷启动，目前100%成功率。

### 第四件事：搭团队

我们公司从知识付费转电商，优先把优秀操盘手调到电商团队，他们也很开心。很多做知识付费久的运营，发现公司增长空间有限会迷茫；进电商是全新赛道，天花板更大。所以不用担心人员大变动。优秀人才，你告诉他前景，他能跟上；如果看不见、看不懂、不听、不信任，那也不是能并肩作战的战友。优秀知识付费操盘手进电商是降维打击，因为知识付费卖空气，对用户敏感度、销转细节体系要求更高，进短平快的电商能快速适应，甚至比一直在电商的人做得更好。

团队要多少人？转型时我们把20%的人调进电商，保留40%在原知识付费团队，精简40%。知识付费博主月销300万，后端至少10~20人，涉及课程制作、私域运营、私域销转、非标交付，前后复杂。电商博主简单得多：月销300万的三高赛道，不需要直播间人数很高，最少两个人就够。一个是中控运营，直播时配合弹产品讲解、带气氛、发福袋、看数据、做场控；核心画像细致、聪明、数据能力强。另一个是用户运营，做私域引流、公域回复、VIP一对一触达；核心画像负责、耐心、学习能力强。电商带货很扁平，老板把供应链和直播抓住，有优秀的人配合干，没有优秀的人就招基础的人把活干仔细，先有再优。

最后说个我走过的大坑。当初我在杭州，以为回老家成本会低，就带核心骨干回县城租场地、装修，最后发现人才招不到，供应链离得远、配合不默契。给想创业的人一个建议：想创业，就要背井离乡。

# 小红书单月引流1.3万、全年变现千万：实战与团队管理

大家好，我是佳能，生财潜水新人，谢无敌老师的关门弟子，目前做线上教育类目。今天主要分享我做小红书以及团队管理的一些经验，部分知识来自谢无敌老师的实战营。

先自我介绍：今年是我工作的第6年，这6年里我打过杂、带过项目、当过运营主管，也自己创过业，目前是公司合伙人。我和另一位朋友共同管理15人团队，靠0成本获客，45天做了100多个账号，引流3万多人到微信，单月变现80万+，全年变现1000万+。

我现在的岗位叫全栈运营，也叫全域运营。知乎、B站、公众号、微博、抖音都做过；活动运营、产品运营、增长运营、内容运营、社群运营也都干过。

一、先聊实战，结果倒推

先问大家3个问题：

你有没有制作流量热点地图？
你的矩阵号有没有分类？
流量爆了之后，成单率是不是也变高了？

大家可以带着这三个问题，再看我接下来的分享：单月引流1.3万，我做对了哪些事？

1.抓住热点，提前2个月布局

不管做新业务还是老业务，最好赶紧把全年的流量热点地图做出来。

比如大学四六级考试，永远是考前一个月流量最多。减肥类目，春夏需求最旺，因为冬天大家爱吃火锅，天气冷也不愿动。
