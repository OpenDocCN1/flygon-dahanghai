1. 常用运维工具入门

1. 服务器管理

先介绍宝塔面板。宝塔面板（BT 面板，全称宝塔 Linux/Windows 面板）是一个可视化的服务器运维管理工具，主要用来简化服务器上的建站、运维和管理工作。它提供图形化 Web 管理界面，即使没有太多 Linux/Windows 命令行经验，也能快速上手部署和维护网站、数据库、FTP、SSL 等服务。

[PRE52]

1. 核心功能

- 一键环境部署
  - 可一键部署常见环境，如 LNMP（Linux + Nginx + MySQL + PHP）、LAMP（Linux + Apache + MySQL + PHP）、Tomcat、Node.js、Java 等。
  - 支持一键安装、升级和切换不同版本的 Nginx、Apache、PHP、MySQL/MariaDB 等。

- 网站管理
  - 可快速创建网站、绑定域名，并配置 HTTPS（免费 Let's Encrypt 证书）。
  - 提供伪静态规则管理、301/302 重定向、反向代理、负载均衡等功能。

- 数据库管理
  - 支持 MySQL、MariaDB、PostgreSQL、MongoDB。
  - 内置 phpMyAdmin、Adminer 等可视化管理工具，也支持远程连接。

- FTP/SFTP 管理
  - 内置 FTP 服务，支持用户分级权限管理。

- 文件管理
  - 可在 Web 界面完成上传、下载、编辑、解压缩文件。
  - 支持在线编辑代码。

- 安全管理
  - 防火墙管理：端口放行、IP 黑白名单。
  - 系统安全体检，提示风险配置。

- 计划任务
  - 支持定时备份数据库和网站文件，也支持自动清理日志、定时执行脚本。

- 监控功能
  - 实时监控服务器 CPU、内存、硬盘、流量等指标。

[PRE53]

[PRE54]

1. 优势

- 上手门槛低：对新手和非专业运维人员比较友好。
- 功能覆盖全：建站、运维、管理、监控都能在一个面板里完成。
- 插件生态丰富：应用商店提供缓存、负载均衡、监控告警、云端备份等插件，部分需要付费。
- 跨平台：同时支持 Linux 和 Windows。

1. 不足

- 安全风险：宝塔默认运行在 8888 端口，如果没有做好防护，比如修改默认端口、限制 IP、设置强密码，就容易成为黑客扫描攻击的目标。
- 性能开销：与纯命令行操作相比，会多占用一部分服务器资源。
- 商业化：基础功能免费，高级插件和部分功能需要付费。

1. 适合谁用

- 个人站长和独立开发者：用来快速搭建网站，比如 WordPress、Discuz 或类似 Shopify 的系统。
- 中小企业：用于建站和内部系统部署。
- 学习和测试环境：练习 LNMP、LAMP 环境搭建。

1. 把项目部署到服务器

# 1. 部署方案对比

- 自有服务器：约 16 美元/月，时间成本低，可维护性高。
- Vercel + Supabase：20 美元 + 25 美元，配置相对复杂，可维护性中等。

自己有服务器的话，部署会简单不少，不需要太多复杂配置，想装什么工具都可以。一台服务器可以承载多个网站，通常 2 核 2G 的配置至少能部署几十个网站。

这是一套通用部署思路，并不局限于某个特定框架。

# 2. 用 AI 自动部署

用 AI 部署需要能力较强的模型，比如 Claude Code，比较适合测试环境。尽量不要让 AI 直接操作线上环境，因为存在风险；操作前请先备份数据或创建快照。

服务器可以使用前面用过的 DigitalOcean，也可以选择其他云平台。

不过 AI 的表现并不总是稳定，可能需要多尝试几次。

# 2.1 先在设置中上传公钥

这次要使用 SSH Key 登录，主要是因为 Windows 环境下 AI 无法用明文密码登录服务器。需要先上传公钥，创建服务器时选择对应公钥，它才会被加载。
