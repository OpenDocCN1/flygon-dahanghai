# 3.4.2 从搜案例到定稿的实操课

新闻稿写作别急着下笔。先把“对标”和“认知”做足，再拆任务、搭骨架、喂素材、出初稿，最后人工打磨。下面按步骤走。

# 3.4.2.1 先找对标，统一认识

写主持稿前会先查资料，新闻稿也一样。可以用秘塔、百度等搜索“新闻稿”到底指什么，先建立基本认识；随后找几篇优秀样稿，加上客户发来的模板案例，逐篇拆解，看看别人怎么组织内容、怎么落笔。

比如本案例，搜索关键词就是“新闻稿”。

第三步：定选题大方向
客户已经指定题目：《年轻人把五星级酒店当食堂引发分析》，这个不再改。写作者只要知道大致方向即可；客户要求明确时，直接照要求执行。

第四步：搭骨架
总字数约1500字。按常用骨架原则：全文3000字以内，正文一般设3个维度就够，多设两个不是不行，但没必要，能少则少。维度设计上，每个维度下可以有多段，每段还可以带子标题（二级、三级标题）；正文3个维度就是3个一级标题，一个维度表达一个大观点。字数分配上，每段控制在250—500字。由此推：正文3个维度，每维约400字，3×400=1200字；余下300字，引言约100字、结尾约200字。
客户要求“必须从三个角度分析”，那就按三个维度拟大纲。

第二步：人工干预，生成定稿
标题：年轻人把五星级酒店当食堂引发分析
一、舆情背景 300字
近年消费观念变化，一部分年轻人把五星级酒店自助餐厅当成“食堂”，花不低的价钱买自助餐年卡，一日三餐在酒店解决。短视频和社交平台上的分享很快带起模仿潮，媒体和公众也加入讨论：有人觉得这是会算账、追求品质生活的选择；也有人怀疑是否真划算，并担心长期这样吃不利健康。舆情不简单，需要多角度拆解背后的社会心理和经济因素。

二、舆情分析
维度一：消费升级与生活方式变化 400字
一是有观点认为，年轻人把高端酒店自助餐当日常就餐选择，说明消费升级下生活方式在变。腾讯网认为，这体现年轻人看重生活品质，也希望在忙碌中省事高效；他们不是单纯追求奢华，而是在实惠、便利和饮食品质之间找平衡，用精打细算换“聪明消费”。这也显示出年轻一代愿意打破常规、尝试新生活，在经济压力和生活质量之间找平衡。不过，这种消费升级是否会让一些人过度依赖外部服务、忽视自我生活技能，仍值得讨论。

维度二：社交媒体推动消费行为 400字
二是有观点认为，社交媒体在这股风潮的传播中起了关键作用。新浪新闻分析，平台上大量年轻人晒五星级酒店用餐经历，带起模仿，使这种消费迅速成为热点；短视频和图片把这种生活方式包装成高品质、高性价比的象征，吸引更多人关注跟风。知乎报道进一步指出，社交媒体上的“炫耀性消费”会放大趋势，让个人消费变得公开、可模仿，形成“社交货币”。但这也暴露问题：短期满足和表面性价比容易被放大，长期经济规划和健康考量容易被忽略；年轻人若被平台推着走，可能不顾实际需求盲目跟风，掉进不理性消费的坑。

维度三：经济压力与理性消费的矛盾 400字
三是有观点认为，年轻人买五星级酒店自助餐年卡，背后是经济压力与理性消费的拉扯。网易新闻指出，面对高房价、高物价，年轻人更在意怎样用有限预算把生活质量做大；精细核算后，把自助餐年卡当节约生活成本的办法，其实是对当前经济压力的应对。四川在线的分析则提醒，这种看似划算的选择短期内可能缓解经济压力，但长期是否真节约，还要看健康问题和其他隐性成本；盲目跟风买年卡、不考虑个人实际，也可能带来财务压力。所以，追求高品质生活的同时保持理性、别被短期利益遮住长期影响，仍是年轻人要面对的课题。

# 3.5 课程教案写作指南 @海盐芝士

通俗说，教案就是教师上课前准备的详细计划，像做事前列的清单。它能帮教师理清思路：这节课讲什么、怎么讲、怎样让学生听懂掌握。教案常用于教案比赛、教学展示、招聘面试、日常教学等场景。教师掌握这套方法，可以提高备课效率。
教案写作常见三种场景：
1.自主创作：完全原创，不依赖现有模板，围绕教学目标和内容自由构建方案。
2.模板适配：按指定格式写作，在既定结构框架内填内容，保证符合标准化要求。
3.修订完善：对现有教案润色改进，基于原稿更新内容、优化策略或调整表达。
下面依次展开。
