# 2.2 盖洛普测评到底准不准？

想判断一份优势测评靠不靠谱，不妨从三个角度来打量：结果稳不稳、测得对不对、有没有防作假的设计。

1）信度：结果稳不稳？

信度关注的是结果的一致、稳定与可靠程度：用同一套方法重复测量同一个人，前后所得是否一致。信度越高，说明结果越稳、越可信。人本身就复杂，带着社会化的自我，测试时常常不自觉戴上“面具”，把自己往好里修饰。因此，市面上暂时找不到百分百精准的优势测评。盖洛普的重测信度约73%，也就是两次作答的前后一致性能达到七成多；这已经高过大多数同类工具，结果值得参考。

2）效度：到底测没测对？

效度讲的是有效性：一项测评是否真的量到了它想考察的内容，也就是大家常说的“准不准”。效度越高，结果越贴近个人优势，准确度也越高。盖洛普测评出自美国优势心理学之父、盖洛普前董事长唐纳德·克里夫顿之手。团队前后投入至少30年，访谈了200多万名来自不同国家、不同行业的杰出人士，追问他们如何成为行业中的佼佼者。依托海量访谈数据，团队梳理出这些成功者共有的思维模式，并归纳为34项天赋才干主题，用它们为这些模式命名。官网已积累3000多万份样本数据，为其有效性提供支撑。

3）测谎机制：能不能防住“美化答案”？

人很复杂，哪怕面对自己，也未必足够坦诚。一旦开始反复权衡，或者被“政治正确”带偏，测评就很容易被做出漂亮答案。市面不少测评要求你给自己打分，或给出政治正确意味明显的选项，比如“你觉得自己责任心很强吗？”这类题很容易伪装。因此，不少专业付费测评会加入测谎设计。

盖洛普走的是另一条路：它观察你下意识的行为模式，关注不经理性推敲的反应。等你弄懂它的出题方式，上面的顾虑大概会消解不少。为了压住人为主观误差，盖洛普在题目设计上颇费心思：整套题共177道，前后会交叉印证；同一项才干被分散到不同题目中，还尽量不让你察觉它其实在重复测量同一个特质。拿“积极”来说，它可能表现为生活里有不少欢乐，也可能表现为你常夸别人、常留意事情好的一面，或者单纯很爱笑……这些描述都比较好判断像不像自己：越吻合，该特质越靠前；大致吻合，就落在中间；越不吻合，排名越靠后。

（等你对盖洛普体系足够熟悉后，就不建议反复测了。你已经知道每道题在考什么，准确率反而会下降。）
