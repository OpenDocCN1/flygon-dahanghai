# 宠物烘焙：冷门生意，利润不低

给宠物做点心，正在成为一门值得留意的小生意。所谓宠物烘焙，就是用宠物也能放心吃的原料——肉、奶制品、果蔬等——制作宠物版蛋糕、粽子、月饼和手作零食。产品之外，还可以开设课程，教大家宠物营养怎么搭配、宠物烘焙食品如何制作。

这个方向目前仍偏冷门，主要在一线、二线城市流行；不过利润率通常比普通烘焙店更可观，并且能继续延伸出多种后端宠物生意。
