# 5.8 写作复盘：三个关键提醒

把一篇文章从构思推进到发布，一般要花 1～2 小时。拖慢进度的主要原因是 GPT-4 响应偏慢，所以尽量别在晚上赶稿——夜间速度比白天慢不少，网络还经常出状况。

第一，调教好 ChatGPT 后，别急着无限写下去。按经验，连续生成约 5 篇文章，就应该重新调教一次。依据 GPT-4 API 的输入限制，可以推测它的对话能记住约 25000 个 token 的上下文。至于 token 和字数的换算，目前没有统一标准，常见说法是 1000 个 token 大约等于 750 个英文单词，或 400～500 个汉字。5 篇文章再加上前面的调教内容，通常接近 10000 字；如果继续写，ChatGPT 很可能已经忘了最初设定的要求。

第二，模型选择上，结论很明确：一定要用 GPT-4。GPT-3.5 能记住的上下文只有 4096 个 token，基本写一篇就得重新调教一次。

第三，如果只能用 GPT-3.5，就得多花时间反复调教。它不太能记住上下文，逻辑性也弱，容易出现前后不衔接的情况，有时还会一本正经地乱说。条件允许的话，GPT-4 更值得用：它能接住上下文，表达更有逻辑，也更多一点人情味，相当于帮我们多往前走了一步。
