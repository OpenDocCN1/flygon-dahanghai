# 内容自动化×垂直小号：21天实操手册

# 引言：先看清这趟航程

## 第一课：上船前的方向确认

### ⛵ 这个项目到底在做什么

「垂直小号-内容自动化」并不等于“用AI写稿”。它是一个让新手从零运营一个公众号垂直号、并用 WorkBuddy + Skill 提高产出效率的实操项目。你会在明确的细分方向上，搭建1—3个公众号小号，借助热点选题和内容 Skill，持续生成贴合账号定位的文章，再一步步完成发布、开启流量主、挂载商品等动作，最终跑通“选题 → 成文 → 发布 → 变现设置 → 数据反馈”的完整闭环。

为什么首选公众号垂直小号？短期来看，公众号依然是承接垂直内容、搜索流量和私域信任的合适选择；对第一次做内容项目的人，它比一上来做复杂矩阵或复杂产品更容易进入状态。长期来看，垂直小号不是发一两篇就结束，而是围绕固定人群持续输出，慢慢积累账号资产，之后再向流量主收益、商品挂载、带货等方向延伸。

这21天的核心打法很清晰：先确定赛道，把账号准备和定位做好；然后利用热点库、WorkBuddy 和内容 Skill，快速生成并发布文章，建立稳定更新节奏；接下来根据数据反馈，继续学习拆解爆款、调整运营、扩展变现方式。整个航程中，每位船员以1个公众号小号为基础，按每天2篇的节奏推进，预计累计发布约40篇内容，同时完成流量主/橱窗带货等基础变现设置，最终拿到一份可复盘的发布记录和数据反馈。

### 学习方式：边做边学，分段推进

这次航行采用“边做边学、分段推进”的模式，不需要先把所有课程和工具都学完再运营账号。整条路径围绕3份阶段作业展开：每完成一个关键结果，就进入下一个阶段。

21天要跑通的路径是：
账号定位与配置 → 首篇文章发布 → 连续更新 → 数据复盘与下一轮计划

建议每天投入1—2小时：一部分时间学当天的方法，一部分时间操作自己的账号，最后留几分钟记录结果和问题。学习的最终检验标准，不是“看完了课程”，而是账号真的往前迈了一步，手里多了一份可以复用的记录。

#### 3.1 完成账号启动

这一关的重点是：明确方向、搭好基础、会用工具。刚开始不要急着写文章，先回答三个问题：这个账号准备服务谁？持续写什么？读者为什么愿意关注？在此基础上完成公众号主页配置，让头像、昵称、简介等信息都能体现内容方向。

接下来，安装或登录 WorkBuddy，导入同赛道 Skill，做一次简单的写作测试。这个测试不追求产出正式文章，而是要确认工具能理解你的账号定位，Skill 输出内容也符合赛道和用户需求。

本阶段的学习顺序：

1. 了解垂直小号的基本玩法，选定一个愿意长期投入的细分方向；
2. 观察同赛道账号，初步理解目标用户和常见内容类型；
3. 完成账号名称、头像、简介等基础设置；
4. 用一句话写出账号定位；
5. 导入同赛道 Skill，发起一次写作测试；
6. 按提交模板整理截图和文字，完成作业。

完成这一关，说明你已经从“想做一个公众号”进入“知道这个号写给谁、准备写什么，并且可以开始生产内容”的状态。

#### 3.2 跑通首篇发布

账号准备完成后，马上进入真实内容生产。此时不要同时测试太多赛道和工具，先围绕一个与账号定位相关的热点，把文章生产流程完整走一遍。

你需要逐步掌握：如何判断一个热点适不适合自己的账号；如何把选题交给 Skill 生成初稿；如何对初稿进行人工修改；如何完成公众号发布前的关键设置。

本阶段的学习顺序：

1. 从热点库、对标账号或用户问题中选一个合适的选题；
2. 使用 WorkBuddy + Skill 生成文章初稿；
3. 重点修改标题、开头、人设表达、观点补充或同质化表达中的1—2处；
4. 完成配图、排版、原创、广告、封面图、赞赏或带货商品等适用设置；
5. 发布文章，检查文章页面和设置是否正常；
6. 记录这次人工修改的原因，提交作业。

这一关的关键不是证明 Skill 能代替你写文章，而是学会把 Skill 变成自己的生产工具：机器负责提效，你负责选题判断、内容取舍和最终审核。完成这一关，说明你已经跑通了一次“选题—成文—修改—发布”的完整流程。

#### 3.3 从单篇发布进入连续更新

首篇文章发布后，学习重点就从“能不能发出来”转向“能不能持续发、哪些内容值得继续做”。这一阶段按每天2篇的节奏推进，边发布边积累自己的选题库、文章记录和数据样本。

你需要逐步掌握：如何记录每篇文章的发布时间、标题、内容方向和链接；如何查看后台可见数据；如何通过不同文章之间的表现差异，判断下一轮内容应该怎么调整。

本阶段的学习顺序：

1. 持续从热点、对标账号和用户需求中寻找选题；
2. 按照每天2篇的节奏生产和发布内容；
3. 用一张表记录已发布文章，逐步形成连续发布记录；
4. 定期查看阅读、推荐、关注、互动、流量主收入或商品订单等数据；
5. 对表现较好的文章，拆解其选题、标题、开头和内容结构；
6. 对表现较弱的文章，判断问题出在选题、标题、内容匹配还是发布设置；
7. 写出下一轮要保留、调整和暂停的内容方向，完成作业。

完成这一关，说明你已经不再只依赖感觉写文章，而是开始用真实发布和数据反馈决定下一步怎么做。

#### 3.4 把方法继续用下去

完成作业不是航海的终点，而是从“跟着任务做”进入“自己运营账号”的起点。后续继续保持发布节奏，同时把前面形成的记录和复盘结论用于下一轮选题。

建议重点做好三件事：

• 保留表现较好的选题类型，继续做相近主题和系列内容；
• 根据数据调整标题、开头、文章结构和发布节奏；
• 检查流量主、橱窗和商品挂载等基础变现设置是否适合账号当前阶段。

21天结束时，你应该拿到的不是一篇孤立的文章，而是一个已经完成基础定位、跑通过内容生产流程、留下连续发布记录，并且知道下一步如何调整的公众号垂直小号。

#### 3.5 每个阶段都按这个方式学习

每一阶段都按照“先学方法、再做操作、最后交作业”的顺序推进：

1. 先学方法：只学习当前阶段需要的内容；
2. 马上做操作：把方法用到自己的账号上；
3. 留下结果：保存截图、文章链接、数据或文字记录；
4. 完成提交：按作业模板提交，不遗漏必填项；
5. 带着反馈前进：把这一阶段遇到的问题，带到下一阶段解决。

如果某天时间不足，优先完成当前阶段对应的核心结果。先让账号向前推进，再利用后续时间优化文章、补充记录和完善工具流程。

#### 2. 公众号注册与账号检查

一个实名主体只能注册一个实名公众号，建议从三个账号起步。

##### 2.1 方式一：在微信平台注册公众号（最推荐）

注册路径：微信 → 公众号盒子[PRE27] → 右上角人像[PRE28] → 点“发贴图”[PRE29] → 填写信息并创建公众号，注册即成功。
