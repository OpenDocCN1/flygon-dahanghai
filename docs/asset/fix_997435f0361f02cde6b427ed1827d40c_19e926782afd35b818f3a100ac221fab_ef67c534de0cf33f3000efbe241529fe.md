7.6.3.1.2 提示词怎么组织

提示词就是给 AI 的“需求说明”。正向部分写你想要的，负向部分写你不想要的。举个例子，一条提示词可以同时打包画质词、角色、服装、场景、姿势和细节：画质方面有 masterpiece、best quality 这类；角色方面可以写 1girl、cute、chibi；发型是白色波波头，眼睛是红色，戴耳环，穿白衬衫、黑短裙和蕾丝腿袜；动作是坐在红色沙发上，神情妩媚；沙发前的黑色茶几上放几件小装饰；脸部与眼部再强调高精细度。负向提示词则把不想出现的元素明确写进去。想进一步了解提示词，可跳到五、【项目实操 4/4】提升 AI 绘图能力——提示词。新手用提示词，关键是先想清楚“要什么”和“不要什么”，再逐步叠加细节。

7.6.3.2 第一次出图

启动成功后就进入出图界面了，这也是你接下来的主要操作区。要放图的话，点左下角的文件夹图标，或者用界面顶部的入口：[PRE0]。出图本身不复杂；想调整效果，一种常用做法是换模型：[PRE1]。【生成】按钮下方还有 5 个辅助功能键：[PRE2]。① 从提示词中读取参数；提示词为空时，读取上一轮的生成参数。② 删除当前提示词框里的内容。③ 打开模型选择位置，效果见 [PRE3]。④ 把下方 Style 里的提示词粘贴进来。⑤ 将当前提示词存档，下次在 Style 里单击即可调用。

7.6.3.3 参数面板详解

先认一下页面上的各个控件：[PRE4]。采样器新手可以尝试 DPM++ 2M、Karras 和 Euler a。DPM++ 2M 算法更稳，Karras 在它之上做了进一步改进，Euler a 则容易蹦出小惊喜。[PRE5][PRE6]

① 迭代步数 Step：相当于画师下笔的次数。20~36 步效果通常不错，别开太大。它对应去噪次数：去噪次数增加后，画面往往会更清晰、细节更丰富，但耗时也会变长，过多反而不理想。② 面部修复：真人、3D 建议开启，二次元和风景慎勾。右侧两种算法分别是 GFPGAN、CodeFormer，效果对比如 [PRE7][PRE8][PRE9]。③ 高分辨率修复：画面太糊时勾选，生成大图；显存不足就免了，容易出不了图。[PRE10] ④ 宽高设置。⑤ 提示词相关性 CFG：值小，AI 更自由；值大，约束更强，可能出现锐化和线条不自然。⑥ 种子 Seed：类似画纸编号，-1 表示随机。若想基于某张图继续微调，点骰子右侧绿色箭头组成的圆圈就能固定种子。[PRE11] 理论上，同一台电脑上，prompts、Seed、CFG、Step 这些参数完全一致时，复现出来的图也应该一样。⑦ 批次和单批数量：批次决定一次跑几组图，组与组之间变化更明显；数量决定一次输出几张，同批图彼此差别较小。显存有限就每次只出 1 张。

7.6.6 模型：认识、使用与自炼 @大刘 @吴东子

7.6.6.1 模型基础

把 Stable Diffusion 想成一摞空白速写本，模型就是风格各异的插画师。每个插画师擅长的领域不同，同一摞纸交到不同人手里，呈现出的画面也截然不同。这些“插画师”在 SD 里叫模型。模型大体分两类：一类是控制整体风格的底模，另一类是用于定向微调的附属模型。下载资源主要在社区模型站（如 Civitai）上。

7.6.6.1.1 后缀名怎么看

很多新手会被文件后缀搞晕。常见的后缀包括 .safetensors、.ckpt、.pt、.pth 等，但只看后缀并不能确定是哪一种模型。实际用起来的差异不大，主要区别在于安全性。

7.6.6.1.2 底模

底模是画面整体风格的基础，体积也大，通常按 GB 计算，常见 2G、4G、7G。文件后缀多为 .safetensors 或 .ckpt。放置路径：你的 SD 项目目录\models\Stable-diffusion。[PRE32] 使用时要打开生图界面，点一下刷新键，在下拉列表中选择目标底模即可。[PRE33]

7.6.6.1.3 VAE

VAE 的说明及对比图看这里：[PRE34][PRE35][PRE36]。

7.6.6.1.4 嵌入式 Embedding（Textual inversion）

Embedding 是一种轻量级参数注入方式，也常被称为 Textual inversion，相关介绍见 [PRE37][PRE38]。

7.6.6.1.5 超网络 Hypernetwork

Hypernetwork 的可调参数极多，一些夸张版本甚至能做到 GB 级别。[PRE39]

7.6.6.1.6 LoRA 模型

LoRA 可以理解为底模之下的附属模型，专门针对某种画风、某个人物、物品或风景做定向训练。通常从社区模型站下载，也可以自己训练。新手先用现成的就好。[PRE40] 插件版 LoRA 的存放位置：[PRE41]；WebUI 自带 LoRA 的位置：[PRE42]；插件版的使用方法：[PRE43]；WebUI 自带版操作也差不多。

7.6.6.2 LoRA 与底模搭配技巧

这节的核心就是“复刻他人成果”。在社区模型站看到感兴趣的样图，想把参数搬过来试试，就按作者原图上的参数（包括种子）放到自己面板里，底模和 LoRA 都保持一致，还原度通常很高。细节有出入很正常，毕竟机器不同。社区模型站就是上面提到的 Civitai，[PRE44][PRE45][PRE46][PRE47][PRE48]。一句话：参数照抄，模型选对，就能得到接近的效果。[PRE49][PRE50]
