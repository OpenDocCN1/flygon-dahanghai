# 6.5 分销引流变现 @谢无敌

只做内容的博主，同样能主动挑品，再联系靠谱商家谈合作。

打个比方，母婴博主发现某款奶瓶不错，就去找卖这款奶瓶的商家聊分销。

合作敲定后，博主用高质量的种草内容吸引人；笔记一旦爆了，评论区很可能不少人追问购买方式。

这时就可以把意向用户引到自己或商家的私域池，再完成成交。

# 6.6 靠直播创收 @谢无敌

董洁、章小蕙、伊能静这些明星陆续开播后，小红书直播又火了一轮，涌进来的主播越来越多。那普通人既非明星也非达人，能不能靠直播赚钱？

答案很明确：能。

这说明，直播并非明星和大 V 的专利；普通创作者只要肯投入、内容过关，同样能在小红书靠直播获得收入。
