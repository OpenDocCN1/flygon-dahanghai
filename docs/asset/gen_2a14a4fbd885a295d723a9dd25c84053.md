# 2.1.8.1 观赏素材从哪来？

观赏价值的素材，大体可以分成两个来源。

**一是自己拍、自己修。**
我很少发这类内容，原因很实在：拍照和修图都不是我的强项，审美也一般，所以发得不多。我的优势更偏观点表达，因此平时写价值观类内容更多。可如果你很会拍图、修图，审美也在线，那就别浪费这份天赋，多分享自己拍摄和修整的图片。自修类图片确实很好用，观赏价值很容易做出来。

**二是从网络上收集。**
我常逛的渠道有三个：

- 公众号“舞蹈网”和“骑驴旅行”：图量非常大，前者偏舞蹈，后者偏风景；
- 微博[喵呜不停](https://weibo.com/ixuebai)：作者主要拍猫狗。

这三个是我最常用的，因为它们的美图一直在更新。

当然，这些渠道未必适合每个人。你完全可以按自己的喜好找图源，比如[堆糖](https://m.duitang.com/)、[花瓣网](https://huaban.com/)、[Unsplash](https://unsplash.com/)、[Pexels](https://www.pexels.com/zh-cn/)等，各大社交媒体也能成为素材库（部分网站要留意版权）。
