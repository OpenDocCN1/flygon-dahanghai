# 案例十二：Scrubber：把社交黑历史扫出来

Scrubber 是一款帮人翻查并清理社交账号旧账的工具，专门定位那些可能惹麻烦的内容——爆粗、涉毒、酒精、性、政治等。范围不只自己发过的帖子，还包括自己给别人的留言、别人给自己的评论，以及别人提到自己的内容。它还允许自定义关键词，把特定姓名、职位或机构相关的内容标出来。这门生意每月能带来 3,800 美元收入。

这个话题天生容易传播：用户愿意讲，媒体也爱写。Cosmopolitan、华尔街日报和 Good Morning America 都报道过它，对早期冷启动帮助很大。

## 1、怎么赚钱

注册免费。扫描出问题内容后，用户可以自己回社交平台翻找删除；嫌麻烦或量太大，可以付费让 Scrubber 给出链接，直接跳到目标位置。若希望每次技术升级后重新扫一遍，则按月付费。不过多数人付一次扫描费后就离开了。

这里有个细节：Scrubber 真正做的是“帮忙找到不当信息”，删除仍要用户亲手完成。原因大概是 Facebook 等平台没有开放第三方删除接口。这样做也是做 MVP 的简化办法，甚至完善产品时也适用：要解决的问题，不一定等于你提供的解决方案。

## 2、灵感、MVP 与起步

作者 2017 年才正式推进 Scrubber，但这个念头已经在他脑中放了三年。灵感来自 4SquareAnd7YearsAgo（现 Timehop），他由此对“Digital History”产生兴趣，并想到几十年后，个人数字历史会变得多么庞杂、多么难打理。

他把想法告诉当时读法律的女友，她很看好。她说有位同学特别担心自己在 Twitter 或 Facebook 上的不当发言会影响未来的法律职业。作者马上在笔记本电脑上做了个原型，拿给几位朋友看，反馈不错；然而他又拖了一年才发布。

一年后网站上线。Cosmopolitan 的一位作家不知怎么发现了它并写了篇文章，一天内带来 10,000 名用户，Scrubber 就这样跑起来了。之后靠口碑传播，华尔街日报和 Good Morning America 也相继报道。
