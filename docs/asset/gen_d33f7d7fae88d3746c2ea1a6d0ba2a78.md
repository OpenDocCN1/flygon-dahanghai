# 1.1 项目背景 @胖大魔 @相柳

AI可视化，是指借助AI技术把复杂数据自动转成直观图形图表，让用户更快理解数据。不过本手册讨论的范围更聚焦：用AI大模型把简单或复杂的图文数据做成美观的HTML卡片或图片。

# 1.1.1 为什么要学习 AI 可视化？

过去，AI可视化技术门槛不低，要同时接触AI、数据处理、图表生成等知识。想做出好看的数据展示，常要依赖复杂工具、插件或投入大量人力开发。现在，借助Claude 4、DeepSeek V3等大模型，再加上简单提示词，就能较轻松地把图文内容转成精美HTML卡片。这不仅降低了门槛，也明显提升了信息理解与传播效率。

学习AI可视化的意义，在于掌握一种快速提炼重点并高效进行视觉传播的能力。过去这种能力稀缺，如今人人都有机会获得。提前熟悉相关工具，也能更从容地面对AI时代持续迭代的新变化。

# 1.1.2 AI 可视化的商业机会

不少人关心AI可视化有没有商业机会。商业价值主要看两点：

1. 卡片本身是否足够惊艳，能不能吸引用户购买？
2. 卡片是否具备收藏与传播价值，能否让购买者获得实际收益？

目前，市场对知识卡片的认知还多停留在“好看”“有趣”，尚未形成大规模、稳定的商业模式。未来，机会可能更多出现在差异化的下沉市场，例如K12课外辅导、小班教学或专项培训。要抓住机会，先要准确理解用户需求，找到有实际价值的应用场景，并提供差异化服务。这种路径适合小而精的市场，大资本不容易进入，普通人反而能凭专业能力抢占先机。

# 1.2 手册结构与学习方法

# 1.2.1 本手册的目标

通过分层设计，帮助不同基础的人学到合适程度。

# 1.2.1.1 必修目标：通过手册提供的提示词实现卡片制作

考虑到不少圈友是第一次接触，手册附录会提供可直接复制的提示词。这些提示词经过打磨，发到对应模型后通常能正常输出卡片，按普通对话方式使用即可。需要提醒：

- 在AI输出满意卡片的过程中，几乎一定会出现“废卡”，也就是存在各种瑕疵的卡片。
- 遇到“废卡”不必灰心，重新发给AI再问一次，或者直接指出卡片问题，让AI自行修正。
- 条件允许时，优先推荐Claude官网的4模型，或Cursor中Agent模式下的4模型。
- 考虑到部分圈友的网络情况，工具和示例中也会提供DeepSeek-V3模型演示。

卡片微调通常有两种情况：

1. 手动修改HTML代码，需要一定代码基础；
2. 把问题与希望达到的效果告诉AI，让AI自行修改迭代。

# 1.2.1.2 选修目标：自己写提示词来进行卡片的制作

希望航海结束时，人人都能走到这一步。想做到用自己的提示词抽卡，通常要经历这些阶段：

基础阶段：了解与AI对话的基本操作，知道提示词的基本组成。

应用阶段：根据模型类型选择沟通方式。

- 推理模型：可直接表达，或使用“要求-对象-目标-约束”框架；
- 问答模型：适用RTGO（角色-任务-目标-要求）框架。

进阶阶段：

- 能借AI辅助编写提示词；
- 能识别并改进提示词短板；
- 通过测试迭代获得稳定效果；
- 实现提示词跨模型应用（进阶目标）。

不同学习者有两条路径：

- 追求精进者：可在框架基础上替换内容，在实战中迭代优化；
- 实用导向者：可让AI先完成初稿，再通过多轮修改迭代到合适版本。

实践是学习的起点，学习是使用的开端；技巧来自反复使用，熟练来自持续练习。商业化是一种可能性，不是最直接目标，但可以成为长期追求的方向。

# 1.2.2 如何高效使用本手册

手册结构不复杂，不要求从头到尾按顺序读：既可以系统顺序了解，也可以按需取用。

- 体验型选手：可直接跳章，或先走必修目标；
- 学习型选手：按章节推进，也可以先用现成提示词跑实战，再回来补内容；
- 应用型或商业型选手：建议从头到尾阅读。

不清楚的地方，可以问AI（优先推荐Claude，其次DeepSeek），也可以问作者。

# 3.1 什么是个人介绍卡片

顾名思义，个人介绍卡片就是一张用来介绍自己的卡片，以图文图片形式呈现。它会在相同或不同模板下承载不同内容信息，再由AI排列并渲染效果，形成丰富的视觉呈现，让别人一眼记住你的闪光点。

文字版自我介绍在篇幅冗长或过于简短时，容易分别出现信息密度低（废话多）或信息不足（没重点）的问题。视频版、PPT、PDF介绍有时也有不小阻力。多数情况下，面对陌生人或刚认识的人，大家更习惯先接收一目了然的信息，这就给个人介绍卡片带来了需求与机会。

# 3.2 实操案例一：个人介绍

现在把自我介绍部分展开。AI主要做的是提取、排列和丰富视觉，因此需要我们先提供一些基本信息。信息太少时，AI虽然会补充，但效果未必好，所以自我介绍部分要有一定的基础信息密度。

# 3.2.1 步骤一：写个自我介绍

这里不必特别讲究，可参考下面的案例。

个人介绍示例：

【昵称】相柳

【区域】深圳

【自我介绍】大家好，我是相柳，深耕互联网十年，腾讯云TDP常务理事。

腾讯云架构师、百度知道行家、人工智能应用工程师、头部科技社群“龙哥盟”特邀AI教练、10+期资深航海领队/志愿者、👸号聆因主理人、国学爱好者，对大国学儒释道以及山医命相卜各有涉猎，欢迎交流。

【我能提供】

项目预判（创业前期）、商业模式梳理（单元模型跑通）、企业管理交流（年千万级以下）。

天赋优势挖掘（因材施教）。

企业上云咨询（协助企业降本增效）。
