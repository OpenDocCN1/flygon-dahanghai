# 3.2.3 快速出单的编辑小窍门

一句话说透：把闲鱼上卖得好的商品找出来，价格压到有竞争力的位置，再简单改一改上传到自己店铺。

具体怎么做：

找到市场里动销不错的商品链接；

去拼多多找到对应商家，算清成本；

在还有利润的空间内，把最低规格价格调低；

标题前后稍微改一改，主标题保持不动；

主图做简单裁剪，改变 md5 值（图片识别专属数值）；

产品介绍和其他照片可以沿用，也可以稍作修改；

最后编辑发布就行。

这套做法门槛低、上手快，出单效率也更高。

# 3.2.4 上架编辑避坑点

1. 标题里别带品牌词，图片也尽量避开品牌标识。

2. 标题和正文别写“无添加”“联系”“🛰️”等把用户引到站外的词。

3. 发布地可以挑人口密集的一线或新一线城市。

4. 上传时间优先早上8点前后，其次晚上8点前后，最差也选中午11点半左右。

5. 一天发5条左右链接就够，别贪多，以免被平台当成营销号。

# 4.1 客服回复话术

在闲鱼卖高客单商品，话术直接影响咨询转化。下面整理常见问题和参考回复，重点是学思路，不必照搬。

# 4.1.1 高客单通用售前话术

买家问“在吗？”

可以回：在呢在呢，刚看到消息，让您久等啦。您想看哪一款？

买家问“可以自提吗？”

回法一：老板，我们是厂家直营，不是门市，没法接待散客哦，实力厂家的售后更有保障。产品给您包邮到家，一般三天左右到，您拍下我就安排发货。

回法二：老板，您这边急用吗？目前这边没货，您下单后我马上找离您最近的仓库发，三天左右能到；需要的话直接拍，我这边安排。

买家问“全新未拆封吗？”

回：是的，产品都是全新的。厂家直发，所以价格会低一些，质量和售后都有保障。喜欢的话拍下，我早点给您安排发货。

买家问“你电话多少？打电话说。”

回：老板，您把您的号码发给我就好。

注意：在闲鱼发布电话或🛰️有违规封号风险，这里别给顾客电话或🛰️，建议让顾客把他的电话发给你。

买家问“你不是发布在郑州吗？怎么是江苏发货？”

回法一：老板，我们是厂家直销，郑州那边很多老顾客反馈都很好，所以发布地写了郑州。产品您放心用，咱们顺丰（或某某快递）包邮到家，基本三天到。

回法二：老板，我们全国多仓发货，郑州这边目前没现货，需要从江苏调，您需要可以直接拍下，我给您安排加急。

回法三：老板，发布地是系统随机显示的，我们的仓库在江苏这边。

买家问“某某产品多少钱？”

回：老板，咱们这款产品（这里用简洁语言补上卖点+售后），报价是……

买家问“某某产品最低多少钱？”

回：老板，您要多大的、什么配置、要几个？收货地址是哪里？先问清需求再报价，在保证利润的基础上可以稍微低一点，哪怕客户只买一台也有利润。

买家问“有淘宝店铺吗？有其他店铺吗？”

回：老板，工厂现在不搞淘宝了，淘宝经营成本太高，羊毛出在羊身上，成本高了卖到客户手里价格也高。我们厂主要以批发为主，为了走量，质量保证的同时价格有优势；在闲鱼上架是因为开店不花钱，能降低成本，您到手价也更低。期待您收到货用得好，帮我推荐顾客呀。

买家问“哪一款好用？”（纠结款式）

回：先讲清楚顾客纠结的A款和B款各自优缺点，再帮顾客做选择。A款也有人选，价格相对B款低一些；如果您更追求体验，可以选B款，顾客反馈都很好。您看喜欢哪款？拍下我改价，咱们早排单早发货。

（款式特点可以去拼多多详情页找，套进话术里就行）

买家说“你家的比其他家卖得贵。”

回法一：老板，卖啥产品都有高价和低价。我们是工厂直发，做的是实体店品质，用料实在，质量有保障，不是网红款，您放心拍。

回法二：老板，有的同行确实卷，很多拿瑕疵品当正品卖，售后没保障，时间久了出问题您找谁？我们是实体店直发厂家，用料和售后您放心。

买家说“我再考虑一下哈。”

回：老板，我理解您的顾虑，选一件满意的产品确实要慎重。我相信咱家产品您也是比较喜欢的，不然也不会聊这么久。您方便说说目前主要考虑哪方面吗？是产品本身，还是价格？

买家问“怎么拍？价钱不对啊？”

回：

① 右上角点一下“立即购买”；

② 确认购买；

③ 会提示输入支付密码，先不要输入，直接返回；

④ 稍等一会儿，我改好价格，最后付款就行。

催单话术：

回法一：老板，产品喜欢的话直接拍下付款就好，这款卖得挺火，您早拍下我这边尽早安排发货。

回法二：老板，您眼光真好，选的这款是厂里卖得最好的，很多顾客买，经常断货，目前只剩两三台了，担心等会儿又没了，您拍下我给您安排发货。

客户拍下未付款怎么办？

可以在下午发货前一两个小时发消息问：老板，这个产品您还需要吗？今天拍下的话，我好给您安排打包发货。

遇到客户砍价怎么办？（案例思路）

1. 先认同对方挑的款式，夸对方眼光好；

2. 先问要几个、发到哪里；

3. 回：因为咱家是大件产品，物流运费比较贵（或者说以批发为主，单件利润很低）。您这边购买是包邮送过去的，我们薄利多销，价格已经给您到最低了；

4. 安排好评返现＋复购优惠券，优惠金额看产品利润来定。

[PRE10]

遇到客户犹豫不决怎么促成交？（案例思路）

1. 先问客户要哪个款式，再赞美对方眼光好；

2. 问需求，给出适当建议，这时候别急着逼他决定买不买；

3. 需求解决后，判断客户有购买意向，最后价格环节别让顾客一直纠结，可以开始逼单，比如赠小礼品，或者说今天下单是福利价。

# 4.1.2 二手机售前话术

本期航海提供的二手手机货源是自建库存，都是现货，并且提供售后，支持三天无理由，主板问题一年内保修。

二手产品能提供完善售后，大胆的买家想要实拍图或视频，都可以直接找团队客服提供。机况真实，会如实描述手机瑕疵和问题，客户问什么就按实际情况回复。

话术决定转化率。

可以用小号多和同行聊，把买家问你的问题拿去问同行，慢慢形成自己的一套话术。

话术框架可以参考：

买家：在吗

回：在的，要多大内存的？（先确认内存，直接报价，节省时间）

买家：128G

回：XXX元。

买家接受就继续聊，接受不了就不回复，换下一个。

买家：256G多少钱

回：要一般的还是好一点的？成色不同价格不同。

买家：好点的

回：XXX元，成色不错等等。

买家问手机情况，就把产品相册里对应机况告诉他，委婉但如实描述。

例如：

相册描述：内屏老化发黄

我们回复：屏有一些发黄，但触屏都正常，正常使用没问题。（把“内”字去掉）

话术不固定，多和同行聊。

注意：聊天中不能出现违禁词，会扣分限流，严重会封号。违禁词包括🛰️、WX等任何淘宝系之外平台，谐音字也不行；不能主动发手机号；分身、多开、位置穿越等也不能发。

# 4.1.3 售后应答话术

售后话术比售前简单，核心就是做“传话筒”：把客户发你的话复制粘贴发给拼多多客服即可。

下面列几个常用话术供参考：

显示派送：

回：老板您好呀，我刚帮您查了物流，您在小店买的宝贝已经到您所在地了，快递小哥近期会安排配送，请注意信息哈。有问题可以联系我，也可以直接联系快递小哥，电话XXXX。

显示签收：

回：老板您好呀，您的宝贝显示已经签收了，您对这个宝贝还满意吗？满意的话希望给我一个好评哈，非常感谢。

客户验货再签收：

回：亲，我们赠送了设备运损险。大件商品运输不便，可能出现小磕碰，请您谅解。如果出现大的破损问题不要签收，任何凭据及时反馈给我；签收即视为产品完好，再出现破损快递/物流公司不再赔付。

改价（案例展示）：

如果实际商品价格和你标的一口价不一样，需要改价，可以这样引导客户：

① 右上角点一下“立即购买”；

② 确认购买；

③ 会提示输入支付密码，不要输入，直接返回；

④ 稍等一会儿，我修改价格。

更多具体售后问题处理，见【4.3 售后处理流程】。

以上就是闲鱼上最常见的问题和回答。

如果还有不知道如何回复的问题，可以用两种方式：

1. 去淘宝或其他闲鱼店铺找同款商品咨询，拿到信息——同行就是你最好的客服和老师；

2. 在航海群里一起交流。

# 4.2 出单后的发货操作

# 4.2.1 出单后先重新上架

宝贝卖出去后第一件事就是重新上架：闲鱼“我的”—“我发布的”—右上角“已下架宝贝”里点重新发布，立马上架流量会很大。

这个动作适合还没开通鱼小铺的新手卖家；如果已经开通鱼小铺，就不需要手动重新上架。

鱼小铺是什么？

鱼小铺是卖家运营工具，为有需要的用户提供更丰富的工具和服务，目前是系统定向邀请，基本上出几单就会收到邀请。

开通鱼小铺后，你会从个人出闲置的身份进入专业卖家身份，也会进入鱼小铺商家的池子，流量竞争会有变化。因此不少卖家反馈刚开通时店铺流量下滑，核心原因还是链接质量打磨不够。

不过开通后功能更多，操作也更方便：

1. 可以增加单个产品的上架库存数量，避免订单被拍下后还要重新上架；

2. 可以直接上架多规格产品，成交环节不用再手动改价，避免客户流失；

3. 有数据分析等功能；

4. 可以上架500个品。

大家可以根据自身情况选择什么时候开通鱼小铺。

# 4.2.2 出单后的发货步骤

1. 拼多多选品发货流程

我们说过，闲鱼带货做的是一件代发赚差价的生意，所以在闲鱼出单后，要尽快去货源处下单，可以直接去拼多多下单，相对其他平台更方便、更好把控。

具体流程：

1. 客户在闲鱼下单后，你去对应电商平台下单（以拼多多为例），收货地址填顾客的，收货电话写自己的。

2. 拼多多商家发货后，把发货单号填到闲鱼上即可。

路径：闲鱼“我的”—“我卖出的”—找到相应订单—点“去发货”—“我已寄出”—填写单号后提交。

[PRE11]

注意：这里会涉及拼多多给顾客发短信的问题，解决办法如下：

下单时先填自己的电话付款；下单成功后联系拼多多客服，改成客户电话，就不会发短信了。

最安全的还是直接写自己的手机号，跟客户可以这样解释：亲，为保护您的隐私，商品包裹通过隐私号码发货，目前查件尾号是XXXX；快递到了可以把取件码主动发过去：您的快件已经送达，取件码是XX。

[PRE12]

1. 二手机发货流程

如果你用的是本期航海提供的二手机货源，可以直接找你的志愿者申请进【二手机发货群】，对接负责货源的老师。

具体流程：

1、首次出单后，私聊志愿者申请进入【二手机发货群】；

2、在群内@售后老师，提供相册里的产品编号，确保货源正常；

3、确认货源正常后，扫描群公告里的货款支付二维码完成支付；

4、把支付成功的订单截图和客户收件信息发到群里并@售后老师；

5、售后老师安排发货后，会把单号发在群里（18:00之前的订单当天发，18:00之后的第二天发）；

6、在闲鱼回填运单后完成发货；

7、客户确认收货后钱款到账。

注意：如出现售后问题，及时向发货群里的老师提问并解决。

# 5.1 优化获取更高曝光

做好下面几点，可以帮助产品获得更高曝光：

1. 每天至少发布3个品，新手至少发满50个品。

2. 图片要高清，比例尽量1:1或3:4。

3. 写好产品标题。

4. 开启闲鱼币抵扣，即支持买家使用闲鱼币抵扣商品价格的5%或10%，可获得额外曝光。

5. 急速卖：使用闲鱼币推广你的宝贝，提高成交几率；一般用于卖爆的产品，效果相对好一些。

6. 更多优化动作，可结合自己的数据情况继续补充。
