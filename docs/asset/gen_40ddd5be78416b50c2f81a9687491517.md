# 3.1.1 四大优势维度，怎么用才更容易出结果？

优势放对了地方，结果往往更容易出现，这一点从报告里就能看出来。不过，四个维度在发挥时也各有容易踩的坑：

执行力：能做事是长处，但如果只闷头干、不让别人看见你的价值，就可能被忽略，不容易被重用。

影响力：能推动别人是本事，但如果不能让人信服，别人容易觉得你强势、难相处、只会动嘴，是个空架子。

关系建立：会换位思考很珍贵，但如果丢了自己的立场和感受、一味迁就，别人可能觉得你好欺负、玻璃心。

战略思维：会做决策是优势，但如果讲不清决策逻辑，或者觉得别人笨、懒得沟通，别人就会觉得你高冷高傲，也不明白为什么要听你的。

所以，了解并运用自己的优势维度时，要多看自己在什么领域更能把优势发挥出来；对盲点也要有意识地觉察和调整。

比如，一个人执行力+战略思维很靠前，关系建立+影响力靠后，找工作时若做销售，去研究营销工具、提升转化率，会比直接和人面对面打交道更符合他的天性。

# 3.1.1.1 人际关系里，四大维度各是什么画风

执行力：执行力强的人未必嘴甜，但你需要的时候，他常能搭把手，甚至平时已经默默付出了不少，是让人安心的存在。

影响力：影响力强的人像聚光灯，自带一种“力量感”，在关系里爱掌握主动权，也更敢表达自己，常常让人不自觉地跟随。

关系建立：关系建立强的人像一米阳光，温润如水地走进人心里，让人觉得温暖、可依赖、可信赖，更乐于换位思考，也容易建立长期深厚的关系。

战略思维：战略思维强的人偏爱能进行精神交流的关系，常常不自觉成为关系里的“智囊”。比起大量社交，他们可能更喜欢独处。

# 3.1.1.2 带团队时，四大维度各自看重什么

执行力：执行力突出的管理者更关注和做事有关的部分，比如结果、流程是否合理、制度是否好用、事情能不能平稳落地。有时他们以身作则，干起来比员工还起劲。对他们来说，没有结果万万不行，最反感“说到做不到”和复杂的人事关系。

影响力：影响力突出的管理者更看重能否掌控局势，比如怎样快速打开市场、怎样统领团队、怎样拿到行业领先位置。他们总想做更容易获得鲜花和掌声的事。默默无闻不行，被边缘化也不行；最讨厌“小富即安”和事情脱离掌控。

关系建立：关系建立突出的管理者更看重团队氛围，在意成员有没有成长、团队有没有达成共识、每个人是否在最擅长的位置上。他们愿意在员工身上投入资源，相信人对了，事就对了。团队四分五裂不行，最讨厌冲突频发和只考虑自己的同事。

战略思维：战略思维突出的管理者更看重决策是否正确，在意行业趋势、愿景、决策逻辑是否合理。他们喜欢研究信息和工具、搭建系统，想清楚之后再推动员工执行。不动脑就干活不行，最讨厌重复工作和拍脑袋做事。

# 3.1.1.3 挑工作/项目时，四大维度会怎么选

执行力：务实实战派，更喜欢目标或流程明确的工作与项目，整体偏务实。方向不明确时，他们不一定会想很多，相信未来是干出来的，不是空想出来的；手上有活，生活反而更舒服。

影响力：渴望做能不断展示自己、表达自己的工作或项目，分享欲很强。最好有很多人一起干，而不是什么事都自己扛；能持续得到更多人的正反馈，他们就越干越起劲。

关系建立：渴望加入轻松、舒适的团队。如果团队关系糟心、冲突不断，会直接影响工作动力；在天然需要深度关系的领域，他们往往得心应手。

战略思维：意义探索家，比较看重一件事的意义，想法很多，讨厌重复的工作内容。选项目或工作之前，会花时间收集信息来辅助决策；如果一份工作有大量脑力劳动，他们会做得更开心。

以上是我随机列的三个场景，不同维度的人会怎么做事。实际解读中，有人四个维度比较平均，都有涉猎；有人一两个维度更突出，领域特质也更明显。大家可以查看自己21页的维度，在不同场景里做解析，大概就能看出自己的总体偏好和优势。

# 3.2 第二步：看清你的才干排序

了解自身优势维度之后，你对自己的优势已经有了大致认知。接下来要看自己的才干排序，这一步非常关键。

盖洛普把人的行为、思维、情绪模式分成34种才干。这些才干是我们与生俱来的天赋能力，在一定的知识、技能训练下，就会发展成我们的优势。

接下来，请翻到盖洛普报告第1页，查看你的才干排序。

报告第2—11页是你的前10才干具体分析，其中前5才干有个性化分析解读，需要重点查看。

每个人的才干排序不同，形成的价值观、性格和优势也不同。一般来说，我们更需要关注排名靠前的才干，那里可能是我们发挥优势的天赋区；越靠后的才干，越代表我们不常使用的天赋，也可以理解为不那么擅长。

以醒醒为例，我经常用的Top 3才干是“体谅”“个别”“理念”，不怎么用的倒数3个是“公平”“分析”“纪律”。（关于才干的具体解读，我们会在「3.4 了解34项基础才干」中详细说明。）

我总能敏锐感受到他人的情感需求（体谅），发现每个人的独特之处（个别），也有很多新奇点子（理念）；但对规则（公平）、数据与逻辑（分析）、计划（纪律）这类事，我并不擅长，也不太关注。

所以我可能存在的优势是“共情力”“组优势团队+人才发展”“创新力”；不擅长制定规则、推理和做计划。

在盖洛普报告里，每种才干都有对应的价值。越靠前的才干，越是我们无意识中不费力就会使用的，这很可能就是天赋所在。举个例子：

有人从小语文很好，物理数学却很差，对文字的理解天然强于对数字和逻辑，他可能有文字方面的天赋；有人从小喜欢和朋友一起玩，不爱待在家里，他可能在社交上有天赋；有人从小喜欢观察人、研究人，他可能有识人辨人的天赋。这些从小就有的特质，在盖洛普里大概率会被测出来排得很靠前。

通常来说：

Top1—10的才干：突出才干。越靠前，越可能是你最擅长的天赋才干，天然就能在某些方面做得不错。

Top11—20的才干：辅助才干。偶尔也会用上，能辅助你把事情做好，但使用频率不一定比前10才干高。

Top21—34的才干：底部才干。越往后越可能不常用，甚至不怎么出现。

初学盖洛普，更需要关注排名靠前的才干是怎样一种天赋，在什么情况下用得好、什么情况下用得不好，并找到能把它用好的环境。这样，生活和事业都会更有价值感和意义感。靠后的才干虽然不擅长，也可能影响我们，但不一定是我们的弱点。

# 3.2.1 读 Top 5 才干，圈出让你有共鸣的地方

想了解自己有什么天赋、这个天赋是什么，最好从自己最擅长的Top 5才干入手。盖洛普报告第2页给出了“了解自己的天赋的方法”。

以醒醒排在第一的体谅才干为例，要重点看以下几点：

才干的特质描述：了解才干特质，才能充分看到自己可能有的天赋。

才干是如何使用的：查看具体描述，找出有共鸣的部分，不断回想自己曾经做到的事中，是如何使用这个才干的，带来了什么效果。

提醒：重点看前5才干的阴影部分。这是个性化报告，也是含金量很高的部分。不同的人体谅排第一，报告内容也不尽相同，因为其他才干不一样。

行动建议：如何持续用好天赋才干的建议。日常生活中可以对照行动建议来练习，加深理解和使用。

[PRE3]

才干盲点：才干就像硬币，有正反两面，有时用得好，有时用得不好。看到盲点、更好地管理盲点，能帮我们更好地发挥优势。

拓展：靠前的才干发挥出盲点、带来负面反馈怎么办？可以尝试：找到天赋才干适合发挥的场景；不断练习使用你的天赋才干，尽量发挥优势，避免盲点出现。

举个例子：一个人行动才干突出，想到什么总能立刻开始做，行动力强是他的优势。同时，他也可能是个急性子，没想清楚就行动，要花不少时间试错。如果把他放在需要持续开拓新项目、敢于尝试的环境里，他有干劲，能开疆拓土，可能经常收到“敢于进取”的评价；但如果放在需要谋划很久再行动、一旦做错要付出巨大代价的环境里，他可能经常收到“莽撞”的评价。

通过这个案例能看出，任何才干都是中性的，没有绝对好坏。当我们在无意识状态下使用才干，不管擅不擅长，都可能因为使用不当而暴露弱点。目标合理时，当我们能根据目标有意识地使用擅长的才干，弱点出现的概率就会大大减少。

这里解释一下，什么是“有意识管理”和“无意识发挥”：

无意识发挥：你的才干就像汽车的自动驾驶系统，只要上了跑道，自己就跑起来了，也不管会跑去哪。例如竞争才干突出、胜负欲强、想拿第一，无意识状态下总和别人比较，想赢过别人一头，容易出现“到处是假想敌”的情况，把人放在对立面，弄得关系不好、得罪人。

有意识管理：你知道自己会这样做，也知道是哪个才干在影响，了解并接受每个才干都有优势和盲点。使用时尽量根据目标来使用才干，尽可能发挥优势那一面，避开盲点那一面。例如，如果和别人争对自己更有利、值得一争，那就争；如果大事小事都要争，因此到处树敌，就没必要了。

总之，圈出有共鸣的地方后，在不断回想高光时刻的过程中，你自然而然能看见擅长才干应用的影子。对靠前的才干有了感知后，在生活中不断观察自己和他人的区别，关注自己的感受和下意识反应，就能更有意识地使用它，看见它的优势。

# 3.2.2 看懂 Top21-34 靠后才干，别把弱点当死穴

所谓靠后才干，就是报告中排在第21—34位的才干。

当我们经常使用靠后才干，很可能因为不擅长、做不好而出现负面反馈，成为我们的“弱点”。在盖洛普里，“弱点”指的是在发挥优势的过程中，由于才干管理不当，或者技巧、知识不足和使用不当，给自己和他人带来了困扰。

当我们使用靠后的才干、带来了负面反馈，该怎么办？

例如，你很想扩大社交圈、认识更多新朋友，但取悦才干靠后，目前圈子狭小，怎么办？未必非要直接参加各种活动去认识新人，关键是找到自己擅长的切入口：

取悦才干天然能做到和陌生人交朋友，但你不擅长使用取悦才干，怎么办？

「学习才干突出」→如果你特别喜欢学习，可以多参加感兴趣的线上课程，通过和同学交流来认识新朋友；

「交往才干突出」→如果你有特别要好的朋友，平时经常参加活动，可以让她陪你去，慢慢融入环境，或者让她帮你推荐新朋友；

「排难才干突出」→如果你特别善于解决问题，就多帮别人解决问题。一段时间后，自然会有更多朋友认识你。

……这里不一一列举。面对弱点，我们可以做的事有：

1）梳理自己想要达成的目标并进行目标拆分，根据目标盘点擅长的才干能否达成目标。

具体拆解方式可以参考：澄清目标—理出优势—制定策略—跑通路径—重复成功。

例如：

我的目标：完成生财拉新500人。

我的优势：我的战略思维+关系建立维度有7个才干突出，擅长定策略、把合适的人放在合适的位置、将策略落地。我影响力靠后，不擅长招募新人、快速成交。

我的策略：

战略12+体谅1+个别2：盘点生财、拉新团队、用户、核心团队的需求，找到四方利益的平衡点，根据内容制定销售漏斗策略，写SOP，带领大家执行SOP。这些都是我擅长的。

取悦26+统率25+专注16：不擅长快速引流、快速成交，也不擅长处理掌控主动权。

我的路径：我选择用内容来找同频客户，自动化成交。利用关系建立的优势，找有影响力的朋友一起合作，我来写策略+内容。

我的成果：通过为期30天的运营，今年最终拉新了847人。

2）找优势互补的人来合作。

还是以拉新为例。我的好朋友梁靠谱是“影响力+执行力”特别靠前的人，对应的才干是“统率+专注+取悦+积极”。所以她成交欲望高（统率+专注），擅长和陌生人打交道，能吸引大家加她微信，引流效果很好（取悦）。

我俩一起拉新特别愉快。提前半年就商量好，她负责招募和直播，我负责策略+调动人+后端的精细化运营。最终成效不错，拉新847人。

总之，要找到合适、让自己舒服的方式来弥补“我认为的劣势”。最好的补短板方式，是了解自己擅长的才干，用最擅长的那一部分去打通不擅长的部分。

补充：靠后的才干如果也能稍微学习一下使用方法，很多时候能帮我们提升整体竞争力。举个例子，醒醒分析才干靠后，会刻意找一些擅长的朋友多交流，学习他们思考的方式，现在有明显提升。

无论你信不信天赋存在的意义，但你有意无意中都在用这种方式保护和捍卫自己。如果没有出现好的结果，也许只是你正处于一个无法发挥天赋的环境。

最后提醒大家：天赋用对，势如破竹；总在弱项里硬扛，只会处处难受。即便是补短板，也不要硬补。

# 3.3 第三步：理解才干组合怎么用

前面，我们了解了排名靠前和靠后的单个才干。才干是组合发挥作用的，接下来就来了解组合才干的应用。

盖洛普测评的颗粒度很细。大多数测评工具像一面模糊的大镜子，只能照出人大概的类型；而盖洛普像8K超高清相机，通过才干组合，能照出一个人的高矮胖瘦和五官，帮你更清晰地看到自己的“天赋才干”。

以人际关系为例，表现形式可以有N种。举个例子：

[PRE5]

假如A、B两人的前五才干中都有取悦，意味着他们都喜欢社交、认识新朋友，不断与新人朋友建立联系并获得青睐，这会让他们感到满足。其中A排第一的才干是沟通，B排第一的才干是成就。

A：沟通+取悦：喜欢通过交流和表达，不断和别人交换信息、建立关系。

B：成就+取悦：喜欢做能不断认识新朋友的工作，一边做事一边交朋友。

如果在“两两组合”之上再加一个才干进行组合，例如：

沟通+取悦+交往：八面玲珑，全世界都是朋友。总能找到话题，不断和新朋友、老朋友交流，维护好关系。

成就+取悦+完美：在工作中本能想结交特别优秀的新朋友，本能地向上社交，在做事的过程中结交朋友。

每增加一个才干，才干组合的复杂度和难度都会更高，但也会变得更精准。也就是说，才干的N种表现形式，体现在测评报告中34个才干的排列组合数量、排序不同，这意味着：

第一，测试结果就像基因一样，几乎具有唯一性，展现的是测试者本人与生俱来的独特性。

第二，34种才干有无穷的排列组合。尽管人和人之间有相似的优势，但才干组合不一样，反映的是差异化优势。

对于初学者来说，不需要一上来就死磕组合才干，很容易绕晕。如果想更精确地了解自己的天赋才干组合，依然要从单个才干入手，了解清楚后再进行两两才干组合的练习，慢慢就会更熟练。

以下一些才干组合，可能比较容易同时出现在前五，作为了解即可（常见组合数据来自盖洛普官方）。

成就+学习：完成某个任务时，渴望顺利收尾；如果接触的是新事物，会忍不住想弄明白，自动开启学习模式。

专注+成就：以目标为导向，按重要性给任务排序，不达目标不罢休。

统筹+责任：配合别人工作时，只要和自己有关，无论是过程还是结果，都希望能负责到底。

信仰+责任：坚守自己认为重要的原则和目标，对需要自己帮忙的人，做出承诺就尽心尽力。

审慎+责任：尽责且谨言慎行，恪守自己许下的承诺。
