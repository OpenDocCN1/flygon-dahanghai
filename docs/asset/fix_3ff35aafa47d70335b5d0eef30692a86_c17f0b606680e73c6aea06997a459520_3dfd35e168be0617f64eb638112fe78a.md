## 2. 各字段创作指令：

### **"Title" (String):**

任务：拿原文当底稿，起一个让人想点开的爆款标题。可用手法包括数字、问句、反差、悬念、利益承诺等。底线：别写成流水账，也别让标题寡淡无味。

### **"Summary" (String):**

硬杠杠：整段摘要压到 60 个汉字以内，标点也计入字数，这条优先级最高。目标：用有画面感的表达重写，让读者三秒内抓住价值点并愿意点开。技巧：用“你”来对话，先戳一个痛点，再暗示解决路径，收尾留一个问题或一句值得琢磨的话。雷区：原句照搬绝对不行。

[PRE9]

下面这段脚本负责从模型输出里抠出 Title 和 Summary：逐条执行时读取当前项的输出，截取花括号内容，解析后只把两个字段交给下游。

```javascript
// 逐条执行模式下，当前数据项取自 $input.item
const rawText = $input.item.json["output"];

// 从文本中截出最外层花括号包住的部分
const braceMatch = rawText.match(/\{[\s\S]*\}/);

// 没有匹配到就中断，避免脏数据流入下游
if (!braceMatch) {
  throw new Error("未找到可解析的对象内容。");
}

// 取第一段匹配文本并转为对象
const parsedResult = JSON.parse(braceMatch[0]);

// 解构出标题与摘要
const { Title: outTitle, Summary: outSummary } = parsedResult;

// 返回给后续环节
return {
  json: {
    title: outTitle,
    summary: outSummary
  }
};
```
