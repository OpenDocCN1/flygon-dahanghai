# 3.2 视频号选品：查重、筛货、挑号 @黄老师

做视频号带货，选品之前先查重。很多号主会把内容同步到多个平台，所以看中一个商品或一条视频后，先去视频号确认有没有被人搬过：先搜名称，再从视频文案里挑几个有辨识度的字去搜。要确认没被搬运，或者二次剪辑不算多；如果切到实时页发现同行扎堆，这个品就放弃。

**选商品：按条件一层层筛**
从抖音、快手等平台看商品，按下面的条件逐项过，不合适的直接淘汰：
- 价格带是否合适；
- 销量够不够，要结合利润空间自己判断；
- 买家画像是否匹配，视频号用户以40岁以上为主；
- 用搜图找源头供货价，倒推利润是否成立；
- 看推这条商品视频的博主是谁；
- 带货方最好只有一个；如果有多个号，要能看出是同一家在操作；
- 看博主的视频和直播：各条带货视频的销量要比较均匀，若主要靠单条视频爆量，我一般会放弃，这种运气很难复制。直播要看是否多场都有成交，而不是某一场突然冲出大量订单。逛数据平台多了会发现假数据不少，很多商品销量是刷出来的；按这套筛法能避开不少坑。

**选账号：借抖音、快手做对标**
在蝉妈妈、考古加这类平台，按涨粉表现挨个翻账号，花时间也值得，因为能直接看到带货型账号。视频号目前没有第三方工具可用，只能看抖音、快手的号来对标：用蝉妈妈、考古加看抖音账号的内容、数据和选品，先作参考，再放到视频号测试。
- 账号挂的商品越少越好，这类号通常内容更垂直；
- 看涨粉：优先近三个月起的新号。比如总粉30万、近三个月也涨30万，涨势稳定，不是靠一两条视频突然拉起来；
- 看更新频率：90天内发布的视频，点赞和商品转化是否比较均衡，更新越多越好。别嫌别人视频粗糙，我们面向的是40+人群，审美不同；它能卖动，就说明粉丝有需求，搬运也是这个道理；
- 看内容：越垂直越好，主页大多是带货视频；
- 有直播能力的话，再细看对方直播。这类号直播间通常不复杂，等后期视频有流量，买回样品就能开播。
