# 别只顾低头写，文字生财先要被人看见

[PRE0]

有天夜里，主编忽然发来一个关于毛晓彤的选题。次日清晨六点，我便坐到桌前动笔。当时心里的弦绷得很紧——百万级流量号我固然写过，可这回要面对的是坐拥三百万粉丝的心理类大号，门槛摆在那儿；何况我入行投稿满打满算才两个月，赶急稿手速慢，又要搭观点又要翻资料，前后折腾了一天多，中途还忍不住干掉一份KFC。

[PRE1]

这篇热点稿的处境有点特别，编辑会帮着润色，上线时间也往后拖了拖。结果首发一小时就跑出三万阅读，紧接着破了十万，稿酬八百。对刚起步的人来说，若一味往小号投，即便中了，声量也有限（当然，少数中小号走精品路线、文章被大号转了能做背书，那是另说），变现和名气爬坡都慢，兴许熬半年才挪一小步。所以说，新人得主动替自己制造被看见、被传播的窗口。

[PRE2]

头一篇十万加问世后，凡是能贴链接的群我全发了一遍，还拉着朋友帮忙扩散。这里提个醒：手头变现成绩还薄的时候，最好别让家里人晓得你在靠写字挣钱，容易挨一盆冷水。链接同样丢进朋友圈，好让编辑刷手机时撞见。没过多久，先前加过微信却一直没合作的编辑便来约稿了。打那以后，我不再满世界找新号，而是挑几个号深耕（顺带掂量性价比），一边攒过稿履历，一边稳稳当当进账。阅读表现亮眼的文章，我把链接归拢成一份文档，拿去跟优质号的编辑要选题；后来陆续进了摆渡人作者群、百万粉inslady作者群等等，写的稿子多了，报酬也跟着往上走。拿十万加和优质稿当跳板，去够更大的平台，文字变现的路子和荣誉感才会越来越多。人嘛，往往是先瞧见成果得了甜头，才肯再多使一把劲。其实按年算总账，那些变现总额高的人，并非只产高质量文，而是质量稿与流量稿两头都吃得下。靠文字传递正向力量、输出有深度的思考，或者写点供人饭后嗑瓜子的热搜流量文，二者本身没有高下之分。保持稳定的写作节奏、持续产出有见地的质量稿，同时顺手接些流量稿换钱；经验尚浅者写流量文月入两千到三千，一年攒下来也是笔不小的数目。

-03- 先用流量涨粉，再拿内容破圈，圈子选对了才有人看见你

前文聊的是怎样迅速投稿换钱、攒代表作、跟编辑处关系，以及新人如何初步搭建自己的写作人脉。接下来我想问：你打算每月靠码字挣多少？人的气力终究有限，哪怕不眠不休，一个月能写出的字数也是定数。同样是写字换钱，为何有人只落点零头，有人能进账几万？光靠文字、背后没有圈子资源托着，收入天花板很低。一个入行半年的人，若只给几个号供稿、不从人脉里裂变出赚钱的门路，月入大概一千到六千。不少人只顾埋头写稿，或自己单干做平台，压根没有跟编辑、平台运营打交道的念头，也没想过把文字生意做大（兴许月入五千就知足了），更没把写作当成一项长期手艺来看待。跟编辑、平台运营往来，既是摸清市场的一条路，也是撬开他们身后资源的入口。有流量思维的人与闭门造车的人，日子一长，走向、成长节奏和收入都会分出高下：闭门造车者不做推广，或者沿用老办法砸钱买流量，慢慢磨；有流量思维者则借平台或大V的势，拿资源给自己加码，以价值换价值。想长久靠文字吃饭，打一开始就得有意识地把作品攒成背书、经营自己的私域流量，再挤进合适的圈子，让写作技能跟你的专业领域嫁接，赚更多的钱。下面讲讲新人如何借内容放大影响力，一边写字挣钱，一边结合自身长处和所处阶段，找到对路的圈子。这些法子，学流量增长、品牌营销、视频营销的人同样用得上。

[PRE3]

一、把内容铺向多个平台
知乎、抖音、视频号、小红书等等都算。不管稿子过没过，日常写的东西都要坚持分发；投中的稿子在对方账号发出后，记得找编辑申请转载授权，也就是行内说的“开白”。

二、过稿后进了作者群，别让机会溜走
部分账号设有作者群，你过稿后编辑会拉你进去，群里时不时会放内部选题（也有些号压根没有）。入群的好处有二：其一，多一条变现的路；其二，跟群友搭上线，处成熟人后互相引荐，说不定能踏进新圈子，或被推荐去对接新的账号平台（资源好坏，看你处在哪个写作阶段、人脉成色如何），投稿渠道自然越铺越宽，变现也快起来。

[PRE4][PRE5]
配图说的是这么回事：我进了某号作者群后主动跟群友往来，从认识到交心，最终拿到了心仪收稿平台编辑的微信。你得主动些，用“结交新朋友”的法子做裂变，把新资源揽过来。

三、跟编辑、平台运营处出深交情
一来，约稿量涨了，进账自然多；二来，表现拔尖的人可能被引荐给别的号写，这也是一种资源裂变；三来，编辑或许会牵线让你做文字类兼职，比如兼职责任编辑之类。

四、借分享会把自己推到人前
写作分享也好，专业领域的经验分享也罢，可以自己搭台，也能蹭别人的平台造势。
1. 主动办一场：挑一个切口细、主题明的题目（题目清不清楚，直接决定能来多少人），请朋友帮忙转发直播消息，现场设个抽奖之类的钩子。
2. 自荐或受邀去行业里、圈子里各种大小的分享会露脸（不限于写作社群），把自己推销出去。

[PRE6]
五、扎进社群：让人记住你、信得过你
靠内容留下记忆点，赢得信任，把影响力铺开。
1. 写作爱好者群（大多免费）：写作打卡群也算这一类，资源近乎为零，本质是向下兼容新手小白，不建议往里砸太多精力。刚学新媒体写作那阵，我加过一堆小白交流群，那段时间看着挺“忙”，回头一看多半白费功夫。本事不够的时候，把主要精力搁在提升能力和做出成绩上。这类群资源稀薄，想借它摸到写作变现行业群，概率是零（二三十块的低价稿费群不算）。
2. 学习群（付费写作班也归此列）：以学习、打磨笔力为主，质量尚可，优质资源不算多，可以适当勾连。在里面找水平跟你差不多、或成绩比你亮眼的人，彼此打气、互评、改稿。替别人改稿本身也是一种练笔；挑出对方的毛病，也是在帮人家长进。想借此进行业资源群，希望不大。跟爱好者群一样，这是拿时间换价值，向下或平级兼容，把自己混成学霸来攒影响力。
3. 关于写作班：学写作绕不过这个话题，我简要说几句。
[PRE7][PRE8]
市面上的写作班五花八门，好老师不少，你能学到些写作窍门和一部分实战心得。前期可以靠写作班多写多练，多中几篇稿攒背书。可若想长期靠文字变现、在写作这行扎下根，就得往更高处看。报班这件事，出不出成绩八分靠你自己，两分看你挑的老师和其背后的资源成色；报班不过是学写作的众多动作之一。我在写作班待过一阵，后来自己写投稿、接稿、写文案，七月开了付费咨询，一边写稿一边自己接活，再往后才做写作班。报班的正确打开方式：一开始挑两个学员在心里当假想敌（别让对方知道），再结交三到五个能高频交流的伙伴（从学员自我介绍里挑你感兴趣的、或者有成绩的），人脉贵精不贵多；这几个人得是能一路陪你成长的，最好都奔着变现去，日后好一块做事。
4. 行业群：
1）以自媒体号主为主体的群：用来摸行业风向、互推、换广告位等，链接力看具体群而定，有机会踏进更高的圈层，适合新人开眼界。
2）写作圈变现资源群（供成熟作者对接写稿）：里头通常有职业资源人（中介）、图书出版编辑、各类图文文案的甲方（公众号、抖音、小红书等）。资源厚，链接力中上，适合有写作底子、手头攒了些过稿记录的人。想在文字变现这行扎根，这个群非进不可。
[PRE9][PRE10]
我在写作行业资源群里接过不少稿子变现，也借这类群迅速搭上一些大的优质收稿平台并成功过稿，比如S叔Spenser、李月亮等。
[PRE11]
经人牵线进了圈子，靠资源接活挣钱（S叔号、暴走漫画号）。每回中稿，我都会在社群和圈子里吆喝一声，总有人会留意到你，乐意帮你一把。
[PRE12][PRE13]
我进的第一个写作圈资源群，是某位编辑把我介绍给一位老编辑，再由她拉我入伙的。她那个圈子只跟成熟作者、编辑、自媒体大V打交道，因为信息不对等，普通菜鸟既不知道，也够不着她。进圈才一周，我便主动搭上了知名作家李月亮。这家情感号名气大，过稿门槛也高。我投了两篇：头一篇因热点走向不明、发布时机不对，折了；第二篇写古天乐，顺利过稿，稿费一千多。这篇爆文首发李月亮，被十点读书转了（百万阅读、点赞破万），又被多家百万级账号跟进，全网累计阅读近千万，成了我一块响亮的招牌。搭上李月亮老师后，经她不时点拨交流，我的笔力也在长进。靠文字挣钱，多摸清圈子，插进这类写作圈变现资源群能让你迈大步：对接平台高层，拿到更好的变现扶持；跟平台上的能人贴身学，把写作磨得更精。
3）其他行业的群：资源不少，链接力中上。多进几个高质量社群，把自己亮出来、跟人搭上话，一边给社群出力，一边攒影响力，把自己当一个品牌来经营；既添变现机会，也链上不同圈层的资源，觅到合拍的伙伴一起赢。怎么做？看群的性质和需求，定不同的分享题目。比如在生财商业社群聊“怎样用写作放大圈子影响力”，在写作圈就聊“十万加是怎么写出来的、变现经历几何”，用信任和价值立住个人IP。举个例子：
[PRE14]
生财圈友孙六六给我介绍过活儿：改人物故事名片。还有些别圈的人跑来问我写作和文案约稿的事。进优质社群、搭上大佬，能推着你行动和成长。生财社群里高人扎堆，无私分享各行业干货和项目玩法，涛哥和明白是我学习的标杆。在生财，我还隔着屏幕结识了各行各业的精英圈友；也是通过生财，我加了多位大佬的星球社群。我接触写作满一年，翻过生财有术好些篇讲知识付费的精华帖，可等自己有了些写作经验和变现能力、想开班时，却犯了拖延症，直到十一月底被涛哥一篇问答文点醒，立马动手开班。
[PRE15][PRE16]
于是十一月二十三号我开始写干货，二十六号在某个社群做分享，周末赶招生广告，三十号夜里在个人号挂出广告，脚不沾地；从一号到四号，二十多人掏钱报名，前后只用了十一天。首期班开成，我在群里谢了涛哥。随后我请杨涛来当我的付费星球嘉宾，涛哥一口答应，我心里美滋滋的。
[PRE17]
在优质社群里露脸、参与活动，能把你和大佬的线上距离拉近。持续跟他们过招，让对方看到你的进步和更多可能，慢慢发展成他的客户或朋友，拿时间换价值，或者以价值换价值。去年到今年，我砸了几万块在知识付费、进高质量社群上，不光拓宽了写作变现的渠道，还让不同圈子的人认识了我，这是我对外很重要的一个窗口。

六、先利他，影响力自会回流
1. 给同行点评、改稿，让对方在朋友圈或个人号上道声谢，借他的流量给自己攒影响力。
[PRE18]
我帮微博千万级爆文作者陈艺华改过稿，她在朋友圈谢了我。多干这种事，就是在给自己添曝光。
2. 把好作者引荐给账号编辑。
[PRE19]
经我牵线，那位作者在账号上接连过了几篇。说说我和写手王渤的小插曲：1）我在行业圈子里认识了她，又通过她搭上了鸡汤号洞见（单篇两千）的编辑。2）我评了她的稿子，还把那篇推荐给樊登读书；她在那边过了两篇后，其中一篇被洞见公众号转载，她在写作圈的分量也跟着涨了。
[PRE20][PRE21]
小结一下：人和人之间的帮衬是相互的。我伸手帮人、真心利他的时候，其实也在给自己的影响力添砖；靠着转介绍，我拿到了一些能迅速入圈的关键人脉。多干利他的事，帮别人成事，就是帮自己。

七、学会合作，玩转资源置换
跟别的行当一样，可以互推、置换、买广告位等等。这段小结：写作不能一个人闷头干，挑些人跟你并肩走。老话说“三人行，必有我师”。好的写作伙伴该是什么样？又怎么筛出适合同行的人？我拟了份简单的自测题给你（别的行业也管用）：
- 交换信息：频率高，且信息有含金量（我不排斥八卦），能让你变得更好。
- 把自己的朋友互相介绍认识：圈里人、行里人。
- 你/TA把资源或兼职机会递到对方/你手上。
- 分享自己的学习心得、改稿过程。
- 情感支撑（鼓励/热情/鞭策/安慰这类正向情绪）。
- 认知水平在线，三观正（交友翻车，多半是栽在这一条）。
- 愿意掏钱买你/TA的付费产品或内容。
照这份清单把朋友圈过一遍，有几个人能占到三条以上？想跑得快些，多琢磨“朋友”能帮你多少、能帮到什么份上。当然，你自己也得使劲，毕竟没人待见一条躺平的咸鱼。要是上面两条都不沾，要么是彼此领域八竿子打不着，要么是对方压根没想跟你深交。

-04- 写作赚钱，这几个坑绕开走

一、投稿变现：让编辑心里舒坦，你才能舒坦
头一条，稿子被拒了，别一怒之下把编辑微信拉黑删掉。写作圈就这么大，这回不合适，下回还有机会，新人要爱惜自己的羽毛。你产出的东西够好，编辑自然乐意给你派选题；有了选题，等于上稿有了一半把握，只消记得按时交稿，别放编辑鸽子。要是编辑三言两语点出你文章的毛病，这是长本事的机会，该道谢，别不服气。编辑让你改稿，说明过稿有戏，改动是为了更贴账号的调性。至于最后改了几轮不打紧，你的目标是上稿和影响力。改完若还是没达到账号要求，编辑不收，那就果断转投别家。
二、别接低价稿，坑的是自己
稿费一百块以内的活，我不建议接，新人顶多试一个月。一篇文章从找选题、列大纲、写初稿到修改定稿，工序一道不少。写十篇低价稿耗掉的精力，不见得比打磨一篇高价稿少。稿费压得低的平台，对质量往往也没什么要求。你有那写稿的功夫，干点啥挣不回这累计的几百块？大平台稿酬高，对质量有门槛。我建议奔着高稿费去，多投几家优质大平台练手，同时拿过稿成绩给自己的影响力加码。谁都有过一段暗无天日的时光，得靠自己一步步蹚出那条窄路。要是你的笔力暂时够不着两三百的稿费，就潜心磨功底，直到中稿，让写作能力一次次得到行业认可，进而踏进新媒体圈子，捞到更多机会。

-05- 给写作新人的几句实在话

1. 从起步就做好写作成长规划
新媒体这行是块淘金地，每个进来的人都想挖出属于自己的那桶金。什么样的人能干出成绩？1）能持续输出内容：对自己钻研的行业有深认知，能连写至少三年。2）懂引流，知道怎么把读者招来。3）爱琢磨，会分析并匹配用户需求，擅长“试错”。写作跟干别的行当一样，不管月入三千还是三万，都得有发展路线。我们学写作、码文章，是为了让自己变好，靠文字挣钱，顺带让家人的日子也宽裕些；有规划和放任自流，结果差得远。用写作塑个人品牌，抬收入，多链资源和机会；用写作给本职工作做纵深，对接客户资源；用写作搞好引流，提升销售转化。进阶路径：兼职写手，看稿件难度每周过一到两篇新媒体长图文，不含商稿软文；独立讲师、咨询型付费IP；写作班训练营主理人/授课老师；全职方向如出版编辑、文案策划、新媒体编辑等；内容平台网赚高手；资源对接：资源/圈子/人脉；个人视频剪辑IP；抖音/视频号视频文案写手/视频剪辑讲师；剧本杀、网文小说向。其中2和3我分开看，这俩还是有区别，几个类型都能跟类型6叠着做。每个人写文都有拿手的领域，建议挑离钱近、离资源近、自己又感兴趣的方向。比如历史文在头条吃香，能一边带货卖书，可在公众号变现就一般；故事文、情感文在头条和公众号都是大类，变现都不赖。前期写这类稿、投平台赚稿费和流量费，一边攒粉丝。等你在写作和专业领域的成绩越攒越多、混的交流社群也多了，后期就能卖同类型的网课，把写作技能和专业知识点系统化，做海报卖课（卖写作课、卖专业课），课程逐步迭代，还能开付费专栏做连载（头条万粉可开）。跟编辑圈子处好关系，随着过稿成绩变多、文章质量过硬，可能有引荐递来兼职机会，比如兼职责编、兼职编辑。还有一条路是做写作学霸IP：你七十分时，能教五六十分的人。等你在写稿上攒下些成绩和影响力，就可以出网课了。第一批学员打哪儿来？从跟你一块学写作、看着你成长的人，以及各条圈子路径吸引来的粉丝里来。这时候可以多进些副业变现、教人做知识付费IP的社群取经，借势，找合作者，推你的课。互联网这行节奏飞快，做新媒体也一样。要是抱着守着一亩三分地的心态、按部就班，不出三年，别说新媒体小编，程序员也得面临“下岗”的尴尬。踏实干事，在吃透行业知识的同时，钻研迭代新媒体引流手法、写作技巧，沉淀出自己的方法论，并勤于实践验收、积累经验。总之，新人得有自己的写作路线和方向，想清楚再动。
2. 行动就在当下
先动笔写，再谈变现。古人讲，欲先取之，必先予之。在我看来，学写作，先交出你的注意力和耐性。人做任何事都有成本，干了就想立马见回报，这是天性。就写作变现来说，成果因人而异，不是谁都能速成。但只要下了决心、迈开步子，有恒心的人结果差不到哪儿去。我身边有些新手朋友，写了三到六个月后，进步肉眼可见（公众号长图文方向）。古罗马的塞内加说：“正是因为我们不敢做，事情才变得困难。”你做事时的每一次迟疑、犹豫，都是对自己的精神内耗；次数一多，还没上阵就先乏了。体育项目里的射箭，开局柔缓地把弓拉满，随即全力以赴射出去。你要做的，就是成为自己的弓和箭，全力飞驰。学写作，别内耗自己，持续行动就对了。
