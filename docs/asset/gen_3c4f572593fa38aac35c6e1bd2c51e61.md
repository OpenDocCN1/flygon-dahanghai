# 1. 新手直接把 JSON 文件拖到工作流中运行

# 1.1 工作流拆解

这个工作流一共分三层：

第一层是生图层，节点包括读取行信息的 Google Sheet 节点（用来更新想跳水的动物）、提示词生成节点，以及生图节点。

第二层是生视频层，节点包括建立生图任务的 HTTP 请求、延迟、视频下载节点、延迟节点。因为生成视频的时间比较长，fal API 这里采用异步生成。可以这样理解：去餐厅吃饭，服务员先帮你点单（建立生图任务的 HTTP 请求），然后等上菜（延迟），服务员端菜（延迟），菜还没好，服务员还要不停跑厨房去看菜（延迟）。

第三层是配音层，给生成好的视频配上声音，让完成度再提升一个档次。主要节点有：从视频下载节点里取链接的 Extract from File 节点、建立配音任务的 HTTP 请求、延迟，以及音频下载节点。

最后还有一个视频更新节点，把生成好的视频链接写回 Google Sheet 表格里。

# 2.2.2 节点二：延迟

视频生成速度肯定比生图慢很多，而且官方用的是异步生成，所以这里要加一个延迟，用来等结果生成完。找到 Wait 节点添加并串好就行。这个节点设置比较简单，按图配好即可。我在这里选择延迟五分钟，比较稳，你也可以适当调快一点。
