# 五、日常运营SOP

💡 章节概要

当陪伴群招募到50人以上，运营就进入日常阶段。这一章解决的是：怎样做日常交付与运营，让群保持活跃、让成员愿意留下来。你可以沿着航线图，从“群内日常交付和运营”开始学，然后动手筹备。

# 5.1 最小功能

假设你的社群只能保留一个功能、一个意义，那会是什么？它值多少钱？想清楚这个，其他都是额外送的。小满即圆满，人也会更坦然、更笃定。

# 5.2 按时出摊

你看梁靠谱，再看641、润宇、李一舟；往上看薇雅、李佳琦、海参；再往上看罗永浩、罗振宇——他们身上有个共同点，四个字：按时出摊。

明白老师为什么火？能写、是全栈、会演说，这些都厉害，但最深入人心的标签是“9点半睡觉、早起日更、日更2000天”。以至于我一看到有人昵称后面括号写几点睡觉，就怀疑是跟明白老师学的。人天生会服从那些做到了自己做不到之事的人。注意，是服从，不是单纯的钦佩或敬仰。这种潜意识里，付费的可能性就长出来了。

所以，收钱、建立双向羁绊、按时出摊、共同进步，这条路径最稳。前提是群要合规：开车、政治话题、🪜、数字货币等容易违法违规的高压线坚决不碰，发现就及时移除。

「让人有事可做」

这一点极重要。群友来这里干什么？你得引导他们动起来：打卡、提问、讨论、互动都算，买东西算，适度展示自己也算。

「发什么」

“发什么”不是社群的全部，占比甚至不大。干货和信息早就过剩，很多人恰恰因为被内容压垮而退群。这件事其实简单：前面讲过搭建素材库，而且是永不枯竭的素材库；实在懒，就从赚钱找内容交付；有余力，再做更高端的互动。

比如每周三开直播，和群员答疑互动。这场直播除了交付和交互，还自带拉新功能。直播并不难，这就是手把手教你的“开直播无限话题”打法：手机背后放电脑，屏幕开着风向标就直接讲，开着读书笔记就直接讲，开着精华帖就直接讲。

托也很重要。安排五个人在直播间问你轻车熟路的问题，你的直播状态就能被解锁；群里只要有五个托，其他沉默群友也可能被唤起。托是社群最重要的元素之一，终极形态是人人都是托：前期靠小号、心腹，后期自来水越来越多，事就成了。

你可以想象：知识付费群里有人不断晒后台、晒ROI、晒GMV；健身减肥群里有人秀肌肉、秀身材；好物群里有人晒单、拆箱；自律打卡群里有人晒单词、晒时长、晒读书笔记……这对转化率的提升有多大？

再举个场景：一个女生立flag时总觉得自己能超越宇宙。她进了读书群，要求每天发读书笔记，坚持三天就撑不住了。但每天看到群里别人疯狂发笔记，她不会怪群主，只会觉得自己是小辣鸡。然后下个月，她续费了。是的，这对留存、客诉、转介绍都有正面作用。

# 七、售卖高阶产品

💡 章节概要

养成系IP初期，用低客单产品吸引用户；等内容成熟、影响力变大、铁杆粉丝增多，就可以卖更高阶的产品，比如训练营、课程、知识星球。这一章讲高阶产品怎么设计、怎么卖。现在开始筹备。

一鱼多吃，市面上也叫“A种B收”。本质是：你和粉丝迈过信任门槛后，可以反复在他身上完成价值实现。

比如你吸引了一个创业粉，可以先卖给赚钱，再卖给花爷，再卖给帅张……怎么卖？简单，“加我领资料”，一张海报，领取免费课，人就过去了。过去之后，你钱到手，后续转化看对方本事。只要合作方把好关、产品做好品控，这对你的势能不是伤害，而是增益。

万物皆可CPS。产品是多态的：自己研发的、别人的产品、别人的社群、别人的知识付费产品，都可能是好产品。做电商，你做流量卖货，别人生产和发货；做医美，你做流量成交，别人服务售后；卖课，你做流量，别人转化交付。道理一样：有交付能力，就做自己的高阶产品；没有交付能力，先帮别人做，边做边学，一起精进，等风来，等花开。

「流量价值」和「客户价值」

流量价值，是你做的这个选择能带来多少利益，是否符合“五高”：高客单、高利润、高粘性、高复购、高转介绍。传播属性也很重要。实在不行，至少符合两个以上。要去搞富人的零花钱，别赚穷人的生活费。如果不符合，就问自己：这个流量来得是否轻松？是否清楚它只是过渡？终局要通过什么手段、赚谁的钱、赚多少、怎么赚？

客户价值，是和你发生金钱交易的客户，是否迈过了最基础的信任门槛，你还能不能反复从他身上创造价值。举个例子：今天出100单大日化，卖128元蓝月亮、威露士套装，也加到🛰️了，这些人有价值吗？有，但不多。同样128元客单，成交100单，卖的是祛斑祛痘、减肥小药丸，要往脸上抹、吃进嘴里的，这些人有价值吗？有，还挺大，因为他们算真迈过了信任门槛。

以后做事可以骚、可以浪、可以试错、可以过渡，但多用“流量价值”和“客户价值”这两个标准框定终局，思路会清晰很多。能积累迈过信任门槛的客户的事业，就是更正确的事业。

客户是什么？客户是你最强的生产要素。一个人5年前炒股，5年后大概率还在炒股；5年前减肥，5年后大概率还在减肥；5年前知识付费，5年后大概率还在知识付费。回到减肥茶例子：这样的客户在你手上，就能反复转化。她买减肥茶，大概率还会买减肥药、减肥装备、普拉提装备、瑜伽装备；还会买代餐、辅食；还能转化皮肤管理、美白、祛斑、祛痘、医美、生美、科美；还能转化未来的母婴、大健康；甚至转化她做副业、做微商、做知识付费，以及读书会、成长、情感。这样的客户，就是你最具确定性的生产要素，能陪你穿越周期。

默克制药的座右铭很到位：药是用来治病的，利润是随之而来的，不会缺席、不会迟到、不会少。很多结果是行为的结果、专注的结果、解决问题的回报、提供价值的回报，不是目的，不是想当然。

小结一下：“选择”大于努力，不是鸡汤，是顶级策略。记住这个模型，会少走很多弯路。当然，前期受年龄、社会阶段限制，我们未必有太多选择权，但别怕，我们在赚钱。

当前最优解：不用焦虑，不用一步到位，有思考就先干着。人生战略，就是在下一个战略“涌现”之前的最优解。心里埋颗种子，就更有方向。高阶产品可以很多：课、高阶课、训练营、陪跑、收徒、咨询、私董会、星球……

比如做课，真心不难。你有想做的方向，就带着关键词去学浪、千聊、各种云课堂找被市场验证过、最受欢迎的课。看他们的海报和课程表——因为是你的领域，看完课程表基本就知道他们要讲什么。然后你有了框架、大章节，再把不擅长的章节剔除，就得到自己的课表。过程中会不断遇到可加入的点，但基本框架很重要，不然会变形。可以这样做：

01，定框架：找同主题的标杆老师和标杆课程，找出被市场验证可行的知识点。
02，到千聊、荔枝微课、得到、喜马拉雅、混沌大学、十点课堂等平台，把第1步能用的知识点汇总。
03，记录每门课宣传文案里的大纲、更新说明、适宜人群、配套运营动作、推广动作、礼包福利。
04，用幕布笔记确定大纲。
05，按你的舒适区分为几个模块，把第4步的大纲打散，分别放进去。
06，逐个整合模块，删重复、做精简。
07，第6步做完，一门综合多个课程热点、更全面的新课就登场了。
08，按新大纲写稿，一个小节一个小节写。
09，全部写完后改稿，每遍关注点不同。
10，第一遍改稿：提取关键概念、思维模型、关键问题，否则课不够深。
11，第二遍改稿：加入案例、故事、金句，否则课不够生动。
12，第三遍改稿：看哪里需要加图示，比如流程图、知识卡、插画。
13，第四遍改稿：通读，把书面语改成口语，书面语太生硬，口语要有引导、有情感。
14，配备必要的PPT。
15，看未来课程的平台要求，想清楚在哪个平台交付，再决定录语音、短视频还是直播。

然后结束了吗？没有。

16，常见问题：往下走时可能不自洽。比如框架出来了，在第8条之后填充内容时，一嗨就加戏，加着加着把既定框架推翻，或打乱顺序，原本50页变100页。怎么破？
17，按第8条的大纲，一节一节写。
18，写的时候新开一篇幕布，拷贝第8条大纲；有想加的新章节，先放这里，暂时不管顺序和逻辑自洽。
19，第2条里想到的新点子、新模块，用知识卡记录。格式：一个关键词+简短小标题+内容，500到2000字不等；知识卡集中放一处。
20，按第8条大纲写完，再调整大纲，把第8条内容和另外攒的知识卡放进新大纲，继续填充细节。过程中如果又嗨了，就重复这个过程，会递减、会穷尽，最后稿成。

另外，这需要你有把一句话演绎成三千字的能力，或者掰扯大量案例的能力。其他产品也大同小异，并不复杂。

你会发现，内容其实差不多：初阶课加上情绪价值、大量案例拆解、作业布置、模板收集、内容共创，就构成了训练营。我们当然可以想尽办法把交互和交付做得更好。

比如训练营、陪跑营里的奖励和激励。激励和奖励不一样：奖励是平均的，群主时不时发红包，意义不大；但如果谁对社群有贡献，你发专属红包，或把红包命名为“感谢某某”，再发一个大家都能抢的红包，讲几句花团锦簇的话，激励就到位了——情绪、面子、里子都有了。

这种事要随机、不递减、养成习惯，但不该给人期待，也不是约定俗成。随机，是想发就发，主观的；不递减，是第一个贡献红包很大、后面不会越来越小；养成习惯，是你自己不断激励群员；不给期待，是别引发功利心。它不是规则，是你的主观。很微妙，但这是群主权威的塑造，也是你和其他群主拉开差异化的有效手段。久而久之，大家会把更多注意力放到你的群里。注意力就是钱，信任就是钱。
