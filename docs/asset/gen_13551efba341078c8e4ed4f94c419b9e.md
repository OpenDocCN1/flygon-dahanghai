# 5.8 NFT 市场的潜在风险

任何新兴领域都不可能只有机遇，NFT 同样暗藏诸多隐患，值得每一位参与者警惕。

1）安全防护风险

这个圈子里黑客活动频繁，各类骗局层出不穷。若缺乏足够的警觉和基础安全知识，很容易落入陷阱。与此同时，一些项目方的安全意识和防护能力不足，导致 Discord 服务器遭到入侵，进而连累大批粉丝受骗。

我亲眼见过太多人辛苦积累的财富，仅仅因为一次安全疏漏就瞬间归零，这件事再怎么强调都不为过。

2）二级市场波动风险

和股市相似，人们总爱追涨杀跌，但 NFT 市场的波动远比股票剧烈得多。价格可能在极短时间内翻倍，也可能迅速腰斩。如果在高位冲进去，大多数人的结局只能是割肉离场。

3）流动性枯竭风险

一旦某个 NFT 缺乏流动性，哪怕价格压得再低，也没有人愿意接盘，最终就会形成“有价无市”的尴尬局面。那些本身没有价值的 NFT，最后只会变成手里一堆卖不出去的图片。

4）交易摩擦成本

玩以太坊项目时，铸造 NFT 不仅要支付本身的费用，还得额外承担一笔不小的 Gas 费。特别是在 Gas 居高不下的时段，多花几十甚至几百美元都是常态。频繁买卖未必能提高收益，但交易成本却会明显上升。

5）项目方作恶风险

由于 NFT 发行门槛并不高，很多项目方从一开始就抱着“捞一笔就跑”的心态，并没有长期深耕的打算。他们常用虚假承诺和夸大宣传吸引买家，等大家买入后才发现，到手的只不过是一张毫无价值的图片。

6）项目辨别能力不足的风险

看不懂项目本质，听到别人说哪个好就盲目跟风，自己却缺乏独立判断和深入了解。遇到劣质项目自然难有回报，就算碰到好项目，也会因为一点风吹草动就恐慌抛售，最终亏损在所难免。

7）买到假冒品的风险

由于任何人都能铸造和上架 NFT，OpenSea 上充斥着大量非官方假货。如果你无法准确辨别真伪，很可能花了高价，最终买到的却是一个冒牌货。

可见，不是每个人都能轻松驾驭这个市场。那么，到底什么样的人不适合参与 NFT 呢？

以下七类人，最好离这个圈子远一点：

1）幻想一夜暴富的人。NFT 市场上确实有不少暴富神话，但这里面存在严重的幸存者偏差。赚到大钱的人会到处宣扬，亏钱的人却只能默默舔舐伤口。如果整天盼着靠它发大财，看到别人赚钱就心态失衡，只会让自己更加焦虑。真正该做的，是在过程里不断打磨认知，才可能抓住属于自己的机会。

2）缺乏执行力的人。只停留在刷信息、看热闹的阶段，几乎从不实际操作。嫌这个麻烦、嫌那个复杂，不愿去钻研。当真正的机会出现时，往往因为没有经验储备或基本条件而眼睁睁错过。

3）没有独立思考能力的人。听到什么就信什么，别人说哪个项目好就冲进去，从不琢磨背后的逻辑和原因，更不会深度研究项目本身。一有风吹草动，立刻恐慌、放弃。

4）缺少基础解决问题能力的人。其实很多小问题，打开百度搜一搜就能找到答案，或者多试几次也能搞定。如果连这些都不愿自己解决，总指望别人手把手教，不仅效率低，成长速度也会慢很多。

5）缺乏安全意识的人。从不做任何安全防护，遇到风险极高的项目，也不知道用独立小号钱包去尝试隔离风险。

6）没有辨别能力的人。哪怕手段极其明显的骗局也看不穿，轻易就被利益诱惑，脑子一热就上了头。

7）赌性太强的人。经常不做任何分析，就 All in 某个项目，妄想凭运气博取高额回报。

反过来看，如果你具备与之相反的特质——例如学习能力不错、执行力到位、能在实践中不断复盘迭代，持续提升自己的认知水平——那么在这个领域里，会更容易游刃有余，项目胜率也会随之上升。
