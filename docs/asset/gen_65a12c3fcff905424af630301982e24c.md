# 大妈效应：把“爱便宜”做成生意

先聊一个城市里常见的画面：不少上了年纪的人愿意搭免费公交，穿过大半个城，只为了买到更便宜的吃穿用品。商超里有些促销商品，价格甚至压过线上，也低于进货成本——商场强行打折，等于赔本换人流。这背后，就是值得琢磨的“大妈效应”。

广场舞把大妈群体天然聚到了一起；她们对日用品的价格格外敏感，消息传得也快。智能手机普及之后，完全可以给她们装一个 App：只推送附近哪些店在打折。大妈一看到，就可能结伴蜂拥到店。

落地时有几个关键点。

第一，产品要极简。这个 App 只做基于位置的促销信息，不塞其他附加功能。

第二，地推有路径。开小超市的不少是江浙人，彼此认识，容易形成有效团体；大超市也多有开放合作的空间。前几年一些跑腿业务，对商超商品价格很熟，也可以借力。

第三，收费对象是参加促销的门店。因为大妈到店后不会只拿特价品，还会顺手带走其他商品。收费比例和价格，可以参考云蚂蚁。

评论区也有不少碰撞。有人问：美团跟进怎么办？分享者的回应是，云蚂蚁的模式是在一定公里范围内只允许开一家；客群也不同，这里专门面向大妈，打法简单直接，而美团等平台，大妈未必会用。也有人担心地推效率低、实际购买的品类少；分享者认为，朝阳群众和大妈群体的流量并不低，城市购买力也很惊人，看看每年的年货会就知道了。至于品类，可以放开想象——她们为了几毛钱也愿意囤货，传播率又高。另一位读者则判断，优惠产品的体量可能撑不起来。

还有人建议把洞察做得更细：大妈为什么愿意为便宜这么拼，是过去穷过，还是追求成就感？现有围绕这类需求的产品有哪些，各自怎么做、成绩如何？未来十年、二十年陆续进入这个年龄段的人，还会和现在的大妈一样吗？

一位叫麒麟的读者补充了“招徕定价”的逻辑：用低价吸引顾客到店，低价只是手段，到店才是目的，最终带动其他商品销售。他举例说，母亲看到超市面包“买二多一”，便叫上张姨、李婶一起去，最后购物车里装得满满当当，远不只买了便宜面包，还放了不少并不便宜的商品。可见大妈不只是偏爱低价，更在意心理平衡：面包上占了便宜，买猪肉时多花块八角也能接受，心理定价因人而异。对商家来说，关键是选好引流品，让大妈忍不住招呼好友一起到店；哪怕只买面包，至少也能聚人气，从众心理随后会发挥作用。麒麟还提到，自己加入生财第 172 天。

读者木头也温柔则提出一个角度：这套思路是不是从小城市包围大城市？据他了解，小城市大妈的从众效应更明显，大城市的情况未必相同；如果在大城市做从众效应，从相亲这个点切入可能更好，当然这只是个人浅见。

归根到底，这个思路抓住的是大妈群体价格敏感、传播快、爱结伴行动的特点，用位置化的促销信息把她们聚到门店，再向有引流需求的门店收费。与此同时，品类供给、平台竞争、代际变化和从众边界，都是需要继续验证的问题。
