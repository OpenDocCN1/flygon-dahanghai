# 三年从零收入到日入八千：一个女孩的赚钱认知升级记
（精华帖）（132 赞）

作者：周周  
日期：2021-03-30

想聊聊我那段单枪匹马折腾赚钱的三年。对一个普通女孩来说，这段经历不算传奇，却足够真实。

真正改变我的，是2017—2019这三年。那是我对“赚钱”这件事开窍的关键期，也是后来所有选择的底子。后来我也干过一个月跑通百万元目标的事，但我更想讲的，是最初从零起步、笨拙摸索的阶段——因为很多普通人要么经历过，要么正卡在这里。把过程摊开说，或许更能帮到人。

2017年我裸辞，之后整整五个月，账户里没有一笔进项；到2019年，一个人待着，很多天不用做具体事务，日入六七千、八九千也不稀奇。从手头紧到崩溃，到后来相对从容地进账，中间做了什么、当时怎么想，我都愿意讲。配图和记录都在，图片放不下的部分，我附了PDF原文。

这篇会分成这几块：

1、一天不忙也进账
一个人，一天里几乎不用忙什么，进账六七千、八九千是常有的状态。

2、最难熬的日子
女生常见的那些爱好，我几乎都搁下了。在最好的年纪里，我基本没把心思放在打扮和享受上，只盯着一个目标：想办法挣钱，逼着自己硬扛。

3、把赚钱路子摸了个遍
那阵子真是五花八门，明的暗的、擦边的、正规的，市面上常见的赚钱模式我几乎都研究过一遍。所以后来在龙哥盟里看到各种玩法，我也不陌生。

4、踩过坑，也见着过钱
做过的事拿几个出来说：有的赚得多，有的赚得少，也有忙活半天颗粒无收的。

5、说到底拼的是认知
弯路走了一段又一段，但正是这种疯狂试错的阶段，让我对赚钱的理解进步最猛，也慢慢从门外汉换了脑子。

6、开始带人做培训
自己挣钱当然要继续，更关键的是，确实能带着别人也拿到收入。
