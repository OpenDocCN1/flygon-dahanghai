# 4.1.2 总在否定自己？先看这套才干组合 @醒醒同学

一个从小缺乏底气、习惯把“我不行”挂在心里的人，怎样才能慢慢建立自信？这个案例或许能给出线索。

她的四个维度强弱顺序是：执行力排第一，关系建立第二，战略思维第三，影响力第四。排进前十的才干依次为：审慎、和谐、回顾、伯乐、统筹、排难、体谅、成就、适应、交往。

**从盖洛普视角拆解部分才干**

当审慎、和谐、排难、体谅、适应这五项同时进入前十，而积极、自信、统率却落在后面时，这个人大概率会长期陷入内耗，精力常常被自我拉扯消耗掉。这样的组合，也许最容易让人缺少自信。

先看四个维度：关系建立与执行力都相当靠前。放到日常里，她往往能迅速捕捉别人的需要，也乐意配合大家把事情办妥。和她相处轻松自然，没有攻击性，她习惯安静地付出，不爱惹麻烦，也不主动挑起争端。若你能成为她的朋友，常常会有被认真珍视、被放在心上的感觉。

体谅、伯乐、交往三项叠加时，她对熟悉且认可的朋友会给出充足的支持、照顾与信任。无论工作还是生活，只要是她认定的朋友，她都很在意对方的感受，也容易看见对方身上的亮点，并鼓励对方去做想做的事。

审慎、交往、体谅放在一起，她很可能成为不少人的“树洞”，而且口风紧，不会随便把秘密说给旁人听。

适应与成就并存，意味着只要你有需要，哪怕会打乱她原本的节奏，她也愿意先帮你，再回头处理自己的任务；灵活度和完成度都不低。

审慎、排难、和谐、体谅同时作用时，别人随口一句“你为什么不这样处理？”，她表面也许没什么反应，内心却可能已经翻涌起来（体谅），先怀疑是不是自己哪里没做好。但她未必会讲出来，也不觉得有必要争辩，于是把话憋在心里，反复琢磨自己的问题（排难）。她不喜欢冲突（和谐），又担心说错话让矛盾变大（审慎），所以常选择默默用功，拿成绩和付出来证明价值；如果还是得不到认可，就会认为是自己不够努力。

排难这一项也很典型：别人夸她九句，只要有一句指出不足，她的注意力就容易黏在那一句上，觉得自己还不够好，接着开始内耗。不过，她也愿意正视不足，韧性很强。

总体来看，这是一套无论做出什么成绩都很难真正相信自己“已经不错”的才干组合，她对正反馈的需求非常高。但在人际关系不复杂、团队稳定性较高的环境里，她通常能获得不少认可，尤其适合用户运营相关岗位，服务好评度往往不错；如果遇到一位对内护犊子、对外强硬的领导，会更有利于她发挥。过于狼性的工作氛围，最好避开。

除了留意环境对自己的影响，想提升自信，可以抓住三步：第一，意识到并接受自己总会习惯性否定自己；第二，多和「积极+沟通+伯乐才干」靠前的人相处，从他们身上感受充足的正反馈；第三，每次否定自己时，也别忘了回头看看自己做得好的那一面。
