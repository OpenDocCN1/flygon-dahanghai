# 2.5 安装 Postman（API 测试工具）

Postman 是什么？

Postman 是专门用于测试网络接口（API）的工具。后端开发时，可用它模拟前端请求，确认接口是否正常，是前后端联调的好帮手。

使用场景：

接口调试：开发 API 时，先用 Postman 发请求，确认返回数据正确。

前后端联调：前端页面尚未完成时，可用 Postman 模拟请求，检查后端接口数据是否对得上。

自动化测试：编写测试脚本，自动检查接口稳定性。

接口文档管理：生成 API 文档，便于团队共享。

安装步骤：

1. 打开 Postman 官网下载页。

1. 下载与你操作系统匹配的版本并安装。

接下来把游戏网站发布到互联网。

步骤一：进入 GitHub 项目仓库，点击“Settings”。

步骤四：点击“Save”。

步骤五：触发部署。回到代码编辑器，随便改动一点内容（例如新增 README.md 文件），再次提交并推送到 GitHub。这次推送会自动触发 GitHub Actions 开始部署。

1. 需求分析

不少做自媒体或社媒营销的人，常常要从抖音、小红书等平台找素材做二次创作。但平台下载的视频和图片往往带水印，后期处理很麻烦。市面上已有去水印小程序和网站，不过自己做一个也完全可行。

核心需求点：

1. 交互界面要简洁，能粘贴分享链接。

1. 工具能自动解析链接，并覆盖多个主流平台。

1. 解析后展示视频或图片封面，并支持无水印下载。
