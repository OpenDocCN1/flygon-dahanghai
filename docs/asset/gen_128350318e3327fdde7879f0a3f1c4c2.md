# 渠道二：学术资料，去这里找

教材和参考书通常结构清晰、体系完整，但成书周期摆在那里，部分内容难免停留在较早阶段，最新研究与数据往往覆盖不足。想补上这块，可以转向学术期刊、论文、研究报告和行业杂志，从中追踪所在领域的新成果。

下面这些入口在国内使用频率较高，适合作为查找学术资料的起点：

• 中国知网：www.cnki.net/
• 维普网：www.cqvip.com/
• 万方数据知识服务平台：www.wanfangdata.com.cn/index.html
• 百度学术：xueshu.baidu.com/
• 全国图书馆参考咨询联盟：www.ucdrs.superlib.net/
• 超星发现：chaoxing.com
