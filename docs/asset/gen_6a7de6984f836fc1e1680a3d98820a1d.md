# 7.1.2.4 时事新闻：让AI写稿前先备好这些 @肉松

想让 ChatGPT 帮你写时事新闻，先别急着让它动笔。把下面五类材料交代清楚，它才更容易写出靠谱、能用的稿子。

- 报道对象与标题：说明你想写哪件事，并给出一个拟定题目。
- 事件来龙去脉：补充背景，包括历史脉络和当前状况；如果涉及政治、经济或社会议题，再附上相关历史、数据和背景知识。
- 关键人物与机构：列出政府官员、企业负责人、专家学者、民间组织等主体的姓名、职务和必要身份信息。
- 最新动态与影响：若事件仍在发展，提供最新进展，并说明它对相关群体和社会可能造成的影响；有条件的话，加上专家或权威人士的点评与分析，帮助读者更好理解。
- 信息来源：给出新闻报道、研究报告、专家访谈等可靠出处；若你本人就是参与者或目击者，也可以补充亲历观察。

把这些信息交给 ChatGPT，它可以据此写出一篇面向公众号的时事新闻稿，力求准确、符合客户意见且有传播价值，方便你向读者传递信息，并引发关注和思考。上述整理来自 ChatGPT。

举个例子，素材中的简单时事案例是“《向往的生活》综艺栏目第七期后不再录制”。换成提问场景，可以设定你以娱乐评论人的身份发问：请评析《向往的生活》第七季收官后，黄磊主动为这档综艺收尾一事，说说你的看法和评价。
