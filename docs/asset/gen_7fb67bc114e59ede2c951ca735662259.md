# 5.6 标题得人来定

拟标题这件事，最终拍板还是得靠人。一个标题够不够抓人，往往直接决定文章有没有被点开的机会。ChatGPT 给出的标题，现阶段还不能拿来就用；不过，让它多拟几个，倒是能提供不少灵感。

操作上可以这样：先让 ChatGPT 看几组爆款标题，熟悉那种吸引人的感觉，再让它围绕自己的文章出标题。示例 prompt 如下：

爆款标题样本 1
爆款标题样本 2
爆款标题样本 3
爆款标题样本 4
爆款标题样本 5
请借鉴这 5 个样本，为下面的文章生成 5 个有吸引力的标题。
text: """ 文章内容 """

• 吸引力还不够，能否再优化？加入异常、反转、数字、冲突等元素
