# 6.1.3 会造梦，也要会讲故事

**一、先把梦造出来，精神价值才卖得动**

1. 造梦，是高客单价生意的底层能力

奢侈品从来不是刚需。可为什么普通人也会心心念念想拥有？答案就在两个字：造梦。

那些大牌是怎么操作的？它们反复告诉你——你值得更好的东西。高级大片、广告画面，全在往这个方向推。等你走进门店，灯光、香氛、陈列，连导购微笑时露几颗牙都经过设计，这一切都在悄悄替你编织一个梦。梦一旦立起来，人心里那股渴望就被勾出来了。

那放到线上、做私人运营的高客单价产品，梦该怎么造？美德的做法是抓住三个抓手：产品分级、视觉图片、顾客惊喜。

（1）选品本身就是造梦的一环

把产品线拉开档次，奢侈品早就在这么干了。一线大牌几乎都有高定系列，贵到离谱，全球能消费的也就五百来人，可大秀照做、高定照推；香奈儿、LV、迪奥这些以包袋服装为主打的品牌，也要挤进高级珠宝赛道。图什么？图的是拔高品牌调性，让全线产品的溢价空间跟着往上走——顾客花小钱，也能尝到更高级的梦。

美德在新品上架时也用了这个思路。社群里始终保留一定量的爱马仕，以及卡地亚、江诗丹顿这类几十万甚至百万级腕表的内部渠道资源。真正下单的人极少，一年也就那么几次，但美德基本每月上新三到四回，差不多每周一次，节奏不能断。

反过来看，顾客也是要养的。不少人向往奢侈品却暂时够不着，没关系——美德手上有大量美妆类内部资源，价格比专柜友好得多。这些品不挣钱，照样往群里发，目的就是让客户养成一个习惯：想买好东西，先想到美德的群。等她真正有能力拥有的时候，自然也会回头找我。

（2）图片，是梦照进现实的第一步

一张图，往往就能决定顾客买不买。有时候让客人不再犹豫、直接下单的，就是某张图。

这跟奢侈品广告、明星穿搭的逻辑是一样的。线下店里，客人只能看实物、看镜子里自己的上身效果；线上就不一样了，可以看长得好看的人穿在身上——好看本身就有吸引力。

为了控成本、算清楚前期投入产出，美德没有自己组团队拍专业图，而是搭了一个图片搜集小队，专挑高清、有质感的素材。光有官方图还不够，太高端反而让我的客群产生距离感。所以小红书上好看的素人图也是上新内容的一部分。再加上到货实拍、美德自己的上身图，亲切感有了，带货效果也就出来了。

（3）顾客惊喜：让梦真正落地

细节不展开，总之是让一部分客人产生“哇”的那一下。感兴趣的话，来做我的VIP客人亲自感受。

（4）帮顾客造一个“用得上”的场景

卡地亚每年办高级珠宝展，店铺大客户团队会邀请有实力的客人到场看展，顺带引导消费。展览配套的晚宴等环节，规格都做得很足。为什么费这个劲？因为很多高级珠宝动辄几百万上千万，客人买回去多半是收藏，平时根本没机会“亮出来”。所以，替客户创造展示的机会，本身就是服务的一部分。

这个思路可以迁移：做减肥的，可以搞走秀、走红毯、拍形象照——肥都减完了，当然要给客户一个展示的舞台。

美德平时也会办活动，让顾客穿着在我这儿买的衣服、背着我这儿买的包，美美地拍照留念。办活动有一个巧招：借你所在城市的活动或展览资源，把格调撑起来，这本身也是造梦的一环。美德常借助各品牌的展览资源做活动，上次活动反馈就特别好。

**二、会讲故事，才给得出精神价值**

营销课讲奢侈品，总说它们擅长讲故事。故事讲到最后，是让消费者心甘情愿为“感觉”买单，说白了就是用好价值定价法。

卡地亚猎豹系列就是典型。这个系列最出名的梗，是温莎公爵夫妇的爱情故事——爱美人不爱江山，放弃王位娶了温莎公爵夫人，并请卡地亚为她设计了多款猎豹元素珠宝。从那以后，猎豹系列成了爱情的象征，也成了品牌常青款。这个故事太经典，经典到至今仍是卡地亚的主力系列。奢侈品的每件作品，背后都有故事、有灵感、有设计师想传达的理念。

再比如香奈儿。香奶奶和十几个男人的轶事，大家耳熟能详，可这个故事能传得这么广，很难说没有商业运作的影子。香奈儿走过一百多年，品牌能延续至今，靠的早就不是创始人和她的后代，而是背后的资本——维德摩尔家族，可听过这个家族的人少之又少。品牌刻意让资本隐身，让香奈儿的故事变成传奇，故事才能一直传下去。那些风流韵事，本来也是品牌公关的一环。

如果我运作一个新品牌，一定会研究怎么讲好品牌故事和产品故事。但我现在卖的是别人的品牌，所以我要做的，就是把产品本身的故事讲透。

我们很少像代购或其他奢侈品卖家那样，在朋友圈、群里刷产品细节，反而更愿意聊背后的故事，这也是和其他卖家拉开差距的地方。分享一个最近的案例。
