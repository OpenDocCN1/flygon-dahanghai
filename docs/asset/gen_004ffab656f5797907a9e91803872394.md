# 别让陪玩的人干等

当宠物在店里接受洗护、美容等服务时，陪同的主人其实不必无聊坐着。完全可以让他们喝杯咖啡、翻翻书、闲坐一会儿，或者和身边的人聊聊天、交个朋友。

顺着这个思路，还能想到另一个场景：不少带娃出门的家长，常被挡在只允许孩子进入的游乐区外，只能低头刷手机消磨时间。那么，是不是也能给家长留一块舒服的地方——有饮品、有读物、有座位，既能休息，也能社交？

有人提到，如今很多培训机构都由爷爷奶奶、外公外婆负责接送孩子。若能在附近给老人提供下棋、写字的空间，应该会很受欢迎。

亦仁认为这个方向中标，术值+1。在上方 #星球栏目 专栏里点击 #中标，可以查看所有中标风向标。

麦子哥说，孩子能进、大人不能进的地方，最适合带娃的大人放松一下，哪怕只是刷刷手机，也已经很满足了。

王小七提醒，家长也不能一直不关注孩子，还是要隔一阵看一眼。
