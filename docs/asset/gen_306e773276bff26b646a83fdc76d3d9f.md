起号通常有两条路可走：第一条，先把初期进来的那点流量接稳，用漂亮的数据证明直播间有承接力，同时从中辨认出谁才是目标客户，让系统逐渐清楚“哪些观众偏爱我们”。连续几场数据往上走，直播间权重就会抬起来。第二条，直接投流买一批相对精准的用户，用这批人做出数据，让系统更快学习直播间画像，从而缩短起号周期。

但不管运营手段怎么选，最后都得落在直播承接能力上。航海期间，心态要健康积极，别急着求成，结硬寨、打呆仗，每一场都认真播、认真感受流量、认真复盘，慢慢就会走上正确的直播路径。

# 2.2.2 直播计划怎么排？

大多数船员第一次接触直播，所以这里先给一份可参考的计划。大家要结合自己直播间的数据反馈，及时判断当前阶段目标，并调整复盘和准备的重点。

起号阶段安排在第1—5天，目的是让账号正常推流、直播间具备基础权重。目标数据是每小时场观150+、在线10人，并且直播间能出单。这一阶段的重点有三件事：熟悉直播感觉，心态稳住不慌张；了解直播内容，能把脚本话术流畅表达出来；熟悉观众常见问题，做到从容应答。

破层级阶段安排在第5—15天，目标是直播间初步起号，拥有一定精准观众，并能稳定把流量引到私域成交。目标数据是每小时场观300+、在线20人、每场直播引流10人。重点在于：理解直播间推流逻辑，能够做数据分析和复盘；能针对直播间问题改进，持续优化话术；在直播中有意识地做数据。

稳号阶段在15天后，此时直播间流量比较稳定，每场都能成功引流，数据逐步递增。目标数据是每小时场观800+、在线50人、每场直播引流50人。重点在于：主播能力逐步提高，每场稳定发挥，吸引精准受众；会看实时流量图，并能根据数据及时调整直播节奏。

# 2.2.3 新号开播怎么起？

新号刚开播时流量少，这个阶段要把点对点互动和要数据作为重点。

前期流量不多，先专注练内容，把直播内容播好。有用户互动时，可以适当多交流，让精准用户多在直播间停留，帮我们做数据，慢慢就能起号。流量少的时候，少做引流动作，多讲干货，提高直播节奏和内容密度，减少一切可能让客户流失的行为。如果发现流量突然上涨，一定要及时调整状态，承接好这波急速流；急速流接住了，直播间的流量口子就可能彻底打开。

如果直播间持续有推流，可以适当拉长时长，尤其是视频号，只要有流速就不要轻易下播。如果每分钟推流低于5人并持续半小时以上，可以考虑下播；如果每分钟推流长时间在1—3人，说明自然流基本没有了，建议下播。可以过半小时再开一场，一般每场直播都会有一定初始推流，尝试再利用初始推流做数据。

# 2.2.4 起号后怎么播？

起号成功后，直播间在线一般在30人以上。这时如果点对点互动太多，其他没被互动到的观众容易觉得内容没重点，然后划走。所以这个阶段不要做过多点对点互动，除非互动观众提的问题是受众普遍存在的问题，可以重点讲；否则一句带过，甚至可以不回应。

稳流量阶段，要多关注直播曲线图和流速变化。流速持续上涨时，一定要专注，保持好状态把流量往上推，同时关注数据，别忘了及时引流。流速下降时，就提高干货密度，不断放钩子做停留数据。

每天复盘时要重点做内容复盘，找到什么内容吸引人、什么内容掉人。后面直播时如果人掉得比较快，可以考虑转到更吸引人的内容上，持续控制流速，让流速保持稳定，避免掉层级。

起号成功后，不要等到直播间完全没人再下播。观察开播急速流的大小，当前流速低于开播急速流的20%时，可以考虑下播，让本场数据层级不会下跌得太严重。

# 💡 本章导读

# 2.3.2 常见直播数据怎么理解

场观与在线：这是直播间最基础的数据。说白了，就是每场直播有多少人看过我们，以及现在有多少人正在看。场观要尽早建立一个概念：每小时场观。每场直播时长不同，单纯比场观没有意义，用场观除以直播时长就是小时场观，可以理解为“播效”。

直播间曝光进入率：平台会把直播间推给用户，用户点击进入后才成为观众。用场观人数/曝光人数×100%，就是曝光进入率。不同赛道差异较大，和受众、直播形式有关，一般来说10%—60%都算正常。

流速：指直播间推流速度，也就是每分钟能进多少人。假设平均流速是每分钟10人，每小时场观就是10×60=600人，流速直接决定场观。直播时应该重点关注流速，而不是平均在线，因为平均在线本质上由流速和平均停留时长决定。

平均停留时长：指直播间平均每个观众停留多长时间。停留时长是很重要的浅层数据，也是重要赛马指标。一般来说，同一类直播间里，平均停留越久，系统推流越大、越精准。所以做知识付费直播间时，要千方百计做平均停留时长：让更多用户在直播间停得更久，流量就会更大。

互动率：直播间互动一般包括评论、刷礼物、关注、加粉丝灯牌。抖音直播中，加粉丝灯牌对赛马权重较高，要重点做，其次是关注。互动率也是影响直播流量的重要指标，通常互动率越高，流量越大。

# 2.3.3 获取数据的几种技巧

下面分享一些知识付费直播间的小技巧，能有效帮助提高直播间数据，更容易快速起号。注意，这些方法主要适用于干货教学直播间，不适用于所有直播间，比如带货直播间。

# 2.3.3.1 点对点互动

刚开播时，直播间在线可能只有个位数，去掉几个系统机器人，实际可能只有两三个人，这很正常。虽然人少，但我们的赛马对手同样也是没人气的直播间。如果能让直播间仅有的几个人帮忙做数据，就很容易提高推流层级。

前期没人时，最好的办法就是点对点互动。和每个进入直播间的人点对点交流，可以大幅提高真实用户互动率和停留时长，是直播间人数少时最有效的要数据手段。举例来说，直播间正在讲AI干货，这时张三和李四进来了，我们在互动大屏看到在线用户数据后，可以直接问：“张三之前有没有做过这个项目？”“刚才我讲的，李四听明白了吗？没听明白可以直接在公屏提问。”点对点互动的对象可以是刚进直播间的人，也可以是停留很久的人。用户不回复也很正常，不要因为一两次没人回应就放弃，前期人少时一定要多尝试点对点拉数据。

# 2.3.3.2 主动要数据

我们做的是教学型直播间，是以“老师”的身份直播。所以直播时要有自信、有气场，不要唯唯诺诺、过于谦虚，否则不容易吸引用户停留。同时也要大胆给用户提要求、要数据。比如用户提问，如果直播间人不多，可以先回答，然后说：“这里听明白的给我点个关注、加个粉丝灯牌，有其他问题也可以继续问。”如果在线大于30人，有用户提问，可以说：“想提问的先给我点亮灯牌再问，现在提问的比较多，我肯定优先回答粉丝的问题。”“xxx问的这个问题很好，你先加个粉丝灯牌，我告诉你怎么做。”有经验的干货分享主播和没经验的主播，差距往往就在有没有养成要数据的习惯。会要数据的主播，起号速度通常更快。

# 2.3.3.3 钩子前置

内容直播间往往由吸引人的内容和不那么吸引人的内容组合而成，不可能一场直播全程高潮。那么讲“不那么吸引人的内容”时，怎么让观众继续停留？办法就是提前把有吸引力的内容抛出来，让大家有期待，从而在直播间停得更久。比如：“我先给大家讲一下xxx这里，刚才不是有好多同学想学yyy吗，过1分钟后咱们就开始讲。”“过会有个福利给到大家，讲完这里就发，大家可以猜一下是啥，待会很快给大家发。”实际上xxx可能讲10分钟，但不用在意，要学会用利益诱导做数据。

# 2.3.3.4 干货后置

直播内容里，有些话题天然吸引人。讲这些“天然留人”的话题时，要把握好节奏，不要讲太快。在有吸引力的话题上多“墨迹”，多“讲废话”，可以叫“讲细一点”。讲干货前也可以多加一些前戏，多让观众互动，比如：“我给大家讲一下真正的干货，讲之前先问一下，大家做xxx的时候，是先做a还是先做b？”因为大家都着急听干货，这时互动率会比较高，同时在互动过程中也潜意识完成了停留。千万不要着急把吸引人的内容快速讲完，也不要怕被观众骂“太墨迹”。如果真的怕被骂，可以提前把“太慢”“墨迹”“快点”“赶紧”等内容设为屏蔽词。

# 2.3.4 直播数据怎么复盘

想做好直播，一定要养成复盘习惯，在每场直播中找问题并提高。但直播复盘需要较丰富的运营经验，本期航海不会讲太专业复杂的数据复盘流程，而是分享几个重点关注的基本认知，先帮大家建立基础复盘思维。直播新人复盘时，可以先重点思考这几件事：

1. 我们播得有没有硬伤？硬伤从两方面检查。首先听回放，从观众角度听“我们播得是否舒服”，包括语速是不是过快或过慢、发音是否清晰、话术是否熟练、是否经常磕绊、有没有口头语。这些问题99%的新人主播都会有，解决方法无他，就是刻意练习。其次是看数据，前期重点看停留时长和关注率。停留时长低于1分钟，要么内容太不吸引人，要么播得太差，这个问题一定要复盘并针对性解决，解决之前不要盲目继续重复直播。关注率低于2%，说明要数据能力太差，也要尽快解决。如果这两个数据达标，说明直播间至少及格，再去重点复盘其他内容。

2. 这一场的数据相比上一场有没有提高？每场直播后，都要对比过去两场的数据，主要目的是复盘“我们做的调整是否有效果”。重点对比场观、最高流速、最高在线、停留时长、关注人数。如果数据偏差在5%以内，基本可以认为两场数据一致、没有变化；如果本场相比上一场明显提高，说明调整有效，继续保持并优化，做到每场递增，很大可能起号成功；如果某项数据明显降低，就要分析问题所在。

3. 这一场直播有没有异常数据，为什么？检查每场是否存在异常数据，比如突然走了一批人、曝光进入率大幅提高或降低、停留时长变化较大。如果在复盘时发现这类问题，一定要重视，这种异常点往往是优化和调整的关键。复盘异常数据时，要结合直播回放去看，重点思考直播间播了什么内容导致异常。直播数据本质上是直播内容的映射，反映了内容对观众的影响。养成分析异常数据的习惯，直播能力提高会非常快。

4. 这场直播中，哪部分内容吸引人，哪部分非常不吸引人？我们做的是内容直播间，大多数时候是干货分享，所以直播间内容设计非常重要。一开始不知道什么内容好、什么内容不好，只能凭经验写个大概脚本然后开播。所以前期直播时，及时复盘并优化内容很重要。每场直播结束，重点看直播曲线，分析哪里吸引人——“讲这个内容时观众都不走了”，哪里不吸引人——“讲这个内容时大量离开”。怎么找呢？看直播流速曲线图，打开推流曲线和离开曲线，寻找推流曲线持续高于离开曲线的部分，说明这段内容或话题非常吸引人，大家都愿意多看；离开曲线突然急速猛增的部分，说明这里大家都不想停，一下子都走了。

[PRE5]

每场直播分析出哪里留人、哪里掉人，后面直播时就可以针对性优化。掉人的内容，优化结构或者做钩子前置；留人的内容，继续丰富或者做干货后置。几场之后，直播内容就会变得非常能打。

# 2.4 把直播流量导入私域

# 💡 本章导读

现阶段平台对知识付费类直播间和AI赛道的管控都比较严格，把商品或服务直接上架到后台售卖的难度较大，比较建议大家把用户引流到私域进行转化。但在公域平台做私域导流同样容易违规。常见的私域引流方法有几种：一是在简介留微信；二是在直播间直接用话术或画面引导；三是先转化到平台自有粉丝群，再二次导流；四是使用官方引流组件。其中第4种最稳妥，但一般需要付费投流才可以使用。手册会根据抖音和视频号两大平台的特性，重点讲解其他三种方法。

# 2.4.1 抖音直播怎么引私域

抖音直播引流的两种推荐方式：一个是简介留联系方式，一个是引导到粉丝群后再引到私域。

简介留联系方式：部分账号可以在个人简介里直接添加微信号，但不能用过于直白的引导，比如“微信：xxxx”“🌏号：xxxx”等，很容易被系统检测屏蔽，或者被举报后违规。可以更委婉地表达，比如“合作xxxx”“交个朋友xxx”；也可以直接把微信号“xxx”放到最后一行，直播时引导“想链接我的可以看我主页简介最后一行”。

引导到粉丝群再引导私域：这是目前抖音上最建议的引流方法，也是我们主要用的方式。粉丝群引流分两步：第一步，在直播间引导观众加粉丝群；第二步，在粉丝群里告知客户如何加私域。在直播间引导客户加粉丝群时，不建议用话术直接诱导，很容易触发话术检测违规。比较好的方式是打印一张A4纸或KT板，上面手写“领资料（换行）加fen丝群”之类内容，正常观众一看就明白，但AI不好判断含义；准备引流时直接拿出牌子，用手指即可。也可以由运营使用小号在评论区做话术引导，这样直播号不会被处罚。客户引流到粉丝群后，引流私域的话术处理不当仍然很容易违规。粉丝群引流常见方法有：运营小号发微信号、使用不容易被检测到的图片发微信号等。我们目前用得比较多的是主播在粉丝群里发语音直接引导，这样有效易懂，也不会被检测到。

# 2.4.2 视频号直播怎么引流

视频号引流的两种常见方法：一个是简介留联系方式，一个是直播间直接引导。简介留联系方式的方法同抖音，不再赘述。需要注意的是，视频号目前对个人简介的检查比较严格。之前我们的直播账号被判“医疗引流”，封禁3天，但直播间并没有说违规内容，前后排查很久，才找到原因是简介里有“需要直播食谱可以私信我”，问题就在“私信”两个字。所以在个人简介中一定注意，不要出现明显的引导词。
