# 1.3.2 航海教编程，为什么从 AI 切入？

先聊一位圈友的分享，标题是《一个人可以不依赖于别人，创造出一些新东西，这是真正快乐的来源》。

发帖的人正是我们的星主龙哥。他原本完全不懂技术，靠着 AI 生成代码、自己边看边学，只用了一个晚上就写出了网站爬虫。对非技术背景的普通人来说，这样的时刻称得上里程碑。

互联网越普及，普通人越需要懂一点编程，才能更好地驾驭 AI、融入数字化社会。但编程向来难学，很多人还没开始就退缩了。好在 AI 能帮我们跨过这道坎，甚至直接替我们写出代码——这正是航海项目叫“AI 编程”的原因。

有一点要注意：AI 给出来的代码，并不能在 AI 界面上直接运行。想让代码跑起来，得先装好运行环境和相关工具。这便是航海手册【第二章：应用工具准备】的任务——手把手带大家配好 AI 工具、Python 环境和代码编辑工具，为后续动手打底。

同时，读懂 AI 写的代码也需要一点基础。如果完全没有概念，AI 写出来的东西在你眼里就是天书。所以【第三章：借助 AI 掌握编程基础知识】会陪大家从零开始，搞懂怎么学编程、Python 基础语法、编程思维，完整理解产品代码的逻辑，以及如何用 AI 修 Bug。

这些基础内容学起来枯燥，但它们是编程思维的直接体现：严谨、自动化、批量化。也正是在这里，提示词的用法会被反复操练。没有这层底子，后面想让 AI 帮我们写产品代码，基本无从谈起。

# 1.4 给 AI 编程学习者的几点建议

# 1.4.1 多数问题，源于没把手册读细

航海过程中，手册一定要认真看。手册里的每句话、每张配图、每段视频，以及每一次高手领航，都值得反复看、反复练。做到这一点，跑通全部案例基本不是问题。

# 1.4.2 所有问题，先试着交给 AI

遇到问题别急着找人帮忙，先试试问 ChatGPT。让 AI 帮你排查和解决，它才是我们最强竞争力。这次航海同样要靠 AI 辅助学编程、学爬虫，学会把 AI 用起来。

# 1.4.3 AI 能降低门槛，但门槛仍然存在

编程本身就有门槛，AI 只是把它压低，而不是直接抹平。ChatGPT 的特点是：你强它也强，你弱它也弱。它能不能帮你学习和创造更多价值，关键还是看你对知识的理解程度。

刚接触编程的人往往没有概念，这很正常。认真读手册，先建立基本认知，再让 AI 带我们深入。这样你只会越来越强，用 AI 也会越来越顺手。

# 1.4.4 遇到问题别怕，那恰恰是成长机会

不要一碰到问题就想放弃，更别拿“技术太难”当逃避理由。成长需要探索精神，也需要解决问题的能力，而编程正好是很好的试金石。

赚钱也是一样：路上遇到点波折就撤退，怎么可能赚到钱？真正让人变优秀的，是持续解决问题的过程。优秀的人，学习能力和解决问题的能力都很强，而这些能力全靠后天锻炼出来。

# 1.4.5 保持利他精神，路会越走越宽

先跑通的圈友，拉一把那些非技术出身、学得吃力的同伴。航海里也有不少程序员，别错过展示自己、连接他人的机会。

你在帮别人的同时，也在成就自己。利他便是利己，说不定你的事业合伙人、人生贵人，就在这些人里出现。

# 2.1 出发前要准备什么？@乔帮主

1. 备好 AI 大模型。

大模型是整条学习路径的核心，它可以帮我们降低编程难度，也能直接产出爬虫代码。建议用 ChatGPT-4o 或 Claude 3.5 来跑实战案例，国内的大模型暂时还带不动这些案例。

2. 装好并配置 Python。

装 Python 是为了在本地运行和测试 AI 生成的代码。AI 出的代码没法在 AI 页面直接执行，必须放到独立环境里跑。装完后还需要配置环境，比如把 Python 加入系统 PATH、安装必要的依赖库，确保它能正常使用。

3. 安装代码编辑器。

代码编辑器是写 Python 的工具，程序员基本天天用。AI 生成的代码可以放进去直接跑，也可以改来改去。编辑器带代码高亮、语法提示，还支持各种插件，写代码和调试的效率会明显提升。

4. 配置产品工具代码环境。

后面做产品工具时，代码运行还需要 Python 相关的依赖库或插件来支撑。这部分会在项目实战章节详细讲解。
