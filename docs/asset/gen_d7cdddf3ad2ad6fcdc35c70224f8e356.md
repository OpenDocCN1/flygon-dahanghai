# 2.4.2 怎样判断对标账号是否适合自己

找参考对象时必须学会筛选，别一看到明星或 KOL 就急着照搬，并不是每位博主都值得你模仿。可以从下面几个维度来判断：

1）类目定位

先看对方所在的细分领域跟你是否一致或接近。比如穿搭博主去对标美食博主，显然不太合适。小众赛道往往很难找到完全同类的账号，这种情况下可以参考领域相近的类目博主。

2）变现模式（变现效率、变现空间、你是否有能力或潜力做到）

纯博主和精准引流博主的内容规划与侧重点并不一样，因此找对标时要研究对方的变现方式：是接广告，还是往私域引流带货、卖课程？这套模式跟你现在或未来的变现路径像不像？

3）粉丝级别（近期涨粉快的；或者本身粉丝不少，腰部比头部更值得对标）

看粉丝量时，别选太少也别选太多，尽量挑近期涨粉快或起号迅速的账号。对小红书新手而言，腰部博主（粉丝 10 万+）通常比头部大博主（粉丝 50 万+）和明星博主更值得参考。头部账号大多签在 MCN 旗下，有团队一起包装，个人很难复制到同样的高度。

4）IP 内容调性

筛选时快速浏览对方主页，判断其内容调性跟你的 IP 是否吻合，以及你有没有能力模仿并输出类似内容。难度过高、难以模仿的，可以直接放弃。

5）点赞比例 @星月

单篇笔记的点赞数比总粉丝数还多，这种笔记更值得借鉴。并非点赞越高就代表笔记越好，粉丝量高的账号会把笔记数据一起拉高。

刷对标时，多留意点赞量看起来没那么夸张的笔记（100—1000），一定要点进主页看看账号粉丝量，而不是只盯着点赞 5k、1w 的笔记。很多笔记有 5000、1w 点赞，但账号粉丝只有 8w、10w，这种数据的参考意义并不大。

把这些低粉高赞的笔记收藏起来，或者专门建一个自己的选题库，它们都是源源不断的爆款素材。

6）一个账号有多篇爆款 @星月

大家都知道，爆款有偶然性。

一个账号只出一个爆款，可能只是运气好，还不足以判断它是否值得对标。但如果持续出现爆款，就说明它身上有“爆款基因”，可能是封面，也可能是选题。

7）时间距离 @星月

借鉴最近一个月做起来的笔记或账号，会更有意义。

这就涉及“热度”了。在自媒体平台，热度比什么都重要。你会发现冬天搜羽绒服的人多，情人节搜礼物的人多，最近甲流、感冒药的热度也高。

不同时间段的热门词并不一样，所以要找最近、最热的账号或笔记来做对标。值得一提的是，不同关键词除了市场反应不同，平台在分配热度时也会有些随机偏爱。我们需要关注最近火起来的内容，尽量迎合平台的推流。

1 个月只是大概范围，并非绝对标准，原则是最好近期爆发起来。一周内最好，如果是 3 天内那就更妙了，还带着热度呢！

# 2.5 账号包装

账号包装相当于开店前的门面布置，这是粉丝对你的第一印象。

一个用户选择关注一个博主，往往不会只因为一篇优质笔记就下单关注。用户会看博主的主页，查看昵称、头像、个人简介、背景图以及之前发布的笔记，然后再决定是否关注。

另外，对我们博主来说，完善账号信息还能提升账号权重。

因为账号信息越完善，越有助于平台给账号贴标签。有标签的账号，发布的笔记获得的流量更加精准；流量精准后，更多用户会点开笔记，浏览量等数据会大幅提升，随之而来的就是账号权重越来越高。

如何进行账号包装呢？参考前面找到的对标账号，根据领域进行修改，塑造领域人设。

# 2.5.1 头像怎么选

不要太花哨，选择符合账号定位的。

制作方式：可以使用图怪兽等网站来制作图片，将满意的图片作为头像；也可以找一些无版权图片：

图怪兽：https://818ps.com/

可画：https://canva.com/

创客贴：https://www.chuangkit.com/

⚠️注意事项：注意避免使用容易侵权的商标类图片。

# 2.5.2 昵称怎么起

要有辨识度、好记、有趣，名字里带领域关键词，能更有辨识度和真实可信感。不要用复杂符号或特殊语言。

比如美食领域，名字叫“小溪教你做美食”，一眼就让粉丝知道这个账号是做什么的。

有以下 4 种公式可作参考：

昵称 + 个性：大鹅的七七八八

昵称 + 地区：姚老板在北京

昵称 + 专业：跟着拆哥看房

昵称 + 价值观：阿鱼爱学习

# 2.5.3 简介怎么写

简介主要告诉粉丝：关注你的账号能带来什么。比如穿搭领域，“小个子穿搭分享|感谢喜欢”。

一个写简介的公式：

你是谁

你做过什么牛逼的事（如无可不写）

关注你有什么好处，或者分享哪些领域的内容

有的账号出了上万点赞的爆款，但粉丝只有 100 个，主要原因是账号内容不垂直，且个人简介没有写好，没有给粉丝关注的理由。

所以，写简介时千万不要谦虚。如果你不能展现出可以给粉丝提供的价值，他们凭什么关注你呢？

# 3.3 检查笔记内容，避免违规 @周恩俊 @吴小二

完成笔记后，我们可以检查一下笔记内容，避免违规，影响流量。

# 3.3.1 常见违规类型

一般来说，视频违规的原因基本都是二创去重不彻底，触发了系统的笔记违规、笔记优化提示，需要进行整改，才会继续推流。这种常见违规偶尔一两次问题不大，但如果经常违规，就会导致专业号掉灰，这样后续就入驻不了蒲公英，也接不了广告，会比较麻烦。

图文虽然不容易出现去重不彻底的问题，因为图片都是用新模板去套，只是参考爆款内容，所以相对来讲比较安全。

但有些图文赛道也容易违规，比如情感、正能量、星座等赛道。有些朋友会因为某些敏感词导致违规，比如出现负能量传播、情绪价值偏激、封建迷信等违规。一般出现这种违规，系统会提示你怎么整改，按要求整改即可，整改完基本就没什么影响了。

接下来我们具体看看，后台会收到哪些违规提示？如何处理？

情况一：搬运抄袭

这是大部分人会出现的问题，因为二创没有到位，导致同质化内容多，被平台检测出来；

加大二创程度，最好的方法就是文字二创，图片替换模板，视频打乱顺序，多个片段混剪。

情况二：引流违规

很多人觉得笔记没发引流内容就没事，但有时候会有粉丝私聊问链接、问微信，这种千万不能发，一旦发了，会被判定站外导流；

可以直接忽略此类消息，必要时候也可以拿小号去回复。

情况三：数据异常

有时候被粉丝连续点赞收藏，也会被平台判定为互动异常，这个时候可以在主页简介备注“请勿连赞”，或者在笔记/评论区中提示；

其次不能为了快速涨粉，或者笔记数据好，去刷数据，这是属于作弊行为，严重会直接封号，得不偿失。

情况四：内容涉及低俗/不宜未成年
