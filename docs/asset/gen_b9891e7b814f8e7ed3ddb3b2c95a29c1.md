# 章节概要

到这里，选品和内容发布都已经完成了，那怎么判断选的品到底行不行？

对大多数新手来说，你很难预估一个品的效果，前期可以多发一些流量视频，等视频爆了再去挂商品测品。如果带货视频爆了，记得马上开直播，转化率会大大提高。

本章整理了几种高效的测品方式，大家按需选择。

建议重点关注：

✅交叉测品法：既能对比多个账号的优劣，也能同时判断多款产品的受众情况，再用结果去优化产品素材和视频细节。

其他测品法按需使用：

✅集中测品法：每个品类每天 10 条视频发在同一个号。

✅分布式测品法：定了人群但没定品类时，先同时发布不同品类的视频，哪个爆了继续发，其他删掉。

✅暴力测品法：把对标视频直接拿来发，3 天 0 播放就换品，爆了就马上精耕细作。

✅带货 / 流量视频比例：按一定比例交替发带货视频和内容流量视频。

✅137 法则：看第 1、3、7 天的账号数据，哪个环节出问题就果断放弃该品。

# 4.2 高效测品

# 4.2.1 交叉测品法 @李诚

大多数新手根本不知道一个品到底行不行，前期可以多发流量视频，视频爆了再测品。

交叉测品是我用过之后觉得效率最高、出结果也快的方法，推荐新手以它为主去测品。

拿 3 个账号举例，方便大家理解交叉测品的逻辑。如果账号少、视频量也少，把测试时间同步拉长就行。比如每天发 6 条视频需要测 3 天，每天发 4 条就要测 5 天。

3 个账号测 3 个商品的玩法：

每个账号每天发 2+1，也就是 2 条流量视频 +1 条带货硬视频，精力够的话就发 2 组（2 条流量视频 +1 条带货硬视频）

把测试账号的基础播放和视频基础播放记下来，两个账号同步对比，反馈数据结果。

举例：

A 账号：X 产品 2 条流量视频 +1 条带货视频，Y 产品 2 条流量视频 +1 条带货视频，持续观察三天

B 账号：Y 产品 2 条流量视频 +1 条带货视频，Z 产品 2 条流量视频 +1 条带货视频，持续观察三天

C 账号：Z 产品 2 条流量视频 +1 条带货视频，X 产品 2 条流量视频 +1 条带货视频，持续观察三天

通过 3 个账号 3 天的数据，能同时看出 ABC 三个账号哪个更强，XYZ 产品里哪个受众更广，接着再去优化产品素材和视频细节。

如果带货视频爆了，立刻开直播，很容易放大成交。

直播技巧看【章节 6.1 开启直播带货】

# 4.2.2 其他测品法 @兰心

# 4.2.2.1 集中测品法

假设你有 5 个号，也选了 5 个品类，可以每个品类每天在一个号上发 10 条视频，同时测品。

举例：每个品类搬 10 条视频，一共 50 条。5 个品类各挑 2 条发到 5 个不同的号上，哪一条爆了，就把这个号定为这个品类的垂直号，接着发该品类视频，其他 4 个号继续测。如果第一天 50 条发完没动静，就继续每天 50 条，连测 2-3 天。

# 4.2.2.2 分布式测品法

人群已经确定，但品类没定，可以同时发不同品类的视频，哪个爆了继续发，其他的删掉。

账号不多，又纠结做好几个品类拿不准时，可以同时发不同品类的素材，哪个爆了追哪个，剩下的直接删。

举例：你想做宝妈市场，但在育儿书籍、育儿好物、婴儿服饰之间摇摆不定，而且三个品类的视频都找好了，那就三个一起发，哪个先爆做哪个。

# 4.2.2.3 暴力测品法

拿对标视频直接搬运发布，3 天 0 播就换，爆了马上精耕细作。这种玩法适合号多的人，不做去重确实是爆款概率低，但省下来的时间能多养几个账号。

# 4.2.2.4 带货 / 流量视频比例

有人说七三，有人说五五。

其实没有绝对固定的比例，更多是看账号本身状态和你自己的选品经验。比如账号很多，那就按不同比例去编组，哪种效率高就怼哪种。如果选品很有把握，就多发带货视频，夹带一两条流量视频。

如果还不清楚品到底行不行，前期多放流量视频，爆了再测品。

4.2.2.5 137 法则

第 1 天：破了 300 播放，账号正常、视频正常，继续。

第 3 天：还能破 300 播放，一切正常就继续。没破的话，可以考虑换对标视频，原来的隐藏。也可以拍一段窗外的风景配个音乐发出去，看看有没有播放——有播放说明号没问题，是去重做得不够。

第 7 天：去重没问题但视频上不了推荐，直接注销重来。反复循环，直到每个号都稳定播放、稳定出单。

先搞懂平台推流机制，做起事来才更有方向和依据。视频号直播带货，除了关注人气数据，更要看成交数据、公私域流量。

这些指标能让账号在短视频平台增加影响力、提升人气和直播质量，从而更顺畅地推广产品。不过要注意，平台的政策和算法可能会变，多了解最新规则和趋势才能跟上节奏。

# 5.1.1.1 人气权重

1、曝光进入率

这个指标就是观众通过平台的曝光渠道点进直播间的比例，也就是进入直播间人数/平台曝光给用户的总人数。

直播间在曝光时展示给用户的内容，通常是标题、封面和直播画面；

用户在视频号信息流里上下滑时，影响进入率的主要是标题+直播画面+此刻主播的话术；

在直播广场上下刷时，影响进入率的主要是封面+直播画面；

这些元素会决定观众是否点进来，用这个比率能判断有多少看到直播间的人真正进入了。
