## 3.3 分成计划被取消后，怎么恢复？ @郭耀天

分成计划设立的初衷，是鼓励创作者持续输出优质、原创的内容。如果内容达不到平台要求，可能会先被要求整改，甚至被取消权益。

如果你收到的是“内容整改通知”：需要你先发布至少10条平台认可的优质原创内容，发布完成后平台会帮你恢复权益；如果已经发满10条，耐心等待审核即可，审核结果会通过「视频号团队消息」推送到你这里。

如果你收到的是“权益取消通知”：要是因为发布了非原创、非优质内容，或者内容方向发生偏离导致取消，你只要继续坚持发布原创优质视频，满足要求后权益就会重新激活，到时可以通过邀请私信申请加入。

如果是因为视频号认证身份信息发生变化导致取消，那么可以去修改认证信息，符合条件后权益会自动恢复，之后再申请加入就可以。

如果你觉得平台的违规判定有问题，也可以申诉：

假如是内容整改审核没过，或者因为发表非原创、非优质内容导致权益被取消，可以在通知页面底部找到「申诉」入口，提交相关证明材料。

### 4.1.1 抓住收益关键点 @白丁

视频号分成计划是一个特别吃赛道的项目。分成收益都藏在评论里，评论的点击量基本决定了这条视频能赚多少钱。

所以，视频号分成计划的赚钱核心逻辑就是：内容 + 评论。

评论点击量很难人为干预，贸然去操作数据，很容易吃违规，甚至被限流。

我们继续看怎么提高收益。先看两张图：

这两张都是已经开通分成计划的账号，但为什么第一张没广告，第二张有广告？

前面提过，分成计划的收益来自第三到五条任意位置的卡片广告——但这说的是评论较多的情况。如果评论数量少，只要凑够两条评论，广告就会出现了。所以，只有一条评论根本不够引出广告。

这里就有一个小技巧：发布完视频后，先用主号或小号去评论一条，这样就降低了流量收益的损失。

只靠这一条评论技巧，就能提高至少20%的收益。

现在网民已经形成了评论文化，看到有人评论，总忍不住点进去看看。如果你的评论做得好，还能引导更多人跟评。评论越多，对内容的加热就越有帮助。

其他数据就不要再去干预了。接着看内容。

内容 = 视频素材 + 文案。

一条视频能不能爆，和视频素材有非常直接的关系。这就需要我们有网感，知道怎样的话题会引发爆点。这也是一种技能。我一直觉得，一个项目能不能赚钱，和技能有关。技能到位了，刚好碰上合适的项目，钱自然就赚到了。

网感不是天生的，完全可以通过训练来提高。最好的方法就是拆解同行：把同行的爆款素材下载下来做档案，列出爆款原因。当你分析大量素材后会发现，很多爆款背后的因素高度相似。这就是规律。知道爆点在哪里，做内容时朝这个方向使劲，坚持一段时间后就会发现，做出爆款简直太简单了。

另一个关键点是文案。视频号对文案要求非常高。大家可以用“开头固定钩子 + 补充完整内容”的方式来写稿，这样重复度很低，平台接受度也高。

在视频号，你只要有爆款网感，再加上好文案，想不爆都难。

方向和方式确定后，赚钱最关键的就是执行，雷打不动地更新。账号80%的收益都来自20%的视频。只要方向对了，坚持更新总会爆。视频号爆一次，就是上千的收益。

### 4.1.2 为什么收益总比别人少？ @郭耀天

很多伙伴会问，自己的收益为什么和别人不一样。想搞清楚这个问题，先要知道钱是从哪来的。这笔收益不是腾讯给的，而是商家在视频号评论区投放广告，商家把钱给到平台，平台再根据你的账号流量和点击来结算。

既然钱不是平台出的，那收益高低就很好理解了：大家选择的领域不同，广告点击价格也不一样。

比如，某个领域的广告主比较多、预算充足，收益自然更高。而且广告是智能匹配的，如果给你匹配的广告单价很低，你拿到的收益就会比较少。

另一种情况是，你的视频刚好在某个时间段火了，但商家的预算不足、投放也不足，没有足够的广告可匹配，这时你的收益同样会低。

关于收益高低，我们其实是没法干预的。唯一能做的就是多做视频，视频火了收益自然就高了。或者选择财经、美容、酒类这些“有金主”的高质量领域。如果做的是泛娱乐，收益就会相对低一些。

### 4.1.3 提高收益的三种方法 @郭耀天 @思蒙

**方法一：选择年轻人多的赛道**

已经开通分成计划的伙伴，有人觉得收益太低，这很正常，因为目前视频号分成计划还没有完全爆发。如果你细心观察，会发现现在的广告大部分是游戏广告，或者是腾讯自家的广告、网剧广告。

比如很多人选择做祝福、早安类的视频，这类内容转发量很大，但用户大多数是老年人。广告主不太会投这些领域，因为老人不是他们的目标用户，所以收入自然就低了。

如果想提高收益，可以选年轻人相对多的赛道，比如科技、娱乐、情感。年轻人多，广告费也会高很多。

**方法二：提高视频互动性**

目前视频号分成计划的收益来自评论内广告，所以第一要务是把内容做好，让内容爆火，引发传播和转发，这样才会带来更多评论。

第二个是可以引导用户去评论，或者自己先评论几条、用小号评论几条，让广告早点出现。否则要等评论凑到一定数量，广告才会展示。目前需要有两条以上评论，广告才会出现。

另外，我们制作的内容最好有较强的互动属性，这样才能吸引大家关注和参与。

比如找图中的人物、找图中的动物、问答题，这类内容都很不错。有时还需要在视频里做一些引导，让大家一起参与进来，这样收益才会更高。

举个例子，有位伙伴做的是“一张图里找头像”，用户看完后会在评论区打出答案；还有的做语录视频，问观众“这句话说得对吗？请把答案打在评论区”。

这些技巧需要多研究、多操作，慢慢就会有体会。

**方法三：提升内容创作效率，用跑量放大收益**

对于门槛比较低的项目，比如「视频号创作者分成」，本质上就是用数量博概率的游戏。

所以，能多发作品就多发作品，能多起账号就多起账号。

在航海过程中你会发现，有些小伙伴的视频和你差不多，甚至算不上多优秀，但人家的账号就是爆了。这就是概率问题。

在搞定选赛道和视频制作技巧后，剩下的就是拼【量】。

发一条视频，爆的概率是1%；发10条，或者用10个账号发，每一条都是1%，加在一起，能爆的概率不就大多了？

为了能更好地搏量，大家要在实操中不断提高创作效率。不管是更快找素材、更快写文案，还是更快剪视频，都是熟能生巧的事，多练练就会进步。

## 4.3 账号与内容如何运营得更好 @郭耀天

**获得关注的技巧**

浏览者更愿意关注内容真诚、能带来良好体验的视频号。如果你想获得更多人关注，可以参考以下技巧：

1）定位清晰，塑造个人风格，坚持原创

3）积极和浏览者互动，提升用户的观看体验

**内容上热门的技巧**

通常，画面清晰、内容完整的原创内容会更受🛰️用户欢迎，也更容易出现在热门页。

1）发布原创内容，避免搬运他人创作；

2）视频内容、封面尽量清晰，不要出现拉伸、黑边、卡顿，也不要过度使用马赛克和虚化效果；

3）视频有字幕的话要完整展示，裁切时注意别遮挡；

4）内容完整、表达清晰，可以用配音解说，方便浏览者理解；

5）内容健康，避免低俗擦边内容和争议内容。

## 4.4 常见问题与应对方法 @郭耀天

以下是做项目过程中比较容易遇到的共性问题，整理了一些经验给大家。

**问题一：怎么防止掉广告？**

操作视频号分成计划时，你会发现，即使是爆款的纯原创视频也会掉广告。通俗说，就是评论区没有广告可匹配，特别是一些几百万、上千万播放的视频也会这样。

分享一些伙伴们测试出来的方法，不一定百分百有效，但有一些道理。很多人做视频都用剪映，其实视频号官方也有一个剪辑工具，叫“秒剪”（官网：https://miaojian.weixin.qq.com/）。用秒剪剪辑视频，流量有概率会高一点。

第一种方法：

从剪映导出后，直接放到秒剪里过一遍，再导出。

第二种方法：

把剪好的视频导入秒剪，随便过一遍滤镜，然后把画质颜色调到10以下。我常用的参数是5。

第三种方法：

导入视频后，过一下秒剪里的模板，模板选“治愈调节”。治愈调节自带音乐和滤镜，然后把原音打开。它自带的滤镜叫“橘子海”，把橘子海的参数调到10。

第四种方法：

用秒剪的橘子海滤镜，参数调到10，再调整：亮度3、对比度4、饱和度4、色温5，这四个参数都不要超过5；暗角9，不要超过10；锐化14，不要超过15；贴纸3~4个，再加2个个性文字。

另外，建议大家不要用WiFi发布作品，可以用4G。WiFi涉及的区域比较小，4G发布的区域会更广。

[PRE11]

**问题二：为什么「参与收益中的视频」数量显示为0？**

加入计划、发表视频并声明原创后，为什么“参与收益中的视频”数量是0？

这个专区统计的是账号在过去7天内真正产生过收益的视频。如果显示为0，可能有这几种情况：

1. 该账号发布的视频，评论区没有展示广告；

2. 该账号发布的视频近7天没有实际产生广告收益。创作者可以继续发布优质原创视频，等视频产生收益后，就会显示在“参与收益中的视频”专区；

3. 该账号正处于内容整改期，或者创作分成计划权益已被取消，视频无法参与广告分成。

[PRE12]

**问题三：哪些视频不会被推荐？**

视频会不会被推荐，主要看视频质量、内容质量和精准关键词三个方面。

**视频质量低**

如果视频存在声画不同步、分辨率低、卡顿模糊、大面积无画面、剪辑混乱无逻辑等质量问题，简单说就是对用户观看不友好的视频，基本不会被推荐。

**内容质量差**

视频号对内容的要求有两条原则：热点性和价值性。

要追热点、有时效性，也要输出有价值的内容，这点和其他平台一样。如果发布的视频没有热点、没有争议、也没有传播价值，那你的账号就相当于“信息公开的朋友圈”，基于社交推荐机制，基本只能自己和部分好友看到，不会有流量推荐。

同时，如果内容同质化严重，或者旧闻已经过了时效，同样不会得到推荐。太多的低质量内容也不是平台想要的，自然不会被推荐。

**关键词关联弱**

视频号的推荐模型会根据视频内容、标题文案、话题标签、地理位置等关键词进行精准推荐。如果你发布的视频和关键词关联不大，同样得不到推荐。

[PRE13]

**问题四：加入创作分成计划会影响视频流量吗？**

完全不会。视频流量和视频内容质量、内容主题等因素有关；

广告只展示在视频评论区，不会影响视频本身。

[PRE14]

**问题五：加入创作分成计划后，广告会自动展示吗？**

申请加入分成计划后，创作者在发表视频时开启「原创声明」，该视频评论区下方就有机会展示广告，不需要创作者再做什么操作。

你可以在“创作者中心—创作者服务—创作分成计划—参与收益中的视频”中查看成功加入分成计划的视频。

[PRE15]

**问题六：为什么我的视频评论区没有展示广告？**

如果你没有加入创作分成计划，仅声明原创的视频，评论区是不会展示广告的。

加入分成计划后，发视频一定要点开原创声明按钮。发完以后自己马上评论一两句，广告很快就会出来。有评论才会有广告，一般有一条他人评论就会出来；自己再补一条评论，广告也就出来了。

如果你已经加入计划，也声明了原创，评论区还是没有广告，可能存在这几种情况：

1. 当前暂时没有广告能和你的视频匹配；

2. 视频属于暂不支持展示广告的类型，比如：

非公开浏览状态的视频

信息流广告 / 短视频商品分享 / 视频变现任务 / 互选平台等带有商业推广信息的视频内容

不符合《🛰️视频号运营规范》的视频

3. 该账号正处于内容整改期，或创作分成计划权益已被取消，视频无法参与分成。

[PRE16]

**问题七：发过其他视频的账号，怎么养号？**

可以直接拍随手拍视频，一直发。我们的老号这样操作也成功了。

如果实在担心，就把全部删掉，把不是原创的、不是同类的视频全部删除，持续更新随拍视频。如果更新了几十个还没有满足内容规范，就可以考虑把账号注销，再注册一个新号。

[PRE17]

**问题八：以前发的内容流量不好？改发这个会不会也没流量？**

可以先发几条随拍视频，看看有没有流量。如果有流量，可以直接开通分成计划。

如果没流量，就换个领域再测试。测试了好久还是没有流量，那就直接注销，重新起号操作。

[PRE18]

**问题九：满足条件开通了广告分成，以前的视频要不要删除？**

最好是删除，也可以选择隐藏，看你自己情况。

如果以前的视频也完全符合内容规范，质量高，而且是原创，那当然不用删。
