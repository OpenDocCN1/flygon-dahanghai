# 精华帖｜194 赞：没编程功底，新手也能靠 ChatGPT 把工具站做出来？

大家好，我是易焘。我的技术水平比较特殊：既不是完全不懂代码的纯小白，但也绝对算不上科班出身的专业程序员，顶多算是对技术和产品有点感觉的普通人。

今天想和大家聊聊，一个工具站领域的新手，是怎么在 ChatGPT 的帮助下，把一个英文工具站产品从构思一步步做成现实，并顺利上线的。

目前我的插件已经完成了 4 个版本的发布和迭代，每一次改进、每一段关键代码，背后都离不开 ChatGPT 的支撑。这件事本身说明了一个重要的可能：哪怕你缺乏扎实的开发功底，甚至几乎没有编程能力，借助 ChatGPT 的力量，同样可以上手编程，并把英文工具站产品落地。

那么，我们和 ChatGPT 一起，究竟能碰撞出什么样的未来？它又能为普通人打开怎样一扇门？……
