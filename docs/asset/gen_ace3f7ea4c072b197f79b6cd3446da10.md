# 10.6 上班带娃做博主，她的时间从哪来？

运营女超人子渝的日常，是工作、家庭、博主副业同时推进。她白天要上班，回家还要顾孩子，副业只能塞进两类时段：白天各种碎片时间，以及晚上下班后的9点到12点。

白天哪怕只有午休，甚至去洗手间的几分钟，她也会刷最新内容、捕捉灵感，顺手记下来。下班后把零散灵感整理成稿，周末再集中录制。她还报了两门学习班给自己充电，目的很明确：让内容表达更有感染力。上课和消化的时间，就安排在周末孩子去补习班、或者自己收拾房间的间隙。整体状态确实紧绷，但她把节奏跑通了。

她的时间管理主要靠两招：一是用SOP把重复动作流程化，二是花钱把基础工作外包。流程固定后，临时重新排计划、做安排的损耗会少很多，效率也就上来了。她会先搭好选题排期，趁周末和假期批量录制，素材存进百度网盘，之后再用碎片时间剪辑。

另一招是“用小钱换时间”。人忙，往往不是被大事压住，而是零碎事项太多；这些活其实可以交出去，把精力留给真正核心的部分。最近她请了小助手帮忙剪视频、做图文，自己只盯内容生产。收入会因此少一些，但她觉得，合理分工反而更容易长期坚持，也能把注意力放在内容和视频表现的打磨上——这正是在强化自己的核心能力。
