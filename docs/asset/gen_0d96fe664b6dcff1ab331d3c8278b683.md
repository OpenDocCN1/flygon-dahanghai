# 开干前，先备齐

真正进入实操之前，前期铺垫不能省。准备做得越充分，后面推进就越稳。重点包括：挑平台、搭账号、锁定可参考的对标账号、把账号包装做到位，以及坚持日常养号。

平台方面，抖音竞争最激烈，但转化表现也最突出；小红书则对新手更友好，上手门槛更低。因此这次航海会把重点放在抖音和小红书：讲清楚如何从零起号、持续做内容，并把小说推广这个项目真正跑通。

账号包装尤其值得多花心思。建议多拆解你的对标账号，把这几处细节补全并做好：✅账号资料 ✅头像 ✅账号名称 ✅简介 ✅背景图。它们不是一次设置就完事，而是在不断调整中持续优化。本章节也会带大家一起实践这些内容，希望给大家提供更多可参考的方向。

如果你已经有账号基础，这一章可以跳过，直接进入项目实操「四、确定小说与关键词」。若你正卡在账号环节，比如找不到合适的对标账号、包装总不到位、不清楚怎么养号，也不妨回头把本章节再复习一遍。

需要的话，现在就开启你的学习之旅吧～
