# 3.5 作品类型：权重怎么排？

先抛一个问题：如果只看作品类型、不看内容质量，下面六类作品的权重从高到低该怎么排？商品（团购）、直播间、小程序、视频合集、单个视频、图文。

[PRE0]

[PRE1]

结论先给：商品（团购）排第一，之后依次是直播间、小程序、视频合集、单个视频，图文排在最后；其中单个视频的权重大于或等于图文。换句话说，顺序就是：商品（团购）＞直播间＞小程序＞视频合集＞单个视频≥图文。

[PRE2]

为什么这样排？底层逻辑是：在守住用户体验底线的情况下，尽量把商业化做足。电商是抖音的核心业务，既能帮商家赚钱，也能给平台带来收入；而真正既能成交、又能挂推荐词的带货词并不多，所以只要具备卖货条件，就优先卖货。直播间同样能成交，还能把主播、商品和场景整合起来，实时互动、当场答疑，转化表现很突出。视频合集的权重按合集内全部视频的点赞、播放、评论、收藏等数据综合计算，自然高于单条视频。至于视频优先于图文，这一点大家基本都明白。
