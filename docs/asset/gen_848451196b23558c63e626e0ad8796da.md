# 先找长板，再谈竞争力

很高兴在“5月航海｜个人优势挖掘｜实战手册”与你相遇。接下来的学习里，我们会多次碰面。

在正式翻动手册前，先想清楚一件事：为什么要找到个人优势？

过去多数教育都在强调查漏补缺、门门全面发展。可现实往往相反：与其和短板较劲，不如把长板磨尖。不擅长的领域拼命追赶，可能只到60分；天生有感觉的领域稍微投入，就有机会做到95分。

真正让你站稳脚跟的，是核心竞争力。如何找到优势、精进优势，并把它变成核心竞争力，对每个人来说都不是选修，而是必修。这正是本期航海最核心的命题。

平时可以从自己做成过的事、反复出现的行为里捕捉优势线索；若借助测评工具，效率会高很多。我们因此选用了颗粒度较细、科学性较高的盖洛普优势识别器，帮大家更系统地挖掘优势。

通过这份手册，希望大家能认识盖洛普、初步读懂它，并借案例理解自身优势，用它处理一些现实困境。不过，盖洛普体系庞大，仅34项才干就能组合出上千种结果，所以别指望一份手册让你立刻吃透报告、一次性发现全部优势。

我们更建议把它当工具书来用：

- 完全没接触过盖洛普：从头读；
- 只想先了解：看「二、了解盖洛普测评」；
- 想分析自己的报告：看「三、如何看懂盖洛普报告」；
- 想看优势如何发挥：看「四、从实际应用看盖洛普」。

报告到手后，请按「三、如何看懂盖洛普报告」的流程，确认自己的优势维度，找到擅长才干与优势盲点。由于盖洛普内容多为英译中，不少表述不太好懂，我们用更通俗的语言重新解读了「3.4 了解 34 项基础才干」。

过往不少优势测评只给结果，却不教怎么用。因此，我们在「四、从实际应用看盖洛普」中放入几种经典场景，并拆成「应用方向」和「实操案例解读」两部分，供你参考。

手册末尾，「附录二：常见问题答疑」会回应航行中可能遇到的疑问；「附录三：优势&成长书单推荐」则列出相关书单，希望你在学有余力时读完1—2本，对个人成长会有更多帮助。

如果你刚接触盖洛普，想先做一次测试，可查阅「附录一：如何进行盖洛普测评」，这里需要支付410元购买测评码。

本期手册想传递一个概念：我们要用擅长的才干去突破弱点，也要相信同一个问题不止一种答案。交朋友并非只有一条路，把专业能力练扎实，同样能吸引大量同频的人。

过去我们常在无意识中调用才干，无论擅长与否，错误使用都可能让弱点暴露。当你足够了解自己的才干，它们会成为最好的武器；有意识地使用擅长部分，许多问题会迎刃而解。

航行结束后，这份手册依然可以作为你的实操教材。航行期间，我们也会邀请教练做多角度分享，回应大家可能遇到的各类问题，欢迎一起交流优势挖掘心得。

还有一点很关键：多问、多交流。手册覆盖不到的地方，别憋着，多提问，我们一起找到更多解法。

希望大家这次航行既能拿到成果，也能结识一群并肩的战友。
