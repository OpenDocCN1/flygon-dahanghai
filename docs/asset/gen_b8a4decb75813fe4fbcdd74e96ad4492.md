# 零基础航拍，怎样做出个人IP和副业收获

各位圈友，大家好，我是黄浩在观察。今年4月18日，我才成为生财有术的一员，平时喜欢摄影，目前在无人机航拍这块做出了一点小成绩：

- 有63件航拍作品登上本地官方媒体网站，其中40件获得置顶推荐，两次拿奖，累计浏览超过21万；
- 在航拍社区“天空之城”发起的“腾飞70年·换个角度看中国”活动里，每座城市只选出5位获奖作者，我同时拿到了优秀航拍地视频、图片两个奖项；
- 靠主动投稿，我成了视觉中国签约供稿人，也是720云VR全景签约供图作者。

今天想和大家聊聊：一个非摄影科班出身的IT男，怎么因为喜欢，从无人机航拍入门，半路出家摸索摄影，一步步做出自己的个人IP，并朝着职场与副业双丰收走。我会把自己实际有效的做法、真切踩过的坑，都摊开来分享。如果你也想打造个人IP，或者想学航拍内容制作，或许能从中得到一点参考。

这里要特别谢谢生财有术组织的小航海，让我有机会登上龙珠修行营这班车。沐文船长的价值拆解课，让我萌生了把航拍学习、投稿、参赛、扩大影响力这些经历整理成文的想法；也感谢老师帮我分析拆解经历，感谢志愿者经常提醒我上课、交作业，感谢一路支持我的朋友。
