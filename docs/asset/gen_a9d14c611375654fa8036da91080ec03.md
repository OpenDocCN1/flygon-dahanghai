# 企业能走多远，底层三件事说了算

文/茅矛

前些天，龙哥突然找到我，让我把在紫菜团队分享抖音带货经验与教训后、评论区里提到的“底层逻辑缺失”展开说说。说实话，加入赚钱后我心里一直有点忐忑：我在区域互联网摸爬滚打十几年，习惯的是慢功夫，赚快钱的办法见过不少，但企业能不能走得久、走得稳，靠的从来不是一两个突然冒出来的盈利项目。也正因如此，我总觉得自己和赚钱的交流节奏不太合拍，不知道能分享什么。

回到紫菜团队那场复盘。我之所以说营收会遮住很多底层问题，是因为账面有流水，不等于企业底子扎实。先看利润管理。有订单的时候，很多企业容易盲目：不细算成本，不估税负，不看应收应付，更忽略财务运作不规范带来的经营风险。

举个电商案例。某平台卖旅游卡，进货240元，售价300元，乍看每单赚60元。财务核算后直接跑到老板面前拍桌子：“这单做下来要赔。”为什么？售价300元，按13%的增值税算就是39元，只剩21元，还没算平台和人力成本；再算企业所得税、个人所得税，所剩无几。老板也纳闷：我明明只赚60元，为什么要交接近40元增值税？可如果和供应商在协议里约定“代收代付”，这60元/单的进利就可以定义为营销推广所得，按现代服务业常见标准6%征增值税，当时甚至还能享受小规模纳税人1%的优惠。税从39元降到0.6元，直接多出38.4元利润。所得税虽然免不了，但利润空间完全不一样了。

这还只是经营范围和税务筹划的一个角度。我在高维学堂听原永辉超市财务总监徐薇老师讲过，国内某知名办公用品品牌的财务团队——注意，是财务团队，不是采购团队——对供应链实时价格了如指掌，原材料在她们手里像期货市场一样操作，还会利用账期在应收应付上做文章。这个时间差能带来几倍于自有资金的运作能力，所谓钱生钱，在这里就是最好的案例。国内大超市、电器卖场，几乎都是同样的套路。

有些企业觉得自己已经够正规了，该开票的都开了，却在开销登记和凭证管理上不够重视。等到财务审查时，很多记账凭证缺失，无法有效证明真实办公开支，反而花了不少冤枉钱。比如某公司采购十来万元办公设备，为了不支付13%的增值税，没把票据留全。年底盘账时缺少支出凭证，最终公司按采购金额20%承担了企业所得税，算下来差不多2万元。明明花了十来万，就因为想省万把块税点，到头来多交2万元左右企业所得税，残酷不残酷？反过来，有些老板用公司名义购置车辆，不仅免掉相应购置税，还抵扣了同等金额的企业所得，平时车辆日常开销也能计入办公成本进行抵扣。这些都是合理的税务筹划，和会计带账做平收支完全不是一回事。

再把公司主体设定、政策、地方差异等条件结合起来，通过合理税务筹划，在1000万元营收的基础上，节税空间甚至能从小几万元做到上百万元。这年头挣百来万有多不容易？只要筹划得当，就能妥妥省出百来万。所以，财税规划和财务规范，是保障企业良性发展的第一要素。疫情那阵子，我听不少同行说，今年能不能活下去，就看账上有没有能发三个月工资的现金。可见利润管理只是财务管理里很小的一个点，真正把财务管理建设做透，企业的根基才会扎实。

第二块，是团队建设。紫菜团队发展势头正好的时候，和主播出现意见分歧，最后不得已分道扬镳，销量随即雪崩。表面看，是前期规则没定好导致人才流失；往深里看，它牵出的是企业人力资源的多重问题：人才从哪里来？选人的画像和模型怎么搭？新员工入职培训体系如何建立？不同工种的考核机制和绩效体系怎么设计？内部晋升通道和成长路径怎么铺？怎样加速团队内部的优胜劣汰，让整个组织保持战斗力和上升空间？又如何拓展企业边界，形成不断成长的团队梯队？

如果说资金是企业运转的保障，那么人才就是推动企业发展的动力。甚至可以这样理解：财务像燃油，人才像发动机，企业像那台车。但两者最大的区别在于，汽车的发动机出厂时就得配好，而企业的人才需要多种因素慢慢沉淀、长期培养。

赚钱里很多大神既是自己企业的灵魂，也常常成为企业做大做强的绊脚石。为什么？因为大多数人冲在业务一线，却忽略了企业本身的体系构架，其中造血能力是大多数企业的短板。缺乏造血能力，很多事情最后只能创始人亲力亲为：向上没法考虑更远、更长久的战略，向下没法打造强有力的团队，好比陷进泥潭拔不出来。我在很多咨询过的站点都提过这一点，希望创始人和站长能放下一些具体业务，把更多精力聚焦到企业人力资源上，至少在现阶段给予足够重视。这里必然有取舍：生存面前，业务为先；但当业务趋于稳定，进入喘息阶段时，是不是该把团队建设提上重要位置？

这两天我走了两个站点，都在考虑启动新项目。钱、资源可能都不是问题，没有团队才是最大的瓶颈，而这又回到前面那七个问题。它们环环相扣，各自独立又相互关联，对任何企业来说，都是一套庞大而漫长的体系构建。

第三块，是信息化建设。什么是企业的信息化建设？现金流、签约额、应收款、利润率、人均产值、薪资占比，这些是基于财务的重要信息；平台流量、指数、用户体量、外围资源，是评价一个区域互联网站点的参考指标。再拿招聘网站这个垂直业务来看，用户登录数、平台上可投递的岗位数、企业数量、每天新增简历数、投递数、新投递简历的查看率、简历完备度、销售跟进企业的密度和细节，这些信息都能很好衡量平台运营状况，有时还能从个别指数和细节里找到蛛丝马迹，去寻求改善和提高的关键点。

当管理逐渐分层，我们越来越需要各种信息过滤，来判断企业各部门、各项业务运转是否良性，并针对不同的人提供不同等级的综合信息。这是企业信息化管理的本质：通过信息流转加速各项事务的信息传递、状态判断，并引出管理层对关键决策的主动出击。各种信息经过整理向下释放，又是对团队的一种总结和促进。做得好，就加以总结，未来再接再厉；做得不好，就去找改善点、提高点，引以为戒，在今后的工作中降低无谓成本。信息公开化、透明化最大的价值，就在于拉通企业上下对整体战略和具体事务的信息归一，不会因为某种信息差产生目标上的差异。

是不是觉得很熟悉？OKR就是一种典型的信息串联。通过O与KR的上下传递，在组织中将公司的战略、目标拆解融会贯通，可以朝任何方向传递，让所有人理解公司整体战略，并在过程中不断修正、自我调整和迭代，从而实现企业的自我更新和发展。在很多大厂，OKR已经成为标配；OA系统打穿了公司各部门的联络和工作协同；CRM能直观地把所有客户的联系和维护无死角展示给管理者；各种系统的后台统计可以直观反馈部门的运转效率和结果产出；各类办公协同软件都在不同程度上尝试打通公司内部的交流盲区；财务软件则反馈出企业的运转良性程度，徐薇老师曾提出过“财务仪表盘”一说。这些都是企业在管理进化过程中信息化建设的各种形态。信息化建设既可以理解为各种工具的集合，从本质上更应该理解为一种管理理念和意识形态。

当今企业早就过了凭感觉发展的时代，一切都有原则，一切都有体系，一切都有底层逻辑。本文提到的三个方面，是我去年在徐薇老师财务课的企业战略地图中看到的三个支持层。徐薇老师提到企业管理有四个层级：战略层，指业务战略和经营规划；结构层，指组织结构和管理体系；运营层，指产品研发、营销销售、供应链、客户服务；支持层，就是财务管理、人力资源管理、信息化管理。我觉得大部分企业在战略层、组织层、运营层都很重视，而且做得不错，但最底层的支持层常常被忽略。这也是我看过紫菜团队复盘分享后，尤其感慨的原因。

收了钱，不代表你就有好的财务管理；看似有了一定规模的团队，不代表你具备自我造血的能力；缺了信息化管理，就会导致大量信息差，进而带来协作上的不融洽。这三个因素甚至还会相互影响。

举个场景，说明支持层的重要性和相互关联性。比如你要启动一个项目或者事业部，首先要考虑几个问题：谁来做这件事？需要组建多大的团队？团队未来增长的步调是怎样的？组建这样的团队需要多少成本？项目组的培育期预计多长？项目的关键节点和milestone评估如何设定？如何确保项目推进过程中的监督和关键矫正？项目的止损点如何把控？结合支持层的三个要素，无非就是解决团队、成本核算、风险把控，这恰恰是人力资源管理、财务管理、信息化管理各司其职的点。

有人可能会说，想这么复杂干什么，干就完了，以前没有这些东西不也干起来了吗？没错，支持层在早期并不是必需品，但野蛮生长的状态并不适用所有项目。当企业和项目发展到一定规模，人力的匮乏、信息的通达度、财务预算机制的保障，都会限制项目更进一步。

所以，企业的底层逻辑建设很容易被忽略。而在高速发展过程中，当支持层的重要度被慢慢意识到时，体系建设对大多数企业来说是极其痛苦又漫长的过程。尤其对早期已经习惯了爆发式增长的创业者来说，支持层这种精细、短期又难以见效的过程，真是折磨又纠结。可能只有少数看得更远的创业者，才会坚定不移地把这一块坚持下去。

这是我对于企业底层逻辑建设的一些观点和看法，欢迎各位指正和探讨。
