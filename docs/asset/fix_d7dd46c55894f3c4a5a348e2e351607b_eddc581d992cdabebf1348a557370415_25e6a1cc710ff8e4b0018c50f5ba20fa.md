观众刷到你的那一刻，先看到的是封面画面和封面上的字。它们决定了曝光之后有多少人愿意点进来，所以值得花时间打磨。最省力的做法，是找同行样本拆解借鉴。

拍摄时注意这几点：

1. 书要拍完整、拍清楚，精装书可以放在后面当背景；
2. 单本书从上往下拍，多本书从侧面拍；
3. 开播时手机画面往往偏大，用备用机看实际效果，再决定镜头远近要不要调；
4. 贴片文字照着销量好的场子做。

单品图书直播我们实战过很多场。这类场观众平均驻留约1分钟，话术不复杂，叫循环话术，正常讲2分钟左右走完一轮，开播后反复介绍图书即可。

低价书场：原价和现价的差距要讲透，强调今天优惠力度大、买到划算，差不多一半时间放在这里。

高价书场：多讲书的内容、稀缺性和库存有限，书本身的价值权重更高。

选品注意：在选品广场挑货时，优先选销量高、评分高的书商。盗版书一旦翻车，会拖累带货分；小书商售后也没保障，严重时可能连累橱窗被封。

挑商品别只盯高佣金，要看总销量和评分。微信小店评分分高中低三档，低分店铺尽量不挂，只带中高评分店铺，并优先上架销量高的店铺。

一、开播前要备齐的五件事

1. 把低价引流书、主推书、畅销高佣书加进橱窗，控制在480本以内，价格由低到高，2.9元起步。顺序排得好，进来的人更愿意停留，主推款放一号链接。
2. 把开播场景搭好。
3. 选品：录对标场半小时，重点听主推款怎么讲，那就是你的话术素材。
4. 主推款话术提前练熟，讲顺、不卡壳。
5. 加柔和纯音乐当背景，例如《痴情冢》《吟游诗人的诗歌》，开播时试一下音量，别盖过主播声音。

四、图书账号冷启动的几条路

一个健康的开播空间有自己的粉丝标签。播久了、有成交数据，标签自然形成。标签的作用是让系统知道你的场子能吸引哪类人，从而决定推哪类人群。图书类目冷启动打标签，大致有三条路：

1. 拉时长、拉场观，等系统把买书人群推进来，洗标签、洗人群。先用低价款做密集成交，再引导拍高价书，给账号打标签。
2. 在拉时长拉场观的基础上做付费加热，也就是微付费，加速标签定位，积累买书粉，缩短起号周期。前提是人货场及格，否则就是烧钱。新人建议先自然流播3到5场，每场都有成交，等人货场及格再考虑付费助力。记住：付费是锦上添花，不是雪中送炭。
3. 用短视频积累流量和粉丝。有短视频基础的人，可以发图书混剪或实拍口播，引导观众进间成交。

提醒：一切前提是把人货场做好。场景乱、画质糊、声音不清，观众看一眼就划走，再多技巧也难成交。开播先做浅层数据：停留、关注、互动、点赞、粉丝灯牌，同时把成交数据做好。平台有了这些信号，才知道该给你推什么人。

五、单品场付费加热起号指南

建议先播3到5场以上，等人货场及格再碰付费加热。前几场下播后及时看回放，分析自己的场子和对标同行的差距，调整优化后再结合付费，加快起号。

付费有风险，花钱要谨慎。它的作用是把高质量买书人群推进来，但能不能留住、能不能成交，取决于你的人货场、话术表达、主播情绪感染力和转化能力。所以，等人货场和话术都基本没问题了再尝试，否则容易浪费钱。

开播时先循环卖低价福利品，也就是两块钱左右一本的书，成交三五单后切到主推单品，一直讲到下播。浅层互动、停留、点赞、关注、粉丝灯牌仍要继续做，否则没有数据，可能出现微信豆烧不动、加热不消耗的情况。

# 5.2.1.2 模式二：主播露脸的多品循环场

这种模式是多品讲解、主播露脸、多套书循环讲，一般单场讲十套书循环即可。目前主要有三种场景：

第一种是绿幕场。绿幕能低成本搭出仓库、书架等背景，配合清仓话术、限时折扣和逼单话术提升转化。但平台偶尔会判违规，原因多半是抠像不清晰。手上有五个号以上的人，可以快速搭绿幕开播，尽快拿到正反馈。绿幕的好处是换场景成本低。

第二种是画布背景，第三种是实体搭建的真实书架场，这两种在场景本身上完全不违规。目前推荐先用背景布开播，等后期拿到结果，再考虑搭真实书架背景。

这种主播露脸模式属于多品循环场。开播前小黄车会挂400多款图书，视频号规则是小黄车上限500个品。目前以中医、国学、养生类，孩子课外书，以及热门经典书为主，也要及时跟进抖音爆款。书价从1.9元到499元不等，低价书用来做福利、做成交数据，也能吸引观众停留。

中等价位比如9.9到29元的书微利，29元以上的书佣金率相对可观。一场几小时的直播下来，各种书基本都会有成交，综合利润率在25%到30%左右。前期起号可以结合微付费或亏品卖书，账号稳定后投流费用不多，所以也可以看作净利润在30%左右。

开播前还要准备展示样品书，也就是下面图片前排那十几本，准备15到20本就够，照着图片挑选。后期开播几场、有销量后，微信小店客服会来找你带书，可以谈免费寄样，或者卖出多少单后返费用，所以后期基本不用自己花钱买样品。

对标场的书都是经过挑选的，录好屏后去微信小店上架。挑小店要有标准：第一店铺评分高，第二佣金率不错，优先规模大、销量高的后端小店。看同行带得好的店，也可以跟着上。尽量不要上刚开的后端图书货源，可以看小店总销量，低于5000单的店尽量别加。它可能是个体户一个人开的，你这边爆单了，它可能来不及发货；拖两三天到四五天不发货，顾客可能就退款，白白浪费成交。

销量高的后端售后通常更好，服务更有保障，也能降低被投诉的风险。上架时还要看小店评分，低评分店铺尽量不上。视频号小店评级分高中低三档，低分商品卖多了会影响达人评分。视频号对达人有综合评分，包括商品售后评价。橱窗评分是动态调整的，低于4.1分后直播间就不能投流，还会影响小店给你开图书定向高佣金。

后期上架时，可以在后台选平台近期热销的书。商品排序里有“热销优先”，再设定价格范围，就能看到近期平台热卖图书，想找哪个价位都能筛。

另一种选品方法是刷抖音，及时跟进爆款书。一般抖音热卖的书，一个月后视频号也会有一波流量，比如之前董宇辉推荐的《额尔古纳河右岸》，还有每年茅盾文学奖、诺贝尔文学奖相关热点书，评选后往往有不错的流量和销量，要跟上。另外，观众经常问想要的书，也说明是近期需求。下播后及时找后端小店要链接上架。

后期选品还要做一件事：每天花一小时左右刷视频号直播广场的高场观场子，看同行热卖什么书，及时跟进。同行近期卖得好、你还没有的书，要尽快补上。

刷到高场观同行时，还要仔细观察拆解他们的人货场，看哪些地方值得学，及时升级优化自己的场子，保持不被行业淘汰。逆水行舟，不进则退。

尤其要关注同行的贴图，也就是噱头文字。这一点很重要，也是视频号绿幕清仓类场子变动最快的地方，因为贴图文字会直接影响场观和停留。好的噱头能天然引发好奇，观众产生好奇才会停留，停留后才可能自主下单或听你讲解。

同时，视频号规则相对抖音更新较快，多看同行场子有助于及时发现直播动态和新变动，保持敏锐。

三、账号起号建议

目前主播露脸场起号有两种方法：微付费和福利品。我们现在以福利品起号为主，因为微付费如果没有好人货场承接不住。新人刚播，人货场都在练习期，优先选低价福利品起号，开播会更从容。亏品起号就是平台卖2.9或5.9的近期爆品书，你直播间卖1.9，每单亏1到4元左右。

一般新号准备四个通品书，就是原价3.9或2.9的书卖1.9，每个品准备50到100单。偶尔也能找到2.9卖1.9的品，这种相对少。

另外再准备一个价格竞争力很强的品，原价5.9卖1.9，一场准备20到40单即可。

正常来说，3到5场可以起号，稳定后就可以不卖或少卖亏品。

第一天怎么起？准备4个福利品，刚开播在线人数少的时候循环讲，一直讲到场观破2000。这时可以逐渐讲5.9、9.9、19.9的书，循环着讲。但讲非福利品时，1.9的福利品仍要挂在小黄车上，不要下架。这个品是给你留人的，场子里只有多成交，系统才会持续推流；没有成交，进人就少。

这是第一天开播的讲解流程。正常第一场4小时打底；如果进人一直不错，播6小时以上更好。我们也见过同行第一场就起飞、卖大几千GMV的，这种需要拉时长。有两个人手时，可以播七八个小时甚至十几个小时。单场成交订单越多，场观越大，越有助于账号打标签，第二场推流也会更大，人群相对更精准。

直播时如果有手机，准备两三台鱼塘手机进自己的场子。讲解需要互动时，用小号及时回应，带动氛围。
