# 5.1.2 线下接待，细节赢回头客 @Mage

夏天客人到店前，我会先开一到两小时空调，再把切好冰镇的西瓜摆上桌。从三十五六度的户外走进凉爽的别墅，桌上还有冰西瓜，体感与心情都会明显不同。

团建期间，我会顺手免费拍些照片和短片，活动结束后再发给他们。留宿客人则更留意夜间体验：提前调好热水，在客房插上驱蚊灯，每个房间再摆一束鲜花。重点都落在这些小地方。

这些安排多出来的开销其实有限，却能让客人的体验大不相同。客人离开后，我还会发一份满意度问卷，再按反馈及时调整服务方式与运营策略。

[PRE1]

客户运营方面，我会建微信群，把咨询过却还没下单的人先聚到群里。每天固定用红包打招呼，金额十到二十元，拆成二十到三十个；包数别设太多，不然多数人只能抢到几分钱，抢的动力不足，群就容易沉寂。

[PRE2]

之后每周挑一两次发出其他客人的团建视频，聚会和生日场景最常用；同时每周安排一场定时秒杀，多放在周三、周四，把尚未订出的档期拿出来做活动，价格通常是原价的五折到七点五折。

除了未成交客户，到店过的客人也会单独建群。这个群每周做一两次轻量触达就够，频率过高容易让人反感甚至退群。他们来过、也知道你的群就在聊天列表里，真有需要自然会先想到你。
