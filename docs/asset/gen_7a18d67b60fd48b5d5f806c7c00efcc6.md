# 从种草到成交：宠物单品月销300万复盘

如果你在淘系做生意，大概体会过这种无力感：预算一加，流量就来；预算一停，曲线就掉。直通车等付费工具花得不少，却很难留下持续增长。流量越来越贵，增长怎么破？

本期「生财合伙人」专栏，分享人@起醉 以自己操盘的宠物品牌为例，拆解了一条完整链路：在小红书、知乎做内容种草和口碑，借KOL、大V评测建立信任，再与达人、明星合作产出视频素材，剪辑后投到抖音做信息流，最终在天猫完成成交。单个产品一个月做到300万元销售额。他目前在一家宠物品牌电商部门做运营经理，负责的线上业务规模约2.3亿元。测试品牌从五六月启动，原先单月销售额300万元，到11月增至约1200万元。行业不同，但电商操盘思路可借鉴。

大家好，我加入生财社区快一年，平时多在看帖，也做过一些小项目，收获不小。社区里应该有不少宠物行业圈友。前些天鱼丸找到我，希望我聊聊宠物内容，于是结合自己的经历写了这篇分享，希望能带来一点启发。

先介绍自己：我在宠物行业一家品牌电商部门做运营经理，负责的线上模块约2.3亿元规模。从行业高速增长到遇到瓶颈，我一路看下来，最近才逐渐摸到一些新方向。

今天主要讲两块：

1. 我对宠物行业发展阶段的认识，以及对未来方向的判断；
2. 一个传统电商平台结合全域营销打造新宠物品牌的案例。

—Part 1—

## Part 1 宠物行业：流量、产品、内容三段并行

以我的观察，宠物行业大致有三个阶段：早期拼流量，后来拼产品，最近开始拼内容。三者并非完全割裂，而是同时存在。也有商家早已转向产品，深挖用户需求，洞察市场风向，用独家优质产品吸引顾客。

第一阶段：流量阶段

线上购物平台快速发展的节点，恰好与宠物行业高速增长重叠。线上红利叠加行业红利，最高年份年复合增速能到100%。到2015年，宠物行业复合增长率约50%，市场规模约700亿元；到去年，整个行业已到3000亿元级别。感兴趣可以查宠物行业白皮书，新版应该刚发布。

在那个背景下，宠物行业像站在风口上。和同行交流时，对方回忆：当时几乎上架产品就能卖。

可惜这种日子回不去了。即便到今天，不少商家的思维仍停在流量阶段，线上靠直通车、钻展、品销宝、超级推荐、万相台等付费工具砸爆款、带品牌，凯*思等几家比较有代表性。

第二阶段：产品阶段

市场规模还在涨，但50%以上的复合增长时代已经过去。疫情这几年更明显，行业增速降下来了，虽然仍在增长，实际已提前进入存量博弈。

流量有限，为了拿竞争优势，很多宠物商家回头重视产品品质。最明显的变化是，留心观察会发现国产宠物食品正在慢慢崛起。

宠物圈有个著名笑话：一些河北粮会在主粮里掺土卖。这也侧面说明野蛮生长年代，国内宠物食品品质有待提升。这个阶段跑出了一些相对优秀的品牌。整体看，目前行业仍处于第一、第二阶段。

第三阶段：内容阶段

产品品质在提升，销量却没有想象中美好。流量日渐枯竭，很多头部品牌陷入增长难题，尤其疫情以来的今年，我们也在逐步下滑。

总结行业里部分成功品牌的经验，我们大胆做了初步测试——不得不做——终于积累了一些对未来发展的心得：把资源压到内容侧，借助抖音、小红书等全域渠道推动品牌增长。这部分结合第二部分案例展开。

改变第一步：切换赛道

做电商的都知道，可以通过市场行情里的市场大盘看各类目成交与流量情况，再借助特定工具转化指数，算出类目大盘复合增长率和整体销售变动。我用小旺神：xiaowangshen.com/

结合行业分析报告，猫粮增速远高于狗粮，所以我们决定以猫粮作为新切入口。以前也知道，但难以下决心转型，毕竟这个品牌的狗粮业务一年也有上千万元。

举个例子：我用工具记录历年年中6月淘系平台的猫粮、狗粮成交数据并汇总。狗粮增长率逐渐降低，快低到10%；猫粮增长率仍在40%左右。2021年猫粮成交数据量太大，超过工具转化上限，只能猜测。结果一目了然。如果你是宠物行业从业者，还在死守犬品类，应该换换思路了。大家也可以用同样方式看市场增长，或根据月度销售确定营销节奏。

[PRE4]

改变第二步：打磨产品

这一步最需要关注。国内宠物行业仍处于群雄并起阶段，个人起订5吨左右就能定制品牌，原料配方可由代工厂提供，可能每天都有新品牌上线。所以你会发现，很多品牌的主粮差不多，无非内容物成分比例不同。今天你品牌蛋白含量20%，明天就有别的品牌做21%，不胜枚举。其他方面也大同小异，不像成熟类目那样围绕顾客痛点做针对性开发。

我们提前做了缜密调研，以发现真实需求痛点，主要有四个方向：

1. 电话调研。从品牌过往消费者中选人，分配给主管级别以上同事，每人20通电话，覆盖运营、产品、市场等多个部门。各岗位从自身视角设计专属问题，围绕产品价格、营销、适口性、耐口性，以及宠物主购粮最关注的点等维度，让一线同事切实理解顾客需求。
2. 线上问卷。设计整套调查问卷，委托第三方收集数据。
3. 邀请真实顾客共创。电话联系约100名真实消费者，为每人准备约百元宠物食品玩具礼包，邀请到公司开座谈会，深入探讨真实需求。
4. 竞品评价分析。这一步最简单：抓取竞品在天猫、京东等渠道的评价，从评价里提炼关键需求。

大约一个月后，最终确定现有产品。下一步是定价，需要缜密测算。每家公司实际情况不同，计算方式不同，但逻辑相通。

传统宠物行业主粮类目毛利率大概40%—55%。扣除成交平台扣点和中后台人工、物流等成本，产品综合毛利率至少要保证在65%以上，才有机会成功。否则没有足够利润支撑这件事。

电商从业者可能感触更深：平台扣点和活动综合费用约6%，推广费用约12%，仓储物流成本约15%，再加上人工等办公成本，其实50%毛利挣不了多少钱。

走完这两步，市场和产品都确定了。

改变第三步：营销推广引流获客

这块是我们重点改变的地方。我们属于淘品牌，更侧重淘内营销，早年黑车玩法玩得飞起；即使现在，我们在直通车、钻展、品销宝、超级推荐、万相台等渠道的费用占比也在12%以上。

但我们发现，最近两年花大功夫、大预算在淘内，很多都是无用功。一旦没有费用支撑，流量就逐渐萎缩。直到知道一组数据，才发现问题所在：淘宝日活约2000万，抖音日活却在6亿级别。虽然我们每天刷抖音，也常看到宠物内容，却忽视了这一大块市场。

以前其实关注过，但抖音投产比太低，ROI普遍在0.5以下。作为传统电商公司，ROI太低公司不会考虑，所以2019年投放测试后直接放弃了。现在想来，差点重演线下商家面对线上冲击时的老剧本：先轻视，再排斥，随后困惑，最终错过。幸好醒悟不算太晚。

明白问题后，我们对宠物行业新打法有了些想法。借鉴美妆等成熟行业案例，开始全域营销尝试。过程中犯了不少错误，但方向是对的：

通过小红书、知乎等内容分享渠道做种草和口碑宣传，借KOL和大V评测做信任背书，再与达人、明星合作产出优质视频素材，将素材剪辑后在抖音做信息流投放，最后在天猫渠道落地成交。

结果就是：单品月销300万元。

我复盘了几个关键动作，希望对大家有帮助。

1. 私域做部分基础销量和评价

我们有自己的私域池。前期产品开发调研时，很多真实顾客已经知道产品。我们邀请顾客下单，再全额返现，完成产品前期基础单量和评价。做得精细的话，可以让顾客从搜索入口进，前提是直接搜索标题或半标题。这属于传统电商领域的形式，类似黑搜螺旋，感兴趣可在社群里搜淘宝运营知识。

2. 小红书、知乎做内容分享

我们预先筛选约400个做小红书的博主，越多越好，进行合作。找达人主要有三种途径：官方平台小红书蒲公英、专业媒体机构、直接私信对接。

确定合作意向后，流程是：沟通价格和推广方式→商家寄样，达人输出框架内容→沟通确认→达人创作→商家审核并二次调整→安排发布。公司内部员工也会在其他博主内容下做部分广告，侧面凸显自己的产品。尽量保证小红书、知乎等渠道关于品牌的产品评价正面，并让每个真实养宠用户了解核心卖点和竞争力。

内容合作不一定非找头部KOL：一方面收费高；另一方面，这部分主要任务是口碑营销，很多粉丝不多的新博主也可以合作。我们还发动素人分享：发推荐文章可免费领取宠物主粮，主要从自有顾客中通过1带1裂变而来。合作前提是选好达人，研究达人粉丝画像是否属于品牌目标用户。外部有不少专业分析平台可借用，比如新红：https://xh.newrank.cn/；cc：https://ccsight.cn/。

3. 大V评测

大家上不上B站等网站？B站等渠道有很多做产品评测的。宠物行业目前意见领袖的观点很重要，行业内有比较知名的大V，比如老阳和狗哥。我们联系大V对产品做评测，输出优质评测视频，为品牌做信任背书。不同行业和品牌收费标准可能不同，宠物行业一般10万元左右可以拿下，整体合作流程跟小红书达人一致。

4. 核心引流：抖音投放

前面几步属于前期基础，抖音投放才是最关键的环节。这部分主要有两方面：投放素材产出和落地优化投放。

先说投放素材产出，主要来自三方面：直播切片、达人推广视频、头部带货主播或明星合作。

（1）直播切片。截取主播直播过程中表现不错的时间段，结合文案等二次创作成视频。效率高、出片快，可迅速大批量产出。我们和专业团队合作，进一步提升了效率。

（2）达人推广视频。流程跟小红书环节一样：达成合作意向→寄样，达人给框架→确认→达人创作→商家审核调整→安排发布。这类视频既能触达达人现有粉丝，也能帮品牌产出相对优质的内容。优缺点明显：内容优质，但费用较高。

（3）头部带货主播或明星合作。现在明星下场带货越来越多，虽然产出基本无法保障，但天然背书不是一般达人能比的。用他们产出的视频再投放，效果会更好。头部主播如李佳琦、老罗，明星如金星，价格都不便宜。以金星为例，直播坑位费约6万元；额外获得授权，可用直播切片在抖音等渠道投放，单月费用约3万元。这部分需要具体品牌具体分析，而且听说还在涨价。

再说落地优化投放。

互联网企业用大数据很普遍，抖音推荐算法是佼佼者。它根据浏览记录和偏好做定向推广，所以你会发现，越喜欢看什么，抖音越推什么，看到的相关内容越来越多。我们和抖音交互时，平台会给每个人打上成千上万个标签，比如我的标签可能是：单身、25—30岁、男性、江苏、小米手机用户、小镇青年等。抖音信息流投放主要针对这些标签进行。

信息流投放主要依靠UD和AD。UD主要借天猫系统的淘积木作为落地成交页，AD则不需要，但整体投放逻辑思路一样，只是工具不同。抖音上常见的带购物车广告视频，就是这么来的。

我们主要用人群标签组合投放。投放中可选择的标签很多，不同类目产品选择不同。我们根据地域、城市、省份、性别、年龄、消费层级、兴趣偏好、宠物等标签组合投放。

举例：前期先投二级组合标签——年龄+性别，如18—25岁女性、18—25岁男性、25—30岁女性、25—30岁男性、30岁以上女性、30岁以上男性等。对这些标签做投放测试，测出收藏加购和投入产出比更优的人群，比如18—25岁女性、25—30岁男性。再在表现好的标签基础上做三级组合——年龄+性别+地域，如18—25岁杭州女性、25—30岁杭州男性、18—25岁上海女性、25—30岁上海男性等。依次类推，几乎能组合出成千上万个标签。这些标签有好有坏，有的有流量，有的没流量，需要根据自身品牌产品人群不断测试调整。

一般来说，人群标签越精准，转化越高，但流量越小。想放大，必然要放开人群，这会造成人群不精准，整体投入产出变低，需要商家自行衡量。

投放中也会碰到问题，希望大家避开：

1. 计划里有预算，却一直消耗不出去。这主要是账户或计划问题，最简单的方法是多个建计划、直接复制。相同计划中，有的能消耗，有的怎么都花不出去费用，这种情况比较常见。
2. 计划以前很好，突然变差，投产和点击下降。我们当时反复检查没发现问题，最后才明白是素材问题。抖音投放素材有“保质期”，视频过时很快，需要不断优化投放素材、迭代更新。
3. 投放的客户群体成交很差。当时投18—25岁左右人群，效果很差，反而40岁以上人群效果很好。原因在投放素材：剪辑视频偏向促销降价，客户群体明显中年化；素材偏向场景化、情景化、剧情化，年轻人会多一些。每个品牌可能不同，需要根据实际情况具体分析。

投放中还会碰到形形色色的问题。我们选择了几家专业投放机构帮忙，他们经验丰富，帮我们避开了很多坑。下面看部分投放计划数据截图，重点看逻辑而非数据，数据做了部分脱敏处理。

## Part 3 复盘与建议

1. 定价是关键。确保毛利，算清利润再开始执行计划。
2. 此方法需要投入大量费用。我们大概投放1000万元左右，产出1500万元，即使目前也处于刚刚收支平衡阶段。相对于亏损，我们更在乎整体品牌增长以及未来发展。
3. 投放过程压力山大。开始几个月极度绝望，综合投入产出刚开始只有0.2—0.3，稍好些0.4左右，远远入不敷出，每个月亏损几十万上百万元，更关键的是不知道是否会成功。
4. 整个过程属于团队协作。从流程前端到后端，从产品到营销，都需要全方位配合，只有团队完善才建议尝试。
5. 小商家可以借鉴思路，不要照本宣科。抖音是未来发展大趋势，建议都去开抖店。不要重复“先轻视、再排斥、随后困惑、最终错过”的老路。
6. 今天的分享偏大方向，详细操作可根据每个环节重点在生财社群搜索，基本都能搜到，小伙伴们关于细节操作的分享可以借鉴。
