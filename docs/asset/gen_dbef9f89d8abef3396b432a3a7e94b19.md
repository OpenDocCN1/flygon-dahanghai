# 3.6 技巧六：朋友圈发生活碎片，别把好感变减分 @王子冯

生活切片式的朋友圈，其实是情绪价值的一种表达方式。和一般情绪输出相比，它更接地气、更有人情味，也更容易让看的人觉得你就在身边，从而缩短彼此距离。不过，发这类内容也有几条红线要留心。

1）自黑别变成自贬

有人会发自己头发乱糟糟的照片，或者故意扮丑，甚至把家里拍得像杂物堆。假如你的外形条件像明星那样能打，偶尔不修边幅、搞怪一下，读者会觉得有趣可爱；但多数人并没有这样的底子，这么做只会让自己的形象掉价，根本算不上生活分享。

自黑和自毁形象是两回事。判断方法很简单：这条内容发出去后，大家被逗乐，觉得你真实又有趣，那就没问题；如果看完只让人冒出“怎么这么邋遢”“怎么这么掉价”的念头，那就不是加分，而是给自己添堵。

2）晒娃别晒出隐私

不少人把孩子的吃喝拉撒全搬进朋友圈，翻一圈像在看宝宝成长流水账。前面已经提过，晒娃本身风险不低，频率越高越要谨慎；当然，做母婴或家庭教育相关内容的账号可以另当别论。

尤其要避开这些做法：把孩子的隐私部位、排泄物发出来，发母子嘴对嘴亲吻的照片，或者晒孩子裸露的画面。旁人看了不舒服，更重要的是，这也是对孩子隐私的不尊重。

3）炫耀别刷屏

曾有个做微商的人去人均消费千元以上的京兆尹吃饭，从进门起就开始拍视频，一道菜发一条朋友圈，前后刷了三十多条。平时吃顿饭、爬个山也能连发几十条的人，会给人什么观感？别人多半会想：这是平时没怎么吃过好东西吧。

4）恩爱别秀过头

频繁秀恩爱也很容易尴尬。把“恩爱”当人设来立，翻车概率不低，娱乐圈里这类例子并不少见，毕竟感情牵涉的变量太多太杂。

还有一种秀法让人看得脚趾抠地。秋天第一杯奶茶流行那阵，有位姑娘发朋友圈，大意是老公对她实在太好了：结婚前她舍不得买这么贵的奶茶，老公却舍得给她买。九块钱一杯的饮料，被赋予这么重的情绪价值，围观者只会更尴尬。

5）卖相差就别硬发

饭菜卖相不好，最好不要硬晒。我一直鼓励大家学做饭，手艺练好后经常在朋友圈展示，是很加分的事；可如果费半天劲做出来的是黑暗料理，还是收着点。去网红餐厅打卡当然可以发。

说到底，凡是和颜值、卖相相关的内容，先问自己一句：这条能给我加分吗？能就发，不能就忍住。

总的来看，上面这些提醒都指向两个字：适度。生活可以展示，人设可以经营，但一旦过了头，反噬也可能随之而来。
