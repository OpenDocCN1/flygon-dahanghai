# 3.3 项目架构规划

# 3.3.1 认识 MV 架构

苹果官方推荐 MVVM：Model 管核心数据与业务逻辑（数据库/网络请求）；View 展示界面接收操作，不处理业务逻辑；ViewModel 是 View 与 Model 桥梁，转换数据为 UI 格式，管理 UI 状态交互，双向绑定同步。本次入门简化成 View 和 Model：View 负责页面显示，Model 负责数据。掌握后可逐渐过渡 MVVM；现实中 APP 未必复杂到需要 MVVM，View+Model 往往够用。

# 3.3.3.3 分清 Xcode 与 Cursor 的职责
