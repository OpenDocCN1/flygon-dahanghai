# 别追爆款了，做这种小众高利润品

未来十年，跨境卖家真该慢慢把“爆款思维”放下了。在我眼里，追爆款等于给自己挖坑。

真正值得盯的，是那种差异度做得很足的货：进货大约七十元人民币，放到海外能卖七十美元，海外买家依然觉得划算；1688上还能找到现成货源。新手找不到这类供货方，不是市场上没有，而是认知没到、注意不到。

类似品类叠加小语种发达国家的门槛，我们已经吃了七八年的独占红利。为什么不怕别人跟卖？因为这类品销量不算大，选品工具扫不出来，可利润空间很厚。一个这样的品，一年净赚百万上下并不稀奇。

所以好选品不局限于一个渠道：亚马逊、独立站、TikTok都能跑。选对了，红利周期长、利润稳，不会火一阵就消失。
