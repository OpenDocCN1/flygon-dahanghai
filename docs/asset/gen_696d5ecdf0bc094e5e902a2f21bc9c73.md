### 03. 上手体验这三个 Skill

### 1. 先用自己的稿子

这一步很关键，别跳过。

翻一篇你自己写过的东西出来：👸号旧文、朋友圈长文案、群里发过的通知、产品介绍，甚至一段没发出去的草稿都可以。1000 字以内最合适。

为什么一定要用自己的稿子？

• 用样稿测试，你看到的只是“这工具挺神”
• 用自己的稿子测试，你才会看到“原来我写东西有这些毛病”

后面这种感受，才是这一关真正想给你的。而且你手上还会多出一篇改好的、可以直接发的文章。

### 2. 练习素材：4 份参考样稿

如果手头实在没有可用的文章，我们准备了四份样稿，都放在【2.2-方式二】的【关卡1 资源包】里。

挑一份和你行业最接近的：

| 样稿 | 讲什么 | 适合谁 |
| --- | --- | --- |
| 样稿 A | 1688 选品心得 | 做电商、做供应链的 |
| 样稿 B | 下班后做副业踩的坑 | 上班族、想搞副业的 |
| 样稿 C | 为什么我的课程卖不动 | 做知识付费、做课程的 |
| 样稿 D | 开了三年小店的经验 | 做实体、做本地生意的 |

这四份样稿的行业跨度很大：电商、职场、知识付费、实体店。

但把它们摊开对比就会发现，毛病几乎一模一样：都喜欢用“在当今这个……的时代”开头，都爱用“首先、其次、最后”串结构，中间都有一个长破折号，结尾都以“让我们一起……更 X、更 X”收尾。

这就是所谓的“AI 味”，它跟你写什么无关，只跟你怎么写有关。

也正因为套路固定，它才能被一个 Skill 批量改掉。

[PRE34]

同一份稿子，分别按抖音和📕各查一次，你会发现结论不一样，有些甚至完全相反。

如果你一稿多投，抖音能过，不代表📕也能过。

不同平台的审核规则不同，建议根据发布平台选择对应的规则库。

[PRE35]

💡注意事项：

**1️⃣它主要适用于短视频内容审核**

这个 Skill 的 references 文件夹里有四个文件：1 份通用规则、3 份平台规则（抖音、📕、视频号）。

• **通用那份是普适的**（法律红线、虚假宣传、诱导导流这些），不管你发在哪里都适用  
• **平台专属那三份针对短视频场景**（画面模糊、评论区引流、AI 生成标注等）。如果你审核的是👸号、文章或🛰️群内容，其中不少规则并不适用

**2️⃣它不会检查商业条款**

我拿一条“充 200 送 50，限 30 个名额”的促销通知实测过，规则库里没有任何一条涉及预付卡、充值赠送、有效期。这类最容易起纠纷的内容，它是盲的。

**3️⃣报告通过 ≠ 内容安全**

即使超出了它的能力范围，它也会生成一份完整的审核报告，不会主动告诉你“这个无法判断”。

**4️⃣有些风险它识别不了**

例如收入截图、夸大宣传、制造稀缺焦虑（如“仅限今天”“前 50 名免费”）等，仍然需要人工判断。

所以审核通过，不代表内容一定合规。

这个 Skill 的作用是帮你发现明显的违规词和高风险表达，而不是代替人工审核。涉及金钱、承诺、资质等内容，仍建议人工复核。

没有一个 Skill 是完美的。

### 04. 常见卡点清单

💡遇到问题先别急着放弃，可以先问 AI。本期推荐优先使用 Codex 或 WorkBuddy，把报错信息、截图或你的需求新开一个任务窗口发给它们，让 AI 帮你分析原因、排查问题，甚至直接帮你解决。

[PRE37]

慢慢养成先问 AI、再求助他人的习惯，很多问题都会解决。

| 常见卡点 | 先检查什么 | 下一步动作 |
| --- | --- | --- |
| 装不上 / 找不到 Skill 列表 | 安装命令有没有发全，仓库地址对不对 | 把 SKILL.md 内容直接粘进对话框用，先跑通体验，安装问题去答疑群问 |
| 装上了但没反应 | 你说的话有没有命中它的触发场景 | 换个说法，明确带上关键词：“用 wechat-writing-style 改这篇” |
| 看着在跑，但结果不对劲 | 是不是只拷了 SKILL.md，没拷整个文件夹 | 重新装一遍，确认 references/ 目录也在 |
| 排版跑到一半断了、HTML 是残缺的 | 你用的模型单次输出上限够不够 | 文章控制在 1500 字以内；跟它说“用留白禅意风，不要封面和目录” |
| 粘进👸号后没有大标题 | 不用查，本来就这样 | 这是正常的，👸号标题要单独填在后台标题框里（没👸号的忽略这条） |
| 文末有 {{作者名}} 没换 | 不用查，改掉就行 | 手动改成你自己的名字和简介再发 |
| 改写后感觉“这不是我说的话” | AI 扩写时可能编了经历 | 通读一遍，把不是你干过的事删掉或改对 |
| 合规报告说没问题，但我还是不放心 | 不用查，你这想法是对的 | 对的，应该不放心。它只查明显的坑，晒收入、制造焦虑这类它查不出来 |

### 05. 本关小结

恭喜你！你已经体验了 3 个成品 Skill，并且完整跑通了一条“改文字 → 排版 → 发布前体检”的内容工作流。

这一步做完，Skill 对你来说就不再是一个新名词了。

你亲眼看到了：同一篇稿子，经过 Skill 处理之后，可以从一段普通文字，变成更像人写、更好阅读、还能顺手检查风险的成品。

尤其是做完前后对比之后，你应该已经能感受到 Skill 的魅力：它不是让 AI 临场发挥，而是把一套稳定做法提前装好。

下次再遇到同类任务，不用重新解释标准和流程，直接调用它就能接着干。

所以这一关我们并不追求装得多、懂得深。你只要确认 3 个 Skill 能被叫出来、能跑出结果、前后差别一眼看得出来，就已经过关了。先尝到甜头，后面我们再慢慢拆它是怎么做到的。

**核心三个动作：**

1. **装好 3 个 Skill**：安装整个文件夹，通过 AI 回复了解每个 Skill 的能力。
2. **用真实稿子跑一遍**：优先拿自己写过的内容测试，依次完成改写、排版和发布前体检。
3. **留下可验证证据**：截图要能看出安装成功、命令发出、结果返回，以及改写前后的明显差异。

这一关之后，你已经完成了第一次 Skill 体验，知道了 Skill 是如何安装、如何触发、如何产出结果的，以及 Skill 带来的神奇效果。
