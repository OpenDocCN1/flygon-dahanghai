### 01. 把 Skill 创作变成一件好玩的事

**1.** Skill 比你想的更有意思

前面那些例子集中在职场任务上——写作、判断、资料、脚本，目的是先让大家明白 Skill 的运作方式。但 Skill 的边界远不止工作。不少好玩的 Skill，最初都只是生活里的一个小念头。

比如：

**🍳 食谱 Skill**

刷到做菜视频，不想反复暂停手抄步骤，于是做了个 Skill。只需一句指令：看着这条视频，帮我整理出一份能直接下厨照做的菜谱。Skill 会自动生成：食材、用量、步骤、时间。

[PRE1]

**❓Grill Skill**

很多产品人真正卡住的地方，不是做不出来，而是想法还模糊。Grill Skill 不替你写答案，而是连续发问：为什么做？用户是谁？为什么现在做？还有没有别的办法？有人被它连问了几百个问题，原本朦胧的念头逐渐变成可落地的产品。

[PRE2]

**✈️ 旅行地图 Skill**

出发前最头疼的往往不是没目的地，而是收藏夹太满、路线排不开。这个 Skill 能把截图、愿望清单、酒店位置和口味偏好梳理成顺路行程，并生成一张到当地就能打开的手机地图页。

**2.** 灵感可以从哪里来

工作或生活中，你大概冒过不少点子；可等真正动手，又常常不知道先做哪一个 Skill。若暂时没头绪，不妨从以下三类场景切入：

**2.1** 工作中反复出现的事

某件事若已经重复多回、每次还得从头再来，就很适合交给 Skill。比如：

- 每周整理会议纪要、写周报；
- 每次写公众号、小红书或邮件；
- 每次分析数据、做复盘；
- 每次整理资料、归类文件；
- 每次做选题、策划活动、写方案；
- 每次回复客户、处理售后、整理 FAQ。

同一件事若累计做过三遍以上，就该想一想：其中一部分，未来能否交给 Skill 代劳？

**2.2** 已经形成个人经验的方法

有些事别人同样能做，可你已经摸索出自己的尺度，例如写作风格、判断标准；除此之外还包括：

- 自己整理知识的办法；
- 面试、销售、客服话术；
- 选品、运营、带团队的经验；
- 自己归纳的工作流程。

这些经验原本只装在脑中。做成 Skill 后，它们就成了能反复调用、不断打磨的能力资产。

**2.3** 生活里“要是有人帮我就好了”的小事

Skill 未必要围着工作转，不少有趣作品都取材于日常。例如：

- 看到做菜视频，自动整理成菜谱；
- 帮自己规划旅行路线；
- 根据家里现有食材推荐今天吃什么；
- 帮自己制定健身计划；
- 读完一本书后自动整理重点；
- 玩游戏时整理攻略、记录任务。

许多出色 Skill 的起点都很简单：“要是有人能替我处理这件事就好了。”后来，这个念头真的变成了能帮自己的工具。你完全可以从工作、生活或兴趣出发，把想沉淀的经验、想解决的问题做成 Skill。出色的 Skill 通常不是凭空设计出来的，它往往生长于真实生活和具体需求。

**3.** 大胆创作你的 Skill

把你的经验拿出来，让更多人直接复用。你发布的第一个 Skill 不必一开始就很完整。它可能只是一个已经帮你解决过问题的方法，也可能还没被多少人使用。这都没关系。Skill 并非一次发布就定型的作品，它会在真实使用中持续进化。你可以持续补充内容、优化提示词、增加工具和脚本，让它越来越顺手。SkillHub 想做的，就是让那些留在个人电脑、对话记录或工作流程里的经验，被梳理、被看见，并被更多人再次使用。如果你已经把有趣想法或实战经验做成 Skill，就点击炼术营专属的 Skill 发布页分享：

### 02. 本关小结

🎉 恭喜你，Skill 航海的全部关卡已经走完！

再回头，你收获的远不止一个 Skill 成品。从试用他人做好的 Skill 起步，你掌握了安装、触发与效果验证；之后又学着拆解结构、编写 SKILL.md、补充 references/、加入 scripts/，把个人写作风格、判断尺度、真实案例和固定流程，逐层转化为 AI 能反复调用的能力。再往后，测试、迭代、撰写说明、发布到 SkillHub 也逐一上手，自己的 Skill 能力库开始成形。

走完这一程，真正的改变并非多掌握几个工具，而是你开始形成一种新的工作方式。面对真实任务，你会先判断：

- 它是否高频重复？
- 其中是否存在稳定流程、标准或经验判断？
- 哪些内容适合写进 SKILL.md？
- 哪些资料和案例该放进 references/？
- 哪些容易出错的计算或检查应交给 scripts/？
- 能否先做成边界清楚、结果可验证的小 Skill，再逐步扩展？

这也是这次航海真正要练的能力：Skill 既不是更长的提示词，也不是一次性工具收藏；它把经验、偏好、资料、流程与判断标准整理成可复用、可更新的工作资产。

别急着追求全能。先做一个能解决具体问题的小 Skill：聚焦一个场景、一种任务、一类经验。只要它帮你省时间、少犯错、少重复解释，就值得做。随后继续测试、补资料、加脚本、迭代，让它更贴近你、更懂场景，也更适合分享。

回望 21 天，你从第一次听说 Skill 是什么，到体验、拆解、制作、验证、迭代、整理、发布和管理，已经拥有第一批自己的 Skill。更重要的收获，是一套把真实经验沉淀给 AI 并持续优化的方法。今后遇到重复、标准明确、可验证的事，别只想着“我再做一遍”，先问：这件事能不能沉淀成一个 Skill？

愿这 21 天的作品只是起点。未来实践里，你会慢慢积累出完整的个人 Skill 能力库。期待在 SkillHub 看到你更多创作。恭喜顺利靠岸，继续创造 🚀
