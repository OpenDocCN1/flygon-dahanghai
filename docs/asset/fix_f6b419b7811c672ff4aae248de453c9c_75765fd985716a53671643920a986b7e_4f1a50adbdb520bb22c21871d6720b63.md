# 4.3.2 借势入局：先让目标人群看见你

一个人一旦走出自己的影响圈，基本就等于隐形。那怎么才能被人注意到？答案可以浓缩成一句：选一个够格的落点，把内容装进去。

落点选得好不好，往往决定成败。圈里人爱拿抢占风口、搭顺风车、踩中上升电梯来打比方，说的都是这件事。热点当然能当落点，但落点绝不限于热点。有些高手，不管对方开什么话题，都能三言两语拐回自己熟悉的领域，顺势嫁接上去——在他眼里，世间万事皆可成为自我表达的出口。

不过有个常见的翻车点：有人追热点追出了大流量、大曝光，可翻遍作品也找不到“作者本人”。追着追着，把自己的立场、判断、辨识度乃至产品统统留在了场外，压根没融进那个落点。这样的成绩单再唬人，也撑不起真正的价值。

那具体该怎么办？拿“给行业新手做社群”来演示一套通用打法：

- 第一步，摸清新手扎堆、交流的公共场域，线上和线下都别漏；
- 第二步，把新手最高频的困惑拢到一起，途径可以是问卷、检索，也可以直接致电典型用户去问；
- 第三步，圈定你个人最看好的100个问题，请种子用户投票，看他们最想先解开哪些；
- 第四步，选出得票最高的20题，下功夫打磨内容，前期偏重文字稿，务必用新手愿意看、读着有代入感的话来写；
- 第五步，找到公域里正在聊这些话题的角落，把备好的内容投放到那里，再按具体场景挑图、文、长视频、短视频或音频等形式；
- 第六步，每天去转一圈，盯住数据反馈，哪里的表现亮眼，就在哪里扎根建渠道。

谁能把新手的高频疑问（FAQ）吃透，谁就真正摸清了新手，也才拿得到信任，让新手愿意向你靠拢。

倘若你还记得自己当初是菜鸟时的种种细节，能掏心窝子讲讲自己怎样一步步摸爬滚打过来，这同样是很适合做成主页置顶的好素材。

这里头还有讨巧的路子。不少专门服务工具型入门小白的人，不过是老老实实扒了扒生产力软件（如Pr、Ps、剪映、达芬奇、Anaconda等）官网或说明手册里的FAQ，再翻翻用户论坛里的高频疑问，把它们录成视频，就足以解决小白八成的困扰，成了能切实帮到他们、每年稳赚几十万起步的大V。

当然，坑依旧存在。翻找高频疑问时，我们眼里的头号问题，和用户真正挠头的问题常常对不上号。别凭感觉拍脑袋，得想办法把自己的身段压下去，再压一压，一头扎进用户堆里，瞧瞧他们反复问、最爱问、真正挂在心上的是什么。也许那问题看着挺傻，可你替他拨开迷雾，他照样会念你的好、认你的账。更进一步，如果他没开口提示，你就精准点中那个让他翻来覆去睡不着的问题，还附上漂亮的解法，那对他内心的冲击将是巨大的。

看到这里的朋友，恭喜你。留一道练习：如果你对未来要做的社群已有了大致轮廓，请逐条作答——你的目标用户长什么样？去调研一下，他们最高频的20个疑问分别是什么？为什么偏偏是这20个，你的依据何在？

说到底，高频疑问就是你靠近用户的落点；而你的解答，就是你注入问题之中的独有内容。这种落点凭什么有力？因为那恰恰是用户最上心的东西。以上便是我对“外部渠道”如何搭建的思考与实例。

当体量尚小时，搭建外部渠道最常见的打法，就是我所说的“当风轻借力”。但请记住，借力归借力，别在过程中把自我弄丢了。侯蒙在《临江仙·未遇行藏谁肯信》里写得妙：“未遇行藏谁肯信，如今方表名踪。无端良匠画形容。当风轻借力，一举入高空。 才得吹嘘身渐稳，只疑远赴蟾宫。雨馀时候夕阳红。几人平地上，看我碧霄中。”

再以知乎为例。2017年运营知乎知识星球那会儿，我只在上面答了4道题，答完便完全撒手，可就是这4个回答，当年给我进账六位数。解答用户上心的问题，比解答你自己上心的问题，更显得你在意用户；接住用户真正关切的议题，比凭空造一个自己关切的议题，更显得你在关切用户。查理·芒格讲过，想钓鱼，诀窍很简单——去有鱼的水域下竿。反过来，先把竿子甩下去、再盼着鱼游过来，是典型的以自我为中心的思路，未必行得通。

知乎里建渠道的窗口在于：平台上仍存着海量用户当下关心、却还没被商业化的问题，而且这些问题的阅读量每天都在新鲜增长。

那如何判断一个问题热不热？若问题挂在百度知道，可借助简单的原生接口，拿到它浏览数据的每日增量；也能用百度指数，看对应关键词热度在一年里的周期起伏。若是在微博热搜上瞄到的，得留个心眼——不是每条都真热，有买的，也有真火的。当时有个很朴素的测法：把你关注的某个热搜词，原封不动地嵌进一条微博里，拼成一个句子发出去，看这条能跑出多少浏览。你关心的每个词都能这么试，浏览量蹭蹭往上窜的，才是真热度。

2. 信念感
3. 外部渠道怎么搭建
4. 借力时别把自我弄丢
5. 关键词热度如何测
