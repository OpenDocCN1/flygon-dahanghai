# 1.3 为什么先从英文工具站做起？@刘小排

如果你是一名独立开发者，想尽快把产品做出来，我的建议是：从海外英文工具站切入。原因很直接——它是所有产品形态里，能最快上线的一条路。

相比之下，做 App 的周期明显更长。移动端开发不仅代码复杂度更高，对工程师的技术要求也更苛刻。更麻烦的是，上线前要经历打包、提交审核等流程，一旦被驳回，又得反复修改，时间成本成倍增加。如果你做的是国内 App，还要额外准备软件著作权证书，光拿到它可能就得花上三个月，之后才有资格登录国内应用商店。最让人头疼的是，哪怕只是修复一个小 bug，也得重新发布版本，用户必须手动升级安装才能生效。这样的节奏，会极大拖慢你的迭代速度。

做国内网站同样快不起来，核心瓶颈在于域名备案。整个流程通常要耗费一到三周，如果在备案审核特别严格的地区（比如北京），被打回重填也是家常便饭。

🛰️小程序比前面两个稍好一些，但依然谈不上快。因为小程序的开源生态不够成熟，很多现成的代码库轮子没法直接引入，你只能自己造轮子，编码效率自然也上不去。

而海外网站的优势就在这儿：它不需要软著证书，不需要域名备案，不需要应用商店审核，功能更新后用户也无需重新下载任何东西。代码推到 Github 仓库，配合 Github Action 做 CI/CD，提交即自动部署，整个开发体验酣畅淋漓。

当然，“从网站开始”并不代表你的产品永远停留在网站形态。它只是 MVP 阶段的一个选择。等你积累了足够的用户数据反馈，再顺势去补🛰️小程序、iOS 或 Android 版本，完全来得及。
