从行业实践看，资金体量不算大的用户，把资产放在头部中心化钱包往往比去中心化钱包更稳妥，原因在于币安这类平台的安全能力很硬。但它也有代价：平台处在监管框架内，个别账户可能因监管措施被冻结。

去中心化钱包按私钥是否联网保管，分成冷钱包和热钱包。冷钱包不联网，硬件钱包最常见，用法类似银行U盾，私钥从生成到使用都不碰网络，只待在不联网设备里，因此防护级别更高。热钱包则相反，创建和使用过程都会触网，日常常见的小狐狸钱包就是例子。综合来看，“中心化交易所钱包+冷钱包”是较优组合；热钱包抗风险能力偏弱，容易被钓鱼，不适合放大额资金。

# 4.1.1 去中心化金融入门 @可达 Koda @馋嘴猫

Web3的两根支柱，一根是区块链技术，一根是金融。区块链技术可以归入密码学与计算机科学的交叉分支；而金融类产品，在Web3里几乎已经全品类铺开。本章先带大家认识Web3金融的基本概念与产品形态。

在Web3语境中，金融被称作去中心化金融，英文DeFi，全称Decentralized Finance。很多人会觉得，中心化金融已经够好用了：信用卡、支付宝、微信支付都很顺手。

这里我不打算重复那个常见说法：全球还有17亿成年人没有接触金融系统，享受不到传统银行服务，而加密货币能让其中拥有智能手机的大部分人获得现代金融便利。这些当然是正在发生的事实：在第三世界国家、跨境支付以及某些特殊支付场景里，加密货币确实有真实需求，而且需求还在增长。

可换个角度看，这些需求似乎也没那么“非它不可”。有加密货币当然更方便；没有的话，无非成本高一些、到账慢一些，金融基础设施落后的地区少享受一些服务而已。

那Web3内部到底有没有强刚需，能稳稳撑起这座大厦？如果没有，Web3的地基就不牢，可能只是有人不断吹泡泡，泡泡终有破的一天。

我认为答案是有。

从底层看，Web3里比较确定的东西，是比特币等去中心化资产的价值。这个价值很难被替代，至少目前还没看到替代者。请注意，我说的是“比特币等去中心化资产”，并非只指比特币。关键点在于：去中心化资产让财富真正归自己掌控。

比特币算一个，但它的原罪也很明显：挖矿消耗大量能源，带来环境问题，一直受到批评。以太坊在9月完成PoW转PoS后，不再依赖实体矿机，能耗下降99%以上，因此更受传统机构巨头青睐。并且，转PoS之后，以太坊从原先每年约4.4%的固定通胀，逐步走向通缩，已经开始露出与比特币争夺“数字黄金”地位的苗头。

对持有大额账面财富的人来说，配置一些真正能自己说了算的资产，似乎不需要太多理由。

前几天和几位老朋友聚会，聊到比特币估值。有人提到，可以把全球1%富人拥有的1%资产总和，当作比特币估值的一个参照。按这个思路，大家可以算算，比特币单价最高可能到多少万美元？这只是假设。不过这个假设至少还要考虑两点：

第一，部分助记词已经遗失，几百万枚比特币实际消失了，等于流通总量不再是2100万枚，这样估算出来的单价会更高。

第二，随着以太坊崛起，比特币已不是富豪们唯一考虑的加密资产。尤其以太坊的节能环保属性，比比特币更受机构巨头欢迎。所以，“全球1%富人1%资产”对应的总估值，不应只算比特币，而应算作部分比特币+部分以太坊，未来还可能出现其他储备资产。

为什么是“部分比特币+部分以太坊”？因为除了财富储备，比特币和以太坊还有其他价值，可以支撑各自的一部分市值。以太坊尤其明显：公链生态不断壮大，它正在慢慢变成一台世界计算机；运行其上的所有Dapp都要消耗ETH作为汽油费，系统越庞大，ETH消耗越多，其价值也就越有支撑。

传统金融掌握在政府或金融组织手里；去中心化金融则不同，无论比特币还是以太坊，理论上资产的归属权都由你自己的私钥决定。产品层面，DeFi几乎把传统金融产品照搬了一遍。

DeFi与传统金融最大的区别在于本位不同：传统金融是法币本位，美元、欧元、人民币等政府货币都叫法币；DeFi则是加密货币本位，要么是稳定币（简称U），要么是比特币、以太坊等网络中的加密货币（Crypto）。

目前Web3去中心化金融主要由两大类产品承载：中心化交易所和去中心化交易所。中心化交易所也叫加密货币交易所，通常由公司经营，并配合主权政府的监管政策；去中心化交易所的运行原理与比特币网络相近，由算法程序自动执行，不受人为干扰。后文我们会依次了解稳定币及相关产品、中心化交易所及相关产品、去中心化交易所及相关产品。

# 4.1.2.1 资产发行【新】

先看资产发行方式。前面的学习里，我们已经认识了ICO（首次代币发行，Initial coin offering）。这一节看ICO之后常见的两种发行方式。

1. IDO（首次去中心化交易所发行，Initial DEX offering）
与ICO相比，IDO最大的不同是借助DEX（去中心化交易所）来发行代币并融资，所以也有人称它为“首次通过DeFi发行”。流程是：发币项目方向DEX提供代币，用户把资金质押进DEX的流动资金池，DEX按照用户质押资金规模完成代币分发与划转，整个过程由智能合约执行。

IDO的优势在于：对用户来说，靠谱的DEX通常比项目方更安全；而且IDO不做KYC身份认证，有钱包就能参与，方便快捷。对规模小、知名度低的项目方来说，通过去中心化交易所发币，比上中心化交易所更容易，成本也更低。

2. IEO（首次中心化交易所发行，Initial Exchange offering）
IEO与IDO的区别，关键在于交易所平台是否去中心化。币安Launchpad就是典型IEO。用户参与Launchpad时，通过质押特定资产进行项目挖矿，获得代币，等二级市场开启后卖出获利。有些币安Launchpad明星项目代币，上架后24小时收盘价涨幅甚至超过3000%，这也是大家参与币安IEO热情一直很高的原因。

# 4.1.2.3 资产流动

资产有自由流动的需要，而去中心化资产的自由流动，自然依赖去中心化基础设施。

1）公链基础设施（Layer1，Layer2，侧链等）
比特币交易速度是5-7笔每秒，大约10分钟才能打包一个区块，等6个区块之后一笔交易才差不多真正完成。以太坊稍高一些，目前状态下每秒也就15-20笔交易，效率非常低。因此产生了新公链和扩容提速的需求。从2017年到现在，从EOS到Solana再到Aptos，新公链高TPS的叙事一直没变，而且屡试不爽。Layer1、Layer2、侧链都走扩容路线，扩容也是近几年行业大热板块，核心目标都是解决资产流动效率问题。

2）跨链
目前比特币生态发展还比较弱。如果想把比特币卖成稳定币，或者赚点利息，又不想去中心化平台，怎么办？这时跨链就派上用场了。把比特币这条链上的资产跨到以太坊生态或其他生态，再去抵押获得利息，或者抵押借出其他资产，提高比特币资产的利用效率。当然，目前公链众多，不同公链之间都需要跨链来相互通信，所以跨链也是提升资产流动效率过程中不可忽视的重要一环。

3）预言机
这个词一般人可能比较陌生，因为主要是to B的业务形态。举个简单例子：你在AAVE（借贷平台）抵押1个比特币，借出1.5万美金；当比特币价格暴跌时，AAVE会开始清算你的比特币，以免产生平台债务。那AAVE从哪里获得价格？答案是预言机。预言机会从各大中心化或去中心化交易平台调取比特币价格，提供给AAVE。目前预言机龙头是Chainlink，确实做得不错，基本没出过大问题。最近币安也开始下场做预言机，开始打破一家独大的局面，有竞争对行业来说是好事。

4）去中心化存储、隐私
存储也是非常重要的板块，主要用来保存重要数据信息，目前包括Dapp的一些前端后端数据、NFT图片元数据、某些公链数据备份、Web3相关数据代码以及去中心化社交平台数据。不过目前去中心化存储应用范围还不算广，盈利能力不强，龙头Filcoin也开始转战计算领域。隐私板块主要是保护相关交易信息、隐私数据等，但隐私板块一直没有大火起来，可能等以太坊的二层ZKrollup来带动。

1. DAO
这里提到的更多是去中心化项目基金会组成的DAO，用来保管项目代币、负责财务支出核算等。至于社区型DAO，目前运行机制还不太成熟。更详细的DAO内容，我们在后文「七、了解 DAO」中展开。

5）DeFi（Dex、去中心化借贷、去中心化衍生品、稳定币、去中心化保险等）
DeFi的重要性自不必说。比特币这类去中心化资产，要想在脱离中心化机构管控的情况下实现资源效率最大化，DeFi必不可少。从分类看，Dex（Uniswap、Pancake等）是去中心化交易；除交易外，还有借贷（AAVE、Maker）、衍生品（Dydx、Gmx等）、稳定币、去中心化保险（目前基本没发展起来，没有优质项目）等。

现在回头看第二大类“资产流动”里的前几项：公链基础设施、跨链、预言机、去中心化存储、隐私、DAO等，都可以说是为DeFi服务；甚至第一大类“资产保管”中的几项，也是DeFi必不可少的基础设施。所以我们说，DeFi是Web3世界最重要的应用。目前正在建设的Web3基础设施，绝大多数都围绕DeFi运行。

从Web3的核心支撑需求“去中心化资产”出发，我们延展出了一个有价值的Web3框架。从这个框架看，Web3各大刚需板块都和DeFi不无关系，DeFi是Web3中最重要的应用。

说到这里还没提GameFi。不过目前GameFi确实还没有找到确定的突破模式：不管是在现有游戏里加入DeFi元素，还是打造原生GameFi项目，都没有出现优质且持久的项目模式。GameFi这条路还需要慢慢探索，或者说，这个需求是不是真实的？是重Game还是重DeFi？如何突破？还需要再观望。如果谈GameFi和DeFi的关系，目前的GameFi可以算DeFi应用的一种延展，具体内容我们在后文「六、了解 GameFi」中展开。把GameFi并进去，基本就是目前行业里流传甚广的Web3框架了。

当然，关于Web3的定义目前争议还很多。但我觉得，从最底层需求出发，找到Web3最重要的支撑点，再顺着脉络梳理相关板块，会更有底气和确定性。

# 4.2 稳定币基础 @可达 Koda

这一节主要解决几个问题：什么是稳定币？稳定币解决什么问题？解决方案是什么？如何选择稳定币？

开始前先解释一个概念：加密货币，英文cryptocurrency，也可简称crypto。通过之前的学习我们知道，无论是比特币bitcoin还是以太坊ETH，这些概念背后都有多层含义。而cryptocurrency指的是货币、股票、债券这些金融产品层的含义。比特币、以太币都可以成为cryptocurrency，也就是加密货币。这个中文翻译我认为也不够准确，因为它不只有货币属性；除了货币，在一些场景下可以理解为股票，在一些场景下可以理解为债券。

# 4.2.1 稳定币是什么？它解决哪些问题？

稳定币，英文stablecoin，也是加密货币的一种。这里说的“稳定”，指的是价格稳定。通常加密货币价格并不稳定，即使是头部币种比特币、以太坊，价格波动幅度也很大，并且7×24小时在交易，价格也随之波动。

如何获取加密货币？从比特币和以太坊网络的激励机制中我们知道，为网络做建设，或者在网络中付出劳动，可以得到网络奖励的加密货币。除此以外，作为一种金融产品，自然也会产生通过法币购买的方式。如果通过法币购买，就会出现下面的问题：

加密货币价格7×24小时波动，又在区块链网络中运行，法币和加密货币的买卖双方很难直接达成交易。一个法币持有人想兑换比特币或以太坊，应该怎么办？如果直接找人或者找平台兑换，双方达成交换协议的下一刻，没等买家转账，价格就变了。

另外，Web3网络内部的各类金融和应用交易，也有必须使用价格稳定媒介货币的场景，比如发工资。员工在一家Web3公司打工，公司发给他美金等价的加密货币作为工资，结果第二天币价跌成原来的1/10，很多人是无法接受的。并不是所有人都是加密货币本位。

所以，稳定币的需求就出现了。除此之外，一些国家和地区的政策也不支持直接用法币购买加密货币。为解决上面三个问题，稳定币在Web3中出现了。

简单理解，稳定币就是钱，是Web3世界的美元。因为目前使用最广泛的稳定币叫USDT，所以我们也把稳定币简称为U。这也是大家常遇到的问题：你们说的U是什么？U就是稳定币，和美元等价。于是，如果想购买加密货币，可以在中心化交易所换取稳定币，稳定币可以和美元1:1兑换；然后再用稳定币，在加密货币交易所购买加密货币。

# 4.2.2 稳定币有哪些类型

接下来大家可能会问：我怎么确定稳定币和美元等价？你随便拿来一个数据库，我怎么相信它有价值？为了实现稳定币和美元价值等价，目前Web3主要有以下解决方案。

# 4.2.2.1 法币抵押型稳定币

稳定方式：1:1抵押美元。每质押100美金现金，就发行100美金稳定币。以USDT这家公司为例，它目前是市值最大的稳定币币种。USDT由总部位于香港的bitfinex加密货币交易所控制的泰达公司发行。因为它承诺：你在我这里买1美金，我就有1美元，所以当你要兑换成美元时，这家公司可以把美元还给你。由此构成稳定机制，本质还是通过共识和中心化信任来实现稳定。

但是这家公司到底存了多少美元，外界并不知道，也没有公开并接受审计。优点：稳定性强。问题：中心化，存在发行方信用风险。代表币种：USDT、USDC、BUSD。

# 4.2.2.2 加密资产抵押型稳定币

稳定方式：加密资产抵押。加密货币虽然价格波动幅度巨大，但也不是完全不能起到抵押作用。比特币和以太坊如果把价格和美元换算，再加上一个安全系数，也能实现类似功能。以DAI为例，DAI是由以太坊网络中的一个去中心化组织MakerDAO发行的稳定币。当一个人想从MakerDAO获取1000美金的DAI，规则要求他需要在MakerDAO里存入1500美金的ETH或者BTC。
