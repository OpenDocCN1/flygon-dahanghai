# 小红书测品：流量稳，单才稳

选品更多靠理论推演和经验判断，测品则是真刀真枪的实操；判断选品对不对，唯一办法就是下场测。小红书测品，说到底测的是获取流量的能力。产品足够细分，引来的流量通常也精准；只要商品链接页面的转化率已经打磨好，流量稳定后基本就能出单。

测品周期按一周来。高客单蓝海电商走精品路线，不学店群铺大量链接；同一类目的品可以集中在一个店，没必要一店一品，一般一个店铺放不到20个品就行。实操上建议逐个测：上一个测一个最稳；想一次性全上也行，但从选品数据最亮眼的那个先开测。每天发3-5条笔记，别集中发，测一周，能出单的品自然会见分晓。小红书蓝海电商出单通常较快，产品够细分、流量够精准，链接转化率没问题时，一周还没单就该考虑换品。一周能出单就继续做，重点练获取流量的能力；新人一般要2-3个月才能把流量和出单稳定下来。

有些品有流量高峰，比如玄学类产品，在中考、高考、考研、考公等考试前夕会迎来小高峰。选品时要通过数据发现这种节点，并安排好测品时间；如果完美错过，做起来会很累。玄学产品利润虽高，但操作有难度、容易违规，对新人不够友好，刚入行的朋友还是挑其他类目更容易拿到正反馈。这里只是举例，不代表推荐大家做这个类目。

# 3.2.1.2 定价别拍脑袋

不是把拼多多货搬来直接翻三倍就能卖，小红书用户也会算账。我问过50多位女大学生，多数人仍在淘宝、拼多多、得物下单，而且比价很普遍。定价时去搜淘宝和拼多多销量靠前的店铺，把价格放在两个平台的区间内。用户比完发现你略便宜，再加上原创视频主打“所见即所得”，通常就不会去别处下单了。

举例：拼多多榜单里一条牛仔裤39元，去淘宝搜同款、按销量排序，月销1000+的多在70-90元，也有40多元的。这时可以定59-69元，再算自己的利润率。

# 3.2.2 把链接转化率提上来

测品前，商品链接的转化率不能拉胯。以下六个方法经过实操总结，可以从这些方面提升店铺链接转化率。

1. 链接补评论。新链接补至少5条图文评价，5条图文评价的边际效果最大。找亲朋好友就能搞定；不想麻烦亲友就找老客户；没有客户积累就找微信好友；微信好友也不想麻烦，就去闲鱼发布任务。

2. SKU引导。多数链接有多个SKU，SKU一多用户容易选择困难，反而拉低转化。可以在SKU名称上利用从众效应，引导用户选你想推的那个。以脐橙为例：原始设置只列参数，没有营销信息，客户一眼看不出哪个更好，这种设置很差：

主推SKU该放前排却放最后；主推该推利润高的，却推了尺寸最小的果；营销话术也还能改进。再看合格版本：

主推放前排，方便客户优先锁定，放第三位的其实放第二位更好。第一位放店铺客单最高的，用来锚定价格：客户先看100元，再看主推80元，就觉得80不贵。除主推外，其他SKU也都有营销话术。主推前的“好评最多”可优化成“千人好评”“万人好评”，前提是销量够；销量不够就用“好评最多”。这类话术是在告诉客户：大家都选这条，闭眼付款就行。

3. 设置优惠券。先设较高的初始价，再设较高的优惠券，让客户有捡便宜的感觉。非标品尤其好使，因为没有同行参考价，你的标准就是唯一标准。

4. 用漂亮的模特。需要模特展示效果的产品，尽量用漂亮模特，越漂亮越好。比如祛痘、美白产品要展示前后对比，效果图可网上选，也可让美工合成。展示对比的模特越漂亮，转化率越高，因为客户会自我代入；模特较丑会起反效果。人都喜欢好看的东西，女性尤其希望自己更美。

5. 利用恐惧情绪提升转化。人的情绪里，有不少能用来促转化，我们效果最好、用得最多的是恐惧。比如卖儿童用品，会说“不及时纠正孩子某某行为，以后会如何如何”“同学都在用这种方法，你的孩子不用就会落后”。卖美容护肤产品，会说“不舍得花钱保养，省下的钱会被小三花掉保养”。但要记住，用恐惧是为了成交，不是为了单纯吓唬客户。

6. 用相似性包装小红书账号。店铺和笔记相辅相成，不能分开看。小红书本质不是纯电商平台，而是种草平台：用户有需求、买了产品、用得好，真诚分享给姐妹，姐妹被打动后下单。所以账号定位别做卖家，要做产品爱好者、使用者，或某个问题的解决者；这样你和有同样需求的姐妹就有相似性，能成为朋友，而不是买卖关系。姐妹更信相似的朋友推荐，还是更信商人卖货？答案很明显。

还要清楚目标用户画像和圈子里的特定术语，可以搜关键词看笔记和评论获取信息。账号性别栏有没有设为女性？笔记有没有用产品使用者的口吻推荐？记住，你在小红书的定位不是商人，而是客户的朋友，你们具有相似性。比如一个卖儿童用品的账号，人设是成长型宝妈，分享育儿经验，很容易获得宝妈信任，大家会觉得她是“自己人”，因为彼此相似。

# 3.3.1 选图文还是视频

不同品适合的内容形式不同，效果也不同。百货赛道大部分产品需要展示功能和应用场景，让消费者发现产品能解决自己的需求，所以多数百货产品更适合视频笔记。

图文笔记适合的产品类型：图片能直观让用户一眼看到亮点、展现痛点；小红书这类产品的爆款笔记普遍以图文居多（搜关键词可查）。举三个例子找感觉：
