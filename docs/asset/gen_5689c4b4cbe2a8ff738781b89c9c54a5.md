# 4.4.1 标题没钩子，正文白写

一篇内容想拿到更高的阅读量与收益，起跑线往往不在正文，而在标题：它得先给人一个非点不可的理由，把目光和注意力拽过来，让读者产生一探究竟的冲动。

真正的诀窍并不玄乎——把读者最在意的信息放进标题里，让欲望和好奇同时被点燃。

标题成不成，直接决定对方会不会点开。若读者连点开的念头都没有，正文写得再漂亮，也很难被看见；没人看，内容就等于白忙，收益自然也无从谈起。

而要把标题写好，关键在用好“开幕雷击”。

这个技巧最早由圈友 @半塘梦呓 在星球分享。他当时从微头条写作切入，讲的是怎样让开篇第一下就抓住点击。感兴趣的话，可以翻原文《半塘梦呓：如何用好开幕雷击》。

所谓开幕雷击，说白了就是：用户第一眼扫到的内容里，出现了让人吃惊的说法或画面，像突然被雷击中一样愣一下。

我反复测试后，把爆款标题里的“开幕雷击”拆成七类刺激点：一是钱和数字；二是性暗示；三是暴力；四是死亡；五是捷径；六是反常与悬念；七是民族主义。

这七类里，“反常”尤其百试百灵。而且它们并不只服务👸号——短视频、百家号、头条图文、问答、微头条等自媒体场景，都能迁移使用。只要不违反平台规则，标题里能多装几个要素就多装几个。

不少同学正文功底不差，问题恰恰出在第一击没打准；也有人把“雷击”误读成狗血、暴力、血腥，这其实跑偏了。那样做只会让读者反感，内容还可能被限流，甚至遭遇投诉、举报，最终被删除或封号。

真正的雷击，是让第一眼出现令人震惊的言论或画面，挑起好奇，让人感到反常、与日常思维相反。它不是把“很震惊”“惊呆了”直接糊上去，更不是把“某人挥刀、血溅一身”“倒在血泊中”这类场面直白摆出来；更高明的做法是点到为止，用含蓄的字眼留白，让读者自己联想。

比如：某人的家人病逝，按理说应当悲伤，可他却显得高兴。这种反常会让人忍不住点开：他为什么反而开心？

再如：小店矿泉水单买3元一瓶，10元能拿3瓶。旁人都笑老板不会算账，纷纷一瓶一瓶买，三瓶只花9元；没想到老板反而乐了。这个标题同时装了“钱”和“反常”：价格很直观，反常在于老板明明像吃亏，为什么还高兴？换作你，是不是也想点进去看个明白？

记住：不要直接渲染暴力、血腥、色情，也别写低俗小黄文。要隔着一层纱，字面别露骨，把联想交给读者。为了流量去挑战平台规则，往往得不偿失。

一个标题只要命中七要素中的两个，打开率通常就有底了；当然，要素装得越多越好。
