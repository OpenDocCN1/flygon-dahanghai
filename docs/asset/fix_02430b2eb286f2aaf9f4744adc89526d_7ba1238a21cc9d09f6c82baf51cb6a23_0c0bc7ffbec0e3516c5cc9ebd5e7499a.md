# 10.2 潮玩盲盒角色出图演示

想做潮玩盲盒质感的角色图，可以先把 MidJourney 作为起步工具。若对它的基础界面和出图流程还不熟，建议回第四章补一遍基础操作。

写提示词时，建议拆成六个槽位：画风基调、画面主角、人物特征、氛围走向、渲染方式、画质补强。把这六项按顺序填好，出图方向会稳定不少。
