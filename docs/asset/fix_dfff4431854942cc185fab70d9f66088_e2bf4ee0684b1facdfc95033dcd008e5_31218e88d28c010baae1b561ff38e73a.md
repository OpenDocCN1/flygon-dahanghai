# 零投入、三方赚：连锁餐饮折扣券的“全年折扣卡”玩法

先说一个例子。连锁餐饮品牌为了吸引顾客进店，通常会在各个渠道发折扣券。我们把这些折扣券收拢起来，用很低的批价交给微信团购渠道的推广团长。顾客通过团长下单，能以约八折价格买到KFC；团长赚到推广佣金；我们则从顾客的餐费中拿一点分成。大家都不用额外掏钱，三方都有收益。

这个生意具体该从哪里下手？

早几年，这类权益商品大多放在微信公号的分销系统里卖，用户要先关注才能购买。微信里的团购工具出现后，下单路径缩短了很多。我们做的，是把单个品牌的优惠权益组合成多品牌打包的“组合包”。组合包覆盖面更宽，大家更容易接受；销售佣金让给推广方后，我们既不用管实物，也不用处理退货，还能源源不断积累下单数量和参团人数，等于给自己装了一台免费获客机器。

顺手问一句：你平时点KFC或Starbucks，是柜台下单、扫码下单，还是打开官方App？如果有一个微信公号入口能让你享受五到八折优惠，你会不会换一种点法？

再换个角度：花8.8元，就能在很长一段时间里不限次数地享受KFC、M记、Burger King、Starbucks等连锁品牌五到八折，你会不会想掏钱？多数人会觉得很划算，因为消费一两单就把卡钱赚回来，之后全是省下的。单价低、覆盖面广，这让团购变得容易做。如果再叠加更多品牌，吸引力会更强——这就是我们要做的全年折扣卡。

## 一、先弄明白：这张卡是什么

所谓全年折扣卡，是把多家连锁快餐品牌的优惠下单入口集中到一个权益里。卖家通常标1—2年使用期限，实际做的时候，可以做到一次开通、长期按优惠价使用。可覆盖品牌包括KFC、Pizza Hut、M记、Burger King、Starbucks、瑞幸、喜茶、奈雪等，也可以按需要增加。消费者按店内原价五到八折下单，确实能省钱；卡价常见在3.8—12.9元之间。对推广团长来说，这类卡有利可图，不用发实物、不用处理退货，还能迅速提高订单数量与参团规模，所以普通用户也愿意买单。

## 二、为什么成本可以压到接近零？

[PRE3]

原因很简单：这些优惠下单的链接，是按成交分成的推广资源，通常并不需要花钱获取。有的微信公号甚至把链接放在页面底栏，谁都可以点。真正的壁垒是信息不对称：你以为路人皆知，实际还有九成用户不知道。我们做的是把这些链接整理成统一入口，加一道兑换码验证，再售卖兑换码。收益来自用户下单后的佣金，因此几乎没有采购成本。

用这种方式获取的客户，质量也比较高。过去我们也试过抽奖活动、公号广告投放等获客方法，都不如这条路精准。卡卖出去后，佣金大头给推广方，自己可以只留很少一部分，甚至完全让利，于是它成了一台免费引流设备。消费者省到钱，推广者赚到钱，我们拿到抽成，模式因此能长期运作。

## 三、订单和用户从哪里找？

早期，行业里卖的是单品牌权益卡，主要在旅行平台的分销网络里流通。比如KFC卡、Starbucks卡，平台留一两元，分销方赚六七元。这类平台一般是地方旅行类微信公号，用第三方旅游分销系统搭建；他们愿意卖，主要是为了涨粉，因为消费者从海报扫码进来，得先成为账号关注者，才能点进商品页。

2020年疫情之后，微信生态里的团购工具开始起量，其中的代表就是快团团。它不需要下载App，也不用先关注账号，靠微信里的聊天和社群就能触达大量用户。于是，旅行分销平台上的做法被搬进了这些工具。

我找推广团长的方式比较简单：在闲鱼上搜这类工具，就能看到有人出售团长名单，他们也能从中拿到返点。

## 四、成交的关键在哪？

对普通用户来说，6.6元或8.8元的门槛很低，随便下一单就赚回卡价，没什么决策压力。对团长而言，供货价只要1毛钱，加上可观的佣金空间和下单数量，自然愿意推广。

## 六、团长们最担心什么？

[PRE15]

售后是最大的坎。团长最常被问到的，是兑换码能不能及时给到、有没有空码、下单后是不是要等很久才出取餐凭证、订单会不会黄掉。我们的处理方式，是把兑换码直接交给团长，由他们发货；遇到不能兑换的，随时补发。点单环节则靠长期筛选出来的供应商，主要看上餐速度、稳定性和分成比例。早期我们吃过亏，遇到一个靠人工手动匹配的供应商，平均要等7到15分钟，高峰期能拖到半个钟头，偶尔还会失败。从那以后，我把速度和稳定放在合作的第一位，后面就顺畅很多，售后极少。

有朋友留言说，单看折扣卡和团购工具都熟悉，就是没想过组合起来用。也有人问：卖卡的钱全给团长，自己只赚佣金吗？是的，返佣比例大概6%。还有人问靠谱的权益渠道是不是难找——确实需要慢慢筛，留下上餐快、后台稳的供应商，后面就很省心了。
