# 绕了十一个月，我终于摸到赚钱的门

2019年走到尾声时，我离开检察院已经三年，存款也快见底了。回头算账，这一年在“怎么赚钱”这件事上，前前后后绕了十一个月，直到最后一个月，才终于看见一点真正的转机。

2月，我下定决心和阿里文学解约。事情要从2018年初说起：我和阿里文学旗下一个App签了约，写拆书稿。因为看书、码字还算拿手，拿到了独家合同，单篇报价6000到9000元，已经是平台顶薪。可即便条件这么好，我的稿子还是从2018年一直拖到2019年，最后只赚了几万块。原因很简单——我心里并不认同这件事。

在签独家之前，投稿期我还和平台谈过一个大单：一个月交25篇稿，每篇4000元。25这个数字是我特意凑的，为的是冲10万元。31天里，我看完25本书、写完25篇稿，确实赚到了10万。但钱到手的同时，我心里已经不想再干了。

旁人听说“月入十万”，很容易想象我年入百万。可那一个月究竟怎么熬过来的，只有我自己清楚：写完稿，后面病了半个月。那种强度的输出只是一次巅峰表现，不可能长期维持。更让我清醒的是，我算过一笔账——就算我能以这种状态硬撑一整年，扣完税也不过百万出头，代价却是随时可能倒在电脑前。有人觉得我心大，连一百万都看不上；但假设出来的极限值，和现实根本不是一回事。而且，如果连理想化的上限都走不通，那就说明这条路本身不通。

那时我心里定下一个很清楚的判断：靠单份时间反复出售的活法，没有前途。一份时间只换一份钱，不划算。那些稿子换不来名气，也换不来明显的技能增长，纯粹是在卖钱。更关键的是，看书写稿会把我整段注意力锁死，我根本没有心力再去关注外界信息，也没法做让自己增值的事。

当然，话说得再明白，人毕竟还是没见过钱。我又拖了大半年，实在找不到让自己不拖稿的办法，才决定解约。到2019年2月，我终于承认：如果只为了钱，没有别的驱动力，这件事我干不下去。这个判断，6月份又应验了一次。

4月，我加入了龙哥盟。3月那阵子我迷茫得厉害，压力也大：刚扔掉一个能赚钱的工作，又找不到像样的收入来源。很多人劝我去上班，但我觉得，还应该再硬扛一下——用存款换时间和空间，再用时间和空间换方向。一个人的现在，是他过去认知指导下的结果。既然这些人的现在并不是我想要的，我就不该照着他们的建议走。我可能暂时不知道什么是对的，但听他们的，大概率是错的。一定有一条路能走出来，只是我还没找到。

4月18日，我迫不及待进了龙哥盟，进去先把精华帖尽量翻了一遍，眼界一下被打开。说实话，我很后悔：2017年在曹大星球就见过龙哥盟，当时心动了一下，舍不得几百块钱，没加；2018年又看到，价格更高，还是没舍得。直到2019年被逼得没什么退路，才把这笔钱花出去。可里面很多东西，正是我苦苦琢磨很久都找不到方法的。如果早点加入，大概早就把几百倍入圈费赚回来了。舍不得孩子套不着狼，花钱买高质量信息，是收益最高的投入。这个道理，11月份我又体会了一次。

6月，我妈查出癌症，需要一大笔治疗费用。5月底我参加赚钱线下聚会，进了个大群，大家自我介绍，我加了不少圈友。其中一位大神夜息跟我聊了聊，说我们似乎可以合作，邀请我去南京面谈。那时我妈已经在老家查出疑似癌症，正在同济复查，等诊断结果。资金像突然被撕开一个大口子，我太需要钱了。阿里的编辑回来找我继续写稿，我接了；夜息邀我去南京，我也马上买了票。只要像是一线赚钱的希望，我都想抓住。

和夜息谈得不错。他很擅长做视频、批量操作和SEO，缺的是内容；我主要能做内容，别的并不擅长。夜息原本希望我从法律领域切入，聊着聊着，方向逐渐调整到学习考试领域。我考试还行，有自己的方法，从前也做过几年公益辅导，帮别人应对过高考、考研、司法考试、公务员考试等各种大考，战绩还可以。夜息很大度，对我也信任，给的条件挺好。我们当场谈妥，等我交个大纲，他们看过没问题，就可以开始分条写内容、录制。

可回去写大纲时，问题来了。我2004年高考，2008年考研，2009年司法考试，2011年公务员考试，最近的也过去8年了。这么多年，考试从形式到内容都变了很多，我们也从PC时代走进了智能手机时代，命题思路、备考逻辑、实操工具全都更新了。让我自己去考没问题，我可以调整；但要教别人，就不得不说很多没有经过实战检验的东西。我觉得这算骗人。

纠结了几天，我妈的检查结果出来了。我跟夜息打了招呼，先回武汉陪她看病，和医生定方案。回来后，大纲还是被我一直拖著。其实心里不愿做，但又想抓住这个赚钱机会。大概一个月后，夜息来问我。我还是不想放掉机会，决定再试一次。我讲了自己的顾忌，夜息说，就踏踏实实做那些能做的。于是我承诺期限交大纲。

可再去查一遍各种考试题目，我还是下不了手。那个问题绕不过去：新考试我没实战过，不知道自己的方法是否足够好；旧方法思路上没问题，但铺开讲一定会涉及很多细节，也一定会涉及新内容。我手头有把握的内容，能撑起一个2小时的视频，却填不满几百个小视频。想了很久，我硬着头皮去跟夜息道歉，说这件事我做不了，也讲了原因。夜息没有再回我，合作自然不了了之。

我心里愧疚了很久，觉得自己这件事做得非常不好。因为太想赚钱、太急于抓住机会，前面匆忙拍板合作，后面又没舍得及时放手。可如果只为了钱，没有别的驱动力，我确实做不了内心不认同的东西。终于，我痛下决心看清自己：以后答应的事就要做到；如果发现情况有变，要及时应对，绝不能再拖延合作方。一个人要是不靠谱，什么事都做不长久。

6月到10月，近半年我依然很迷茫。做了几个月👸号，没做起来，人反而变得浮躁。幸好及时被大黄哥和马哥提点，稳了回来。我也考虑过今日头条、B站、抖音，但都不得要领。我觉得，自己还是不太会赚钱。

加入赚钱后看了许多精华帖，学了不少新东西，对赚钱这件事比之前明白了很多，但也知道自己欠缺得更多。我逐渐感觉到，赚钱背后有一套思维、体系、步骤和细节。缺了这些，机会从眼前路过也看不见；就算别人把机会点出来，自己也不知道怎么操作；哪怕手把手教，解决了一个问题，还有更多问题。从不会到会，中间要补的是一整套东西，而不是案例里拿出来说的那几个点。我能做的，只能是一再学习、实践、改变，朝自己要的方向靠近，期待哪天把这条链路打通。

到了11月，手头钱已经不多了。再找不到出路，我就不得不老老实实去打工，停止自己的尝试和探索。这时候，转机终于来了。

先是股市终于赚到钱。我在股市几年，老是亏损，现在渐渐明白以前有多蠢：其实就是自己毫无选股和择时的能力，也不该指望自己有。我擅长的从来不是选股，而是识人。选中一个强大又可靠的投资人——他是好友的好友，过往战绩优秀，投资观念我也认可。我完全信任他的判断，买入他看好的股票，稳稳拿住，不贪心、不恐惧，盈亏自负。不是每件事都要靠自己的脑力去判断。专业的人见识高过我百倍，如果品格可信、肯对我说真话，抄作业就比自己琢磨的成功率高得多。承认自己是个傻逼，有时候事情反而会变得更简单。靠这个，最后两个月，我吃到一笔80%涨幅，又吃到一笔25%涨幅。

但这么做，还是不那么靠谱。等攒起入场费，就直接交给专业人士打理吧。A股不是我的战场，我要去做自己擅长的事。

11月下旬，我又加入另一个付费社群，看到新的赚钱路径，实操性很强。具体涉及一些不合规操作，就不公开讲了。有机会就伸手抓住吧，我毫不犹豫借钱上了杠杆。整个12月，我忙到飞起。

11月底的龙哥盟曹大闭门会，我也去了。7个小时下来，听到许多很有价值的东西。其中大黄哥讲的快手，还有半佛讲的地区税收政策，我直接能用上，可以作为盈利方向发展。迷茫了一整年，找不到靠谱项目，有力没处使；突然之间怎么就像井喷一样，抓到了一把可以做的事，只恨时间排不开。那感觉太幸福。

2020年，我打算先把能直接赚钱的项目铺开做熟，努力赚30到50万。如果能腾出手，尽早切入快手；税收政策的事，或许要等到2021年才有时间做。只要知道世上有这样的事情，总能找到机会；没有这个，也有另一个。

但以上这些，都只是赚钱的方法。我并不希望它们占据我所有的时间和精力，只是想用这些方式赚到钱，来养我真正想做、又暂时不赚钱的事情。我喜欢的，始终还是读书、码字。个人成长与影响他人，都让我由衷快乐。只是目前这一块能力还不够：既没找到巧妙的变现模式，也没攒出能自然变现的实力。两者都需要时间，而我努力赚钱，就是为了给自己时间。

有时候我也相信是有天意吧。像是上天支持我的探索，每次手头没钱的时候，就送一次续命的机会。

未来我还会继续探索，等待哪天踩出一条适合自己的路，能高高兴兴把钱挣了，以自己喜欢的方式生活。

感谢龙哥盟。在这里遇到许多良师益友，学到大量宝贵的信息与经验。也谢谢留言里给我打气的朋友。

新的一年，我会努力。慢一点也会到，远一点也能达。
