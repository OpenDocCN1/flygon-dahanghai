# 书画课怎么选、项目怎么复盘？这篇讲透

如果你正在挑书画课，或者已经跑通视频号知识付费的最小闭环，下面这些选课疑问、复盘方法和放大思路，值得一次看完。

家里如果有人也想学，完全不用重复报名：一个名额，两个人可以一起上课、一起练。

**孩子能不能学？**  
可以。课程主要面向成年人设计；如果孩子年龄偏小，更稳妥的方式是大人带着一起学。

**录播课是不是偏贵？**  
价格其实已经压到同类型课程里很低的位置。主讲老师来自央美，央美在美术圈的地位，差不多相当于综合院校里的清华；央美每年书法专业只招10人，老师既有实力也有书法天赋。这样的课程还配班级群、老师陪跑和一对一指导，基本相当于请了一位一对一老师。同类课程放到别的书院，通常要上千甚至上万元。之所以能做到这个价，是老师主动让利，希望更多零基础的人能入门，也想着把传统文化传播好——市面上不少“江湖老师”容易把人带偏，而只有真正的好老师，才能带大家走得更远。

**想学，但别的书院是直播课，怎么选？**  
不用纠结，关键看你想跟着哪位老师学。我们没做直播课，原因很实际：老师要留大量时间备课，还要定期外出写生提升自己；直播时一边看评论区一边回答，很容易打断讲课节奏，甚至被学员带偏思路。看似播了两个多小时，真正讲透知识的时间可能只有40分钟，没赶上直播、回头听回放的人会更吃力，效率也低。录播课能保证一小时里都是干货和知识点，学起来更专注。而且真要做直播课，价格也不会是现在这个水平。想和老师交流，我们定期安排直播交流时间；大家交的作业老师也能看到并点评。

**助教是什么水平？**  
助教是八大美院研究生水平，和主讲老师在一起工作，辅导作业完全没问题。

**最近没空，想下周、下半年或退休后再报名？**  
可以，等有空再学没问题。不过对普通人来说，书画既是兴趣也是一项技能，早学会就能早用上。这一批报名的书友不少，等别人都能独立完成作品了，再后悔或羡慕就不划算了。课程随时能点开，也可以先报名、先听课、先掌握方法，等有时间再动笔练，最终由你自己决定。

**书法课讲什么？**  
可以看老师的大纲图。课程主讲篆书铁线篆、褚遂良《雁塔圣教序》和二王行书，但核心是先把楷书学好，再带着大家完成从楷书到行书的过渡，最后轻松上手行书。课程安排是先学褚遂良楷书；如果楷书刚学完就直接写行书，很多人会跟不上，这也是不少书友“楷转行”卡住的原因。所以我们专门加入铁线篆来夯实基础，再写行书就会顺手很多。

**国画课讲什么？**  
同样先看大纲图。老师准备得很全，瓜果、虫草、花卉、动物、松石、翠鸟都会带着画。这门课最关键的是学习方法，它是写生课：春天出游多，遇到好风景、小动物，该怎么画、怎么构图、怎么用色、怎么把眼前景物落到纸上，都是要教的能力。报名后，生活中看到的风景可以随手画下来。还有一点很重要：无论在哪家书院报国画课，都要选好老师。国画是艺术，老师的审美和造诣高，才能带学生走得更远。

#### 5.1.2 零播放怎么诊断、怎么解决

视频播放挂零，诱因往往不止一个，可以逐项排查。

**问：拿实拍风景来测试账号行不行？**  
除非视频质量足够高，否则不建议。低质量内容哪怕实拍，也可能零播放；账号发实拍也零播，有可能是实拍质量太差。

**问：收到系统判定搬运的违规通知，账号是不是废了？**  
大多数零播账号并没有收到通知。收到通知，某种程度上说明账号还有被提醒的价值。一般把违规视频删掉，继续发新视频即可。

有的圈友突然所有账号都零播，也有的只是个别账号零播。我们推测：第一，单个账号若被高频检测出低质量或搬运内容，容易零播；第二，同一设备、同一网络、同一IP下大规模上传，且这些账号集中发布低质量或搬运视频，很容易被批量零播。

**问：用批量上传工具会不会违规？**  
判违规通常有两个前提：账号集中出现低质量或搬运内容，以及批量操作。如果批量上传的是高质量、非搬运视频，问题应该不大。所以我们并不完全否定批量工具；只是账号不多时，它省下的时间有限，没必要冒险给自己增加不确定性。

**问：被大规模零播的IP、设备还能用吗？**  
按我们掌握的信息和圈友反馈，暂时没遇到封设备、封IP的情况。也就是说，遇到零播暂时不用急着换IP或换手机，注册新号继续发即可。

零播后怎么办：如果是账号问题，直接注销账号，马上启用储备的新账号继续发；如果是选视频的问题，就提升选视频技巧。

**问：账号注销后就是全新账号吗？能马上发吗？**  
申请注销后，第一次要等7天才能完成注销并注册新号，第二次是10天。注册好的新号就是全新账号，可以马上发。建议多准备账号：旧号申请注销后立刻启用新号，避开7天等待。

**问：怎么准备这么多账号？**  
每个人可注册5个微信号、5个视频号；三大运营商各可申请5个手机号，此外还可申请注朋卡。用自己或亲友的手机号申请新微信号、视频号，再请亲友帮忙认证，很容易做到15—20个账号。

**问：账号要注销，佣金来不及提现怎么办？**  
可以把多个账号的带货佣金统一结算到同一个微信号，具体看星球贴《微信小商店带货佣金集中的操作》（感谢圈友@未来的分享）。

避免零播：手机尽量一机一号，用流量登录微信，避免同一IP下批量操作被批量零播处罚。

5.文件夹有视频但软件检测不到：测试大概100字左右；如果某个视频文件名超过255个字符（约120个汉字），会导致软件读不到该文件夹所有文件，手动改文件名即可。  
6.“当前账号已经上传完成，自动停止”：可能是设置了单账号循环、设置了总发布上限，或软件检测不到文件夹内视频（文件名超过100字或含无法识别符号）。这个软件可提前设置标题、发布间隔，批量上传、定时发布短视频。实测能省很多时间，也不影响流量。

### 6.3 引流与转化的思路

1.用一个微信号承接流量。矩阵号引流时，建议所有用户都加同一个微信号。几个账号同时引流，能大大加快成群速度。一般一个人3—4个账号，确保每天发笔记数量，一周可以开1—2期课程，统一转化。

2.一个用户可以多次转化多个课程。注册成为分销员后，系统内课程都可以分销。航海期间为了不混乱，只放了2个商品，先让大家集中精力完成至少一次转化；航海结束后会开启所有商品的分销权限。这样在必修部分书法、国画转化课的基础上，还能增加其他课程，做二次甚至多次转化。比如开隶属体验营，转化隶书课程；开莫骨画训练营，转化莫骨画课程。首次没购买的用户，可以二次邀请他参加其他体验营尝试其他转化；首次购买的用户，学期结束后也可以二次邀请他参加其他体验营尝试其他转化。

3.可以尝试自己做课程，打造自己的课程体系。做课程没大家想得那么难，不需要你具备专业知识，找到书法和国画专业的大学生合作做课即可。你需要做的是了解、参考市面上热门书法国画课，调研用户需求，确定课程形式和要讲的内容，专业部分交给老师制作。可以先从简单的单门课做起，比如楷书课、隶书课、写意画课程。做成一个课，就能提高一部分利润，再逐渐完善课程体系。缺老师资源，可以联系前面说过的分配点评老师的助理微信【4.2.1 正式开课前准备-5.获得点评老师】，他能推荐一些老师资源。当然，如果你有课程研发经验，做起来会更容易。等流量稳定了，也完全可以找有相关能力的人一起合作。
