# 人生苦短，为什么我依然推荐 Python？

在 Python 的诸多金句里，我最偏爱的一句仍是“人生苦短，我用 Python”。它出自 Python 之父吉多·范罗苏姆（Guido van Rossum）。这句话背后，其实藏着 Python 的几项长处：语法清爽、开发效率高、第三方库丰富，开发者能更快把项目交付出来，把时间省下来。

它同时也折射出 Python 社区的一种气质：用这门语言为工作与生活提效。Python 的用武之地很广，网站开发只是其中一块；到了数据分析和人工智能，它同样是很多人的第一选择。哪怕是在“搞钱”这件事上，做自动化工具也常把 Python 放在首位——视频批量自动合成、图文笔记批量生成，对 Python 来说都不算难事。

它上手简单，能力却不弱，很多人用着用着就离不开了。到最后你还会发现，写代码和写诗、写文案有相通之处：都在书写属于自己的精彩人生。

# 1.3.2 为什么这门航海课要从 AI 讲起？

先看一位圈友的帖子，标题是《一个人可以不依赖于别人，创造出一些新东西，这是真正快乐的来源》。

这位圈友不是别人，正是我们的星主亦仁。他完全不懂技术，却借助 AI 写代码、自学编程，只用 1 晚就完成了网站爬虫抓取。对不懂技术的普通人来说，这是一个很有标志性的时刻。

互联网越发展，普通人越需要编程能力：它能帮助我们更好地驱动 AI 工具，也更好地参与这个数字化世界。但编程学习门槛不低，很多人一看到就发怵。好在 AI 工具可以降低学习门槛，帮我们写代码——这也是航海项目以“AI 编程”为主题的原因。

不过，AI 生成的代码并不能直接在 AI 里运行。所以我们需要安装并配置代码运行所需的环境与工具。这正是航海手册【第二章：应用工具准备】要解决的问题：手把手带大家备好 AI 工具、Python 环境、Python 代码编辑工具，为 AI 编程打底。

想借助 AI 写出产品工具的代码，前提是掌握编程基础知识。没有这些基础，AI 写出的代码在我们眼里就像天书。因此【第三章：借助 AI 掌握编程基础知识】会带大家借 AI 学会如何学习编程、理解 Python 基础语法、建立编程思维、完整读懂产品工具代码逻辑，以及用 AI 排查 Bug。

这些编程基础都借助 AI 来完成学习，也是 AI 提示词的核心应用。它们学起来也许枯燥，却集中体现了编程思维：严谨、自动化、批量化。这些是后续用 AI 编程写产品代码的重要基础和底层能力；缺了它们，我们就很难真正驱动 AI 为自己所用。

掌握第二章、第三章的核心内容后，就进入项目实操：用 AI 编程来做产品工具。这一期航海相比上一期，除了爬虫应用，还重点加入了网站应用、游戏应用、办公提效、数据分析、营销工具等热门场景。

本期 AI 编程航海一共有六大应用场景：网站应用、游戏应用、办公提效、数据分析、营销工具、网络爬虫。它们分别对应以下章节：

# 1.4 给 AI 编程学习者的几条建议

# 1.4.1 八成问题，其实出在没细看手册

航海过程中，请认真仔细地看航海手册。手册里的每一句话、每一张配图、每一段视频讲解，以及每一次高手领航，都值得反复学习。做到这些，跑通所有案例基本就不难了。

# 1.4.2 让 AI 成为你的第一响应人

遇到问题，别第一时间想着找别人帮忙。要学会用 ChatGPT 解决自己碰到的问题，AI 是我们的核心竞争力。本次航海也主要借助 AI 辅助学习编程、辅助学习爬虫代码。

# 1.4.3 AI 降低门槛，但门槛仍在

编程是有门槛的。AI 能降低学习门槛，但不等于没有门槛。ChatGPT 是一个“遇强则强，遇弱则弱”的超级人工智能工具；能不能让它辅助我们学习和创造更多价值，关键取决于我们对知识的理解与掌握程度。

刚开始接触编程，对编程没概念很正常。所以一定要仔细学习航海手册，有了初步了解后，再结合 AI 进一步学习。这样你会越来越强，用 AI 也会越来越顺。

# 1.4.4 遇到问题是常态，别急着退场

不要碰到一点问题就放弃，也不要把“技术很难”当成逃避的理由。成长过程中，我们需要强大的探索精神和解决问题的能力，而编程就是一块很好的试金石。

这跟赚钱是一个道理：赚钱路上遇到一点问题，难道就放弃吗？不断解决问题的过程，才是成长的过程。也只有这样，我们才会变得更优秀。优秀的人，学习能力和解决问题的能力通常都不低，而这些能力都是后天锻炼出来的。

# 1.4.5 帮别人，也是在帮自己

先跑通的圈友，可以多帮帮那些非技术专业、学起来吃力的圈友。航海里其实有不少程序员圈友，也别错过这个展示自己的好机会。

你在帮助别人的同时，也在成就自己。利他便是利己，说不定在这个过程中，你会遇到事业合伙人，甚至人生贵人。

# 2.1 开工前要备好哪些工具？@乔帮主

1. 准备 AI 工具。

我们需要借助 AI 工具降低编程学习门槛，并帮我们写爬虫代码，所以 AI 工具的使用是核心。推荐使用 ChatGPT-4o 或者 Claude 3.5 来跑实战案例，国内的大模型 AI 工具满足不了我们跑实战案例的需求。

2. 安装并配置 Python 环境。

安装 Python 是为了在本地运行和测试 AI 生成的代码。AI 生成的代码不能在 AI 上直接运行，需要单独的环境来运行。安装 Python 后还要做环境配置，包括设置路径和安装必要的库，确保 Python 环境能正常运行。

3. 安装代码编辑器。

这是编写 Python 代码的工具，程序员写代码用的就是它。AI 生成的代码可以放进编辑器直接使用，也可以修改调整。代码编辑器不仅提供代码高亮和语法提示，还支持插件扩展，能增强代码编写和调试的效率。

4. 配置产品工具代码环境。

产品工具代码的运行，需要 Python 相关的依赖库或者插件驱动，这部分会在项目实战章节中详细讲解。
