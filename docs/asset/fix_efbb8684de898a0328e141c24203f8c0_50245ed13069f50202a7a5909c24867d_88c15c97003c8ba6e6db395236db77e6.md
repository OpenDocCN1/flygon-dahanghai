# 玩法二：让AI从零开始写文案

参考提示词第一组：

帮我创作一条跳绳带货文案，从用户的痛点切入，比如减脂、瘦腿、收腰。全文控制在500字以内。

具体要求：
1. 第一句用金句、故事或痛点开场
2. 说话方式亲切、利他、口语化
3. 给出可执行的具体建议，并且分点说清
4. 尽量用数据来支撑，显得更可信
5. 结尾用“我”的真实体验来分享，让人自然想下单，但表面要让人觉得是为他好
6. 不要假大空，痛点要扎心，读者看完要觉得“这就是我”“你懂我”，并产生收藏和购买的想法

参考提示词第二组：

假设你是公众号带货老手，有5年写作与带货经验，特别擅长在公众号里写爆款文章和利他型干货，同时把产品卖出去。

现在请你以“……”为主题，先想一个标题，再写一篇300字左右、短促有力的文案，带货目标为“……”。

写作要求：
1. 用一句简短又有哲理的话开头，直接切入主题
2. 来一个生动的比喻或对比，说明会说话这件事有多重要，也为后面推荐书埋下伏笔
3. 把推荐理由写清楚，让读者知道这本书对提升相关能力有多关键，尤其是针对某类人群，要足够精准
4. 内容要丰富，列举这本书的优点、对“我”的实际帮助，让读者对书有更具体的印象，从而产生想买的冲动
5. 多用能引发情感共鸣的叙述，让读者感受到读完这本书之后的收获和自信，情绪被带动起来

# 怎么把AI味去掉？这些提示词可以直接抄

补充案例：
问题：段落中只有结论，没有真实案例，说服力不足。
指令：为这段内容加入某个真实发生的例子，让结论更有可信度。

删除冗余：
问题：段落里反复出现相近信息，显得拖沓。
指令：删掉重复无用的句子，让文字更紧凑。

扩展论据：
问题：某条论据太单薄，撑不住论点。
指令：把这一论点展开，补几条有分量的论据，说服力更强。

引入对比：
问题：全文只有一个角度，观点偏平。
指令：加入一个对立的看法来做对比，让讨论更有层次。

简化开头：
问题：开头铺垫太长，读者很容易划走。
指令：把开头改短，直接进入主题，留住读者。

调整段落顺序：
问题：段落排列不符合逻辑，阅读时容易卡住。
指令：按照重要程度或时间先后重新排序，让行文顺畅。

段落分割：
问题：一段文字承载太多信息，眼睛累。
指令：把长段落切成几个短段落，阅读负担更小。

添加小标题：
问题：内容板块多，找重点很费劲。
指令：给每个板块添加小标题，结构一眼就能看清。

运用比喻和类比：
问题：表达太直白，缺少画面和趣味。
指令：在合适的地方加入比喻或类比，让文字更形象生动。

引用名言：
问题：论述没有权威支撑，说服力不够。
指令：挑一句契合主题的名言或经典句子放进去，增强可信度。

增强画面感：
问题：描述太笼统，读者脑中没有任何场景。
指令：把画面写具体，让人一看就能想到那个画面。

增加趣味性：
问题：内容太严肃，读者容易走神。
指令：适当穿插有趣的说法或轻幽默，让阅读体验更愉快。

1. AI写出来的内容一定要亲手改一遍，直接复制可能会被系统误判，影响流量。

3. 正文字数控制在10-500字，太长会让人读不到最后，进而影响成交。
4. 排版注意分段、加表情，降低阅读门槛。

# 4.3.5 商品入口的两种挂法

目前主要有两种方式可用：第一，在图文区域加入商品卡；第二，内容火了之后，在评论区放购买引导。

以前大家几乎都用第一种，但最近有圈友反馈，内容里带商品卡的图文流量不太乐观，于是很多人转向第二种——先做一条干净的热门内容，等数据起来后再在评论区卖货。平台规则随时可能变，两种思路都可以多试试。

第1种：正文里放商品链接

操作思路是：优质图文+引导转化的话术/表情包+商品卡。

电脑端流程：按照【2.2.2 选品操作流程】完成选品，接着从公众号后台进入图文编辑页，打开橱窗，选中商品，插入正文。

# 5.1 发文很多阅读却停在个位数，问题出在哪

阅读上不去，通常绕不开这四个原因，可以逐项优化：

# 数量没堆够
小绿书本质上是在用数量对冲概率。如果还没写满30天（至少150篇），先别着急抱怨，继续发下去。

# 封面不吸引人，点击自然低
一般情况下，一个新号在当前机制下能获得约100-200的初始曝光，但曝光量不等于阅读量。如果封面没有抓力，点击就会很惨。
举个例子，有篇笔记的初始曝光超过2000，点击只有22（点击率0.81%），主要问题就是封面不够吸引人。另外，图片清晰度不足也会直接影响点击表现。
封面具体怎么改，可以反复研究【4.1.2-1 封面拆解】。

# 阅读完成率不理想
有公众号经验的人都知道，读完比例非常关键，小绿书同样如此。润宇老师说：“图文本身比较短，阅读完成率基本要做到40%-50%以上。”
想提升阅读完成率，核心是控篇幅。如果只有一张图，正文尽量别超过800字，更推荐控制在10-500字之间。小绿书是图文，不是长文章，写太多没有几个人能耐心看完。
还有一个细节要提醒：有人为了让商品曝光更多，在图文里密集插入商品图，每隔两三段就弹出一个商品卡，这种做法相当影响观感，反而会适得其反。

# 平均阅读时长不够
真正的爆款，平均阅读时长常常能到1分钟以上。想拉长这个指标，可以在封面图和其他图片右下角加上“向右滑，看更多精彩内容”这类提示，引导用户不断翻阅。

以上四点都做到了，再观察发送后的互动反馈。目前小红书的互动数据比较公开，小绿书还没有完全开放，不过润宇老师给了一个参考公式：评论>分享>点赞>在看。

# 5.2 笔记爆了却没订单，先检查这两项

① 选品本身没过关，没有按照“实用+特色+猎奇”的标准来挑商品
② 商品和文案之间缺少连接，卖点没有清晰传达

先说选品。新手想走捷径，最快的方法是照热门爆文的品类来选，参见【2.3.3 选品推荐】。想获得更长线的能力，还可以去翻《6月航海 | 视频号带货 | 实战手册》第2.1节和第2.2节，那里讲了选赛道和选品的方法。

再讲卖点表达。不少人习惯用公众号流量主爆文的思路写内容，再随手挂一个商品，这种做法大概率卖不动；要么就是商品与图文内容关联度太低，同样很难激发购买欲。

看一个反面案例：作者选的商品本身就不够热卖，图文内容又与商品使用场景脱节，卖点也没有刻画出来，读者自然没有想要的感觉。

# 六、带货佣金怎么提出来

手机端打开“创作者中心”，就能找到数据看板。需要特别留意的是，数据看板里“今日数据”显示的是销售额，并不等于你的实际佣金。

[PRE16]

进入【带货中心】-【佣金】-【收款明细】，可以查看待打款与已打款的记录；点击【订单详情】，能看到订单状态和结算状态的佣金。佣金支持人工提现，提现会收取1%服务费。

另外，在【带货中心】-【佣金】-【订单详情】里，能够查看全部带货订单，点开任意一单，订单状态和结算情况都一目了然。
