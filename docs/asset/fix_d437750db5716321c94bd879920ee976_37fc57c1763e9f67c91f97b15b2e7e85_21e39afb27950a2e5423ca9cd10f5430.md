# 【新增】09.借势热点做二创

运营AI视频账号，绕不开追热点这件事。玩法迭代快，生命周期长短不一：短则十余天，长则一两个月。手册落笔时算新玩法，等航海开营，可能已经过时。新热点对应新的流量入口。先入场者占便宜，后入场者分残羹，再晚可能连汤都喝不上。这只是打个比方，真实情况有幸存者偏差。等你把制作流程练熟，就该琢磨怎样蹭热点，做出新鲜有趣的内容。

需要权衡的点不少，先解决两个核心问题。

1.哪些热点适合追，哪些要避开？

下面列15个近期话题，你可自行判断：赵露思、罗小黑战记、捕风追影、ASMR、碳烤labubu、生万物、浪浪山的小妖怪、抗战胜利80周年、秦始皇骑北极熊、人民校长、萌宠吃播、黑神话钟馗、蜜雪冰城、南京照相馆、labubu。

适合追的：罗小黑战记、捕风追影、ASMR、浪浪山的小妖怪、生万物、秦始皇骑北极熊、人民校长、宠物吃播、labubu。
不建议碰的：赵露思、碳烤labubu、抗战胜利80周年、黑神话钟馗、蜜雪冰城、南京照相馆。

概括一下：影视剧、动漫、抽象内容、潮流和各类梗，都可一试。其受众大致是28—35岁的青年，男女比例约3:7。相反，明星话题、冷门热点、敏感议题，不宜拿来二创。它们或许能带来更高关注，但风险也大，可能没流量、被限流，甚至封号。
