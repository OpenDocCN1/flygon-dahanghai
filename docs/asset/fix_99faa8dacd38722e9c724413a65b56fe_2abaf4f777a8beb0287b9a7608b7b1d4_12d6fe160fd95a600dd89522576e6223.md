# 达人合作三关：费用算清、条件谈透、阵型选准

先看一笔合规报备的账：假设创作者单条视频报价1万元，品牌结账时实际掏出1.1万元，多出的1000元来自平台按一成抽取的佣金；创作者侧也会被扣一成，实收9000元。合起来看，平台在这一单拿了两成，供需两端各承担一成。

## 非报备内容：更灵活，也要防风险

所谓非报备内容，指品牌与创作者绕开平台、私下敲定的推广合作，通常把产品体验、测评或使用感受软性植入图文、视频中。

优势：一是创作空间不受限，呈现方式更多样；二是预算门槛通常更低。

短板：一旦被平台怀疑是营销推广，可能被提示整改、删帖、限流或不予收录；私下打款结算，也存在交易风险。

因此品牌不必二选一，两条路都该走：非报备胜在灵活；报备则像向平台交了一笔“合规成本”，账号不容易被直接处理。

#### 9.3.3 对接创作者：先摸诉求，再锁条件

联系到创作者并说明意图后，下一步就是具体对接。此时要围绕双方诉求，在敲定合作前把条件、细节逐项确认，防止后面扯皮、拖累效果。

第一步，把合作条件聊透。

沟通过程要清楚、高效，也要给对方足够尊重，让对方感觉双方站在同一侧：一起把内容做好，而不是投完广告就收工。

这个阶段要摸清创作者真正在意的点，例如报价期望、风险如何规避；同时把价格、需求简报、审稿环节、注意事项逐条敲定。

比如图片授权，合作前就要说好：若内容数据爆了，品牌能否把图片拿去用于电商主图、详情页。若事先不讲，部分创作者事后可能不授权。

细节怎么逐项落实？可翻阅3.7（达人建联）至3.9（合作前确认清单）。

#### 9.3.4 推进过程：里程碑对齐，稿件审核不松

合作启动后要有节奏地推进：锁定关键里程碑、确认核心需求、追踪内容进度、审阅稿件。

### 9.4 达人投放的三类主流阵型

#### 9.4.1 五角星阵型：目标为锚，垂类打透

五角星阵型从投放目标出发，不按粉丝量级设限，围绕垂类内容精确覆盖目标受众。

它更适合刚起步或体量偏小的品牌搭建种草投放组合。

[PRE3]

#### 9.4.2 金字塔阵型：层层向下扩散

金字塔阵型遵循传播扩散逻辑：顶层由明星造势，头部KOL与知名创作者带话题，中部腰部创作者做专业测评与种草，初级创作者铺开垂直扩散，素人、路人跟风模仿，层层向下串成完整传播链路。

它更适合处在成长阶段的品牌搭建种草投放组合。

[PRE4]

#### 9.4.3 橄榄型阵型：押注高性价比腰初部

橄榄型阵型顺应平台流量分发规则，把预算重点放在性价比更高的腰部与初级创作者身上。

它更适合处在成熟阶段的品牌搭建种草投放组合。
