先把底线说清楚：个人若参与加密货币买卖，财产权益得不到法律保护。谁若披着Web3外衣去做洗钱、赌博、传销、非法集资、网络诈骗等传统金融违法勾当，依旧会依法处理。另一个现实是，token的法律身份仍缺统一界定，具体案件涉及加密资产纠纷时，有地方法院将其视为合法标的，也有法院判定为不合法标的。

【税收监管】
当前税收监管重点在联盟链，加密货币暂未纳入。

# 欧盟：开放创新，规则友好

2020年9月，瑞士议会通过《区块链法》。在瑞士法律框架下，加密货币交易、交易所运营等Web3业务具备合法性。卢加诺市更进一步，比特币、USDT等稳定币以及当地发行的代币，都能像法币一样用于日常消费。受瑞士带动，欧盟整体对Web3和加密资产态度开放，政策也较友好。

欧盟当前政策大致如下：

【定性】
token被当作合法财产。

【金融监管】
加密资产可能落入证券、货币、基金、虚拟货币四类，分别有对应法规；不同国家和地区还会要求相应金融牌照。

【税收监管】
币与法币互换原则上应纳税，但目前按免税优惠处理；挖矿等服务在各成员国有差异。

# 韩国：力推数字资产合法化

韩国是全球重要的加密交易市场，热度很高。2021年初，韩国设立2237亿韩元的元宇宙生态发展基金，用于搭平台、育人才。全球知名稳定币项目LUNA和UST也出自韩国。不过，接连爆雷促使政府收紧监管。尹锡悦新政府计划在2023年推出《数字资产基本法》，对加密资产实施统一管理。

【定性】
虚拟资产，不是法定货币，可合法持有和交易。

【金融监管】
ICO被禁；交易所可合法运营，但须政府审批注册，用户要做实名认证，方便监管。

【税收监管】
2023年1月1日起开征20%资本利得税。

【金融监管】
金管局向达标企业发牌，允许合规加密业务开展。

免征商品和服务税。

# 8.3 Web3安全合规：隐私与监管的两条路

面对合规，Web3有两条路线。一条强调完全去中心化，认为任何资产都可自由流转，个人产权和隐私优先；另一条是合规路线，认为去中心化也要受监管约束。由此产生两类公司：一类主打隐私和去中心化，保护个人隐私与资产安全；另一类服务监管，帮政府解决合规难题。

隐私派代表Tornado提供链上资金混合器：用户把资金存入后，第三方很难追踪相关交易，转账等金融行为的隐私得到保护。以太坊创始人V神给乌克兰捐款时就用过它。但2022年8月，美国对Tornado实施制裁，禁止美国个人或实体为其协议提供服务，也禁止与相关以太坊钱包地址交互。美国制裁通常针对涉及外国政权、恐怖分子、国际毒品走私、大规模杀伤性武器扩散，或威胁美国国家安全、外交政策、经济的行为。可见这类隐私工具很容易触碰主权政府监管边界。制裁后，相关Web2和Web3公司也停止与Tornado往来。

监管派则直接服务政府需求。例如Elliptic（https://www.elliptic.co/）做链上反洗钱与制裁合规分析，提供钱包扫描、交易监控、调查等服务，Coinbase这类大型交易所是典型客户，其他需配合各国监管的项目也是主要服务对象。国内代表欧科云链提供“链上天眼”方案，配合公安侦破案件。希望这部分能帮你初步了解各国监管，并形成自己的独立思考。

# 9.1 先弄懂：你赚的到底是什么钱

做生意或投资，若不知道赚的是什么钱，韭菜就是自己。参与Web3，收益大致两部分：一是金融层面的先发优势；二是商业价值层面的增长回报。

先说金融层面。很多人看不懂比特币、以太坊，根子在对“价值”和“金融”概念不清。把下面六个问题想明白，答案会浮现：货币解决什么问题？黄金为什么有价值？金融解决什么问题？当今世界货币有哪些用途、解决什么问题？Web2发展赚的是什么钱？比特币和以太坊各自解决什么问题？

我的理解是：没有货币前，事物价值缺少量化标准；货币定价后，有形无形、有用无用之物都有了价格。人们反而更容易对无形、无用之物达成共识。几千年前没有货币，黄金充当货币，解决的是以物易物难题：我拿闲置斧子换你的牛，但并非所有人都需要斧子；黄金出现后，人们愿意接受各类物品与这种金属兑换，黄金因此有了价值。它能胜出，是因为稀有、数量有限、稳定、恒久、便携、可分割，符合人性。

资产本质是什么？货币本身成为商品，就是资本；把货币当稀缺资源，就能生出金融产品。给风险定价叫保险和期货，给企业定价叫股票或债券，给房子定价叫房产。被货币定价后，稀缺资源就成了资产。金融产品通过借本生息提高社会资源配置效率：闲钱进入金融机构，机构以利息借出。这个模式一旦出现就很难消失。

货币铸造权被中心化政府掌握后，除了定价，执政周期有限也决定政府大概率用通胀刺激经济。新货币产生，最初使用者受益，最后使用者受损，普通人不易察觉。通胀是双刃剑：好处是经济繁荣加快，弊端是劳动价值被稀释。按货币定义，你原有1000元，印钱后多给你100元，直觉是赚，实际相反。上一波互联网，钱从美联储印出，经华尔街金融机构分发全球；很多互联网公司不赚钱也能多倍估值上市变现，因为市场钱多，本质是货币击鼓传花，这也是过去两年垃圾互联网概念股暴跌的原因。

Web3.0的源头，比特币和区块链技术，点对点电子支付系统，解决的就是主权货币弊端，仅此而已；以太坊是把金融理念用到其他体系的平台工具，细节不展开。若把比特币类比黄金，当比特币总市值等于黄金总市值，价格是多少？有文章估算约50万美元一枚，现在不到2万美元，约25倍空间。若把加密资产按美元M2类比：世界银行2021年统计全球GDP接近100万亿美元。

再看商业创造价值。我们赚的是Web3生态中快速增长、持续产生利润的公司的增长回报。什么商业活动创造价值？生产和创造可以，因为它们解决人类问题、提高效率。互联网把信息流动成本降到几乎为零；Web3.0把资产信息成本降到几乎为零，是互联网变革最后板块。至今互联网主要提高信息网络效率，未提高价值网络效率。这样的赛道里，细分领域一定会有百倍以上增长机会。价值创造后，货币会标记价值，表征就是盈利。

判断公司，可问：为谁提供什么产品服务？收谁的钱？收多少？在客单价、人群规模、转化率、复购率、转介绍率、毛利率上是否有长期优势？答清楚，无论在Web几都是好公司；答不清，在Web几都是垃圾公司。比如币安，虽是交易所，本质和腾讯没区别（赌场和游戏运营本质相近，结果都是高毛利润）。毛利润高，做平台，更多用户使用，更多项目在平台发售，形成生态垄断，并投资更多生态初创企业；其商业模式是典型双边市场。活动上得到数据：Web3全球开发者月活不到2万；国内投资活跃用户估计不到20万；全球用户几百万（从V神粉丝数也能看出）。相对全球互联网用户，增长空间巨大。像币安这类模式跑通的公司以后一定出现。这类公司不发股票，只有Web3世界自己共识的token，即加密资产。目前Web3仍非常早期。

# 9.2 入局方式一：创业

想做大的互联网创业者，最好参考VC判断：VC看赛道，创业者做经营，专业人做专业事。VC视角里，Web3.0是重点关注方向之一，要在有钱的地方创业。具体切入点要结合兴趣和比较优势，因人而异。从Web3演进架构看，与Web2无差别：底层公链网络、基建、应用层；技术型或市场型创业者都能找到位置。

我自己对投资感兴趣且有积累，长期理想是做一家Web3的伯克希尔；短期在内容营销和知识付费社群有积累，就从Web3投资社群起步，解决大家入门Web3的痛点，把Web3社区RichDAO的投资入门训练营和投资俱乐部变现跑起来。小伙伴可能没意识到，我们在龙哥盟里已潜移默化积累了一套知识付费商业技能，这是比较优势。在Web3，我发现赚钱伙伴商业化和社群运营能力很强，这是龙哥盟给的优势。对各类从业者赚钱方法感兴趣，可看文档《币圈赚钱的十八般武艺.pdf》，基本概括目前Web3主流赚钱方式。

真正适合创业的人极少，可能由基因决定。喜欢创业的人，往往有冒险、不循规蹈矩、不安于现状的基因。马云给湖畔大学第一期创业者上的第一课是如何面对失败；优衣库创始人写过《一胜九败》。创业本身就是不断失败构成的商业活动，与Web几无关。创业者天生有面对失败的乐观精神。因此要不断审视、识别自己属于哪类人。

Web3创业机会：每个发展阶段都有阶段机会。Web3从比特币、区块链技术诞生，到以太坊去中心化应用平台，再到最近公链、游戏、NFT等大爆发，某种程度是时代产物。万象区块链董事长最近演讲判断：基建层逐步完善，应用层将迎来大爆发。我比较认同。这个阶段，底层公链网络和交易平台已形成垄断效应，头部梯队手握大量资金，新入局者只要冒头就可能被收购；头部公司已做得很好。底层网络搭好后，基础建设层和应用层都有机会拿到大结果。去年公链和游戏赛道爆发的团队并非一蹴而就，而是提前埋伏深耕两三年；同理，现阶段各类基建和应用有非常多创业机会。后来者完全可能通过现象级应用切入，甚至因手握流量反攻底层公链、进行颠覆。到目前为止，Web3网络演进与Web1、Web2无差别：从底层协议到基础设施，后来Web2借移动互联网迎来应用层大爆发。Web3会被什么引爆应用层大爆发？价值网络能力百倍提升？VR、AR还是其他？不知道。从人性底层看，社交、游戏是刚需，任何时代都需要，但以什么形式颠覆，不知道。这正是增长中行业的魅力，让人期待。
