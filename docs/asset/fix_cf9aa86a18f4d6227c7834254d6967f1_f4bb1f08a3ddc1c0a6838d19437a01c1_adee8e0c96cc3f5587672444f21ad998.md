电商做图，常常要在现成图片上继续加工：给模特换衣服、换场景、做风格化……这些都指向同一个能力——图生图。下面从最常用的节点和操作讲起，带你从零跑通。

“改图”在电商实操里几乎躲不开。图生图的好处是：原图的结构还在，但风格、背景、细节可以大改。本章要掌握的内容包括：

1. 图片读取与编码：把原图送进 ComfyUI，再用 VAE 编码器转到潜在空间。
2. 噪点/降噪参数：决定原图细节保留多少；数值越小越像原图，越大改动越明显。
3. ControlNet（可选）：想控姿势、控骨架时用它，也能配合预处理器做线稿、深度图。
4. 图像缩放与对比：适配尺寸，或者做前后效果对照，方便调试微调。

学完之后，你能把一张已有图交给 AI 做局部修改或风格转换，用“图生图”完成创意二创，满足商品展示升级、风格统一等需求。

先打基础——在 ComfyUI 里怎么搭图生图工作流。它的用途很广，比如：

# 3.2 用 VAE 编码搭桥

图读进来后，AI 还得能识别它。办法是把图片转入潜在空间——也就是 K 采样器干活的地方。桥就是 VAE 编码器。

做法：搜 VAE Encode，把这个节点加进来。

连线思路：从 Load Image 的输出拉一条线，落到 VAE Encode 的图像入口；VAE 模型接到它的 VAE 插槽（默认模型够用，也可换成自定义模型）；再把编码后的 Latent 送给 K 采样器的 Latent 口。

原理不复杂：图片由像素组成，处在像素空间；经过 VAE 编码会被压到潜在空间，K 采样器才处理得了。

[PRE6]

到这一步，基础工作流就成形了。你会发现，文生图里的“空 Latent”节点在这儿没用了——因为现在用的是上传图，不需要再设尺寸，所以可以直接删。

[PRE7]

删掉“空 Latent”后，还想批量出图或者调尺寸怎么办？别急，ComfyUI 很灵活，都有对应解法。

# 3.3 一次多出几张

想做批次生成，可以加一个新节点：搜“复制 Latent 批次”。

[PRE8]

连线：VAE 编码的 Latent 输出接到“复制 Latent 批次”的输入；它的输出再送到 KSampler 的 Latent 口。

参数：批次大小填 2、3、4 都行，想出几张填几张。

拿花生图跑个例子：模型选“maiju v7 麦橘写实。safetensors”，正面提示词写“A kitten sitting on the table”，负面提示词用“easynegative”（直接输入即可），步数 30，CFG 5，采样器 DDPM++ 2M SDE，然后生成看看。

# 3.4 降噪才是关键

降噪滑杆藏在 K 采样器面板里，它直接决定生成图和原图有多像。

[PRE11]

范围是 0 到 1。

规律：越接近 1，AI 自由发挥越多，跟原图差得越远；越接近 0，越像原图，原始特征保留得越多。

把降噪调到 0 试试。

[PRE12]

几乎就是花生本尊。

再把降噪调到 0.5 看看。

这时画面开始抽象了，像是花生本体和提示词各掺了一半。

一句话：降噪是图生图的核心开关。想保住原图就调低，想大改就调高，按需求来。

# 3.5 改尺寸

想把图片变成正方形？用“图像缩放”节点。

节点：搜 Image Scale。

位置：夹在“加载图像”和“VAE 编码”之间。

参数：缩放算法默认第一个；裁剪方式选中心（center），以中心为基点裁；尺寸比如设成 512×512。

# 3.7 进阶：角色风格转绘

如果想变化更大、又保留人物形象怎么办？比如让“花生”换个画风，但姿势不动。这时就该 ControlNet 上场了——它能在结构不变的前提下调整风格。

步骤：

1. 加载 ControlNet 模型。添加“ControlNet 应用”和“ControlNet 加载器”。用 ControlNet 需要额外模型，所以加载器不能少。

[PRE17]

在加载器里选 lineart 模型。应用节点里的“强度”和 K 采样器的降噪类似：0 到 1，越高差异越大，越低越像原图。

[PRE18]

这里这样调：ControlNet 应用强度 0.8，降噪 1。

2. 预处理图像。还需要一个预处理器来勾线条：搜“Lineart 预处理器”。把 Load Image 的输出接到预处理器的图像入口。分辨率默认 512，也可调到 768 或 1024；粗糙化默认禁用。想预览处理效果，可以加一个“预览图像节点”。

[PRE19]

3. 连节点、选模型。接着给“ControlNet 应用”接线。

[PRE20]

让 CLIP 文本编码（正面+负面提示词）流向 ControlNet 应用，再流向 K 采样器。然后选大模型：Samaritan 3d Cartoon 3d 卡通-SD1.5.safetensors。

# 本章速览

前面已经拿下文生图和图生图，这一章把它们组合起来，落到电商最常见的 5 个场景：模特换装、商品换背景、商品试用图、模特换脸、视频换脸。

# 4.1 模特换衣

# 4.1.1 先搭基础骨架

动手前，先准备两张图：

一张用来换装的服装图（[PRE28]）；一张模特图，也就是要穿上那件衣服的人（[PRE29]）。

下面先搭最基础的框架，再一步步加节点。

# 4.1.1.1 读入两张图

先把衣服图和模特图都用 Load Image 节点读进 ComfyUI。这样就有了原材料，后面的操作都基于它们展开。

节点：Load Image。

做法：添加两个加载图像节点，分别放模特图和衣服图。快捷键 Ctrl+C、Ctrl+V 可以复制节点。

[PRE30]

# 4.1.1.2 尺寸对齐

两张图尺寸不一致（模特是 9:16，衣服是 4:3），所以要用“图像缩放”节点统一尺寸。

节点：Image Scale。

[PRE31]

做法：先加第一个缩放节点，参数这样设——宽度 1000，高度 1000（看显存调整，显存低可设 512×512）；插值选 Lanczos（可选，默认也行）；Method 选 proportion，保持宽高比；其他条件、乘数用默认值。再复制一份缩放节点，确保两张图和后续蒙版尺寸一致。模特图、产品图都接上缩放节点。

注意：尺寸一致是局部重绘的关键，否则会报错。

[PRE32]

如果想把两张图放同一张画布做对比，可以用“图像连接”节点：图像 1 接衣服图（缩放后），图像 2 接模特图（缩放后）。这样预览时左边衣服、右边模特，后续处理和对比都方便。

[PRE33]

可以拉一个图像预览看看效果（演示视频：20250311-142635.mp4【在线播放】）。

# 4.1.2 画出替换区

目标很明确：只给模特换衣服，脸、头发、背景都不动。最直接的办法，就是做一张只覆盖衣服区域的蒙版。

1. 回到模特图的加载节点，右键→“在遮罩编辑器中打开”（Edit Mask）。
2. 用笔刷在模特图上涂要换的衣服区域。白色代表要改，黑色代表保留；不用涂得特别精细，稍微溢出也没关系，InPainting 会做环境融合。

（演示视频：3月11日.mp4【在线播放】）

[PRE35]

3. 点 Save 保存，就会得到一张和模特图同尺寸的蒙版图。

[PRE36]

涂好之后，还得把遮罩尺寸统一。你可以把遮罩当成一张单独的图，分辨率必须和原图一致，否则后面会报错。

怎么处理？还是用“图像缩放”节点。复制一个缩放节点去接遮罩——很多人会发现，遮罩是绿色圈，图像是蓝色圈，根本连不上。

[PRE37]

这时要加一个转换器：“遮罩到图像”。通过它，遮罩就能接到图像链路上了。

# 4.1.2.2 黑底与蒙版合并

接下来，要把图片翻译成 AI 能理解的语言。

在 AI 的世界里，黑色表示不改，白色表示要改。所以还得对蒙版图做一步处理。

步骤一：创建黑色“纯色图像”（Solid Color Image）节点，颜色设为黑色（#000000）。右键该节点，把高度和宽度转成输入参数。这样可以把前面的图像节点接到黑色图像上，让尺寸保持一致。

步骤二：合并处理后的图像。创建一个“图像连接”（Image Combine）节点，把加了黑色蒙版的模特图和应用了纯色效果的衣服图接进去，完成合并。

[PRE40]

预览一下：如果左边是黑、右边是衣服区域的白色蒙版，就说明操作成功。
