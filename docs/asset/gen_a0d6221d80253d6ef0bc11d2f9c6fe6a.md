# 学霸笔记引流，家长后端变现

在抖音卖教辅，真正跑通的思路，往往不是只盯着那几本笔记，而是把笔记当成入口，顺着家长的需求继续往下做。

**为什么这个品容易起量**

衡水中学在全国家长圈的认知度很高，名校背书强，天然容易吸引中学家庭。承接方式也灵活：既可以导到微信做私域，也可以在抖音精选联盟直接卖《衡水重点中学学霸笔记》。把引流品、基础资料、周边衍生和高客单服务串起来，一个商业闭环的雏形就出来了。

**这个赛道适合长期做**

每年都有新一批学生和家长，需求不会断；品类也能扩，除了学霸笔记，还能做英语学习资料、教辅书等。只算资料变现，单账号一个月几千到三万；如果视频或图文爆单，收入还能往上走。想放大，可以买实物笔记自己拍，做多账号矩阵。

**真正值得重视的是后端**

高考志愿咨询和职业生涯规划就是一条线：普通咨询几百元起，一些城市的高级咨询师收费能到数万元，月收入从几万到几十万，最高有90万的案例，同时还能给咨询业务引流。

学生心理健康也是强需求：厌学、抑郁并不少见，学校通常只配一到两位心理老师，预约的家长很多，老师长期超负荷；情况严重时会建议家长去校外找专业心理医生，医院心理科住半个月花费一万多。这里既能给心理咨询师导流，也能合作打磨心理咨询交付SOP。

另有高考志愿填报卡，成本几十元，售价300到1000元；出国留学项目、暑期两周研学项目也可承接。
