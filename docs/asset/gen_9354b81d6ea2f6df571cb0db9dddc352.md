# 账号定位：越垂直，越精准

做账号，底层思路就三个词：垂直、精准、细分。

找定位，说到底是在找目标人群：你想让谁看、内容拍给谁。比如做青年旅游，瞄准18—28岁年轻人，就把IP包装成这个群体偏爱的样子，发他们可能来咨询、下单的内容。

确定细分领域后，IP包装和内容都要围着这类人转。以西安亲子游为例，后端能承接成交，IP可塑造成“爱遛娃的宝妈”这类人设，内容就发宝妈想看、容易被种草的东西。

在小红书，不管做哪个领域，定位都要收窄到垂直细分，转化才更精准，变现才更稳。

#### 3.2.2.2 账号门面：让用户一眼看懂你

账号包装，相当于开店前先装修门面。原则是简单：比如做云南旅游，头像、昵称、简介都围绕云南展开。

用户关注一个博主，很少只因为一篇爆款笔记。他会进主页，看昵称、头像、简介、背景图，也看之前发过什么，再决定关不关注。所以主页展示很关键，既影响关注度，也在一定程度上影响用户是否愿意买你的旅游产品。

对博主来说，资料补得越全，平台越容易给账号打标签。标签清晰后，笔记拿到的流量更精准；流量精准，点开笔记的人更多，浏览量等数据上去，账号权重也会逐步提高。

下面从昵称、头像、简介、背景图、主页排版拆开讲。

**昵称**

昵称是用户认识你的第一步。用户先通过它判断你是谁、做什么。常见问题是太含蓄、太个性，用户看不出你的业务，甚至看不懂。好昵称要能用关键词带来搜索量。

可直接套用的模板：

- 名称+地域+身份：云南导游XX、西安定制师XX
- 名称+地域：XX带你游云南、法国XX爱旅游
- 名称+类目：XX爱旅游、XX的旅行日记、XX环游记
- 个性+昵称：不油腻露营大叔、大漂亮的遛娃日记

总之，昵称要直接体现定位，让用户一眼知道你能提供什么。注意：个人号昵称要体现“人”的行为或定义。别把昵称设成大品类，如XX旅行、XX定制游、云南旅游、XX周边游；这类名字缺个人属性，而且通常只有企业号才能申请。

**头像**

头像可以用文字形式，也可以真人出镜。文字头像和昵称配合，让用户一眼看懂业务；真人头像能拉近距离，显得真实，信任感更强。做IP人设的账号，尤其建议用真人出镜，也可以用昵称或地域元素做头像。

不少人爱用风景照。风景虽和赛道相关，但只有景、没人、没地域名，辨识度和记忆点都弱，不建议。

**个人简介**

点进简介的人，通常是从某篇笔记进到主页，想多了解你。所以简介很重要，往往是用户决定关不关注的重要依据。

好简介要回答：你是谁、做什么、为什么值得关注、能给TA什么。

示例：

1. 我是谁、做什么、能提供什么：在新8年司导、私人订制行程、本地跟团、新西兰旅行服务团队
2. 专业背书：新西兰旅游协会TAANZ会员
3. 差异点：专注高品质纯玩、累计服务5000人+，包括陈道明、靳东等明星

排版上，3—4行最佳，短句为主，适当放数字。

简介还要注意违规点：可以单独写私人订制、定制游，或专注XX旅游；不要写“提供私人订制服务”“专注私人订制旅行”等，我们实测这些容易违规。

**背景图**

背景图可以放和产品、人设、场景有关的内容：

1. 用文字写清你能提供什么服务；
2. 放好看的标志性景点，做哪个目的地就放该目的地景点；
3. 放真人出镜的旅游照片，注意美感，别太拥挤；
4. 放线下旅行社门头照片；
5. 发一些类似朋友圈的生活、旅游打卡，尽量与IP领域相关，用来拉近距离。

**主页排版**

笔记封面要体现你的风格和特色。整体风格统一，色彩协调，不要杂乱。封面可以调整优化，但别一天一个样。

## 3.3 发出第一篇小红书引流笔记

💡 **本节目标**

这一节带大家完成第一篇小红书笔记的发布，也是项目的重要节点。关键任务包括：

✅ 弄清所选线路产品的资料
✅ 学会搭建素材库，并在后续持续更新
✅ 跑通小红书旅游笔记从制作到发布的流程

想练到10分钟产出一篇笔记，前期练习少不了。熟能生巧，爆款自然水到渠成。

[PRE6]

### 3.3.1 先定要引流的线路产品

前面已经选好旅游目的地。一个目的地往往对应多条线路产品，所以写笔记前，要先确定具体推哪条产品。可以只选1条线路来写，也可以选多条做成合集。

### 3.3.2 把线路产品信息吃透

动笔前，先通过旅行社给的路线资料学习；更多资料还可以去携程、途牛、百度等渠道查。

散拼团需要了解这些信息：

1. 线路会玩哪些景点？
2. 这些景点各有什么特色？
3. 散拼团什么时间发团？
4. 几点集合出发？
5. 团队上限多少人？
6. 价格多少？成人和儿童有什么区别？
7. 有没有自由安排时间？
8. 有没有导游讲解？
9. 是否提供接送？

### 3.3.3 搭好图片与景点文案素材库

做旅游赛道，素材库很关键。一篇笔记最基础的内容，就是景点介绍文案加景点图片。比如做西安散拼团，笔记必然会涉及线路里的景点、不同玩法，再配上相关图片。

所以前期查景点资料时，就可以同步整理进文件库。后面写笔记直接查、直接复制粘贴，不用每次再百度景点介绍、玩法，省下大量时间。

**文案素材**

比如做西安散拼团，产品有华山一日游、兵马俑一日游，就分别建“华山一日游”“兵马俑一日游”文档，把景点相关信息整合进去。像华山文案介绍、华山有哪些玩法、西上北下和北上西下有什么区别，都提前搜集整理好，后面写笔记直接套用。

**图片素材**

除了文案，图片归类也很重要。一个目的地景点很多，每次发笔记都要给相关景点配图，临时找很费时间。最好的办法是：一次性整理，或者每次看到好看的相关景点图，就立刻放进对应景点的图片文件夹，下次直接上传。

图片可以分两层：一层按景点分类；另一层按每个景点涉及的餐饮美食、景点景色、酒店住宿、体验活动/游玩项目、用车情况等分类。

### 3.3.4 笔记创作与发布的标准流程

怎么写小红书优质笔记？关键是知道用户喜欢什么。现成的爆款笔记，就是用户偏好的直接体现。找对标、拆爆款，是想在小红书快速起号必备的能力。

**第一步：找到爆款对标笔记模板**

1）怎么找对标笔记？

- 搜领域关键词：比如做“华山一日游”，就在小红书搜索框搜相关词，从主页出现的笔记里筛选适合对标的对象。
- 点爆款笔记里的话题：打开互动数据较好的爆文，正文底部通常带话题标签，点进赛道话题，顺着标签继续找其他爆款笔记。

[PRE12]

[PRE13]

- 不停刷同类对标笔记：持续刷和账号调性相符的内容后，系统会按你的阅读偏好，在发现页推荐相似笔记，再从里面筛选合适对标。
- 去数据平台找：用灰豚数据、千瓜等平台搜低粉爆文，模仿这类笔记，再次爆的概率会高不少。（这些功能要开会员，可以去淘宝闲鱼买个账号，问题不大。）

2）什么样的笔记适合做对标？

- 看互动数据：一般来说，互动数据大于100算小爆，大于1000算大爆。找对标时尽量选大爆笔记。
- 看评论：有些笔记赞藏不显眼，但评论区全是精准询单，询单和赞藏接近1:1，甚至超过赞藏，这类笔记也值得重点借鉴。
- 看时间：发布时间在3个月内最好。如果是季节性产品，比如冬天滑雪泡温泉、夏天避暑胜地，可以借鉴往年爆款。
- 看博主粉丝量：腰部甚至头部百万粉博主的爆款，参考意义不大，因为数据很大程度靠粉丝，你复制不了。

**第二步：准备相关素材**

确定对标后，按对标笔记准备图片和文本素材。

1）图片素材

图片可以从自己素材库找，也可以去百度、携程、小红书搜。但要注意：除了旅行社对接提供的图片，其他图片尽量不要用有真人出镜的。

如果确实想用真人出镜图，尽量别在国内平台找，容易被本人刷到并举报。可以私信或去博主笔记下留言要授权，说明会备注图片来源。这样对方同意的概率更大，也相当于多一次曝光。

2）文本素材

来源主要有两类：

① 旅行社提供：旅行社会给相关产品资料，把内容整理进自己的素材库。
② 网上搜索：百度、携程、途牛、小红书、知乎等都能查到相关信息，也可以用ChatGPT辅助。

**第三步：制作图片**

1. 制作封面

怎么对标爆款做像素级拆解，再做出封面？思路就是：贴近对标，精准拆解。

[PRE24]

一张图可拆成四部分：

1. 四宫格真实景点拍摄+真人出镜；
2. 图片正中间放主标题“XX6日轻奢游”，再加副标题写行程主要景点；
3. 主标题正下方放“人均1000+”小标题，突出低价；
4. 主标题左上方写行程能提供的服务亮点。

拆完后，按模板找对应素材。步骤是：

1. 从第二步搭的素材库里找4张偏真实的目的地景点照片，其中一张带真人出镜（背影或正面都行，注意是否侵权），用稿定设计或WPS拼成四宫格；
2. 在首图正中间找笔刷图形做底色，在底色上排主标题+副标题。主标题写：XX（目的地，可以是单个景点，如华山）几日（散拼团多为1日游）轻奢游；副标题写目的地下级小景点或玩法（如华山：索道、滑道、西上北下、东峰日出、山顶帐篷）；
3. 主标题正下方写：“人均XXX（散拼团价格多在300左右）”；
4. 主标题正上方写一日游能提供的服务（如全程接送、吃喝门票一价全含）。

从初始封面到爆款封面，优化时记住三点：

- 真实好看：旅游赛道最好的图，是既好看又真实，真人出镜最佳。
- 氛围营造：整体配色、背景、选角都要和选题强相关，突出氛围感，让用户有好感。
- 突出卖点：主标题字体要精准吸引、放大突出，有“一眼记住”的效果；小标题简单罗列主要卖点，比如玩法、价格、服务。

快速判断封面合不合适：把图发到微信聊天框，只给自己1—2秒停留时间，看能不能快速抓到封面主体和标题关键词。能，就说明封面合格；还要停下来细看才能发现，就说明不合格，排版和花字需要优化。注意别自嗨，少走弯路。

**第四步：写文案**

旅游赛道的内容框架并不复杂，基本由这些部分组成：①用户痛点；②自我介绍；③景点介绍；④行程线路；⑤行程亮点；⑥产品细节；⑦亮点细节。
