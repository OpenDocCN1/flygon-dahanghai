# 6.3 发布节奏与下架时机
普通闲鱼号最多能上50个商品，不用一次性上满。前3天每天上3—5个，别一天堆太多；熟练后每天可上10个，大力出奇迹。也不要一次性把当天商品全发完，要间隔发布，可以1小时或2小时发一次。发布时间一般选上午或下午。
平台流量像一块田里的肥料，商品像农作物：这块地种得越多，每株分到的养分越少。所以商品要定期迭代，数据不好的下架，换成新的。

# 七、闲鱼运营推广技巧 @陈bu懂
单品发布完，进入闲鱼运营流程。下面讲如何给商品增加曝光和咨询量。先普及三个要持续关注的数据：商品页面有曝光、浏览、想要。
曝光：商品展示在别人手机页面上的次数；
浏览：别人看到商品后点进去的次数；
想要：别人点进商品后，点击“我想要”或“聊一聊”的咨询次数。
通过下面的运营动作，可以在一定程度上提升曝光，增加被浏览和咨询的几率。

什么商品适合开公益宝贝？捐赠比例不建议太高，1%即可。新上1—2天的商品可以开，后面成交时可以把公益宝贝关掉。
商品无法开启公益宝贝怎么办？公益宝贝主要在新上品推自然流时有点作用；想直接上，可以选“发布公益宝贝”。实测它是加分项，但权重没那么高，所以是可选操作。做好后续运营更重要。

## 8.1 🛰️养号与运营 @陈bu懂@小虎牙
### 8.1.1 🛰️为什么要养号？
🛰️对新号管控严格，频繁加好友、群发消息、转账都有可能触发风控。客户看到风险提示，会降低对你的信任。
### 8.1.2 🛰️养号流程（模仿正常用户，持续一周）
1. 每天收款1笔50—200元，每天转账1笔，时间间隔开。
2. 每天加好友1—2个，可以加自己🛰️大号的好友（推荐加权重高的老号）。
3. 一周随机时段发5条朋友圈，并和好友发的朋友圈互动。
4. 一周加几个活跃的群，适当互动。
### 8.1.3 🛰️资料设置
客户加到🛰️后，第一眼会看个人信息和朋友圈。好的朋友圈人设能极大提升私域成交率。下面讲私域怎么装修打造。
Part1. 🛰️号运营
①头像：可以和闲鱼账号一致，也可以用其他图。
②名称：尽量和闲鱼账号保持一致，可加上自己的在线时间。
[PRE16]
③个人简介：可写个人身份、在做的业务、在线时间等。
Part2. 朋友圈打造
朋友圈运营是重中之重。打造朋友圈主要有三个目的：
①告诉客户你是真实的人，不是机器人；
②告诉客户你的业务是什么；
③告诉客户你这个业务做得怎么样。
朋友圈内容建议主要发三类：生活相关30%、业务相关30%、工作相关40%。
①生活相关：告诉客户你是真实的人，不是机器人。生活类朋友圈就是“吃喝玩乐”，大家一般都会发，这里不展开。它能增加你作为真实个体的感觉。
②业务相关：告诉客户你能做什么。业务相关朋友圈都可以置顶，让客户一眼知道你是做什么的。把你能做的事发几条朋友圈展示出来。

③工作相关：告诉客户你做得怎么样。可以发客户成交截图、好评截图、转介绍截图、给客户答疑解惑体现专业性的截图。生活日常、思考感悟、客户好评、转介绍、付款记录等都可以发。内容类型要多样，从多个维度体现真实个体，增强客户信任。

## 8.3 售前沟通与成交
把客户引到私域后，就可以沟通需求了。
### 8.3.1 沟通思路
📌 AI写作项目中，客服是plus级别的写手。一个不懂后端产品的销售，不是好销售；不会写作、不懂写作的人，较难做好客服。好的客服应该从好的写手中培养。
客服报价、谈单、成单跟很多变量相关，比如沟通、谈判、说服、销售、用户心理把握、预期管理、专业展示、情绪价值提供等。AI写作市场没有统一定价规则和标准，品类都是非标品，非标品才有溢价空间。最终成单价格受稿件类型、用途、字数、时间要求、同行竞争、客户预算、谈单话术等因素影响。
1. 客服第一目标是成交，但不要为了成交过度承诺，要以长期合作为目标。
2. 站在客户角度思考，有同理心，让客户感受到利他精神，以信任为基础建立深厚客户关系。
3. 想尽办法展示专业度，用专业话术、成功案例、实力背景等增加客户信任。
4. 谈价时以价值为导向，引导客户意识到盲目压价会影响最终写作质量，避免被动陷入客户讨价还价的模式。
### 8.3.2 客户沟通流程
#### 8.3.2.1 接待客户
第一步：问候与自我介绍
话术示例：“宝子你好，我是xx专业的老师，可以和我说一下你的写作需求。”
同时进一步判断客户身份和付费能力，比如问专业、学历、学校/学校级别，或者看闲鱼IP、发品/成交记录、朋友圈等。
第二步：了解客户需求
了解客户信息：学历&学校&专业、行业&公司&职业。引导客户详细描述写作需求，如稿件类型、具体用途、审核/汇报对象。
话术示例：“宝子，这份商业计划书是作业、用来参赛还是融资使用？”“这份教案是日常授课还是参赛使用？”
第三步：问题探询
询问项目具体要求，如字数、语言风格、完成时限等。引导客户提供补充信息，如需不需要加数据图表、设计图等，更精准分析写作难度和工作量，以便准确定价、避免踩坑。
话术示例：“除了字数7k以上，这篇调研报告是否需要问卷调查和数据分析部分？”
💡 P.S. 如果看不懂客户需求怎么办？
可以借助AI先大致理解客户写作需求，用自己的话梳理清楚，再和GPT对话。prompt示例：“有个客户需要写一篇教师征文，方向是初中英语教学中，情景短剧中的作用，6000字，请你扮演专业的教师征文写作老师，与客户沟通写作思路和架构，让他觉得你很专业且能够和你建立信任。”
也可以把自己带入客户角色，去咨询闲鱼、淘宝同行。问客户有没有参考样稿/对标范文，分析工作量；如果没有，去Meta搜类似文章，初步评估工作量。
#### 8.3.2.2 介绍服务与报价
报价与费用说明：根据客户需求提供阶梯报价，分为“正常质量XXX”和“高质量XXX”，帮助客户清楚不同服务档次的价格区间。解释各项收费标准，指出影响报价的具体因素，如加急服务、内容复杂度、特殊要求等，让客户理解费用背后的逻辑。
折扣与优惠信息：预算有限的客户，为促成订单可提供小额折扣（5—10%），但折扣不宜过大，以免客户认为议价空间充足、我们利润过高。和客户议价时，话术要强调价格和质量挂钩，引导客户理解：在不影响质量标准的前提下，可以通过适当减少字数、减少1—2个图表制作、限制修改次数等方式适当降低价格。让客户感受到每一次价格调整都是基于合理的成本考量。
