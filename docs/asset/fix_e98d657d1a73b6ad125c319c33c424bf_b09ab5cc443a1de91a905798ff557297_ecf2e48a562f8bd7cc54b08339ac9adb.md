#### 1.3.1 六个动作跑通小红书小店：新手最小闭环

想把小红书店铺从0跑到1，不必一开始就重投入，先让最小交易链路转起来。整体拆成六件事：开号并完成开店、挑货、商品上架、发内容、出单后再找供货方、日常打理店铺。

真正拉开差距的，是挑货和发内容这两环。下面按顺序说清楚：

**1. 开号与开店**

刚上手的人，建议先配2套账号和店铺；已经熟练的，可以用7个号轮流运营。

**2. 挑货**

货选得怎样，很大程度决定能不能出第一单。新手前期从低客单、热度高的品类切入更稳妥。这次实操会拆解一些曾经的爆品，帮你找选品感觉；如果你已经掌握了必修篇的方法，想拓宽渠道，可以到七、【选品拓展】里继续练。

**3. 发内容**

选题时，盯住小红书商城里垂直类目最近销量上扬的商品，拆它的爆款笔记再模仿，起量会更快。

制作上，平台对混剪视频的管控会逐步收紧。新手前期用混剪练手可以，但长远要尽量转向实拍。

**4. 对接供货方**

前期订单少，先和商家约定手工打单，确保面单不出现其他平台信息；订单多起来后，就要接入商家的ERP系统。

#### 1.3.2 内容推荐逻辑 @曜文

1.3.2.1 审核流程

笔记发出后，先进入平台的“黑盒审核”。

系统按既定规则（可查官方号“薯管家”）做第一轮筛查，重点看敏感词、违规词、低质图片等。

一旦命中违规，笔记直接判失败，拿不到曝光。

机器识别不了的内容，会被标记为疑似违规，再交给人工复核。

没通过审核的笔记会被关进“小黑屋”，实际表现就是流量受限。

别人在你的主页看不到这篇笔记；想确认是否限流，可把笔记分享到微信等外部平台试着打开。

通常黑盒审核几分钟到十几分钟结束。若发布高峰时审核变慢，多半是进入了人工审核。

1.3.2.2 推送逻辑

审核通过后，笔记会交由小红书的“AI语义系统识别拆分笔记”算法处理。

算法会拆解内容，完成类型归类，并打上兴趣标签和收录关键词。

随后，笔记被推送到粉丝首页及其他用户首页。

按算法结果，先精准投给约100人的小范围用户。如果初始曝光互动好，笔记会被推给更大群体，曝光机会随之增加。

有一个公式要记住：CSS = 点赞×1 + 收藏×1 + 评论×4 + 关注×8

它衡量的是互动与转化，计算结果会持续影响首页推荐频次。

所以，前100个精准用户的点击和互动很关键；笔记发布后18至24小时内的互动表现，也会决定能否继续吸引流量。

1.3.2.3 权重构成

小红书笔记权重，主要看三块：

1.原创度

原创度低于60%，权重会被压低，还可能被限流。

2.转化率

转化率指笔记发布后的曝光与互动之比。转发、评论、收藏、点赞的权重排序为：转发＞评论＞收藏＞点赞。

3.内容

内容有两个要点。第一，关键词标签与整篇内容的关联度；关联度太小，容易被判为恶意引流，权重下降。

1.3.2.4 排名与收录

笔记排名，是用户搜索关键词后，结果页中笔记的展示顺序。越靠前，被点击的概率越高。

说排名前，先理解“收录”。

收录指搜索引擎抓取笔记内容并存入数据库的过程。通常审核通过的笔记会被收录，但以下情况可能导致收录失败：

4.账号问题

账号多次违规，整个号受限，笔记也无法被收录。

5.抄袭问题

系统判定笔记重复率高或非原创，平台不会给予支持。

6.营销问题

笔记中广告、营销话术过多，会被识别为推广笔记。

7.多次修改

每次修改都会重新触发审核，改得太频繁容易失去收录。
