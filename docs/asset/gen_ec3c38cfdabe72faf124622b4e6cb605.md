# 1.2 闲鱼高排名、高曝光的底层逻辑

不管是闲鱼，还是📕、抖音等平台，背后都是机器算法。我们在平台上操作，要符合平台的算法机制。顺着算法做事，更容易获得推流和曝光，反馈也会更好；反之，推流和曝光可能偏低。

做平台规则允许的事，做平台喜欢的事，把产品的曝光、点击和转化做好，提升店铺权重，排名和曝光自然会更理想。

流量＝一个个用户汇成的海洋。  
内容＝我们与用户沟通的桥梁。

当下几乎所有公域平台都靠系统推送流量，人工分配流量的平台几乎没有了。

系统分配流量的标准，在于数据表现。系统会通过赛马机制判断数据好坏。数据越好，流量越高。

而数据产生的源头，一定是内容：主图好，“浏览”数据就高；文案配图好，“想要”数据就高；话术好，“下单”数据就高。

所以，与其追着流量跑，不如认真打磨内容，也就是商品链接里的图片和文案。用内容吸引真实客户，产生真实数据，流量自然会越来越高。

落到具体动作上，就是：

上平台用户需要的产品；  
按平台用户的习惯编辑并上传产品；  
及时回复用户问题；  
及时处理订单；  
保证产品质量，让好评增多；  
及时处理售后，并尽量减少售后。

# 1.3 为什么建议做蓝海高客单？

进入闲鱼赛道的人很多。新人如果还在红海里打价格战，比较难拿到正反馈。

所以这期航海重点带大家学习【蓝海选品＋内容打磨】：用选品策略找到蓝海市场、争取利润；用内容优化去拿下蓝海的大部分市场。

为什么做高客单？

在闲鱼卖低客单产品，出单虽然容易，但利润低，顾客更计较，售后也多。一单赚 3—5 元，就算一天出一百单，利润也就三五百元。还要不停回复顾客、下单、上传单号，占用时间不少。对于把闲鱼电商当副业的圈友来说，需要投入一定时间和精力。

而在闲鱼卖高客单产品，出单量通常会少一些，但单笔利润更高，一单利润可以达到三位数、四位数，甚至五位数。折算下来，时间成本更低。哪怕一天只出一单，三位数利润到手，对副业做闲鱼的人来说也比较合适。

# 1.4 为什么建议做垂直店铺？

做垂直店铺最大的意义，是能把店铺里其他数据带动起来，让流量在店铺内部多次流转、循环使用。

平台会根据赛马机制的结果分配流量，评判标准就是数据好坏。数据好，就能进入下一个流量池。垂直店铺的根源，就在于让店铺里的其他链接拉高数据，从而跑赢同行、获得流量。

比如：户外桌子和椅子两个产品。如果桌子链接爆了，其中一定会有部分客户需要买椅子，椅子的数据就会增加。

这时从数据层面看椅子链接：平台没有额外分配流量，但数据确实增加了。平台拿着椅子的数据去参与赛马机制，椅子链接就有很大概率跑赢同行，也就是说椅子链接也可能爆。

椅子链接爆了之后，依旧会有一部分客户需要买桌子，从而反哺桌子的数据，相当于变相增加桌子的数据，延长桌子链接的生命周期。

这里说的垂直店铺，不是垂直产品，也不是垂直材料，而是垂直场景。只有同一场景，才能让流量实现二转、三转。

我们可以去看其他电商平台的标题，判断产品到底有几个使用场景，再想这个场景里还会出现哪些产品。总之，一个店铺只做一个场景，尽量让客户一次性把东西购齐。

# 3.1.1 蓝海选品思路

# 3.1.1.1 蓝海选品的 3 个参考标准

1. 看这个产品最高的想要数  
客户点“想要”，最低也是想看看价格，这类客户意愿比较强。所以看想要数，就等于评估产品市场有多大。

2. 一周内有留言的爆款链接，内容还有优化空间，就有机会  
市场在不断竞争，商品链接内容也在不断迭代，用户喜好会变化。  
有些爆款数据高，但可能是很久以前的爆款，不适合当下市场，数据上表现为最新留言停留在一个月前或更久。  
因此要看这个爆款链接【一周内有没有留言】，判断它近期有没有推流；再判断链接还有没有优化空间。内容质量决定流量高度，你认为能优化，就是有机会；你认为已经很好，那对你来说就没机会。

3. 链接标价是否低于卖价的 50%？  
点击是所有数据的开始，决定客户是否点击的内容就是点击四要素。一般同行内容会先卷主图，再卷价格，最后才卷标价。当标价低于实际卖价的 50% 时，意味着竞争已经非常激烈。  
至于这个品是蓝海还是红海，根据上面提到的问题，就能得出答案。

# 3.1.1.2 通过异常值选品

所以，同样的产品，异常值就是成功的差异化案例；不同的产品，异常值就意味着旺盛的市场需求。

这种明显高于同类产品标准线的数据，就是异常值。找到异常值后，一定要多维度拆解分析。  
从主图、标题、营销词、文案、配图等多个角度，找到异常值产生的原因，并尝试把它应用在自己的实物产品上。

如果说成功有捷径，那异常值就是那条近路。

异常值之所以藏着巨大机会，无非两点：

1、从数据上看，异常值本身意味着已经被市场认可、被用户认可，是一个成功案例。  
2、新鲜出炉。任何差异化随着被同行不断抄袭，也会逐渐变成常态；一旦常态化，数据上就不会再有异常值。所以每一次异常值，都是最新的机会。
