# 2.2 账号注册与养号要点

@思蒙 @惟乔 @清欢 @云珞 YunL

做短剧CPS，抖音、快手、视频号这三家平台都能跑。不过快手和视频号的审核尺度更紧一些，抖音眼下是最好切入的。

**账号注册的门道**

抖音要求一部手机对应一张电话卡，且仅登录一个账号。网络方面，移动流量或家里的WiFi都行，但要做矩阵的话，别让一批设备连同一个WiFi。快手只要账号没有违规记录，新号旧号都能上。视频号则推荐从新号开始。

**老号与新号的真相**

不少人把“注册时间久”当成老号的标准，抖音可不这么看。注册时间很长、但一条作品都没发过的，会被归为新号；哪怕发过几百条作品、粉丝却停留在几百到几千，同样按新号处理——因为标签尚未打上。真正意义上的老号，是在某个领域已经有了标签、粉丝量达到几万的那种。如果你想换到一个相关性不强的领域，最好重新注册。举个例子，原账号积累了5万粉丝，转做新内容后，新号至少也要达到同等量级，才能抵消旧标签的牵制，这是抖音官方的解释。

我新号旧号都实操过，同一条视频，旧号跑出的效果反而更亮眼，还顺带拉高了以前作品的播放量。抖音官方的说法是：粉丝量不大、标签尚未形成的账号，无论注册时间早晚、是否发过内容，一律视为新号。

当然，前提是账号没有违规。一旦有违规记录，最稳妥的做法是注销账号、卸载抖音，再重新下载注册。若你仍有顾虑、坚持启用新号，可以用另一张身份证做换绑，把老号腾出来后再注册新号，这样能省去注销要等的7天时间。

**养号这件事，做不做？**

抖音这边，建议先养2到3天再发视频。方法不复杂：每天花2到3小时刷视频或看直播，顺手点个赞、加个关注就行。没时间刷的，找个直播间把手机放一边也可以。不必专门去刷短剧类内容，让平台判断你是个正常用户就行。视频发布之后，每天依旧要刷2小时，发布前刷10分钟以上，发布后也刷10分钟以上。

不过养号的说法多少带点玄学味道，我更建议把精力倾斜到作品产出上。如果你很在意，可以按这个方式操作。快手在这块没那么多规矩，视频号同样不要求养号。新号刚开始那几天流量会给得比较足，要珍惜这个窗口。
