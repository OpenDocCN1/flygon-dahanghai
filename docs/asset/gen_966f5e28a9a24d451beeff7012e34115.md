# 六、更多选品方法

# 6.1 蓝海选品的 3 个参考标准

1.  先看这个产品的最高“想要”数

客户点下“想要”，通常至少是想了解价格，这类人的购买意愿相对更强。所以“想要”数的高低，本质上反映的是产品市场有多大。

1.  一周内有留言的爆款链接，说明内容还有优化余地，就有机会

市场一直在竞争，商品链接的内容也在不断迭代，用户的喜好同样在变化。

有些爆款数据看着漂亮，但可能是一个月甚至更久以前的老爆款，早已不适应当下的市场——数据上的表现就是最新留言停留在一个月前或更早。

因此，判断一个爆款链接近期有没有被推流，要看它【一周内有没有新留言】；再判断这个链接的内容还有没有提升空间。内容质量决定流量天花板，你觉得能优化，就是机会；你觉得已经无可挑剔，那对你来说就没机会。

1.  看卖家数量和产品均价

用关键词或标题去搜索平台上的同行和客单价。如果同行不超过10家，而均价又高于同类产品，说明竞争不算激烈。

至于这个品是蓝海还是红海，对照上面几条标准，答案自然就出来了。

# 方法一：通过异常值选品

红海竞争太激烈，最好的策略就是避开正面交锋，走差异化路线。只要是成功的差异化，数据上一定会偏高，表现出来的就是“异常值”。

也就是说，同样的产品里，异常值代表成功的差异化案例；不同的产品里，异常值则意味着旺盛的市场需求。

这种明显高出同类产品标准线的数据就是异常值。找到异常值之后，一定要多维度拆解分析。

从主图、标题、营销词、文案、配图等多个角度，找出异常值产生的原因，再尝试把它用到自己的实物产品上。

如果说成功有捷径，那一定就是异常值。

异常值之所以藏着巨大的机会，原因无非两点：

第一，从数据上看，异常值本身说明它已经被市场和用户认可，是一个成功案例。

第二，新鲜出炉。任何差异化都会随着同行不断抄袭而逐渐变成常态化，常态化之后数据上就不会再有异常值。所以每一次异常值，都是最新的机会。

所以，如果你没能力做第一个吃螃蟹的人，不妨试试做第二个吃螃蟹的人——安全无害，还有收获。

# 七、更多变现方式

# 7.1 引流

私域为王。引流的目的就是把流量导入自己的私域，再通过一对一话术或朋友圈去转化更多的SKU、更高的客单价。

操作步骤和正常上品流程一样，只是价格设置和发货环节有些差异：

1.

在闲鱼主页搜索关键词，比如“副业”“赚钱”

2.

尽量找到想要人数多的对标商品链接

3.

复制对标的文案和图片

4.

设置商品价格（关键）

引流商品的价格设置有讲究：可以先把价格设成2块，然后每小时降1毛，一直降到1块就停住，没人买也不用恢复成2块。

5.

发布地区：主要选一二线城市，但不要频繁更换

6.

发货（关键）

去买一份项目资料存到自己网盘，再把你的私域联系方式或二维码上传到网盘（转化话术也可以做成图片），生成一个网盘链接。买家下单后就发给他。
