1. 点击「配置」。
1. 填入服务器的公网 IP（只填 IP，不要带端口号）。
1. 点击「确认」。

**常见问题**

找不到 openKfId 怎么办？

这种情况不只你遇到。有时页面里就是不好找，甚至不直接展示。

解决办法：

1. 先确认客服账号已创建成功。
1. 记住客服名称。
1. 通过接口拉取客服账号列表来查 ID。

别因为 UI 里没看到，就怀疑前面全做错了。

回调配了，为什么发消息没反应？

先看回调 URL 配在哪。

如果配在自建应用里，而不是🛰️客服后台，这很可能就是原因。在 wecom-kf 这条链路中，回调 URL 应优先在🛰️客服后台配置。

客户发消息了，AI 没回复

三关排查法，哪关断了修哪关：

第 1 关：消息到你服务器了吗？

看日志有没有 [wecom-kf] callback received。

- 没有 → 消息根本没到。查：URL 对不对、端口开没开、Gateway 在不在跑。
- 有 → 到了，查下一关。

第 2 关：消息拉取成功了吗？

看日志有没有 sync_msg。

- 报错 → 一般是 corpId 或 corpSecret 填错了，或者 IP 没加白名单。
- 正常 → 继续。

第 3 关：AI 处理了吗？

看日志有没有 dispatching to agent 或 reply sent。

- agent 报错 → AI Agent 自身问题，与🛰️客服无关。查 Agent 配置。
- reply sent 但客户没收到 → 看错误码，对照下面的。

报错 95017

48 小时窗口过期。客户最后一条消息超过 48 小时，企微不允许再回。

正常客服场景碰不到。调试时遇到，让客户重新发一条即可。

报错 60030

接待人员不在应用可见范围内。

回第二步的应用 → 改「可见范围」→ 把接待人员的部门加进去。

回复格式乱了（星号井号满天飞）

🛰️客服不支持 Markdown。插件会自动转换（标题变【标题】，加粗去星号），但有时不够完美。

解决：在 Agent 的系统提示词里加一句——“回复客户用纯文本，不要用 Markdown。”

回复太长被截断

企微单条消息限制 2048 字节（约 680 个汉字）。插件会自动拆成多条，但超过 5 条就会被限制。

解决：在 Agent 提示词里加——“回复控制在 500 字以内。”
