# Sora引爆AI视频：落地、鉴真与追赶

从公开信息看，Sora很可能成为内容生产的效率放大器：一边提升产出速度，一边压低制作成本。对于手握大量IP储备的影视公司来说，未来可用Sora或类似工具生成短剧、短视频，再借现有成熟的短剧/短视频营销体系，把内容推向规模化、商业化变现。

**华策影视：4秒文生视频已有技术储备**

财联社2月21日消息，华策影视在互动平台回应称，公司对AI技术研发与应用高度重视，并持续关注以Sora为代表的新兴文生视频平台。公司于去年成立AIGC应用研究院，自研的编剧助手、剧本评估、视频检索、AI剧照等功能，已在内部投入使用或处于内测阶段。通过对开源技术的学习、吸收与消化，公司当前技术储备已能生成4秒时长的文生视频。接下来，公司将探索文生视频等AI新技术在传媒行业的落地与业态创新。不过，公司也提示，相关AI技术储备短期内不会直接增厚业绩。

**国投智能：AI-3300“慧眼”可鉴别Sora视频**

财联社2月20日消息，有投资者在互动平台询问：公司AI-3300“慧眼”视频图像鉴真工作站能否鉴别Sora生成的视频并出具鉴定报告？国投智能答复称，该工作站可以鉴别此类视频，并支持出具鉴定报告文书；这款产品已经向客户销售。

AI视频眼下至少有两道坎：第一是算力，视频场景对算力需求更高；第二是竞争，头部科技巨头几乎都已下场，只是产品还没全面公测。还要注意，W.A.L.T模型的案例说明，算法演进对AI视频的影响不可低估。曹旭特建议重点关注视觉算法领先的虹软科技、当虹科技、格灵深瞳，同时可关注应用侧的金山办公、万兴科技、福昕软件等。

## 附：资料整理者大国的个人思考

大国接触AI一年多，总结了十条心得：

1. AI不只是风口，它会深入生活、工作乃至思考，成为必备工具。
2. AI技术迭代飞快，你可以质疑眼下的缺陷，但不要怀疑AI持续变聪明的趋势。
3. AI进化速度太快，过程中可能出现人为干预；如果AI来得过猛，社会尚未反应，政府也会面临压力。
4. 普通人应多研究AI应用，把AI纳入自己的思考过程，才不容易被淘汰。
5. 不必过度恐慌AI带来的变革，但对容易被替代的岗位也别太乐观。
6. 普通人也能参与AI机遇：即便不懂技术，也可以认真研究应用场景，甚至探索新场景，为更多人提供示范案例。
7. 多关注国外AI技术变革。国内一直在追赶国外技术，差距还不小；每次革命性的AI节点，多由国外技术推动。
8. 在AI赛道创业，出海项目明显增多，这是不错的选择；海外市场比国内大得多，这也是少有的国内外同步进行的技术革命。
9. 国内各大内容平台正在迎合AI生产内容，甚至不得不接受AI生产内容，因为这是趋势。
10. 谁掌握先进生产工具，谁就更容易站在金字塔顶端，这就是AI带来的机遇。
