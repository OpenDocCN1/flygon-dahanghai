# 三次创业复盘：水果店败退后，我如何转身站外服务商

我是 Rick，海豚出海合伙人。今天不讲空话，只讲自己从水果店关门，到在亚马逊折腾，再到成为千万级站外服务商的真实经历，希望能给做跨境的你一点参考。

全文分六块：
1、误入站外赛道
2、站外推广的底层逻辑
3、卖家为何需要站外流量
4、站外渠道全景
5、服务商与自营的取舍
6、海豚出海与品牌出海

## 1、误入站外赛道

不少人好奇，我怎么会干起站外。其实起点很普通。

2012 年快毕业时，我还没想好职业方向，干脆花半年啃雅思。当时也没有长远规划，只觉得成绩考出来，求职或出国都用得上，就硬着头皮坚持。后来在招聘网站刷到一家公司招外贸业务员，我口语不算好，临时背了几天面试范文，运气不错，就这样入了外贸销售的门。

2013 年，一位高中同学找我借钱开奶茶店，这事把我刺激到了。他读书时成绩不如我，毕业后却直接当老板，而我似乎一眼就能看到职业尽头。我不服，也开始琢磨创业。

[PRE0]

第一次折腾，我选了水果店。起因挺偶然：去佛山同学家，路过百果园买了几样水果，结账接近两百块。我第一反应是：卖水果利润真高。回家后越想越上头，脑子一热辞了职，把店开起来。

但我没经验，犯了实体店大忌：选址没做好，客流差，生意自然难看。转让费东拼西凑十几万，每月房租水电近两万，水果损耗又高，亏损越滚越大。那阵子压力压得人喘不过气，我知道不转型就活不下去。

店离科技园不远，我便改做企业下午茶。每天六点起床，七点到地铁口发传单，九点半进科技园扫楼，一家家跑；不扫楼就骑电单车逐户送水果，下午六点回店守到十二点收摊。硬撑一年，钱没挣到多少，压力却更大，最后只能把店转出去。第一次创业，就此收场。

[PRE1]

正好原公司准备开拓海外市场，领导看我懂技术、又能用英语，便打电话问我愿不愿意回去，到新成立的外贸部门做销售经理。于是我又回了老东家。

第二次折腾，我做的是亚马逊。2016 年底，我在加州圣迭戈参展时认识一位当地华人，聊得很投缘。他说自己后悔移民美国，若当年留在国内，发展可能完全不同，也不至于每月税后只拿四五千美金。之后我们一直保持联系。2017 年初，我开始接触亚马逊，和他越聊越合拍，便辞职合伙干亚马逊。

[PRE2]

当时分工是：他在美国熟悉当地消费习惯，负责选品；我负责运营。

第一年主要是开店、进货、上架几条 listing，先熟悉平台。2018 年上半年，我们做了一款带 LED 灯的插座盖板，拿货价很低，却能卖到 29.99 美金，链接上架一天就有一百来单。卖了约半年，被 Snappower 告了，原因是侵犯专利，平台给了警告并删除链接。

2018 年下半年，我们又做了一款 ACK 户外折叠刀。很多户外刀抄袭国外品牌款式，而 ACK 是意大利品牌，在美国没有专利，所以卖得很火。拿货十几块一把，能卖二十几美金，体积小、重量轻。卖了约半年，平台开始扫主图，说刀尖太尖，链接被删。我们就反复上，能卖一阵又被下掉。后来平台力度加大，几乎一上就被抓主图。

[PRE3]

靠这几个产品，2018 到 2019 年我们小赚了两百多万。

2019 年，我们开始追热门产品。背背佳利润不错，我们用测评资源给一个链接第一个月怼了二百多个好评。随着单量加大，产品质量问题暴露，评论开始掉，掉到 3.5 星，评论两三千条，最后实在救不活，只能放弃。这款产品前后至少亏了四五十万。

后来我们又陆续上游戏手柄、卷发棒、热风梳、计数跳绳、锻炼拉力带等。当时看数据都不错，我以为靠自己的资源能打上去，结果事与愿违，亏了很多。再加上二刷导致店铺死掉没申诉回来，之前挣的钱全赔了进去。

亚马逊失败小结：
1）没有链接沉淀，缺少长期主义。早期平台红利期政策不严，擦边球还能玩；平台越来越严后，我们还停留在旧思维里，没及时转变。
2）产品为王，是失败后才真正领悟的。当时对平台认知没跟上，选品只看数据好，可别人也看得到数据，最后只能拼谁扛得住卷。
3）从不同品类拿货，始终没沉淀出一个垂直类目，也没有供应链优势产品线。若有产品壁垒，别人跟进至少要几个月；而拿货模式谁都能拿到。

亚马逊失败后，我们已没钱维持运营，一个月仓储费都让人头疼。只好扔掉一些，又在线下收库存的处理掉一些，卷发棒和热风梳还有库存留在亚马逊。

那时我知道站外推广，却没深入。找个服务商花 500 发 20 个群，试了两次也没多少单。为省成本，我决定自己做。跟美国合伙人一商量，他说自己常混 Facebook 群和 Deal 站，我们便自己联系开发群组。像 Sweet Deals Finder 之前的主群有 80 多万粉丝，效果很好，8 美金一个帖子，加上其他群组，持续放了两个月，把库存清完，回款十几万，挽回了一些损失。

[PRE4]

清完货后，我们对亚马逊还抱有希望，可又没资金从头再来。回去上班，也不甘心。

第三次创业，我做站外推广服务商。偶然在群里看到有卖家找测评申诉服务商，因为是一刷，我很有把握就接了下来，顺利帮他救回店铺，只收了 1000 块。他参加过不少培训，觉得我靠谱，把我推荐到各种培训机构的内部群，客户一下子多了。加上我之前操作比较多，各类申诉都熟悉，生意越做越好。

做久了卖家再转服务商，我常会站在卖家角度想问题。申诉利润不错，但靠信息差，而且是在别人最困难时挣钱，这不是我真正想做的事。我也不是清高，平时朋友需要帮忙我都仗义，总想着力所能及做点有意义的事，所以更想做个靠谱的服务商。

[PRE5]

[PRE6]

客户常问我们做不做站外。加上之前清货尝到甜头，有些产品站外打折后还能留几美金利润。我们判断，平台广告费越来越贵后，站外会是趋势，于是放弃申诉，彻底转型做站外推广服务商。

卖家转型服务商，我不熟悉其他站外服务商流程，总觉得“我是卖家就希望效果付费”，就这样坚持了近一年。后来做站外的人越来越多，效果不如从前，基本没利润，还有些连续推一个月不付款。之后我们开始像其他服务商一样做套餐付费。

下面从服务商角度聊聊站外推广，内容可能有点干，但都是干货。

## 2、站外推广的底层逻辑

要理解站外，先得看懂亚马逊联盟。

亚马逊联盟是全球规模最大、起步最早的联盟营销项目之一，帮内容创作者、发行方和博主把流量变成收入。平台上有数百万商品，联盟伙伴用简单链接和推广工具，把受众带到推荐商品页，只要产生符合条件的购买，就能拿到佣金。

[PRE7]

这个生态里，平台出场景，联盟创作者出流量，卖家出商品。Facebook 群组管理员、社媒红人、平台影响者都属于流量方。三者搭在一起，才构成完整的联盟营销链。所以别轻易说站外没用，平台每年都在站外砸下大笔推广预算。

[PRE8]

早期平台要扩张，最依赖联盟客把站外流量带进来，给他们的奖励也大方。博主起初多是建群，把平台自营商品搬给粉丝。后来社交媒体折扣上线，卖家在后台建折扣，系统会把折扣同步到联盟，不少博主也愿意转发卖家生成的联盟链接。那时博主主要赚平台返佣。随着卖家主动上门，他们开始按帖子收推广费，这便慢慢演变成今天常见的站外投放方式。

[PRE9]

## 3、卖家为何需要站外流量

**1. 辅助亚马逊运营**

站外怎么配合站内？可以这样想：

**a：激活链接。** 新品广告不出单，先用站外折扣撬动首批订单，把链接激活。
**b：配合站内活动。** 秒杀前放站外，有助于拉排名，让秒杀更猛；秒杀结束后继续放，延长出单窗口，链接更容易起来。
**c：出单索评。** 站外折扣大、价格低，买家留好评的意愿通常比站内高。
**d：维护老链接排名。** 系统给每个排名阶段的自然流量有限，想往上一档走，就得持续守住上一档需要的单量。
**e：稀释评论。** 平台这两年对刷单查得严，但仍有卖家通过其他路径留评。站外大量出单能拉低留评比例，降低风险；价格低也能稀释退货率。
**f：站外也能挣钱的产品。** 现在仍有利润高、打完折还能赚的商品。大量发帖吸引订单，既赚钱又稳住站内排名，一举两得。
**g：绑定 FBT。** 先看互补产品投过哪些站外渠道，再投同样渠道，就有机会和互补的 BS 链接绑在一起。

从平台角度看，站外能带来新客户并促成成交，平台有得赚，自然愿意给链接加权。

**2. 清库存**

常见清库存方式有几种：

**a. 平台活动。** 例如 Outlets，但很难等、很难选上，就算选上效果也未必好，不建议干等，仓储费摆在那。
**b. 线下收库存。** 基本一折左右清，很容易踩坑，现在越来越挑，价值不高很难出。
**c. 站外清库存。** 有些产品放站外还能有利润，比如我们之前做的卷发棒，还有去年较热的水弹玩具枪。站外清库存折扣通常很大，要特别注意折扣叠加，避免不必要损失。

**3. 打造品牌**

现在站内广告太贵，增长太快，利润空间被严重压缩。以前好做是因为信息差：卖家少，平台需要丰富品类；平台也不是天生自带流量，而是靠联盟从站外引流，再亏本给到卖家。

现在不好做，是因为信息差已经过去。平台不缺同质化产品，首页评论多的商品已经满足买家需求，新品如何突破流量池？产品再特别，买家看不见、不了解，又怎么会买？平台要靠广告费收割时，我们只能自己从站外引流。

品牌是最好的流量池，品牌自带流量，是赢得人心的结果。亚马逊做到最后，大家都会有深刻的品牌意识。站外推广的终局应该往品牌走。说白了，目前流量推广基本是辅助亚马逊，并不是脱离亚马逊，而是把亚马逊当成交平台，自己推广获取品牌流量。像亚马逊上的苹果耳机、耐克，并不依赖平台给的流量。

推广是条漫长的路，酒香还怕巷子深。平台没有流量红利后，大浪淘沙留下来的产品更需要好好推广，我们也比以往更需要耐心。

## 4、站外渠道全景

内容创作者或博主大致分两类：一类是泛流量，更偏向大折扣、出单量，这是目前市面主要渠道；另一类是垂直类目，受众更精准、粉丝质量更高，但更多基于需求和品牌，目前更倾向品牌曝光，常用于打造品牌渠道。

可以简单称为流量推广和品牌推广。

**1. 流量推广**

**a. FB 群组：** 群组创建之初，多是分享给亲朋好友，跟国内微商有点像。渐渐他们会联合不同品类博主分工运营、壮大群组：有人专门拉粉丝，其实叫拉人头更贴切，这种模式注定后面没有粉丝粘性，所以不该叫粉丝；有人专门发帖，不断丰富产品满足大部分群员需求，再通过人带人壮大群组。

群组特点是方便、快速，通过大量帖子博取爆单概率。但单价低、分佣管理员多，所以必须靠不同产品满足群员、激活活跃度。如果只发单一类目，一年也买不了多少次，从亚马逊拿的佣金完全不够几个管理员分。因此大部分群组是综合群，满足群员大部分需求，让他们每天都活跃，管理员才更挣钱。这也是垂直类目群组很少的原因。

[PRE10]

FB 群组是最方便快捷的渠道，群员的需求多是找到合适又便宜的产品。发展到现在，折扣基本 40% OFF 起步。

**b. FB 主页**

[PRE11]

有些 Facebook 主页专门为群组服务，还有一些只经营自己的主页。她们收集粉丝建议，发布粉丝需要的折扣产品，快速涨粉并增加粘性。这类主页一般发帖量不大，粉丝粘性比群组强很多，同等粉丝量下效果通常好不少。这些才是真正的 FB 博主，很多服务商把普通管理员也叫 FB 博主或红人。

**c. Deal 站**

FB 群组有被封风险，有些博主会建网站专门发布促销折扣，现在很多群组也开始做自己的推广网站、App 等。这类网站偏某些类目，比如电子、玩具、母婴。Deal 站受众人群男女比较平均，有的老牌网站流量大，发帖价格也贵，适合客单价高或清货需求的卖家。

[PRE12]

常见 Deal 站如 Slickdeals、Dealnews、1sale、Techbargains，收费从几十到几百美金不等，编辑对链接甚至店铺要求都比较高。

**2. 品牌推广**

人人都想做品牌，大部分亚马逊卖家也想往品牌走。累了困了喝东鹏特饮，果冻就吃喜之郎，耐克的 Just do it，这些耳熟能详的广告语，背后都是花了几个亿广告费才占据消费者心智。

品牌出海时，最容易触达消费者又不牺牲品牌调性的渠道有哪些？

**a. PR 软文：** 包括新闻网站、行业网站，主要发布新闻通稿或做产品评测。

[PRE13]

**b. KOL 网红营销：** 国外社媒主要是 Facebook 主页、YouTube、Instagram 这几个平台的红人。关键词搜索是最常用手段，大部分用户在 YouTube 上也是通过关键词搜索找到想要的视频，开发时尽量模拟真实用户搜索场景。网红粉丝粘性往往很强，我平时很少购物，但很喜欢樊登老师，就常在他直播间买书。粉丝会因为对红人的偏爱产生消费，或因为红人种草，当对产品有需求时第一就联想到这个品牌。因此这类推广效果往往持续很久，带来长期品牌影响力。

**c. 众筹——通过单品引爆品牌**

可以去官方找 KICKSTARTER 或 INDIGOGO 的工作人员，提交资料给他们审核即可。

[PRE14]

众筹首先要有好产品，并且足够创新。一般会在产品上线前 2 个月提交资料给官方编辑，比如 ID 设计图、3D 结构图等。上线后开始预售，这时需要导流到平台。如果幻想官方直接给流量，那就太天真了。平台要看你导入多少流量，之后才会让你撬动平台流量。前期基本靠自己导流，怎么导？

**1.** 找垂直网红，给他们早鸟价格，通过挂链接把粉丝引流到众筹网页。
**2.** 在行业杂志或网站写软文引流。
**3.** 参加 kickstarter 官方或其他社区引流。

众筹成败就在前一周导流，如果不理想，基本第二周就凉了，也不要垂死挣扎。真正的网红基本是垂直的，他们很在乎为粉丝带来真正价值，往往需要寄产品给他们时间拍摄和使用，发布实测心得，而不是简单发一个帖子，所以报价一般比较高。但网红的帖子往往代表粉丝喜爱的网红对该品牌的偏爱，粉丝对品牌印象深刻，是常见的品牌推广渠道。因其受众精准，配合大一点折扣力度，几万粉丝的网红爆单也很有可能。当然，如果一味追求单量，不建议尝试。

## 5、服务商与自营的取舍

了解完怎么做站外后，到底该找服务商，还是自己做？

大部分卖家刚接触站外推广时，可能都会选择找服务商。服务商优点是省事，设置好折扣提交过去即可。但服务商有以下缺点，会限制推广目的：

1. 反馈打码，数据不透明，压根不知道发了哪些资源。
2. 单量集中在某一天，很难配合卖家推广目的。
3. 没办法根据产品分析适合什么渠道。

这样一来，一旦效果不如预期，有些卖家就不停换服务商，花钱试哪家效果好，成本反而增加。也有一些经常做站外的卖家，对站外比较熟，为达到预期效果会同时找几个服务商一起放，但很多服务商资源重叠，相当于花几份钱达到一份效果。

这几年做服务商运营，我常站在客户角度考虑问题，和很多客户成了好朋友。常有客户让我帮忙分析他找其他服务商放了哪些渠道，分析来分析去，发现资源重叠严重。还有很多老客户对站外推广比较熟悉，也从不同渠道了解到一些优质群组，但因时间和人员关系，无法联系管理员发帖，于是找到我们，想指定群组发帖。

## 6、海豚出海与品牌出海

站外推广不是一锤子买卖，更不是脱离亚马逊另起炉灶。它应该辅助成交、沉淀品牌流量，让真正有产品力的卖家走得更稳。海豚出海愿做那个靠谱的陪跑者，助力真正品牌出海。
