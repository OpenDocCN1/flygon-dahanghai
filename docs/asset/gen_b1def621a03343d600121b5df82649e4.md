# 绿植类目在涨，账号方向怎么定？

先看一个对新手和初创团队挺友好的盘子：这个类目月销售额大约2亿元。更关键的是，当时绿植的月度增长很稳，最近三个月每月大约涨20%，说明在抖音上，绿植这个方向正越滚越大。眼下是2亿元，不代表以后还是这个数；我1月28日再查时，绿植类目已经冲到3.19亿元。

综合这些信息，我把目标用户定为：18—35岁、平时爱养花种草折腾绿植的人。

小结

从兴趣切入，最大的优势是：你自己就是这类用户，懂他们的需求和痛点，起盘会更顺，选品、做内容也更容易命中需求，成功概率更高。同时，做的是自己喜欢的事，过程更享受，不容易觉得累，反而会做得挺开心。

但有一个坑要避开：人群别太小众。太小众意味着天花板低，赚大钱难，还不容易及时拿到正反馈；长期没有正反馈，人很容易放弃。

# 第三步：冷启动破千粉，开通橱窗

💡

章节概要：前文提到，「抖音图文电商」的核心变现方式是开通「商品橱窗」，再通过挂购物车、引导橱窗购买，或点击直播间成交来转化。

但开通「商品橱窗」有门槛。按官方规则，必要条件有三条：公开发布视频数≥10条；抖音账号粉丝≥1000；账号已完成实名认证。所以这一章的核心任务就是：✅3.1 弄懂抖音带货权限；✅3.2 快速做到千粉；✅3.3 开通橱窗并添加商品。完成这一步，冷启动最大的难题就解决了。

[PRE8]

## 3.1 先弄懂带货权限

「商品橱窗」就是「抖音带货权限」：用户在抖音拿到这项权限后，可以短视频挂车、做达人推荐橱窗、直播间挂商品；拿到权限的人既能卖自家商品，也能帮别人带货。

[PRE9]

很多人分不清抖音号、商品橱窗、抖音小店，这里一次说清。

①自己有货源，卖自己的货：需要一个开通商品橱窗的抖音号，再加一个缴纳了对应类目保证金的抖音小店。

②自己不碰货，帮别人卖货：只需要一个开通商品橱窗的抖音号，然后从别人的抖音小店挂商品链接去卖。

所以，开通「商品橱窗」对抖音带货来说，基本是必要条件。

按官方规则，开通「商品橱窗」的必要条件为：公开发布视频数≥10条；抖音账号粉丝≥1000；账号已实名认证。其中前两条需要我们努力达成，尤其是「抖音账号粉丝≥1000」。因为一般做到千粉的过程中，视频数自然也会≥10条。所以下面重点说，怎么达成千粉。通常建议粉丝涨到1000以上；想稳一点，可以多涨一些，到5000左右。后期靠自然流量涨粉，不需要额外做投放抖加等动作。

## 3.2 快速做到千粉

### 3.2.1 先定人群再起号

新账号先在电脑端开通查看视频数据功能，入口是「抖音创作者服务中心」。正常发布视频，同时开始小额投放抖加，让账号快速打上创作者标签。投放金额：每条视频20—30元，投3—4条作品。投放设置里选性别、年龄、对标账号、粉丝量，对标账号选对标达人即可，达人数量5—10人。这样操作一轮下来，新发布的视频大概率就能推送给比较精准的目标人群。

[PRE11]

### 3.2.2 用Dou+加速涨粉

持续发作品，遇到播放量、点赞率等数据表现比较好的视频，就投达人相似涨粉。投产比在1:1以内，也就是一个粉丝成本低于1元时，马上追投。建议投到1000粉以上；想更快完成账号启动，可以按预算继续投到5000粉。

总结一下：遇到好投产比，要尽快完成冷启动，时间就是金钱。如果投产比太低，比如一个粉丝2元多，就看自己的接受范围；花费太高就停掉抖加投放。做法是把作品设为私密后再公开，投放会自动停止。

## 3.3 开通并使用橱窗

### 3.3.1 开通商品橱窗

达成千粉后，打开抖音APP：选择“我”—右上角“三横杠”—抖音创作者中心—电商带货，就能进入「商品橱窗」开通页面。

[PRE18]

以前开通橱窗要缴纳500元保证金，现在改为完成100单以上销售后，再补交500元保证金即可。满足条件后，点击「立即加入电商带货」申请开通。申请权限时，按自己的实际情况选择成为「带货达人」或「小店卖家」。带货达人适合自己无货源、未开店、帮其他商家带货的用户；对做「抖音图文电商」的人来说，基本选这个即可。下一步会选择收款账户，主要是方便结算佣金，佣金会打到对应账户。

怎么确认是否开通成功？返回抖音首页，点“我”—“商品橱窗”。如果页面提示“恭喜您-已经成功完成电商达人带货权限申请，可以前去选品广场添加商品推广了”，说明已经开通成功；如果提示“推广商品需开通带货权限申请，申请成功即可成为带货达人”，说明还没完成，需要按提示完善账户信息。

商品橱窗开通后，可以到选品广场选择精选联盟产品，添加到橱窗进行带货，也能查询订单金额等数据。

开通「商品橱窗」后，发布带购物车视频有限制：粉丝数低于1000的账号，每周限发1条；粉丝数1000—3000的账号，每天限发2条；粉丝数3000—10000的账号，每天限发5条；粉丝数10000及以上的账号，每天限发10条。

## 4.1 选品底层逻辑

抖音选品的底层，其实是选需求；选需求的底层，是选目标用户。

所以最底层的逻辑是：先确定一个自己想做的目标用户人群；再找这群人的需求，细分类目；最后根据各种方法找到匹配度高的产品。

选品还要结合市场供需来看：春夏秋冬分别适合卖什么？节日里什么产品有需求？最近卖得好的品，有没有相关产品可以跟？比如很多人在家里摆绿植，天气炎热时绿植容易发黄，就可以想到绿植营养液这类产品，顺着这个点继续深挖。
