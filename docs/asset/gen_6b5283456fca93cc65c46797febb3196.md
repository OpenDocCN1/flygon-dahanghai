# AI绘画新手怎么赚钱？我围观一个月摸出5条路

文/温酒

各位好，我是温酒，混生财圈到今年正好第三个年头。这一个月我没急着上手，先看别人怎么用AI绘画跑通变现。看完后，整理了几条新手也能试的方向，分享给大家：

- **赚信息差的钱**：你掌握的工具、玩法、渠道，别人还不了解，这中间的认知差就能变成收益。
- **接专属头像单**：帮人做个性化头像，按单收费。
- **公众号流量主收益**：用公众号承接AI绘画相关内容，靠流量主拿广告分成。
- **小程序取图**：通过小程序提供取图服务，从中获得收入。
- **社群收费**：围绕AI绘画建社群，做交流和服务来变现。
