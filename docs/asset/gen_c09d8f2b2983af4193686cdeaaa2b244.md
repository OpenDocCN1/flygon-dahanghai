# 第一步｜先把视频号摸清楚

做视频号，很多人一上来就急着拍、急着发，结果忙活半天，数据纹丝不动。问题往往不在执行力，而在于还没弄明白自己面对的是个什么样的平台。

所以真正该做的第一件事，是停下来，把视频号了解清楚。

它是一个长在微信生态里的内容场：社交关系是天然的传播链，一条内容可能因为朋友的点赞而被推到更多人的面前；它与公众号、朋友圈、小程序、直播彼此连通，公域流量和私域沉淀可以相互导流；它的内容形态也不止短视频，直播同样是重头戏。

把这些基本盘搞懂了，你才会知道：该做什么样的内容、流量从哪里来、用户看完之后往哪里去。方向对了，后面的拍摄、剪辑、运营才不至于白费力气。

了解视频号，不是可有可无的准备动作，而是整个链路真正意义上的起点。
