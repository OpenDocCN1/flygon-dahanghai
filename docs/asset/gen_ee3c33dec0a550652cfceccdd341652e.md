# 2.2.2 商标类别怎么选？

当你敲定了打算入驻的类目之后，还得留意一件事：美团电商在审核入驻时，除了看公司的经营范围资质，还会要求你提供与目标类目相对应的二级类目品牌的商标授权。不过这里有个容易被误解的点——这份品牌授权仅仅是用来帮你完成入驻审核的“敲门砖”，它并不会限制你后续店铺里卖什么牌子的商品。

举个例子就明白了：假设你拿到的是个没什么名气的日用百货品牌“李小明”的授权，用这个授权把店铺申请下来之后，你完全可以在店里上架别的牌子的货，比如“李小刚”的收纳架，照样没问题。
