# 7.3.5.6 标题：一眼抓人，还能被搜到

把标题留到最后讲，不是它次要，而是它分量最重。

它主要承担三件事：先把笔记主旨压缩成一句，让读者秒懂重点；再决定第一眼吸引力，懂用户需求的标题，才更容易把浏览变成点击；最后服务搜索，关键词放对位置，系统更容易识别内容归属，把笔记推给真正感兴趣的人。

写标题时，关键词不必贪多，但下面四类搜索词至少得占一类：

- 核心词：用“迷你披萨”搭配账号“君君辅食记”，直接点明主题；
- 转化词：从“黑头闭口怎么处理”切入，借李佳琦的做法带出解决方案；
- 热搜词：用“小阳人”亲身经历做引子，讲喉咙像刀片后如何缓解；
- 关联词：做彩色睫毛测评，突出自然又有点小心机。

核心词也不是只能单打独斗，还能和其他类型拼在一起：

- 场景词：围绕办公场景列100件养生小物，主打提升日常幸福感；
- 人群词：点名梨形身材的姐妹，送上一份不费劲的瘦腿运动；
- 价格词：十元上下的小物清单，清洁、提亮、润唇、卸妆都涵盖；
- 品牌词：想找大牌眼影（如M.A.C）的平价替代，相似到像同一个模子；
- 功效词：十块钱的冬季国货护手霜，保湿力在线，手部不容易皴裂；
- 本地词：杭州拱墅门店的小猫很亲人，抱一抱心都化了。

但别为了搜索量或眼球效应，把跟产品或正文无关的词硬塞进标题。读者点进来发现货不对板，会觉得上当，平台也不提倡这种操作。

前期找词、排词确实要花点工夫；可一旦搭好框架，就能把平台提供的免费曝光用得更充分，目标用户也会持续主动找过来。
