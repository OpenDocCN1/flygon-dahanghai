# Tufting店怎么长期赚钱、还能复制？

我是跨境杨少，做跨境电商12年，也是个连续创业者。港/美股程序交易、培训行业SNS、高端西餐酒吧、跨境电商、支付通道服务、出海日本服务商、抖音选品课，以及tufting手工店，我都从零起盘做过。餐饮项目亏本关停过，其余大多数项目年变现能到百万级。我对蓝海有执念，近十年创业切入点大多选在竞争还不拥挤的地方。

今天聊的网红tufting店，看似和跨境无关，但底层运营思路相通，也是我把《选品四层方法论》放到线下做的一次小实践。

先看提纲：

1. 判断副业/小项目靠不靠谱、成功率多高

## 1. 副业/小项目值不值得做，先看两层

用《选品四层方法论》里最下面的两层——“套利”层和“流量&转化”层，就能快速判断大多数副业和小项目能不能做。

**a）套利三要素**

说白了就是：信息差、低成本、确定性。

信息差，就是蓝海思维。别人不知道，你知道；别人还没进场，你先进去。十年前跨境电商就是典型。很多老板骨子里都是蓝海偏执狂。

低成本，是尽量压低前期投入，时间和钱都算。比如“跨境电商一键铺货代发”当年就是这种玩法。十年前跨境还能低成本无脑起步，现在很难，只有专业打法才能做出类似效果，这个以后另讲。

确定性有两层：一是确定利润空间够大，二是确定已经有人跑通。尽量别自创模式，多复制验证过的模式。信息差够大、投入够低时，确定性往往也会更高。

那网红tufting店符合套利层吗？

tufting的信息差最早来自2021年12月的📕。2021年底到2022年1月，第一批在中大城市抢先开店的，很多1—2个月就收回全部投入，甚至把预付的半年房租也赚回来了。启动成本也不高：房租3000—6000元就能开干，设备和软装约1万元。一副tufting物料成本10—20元，客单价普遍200—400元，赚钱的确定性摆在那里；第一批成功店铺，又提供了模式确定性。

不专业的人选品，专业的人选模式；先变专业，再变有钱。

生意的底层，很多时候是相通的。

所以中小创业者记住一句话：没有套利空间，别急着创业。

**b）流量就是精准和便宜**

流量玩法千千万，有人能讲三天三夜，我喜欢直接说结论：流量要精准，还要便宜。

很多新手创业前没有流量思维，或者把引流想得太简单——“让朋友发发朋友圈”“找熟人来给好评”不就行了？不少实体店老板还爱发传单，这是典型的外行。传单既没有精准人群概念，成本也不低，最后转化成本根本算不清。跨境铺货的逻辑本质上是撒大网、守株待兔，可守株待兔是贬义词，真靠这个发财，世界上就没穷人了。

很多老板以为自己懂精准营销，其实未必。我有个很绝的判断法：你觉得奔驰新C怎么样？

大部分男性老板会嗤之以鼻：30多万还全系1.5T，样子货。

大部分女性老板会满心欢喜：30多万的“小S”，内饰还是S级下放。

男女看法差这么大，彼此还互相不理解，这就说明很多人并不真懂“精准”二字。

善于换位思考、有共情能力的人，往往答得好。渣男就是其中之一——渣男最懂精准，只转化可转化的人，这话不虚。

有人流就能开tufting店吗？显然不是。tufting店不适合进商场：商场人群不精准，流量还贵，租金已经体现出来了；商场店铺软装成本也更高。但每个大城市几乎都有开在商场里的tufting店。同样都是老板，差距就在这儿。

怎么解决？后面第3—6节讲。

**c）转化就是便宜和好**

老板需要便宜的流量，客户需要便宜的转化。

便宜还能拿到好东西、好体验，转化就不愁。

有些人很推崇把便宜货卖出极高价格的营销个案。个案不可复制，也没有普遍意义。

中小创业者别动不动就Jack、Pony，也别过度沉迷商业自媒体拆解大生意大人物。个案没有意义。过分强调个案、从个案引申理论，是思维水平比较低的表现。每天迷信个案、转发养生文和怪力乱神的父母们，就是这类人群。你别在另一个行业变成父母的样子。

选品上过分追新奇特、追热点、跟卖的跨境卖家很多。太关注“术”，不花时间总结“道”，人迟早会因为困境焦虑——这个困境就是拿不到红利期长的品类。新奇特产品的红利，会随着信息差暴露快速衰减。

开tufting店也是一次选品，也是在追新奇特蓝海信息差。2022年后半年，这个项目的店家确实慢慢面临竞争加剧、红利变少、红利期缩短的困境和焦虑。

tufting店要解决这个问题，仍然从流量与转化入手：流量成本有优势，价格战就有优势；转化优势怎么建，第7节讲。

## 2. 网红tufting店的正反案例

**a）开店前考察到的成功案例（临平）和濒临失败的案例（钱江）**

钱江某写字楼里有一家tufting店，老板是两个艺术院校毕业的女生。店环境很好，空间100多平，店名是西班牙语，背景音乐也是西语歌，店里有专业咖啡机，还拿出近一半空间放了不错的沙发和茶几，客单价400+。

客户体验确实棒：坐在落地窗前，一边tufting，一边看窗外写字楼林立。

但店铺年租金30万，咖啡机大几万，加上软装，前期投入几十万起步。

这样的店也许是个人情怀的成功，能满足一部分高端客户体验需求，客单也做到400以上；但从商业角度看，很难快速盈利和回本，还浪费了项目红利期，赚钱不确定性很高，在我看来甚至濒临失败。很明显，老板不懂生意的底层逻辑。

另一个店在临平，地铁口附近一个档次一般的写字楼，年租金只有几万，几乎没装潢，简单桌椅，情侣创业，客单只有200左右，但上座率明显高很多，工作日单日销售额能到近千。刨去各项成本，估算月净利润至少2—3万。

后者的模式，显然更适合副业/小创业者参考和复制，也符合套利底层要素。

**b）“都选C”的成功**

对比2—3家店后，我们更多参考临平那家，把店开在城西银泰商圈的太合中心写字楼。选址过程和要素第4节细讲。

店名起为“都选C”。这是个熟词，好记，既有relax的感觉，又能在入驻美团大众时给客户从众心理暗示。试营业期间，来店客户几乎都能记住“都选C”或“都选”两个字，甚至潜意识觉得我们是区域人气第一。我们想用羊群效应提升转化，也真的很快做到区域第一——2个月内收回所有投资，包含半年租金。同时我们把“都选C”提交了35类商标注册，为品牌授权和加盟做准备。

做跨境电商品牌时，我们也要求要么不做，要做必须能蹭到流量或蹭到转化，比如假洋牌。

“都选C”就是在蹭转化。

从第3节开始，会从精准流量和转化等方面详细拆解“都选C”的起店过程。

**c）收购了一家失败tufting店的物料和设备**

开店3个月左右，一家失败关店的tufting店联系我们，要出设备和物料。我们去他店里谈，一眼看出问题：选址不当。店在城郊创业园区，想覆盖上班族，但上班族平时上班，双休日又不在园区。正常来说，双休日是tufting店最忙的时候，一天销售额接近工作日半周总和；这家店双休日却没生意，因为人都休息了。

看着周围有人，却抓不到流量，转化自然无从谈起。

我们以6000元收购了其所有设备和物料。

**d）那些开在商业中心里的tufting店**

后来我们又考察了杭州某商业中心和南京某商业中心里的两家tufting店，上客和盈利都不理想，客单400起。本来精准流量就不多，高客单还限制转化率。

这印证了前面的判断：tufting店不适合入驻商场，属于大概率要失败的案例。

## 3. 客群画像：情侣、女学生、亲子、95后女性、跟风族

**a）tufting项目人群**

综合多家店考察结果，再结合📕推送人群，这个项目的人群很明确：首先是年轻女性，年龄基本在95后，几乎看不到95前；大学在校生是主力，一部分高中生也常来。

一副tufting完成时间1—3小时，很多年轻情侣把它当作新的消磨时间约会方式；也有网友初次约会、面基选在tufting店。项目风口期，跟风族群不少。

虽然主要适合成人娱乐，但双休日和假期，也有不少妈妈带着中学生女儿一起来玩，这属于大龄亲子人群。

这个人群的精准引流方式只有一个：美团大众的附近搜索。

**b）老文娱受疫情挤压人群**

疫情常态化下，电影院、KTV、剧本杀、酒吧、密室等遭遇关停期间，客群也会对tufting产生需求。tufting属于新文娱，尚不在政府管控之列，只要不遇极端疫情，常态化管控下甚至长期利好。tufting消磨时间够长，花费也更便宜。习惯老文娱打发时间的年轻人，在老文娱关停时，tufting成了为数不多的选择之一。

这个人群的引流方式之一，是与老文娱项目结成广告联盟，客户互推。玩法不少，不限于这一种。

**c）小手工项目刚需人群**

进一步分析和考察非tufting类手工店后，我们发现一个确定需求，也解释了为什么95后、00后女性喜欢手工项目：这个人群小时候就接触奶油胶之类手工。尤其城里95后、00后，十多年前城市商业综合体已经很多很发达，幼年亲子活动有大量是父母带着做手工。等他们长大或接近成年，仍然对手工娱乐有兴趣，这仍是记忆中的娱乐方式。他们需要继续找地方玩石膏娃娃、奶油胶手机壳等手工项目，但很多城市这类店仍只针对幼儿，没有专门面向刚成年大人的。这些刚成年的大孩子，也不好意思去幼儿店玩。

这一点上，市场供需失衡。我们考察发现，某些大城市大学城竟然没有一家针对大学生的奶油胶类手工店，更不用说tufting这种新潮手工项目。

所以某些区域形成市场空白，这就是信息差，是典型有套利空间的项目。

这也是为什么我们决定在tufting店中增加石膏娃娃、奶油胶手机壳等产品线。第7节会详细分析如何把这些项目作为引流款，打造相对综合的手工店，从网红项目店往长期盈利的手工项目店发展，并实现可复制性。

**d）大客户人群**

年轻女性员工为主的公司团建，可以作为店铺运营尚有余力时的选择。团队客户资源因人而异，可结合自身情况规划，这里不多赘述。

## 4. 选址关键词：商圈、地铁口、小区、院校、写字楼

杭州tufting店里，我们看到很多选址有问题的。前文已提到一个开在创业园失败的案例。

选址要围绕人群，不是老板拍脑门觉得哪里便宜或哪里人多。

第3节分析完，接下来就简单了。

怎么选址？覆盖上一节的人群a、b、c，尽量方便人群d；当然，忽略d也不是不可以，因为很多d希望你带设备上门服务。

**a）人群a、b、c必须在你周边**

或者说，你周边必须有人群a、b、c。但真的很多店做不到。

所以选址周边必须有商圈、小区、院校。这三样里面有人群a、b、c。

引流营销无非两种：人找你，或者你找人。无论哪种，都得离他们近一点，交通方便一点。我做了十年多跨境电商推广投放，广告主要也是这两种：display展示广告，你找人；search搜索广告，人找你。生意底层就是这么相通。

大部分能立即启动成功的生意，都得益于search广告便宜，然后产品转化率高。

因为search广告天然精准。跨境电商要做到这个精准，也许还需要点专业度。

tufting店不需要。

tufting店启动，下文会细说，靠大众美团附近搜索。你离精准的人近，等他们来搜索你，还有比这更简单的吗？

**b）不要进商场**

上文有失败案例，不再赘述。商场流量不精准，流量贵就是转化成本高。这点很重要，所以单独做标题提醒。

**c）地铁口、写字楼，严控租金成本**

地铁口的写字楼，50—60平，自带地板、白墙就可以，真的不贵。杭州城西银泰旁边的萍水街地铁C口出来几乎0米，就是我们店所在的太合中心，月租金6000，大学生创业还有补贴，这样开店简直稳赚不赔。

**d）周围没人开店**

我们选址开店时，城西银泰附近、萍水街地铁站方圆2—3公里内只有我们一家tufting店。目前已经开到3家左右。还有同业者想开进太合中心写字楼，但太合商管很专业，对竞业有保护，不租给非我们的第二家店。

最重要的是，太合中心周边有城西最成熟的银泰商圈，有较多中高档小区，也有院校。

## 5. 平衡点：用尽量低的开店成本，满足基本客户体验

**a）不要选市中心商圈**

市中心商圈的tufting店也许客流确实多，但租金成本压力非常大，写字楼也不例外，周围肯定有竞业同行，客单跟非市中心商圈几乎差不多。hard模式不要选。

**b）尽量不要装潢**

写字楼里的tufting店，赚不赚钱，跟装潢好不好真的关系不大。这块前期成本可以省很多。很多写字楼自带硬装已经完全够用，比如太合中心就是。

**c）桌子板凳用好闲鱼**

tufting有时候甚至有客户喜欢站着做。我们闲鱼采购的桌子100多一张，凳子20一个，按店铺布局放满，才2000块。

前台桌闲鱼500，还碰到好心人免费送上门。宽带不装，或者用随身WiFi放店里，省去商业宽带较贵的初装费和月费。电脑也闲鱼，会配的人，1000多整套完全够用。

**d）接受培训，购买筹备清单**

时间就是成本，付费是捷径。筹备期我们看到有先期开店店家在自媒体售卖筹备清单和简单教程，果断购买。

从第4节写到这里，目前成本支出是：房租6000，桌子板凳2000，tufting设备和物料10000左右，房租付3压2是3万，美团入驻4800，搜索推广充值3000，全部支出5万左右。这钱现在够开什么店？而且还是客单毛利10—20倍的项目。

## 6. 店铺引流：低成本、精准、高确定性流量

知道人群，就不愁没有精准流量。但真的很多老板没有这个概念，或者概念不够完善、不够系统。

**a）自媒体流量没有确定性，不适合用来启动店铺**

前一段时间，赚钱有上海圈友分享过tufting项目，但他的分享缺乏人群分析和流量分析，引流主要靠📕。这适合前半年项目风口期没什么竞争的时候。

有竞争时，别人看到📕，完全可以就近搜索别家店去玩。另外，自媒体引流永远是个案，个案永远难以复制。大多数老板不掌握自媒体引流的确定性。虽然圈友分享的项目月赚10万，但我个人认为可复制的确定性较差。2022年4月份，我们也付费请了杭州某📕红人来店体验并宣传，但复盘下来，对流量和转化的影响几乎没有可量化的改变。就事论事，不针对这位圈友老板。

项目风口还没形成或刚刚形成时，即需要教育和引导需求时，要投display流量，自媒体就是这种。项目火起来后，需求不需要你引发，摘风口的果子，这时靠search流量，也就是上文说的“你找人”和“人找你”的区别。我分析，这也是为什么早期启动项目靠自媒体更好，后期靠平台搜索更好。但自媒体终究流量确定性有问题。

**b）美团CPC流量浅尝辄止**

能把这个项目启动成功的流量，一定是大众美团附近搜索，也就是覆盖第3节中的“人群a”。这一节只详细讲这一点，人群b、c、d的引流，上文已经提到。
