# ChatGPT加AI绘画，定制玩法不止生日祝福

把ChatGPT和AI绘画组合起来，能做的事情并不只是生成几张图。七小在2023年3月10日分享的一个场景，就是把这套工具用于生日祝福的个性化定制。

[PRE0] [PRE1][PRE2]

评论区里，不少人认可这个思路，有人直呼厉害，也有人觉得还能当作炫耀素材。卓桐则顺着这个方向做了延展：同样的方法可以拿来做求婚纪念册或短片，用漫画呈现两个人从恋爱到求婚的过程。从恋爱走到求婚，不少男性往往想不到拍照存档，也没有剪成短片的习惯；而借助ChatGPT加AI绘画，可以把两人的相处过程和关键瞬间画成漫画，做成求婚或婚礼的定制产品。产品可以是短片加画册，大概率能卖到几百甚至上千元。

当然，也有人提出了实操问题。melisa就问：要是主角换成朋友，如何把朋友的人脸合成到画面中？这个问题也说明，场景越具体，落地时越需要解决细节。

从生日祝福到求婚纪念，ChatGPT与AI绘画的组合，确实让定制内容的玩法有了更多可能。
