# Sora来了，人类还分得清真假吗？

出门问问创始人李志飞在朋友圈抛出一个灵魂拷问：大语言模型ChatGPT模拟的是虚拟思维世界，而Sora这类视频生成模型模拟的是物理世界——当两个世界都被建模了，现实到底还剩下什么？

普林斯顿大学计算机科学教授Arvind Narayanan同样忧心忡忡。他指出，Sora这类技术可能催生大量“深度伪造”视频，普通人根本分辨不出来。虽然AI生成的画面仍有破绽，但多数人压根不会留意那些细节。“迟早，我们得习惯一件事：看起来真实，不等于真的真实。”

**隐私这道坎，绕不过去**

Sora训练时如果未经处理就使用了带人脸、声音样本等敏感信息的素材，侵犯隐私几乎是必然的，生成的视频还可能间接泄露这些信息。可以预见，Sora大规模铺开后，被抓取、被模仿的个人信息只会越来越多，隐私保护将变成一块难啃的硬骨头。

**版权这笔账，迟早要算**

上海大邦律师事务所高级合伙人游云庭直言：“Sora正式向公众推出前，必然要面对现有行业的挑战。训练素材的授权合规本身就是个大问题，目前并不透明；输出内容不侵权的合规同样棘手。”

去年好莱坞编剧和演员大罢工，核心谈判点之一就是人工智能的适用范围——这个问题至今悬而未决。

AI跑起来之前，得先喂数据、训模型。训练阶段不可避免地要吞下海量素材，其中不少是别人享有著作权的作品，擅自抓取就埋下侵权隐患。2023年，美国一群作家对OpenAI发起集体诉讼，指控其未经授权将他们的作品用作训练数据，认为这本身就是在复制作品。法院虽以证据不足部分驳回，但AI作品版权归谁，已经是一个迫在眉睫、必须回答的问题。

**假信息泛滥，谁都可能中招**

AI短视频构建的世界，极可能是虚实交织的迷宫。假视频的制作成本越来越低，假新闻、假消息泛滥的风险随之飙升。更要警惕的是，不法分子会利用技术犯罪——AI诈骗会变得更加逼真；还有人通过人像采集合成视频，用来诬告陷害他人。

此前Deepfake在网络上掀起的假信息和谣言，对泰勒·斯威夫特等明星和普通人造成的伤害，都是OpenAI必须直面的质疑。

未来Sora向普通用户和社交媒体创作者开放后，海量视频内容必然涌现，但不是每个人都会像创意或广告从业者那样留心法律问题。

今年2月，一伙诈骗分子利用深度伪造技术，对一家跨国公司的香港分公司下手，成功骗走2亿港元——这是香港迄今损失最大的AI换脸诈骗案。

美国歌手泰勒·斯威夫特最近也深受深度伪造之苦。大量虚假“不雅照”在社交网络疯传，引发轩然大波。这已经不是她第一次受害。就在“不雅照”事件前不久，一则AI生成的斯威夫特带货广告在海外社交媒体上被疯狂转发。这则假广告用深度伪造技术合成了她的声音，把声音、形象和某品牌炊具广告片段拼在一起，宣称免费送粉丝炊具，诱导受害者点击并支付运费——炊具当然不会真的送出。

每个人的声音和相貌都是独一份的，而深度伪造技术正在抹掉这条边界，让“眼见为实、耳听为真”变成过去式。多名专业人士指出，随着AI技术的发展和普及，深度伪造被用于违法犯罪的比例会上升。“像Sora这类模型工具和相关软件的开发普及，即使是不懂技术的普通人，也能制作深度伪造内容，而且虚假内容产出速度更快，也更难被人眼识破。”裴智勇说。随着Sora等大模型技术的开发和应用，用更少的人脸数据就能构造出高逼真的特定人脸模型，客观上降低了不法分子制作虚假人脸视频的成本。

目前OpenAI承诺会向全球的艺术家、教育工作者和政策制定者征集反馈，了解人们对这项技术的担忧。

针对业界忧虑，美国联邦贸易委员会（FTC）2月15日提出规则，禁止使用AI工具冒充个人。FTC表示，正在提议修改一项已经禁止冒充企业或政府机构的规则，把保护范围扩大到所有个人。OpenAI内部也在持续开展模型伦理侧的对抗性测试，比如错误信息、仇恨内容、偏见内容、色情暴力内容等，会在文本输入时被拒绝。

Sora目前仍未对公众开放，只对“红队”（Red teaming）开放，处于安全测试阶段。在OpenAI针对Sora开展的“红队”演习中，专家们试图攻破AI模型的保护措施，评估其被滥用的可能性。OpenAI发言人表示，目前参与测试Sora的都是“在错误信息、仇恨内容和偏见等领域的专家”。这项测试至关重要，因为Sora可能被别有用心者用来生成虚假视频，骚扰他人，甚至干扰政治选举。学术界、商界、政府和AI专家都担心，AI生成的“深度伪造”内容可能造成虚假和错误信息的广泛传播。

据外媒预测，GPT-4经过6个月测试后正式向公众开放，预计Sora将于8月向公众开放。

网络技术人员建议，提供AI深度伪造技术的服务平台和公司应推行隐形水印机制，在视频、音频和图像中嵌入不可见的水印来保护信息，以便快速识别AI合成内容并进行溯源；各社交平台也应以技术手段加强对疑似AI生成图文、视频内容的识别。OpenAI已经在其系统生成的视频中加上水印，标明这些视频由AI生成。但该公司也承认，水印可被移除，也可能难以被发现。OpenAI还承认，尽管进行了广泛的研究和测试，“我们仍无法预测人们将使用我们技术的所有有益方式和滥用我们技术的所有方式”。OpenAI发言人强调，在将Sora用于OpenAI的产品之前，公司正在采取多项重要的安全措施。例如，已使用自动化流程，防止其商业AI模型生成针对政客和名人的虚假内容。OpenAI称，在真正面向公众推出产品时，将确保生成的视频包含来源元数据，并推出检测视频真伪的工具。

业内人士指出，在当下治理框架、管控措施都未跟上的情况下，仅靠企业恐怕无法提供社会所需的人工智能安全性和信任度。

除了技术手段，法律手段也得跟上。

我们迎来了Sora这个被誉为视频生成领域里程碑式技术的时代，同时也必须面对一个令人不安的事实：眼见不再为实，人类的安全感和信任基础正在被侵蚀。出门问问创始人李志飞的言论和Arvind Narayanan教授的担忧，指向同一个核心问题：当物理和虚拟世界都可以被模拟，我们凭什么分辨真实与虚假？

Sora的出现让深度伪造技术大步前进，虚假信息的制造成本大幅降低，生成的视频更难辨真伪，随之而来的是一连串社会、法律和道德难题。

未来，个人隐私保护将面临严峻挑战，版权争议会频繁爆发，假新闻和诈骗案例可能激增。Sora大规模使用后，更多个人信息会被采集利用。去年轰动一时的香港AI换脸诈骗案，利用深度伪造技术成功骗走2亿港元——隐私泄露给社会带来的冲击前所未有。2023年美国作家对OpenAI提起集体诉讼，控诉其未经授权将他们的作品用作训练数据。AI版权同样是亟待立法解决的紧迫问题。

在这样的背景下，AIGC（AI生成内容）安全该往哪儿走？

技术平台和开发者首先要扛起责任。据悉，OpenAI已经通过加入水印、开展红队测试和增强内容识别功能，努力降低技术被滥用的可能。国内自媒体平台也在倡导创作者主动声明AIGC作品。

但这些还远远不够——技术跑得太快，规则和措施的制定远远落在后面。法律制度的更新同样迫在眉睫。美国联邦贸易委员会提出的“禁止使用AI工具冒充个人的规则”是一个积极信号，但需要更多国家和地区跟进，建立全球性的法律框架来规范AI技术的发展和应用。

公众教育和意识提升也至关重要。通过普及教育，提高公众识别和防范AI生成内容的能力，让大家意识到不是所有内容都真实可信，学会在接受信息之前先验证。

人类需要一种全新的视角来面对这个问题。正如Arvind Narayanan所言，我们可能需要适应一个“现实主义不再是真实性的标志”的新时代。我们可能需要重新定义真实性、信任和安全的含义，建立基于新技术的全新社会信任机制。

Sora代表了人工智能领域的重大进步，也向我们展示了技术进步的双刃剑效应。这需要多方参与、多维度协作的社会性共同努力，才能在享受技术便利的同时，保护人类的安全和信任不受侵害。
