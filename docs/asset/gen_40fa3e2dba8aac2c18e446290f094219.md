| 下游能收到上游机器人明确的 @ 提及 | 真实群消息和下游回复 | 通过 / 未通过 |
| 上游使用的是正确的下游机器人 ID | 上游应用查询到的群成员记录 | 通过 / 未通过 |

第一次自动接力通过后，再多跑几次稳定性测试。下面这些条件都满足，再把它变成日常方式：

- 上游 Agent 连续几次都能给出结构一致的交付消息；

- 没有重复点名和循环触发；
- 权限与结果链接保持稳定；
- 遇到异常能暂停并通知人。
