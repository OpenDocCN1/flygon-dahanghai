# 7.3 售前沟通&成交

客户进了私域，再开始细聊需求。

# 7.3.1 沟通思路

📌 在AI写作项目里，客服得是plus级写手。销售若不懂后端产品，很难成为好销售；不写作、不懂写作的人，也难把客服做好。优秀客服通常是从优秀写手里长出来的。

客服报价、谈单、成单，受很多变量影响：沟通、谈判、说服、销售、用户心理、预期管理、专业展示、情绪价值等。

AI写作市场没有统一价，品类属于非标品，非标品才有溢价空间。最终成交价会受稿件类型、用途、字数、时间要求、同行竞争、客户预算、谈单话术等影响。

1. 客服第一目标是成交，但别为了成交过度承诺，要以长期合作为目标。
2. 站在客户角度想问题，有同理心，让客户感受到利他精神，以信任为基础建立深度关系。
3. 用专业话术、成功案例、实力背景等展示专业度，增强信任。
4. 谈价以价值为导向，引导客户理解盲目压价会伤害写作质量，避免被动陷入还价模式。

# 7.3.2 客户沟通流程

# 7.3.2.1 接待客户

第一步：问候与自我介绍  
示例：“宝子你好，我是xx专业的老师，可以和我说一下你的写作需求。”  
同时判断客户身份与付费能力，可以问专业、学历、学校/学校级别，也可以看闲鱼IP、发品/成交记录、朋友圈等。

第二步：了解需求  
了解学历、学校、专业、行业、公司、职业。  
引导客户详细描述稿件类型、具体用途、审核/汇报对象。  
示例：“这份商业计划书是作业、参赛还是融资使用？”、“这份教案是日常授课还是参赛使用？”

第三步：问题探询  
询问字数、语言风格、完成时限等。  
引导客户补充信息，比如是否需要数据图表、设计图等，以便分析写作难度和工作量，准确定价，避免踩坑。  
示例：“除了字数7k以上，这篇调研报告是否需要问卷调查和数据分析部分？”

# 💡 P.S. 看不懂客户需求怎么办？

可以借AI先大致理解需求，用自己的话梳理，再和GPT对话。prompt示例：“客户要写教师征文，主题为初中英语教学里情景短剧的作用，篇幅6000字；请你以专业教师征文写作老师身份，和客户聊思路与架构，展现专业并建立信任。”  
也可以把自己代入客户角色，去咨询闲鱼、淘宝同行。  
问客户有无参考样稿/对标范文，分析工作量；若没有，去Meta搜类似文章，初步评估工作量。

# 7.3.2.2 介绍服务与报价

报价与费用说明：  
按需求给阶梯报价，分“正常质量XXX”“高质量XXX”，让客户明白不同档位的价格区间。  
解释收费标准和影响报价的因素，如加急、内容复杂度、特殊要求等，让客户理解费用逻辑。

折扣与优惠：  
预算有限的客户，为促单可让利5-10%，但幅度别太大，否则客户会以为还有很大议价空间、利润很高。  
议价时强调价格与质量挂钩，引导客户理解：在不降质量标准前提下，可以通过减少字数、少做1-2个图表、限制修改次数等方式适度降价。让客户感到每次调整都有成本依据。

# 💡 AI写作定价公式

价格=工作量（基础+复杂+修改）+质量要求+时间紧急程度

以调研报告为例：  
基础工作量相当于字数。  
复杂工作量看领域是否小众、是否需要特定专业知识、是否涉及数据、表格、设计图、代码、公式、仿真、建模等，对写手要求高。  
修改量看是否反复修改或改核心内容。  
质量要求看客户目标。  
时间紧急程度：急单需加收加急费。

按客户信息和需求报价，按交付质量、写手资质、修改次数等维度做阶梯报价，给客户多种选择；小单可直接一口价。

演讲稿谈单案例：  
1. 需求沟通与收集：稿件类型、字数、用途、交付时间。  
2. 报价：按质量要求、修改次数提供不同方案。

# 7.4 售后问题解决方法

# 7.4.1 如何规避售后问题

专业客服能在售前把大部分售后消化掉。比如明确需求与规则，向客户要评分标准、参考样例，确认稿件目标是获奖级还是普通应付领导；详细拆解需求指标，用售前手段提前排雷，避免后续纠纷扯皮。

售前完成后，还要看交付质量。客服谈得再漂亮、价格再理想，若写手不靠谱、质量低，也会砸掉信任。

高质量写手能靠满足需求的稿件让客户满意。市场上找人代写文案的客户，80%对质量要求并不高；用航海手册里的海盐大法（方法论）写作，已经像拿着秘籍，能明显高于普通水平。

99%找代写的客户并非想白嫖，而是需要质量不错、符合需求和标准的稿件。我们分析大量售后案例，原因无非两类：

1. 谈单客服不专业  
客户需求不明确，客服无法挖掘梳理真实需求，只能给写手不完整或被加工曲解的需求。写手接到任务后不知道写成什么样才能满足客户，往往交稿后被要求重写。半懂不懂、需求不清的客户仍说不明白想要的效果，稿件改了一遍又一遍，最后客户给客服贴上“不专业、不靠谱、瞎写”的标签。

2. 写手水平不达标  
交付稿件AI词多、内容空、结构乱，通常因为没搞懂需求，或缺相关经验与背景。客户拿到后只觉得“不专业、不靠谱，写的啥，还能信你吗？”改了几次仍有问题，旧问题未清又出新问题，客户最后说：“退款吧，写的是什么东西，骗子，改这么多次浪费我时间，还没搞定，没空跟你墨迹了。”

大量实战订单剖析和优化后，可以确定：95%的售后问题能靠售前解决。专业客服+靠谱高质量写手，能搞定绝大多数客户。

当然，小白处于练手期，会有成长过渡。前面教的沟通思路和技巧还没完全吸收，出现少量售后退款也正常。技术实力不够硬时，可主打态度好。市场和客户是最好的老师，认真修改、负责到底；宁可多查资料、多改几次；实在满足不了，再平和退款，避免客户去评论区留差评，影响新客户信任。

小白起步，吃亏是福。搞不定的订单和客户很正常，都是宝贵成长经验。

若没cover住客户，又实在不想退款，可参考下方退款纠纷话术，相信能帮到小白阶段的宝子。

能不通过闲鱼官方解决纠纷，就别走这一步。这一单的钱没那么重要，时间宝贵，退给客户。你和客户撕逼battle的聊天记录，99%的客户会截取对自己有利的部分去差评，而评论区差评永久可见。你再有理，一些客户看到差评和撕逼记录，也会印象不好，不想冒险找你。理智的人少，看到你撕逼，下意识觉得他找你写也可能被撕逼的人更多。

快节奏时代，差评多的店铺，客户可能不点开细看原因，店铺那么多，直接划走。非100%好评店铺在闲鱼权重会降低，拿不到100%好评标签，影响商品推流。

稿件写作是虚拟商品，平台通常偏向顾客，所以要更有效处理纠纷，尽量挽回损失。

# 八、常见问题QA@小虎牙@陈 bu 懂

# 8.1 闲鱼基础问题速答

Q1：手机实名账号有数量上限，能不能用亲友注册认证新号，再放到自己手机上运营？  
A：可行，但闲鱼可能每半个月到一个月要求人脸识别。

Q2：注册支付宝和闲鱼账号必须用新手机吗？  
A：不必，但运营要遵循一卡一号一机：一张手机卡、一个账号、一个手机。

Q3：闲鱼在哪里解绑淘宝？  
A：设置→账号与安全→授权管理。

Q4：鱼小铺领域选择在首页推荐权重更高吗？推荐开吗？  
A：影响不大。新手前期先别开鱼小铺，等账号询单起来再开才有效果。

Q5：三个账号的头像、姓名等信息要不同吗？  
A：头像、姓名等信息要有所区别，防止同行恶意举报。店铺商品风格可统一，统一风格能体现专业性。

Q6：手机同时开流量和wifi，闲鱼设使用流量，可行吗？平台检测设备IP、流量IP还是wifi的IP？  
A：风控规则会变，设备IP和流量IP都会检测。严格一卡一号一机基本没问题。

Q7：背景图能用同行的吗？  
A：可以，但直接搬运注意水印，去小红书搬运也一样。还要注意图上是否含违禁词，注意避开。

Q8：我三个支付宝号都在同一手机登录过，有问题吗？  
A：没问题，后续正常分开运营即可。

Q9：背景图和头像含写作敏感词可以吗？  
A：不行，有违规概率。图片不必放敏感词，文字和SEO搜索才用得上。背景图和头像最好体现专业度。

Q10：支付宝绑同一张银行卡会影响流量吗？  
A：不会。

Q11：创建简历开启副业模块需要打开吗？  
A：不需要。

Q12：不同手机用同一个苹果ID下载闲鱼App有影响吗？  
A：不会，IP和设备独立。

Q13：手机双开闲鱼登录两个账号有影响吗？  
A：会，两个账号同一IP会影响流量。

Q14：能在其他人商品下留言截留吗？  
A：不要频繁在别人商品下留言，别人会删留言并举报；在留言里留微信也会违规。

# 8.2 闲鱼账号养成问题速答

Q1：闲鱼运营用老号还是新号？  
A：都行。老号权重可能更好，新号需养一段时间。

Q2：养号浏览商品时，要和商家沟通一个来回才算完成，还是点“我想要”就行？  
A：完善个人信息后可只点“我想要”；若还是新号或个人购买的账号，可来回沟通。

Q3：变成写作号后，还要咨询同行吗？  
A：要，继续刷一刷、养一养，既增加权重也增加活跃度。

Q4：浏览商品要看“我想要”数量吗？咨询、收藏看什么数据？  
A：要看。把自己当成真实买家，想想你买东西时会关注哪些信息。

Q5：首页下拉刷新要减少吗？上午主页都是写作相关，刷新多了下午就变乱。  
A：号没养好就会这样，继续养号。

Q6：主页养好了，后面刷新又变回去，需要重新养吗？  
A：每天保持闲鱼基本运营动作，一般不会变回去。

Q7：养号过程怎么录？每天养号要录屏吗？  
A：录屏即可。我们主要看你刷品动作，按教程养号2-3天基本可以。

Q8：上品后主页没出现相关写作商品，要停止上品继续养号吗？  
A：可以继续上品，同时每日养号，把号养垂直效果更好。

Q9：搜索时用闲鱼推荐词和自己手动输入关键词有区别吗？  
A：没有区别。

Q10：首页权重看推荐的这四个吗？  
A：是的，这看养号。

Q11：短时间关注、评论、点赞过多，被提示操作频繁，20多分钟后再操作，会影响后面流量吗？  
A：账号权重不够、评论截流数量多，触发风控。慢慢养号并后续交易即可。
