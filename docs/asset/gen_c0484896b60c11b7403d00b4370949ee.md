# 5.1 抖音搜对标，新手先学这招

作者：@云珞 YunL @猫柠 @张柯 Ker

做短剧推广，别急着闷头开剪，先去抖音找“参考答案”。一个值得模仿的对标视频，通常要满足这些条件：发布时间在一天以内；点赞破千；播放量明显甩开该账号的其他作品；账号粉丝基数越小，越有参考价值。

第一步，在抖音搜索“短剧”，筛选条件选“一天内”和“最多点赞”。如果一个词没找到合适样本，就换词继续试，比如“短剧推荐”“好剧推荐”“热门短剧”“因为一个片段看了整部剧”，或直接搜具体剧名；也可以点开任意视频，看看别人用了哪些标签，再照着标签去搜。

[PRE0]

第二步，按点赞数排序，优先挑与自己方向一致的作品——做男频就找男频，做女频就找女频——点进点赞1000以上的视频查看。遇到符合条件的样本，前期可以先做1:1仿剪，之后逐步加入自己的创新。

如果某部剧的数据看起来不错，重点观察三件事：剪的是哪部剧；视频时长多少，可作为剪辑长度参考；开头和结尾怎么处理，可作为剧情编排参考。

要是同时找到多个符合条件的视频，且点赞量接近，就优先模仿粉丝数更少的账号：
