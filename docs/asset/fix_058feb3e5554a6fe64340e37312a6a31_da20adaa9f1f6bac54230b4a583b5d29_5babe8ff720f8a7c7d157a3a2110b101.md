# 3.1 产品订阅套餐设计

套餐设计是产品商业模式的核心：既要接住不同用户群体的需求，也要兼顾收入和增长目标。

# 3.3.1 设计思路

1. 分层满足需求

零元用户：降低试用门槛，扩大用户池。

付费用户：拿到核心功能和效率提升。

高阶用户：解决专业/企业级需求，附带 API 调用、团队协作、专属服务等额外价值。

2. 价格锚点效应

至少准备低、中、高三档，用户会自然偏向中间档，这就是心理学里的“折中效应”。

3. 差异化设计维度

使用额度：视频时长、生成次数、存储空间。

功能权限：高级功能、API、批量处理。

服务体验：客服响应速度、团队成员数、白标/定制化。

结算周期：按月/按年，年付打折。

# 3.3.2 常见套餐结构

以 AI 工具站/视频剪辑 SaaS 为例：

1. 零元档（Free）

目标：拉新，并让用户建立使用习惯。

内容：限制部分功能（如导出视频带水印）；每月设置使用上限（如 30 分钟视频处理、100 次 AI 调用）；提供社区支持。

2. 入门档（Starter / Pro）

目标：个人用户或刚起步的创作者。

定价：9.9–19.9 美元/月。

内容：去水印；提高额度（如每月 10 小时视频）；开放常用高级功能（字幕编辑、批量导出、AI 解说）；邮件客服。

3. 进阶层（Advanced / Creator）

目标：重度个人创作者或小团队。

定价：29–49 美元/月。

内容：更高额度（每月 50 小时视频）；全功能解锁（API、自动化工作流、跨平台发布）；团队协作（3–5 人）；优先客服（实时聊天）。

4. 企业档（Enterprise / Custom）

目标：中小企业或大客户。

定价：99–299 美元/月，也可定制报价。

内容：无限额度或大幅扩容；专属客户经理；白标/二次开发能力；发票和法人合规支持；SLA（服务级别协议，保障稳定性）。

# 3.2 收款渠道

# 3.2.1 Stripe 与海外公司注册

为什么要注册海外公司？

- 有稳定的收付款渠道和海外银行账户；
- 很多海外服务对大陆身份有限制，风控也更严；用海外公司主体更容易接入。

海外手机号准备：

- 英国 giffgaff：180 天发一条短信就能保号，费用约 £0.3，官网可免费申请；
- 美国 Ultra Mobile PayGo：月租约 $3；
- 上面这些号码也可以通过淘宝、京东代购。

海外公司注册地怎么选：

- 英国公司：注册更简单、更便宜，推荐 [1st Formations]，开户可用 Wise 企业账号；
- 美国公司：更适合拓展业务，常见注册州是 Wyoming（怀俄明州），公司类型选 LLC，适合个人开发者。

一站式服务推荐 Firstbase：

我选的是 Firstbase，体验更像 SaaS，注册、地址公证、EIN、开户一条龙。

流程概览：

1. 注册公司：选怀俄明州 LLC。
2. 地址公证：租私人邮箱地址，用 Notarize 视频公证（1583 Form）；准备身份证明（护照/驾照翻译件，淘宝可代办），注意照片和地址要同页展示。
3. EIN 申请：Firstbase 代办，大约 10 个工作日收到 IRS 信件。
4. 银行开户：推荐 Mercury，关联 EIN 和护照后，1 个工作日内审核通过。

走完这些，你会拿到：公司主体、EIN、私人地址、银行账户、海外手机号。

Mercury 银行优势：

- 虚拟卡不限量，能按商户限制使用，管理订阅和退款方便；
- 虚拟卡可绑支付宝，单笔 200 元以下免 3% 手续费；
- 可接收账单地址邮件，比如 Google AdSense 验证信件；
- 支持申请实体卡并转寄回国。

Stripe 商家账号开通：

- 用 EIN 注册即可；
- 网站语言可切中文填写信息；
- 个人验证用护照；
- 提现账户绑定 Mercury；
- 建议同时注册 Lemon Squeezy、Paddle 做备用收款渠道，但需要验证产品网站。

Wise 个人收款与提现：

- 支持大陆身份和护照注册；
- 入金可通过 Mercury 转账，或淘宝代充；
- 实体卡（含 3 张虚拟卡）需 $9，支持激活后修改地址再申请；
- 支持提现到国内银行卡、支付宝、微信，手续费低，汇率比国内结汇更优。

# 1. 流量运营

我的价值观里，产品永远第一位：你有没有真的解决用户问题。所以我们一直强调找 PMF，也就是产品和市场的匹配度。产品跟市场足够匹配，流量就不会是问题；像特斯拉、微信这类产品，本身就不需要靠营销。但新产品起步，至少要先拿一部分流量做冷启动，后面再根据产品发展决定用哪种方式放大。

# 1. SEO（搜索引擎优化）

SEO 是最有长期价值的流量来源。核心是优化网站和内容，让搜索引擎更愿意推荐，从而拿到免费自然流量。

关键要点：

- 关键词策略：盯住用户真实搜索需求，选相关度高、竞争没那么激烈的词（工具可用 Google Keyword Planner、Ahrefs、Semrush）；
- 内容建设：持续产出高质量落地页、教程、FAQ、博客文章，解决用户背后的搜索意图；
- 权重提升：通过友情链接、投稿、媒体报道拿高质量外链；
- 用户体验：优化加载速度、移动端适配和交互设计，让用户愿意多停留。

适用场景：适合想长期积累、沉淀品牌价值的产品，比如工具站、知识型网站。

案例：海外 AI 工具站（如 TAAFT、Futurepedia）靠 SEO 做了大量长尾关键词页面，持续拿到自然访问。

# 2. 社媒营销（Social Media Marketing， SMM）

社交媒体传播最快、也最灵活，核心是借平台的传播机制，让用户主动帮你扩散内容。

常见平台：

- 海外：Twitter/X、Reddit、YouTube Shorts、TikTok、LinkedIn；
- 国内：小红书、抖音、知乎、微博。

常见打法：

- 短视频/动图展示：用对比、演示、教程快速讲清产品价值；
- 话题运营：蹭热点、参与讨论，在评论区适度引流；
- KOL/达人合作：借有影响力的人快速放大传播。

适用场景：特别适合冷启动，尤其是视觉冲击强、容易引发讨论的话题型产品。

案例：不少 AI 换脸、AI 绘画应用，都是先在 TikTok 上用效果展示视频走红，然后才实现规模化获客。

# 3. 付费广告（Paid Ads）

付费广告是拿精准用户最快的方式，直接用钱换流量和转化。

常见渠道：

- 海外：Google Ads（搜索、展示、YouTube）、Meta Ads（Facebook/Instagram）、TikTok Ads；
- 国内：百度推广、抖音广告、快手广告。

操作关键点：

- 精准定向：按兴趣、地域、年龄、消费能力筛人群；
- 转化追踪：用像素/转化 API 跟踪行为，持续优化投放；
- 小额测试→规模化：先用多组广告小额测试，找到 ROI 最高的素材，再逐步加预算。

适用场景：适合需要快速拉新或验证市场需求的产品。

案例：不少 SaaS 创业者会先投 Google Ads，用“关键词广告 + 免费试用”测试市场接受度，再决定要不要长期投入。
