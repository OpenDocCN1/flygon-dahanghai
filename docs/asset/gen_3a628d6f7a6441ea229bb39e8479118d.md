**用 Git 手动拉取**
前提是电脑上已装好 Git 工具。点开后会弹出黑色命令行窗口，按顺序执行：
输入 `cd ..` 回车；
输入 `cd extensions` 回车；
输入 `git clone XXXXX.git` 回车；
等待下载完成即可。
注1：上面的 XXXXX 指你要安装的插件地址。
注2：通过 Git 安装的好处是，后续插件更新会更方便。
