# 3.3.1.2 门店裂变四步法 @尹基跃

第一步，先完成门店裂变海报的策划与设计，让海报中的扫码入口直接指向门店的个人微信号。

第二步，设置转发激励：顾客把店内海报发到朋友圈，立刻可享五折优惠，或者额外获赠一杯饮品；用一杯饮料的成本换来一次朋友圈曝光，投入非常低。

第三步，提前打磨话术。海报和转发文案的领取方式可以设计为——先添加门店个人号，再回复指定关键词获取；同时准备好引导顾客转发的沟通话术。

第四步，把活动流程安排清楚。配合合适的社群工具来辅助执行，让整个活动推进得更顺畅、更高效。

四步做完，一个小型裂变闭环也就跑起来了。

出处：《饮品店私域流量构建的几点建议》
