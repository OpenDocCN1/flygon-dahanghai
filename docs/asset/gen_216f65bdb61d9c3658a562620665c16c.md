# 四步选品法：百万爆款的底层路线

新手先别急着铺货上架，先把选品这件事做专业，往往才是更短的路径。

我是跨境杨少，做跨境13年，跨行业连续创业，九成以上项目做到年变现百万级，也是彻底的“蓝海偏执狂”。很多人对《选品四层方法论》感兴趣，这篇是它的微缩版，完整内容在付费课。我把选品从底层往上拆成四层：一，套利；二，流量与转化；三，模式；四，品与品类。翻成大白话：第一层是用低成本、信息差和确定性管住风险；第二层是每花一笔钱、每投入一段时间，都必须解决流量或转化中的至少一项，别自嗨；第三层是选品要升级成选模式，才能吃到更长的红利；第四层是建立自己的“选品字典”，让成功可以规模复制。

接下来，我用一个四步选品范式，演示这四层怎么被满足。标题看起来夸张，但过去一年多我不止一次分享：在亚马逊官方活动做嘉宾时讲过，也在其他线下大会讲过；听众里有大卖、大V、大服务商、外贸厂老板，多数人承认自己的成功大体没跑出这四步。一些国内电商朋友也受启发，有人按这个思路找到淘宝蓝海产品，客单净利做到200—400，红利期还不短。所以这篇正标题不再强调“跨境电商”。生财里不少大V是强流量团队，流量做得好当然能成功，甚至一夜爆发，但也会有昙花一现的焦虑。盗坤曾写文反思，没有长期可做的好产品，常有打游击之感，这很真实；我也欣赏他的自我迭代。生财也有产品能力很强的大V，比如seven，但产品多走白帽流量，和很多流量团队比偏冷启动。强流量和强产品若能合在一起，就是赢面很大的长期生意。产品怎么做很复杂，有钱的打法很多，差异化讲三天三夜也讲不完。本文从“没钱”的角度谈：做产品有没有成功率较高的套路和规律，也希望能引出更多产品达人分享。

1. 我如何判断亚马逊、独立站、TikTok、速卖通、Etsy、Ozon、Shopee、煤炉

会选品的人，在挑平台时就能看出差别：优先选小语种发达国家、人口超过一亿、且有本地入驻门槛的头部平台，通常比不分青红皂白乱做要轻松。先记住这三点。

a) 亚马逊
“亚马逊好不好做”没法一句话回答。欧洲、北美、拉美、日本、澳洲、印度、中东情况不同。澳洲是发达国家、客单高、竞争少，但人口才两千万，亚马逊市占率甚至低于eBay，同样功夫下去出不了几单。我的看法是欧亚、美亚、日亚还能做，但仅限于蓝海选品。美亚现在风评差，很多新手亏钱；可同一套蓝海打法，放在虾皮连毛利润都没有，在亚马逊仍可做到客单净利100元人民币以上。新手不懂蓝海，抓不到利基市场，还铺货、乱压FBA，一亏十万起，这怪谁？FBA还是FBM好，判断标准四个字：客户体验。FBA时效快，体验更好；产品有竞争时，体验好的人出单。若真抓到蓝海独家产品，客户只能找你买，你发货慢他也得等，FBM同样能出单。所以蓝海选品完全可以用FBM测品，降低资金风险。很多跨境主播直播间几乎没人把“客户体验”和“分产品判断”讲出来。新手面对“亚马逊好不好做”“FBA还是FBM”，听谁的？听自己的，先弄懂。讲不出所以然的人，大概率是镰刀；镰刀还会说“说FBM能做的都是割韭菜，别问为什么，听我的包你赚钱”——承诺发财，是镰刀的第二个特征。

b) 独立站
过去三年我对接服务过1000多个独立站，有些还是站群。有些品类我一看就大致知道有没有戏。两三年前多数独立站是杂货铺，确实有老板月赚100万，但近两年基本死光。原因在于杂货铺靠FB测爆款，本质是铺货思维，没有选品，只是把铺货搬到FB广告组；独立站站内铺货没意义，因为没有自然流量。现在活得不错的是品牌出海站、垂直站、定制站。两三年前顾小北强烈推荐的FB+Shopify模式，如今也只能偃旗息鼓。所以现在说“独立站不行了”的人，多数是掉过FB测爆款坑的。流量分两种：人找货和货找人。FB属于货找人，模式信息差没了，测的人多，还有不发货、不对版的，ROI早崩。独立站也有人找货的平台式流量：SEO见效慢不推荐、搜索广告、Google Shopping广告；再加蓝海选品，这部分玩家目前容易赚钱。但市面上独立站课程大多还是FB+Shopify，模式早崩，顾小北亲自来教也没用。所以独立站好做不好做都对，听自己的，要懂底层判断依据：流量、转化。让自己多懂一点、专业一点并不难，不专业怎么赚钱？

c) TikTok
它和FB一样是“货找人”的流量性质，算了，洗洗睡吧。TikTok是娱乐平台，你卖货要拍产品视频，产品短视频怎么娱乐别人？平台为什么要给你流量？TikTok又分很多国家，你选得好吗，不会又选到东南亚去吧。大力出奇迹，每天上100个视频、我要all in？你的时间不值钱吗？all in一个月，好好打工一万块赚不到？这样做TikTok和赌博有什么区别。90%新手做TikTok是两条腿断着走路：一条流量，一条选品；也不懂用付费广告解决流量跑出去和通过投放标签选相对精准人群。结合TikTok广告一级代理商数据看，广告ROI极不稳定，付费玩家盈利的也不多，何况只想蹭蹭的。TikTok让人心痒的是每天有人自然流量爆单，让人心碎的是每天爆的都不是你。成功老板抓确定性，只有韭菜财迷爱抓彩票；我接触的大卖，没有一个主战场在TikTok。

d) 速卖通、虾皮
低价平台。这两个平台的卖家都比我厉害，因为我算来算去他们都是亏的，我真算不出他们怎么赚钱；那价格我只能说认输，看不懂，再见。我在速卖通有过短暂成功，不到两年，因为我做了一个在国内抢注成功的品牌的山寨；类似打法还有抢注国外三线商标到手表等产品上，再上速卖通。速卖通只要有国内商标注册证就合规就能卖，老外分不清，可以蹭流量，高客单高转化。虾皮有一部分赚钱的店群卖家，产品或多或少跟侵权沾边；虾皮现状是仿牌都卖亏本价，这让蓝海选品怎么玩？虾皮入驻广告铺天盖地，跨境电商里坑宝妈和副业人群最多的就是虾皮。Temu也是低价平台，不建议新手入。前两年Fanno出来时跨境界一片欢欣鼓舞，我接受财经媒体采访就说不看好：一是低价平台，二是作为字节亲儿子，TikTok却不导流，底层流量和转化都存疑，半年后果然崩了。

e) Etsy和Ozon
相对新兴的平台，有一定铺货红利，估计也快结束。Ozon也是低价平台，意思不大。俄罗斯把西方大牌赶走后，将平行进口合法化，所以在Ozon卖仿牌有一定窗口期，只要票据全，中国卖家这些都能搞定。Etsy有很多设计师产品，手工艺品类目迭代比亚马逊快，和亚马逊之间有平台搬运红利，有助于亚马逊蓝海选品参考。

f) 煤炉、FB商城、C2C
这些几乎都是店群或批量账号卖仿牌，不展开讨论。

2. 第一步【找蓝海】：先定市场、平台和产品方向

我把蓝海市场和蓝海平台分四档：
最蓝的第一类：小语种发达国家、人口超过一亿、有本地入驻门槛的头部平台，比如日本乐天。
次蓝的第二类：发达国家、人口超过一亿、平台仍有蓝海选品空间，比如亚马逊欧美日。
微蓝的第三类：新上线平台、刚开放中国卖家入驻的平台，即使是低价平台也有一点铺货红利。
不蓝的：所有低价平台。
只要有选蓝海市场、蓝海平台的意识，你已经超过90%跨境小白和新手。

接着找这个市场的蓝海方向。比如日本我们找真皮方向，美国我们找户外防风防水科技材料方向。有没有按图索骥的方法？“海关壁垒”算一个，还有“平台搬运”“材质升级”等；更多方法和落地细节在付费课《选品四层方法论》里。真皮方向属于海关壁垒，详细筛选过程、落地案例和细节见我第一篇精华帖。简单说，我们筛日本海关关税信息发现，真皮制品在日本关税很高，导致价格长期处于高位，没有被传统外贸倾销过，价格体系没被打破。比如真皮靴，日本人普遍认为该卖到100多美元以上，而中国工厂出厂价有的只要几十元人民币。这就是广阔的蓝海选品大方向。蓝海方向不等于蓝海品类；真皮或科技材料可以做好几个品类。真皮我们重点选鞋类，科技材料既做鞋也做服装。方向有了还比较宽，离具体选品有距离，但这一步已经开始解决精准流量：真皮是相对垂直的关键词，对应的是对产品有要求、有消费力的人群；高科技材料也一样，有自己的搜索量。走到这里，你已实现蓝中蓝，基本告别难中难（比如虾皮），可以说超过99%刚入门的小白。

3. 第二步【走捷径】：把流量和转化一起设计

“七分选品，三分运营”？我们认为选品就是运营，运营主要解决两件事：流量、转化。好的选品，在确定具体产品时，就已经确定引流方法和转化方法（卖点）。好的选品模式，必须把流量和转化解决一个，或者两个都解决。

举一个两个都解决的案例：合规山寨。很多人分不清山寨和仿牌：仿牌违法；山寨确实有些产品侵权，比如商标权、专利权（外观专利、设计专利、知识产权专利等），但大量山寨产品可以做到合规。为区分，这类合规产品我们不用“山寨”二字，而叫“平替”，即合规平替。合规平替不仅能平替具体明星产品，也能平替高端材质；这两种方向都自带流量，因为明星产品和高端材质有对应搜索流量，这就是可布局的精准流量。只要产品合规、有自己的品牌，在亚马逊可以大胆投放竞品品牌关键词广告，包括很多知名大牌；除品牌词，还有产品系列词等，都是好用、便宜的精准流量词。既可投付费广告，也可做关键词优化拿自然流量。课程里提供4个找精准词的引流方法，还包括平替如何实现合规。

4. 第三步【加光环】：快速补齐品牌力、溢价和复购

十年前我们发现，JEEP、骆驼、CAT的鞋服，实际上跟美国JEEP越野车、骆驼香烟、CAT重型机械没啥关系；这三个鞋服品牌最早是中国老板成功抢注的。十年后，这三个品牌都不同程度与美国品牌方和解或授权，普通卖家已不能随便卖，但这个操作值得借鉴。十年前日本乐天和亚马逊对这三个品牌鞋服不要求授权备案，也不审查，因为这三个鞋服品牌在国外并不存在；又因为是知名品牌，也没法在日本抢注到鞋服类目。于是对中小卖家形成了几年搬运倒卖的窗口期。这是我们第二桶金的来源：我们在日本长期垄断这三个品牌鞋服的销售，还给它们起了名字叫“空壳品牌”。这也是一种选品模式，虽然只有特定窗口期。这个模式到今天仍有可复制性，比如前文速卖通客单净利100+的产品，就是这个模式出来的；空壳品牌在速卖通有独有合规优势，前文已解释。

按占便宜程度和境外合规风险，空壳品牌分几类：1.抢注国外品牌，并复制它的全系产品，例如koolaburra已被UGG收购；2.抢注国外品牌，跨类目做新类目产品，这是速卖通常见套利玩法；3.在国外注册品牌，策划国外品牌故事和品牌形象，这是国内电商常见品牌捷径。不同时期，这三类在亚马逊都有窗口期；目前还能继续做的是第三类。很多老板做品牌出海或美亚，老老实实用中国品牌不是不行，但更好的方案是策划空壳品牌：在日本做德国品牌，在东欧做日本品牌，在美国做欧洲或日本品牌，都可行；本土客户查不到，故事随便你说。这个打法在淘宝也有很大红利：某渔具淘系卖家把渔具包装成日本品牌，做日本独立站官网，反向营销到国内市场；日本渔具口碑好，直接带来远高于淘宝渔具正常利润的溢价空间和复购。按经验，成功空壳品牌可以做到10%复购，净利提升最多达30%。它不仅是增加转化的方法，有时还能单独演变成一个选品模式：低成本、搬运式地把成功产品输出到跨境市场；信息差较大，以后有机会再介绍。

5. 第四步【微创新】：把红利期拉长

前三步基本可以工具化，或者花点钱实现；第四步主要做产品差异化，对人的要求高一些，做成功了护城河更深，产品红利期也更长。微创新其实是不创新。我们比较推荐新手做的微创新差异化套路是材质套利，它是上文材质平替的延伸。新手做差异化，不要考虑原创设计、痛点迭代，这些没有专业积淀很难拿到成功确定性；新手适合基于大标品，做升级式和热点嫁接式差异化产品。

首先，大标品不愁卖，也不需要买选品软件分析大标品；但大标品往往是低级材质或价格战重灾区，客单非常低，没有利润空间，大多数新手又喜欢一上来就干这个。跨境直播间讲亚马逊热卖产品时从不缺人气，在我看来跟路边看人吵架没区别，没意义。其次，真正的高端货，中国卖家向来不去挑战，也挑战不了；那么中端性价比市场就相对空白。我们找出高端材质方向，找到能还原90%体验的低成本平替材质，去做稍稍消费升级的人群，就能避开大量竞争，获得长期蓝海空间。上文平替案例可见，1688已有现成供应商，甚至几千元投入就能做出差异化产品，非常适合新手。
