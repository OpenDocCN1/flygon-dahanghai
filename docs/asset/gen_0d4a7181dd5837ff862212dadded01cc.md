# 先攒素材再写稿：6个库的复用方法

写故事可以按一套骨架来：先交代主角身边的人或物——他们与主角是什么关系、如何认识、各自做什么、基本情况怎样。再写主干：主角想达成什么、中途发生了什么、卡在哪里，其中包括目标或梦想、挫折阻碍或意外。最后写结局：这件事怎样影响主角、主角如何应对或应该怎样做、结果是什么。按这个框架整理材料，就能把素材库建起来。

日常看到的真实事件、文学作品、小说、影视剧、热点新闻和各平台内容，都可以成为素材来源。想让它们反复发挥作用，可以先建6个库，之后交叉搭配，故事就能很快成形。

## 1、标题库

平时遇到那种反常、有悬念、一看就想点开的标题，随手存下来。比如：

1）66岁，每月退休金8000，儿孙绕膝，却冒出不想活的念头；
2）听完母亲临终那番话，我这辈子都结不了婚；
3）和堂哥的地下恋走了20年，结局出人意料；
4）68岁生过大病才明白，有些东西得抓紧，比亲生孩子还可靠。

这类标题的共同点是异常、有冲击力，让人忍不住点进去。

## 2、主人公库

来源可以是新闻、报道、八卦、小说、影视，也可以是身边真实发生的事。把里面的人物放进库中备用。比如：

1）18岁没结婚就当了妈妈的小佳；
2）患不孕症的小爱；
3）40岁不结婚、还有不少女人倒贴的老光棍；
4）55岁大妈生三胎；
5）50多岁大妈再婚，还要100万彩礼。

这些人物往往有异常、有争议，容易撑起故事。

故事主干库可以拆成三个子库：梦想或目标库、挫折阻碍意外库、惊喜或反转库。三个子库的来源同上，把事件中人物的目标、阻碍和反转分别记下来。

## 3、梦想或目标库

比如：不孕夫妻想生娃；结婚想买婚房；老大爷想找老伴；重男轻女家庭二胎盼男孩；想开一家美容院。

## 4、挫折、阻碍或意外库

比如：恩爱多年却始终怀不上，医院也查不出毛病；房租突然涨价；恋爱几年，因彩礼、房子等原因被父母反对；跳舞时突然中风；感情很好时一方卷钱失踪；夫妻恩爱多年，对方突然提出离婚。

## 5、惊喜或反转库

比如：老家拆迁，得了钱和房；女友父母原本要50万彩礼，突然只要8万；失散多年的儿子开着宝马回来；多年不孕的女人三年后突然怀孕；房东主动减免房租。

## 6、结局库

比如：复婚；离婚；一家人幸福生活；儿子接去养老；找到合适老伴安享晚年；住进养老院；夫妻更恩爱。

6个库建好后，几分钟就能搭出一个故事。拿库里的1、5、2、4、5、3来组合：小佳18岁未婚先当妈（主人公1），她想开美容院（目标5），手里只有8万，看中月租7万的店，房东却要9万（意外2）；她想放弃时，房东中风（意外4），儿女不愿出治疗费，想尽快把店租出去，降到6万租给她（反转5）。8年后，美容院做成连锁，孩子父亲也回来，一家人幸福生活（结局3）。这样初稿就有一波三折，还带真实感，容易让人共鸣。

若不想写故事，想写观点鸡汤文，可以用3个小故事，每个故事后面接观点、名言或金句；再建一个观点、名言、金句库即可。

有了故事，再补细节、对话、动作和心理活动，就能写成有血有肉的文章。情节要曲折，起承转合要清楚；素材库里的主人公、目标、挫折、反转、结局可以打乱重组，稍作调整就是新故事。比如小佳用了1、5、2、4、5、3，也可以换其他组合，只需微调。

再举个简单例子：主人公是小爱26岁，做财务；小王29岁，做业务员，两人是夫妻。目标1：想生个孩子；挫折1：结婚3年没怀上，看医生、吃药都没用，后来认命停治；反转4：一年后意外怀孕；结局7：夫妻更恩爱。串起来就是雏形：

我叫小爱，26岁，做财务；老公小王29岁，是业务员。我们结婚3年多，一直想要孩子，没有避孕也没怀上。看了不少医生，吃了不少药，还是没用。后来我们认命了，不再治，结果1年后意外怀上了。

这样字数少，不够吸引人，要往里填细节、对话、动作、心理，情节越曲折越好。成稿后@自己，补上总结观点或感悟，再向读者抛一个问题：可以是问读者认不认同你的观点，也可以是问对故事里的事怎么看。这个观点、感悟和问题不能省。比如小爱这个故事，可以给观点：怀不上孩子的夫妻别轻易放弃，积极就医、放松心情，奇迹仍可能出现。再问读者：你身边有不孕夫妻吗？他们后来生孩子了吗？如果能引用鸡汤、名人名言、影视或书里的金句，就更好了。

以后看电影、看新闻、看书、刷剧、刷视频时，把有意思的标题或开头、主人公、目标、挫折、惊喜和结局这6个要素提取出来，分类放进库中，要用时直接拿，就不怕没素材。

说白了，收集素材像逛超市，喜欢什么菜就放进购物车；整理建库像回家把菜分门别类塞进冰箱，要煮时随手拿；写故事像炒菜煲汤，可以胡萝卜、玉米、马蹄、骨头一起煲，也能换别的组合。至于大家爱吃什么菜、喝什么汤，众口难调，多试几次才知道。

注意：故事主干和情节要详略得当。与主题无关的略写；能体现人物性格、推动故事的详写。结尾尽量反着来，让读者产生意料之外、情理之中的感受。主干多用动词、大白话，少堆形容词；用连续动作制造画面感和代入感，让读者感同身受、产生共鸣。语言要简练，比如“月工资100元”“一个月挣100块”；带入场景，多用动词加名词，穿插转折词和连接词。

还有，别抄袭，别抄袭，别抄袭——标题也一样。可以模仿思路，不能照搬文字，一定自己动脑改。内容尽量贴近生活、温情、正能量，别太狗血、太暴力；有违公序良俗、乱伦、色情的内容千万别碰。

我用Excel建库，再导入印象笔记，因为表格看着直观；大家用什么顺手就用什么。

# 5.2 爆文发布前后：自检清单与数据复盘

# 5.2.1 发布前先过一遍自检关

1）文章尽量快短平：尽快入题，句子短，最好平叙。
2）读者多在休闲中想学点东西，不愿动脑，偏爱浅显文字；太文绉绉反而不讨喜，用大白话写就好。
3）单句尽量不超过15个字，段落里别堆太多话，两三句即可。
4）检查病句，主谓宾是否齐全；段尾和下一段开头是否承接。做到这些，阅读体验会更顺。
5）要有避坑意识，知道什么能写、什么不能写。写了违禁内容，时间花了没收益，还可能封号，白忙一场。政治相关别碰，记住“党史”“军史”两个词；黄赌毒也不能写。
6）最后看开头有没有“开幕雷击”，冲击力、画面感够不够；不够就优化到OK。

打开公号爆款之路后，粉丝和收益会慢慢来；能举一反三，在其他平台也可能有惊喜，实现一鱼多吃。

# 5.2.2 复盘怎么看数据 @枫宇翔

文章复盘主要看完读率、渠道构成、用户画像、数据趋势，这些是公众号后台给的数据。

电脑打开微信公众号后台，点“数据=>内容分析”，就能看到已发文章；点详情可看各项数据。

[PRE1]

第一，完读率。这个指标很重要。我有一篇阅读20万，收益600多；另一个人同样阅读量，收益300多，差别就在完读率。读者读完，才能拿到文中两个广告和底部一个广告的收益；读完的人越多，完读率越高，收益也越高。比如浏览到100%时跳出比例是52%，完读率就是52%，约一半人没看完，说明内容还不够吸引人。我会把精彩内容放在后面，前面做引导，比如“详细数据在文末，感兴趣可到文末查看”；字数太多就有意识压缩，提高完读率。若阅读量高，但用户在浏览30%—40%处跳出比例约50%，等于一半人只看了一个广告就走，很少看完三个广告，阅读再高收益也少，下篇要及时调整。

第二，渠道构成。看用户主要从哪来。推荐多，说明文章进了流量池，不错；搜一搜多，说明没进推荐池，可能碰到某个节点，热度过了会断崖式下跌。这时别急躁，继续日更。朋友圈、公众号消息占比通常不大，我不太关注。

第三，用户画像。包括性别、年龄、地域分布。性别看男粉多还是女粉多；年龄看哪个年龄段多。比如我的数据是36岁以上男粉居多，内容就更偏向这个群体，游戏、时尚之类不放。也会有意识地按赛道和用户了解去测试相关选题，看能否提高阅读。地域能看出哪里爱看你的文章，广东居多就多写广东内容，增加爆款概率。

第四，数据趋势。这个也稍微关注。

# 5.3 账号快速入池的实操技巧

进流量池没有确定时间：有账号一天就进，有账号半年也进不了，有点玄学。但多数情况下，7到21天坚持写，基本都能进。换句话说，持续更新、标题有戏、内容垂直，早晚能进。老号注册一年以上，通常有一定权重，入池更快；我们做过不少测试，老号确实有优势。没有老号，可以发朋友圈问问身边人有没有注册较久的公众号，拿来实操。新号先选领域，定好后找对标账号，按对标账号的爆款选题和内容二次创作，每天更2到3篇，不断更，也能较快入池。

进了流量池，就意味着开始赚钱。若一直没进，要想想自己花了多少时间、投入多少精力、有没有研究标题。付出和回报大致对等：一天写一篇和一天更两篇、做一个号和做两个号，测试效果自然不同。

# 5.3.1 怎样判断账号已进流量池 @一来

微信公众号规则也在变。以前单篇文章阅读从个位数变成三位数、四位数，有了“看一看”流量，账号基本就算入池，第二天再发阅读往往会上来。但这一段时间似乎有调整：单篇进了“看一看”，第二天再发流量仍可能很少，甚至只有个位数，那就继续更新，直到账号入池。最直接的变化是阅读突破1000甚至上万；若只从个位数变成两位数、三位数，不一定，因为流量可能来自搜一搜。所以观察和持续更新很重要。
