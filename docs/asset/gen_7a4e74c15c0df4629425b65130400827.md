# 6.1 手机端发视频，注意这几处

手机端发布视频的操作并不复杂，下面先梳理流程，几个容易忽略的细节稍后再讲。

[PRE0]

• 描述：填写与所售商品有关联的文字内容。

• 话题：优先选择流量较高的话题。比如卖芒果，既可以加垂直领域的 #芒果，也可以加类目相关的 #水果。

• 提到：这个功能暂不使用。以带货为目标时，目前还没找到合适的应用场景。

• 所在位置：可以填上自己附近的地点，位置信息对内容分发也能产生一定帮助。

• 活动：通常不会添加。创建活动后，可以在其中填写直播活动、私域引导等信息；每条视频都挂上同一个活动，有助于提高曝光。

• 链接：上一篇文章已经说过，带货链接主要放在这里添加。
