# ChatGPT诞生第135天，我用AI写文10分钟赚了1000块

各位圈友，我是袁永兵，干了三万小时电商，山西省商务厅认证的电商实操专家。上次在生财第一次发帖，直接被打回，没想到不少圈友主动来加我，给了很多认可。这版重新发，我把收益截图、耗时记录都更新了一遍，文章也重写了，想验证这套方法到底稳不稳。

今天不聊电商，只聊一件事：我把全民热捧的ChatGPT用在了公众号写作上，而且打出了多篇10W+。我能确定，这俩东西结合起来的空间远超想象，背后的生意足够大，光红利期就能持续五年以上。国内大厂虽然都在追，但三五年内不可能真正追上，更何况ChatGPT本身还在快速升级。试了很多次之后，我通过它辅助写出的文章，平均一篇十万加就有千把块收入，真香。现在号跑通了，就把我的公众号十年折腾史，和这篇10W+背后的完整细节，一次讲透。

我当时的原话是：“以前真看不上这几个小钱，可小钱实实在在进了口袋，认知就变了。”这就是我2018年前后的真实心态。时间拉到2021年上半年，我做短视频和直播，亏光了300万，还背了300万债，整个人被现实按在地上摩擦。正是那次摔到谷底，逼着我彻底重新审视自己，也才有了后面和公众号的故事。

2021年之后，我开始猛进付费社群，朋友介绍加自己找，主流圈子基本都进了，累计花了不下10万块。这笔账很划算，把我认知和信息的缺口补上了不少，不再活在“一说就会、一做就错”的假懂状态。另一个重大变化是：凡是我没亲自从0到1跑通过的事，绝不再交给外面请的人。说实话，市场上能招到的员工，能力天花板就摆在那，尤其是在山西，愿意出来上班已经算有冲劲了。我过去总拿“伪认知”“伪信息”当武器，结果被现实狠狠上了一课。别人讲道理，你学不会；事情教人，一次就会。经历没法跳过，踩过的坑都是垫脚石，共勉。

至于执行力，倒是我多年没丢的底牌。所以，为啥要做公众号？答案很简单：对普通人来说，赚大钱的门路从来都是从赚小钱开始的。小钱赚不到，大钱凭什么轮到你？话就到这，懂的都懂。

## 二、公众号十年，拿起又放下，我终于走出一条自己的路

这十年我分三个阶段。

第一阶段是2013年前后。当时跟着大哥和兄弟们注册了十几个号，还派了一个员工去兄弟那边学了一周怎么运营。文章发了两年，粉丝最多的号也没到一万，流量主压根没资格开。那会儿电商生意好得很，根本看不上这点广告费。结果这一放，直接掉队。大哥他们的号从2016年开始大丰收，人人千万级收入，还有人靠公号做到过亿营收，全是真金白银。反观我们，2018年电商生意滑铁卢，营收断崖式下跌。两边一对比，一个天上一个地下，对我的刺激实在太大了。

顺带说个小插曲：2018年我还搞过一批头条号，纯搬运赚了点小钱，结果用自己身份证注册的账号被永封。直到上个月，我才找到方法把身份证解出来，又能用了。这似乎在暗示，2023年该轮到我搞钱了，就是这么顺。

第二阶段是2021年。短视频和直播亏空之后，我们一口气注册了上百个公号，第一次玩批量布局。跑出几个号，粉丝多的七八万、少的有一万多，流量主收益从几百到几千都有，内容多数靠搬运。看没什么大起色，就又扔一边了。转折发生在2021年最后一天，我看到有人用公号引流卖虚拟资料，马上跟进去，当天就净赚5000。2022年上半年和下半年，因为封控宅在家，又动起了公号的念头，重新捡回来做。那段时间，之前表现最好的号一个月分到16万，还有单日收入破万的记录。要不是后来号没了，可能也没有现在的第三阶段。

经历完这三个阶段，我总结出两个教训。第一，项目必须自己亲手跑通，只坐在指挥室里听汇报，迟早翻车。第二，现在入场已经晚了，号里没有粉丝积累，纯搬运根本走不通。就算不计成本堆人，遇到一言不合就整顿职场的00后，每天都是一地鸡毛；再加上这行门槛低、新人培养周期长、老手熟了就去单干，等于出钱帮对手培养人才。这么拖着，永远不是个事。

认知和信息上的差距，我选择用钱来补，花钱能解决的，都是最简单的麻烦。执行力方面，哪怕我笨一点、慢一点，别人三天，我就三十天、三个月、三年。只要内容够好，什么时候进场都不晚。你看我，十年后重新做公号，照样有机会。今年是我公司化运营公号的第一年，手里多了一个趁手的工具，效率和效果都已经被数据验证。下面是用ChatGPT写文以来，一个新号目前的成绩：

## 四、10W+是怎么“生产”出来的？

我主做情感领域，情绪价值是最重要的抓手。于是搭了一道人机协作流水线，总共三步：

1. 选题+标题（占50%）——做内容就是选选题，选题比怎么写更重要
2. 正文
3. 情绪价值

人工负责第1和第3步，中间第2步交给ChatGPT。整套流程跑下来，我自己计时，最多10分钟完稿。其中选题和标题大概1分钟，爆文库、榜单上全是现成线索；再花1分钟定标题；ChatGPT输出大约1分钟。也就是说，3分钟能拿到一篇机器初稿，这时原创度差不多60%。接下来5分钟做第3步：补引文、打磨段落之间的承接、升华结尾，把情绪价值填满。全部加起来，一篇千字原创不超过10分钟，而且再测原创度，能抬到70%以上，主流平台都容易过。

为什么要专门加第3步？因为ChatGPT写出来的东西，格式感很强，不是“1、2、3”，就是“首先、其次、最后”，特别机械、程序化。这能理解，毕竟是程序员造出来的，逻辑自洽、条理清楚是优点，输入即输出，问什么答什么。它给的都是标准答案，我甚至觉得它的智商比国内很多211本科生都高，可惜没有温度。之前我试过直接发它写的文，数据很平淡，缺的就是人情味。所以第3步是灵魂。好在现在的GPT-4已经更通人性，等于帮我们又往前走了一步。

这就是整套框架。写完之后，直接发出去，剩下的交给系统、交给用户。

另外必须说明：2021年以后，公众号也接入了系统推荐，这才是这个老平台能一直活到今天的原因。如果没有推荐机制，一个不花钱的新号想入场，门都没有。正因为有推荐，诞生十年的公众号才重新给了新玩家机会。这是平台送的红利，也是2023年我最大的运气。

还有一点，2022年上半年之前，有人靠视频号给公号导流，也薅到过一波羊毛，我手下有几个号就是那时候做起来的。最近视频号也出了分成计划，如果图文之外再配上视频，公号+视频号，一个内容吃两遍，这波红利可能更猛。

## 五、给想做自媒体的朋友几句掏心话

台上十分钟，台下十年功，这话真不假。

太多人幻想自己一敲键盘就是10W+，最好篇篇爆。醒醒吧！这种心态最能毁人，也是大多数人坚持不下来的真正原因。公众号写作本质是长期积累的事，先问自己能不能从一百天做起，从一年做起。没有这股韧劲，结果早就写在开头了。

就拿我来说，你看到的是10W+，看不到的是前后折腾十来年，是三次起号三次失败的意难平，以及各种违规、封号、踩坑。这些避坑规则，全是拿真金白银换出来的。

还有两个自己的毛病要改。2022年航海，我一次性报了三个项目，典型的贪多嚼不烂。以前我还爱看各种高大上的行业报告，看一份转一份、收藏一份，以为学到了，其实全是在浪费时间。那些报告大多出自办公室实习生之手，水得很，看多了还容易飘，觉得自己啥都懂，结果一到实操就废。这个“一说都会，一做就错”的毛病，根源之一就是报告看太多。

所以2022年起，我再不看那些虚头巴脑的报告，只埋头研究手里的文章。练标题时，我连着抄了一个月，每天早上到公司第一件事就是打开爆文榜，抄满一页A4纸的三段式标题，再总结规律。这种笨功夫，配合SEO关键词布局、对人性的琢磨，才是炼出爆文的必经之路。

最难改的还是思维模式。这属于认知层面，你得先意识到问题，再动手调整。我今年40岁，还在调，因为认知不动，结果不动。我总拿一句话提醒自己：“如果我是对的，我现在就不会是这副样子。”不过话说回来，虽然已经写出10W+，我心里也清楚，靠AI编故事，很容易被人举报；就算没人举报，限流、违规、封号的风险也不小。要是几年前的我，可能早就打退堂鼓了。现在的我，号没了就没了，只要产出大于损失，就接着干。当然，能不封最好，尽量稳住，学会保护自己，朋友圈和公开交流里绝不透露账号名，这些都是没办法的办法。
