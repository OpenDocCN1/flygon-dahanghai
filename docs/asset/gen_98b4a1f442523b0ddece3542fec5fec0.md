# 6.3.1 画面主角，你说了算

一幅画里最先要定下来的，不是光影，也不是风格，而是主角。所谓主体，就是整张图里你最想让人看到的那部分内容。

它可以是这些画面：

一间朴素的小屋；
一艘落在玉米田里的飞船；
……

也可以是：

一只架着墨镜的猫；
特朗普和希拉里相拥；
田野间的小村落；
开得五颜六色的花；
一个收纳置物架；
星际宇宙中穿梭的景象；
……

说到底，你希望画面里出现什么，这块区域完全由你决定。尽情放飞、不必设限，这也是普通人最容易施展想象力的地方。
