欢迎来到 12 月航海「出海第一站」实战手册，今后一段时间，我们会在这里频繁碰面。

这一程，我们的目标很明确：做出第一个初步的海外静态网站，并在里面埋下一个能变现的入口。

原因在于，靠英文工具站赚钱这件事，本质上是个长期工程。在你还未投入大量精力去寻找完美需求、打磨理想产品之前，我们更希望你先把整套流程走通一遍，亲手操作每个环节，慢慢养成 MVP 意识和 SEO 思维。

所以本次航海的重头戏，集中在必修篇——我们会完整展示一个网站从挖掘需求到尝试变现的全过程。

当第二个、第三个需求出现在你面前时，你就能够快速执行、抢占流量，让这些工具站真正为你带来回报。

那么，在正式动手之前，先厘清几个问题：

1）为什么是海外工具站？

和国内的竞争烈度相比，海外的赛道要宽松不少，流量体量也更为庞大。与此同时，海外工具站天然有壁垒，不是随便一个个体或小团队就能轻易复制的，做得好的站，一年下来利润能到亿级水平。往前进可以融资，蜕变成 SaaS 独角兽；往后退也能守住阵地，悄然盈利。想象空间相当可观。

此外，海外市场对谷歌搜索流量的依赖度极高，短期内看不到什么结构性危机。一旦把一个工具站跑通了，这套能力完全可以平移到下一个需求上，再复制一遍。

龙哥也曾在星球里多次建议那些具备产品开发或流量获取能力的圈友去尝试海外产品，还半开玩笑地说过：如果他不做龙哥盟，就会去做英文工具站。

需要强调的是，做海外工具站没办法一蹴而就。想快速验证需求、获得用户的真实反馈，从挖需求到上线推广的每个环节，都要带着 MVP 意识和 SEO 思维往前走。

2）什么样的人适合做这件事？

① 本身有一定产品设计、开发与营销能力的人；

② 对海外市场有兴趣、有耐心试错，同时对挖掘用户需求和开发工具这件事有一定感知的人。

另外，如果工具站做出稳定流量，完全可以长期持有，日常花少量时间打理，就能实现“躺赚”。当然，这个项目也有它的门槛和挑战：

1、开发容易推广难，网站上线后还要持续关注流量走向并不断优化；

2、技术门槛客观存在，如果开发能力不够，可以考虑自学、借助工具，或者找搭档一起解决。

最后，希望大家在这次航程中不仅收获成果，还能结识一路同行的伙伴。

## 1.1 什么是工具站？

### 1.1.1 网站的常见类型 @ChatGPT

本节内容来自 ChatGPT 的辅助：

简单来说：

工具站：专门提供某种工具或服务的网站，比如搜索引擎、在线存储空间、翻译工具。

内容站：主要提供文本、图像、音频或视频内容的网站，如新闻门户、博客、社交媒体。

电商站：以商业交易为核心的网站，例如独立站官网、在线市场。

社区站：让用户彼此连接、互动和分享内容的平台，如论坛、社交网络、博客社区。

教育站：提供教育资源、在线课程和学习工具的网站，像在线学习平台、教育博客、学校官网。

娱乐站：提供娱乐内容、游戏和视频的网站，比如在线电影、游戏站、音乐平台。

新闻站：及时更新新闻、事件报道和评论的网站，如新闻门户、媒体网站。

……

这些类型的网站我们经常碰到，但这次实战，我们把目光锁定在工具站。为什么选它？因为它能在“挖掘用户需求”到“实现变现”的完整体验上，帮你走通每一个环节。

### 1.1.2 工具站的特点和分类 @ChatGPT

本节内容来自 ChatGPT 的辅助：

一般来说，想做出一个既叫好又叫座的在线工具产品，有这么几个维度值得用心：

用户需求：搞清楚用户真正需要什么，并给出对路的解决方案。

用户体验：界面简洁、操作顺手，让用户用得舒服。

功能强大：功能要拿得出手，真正能帮用户解决问题。

技术实现：用高效稳定的技术搭底子，保证网站健壮、流畅。

数据安全：以高安全标准保护用户的数据和隐私。

市场营销：用有效的推广策略，把用户吸引过来。

客户支持：提供靠谱的客服支持，帮用户排忧解难。

数据分析：借助数据分析用户的行为与偏好，持续迭代优化。

工具站的核心价值，就是提供称手的工具来帮用户解决特定问题，比如个人所得税计算器、万年历、IP 信息查询这类。

再举一些具体的工具站分类：

邮件营销工具：如 Mailchimp、Constant Contact、AWeber 等

项目管理工具：如 Asana、Trello、Basecamp 等

网站分析工具：如 Google Analytics、Mixpanel、Heap Analytics 等

在线支付工具：如 PayPal、Stripe、Square 等

在线图片编辑工具：如 Canva、Piktochart、Visme 等

在线文档协作工具：如 Google Docs、Microsoft Office 365、Zoho Docs 等

在线客服工具：如 Intercom、Zendesk、Freshdesk 等

在线表单工具：如 Typeform、Google Forms、JotForm 等

上面这些大多是大名鼎鼎的产品。而对于个人或小团队来说，更值得瞄准的是细分领域的用户需求，也就是所谓的「Micro SaaS」。Micro SaaS 是一种轻量级的软件即服务（SaaS）产品，通常简单易用，专注于解决某个特定的业务问题。

与传统 SaaS 相比，Micro SaaS 更聚焦于单一场景，价格也更亲民。要做这类产品，关键在于洞察用户需求，并拿出简单实用的方案。

工具站一旦上线，日常运维并不需要耗费太多精力，基本可以自行运转。而且只要工具真的好用，用户会主动收藏网址，或者把它放进书签，下次直接访问。

### 1.1.3 为什么要做英文工具站 @刘小排 @哥飞

为什么要把起点放在海外网站，而不是别的形态？

答案很直接：做海外网站，是速度最快的一条路。

不信的话，对比一下就知道了——做 App 很慢。

做 iOS、Android 应用，光是编码就比网页复杂得多，对开发能力的要求也更高；上线前还要走打包、提交审核的流程，审核还未必一次通过，时间成本相当可观。

如果做的是国内 App，那就更慢了——你得花三个月左右拿到软件著作权证书，才有资格上架国内应用商店。更让人头疼的是，一旦要修个小 bug，又得重新发版，用户还得手动升级安装才能用上修复后的版本，bugfix 的节奏被拖得死死的。

做国内网站，同样快不起来。域名备案这关是绕不过去的，周期大概 1～3 周；如果碰上北京这样管理特别严的城市，被打回重报也是家常便饭。

做🛰️小程序，倒是比上面两个略好一点点，但也谈不上快。问题出在：小程序的生态不够开放，很多轮子得自己造，无法直接引入现成的开源代码来加速开发。

绕了一圈你会发现，做出海网站是这里面最短的路径。它不需要等软著、不需要备案、不需要过审，更新的时候用户也不用重新安装。把代码丢到 Github 仓库，配好 Github Action 做 CI/CD，一提交代码就能自动上线——这种开发体验，是真的爽。

而工具站做起来后，一旦权重和排名稳了，就可能持续带来十年甚至二十年的回报。只要互联网还在，搜索引擎还在，互联网广告还在，收入来源就不会断。而且一个站活得越久，留下的外链就越多，排名也越发牢固。

当然，这一切的前提是：别做垃圾站。能赚钱的工具，一定是真的对用户有帮助，用户才会心甘情愿帮你传播。

种一棵树最好的时间是十年前，其次是现在。做网站是典型的长期积累型项目，别总想着“以后再说”，现在就该动起来。哪怕做完放着不更新，只要还有人在用，权重就会随时间慢慢沉淀、走高。

再说眼下，2023 年大家对 AI 的热情有目共睹。只要你做的工具跟 AI 沾点边，用户就会自发地帮你扩散。

所以，现在就是下场的好时机。

能做的方向实在太多了：有短期需求，也有长期需求；有纯粹 for fun 的，也有真正切中工作生活痛点的。

对大多数新手来说，不妨先用短期的、或者纯粹好玩的练练手。在这个过程中，你会逐渐学会怎么挖需求、怎么做 SEO、怎么搞流量、怎么推广、怎么把流量变成钱。

等你跑熟了，再布局那些长期、高频、扎根于工作生活的工具需求——盯着竞争对手，争取在某些维度上超过它：做得更好用、做得更漂亮。

正好最近读吴晓波的《激荡四十年》，有感而发，想借这个机会带大家回顾一下中国工具出海的时间线。这激荡二十年，大致可以分为四个时期：萌芽期、起始期、扩张期、转型期。

1、萌芽期

萌芽期是 1998-2007 年，当时正值中国互联网发展早期，整个大环境还是 Copy to China 的时代。在中国工具出海第一人周奕的带动下，从 MP3 CD Maker 起步，中国互联网出海迎来了第一缕曙光。

[PRE8]

2、起始期

这个阶段大家开始渐渐意识到：工具出海，是可以抹平中西方文化差异的。2007 年，初代 iPhone 和 Apple App Store 相继面世，移动互联网时代拉开大幕，中国工具出海由此进入起始期。久邦、百度、360、UC、金山这批国内玩家，开始在海外“悄无声息”地开疆拓土，闷声赚钱。

3、扩张期

2011-2016 年，移动互联网出海跑步进入扩张期，工具赛道开始涌现细分品类：手机管理类有 Clean Master，相机图片类有美图秀秀，桌面类有 Solo Launcher、Go Launcher，浏览器类有 UC、海豚浏览器等。当时获客成本还不到 0.01 美金，安装量动辄数亿甚至数十亿，出海资本迎来了一段明媚的春天。

那个年代也冒出了大量广告代理公司，比如 Yeahmobi、Mobvista、Avazu，还有像猎豹 CM 这样自己开辟广告代理业务的。很幸运，我也是在那个年代入的行，服务过很多当时的明星产品，算是亲眼见证了出海行业的黄金岁月。

4、转型期

时间很快来到 2017 年，工具出海经历了几年的黄金窗口之后，增长方式越来越多元，变现手段也越来越“成熟”——或者说，越来越夸张。与此同时，海外人口红利在收缩，产品同质化在加剧，平台规则（尤其是 Facebook 和 Google）也在不断收紧。

## 1.2 英文工具站的变现方式一览

赚钱这件事，核心就跑不开两样：流量 和 产品。

流量和产品这两个核心元素必须同时盯紧，别只顾着闷头做产品，结果压根没有盈利能力。

接下来，我们看看具体有哪些变现路径。选定方向，再朝它使劲儿，才是正确的姿势。

[PRE13]

### 1.2.1 卖流量 - 广告变现 @子木

卖流量，顾名思义，就是通过免费开放的工具网站把用户吸引过来，再用广告把流量变成钱。类似 https://decompilertool.com/、https://sharegpt.com/ 这类站，挂上广告就能持续产生收益。

[PRE14]

这类工具站有什么特点？一句话：不求每个用户付费，只求访问量够大、能喂饱广告位。

### 1.2.2 卖产品 - 付费变现 @子木

卖产品，则是直接靠付费工具来变现的模式。

典型的例子是 ChatGPT 相关的付费工具站，比如 https://www.proseoai.com/ （圈友做的谷歌 SEO 获客内容神器）。这类站的思路是：让用户体验后，转化成付费用户。

[PRE15]

这条路线有个硬性前提：产品本身要有值得付费的价值。

同时它的链路也更长：搞流量 -> 做转化 -> 客服谈成交 -> 售后跟进。也就是说，你得建起一整条完整的销售链路：获客、转化、客服销售、售后维护，一个环节都不能少。

那能不能同时卖流量和卖产品？当然可以。

手里握着流量，意味着你既能卖自己的产品，也能把流量卖给合适的人，只要保证产品与受众之间的相关性、以及目标客群的一致性。这样一来，双重变现就实现了。
