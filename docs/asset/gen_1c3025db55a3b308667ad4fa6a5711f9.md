回头复盘，当初设计的变现路径确实铺得太长。做账号那段时间，真正跑通的只有第一步：有近十位用户付费购买了咨询服务，并且顺利拿到心仪 offer，这说明我的求职方法论是有效的。但后来主业进行了一轮调岗，笔记创作节奏被打乱，持续输出的动力也弱了，账号就慢慢搁置了。

因此，如果你符合以下情况，可以尝试做小红书职场号：

1）每天能稳定抽出 1—2 小时探索副业；

2）在求职面试、人际沟通、专业技能等方面有可分享的经验；

3）已有成型的文字或视频课程，或者有足够时间和精力开发课程。

另外，分享几条尚待验证的变现思路：职场号很适合做个人 IP，前期变现能力可能不如美妆、家居、母婴博主，但只要长期经营，变现方式会越来越多，具体可参考上方 @子渝 的职场号案例分享贴。

## 9.5 小红书宠物赛道：从科普切入

### 9.5.1 宠物号案例 ① @虾饼的起号路径

#### 9.5.1.1 赛道概况

宠物行业近年发展趋势向好。比起生娃，现代年轻人更偏爱养育成本低、精神陪伴价值高的宠物，把它们看作家庭成员，愿意付出精力和金钱。

但我选择这个赛道偶然性比较大，没有像别人那样用很科学的方式调研分析，只是从个人长处出发。我是一名铲屎官，特别爱我的毛孩子，有事没事逛论坛取经，学习科学养育知识，淘车价好物，也很热衷分享。所以我的优势是：有知识储备（量多量少不要紧）+ 热爱分享。因此我大类选宠物，细分赛道做科普。误打误撞，这个赛道恰恰是最适合新人入场的赛道之一。

先说起号情况：2021.10 开始利用通勤时间发简单科普笔记 + 萌宠日常，后来发现科普笔记流量更好，通过蹭爆款标题一个月积累了近千粉丝。零零碎碎接广，一个品报价小几百。2022.2 用了一个爆款模板，一周涨粉 3W，广告邀约不断，报价四位数。

2）推广合作流程

① 合作形式

合作形式分为报备笔记和非报备笔记。报备笔记就是前面提到的官方认可的品牌合作，要被收取“保护费”；非报备就是私下合作，悄悄打暗广。

非报备又分单品和合集。单品是一篇笔记里只能含这个品的广告；合集是同时有好多个品给你广告费，出现在你这篇笔记中。单品里还有“伪合集”概念：一篇笔记里看似出现很多产品，但真正给广告费的只有一家，这样能最大程度避免被判定为私自推广。

跟 PR 聊时还要问清楚以下几个问题：

档期：出初稿、终稿以及最后发布的日期。

授权：能否授权品牌方在其他平台发布，是否免费，授权周期多长。尾部博主一般免费授权，周期一般三个月到半年。

笔记发布后的保留周期：一般一年或永久。

排竞：发布这篇笔记的前几天到后几天，不能再发布该品牌竞品的相关笔记。

活动出席：美妆和穿搭类品牌可能邀请达人出席产品发布会之类。

② 如何报价

推广分两大类：无费和有费。无费推广就是置换，把东西送给你，你帮忙出一篇笔记，跟小红书好物体验差不多；有费就是给一定报酬。大原则上报价一般按粉丝量的 10%—20%，具体看账号情况。如果这段时间流量很好，账号定位跟品牌契合度很高，可以再往上报。

还要看你是否注重长期合作。一种情况是报价相对较高但效果不好，人家可能不会考虑二次合作；另一种情况是原价 2000 一篇，按他们预算一个月只够合作一次，如果能谈到 1500 一篇，或许一个月内就会合作两次。

再者要看是跟品牌直接对接，还是跟机构对接。机构一般会要返点，返点是收推广费后返一部分给机构。返点 20% 左右比较合理，35% 以上有点离谱。

图文报价一般低一些，大概是视频报价的 60%—70%。但如果你本身偏向图文博主，图文报价可以和视频报价相当。

报备笔记报价要高于非报备，因为不仅被品牌收取服务费，还要接受更严格审核，可能需要更高度的配合，如果到手比非报备低就太亏了。

有一点很重要，一定要跟 PR 讲：现在给的价格是几月份的价格，是不是一定当月发布稿子；如果延迟到下个月发布，是不是要涨价（保价概念）。
