# 3.4 粉丝破千后，正式签约蒲公英

## 3.4.1 签约蒲公英需要什么条件 @周恩俊

首先，账号必须完成实名认证，并且本人年满18周岁。

其次，粉丝数量要突破1000大关。

选准方向之后，通常10到15天就会慢慢起量，大多数人一个月上下就能攒够千粉，接着就能签约蒲公英平台，开启广告接单的变现之路。平均下来，单账号单月的收入大概在1500到2000元这个区间。

这里有个小提醒：千粉之后别急着马上签约，担心会掉粉的话，最好等到1050粉左右再操作。入驻之后千万别断更，保持每天更新。笔记的阅读量尽量维持在1000以上，这样品牌方主动找上门的几率会更大。

⚠️特别提示：实名认证建议等到千粉之后再去做，免得浪费名额，具体操作可以看「3.4.2 入驻流程」。以后也可以用家里人的身份来完成认证。

## 3.4.3 如何设置报价 @漫漫 mansi

1）看粉丝消费力与数据表现

不同赛道在定价时，要结合粉丝的消费水平以及账号的数据效果来定。举个例子，学习类赛道在粉丝不足1万时，报价大概在700到1000元；粉丝到10万时，可能涨到1500至2000元。不过学习赛道有个特点，粉丝涨到20万之后，价格增长就会明显放缓。

像美妆、护肤、母婴这些赛道，报价普遍会更高一些。数码科技类产品的价格也不低，值得重点开拓。

⚠️判断报价的小窍门：品牌方投广告图的是转化，所以粉丝消费能力越强，对品牌的吸引力就越大，品牌也更舍得砸钱。品牌投放时最看重ROI，花1000块能曝光2万，肯定比花2万曝光2万来得划算，这也正是为什么很多大博主会专门做小号、用小号去接单。

2）借助数据平台了解行情

建议多去数据网站查一查行业标准和市场价位，摸清后台报价情况，然后在蒲公英平台给出的价格基础上做适当调整。

3）根据品牌反馈灵活调价

价格也可以在和品牌方沟通的过程中去调整。比如你报完价对方一口就答应了，那说明你报低了；如果对方跟你来回砍价，最后看大致成交在什么数，那个数可能就是你真实的市场价。

这时候笔记还没正式发布，其他用户看不到。提交之后，笔记会进入平台和品牌的审核确认环节。

如果审核没通过，会在消息通知和蒲公英后台收到通知，需要按要求修改笔记。

审核通过后，就可以进入笔记发布环节了。在和品牌方约定好的时间，点APP「消息通知」里的前往发布笔记，或者点笔记详情页面左上角的「合作品牌已确认」，就能正式发布笔记。

品牌确认完成订单后，合作款项就会到账。如果品牌方没有主动确认，7天后系统也会自动确认订单，收益同样会到账。

如果对接的是商家，直接结算订单收益就行；

如果对接的是PR，对方可能会要求抽佣。

一般加🛰️后，如果对方是PR，会跟你聊广告内容和返点佣金。返点通常抽20到40元左右，能接受就合作，接受不了就拒绝。

当然不是所有PR都抽，只有想自己赚点的才会这么做。后面笔记发布完、收益到账，按谈好的分佣直接私发给PR就行。

提现：订单确认后7天，到📕钱包统一提现，提现时扣10%的税。

# 4.4 注意事项 @虾饼

合作形式分为报备笔记和非报备笔记。报备笔记就是前面说的官方认可的品牌合作，要被收取“保护费”；非报备就是私下合作，悄咪咪打暗广。

非报备又分单品和合集。单品是一篇笔记里只能出现这一个品的广告；合集是同时有多个品给你广告费，出现在同一篇笔记里。

单品里还有个概念叫伪合集，就是一篇笔记里看着出现了好多产品，但真正给了广告费的只有一家，这样做是为了最大程度避免被判定成私自推广。

跟PR沟通时，下面这几个问题要聊清楚：

档期：就是你出初稿、终稿和最终发布的日期。

授权转发：能不能授权品牌方在电商或内容平台上发布，是否免费，授权周期多长。尾部博主一般免费授权，周期通常在三个月到半年。

授权投流：能不能授权品牌方在📕里投流，是否免费，授权周期多长。虽然投流能帮你涨数据，但万一品牌爆出丑闻，还继续拿你的笔记去投流，会影响你账号的形象。所以最好定个周期，比如一年内免费授权投流，一年后再看情况决定是否继续授权、是否加费用。

笔记发布后的保留周期：一般是一年或永久。

排竞：在你发布这篇笔记的前几天到后几天，不能再发该品牌竞品的相关笔记。

活动出席：美妆和穿搭类品牌可能会邀请达人参加他们的产品发布会之类的活动。

# 5.1 优化笔记，提升数据

## 5.1.1 笔记数据不理想，怎么优化？

有人问，我一篇笔记浏览量在100到300、300到500这样的区间，正常吗？

很明确地告诉大家：正常。

自己的浏览量不低于50，在50到500这个区间，作为新号，发内容时看的人偏少，是很正常、很普遍的情况。

因为你不是有名气的大博主，比如别人有十万粉甚至更多粉丝基础，一发笔记就有固定粉丝受众，浏览高很正常。

所以心态很重要，一定要稳住。

其次，做数据对比时，可以跟正常的内容数据比。

比如你发了很多篇笔记，都会有一个数据对吧？那你看自己发的笔记里，哪些数据比较好，然后试着分析好的原因在哪里。

再次，可以和自己同等级的博主做内容数据对比。

所谓同等级比，就是对方粉丝基数500左右，你也是500粉左右，这样对比才有意义。

你不可能自己只有500粉，硬要跟10000粉的博主比，那样对比往往没有参考价值。

和别人对比的过程中，可以看自己的点赞收藏数，再看评论区。

为什么别人笔记里评论比较多，或者收藏比较多？可以看看他们的内容，观察他们引导互动的方式，尽量去模仿和学习。

如果确认数据不理想，可以从以下几个方面反思和优化：

1）小眼睛（阅读量）不佳

一般发布后2-3小时内阅读量差，或者长期只有100-200甚至低于100，可以对照下面几个问题检查：

运营初期的正常现象，账号权重还太低；

笔记违规、触碰敏感词，或者发了平台本身就不会大力推荐的内容（比如医美、保险、社会负面、中国负面）；

选题、标题文案或首图不吸引人，尤其要重点检查选题角度和首图。

2）点赞、收藏、评论等互动数据不佳

用户收藏这篇笔记，说明内容有实用价值，现在或未来用得上；

用户点赞或评论，说明内容获得认可、引起情绪共鸣；

用户因为笔记转粉，说明不仅认可笔记，还认可你本人，期待你以后产出更多优质内容。

互动数据不好，排除违规和玄学问题，十有八九还是笔记内容质量不够好。

可以对照下面几个问题检查：

完全文不对题，选题标题吸引人，但点进来内容跟主题毫无关系

内容文字营销感太强，全是硬广、打广告

内容给用户的收获感不强，实用性不够

内容很像无意义的朋友圈，既没提供情绪价值也没提供实用价值

3）发布后修改笔记的注意事项

经常有人问：修改已发布的笔记会不会影响曝光量？

从观察到的数据来看，修改后阅读率确实会重新计算。但只要不频繁修改，是不影响这条笔记的。

但修改笔记可能会重新审核，审核没问题才会放出来。有时候笔记里有敏感词，改过后重新发，或者优化了标题等，数据反而会更好。

也有一些情况，本来审核过了、正常给流量了，修改后工作人员觉得有问题，反而开始限流，数据就不好了。

如果有笔记爆了但想修改，克制住，别动笔记，可以在置顶评论里补充。

图文笔记全部都可以替换修改；视频笔记只能改文本和首图，视频本身无法替换。

修改提交后平台审核系统会做二次审核，没违规的都会照常通过。

如果已经是爆款笔记，且热度还在持续上升，不建议轻易修改，可能影响数据增长。
