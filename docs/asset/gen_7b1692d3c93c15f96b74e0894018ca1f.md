# 方法一：自己找番茄官方签约

想直接对接番茄小说官方、拿下推广合作？可以，但先把规则看清楚。

自己联系官方时，关键词申请、链接回传、佣金结算等环节出现的问题，都要由你自行处理；同时不能使用「乐推联盟」的合作表单。还要记住：官方和服务商是两套独立的查询系统，彼此并不互通。

1）联系番茄小说官方客服

拨打95152，服务时间为每天8:30—22:00。接通后按0转番茄小说平台，再按6进入人工。向客服说明：你想在抖音推广番茄小说，询问如何签约。客服会提供一个🛰️号；在工作日添加，备注“达人推广+在抖音上推广番茄小说”。通过后，按官方要求完成后续签约。

2）获取小说链接

方式一：打开小说，点右上角三个点，选择系统分享，复制链接后删掉文字部分。

3）填写关键词申请表

当天14:00前提交的，工作人员配置好别名后会在当天统一通知；14:00之后提交的，则顺延到第二天配置。别名显示灰色，说明未通过，修改后重新申请。如果视频已经发布，建议尽快更换别名，并把新通过的别名放到评论区等位置。

4）作品回填

把已发布作品的链接和关键词一起填写回传。无论你发了多少条视频、在哪个平台发布，都只需要填写一个关键词。
