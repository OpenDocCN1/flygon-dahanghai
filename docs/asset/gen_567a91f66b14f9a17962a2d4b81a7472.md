# 内部「龙珠」：团队激励新玩法

这两年，社群里不断有优秀伙伴走进我的团队，把精力投到社群、产品、广告和短视频这些业务里。

我盼着公司一步步进化成“孵化平台”：物色操盘手，拿出启动资金和资源，帮忙组建初始班底，明确业务方向并给予指导，然后与团队共同成长。一群聪明人聚在一起，完全可以做出许多有趣且有价值的事。

从社群里走进团队的那些伙伴，不论价值取向是否合拍、看事情的格局、眼界还是办事能力，都更让人放心。我也定下一条规则：今后生财有术的社群运营岗，只从生财有术圈内招募。有想法的人可以直接来找我聊。

团队里优秀的人多了，我最近一直在琢磨：怎样设计一套规则与氛围，让每位伙伴的产出更高，也愿意一直保持优秀。

今早晨会上，一个念头突然冒出来：在社群运营团队里，或许也能引入一套类似“龙珠”的玩法。

比如，策划并执行一场好活动，让生财有术圈子里的朋友体验更佳；月度复盘积分排第一；带队大航海并取得亮眼成绩；负责私董会并交出优质成果……这些关键且有效的动作，都能换来内部龙珠。手里有内部龙珠，便可分享社群营收和孵化项目的分红，甚至内部龙珠还能与外部内容互通兑换、交易。

这个想法让我格外兴奋。我坚信，今天埋下的想法，会在未来某个合适节点破土、抽枝，最终长成一棵大树。
