# 4.3 规划工具：不妨试试50+10

提到时间管理里的经典方法，很多人会想到“番茄工作法”：把30分钟当作一个循环，其中25分钟全神投入，5分钟用来歇口气。它背后的依据是，人的注意力通常只能维持15到20分钟。从理论上说，这套设计相当合理，但落到职场里，25分钟专注加5分钟休息的组合往往并不好用，原因大致有三点。

一是25分钟偏短，不少人刚找到工作节奏，时间就到了。二是办公室场景未必允许你每隔25分钟就起身走动、接水或休息。三是职场中被打断几乎是日常，想连续25分钟不受干扰，更像一种理想状态，未必真能实现。

因此，更实际的安排可以调整为：连续工作50分钟，再集中休息10分钟。前50分钟尽量把注意力放在任务上，后10分钟则专门拿来放松和整理，比如去倒水、上卫生间、做几组简单拉伸，顺便核对一下手头工作的进度。

落地方法也不复杂，用电脑桌面闹钟做提醒就行。苹果iOS系统可以借助Be Focused；Windows系统自带的闹钟功能已经足够。每次休息结束后，还可以顺手换一下办公姿势：前一个50分钟坐着，后一个50分钟站着。如今能帮助站坐切换的桌上桌、落地桌选择不少，按自己的需要配置即可。

结合前面的记录和梳理，我们就能整理出一份按时间顺序排列的基础安排。几天的记录下来，你或许会发现，每天早、中、晚都有一些固定行程，它们是每天都要完成的事，而且越稳定越好。这样一来，行为惯性就能帮我们减少意志力的消耗。
