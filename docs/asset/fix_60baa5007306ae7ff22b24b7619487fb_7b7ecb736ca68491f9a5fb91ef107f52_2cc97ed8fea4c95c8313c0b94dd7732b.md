# 4.5.1 口碑：增长会自己来

口碑这件事，本质是让足够多的人愿意替你说话；当这种声音汇成一片，增长就不必只靠你一个人硬推。

外界记住的小米，常带着理想主义色彩：硬件综合毛利率卡在 5% 以内，口号是“为发烧而生”。但容易被忽略的是，小米起步阶段没有把拉新当成第一动作，而是把口碑当主线。小米内部那本营销手册《参与感》讲得很直白：把口碑做厚，增长会自己找上门。

真诚要摆在台面上，回应也别绕弯子；对外扩散时，重点不是夸群多好，而是让那些真正因群受益的人被看见。这些动作坚持久了，口碑才会长出来；它属于社群运营中那种经典但不容易做对的事。

若要从零起步，该抓什么？我会盯两处：参与者感受，以及成员之间的相互带动。

## 1）参与者感受

感受要转化成口口相传，最先卡住的往往是命名：群叫什么、活动叫什么。踩中下面任意一条，这个称呼就很难算合格。

- 一百人听一遍，一半人写错，这称呼就不合格；
- 靠出人意料的同音字替换来抖机灵，通常也不行；
- 中文里夹外文，多数情况下减分；
- 用外文词且词义生僻，多数情况下减分；面向国内用户，外文能少则少；
- 像 KFC、ETC 一类的缩写，字母最好控制在三个以内，三个已是上限；
- 字数多于五个汉字，多数情况下减分；
- 念起来别扭，直接淘汰；
- 顺嘴、易记，同时不影响商标注册，才算达标。阿里巴巴这种四字、念着有节奏的词，以及小鸡叫叫、4399、农夫山泉，都属合格样本；
- 听完之后脑海里冒不出具体形象，多数情况下减分。苹果、小米就比讯飞更容易形成画面；风向标也比商业线索更具体。

这些条目可以当成一把尺子，拿来量自己起的称呼。原理不必展开，关键在体会。

活动里的高光片段，也能把复杂感受压成可转述的要点。一场活动结束后，每个人记住的片段并不一样。做复盘和二次扩散时，与其堆信息，不如把素材做得有场景、有细节、能压缩成一句顺口的话或一个梗。

饭局上，说“00 后拿分酒壶仰头清空，将近一斤下肚，中途不喘”，比只说“年轻人酒量好”更容易被记住和转述。

🛰️群里，主讲人话音一落，十多位成员接连发红包，聊天框瞬间被红包盖满，这比“老师讲得扎实、线上氛围热烈”更值得转述。

“当时大家只能靠文字交流，却像有人按了静音键，所有人屏住呼吸等下一句弹出来”，比“他讲话时没人插话”更鲜活。

这些内容别只在群里说，要往外说，而且得长期、有章法地向圈外扩散。

当成员被朋友问起“你在这个群里得到什么”，他能不假思索说上几条，口碑就已经在路上了。群里的故事会进入他的茶桌、聚会闲聊，也会变成他向外介绍新事物时的社交凭证。

在各类感受里，带情绪的片段留得最久。道理、资料、知识点很难形成统一而牢固的印象，情绪却能。

## 2）成员带动成员

这里要围绕三件事：扩散发生在哪里、拿什么给成员当转发素材、奖励机制怎么搭。

如果没有太强的技术手段，只靠人际关系做社群增长，第一问就是：怎样让现有成员引来更多成员。

每个小活动都埋一点“老成员拉新成员”的机制，扩散效率往往高于你自己单点去覆盖多处。

拼多多是常被拿来讲的样本。它获客花费低，原因之一是一个用户带来传播后，能触达三到四个潜在用户；这套“成员拉成员”的机制从一开始就写进产品设计。

行动类、成长类社群常发实体或虚拟荣誉：徽章、纪念物、头衔。对成员来说，这是可展示的成绩；当他认为这个头衔或品牌有分量，日后介绍自己时就会带上。旁人一听便问“这头衔什么意思”“这徽章哪来的”，于是又有一批人回流。站在社群角度，这同样是拉新。
