# 三页促销站放养两年，账户里躺了848美元

1）起因很简单：公司有个主项目要推，我们顺手做了一个面向海外的促销商品展示站。页面只有三个——首页、分类列表、商品详情，界面也没精雕细琢，两天就上线了。功能极简，没有注册会员，没有留邮箱换折扣码，连发折扣码的模块都没做，纯粹是商品陈列。

后来觉得空着可惜，就注册了亚马逊联盟，把推广追踪参数嵌进每个商品的购买按钮。用户点链接跳到亚马逊下单，我们按成交拿佣金。再后来公司自己的商品业务忙不过来，这个小站就基本进入放养状态。

那段时间大约进账一百多美元。2019年那会儿提现流程麻烦，我也没心思折腾，亚马逊最后把钱折成了礼品卡兑换码。当时想法很朴素：钱都取不出来，更犯不上花精力。过了些日子收到通知，说联盟账户被关了——大概是连续多少天没达到销售门槛，具体数字记不清了。连带其他国家站点也一起被封，我们没去重新申请，等于到今天少赚了一些，哈哈。

之后换了一个新的亚马逊美国站联盟ID，照旧没怎么管。

直到2022年2月底，我偶然登进亚马逊联盟美国站后台，发现里面躺着848美元（见下图）。

## 成绩 2）月访客4.3万，这个小促销站做对了什么
[PRE4]

说来惭愧，当时我根本没系统学过SEO，只翻过几篇入门文章。做的操作就是：给每个商品页单独配TKD（标题、关键词、描述），商品链接里带上商品名（例如*-mechanical-gaming-keyboard-），再设置页面定期生成、提交给谷歌。其他真没了。时间太久又没上心，现在只能对着网站和代码回忆，未必全面。以前完全没把SEO当回事，现在等于才开始补课。

## 3）需求是怎么被撞上的
[PRE5]

这个站纯属误打误撞。但要说“挖掘需求”，我能想到的是：促销打折是大众需求，总有人需要，尤其当下经济环境偏紧，海外用户也精打细算，能省一点是一点。拼多多海外版TEMU上线几个月就火成那样，就是例子。不过大众需求也意味着竞争激烈，促销类网站大大小小确实很多。

好在促销站日常维护不算重：定期尽量多地更新商品（基本可一键操作），持续优化即可。新手如果有精力，可以试一试。它看起来像内容站，实际更接近工具站，内容添加能用不少自动化方法。SEO搞流量的同时，有余力也可以多花点精力做海外社媒。后期流量起来后，如果有一键代发的自有商品、利润空间更大，再考虑谷歌等广告投放也未尝不可，纯属畅想，哈哈。另外流量大了，还能给卖家做站外推广挣中介费，之前看生财有术里也提过。

## 4）踩过的坑与攒下的经验

当时系统设了商品30天后自动下架不展示，导致商品数量掉了很多。加上站点没管理，证书过期了也不知道，老用户流量下滑不少，付费转化也跟着减少。本来流量已经起来了，结果直接腰斩（见图）。
[PRE6]

其他国家站点最初被统一封号后，我只重新申请了美国站。这里提醒：要留意自己所有其他国家站点的联盟ID，一旦失效尽快补上；除非你不做那个国家的生意，否则多挂几个站就多几个赚钱机会。SEO优化也做得不足，我没系统学过谷歌SEO，当时只看了几篇文章，以为把TKD做好就万事大吉。网站没做多语言，对小语种国家用户不友好，转化估计难。应该加上博客功能，写一些商品类别排行榜文章，尝试模板化，更方便谷歌收录和获取流量。还可以注册一些一键代发平台，上架那种商品，相当于卖自己的货，应该能多赚些。后续可以用邮件营销唤回老用户复购。
