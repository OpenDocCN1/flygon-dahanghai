# 月薪5000到月入10万，我用500个号跑通了普通人做公众号的路

我在国企做外包，每月到手5000块。2021年咬牙拿出一个月工资，加入了生财有术。那时候我爸全年收入也就3000，我妈转账时专门写了“工资”俩字当备注。

公众号这事，我前前后后折腾了八年。头七年全靠自己硬扛：标题自己琢磨，正文自己码，一篇稿子耗掉五个钟头，推送出去阅读量也就两三个人，其中一个多半还是我自己点进去的。

转机出现在2025年3月。我把AI批量写作这套打法彻底跑通了，第一个月进账1880块，还写出一篇阅读过万的文章，当时整个人都懵了——像是突然摸到了互联网的一道暗门。五个月后，副业月收入突破十万。如今我手里有500个公众号组成的矩阵，注册了公司，合伙人是南虎，另外还有四位员工。

号做到80个那会儿，我妈一度以为我在搞电诈，专门打电话给我媳妇，让她看住我、别让我再碰互联网。我是生财有术五年的老圈友，当初顺着明白老师的链接进来的。我常讲，这三十年里身价最高的一笔投入，就是它，没有第二笔能比。这次大会我彩排了15遍，前一天凌晨五点还对着PPT逐句过，合伙人早打着呼噜磨牙了，我还在练。

## 道（底层认知）

### 别死磕满分，60分能批量复制才是普通人的赢法

从0到1，我走了八年。头七年自己写标题自己写正文，五个钟头憋一篇，发出去就两三个人看。后来我琢磨明白了：没必要奔着100分去。AI产出的稿子兴许就60分、70分，人工再修一修能到80分。可要紧的是，我七分钟能出20篇。十个豆包页面同时开着，七分钟就是200篇。一篇100分的文章，还真不一定干得过200篇80分的。

有人讲批量产出的东西都是垃圾，这话我不认。我手上所有号都是批量做的，同一套8000字提示词翻来覆去写了成千上百篇，给我带回十万、二十万的进账。微信官方搞垂直小号内测，我拿了第一，280多篇文章全是批量出的，一个字没动就传上去了。直到有粉丝在后台留言问我写了啥，我才倒回去瞄一眼。所以说，批量不等于垃圾，根子在于你的提示词够不够硬、框架够不够牢。

### 当不了大IP，那就铺几百个小IP

咱都是平凡人。别指望一个号就攒千万粉丝、吃无数流量，那不现实，人家是一二十号人的班子在推。我换了个念头：我成不了大IP，但我能铺出几百个小IP。500个号，个个都是我的个人IP，搁一块儿算，是不是也顶得上一个大IP？靠数量往上堆。

普通人做事得讲概率。拿时间换确定性，不必追求完美照样能挣钱。量堆够了，概率自然往你这边靠。

### 灵感这东西靠不住，靠得住的是SOP

八年公众号写下来，头七年全凭灵感和自己的感觉。2025年3月有那么一回，我直接抓了一条10万加的标题来套写，那篇冲上了我历史最高阅读——一万加。当时人就傻了，感觉摸到了互联网的一道暗门。

打那以后我就认准了：别信天赋灵感那一套，要信标准化的SOP。拿一套验证过的爆款框架写100遍，远比吭哧吭哧原创100篇划算。我每个赛道都配了8000字专属提示词，每天抽五分钟调一调，出来的稿子质量就一点点往上走。

### 八年才迈过从0到1，关键是别下牌桌

我手上带过不少纯新手，好多人熬了十天没见正反馈就撤了。可我的体会是：简单的事反复做，你就成了专家；重复的事用心做，你就成了赢家。真正的高手不是啥招式都会一万种，而是把同一招练足一万遍。

我从0到1花了八年，从1到10花了五个月，从10到100花了七个月。只要人还在牌桌上，总能等到天亮。坚持和实操，就是唯一的近道。我月薪三千到五千的时候都觉着自己能成，在座各位肯定也能成。千万别看轻自己的前路，也别把心里的梦给扔了。

## 法（方法论）

### 赛道决定生死，定位决定成败

我选公众号的理由有三条：头一条，工资低，想搞份副业，公众号只要敲字就行，门槛相对低；第二条，我这人轴，八年都没撒手；第三条，生财里一抓一把靠公众号月入十万、年入百万的高手，踩着成功者的脚印走，大概率错不了。

挑赛道我拿六个维度来卡：流量池够不够深、变现快不快、内容能不能批量出、新手有没有突围空间、合规上安不安全、个人能不能长期扛。能同时占上五六条的，就是合你脚的优质赛道。

定位不是越垂直越妙，而是要垂到精准、垂到能变现。最稳的路子是大领域配小切口——别做泛品类，也别钻太窄的品类，就锁定一类人、一个核心问题。打个比方，读书赛道啥书都写，不如只写《天道》，只扎一类人群，只解一个核心问题。定位公式说白了就是：我给哪类人，在什么场景下，用哪种风格，供什么价值，跟别人不一样的地方在哪。

### 找对标就等于找钱

谁挣着钱就向谁取经，谁赚着钱就照谁抄。这个“抄”分两层：头一层是抄写，拆解它爆款内容的结构；第二层是超过，琢磨怎么在收入上把它甩后头。

锁定对标号之后，我拿五个维度来掂量值不值得跟：平均阅读能不能到5000加或1万加、是不是日更、内容能不能批量复刻、变现走哪条路（广告、带货还是虚拟产品）、互动率高不高。

拿中老年情感短评赛道来说。我调研时瞅见一个号，篇均阅读四五万，天天更新，文章短得很，一两百字，批量复刻毫无压力，变现靠底部流量主加留言区广告，5万加阅读能榨出近1000块。我摸的时候还没几个团队盯上这块，我们就扎进去了，掘到第一桶金。

### 拆爆款框架，一套提示词写千篇

我核心的方法论浓缩成一句：拆解爆款文章，提炼出能反复用的提示词，拿它写100遍，而不是费劲写好100篇。

落地怎么做？先把对标领域的爆款文找出来，让AI逐字逐句按维度拆——选题、标题、封面、内容结构里的人设、场景、情绪，最后吐出一套该领域能反复用的提示词。再把你的真实个人IP嵌进去，让AI产出原创稿。虽说够不上原文100分，但60到70分人工再修修，能推到80分。我的提示词由三块拼成：模仿提示词＋对标链接标题输入＋个人IP故事感框架。三样一融合，一套提示词就能撑起几百上千篇。

### 80%确定性搭20%创新，就是你的内容

我的经验公式是这样：80%用被验证过的确定性因子——爆款框架、爆款逻辑、爆款人设，剩下20%留给创新——你的独到视角、你的个人IP。

我会在提示词里揉进故事结构的起承转合，让人读着觉得你是个活生生、有情绪的人。再添上五感——视觉、听觉、嗅觉、味觉、画面感。再塞进热点词，热点是公众号的绿色通道。收尾是情绪，只有把用户情绪撩拨起来，他才会对你留印象。

好内容长啥样？优质选题＋优质标题＋优质封面＋优质内容结构。内容结构里最要紧的三样：清晰的人设、能代入的场景、能共鸣的情绪。

## 术（现在直接用）

### 选题与对标

- **微信搜一搜找对标**：敲关键词 → 挑“最热”＋“最近半年” → 挖出粉丝少却出过10万加文章的号 → 把爆款标题复制下来 → 丢进“对标账号群”和“对标选题群”
- **AI找对标**：甩一句“帮我推荐10个XX领域的公众号，要求发布天数300天以内，平均阅读1万加”，一口气捞回二三十个对标号
- **其他渠道**：新榜、易撰、注册个微信新号让系统给你推优质文章、从抖音小红书扒热门选题挪到公众号

### 内容生产SOP

- **标题**：直接套10万加的优质标题，别自己憋原创——八年公众号验证出来的铁律
- **封面**：把对标号的封面扒下来 → 喂给AI提示词让它1:1仿着还原，不踩违规线
- **写稿**：使豆包，塞进8000字提示词＋20条对标文章链接或标题 → 自动吐出20篇，从第一篇标到第二十篇 → 开十个豆包页面 → 七分钟出200篇
- **为啥挑豆包**：实测灵感更足、AI味更淡、八岁到八十岁都能上手，最要紧的一条——白嫖
- **人工优化检查点**：标题内容结构有没有毛病、有没有把你的产品和服务埋进去、有没有引导关注、有没有情感升华
- **AI评分优化**：稿子出来后让AI打个分、给点修改意见，再微调一下推出去

### 去AI味实战技巧

- **禁用递进逻辑词**：把“然而”“此外”“总之”这类AI爱挂嘴边的词拉黑
- **禁用结构性词汇**：拉黑“首先”“其次”“最后”“第一”——用户扫一眼就晓得是AI的手笔
- **标点替换法**：中文逗号改英文逗号，句号改点号，AI味基本能压到很低（写了10万篇才敢下的结论）
- **植入个人真实IP**：把你的真实人设、真实故事、真实情感掺进去，原创度和用户粘性一起往上抬
- **在提示词里加禁止清单**：把要拉黑的AI味词汇一条条列明白，让AI输出时自己绕开

### 矩阵运营路径

- **起步**：从3个号开跑，验证单篇能稳到篇均2000加阅读再撒开量
- **验证周期**：先把提示词调顺，做好一篇内容打样，能持续跑出2000加阅读才算模式立住
- **扩量路径**：3号 → 20号（自己操盘）→ 50号 → 500号（得靠团队＋工具）
- **账号来源**：校企合作（大学拿实习岗位换200家号）、企业合作（合伙人供了870家号）、自己和合伙人四处搜刮一百多个
- **发布节奏与算法**：推出去后0到2小时是小流量试水，2到12小时定夺给不给大推荐，12到24小时最终拍板能不能爆
- **运营优化维度**：点赞率、转发率、分享率、互动率、阅读完成率

### 商业变现体系

- **基础盘**：流量主进账＋广告主投放（像中信银行单笔4.5万）＋橱窗带货
- **进阶盘**：课程训练营＋个人咨询＋服务收入
- **收入结构示例（单号月入10万）**：广告进账4.5万＋训练营几千＋服装带货几万＋流量主3万多
