# 6.3.2 发圈时间怎么排？

每个时间段，客户状态不同：是在发呆、工作、挤地铁，还是在喝酒聚餐？虽然不能百分百猜中，但同一时间大多数人做着相似的事，比如早上起床吃早餐，下午上班摸鱼玩手机。所以这个环节很重要，直接影响转化率。

发朋友圈的七个黄金时间段：

① 07:30-09:00 早安圈：一天开始，大家早起或吃早餐。

② 10:00-12:00 产品圈：工作一阵会休息看圈。适合发高级感产品摄影图（养眼又养心）；故事感软广文案（用共鸣小故事）。

③ 12:30-13:00 反馈圈：午休大家爱翻圈看热闹。适合发客户好评晒单图、美图，可配与客户对话开头的走心文案。

④ 15:00-17:00 价值圈：工作间隙休息喝下午茶。适合发原创感悟类文案，可纯文字也可图文。

⑤ 18:00-18:30 产品圈：下班吃完饭休闲一会儿。适合以顾客视角写产品软广，一定结合自己对产品的理解。

⑥ 19:00-20:30 生活圈：吃过饭或聚会的黄金时间。适合发生活摄影图展示生活品味，写走心生活场景文案。

⑦ 21:00-23:00 复盘圈：睡前很多人会复盘白天发生的事。

以上就是发圈黄金时间，照着发一般不会错。

# 七、资料准备

# 💡

章节概要：

资料引流的主角是谁？当然是资料。这一章讲怎么搭建资料库，并从中找到你的引流资料。要注意，我们更鼓励你提炼自己已有的课程内容或资料，把核心内容做成引流品放到小红书，吸引那些还没被充分转化过的高精准用户。

# 7.1 资料库怎么搭？

这里给你3种搭建资料库的方法。

# 7.1.1 第一种：自建课程/训练营

如果你有自己的课程或训练营，有不错的IP内容沉淀，完全可以从已有资料里提炼出有吸引力的核心内容，把最有价值的部分放到小红书笔记中，作为引流资料。如果你暂时没有自己的课程内容，星球上有很多教“如何搭建课程”的精华帖可以看。

# 7.1.2 第二种：借力合作伙伴资料

如果你有信任的合作伙伴，他们有自己的课程内容，你也可以做一个带货玩家，带的就是他们的服务、课程/训练营等。达成合作后，你可以用他们的部分资料作为自己的引流资料，把引流来的客户交给他们做后续成交，你从中拿相应佣金。

# 7.1.3 第三种：汇总公域无版权内容

如果前两种都不符合你的实际情况，你更想先跑通小红书资料引流闭环，那就建议用第三种：从公域无版权内容出发，收集汇总这些资料，作为引流资料库。要注意，第三种不是长久之计，只能收集市面上无版权、免费流通的内容，这样才能合规、避免版权纠纷。长期来看，更推荐前两种，第三种只是暂时过渡。由于大部分人可能没有资料，所以下文会详细介绍第三种方法的完整流程，帮大家先快速上手，拿到正反馈。
