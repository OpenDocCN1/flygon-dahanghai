# 督学做得好不好，看学员赢没赢

上周末北京龙珠的年夜饭上，我碰见两位在「抖音商业IP大航海」里做出名堂的圈友。一位是大黑哥——第一拨跑出爆款、第一拨拿到官方扶持、变现过了十万元门槛；另一位是亮亮教练，熟悉他的人都知道，各个群里隔三差五就能看到他分享做号心得。

散场时大黑哥跟我逗了一句：这回你带哪支队伍？到时候我们挑你们队的。亮亮教练在旁边补充说，想试水抖音知识付费，先去大航海当一回志愿者，把赚钱那套交付亲手摸一遍，不会亏。

对头一回参加龙珠夜话、社交有点怯的我来说，这两句话分量不轻。回去路上我一直在琢磨：新一期抖音大航海眼看要开船，我能不能把这趟学到的东西整理成一篇帖子？如果有志愿者同好翻到，能拿到一点鼓励和几样抓手，带着船员走出一段不一样的航程；要是被今年想抓住抖音知识红利的人刷到，对交付也能有点启发。

打算按四块来写：
一、学员先赢，口碑才立得住
二、自驱力，逼不出来只能养
三、带人这件事，阿德勒有答案
四、交付的细节，跟得到班主任学

## 一、学员先赢，口碑才立得住

兰卡老师在知识星球提过一个公式：训练营的成败等于规模乘以口碑。规模看的是你触达并影响了多少人——比如报名加入的人数；口碑看的是真想学、真想干的人有没有学到真方法、拿到真结果。

口碑的源头是好案例，好案例的源头是选对人。一个人要发生大改变实在太难，但找到那种离改变只差最后一步的苗子，推一把就成了。

捋下来就是一条链路：锁定高潜学员→把他们带出结果→口碑自然散开→训练营或者大航海就跑通了。这和重点高中抓尖子班的套路很像——招好苗子，出清北成绩，名声起来了，生源一届比一届强。大航海/训练营的底层逻辑，说到这儿也就清楚了。

志愿者手里真正握着的杠杆，只有“学员成功”这一环。所以，把督学陪伴做扎实、帮学员跑出结果，就是志愿者最重要的交付。这一环要是塌了，其他花活儿做得再热闹，大概率也是白费劲。能聚焦的时候，一定要聚焦。

## 二、自驱力，逼不出来只能养

《驱动力》把人类动机的演变划成了三段：1.0阶段，主要靠生存本能和生物冲动——避害、找吃的这类；2.0阶段，奖励和惩罚成了主力，也就是大家常说的胡萝卜加大棒，这套逻辑默认工作本身没意思，用来对付机械性问题尚可；到了3.0阶段，三个新引擎浮出水面：自主权、精进感、以及“想比昨天的自己更强”的渴望。它成立的前提是：有些工作本身就很有趣、有挑战、需要大量探索。

顺着这个思路，碰到真正有挑战性的事，对待员工、学员或者志愿者，方式就该反过来：把信任交出去，把空间让出来，把资源给到位，再引导他们把本事磨精，让他们自己生出往更高处够的劲头。

一句话概括：你希望对方扛下一件大事，就别替他扛。把能量给他，让他自己愿意跑。

[PRE2]

大航海不是标准流水线，它是探索型项目，每一期都可能长出新东西。没有哪套SOP能包打天下，上一期的成功配方，换片海域可能就失灵了。我们能做的，重点不在管控，而在养土壤——造一个能让各种内在动机自然冒出来的环境。

反过来想，假如你默认人是懒惰的、能逃就逃，于是靠盯、靠管、靠惩罚推着走——“必须盯着他们、控制他们，用惩戒施压，他们才会好好学、好好干”——那产出一准好不了。

## 三、带人这件事，阿德勒有答案

上一期大航海收尾后，我反复琢磨一件事：我带队偏散打式、个性化，这套东西有没有可能提炼出某个更底层的抓手，移植到别的项目里？想了很久没头绪。直到李小随老师在龙珠群推了一本书，叫《管理精进：跟阿德勒学带人》，我才把线头接上。

书名看着像管理教材，其实讲的是人。阿德勒的底层判断是：一切问题归根结底都是关系问题。而教育这件事，从来不是单向灌输——更像一棵树带动另一棵树，一片云推着另一片云走，是一个灵魂把另一个灵魂叫醒。带船员也好，撑志愿者也好，说到底都是“带人”。

整本书如果只留一句话，那就是：给人勇气。

看过《自卑与超越》的朋友应该记得，阿德勒说自卑人人都有。区别在于出口——有人把它变成往上走的燃料，有人把它拧成往下坠的借口。分水岭就在勇气存量。吼叫和恐吓跟勇气不沾边，真正的勇气是那股“迎难而上”的活力。

阿德勒心理学认为，勇气一旦缺位，人就容易把头埋进沙子，绕着问题走；勇气在线，才会正面迎上去，想办法啃下来。所谓给勇气，就是让对方自己长出解决问题的手感，自发地去跨过障碍——毕竟，人天生都有“变得更好”的倾向，我们要做的是把那个开关打开。

具体怎么给？三条原则：别用表扬的姿态、别用训斥的语气、别直接上手教。

1、别用表扬的姿态。表扬和称赞听着像一回事，其实不同。称赞是平视的欣赏，表扬往往带着俯视感，甚至裹着控制。没人真心喜欢一个总端着架子的领队——哪怕嘴上不说。

[PRE3]

2、别用训斥的语气。我自己当船员时，碰上脾气冲的志愿者或助教，被凶几次之后就不想再靠近，更别提主动请教了。人在那种氛围里，学习效果能好到哪去？换人都是有可能的。

书里给过一个反面示范，大意是劈头盖脸地否定：“不行不行，你再这么干准出问题！动动脑子，照我说的来，赶紧改！”——这种单方面的、没有商量余地的表达，传递的潜台词就是“我对你错，我懂你不懂”。

别拿“严师出高徒”当挡箭牌。当个领队、志愿者或助教，咱就自动变严师了？换一种更平视的说法，费不了多少劲，效果反而更好。比如：“这个环节，如果多留意某个点，可能会顺一些——你自己怎么看的？”下回想发火之前，试着把指责换成商量，把俯视换成平视。

[PRE4]

3、别直接上手教。上一期大航海，我最得意的不是某个成绩，而是队里几乎每个志愿者都玩出了自己的花样，小组各有各的打法，最后交出来的东西还都挺亮眼。为什么能这样？因为我没把想法摁成任务派下去，而是把他们的思路当回事，放手让试。

前面聊过我对大航海的理解：它更像荒野探路，不是流水线上拧螺丝——按指令机械执行换不来突破，得让每个人的主动性、创造力真正转起来。当领队的，把方向指清楚、把劲鼓起来，惊喜自然就来了。

## 四、交付的细节，跟得到班主任学

得到品控手册里关于班主任的部分，我翻过一遍，发现不少思路和赚钱优秀志愿者的实践是通的。既然人家已经总结得很系统，我就借过来，按大航海的场景做点转译：

1、靠谱的志愿者不该把自己定位成有求必应的服务员。真正要传递出来的状态是：真诚、利他、主动、开放、空杯心态、每天往前拱一点。做到位了，船员会把你当朋友，甚至当参照。

2、信任和威信不是靠讨好换来的，而是靠四件事慢慢立住：把船员的信息摸透、把自己的精力管好、把支持网络搭起来、把船员持续点亮。

3、了解船员这件事，不能等他进组了才开始。招生阶段就可以借面试官多打听；如果是往届学员推荐的，推荐人就是现成的信息源。开船前的那次单聊尤其值得花力气——当对方察觉你提前做过功课，那种信任感的升温会比预期快得多。至少在🛰️里要挨个聊一轮，把他的报名动机和学习目标弄清楚。

名字必须记住。方法不难，三个晚上差不多够：把每个人的头像和名字放在一起，做成一张对照卡，认一遍；等建了群、大家轮流自我介绍，再把头像、名字和他自己贴的标签串起来记一遍。下一回单独聊天，能直接叫出名字、说出职业和当初贴的标签，距离感一下就小了。

4、搭自己的支持网络这件事，遇到卡点，错误地问也比闷着强。领队和赚钱当然可以求助，但最顺手的资源往往是其他志愿者和领队踩过的坑。新志愿者主动一点，找有经验的老人结个帮扶对子。也欢迎加我🛰️：yangchangpku（杨昌拼音+pku），能答的我尽量答。

往届船员是隐藏资源。从你服务过的热心里发展你的“幕僚团”。本届学员同样是你网络的一部分——学期开始前，有几类人值得重点经营：年长阅历深的、群里爱互动的、往届推荐来的、以及赚钱的学霸型学员。这几类人通常乐意帮班级出主意，是能借力的对象。

5、让船员被看见，才是取信的正道，讨好不管用。他得能感觉到：你盼他好、想他成、看得见他的努力。做到这一点，他才愿意跟你的节奏走。

几个常规动作可以做起来：每个船员至少收到一次单独给他的认可——不用端着，挑一个真实的亮点就行。表现突出的，在群里公开提——最省事的做法是从作业里挑亮点，不需要长篇点评，把人名放大、亮点拎出来就够了。在赚钱茶馆发工作笔记时顺手夸；或者每天一封日报，把航行全貌、你的思考摆出来，该夸的别省。特别出彩的船员和动作，积极向赚钱官方推荐，帮他攒宣传素材，让更多人看见。整个航程可以专门建个文档记小组共同做过的事、拿到的成绩，毕业那天当作一封“峰终体验”的信交到船员手上。

6、方法千条万条，最硬的一条其实就一句：真诚本身就是路，没有别的路能通向真诚。对志愿者来说，真诚待船员就是最好使的工具。它不是口号，得落在具体动作上。

一开始就和船员交底。比如写一份“志愿者使用说明书”，讲清楚你能提供什么、你不擅长什么。承认短板不是推责，是告诉对方：我可能做不到事事完美，但我会找官方、找资源，把服务你的这件事兜住。

投诉和不满大概率躲不掉。怎么处理另说，态度先摆正：别绕道、别往后拖、别糊弄事。第一时间告诉对方“收到了，我自己能处理或需要上报，几点前给你明确回复”，并且一定把反馈闭环掉。
