# 新手可复制：抖音资料图引流变现全流程

文/胖猫｜2022-07-29

先交代结果：我从今年2月初正式动手，2月11日拿到第一个付费用户，客单价只有19.9元。钱虽然少，却让我第一次有了继续做下去的动力。到4月30日，这个项目带来的直接收入约2.7万元，同时微信新增3000多人。

这点成绩放在星球大佬面前不值一提，但对一个长期找不到方向、反复试错的人来说，确实是一针强心剂。如果你也正处在迷茫期，又看得上每月多赚几千块的小项目，那这套玩法可以继续往下看。

星球里常见童装轮播、中老年服装轮播，我这次聊的是教育行业的图文轮播。2019年5月加入生财有术后，我才开始接触商业和副业。此前我的规划很简单：在职场里一步步晋升。后来因为对赚钱有渴望，偶然进了星球，才发现原来还有那么多机会。之后我陆续试过淘宝客、抖音小程序、书单号、知乎好物、闲鱼无货源、线下拉新、摆地摊、外卖CPS等，凡是觉得能试的都试了，结果基本都没跑通。快放弃副业念头时，我碰上了现在这个项目，才终于得到一点正反馈。

**1. 这个项目到底是什么**

说白了，就是在抖音发小学资料的轮播图，把家长引导到微信，再让他们付费进入资料群。“双减”之后，平台不允许明着做K12培训，但家长希望孩子成绩更好的需求并没有消失，所以卖学习资料这件事仍然行得通。

**2. 我为什么选它**

第一，我觉得自己做得来。我是硕士毕业，读书时一直算学霸，对找资料、整理资料、回答学习问题并不排斥；再加上做过视频号和抖音，基本剪辑和运营套路也懂一些。

第二，我看到同行确实赚到了钱，这对我刺激很大。

第三，这个项目能积累家长粉，把人沉淀到私域后，未来想象空间不小。

第四，正反馈来得快。只要坚持发视频，就可能看到收益，人更容易坚持下去。

**3. 具体怎么做**

整个项目有两条线：一条做流量，一条维护资料库。

**1）流量获取线**

要做的事包括：设置抖音账号、发图片轮播、引导用户加微信、在微信里私聊成交，再把用户拉进QQ资料群。

先看账号设置。账号主要由名称、头像、背景图、简介和粉丝群组成。

名称可以叫“小学资料分享”“小学资料库”“一年级学习资料分享”“李老师分享小学资料”等，让用户一眼知道你是做什么的。

所以我猜测，平台对我们的小动作其实都能监测到，区别只在于处不处理。简介可以写“每天分享电子资料，需要资料请+V：XXXX”。粉丝群要开一次直播后才能建，它不是为了在抖音里做私域运营，而是为了方便把人导出去。我现在的路径是：先把人引到抖音粉丝群，用户进群后自动@他，并发送欢迎语“更多资料在付费资料群（24.9一学期），进群请加V：XXXXX”，借此引导加微信。

接着是发图片轮播。这一步直接决定视频能拿多少流量，也决定你能赚多少钱。我的播放量基本稳定在2万以上，最高到过120万左右；单条视频最高收益约4000元，那条播放量在70万左右。

什么样的图片容易火？一种靠手感，发得多了，自然能判断家长喜欢什么，知道什么内容会让他们点赞、收藏、私信。另一种是“什么火发什么”：看同行哪条点赞多，下载下来处理一下再发。这个方法不鼓励，而且有风险。更稳妥的处理有两种：一是找到对方视频对应的资料，把电子文档直接生成图片，这样图片就是原创的，可以放心发；二是找不到原资料，就发相似内容。比如别人“看图写话”火了，你就找一份看图写话资料做成图片或视频发出去。还可以看小红书上近期哪些资料点赞、收藏高，下载后做成轮播图发到抖音，大概率也能起量。这有点像电商选品里的“跟品”：不知道什么内容容易火时，跟着热门走最有效。下载无水印视频，可以在微信小程序搜“去水印”，随便找一个能用的就行。

学习资料账号还有周期性。比如期中考试刚结束，你再发期中内容就不容易火；如果赶在期中前一周发练习题、知识总结，就很容易爆。我那条带来4000元收益的视频，就是踩中了期中节点。所以做这个项目，得了解学生的学习进度，内容跟进度对上，才更容易火。

除了踩周期，还有一类资料容易火：让用户看起来“获得感满满”的资料。比如“一年级上册数学必须掌握的50个知识点”和“一年级上册数学第二单元课时练”，前者大概率更受欢迎。

自己制作图片也不难。如果手里有一份PDF资料，觉得质量好、有火的潜质，可以用WPS把PDF生成图片，挑6到9张直接发到抖音。制作轮播图时还有个小技巧：用文字或贴纸遮住一部分资料。一来防止别人直接下载，因为遮住了关键内容，下载了也用不了，只能来找你要；二来能引发用户吐槽，增加评论区热度，更有助于上热门。

视频标签最好固定几个，并且和内容匹配。比如发一年级看图写话，标签可以用“一年级”“一年级语文”“一年级下册”“看图写话”，同时再加“知识分享”“图文来了”，这两个标签流量比较大。发布时间要看粉丝活跃时段，我的粉丝晚上8点到11点最活跃，所以我一般选下午或晚上发。

再讲引导加微信。平台内不能直接说“微信”两个字，要用“违心”“微心”“胃新”等谐音替代。我留微信的地方有三个：背景图、粉丝群欢迎语、合集名称（把合集名改成“需要资料+VX”）。同行还有在简介里留的，内容差不多是“需要电子版资料请+VX：XXXX”。我见过最猛的，直接把微信号留在资料上，居然也能有几千点赞。这几个位置里，我觉得粉丝群最好，安全性高，效率也更高。还有些家长不会看背景图，不知道怎么加粉丝群，不明白“+VX”“+违心”是什么意思，甚至不会添加微信好友，但他们都有一个共同点：想给孩子找学习资料。

最后是微信私聊成交。这部分最耗时间，因为要一对一沟通。我的流程是：对方加我后，先发一份资料，再问“请问需要进付费资料群吗”。如果对方不回复或说不需要，我就不再追。如果对方表现出兴趣，比如回复“要进”“好的”“什么样的群”“多少钱”，我就把群介绍话术发过去，同时发资料群视频。对方继续说“好的”“可以”，我就把付款码和QQ群二维码发给他，付款后通过入群申请。

这里要注意：视频爆了以后加微信的人会很多，回复太频繁可能被限制聊天功能，所以加人特别多时要控制回复频率。另外，最好不要直接用微信红包、转账收钱，量大了对方会收到风险提示，不利于付费。更稳的方式是办一个微信商业收款码，安全、稳定，也可持续。

**4. 资料库怎么维护**

**1）建QQ群**

普通账号最多建500人群，想建1000人、2000人甚至3000人的群，需要开通超级会员，官网能买，淘宝、拼多多也能买，一二百块钱就能搞定。我现在建了一个2000人群，里面有1300多人，这学期大概率不会突破2000人。新手建2000人群就够用了。

**2）获取电子资料**

渠道很多：淘宝、拼多多、小红书、公众号等。最简单高效的是找同行，直接用同行资料。在抖音找一个同行，花几十块钱进他的QQ资料群，把群里的资料全部下载下来。如果对方持续更新，那就他上传一个，你下载一个。

**3）整理资料**

从同行那拿到的资料一般带对方微信号，需要先去掉水印。通常可以用WPS删掉页眉、页脚和水印，再加上自己的信息。我一般加页眉“需要更多资料加微信 XXXXX”，既不影响用户使用，也留下了自己的钩子。稍麻烦的是资料加密、无法编辑，这种情况也有办法：在淘宝、拼多多找人破解密码；或者用WPS把资料转成图片，再把图片生成PDF，最后用“编辑-擦除”去掉水印；还可以搜破译密码的工具，直接暴力破解。破解后文件就能编辑了。懒得找工具的，也可以找我要。

**4）上传资料**

我固定每周六上传，而不是有资料就随时传。这样一方面省自己的时间，另一方面也不会频繁打扰群成员。QQ群文件要分类整理，比如不同版本分开，一课一练和单元测试分清楚，方便用户查找。不知道怎么分，就照抄同行的分类方式。

**5. 一些其他问题**

**1）做这个项目需要什么条件？**

时间相对自由，能及时回复用户，提高转化率；会基本剪辑；会WPS基本操作，比如调整格式、生成图片、图片转PDF；有一定文化水平，能回答家长的学习问题，偶尔还能解答具体题目；有搜集和整理资料的能力。个人觉得大学生、宝妈比较适合。

**2）播放量起不来怎么办？**

第一，坚持持续发。第二，试着发一些话题范围更广的内容。比如账号叫“三年级小学资料分享”，正常只发三年级资料，但三年级受众比较少，可以发一些面向整个小学阶段家长的内容，比如“小学生必须要养成的10个好习惯”，人群基数更大，更容易破量。当然，账号里绝大部分视频还是要围绕定位发。

**3）抖音粉丝群怎么维护？**

除了定期发资料，还要考虑要不要设全员禁言。设禁言的好处是，能避免同行或其他人乱发东西；不设禁言的好处是，大家可以交流，而在交流过程中，会有热心用户告诉其他人怎么加我们的微信。虽然我们设了进群欢迎语，但有些人看不懂，就会在群里问怎么加微信，然后其他用户会回复他。也可以设禁言，再定期在群里发消息，告诉大家加微信的方法。我没有具体测算，但整体感觉是不设禁言时转化效果更好。

**4）这个项目竞争大吗？是红海吗？**

我感觉介于红海和蓝海之间。网上一搜，做的人不少，确实有竞争；但我作为新手，操作几个月也赚到了钱，说明还有得做。而且资料类项目和别的项目不太一样，竞争性没那么强。父母给孩子找学习资料永远不嫌多，用户可能既买了我的资料群，也去买你的资料群，因为他想看看你有哪些不一样的资料，想让孩子多学一点。我的付费用户里，确实有几个买了多个这类资料群。

**5）最后一句**

不会做的时候，就去看同行。同行是最好的老师。
