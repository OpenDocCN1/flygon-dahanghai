# 渠道五：权威数据站点随手查

写方案、做分析、判断市场风向时，宏观统计、行业报告、平台监测这三类信息往往都得备齐。下面把官方统计口径和行业观察入口分成两组，整理成一份即取即用的清单。

1）国家级数据

查宏观经济运行、互联网基础规模等官方数据，可以先从这几个入口看起：

• 国务院宏观经济运行查询页：[`www.gov.cn/shuju/chaxun/index.htm`](http://www.gov.cn/shuju/chaxun/index.htm)
• 国家统计部门官网：[`www.stats.gov.cn/`](http://www.stats.gov.cn/)
• CNNIC（中国互联网络信息中心）：[`www.cnnic.net.cn/`](http://www.cnnic.net.cn/)

2）行业 / 平台级数据
