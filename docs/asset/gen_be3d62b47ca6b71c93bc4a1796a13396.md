# n8n自动化实战：AI生成视频+自动记账，一条流水线全搞定

你有没有想过，把“想一个点子 → 生成一条视频 → 把成品和记录存进表格”这一整套流程，交给机器人自己跑？

最近我搭了一个n8n工作流，灵感从AI Agent里出来，视频由Kie AI负责生成，最后成品自动归档到Google Sheets。整个过程不用人工盯，跑通了还挺爽。下面拆解一下核心思路。

## 流程第一站：AI产出创意

工作流启动后，AI Agent会先输出一组内容，其中包含用于生成视频的提示词（也就是`prompt2`）。这个提示词后续会被直接传给视频生成接口，相当于整个流程的“剧本”。

## 第二站：Kie AI生成视频

拿到提示词后，工作流向Kie AI的`/api/v1/veo/generate`接口发起POST请求，使用`veo3_fast`模型，把`prompt2`作为生成参数。请求时需要带上Kie API Key，同时声明`Content-Type: application/json`。这一步相当于把文字创意变成了视频素材。

## 第三站：等待 + 轮询任务状态

视频生成不是秒回的，所以工作流里安排了一个等待节点，先停顿10秒，接着调用`/api/v1/veo/record-info`接口，把刚才返回的`taskId`作为查询参数，去问Kie：“任务跑完了吗？”

这里有个关键的判断节点：只有当返回结果里的`successFlag`等于1时，才认为视频生成成功；否则继续等下一轮。这种“等待→查询→判断”的循环，是异步任务的标准处理方式。

## 第四站：Fal.ai拿最终成品

当Kie那边的任务标记成功后，工作流会转向Fal.ai，利用FFmpeg相关的接口，向`https://queue.fal.run/fal-ai/ffmpeg-api/requests/{{request_id}}`发送请求，拿回最终视频的下载地址。这一步相当于对原始素材做了后期处理，让视频可以直接交付。

## 第五站：自动归档到Google Sheets

拿到视频链接后，流水线最后一步是把它写进Google Sheets。具体操作是向名为“0817演示”的表格追加一行，写入的Sheet页叫“案例4”。落库的字段很清晰：

- **Date**：当前日期，自动生成
- **Idea**：来自AI Agent输出的创意内容
- **Status**：固定为“done”
- **Video Url**：“请求最终视频”环节返回的视频链接

这里用的是Google Sheets OAuth2账号认证，所以全程不用手动填表，每跑完一条，表格里就多一条记录。

## 小结

这个工作流把“AI创意 → 视频生成 → 状态轮询 → 后期处理 → 数据归档”串成了一条完整的自动化链路。对于频繁需要产出短视频的人，比如做案例库、批量内容运营，或者单纯想解放双手的同学，这套思路都挺值得参考。

核心就一句话：把重复的动作交给编排工具，你只管设置规则和检查结果。
