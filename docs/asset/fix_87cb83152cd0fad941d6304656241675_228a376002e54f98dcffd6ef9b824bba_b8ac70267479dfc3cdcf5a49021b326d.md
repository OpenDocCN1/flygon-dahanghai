# 抖音本地生活，机会与坑都在哪？

36氪今年7月的一篇报道透露，抖音本地生活给自己定了个挺激进的目标：直播成交占比要冲到一半。可直播天然是冲动型消费，用户很少因为“刚需+高频”才下单，核销率大概率好看不了。这个坎，所有想进场的人都得先想明白。

眼下抖音直营中心已铺到50多个城市，入驻商家70万+，服务商（官方认证的没算）4万多家，达人320万。整个生态的玩法不算复杂，主要是达人牵线、服务商和商家对接，佣金普遍落在10%-15%区间。

2022年6月，字节在巨量网挂出《2022年生活服务软件服务费标准说明》：商家只要在抖音发布商品或服务信息——像商品名、价格、门店地址这些——并且和用户产生了交易，就得向平台交软件服务费。计费基数是“消费者实付金额+商家自掏腰包之外的其他补贴”，再按品类对应费率算。平台划了8个类目，费率2%-8%不等。照这个节奏，6月抽佣已过千万，7月大概率冲上5000万量级。

（**2**）抖音对美团：兴趣推荐VS主动搜索，谁更胜一筹？

理想化地看，美团是10年代的产物，本地生活走的是“需求→搜索→图文→比价、烧流量内卷”这条线。抖音则是20年代的产物，兴趣电商算法把“推荐”做成唯一入口，用短视频直击用户心智，传播速度和覆盖面都远超美团。这也是很多人看好抖音本地生活的原因。

2021年3月抖音本地生活闭环至今，快一年半了，发展不算慢。但眼下的生态，平台并没给从业者多好的土壤。商家这边，竞争主要靠破价引流，还得应付同品类“猜你喜欢”来抢客，对商家并不友好；服务商那边，商家佣金压得低，交付很难让人满意；流量主在商家眼里甚至成了“要饭的”，职业素养也常被吐槽。这些问题得抖音自己引导解决，靠几家服务商撑不起来。

再拆解一下美团系和抖音的异同，看清两个平台到底差在哪。

相同点很直白：都是撮合与推荐服务，都得付费换效果。

不同点分几个维度看。宏观上，抖音和美团存在代际差——短视频与图文带来的感官冲击不同，传播深度、速度差距明显，流量密度也不在一个量级。供需关系上，美团是C端先有需求再主动搜索，抖音是用兴趣逻辑激发C端消费。内容层面，美团追求“网罗所有商家”，突出评价和排名，各城市站点大同小异；抖音把站点入口、排名入口藏得很深，核心只推有传播属性的商家。

所以现阶段说两个平台正式抗衡还为时过早，抖音还需要时间成长，去赢得消费者、服务商、流量主和商家的认可。

（**3**）抖音和美团的差距有多大

2021年抖音本地生活GMV接近200亿，按平均抽佣3%估算，2022年抽佣预计15亿左右。美团到店和酒旅2021年营收325亿（经营利润141亿），GTV 7021亿，总营收1791亿。

两组数字一摆，差距一目了然。抖音还得花时间去理解本地生活、理解行业需求，想清楚怎么真正赋能赛道、推动它往前走。否则很可能泯然众人，几年后新平台冒出来，把这一切又夺走。

**2.**服务商的生存现状

（**1**）大环境

先说环境。第一，平台政策变太快。2021年直营中心下场，小程序几乎瓦解。小程序其实月月都在变，只是最后突然剧变，很多人一下接受不了。2022年群峰还没玩明白，6月抖音来客就来了；后面还有外卖平台，可能还有新后台。到2022年7月小程序又能运营了。一切都在动，充满不确定性。

第二，核销率像根刺扎在所有人心里。产出比不再稳，随时可能腰斩，让看着不错的生意变成不赚钱。比如ROI做到6，核销率只有四成，投入产出就是2.4，扣完成本基本白干，甚至亏。

第三，服务商目前至少4万家，达人超300万，质量鱼龙混杂，得靠市场竞争慢慢沉淀出好生态。

（**2**）服务商一定是平台刚需

有个共识得先立住：只要你想在抖音做本地生活、想成为服务商，你就能入局。因为这是刚需——官方用很多动作证明自己干不完，必须靠服务商，这就是你的价值。至于你怎么赚钱，平台管不着。

为什么抖音一定需要本地生活服务商？因为抖音是内容平台，口号是“创造美好生活”。但本地生活的土壤完全不同，活儿又脏又累：你得跟认知不高的商家反复周旋，内容要接地气，上门拍摄得使出浑身解数吃喝玩乐、卖力表演。这种事字节没法尽心尽力去做，事实上它也试过但干不好。比如2021年11月开始的本地生活直营，拿出10%佣金，结果探店内容品质低下，本地生活流量全线吃紧。再比如2022年3月官方成立服务商管理部，这就是明摆着告诉所有人：我需要服务商。

（**3**）官方服务商

现在官方正规军主要有两类：本地生活SaaS服务商、抖音来客服务商。这两类都能申请，想抱官方大腿的去百度或字节官网查准入要求就行。流程大致是：报名→跟官方同学对接→拿出计划和资源展示→交10万保证金→按双方定的KPI往前走。

我们团队两种身份都经历过，现在走“去字节化”路线，为了摆脱官方约束把服务商退了。这得看你们团队的生意模式再决定和官方怎么合作，细节可以私聊。

但你要清楚服务商的价值，摆正位置，也别妄自菲薄：第一，本地生活短视频化板上钉钉，行业需要人去把服务补全；第二，市场有20多万亿，美团也只吃到8%，需要庞大服务商群体去瓜分；第三，本地生活需要更多服务商倒逼商家进化、更新换代，制约资本制造的餐饮垃圾，真正推动消费升级。

（**4**）短视频和直播

我个人觉得，做服务商得先把短视频想明白，再考虑直播。按我们的经验，ROI做到10、核销率70%的投放，也没想象中好做，大家一定掂量清楚。

（**5**）入局建议

第一，千万别铺BD。能合作的渠道很多，行业协会、本地朋友圈意见领袖、商会，每个人都有资源，都是你的业务员。

第二，选品比什么都重要，选对了自然有流量，比如小龙虾、冰面包这类爆品。

第三，矩阵一定要做，别不重视，这是真正能拉高产出的工具。

第四，学会拆解流量底层逻辑，优化运营方式和技巧。

第五，销售渠道要多元，学会做全案，赚团购之外的钱。不会做全案，就去淘宝买别人做过的案例，研究透了再改、再抄。

第六，抱紧官方大腿，要方法论、资源和案例。但别当应声虫，什么都听它的，否则团队会很难受。

未来怎么走？参考电商行业就知道：短视频、直播、策划服务、品牌陪跑、达人派遣、战略咨询、投资管理，未来5年一定非常精彩。

**3. **达人的生存现状

（**1**）大环境

第一，达人市场严重泛滥。粉丝量过千就敢做探店达人，商家对达人印象越来越差，动不动骂“要饭的”“乞丐”。

第二，达人撮合链条变短。拉个群就能把本地大部分达人聚起来，价格、资源全透明，生意反而没法做了。

第三，好内容不等于有大流量。很多达人渐渐不想用心做探店视频。当然，能稳定产出的账号依然吃香，但只要翻一次车，本地圈子就会传“效果一般”，以后收费就难了。

第四，本地生活流量忠诚度不高，KOL做不到一呼百应。本地人对吃喝玩乐都有自己的判断，博主发个视频，很难让所有人都跟着下单。

（**2**）收益情况

第一，佣金普遍6%-12%，算上核销率影响，实际到手至少打对折。

第二，以长沙为例，本地V6级别达人基础收费约1500-2500元/次，前置收费还在往下走。百万粉丝账号需求也不旺盛，处境挺尴尬。

（**3**）入局建议

策划能力很关键。流量主要多学前人经验，比如地产、餐饮的营销案例，把转化核心放在抖音，有机会形成裂变传播。一旦做成了，就是你的案例、你的成名之战。现在市场上能策划出营销事件的内容型流量主非常稀缺，只要你做到了，收费拉高是必然——品牌方愿意为创意买单。

别为了探店而探店。文案全是模板，表演没功底，表情僵硬，跟商家、服务商沟通又差，这些都会让口碑下滑。现在竞争这么激烈，风评一差，商单就少。建立专业度和职业素养很重要，这也是能力的证明。

**4. **品牌方的现状

（**1**）困境

第一，品牌方自己组织达人探店，效果往往比直播好，因为交付握在自己手里，可以提要求。

第二，现阶段大部分品牌最缺的是到店客流，但又不知道怎么挖掘核心爆品、怎么实现增长。

第三，基本都没有私域运营能力，可私域流量的获取门槛其实很低。

第四，抖音引流到店的比例约15%-25%，怎么延续流量价值让很多品牌方头疼。不过，只要抓到抖音这波机会、又没上头去冲GMV的品牌方，应该都有盈利。

（**2**）入局建议

第一，抖音外卖可以试试，多渠道触达用户。经营好了就是自己的私域流量。疫情一来，自己的流量储备就是最大底牌，至少保证不亏太多。

第二，学会做店内爆品。不会就找你品类的头部，跟着学、跟着抄也行。好产品自带流量，能让生意事半功倍。

第三，创始人IP至关重要，有能力和时间一定要做。它能带来加盟、门店引流、吸引投资、技能培训等一堆好处。

第四，可以去“白嫖”服务商，谈纯佣合作。当然，我也劝服务商别接纯佣，这就是商业博弈，看双方怎么把合作落地。

第五，电商品牌的本地化大有可为。你们要好好想想怎么构建新场景，一旦落地，结果会很不错。

**2. **如何将**POI**加热

前面说过，抖音榜单现阶段主要看用户推荐度和评价，其次是GMV、收藏等。抖音本地生活里有个不成文的规矩：某个地址成了热门地址，你随便发个视频，流量都比其他POI高，这是大家都心知肚明的。

所以要把地址做成热门地址，说白了就是视频量要够大——靠素人视频矩阵。一般建议铺100-200条视频，地址的基础热度就能起来，好评率保持在90%以上。“空卡打酒站”就是按这个思路调整后热度飙升的，这就是POI加热的意义。

推广前后的对比非常明显，后期再上达人，效果会更好。这里提醒一句：POI没加热之前不要贸然上达人，效果会很差，这是我们跑过成千上万次的经验。曝光基数上去了，销售额跟着涨，热度就会像滚雪球一样。

这个阶段非常考验运营能力：第一，确认要推广的POI地址没问题；第二，确认团购套餐没问题，套餐标题要一目了然，让人一看就想点进去；第三，组织素人发视频；第四，监督数据发布情况，及时联系出错的素人，如果某条素人视频爆了，可以适当加投放。

说到素人，肯定有人问素人从哪来。这就涉及招募：我们这边一条视频发布给5-10元，没有分佣设计。每个公司的运营基础不一样，和素人的合作模式也可以不同。前面提到我们用过爆店码做分发，现在已经换成账号托管+自动发布，全流程模拟人工在电脑端发布。为什么这么做？原理不细说了，主要是为了素人管理和发布及时性，流量也比爆店码分发更稳定。

这里还能做一个提升爆单几率的小操作：素人推广期间，组织一批人购买团购套餐，大概20-30单。一是做出基础销量，二是让系统知道产品在跑、有转化。这是我们运营中比较细的一环，原理跟电商补单有点像。后期如果推广增量有限，也可以在私域里导流一波，重新激发流量。
