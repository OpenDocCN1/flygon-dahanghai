#### 1.3.1 从零跑通一单的最短路径

新手在平台开店，别急着把摊子铺大。先把一条能成交的链路走通：注册并开出店面→找货→把货挂上去→发内容→有订单再联系供货方→日常打理。真正吃功夫的环节只有两个：找货和发内容。

1. 注册与开店

刚上手，建议备两套号与店；已经熟门熟路的，可以拿七个号轮着转。

2. 找货

首单能不能来，多半看这一步。刚起步可从价格不高、需求旺的品类切进去。本次会拆一些过去卖得好的品；如果必修篇里的方法已经吃透，还想多开渠道，可以看七、【选品拓展】。

3. 发内容

选题别凭空想，盯住商城里垂直类目最近卖得动的商品，把它们的爆款内容拆开、学着做，起量会更顺。制作上，平台对搬运混剪的识别越来越严；新手早期可以用混剪练手，想走得久，尽量自己拍。

4. 对接供货方

刚开始订单少，先和商家说好，手工打单时别让面单露出别的平台信息；订单多起来，再接入商家的ERP。

#### 1.3.2 平台内容分发逻辑 @曜文

1.3.2.1 审核分两层：机器先筛，人工再看

内容发出后，先进入平台的“黑盒”初筛。系统按规则（官方账号“薯管家”里能查）检查敏感词、违规词、低质图片等。一旦命中，直接判失败，没有曝光；机器拿不准的，会标成疑似违规，再交人工复核。没过关的内容会被压住，表现就是流量受限：别人进你主页看不到；你可以把它转到微信等外部渠道，试试能否打开。初筛通常几分钟到十几分钟；若赶上发布高峰变慢，多半是进了人工环节。

1.3.2.2 推送先拆内容，再一层层放量

通过审核后，平台会用语义识别与拆分算法处理内容：拆开、归类、打兴趣标签、提取收录词，再分发到粉丝首页和更多用户首页。系统先给约一百名精准用户看；这轮反馈好，才会扩到更大的人群。记一个计分式：CSS＝点赞×1＋收藏×1＋评论×4＋关注×8。它看的是互动与转化，结果会持续影响首页推荐次数。所以前一百名精准用户的点击和互动很要紧；发出后18—24小时内的反馈，也会决定能不能继续吸流量。

1.3.2.3 权重看三块

第一，原创度。低于60%会掉权重，还可能被限流。第二，转化率。也就是曝光与互动之间的关系。转发、评论、收藏、点赞的权重大小依次是转发＞评论＞收藏＞点赞。第三，内容本身。关键词标签和整篇内容的关联要够紧；关联太弱，容易被判成恶意引流，权重随之下降。

1.3.2.4 先被收录，才谈搜索排位

搜索某个词后，结果页里的内容顺序就是排名；越靠前，被点开的概率越高。先理解“收录”：搜索引擎抓取内容并存入数据库。一般来说，审核通过就会收录，但以下情况会卡住：账号多次违规被限制，内容难收录；重复率高或非原创，平台不支持；广告和营销话术太多，会被当成推广内容；修改太频繁，每次都要重审，反而容易失去收录。

## 二、【实操1/4】起步先备店、找货、上架

### 章节概要

项目全貌看清后，就该动手了。平台电商的前置条件是店铺准备与选品。这一章把启动期要办的事收在一起：备好手机号和手机；开出适合自己情况的店；把百货赛道的账号包装好；做第一次选品，并知道怎么测；再把选中的货挂上去。

各店铺类型的入驻门槛不一样，先结合自身条件看明白，再走进驻流程。选品是本章要重点练的。百货赛道里，新手比较顺手的组合是“抖音创意中心选品法＋站内低粉爆款选品法（手动刷＋灰豚数据配合）”。最后还会拆几个过去的百货爆品，帮大家找找选货的手感。做生意不能只低头赶路，多观察市场，成功率才会更高。

本章航线图

学完并做完，就能完成航线图第一阶段：定赛道、选品、备好开店（约2天）

1. 至少开出2家店（约2小时）
2. 了解百货品类特点，先拟10个品（约3小时）
3. 学会选品方法，定1个主推、3个备用（约4小时）

4. 至少完成1个商品的上架与发布（约30分钟）

### 2.1 账号先备齐

#### 2.1.1 起步至少两套账号

新手通常从个人店开始；两家个人店就要两套账号。要备：至少两部手机（不建议一部手机多开，可能被限流）；至少两张电话卡（两个号要两个实名，对应两张卡）；至少两张身份证（家里人的也能用）。

电话卡：三大运营商都能办副卡，一个人可注册认证5个号码，一拖四，副卡月租10元。

手机：既用来登录，也用来拍视频。只做短视频，千元安卓机足够，而且安卓支持系统双开；以后想放大做直播，iPhone稳定性更好，但它不能双开。

[PRE4]

#### 2.1.2 登录、实名和养号 @渡

2.1.2.1 一部手机能登两个号吗

可以，但有风险。若手机自带应用分身（部分安卓机型，比如红米），一部手机登两个号可行，我目前就这么操作，账号还没出问题。

如果手机没有分身功能，别去装分身神器，容易封号。这种情况下只能再拿一部手机专门登录，去闲鱼或拼多多买三四百元的二手设备，日常够用。

2.1.2.2 实名认证

这里要记牢：一张身份证只能认证一个账号，认证后只有注销才能解绑。操作路径：我→左上角三条杠→创作中心→创作服务里的更多服务→开通专业号→成为专业号→选择个人→立即申请→填写实名信息。

#### 2.1.3 把店开起来

2.1.3.1 店铺分哪几类

入驻前先弄明白种类，因为权益不同。大方向有两类：个人店铺和企业店铺。不管开哪一种，第一步都要先认证专业身份；新号默认不是专业号，而非专业号不能做商业动作，薯条投放、开店都不行。想变现，先升级。

专业身份也分个人和企业两种。

个人专业身份，标识是“XX博主”，比如时尚博主、美食博主这类兴趣博主，基本申请就能过，不收费用。流程：点【创作中心】→【更多服务】→【开通专业号】→【我是个人】→【实名认证】→选身份证，填信息。

[PRE13]

医生、律师等特殊职业，要传资质，并交300元。

[PRE14]

有了个人专业身份，可以开个人店或个体工商户店。店名：XXX（昵称）的店；保证金最低1000元；平台技术服务费按每单对应类目费率扣。费率看《2024小红书基础技术服务费费率标准》；算法看修订后的《小红书技术服务费规则》公告第四条。

企业专业身份要传营业执照，并交600元，标识为“XX品牌”。流程：点【创作中心】→【更多服务】→【开通专业号】→【我是企业】→【填写基础信息】→【填写主体信息】→【资质公函上传】→【运营人信息填写】→交600元，等审核。填写要点见下图：

申请后要留意：有效期30天，30天内没走完，费用不退；通过后每年年审，续费600元。

企业专业身份能开普通企业店和专卖店/旗舰店。名称是XXX专卖店/旗舰店；保证金境内最低2万、境外3500美金；技术服务费按每单类目费率扣。费率看《2024小红书基础技术服务费费率标准》；算法看修订后的《小红书技术服务费规则》公告第四条。

同一品牌只能开一家旗舰店，但可以同时开不同类型，比如旗舰店+专卖店，或旗舰店+普通企业店。企业专业身份的营销权益比个人更多，但两者只能二选一，按需来。一般来说，新手开【个人店】就行，门槛低；企业店更多是放大做矩阵时用，平台对账号的宽容度也更高。

2.1.3.2 【个人店】门槛与开通步骤

个人型店铺又分【个人店】和【个体工商户店】。个人店只支持服装、百货等常见类目；个体工商户店除常见类目外，还支持奢侈品、珠宝等。

[PRE17]

不同店铺类型能经营的类目不同，打勾的部分就是可经营类目，具体到学习中心→规则中心→经营总览里查：

[PRE18]

开店要交保证金，个人店和个体工商户都是1000元；保健品、奢侈品等特殊类目会贵一些。

[PRE19]

客服接待上，个人店铺可以选平台代运营或自主客服；平台代运营收费，按自身情况选。

平台佣金又叫平台技术服务费：每出一单按对应类目费率扣。费率看《2024小红书基础技术服务费费率标准》；算法看修订后的《小红书技术服务费规则》公告第四条。

目前平台为减轻个人店和个体工商户负担，入驻后不用先交保证金，就能发布商品上架售卖；等累计交易额超过1万元，7天内补缴保证金，真正实现“无门槛”开店。

选个人店铺后，先选经营类目，再提供姓名、身份证号、手机号，过人脸识别，验证成功就开通。

[PRE20]

个体工商户店铺要提前备好：（1）公司信息的营业执照照片、公司名称、统一社会信用代码、经营地址、营业执照有效期；（2）店铺运营授权书。同样先选经营类目，再按提示上传资料。

[PRE21]

和个人店不同，个体工商户店审核一般要两到三天。审核期间可以登录入驻系统查进度；入驻中遇到解决不了的问题，9点到24点直接找人工客服。

[PRE22]

2.1.3.3 【企业店】门槛与开通步骤

企业型店铺分普通企业店、旗舰店、专卖店和集合店。普通企业店的命名格式和个人店一样，“专业号账号名称+的店”。企业专业身份取名要和商标对应，不然开不了店。旗舰店叫XXX（品牌名）旗舰店，专卖店叫XXX专卖店，集合店叫XXX的海外店。企业型店铺能经营大部分类目，包括保健品、医药等特殊类目。平台佣金和个人店一样，1万元以下不收，超出部分按5%收。保证金按类目不同略有差异，一般境内最低2万、境外3500美金。不知道怎么选，可以看下图快速判断：

【普通企业店的开通流程】

登录后大概六步。第一步，店铺类型选普通企业店。

[PRE24]

第二步，填公司信息，上传营业执照；执照要拍得清晰、完整，避免扫描出错。

[PRE25]

然后填法人或店铺运营人信息；联系人要和营业执照上的法人一致。

第三步，填店铺名称，系统会自动抓取。命名形式是“昵称+的店”，和昵称直接挂钩；要改的话，去专业号中心改昵称。

第四步，选经营类目；类目必须在商标注册证范围内。

[PRE28]

第五步，等审核。一般3个工作日内；失败会电话或邮件通知，期间有问题可联系在线客服。审核通过后，最后一步交店铺保证金；开卡账户是对公账户，开户人要和入驻时填的经营人姓名一致。

【旗舰店/专卖店开通流程】

大体和普通企业店差不多，有四点要特别注意：

1. 填品牌信息。系统里没有品牌名，就点“新增品牌”添加；上传logo要和商标注册证完全一致。

[PRE30]
[PRE31]

2. 分清自有品牌和代理品牌。代理品牌要确保授权链路完整，公司名称选营业执照上的名称即可。

[PRE32]

自有品牌是指商标持有者为自己公司或公司法人；注册类型分R标和TM标。R标是注册商标，TM标是商标注册申请受理通知书。

如果商标注册类型是个人型R标，要上传商标注册证，以及商标权利人的身份证或护照复印件/扫描件。

[PRE34]

同样，个人型TM标要上传商标注册申请受理通知书，以及权利人的身份证或护照复印件/扫描件。

[PRE35]

如果申请的是企业型R标或TM标，只需商标注册证或商标受理通知书。

3. 选售卖品类时，谨慎选“定制”类目。

[PRE36]

4. 审核通过后还要签合同。合同以线上邮件形式，通过电话或验证码确认签署。
