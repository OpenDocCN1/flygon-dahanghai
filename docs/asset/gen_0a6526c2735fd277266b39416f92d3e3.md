找对标的办法：先关注这类频道并点赞，再回主页刷新，平台就会推送近期同类视频；也可以顺着视频标题里的标签去找。

# 4.1.5.2 第二步：分镜结构拆解

先拆分镜结构。以对标一为参考，动物示警视频可以拆成 5—6 个分镜组合：动物拦车 + 动物与车互动（中景，车外角度）+ 动物与车互动（近景特写，车内向车外拍）+ 灾难镜头（主体车辆和动物二选一）+ 动物近景特写（可选）+ 温馨时刻。按这个结构剪，视频时长基本落在 22—26 秒。

建议不要一模一样复刻对标视频的所有分镜。可以在动物与车互动部分调整提示词里的镜头角度或互动位置来做区分，避免同质化导致卡万播。

# 4.1.5.3 第三步：AI 工具怎么选

老话说，工欲善其事，必先利其器。做视频也离不开顺手的工具，下面说说我实际使用这些工具的体验。

# 4.1.5.3.1 提示词环节

提示词优化工具：GPT4、deepseek。

写提示词的思路：先对对标视频做分镜头分析和拆解，再按自己的创作思路整理出分镜图，然后把分镜图上传给 GPT，让它推导提示词。这里不用 mj、sd 等反推，一是自己还不熟，二是它们推导出来的提示词错乱比较多。GPT 能识别图片，推导准确率相对高一些。不用 deepseek 的原因，是它只能识别图片中的文字，没法对图片整体做识别推理。

用 GPT 主要是想确定这类图片提示词的结构，因为提示词前后顺序会影响权重。可以让 GPT 以中英文对照的形式输出，方便后续修改和优化。

比如我想做狗趴在窗外的分镜图，自己怎么写都出不来，最后把想法和对标图发给 GPT，得到了想要的效果。

# 4.1.5.3.2 文生图工具挑选

文生图：mjdjourney、stable diffusion。

这两个工具大家应该比我这个新手用得好，使用方法就不说了，暂且说说图片色彩度和真实性方面的心得。按我的体验，sd 的出图效果优于 mj。这里分享我用到的模型和一些使用心得。

stable diffusion：

电脑配置不够的话，可以用云电脑、在线端替代。这里以 libulibu 在线端为例，地址：https://www.liblib.art/sd

大模型：绘梦写实摄影大模型、F.1 基础模型、星流 star-alpha 大模型（可在模型广场直接搜索收藏使用）。

lora 模型：纪实摄影 F.1、蔚蓝 blue 高清动物摄影大模型（可在模型广场直接搜索收藏使用）。

mjdjourney：

mj 模型选 v6.1，但有时生成的图片会过于清晰、色彩过于饱和，甚至给人一种黑黑的感觉。如果出不来想要的色彩度，可以先用 sd 生成一张图，再用垫图的方式让 mj 参考 sd 生成图片的风格，也就是 --sref+图片链接，这样出来的图片感觉会好很多。

不管是 sd 还是 mj，文生图都优先看色彩度和真实性，其次再考虑图片中的部分变形或主体站位等因素。
