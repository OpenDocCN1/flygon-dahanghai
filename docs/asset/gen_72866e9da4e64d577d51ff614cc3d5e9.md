# 4.1.4 进阶玩法：敢选新剧，抢先试水 @惟乔

这套打法门槛更高，刚入门的朋友先别急着照搬；它更适合已经有一定内容判断力、能自己拿主意的玩家。

新剧往往缺少可对照的成片，剪辑逻辑得自己搭。具体怎样把素材拼成更顺的剧情，第五部分“下载素材并组合剧情”会展开讲。

新剧的品质并不稳定，真正的价值在于提前占位。麻雀 Matrix 和创作猫都能通过筛选功能找到新剧。

如果把短剧 CPS 看作短视频里的蓝海，那么新剧就是短剧 CPS 里更靠前的蓝海入口。

挑新剧还要看账号定位。眼下短剧的垂直分类还没那么细，基本就是男频、女频两条线。

要是某部男频剧跑出了数据，先看看粉丝男女比例，确认观众是否真的以男性为主；如果是，之后就把剪辑重心放在男频剧上，新剧也优先选男频。

女频主流是虐剧：先虐，再反转，冲突多围绕女主与男人、女主与“小三”、女主与家人展开，结局大多是 HE（happy end）。

男频则主打爽感：复仇、扮猪吃虎、穿越、艳遇，都是常见套路。
