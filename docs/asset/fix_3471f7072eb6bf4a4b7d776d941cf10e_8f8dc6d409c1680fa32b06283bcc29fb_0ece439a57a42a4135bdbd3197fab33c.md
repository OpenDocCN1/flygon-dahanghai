2.1.2 主题：切口先收窄，跑通再复制

新手最常踩的坑，是一上来就给自己圈一块大地盘——个人成长、学习方法、赚钱……这些词听着有气势，实际宽得让人无从下手。

稳妥的路子分两段走。

**起步：只开一个小口子，先让整条链路转起来。** 比如把“个人成长”压缩成“思维模型”，把“赚钱”压缩成“小红书虚拟电商”。口子一小，取舍标准立刻清晰：哪些该留、哪些该扔，心里有数，出成果也快。搭建、筛选、整理、调用这一串动作，先在一个小主题上完整跑一遍，你才摸得清自己适合建什么样的库。

**扩展：首个小主题跑顺了，再顺着大方向逐个加第二、第三个窄模块，最终拼成一座垂直大库。** 拿我的“一人变现系统”打比方，它服务的是“怎么用 AI 做一人公司”这条主线，但内里由若干小模块拼装：10-思维模型库供写作引用和决策参考，01-搞钱案例库收真实副业与创业案例，02-内容运营技能覆盖小红书、公众号的打法，04-电商与变现管虚拟产品选品、引流、转化……[PRE0]

每个模块主题都很窄，各自按“需求判断 → 信息搜集 → 内容整理”这套流程搭建。几个模块并起来，才形成一座完整的垂直知识库。

2.1.3 边界：两道关卡，先主题后质量

主题落定，还得划一条红线。红线有两道：第一道管主题，第二道管质量。

**第一道，主题关。** 先问这条内容聊的，是不是我这座库要装的东西。

**第二道，质量关。** 主题对口还不够，内容得满足“原理 + 案例 + 应用”三样里占住至少两样。不少文章标题看着对口，点进去只有结论、没有推演，这种不收；同一个话题若已有多篇，只挑质量最硬、洞察最深的那篇入库。

以“思维模型”为例。能进库的：李善友《第一性原理》把原理讲透，又落到创业场景，够深；B 站那条“决定火箭尺寸的，竟然是两千年前的马屁股？”用经典案例把概念掰开揉碎，也值得留。不能进库的：《10 个思维模型改变你的人生》光报菜名不解释，读完跟没读一样；《我学了思维模型，人生就此开挂了》通篇感慨，既无方法也无案例。[PRE1]

回头看，这类内容我基本不会点收藏——对“第一性原理”的拆解大多停在表面，鸡汤味重。真正收进来的是李善友教授那本书，配 B 站 UP 主的案例，一块儿讲清“第一性原理是什么、日子怎么用”。我的红线很明确：要深度学习、要能落地，就选最权威的；越线的，再热闹也不收。红线画得越利落，库里的信噪比越高。换成小红书选品也同理：第一道换成选品领域，第二道的“原理+案例+应用”照旧。《从小红书月入 10 万的 3 个秘诀》跟选品相关度为零，纯属关键词碰瓷，一样拒收。

2.2 信息搜集：主动出击，集中归仓

需求明确了，接下来是找料。不少人卡在这一环——搜不到好货，于是刷到什么存什么，质量参差不齐。

更靠谱的路子是：让 AI 帮忙倒推搜索词 → 自己到各平台主动搜 → 全部归到一处。

**第一步：请 AI 开一份关键词清单**

需求说得越细越好：要解决什么、想挖多深、将来用在哪儿。

我做“怎么用 AI 做一人公司”那会儿，是这么问的：[PRE2]

有两个要害。

其一，需求必须具体。哪个主题、什么角度、落在哪，都得交代清楚。

其二，关键词尽量用英文。YouTube 上一手好料大多是英文，中文圈的内容往往已经被转译过一手，成色打了折扣。

AI 吐回来的关键词通常分几层，大致是这样：[PRE3]

拿到清单，再按平台分工去捞。

**第二步：平台各有分工**

各平台调性差别不小，挑两三个顺手的就足够：

- 公众号：长文深度、中文原创观点、行业老炮儿扎堆，适合找方法论、行业分析和复盘。
- 小红书：实操笔记、真人经验、图文干货，适合挖执行细节和同路人心得。
- 即刻：创业者的即时动态、碎片想法、行业风向。
- 知乎：系统性问题的完整答案。
- B站 / 小宇宙：大佬访谈、系统课程、深度讲解。
- YouTube：海外方法论、工具教程、创作者访谈。
- X（Twitter）：个体创业者（solopreneur）的实时心得、英文短观点。

我个人的偏好是 B站、YouTube、X 优先，公众号兜底，具体看内容方向定。

**第三步：一条内容值不值得留**

刷到任何东西，拿三个问题过筛：

（1）跟我的主题直接相关吗？主题是思维模型，一篇讲“第一性原理日常怎么用”的，对口；一篇只会喊“思维模型让我人生开挂”的，没干货，翻翻就过。

（2）有没有我没见过的新观点、新案例、新方法？B 站那条马屁股视频，给的就是我没见过又特别有用的案例。反过来，把二八定律又复述一遍的，没新意，跳过。[PRE4]

（3）我能不能预判它日后用在什么地方？看着爽、将来却用不上的，别留。比如眼下刷到一篇讲投资的好文，但你既不投资、近几年也没这打算，那就不必收。

三问里至少中两问，再动手保存。这套标准刚上手会觉得苛刻，咬牙执行一个月你会发现：库里东西不算多，但每一条在哪儿、能干嘛，你都门儿清——这才叫真有用。

**第四步：集中存放**

定下来要留的，统统归到同一处。我用的是飞书知识库。

内容类型不同，存法也不一样：

**网页文章 / 飞书文档：** 多数直接复制进飞书即可。原文若本身就在飞书，保存副本更省事。[PRE5] 推特文章或其他公开网页，可借 Obsidian Web Clipper 采集：https://obsidian.md/zh/clipper 。即便不玩 Obsidian，也能拿它把内容抓进剪贴板，再粘到飞书，或存成文件后导入。[PRE6] 复制完，新建空白文档一粘就好。[PRE7]

**公众号文章：** 路子一，全选复制粘贴；路子二，装个飞书剪存，浏览器里打开文章，点剪刀图标一键收录。[PRE8][PRE9][PRE10]

**视频 / 播客 / 直播：** Get 笔记丢进链接，自动出逐字稿，再复制进飞书。[PRE11][PRE12][PRE13][PRE14]

**图片 / 截图：** 花瓣网插件能批量抓取页面图片：https://huaban.com/ 。装好后把鼠标悬在图上，左上角冒出“采集”，点一下即收进花瓣网。[PRE15][PRE16][PRE17] 不过图片落在花瓣网，还得手动搬到飞书。

最终所有东西汇集到同一座飞书知识库，按主题分文件夹。怎么整理、怎么调用，后文再讲。

保存时既可手动复制粘贴，也能把 pdf、md、word 文件上传，飞书会自动转成在线文档。[PRE18] 前期搭建本身就是一道筛选工序，量不会太大，一条条手动存问题不大。若要采集某位博主的全部内容，就得动用批量工具，那属于进阶玩法；各平台工具也不一样，比如 YouTube 博主，可以把链接一股脑塞进 NotebookLM；推特这类渠道，有本事的话用 Claude Code 写个小插件。

2.3 内容整理与分类

素材收完，飞书知识库里已经躺着一堆东西。但若只是把原始内容生堆进去，日后照样得逐条点开看，等于没整理。

这一步的关键在于：让每一条内容都能被 AI 顺利调用。文章类直接存；视频、课程、播客类先交给 AI 做成精读笔记再入库。

**第一步：按主题搭骨架**

打开飞书知识库，按主题建文件夹。我的结构长这样：01-搞钱案例库、02-内容运营技能、03-商业模式拆解、04-电商与变现、05-AI 与效率工具、09-好书长文精读、10-思维模型库、11-播客与 TED、12-生活方式。开头建三到五个足矣，后面慢慢补。文件夹名要一眼看明白装了什么，尽量别设“其他”这种万能筐。

**第二步：分类型处理**

1、文章类（公众号、帖子、网页文章）：直接归入对应文件夹。文章本来就是结构化文字，AI 读得懂，无需二次加工。[PRE19]

2、视频、课程、播客等逐字稿：这类文本冗长散乱、口语痕迹重，直接丢给 AI 很难提炼。得先在 DeepSeek 或豆包里过一遍，整理成精读笔记再存。[PRE20][PRE21]

几个小窍门：逐字稿破万字就分段喂给 AI，最后拼合；AI 给的版本不必字字完美，能用即可；某些文章又长又好，也可以让 AI 顺手做份精读笔记，与原文并存。

**第三步：用飞书知识问答做检索**

飞书自带的“知识问答”，能直接基于你的库做 AI 问答。提问时带上具体任务，别抛空泛问题。

比方说，别张口就问“有什么赚钱方法”——太宽，AI 摸不准你要啥。换成：“我想在小红书卖虚拟产品，库里有讲选品的吗？有具体案例可参考吗？”背景交代越具体，回答越对路。[PRE22]

3. AI 知识库工具推荐

上面整套流程，主力工具都是飞书系，且全部免费。

| 工具 | 核心优势 | 使用门槛 |
| --- | --- | --- |
| 飞书知识库 | 统一收口所有内容，主题分文件夹，结构清晰，个人团队通用 | 上手低，新手友好 |
| 飞书知识问答 | 基于库内内容做 AI 问答，还能搭对外分享的问答空间 | 需先有内容垫底 |
| DeepSeek / 豆包 | 整理逐字稿、提炼精读笔记，处理几百条也就几块钱 | 上手低，注册即用 |
| Get 笔记 | 抽取直播、课程、视频的逐字稿，转文字后便于 AI 整理 | 上手低，适合内容整理场景 |

推荐组合：飞书知识库（收集沉淀）+ DeepSeek / 豆包（精读加工）+ 飞书知识问答（搜索提问）。三者接力，就是一套完整的知识库系统。

4. 案例实操：从零搭一座“思维模型”知识库

前面拆了需求判断、信息搜集、内容整理三项功夫。这一章把它们串到一块儿，拿个人成长里的“思维模型”当案例，从零走一遍。

**先瞧瞧成品**

我自建的“思维模型库”，是“一人变现系统”底下的一个分支。[PRE23]

里面只放了 7 个完整模型：第一性原理、二八定律、逆向思维、微积分思维、输入输出模型、物质变化框架、行为设计罗盘。每个都带一句话定义、来源（书 / 视频 / 文章）和精读笔记正文。它是我写公众号、做产品决策时翻得最勤的库之一。当然，你按自己的需要挑模型就好。
