# 十一、天生掌舵者

这类人身上有一种藏不住的本能：遇事不躲，遇难不怯，立场坚定，是非分明。他们不习惯看人脸色，也不怕正面交锋，越是局面复杂，越敢站出来拿主意。他们享受掌控全局的感觉，表达观点时直接有力，不喜欢拖泥带水。

在他们心里，一个团队应该有清晰的边界，大家都能坦率说话、直面问题。最让他们难以忍受的，是明明有问题却为了维持和气而假装一切正常。那些被遮掩、被回避的矛盾，在他们眼中就像刺一样，必须拔出来。

不过，这种与生俱来的强势，如果无意识地释放，也会带来麻烦——说话太冲、做事太绝，容易让人喘不过气；决定下得太快，听不进不同声音，难免被贴上“刚愎自用”的标签；习惯了自己拍板，身边的人渐渐就不愿再提意见。

当这份才干被有意识地打磨，它就会变成真正的领导力：该断就断，爱憎分明，不惧怕任何冲突；更重要的是，他们总能一眼看穿那些被刻意隐藏或回避的问题，并且有勇气当众揭开。团队里有了这样的人，很多暗处的隐患，才不会被时间拖成死结。
