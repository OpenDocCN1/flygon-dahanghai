# 8.1.1.1 小红书赛道怎么打？

想在小红书做内容、接广告或做账号变现，先把三件事看清楚：平台人群是谁、流量从哪来、钱怎么赚。下面按这三层拆开讲。

**1）先看平台人群**

小红书的消费主力一直是女性，她们在意生活质感，也热衷分享。围绕这类人群，赛道可以分成主次两层：

- 主赛道：护肤、美妆、母婴、零食、穿搭
- 次赛道：科技数码、游戏、出行

**2）再看流量结构**

小红书的流量入口并不复杂，核心就是关注页、发现页、搜索页三块。

① 关注页——流量占比约10%。关注页在界面最左边，用户关注你之后，点进这个页面就能直接看到你的笔记。它占比最低，也不参与流量层级的数据结果，所以有价值，但作用有限。

② 搜索页——流量占比约10%—20%。这是增速最快的入口。相当多用户一打开小红书就直奔搜索框，把它当搜索工具用。搜索带来的数据不参与笔记流量层级测试，可它的长尾属性很强；只要关键词布置到位，就能在很长一段时间里持续收获精准搜索流量。搜索机制有两个核心：关键词和权重。

关键词分为9类：主关键词、细分关键词、品牌词、产品词、需求词、场景词、行业词、人群词、地域词。

拿美妆里的防晒霜举例：

- 主关键词：防晒霜
- 细分关键词：宝宝防晒霜、油性肌肤防晒霜
- 品牌词：具体品牌名
- 产品词：品牌+主关键词/品牌+细分关键词
- 需求词：怎么选、怎么挑、测评、推荐、效果、怎么样
- 场景词：户外防晒、日常防晒、海边防晒
- 行业词：美妆护肤
- 人群词：学生党、办公党、男性防晒、婴儿防晒、孕妈防晒
- 地域词：三亚防晒

权重既看发布笔记的账号，也看评论、点赞用户的账号。一句话：权重越高，排名越靠前。

③ 发现页——流量占比约70%—80%。发现页贡献大头，也是平台做流量层级测试的核心场景；一篇笔记能拿到多大曝光，取决于它在发现页的用户反馈测试。

分发逻辑说穿了就是内容标签匹配。笔记发布后，系统会把它拆成N个标签，再推送给近期偏好同类内容的用户。内容端，图片和文案都会被系统按标签区分、理解；用户端，近期阅读喜好同样会被标签化分类和匹配；说到底，就是内容标签去匹配用户标签。

推给用户后，系统会依据一系列互动行为给笔记打内部评分，再决定要不要继续放大推荐。粉丝的互动行为会间接体现内容质量；哪怕达人粉丝不多，只要笔记评分优质，也会被系统推给更多粉丝，形成“阶梯式”算法推荐。

高分笔记还能进一步获得小红书站内搜索、百度搜索等渠道的流量加持；这类流量持续性强，让笔记具备明显长尾效应，甚至发布几年后依旧能收获点赞和评论增长。

**3）最后看变现**

① 平台变现情况：千粉账号报价大致在500—1500元，万粉大致在1000—10000元。博主报价并不太看粉丝数，关键看内容流量；流量表现好的账号，报价自然更高。

② 个人经验：不少人会认为护肤/美妆赛道卷得厉害，头部大V扎堆，是竞争惨烈的“红海”。但选方向时，我建议优先靠近能变现的领域。我早期做IP时尝试过纯手绘账号，起号速度很快，可变现很吃力。仅从接广告看，文具品牌本就少，还喜欢用置换“白嫖”；做到3万粉时，最大变现成果只是换到一块手写板，市场价约1500元，于是我果断放弃。反观护肤/美妆账号，5k粉时就能接广告；只要勤快些，月入过万并不难。
