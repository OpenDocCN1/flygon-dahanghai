# 狗狗出镜当主角：直播间差异化带货新思路

小振哥｜2023-05-11

做直播带货的都知道，现在靠常规画面留人越来越难。真正能让人停下来多看一眼的，往往是那些从第一眼就让人觉得“不一样”的直播间。最近我就刷到一个很有意思的案例：镜头前的主角不是真人，而是一只狗；背景是宠物主题的场景，狗面前摆着一张写满字的A4纸文案，用户一进来就会下意识地想知道上面写了什么。卖的也正是狗粮和各类狗狗用品。

这里面的底层逻辑，其实是一次“人货场”的重组：人位让给了宠物，货是宠物食品，场景和道具也都围绕宠物展开。因为出镜的是狗，所以刷进直播间的用户天然就是养狗、爱狗的人群，流量非常干净。这时候后台只要持续弹窗曝光商品，转化起来就会容易很多。

我自己也是做直播带货的，凭经验判断，这个直播间的单场销售额应该在5万到20万之间，表现相当不错。

如果你想复刻这套打法，不一定要用狗。猫、兔子或者其他宠物都可以，关键是场景和道具必须和所选宠物深度绑定。流量精准了，成交就是水到渠成的事。
