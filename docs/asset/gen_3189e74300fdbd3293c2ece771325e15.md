# 3.3 常见疑问

这里针对一些场景问题做尝试性回答，通常分两类：输出质量不好，卡片效果不好。

# 3.3.1 输出质量很差

优先推荐 Claude 4 模型，其次是 DeepSeek V3，这两个是反复测试后更稳定的选择。可以通过两者官网或 Cursor 操作；Windsurf 没有经过大量测试验证，可以试试。其他如 kimi、文心、元宝等未通过稳定性测试，可能出现输出不完整、卡顿、HTML 不成型等问题。有人会让模型续写，或多个 AI 交叉完成，但效果都不如 Claude 或 V3 一次性完整输出，所以不推荐。

# 3.3.2 卡片效果很差

模型的特点决定了：哪怕内容完全一样，在不同时间戳的对话窗口也会输出不同结果，这个过程叫抽卡。卡片效果差时，要综合判断是视觉问题还是内容问题。视觉方面，要给 AI 详细说明，比如“色系不满意，换成鲜艳风格”，或“某个样式不对，我希望是某种效果”。如果对细节描述不擅长，说不清修改点，就只能用模糊沟通，比如“卡片不够惊艳，没有眼前一亮的感觉，重新设计一下”。内容方面，主要考虑自我介绍；请参考如何写好自我介绍的部分重新调整。要用明显区分，注意段落，不要堆叠在一起、没有首尾的介绍。举个例子：我是相柳，家里卖酒，什么酒都可以先问我，家里一直做这个，我没什么其他爱好，就是出来交朋友。尽量格式化或有辨识度地描述。昵称：相柳；区域：深圳；自我介绍：一直从事酒水行业多年（或直接写年份），白酒、红酒、啤酒、洋酒都能供应，白酒如飞天茅台系列，葡萄酒覆盖进口和国产主流品牌，市场畅销啤酒都做，XO 等洋酒也有供应。欢迎聊酒相关内容，酒文化、业务或交朋友都可以。上面这段还能继续优化，也可以让 AI 优化。以上是虚构示例，请按实际情况或参考 3.2.1.3 的简单示例。

# 4.1 知识卡片是什么

知识卡片是一种提炼：把复杂信息吸收后做重点摘要，也可以理解为划重点的信息呈现方式。借用 AI 的结论：知识卡片是信息爆炸时代的认知杠杆，本质是“用设计思维重构知识”。学生、职场人或创作者都能借它高效沉淀和应用知识。

# 5.1 四格漫画是什么

四格漫画用四个固定画面讲故事，通常遵循“起承转合”结构。特点是短小精悍，靠前三格铺垫、第四格意外转折（Punchline）制造幽默或讽刺。因为高效且有独特魅力，至今仍流行。当然，这里主要取其形式，不要求完全遵循原则。
