# 新手怎样进入 Coze 与多维表格提效工作流？

# 1. Coze 工作流和飞书多维表格是什么

ChatGPT 让 AI 具备了理解需求的能力，而 Coze 这类工作流平台，则让 AI 真正能动手执行。你只要在 Coze 里拖动几个模块、连上几条线，就能让 AI 接管那些原本耗时又费力的重复任务：批量处理飞书表格数据、跟踪小红书竞品动态、自动产出周报月报、批量修图去水印等。

更关键的是，这些以前要靠程序员实现的自动化，如今用鼠标拖拽就能快速搭出来。它当然不能包办所有复杂开发，但应付日常大多数重复工作已经够用。

# 2. Coze 简介

扣子是新一代大模型 AI agent 开发平台。无论有没有编程基础，都可以在扣子上快速搭建基于大模型的各类 AI 应用，并把应用发布到社交平台、通讯软件，也可以通过 API 或 SDK 集成到业务系统中。

Coze 国内版：www.coze.cn

Coze 国际版：www.coze.com

国内版和国际版的主要区别在于，国际版支持 ChatGPT/Gemini/Claude，两者使用方式基本一致，我们主要使用国内版 Coze。

优势：

1、零代码入手，学习门槛低，通常几天就能开发自己的 AI 应用。

2、插件商店里有大量官方和创作者提供的插件，比如画图、网页内容提取、视频下载等，覆盖自媒体、职场办公等绝大多数使用场景。

3、可以快捷发布到微信、飞书、多维表格等平台，也能通过 API 灵活调用。

最重要的是：用 Coze 可以完成很实用的链路，比如从主题到文案、图片、配音、视频，再对接存入多维表格，一整条流程都能轻松跑通。

# 1.3 Prompt 工程入门

想象一下，你有一个极其聪明、但理解方式很独特的助手，比如 ChatGPT、Claude、Gemini 等大语言模型。它能写诗、编程、分析数据、回答问题，但它不会读心术。Prompt 工程，就是学习如何清晰有效地向这位助手表达需求，并引导它产出最佳结果的艺术和科学。掌握基础 Prompt 工程，能显著提升你与 AI 协作的效率和质量。

核心目标：清晰、具体、有引导性。好的 Prompt 关键在于消除歧义，让 AI 准确理解你想要什么，以及希望它如何表现。

基础原则与技巧：

1.清晰明确你的任务。

不要模糊：比如只说“写点关于人工智能的东西”，这个指令太宽泛，AI 不知道写什么、写给谁、用什么风格。

要具体：比如“写一篇面向高中生的、300字左右的科普短文，介绍人工智能是什么，并给出它在日常生活中的两个应用实例。要求语言生动有趣。”

关键点：明确主题、目标受众、长度、格式（段落、列表、代码等）以及具体内容要求。

2.提供充足的上下文。

背景信息：AI 没有你脑海里的背景知识，要告诉它相关背景。

例子：你是一名经验丰富的营销顾问。请为一家新成立、主打有机食材的轻食外卖店，制定三个吸引25—35岁都市白领的社交媒体营销策略点子。

角色扮演：让 AI 扮演特定角色，比如专家、老师、某种风格的作家，从而调整输出视角和语气。

例子：假设你是一位幽默的历史博主，用轻松调侃的语气，简要介绍秦始皇统一六国过程中发生的一件趣闻轶事。

明确告诉 AI 你希望结果以什么形式呈现。

请把答案组织成要点列表。

用表格形式对比方案A和方案B的优缺点。
