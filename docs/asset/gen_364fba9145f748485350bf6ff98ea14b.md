# 8.2 让测评网站替你导流 @亦仁

网络上有不少专注评测与教程（how-to）的站点，例如国内的 36氪、小众软件。它们会盯住用户在使用大型网站时遇到的麻烦，再对能解决这些麻烦的工具型产品做评测，从而为工具站带来访问量。对咱们的网站来说，只要能被这类评测大站收录并测评，就有机会获得一批初始流量。

我曾通过 ahrefs.com（外链查询工具）研究竞品 `vibbi.com/instaport/`，查看它的 Top referring content 页面：

[PRE0]

结果发现，Mashable、Lifehacker、MakeUseOf、PCMag 等高流量平台都推荐过这个工具站，并给它带去了可观的访问量。

这些平台显然也注意到了“下载 Instagram 图片”这一真实需求，只是它们选择了更轻的做法：不亲自做产品，而是用内容为用户解决问题。它们通过评测工具站来给用户指路，用户顺着内容最终来到这些工具站。

因此，下一步很明确：把报道过竞品的网站梳理出来，逐个联系并请求评测。这就像启动一个开关——只要有几家大型站点愿意接受评测，流量便会持续进入，随后形成自增长；即便暂时不做推广，过一段时间也可能发现不少测评站主动链接到我们的工具站。
