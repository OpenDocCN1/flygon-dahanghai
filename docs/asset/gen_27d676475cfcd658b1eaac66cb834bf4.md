# 创业团队晋升体系：怎么搭，才能留住核心骨干？

作者：许大范｜2021-08-06

各位好，许范范就是我，这篇分享的署名是许大范。

前三篇帖子发出去后，接连拿到三颗龙珠，被认可当然很开心。不过我也在复盘：那三篇的写法是不是最利于大家吸收？内容我尽量写得系统、信息量足，可对大多数人来说，真的容易读进去吗？这段时间，不少带团队的创业圈朋友陆续来问管理上的问题，他们更想要聚焦、能直接套用的答案。所以写第四篇时，我特意更谨慎，也换了一种讲法。

我把“晋升发展”拆成七个大家最关心的问题，用问答加案例的方式展开，每个问题配一个故事和一版建议方案，你可以按自己关心的点跳着看。这样读起来应该更有针对性，也更好消化。

照旧先做个自我介绍。我在一家五百强公司担任区域人力资源副总，早些年在一家HR咨询机构做到高级顾问，也做职业发展教练，同时是生财私董会的一员，平时会给创业团队提供管理和人力方面的咨询。我来自山东，个性爽朗热情，平常爱琢磨人性，也喜欢打麻将、帮人牵线，还经营着一个公众号：#职业超有范。

今天带来第四篇“发展有术”。聊的核心是：创业团队怎样搭建晋升与发展机制，既让成员有奔头，也尽量避免核心骨干流失。

我把这个话题归成七个常见问题：

问题一：创业团队到底要不要设晋升发展通道？
问题二：团队走到哪个阶段，再上晋升通道比较合适？
问题三：常见的晋升通道有哪几类？自己的团队该怎么选、怎么搭？
问题四：一条通道设多少级合适？不同通道之间的级别又该怎么平衡？
问题五：凭什么判断一个人处在哪一级？评价标准怎么定？
问题六：标准有了以后怎么落地？由谁来评、具体怎么评？
问题七：员工不认同晋升评价结果，该怎么处理？
