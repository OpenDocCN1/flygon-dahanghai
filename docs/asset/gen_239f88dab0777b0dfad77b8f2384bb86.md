# 创业分享：从海外流量玩家到跨境电商服务平台，他做对了什么？

每周三，照例认识一位新的赚钱合伙人。

前两天，龙哥发了一条朋友圈：每一个成功人士的背后，必定曾经做出过勇敢而又孤独的决定。这条状态引起了不少人的共鸣，也包括我。

我接触过很多赚钱合伙人，发现即便是创业老司机，面对未知时也常常会彷徨，甚至恐惧，彻夜不眠、压力大到几个月白了头的情况并不少见。但想想都是问题，干了才有办法，如果因为恐惧而停下来，那就什么事都做不成。创业，必须学会克服恐惧，带着恐惧往前走。

今天这位赚钱合伙人，就是不断与内心恐惧较量、一次又一次做出勇敢决定的人。他做海外流量，一个 niche 站月入五万美元；做亚马逊卖家，旺季单月销售额突破五百万美元；做资源整合，又搞出了亚马逊最大的刷 Review 公司，日刷万单。现在，他转型做新媒体，究竟如何从流量玩家变成媒体玩家？欢迎侃侃网创始人 Moss。

大家好，我是 Moss。感谢龙哥的邀请。先简单介绍一下自己：我在新西兰和澳洲完成本科和硕士学业，专业是电子商务和计算机科学。毕业后独自去美国创业，小有成绩后回国继续打拼，目前仍在路上。

这几年，我辗转于合肥、杭州、重庆和深圳几个城市。目前公司在重庆和深圳，所以今年基本两地跑。有机会的话，很希望和这两个地方的朋友多聚聚。

如果按自传式的方式记录这些年，未免太冗长，大家也未必感兴趣。在我的世界观里，人的一生是由不同阶段组成的，可以是事业阶段、情感阶段，也可以是生理阶段。既然这里叫龙哥盟，不是情感频道，也不是人生哲学，那今天主要聊聊我事业上的几个阶段。

作为连续创业者，我在每个阶段都获得了某种意义上的成功，主要体现为财务上的成功。准确来说，我的所有创业项目都围绕一个大行业展开，没有跳脱太远。而且每个项目都收获巨大，积累的经验和人脉会强烈推动下一个项目。某种意义上，它们是承前启后的——上一个项目为下一个做铺垫，而下一个项目跑起来时，上一个项目还能在不占用太多精力的情况下，提供大量现金流支持新项目前期运转。所以，我算是一个幸运儿，也是一个谨慎的创业者。

下面按四个创业阶段，讲讲这些年的故事，希望能给大家带来启发，也欢迎交流讨论。

第一阶段：海外流量玩家

大学时学过一门课，内容大概是 social media、SEO 和 SNS 这些。课程并不深入，偏介绍性，但老师讲得真的不错，给了我很大的启发。我就从那里开始，入了海外流量的坑，算是半个启蒙。

刚开始玩时还是学生，什么都不太懂，就一阵瞎捣鼓。我自己建站，做了一些产品测评网站，把亚马逊的 review 拿来改写，再对接 Google adsense，想靠流量变现赚钱。结果可想而知，站点虽然有模有样，但流量屈指可数，很快就失败了。

我一直是个坚韧的人，当然不会轻易认输。在不断学习、找原因的过程中，有几件事对我影响很大。第一件事是看了两本书，一本是《长尾理论》，另一本是 Zac 的《SEO 实战密码》。《长尾理论》让我放弃了以前做一两个大站的想法，开始尝试长尾站群、做 niche 站点；流量变现的方向也从 CPM 模式的 adsense，转向了 CPA 模式的亚马逊联盟。Zac 的书则给我搭起了一个完整的 SEO 思路和大体框架。

另一件事是加了很多黑客群、SEO 群，认识了一帮莆田大神。很有意思的是，机缘巧合下我认识了一个高中生，也是莆田人，在百度、Google 上玩黑五类玩得风生水起。我当时咬了咬牙，花一万块拜师学艺，他答应线上授课，几个月教会了我很多黑帽玩法，比如流量点击脚本制作、流量劫持等等。因为计算机本来就是我的专业，这些方向性的东西只要提一下，我基本就能自己钻研融会贯通。所以有时候，有人带路比自身努力更重要。

经过一段时间学习，后面就顺风顺水了。最巅峰时，我一个人有 150 个 niche 站点，其中最大的一个月收入超过五万美金。那时候，我还是一名学生。

第二阶段：跨境电商亚马逊卖家

快毕业时，我觉得这件事毕竟不能长久，想换一个更稳定的创业方向，或者说，找一个能当事业来做的事。主要原因是黑科技玩法玩得有点猛，后面还碰了黑五类，暴利的同时风险也巨大，谷歌K掉了不少站，收入受到很大影响。

当时因为一直在做 Amazon affiliate，我就在想：通过联盟都能赚这么多钱，如果直接去亚马逊卖货，是不是能赚更多？但这一块确实是陌生领域。而且当时亚马逊还没有全球开店业务，中国团队也还没建，要开店只能借助目的国的公司或个人身份。我思来想去，决定毕业后去美国找找机会，看看能不能抓住这波红利。

我申请注册了一个美国公司，找了一个有身份的华人合伙人，就开始干了。货源很简单，直接从速卖通做 dropshipping。当时亚马逊 FBA 还不流行，基本以 FBM 自发货为主。做亚马逊算是踩中了风口，那时平台上主要是鬼佬卖家，流量成本非常便宜，刷单也几乎没人打击。

我当时用虚拟机开镜像配 V-P-N 的方式，养了 1000 多个亚马逊买家账户。产品上架以后就开刷，广告也不做，同时用直评模式，一个 listing 一上架就刷几百个 review，然后关键词刷到首页，直接收割。基本上刷一款爆一款。后来量太大，速卖通 dropshipping 已经扛不住了，直接用阿里巴巴国际站开始 B2B 采购。巅峰时，黑五旺季差不多一个月销售额破了五百万美金。

开局很美好，但后面很严峻。物流和供应链这一块我没有主动权，说实话也不太懂，毕竟我是玩流量出身，对产品的把控也比较欠缺。结果导致大量发货延迟、退货，亚马逊账户直接被关停，损失惨重。但我依然很看好亚马逊这个行业，因为跨境电商是国家外贸出口的全新方向，外贸又是拉动经济增长的三驾马车之一，中国又非常依赖外贸出口。所以我的判断是，亚马逊可以做成长久的事业，而且供应链在中国，还是得回去才有更好的出路。

第三阶段：亚马逊最大的刷单公司

回国后我开始整合供应链资源，也谈了很多家工厂。亚马逊卖货的生意一直在做，后来又开展了跨境电商独立站业务，主要是 Shopify + Facebook 的模式，还根据情况承接了一些代运营业务。整个卖家体量维持在一个不大不小的规模，最高峰是 2016 年，销售额差不多 1.5 个亿。

但随着中国卖家越来越多，竞争压力越来越大，FBA 又要提前压货到美国，整体资金链变得非常不健康——所有利润都滚进库存，完全见不到现金，一旦被封号，之前的利润可能就全没了。所以我需要寻找新的现金流业务。正巧 2016 年底亚马逊出了一个政策，禁止激励性评价，Review 的获取一下子变成巨大的难题。我们抓住这个点，开始筹建刷单团队。

当时分几个方向走：一是通过美国线下拉人头派单，主要面向华人；二是用 Facebook 广告加群控，把人拉到私密 group 里派单；三是通过短信和邮件轰炸去拉人头；四是用 WhatsApp 群控买数据加人、拉人头；五是与北美机房合作，加上家庭 IP 渠道，自养账号刷单，这部分机器号在系统里是全自动完成的。

亚马逊卖家为了拿评价，基本是白送产品，只要留评就行，所以吸引力非常大。我们很快拉起来一支庞大的刷单团队，以自然人作为主力，机器号作补充，很快就成为亚马逊行业里数一数二的刷单公司。

但这件事只能补充现金流，毕竟拿不上台面。随着后面亚马逊打击力度越来越大，黄金收割期一过，这个业务也开始走下坡路了。

第四阶段：跨境电商新媒体一站式服务平台

我们看准的下一个风口，在跨境电商行业的新媒体平台，这也是目前公司正在做的事。因为 B2B 外贸出口逐年下跌，跨境电商异军突起，已经成为外贸出口里的新起之秀。政府越来越重视，国内大型外贸工厂、传统品牌商也纷纷进场，品牌出海越来越热。

准确说，我们今年年初起步，第一步就是尽可能把流量做到最大。平台叫跨境电商侃侃网，花不到一年时间，已经做到整个跨境电商行业流量最大的媒体平台。半年内，通过社群玩法、分销裂变等方式，三个🛰️👸号粉丝均突破五万，最大的“Moss的精神家园”已经超过十万粉；同时有 2000 多个🛰️社群，覆盖跨境电商卖家从业者约二十万人，付费会员破万。这个规模放一般行业可能不算什么，但在垂直行业的新媒体里已经是非常大的量级。前期重心是布局👸号和🛰️社群矩阵，重点在🛰️这一块；后面的目标是尽可能把侃侃网网站的流量做大，形成网站论坛、媒体资讯、视频直播、小程序、APP、🛰️👸号和社群相结合的完整生态链。

线下成绩也不错。半年内举办了一次大型千人跨境电商选品大会，五场千人干货交流分享会。同时模仿樊登读书会模式，在全国五个主要跨境电商城市都建立了线下社群，定期聚会、交流学习。最终形成线上线下流量互相引流的良性循环。

可能很多朋友疑惑，我们为什么短时间内能起来？一方面是因为我们在跨境电商行业浸淫已久，现有的卖家代运营等业务还在继续，能提供足够的运营选品干货和绝对第一手的资讯，内容上有很大优势；另一方面，我们用了很多裂变玩法和社群玩法，相当于用增长黑客模式代替了传统投放广告增长。这里就不多说了，感兴趣的朋友可以私下交流。

另外，我们成功把以前玩海外流量的思维模式和方法论，与国内新媒体流量玩法做了无缝连接，这也是起步快的原因。刚进新媒体行业时，《流量池》这本书对我启发很大，推荐各位去看一看。

所以，现在的侃侃网是一个跨境电商一站式新媒体服务平台，助力中国品牌出海。我们为跨境电商卖家、出海品牌提供最新资讯、货真价实的运营实操干货、各种信息咨询、推广代运营落地服务，以及品牌出海工厂转型的整套方案。如果有想出海做品牌、想转型跨境电商的传统 B2B 外贸工厂和国内电商卖家，欢迎和我联系，欢迎沟通交流！
