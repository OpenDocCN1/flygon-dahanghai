# 卖货三年，我把亚马逊从选品到爆单的打法全摊开

作者：Lissa Tam｜2020-04-20

各位好，Lissa Tam 是我。跨境卖货是吃饭的本事，B站做UP主算业余消遣。刚混进龙哥盟这个圈子，兴奋劲儿还没过，索性把亚马逊创业这一路的经验——从挑产品到日常运营——完整讲一遍，也算我的入场自我介绍。

2019年我落脚深圳，加入一家中等规模的跨境企业，目标定得很清楚：押注品牌、走精品路线，在亚马逊上扎扎实实练一年。这段历练回报不小。新品上线三个月就冲到类目最前面，单月流水做到八十万；之后我接管整个站点，差不多两个月，品牌从原先第八到第十的份额位置一路爬到英国站头名；再往后美国站交到我手上，两个月业绩翻了一倍。我管的几个站点加总，月均三百万上下，团队算上我就三个人。前期为了抢地盘，利润只留一成左右；如今盘子稳了，英国站长期霸着BS，全店产品都守在首页，美国站推起来的爆款同样没掉出首页，整体利润率估计能到两成。

2020年开年我辞了职，跟合伙人正式干。自己当老板才发现，创业是全局博弈，跟下棋一样得掂量轻重、该舍就舍。到现在将近四个月，YQ搅得事情一波三折。不过回头看，这段摔打挺值——跨境电商的钱到底怎么挣，供应链、挑货、渠道、运营、公司运转这一条线怎么串起来，我总算摸透了。头一仗我选了自己最拿手的亚马逊。下面按平台、选品、做品、运营四个板块，讲讲我的实际操作。

## 一、平台怎么挑，开店要备什么

主流玩家无非这几家：亚马逊、eBay、速卖通、wish、shopify。亚马逊的强项在于前端客服体系成熟、后端仓配也完善，主力客群是欧美中产往上那批人，也正因如此，货选得对不对格外要命。eBay那边用户对价格敏感得多，气质接近国内的闲鱼。速卖通带着阿里系的基因，买家多来自发展中国家，东南亚尤其吃重。wish走的是图片信息流，基本靠铺货跑量。自建站则有点像半开放的👸号，流量入口得自己一个个去撬。

我们这回是想把品牌做细，所以光有亚马逊卖货不够，还得有个官网承担展示和抓信息的角色。比来比去，建站平台我定了shopify。平台敲定，配套材料得同步走：店铺、商标、域名。

亚马逊开店的门槛一年比一年高，2020年起还加了视频验证，现成店铺的行情也跟着往上蹿。开店这块我钻研不深，但有一点我很笃定：亚马逊一直在给品牌化铺路，所以我的算盘很简单——能多拿平台资源和扶持就行。于是我拿公司主体去注册，同时把商标备好做品牌备案。落地清单是这样的：先把公司注册下来，办一张VISA信用卡，找靠得住的招商经理递店铺申请，再买个商标。审核这块不轻松，要过两道关，美国站尤其容易被拎去二审；不少卖家就栽在这一步，一旦没通过，那套注册材料基本报废。当然，嫌麻烦的话整条链子都有服务商能接。域名我习惯在namesilo.com买，有些平台头年便宜、往后年年加价，这家每年报价差不多，几十块钱管一年。说到底，平台只是壳子，生意的内核永远是低价进、高价出。所以先解决第一件事：手上得有货。

## 二、选品：方向先定，再从里面挑货

在星球上我提过挑品类的三条线：一是找蓝海，对手少；二是找自己供应链能发力的，资源能往你这边倒；三是找传统行业占大头、差异化还能玩得开的地方。

照着我们自己的底牌，厨房这个品类被选中了。原因有二：供应链愿意给支持，品质、价格、交期上我们不吃亏；再者它是老牌传统行业，卖得动的产品多半吃线下品牌积累和上市年份的红利，精细运营的水平普遍不高。对我这种在3C红海里拼杀过的人来说，可施展的空间很大。我们把调性定成潮牌，从传统产品的外形设计上找突破口，靠造型做差异化，往生活美学那个方向靠，瞄准厨房品类里20到35岁的中产主力。盘完资源，品类下面划出四条品线，接着才进逐个挑货的环节。

跟“先看市场再定产品”反着来，我们是先框方向，再从框里选货。这一步的重心落在市场研判、可行性推演、竞品拆解和最终定款上，靠调研数据去摸市场容量、算利润率，判断这条品线值不值得做。市场研判主要盯这几项：品牌集中度、产品上线年头、BSR位次、评论条数、星级、详情页质量。要是有哪个品牌一口吞掉某个市场五成销量，形成垄断格局，前期硬碰硬没胜算，我们直接跳过；单SKU评论破千的产品要是攒够十条以上，同样出局。

调研跑完、产品定下来，就去找对标的竞品，再到阿里巴巴上摸成本价，先把利润粗算一遍。亚马逊卖货的基础开销包括：进货成本、FBA配送费、单件头程、平台佣金、FBA仓储费。FBA那部分可以用免费计算器跑，Tool4seller和卖家之家我都试过。头程可以拿物流单价乘单件重量估，比如眼下海运到美国大约10RMB/kg，乘一下就有数。基础开销之外，管理成本和推广成本也得留出来，前者通常按5%计，后者按10%左右。这么一算，利润率要是低于30%，这个品基本可以划掉。反过来，利润能过30%，说明选品站得住，接着做竞品拆解：把竞品评论扒下来，提炼卖点、归纳痛点；照着痛点列出产品要求，拿去工厂问价，再精算一遍利润，顺便把产品定位和初步打法定下来。同时并行走一遍项目可行性推演，至少往后看六个月的投入与产出，涵盖推广节奏、物流与备货安排、销量预测，最后落到一张项目预算表上，用来算前期要砸多少钱、多久能回本。业内大卖的回本周期普遍在七八个月；超过九个月还没优化空间的，通常也就放弃了。

## 三、做品：货、包装、视觉三样都得立住

产品敲定，就进打造环节。这段要落地四块：做货、软包装、图像拍摄、VI设计。做货拆成打样、确认样板、做大货；软包装包含外盒、说明书、售后卡；图像拍摄分图片和视频；VI设计则覆盖官网搭建、LOGO、公司介绍等文案物料。

做货这步不必多讲，样板确认、合同签好就能开工。不同品类交期差别不小，长的二十五天上下，快的七天就能出货。亚马逊骨子里做的是货的买卖，货得先压在海外仓，资金回笼慢。交期直接牵着运营节奏走，所以签合同时最好把账期谈妥，写清交货日期，以及延期怎么追责；行规是每拖一天，按合同金额0.5%赔违约金。

软包装这一环，直接决定用户拿到手是什么感受。工厂曾经问过我：你们做线上生意，亚马逊上一堆卖家包装都随便糊弄，你干嘛在盒子上花这么大心思？我说，这就是做品牌和纯卖货的分水岭。线上那一单决定成交，线下那一拆决定体验。体验好，口碑就起得来；口碑起得来，产品才有二次传播的可能。罗振宇在得到讲过一个判断标准：产品成不成，就看用户愿不愿意跟它合影。国内花西子的盒子，一层层拆开全是惊喜。增长黑客那五个阶段——获取、激活、留存、变现、口碑——我们也是照着走的：靠亚马逊站内站外的SEO和SEM把人拉进来，用促销和新品（往后可能再加内容）把人激活，靠品牌建设和官网把人沉淀下来，用买卖完成变现，最后拿过硬的产品和极致的体验把口碑做起来。包装之外，说明书、售后卡，凡是能加体验又能带转化（比如拉高好评率）的招都可以试。我在售后卡上就印了一句“上官网领VIP礼物”，把邮箱收回来，用户沉淀到站里，同时官网再挂个好评有礼的流程，留评率也跟着涨。

图像拍摄的使命是提转化。线上买东西，用户全靠图去感知产品。图拍得好，用户会产生“这东西我正看着、正摸着”的错觉——触感恰恰是点燃购买欲的关键。内容形式上，视频压图片，图片压文字；视频能把性能和使用场景全方位摊开，用户看得越明白，信任就越足。拍图这事最好交给专业团队。提醒一句：开拍前先把定位钉死，弄清目标客群是谁，需求文档写细。同一系列调性要一致，才能显出品牌的聚焦；同类产品可以按风格或人群切分，免得自家人打自家人。VI设计的目的在于把品牌调性拧成一股绳，后面套图和A+设计里字体、配色统一，形成规范。官网搭建反倒不难，既然定位是展示站，shopify上最朴素的模板就够跑。想看对手用什么建站系统，builtwith.com一查便知；流量来源和装了哪些APPS，Commerce Inspector能翻出来。关键还是想清楚建站图什么——像我的核心诉求是收信息加提留评率，那心思就全花在用户进站后的注册和留评动线上。官网还有个用处是售后。有了域名就能开官方邮箱，我的站是Lissatam.com，借腾讯企业邮箱这类平台就能生成一级邮箱名，比如lissa@lissatam.com、support@lissatam.com，比起杂牌后缀，客户看着就专业。

## 四、运营：把流量和转化这两件事磨透

货做好，Listing就能写起来上传了。时间紧的话，先草草写一版传上去，货先发出去，回头再回来打磨；时间宽裕就别偷懒，一次性打磨到位再传，少改几遍。上传要用产品标识码，常规是UPC。要么买UPC，要么申请UPC豁免。买的话创蓝论坛和barcodestalk.com都行，前者便宜、服务也顺，后者看着更正规。UPC豁免就是申请不挂标识码直接上传，品牌产品适用，品牌授权店铺和非授权店铺都能用。操作不复杂，网上有现成文档可循。我怕中间商手里买的码后面出岔子，干脆走了豁免这条路；申请时我还没做品牌备案，交几张产品图，24小时内就批了。货传完，后台安排发货。发美国FBA，空运十五天上下，海运二十五天左右。挑个靠谱货代，价格比对清楚，就能发走。

下面重点说Listing怎么磨。这活挺耗时间。Listing分图和文案两块，前期得按市场研判把定位做实，敲定主打卖点。我的路子是：先把产品核心卖点列出来，再把竞品差评捋一遍，两边一撞，选一个当主卖点，其余按用户在意程度排成辅助卖点。卖点定了，出套图和A+的设计需求表，扔给设计师做，我自己专心抠文案。文案就是标题、卖点、详情描述三件套，写的时候得顺着亚马逊SEO的抓取逻辑走。你卖苹果，平台认它是苹果，才会帮着你推；你卖苹果，平台非觉得是梨，那怎么使劲都起不来。说到底是产品和用户的匹配度，也就是转化率在说话。所以第一要务是把产品说清楚，关键词尽量铺足，对上亚马逊的搜索规则，多占几个流量入口。

再往下要想用户的转化路径：人点进页面之后，怎样一步步被推到下单。一个玩法是借竞品的流量。用instant data scraper把对手的差评扒下来，归纳出主要痛点；确认自家产品能解决这些痛点后，就把它当成主卖点摆出来，广告直接投到竞品页面底下。那些看完竞品、被差评劝退的人，一转头发现我们的Listing正好补上了这个坑，下单概率自然高，转化率也就上去了。另一个是传统打法：回到Listing本身，把市面上最突出的几个需求和痛点拎出来，文案里把满足程度写透。还可以加一段对比，让客户既了解产品，又看到它跟别家的差别，再附上已购用户的好评。这套淘宝卖家玩得最熟，亚马逊还是以亮卖点为主，不妨多翻翻淘宝的BS产品，研究人家的转化路径怎么设计的。

写Listing时多看竞品的Listing，也看行业里写得好的。用webscraper把前10页产品的标题、卖点、详情一把抓下来，丢进wordart做词频分析，筛出卖家最常挂的关键词。同时用卖家精灵这类工具，把用户搜索词和对应搜索量捞出来，跟卖家常用词做反向比对，常常能挖到搜索量大、对手又用得少的长尾词；把这些词嵌进Listing，等于白捡一块流量。产品要是在市场上做出了差异、质量又扛得住、Listing的转化设计也够扎实，后面的运营基本是水到渠成。客服跟上，质量盯住，反馈及时迭代——市面上讲的“产品七分、运营三分”，大概就是这个意思。但也没那么绝对，运营能腾挪的地方多着呢，前提是你把平台规则吃透，顺着规则推产品。比如把关键词自然排名顶到首位、换节点抢BS、跑ppc广告等等。做3C那会儿，产品本身质量平平，我照样靠纯运营把它推爆，做到站点第一。早前在星球里我系统写过新品怎么稳出单、爆款怎么打，感兴趣可以去翻。

另外，等货的那段时间，既然做的是品牌，可以在海外平台先铺二十篇左右的软文，免得用户一搜品牌名满屏空白，也打消他们的顾虑。可落子的地方包括问答类如quora、门户类如yahoo、社交类如Facebook和YouTube，以及各垂直领域平台。运营是离客户最近的一环，能听到最多真实声音。把用户反馈及时归拢，推动产品迭代；对市场保持嗅觉，竞争力才不掉队；数据常做分析，全局观和操盘手感才能练出来。归纳到底，就六个字：流量加转化。精力有余，多试几种玩法，去优化、去打磨、去创造。

——

以上就是我创业流程里关于产品的一些实践和体会。

我是运营出身，所以在我看来，任何产品，前期市场功课做足、质量把住，都推得起来。也正因如此，流程里没提测款这回事；加上我们起订量大，第一批款式自己都挺喜欢，就直接开做了。当然，测款本身不能省。据我了解，Facebook广告可以测，也可以先小批量空运一批新品进亚马逊仓，跑广告看后台数据，哪个表现好就押哪个。再往后就是具体到品线和单品的运营策略。去年我总结过怎么稳住出单、怎么打爆，说穿了还是流量加转化，国内那套打法搬到国外，八九不离十。龙哥盟圈里肯定藏着不少高手，涛哥@杨涛就秀得厉害，玩流量玩到飞起，一直是我膜拜的对象。要是这篇对你有用，顺手点个赞。最后谢谢赚钱圈子，盼着跟大家一块儿玩——一起龙哥盟，感恩遇见。
