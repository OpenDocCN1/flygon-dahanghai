# 团购售后处理手册：糯米团篇

在糯米团下单后，如果遇到售后问题，按下面这些规则处理会更省心。

1）凡是快递环节引发的售后，第一步都是立刻对接快递申请赔付，需要补发的直接安排补发。对接路径是：客户先找帮卖团长，帮卖团长再找供货大团长，供货大团长再联系实际发件的快递公司。简单说，谁发的货，谁负责跟快递沟通。

2）如果包裹因快递运输粗暴而破损，请马上联系快递公司（仍由发货方负责与快递公司对接），同时请客户提供现场照片，方便核实处理。

3）涉及按比例退款的情况，可直接用红包形式完成售后（后台支持操作）；把相关证据提交给糯米团，即可申请赔付红包。

4）客户想改收货地址：订单还没发货时，建议取消原订单后重新下单；如果已经发货，则联系糯米团客服协助修改地址。

5）标品因质量问题需要退换货时，往返快递费用由糯米团承担；但如果是客户买了不喜欢而走无理由退换货，退回产生的运费需客户自行承担，收到退货后再退全款。

6）清仓款、特价款、食品类、美妆类以及贴身衣物类团品，不支持7天无理由退换货。可支持7天无理由退换货的团品，往返运费需自理；并且商品要保持不影响二次销售。换货的往返运费由客户自理；退货时需先扣回发货运费，再办理退款。

7）遇到漏发、错发等卖家方面的问题，请在签收当天联系客服处理，并提供照片作为凭证。

8）因质量问题产生的退换货，运费补贴按地区情况为5—10元；退回件请不要使用顺丰寄回。
