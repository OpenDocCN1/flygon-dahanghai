# 2.1 推广合作，先找对服务商

平台数量不少，但真要谈成小说推广合作，门槛并不低。多数平台并不直接和达人对接；除番茄小说外，其他平台都要通过服务商提交推广申请。

所以，想把这个项目顺利跑起来，关键一步是找到靠谱的服务商机构，让它承担达人与小说平台之间的对接工作。具体分工是：我们负责挑选要推的小说、确定关键词、制作并发布视频、做好引流；服务商负责平台侧沟通，保障关键词回传、出单数据查询等环节顺畅。

这次航海，圈友@seven 提供了帮助。我们可以通过他的服务商机构「乐推联盟」对接小说平台，把小说推文从推广到变现的完整链路打通。

机构名称：乐推联盟

规模方面：合作达人 3000+，合作团队 100+；在知乎平台的运营体量处于同类机构中上游，月均对接约 30w 单，其他小说平台的对接量也位于中上游。

优势方面：回款速度偏快，基本为 T+2；公司每月垫资 300w～500w；以公司化方式运营，能承接较大的流量规模。

可直签的小说渠道：
- CPS（开会员分佣）：知乎、最右 APP、UC 故事会、书旗
- CPA（拉新分佣）：QQ 阅读、番茄小说、夸克浏览器、起点

本次航海期间，服务内容包括：
- 对接各小说平台，支持关键词审核、推广订单查询、出单数据查询等；
- 由专人审核关键词，最多一天内通过（番茄小说需在每天两点之前提交）；
- 提供一份覆盖各大平台的爆文表单，供船员选文参考，并保持每周更新。

合作注意点：
- 对合作中知悉的商业秘密、其他达人个人信息等，需严格保密，且只能用于本项目；
- 合作期间如出现刷量等违规操作，将视为根本违约处理；
- 如存在抄袭等权利瑕疵，需承担全部责任；
- 服务商可根据业务情况及达人履约情况，保留单方解约权。
