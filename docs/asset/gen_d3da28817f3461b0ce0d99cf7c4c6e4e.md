# 12.4 解决场地管理

1.

创业初期，非必要不租办公室。

不少热血青年东拼西凑几十万，事情没做成钱却亏完，很大一部分就花在办公室上。

办公室再漂亮也不属于自己，好看和业绩没有半点关系。

创业初期省钱才是硬道理，别为了面子烧钱。

把钱花在搞流量上，才最关键！

建议：先用自家改造、居民楼、商业公寓等最低成本方式运转，只要一条网线就能开干！

2.

业务起来后，需要写字楼。

找写字楼怎么避坑？

1.

办公楼租赁虽按月计费，但通常至少签1年，也不宜超过3年，业主一般不会同意，或要求一定幅度递增。租金常分“包票”和“净到手”：包票是租金含租赁税发票，净到手则不含。要问清：起租期多长？租金是否含税？增长幅度多少？

2.

办公楼还有管理费（物业费，按每平方米每月）支出，要主动询问。按行业看，20元以下多数没有中央空调，或空调费另计；20元以上多为中央空调。管理费通常含公共区域水电维修保养、清洁卫生等。要问：物业费多少？是否含空调费？电费多少一度？网络费多少一个月或一年？一般来说，联合办公租金已包含物业费、水电费等全部费用。

5.

另外，各写字楼中央空调开放时间不同，很多有时间段和月份限制，极少24小时供应，大部分只在上班时间（多为8:30-18:30），加班还要付加班空调费。少部分可自装独立空调，如需加班或不想用中央空调，可问能否安装独立空调。还要问：空调时长多少？能否自己调控？能否安装独立空调？
