# 4.1 挑女装供货方，先看这几点

下单样品那一步，其实已经接触过供货方。等出单后再找对方细谈代发即可。下面把找供货方的方法和注意事项补完整。

1. 价格空间

供货价和你的上架价之间要留出利润；报价太高，和同行相比就没优势，转化也会被拖累。

2. 款式与品质

可让商家拍照确认，也可以自己买样回来判断。货够优质，后续长期合作才稳。

3. 单量大时能否接ERP

订单到100+后可以上ERP系统，发货效率更高。不用再导单给商家，商家在ERP里直接看订单、打单发货，既少一道环节，也能降低系统判定店铺无货源的风险，还能打印小红书面单。具体用法见4.5对接工具。

4. 能否打手工单、避开第三方电商平台面单

前期单量少可以不上ERP，但必须和商家确认走手工单，防止被平台识别成无货源，保住店铺安全。咨询前先说明自己做小红书电商、能长期合作，也可以多聊几家，让对方感觉你是会持续下单的人，而不是只问不买。

5. 货期与退换

先问清楚是否接受退换货，避免部分供货方只退40%-80%的货。

# 4.6 供货方避坑清单

如果你还在做无货源，尚未完全转成货源合作或自有货源模式，下面几个避坑点能帮你少走弯路。

1）怎样避免淘宝或拼多多给客户发短信

常用应对：

① 收件手机号不填真实号码，在地址后面补上真实电话。比如张三1894263109，四川省成都武侯区玉林路88号小酒馆；拍单时写成：张三18900001339，四川省成都武侯区玉林路88号小酒馆到了打1894263109。单量大时客户仍可能收到短信，那就换第二种。

② 把数字替换成字母，做一点障眼法。在手机号里挑一两个数字改掉，例如1写成I、2写成z、6写成b，平台识别不出完整号码，快递员仍能看懂。最终大致是：张三18900001339，四川省成都武侯区玉林路88号小酒馆到了打I8942b3I09。

③ 走中转仓。上架下单时地址填中转仓，中转仓会做二次面单，二次面单写客户真实地址后再发出。这样能彻底避开客户收短信，只是中间会多一两天。

2）商家不发货，或发来的货很差怎么办？

拼多多上的无货源商家目前最多，因为成本最低，很多人一人铺几十家甚至几百家店。你在这种店铺下单后，对方可能找不到货，或觉得会亏，于是不发货、以次充好。去多多进货（其他平台同理），要会看：

① 别盯成交件数，尤其10W+成交的不看；重点看评论数和最近评论数。

② 看发货时效，页面前面标了“多少小时发货”的商家，通常出货更快。

③ 看店铺产品数量，若产品极多（图书、食品类目除外），尽量避开，多数是无货源或经销商。

④ 看店铺爆款和评分，四星半以下尽量不选。

⑤ 看店铺资质，点店铺首图能看到开店主体；如果产品打假风险高，尽量只选公司主体店铺。

# 5.2.1 女装发货标准

# 5.2.2 超期发货：报备与触发

超期发货，指商家没在承诺给消费者的发货时效内发出，且未在平台上传真实有效物流单号。因不可抗力导致超期的，商家可通过小红书商家管理后台做订单延迟发货报备。注意：平台按客观事实判断是否违规；除法律法规和平台规则明确的免责事由外，商家不能以自身无过错为由主张不违规。

超期发货不报备的影响：

1. 影响店铺服务分：服务分低于一定水平，平台有权终止合作。

2. 影响店铺流量与积分：平台会按严重程度扣店铺及专业号流量，并扣商家违规积分。

3. 订单赔付：平台会从商家结算货款、保证金等中扣除相应金额，赔付给买家。
