# 写在前面：先回答三个关键问题

💡 欢迎来到 12 月航海的小红书教育资料引流专题。正式动手前，先把三件事弄清楚。

1）这个项目到底是什么？

通俗地说，就是先在小红书持续输出优质内容，把对教育领域有需求的人引导到微信私域，再通过教育资料产品完成成交，从而获得收益。行业里还有学科资料变现、小红书学科教辅、小红书虚拟资料、小红书虚拟电商等叫法，名称不同，本质相通。

整条路径有两个卡点：一是怎样避开违规限流，把引流动作做顺；二是怎样建立属于自己的资料库。后面会展开讲。

2）项目现状和收益空间怎么样？

教育是长期刚需，家庭对教育的投入意愿一直很强，政策也在支持教育行业发展，当下正处在红利期。几乎人人都有教育资料需求，市场空间很大。

从小红书来看，平台用户有较强消费潜力和付费意识，人群画像与教育资料赛道也比较契合。但要注意，小红书已经不是早年靠简单搬运、洗稿就能轻松赚钱的阶段了，只有踏实做内容，才可能长期留在牌桌上。

和传统电商相比，教育资料多为虚拟产品：不用垫资、不压货、没有物流仓储，成本低、利润高、售后少。这个项目的特点是重运营、轻交付，时间和精力主要花在内容制作与引流获客上。

3）哪些人适合做？

第一，想靠卖教育资料获得变现的人；第二，做副业或居家创业的人；第三，在教育领域被流量增长困住的人；第四，已有教育产品或服务、或者能找到教育机构合作分销的人。

整体来看，项目入门门槛和操作难度不算高，大多数人都能上手。随着流量不断积累和沉淀，收益也会逐步变得可观。

# 一、先弄懂小红书教育资料引流

# 1.1 项目定义与机会

教育资料引流，就是吸引精准教育粉丝进入私域，再匹配高需求的教育资料产品，最终完成销售变现。

市场上对该项目有多种称谓，如学科资料变现、小红书学科教辅、小红书虚拟资料、小红书虚拟电商等。叫法虽然不同，本质都是小红书教育资料引流。

教育在我国一直是超高需求行业，而且热度只增不减。以高考志愿填报为例，艾媒咨询数据显示，2023 年中国高考志愿付费市场规模达到 9.5 亿元，是 2016 年的 7.3 倍。

再看三个真实案例，会更容易理解其中的价值：

一份 PPT 模板卖 139 元，售出 9167 份，营业额 127 万 4213 元；成本大致只是平台提现手续费约 5%，模板开发出来后边际成本几乎趋近于 0，一个人就能赚到约 120 万。

每天搬运一篇外网文章，169 元一年会员，已售 2.1 万+，收入 354 万 9000 元。手机摄影课程 199 元，已售 3 万+单，合计营收 597 万+。

分享留学干货，家长来下单咨询，再和留学机构或个人工作室合作完成后端文书交付，30 万咨询费可直接抽成 30%，也就是 9 万到手。

为什么选择小红书做引流？结合平台和用户特征来看：

① 用户精准。80% 的女性用户年龄集中在 18～34 岁，基本就是这个教育资料项目的精准人群。想想身边的年轻女性，除了抖音和各大社交平台，刷得最多的往往就是小红书。

② 定位精准。小红书现在是仅次于百度的搜索场景，平台定位就是种草和分享社区。只要用心分享有价值的信息、有知识点的笔记，就更容易获得信任；再通过方法引导点赞、收藏、评论、关注和私域引流，成交会更顺。

③ 付费意愿高。女性在消费中的地位不言而喻，小红书用户在消费决策上的表现普遍高于其他平台。图文并茂地描述一个东西，往往就能安利到一大批人。

理由一：用户特质高度匹配，找准赛道。在小红书看少儿教育内容的家长，大多来自一二线城市，自身有一定教育水平，重视素质教育和快乐教育，对子女教育投入意愿较高。另一方面，小红书用户整体偏年轻，重视实用主义，核心动机是提升职业技能和竞争力，值得成人教育机构投入。平台用户画像符合教育领域消费群体，尤其是直接在网上购买资料这类决策成本低的事情。

理由二：小红书种草属性强，便于建立用户关系。[PRE3]

小红书是社交型种草平台，优质内容加上精准账号定位，能迅速吸引目标用户关注。课堂笔记、论文答辩、学习打卡、准留子出圈指南……越来越多年轻人在小红书上分享学习心得、交流经验，也会寻找各种“上岸”方法论。过去一年，小红书教育行业内容增长 665%，教育行业专业号增长 181%，已经是教育行业的流量洼地。

理由三：小红书教育生态健全，便于找准人群。[PRE4]

近年来，考公、考研、英语学习等教育话题持续受到关注，小红书教育行业内容暴涨 665%，已有 130 万+教育创作者产出超 5000 万教育内容笔记。国内教育体系里，你基本都能在小红书找到相关笔记案例；某些小众需求或垂直细分赛道内容较少，这恰恰是蓝海机会。

理由四：小红书用户自我驱动，容易引发共鸣。[PRE5]

举个鸡娃的例子：一个家长看到某位老师分享的学霸手写笔记，再想到自家孩子时常年级倒数，购买欲是不是马上就上来了？

举个备考的例子：一个备考学生看到前辈已经把往年考试重点做了提炼和注解，购买欲是不是马上就上来了？

再举个备课的例子：一位教师正在小红书苦苦找案例素材，正好看到某位老师分享了全国名校全套教案素材，购买欲是不是马上就上来了？

教育资料引流的项目流程是什么？

1. 确定赛道：考验市场数据分析能力。通过分析我国教育领域大部分细分赛道，结合小红书平台用户需求，选定赛道后再做账号定位和内容选题。第一阶段教学会详细解释我国大部分教育细分领域，供你选择，并教你结合自身优势找到最适合的赛道。

2. 整理产品：考验资料检索和整理能力。确定赛道后，要匹配对应产品。第一阶段会教你怎么整理资料、搭建产品库，为后续变现做好铺垫。

3. 搭建账号：考验定位能力。根据所选赛道，搭建适合的小红书账号 IP，所有搭建细节会在第一阶段详细指引。

4. 制作作品：考验内容制作能力。前三步完成后，就进入作品制作环节。第二阶段会详细拆解做出爆款作品的具体步骤，希望大家动起手来，把手弄脏。

5. 引流私域：考验平台运营能力。作品爆了、流量来了，如果无法进入私域就很可惜。第二阶段会分享小红书导流私域的小技巧，尽量避免这种遗憾。

6. 成交转化：考验销售转化能力。项目走到最后阶段，就是私域成交转化，涉及成交话术、朋友圈打造、私域运营技巧和注意事项。第三阶段会进行私域板块的魔鬼式训练，这也是当下互联网人非常稀缺的私域运营能力。

# 1.2 变现方式：新手先卖资料包

教育资料项目主流有 8 种变现方式。本次航海选择最容易上手、门槛最低的“出售资料包变现”带大家实操，其他 7 种可以在选修中查看。

变现形式 1：单一销售某一种资源。

以 K12 教育资料为例，可做语文、数学、英语、科学、道德与法治、音乐、美术等科目。以英语四六级资料为例，可做词汇表、语法精讲、历年真题解析、模拟试题、听力练习、口语练习等。客单价一般几十到几百不等，具体看所在赛道市场情况。

以 K12 教育资料为例，可做学期群、学年群、全年级学科群、永久资料会员等。以英语四六级资料为例，可做四级 VIP 全程班、六级 VIP 全班。客单价比单一资源更高，一般几十到几百不等，甚至上千，具体看赛道市场情况。

# 二、把赛道选对

💡 章节概要：选择大于努力，方向不对，努力白费。在优质赛道里深耕，大多数情况下收益会高于低质赛道。赛道意味着起跑线，也意味着天花板。

# 2.1 怎么选赛道

从自己的经历里挑：求学、工作、爱好兴趣、身份，都可以作为入口。

不要像叶公好龙那样，把“自己没经历过、只是脑子里觉得不错”的事情当成赛道。要把上帝给你的每段经历当作礼物。比如：

求学生涯里，你最初是专科，后来专升本，再考上研究生，那么可以做专升本、考研方向。

工作经历里，你是英语教师，或做过英语家教，总之和英语教育沾边，那么可以做英语方向。

爱好兴趣里，你喜欢把读书心得、课程笔记做成竖屏思维导图，那么可以考虑竖屏思维导图方向。

身份里，你有一个上小学一年级的女儿，你是一名宝妈，那么可以做一年级，也可以做宝妈能变现的事情。

如果实在不知道选什么，就让教练推荐一个。最好跟某个教练做一样的赛道，甚至卖一样的产品，遇到问题马上找他解决。与其骑着同行过河，不如直接骑着教练过河更快。
