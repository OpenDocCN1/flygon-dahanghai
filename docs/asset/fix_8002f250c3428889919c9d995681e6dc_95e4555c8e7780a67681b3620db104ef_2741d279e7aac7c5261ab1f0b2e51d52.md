# 零、项目概览

# 💡

# 本节要点

眼下小红书约九成卖家扎堆在女装、日用、小配饰这类低客单领域，靠压价、拼款式抢单，单笔利润常常不到三成。反观手工银饰、中古家具、户外装备等高客单蓝海，供给规模小于搜索需求，平台流量池还在扩张，供需缺口自然带来溢价空间。

这一章会结合平台走势，讲清两件事：为什么要切高客单蓝海，以及具体怎么做，为后续实操打底。

# 0.1 为什么高客单蓝海值得做

小红书电商发展几年后，大品类逐步饱和，竞争非常激烈，但不少细分方向仍是待挖的金矿。本期教练古辛最早做淘宝蓝海起家，在他看来，小红书蓝海比淘宝蓝海更有优势：用户以女性为主，能接受更高客单，利润空间也更足。

小红书同时具备推荐和搜索两套流量机制，这让创新类产品更容易跑出来。创新产品不断涌现，因此只要平台流量机制不变，蓝海方向就能持续做，选题也不会枯竭。

和红海类目相比，小红书蓝海离成交更近，正反馈来得更快；产品选对，出单并不难。

蓝海电商有几个明显特征：第一，反馈快，做完动作较快能看到结果；第二，竞争相对小，更容易做出成绩，发生价格战的概率也低；第三，项目周期长，其寿命取决于小红书流量机制，只要机制不变就能持续做，而淘宝蓝海后来变难，核心原因就是流量机制改变；第四，不缺产品，掌握正确选品方法后，蓝海货品会持续出现。

这个方向门槛不高，新手即使没有电商经验，也较容易较快获得正反馈。竞争小，选对品后出单相对轻松；真正的难点是持续稳定出单，这既看产品是否稳定，也看获取流量的能力。

# 0.2 玩法拆解与最小闭环

1. 最小可行路径

第一，执行顺序：注册账号并开店 → 选品（关键） → 找笔记素材 → 发笔记测品（关键） → 出单后对接供应商 → 上架商品并安排发货 → 有稳定流量后买样品 → 自己实拍并发笔记 → 持续做店铺运营管理。

第二，节奏安排：前3天开通店铺并完成选品，第一周至少发5篇笔记，边选边测，目标3周内出首单，再转向实拍。

2. 核心关键

其一，选品约占七成权重，直接决定成败。

其二，前期不必强求实拍，先跑通“蓝海选品—混剪笔记—卖出首单”的最小闭环。

其三，内容提效：航海会教用 AI 工具辅助创作，例如 Deepseek 配合多维表格写爆款文案。

其四，轻资产启动：初期主要是每店约1000元保证金，也可等提现时再交；后期样品采购每次预估几百元，还可以和老板谈免费拿样。

3. 航海目标

选品需要反复练，电商里选品几乎定生死。新手21天没赚到钱很正常，不必焦虑；这是长周期项目，应看长期收益。

# 1.1 账号与设备准备

# 1.1.1 备好两个账号

新手一般建议开个人店铺，2个个人店铺对应要准备2个账号，具体包括：

1. 至少2部手机；不建议一部手机多开，存在限流风险。

2. 至少2张电话卡；两个小红书号需要两个实名，对应两张卡。

3. 至少2个身份证信息，可用家人的。

电话卡方案：移动、联通、电信都能办副卡，一个身份证可注册认证5个号码，一拖四，副号月租约10元；移动有一款副卡月租10元，一张身份证可领2张，首张与第二张需间隔90天，营业厅和App都能办，营业厅还可争取免首年月租；电信App搜“无忧卡”，5元/月，通常次日上门；移动另有8元保号套餐。

手机建议：手机既登录账号也拍视频。拍摄优先 iPhone XR 及以上机型，成片效果更好；后续做直播，iPhone 稳定性更佳，但 iPhone 不能双开。

[PRE7]

# 1.1.2 登录、实名与养号

登录方式：同时运营两个号，能否只用一部手机？可以，但有风险。若手机自带小红书应用分身，例如部分红米等安卓机型，可一部手机登两个号；目前这样操作，账号暂未异常。

[PRE8]

若手机没有分身功能，不要装第三方分身软件，封号风险高；此时再备一部手机登录账号即可，闲鱼或拼多多三四百元的二手手机就能满足日常。

实名认证：一个身份证只能认证一个账号，认证后只有注销账号才能解绑。操作路径：我—左上角三条杠—创作中心—创作服务的更多服务—开通专业号—成为专业号—选择个人并点击立刻申请—填写实名认证信息。

[PRE9]

[PRE10]

养号：新注册账号每天刷30分钟以上，提升权重；按所选赛道刷对标笔记，一般持续1-3天。不要一上来就挂车。

[PRE11]

# 1.1.3 店铺开通

# 1.1.3.1 先分清店铺类型

入驻前先分清店铺类型，不同类型权益不同。大类上分个人店铺和企业店铺。

无论开哪种店，都要先认证专业号。新注册账号默认是非专业号，不能参与商业行为，包括薯条投放和开店。因此变现第一步，是升级专业号。专业号分个人专业号和企业专业号。

个人型：个人专业号的身份标识是XX博主，如时尚博主、美食博主等兴趣类博主，基本申请即通过且不收费。认证流程：创作中心—更多服务—开通专业号—我是个人—实名认证—选择身份证并填写信息。个人专业号可申请个人店铺或个体工商店；名称格式为XXX（昵称）的店；保证金最低1000元；平台按类目收2%-5%技术服务费。

企业型：企业专业号需上传营业执照并缴600元，身份标识为XX品牌。流程：创作中心—更多服务—开通专业号—我是企业—填写基础信息—填写主体信息—上传资质公函—填写运营人信息—缴600元—等待审核。填写注意事项见下图：

[PRE12]

提交后注意：申请有效期30天，30天内未完成申请，费用不退；通过后每年需年审并续费600元。企业专业号可开普通企业店、专卖店或旗舰店。命名分别为XXX专卖店/旗舰店；普通企业店保证金最低2000元，详见《小红书类目保证金明细》；月营业额低于1万元时平台免收技术服务费，超出1万元的部分按5%收取。自2023年9月10日起，一张营业执照最多申请2个专业号、2家店铺。

[PRE13]

同品牌只能开一家旗舰店，但可并行开其他类型，如旗舰店+专卖店，或旗舰店+普通企业店。企业专业号营销权益多于个人专业号，二者只能选其一，按需求定。新手一般开个人店即可，门槛低；企业店多用于放大矩阵，平台对账号的宽容度也更高。

[PRE14]

# 1.1.3.2 个人店：条件与流程

入驻条件：个人型店铺分个人店和个体工商户店。个人店只支持服装、百货等常见类目；个体工商户店除常见类目外，还可经营奢侈品、珠宝等。

[PRE15]

各店铺类型可经营类目不同，图中打勾项即可经营类目，具体可在小红书学习中心-规则中心-经营总览查阅：

[PRE16]

开店需缴保证金：个人店和个体工商户店均为1000元；保健品、奢侈品等特殊类目会更高。

[PRE17]

客服模式：个人店铺可选平台代运营或自主客服，平台代运营收费，按自身情况选。平台佣金即技术服务费，按类目收2%-5%，细则见：https://school.xiaohongshu.com/rule/detail/27/2585?jumpFrom=school 。为降低个人店和个体工商户开店负担，目前入驻后不缴保证金也能发布商品上架售卖；店铺累计交易额超过1万元后，下个月月初才需补缴保证金，基本实现“无门槛”开店。

开店步骤：选择个人店铺并选经营类目，然后提交姓名、身份证号、手机号，完成人脸识别，验证通过即可开通。

[PRE18]

个体工商户店需提前准备：营业执照照片、公司名称、统一社会信用代码、经营地址、营业执照有效期；以及店铺运营授权书。操作上同样先选经营类目，再按提示上传资料。

[PRE19]

个体工商户店审核一般2-3天，期间可登录入驻系统自查；遇到无法解决的问题，可在9:00-24:00联系人工客服。

[PRE20]

# 1.1.3.3 企业店：条件与流程

入驻条件：企业型店铺包括普通企业店、旗舰店、专卖店和集合店。

普通企业店命名同个人店，为“专业号账号名称+的店”；企业专业号取名须与商标对应，否则无法开店。

旗舰店为XXX（品牌名）旗舰店，专卖店为XXX专卖店，集合店为XXX的海外店。

企业店可经营大部分类目，含保健品、医药等特殊类目。

平台佣金：1万元以下不收费，超出部分按5%收取。

保证金按类目有差异，一般境内最低2万元，境外3500美元。

不确定选哪种，可看下图快速判断：

开店步骤：企业店材料较多，建议在电脑端操作，入口为 gaia.xiaohongshu.com。先说普通企业店，登录后大致6步。

第一步，店铺类型选“普通企业店”。第二步，填公司信息并上传营业执照，照片要清晰完整，避免扫描出错。

接着填写法人或店铺运营人信息，联系人须与营业执照上的法人一致。

[PRE23]

第三步，店铺名称由系统自动抓取，格式为“昵称+的店”，与昵称直接绑定；要改名称，需先去专业号中心修改昵称。

[PRE24]

第四步，选经营类目，类目须落在商标注册证范围内。第五步，等待审核，一般3个工作日内完成；失败会通过电话或邮件通知，期间可联系在线客服。审核通过后，最后一步缴店铺保证金，注意开卡账户为对公账户，开户人须与入驻时填写的经营人姓名一致。

再说旗舰店和专卖店，步骤与普通企业店大体相同，重点有四点：

第一，填写品牌信息。系统里没有品牌名时，点“新增品牌”添加；上传的 logo 图片须与商标注册证完全一致。

第二，分清自有品牌和代理品牌。代理品牌须有完整授权链路，公司名称选营业执照上的名称。

自有品牌指商标持有者是本公司或公司法人，注册类型分 R 标和 TM 标：R 标为注册商标，TM 标为商标注册申请受理通知书。

个人型 TM 标同样要上传商标注册申请受理通知书，以及权利人身份证或护照复印件/扫描件。

若申请企业型 R 标或 TM 标，只需提供商标注册证或商标受理通知书。

第三，选售卖品类时，谨慎选择“定制”类目。

第四，审核通过后还要签合同，合同以线上邮件形式发送，通过电话或验证码确认签署。
