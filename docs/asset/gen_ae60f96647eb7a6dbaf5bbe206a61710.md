# AI宠物画：精准吸引养宠人

作者：筑梦｜2023-03-21

小红书上的养宠人群规模可观，因此宠物类内容长期不缺流量。用AI生成宠物主题画作，能够把真正喜欢宠物的人聚过来。

变现路径不止一条：

其一，把想拿图的人导到公众号：账号可以迅速涨粉，再靠宠物知识类内容承接转化。

其二，做夸克网盘、迅雷的新用户拉新：把免费取图设置成下载后领取，头像号和宠物号都能用。

其三，接宠物头像、壁纸定制：宠物头像的客单价普遍高于人像，常见在200元以上；人像大约50元。
