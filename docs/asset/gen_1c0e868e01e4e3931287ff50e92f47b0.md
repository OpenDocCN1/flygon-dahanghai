# 8.3 第三步：上案例

光给方法，往往还不够准；方法本身偏概括。这时不妨再找一批同行的优质标题，交给 ChatGPT 拆解、学习。

提示词：

收集同行标题这件事，很建议做。操作不复杂：打开📕刷5到10分钟，把点赞高的笔记标题记下来，先攒20到30条；再从中挑10条左右，连你自己都控制不住想点进去的标题。（其他平台也一样）

下面准备了一组很能打的标题库。请总结它们抓人的共性，并做到举一反三，给其他内容也起标题。先学习，再总结：
