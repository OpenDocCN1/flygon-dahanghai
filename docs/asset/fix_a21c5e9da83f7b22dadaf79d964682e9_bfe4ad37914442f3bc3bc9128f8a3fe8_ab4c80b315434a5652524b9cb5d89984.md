# 11.1 做LOGO，AI能替你走多远

LOGO 是什么？可以把它理解成企业、机构或品牌在生意场上亮出的身份牌，也是识别体系里少不了的一环。动手之前，得先摸清品牌自己的调性和站位，再把图形、字体、配色这些零件组织起来，让品牌的主张、气质与面貌被看见，最终服务于传播和推广。

LOGO 的常见做法可归为四种：字形类只靠文字或字母说话；图形类以图案唱主角；组合类把字与图拼到一起，信息更密、层次也更丰富；徽标类则接近印章、徽章那一类。

风格上也有五种调性可选：扁平化路线减少装饰，画面干净利落，现代味道更足；立体化路线借光影过渡和渐变堆出体积与材质层次；手绘路线用笔触和手工感呈现字与图，品牌会显得更亲切、更有个性，轻松有趣的调性尤其合拍；经典路线偏传统美术语汇，讲求积淀与沿袭，家底厚、历史长的品牌更对味；未来主义一路视觉更前卫，突出科技属性和领先姿态，科技、创新类品牌比较适合。

在 LOGO 这件事上，AI 作图的长处和插画创作差不多，这里不再展开。

不过，和插画相比，它还多两道坎：一是字符和字母很难做到位；二是给的多是方向，不能直接拿去交付。

就目前来看，让 AI 稳稳写出文字仍很难，单个字母（例如 L）尚可应付，整词和中文就吃力了。按类别看，图形类和徽标类它还能搭把手，字形类则远没达到能用的程度。拿“LIN”这个词让它试，出来的结果就是下方这样，离预期有距离。
