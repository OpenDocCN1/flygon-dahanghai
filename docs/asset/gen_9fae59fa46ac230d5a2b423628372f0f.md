# 情感咨询公司怎么赚钱？一套跑得通的模型

2023年3月31日，阳老板在生财发了自己的第一篇帖子，主题是情感咨询公司如何做成盈利生意。他2010年就进入情感行业，曾搭建过260多人的咨询团队，算得上这个领域的老玩家。他发现社群里聊情感咨询的内容不多，于是把自己的行业观察整理出来，供感兴趣的人参考。毕竟情感需求长期存在，这个市场一直有空间。

他提到一个关键结论：月营收超过1000万的大型机构，和只有三五个人小团队，背后跑的都是同一套运营模型。也就是说，想切入这个赛道，不必先追求规模，先看懂底层流程更重要。完整拆解内容较多，他放在了语雀文档里，原文还带了 #风向标# 标签：

留言区也有不少行业补充。有读者感叹这行利润空间可观，30万元营收能留下十几到二十万元利润；阳老板回应说，自己做流量是可行的。还有人提到广州这类公司扎堆、竞争激烈，阳老板也认同，并表示月流水300万以上的机构大多集中在广州。不过他补充，仍然有不少自己搞流量的团队很赚钱，今年情感类直播尤其受欢迎。另有读者表示，头一回在这里了解情感公司的流程，也有人提到自己加了创富会，还有人留言说厉害。

整体看，情感咨询的需求持续存在，行业模型也有章可循。想入场的人，不妨先从这套流程研究起。
