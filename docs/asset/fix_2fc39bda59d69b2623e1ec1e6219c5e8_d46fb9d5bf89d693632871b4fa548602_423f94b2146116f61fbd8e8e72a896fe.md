# 微信客服接入 AI，九步配置通关

动手前先把三个基础项填掉：公司名称随意取，比如“XXX 工作室”；行业类型按实际情况挑；人员规模直接选最低那档。

1. 拿手机用你日常的个人微信，扫一下页面上的码。
1. 跟着系统提示点确认，这一步就结束了。

1.2 保存企业 ID

1. 确认完一般会自动跳到管理后台；要是没跳，自己在地址栏敲开：https://work.weixin.qq.com/wework_admin/frame
1. 进后台后看左边导航，一路拖到最底部，点「我的企业」。
1. 进入后继续往下拉，会碰到「企业 ID」这一项。
1. 它的值是一串 ww 打头的字符，例如 ww1a2b3c4d5e6f7890。
1. 复制下来，先丢进手机备忘录。

**第四步：到微信客服后台拿回调参数**

这一趟能带回两个值：Token（第三个）和 EncodingAESKey（第四个）。

请认准微信客服后台 https://kf.weixin.qq.com/，别跑去自建应用详情页。

1. 进微信客服后台。
1. 找到 API 配置那一页。
1. 生成 Token。
1. 生成 EncodingAESKey。
1. 先把它们复制下来存好。
1. 此刻先不要按「完成」或者「开始使用」。

原因很简单：一点完成，微信客服马上就会去请求你填的那个回调地址。OpenClaw 此时还没弄好，验证十有八九会挂。

另外再强调一句：回调 URL、Token、EncodingAESKey 这三个东西，都在微信客服后台这边搞定，不要去自建应用的「接收消息」里折腾。

**第五步：把服务器 IP 加进白名单**

企业微信有个硬性安全机制：API 只认白名单里的 IP。你的机器不在名单中，接口会当场回绝。所以得手动加。

1. 左侧导航进「应用管理」，点你自己建的那个应用。
1. 进入应用后往下翻，找到「企业可信 IP」。
1. 点「配置」。
1. 把服务器的公网 IP 填进去——只写 IP，端口号不要带。
1. 点「确认」。

**常见问题**

找不到 openKfId 怎么办？

别慌，这不是你一个人的困惑。有些页面就是把它藏得深，甚至不直接露出。

处理路数：

1. 先确认客服账号确实建成了。
1. 把客服名称记下来。
1. 然后走接口拉客服账号列表来定位 ID。

不要因为界面上暂时看不到，就怀疑前面每一步都白做了。

回调配好了，为什么发消息没反应？

先问自己回调 URL 到底配在哪儿。

如果你把它塞进了自建应用而不是微信客服后台，八成就是这里出的岔子。在 wecom-kf 这条链路里，回调 URL 应该优先写在微信客服后台。

客户发消息了，AI 不回复

三关排查，哪一关断了修哪一关。

第 1 关：消息到服务器了吗？

看日志里有没有 [wecom-kf] callback received。

- 没有 → 消息根本没进来，去查 URL 是否正确、端口有没有放开、Gateway 是否在跑。
- 有 → 说明消息到了，看第二关。

第 2 关：消息拉取成功了吗？

看日志里有没有 sync_msg。

- 报错 → 通常指向 corpId 或 corpSecret 填错，或者 IP 白名单没加。
- 正常 → 继续第三关。

第 3 关：AI 处理了吗？

看日志里有没有 dispatching to agent 或者 reply sent。

- agent 报错 → 说明问题在 AI Agent 本身，与微信客服无关，去查 Agent 配置。
- reply sent 出现了但客户没收到 → 对着错误码往下看。

报错 95017

48 小时窗口过期。客户最后一条消息已经超过 48 小时，企微不允许你再回复。

正常客服场景基本碰不到。调试时撞上了，让客户重新发一条即可。

报错 60030

接待人员不在应用可见范围内。

回第二步那个应用，改「可见范围」，把接待人员所属部门加进去。

回复格式乱了（星号井号满天飞）

微信客服不认 Markdown。插件会自动转一道（标题变成【标题】，加粗去掉星号），但不保证每次都完美。

对策：在 Agent 的系统提示词里补一句——“回复客户用纯文本，不要用 Markdown。”

回复太长被截断

企微单条消息上限 2048 字节，折合约 680 个汉字。插件会自动拆成多条，但超过 5 条就会受限。

对策：在 Agent 提示词里加一句——“回复控制在 500 字以内。”
