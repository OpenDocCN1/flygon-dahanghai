# 1.2.3 视频号导流，私域怎么收钱

视频号如今在微信体系里的分量，已经不必多言；视频号小店也接替了微信小商店的位置，成为微信重点托举的对象。正因如此，整个微信生态给了它相当多的便利：直播间能够连接小程序、企业微信，甚至可以在视频号主页直接亮出个人微信号。

把人引到私域之后，变现路径其实很丰富。最普遍的是做电商卖货；再往后，知识付费课程、虚拟产品也很常见，因为多卖一份几乎不会增加多少成本。游戏CPS同样值得考虑，靠充值返佣获利，新增收入所付出的成本也很低。

这里尤其建议尝试虚拟产品。实体商品卖得越多，新增成本和管理压力往往同步上升；虚拟产品则不同，复制成本更低，延展空间也更大。像游戏、小说、短剧这类内容，满足的是精神消费，赚钱能力往往比普通实物商品更强。
