# 4.1.1 不推销的成交：个人IP吸引力法则 @李思念

我始终相信，成交不是靠说服推动，而是由吸引力自然带来。

早些年刚创业时，我也上过一些销售课。那些方法听上去逻辑完整，每个技巧都能自圆其说。可当我换个位置，作为消费者面对满屏话术和套路时，心里其实很不舒服。

于是我会想：如果连我自己都抗拒这种逼单方式，那我的潜在客户被同样对待时，会不会也感到别扭？

买卖不该只是“我卖你买”的单向动作。它更像一次双向筛选，也是一种价值交换：客户付出金钱，得到真正需要的产品或服务；双方觉得值，合作就顺理成章。整个过程应当没有压迫感，双方都能感到自在和满意。

所以我不再依赖话术，而是把精力放在打造吸引力上。愿意靠近的，自然是与我节奏一致的人。

说到吸引力，就绕不开个人IP。销售路径其实可以分成两类：老式成交路径是，客户先来咨询，卖方答疑、摆案例、做说服，等信任建立后再成交；而以个人IP为核心的路径则是，先立住个人IP，再积累信任，最后水到渠成地成交。

想把朋友圈做成能自然出单的场域，本质上就是在圈内持续建立个人IP，让潜在客户逐渐对你产生信任。

内容整理自《如何打造自动成交的朋友圈系统》
