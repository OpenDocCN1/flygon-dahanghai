# 先卖组合，再谈单品

等这套表达打磨好之后，销售动作就要从“等客户上门”切换成“主动出击”。当然，具体话术可以按自己的业务情况微调，下面只作参考。

核心思路其实很简单：把产品做成组合套餐来卖，单独拎一个单品出来，竞争力通常很弱。与此同时，设置好价格阶梯，顺着客户爱占小便宜的心理，让他感觉自己拿到了更多实惠，获得感自然就上来了。讲透两个关键问题后，话术可以自由发挥。

设计1、2、3时，要让它们彼此咬合，形成包含关系。举个例子：1设计成积分兑换券，定价9.9元，用来筛选来领资料的人群，判断对方是班主任；那么2就顺着人群设计成“班主任开学资料包”，并且资料包里包含1；3再包含2。这样整套话术就闭环了，成交率也会更高。

# 8.3.2 朋友圈发布时间指南

不同时间段，客户的状态不一样：可能在发呆，可能在工作，可能在挤地铁，也可能在喝酒聚餐。虽然没法100%猜准对方在做什么，但同一时间，绝大多数人往往在做同样的事。比如早上起床就是吃早餐，下午茶时间就是摸鱼玩手机。所以发布时间是很重要的一环，直接影响转化率。

# 九、更多资料赛道

# 9.1 选择优质赛道的方法

💡 对于找赛道不迷茫的小伙伴：

1. 本身就在教育行业多年，有一定经验积累，知道自己的客户群体和痛点，能快速匹配产品。

2. 懂得看行业数据，知道哪些行业处于上升阶段。

3. 网感好。比如前阵子的“高考志愿填报”相关服务和产品，就是一个风口项目。

💡 迷茫的小伙伴：

1. 过往没了解过或没做过教育相关行业。

2. 不擅长看行业数据分析报告。

3. 网感一般。

但我想说，这都没关系。没有人天生就天赋异禀。幸运的是，我们都在生财有术，能够接触到一线的互联网信息源，已经优先于90%的普通玩家。

在找赛道之前，先要搞清楚什么是优质赛道：

**市场规模足够大。**

比如我带闲鱼项目，如果是“闲鱼数码项目”，那我就只能收对数码产品感兴趣的学徒；如果我是“闲鱼高客单价项目”，那我就可以收任何想做“高客单价产品变现”的学徒。在有鱼的地方才能钓到鱼，在鱼多的地方才能钓到很多鱼。

**消费频率高，也就是复购率高。**

比如K12教育，每个新学期都要学新内容，这样都能给补习机构带来成倍增长。

**可持续性强。**

有些项目昙花一现，短期蹭一波流量、吃一波红利就没了；有些赛道则会有稳定流量。

接下来教大家几个选择优质赛道的技巧。

## 方法三：差异化，从需求入手

如何通过差异化找到蓝海市场？我们把“教”和“育”分成两个方面：“教”主要以老师为中心，“育”主要以学生为中心。

比如大家都在做K12教育的学生市场，那我们能不能针对教师群体市场做文章？用一个赛道对比表格做市场定位解析，明晰之后就可以开始后续工作。同样的例子还有很多，比如都在教育孩子，那能不能换成“教家长如何教育孩子”？希望大家都能挖掘到属于自己的蓝海。

## 方法四：结合自己的专业/兴趣，从自己入手

都说兴趣是最好的老师。结合兴趣与市场需求，找到两者之间的交集，选择一个既能满足个人兴趣、又有一定市场需求的赛道。

1）从成就事件中寻找优势。

举个例子，我的朋友L是做投资的。她天生对数字、原理非常敏感，从小数学成绩就很不错，这是成就一；大学期间，她爸爸一次性给了她四年学费，她把这些钱拿来投资，过得很滋润，仿佛赚钱就是一场数字游戏，这是成就二；工作以后，她开始专注炒股，总能在看盘面后找到买卖点，收益总体很不错，这是成就三；每次我们聊投资，她看几眼就能立刻说出不同数字背后代表什么，并推导出合适的买卖时机。她从不害怕别人的质疑，甚至享受逻辑验证的过程，靠专业度吸引了不少客户，这是成就四。

从小到大，她一直对数据、逻辑、原理非常敏锐，分析能力很强，也一直靠这种方式达成各种成就。而她的这种特质，放到盖洛普的语境里，就是“分析”才干：对数字非常敏感，喜欢探究事物的来龙去脉，无法忍受未经证实的结论，相信科学而非直觉，总能看透事物的本质。

像这样列出自己的3—5个成就事件，找出其中的共同点。你会发现，在这些和获得成就有关的人和事里，我们总是用某种方式来获取阶段性成果，这个“时常出现的方式”往往就是我们的优势。

2）从重复行为中寻找优势。

一个人愿意花很多时间去做同样的事，大概率是这件事有吸引他的地方，而在这件事里就可能潜藏了他的优势动力。

举个例子，我的朋友A喜欢出门、喜欢参加活动、喜欢结交新朋友。所以她会不断去参加活动，哪怕半夜11点，也会准时到场。同时她会不断出去认识新朋友，如果一段时间不社交，她就会变得很无聊。一旦生活上遇到难事，她的第一反应也是出门见人，听听朋友的经历与建议。

A的“取悦+行动+积极”才干非常突出。认识新朋友、尝试新的人生体验，对她来说是一种充电行为；在与她人的互动中，有她在的场子不会冷场，大家都很开心，这是取悦+积极；听到好的建议立刻做起来获得反馈，会让她持续迭代。

当然，重复行为不一定永远都能获得正反馈。比如，我是一个忍不住到处看各种消息、商业报道和发朋友圈的人，这样的我也很容易溜号。我另一个朋友是忍不住学各种课程、搜集各种小东西放在房间里的人，她也可能被人说是不务正业。还有朋友总是不怎么说话，一开口就是指出问题给解决方法，被人认为喜欢挑刺。

我们都在人生的不同时刻怀疑自己走的不是正路，但没意识到这些忍不住去做的事，背后体现的是思维、理念、搜集、学习、取悦等才干。就像我几乎不缺朋友圈素材，搜集才干搜集了大量素材，理念才干灵感不断，思维才干加工写出来，依靠持续不断的写变现了七位数，但我从没系统学过写作。

所以，如果你有忍不住想去做的事，无论周围的人支持或否定你，这个事情大概率藏着你底层才干的需求，关键是找到这个才干适合应用的场景，不断放大优势。

不过，选择赛道的前提，一定要遵循市场需求为第一原则。否则容易陷入虚无主义，最后为爱发电了。

# 注意事项

1. 切记没有准确的赛道定位。反面例子：本来想打造一个考研老师的人设，正常要卖考研资料，结果去卖小学作文素材了。

2. 切忌赛道多而杂。切记做成大杂烩，我们要做精品店、专卖店。一个账号又是小学、又是初中、又是考研、又是教师资格证，太杂太乱，没有一个明确の定位，让别人一眼就觉得你很不专业、很不靠谱。所以做项目、做账号定位时，最重要的是专业性，尤其在教育领域，大家最看重你的专业度。

3. 切忌坚持不到一半就放弃。切勿三分钟热度，今天搞K12教育资料，明天跑去做考研资料，后天又去做法考资料。短期看不到结果，一定是有问题；如果不及时改正，下一个赛道依旧会遇到同样的问题，无法根治。认准一个赛道之后，尽可能把它跑到闭环。
