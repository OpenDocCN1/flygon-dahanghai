# 6.2 方法二：售后拆成三类，处理起来不慌 @叶子

都说“常在河边走，哪能不湿鞋”，做团购也一样，哪怕选品再严谨，总会有翻车的时候。卖货就一定会遇到售后，所以第一件事是把心态放平，然后再想解决办法。要是本身就怕麻烦，干快团这行确实会很累。

我的看法是：售后不用怕麻烦，反而是你和其他卖家拉开差距的机会。多数客户并不是真要你做什么，而是希望看到你的态度，用态度来弥补心理上的不平衡。

下面说说常见的售后和应对思路。

第一类，是可度量的售后。比如催发货、快递卡住、商品破损补偿、退换货等等。这里面最难搞的是催发货，因为供货团长的货常常不在自己仓库。遇到这种情况，要先跟供货团长问清楚，延迟发货到底会延迟多久。如果延迟时间没准，而且是不可抗力造成的，比如灾害、疫情，那就给客户一个专业说法，让客户先退款，等发货恢复稳定了再重新下单。如果是商家自己的原因，就跟商家沟通，给延迟发货的客户补偿红包，基本没有客户会不同意，如果有，多半是红包金额不到位。至于破损补偿，就要灵活掌握，看看供货团长能给多少，以及这个客户重不重要。

第二类，是特殊售后，典型表现是不按我们的售后标准来提供依据。这类最让人头疼。我们的做法是看客户的情况和态度再决定。如果客户很重要，态度也好，我们会先把售后标准说清楚，然后补一句：这次就先给个红包补偿，下次记得提前准备好依据。其实这类客户要的就是一个态度。举个例子：有客户反馈丑苹果没有果柄，怀疑不新鲜。很多卖家会回复说：生鲜运输过程中有水分流失很正常，只要没有大面积磕碰和腐烂就不能售后。客户听到这种话肯定不认同，他会觉得找你买货，品质就是不好。而且每个人评判标准不同，卖家觉得苹果皮也不皱，怎么会不新鲜？客户却觉得肯定是放了很久，不然果柄怎么会掉？这时候只要告诉客户：我们的丑苹果是15年的老树果子，很多果树没有改良，采摘时没法用剪刀剪，都是用手扭下来的，所以果柄自然就没有啦！就这么简单一句话，客户的疑虑全消了，买你的果子，少了猜疑和担心，多了信任。

第三类，是少量质疑类售后，主要表现是“不好吃”“不好用”。处理这类售后，在私域里不能套用电商的售后标准，比如“口感问题不售后”这种话千万别说。正确姿势是两手抓：专业知识+诚恳态度。

这里借用别人的一个案例：客户收到脆皮金桔，觉得皮硬，来找售后。有些团长会直接甩一句“因口感问题不售后”。我们可以换一种回复：

“11月中旬开始，国家级地标融安脆皮金桔开始采摘，我们给您推荐的是金桔二代。跟原来皮薄麻嘴、不甜有籽的一代相比，二代果香浓、甜度高、汁水多。不过头茬果子的皮会稍微厚一点，很多客户都能接受。金桔这个品种很特别，一棵树要开三四次花，果子也是一批批熟的，头茬果个别皮厚很正常。带皮吃营养更丰富，如果介意也可以把皮啃掉再吃，或者做成金桔酱，秋冬季节冲水喝，化痰止咳很管用。另外，我们确实没把链接里的细节好好介绍给您，这样吧，这边补一个小红包，略表诚意……”

这一套干货输出加上诚意表达，客户首先会觉得你很专业，有些人听完甚至会觉得自己太不懂行。结果自然不用多说。
