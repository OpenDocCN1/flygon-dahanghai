# 借力同行文案，闲鱼小说代写从零到接单全流程

[PRE0]

做闲鱼小说代写，别总想着自创文案。同行挂出来的内容早就被平台验证过，照着学不容易踩红线。敏感词这东西防不胜防，你不知道哪句话就撞枪口上了，所以拿别人检验过的底稿最省事。在闲鱼里搜“小说润笔”“网文续写”“小说定制”，能翻出一大批现成模板。抄的时候不要整段复制，把信息点的顺序打乱，重新拼接成自己的话。

# 💡

**参考案例：同行的挂单文案**

小说大纲、章纲、开头文、续写都可接，当前无排期压力，随时下单。作者写过九本书，玄幻、都市、历史、年代都熟，百万字以上完结并签约上架；短篇和多篇开头、大纲也有不少积累。脑洞大，欢迎咨询，价格好商量，越大量越优惠。大纲：一份xx元起（3000字左右，命名、发展、结局、高潮点、建议都包含）。章纲：按千字计，有大纲的xx-xx元起（根据需求浮动）。续写：需要自带大纲或章纲。开头文：千字xx元起，需提供要求和设定。需要升级服务点“我想要”，可议价，不跑单。

现在排期有空，随时约稿！本人写过多部小说，玄幻、都市、历史、年代等类型都拿手，累计百万字完结并顺利签约，短篇、开头文、大纲经验也足。创意丰富、交付稳定，价格美丽，订得越多折扣越多。小说大纲定制：xx元起一份（约3000字，含书名、过程、结局、高潮节点和修改建议）。章纲定制：按千字计算，有大纲者xx-xx元起（按具体需求来）。开头文：千字xx元起，请带要求和设定。续写：需自带大纲或章纲。点击“我想要”下单，欢迎商量，绝不鸽。

碰到数据特别亮眼的同行，点进主页看看。只要对方没关动态，就翻一下那条爆款链接大概是什么时候上架的——是近期靠着新流量冲起来的，还是靠时间慢慢累积的。老链接的文案通常没问题，可以直接借鉴；新链接数据却很好的，要多留个心眼，检查有没有踩线的措辞。

**发布地与标价**

每个商品都换个发布位置，优先选省会或大城市周边。价格可以设5元、10元、20元，别压得太低也别虚高。

**审核**

发布后遇到审核是正常现象，等系统放行就行。

**上新频率**

尽量每天都上新，实在没时间发一两个也算数。闲鱼的流量说来就来、说走就走，今天有量的号明天可能就凉了，只有多上新才能多抢流量。

新号前期建议一天发10个或更多，多试不同类目、不同风格的主图。

# （5）私域承接转化

**摸需求：** 先弄明白客户想写什么、写多少字、什么风格、什么时候要，需求不清楚后面很难推进。

**亮服务：** 把自己的服务范围、收费标准、工作流程、交付时间告诉客户。可以直接说，也可以发介绍文档，或者引导对方看作品集。

**定细节：** 需求聊清后，敲定稿件要求、价格、预计完成时间。条件允许就签个简单协议，把双方权责写明白，避免日后扯皮。

**答疑问：** 客户会关心风格、修改范围、版权归属等问题，耐心回复，帮对方搞懂流程和成果，信任感自然就来了。

询盘阶段决定第一印象，沟通到位了，后面才能给出精准方案。

需求聊透之后，引导对方加微信号继续谈。尽量别主动发自己的微信号，小心被同行举报。（具体话术详见7.3）

# 7.1.3 在BOSS平台找兼职写手

选好地区后，在BOSS上搜“小说”，按关键词一个个筛出合适的岗位。

# （1）面试兼职写手注意点

试稿是躲不开的环节，注意下面几件事：

**弄清试稿要求**

主动问清试稿的题材、字数、风格、交稿时间，防止因为理解偏差导致返工或被拒。

示例问题：“试稿的主题和风格有参考案例吗？需要多少字？有没有特定关键词或禁忌内容？”

**确认版权归属**

提前确认试稿内容会不会被无偿拿走，可以说“试稿仅用于能力评估，未经授权不得商用”，防止被白嫖。

如果HR要求试稿篇幅过长（比如完整章节），建议分阶段交，先给大纲和开头片段。

**判断对方专业性**

看HR能不能把合作模式（分成、买断、保底稿费）讲清楚，如果对方含糊其辞或者急着压价，要提防是不是低质甲方。

# （2）与HR谈试稿和长期接单

**结算方式和周期**

说清稿费标准（千字价/篇数计费）、结算周期（周结/月结）、付款渠道（某宝/公司账户转账），避免后期纠纷。

示例问题：“长期合作有阶梯稿费吗？逾期付款有补偿吗？”

**内容要求和修改规则**

确认内容类型（网文/IP定制/新媒体短篇）、更新频率（日更字数）、修改次数限制（比如免费改2次后额外收费）。

也要表明自己的创作边界（比如不接耽美/灵异）。

**长期合作可能性**

问清楚后续接单稳不稳定（“每月保底多少万字？”），以及有没有晋升空间。

# （3）防坑技巧

**合同条款**：要求签电子协议，重点看保密条款、版权归属（是否署名）、违约赔偿（比如甲方无故拒稿）。

警惕“试稿过了再签约”但没有书面承诺的情况，可以要求先签一份简单意向协议。

**保护个人信息**：试稿时别透露太多个人经历或原创设定，防止创意被窃取。

**留好沟通证据**：在BOSS或微信里保留关键约定（稿费、交稿时间），别轻信口头承诺。

# 💡

总结：试稿是双向筛选的过程，既要拿出专业度，也要通过细节判断甲方值不值得合作。前期沟通越细致，后面纠纷越少，重中之重是守住创作权益，别当廉价劳动力。

# 7.2 价格设定方案

# 7.2.1 按字数收费

女频小说：每千字10—20元

男频小说：每千字10—15元

备注：

字数计价适合大多数小说创作，特别是情节不复杂的类型。价格区间可以随故事复杂度、情节布局、人物设定适当浮动。遇到特别复杂的情节或需要强烈情感描写，建议加价。

# 7.2.2 框架写作价格

已有完整大纲、只负责写成正文的：每份10—15元

备注：

这个价格适用于客户手头已经有完整故事框架、只让你扩写成正文的情况。报价之前要和客户确认大纲的具体要求，比如每章的内容细节、人物设定、背景世界的复杂程度。如果大纲比较抽象或粗略，可以按工作量和时间调整。

# 7.2.3 单开头的报价

单独写开头：每千字40—50元

备注：

开头是吸引读者继续追下去的关键，对创意和文笔要求极高。价格定得高，是因为它要奠定基调、扣住注意力、铺好情节地基。价格可以依据开头的创新程度、情绪铺陈和引导效果来浮动。

# 7.2.4 完整框架策划报价

完整大纲定制：每份50—100元

备注：

大纲制定是写小说前期的重要环节，涉及情节规划、人物设定、主线与支线的协调。你要在大纲里写清每章目标、人物发展轨迹和高潮布局。大纲越复杂，报价越高；如果客户要求极度详尽的大纲，就往区间高端走。

# 7.3 私域谈单与转化方法

# 7.3.1 破冰开场：先拉近关系（情绪价值）

# 💡

核心：沟通刚开始要用温暖真诚的态度让客户感到被重视，别一上来就“推销模式”。先从称呼或氛围建立情感连接，再一步步深入需求。

如果客户年轻，有个通用办法：男生叫“宝子”，女生叫“宝宝”，再配点表情包，能很快打破陌生感。

除了“宝子”，也可以用“哥哥”“姐姐”“美女”这类称呼，但语气要自然亲切，别太客套。第一次沟通也可以直接切入正题，后面再慢慢建立信任。全程始终保持真诚和专业。

实用建议：

去掉“过度热情”——少堆修饰语和多余称呼，直击客户心理，让对方感到你爽快又真实。

加点“幽默细胞”——适当调侃，比如夸对方头像、昵称，甚至自嘲，能快速破冰。

不绕弯子——开场白压在一两句内，直接抛出需求或问题。

# 7.3.2 挖需求：找准痛点（理解客户）

核心：通过提问和引导，搞清楚客户真正的需求和难点，确保后面给的方案精准命中。

**第一步：了解基础需求**

话术示例：

“您好，感谢信任！为了更好定制小说，想先确认几个方向：

小说类型：都市言情、悬疑推理、玄幻修仙，还是其他细分题材？（可给热门标签参考）

目标读者：面向男频还是女频？倾向哪个平台（晋江、起点等）或年龄层？

核心亮点：侧重人物成长、世界观设定，还是强剧情冲突？有对标作品可以看吗？”

作用：快速定位基础需求，筛掉不合适的人（比如需求和自己擅长领域不搭的）。

**第二步：细化创作要素**

话术示例（针对需求模糊的客户）：

“您提到‘偏轻松风格’，具体是指：

语言风格：幽默吐槽风（像《大王饶命》）还是细腻情感流（像《偷偷藏不住》）？

章节节奏：要快节奏打脸爽文（日更万字），还是慢热铺垫型（重视伏笔）？

角色设定：主角人设有特殊要求吗（比如大女主、反派重生、系统金手指）？”

技巧：用选项帮客户收窄范围，避免对方因为“说不清需求”而放弃沟通。

**第三步：确认交付边界**

话术示例：

“为保证内容符合预期，还需要确认：

篇幅规划：是单篇短篇（5万字内）还是长篇连载（分大纲+正文阶段交付）？

更新频率：由作者自主创作，还是按日/周固定交稿？

内容边界：有没有禁忌内容（血腥描写、政策敏感题材）需要避开？”

作用：把合作风险点摆到台面上，避免后期因需求变更闹纠纷。

**第四步：引导客户补充隐性需求**

话术示例（针对犹豫型客户）：

“不少客户都会关心这些细节，您可以参考：

世界观扩展：需要作者帮忙完善设定吗（比如地图、势力关系图）？

IP衍生需求：后续打算做有声书、漫画改编吗？如果有，建议提前把人设做得更丰满。

数据反馈：需不需要根据平台读者评论调整后面的剧情？”

技巧：用行业经验提前想到客户没说出口的需求，专业感一下就上来了。

**第五步：总结需求并报价**

话术示例：

“根据刚才的沟通，你的需求整理如下（请确认）：

题材：女频古言重生爽文，对标《xxx》，目标平台晋江；

字数：大纲+前10章（约3万字），后续按千字xx元续订；

风格：强打脸逆袭，节奏紧凑，周更2万字；

附加：提供基础世界观设定表，免费修改2次。

报价方案：大纲+前10章费用xxx元（含2轮修改），3天内给大纲确认，7天内交付正文。您看需要调整吗？”

关键点：

1. 用结构化列表复述需求，降低客户理解成本；

2. 把报价拆成阶段（大纲→正文），减少决策压力；

3. 强调交付流程（“大纲确认后再写正文”），传递靠谱感。

**应对客户“不确定”的话术**

场景：客户说“先随便写个方向试试”。

回应：

“理解您的顾虑！为了避免试稿方向跑偏，我们可以：

4. 提供3个热门题材提案（含核心梗概），您选一个细化；

5. 根据您的模糊描述，我起草2版500字短纲给您投票。

（注：提案阶段只收xx元定金，成交后抵扣稿费）”

底层逻辑：用低成本方案引导客户进入决策流程，顺手过滤“白嫖党”。

# 7.3.4 多维报价：引导选择（多种方案匹配）

**报价分层设计**

引导策略：纯写作需求话术

1. 对比法引导中间档

话术示例：

“以男频玄幻小说10万字为例：

基础版：总价1500-3000元，保证基础完本，但缺少爆点设计，需要您自己优化数据；

标准版：总价6000-9000元，我们负责设计‘退婚打脸’‘秘境夺宝’等经典爽点，点击率平均提升40%；

旗舰版：总价1万-1.5万元，资深编辑把控‘情绪钩子’，适合冲平台新书榜。

建议：如果想要平衡成本和效果，标准版能覆盖90%的常见需求，而且支持分阶段付款（比如先付30%写大纲+前3章）。”

2. 低成本试水转化

场景：客户犹豫要不要签长篇。

应对：

“可以先选单章试写：

付费250元，我们按您的要求写1个完整章节（约5000字）；

满意的话，试写费用全额抵扣后续合同总价；

不满意的话，免费提供1次剧情调整（限改1次）。”

3. 应对价格异议

客户质疑：“别家千字20元也能写。”

专业回应：

“低价稿件常见的坑：

① 重复率高：机械套模板，容易被平台判定抄袭；

② 断更风险：写手同时接多单，更新不稳定；

③ 修改成本高：需要您逐字指挥，耗时耗力。

我们的标准版包含原创度检测（查重率＜8%）+更新保障协议，实际帮您省下30%隐性成本。”

**实战案例：分层报价促成签约**

客户背景：

需求：悬疑推理短篇（8-10万字），预算有限，但希望“有机会上平台首页推荐”。

沟通策略：

4. 需求分析：

客户隐性需求：想低成本试水市场，要是数据好就再追加投入。

5. 方案匹配：

✅ 阶梯式合作：

“前3万字按标准版（千字15元）重点打磨‘连环凶案开场’和‘主角侦探人设’，如果点击率进频道前50名，后续按基础版（千字40元）快速完结，总成本控制在6000元内。”

6. 结果：

客户签了标准版，前3万字拿到平台新书潜力标，主动续订到8万字（总价5600元）；

作品完本后均订破3000，客户又返单委托同系列第二部。

**客户决策辅助工具**

7. “需求-预算”匹配表：

低预算+高要求 → 选旗舰版短篇（5万字内）；

中预算+长期连载 → 选标准版分阶段付款；

高预算+急稿 → 选旗舰版加加急费（总价+20%）。

8. 风险保障承诺：

“如果因我方问题导致断更，按缺更字数双倍补偿或免费续写。”

# 7.3.5 适当优惠：促成成交（符合客户预期）

关键点：报价和谈判中可以适当让利，但底线要守住。把服务价值讲清楚，让客户明白这个价格合理。

走到这一步基本就是讨价还价环节，做过销售或买过东西的人都懂，专业说法叫询盘、回盘。

适当地给点优惠，比如9折、88折，或者送1-2次修改，后期再送点附加服务。如果是老客户介绍来的，可以说“看在朋友面子上给你个优惠价xx折”。成交之后别忘了给介绍人发个红包，鼓励他们继续复购、继续推荐，把圈子滚起来。
