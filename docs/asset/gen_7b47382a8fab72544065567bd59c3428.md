# 技巧六：朋友圈别条条带货

这个话题前面聊过，但确实值得再摊开说透。

假如每条动态最后都落到产品上，看起来是在持续输出专业价值，实际上就等于把朋友圈变成了广告栏。这个道理很多人心里都明白：广告刷屏并不合适。

可一到真正下笔，情况往往相反。明明知道不该篇篇都往产品上引，手却总是不由自主地拐过去。尤其对朋友圈文案还不够熟练的人来说，更容易冒出这样的念头：憋了半天才写出一条，不顺便卖点东西岂不亏了？

所以，读完这一节，我希望你先把功利心放一放。

很多时刻，我们需要一点不那么“有用”的纯粹。

打个比方：你和几位好友出门旅行，难道这趟行程不能让你立刻学透《中国地理》，你就不出发了吗？和朋友结伴出游本身的快乐，难道不算收获？
