# 📕卖货，一个账号只押一个品

在📕做电商，与其把货架铺得很杂，不如把精力收拢到一个单品上。先去电商平台筛选那些正热销、或者虽然小众但销量尚可的产品，核心是它能接住用户的某一个具体小需求。

账号不用贪多，围绕一个产品持续发笔记、拍视频就够了。相对而言，视频更容易带来转化。用足够多的内容去提高爆款出现的概率；一旦某条视频跑出数据，就把它当成模板反复复制。

自带原创属性的产品，往往更容易冲出来。📕用户对原创的付费意愿更强，利润空间更足，红利周期也更长，别人想模仿也需要时间。比如小众挂件、饰品、手链手串，都符合这个思路。当然，纯原创有门槛，做“伪原创”也不是不行，重点是要好看、可爱、有特别感。
