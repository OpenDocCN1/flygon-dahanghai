# 亚马逊单干一整年：踩过的坑、赚到的钱和熬过的夜

文｜Lissa Tam  
2022年6月22日

提笔之前翻了翻日历，才惊觉“生财”这个社群几乎陪我走完了整段创业路。时间这东西真是不打招呼就溜走……我写第一篇稿子时，还在琢磨2020年到底适不适合做跨境电商；后来回去上班，再出来单干，一晃又满十二个月了。

我叫Lissa，电商科班出身，在跨境圈子里摸爬滚打了五年，2020年进了生财。在那里，选品这门手艺、商业思考的框架，还有跟焦虑和平共处的能力——都是慢慢练出来的，这点特别实在。同时也见识了不少亚马逊之外的新鲜玩法。

在那个圈子里，我对付焦虑的方式很土：把手头的事做扎实，承认自己就是个普通人，然后比别人多迈几步。

今天想聊的，是这一整年的小结。说“创业”听着有点大，叫“自由职业者”更贴切。主要分享四块：

1. 我的自由职业经历  
2. 我的营收模型  
3. 我的日常规划  
4. 以及关于“要不要创业”，我想说的一些话  

如果我能走到这里，那么在看的各位，一定可以做得更好。

## 一、我的自由职业经历

刚起步那阵子，别人喊我自由职业者，我心里是抵触的。因为我认定自己在做一件有价值的事，在经营一家有意义的公司。

眼里有光、手上有想做的事，这种人跟迷茫的人聊天，杀伤力很强——对暂时没找到自我使命的人来说，那几乎是一种致命吸引。我曾经也爱摆这种姿态，后来发现没啥用……按理说，“仰望方向”和“埋头赶路”并不矛盾，真正的问题是：手上的资源能不能把这两头连起来。

不到半年，现实就把我抽得没脾气。开公司第一要务：先活下来。

自由职业者也好，soho卖家、一人公司、有限责任公司也罢，核心都是赚钱。说虚一点：提供社会价值，换回酬劳；做得好，还能得到社会认可和奖励。

于是你们的Lissa林氧氧同学，越来越现实，越来越落地，越来越努力地成为一个合格商人。

### 为什么选择创业

2021年算是亚马逊创业泡沫破灭的一年。就像买股票，我买在了高点。真·别人恐惧我兴奋，别人兴奋我羡慕，别人转行我入坑·实锤。

我创业的原因，可能很多人想不到：因为一些不可抗力，我4月份离职了。当时其实也没想好要干什么。

我不是个安分的人。无论打工还是创业，我都在想怎么做出一个“作品”，而大部分工作短期内根本达不到这个目的。咱们卖货的，在公司首要任务是打正、给公司赚钱、创造利润。花钱试错这种事，不是每家公司都愿意让员工大胆干。

再加上成熟公司岗位分得细，大家都是螺丝钉，上下左右能对接的人层层分明。很多资源看着近在眼前，就像驴眼前的胡萝卜，看得到，吃不着。我急，急死了。

但很多事又急不来。

人在公司里，融进运转的机器之后，只能用时间建立强信任、证明自己，后面才有故事。我的性格偏偏不是能耐住前期寂寞、慢慢等的人。无聊的、一成不变的工作，只会让我麻木、停滞，这是我最恐惧的事。

我太着急，太想看到公司运转全貌，太想学更多东西。在亚马逊公司里，进步慢、成长慢，就算拿着稳定薪酬，我也每天焦虑。

朋友劝我：要不你就创业吧，省得每次有这个想法又不行动。反正你年轻，干脆全身心试一次，踏踏实实创个业；做得不好，再回来踏踏实实打工。

于是，我就创业了。

然鹅，创业之后，更焦虑了🥲。

### 我的创业历程

4月初开干，啥都还没开始，资料和店铺先损耗了3套。

天知道我踩了什么狗屎P。那段时间，我花了十多天在申诉上，跑水务、网电、物业、煤气局，收集资料，招商经理、客户经理能联系的全联系了，无解。

最惨的是货已经发出去了，店铺回不来，每个月还倒扣银行卡的钱，各种仓储费等等，一个月四五百。再加上物流出问题，2个月一直没到货，想移除都没办法，我硬生生又被扣了好多钱。

那段时间，我看起来就像个被下了咒的倒霉孩子，浑身乌云密布。

直到6月中，事情才慢慢好转。

我放弃了之前所有资料、店铺，以及店铺里的货，计亏损2万。找朋友借了一套资料，一切重新来过。店铺开好后，把处理好的货发走，这才正式开始。

我很清楚地记得，时间是6月16号，正好是去年的这个时候。

店铺稳定后，后面的选品、上架、运营，也就按流程稳步推进。

用2个月稳定基础端（店铺），用2个月跑出一个盈利产品并保持返单，剩下8个月重复“选品、拿样、采购、拍摄、运营”这个流程。从一开始货堆在客厅，到借朋友仓库一平方地，再到自己租仓库。库存慢慢变大，直到我的小仓库也放不下，里里外外堆满成品和半成品。

[PRE0]

今年3月我开始招人，从1个人到一个小团队。后面运营职业发展迷茫，选择离职转行，我又回到1个人的状态。今年亚马逊行情仍旧一般，我的产品属于下半年旺季，暂时也就没有再招人。等到7月份新品上架，再把团队拉一拉。

网上看到过一张创业公司曲线图：开始高歌猛进，奔向巅峰，然后急转而下，底部徘徊，接着一路坎坷，几近崩溃。其实很多创业公司走不到后面。所谓创业九死一生，拼的就是谁能熬到最后。

[PRE1]

涛哥之前在直播间讲过，创业其实考究一个人的耐受力。什么意思？好比挖井需要6个月，有的人只能接受干1个月没回报，挖一个月就走了；有的人能接受干半年没回报，前期埋头苦干，第6个月迎来增长曲线。

我是一个耐受力很差的人，只有不断得到强有力的正反馈，才能让我兴奋。

亚马逊呢，说来也简单：上产品、测试、销售。只要不断上产品，提高选品能力，然后快速测试、正常运作，盘子就能越来越大。

单一产品的天花板可能很低，但整体来看，卖货的天花板其实很高。

当然，如果能做垂直肯定很好，特别是有合作很久的供应链资源的时候。但如果没有，像我这样一穷二白的，直接做垂直，更适合多测试几个方向的产品，慢慢找到自己适合的类型，再去做垂直。说起来轻松，其中的时间花费也要一年以上。

这两天我实际上想明白了一件事：我可以慢慢开产品。往常目标是每个月2个品，现在甚至可以放慢节奏，每个月开1个品。如果每个品能做到月销2万美金，净利润15%，理想状态下，每年也有150万美金，一年能赚22万美金。这不比焦虑地上产品幸福得多吗？

卖得好，正反馈强，我就越兴奋，状态就越好。当然，这不是什么所谓的“长期主义”。在我的理解里，真正的长期主义，应当是在短期活下、活好之后，自然而然出现的东西。因为长期赚的钱肯定比短期综合赚得更多，才选长期哇！这都是账。所有的理想主义，都要在会计学的认可下，才能开始实践乃至实现。

焦虑是正常的，创业哪有不焦虑的。要选择和焦虑做朋友，适应它的存在，并友好地利用它，疯狂赶进度、赶DDL，这才是有效焦虑。今天看到新东方的带货视频，我也直呼卧槽。

他们说，没想到涨了好几万粉，以前直播间只有几百个人，也一直在坚守、在熬；痛苦是对的，它源于对现状的不满，痛苦才会让人想改变，痛苦就是力量；焦虑也是对的，焦虑是因为你想做得更好，说明你追求高；悲观是远见，乐观是智慧，意识到现在不够好、未来也不一定一帆风顺，本身就需要勇气、知识和智慧。

不管外界怎么样，我们继续做好自己的事情就好。只要我们保持持续进步，保持一直在场，珍惜并利用好每一分钟，即便是我回去上班，也能拿到更高的待遇和机会。

想到这，就没啥可慌的，继续造哇～

## 二、我的营收模型

诚如上文多次提到，做生意最重要的是赚钱，创业最重要的是活着。

亚马逊是一个相对很重的生意，前期我们不仅投入时间，还要投入真金白银。

这里我不得不说，生财虽然带给我焦虑，却也是前期让我支撑下去的核心。

刚开始创业那会儿，正好遇上生财2021年的纳新。我想着自己从没做过社群推荐，那就试试吧！于是在纳新开始前3天，开始推广、拉群，最终邀请了24人，赚了第一笔内部分佣，解决了前期的生存问题。再加上我在生财做过分享，拿过社群币龙珠。现金流紧张的时候，10K卖掉过一颗，又稍微回了回血。

一个人创业很孤独，很容易自我封闭。这就是有个社群能够交流的重要性：很多新鲜事、机会、新玩法、同频交流的人，都能见识到。这也是我创业时的重要信息源和知识库之一。

如果用《小狗钱钱》里下金蛋的鹅来定义我的投资及营收情况，那么我现在拥有：一只鸡，一群鹅。

鸡是我的自媒体板块，目前还是只小鸡。这只鸡的投资回报很高，只要我坚持每天给它喂粮，它就能持续给我下蛋。虽然更新不多，却也积累了一些忠实粉丝。

鹅是我的亚马逊卖货，目前有8只，有大有小，能够持续稳定地下蛋。但事实上，它的投资回报率比较低。这两年亚马逊物流费用飙得不行，所有的货只能走海运，原本投资回报只有50%，再加上仓库、海上压货，投资回报就只有25%了。利润太低，钱一直在货里滚，转不出来。

干了一年，在亚马逊上赚了不到五十万人民币，都在货里了。我可谓是纯纯搬砖人，赚了点社会给我发的工资，工种叫做“全球资源流转加速官”🫠

在我的规划里，跨境电商花费的时间占80%以上，主要集中在亚马逊上，通过重复选品循环，提高整体营收，来对抗单一产品生命周期变短的问题。

能找钱，会花钱，把钱运转好，计算现金流周转表，生意就能实现自循环，正常运转。

这里有个插曲。因为我实在对“招人”“做团队”这一块没经验，外加上我又十分要脸皮……我很怕招人进来后给不到对方对应的成长和想要的钱，因而一直在等自己准备好，再开始招人。创业公司，也是资源受限啊，钱给不到位，也就招不到什么好人才。

之前涛哥教我，要计算个人的时间成本。比如我一个小时值1000块，我去干80块/小时的活，我就亏了、浪费了嘛！

但是我脑瓜子那时候不是这么算的：我不是每一个小时都能获得1000块利润，那么在我剩余无所事事的时间段，80/小时也是赚哇！（不知道涛哥看到这个逻辑会作何感想，哈哈）

前阵子和朋友聊天，谈及个人成长，我原计划是未来要考MBA，大约1-2年以后。我用我的魔鬼逻辑🤏指一算：既然读MBA要钱，那么我不如提前把这个钱花掉，用来招人，于是乎我就可以把我的时间节省下来，去学习，去拓展哇！

我假设自己有了60万的未来预算，并把它前置，用在团队扩展上，提高综合生产力。而且人招过来总不能亏钱，我们假定他最多亏2个月（一般赚不回自己的工资都被开掉了嘛），那即便是我招2个人，也就最多亏个4万块。

但是我有时间拓展新的项目，我相当于花这个钱做了自我提升，这不比花钱报韭菜培训班强吗？这样未来我能读更好的MBA，有更大的成长空间哇～（朋友说虽然结论很离谱，但是魔鬼逻辑💯）

## 三、我的日常规划

有朋友和我说，想看我的日常，觉得我是时间管理王者，好像能做好多好多事。实际上并不然。

当亚马逊跑通后，我的流程基本上是：选品、拿样、确定产品方案、采购、拍摄、修图、剪视频、运营、补货。

大约是2-3周一个循环，偶尔遇到选品瓶颈期，则往后顺延。

可以给大家看一下21年刚创业的时候做的进度甘特图。

[PRE6] [PRE7]

选品是最让我觉得“好像每天都没有产出、无所事事”的一个环节，这部分以“选出来一个产品”为里程碑。

因为周期着实有些长，这让我感受不到什么反馈。

后来我就尽可能把量化颗粒度做细一点，比如一天要海选出XX个产品、一周做X个产品方案、一个月确定X个可量产的产品方案。

除了工作流程外，重要的还有数据分析和汇总。通过三方工具进行数据整理，自己再用Excel做个数据分析看板，用来追踪各个节点达成率。推新品也会有专门的推新记录表格。记录每日的销售数据、关键词排名、产品数据、流量转化率、新品日志等等，便于后续复盘，以及推新策略的可复制。

[PRE8]

大部分时间，我都花在选品上，预估占65%。产品花的心思比较多，在运营这一块，时间花费相对少一些。

在运营端，我目前只做效率最高、ROI最漂亮的事情：投广告。像post这些，之前招了人我是全部给运营在做的。这个对于我而言，是需要花时间、ROI还不错的事情，但我没有那么多时间和精力去做，遂排名靠后，时间不够我就不做。

新品我会每天都盯着，老品则时间节奏拉得比较长。

新品每天看排名、看销量、看广告数据，进行调整；老品一般一周看一次，统一调整。然后再一周统计一次销售数据，对齐销售目标。

看起来很多很琐碎的事情，拆分到天，其实也没有那么忙。比方说最近一段时间，我会睡到8点起床，在星巴克从9点待到12点，回办公室从1点待到晚上10点。推进了上个月两个要开模的产品，同时毙掉了上个月和这个月选出的品，目前正在为这个月的产品KPI发愁。

至于每天做的事，我偶尔在事情多的时候，会用印象笔记记录下来要干的事，然后对照着做（实际上大部分我都没办法当天完成）。更多的时候，我则按心情做事。

我是个拥有人类缺点“拖延”“懒散”“情绪化”的人，我没有办法100%克服，而正因如此，这才塑造了我的样子。

我属于“时间管理能力其实挺菜”，但我用“加班来凑”的人……

自由职业者贵在自律。自律使人自由，诚不我欺。

在我的时间管理方法里，我个人的理念是：时间管理旨在提高单位时间利用率，而不是时间总长度的花费。

我更倾向于“结果导向”+“聚焦”，这也会结合到精力管理。只有精力管理好了，时间利用率和效率才会变高。

作为创业者来说，时间维度是需要拉长来看的，至少得半年往上。创业是个长期的事，很多时候往往放弃，是源于坚持不下去了，而非破产倒闭。

在制作个人使用说明书的时候，我对小白@白一喵老师的话印象深刻：一个人的时间花费，决定了这个人是什么样子。

https://t.zsxq.com/037iuN7Mf（白一喵老师的原帖）

如果时间放长到周、乃至月，那么我一般是这样安排的：

1. 按照亚马逊项目流程进行工作，一般平均工作60小时/周  
2. 每周会文字复盘一次，2k字的文章，时间花费在1-2个小时；6k字及以上的文章，时间花费在8个小时  
3. 每周至少锻炼2次，一般是跑步/刘畊宏/健身房/羽毛球，平均3小时/周  
4. 每周休息一天，大部分时间追剧、看书，偶尔画油画；每2周/月会自嗨一次，一般是花一个小时愉快地唱歌  
5. 每月/2个月偶尔出去玩一次，一般是海边/爬山  
6. 每周喝2杯奶茶，一般是为了缓解焦虑（乱入）

生活看起来似乎平淡又枯燥，但也正常运转着。

要是说我有什么遗憾，我觉得最大的在于：我没有充分利用好自由职业者的“自由”——空间自由和时间自由。

随时随地的办公，去任何想去的地方旅行，做自己想做的事情。

我曾经幻想过，我或许可以过上数字游民的生活，像Jarod、Natalia一样，在东南亚地理套利，用极低的生活成本，享受极高的生活体验。跳伞、潜水，带着电脑，出入各种各样有调性的城市咖啡店；我或许可以过上房车自驾游的生活，像博主小墨与阿猴一样，花上半年时间，走到一个地方，停下来，住一段日子，感受生命的真实，体会大自然的馈赠……我也想过更可行的：每个月选择一个城市旅行，待上一周，找当地的三五好友小聚，体验不同的人文与生活方式。

当然啦，我每次想去的地点都是西双版纳，但每次实际的出行地点或者是准备地点都是杭州😂

最近一年甚至连杭州都不敢出发了。总觉得身上有好多好多事情，虽然也没有特别紧要、没有非要在周边，却也不敢怠慢，不敢离开。

卖货就是这样，或者说，我目前的模式就是这样。仓库每周/每两周都必须要去一趟，得看看，有货要处理、要质检；办公室总有样品寄来，得拿到手感受。我自己甚至还想了个歪招儿，把仓库搬回老家，让我爸妈帮我看着，帮我质检发货。然后我就可以愉快地玩耍～哈哈哈！（只能想想）

不放心手头的事，又觉得总会慢慢做大，要招人干活，因而也没有自由职业者的自由，这也就让我慢慢困在这一公里内了。

这是我的困境。我不清楚，这是不是大多数个人创业者的困境。

### 关于是否要创业，我想说的

最后一个话题。因为销售行业的特殊性，我发现好多运营/开发都会选择出来单干。再加上网上各类博主的吹嘘，很多老板们也在寻求增长，想要入局跨境电商。

但看完我这一年，至少该先问自己几个问题：能不能接受先活下来？能不能熬过长期没反馈？能不能把账算清楚？创业不是逃离上班的捷径，它只是另一种更硬的功课。
