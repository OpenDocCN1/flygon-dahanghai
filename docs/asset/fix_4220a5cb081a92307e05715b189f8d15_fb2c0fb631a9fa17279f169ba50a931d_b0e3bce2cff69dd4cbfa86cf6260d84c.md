# 跨境11年，10条供货避坑心得

我是竹叶三十，做跨境供货这行已经第十一年。本科、研究生阶段读的都是相关专业，老师是马士华——很多学校用的《供应链管理》教材就是他编的。后来去中兴做采购计划，第一年手上经过十几亿采购额。再往后自己出来做跨境，主攻服装和小日用品，货源多在浙江，铺货和精品两条路都跑过。

今天分享一些踩坑后的总结。不承诺帮你做出爆发式增长，只希望在“少亏钱”上给点提醒。如今这环境，少亏当赢。

**1. 零断货未必健康**

采购本质是猜需求，猜就有误差，不是多备就是少备。若你长期不断货，大概率是备多了。那种“绝不缺货”的采购，反而可能让公司背最多损失，准时制模式除外。健康状态是断货和积压都允许存在，只要幅度可控，别追求极端。我曾在一家通信企业见过同事为保项目零断供，把成批设备发到埃塞俄比亚，剩余电池长期露天堆放，最后十亿级报损，全公司折腾一年。老板们也别下“100%不断货、100%零库存”的死命令。

**2. 卖得越猛，越要防上头**

销量最旺时往往最危险，因为销售端容易冲动。2017年黑五前两周，一款货冲进大类前100，日销两三千件。我兴奋地让采购下十万件，采购提醒可能过量，我回邮件说风险我担。结果货到销量掉头，十万件清到2020年。还有一家家居大卖，销售额涨十倍后把十万张桌子发到美国，后来每天只出一张，资金链被压断。销量陡升时，先问自己：这股势能能撑多久？

**3. 第一单成交后，补货就得有公式**

别拍脑袋。最基础的算法：日均销量乘补货周期，等于这次该下多少。理想状态是上批刚售罄，下批到仓门。周期起点看平台允许的最长发货时限，再结合每次下单的固定成本做微调。用表格算，不要凭感觉。

**4. 物料清单要拆细，采购节奏按周推**

物料清单拆到实际采购颗粒度。它一是给下单做导航，二是把资料沉淀成公司资产。我做过手工蝴蝶结，行业里没人细算织带用量，通常整卷起订，成品多少收多少。我自己做了用料计算表：每个用红带3寸、白带1寸，十个就是30寸和10寸。后来谁都能按表算料，我能一打起订，吃了几年先发优势。采购计划则按周滚动：每周算需求发给工厂，要求分批交。工厂一开始会乱，常抱怨同一款上周第三道工序没完，这周又排第一道。坚持后，生产周期和库存都降。

**5. 压货是电商大敌，别为折扣冒库存险**

一次多买能拿好价，但小批量带来的少压货价值，通常高过折扣。潮品过季就难卖，电子品不断换代，家居品也会被同行和需求变化追着跑。国内产能充足，折扣空间有限；好价格还能靠关系、谈判、饭桌沟通争取。

**6. 柔性供应：借小厂之力，盯紧进度**

体量不大时，柔性靠两招：小厂和跟催。大厂流程稳、交期质量可控，但靠大单养，小单容易接不住；要柔性，得敢放弃大厂、联合小厂。Shein早期就是大量广州小厂托起来的。跟催就是高频追踪。我在上一家公司学到的第一课：马来西亚前线要7天出货，标准周期28天。原料齐，我就逐环节催仓库、催调拨、催产线，电话不行就上门，最后七天出货。我的口头禅是：进度是催出来的。

**7. 小厂要带教，不是签完合同就完事**

小厂能力有限，得由主导方带。它们常只会做货，备料、排产、管理都粗放。我们帮做送货单、陪找原料、对接供应商、教周计划。让它们愿意配合，一是订单量占其产能三成以上，有话语权也有弹性；二是挑有成长意愿的老板。被带顺后，它们也会觉得体系更顺。自己开厂更可控，但招工难；我在eBay裙装细分曾做到第二，后来被自建工厂的赛维超过。

**8. 海空运和海外仓，要算总账**

选运输方式别只盯运费，要把资金周转和销售节奏一起算。eBay虚拟仓比海运贵三四倍，仍有人用，因为周转快、综合回报高。快递到空派再到海运，运费递减，资金占用和风险递增；三柜分布——本地、海上、国内——风险不小。

**9. 物流商别只看报价，建个池子更稳**

我很少因低价换物流商。稳定可靠比价格、服务更关键。曾有个创业小伙价格低、天天来仓库帮忙，结果把货拉回家拆外箱、分包装、折盒子赚体积差，英国客户投诉后我才知道。此后只找本地有仓的知名公司。长期价格用池子：每条线三家，每天报当日报价，发最低价并告知规则。

**10. 把供应端当长期盟友**

链条不是零和，不是一锤子买卖，而是一起进步。我的生产和物流知识很多来自供应商，也会开放管理文件。共同赚钱才能长久。最后打个广告：我在筹备TikTok端的供货服务，欢迎短视频、直播朋友私信聊需求。

**评论区**：郑小焦留言说，九月见流量起势，为冲圣诞连续补货，结果销量没跟上，货压在平台仓和自家仓，按眼下速度还能卖三个月，只求别再生变；卷毛娜小姐也说，备货时容易看到爆单就追加，仓库还躺着一堆库存。另有几位读者留言交流、要联系方式。
