# 10.4 场地怎么选

1. 创业非必要不租办公室

不少热血青年拿着东拼西凑的几十万资金，事情没做成，钱却亏完了，很大一部分花在了办公室上。办公室再好看也不是自己的，而且好看和业绩没有关系。创业初期省钱才是王道，别为了面子。把钱花在搞流量上，才是最重要的。建议先改造自己家、租居民楼或商业公寓，用最低成本运作起来，只要一条网线就能开干。

2. 业务起来了，需要写字楼

找写字楼怎么避免踩坑？

1. 办公楼租赁按月计费，但一般至少签1年，也不能长签3年以上，业主通常不会同意，或者会要求一定幅度递增。价格常见“包票”和“净到手”两种：包票是租金里已含租赁税发票，净到手是不含。要问：起租期多长？租金含不含税？增长幅度多少？

2. 还有管理费（物业费，按每平方米每月算），要主动问。行业里20元以下的多数没有中央空调，或者中央空调费另计；20元以上的多为中央空调。管理费通常包含公共部分水电维修保养、清洁卫生等。要问：物业费多少？是否含空调费用？电费多少一度？网络费一个月或一年多少？联合办公的租金一般包含物业费、水电费等所有费用。

5. 每栋写字楼的中央空调开放时间不一样，很多有时间限制和月份限制。极少24小时供应，大部分只在上班时间供应（多为8:30-18:30），加班可能要付加班空调费。少部分可以自己装独立空调，如需加班或不想用中央空调，可以问能否安装独立空调。要问：空调时长多少？能否自己调控？能否安装独立空调？

6. 互联网公司经常通宵，但写字楼内不可以住宿（有商务公寓的除外），也不可以明火煮食，微波炉可以用。也有复式写字楼可以居住或商住两用，这些都可以主动问。要问：是否能住人？

7. 停车场怎么收费也要了解，老板和员工一般办月卡，主要问月卡多少钱一个月。承租面积大的客户，有送1-2个免费停车位，记得争取（个人业主除外）。要问：停车费一个月或一年多少？按年有没有优惠？临停多少一小时？日封顶多少钱？

8. 如果是毛坯办公楼，记得向业主要免租期，1-3个月不等，具体看面积和装修风格需要的时间，可以商议。哪怕是带装修的，也会有1周左右免租期，搬办公室也需要时间。要问：免租期多长？

9. 租赁期递增：租期超过一年以上，一般会有不同程度递增，通常从第二或第三年开始月租金递增5%-8%，个别大厦连管理费也一起递增。要问：租金涨幅多少？

10. 合同签订：以上都了解清楚并谈妥后，预约时间签合同。要弄清楚是跟业主签，还是跟二房东公司签。一般来说，大业主和二房东都比较好说话，很多事情可以找他们帮忙。要问：你们是大业主、二房东还是小业主？

11. 办公楼租赁还有定金环节。很多情况不允许直接签合同，下定金是最好的折衷办法。一般定金下了以后，业主反悔需要双倍返还。

常见问题总结：

1. 起租期多长？
2. 租金含不含税？
3. 涨幅多少？
4. 物业费多少？
5. 是否含空调费用？
6. 电费多少一度？
7. 网络费一个月或一年多少？
8. 空调时长多少？
9. 能否自己调控？
10. 能否安装独立空调？
11. 是否能住人？
12. 停车费一个月或一年多少？
13. 按年有没有优惠？
14. 临停多少一小时？
15. 日封顶多少钱？
16. 付款方式怎么付？
17. 免租期多长？

# 十一、投流放大

章节概要：

小红书虚拟店铺投流主要涉及两个平台：乘风、聚光。乘风专为电商设计，适合直接促进销售转化，应用场景包括商品推广、笔记加热、直播预告等；聚光主要用于信息流、搜索等广告触达用户，应用场景包括内容种草、后期想引流做客咨收集等。投流要花钱，这里不作为必修内容，有预算和经验的伙伴可以尝试。

# 11.1 乘风

小红书的乘风工具从2024年9月开始全量公测。刚出来时比较粗糙，很像把聚光的电商投放板块单独拆出来，投放效果也一言难尽。本质原因是小红书电商板块GMV太低，很多用户没有电商行为，用户数据积累少，人群画像不精准，所以投放效果不好。2025年比刚上线时好了一些，但仍不够理想。预计等小红书电商GMV达到抖音的1/10时，乘风投放效果可能会不错。所以新手可以先不着急投放。详细乘风投放手册自取：https://doc.weixin.qq.com/doc/w3_AfEA_waPAH4gCVL1rebSQy1UTwTlo?dver=

# 11.2 聚光

# 11.2.1 先算投放成本

投聚光要先算投入产出比。投聚光获得私信豁免权，需要日消耗100元以上，并且投流第三天才可豁免，同时要持续投放。也就是说，每天成本是100元。拿小学资料项目举例，快到期末时转化率是20%-30%。假设按20%算，客单价49元，一天引流15人：15×0.2×49=147元，大于投流成本100元。所以一天至少引流15人才能覆盖成本。假如一天引流100人：100×0.2×49-100=880元GMV。

因此，要不要投放，要看自己的内容制作能力和引流能力。引流能力很重要：投放时是无缝衔接直接发微信引流，而免费流有各种折损，还会吞微信、吞图片，100人问，真正能引流过来的可能只有20-30人（实测数据）；使用聚光私信通可以自动发微信，100人问，来的人为80-100人（实测数据）。综合以上计算，以小学资料为例，在没有封号的情况下，不用聚光一天能引流6人以上，则开通聚光大概率能回本，也就是有价值开。第一个计算一定要掌握，一定要根据自己产品的客单价、转化率来算。聚光另一个大作用是信息流投放，但这种玩法适合高客单产品，获客成本一般几十元一个人。我们做小学教辅虚拟资料，主要是要私信豁免权，信息流玩法不必关注太多。

# 11.2.2 投放渠道

官方渠道要求5000元起充，可以找官方渠道：小红书聚光平台。

# 11.2.3 投放门槛

做聚光投放需要蓝V号，也就是说要注册一个个体户营业执照，然后花600元开通蓝V，才可以投放。个人账户现在做不了聚光投放。做小学教辅，需要办理出版物经营许可证，认证图书号，出版物经营许可证在淘宝上办理大约1800元。成本大家自己核算，有预算的伙伴可以尝试。

# 11.2.4 私信通开通条件

针对做引流的人，这个功能最大的帮助是：消费者打开与你的私信对话框后，会自动弹出一段话，这段话可以设置为你的微信，比如“这里发不了电子版资料，加我微信：xxxx”。这个需要消耗满1000元，然后每周二会自动开通，叫私信通。

# 11.2.5 投放策略

一个广告账户只能绑定一个蓝V账户，也就是说其他矩阵账号获得不了私信豁免。我们可以做1个广告账号，矩阵操作几个普通号，比如5个普通号，在这些普通号的简介上填：需要资料@（蓝V号）。这些矩阵号不回复任何私信，不评论任何评论区，只在个性简介处写一句“需要资料的找@（蓝V号）”，这样能把投聚光的蓝V号最大化利用。
