# 1.2 项目：先讲清，再拆透

这一节要做的，是把一个项目从“模糊印象”拉到“清晰判断”。先介绍，再分析，顺序不能乱。

介绍部分，重点回答三个问题：这个项目是什么，为什么要做，准备做到什么程度。把背景、目标、范围、关键角色、资源投入、时间节点和核心指标讲明白，让读者不用猜。介绍不是信息堆砌，而是用一条清楚的主线，把项目的基本盘交代到位。

分析部分，则是在介绍的基础上继续往下走：值不值得做，能不能做成，风险在哪里，成本如何控制，优先级怎么排，落地路径是否可行。分析不是套术语，也不是罗列优劣，而是围绕关键假设和关键数据，把判断依据摆出来，把不确定项标出来。

一句话概括：介绍负责让人看懂，分析负责让人做判断。两者衔接起来，项目才不是一份说明书，而是一张可执行的行动图。
