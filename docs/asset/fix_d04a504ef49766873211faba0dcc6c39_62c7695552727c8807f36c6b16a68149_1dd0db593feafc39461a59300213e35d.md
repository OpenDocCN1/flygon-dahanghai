# 1.1 快团团：私域开团入门

想在微信里把熟人生意做起来，快团团算一个常见入口。它由拼多多推出，本质上是一套服务私域场景的拼团小程序：发起活动、汇总订单、在线收款，都能在手机上完成。

更具体地说，它向开团者开放了一套连接货品与顾客的工具。进驻不交钱，发起团购步骤简单，平台服务成本低，还能统一管理订单。帮卖、报名、店铺、团购、直播以及订单处理等能力也都齐全，使用本身不收费。

[PRE0]

它真正放大的，是微信关系链里的信任资产。熟人圈子里，每位组织者往往都是一个小型关键推荐人。

和淘宝、京东、拼多多店铺那种纯交易场景相比，这里的组织者更像微信好友圈里的挑货达人。重点不在单次成交，而在信任建立后形成的高复购与长周期黏性。把微信视作舞台，它就像一个开在熟人圈里的带货现场；你承担选品和服务职责，角色类似公开平台直播中的头部主播，只不过服务对象是自己的群友，最终让圈层的商业价值释放出来。

手里已积累微信好友或群资源的人，可以借它反复激活存量关系；团购页生成后，转发到个人动态或聊天群就能扩散。

• 开团要不要先注册？

不用另开账号，授权手机号就能开始。

• 使用过程要付费吗？

团长端的功能不设使用费，也不收年费或佣金抽成。真正产生成本的是顾客付款环节：微信支付通道按成交金额的千分之六扣费，这笔钱由供货方的大团长承担。

[PRE5]

• 有没有电脑端可用？

有，网页入口为：https://ktt.pinduoduo.com/

[PRE6]

在电脑浏览器里，发团、上新、批量导入或导出各类订单、录入运单号、打印面单并发货都会更顺手。PS：帮卖团长不用电脑端也完全不影响。

• 顾客付款后，钱何时能到？

这取决于团购发起人的结算配置。有些供货方选择人工发佣；如果没做这项配置，系统会按自动模式把佣金打入帮卖团长的账户。

自动模式下，订单一完成付款，佣金即进入帮卖团长的快团团余额，可马上申请提现至零钱或银行卡，平台不收提现手续费。

到账与额度规则：

• 零钱渠道：单日上限3000元，实时入账；
• 银行卡渠道：单日上限5万元，9点至23点之间5万元以内秒到，其他时段按T+1处理。
