# 程序员做录播课，月入 5W+ 的细分打法

作者：鱼丸｜亦仁助理

抖音商业 IP 大航海 2.0 已经开船，不过不少圈友时间排不开，没法一路跟学。没关系，这一期「生财合伙人」请来 @突围一只鹰，聊聊知识付费的另一条入口：录播课。

直播课要迁就学员时间，录播课却能把同一份时间反复卖，覆盖人数自然更大。多数垂类录播课的收入上限在百万级，谈不上惊人，但对个人来说仍是好选择。

他会以细分 IT 录播课为例，拆解一门爆款课从制作、售卖到交付的全过程。领域虽小，课程制作、销售和售后逻辑却相通。如果你正在找一个时间效率较高的副业方向，这篇会给你答案。

**—Part 1—**
录播课，适合当副业吗？

我判断好副业有三条：

第一，收入空间要够大，长远看有机会超过本职。
第二，能和本职互相成就：本职经验给副业优势，副业影响力再反哺本职。
第三，能长期做，有积累、有复利。

录播课恰好对得上：

1）同一份时间能卖出多次。垂类课收入天花板多为百万级，对个人仍然划算。
2）能打造个人 IP，提高你在技术生态里的位置，也会增强职场竞争力。
3）教育需求会长期存在，只要内容顺应趋势，就能持续做。

如果你也是程序员或技术类从业者，这条副业很适合：既能增加收入，也能推动主业，甚至超过主业。

**Q：我怎么走上录播课这条路？**

本科毕业后，我一直做软件开发。平时写技术博客，把工作问题和新技术记录下来。博客里常有人问很基础的操作，比如某功能入口在哪、某设置怎么改，还有人直接问：博主有没有视频教程？

起初我没当回事，不觉得这是风口。后来发现图文有局限：自己写作能力有限，表达常不够准确；而我学新技能时也更爱看视频。于是慢慢意识到视频课的优势：图文是有选择地讲，难免漏；视频能记录完整操作，学习者照着步骤模仿，能少踩坑。

2018 年初，我录了一个短教程，定价 38 元，上架腾讯课堂（抽成 10%），反响不错，头几个月每月有一千多元。我当时想，要是录 100 门，每月不就 10W？当然是想得太美，原因后面说。

2018 初到 2021 底，我共做 50+ 门课，在售 20 门；靠全网多平台自然流量，月收入稳定在 5W+。

**Q：对讲师有什么硬要求？**

门槛没想象中高。类似你平时给新同事讲你负责的东西，再加一点精炼即可。大致需要：

1）有一项熟悉的技术或项目。熟悉即可，不必难度很高。优秀高中生能教小学初中，所以别怕自己不是专家。不是非得成为罗永浩才能直播带货。大作业、课程设计、自学技术，或商业级实战项目、专业系统课，都能做成课。
2）正常表达能力。
3）会视频剪辑，不会可以学。视频要精炼，别发未剪辑版，把无关内容剪掉，替用户省时间。

看到这里，你大概能判断录播课适不适合自己。下面一起做第一门课。

**—Part 2—**
一门录播课怎么做出来？

爆款课第一步，先回答：别人为什么买？你的课要帮学员解决困难、完成工作、找到更好工作、赚更多钱；你从他们收益里分一部分，课程才能越做越好。让买课的人高效学会技能，进一步帮他们解决问题、求职、升职加薪。这是原则，遇到问题就回到这句话。

第一步：选题

2018 年初第一门小课尝到甜头，我打算疯狂录课，一年 100 门。于是拍脑门定题、上架，定价都在 200 元以内。结果随后 3、4 门销量很差。还发现产量跟不上：第一门虽两三天录完，但前期准备很久；一年 50 门都很难。

产量上不去，只能抓质量。我分析卖得好的课，有两个原因：

1）踩中热点。那门课是微信跳一跳小游戏教程。后来几门既没热点，也忽略市面已有同类课，而且对方有数据和评价支撑，我的课没差异化，学员自然选别人。
2）人群精准。当时误打误撞，后来才明白，80% 买这类小课的人是为了完成课程设计；课程内容、难度、价格刚好匹配。

所以，录播课能不能赚钱、赚大钱，选题占一半以上。选题对了，后面事半功倍。这是决定成败的第一环，怎么强调都不过分。

一、选题类型

先了解四类课程：

1. 0 基础入门课
面向小白，核心需求是快速入门。知识点要讲细，否则答疑压力大。这个阶段，学员不主要买视频，而是买一个能随时答疑的老师。讲师不必技术背景很强，现学现卖也行；把官方图文教程用视频演一遍，也有人买。
缺点是门槛低、竞争激烈，B 站免费基础课很多。
机会在新兴技术：国内暂无系统入门课，早期从国外网站学习并用中文重新演绎，在垂直领域站住脚，也能有不错收入。缺点是早期技术变化快，是把双刃剑：没人做时你能快速占市场，但维护成本高，录制中技术可能就变了，学员跟着学问题多，答疑压力大。想做长期被动收入，我不推荐这类选题。

2. 专题进阶课
比如《0 基础入门 Excel》是入门课，《如何在 Excel 中使用 VBA》是专题进阶课。面向有基础的人，需求是解决工作问题、增强竞争力、争取升职加薪。大课客单价可以较高，但要求较强技术背景，对专题很熟。

3. 项目实战课
优势是：两门课技术点大体相同，用不同实战项目串起来，就能当两门课卖。主要定位三类人：
在校学生：项目当课程设计作业。内容不用多，重点不是技术讲解，而是跟着视频能把项目做出来。对价格敏感。
应届毕业生：项目当毕业设计或求职作品集。内容相对完整，有一定难度，符合最新职场技术方向。对价格不太敏感。
求职者：项目要写进简历。内容完整，看起来像商业项目案例，有较多技术难点，能经得起面试官提问。对价格不敏感。

4. 系统就业课
面向应届生和求职者。目标是掌握技术达到岗位要求，通过笔试面试找到工作。内容完整、系统化，既讲基础原理，也含实战项目；涵盖前三类内容，但不是简单拼凑，而要系统设计。

二、选题原则

我总结四条：

1. 力出一孔
尽量集中精力做一门优质大课，比如项目实战课或就业课（有信心可以包就业）。为什么？学员对低价课和高价课的品质、服务要求一样；低价课客服答疑成本不少，算总账未必赚钱。5000 元左右的高价课，一方面减少精力分散，另一方面收入足以支撑你把课程各方面做好。

2. 选题查重
选题基本确定后，一定去市面查类似课程。若有，想清楚差异点、竞争点：用户为什么买你而不买友商？没有明确答案，就放弃。

3. 强获得感
学完后，学员要能跟着做出实际案例，能用于学业、求职或升职作品。这样才有获得感，不会学完什么都没留下。

4. 蹭热点
尽量跟当下热点，获得流量加持，但别为蹭而蹭，核心还是课程内容。比如《原神》火，可出《原神渲染实战课》，核心仍是渲染技术；拼多多火，可出《从 0 开始开发一个拼多多 App》，核心仍是 App 开发技术。技术是内核，项目只是外壳，外壳能换，内核要稳。
同时避开“选太早期、变化太快的技术做教程”。那是双刃剑：早期没人做，你能快速占市场，但维护成本高，录制中技术可能变化，学员问题多，答疑压力大。

三、选题步骤

1）按技术储备定大方向。比如擅长 Android，就定 Android。
2）定位目标用户：课程卖给谁，解决什么问题（学生课程作业、毕业生就业、在职人员转行等），基本确定课程类型。
3）用数据驱动选题法，找出 20 个高关注技术、项目作备选，依次执行 4-7 步。
4）搜索引擎查有无类似课程。有且与目标用户冲突，排除。
5）评估主题技术范围是否力所能及。是，选用；不是，下一步。
6）范围太大，评估能否缩到能力圈。比如讲不了《拼多多系统架构实战》，可讲《拼多多 iOS App 开发实战》。能缩小，选用；不能，下一步。
7）评估能否现学现卖。很多技术自学后录视频二次演绎效果很好，因为你能从初学者角度讲。能，选用；不能，放弃，回第 2 步。

拿到选题后，就可作为课程设计题目。举几个例子：刚入门，可从初学者视角做 0 基础课，这种视角技术大牛很难做到；研究很深，适合专题进阶课；项目经验丰富，适合实战课；在技术岗位超过 5 年，适合系统就业课。

**Q：什么是数据驱动选题？**

找你想录课技术领域里规模最大的公众号，扒最近一年推送数据，分析阅读量、点赞量、转发率最高的文章。程序员当然不手动扒，写爬虫。不熟爬虫，可用新榜、拓途数据的公众号回采服务：新榜贵些，拓途数据 500 篇 30 元；还嫌贵，去某宝搜“公众号回采”。同理，分析博客网站、课程平台数据，看当下热门，更看几年都热门的话题——这类技术关注度长期高，课程更不易过时。还有一个来源：找在线课程平台的类目经理，他们有一手实时数据，能给选题建议，参考价值大。

四、选题验证

选题完不要马上制作。要验证用户是否真感兴趣、会买，同时找种子用户。怎么做？

按选题写一篇相关图文教程，内容包含选题中的部分知识点。文末留 QQ 群号（XXX 技术交流 Q 群：1234567XX），发到 CSDN、博客园、知乎、简书等技术博客，也分享到你加入的技术群。感兴趣的人会加群。连续 3 天在群里讨论相关技术，第 3 天分享课程大纲，看反馈；第 4 天发布预售，1 元定金（上线后可抵 XXX 元）。如果入群到交定金的转化率超过 20%，说明选题真有需求，可以制作。

选题验证就是用真实用户反馈确认不是一厢情愿，并积累种子用户。这用到精益创业的假设验证法，避免产品做出来才发现没人要。先做假设：项目成功有许多先决条件，这些条件就是假设，验证成立，项目才可能成功。再验证，成本从低到高：常识 < 数据分析 < 调研 < MVP。这个话题后续再详述。

第二步：课程设计

选题验证过，也有种子用户，就可以设计课程。先查资料、找对标，还是先写大纲？都是必要环节，但我觉得最先做的不是这些。

一、先定价

最开始是定价。你可能会诧异：什么都还没有，怎么定价？

定价不是收尾动作，而是产品设计的起点；价格一变，产品形态也会跟着变。

同一瓶洗发水，定价 20 和 200，产品方案完全不同：卖点、包装、渠道都不一样。所以选完题，结合能力先做初步价格预估。同一选题，做 200 元小课还是 2000 元大课，设计一定不同。200 元小课可能只含主题知识点，很少延伸，约 10-20 小时；2000 元大课内容更丰富、系统化，还提供答疑、督学、直播加餐等增值服务。但记住，不同价位用户对质量和答疑的需求差别不大。有能力建议多做高价课：引流、服务成本几乎一样，高价课能让你更专心提升内容质量和服务。

如果对能卖多少钱没概念，可参考：

1）看同类型课程定价格范围，上架先用较低价格试验（早鸟价、首发价），后续逐步提价。
2）独有课程、差异化大且刚需，可定高价，甚至过万元。
3）按课程给学员带来的收入增量定价，比如学完包就业 8K 以上，可收 1-3 个月薪酬，即 8K-24K 学费。

二、大纲设计

大纲设计和优化贯穿制作全程。初版可按以下步骤：

1）用思维导图（我用飞书文档），先不查资料，拍脑门列出选题要讲的内容点。
2）验证这些内容点能否支撑目标用户需求和课程定价（不确定就去课程平台搜，对标相近价位同类课）。
3）不能，就扩展内容点或增加实操案例。
4）细化大纲思维导图。有些实战课可直接拿思维导图录课，不必额外做 PPT。
5）开发大纲中的实战项目。

三、课程制作

一般包括：

1）PPT 制作。是否做 PPT 看内容：理论多，建议 PPT 图文搭配讲解；实战项目少讲原理、多操作，可直接用思维导图大纲串课。PPT 尽量别放二维码等，有些平台审核严，严禁站外导流。
2）配套实战项目开发。
3）几篇图文干货，用于图文平台推广。
4）几节试听课：为什么学？讲问题、技术背景、前景、学完收获（升职加薪等）。能得到什么？展示本节课直观最终成果，比如实战课最终成品。为什么跟你学？用一两节吸引人的课程内容。

四、录制

录课所用技术版本尽量用最新稳定版，优先最新 LTS（长期支持）稳定版，因为企业常用 LTS，BUG 更少。用最新版还能保证课程寿命，不会因技术过时过早淘汰。
