# 别再让AI替你思考：一份真正落地的内容创作实操手册

AI写作的短板在哪里？

真正有深度的原创洞见、第一手的行业数据、高度个人化的情感表达，以及复杂的因果推演——这些恰恰是AI难以胜任的。所以更聪明的做法是：核心观点和你的个人洞察由你来把控，把结构梳理、措辞打磨和逻辑串联这些活儿交给AI。

# 原则五：吃透“提示词设计”这件关键事

AI输出质量的高低，很大程度上取决于提示词怎么写。这项技能值得刻意练习。

一条高质量的提示词，通常包含四个要素：

1. 任务与目标清晰化：写什么内容、面向哪类读者、希望达成什么效果；
2. 交代背景信息：行业环境、受众画像、发布渠道；
3. 划定限制条件：文风偏好、篇幅要求、格式规范；
4. 引导输出框架：建议的结构、段落安排、视觉呈现方式。

升级版提示词公式：基本指令 + 背景信息 + 限制条件 + 结构引导 = 高质量产出

# 原则六：用“角色扮演”拉高专业水准

让AI代入某个特定专业身份，能明显增强内容的专业感和可信度。

操作要点：

让AI以该领域行家自居，比如“假设你是一位从业二十年的营养学专家”；

也可以同时指定几位不同身份的专家，帮你拿到多维视角；

再搭配特定的分析框架，例如“请用SWOT模型展开分析”。

角色设定模板：

请你以[专业角色]的身份，借助[分析框架]，就[问题/主题]展开分析。行文需体现[专业特征]，同时兼顾[受众诉求]。

# 原则七：用好“指令分层”这个方法

[PRE0]

把复杂的创作任务拆成有层次的指令，保证每个环节都被细致打磨。

三个层次的指令结构：

1. 战略层：整体目标、核心定位、关键成果；
2. 战术层：内容架构、论点编排、表达策略；
3. 执行层：具体遣词、句式变化、修辞运用。

实操路径：先用战略层指令搭出框架，再用战术层指令补全结构，最后以执行层指令打磨表达。

# 原则八：搭建属于自己的“提示词库”

[PRE1]

用得越多，越要有意识地沉淀和迭代自己的提示词库，逐步形成一套个人化的写作系统。

提示词库里可以放这些内容：

常见内容类型的模板化提示词；

针对特定平台的风格指引；

用于润色和优化的专用提示词；

成功案例的完整提示词存档。

成长路径：从通用提示词起步→按需调整适配→记录实际效果→提炼规律模式→沉淀为个人提示词库。

希望这套AI内容创作实操手册，能帮你真正把AI当作创作助手用好用足，逐步构筑起自己的内容创作护城河。

请记住最关键的一点：AI是放大你创意的工具，而不是取代你创造力的技术。掌握这些方法之后，你就能腾出更多时间投入真正的创意思考，让内容创作回归它的本质——连接、影响与启发。

# 4.2 用AI作图

# 4.2.1 AI作图实操要点

提示词其实就是一小段文字，或者一句用自然语言写成的描述，用来让AI生成图像，整体操作并不复杂。

正式开始动手之前，先摸清几个操作要点。

提示词撰写注意事项：

1. 凡是跟你需求相关的背景和细节，尽量说清楚；
2. 把注意力放在你想要的内容上，多描述“要什么”，少描述“不要什么”；
3. 一些专有名词AI可能理解不了，换成更通俗的说法来解释。

通用提示词公式：

# 💡

公式：Subject + Style + Setting + Composition + Lighting + Additional Info

译成中文：主题 + 风格 + 环境 + 构图 + 光照 + 附加信息

（前三项最为关键）

1. 风格

需要交代：你偏好的风格或时代感。

2. 主题

需要交代：核心对象（人物、物品、动物等）的特征，包括外观、颜色和独特之处。

3. 环境

需要交代：场景位置（室内、室外、虚构空间）、环境元素（自然或城市）、时间与天气状况。

1. 构图

需要交代：视角选择（特写、广角、航拍）、拍摄角度以及具体的取景偏好。

2. 光照

需要交代：光线类型（明亮、昏暗、自然光）、情绪基调（愉悦、神秘）和氛围效果。

3. 附加信息

需要交代：次要对象、角色、动物，以及它们与主体的互动关系或相对位置。

7. 确定形象风格（以写实为主）

选择合适的背景（纯色背景或模糊的专业环境）

Step 5: 形象一致性优化

1. 在基础提示词模板上迭代修改

人物核心特征描述保持不变（年龄、性别、发型等）

摄影风格描述保持不变（确保一致性）

2. 用即梦的变体功能（如果有）尝试不同表情

核心描述不动，只改表情部分

例如把“表情自信专业”改成“表情温和亲切”

3. 检查生成结果的一致性

确认不同表情、不同场景下能认出是同一个人

持续调整提示词，直到一致性满意为止

进阶技巧

4. 写实风格提示词技巧

使用专业摄影术语：“人像摄影”“商业人像”“自然光人像”

描述光线效果：“侧光”“蝴蝶光”“轮廓光”

5. 一致性保持的核心要点

最重要：人物特征保持一致（发型、脸型、标志性特征）

第二重要：摄影风格保持一致（色调、光线、质感）

第三重要：背景环境风格保持一致（即使场景不同，处理方式相似）

6. 形象迭代优化方法

记录成功生成的完整提示词

只改动需要变化的部分，其他原样保留

对比检查新形象与基础形象的一致性
