# 30天卖课60万，私域里藏着哪些关键动作？

大家好，我是宋老师。知识付费这行，我做课、卖课已经两年多。过去一年，六千多名知识博主曾与我交流取经，我的私域里也聚拢了近三万名知识博主；靠短视频加私域，单月收入做到接近七位数。今天先拆解一位知识博主的私域操作细节——把课程放到私域里成交。

我会结合自己的实战，围绕三个问题展开：做知识付费的老师，为什么非经营私域不可？怎么在私域里快速把成交推起来？还有哪些细节动作最容易被忽略？
