# 自媒体十年，我踩过的坑和攒下的经验

嗨，我是 Crossin，做的是“Crossin 的编程教室”，主打 Python 教程和案例。这篇东西是 2023 年 6 月 15 日应小灰老师之约写的，聊聊我做自媒体的那些事儿。

干这行满打满算十年了，本来没打算这个节点写总结。原因也简单：眼下公众号的流量跟前两年完全没法比，再加上一些私事缠身，我基本处于“能更就更、不能更就歇”的状态；而且我正往视频方向摸索，流程和方法论都还没跑顺。所以此刻既不是成功学样本，也算不上失败教科书。不过既然话赶话聊到这儿了，就随便扯扯吧。

先交代一句：下面不少情形跟今天已经大相径庭，同样的路数现在很难复刻，没兴趣的朋友可以直接翻到最后看建议部分。

## 一、我的十年轨迹

时间线大概是这样：

**2013 年**——注册公众号，开始写 Python 入门系列；同年开了知乎账号，答 Python 和编程类问题。那会儿公众号还算稀罕物，谈不上什么商业逻辑，“自媒体”仨字都还没流行。但稀罕有稀罕的好处：只要内容过硬、更新稳定，很容易被大号瞧上帮你推一把，号主之间也爱互相搜罗优质账号做推荐。知乎那时正往上走，用户以在校生和职场新人为主，知识技能类的氛围很浓，而且早期对作者往站外导流几乎不设卡，回答里挂公众号二维码完全没问题；加上百度对知乎内容的收录权重高。所以那阵子在知乎做技能分享再把人往公众号引，确实是个天大的红利期。

再往后几年，我主业还在游戏公司，公众号纯属兼职，更新慢得很，可粉丝量却一直在往上爬。期间接过两家广告，一次差不多一千块，其中一家最后一期还赖账了，不过也算开了张。

**2016 年**——辞职全职做自媒体，年中上线付费服务，下半年注册公司、拉队伍、参与创业孵化。那会儿知识付费刚冒芽，移动支付也铺开了，大家掏钱买线上内容的意愿变强，而机构还没大举杀进来。公众号广告主不多，只能自己琢磨课程、训练营之类的变现路子。知识星球（那会儿还叫小密圈）和生财有术都是这时期冒出来的，我算是最早一批用户。我的付费服务前后改了很多个版本，从生财有术那儿也偷师了不少。最早那版会员连课程都没有，就是拉个 QQ 群答疑，结果几十个名额一放出来就被抢光，这给了我继续干的底气。

后来觉得有戏，就开始注册公司、搭班子。2017 年一直在试团队化运作，想把“内容引流—培训服务”这条链路跑通。但我管理经验太嫩，团队的作用没释放出来，自己写内容也受了拖累，两头都没顾好。整体没怎么亏钱，粉丝也在涨，但状态特别别扭，对小伙伴和我自己都不太好，2018 年初就把团队散了。

**2018 年**——试水视频。抖音火了之后我也跟着玩短视频，一周就搞出个千万播放的爆款，可惜跟编程八竿子打不着，短期内也没想明白怎么把编程和这个方向捏到一块儿。与此同时公众号的品牌投放开始猛涨，于是重心又缩回图文，抖音就这么撂下了。

**2019 年**——心里想着转视频，但没真当回事。那阵子公众号广告市场红火，商单一个接一个，是做号很舒坦的一段日子。我又找了几个帮手，多数是线上兼职。继抖音之后，B 站也慢慢破圈，我其实是 B 站老用户（准确说是 A 站那拨的），但之前压根没想过 B 站也能发编程内容，于是跟抖音一样，起得早、赶得晚。虽然有几期播放还行，可始终没把 B 站当主阵地。

**2020 年**——正式变成“自媒体人”。那年的事大家都清楚，但对公众号主冲击有限，甚至还帮了忙：线下活动停了，线上流量涨了，我的网课也多卖了一些。而且我阴差阳错在一月初退了办公室，彻底回到一个人单干的自由职业状态，反倒躲过一劫。可时间一长，培训机构类的金主也扛不住了，到 2021 年下半年广告量已经掉得厉害。再加上视频挤压图文、知乎转做“故事会”，我的公众号数据跌得没法看。那阵子我索性有点摆烂，过起了半退休日子（学了指弹吉他、打鼓、攀岩，偶尔还去公园跟大爷大妈抖空竹……）。

**2022 年**——再战短视频。年中下了狠心转型，做编程教学类短视频，主攻抖音和 B 站，顺手同步视频号和小红书。目前数据不算炸裂，但好歹在缓慢爬升，暂时还是以内容创作为主继续走着。

## 三、收入这事儿

估计不少人关心这个。但说实话，这个问题参考价值真不大——自媒体的收益千差万别，而且跟流量并不完全挂钩。

拿我举例：头几年几乎零收入，最巅峰时年入百万。但这百万是营收，还得扣掉课程研发和运营成本，而且后来也没能续上。如果把 2013 到 2022 当成一个完整项目周期来看，总共进账大概两百万。从 2023 年往后看，短期内我怕是回不到这个水平了。

单看绝对值，也差不多是个上班族的工资。但我要是老老实实去大厂敲代码，收入肯定更高。不过以我这性格，既不爱管人也不爱被人管。做自媒体至少给了我这么个机会；至于能不能比上班挣得多，那就看缘分了。

## 四、我做对的事

能靠一个自媒体号做到不用上班，我觉得中间还是干对了一些事情。

**1.** 踩中了公众号和知乎的风口，也吃到了知识付费的红利。这里头运气成分不小，但运气偏爱有准备的人——当时要是没积极去试，风口也就从眼前刮过去了。

**2.** 持续输出。虽说有风口，也等了好几年才真正起飞。这期间不管频率高低，我始终在写、在更，这是后来能吃到红利的重要前提。另外，出爆款本质是个概率游戏，你只有不停更、基数够大，才有更多机会撞上。说实话，我的公众号运营算不上激进，内容也没多独特，主要靠写得久。

**3.** 冷启动时借了外力。很多人做自媒体都卡在冷启动：辛辛苦苦写完发出去，阅读量个位数，这谁坚持得下去。早期大 V 的推荐加上虎扑引流，让我很快就跨过了这个阶段，基本算是从 500 粉起步的，创作体验就好很多。

**4.** 从用户角度琢磨内容。写公众号也好、做视频也罢，是给别人看的，跟发朋友圈不是一码事。我会盯着不同内容的数据表现，也做问卷，据此调整方向。最后把内容定位在偏入门、短篇幅，要么好玩、要么管用这个方向上。

**5.** 专业内容蹭热点。现在“蹭热点”几乎是基本功了，但早年没多少人意识到这个，我一开始也不懂。不过运营过程中自己慢慢摸到了门道，做出了几篇还过得去的内容。

**6.** 变现链路完整。我自带开发能力，所以一开始就自己搭了教程网站，后来在上面做付费课程和学员系统。从内容里的钩子导流，到公众号文章承接，再到后续课程服务，整条链我自己能掌控。即便大环境不好，也有靠谱的变现通道。

## 五、我踩过的坑

讲完做对的，再聊聊做错的或者说错过的。当然，所谓“做错”也只是事后假设，真那么做了也未必更好。

**1.** 流量（内容）和变现（服务）都想抓。前面说完整闭环是优势，但反过来看，这个闭环也一定程度上拖了我的增长。一个人做自媒体精力有限，什么都自己扛，相当于拿增速换稳健。要是把那部分时间省下来全砸在内容创作上，性价比可能更高，说不定流量还能再上一个台阶。

**2.** 团队化搞早了。团队化本身不是不行，只是不适合我的情况。跟上面一条同理，这事儿牵扯了大量精力，效果却没达到预期。也许是缺一个能互补的合伙人吧。

**3.** 视频转型不够早。我很早就意识到视频会取代图文，但却没有像当初积极搞公众号、知乎那样去积极转视频。不过得承认，视频的门槛确实比图文高，尤其对我们这种习惯码字的人来说，面对镜头是需要很大勇气才能迈过去的坎。

[PRE7]

下面几条建议就是围绕这些选择展开的。

**1.** 先想明白你为什么做自媒体。大方向不同，打法就不同。自媒体门槛低、天花板高，听着挺美，但通往天花板的路极其拥挤，而且越来越挤。

   如果你本职工作干得不爽，想裸辞全职做自媒体赚大钱，那我得泼盆冷水：好做的窗口期已经过了，没有过人天赋很难冒头。

   但如果你是想搞个副业、多一条路试试，那我举双手赞成。我这两年就间接帮一位朋友成功转行做了自媒体。不过请记住：别辞职！别辞职！别辞职！想做就先干起来，立刻干，今天就开始。你要说不辞职就没时间，那相信我，辞了职你大概率也更不了几期。等你做到稳定更新了，再考虑要不要全职。

   就算成不了赚钱的副业，通过自媒体输出专业知识和独家观点，对你的职业发展也有帮助，常常会带来意想不到的机会。

   还有一种很适合做自媒体的情形：手头有现成的生意，用自媒体来宣传和获客。眼下做纯网红大 V 很难了，但把自媒体当成专业能力的展示窗口是很有搞头的，不少平台的流量机制也在往这个方向偏。举个例子，你开了家饭馆，纯靠自媒体养家可能不容易，但认真做点美食内容，把店里销量翻一倍并不难。要是你的业务能搬到线上，比如培训、咨询、卖保险之类，那效果更佳。

   当然，也有人纯粹是兴趣驱动、为爱发电，那不需要我多嘴，玩得开心就好。

**2.** 发视频肯定几个平台同步更，但风格上得各有侧重。新手建议优先从 B 站、抖音、小红书里挑最适合自己调性的。这几个平台都有用户推荐机制，哪怕冷启动，坚持更一段时间通常也能拿到反馈；而且它们有 IP 这个概念，你做得好，别人会关注、会追更，慢慢攒粉丝，形成正循环。头条那种重内容轻 IP 的平台，适合批量做营销号。公众号我把它归到“私域”里，这说法不严谨，我想表达的是它没有公共推荐流量。不过眼下公众号机制似乎有变化，也开始重视推荐了。但图文毕竟是过去式，除非你文字功底真的很硬，或者实在做不了视频，才考虑公众号。现在的公众号，平台规则相对宽松，更多是当作最终变现的渠道来用。

**3.** 你的内容得跟大方向、变现模式对得上。拍搞笑短剧受众广、流量能做大，但多半只能靠内容激励或直播带货来变现。做专业内容，比如像我这样的编程教学，流量注定不会大，但来的都是垂直细分用户，给他们提供需要的服务，客单价可以更高。还有前面说的，自己有生意就容易多了，只要把潜在客户吸引过来，他们会主动找你。你要想在抖音卖课，却天天跟风拍搞笑段子，那即使出了爆款也没价值。做垂直内容的别羡慕别人的爆款：他十万播放可能只带来几十块收入，你十个播放说不定就带来一个高价值客户。

**4.** 前面说要从观众角度选内容，但我还得反过来补一句：自己都不喜欢自己做的东西，也很难坚持下去，至少别讨厌吧。所以理想的方向，是用户需求（可能爱看，也可能实用）、自己擅长、自己喜欢这三者的交集。兼顾不了的话，至少取一个能接受的平衡点。

**5.** 最后，做自媒体的心态，尤其是新手，要做到：先干起来再说，然后坚持、不要脸、坚持不要脸。

   做自媒体不需要什么准备，你今天想做就能立马动手。不放心就先拿个小号试水，边做边想边调。你要觉得“等我怎样怎样了再开始”，那要么是想法有问题，要么就是在给自己找借口拖延。很多事情预想的和实际的差很远，不亲自上手就体会不到细节。有人完美主义，觉得视频做得不够好不想发，要继续改，甚至重拍、换选题。对此我送一句话：永远在下一条视频里改进。一条视频做好了就发，发出去就是最大的成功。

   坚持这事儿不用多说，大家都懂，但很多人潜意识里低估了坚持的分量，更愿意归因于能力、环境、运气。可在自媒体这条路上，坚持是排第一位的，是其他所有因素的先决条件——你没做到一定的量，别的方法论压根没机会施展。另一方面，大家又低估了坚持的难度：初期缺少正向反馈的时候，放弃实在太容易了，可能今天加个班，明天朋友喊你吃顿饭，你就彻底断更了。

   我之前跟一位想尝试自媒体的朋友说“你得不要脸”，她果不其然想歪了。网上确实有一堆“不要脸”的内容，但我说的不是那种。即便你正常写文章表达观点、拍视频做节目效果，也难免会面对镜头恐惧、觉得尴尬。这种尴尬再配上寥寥无几的播放数据，对新手的打击几乎是毁灭性的。这时候你就得硬着头皮上，别想那么多，继续更。

   我们受过的教育总给人一种“凡事只有一次机会”的错觉，觉得一旦搞砸了就会出大问题。但在自媒体上，我觉得不存在，至少对新手不存在。只要你不碰违法违规的内容，尽管放手去试，不停更新，你会在更新中慢慢找到感觉，而不是在纸面的学习和思考里找。
