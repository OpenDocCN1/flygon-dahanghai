# 直播带货避坑与复盘指南

想把视频号直播带货做顺，光有热情不够，规则和复盘得一起抓。商品能不能上、话术怎么说、营销怎么玩、内容怎么发、数据怎么复盘，每一步都有门道。下面把常见违规点和运营提效方法一次讲清。

## 商品与信息发布别踩线

先弄清平台里哪些产品开放、哪些不开放、哪些属于定向准入，部分定向准入产品还要知道销售底价。通常直播间只能卖绑定小店已开通类目的商品；其他类目想上架，或者想当赠品送出去，都得先翻规则文档，确认不在禁售范围。

具体细则，详见：《相关商品橱窗类目准入规则》《视频号橱窗类目、商品资质总览》。

[PRE0]

**1）发布违禁信息：** 发布的信息或商品触犯《中华人民共和国广告法》等法律法规，主要分两类。一类是食药同源或滋补品，直播时容易把功效说大；另一类是主播或直播团队被全网拉黑，或本身涉及违规违法。

比如，口播说亚麻籽油能通血管、养大脑，普通食品被吹成功效产品，会被处罚；拍A发B卖“幸福小丸子”这类壮阳物品，会被处罚；主播喊“男人加油站”“懂的都懂，一个小时打底”，也会被处罚；口播古玺堂精油炙疗腿疼、颈椎膝盖不适，把护肤品说成有医疗功效，同样被处罚。以上情形处理结果是禁播15天。

应对策略：主播话术避开极限词、虚假文案和欺骗性表达，同时熟悉平台规定的违规场景。

具体细则，详见：《视频号橱窗达人【发布违禁信息】实施细则》。

[PRE1]

**2）发布虚假宣传信息：** 视频号橱窗达人违规使用极限词、虚假限时文案，欺骗或误导用户，都属于这一类。判罚逻辑大致看货不对板、质量问题、用户投诉、纠纷单量大、物流问题。

例如，商品品质与宣传不符、出现少件，消费者体验差，举报和投诉数据多；商品品质与描述不符，还叠加物流异常，投诉数据多；主播口播说商品能祛斑，但提供的特殊化妆品证明名称和商品名称对不上，无法证明该证明对应此商品。

应对策略：虚假宣传很容易触发，核心是直播间货品和实际货品质量不一致，引发投诉或纠纷。承诺物流快、几天内送达，如果做不到被举报，也可能被判虚假宣传。所以要重视产品品质，直播样品和正品保持一致；主播话术别为了逼单给出过多承诺；售后服务一定要跟上，客服要及时响应咨询并处理售后。

具体细则，详见：《视频号橱窗描述不符/虚假宣传纠纷处理判责标准》《视频号橱窗交易纠纷处理规则》。

[PRE2]

**3）发布不合规信息：** 主要是商品重要信息缺失和类目乱挂。比如商品名称没写重量，玉石材质或镶嵌类商品无品牌、无重量；商品标题缺少品牌信息；翡翠手绳错挂到翡翠手镯、翡翠吊坠上；正红菇干货本应放在食品饮料>粮油调味>南北干货>类目，商家却挂到生鲜-蔬菜-根茎类。

应对策略：不合规信息多出现在定向准入商品或较特殊商品上，这类商品往往需要产地、品牌、重量等信息，关键信息缺失就可能被判发布不合规信息。

具体细则，详见：《视频号橱窗达人【发布不合规信息】实施细则》。

# 情况二：直播间违规雷区

**1）不正当营销：** 视频号橱窗达人用虚假福利、虚假抽奖、虚假赠品等方式吸人气、求关注，最后不兑现，就属于不正当营销。

常见情形包括：直播宣传全场1折、1折清仓、全场X元/折起、免费送XX、某品牌商品个位数、全场清仓、清完走人、专柜X折、特殊材质商品个位数、扣XX免费送、新人免费送等；直播间物料或举牌出现1折、X元、免费送等字样，包括字纸印刷物、电子显示屏、灯牌、第三方推流贴图等；低价商品高运费，商品明显低于市场价或成本价，却用高额运费引流；直播间口述、视频号昵称、简介、直播主题、公屏互动等场景也可能被打击，比如工厂直销一折优惠、标题宣传全场9.9做低价引流、直接展示产品免费试用、写“新人每人送2份见面礼”、用1元商品引流但实际商品价格高于宣传价。

应对策略：不正当营销是目前平台处罚最多的规则之一，凡是涉及低价、赠送、福利品，都可能被判定为不正当营销。视频号规则不允许靠低价引流，价格不能低于9.9，折扣也不能过低，否则容易被看作恶意竞争、打价格战。抖快的直播习惯和套路，并不完全适用于视频号。

具体细则，详见：《视频号橱窗达人【不正当营销】实施细则》。

**3）这些场景别出现虚假福利：** 直播间封面、背景、头像、主题、评论区、昵称等位置，不要出现“扣XXX送XX”“新人送XX”“关注送XX”“免费送XXX”等虚假福利或不正当营销内容。比如扣1分享朋友圈送手镯、关注送项链、扣666免费送梳子、新人免费领大礼包、进来免费送、0米送等，凡是引导用户在直播间互动换礼品的说法都要小心。其他敏感词可查《视频号直播敏感词汇注意事项》《视频号直播违禁词大全》。

各品类还有各自规则。比如生鲜类直播间，第一，必须展示实物商品，包装商品要拆开包装展示内容实物，不能用绿幕代替商品展示；不能只展示内容物，包装也要一起出现在直播间。卖生鲜肉的直播间，要同时展示带包装产品，不能只展示肉本身；卖冰冻鱼的，不能只展示新鲜鱼，要展示冰冻包装鱼，避免误导消费者。第二，商品标题、商品实物包装名称、直播间展示实物，三者要一致。

最后分享一个经验：直播过程中如果后台两次弹出直播处理通知，最好马上下播，重新开一场新直播。因为出现第三次弹窗通知，处罚至少禁播1天起；而新开播会重新计数，这样能降低一点禁播风险。

# 6.2 整体复盘优化

# 6.2.1 优化认知

视频号上赚钱的案例很多，容易让人产生错觉：以为一开始做就能百万播放，涨1000粉轻轻松松，爆单很容易。其实这是错觉。新手别期待一夜暴富，也别期待短时间做到百万播放。先行动，没有行动，再好的成绩也是别人的；只有动手干，才有可能。还没动手的小伙伴赶紧行动起来，量变会产生质变。

看着再简单的东西，也是别人总结出来的，只有消化了才会变成自己的底蕴。不动手、不实践，拖一拖，几天没动静心又焦虑，逐渐想逃避，这都是常态。但越是这个时候越需要坚持和正反馈。大家都是成年人，学习是对自己负责，正视问题、实事求是，多和老师圈友交流。没出成绩不要紧，最主要的是有没有学到知识，能不能走通一个闭环。走得快未必走得远，走得慢也意味着走得稳，到达终点的方式有很多种。只要还在牌桌上，就有机会，千万不要下牌桌。视频号是最简单、复制性最高的项目，跨越了空间限制，所有普通人都能参与进来。

# 6.2.2 优化商品

**第一，你选的品不够吸引人。** 同样选手机充电线，一个选普通数据线，展示线身线接口，和大家手里的差不多，没特色；另一个选华为超级快充数据线，直接展示快速充电界面，满足快速充电需求，又和大家手里的不一样。同样品类，产品选得不一样，视频制作再好用处也不大。

**第二，用户不需要，或者产品生命周期已经过去。** 夏天卖棉袄，再好也难下单，因为用户这个周期没需求。有做渔具的朋友说11月、12月视频带货出单很少，怀疑视频质量或竞争增加。问他冬天是不是很少人钓鱼，他说是的，冬天不适合钓鱼，几乎没人钓。所以不是播放量问题，也不是用户问题，而是产品选错了。产品选错的背后，是没洞察到用户需求变化：春天、夏天、秋天钓鱼的人多，冬天就少很多。

**如何优化选品？** 选品时一定反问自己：这个品的视频展示效果够不够好？展示效果好的品，不用过多剪辑也能带来播放量和成交。同时要根据数据选品，不要想当然，数据是验证用户需求最好的方法。具体优化选品的方法，和寻找优秀选品本质上一样，有时间可以学习这个选品手册：《通用能力 | 如何定位和选品》。

# 6.2.3 优化视频

**1. 增加去重手段。** 二次剪辑要尽可能提升视频独特性，增加去重手段，避免内容重复度过高被限流。可用方法有：去水印、修改分辨率、加片头片尾；调整帧率、滤镜、播放速度、背景音乐；镜像、滑动、画中画、视频蒙版、图片蒙版、背景颜色、背景图片、背景视频、模糊拓边等。

**2. 提升视频画质。** 挑选清晰视频，不要用模糊视频做二次剪辑素材；本来模糊，二次剪辑后更模糊，容易被抖音判为劣质视频，平台自然不会给流量。素材来源包括视频号同行、抖音、快手、小红书、微博、微视、西瓜、国外TikTok、国外YouTube。最推荐两个渠道：抖音、快手。

**3. 利用热门话题或引流视频造势。** 新号没粉丝基础，但一般有新号流量扶持。可以先不直接发带货视频，先找最新热门话题或引流视频，前提是观众画像符合账号粉丝画像定位。发1—2条这样的内容，吸引基础粉丝，提升账号权重，然后再发带货视频，基础播放量可能比新号直接怼带货视频好一些。比如有位圈友前一天下午发布容易引起争论的引流视频，带来50多万播放，增加了一些粉丝，后面的视频播放量就好一些；隔天早上发的一条视频小爆了一下，出了几十单。

**4. 学习制作原创视频。** 原创视频内容基于不同赛道类目的产品差异化很大，这里不给具体操作流程。建议按赛道选取对标账号，拆解账号脚本模型，从仿拍到仿拍一部分，再到仿拍全程，最后迭代出自己的优质内容视频。

如果视频没有流量（0播放），可能原因很多，比如账号被判定为营销、视频内容已经被搬运过。可以一步一步排除：如果视频号发布其他内容有流量，那是视频内容的原因，换视频内容即可；如果账号发什么内容都没流量，那可能是账号原因，用其他账号测试发布相同内容存在流量，就可以注销视频号。从现在的反馈和实际操作来看，官方对搬运视频的打击越来越严格，前面「5.1 视频零播诊断和解决方案」也有讲到。
