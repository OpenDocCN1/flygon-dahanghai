# 方法五：抖+投放全流程拆解

新号刚起步时，系统还没摸清你的受众，铁粉也没沉淀下来。这时候哪怕内容做得再用心，平台也很难准确推给对的人；人群一偏，互动就起不来，作品自然不容易爆，点赞数也常常偏低。

投抖+，本质上是给账号加一个流量助推器。用好了至少有三重价值：第一，用付费流量带动自然推荐，互动表现一好，作品就有机会冲进更大的流量池；第二，把点赞、评论等数据抬起来，作品权重跟着提高，也能顺带做搜索优化；第三，找出有爆款相的内容，放大涨粉效率，让粉丝量更快起来。

什么样的作品值得投？一种是已经能在搜索关键词下找到，但名次偏后，比如排在二十名左右；另一种是数据出现“异常值”的作品，这种投放效果通常最理想。

异常值怎么看？点赞、收藏、评论、转粉率里，任意一项比日常水平高出三成以上，就算异常。比如平时综合互动不到50、评论不到10，某条作品突然做到80—130甚至更高，那就是异常值。

当然，这条内容最好能体现你的专业度，带来的是精准用户而不是泛粉，才值得投。如果标题里还埋了你想要的搜索关键词，那就更划算，还能接住搜索流量。

1）投放目标怎么定？

短视频投抖+，目标选哪个？
A 点赞与评论
B 粉丝增长
C 主页浏览

[PRE0]

正确答案是A：点赞与评论。

起号前期，作品的基础互动通常都不占优势。先把点赞评论投起来，能迅速积累一轮互动数据；有了基础数据，别人才更愿意跟着点赞、留言。很多人习惯先翻留言区，如果你连留言都没有，别人连看的机会都没有，完播率大概率也会被拖低。再加上大家都有随大流心态，看到数据还不错的作品，才更愿意点个赞。

为什么不建议投粉丝增长？因为一旦选了这个目标，平台必须把数量完成，很可能推来一批“爱点关注”的人，而不是你的目标受众，比如五十来岁的泛人群。粉丝目标也许完成得更快，却会拖累后续流量分发。

为什么后续会受影响？靠付费换来的关注，不一定真正认可你。他们可能只是一时兴起点了关注，对你的内容并没兴趣，之后大概率不会看你的作品；即便刷到，也未必愿意互动。这样一来，账号后面发的内容反而可能被拖后腿。

投点赞评论则很可能帮你突破当前流量池，因为互动数据会给作品加分。

当某条作品投起来后，点赞评论表现比较亮眼，比如点赞2000+、评论200以上，并且能吸引到精准粉丝，这时涨粉效果通常不错，可以转向投涨粉。

2）投放时长怎么挑？

投抖+时，时长怎么选？
A 2小时
B 6小时
C 12小时
D 24小时

[PRE1]

先看各时长的差别：2小时能快速跑点赞评论，但精准度不够；6小时也是快速跑完互动数据，精准度略好一些；12小时给了平台更充足的时间，精准度已经不错；24小时跑满一天，精准度最高。超过24小时的投放数据，就不用再看了。

正确做法是“先短后长”：先投2小时，再补24小时；或者直接投24小时。

为什么要这样投？先想清楚我们要什么：一是短视频的基础权重，二是精准粉丝。按前面的随大流心态，点赞少时别人不愿点赞，评论少时完播率容易低。所以可以先花100元投2小时点赞评论；虽然2小时的精准匹配不如24小时，但能快速把基础数据拉起来，然后再追投一单24小时，让系统慢慢跑。

如果你对作品的互动数据比较有信心，也可以只投24小时，让系统慢慢做精准匹配，拿到性价比更高的流量效果。6小时和12小时更适合覆盖固定时间上线的人群，比如你想投深夜人群。蓝V投放没有2小时选项，用6小时替代也可以。

如果粉丝模型已经建立，正确选项是A；如果粉丝模型还没建立，正确选项是B。

怎么判断粉丝模型对不对？如果视频点赞的人不是中老年泛人群，留言区也多是精准用户，说明粉丝模型没问题。这时选智能推荐，可以拿到5000左右播放量。抖音的算法在全球都算顶尖，算法机制本身就是它的壁垒之一，要相信算法的匹配能力。

新手起号阶段，更推荐投达人相似。达人相似投的不是某个对标达人本身，而是近期对标作品所搭建出来的观众画像模型。比如某个博主刚火，是因为说某个产品好而火，但他并没有卖这个产品；这时你投这个产品相关链接，往往能事半功倍。

找对标达人很关键，有几个要求：第一，对标达人的粉丝要垂直精准，最好是对标达人刚起号成功；第二，对标达人的粉丝量不建议太高，否则人群会比较泛，建议在1万—10万之间。

如果实在找不到合适的对标达人，建议用自定义模式，把年龄、地域、兴趣偏好、性别等维度划细。

5）Dou+不让投放是什么原因？

平台希望优质内容获得更多展示机会，但下面这些类型的视频无法投放DOU+：

1. 画质或内容不达标：没有实质内容、画面模糊、产品bug、静帧视频、视频拉伸、3秒及以内破坏景物的视频，以及观看后让人极度不适的视频。
2. 非原创或搬运内容：视频中ID与上传者ID不一致、账号状态标签为搬运号、明显截取的PGC内容、录屏视频、视频里出现其他平台水印。
3. 内容调性不符：低俗含软色情、引人不适、不符合平台调性、非正向价值观。
4. 潜在风险内容：视频或文案出现广告、欺诈内容、标题党、医疗养生类、抽烟喝酒行为、违规饲养野生动物、虐童现象、疑似赌博场景。
5. 硬广痕迹过重：内容中有明显的品牌定帧、品牌词字幕、品牌水印、口播；视频背景里有明显的品牌词、商业元素。
6. 未授权明星/影视/赛事类视频。涉及侵权无法使用DOU+；请把相关授权证明发到 feedback@douyin.com。
7. 视频标题和视频描述包含以下元素，无法使用DOU+：
（1）联系方式：电话、微信号、QQ号、二维码、微信公众号、地址；
（2）招揽信息：标题招揽、视频口播招揽、视频海报或传单招揽、价格信息。
8. 标题产品功效介绍；
（3）曝光商标：品牌定帧、商业字幕、非官方入库商业贴纸；
（4）指向性的企业店铺名称。

内容不符合抖音站内社区公约的视频，同样不能投。

6）抖+投放总结

新号投抖+，可以投对标达人，时长选24小时，把所有作品先投一遍，最后筛出点赞和涨粉表现最好的那条。

对标达人怎么选？可以找作品质量不如你、但粉丝数很多的账号；对标达人很重要，所以值得多花时间找。如果实在找不准，或者心里没底，也可以用自定义选项，把年龄、性别、喜好、地域等数据精细选好。

起号阶段建议至少准备2000+元：1500元投点赞评论，500元投涨粉。投放时一次选5个作品，每个投100元，选择点赞评论，先把所有作品投一遍；剩余预算给点赞评论互动数据最好的作品。再找出涨粉最好的作品，投500元涨粉，观察粉丝单价。后续如果有预算，粉丝单价低于1元，就可以围绕涨粉率高的作品，把粉丝数拉到5000以上。
