# 案例十一｜儿童摄影门店 @文文：7天拿下5252单的线上活动复盘

•Part1：前期准备【定价、选品与活动玩法】

活动正式启动前，我们先把目标客户和现有客户底子摸了一遍。这家儿童摄影店的客户量并不算大，而且大部分好友都零散地躺在员工个人微信里，没有做系统的分组、打标签或精细化管理。

基于这个情况，我们判断：一部分老客户其实处于可被重新唤醒的状态，只要给出足够吸引的复购理由，再加上一套强裂变机制，就有机会做到1:2甚至1:3的转介绍。

于是这一轮活动的目标变得很明确：用一次线上活动，把微信里的用户完整盘活，既让老客户重新下单，也借老客户带来新客。整体策略是“引流锁客”——先进店拍完，再做后续转化和成交。

围绕这个目标，我们设定的主体产品是“体验拍摄”类的引流套餐，挑出几个容易出片的爆款主题，同时选了一批市面上比较少见的新奇产品，包装成“新品发布会”来做活动噱头。朋友圈也同步开始大面积预热和造势，先把客户的注意力重新拉回到门店。

•Part2：前期准备【快闪群激活用户，沉淀新粉丝】

因为店里的微信号此前没有系统维护，活动启动的第一步，就是先把用户的关注度重新唤醒，再用福利引一批新粉进来。所以我们决定建一个为期2天的快闪群。

顾客入群就能免费领一次价值99元的宝宝证件照拍摄；如果能再邀请5位本地宝妈进群，还会额外送一个网红泡泡机。这一步其实藏了三个目的：

1. 用进群送礼把顾客集中到群里，活动开卖时能第一时间完成转化；
2. 顾客邀请好友进群，相当于完成了一次1:5的精准老带新；
3. 礼品和拍摄都需要到店领取，也为后面的二次成交和转介绍创造了机会。

[PRE1]

建群的具体操作是先朋友圈造势，再一对一私聊邀请种子客户。每个员工按自己微信好友数量建一个福利群，群里的种子客户控制在70-100人，这样能留出足够空间让种子客户邀请新朋友进来。

群名、群公告、群欢迎语这三件套提前准备好之后，我们一口气建了17个社群，并在48小时内完成了种子客户进群+邀新流程。到这时，社群总人数已经接近5000。

正是这批基础粉丝，为后面的第一批成交客户打了底。

•Part3：正式发售【群内拿下首批成交】

粉丝福利群建好之后，第二天晚上进入正式销售环节。工作人员统一在群里做转播，把本次活动的优惠力度、福利细则同步到每个群，并提醒大家按指定时间到店领取礼品。

政策讲完后，直接亮出成交价格和具体活动内容，吸引大家下单。为了让群内气氛更热，每个群都提前埋了“水军”，在发售过程中带节奏、做互动，推动顾客快速成交。

另外，为了让大家当晚就做决定，我们还设置了一个“限时加赠”的福利：前300名付款成功的顾客，可以额外得到一个安抚大象玩具。

[PRE3]

这个安抚大象的成本其实在套餐定价时就已经算进去了，选择在发售当晚抛出来，利用的是顾客“怕错过、怕吃亏”的心理，从而缩短决策时间，加速成交。

与此同时，所有员工的朋友圈都开始晒客户见证、订单截图和好评，把热度再往上推一层，也能唤醒那些还在观望或者还没进群的客户。群内则用“已购接龙”的方式，带动更多人跟进下单。

•Part4：客户裂变【拼团玩法，让客户拉客户】

首批客户成交后，下一步最关键的就是裂变——毕竟这才是门店经营者最看重的东西。

我们设计的第一种裂变方式是团购。为了让顾客更容易成团，我们设置了三个阶梯式的团购档位，对应不同的奖励规则：团购人数越多，奖励越丰厚。经过测试，2人、3人、5人成团对宝妈群体来说难度最低，最容易完成。

[PRE4]

活动报名通过H5链接完成，顾客打开链接填写信息就能直接付款购买。我们会鼓励顾客把活动链接转发给好友，邀请她们一起拼团；拼团成功后，客服会第一时间告知，同时引导顾客去冲刺更高档位的团购福利。

如果不用H5链接，而是用微信红包收款，那一定要做好客资统计和客户信息登记，并且要求客户把客服微信推给一起参与拼团的用户，方便我们在微信端给每个人做好备注和标签。

无论是哪种方式，本质都是用团购福利作为钩子，推动老客户主动带新客户，完成裂变闭环。

•Part5：客户裂变【朋友圈转发拉曝光】

除了拼团，第二种裂变方式是引导顾客分享朋友圈，以提升活动曝光量为目标。顾客只需要把我们准备好的文案+链接发到自己的朋友圈，就能领取福利。

[PRE5]

这个操作本身没什么门槛，但因为福利要等到顾客到店后才能兑换，所以这条朋友圈在兑换前基本会被保留，不会马上删除或屏蔽。而且我们设置了“连续转发3天才算激活”的门槛，这三天正好是我们重点跟进团购客户的黄金时间。与此同时，微信号的粉丝量也在快速增长——大部分新粉丝都是靠老客户推荐或主动加过来的。

[PRE6]

靠着拼团和朋友圈转发这两套裂变机制，这次活动的新客占比做到了70%。具体做法是给介绍人和被介绍人同样的福利和待遇，同时过程中一定要做好提醒和监督。我们每天晚上都会在群里提醒：记得转发朋友圈，记得把拼团链接发给身边有需要的小姐妹，大家一起领福利。

•Part6：活动倒计时【限量名额制造紧迫感】

活动进行到第6、7天，基本进入尾声。这个时候我们要做的就是给还没下单的顾客制造紧迫感，于是开始每天定时放出700个活动名额，抢完就截止，朋友圈同步倒计时。

对已经成交的顾客，再做最后一轮提醒，催促他们赶紧把团拼成功——如果活动结束还没成团，福利就领不到了。到了这个节点，很多原本犹犹豫豫、一直观望的顾客都会选择下单。

•Part7：活动复盘【客资归档，邀约到店】

活动最后要做的，是把所有客户资源统计和梳理清楚。一次引流活动本身不是终点，真正重要的是给这些用户做好分类，后续才能持续转化、长期成交。所以我们把标签、备注、分组、客户来源全部做了细分，然后开始一个个邀约顾客进店。
