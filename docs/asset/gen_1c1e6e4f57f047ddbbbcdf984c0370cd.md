# Sora来了，真实还够用吗？

Sora一出现，科技圈先沸腾，紧接着就该冷静了。它被视作视频生成领域的里程碑，可里程碑旁边也立着一块警示牌：当物理世界和虚拟世界都能被模拟，我们靠什么分辨真假？出门问问创始人李志飞和普林斯顿大学教授Arvind Narayanan，都指向了同一个追问。这不是杞人忧天，而是已经发生的现实。

深度伪造的门槛被大幅拉低，造假视频的成本越来越低，肉眼越来越难识破。结果就是隐私、版权、假新闻、诈骗一起冒头。去年香港那起AI换脸诈骗，骗子用深度伪造卷走2亿港元，剧情比电影还离谱。2023年美国一批作家把OpenAI告上法庭，集体诉讼的核心就是作品未经授权被拿去训练模型。你看，AIGC安全问题不是未来时，是进行时。

那AIGC安全往哪走？第一责任在平台和开发者。OpenAI已经在加水印、做红队测试、增强内容识别，试图降低滥用风险。国内不少自媒体平台也在推动创作者主动标注AIGC作品。这些动作值得肯定，但还不够。技术迭代像高铁，规则更新像绿皮车，差距越拉越大。

法律必须提速。美国联邦贸易委员会提出禁止用AI工具冒充个人的规则，这是个积极信号，但远远不够。需要更多国家和地区跟上，逐步搭起全球性的法律框架，给AI发展和应用划出硬边界。

公众教育同样关键。得让普通人知道：不是所有视频都值得信，不是所有“有图有真相”都成立。学会在转发之前多问一句、多查一步，这本身就是数字时代的防身术。

更深一层，人类可能要换一种视角。Arvind Narayanan说，我们也许得适应一个“现实主义不再是真实性标志”的新时代。听起来有点残酷，但这就是技术抛来的考题：重新定义真实性、信任和安全，在新的技术底座上重建社会信任机制。

Sora是人工智能的重大进步，也是一把双刃剑。便利和风险同时被放大。要守住人类的安全与信任，不能靠某一家公司、某一个国家单打独斗，得靠多方参与、多维度协作。别急着为技术狂欢，也别因风险因噎废食。真正的难题是：我们能不能在享受Sora的同时，把“真实”重新锚定。

把镜头拉远，未来像一部正在加载的科幻片。星辰大海一闪，切进数字空间，一道极光划过，每个人的数字身份像星辰一样亮起。孩子们站在金字塔顶端，伸手触碰光影，下一秒就穿越到另一个时空，历史在眼前重新开机。虚拟会议室里，不同肤色、不同语言的人围坐一桌，AI算法让每个声音都被听懂，距离感被按了删除键。镜头再切到绿色城市，高楼和森林共享天际线，无人车安静掠过，人和自然不再互相为难。最后，地球缓缓旋转，一颗叫Sora的星划过天际，火星上的人戴上设备，远程赴一场地球的Sora盛宴。Sora横空出世，送给人类最贵的礼物不是炫技，而是四个字：无限可能。人类社会将如何重塑？答案不在代码里，而在我们如何划定边界、重建信任。接住这份礼物之前，我们得先学会和真实握手。
