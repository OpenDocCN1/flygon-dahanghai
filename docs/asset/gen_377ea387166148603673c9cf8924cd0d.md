# 10.2 Lissa Tam：亚马逊创业，时间花在哪？

亚马逊这条链路跑顺之后，我的工作循环基本就固定下来了：先挑产品、取样品，再敲定产品方案，接着采购、拍照、修图、剪辑视频，随后上架运营、安排补货。

通常两到三周走完一轮；如果选品卡住，整体进度就往后延。下面是我2021年刚开始创业时画的进度甘特图。

选品是最容易让人产生“整天没成果、像在空转”感觉的环节，所以我干脆把“选出一个产品”当成阶段里程碑。

可这个周期确实偏长，反馈感很弱。后来我尽量把量化颗粒度做细：一天初筛多少个产品、一周完成几个产品方案、一个月定下几个能量产的方案。

除了流程本身，数据分析和汇总也很关键。我会用第三方工具整理数据，再用Excel做分析看板，追踪各节点的达成率。推新品还有专门的记录表，把每日销售数据、关键词排名、产品数据、流量转化率、新品日志等都记下来，方便后续复盘，也方便把推新策略复制出去。

[PRE2]

我的时间大头在选品上，大约占65%。产品上花的心思多，运营端自然就少一些。运营目前只做效率最高、ROI最漂亮的事：投广告。像post这类工作，之前招人后我都交给运营处理。它对我来说需要花时间，ROI也还可以，但我精力有限，优先级只能往后放，时间不够就不做。

新品我会每天盯着，老品节奏就拉长。新品每天看排名、销量和广告数据并调整；老品一般一周看一次，集中调整。然后再每周统计一次销售数据，对齐销售目标。

这些事听着零碎，摊到每一天，其实也没那么忙。比如最近我8点起床，9点到12点在星巴克，下午1点到晚上10点在办公室。这段时间推进了上个月两个要开模的产品，也毙掉了上个月和这个月选出的品，现在正为这个月的产品KPI发愁。

事情多的时候，我偶尔会用印象笔记列待办，再对照着做（实际上大部分当天都完不成）。更多时候，我还是按心情做事。

我身上也有拖延、懒散、情绪化这些普通人的毛病，做不到彻底改掉；但也正是这些特点构成了现在的我。我的时间管理能力并不强，只能靠加班来补……

自由职业最考验自律，而自律真的能换来自由，这话不假。

在我的时间管理理念里，重点不是把总时长拉长，而是让单位时间更值钱。我更偏向“结果导向”加“聚焦”，这也会结合精力管理。精力管好了，时间利用率和效率才会上去。

这套方法是我在生财学到的，来自易仁永澄老师的时间管理 https://t.zsxq.com/03MrB2Zb6 和 CC 老师的精力管理 https://t.zsxq.com/03ZrfiybY。

对创业者来说，时间维度要拉长看，至少得按半年往上。创业是长期的事，很多时候放弃，是因为坚持不下去了，而不是破产倒闭。

如果把时间放到周甚至月，我一般这样安排：

• 按亚马逊项目流程工作，平均每周60小时；
• 每周做一次文字复盘：2000字文章花1—2小时，6000字及以上花8小时；
• 每周至少锻炼2次，跑步、刘畊宏、健身房、羽毛球都算，平均每周3小时；
• 每周休息一天，大多追剧、看书，偶尔画油画；每两周或每月自嗨一次，通常花一小时痛快唱歌；
• 每月或每两个月偶尔出去玩一次，一般去海边或爬山；
• 每周喝2杯奶茶，主要是为了缓解焦虑（乱入）。

日子看着平淡甚至有点枯燥，但一直在正常运转。要说遗憾，最大的还是没把自由职业者的“自由”用足——空间自由和时间自由。随时随地办公，去任何想去的地方旅行，做自己想做的事。
