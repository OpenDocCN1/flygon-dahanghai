# 新手如何跑通📕虚拟知识库项目？

# 1. 项目全貌：为什么普通人也能做

📕虚拟电商现在是什么局面？龙哥盟的虚拟产品航海已经跑过两轮，带过上千位圈友实操；📕平台也多次更新虚拟电商月度榜单。整体看，这个方向对普通人很友好，多数人都有机会通过它获得收入。但今天的方法和3月已经不同。第一，不能再用简单搬运的思路。📕底层是内容分享，电商基因也建立在内容上，所以它是内容电商，内容是“1”。只做纯搬运的人，往往没有真正理解自己卖什么，只是简单介绍产品、靠大量笔记堆量获取公域流量；这种做法没有壁垒。平台也不喜欢低质内容注水，因为会影响用户体验。因此现在做📕电商，必须深度打磨内容和产品。

# 知识库细分赛道的机会

这次虚拟产品航海为什么选知识库？如果你想在📕卖高客单产品，会发现不少高客单商品本身就是知识库。比如人力资源知识库，定价299元，卖出6126单，总销售额183.1万元……

[PRE2]

所以，如果你想做IP、想在📕卖高定价产品，又不愿意做纯原创，知识库可能是普通人在📕虚拟产品里为数不多的机会。而且知识库生意里，不少项目能做到百万GMV，这百万GMV基本全是利润。

知识库是什么？很多圈友的卡点是觉得知识库构建很专业、非常难、审美要求也高，于是望而却步。这里纠正误区：知识库的关键，是给目标受众提供他们需要的内容。这次航海所说的知识库，不一定全是“知识”，它只是一个统称。

这个项目的核心流程是：调研同行 > 结合自身优势和推荐赛道，确定1个赛道和选品 > 搭建账号并开通店铺 > 上架虚拟商品 > 制作笔记并发布 > 引导成交 > 尝试用AI开发自己的知识库。具体可参考本期航线图：

项目操作重点

对很多人来说知识库比较陌生，其实很简单。知识库可以很小，小到一个面试题库、一份考试经验总结；也可以很大，大到一个个人学习知识库、一个英语口语练习知识库。整体并不复杂。大部分同学要做的事，是围绕出单这个结果展开，不要纠结前期准备，更不要把过程想复杂。比如有人总想推陈出新，做一个市场上从没出现过的产品，研发投入过多；一旦结果不好，很难接受。更好的办法是量大出奇迹、干中学、事上练。先从模仿开始，但模仿不是抄袭，而是借鉴底层流量密码。比如做职场、面试题知识库，可以看职场赛道销量高的商家，研究他们的笔记策略、标题、封面图怎么做、怎么拍。如果自己模仿能力不够，可以交给AI大模型帮你分析。

举个例子：假如你已完成知识库开发，却卡在发笔记，不知道怎么做，也担心没流量。这时要解构一篇笔记：封面图+标题+正文+评论区。观察知识库TOP级玩家怎么发，先粗略模仿，后续再考虑创新。比如很多知识库卖家的封面图，是用手机直接拍电脑屏幕；这种方式新手完全可以复制，也不耗费太多精力。

产品做好后，一定要勤发笔记。一天可以发3篇，围绕产品不同角度去发，同时学会布局关键词。比如9月是招聘旺季，如果你做职场赛道，你会搜什么关键词？把想到的关键词融入笔记。记住，你的笔记其实就是解决方案。

总的来说，📕电商做知识库，关键卡点有两个：第一个是知识库，第二个是笔记。解决这两个卡点后，要思考如何放大结果。尤其是拿到一个账号的结果后，应思考如何赋能其他账号，快速从0-1进化到1-10。

## 1. 如何定位选赛道

# 1. 本章要点：选对方向再发力

方向若偏，勤奋会打折；赛道选对，深耕才更值钱。在优质赛道里持续投入，大多数情况下比在低质赛道里高强度消耗更有效。选赛道主要看两个因素：
- 外部因素：市场环境，决定项目难度和收益天花板。
- 内部因素：兴趣与优势，影响你在这个赛道深耕的毅力。

如果你善于挖掘需求，可以自己找10个竞品调研，挖掘细分需求。本期航海也帮大家筛选出一个大赛道方向和细分赛道，你可以结合自身优势和兴趣选择。⚠️长期看，还是鼓励大家选择自己原创的虚拟资料，所以选赛道时也可以想想：这个赛道的资料，我后续是否有能力原创？赛道意味着起跑线，也意味着天花板。

本章航线图：完成本章节学习和实操，即可完成航线图第一阶段：确定1个赛道和选品（约1.5天）。其中：对10个竞品进行调研，挖掘细分需求（约1天）；确定1个适合自己的赛道和品（约0.5天）。

# 2. 定位与选赛道：先盘资源再找位置

赛道与自身匹配，做起来才会顺手。很多博主内容表达能力很强，但没有合理分析自己的优势，直接扎进不熟悉的领域和赛道，最后草草收场。越急越容易绕远路。做📕虚拟产品，一定要先学会盘资源和找准定位。为什么盘资源和找定位重要？如果你没有盘点自己的优势资源，最后很容易陷入选题慌。比如你是经验丰富的HR，却非要走美妆赛道；HR赛道你是专业的，过往有大量经验积累，在📕上表达顺手，选题源源不断，起号对你来说不是难事——你只是把过去的经历和经验转移到📕。这类经验鲜活、独特、专业，很容易吸引算法和粉丝。这时你再开发相应的虚拟产品和服务，就真正完成商业闭环，也从打工人角色转变成生意人，完成角色蜕变。

到底该如何盘资源和找定位？第一步自我提问：你是否完成过一些成就？完成这个成就的过程中，是否经历挫折和失败？虽然过程曲折，但你最终战胜了自己，并且有足够丰富的表达欲去表达这件事，而且这个经验很利他。这个问题很重要，因为它对你是隐藏的内容金矿；如果不刻意搜索，大脑很难想象你有这样一段经历。这个问题的关键在于：这个经验是否利他。因为你要挖掘出能够利他的因素，否则整理出来太小众，不仅无法引起共鸣，也会打击自信心。所以，要找到真正的市场和你的优势进行匹配，把你的知识残片变成他人的生存刚需。

如果还是不知道如何盘点资源，可以参考以下几个问题自我提问：
- 你拿到过什么大结果？
- 你是否在某个领域有超过其他人的经验积累，比如考公、考证、考研等等？
- 你是否有很强的基础技能：飞书多维表格、Notion模板搭建、视频剪辑、AI、PS、PPT、手绘、Procreate做饭等等？
- 你是否有其他人不具备的复合标签，比如大厂、35岁、父婴博主、留学经历、正在装修房子、即将裸辞、数字游民、减肥成功等等？
- 在核心课题上，你有没有一些傲人的成就和表达欲，以及跳脱俗人视角下鲜活的个体感受？核心课题包括事业、家庭、个人成长、健康、成为更好的自己。

举个例子：如果你非常擅长搭建飞书多维表格，就可以根据用户需求，创建不同场景下的飞书解决方案。现在正是秋招招聘季，有📕博主用飞书多维表格开发了秋招进度表，卖了3000多份。假如你对自己的优势没有思路，可以参考上面5个问题。

看懂需求只是起点，能主动做出新需求更关键。你能想到的解决方案，其他人也能想到；所有人都能想到的办法，一定不是好办法，很容易把智力劳动变成体力活。不要去卷一个没有门槛、完全耗费时间的赛道。虽然你可能看到很多人都拿到了结果，但他们可能并没有披露什么是胜负手。所以，做自己的数字产品时，不要只是整套照搬别人的商业模式。比如别人卖中小学资料，你看到销量很好也跟着卖，结果发现自己根本开不了单。根本原因在于你只是单纯复制了他们的产品，但这并不是你的主战场。可能对方是K12教育老师，非常了解学生需求，发的笔记能解决学生痛点；而你的内容非常普通，毫无亮点。

发现需求有价值，创造需求价值更高。因为只有创造需求，并且这个需求能被消费者认可，你才能建立自己的差异化优势，也就是你的利基市场，或者说是第一个吃螃蟹的人。但要注意：虽然你创造了新需求，由于国内市场竞争激烈，也可能被模仿。所以前期需要迅速扩大自己的结果，比如销量、笔记数。这个道理很简单：如果你是买家，在低客单情况下，一定会选择销量高的商品。假如你在📕搜简历模板，会看到卖同样产品，有人能卖3万单，有人只有几十单。所以前期准备工作一定要到位。

那么如何创造需求？一个需求存在但没被发现，有黄金准则：
1. 它存在一定的技术门槛；
2. 它可以被解决，但是很紧急；
3. 它有一定的社交属性，能够分享到朋友圈；
4. 它经常让人发出感叹：这也能赚钱？

所以，可以去📕看有没有大量类似需求。比如第一点“存在技术门槛”：专业软件安装、CAD安装教程都可以卖几千单。第二点“可以被解决但很紧急”：专业证件照P图，特别是工牌照、海马体、新婚照等。第三点“有社交属性，能分享到朋友圈”：手写婚书、小朋友生日视频定制【奥特曼】。

# 3.1 个人成长类知识库

这一类知识库在📕很常见，但目前已偏向红海，因为很多人都在讲个人成长，而且这个领域有头部玩家：参考答案阅览室。头部玩家参考答案阅览室已占据大部分流量红利，后来者想反超并不容易。个人成长知识库的做法，是把国内外优质的关于个人成长、职场、工作效率、习惯养成等内容进行分类整合，最后提供给用户深度阅读。
