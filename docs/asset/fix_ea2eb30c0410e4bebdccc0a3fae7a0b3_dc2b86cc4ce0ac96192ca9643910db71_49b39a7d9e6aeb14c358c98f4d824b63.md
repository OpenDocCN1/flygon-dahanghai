# 本节导读

这一章分7个小节：执行力、社交关系、亲密关系、时间管理、自信问题、情绪管理、职场问题。每节下面放1—2个问题。除个别情况外，每个问题都从三层来讲：

为什么才干突出反而会带来这个问题？
怎样调整，才能减少才干过度使用造成的麻烦？

才干不能孤立看，要放回场景、目标、身份和行为里。换成更直白的话：我要做什么事，想拿到什么结果，需要连接哪些人，要调动哪些资源，我手上的才干又能怎样帮我把事推进下去？

拿做直播销售来说，沟通和追求靠前的人通常更容易适应镜头，讲产品生动、有表现力；但如果不练供应链、不练价值呈现、不练成交，结果也未必理想。肯下功夫补齐这些环节，成功率才会上去。

换个情况：成就、学习、搜集靠前的人，先研究50个做得好的主播怎么打（学习+搜集），再每天持续练5小时（成就），最后做出来的效果，可能比前者更好。

同一个结果，背后可能是不同才干组合在起作用。更值得关注的是：你擅长用什么方式达成，以及怎样把目标真正拿到手。

下面这些案例不可能覆盖所有情况，多数是从才干角度举例，供你参考，具体问题仍需具体分析。（案例均获本人同意公开）

# 4.1.1 执行力：从目标到结果

执行力说白了就是：定下目标，动手去做，最后拿到成果。

不少人被执行力问题困住：光想不动；样样想试却难做精；忙个不停却看不到推进；总拖到截止前才开工……

受篇幅限制，这里挑两个高频困惑——“拖延：总想准备充分再动手，顾虑太多”和“难坚持：开头热情高，很快放弃”，试着从盖洛普视角给出破解思路。

# 4.1.1.1 拖延：总想准备充分再动手，顾虑太多

拖延是很常见的心理现象，很多人都会被它缠住。

它往往来自对结果的过度担心：怕时间不够、怕能力不足、怕知识储备不到位，也怕过程中冒出难题。于是，任务迟迟开不了头，目标也一直悬着。

① 哪些才干靠前的人容易遇到？
完美、审慎、排难、分析、战略

② 症结在哪（才干分析）
完美：想把事情做到极致，对自己要求高，容易出现“要么不做，要么做到最好”的倾向。如果眼前项目不能充分体现自己的价值，可能压根不愿意启动，也接受不了“能赚钱但回报率偏低”的选择。
审慎：风险雷达很灵敏，看什么项目都能先看到隐患，担心投入后没结果，于是一直等那个“完全放心”的机会。
排难：擅长发现问题、解决问题，还没动手就先推演项目会卡在哪里；如果找不到解法，就不肯开始，总觉得后面做不下去。
分析：喜欢追根究底，做事前习惯把商业逻辑捋顺；一旦想不通，就可能质疑项目，陷进分析里，反而忘了可以用实际行动去检验判断。
战略：很会找路径、找方法。可当选项太多时，战略才干总想挑出最优解，挑不出来就动不了，觉得哪个都不够好。

③ 可以怎么破（仅供参考）
完美：优先选能发挥优势、而不是总在补短板的项目；有时要允许自己“先完成，再完美”。完美才干不等于完美主义，但想做得太漂亮，反而容易压力过大而迟迟不动。
审慎：尽量避开需要频繁决策、不断应对变化的工作，可以选做风险把关、给建议的角色。也可以和“统率”“自信”“行动”“积极”用得好的人搭档，他们能帮你排除异议，先把行动推起来。
排难：选稍微有点挑战的项目。排难才干陷进具体问题时，就像路上有块石头挡着，不搬开就难受；其实也可以绕过去。选项目时别总被尚未发生的问题吓住，那会限制行动力。可以把问题全部列出来，要么在行动中解决，要么找前辈请教，别把“大招”一直憋着。
分析：不是所有项目的商业模式都能理得明明白白。分析才干得不出结论时，也可以先下场验证，或与“行动”才干强的人合作，边做边看。
战略：长期最优，不一定等于当下最优。要结合自己所处阶段和目标来定策略，也可以考虑和“行动”“成就”才干靠前的人配合。

# 4.1.1.2 开头猛、后劲弱：热情来得快，去得也快

所谓开头猛后劲弱，是指一开始热情很高，但因为某些原因很快失去兴趣和动力，随后放弃，或者转向别的事情。

① 哪些才干靠前的人容易遇到？
行动、适应、理念、战略、学习等

② 症结在哪（才干分析）
行动：行动靠前的人启动快，不太纠结结果，先干起来再说。可一旦尝试后没拿到正反馈，就可能觉得继续下去没价值，于是丢下这个项目，换下一个。
适应：适应靠前的人能随环境调整，对当下反应快。如果被杂事反复干扰，进度被严重拖慢，甚至事情没结果，也容易来一句“算了吧，顺其自然”。
理念：点子多，不喜欢枯燥重复的事。做的过程中一旦冒出新鲜想法或有趣的事，就忍不住去试，手头项目可能因此被晾在一边，最后半途而废。
战略：擅长找路径、找捷径，会不断尝试寻找更好更优的项目，容易觉得现有方案不够好，于是把当前项目搁置。
学习：好奇心强，爱学新东西，但不一定盯着学习结果。可能报了不少课，学到知识就满足了，看到新课程又想继续报。

③ 可以怎么破（仅供参考）
行动：可以考虑和“前瞻”“分析”“战略”“回顾”突出、且有一定领域经验的人合作，他们能给出更长远的方向和决策判断，帮你看清前路，形成优势互补。
适应：避开需要长期规划的工作，更适合短期任务。可与“专注”“战略”“信仰”突出且有领域经验的人合作，让他们帮你理清长期目标，把注意力拉回主线。同时主动接受一些挑战，多和优秀的人共事，自然会被带动起来；尽量别待在凡事规规矩矩、鼓励躺平的环境里。
理念：尽量选需要创造力、新想法的工作和项目，让天性有发挥空间。也可以和“分析”突出的人合作，帮你补足落地性；或与“行动”突出的人搭档，他们能快速行动，帮你验证想法。有时候边想边做，比非要想到“更好的点子”再动更有效。
战略：适合做替他人做策略参谋的角色，最好围绕目标来定战略。没有目标牵引，战略才干容易绕弯路。如果你执行力维度偏弱，可与“行动才干”或执行力强的人合作，让他们把你的部署落实下去。

# 4.1.2 社交关系

社交是日常绕不开的课题。

不管在学校、职场，还是朋友聚会，我们都可能遇到各种社交挑战。这一节主要解决两类难题：如何与陌生人或不熟的朋友打交道。
太在意别人怎么看，怕说错话，不敢社交，怎么办？
凡事自己琢磨，不好意思开口问别人，如何打破这种沉默？

[PRE4]

# 4.1.2.1 太在意别人评价，怕说错话而回避社交

这种状态，通常来自对他人评价的过度关注，以及对自己能力的不确定。很多人面对陌生人或社交场合时会紧张、有压力，于是选择沉默，能躲就躲。

① 哪些才干靠前的人容易遇到？
和谐、审慎、体谅

② 症结在哪（才干分析）
和谐：当自己和别人观点不一致时，如果担心可能冒犯对方，就不一定说出真实想法，容易委曲求全。
审慎：本能地会预演每句话可能给关系带来的伤害，字打出来又删掉，不想面对“祸从口出”的场面；在不安全的交流环境里，干脆不发言，先保平安。
体谅：总能感受到听者的情绪。如果自己的话让对方不舒服，自己也会难受；为了避免这种情况，会尽量说让对方舒服的话，有时担心打扰对方，索性就不去联系了。

③ 可以怎么破（仅供参考）
这三个才干相处起来很舒服，但用不好时，可能因为太照顾对方而忽略自己的感受和需求。如果思维靠前、沟通靠后，容易在脑子里预设“对方听了会不舒服”，从而不敢连接，而不是在实际相处中验证。别全凭猜测和直觉判断对方是否不舒服，适当提高“钝感力”，也可以直接向当事人求证。
多和“沟通”“积极”“取悦”“包容”用得好的人交流，他们容易开启话题，也能自然地把朋友介绍给你，帮你打开社交圈。
找到自己擅长的领域，持续做出成绩，愿意和你做朋友的人自然会多起来。
推荐书籍：《被讨厌的勇气》《5%的改变》《重塑心灵》《沟通的方法》

# 4.1.2.2 习惯独自琢磨，不愿开口请教

总是一个人研究，可能本身就享受探索过程；也可能是怕暴露“不懂”“问题太基础”，担心被批评或否定；还可能是不想麻烦别人，被想象出来的恐惧拦住了。

① 哪些才干靠前的人容易遇到？
排难、分析、思维、体谅、责任

② 症结在哪（才干分析）
思维：喜欢思考，也享受独处，想通了就开心，可能没养成向别人请教的习惯。
排难：习惯自己上手解决，也可能担心打扰别人；一旦解决不了，心里就难受。
分析：喜欢把一件事的来龙去脉研究透，享受这个过程；研究不透时，也会难受。
体谅：担心打扰对方，不希望对方产生不好的感受。
责任：不好意思麻烦别人，怕给别人添负担，也怕让人觉得不靠谱。

③ 可以怎么破（仅供参考）
分析、思维、学习、搜集靠前的人，往往享受研究、搜索知识、推进项目的过程。要留意的是，别陷入过度思考而迟迟不行动；研究不明白时，多用行动去验证理论。
体谅、责任突出的人，如果担心给别人添麻烦，可以考虑付费请教，或加入行业交流群——本来就有这份权益；也可以和别人合作做项目，有了安全的表达环境，体谅和责任的负担就会轻一些。
试着做“发起者”，比如组一个“某某项目交流群”，邀请兴趣相投、做事认真的朋友一起研究，也能创造安全的交流环境。
善用ChatGPT或搜索工具找答案。

# 4.1.3 亲密关系

在亲密关系里，记住两句话：“谁先改变，谁就是关系的引领者”“好的亲密关系，不是总讲道理”。两个人的才干报告差异很大，既可能互补，也可能水火不容；报告很相似，既可能特别懂彼此，也可能纠缠不休。关键看两个人怎么调整，能不能一起面对问题、解决问题。
想让关系越来越好，最好从“先了解彼此”开始。懂比宠更重要，只靠一个人，解决不了两个人的问题。
建议和伴侣一起学盖洛普，把这份报告当成一种对话语言，减少主观评判，增加看见彼此需求和差异的机会，也更容易找到突破口。

# 4.1.3.1 相处模式难磨合

每个人性格不同，相处方式也各不相同。这里用一个盖洛普报告差异较大的案例来展示。

难磨合的痛点：
常见的情况是：女生想尝试某件事，男生会先分析一通。他不是故意打击，但分析完，女生会发现很多项目产出可能并不高，总像被浇了凉水。平时逛街男生也不太感兴趣，她只能找闺蜜。
女生希望男生多理解自己，支持她做一些尝试，而不是完全用理性分析来回应。

怎么磨合？

① 借才干报告看懂对方需求
男：战略 成就 追求 专注 统筹 分析 行动 责任 取悦 个别
女：体谅 理念 积极 伯乐 个别 搜集 战略 交往 学习 思维

男生在事业上很清醒，勤奋、有野心、非常理性，不愿把时间花在无意义的尝试上。
女生在关系里更主动，喜欢尝试新奇事物，会报名各种课程，也很能体会他人感受，整体更感性。
两个人本能的习惯不同，差异自然会出现。以旅行为例：男生大概率希望先明确目的地，按计划走就行；女生即便做了规划，到了地方发现别的更好玩，也可能临时更换。
男生可能会疑惑：怎么又去别的地方了？不是说好先去甲地吗？
女生则觉得，如果提前把计划讲得太清楚，一切都在预料之中，就少了一点意外之喜。

② 一方先换位，主动改变
关系磨合，总得有一个人先动。能开始换位思考，对方感受到关系有变化后，再聊需求、讲道理，效果会好很多。如果没人先改变，新的关系模式就不会出现。
怎么知道对方的需求？
去看34项才干卡片里每个才干下方的“我需要”一栏。比如“追求才干”，越被欣赏越有能量，格外需要一个能欣赏自己的伴侣。
那就多创造能展示他的场景，并经常赞美他，他会很开心，也越来越有能量。如果他长期不被关注，可能会觉得失落。
用盖洛普工具理解对方的需求，彼此的付出才更可能对上频道，关系也会更甜。

# 4.1.3.2 另一半总读不懂自己的需求

亲密关系里，常见一种情况：你不理解对方，或者对方不理解你。沟通一旦不畅，双方就可能陷进不健康的相处状态。

① 容易遇到的人，才干如何分布？
可能关系建立、战略思维、执行力靠前，而沟通才干靠后。

② 症结在哪（才干分析）
每个人都不一样。如果对另一半了解有限，就可能按自己的猜测，用“自己觉得爱对方的方式”去爱。比如：无微不至地照顾、不想给对方添麻烦、替对方省钱，觉得这些都是爱的表现。但对方可能恰恰不喜欢这种方式，反而觉得自己不被需要、没有价值感，甚至感到压力。
关系建立靠前的人，对情绪和需求很敏锐，有时不用多说就能猜出对方需要什么，也期待对方同样懂自己。如果对方没做到，就可能觉得对方不上心。
执行力靠前、沟通靠后的人，往往不擅长说，更愿意用行动表达爱。但这种方式是否符合另一半的期待，就不一定了。
如果对方不是关系建立突出的人，可能真的没有你那么敏锐，于是你容易生闷气。

③ 可以怎么破（仅供参考）
直接、明确地说出自己的需求，有时比让对方猜更有效。比如你希望对方也分担家务，就直接商量：能不能一起做家务。
定期交谈，比如每周或每月聊一次，说说相处中的感受，增进了解，而不是把情绪都压着不讲。
学一些亲密关系里的沟通技巧，读相关书籍，在实践中慢慢迭代。

# 4.1.4 时间管理

时间管理是每个人都要面对的课题。同样24小时，有人能兼顾工作与生活，还能保证睡眠；有人只能熬夜加班，成果却拿不出手。
这一节主要讲两个问题：
计划总落空，怀疑自己不自律又浪费时间。
时间不够用，想做的很多却都做不好。

# 4.1.4.1 计划总落空，怀疑自己不自律又浪费时间

① 哪些才干靠前的人容易遇到？
适应、理念、行动

② 症结在哪（才干分析）
适应：非常灵活，擅长短期任务，越在变化中越舒服。强迫自己按计划走，会压抑灵活的天性；也可能给自己塞了太多任务，最后完不成。
理念：想法多、想尝试的也多。一旦冒出新点子就想调整，看起来就像坚持不住原来的计划。
行动：想到什么立刻开试，善于启动，但不执着于结果。尝试后没有正反馈，就换新的继续试。

③ 可以怎么破（仅供参考）
适应：尽量选需要灵活性的工作，比如关系建立靠前的人可以做用户运营；也可与“战略”“专注”靠前的人合作，既看长期，也看短期。
理念：避开重复性事务多的工作，考虑创新、创意、需要给客户提供解决方案的岗位，让理念天性有发挥空间。同时可与“专注”“成就”“分析”用得好的人合作，他们或许能帮你把想法完善并落地，而不是新点子不断却都没结果。理念才干的自律，不是一成不变，而是提高想法的可落地性。
行动：尽量选处于初创期或需要转机的工作内容，行动才干的敢试会很有价值。可与“战略”“分析”用得好的人合作，及时找准方向，持续迭代拿结果。

# 4.1.4.2 时间不够用，想做的很多却都做不好

① 哪些才干靠前的人容易遇到？
成就、统筹、适应

② 症结在哪（才干分析）
成就：像停不下来的小蜜蜂，闲不住，完成任务才有成就感。有时会积压过量任务，导致时间不够用。
统筹：擅长多线程推进，能同时做好几件事。可当并行任务过多、忽略资源有限时，就可能哪件都没做好。
适应：习惯根据当下环境调整任务优先级。中间插入一件事，就把精力投进去，结果每件都没干完，局面容易乱。

③ 可以怎么破（仅供参考）
成就：答应接任务前，先评估自己的精力，别轻易点头。
统筹：多留意可调动资源和任务之间的匹配度，同时做多件事之前先做减法。
适应：适当屏蔽干扰，可以在身边贴优先级任务表提醒自己，减少微信、App和他人信息的打扰。
