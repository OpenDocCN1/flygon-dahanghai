# 情况二：直播违规红线，提前避开

做视频号直播，先把规则摸清，比一味冲流量更重要。下面这几类问题最容易踩线。

## 1）不正当营销：低价、赠送、福利承诺不能随口说

视频号橱窗达人不能靠虚假福利承诺、虚假抽奖、虚假赠品等方式拉人气、诱导关注，最后却不兑现。直播宣传里出现“全场1折”“1折清仓”“全场X元/折起”“免费送XX”“某品牌商品个位数”“全场清仓/全清/清完走人”“专柜X折”“特殊材质商品个位数”“扣XX免费送”“新人免费送”等说法，都可能被判为不正当营销。直播间物料和举牌也要注意，纸质印刷物、电子屏、灯牌、第三方推流贴图等位置，都不能出现“1折”“X元”“免费送”等字样。低价商品高运费同样属于引流套路：商品价格明显低于市场价或成本价，却另外收取高额运费。打击范围还包括直播间口述、视频号昵称、简介、直播主题、公屏互动等场景。比如“工厂直销一折优惠”、标题写“全场9.9”做低价引流、直播间直接展示免费试用、“直播间新人每人送2份见面礼”、用1元商品引流但实际商品价格高于宣传价，都在风险区。

应对策略：从平台处罚频次看，不正当营销排在前面。低价、赠送、福利品这几类玩法，都容易被认定为不正当营销。视频号当前不认可靠低价拉流量的做法，商品价格设到9.9以下不行，折扣打得过猛也不行；在官方判断里，这属于恶意竞争、打价格战。因此，把抖快那套直播玩法直接搬到视频号，未必行得通。具体细则见《视频号橱窗达人【不正当营销】实施细则》：https://support.weixin.qq.com/cgi-bin/mmsupportacctnodeweb-bin/pages/f1CGl0U4bOXqGABK

## 2）低质量内容：无人直播、录播别碰

平台把无人直播和录播归入低质量内容，原因在于画面播放的是提前录好的素材，而非实时开播。若没有走特殊申请，这两种形式现在都不能做。需要说明的是，绿幕直播本身可以，但背景若挂一段视频反复循环，就不行。从今年2月开始，平台对背景视频开了一个口子：服装类直播间能用模特走秀视频作背景，画面要清楚、铺满全屏，暂时只限这一种。想参考的话，可以看两个持续开播的账号：百丽集团旗舰店、佑游健身。具体细则见《视频号橱窗达人【发布低质量内容】实施细则》：https://support.weixin.qq.com/cgi-bin/mmsupportacctnodeweb-bin/pages/3YNfDmg53I7Zsldl

## 3）这些场景和品类细节也要注意

直播间封面、背景、头像、主题、评论区、昵称等位置，不要出现“扣XXX送XX”“新人送XX”“关注送XX”“免费送XXX”等虚假福利或不正当营销内容。类似“扣1，分享朋友圈送手镯”“关注送项链”“扣666免费送梳子”“新人免费领大礼包”“进来免费送”“0米送”等用礼品诱导互动的说法，都要避开。更多敏感词可查《视频号直播敏感词汇注意事项》（https://docs.qq.com/doc/DWEZSUmdDaXNkS1dh）和《视频号直播违禁词大全》。

不同品类还有各自规则。以生鲜类直播间为例：第一，镜头里必须展示实物商品；带包装的商品要拆开包装展示里面的实物，不能用绿幕代替商品展示。换句话说，包装和内容物都要出镜，不能只拍内容物。卖生鲜肉时，带包装的产品也要一起展示，不能光拍肉；卖冰冻鱼时，不能只拿新鲜鱼出镜，冰冻包装鱼也得展示，免得让消费者误解。第二，商品标题、实物包装上的名称、直播间展示的实物，三者必须对得上。

最后分享一个实操经验：直播中如果后台先后两次弹出直播处理通知，建议立刻下播，另开一场新直播。原因在于，第三次收到弹窗，处罚起步就是禁播1天；重新开播后计数会重置，能稍微降低禁播风险。
