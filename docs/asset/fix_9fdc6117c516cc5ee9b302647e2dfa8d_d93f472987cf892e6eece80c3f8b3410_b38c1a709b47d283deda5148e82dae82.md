# 微商团队别再靠人硬扛：把组织做成系统

我是小王子。做微商到第二年，我下决心拆掉旧架子：原来靠人情、靠个人盯人的那套管理，要换成可复制的标准动作和协作流程。

旧办法是“谁拉来的人，谁管到底”。新人从写文案、受培训，到复购、升级，全压在引荐者身上。带得动带不动、有没有空，都得硬上。责任感强的会认真管；责任感弱的，钱一到手就失联，而且这种情况占多数。

我们曾在一年内分出三十支左右小团队，可到第二年，大半都没了动静。复盘下来，原因有四类：

第一，负责人未必腾得出时间，本职工作一忙、家里一出状况，精力说断就断。  
第二，自己卖货和带一支销售队伍是两回事。不少人原创能力不足，社群不会运营，也调动不了气氛。  
第三，有人只盯着短期收益，收一波就走，没有长期打算。  
第四，负责人活成了杂工，海报、课程、讲课、社群全自己扛，时间久了非常累。

看清弊端后，我开始推标准化与流程化。说白了：伙伴只负责把人带进来，后面统一送进“微商学院”这套运营中台，由专人培训，出来就是能打的微商人。引荐者不必再把时间耗在带人上。

这套学院每期大约收九十人，成员从级别靠前的伙伴里选，专门服务团队。（运营地图见图1。）

我让他们参与线上运营，有两个考虑：一是卖货之外多学一门本事；二是团队不是我的私产，希望大家有主人翁意识，一起把盘子做大。

学院分三块：

**导师学院**（两位院长牵头）：销售培训组管新人培训、销售实战、朋友圈特训、故事课等；产品知识组讲产品，也承担招商会答疑；朋友圈组做培训、大型活动文案模板，还点评伙伴的朋友圈。

**运营学院**（两位院长牵头）：公众号组更新大群和活动内容，接近日更；海报设计组包揽日常分享与活动海报；统计组相当于财务，记活动经费；社群运营组负责各大群、培训群和线上招商会群。

**流量学院**（我自己带）：讲获客方法，让伙伴们去学。

成员多来自最高两个级别，对团队黏性更强、更忠诚，既练技能，也有助于业绩。体系跑了十八个月，一直在迭代；每季度招新，新人有入口，老人也能带新人。团队实现自动运转，我腾出手去做更高层面的事。

它还是扩张的承接器：伙伴敢招人，后端随时接得住。去年下半年我越发确信，缺少标准流程，大流量来了也接不住；大IP通常不会亲手带微商新人，我们把这块兜住，合作就少了后顾之忧。

## 2. 社群分舱，各群只做各群的事

**基础群**有五个，所有级别的用户都在里面。目标是让大家产品用得开心、放心、有信心；每天排课，靠氛围带动自动升级和复购，促单压力也轻了。社群运营组提前七天排好下周课表，方便大家转发到朋友圈。

**代理群**只有一个，只谈销售和财商，最高两个级别才能进。作用是承接基础群的人往代理升级；销售上的疑难杂症都能在群里互相支招，出单就打卡，彼此刺激，让金钱和能量流动起来。每半年，我会请专业财商老师带大家做一次基金定投。微商手里现金流多，我希望大家别当验钞机，而是让钱经过思考后真正留下，而不是买豪车豪宅糟蹋掉。（代理群海报见图2。）

**全国总代群**也只有一个，成员是对团队忠诚、业绩漂亮的最高级别伙伴。有些话对外讲容易引起误会，我会在这里说；这里也做价值准则宣导，隔一两周启用一次。

各群功能分明、职责分明，免得混乱。当时的考虑是：有人只想当用户，不想看见销售内容；群里一发销售信息，他们会觉得被推销，心里不舒服。所以干脆分开：基础群不碰销售，代理群只聊销售与财商。

这么多社群谁来运营？就是学院的社群运营组。他们内部也分工明确，每周有人提前安排。

训练营群也有流程：先由统筹发起项目，招募运营官和小助手，安排好导师与课程；海报组出图，社群运营组负责运营，各司其职，一起完成项目。

## 3. 培训排成课表，新人和老人都有路径

针对新人，也就是最低级别伙伴，我们提供新人培训，内容包括：价值准则宣导（我亲自讲）、产品知识、资料库建立、出道文怎么写、如何加人、怎么开口讲产品、微商常用APP使用等。

作业按课程内容布置，文字、图片类提交到打卡小程序，导师打分。开口讲产品这项作业，是让伙伴跟自己的上级模拟一段买卖对话。新人培训每月一期，滚动开班。

针对最高两个级别，提供销售实战培训和价值观输出特训。他们就是冲着赚钱来的，所以要有文案训练、销售实战训练；大家去实战，导师点评，在线共同学习。

此外还有日进斗金训练营、瘦身营、美妆营等。训练营收的押金比较高，在五百至一千五百元之间，目的是保证完成质量。

我做过六年英语老师，其中三年半在机构做培训，写过大量教案、教学计划和作业设计，所以会参与团队课程设置。我受不了粗糙的培训，也知道什么课程适合什么样的学员、学完会有什么结果。

## 4. 线上招商会：越短越有劲

我们每隔两到三个月办一次线上招商会。一般由导师学院年初做好规划，提前十五天准备：先找统筹人，也就是项目经理，再由她牵头成立工作组，宣传、海报、审核、统计、答疑、故事、场控、公众号等各就各位。

正式开始前，我们会彩排一到三次，看时间卡点和配合度。以前搞过三天、两天，最近两次尝试六十分钟快闪，我发现大家更喜欢快闪式。最近线上招商会成交的客户，基本是被我们的运营吸引来的。

内容设置上，如果做六十分钟场，就不单独讲产品。正式开始前，先在群里接龙产品疑问，答疑组迅速写下答案，留到答疑环节用。开场由团队长讲团队规模、业绩、价值观；接着两三个人讲故事；再是产品答疑；最后促单。

我们会提前定制很多礼物。快闪式招商会，一个群六十分钟成交额在三十六万元左右，这是最近的数据。

招商会结束后，会有很多新人进来。接下来一周，我们办新人培训，大约一周时间；新人往往学会朋友圈框架、怎么开口谈单、如何整理资料、如何加人，也会出货，于是开始考虑升级。再过一周，办销售实战培训，专门练硬核技能，也就是出货。从招商会到最后两次升级，基本不需要邀请人操心，学院运营团队全搞定。

## 5. 心法：让九十多人愿意持续把事做好

看到这里，你会发现所有活动都是运营团队在做。组建这样一支队伍不难，难的是让九十多名运营成员除了卖货之外，还愿意义务做事，并且做得很好。

### 01｜价值观教育

我们有个十二字价值观：克制务实、极致利他、长期主义。它像公司的企业文化，把心聚在一起，做事才不累，也更容易出成果。

微商现金流多，一不小心就去赚能力圈外的钱，P2P、各种盘，倾家荡产的不在少数。我不希望伙伴们碰这些，所以必须克制务实，克制贪欲。同时，也不要链接不靠谱的人，万一哪天爆雷，容易受牵连。

我一直提倡做个人影响力，这是长期过程，要耐得住寂寞，每日耕耘。打造个人品牌的核心，就是长期持续做一个靠谱的人。我们的项目也不错，是快消品，一直做一直有复购，其实是一本万利。我不希望他们今天做这个、明天做那个，做一辈子还是低层销售。

另外，大家要团结一致、互帮互助，比如一起做线上运营，共同运营团队。我们的价值观就是这么来的。

如果你也带销售团队，一定要有价值观。不管是公司的还是自己的，要挂在嘴上，从上到下知行合一，团队凝聚力才会越来越强。

### 02｜招募环节：竞争上岗

我们的运营成员是竞争来的，这样大家会更珍惜。

提前十五天发招募通知，并做一张表格，内容包括：八个工作组你愿意进哪个？你曾经有什么成就？你愿意在这件事上花多长时间？为了做好，你愿意付出哪些努力，不低于三点？

通过这些问题，我们能大致了解他们的想法和行动力。第一轮挑积极认真填问卷的人；第二轮筛掉平时不在群里出现的人，因为我们对他的才华不了解，也不清楚为什么这次冒出来。

名单确定后，四位院长分别通知自己的队员，告知被录取，并附一张精美录取海报，上面有团队公众号二维码。大家一定会发圈，开心得到这来之不易的运营机会，公众号也就传播出去了。

### 03｜开营、结营仪式

仪式感很重要。

作为团队长，我不参与这些细节。开营、结营仪式属于社群运营组的工作范畴，全部交给他们策划。

开营仪式上，最先出场的是我。我会隆重介绍四位院长，他们是我的左膀右臂，在团队改革中立下汗马功劳。一一介绍，一方面是让他们和所有人看到：我这个团队长没有居功自傲，也没有夺取劳动果实，我是发自内心欣赏并尊重他们；另一方面，也侧面暗示新一期运营成员：请尊重他们，配合他们的工作。该给的情绪价值，要给到位。

接下来是四位院长出场，然后各工作组组长出场介绍自己。

开营仪式和其他社群活动里，我总能发现团队中的运营奇才。所以，如果你觉得自己团队没有可用的人，一般来说只是你没发现。

结营仪式上，对功臣大赏，物质和情绪价值都不会少。

### 04｜每月一次分享

这个分享不是培训。在运营上他们比我更厉害，轮不到我培训。我主要讲成长类内容。

招募前我们许诺过：进商学院，第一可以获得技能，比如公众号编辑、销售培训、社群运营等，我愿意给万人团队背书，方便他们出去卖技能；第二可以优先获得我的成长经验，我今年的学费差不多有四十五万元；第三，如果他们愿意转型，我会对接一些微商团队代运营项目，在这里做得好，我可以推荐出去帮别人做运营赚钱。

### 05｜团队长的角色

我一年多没参与群里任何运营，都是在一旁静悄悄地看。我想要什么效果，运营团队去帮我实现。

团队里的定海神针。说起来我只是团队的吉祥物，也是他们说的定海神针：随便怎么折腾，有我顶着。

团队长是引领者。我坚决不做服务员、老妈子，坚决不养巨婴。我在前面走，愿意跟着的人就一起走。

我愿意让优秀的人更优秀，让牛逼的人更牛逼，而不是把精力放在末端。

团队长要出圈学习，链接圈外人脉。我曾经组团大约四十人去学习社群运营课，回来之后一个眼神大家都懂了，工作效率极大提高，质量也更高。同时，作为团队长，也要花钱出圈学习，不要把自己框死在微商领域。

一年前，我在这里只分享了做法，那时运营体系还不太成熟；一年后的今天，我分享的是背后逻辑和心法，因为这个体系目前非常完整、运营流畅，希望能给大家带来不一样的视角。

道理听来终觉浅，真正落地还得自己练。如果我的分享对你有用，那就去练起来吧。
