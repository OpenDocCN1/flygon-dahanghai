# 2.7.5 锚点收益避坑清单

从 3 月 13 日开始，单条视频绑定的锚点不再受结算周期限制，长期有效；数据回传和打款节奏与“番茄小说”保持一致。

报名采用问卷形式，按天登记达人信息，需要填写发文账号、发文抖音号、发文抖音 uid 和 did、粉丝量。周一至周五每晚 16 点截止收集，预计当晚 20 点后，已上报账号的锚点“故事”标签就会生效。

达人想选书时，可以直接在抖音添加，也能通过[达人选书库](https://bytedance.feishu.cn/sheets/shtcndcoSv3hTWu8CiR1MEDkNRe?from=from_copylink)筛选。

划重点：视频里一定要有引导粉丝点击锚点的文案、话术或小标识等指引动作。否则视频流量再高，也很可能拿不到任何收益。

视频发布成功即生效，但锚点会经过“相关性审核”，也就是发布内容要和锚点书籍对得上。若内容与锚点书籍不相关，锚点会被撤下且无法重新绑定，进而造成收益损失。

如果锚点无缘无故消失，请尽快联系对接人。

同时要确认上报的发文抖音号和收款账号准确无误，否则锚点和收款都可能无法正常获取。

另外，不要同时添加“位置”和“标签”。抖音默认“添加位置”优先级最高，一旦选了位置，锚点就会被覆盖。
