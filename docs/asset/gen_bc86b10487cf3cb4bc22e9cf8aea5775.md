# AI绘画正热，批量出图怎样接住流量

AI绘画这段时间有多热，刷几条抖音、B站或小红书就能感受到。相关内容里，大约九成是在晒生成的图，剩下一成左右才讲教程或做引流。我是明月，98年生，平时喜欢研究各种好玩又能赚钱的工具。稍加留意会发现，这些刷屏作品背后，出镜率很高的并不是功能复杂的主流AI绘画软件，而是一款叫“意间AI绘画”的微信小程序。

它凭什么比功能更强的主流工具更容易出圈？我看有两点：第一，操作轻、上手快，门槛低；第二，支持图生图，作品能和用户本人产生联系，分享欲更容易被点燃。这个路数，和之前爆火的“羊了个羊”很像。

那能不能借这波热度做流量？说白了，就是怎样用AI绘画把流量接住。下面分享我花一周摸出来的做法：用Stable Diffusion（下称SD）批量出图。

评论区里也有不少实操交流：有读者刚报名AI绘画课程就刷到这篇，直呼幸运，并问实操遇到问题能否再来请教；作者回复可以，欢迎链接。有人评价文中的比方很好懂；也有人追问，用SD批量出图到底怎么蹭意间的热点。作者补充得很直接：意间AI出图效率偏低，可以用SD模仿意间的风格批量作图，再用多个账号分发作品。提问者表示理解并致谢，还有人直呼太牛。另有读者反馈，在微信小程序里搜“AI绘画”，搜不到任何小程序。
