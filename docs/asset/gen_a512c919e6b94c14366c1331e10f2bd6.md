# 一、基础认知 @洛羽

## 1.1 资料、信息与知识整理到底是什么

互联网时代，几乎人人都有电脑和手机。为了获取更多信息和资源，大多数人的设备里装了不少资讯、社交、办公、学习甚至理财类软件，每个软件又会源源不断产生碎片信息。

面对这些碎片，多数人的整理方式是怎么方便怎么来。看到好内容，第一反应是收藏：要么用网页收藏工具，要么顺手转发到🛰️或朋友圈。这样存的时候很轻松，可等到要用时，翻遍用过的软件、平台和聊天记录，也未必找得到想要的东西；即便找到了，中间也耗掉大量时间。

相比之下，另一些人能迅速定位自己需要的资料。别人还在苦想“在哪里看过”“东西放哪儿了”，他们已经高效且靠谱地把内容摆了出来。

资料与信息管理是乱是整，往往也映照出一个人大脑处理信息的条理程度。

当然，也不排除极少数人看到资料的同时就能直接消化运用，不需要再额外整理。但这样的人有多少呢？我们 99.9% 的人都是普通人，没有这么强的信息处理能力，只能靠反复“搜集+理解+消化+应用”，才能对内容有一定把握。

所以从总体上看，一个人能把所有资料和信息分门别类整理好，并在任何时候快速找到所需内容，说明 TA 具备很强的资料信息整理能力。这几乎可以算作互联网时代的一项“强大竞争力”。

知识整理也类似。常规理解中，它和资料管理、信息管理没有特别明确的概念区分，都是对内容进行处理。按专业理解，资料和信息更偏向即时的、碎片的、海量的、尚未经过实证检验的内容；知识更偏向时间与实践沉淀出来的、较体系化的、有数据和样本支持的理论和方法。

总的来说，资料也好、信息也好、知识也好，不必在概念上纠结太多。只需知道：所谓资料/信息/知识管理，本质上是一项重要的内容管理技术。它通过工具和策略对内容做有序处理，目的是让这些内容能够妥善储存、提取和使用。

为方便操作，下文不再对上述内容做概念区分，统称为“资料”，对“资料”的处理统称为“资料管理”。

## 1.2 做好资料管理能带来什么

学会资料管理这项技能，好处不少，归纳起来主要有以下几点：

### 1.2.1 工作产出更高效

工作是我们投入时间精力最多、也必须要看到成果的领域。如果能通过收集和整理，搭建出自己的行业资料库和业务资料库，工作效能就会明显提升。

具体来说，当资料库分类清晰时，平时看到行业或业务相关资料，可以快速收进去；后续需要时，又能快速提取出来，用于实际工作参考或运用。

除了收集和提取外来资料，还要沉淀和提取个人方法论。当业务取得一定成果时，可以把相关项目资料和方法论梳理出来，有序沉淀到资料库中。后续遇到同样的业务需要跟进，或者其他人需要参考资料时，就能快速提取复用。

### 1.2.2 个人成长更高效

个人成长领域也一样。如果能通过收集和整理，搭建出自己的人生资料库，成长效能同样会大大提高。

具体表现和上面类似：资料库分类清晰后，平时看到任何与个人成长有关的内容，或者自己取得任何成长和进步，都可以把相关资料沉淀进去，方便后续参考和复用。

持续地“搜集+理解+消化+应用”，成长就不再是碎片化、毫无章法的，而是有迹可循、不断迭代的。可以把自身看成一个系统，资料库则是外挂大脑；升级外挂大脑的同时，个人系统也在升级。

### 1.2.3 打开第二增长曲线

除了工作和成长，资料整理还有一个隐形好处：拓展第二曲线，开辟更多营收渠道。

据我所知，和资料、信息、知识相关的商业化思路主要有：

资料引流：把整理好的资料放到各平台引流，再在私域完成成交转化；

技能变现：承接资料收集、整理和出品的商业需求，直接靠技能变现；

IP 打造：在整理和消化资料的过程中，逐渐成长为“知识型 IP”，并通过内容本身进行商业化变现。

这几种方式难度依次递增，下面逐一展开。

#### 1.2.3.1 用资料做引流

设想一个场景：现在让你添加某某🛰️，免费送你价值 1999 元的 100 份直播电商报告、100 份直播脚本、100 份私域操盘方案、10 节视频直播课程……如果是真的，你愿意添加吗？或多或少，一定有人会加。

再回想一下，我们在📕、朋友圈、知乎等平台，是不是见过类似的送母婴育儿、运营地图、私域方案的资料玩法？

为什么一定有人需要？其一，有人帮忙做了整理，节省了本人大量时间；其二，大多数人都有厌损心理，总担心自己错过重要资料。

这些资料可以是电子版资料或模板、语音直播课程，甚至纸质书籍，全看引流需求。一般来说，以电子资料为主，交付较轻。

比如现在只要涉及 ChatGPT、知乎好物、直播带货、私域运营、外卖 CPS、跨境电商等任意一种资料，就一定能吸引一部分用户关注。

等用户通过获取资料进入我们的私域池后，再引导他们购买其他商品，就能实现营收变现。

这就是资料引流的玩法，资料整理是其中至关重要的技能。

#### 1.2.3.2 把整理技能变成收入

不知道大家有没有看到龙哥在星球分享的，关于开设“资料整理”这个航海选题的考量。

他说：

“对于很多圈友来说，其实是没有专业知识的，更没有专业知识的输出能力，属于没吃过猪肉只看过猪跑的这群人。

比如我让你设计一套社群运营课，你肯定设计不出来，但我让你收集整理一下：互联网上有哪些好的社群运营相关的文章，帮我整理出来，清晰呈现给我。

这个你大概率能完成，我愿不愿意付费？当然，我需要这样的整理好的东西，节约了我大量的时间。

所以，没什么专业知识的人，学一学资料收集整理的技能，反而很多人愿意买单，因为绝大多数人实在是太懒了。”

关于资料管理的技能变现，类似的还有：

1）把嘉宾分享的音频、视频、现场内容整理成逐字稿，并打磨成一篇干货文章交付给需求平台。我通过这种方式，和笔记侠、腾讯学堂合作过。

2）将一些专业人士分享的内容，收集整编成一本电子书或实体书籍。比如赚钱圈友七小，为很多有 IP 的圈友汇编了电子书，这里面有一定的合作空间。

3）将一些课程或书籍的文字内容，整理提炼成思维导图或各类视觉笔记。这种方式可以和樊登读书会、得到以及商业书籍出版社合作。

4）把自己整理资料的方法论沉淀出来，通过技能教学实现商业变现。

#### 1.2.3.3 走向 IP 变现

💡

互联网时代，很多人都在打造个人 IP。个人 IP 中有一类叫“知识型 IP”，即对某个特定领域有比较系统全面的知识储备，能提出比较专业深刻的见解，以及切实可行的建议。

要成为这样的“专家”，必须有足够的信息输入，还得把信息转化成自己的认知和经验。这就离不开强大的资料收集、整理、学习以及内容输出能力。

成为知识型 IP 后，商业化变现方面可以入驻知识平台当讲师、开设专栏、上架课程、出版书籍、举办训练营以及一对一咨询等。

# 二、资料管理背后的逻辑 @洛羽

## 2.1 资料管理为什么总做不好

第一章和大家介绍了什么是资料管理，我们为什么要做资料管理。相信大家看完之后，也都知道了做资料管理的必要性。

接下来，我们思考一个重要问题：为什么很多人做不好资料管理？

根据我的个人经验，最核心的原因就是：不知道如何对资料进行分类；再核心一点，就是不懂这些资料。

人类从诞生到现在，一边实践一边沉淀了海量的经验和资料。从口口相传到用龟甲石头刻字，从牛皮纸张竹简再到现在的信息时代，我们记录、传输和沉淀信息的能力越来越强。现如今，几乎完全不用担心信息和经验留不下来。

很多时候，我们会说当下的世界充满了信息和知识焦虑，但其实这种现象，从古至今一直都存在。

面对浩如烟海的文字和材料，如果不是每个时代都有那么一批人，不断对这些内容进行分类、编撰和归档，这些古老的经验也不会流传到现在，变成全人类共同的财富。
