1. 上架时先看这些

问：小红书店铺版权怎么看？
答：开店最好别传有版权的资料；有版权方找过来容易被举报，店铺是实名过的。判断版权：最好不要有水印；看同行有没有在卖，卖的人有3个以上说明能卖。再送一个【免责说明】详情页图片，跑路用。

问：店铺听说都打价格战？
答：淘宝、闲鱼、拼多多等货架电商比价严重，但小红书本质是兴趣电商，用户习惯不爱比价。100个访客卖不出去可能是价格太高；但只有几个访客，就别先怪价格。记住，小红书用户对价格很不敏感，不要怕比同行高，往高了卖；价格高订单数可能减少，但最终收益未必减少。

问：虚拟资料订单发货时仍需要寄件，怎么解决？
答：选无物流发货，发货处有选项。

问：店铺和私域能同时在一个账号进行吗？
答：店铺号是实名过的，店铺也在这个号里。不建议一个账号打两种打法；私域是违规行为，号被封了店铺也会关。店铺用来做低客单售卖，前期赚钱可以过渡；私域可以另弄号。

1. 什么账号值得对标
在任何平台创作中，模仿对标账号都很有效。对标账号就是同行业或同类型的其他用户账号；创作时可从它们的图文/视频内容、话题选取等方面模仿。

选择标准：
⭕ 低粉：一万粉以内，高的不看。
⭕ 高赞：赞数大于粉丝数，内容有价值、有质量。
⭕ 最近一个月：周末看的人多，只选一周没有参考意义。
⭕ 主页多次出现：刷主页时这个封面多次出现，说明账号值得对标，抄就完了。

爆款笔记四个密码：爆款选题心法+爆款封面做法+爆款标题起法+爆款内容写法。
⭕ 小爆款：赞藏+评论总数≥200
⭕ 中等爆款：赞藏+评论总数≥1000+
⭕ 大爆款：赞藏+评论总数≥1w+

# 2. 封面&内页
# 2.1 排版基本原则
# 2.1.1 三个要点
✅ 针对零基础作图功底的小伙伴，给出几个要点。封面排版牢记三要点：
要点一：封面尺寸。竖屏选3:4，方形选1:1，横屏选4:3。竖版笔记屏幕占比更大，能停留在用户视野里更久，不仅传达更多信息，被划走几率也相对更小。
要点二：精准选图。视觉冲击力强的高颜值配图（可用AI生成）；视觉效果简单明了的手写类型（可简单手写）；适合合集、美食、旅游攻略等。
要点三：简要文字。小红书笔记标题只限20个字符（emoji表情占1～3个字符）。想补充更多信息，要好好利用封面。用户发现页浏览时是茫然的；字体在核心部分要占据足够画面，概念清晰，直击用户需求，告诉用户“这是一篇对你有价值的笔记”，让用户产生点击冲动。

# 2.1.2 二少原则
二少原则：少变/少用。
原则一：少变。不要经常更换封面版式。尽量做到【模板化/可替换化】，排版、字体、风格一致（颜色可同色系变换），保证主页整齐性，也有利于粉丝辨识你。
原则二：少用。少用不相干的贴纸，避免喧宾夺主、分散用户注意力。

# 2.2.1 截图
截图是作品最简单的呈现方式。怎么解决截图同质化？很简单：
1. 自己截图发。
2. 给作品加边框等，调节图片参数。
3. 把文件内容复制到AI软件，让AI重新写一个相似的，再截图，完完全全是个新文件。
4. 打印出来，拍打印的作品。
以上方案都建议采纳；如果这个素材在你账号爆了，就想办法换个方式再表达一次，让它达到二次爆的效果。切记！！！
