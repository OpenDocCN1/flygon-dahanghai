# 2.5 安装 Postman（API 测试工具）

Postman 是什么？

Postman 是专门用来测试网络接口（API）的工具。后端开发时，可以用它模拟前端请求，验证接口是否正常工作，是前后端联调的必备工具。

使用场景：

接口调试：开发 API 时，先用 Postman 测试请求能否返回正确数据。

前后端联调：前端页面还没写好时，可以用 Postman 先模拟请求，检查后端接口数据是否正确。

自动化测试：编写测试脚本，自动验证接口稳定性。

接口文档管理：生成 API 文档，方便团队共享。

安装步骤：

1. 访问 Postman 官网下载页面。

1. 下载对应你操作系统的版本并安装。

# 4. 自动化部署与分享

# 4.1 使用 GitHub Pages 部署网站

现在把游戏网站发布到互联网上。

步骤一：进入 GitHub 上的项目仓库，点击“Settings”。

步骤二：在左侧菜单选择“Pages”。

步骤三：在“Build and deployment”部分：

Source 选择“Deploy from a branch”。

Branch 选择你的主分支（通常是 main 或 master）。

步骤四：点击“Save”。

步骤五：触发部署。回到代码编辑器，随便修改一点内容（比如添加一个 README.md 文件），然后再次提交并推送到 GitHub。这次推送会自动触发 GitHub Actions 开始部署网站。

1. 需求分析

很多做自媒体或社媒营销的朋友，经常需要从抖音、小红书等平台找素材进行二次创作。但平台下载的视频和图片通常带有水印，后期处理很麻烦。市面上虽然有一些去水印小程序和网站，但为什么不自己开发一个呢？

核心需求点：

1. 需要一个简洁的交互界面，可以粘贴分享链接。

1. 工具能自动解析链接，并支持多个主流平台。

1. 解析后能展示视频或图片封面，并提供无水印下载功能。
