# 6.3.1 广告变现：公众号的主要收入来源

所谓广告变现，就是在推文里嵌入广告位，比如小程序、游戏、电商等卡片；用户点开卡片，或者点击后完成消费，创作者都能拿到一笔分成。还有一种情况：整篇推文本身就是广告。

目前常见的玩法有四种。

1）方式一：自己接广告任务

先关注公众号“新榜有赚”。这个平台上的赚钱方式不少，有分销类，也有文案类。文案类通常按阅读量结算，单次阅读大约四毛钱；展示时间要求不一样，有的满24小时就能删，有的可以长期挂着。平台里有教程，想做的可以自己研究。

2）方式二：商家主动找上门

商家会在后台留言“商务合作”，然后加微信谈价格。一般需要我们这边先报价，文案由对方提供，我们复制粘贴发布即可。费用按位置分头条、二条和三条，头条价格最高，通常2000以上一篇。

这种广告要谨慎接。先看对方给的文案涉及什么内容，涉黄、涉赌、封建迷信类的不要接，否则可能造成封号。

3）方式三：在推文里带货 @徐胖子

公众号带货十年前非常火，但这几年视频带货兴起，文字带货的效率越来越低。不过也要看到，公众号带货依然有前景。

为什么说公众号带货还能做？主要有四点优势。

第一，公众号流量大。圈友@渭水徐公 的公众号训练营已经开到第七期，十万加爆款累计1000篇以上，阅读量过万的小爆款更不用说。一个账号每天发布8篇文章，每篇文章最多可以植入10款产品，8篇下来就能植入80款产品。只要推文里有一款产品爆了，收益都会很可观。

第二，公众号创作灵活，图文和货物的相关性要求低。比如你写情感领域，学习类、励志类、文学类、情感类书籍都可以带；吃的用的，也能通过公众号来带货。

第三，公众号佣金高。带的商品可以自己找商家谈佣金，书籍佣金最高能到50%，水果和蜂蜜的佣金也不低于20%。

第四，结算安全。官方结算链路，流量主收入有保障，佣金结算效率高。用户下单、确认收货后结算带货佣金，创作者在后台查看佣金，官方打款，这些都能在后台看到。

具体操作流程如下：先申请公众号并进驻平台；粉丝数满足500以上，确认财务结算资料，申请开通流量主。流量主审核一般3—5个工作日完成，正常提交资料当天就会通过。开通流量主后，再开通返佣商品广告，进入推广商品，在文章内植入返佣商品广告并发布，分享文章就能赚取收益。

公众号带货功能和头条带货一样，文章里有商品关键词，就在文章里插入相关商品即可。

[PRE9]

单篇推文最多支持插入10款商品。读者阅读时点击商品卡片，可直达小程序一键下单；带来实际成交后，流量主就能获得销售分成。

另外，不管什么时候带货，带书、带日用品还是带水果，都可以套用这个模板：第一部分用故事切入，第二部分从故事转到话题，第三部分介绍商品内容，第四部分引导下单。具体带货文案怎么写，可以查看高手分享3月6日《如何在公众号带货》@徐胖子。

4）方式四：文末贴片广告带货

识别二维码，注册成为有赞的分销商，然后挑选自己想卖的产品，做成超链接，再把超链接贴到文末即可。
