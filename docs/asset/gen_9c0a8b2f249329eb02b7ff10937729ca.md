# 宠物服装在小红书，为什么是门高利润好生意？

今天聊一个小众但很有潜力的电商赛道——小红书上的宠物服装。

这个领域目前竞争还不算激烈，算得上是一片蓝海。宠物衣服本身的成本其实很低，但定价空间非常大，既可以走亲民路线，也能做中高端，利润相当可观。

更重要的是，把小红书上的客流引入私域之后，还能继续卖其他相关产品。宠物主的回购频率和忠诚度普遍很高，复购根本不用愁。
