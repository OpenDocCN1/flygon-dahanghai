# 2.1.2 第二步：找准你的“目标鱼群”

一口鱼塘里，不会只有一种鱼；一个平台上，也从来不会只有一类用户。年轻人、中年人、学生党、上班族……不同圈层的人，刷到的内容不同，感兴趣的东西也天差地别。

所以，公式里的“XXX人群”，本质上就是在回答一个问题：你到底想钓哪批人？

你可以从这些维度来描摹你的目标用户：

- 年龄：小学生、大学生、25-35岁职场人、35-45岁家庭主力……
- 职业：学生、办公族、一线工人、全职妈妈、小店主……
- 收入：基础消费、中等收入、高净值人群……
- 地域：本地、省内、全国……
- 性别：男性、女性
