# 6.1 玩法一：朋友圈这么发，信任感很快拉满（@劲猫 @杉木）

经营朋友圈，是私域卖货中很关键的一环。用户从小红书添加你的微信后，十有八九会先翻翻朋友圈。你发的内容是什么画风，直接决定他对你的信任值。

每天的量保持在五条左右比较合适：一条小红书干货、两条生活日常、两条案例反馈。这样的配比，既能让人看到你的专业服务，也能让人了解你的个人状态。从小红书跳转过来的新好友，刷到这种搭配，心里那层戒备往往就会卸下不少。

绝对别学微商那种刷屏式卖货法。朋友圈需要有人情味，多分享点个人生活，账号才会显得真实可信。同时要有用户视角，清楚你的粉丝喜欢什么、关心什么。比如，如果你的客户主要是年轻人，多用点有意思的表情包、玩一玩网络热梗，就能很快拉近距离。
