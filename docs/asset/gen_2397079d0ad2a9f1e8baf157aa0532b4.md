# 1.1 网站类型速览 @ChatGPT

这一节由 ChatGPT 协助整理。平时上网会接触到各式各样的站点，按用途来划分，大致能归为下面几类：

- 工具型站点：把某项功能或服务搬到线上，例如搜索服务、云端存储、翻译应用等。
- 内容型站点：以文字、图片、音频或视频输出信息，常见形态包括资讯门户、个人博客、社交平台等。
- 电商型站点：围绕商品或商业服务展开，品牌独立官网、在线交易市场都属于这一类。
- 社区型站点：核心是让用户彼此连接、交流并分享内容，讨论区、社交关系网络、博客托管平台是典型代表。
- 教育型站点：汇集学习资源、网络课程与教学工具，网课平台、教育主题博客、学校官网都在其中。
- 娱乐型站点：主打休闲消遣，提供影视点播、游戏站点、音乐服务等内容。
- 新闻型站点：发布新鲜资讯、事件动态与观点评论，资讯门户、自媒体博客、新闻媒体站点均可归入。

这些类型在日常生活中并不陌生。不过，本次实战会把重心放在工具型站点上。原因很直接：它能覆盖从挖掘用户需求、明确产品定位，到最终实现变现的完整链条。
