# 3.5.1 抓人标题的常见写法

在📕发笔记，标题上限是20字。实操时，优先把大词和小词搭配使用；另一个办法是先把同领域热门前十的标题收集起来，拆出其中关键词，再拼成一条新标题。

这个环节不能省。平台流量入口以搜索为主，笔记想被搜到，正文和标题都得和用户输入词建立联系，其中标题在搜索排序中的分量尤其明显。

还可以把“如何、分享、推荐、搭配、必备、新手、知识、技巧、教程、步骤、怎么做”这些词随意穿插组合。

数字也能增强吸引力：标题里多放具体数量，比如“2种方法”“10大”“4项要点”。像“到新疆旅行，3个地方值得打卡”就是数字型写法。整体思路与👸号、知乎的起题方法相近。

拿旅游攻略笔记来举例，可以这样拟题：

• 新疆不可错过的景点
• 新疆12日游，人均5K怎么玩
• 新疆之行发完圈，好友把我拉黑了
• 结束新疆行，整理出33条避坑提醒
• 去新疆玩，这20件事别做
• 2022新疆花季指南
• 毕业游或情侣游：新疆8天9晚玩过瘾
• 新疆旅行疑问，在线帮你答
• 新疆这一程，多亏男友通宵整理攻略（真实记录）
• 去新疆前，这10件事先了解

旅游攻略笔记可以照这个路子起标题；换到别的领域，只需替换关键词，方法照样能用。
