# 选对短剧，推广就成功了一半

大家在熟悉平台的过程中，应该已经刷到过各式各样的短剧。真正关键的问题是：哪些短剧更适合拿来推广？这也是本章要重点聊清楚的事。

对刚入门的人来说，完全靠自己去筛出容易爆的短剧并不轻松。短剧 CPS 本身就带有很强的概率属性，哪怕是经验丰富的老手，也常常会遇到翻车。掌握一些选剧技巧，往往能让推广少走弯路、效率更高。

麻雀 Matrix 和创作猫显然也注意到了这一点，因此这两个平台都会整理出一批爆款案例，供大家在选剧时参考，让方向更明确。

综合来看，本章会从以下几个方向分享选剧思路：

- 通用思路：借助视频表现，倒推哪些短剧更可能成为爆款
- 平台参考一：看麻雀 Matrix 的爆款案例
- 平台参考二：看创作猫的爆款案例
- 进阶策略：把目光放到新剧上，敢于尝试

⭐️ 航海期间，教练们还会在群里同步近期表现亮眼的短剧以及可对标的视频，大家记得跟进学习。

当你找到觉得值得推广的短剧后，别忘了把素材拿到手。

这里要特别提醒：原片一定不能直接发布，必须先做剪辑。具体怎么剪，我们会在「六、剪辑视频」里详细讲。如果把原片直接传到各个短视频平台，不仅可能被判定违规，严重时还会面临封号风险，短剧推广平台也会扣下收益。

百闻不如一见，百见不如一练。找到适合自己的小技巧，动手去筛一筛，尝试找到更好推广、更易出爆款的短剧吧。
