# 起薪三千，后来千万：五个岔路口

我是牟长青，2012年起进入新媒介创业，也办培训、峰会和社群，接触过不少同行。今天不空谈，只讲身边真实发生的事。十六年网络行业经历里，我亲眼见过一批年轻人从两三千月薪起步，后来做到千万级体量。

十一年前，28推最早那批人多数刚工作或还在读书，八成月薪2到3千。不到十年，约一半累计过千万，8人过亿。他们做对了什么？我归纳为五次关键动作。前三次不少人能完成，真正拉开差距的是第四、第五次，建议看完。

## 一、先站上有上升空间的赛道

老话说嫁错郎、入错行，意思方向比蛮干重要。十一年前扎进网络行业的人，第一步就占优。这个行业机会密集，年轻人突围概率更高。福布斯榜上近年跃升的老板，不少来自网络企业；滴滴程维创业数年就上市，一度登顶首富，后来主动降低持股比例。

2007年我在北京拿过三千月薪，身边也有一批同样收入的网络从业者。十年后回看，仍打工的年薪普遍不低于20万，创业成功者更高。杜均就是那时认识的，19岁，在康盛创想做基层。此前他在北京网吧干过活，也在餐馆端过盘子。后来他靠域名投资身家过亿，又参与创办火币网、金色财经。区块链圈传他赚了几十亿，我没向他本人核实，但几个亿应无悬念。

老家同学当年也是两三千待遇，但不在网络行业。十年后多数年薪约10万；我那些网络圈朋友平均在30万以上。差别就在赛道。网络行业重积累，能熬十年的人，年薪低于30万的不多，因为机会一波接一波，抓住一次就可能翻身。选对行当，千万目标先完成五分之一。

## 二、入行后有没有持续充电

我2006年开始写独立博客，2009年前后最热，单篇阅读2万以上，至少一万名固定读者，在我看来都是愿意学的人。有人偶然刷到，有人定期来看更新。当时不少粉丝说，进网络推广岗第一天，老板就让他们来我博客补课；甚至“看没看过我博客”成了招聘参考。

很多人留言或线下见面说，看了博客受启发，工作事业有帮衬。新媒介早期，我和一些后来成名的大佬互加微信，对方常说以前常读我博客，比如猫老大、十点读书林少。28推和微盟谈线下活动赞助时，微盟创始人孙涛勇在群里直接说，我文章给他做个人站长不少启发，愿意连赞两场。

## 三、碰到实战学习机会，敢不敢报名

2010年，网络推广和SEO培训很流行，夫唯的SEOWHY等课程都有。我当时在北京，写了四年推广博客，圈里小有名气。闲来随手发帖，说招10个徒弟做网络推广实战训练，结果收到400封简历。

那阵子单篇阅读2万多，招徒帖至少1万人看到。400封邮件看似多，回头想，一万名固定读者里，为什么只有400人敢写邮件？

[PRE2]

可能是门槛吓退不少人，比如要求27岁以下，就挡掉一批。我的想法很简单：不想要比我年长的徒弟，管理麻烦；也担心年纪大体力跟不上，不能按我的要求狠干。但也有人没被硬条件吓住。28推最早班底里的大师兄、后来禾葡兰董事长黄志雄，当时42岁，仍鼓起勇气投邮件，我最终破格收下。也是这段缘分，后来他带部分师兄弟做出禾葡兰和有点牛两家圈内知名公司。

[PRE3]

那时黄志雄在深圳开印刷厂，收入不差，是28推初始班底里少数早期就创业的人。但他做网络项目一直没成，前后亏了几百万，直到加入28推才走上坡路，在网络行业赚到钱。2017年做28推公司初期，他帮了我很多。我现在仍是禾葡兰高级荣誉顾问，合同签了100年，每年有分红。

## 四、实战中能不能扎实落地、不被淘汰

我原本只招10个徒弟，报名太多、符合条件者也多，后来想扩到30个。可选到第28人时，我觉得剩下都差不多，不想凑数，于是“28推”这个名字就来了。

中间还有插曲：有两人我本来没打算录取，但他们主动在腾讯微博询问结果，希望给机会。我看对方两次来问，觉得是真想学，就收了。这两人是班魁、何秋辉，至今仍在初始班底。外面风言风语不少。即便没收一分钱，网上仍有人骂，说我年纪轻轻没资格带徒弟，说招徒就是割韭菜、找免费劳动力。我不想多解释，时间会说话。

对这批人我挺认真，每周一个实战任务，每个任务打分点评。前两个任务是微博和数据分析，后来公益培训也沿用。28人从400名竞争者中胜出，但不是每个人都兑现报名时的承诺。训练一个月，我淘汰6人。不是能力差，主要是没认真对待任务。

[PRE4]

第五个任务排名时，前面已淘汰6人；剩下22人里又淘汰7人。因为少了6人，才有了28推论坛早期的补招。现在初始班底里的黎一中、易小歪、胡选燕、罗登、朱文健，都是补招进来的。最早报名没成功的人，后来也抓住28推公益培训机会，拿到新媒介入场券，比如彭勇俊、王强、储海洋。

从2010年底招徒，到2012年底做微信公众平台的两年里，最初28个徒弟我最终淘汰13人。离开28推圈子后，这13人基本没抓住新媒介机会，基本没人做到千万收入。而留下来的人里，一半收入过千万。所以第四步最要命，它决定你能不能长期待在一个好圈子里：一步向上，一步平庸。

## 五、行业风口来了，敢不敢试

2012年8月，微信公众平台上线。第三天我发现价值，注册了第一个号“吃喝玩乐在重庆”。这个号现在还在，是重庆区域自媒体头部账号之一，粉丝100多万，目前由兄弟公司重庆有点牛运营。

当时我觉得机会很大，就号召28推成员和学员一起做。我还在28推QQ群发公告，说可以帮他们解决初始粉丝，找人带号。但不是所有人都响应。胡选燕、吴迪、郝明霞、易小歪、黎一中等成员第一批加入，后来做到八位数粉丝，赚到早期资本。谢匡华、彭勇俊、莎莉、王彬彬、储海洋等优秀学员也第一时间进入，后来表现好，加入28推初始班底。

风口来时，敢试才抓得住。有的成员一直观望，迟迟不入局，多年后跟我说后悔当年没响应。大师兄黄志雄则带陈朝波、沈海波、百度姐、罗登、李泽等人在深圳成立欣所罗门，专做微博营销，攒下5000万腾讯微博粉丝、1000多万QQ空间粉丝，也赚到早期资本。只是进公众号领域稍晚，后来转私域电商，做了禾葡兰。

## 六、轮回会重演吗？

上面这些案例说明，这群人从三千月薪到千万量级，主要做对五件事：

1. 选一个有前景、有上升空间的行业；
2. 入行后不只会埋头干，还主动上网补行业知识；
3. 看到靠谱训练，有胆量报名；
4. 报名后能把任务做到位，而不是像现在不少人，买了课不听就以为学会了，或者光听不练；
5. 通过实战有基础后，遇到好项目敢试。

今天的生财有术，和我当年的28推论坛很像，也是一群人交流分享，还能参加实战训练。只是生财有术门槛更高，先交2000多成为会员才有资格，来的人群质量也更高。能进社区学习的人，其实已经走了前两步。但第四步才是分水岭。比如生财之前的大航海活动，好像1000多人报名，看着不少，但生财有3万会员，为什么那么多人连报名勇气都没有？大部分人第三步都没跨进去。

报名之后到第四步，因为没什么成本就进来，你能否扎扎实实落地？我当初招28个徒弟也没收钱，但最终13人没珍惜，被淘汰。被淘汰的真不是能力不行，就是单纯没落地劲头或没长期坚持。个别被淘汰的，初期任务其实做得不错。

第五步可遇不可求。但没有前四步积累，第五步来了也抓不住。老话说，机遇留给有准备的人。

最后放一张28推初始班底在桂林的周年聚会合影。我们一起走过第一个十年，现在携手第二个十年。为什么11年了感情还这么好？因为一起同甘共苦过，现在生活好了，也能共富贵。做得好的师兄弟，也不忘拉一把暂时落后的。

很多人有成功潜力，只是缺靠谱圈子和被点醒的机会。选赛道、持续学、敢报名、强落地、抓风口，这五步走稳，下一个十年更值得期待。
