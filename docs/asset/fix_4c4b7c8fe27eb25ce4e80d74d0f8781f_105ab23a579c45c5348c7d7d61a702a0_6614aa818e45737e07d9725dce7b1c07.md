# 一、数字人 IP 是什么？

先拆解“数字人”。在本次课程中，数字人是由 AI 技术驱动的虚拟形象：一种是把真人形象复刻成数字分身，另一种是完全原创的虚拟角色。AI 是它的核心——用声音克隆或语音合成生成声音，靠算法带动表情和嘴型，让它能像真人一样表达和播报。效果演示见视频：数字人IP呈现效果-1.MP4【在线播放】、数字人IP呈现效果-2.MP4【在线播放】。

再看“IP”。这个词来自 Intellectual Property，在内容创作和品牌语境里，可以理解为一个容易被识别的“人格符号”或“品牌资产”。自媒体账号、公众人物、消费品，一旦形成独特风格、明确站位和用户记忆，就拥有了 IP，它既代表影响力和认可度，也藏着商业空间。

要做好数字人 IP，有四类问题需要正视：

1. 细节真实感还不够。数字人远看接近真人，但细看眼神、表情、动作仍有破绽，容易让观众出戏。尤其口型与声音不同步，语速快、情绪强时更明显。课程会教大家怎么录制口播素材、怎么控制节奏，让 AI 生成的嘴型与音轨更匹配，降低违和感。

2. 成本与方法门槛。免费 AI 工具看似省事，实际画质、动作、音色都不够好，常常要回头付费买效率。航海会对比国内外多个平台，帮你选出效果和价格平衡的产品，避开常见坑。

3. 特殊场景表现力有限。AI 目前还不太能处理复杂感情、临场互动和细致的肢体表达，某些口播内容会受限。所以本次航海专门安排了自然口播与拍摄训练，让克隆出的数字人更有真实感。

4. 保持人设稳定和“人味”。AI 生成的内容容易同质化、缺少情绪。要靠人的策略和精心设计的提示词来兜底，航海也加入了智能体训练，让 AI 写出的文案和语气更贴近你自己的语感。

# 2.2 锁定目标受众和平台选择

前面已经理清了特长、方向和价值，接下来要回答：这些价值是为谁准备的？受众定义得越清楚，平台、内容策略和表达风格就越容易定。

继续追问自己：

- 谁最需要你提供的价值？试着画出他们的画像：年龄、职业、兴趣、知识背景。
- 他们活跃在哪些平台？抖音、视频号、B 站、📕，还是其他垂直社区？
- 他们的内容偏好是什么？喜欢节奏快的短视频，还是深度讲解？喜欢专业严肃，还是轻松有趣？

了解受众，是为了用他们舒服、听得进的方式去沟通。

回到前面的例子：
- 例 1 的受众：不懂技术但关注 AI 的职场人士和创业者。
- 例 2 的受众：压力较大的年轻白领和学生。
- 例 3 的受众：垂直领域的初学者和想进阶的从业者。

💡 如果前面已经和 AI 聊过，可以直接问它：我的目标客户是怎样的？主要活跃在哪个平台？时间允许，可以多平台分发，但要分清主次，不然每个平台都做不透。

AI 给出的平台策略可以概括为：主战场放在📕，抖音和视频号作为重点增量，B 站当作补充，海外市场再做 YouTube 和 TikTok。

📕：人群以女性为主，购买力强，看重生活品质、个人成长和学习提升。社区信任度高，适合知识付费与好物分享，转化路径最短；你踏实又有朝气的口碑也会在社区里慢慢被更多人认可。

抖音：用户规模大、算法分发强，内容需要短平快，前 3 秒就要抓住人。可以围绕逆袭、搞钱、反内卷等标签做传播，也想适合把“反 PUA”的职场建议放进去，但用户信任建立需要更多时间，通常靠私域或直播承接变现。

视频号：依托🛰️社交关系链，适合私域联动。如果你的社群或航海需要在🛰️完成转化，视频号是很好的承接平台，内容可以偏向情感共鸣、实用技能、人生经验，像家庭关系这类话题也容易引发熟人转发。

B 站：年轻用户集中，社区文化浓，弹幕互动强，适合深度内容和知识区。做详细复盘、系统讲解可以获得强粘性粉丝，但视频制作周期也相对更长。

YouTube/TikTok：面向海外用户，内容主要覆盖海外华人或更广泛的国际观众。YouTube 更适合中长视频和搜索流量，TikTok 更适合短平快和潮流内容；除非想做出海，否则优先级可以往后放。
