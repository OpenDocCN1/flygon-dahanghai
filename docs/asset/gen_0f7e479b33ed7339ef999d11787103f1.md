# 快团团拉新：8招把客户引进来

快团团能不能真正“团”起来，关键不在货架，而在人。这一节只聊一件事：怎样让更多人愿意成为你的客户。

结合多位老师的实战经验，我们梳理出8条路径：

1. 借私域做裂变，把朋友圈经营起来；
2. 用一个有记忆点的特色品，打开冷启动；
3. 先锁定种子用户，再通过活动带动裂变；
4. 在社群里安排氛围角色，让初始群不冷场；
5. 深耕本地资源、混群学习，同时把口碑做扎实；
6. 从公域平台导流，并持续运营朋友圈；
7. 通过线下广告把人引过来；
8. 在📕做引流。

其中，在当下的公域引流方式里，📕是相对适配的一种。不少做快团团的同行已经在📕拿到结果，值得认真试一试。

这8种方式，很多人在各类群聊里都见过，甚至已经参与过。今天我们就把它们拆开，看看真实玩法。

它们并不是彼此孤立的。实际操作中往往交叉使用，也有共同动作：让社群保持活跃，塑造可信、有人情味的形象，适时用活动做裂变，以及维护好朋友圈门面。

继续往下看，你会找到适合自己的一套打法。选定之后，别只停留在收藏，尽快启动你的社群冷启动。
