# 5.8.2 ControlNet1.1 插件快速实操指南

在 Stable Diffusion 的生态里，ControlNet 插件一直是精准控制画面的利器，而 1.1 版本则让这一过程变得更加顺手。很多刚接触 SD 的朋友，面对新版本插件时往往不知道从哪里下手。下面我们就用最直白的方式，把 ControlNet1.1 的入门用法拆开讲清楚。

先说说准备工作。安装插件其实很简单：在 WebUI 的“扩展”页面里，从“可下载”列表中找到 ControlNet 并点击安装，或者直接把 GitHub 上的项目文件放进 extensions 目录。装好后记得重启界面，然后在“设置”里勾选允许脚本读取 ControlNet 配置，这样后续操作才不会卡壳。

真正上手时，你会看到一张“控制网络”面板。别被一堆参数吓到，基础使用只需要关注三个核心区域：上传参考图、选择预处理器、选择模型。参考图决定了你想要的构图、姿态或轮廓；预处理器负责把这张图里的关键信息提取出来；模型则负责按照这些信息去生成新画面。三者联动，才能达到“按照参考图来画”的效果。

实际生成时，建议先把“启用”开关打开。若是只想用参考图的一部分逻辑，还可以勾选“像素完美”来让细节更协调。重量这个参数很关键：数值越高，生成结果越贴近参考图；数值太低，则容易跑偏。初学者一般从 0.6 到 1.0 这个区间试起，效果不理想再上下微调。控制模式可选“均衡”“更偏向提示词”或“更偏向 ControlNet”，具体选哪个，取决于你希望主导画面的到底是文字描述还是参考结构。

至于预处理器和模型，新手可以从 Canny、Depth、OpenPose 这三类最常用的开始尝试。Canny 适合边缘清晰的线稿场景，Depth 更适合需要空间层次感的画面，OpenPose 则专门用来锁定人物姿势。每一种都有对应的模型文件，使用时必须保证预处理器与模型匹配，否则很容易出现无效果或报错的情况。

最后提一个容易忽略的小细节：如果画面完全不受控制，先检查是不是模型文件没下载完整，或者预处理器没有选对。既然版本升级到了 1.1，很多早期教程里的路径和模型名就不再适用，所以尽量以插件自带的说明文档为准。

总的来说，ControlNet1.1 的基础使用并不复杂，记住“传图—选预处理—选模型—调权重”这个流程，大部分常见需求都能轻松搞定。多尝试几次，你就能掌握这套插件的脾气了。
