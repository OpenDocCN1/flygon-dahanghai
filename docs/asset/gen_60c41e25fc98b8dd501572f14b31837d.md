# 3.4.3 传单还值得发吗？@芷蓝

经常有开线下门店的朋友问我：现在发传单还有没有用？我的答案一直很明确——有用，但关键看两件事：你能坚持多久，以及由谁来发。

先说一个我特别确信的道理：把钱花在自己的品牌资产上，永远不亏。

具体怎么做？就是在门店附近，选好固定的时间和地点，每天雷打不动地出现，逢人就递上传单，同时把你的品牌名字说出口。一次两次可能没什么感觉，但当你反复出现在同一条街、同一批人面前，你其实是在悄悄搭建品牌和潜在顾客之间的桥梁，慢慢影响他们的心智。

线下地推有一个线上投放比不了的优势：对话刚开始的那1到5秒，用户的注意力完全在你身上。这是信息流广告很难做到的。

发传单，不一定非要让人当场进店。更重要的是，当他某天正好有需求时，能突然想起来：哦，我上班或住的地方附近，好像就有一家这样的店。

所以，只要你发得够久，只要发的人是你自己或你信任的店员，只要在发的同时不停告诉对方你们店叫什么、在哪里——这件事就一定有效。

关于传单怎么做、去哪发，我整理了几条经验：

① 传单不是产品说明书，千万别做三折页。一张纸就够了，连打开三折页这个动作都是在给顾客添麻烦，能省则省。

② 字体一定要大。别觉得字大显low，顾客拿到传单可能只瞄一眼就丢掉，那一眼能看到多少信息，完全取决于字有多大。字号越大，招牌信息越容易进脑子。

③ 一张传单上只需要三个核心信息：促销价格、品牌名、门店地址。其他内容都是多余的。我们的目标是让人到店，不是让人在纸上研究你的产品。

④ 做传单直接上淘宝找商家就行，最好先找一个你喜欢的现成模板，把参考图发给设计师，简单改改就能印。

⑤ 发传单的地点可以选三类：以门店为中心周围500米范围；所在城市的商业中心；目标人群扎堆的地方，比如学校门口。

⑥ 发的时候，最有效的说法是“促销信息＋地址”。比如我自己发传单就会直接说：“19.9元体验中国舞，就在金街大厦11层，今晚来试试？”记得给路人一个明确的行动指令，比如“今晚8点半过来体验”，比单纯让他拿传单更容易促成行动。
