# 6.3 借社媒与网站找选题

想给内容创作找灵感，别只盯着一个渠道。把资讯聚合站点和社交平台放在一起用，是另一条发掘选题的有效路径。这类平台往往汇集了大量用户产出的内容和讨论，浏览并分析其中的信息与话题，就能筛出不少可写的题目。具体可以这样做：

第一，去 Reddit、Quora、知乎这类问答社区，搜与你的方向有关的问题和答案。参与者多、讨论密，能让你看到更丰富的内容和不同角度的理解。

第二，在 Twitter、Facebook、Instagram 等社交平台上追踪相关话题与趋势。那里聚集着海量用户生成内容，文章、图片、视频都可能是选题线索。

第三，借助谷歌新闻、Feedly 等聚合网站，获取相关领域的最新报道和文章。它们会把不同来源的新闻与文章汇到一起，呈现更多样的内容和观点。

把这几种方式配合起来用，选题的生成和延展会更顺，自媒体写作水平也能随之提升。

上述内容整理自 ChatGPT。

还要注意：免费版 ChatGPT 不能联网，无法自己读取网站上的最新信息；你需要把相关材料以文字形式交给它，供它学习。ChatGPT Plus 版已经支持联网，若你使用 Plus 版，可选择 ChatGPT 4.0 - 联网功能，让它联网检索并提炼你所需的信息。
