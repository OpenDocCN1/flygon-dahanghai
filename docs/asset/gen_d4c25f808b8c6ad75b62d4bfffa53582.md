# 一、【项目概述】认识视频号直播

# 💡 本章要点

这一章先一起认识视频号直播项目：平台目前是什么情况、有哪些特点、市场空间如何、项目怎么玩。本次航海的重点，是带大家从0到1跑通视频号直播，所以先把整体项目概况摸清楚，很有必要。

# 1.1 当前项目情况@李诚

# 1.1.1 平台基本面

视频号依托微信超12亿日活流量池，消费市场基础很强。2024年，视频号电商GMV同比实现翻番；达人带货单季度增长140%，订单量增长超过两倍。

视频号还与公众号、社群、小程序深度打通，支持“微信小店带货者”做全域运营，商家可以通过社交裂变激活私域流量。这些动作说明视频号带货的商业化前景较好，官方也在持续出台政策支持带货者。

从电商特征看，视频号客单价较高、复购与用户黏性强、转化效率好、退货率低，上手难度也不高。细分领域里优质内容和成熟账号仍然偏少，适合新手实操入局。目前平台直播流量较好，支持多账号矩阵操作。3月航海学员实操视频号后，也反馈拿到了不错的结果。

# 1.1.2 盈利空间

视频号直播的电商总量逐年增加，越来越多微信用户开始尝试并习惯在视频号购物。相比抖音、快手、拼多多等平台，视频号电商产品价格略高，毛利空间更大，所以带货佣金也相对更高。

视频号直播里不少产品属于兴趣电商，很多中老年用户对新品兴趣高，愿意下单尝试，靠自然流也能获得较大流量。直播带货的转化路径比短视频带货更直接，下单率更高，佣金收入也更可观。

# 1.2 核心玩法拆解

# 1.2.1 最小可行路径与关键动作

目前视频号直播的主流玩法是：先发带货视频，等视频起量后，立刻开播承接流量、放大成交。因此，视频号直播从0到1的最小闭环可以概括为：选赛道—搭账号—选品—对标爆款做视频并发布—直播带货—复盘优化—成交。

几个关键点要强调：

账号开通方面：新手建议至少开2个账号，有条件可以开3到5个，找亲友帮忙也行。因为素材剪辑、内容把控、平台管控等多方面原因，账号容易出现限流，一限可能就是一周左右。

视频制作、发布与直播方面：对标爆款做出高质量视频，是本项目的关键动作。建议新手每个号每天发3到5条视频。平台审核越来越严，每条视频在混剪基础上最好加入一些实拍素材，实拍占比约1/4到1/3，更容易通过原创审核。这次也会教大家用AI数字人做视频提效，不想出镜也能操作。

另外，二次混剪时注意别大范围露出原作者真人的脸，否则容易被原作者投诉下架，甚至封号；尤其是明星、网红等素材，出镜过多过大，系统会核查并提示需要出示核验或授权。直播前可以对标同行直播间，学习话术，开播测试话术和直播脚本。

测品方面：带货账号每个要交100元保证金才能选品，这笔钱后期可以退。每个账号每天能发布的带货视频数量，会根据粉丝数调整：粉丝不足1000，每自然日最多发1条商品分享视频；粉丝在1000到9999之间，每天最多2条；粉丝在1万到99999之间，每天最多5条；粉丝超过10万，每天最多10条。如果账号不足1000粉，其他视频挂不了商品，也可以在评论区引导用户去橱窗购买。

# 1.2.2 内容分发机制

1. 社交推荐：这是视频号生态的特色。系统会根据用户好友及好友圈子的发布、点赞、关注、评论、转发等行为，优先推荐相关视频。
2. 个性化定位推荐：基于微信社交生态，每个用户都会被贴上性别、年龄、职业、兴趣、城市等多元标签，系统再从海量内容里匹配用户可能喜欢的内容。
3. 搜索推荐：微信搜一搜的关键词搜索会影响推荐，点赞评论表现不错的视频更容易被优先推荐，用户搜索过的内容也会更多出现在其推荐列表中。
4. 同城推荐：视频号会根据视频发布的地理位置，推送给同城用户。线下商家尤其适合用这一点提供商业服务。

# 2.1 工具清单

# 2.1.1 手机号与设备

新手建议至少准备2个账号，因此你需要：至少1部手机，带多开功能或多个手机都行；至少2张电话卡，因为1个视频号需要1个实名微信号，对应1张电话卡。

电话卡推荐：三大运营商都能办副卡，一个人可注册认证5个微信，一拖四，副号月租费10元；移动万能副卡1张10元月租，1个身份证能领2个副卡，第一张和第二张需间隔90天，营业厅和App都能办，营业厅还可操作免第一年月租；中国电信App搜“无忧卡”，5元一个月，基本第二天送上门；移动也可以办8元保号套餐。

手机推荐：手机除了登录账号，也会用来拍视频。如果只做短视频拍摄，千元安卓机就够，安卓系统还自带双开功能；如果后续想放大做直播，iPhone的直播稳定性更好，但iPhone无法双开。有条件的话，也可以准备3到5个账号同步跑，投入会相应增加。

# 2.1.2 拍摄器材

1. 拍摄设备与软件：建议直接用手机，现在手机像素足够拍短视频，拍摄时用后置摄像头性能更好。担心看不到自己，可以用镜拍的方法解决。有单反相机效果会更好，但大多数人还是以手机拍摄为主。拍摄软件千万别用美颜软件，直接用手机原相机。
2. 提词设备与软件：可以用2部手机，1部拍摄、1部提词；也可以手机拍摄加电脑提词。手机端可用提词拍摄或快题词，拍摄时直接看提词字幕，剪映也自带提词器。iOS App Store和安卓应用商店都能下载。

# 2.2 账号筹备

# 2.1.1 账号注册、登录与维护

账号注册：走完以下6步，就能创建视频号。

1. 在微信「发现」页点击「视频号」。
2. 在「视频号」页点击右上角「人像」图标，进入视频号主页。
3. 在主页点击「发表视频」，进入创建页面。
4. 在创建页填写账号信息（头像、性别等），勾选“我已阅读并同意《微信视频号运营规范》和《隐私声明》”。
5. 如果不想让账号好友看到你发布的内容，关闭「在个人名片上展示视频号」。
6. 创建完成。

账号登录：可以用双开形式，1部手机登2个微信；也可以把多个视频号的运营者都绑定自己的大号微信，之后用网页版登录这些视频号操作。

需要注意：如果多个视频号绑定了同一个微信号作为运营者，这个微信号一次只能同时登录一个视频号。比如微信号A绑定了视频号①和视频号②，扫码登录视频号①后，再登录视频号②，视频号①就会被退出，再登录需要重新扫码。

多个微信号的维护：批量注册的微信号容易被封，注册了2个号也要留意。微信养号的核心是模拟真人操作，具体可参考5个办法：完善头像、名称、背景墙等基本信息；修改微信号、密码、支付密码，零钱包里放几块钱；每天发2到3条朋友圈，内容、长度不限；随便添加5到10个好友，每天发几条消息；每天在视频号刷视频、看直播。

# 2.1.2.2 账号包装实操

1. 账号名称

先看官方给出的【账号名称】注意事项：名称要根据账号类型来定，一个好名字能自带搜索流量。最常用的办法是相关关键词组合，比如健康、书籍、认知等。用关键词组合，别人搜索时更容易找到你。不过有些朗朗上口的名字已经被抢注，注册时要多准备几个，逐个尝试。账号名一年最多改5次，没想法时可以参考各平台同类型账号的取名方式，也可以取通用名称，例如【xx-同款在橱窗】。

关于昵称修改，@麦洛提醒：昵称一年只能改5次。建议先设置一个通用昵称，比如“xx-同款商品在橱窗”。简介在视频号创建完成后可以修改，路径是：视频号主页头像→右上角…→头像→简介。简介最好放3行文字，多了会被折叠。简介里可以放引导成交内容，例如“同款商品在👇🏻下方购买”。不建议轻易放微信号，因为引导到微信成交效率很低，精力浪费很大。
