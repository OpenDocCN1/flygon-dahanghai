# 出海买量广告的精细打法

上一篇聊过怎么从 Facebook 和 Google 的流量里找红利，这次再补几条投放观察。先提醒一句：下面有些操作在平台规则边缘试探，别盲目照搬。

1. 买量用户与自然用户分开对待。通过 Facebook、Google 投放带来的用户，才触发广告；自然流量进来的用户不弹。这样审核人员主动搜索、下载应用时，不容易撞见有问题的广告位。节奏由云端统一控制：前三天先上相对温和的展示位；充电锁屏、挂断页广告这类更激进的样式往后放，通常第三到第七天才出现。

2. 按流量来源匹配广告平台。Facebook 渠道来的用户，优先展示 Facebook Audience Network 的广告；Google AdWords 带来的用户，先走 Google AdMob；剩下的流量再用 MoPub、Flurry 等平台补量。

3. 场景不同，广告也不同。出差旅客刚下飞机、解锁手机时看到 Uber；走到酒店附近，出现 Yelp 和周边热门景点推荐。这是按地理位置（LBS）分发。一天里的早、中、晚也能拆开精细化运营，别把所有广告一股脑塞给用户。

4. 充电锁屏在 2015 年最泛滥。某数字公司、某动物公司、某*娘公司当年出海的产品接入这个位置后，每天多出几十万美元收入（还是保守估算）。16 年初在印度出差时，我见到酒店前台小哥插上 USB 充电，竟要连着解锁四个 App 的充电锁屏，四次全屏广告就这么看完了。这种小聪明，真是到处都能见到。到了 2017 年 Google 开发者大会，谷歌已不允许非锁屏类 App 使用锁屏广告；只是规则与对策的较量仍未结束。
