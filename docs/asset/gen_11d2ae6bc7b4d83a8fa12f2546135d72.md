# 中高考前，小红书押题帖火了

每年到了六月的考试季，流量热点总是格外密集。眼下高考、中考近在眼前，“押题”相关内容在小红书上热度持续攀升，成了不少博主吸引关注的新选择，导流效果相当亮眼。随手一刷，就能看到大量相关的热门笔记，讨论度和互动量都很可观。
