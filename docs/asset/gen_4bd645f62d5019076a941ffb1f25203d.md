# 2.2.2 账号包装四步法

账号包装不只是填资料，下面这四步，每一步都影响搜索、记忆和成交。

1. 账号名称：让名字自带搜索入口

先看平台对【账号名称】的提示：

[PRE0]

起名时先想清楚账号做什么类型，名字取得好，本身就能承接搜索流量。最常用的方法，是把相关关键词组合起来，比如国学、书籍、认知等；这样别人搜这些词时，你更容易被搜到。好记又顺口的名字很多已经被注册，所以注册前多准备几个候选，逐个试哪个能注册。账号名一年最多改5次；如果没思路，可以看各平台同类型账号怎么取名，也可以先用通用名，例如【xx - 同款在橱窗】等。

@麦洛 关于昵称修改的提醒：昵称一年只能改5次，所以建议先设一个通用昵称，比如：xx-同款商品在橱窗。视频号创建完成后，简介还可以修改；修改路径为：视频号主页头像 → 右上角 … → 头像 → 简介。简介最好放3行文字，多了会被折叠。简介里可以放成交引导，例如：同款商品在👇🏻下方购买。建议不要轻易放微信号，因为引导到微信成交的效率很低，精力浪费极大。

参考来源：《视频号带货建议指南》

2. 头像：让人更容易记住你

好头像能让人更容易记住你的视频号。头像可以用纯文字（名字缩写），也可以做图文形式；如果拿不准，就去搜你所在内容定位下的视频号大V，看看他们通常怎么设置头像。制作时可以用图怪兽等网站，或找无版权图片：

•图怪兽：[`818ps.com/`](https://818ps.com/)
•可画：[`canva.com/`](https://canva.com/)
•创客贴：[`www.chuangkit.com/`](https://www.chuangkit.com/)

注意别用容易侵权的商标类图片，也不建议用个人头像，容易和账号定位不符。

3. 个人简介：直接告诉用户怎么买

简介随时能改，关键要贴合账号定位，完全可以参照成熟大号的做法来编辑。带货号最直接有效的简介，就是告诉用户怎么买，比如可以直接写：

视频同款，在👇🏻下面【商品】购买

微信号可留可不留。如果想在简介里留微信，虽然是在腾讯自家平台，但为了保险，可以用隐晦些的表达。不过建议初期先别加，可能被同行举报；等账号成熟、粉丝多了再改也不迟，例如：

•+v:
•更多 xx 联系领取：
•商务合作请联系：

4. 置顶视频（后续开始更新后）

一个账号最多能放2条置顶视频，先后顺序也要留意。通常第一条置顶可以选爆过的或近期热点视频，第二条置顶放最看好的带货视频。带货号还有个小技巧：置顶视频可以放一条教用户如何下单的引导视频：
