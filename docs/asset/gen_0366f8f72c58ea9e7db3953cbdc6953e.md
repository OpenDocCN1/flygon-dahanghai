**1.2 五维筛选法**

把前面列出的每项工作依次对照下面五个问题。每答一个“是”，记 1 分：

1. **出现频率高吗？**是否每周都会碰到，或几乎每个项目、每场活动都要再来一遍，并且要持续花时间？

2. **输入是否稳定、好辨认？**每次拿到的材料类型是否比较固定，例如聊天记录、文档、网页或表格，而不是每次都完全变样？

3. **处理流程和判断规则清楚吗？**多数情况下是否有较固定的操作顺序与判断口径，不用每次临场想怎么做？

4. **结果是否清晰、能验收？**是否可以通过文档、表格、消息或链接，直接判断有没有完成、做得对不对？

5. **出错时能否人工兜底？**Agent 做完后，你还能在发送、发布或交付前检查一遍，即便有误也不会马上带来重大损失。

**得分 ≥ 4 分：**很适合优先做 Agent 化。**得分 2–3 分：**可以试，但最好先精简流程、补齐规则，或加入人工复核。**得分 ≤ 1 分：**暂不建议优先 Agent 化，先放入“不做清单”。

### 04. 本关复盘

**Agent 岗位卡，本质上是把“能跑的 Demo”转化为“职责清晰的 AI 员工”。**

第 1 关你已经看到 Agent 能完成一次可见任务；本关则要把这种体验落到自己的真实工作中：先找出重复事项，再判断哪项适合交给 Agent，最后写成一张职责清楚的岗位卡。

第一个正式 Agent 最好从一个小岗位起步：任务会反复出现、输入来源明确、处理步骤说得清、输出结果可验收，出错时还能人工兜底。

**核心四个动作：**

1. **列出重复工作**：先通过 AI 对话，把每天、每周以及被动触发的重复任务整理成候选清单。

2. **用五个维度筛选**：让 AI 先做初筛，频率、输入、规则、验收方式和风险边界仍由你最终确认。

3. **写一句话岗位定义**：借助“收到什么输入、自动做什么、输出到哪里”把岗位说明白。
