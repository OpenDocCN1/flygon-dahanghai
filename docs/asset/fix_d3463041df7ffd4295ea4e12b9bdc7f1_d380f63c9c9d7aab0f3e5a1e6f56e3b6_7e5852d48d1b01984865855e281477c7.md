# 3.9.3 新手用AI接PPT单：红榜与黑榜

# Part 1 新手红榜

1、纯文科答辩演示文稿
理论分析类演示文稿的关键，是把观点理清楚。版式交给智能工具处理，不用改图表、不用调代码，新手可以优先尝试。
步骤一：整理内容。把长文里的观点拆成小标题和关键词，比如“研究背景→案例→结论”，交给智能工具自动分点，不必纠结实验数据或代码。
步骤二：设计上省点力。文科类不需要复杂配图，系统给出的纯色版式配微软雅黑，白底黑字也能看。老师更在意逻辑顺不顺，样式选AIPPT里的基础学术版式就行。
步骤三：重点查逻辑。产出后一定核对标题是否贴合论文本身，比如“发现问题→分析原因→解决对策”，自己再顺一遍，答辩时老师常问这些。

案例拆解：拿【省域入境旅游服务贸易竞争力研究】当样稿，用WPS AI走一遍。
第一步：浏览文章。打开论文文档，重点看目录结构、研究方法，以及现状、问题、策略等主要观点。
第二步：让智能工具搭框架。打开DeepSeek对话框，输入指令：

💡 【任务】我的答辩文章题目为《___________》，需要你为我生成一份PPT设计大纲，XX页。
【结构要求】封面页、目录页、正文页（按正文实际内容设计）、总结页、致谢页。
【要求】……

操作技巧：点回形针上传论文PDF，关掉右上角“联网搜索”，模式选“深度思考R1”。

# Part 1 新手黑榜

1、急单
风险点：客户要求几小时内完成。表面看时间短、报酬高，还有加急费，实际不确定性很大。
具体问题：用智能工具出初稿后，常发现某些页面要手动调，比如特殊图表、复杂排版。如果演示文稿基础操作不熟，光调字体对齐就要半小时，更别说客户中途新增要求。对软件基础不扎实的人并不友好。

2、纯美化
风险点：客户发来的演示文稿已经有完整内容和版式，只要求“优化得更高大上”。客户常以为“不就是调个颜色换张图”，实际可能涉及：重新设计20页图标体系、统一全文档字体间距、调整50处图文混排对齐。收费也难：客户看到成品常说“这和原来差不多啊”，尤其原稿本身不差时，他们意识不到背后有200多处细节调整，最后钱和时间都容易打水漂。

3、带复杂动画的
[PRE23]
为什么智能工具搞不定？系统产出的动画多是“淡入淡出”“左右飞入”这类基础动作。比如客户想要“用动画画出建筑结构”，系统只能让整张图突然出现，做不到“地基→墙体→屋顶”的分层建造。
踩坑案例：曾接儿童教育演示文稿订单，客户要求“字母A变成苹果的动画”。系统只能让字母消失、苹果出现，而客户想要的是字母A的横杆慢慢弯曲成苹果轮廓。结果花3小时研究动画路径工具，最后客户退款。
避坑：有些客户会发参考视频说“就要这种效果”，但视频里的动画可能是专业影视软件做的，一定提前问清动画细节。

4、数据分析类
[PRE24]
案例：客户有300份问卷结果，要统计成饼图、柱状图。为什么进黑榜？
一是智能工具可能变“复读机”。客户发来包含678条销售记录的Excel，系统只会把数据转成文字，比如“7月销量最高达230万，环比增长12%”。实际需要的是：整理数据、删除无效条目、用折线图对比6—7月趋势、在图表旁标注重点数据。
二是客户预期错位。客户觉得“你不是智能生成很快吗”，但实际：数据有错时，比如合计金额≠明细相加，系统不会提示；要做组合图表，比如柱状图+折线图双坐标，系统只会生成分开的两个图；客户中途改数据源，所有图表都要手动重调。

# 3.9 淘宝“新手村”路线@海盐芝士

# 3.9.1 心态先摆正

1、用实习者心态，别把赚钱当第一目标
为什么把淘宝叫“新手村”？就像刚进新公司，派单的人前期并不了解你的能力，你也没经验。所以前10—30单，适合以新人练手的方式做，不必把能不能拿到报酬看得太重；真正去写实际单子、实操、踩坑，才是第一目标。有实操机会已经很可贵，还大概率有报酬；就算经验不足踩了坑、没拿到钱，也别太在意。实战经验很值钱，把淘宝当新手村练手就好。

2、可能拿不到报酬的原因
淘宝和外部一些同行中，不少客服和客户没经过专业培训，不太专业也不太靠谱。谈单客服在售前售后有时没和客户谈好收款条件，客户耍无赖要退款，他们就直接退了，撰稿人就可能拿不到钱。
了解情况即可，自己留个心眼。发现对方说得不对，主动沟通；他们并不权威，哪怕错了，也可以把建议和客户说清楚。若对方认知不到位、不专业，非要那样写，就按客户需求写。撰稿人的职责是根据客户已确认的需求写文案；过程中发现不合理，提醒到位即可，决定权交给客户。该提醒的都提醒了，他不听，责任不在我们。真拿不到报酬，也别内耗。外部行业情况如此，第一目标仍是实习实操、涨经验。有钱更好，没有也没关系；价格低也没关系，经验是自己的。

3、扩大分母，提高新手应聘淘宝成功率
可以多去应聘几十家，争取进入至少10家店铺。进了接单群，就能看到很多单子：哪些单价高？哪些需求自己大概能看懂？去网上快速找对标，再用方法论套用，能力就提升了。

4、有经验后，再去天猫店应聘
前期至少10单不建议去天猫。等自己有了10—20个真实客单的体感，包括客户沟通、客服沟通经验后，再去应聘一波天猫店，并扩展几十个淘宝店铺。这时要好好包装简历，比如写文学硕士、某某专业，再搜一些优质稿件重写一遍，当作自己之前写过的真实稿件去应聘。相当于拿一份好简历去新公司面试。

5、尽量展示能力，等待飞轮效应
前期大概2—3周，是淘宝客服和你互相试探的阶段。单子可能不多，但一旦有几个客服给你发单，或你主动抢到一些单，让他们发现你靠谱、能写的类型多、质量好、效率快，一个客服就可能推荐给几个客服，也会把单价相对高的单给你。多数普通人还是要积极主动抢单、接单，客服才能发现你，能力值才能被看见。底层市场需求是：淘宝非常缺靠谱、质量高的撰稿人。最大的店铺有3000个撰稿人，里面不到50个抗打、能写中高端品类且靠谱。前期2—3周，快的话1周，有的同学面试后客服就直接发高单价单子。这看写作能力和一点运气，就像面试遇到好领导也有概率，所以要多扩大分母。

6、只做撰稿人，在淘宝接单，靠谱+质量好，月入过万没问题
有位朋友的妈妈被裁员后没事干，来做AI写作项目。她只有高中学历，也没突出能力，更没系统学习，就自己闲着去淘宝接单，在网上找素材资料，用智能工具给客户写。第3个月赚了3000+，从第3个月开始月均3—5万，现在在几个淘宝店铺里成了顶尖撰稿人。
