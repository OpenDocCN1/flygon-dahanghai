# 3.1 订阅套餐怎么定

套餐设计是产品商业模式的核心：既要接住不同用户的需求，也要兼顾收入和增长。

# 3.3.1 套餐设计的逻辑

1. 分层满足需求

免费用户：把试用门槛降下来，扩大用户池。

付费用户：拿到核心功能和效率提升。

高阶用户：解决专业/企业级需求，附带API调用、团队协作、专属服务等额外价值。

2. 价格锚点效应

至少准备低、中、高三档，用户会自然偏向中间档，这就是心理学里的“折中效应”。

3. 差异化设计维度

使用额度：视频时长、生成次数、存储空间。

功能权限：高级功能、API、批量处理。

服务体验：客服响应速度、团队成员数、白标/定制化。

结算周期：按月/按年，年付打折。

# 3.3.2 常见套餐长这样

以AI工具站/视频剪辑SaaS为例：

1. 免费套餐（Free）

目标：拉新，并让用户建立使用习惯。

内容：限制部分功能（比如导出视频带水印）；每月设置使用上限（如30分钟视频处理、100次AI调用）；提供社区支持。

2. 基础套餐（Starter/Pro）

目标：个人用户或刚起步的创作者。

定价：9.9-19.9美元/月。

内容：去水印；提高额度（如每月10小时视频）；开放常用高级功能（字幕编辑、批量导出、AI解说）；邮件客服。

3. 专业套餐（Advanced/Creator）

目标：重度个人创作者或小团队。

定价：29-49美元/月。

内容：更高额度（每月50小时视频）；全功能解锁（API、自动化工作流、跨平台发布）；团队协作（3-5人）；优先客服（实时聊天）。

4. 企业套餐（Enterprise/Custom）

目标：中小企业或大客户。

定价：99-299美元/月，也可以定制报价。

内容：无限额度或大幅扩容；专属客户经理；白标/二次开发能力；发票和法人合规支持；SLA（服务级别协议，保障稳定性）。

# 3.2 收款渠道怎么落地

# 3.2.1 Stripe与海外主体怎么配

为什么建议注册海外公司？

- 有稳定的收付款渠道和海外银行账户。
- 很多海外服务对大陆身份有限制，风控也更严；用海外公司主体更容易接入。

海外手机号准备：

- 英国giffgaff：180天发一条短信就能保号，费用约£0.3，官网可免费申请。
- 美国Ultra Mobile PayGo：月租约$3。
- 上面这些号码也可以通过淘宝、京东代购。

海外公司注册地怎么选：

- 英国公司：注册更简单、更便宜，推荐[1st Formations]，开户可用Wise企业账号。
- 美国公司：更适合拓展业务，常见注册州是Wyoming（怀俄明州），公司类型选LLC，适合个人开发者。

一站式服务推荐Firstbase：

我选的是Firstbase，体验更像SaaS，注册、地址公证、EIN、开户一条龙。

流程概览：

1. 注册公司：选怀俄明州LLC。
2. 地址公证：租私人邮箱地址，用Notarize视频公证（1583 Form）；准备身份证明（护照/驾照翻译件，淘宝可代办），注意照片和地址要同页展示。
3. EIN申请：Firstbase代办，大约10个工作日收到IRS信件。
4. 银行开户：推荐Mercury，关联EIN和护照后，1个工作日内审核通过。

走完这些，你会拿到：公司主体、EIN、私人地址、银行账户、海外手机号。

Mercury银行优势：

- 虚拟卡不限量，能按商户限制使用，管理订阅和退款方便。
- 虚拟卡可绑支付宝，单笔200元以下免3%手续费。
- 可接收账单地址邮件，比如Google AdSense验证信件。
- 支持申请实体卡并转寄回国。

Stripe企业账号开通：

- 用EIN注册即可。
- 网站语言可切中文填写信息。
- 个人验证用护照。
- 提现账户绑定Mercury。
- 建议同时注册Lemon Squeezy、Paddle做备用收款渠道，但需要验证产品网站。

Wise个人收款与提现：

- 支持大陆身份和护照注册。
- 入金可通过Mercury转账，或淘宝代充。
- 实体卡（含3张虚拟卡）需$9，支持激活后修改地址再申请。
- 支持提现到国内银行卡、支付宝、微信，手续费低，汇率比国内结汇更优。

# 流量运营

我的价值观里，产品永远第一位：你有没有真的解决用户问题。所以我们一直强调找PMF，也就是产品和市场的匹配度。产品跟市场足够匹配，流量就不会是问题；像特斯拉、微信这类产品，本身就不需要靠营销。但新产品起步，至少要先拿一部分流量做冷启动，后面再根据产品发展决定用哪种方式放大。

# 1. SEO：把免费流量做厚

SEO是最有长期价值的流量来源。核心是优化网站和内容，让搜索引擎更愿意推荐，从而拿到免费自然流量。

关键要点：

- 关键词策略：盯住用户真实搜索需求，选相关度高、竞争没那么激烈的词（工具可用Google Keyword Planner、Ahrefs、Semrush）。
- 内容建设：持续产出高质量落地页、教程、FAQ、博客文章，解决用户背后的搜索意图。
- 权重提升：通过友情链接、投稿、媒体报道拿高质量外链。
- 用户体验：优化加载速度、移动端适配和交互设计，让用户愿意多停留。

适用场景：适合想长期积累、沉淀品牌价值的产品，比如工具站、知识型网站。

案例：海外AI工具站（如TAAFT、Futurepedia）靠SEO做了大量长尾关键词页面，持续拿到自然访问。

# 2. 社媒营销：让内容自己跑

社交媒体传播最快、也最灵活，核心是借平台的传播机制，让用户主动帮你扩散内容。

常见平台：

- 海外：Twitter/X、Reddit、YouTube Shorts、TikTok、LinkedIn。
- 国内：小红书、抖音、知乎、微博。

常见打法：

- 短视频/动图展示：用对比、演示、教程快速讲清产品价值。
- 话题运营：蹭热点、参与讨论，在评论区适度引流。
- KOL/达人合作：借有影响力的人快速放大传播。

适用场景：特别适合冷启动，尤其是视觉冲击强、容易引发讨论的话题型产品。

案例：不少AI换脸、AI绘画应用，都是先在TikTok上用效果展示视频走红，然后才实现规模化获客。

# 3. 付费广告：花钱买精准

付费广告是拿精准用户最快的方式，直接用钱换流量和转化。

常见渠道：

- 海外：Google Ads（搜索、展示、YouTube）、Meta Ads（Facebook/Instagram）、TikTok Ads。
- 国内：百度推广、抖音广告、快手广告。

操作关键点：

- 精准定向：按兴趣、地域、年龄、消费能力筛人群。
- 转化追踪：用像素/转化API跟踪行为，持续优化投放。
- 小额测试→规模化：先用多组广告小额测试，找到ROI最高的素材，再逐步加预算。

适用场景：适合需要快速拉新或验证市场需求的产品。

案例：不少SaaS创业者会先投Google Ads，用“关键词广告+免费试用”测试市场接受度，再决定要不要长期投入。

# 收尾：把复利交给时间

不积跬步，无以至千里。

成长和财富的积累，底层都靠复利。复利不是一夜之间的改变，而是长期坚持，把每一次小小的进步滚成指数级飞跃。

我们现在做的事，本身就是一种低风险的长期投资。刚开始可能看不到立竿见影的效果，但每一次学习、实践和微小成果，都会变成未来爆发的筹码。等风口来了，你积累的底层能力和资源，会让你拿到远超常人的收益。

所以，真正的差距不是一时拉开的，而是日积月累的复利效应。

从现在开始积累你的复利，把耐心和坚持当成最好的投资工具，让未来的自己感谢今天的你。
