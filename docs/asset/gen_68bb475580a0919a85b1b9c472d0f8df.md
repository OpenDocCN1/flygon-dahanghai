# 7.4.2.1 强关联内容达人，怎么找更准？

想在📕投放时少走弯路，先把内容方向与品牌契合的强关联达人圈出来。千瓜数据把“达人特征”和“粉丝群体”两条路径都打通了，下面这套筛选思路可以直接用。

**1）先看账号标签，按内容分类锁定**

平台会给创作者的每篇笔记标注内容分类；如果一位达人长期稳定地产出同一领域的内容，其账号也会逐渐带上对应类别标签。📕会依据账号标签，把内容推荐给相关粉丝，粉丝越垂直，流量表现通常越好。进入千瓜数据“达人搜索”栏目，就能看到按文章类型汇总出的分类标签，直接勾选条件，筛出符合行业方向的达人。

[PRE0]

**2）六维评估账号质量**

搜到候选达人后，别急着定，先进一步看账号质量。可以从以下六个方面判断：

- 看整体数据，包括平均数和中位数，确认是否达到基本数据门槛。
- 看笔记类型分析，判断达人更擅长哪类内容：笔记分类占比要高；同时留意“笔记分类互动量占比/笔记分类占比＞1”这一指标。
- 看平均“赞藏”表现，如果走势比较平稳，通常说明粉丝相对稳定。

[PRE1]

- 看“粉丝分析”里的活跃粉丝占比与水粉丝占比。千瓜会结合粉丝在📕的互动行为综合计算，这项指标能反映粉丝质量。
- 看新增数据表现，判断达人笔记更新频率，以及在与相近粉丝量级达人对比时，同一时间段的点赞增量水平如何。
- 看数据真实性：笔记内容是否重新编辑过，以及内容与笔记标签是否严重不匹配；若出现这种情况，可能存在笔记内容替换。

[PRE2]

**3）根据场景切换检索方式**

不同搜索需求对应不同检索模式，选对方式才能更精准地筛人。

- 按关键词检索：用昵称关键词配合丰富筛选条件，快速锁定目标达人。
- 按笔记内容检索：比分类标签更细，可直接锁定达人笔记内容中的指定关键词。

[PRE3]

**4）从粉丝标签反向寻找达人**

达人背后连接的是粉丝，锁定达人本质上也是在锁定其背后的粉丝群。因此，选择与品牌调性相符的达人很关键。千瓜会分析达人粉丝类型，并归纳出数十个人群标签；在“达人搜索”中点选粉丝人群标签，就能定向找到覆盖目标粉丝群体的达人。

[PRE4]

**5）拆解粉丝关注点与人群画像**

进入达人分析页，右侧“粉丝分析”可继续查看粉丝关注焦点、粉丝人群标签，以及性别、年龄、地域、活跃时间等画像基础数据。这些信息能帮助判断粉丝是否符合投放需求。

[PRE5]

**6）读懂粉丝互动偏好**

借助AI建模分析，千瓜能刻画达人粉丝在整个平台的互动偏好，既方便了解粉丝，也便于筛选更多同类型账号。

- 笔记分类偏好：汇总粉丝发布的笔记类型，直观看出粉丝喜好。
- 互动偏好：从粉丝互动评论的笔记中提取高频词汇，了解他们在平台上的关注点。
- 品牌偏好：梳理粉丝发布笔记及互动笔记中提到的品牌信息。
- 关注的达人偏好：汇总分析粉丝除当前达人外还关注哪些类型的达人，以及达人粉丝区间和赞藏区间。
