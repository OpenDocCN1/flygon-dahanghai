# (精华帖)(74赞)从1-2%到7-10%+：亚马逊利润细节拆解

作者：thousands｜2022-07-05

我是thousands，在一家鞋服公司带亚马逊运营团队，团队年度GMV在7000万到8000万美金区间。和很多同行一样，去年最难的时候，新品单月净利率几乎打平，老品从10%掉到5%以内。后来我们把每个环节拆开抠，新品做到7%，老品回到10%以上。我们算是走出来了，但不少卖家还困在低利润里，所以把实操拆给大家。

先看底层公式：利润＝收入－成本。

收入端只有两个变量：售价×销量。成本端包括采购款、头程运费、平台佣金、仓储、履约配送、广告、促销让利、退换货与破损损失等。能正向拉动利润率的因子主要有：定价、采购成本、头程、仓储、广告、配送、退货率和破损率。我们围绕这些因子做了细化拆解，重点落在下面几块。

一、选品：抬高定倍率，多挣10%以上毛利

1. 体量要匹配自身实力

每个类目都应尽量挤进头部——既包括类目头部，也包括关键词排位头部。亚马逊是流量平台，流量紧缩期更明显：淡季流量会优先给头部。产品做不到头部，自然流量就少，只能靠付费流量硬推，推广成本很难降。做到头部，至少在当下平台，和工厂议价时更有底气。所以要结合预算，预估细分赛道冲到头部需要多少资金，再判断是否去抢类目或细分需求的TOP。

我们自己的产品已经拿下多个类目TOP。同等单量下，TOP链接转化更高，广告订单占比更低，综合下来广告花费占比能少约2个百分点；供应链上也有优势，大厂愿意优先排单，价格更低，还能在竞争里形成挤压。

2. 挑综合实力偏弱的对手所在的类目

选品时多列几个备选，再筛。亚马逊眼下没有绝对蓝海：相对而言，弱于你的市场是蓝海，强于你的市场就是红海。筛完后，从供应品质（评分、断货频次）、页面视觉、文案水平、推广节奏（历史销量曲线）、资金实力等维度拆竞品，再决定跟进哪个类目。

3. 新卖家优先轻、小、快

初创卖家从0到1容易走弯路。选轻小快，能省时间成本，最快跑通流程，也方便验证自己的细节判断。

4. 做差异化，别一头扎进同质化内卷

差异化是拒绝内卷的重要部分。产品有差异，议价权才更好。平台电商里差异化产品也会被跟进，但护城河越深，利润溢价能守住的时间越长。

5. 定价要敢留利润

如果不是价格敏感型产品，在不大幅影响转化的前提下定高价，毛利水平会更好。有几款服装临近断货，我们上调了5美金左右，转化率几乎没受影响。对价格不敏感的商品，建议胆子大一点卖高价。

这一环做完，对整体利润率的影响约5-8%。

二、生产端：把供应链变成利润支点

1. 找供应链有优势的品

看速度：开发速度和量产速度；看质量：能不能做好品控；看灵活性：能否柔性生产、少量多批次开发测试；也看工厂综合实力。我见过不少原本不错的工厂，因为资金链等问题 later 变差。有供应链优势的产品，能帮我们省下大量测试成本，也能规避测试风险。

去年年初，我对自己的选品和推广能力过于自信，很多新品第一批就备了小万件过去，结果工厂质量出问题，评分低、退货高，最后只能靠放量等手段草草收尾。去年“大跃进”式备货，净亏了大几十万元人民币。

一方面少踩坑；另一方面，配合度高的好工厂在起量后，能用更合理的备料、更顺的流程把成本压下来，为了拿更多订单也愿意给更低价格。

2. 多备工厂，让供应商之间形成竞争

优质供应链只靠一家不够，要让工厂之间有危机感，才能快速知道谁又快又好又便宜。我们的做法是定期开某类供应商会议，反馈诉求和问题，对能响应的供应商重点扶持，定期淘汰劣质供应商。

这一环对整体利润率的影响约1-2%。

三、运输：把物流价格打成可控项

1. 摸清物流淡旺季，避开价格尖峰

海运价格会随购物流量波动，Prime Day、黑五等活动旺季前尤其明显。今年Prime Day要求6月20日前停止入仓，美森快船约30天时效；若卡在5月10日发，价格一定高。供需决定价格，所以我们在Prime Day前90天，把在途加在库的备货再拉长20天左右；到了价格高峰，只做缺口补货。头程成本因此至少降了6%，折算到利润率约0.5个百分点。

2. 多找几家物流商比价

起初我们只依赖一家长期合作的物流商；后来同行介绍才发现，它的价格常高于市场平均，时效也没优势。之后我们不再只信最初判断，经不同行业卖家介绍，分别测试几家物流商，分析时效和价格，再把数据拿去沟通。每次发货前结合时效比价，物流商彼此知道，价格上多有让利。这一环又抠出约0.8个百分点的利润率。

3. 用免费海外仓做缓冲

有些季节性产品，发货高峰正好撞上物流价格高峰，所以要把发货期提前。但新品在新店铺过早大量发货，会让库销比过低，仓储费高，甚至无法正常发货。我们会结合提供45天内免费仓储的海外仓服务商，把旺季的货先放一部分在海外仓，到季节再安排入仓。这部分节省要结合第一点一起看。

4. 包装要算体积重

重货与抛货混装是个办法。物流头程按体积重或实重取高计费，体积重＝长cm×宽cm×高cm/6000。用两个虚拟产品做对比：A产品0.6kg、12件/箱；B产品1.9kg、36件/箱。[PRE0]

同一箱规下，轻货和重货混装能让体积重更接近实重，头程就省；第二种装法只少装一件轻货，却能多塞三件重货，单件发货成本大幅下降。靠这种方式，我们实现了跨类目重货的成本突破，部分重货的履约价能比同行低约30%，毛利反而领先约5个百分点，所以我们能更“卷”还留得住利润。

另外砍掉非必要包装。去年年中集中盘点装箱方式，压缩不该用的箱规；对以体积重计费的箱子，头程降约10%，净利率增约0.8%。产品包装也要处理：亚马逊配送费按体积重或实重取高，机器扫描会取长宽高最高值，我们有一部分抛货，于是把龙骨带和龙骨以上多余部分严格压住，不够紧凑的外包装换成更贴合的袋装或盒装。[PRE1]

调整后，部分产品的FBA配送费下降约20%；平台新规落地时，同行按同等幅度提价，我们的净利率反而多出约2个百分点。[PRE2]

这一环对整体利润率的影响约2-3%。

四、仓储：用计划压掉冗余库存

1. 销售计划与备货计划要细，砍掉冗余库存

海运产品库存含在途，天数控制在50天上下比较合适。销量不是一成不变的，要按推广节奏、季节、活动提报做销量预测，把库存销售天数控制好，仓储费就能明显下降。我们把备货周期从90天压到50天，仓储费至少砍掉四成，Q4净利率提升约1%。[PRE3]

2. 用海外仓缓冲季节差

仓储费贵，所以季节差大的产品可以提前备到海外仓；不影响推广节奏，又能减少仓储费。

3. 滞销品要快处理：放量、清仓、弃置

以前给运营的试错时间太长，有些产品前期备货夸张，跑一段时间数据才发现并不是“爆款”，又没及时处理库存，长期仓储费就出来了。后来新链接到一定节点（约1个月）如果没按推广节奏走，我们就介入帮带、把控节奏；介入后仍解决不了滞销，就果断放量配合降价清理，尽量把冗余库存处理掉，省仓储费，也尽量回收投入成本。

这一环对整体利润率的影响约1-2%。

五、推广：以CPA为尺，少花冤枉钱

1. 组合站内工具，去竞争小的流量位，把CPA压低

我们基本不做人工干预，广告是核心推广手段，也是多数白帽卖家的打法。去年CPC猛涨，我们没及时调策略，仍盯着高点击、高转化的位置，结果CPA（每出一单的广告成本）一路走高；广告订单占比没变，总广告花费占比却涨了3到5个百分点，净利被直接吃掉。

内部深度研讨后，我们开始尝试新的广告方式，更多以CPA为导向。常用手段有第三方代投DSP、站内AMS、SP、SB、SD，并把不同类目数据汇总分析。DSP只有再营销和站内竞品关联位表现较优，其他类目和陌生人群的扩量就收窄了；心态从“试错、可放量、允许亏”改成“不赚钱就不投”，并定期复盘、按数据调预算。

SP过去靠关键词卡首页，打法很猛、起量明显，但后期CPA很难看。后来发现用定位也能在一些词上拿到同样效果，CPA更漂亮。关键是我们几乎把各类广告都测过，有足够数据，能快速判断当前哪种广告CPA最低。结论：多用定位；多挖竞争力偏弱的长尾词，单个词小，但量堆起来很可观。

SB、SD过去被我们当“钓鱼”工具，表现不差，但订单占比不高。后来看竞品广告报告，有卖家这两块占比高、广告表现也更好，于是我们通过堆叠和竞价调整，把低CPA的占比拉上去。

广告没有神秘技巧，核心就是多测、别错过亚马逊的新动作，用对比找更优路径，再放大。广告还有一个重要目标：自然位，让产品拿到持续免费流量。若产品有差异化，可以结合自然位观测，适当关掉部分广告。

2. 页面值得花时间，转化率每抬一点都是利润

页面分两部分。静态部分如图片和文案，最基础的方法仍是先研究、再模仿、最后超越：先学优秀竞品，再看优秀类目的做法借思路。动态部分如rev、QA：即便不做人工干预，也能通过点赞把更优质的rev顶到前面；QA则分析用户最关心的问题，用自问自答建立信任。

3. 慢慢降低付费订单占比

自然订单占比一直起不来，也是利润率卡住的原因。后来才明白亚马逊的货架理论：同一页面里同asin会互相抑制。于是我们对老品分批下调广告预算，总订单没降，甚至上升；总广告花费占比至少省了3%。

4. 站外引流与红人种草：难，但效果持久

去年开始，我们逐步增加站外投放，联系Instagram、Facebook、独立站网红和编辑，慢慢积累站外流量。初期很难：网红触达率低、没有合作经验、经常被拒；但坚持积累后，这些网红编辑成了重要伙伴。有些新品靠这部分流量，在新品期就做到自然流量与付费流量8:1。很建议亚马逊同行也做这块。

5. 关联位与流量闭环，减少跳转流失

起初流量闭环做得不好，关联位甚至A+布局都不完善，进来的流量被竞品分走。后来用页面布局配合站内广告，把页面内关联位尽量铺满：一是自动覆盖自然关联位、省费用；二是关联链接调性接近，流量能在自家链接内继续转化。

这一环对整体利润率的影响约4-5%。

六、退换货：把差评和退货率压下去

1. 差评要反推到供货改进

客户体验是亚马逊飞轮里极关键的一环，却常被卖家忽略。链接有利润时只顾冲量，久了就会被平台逐步淘汰：评分差、退货率高，链接越来越难正向循环。去年我们对不少老品做了定期改良。[PRE4]

具体做法是：把退货报告拆细，找清退货原因，和工厂一起改；先在某个小批量（比如服装的某几个颜色）试，结果好再推到全链接。同时收集差评和QA，产品薄弱处马上改，劣质变体及时砍掉，降低差评率。

这一环对整体利润率的影响约1-3%。

这事说起来简单，做起来是长期活。我们有些3年以上的老链接一直没被淘汰：一是持续加新元素迭代，二是评分和退货率优于竞品，平台更信任，自然流量更多，退货损耗也更低——以定倍率约5的产品算，退货率每降1个点，净利率能多0.3个点。

总结

卖家数量猛增，有人的地方就有竞争。[PRE5]

有实力的卖家一内卷，利润率被大环境压住，很正常。我不主张大家盲目铺摊子。有了一定体量后，先把各环节细节做到最优，把现有体量下的利润率提上去，硬实力才会更强。蓝海是相对的：硬实力越强，你在亚马逊看到的蓝海就越多，选择空间也越大。祝新老圈友利润率一路往上。
