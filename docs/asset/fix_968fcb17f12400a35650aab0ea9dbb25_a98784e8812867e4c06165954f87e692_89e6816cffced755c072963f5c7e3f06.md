# 3.3.3.1 找到爆款对标笔记

挑对标笔记的核心原则是「近期低粉爆款」。三个关键词缺一不可：爆款、近期、低粉。

优先级上，爆款＋近期 ＞ 低粉。也就是说，只要是最近刚爆起来的内容，哪怕账号粉丝量不低，只要产品对路，照样可以拿来模仿测试。

# 3.3.3.2 根据对标制作视频笔记

情况一：手上没有实物产品，就通过网络素材做二创混剪，重点注意素材去重。

❗想避免违规的话，尽量别从📕站内扒素材，特别是百货类目。📕上很多素材其实源头都在抖音，一来被反复用过的素材画质差；二来更容易被系统识别出重复。抖音找素材有3个办法：

1.  直接搜产品关键词，翻视频内容；

1.  进创意中心，找到爆品之后，页面最下方有“关联达人秀”；

1.  搜到某个带这款产品的博主后，点进主页看看有没有更多素材。

1.

混剪视频

1）搜集视频素材

从抖音或📕搜罗爆款视频做记录，格式一般是3:4或9:16；

2）混剪去重

去重手段主要有：换音频、做分割、加转场、插入画中画等剪辑操作。

详细的混剪去重方法，可以翻这份文档：《如何剪辑视频和制作剪辑模板》

2.

制作封面

视频封面主图直接拿爆款的封面来用，做一下图片去重就行。

3.

写标题

把5个对标视频的标题记下来，套用前面【章节3.3.2.2】讲的图文笔记爆款标题重组法，把标题写好。

更细致的视频剪辑方法，也可以参考【6月航海手册 - 3.2.4 第四步：进行混剪】

1.

先找同领域的爆款素材做记录，挑出自己能落地的拍摄方式，按1:1参考实拍。

3.

笔记做完就可以发布了。同样地，等测品跑出结果再去找供应商也不迟。

视频笔记制作要点：

4.

混剪一定要注意素材去重，搜集爆款素材做去重混剪时，最好拿5个以上爆款视频来混，单个素材反复用太多会被判违规；

5.

新手前期可以先从混剪入手，难度低；长远来看还是要落实拍，找到爆款对标笔记后，评估自己现有条件能不能做到1:1模仿，能的话就实拍；

单品类的混剪视频控制在5条以内，然后换其他款去测。如果混剪数据24小时低于200小眼睛，建议直接删笔记，免得后期被举报，这样后续还能继续测款。

# 3.3.5 笔记避坑指南

电商号的笔记尽量围绕产品来做，这样引来的流量才精准。行业知识科普、避坑类笔记也行，流量相对精准。跟产品无关的内容别往账号里塞，虽然流量可能大，但转化不了。

做电商要的是精准流量，能转化的才算精准流量，不能转化的流量搞再多也没意义。

有些笔记只有几百小眼睛，照样能出单，因为流量足够精准。

下面几个典型反面案例，供大家参考：

1）博眼球行为

什么叫博眼球？说白了就是严重的标题党。

市面上不少教人写种草标题的模板，举例：这张图，那种所谓吸睛标题，对做店铺的人来说真没啥营养。

[PRE21]

就像“朋友来我家吃饭，居然说我家很寒碜”，结果点进去菜品丰盛、屋子富丽堂皇。观众会觉得你在骗人，故意引他进来看你炫富，产生抵触心理，连带抵触这篇笔记。

再比如“sos，快来种草这个无广的国货！”，点进去一看，就是天天打广告的某护肤产品，观众会极度不适。

2）调性不统一，定位不明确

爆款标题模板、吸睛标题，要搞清楚适合什么样的内容。📕可以做店铺变现、引流变现、ip变现，但这三者别混为一谈。

很多人的情况是：有时发生活日常，有时发挂车笔记；封面有时是纯色底配大字，有时是自拍，有时是四宫格对比图，有时是平平无奇的产品图……什么封面形式都有，关键是封面还挺low，毫无美感。

3）价格跟受众人群不匹配

产品面向大学生群体，价格却高得离谱，你觉得会有人买吗？

文案写着原材料很贵，商品价格却压得很低，你觉得会有人信吗？

# 4.1 找供应商要考虑哪些因素？

挑合适的供应商，主要看这几点：

1.

单价

供应商报价和我们上架价格之间要有利润空间（30%以上）；如果进价太高，跟同行比没优势，可能影响转化。

2.

款式、产品质量

款式和质量方面，可以让商家拍图确认，或者自己买样回来检查产品质量，找到好货才方便长期合作。

3.

单量多是否可以走ERP

单量跑到100+的时候就可以走ERP系统，发货效率高，不用再导单出来二次下单。商家直接在ERP里看到我们的订单，直接打单发货省去中间环节，也能避免系统判定店铺无货源，还能打印📕面单。

我们一般用店管家关联供应商店铺ERP，这里展示一下关联步骤，方便理解：

（A店铺=供应商店铺，B店铺=我们自己的📕店铺）

第一步：先用店管家登录B店铺（子店铺）--->点击关联店铺--->复制关联代码

[PRE26]

第二步：让供应商登录店管家，打开A店铺的关联店铺--->立即关联--->选择关联平台--->粘贴复制的B店铺关联代码--->完成添加

[PRE27]

第三步：关联成功后，A店铺会显示B店铺的订单数量，供应商可以直接进行📕面单发货

[PRE28]

4.

是否可以走手工单，不走第三方电商平台面单

前期单量少的时候可以不搞ERP，但一定要跟商家确认能打手工单，避免被平台检测到无货源，保证店铺安全。

当然，咨询供应商之前可以先表明自己做📕电商、能长期合作，多聊几家店增加商家合作意愿，让供应商觉得你是能持续下单的人，而不是随便问问不买的。
