# 4.3 复盘：稳定币 UST 崩塌、Luna 百倍神话，创始人如何卷走 40 亿美元？ @可达 Koda

在加密市场的暴风眼中，稳定币 UST 的崩盘堪称一场教科书级的灾难。它曾是所谓的“算法稳定币”代表，标榜无需抵押任何现实资产就能维持 1:1 美元锚定。然而，这个看似天才的机制最终在市场的残酷检验下被瞬间击穿，URT 价格如瀑布般狂泻，直至归零。

与 UST 深度绑定的 Luna，曾是无数人眼中的“百倍币”奇迹，却在短短数日之内经历了从天堂到地狱的坠落。而就在这场席卷全球投资者的金融海啸中，Luna 的创始人却精准地完成了惊人的套利动作，据媒体报道，其获利高达 40 亿美元。

这是一场对“去中心化信仰”的冷嘲，也是一次对普通人财富的终极收割。当迷幻的收益叙事崩塌，留下来的只有对行业的深刻追问：所谓的算法稳定，究竟是一场协议愿景，还是一把精心设计的镰刀？

回顾整个事件，Luna 与 UST 的关系像一场“击鼓传花”——Luna 不断增发，为 UST 的需求背书；而 UST 的持有者越多，Luna 的币价就越显得“坚不可摧”。但这种互相支撑的循环恰恰为灾难埋下了伏笔。当市场信心稍微松动，抛售风潮便迅速滚成雪球，UST 的锚定在短短几天内彻底失效，Luna 也从辉煌的轨迹沦为几乎零价值的代币。

我们不应该忘记，那些随 UST 一同归零的，不只是代码和数字，还有许多普通人的全部积蓄与梦想。与此同时，创始团队通过提前洞察流动性危机，甚至敢于在自家币种暴跌途中大举变现——这种“赚认知之外的钱”的手腕，让整个事件显得更为冷酷。

Luna 与 UST 的落幕，是一面照妖镜。它提醒所有后来者：没有真实资产支撑的“稳定”，在极端行情下，和沙上之塔并无区别。所谓百倍币的光环，或许只是一个精心包装的陷阱；而伟大的叙事，抵不过一次真正的挤兑。

当潮水退去，才知道谁在裸泳。这场价值 400 亿美元灰飞烟灭的教训，注定会被反复提起，成为行业史中说无数次的警示。
