# TikTok 搜索词里，藏着哪些出海赚钱机会？

作者：三林  
日期：2022-04-11

关键词：Google流量研究、关键词挖掘、TikTok、SEO；全文约3000字，8分钟可读完~

大家好，我是三林，做互联网产品。上一篇聊过一个“资源套利”型下载站：靠SEO拉流量，再把人引到公众号做广告变现，切中的是国内用户想用谷歌浏览器插件、下载却不容易的痛点。那如果回到需求本身，我们该怎么找到类似的创业或生财机会？今天就围绕这个问题展开。

我把研究对象定在TikTok——出海产品里的热门选手，圈内不少朋友也正在这条赛道上做事。

核心思路是：以TikTok相关关键词为切入口，把Google搜索量作为判断依据——哪些词既有稳定的大搜索量，又有对应的产品或服务在承接需求。用户主动去搜的内容，通常就是真实需求。这样从大数据里发现产品机会、校准方向。

二、关键词挖掘的简易方法

2.1 什么是关键词流量研究？

从上面这些关键词流量部分能看出，工具型网页产品极其重视搜索引擎增长，通过SEO获取流量。我一直记得亦仁2017年写的经典文章《通过Google挖掘细分市场的一个案例》，第一步就是围绕巨头平台做搜索发现，探寻商业机会。当我们搜索一个词时，搜索框的联想推荐、其他人也在搜索的词，能无门槛地暴露需求，简单、快速；缺点也明显：不知道从哪个词入手，而且搜到的词可能不够全面、不具代表性。

在SEO领域，关键词研究被称为“关键词挖掘”。“关键词挖掘”是个系统性工程，对一个行业要挖出数百万个带搜索量的词才算合格，用时往往一个月左右。不过，我们可以借相关工具先简单、快速上手。

2.2 简单上手关键词挖掘

分享我的经验。第一步：框定母词。先基于研究对象：TikTok、YouTube或Tesla等，确定一系列母词。比如tiktok，我会选tiktok video、tiktok live、tiktok shop、tiktok fans等来圈定大范围。

接着第二步：拓词。通过“谷歌关键词规划师”等第三方工具，发现相关搜索词。

第三步：清洗，再度拓词。再次查询关键词流量。

第四步：对搜索结果二次分组，统计哪些“关键词”的流量具备代表性。

第五步：筛选有价值的关键词，并定向研究具体产品/服务承接。把它们收录进自己的“项目库”或“需求池”。充分调研、评估之后，再决定如何“杀”进去。这里先不展开。

3.5 关键词挖掘的技巧补充

关于母词，要多且准。母词数量建议在“四位数”：数千个母词，可以拓出数十万到百万个词。精准很关键，否则容易拓出不相干的结果，筛选成本会变高。比如“Tiktok”容易拓出一些大网红的名字，这些词在拓词时要先删掉。那从哪里找母词？分享三点：

1. 从目标网站挖掘：比如从网站首页、关于我们等页面提取关键词，比如slogan、描述、Metawords、底部导航菜单命名。描述业务的词，越全越好。

2. 找母词的角度：从自己所处行业开始头脑风暴，包括但不限于直接相关词、行业相关词、人群相关词。

3. 从广告投放词来用作关键词母词，也特别好。Ahrefs上线了一个新功能“付费关键词”，可以查询一个网站所投放的关键词，这个太强了。你想，人家愿意按点击付费购买的关键词，能不精准吗~下图以Shein举例：Ahrefs共收录了7.4万个关键词，可过滤导出进一步筛选。

四、总结

Google搜索大数据能直接反映用户的真实需求。关键词研究若想对一个行业做得更全面，需要更耐心地挖词、选词。我介绍的是通过工具快速上手的方式。围绕TikTok可以这样做，试试其他产品方向呢？比如据说最新估值1000亿美金的Shein，又有哪些周边机会可做？

平台在变，但用户需求有延续性。若能在新兴平台提前布局相关服务，不失为分到一杯羹。比如Instagram/YouTube下载站的经验，在TikTok上再来一遍。通过Google搜索平台做关键词研究，发现用户需求/产品机会，我称之为“生财机会”。

关键词研究很有意思：你会发现，居然有人在这样搜索一个词；当你去搜这些词，又会惊奇：我靠，居然还能这么做。关键词研究的运用场景很多，不止用于需求发现和SEO/SEM，还可用于内容生产维度参考、信息流投放、舆情监控、KOL挖掘等。

试试看，期待你的“我靠，绝了！”。当你哪怕找准了一个好关键词，我想，这一定是个伟大事业的开端。
