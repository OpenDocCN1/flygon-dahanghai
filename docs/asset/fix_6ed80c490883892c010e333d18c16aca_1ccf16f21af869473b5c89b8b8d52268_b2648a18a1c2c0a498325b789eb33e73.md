# 十、资产安全与投资理念🔥@可达 Koda @温格区块链

一个行业往往从无序走向有序，再回到无序，这是事物运行的规律。

Web3早期同样混乱。这个行业离钱近，监管却没及时跟上，一度作恶几乎没有成本。全球每天都有大量盗窃和诈骗发生。

# 10.1 为什么资产安全是底线

据《区块链日报》记者不完全统计，截至2022年，仅交易所就发生了28起比特币被盗事件，损失高达120万枚比特币。按比特币2万美元计算，被盗金额超过240亿美元。这还没算个人钱包被盗。

[PRE1]

除了被盗，管理不当造成的遗失也很致命。

区块链分析公司Chainalysis在2020年的报告里提到，至少有370万枚BTC五年以上没被触碰。加密数据公司Glassnode估计，约300万枚比特币会永久丢失（可延伸读《加密交易所历年被盗情况：超120万枚比特币、530亿美元被盗》）。

丢失原因包括忘了钱包私钥，或者私钥的物理载体损坏、遗失，导致资产永远找不回，变成沉默资产。

Web3历史上，每隔一段时间就会爆出大型黑客盗窃事件，比如门头沟事件、以太坊DAO硬分叉事件。

我身边不少人因为操作不规范或一时失误被盗，损失少的几千上万，多的几千万。

如果把资产看成“10000”这串数字，安全就是最前面的“1”。没有安全兜底的投资，最后可能竹篮打水一场空。

我常举一个例子：有位老板在低价时囤了几十个比特币，囤了好几年。去年比特币涨到6万美金，约40多万人民币一枚，但他把助记词放在线上笔记里，资产全部丢失。几千万瞬间归零，非常可惜。

这一节，我们就一起学习如何尽量避开Web3资产风险，降低损失概率。

# 🏆10.2 去中心化钱包的安全防线

开始前，先弄懂诈骗和盗窃的原理。前面学过：Web3资产由私钥掌控，别人想盗你的资产，最终都要绕到私钥上。

目前围绕私钥作案，主要有两种方式：

1. 骗走你的私钥

比如把助记词存在线上记事本，或者手机、电脑中了病毒，都可能让私钥信息泄露。

记住：私钥和助记词，不会有任何项目方来向你要。

私钥和助记词，相当于银行卡号+银行卡密码+身份验证信息。别人拿到后，就能不经你同意转走资产。

还有一种话术：让你把私钥导入某个网站去“打新”，操作一结束，钱被取空，资产也被挪到新钱包。

2. 通过智能合约，诱导你授权给对方私钥使用权

这种方式是让你在钱包里稀里糊涂点授权，对方拿到私钥使用权后，把资产全部转走。

不要随便点开地址，尤其是不认识的人发来的。哪怕是熟人发的，也要去官网交叉确认。

基于这些，记住五条去中心化钱包安全心法：

任何时候，保护好自己的钱包密钥、助记词，坚决不让它们触网（不要放桌面、Excel、飞书、印象笔记等）。

不明链接不点、不随意连接钱包，不贪小便宜，牢记天上不会掉馅饼。

对Discord、Twitter、Telegram上的私信高度警惕，里面的链接大多是诈骗。

不要让自己陷入信息孤岛，遇到问题第一时间找身边朋友、社群求助。

主要钱包的物理助记词，记得备份保存。

# 第一条：只从官网下载

Web3应用，一定要去官网下载。

你可能会觉得这是废话，但我身边从去年到今年就有好几个人因为没去官网下载被盗。

举个例子：

去年8月的一天，社群一位学员给我发消息，说他三个钱包从没领过空投，也没授权过任何应用，怎么8月5日无缘无故被盗走15个ETH和0.1个BTC（当时约34万人民币），问我原因。

我说，会不会是你之前把私钥或助记词截图存在相册，或者在社交工具里传过私钥、助记词？

他说不可能。自从上次丢了以太坊（上次是把钱包导入一个很偏的小钱包，后来被盗），他就很小心，还专门下载了一个新钱包存资产。

我也觉得奇怪，就让他把被盗钱包的转出地址发来。总共两个以太坊地址和一个比特币地址。我打开以太坊浏览器查看，发现基本都在8月5日这天有多次转入，随后骗子把转入资产全部通过Uniswap换成以太坊。两个地址分别有134个ETH和96个ETH，另一个比特币地址里的资产已经全部转走。

如果钱包没问题、没做过授权、私钥助记词也没泄露，那怎么可能无故被盗？我当时也困惑，就建议他把情况发给imToken客服，看看怎么说。

邮件回复后，真相大白。

原因是他用了第三方渠道下载的imToken App。邮件发来时他才想起来，6月份确实重新下载过一次imToken，当时是在非小号上下载的。

后来我建议他报警（虽然我知道追回概率很小，还是让他试试）。他去了，结果不出所料，当地警方不接，也不立案。

# 第二条：分散存放，先把风控放前面

这一条，圈里人基本都知道。11月最大的事件，就是全球排名前三的交易所FTX暴雷。原因有多方面，核心是创始人SBF挪用用户资金。

事情最初被曝光，是因为Coindesk一篇文章分析了FTX和Alameda的资产负债表异常，于是“大厦将倾”的前奏开始了。后来全球第一大所币安创始人CZ知道后，发推说要卖掉持有的全部FTT规避风险。

本来就有问题的FTX，在CZ发推后市场更恐慌。FTT两天从20美元跌到2美元。中间还有不少波折，这里不细说。

这个过程中，风控意识强的人一听到消息就提币了；风控差或反应慢的，可能就被埋了。我自己也是被埋的一个。当时大意，因为里面只剩不到1000美元的山寨币资产，没放心上。等我觉得不妙时，已经来不及，不能提币了。

当初在FTX打新赚了小几十万，觉得交易所不错，倒的概率小；

当初几美元买的FTT也赚了，觉得交易所不错，倒的概率小；

这是美国两党都爱护有加的交易所，怎么可能倒（创始人给两党捐了不少钱）。

……
