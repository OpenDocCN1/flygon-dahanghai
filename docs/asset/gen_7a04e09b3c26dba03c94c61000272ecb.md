# 小红书操盘手记：选品、选题与定位

做小红书，别急着日更。先把两件事想明白：能不能赚钱，成本划不划算。很多动作一旦用这两把尺子量过，方向会清楚很多。

先说选品。红海品类未必没有机会。拿T恤来说，竞争已经很激烈，但有一篇笔记拿到了4000多个精准询单，完全符合高质内容笔记的标准。

[PRE0]

拆它的文案和产品，结论很直接：询单量大，靠的就是高克重、专属定制这两个卖点。市场在急切寻找这样一款T恤，所以刷同类笔记时，也可以反向发现一些值得做的产品。

接着要算内容制作成本。做矩阵号，必须把每篇内容的生产成本量化，心里有本清楚的账。找赚钱笔记的过程，本质上也在对比成本。专业布景、玩味文案、讲究的图片构图，通常对应高成本；但高成本一定带来高询单吗？未必。前面提到的瑜伽裤就是鲜明案例，内容成本不到20块钱一篇。小红书也好，抖音也罢，低成本高产出的经典案例并不少见，这正是内容营销的魅力。

#### 4.2.2.3 要素三：强化代入感 @梨云

刷小红书时，我看到十万赞大爆款《公主学习法》。虽然觉得有点low，但敏锐的觉察力告诉我：这篇不简单。看完内容，我真的像体验了一把当公主的感觉；再看评论区，一片好评。目测这是一个爆款选题。

我立马以此为选题写了一篇，爆了，将近10w点赞。学习娱乐化，知识趣味化。如果假设成立，我就能开辟一条新的细分赛道，成为唯一。说干就干，我从评论区分析粉丝感兴趣的角色，再进行创作，发一些极具创意的学习法试水。结果篇篇原创，篇篇爆款。于是我开始在比例上加大这种被娱乐化包装的学习方法，内容高度垂直统一，主页转粉率接近30%。

[PRE2]

这种垂直又爆款的内容，还引起了小红书官方注意，直接为我在灵感笔记里单独开辟出话题咖位。

从模仿到原创，依然篇篇爆款，我做对了什么？

一是以人为本，和粉丝深度链接，了解他们的痛点，关注他们的需求。二是提供价值，内容要能解决粉丝的问题，要么是实用方法论，要么是情绪愉悦感，或者像我这样两者兼备。三是主动学习，了解粉丝需求时会遇到很多闻所未闻的东西，比如他们喜欢的耽美、凹凸世界，这就倒逼自己主动学习，才能产出粉丝喜闻乐见的内容。四是长期主义，站在粉丝需求角度用心输出每一篇内容，踏踏实实做内容，同时不断输入输出、精耕细作。因为一事精致，便已动人。

内容来源：《小红书三个月涨粉 17w，变现 10w+，我做对什么？》

找关键词，素材给了3种方法，先看两种能直接上手的。

方法1：在小红书搜索框输入关键词，找到下拉词。比如输入【女频言情小说推荐】，会出现【女强言情小说推荐】、【女生言情小说推荐】等下拉词，这些词都可以用于标题和正文。

[PRE4]

方法2：点开一篇高赞笔记，看它的标题和正文，测试哪些词是关键词。

[PRE5]

以一篇笔记为例，我推测【真的好绝】、【超级喜欢】、【甜文】、【双向奔赴】、【可冲】等词是关键词。

关键词怎么用？先把推荐这篇小说的理由写出来，再把收集到的关键词放到内容合适的位置。比如选一本《XX（书名）》言情小说做推荐，我看过也很喜欢，标题和正文可以这样写。

第一稿标题：推荐一本女主言情争霸小说！！！正文写：今天看了一本很好看的言情小说，已经完结了。这本书讲女主穿越到异世界，带着金手指大杀四方。女主本身很有魅力，不只是金手指的作用。以前看过类似小说，女主拿到金手指后偏向宅斗、宫斗，或者辅助男主成为天下霸主；这本完全不一样，女主没有被古代同化，自己拿着金手指争霸天下，为百姓带去幸福生活，而且一点也不违和，非常符合常理。男主男配们很有魅力，感情戏也好看。

第二稿标题：N刷！！巨好看的言情小说，绝对不能错过（注意：小红书笔记最多20字，16—18字为佳）。正文中加入“已经完结了，真的好绝，我超级喜欢”“可冲”等表达。

两稿的区别在哪？我把「n刷、真的好绝、超级喜欢、可冲」等关键词放进了标题和正文。靠这个方法，我经历过一篇笔记1小时100赞，24小时千赞。如果一篇笔记1小时能到100赞，那么24小时后能千赞。当然，这不是百试百灵，也要看推荐的小说是否符合自己的定位、是否符合读者口味。有时我的笔记几天后到千赞，有时只有几百赞，但这个方法能提高点赞概率。比如发100篇笔记，用这个方法，千赞笔记占20%，几百赞笔记占50%，几十个赞笔记占30%（这个概率不准确，是我根据自己的笔记粗略算的；但做过小红书就知道，这个效率很高）。

为什么关键词法能让笔记如虎添翼？看案例就知道，内容很简单，就是把小说亮点突出来了。有时我偷懒，直接取个标题，正文写“已完结、超级好看”就发出去，依旧有几十赞、几百赞。为什么？因为我推荐的小说好看、本身有价值，读者容易点赞。但做学习博主不一样，必须提供有价值的内容，再用关键词法撬动流量，读者才会点赞。

内容来源：《手把手教你如何成为小红书小说博主》

#### 4.2.2.5 要素五：技巧合集 @吴小二

第一个技巧：把资料拆分。一份资料可以拆成多份，甚至强行拆成5份，编号a、b、c、d、e，然后让评论区留下喜欢的编号。这样评论区就热闹起来了。

第二个技巧：回复最初的几个评论。对最开始的几个或几十个评论，每个都回“已发，祝顺利”之类的话，比较礼貌的用户还会回一句“谢谢”。这样既能增加发资料的真实性，加热阶段的评论量也上来了。每天上千条评论不可能全回，加热阶段回复就行，不然手指头要痛。

第三个技巧：把最热门的编号当成封面。前面两步之后，每个帖子至少有5张图片。发第二个帖子时，把第一个帖子中留言最多的编号当成封面。可以理解为：第一个帖子在测试5个资料哪个更受欢迎，第二个帖子就把多的那个放到第一张。一次发一个，要发5次才知道哪个火；一次发五个，评论区能帮你筛选，其他喜欢少的也能增加帖子热度。这样循环起来，爆贴概率大大增加。我有一个编号封面，让几个人看都觉得丑，但数据就是奇怪地好，连着发三次都是千评以上。要相信数据的力量，评论多的就反复当封面发。

第四个技巧：巧用搜索联想词。在小红书搜索框输入关键字，会自动跳出联想词。把这些联想词放进内容和标题，甚至用关键词当昵称，能增加很大一部分流量。这个技巧手册里提过，但很多人不够重视，所以再提一次。

### 4.3.3 制作可批量制作内容的模板 @梨云

一个优秀的内容模板，既能帮我们批量生产内容，也能带来不错的数据。@梨云 发挥平面设计专业优势，原创了一套模板，思路如下。模板构成的要素无非几个，每个都迭代即可。

1）配色：选森系绿，因为太多人一看到这个配色排版就想起我，我干脆取名“梨云绿”抢占心智；再搭配阳光暖黄和纯白色，给人一种温馨、岁月静好的感觉。

2）封面：用简单粗暴的大字报排版，以两行字突出标题重点，聚焦关键词，让用户一眼知道这篇笔记讲什么，快速做出点击选择。

3）内页：取消之前对标博主“封面+文案排版”的形式，改成全图流。靠文字排版，结构感还是差一点，容易视觉疲劳；全图流可以改字体颜色、加贴纸图案，操作空间大。我采用大标题、导语、小标题、内容、底部标题的排版。大标题可以概括本页内容，给读者预判信息，也可以每页统一，用来埋关键词、提高检索权重，它还是重要广告位，写品牌名字的地方。导语负责铺垫，写下出这篇笔记的原因，承担一部分共鸣作用，同时做行为设计，比如我会说“宝子投稿”，暗示大家积极在评论区投稿，用留言数拉动曝光增长。小标题用四个字压缩一句话，概括内容，减轻阅读负担。内容一般不超过3行，做轻内容，提升阅读愉悦感；行文时用平台女生喜欢的爆款流行语、最近火热的梗，让内容灵动活泼。底部标题是很重要的细节，很多人模仿我时忽略了。它的作用是用游戏化口吻引导对方翻页，减少读者因为对当前页不感兴趣而退出。形式借鉴游戏里的指令性表达，句式为“开始+动词、马上+动词”，特别好用，给人一种想不停往下翻的冲动。只要内容没问题，阅读时长有了，赞藏评概率也会大大提升。

# 五、持续优化账号&内容

## 5.1 持续优化完善个人定位

做定位，从来不是一步到位。V先生有句话大意是：定位是“1”，其他事情都是后面的“0”。随手写也有复利，但写一段时间会发现难赚钱，慢慢就没信心继续写了。所以做小红书，核心一定要做一个赚钱的账号，否则大概率会半途而废。而做一个账号最重要的前提，是做一个赚钱的定位；定位决定了账号变现能力的强弱。前期要把40%的精力放在定位上，其次才是选题、内容、引流。

[PRE25]

要做一个赚钱的小红书账号，先明确两个核心原则：1、痛点 >> 痒点。有多种定位选项时，能解决痛点需求，就不要选痒点需求。因为大多数人在痛点上消费毫不手软，在痒点上却“唯唯诺诺”。比如职场领域，大学生群体最痛的点是什么？如何快速找到好工作？找到工作是核心需求，但里面包含太多细分需求，比如简历优化、面试指导、入职体检、能力培训等。相对体检、培训，大学生更愿意为简历优化和面试指导付费。众多需求中，要专注用户更愿意付费的痛点需求，吃透它，建立信任最快，离钱最近。2、帮助别人赚钱 >> 帮助别人成长。成年人进入社会后，不再是个学生，单纯的学习成长重要性会降低，赚钱成了最重要的事。如果你靠技能赚到钱、做项目赚到钱、做自媒体变现，有赚钱相关经历，最好的定位是帮助别人赚钱，而不是帮助别人成长。定位时最好明确这两个原则，尽量选痛点 >> 痒点、赚钱 >> 成长。脱离基本原则，就不能击中用户最痛的点和需求，建立信任慢，变现路径也长。注：以上两条针对新人，而非领域专家。任何一个领域，只要你成了专家，都不愁赚钱。
