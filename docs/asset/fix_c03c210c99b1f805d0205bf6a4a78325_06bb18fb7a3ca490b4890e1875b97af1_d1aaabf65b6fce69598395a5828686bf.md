# 非洲外贸：普通人的机会在哪？

欧美市场竞争越来越挤，非洲生意却对个人履历没那么挑，对想找出路的人来说，确实值得多看一眼。但多数人一提到非洲，还是觉得陌生：到底什么货走得动？和当地商人怎么建立关系？跟熟悉的欧美业务又差在哪？本期专栏请来一位长期驻扎非洲多国、做过肉类与快消品进口，也操盘过机械、轮胎、空调、化肥等出口的嘉宾，重点讲讲选品这件事。欢迎分享。

---正文---

感谢鱼丸给我这个机会，在生财有术和大家交流。我在非洲多个国家待过，也实际做过不少品类的国际贸易，希望这次分享能起到抛砖引玉的作用，认识更多对非洲市场感兴趣的朋友，一起学习、寻找合作空间。

一、非洲生意的优势在哪

非洲不看重你是不是名校出身、背景多漂亮。当地年轻人口多，接受新事物的意愿强。只要人勤快，平台、商业模式、货品和搭档选得合适，盈利难度相对会小一些。开发客户时，精准地扩大接触面，再靠口碑发酵，往往比较管用。非洲不少产品天然、污染少，价格也有谈的空间；同时国家鼓励进口非洲的优质商品。因此不管做进口还是出口，都有可借力的地方。

二、做非洲生意要防哪些坑

机会多，但市场不够规范，骗子也要防。安全、疾病、汇率、信用、物流以及所在国政局，都是要提前考虑的风险。第一次过去，最好有非常信得过的人带路；如果没有，就尽量选择知名度较高、评价较好、手续正规的企业作为依托，签证流程也要合规。出门随身带些零钱，护照原件务必收好。起步阶段最好从自己熟悉的行业切入，因为专业感是建立信任的第一步。做实货贸易，优先考虑外汇兑换方便、环境相对稳定的地方：南非大部分区域（约翰内斯堡个别地方除外）、博茨瓦纳、纳米比亚；西非的科特迪瓦、加纳、喀麦隆；东非的卢旺达、肯尼亚、坦桑尼亚等。电商环境较好的有南非、肯尼亚和埃及。安哥拉、莫桑比克这类葡语国家换汇难度偏高；苏丹、津巴布韦受西方制裁，小规模实货起步会更吃力。治安方面，西非和中非的乍得、马里、布基纳法索，东非的索马里、埃塞俄比亚提格雷州，南部非洲的莫桑比克北部，目前都不太理想；各国疫情状况也要持续留意。

三、进口货品怎么挑

做贸易要盯紧汇率。眼下汇率走势对进口有利，所以先讲进口选品；等体量起来，进出口可以并行，用汇率形成对冲。

1. 农产品进口怎么选

非洲农产品和水果很看重时效，核心是打国内反季节销售。比如卢旺达、埃塞俄比亚、乌干达的咖啡（不少日本品牌咖啡其实源自埃塞俄比亚），卢旺达的辣椒，贝宁、埃塞俄比亚、坦桑尼亚的大豆，南非的鲜葡萄、苹果、柠檬、葡萄柚、橙、柑橘等水果，南非的苜蓿草，肯尼亚的冷冻牛油果，尼日利亚、莫桑比克、坦桑尼亚、苏丹的芝麻，马达加斯加的丁香等。

拿非洲大豆举例：先上海关网站查该国农产品商家的准入名录（名单里的“商家”不一定是工厂，也可能是经销方）。能进入名录，一般已经过海关（原质量检验检疫总局）审核，具备初步信用；名单上会有联系人邮箱，可以逐个发正式询价邮件，比较之后挑回复专业、正规的商家继续谈。通过邮箱和公司名，也能找到企业网站，最好先索要样品。如果当地有可信的朋友（尤其是业内或律师朋友），尽量实地看一看。对对方不熟时，付款优先选不可转让信用证，尽量少用电汇；合同里要约定当地验货标准、包装方式以及违约条款；请当地朋友协助监装、发运，并要求供货方提供SGS等权威第三方验货报告，及时交付提单、原产地证等材料。

询价反馈快不快很关键。以坦桑尼亚大豆为例，那时当地只有一家大豆商家拿到准入；从名单中的外方邮箱找到商家网站，发现网站法文内容不少、在法国也有公司，于是通过坦桑尼亚的法国朋友第一时间联系上对方，拿到了大豆报价。报价到手后要留意有效期（通常几天到几周）、付款方式（信用证）、包装和运输方式（集装箱）。国内买家要找用过非洲非转基因大豆的客户，起步阶段尽量让客户自己负责清关。

2. 冷冻肉类进口怎么选

冷冻肉分牛肉、猪肉、鸡肉。非洲目前只有南非和纳米比亚有厂家拿到冷冻牛肉输华许可，量并不大。冷冻牛肉和鸡肉（主要是冻鸡爪、冻鸡翅）近期多来自南美洲（巴西、阿根廷、乌拉圭、玻利维亚）以及俄罗斯等独联体国家。

以冷冻猪肉为例：曾通过非洲认识的朋友联系到拿到准入的欧洲商家，先签买卖合同，把各时间点和违约责任定清楚，买家支付一定比例定金，外方备货并安排发运。发运后，外方先把提单和全套清关文件草本的扫描件发来，审核无误后买家付尾款，外方再快递文件正本，集装箱到港后由客户自行清关。前后成功进口过数百吨，也建立了稳定合作关系。肉类贸易本身不算难，关键在合作方靠谱，再根据国内客户需求拟好对内对外合同，尽量选畅销部位肉（留意带骨带皮），盯住价格变化，认真审核所有单据，避免到港清关被耽误。

目前南美的冷冻鸡爪和冷冻牛肉有一定性价比，但肉类价格波动大，南美国家政策也常变（阿根廷曾暂停牛肉出口一个月），品质和数量参差不齐，还出现过厂家把同一票货卖给多个买家的情况；国内港口也普遍有冻柜滞留、消杀环节增加的问题。所以起步期先和有经验的买家合作，把风险控制住。等实力上来，可逐步介入冷库等存储、加工环节，拓展自营销售渠道，尤其在综合保税区内对农产品和肉类做初加工；价格变化时，可以存储或借助供应链金融等待升值再卖，也可以直接深加工、分装（大包装改小包装）来增值；猪肉已有期货，可考虑与现货对冲。

3. 快消品进口怎么选

欧洲、非洲有一些知名母婴用品、高端服装、家居用品在找国内代理商，关键看你熟悉哪些销售渠道。以母婴用品中的纸尿裤为例：先和国外厂家谈下国内代理权（最好是独家）；再通过专业进口代理公司弄清清关流程和中文标签要求（标签不合规，会很耽误事）。如果这个产品此前没在国内卖过，要让外方先发足够样品，提前到海关指定的危险品中心实验室取得检验报告，合格后才能顺利清关。欧洲产品的规格和相关标准与国内略有差异，标签中要写明白。

四、出口如何找客户、定品类

做出口，选好产品和合作伙伴很重要，收款时要注意货款来源正规、清晰。做实货贸易，第一次见面很关键。每次接触前，我都会通过朋友或网络做足功课，根据客户关注点准备介绍材料或特色小礼物；交谈时从对方感兴趣的事，或对方眼下业务的难点切入，让对方快速看到双方互补性和合作可能，小礼物也能加深记忆。初步信任建立后，靠积极快速的响应和一个个小项目累积，后来对方一些集成采购业务也交给了我的团队。另一个经验是已售产品的后续配件服务，比如发电机配件、水泵配件、车辆配件（轮胎等）、矿用机械配件等。能解决客户急需的问题，关系会更深。比如不少非洲国家疫情严重，不只缺防疫物资，更缺医用注射器、疫苗冷藏箱、储药冰柜；同时当地家庭普遍喜欢音响、游戏机等。农业和安防领域，支持当地语言的无人机、高清摄像头都有广阔市场。日常用品里，除了假发，煤气罐及配件、蚊帐、驱蚊产品在网上营销效果也不错。盲盒、手机游戏、手机音乐、手机叫车（除优步外，尼日利亚、肯尼亚、安哥拉都有国人在做）在非洲应该有不错前景。

要扩大已有外国客户的采购量，先把售后服务做好，保证买方问题能及时解决，树立口碑，这主要靠当地合作伙伴；也可以请非洲本土明星做平面广告（如车身、机场、公路主干道、大型建筑）。疫情期间出国不便，扩大贸易规模要善用金融工具。这里重点说中国出口信用保险公司（国内唯一政策性出口信用保险机构，不是商业保险公司）的特险服务，中信保也能协助审核外国客户资信。特险本质是卖方允许外国买方在1—2年内分期付款，但通过投保出口信用保险来保障及时收款；南部、西部非洲银行贷款利息普遍高于15%，所以外国买方往往愿意承担保费来换取分期付款。卖方拿到保单后，可凭保单在国内商业银行做债权买断，相当于银行在货物发运后先把后续分期款垫付给卖方，之后外方分期还给国内银行，一旦逾期，出口信用保险公司会代为追讨。除信保外，一些商业银行、保理公司也推出进出口贸易资金池、循环授信等业务，前提是外国买方足够优质（财务报表较好、负债率低、有一定行业知名度）并积极配合。但优质客户并不容易找，因此可以考虑与在非洲有业务的欧洲、中东客户合作：在安哥拉、莫桑比克等葡语国家做贸易，可找葡萄牙人合作；在科特迪瓦、喀麦隆等法语国家，可找法国人合作。还要算国内与非洲的利息差、汇率差：南部和西部非洲银行利息年化普遍高于15%，汇率波动也大；国内贷款利息4—6%，欧元、美元贷款利息不高于3%，合作空间很大。

一时去不了非洲，电商平台是很好的切入点：阿里巴巴国际站、虾皮（重点东南亚）、京东出海（印尼、泰国站）、阿联酋NOON、非洲KILIMALL（肯尼亚）、JUMIA（尼日利亚&肯尼亚）、Takealot（南非）、Zando（南非）、Tospino（加纳）等；不少非洲电商平台对中国商家免费开放入驻。这些我也还在学习和摸索，之前在生财看到有人通过虾皮往东南亚卖小金龟，很受启发；利用好时机、选准细分领域很重要，希望大家多交流、抱团发展，电商贸易和实体贸易融合创新会很有前景。评论区也有读者提到旧鞋出口非洲、后来在埃塞建厂，以及TikTok自媒体和Facebook营销值得关注；嘉宾回应可在非洲明星脸书投广告或做隐形带货。

五、潜力代理与合作方怎么找

非洲谈生意比国内简单直接，但可持续性偏弱，所以要不断开发新的优质客户，找到成长型代理商很关键。这需要勤奋地扩大接触面，也讲一点缘分；找准、找好、共同发展，才能获得长远收益。道理有点像知名咨询公司更愿意培养有潜质的优秀毕业生，而不是靠猎头挖人。国内一家知名白电企业的非洲负责人曾分享：初进非洲时，冰箱、电视机等市场由日韩和欧美品牌主导，当地不认可中国品牌，只能联系那些不受日韩品牌重视的当地代理商（尤其是有良好教育背景的年轻代理商），或者日韩品牌代理商中被边缘化的经理人；通过更好的合作态度、更贴近客户需求的产品改良（当然还有更好的价格和售后服务）赢得这批代理商支持，再配合适当广告宣传，逐步扩大知名度，之后合资设立组装厂、发展工业园区，渐渐成长为在非洲知名度靠前的白电品牌，海外销售额占集团总销售额30%—50%。合作期间多留意伙伴需求，提出共赢建议。比如合作伙伴参与当地电站/医院建设及设备供货，可以尝试洽商共同参与电站/医院运营，参与耗材和用品供应。手机里的传音在这方面也做得很好。

六、非洲市场未来怎么看

在非洲创办企业并不难，很多模糊地带可以人情化处理。过去传统贸易主要靠不停跑客户，客户下单后安排发货，到港后跑清关，不厌其烦地沟通、解决各种问题，满足客户五花八门的要求，逐步筛选出互相信任、共同成长的重点客户。其实适应语言、文化习惯差异，克服安全、疾病等问题后，把前期工作做扎实、合作对象选好，剩下的低买高卖并不复杂。但眼下的非洲疫情态势和科技日新月异的发展，让过去的经验已不完全适用。未来应该是电商平台与实体贸易结合，增加产品附加值，打造差异化的非洲品牌。进口方面，可多个伙伴合作批量采购、分散出货、加工增值；出口方面，利用电商平台开拓新客户，并运用各种金融工具做大与优质客户的贸易额，在细分领域做出名气。南非、埃及等经济较好的国家有不少支持创业的基金，在非洲上市也可望可及。期待生财有术非洲创富群。
