# 6.3 增长乏力时，先回到用户身上

产品迈入平稳阶段，甚至走到下滑段，诱因未必单一：市场环境可能变了，用户也可能已经不是原来那批人。此时更该瞄准的，是第二轮用户扩张，或新的收入增长点。也就是说，重心要再次落回用户，摸清他们此刻究竟需要什么。

我负责的桌面产品曾跑出过一条非线性的增长曲线。复盘后发现，关键在于当时那批目标用户仍有需求未被满足，而我们可以借助有别于常规的运营和推广方式，把这部分用户争取过来。

但我自己做的小App，多数已经进入平稳阶段，或者开始下滑。平稳阶段的需求相对稳定，服务、推广也跟得上，所以我会继续维护。

至于下滑阶段的App，原本就是短期回报逻辑，再重投入只会变成负担：留着没多大滋味，舍弃也不用心疼。
