# 3.2.3.1 不到千粉，小店靠📕引来客源

作者：@怡伶 78667 @Nico 酱

从去年10月开始经营艺术体验门店，我的📕个人号至今只有700个关注，询单集中爆发时甚至不到500粉。但门店约九成客源由📕带来，其中还有客单价1万、2万以上的企业订单。

我的成交路径不复杂：用📕等公域平台把人引到🛰️，对方预约后到店体验并成交。📕上来的客户大多意图明确，几乎来一个成一个。私域我投入不多，朋友圈也发得少。

赚钱里关于账号注册、定位、主页搭建、私域运营的分享已经很多，我不重复。这里更想讲我对📕内容种草获客的复盘，包括跑通过的方法和踩过的坑。

把主营项目调整为Tufting后，我重点发了两类种草笔记：

- 个人引流名片
- 案例作品种草

两类内容都提升了账号和门店曝光，也带来了不少精准成交客户，属于转化效果较好的笔记。实战营同学测试后基本都有反馈，很多类目都能借鉴。

**引流方法一：把个人名片笔记置顶**

置顶个人名片是我写的第一篇Tufting笔记，也是带来询单和预约最多的一篇。在📕搜“上海 Tufting”或“Tufting 上海”，这篇大多能出现在前十名（不同人搜索结果会有差异）。这类名片笔记很适合把自家产品或服务软性带出来。我拆成“笔记类型”和“写作技巧”两部分。

从类型看，引流名片常见三种：故事经历型、硬广介绍型、伪真实体验型。

故事经历型：做自我介绍、讲个人经历，但不要写成流水账，要把重点放在工作部分，方便自然带出产品和服务；在不直接导流的情况下，让用户知道“在我这里能买到XXX”：

[PRE1]

真实体验型：我最初写得偏硬广，后来改成常见探店笔记的样子，置顶在主页面，连门店地址直接放上去也没有被系统判定为导流违规。有门店的可以试试这种伪探店口吻；没有门店，也可以模仿普通用户的体验口吻，有时系统确实识别不出广告，效果很好用：

[PRE2]

硬广介绍型：直接说明自己是谁、提供什么产品或服务、流程和理念是什么，整体更硬广。它更适合企业号；个人号如果拿捏不好，容易触发违规：

[PRE3]

这三种可以按自己的情况测试，并长期置顶在主页（发满20篇笔记可解锁置顶功能）。我那篇笔记的互动都来自自然流量，所以下方询单较多。若前期互动不足，可以人工做冷启动，把“怎么联系”“怎么预约”“店在哪”等咨询型评论错开布局，效果不错。新用户进主页第一眼会看到自我介绍和下方评论，有需求自然来问：

[PRE4]

写作技巧落在图片和文字上：图片与工作、产品或服务相关即可，最好真人出镜；不想露脸，侧脸或真实工作场景出镜也行。文字不用炫技，大白话、聊天感最有效，越接地气，📕用户的防备心越低，越愿意来问。

**引流方法二：用案例作品做种草笔记**

做定制、客定、设计类商家IP，很难不用客户作品做种草。比如我要发客户的Tufting成品，才能吸引对这类体验感兴趣的人。但这里有两个坑：

- 案例作品容易写成干巴巴的硬广，个人号效果会打折；
- 爆款种草多是素人体验口吻，商家总不能一直说“这是我亲自体验的”，角色切换有难度。

我看了不少做得好的企业号和商家个人号，再结合自己的实战，觉得可以这样解决：

第一，大大方方承认自己是老板，从老板视角讲客户到店体验的过程、展示客户作品；也可以设定成公司或工作室员工的人设。比如我有一篇就是老板视角，赞藏不算突出，但评论和私信询单不少：

[PRE5]

再比如小浔溪那篇，用的是踢脚线工厂打工妹角色，既爆又精准：

[PRE6]

第二，不管老板还是员工视角，口吻都要像聊天，像街坊邻居唠嗑。文字别太长，语气可以俏皮一点。感受一下两种写法：

- 生硬种草：冬日上新 这款实木餐桌真的很值得买买买
- 聊天种草：客户全家都夸爆的实木餐桌！姐妹们快给我冲！

口吻真的很关键。即便你明说自己是企业、老板，只要够接地气，用户通常不会太反感，反而可能因为你“可爱”“真实”“坦率”而对产品产生兴趣。

另外几种📕引流方式也可以参考：

引流方法三：在个性签名里留🧣，做跳转引流。

引流方法四：评论区剧本式引流。比如我发过一篇美业门店资料笔记，安排几个小号在评论区回复“求分享”“求完整电子版”等话术，营造从众感。

引流方法五：私信自动回复引流。相同内容不能超过3次，需要提前准备带联系方式的图片。

引流方法六：笔记收藏式引流。用小号发带联系方式的笔记，再用大号收藏，别人查看大号信息时就能看到联系方式。

引流方法七：把📕名字设置成🛰️号引流。这是所有方法里效率最高的一种，客户咨询时直接回复“看我名字”。

1. 首图

用户第一眼看到的就是首图，前期必须认真打磨。我观察下来，📕爆款首图要么美好精致，要么真实接地气，主要看类目和IP人设。我的产品偏网红时尚，好看精致更圈粉，所以每张图都会处理美化：

2. 关键词

关键词选得准，效果真的称得上YYDS。下面这套方法也适用于其他平台，逻辑差不多。

先挖掘行业里高流量的产品关键词。在📕搜索“画画”这类关键词，图中画圈位置会出现很多相关词，从中挑适合的加进日常文案；继续往下滑，还会出现更多细分关键词，也可以参考：

再去同行对标账号里收集，把爆款文案中的关键词记下来：

[PRE10]

还要看企业号的关键词投放、买量和搜索情况。这个专属功能挺实用，我刚升级企业号，后续有新的经验再分享。

词收集完就可以铺。我通常会在标题、正文、末尾都放关键词，尤其是本地关键词（比如上海 Tufting）。起号阶段最好泛词+精准词组合使用。泛词是更大众人群的热词，比如探店、上海探店、周末探店；精准词对应产品细分，比如Tufting、上海Tufting、戳戳绣。我刚开始只放精准词，流量一般；加上泛词获得更强曝光后，整体效果就不一样了。当然，前提还是笔记内容得吸引人。这个玩法在大众点评也吃香，做大众点评的老板可以试试把店铺名+团购都加上关键词。
