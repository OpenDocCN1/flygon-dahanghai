# 独立开发者：周末做出 MVP

作者：刘小排｜2023-02-09

这篇内容面向独立开发者，整理自我 12 月在生财有术“海外工具小航海”里的分享。两个月前，我聊过怎样找到产品 idea；这一次接着往下说：拿到点子之后，怎么尽快把它变成 MVP。

一、为什么要把 MVP 做快？

原因很直接：新品夭折的概率太高。想抬高整体成功率，只能增加尝试次数，持续押注新的 idea，这几乎是所有创新者绕不开的路。

同样一年时间，你能上线 12 个 MVP，而对手只发布 3 个，你就多了四倍试错机会。

独立开发者 Peter Levels 今年 10 月推出 avatarai.me，上线第一天入账 1 万美元，十天内累计 10 万美元。他的方法并不神秘，核心就是“多”。过去十年左右，他做了约 70 个产品，只有 4 个跑通，成功率仅 5%。全球顶尖独立开发者尚且如此，我们更不该指望一击即中。

所以更合理的做法是：

1. 把你能想到的每个 idea 都做一遍；
2. 用最省力的方式、最快的速度上线，比如压缩到一个周末；
3. 上线后盯用户数据，让市场决定要不要继续加码。

那么，怎样在一个周末做出 MVP？这就是下面要讲的重点。

二、MVP 该做成什么样？

我的核心思路有两条：

1. 起步优先做海外网站；
2. 提前想清楚这次要验证什么。

先说第一条。为什么海外网站更快？因为相比其他产品形态，它的上线阻力小得多。

做 iOS、Android App 慢：编码更复杂，对开发能力要求更高；还要打包、提交审核，审核还可能卡住。国内 App 更慢，上架应用商店前往往要花 3 个月拿软件著作权证书。更麻烦的是修小 bug 也要重新发版，用户还得升级安装才能用，bugfix 效率被严重拖累。

做国内网站也不轻松，域名备案通常要 1 到 3 周；北京等要求严格的城市，备案还经常被打回。

微信小程序比前两者略好，但也不够快。它的开源生态不够大，很多轮子得自己造，很难直接引入开源代码来提速。

海外网站则省掉了软件著作权、域名备案、应用商店审核；软件更新时用户也不用重新下载 App。代码放在 Github 仓库里，用 Github Action 做 CI/CD，提交代码就能自动上线，开发体验很顺。

需要说明的是，“从网站开始”不代表产品永远只能是网站。MVP 阶段先用网站验证，等拿到足够的用户数据反馈后，再补微信小程序、iOS App，完全不迟。

再说第二条：MVP 功能怎么取舍？

办法是提前确定要验证的内容，然后只围着它开发；无关功能一律不做。

比如你想验证“我发明的某个功能有没有人用”，那用户注册、登录、支付都不必做，只做那个功能即可。此时重点看“回头客比例”：如果流量里回头客占比不错，说明用户是真的觉得产品有用，而不是随便看看。

再比如你想验证“这个产品有没有人愿意买”，那连功能都可以先不做。把卖点列出来，放上付款链接，甚至只放一个收集邮箱的输入框，然后去买搜索关键词广告，测试付费转化率。这时核心数据是付费转化率；当它大于 30%，再考虑把 MVP 做成正式产品。

注：搜索关键词广告是最精准的广告，因此这里要求的付费转化率门槛特别高。如果流量来自其他渠道，标准可以放低，但也不建议低于 5%。

三、有没有实际例子？

有。

我在机器人创业公司工作，平时基本 996，只有周末能自由安排。到了周末手痒，就从笔记本里翻出一个旧 idea，快速把它实现。

9 月“海外工具小航海”期间，我一共做了两个 MVP，每个都控制在两天内完成，也就是利用周末。

第一个 MVP 花了一个周末。那是 9 月最后一个周末，做完就放假了。运气不错，产品起来了。细节我暂时不展开，因为我准备认真做它，不想过早引入竞争。

四、两天内怎样做出 MVP？

前面说过，想快，产品形态优先选海外网站。作为一个海外工具网站 MVP，只有两点最重要：

1. 界面要漂亮，看上去就很贵、很专业；
2. 核心功能要可用。

围绕这两点，方案就很清楚了。

界面怎么漂亮？花钱买模板。我买的是 https://tailwindui.com/templates/salient。你可以拿它和 https://keywordsea.com 对比，是不是感觉几乎一模一样？不过这款挺贵。我更建议去 themeforest.net 看看，选择更多、价格也更友好，通常大约 10 到 50 美元。

核心功能怎么完成？方法是：只写一个函数。

对，只写一个函数，它就是你的主功能，其他函数一概不写。我不太相信一个合格程序员在开源社区帮助下，8 个小时内写不出来。

比如你想做“下载 YouTube 视频”的工具，先定义好输入和输出：输入 URL，输出视频文件；然后去 Github 找代码，稍微改一改，全程不超过 1 小时。

总结一下时间：

买模板：1 小时  
买域名：1 小时  
写文案：1 小时  
改模板：2 小时  
主函数：8 小时（往往更少）  
部署上线：2 小时  

两天时间绰绰有余。

上线后，把链接发到一些 Startup 社区，比如 Product Hunt，然后等数据。观察什么？如果是免费产品，重点看自然流量增长，因为它代表用户在自传播。自然流量包括社交网络流量、搜索流量、外链流量。

五、半天内怎样做出 MVP？

敏锐的你可能已经发现，上面最耗时的是写主函数，其次是前端界面——买模板加改模板，这两项占整个 MVP 时间的 70% 以上。

如果这两项都不做，是不是还能进一步缩短？

没错，真可以。

尤其对付费产品来说，你完全可以先不做主功能，因为只需要验证“付费意愿”。“验证付费意愿”的最好办法就是预售，也就是大家常说的“卖空气”。

具体步骤：

1. 写产品预售的营销文案，重点列清楚你要解决的问题和 3 个卖点。
2. 用工具生成 Landing Page。推荐 carrd.co、Webflow、Framer，把文案填进去。
3. 用 Typeform 接入 Stripe 支付功能。
4. 购买 Google 关键词搜索广告，关注转化率数据。

六、连续做几个产品都失败，怎么办？

答案是：挺好，你需要提高失败的速度，然后继续尝试。

我很喜欢玩德州扑克。

最早我觉得它是个数学游戏，获胜诀窍是“计算概率，只在赔率合适时下重注”。

一年后我发现，算概率只是基础入门，大家都会算；我开始认为诀窍是“meta game”——通过察言观色等方式发现隐秘线索，从而精准读取对手的牌。

再过了两年，我才意识到诀窍是“Mental Game”：在长时间内保持情绪稳定，才是最重要的。而要做到情绪稳定，你需要“打无记忆的牌”。

有人因为连续输了几把冤家牌，就变得急躁；也有人连续赢了几把后手变松，不把筹码当筹码了。这都是业余玩家最常见的错误。

已经发生的事，无论好坏，你改变不了；这一手拿到的牌，无论好坏，你也改变不了。我们唯一能决定的，是忘记过去、不怨天尤人，把当前这手牌打到最好。

这和做产品何其相似。

有人做成功了一些产品就飘了。这很常见——你能说出几个连续做多个产品、连续获得多次成功的人的名字呢？不多吧？就像某些 rapper，还没出名时能写出很好的作品，成名换了大房子后，反而再也写不出来。

也有人连续做失败了一些项目，对自己的评价就变了，甚至抑郁。这也很常见，生财有术里不少圈友就是这样。他们都没有做到“打无记忆的牌”。

所以，如果你连续做了好几个产品、好几个项目都失败，应该怎么办？从失败中学习，然后继续尝试，就像 Peter Levels 一样，也像职业德州扑克选手一样。

七、几条补充建议

别抠门。免费的东西往往最贵，收费的东西反而最便宜。时间和精力，才是你最宝贵的资源。

我从十年前开始，每个月强制留出收入的 10%，当作“科研经费”，用来购买能提升生产效率的工具、服务、体验和课程。你也可以试试，投资自己是最好的投资。

模板怎么来？花钱。一般模板才几十美元。我买了 Tailwind 官方模板，也才 299 美元。一个漂亮的模板不仅提升产品颜值和用户体验，还能帮你省下数十小时。程序员是国内平均薪资最高的行业之一，算算自己的时薪，50 美元省 50 小时，不香吗？

Typeform 要 29 美元，有没有免费的？有，但不如 Typeform 好用。建议用最好用的。

我们聊的是“如何快速做出产品 MVP”，不是“如何最省钱但降低品质、降低效率地做出 MVP”。

Stripe 账号怎么来？花钱，使用 Stripe 官方的 Stripe Atlas 注册美国公司，才 500 美元。如果你决心做海外工具，这 500 美元很可能是最划算的投资之一，未来很多年都能持续帮你节省海外收款的时间和精力。
