# 选品选对人，小店销量悄悄涨了40%

很多人问我：为什么我小红书店铺的销量总是不温不火？其实问题往往不在产品，而在选品思路。

我先讲几个真实例子。

我有一家卖女鞋的小红书店铺，结果发现袜子的销量，几乎和鞋子持平。另一家钓鱼用品店，饵料卖得比鱼竿还多。上个月刚开了一家露营店，原本以为桌椅是主角，没想到氛围灯也跟着爆单，关键是这灯跟露营看上去关系不大。

为什么？因为这些商品背后，站的是同一群人。女鞋买家需要袜子来搭配，钓鱼佬离不开饵料，露营的人想要拍照好看的氛围感。这就叫人群关联选品。

说白了，选品拼的不是运气，而是你对用户的观察和理解。如果你选品时完全不考虑人群的强关联性，那么就算你推广再用力，销量也可能被隔壁老王按在地上摩擦。

这个玩法最大的好处是什么？流量很精准，转化率特别高。你只需要把一款产品推出去，吸引来的人往往会在你的店里顺手再买一两件关联商品。单品单价或许不高，但客单价却会明显拉高——通常一个人进店，至少买两单。

换句话说，主推款就是发动机，一旦跑起来，整个店铺的关联产品都会被带着走。我自己的店铺基本都是靠这个方法，只要一款产品拿到了流量，其他产品的销量也能被冲起来。每个月都能带来不少额外收益，而且成本低、不费劲。

如果你的店铺想复制这套打法，记住两点：

1. 想清楚你的产品搭配什么卖，用户才会觉得“更完整、更值”；
2. 集中火力先推一款主产品，让它的流量自然带动周边产品的销量。

选品不只是选货，更是选人。当你把同一类人的需求串起来，店铺的生意自然就活了。
