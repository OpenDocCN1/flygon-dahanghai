# 4.1.4 角色指令不会写？这两类工具帮你快速上手

对刚接触的人来说，想独立写出一份让自己满意的角色指令，确实不容易。下面介绍两类能帮上忙的辅助工具。

（一）角色指令生成器

AICosplay 是一个提供角色指令生成服务的 ChatGPT 应用站点。你只要输入角色身份关键词或相关描述，就能让它生成想要的角色指令。

它产出的内容通常包括身份设定和任务设定，但约束类指令未必齐全，需要你按实际情况补充完善。

使用生成器时，建议尽量把任务描述写具体，这样指令质量会更高。比如“小红书博主”后面补一句“文案要带 emoji”，效果会更好；“个人工作周报生成器”比只写“周报生成器”更容易得到符合预期的结果。

如果生成结果不理想，可以多生成几次，再把这些结果放在一起调整。

还要注意，AICosplay 为了兼容不同角色的生成需求，会带出一些冗余指令，参考时按需删减即可。

网址：`role.aicosplay.com.cn/zh?f=scys`

（二）导入现成的身份库

这里推荐两种方案：

方案一：Awesome-ChatGPT-Prompts

国外已经有人把不同身份的文案整理成了现成的身份库。你可以访问：github.com/f/awesome-chatgpt-prompts 网站，获取大量不同身份的文案。

[PRE1]

想让 ChatGPT 扮演哪个身份，直接把下面对应的身份文案复制粘贴到 ChatGPT 聊天窗口即可。

要注意，这些文案是英文的。你用它们和 ChatGPT 对话时，它返回的答案也会是英文。此时可以用“请用中文简体来回答接下来我的问题”来切换语言。

这样，你就相当于拥有了一个专业身份的 ChatGPT，可以用它获取大量相对专业的知识。

如果英文能力有限，我们也找到了一份中文身份库文案，具体见《ChatGPT 身份指令关键词》，使用方法同上。

方案二：ChatGPT App（非官方）

国内有人把 ChatGPT 的身份库做成了 App。你可以下载 ChatGPT 这款 App，为 ChatGPT 导入身份库。这样在 ChatGPT 环境里通过“/”就能调用身份库，很方便。

具体步骤如下：

第一步：访问 github.com/lencx/ChatGPT/releases

选择适合自己的版本。这里以 Mac M1 版本举例：

第三步：登录 ChatGPT 账号，点击左上角“preference”下的“Control Center”
