比特币生态新地图：铭文、闪电网络与钱包

故事得从2022年冬天讲起。软件工程师Casey在当年12月抛出一个叫Ordinals的协议构想，2023年1月，这个协议正式与大家见面。它背后的思路很巧妙：比特币总量2100万枚，拆分到最小单位“聪”，一共是2100万亿个。若把这2100万亿个聪按固定规则依次编号，从0排到2100万亿，每个聪就有了可追踪的身份。再往每个聪里写入图片、文字、视频，甚至一段代码，就等于在比特币网络上造出可安全发行、转移的Web3资产。把数据写进聪的过程叫“铭刻”，铭刻出来的结果就叫“铭文”。Ordinals并不另起炉灶，它靠的是比特币底层能力，铭文转账也由比特币网络完成。

最初，Ordinals更多承载复杂数据，也就是NFT。到了2023年3月9日，匿名开发者Domo在Ordinals之上提出新玩法：不仅能发NFT，还能给资产定统一协议标准，用来发行代币——这就是BRC-20。可以把它看成一套运行在比特币上的“山寨币发行规则”：规定一种特定格式的JSON数据包，再通过Ordinals铭刻到比特币上。部署BRC-20代币不设门槛，谁都能做，规则公平，先到先得；代币名称和总量由部署者自定，但别人已经占了名字，后来者再部署就无效。如今涨了近万倍的$ORDI，正是Domo部署的第一个BRC-20代币。随着关注度升高，改进协议、仿盘协议纷纷出现，比特币生态迅速扩张。铭文市场火热也带来链上交易数激增，矿工手续费收入占比明显提高，铭文已成为矿工的重要收入来源。整体看，Ordinals和BRC-20带来的是比特币生态的深层变化和技术进步，其已显露的潜力，可能成为下一轮加密牛市的重要叙事。

### 2.5.2 闪电网络：把支付搬出主网

说到Layer2，很多人先想到上一章的以太坊二层，因为以太坊Layer2这几年发展快、可用性高，以至于有人误以为Layer2是它独有的。其实Layer2概念最早来自比特币，甚至2009年中本聪提出比特币时，就已经有Layer2雏形的设想。前面我们已经解释过Layer2：把主网上复杂交易放到二层处理，主网只负责简单关键数据，从而减轻压力。以太坊有交易慢、手续费高的问题，比特币网络同样躲不开。

正常情况下，比特币大约每10分钟出一个块，块内能装的交易很有限，是稀缺资源。用户为了让自己的交易被优先打包，只能互相竞价：手续费给得高，矿工先处理。市场冷清时，手续费低一些也没关系，后面几个区块总会确认。可一旦行情狂热，大家都抢着交易，甚至主动抬高手续费，低费交易矿工根本不看，因为总有人出更高价，你的交易就会长时间悬着未确认。有时手续费在极短时间被拉高，矿工还会放下手头正在打包的交易，转去处理新来的高费交易；这个逐利过程中，链上迟迟没有新块产生，也就是常说的“卡块”，直到手续费稳定，矿工才重新安心打包。

比特币Layer2就是为解决这些问题而来，其中“闪电网络”最知名。它建立在比特币之上，目标是解决交易慢、费用高，让用户能快速收发比特币，而且几乎不收费。

它怎么做到？第一次和某人交易时，双方会建立一个智能合约，可以把它想成两人共同持有的私人账本。多笔交易可以直接记在这个账本里，只有双方可见，不上比特币主网。这个私人账本在闪电网络里叫“通道”。例如我和张三各自往账本投入5个比特币，账本余额就是各5个。我转给张三1个，余额变我4个、张三6个，这个结果会传回比特币主网；但“我转张三1个”这笔具体交易不会记入主网，只留在两人账本里。结果回传主网记录时，由于私人账本存在，无需等主网区块确认，支付和转账可以先完成；等区块确认后，再按结果把相应金额分配到双方地址。比特币主网正常TPS约7，还常卡块；走闪电网络，TPS可达百万级，每100美元比特币交易手续费不超过1美分。支付速度提高、门槛降低，比特币全球支付场景因此获得很大成功。

### 2.5.3 其他：账户模型、UTXO 与新协议

今年比特币生态可谓百花齐放。除了Ordinals和BRC-20，再挑几个有代表性的协议案例加餐。开始前先补两个模型：账户模型和UTXO模型（Unspent Transaction Output，未花费交易输出）。

账户模型可以类比银行账户体系，银行转账、支付宝微信转账都属于这一类。假设A有100元，B有100元，A给B转50元，系统里记成A减50、B加50，余额变成A50、B150，一笔转账完成。再假设A仍有100元，要给100个新开户新人每人转1元。第1笔A减1、第1人加1，余额A99、第1人1；第2笔A减1、第2人加1，余额A98、第2人1；如此到第100笔，A0、第100人1。理论上要转100次，而且下一笔必须等上一笔完成，否则余额一致性无法保证，容易混乱：到底多转没有、余额还够不够。交易笔数越多，执行时间越长。

UTXO模型更像现金。比特币用的就是UTXO，我国数字人民币也基于UTXO。举例：A现实钱包里有1元、10元、100元面值现金各一张。现在A要给B、C、D各1元，有三种方式：拿1元给B；拿10元给C，找回9元；拿100元给D，找回99元。三种都能完成交易。回到链上，每个面值的钱可看成一个UTXO；使用UTXO时不是把原UTXO搬来搬去，而是销毁旧UTXO、重建新UTXO。比如A用第二种方式给C转钱，10元UTXO销毁，系统生成1元和9元两个UTXO，1元给C，9元还给A。第三种同理，100元销毁，生成1元和99元UTXO，1元给D，99元还A。UTXO与账户模型的转账方式不同，更强的是UTXO可并行转账：余额分散在多个UTXO里，1元、10元、100元三张现金能同时转给不同人，A可在一笔交易中同时给B、C、D转钱，因为不涉及账户一致性，每个UTXO独立计算。对比账户模型每笔依赖上一笔，性能差距明显。再回到A有100元要给100个新人各1元的例子：面值100的UTXO可拆成100个面值1元的UTXO，然后一笔交易直接分给100人，瞬间完成。总之，把UTXO面值想成更灵活的现金，在链上不断销毁和重建；想知道某地址到底有多少钱，就统计它名下所有余额UTXO并求和。

掌握UTXO模型后，再看今年比特币生态的其他协议。

**Atomicals 与 ARC20**

[PRE1]

Atomicals是针对Ordinals和BRC-20的优化协议，重点在代币，试图解决BRC-20过度依赖中心化链下索引的问题。什么是中心化链下索引？简单说，Ordinals的运转离不开比特币主网之外的线下服务来维护状态；一旦这层状态服务出问题，资产就可能受损。主网本身拦不住无效铭文，只能靠中心化平台来裁定哪条铭文算数，算数的才被收进合集。这里用的技术方法不像智能合约那样是公开透明代码规则，所以Ordinals难以满足共识、防双花等资金安全需求。Atomicals则利用并扩展比特币UTXO模型，把每个“聪”的UTXO当成特定Atomical代币或数字对象，从而在比特币上创建和管理复杂数字对象与代币系统（ARC-20）。Atomicals在2023年9月推出后，第一个代币ATOM很快被挖完。与BRC-20相比，ARC20铸造引入POW机制，铸造者需要先算出带有指定前缀字符的哈希值，才有资格铸造，这是一种更去中心化、更公平的分发方式。整体看，Atomicals作为Ordinals竞争者，专注同质化代币和数字对象的去中心化创建管理，通过扩展UTXO模型，实现更去中心化、更贴近比特币文化的代币系统。ARC-20凭借技术优势和符合比特币原教旨主义的设计，有望获得比特币核心社区支持，为生态带来更广泛应用可能。

**Runes 与 PIPE**

[PRE2]

Runes构想来自Ordinals创始人Casey对BRC-20不足的思考，也是基于比特币UTXO模型的代币协议构想。它的主要特点和设计理念包括：基于UTXO，Runes余额存放在UTXO中，每个UTXO可包含任意数量Runes；特定脚本输出被视为协议信息的一部分，用来定义Runes转移和分配方式；转移通过解释交易中的数据推送实现，分配方式灵活；第二个数据推送视为发行事务，允许创造新Runes；协议尽量简单，不依赖链下数据或原生代币，并适应比特币UTXO模型；Runes可关联符号，但协议不涉及符号抢注问题，以维持简单性。Runes目前还停留在概念设计阶段，不过活跃的比特币社区开发者BennyTheDev在2023年10月推出了基于Runes思想改进的Pipe协议，发布后吸引BRC-20的炒作热情，并快速完成首轮炒作。整体看，Runes和Pipe体现了比特币社区对同质化代币实现方式的持续探索与创新；这些协议虽处早期，但已展现潜在可能，未来有望为比特币生态带来更多交易费收入、开发者和用户。

**3. Bitmap 与 BRC-420**

[PRE3]

Bitmap.land是比特币生态首个元宇宙项目，基于Ordinals协议和Bitmap Theory（位图理论）。位图理论由推特用户@blockamoto在2023年6月13日提出：把比特币区块中的每笔交易输入映射成地块（Parcel），形成街区或区域（District）；不同交易输入大小不同，映射出的地块大小也不同。Bitmap.land采用在地图上划分土地、绘制图案的方式，用户通过铭刻把数据写入“聪”，获得特定比特币区块的所有权。比特币区块链上每个区块被划分为四个部分，代表不同减半周期；用户可在Bitmap.land网站查看每个区块编号和颜色，不同颜色代表不同售卖状态。Bitmap允许用户拥有和记录单个区块，为比特币区块链每个区块提供新维度；任何区块都可通过Bitmap成为元宇宙一部分，为社区带来新的创造和所有权机会。

BRC-420协议自2023年11月13日以来，随着Ordinals总铭文数量超过4000万，已成为比特币生态活跃代币协议之一。与传统代币协议不同，BRC-420专注链上铭文模块化，创造比特币上全新资产类型。它的首个通证俗称“蓝盒子”，从最初0.15美元涨到1000美元，开发者短时间获得丰厚链上版税收入。BRC-420基于Bitmap资产协议，通过把多个铭文组合成复杂资产，创造出从小型角色、宠物到完整游戏脚本和虚拟机的各类资产；这些资产因链上开源，任何客户端都可运行或校验。整体看，BRC-420和相关Bitmap项目正在比特币生态激发创新和活力；通过创造复杂、模块化数字资产，为创作者、开发者和用户提供新经济机会和交互体验。随着团队不断努力，比特币生态的全链游戏和元宇宙概念正逐步成为现实。

# 三、DID 与钱包：把身份和资产握在自己手里 @可达 Koda

## 3.1 去中心化身份：公钥、私钥与助记词

DID，全称decentralized identifier，中文叫去中心化身份，要解决的是个人对数字身份的所有权、控制权和管理权问题，这些权利完全归用户。前面章节提过，Web2里数字身份属于各大公司或组织；到了Web3，数字身份产权归自己。借助区块链技术和去中心化身份概念，你的链上交互都会留下记录，有据可查。当然这也是双刃剑：交易公开可查，链上资产和其他操作更容易被别人知道，存在潜在隐私问题。

去中心化身份目前主要载体是公钥和私钥，二者由区块链密码学规则产生。公钥可理解为银行账户：你在链上生成公钥，相当于在银行开户；公钥地址通常是以0x开头的一串字符，可看成这个账户的银行卡号。私钥是一长串无序数字和大小写字母的组合，通常很难记，却是去中心化身份最重要的环节——私钥即产权。拥有私钥，就拥有该私钥下数字资产产权；私钥只属于你自己，不属于任何组织或机构。理解时可把它当成银行卡密码。

钱包是生成和存储私钥的工具。经过你授权，钱包才能调用其中私钥进行数字资产交易。多数人注册钱包时还会遇到助记词。因为私钥太长不好记，助记词就成了一种容易读、容易记的私钥表现形式。比如密码是12345，单词库里有apple、orange、tom、june、july，数字和单词一一对应；单词形式更可读好记。由于整个区块链共用一套密码学规则，即使你用的钱包公司倒闭，只要区块链网络还在运转，只要你知道私钥，就能用新的钱包工具登录并管理资产。Web2则不同：所在公司或平台破产、跑路，你在其中的资产也会一起消失；在Web3，这种风险大大降低。使用钱包时还要设一个钱包密码，主要用于钱包应用登录，类似Web2各应用密码。不同点在于，同一个私钥可在不同设备的不同钱包中使用，且不同设备可设置不同登录密码。

## 3.2 钱包分类：中心化、去中心化、冷与热

钱包涉及几个概念：中心化钱包、去中心化钱包、热钱包、冷钱包。判断标准很简单：私钥归机构保管，属于中心化钱包；私钥留在用户手里，则是去中心化钱包。中心化钱包最常见场景是各大交易所钱包。以币安为例，想用它交易数字货币，先注册账号密码，并提供Web2世界个人身份信息，和注册股票证券交易所几乎一样。这个过程相当于你信任交易所，把钱包委托给交易所保管。行业现状是，如果资产金额不是很大，头部中心化钱包安全性好于去中心化钱包，因为币安安全技术非常强；但也有不好之处，会受监管，有些人的账号可能因监管被资产冻结。

去中心化钱包又分冷钱包和热钱包，主要按私钥存储是否触网区分。所谓冷钱包，就是不联网的钱包，常见形态是硬件设备，作用类似银行U盾。它的私钥从生成到使用都不接触网络，直接保存在离线设备里，因此安全系数更高。
