# 方式二：让 AI 直接帮你写

第一组prompt参考：

我现在要写一条跳绳的带货文案，切入点选用户痛点，比如想减肥、瘦大腿、瘦腰等，写一篇不超过500字的文案。

要求：
1. 用金句/故事/痛点来开篇
2. 语气亲切、利他、口语化
3. 给到可落地的实操建议，分点写清楚
4. 最好带上具体数据，增加可信度
5. 结尾用“我”的亲身体验来分享，自然引导下单，但话术上还是要显得为读者着想
6. 不要空话套话，痛点要戳得足够深，让人看完觉得“这不就是我吗”“太懂我了”，觉得这篇笔记值得收藏、有实用价值、我需要这个商品

第二组prompt参考：

假设你是一位👸号带货达人，有5年写作带货经验，很擅长在👸号写爆文和利他型干货，同时把货带出去。

请以“”为主题，想一个标题，再写一篇300字左右简短但有力量的文字，带货目标是“”

要求：
1. 开头用一句富有哲理又简洁的话点明主题，迅速抓住人
2. 用生动的比喻或对比，形象说明会说话的重要性，也为后面推书做铺垫
3. 给出明确的推荐理由，点出这本书对提升相关能力的重要性，尤其针对特定人群，非常精准有吸引力
4. 内容展示要丰富，通过列举书的好处、对“我”有什么用，让读者对书有具体了解，增强购买欲
5. 引发强烈情感共鸣，用描述让读者感受到读这本书后能带来的积极变化和自信提升，激发共鸣

# 去 AI 味儿的提示词清单

补充案例：
问题：段落中的论点缺少实际例子支撑，说服力不够。
指令：给这段补一个具体案例，让论点更有事实感。

删掉冗余：
问题：段落里有重复或不必要的信息，显得拖沓。
指令：删掉重复和没用的信息，让文字更简洁，不啰嗦。

扩充论据：
问题：某个论点证据不够，撑不起观点。
指令：把这个论点展开，补更多支持性论据，增强说服力。

加入对比：
问题：段落观点太单一，读起来单薄。
指令：加一个相反观点来对比，让讨论更有层次。

简化开头：
问题：开头太绕，读者容易失去耐心。
指令：把开头改得简单直接，让读者更快进入主题。

调整段落顺序：
问题：段落顺序别扭，逻辑不顺。
指令：按重要性或时间顺序重排段落，让逻辑更清晰。

拆分长段落：
问题：段落太长太密，读着累。
指令：把这段拆成几个短段落，读起来更轻松。

添加小标题：
问题：段落多，没有小标题，不容易找到重点。
指令：给段落加上合适的小标题，让结构清楚，方便查找。

善用比喻类比：
问题：表达太直白，不够形象。
指令：在合适的地方用比喻或类比，让表达更生动，内容不干巴。

引用名言：
问题：论证缺权威背书，说服力弱一些。
指令：在合适的地方引用名言或经典句子，增强说服力与文字深度。

强化画面感：
问题：描述太抽象，读者脑子里没画面。
指令：把描述写得更可视化，让内容具体、生动，方便读者想象。

增加趣味性：
问题：内容干巴巴，可能留不住人。
指令：在合适的地方加点有趣内容或幽默元素，让文章更有吸引力，阅读体验更好。

# ⚠️发布前必须注意：
1. AI写完一定要自己再改一遍，直接复制可能被系统识别，影响流量。
2. 发布前用“零克查词”查一遍敏感词，保证笔记安全上线。
3. 正文控制在10-500字，写太长影响转化，很多人划不到文末。
4. 排版要分段、加表情，方便阅读。

# 4.4 发布节奏与注意事项

发布节奏：
小绿书现在没有次数限制，但为了确保内容质量，还有其他不确定因素，建议每天至少发5条。

# 5.1 阅读量总是0或个位数，怎么办？

阅读量低，基本是这几个原因，重点优化：

# 发布量不够

小绿书可以用量对抗概率。如果还没发满1个月（至少150篇），先别抱怨，继续发。

# 点击率低（头图不抓人）

一般情况下，一个号在当前机制下能拿到大概100-200的初始曝光。但初始曝光≠阅读量，因为头图不吸引人，点击率就低。

比如这篇，初始曝光有2000多，点击只有22（点击率0.81%），问题就出在首图不吸引人，需要优化。再看这张图，清晰度也不够，直接影响点击。

[PRE10]

封面具体怎么优化，多看爆款拆解【4.1.2-1 封面拆解】。

# 完读率低

做过👸号爆文的都知道，完读率很重要，小绿书也一样。

润宇老师：“因为本身是图文，文章不长，完读率基本要干到40-50%以上。”

怎么提高完读率？答案：控制篇幅。

如果只有一张图，正文别超过800字，最好在10-500字左右。它是图文不是长文章，写太长没人耐心看完。

还有一个细节：有人为了多卖货，在一篇正文里插好几个商品图，每隔2-3段就冒出一个商品。这反而影响观感，适得其反。

# 平均停留时长

一般大爆款，平均停留时长能达到1分钟甚至更高。

怎么拉长停留时间？一个小技巧：
在首图和其他图片右下角加一句“向右滑，看更多精彩内容”之类的话，引导读者不断往下翻。

把这4点做到了，再看发布后的“互动”情况。互动数据目前📕比较公开透明，小绿书还没公开，但润宇老师给了一个公式可以参考：评论＞分享＞点赞＞在看。

# 5.2 笔记火了却没出单？

图文火了却没出单，先检查这两个动作做了没：

① 选品没做好，没按“实用＋特色＋猎奇”的标准来选
② 产品和文案没关联，卖点没体现出来

① 选品
新手最快的办法，就是参考爆文品类来选品：2.3.3 选品推荐
长期看，选品能力也要持续提升，可以参考《6月航海 | 视频号带货 | 实战手册》章节2.1-选赛道的方法~章节2.2-选品的方法

② 产品卖点
很多人用👸号流量主爆文的逻辑写文章，再随手挂个品，这种基本出不了单；或者产品跟内容关联度低，也很难转化。

看个反面案例：
作者选的品本身不是热销品，图文内容跟产品场景也匹配不上，卖点没体现出来，自然没有下单欲望。

# 六、带货佣金怎么提现

手机端打开创作者中心，就能看到数据看板。数据看板里的“今日数据”显示的是销售额，不是纯佣金。

[PRE16]

点【带货中心】-【佣金】-【收款明细】，可以看到待打款和已打款的明细；点【订单详情】可以看订单状态和结算状态的佣金，支持人工提现，提现会扣1%服务费。

再点【带货中心】-【佣金】-【订单详情】，能看到所有带货订单，点进某个订单还能查看订单状态和结算状态。
