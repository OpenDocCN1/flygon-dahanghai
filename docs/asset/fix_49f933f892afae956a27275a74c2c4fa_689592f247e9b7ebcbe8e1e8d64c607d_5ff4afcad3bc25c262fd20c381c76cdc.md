# 1. 开篇概览：MVP 思路与环境准备

先记住一个提问套路：如果你要为某类用户在特定场景里解决某个麻烦，并打算用 App 来承载，那么可以直接让 AI 帮你拆解——“这个产品的 MVP 应该有哪些功能？逐项列出来。”

错误示范：造车只交一只轮胎，用户还是到不了目的地，这不算 MVP。正确示范：先交一辆滑板车，虽然简单，但已经能让人比走路更快地移动。

本章目标，是把 iOS 开发所需的硬件、软件和账号条件配齐。硬件方面，Mac mini M4（3499 元）性价比突出，也可以选 M 系列 MacBook；另备一部 iOS 16+ 的 iPhone 做真机调试。租机虽可行，但性价比一般。账号方面，普通 Apple ID 就能免费开发；99 美元/年的开发者会员主要用于上架和长期测试；首次实名申请有哪些常见坑，也会讲到。工具方面，需要安装 Claude Code / Augment / Cursor 这类 AI 编程助手，安装 Xcode 并创建项目，同时熟悉项目结构、真机编译和图标设置。关键技巧有两个：项目根目录要设对，让 AI 工具与 Xcode 联动起来；开发者账号要配置好，真机调试才能跑通。学完本章，开发环境就绪，可以开始用 AI 写第一个 App。

1. Mac 怎么选

在 Mac 选择上，底线是能运行最新版 Xcode（当前为 Xcode 16+），M 系列 MacBook 或 Mac mini 均可，m1 也够用。若自己买，Mac mini m4 值得优先看：国补后最低 3499，配置与性价比比二手 MacBook Pro 更稳，不过键盘、鼠标、4K 显示器要另配。第一次接触 Mac，教程可以上网找，DeepSeek、元宝、豆包也能随时问。

租机方面，支付宝报价约 300-400/月，至少租 3 个月，配置别低于 i7 和 16G 内存。我认为不太划算——三个月租金接近新款 Mac 的三分之一，再加几百元甚至能入手低配二手 MacBook。真机调试则建议准备一部 iOS 16 及以上的 iPhone，并用原装线连接；能上真机就别只靠模拟器。

1. 域名、服务器与备案常识

# 3.1 先判断：域名、备案、服务器要不要

先问自己三件事：App 是否联网？服务器放哪里？业务面向谁？

域名不是必选项。App 若需要请求后端接口、加载网页或调用 API，就得有一个公网地址，通常表现为域名；若 App 完全本地运行，数据、逻辑和资源都随安装包走，不碰互联网，域名可以省掉。

备案要看服务器位置。服务器在中国大陆（阿里云、腾讯云大陆机房等），域名必须先做 ICP 备案，否则解析不到该服务器，访问会被拦。服务器放在香港、新加坡、日本、美国等境外地区，则无需备案，域名可直接使用。

时间上，ICP 备案通常要 2-3 周。不少人为了抢上线，会先用香港或海外服务器跑起来，再考虑是否迁回大陆；代价是大陆用户访问可能偏慢，部分网络环境下也不够稳。

如果服务器在大陆且业务面向国内用户，备案就是硬门槛：没有备案，DNS 不会指向你的服务器，网站或接口相当于打不开。备案还影响接入——支付、短信、🛰️/支付宝等第三方 API 往往要求备案号；广告投放和应用分发平台也可能核查备案状态。

那服务器在国外，能不能做大陆用户生意？访问本身没有硬性禁止（内容违规被墙除外），但速度和稳定性容易出问题，视频、实时交互类业务在高峰或某些运营商网络下会明显卡。若业务面向国内公众用户，用境外服务器实质是在绕开备案，法律上不合规，被查可能封域名、封应用。国内生态的接入点（🛰️支付、支付宝、短信网关）也会查备案，没备案就卡住；服务器在境外也绕不开这些环节。

# 3.2 备案怎么走：阿里云示例

下面以阿里云为例。

第一步，买服务器。阿里云 ECS 入口：https://www.aliyun.com/product/ecs；腾讯云 CVM：https://cloud.tencent.com/product/cvm。

第二步，买域名。可在阿里云或腾讯云注册，.com/.cn 约 30-55 元/年，其他后缀约 10 元。腾讯云域名入口：https://cloud.tencent.com/product/domain；阿里云万网：https://wanwang.aliyun.com/。

第三步，把域名解析到服务器 IP。

第四步，提交 ICP 备案。入口：网站备案_ICP备案_备案迁移_备案-阿里云。按页面填写，App 接入信息栏要填服务器和域名。注意：阿里云活动服务器不能备案，必须用自己购买的服务器。之后等 1-2 周，管局审核通过拿到备案信息，再到 App Connect 填写，并在 App 内展示 ICP 号。

# 3.3 备案提醒：少走弯路

阿里云、腾讯云都有备案入口（https://beian.aliyun.com/?spm=5176.100251.console-base_top-nav.dicp.48654f15gRzxw6），按提示交材料即可，个人也能独立完成。

个人备案时，网站类型和备注建议写成“个人学习使用，用于建设个人网站，记录工作和生活”，别写商业用途。若个人备案的域名后来被拿去做直观商业用途，例如搭建无需登录就能看完整内容的海外站点，服务商可能强制注销备案；有这类需求，建议用个体/企业执照备案。

备案最好在买服务器的同一服务商办理。域名备案需要备案号，买服务器一般会送 2 个；没有的话，淘宝搜“阿里云 icp 备”，约 10 元买一个填上。提交后 24 小时内留意服务商来电，会核对个人信息；有问题也会驳回并给修改建议。

1. 开发者账号准备

# 4.1 Apple ID 和开发者会员

在 Xcode 里开发 App，建议先登录 Apple ID。iPhone/Mac 用户通常已有，用自己的或单独注册都行。Apple 开发者会员年费 99 美元，核心权益有两项：把 App 上架到应用商店；用 TestFlight 在真机上做长期测试（非会员测试的 App 在手机上只能用 3 天）。⭐️所以现在不必急着缴费，等需要时再回来看。下面附 iOS 开发者账号申请与配置完整指南。

# 4.2 注册时容易卡住的地方

这里很常见，务必留意。首次实名 Apple ID，不要在登录过 3 个以上 Apple ID 的设备上操作；用租机设备申请开发者账号时，设备是否为公共设备不确定，可能导致申请失败。先确认自己或家人是否有更早实名的 Apple ID；如果自己的信息注册不了，可以换家人信息试试。遇到“账号异常”，直接发邮件到 chinadev@Apple.com。

# 5.1 Xcode 与 AI 工具怎么配合

第一步，在 Xcode 点 Create New Project 新建项目，选默认应用类型，项目名用拼音或英文。Organization Identifier 填 com.xxxx.xxxx，域名要反写，com 在前。例如项目叫“yuyin3”，域名是 cuanxue.com，就填 com.cuanxue.yuyin3。以后新建项目填的域名，也是上架 App、创建 App ID 时用的信息。

# 5.2 Xcode 项目文件各自做什么

Xcode 建完项目会生成一组目录，只有第一项是项目根目录。Contentview 是主视图文件，可理解为 App 打开后的第一页，项目创建后里面自带“hello word”文字；在 composer 模式下首次生成代码，需要 @ 引用它。yuyin3APP 是应用容器，最终装到手机上的就是它，打包时会带上项目全部资源。Assets 用来放 App 图标和图片，支持 PNG/JPG，建议压缩后再传。yuyin3 是权限配置文件。Preview content > Preview Assets 属于预览资源，上架打包不会包含，只在预览/测试时出现。
