# 第四步：挑对短剧，拿到素材🔥

大家在了解平台的过程中，应该已经看到很多类型不同的短剧。那么怎样选出适合推广的短剧？这是本章要解决的核心问题。

尤其新手，很难单靠自己找到更容易爆的短剧，毕竟“短剧 CPS”在很大程度上是拼概率的项目，老手翻车也很常见。适当用一些技巧，才能事半功倍。

麻雀 Matrix 和创作猫也清楚这一点，所以这两个平台会总结一些爆款，帮助大家选剧更有方向。

本章会从这些角度提供选剧方法：

✅ 通用方法：从视频数据反推爆款短剧  
✅ 平台方法一：麻雀 Matrix 的爆款参考  
✅ 平台方法二：创作猫的爆款参考  
✅ 进阶玩法：选择新剧，大胆尝试  

⭐️ 航海期间，教练们也会在群里分享最近的爆款短剧和一些对标视频，大家可以跟进学习。

找到觉得值得推广的短剧后，别忘了获取素材。注意：素材原片千万不能直接发，必须经过剪辑，剪辑方法会在“六、剪辑视频”细说。如果直接在各短视频平台上传原片，不但会被判违规，甚至有封号危险，收益也会被短剧推广平台没收。

百闻不如一见，百见不如一练，找到适合你的小技巧，尝试找找更适合推广、更容易爆的短剧吧。[PRE57]

## 4.1 如何选出适合推广的短剧

### 4.1.1 方法一：参考麻雀 Matrix / 创作猫爆款 @猫柠

常用平台有麻雀和创作猫，两个平台都会有爆款剧推荐。

麻雀 Matrix：  
先看麻雀平台，它有“热门短剧”标签页，会推荐当前比较火的短剧。下方有筛选功能，可以按不同剧场、不同时间筛选热门短剧：[PRE58][PRE59]

7 天内的热门短剧基本可以直接挑出来用。特别火的剧，筛选时间可以适当放宽，比如之前火过好几个月的《顾少的隐婚罪妻》。

同时，在右侧“全部”标签页中，也能筛出最新上线的短剧。有人更喜欢找新剧做，觉得内容越新竞争越小、效果越好。其实平台几乎每天都有新剧上线，但不是所有新剧都能成为爆剧。我们要追求的不是“什么新做什么”，而是“什么火做什么”，顺着平台调性走，做用户喜欢的内容，平台才会给流量。

创作猫：  
对比两个平台的热门短剧推荐，眼尖的人会发现有重合剧目，比如《叔的小祖宗闪婚后宠爆了》。[PRE60]

为什么两个平台推荐的热剧不完全相同？因为不同平台涉及不同剧场授权、推广用户数量和粉丝量差别，数据多少会有出入。但一部剧如果被两个平台都收录进热门推荐，足以说明它的数据非常不错。

拓展：爆剧和新剧怎么选？经验是：

① 优先做爆剧：爆款剧 ＞ 新剧  
② 如果两个爆款剧火热程度不相上下：爆款新剧 ＞ 爆款老剧  
整体来说：爆款新剧 ＞ 爆款老剧 ＞ 新剧。
