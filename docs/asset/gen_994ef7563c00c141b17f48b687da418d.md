# 5.2 图片类需求怎么找、功能怎么做

# 5.2.2 图片类需求怎么挖？

方法不复杂：多逛图片类网站。具体来说，可以在 Toolify 榜单里筛出 AI 图片类站点，再用 Semrush 等关键词工具导出这些网站的关键词，然后结合谷歌网页和关键词工具做调研，综合判断哪些图片类需求还值得切入。

# 5.3.6 上线后还要做什么

如果你已经跟着成功上线了一个网站，下一步就是熟悉模板。可以把代码都发给 AI，让 Claude 帮你修改文案，这样就不容易出现重复网站；接下来只要找准人群定位和推广渠道即可。

# 5.3.6.1 绑定域名

最后一步是上线域名。

在设置里找到域名，把买好的域名输入进去，点 ADD。这里我用一个很早之前买的域名做测试。添加完域名后要设置 DNS：可以先放到 Cloudflare 上再改 DNS，也可以直接去域名注册商那里改。我演示的是后者，日常建站建议用前者。

# 5.5 网站优化与推广进阶策略

网站优化是长期活，包括增加内页、补充功能内容等。推广方法很多，但最适合小白、也最有效的办法是每天发外链。步骤很简单：第一步，找出你所做网站的一系列关键词；第二步，谷歌搜索这些关键词对应的网站，也就是竞品网站；第三步，把竞品网站放进外链工具，查它们去哪里发了外链：https://ahrefs.com/backlink-checker/?input=
