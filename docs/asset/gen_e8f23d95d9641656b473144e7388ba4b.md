# 4.2.1 定价别只算成本账

不管是接公司的项目，还是做个人的外包，很多人第一反应都是“先把成本管住”。想让利润更可观，常见办法无非两种：压低开支，或者把谈单本事练得更强。这个逻辑听起来没毛病，但刚起步做副业时，也很容易被它带偏——先盘算自己投入了多少，再在支出之上加个安全垫，确保不亏还有得赚。

真正麻烦的是在小众市场里直接面对使用者。价格怎么定，确实让人挠头，因为你做出来的东西，未必是为你自己服务的。就拿我那个 YouTube Comment Bot 来说，最早标价 1.99 美元。为什么定这么低？它对我个人的用处并不大，投入的开发精力也有限。

后来我才彻底转过弯来：价格应该锚定在用户能得到的好处上，而不是我这边花了多少。于是索性把价格清清楚楚摆出来。谈钱就伤感情？该谈还是得谈。
