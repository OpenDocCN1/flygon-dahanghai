# 自媒体写作与变现：从标题到收益的实操笔记

写历史类公众号，路数和头条的微头条、问答、文章其实一脉相承——先抛问题，再给答案。

真正的差别在标题。头条偏重深度和概括力，读完让人有所得；公众号则讲究抓眼球、造好奇，标题越让人忍不住想点，越算成功。

**1）写人物结局，主打遗憾或出人意料。**
沿着人物一生来捋：出生、青年、中年、晚年，每个阶段塞一两个关键事件。晚年那段尤其要写得有棱角，因为点题全靠它。

**2）写性格与事迹，主打反差和震惊。**
整体还是讲生平，但挑一两件事重点写他性格的反面——好人做过的恶、明君干过的糊涂事。大部分篇幅写大家熟悉的那面，留一小段揭他不为人知的那面。

# 3.2.6 情感类：爆款故事公式

一个情感故事=标题+主角+故事主线+收尾。

展开说：主角是谁、想干什么、为什么干或怎么干、过程中碰上什么、最后怎样。

先定主题，再拟标题，然后顺着主题往下写。

主角介绍：我是谁、多大、哪的人、干什么的，简单交代；再带出相关的人或物，什么关系、怎么认识、什么背景。

故事主干：目标或梦想、挫折阻碍意外。

结局：对主角的影响、他怎么应对、结果如何。

爆款故事有五个基本条件：好标题、原创、有信息增量、不重复新闻、不传负能量。一般用第一人称写，方便读者代入；不是硬性规定，看个人习惯。主干情节详略得当，无关的略写，能体现性格、推动故事的详写。结尾尽量反着来，让读者觉得意料之外、情理之中。比如某女结婚彩礼要太多，婆家要退婚——读者以为会分手，结果却结婚了；为什么还结，靠反转情节来圆。故事可以虚构，也可以真实，但必须正向引导，不违伦理、不传负能量。

例文：
《除夕夜公公给我们100万，本是高兴的事，可被老公闹得家里鸡飞狗跳》
《我69岁，发现40岁保姆偷我钱，我要求她“肉偿”，她的反应吓傻我》
《我33岁阳了，老公连夜带着孩子逃了，半夜有人压在我身上，睁开眼我吓傻了》
《公公病危，儿媳献身，公公舒服，婆婆支持，老公发飙，结局意外》
《我51岁，二婚老婆夜班，继女爬上我的床，说难受让我帮帮她，我让她愉悦，老婆夸我真棒》

# 3.3 把标题打磨到位

标题决定打开率，打开率决定阅读量，阅读量决定收益。标题写作有套路——“开幕雷击”。让读者第一眼看到就震惊，像被雷劈了一样，忍不住点进去。下面用案例讲这个技巧。

# 3.3.1 第一眼就要“炸”

每篇文章想拿高阅读、高收益，标题必须抓人。核心是把读者在乎的东西塞进标题，勾起欲望和好奇。标题不行，内容再好也没人看，等于白写。

开幕雷击最早由圈友@半塘梦呓在星球分享，从微头条切入讲开篇怎么吸引点击。感兴趣可查原文《半塘梦呓：如何用好开幕雷击》。

开幕雷击就是第一眼看到的内容有令人震惊的言论或画面。反复测试后归纳为七个要素：金钱数字、性暗示、暴力、死亡、捷径、异常悬念、民族主义。其中“异常”最百试百灵。这七要素不限于公众号，短视频、百家、头条图文问答微头条都能用。不违规的前提下尽量多糅。

很多同学文章不错，就是开幕雷击没把握好，还有人误解成狗血暴力血腥，那只会让读者不适，还会被限流、投诉、封号。真正的雷击是出现令人震惊的言论或画面、勾起好奇就行，让人觉得反常、跟正常思维拧着来。不是直接写“震惊”“惊呆了”，更不是“一刀砍下去血溅满身”“倒在血泊中”，而是用委婉字眼让读者自己联想。

比如家人病逝本该伤心，他却高兴——这叫异常，读者忍不住点进去看为什么开心。再比如小店矿泉水3元一瓶、10元三瓶，大家说店家傻，都一瓶一瓶买，三瓶只要9元，没想到店家乐了——金钱加异常，你不想点进去看看亏本买卖他为啥乐？

记住：别直接写暴力血腥涉黄，隔层纱，字面别带出来，让读者自己联想。别为流量挑战平台规则，得不偿失。标题含七要素中两个，打开率基本有保障，越多越好。

# 3.3.2 标题技巧（张波）

**爆款标题四要素：**
1. 调动情绪：让读者产生喜悦、悲伤、愤怒、好奇。
2. 用数字和数据：具体真实，感知明确。
3. 用极端或夸张词汇：增加冲击力。
4. 保持简洁清晰：一眼看到重点。

**万能公式：** 突出主题+矛盾冲突+引发悬念。
比如：
• 47岁的我，搬进丈夫的工地宿舍，被一群硬汉围着，夜里心里燃起了期待的火焰。
• 35岁新郎一句话让26岁新娘哭了：你这二手货有什么好疼的？

**润色技巧：**
1. 植入流量热词，如“疲惫不堪”“心满意足”“笑容满面”。
2. 用具体生动的语言造情境、展角色、反转或设悬。
比如：
原题：50岁单身汉，被46岁寡妇骗进家，干完体力活后偷偷跑回了家
改后：50岁单身汉，被46岁寡妇骗进家，干完体力活后寡妇却笑容满面
原题：新娘缺席婚宴，丈夫报复性分居十几年，妻子的态度坚定，一直未变
改后：新娘缺席婚宴，丈夫报复性分居十几年，妻子晚上却笑容满面等着隔壁老汉的反击
原题：怀孕的妻子被婆婆安排去旅游，丈夫一招架醒她，却引发了一场结局
改后：怀孕了，婆婆安排去旅游，丈夫一巴掌把我扇醒，结局却让我如愿以偿
原题：45岁美女房东求助28岁小伙修水管，修好后却有了意外收获
改后：45岁美女房东晚上求助28岁小伙修水管，修好后虽疲惫不堪却体验了不寻常的快乐

# 3.3.3 标题范例（张波）

**1. 提出疑问：** 人物+为什么+具体事件；人物+经历+凭什么
《千聊、荔枝有那么多育儿课，凭什么李老师的课卖得最爆？》
《14岁辍学，29岁身价过亿，这个90后女孩凭什么》

**2. 制造悬念（说一半留一半）：** 如何/为什么+事实+反转
《如何用10秒钟，把堵塞的鼻子变通畅？用它喷一喷，舒服一整天！》
《为什么孩子越大越不愿意和你交流？99%的家长都不知道》

**3. 数字与数据：** 数字+事实+奖励
《我这里有200页重磅PPT，20个压箱底文案小技巧等你来领取》

**4. 蹭热点：** 热点话题引入标题
《杭州亚运会开幕，但你还记得33年前在北京唱亚洲雄风的刘欢如今苍老成这样？》

**5. 作比较：** 形成反差和对比
《真正聪明的人，往往很少交朋友》
《35岁月薪3500，你拿什么安身立命》
《为什么方便面就有大品牌，挂面却没有》
《总是踩点进办公室的人，一年后和提前5分钟进办公室的人差在哪》

**6. 权威稀缺：** 提供独家信息
《人民日报》：人之所以要努力，是为了当自己遇到喜欢的人和事的时候，除了一片真心，还有拿得出手的东西
《张小龙首次公开演讲，官方无删减版》
《离职前，我把运营黄埔军校阿狸的干货都供了出来》

总之，吸引点击的标题往往特别口语化、甚至看着有点“low”，不需要文采，只需要换个写法。

1）《我65岁，再婚老伴每月退休金9000，直到外孙生日，才发现老伴骗了我》——金钱+悬念，爆了40万+阅读，收益3000多，分发头条也爆了35万。

# 3.3.4 点击率超70%的标题心法（开卷🌀）

做自媒体，选题定生死，标题很大程度上决定打开率。我的主账号爆款点击率70%以上，配图大多是免费通用图，核心全在标题。处理方式两种：直接沿用，或按经验改写。

# 3.3.4.1 拿来就用

很多人有精神洁癖，不愿用别人的标题。想想小时候写命题作文——选到好选题，对方标题不错，就当命题作文写自己的观点。小红书经典爆款选题如“一个普通女孩的十年”“99年自媒体一年，一个人赚了30W”“我发现，不上班的出路比你想象的多”，各平台各领域都经典。写这些选题不是谁抄谁，就像没人规定鲁迅写了《纪念刘和珍君》别人就不能再写，只要不抄袭洗稿，谁都能写。

# 3.3.4.2 按经验改造

前面说“觉得对方标题还不错”就用，新手最难判断什么算不错。有人把爆款标题改得平平无奇，因为觉得“这是我原创的，要和别人不一样”。原创可以，但得加入自己的思考。比如看标题里有没有开幕雷击七要素中的至少两个。选题不错但标题还有优化空间，就按【开幕雷击元素+爆款标题套路】去改。经验来自多刷对标，不只公众号，抖音小红书同方向爆款也多刷。

常见问题：既然选题定生死，标题无所谓，内容好就行？真不是。面前两个女生，一个精致到头发丝，一个邋里邋遢，你先跟谁搭讪？标题和封面是门面，像人的外表；选题是灵魂。没人有义务透过平庸外表看你精致的灵魂。好标题和配图的威力，刷过小红书都见识过，精致高级本身就是魅力。

# 四、【项目实操 3/3】公众号如何变现

公众号收益按阅读量算，本质是流量生意。流量长尾很长，很久以后还有源源不断的流量。建议文章写到1200字以上，能插两条广告增加收益。

公众号不用自己提现，每月收益自动打到开通流量主时绑定的银行卡，次月1号和15号分别入账，哪怕一分钱也准时到。

目前爆文主要两种变现：广告变现和打赏变现，前者为主，后者偶尔加鸡腿。本章详细讲这两种。本章主要介绍变现方式，不设航线图任务。

# 4.1 公众号靠什么赚钱

收益按阅读量算，流量越高收入越高，流量长尾长。流量单价由很多因素决定：文中和文末广告展示量、点击量、完读率等。文章最好1200字以上，文中可插两条广告；800字左右只能插一条。

# 4.2 公众号的赚钱路子

两种：广告变现（主要）、打赏变现（次要）。

# 4.2.1 广告变现（主力）

广告变现指文章中插广告，如小程序、游戏、电商卡片，点击本身或点击后消费都有收益，或者文章本身就是广告文。目前四种方式。
