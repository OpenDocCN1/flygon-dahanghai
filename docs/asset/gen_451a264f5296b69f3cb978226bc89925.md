# 绩效考核，别只拿来分钱

团队规模还小的时候，全员放进同一套强制分布里操作就行；等人多了，就要以部门或小组为单元来落地，而且这个单元的人数最好超过10人。

[PRE0]

具体比例并非一成不变，而要跟着业务阶段走：业务进展顺、想给队伍打气，可以把优秀、卓越档的比例调高；业绩承压、需要提醒甚至汰换后进者，就适当提高待发展及以下档的占比。

如果希望个人表现和团队成绩绑在一起，还可以让各部门/小组根据自身考核结果采用差异化分布。比如部门拿到A优秀或S卓越，成员就能多分到A/S，少评甚至不评C/D；部门结果不理想，则反向调整。

部门/小组人数很多，超过30人时，一些管理者还想把“胜任”群体再拉开层次，让奖金分配、晋升发展更有区分度，这时可以增加B+和B-两档。

## 4. 考核结果可以怎么用

不少创业公司把考核结果只当成发奖金的依据。这样做不算错，但确实可惜。人才选用育留的多个环节都能用上考核结果，包括奖金分配、晋升淘汰、任务选择、荣誉表彰、经验分享、人才盘点、人员招聘和考核体系优化。下面逐项说。

**1）奖金分配：规则要透明**

这里最容易踩的坑，是绩效和奖金之间的规则说不清楚。原本想做到公平公正的考核，反而容易被员工怀疑成暗箱操作。

有些公司的原则里写着“视考核情况酌情分配奖金”。什么叫酌情？员工会怎么想，又凭什么信服？

如果考核体系刚运行不久，对客观性还没底，不敢把全部奖金都和绩效挂钩，可以把奖金拆成两块：一块是绩效奖金，直接与考核结果联动；另一块是专项奖金，跟营收、利润等容易评估的指标挂钩，设置阶梯式提升比例，形成双重保险。

其中直接挂钩考核结果的绩效奖金，建议创业公司别设计得太复杂。最常用的方式是系数法，也是设计考核体系时常见做法，示意如下。

绩效系数影响的是绩效工资部分，不是基本工资。系数能上下浮动多少，一方面要看公司人工成本测算，另一方面要结合岗位对业务的影响和岗位性质做微调。

**2）晋升淘汰：用评级立规矩**

可以依据考核评级设置晋升、淘汰条件。比如年终考核或季度考核连续2次拿到S卓越，获得晋升与加薪机会；A优秀可以加薪；C待发展降职或降薪；D不胜任则淘汰。部分管理类岗位竞聘，也可以把考核要求设为资格门槛。

**3）任务选择：让结果影响机会**

A优秀/S卓越的员工，可以有资格承接标杆项目、开拓性项目、高利润项目，甚至在新赛道上拿到与业绩兑现挂钩的股权。C待发展/D不胜任，则需要服从强制性分配。

**4）荣誉表彰：把行为讲清楚**

对A优秀/S卓越员工，可以做有仪式感的荣誉表彰、先进评优、榜样故事撰写，立标杆时重点宣导行为事迹。不要只夸个人，一定要讲清楚他做了什么、表现出什么行为，才取得成绩并受到表彰。

对团队、部门乃至公司，每当出现关键的、标志性的成果，也可以设计仪式感庆祝。有一家创业公司准备了一面系着大红绸的铜锣，谁完成自己的关键成果就去敲响它，公司用拍立得拍下来贴在旁边墙上，写明完成了什么挑战。敲锣成了很多人期待的荣誉。

**5）经验分享：把个人能力变成组织能力**

组织A优秀/S卓越员工做优秀经验分享，把“大牛”的能力及时沉淀为团队和组织的能力。创业团队要逐步减少对个别大牛的强烈依赖，避免其情绪和业绩波动大幅影响公司。最有效的办法，就是萃取大牛经验，这也是培养发展团队的有效方式。C待发展/D不胜任的情况，也可以组织小范围负面清单复盘。

**6）人才盘点：盘人和盘钱一样重要**

对公司和管理者来说，盘人的习惯和频率应该像盘钱一样。通常可用“绩效—潜力”九宫格盘点团队成员，时时警惕，确保人才队伍能支撑业务。结合盘点结果，及时调整人才选用育留策略。

[PRE3]

**7）人员招聘：让考核反推招聘**

考核结果也能用于招聘策略。一方面，结合考核指标调整招聘要求，尤其是冰山以下不易改变的性格、价值观和驱动力。比如有家公司给做出纳岗的价值观要求是坐得住、有耐心，但招聘时对所有岗位都要求有野心、勇于挑战，这显然相互矛盾。另一方面，结合考核结果和人才盘点，及时调整招聘策略，补足团队短板，或引入能激发鲶鱼效应的成员。

**8）优化考核：每次出结果都复盘体系**

还有一个常被忽略的用法：每次考核结果出具后，对照团队和公司目标达成情况，再复盘绩效考核体系是否合理、有效，不断迭代优化。对处于敏捷行业的创业公司，这一点尤其重要。

## 5. 考核结果怎样反馈辅导

这里最大的坑，是考核结果出来、应用完就结束了，员工却一脸茫然：好或不好，都不知道为什么。

考核是管理工具，不是目标。最关键的是让员工知道：什么行为值得鼓励，什么行为不好、为什么不好、正确做法是什么、接下来怎么调整提升。否则考核的价值和意义就很有限。

我也见过好一点的公司，会要求管理者做绩效反馈。但反馈什么、怎么反馈、怎么和员工沟通，全靠个人本事。结果反馈了还不如不反馈，矛盾反而更深。员工边哭边吼：“你凭什么说我不努力，你了解过我经历了什么吗？”然后拍桌子走人。

所以考核后，不仅要安排管理者做一对一反馈辅导，更要提前给管理者做反馈辅导培训。绩效反馈辅导对管理者很有挑战：做得好，士气大振；做不好，军心不稳、骨干流失。

**1）先解决管理者愿不愿意做反馈**

管理者对下属做反馈辅导，同样会遇到“想不想做、能不能做、会不会做”的问题。

[PRE4]

**2）再补上反馈辅导技能**

管理者给下属反馈时，常会遇到棘手情况，因此相关技能也要培训。

[PRE5]

分享几个实用技巧。

第一，基于行为和事件反馈。

反馈行为及行为评价，可以沿用BEI行为事件沟通法。千万不要只给主观评价，比如“我觉得你沟通能力不太行，需要提升”“好几个人说你沟通表达不太好”。这种表述容易激发矛盾和逆反；即使是夸奖“你沟通表达能力很强”，听起来也像场面话，不够真诚。一定要基于行为来反馈。

[PRE6]

可以让对方分享自己的经历和典型事件，也可以描述你观察到的事件、他的角色、行为，以及行为产生的结果和影响。必要时，还可以对照拆解一个标杆人物的事件和行为，这样会很有说服力。

第二，辅导个人能力提升和职业规划。

这里要用的能力和技巧更多。比如基于大五性格职业优势模型，帮他分析天生的优劣势。

[PRE7]

基于职业锚驱动力模型，分析员工的职业动力在哪里、看重什么、适合负责什么工作，以及近期表现与驱动力是否被满足之间的关系。

[PRE8]

基于GROW模型帮他梳理下一步提升计划，一起探讨目标设定、现状差距、选择方向、行动计划，并在过程中有效跟进、辅导、支持和肯定；基于能力意愿矩阵，和下属探讨下一步管理策略。

[PRE9]

也可以不拘泥于工具，管理者可以寻找最适合的方法辅导下属成长。

## 三、总结：体系落地，关键看管理者

绩效管理非常考验管理团队的综合能力。它会涉及业务规划、公司愿景、价值观、员工岗位适配、培养发展、激励保留、员工性格与驱动力分析、矛盾冲突分析解决等一系列问题。

考核体系设置得再好，最后都要靠管理者落实，所以管理者能力是考核效果的关键。需要提前给管理者赋能，包括但不限于：

1）公司业务目标、发展愿景、阶段重点、企业价值观等，管理层要达成一致。
2）不同部门/小组的核心价值、关键重点、如何协同，管理层要精诚合作。
3）不同岗位的岗位价值、岗位职责、考核要求，相应管理者要清晰明确。
4）针对性的绩效反馈辅导能力培训，比如反馈时如何处理负面情绪、怎样做建设性反馈等，管理者要掌握到位；而且反馈辅导不只针对考核结果，日常工作行为也需要及时反馈。
5）员工职业发展规划技能，比如优势定位、成长地图、培养发展等，管理者要擅长。
6）其他方面：管理者自身领导魅力、管理层彼此磨合、表率作用、对人性的洞见、对业务流程的提效管理等。

这些都会影响绩效考核的最终效果。

绩效考核是一件路漫修远、任重道远的事。团队小的时候，往哪里跑喊一嗓子可能就好了，方向错了再喊一嗓子也许能回来。但当团队大起来、业务复杂起来，几十人、数百人甚至上千人一起冲锋，指挥棒就必须迭代升级，让方向目标、关键结果更聚焦、更系统可控。

搭建绩效考核体系，不必第一次就追求完美。在执行过程中不断复盘、优化、迭代，可能是更好的选择。在这件事上，小碎步跑，也会很快。
