# 3.1 哪些资料值得纳入管理？@洛羽

动手整理之前，先别急着建一堆文件夹。真正该做的，是把手头的资料按用途和重要程度分清楚。

日常会反复用的，比如工作文档、项目过程稿、学习笔记和常用模板，适合放在随手能取的位置；需要长期留存的，比如合同、票据、证件扫描件、重要记录和旧版本备份，则要单独归档，定期检查；灵感素材、图片视频、参考链接这类内容，最好按主题收拢，免得用的时候找不到；多人协作的文件，要统一命名和存放位置，减少重复发送；账号信息、密钥、隐私材料等敏感内容，则必须加密并限制访问。临时文件也别放任堆积，设个周期清理，能省下不少检索成本。

资料管理的第一步，不是挑工具，而是认清类型。类型分对了，后面的命名、归档、备份和清理才有依据。@洛羽
