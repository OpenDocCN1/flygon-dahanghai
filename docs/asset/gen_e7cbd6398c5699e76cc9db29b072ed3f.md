# 1.1.3 除了股票房产，还能看什么

把股票、房产的投资经历与Web3相关投资并排来看，反差相当直观；这是回望最近两年的感受。

再把时间轴拉长到十年：全球范围内涨幅最突出的资产是什么？答案指向数字资产比特币。这不是观点，而是已经发生、可查的数据事实。

同一时期，美股龙头苹果从90走到150，约1.7倍；谷歌从1460到2900，约2倍。A股和港股同期却是负增长。

需要再次强调：这本手册不构成投资建议，只是为大家展示一种理财配置的新渠道可能性。

有个故事挺有意思。BTC China的掌门人曾与当时对Web3还陌生的赵长鹏聊起数字资产，建议他拿出10%的资产换成比特币：归零的概率很低，翻10倍反而更值得期待；若真翻10倍，整体资产就翻倍。赵长鹏听完，先把自己在上海的房产出手，换成比特币，接着踏上Web3创业路。今天，他已是Web3世界最富有的男人，出现在福布斯全球富豪榜TOP20。
