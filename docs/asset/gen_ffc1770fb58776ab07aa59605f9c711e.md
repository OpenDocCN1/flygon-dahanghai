# 4.2 基础时间规划四步法

基础时间涵盖睡眠、饮食、清洁与家庭，这部分安排起来并不复杂，只需四步：记录、调整、固定、优化。

第一步：记录

前文提到过，人往往是习惯的产物，很多行为都在“不知不觉”中发生，基础生活领域尤其如此，只是我们极少以旁观者的眼光审视自己。而睡觉、吃饭、清洁、家庭这些基础事务每天都会发生，日积月累，其中被浪费的时间相当惊人。比如早起这件事，不少人一睁眼就习惯性拿起手机刷个不停，一晃半小时甚至一小时就没了。这个不起眼的坏习惯，不仅毁掉了宝贵的晨间时光，还让大脑在一天刚开始时就接触大量高刺激、易获取的信息，等到白天工作时，反而很难集中注意力去处理真正有难度的问题。因此，记录的意义就在于，先把一天从醒来到入睡的全部时间完整记下来，看清楚自己行为里的惯性模式。

第二步：调整

举个例子，如果你通过记录发现自己一睁眼就刷手机，直到不得不起来，整个早晨都被耗掉了，那就把醒来后的这段时间改成坐在书桌前读半小时或一小时书。同样的时段，内容就从“刷手机”变成了“阅读”。再比如，有些女生通过记录发现，每天早晨纠结穿什么、反复试换，能花掉半个多小时。那就可以把“挑衣服”的时间挪到前一晚睡前，顺便整理好衣橱，搭配出几套固定组合，第二天起床直接选一套穿好出门。这些一点一点调整出来的时间，经年累月，积少成多，能帮我们避开大量无谓的消耗。

第三步，固定

想改掉一个旧习惯，最有效的方式是用新习惯去覆盖它。但旧习惯之所以顽固，是因为它已经在我们的日常节奏里扎根很久。所以，当我们用早起阅读取代早起刷手机之后，还需要持续坚持一阵子，靠反复重复让新行为稳定下来，最终让好习惯真正替代坏习惯。

第四步，优化

从原则上讲，基础时间越有规律越好，比如在固定的时间入睡、起床，刷牙洗脸的时长也尽量固定。在这个过程中，我们还能继续挖掘优化空间。比如刷牙时顺便煮上鸡蛋，休息时靠着墙站一会儿，同时看一部喜欢的电影；再比如把打扫卫生拆开，每天下班到家先花10分钟随手收拾，每周五或周六再集中3小时做一次大扫除。这些细节上的打磨，都是实践中慢慢摸索出来的，积累久了，就会形成一套属于自己的高效基础时间安排。

拿我自己来说：睡眠方面，通常23:30到0:00之间上床，早上7:00到7:30起来。三餐时间比较固定，早餐8:15到8:30，15分钟；午餐12:00到12:20，20分钟；晚餐18:20到18:40，20分钟。洗漱方面，早上洗漱加化妆大概30分钟，晚上卸妆加洗漱约15分钟。打扫方面，我习惯每天随手收拾10分钟，每周五或周六再做一次3小时的大扫除。家庭方面，每天跟家人通话至少30分钟。休息方面，每工作50分钟就休息10分钟。

等你坚持记录一段时间，也会对自己的基础时间了如指掌。毕竟这部分是每天的固定开销，完全不必为此焦虑。既然吃饭这件事每天必须花时间，那就安心吃饭，别在餐桌上还想着工作、想着客户。其他基础事务也是同样的道理。

在基础时间这块，有两件事需要特别提醒。

•关于睡眠：想保持高效的生活，规律且高质量的睡眠至关重要。提升睡眠质量并不难，和时间规划一样，睡眠也不适合一上来就强行规定。可以分三步走：先监测睡眠，再找出规律，最后优化作息。市面上能记录睡眠的工具不少，比如手环、手表、App等等，按自己的情况选一个顺手就行。偶尔熬夜或失眠都很正常，关键是通过监测和调整，尽快回到正常的睡眠轨道。另外，社群里的杨涛同学也分享过不少改善睡眠的技巧，有需要的话可以直接跳到10.3查看。

•及时休息：现在的办公场景大多需要坐着，但久坐带来的危害远超我们的想象。第一个事实：久坐和多种疾病有关联，比如容易引发颈椎病、腰椎间盘突出，减少肌肉量，增加内脏脂肪，还会让2型糖尿病风险升高88%，心脏病风险升高14%，肺癌风险升高27%，肠癌风险升高30%，子宫癌风险升高28%。至于这些数字是否精确，并不重要，我们只需要记住一点：久坐会伤害身体的方方面面。第二个事实：运动并不能抵消久坐的负面影响。哪怕你每天坚持运动两小时，也无法弥补连续坐六七个小时甚至更久给身体造成的损伤。所以，与其把重心全放在加强运动上，不如先做到及时起身休息。
