# 1.1.4 朋友圈到底该发什么？ @小女巫忻忻

不管卖的是实物、课程还是服务，销售的逻辑从来都没变过，朋友圈营销只不过是在另一个场景里完成这件事。

真正拉开差距的，不是文案技巧，而是你有没有在刚开始就想清楚：你打算让刷到你朋友圈的人，看到什么样的“规则”和“信息”。

这里有两个核心维度值得反复确认：

- 你这个人本身是否鲜活、真诚，并且能让人一眼看出“关注你能得到什么”
- 你对别人而言，究竟能提供怎样的价值——是情绪上的共鸣，还是专业上的干货

如果你是卖课的，那你朋友圈唯一的呈现重点，就是：你的方法能不能真正帮到别人，并且让他们学得懂、用得起来，不用费太大力气就能拿到结果。

朋友圈其实有一条底层逻辑，叫「销售生活化」。大家刷朋友圈的原始动机，并不是看广告，而是满足一种对他人生活的好奇。他们想了解你这个人，而卖货卖课，只是顺带的附加需求。

说白了——如果你的朋友圈内容连让别人“想认识你”的吸引力都没有，那凭什么指望别人愿意为你背后的产品买单呢？

想清楚你想表达什么，比急着发什么更重要。
