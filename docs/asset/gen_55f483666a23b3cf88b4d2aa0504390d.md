# 老人洗澡也能上门？深圳卫健委这条消息引发热议

深圳市卫生健康委近期介绍了一项面向老年群体的上门洗澡服务，相关消息发出后，迅速引来不少网友围观和讨论。[PRE0]

对许多家庭而言，高龄、失能老人如何安全舒适地洗澡，一直是个现实难题。官方层面推出居家助浴服务，自然容易触动大众对养老照护的关注。[PRE1]
