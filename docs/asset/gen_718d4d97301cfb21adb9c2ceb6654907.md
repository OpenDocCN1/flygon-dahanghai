# 2.4.1 区块链的“不可能三角”

在区块链世界里，有一个绕不开的底层规律：一个网络很难同时实现“性能优越”“高度去中心化”和“极致安全”这三件事。这就是常说的“不可能三角”。

这里说的性能，其实可以通俗地理解成处理交易的速度和效率。

纵观比特币这类传统链，它们在这三角之中，明显更侧重于去中心化与安全。为了确保账本由全网共同维护、数据几乎不可篡改，它牺牲了效率，转账有时候要等很久，遇到高峰期甚至好几个小时都到不了账。

以太坊也没能躲开这个难题。随着生态越来越庞大，网络的处理能力逐渐跟不上需求，也成了它成长路上绕不过去的坎。因此，今年以太坊正大力推动二层扩容方案，本质上就是在为算力瓶颈寻找突围的口子，试图在不牺牲核心特性的前提下，把效率提上去。

反观我们天天在用的 Web2 互联网，效率和规模化做得相当到位，体验流畅、承载量大，几乎把“可扩展”和“安全”打磨到了极致。但这背后，网络走向了高度中心化，普通用户的数字资产与个人数据，实际上都交由平台掌控，用户自己反而失去了对网络的所有权。

也正因为去中心化程度各有不同，目前一种常见的分类方式是把区块链划分为公链、联盟链和私有链。关于这一点，我们在后面的章节中会详细展开。

自区块链技术问世以来，各类公链项目本质上都在这个三角框架内寻找平衡点，努力在取舍中做出最优解。下面我们就来逐一细细剖析。
