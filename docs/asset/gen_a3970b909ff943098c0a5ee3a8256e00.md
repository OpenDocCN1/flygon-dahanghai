# 3.8 吸睛开头：前三行就抓住人 @李思念

朋友圈内容在信息流里通常只露出三行，所以一条文案能不能让人停下来，开头几乎起了决定性作用。下面分享几种我常用的吸睛开头方式：

1. 悬疑式开头

先用悬念把读者的注意力钩住，让人产生好奇，忍不住继续往下看，从而起到引导营销的作用。

比如可以这样写：

「客户突然来一句“你把我害惨了”，我当场愣住……」

「不好意思，今天我要自曝了！」

2. 对话式开头

直接发硬广容易显得生硬，一个讨巧的办法是把一段对话截取出来作为开头。对话天然带有窥探感，读者会想知道双方聊了什么、为什么会出现这句话，于是更容易读下去。具体操作时，可以用双引号把对话放在文案开头，而引号里的内容必须是最抓人、最有爆点、最能点题的，比如客户对你的表白、感谢，或者聊天中最出彩的那句话。

比如：

「“思念，你那条圈让我突然想通了”」

「“这堂课干货太密了，我反复看了好几遍，太喜欢了”」

「她说“老师你可能不信”，我回她“我信，因为我见过太多表面风光的创业者了”」

3. 融入数字

一篇文案里，数字往往是最先跳进读者眼睛的元素。它能把重点顶出来，快速抓住注意力，所以写文案时要学会多用数字。发朋友圈时，还可以把数字做成花字或 emoji 数字，让它们更显眼、更吸睛。
