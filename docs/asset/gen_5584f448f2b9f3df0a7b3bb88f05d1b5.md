# ControlNet 1.1 新功能速览

ControlNet 1.1 这次加入了一个叫“SoftEdge_safe”的新软边缘方案。原因在于，HED 或 PIDI 在做软估计时，容易把原图里损坏的灰度版本悄悄藏进去；这种隐藏模式会抢走 ControlNet 的注意力，最后效果就不理想。解决思路是先做预处理，把边缘图量化成多个等级，从而彻底清掉隐藏模式。具体实现放在 annotator/util.py 第 78 行。

性能大致可以这样记：

鲁棒性：SoftEdge_PIDI_safe > SoftEdge_HED_safe >> SoftEdge_PIDI > SoftEdge_HED  
最高结果质量：SoftEdge_HED > SoftEdge_PIDI > SoftEdge_HED_safe > SoftEdge_PIDI_safe

综合权衡后，建议默认选 SoftEdge_PIDI，大多数场景都够用。固定种子 12345（“a handsome man”）：

**语义分割**
用语义分割来控制稳定扩散出图。不同颜色代表不同物品和场景，识别之后可以手绘对应物品的颜色上去；颜色与物品的对应图网上能搜到。模型文件：control_v11p_sd15_seg.pth；配置文件：control_v11p_sd15_seg.yaml；训练数据：COCO + ADE20K。可接受的预处理器包括 Seg_OFADE20K（Oneformer ADE20K）、Seg_OFCOCO（Oneformer COCO）、Seg_UFADE20K（Uniformer ADE20K），也支持手动创建的掩码。现在模型能接收 ADE20K 或 COCO 两类注释。我们发现，让 ControlNet 编码器识别分段协议并不难，而训练支持多种分段协议的模型还能带来更好表现。以 12345 为种子，ADE20k 协议、“house”：

**Openpose 骨骼识别**
这就是俗称的骨骼识别：用骨骼图生成图片，用来固定人物姿态和动作。这次还新增了面部表情识别。动作和表情怎么组合？这里不展开，感兴趣可以自行研究。使用 Openpose 控制稳定扩散。模型文件：control_v11p_sd15_openpose.pth；配置文件：control_v11p_sd15_openpose.yaml。该模型训练时可接受这些组合：Openpose 身体、张开手 Openpose 脸、Openpose 身体 + 手、Openpose 身体 + 脸、Openpose 手 + 脸、Openpose 身体 + 手 + 脸。不过把所有组合都摆给用户太复杂，建议只留两个选项：“Openpose”=身体；“Openpose Full”=身体 + 手 + 脸。

这次改进主要来自我们对 OpenPose 实现的优化。我们仔细对比了 PyTorch 版 OpenPose 和 CMU 的 C++ OpenPose，现在处理器应该更准确，尤其是手部；处理器变准，也带动了 Openpose 1.1 的提升。它还支持更多输入，包括手和脸。此前 cnet 1.0 的训练数据集有几个问题：（1）一小部分灰度人像被复制了数千次，导致旧模型有点容易生成灰度人像；（2）部分图像质量低、很模糊或有明显 JPEG 伪影；（3）数据处理脚本出错，使少量图片的配对提示有误。新模型修复了这些数据集问题，很多情况下会更合理。固定种子 12345（“man in suit”），未经挑选的批次测试：

**Tile 拼接（模型还未完成）**
简单说，就是把一张图切成多张小图，再对小图做细节化重绘，完成后拼回原图。用 Tile 控制稳定扩散。模型文件：control_v11u_sd15_tile.pth；配置文件：control_v11u_sd15_tile.yaml。越来越多人想用不同办法在拼贴处做扩散，让图像能做到很大，比如 4k 或 8k。问题在于，Stable Diffusion 里提示词总会影响每个板块。比如提示是“a beautiful girl”，把图分成 4×4=16 个 block，每个 block 做扩散，你会得到 16 个“beautiful girls”，而不是一个“a beautiful girl”。这是众所周知的问题。现在常见的办法是用“清晰、清晰、超清晰”这类无意义提示去扩散块，但可以预料，去污强度一高结果就很糟，而且提示糟糕时内容会非常随机。ControlNet Tile 就是来解决这个问题的：对给定图块，它会识别内部内容，并增强识别语义的影响；如果内容不匹配，还会降低全局提示的影响。固定种子 12345（“a handsome man”），未经挑选的批次测试（看左边上传图片里圈出的小框，右边 6 张是重绘框内图像）：

问题二：如果报错说页面文件太小怎么办？
解决办法：参考以下步骤设置虚拟内存。
1. 打开“我的电脑”，在系统桌面找到“此电脑”图标，右键点击，在弹出菜单里选“属性”。
2. 打开系统页面后，点击左侧导航栏的“高级系统设置”。
3. 在系统属性界面点击“高级”标签，在性能一栏下面点“设置”按钮，进入性能选项页面。
4. 在“性能选项”窗口点击顶端“高级”标签，在“虚拟内存”一栏下面点“更改”按钮。
5. 在弹出的虚拟内存窗口里，点击“自动管理所有驱动器的分页文件大小”复选框，去掉小勾。
6. 点击系统所在驱动器，再点“自定义大小”，在“初始大小”和“最大值”输入框里填入设定数值，最后点“设置”按钮和底部“确定”。切记一定再点一下设置按钮，不然不生效！建议设置大一些，不够再加，记得确认；不想玩了记得改回来。

# 六、学习描述词 @天辉 @大刘 @瑾糖🔥

描述词也叫关键词、提示词，是学 AI 绘画很关键的一环。简单说，就是学会和 AI 沟通的语言，让它听懂你的需求，画出你想要的画面。会表达，就相当于会画画；会调数字，就相当于会改图。想学好 AI 绘画，学描述词是绕不开的一步。

早期我会推荐用对标模仿的方式去写描述词，因为描述词对画质影响很大，而且一张图产出要很久。但现在技术变了：对 MidJourney 来说，描述词已经没那么复杂，也能画出好看的图；对 Stable Diffusion 来说，模型和各种插件带来的效果更强。所以我的建议是，先简单了解描述词的逻辑，然后直接上手，用自然语言描述画面。简而言之，【我想画一幅什么样的图片】比描述词技巧更重要。当然，这里仍会给大家大量描述词参考，毕竟对新手来说，通过复制粘贴来熟悉，是最方便快捷的方式。
