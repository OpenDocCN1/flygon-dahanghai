# 写作变现：先被看见，再被选择

[PRE0]
有天夜里，主编突然丢来一个毛晓彤热点选题。第二天清晨六点我就开工，心里绷得很紧。虽说在百万流量号上写过稿，可这次面对的是300万粉丝的高质量心理号，门槛不低；而我投稿才两个月，写急稿又慢，既要立观点又要找素材，折腾一天多才改完，中间还暴食了一顿KFC。

[PRE1]
这篇热点稿情况特殊，编辑会帮着改，排期也往后挪，上线首小时3万阅读，之后冲到10万+，稿费800。对新人来说，如果只盯着小号投，过稿影响力有限（少数中小账号走精品路线、被大号转载后能做背书，另当别论），变现和影响力起步都慢，可能半年才挪一小步。所以，新人要主动给自己制造曝光和传播的机会。

[PRE2]
第一篇10万+出来后，我把能发链接的群几乎转了个遍，也请朋友帮忙转发。这里有个提醒：变现成绩还少时，最好别让家里人知道你在做写作变现，容易被泼冷水。文章链接也发到朋友圈，让编辑刷圈时能看到。很快，之前加过微信但没合作过的编辑来约稿；从那以后，我不再到处开发新号，而是集中给几个号写（同时看性价比），一边积累过稿数量，一边稳稳赚钱。阅读数据好的文章链接整理成文档，拿去向优质账号编辑要选题；后来进了摆渡人作者群、百万粉inslady作者群等，稿子越写越多，稿费也上了台阶。用10万+作品和优质文章当跳板，去挑战更大的号，才能拿到更多文字变现机会和荣誉感。人往往因为看见成果而受益，才愿意做得更多。其实写作变现按年统计，总金额高的人并非只写高质量文章，而是质量文和流量文都能接。用文字传递正能量、输出深度思考，或提供饭后闲聊的热搜瓜流量文，本身没有对错。保证正常写作频率、持续输出有深度有观点的质量文，同时适当接一些流量文赚稿费；经验不多的人写流量文月入2000—3000，一年下来也是一笔钱。

-03- 先借流量涨粉，再靠内容破圈，混对圈子才会被更多人看见

前半部分我聊的是怎么快速投稿变现、积累代表作、和编辑打交道，以及新人如何初步搭起自己的写作人际圈。接下来问一句：你想每个月靠文字赚多少？人的精力有限，就算不睡觉，每月能写的文字量也是固定的。同样是写字赚钱，为什么有人只赚一点，有人能赚几万？只靠文字、没有圈子资源支撑，收入很有限。一个写作变现半年的人，如果只给几个号写稿，不从圈子资源里裂变赚钱路径，每月大概1000—6000。很多人闷头写稿或埋头做自己的平台，没有和编辑、平台运营打交道的意识，也没把文字变现做大（可能月入5000就满足），或者没把写作当成长期技能。和编辑、平台运营打交道，是了解市场的一种方式，也是敲开他们背后资源的路径之一。有流量思维的人和闭门造车的人，时间一长，方向、成长速度和收入都会拉开差距：闭门造车的人不做推广，或用传统买流量的方式慢慢推；有流量思维的人会借平台或大V的势，借资源为自己赋能，用价值换价值。想长期靠文字赚钱，从一开始就要有意识地用作品积累背书、打造私域流量，并加入合适的圈子，把写作技能和自己的专业领域结合起来赚更多。下面讲新人如何用内容扩大影响力，一边用文字赚钱，一边结合个人优势和所处阶段找到合适的圈子。这些方法同样适用于学流量增长、品牌营销、视频营销等。

[PRE3]
一、把作品铺到多个平台
知乎、抖音、视频号、小红书等都可以。不管有没有过稿，日常写的内容都要坚持分发；投稿过稿的内容在账号发布后，记得和编辑申请转载，也就是“开白”。

二、过稿后进作者群，别浪费群里的机会
有些账号有作者群，你过稿后编辑会邀请你加入，群里可能经常放内部选题（有的号没有）。进群有两个好处：第一，增加变现机会；第二，链接群友，发展成共同好友后再转介绍，有机会进入新圈子，或被推荐去链接新的账号平台（资源优劣取决于你所在写作阶段和人脉质量），从而拿到更多投稿渠道，加快变现。

[PRE4][PRE5]
那张配图记录的是：我加入某号作者群后链接群友，从相知到相交，最后得到了想要的收稿平台编辑微信。你要主动一点，用“交到新朋友”的方式做裂变，获得新资源。

三、和编辑、平台运营建立深关系
第一，约稿量增多，变现金额也会增多；第二，表现优秀的人可能被推荐给其他号写，这也是资源裂变；第三，编辑可能引荐你做文字类兼职，比如兼职责任编辑等。

四、用分享会把自己推到台前
写作分享会或专业领域经验分享会，可以自己办，也可以借他人平台宣传。
1. 主动开分享会：做一个细分、明确的主题（主题清楚与否，直接关系到能招来多少人），请朋友转发直播信息，听分享可以设抽奖等。
2. 自荐或受邀参加行业里、圈子里的大小分享会（不限于写作社群），把自己推广出去。

[PRE6]
五、进社群：让别人记住你、信任你
用内容形成记忆点，获得信任，扩大影响力。
1. 写作爱好者群（免费居多）：写作打卡群也算这类，资源几乎为0，属于向下兼容新人小白，不建议投入太多精力和体力。刚学新媒体写作时，我加过许多小白交流群，那阵子看着很“忙”，其实多是无用功。实力不足时，把大部分精力放在提升个人能力和出成绩上。这类群资源很少，链接到写作变现行业群的机会是0（20、30块低价稿费群不算）。
2. 学习群（付费写作班也属于这类）：以学习、精进写作力为主，质量可以，优质资源不多，可以适度链接。在里面找和你水平相当或比你成绩好的人，互相激励、点评、改稿。给别人做改稿练习，也是促进自己写作力的一种操练；指出对方不足，也是在帮对方进步。进入行业资源群的可能性小。和爱好者群一样，属于用时间换价值，向下和平级兼容，把自己变成学霸做影响力。
3. 关于写作班：学写作绕不开这个话题，我简单说下看法。
[PRE7][PRE8]
市面上的写作班林林总总，优秀老师很多，你能学到一定写作技巧和部分实战经验。前期可以依靠写作班多写多学，多写多过稿做背书。若想长期文字变现、扎根写作领域，就要追求更高的地方。在写作班里，出成绩八分靠自己，两分靠你选择的老师和背后资源优劣；选择写作班只是学写作的一个动作。我在写作班学过一段时间，后来自己写投稿、接稿、写文案，7月开了付费咨询，一边写稿一边自己接单，后来做写作班。写作班的正确玩法：开局选2个学员做假想敌（不要告诉对方），结交3—5个高频交流的好友（从学员自我介绍里选你感兴趣的，或有成绩的人），链接在精不在多；这几个人要能一直陪你成长，最好都追求变现方向，后面能一起做事。
4. 行业群：
1）以自媒体号主群体为主的群：了解行业风向、互推、广告位等，链接力视具体群而定，有机会进入更高圈子，适合新人打开视野。
2）写作圈变现资源群（供成手作者写稿对接）：通常有职业资源人（中介）、图书出版编辑、各类图文文案需求的甲方（公号、抖音、小红书等）。资源丰富，链接力中高等，适合有写作基础、有一定过稿记录的人。想扎根新媒体文字变现，一定要进这类群。
[PRE9][PRE10]
我在写作行业资源群拿到过多份稿子变现，也通过这类群快速链接一些大的优质收稿平台并过稿，比如S叔Spenser、李月亮等。
[PRE11]
经人引荐加入圈子，用资源来写作赚钱（S叔号、暴走漫画号）。每次过稿，我都会在社群和圈子里宣传，总会有人注意到你，愿意为你赋能。
[PRE12][PRE13]
我进入的第一个写作圈资源群，是一位编辑介绍给老编辑后拉我进去的。她所在的圈子只和成熟作者、编辑、自媒体大V等接触，因为信息断层，普通菜鸟不知道，也很难联系到她。进圈一周，我便主动链接到牛人作家李月亮。这家情感号知名度高，过稿难度也高。我投了两篇：第一篇因热点事件发展不明朗、发文时机不合适没过；第二篇写古天乐，成功过稿，稿费1000+。这篇爆文首发李月亮，被十点读书转载（百万阅读、点赞1万），又被多家百万级号转载，全网阅读累计近千万，也因此成为我的大背书。链接李月亮老师后，经她不时的指导和交流，我的写作也在进步。做文字赚钱，多了解圈子，加入这类写作圈变现资源群能让你大跨步走：链接账号平台高层，得到更好的变现扶持；和平台牛人贴身学习，精进写作。
3）其他行业的群：资源较多，链接力中高等。通过加入多个高质量社群展现自己、链接他人，一边为社群贡献价值，一边做影响力，把自己当作品牌来运营；既增加变现机会，也链接不同圈层资源，找到合适的合伙人共赢。怎么做？根据不同行业群的定位和需求，做不同的分享主题。比如在生财商业社群谈“如何通过写作增加圈子影响力”，在写作圈就谈“如何写出十万加、变现经历”，用信任和价值做个人IP。案例：
[PRE14]
生财圈友孙六六介绍给我单子：改人物故事名片。还有些不同圈子的人向我咨询写作和文案约稿。加入优质社群、链接大佬，能促进你的行动和成长。生财社群大佬云集，无私分享各类行业干货经验和项目玩法，涛哥和明白是我学习的榜样。在生财，我还在线上接触到各行业精英圈友；通过生财，我也加入多个大佬的星球社群。我接触写作一年，看过生财有术多篇关于知识付费的精华帖，但在有了一定写作经验和变现力后，想开班却犯了拖延症，直到11月底看到涛哥的一篇问答文点醒了我，立马开班行动。
[PRE15][PRE16]
于是，我11月23号开始写干货，26号在某社群做分享，周末写招生广告，30号晚上在个人号发布广告，马不停蹄；从1号到4号有20多人报名付费，总共用了11天。第一次开班成功，我在群里感谢涛哥。随后，我邀请杨涛做我的付费星球嘉宾，涛哥欣然答应，让我很开心。
[PRE17]
在优质社群展示自己、参与社群活动，会让你和大佬的线上距离更近。持续和大佬打交道，让他看到你的进步和更多可能，发展成他的客户或朋友，用时间换价值，或者用价值交换。去年和今年我花几万在知识付费、加入高质量社群，不但丰富了写作变现渠道，还让我被不同圈子的人知道，是我重要的对外窗口。

六、先利他，影响力会回流
1. 帮同行点评、改稿，让对方在朋友圈或个人号表示感谢，借对方的流量积累个人影响力。
[PRE18]
帮微博千万加爆文作者陈艺华改稿，她在朋友圈感谢我。多做这样的事，就是在帮自己增加曝光。
2. 把优秀作者介绍给账号编辑。
[PRE19]
经过我的对接，该作者在账号连续过稿几篇。我和写手王渤的小故事：1）我在行业圈子里链接到她，并通过她链接到鸡汤号洞见（单篇2000）的编辑。2）我点评她的文，并把这篇推荐给樊登读书；她在这家过2篇稿后，其中一篇被洞见公号转载，增进了她的写作圈影响力。
[PRE20][PRE21]
总结一下：人和人之间的帮助是相互的。我帮助别人、真诚利他时，其实也在为自己的影响力加码；通过转介绍，我拿到一些能快速入圈的关键人脉。多做利他的事，帮别人收获成功，就是帮自己。

七、学会合作与资源置换
和其他行业领域一样，可以互推、置换、买广告位等。本段总结：写作不能单打独斗，选一些人与你同行。人们常说“三人行，必有我师”。好的写作朋友是什么样？如何筛选适合与你同行的人？我做了一份简单自检题送给你（其他行业也适用）：
- 交换信息：高频，且信息包含价值（我不排斥八卦），能让你变得更好。
- 介绍自己的朋友们相互认识：圈子人、行业人。
- 你/TA介绍资源或兼职机会给对方/你。
- 分享自己的学习经验、修改文章过程。
- 情感支持（鼓励/热情/鞭挞/安慰等正面情感）。
- 较高的认知水平，三观正（交友不慎，通常就是不符合这点）。
- 愿意购买你/TA的付费产品、内容。
按这个清单筛一遍自己朋友圈，哪些人符合至少三点？想快速提升进步，多想想“朋友”能帮到你多少、可以做到什么程度。当然，你更要努力，毕竟谁也不喜欢一条人生躺平的咸鱼。如果以上两点都没有，要么彼此领域关联太差，要么对方没想深入链接你。

-04- 写作赚钱路上，这些坑别踩

一、投稿变现：让编辑心里舒服，你才会舒服
第一，遇到投稿被拒收，不要拉黑删除编辑微信。写作圈不大，这次不合适还有下次机会，新人要多爱惜羽毛。你的产出内容好，编辑自然愿意给你选题写；有了选题，相当于有了一半上稿机会，只需注意及时写完，不放编辑鸽子。如果编辑三言两语指出你文章的缺点，这是学习提升的机会，要感谢，忌不服气。如果编辑让你改稿，说明有过稿机会，改稿调整是为了更符合账号调性。最终改了几次不重要，你的目标是上稿和影响力。改稿后如果没达到账号要求，编辑不会收，立马转投其他号。
二、不要接低价稿坑自己
我不建议写稿费100块以内的低稿费文，新人建议最多写一个月。一篇文章的产出，少不了找选题、列大纲、写初稿、修改、定稿这套工序。写10篇低价稿占用的个人精力，并不比写出一篇高质高价稿的付出少。稿费太低的平台，往往对文章质量要求极低。你有写稿的时间精力，做什么不能赚到这多篇累计的几百块呢？大平台稿件稿费高，对质量有一定要求。我建议追求高稿费，多次投稿挑战优质大平台，同时用过稿成绩增加个人影响力。每个人都有一段灵魂暗夜时刻，要靠自己独自走出幽暗小径。如果你的写作水平暂时达不到两三百块的稿费，就努力磨练功底，直到中稿，让自己的写作能力接连得到行业认可，进而走进新媒体圈子，收获更多机会。

-05- 给写作新人的几条实在建议

1. 从新手阶段就做写作成长规划
新媒体行业是淘金地，每个进来的新人都想挖出属于自己的金子。什么样的人做新媒体会有成果？1）能持续写内容：对自己研究的行业有深度认知，能持续写至少3年。2）会引流，懂得如何吸引读者。3）爱钻研，分析匹配用户需求，善于“试错”。写作这件事和其他领域一样，无论月入3000还是3万，都需要规划发展路线。我们学写作、写文章，是让自己变得更好，用文字赚钱，同时让家人的生活变得更好；有规划和自由发展的结果是有差异的。用写作打造个人品牌，提高收入，增加链接资源和机会；用写作做本职工作的纵深发展，链接客户资源；用写作做好引流，提升销售转化。进阶方向：兼职写手，视稿件难度每周过稿1—2篇新媒体长图文，不包括商稿软文；独立讲师、咨询付费IP；写作班训练营主理人/授课老师；全职方向如出版编辑、文案策划、新媒体编辑等；内容平台网赚高手；资源对接：资源/圈子/人脉；个人视频剪辑IP；抖音/视频号视频文案写手/视频剪辑讲师；剧本杀、网文小说向。其中2和3我拆开看，这两个有一定区别，几个类型都可以叠加类型6一起做。每个人写文都有擅长的文章领域类型，建议优选离钱近、离资源近并且感兴趣的方向。例如写历史文在头条吃香，可以一边带货卖书，但在公号稿子变现一般；故事文、情感文在头条和公号都是大类，变现都不错。前期写这类稿，写平台赚稿费、流量费，一边积累粉丝。当你在写作和专业领域做出的成绩越来越多，接触的交流社群增多，后期可以写卖同类型的网课，把写作技能和专业领域知识点系统化，再做海报卖课（卖写作课、卖专业课），逐步迭代课程，还可以开付费专栏做连载（头条万粉可开）。和编辑圈子做好链接，随着过稿成绩越多、文章质量好，可能有引荐接到兼职机会，例如兼职责编、兼职编辑。还有一个方向是做写作学霸IP：当你70分时，可以教50、60分的人。当你在写稿上积累了一定的写作成绩和影响力，就可以出网课了。第一批学员从哪里来？从和你一起学写作并看到你成长的人，以及各种圈子路径发展出来的粉丝里来。这个时候可以多加入一些副业变现、教人做知识付费IP的社群学习，去借势，找到合作人，推广你的课。互联网行业发展节奏非常快，做新媒体亦然。如果抱着偏安一隅的心态，循规蹈矩，不出三年，不仅新媒体小编，程序员也面临“下岗”窘况。踏实做事，在努力精通行业知识的同时，钻研迭代新媒体引流方法、写作技巧，得出自己的方法论，并勤于实践验收，积累经验。总之，新人要有自己的写作道路规划和方向，谋定而后动。
2. 行动在当下
先写作，后变现。古人说，欲先取之，必先予之。在我看来，学写作，先交出你的注意力和耐心。一个人做任何事都有成本，做事想得到即时满足，是人的天性。就写作变现而言，成果因人而异，不是每个人都能速成。但只要下定决心、迈出行动，有恒心的人结果都不会太差。我身边有的新手朋友写了3—6个月后，进步明显（公号长图文方向）。古罗马的塞内加说：“是因为我们不敢做，事情才变得困难。”你做事时的每一次犹豫、迟疑，都是对自己的精神消耗；次数多了，未战先疲。体育项目里的射箭，一开始柔缓用力把弓拉满，随即全力以赴射出。你要做的，就是成为自己的弓和箭，用全力飞驰。学写作，不要内耗自己，持续行动就对了。
