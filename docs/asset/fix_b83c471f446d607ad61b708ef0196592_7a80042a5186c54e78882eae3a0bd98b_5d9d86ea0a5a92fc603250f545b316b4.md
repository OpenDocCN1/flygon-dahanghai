# 2.1.2.3 养号这件事

账号刚注册下来，别急着发东西，先花点时间“养”一养。每天至少刷满三十分钟，让系统觉得你是个活跃用户，权重自然往上走。刷什么呢？就盯着你打算做的那个方向，多看同行的对标笔记。这个过程一般维持一到三天就够了。

# 2.1.3 开店怎么选

开头先给个结论：刚上手的朋友，优先考虑个人店；后面想铺开、玩矩阵、多店并行的，可以上个体店；至于企业店，更适合有品牌背书的商家。

接下来把📕个人店（含个人店、个体店）和企业店的区别掰开讲，大家看完再对号入座。

# 2.1.3.1 先搞清楚店铺分类

入驻之前，得先明白店型分哪几种，因为类型不一样，能享受的权益也不同。

往大了说，就两类：个人店铺和企业店铺。

不管开哪一类，头一件事都是认证专业号。新注册的号默认不是专业号，而非专业号做不了任何商业动作，薯条投放不行，开店也不行。所以想在📕变现，第一步就是把账号转成专业身份。

专业号同样分两种：个人专业号和企业专业号。

个人专业号

身份标识一般显示为“XX博主”，比如时尚博主、美食博主这类兴趣向的博主。基本申请就能过，不花一分钱。

操作路径：创作中心—更多服务—开通专业号—我是个人—实名认证—选身份证，填好资料就行。

不过医生、律师等特殊职业，得额外上传资质，还要交三百元费用：

企业专业号的营销权益通常比个人专业号多，但两者只能二选一。新手一般建议先开个人店，门槛低；企业店多用于放大矩阵，平台对账号的宽容度也更高。

# 2.1.3.2 个人店：准入条件和开通步骤

入驻门槛

个人型店铺分个人店、个体工商户店。个人店只支持服装、百货等常见类目；个体工商户店除了常见类目，还支持奢侈品、珠宝等。不同店型可经营类目不同，打勾项即可经营类目，具体到📕学习中心—规则中心—经营总览查：

[PRE8]

开店要交保证金：个人店和个体工商户店均为一千元；保健品、奢侈品等特殊类目会更高。

客服接待可二选一：平台代运营、自主客服。平台代运营收费，按自身情况选。

平台佣金即技术服务费：每单按类目费率扣，费率/算法同上。

目前为了减轻开店负担，个人店和个体工商户店入驻后不交保证金也能先发布商品上架销售；累计交易额超一万元后，七天内补缴保证金，相当于“无门槛”先把店开起来。

入驻流程

个人店：选店型后选经营类目，提供姓名、身份证号、手机号，做人脸识别，验证通过即开通。

个体工商户店需提前备好：

（1）营业执照照片、公司名称、统一社会信用代码、经营地址、执照有效期；

（2）店铺运营授权书。

注意：一张营业执照若要开两个个体工商户店，需先建两个号并升级专业号后再开店，直接开是开不了两家的。

随后同样先选经营类目，按提示上传资料。

[PRE9]

个体户店审核一般两到三天。审核期间可登录入驻系统查询。过程中有问题，九点到二十四点可联系人工客服。

# 2.1.3.3 企业店：材料多，审核细

入驻门槛

企业型店铺分普通企业店、旗舰店、专卖店、集合店。

普通企业店命名与个人店类似：“专业号账号名称+的店”。注意企业专业号取名要和商标对应，否则可能开不了店。

旗舰店名称：xxx（品牌名）旗舰店；专卖店：xxx专卖店；集合店：xxx的海外店。

企业型店铺支持大部分类目，包括保健品、医药等特殊类目。

平台佣金同个人店：一万元以下不收费，超过部分按5%收。

保证金按类目略有差异，一般境内最低两万，境外三千五百美金。

# 2.2 女装选品怎么下手

# 2.2.1 女装选品看两点

📕女装选品主要看两点：

1. 找对标爆款；

2. 找退货率低的。

如何通过对标爆款选品？

📕女装选品较简单，主要来自站内：

低粉爆款对标笔记，跟款；

及时看对标账号爆款笔记，并跟款；

没挂链接的笔记，评论区求购多、蹲链接多（说明需求多，及时找到款式上架就可能出单）。

注意：📕女装爆款很大程度受“季节性”影响，要及时关注行业风向或对标账号。

比如去🧣、抖音等热门平台看热点；当天出现爆款产品，及时到📕发笔记跟款，更容易做出爆款笔记。

如何筛退货率低的品？

女装别选特别挑身材的，最好通版。

新手不建议选新中式、国风、连衣裙等。虽然这些在📕较火，但不是大部分人都能穿，很多人自我感觉好看就下单，退货率非常高。

推荐方向：开衫、衬衫、裤子、背心、外套、打底衣等，退货率相对低。

# 2.2.3 选品别踩坑

1. 尽量避开货源稀缺的款式。笔记爆单时，慎重让厂家生产，因为自主生产无法退货；

2. 避开特定人群款式，如新中式、国风，挑人穿的款式退货率可达70%-80%甚至更高；

3. 产品低于市场平均价要慎重拿货，容易出现质量差、退货率高、店铺负反馈严重；

4. 选品前让商家发产品实拍图、细节图，直观判断质量，避免货不对板；

5. 看商品评价，网图评价多于客户真实评价，考虑刷单做评价，质量要检查核对。

# 2.3 先拍样品，物流约1-4天

选完品后，建议新手第一批下三到五个品的样品，用来拍产品实拍图。

注意：这个环节先不谈代发，等出单再谈。

下单样品步骤：

第一步：确定要下单的选品，保存产品图片；

第二步：用拼多多、1688、以图搜图找供货商，查看材质描述，款式是否和爆款商品描述一致；（找供应商方法详见【章节四：找到优质稳定的供应商】）

第三步：点销量高的店铺，价格有30%-50%或以上利润空间即可。（比如📕卖七十八，拿货三十九，利润率50%）

注意事项：

1. 查看商品描述，材质和规格是否与爆款一致，并咨询是否24小时内可发货；

2. 普通快递一般三到四天到货，同省一般一到两天；

3. 样品下单直接在店铺拍单即可；后续想长期合作，可和供应商确认对接流程，是加🛰️下单还是走ERP下单。

补充两种下单方式区别：

🛰️下单是为了避免二次面单被平台判无货源；

ERP下单是为了单量多时，商家能看到我们店铺后台订单直接发货；

建议新手前期单量少时直接走🛰️下单。

# 2.4.2 定价要算清楚

很多人觉得把拼多多商品搬到📕提价三倍照样卖，但📕用户没那么傻。我问过五十多个女大学生，大部分人还是在淘宝、拼多多、得物下单，而且现在大学生很多会比价。

产品定价我会搜淘宝和拼多多销量靠前的店铺，定价在这两个平台区间内。很多用户即使比价后发现比淘宝略便宜，考虑到我们图片是原创拍摄，主打“所见即所得”，基本不会再去其他平台下单。

比如随便在拼多多榜单看到一条牛仔裤价格三十九，去搜同款在淘宝按销量排序，月销一千+的基本在七十到九十区间，当然也有四十多的。这时我可能定价五十九到六十九，具体算自己的利润率。
