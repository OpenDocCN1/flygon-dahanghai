第三，从搜索联想词里找选题。在📕，六成以上的人打开搜索时目标早就清楚了。敲进“英语口语”，联想栏蹦出来的那些词——跟读怎么练、日常怎么聊、零基础从哪起步——恰恰是他们真正在解的题。每一条这样的联想，都能单独撑起一个选题方向。

记住一条：动笔之前先做需求调研，别脑门一热就发。

3. 把笔记做成爆款

这一段是全流程的重头戏。

笔记真正要干的不是讲课，而是让读者心里冒出一句“这不就是我嘛”。别端着老师的架子——你要扮演的，是跟他吃过一样的苦、后来自己摸到门道的那种人。

一条笔记的骨架就四块：先让他觉得你懂他 → 再点破他卡住的根由 → 然后递上可执行的做法 → 最后顺带提到工具。

往下细说：

第一步：把痛写进画面，让人自动认领

读者划不划走，全看这一屏。

诀窍是：把苦说得有场景、有镜头，他一眼就心想“这写的是我”。

顺序是——先锁定读者是谁，再推演他在哪个时刻最难受，然后把那一幕还原成文字。

假设读者是外企员工，可以直接写：轮到我在会上开口，脑子嗡一下空了，嘴里只蹦得出零星几个词；等我在心里把句子拼完，议题早翻过去了。同事以为我没观点——其实我观点一箩筐，就是嘴落在后面。

通篇是镜头，没有一句抽象话。读者会嘀咕：你怎么知道？我就是这样。所谓共情，就是先把他的难处接住，他才肯继续读。

人群一换，痛点镜头也就全变。打工人的镜头是被点名时僵在原地；出境游客的镜头是对着菜单只会指图说 this；宝妈的镜头是生怕自己的口音把孩子带歪；雅思考生的镜头是背了一堆素材，一上场全忘光。你写给谁，就搬谁的生活。

所以动笔前把两个问题答清楚——这条给谁看？他最痛的瞬间是哪一刻？答案一出来，那段描写自己就长出来了。

第二步：一句话把根子挑明，让他“哦”一声

痛写够了，马上解释他为什么总在原地打转。

手段是打一个贴生活的比方，把道理讲透。术语别端出来，读者既看不明白也懒得看。

你想说的是“口语属于肌肉记忆，不属于知识记忆”，那就换成：菜谱背得再熟，也炒不出一盘菜。嘴也一样——脑子里懂，不等于嘴上跟得上，它得单独练。

一个贴切的比方，顶得上十段论证。读者心里“哦，原来如此”，紧接着就会追问：那怎么练？第三步顺势就接上了。

第三步：把做法削到最简，让他觉得“我也行”

到这里，他已经站到你这边。该给动作了。

原则只有一条：轻、门槛低、当天就能开干。

像这样：每天挑一小段对话，一句一句跟着念，每句三遍，加起来十分钟。够轻吧？他一看就想“这个我做得来”。

千万别写成“先做这、再做那，还得留意甲乙丙”——一复杂，人就划走了。只给三样：做什么动作、花多久、做到什么程度。他会觉得今晚就能起步。

第四步：接上工具，破掉“坚持不下去”

前三步都在给方法，第四步才轮到成交。

思路是：他认了你的做法，可立刻冒出新疑问——材料上哪儿找？靠自己撑得住吗？

这时你顺口一提：嫌自己搜材料费劲的话，我平时在用一个小工具，打开就是成段的对话，一句句带着读，跟着走就成。想要的姐妹评论区扣“素材”。

切记别硬推。你的人设是“我也这么练上来的，顺手把用的东西告诉你”，而不是“我在卖课”。

说说标题和封面。

好标题得同时装下两样：我的身份 + 我拿到了什么。比如“零基础起步的我，跟读三个月，同事以为我在国外待过”——前一句让人对号，后一句拿结果勾人。前十个字分量最重，把最核心的身份词塞到最前面。

封面得能让人在刷信息流时手指一顿。前后对比的聊天截图、咖啡厅或机场的对话实拍、大字号观点图，都行。同行哪种样式跑出了好数据，就照着做。

行文上多说人话，句子切短，段落拆碎——这里的读者没什么耐心，每段控制在两行内，当成跟朋友唠嗑来写就对了。

4. 拆一条真实笔记

📕笔记案例：

三个 500 小时，英语从 0 基础到听说自由

点击打开【📕】查看笔记！

下面照前面那套框架，把这条笔记拆开看。

第一步：共情。开头讲的是家长找不到路径、折腾好几年孩子仍卡在 G-H 这个级别——用具体卡点请家长认领。但这一段的力度偏软，镜头不够，读着更像在陈述现象，没能扎到心里去。

第二步：点因。借“十聋九哑”以及婴儿学话的天然次序来讲底层道理——耳朵先行，听是拉动整辆车的车头；只会写不会说，说到底还是输入太少。这个类比立住了，家长当即有被点醒的感觉。

第三步：给路径。路径写得细，切成三个“500 小时”：

• 第一段：图像与声音同步，天天一小时，大致一年

• 第二段：难度相当的窄输入，靠兴趣推着走，半年到一年

• 第三段：用兴趣把词汇盘子铺大，做到听得不费力

每段都有目的地、有验收点、有具体动作，照着能做——这正是全篇最值钱的部分。

第四步：接工具。这条笔记其实没挂产品，不过要是在这里配一个小程序去承接前面那些痛点，是相当对路的。

1.4 钱怎么结

每天上午八点到十点之间，前一天的数会刷新。登后台一眼就能看到昨天进账多少，细到分。

打款节奏是每月一号和十五号各一次，平台扣完个税，七个工作日内到账。第一次提现前，得先在后台把银行卡填好。

1.4.1 提高收入的几条体会

前后做过十几个小程序，攒下几条提收经验：

封面广告排在最前。几类广告当中，它的进账占比最高，一般能占一半往上。确认它开着——就这一个动作，可能抵得上你调半天别的广告。

激励视频要卡在他最想要的那一刻。核心功能已经用完、还想要更多时，人最容易接受广告。比如做测试类产品，把详细报告锁在激励视频后面——他刚做完题，正急着看结论，等三十秒完全乐意。

别让广告伤到主体验，这属于红线。一进来就满屏弹、操作途中反复打断，人很快就删了。跑掉一个用户，亏的远比多放一次广告赚的多。理想的配置是——他知道广告在那里，但不觉得被打扰。

收入有起伏很正常。单价随广告主预算走，四季度（双十一、双十二）往往是一年中最肥的时候，开年则淡。同一个小程序，四季度的日流水能到年初的两三倍。短期晃一晃别焦虑，盯月度和季度走势就行。

多铺几个小程序来分摊风险。全压在单一产品上太悬——万一它被投诉、规则一变、用户跑掉，收入就是断崖。手上同时有五六到七个在转，某一个出事，对大盘的冲击就有限。

2. 靠订阅收钱

订阅说白了：拿免费额度把人勾进来，用会员的体验把人留下。

设计上守住三条：

• 干干净净不带广告，体验本身就是你最强的护城河

• 免费那部分要刚好让他尝到味，又不够吃饱

• 掏钱的门槛压低，月付比年付更容易让人迈出第一步

2.1 📕的脾性与打法

刚起步的会员型小程序，📕算得上最容易上手的渠道之一。这里的人习惯先被内容说服，再掏钱下单，跟逛货架式电商完全两回事。他们眼前出现的不是一张商品详情页，而是一篇篇真人体验和实用干货。

因此在这里推会员，落点只有一条：靠内容说话。每条笔记其实都在回答某位读者的具体疑问——这个会员究竟能替我办成什么。要是只做搬运、拼数量，既没辨识度，平台也不乐意给流量。眼下平台明显更偏重深度和原创。

2.2 怎么把商品链接挂到笔记上

2.2.1 先理清挂链接的时机

新手常纠结：刚发出去要不要缓一缓，等有了流量再挂？其实建议发布那一刻就把链接带上。挂上之后自然推荐或许会有一点波动，但带商品的笔记抓到的本来就是购买意图最强的那批人，比泛泛的浏览值钱得多。

能放链接的地方有两处：笔记底部的标签栏（手机、电脑都能弄），以及评论区置顶（这个只能用手机）。平时建议电脑端发（快），碰上数据跑得好的笔记，再用手机去评论区把链接补上。

2.2.2 新号的发布节奏

全新账号稳一点的打法：头三天只发纯内容，链接先不挂。过了三天再回去编辑补上，之后就照常节奏走。

几个常踩的雷：

• 简介里避开“私戳”“后台踢我”这类词，很容易被算作招揽站外流量。哪怕你没那意思，眼下审核也很紧，宁可错判也不漏。

• 别拿📕号的私信直接回客户。就算只想把人引到店铺下单，字句稍有不妥也可能被判违规。咨询可以放到千帆手机端处理。

• 新笔记“小眼睛”数字难看是正常的，2024 年 9 月以后平台整体压低了基础分发量。可以这样换算：抖音那边的播放数乘上 8%，大致相当于这里的浏览量。

2.2.3 多号配合的打法

一个号一天发太多，容易被打上标记。稳妥的组合是“一个店铺专业号 + 三个主理人号”：专业号少发甚至不发，内容产出和挂链接交给主理人。按现在的规定，一个店铺最多绑四个号。

2.2.4 买完之后怎么带他激活

买家在店铺付完款，真正的关键动作是把他顺顺当当送进小程序、把会员开起来。常见做法：订单自动回复里塞一份激活指引和图示；商品详情页加一段“买完怎么激活”的图文；发货时随附 PDF 教程；发货内容里写上小程序的关键词（别直接甩🛰️号，容易触发风控）。

2.2.5 定什么价

这里的买家不盯着比价，他们更在意内容值不值、用起来顺不顺。价格往上抬一点，单量或许会掉，但每单金额上去了，总收入往往更好看。建议年费从 39.8 元起。

2.2.6 发货设置与售后应对

会员是虚拟商品，编辑时物流方式必须勾“无物流配送”，不然自动发货跑不起来。运费模板记得挑全国包邮那个，默认模板一般把偏远地区排除在外。

常见售后与处理：

• 不知道怎么激活：提前备一段短视频或图文，把“打开🛰️小程序 → 登录会员”整条路演示一遍。

• 觉得内容太多不知从哪看起：告诉他先挑自己最急的那块用，权益长期有效，不必一口气吃下。

退款这块要格外留心：有人来退，态度放好、配合操作。重点是把原因引到“拍错/多拍/不喜欢”或“其他”上——一旦勾了不利于店铺的选项（比如“商品质量问题”），就会落进负反馈率里。而且系统只记第一次的选择，后面改了也不算。

⚠️ 提醒一句：平台最近把考核压到了店铺运营端，光看笔记表现已经不够。售后数据不达标，流量分配会直接受影响，这条别当耳旁风。

2.2.7 自动发货插件（阿奇索）

等单量稳住了再接自动发货。阿奇索有七天试用，前期单子少，手工发也完全应付得来。发货内容填激活码或者教程链接都行。

路径是：千帆后台 → 左边「服务」→「服务市场」→ 搜“自动发货”→ 找到阿奇索注册。Windows 用户装个发货助手就能全天候自动发；Mac 没有客户端，在订单页面里手动操作也照常能用。

建议配好后自己先买一单走完整流程，确认买家能收到激活信息、会员能正常开起来，免得后面冒客诉。

2.2.8 自动回复怎么帮上激活

千帆后台能设自动回复，把问得最多的问题先写好答案。会员类的高频疑问无非：怎么开、管多久、有哪些功能和内容、能不能先试、换设备还能不能登。这些答案备好，顾虑消得快，成交率也跟着上去。

还能在发货信息里塞一句好评回馈：留下好评就送额外的会员福利或资料包。好评攒起来的同时，也推着买家早点确认收货，钱回得更快。

建议把七天无理由退货打开。关着也拦不住真想退的人，倒是页面上那个刺眼的“不支持”标签，会把不少还在犹豫的买家直接劝走。
