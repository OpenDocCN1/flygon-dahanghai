# 2.4 多链时代：谁能撼动以太坊？

理解公链的世界，绕不开一个核心话题——以太坊。但要真正看懂它，得先把它身上的几层身份拆开来看。

第一层，以太坊是一个组织，也可以说是一家公司。这个组织的初衷，是解决去中心化应用的发展难题，让区块链不必一直停留在比特币的交易场景里。为了实现这个目标，他们搭建了一个面向开发者的平台，就像安卓或 iOS 之于移动应用一样。也就是说，以太坊本身也是一个基础设施，这是它的第二层含义。

不过，和 Web2 时代的平台不同，以太坊从协议层就开始内嵌了一套金融体系。流通于这个体系里的资产，叫作以太坊，也叫以太币，英文简写是 ETH——这是它的第三层含义。

顺带一提，中文里把这类资产统一译作“代币”，其实不够精准。英文的 token，更贴切的翻译应该是“通证”或“令牌”。因为在 Web3 网络中流通的不只是货币，还有债券、股票等多种属性的权益，简单译为“代币”容易让人误以为它只是一种支付工具。

也因为以太坊从底层协议到上层应用都跑在这套系统里，它也可以被视作一张 Web3 网络。由于这种网络建立在区块链技术之上，行业里更习惯称之为公链——意思是人人都可参与使用的链。

商业世界的逻辑很简单，越有影响力的底层平台，越会成为兵家必争之地。资本也好，技术团队也罢，没有人愿意看到以太坊垄断整个赛道，于是各类公链陆续涌现，纷纷瞄准以太坊的短板，拿出各自的解法。
