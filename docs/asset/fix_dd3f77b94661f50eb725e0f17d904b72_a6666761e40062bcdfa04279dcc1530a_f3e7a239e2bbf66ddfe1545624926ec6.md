# 付费策略五：借内购实现单点收费

以 Fitness Pal 为例看会员体系怎么分层：VIP 把专业训练方案与无广告浏览组合在一起；SVIP 再往上叠加一对一教练和个性化训练安排。如此安排，基础用户能感受到入门权益的实在，高阶用户也获得了身份升级的满足感。

再说场景化的小额收费——面对荷包不鼓的人群，把使用频率高的功能单独拆出来卖，Tinder 的“让内容被更多人刷到”“超级喜欢直接置顶推荐”就是典型例子，正好迎合消费收缩阶段的用户心理。还有一条路是服务分层加价：Epic 的年鉴照片加急通道标价 5.99 美元，普通通道只要 3.99 美元；从近一个月美区内购数据看，走 AI 年鉴加急通道的订单已经占到全部付费的 20%，成了新的营收拉动点。

# 8.2.1 订阅动线如何安排

先谈周期档位：通常按周/月/年划分，时间拉得越长，折算到每周的花费越低，靠这个引导用户往长期走。

压低决策负担。并不是每家都把周、月、年三个档位同时摊开。档位一多，用户就得琢磨哪个划算，思考时间被拉长，感性消退、理性上线，决策成本反而变高。拿 AIBY 的《AI Arta》来说，首次进入只抛出一个 $29.9/年的 SKU，用户主动点免费试用之后，$4.99/周的 SKU 才会冒出来。

[PRE4]

AIBY 的《AI Arta》订阅页

降低单次支付的痛感。那是不是只留一个档位最优？未必，得结合自身产品跑分版本实验。只放短周期，续费率掉下来会伤营收；只放长周期，一次掏的钱多又压制付费意愿。摆出两到三个周期，可以搭出价格参照系，对把用户推向长期档有拉动作用。像 AIBY 的《Chat on》和 Codeway 的《Ask AI》都同时挂出短周期和长周期，终身或年度方案的优惠幅度肉眼可见地超过七成。

# 8.2.2 卸下心理包袱

留意一下就能发现，多数 App 都设了三天免费试用。这其实是个钩子——用零门槛把用户拉进来，之后总有一部分人忘了退订，系统自动扣款，这块在订阅收入里分量不轻。Codeway 的《Ask AI》会在页面上写清“现在不扣款、先开试用与计划”，实际上就是在引导用户先免费体验。

# 8.2.3 营造紧迫感

倒计时形式的限时礼包，可以搭配有吸引力的功能或内容；如果用户没在第一次订阅弹窗时买单，系统会追加一个限时降价的钩子。像 AIBY 的植物识别产品《NatureID》就曾放出一小时之内五折的窗口，用足够低的价位让用户很难说不。

# 9.4 全天候监控要点

路径：销售与趋势 → 左侧导航栏选择「产品销量 / 销售额 / 收入」

两组数字别搞混：

销售额：用户实际支付的金额（包含苹果抽成）；

收入：扣掉苹果分成后真正落袋的净收益。

监控的意义在于实时观察促销动作、版本迭代等事件对销量的拉扯。
