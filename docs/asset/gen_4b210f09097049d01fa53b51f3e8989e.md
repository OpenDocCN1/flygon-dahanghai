# 6.2.4 这四类素材，最好别用

素材拿到手，并不代表都能直接上。正式用之前，最好先做一轮筛查，下面这几类内容尽量避开。

第一类，带营销推广属性的素材。判断起来不难：品牌标识明晃晃地出现在画面抢眼位置。碰到这种情况，建议整条素材直接删掉。广告费没拿到，还容易被平台识别出来，尤其新账号前几条视频，更要绕开这类内容。

第二类，过度惊悚猎奇的素材。像掏耳朵、挤黑头这类画面，互动数据可能略好看一点，但转化通常不理想。观众的注意力容易被画面吸走，而不是落在小说上，最后还会拖累作品推流。毕竟观众到底是来听小说，还是来看猎奇内容的，谁也说不准。

第三类，年代久远、被反复使用的素材。比如肥猪猪、猪精女孩这类几百万甚至上千万粉丝的甜品大号，它们的素材早就被混剪、去重、用烂了，新作品一发出来还有一堆博主盯着，所以别再把目光放在这些大号上。如果确实想走美食方向，可以搜更细分的品类，找相对冷门的博主；检索条件越具体、限制越多，和你撞素材的人就越少。

第四类，和文章属性不搭的素材。用王者荣耀录屏，就别配女频言情或古言，女生边听小说边看王者荣耀，接受度并不高，换成光遇、蛋仔派对会好一些；反过来，美甲、口红这类画面也尽量别配惊悚悬疑文章，实在太出戏。
