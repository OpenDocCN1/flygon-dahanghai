# 7000+人付费365元/年，这个高格调女性社群是如何炼成的？

分享人：亦仁

日期：2020-07-29

每个人内心深处都有被看见、被关注的渴望，每一个圈子也天然需要彼此连接。垂直付费社群之所以成立，正是因为它能过滤掉杂音，让真正同频的人聚在一起，进行有深度的碰撞和往来。生财有术是这样一个地方，设计师日记是这样一个地方，知识星球上的每一个小星球，也都是这样的场域。

如果你发现，某个和你拥有共同爱好的群体，至今还没有一个高质量的交流空间，那不妨留意一下——新社群的机会可能就在眼前。

今天，我请来一位高格调女性社群的创始人，她叫Juan。她将和我们聊聊，自己如何认知并操盘这样一个社群。欢迎她。

另外，提前说个八卦：下午的预告帖里，不少人在猜Juan的性别。她后来回帖说，圈友有兴趣可以私下约她吃饭聊（龙珠圈友优先，这句话是我补的）。我只能帮到这里了。

生财有术的各位朋友，大家好。我是花神妙华云境的Juan，感谢亦仁的邀请，来分享我运营高格调女性社群的一些经验。

目前我手上有三个产品：一个7000+人、年费365元的知识星球“花神妙华云境”；一个十万粉丝的情感公众号“花神妙”；还有一个女性生活方式类的付费千聊直播间。收入来源主要是星球门票、星球付费提问、公众号广告、直播和私密咨询。加起来年收入有七位数，但我只当零花钱——我的主业是家庭主妇。

【明线与暗线：一个人如何长成今天的样子】

聊社群之前，先讲讲我自己的经历。我的人生有两条线，一条是明线，一条是暗线。

明线很简单：我来自江苏一个普通家庭，求学过程平淡无奇。18岁考上南京大学读本科，那时候和亦仁是校友。后来到上海戏剧学院念戏剧文学硕士，毕业后在几家大公司工作过，再后来做了自媒体。

这些都是事实，但一个人简历上的明线，解释不了她灵魂里另外一面的模样。

我对人性的复杂面一直很有兴趣。虽然我做的是情感公众号和情感社群，但情感只是表壳，真正探进去，是对“人”的好奇。因为我自身就有很多面，这些面共存，让我的人生体验格外丰富，仿佛一辈子活成了好几辈子。

暗线则要从初中说起。我从小就爱阅读，从书里领悟到很多学校、老师、家长不会告诉我——甚至他们自己也不知道——的人间规则。考试卷子翻来覆去做，没太大意义，模拟考分数也不能让我有多少情绪起伏。于是我把时间省下来，保持自己的阅读节奏。表面上看，我还是循规蹈矩的好学生，好好完成学业，好好读大学；但内里，我按自己的进度在悄悄学习。

到了大学，我也是一边跟着文学院的课程走，一边去读其他学科能读懂的东西。

很多人好奇，一个情感博主自己的感情经历是什么样的。我因为初中起就大量阅读，心智早熟，很明白中学阶段的恋爱不是我想要的。那时候该做的只有两件事：一是考上好大学，二是在内在层面抓紧自学。所以早恋这事，在我身上不存在。

事实上，恋爱谈得多，不等于对爱情洞察得深；和谁谈，才真正重要。你站得越高，看到的风景越不同，能遇到的人也不一样，你对世界和人心的理解自然不同。

回头看，南京大学提供了一个很高的平台，让我认识了一位后来深刻影响我的男士，我的命运在暗线上由此转向。当然，一个20岁女生能清楚知道自己要什么，和她12岁起就开始的阅读，是分不开的。

南大的教育很严格，但经由南大校友层层介绍而认识的那位男士，给了我另一种独特、稀有、私人、立体的“商学院式教育”。他让我可以使用顶级商学院的图书馆，去听一流企业家的讲座，到全世界各地参观公司。这些，都是暗线上的成长。

多年之后，我还是想一遍遍感谢他：谢谢你，给了我另一段瑰丽的人生。

因为亲身体会过一位好伴侣对女人成长有多重要，这成了我做女性情感社群的初衷之一。

要选择那个能带给你瑰丽人生的人，至少是能让你生活更丰富的人。而这背后，需要你对很多领域有足够的了解。

举个例子：很多女生偏爱投行男，觉得他们学历高、帅气、体面、收入高。但如果你把一个互联网大公司的战投男放到她们面前，她们可能心想“哦，不过是个在互联网公司打工的”，觉得不如投行男。

这就是不懂行业造成的误判。实际上，互联网大厂战投男的含金量，不输给传统投行男，甚至某种程度上更高。一个女孩子，得掌握科技、商业、文化等方面的知识，才不容易被忽悠，才能从一个男人的职业履历里，倒推出他的性格特质和未来前景。

婚恋之所以复杂，是因为越往上层走，人的社会属性越强。所以，光靠我一个人的认知还不够，整个“花神妙华云境”星球里，来自各行各业的星友彼此交换行业信息，这对其他人来说，是很有价值的参考。

【从零到一：社群是怎么建起来的】

创建“花神妙华云境”的起因，还要从公众号说起。当时“花神妙”这个号已经写了两年多，公众号的变现方式主要就是接广告。但那时阅读数不算高，我又坚持只接次条广告，广告费自然不高。对一个内容精品、不走流量的号来说，靠接广告赚到的钱很有限。

2017年，自媒体圈里很多人开始尝试“小密圈”。我当时不知道那是什么，但也跟着建了一个。

那时候创建小密圈非常简单，几分钟就搞定，不像后来那么麻烦。建好之后，我并没想清楚要拿它做什么、怎么做，只是先建起来，看看会发生什么。

我对新事物一直保持开放、尝试的心态。如果做什么事都要先做详细调查再行动，我觉得会错过很多机会。

建好圈子后，我把海报放到微博上。当时小密圈最低定价是50元，我看了看其他大咖，有的定99元，有的定129元。我想自己算不上大咖，就定了个66元的保守价。

然后发生了什么？手机不断弹出有新成员加入的提示，没过多久，小密圈钱包里就有了六七千块钱。

当时我的第一反应是：天啊，已经这么多人付费进来了，可我还完全不知道这个社群该怎么做！虽然一无所知，但我从做“花神妙”公众号开始，就有一个心法：随顺众生。我不用费心想“该怎么做这个社群”，不如让大家来告诉我。

用户真的比我聪明。很快，有星友发现了小密圈的提问功能，她们用这个功能向我提问。这件事启发了我：为什么不干脆做成一个纯问答社群呢？

后来在“花神妙华云境”星球里，内容分成了三部分：提问、回答、评论。

星主和嘉宾都会严格筛选提问。只有那些有价值的、带着真实个人情况和思考的提问，才会被回答。这样一来，随意的、情绪强烈的、影响别人阅读体验的提问都被挡在门外，留下的每一个提问本身，都具有可读性。

回答问题时，星主和嘉宾也非常认真，力求让答案本身就像一篇篇独立精彩的文章。

这种严谨的气质，也带动了评论区。读者评论经常带着深度思考，几百字以上的高质量留言并不少见。那些在评论区活跃、有真知灼见的星友，会被选拔为嘉宾。

华为任正非说过一句话：资源是会枯竭的，唯有文化生生不息。

“花神妙”公众号和“花神妙华云境”星球，追求的就是“随顺众生、严谨”的文化氛围，用隐形的精神追求，把同心同德的人聚起来。

目前星球的收入，主要来自门票和付费提问。

【社群的内在逻辑和文化属性】

1. 随顺众生

当初创建“花神妙”公众号时，我方向感还不强。有一次我去江苏宜兴的大觉寺，看到一句话：随顺众生。

和那些历史悠久的老寺庙不同，宜兴大觉寺是一座新建的寺庙。它之所以能在短时间内建成如此宏伟的规模，是因为团结了千千万万愿意为它付出的人——也就是“众生”。那里的气场是“温暖”。

这个气场给了我启发：我应该做一个线上的温暖气场聚集地。

随顺众生，就是尊重每个人心里开出的那些花，试着理解她们为什么会有那样的想法，让她们表达欢乐、迷醉、痛苦，随她们的喜悲，顺她们的细思。

常见的女性情感博主，会输出自己的价值观，她们是意见领袖，是光圈的中心。但我的核心逻辑是“随顺众生”——众生在我前面，我充分尊重她们表达的权利。

知识星球里，星友们可以发表不同看法，但不能碰触“伤害星球生态”的红线。如果有人对别的星友进行人身攻击，会立刻被拉黑。过分情绪化的表达，也会受到约束。

2. 隐秘的高门槛：“人间文化”

“花神妙”系列文章本身就是一道筛子。我写作用词严谨、理性分析，每一期推文还会引入经济学、投资学、历史学、文学甚至园艺学等不同学科的知识和概念，用查理·芒格的格栅理论，让情感问题不再只是情感问题，而是通过情感问题举一反三，带动对生活和工作其他方面的思考。我把这称为“人间文化”。

这种严谨的文章，对读者的阅读能力有一定的要求。它天然筛掉了那些文化功底不足，或者不愿意深度思考的人。

筛选的结果是，“花神妙”的粉丝中，高社会地位、高学历的女性比例非常高，她们都是能从阅读启发中获得快乐的人。

“花神妙”系列之所以有这样的气质，和我的个人偏好有关。虽然我是情感博主，但我的兴趣爱好主要在文化上。写情感文章时，我会顺手夹带各学科里我感兴趣的“私货”。一开始只是无意为之，后来发现，有同样喜好的读者不少，于是慢慢形成了这种独特的文章气质。

追求“文化”的需求其实非常隐秘，藏在很多人心里。一旦你用真知和文化去和这些人交流，大家会通过“文化密码”认出彼此。

文化认可，是一种隐秘的高门槛。因为一个人有没有文化，是需要禀赋、多年刻意练习、发自内心的热爱的，这些都没法装。而当她们彼此认出，就会格外珍惜这段关系。

和纯学术研究型文化不同，“花神妙”主张的“人间文化”不拘泥于学科边界，而是能应用到日常生活中，还带着一种变身般的魅惑力。

比如，提到三星堆的经典人像，往往是一层青铜面具外加一层黄金面具。“花神妙”会用这个来比喻：当一个女生想营销自己，普通女生只知道靠医美等方式，给自己戴上一层漂亮的“青铜面具”；而更用心的女生，则会用“创业成功”等更稀罕的标签，再给自己加一层“黄金面具”。

3. 积累质地高级的品牌资产

一个聚集了许多女性的情感社群，很容易被别人想象成“一堆女人的情绪”，或者“一群人为了某个现实目标一起努力”。这些当然也很好，但我希望在功能性之外，还能积累起质地高级的品牌资产。

“质地高级”的意思，是能让人心中升起“敬意”。

“花神妙”系列虽然是我在主导，但知识星球的嘉宾、千聊直播间的嘉宾们也很重要。我选择嘉宾的标准是：她们一定是在各自领域里让人“尊敬”的，通常有世界一流的教育背景、非常能吃苦、有真知灼见。

起心动念的正派，也是赢得敬意的前提。人性中有很多缺陷和弱点，尤其是在情感世界里，一个掌握了一定人性规律的女孩子，稍微用点手段，就能得到很多想要的结果。但“花神妙”系列只指认人性的复杂面，绝不鼓励星友把规律用在邪恶的目的上。因为那并不高级——那样做的人，不会得到社会的尊敬；那样做的社群，也不会得到星友的尊敬。

除了“我能帮星友们获得多少好处”，我还经常问自己：“我能让多少人尊敬‘花神妙’这个品牌，以及让她们每时每刻都意识到，被尊敬本身有多重要？”

以上分享的内容可能有点务虚，但这些都是我的真实想法。我亲眼见过，一颗起心动念的种子，放进互联网的土壤里，会长出怎样迅猛的花。

【庭下如积水空明，水中藻荇交横，盖竹柏影也。
何夜无月？
何处无竹柏？但少闲人如吾两人者耳。】

苏轼在《记承天寺夜游》里写的，是眼前的实景：月亮、松柏都很常见，难得的是那天夜里他们两个人的心境之闲。

对我来说，运营社群的技巧固然重要，但更难得的，是技巧背后的心境。
