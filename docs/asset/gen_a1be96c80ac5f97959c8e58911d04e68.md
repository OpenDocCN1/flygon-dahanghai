# 10.1.4.2 定位先定准

做视频创作，先选定一条主线。情感、励志、育儿、国学等方向都能做，但建议只挑其中一类，持续深耕。

方向明确后，把账号的基础信息补齐：昵称、头像和简介都要与这个定位相呼应，让用户一眼看懂你是做什么的。

新账号刚起步时，系统并不会自动给你的作品贴上明确标签，通常要等同类内容积累到一定数量，账号标签才会逐渐清晰。因此，每次发布作品时，话题里一定要带上能代表你所在领域的关键词，帮助平台更快识别你的账号。比如可以使用：#读书 #阅读 #情感 #励志 #成功 #智慧 #国学 #人生感悟 #成长 #育儿。

另外，前期不必每条视频都围绕书来做，也要安排一些引流型内容，主动引导观众点赞和关注。作品数量、粉丝数量提升后，账号权重也会随之增加，这对后续长期、稳定地获取流量更有帮助。
