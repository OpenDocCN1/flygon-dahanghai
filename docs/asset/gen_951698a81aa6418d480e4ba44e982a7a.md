# 4.8.2 笔记内容怎么做？@李晓飞

做内容之前，选题的分量不亚于电商挑品。选对了方向，后面的创作才更有把握。我通常把选题分成三类：实用干货（比如挑水果小技巧）、产品素材、稀缺内容。

其中，实用干货很容易起量。我曾用 0 粉账号拿到 1.5 万赞，但真正下单的人并不多，原因在于内容和购买意图关联不强。它的好处是能涨粉，粉丝还能为账号背书，同时有助于提升账号权重。

[PRE0]

**干货内容怎么写？**

可以先找小红书上已有的同类干货作参照，再补充自己搜集到的资料，最后加入个人理解做二次加工。

产品介绍型素材吸引来的用户更精准，制作门槛也不高，可以靠数量推进。单条播放或许只有 500，但一天发 10 条，累计就是 5000。

**素材从哪里来？**

自己购买产品进行实拍，尽量多角度各拍几张，再分几天陆续发布。

**稀缺内容怎么做？**

锁定平台上供给稀缺的内容，笔记更容易持续获得热度。

举个例子：一篇讲国外软件的笔记，至今仍不断有流量进入。因为平台可选内容不多，甚至出现空缺时，系统会更愿意推荐你的内容（数据统计截至去年）。

[PRE1]

**怎么找稀缺内容或关键词？词往往就是内容入口。**

1）先拿一个关键词，在 [`account.5118.com/`](https://account.5118.com/) 扩展相关词和行业热词；也可以借小红书下拉框、推荐词等入口寻找。

2）再到小红书搜索对应词，比较笔记数量和阅读量。差距明显，通常就说明这类内容稀缺。

想提高效率，可以用套模板的方法：挑到好模板后，持续发布。

**模板怎么找？**

1. 先找与业务相关的话题词，比如水果、团购等；
2. 用后裔采集器抓取前 500 条数据；
3. 逐条分析共性，包括选题共性和模板共性，重点关注低粉高赞、低粉高评论的内容；
4. 按模板 1:1 发布：把对方图片放进软件，图层置于最底层，再在其上创作，位置、字号、文案、颜色、图片等尽量模仿；
5. 持续发布，不要停。
