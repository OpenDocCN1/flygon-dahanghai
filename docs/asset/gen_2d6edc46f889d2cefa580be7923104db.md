# 8.1.2.4 变现的三条路

账号想获得收入，常见做法大致有三类，下面逐一说明。

1）品牌广告合作
这是账号变现里最普遍、上手门槛也相对低的一种。护肤品牌会主动来谈合作：粉丝体量较小时，可能拿不到现金稿酬，只收产品；粉丝达到几千后，通常既有产品赠送，也会收到费用。行业里常见的报价算法是粉丝数的一成，比如一万粉约对应一千元。当然这只是普遍行情，运营出色的账号往往能谈到更高价格。广告收入的上限不低，一年赚几万、几十万乃至上百万都有可能。品牌邀约多从小红书站内发出，也能通过邮箱接洽；后续都要转到微信沟通具体细节，加上微信后还方便反复合作。

2）私域成交护肤产品
先把关注者沉淀到微信，再向他们销售产品来赚取利润。常规私域卖货的利润率多在30%到50%；若销售的是自家旗下产品，利润空间会更大。

3）直播成交赚佣金
在小红书开播卖货，按实际售出的数量拿佣金；粉丝量大的博主还可能获得坑位费。这种变现方式更依赖粉丝粘性。
