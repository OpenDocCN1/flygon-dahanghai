# 租房行业的门道与机会

今天想和大家随便聊点关于租房行业的想法。为什么说“随便聊点”？因为这行太大了，要展开说能聊上几天几夜。我重点说说长租公寓的发展，以及它带给我的启发。这些思考不一定只适用于租房，你也可以结合自己的行业去琢磨、去拆解。最后，我会聊聊这个行当里，有哪些雷区不能碰，又有哪些机会可以抓。全文8000多字，完整版放在石墨文档了，链接如下：https://shimo.im/docs/yhjTkvr8VRCqwHvT

评论区：

惠一问：开发商做公寓，实际上活得怎么样？长租和民宿能结合着来卖吗？

猿媛说答：开发商做的公寓其实日子不好过。它们属于集中式公寓，虽然比分散式的稍微强那么一丢丢，因为后期管理成本低不少。长租跟民宿，或者说长租跟短租，完全可以结合。特别是快过年了，或者租赁市场进入淡季，用短租来调节一下，是个不错的销控办法。

惠一：我私信你了，能加微信聊吗？

猿媛说：好呀。

邓双义问：短租单价是高了，可渠道成本不也上去了吗？而且短租客和长租客的需求不一样，真不一定能服务好，搞不好接的是酒店那帮客户。

猿媛说答：短租放在长租公寓的体系里，更像是应对个性化需求或特殊销售环境的PlanB。长租公寓最大的成本是付给业主的房租，短租的价值在于能消化掉一部分空置，本质上是“少亏一点”的方案。
