# 从0到100万：我的亚马逊站外推广生意经

作者：雪球（陈凯锐）｜日期：2022-02-17

大家好，我是雪球（陈凯锐），96年生人。2019年毕业后进入跨境电商做亚马逊运营，2020年和别人合伙创业，2021年3月我独自All in亚马逊站外推广服务。到2021年10月，我赚到了人生第一个100万：给家里转了50万，自己账上还剩约50万。团队从1个人发展到8个人，办公室从15平方米换到50平方米。最让我有成就感的是，身边有三个人因为这项业务月入过万——两名员工、一名代理。100万在生财有术圈子里不算大钱，但对我个人来说，这是第一桶金。

**—前言—**

2021年10月，我算了一笔账：给家里寄了50万，自己手里还有50万左右，合计100万。钱不算多，但意义不小。更让我开心的是，团队已经扩展到8个人，办公场地从15平方米搬到50平方米，还有三个人因为我实现了月入过万，其中两个是员工，一个是代理。

**—01—**

**我是如何在不到一年时间赚到100万的？**

2021年3月，我离开原合伙团队，租下一间15平方米的办公室，开始单干，方向很明确：只做跨境电商亚马逊的站外推广服务。

为什么选这个项目？

第一，合伙创业时我们已经尝试过这项服务，并从0到1跑通了一个小闭环，说明市场需求真实存在。之前一边做亚马逊卖货、一边做服务，精力分散没做好；现在我有信心All in进去，把它做得更扎实。

第二，我判断2021年站外推广服务会进入红利期。2020年末，我发现不少外行开始涌入亚马逊，据说每天新增3700人，起因之一是媒体炒作“深圳湾一号的房子被做亚马逊的人买走了”。同时，亚马逊算法越来越严，平台逐步正规化，只靠刷的卖家很可能被淘汰。

第三，站外推广服务的模式不复杂：靠流量变现，通过公众号、论坛把卖家引到微信，再提供站外推广服务完成转化。

第四，资金投入极低。服务型生意基本是一手交钱、一手交付服务，只要需求存在、资源过关、服务到位，每天都能有稳定现金流。创业初期，现金流太重要了。

接下来，我按三个阶段推进自己的单干创业。

**第一阶段：从0到1，站外推广模式**

**模式拆解之「服务」**

我的商业模式可以概括成三个词：服务、流量、变现。

[PRE1]

站外推广服务，就是帮亚马逊卖家在亚马逊平台之外做推广，主要形式是促销，英文叫Deals。说白了，我们是流量中介，把站外流量转卖给亚马逊卖家。理解一项服务，先要看它有没有需求，再看底层逻辑。

**1）需求**

我自己做过亚马逊卖家，很清楚卖家的站外需求主要有这些：

拉动排名、推产品；  
清理库存、提高库容；  
给秒杀预热；  
稀释留评率、退货率和投诉率。

**2）底层逻辑**

简单说，我们倒卖流量，满足亚马逊卖家的需求；站外红人也能获利；我们服务商赚中间差价。

收入一部分来自发帖手续费，也就是我们付给红人的发帖佣金；另一部分来自亚马逊联盟佣金，这部分才是大头。

[PRE2]

我们的站外流量掌握在红人手里，他们有自己的粉丝群。我们把Deals发到群里，带动销量，客户需求就被满足了。

那问题来了：红人为什么要帮我们带流量？他们能得到什么？

**模式拆解之「流量」**

亚马逊联盟有点像国内的淘宝客。只要推广的产品绑定了某位管理员的联盟账号，亚马逊就会按成交销售额抽一定比例返还佣金。本质上是亚马逊花钱买流量。比如一个约7万人的美国群组管理员，每天收入大约1000美元，一个月差不多3万美元。

下面是亚马逊联盟较新的佣金比例，不同类目不一样：

[PRE3]

我们服务商扮演的是流量中介，类似国内网红直播带货：网红拿佣金，买家买到性价比高的商品，商家提升销量，三方都赢。

站外推广也一样：给亚马逊买家提供高折扣商品，帮卖家提高销量，我们中介赚佣金，同样是三赢。所以这套商业模式是成立的。

模式跑通后，重点就变成获客。只要对方是做亚马逊的卖家，就可能有站外推广需求，所以核心是持续获取亚马逊客户。

难题在于：当时市场鱼龙混杂，服务商整体口碑很差，新服务商很难取得信任。大家更愿意找长期合作的服务商，而不是刚冒出来的新人。我当时一直在想，怎么在这种环境里杀出一条路。

我能想到的获客途径有三个：

**1）公众号**

同行是最好的老师。我经常研究一个头部同行的公众号，慢慢摸出他们的引流方法：用干货内容吸引人，再用资料引导转发裂变。这样来的用户比较精准，需求也大。而且当时这么做的服务商不多，除了头部那家，基本就我在做。我的第一批用户就来自这里。不到半年，公众号从0做到5000多粉丝，基本都是精准亚马逊卖家。此前另一个号也做到5000，但被封了。

[PRE4]

[PRE5]

**2）跨境论坛**

我把公众号内容同步到各个亚马逊论坛，浏览量都不错。后来我研究论坛规则，发现只要帖子有人回复留言，就会被顶一次。于是我分享文章时会提醒大家留下邮箱，方便我把资料发过去。结果帖子经常被顶到首页前几位，曝光很强，引流到私域的人非常多，几乎每天至少上百人加我微信。虽然来的人多是亚马逊小白，但只要他们做亚马逊，就是潜在客户。

[PRE6]

**3）付费社群**

我还加入了两个付费社群：生财有术和优联荟。

生财有术是一个“谈钱不伤感情”的圈子，我在里面认知提升很大。那段时间天天熬夜刷精华帖，看很多大佬的案例，对私域流量有了清晰认识。我当时的目标很简单：只要微信里加上足够多亚马逊卖家，他们就是潜在客户，因为他们有需求。

优联荟是外贸人的社群，里面也有不少做亚马逊的卖家，是我的潜在用户。我最初只是想进去学习，但因为分享，大家对我比较认可。后来优联荟创始人小北老师把我的文章转发到了他的公众号。

当时在Lissa的鼓励下，我写了一篇关于站外推广从0到1的万字长文，也发到了优联荟社群。运气不错，这篇文章被顾小北老师看到，并转发到他的公众号“小北的梦呓”。在小北老师的光环下，文章阅读量达到1.2万，也给我带来了一批忠实客户。大家开始叫我“顾小北推荐的站外服务商”。很幸运，有了小北老师背书，我的站外推广品牌“雪球站外”完成了冷启动。

**模式拆解之「变现」**

[PRE7] [PRE8]

站外推广服务靠赚中间差价变现，公式很简单：中间差价=收入（客户给的钱）-支出（付给红人的费用）。正常来说，一单利润大约是销售额的50%。至于怎么通过提效率、上规模把利润做高，后面再说。

这里面存在信息差：很多亚马逊卖家不知道怎么找站外流量；有些卖家即使知道，也不愿花时间去找。我们把流量倒卖给卖家，既帮了卖家，也能盈利。

操作上需要用到Facebook账号，主要用来对接国外流量资源，比如群组、主页管理员。模式不复杂：不断找到能发Deals的群组和主页，再持续联系管理员。

[PRE9]

这个阶段，我一个人跑完整个流程，投入0成本。通过不断积累客户和站外资源，每月净利达到2万。

**第二阶段：从1到10，团队的搭建**

[PRE10]

如果说前面是从0到1跑模式，那么搭团队就是从1到10。

单干不到一个月，0到1的模式已经跑通，每月利润2万。我就想：能不能复制几个“我”？我一个人做到顶也就2万左右，如果有5个“我”，情况会不会完全不同？抱着这个想法，我开始招人。

一个人做好相对容易，带一群人做好就难了。作为创业小白，我在管理上没经验，组建团队时遇到不少问题。

**1）团队招人**

前期为了省钱，我把办公室选在深圳宝安比较偏的地方，结果埋下隐患：一直招不到人。大部分年轻人更愿意去市中心上班。没办法，只能烧广告，我同时开了Boss直聘和前程无忧，最后确实有效果，但广告费花了近万元。幸运的是，招到了比较合适的伙伴。

**2）激励机制**

公司刚起步，流程不完善，前期需要手把手培训。我们招的是客服岗，技术门槛不高，很多员工会觉得单调，有人上班没几天就走了。我当时很苦闷：问题到底在哪？

请教前辈后我发现，是激励机制和福利没做好。员工来了之后觉得工作单调、没盼头。于是我制定提成制度，还设置销售冠军、进步奖等激励。之后开会我会提醒大家，并把每个人每周业绩放在在线表格里，大家都能看到、能对比，也知道自己离目标还有多远。

有个员工在2021年最后一个月拿到销售冠军，月薪破万；其他人薪资大多在6-7k。钱不算多，但对员工来说是很强的激励。

[PRE11]

团队搭建起来后，我们做了三个动作，让体量逐渐逼近头部。

**1）自动化系统提高效率**

订单量增加后，人工不够用了。我找程序员做了一套自动化系统。

当时每个订单叫一个帖子，流程是：接帖子—整理帖子—测试折扣码是否生效—发给红人—检测效果。这一套下来很耗人力，按当时业务量，至少需要三个人。

我就想，这套流程机械性很强，理论上可以程序化。那段时间我常去拜访同行业头部服务商B，一方面合作，一方面学习。交流久了发现B已经实现自动化，我更有底气了。于是把需求提给一个程序员朋友，一个月后系统上线。原本三个人才能完成的事，后来一个人就能完成。

[PRE12]

**2）规模效应降低成本**

当时站外市场的规则是：我们按帖子数量付佣金给管理员，一个帖子就是一条促销信息，管理员帮我们发给粉丝。

单量起来后，我们开始和管理员谈价：原本一个帖子5美金，我们问如果买1000个帖子能不能便宜？这样每个帖子成本直接压到1-2美金。甚至有些管理员接受包月，一个月给固定费用，就能在他们的群里不限量发帖，边际成本几乎为0。

[PRE13]

自动化和规模效应省下来的成本，一部分变成利润，另一部分用来给客户发更多帖子、覆盖更多站外粉丝，提高爆单概率。结果就是我们的效果比同行高不少，也间接带来更多转介绍。

**3）三级火箭策略**

亦仁大大说过，先向女性用户卖A罩杯，再推荐丰胸产品。不同的是，我的“丰胸产品”不拿来盈利。

站外推广口碑做大后，我们开始给客户推荐“丰胸产品”。亚马逊卖家需求很多，也衍生出不少周边服务。我去找了几家源头供应商，因为我们有流量资源，可以拿到更低价格。

亚马逊周边服务很多，比如物流、知识产权、图片视频等。但我不懂的东西不碰，每个领域都需要沉淀，所以尽量选和运营相关的服务。我们做了买家秀、QA、点赞、首页无差评等比较简单、高频的服务。外行人可能不知道这些是什么，内行人早就习以为常。这部分利润低，但几乎刚需，所以不靠它盈利，直接给客户接近成本价，用来提高粉丝粘性。

这个思路主要受梁宁的三级火箭策略影响。什么是三级火箭策略？

[PRE14]

我给自己的三级火箭这样定义：

一级火箭：抓住头部流量。通过内容和高频周边服务，让大量亚马逊卖家加微信，这一步不赚钱。  
二级火箭：做沉淀用户的商业场景，主要是微信群，安排专人在群里解答亚马逊问题。  
三级火箭：高利润商业变现，也就是主打服务——站外推广。

还有一个原因：站外推广并不是特别刚需，频率也偏低，所以需要用高频、高需求的服务带动，这就是三级火箭里的“高频带低频”。

[PRE15]

**2、跟头部同行学习**

我们的三级火箭虽然只是简单版本，但很有效。粉丝粘性高，转介绍多，粉丝量慢慢扩大。

再加上平台红利，业务量逐步放大。最高峰时一天利润达到2万，日订单量100多单，逐渐逼近行业头部。当时头部服务商一天大约150单，而他们已经做了2-3年，我们不到一年。

最后总结这次创业成功的原因：

**1、平台红利**

年初的预想成真了。大量卖家涌入，出现了卖家红利。很多人觉得亚马逊赚钱，就盲目进场。2020年末我已经有预感，过完年回来就全力投入亚马逊服务赛道。

平台政策上，上半年亚马逊有两个动作：限制仓库库容、封掉很多人工干预的大卖品牌。这直接改变了玩法。第一，开新品需要把滞销库存清出仓库，就得找站外推广清库存；第二，过去很多人靠刷，现在怕封店，只能采用更安全的方式推产品，也就是站外推广。

**2、跟头部同行学习**

前期我们只有一个微信号和一个Facebook在运作，模式并不完善。后来我去找头部同行学习，不断交流、吸收经验，逐渐把整套流程做成SOP，方便后续招新和入职培训。

**3、个人聚焦**

2021年前，我既做亚马逊卖家又做服务；2021年后，我只专注站外推广服务，并利用自己的优势写公众号，把流量引到微信上变现。

**4、口碑和背书很重要**

我们能在短时间内追赶头部，基础设施其实差不多，差别在口碑。服务商在跨境行业整体口碑偏差：有的资源偷工减料，有的服务态度差。我们团队的原则是一切以客户为中心。口碑做好，再加上亚马逊牛人朋友的背书，我们把站外服务做成了品牌，老客户复购强，转介绍也多。

**5、团队的力量不容忽视**

业务量增加后，我们想办法提效率，做了一套自动化方案，效率提高好几倍。从0到1跑完流程后，接下来就是复制。团队像飞轮，管理者要做的，是让飞轮高效运转，哪怕自己不在，它也能继续转。

**—02—**

**我的成功源于我过去的积累和踩的坑**

很多人问我，为什么会接触亚马逊？时间回到2019年2月，我刚出来实习，在一家亚马逊公司上班，主要运营欧洲站。当时我没什么经验，公司运营手法比较粗放，核心就一个字：刷。每天接触最多的是Facebook，在群组里发帖找老外帮我们做数据补充，日复一日。

那时亚马逊管得不严，整个深圳卖家圈都笼罩在数据补充的氛围里。确实，只要刷，基本都能做起来，很多人也有靠刷成功的案例，线下交流也绕不开这个话题。但我知道，数据补充没有未来，于是开始拼命学习广告和站外推广玩法。

那时我每天写公众号，把学到的知识整理后发出去。输出会逼着我学得更快，因为我想尽快摆脱那样的环境。另一方面，通过分享，我认识了一些做亚马逊的卖家朋友，我的前合伙人A就是通过公众号认识的。

乔布斯说过：你不能事先把点点滴滴串在一起，只有回头看的时候，才知道这些点滴是如何连起来的。

第一，我熟悉了整个亚马逊体系，也结识了一些亚马逊卖家；  
第二，我积累了Facebook站外推广资源。

[PRE16]

现在证明，我当时的想法是对的。虽然当时觉得做很多事像浪费时间，但回头看，之前走的每一步都有用。

这次上班给我的收获：
