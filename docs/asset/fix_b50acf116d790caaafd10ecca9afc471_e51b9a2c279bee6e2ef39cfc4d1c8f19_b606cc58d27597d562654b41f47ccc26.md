# 2.2 视频号账号的注册与准备 @郭耀天

视频号生长在微信体系里，二者是绑定的对应关系：备好一个微信号，就相当于拥有一个视频号入口。想多开视频号，核心就是多准备微信号。注册微信时需要辅助验证，按官方指引即可——找身边人协助是最常见的办法，手机号既能在营业厅办理，也能用虚拟账号注册。

# 2.2.1 第一步：电话注册

移动用户可以用“和多号”申请小号，但这类号码在微信注册上有限制；联通有小号功能，电信部分区域也提供类似服务，中国广电同样能办。假如在这几家运营商各办五张卡，加起来就是20张，日常操作基本够用。若还不够，找家人帮忙注册即可；团队或公司操作时，安排团队成员批量办电话卡就行了。

[PRE5]

# 2.2.2 第二步：微信注册

如今注册微信确实比以前麻烦，必须走辅助验证。只要请身边人帮个忙，比如找七大姑八大姨搭把手，基本都能通过。注册成功后还需要“养号”，按照普通用户的习惯来使用，刷一刷短视频、发几条朋友圈即可。不过只要不加好友、单纯用来注册视频号，问题并不大，刚注册好的新微信号也能直接开通视频号。团队测试的大量账号就是用这种方式搞定的。视频号眼下确实是窗口期，能多注册微信就多注册，顺手把视频号开通。

[PRE6]

# 2.2.4 第四步：视频号注册

开通视频号前，微信号必须通过实名认证，此处不再细说。打开微信，按照“发现”→“视频号”→右上角小人图标的路径，就能进入个人主页：

点击“发表视频”，设置好头像，把名字、姓名、地址填写完整，再点“创建”，视频号便注册成功了。完成后点击右上角三个点→“资料设置”，就能修改个人资料、补充视频号简介：

需要留意：视频号的命名规则和公众号一致，遵循先到先得，不允许重名。每个账号每年有5次改名机会；如果心仪的名字已被占用，可以申诉，也可以在名字后面加上点或符号，再重新申请。确实想用自己的名字，则需要能证明拥有该名称的使用权，例如有商标、公众号注册得早，或者持有著作权，都可以尝试申请。一般情况下，照搬对标赛道的账号去设置视频号信息就好，不必投入太多时间。

# 2.3.3.2.7 要点总结

封面图极为关键。这类内容的流量入口就是封面图，它直接参与图文推荐机制。抖音主要靠封面图来推流，封面点击率是重中之重；点进来的人越多，系统就越可能把作品推向更大的流量池。

背景音乐也要用心。内容偏忧伤就配忧伤的曲子，偏治愈就搭治愈的旋律，BGM的情绪必须和文案一致，音乐一定要选准！不知道怎么选，就抄同行的答案，同行就是最好的老师。

文案比图片更重要。图片做得好看自然最好，一般一点也没太大关系，但不能太丑；新手完全没必要有心理压力。观众看的是文案，不是图片本身，所以文案一定要清楚。图上文字要让人一眼看懂，不要写太长；每一张图都要有让人想继续看的吸引力，完播率才会好看。如果观众扫一眼就觉得“写的什么呀，太乱了”，手指一滑就走了，完播率必然低，数据也很难跑起来。
