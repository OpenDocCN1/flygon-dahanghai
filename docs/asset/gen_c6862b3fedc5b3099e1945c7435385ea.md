# 广告收益，拆开看更清楚

前面聊过广告收益模型：把广告平台数据和客户端采集到的用户行为数据放进同一个模型里，再结合广告主侧不同的出价方式逆向拆解数据，从而估算每个广告平台能带来多少收益。

这一节就聚焦广告收益，从广告类型、出价方式、广告定位几个角度展开细看。

Adsense 的产品类型主要分两种：PC 网站的内容广告和移动端的内容广告。若从 PRM（每千次搜索产生的广告收入）来看，美国、澳大利亚、英国、加拿大等市场更值得深耕，钱相对更好赚。

出价方式上，收入贡献最大的是按点击计费；广告定位方面，收益最高的是个性化广告，其次是内容相关广告。

如果按每 100 万 PV 带来的广告费来算，不能简单地下结论说中文网站点击单价低、英文网站点击单价高。真正要看的还是网站内容和用户群：内容离钱越近，价格往往越高；用户群的购买欲望越强，价格也越高。
