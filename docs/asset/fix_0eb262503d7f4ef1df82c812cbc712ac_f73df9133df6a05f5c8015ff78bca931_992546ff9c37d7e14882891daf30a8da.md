# 六、实操案例四：把微信对话变成AI日报（仅限Windows）

# 💡

本章要解决什么：

群聊里那些零散发言，能不能攒成一份体面的数据报告？答案是可以。下面完整走一遍。

所谓群聊日报，做法是把某个群在一段时间内的发言抓取出来，喂给大模型做归纳，最后落成一张卡片，上面能看到热词排行、精彩语录、谁最活跃之类的信息。

本章覆盖：

从装工具到出成品，整套分析链路你都会走一遍，最后交出属于自己的专业群聊报告。

无论是向上汇报还是社群运营，这些手艺都用得上。

# 6.2 实操案例一：让微信对话变身日报

微信里若存着要紧资料，先拷到移动硬盘或别的盘符，再动手。

前置条件：

- 系统为Windows 10或更新版本

# 6.2.1 第一步：安装MemoTrace-留痕

MemoTrace（留痕）是一款专门管理聊天存档的软件，可按日期把内容导成Markdown、Pdf、HTML、txt等多种样式，还附带年度总结与分析报告功能。

获取途径：

微信Windows旧版本下载页：https://github.com/tom-snow/wechat-windows-versions

网盘里的留痕安装包：

链接: https://pan.baidu.com/s/1U01bduRMBLviazQNbVDmUA?pwd=92ib 提取码: 92ib

--来自百度网盘超级会员v7的分享

MemoTrace-2.1.1.exe

下载完毕即可运行安装程序。

[PRE8]

有时需要先解压，再双击MemoTrace.exe完成安装；装好后打开软件。

# 6.2.2 第二步：借留痕把对话导出来

先点“获取信息”，再执行解析（电脑上的微信要处于登录状态）。

[PRE9]

进入主界面，挑中目标联系人或者群，点开右上角的三点菜单，那里有txt与AI格式txt两种导出选项。两者差别不大，只是内容组织方式不同，建议各试一次，本篇先走txt。

文件和链接按需勾选，原因在于别的文件一般留在本地，AI处理报表时未必读得动。

[PRE10]

按下“开始”，等进度走完，聊天文件就落到硬盘里了。

结束后点“打开”，系统会跳到对应目录。

# 8.1 指令到底是什么？

绝大多数场合，指令≈说人话。

随着AI进步，过去必须靠精心编排才能约束模型输出结果的情形，未来会越来越多地靠自然语言直接解决。

低频需求通常不必打磨指令，多轮对话往往就够了。

真正值得打磨的，往往是高频复用的场景，比如个人介绍、知识卡片、AI速读等。

所以本章只是借AI可视化做切入点，实操演练一遍：

一条看起来复杂的指令，如何从0到1长出来。

学完本章，你可以把这套流程迁移到生成小红书爆款标题、公众号爆文、小说创作等场景的指令上。
