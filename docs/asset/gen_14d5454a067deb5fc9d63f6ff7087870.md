# 2.1.3.2 人设定位，先想透这五个问题

做 IP 人设，别急着定头像、想昵称。先把定位拆成五个问题：别人如何认识你、你靠什么立身、他为什么愿意停下来、你能给他什么价值。再往下拆，就是下面这些具体维度：

- **有记忆点**：身上得有一个让人记住的标签。比如“已经去过 80 个国家”。
- **有可信度**：要么有专业背书，要么能证明自己够专业。比如“携程签约摄影师”。
- **身份与供给清楚**：你是谁、做哪一行、能交付什么，要一句话说明白。比如“90 后川西旅拍领队”。
- **差异点明确**：你和同类账号到底哪里不同。比如“面向 90 后、只做纯玩小团的旅行组织”。
- **关注理由充分**：用户一眼能看明白；账号定位聚焦；内容始终守着一个垂直方向，不随意发散；最后还要给他一个非关注不可的理由。

一句话总结：人设不是包装自己，而是让用户快速判断“这人是谁、能帮我什么、为什么值得跟”。
