# 从广告投放反推对标：AI账号怎么找、怎么拆

想快速摸清一个赛道里谁值得对标，别急着埋头开拍。先翻出杨昌老师去年那篇盘点，看看2024年Q4各大广告主的投放分布——豆包、Kimi、夸克等品牌都在加大曝光。知道哪些品牌投得猛之后，第二步就是顺藤摸瓜，找到承接这些广告的博主。

拿Kimi举例，在抖音搜“Kimi”“kimiAI”这类关键词，会刷到不少视频左下角挂着链接，或者文案里直接推荐Kimi的创作者。点进对方主页，多翻几条其他视频，判断内容方向是不是你真正想做的。同时要留意他近期的商单情况：有些产品突然爆火，博主可能短期内接了一两条广告，但账号长期变现并不稳，更新也时断时续。这种昙花一现的账号，不适合当作长期对标。接着从这些博主身上拆解定位、风格和呈现形式，筛出真正值得跟的对标账号。长期稳定投放广告的，主要还是几个主流大品牌；用品牌倒推去找对标，确定性会高很多。

# 2.4.2.2 案例二：图灵的猫的深度科普路线

## 内容布局
内容覆盖面广且有深度：专注人工智能领域，涵盖AI预测、AI绘画、AI写作文等多种应用工具的科普展示；也会深入展示自研AI工具的开发过程，比如自动写小说、写高考作文的网站以及反诈AI等；还会探讨AI在游戏等领域的实际应用，多维度呈现AI技术在不同场景中的魅力和价值。

## 人设定位
专业背景深厚：他是专业的AI技术开发者与研究者，毕业于人工智能相关专业，并从事算法开发工作，专业基础扎实。科普角色也很鲜明：知识渊博又乐于分享，善于把复杂的AI技术讲得通俗易懂，帮助大众了解AI的实际应用和发展动态，拉近与观众的距离。

## 简介记忆点
“给岁月以文明，给时代以AI”，这句简介传达出他希望借自身力量推动AI知识普及，让AI在时代中发挥更大影响力的愿景，也彰显出他对AI传播的使命感。

## 表达风格
他的表达专业严谨，在讲解AI技术原理、开发过程时，用词准确、逻辑清晰，能看出深厚的专业功底；同时又能做到通俗易懂，会用生动形象的例子和比喻解释复杂概念，让非专业观众也能理解。

借高考热点做选题，比如“AI预测2022高考作文题”“让AI来写今年的全国甲卷”等，借助高考季的关注度，把AI预测工具的实际应用展示给大众，引发广泛关注。

借英雄联盟S12的热点，用“用AI预测英雄联盟S12总冠军”这类选题，同时吸引游戏爱好者和AI关注者两大人群，实现跨领域受众覆盖，提升选题吸引力和传播力。

还聚焦人性痛点：损失厌恶、担心被骗的人群很广，于是推出“AI迎战杀猪盘骗子”。这个选题聚焦社会热点，通过训练AI与骗子对话，展示AI在反诈领域的应用，现实意义和话题性都很强，因此传播效果很广。
