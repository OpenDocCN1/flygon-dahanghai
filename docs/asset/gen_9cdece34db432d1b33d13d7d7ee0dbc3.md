# 水杯账号靠“时间差”卖爆了

一个做水杯设计的账号，选品思路相当精明。

二月前后，大家对水杯的需求其实并不旺盛，于是它先用设计类内容做铺垫，慢慢养客户。等到六七月盛夏，饮水需求猛增，再把先前攒下的关注者集中变现。

杯子的配色走的是撞色路线，视觉冲击力强。从账号起步阶段起，作者就不断在内容里提醒大家“蹲蹲”。

从二月开号到眼下，五个月更新了三十多条笔记，粉丝涨到2.2万。评论区里“好看”“怎么买”这类高质量留言随处可见，十个粉丝群全部满员，销量已经突破一万件。

有设计功底的朋友，不妨研究一下这套打法。
