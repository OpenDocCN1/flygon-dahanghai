## 2）数字艺术：版权、真伪与收益一起上链

在 NFT 的众多落地方向里，数字艺术的热度一直不低。作品上链之后，创作者能够掌握版权归属，买家也能核验来源和真实性，盗版、造假的空间被明显压缩。所有权证明由区块链来承担，艺术家不必再依赖第三方完成作品保护，中间环节少了一层，收入分成也更有利于创作者。数字艺术完成代币化后，创作、交易以及后续版税结算都变得更顺手。海外原生加密艺术品平台中，Art Blocks 是目前很有代表性的一个。

## 3）音乐：让每一次播放都有账可查

当下音乐人最头疼的问题之一，就是作品被播放后很难拿到应得报酬。过去几年，非法下载一度猖獗，流媒体播放又变得极其容易，整个音乐产业每年因此损失数百万。很多艺术家的主要收入来自现场演出门票，但疫情让音乐行业雪上加霜。区块链进入音乐行业后，听众使用或收听艺人在链上发布的音乐，会通过加密、安全且不可更改的智能合约完成支付。区块链像一个透明账本，一首歌的每笔交易和流向都能被记录；在公共链上，艺术家和粉丝都能查看歌曲在何时、何地被播放。

## 4）门票：把假票和囤票挡在链外

门票伪造和大量囤票，是亟待解决的大问题。NFT 的记录保存在分布式账本上，具有不可更改性，因此票据可以在链上独立验证和认证，作弊手段更难奏效。为了限制大规模囤积，还可以把购票行为与基于区块链的特定身份绑定，从而设置销售限制。

## 5）域名：难记地址变成可读名字

以太坊名称服务（ENS）做的，是把可读名称映射到区块链和非区块链资源中机器可识别的标识，比如以太坊地址。通俗地说，ENS 会把 .eth 域名解析成以太坊地址，让地址更容易记住。ENS 域名也可以在二级市场买卖。如今 DID 赛道还衍生出不少类似形态，例如 .bnb、.bit、.sol、.nft 等。

## 6）身份验证：让数据归用户自己管

NFT 内含特定商品或资产的独特信息，这让它很适合用于区块链上的识别与认证。每个人都拥有独特属性和身份信息，因此病例、个人档案、教育信息、地址等内容都可以借 NFT 数字化，并由用户自己轻松操控。随着区块链应用增多，用 NFT 存储个人数据的人也会越来越多。

## 7）实体资产与文件：房产证也能上链

现实世界中的资产和证明，例如房产、股票、文件、资质、执照、病历、出生和死亡证明，都可以通过 NFT 完成代币化。以房地产为例，传统行业记录土地所有权和财产登记时，文书流程十分繁杂；NFT 能把整个流程数字化。房产在区块链网络上被代币化后，会成为可交易的代币，在二级市场轻松流转，经纪人、银行、代理商和律师等中间商也就能被省去。

## 8）DAO 与社群权益：一张 NFT 就是成员证

随着社区不断发展，许多传统运营模式正在转向完全去中心化的自治组织，也就是 DAO。NFT 可以作为 DAO 或社群的唯一证明，持有者能够享受社群私密信息、互动机会，以及可能的收益分红。

# 12.3.3 从预热到开图：NFT 发售全流程 @可达 Koda

这里简要梳理一个 NFT 项目从发起到发售，再到发售后各阶段的机会。

项目准备启动时，通常会先运营一个推特账号做预告。官方会不时发布 NFT 预览图，也会举办白名单活动。白名单可以理解为提前购买 NFT 的资格证明：拿到它，基本就能确定买到该 NFT；有些白名单还附带额外权限，比如免费铸造权或折扣购买权。这个机制有点像参与港股打新时拿到申购新股的资格。

到一定阶段，官方会开设 Discord 服务器。Discord 类似“微信+论坛”的综合体，一个服务器里可以开很多个类似微信群的频道，是国外最流行的聊天工具之一，也基本是所有 NFT 项目运营的标配。服务器里会有综合聊天区、公告区、灌水区、粉丝作品区、地区语言交流区等频道。想拿白名单的用户，需要在 Discord 完成官方指定任务，例如邀请人、提升聊天等级、提供美术作品等，以此争取资格。

接下来进入预售和公售。预售阶段，拥有白名单的人可以优先铸造 NFT。白名单数量通常占发行量的 1/8 到 1/4，比如发行 10000 个 NFT，常规会设置 2000 个以上白名单。预售结束后，一般在 24 小时内，也可能更短，就进入公售阶段，向社会大众开放，大家都有机会购买。热门项目可能出现几万人抢几百个 NFT 的场面，拼的就是手速。目前常规项目售出的多是盲盒状态 NFT。公售后过一段时间，官方会宣布何时揭秘盲盒，也就是俗称的“开图”。NFT 有稀有度设计，稀有度越高价值通常越高，类似限量款，价格甚至能冲到顶峰。开图当天交易量往往达到高点：有人把自认为普通的 NFT 挂售，鲸鱼玩家则买入较稀有的 NFT。之后，项目会按官方 ROADMAP（路线图）继续发展，可能表现不及预期、价格大跌，也可能越做越好，成为新一代蓝筹 NFT。

# 12.3.5 NFT 常见术语速查 @焦波｜水镜

下面这些常见术语，先建立概念即可：

MINT：铸造，也就是生成 NFT 的动作。很多机翻会把 MINT 译成“薄荷”，在 NFT 语境里理解成铸造就对了。

FREE MINT：免费铸造。一般指项目不收铸造费，只需支付小额 GAS 手续费。成本低，在热度有保证的情况下，获利概率相对较高。

PFP：Profile Picture，主要用作社交网络头像的 NFT，例如 Cryptopunk、BoredApes。

ETH：以太币，常简称以太，是以太坊这条主流公链的加密货币。主流 NFT 多架设在以太坊上。素材写作时，1 个以太币约 1250 美元，约合 8500 元人民币。

Alpha 社区：Alpha 是投资领域用词，指不论市场如何变化都能获得的收益。Alpha 社区通常寻找这类投资机会并分享给社群成员，机会往往出现在项目早期白名单阶段。

Scam：骗局，指项目本身有问题，可能骗取金钱或盗取钱包。

Rug：全称 Rug Pull，中文直译“抽地毯”，通常指卷款跑路。

Opensea：目前最常用的 NFT 交易平台，也简称 OS。

蓝筹项目：认可度较高的 NFT 项目，一般指总量 10000 以上、地板价长期大于 5 ETH 的项目。

空投：英文 Airdrop，指向特定人员发放 NFT 或代币。比如 BAYC 母公司曾给每个 BAYC 持有人发放约价值 100 万美元的土地空投和 Ape 代币空投。

MOD：Moderator，即 Discord 社区或单个频道的管理员。

开票：Ticket/support，意思是与项目方单独沟通。Discord 中项目方会开设专门频道，用户遇到技术或特殊问题时可在此沟通。

版税：在 Opensea 或其他平台交易 NFT 时，每笔交易会扣除发行方设置的税费，这就是版税，一般为 5%—10%。

LFG：Let's fxxking go，类似冲锋口号，是 Discord 讨论中常见的聊天吹水词。

FOMO：Fear of Missing Out 的缩写，中文即“害怕错过”。指人们因担心错过下一波行情而盲目买入。

Diamond Hand：钻石手，指项目的长期持有者或坚定持有者。与之对应的是 Paper Hand，即纸手，铸造完 NFT 后有利润就抛售的玩家。

DYOR：Do Your Own Research，自己研究。

# 12.3.6 普通人玩 NFT 的稳妥打法 @焦波｜水镜

普通人怎样玩 NFT 更合适？

普通人的资金量较小，也经不起大风险和频繁交易的手续费摩擦。所以更稳妥的方式还是一级市场：挑选较优质的项目，尽可能早地拿到白名单，然后在铸造阶段确认有确定性市场收益后再出手。

初期练手时，可以选 ETH 链上免费铸造的项目。免费铸造只需支付小额 GAS 费，常规在 1—5 美元之间，可以多次实操走流程，快速提升经验。

另一种做法是拿到白名单后直接出售获利。这种安全系数更高，但可能损失潜在收益。当然，如果短期项目非常热门、存在很高溢价可能，完全可以直接出手。

遇到确定性收益项目，抢到就是赚到，尽量多参与。以太坊项目可以用“抢失败不扣 GAS 费”的方法避免损失；BSC 和 SOL 链的 NFT 手续费都很低，这类机会可以大胆上。

还有一些几乎零成本捡钱的机会，尽可能多参加。比如填表就可能获得白名单，而填表限制不高，那就可以大量填表提升获取白名单的机会；再比如玩游戏获得 NFT、解谜获得白名单等，不需要花费成本，都可以多参与。

如果有一定时间和英文沟通能力，可以尝试应聘 Discord 管理员，一般会获得白名单作为回报。遇到好项目能应聘上，收益也不错。

或者不直接下场玩 NFT，而是为玩 NFT 的人“送水”。比如批量生产账号，替别人做账号邀请、聊天、画画等任务，同样能获得不错的收益。
