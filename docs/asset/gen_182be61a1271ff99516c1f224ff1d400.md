# 6.2.4 高客单成交，靠什么提速？

做高客单转化，我总结了几个实战体会。现在我们每月客单价 1 万元的客户，大概能成交 25 个。真正起作用的，主要是下面三点：

1、案例越充分，成交越快

早期手里没有案例，谈单周期拖得很长；后来把案例整理成 H5 页面，转化大单的速度明显提上来了。

2、敢拒绝，反而更吸引人

刚开始收高价时，我面试筛选做得少，结果成功率没达到预期，客户量也不理想。后来我开始设门槛，条件太差的直接不接，拒绝之后还会发朋友圈。有人甚至直接打钱过来，我也没有收。这样的拒绝多了，找上门的人反而更多，整体素质和能力也提升了不少。所以规矩必须立住，没有规矩，大单很难来。

3、销售工具要齐全，这是临门一脚

最近世界杯，很多人球都带到门前了，却踢不进去。这和不少老师聊转化很像：客户都问到课程了，最后还是没成交。问题未必出在话术，而是转化工具没跟上。只靠一张嘴收大单，确实不容易。
