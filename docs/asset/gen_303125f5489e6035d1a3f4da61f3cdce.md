# 8.2 正念处理情绪：四个关键动作

面对情绪，很多人第一反应是担心被它困住，于是本能地开启防御。可情绪通常比理性更早到场，防御往往拦不住，反而让人产生挫败感，进一步滋生出更多低落与烦躁。真正会处理情绪的人，走的是另一条路：先觉察，知道自己此刻正处在某种情绪之中，并接纳这个事实；再做分析，冷静拆解这份情绪；然后着手处理、解决问题；同时在整个过程中不断复盘、优化做法。

这套路径的理论根基，是心理学中的正念疗法。它主张带着清醒意图去感知，把注意力放回当下这一刻；在觉察与专注的过程中，不急着作价值评判，也不忙着区分好坏对错。

落到操作上，可以先问自己“我现在是什么感受”，承认它存在；接着分析这份情绪；再找到合适的应对方式并行动；事后回看处理过程，调整下一次的做法。如此反复，情绪便不再是需要躲开的东西，而成为可以练习和提升的能力。
