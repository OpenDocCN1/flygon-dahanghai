# 儿科医生零基础起步，如何把育儿社群做到10w+变现？

大家好，我是黄伊森，一名在上海三甲儿童专科医院工作了18年的儿科医生。这些年我接诊过超10万个宝宝，生财社群第6期新人。我的主业是医生，副业是医疗自媒体、健康科技公司顾问，还有母婴好物电商。我的目标是当好生财的首席儿科医生，为球友们的下一代服务。

今天想跟大家聊聊，一个完全没有社群运营经验的素人，是如何把人生第一个付费社群做到600多人，保持高活跃度，跑通商业闭环，最后成功变现10w+的。

我是2020年从新西兰留学回来，继续做医生。在此之前，既没做过自媒体，也没碰过社群。回国后从2021年中开始做短视频和图文，直到2022年初才打算建自己的第一个私域社群。

既然是儿科医生，第一个社群自然是宝妈育儿群。建群前我对运营一无所知，于是先去听了生财星友@北大苏姐的一堂社群运营踩坑课。那堂课直到现在我都印象深刻，从中学到了不少社群运营容易踩的坑，先分享给大家。

大家都听过那个著名的消费能力排序：孩子＞女人＞宠物＞男人。所以说，育儿+宝妈群的消费能力和变现空间都很可观，宝妈群也始终是各类社群里最活跃的。但要是运营方式不对，很容易就沦为一个日常闲聊加吐槽的群。

我始终觉得，一个真正的好社群，应该是带着大家共同去完成某件事，让人愿意待在里边，每天都觉得有收获、在成长，而不是每天为了“活跃”而活跃。

加入生财后，看到不少球友都在卖生财日历，还运营日历共读群，把同频的人聚在一起，交流见识、一起成长。这让我确定了私域社群的方向：育儿日历共读群。群规就是“抱团取暖，互惠利他，保持同频，鼓励链接”。把育儿日历做成类似生财日历的共读形式，每天分享一个育儿知识点，宝妈们每天都有新内容可以学习，还能围绕主题展开讨论。

第一批种子用户，其实是我门诊的铁杆粉丝。社群虽然是付费的，但最初一部分人是免费邀请进来的，都是些小朋友的家长。她们作为第一批友军，给了我特别大的支持。

在群舆论把控上，她们帮了我很多。我每隔三四天就会问她们一次，对分享内容和运营有什么反馈。因为之前建立了信任基础，她们给的反馈特别中肯、直率。我听完就及时调整，事实证明这些调整对社群运营非常有效，让内容分享变得更高效、更及时。

在那之前，我完全没有互联网销售经验，完全是个素人。记得我的自媒体合伙人@梁靠谱医生，曾在她自己的生财日历共读群里分享：一个互联网素人想闯出名堂，第一靠持续的内容输出能力，第二要有属于自己的互联网标签。

后来我关注到视频号直播正火，也看到粥左罗老师在做连续100天直播挑战。当时我就冒出一个念头：我是不是也能在自己的社群里发起一个连续100天直播挑战？

说实话，刚定下这个目标时，我心里完全没底。能不能连续10天都难说，更别提20天、50天、甚至100天了。

为了不让自己半途而废，我做了几件事逼自己坚持：

第一，我直接在付费育儿社群里放话，说黄医生会每天直播，分享育儿科普、在线答疑。这是对付费用户的承诺，既然做了内容付费产品，就得说到做到。

第二，我跟好几个自媒体伙伴放出消息，说自己要做连续100天直播挑战。话已经说出去，大家都在看着我，这就没有退路了。

第三，我每天都在朋友圈打卡，发倒计时：“连续直播100天挑战之第N天”，让朋友们一起监督我。开弓没有回头箭，既然包都扔过墙了，就不得不翻过墙去。

但连续100天直播，难的不只是时间连续，更关键的是内容要保持高质量。你不能每天到点开播，瞎聊几句就结束，得让来直播间的每个人都有收获，还能对你这个人和产品有更深了解。所以我专门做了详细的直播选题规划。

其实育儿科普的话题非常多，但每个话题的热度不一样，也不是所有都适合直播分享。我结合自己十多年来的临床积累和门诊经验，从育儿方方面面里选出了近100个选题，每天和大家聊一个。

当然，我也不是什么都懂。定好选题后，还要去查最新资料、请教同事，确保直播间里讲的都是最新、靠谱、实用的育儿知识。

我还报名了几个视频号直播训练营，系统学习直播间的准备、运营、话术、互动和转化技巧，比如怎么选封面、挂福袋、上链接、发红包、和粉丝互动等等。平时有空也会去场观数据好的大V直播间，学人家怎么做直播。有了理论储备再去实操，心里会踏实很多。

随着育儿社群做得越来越久，我发觉家长不只看儿科，还很关心眼睛、口腔、儿童心理等方面。于是我请来了口腔科、眼科、儿童心理学的专家，一起做视频号连麦分享。

同时，我也关注到宝妈们自身需求，所以又邀请了医美科和妇产科医生，聊聊医学美容、产后康复。这些分享嘉宾，一方面满足了社群成员的不同需求，另一方面大大增加了内容深度，还能互相引流，提升彼此个人IP的影响力。

最关键的是，这些都是我这些年积攒的业内人脉和资源，别的育儿社群很难复制，这也是我们打出的一个差异化优势。

宝妈群体消费能力强，婴儿用品占了很大消费比例。可市面上产品太多太杂，还有不少是智商税。我从儿科医生专业角度出发，帮宝妈看成分表，筛选合格、靠谱、实用的育儿产品，让大家少踩坑、少交智商税，这也是一个非常吸引人的点。

后来直播过程中，不少母婴电商平台主动找我合作。经过沟通和筛选，我选了一家觉得靠谱的母婴用品平台。我们新建了一个“伊森严选母婴好物群”，主打靠谱实用、有专业背书的母婴产品。

到现在，我的整体销售额已经超过10w+，个人佣金也到了一万多块，这还是上海疫情期间物流严重受限的情况下做到的。虽然这个数字不算多，但任何100万都是从第1块钱开始的。而且随着口碑和影响力不断积累，未来的增长一定不是线性那么简单。

社群运营到一定阶段，就需要在合适的时机迭代升级，从低客单价向高客单价转变。下面是我做的几件事。

随着社群越来越大，成员的需求也在不断增加。我要求自己敏锐观察社群需求的变化，甚至主动挖掘潜在需求，再根据这些需求升级产品，这样才有可能把客单价一步步往上提。

刚开始运营育儿社群时，它只是低客单价的引流产品，和很多同类社群一样，我一个人包揽所有事情。因为临床干得久了，群里90%的问题我基本都能解决。

但社群慢慢壮大后，你会明显感觉到：一个儿科医生即使专业知识再全面，也无法覆盖儿童健康的所有领域。现在的宝妈关注点越来越多，不只生病看医生，还包括喂养、睡眠、儿保、视力、口腔等等。另外，宝妈自身需求也值得挖掘，比如产后康复、女性成长、宝妈副业，这些都是潜在的社群增长点。

那发现新需求、自己又没办法满足时，怎么办呢？

我的策略是：放弃个人创始人IP，找同行当医疗合伙人，打造一个“小而全”的团队。

医生这行比较特殊，合伙人不仅要专业过硬，还得具备一定互联网思维和商业思维，愿意在线上输出专业知识，能跟上社群运营节奏，一起做产品升级。比如遇到小朋友有眼科、口腔、睡眠、喂养、身高这些需求时，我就会在各种社群里留心观察，寻找优秀的同行。遇到合适的，就邀请对方来做一次直播连麦或图文分享，在过程中考察他的专业能力和互联网输出水平。

经过层层筛选，我最终找到了6位医疗合伙人。他们能覆盖儿童心理、喂养、睡眠、口腔、眼睛，以及宝妈产后妇科问题等健康需求。这样一来，我们社群的护城河就挖得更深更宽，专业能力也上了一个台阶。

合伙人团队确定后，我专门写了一份合伙人手册。手册里清楚列明了每位合伙人需要在社群输出哪些内容、什么时候需要做什么事，做到分工明确。

同时，手册里也写清楚了大家可以通过哪些渠道赚到钱。我的原则是“进四出六”，社群产生的利润，大头分给各位合伙人。只有这样，大家才会有足够动力去拉新、做好社群服务、持续成长，整个团队也才能更有凝聚力。

做知识付费的人，大多很反感那种双手朝上的白嫖党。但在社群升级时，我反而设置了一个体验卡制度：如果对我们的社群不太了解，新用户可以免费体验28天。在体验期内，不限次提问，还能参加期间举办的实操训练营。28天全程免费，到期后你可以自由选择退出，如果觉得我们的服务没达到预期，我们一分钱不收。

为什么敢这么设计？因为我们做的是长期陪伴型的育儿社群。28天对一个宝宝来说非常短暂，我们只是给宝妈一个机会，了解这个拥有专业服务团队的社群到底怎么样。

我们完全不担心她白嫖28天。因为她一旦体验过我们的专业服务，我们很有信心她在28天后会选择付费留下，而不是退出。毕竟在别的地方，很难找到第二个这么专业的育儿社群。这一点，我对自己的产品非常有信心。

而且付费用户也是一个双向筛选的过程。如果发现这位宝妈的育儿理念实在跟我们相差太大，我们也会主动劝退。28天结束，好聚好散。毕竟育儿理念不合，强留也没意义。

3月8号是我们社群运营一周年纪念日。我在育儿星球举办了会员日抽奖活动，参与方式很简单：写一段这一年来和社群发生的故事，再晒一张宝宝照片，就可以参加抽奖。

这个活动主要为了创造共同回忆，同时让宝妈们主动给我们提供真实反馈和宣传素材。效果真的不错，收获了很多真情实感的好评，都是真实发生的故事。这些素材后来反复用在朋友圈和社群升级宣传中，特别有价值。
