# 4.2.4 法律类选题：新闻怎么挑更稳妥

做法律类内容，选题这一步很关键。写新闻稿时，尽量挑官方媒体已经报道过的事件，这样后续引发投诉的概率会小很多。

尤其要避开时政、军事议题，把目光放在柴米油盐、邻里纠纷这类民生话题上，越贴近普通人的日常越好。真正容易传播开的新闻选题，大多也集中在这一类。

这也是我这次没让大家去微博、知乎翻素材的原因。地方台的新闻栏目同样能当选题库。刷到某条新闻让你血压飙升，就把它列入候选；看完毫无波澜的，直接放过。

想更冷静地判断，就拿“开幕雷击七要素”逐条对照：命中两条以上的优先考虑；只中一条的别急着用；一条都不沾的坚决放弃。

至于配套法条，直接上网搜就行。搜索词要抓住事件的核心。打个比方，有人把别人的头打破了，就搜“把人打成轻伤怎么判刑和赔偿”，相关材料会出来很多，整理后放进这一部分即可。
