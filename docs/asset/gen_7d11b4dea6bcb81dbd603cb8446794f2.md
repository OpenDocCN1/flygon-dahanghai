# 3.3 高客单：精品课教学类PPT实战

下面以教师精品课比赛中的科普类为例。这类一手订单的价格通常在四位数，二手订单也有大几百，属于高客单PPT，对质量和能力的要求都比较高。

精品课比赛一般由教育行政部门、教研机构或学校组织，面向各级各类学校教师开展教学能力竞赛。呈现形式以微课或课堂实录为主，同时配套教学设计、学习任务单、课件等教学资源，通过逐级遴选评出优质课程。

精品课官网是：https://jpk.basic.smartedu.cn 。官网里有很多案例，不了解的话直接去看展示案例，就能大致明白我们要交付的内容是什么样。

基础教育精品课作品的基本要求（教育部标准）如下：

- **学科课程、特殊教育、人工智能教育、阅读课**：以微课形式呈现，小学10—15分钟，中学15—20分钟；需提交微课视频、教学设计、学习任务单、课件、作业练习，部分类别可选。
- **实验教学类**：以**课堂实录**形式呈现，需提交实验教学视频、实验教学设计、导学案、课件等。
- 内容必须符合国家课程标准，体现核心素养导向，解决教学重点难点问题。

## 3.3.1 先把需求对接清楚

这单客户已经自己写好了逐字稿；如果客户没有写，也可以根据需求用AI辅助生成内容。我们要做的，就是根据他的逐字稿制作精品课PPT。精品课每年官网都会发布对应要求，制作时必须按这些要求来。

制作时有一个重点：页面右侧要留出三分之一的位置，目的是给后期剪辑留出空间，把老师真人讲课的人像放进去。

**向客户索要文件：**

如果涉及比赛，一般都会有相关的比赛要求文件，不同比赛对应的官网也不一样，让客户直接发给我们即可。

通常接到这类客户时，对方都是带着明确意向来的；或者接二手订单时，老板已经和客户沟通好了。你需要做的是了解精品课是什么（精品课官网：https://jpk.basic.smartedu.cn）、它的制作规范，然后按照客户选定的课程内容进行制作即可。

正常情况下，一个精品课课件并不需要生成很多数字人对话，一般2—3个、每个10—30秒左右的AI视频就足够了。

## 3.3.2 数字人精品课PPT制作全流程

**智能抠图或者自定义画笔抠图**都可以，一般智能抠图就够用了。它会自动把刚生成的数字人视频黑色底抠掉。

有时候对话过长，即梦不能一次性生成，需要把数字人说的话分成几句，分别生成视频后，再在剪映里拼接。数字人说话的音频生成后，有些语气语调不准，可以换个音色重新生成试试，音色不同，说话效果也会不一样。如果实在无法把控音色，也可以真人录音，然后在剪映里把真人录音放进去。

[PRE39]

怎样让两个人物一个有动作、一个静止不动？

在剪映插入一段数字人视频后，把鼠标放在第一帧的位置，点击“定格”，会出现一段人物静止的视频画面。这段静止画面，是为了让小女孩说话时小男孩保持不动，定格视频的时长要和小女孩说话的时长相等。

同理，生成小男孩说话、小女孩不动的视频时，生成一段小女孩的定格画面，让它保持与男孩说话的时长一样。

其中一个视频完成后，可以先打个水印和客户确认，再继续往下做。

**视频打水印方法：**

文本—文字模板—在搜索栏搜“水印”，选择其中一种直接拖拽到编辑区最上方，把时长拉到和视频时长相等的位置，这样视频从开始到结束都会出现水印。客户定稿以后，直接把水印这一层删掉即可。

[PRE45]

由于客户要求但凡有学生说话的地方就要有数字人，而数字人说话是视频，需要和PPT上的文字内容相互搭配。

PPT中播放视频时，如何同步展示文字内容呢？

我的解决办法是：把这页PPT的背景当作视频的背景，先生成数字人说话的视频，视频右侧留出PPT文字展示的位置。

把视频放进PPT时拉满整个PPT画布，让视频作为PPT的最底层，再在视频上面放PPT的文字和图片。
