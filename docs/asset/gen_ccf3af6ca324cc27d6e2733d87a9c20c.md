# 1.3 航海权益 | 选择靠谱大团长，帮你避开这些坑

在航海项目里，帮卖团长的安全感和收益，很大程度上取决于你选谁、跟谁上船。

先提醒一句：请务必认真挑选合作的大团长。一旦遇人不淑，就可能遇到这些状况——

客户付了款，货却迟迟发不出来；商品实物跟图片完全是两回事；收到的东西有瑕疵，售后却推三阻四……

所以才会反复强调：别轻易帮卖，别轻易帮卖，别轻易帮卖。

同样值得留个心眼的，还有那些不相熟的人发来的帮卖卡片。如果对方来路不明，最好先做个细致的背景调查，搞清楚对方的情况再决定是否合作。否则风险可能悄悄藏在后面。

这里说一个最大的坑：假设你通过A推荐，成了某个团长的帮卖。后来你的客户买了货却出了问题，需要退款。这时系统会从A的账户里扣除他之前拿到的佣金，用来退还给你客户。可如果A早就把账户里的钱提现干净，余额为0，那这笔退款操作根本进行不下去——卡住了，客户的钱退不了，你的处境也会非常尴尬。

举个更具体的例子：我给你一张二维码卡片，你扫码成为某个团长的帮卖，之后每卖出一单，我就能获得大概1%到1.5%的佣金（关于佣金的详细说明，可以跳转到「2.2.1 帮卖团长参与帮卖」查看）。如果后来你的客户要求退款，系统会把我的那1.5%佣金退回去。但万一我提前提现走了，账户里一分钱没有，你的客户退款也就跟着没戏了。

所以说，光看团长的排名和订单数据，根本不靠谱——这些都能造假。你需要对快团团的货源渠道有自己的判断力。至于怎么甄别，后文专门有一篇「2.3 快速去看如何甄别大团长是否靠谱」，到时候可以对照着看。

因此，向你推荐帮卖的人，同样至关重要——你很可能因为一个人的介绍，就掉进另一个人的坑里。

为了让本期航海更稳、更安心，我们特意联系了一批靠谱的供货商大团长圈友，由他们来提供货品，帮大家更顺畅地跑通整个流程。具体名单会在开船后，于航海群内统一推送给大家。

如果你眼下没有合适的货源，可以先从这些推荐团长的商品里挑一些来帮卖。只要产生订单，佣金就会自动结算到你的账户上。先拿到第一笔正反馈，成功开启第一步，后续的信心自然就有了。

另外，航海期间，航海群内只允许上架推荐团长的货品。这么安排，主要是为了帮大家避免因为货源不靠谱而引发初建群时的“信任危机”，助力每位圈友顺利完成首单。据多轮验证，15%以上的圈友第一次在朋友圈发布商品，当天就能成交。

等航海期结束，更丰富的供货资源就需要大家自己去寻找和拓展了。但请务必记住：无论如何都要仔细筛选，千万不要一加了大团长的账号就急着带货——先把对方验证清楚，再启动销售，这才是长久稳妥的做法。
