# 五、选供应商，合适比便宜更关键

💡 挑合作方，别急着比价，先想清楚自己到底要什么。

找供应商这件事，最怕一上来就广撒网。先把手里的需求理明白：要什么规格、多久交一次、能接受什么价位、质量底线在哪。需求越清楚，后面筛人越省力。

渠道也别只盯一个地方。行业展会、同行推荐、线上平台、本地产业带，都可以交叉着看。初次接触时，先问产能、问交期、问做过哪些类似客户，再让对方发资质和案例。能说清楚细节的，通常比只会报低价的更靠谱。

到了实地或线上核验环节，重点看两件事：一是它有没有稳定做这类产品的能力，二是出问题时有没有人及时对接。条件允许的话，先小批量试单，用真实订单验证质量、交期和服务，比听十句承诺都管用。

最后别忽略合同和风险。付款方式、验收标准、售后责任、违约处理，都要提前写明白。合适的供应商，不是价格最低的那个，而是能长期稳定配合、让你少操心的那个。
