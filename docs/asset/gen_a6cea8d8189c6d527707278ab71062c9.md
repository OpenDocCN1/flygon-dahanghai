# 亚马逊还能做吗？选品、运营与自动化破局笔记

先给结论：亚马逊这门生意，现在仍然能做。

我是张子卿，97年生，在B2B跨境电商做了两年，2021年年中转到B2C亚马逊，从蓝海选品切入创业。一年多时间里，围绕消费者真实需求做产品研发设计，在美国站做到GMV 1000W以上，毛利十多个点。

下面聊聊我们创业途中碰到的问题和对应解法，主要分享一些道与术。这篇是精简版，完整版一万多字，链接放在文末。

开始前先打个预防针：亚马逊生意的终局，看的是投资回报率和链接资产；创业阶段的核心优势，是能用较低成本、较低门槛反复试错，并且借势。借势的关键落在选品上——借中国制造丰富且响应快的供应链，对产品做独特设计和改良。

**—01— 选品难怎么破：先定赛道，再迭代产品**

我习惯把复杂问题拆成几个简单步骤来想。

任何公司都得牢牢握住选品能力，这是做亚马逊的核心。选品在我看来分两块：一是选赛道，二是产品迭代优化。

一、选赛道

选赛道的核心思路，是利用可获取数据背后的信息，按3个原则做筛选：

关键词就是赛道；
关键词搜索量代表市场容量；
市场容量与关键词下竞争情况之比，决定赛道蓝不蓝海。

具体操作上，我用数据软件和爬虫并行解决。先对海量关键词做粗排序，找出要做的蓝海市场；再靠人工和相应软件做详细调研、精排序，把赛道定下来。

二、产品迭代优化

选完赛道，还要持续做产品迭代更新。本质上，我很鼓励跨境卖家走这条路：从研究产品，到研究用户，再到研究真实世界的需求。

常用方法有几种：先确定定价区间、算清利润范围、给出采购预算；再研究用户和需求，决定做哪类人群，是高客单价走利润，还是低客单价走量。预算区间内，尽量做这些迭代：

1. 成本优化，比如材质变更；
2. 外观优化，比如颜色、包装改进——本质在主图，在点击率影响的广告权重；
3. 把设计理念传递到链接文案优化——产品设计可以和运营端讲故事结合；
4. 降维；
5. 跨维；
6. 产品研发设计。

产品迭代优化：

1. 优先考虑能否降低成本。因为除非走海运，否则产品预算已经严重不够；稍有波澜，ROI连50%都达不到，风险过高。采购成本上，在保证质量的前提下找价格最合适的卖家；运输成本上，思考海运方向；材质方面，看是否有更合适、更廉价且同样能满足需求的材料。写此文时，已经有人做了类似变换。

[PRE13]

额外溢价方向，是能否修改产品本身，做出更高溢价空间。经过一系列沟通，得知产品底部磁铁如果还要更强、尺寸更大，成本需增加2元。聊遍市面厂家后，硅胶材质上进一步降成本这条路已经不可能。走海运确实能降一部分，但基本和增加的磁铁成本抵消。

这时就要思考：能否用其他材质满足同样需求，以此节省成本，达到理想ROI。同时也可思考，能否进一步满足潜在消费者需求，做出高溢价产品。也就是说，实际定价可以高出11.99$区间。

如何让客户在众多商品中一眼就想点？可以从产品颜色改变、外包装改进、配件增加入手。总之要结合实际拍摄主图难度深入思考，最好达到一眼让产品脱颖而出的效果。甚至可引入测试投票，用PICKFU网站完成。对这款产品而言，这方面收效甚微，因为该类目直接上应用场景图，而不是白底图。改变颜色、增加配件、优化外包装来提高点击率，都是建立在白底图基础上。

3. 从理念传递到链接文案优化——产品设计可以结合运营端讲故事。数据导向最终看产品转化率。简单说，产品设计之初如果抱有某种理念，后续链接文案和详情页会事半功倍。比如卖化妆品，设计之初就是为身上有疤痕的女士提供纯天然高质量遮瑕产品，文案上就可以大做文章。对我们这款产品而言，可以从优化生活细节、保护孩子和宠物等角度考虑，但影响并不大，也不值得按新理念重新设计。因为这是实用类产品，看的是实用性和使用价值，而且不管硅胶还是塑料，开模成本都比较高。

关于运营端需要关注的数据细节和数据陷阱：

**—02— 运营端别只看日常：关键指标与数据陷阱**

运营端除日常操作外，还要尤其关注几个关键数据指标和表相陷阱。

如果以计算机算法角度思考运营端数据，对一个产品最核心的关键数据是：点击率、转化率、核心关键词排名、星级评分，以及整个项目单位时间的ROI。

一、点击率——产品可影响的最核心指标

点击率排第一，原因在于它直接影响广告组权重，影响广告出价。点击率高的产品，出价上可能相差100%；1美金出到2美金的位置很常见。影响点击率的核心因素有：主图、价格、标题、星级。

PS. 广告核心权重在点击，点击本质在选品后端的迭代端和主图。点击率可以人为大幅调整优化，也叫可操作数据。比如一张优秀主图，可直接拉升50%点击率。

二、转化率——一个巨大的数据陷阱

市面上无数帖子和回复都提到，转化率是产品极重要的数据指标，这本身没错。它在我眼里是陷阱，问题在于它基本属于不可操作数据。

想想转化率和哪些因素有关：价格、五点文案（产品卖点）、图片、A+页面、QA、评论区、AZ/BS标签……你会发现，如果按正常流程做每款产品，比如认真调研、开发产品卖点、参考对比、写出本土化文案、找相同团队拍摄图片和视频等，转化率其实拼的是内功、产品开发设计、文案、图片、视频、QA。

核心点：影响关键词排名的核心权重，在于链接单位时间对应关键词下的销售额，即淘系说的坑产。

产品上架后，转化率几乎无法操控；上架前，这些工作基本已形成固定流程，也无法大幅变更。所以产品开售后，除了测评和降价，运营几乎没有手段影响转化率。归根到底，转化率体现的是做产品过程中流程制度的优越性。上架后不需要过度每天关注，因为可做的事很少。

三、关键词的核心排名

其他表象级影响因素：标签、转化率、评论、星级、历史数据等，均为间接影响销售额的数据。这里必须是对应关键词下的销售额，站外和折扣都不计入其中。

四、如何用优化leadtime解决现金流不充足而项目过多的问题，同时降低单项目备货失败风险？

——以leadtime数据为导向，从投资角度思考亚马逊这门生意。

运营端还需特别关注并对整个项目ROI和风险做评估，对所需资源量和回报率合理预估。这种能力的流程化，对将来能否突破商业天花板尤为重要。

这里重点提一点：要对全年整个项目的资金投入ROI进行优化和关注。这就需提到leadtime这个核心指标。leadtime是从产品生产到发货上架这段时间，对整个大框架项目ROI影响非常重要，而且是可控数据。

举个不完全准确的例子：假如一款木制品，生产30天，运输25天，上架5天，那么leadtime就是60天。假设售价39.99美金，重量1.5kg，产品成本40元，佣金15%，FBA配送费5.4美金。海运15/kg，产品运费需要22.5元。不考虑广告等其他投入：

产品利润（39.9*0.85*6.3-40-5.4*6.3-22.5）=117.1
产品运费和单价为（22.5+40）=62.5元
理想ROI=117.1/62.5=187%

假设月销1000套，实际需要投入的资金远不止1000*62.5元。因为leadtime长达60天，一个月销售就可能需要三个月资金投入来保证不断货。往往你投入的是3个月资金，而实际在售卖和计算的是一个月库存资金的ROI。所以在60天leadtime前提下，实际ROI往往只能达到理想187%的三分之一。日常运营中，销量是增长或动态的，实际支出往往比理想状况还多。这还没算亚马逊压的回款等因素。

如果通过提高产品单价、选择出货更快的供应商、选择更快物流，把leadtime缩短到40天，哪怕单价上升10块钱，最后实际资金ROI也远大于之前。节省下来的空置资金还可以投入新项目。这就是leadtime数据的核心思想：优化leadtime，哪怕牺牲部分利润，因为你可以用更少的利润赚更多的钱。产品上架后，不断降低leadtime，其实就是另一种财务角度的优化。

小结：

运营端工作切勿陷入表象，而忽略深层次内核。比如转化率、关键词排名，建议结合公司实际情况深入思考，做针对性流程优化。同时，亚马逊初创阶段资金有限、可做项目较多，Leadtime优化对最终相同投入下实际资本回报率影响巨大，甚至往往可以牺牲利润换取高速周转。

到这里，只要不断尝试、不断迭代优化，小团队的亚马逊模式就能运作起来。

但任何商业模式，我们都希望做到像工厂流水线生产一样自动化，这是做业务的终极追求之一。

针对亚马逊业务，如果想突破认知天花板和选品上限，核心点在于：

自研发选品软件，解决选品产能问题；
通过流程化制度和体系化知识，培养跨境电商领域的产品经理，解决产品落地问题；
文案和图片专业外包，靠有视觉审美的运营去统筹并提出专业需求；
成熟期产品使用人工智能调节广告，实现后端运营全自动化，从回复追评到广告中后期都可以用人工智能。
