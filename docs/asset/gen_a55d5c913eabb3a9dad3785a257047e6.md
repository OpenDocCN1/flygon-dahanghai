# 7.3.5.6 标题写对，笔记才有人点

标题这个话题放到最后聊，恰恰因为它是整篇笔记里最关键的部分。

它有三个核心作用：第一，标题要提炼笔记主旨，让用户一眼看清重点；第二，标题会影响点击表现，会写标题的人往往能戳中用户需求，把浏览变成点击；第三，标题还关系到搜索效果，关键词排布得当，系统更容易判断笔记属于哪类内容，从而推荐给更匹配的人群。

标题中的关键词安排，一般要从以下四类搜索词里至少选一类用上，例如：

- 核心词：迷你披萨❤️君君辅食记
- 转化词：闭口黑头怎么办？看看李佳琦是怎么做的吧
- 热搜词：小🐑人亲测有效！！喉咙的刀片取出来了！！
- 关联词：不夸张的彩色睫毛大测评！心机又特别！

当然，核心词也能与别的词类组合使用，常见的有：

- 场景词：提升幸福感❗️100 个办公室养生好物🌟
- 人群词：梨形👭进｜请收下今日份敷衍痩腿运动✅
- 价格词：均 10💰好物合集‼️清洁/提亮/润唇/卸妆
- 品牌词：MAC 眼影盘平替！天王老子来了都说是亲姐妹
- 功效词：10 元冬季国货护手霜太🐂了！保湿防开裂！
- 本地词：杭州拱墅店的小猫求抱抱太可爱了

有一点要提醒：不要为了搜索流量或吸睛，硬堆与自家产品或笔记内容无关的搜索词。标题与正文不符，用户会有被欺骗的感觉，平台同样不鼓励这种行为。

前期挖掘和布局关键词，确实要投入一些时间和精力；但一旦做好，就能更充分地利用📕的免费流量，让目标用户持续主动找上门。
