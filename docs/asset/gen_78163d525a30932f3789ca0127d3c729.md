# 动笔前，先摸清📕笔记的门道

真正开始下笔前，有必要先认识📕笔记的常见呈现方式与内容类别。

从呈现方式看，主要分为图文与视频两类。图文内容在平台上的占比和出现频次都居首位，对刚入门的新手也最友好；视频笔记在曝光和涨粉上的表现更亮眼，当前还能获得平台扶持，不过对创作经验和时间投入有更高要求，若是想塑造个人 IP，视频形式往往更能打出效果。

从内容类别看，我们整理了 6 种对新手最友好、在起号阶段更容易跑出爆款的笔记方向：✅合集类笔记 ✅测评类笔记 ✅科普类笔记 ✅避坑类笔记 ✅教程类笔记 ✅攻略类笔记

通往爆款的路不止一条，大家不妨结合我们提供的内容，挑选最契合自己的一种或几种笔记类型去尝试。
