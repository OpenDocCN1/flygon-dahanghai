# AI写高考作文，别只盯着“秒出”

高考作文题目一公布，热点立刻升温。朋友圈和不少AI账号纷纷晒出“AI几秒写作文”的成果。我原本没打算跟这个风，但翻了几篇这样的展示后，还是决定写几句。

原因不在热点本身，而在于我看到的普遍偏差：很多人把AI写作理解成按一下按钮就拿到成稿，仿佛中间不需要分析题目、搭建框架、反复沟通和修改。真按这种思路去考场，恐怕也很难凭自己写出好文章。

我想做的，不只是用我的方法示范几篇作文。我更想借“让AI写高考作文”这个具体场景，把一次完整的思考和解题过程拆开：如何理解任务、如何给AI有效输入、如何判断和调整输出。考场作文只是切口，背后讨论的是AI参与文字创作时更普遍的方法问题。

接下来进入实操部分：我具体如何借助GPT完成一篇考场作文。步骤较多，篇幅也长，完整内容我放在飞书文档里，想看细节可以移步过去。

评论区里有读者把要点总结得很到位：第一，GPT不是神，仍然需要使用者认真交流、持续训练；第二，GPT看起来让创作门槛变低，实际上对使用者的判断力、表达力和方法要求更高，人与人之间的分化可能因此更明显。
