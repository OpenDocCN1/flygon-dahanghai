# 百万爆款四步法：先专业，再铺货

我是跨境杨少，在跨境电商里摸爬滚打13年，也连续做过多个跨行业项目，九成以上项目做到年变现百万级。说白了，我是彻头彻尾的“蓝海偏执狂”。我有一套《选品四层方法论》，这篇是微缩版，完整内容放在付费课里。

我把选品由下往上拆成四层：

1. 套利：低成本、信息差、确定性——先把风险压住；
2. 流量&转化：每一分钱、每一段时间，至少得解决流量或转化中的一项——拒绝自嗨；
3. 模式：选品要进化成选模式——红利期才够长；
4. 品&品类：建立自己的“选品字典”——才谈得上规模复制。

下面我用一个四步选品范式，带你看这四层是怎么被满足的。标题写“必胜法”确实夸张，但过去一年多我多次讲过这套东西：在亚马逊官方活动当过分享嘉宾，也在线下大会讲过。听众里有大卖、大V、大服务商、大外贸厂老板，多数人回头一看，自己的成功基本没跑出这四步的范围；一些做国内电商的朋友也受了启发，有人按这个思路选出淘宝蓝海产品，客单净利做到200—400元，红利期还不短。所以标题里我也就不再强调“跨境电商”四个字。

生财有不少大咖大V，本质是成功的流量团队。流量做强当然能成，甚至一夜暴富，但总带着“昙花一现”的焦虑。盗坤在公众号里反思过：没有长期可做的好产品，常常像打游击，这个判断很真实，我也欣赏他的自我迭代能力。生财当然也有产品很顶的大V，比如seven，但他的产品多靠白帽流量，和很多流量团队的打法比，偏冷启动。强流量和强产品如果能合在一起，长期主义的赢面会大得多。

做产品很复杂，有钱人有各种打法，聊差异化三天三夜也说不完。本文只从“没钱”的角度出发：做产品到底有没有成功率较高的套路和规律？也算抛砖引玉，希望炸出更多产品达人分享经验。

1. 平台怎么挑：亚马逊、独立站、TikTok、速卖通、Etsy、Ozon、Shopee、煤炉逐个看

平台挑得准不准，往往一眼能看出选品功底。会选的人通常会盯三个条件：一是小语种发达国家，二是人口超过一亿，三是有本地入驻门槛的头部平台。比起不分青红皂白乱做，这三条是不是听着就更容易赚钱？先记住这三点。

a) 亚马逊

亚马逊好不好做，不能一句话回答。欧洲、北美、拉美、日本、澳洲、印度、中东，各地情况差得远。澳洲是发达国家，客单高、竞争也少，但人口只有两千万，亚马逊市占率甚至低于eBay，同样的功夫砸下去，单量可能起不来。

我认为欧亚、美亚、日亚还能做，但只限蓝海选品。美亚现在风评不好，很多新手亏钱；可同一套蓝海打法，放到虾皮连毛利都没有，在亚马逊仍能做到客单净利100元人民币以上。新手不懂蓝海，抓不到利基市场，一边铺货一边乱压FBA，一亏十万起，这能怪谁？

FBA好还是FBM好？判断标准就四个字：客户体验。FBA物流快，体验更好；产品有竞争时，体验更好的一方更容易出单。真抓到蓝海独家产品，客户只能找你买，你发货慢他也得等，FBM照样能出单。所以蓝海选品完全可以用FBM测品，把成本风险降下来。我听过很多跨境主播的直播间，几乎没人把“客户体验”和“分产品判断”讲透。

所以新手面对“亚马逊好不好做”“FBA还是FBM”该听谁的？听自己的。先弄懂，知其所以然。讲不出所以然的人，大概率是镰刀；镰刀还有个特征——承诺你一定能发财。

b) 独立站

过去三年我对接服务过1000多个独立站，有些老板做站群。有些品类我一看就大概知道有没有戏。比如两三年前，大部分独立站是杂货铺，确实有老板一个月赚100万，但近两年基本死光了。杂货铺靠FB测爆款，本质还是铺货思维，没有选品，只是把铺货搬到了FB广告组里——独立站站内铺货没意义，因为没有自然流量。

现在活下来的是品牌出海站、垂直站、定制站。两三年前顾小北强烈推荐的FB+Shopify模式，如今也只能偃旗息鼓。所以现在很多人说独立站不行了，这部分人基本都踩过FB测爆款的坑。流量分两种：人找货和货找人，FB流量属于货找人。现在模式信息差没了，测的人多，还有不发货、不对版的，ROI早崩了。

但独立站也有人找货的平台式流量：SEO见效慢，不推荐；搜索广告和Google Shopping广告可以。再加上会蓝海选品，这类独立站玩家目前比较容易赚钱。可市面上独立站课程大多还是FB+Shopify那套，模式早崩了，就算顾小北亲自来教也没用。

所以说独立站好做不好做都对，听自己的。要懂底层判断依据：流量和转化。让自己多专业一点并不难，不专业怎么赚钱？

c) TikTok

它和FB一样，也是“货找人”的流量性质，算了，洗洗睡吧。

TikTok是娱乐平台。你要卖货就得拍产品视频，可产品短视频怎么娱乐别人？平台凭什么给你流量？TikTok还分很多国家，你选得好吗？不会又选到东南亚去了吧？

有人信奉“大力出奇迹”，每天上100个视频，喊着要all in。你的时间不值钱？all in一个月，好好打工赚不到一万块？这样做TikTok和赌有什么区别？90%的新手做TikTok是两条腿断着走路：一条是流量，一条是选品。另外还不懂用付费广告解决流量跑出去的问题，也不懂通过投放标签选相对精准的人群。可从TikTok广告一级代理商的数据看，投放ROI极不稳定，付费玩家盈利的都不多，何况只想蹭一蹭的玩家？

TikTok让人心痒的地方是，每天都有人靠自然流量爆单；让人心碎的是，每天爆的都不是你。成功老板抓确定性，只有韭菜财迷爱抓彩票。我接触的大卖，没有一个把主战场放在TikTok。

d) 速卖通、虾皮

低价平台。

这两个平台的卖家都比我厉害，因为我算来算去他们都是亏的，我是真算不出他们怎么赚钱。那价格我只能说“word妈”，我认输，我太菜，看不懂，再见。

我在速卖通有过短暂成功，不到两年，因为做了一个在国内抢注成功的品牌的山寨。类似打法还有把国外三线商标抢注到手表等品类上，再上速卖通——速卖通只要有国内商标注册证就合规就能卖，老外分不清这些，可以蹭流量，高客单高转化。

虾皮有一部分赚钱的店群卖家，产品或多或少还是跟侵权沾边。虾皮现状是仿牌都卖亏本价，这让做蓝海选品的人怎么玩？虾皮入驻广告铺天盖地，跨境电商界坑宝妈和副业人群最多的就是虾皮。

Temu也是低价平台，不建议新手入。前两年Fanno出来时，跨境界一片欢欣鼓舞，我当时接受财经媒体采访就说不看好：一是低价平台，二是作为字节亲儿子，TikTok却不导流，底层上流量和转化都存疑。半年后果然崩了。

e) Etsy和Ozon

相对新兴的平台，有一定铺货红利期，估计也快结束了。Ozon也是低价平台，意思不大。俄罗斯现在把西方大牌赶走了，平行进口合法化，所以在Ozon上卖仿牌有一定红利窗口，只要票据全，你懂的，中国卖家这些都能搞定。Etsy有很多设计师产品，手工艺品这个类目迭代比亚马逊快，跟亚马逊之间有平台搬运红利，有助于亚马逊蓝海选品参考。

f) 煤炉、FB商城C2C

这两个几乎都是店群或者批量账号卖仿牌，不多讨论。

2. 第一步：找蓝海，市场、平台、产品方向一起看

我把蓝海市场和蓝海平台分成几类：

最蓝的（第一类蓝海）：1.小语种发达国家，2.人口大于一个亿，3.有本地入驻门槛的头部平台，比如日本乐天。

次蓝的（第二类蓝海）：1.发达国家，2.人口大于一个亿，3.平台仍有蓝海选品空间，比如亚马逊欧美日。

微蓝的（第三类蓝海）：1.新上线的平台，2.刚开始开放中国卖家入驻的平台，即使是低价平台也有一点铺货红利期。

不蓝的：所有低价平台。

只要你有选蓝海市场、蓝海平台的意识，就已经超过90%的跨境小白和新手。

接着找这个市场的蓝海方向。比如日本我们找到真皮方向，美国我们找到户外防风防水科技材料方向。有没有方法按图索骥地发现这些方向？“海关壁垒”算一个，还有“平台搬运”“材质升级”等，更多方法和具体落地在付费课程《选品四层方法论》里。

真皮方向属于海关壁垒，详细文章见我第一篇精华帖，里面有筛选过程、落地案例和细节。简单说，我们筛选日本海关关税信息，发现真皮制品在日本的关税非常高，导致真皮制品在日本市场价格长期处于高位，没被传统外贸倾销过，价格体系没被打破过。比如真皮靴子，日本人普遍认为应该卖到100多美元以上，而中国工厂出厂价有的只有几十人民币。这就是一片广阔的蓝海选品大方向。

蓝海方向不是蓝海品类。真皮或者科技材料，可以做的品类有好几个：真皮我们重点选鞋类，科技材料既做鞋类也做服装类。方向有了但还宽泛，离落实具体选品有距离；不过到这一步，我们已经开始解决精准流量了，因为真皮就是一个相对垂直的关键词，对应的是对产品有要求、又有一定消费力的人群，高科技材料也一样，有自己的搜索量。

到这一步，你已经实现蓝中蓝，基本告别难中难，比如虾皮，可以说超越99%刚入门的小白和新手。

3. 第二步：走捷径，流量和转化一起设计

有人信“七分选品，三分运营”？我们认为选品就是运营，运营要解决的主要就是两个问题：流量、转化。好的选品，在确定具体产品的时候，就已经把引流方法和转化方法（卖点）定下来了。也就是说，好的选品模式，必须把流量和转化解决一个，或者两个都解决。

举一个两个都解决的选品模式：合规山寨。

很多朋友分不清山寨和仿牌。仿牌是违法的；山寨确实有一些产品侵权，比如侵犯商标权、专利权（外观专利、设计专利、知识产权专利等），但也有大量山寨产品可以做到合规。为了区分，这类合规产品我们不用“山寨”二字，而叫“平替”，即：

合规平替。

合规平替不仅能平替具体明星产品，也能平替高端材质。这两种做产品方向都自带流量，因为明星产品和高端材质有相应搜索流量，这也是我们可以布局的精准流量。只要产品合规、有自己的品牌，在亚马逊就可以大胆投放竞品品牌的关键词广告，包括很多知名大牌；除了品牌词，还有产品系列词等等，都是好用又便宜的精准流量词，既可以直接投付费广告，也可以做关键词优化拿自然流量。课程里提供了4个具体寻找精准词的引流方法，另外还包括平替如何实现合规。

4. 第三步：加光环，品牌力、溢价、复购快速补齐

十年前我们发现，JEEP、骆驼、CAT的鞋服，实际上跟美国JEEP越野车、骆驼香烟、CAT重型机械没啥关系。这三个鞋服品牌在国内最早是由中国老板成功抢注下来的。十年后，这三个品牌都不同程度与美国品牌方达成和解或者授权，普通卖家已经不能随便去卖，但这个骚操作值得借鉴。

十年前我们还发现，日本市场的乐天平台和亚马逊平台，对这三个品牌的鞋服都不要求授权备案，也不进行审查，因为这三个品牌的鞋服其实在国外并不存在；由于是知名品牌，也没办法在日本抢注到鞋服类目上。所以对中小卖家形成了一个几年的搬运倒卖窗口期。这正是我们第二桶金的来源，我们在日本长期垄断了这三个品牌鞋服的销售，还给它们起了个名字，叫“空壳品牌”。这也是一种选品模式，虽然只有特定的窗口期。

这个模式到今天仍然具备可复制性。例如上文提到的、我们在速卖通能做到客单净利润100+的产品，就是这个模式出来的。而且空壳品牌在速卖通有独有的合规优势，上文已经解释过。

我们把空壳品牌按占便宜程度、境外合规风险程度，分为几类：

1.抢注国外品牌，并复制它的全系产品，例如koolaburra已被UGG收购；
2.抢注国外品牌，并跨类目做新类目产品，这是速卖通常见的套利玩法；
3.在国外注册品牌，策划国外的品牌故事和品牌形象，这是国内电商常见的品牌捷径。

在不同时期，以上3种打法都在亚马逊有过窗口期，目前还可以继续做的是第三类。

很多老板做品牌出海，或者做美亚，老老实实用自己的中国品牌形象，不是不行，但更好的方案一定是策划一个空壳品牌。比如我们在日本做一个德国品牌，在东欧做一个日本品牌，在美国做一个欧洲或者日本品牌，这都是可行的，本土客户查不到，故事随便你说。

这个打法在淘宝也有非常大的红利。某做渔具的淘系卖家，就把它的渔具包装成日本品牌，做日本独立站官网，再反向营销到国内市场。因为日本渔具比较有口碑，直接带来的就是远高于淘宝渔具正常利润的高溢价空间和复购。

按我们的经验，成功的空壳品牌可以做到10%的复购，带来的净利提升最多可以达到30%。这不仅是一个增加转化的方法，有时候甚至可以单独演变成一个选品模式，低成本、搬运式地输出成功产品去跨境市场。这个由于信息差比较大，以后有机会再介绍。

5. 第四步：微创新，把红利期拉长

前三步基本上都可以工具化实现，要么花点钱实现；第四步主要是做产品差异化，对人的要求高一些。如果做成功，对应的护城河更深，产品红利期也更长。

微创新其实就是不创新。

我们比较推荐新手去做的微创新差异化套路是：材质套利，它是上文材质平替的一个延伸。

新手做差异化，不要去考虑原创设计、痛点迭代，这些方向没有专业积淀，很难拿到成功确定性。新手适合基于大标品，去做升级式的和热点嫁接式的差异化产品。

首先，大标品不愁卖，也不需要买选品软件去分析大标品。但大标品往往很多是低级材质，或者价格战重灾区，客单非常低，没有利润空间。大多数新手也喜欢一上来就干这个。跨境直播间凡是讲亚马逊热卖产品的，都不乏人气，这在我看来跟路边看人吵架没啥区别，没有任何意义。

其次，真正的高端货，中国卖家向来也不去挑战，也挑战不了；那么中端性价比市场就相对空白。我们找出高端材质这个方向，找到可以还原90%体验的低成本平替材质，去做这个稍稍消费升级的人群，将规避掉大量竞争，获得长期的蓝海空间。上文的平替案例可以看到，1688已经有现成的供应商，甚至投入就在几千块的水平，就可以做出差异化产品，这个非常适合新手。

但如果把它放到与十几、二十几的冲锋衣一起展示，它就无法展现差异化的卖点，也没有价格优势。所以这个SKU干脆放弃标品词，只做长尾词，这样才能获得流量优势、转化优势。这就是差异化产品的优势。

刚才说的是材质升级、平替套利的差异化。下面我们看一个材质升级+平替套利+热点嫁接的差异化：

[PRE7]

材质升级：帆布升级到真皮；
平替套利：头层皮换成二层皮，成本下降三分之二；
热点嫁接：厚底、边扣；
精准流量词：真皮、厚底、边扣、某品牌、高跟、增高、女式板鞋、侧拉链等等；
转化点：厚底、经典平替、极致性价比等。

所以这个鞋子跟普通帆布鞋、板鞋标品比，实际上有4个差异化点：1.真皮，2.边扣，3.厚底，4.平替。每一个点都对应一个精准引流点。精准流量的转化率远远高于大词标品词，还便宜，因为竞价的人少。

达到这个差异化水准的产品，70人民币跨境卖70美金，老外仍然觉得性价比爆棚；1688仍然有做好的现货。新手发现不了这样的供应商，是因为认知不够、关注不到。
