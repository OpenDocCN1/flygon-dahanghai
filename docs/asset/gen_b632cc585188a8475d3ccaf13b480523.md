#### 3.2.3.2 模型怎么挑？
前面聊了MidJourney不同模型的出图风格，接下来自然要问：到底该怎么选、怎么切换模型？MidJourney默认使用V5.2，想换其他模型，只需在提示词末尾加上对应参数。
切换模型的参数格式是：
（空格）--（V或niji）（空格）（模型版本）
这里的“--”表示调用参数，后面还会反复用到。
[PRE12]
#### 3.2.3.3 关键点回顾
1. V1-V3模型已经过时，不建议再使用。
2. V4、V5、V5.1、V5.2各有特点，可以按作图需求灵活切换。
3. niji4和niji5更适合动画场景。
4. niji5有三种预设风格，niji4没有。

### 3.2.5 常用参数全解
上一节提到，切换模型需要在提示词后加参数，例如“ --niji 4”就是选用niji 4模型。
其实MidJourney的参数远不止模型切换，还有其他各类参数。之前文生图、图生图、局部重绘和扩图部分已经接触过一些，这里再具体展开。
#### 3.2.5.1 参数① --seed：种子值

讲到这里，应该能理解这个参数的意义了。它的核心用途就是复现图片。
只要拿到一张图的提示词和--seed值，就能在MidJourney里生成相同内容。
比如用MidJourney生成了一张“未来城市夜景”创意海报，效果特别吸引你，觉得非常接近理想设计。但又担心下次输入同样提示词做不出这张图，这时就可以用--seed值来复现。
那--seed值怎么获取？用之前生成的猫咪图片演示一下。

#### 3.2.5.5 参数速查表
下面把MidJourney里可能用得上的参数整理成一张清单，先大致看一遍，需要时回来翻查即可。
💡
《MidJourney参数速查》
1. 纵横比（--ar / --aspect）：调整生成图像的长宽比例。
2. 变化程度（--chaos）：取0到100，决定生成图像的多样性，数值越高结果越独特、越出人意料。
3. 快速模式（--fast）：临时切换到快速模式运行当前任务，加速图像生成。
4. 图像权重（--iw）：取0到2，设置图像提示相对于文本描述的重要性，默认1，数值越高图像影响越大。
5. 排除元素（--no）：例如“--no plants”会尝试在生成图像中排除植物。
6. 渲染质量（--quality / --q）：可选.25、.5或1，决定图像渲染质量和耗时，高值质量更高但更耗时。
7. 随机风格（--style random）：自动在提示中添加随机风格代码，可选16、64或128种风格之一，增加创意元素。
8. 放松模式（--relax）：临时切换到放松模式运行任务，生成较慢但资源消耗更少。
9. 重复任务（--repeat / --r）：取1到40，用同一提示多次创建任务，适合快速尝试多种结果。
10. 种子（--seed）：取0到4294967295，指定生成图像的起始随机因素，相同种子和提示会产生相似图像。
11. 提前终止（--stop）：取10到100，提前结束生成过程，数值越小图像越模糊、细节越少。
12. 风格（--style）：切换不同版本的MidJourney模型，例如不同5.x版本或Niji模型，改变图像风格。
13. 风格化（--stylize / --s）：控制MidJourney默认美学风格对图像的影响程度。
14. 图块（--tile）：生成可作为重复图案的图像，用于创建连续图案效果。
15. Turbo模式（--turbo）：临时切换到Turbo模式运行任务，加快图像生成速度。
16. 怪异（--weird / --w）：取0到3000，探索不同寻常和创新的美学风格。
17. 视频（--video）：生成图像生成过程的短视频，适用于某些特定模型版本。
18. 提示变体：使用大括号{}创建多个提示的不同变体，例如{red, green, yellow}会生成红色、绿色和黄色的不同图像。

### 3.2.4 常用命令一览
接下来学习MidJourney的命令。前面说的参数主要帮助调整图像细节，而命令更像是在告诉MidJourney我们要它做什么。
其实之前已经接触过一些命令，比如“/imagine”代表让MidJourney生成图片，“/describe”是让MidJourney帮忙优化描述词。
除此之外，MidJourney还有哪些常用命令？
#### 3.2.4.1 命令① /blend：图像混合
/blend可以将2到5张不同内容的图片融合在一起。
[PRE41]
在生成的图片中，MidJourney把黄色圆形面包和用叉子挑起的意面融合在一起，效果相当不错。
#### 3.2.4.2 命令② /setting：默认设置
setting即设置，可以在里面调整默认模型和风格、出图速度等。
[PRE42]
每个按钮对应的功能列在下面，感兴趣可以看看：
Use the latest model (5.2)：下拉菜单，可选择使用MidJourney最新模型版本生成图像。
RAW Mode：原生模式，使用最少的预设风格和处理，让生成图像保持原始状态。
Stylize low/med/high/very high：调整图像风格化程度，从低到非常高，数值越大风格化效果越明显。
Public mode：公开模式，创作会在社区公开展示。
Remix mode：混合模式，允许对已生成图像进行局部修改和再创作。
High Variation Mode：高变异模式，生成图像会有更多变化和创意。
Low Variation Mode：低变异模式，生成图像变化较少，更接近初始提示。
Sticky Style：粘滞风格，一旦选择某种风格，会被保留并应用于后续图像生成。
Reset Settings：重置设置，将所有选项恢复到默认状态。
点击按钮变绿表示已激活或开启，再次点击即可关闭。
#### 3.2.4.3 命令③ /info：账户信息
info命令可以查看个人信息，包括充值时间、剩余快速出图时长。快速出图时长用完后，如果不购买，会自动使用慢速出图。慢速出图是无限生成的，速度大约比快速慢三分之一，前提是服务器空闲；如果服务器一直拥挤，可能一张图要等十几分钟甚至更久。

#### 3.2.4.4 命令清单
除了上面提到的，MidJourney还有其他命令，已经帮你汇总好了。

《MidJourney命令清单》
获得答案（--ask）：向MidJourney提问并获得答案。

帮助（--help）：显示关于MidJourney机器人的有用基本信息和提示。

自定义选项（--prefer option）：创建或管理自定义设置选项。
查看选项（--prefer option list）：查看当前自定义选项。
后缀添加（--prefer suffix）：指定添加到每个提示末尾的后缀。
变化切换（--prefer variability）：在高和低变化模式之间切换。
公共模式（--public）：专业计划订阅者可切换到公共模式。
放松模式（--relax）：切换到放松模式，图像生成速度较慢。
