# 写在最前面

欢迎加入六月航海｜小红书电商-蓝海实拍｜实战手册。接下来这段路，我们会在手册里碰面许多回。

正式动手前，先聊清楚两件事：

1）小红书高客单蓝海到底是个什么项目？值不值得投入？

放眼2025年，小红书电商仍旧处在红利窗口期，并已进入放量增长阶段。站内用户购买力不容小觑，且主动搜索的习惯已经养成，这恰好匹配高客单蓝海产品的特质：利润空间可观、竞争者偏少，新人拿到正向反馈的周期也相对短。

本次航海紧跟平台风向，主攻高客单、高利润、可长期运营的模式：

开局以一件代发轻装上路：锁定高利润蓝海品后，用混剪二创的方式快速验证市场；

当单品链接积累起稳定销量，再切换到实拍模式，并同步加深与供应链的协作，压低风险、放大利润。

相较于以往低客单混剪的玩法，这套方法要求更多技能储备，时间投入也更大。新手在前期能零零散散出单，但要实现持续稳定的收入，通常得深耕两到三个月。建议大家提前做好心理建设。

2）哪些人更适合这条高客单蓝海路线？

有电商选品根基、对爆款有嗅觉，或者具备图文/视频制作功底和审美sense，跑通概率会明显更高。

当然，足够勤奋也能弥补不少短板。本期航海偏考验耐性；想要稳定收入，新手大致需要两到三个月打磨技能，不过从0到1跑通这一步会相对轻快。

# 零、项目介绍

# 章节概要

当前小红书上，大约九成商家扎堆在女装、日用、小配饰等低客单赛道，卷价格、卷款式，单笔利润常常到不了30%；

而高客单蓝海品类（手工银饰、中古家具、户外装备等）供给量＜搜索量，平台流量池还在持续加码——供需失衡，就是溢价的温床。

本章结合平台趋势，拆解为什么选高客单蓝海、以及具体怎么操作，为后续落地打好地基。

# 0.1 为什么建议做小红书蓝海电商

# 小红书电商趋势

小红书电商摸爬滚打几年后，部分大品类已逐渐拥挤，竞争近乎白热化，但仍有不少细分方向仿佛未被开采的矿脉。本期教练之一古辛是淘宝蓝海出身，在他看来，小红书蓝海更具优势：客群以女性为主，对客单的接受上限更高，利润也更肥厚。

小红书同时跑推荐与搜索两套机制，因此创新产品等品类在此更容易起势。创新产品源源不断、层出不穷，只要流量机制维持现状，蓝海就能一直做下去——因为总有新东西可卖。

并且，相比红海类目，小红书蓝海离成交更近，正反馈来得更快。品挑对了，开单并非难事。

# 蓝海电商的特点

正反馈来得快：这是小红书蓝海最鲜明的标签。

竞争偏温和：所以更容易做出成绩，打价格战的概率也小。

项目寿命长：能走多远，核心取决于平台流量机制；机制若稳定，蓝海就能持续。淘宝蓝海后来步履维艰，根源就在流量机制发生了改变。

产品供给无忧：只要选品方法对了，蓝海品会持续涌现。

# 成功案例

小红书蓝海的门槛并不高，入门不难，哪怕毫无电商背景，也可能较快拿到正反馈。

品选准了，出单顺理成章，因为竞争不激烈。真正难啃的是持续稳定出单，这既考验产品本身的稳定性，也考验搞流量的本事。

# 0.2 玩法说明

1. 最小可行路径

a. 操作链路：注册账号开店 > 选品（关键）> 找笔记素材 > 发笔记测品（关键）> 出单后对接供应商 > 上架商品并发货 > 有持续流量后下样品 > 实拍并发布笔记 > 做好店铺运营管理

b. 时间节奏：头3天搞定开店＋选品，第一周至少发5篇笔记，持续选品测品，争取第3周出首单，再切到实拍

2. 项目核心关键点

a. 选品权重：70%决定成败

b. 最小可行思路：前期别急着实拍，先把蓝海选品—混剪笔记—卖出首单这条链跑通

c. 内容效率：航海会教大家用AI工具辅助提效（Deepseek＋多维表格写爆款文案）

d. 轻资产投入：初期约1000元/店铺保证金（也可等提现时再交），后期采购样品每次预估几百元（也可跟老板谈免费拿样）

3. 航海目标

a. 选品是个需要反复练的技能，电商选品定生死。新手21天未必能赚钱，这很正常，别焦虑。项目寿命长，要盯长期收益。

# 1.1 准备账号

# 1.1.1 准备至少2个账号

新手一般建议开个人店铺，2个个人店铺对应需要2个账号，具体要备好：

1. 至少2部手机（不建议一部手机多开，可能被限流）

2. 至少2张电话卡（2个小红书号需2个实名，对应2张卡）

3. 至少2张身份证（可用家人的）

电话卡推荐：

三大运营商均可办副卡，一人可注册认证5个号码，一拖四，副号月租10元；

移动万能副卡，1张10元月租，一个身份证能领2个副卡，第一张和第二张需间隔90天，营业厅能办，App也能办，但营业厅可争取免首年月租；

中国电信App搜无忧卡，5元一个月，基本第二天就送上门；

移动可办8块的保号套餐。

手机推荐：

手机除了登录账号，也会用于视频拍摄。

拍摄建议用iPhone，XR以上机型效果最好；

后续放大做直播，iPhone的直播稳定性也更佳，但iPhone无法双开。

# 1.1.2 账号登录&养号

账号登录：

同时运作2个账号，有人会问：我能用一部手机登录吗？

可以，但有风险。

若手机自带小红书应用分身（部分安卓机型有，比如红米），可一部手机登两个小红书号；我目前这样操作，账号还没出过问题。

[PRE11]

但手机没有分身功能时，别去下载分身神器，容易封号。这种情况下只能再备一部手机登账号，去闲鱼或拼多多买二手，三四百块钱就能满足日常需要。

实名认证：

注意：小红书实名认证，一张身份证只能认证一个账号，认证成功后只有注销账号才能解绑。

认证路径：我 - 左上角三条杠 - 创作中心 - 创作服务的更多服务 - 开通专业号 - 成为专业号 - 选择个人点击立刻申请 - 输入实名认证信息即可。

# 1.1.3 开通店铺

# 1.1.3.1 小红书店铺分类

入驻之前，先弄清楚店铺种类，因为不同种类权益上有差别。

大方向分两种：个人店铺、企业店铺。

无论哪种类型，都要先认证专业号，因为新注册账号默认非专业号，而非专业号不能参与任何商业行为，包括薯条投放、开店铺等。

所以，想在小红书变现，第一步是把账号升级成专业号。

专业号也分个人专业号和企业专业号。

个人型：

个人专业号身份标识为XX博主，比如时尚博主、美食博主等兴趣类博主，基本申请即过，且不收取任何费用。

认证流程：

点击【创作中心】—【更多服务】—【开通专业号】—【我是个人】-【实名认证】-选择身份证，填写相关信息即可。

[PRE18]

个人专业号可申请开个人店铺或个体工商店。

名称为XXX（昵称）的店；

店铺保证金最低1000元；

按类目不同，平台收取2-5%技术服务费。

企业型：

申请企业专业号需上传营业执照，并缴纳600元费用，身份标识为XX品牌。

申请流程：

点击【创作中心】—【更多服务】—【开通专业号】—【我是企业】-【填写基础信息】-【填写主体信息】-【资质公函上传】-【运营人信息填写】-缴纳600元费用，等待审核。

填写注意事项见下图：

申请之后要多留心，因为申请有效期为30天。30天内没完成申请，费用不退。通过后每年年审，并续费600元。

企业专业号可开普通企业店和专卖店/旗舰店。

名称为XXX专卖店/旗舰店；

普通企业店保证金最低2000元（详见《小红书类目保证金明细》）；

月营业额＜1万，平台免收技术服务费；

超过1万的部分，平台收取5%作为技术服务费。

2023年9月10日起，一个营业执照最多申请2个专业号、2家店铺。

[PRE20]

同一品牌只能开一家旗舰店，但可同时开不同类型的店铺，比如一家旗舰店+一家专卖店，或一家旗舰店+一家普通企业店。

企业专业号的营销权益比个人专业号更多，但两者只能二选一，可按需选择。

一般来说，新手开【个人店】即可，门槛较低；企业店主要用于放大做矩阵，平台对账号的宽容度也更高。

# 1.1.3.2 【个人店】入驻门槛与流程

入驻门槛：

个人型店铺又分【个人店】和【个体工商户店】。

个人店仅支持服装、百货等常见类目；个体工商户店除常见类目外，还支持奢侈品、珠宝等。

[PRE22]

每个店铺类型可经营类目不同，打勾部分就是可经营类目，具体可在小红书学习中心-规则中心-经营总览中查阅。

开店要缴保证金。个人店和个体工商户均为1000元，但保健品、奢侈品等特殊类目会贵一些。

[PRE23]

客服接待角色，个人店铺可选平台代运营和自主客服两种模式。注意平台代运营要收费，大家按自身情况选择。

平台佣金又叫技术服务费，按类目不同收取2-5%服务费，收费准则详见：https://school.xiaohongshu.com/rule/detail/27/2585?jumpFrom=school

目前小红书为减轻个人店和个体工商户开店负担，店铺入驻后无需缴纳保证金即可发布商品上架售卖。若该店铺累计交易额超过1万元，下个月月初才需补缴保证金，真正实现“无门槛”开店。

入驻流程：

选择个人店铺后，需选择经营类目，之后只需提供姓名、身份证号、手机号，并进行人脸识别，验证成功后店铺开通。

[PRE24]

个体工商户店铺需提前准备：

（1）公司信息的营业执照照片、公司名称、统一社会信用代码、经营地址以及营业执照有效期；

（2）店铺运营授权书。

同样先选店铺经营类目，再按提示上传资料。

与个人店铺不同，个体工商户店审核时间通常为两到三天。

期间可自行登录入驻系统查询。若入驻中遇到无法解决的问题，可在9点到24点直接联系人工客服咨询。

# 1.1.3.3 【企业店】入驻门槛与流程

入驻门槛：

企业型店铺分普通企业店、旗舰店、专卖店以及集合店。

普通企业店铺与个人店铺命名格式一样，“专业号账号名称+的店”。注意企业专业号取名要和商标对应，否则会开不了店铺。

旗舰店名称为xxx（品牌名）旗舰店，专卖店为xxx专卖店，集合店铺为xxx的海外店。

企业型店铺支持经营大部分类目，包括保健品、医药等特殊类目。

平台佣金与个人店铺一样，1w以下不收费，超过部分按5%收取。

保证金根据类目不同略有差异，一般境内最低2万，境外3500美金。
