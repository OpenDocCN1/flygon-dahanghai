# 两轮改稿，押题书三天冲到近三千单

文/猎音狮 2023年5月22日

圈里的朋友好，五六月对教辅图书来说，是冲中高考配套产品的黄金档。王后雄家的押题卷、万唯那套中考黑白卷，最近都挺走俏。

[PRE0]

万唯这套黑白卷，没投流也跑出了订单。下面这张图，是我近期起量的意林押题作文素材。

[PRE1]

到今天，接近三千单已经落袋，曲线还在往上抬……

[PRE2][PRE3]

当然，不是首条就炸。前后改了两轮，数据才起来。先复盘初稿。

有预测说，今年中考作文或许会碰到“淄博烧烤”这个材料。理由不复杂：一些地区的二模卷里，已经出现了相关题目。

如果真撞上，孩子从哪儿下笔？家长可以先点个赞、存下来。

我给四个切口：
一、拿真心换真心；
二、游客与城市互相成就；
三、独有特色才抓人；
四、借势风口完成跃迁。

学生在校园里摸不到手机，对淄博这波热度可能没概念。可热点远不止这一个。《意林中考作文热点素材》里，智慧、变、我的高光时刻、互联网、我心目中的英雄等方向都收进去了，也都有入题可能。意林这套书，十二年里多次和真题方向撞上，连拿来就能用的素材都替孩子选好了，考到就能直接下锅。

所以临考那几天，这两本书还是值得翻一翻。

[PRE4][PRE5]

首条内容在五月三号上线，我也顺手发进了星球。点子来自抖音首页的一条短视频：人家五月二号发，我第二天刷到，直接拿来改了。

[PRE6]

内容上线后，我隐约觉得要起势。干这行久了，手感会很灵，也就是大家说的网感。

[PRE7]

那一版推的书是《中考作文素材密押》，同样发在星球里。

[PRE8][PRE9]

操作很轻：一个七秒钟的镜头，小孩在翻书，画面上叠文案，走场景种草。宝妈类账号常用这招，干脆利落。链接挂的是孩子正在看的那本，这一轮成交三百多单。

[PRE10]

插一句实操心得：片子发完，人得守着留言区。一方面把搅节奏的评论处理掉；另一方面，留言区就是一份现成的用户调研，产品哪里让人犹豫、内容哪里没讲透，都能看出来，下一条就能补。

结果这一版踩了坑。家长群起质疑，留言区被带偏，下单明显受挫。现在复盘时，不少评论已被我处理掉。印象最深的是这种声音：

[PRE11]

小孩平时不碰手机，淄博这波他怎么可能知道？

播放量不算低，偏偏下单被压住，合作方也坐不住了，直接私信来问：

[PRE12][PRE13]

我处理了两百多条评论，干脆借力打力，把一条回应顶到最上面。

[PRE14]

没多久，下单曲线就抬头了。第二条内容换成真人对着镜头讲。上次的教训记下了，我把“学生平时碰不到手机”这层担心写进了开头。

[PRE15]

然后自然拐到产品，让书来回答这个疑问：

[PRE16]

没想到第二波质疑更凶。家长反复提：卷子早定稿了，淄博这题进不去。我一开始也觉得在理，毕竟它全网出圈是在五一小长假。那批留言我处理得差不多了，回头找时，还能看到不少类似说法。

[PRE17]

总不能一直被风向推着走。我搜了下资料，淄博那波热度，三月份就烧起来了。

[PRE18]

[PRE19]

这招把疑虑压了下去，还有家长主动替我解释：准确说，三月三号那个周五，大学生下课后就成群坐高铁去淄博吃烧烤了。风向总算扭转。

网上有种判断：今年中考语文卷，也许会把“淄博烧烤”摆进作文材料。概率不低。试卷四月末已定稿，而淄博三月份就有热度，不少地区的二模也碰到过。（这里是在消除家长“押不中”的担心，拉高成交）

[PRE25][PRE26]

如果真遇上，孩子怎么落笔？建议先收藏。

四个切入方向：
一、诚信者得天下；
二、人间烟火气；
三、借范仲淹《岳阳楼记》谈“政通人和”；
四、用《桃花源记》设题。

[PRE27][PRE28]

学生在校很少摸手机，对淄博这波未必有感觉。热点也不只它一个。意林那本中考热点作文素材，还把梦想、成长、真情这些常考方向收进去了。这个品牌十二年里多次和真题方向撞上，现成素材和示范文章都替孩子理好了。考前翻一翻、背一背，进考场就能套。

所以临考那几天，这两本书里哪怕只多记一句话，也可能帮上忙。（这句能把下单动作推到临考那一周，成交会更好）

之后再看留言反馈，继续迭代第四稿、第五稿、第六稿……

说到底，写文案不能只图自己痛快，也不能想当然。得盯住买家卡在哪里、担心什么，把疑问拆掉，把顾虑接住，货才走得动。
