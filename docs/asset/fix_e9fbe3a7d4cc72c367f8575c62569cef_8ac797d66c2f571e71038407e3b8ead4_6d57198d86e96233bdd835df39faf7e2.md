# 抖音获客从主页到搜索：一套可落地执行清单

先拆两个样本，后面的方法会更好理解。

样本一：一位体重150斤的加大码女装店主，经营着一家做了13年的女装工厂店。她日常更新显瘦、有质感的搭配方案，粉丝进群可领100套微胖女孩穿搭参考；关注她，视觉上瘦20斤是给出的结果承诺。

## 案例2：二手车行业

人称车界老王的从业者，在二手车赛道干了20年，累计卖出二手豪车两万多台。私信他，可领取一份《选车避坑指南》，帮买家少花钱开上靠谱好车。

主页面简介要放入行业大词，结构可拆成四块：背书、案例、福利、行动指令。

企业官方类可参考：

金夫人——为中国人记录婚纱照。线下网点400余家，累计获得600多万对新人认可；定位高品质情感婚纱摄影；当前热拍风格有三生三世、前世今生、目的地婚礼。

人设IP类A：

一位入行8年的室内设计师，设计、量房、报价三项免费，服务范围覆盖全国150多个城市；私信可领取设计名额。

人设IP类B：

浩哥，做海南高端定制游7年，亲自接待过8000多位顾客。兄弟局、情侣蜜月、闺蜜轰趴、家庭度假、公司团建均可承接；贵宾楼豪车接送、专属管家独栋别墅、游艇派对、海陆空深度体验都能安排。对话框一打开，服务即刻启动。

置顶视频放1—2条即可。品牌号可秀肌肉，讲品牌或创始人的成长故事；机构背书可放市场规模、官方认证、供应链优势等，再配优秀案例，持续强化品牌心智。人设IP号适合走“平凡英雄”路线，用创始人或主理人的经历引发共鸣：出身普通、创业艰难、最终拿到结果、做到一定规模。

# 客服配置：欢迎语引开口，自动回复接问题

私信欢迎语可套模板：感谢语+背书话术+业务介绍+福利或优惠引导+客服在线时间+转化入口。

示例写法不必逐字照搬，可包含这些信息：欢迎咨询天鹅到家、全国领先家庭服务平台、与公安机关联网的家政公司、选大平台才有保障、提供保姆/月嫂/育儿嫂上户服务、客服小鹅8:00—20:00一对一答疑，以及门店周年庆预约咨询领优惠。

另一个示例：竞争力写IP经验+案例背书，行为好处写免费3套设计方案。

自动回复有两条路径：路径1，运营工作台-咨询管理-自动化设置-关键词匹配；路径2，运营工作台-客服中心-智能客服-自定义知识。核心价值是根据用户高频咨询词设置自动回复，提高服务效率（3分钟回复率要大于50%，否则私信限流），也提高线索转化率。

形式一：欢迎语+问题引导。底层逻辑是构建私信问答闭环，同时完成流量筛选。操作路径：运营工作台-自动化设置-自动回复（进入对话/关键词匹配）。欢迎语预设附加问题，关键词匹配预设问题并设置针对性回复。

[PRE5]

形式二：欢迎语+表单预约。底层逻辑是引导用户自主预约，节省客服沟通成本。操作路径：运营工作台-自动化设置-自动回复（进入对话）。欢迎语附加“高级预约组件”或“一键留资”；高级预约组件需提前创建，过审之后可选。形式二适合刚需性行业（如法律、家政等），这类用户往往更习惯私信沟通留资。

# 4.3 筛选高转化关键词

# 4.3.1 明确业务核心词

从自身业务出发，确定核心业务词和行业词。比如产品是床垫，业务词可选“买床垫”“床垫如何挑选”等，行业词归到“家居软装”“床上用品”等。注意排除与成交无关的词，比如“床垫回收”“床垫除螨”就不算业务词。

# 4.3.2 找主流量关键词

手动查找可去AIDSO网站的关键词板块。网址：https://www.aidso.com/

[PRE8]

筛选时重点看四个数据：月覆盖人次、7日搜索人次、下拉词数量、竞争度。月覆盖人次反映近30天挂该词的内容触达人数，覆盖大意味着流量池大，却未必容易占排名。7日搜索人次指最近一周在抖音搜该词的人数，数值越高越值得抢位。下拉词数量指该词衍生词有多少，衍生词越多，排名难度越高，因为用户可能分流到下拉结果。竞争度是整体难度。

# 4.4.1 制作DSO短视频

做DSO短视频时，文案、画面、字幕、背景区、视频封面、视频前3秒都要尽量覆盖关键词。

# 4.4.1.1 先定视频形式

写脚本和制作前先确认自己做哪种类型。依据关键词含义去搜这个关键词的受众人群会想看什么，也可以根据关键词前十个作品判断形式。

示例：选择关键词“考研怎么选学校以及专业”

[PRE14]

点击关键词在抖音搜索，能看到作品情况。

步骤1：分析靠前作品的形式。这个词靠前有四种形式，靠前都是口播。  
步骤2：考虑口播形式自己能不能做。如果能做，就去看靠前内容大概是什么样，再写脚本（不能原样抄袭）。如果做不了口播，就考虑剩下三种里自己能做哪一种。

优先级是：关键词下最多的视频形式；再依据关键词内容定位确定视频形式。

剧情类（Vlog）：用有起承转合的故事吸引观众，题材可包含搞笑、悬疑、情感、励志等。比如关键词“0成本创业适合做什么？”，讲职场成长故事，并把业务侧能带给用户的帮助放进去，让观众产生情感共鸣。

口播类：主要靠语言表达传递信息，如新闻资讯播报、观点评论、故事讲述等。比如时事评论员对近期热点事件发表看法。口播类适用各行业，操作难度也低。

技能教学：教实用技能，像烹饪技巧、健身方法、化妆教程、摄影教学、乐器演奏教学等。比如关键词“健身教练证怎么考”，可详细展示考证步骤，并带出自己的相关业务，让观众跟着学并来找你咨询。

知识分享：把自己擅长领域的知识讲得通俗易懂，如历史知识、科学原理、财经知识、法律常识等。比如关键词“怎么学会投资？”，用生动案例讲经济学供求关系原理，分享实用小常识，帮观众增长知识，进而信任你、对你的业务感兴趣。

混剪类（录屏、素材混剪）：把多个视频片段剪辑组合，配上合适音乐和解说，形成有主题的新视频。比如关键词“北京旅游团”，把旅游时拍摄的各地风景片段混剪在一起，加上业务宣传，用户感兴趣就会来咨询。

图文内容要根据关键词搜索含义来分析，也可以去其他网站找内容参考。

# 4.5 发布视频/图文

# 4.5.1 发布时间

分析行业人群，观察行业人群的上线时间，在行业人群活跃前1—2个小时发布作品。比如受众是大学生，上线时间大致在9:00—23:00，因为大学生不会太早起，闲暇时间也多，这期间可以多发；如果受众是白领，就要推算他们的休息时间，因为这类人群多在休息时刷抖音。如果实在不清楚，前期新号可以多测试，看数据趋势、总结特点，看哪个时间段发布互动数据更好，多测几次就能摸出规律（新号建议一天发5—7条，早6点到晚22点每隔2小时发布）。

# 4.5.2 发布文案怎么写

手机端直接点击发布编辑，电脑端进入抖音创作者中心后台发布。

标题要包含完整关键词，可加前缀和后缀，整个标题要符合关键词含义。文案包含1—2次关键词，整体符合关键词含义，不要无意义地重复堆积。话题第一个必须是关键词，剩余4个可添加行业相关关键词（关键词库）。就算关键词话题应用为0，也要使用。
