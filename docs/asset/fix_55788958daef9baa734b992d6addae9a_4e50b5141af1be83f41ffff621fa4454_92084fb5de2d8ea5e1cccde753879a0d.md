# 开场白

先回答两个问题。

导图值不值得学？

它更像一种把思考外显的图形工具：中心主题向外分叉，相关节点逐层铺开，看起来像脑内神经联结的放射网。除了读书笔记，它还能用在很多地方。

工作上，导图能帮你把面试自我介绍、工作规划、活动方案、复盘、会议头脑风暴和创意讨论理出条理。

副业与自媒体上，它也能变成收入来源：整理知识资料包做引流，开导图课程，替人定制导图接单，或者结合专业做个人品牌。

生活里，育儿准备清单、生活梳理与复盘、自我成长、困惑整理、情绪调节，都能用导图完成。

学习时，带孩子读绘本、学英语数学古诗、搭建个人知识体系库，也都适合。

圈里有人因为使用和分享导图，拿到工作机会、发展副业，甚至找到新的事业方向。

这次航行能拿到什么？

先说明：导图是一项技能，不是一上手就变现的项目。所以本次的首要目标，是让大家真正掌握它。

### 1.1 为什么学习思维导图？

#### 1.1.1 什么是思维导图？@罗卜

MindMap（脑图）由东尼·博赞（Tony Buzan）在 20 世纪 60 年代提出，常被视作高效的思考辅助工具。

它的形态是：中心主题向外分叉，子题逐层展开，像脑内神经联结般呈放射网；这种图形化方式能把思考过程摆出来，便于组织观点和表达想法。

[PRE7]

图注：左右脑主要智力功能，来源《思维导图》，东尼·博赞

[PRE8]

图注：神经元突触与神经通路构成的网络，来源《思维导图完整手册》，东尼·博赞

这种放射结构既能呈现事物间的逻辑关系，也能激发联想，让思考和记忆更有效率。

它把图形、符号、文字组合在一起，让思维过程和结果可视化；逻辑输入与创意输入并置，口语和文字之间的沟通障碍被跨过去，理解与记忆也更轻松。
