# 为什么买房让人安心，炒股却让人心慌？

不少人觉得购置房产稳妥得很，说到底是因为楼市缺少一套像证券交易场所那样的机制——随时报出价格、眨眼间完成成交。没有这套东西，房价涨也好跌也罢，多数人压根感知不到；再退一步讲，就算隐约有感觉，也没法立马变现，于是干脆丢在一边不去管它。

可你换个角度想想：倘若真有这么个系统，天天把报价推到你眼前，账户数字实时跟着跳动，那种心理上的冲击得有多大？不管你参不参与投资，财经资讯、市场解读、专家观点乃至流言蜚语每天都会涌过来，行情也日日对这些信息作出反馈。眼瞅着账户里的数字忽上忽下，能顶住追涨杀跌这种本能冲动的人，实在没几个。

再设想另一种情形：十多年前你在一线城市置办了一套住宅，单价一万元，到2020年已经翻了十倍，达到十万元每平米。但在这漫长岁月里，假如国家真弄了个房产交易场所，你随时能一键卖出或买回，那么当价格爬到三万时，或者从七万滑到五万时，又或者在五六万区间横盘三年纹丝不动时，有多少人能咬牙攥着、一直守到十万？恐怕屈指可数。

可这套机制压根不存在。于是绝大多数人既搞不清自家房子到底是赚了还是亏了，就算搞清了也没法马上动手，索性就随它去吧。有知有行的同事有个挺逗的比喻：过去二十年，相当一部分中国家庭其实是“稀里糊涂发了财”。

## 波动和风险是一回事吗？

沿着这个思路，我们再回过头看“股市风险极高”这个判断，也许能看得更明白些。

首先能确定一点：波动并不等于风险。

你多半知道，传统金融学教科书习惯拿“波动率”来定义风险。它是个统计口径，算的是某段时间里资产价格跟其均值偏离得厉害不厉害。但显然，光靠波动幅度来判断某样东西“风险大不大”，太过片面。瞧瞧过去十几年那些明星股——苹果、微软也好，茅台、格力也罢——哪一个没经历过大起大落？单用“风险大”来概括它们，肯定不准确。

这给了我们一个启发：对普通人来讲，投资最要紧的事，是挑一个长期趋势朝上的市场。

对于相对专业的玩家，在反复震荡、上上下下的市场里挣钱是有戏的；但对大多数人而言，只要你的投资标的长期向上，哪怕中途有些颠簸，最终拿到正回报的概率也要大得多。就像过去十多年一路走高的楼市，只要自己不胡乱折腾，挣钱几乎是板上钉钉的事，无非是挣多挣少罢了。

相比之下，权益类资产倒有可能在未来一个新的十年里登上舞台。

第二，随着房地产高增速时代渐行渐远、固定收益类产品越来越稀缺，更多资金会流向股票市场；

第三，中国经济在全球依然领先，未来前景依然广阔，海外资金也会逐步提高对中国资产的配置比例。

第二个启示：尽量长期持有，少动手。

同样是长期向上的资产，房产因为流动性差，让很多人被动地长期持有，结果赚到了钱；而股市可以随时交易，大多数人反而亏了。

行为金融学里有个概念叫“短视损失厌恶”，由著名学者理查德·赛勒和施洛莫·贝纳茨提出。他们在1995年发表的论文里描述了一个有趣的现象：投资者查看自己投资账户的频率越高，回报通常越低。原因在于大多数人受不了短期价格波动的刺激，总想躲开暂时的浮亏，或者赚一点就急着“落袋为安”。这样反复折腾，不但多交了不少手续费，还损失了更多长期收益。

在这方面，有知有行会给你最大的支持。无论是市场跌入谷底、反复震荡，还是亢奋狂热，我们都会冷静地帮你分析当前局势、理解市场情绪，并给出最适合你的行动建议。

当我们对风险有了正确的认知、建立起事前和事后的应对方法，并且有纪律地坚持下去，不仅能获得财务回报，更能收获内心的平静。

#### 3.3.3 持有股票多久可以稳赚不赔？

通过与房产的对比，我们明白了投资股票也应该长期持有。那到底多久才算“长期”？持有多长时间股票才能稳赚不赔？

我们还是用数据来回答。之前多次出场的杰米·西格尔教授对这个问题也做过统计。在《股市长线法宝》一书中，他计算了1802年到2012年这二百多年间，在任意时点持有股票和债券的收益情况。

更有意思的是，当时间拉长到十年以上，持有股票的最差收益率已经开始高于持有债券和国债了。到了二十年以上，你能拿到的最差收益也是正的。换句话说，在这个时间尺度上，只要拿着不动，你根本没有亏钱的可能。

## “长期”到底意味着什么

再来看看A股的情况。虽然A股没有美股那么长的历史数据，但我们仍然可以做类似的研究。我们选取万得全A指数，从2005年1月1日到2020年10月19日近十五年的数据进行研究，结果是：在任意时点持有8.75年以上，都能获得正收益。如果把获得正收益的概率从100%放宽到80%，最短持有周期会降到4.83年——这个数据比美股还要好。

所以这组数据应该算部分回答了刚才的问题。当然，我们并不是说投资十年才叫长期，投资一两年、三四年就不算——关键不在于抠字面上的定义，而在于掌握更多正确的信息。

不过道理大家都懂：只要标的别选得太差，投资时间越长，赚钱概率越高。那为什么长期投资还这么难坚持呢？这里我们先不提那些认知不足、贪心、自身情况不允许等主观原因，先看看客观上“长期持有”为什么这么难。

## “轮动”对投资的影响

长期投资之难，还体现在另一个重要方面：市场总是在“轮动”。

这里说的“轮动”，通俗讲就是“三十年河东，三十年河西”，或者“风水轮流转”。它可能指资产表现的轮动、投资风格的轮动，也可能是行业板块的轮动等等。我们之前的课程说过，万物皆有周期，“轮动”就是周期的另一种体现。

举个例子。回看历史会发现，美股市场在1970年代和1980年代的表现简直天差地别。1970年代，美国经历了一系列危机——越战升级、布雷顿森林体系瓦解、中东石油危机等等。从1969年末到1979年末整整十年，道琼斯工业指数和标普500指数起起伏伏，十年下来几乎没怎么涨，算上通胀甚至是亏损的。

不过无论怎么定义，有一件事是确定的：不论中国还是美国，这个时间段的市场风格都是把头部公司的价格越推越高，而非头部公司哪怕非常便宜也无人问津。之前我们在课程里也提到过“漂亮50”现象，没多久市场风格转换，不再那么热捧那些大公司了——这就是风格的一种轮动。

另外大家最熟悉的，就是行业轮动了。比如2020年白酒、消费、医药是最热门的题材，但仅仅几年前，大家还在追捧银行地产，或者5G半导体。所以市场对行业的偏好也在轮动。

说了这么多轮动，它对我们长期投资的影响是什么？我觉得有两个非常大的影响：

第一，如果当前市场最受追捧的主题和你喜欢或擅长的领域不一致，那么再坚定的人也会对自己的持仓产生怀疑。比如你可能对汽车、地产很熟悉，但看不懂各种热门科技公司在做什么，就会想：市场还会轮动到我这边吗？我是不是该放弃现在的持仓，切换到别的地方？这种过程中的未知感和不确定感，非常难熬；

第二，更关键的是，哪怕你的投资表现不错，但市场上总会有表现更好、更热门的东西。比如你可能在一两年里跟随大盘涨了40%到50%，已经是很不错的收益了，但别人可能投了蔚来、拼多多、特斯拉、比特币，一两年翻了五倍十倍……看到别人赚得比自己多总是更难受的，这也会对我们的长期投资造成影响。

## 小结

最后，我想从另一个角度重新回答一下这个问题。

当我们问股市长期投资需要多长时间时，背后真正的问题可能是：我们都不希望老了才变富。

我们通过投资获得的收益，和三个因素有关：本金、时间和收益率。

收益 = 本金 ×（1 + 收益率）^ 时间

前面的课程里，我们讲过股市长期的预期收益率，今天我们推演了长期投资需要的时间。这些因素都是客观的，不会因为我们希望快速变富而改变。我们唯一能控制的，是投资的本金。

因此，对我们来说，可能更重要的事情是：放下焦虑，专注在工作和生活上，在自己不断变得更好的同时，去收获更多的工资、股权等其他收入。与此同时，做好资产配置，根据自己的兴趣慢慢拓展能力圈，在合理范围内提高我们能获得的收益率。

### 3.3 怎样为自己制定一份长期资产配置方案？

#### 3.3.1 股债平衡

通过前面的内容，我们已经了解到股权类资产是长期收益最高的品种，并且对股权投资市场和市场的周期、波动、风险有了正确的认识。接下来我们来看，在这样的市场中，具体如何做好长期投资。

长期来看，股票是收益最高的资产，因此我们应该围绕“长期持有股票”来打造自己的长钱体系。但通过前面的学习，我们知道股市波动很大，很容易影响心态。所以，长期投资的第一步应该是做好股债配置。

什么是债券？

债券是政府、企业、银行等债务人为了筹集资金，按照法定程序发行并向债券持有人承诺于指定日期还本付息的有价证券。

债券品种很多。比如固定利率债券的发行人承诺每年向持有人支付一定固定数额的利息；浮动利率债券则以当期市场利率为基础支付利息，利息是浮动的。

虽然债券品种多样，但实质上它是一种债权凭证，持有人与发行人之间是债权债务关系。发行人是债务人，持有人是债权人。

不论是机构投资者直接参与债券交易，还是个人投资者通过理财产品间接投资债券，都需要了解投资债券一般能获得多少收益、要承担多少风险。

债券收益主要来源于三部分：利息收入、资本利得和再投资收益。

利息收入是债券发行时就决定的，票面利率越高，债券收益越大。例如风格稳健的投资者配置债券主要是为了获得安全稳定的现金流，就会选择购买并持有到期策略，不考虑存续期内债券价格如何波动。

资本利得是指债券买入价与卖出价或买入价与到期偿还额之间的差额。债券价格随市场变化而周期性波动，投资者可以通过低买高卖获得价差收益。当然，如果预测不准确，则可能承受亏损。

再投资收益是投资债券期间获得的利息收入通过再次投资获得的收益。

为什么债券跟股票相比风险较低呢？

我们经常管股票投资叫“炒股”，但从来没听说过“炒债”的说法。原因有很多，我觉得主要原因是股票和债券的本质不一样。

股票作为公司的所有权，收益主要来源于公司盈利增长，是面向未来的，是对未来的定价，而未来带有相当程度的不确定性，这就导致股票价格波动很大。而债券作为债权凭证，是对过去借钱行为的补偿。首先，债券的票面利率和期限都是约定好的；其次，债券存续期内价格涨跌主要受利率影响，而利率作为资金成本一般都受到调控，不会大涨大跌；另外，不论存续期内债券价格如何变化，最终都要回归面值，也就是说最终会按面值归还本金。

所以，债券跟股票相比风险较低，可以当作避险资产。当然，这是大多数情况下——如果某只债券违约，可能造成本金亏损，此时债券的风险甚至可能比股票还高。

历史上看，投资债券能获得多少收益、承担多少风险呢？

在美国，短期国债和长期国债的年化收益率分别约为2.7%和3.6%。在我国，以主要投资债券的纯债基金为例，从2005年到2022年底，中长期纯债基金指数的年化收益率为4.89%，年化波动率为2.01%。但随着国内无风险利率下移，债券基金的收益预期也有所降低——2017年到2022年底，纯债基金指数的年化收益为3.68%。过往的历史收益并不代表未来的预期回报。投资者要建立合理的预期：中长期来看，投资债券具有保值增值的作用，风险不高，但短期持有仍可能面临亏损。

为什么要配置债券？理想的股债比例是多少？

先来看看价值投资鼻祖本杰明·格雷厄姆在80年前对长期投资的建议。在《聪明的投资者》中，格雷厄姆提出，不论是进攻型投资者（风险偏好较高）还是防御型投资者，都需要同时配置一定比例的股票和债券，并且债券比例不能低于25%。

同时持有股票和债券有两个原因。首先，大多数情况下股票和债券不是同涨同跌的，因此同时配置这两种资产能有效降低组合波动。更重要的是，持有一定比例的债券，能帮助我们在类似2018年大熊市时心里有底，感觉自己还有弹药，不至于把手中的股票卖光。
