# 技巧一：观赏型文案，只负责请你看图

写这类文字时，最忌讳往里塞观点。你发图的目的很纯粹：把好看的内容递到读者眼前。

所以文案只需传递一个信号：这张图、这段视频真不错，我拿来和你分享。

那碰到漂亮照片、风景照、人物视频，配文该怎么落笔？先别急着抒情，记住一条：别抢画面的戏。

可以参考这样的思路：

“这张图太美了，分享给你。”

“刚拍的 XXX 景色，还热乎，发出来一起看。”

除此之外不必加料：不灌鸡汤，不扯题外话，也不输出大道理。

发观赏类内容，本来就是邀请大家看、请大家欣赏；我觉得好看，所以转手分享给你。

你掌握了吗？
