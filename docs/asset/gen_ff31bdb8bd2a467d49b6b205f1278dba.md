# 8.4 原创度低被限发？两步申诉解封 @狼魂小毛

一开始二次创作打磨得不够，几个账号陆续被平台判定“原创度低”，发布权限也因此受到限制：

[PRE0]

[PRE1]

遇到这种情况怎么处理？可以分两步走。

第一步，先开具短剧作品的授权证明，再上传到平台发起申诉；电子版材料即可。

[PRE2]

申诉说明可以这样写：已经与该影视剧的拍摄公司谈成推广合作，对方也同意授权推广。

如果这一步不清楚具体怎么弄，可以直接到航海大群求助。

第二步，把作品原创能力补起来，持续优化创作方法，避免在同一个问题上反复出错。
