# 三年闲鱼老卖家，聊聊我亲眼见过的那些赚钱模式

我是杨小六，在闲鱼上摸爬滚打了三年。今天不吹不黑，把我这些年看到的闲鱼赚钱路子一次性讲清楚。

先说说我为什么最后选了闲鱼。2018年其实就入了坑，但那时候刚毕业，心气高，总想去外面的世界闯一闯，于是跑去杭州做了天猫运营。到了2019年初，回到老家想搞电商创业。可那会儿在杭州见的都是Top级店铺，直通车月花费上百万，自己兜里没几个钱，十几万砸进去怕是连水花都看不见，果断放弃。在家找项目的时候也试过抖音书单，就是一张图配音乐那种，涨了大概两千粉丝。可想了想，自己待的是小镇，愿意回来的年轻人本来就少，而抖音更吃人才和团队，我既不懂也不会招人放大，于是转头重新捡起了跟电商沾边的闲鱼。

总结下来就三条：

第一，闲鱼门槛极低，不需要大投入，连保证金都不用交（不过目前部分类目需要200块保证金，仅限鱼小铺）。
第二，闲鱼特别适合当副业。杭州消费高，我又不是什么省吃俭用的主儿，所以一直把它当作补充收入的兼职，一个月多个两千块，够付房租了。
第三，闲鱼本质是人力密集型工作，不太建议在工资加社保超过5000块的城市做。如果实在想做，最好走合伙人模式，这个我之前的文章提过，也可以评论区聊。

下面进入正题。这三年来，我见过的闲鱼运营模式大致分三类：兼职副业卖货、团队化卖货、闲鱼引流。另外还有一块是闲鱼培训，因为水太深，我也没完全摸清，这次先不聊。

## 第一类：兼职副业运营

这类最常见，也是闲鱼商家的主力军——宝妈、大学生、有正经工作的年轻人。2018年初的时候，闲鱼上还没多少大规模卖家，平台管得也松，甚至可以直接在宝贝描述里留🛰️号。到了2019年下半年，培训机构开始收割了，一大波想找副业的人报名交钱，其中有些个人IP还顺手把学员套进淘客返利的模式里，又拉了一波下线。

这批人来得快去得也快。很多人试了一两周，发现一天只能赚个几十块，又麻烦又耗时间，觉得还不如躺平刷抖音快手，于是果断撤退。

只有那些一开始就赚到钱的人可能留下来。但接下来还有一道坎：闲鱼卖货是有周期性的。个人账户少的时候，可能连续三个月收入不错，但不管后面俩月怎么折腾，就是不进单。这一波又淘汰了不少还在坚持的人。

那真正留下来的人有什么特质？就俩字：知足。

比如每天多点30块，一个月多1000块，上班之余还能有这笔额外收入，孩子的奶粉钱有了，自己的烟钱也有了，心里挺乐呵。这种人往往能坚持很久。

相比之下，宝妈比上班族坚持得更久。因为宝妈在家基本没什么收入来源，每天多赚30块都会让她更用心地上品、回消息，然后赚得更多，越干越起劲。而上班族有工资打底，月薪五千起步，上不封顶，前期赚得少的时候，很容易就看不上这点钱，转身走人。

所有事都是从0到100的。我最早从一天赚30块到100块，也花了差不多一个月。三年才算真正入行。所以，选定一个项目，不如先干满三个月再说行不行。

## 第二类：团队化运营

一旦走到团队化，货源基本都能搞定，剩下的主要就是跟无货源死磕。

团队架构大概分三档：
简单版：客服 + 运营
中级版：客服 + 运营 + 财务兼进货 + 售后
高级版：客服 + 运营 + 财务 + 进货 + 售后 + 主管

起步阶段基本都是自己一个人全职干，运营是你，客服是你，进货是你，售后也是你，全能选手。

后来你租了个场地，招了第一个员工。你怕她学会了自己单干，所以你干运营，她干客服。这样一来，你时间多了一些，于是又开了几个新账户。你继续管运营，她管客服。遇到售后问题她来问你，因为都是自己的账单，进货也从没记过账，赚多少心里大概有个数。

从最开始一个人干赚8000，到招了一个人后，扣除房租水电，到手勉强一万出头。

你开始不满足了：要不再招几个人，我就能当甩手掌柜了？于是又招了两个客服。结果你自己忙不过来——选品选得头疼，根本没时间处理售后和进货。客服也开始抱怨：顾客老是催发货，骂人也不处理售后。正好亲戚家的孩子找工作，你一想，自己人总不会偷钱吧？于是把售后和进货交给了她，你终于能专心选品了。货量越来越大，厂家也愿意给你降价了。这个月除掉员工工资，到手两万多。

又维持了几个月，团队稳步扩到8个人。你感觉天花板到了，稳定产出3到5万。你心里琢磨：我不想做运营了，能不能换个更赚钱的项目？或者把闲鱼规模再翻几倍？于是你把最优秀的员工提拔成主管，开始教他运营。小伙子聪明，不到一个月就学会了。你的时间空出来了，开始看看龙哥盟，学管理。

学完就实践。团队开始招人，你把亲戚负责的进货和售后拆开，售后专门找了一个人处理。进货的亲戚也开始满平台比价，想着给公司多省点成本。

现在又能多开账户了，企业支付宝也能跳对公了。你趁着机会回老家，七大姑八大姨的支付宝都借了一遍，搞来100个号，按之前的模式直接扩大三倍。人数多了起来，模式变成：

a小组：3个客服 + 1个运营  
b小组：3个客服 + 1个运营  
ab小组共用1个进货、1个售后  
c小组：3个客服 + 1个运营  
d小组：3个客服 + 1个运营  
cd小组共用1个进货、1个售后  
abcd小组共用一个财务，负责账单汇总对账；共用一个主管，负责请假、员工管理、招聘。

就这样，闲鱼团队搭建完成。你每天处理下运营的事，找主管、财务聊聊天，听听汇报，月入接近10万，一脚踏进年入百万的圈子。赚到第一桶金，你可能就离开了那个起步的小县城，去追更大的梦。

团队运营一般分两种：一种费运营，一种费客服。

无货源模式属于费运营型：运营每天要选品、写文案、找图片、发布宝贝，活儿很重，但卖的基本是标品，价格不高、功能透明，客服压力就小。

有货源模式属于费客服型：产品就那么几款，运营只需要找找图片、发布产品就行，客服反而累。比如我们现在做的出行工具，客单价高，运营的活很简单，客服每天要回500多个咨询、上千条消息。

两种模式本质就是看客服和运营的人数配比：运营累就多运营少客服，客服累就多客服少运营，合理分配。

## 第三类：引流卖货

常见的引流类目是莆田系、fk表，但今天不说这些。拿卖宠物举例吧——有个人在我这拿群控，大概400个号稳定在跑，他告诉我月入12万。主要卖狗，少量卖猫，客单价800到3000，都是泰迪、博美这类适合平民玩家的品种，目标客户在大城市。

闲鱼引流有个问题：封号。一个月大概牺牲10%到20%的号。

引流的号怎么来？先找自己人开一批，上架产品、发帖子，自然会有顾客来咨询。因为挂的价格偏低，咨询量很大，但并不是每个来问的人都会买。于是关键来了：不买的那批顾客，租他们的闲鱼账户。注意，只租闲鱼，不产生任何交易，不需要支付宝，不需要密码，只要能发布宝贝就行，一个月给30到70元。这个价格我听到时还挺惊讶——太便宜了，完全没想到。但确实很多人愿意租，可能觉得自己留着也没什么用。

号收来之后直接上群控，一个人就能盯近100个账户。

后面就是活体宠物运输。分两种：离得近的，基本能上门自提，猫舍狗舍留够自己那份，收完钱分给他。第二种是运输，走空运或陆运，大型猫舍狗舍基本都能发货。先收顾客定金，然后视频看狗，收尾款，打包发货。

还有一种无良卖家，顾客视频里看到的狗和实际发货的不是同一只，但长相差不多。视频里看着很精神，发过去的可能就蔫了，毛色也有差异，价格差确实存在，但顾客基本不会深究。真被问起来，就用“路途太远，狗晕车没精神”来推脱。

拿宠物举例，只要你手里的流量渠道稳定，剩下的就是不停找猫舍、狗舍。渠道可以来自58、抖音、百度地图，只要你电话打过去，很多都愿意合作。还有全国各地的猫舍狗舍交流群，里面交易量大得很。

顺便提一句莆田系和fk表。闲鱼对这类封号已经非常狠了。透个fk表的玩法：标价标实价，就是真表的价格，卖的时候说“真表没货了，还有一个fk的，价格xx元，要就拍，不要拉倒”。这样封号几率小一些。但说实话，光明正大赚钱的生意那么多，强烈不建议碰这个。
