# 盖洛普入门：找到你的本能优势

小刀姐在生财全国见面大会上聊到盖洛普之后，不少朋友第一次听见这个名字。为了让大家快速弄明白它是什么、能解决什么，我整理了这篇说明。

一、这套测评到底在量什么？

先看几组日常反应：任务越堆越来劲，像闯关升级一样停不下来，这对应“成就”；一看到课程就想报名，沉迷吸收新东西，这是“学习”；遇到分歧先找共同点，不愿把关系弄僵，这是“和谐”；脑洞大、思路跳，常给出别人没想到的角度，这是“理念”；出手前先排查隐患，准备充分才行动，这是“审慎”；爱追问事情的本质和底层规律，这是“思维”；进陌生场合不怵，甚至越聊越兴奋，能自然找到话题，这是“取悦”；熟人圈里才放松，不爱人多的饭局，这是“交往”；对结论不盲信，习惯用数据说话，这是“分析”。

盖洛普这套评估由美国盖洛普咨询公司推出，量的是一个人本能的心智模式——怎么想、怎么做，相当于一份个人使用说明书。约2900万名用户已经做过，生财有术团队也测过，并认可它的科学性和精准度。

它不只是一份题，更像一套描述行为规律的语言：人在什么情境下会自然做出什么反应，这些反应又对应哪些天性优势。盖洛普优势体系里共有34种行为规律，也就是34种天赋优势，通常称为“才干”。才干是一个人自然而然的行为模式、思维模式，不需要刻意提醒，也不必咬牙硬撑，它更像下意识习惯和内在需求。若你有意识地训练这些本能模式，往往能事半功倍，也更容易获得正反馈。

每个人的34项才干组合与排序都不同，所以测试能体现个体的唯一性。就像钢琴只有88个琴键，琴键有限，却能奏出无穷旋律。

二、做完并请人解读，能带来什么改变？

它能让你看清自己的行为规律：从习以为常的思维和行为里，发现未曾留意的优势，也看到可能限制自己的思维盲点。对教练而言，报告像一份“操作系统说明书”，能更快定位对方的问题，再结合其在意的点做引导，而不是套用通用的大道理。

生活里常有这种情况：遇到问题找朋友聊，建议听起来都对，却很难执行。原因在于每个人的底层操作系统不同，在意什么、哪里痛，都不一样。有人把flag公开、让人监督，执行力更强；有人被围观反而压力大，更愿意先拿结果再对外说。有人不太在意别人怎么看自己，有人却对他人评价很敏感。对后者说“别把自己太当回事、别管别人怎么看”，常常无效，甚至会让他更痛苦，因为会自责“为什么我做不到不在意”。对这类人，我的建议是把别人的看法变成动力，去赢得更多认同；当认同感远大于负面评价时，负面评价的干扰就会变小。

下面结合我服务过的案例说明（均已获本人同意公开）。

1、先避开不匹配的岗位与做事方式，少交试错学费

先说一位偏爱创造性工作的应届生，跟风进银行半年后离开。这个校招进银行的大学生觉得工作压抑，测完盖洛普发现“理念”排第一。理念型的人思维天马行空、脑洞多，不喜欢按部就班，这和银行的工作方式天然冲突，自然干得不快乐。后来他辞职去做文案策划，感觉更开心。他感叹，若大学阶段就接触盖洛普，当初不会随大流进银行。

再说一位社恐型人格做渠道关系维护，做得很难受。这位商务的“取悦”排倒数第二（取悦不是讨好，而是陌生人社交能力）。他每天要对接渠道商、打电话、攒局、逢年过节维护关系，这类工作并不适合他。他更适合不需要维系大量关系的幕后执行操盘类工作，比如广告策划、产品经理等。有人可能会说：我也社恐，但锻炼后也能应对社交场合。对此回应两点：第一，每个人社恐程度不同，克服起来的痛苦程度也不同；第二，靠后天练习成功应对，和天生喜欢跟人打交道，在工作效率和能量上有本质差异。后者做这类事是在充电，不会觉得累；靠克服本能去对接很多人则是在放电，做完需要休息。让一个人硬补最短的短板，精神很励志，却不利于职场竞争力积累。市场竞争力是用更小成本做出更好结果；死磕短板，等于跑到别人的优势领域被吊打。

2、找到内耗与行动力不足的根源

小强（化名）想做抖音自媒体，投入整整一年，课学了不少、器材买了、文案写了、视频拍了、剪辑也弄了，但总觉得不够好，一直没发。他的盖洛普结果是“学习”第一、“完美”第二，于是他理解了自己为什么执行力差：大量时间花在学怎么做抖音、怎么拍好视频上，又过度追求完美，所以迟迟不发布。知道问题所在后，他不再那么追求完美，而是先完成再完美。

阿杰（化名）说自己对内容敏感度不高，想到的爆点总不能让领导满意。别人建议多看热搜、积累多了自然有感觉，他努力看了很多热搜，还是很难判断什么更受欢迎。为什么？因为他看热搜的角度和别人不同，看再多，敏感度也难提升。结合报告，他有“专注”“学习”，喜欢看个人成长类、跟自己目标相关的内容，对与工作生活无关的人和事兴趣不大；而爆点需要对大众情绪敏感。若想提升这部分，可以用他擅长的方式：他很擅长建立共性、分析底层规律，于是我建议他找规律、建数据库来提升敏感度。他觉得这个建议很好，不再怀疑自己不行或要不要换工作，而是重新相信自己能胜任眼前的工作。

3、看清亲密关系里的相处障碍

这是找我做情侣解读的一对恋人，从小青梅竹马，认识二十年，但女生Linda总不理解男友为什么经常打击她的想法。比如她想做小红书，觉得能让简历更有竞争力，男友却不为她高兴，反而用“可能遭遇网暴”来泼冷水。通过盖洛普报告发现，男友“排难”第一，她“积极”第五。她总看到积极面，男友的排难则先看到负面问题和风险。解读时我说：“你男友不是真要打击你，而是提醒你考虑这种情况、提前准备。”男友非常认同，说他了解女友对负面评价很敏感，担心她做小红书后收到不好听的评论会影响情绪，所以用网暴这种夸张方式吓唬她，让她考虑清楚。听到这番心里话，Linda很感动，也理解了男友的思维方式，不再觉得两个人不合适。这个案例让我感触很深，因为我大学时和前男友也有类似矛盾，我总觉得对方老打击我，受不了就提了分手；接触盖洛普后才知道，这是一类人的思维方式，并非真要泼冷水。同样的遗憾没有在这对情侣身上发生，我替他们高兴。两个相爱的人，别因为沟通不在一个频道、相处累就冲动分手；借助盖洛普，你能理解对方的思维方式，减少不必要的冲突和误会。

4、找到团队管理中的内耗卡点

一位团队主管犹豫要不要辞退某个不胜任员工。这名员工经常犯错，提醒几次仍不改，导致团队绩效不好、士气受影响。但她不忍心直接发起流程辞退，总想多给对方机会，也担心辞退会打击对方、让其找不到工作。她的报告中有“和谐”“审慎”，这就能理解她为什么不愿在人际关系里做恶人、会考虑较多不好的后果。定位原因后，我帮她克服“辞退员工就是做恶人”的想法：一个人早一点离开不喜欢的工作，才有机会更早去做喜欢的工作。

一位微商团长吐槽团队带不动。她的“学习”+“成就”突出，每天精力充沛，无法理解为什么有些人卷不动，误以为下属太懒。实际上，下属的精力可能不如她充沛，或者没有她那么看重工作。以前她常抽小皮鞭让大家更努力，团队痛苦，她自己也痛苦。这种情况有两条建议：一是筛选跟自己一样“卷王”类型的人；二是接纳不是所有人都像她那样渴望赚钱，理解团队成员的动力在哪里，用别的动力去激发。意识到这些后，她很少再因为带不动团队而内耗，带能带动的人，团队也发展得很好。亦仁也曾分享过他的才干对管理团队的影响，可点击：https://t.zsxq.com/0cHEoq5DE

5、弄清动力来源，学会给自己充电

一个人工作没动力，往往能从盖洛普报告中找到原因，因为缺乏动力常意味着内心某种需求没被满足。34个才干各自对应一种需求：例如“追求”需要别人崇拜和即时正反馈，才会激发最佳状态；“竞争”需要相互比较、相互激励的同伴，才会不断努力、赢过对方；“适应”需要富有变化的环境，才会持续激发灵活应变潜能，遇强则强。满足才干背后的需求，你每天就会像打了鸡血，对工作充满热情，在职场上勇往直前。比如知道自己的“交往”（熟人社交能力和深度关系维护能力）突出，就要经常和几个固定好友保持联系，常见面、深沟通，和他们在一起会放松。同时你更擅长一对一或小圈子服务，做深度一对一关系，而不是靠走量模式；相应更适合高单价产品，通过提高转介绍率获得流量。

6、找到适合自己放大影响力和获取流量的方式

如果你擅长人际关系，更适合通过社群引流；如果不擅长社交或不太喜欢和用户走得太近，更适合去各大公域平台输出内容，用内容吸引流量。不同性格优势的人，输出内容风格也不同。曾有客户跟我说她写不出深度内容，不好意思写文章；沟通后发现她对搜集提高生活品质的好物很感兴趣。对她来说不必走深度路线，走接地气路线即可。我建议她发现生活中的痛点，做能解决这类痛点的产品测评，同样是在提供价值。还有的人跟人聊天就有话聊，我建议她找朋友，每期选一个话题聊，用对话体输出，像一些两人或三人圆桌播客。

三、体验者怎么评价？

有人看完报告直呼“它怎么这么懂我”；也有人过去不清楚日常反应从何而来，现在能在报告里找到线索，知道自己的优势发挥在哪些地方，还看见不少值得留意的盲点；还有人把择偶、学业与创业的精力分配拿来参考，说以前只算投产比，现在会加上“我擅长什么、在哪更容易坚持、与谁相处更顺、怎么休息更高效、什么模式产出最好、什么样的伴侣更匹配”这些维度，自我轮廓清楚了许多，也更能选到适合自己的路。

五、谁把它做出来的？背后怎么研发？

它由美国优势心理学之父、盖洛普前董事长唐纳德·克里夫顿主导设计。团队花了至少30年，采访不同国家、行业的杰出人士，了解他们如何成为行业佼佼者。基于海量访谈大数据，盖洛普团队找到这些成功人士身上的思维方式，最终提炼出34项天赋才干主题来给这些思维方式命名。关于盖洛普测试更多详细历史，可点击：https://www.gallup.com/cliftonstrengths/zh/253745/克利夫顿优势历史.aspx

六、人具有自我欺骗性，怎么知道测出来的是自己，而不是“我认为的自己”？

人是复杂的，存在社会化自我，也会戴面具。测试无法做到100%精准，但盖洛普测试的信效度在70%（两次测试前后的一致性），已经比绝大多数测试准，具备一定参考性。另外，盖洛普研究的是你下意识的行为模式，是不经过理性思考的行为。当你理解盖洛普题目设计，可能就没这个担心了。专业付费测试会增加测谎机制，盖洛普在题目设计上也做了精心安排，避免人为主观误差。它不像很多测试让你给自己打分，或有明显政治正确的“标准答案”，比如“你认为自己是一个责任心很强的人吗？”那样的测试很容易作假。盖洛普一共177道题，题目之间相互交叉验证，每个才干主题被拆分到不同题目中，并避免让你看出在测同一个特质。比如“积极”这个才干，可以表现为生活充满欢乐，也可以是你经常赞美别人、经常看到事物好的一面、很爱笑……这些描述你比较能确认符不符合自己：越符合，特质越突出；一般符合，排在中间；越不符合，排在倒数。（当你对盖洛普体系比较了解后，就不建议反复测了，因为已经知道每道题在测什么，准确率会下降。）
