# 6.2 推广期：增长要算账

产品迈入推广阶段，往往意味着用户接受度已经过关，要么开始出现自增长，要么手里有资源可以集中放大。这个阶段真正要盯住的，是能否持续获取用户并完成变现。

核心指标也随之切换为新增、活跃、留存和收益。此时你面对的不再是一个个具体用户，而是一组组数据，因此数据统计平台必须在上推广前就接好。

推广通常分两条路：免费和付费。免费流量需要长期维护；付费投放没有神秘技巧，拼的就是“细节”——预算与节奏规划、渠道开拓与维护、质量监控、数据分析，一个都不能少。不同产品适合的付费渠道并不相同，常见的有社交媒体、Google和网盟。

新产品可以先从社交媒体试起，质量相对稳定。若不确定投哪里，不妨看看竞品在哪些渠道铺量，先复制一轮做测试，最后保留一两个ROI最优的渠道长期运营。

除了自增长特别猛的App，多数产品在这个阶段都绕不开付费投放。以我负责过的App为例，有两款工具产品始终没做付费：所处行业受Google压制，它们靠竞品关键词还能维持生存；若强行推高，反而容易成为靶子，于是选择低调活着。

另外，3V和美化类App竞争压力不小，但ROI还过得去，所以付费推广持续在做。它们的经验是：只吃对手看不上的Google长尾流量，在获客成本上做出差异化。

我在猎豹做桌面产品时，大部分流量来自免费渠道，做法是用大量主题APK覆盖海量长尾关键词。

无论免费还是付费，AARRR模型都贯穿用户全链路。用户从看到素材到最终使用，每个环节都要反复做AB testing。比如头部主题产品，每周按语言分组测试图片和文字，以提高点击下载率；安装环节则优化包体大小，在质量和体积之间找平衡；主题下载完成后，是否点击应用，会围绕按钮颜色、样式和推荐主题做测试；应用成功并落到桌面后，继续压缩包体、优化配图和文案；从下载完成到使用，还会根据国家、机型等特征，在第*天推荐相似主题或头部主题，以提升使用率、延长留存。
