# 10.4 Web3 资产安全：3 个必须养成的习惯 @温格区块链

在 Web3 世界，资产真正握在自己手里，风险也一起交到了自己手上。想少踩坑，先把这三件事变成习惯。

**一、私钥和助记词，永远只留给自己**
不要截图、不要存网盘、不要发给任何人，也别输入来历不明的网站。能离线保存就离线保存，必要时用硬件钱包分散存放。谁拿到助记词，谁就拥有资产。

**二、签名和授权，别嫌麻烦多看一眼**
每次连接钱包、签署交易或授权代币前，先确认对方合约和权限范围。不常用的授权及时撤销，遇到“免费领取”“紧急验证”等诱导操作，先停下来核实。钱包弹窗不是点得越快越安全。

**三、入口和合约，只走可信渠道**
尽量从官方链接进入项目，核对域名拼写，不点陌生群聊和私信里的短链接。大额资产与日常交互钱包分开管理，新项目先用小额测试。多一步确认，少一次追悔。

资产安全没有捷径，只有习惯。把这三条守住，才有资格谈后面的机会。@温格区块链
