# 韩国数字资产合法化：监管框架出炉

作为全球最活跃的加密货币交易市场之一，韩国人对数字资产的热情一直很高。早在2021年初，韩国就成立了规模达2237亿韩元的元宇宙生态发展基金，用于平台建设与专业人才培养。此前引发行业震动的稳定币项目LUNA和UST，也正是诞生于韩国。

然而，频繁发生的暴雷事件让韩国政府意识到，必须尽快规范Web3领域的无序发展。尹锡悦政府计划在2023年正式推出《数字资产基本法》，对加密资产实行统一监管。

【资产定性】
明确数字资产属于虚拟资产，不等同于法定货币，但允许合法持有与自由交易。

【监管措施】
全面禁止ICO；加密货币交易所可依法运营，但必须通过韩国政府审批注册，同时所有用户须完成实名认证，方便当局实施有效监督。

【税务规则】
自2023年1月1日起，对数字资产交易征收20%的资本利得税。
