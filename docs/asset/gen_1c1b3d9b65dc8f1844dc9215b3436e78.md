# 10.1 小马宋：工作与家庭，我这样平衡

过去这一年，我在公司待的时间确实很长，晚上经常忙到十点以后才走，回到家孩子早就睡了。后来我调整了做法：除非是直播这类必须在公司完成的事，否则我不再待在公司加班，而是把活儿带回家做。周末也照样在家办公，顺便参与孩子的学习和成长。

我太太问我，在家办公效率怎么样？我说还行，虽然比不上在公司，但综合来看，在家里加班的“总价值”最高——既能陪家人，又能和孩子交流互动。

一个人要处理的事情再多，其实也不需要耗费大量时间。对我来说，每天认真工作四个小时，就足以干完所有该干的事了。

我每天睡七到八个小时，再加上起床、洗漱、做饭和吃早餐（只要我在家，都会给孩子做早餐），那至少是九个小时。不过在卫生间里我也没闲着，会把当天的英语学习任务完成，比如阅读一千字左右的英文新闻原文；做早餐的时候，还能听三十分钟音频课程。

出门上班后，就剩十五个小时了。我骑共享单车通勤，来回十四公里，骑行加步行一共九十分钟。这样一天还剩十三小时三十分钟。骑车路上我会听“得到”或者播客，这算是学习时间；如果不听课，就一边骑车一边思考工作上的事，这一个小时就算工作时间。

午餐大约一小时，加上午休，又用掉一个半小时，剩十二小时。打游戏我会给自己设限，每天最多四十五分钟，剩十一小时十五分钟；刷社交媒体留三十分钟左右，剩十小时四十五分钟。一天里还有一些零碎小事，比如上厕所、做俯卧撑、和同事聊天，平均要花掉一小时，剩九小时四十五分钟。回复微信之类的消息，又要占去一小时左右，最后只剩八小时四十五分钟用于正式工作。当然，谁也不可能全程百分之百投入，就算我每天加班到晚上十点，真正有效的工作时间也不会超过六小时。但这六小时，其实已经非常高效了。

我把所有消息通知都关掉了，只保留电话和微信语音通话的提醒。我也不刷朋友圈，每隔一两个小时看一眼微信就够了。说到底，我们的问题不在于时间管理技巧，而在于自己的意愿。每天想做的事很多，但对大多数人来说，工作恰恰是最不想做的那件事罢了。
