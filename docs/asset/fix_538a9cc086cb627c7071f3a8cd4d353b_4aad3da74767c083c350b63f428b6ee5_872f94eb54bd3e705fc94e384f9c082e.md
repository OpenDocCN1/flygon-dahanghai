# 3.3 工程结构怎么定
# 3.3.1 先了解 MV 分层
苹果官方推荐 MVVM：Model 负责核心数据与业务逻辑（如数据库操作、网络请求）；View 负责展示画面、接收点击输入，不处理业务逻辑；ViewModel 处在 View 与 Model 之间，把数据转换成适合画面展示的格式，管理界面状态与交互，并通过双向绑定保持同步。本次入门先做简化版，只分 View 和 Model：View 管页面呈现，Model 管数据。掌握之后可逐步过渡到 MVVM。现实中也并非每个 App 都需要 MVVM，很多场景 View 加 Model 已经够用。

# 3.3.3.3 分工：Xcode 与 Cursor
划重点：Xcode 用来建文件、建文件夹、看报错、看预览；Cursor 只承担让模型写代码这件事。也就是说，除了写代码，不要用 Cursor 建文件或文件夹；Cursor 里出现的报错先不用管，只需盯住 Xcode 的报错。

# 3.3.3.4 拆页面、排顺序（重要）
从开发者视角看，页面可拆成右侧结构：第一层是行（row），每行放一张图和一个名称；第二层是列表（List），列表由多个行组成，这个列表叫“地标”（Landmark）。于是实现顺序是：先做列表页的第一层——行；再做列表页的第二层——列表；接着做详情页；最后打通从列表页进入详情页的跳转。
