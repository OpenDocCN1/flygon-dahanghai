如果想快速拿到图，可以直接借用多维表格里内置的「AI生成图片」字段，把描述图片的文字填进去作为输入就行。这个办法上手门槛低、出图速度快，不过后续可扩展的空间比较有限。

## 3.具体步骤

### 3.1 设置“开始”节点

给开始节点新增一个入参 api_key。它是生成视频要用的密钥，费用会随会员等级变化：一条 480P、5 秒的视频大约在 0.4 元到 0.7 元之间。密钥需要从 www.aigcview.cn 获取；同款模型下，会员价会比 COZE 官方便宜。使用前先充值，余额不足会导致运行失败。

设置这个入参后，每次运行都要输入两个参数。如果嫌麻烦，也可以把 api_key 直接填到后面豆包图生视频插件的参数里，这样运行时只需输入与古诗词相关的内容即可，和演示视频一样。

### 3.2 添加大模型（生成文案及标题）

点击“添加节点”，选择大模型，把名称改成“生成文案及标题”，再与“开始”节点连线。

#### 3.2.1 节点功能

根据“开始”节点传入的 input（诗句名称），检索出完整诗句、朝代和作者。

#### 3.2.2 参数设置

模型选择豆包·1.5·Pro·32k；输入接“开始”节点的 input。

系统提示词让模型扮演资深古诗词专家：围绕 {{input}} 精准检索对应作品，输出诗词名称、朝代作者、完整诗句；文本写入 zimu，按句拆分后的数组写入 fengjing；朝代作者格式固定为 [唐]·杜甫；只处理古诗词话题，不能夹杂注释、标识或符号等多余内容。

用户提示词为 {{input}}。

输出方面，fengjing 设为 array 类型，zimu 设为 string 类型，记得修改这两个变量名。

### 3.3 添加大模型（文生图提示词）

点击“添加节点”，选择大模型，把名称改成“文生图提示词”，再与“生成文案及标题”节点连线。

#### 3.3.1 节点功能

以“生成文案及标题”节点给出的诗名、作者、朝代和完整诗句为依据，先构思分镜画面，再为每个分镜写出生图提示词。

#### 3.3.2 参数设置

模型仍选豆包·1.5·Pro·32k；输入接“生成文案及标题”节点的 fengjing。

系统提示词让模型扮演 AI 古诗词视频文生图提示词专家：拆解 {{input}} 里的每个镜头，覆盖场景、氛围、动作、表情等要素；每条提示词都要精准生动，既保留古诗词韵味，又适合儿童观看的可爱萌动风格；统一为 3D 动漫卡通风格，主角固定为古代可爱女孩，详细描述服饰的款式、颜色、材质，发型的发髻样式与配饰，以及神态、眼神、表情，保证所有含人物的画面形象一致；全部采用全景景别，人物全身出镜，并讲清人物与环境的位置关系；每段提示词中的人物衣着、发型、形象描述要完全统一；{{input}} 里每个键都要生成对应提示词。

提示词模板为：3D动漫卡通风格，全景，【场景描述】，【人物衣着描述】，【人物发型描述】，【人物表情描述】，【人物形象描述】，【人物与场景位置关系描述】。

用户提示词为 {{input}}。

输出变量名改为 wenshengtu，参数类型设为 array<string>。

### 3.4 添加批处理（图片生成）

点击“添加节点”-批处理，把名称改成“图片生成”，并与“文生图提示词”节点连线。

#### 3.4.1 节点功能

批量接收生图提示词，再把任务分发给“图像生成”节点，批量生成图片。

注意：需要先去智界 www.aigcview.cn 充值，否则无法生图。没有图片，后面的视频素材也无法生成。

#### 3.4.2 参数设置

循环设置里的并行数量必须填 1，因为图像生成只能并行运行 1 次。

输入接“文生图提示词”节点的 wenshengtu。

此时批处理体中还没有添加节点，所以输出暂时无法设置。

### 3.5 添加插件（豆包文生图）

点击“批处理体”，让它显示蓝色选中状态，再点击“添加节点”-插件。

搜索“智界”，找到“豆包文生图-create_image_task”，点击添加。最后与批处理体中的前方圆点完成连线。

#### 3.5.1 节点功能

接收批处理分发的提示词来生成图片，最低 0.13 元生成一张图片。

#### 3.5.2 参数设置

apikey 引用开始节点的 api_key；size 填 1080x1920；prompt 接“图片生成”节点的 input；正向提示词填 {{input}}；重试次数设为 1 次；异常处理方式选择“返回设定内容”。

### 3.6 添加选择器

点击“批处理体”，让它显示蓝色选中状态，再点击“添加节点”-选择器，并与“create_image_task”节点完成连线。

#### 3.6.1 节点功能

接收“create_image_task”的出参 data，判断参数是否为空，也就是判断图像有没有生成成功，再根据判断结果决定后续流程走向。由于 COZE 的图像生成对提示词中的违禁词审核较严，经常导致生成失败；为了保证整个工作流运行不出错、素材不缺失，需要加入一些重试机制。

#### 3.6.2 参数设置

按图示配置选择器条件，核心是判断 data 是否为空。
