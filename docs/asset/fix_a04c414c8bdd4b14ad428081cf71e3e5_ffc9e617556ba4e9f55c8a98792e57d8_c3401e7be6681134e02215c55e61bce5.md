# 七位数进账，六位数亏损：传统媒体创业十年

我叫何靖。2020年5月1日写下这篇长文，算是把进生财有术后一直拖着的自我介绍补上。4月18日成为会员，之后连续两周泡在精华区，越读越后悔：怎么没早点来。

五月的头一天，也借生财有术五月第一篇长文的位置，聊聊我在传统媒体里的打工和创业。账面赚到过七位数，后来也亏掉过大几十万。事情虽然发生在十年前，但有心人应该还能看出些门道。

## 一、从彩铃启蒙到广播节目操盘

我是江西人，2002年来北京上大学，现在也常驻北京。大学时跟朋友小打小闹玩过彩铃，算是最早的行业启蒙。后来老师牵线，我拿到实习机会，开始接触录音和广播节目制作。

实习期间我比较上心，做出来的东西也拿得出手，合作方一家只有5个人的初创公司把我挖过去负责节目开发。加上我，团队一共6个人。在那里，我认识了影响自己很深的Y总——他此前是国内一家教育公司的高管。他手把手教我带人、搭团队、处理事情，把我的成长速度拉快了不少。那段时间也真苦：全公司只有我会做节目，没人能替，只能自己想办法解决问题，再招人、带人，硬熬过一年多每周通宵赶节目的日子。

两年多后，公司从6人涨到150多人，节目进入全国300多家电台、800多个频段。我管内容开发团队和市场团队，做了9档覆盖全国电台日播的不同类型节目，质量在当时算得上头部；合作主持既有各地电台主持人，也有如今配音圈大V阿杰、刘校予。北京奥运会前，我们还和韩乔生老师做过一档奥运体育广播节目，挺有特色。

当时的模式是：用高品质录播节目向各地电台换贴片广告时间，再把节目里的广告时段卖出去。起初接品牌广告，周期长、持续性弱；后来靠SP彩铃下载、短信签名等业务，找到更高效的变现口子，也为后面的业务爆发打下基础。

和TOM、空中网、华友、A8等SP打交道后，我逐渐注意到互动答题类IVR业务增长很猛；又经中国电信的朋友确认，已经有人在做类似节目。于是我用两年多积累的广播媒体和节目资源做广告投放测试，效果很好。2007年，我们做出国内最早的广播电视互动答题节目之一，形式有点像后来的冲顶大会，很快冲到行业前三，靠SP的IVR业务变现，月收入做到千万元，纯利超过70%。

但SP行业的好日子没撑太久。几个月后，最赚钱的业务开始受行业大势拖累下滑；公司又因为后期股东加得太多，意见难统一，逐步想放弃下滑业务——赚过快钱后，确实看不上别的了。中间试过音频播客网站、电子杂志、广播购物等，最后老板们想转传统餐饮。我离开后，他们真开了一家湘菜馆。这个决定后来看挺矛盾：近几年我和老老大聊起，他说当时突然赚到钱，几个股东想收缩，找稳当生意，选来选去开了餐馆；没多久也关门，之后转去做自主品牌电商。

当年的我年轻气盛，觉得公司赚了那么多钱却不坚守原业务、不继续找方向，难以接受，于是辞职重新找路。2008年中离职不久，Y总也因和其他股东意见不合离开，我跟着他做了几个月教育类网站产品。到2008年底，我在广播和电视上又听到、看到类似节目，反复琢磨，觉得之前放弃太可惜；如果坚持，应该还有发展空间。Y总给了我50万元天使投资，我由此开始三年创业。

## 二、第一次创业：踩中风口，也踩进坑里

年轻人不服输、不信邪，我当年就是如此。2009年初，我拉团队注册公司：我、一个合伙人、两个制作、一个产品策划、一个市场，再加两个兼职主持人，热热闹闹又磕磕绊绊地干了三年。

最初想法很朴素：公司得先有收入、能赚钱。通过以前合作的SP，我了解到还有几家有通道——和现在一样，有些业务看起来不怎么样，却一直有人投，说明里面有钱赚。于是节目还没完整成型，我们先和华动飞天（A8音乐）、广东新媒、广州海岩（37游戏前身）、天盈九州（凤凰网）等SP建立合作，拿到产品号段资源。SP分全网和地区：全网号段全国可用，地区号段只能在本地省份用；IVR按拨打时长收费，通常2.5—3元/分钟。分成谈得好能做到1:9，我们拿90%，SP拿10%，坏账有一些但基本可忽略。SP拿得少也愿意，是因为他们类似支付通道，像今天的支付宝、微信支付，只是还要参与产品设计；另外他们有冲业绩、保业务评级的任务，冲流水也是KPI之一，当然也会扣量，细节不展开。

我们从一套两居室起步，几个人没日没夜地干。我负责节目内容出品和SP合作接入，合伙人负责电台、电视台合作。人手有限，短时间内也没有现成节目能免费给媒体换广告时间——后来看，这个“支撑”反而埋了坑——所以先打算用专题节目广告投放的方式，快速和电台、电视台建立合作。

做广电媒体的人都知道，地区越发达、覆盖越广，价格越贵。卫视、省台我们那点资金不敢碰。节目时长最少要25分钟左右，太短效果差、风险大。后来常有朋友问：为什么你们投放价格那么低？广电刊例价看着吓人，一般卖10秒、15秒或几分钟小专题，你们节目那么长，价格却那么低？原因是我们熟悉媒体生态，更关键的是当时环境特殊：全国正打击医药类专题节目，地方电台、电视台很大一块收入来源被切断，很多媒体没得选。我们知道他们缺什么，能提供他们没有的内容资源，或者能帮他们创收的资源；合作洽谈方式也不一样。史玉柱《我的营销心得》里写过类似广电投放，感兴趣可以翻翻。

按当时资金，我们采取“农村包围城市”：先打电话问县级、县级市、地级市的播出时段和报价，省台、卫视先放一边。现在回想，主要就是钱不够；如果当时投卫视，哪怕价格高些，ROI也许能收回来。

一边问时段报价，一边定了个风险可控的试播策略，类似今天的测试投放。和广电媒体谈合作，都按年度或至少半年框架起谈，再结合节目合作，跟对方主任要一个低到月度的核算报价。有些县级、县级市，一档25—30分钟日播节目时段，一个月3000到50000元不等；黄金时段贵些，地区差异也大，百强县比贫困县报价高很多。但对没效果的广告来说，多少钱都浪费。所以我们把月广告费折算到每天，再翻倍给媒体，要求试播3天或7天。比如一个月3000元，一天100元；让我试播3天，我可以给600或1000元。当时还跟主任说可以不要票，你懂的。借口是调试节目内容、看看效果——效果对我们就是播出后有多少用户参与并产生收入。效果好就签长期，还把该台其他空余时段一起打包；我记得有几个地方台一天早中晚都在播我们的节目。前提是先测试几天，最后留下效果最好的时段；效果不好就果断放弃，哪怕短期多花点钱，也为后续止损。

策略定好后，业务慢慢转起来。探寻县、县级市广电媒体时，有些地方台给过我们“这也太猛了”的震撼，这和节目类型关系很大。印象最深两个地方：一个是云南红河哈尼族彝族自治州下辖的泸西县，当时大概30多万人口，每天25分钟节目，一个月播出成本也就是广告费3000元——没看错，3000元一个月，折合一天100元。当时都不好意思聊试播。节目播出第一天，收入2.1万元，我们都震惊了；但播到第6天，台里扛不住，只能停播。另一个是安徽安庆下面的望江县，收入没那么夸张，但投入产出比极高，可惜受节目类型限制，也没能播太久。这两个点的爆发，让我们更坚定去扫1300多个县和300多个县级市的可播出资源，复制打法。

还是太年轻，以为这种爆发是大概率。资金有限、覆盖又广，最高峰一天几十个台在播；有些地区没严格控制成本和付款方式，最后整体利润比预期低不少。更关键的是好景不长：SP行业到2009年下半年已基本进入尾声，号段产品资源逐步关闭，相当于产品没了好的支付通道。做了不到半年，整体算下来盈利不到200万元。虽然账面上赚到过百万元级，后来也凭实力亏得七七八八。

2009年下半年到2010年初，我们转型做传统广播节目，继续推广合作、找新变现机会。账上有点钱后人就不太安分，总想干这干那。其实早在原项目启动两三个月后，我们就启动了传统广播节目制作：一方面想延续之前没坚持的事，另一方面想再用优质内容换贴片广告时间，让公司有业务可做。这个阶段团队扩到20多人，换了大办公室，装了录音棚，做了两档广播节目，运营成本一下子上来。差不多坚持半年，期间一直做内容、基本没收入，再看账上资金，已经亏了大几十万。所以第一次凭实力亏掉的几十万，就是持续没有收入的高成本消耗。难道少了原来的变现方式，这条路就走不通？短期看可能是，但当时没坚持住。Y总建议下，2010年4月左右我们忍痛裁员、压缩成本，重新调方向。

2010年6月，我入局当时还没到百团大战阶段的团购网站。我们还作为草根代表上了《第一财经周刊》团购专题封面报道；在无技术、基本无互联网经验的情况下，几天把网站上线，开始互联网探索。团购期间自己的网站没赚到什么钱，但通过选品和各大团购网站合作，做出两款独家爆品——一款生态玩具、一款通用体检卡——赚了几十万。随着千团大战和后续发展，我发现自己缺乏互联网行业经验，中间花几个月专门学网络营销等知识，打算再通过职场历练自己。首次创业之旅到2012年暂时画上句号。故事太长，团购和后续经历有机会再分享。

## 三、十年回望：几条踩坑心得

虽然这是十年前的复盘，项目也有时代特殊性，可能有人觉得玩法有点灰，但我还是相信，总有人能从中挖出别的思路。

传统媒体的价值仍值得再挖。广播也好，电视也好，都有各自的媒体特性；对某些类型的用户来说，官媒的信任度和背书天然高于其他媒体。

试播或试投放，得去试才知道。但什么时候该坚持、什么时候该及时止损，很值得琢磨。这一点我做得不好，也要继续学。

别总觉得自己比别人聪明，把大多数人当傻子。很多坑，恰恰是自认为聪明的人踩进去的。有些事上，做个傻子挺好。

项目分享完，我也常做假设：如果当初坚持做音频内容，熬到喜马拉雅FM、荔枝FM等网络电台起来，也许是不错的机会——但谁说得准呢？如果当初投卫视，是不是能拿到更多用户、投入产出比也不错？后来试算过，但其他风险谁知道呢？人生没那么多如果。回看十年前创业，收获只有自己清楚：喜忧参半。喜的是年纪轻轻就经历了比同龄人多得多的事，收获经历和阅历；做事先做人，与人为善，多交朋友，懂得吃亏是福，会收获更多。忧的是项目失败、团队解散，以及没能真正让项目持续盈利。

## 四、继续折腾：后来的项目和近况

近几年做过不少事，能细说的不多，大多有特定环境。比如2013年做第一款手游，几乎没花市场成本，产品做到App Store总榜前三，下载量千万级；2014年第二款手游也冲到总榜前五，以后有机会再聊。2015年做生鲜订货系统，被业内一家号称拿了8000万融资的公司反手抄袭，项目后来也因多种原因放弃。创业到现在，我折腾过电商、游戏、生鲜供应链系统、智能硬件媒体等，继续积累经验、寻找机会，期待下一次爆发。
