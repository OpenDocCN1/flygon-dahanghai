挑图时，我会先看配色是否贴近日常认知。柯基通常是橙色系，牛牛则以白、粉为主，第一张和第三张正好属于这种日常感；第二张彩虹滤镜很重，第四张偏废墟氛围，风格化明显。因此复刻顺序上，我会把后两张放一放，先不急着处理。

> 请参考我上传的图，写一份尽量还原画面的英文提示词，并附上中文解释。

随后 DALL·E 会返回英文提示词和对应的中文说明。

多绕这一步，有两个考虑。

一是实测下来，用英文提示词让 DALL·E 出图，稳定性比中文提示词更好。

二是中文说明是给自己核对用的。画面元素一多，英文提示词可能漏掉细节；对着中文解释看一遍，发现少了什么，再让它补进去即可。

这次测试属于运气好，一次就出了比较满意的结果。实际更常见的情况是，DALL·E 生成的画面和预期有差距，需要反复“抽卡”才能拿到想要的图。想再来一次，把提示词复制粘贴再发即可。

# 4.2 故事号 @老马*内容出海

# 4.2.1 故事号是什么

故事号，是从其他文字类社媒平台采集文案，再做二次创作的视频。它有点像国内抖音上的知乎贴文、天涯神贴、贴吧神帖那种呈现方式，但又和小说推文赛道不是一回事。

素材主题多集中在搞笑、狗血、恐怖，配上解压素材混剪。展现形式大致分三类：普通故事风、Reddit 风、短信风。也可以是一人分饰两角的搞笑对话，或者基于搞笑对话素材做二次创作——逻辑跟国内博主把搞笑对话做成沙雕动画差不多，底色都是故事号。

故事号的特点是商业延展性更强：既能吃视频收益，也能做 CPS、CPA、推广产品，以及其他商单。创作难度低，重点主要在素材收集上。下面看看它的优势和劣势。

**优点：**

1. 拓展能力强，故事模板不变，选题可以千变万化。
2. 选题不变，视频展现形式可以千变万化。
3. 商业模型多变，可以接推广、CPA 商单，在没开通收益之前先撑住收入，让自己能持续做下去。
4. 剪辑简单，适合新手快速上手，加深对平台、流量、规则、基础功能的理解。
5. Shorts 新规“三分钟内容”更适合故事号发展，未来还会持续发力，属于潜伏在地下的老赛道。
6. 一般不带标签，除了配乐可能只有一个标题，极难采集。但只要你找到一个两个，也就撬开了这类大门。

**难点：**

成长缓慢，需要熟悉海外社交媒体，克服采集素材和文案的能力，能有效理解文化差异里的梗。把这些吃透，账号起步会更快。

注意：以下所有文案训练方法，没有限制字数或对话次数。可能会出现配音结束、去掉气口后超出一分钟的情况。这种就自行修改提示词，或手动删减内容、对话，缩短时长。做 TikTok 不受影响。Shorts 彻底更新后，大约在 12 月初或中旬，也不受影响，三分钟内。

# 4.2.2.3 第三步：准备解压素材

获取渠道：Ins、YouTube、TikTok、抖音。

别用淘宝上那些几十块多少 T 的素材包，大部分都用烂了，还有一些是实时卖给你的，也是从海外采集来的。解压素材很重要，尤其是高清、合格的素材，它决定了你会不会 0 播、会不会过重。

解压类内容，大部分人搜的关键词是「ASMR」，国内搜「空耳」。尽量用海外素材，因为很多国内素材带文字，去重起来特别麻烦，裁剪又变了味。如果遇到国内无字幕的素材，那完全可以用。

这里我们找一手海外素材，英语课堂开课了：

「ASMR」这个词太大类，容易搜出有人声的，毕竟一些博主也在做这件事，所以要挖更深一点。

深层词：

Sandart：沙子艺术，San（沙子）+ Art（艺术），从这里可以延伸出更多细分领域；

XXXart：比如蛋糕艺术（cakeart）、木雕艺术（Woodcarving）、纸张艺术（PaperArt）、金属艺术（MetalArt）

Satisfying：字面意思是令人满意的、令人愉悦的，比如「A satisfyingly crunchy sound」，一种令人满足的脆响。

Oddlysatisfying：指一些看似奇怪但能让人感到满足和愉悦的事物，通常有视觉或听觉上的特殊性，能激发好奇心和审美情趣。

有了这些词的拓展，是不是好找很多？不抓瞎了吧？这么多细分赛道素材，再加上混剪，总能去重。根据这些细分关键词，就能找到更多解压素材，Ins 首选，其次 YouTube 和 TikTok。

不想找也没关系，我这里有一批整理好的对标，可以拿来练手。但可能需要多混剪，因为都用过，可以追新发的来剪：故事号素材收集库。

想做好故事号，自己的素材库必不可少。你可以根据我的对标，用一个新号关注一波，然后慢慢刷出新的，建立属于自己的素材库。
