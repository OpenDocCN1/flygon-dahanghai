# 7.2 违规检查：每日必做的店铺安全课

做电商，平台规则就是不能碰的底线。每天开店后先别急着盯销量，第一件事是查一遍店铺有没有违规；万一出现重大违规，要第一时间有针对性地申诉。这是运营每天逃不掉的必修课。下面挑几种常见违规和处理方式，给大家提个醒。

信息泄露处罚一旦被认定，罚款10000元，如图所示。

它和前面说的搬货处罚性质相近，在美团电商都属于顶格严惩，二者并列平台最严处罚。

从根子上看，这和淘宝、抖店、京东等平台治理无货源商家的逻辑一致，只不过美团的处理力度更重。真正触发美团处罚的常见原因，是搬货的买家察觉后向平台小二投诉。

买家是怎么发现的？其实生活里很多人都碰到过：在淘宝下完单，卖家一发快递，手机短信或菜鸟裹裹小程序就会提示“该商品已由某商家发出”。这种通知一出现，买家自然容易意识到，货是从别的平台代拍的。

应对办法分两步走。

第一步，把淘宝采购号的菜鸟裹裹提醒关掉：解除淘宝与菜鸟裹裹的授权，注销菜鸟裹裹账号，同时在支付宝里解除菜鸟裹裹小程序的授权。具体操作看教程《【美团 8】重要：淘宝采购号关闭菜鸟裹裹提醒》。

第二步，只要察觉到买家有向小二投诉的迹象，立刻打电话沟通，给个小额红包补贴，或者干脆仅退款处理。做生意有百分之几的货损，很正常。
