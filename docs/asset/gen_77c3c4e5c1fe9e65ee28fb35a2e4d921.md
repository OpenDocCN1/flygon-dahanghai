# 零成本、零跑腿，注册公司并开户

之前有圈友分享过在广州不花什么钱就把公司注册下来的经历，原文在这里：  
https://articles.zsxq.com/id_mfr9c5a6npsr.html

这次我把自己年底实操跑通的方法整理一下：不额外掏钱、不用亲自跑现场、也不需要租办公场地，公司注册和银行对公户都能办下来。先提醒一句，这套方式只适用于有限公司；个体户注册不了，如果你要办的是个体户营业执照，看到这里就可以划走了。

整个流程比想象中简单，下证速度也快。比较关键的一点是地址问题：园区会提供实体工位作为登记地址，不用自己再去租办公室。实操中我还发现，人不在杭州本地也能出证。所以对外地圈友来说，只要不担心异地银行操作环节，也可以尝试。尤其适合做跨境电商、本来就不需要实际办公地址的朋友。

具体操作文档我放在这里：  
https://sbu67xqbm4.feishu.cn/docs/doccnMcAbXl3I2UR5mlf3ApTGYf

评论区里大家问得比较多的两个问题，也一并补充一下：

有人问注销是不是必须到场。自己办的话需要去行政大厅，也可以找代理帮忙办理。

还有人问银行对公账户是不是要法人去银行。是的，法人需要到场核验身份。流程并不复杂：在地图上查一家离你近的民生银行，把信息告诉园区工作人员，他们会帮你约时间；法人带上身份证去核实身份信息，剩下的他们会协助办理。

如果你正好有注册公司的打算，可以先收藏起来，行动前把异地开户和后续注销的实际情况确认清楚。
