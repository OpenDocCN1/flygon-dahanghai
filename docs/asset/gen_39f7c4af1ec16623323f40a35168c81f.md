# 3.3.2 一个让人上瘾的公式

真正厉害的激励，往往就藏在一个简单的组合里：正向反馈 + 不确定奖励。

对照那张总览图可以看到，正向反馈的根基是定位。换句话说，凡是能巩固定位、推动定位扩大与深化的行为，我们都要及时给予正面回应，让这些行为不至于屡屡扑空。

这里还有一个更妙的技巧：在正向反馈上增加一点随机性。一旦加入“不确定”这个变量，激励效果会立刻变得超乎想象。

几个例子就足够说明问题：

- 赌博为什么让人欲罢不能？因为那种随机的、高强度的正向反馈，是人类很难抗拒的。
- 走在路上突然捡到钱，为什么会欣喜若狂？本质也是这两样东西碰到了一起。
- 盲盒手办在商业上能跑通，靠的还是这个组合，为了增强效果，商家甚至设计了隐藏款。
- 抓娃娃机流行这么多年，娃娃做得越精致，那种反馈带来的爽感就越强。
- 还有当年让🐧邮箱、🛰️日活一路高涨的漂流瓶、摇一摇、附近的人，哪一样不是这套逻辑？

这些场景背后全是同一个公式在起作用。你可以试着把两个因素任意拿掉一个，再看这些玩法还成立吗？恐怕立刻就垮掉了。这就证明，被拿掉的那一项，正是商业模式里绕不开的核心要素。

随机的正向反馈还有一个额外好处：能节省成本。把“随机”和“正向反馈”再放到一起琢磨一下，你会发现🛰️红包的本质也在这里。

有人发红包，这就是正向反馈；手气怎样全凭运气，这就是随机。

当年🛰️和支付宝大战，支付上的家底几乎为零。靠着一张春晚牌 + 红包产品，一个春节就逆袭了支付宝多年积累的线上支付基本盘——绑定银行卡的用户规模。这背后，是🛰️团队（龙哥）对“随机正向反馈”和“损失厌恶”心理的深刻理解。

这一役之后，互联网公司买央视春晚广告的套路也彻底被改变了：上来就是发红包。

有意思吧？

2023年春节，有人嘀咕：怎么这年没见互联网公司上春晚撒钱发红包了？我听到这句话时，脑海里第一个浮现的，就是当年🛰️在春晚上那场封神之战——正是它，奠定了🛰️在支付领域的位置。
