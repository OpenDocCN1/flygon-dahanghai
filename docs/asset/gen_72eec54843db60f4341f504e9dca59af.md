# 8.4 第四步：标题要让人想点

这一回，我从百度百科摘了一段关于 GPT 的说明，直接丢给 GPT，想看看它能不能起出那种让人一看就想点开的标题。

我给的提示词大意如下：你学习能力很强，归纳得也到位。现在请把从两块知识里学到的东西用起来——一是二极管标题法，二是优秀标题库。围绕下面这段文字，拟 3 到 5 个标题，供我选择：

ChatGPT 的出品方是美国人工智能研究实验室 OpenAI；它属于自然语言处理工具，背后由人工智能技术驱动，是新近推出的一款产品。它基于 Transformer 神经网络架构，归在 GPT-3.5 架构之下，这个模型擅长处理序列数据，既能理解语言，也能生成文本。训练过程中，它接入了海量语料库，其中包含真实世界里的对话，因此它聊起天来天上地下都能接，能顺着上下文互动，交流场景里几乎和真人分不出差别。它并不只是聊天机器人，邮件、视频脚本、文案、翻译、代码等活也能干。

OpenAI 官网对它的定位是：以优化对话为目标的语言模型，同时是 GPT-3.5 架构的主力。同类产品常见的对话能力它也有，而且能在一次会话中接住前文，回答相关的后续问题。真正让它迅速在全球出圈的，是网友们贴出的对话截图：除了对答如流，它还会作诗、写文章、敲代码。

训练方式上，它还强调道德水准，依照事先设定的准则，对心怀恶意的提问和请求直接拒绝。只要识别到用户提示中存在恶意——比如暴力、歧视、犯罪等意图——它就不会提供有效答案。
