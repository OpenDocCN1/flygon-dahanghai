# 1.1 现在做美团电商，晚不晚？

提到美团，很多人第一反应是点外卖。它正是从餐饮外卖切入，天然离消费者更近。到2022年，美团年活跃用户约7亿；而注册用户突破10亿的超级应用，放眼市场也只有淘宝、抖音、微信、京东、QQ等少数几家。

所以，美团进军电商并不难理解：既有足够厚的用户底盘，也有清晰的对标人群。但电商这条路从来不好走，投入大、链条长、难度高。回看这些年的尝试，美团拉过队伍、铺过站点，也烧过资金、试过多种运营模式，既有收获，也交过学费。

几个关键节点值得回顾：

• 2010年3月，美团成立；
• 2012年至2014年，陆续推出电影票在线预订、酒店预订、餐饮外卖和旅游门票预订等服务；
• 2015年10月8日，美团和大众点评完成合并；
• 2018年9月20日，美团在港交所上市；
• 2020年7月，设立“优选事业部”，推出美团优选；
• 2020年8月，上线“团好货”，之后升级为“美团电商”；
• 2021年，美团战略升级为“零售+科技”；
• 2021年上半年，相关业务与美团优选合并，同时清退约95%的商家，主要是持个体执照的店铺以及缺少质检报告的店铺；
• 2022年上半年，再次开放招商；截至2022年10月，全平台卖家约4000家（作为对比，2021年淘宝卖家约950万家）。

还要看到，美团虽然坐拥近十亿用户，但这些流量对美团电商而言仍属于新用户。美团大力发展电商，本质上是要把现有本地生活服务用户逐步电商化，进而提升平台ARPU值——也就是一定时间内从每位用户身上获得的利润。

如果你正考虑入局美团电商，眼下或许是个不错的窗口：这个项目仍处于中早期阶段。
