# 2.4.1.1 第一类：从生活场景引出产品

为什么有些带货文案看完会让人立刻下单？关键在于结构：先给生活场景，再引出产品，最后用一句指令收尾。场景负责让读者对号入座，产品负责提供解决方案，而下单指令才是推动读者行动的那一下。

六张图里出现的都是真实的日常：自家的生活、宵夜时分、被家人泼冷水、熬夜带娃……没有夸张或离奇，反而让人觉得“这不就是我吗”。一旦读者被拉进场景，接下来的产品推荐就不会突兀。

再注意看，这些案例的结尾，几乎都配有明确指令——“扫码购买”或“找我报名”。这也是最容易被人忽略的重点：读者需要有人告诉他下一步做什么。没有指令，哪怕文案前面写得再精彩，读者也可能看完就翻走。

这个原则，放到其他自媒体写作同样成立。我曾在👸号文章末尾加上一句“请点赞和转发”的提醒，那几篇的点赞、转发数据明显更高；不加这句话，互动就少了很多。

所以说，别等读者主动，读者需要指令。文案结尾，大胆把指令写出来就对了。
