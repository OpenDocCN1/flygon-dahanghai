# 低价货源别急着上架，索赔可能晚点到

作者：蓝海游龙｜日期：2023-05-09

1，作为一个很少发帖的老圈友，今天有点郁闷，不过很快想开了。去年底那个“兔圆圆”商标，后来才发现央视旗下公司申请撤销了使用权，并自己重新申请，自然不会来我这儿买。

（我只是备着，并非专门靠注册商标转卖。）所以这不算真正损失，就当买个教训：以后把使用证明记录做扎实，遇到类似情况也能从容应对。

2，不过这件事一刺激，让我想起知识产权领域的一些操作。有人走长期路线，也有人干杀鸡取卵的事。有些话在别处不方便讲，这里说一个“不厚道”的路数。做快团团和无货源的朋友要留心别踩坑。

（1）你可能刷到一个看着挺靠谱的低价正品货源，入场要求低，小批量就能进货，甚至能由上游直接发给买家。上架后推广花费不大，出单也顺，对方也不管你有没有乱价……

（2）等半年、一年甚至更久，这个品热度降了、竞争更凶了、卖不动了，甚至链接都下了。这时候，法院文书找上门。也许你总共只卖了几千到几万块，利润就小几千，却被索赔几十万甚至更多。你一下子发怵、心慌，也无计可施，因为货确实是假的。

更麻烦的是，你发现某个买家下单后就把各种证据固定好了，你根本辩不赢。而且平台上的销售记录，对方也能拿到。

所以只能认了。后面态度放好、多说好话求情，通常不会按十倍追，最后赔付金额往往落在几万元，约为销售额的三倍。

（3）之所以说这是套，是因为供货源头里，有的品牌从一开始就清楚，有的则被多层中间人刻意安排。人家前期故意不搭理你，等你销量养大（数据又很好查）再动手。看似省了成本，最终付出的代价更重。

（4）换个角度看，品牌方和维权团队合作，成本压得极低：品牌方出授权就行；维权方投入买货和取证的人力。每成一单，双方按约定分账。

这个团队做每个品都养到合适节点才动手，当然他们不只做一个品，还有别的品和别的业务。而且这套做法表面上完全合规。若卖家明知假货还态度强硬，不论在沟通中还是庭审时，处罚往往更重，对方收益也更高。

（5）我把这个套路讲出来，是想提醒做快团团和其他平台无货源的朋友，尤其是美妆护肤这类领域，一定选好上游源头，别因为一时贪便宜栽进去。

（6）这种“下套”方式，并不需要多强的团队能力，投入小、回报大。只是让人觉得很不地道，我个人是做不来的……谁非要做我也拦不住，也别再问我更多细节和注意事项了。→_→
