# （5）私域转化接单

**初步沟通：** 先摸清客户要什么——写什么内容、多少字、什么风格、什么时候要。这一步很关键，需求拿不准后面全白搭。

**提供信息：** 把服务范围、价格、流程、交付时间告诉对方。可以直接聊，也可以发介绍文档，或者引导对方看你的作品集。

**确认细节：** 需求清楚后，把稿件要求、价格、交期敲定。条件允许的话给个简短的协议，把双方权责写明白，省得后面扯皮。

**答疑解惑：** 客户可能问风格、修改范围、版权归属之类的问题，耐心回答，帮对方理解流程和成果，信任感就建立起来了。

询盘阶段是建立关系的第一步，沟通到位了，后面才能给出精准的方案。

需求聊透之后，引导对方加🛰️继续沟通。注意尽量别主动发自己的🛰️号，小心被同行举报。（具体话术见7.3）

# 7.1.3 BOSS直聘兼职写手

选好地区后在BOSS上搜“小说”，按关键词逐个筛出合适的岗位。

# （1）面试小说写手兼职注意事项

面试通常会要求试稿，注意以下几点：

**明确试稿要求**

主动问清楚题材、字数、风格、交稿时间，别因为理解偏差导致返工或被拒。

示例：“试稿的主题和风格有参考案例吗？需要多少字？有没有特定关键词或禁忌内容？”

**确认版权归属**

提前问清楚试稿内容会不会被无偿使用，可以提出“试稿仅用于能力评估，未经授权不得商用”，防止被白嫖。

如果HR要求试稿篇幅过长（比如完整章节），建议分阶段交，先给大纲加开头片段。

**评估对方专业性**

观察HR能不能清楚说明合作模式（分成、买断、保底稿费），如果对方含糊其辞或者一味压价，要警惕是不是低质甲方。

# （2）与HR沟通试稿后期稳定接单

**结算方式与周期**

明确稿费标准（千字价/篇数计费）、结算周期（周结/月结）、支付渠道（支付宝/对公转账），避免后期纠纷。

示例：“长期合作有阶梯稿费吗？逾期付款有补偿吗？”

**内容需求与修改规则**

确认内容类型（网文/IP定制/新媒体短篇）、更新频率（日更字数）、修改次数限制（比如免费改2次后额外收费）。

同时强调自己的创作边界（比如不接耽美/灵异题材）。

**长期合作可能性**

问清楚后续接单稳定性（“每月保底多少万字？”）以及有没有晋升空间。

# （3）风险规避技巧

**合同条款审核**

要求签电子协议，重点关注保密条款、版权归属（是否署名）、违约赔偿（比如甲方无故拒稿）。

警惕“试稿通过后签约”但没有书面承诺的情况，可以要求试稿前先签个简单意向协议。

**保护个人信息**

试稿时别透露太多个人经历或原创设定，防止创意被剽窃。

**留存沟通证据**

在BOSS直聘或🛰️里保留关键约定（稿费、交稿时间），别信口头承诺。

# 💡

总结：试稿是双向筛选，既要展示专业度，也要通过细节判断甲方值不值得合作。前期沟通越细，后期纠纷越少，重点保护自己的创作权益，别成了廉价劳动力。

# 7.2定价体系设计

# 7.2.1 按字数计费

女频小说：千字10—20元

男频小说：千字10—15元

注意事项：

字数定价适合大多数小说创作，包括情节相对简单或常见的类型。价格区间可以根据故事复杂度、情节安排、人物设定等因素上下浮动。如果遇到特别复杂的情节或需要深度情感刻画，建议适当提价。

# 7.2.2 大纲创作定价

有完整大纲要求的，大纲创作：每份10—15元

注意事项：

这个价位适用于客户已经有完整创作大纲、只需要按大纲写正文的情况。报价前要跟客户确认大纲的具体要求，包括每章内容细节、人物设定和背景世界观的复杂程度。如果大纲比较抽象或粗略，可以根据工作量适当调整。

# 7.2.3 单独开头创作定价

开头创作（单写开头）：千字40—50元

注意事项：

开头是吸引读者的关键部分，通常要求较高的创意和文笔。定价偏高是因为它要定基调、抓注意力、铺情节基础。价格区间可以根据开头的创新程度、情感铺陈和引导性来调整。

# 7.2.4 大纲制定定价

完整大纲制定：每份50—100元

注意事项：

大纲制定是前期的重要工作，涉及情节规划、人物设定、主线支线协调等。创作者需要在大纲里清晰描绘每章目标、人物发展轨迹和高潮布局。大纲越复杂定价越高，可以根据详尽程度合理报价。如果客户要求高度详细的大纲，价格就往高端区间靠。

# 7.3私域谈单沟通转化技巧

# 7.3.1破冰开场：拉近距离（情绪价值体现）

# 💡

关键点：沟通开头用温暖真诚的态度拉近距离，让客户感到被重视。别一上来就“推销模式”，先从称呼或氛围入手建立情感连接，再逐步深入需求。

碰到年轻客户有个通用办法：对男性叫“宝子”，对女性叫“宝宝”，配上适当表情包，能有效打破陌生感。

除了“宝子”，也可以用“哥哥”“姐姐”“美女”等称呼，但语气要自然亲切，别太客套生硬。初次沟通也可以直接切入主题，后续互动中慢慢建立信任。关键是全程保持真诚和专业。

实用建议：

去掉“刻意热情”——别堆修饰语和多余称呼，直击客户心理，让对方感到真诚和干脆。

加点“调侃元素”——适当幽默，比如夸对方头像、🛰️名，甚至自嘲，能快速破冰。

别绕圈子——开场白控制在一两句内，直接引出需求或提问。

# 7.3.2需求挖掘：找到痛点（了解用户需求）

关键点：通过提问和引导，明确客户真正的需求和难点，确保后续方案精准匹配。

**第一步：初步了解核心需求**

话术示例：

“您好，感谢信任！为了更好为您定制内容，先确认几个关键方向：

小说类型：都市言情、悬疑推理、玄幻修仙，还是其他细分题材？（可给热门标签参考）

目标读者：男频/女频？倾向哪个平台（晋江、起点等）或年龄段？

核心亮点：侧重人物成长、世界观设定，还是强剧情冲突？有对标作品参考吗？”

作用：快速定位基础需求，筛掉非目标客户（比如需求和自己擅长领域不匹配的）。

**第二步：细化创作要素**

话术示例（针对需求模糊的客户）：

“您说的‘偏轻松风格’具体是指：

语言风格：幽默吐槽风（类似《大王饶命》）还是细腻情感流（类似《偷偷藏不住》）？

章节节奏：快节奏打脸爽文（日更万字），还是慢热铺垫型（注重伏笔）？

角色设定：主角人设有没有特殊要求（大女主、反派重生、系统金手指）？”

技巧：给选项缩小范围，避免客户因为“说不清需求”而放弃沟通。

**第三步：确认交付标准与限制**

话术示例：

“为确保内容符合预期，还需要确认：

篇幅规划：单篇短篇（5万字内）还是长篇连载（分大纲+正文阶段交付）？

更新频率：作者自主创作，还是按日/周固定交稿？

内容边界：有没有禁忌内容（血腥描写、政策敏感题材）需要规避？”

作用：明确合作风险点，避免后续因需求变更引发纠纷。

**第四步：引导客户补充隐性需求**

话术示例（针对犹豫型客户）：

“很多客户会关注这些细节，您也可以参考：

世界观扩展：是否需要作者协助完善设定（地图、势力关系图）？

IP衍生需求：是否计划后续做有声书、漫画改编？如果有，建议提前规划人设丰满度。

数据反馈：是否需要根据平台读者评论调整后续剧情？”

技巧：用行业经验预判客户没说的需求，凸显专业度。

**第五步：总结需求并报价**

话术示例：

“根据沟通，您的需求总结如下（请确认）：

题材：女频古言重生爽文，对标《xxx》，目标平台晋江；

字数：大纲+前10章（约3万字），后续按千字xx元续订；

风格：强打脸逆袭，节奏紧凑，周更2万字；

附加：提供基础世界观设定表，免费修改2次。

报价方案：大纲+前10章费用xxx元（含2轮修改），3日内出大纲确认，7日内交付正文。您看是否调整？”

关键点：

1. 用结构化列表清晰复述需求，降低客户理解成本；

2. 报价拆分阶段（大纲→正文），降低决策压力；

3. 强调交付流程（“大纲确认后再写正文”），传递可靠感。

**应对客户“不确定”的话术**

场景：客户说“先随便写个方向试试”。

回应：

“理解您的顾虑！为避免试稿方向偏差，我们可以：

4. 提供3个热门题材提案（含核心梗概），您选一个细化；

5. 根据您的模糊描述，我起草2版500字短纲供您选择。

（注：提案阶段仅收xx元定金，成交后抵扣稿费）”

底层逻辑：用低成本方案引导客户进入决策流程，同时过滤白嫖党。

引导策略：纯写作需求话术

2. 低成本试水转化

3. 应对价格异议

客户质疑：“别家千字20元也能写。”

专业回应：

“低价稿件的常见风险：

① 重复率高：机械套模板，容易被平台判定抄袭；

② 断更风险：写手同时接多单，更新不稳定；

③ 修改成本高：需要您逐字指导，耗时耗力。

我们的标准版包含原创度检测（查重率＜8%）+更新保障协议，实际帮您省下30%隐性成本。”

**实战案例：分层报价促成签约**

客户背景：

需求：悬疑推理短篇（8-10万字），预算有限，但希望“有机会上平台首页推荐”。

沟通策略：

4. 需求分析：

客户隐性需求：想用低成本内容测试市场，数据好再追加投入。

5. 方案匹配：

✅ 阶梯式合作：

“前3万字按标准版（千字15元）重点打磨‘连环凶案开场’和‘主角侦探人设’，如果点击率进频道前50名，后续按基础版（千字40元）快速完结，总成本控制在6000元内。”

6. 结果：

客户签约标准版，首3万字获平台新书潜力标，主动续订至8万字（总价5600元）；

作品完本后均订破3000，客户返单委托同系列第二部。

**客户决策辅助工具**

7. “需求-预算”匹配表：

低预算+高要求 → 旗舰版短篇（5万字内）；

中预算+长期连载 → 标准版分阶段付款；

高预算+急稿 → 旗舰版加急费（总价+20%）。

8. 风险保障承诺：

“若因我方问题导致断更，按缺更字数双倍补偿或免费续写。”

# 7.3.5适当优惠：促使成交（符合客户预期）

关键点：报价和谈判中可以适当让利，但底线要守住。把服务价值讲清楚，让客户明白价格合理。

走到这一步基本就是讨价还价环节了，有销售经验或购物经历的人都懂，用贸易术语说叫询盘、回盘。

适当给优惠，比如9折、88折，或者送1-2次修改、后期附加服务。如果是老客户介绍来的，可以说“看在朋友面子上给你个优惠价xx折”，成交后别忘了给推荐的朋友发个红包，鼓励他们继续复购、继续推荐、继续裂变。
