# 3.1 👸号注册：入口、资料与名额

打开🛰️公众平台官网（mp.weixin.qq.com/），在右上角找到“立即注册”并点击，页面会跳转到注册入口。接着选择“订阅号”，进入后按照页面提示逐项填写资料。

注册之前，需要准备一张身份证和与之配套的银行卡。这套资料用自己的或他人的都可以；若家里可用的身份证不够，也能以公司主体来注册👸号。

名额方面请留意：个人主体可注册1个，个体工商户可注册2个，企业、媒体和单位主体最多可注册50个。

👸号名称与简介的设置会牵涉到👸号SEO。本次航海主要讲如何写出爆款文章，因此这部分先不展开。对大家来说，取一个容易记住、同时贴合自身账号领域的名称和简介即可。
