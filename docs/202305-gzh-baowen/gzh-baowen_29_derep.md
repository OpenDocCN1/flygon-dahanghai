# 4.3.3 剧评怎么写更容易出爆款？公式与案例拆解

想把剧评写成爆款，可以先记住一个基本骨架：标题抓眼，剧情铺陈，观点或解析落到深处，最后收束成结尾。四部分咬合起来，才是一篇完整的剧评。

1）观点型剧评：所有剧情和细节，最后都要落到一个判断上

这类写法不怕写剧情，怕的是剧情写完没有“落点”。你的观点，就是整篇的落点。

比如《知否》这个选题：明兰不知道，顾廷烨和贺弘文求娶她，其实怀着相同的目的。读者一看就会追问：到底是什么目的？

剧情可以这样展开：顾廷烨暗中筹谋求娶明兰。他清楚明兰与贺弘文快要定亲，便有意把贺弘文那位青梅竹马的曹表妹送进京城。事情果然如他所料，曹表妹提出要给贺弘文做妾，贺弘文也动了心，甚至等着明兰退让。两边僵持之际，顾廷烨正式求娶明兰。

观点则落在“适合”二字上。对贺弘文而言，明兰的家世和处事手段都合他的需求；对顾廷烨而言，同样合适，只是他看重的不是门第，而是明兰的品行与能耐。顾廷烨一直记得父亲那句“娶妻娶贤”，而明兰有主见、有办法，也能与继婆婆周旋，各方面都撑得起这段婚姻。

结尾可以把话题推到婚姻本质：婚姻靠的不只是爱情，更是彼此适合。能互相扶持的关系，往往比单靠爱情维系更稳。正如明兰所说，婚姻里未必非要爱情，女人也不该把目光只放在儿女情长上，而应追求经济与精神独立，去看看更大的世界。

这篇内容阅读量3.8W，收益200+。

再换一个反差感强的案例：盛家四个女儿里，墨兰真是嫁得最风光的那个吗？读者自然会疑惑：她用了那么不光彩的手段，怎么反而嫁得最好？

剧情是：墨兰为了攀高门，不顾盛家名声，与永昌伯爵府的公子发生私情，逼得盛家上下替她收拾局面，帮她嫁进梁家。

为什么说“嫁得好”？因为她虽然手段不体面，但嫁入梁家后，丈夫宠爱、婆婆和善，表面上确实符合她对高嫁的期待。

观点就要翻一层：嫁得体面，不等于过得顺心。

细节可以写她明明是正房，却把心思都耗在与妾室争宠上，还主动给丈夫纳妾，家里日日不得安宁。

结尾再收：墨兰原本在四姐妹中嫁得最风光，却把日子过成一地鸡毛；再看另外三个姐妹，无论靠手段还是谋略，都把并不如意的婚姻经营成了自己想要的生活。

这篇阅读量4W+，收益280多。

以上两篇，其实都遵循同一个结构：标题+细节+观点+总结，合起来就是一篇完整剧评。

2）剧情解析型：从明线里挖出暗线和人物命运

除了观点文，也可以单纯解析剧情，从剧情里引申出暗线、人物处境和命运走向。

比如这个标题：《知否》：曹锦绣半敞衣襟求欢，才看懂贺家为何不要明兰。

对应的剧情是：曹锦绣如愿成了表哥贺弘文的妾室，可日子并没有想象中快活。她不过吃喝不愁，其他方面几乎一无所有；贺家祖母时常拿捏她，贺弘文对她也没多少怜惜。她后来借口生病诓骗表哥，才有了主动求欢那一幕。

解析可以往深处走：曹锦绣没明白，自己成了贺家的妾，反而更容易被贺家拿捏。一来妾室地位低，说白了不少丫鬟多少；二来当家主母责罚妾室名正言顺，不必顾全多少情面。

结尾可以这样落：曹锦绣得寸进尺，早把贺弘文心里那点情分和愧疚磨没了。人在选择时当然会衡量利弊，可一旦付出感情却换来欺骗，心也就冷了。

这篇走的是剧情描述+解析+结尾的路子，阅读量10W+，收益800+。

最后提醒一句：别为了抓眼球自己编剧情。这样做很伤账号。
