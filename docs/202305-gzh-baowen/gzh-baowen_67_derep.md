# 7.1.7 检测工具漏判的敏感盲区

有些词，查词平台未必能识别，却同样可能踩线。这类漏网词，只能靠平时对用词的警觉和一次次踩坑来补。

大致可分三类。第一类偏血腥、暴力，例如自残动作“割腕”、身体组织“脑浆”；第二类带旧时代迷信或行业色彩，像当铺、风水，还有占卜与卜卦；第三类偏两性暧昧，比如“妻妹”这类称呼（平台会把“姐夫”标出来）、黑色丝袜（“蕾丝”会被标）、情趣，以及袭胸。它们在平台里往往搜不到，得靠平日留神。

下面这些建议收藏，都是查词工具识别不了的敏感盲区：

1、人设和两性话题：给男女扣“渣”字帽子的说法；“高和富和帅”拼成的称呼，“白和富和美”拼成的称呼；富裕家庭出身的二代标签、官员家庭出身的二代标签，以及男神这一类称呼；再如情侣主题房、互相调情逗趣的说法；试管受孕、代孕。
2、楼市相关：买房时涉及的首付；再说“房子用来住、不该拿来炒”的政策口径；以及鼓吹房价上行的内容，都会被压。
3、金融工具：第三方支付、可透支的信用卡、各类保险、银行储蓄卡。
4、钱生钱类：投资、炒楼、炒股，还有赌钱。
5、贬损类：贬低人格、暗指对方作了不体面的事、指责懒惰、评价价值观不一致。
6、职场词：辞职或离职、内部资料、人事空降、资本投资。
7、公共议题：奥运、防汛抗洪、三孩政策，聊这些时尺度同样卡得严。
8、追热点要克制，不少热点本身就埋雷。内容再积极正向，风向也很难预判，照样可能被限流。没有金V认证兜底，就尽量写稳当的选题，账号才走得远。
9、某生鲜平台的名字里有“叮咚”两字，它本身属于品牌，建议别在文案里单用“叮咚”。
10、只要牵涉到别家应用、商品商标，干脆不写，最稳妥。

说到底，这事没有固定清单，更多依赖个人对用词的警觉，以及踩过坑之后的总结。
