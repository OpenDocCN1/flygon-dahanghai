# 爆文写作，有路可循

多数情况下，正文创作并不是完全从零开始，常见结构早就有章可循，也有现成框架能拿来参照。我们要做的，是按框架找齐材料，再做适度加工和润色。

放到这次航海提到的五大类型里，各自可复用的爆款框架是：

- 情感类：标题先行，交代主角，铺陈故事主体，最后收尾。
- 热点类：标题打头，交代事件概况，亮出态度或观点，再写结尾。
- 剧评类：标题之后写剧情，随后给出观点或解析剧情，最后收尾。
- 法律类：先点地名，摆出冲突，讲述新闻，带出网友看法，解释法律，说明怎么做，再引导互动。
- 历史类：抛出问题，回答问题。

接下来，就按类型拆解五类爆文可复用的模版，帮你写得更快、更顺。
