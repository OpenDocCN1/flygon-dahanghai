# 创作前准备

动手创作之前，咱们得先把视频号备好。下面是注册视频号的具体操作流程：

1. 打开微信，在底部「发现」中进入「视频号」；2. 点击右上角的「人像」图标，就能来到个人主页；3. 在主页里选择「发表视频」，即可进入创建页面；4. 在创建页面里完善头像、性别等资料，同时勾选同意《微信视频号运营规范》与《隐私声明》；5. 如果不希望微信好友看见你发的内容，可以关掉「在个人名片上展示视频号」这个选项；6. 完成以上步骤，账号就注册好了。

另外，强烈建议大家采用多账号运营的模式。单个账号能做的动作和获得的反馈都比较有限，而多备几个视频号，能够提高跑出结果的概率、放大整体收益，最终赚到更多。这一节也整理了多账号运营的相关技巧，供大家参考 ✅解除视频号实名限制的方法✅电话卡推荐✅登录设备的选择✅多个微信号的维护

接下来，还要明确账号的定位，并且围绕定位来包装账号。后续的选品都会以此为基础，所以在定位上多花些时间和心思完全值得，建议给自己留出 2 到 3 天的时间来打磨。

准备好了吗？咱们开始创作前的各项准备吧。
