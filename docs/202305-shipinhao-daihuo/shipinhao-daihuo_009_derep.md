# 1.2.4 视频号：流量入口与成交阵地

把视频号当作一个流量阵地来用，并且直接在这个平台内部完成收钱动作，这就是这套玩法的核心。落地路径并不复杂：直播时卖货可以，在视频号里挂链接也行；卖虚拟产品或者实物商品，都成立。

它的基本逻辑是，先用短视频承接视频号的公域流量，再把人引导到直播间完成转化和成交，发货环节交给供应商一件代发，整个过程依托免费流量，不额外买量。

不过，动手前一定先把自己的商业模式想明白：你是打算借视频号把粉丝沉淀到公众号或微信里，还是仅仅把它当成一个成交场景？这个问题没想清楚就别急着开干。否则，哪怕粉丝涨了不少、播放量也很高，依然可能赚不到钱，那样的结果其实没有多大价值。
