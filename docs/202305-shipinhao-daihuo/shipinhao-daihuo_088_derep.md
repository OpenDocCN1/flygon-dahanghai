# 十、视频号还能这么玩？（选看）

💡  
如果你也想给视频号换点新思路，这期内容可以看看。它属于“选看”部分，时间紧可以跳过，但说不定能帮你打开一扇新窗户。

还在把视频号当成“发视频、做直播”的普通工具吗？其实它已经衍生出不少更丰富的玩法。比如，有人把视频号当企业内训的阵地，把培训内容拍成系列短视频，员工随时能学；有人把它当作新品的“云发布会”现场，靠预约直播、圈层转发，开售前就把氛围烘托起来；也有人把它和公众号、企业微信串在一起，用内容引用户进私域社群，再一步步做转化。

这些玩法不一定人人都适用，但多看几种，至少能跳出“为发而发”的惯性模式。看完后，不妨对照自己的产品或服务，看看有没有哪一条能拿来用。
