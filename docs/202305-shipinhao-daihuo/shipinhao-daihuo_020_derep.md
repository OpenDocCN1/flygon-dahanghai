# 2.3.2 剪辑工具别纠结

手机剪辑用快影、剪映就够了，它们分别对应快手和抖音生态，常规剪辑需求能覆盖。剪映还自带直接输出60帧的能力。

设备方面，我们挑iPhone，是冲着直播稳定性去的；如果只做短视频，千元级安卓机也足以应付拍摄，而且安卓在视频导入导出上同样省心。

别在起步阶段死磕完美，先把作品发出去更重要。一个小道具，从刷到、比价到真正买回来用上，往往会吞掉不少时间和精力。我之前为挑一支在黑板上书写顺手、观感也好的笔，就耗了大半天。

摄影灯、麦克风、服装、场景布置、道具，以及更高级的相机和手机，都属于加分项，后面再补也不迟。起步时，把时间拿去多产出几条内容并发布，投入创作与运营，比折腾装备更划算。

内容来源：《从 0 到 1000 万粉，给短视频创作者的 80 条建议》
