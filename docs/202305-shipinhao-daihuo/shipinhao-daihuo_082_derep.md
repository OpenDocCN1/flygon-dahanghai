# 8.1.4 开播放大收益

当你已经把视频带货的整个流程跑顺，并且拿到了不错的结果，接下来该怎么让收入再上一个台阶？

一个特别值得尝试的高转化操作是：一旦你的视频爆了，只要条件允许，别犹豫，立刻开播。

原因很简单——视频火了之后，用户刷到它时，页面上会直接显示一个醒目的“正在直播”标记，这很容易勾起观众的好奇心，顺手就点进了直播间。从进来到下单，通常只要 3 到 10 秒，就能出一个橱窗订单。整个路径非常短，转化效率自然也非常可观。

至于开播的具体操作方法，我们在后面的第九步里做了简明梳理，同时附上了 11 月视频号直播航海手册，可以直接拿去参考。
