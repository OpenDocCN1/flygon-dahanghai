# 选品有招，测品有法

不管换到哪个平台，选品的底层流程其实相通：抓住核心动作，就能找到适合自己卖的品。挑品之前，先看清用户需求，这一步同样不能省。为了让你更快上手，这里准备了视频号选品攻略和快速选品方法，帮你掌握视频号选品技能，也能迅速进入实操。

产品挑出来之后，怎么判断它是否合适？可以参考高效测品的做法，详见「3.3 如何高效测品」：

✅ 集中测品：同一账号下，每个品类每天发10条视频。
✅ 分布式测品：人群已定、品类或具体产品还没定时，可以同时铺不同品类的视频；哪条起量就继续做，其他撤下。
✅ 暴力测品：直接拿对标视频发布，三天没有播放就换；一旦爆了，立刻转入精细运营。
✅ 带货视频与流量视频：按一定比例搭配发布。
✅ 137法则：重点看账号第1天、第3天、第7天的数据，发现问题就果断放弃该品。

选品做得准，转化才稳。在电商生意里，挑品是最关键的一步。找到适合自己的选品路径后，就去试出第一个适合你售卖的产品吧。
