# 3.1.4 视频号选品：值得关注的品类

在微信视频号里，下面这几类商品都算得上优质之选：

- 图书方向：国学读物、人物传记、低幼绘本等；
- 穿搭方向：大码女装、发饰、脚链等；
- 家居日用方向：房屋防水材料、防水用品、面条机、老花镜、带定时提醒功能的药盒、老年购物车、老人防走失用品、穿针器、拐杖、广场舞音箱、老人收音机等；
- 其他方向：老年手机、多功能护理床。

中老年人群体的可挖掘空间相当大。同时，中老年群体内部的喜好风格并不完全一致，城市用户与农村用户的偏好也会有所差别。
