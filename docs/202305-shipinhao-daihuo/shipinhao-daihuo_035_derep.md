# 3.3.5 137测号法：三天定去留

测账号别靠感觉，盯住三个时间节点，去留会清楚很多。

第1天：播放量能越过300，账号和作品都没有异常表现，就按原来的节奏继续发。

第3天：若播放还能保持在300以上，说明状态没问题，继续推进；如果起不来，可以先替换同赛道对标视频，把旧内容隐藏。也可以发一条窗外风景配背景音乐的轻内容做测试——只要有播放，就说明账号本身正常，真正要补的是去重处理。

第7天：去重这关过了，作品却始终进不了推荐池，就别耗着，直接注销重新起号。

按这套流程一轮轮筛，直到每个账号都能把播放量和成交稳住。

素材参考：《如何高效测品》
