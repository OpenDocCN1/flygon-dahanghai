# 5.3.2 学爆款，做升级版

找到同领域可参考的视频后，重点不是照搬，而是在原有基础上做加法。对方有一个记忆点，你就再叠加一两个；能加得更多当然更好。同时，画面清晰度也值得继续打磨。下面这两个例子，都是拿到平台推荐的作品。

先看第一条：

![](img/d9a5cf63daad0f838b6430da8fdc9bc8.png)

左图是参考对象，右图是我的成片。两条视频的演讲内容其实完全一样，我动手改的是标题和重点呈现。原来的标题占了三行，信息一眼扫不完，用户很可能没耐心就划走了；我把它收成两行，并把“被罚182亿元”放到更醒目的位置。这样观众打开视频，第一眼就能撞上核心信息，更容易被留住。另外，我这条的画质清晰度也明显高于参考版本。

再看第二条：

![](img/062be9e28d1bc1c474b4794d1b5bb502.png)

左图是参考视频，右图是我的版本。原视频用PPT播报“美团被判向饿了么赔偿”的新闻，我看完觉得刺激点还不够，于是围绕美团继续找素材，最后选中了“外卖小哥三问美团创始人王兴”。这段内容讲的是骑手配送时效、超时赔付等行业痛点，天然容易在评论区引发讨论，也就更有机会被平台推荐。后来这条视频确实拿到了推荐。

有位小伙伴跟我说，他以前刷到过“外卖小哥三问王兴”，没想到还能这样用。没错，素材可以嫁接，效果就是这么奇妙。
