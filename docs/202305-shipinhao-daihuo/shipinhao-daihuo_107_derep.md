# 11.4 视频剪辑：工具与去重清单

做视频剪辑，选对工具能省不少事；把去重思路提前弄明白，后面操作也会更顺。下面这份清单建议收藏，按需取用。

批量去重方面，有一款工具支持批量处理并去重：前99条免费，包月费用为39元。网盘内可以直接下载，官网入口：http://www.cr-soft.net/crvideomate.html（CR VideoMate - CR-部落）。

剪辑工具按设备来分：电脑端可用剪映PC版、PR、AE、Final Cut，其中Final Cut操作相对容易些；手机端则有剪映、快影、秒剪（视频号官方出品）、字说（可生成文字弹幕）、来画动画（能把PPT转成视频）。

字幕处理可以试试网易见外、突字幕、蜜蜂剪辑，以及用Arctime进行视频字幕压制。

特别提醒：去重逻辑需要先理解、学习，属于必读内容。可参考去重技术从一级到五级的分级说明（知乎）：https://zhuanlan.zhihu.com/p/353343261；防搬运实操技巧（抖音视频）：https://www.douyin.com/video/7038496081491086623；短视频打法与爆量素材策略回顾（公众号文章）：https://mp.weixin.qq.com/s/QTiWdOK1oz3DEv8iRAVHGw。
