# 9.1 爆款视频后，直播怎么接？

具体开播方法可参考11月版视频号直播航海手册（即《11月航海 | 视频号直播带货 | 实战手册》），这里不再重复梳理已有内容。

但有一点要提前明确：开播的前提通常是短视频已经跑出爆款，此时最关键的是接住流量、尽快转化。多数进入直播间的用户本就带着下单意愿，因此不必用预热、憋单、福利等方式拖时长，直接告诉他们怎么下单、及时回应产品疑问就够了。

还有一点要记住：一旦出现爆款视频，就算暂时达不到手册描述的直播间标准，也应当尽早开播。此时流量承接和转化优先于场景精致度，直播间可以朴素一些、话术可以简单一些，后续再慢慢优化。

翻阅航海手册时，不必一开始就通读，先挑关键部分学；如果之后要长期做直播带货，再把完整流程补齐。下面已标出优先看的位置，方便定位。

从短视频爆款出现后启动直播，主要分为四步：

✅第一步：布置直播场景，重点翻阅手册第四步“搭建视频号直播间”。

✅第二步：备好内容与货品并正式开播，重点看手册5.2“开启直播”。

✅第三步：推动直播成交并持续调优，重点看手册5.3“如何实现直播间成单”以及第七步“直播间优化与成单技巧”。

✅第四步：做好数据归纳与复盘，重点看手册第八步“数据整理与复盘”。

也建议你提前熟悉直播流程、做好准备工作。爆款往往来得猝不及防，没人能准确预判哪条视频会起量；而在那之前，持续坚持和不断优化仍然是必要功课。

另外，若你用他人账号进行视频号直播，第二次开播认证现在只需输入🛰️支付密码，不再需要人脸识别，操作比过去更省事。
