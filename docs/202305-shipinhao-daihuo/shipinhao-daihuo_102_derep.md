# 10.1.4.6 冷启动，先做对这两步

视频号刚起步时，冷启动大致有两条路可走。

第一条是借私域：请熟人帮忙转发、点赞，或者在群里互相点赞，也可以发个红包表示感谢。第二条是拼内容：把内容本身打磨到位，让系统识别到价值，从而进入推荐池。

推荐机制也值得弄明白：初期平台一般会先给一波随机推荐，算是鼓励；至于能不能起量，关键看观众是否喜欢。反馈好，推荐会继续；反馈差，流量也可能突然停住。另外，靠社交推荐先火起来的内容，还有机会再次获得推荐——原因很现实，视频号目前仍然很缺内容。

至于刷数据，这类操作效果有限，不建议尝试。

内容来源：《视频号 30 天佣金 4W，一个普通人的从 0 到 1》
