# 3.1.3 视频号快速选品方法

3.1.3 视频号选品，四步挑出潜力款

想试水视频号视频带货，又觉得选品流程太绕？不妨先按下面这套比较稳妥的路径走一遍，单靠这一种方法也能把货选出来。

第一步，到视频号直播广场的购物分类里找直播间。目标不是那些一眼看上去训练有素的机构账号，而是像普通素人自己在运营、但观看人次已经超过500的直播间。判断“不太专业”可以看几个信号：头像和封面用的是同一张图；画面里没有商品样品，直播环境跟所卖商品明显不搭；主播也较少与观众互动。为什么要盯500以上？因为这意味着流量已经起来了，通常有两种可能：系统给了推荐，或者短视频那边导来了人。

第二步，翻一翻这个账号发过的短视频。把表现突出的内容挑出来——点赞超过100的就算爆款——再看它挂的是什么商品。这样的品很可能具备潜力。

第三步，去数据平台核对这个品的数据是否拿得出手。重点看销量和参与带货的达人数量，同时留意别扎进竞争过度的红海类目。常用的查询入口有精选联盟和考古加：考古加更新更快、使用门槛低；精选联盟则会受粉丝、小店、保证金等条件限制。

第四步，从该视频关联的达人和带货视频中，找出适合参考的对象。优先看粉丝量在数百万以下、月销售额达到10万元以上的达人：前者不容易和太多人撞车，后者说明变现能力不差。接着从他们的视频里挑可借鉴的素材，再到视频号搜相关关键词，确认要用的内容有没有被大量跟风，尽量避开已经被盯上的视频。

按这几步筛下来，基本能选出合适的商品，也能顺带把视频内容方向初步定下来。
