# 2.1.2 先开两个号，跑通视频带货 @航海手册

1、起步阶段，先把两个视频号开起来

在视频号带货这件事上，我先说一个观察：圈里能做到月入过万的，大多手里不止一个号，十个以上很常见。

不过，刚接触这个项目的人没必要一上来就铺十个。把难度降下来，先从2个视频号起步，借这两个号学会搭自己的带货账号布局。等流程跑熟、精力还够，再继续加号，把结果放大。

2、个人多开视频号，可以这样操作

先看规则：每开一个视频号，都要配一个完成实名认证的微信号。同一张身份证最多能实名5个微信号，所以按常规路径，一个人理论上最多开5个视频号。

破解思路是：办手机卡的人和微信实名的人，允许不是同一位。

举个例子，你用自己身份证办10张电话卡，其中5张用来给自己注册实名微信，余下5张交给家人，由他们完成实名认证，再拿去开视频号。

这里要特别注意：用谁的实名微信，带货佣金最后就进那个微信钱包。所以一定要选信得过的亲友。

电话卡方面，可以按自己的情况挑：
- 三大运营商均有副卡业务。以一个人实名5个微信来算，可做一拖四，副号月租约10元；
- 移动万能副卡：每张月租10元；同一身份证可办2张；两张的办理时间要间隔90天；营业厅和App都能下单，营业厅还能争取首年月租减免；
- 中国电信App里搜“无忧卡”，月费5元，通常第二天就上门配送；
- 移动还有8元保号套餐。

设备不用太讲究。纯视频带货对手机配置要求不高，几百元的机器就能用；家里闲置旧手机、网上淘的低价工作机，甚至向亲友借旧手机都行。建议选小米、华为、vivo、OPPO；不建议苹果和一加，后者无法双开。

操作上，通过应用双开，一台手机登两个微信，5个视频号用3台手机就能运转。也可以把每个视频号的运营者绑到自己的大号微信上，再用网页版逐个登录操作。

但多个视频号若都绑同一个微信号做运营者，这个微信号同一时间只能登一个视频号。例如A同时绑定B和C，扫码登B后再登C，B会自动退出，想再登B得重新扫码。

3、批量微信号怎么养更稳

批量注册出来的微信号很容易被封，养号的关键是让操作看起来像真人在用。具体可以参考这5个办法：
- 把头像、昵称、背景墙等基础资料补齐；
- 改一下微信号、登录密码和支付密码，零钱包里放几块钱；
- 每天发2～3条朋友圈，内容长短不限；
- 随手加5～10个好友，每天发几条消息；
- 每天在视频号里刷视频、看直播。
