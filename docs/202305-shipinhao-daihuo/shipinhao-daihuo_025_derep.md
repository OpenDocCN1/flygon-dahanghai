# 3.1.2 视频号卖货，先搞懂这群人 @麦洛

做视频号别急着选品，先问问自己：我到底为谁服务？比如你打算服务常做饭的宝妈，那就把自己代入她们的日常——她们在厨房里忙碌什么，为孩子的一日三餐操心什么，还有哪些需求没被满足。把场景拆开、把需求列出来，再去填充商品，很多别人还没发现的品，就是这样被挖出来的。

**先说喜好。** 年轻人追捧的东西，放到视频号里大概率卖不动。像索尼游戏机、Supreme T恤，在年轻圈子里再火，视频号的用户也未必买账，所以这类品可以直接跳过。自己不喜欢的品，也未必非得硬做。比如某本书在抖音销量很高，但你连相关的视频都不爱看，那放弃也没问题。倒是父辈喜欢的那些事，或许可以多留心：老爸爱钓鱼，阿姨们爱跳广场舞、逛服装店，围绕这些场景找品，是不是就有方向了？

**再说经验。** 经验不一定都对，但值得拿来参考。2021年抖音百货卖得火热，放到视频号却几乎起不来；2022年初抖音快手的绿植生意已经卷到不行，视频号反而还有不错的收益。再比如，以前在淘宝做蓝海，看到娃娃鱼类目放开，一家又一家商家做起来，那这个玩法能不能在视频号再试一次？又或者，你在春熙路看到100家火锅店，那火锅底料是不是也能做？

别小看这些过往的经验和经历，它们都是你的财富。闭上眼睛想一想，机会可能就在里面。
