# 别追风口，先把你踩过的坑做成课

混迹赚钱社区的人，多半不满足于只收回入场券，或者顺手挣点零用。七位数是个不算离谱、又值得认真冲一把的台阶。

做付费课程，是很适合起步的切口：启动资金接近于零，后续维护轻，规模容易放大，成交能自动跑，录一次可以反复卖。内容付费市场也在升温，虽然还远没到北美成熟盘子的体量——那边一年能做到数千亿刀规模——但愿意为经验掏钱的人确实越来越多。

难处自然躲不开，而且跟别的商品一样：卖不动怎么办。这个先按下不表；在琢磨销量前，先问自己能不能把课立起来。

前一年，我在帖子里聊过一段经历：进社区两年，被反复点燃、启发，也一直学习琢磨，腿都拍青了。项目试了不少，方向没摸到，钱也没见着，焦虑得开始否定生活意义，干脆把星球应用卸了。后来创始人龙哥和左晖（已故）把我敲醒，治好了我的“追热点成瘾”。我选了条不容易但值得坚持的路——在线课程。

中间本来想做些分享，结果十月意外受伤，进了重症监护室；等完全恢复已是年底。之后一直忙课程，没空也没静下心来写。现在总算弄出来了，今天就说说这段时间的体会，顺带推荐些资源，也给想了解视频课的朋友聊聊踩过的坑。

做课期间，我又添了种新毛病：冒名顶替综合征，说白了就是总觉得我这点经验拿不出手。备内容、剪课程、看市场时，越看越觉得高手遍地，甚至有人免费分享。谁犯傻才会为我的课掏钱？

这毛病不止讲课的人有，无论做哪类商品，都可能中招。担心未必空穴来风，关键是拆开看：到底哪儿底气不足。

最初我盯上少儿理财教育，还按长女的长处设计了两套练习，她当时兴致很高。我判断方向有需求：早先连续五十天拍短视频，在多平台拆解社区日历里的例子，主线是教女儿挣钱、让她二十岁前攒到七位数；没有任何基础，从零开跑，某视频平台日曝光能到数万，很快聚来几百关注，私信问问题的人不少。我太太也从某短视频应用买过几本给孩子补金钱观的书，噱头吹上天，内容却糟糕；但这至少说明，家长肯为这类东西付费。

可长女的项目没撑几天就搁浅。我靠社区里的例子和我个人的摸索，录过几段内容；说着说着，自己先觉得站不住。亲闺女都没带出来，难道去当那种卖书骗子？现在回看，当时发虚是对的。价值观还端正的人，并非每笔钱都该挣。

某国际课程平台上，一位国内卖家专挑热门拼课，从短视频一路讲到数字藏品，开了几十门，差评一片却卖出六位数销量。听着都替同胞脸红；换我干，肯定过不了心里那关。

主题该怎么定，才不至于底气不足？

对我冲击最大的是桑妮·莱纳杜齐。这位来自枫叶国的博主既好看又坦诚，频道很值得翻。她的选题思路是：先别盘算市场，只挑自己走过的巨大变化——从低谷走到高光。某件事曾长期折磨你，你花大量精力钻研、学习，最后摸出门道，那它就有分享价值，也大概率能帮到别人。

她两位学生的故事很戳我。其一是德国姑娘，小时候跳舞总踩不上点，聚会时总往后缩，慢慢变得自卑；后来她琢磨出一套好上手的舞步，能在社交场合从容起来，又把这套成人舞步做成课，卖得火爆，每月进账约五万美刀。其二是一位美国小伙，双亲分开留下心结，夫妻关系也亮红灯；他翻了很多资料，整理出一套交流修复法，不光救回婚姻，还把方法做成课程，一年做到七位数美元，压过不少情感博主。

还有用饮食调理痘痘的，每月三万多；教人做手工木船的，也能月入一万多。领域五花八门，共同点却清楚：都先被某个难点折腾过，再埋头研究，最后拿出可执行的方案。因为讲的是我真正趟过的路，所以不虚，也敢把价格往上提。

看完这些，我脑子一下打开，决定重新定题。有一年盛夏，我的英文听力忽然通了，到了不靠字幕、听进去就懂的程度。原本没想拿它做课，因为那时满脑子都是少儿理财：觉得受众广、离钱近、需求硬。桑妮的内容让我反应过来，这才是我该讲的方向。于是花了不少时间研究语言学习规律，再结合个人经历，整理出一套能照着做的办法。

然后，我住进了医院……

能坐起来后，躺在病房里闲得发慌，就把方法讲给两位朋友听。有一位四个来月后也通了关，回音都不错。信心涨了，我动手录课程。开机以后，老毛病又冒头——这回不怀疑内容，改成怀疑画面里的我。

对着录制设备开口，确实不轻松。心里明明排好了，一按录制键就脑门出汗、眼神发直、嗓子发干，词全忘了。看录像时忍不住嘀咕：表情太僵、语气太木、呼吸都不稳，还怎么教人？

第二版我躲开画面，只做屏幕录制。可没有脸分散注意，声音的毛病被放大：老家的口音也显得扎耳、不够体面。更要命的是，画面只剩幻灯片，很难让买家产生信任和亲近。

第三版又露脸：屏幕加角落小头像。很快我又嫌小头像抢戏，画质也糊，眼睛还盯着显示器，缺少跟看的人互动的感觉。总之，左调右调都不顺。

接着就是拖。总想把状态调到最好，一遍遍重来，似乎有长进，转眼又挑出刺；打着对买家、对自己负责的旗号，改个没完。其实心里清楚，这是怕扑街：怕上线后被人嘲笑——就这表现，也配收钱？

不少同行给冒名顶替心态开的方子是：定个最后期限，时间一到就发布，别追求满分。我觉得有几分道理，先把期限放在二月二十二，后来挪到三月十八，再改四月二十八，最后拍板六月二十八……可主动定限期，与上司下死命令完全两回事；对多数人来说，这招并不灵。

做课那阵子，我翻过不少教程，也买过珍妮·布莱克威尔的课。她人漂亮，气场也强，我差点迷上；可惜我住院那段时间她被癌症带走。她说过，自己经手过百余门课程、带学生做过几千门，没有任何一门在发布前能靠单人打磨到完美；只能也必须借买家回音继续修。人虽不在了，她留存的内容还在，想做课的人值得找来。

道理都懂，也能接受，可心理那道坎很难迈。问题是，课程上线后若没人搭理，一个买家都招不来，又哪来回音？还完善什么？

所以这毛病，我一度觉得没药可救。直到碰上另一位女性——她还健在。

她叫莱拉·霍尔莫齐。这回没动心：人长得不错，说话却偏糙，不合我口味。我真正欣赏的是她先生……后面再讲。

无意间刷到她讲白手起家做到七位数的课。核心是能力层级理论：学任何技能，从新手到高手，要过四道关。

第一关：你还没意识到自己差在哪，也看不懂别人为何行，却认定别人能做到，我同样可以。刚进社区时我就这样，觉得将来挣的会比创办人龙哥和那些大神加总还多。

屡败之后，人会滑到第二关：承认自己暂时不够。我是在某个春季走到这儿的。那阵子焦虑得情绪低落，才看清：龙哥比我年轻二十岁，却真有两把刷子，而我确实差得远。从那以后，我把他当成传法师父。他没单独教过我，却始终拿行动兑现理念，借社区这个场，从具体打法入手，说到也做到地讲赚钱之道，整个人有股亮堂的能量。每次看到线下会颁奖照，我都又敬又喜。我常幻想哪天当面对他说：我总想当社区银发组的带头人，这回总算……哈哈，打住，回到四关。

到了第二关，有些人会彻底躺平。既然认了自己暂时不够，就别折腾创业做生意，找份班上，下班后就追剧、打电动、喝两杯，图个安稳；也算想开了：父母、自己、孩子都是凡人。还有不少不甘心的人，像我。人到五十，常被劝要认命；我却觉得，五十岁更该弄明白老天交给我的任务。我不肯认老，想精神抖擞地给俩闺女做榜样。既然差得远，就研究怎么补：多看行家怎么干，缺什么补什么。

随后进入第三关：看懂别人为何成，也明白自己该怎么走；动手、学习，渐渐就能成，而且心里清楚确实吃透了。再往后是第四关：靠手感也能干成，反而察觉不到自己厉害。比如龙哥这种人物，从不自认高手，总说也就是个凡人，像那位提出相对论的科学家一样自谦。又扯远了，一提他就收不住……回到莱拉。

莱拉那套算法很直接：白手起家做到七位数，并不玄乎，只要单品、单类买家、单条渠道。单价一万，就找一百个人成交；单价一百，就卖出一万份。先有货，再找到足够多愿意掏钱的人，凑够数就行。具体操作社区里大神讲得够多，我不展开。

这番逻辑，我闯到第三关时也悟了：买卖做到最后是算数。不会人人都下单，但总有人会；任务就是，把肯掏钱的人找出来。

她还有一句狠话：创业成功率只有一成，而从未落地的点子成功率是零；关键动作，就是先把它干起来。不卖，成算为零；卖了，也才一成机会。那还犹豫什么？先开卖。

单靠这碗鸡汤，我就痊愈？想多了，我没那么容易被一句话打发。

莱拉讲的确实有分量。我判断自己已经越过第二关，因为想透了一些根上的事：心态从“到处挖宝”换成了“动手盖楼”。前两关时，我以为富足人生靠两张图：一张寻宝地图，一张路径表。我过去总在找社区的密码、诀窍，估计不少同路人也在找。可真正缺的是另两张：一张成品愿景图，一张落地工序图。

营生是要盖起来的。先有愿景，也就是成品长什么样：你想建学校还是商场？放在城乡接合部，还是落到纽约或狮城？得先在脑中成形。再往后要有计划，也就是工序：夯基础、搭骨架、铺地面、做外墙、装门窗，一点点把摊子搭成型。京东创始人要是没在北京海淀的电子卖场租柜台，阿里创始人要是没碰企业黄页，只天天跟着别人学消息落差、认知落差，后来也不会有京东与淘宝。课程上线后，可能像阿里早年黄页那样推翻再搭，也可能像京东那位刘先生的柜台那样越垒越高。但总得先搭第一块板。

这些前辈所做的事，前人没干过吗？显然不是。只你有、旁人全无的竞争空白，根本找不到。做得大的人，往往你有，我也有，甚至我标价更高，顾客仍愿意选我。为什么？因为买得舒服。货很难独家，购买过程却可以独家。

营生的底子说穿了不绕：手里有货，别人肯掏钱，就完了。可成交与否，不取决于货本身，而取决于交易提案（offer）——它让货显得与众不同、更能打。这话来自莱拉的先生。

她视频里提到先生，我一搜，发现是位厉害角色：亚历克斯·霍尔莫齐。他先经营健身房，后来摸出一套很接地的经营法，把不少健身场馆救活。早年他做企业咨询，拿工时换收入；方案不差，却难放大。直到转成课程，才真正起来。这人块头大、说话直，不是我喜欢他的原因；真正原因是他在自家网站 acquisition.com 做了个拆解交易提案的教程，正好解了我的结。他的内容我强烈建议找来看：语速快是缺点，干货密度高，而且不要钱。

他教我的关键点：追求完美没有错，课程不能草率开卖，必须打磨。但该完美的是交易提案，不是我在画面中的表现。撇开本人不谈，没人那么在意我讲得顺不顺。买家最上心的，甚至不是内容，而是自己能否拿到结果。课程最该下功夫的地方有三处：体验要独特，结果要兜住，尽量替买家兜底。

于是我把收费方式整个改了：全部方法免费公开，课程压缩到一小时讲完，不占别人时间。市面上有些课云里雾里，几百段视频刷下来，似乎什么都说了，又似乎什么都没说。训练营改成每日一任务，小步推进，避免一次塞太多；练习材料只围绕赚钱话题，让买家一边琢磨怎么多挣，一边把英文提上去，体验更特别。我还承诺三十天内不满意可退、一年没效果学费全退。

实际效果？还未知，哈哈，今天刚开卖，究竟是早年黄页式翻车，还是柜台式垒高，只能看后续。但该较真的地方，我尽量较真了；更重要的是，它终于对外开卖。

所以，要是你越过第二关，真想搭起营生，我建议试试课程。想想哪段经历让你从泥坑走到舞台。如果暂时没有，那就挑某个仍缠着你的难点，先把它解决，再把过程整理成课。

要是嫌这太折腾，成败又没准，想找更省力、更贴合大众、还能保证挣钱的路子——以我半辈子阅历讲：真没有。那种美事只在四处出现，龙哥在前一年的帖子里总结过。一个寻常人做社区，意义不就在于让更多寻常人变得不寻常吗？
