# 怎么找出好卖的二手书？

账号打理妥当之后，就要考虑上架二手书了。做无货源模式，最让人头疼的是：书从哪里来？哪些书更好卖？

其实不用愁，本章给出三条路子，帮你锁定畅销书范围：

- 参考孔夫子网的畅销榜单
- 参考淘宝大店的销量排名
- 对标闲鱼上的同行卖家

同时，选品时要避开违禁书，免得账号出问题；发货前也要留意书本品相，减少售后麻烦。

接下来就照着这三类方法，去确定要上架的书目吧。

![](img/ab7dc6b1e88a35f9e4a63d42b13ad5e2.png)

闲鱼上架二手书，一个账号最多只能挂500个商品，而书籍的种类多到上千万，SKU过于庞大。所以在闲鱼上，合适的玩法就是做爆款，也就是挑畅销书来卖。畅销书的信息，主要来自淘宝大店的销量排行，以及孔夫子网的销量排行等。
