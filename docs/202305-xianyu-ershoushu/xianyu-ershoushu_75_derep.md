# 二手书四个方向，哪个更容易跑通？

这是本系列的最后一章。我们请圈友@老瞿 Qu 梳理了几条当前比较常见、也相对容易落地的二手书细分路线，包括高校教材、小说与文学类，少儿期刊杂志，激活码，以及热销套装书。本章会围绕这几个方向做简要拆解，并配上案例展示，期待这四个案例能为正在寻找切入点的你提供一些参考。

![](img/ab7dc6b1e88a35f9e4a63d42b13ad5e2.png)

结合不少实际操盘经验来看，闲鱼上二手书成交更旺的品类主要集中在高校教材、文学读物和小说。教材类有明显的时间规律：开学阶段需求集中，属于旺季；开学季结束之后，到期末考试季来临之前，行情会相对平淡。小说与文学书的销售则更为平稳，全年起伏不大。除此之外，少儿类期刊杂志、激活码、热销套装书，也都是二手书业务值得尝试的延伸方向。
