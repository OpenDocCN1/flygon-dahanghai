# 5.3.2 闲鱼封号雷区：四个坑别踩

在闲鱼做生意，出单固然重要，但账号稳不稳才是前提。下面四类动作，看着平常，却很容易把账号推到封禁边缘。

- 选品踩进平台禁售区。上架市场明令禁止的商品，风险直接拉满。
- 登录方式太随意。一部手机同时挂多个账号，或在同一台手机上频繁切换账号，都可能被系统盯上。
- 客服沟通触发敏感词。聊天中出现“转账多次”“一单一结”“皇”“🛰️”“联系”“加”“原味”等词，或者同一句话反复发送，都可能引发风控；不少词平时不留神，恰恰容易出问题。
- 售后纠纷堆积。退款、扯皮太多，商家多次拒绝后，买家直接申请小二介入，账号风险自然上升。
