# 8.3 激活码：这桩小生意，闷声月入六位数

别小看一张小小的激活码，在淘宝上，把它做出规模的店铺，每月利润能做到10万以上。如今闲鱼上的个人卖家也纷纷入场，有人把它和二手书搭着卖，也有人干脆专职就卖激活码。

这门生意到底怎么玩？核心前提只有一个——能拿到足够便宜的货源。只要货源稳定，激活码就是典型的虚拟商品，不需要快递，不用打包，连售后都几乎为零。买家拍下后，系统秒发货，对方转眼就能确认收货、顺手给个好评，整个流程轻松到不像是做生意。
