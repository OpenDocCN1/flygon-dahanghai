# 5.2.1.2 闲鱼售后高频问答 @老瞿 Qu

闲鱼成交后，售后咨询通常绕不开物流、破损、退款和平台卡片这几类。下面把常见情形和回复思路整理出来，沟通时可直接参考。

**买家问：物流怎么一直没更新？是不是还没发货？**
回复：仓库这边正在做发出前的准备，包括出库、核对版本与封面、打包，会尽快安排寄出。若遇到品相不达标或版本不符而暂时无法发货，我们会第一时间通知您。

**买家问：快递怎么还没送到？**
回复：亲，不同网点的配送时效会有差异，麻烦您再耐心等等。若超过三天仍没有物流动静，麻烦留言告诉我，我会在看到后立刻向快递公司核实。

**买家反馈空包、破损、无法使用，甚至直接给了差评**
回复：亲，请把快递外包装和书籍一起拍照发我；如果方便拒收，尽量先拒收。我们会核查是出库时没有检查出来，还是运输途中造成破损，并尽快给出让您满意的处理方案。

**买家问：不想要了，可以退货退款吗？**
回复：亲，若您还没收到包裹，需要承担发货运费。二手书售价本来就不高，运费却经常超过书款，所以建议您申请退款时把运费扣除，包裹直接拒收；我们收到退件后会尽快给您退款，谢谢理解。若包裹已经签收，也支持7天无理由退货，只是运费需由您承担。

**买家问：包裹里怎么有拼多多卡片？**
处理方式：到平台商家下单时，可以提前备注：帮朋友买的，别放价格单，也别发短信，谢谢。同时尽量避开拼多多渠道找货源。
回复：我们经营的平台不止一个，那边同样有店，估计是新同事贴错了标签，实在抱歉，已经提醒处理。产品本身您可以放心，质量没问题。
万一您发现拼多多上的价格更低，我们补差价就行。这种情况概率很低，一千单里也就几单，毕竟大家更在意产品本身，而不是下单平台。

上面这些，就是闲鱼售后中最常碰到的情形和应对方式。其他具体问题，欢迎在航海里一起交流～
