# 4.3 闲鱼上架实操要点 @老瞿 Qu

在闲鱼上发布商品，操作细节往往决定流量和成交。这里有几个值得留意的地方：

- 品牌词尽量别露头：标题和文案中不要出现品牌名，商品配图里也最好别展示明显标识，能规避就规避。
- 站外引导词要排除：像“无添加”、“联系”、“微信”这类容易触发平台风控的词，千万别编进标题或描述里。
- 发布地可以选择高校密集的城市，这类区域的用户活跃度通常更高。
- 上架时间有讲究：首选早上8点前后，其次是晚上8点前后，如果实在没空，中午11点半左右也凑合，但效果相对弱一些。
- 单日发布数量控制在20到30个链接，不贪多，稳扎稳打。
