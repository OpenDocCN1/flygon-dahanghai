# 14.1 让AI帮你装点家

AI绘画走进家居陈设场景后，能输出的内容远不止一种：硬包、软包的效果图都能做，室内装潢渲染图、装饰效果图、装饰挂画以及家具效果图也都在能力范围内。

它的长处主要有三点：

- 用作渲染图或宣传图时，AI作品往往风格新鲜、配色与构图别具一格，能给空间制造意外之喜和强烈视觉印象；
- 跟手工艺术品或名家画作相比，AI艺术品的花费更容易被普通家庭接受，让更多人能用艺术品为住处添彩；
- 若拿来做装饰画，打印环节也很高效。

不过，AI绘画也不是万能的：它给不出完整的尺寸、色号、品牌等落地所需信息，实际施工或采购时仍会卡壳。
