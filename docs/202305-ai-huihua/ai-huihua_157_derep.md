# 12.1 AI定制品牌周边：机会与边界

商品个性化定制的覆盖面很广，手机壳印花、帆布袋、马克杯、DIY多功能卡套、钥匙扣等，都能纳入其中。下面以品牌衍生品为切入口，看看人工智能绘图如何介入定制商品的设计环节。

它带来的价值主要有：让产品更具新鲜感；更贴合消费者的个性诉求；缩短上新周期——模型能在很短时间内产出大量设计草案，设计师据此筛选、打样，新品开发和推向市场的节奏随之加快，也更容易踩中潮流、抢占市场；压低研发开支——自动产出方案可减少人工绘制初稿的投入，从而控制新品研发成本；点燃创意火花；放大品牌传播声量——新奇有趣的品牌衍生品更容易在社交平台被转发，借助消费者的“新奇效应”快速形成话题，提升品牌在社交渠道的扩散力；提升产出效率。

与此同时，边界也很清楚：一是品牌辨识度不够，模型很难完整吸收品牌的视觉语言与调性，产出的方案可能缺少识别度，不利于建立品牌印象，需要设计师再做二次加工，比如用PS调整版式、整理图层；二是出图品质不稳定；三是版权风险，机器生成的画面可能侵害他人著作权；四是创意容易受限，生成结果受训练数据分布影响，类型可能偏单一，难以跳出既有设计范式做出真正颠覆性的设计，需要人工以设计思维（design thinking）来推动；五是文化表达较薄，机器画面天然缺少人工设计那种丰厚的文化意涵，不容易传递品牌理念与情感，仍需设计师创作演绎；六是依赖数据资源，模型训练离不开大规模数据集，数据质量与数量都会左右最终效果；七是审美判断不足，系统很难真正完成审美判断与把控，需要人工美术与审美设计介入。
