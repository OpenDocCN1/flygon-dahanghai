# 15.3 美甲关键词速查

先把这套组合思路捋一遍：核心对象锁定“美甲”，再依次补上美甲类型、主体设定、风格、色调，最后用质量词收尾。按这个顺序组织提示词，想要的美甲效果会更容易被准确表达出来。

轮廓类型可以选 square（方形）、circular（圆形）、pointed（尖形）、elliptical（椭圆）、long pointed（长尖）、lipstick（口红形）、ballet（芭蕾形）等。

点缀主体方面，Sequins（亮片）、Luminescence（发光）、Pearlescence（珠光）、High tech Holography（高科技全息）等都可以加入。

风格方向的选择也很丰富：Baroque（巴洛克）、Rococo（洛可可）、fantastic（奇异幻想）等艺术路线；Spring Festival（新春）、Christmas（圣诞）等节日主题；simple（简约）、complex（复杂）、luxury（奢华）、XX 品牌等风格；以及 diamond jewelry（钻石珠宝）、animals（动物）、Disney（迪士尼）等主题都能用。

配色可以挑 Single color（单色）、mixed color（混色）、multi color（多色）、Morandi color（莫兰迪色）等。

最后别忘了补上质量词，让整体描述更完整。
