# 5.7.3.8 启动训练

打开 LoRA 目录，在空白处按住 Shift 并右键，选择“在此处打开 PowerShell 窗口”，输入 `.\train.ps1` 回车即可开始。

训练过程会自动进行，你只需要稍作等候，无需额外操作：

![](img/c62cef6ed57e2aba5cb8e1cd7b81435e.png)

![](img/039b30c2485404c4af184e1f30b34ff3.png)

训练结束后，模型的生成结果存放在 LoRA 目录下的 output 子文件夹里，直接打开即可查看：

![](img/ec1fcba487451e79f7d2862a745916d5.png)
