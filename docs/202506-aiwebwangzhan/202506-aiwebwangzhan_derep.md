# 2.1 拆解一个网站的三大件

# 2.1.1 域名：门牌号是什么，去哪儿挑？@彩笺

常听人说“做个网站”，实际上他指的往往就是域名。baidu.com 就是百度的域名，也就是用户找到你的那个入口。想想看，别人得先知道你家住址才找得到门。域名就是那个独一无二的门牌号，全球只有一个你，别人凭这个名字就能摸过来。

购买的话，我建议走 Cloudflare。市面上卖域名的商家很多，但对开发者来说，Cloudflare 的配套最顺手。域名这笔钱不用急着花，等网站做出来再买也不迟。

# 2.1.2 服务器：代码住在哪、哪里能免费托管

代码需要一个安身之所，这台“房子”就是服务器。有门牌号还不够，总得有地方住。好在现在免费托管服务不少，Vercel、Cloudflare、Netlify 都能让你不花一分钱把代码挂到网上。

这些平台的操作流程大同小异：先注册账号；接着上传站点文件，或者直接关联 GitHub 仓库；一键部署，访问链接就到手；手里有自定义域名的话，再去后台绑定一下。

# 2.1.3 代码：网站的灵魂，静态和动态差在哪

网站的面貌和交互方式，全部由代码主宰。你可以把代码想象成菜谱，最终端上桌的菜好不好吃，就看它。

静态网页的典型特征是“千人一面”——所有访客看到的都是同一份内容，像印好的报纸。好在速度快、风险低、部署省事、花费也少，博客、个人作品集、公司官网这类场景够用了。

动态网页则像聊天软件，内容会随着用户的操作、登录状态实时变化。登录、评论、购物车这类功能它都能撑起来，代价是需要数据库和后端配合，开发量更大。电商平台、社交网站这类依赖用户体系的场景，基本离不开它。

初学阶段建议直接从静态站起步，等流程跑顺了，再逐步加动态能力。

# 2.2 编程语言速通：零基础友好版

# 2.2.1 HTML / CSS / JavaScript：零基础该认哪些关键概念？

把网页比作一个人的话，HTML 是骨架，标题、段落、图片、链接、按钮都由它来定义，常用概念有标签、属性和嵌套；CSS 负责打扮，排版、配色、字号、字体都由它调配，选择器、属性、值是它的基本词汇；JavaScript 则像神经系统，让页面能响应点击、校验表单、播放动画，真正“活”起来。

# 2.2.2 前端和后端，两句话分清

前端是用户看得见摸得着的那部分：布局、视觉、交互都归它管，主力语言是 HTML、CSS、JavaScript，好比餐厅的门面和菜单。后端在服务器上默默干活：数据存储、用户认证、业务逻辑都由它承担，常见语言有 PHP、Python、Node.js 等，相当于餐厅的后厨和库房。

# 2.3 AI 工具，怎么选怎么用

别把 AI 工具当成主角。我自己的做法一直被模仿：用 Claude 的共享账号，理由很简单——单独订阅太费钱，用得不多还可能封号，也免去了各种安装步骤。再说我经常要问的并不只是代码，而 Cursor / Windsurf 这些工具更偏向纯编程场景。

工具装在那吃灰也没关系，等你亲眼看到自己的网站跑起来，就会忍不住常去打开它、优化它，甚至接着开新站。

自己注册有困难，去淘宝买共享或独享成品号也完全可行。从哪弄到账号无关紧要，真正要紧的是尽早用上这个地球上性价比最高、也最聪明的 AI 大脑。

# 2.3.3 更多工具选项：bolt.new、trickle.so、GitHub Copilot……

一句话区分：bolt.new 是零代码新人的福音，支持自动部署、即时预览，可惜不支持版本回退；trickle.so 功能相近，但内置了一堆模板；GitHub Copilot 则面向在 IDE 里写代码的程序员。

注意 bolt.new 和 trickle.so 的后缀比较少见，直接点击可能打不开，需要复制网址到浏览器地址栏再回车。用邮箱登录即可，新用户有免费额度。

搭配刘小排的帖子体验更佳：《5 分钟做个网站，人人都能学会》；也有视频版——《不懂编程，1 分钟让 AI 做一个星座运势网站》。

# 2.3.4 本地环境怎么配：Node.js、npm、Git 极简说明

用大白话来理解：

1. Node.js：相当于给电脑装了一个能“运行” JavaScript 的播放器。过去 JavaScript 只能在浏览器里跑，现在电脑本身就能执行。
2. npm：类似手机上的应用商店，别人写好的代码模块直接下载，省得自己重造轮子。
3. Git：代码界的时光机，每一次修改都有记录，改坏了可以回退，多人一起干活也不会互相打架。

三者的关系：Node.js 提供运行环境，npm 负责在这个环境里取用现成工具，Git 则把代码的变化全程记账。

我本人不是程序员，至今没碰过这些东西；只有在 AI 让我复制粘贴命令时才照做过，也说不上熟练。非程序员的新人不必过度担心，咱们眼下的任务就是把站点发出去。只有尽快把一个个网站发出去，才谈得上快速命中需求、兑现需求。其余的工具、环境、模型统统只是配件，别在上面陷得太深。

# 2.4.1 提需求时，有哪些提示词技巧？

一类走口语化路线。别给自己设限制，想做什么就写什么，哪怕句子乱成一团、前后互相矛盾也没关系。跟 AI 聊着聊着，你的想法会越来越明确，那些杂乱表达也会在反复归纳中变成结构完整、条理清晰的提示词。

另一类走结构化路线。不少圈友习惯用固定格式，把技术架构、角色背景、预期输出等栏目逐一填满。只要形成一套属于自己的模板，跟 AI 的配合会顺畅得多。

# 2.4.2 AI 返回的代码，在本地怎么跑起来？

HTML 类的页面最简单：浏览器直接打开，既能看渲染效果也能翻源码。要修改的话，Notepad++ 这种轻量编辑器就能搞定；或者登录 GitHub 仓库，在代码文件里直接改。

Next.js 这类带后端、由多个组件组成的工程，我基本不在本地调试——没有编程基础的人操作起来容易出错。通常的做法是：把问题截图发给 AI，描述清楚需求，再把它返回的代码片段复制过去反复测试。

# 2.4.3 遇到报错时，怎样让 AI 对症下药？

第一步，准备一份持续更新的网站地图，把它作为背景信息交给 AI，过程中还要请 AI 不时做二次校正。

第二步，出错时把报错画面拍下来，文字性错误也一并复制发送。描述问题请遵循这个公式：预期的结果 + 当前的报错信息 + 你已经尝试过的操作（把具体代码附上）。

第三步，让 AI 把所有可能的出错原因都列出来，然后逐个给出解法，你再去实际验证。这套方法能解决绝大多数报错；只有非常复杂、或提问者缺了某块编程基础知识的问题才可能卡住，这种时候发到航海群，交给技术大牛处理。

# 3.1 游戏站是什么？靠什么变现？

核心观念先摆正：我们不是做游戏开发，而是去捕捉那些可能爆火的新游戏名字，围绕它们把网站搭起来，把搜索流量引过来。

互联网上早已存在海量现成游戏网站，作品就摆在那里，拿过来用即可。怎么拿？只要理解一个关键词——iframe。它的作用相当于在页面里开一扇内嵌的「窗」，窗外展示的是来自其他站点的网页、视频、地图甚至在线游戏，访客不必离开当前页面，就能直接观看和操作这些内容。

这类站点的优势非常清晰：

- 不需要开发技能：你只负责把现成的 HTML5 游戏聚合起来
- 玩家粘性强：游戏自带娱乐属性，用户愿意多待一会儿
- 维护负担轻：隔段时间补几条新游戏链接，内容就保持新鲜

说到变现，首推 AdSense。绑定招商银行（境内大陆发行）的储蓄卡，美元就能直接入账；五万美元以内的收入免人工审核，系统自动记账，申报环节同样自动通过，之后美元购汇成人民币，随时提现。

其他变现路径也一并列出：

1. 广告分成：把 AdSense 或其他广告联盟的代码挂进游戏页面，靠展示产生收益
2. 会员订阅：向玩家出售去除广告或独家内容的付费资格
3. 游戏内购：与开发者约定分成，从游戏内付费中分一杯羹
4. 推广佣金：替其他游戏平台带去流量，按效果获得奖励
5. 定制搭建：为企业客户打造品牌定制版游戏站

# 3.4 进阶：从单页扩展到多页面游戏站

前文已经走通了单页小游戏的上线流程，从域名购买到托管配置都有了清晰认知。但如果想让网站真正做大、获得持续稳定的流量，就必须上线更多网页、更多游戏，把它做成一个规模化的游戏站。接下来结合前面的经验，拆解多页面游戏站的搭建方法：核心结构如何规划、游戏怎么批量添加、用户体验如何丰富。

# 3.4.1 网站结构：分类、导航与页面管理

从单页变成多页后，网站骨架的重要性立刻凸显。合理清晰的结构，既方便玩家快速找到目标游戏，也有利于搜索引擎理解整个站点。可以从三个维度入手：

1. 游戏分类与归纳

不同风格的作品吸引不同人群。可以按玩法类型划分，比如动作、射击、益智、策略、体育；也可以按题材划分，比如恐怖、二次元、像素风。首页或主菜单栏最好放一个「游戏分类」入口，让玩家按兴趣点选。

2. 导航与菜单设计

页面顶部设置全局导航菜单，把主要分类或频道列出来。为了体验更好，首页再加一个搜索框，让用户直接搜索游戏名或关键词。

3. 数据库或页面管理

如果使用 WordPress 等 CMS，可以建一个名为「游戏」的自定义文章类型（Custom Post Type），一篇文章对应一款游戏，内容包含介绍、截图、iframe 嵌入等。

如果使用静态网站生成器或手写 HTML，就按游戏类型分目录存放，文件名与 URL 结构要保证可读性和层次感。

规划到位后，每款新游戏都会拥有简洁美观的 URL，用户分享链接方便，搜索引擎收录和排名也更受益。

# 3.4.2 批量添加游戏：模板化与自动化

多页面模式下，「批量加游戏」往往是耗时最重的环节。每加一款都要手写 HTML，还要同步处理样式、简介、图片，不仅工作量大，还容易反复出错。下面几条思路可以显著提升效率：

1. 通用模板页面

先做出一个通用的游戏页模板，例如包含：

- 标题（H1）
- 一句话介绍
- iframe 容纳区
- 玩法说明与操作提示

新增游戏时，复制模板，只改游戏名、iframe 地址、缩略图这几个字段即可，重复劳动大幅减少。

2. iframe 嵌入标准化

给 iframe 设定统一的宽高，或使用 responsive 自适应写法，确保手机端显示正常。比如定义一个公共样式 .game-iframe { width: 100%; height: 600px; }，所有嵌入游戏就能保持一致的版式。

3. 自动化脚本

有一定开发经验的话，完全能用 Python、Node.js 这类脚本语言，把游戏的标题、简介、IFrame 地址等信息抓取出来，再批量渲染成 HTML 页面。

要是你用的是 WordPress 这类 CMS，那更简单——直接导入 CSV，或者通过插件一次性生成多篇游戏文章，效率能提升好几个档次。

说到底，只要走模板化、自动化的路子，你就能在最短时间里让网站塞满游戏内容，从而吸引到更多不同口味的玩家。

# 3.4.3 让每个游戏页面更丰富

给每款游戏搭页面的时候，别只放一个 IFrame 了事。在嵌入之外，下面这些内容都能帮你留住玩家、提升吸引力：

1. 游戏亮点与上手说明
用三言两语点出游戏的核心卖点，并告诉玩家怎么快速开局。
如果游戏操作偏复杂，那就配上几句操作指引或示意图，比如如何移动、怎么射击、怎样闪避。

2. 截图与视觉预览
游戏还没加载完之前，先放一两张截图，让玩家心里有数。
截图还能当社交媒体的预览图，不光能勾起点击欲，分享出去也更吸睛。

3. 攻略、彩蛋或开发者故事
碰上热门游戏或者内容够深的作品，不妨写一篇短小精悍的攻略。
要是游戏背后有特别的开发故事或背景设定，也可以单独弄个小栏目，满足玩家的探索欲。

4. 同类推荐 / “猜你喜欢”
玩家通关当前页面后，大概率还想再玩同类型的作品。这时候把其他同类游戏链接摆在旁边，不仅能提高用户粘性，还能拉起更多浏览量。

![](img/b44ea565297712e66dd3a0a2f1c74ec3.png)

# 3.4.4 加入互动与社区玩法

游戏站要想真正做起来，不能只当个“发游戏”的平台，还得让玩家感受到自己身处一个可以互动的社区。不妨试试下面这些招：

1. 评分与评论
给每款游戏加上打分入口，让玩家可以点“喜欢”或打五星。
评论区则是玩家交流的主场——分享体验、提问求助、聊聊卡关心得，全都能在上面完成。

2. 热门榜与新品区
在首页或侧边栏挂出“TOP 5 最火游戏”和“本周新游”，按照访问数据或上线时间自动/手动排序。
排行榜这种形式特别容易让玩家一个接一个点下去，访问时长和浏览深度自然就上来了。

3. 一键社交分享
页面里放上 Twitter、Facebook、Reddit 等平台的一键分享按钮。
好的游戏经由玩家口碑传播，是吸引新用户最高效的办法，火爆作品往往就这样被迅速传开。

![](img/915d46a5e48e61f992a2e8ff8422cbe4.png)

# 3.5 多页面游戏站如何优化和推广

网站的结构和内容都到位之后，接下来要做的就是让更多人发现你、点进来。这个阶段，得把 SEO、社交推广和数据分析结合起来，边测边调、持续迭代，网站才有机会稳步向上走。

![](img/555eeedd8eb8a83bdbe0eb4c57b2b385.png)

# 3.5.1 用 SEO 把自然流量做起来

1. 层级与 URL 别乱来
搜索引擎向来喜欢结构清爽的站点。分类目录和 URL 命名都要一目了然，让用户和爬虫都看得懂。
每个游戏页面的 title 和 meta description 也得认真写，页面正文里最好带上自然的游戏描述。

2. 内容与元信息要原创
别以为放个 IFrame 就行，页面上的文字同样关键。
每款游戏都写一段独家的介绍和亮点，别直接抄官方简介或其他站的文案。原创度越高，搜索引擎越愿意收录，排名也会更好看。

3. 速度与移动端体验
游戏站免不了堆图片和动态内容，要是加载太慢，玩家转头就走。
图片压一压、缓存开一开，再上个 CDN，速度基本就稳了。移动端的页面布局也要尽量精简，别让人手指头点半天。

4. 提交站点地图，盯紧收录
把 XML 站点地图提交到 Google Search Console，搜索引擎就能第一时间抓到你所有游戏页。
记得定期看收录报告和报错信息，遇到 404 或重复页立刻处理。

# 3.5.2 多管齐下搞推广，把流量引进来

1. 社交平台 + 短视频
挑几款热门或有特色的游戏，录个简单的试玩短视频扔到 YouTube、TikTok 上，挂上网站链接，自然有人顺着过来。
Twitter、Facebook 也别闲着，定期发新游上架的消息，多和玩家互动。

2. 内容营销 + 混玩家社群
用攻略、榜单、行业资讯这些内容把网站的专业人设立起来，玩家才会持续关注你。
Reddit、游戏论坛等地方也能去，但别硬广。多发攻略、心得、经验这类真正有用的东西，自然流量就会找上门。

3. 外链合作
多去看看同类的游戏站和玩家博客，很多博主都喜欢评测或推荐在线小游戏。你可以跟他们混个脸熟，争取让对方挂上你网站的链接。
再进一步，搭上游戏周边、硬件评测这类相关领域的网站做合作，流量渠道会更宽。

# 3.5.3 写在小结：下一步怎么走

小游戏站建完之后，下一步干嘛？

如果你对这站特别有信心，初期又有点自然流量，那可以继续补外链、加内容页，再推一把。

但大多数情况下，我建议你直接去做下一个网站。

刘小排老师有句话叫“打无记忆的牌，下一个站再来”——既然用户记不住你，那就别恋战。

反复换站有什么价值？价值恰恰在开头那句：只有在不断建站的过程中，你才能一次次去挖掘需求、验证需求。

自嗨没半点用。埋头苦研究技术、执着于页面好不好看，这些对赚钱都没意义。

只有当真实需求被验证、网站自然流量开始涨，推广和优化才转得动那个正向飞轮。

# 4.1 导航站的特征与变现方式

# 4.1.1 好导航站有哪些特征

能称得上优秀的导航站，下面三条特质几乎跑不掉：

垂直精准，分类清晰
好的导航站大多扎根某个细分领域，资源经过严格筛选，类别分得明明白白。用户一进来就能准确找到想要的，体验自然好。

资源实用，持续更新
被收录的内容通常是用户高频使用的高价值资源，而且站点要不断维护，保证链接不过期、不失效。只有长期靠谱，用户才会一直信任你。

界面简单，用着舒服
设计走的是简洁路线，没啥花哨功能，交互顺畅不卡壳。用户不用多动脑子就能找到目标资源，愿意反复访问，粘性就是这么攒出来的。

![](img/0b1715620ee11fcca5e915afb305831c.png)

# 4.1.2 导航站怎么赚钱

导航站能不能变现，前提是手里有高质量流量，并且能把流量精准导给有需要的人。主流的赚钱模式有这么几种：

广告变现
最常规的一条路，下面两个方向都能走：
接第三方联盟，比如 Google AdSense、百度联盟，靠流量点击赚分成；
自己拉广告主，把首页或分类页的黄金位置卖出去，单价通常更高，客户也更精准。

付费收录
当你的导航站有了一定流量和名气，就可以让想推广的网站花钱买曝光位。比如设置“VIP 推荐位”，把位置明码标价，收入自然再上一个台阶。

会员付费
手里有独特资源或独家内容时，会员制很好使：
基础资源免费开放，高级资源只对会员开放；
顺带提供无广告纯净版，用户更愿意掏钱。

联盟营销（Affiliate）
如果你做的是购物、软件、服务类导航，用户本来就有明确的转化意图，那联盟营销很合适。把用户精准引到合作站点，对方消费或注册后你就能分佣金。这种模式转化准、收益稳，在垂直导航里特别常见。

原创内容与增值服务
基础导航之外，还可以靠自己的原创资源赚钱。比如出行业报告、专业评测、精选榜单、干货资源包，走付费订阅、单篇购买，或者给自有产品导流，都是不错的增收路子。

# 4.4 导航站进阶优化方向

更高级的玩法肯定是用模板；再复杂一些是接数据库。初阶航海阶段先不展开。程序员同学可发挥的空间很大，不懂的地方多问 AI，自学也能很快深入。一般来说，可以从下面几个方向优化：

性能：首屏尽量两秒内打开，图片与脚本都瘦身；移动端按钮留大些；版面保持克制，重要入口要显眼。

内容：宁可少而精，只收真正顺手的工具；每周巡检一次链接，发现死链及时换掉；每月补一批新资源；定位锁定一个垂直方向，例如只面向独立开发人群，而不是做成杂货铺。

站内搜索：最好给出即时联想输入框，用户一输入就能定位；分类逻辑别只按技术栈切，要从使用场景出发；每个条目配一两句说明，讲清它解决什么问题。

SEO：分类页标题写明白并自然带上关键词；正文不要只有链接，补一点介绍；分类之间互相导流，让用户愿意多点几页。

拉新：去 V2EX、Reddit 等社区发精选合集；给被收录的工具作者发个通知，对方可能顺手帮你转；遇到相关提问时，再把站内资源自然地带出来。

商业化：留几个精选展示位，把真正好用的工具顶上去；付费产品可挂推广链接拿分成；广告克制，别让体验崩掉。

长期动作：盯住点击与搜索词数据；开一个轻量反馈入口；隔段时间做一次版式对照测试，哪种布局留人更久就沿用。

# 5.1 图片站的定义与变现路径

传统图片站大致包括下面几类：

矢量图库：主打可任意放大的 SVG 文件，方便设计、开发取素材。案例有 Freepik（freepik.com）、SVG Repo（svgrepo.com）、Flaticon（flaticon.com）、Vecteezy（vecteezy.com）、SVG Silh（svgsilh.com）。

壁纸站：高清壁纸聚合，供下载装饰屏幕。案例有 Unsplash（unsplash.com）、Wallhaven（wallhaven.cc）、Wallpaper Abyss（alphacoders.com）、Pexels Wallpapers（pexels.com/wallpapers）、Wallpaper Engine（steamcommunity.com/app/431960）。

摄影作品站：专业摄影师作品展示，按主题、风格或作者分类。案例有 500px（500px.com）、Flickr（flickr.com）、Behance Photography（behance.net/galleries/photography）、EyeEm（eyeem.com）、Getty Images（gettyimages.com）。

表情包/梗图站：流行表情与网络梗图集合，方便社交聊天使用。案例有 Giphy（giphy.com）、Tenor（tenor.com）、imgflip（imgflip.com）、Emojipedia（emojipedia.org）、Know Your Meme（knowyourmeme.com）。

图片托管：上传存储图片并生成外链。案例有 ImgBB（imgbb.com）、Imgur（imgur.com）、Cloudinary（cloudinary.com）、SM.MS（sm.ms）、Postimages（postimages.org）。

这类传统站用 AI 也能搭，但赛道拥挤，想再分到大量流量并不容易。

所谓 AI 生图站，是让模型根据文字描述出图的平台，常见底层有 Stable Diffusion、Midjourney、DALL-E 等。用户写几句提示词，就能得到不同风格与内容的画面，不必具备设计功底。

现在模型能力不弱，可多数产品仍偏向技术型用户。做站的机会在于扎进具体场景和具体人群，把技术门槛降到普通人也能用。

换句话说，让原本不会 AI 绘图的人，忽然也能出图——这就是在解决需求，也是在创造价值。

前阵子直播里聊过我那个小产品 Raphael AI（htps:/raphael.app）。上线前，一些有大厂背景的朋友并不看好，觉得 AI 绘图已是红海，还追问壁垒在哪。结果一个月内月活破百万，用户几乎全靠口口相传，我没投付费推广。因为临时和龙哥盟做了课程合作，连擅长的 SEO 都没来得及做；在 Google 搜 Raphael AI，站甚至排不上号。

别人认定拥挤的领域，它却跑得很顺。价值恰恰来自那个被看轻的“套壳”——把不会 AI 画图的人，带进能画图的状态。

# 5.5 进阶优化与推广

网站做好之后，优化是场持久战，加内页、补功能、填内容，这些都在功课范围内。推广渠道五花八门，但对新手最友好、也最见效的，还是雷打不动地天天发外链。三步走：先把自己网站相关的关键字全部拉个清单；去 Google 里逐个搜这些词，蹦出来的全是竞品；再用外链分析平台查竞品的发链阵地（https://ahrefs.com/backlink-checker/?input=），照着它们的阵地找机会。

第五步，把上面这套动作反复执行，关键词、同行站点、可发外链的渠道会越积越多。这些资源一边能用来打磨自家站点、研究对手，一边也能把推广与外链同步铺开。

# 6.2 选词的方法

新站想快速起量，抓新词热词是最有效的捷径。

什么叫优质新词？它通常诞生于近一周或一个月内，此前无人使用，搜索热度持续攀升——社交平台上讨论它、检索它的人越来越多。

来源大体两类：大平台、大企业造出的新词，以及独立开发者、游戏工作室给新品起名时产生的新词。

但有个前提：抢注他人新词在道德上站不住脚，若对方已注册商标或版权，风险更高。谷歌 Claude 模型就有人照搬模仿做站，后来被清理掉。

所以判断力很关键。经验占大头，也可以靠谷歌检索和咨询 AI 来辅助。

最稳妥的路径：把相关单词本身作为域名注册——不是相近拼写；网站核心标题紧紧围绕这个热词展开。

# 6.3 上站全流程

最近出海圈对新词新站关注度暴涨，市场反而变差：不少人只注册域名却不上站，白花钱也浪费机会；一些组织推出批量建站平台或模板，导致大量站点高度雷同——文案之外，配色、布局、结构几乎一模一样。

# 6.4 数据分析与网站调整

# 6.4.1 GSC 和 GA 的工具介绍

1. Google Search Console（GSC）监控

作用：让谷歌知道你的站点存在，帮助页面被搜到。

在 GSC 可看搜索排名、点击、展示，以及站点问题，如移动端可用性、抓取错误等。

2. Google Analytics

统计访客数量及其站内行为。

借助 GA（或其他分析工具）查看每日访问量、停留时长、跳出率，定位最受欢迎页面。某分类点击率特别高，就持续加内容；某些页面跳出率高，则检查加载速度或内容吸引力。

3. 定期更新与版本迭代

玩家兴趣变化快，站点长期不更新、无新品，很难吸引回访。

制定按周或按月的更新计划，持续加新游戏，或围绕热门游戏页面做延伸内容，保持活跃度与吸引力。

# 7.1 Google AdSense 申请：门槛、被拒原因与实操流程

# 7.1.1 申请之前：资格门槛和常见拒因

官方的具体说明可以直接去 AdSense 计划的资格要求页查看。

Google 使用 AI 加人工的两层审核机制，下面几点要特别留意：

1. 要有一个 Gmail 账户；
2. 网站里的内容必须是原创的，并且能让访客受益；
3. 站内不同页面不能有重复内容，每页都该有独特信息；
4. 浏览体验要顺畅，需要划分频道、提供菜单，尽量把站点结构做得一目了然；
5. 每天独立访客数量建议超过 500；
6. 申请人年龄至少 18 岁。

如果你收到了驳回通知，先去看被拒的具体原因，再对症下药。常见情形包括：

1. 站点所有权尚未验证：按提示操作即可规避。
2. 流量质量不被接受：要区分哪些流量违规。像是来自社交平台的流量、Google 自然搜索流量、邮件推广带来的访客、外部链接引入的流量，通常都属于允许范围。
3. 内容过于单薄或属低质：这一条比较容易踩雷。多半是内容量不够，需要持续补充高质量文章，并且整理出清晰的栏目结构。
4. 内容是从别的站点搬运或改写过来的：用原创内容来化解。
5. 其他账号因违规被封禁：这一般针对同一地址下，过去曾有账号被 K 后再次申请的情况。
6. 缺少 Ads.txt 文件：在站点根目录新增 Ads.txt 就能解决。
7. 页面价值不大：提高内容质量和页面的实用价值即可。
8. 站点还没满 3 个月：大概率是流量积累不够，需要多做推广或优化 SEO 来吸引更多访客。

要记住，只要不是触及底线的错误，Google 一般会给改进机会。如果审核结果显示红色 Needs attention，点击右侧的下拉箭头，再点 Show details，就能看到具体的修改建议。你调整完之后可以再次送审。拿不准的地方也能用邮件联系 AdSense-support@Google.com 询问。

![](img/c4006d8ae8be00d7e09c18cbedfafd31.png)

如果看到的提示属于下面这类情况，就需要通读 Google 的相关策略文档，把站内违反规定的页面清理掉，然后再重新申请。

# 第一步：注册并进入 AdSense

AdSense 与 Gmail 是绑定的，所以你手头需要先有一个 Gmail 账号。接下来打开下面任意一个地址，在页面右上角选择 Sign in 或 Get started，都可以进入官网：

https://adsense.com/

https://www.google.com/adsense/

进入后，就能添加一个用于审核的站点。如果你目前连网站都还没有，就先别注册 AdSense，回去把网站做出来更重要。

![](img/abfdca99f062ad2f61d4d605d19f0db3.png)

# 第二步：添加站点并完成验证

https://www.google.com/adsense/

这是 AdSense 的申请入口。

⚠️账号资料务必填写完整，不然的话，所有站点都不会进入审核流程。这点我踩过坑：好几个账号和网站一直显示审核中，毫无动静。

参与审核的网站需要有一定访客量。如果流量不太多，还会受其他条件限制，比如域名注册时间要超过 3 个月，且站内要有内容。

暂时没有网站的话，可以先搭一个 Wordpress 博客，每天写一两篇原创文章，坚持半个月到一个月再来申请，通过的可能性会明显提高。

![](img/7134ce6778d849217620bf78f19d8426.png)

域名只填写顶级部分，不要加 https，也不要加路径，别忘了取消勾选“我目前还没有网站”。

想最大化 AdSense 的作用，第一项保持选中。国家/地区要填写真实所在地，比如人在中国就选中国，因为后面要做地址验证才能收款，这点不能错。若你在其他国家，就按实际所在地区填写。

点击“开始使用 AdSense”按钮，后面会看到相应页面。

![](img/1b31613978f57e4f1e5922e973ef8c3a.png)

这时要填真实材料，还需要获取一段广告代码，把代码部署到站点后再进入审核阶段。个人信息这里，账号类型选择“个人”，姓名和地址按真实情况填中文就行，不需要转成拼音或英文，填写完提交即可。

![](img/b5465ba8ef4f6c6d55dac30908ac0bcd.png)

# 第三步：放置广告代码

复制代码，然后粘贴到网站。审核期并不会真正展示广告，所以这里的设置不需要额外调整，保持默认状态就好。

![](img/f808a2f3a9a7721df01137cbe69404e8.png)

接下来还要把网站与 AdSense 关联起来，点击“我们开始吧”按钮。

新页面里会再次出现广告代码。如果之前已经复制过代码并放在网站里，那这次就不需要重复操作了。

不过要注意的是，这里虽然提供了两种验证方式，但并不是任选其一。哥飞的实践结论是：两个验证都必须完成。既要加入广告代码，也要在网站根目录放一个 ads.txt 文件。

![](img/9a9906d061f8fc5721130adffd370e35.png)

两项验证都弄好之后，点击“我已放置代码”，然后按“下一页”，在跳转后的页面里选择“申请审核”。

![](img/a82f7fc84a0e2a32038746075bb935f5.png)

第一次审核通常需要较长时间。流程一般是：先由 Google 爬虫检测广告代码和 ads.txt 是否到位，再统计一段时间的站点流量，同时抓取网页看看内容丰不丰富，最后才会交给人工审核。

人工审核首先会看统计结果。如果站点流量不高、内容也不多，大概率会被直接打回，让你先补内容或等流量上来。

网上许多教程说，域名注册必须满 3 个月才能申请，这其实只适用于内容少、流量小的情况。

当账号和网站都通过审核后，广告便开始正常展示，你也能在 AdSense 后台查看报告了。

# 第四步：用 Pin 码完成实名

达到 100 美元的余额之前，Google 不会触发付款。在此之前，你需要填写当前的实际地址，例如人在国内就填国内地址；之后 Google 会从美国寄出一封平信，信内带有 Pin 码。收到后到 AdSense 后台输入 Pin 码，实名才算完成，随后才能安排付款。

跨国平信并不保靠，可能会在途中丢失。如果没能收到，可以到后台请求重新寄送，最多申请 3 次。3 次都收不到的话，还能改用线上实名：在后台提交身份证信息，最好再上传一张自己在所填地址附近、以标志性建筑为背景的照片，证明你确实住在那里，这样的审核更容易通过。

线上实名认证的申请地址是：https://support.google.com/adsense/workflow/11033519

# 第五步：设定收款方式

Pin 码验证或线上认证通过后，广告才会继续正常显示。之后余额满 100 美元，Google 就会打款。

推荐选择招行电汇，使用国内银行卡就能收款。Google 汇入的钱可以直接在招行 App 中查到，也能在 App 里换汇成人民币。

记住关键字 China Merchants Bank，之后需要填写收款信息时，用这个词加上 Adsense 去搜索引擎找，自然就能找到对应教学。

同时，我为 Shopify Product Scraper 也做了一次同样的提价，从 $4.95 一路改为 $6.99、$9.99。图里记录的是各次涨价对应的时间。

令人惊讶的是，涨价并未吓跑用户，价格较高的档位，留存率反而更出色。我后悔没有更早行动——全程没有做任何产品改进，利润却因为提价而增加了。

下面那封邮件是我的一位付费会员写来的。这样的肯定，比金钱更让人满足，也正好说明产品确实在他眼里很有价值。

![](img/30c3fe18d7445feacd1eae9f4594eff1.png)

调价期间，我多次让自己离开技术和产品的层面，从运营角度回看价格与小众市场的关系，最终对一句话有了切身体会：为价值定价！

也就是说，价格要反映用户感受到的价值，而不是自己的投入成本。

过去做公司项目、接外包时，大家习惯性地强调成本控制：想提高利润，要么压低成本，要么靠商务谈判能力。

做副业开局时，我同样被这种思路影响：先算自己花了多少成本，报价就必须高于成本。

然而在小众市场，我们直接面对终端用户，定价就变得棘手，因为你开发的东西，使用者往往不是自己。比如我做的 Youtube Comment Bot，最初卖 $1.99，原因是我觉得这东西自身价值低，开发也不费事。

后来我才真正想明白：应该跟着用户价值来报价，而不是成本；大胆写出价格并不丢人，谈钱也不是伤感情的事。

![](img/5f2bc3084f967a27c237dae75d36d681.png)

把精力集中在 20% 的核心用户身上。

一款产品在小众市场中，什么手段能最快、最直接、最有效地建立用户的预期价值？

不是罗列一堆功能，不是冗长的问答页面，不是免费试用 7 天，不是全天 24 小时客服，不是下载量，也不是评分高低——而是一个简单明确的售价。这个数字会让用户产生与之匹配的价值想象。

偏高的预期自然会筛掉部分潜在买家，但要记得：按照 80/20 规律，两成用户会带来八成利润。所以更应该优先服务好这 20% 的人群。那些真正理解产品价值的人，往往能给出更高价值的建议，让产品迭代更顺畅。

![](img/e3e5ec8d428afe9e4c49bf44326832dd.png)

设置一个价格锚点。

所谓锚点，就是拿来对比的参考价格。商家在营销时常用各种锚点手法，通过对比或暗示，悄悄改变人们对贵还是便宜的判断。

消费者判断某样东西值不值，通常需要一个参照物。这个参照物由商家主动给出，就叫价格锚点。

比如 99 元/年就可以充当锚点，有它垫底，后面的价格才会显得不贵。

![](img/a23c0e2389070e14f56f40eab5d370a9.png)

拿优酷的会员收费来看，套路就相当明显。把“季度 VIP 56 元”当作锚点。

新用户前 3 个月每月 6 元，第 4 个月开始变成每月 15 元，老用户则一直是 15 元/月。按正常情况，包一个季度会员最多也只要 45 元，标个 56 元的季度 VIP 是要表达什么呢？:P

# 7.2.2 分佣联盟：从零接入 Affiliate

Affiliate 营销，说白了就是按结果付费的推广合作：你去推广商家的商品或服务，有人通过你的链接成交了，你就能按约定分到一笔报酬。国内大家见过的淘宝客、知乎好物、抖音书单、外卖返利、美团地推等玩法，本质上都属于这个范畴。

开始实操前，先把 Offer 搞清楚。Affiliate 里最常见的 Offer 类型是 CPS 和 CPA 两种。

CPS 是销售分成型：按最终成交金额给你提成，实物商品可以，软件、订阅服务也行。由于现在的 SaaS 产品越来越多，而且订阅周期长、可重复计费，这类产品的佣金比例往往给得比较大方，综合收入甚至可能比卖实体货还高。举个例子，亚马逊在年末促销季时，部分品类提成最高能到 9.5%；如果卖出一台 300 美元的冰箱，你就能分到 28.5 美元。如果你主推某个品牌的独立站商品，提成比例通常更可观，保健品行业甚至可能超过 50%，想了解可以上 https://fanfuel.co 看看。当然，高佣金通常也意味着更激烈的竞争。

![](img/36e9d6d1de1c95a0809dec0d331b5644.png)

另一种 CPA 则是按动作付费：用户完成指定行为后你才有钱拿，行为可以是下载一款软件、填写一份注册表单等。普通 CPA 任务的单个价格多在 2 到 10 美元之间；像前面提到的保健品领域，单个动作的报酬可能高达六七十美元。

![](img/ee5b56a30c1c21e85b40db47ff7f804b.png)

另外，affi.io 这个站也整理了大量带联属计划的平台，可以根据自己需求去翻一翻。

海外在线产品的种类极其丰富，可选的推广对象非常多，佣金也普遍颇具吸引力。怎么选？首先要明确自己工具站的内容方向，尽量摸清访客的画像，再针对性地考察联盟政策、分成比例，最后再决定做不做。

新人选细分领域时，不要完全靠感觉，更稳妥的做法是找到一个比自己弱的同行，研究清楚他为什么能做成，然后超越他。否则等你把流量做到一定量级，却找不到合适的产品来变现，那就尴尬了。

关于找产品的渠道：你可以直接看竞争对手在推什么，跟着申请；也可以去 Google 搜索“关键词 + Affiliate”；还可以通过 Affiliate Network 中介去合作；甚至直接联系广告主本人。

联盟网络会抽走一部分服务费，但它帮你对接好了各种广告主，省去了很多谈判精力。跳过联盟直接跟广告主合作，佣金确实更高，但对你的能力和资源要求也更高。打个比方，Affiliate Network 就像房产中介，广告主像卖房的房主，而你是夹在中间的那个推广者。

合作时间长了，你还可以和对方谈条件，比如提高提成、减少扣量。

另外，在 https://www.Offervault.com/ 和 https://odigger.com/ 这两个平台，可以按关键词搜索，找到匹配你 niche 的 Offer。值得留意的是，同一个 Offer 在不同联盟里的转化率未必一样，要亲自测试。因为每家联盟的运营打法（以及“道德底线”）都不尽相同。

选定产品后，通常第一步是申请推广资格。国外绝大多数软件/工具类网站的页脚都会放“Affiliate Program”链接；就算没有，直接 Google 搜“产品名 + Affiliate”也能找到入口。注册流程很简单，直接提交即可。对新人来说，资料最好如实填写，不然将来佣金到账了却提不了现，就得不偿失了。

# 7.2.3 收款与付费咨询：PayPal、Stripe 配置方案

先看怎么接受用户捐赠。

第一步，先把捐赠页面搭起来，有两个常用工具：

https://ko-fi.com/
https://buymeacoffee.com/

注册之后，做一个简单的产品介绍页，再连上自己的 PayPal 或 Stripe 账号，就能开始接受打赏了。用户捐出的款项会直接进入你的账户。

第二步，把赞助入口放到显眼的位置。比如网页 Logo 旁、首屏中央、页面底部、顶部导航栏，这些地方都很合适。在社交平台发帖的时候也可以顺手附上链接，那些觉得内容有用的用户，就有可能会支持一笔。

示例：

![](img/a155c9b2943895f2c61f46d18ad93978.png)

![](img/7e644e7944ab7b471735c88cf45de94f.png)

如果你的工具站要做付费订阅，就必须先解决收钱的问题。个人开发者可以从 Lemon Squeezy 起步；而 Stripe 最好用公司主体注册，并且优先考虑海外公司。

等海外公司、银行账户、Stripe 都办妥后，美元、USDT 就都能收，资金最终还能“绕道”回到国内账户。公司银行账户通常会给一张员工卡，绑定支付宝就能消费，同时海外线上服务也能顺利使用，再也不用担心 OpenAI 扣款失败。

需要准备的材料有护照和驾驶证。填写信息时务必真实，一旦造假，账号可能被封，那就得不偿失了。

**为什么要有海外公司？**

最关键的原因有两个：一是你需要一套稳定、可用的收付款通道和海外银行账户；二是很多海外服务不对中国大陆开放，或者对大陆身份的风控特别严格。

手机号也是刚需：英国可以选 giffgaff，每 180 天发一条短信就能保号，成本 0.3 英镑；美国可以选 Ultra Mobile PayGo，月租 3 美元。giffgaff 能在官网免费申办，嫌麻烦的话淘宝、京东上也有现成的。

公司注册地通常在英国或美国之间选。英国公司更便宜、流程也更简单（推荐用 1st Formations），配合 Wise 企业账号就能开户。我自己这次注册的是美国公司；当然，如果业务需要，两边都注册也没问题。

我的注册过程是找了一家一站式服务商 Firstbase，口碑不错，从公司注册、地址公证，到银行开户，全部都有清晰指引。论省事程度，淘宝代办最高效；但我个人更喜欢 Firstbase 这种带 dashboard 的 SaaS 服务，进度一目了然。

注册州我选了 Wyoming，公司类型是 LLC，比较适合个人开发者。

接着是租用邮箱（也就是私人地址），并通过 Notarize 做远程视频公证（1583 表）。办理前要准备好驾驶证翻译件（淘宝几十块钱就行），注意驾驶证上的照片页和地址页必须放在同一页展示，最好合并打印成 A4 纸。视频公证时需要用简单的英文沟通，工作人员会让你展示翻译件，然后询问你是否自愿注册，并让你确认签名。

公证完成之后，Firstbase 会继续代为申请 EIN（雇主识别号）。我的 EIN 是在第 10 个工作日收到的，由国税局寄出。

Mercury 银行开户则直接通过 Firstbase 关联提交 EIN 和护照审核，1 个工作日便通过了。

到这里，公司主体、EIN、私人地址、银行账户、手机号就都齐活了。私人地址的用途还有很多：比如作为账单地址、申请实体卡后转寄回国内，以及接收 Google AdSense 的验证信。

Mercury 一个很实用的功能是：可以免费无限量开虚拟卡，并且能对每张卡设置交易商户和限额。比如 A 卡只能在 Google 上用，B 卡只给 OpenAI 扣费；万一碰到不给退订入口的服务商，直接注销对应卡片就行。

Mercury 虚拟卡还能绑定支付宝消费，单笔 200 元以下免 3% 手续费。

有了银行卡、账单地址和手机号，海外服务基本可以畅通无阻地注册；再进阶一点，还能申请 ITIN 和个人信用卡。

**Stripe 企业账号**

EIN 拿到后，注册 Stripe 很轻松。把网站语言切成中文，用中文信息填写，个人验证用护照，提现账户关联 Mercury 即完成。另外，Lemon Squeezy 和 Paddle 也建议一并注册，但这两家都需要先验证你的产品网站。

**Wise 个人收汇款**

Wise 支持大陆身份注册，用护照即可。比较麻烦的是入金激活：如果 Mercury 里有余额，入金很快；否则可以找人代充。Wise 的实体卡（附带 3 张虚拟卡）不支持大陆申请，但可以在激活后把个人地址改成海外地址，再申请就要付 9 美元，同时需要地址证明。

Wise 余额可以兑换成人民币，提现到国内银行卡，也能提到🛰️和支付宝。算下来手续费比香港银行卡汇款再结汇要低，而且 Wise 的汇率通常更友好。

还有更稳的结汇方法，可以参考：https://twitter.com/zhufengme/status/1706971107885265405

Payoneer 也有类似服务，建议一起注册。

**Kraken 交易所提现到 Wise**

Kraken 同样支持大陆身份和护照注册。充值 USDT 后，在订单簿上买入欧元——注意是用“买入”而不是“兑换”，兑换的手续费非常高。之后选择 SEPA 汇款，通常 1 个工作日就能到 Wise 的欧元账户。

之所以不选美元，是因为大陆身份注册的账户没有 ACH 汇款选项；而欧元走 SEPA 不但可行，手续费还更低，只收 1 欧元。

**注册与维护成本**

1. 美国手机号：每年 $36
2. Firstbase 注册：$399
3. Firstbase 地址邮箱：每年 $350
4. Firstbase 公司代理（含年报、税务申报工具）：每年 $299

美国公司注册代理有不少，Firstbase 这价格说不上便宜。上述所有环节——公司注册、地址公证、EIN 申请、公司代理、报税、银行开户——都可以拆开来自行选择，可以都找代理，也可以自己动手。

另外，圈友 @阿彪 在往期航海里分享过海外收款的经验，想进一步了解，可以看《简单聊聊出海工具，流量和支付的一些事》的直播回放，从 1 小时 03 分左右开始。

至此，你已经看完了用 AI 快速搭建网站的全部流程：从基础知识讲到实际案例，从简单的游戏站做到 AI 图片站，工具和心法都已掌握。
