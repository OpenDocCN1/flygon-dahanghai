# 中小电商人才复制，核心在担责、授权、分利

我是一家30人电商企业的老板，也是“有为谷”私董会的发起者，叫唐有为。公司2018年成立，去年差不多20人，今年多出直播和外贸两个部门，人数才到30。加入生财有术不到一个月，但“先利他、再共赢”这个想法，我一直很认可。

这次分享主要讲我们实际经营中沉淀下来的一套方法，围绕三条线展开：职责、权限、收益。适合刚刚起步、正在爬坡的中小电商团队。

## 一、每个人都该清楚自己的位置

### (一) 招人前，先画出岗位画像

现在偶像组合很流行立人设，颜值、身高、搞笑，什么都能当标签。公司选人也一样，先想清楚每个位置要解决什么问题。电商生意的逻辑，无非是流量进来，有人买，买得贵，买得多，再买一次。所以——

店长，要看得懂数据，对行业、对手、自己、成本都有感觉；懂产品，能调度，压力来了也扛得住。
设计师，要有策展思维，有创意输出。
客服，要态度稳，性子好，能沟通，会来事。
会员运营，要会策划活动，会给客户分层。
财务，对数字要敏感，风险意识要强。
运营负责人，要管住人和事，还要算得清成本。
到了一把手，钱、人、物、方向、激情、使命感，一样都不能少。

创业阶段的公司，在市场上很难直接找到完全成熟的人。只要能碰到具备这些苗头的潜力股，就值得花时间培养。筛选条件要前置到招聘环节。我听过一套《人格14心》测试，一百道题看人挺准，我们没拿它当硬标准，只做参考，几个骨干测下来都挺贴切。还有一位做管理的朋友，面试时会问对方家里情况，这种维度小公司也可以参考。

### (二) 每个位置都要有一张工作指引

公司架构没有标准答案。我们加了直播部，别家也许用不上，可以外包，也可以不碰。工作指引的价值，是先搭好架子，再把每个岗位存在的理由和日常动作固化下来，形成一套可以照做的流程。把人招来以后，先按指引跑通基础动作，再在实践中查漏补缺，岗位目标就容易达成。

我按自己的理解，把几个核心岗位的工作指引说个大概：

总经理：管方向、管资源、管人。方向是中长期战略和年度目标，资源是人财物和外联关系，人是高层的选拔、培训、考核，还要把公司的制度立起来，不合适就调整。

运营总监：管业绩增长。核心动作包括做爆款、清库存、完成年度规划、找蓝海类目、开发新产品、带运营团队、考核月度指标、提升会员复购和新增。

天猫店长：管一个店铺的生意。选品、卖点提炼、产品规划，直通车、钻展、超级推荐、淘宝客这些工具要会用；活动排期要安排，日常促销、品类活动、聚划算、618、双11都要接；数据要盯，行业、竞品、自己一个不落；还要对销售额、利润、会员加粉和转化负责。

设计主管：管视觉和团队。店铺整体形象、品牌调性、VI规范、美工出品、促销页面都要盯。配合运营的主题做图片优化，定期产出活动素材。团队管理也落在她身上，考核、培训、跟踪指导都不能少。

客服主管：管服务体验。从建团队开始，把售前、售中、售后全流程的评估体系立起来；话术要规范，疑难问题要兜底；每天看着数据，发现问题及时和设计、运营沟通；还要组织培训，处理突发事件，带着团队把服务做扎实。

主播运营：管直播这条线。筛选有潜力的主播，配合选品和活动，规划直播内容和排期，维护粉丝群；帮主播做图文、视频内容；看直播数据，给选款和播法的建议；还要建主播团队的绩效考核体系，带着人成长。

财务主管：管钱和风险。电商资金业务要统筹，预算要落地，订单、收入、费用、结算都要核对清楚。成本要控，费用要盯，还要用财务数据反向推动业务改善，优化流程，评估各部门效率。

这些工作指引怎么来？最简单的办法是让表现好的员工自己写。他写一份，既是对自己工作的梳理，也是检验他是不是真懂这个岗位。

## 二、放权的四个台阶

老板放权，不能一把梭。我们分成四个台阶，逐步交出去。

第一个台阶，下指令：适合意愿强但能力还不够的新人。老板说一不二，同时把标准、边界、权责全部讲清楚。

第二个台阶，做教练：适合刚开始受挫的学习者。老板和员工一起商量，但最终由老板拍板。允许犯错，进步就表扬，多让他想，多让他提方案。

第三个台阶，做后盾：适合有能力但偏谨慎的骨干。老板参与讨论，但把决定权交给员工。肯定他的能力，给他部分资金权限，让他敢做、敢复盘。

第四个台阶，真授权：适合能独立承担结果的人。老板不参与决策，员工自己定。给他岗位上的自主空间，给予信任，在人、财、物上提供支援。

## 三、既要谈成长，也要谈钱

### 1. 钱要算清楚，彼此才安心

我很欣赏“钱放到台面上说”这种态度。员工里确实有人就是来上班赚钱的，别硬劝他成长。老板在外漂泊，员工也一样。我们在成都，很多年轻人来打几年工就回老家，要留在城市很难，不是谁不努力，而是现实限制。对这类员工，把薪资结构讲明白，算得清清楚楚，他才能安稳做事。

### 2. 内部转岗，是人才成长最快的通道

公司从初创走过来，人对业务的速度要求会越来越高。今年直播是风口，但真正懂的人凤毛麟角，代播机构又鱼龙混杂。传统电商团队很难招到合适的主播，一个普通主播开口就敢要一万五，创业期公司根本赌不起。

我们运气不错。一个做内容的员工，以前兼职播过，在原来的岗位上没突破。我喊她去直播间试试，先铺多平台，后来拼多多做得起来，就集中火力做拼多多。播了两三个月，店铺业绩几乎翻倍。她信心上来后，我们马上为她配团队，陆续招主播和短视频运营。一个直播部负责人，就在一次次直播和复盘中打出来了。

### 3. 成长氛围，比想象中重要

传统电商公司常常很安静。直播部进来一批95后以后，公司整个气氛都换了。趁热打铁，我们做起了骨干内训。课程从外面采购，现任骨干和预备骨干都能加入，借此也能筛出真正想晋升的人。内训期间，隔一天一场分享会。以前大家只聊干活，不聊想法；现在聊经验、聊方法、聊状态，人和人反而走近了。第一次内训结束，很多人交了一万字心得，说离开校园后都没再体验过这种氛围。管理者最想看到的，不就是这种向上的希望吗？

### 4. 晋升通道要够宽

初创公司最怕把路堵死。比如客服层，往上只有一个主管岗，其他人怎么办？很多老板动不动就说“转运营”，但也要看人合不合适。我们有个应届生，客服做得非常好，但对运营没有野心，也看不出管理潜力。那就给她单独拉一条初级、中级、高级客服的线，她看到职级在走，自然愿意留下。等她做到高级客服，再考虑往管理方向带。优秀的人，就应该有匹配他成长的通道。

### 5. 分钱方式，可以组合着来

①绩效+销售额提成，适合客服、直播等直接冲销售量的岗位；
②绩效+利润提成，适合店铺运营等看重盈利的岗位；
③绩效+奖金，适合设计部等用转化率或店铺数据来衡量的岗位；
④超额分红，年底利润过了目标线，按阶梯比例分配超出部分，适合运营总监这类对全年利润负责的人；
⑤在职分红，按岗位设置分股权益，人在就拿，走就没了，用于绑定管理层；
⑥期权+注册股激励，这个比较复杂，很多公司用不上，我们也没有启用，但值得了解一下；
⑦裂变创业，与其怕培养的人出去单干，不如主动出钱，让他开一家新公司。你当投资方，他当操盘手。创业那么苦，有人投他，他更有劲。这需要老板格局够大，员工也足够靠谱。我期待有一天我的员工能这样对我说：老板，我想创业，你投我；他赚钱，我也赚钱，双赢。

## 收尾：三者必须对等

放权太多，容易滋生腐败；分利太重，内耗会拉满；压责太狠，消极怠工就来了。担责、授权、分利，在任何人身上都要均衡匹配。

各位，你的岗位是干什么的？你用什么方式干？干成什么样算好？

评论区有做投资的朋友分享：他的方案围绕降成本、增效益、返利客户来设计薪酬，导向是股东利益和员工利益都能顾上，资产负债表改善，大家同在一条船上。唐有为补了一句：利他共赢，商业的起点是用户得到好处，合作伙伴让出一部分，公司和员工则是长期共同体。
