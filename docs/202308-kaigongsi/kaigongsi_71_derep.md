# 公司公开用图，先过地图审核这一关

我是张云金，网名后缀是 GISer，长期在地理信息行业工作。地图是这行最常见的成果之一，大家应该都不陌生。

2007 年从地理信息系统方向毕业后，我一直没离开地图：本职是产品经理，负责地图类产品的策划与设计，二维、三维都涉及；业余维护面向同行的自媒体账号，读者四万多，另有一个付费内容社区，订阅者超过一千。也给《中国国家地理》和北斗集团做过书刊地图，偶尔接朋友委托的挂图设计。

很多单位在宣传展示时离不开地图，这次我结合监管要求，聊聊容易踩雷的地方，再给出可操作的合规做法。

分享分四块：

1. 被处罚的案例
2. 国家对地图的硬性规定
3. 正确地图的制作方式
4. 幻灯片中地图的处理

**1. 被处罚的案例**

在不少企业的发布会幻灯片、宣传物料上，能看到边界有误的地图。先看几张图，试试能否发现毛病。

![](img/kaigongsi_1795.png) ![](img/kaigongsi_1796.png) ![](img/kaigongsi_1797.png)

![](img/kaigongsi_1802.png) ![](img/kaigongsi_1803.png)

答案很直接：中国国界线画错了，这类图都属于不合规地图。

我国对地图边界尤其是国界的监管相当严。公开地图的审查工作，过去由原国家测绘局的地图技术审查中心承担，机构调整后职能划到自然资源部。

自然资源部地图技术审查中心：https://www.zrzyst.cn/

![](img/kaigongsi_1808.png)

通常所说的“问题地图”，是指损害国家主权与领土完整，以及国家安全和利益的地图。常见情形有：重要岛屿被漏掉，比如钓鱼岛、赤尾屿、南海诸岛；台湾省表示有误；藏南和阿克赛钦的边界线画法不正确。

一旦出事，轻则公开致歉，重则收回或销毁物料。

再严重些，还会收到行政处罚。

**2. 国家对地图的硬性规定**

我国专门制定了地图管理条例，细则可在这里查：

https://www.zrzyst.cn/flhxzfg/310.jhtml

![](img/kaigongsi_1840.png)

条文不少，抓住两个要点即可：一是地图必须先审核的制度；二是面向社会公开的地图，须交给有审核权的测绘地理信息主管部门审查。

具体谁去申报，可以这样记：出版类地图，由出版机构申报；非出版物的展示或登载地图，由展示方、登载方申报；进口非出版物地图或带地图图形的商品，由进口方申报；进口出版物类地图，按《出版管理条例》办理；出口非出版物地图或带地图图形的商品，由出口方申报；生产带地图图形商品，由生产方申报。

![](img/kaigongsi_1845.png)

通俗讲，凡正规印刷出版的地图内容，连地球仪也算，都得走审核流程。

查询入口：https://wsbs.ch.mnr.gov.cn/publicity/wsbsPage/todtshquery 。从公开信息能看到，不只是出版社，玩具厂、印刷企业等只要做带地图的产品，也要申报。

![](img/kaigongsi_1850.png)

再留意一下：百度地图、高德地图等平台，页面左下角一般会放审图号。

![](img/kaigongsi_1855.png) ![](img/kaigongsi_1856.png)

图书里若含地图，版权页或正文前也常见审图号。

![](img/kaigongsi_1861.png)

有这个编号，通常说明内容已过审，可对外使用。也有出版方为降低风险，干脆把地图页删掉。

![](img/kaigongsi_1866.png)

审查权限怎么分？涉及全国范围、国界线的，多由自然资源部审查中心负责；地方省市的地图，交给当地自然资源部门对应的审图机构。

审查细节可看：

https://www.zrzyst.cn/dtscgzjs/377.jhtml

![](img/kaigongsi_1871.png)

内容同样很多，重点盯住中国地图的高频错误区即可。见下图：

![](img/kaigongsi_1876.png)

![](img/kaigongsi_1881.png)

星球研究所曾整理过一张示意图，标出我国国界容易画错的 15 处。其中出现频率最高的有 5 处：

**3. 正确地图的制作方式**

知道错图长什么样、后果多严重，接下来是怎样拿到合规地图。

自然资源部建有标准地图服务网站：

http://bzdt.ch.mnr.gov.cn/

![](img/kaigongsi_1891.png)

它叫“标准地图”，可理解为官方提供、边界经过确认的版本。图样按照中国及各国国界线画法标准制作，可用于新闻配图、报刊书籍里的插画、广告背景、文创产品底图等，也能作为公开出版地图时的参照底图。公众免费浏览、下载；直接采用时，别忘记标审图号。

站内可选图样有数百幅，按需取用。

![](img/kaigongsi_1896.png)

现成图不合用怎么办？网站还带自助制图，可自行组合。

![](img/kaigongsi_1901.png)

勾选图层后，结果即时呈现，基本是即时预览的效果。

![](img/kaigongsi_1902.png)

更细的步骤我写过一篇教程，需要自己出图的可以看：

https://mp.weixin.qq.com/s/dxqy-XNjae1x542pe_SdMA

**4. 幻灯片中地图的处理**

官方标准地图站的自助工具虽方便，但覆盖范围主要是世界图和中国图；要做某省、某市甚至区县，就不够用了。

日常办公里，多数人不是专业制图员，只是在演示文稿、企业站点或宣传册中插一张图。错误往往出在数据源：用了不合规的边界数据。国外网站下载的数据尤其容易在台湾、藏南、阿克赛钦等位置出问题。

那合规边界数据去哪找？可以看看阿里云这个地图选择器：

http://datav.aliyun.com/portal/school/atlas/area_selector

![](img/kaigongsi_1911.png)

页面右下角带审图号，数据来源相对可靠。

![](img/kaigongsi_1912.png)

要哪一级就点哪一级，省份可直接下载。默认给的是全国分省数据，格式有 json 与 svg 两种。

写代码的同事对 json 更熟；若要在幻灯片里改，或进 AI 二次编辑，选 svg 更方便。较新的 PowerPoint 支持把 svg 拖进去直接载入。比如把中国地图放进幻灯片，会是这样：

![](img/kaigongsi_1917.png)

选中图形，右键→组合→取消组合，先拆开。拆完就能按区域单独上色或做效果。

![](img/kaigongsi_1922.png)

若想展示省内各地市，下载时点该省即可。以浙江为例：

![](img/kaigongsi_1923.png)

最细能到区县，例如杭州各区县：

![](img/kaigongsi_1928.png)

svg 拖进幻灯片即可编辑使用。

![](img/kaigongsi_1929.png)

按这个流程，就能按实际需要做出边界合规的地图。
