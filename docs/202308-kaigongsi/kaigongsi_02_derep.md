# 企业真正的底盘，不在营收里

文/茅矛

亦仁那天突然发消息，让我把紫菜团队短视频带货复盘评论区里提到的“底层逻辑缺失”再展开聊聊。说实话，进生财这段时间我一直有点不安。我在区域互联网干了十多年，习惯的是慢工出细活；快钱玩法见过不少，可一家公司能不能走得久、走得稳，从来不是靠一两个突然冒出来的盈利项目。也正因为这样，我总觉得自己和生财的节奏不太合拍，不知道能拿什么出来分享。

先说结论：回款漂亮，不等于底盘稳。很多问题会被营收遮住。徐薇老师曾把公司管理分成四层：最上面是战略层，定业务方向与经营计划；往下是结构层，也就是组织层，管架构和管理体系；再往下是运营层，涵盖产品研发、营销销售、供应链、客户服务；最底下是支持层，由财务、人力、信息化三块构成。多数老板在前三层舍得花力气，偏偏最下面的支持层常被晾着。我读完紫菜团队的复盘，最有感触的正是这里。

先看钱。有订单时，人容易上头：成本不细算，税负不预估，应收应付不盘点，财务操作不规范埋下的风险也懒得管。某平台卖旅游卡，进价240元，售价300元，表面每单毛利60元。财务一核算，直接冲到老板办公室拍桌子：“这单越卖越亏。”为什么？300元按13%增值税算，税额39元，毛利只剩21元，平台费用和人工还没扣；再叠加企业所得税、个人所得税，基本白忙。老板也懵：我明明只赚60元，怎么要缴近40元增值税？可如果和供应商在合同里设计成代收代付，这60元就能归入推广服务收入，按现代服务业常见的6%计税；当时小规模纳税人还有1%优惠。税负从39元降到0.6元，单笔多留38.4元。所得税仍免不了，但盈利结构完全变了。

这还只是经营范围与税务安排的一个切面。我听原永辉超市财务总监徐薇老师讲过，国内某办公用品头部品牌的财务部门，对上游原料行情盯得比采购还紧，把原材料当期货来做，还会利用账期在应收应付之间腾挪，用时间差撬动数倍于自有资金的周转能力。所谓钱生钱，在这里体现得淋漓尽致。大卖场、家电连锁，也大多玩过类似套路。

有些公司觉得自己够规范了，该开的票都开，却在费用登记和凭证管理上马虎。等到财务审查，凭证缺一堆，真实办公开支没法证明，反而多花冤枉钱。比如某企业买十几万元办公设备，为了省13%的税点不要票据，年底盘账时缺支出凭证，最后按采购额20%补缴企业所得税，差不多两万元。省万把块税点，换来两万元额外支出，冤不冤？反过来，老板以公司名义购车，购置税可免，还能抵扣同等金额的企业所得，日常油费、保养也能计入办公成本。这些是合规税筹，跟会计做平收支完全两码事。

再把公司主体设计、区域政策、地方差异一起考虑，营收一千万时，节税空间少则几万元，多则上百万元。这年头赚百万有多难？方案做对了，等于硬生生多出一大块利润。所以，财税规范与规划，是公司健康运转的首要根基。疫情那阵，同行嘴边常挂一句话：账上现金能撑三个月工资，才有资格谈明天。利润控制不过是财务棋局里的一角；财务体系做透，公司的根才扎得深。

第二块是人。紫菜团队在上升期和主播理念不合，最后拆伙，销量随即断崖。表面看是规则没提前定好，往深里看，是人力体系缺位。人才从哪来？筛人靠什么画像和模型？新人怎么带？不同岗位的考核与绩效怎么定？晋升和成长路径怎么铺？组织怎样持续换血，又不伤战斗力？边界如何外扩，梯队如何长出来？这七件事彼此咬合，搭起来是长期工程。

钱是燃料，人是引擎，公司像一辆车。差别在于，车出厂就自带发动机，人才却得靠机制慢慢养。生财里不少大神既是公司的灵魂，也可能成为天花板。原因不复杂：老板长期扎在业务一线，组织架构和造血机制没人搭。缺了造血，事事回到创始人身上，向上没余力想长期战略，向下带不出能打的队伍，越忙越陷。我给不少站点做咨询时都劝创始人和站长，别把具体业务全攥在手里，至少现阶段要把人力放到重要位置。生存期业务优先没错，但业务稳定、能喘口气时，团队建设不能再拖。

最近跑两个站点，都想上新项目，钱和资源不缺，缺的是能打的队伍，又绕回那七个问题。它们各自独立，又彼此关联，对任何公司来说都不是小工程。

第三块是信息化。它不只是装几套软件。先看经营数字：现金流水、合同额、应收账款、利润水平、人均单产、薪酬占比，这些是财务视角的仪表；平台流量、指数、用户规模、外部合作资源，是区域互联网站点的体检项；拿招聘网站这个垂直业务来说，登录用户、可投岗位、入驻企业量、每日新增简历、投递次数、新简历打开率、资料完整度、销售触达企业的频次与深度，都能反映平台运行质量，有时一个细指标就能牵出改进线索。

管理分层之后，需要把信息筛选后按层级分发，让不同岗位看到匹配颗粒度的数据，判断各部门业务是否健康，并推动管理层主动决策，这是信息化管理的实质。信息向下同步，还能复盘团队：做得好，提炼打法继续放大；做得差，定位病灶减少无效消耗。公开透明最大的作用，是让上下对战略和具体事项形成同一套事实基础，避免因信息不对称导致目标跑偏。

OKR就是典型例子：用目标（O）与关键结果（KR）把公司战略逐层拆解、双向沟通，让每个人理解整体方向，过程中持续校准、迭代，组织因此能自我更新。大厂早把它当常规配置；办公自动化平台让跨部门协作不断线；客户关系系统把客户联系与维护过程摊开给管理者；后台统计反映部门效率与产出；协同工具填补沟通死角；财务软件则像徐薇老师说的“财务仪表盘”，呈现公司运行是否健康。信息化既是工具组合，更是一种管理观念。

回款到账，不等于财务体系过关；队伍变大，不等于能自己造血；信息化缺位，部门墙就会制造信息孤岛，协作自然不顺。三者还会彼此牵制。比如要开一个新项目或事业部，先回答：谁负责？队伍多大？增长节奏怎么排？人力成本多少？培育期多久？关键里程碑（milestone）如何评估？推进中怎样监督和纠偏？止损线在哪？拆到支持层，就是人、账、风险三件事，分别由人力、财务、信息化承接。

有人会说，想那么多干嘛，先干起来。早期确实可以粗放，但粗放扩张不是万能药。项目到一定规模，人手不足、信息不通、预算机制缺位，都会卡住下一步。支持层最容易被晾在一边；等高速发展把问题暴露出来，再补课往往很痛、很长。尤其习惯爆发式增长的创业者，面对精细、慢见效的体系工程，会纠结甚至想放弃。真正看得远的老板，才会把这件事长期做下去。

以上是我对公司底座搭建的一些观察，欢迎交流指正。
