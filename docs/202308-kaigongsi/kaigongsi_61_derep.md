# 创业近十年，他靠积累做到300人

从2014年迈出第一步，到如今近十年，他一直没离开创业这件事。流量与知识付费项目的孵化、流量变现方向的投融资，他都做，公司已经养到300人。离开部队后，他正好踩上移动互联网的热潮。

外人看，这像一路踩中风口；他自己却说，创业拼到最后，拼的是积累。爆发点还看不清时，先把心态调稳，把队伍练好，等机会上门。

回看轨迹，积累的痕迹很清楚：最早去移动互联网大会攒用户；在BBs上主动加人交流，不把自己关起来；2013年拉起QQ群，2014年正式创业。那个群后来被估出上亿元价值，不仅让他找到合伙人，群友公司中有的发展起来，他还入了股，孵化项目的业务也从这里起步。很多方法并非他原创，而是聊出来的——交流本身就成了生产力。

创业头一年进账20万，第二年30万，第三年破亿；营收破亿后持续四年，他依然没碰融资，靠口碑帮人做APP推广。后来搭流量分发平台，把自己做成信息汇聚的关键节点。他有个观点：信息不是靠“看”学来的，而是组圈子让信息经过自己，自己成为枢纽；被动接收信息、降低信息成本，是建圈子的副产品。选投资者时，他用裂变式创新理论。

他出身河北军人家庭，本硕都在军校，曾是“红客”国家队成员。上班时大量泡论坛，对创业兴趣极浓，钱只是副产品。刚离开单位时并不慌，因为很多信息都在佐证决策。创业在他眼里不是救急，而是强者释放能力的过程；好创业者见过大钱，不被小成功迷住，逆商高，面对失败稀松平常。作为资深创业者，他知道该具备什么品质能力，遇到对的人才合作，能降低失败概率、加速成长。

他也强调，创业除了攒能力，还得有勇气。《生财逆袭者》的作者专门约他做访谈，聊了一路经历和心得。评论区有人整理了详细笔记，也有人感叹这期视频有力量。近十年孵化20多个项目，这些经历对不少创业者都有参考价值。
