# 创业公司凭什么成事？

前阵子，我正式推出了「龙哥盟私董会」，面向月收入在 50 万到 1000 万之间的龙哥盟圈友，帮助大家建立更深层的连接、实现跨行业融合。具体介绍都放在置顶文章里了。

手头的事情已经排得很满，我为什么还能腾出精力来做这件事？

原因在于，团队里来了一位新伙伴。有了他的加入和配合，我对「龙哥盟私董会」成员能够获得的价值有了更扎实的把握。既然对这份价值足够有信心，那就没有理由不行动。

这位新搭档是什么来头，又为何能成为我的合伙人？

我专门邀请他写了一篇内容，从自己的视角谈谈“创业公司靠什么能干成”。他很快交来一篇万字原创长文，全文 11000 多字。希望这篇分享能给各位赚钱圈友带来一些启发。

说实话，发布之前我又读了一遍，再一次被内容触动。
