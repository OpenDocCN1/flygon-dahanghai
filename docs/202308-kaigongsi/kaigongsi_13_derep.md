# 草根创业股权避坑实录

有人说，听了再多道理，日子还是过不好。问题往往出在讲道理的人离你太远。如果分享者就是你身边的圈友，这些经验大概率能真正用上。今天这篇分享，就是一位草根创业者用真金白银换来的股权教训，想创业和已经在创业的人都值得花十分钟看看。

分享者Richard，也叫颜过。他2008年开始做外贸电商，也就是后来被称作“跨境电商”的行当。独立站、eBay/wish、亚马逊、独立站/shopify这些热门平台基本都碰过。最近做的一个亚马逊小家电项目，10个月从0做到2000万人民币，两年半累计销售额破亿。前后合伙或创业5次，踩过不少坑，这次重点讲的是股权和分红合作里的那些雷。

**第一次创业：股权和经营权混为一谈**

2011年，他和大学同学X做婚纱礼服独立站。自己占51%，负责资金、营销、供应链，全职干活但不拿工资；X占49%，只负责技术，而且一直上着班，直到散伙。表面看散伙原因是流量成本暴涨、不怎么赚钱了，但后来才想明白，根子不止这里——经营权（该拿的工资）和股权没有分开；股权分配凭感觉，没有考虑双方投入的时间、资金和创业心态；X明显是打工心态，和创业心态完全两回事；两人长期没在一起办公，沟通出问题，错过了流量红利期。

**第二次创业：分红比例一次给太满**

散伙后自己单干。他用“10%分红+高工资”从前同事里招来H，负责Google广告投放，能力没话说，但最后还是把人请走了。问题出在哪？创业公司盈亏平衡点还没算清楚，就盲目扩大，也没给考核目标，公司账目糊里糊涂。正确的做法是先谈好预期，设定目标，再逐步释放分红。比如承诺10%分红，可以分两三年给：前期4%、中期3%、后期3%。这样公司财务压力小，也能和有能力的人一起成长、共担风险。

**第三次创业：亲戚的钱，烫手**

为了补充现金，公司引入两笔亲戚资金。L比自己大10岁左右，传统行业老手，事业有成，懂生意有赚有亏，投100万占20%；W比自己小2岁，也做过生意，说手里有闲钱，投30万占6%。婚纱礼服是先收款再投入，4月旺季来了，虽然引流成本上升，公司还是有利润。10月小旺季一过，到12月收入就惨淡了，小亏一点；接着1、2月春节，国外需求也不旺。自己提前跟两位打过招呼。但W这时说家里急用钱，要抽回本金，还要把第四季度分红分了。其实当初白纸黑字写着资金至少放满两年，分红按季来，也可能根据情况延期。可那时公司已经做了亚马逊，先投入后回收，大量资金压在货上，流动资金根本不够。W觉得公司要垮了，怕亏钱，非要立刻拿回本金和分红，甚至闹到自己家里。实在没办法，只好找L商量，让L接盘W的股份，自己再折价补贴L一部分。教训很直接：亲戚不能随便合伙，更准确地说，没有生意常识、没有盈亏承受力的人，绝对不能合伙。

**第四次创业：和工厂合作，连环踩坑**

随着平台、流量成本、品类不断变化，他决定把公司做大，做小家电大件产品，和工厂FY合作CM-AM项目。这个项目是L的老朋友LXH介绍的，LXH和工厂股东C已经认识十几年。为什么转型？因为过去外贸采购就是低买高卖，没有客户沉淀，看看兰亭集势的股价就明白了。以前跨境电商多做小件或定制类，多少有点灰色，婚纱礼服也是借国外款式起来的。现在和工厂合作做大件，门槛在资金、周转、供应链，同时背靠亚马逊，从商标慢慢做成垂直小品牌。

项目背景：自己占初始19%的股份（因为亚马逊账号不能一人多开，暂时找工厂的人代持）；工厂FY占51%，股东G是中山本地人、改革创业第一代富起来的，C和自己同龄；传统外贸出身的K占30%，K一直在大型外贸厂做业务总监，没创过业；注册资本100万。

前半年自己全职在公司，拿基本工资。项目到第6个月时，工资拆成两半：一半正常发，另一半由G和C以私人借款的方式给，说好以后从自己在公司的净利润里抵扣。当时没多想，觉得都是十几年朋友，对G、C来说也不是大钱，不会被坑。但正规操作应该是向公司借款，这成了后面的雷。K主要精力也在公司，但没全职过来，所以不拿工资；G和C参与运营，但主要精力还在工厂，也不拿工资。

项目发展超出预期，尤其自己负责的跨境电商板块。G提议把办公地点从工厂搬到镇中心商业区，而且没经过自己同意，就说要把公司从“中山市XXX有限公司”改成“广东XXX有限公司”，注册资本从100万直接放大到1000万，股权比例不变。这些是变更完成之后自己才知道的，之前只提过一嘴，还以为要自己签字。这次增资，自己和K都没有补足股本金。工厂通过新公司向工厂采购货，再用还款等操作，项目进行到一年时，陆陆续续完成了工商局的股本金注入。手段其实就是：增资扩股，小股东拿不出那么多钱再投入，被逼放弃股份出局。

项目第一年下半年，K的传统外贸业务急剧萎缩，连续三个月亏损。K对新公司的贡献是兼着亚马逊品牌采购，但外厂产品质量问题频繁。大股东G觉得K整体不行，想清退他。手法给三条路：要么补齐300万股本金，要么拿走初始投入本金和当前分红，要么让K全盘接手工厂FY占公司的51%股份。说白了就是大股东说不干了，让小股东接手；小股东资金实力不够，只能放弃一切出局。

期间G还找过自己，说如果K不出局，就想重新注册公司，清算现有公司。财务一直是工厂FY把持，K出局后自己来运营整个公司，财报上显示亏损：亚马逊退货率增加，利润率下滑，工厂说这很正常，因为证书认证可以掺水，小家电人工组装也免不了出问题。自己去广交会找其他工厂同类产品，发现FY的报价比同行高出30%-50%，即使有私模，制造差异也不该这么大。最终自己也出局了。手段是：从财务上把亏损做大，小股东要承担亏损，承担不起，只能放弃股份。

接着，亚马逊成本上升，产品质量问题进一步暴露，之前K留下的产品还在清货，财务报表连续三个月亏损，国外库存还有很多。G又坐不住了，打着财务合规化的旗号，想把工厂连同跨境电商公司整体打包上市，需要三到五年。既然要上市，就不能亏损，业绩要按上市标准往前推、做大。可是经过K找的外厂产品，整个小家电大类目，如果把所有投入放在亚马逊上问题很大，放得越大风险越大，毕竟平台是别人的，规则由别人定。按现有品类和亚马逊单一渠道，业绩根本完不成，G和C又不同意拓展其他渠道，只能继续亏。第四个月，G建议结束新公司，用了之前对付K的套路。这时自己的股权已经从19%变成30%了。手段就是：大股东给小股东制定根本完不成的业绩，逼小股东走人。

他在这项目里投入了巨大精力，孩子都养大了，不可能平白放手。K的传统业务能带走客户，但跨境电商项目带不走——货、品牌、账号都在公司。之前提到的私人借款这时成了雷。G和C见他坚持不退，先做亏损财报，再解散公司人员，还向深圳法院起诉，说他不还私人借款。

**教训与建议**

回顾和工厂合作的全过程，他从始至终都没占到主动权。这些坑希望能给大家提个醒。过去合伙或合作，说到底都是人的问题，就像天使投资，投的是人。但制度上的防范也不能少。

有两条路可以参考：要么直接拿风投的钱，自己占比小，不要对赌——这几年跨境电商对赌很多，有赌赢的，也有赌掉所有的；要么自己做项目，100%持股，先做到盈亏平衡、有可估值空间时，再慢慢释放股权。

最后，他分享了一套天使投资股权分配表的思路，要同时考虑人的能力和资金成本。公司股权有几条生命线：

1. 占股份67%以上，老板对公司有完全控制权；
2. 51%，有相对控制权；
3. 34%，股东有一票否决权；
4. 20%，股东要界定同业竞争权利，不能做同类项目；
5. 10%，股东可以申请解散公司。

评论区里有人总结：合伙创业前要先小人后君子，责权利清晰，切忌哥们义气和盲目投资。也有人感慨，就算知道大股东赶走小股东的手段，小股东往往也没办法，只能接受。颜过本人回复：小股东要选好人、站好队，实在不行，跑。
