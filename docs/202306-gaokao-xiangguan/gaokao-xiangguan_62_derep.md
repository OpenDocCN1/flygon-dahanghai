# 高考花摊，卖的是好彩头

高考临近，校门口摆花束也能做成一个小生意。真正有意思的是，把花束价格和高校标签挂上钩：985、211这些数字一出现，原本普通的花摊立刻有了记忆点。家长想讨个好兆头，孩子也愿意图个吉利，在一排花摊里自然更容易被吸引。换个角度看定价，生意眼界一下就打开了。
