# 高考志愿，一个入口查明白

填志愿要对比的东西不少：院校怎么挑、专业怎么定、分数线在哪、招生政策有何变化，甚至性格适配也值得参考。夸克浏览器里的“夸克高考”把这些维度收进同一个入口，为学生提供填报指引。

做高考相关内容引流，或者承接志愿咨询付费，这个工具都挺适合拿来用。
