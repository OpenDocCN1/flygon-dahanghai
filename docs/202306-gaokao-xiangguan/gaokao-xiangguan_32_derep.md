# 高考后，7个隐蔽机会

高考结束，除了放松，还能做什么？从考完到大学报到，这段时间其实藏着不少可以切入的小生意。别只盯着分数，下面这些方向值得留意：

1. 志愿填报咨询与陪跑：帮考生和家长梳理院校、专业和填报策略。
2. 兴趣性格与职业方向测评：用问卷或测评工具，帮学生初步判断适合的专业和职业。
3. 经典读物与小说推荐：比如《明朝那些事儿》《如何读大学》这类书单内容。
4. 抖音内容讲解或流量承接：把上面这些内容拍成短视频讲解，或者借高考热点做流量截流。
5. 本地高校新生入学攻略：整理所在地区大学的报到、校园生活等指南。
6. 用户沉淀后的付费服务：做深度规划指导；入学物品快递直送；推出新生开学用品组合，如水杯、被褥、脸盆等。
7. 旅行相关服务：旅行建议、特价线路、家庭出游、校园参观、同学结伴旅行。
