# 2.3.1 专项性管理：聚焦一个领域，把资料管透

上一节聊完了资料的“整体性管理”，有朋友反馈说，这套体系搭建起来工程量不小，想知道有没有更轻巧、更聚焦的切入方式。

顺着这个需求，我们来看“专项性管理”。它的核心思路并不复杂：围绕某个特定领域，进行信息汇聚与资料梳理。

和整体性管理一样，做专项性管理之前，也需要先把目标想明白。从我的实践经验出发，常见的诉求大致分为两类：

一是出于深耕的考虑。想比较系统地吃透某个方向的知识与技能，借此提升自己的专业水准，甚至奔着成为该细分领域的行家里手去努力；

二是出于变现的考量。希望把该领域的相关资料做一次完整盘点，为后续的商业化运作打好底子。

如果你恰好也有这类清晰且聚焦的诉求，那就可以试试下面这套管理逻辑了。
