# 第二步：搞定云空间 / 知识库基建 @洛羽

资料到底放云空间还是知识库？这个不用太纠结，主要看自己平时更习惯哪种方式——一般情况下，二选一就够了。

从我自己的使用经验来看，我更推荐用知识库来当资料总库。原因很简单：在内容呈现和二次编辑上，知识库都比云空间更灵活、更方便。

**1）知识库基建指南**

具体操作非常直接：

- 从“云文档”进去，找到“知识库”，然后点击“新建知识空间”。
- 如果后续打算收集和整理的内容量巨大，一次性建三个知识库也没问题。不过对新朋友来说，先从一个库开始更稳妥：刚开始资料少，硬拆成多个库反而麻烦；等以后内容变多，再按需拆库完全来得及。

![](img/b1426a249b1471aa2742d9eb891ae34a.png)
![](img/10451ee7c412a37b37b3059c44fb41c3.png)
![](img/b03b82c5255fcecfd4bd91c3b1457cc0.png)
![](img/735bd06793eec04d08264556e982e174.png)

- 创建时，把知识库的名称、简介、封面一并填好：
![](img/d917bb74e91ef8bbdb96e32f99edd1fb.png)
![](img/a5a3709ab1a3c3110b60be19a5c6ee9d.png)
![](img/43a60c254b9847df5447ad72ec6c4a39.png)

- 访问权限记得选“仅知识空间成员可见”，别把内容设为全网公开：
![](img/8661bd28d6668bcc1ac89c991cbb965a.png)

- 接着把知识库的目录结构理清楚，主目录、子目录都安排到位：

到这里，飞书知识库的资料库基建就完成了。我还准备了一个飞书知识库模板，可以直接照着用：人生资料库模板。

**2）云空间基建指南**

这套操作更简单：

- 先打开“云文档”，再进“我的空间”，然后选“新建文件夹”。
- 主文件夹建议建三个：认知、决策、操作，三类资料各放一处：
![](img/2bbafeb2f9c57817f701fc2b51387fa1.png)
![](img/0d8534ca82d225e8f4ca6ffb071a77d3.png)
![](img/244bbec94261b1ff6b320f23aa6141fe.png)

- 每个主文件夹里，再分别建好对应的下级文件夹；二级分类推荐用 001-010 来做前缀，排序更直观：
