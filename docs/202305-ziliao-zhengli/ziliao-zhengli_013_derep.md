# 2.1 资料管理做不好，卡在哪？

上一章我们聊过资料管理到底是什么，也说明了它为什么值得做。看完之后，大家应该已经明白：资料管理不是可做可不做的小事。

那接下来就绕不开一个问题：为什么不少人一上手资料管理，就总是做不顺？

结合我自己的观察，最关键的一条是：不会给资料分类。再往深一层说，其实是对资料本身不够了解。

人类一路走到今天，靠的是边做事、边积累，慢慢存下了大量经验与材料。最早靠口耳相传，后来把字刻在龟甲、石头上，再往后用兽皮、纸张、竹简记录，直到进入数字时代。我们保存、传递和积累信息的能力越来越强，如今几乎不用太担心经验和信息会失传。

我们常常感叹，现在信息太多、知识更新太快，让人焦虑。可这种压力并不是今天才有，历史上一直都有类似的情况。

面对数不清的文字和材料，若不是每个时代都有人愿意去做梳理、分类、编撰和归档，那些古老的经验很难一路传到今天，更不会成为全人类共享的财富。

从人类管理和使用资料的经历里，不难看出一个规律：给资料分类，是处理信息与材料的第一步。甚至可以讲得更直接一些——“分类就是知识本身”。

确实如此。一个人要想把大量资料整理清楚，前提是TA真的理解这些材料，然后才可能把它们分门别类、各归其位。

这也解释了一个现象：从古至今，能把资料管理做好的人，大多都是读过很多书、见识很广的人；同样，这也是许多人明明想做资料管理，却始终做不好的根本原因。

看到这里，可能有人会有点泄气：如果自己过去没有大量阅读，也没法很快理解手头的资料，是不是就做不好资料管理了？
