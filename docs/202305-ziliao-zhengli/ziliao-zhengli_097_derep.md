# 案例三：精华帖搭出项目知识库 @七小

各位生财圈的朋友，大家好，我是七小。

初到生财那阵子，我写下过一篇文章：翻阅百余篇精华帖后，我整理出了一套赚钱知识框架，并把它做成了给新人的超全入门指南。

那篇内容完成后，我又冒出一个念头：既然“赚钱知识体系”能单独成文，那“项目知识体系”是不是也能写一篇？这篇内容因此而来。

全文会围绕下面十二个问题展开：

一、项目全景：到底有哪些项目？
二、项目公式：205个项目的名称里藏着什么规律？
三、生财风向标：为什么说风向标里藏着赚钱密码？
四、项目变迁：以【虚拟资料项目】为例，看项目更替的历史规律
五、收入方式：同样是为了赚钱，兼职、副业、创业项目差别在哪？
六、蓝海挖掘：一个蓝海项目该怎么找？
七、项目挖掘：怎样借关键词找到项目？
八、项目挑选：如何锁定适合自己的项目？
九、项目判断：一个项目行不行，该怎么看？
十、项目验证：项目的MVP该怎么做？
十一、项目执行：怎样把精华帖里的项目真正落地？
十二、项目放弃：我们为什么会错过赚钱项目？
