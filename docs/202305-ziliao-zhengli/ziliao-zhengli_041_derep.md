# 3.3 资料库怎么建

💡

想把资料库真正用起来，别急着先挑工具。更稳妥的做法，是先定规则，再一步步落地。

先想清楚：这个资料库给谁用、主要解决什么问题、以后会放进哪些内容。范围越明确，后面越不容易变成“什么都有、什么都找不到”的杂物间。

接着设计分类。分类不必追求大而全，按使用场景或主题拆成几个稳定的大类即可，层级尽量浅，避免点开五六层还找不到东西。命名也要统一，比如日期、项目名、版本号用固定格式，让人一眼看懂。

然后选工具。团队协作就优先考虑权限、共享和检索能力；个人使用则轻量、顺手更重要。工具只是载体，规则才是骨架。

资料入库前，最好做一次简单清洗：重复的合并，过期的标注，重要的补上来源和标签。标签和索引不用一开始铺得很大，围绕高频检索需求设置就够了。

别忘了权限和备份。谁能看、谁能改、多久备份一次，提前说清楚，比事后补救省心得多。

最后，资料库需要维护。定期清理无效内容，更新分类和标签，把新增资料按规则归位。坚持一段时间，它才会从“存东西的地方”变成真正能提高效率的资料库。
