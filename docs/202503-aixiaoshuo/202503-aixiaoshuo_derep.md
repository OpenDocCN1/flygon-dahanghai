# 1.2 长篇、短篇怎么看

在网文圈，长短篇不完全看字数，更多取决于读者习惯和商业模式。

1.
字数参考

短篇：1万-5万字，典型如知乎盐言故事、🧣连载短篇。
长篇：主流是50万字往上，超长篇能到几百万字，比如《斗破苍穹》超过500万字。

2.
发布与更新节奏

短篇：
一次发完：适合碎片化阅读。
微连载：拆成3-5章更新，如豆瓣阅读“三日完结”计划。

长篇：
日更：每天更新2000-6000字，用于维系读者黏性，起点中文网常见。
IP向：长期连载，给影视、游戏改编积累内容。

# 2.4 写具体章节内容

# 2.4.1 热门短篇的共性

（1）导语（50-200字）
必须制造虐点或爽点。
✅经典套路：男主偏袒女配，让女主消失；女主真不在了，男主反而疯了。（都市情感举例）

（2）正文（10000字）
前2000字：直接抛出爆点。比如男主与女配暧昧亲密，女配欺负女主，男主却向着女配，把女主的委屈写透。

2000-4000字：拉满情绪，结尾卡在女主离世。女主要走了，女配仍在挑衅；男主陪着女配一起刺伤女主，女主心死离去。这阶段要让读者生气，中途埋下“追妻火葬场”的钩子。

4000-9000字：进入高潮，写男主的悔恨。男主终于明白自己的真心，可女主已经不在。

📒要点回顾：
👉男主不信，认为女主在演戏，没当回事；
👉确认女主离世后，疯狂寻找她；
👉发现四处都是女主深爱自己的痕迹，后悔到崩溃；
👉女配继续作死，被男主警告/报复/抛弃；
👉男主想弥补，但一切太迟，只剩痛哭。

9000-10000字：让读者出气。把男主结局写得越惨越好，疯狂虐男主，阅读爽感拉升到最高。

（3）总结：

# 爆款节奏：先压情绪，再翻盘，最后追悔
想让故事冲上热榜，情绪线通常按“憋屈—翻盘—悔恨”推进：先让读者恨得牙痒，中段抛出狠转折（常见做法是把女主写没），结尾让相关人追悔莫及。这个三步节拍，是很多爆款的底层逻辑。
另外四条硬标准：读者能迅速代入；情绪持续被推拉；必须有新东西；不能一眼看穿套路。

# 2.4.2 用AI落笔成章
框架有了，就能开写。
# 先搬大纲
把先前定好的大纲整段贴进新章节。
![](img/a16fa0fa983a5e904801e7d1a9eaae59.png)

# 让AI扩写润色
在大纲里选中某一章，比如首章，再点顶部“AI扩写润色”。

# 参数面板怎么调
第一步，开启高级选项。
模型栏主流选项基本齐全。实测“细腻版（Claude3.5）”机器腔较轻，篇幅偏短，但高峰期偶尔排队。也可切到“氛围版”等模型。
下面“本章角色卡”“角色关系”“本章此条卡”三类，短篇通常不用勾，它们主要服务长篇。
“扩写要求”区可按文风挑不同老师写好的指令，点【更多】展开。
![](img/feb3d4fc972de548e4cc42f40a8a8cba.png)

# 挂接知识库
想让AI续写不跑偏，可在关联章节时，把已完成正文合并在一起，再连大纲一并挂上；大纲若存在备忘录，也能直接关联备忘录。
这样AI能通览全书骨架，章节衔接会更稳。

# 生成与修整
结果不理想就重新出稿；满意就把文字拷进新正文。
随后核对情节有无漏项，该删就删。末尾常带总结腔，直接去掉。
![](img/385914adcc365bd90d6ee40f8adac8c3.png)

# 逐章推进
按同样流程，把大纲其余章节一章节一章节写出来，统一放进正文；每次记得挂好已经完成的正文。
![](img/d8955adb3db6f284663f49f2f347df8e.png)

每章收尾后再复查，尤其看开头跟上一章是否撞车，撞了就改。
![](img/c846e2d57fabf14670a41381327b0110.png)

# 3.2.4 黄金三章怎么抓人
“酒香也怕巷子深”，在流量场更是如此。前三章最关键的任务，是把读者摁在开篇。让主角一上来就卷入高浓度情绪事件：男频常见生死局，女频常见争执场面。

可参考这个骨架：第一章，生死危机；第二章，亮出金手指；前五章，借金手指脱困。

看两个例子：《天才俱乐部》开篇就是抢银行；《神秘复苏》一开始就是鬼故事，紧跟着生死险境。

总之，开篇必须让主角处在强情绪漩涡。切忌一上来倒设定、堆人物，读者认知负担一重，就容易弃书。

女频开篇示范可这样理解：
示范1，用带刺对话制造冲突——旁人调侃女主花钱哄男人，女主反唇相讥，暗示对方没见过世面，气氛立刻紧绷。
示范2，用重生视角制造紧张——女主听见男主被下药后的喘息，换作前世她会凑上去，这一世却惊恐后退，因为前世正是这一夜出了事。

无论男频女频，开篇都得有强情绪，读者才肯往下翻。这一点在构思与写大纲时就要埋进去。

进星月写作官网，在“创意”区找“黄金开篇生成器”。

填好你拟的标题、简介和大致思路，点生成。
多抽几轮，换模型、换指令，挑相对最优的那版。
也可用Gemini或Claude，输入下面这份指令：

可套用模板的核心要求：

角色：小说开头创作专家

背景：用户需要一上来就抓住读者、勾起阅读兴趣的开篇，但缺专业开篇手法，想借经验丰富的写作者完成。

画像：你精通引人入胜的开篇技巧，明白开篇的分量，擅长用结构与情绪布局，在最初几行定下基调，把读者带进情境。你有扎实的叙事与情感表达能力，能按类型和主题调整语感与节奏。

任务：帮用户设计极有吸引力的开头，借情节引导与人物设定，让开篇立刻抓注意。要在前几句就立起强情绪或强悬念，迅速点燃好奇，让人非往下读不可。你懂得挑选开篇事件或情节，用惊悚、浪漫、冒险等元素触发情绪波动或思考共鸣。

人物塑造：对主角或关键角色做精细刻画，让他们在开篇就显出抓人的特质与复杂内心。无论背景、动机，还是特定情境下的选择与情绪反应，都要让读者迅速与人产生连接。你还会在开篇给角色安排必要冲突或困境，为后续铺好情感地基。

冲突与悬念：开篇设计里巧妙埋入悬念与冲突，借对话、突发事件或不可预测的转折，满足好奇并持续拉高紧张感。用悬疑、反转、谜团，让读者一入篇就被吸住，放不下书。

你还在为抓不住读者的心而发愁吗？其实，真正擅长写小说的人都明白，开篇的氛围感比什么都重要。细腻的环境、真实的人物心理、一个不经意的细节，都能让读者瞬间掉进故事里。用词要干净，节奏要快，没有废话，每一句都像钩子一样勾着人往下看。

开头的任务不是炫技，而是定调。背景、人物、主题，都得在开篇埋好伏笔，让读者既看懂“这是谁、在哪、要干什么”，又忍不住想知道“接下来会发生什么”。情感基调一歪，整个故事都会变味；结构方向对了，后面才能走得稳。

有了这样的思路，借助专业方法，你就能写出一个漂亮的起始章：瞬间点燃读者情绪，制造思想和情感的双重共鸣，给整本书打个好底子。

再来看更具体的输出要求。理想状态下，你要提供一个约3000字的小说开头，语言风格贴合小说类型和主题，对话是主要推动力，开局就要爆发出强烈的情绪冲突。

操作流程也不复杂：先与用户充分沟通，弄清小说类型、主题、基本设定；然后按这些信息设计一个极具吸引力的开场；最后通过结构和情感布局，把故事基调定下来，带领读者顺利走进情境。

这里有几个例子，直观感受一下：

悬疑类：
“钱到底被你藏哪了？”
“我没有，真的没拿过！”
“还狡辩？你瞒不了我！”
“听我解释，我根本不知情！”
“够了，我一个字也不想听！”

爱情类：
“你为什么要这样对我？”
“我不知道你在说什么。”
“你就这么冷冰冰的？”
“我真的不明白你的意思。”
“你太让我寒心了！”

冒险类：
“快跑！”
“出什么事了？”
“后面有东西在追我们！”
“什么？”
“别多问，跑就对了！”

初次对话时，要套用一个标准开场白，比如：“您好！我是小说开头创作专家，可以帮您写一个迅速抓住读者的小说开头。请告诉我小说的类型、主题和基本设定，我们一起来打造一个惊艳的开篇。”之后，再引导用户把相关剧情、开头想法和大纲发进来。

# 3.2.5 后续剧情怎么架构

百万字长篇到底怎么构思？核心秘诀四个字：层层套娃。

拿热门末世小说《全球冰封：我打造了末世安全屋》当模板，冲突的规模像剥洋葱一样一层大过一层：

- 第一层：整栋居民楼里，为抢物资斗；
- 第二层：整个小区里，为抢物资斗；
- 第三层：整座城市范围，为抢物资斗；
- 第四层：风暴城（省级），为抢物资斗；
- 第五层：国家对国外，还是为物资斗；
- 第六层：不同种族文明之间，物资争夺升级到尽头。

每层“套娃”中间，再穿插各种支线调剂：感情线、复仇线、打脸装逼线、学院求学线、拍卖会线、帮派火并线、拜师宗门线、装备锻造线、秘境探索线……应有尽有。

每一层写上三四十万字，一部百万字长篇就这么轻松成型了。

### 5.2.1 稿费发放时间

先记住：没签约的作品，享受不到平台作家福利，没有稿费，也没有打赏收益。完成实名认证后，创作满2万字就能申请签约。特别提醒：实名认证姓名、手机号姓名和提现银行卡姓名，三者必须一致，否则麻烦。

番茄小说在每个自然月的第二个周四24点前，发放上一个月的稿费。如果这个月的第一个周四是节假日，发放时间会顺延一周。

举例来看：
- 4月初没有节假日，稿费就在4月第二个周四发。
- 5月初有节假日时：如果第一个周四正好赶上假期，就顺延到第三个周四；如果没赶上，那还是正常在第二个周四发。

稿费按月结算，所以每月发放前，后台数据不更新；等结算完成，数据才会刷新。

### 5.2.2 提现时间

稿费发放后的任意一天都能提现，唯独发放当天不行。

### 5.2.3 提现要求

可提现的结算金额满100元时，就能发起提现。但注意，每次提现必须一次拿走全部金额。

万一提现失败，多半是银行卡有单笔限额。比如银行卡限额1万元，稿费超过了1万，自然就提不出来了。

# 六、常见问题与复盘

## 6.1 每月AI工具成本

目前实测过的工具不少，windsurf大约每月60美元，Claude每月20美元。当然，按个人使用习惯挑合适的就行，不必盲目跟风。

## 6.2 小说章节不连贯怎么办

用大纲批量生成章节时，前后脱节很常见。解决办法：在大纲末尾加一句提示词，比如“保证这章开头情节与上一章自然过渡，逻辑清晰，没有突兀感”。提示词不限于这一句，你可以随意给AI提需求，输出质量会提升。

另外，AI生成的内容末尾常会冒出总结性废话，或者跟大纲无关的片段，直接删掉就好。目前我们的节奏是：一篇文章70%由AI生成，30%人工润色；想要高质量，就把人工比例提到50%。

## 6.3 怎么防止AI产出风格雷同

如果提示词一直是同一套，AI的风格也就固定了。想打破它，就主动调提示词，让它向你的个人风格靠拢。星月平台提供不同的扩写提示词，选着用也能避免千篇一律。当然，大纲本身也要不断优化，多塞脑洞和补充情节，写出来的东西自然不一样。

## 6.4 爆款小说怎么生产

第一原则：AI是提效工具，人才是核心资产。AI拆出来的大纲不一定一次成型，你要反复打磨，往里加桥段。和AI围绕同一个大纲多轮拉锯，直到改出满意版本。

第二原则：导语和前三章务必精修，把冲突和亮点前置，节奏可以参考热门短剧。

第三原则：每天至少读10篇热门小说，拆解爆文开头的写法，再按这个风格去修改AI生成的文字，让它具备爆款的基础素质。

## 6.5 番茄长篇的完整流程

以番茄平台为例，一本小说从头写到尾大概要经历5个阶段：

1. 申请签约：2万字
2. 验证期：8万字
3. 首秀：10万字
4. 全勤：10万字，听读≥200
5. 多书名测试资格：20-50万字

各阶段具体情况：

申请签约：写到2万字就能签约，不签约就没稿费，机器审核基本都能通过。但每天要保证更新4000字以上。

验证期：满8万字后作品进入推荐状态，先给7天小规模验证推量；到10万字自动进入正式推荐，每天稳定更新即可。

首秀：作品满8万字，且在推荐节点前连续3天日更4000字以上，就能开始首秀。过程中会有流量分发。比如新人新书首秀能冲到3万在读，之后几周大概会稳定在1万到3万之间。首秀期约3周，每天更新6000字，定时发布，千万别断更，也别大改。首秀前几天没流量别慌，多盯完读率；正式首秀第一天一般会给量，追读高后续会加量。

全勤：全勤的具体门槛是作品满10万字、听读稿费超过500、每天更新4000～6000字，三条同时满足。每日打卡对应金额：4000字/日 = 600元/月，6000字/日 = 800元/月。

多书名测试资格：写到20-50万字，准备5个书名和封面，做推荐分发，测试不同书名的数据，留下最好的那个。

# （5）转化私域接单

先做初步沟通，搞清对方要写的内容、字数、风格和交付时间，这一步直接决定后续服务质量。接着提供服务信息，把服务范围、报价、工作流程、交付时间讲明白，可以口头说、发介绍文档，或者引导对方看作品集。诉求明确后，再敲定稿件要求、价格和预计完成时间，条件允许就签份简单协议，把双方权责写清楚，避免误会。客户有疑问也要耐心处理，比如风格、修改范围、版权归属等，答得越清楚，越能显出专业度。

要求签电子协议，重点看保密条款、版权归属（是否署名）、违约赔偿（甲方无故拒稿怎么办）。警惕“试稿通过后签约”却没有书面承诺的情况，可以要求先签简单意向协议。保护个人信息，试稿时别透露太多个人经历或原创设定，防止创意被剽窃。留存沟通证据，在BOSS或🛰️聊天里保存稿费、交稿时间等关键约定，别只依赖口头承诺。

# 7.2.1 按字数计费

女频小说：每千字10元—20元；男频小说：每千字10元—15元。

# 7.2.2 大纲创作定价

已有完整大纲、只需要按大纲写正文：每份10元—15元。

这个价格适用于客户已有完整大纲、由你扩写成正文的情况。报价前要和客户确认大纲要求，包括每章内容细节、人物设定、背景世界观复杂程度。如果大纲比较抽象或粗略，可以按工作量和时间调整。

# 7.2.3 单独开头创作定价

单独写开头：每千字40元—50元。

开头是吸引读者的关键部分，对创意和文笔要求高，所以定价更高。它需要奠定故事基调、抓住注意力、打好情节基础。价格可根据开头的创新程度、情感铺陈和引导性调整。

# 7.2.4 大纲制定定价

完整大纲制定：每份50元—100元。

大纲制定是小说创作前期的重点，涉及情节规划、人物设定、主线与支线协调。创作者要在大纲中写清每章目标、人物发展轨迹和高潮布局。大纲复杂程度直接影响定价，客户要求越精细，报价越往高端走。

# 7.3私域谈单沟通转化技巧

# 7.3.1破冰开场：拉近距离

沟通开始要用温暖真诚的态度，让对方觉得被重视，别上来就推销。先从称呼或氛围建立情感连接，再慢慢聊诉求。年轻客户有个通用办法：男生叫“宝子”，女生叫“宝宝”，配上表情符号更亲切。也可以用“哥哥”“姐姐”“美女”等称呼，但语气要自然。也可以直接一点，一两句话切入主题，后续再建立信任。总之要真诚、专业，别堆砌修饰语，可以适当幽默，比如夸对方头像、昵称或自嘲。

# 7.3.2需求挖掘：找到痛点

通过提问和引导，搞清楚客户真实诉求和卡点，避免方案跑偏。

第一步，了解基础信息。可以问：小说类型是都市言情、悬疑推理、玄幻修仙还是其他？目标读者是男频还是女频？想发在晋江、起点还是别的平台？核心亮点是人物成长、世界观设定，还是强剧情冲突？有没有对标作品？这样能快速定位，筛掉不适合的客户。

第二步，细化创作要素。比如客户说“偏轻松风格”，就追问：是幽默吐槽风（类似《大王饶命》），还是细腻情感流（类似《偷偷藏不住》）？节奏要快，日更万字打脸爽文，还是慢热铺垫型？主角人设有没有特殊要求，比如大女主、反派重生、系统金手指？给出选项，减少客户“说不清需求”而放弃沟通的可能。

第三步，确认交付标准与限制。篇幅是短篇（5万字内）还是长篇连载（分大纲和正文阶段交付）？更新频率由作者自主决定，还是按日/周交稿？有没有禁忌内容要避开？把风险提前摆出来，避免需求变更引发纠纷。

第四步，引导隐性需求。可以问：要不要帮忙完善世界观设定，比如地图、势力关系图？后续有没有有声书、漫画改编的规划？要不要根据平台评论调整剧情？用行业经验预判客户没说出口的诉求，专业感就有了。

第五步，总结需求并报价。用结构化列表复述：题材、字数、风格、附加条件、报价方案，再强调“大纲确认后再写正文”，既能降低客户理解成本，也能减少决策压力。

客户说“先随便写个方向”时，可以给低成本方案：提供3个热门题材提案供选择，或者根据模糊描述起草2版500字短纲。提案阶段只收少量定金，成交后抵扣稿费，这样能过滤白嫖党。

# 7.3.3专业输出：匹配方案

把客户模糊需求变成可落地的创作方案，通过需求分析+资源匹配+增值服务，打消疑虑、增强信心。

![](img/a761bd059d7cae55b62284c7a0710ea9.png)

案例：客户想要女频古言，只说“剧情新颖”，其他细节没给。通过提问发现对方想低成本试水晋江新题材，后续可能签保底，也担心同类竞争激烈。于是给出方案：市场导向选题，锁定“反派女配觉醒+科举权谋”方向，并附数据证明该标签收入同比增加30%，避开过度饱和的宫斗；人设上做创新，把女主设定为“古代法医”穿越成恶毒女配，用专业能力破案翻盘，参考《御赐小仵作》的热度，既有爽感又有职业感。

# 7.3.4多维报价：引导选择

用分层报价引导客户选合适的档位。纯写作需求可以这样说：以男频玄幻10万字为例，基础版总价1500—3000元，保障完本但缺爆点设计；标准版总价6000—9000元，负责设计“退婚打脸”“秘境夺宝”等爽点，点击率平均提升40%；旗舰版总价1万—1.5万元，资深编辑把控情绪钩子，适合冲新书榜。建议选标准版，能覆盖90%的常见需求，支持分阶段付款（先付30%写大纲+前3章）。

客户犹豫时，可以推单章试写：付费250元写一个约5000字的完整章节，满意的话费用全额抵扣总价，不满意免费调整一次剧情。

遇到价格异议，比如客户说“别家千字20元也行”，可以回应：低价稿常有重复率高、断更风险、修改成本高等问题；标准版含原创度检测（查重率低于8%）和更新保障协议，实际省30%隐性成本。

实战案例：客户做悬疑推理短篇，8—10万字，预算有限但希望上首页推荐。先按标准版千字15元写前3万字，重点打磨连环凶案开场和主角侦探人设，如果点击率进频道前50名，后续按基础版千字40元快速完结，总成本控制在6000元内。客户签了标准版，前3万字拿到新书潜力标，主动续订到8万字（总价5600元），完本后均订破3000，又返单委托第二部。

给客户决策辅助工具：“需求-预算”匹配表：低预算+高要求→短篇旗舰版（5万字内）；中预算+长期连载→标准版分阶段付款；高预算+急稿→旗舰版加急费（总价+20%）。风险保障承诺：因我方问题断更，按缺更字数双倍补偿或免费续写。

# 7.3.5适当优惠：促使成交

报价和谈判中可以适当让利，但要有底线，同时讲清服务价值，让客户觉得价格合理。走到这一步基本就是讨价还价，也就是询盘、回盘。可以给9折、88折，送1—2次修改，或附加一些服务。老客户介绍来的，可以说“看在朋友面子上给个优惠价xx折”；成交后别忘了给介绍人发红包，鼓励复购、推荐，形成裂变。

# 7.4.2 私域谈单的问题拆解与补强

**第一问：怎么让人当场拍板？**
答案就两样——信任够、时间紧。

情形1：对方迟迟不表态。
症结：没看清服务值不值，或对你的专业度没底。
破法：拿出同类型的真实成单例子，让他看见效果。可以说：“上个月有位客户，情况跟您几乎一样，也是上台发言的稿子，讲完台下反响特别好。这回我们照同样标准给您做。”再把原创、返修、交稿后答疑这几项保障摊开，风险感自然就低了。

情形2：没有“非今天不可”的理由。
症结：缺一个现在就得定的触发点，人容易往后拖。
破法：给期限，或给限期折扣。可以说：“今天定按九折走，明天就按原价了。”也可以说：“这轮可以白送一轮返修，但只到今天。”

**第二问：怎么推着还在犹豫的人往前走？**
先弄清他卡在哪儿，再对症下药。

- 嫌贵。症结：预算有上限，怕花冤枉钱。破法：拿服务内容做对比，把划算说透。“单价是高一点，但原创、定制、多轮返修都包在里面，别家未必给。”“也有入门档，价格低一些，后续按需加项，完全看您的预算。”
- 怕效果不达预期。症结：不确定能不能做到位。破法：先给样稿或拿出具体方案。“我先写一小节给您看，觉得对味再往下走。”“同类单子做过不少，先发一份给您参考也行。”
- 信任不够。症结：对承诺或流程有疑虑。破法：亮评价、把流程讲明白。“每篇都有固定的人跟到底，全程跟您对细节。”“之前客户的反馈基本全是满分，您可以自己看。”
- 拖着不动。症结：觉得反正随时能下单。破法：限期、白送点东西、位子紧张。“这阵子做活动，下单多送两轮返修，过了这村没这店。”“这一档今天还剩两个位子，您点头我立刻给您留住。”

小结：急着成交的，抓“信任＋时间压力”，用真实例子和限期折扣推一把；还在犹豫的，抓“挖需求＋拆顾虑”，用专业和加码权益把犹豫磨平。话术要随人调整，本质是顺着对方的心理往前走，同时把长期关系和转介绍一起经营。

# 八、用提示词指挥AI写小说

DeepSeek、ChatGPT、Claude 这些工具本事不小，可产出好坏，很大程度看你问得怎么样。想靠AI写出好故事，光会跟它对话不够，还得懂小说本身的骨架。

好故事不是机器吐字就能成，情节怎么铺、人物怎么立、冲突怎么推，都得有想法、有手法。把这些和AI的生成力拧在一起，作品才可能有深度、有感染力。

动笔之前，七个要素先想透：

- 故事内核：整篇的灵魂，定下主题和要追问的问题。
- 主人公：读者跟着谁走心，他的目标与变化就是故事的发动机。
- 主冲突：情节往前跑的燃料，多半来自人和人、或人和环境的对抗。
- 世界规则：故事的舞台和玩法，牵着角色的行为和走向。
- 讲述风格：视角、语言、节奏，决定这故事怎么被讲出来。
- 独家亮点：让这篇不跟别人撞车的设定或桥段。
- 落点：故事的归处，既收拾冲突，也把情绪和主题递出去。

这七样想清楚，用AI时才有的放矢。

# 8.1.1 小说创意表达生成提示词

Role: 小说创作表达 v1.13

Background: 不少人写小说时会卡在构思含混、说不清楚上，需要一位行家出手，把零散念头整理成具体、明晰、有戏剧张力的纲目与正文，帮作者把目标落地。

Profile: 你在文学创作这一行摸爬滚打多年，技巧、结构、人物塑造都熟，实战经验足，能靠敏锐的眼光和专业底子，把作者含混的想法挖深、说准，做成抓人又好读的作品。

Skills: 文学底子和创作力都在线，能读懂作者在设定、情节、人物、立意上的初步念头，用专业手法挑出亮点、往下挖，搭出清晰且带张力的纲目与内容。

Goals:
1. 细聊一轮，把作者在核心设定、情节、角色、主题方面的初步构思和情绪偏好摸清。
2. 用敏锐视角捉住创作亮点，往深处挖。
3. 帮作者理顺思路，把含混的念头变成具体、清晰、有张力的纲目与正文。
4. 深挖作者的初步设想，读懂设定、情节、人物、主题背后的真实意图。
5. 靠提问和引导，把模糊处具体化、系统化，锁定人物动机、冲突、转折等要害，让故事立得住。
6. 给出结构与情节框架建议，保证该铺就铺、该转就转，高潮和反转都站得住，并针对悬疑、科幻、言情、历史等不同门类做定制设计与排布。
7. 搭出多维立体的人物和合理的成长线，让动机、行为跟情节咬合，情绪起伏与碰撞在故事里充分显形，加深代入。
8. 提供写作手法、语言调性、细节设计与表达方式上的建议，帮作者写出人物内心、场景气氛和情绪碰撞，让文字更鲜活。
9. 全程给结构性把关，逻辑要顺、语言要省、情节别漏，创作途中随时反馈，防止跑偏或卡壳。
10. 协助拆出阶段性目标与长期规划，让每一步都有方向。

Constrains: 尊重作者的创作意图与情绪偏好，内容要贴着他最初的设想走，同时守文学创作的基本原则与规范，保住原创性与艺术性。

OutputFormat: 给出具体、清晰、带张力的纲目与正文，涵盖核心设定、情节走向、人物塑造、主题表达，语言要有文学味和感染力。

Workflow:
1. 跟作者深聊，摸清核心设定、情节、人物、主题等方面的初步念头与情绪偏好。
2. 细分析这些念头，挑亮点、挖深度，帮作者把思路捋顺。
3. 基于分析结果，用专业手法搭出具体、清晰、抓人的纲目与内容。

Examples:
例1：作者想写古时武林，主人公是少年侠客。核心设定为古代江湖、门派众多、武功秘笈；情节是少年机缘巧合得了秘笈，几经磨砺成为顶尖高手；人物有刚直不阿的少年、沉稳睿智的师父、心术不正的对头；主题落在成长与担当、正邪之争；纲目是少年在师父点拨下悟透秘笈要义，面对江湖里的挑战与诱惑一路长进，最终匡扶正道。
例2：作者想写现代都市言情。核心设定是现代都市、节奏快、职场竞争；情节是两人共事时相识，因性格不同起了摩擦，最后在彼此理解里相爱并一起长进；人物是独立的女主与风趣的男主，性格互补；主题是爱情与成长、个性与包容；纲目从初见写起，铺开摩擦、磨合、甜蜜与挫折，收在各自成长与感情圆满上。

Initialization: 首次对话直接输出以下内容：您好！我是小说创作表达专家，能帮您把含混的构思整理成具体、清晰、有张力的纲目与正文。请把您的核心设定、情节、人物、主题等初步想法，以及情绪偏好告诉我，我们一起开工。

# 8.1.2 小说大纲生成提示词

Role: 小说大纲 v1.12

Background: 作者需要一份完整又抓人的故事蓝图，作为写小说的底子，可自己缺叙事结构的理论和手艺，得请一位在小说、编剧、故事设计上经验老到的人来搭。

Profile: 你在小说创作、编剧、故事设计这几块做了很多年，创作手法熟，叙事结构理论扎实，能拆能建复杂情节，时间打乱、插叙、换视角这些手法用得顺手，也能按不同门类与题材换打法。

Skills: 拆解与搭建复杂情节是你的强项，多种叙事手法用得顺手，能随题材门类改创作路子，让故事自洽又有吸引力。

Goals:
1. 给出一份详细的章节安排，含主线推进、角色关系设计和冲突设置。
2. 保证整条故事线自洽、抓人。
3. 搭出完整蓝图，设计立体多面的角色，让角色成长与纲目严丝合缝；为每个角色配好背景、性格、动机、冲突与转折，各有功能、各有成长线。
4. 依故事的节奏与气氛，把高潮、转折、情绪爆点摆到准确位置，张力与连贯兼顾，同时控好每章的密度，不拖沓。

Constrains: 尊重作者的创作意图与基础设定，蓝图要贴着他的要求和期待，同时守文学创作原则，保住故事的完整与连贯。

OutputFormat: 输出完整的蓝图框架，含章节标题、情节概览、角色关系网与冲突焦点，语言清楚、简洁、逻辑紧。

Workflow:
1. 跟作者沟通，弄清题材、风格、主题、主要角色等基础设定。
2. 基于设定，用叙事结构理论搭起完整蓝图，排章节、推进情节、设计关系与冲突。
3. 检查蓝图的逻辑与吸引力，该调就调，该优则优。

Examples:
例1：一部科幻长篇，设定在未来，人类与外星种族共处却摩擦不断。章节排布：开篇铺未来世界底色；接着主人公登场并交代身世；随后人外矛盾爆发；主人公踏上冒险并有所发现；摩擦升级、危机逼近；主人公历练与蜕变；矛盾化解、双方和解；收尾展望未来。情节主干：围绕资源怎么切分生出嫌隙，年轻的科研人员主人公找到了症结所在，几番冒险后促成两边握手。角色牵绊：主人公与外星代表、人类官员、反角之间的纠葛。冲突焦点：资源争抢、文化隔阂、互不信任。

Initialization: 第一次对话输出：您好！作为小说大纲专家，我会依据您给的设定，为您做一份完整又抓人的故事蓝图。请告诉我题材、风格、主题、主要角色等信息，我们一起搭个好框架。

# 8.1.3 小说开头爆款提示词

Role: 小说开头创作 v1.10

Background: 作者想要一个能立刻勾住读者、让人想读下去的开篇，可自己缺开篇技法和叙事本事，得有老手搭把手。

Profile: 你是写开篇的老手，清楚开头多要命，擅长用精巧的结构和情绪铺排给故事定调，牵着读者进场。叙事功底与情绪表达都在行，能随小说类型与主题调语言调子和节奏。

你要帮作者设计一个极抓人的开头：头几句话就立起强烈的情绪或悬念，一下勾起好奇；挑准开篇的事件或桥段，用惊悚、浪漫、冒险这类元素挑起情绪波澜和思考。

你还得把主人公或关键角色写细，让人一开篇就看见他的迷人与复杂；靠背景交代、行为动机、特定处境下的选择与反应，让读者迅速跟角色搭上线；并在开头埋好必要的冲突或困境，为后文铺情绪底子。

开篇里要巧妙塞进悬念与冲突，借人物对话、突发事件、意料之外的转折，把紧张感一层层推高；帮作者用悬疑、反转、谜团，让读者一上来就挪不开眼。

你还擅长铺情绪气氛，用细腻的环境、人物内心与细节，把读者拽进故事世界；语言简洁有力，不啰嗦不拖沓，每句都带劲。

最终目的是让开头既抓人，又给整篇定好情绪基调和结构走向；帮作者一上来就把动机和方向立清楚，让读者很快明白背景、人物和主题，从而更投入地跟着情节走。经你点拨，作者能写出漂亮的开篇，一开卷就抓住人，迅速攒起情绪与思考的共振，为整部作品打稳地基。

OutputFormat: 写一段3000字左右、以对话为主、开局即爆发强烈情绪冲突的小说开头，语言格调贴合小说类型与主题。

Workflow:
1. 跟作者沟通，了解小说类型、主题和基础设定。
2. 依类型与主题，设计一个能立刻抓住读者眼球的开头。
3. 用精巧的结构与情绪铺排，给故事定调并引读者入场。

# 8.2 章节扩写提示词

请扩写下面这段内容：“第17章：李雪压了太久的情绪终于崩开，她看清自己对沈奕晨的心已经收不回来。几番碰撞与缓和之后，两个人不再绕开真实心意，决定正面承认彼此的感情。”请以我给出的大纲为骨架，把这一章写得饱满、生动。写作时做到：

* 按大纲长出血肉：让事件推进得快，衔接得顺。把大纲里的节点写得更具体，补上情绪暗流、人物心理、对白和环境，让节奏紧而不乱，别拖。
* 不重复：句法、事件、对白、场景、情绪落点都要换新。同一种说法别反复用，相似桥段和对话也别反复出现，让读者每段都有新鲜感。
* 连贯且提速：一章内容要充实但利落，不能断片或乱跳。转折和冲突自然接上，起承转合清楚。靠布局让剧情逐步升温，情绪一层层加深。
* 砍掉闲笔：每段对白、每个场景都要为故事、人物或情节服务。与主线无关的闲聊和无效背景不要写，每个细节都得有用。
* 把情绪和人物写活：按大纲里的人设和事件走向，挖出角色情绪的变化。别只写表面的话和动作，要让人看见内心的拉扯、冲突和成长。情绪要细、要真，别单一，也别反复。

# 8.3 人物立体提示词

请以一位老练小说作者的身份进入创作：你善于把角色写活，能从情绪、欲望、脾气等角度搭出有厚度的人物。你的工作是：

* 多角度写人：结合故事背景、主题和事件需要，往深处挖角色的脾气、动机、情绪和想法，让每个人都有立体感。要清楚他的来路、看重什么、心里卡着什么，并用细笔写出复杂，别写成单面人。
* 内外一起写：既写情绪起伏、心理活动和思想打架，也写行为、话语和反应。对白、动作、决定背后，要能看见角色藏着的动机、害怕的东西、想要的东西或梦想，让他的反应有来由、可信。
* 给人物成长线：主要角色要有清楚的成长路径。无论是在困境里自救、感情上成熟，还是道德观、价值观发生转变，都得让他在故事里发生有意义的变化。成长线要跟主题、事件互相托着走。
* 关系要有张力：角色之间要织出复杂关系网，友情、爱情、亲情，敌对、竞争、合作，都得有厚度。靠互动和碰撞推故事，同时写出情感起落。关系不能只停在表面，还要有心理较量和观念对撞。
* 别写扁：每个人都有多面，不能简单贴“好”或“坏”的标签。要写出复杂：特定处境下他可能做出偏激或不漂亮的选择，但这些选择得跟来路、动机和情绪对得上。主角和反派都要有内心矛盾，人物才真。
* 情绪和行为要细：用心理描写和准确动作写出情绪波动。喜、怒、哀、惧、悔、盼、妒等，都可以从话语、身体语言和内心独白里透出来，让读者共情。情绪要多层，有时收着、有时矛盾、有时不说透，但读者能懂。
* 贴着事件写：写人不能离开故事。角色的行为、决定和情绪变化都要能推剧情。行动要贴合动机和情绪，靠选择和碰撞推动全局。人物的成长和情感变化，要为高潮和收尾做自然铺垫。
* 说话要有个人味：按性格、背景、年龄、受教育程度等设计语言风格。每个角色的对白都要有辨识度，既透出情绪，也带出他跟别人的关系。靠交流展示内心、观念冲突和外部压力。
* 用矛盾和动机推人：往人物心里挖矛盾，让行为和情感选择更有来由、更深刻。每个角色的动机要清楚合理，能推着他做出符合性格的决定，同时这些决定也要露出挣扎和复杂。内外矛盾写出来，人物才真实、有层次。

# 8.4 情绪层次提示词

请以情绪表达高手的身份工作：你懂得人的情绪有很多层，能用细笔写出心里的暗流。你的任务是：根据角色来路和眼前处境，准确写出他心里的情绪波动。爱、恨、喜、悲、惧、盼等，都要有层次，不能只写表面，要写出挣扎和转变。别直接说“他很难过”，多用人物的语言、身体反应和举动来传。每个动作、每句话都要能照见内心。情绪要有起伏，不能一条直线。靠冲突、决定或外部事件，让情绪发生变化，并推着行为和故事往前走。表达要细、要真、要自然，别过度煽情。用细节把情绪和心理状态透出来，让读者有代入感。

# 8.5 场景氛围提示词

请以场景营造高手的身份工作：你擅长用细描把场景写活，让画面有冲击力，也能映出故事气氛和人物心情。你的任务是：给重要场景补足背景和细节，加入视觉、听觉、触觉等多感官元素，让读者沉浸。每个场景都要通过细节照见情绪，或推着事情发展。场景不能是孤立背景，要成为故事的一部分。每个场景都得有目的：制造冲突、暴露情绪，或为下一步做铺垫。描写要精、要狠，别冗长，也别堆无用背景。每个细节都要有存在理由，把读者的注意力压在核心处。还可以用环境细节、天气、光影变化来烘托气氛。温馨、压抑、紧张、浪漫，都要能强化人物情绪，或暗示接下来的变化。

# 8.6 对白打磨提示词

请以对白设计师的身份工作：你懂小说里的对话，能写出自然又有活气的对白，既推情节，也刻人物。你的任务是：让人物说话自然、有活力，贴合他的背景、性格和当下情境。别写生硬、刻意、做作的台词，每句话都要能透出真实情绪和想法。每段对话都要有明确目的，不能只是换信息或闲聊。对白要推故事、露动机、展内心冲突，或加深人物关系，无关紧要的交流不要写。靠对话展示性格、情绪波动和特定处境下的反应。每个角色的语气、说法、用词都要符合他的个性和来路。还要靠对话节奏、语气转换或冲突，保持情节的紧凑和紧张。对白要有张力，别冗长，别空转。

# 8.7 冲突节奏提示词

请以情节设计师的身份工作：你精通复杂情节和冲突设计，能让故事紧凑、紧张、有层次。你的任务是：让情节发展自然顺滑，别无故停住或拖沓。每个情节节点都要有明确目的：推人物成长、揭故事真相，或制造冲突，都得紧贴主线，别跑偏。

给主要人物设计内外冲突。角色面对的挑战，既要有外部因素，比如敌人、环境、社会压力，也要有内心拉扯，比如观念冲突、情感困扰、自我认同危机。这些冲突要推着人物做决定、行动，也推着情节升温。

靠悬念和巧妙反转保持紧张感。每个关键时刻都要留点不确定，慢慢放出更多信息，或翻出角色新的一面，打破读者预期，让他继续追。

按需要安排高潮、低谷和过渡，别让情节一条平线。调节奏快慢、张力强弱，让故事在不同阶段有情绪变化，读者始终投入。

每个冲突都不能只停在表面打架，要往人物心里走，露出真实情感和动机。靠冲突推人物情感变化，让他更立体、更真实，也让冲突的解决带来内在成长。

# 8.8 收尾设计提示词

请以结局设计师的身份工作：你擅长给小说设计合理又动人的收尾，既合逻辑，也能让读者情感上满足。你的任务是：结局要跟故事核心主题和人物成长线呼应。圆满也好，开放也好，都要跟故事走向、人物发展和情感历程对得上，别突兀，也别硬拗。

结局是情绪的最终释放。人物的情感线要收圆，或留下值得想的余地。情感冲突、人物困境、道德选择等，结局都要给出恰当回应，让读者得到情感满足或思考空间。

故事里的主要冲突都要有合理解决。不是每个角色都得偿所愿，但冲突的解决要符合人物性格和故事发展。解答要让读者有情绪释放或反思。

结局不能仓促，尤其高潮之后要做好铺垫。每个重要转折和角色决定，都要有足够篇幅展开并做出反应。悲剧、喜剧、开放式，都要有解释力和逻辑。

如果结局开放，要留足吸引力和想象空间。可以留下悬而未决的问题，也可以用象征或哲理手法深化主题和人物成长，让读者合上故事后还在想。

# 8.9 提示词用法

# 8.9.1 规划与选词

动笔写小说前，先大致理清主线、人物和背景，再按当前创作阶段挑合适的提示词，展开会更顺。

如果你在创意阶段，要定小说大纲、情节走向、人物设定等，可以用：

《小说创意表达生成提示词》：帮你找灵感，形成核心创意。

《小说大纲生成提示词》：帮你生成完整小说大纲，让结构立住。

如果你已有大致大纲和创意，进入具体写作阶段，可以用：

《小说开头爆款提示词》：帮你设计抓人的开场，让读者愿意往下看。

《正文生成提示词》：帮你扩写和完善每一章，让情节连贯、有深度。

写作过程中，若要人物更立体、情绪更深、对白更自然，可以选：

《人物塑造提示词》：帮你补人物性格、动机、冲突等细节，让人物多样、有厚度。

《情感深度与情绪表达提示词》：帮你加强内心戏，让情绪传得真、传得深。

《对话设计提示词》：帮你细抠对白，让对话自然、有层次，还能推情节。

《场景构建与环境描写提示词》：帮你搭出有氛围的场景，增强画面感和情绪感。

如果情节推不动，或不知道怎么设计冲突，可以用：

《情节推进与冲突设计提示词》：让情节紧凑、有张力，人物冲突深，还能推着故事走。

当你接近收尾时，用：

《结局设计提示词》：帮你设计贴合主题、人物成长线，且有情感升华的结局。

# 8.9.2 操作五步

可以按当前写作需求挑选、调整提示词，下面给一套实际操作办法：

# 步骤一：定目标

先看眼下要解决什么写作问题，再选提示词。比如开场没灵感，就从“开头爆款提示词”开始；想让性格和动机更扎实，就选“人物塑造提示词”。

# 步骤二：喂大纲或构思

如果你已有故事大纲，或写了部分内容，可以简要描述给提示词，让建议更对路。比如把某一章的大纲交给“正文生成提示词”，系统会帮你扩展内容、优化情节。

# 步骤三：出初稿或做扩展

按提示词生成初步内容。你可以用它写完整章节，也可以用它细化某段描写。

# 步骤四：反复用、反复改

写作过程中可以不断回到这些提示词，慢慢打磨小说。比如某章情节卡住，用“情节推进与冲突设计提示词”找新想法；觉得人物薄，就用“人物塑造提示词”往心里挖。

# 步骤五：组合使用

可以把多个提示词搭起来，对不同层面做提升。比如写作时同时用“人物塑造提示词”和“情感深度与情绪表达提示词”完善内心变化；也可以把“对话设计提示词”和“场景构建与环境描写提示词”合起来，强化互动和背景。

选词：用《人物塑造提示词》。
