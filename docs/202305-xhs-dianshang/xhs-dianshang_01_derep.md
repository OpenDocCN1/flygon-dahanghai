# 337赞精华帖：小红书店铺6天12W+营业额操作手册

大家好，我是阿成。先感谢亦仁老大，也谢谢生财有术的每一位圈友。进圈这段时间，我接触了大量不同领域的实战案例和过来人经验，信息量非常大，整个人的认知一直在被刷新。更难得的是，还有几位前辈愿意耐心地跟我聊项目、讲创业，给的建议都非常实在，这份情我一直记着。

我目前主要做小红书电商，团队去年11月入局，现在运营着14家店铺，而且还在继续扩量。

这次分享的操作手册，是我们团队平时培训新人的完整资料。整份手册分成四个阶段，每一篇、每一步都是环环相扣的。如果你完全没接触过小红书电商，不用想太多，直接从第一阶段顺序往下走就行。内容之所以写这么细，最初是为了带线下员工时能高效上手，后来发现，零基础的小伙伴只要边看边操作，基本都能跑通。当然，中途要是卡住了，欢迎直接评论区问我。

因为图文量比较大，我把手册拆成了很多独立文档，有些文档里还套着子文档。所以阅读时不用从头翻到尾：你现阶段遇到什么问题，就去点对应的内容，相当于“缺哪补哪”。我建议你用电脑打开，体验会更好。

先把这四个阶段走完，把账号开起来、把基础流程跑通，这是入局小红书电商的基本功。后续我还会单独更新一些玩法，但前提是先把这套路径走顺。希望这份手册，能成为你启动小红书电商项目的一个有力帮手。
