# 单号月入6k：小红书电商实战复盘

我是行一，一个持续学习的实践者，方向是把小红书流量导入私域，做相关教练，也在幕后操盘珠宝私域直营。入局小红书电商两个月，团队净利已经超过十万；流量直营线聚焦高客单，之前做命理和珠宝，命理暂时按下暂停键，眼下把重心放在高端珠宝。

电商直营线搭起来才两个月，五位成员做出十万以上净利。现在不少账号仍在持续出单，折算下来，一个人负责一个号，月均六千左右是能跑通的。二月中旬我才知道这个玩法，第一个账号上线第五天就迎来爆单，于是马上复制团队。分工照着流量团队的路子拆：一组做素材采集和剪辑，一组负责账号客服（我的建议是单人至少管五个号），还有一组承接发货与售后，直营团队就这样跑起来了。

我第一个跑出成绩的品类是内衣。那阵子我把同行的账号几乎都收进对标库，盯了一个月，也做了不少数据比对。不过这个类目如今竞争很凶，甚至还会遇到同行举报。内衣素材本身有流量体质，早期发视频就能转化，现在内容同质化明显，只能持续找新素材、测试新的爆款封面。

目前我把重心转到女装、童装、女裤和女鞋，部分品类握有供应链资源；内容端也从搬运逐步转向实拍，最近还在研究直播和投流。
