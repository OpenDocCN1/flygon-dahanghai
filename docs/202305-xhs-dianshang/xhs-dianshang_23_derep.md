# 小红书有货源开店，半年流水翻倍

2023年3月29日，Jing分享了一段自己的经历：她是一位要照顾孩子、没法按常规方式上班的妈妈，却靠自己闯出了一份能持续做的事业。

她的做法是用个人IP带动卖货，账号人设放在“玩具设计”上，切入点很朴素——给自家孩子做一件玩具。2022年11月，她把小红书店铺开了起来，同时用快团团承接转化，开店第一个月流水就超过10万元；大约半年后，营业额又翻了一倍。

评论区里，Lydia问她是不是得先做出IP再开店，潮州痞子蔡的回复很直接：不用。也有不少读者留言说厉害、受启发。
