# 11.6 总失败？那就再快一点 @刘小排

要是你正被“一直失败”困住，我的回答可能有点反直觉：这其实是好事。你该做的是让失败来得更频繁，然后接着试。

我挺爱打德州扑克。刚开始把它当数学题，觉得赢牌靠算赔率，赔率合适才重注。一年后明白，算概率只是入门，人人都会；于是又觉得关键在 meta game，靠观察表情动作捕捉隐藏信息，判断对手底牌。又过两年才真正懂：决定胜负的是 Mental Game——长时间保持情绪平稳。想稳住情绪，就得“打无记忆的牌”。

有人连输几把冤家牌就急躁；有人连赢几把就手松，筹码不当筹码。这都是业余玩家常犯的错。过去发生的事，无论好坏，你改不了；这一手拿到什么牌，无论好坏，你也改不了。我们能决定的，只有忘掉过去、不怨天尤人，把眼前这手牌打到最好。

做产品也一样。有人做成几个产品就飘了——连续做出多款产品、还次次成功的人，你数得出几个？很少。某些 rapper 在没红时写得出好作品，红了、搬进大房子后，好歌反而没了。也有人项目接连受挫后，开始否定自己，严重到抑郁；生财有术里不少圈友就踩过这个坑。他们都没做到“打无记忆的牌”。

所以，如果你的产品连着做了几款、项目连着上了几个，结果都没成，该怎么办？把教训留下，再试下一次。Peter Levels 就是这么干的，职业扑克选手也一样。

内容来源：《写给独立开发者：如何快速做出产品 MVP》
