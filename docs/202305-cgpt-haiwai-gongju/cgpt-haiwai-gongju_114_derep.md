# 案例十四：数据做成网页，搜索带来流量 @阿杰

很多行业里都躺着一些“沉睡的数据”——它们原本就能从固定数据库中查到。国平老师在《我以前在阿里巴巴的流量方法论》中提过一个很值得琢磨的思路：别让这些信息只留在库里，要把它们做成网页，让搜索引擎抓得到、能匹配关键词，搜的人自然会找过来，流量也就归你了。后来有人把 QQ 号、邮政编码、手机号、天气预报等内容逐一搬到网页上，同样收获了大量搜索流量。

我平时也收集了几个例子：查公司和邮编的 alltwcompany.com、twzipcode.com；还有 twedr.com/scmh/，它把分散各地、不易阅读的医院开放时间、医生诊别资讯、看诊进度和交通信息汇总到一个站点集中呈现，也因此获得了不少访问。

另外，把 API 当作内容来源来搭建网站，也是一条很值得尝试的路子。

内容来源：12 月 2 日《在生财有术开启月入过万的工具站之旅》@阿杰
