# 广告进账，逐项拆开算

上一节已经搭过一个测算框架：把投放平台回传的数据，连同站点侧记录下来的访问行为放进同一套计算里，再根据需求方各自不同的计费口径做反向拆解，最终估出每家渠道究竟贡献多少进账。

这一节换三个切口继续看：展示形态、结算方式、投放匹配，逐项拆开聊。

Adsense 的展示形态大致分两条线：桌面网页中的正文展示位，以及手机端的内容展示位。若以 PRM（一千次检索对应的回报名）来衡量，美、澳、英、加四地的单位流量更值钱，变现效率相对更高。

结算口径里，按点击付费（CPC）贡献的流水居首；投放匹配层面，最吸金的是个性化推荐位，主题贴合型紧随其后。

至于按百万级浏览量折算的进账，不能一概而论地认定华语站点单次点击不值钱、英文站点就一定更贵。关键要看站点主题和受众画像：选题越贴近交易环节，报价通常越高；访客下单意愿越强，变现空间也越大。
