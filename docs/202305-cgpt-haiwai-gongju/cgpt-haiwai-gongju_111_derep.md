# 案例十一：阿杰的定制邮件工具，月入20万美元

常用Gmail的人，或许刷到过GMass这个名字。它的作者阿杰在StarterStory上讲述了自己的经历：这款工具目前每月能带来20万美元进账。

阿杰创业十多年，早在2002年就做过一个邮件相关平台，运营十年后卖掉，随后开始寻找新项目。当时Gmail推出了一项让回信更高效的接口，他顺手给自己做了个自用工具，用来加快邮件回复速度——这就是GMass的前身。

出售公司后他手里有积蓄，于是把不少技术环节交给外包；市面上又恰好有一套现成代码库，可直接用来开发Gmail应用，开发难度因此低了不少。不到半个月，GMass的初版就成型了。

早期功能很集中：群发邮件时，可以在内容里插入占位符，比如用{FirstName}代表收件人的名、用{LastName}代表姓氏。这样一来，每个人收到的邮件都会带上自己的名字，实现个性化发送。无论是发冷启动邮件，还是做活动营销，都很实用。产品面向创业者和销售人员，帮他们更省事地发送冷启动邮件与活动类邮件。

上线过程并不惊艳：先去Reddit发帖，再到ProductHunt做介绍，随后直接上架Chrome应用商店。但“早”本身就是优势——当时同类产品的精细度还不够，所以GMass一推出就颇受欢迎。用户的正面反馈让他更有信心，也促使他把这个尝试性项目升级为正式业务。

做内容时，他起初完全不管SEO技巧，只盯质量，要求至少自己觉得有趣；那时他认为SEO更像套路，容易拉低内容价值。后来回看，他也承认“真香”：好内容和SEO其实可以兼得，若自己一时做不到，也可以交给别人来创作。

另一件他始终重视的事是投放。收入中固定有一部分会拿去做广告；如今每月20万美元营收里，至少10%用于广告投放。长期算下来回报不错，毕竟这个工具单笔利润空间很高。

除了盈利，平台沉淀的数据也是一笔重要资产。数年间，通过GMass发出的邮件超过10亿封，积累下邮件格式、各行业打开率、收件设备等信息。这些数据对邮件营销玩家而言像宝库，能让用户特征变得清晰，仿佛拥有全局视野。

目前团队约20人，分布在世界各地，采用远程协作。
