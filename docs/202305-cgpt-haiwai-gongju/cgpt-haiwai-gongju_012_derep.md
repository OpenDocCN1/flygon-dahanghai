# 2.3 免费聚人，后续变现 @静水流深

有些产品并不急着向用户收费，而是先把免费服务做扎实，把人气和用户沉淀下来，再在后面的环节完成转化。下面这个站点就是很典型的例子：

[`realfavicongenerator.net/api/`](https://realfavicongenerator.net/api/)

不少人第一次打开可能会纳闷：页面没有广告，功能还能免费用，这难道是纯靠一腔热情在支撑？事实并非如此。它真正做生意的地方，藏在接口申请这一步——开发者若要调用他们的 API，需要先留下邮箱；拿到这个联系入口后，团队就可以继续向用户推送其他服务，从而实现后续收益。
