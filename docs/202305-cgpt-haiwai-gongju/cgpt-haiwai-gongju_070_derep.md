# 8.5 玩法五：SEO 流量怎么拿？｜@Lebron @小孟*

SEO 是两个英文词组的首字母缩写：Search Engine Optimization，即“搜索引擎优化”；Search Engine Optimizer，即“搜索引擎优化服务商”。直白地说，它的核心做法是在内容里合理布置关键词，让搜索引擎为内容带来访问量。

这类做法在海外市场的多种流量渠道中很常见，Google SEO、YouTube SEO、独立站 SEO 等都是典型例子。相关教学资料在网上已经相当丰富，我们就不从头再讲一遍。圈友 @Lebron @小孟* 筛选并汇总了一批优质 SEO 博客，下面摘录出来，方便大家直接学习。
