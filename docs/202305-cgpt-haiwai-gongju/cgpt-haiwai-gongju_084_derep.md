# 10.5 同样百万浏览，广告收入为何差几十倍？

先别急着给中文站和英文站贴“单价高低”的标签。圈友@哥飞统计过几类站点，按每100万次浏览折算出的广告费来看，差距相当明显：

- 瀑布流商品图片站：约9500美元；
- 秋玉米：约1656美元；
- 趣味测试站：约1053美元；
- Code4App英文站：约970美元；
- Code4App中文站：约233美元；
- 笑话、图片类站点：约204美元。

可见，不能一概而论地说中文站点击价一定低、英文站点击价一定高。真正起决定作用的是站点主题和访客构成：题材越靠近交易环节，广告位就越值钱；访客的消费意向越明确，点击价值也越高。

内容来源：《龙哥盟 #轻享栏目：做 Adsense 网站赚到 3 万美金的实操经验》
