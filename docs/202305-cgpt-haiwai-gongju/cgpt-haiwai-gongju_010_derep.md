# 2.1 工具App广告变现，为何难再复制？ @龙哥

工具类产品有个先天短板：用户打开次数和停留时间，很难跟泛娱乐产品相比。因此，在Google Play早期规则还没调整时，纯工具产品的收入几乎都押在“饱和式变现”上——这个说法来自刘鹏老师👸号，概括得相当到位。

具体怎么饱和？一边在应用内把用户每个操作环节都设计成广告触点；另一边盯住进程活跃度，主动替用户制造“使用场景”，让用户即便不点开App，也能被动触发产品功能和广告，把曝光频次推上去。常见场景包括：锁屏时，充电或正常锁屏弹广告；应用锁时，引导用户给常用应用设打开密码，用户一开应用就弹出密码键盘加广告；通话时，用户正常拨接电话也会弹出广告。

这套打法很粗暴。到了2018年，Google Play政策逐步收紧，纯工具出海公司的这条路基本走到头，不少公司还因产品被下架吃了大亏。这里要提醒一句：产品一旦被Google Play下架，在Android海外市场翻盘的希望很小。Google Play能识别开发者用马甲包重新上架的账户，再以“账户关联到触犯 Google play 政策的账户”为由，封开发者账户、下架产品；而产品下架后，admob、Facebook等主流海外广告平台不会再返回广告，收入几乎一夜归零。

也正因如此，不少出海公司在海外受挫后，于2019年年初陆续回国，把海外那套玩法整体搬回国内。由于国内没有Google Play这样的平台监管，同样的路子照样走得通，一些公司还做得风生水起。
