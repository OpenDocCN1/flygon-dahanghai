# 3.3 先学竞品，再做差异 ★★★★ @刘小排

对多数龙哥盟圈友来说，这是我最愿意优先推荐的一条路径。原因很直接：一个已经跑成功的竞品，等于替你完成了市场验证——需求真实存在，这条路也走得通。

龙哥盟本身就是一个创业案例宝库，里面沉淀了大量实操经验。大家完全可以从照着做开始，再一步步打磨，逐渐长出属于自己的差异点。

“抄”听起来不够高级，但高级不高级不重要，能打才重要。

看看一些成功公司是怎么走过来的。

Google 并不是第一个搜索引擎，在它之前已经有十家同类产品。它先借鉴了现有搜索引擎，再引入 PageRank 算法，让搜索结果排序更合理，由此形成了差异化价值。

百度借鉴了 Google，也做出了自己的差异点，比如早期主打“更懂中文”。

腾讯借鉴了当时颇成功的聊天软件 ICQ，做出 OICQ，后来改名为 🐧。🐧 给用户带来的差异化价值远不止一点，产品体验比原版 ICQ 好很多，大家可以自行搜索了解。再后来，腾讯推出🛰️，这个想法同样不是原创。

优酷、滴滴、🧣、淘宝、抖音……它们也都是从借鉴起步，再做出差异化价值，最终走向成功。这样的例子很多，不必一一列举。

这套方法的好处很明显，短板也同样明显，至少有两点需要留意：

- 你的差异化价值到底是什么？这是最容易被忽略的问题。
- 你借鉴原版，能不能比原版更懂用户？能不能像 🐧 那样，做出比 ICQ 更好的产品体验和流量渠道？

当然，它还有一个最大的问题：你怎么确定，自己的需求别人也同样需要？

这个问题没有标准答案，也不存在成功率 100% 的创业方法。只能说，采用这套方法，创业成功率会比其它方法高一些。
