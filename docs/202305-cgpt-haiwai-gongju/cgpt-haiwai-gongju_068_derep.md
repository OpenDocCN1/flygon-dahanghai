# 8.3.3 子母账号涨粉法

如今 ins 的审核力度不断收紧，像以前那样一天狂 fo 六七百人的玩法，很容易触发风控，轻则操作被限，重则账号直接报废。不过上有政策，下有对策，圈里的大神们很快又琢磨出了“子母账号”的组合打法，把批量操作和精品运营的思路捏在了一起。

母账号这边，一切照常，安心做好内容就行，行为轨迹完全像一个正常用户。真正干活的是那一批子账号：它们负责去 follow 那些可能对你感兴趣的人，当有人回关子账号后，再通过话术或引导，把他们导向你的主账号。这样一来，主账号的操作风险大大降低，涨粉速度却一点没慢下来。

关键就在于子账号怎么玩。子账号相当于一枚“诱饵”，先得让人愿意关注它，还愿意顺着它的引导去关注主号，所以子账号的包装必须用心。

先说头像，大多数人直接上美女图，不过也可以根据你自己的 niche 来定。接着是 username 和 fullname，很多买来的账号用户名是乱码，一眼假，必须改成像正常人会起的名字；fullname 也一定要填，这是主页简介里最显眼的位置，可以加表情、换字体，做批量引流的人最喜欢直接写上🛰️号或电话号码。子账号的名字可以跟 niche 相关，也可以直接做成引导关注的样式。

接下来是重头戏——简介。以前大家直接在简介里 @ 母账号，完全没问题，但现在查得越来越狠，只要一大片子账号同时 @ 同一个母账号，这些子号很快就会被端掉。

两个应对办法：第一个是“金字塔标签法”，子账号先 @ 另一个子账号，再由那个子账号 @ 下一个号，一层层往下导，最后才指向母账号；第二个方法更省事，买几个便宜域名，做个简单网页，点击链接就直接跳转到母账号主页。这两种方式都能有效绕开平台的精准打击。

再聊子账号的日常维护：第一，完成 Follow / Like 之后，只要有人回关，立刻私信他们去关注母账号；第二，平时也要发帖，在帖子里带上 @ 母账号；第三，照片本身上也能 @；第四，去同行的帖子底下评论时照样 @。总之，想尽办法把曝光度拉满。

不过所有操作都要克制，核心原则永远是“表现得像个正常人”。至于帖子和私信的内容，既然是批量操作，肯定不能一封封手写，得用 spintax 语法去建一个模板，配上支持 spintax 的批量软件，机器就能自动组合出不同的句子，既减少重复感，又把风险压到最低。
