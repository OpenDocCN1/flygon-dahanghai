# 案例三：图片站靠搜索流量，140万PV赚到1.3万多美元

瀑布流布局因Pinterest而走红，国内随后冒出大量同类型站点。哥飞也想入场，但更在意做出差异。直到Fancy.com进入视野，他意识到垂直方向或许是个切口。垂直站若想活得滋润，得离交易近一些；于是他决定让用户去分享电商平台上的商品图。

验证想法时，他用程序从eBay抓了几千张商品图，搭了个极简展示站。上线后的数据超出预期：收录速度很快，搜索流量也过得去；更关键的是，同样的访问量能换来更高的广告收益——点击率不算亮眼，但单次点击价格高。

进一步拆数据后，他发现访客大多来自图片搜索。当时图像识别远没有今天成熟，搜索引擎判断一张图，主要依赖图片周边文案，以及alt、title这类标签。他会认真补全alt和title，而很多站点要么空着，要么随手填。差距由此拉开，他的页面更容易排到前面。随后他改页面结构，在代码层面把商品图和h1主标题放得更近，而不是只在视觉上贴近；又把标题拆成词、建立索引，每个词单独生成一个聚合页，把标题中含该词的商品图集中展示。结果证明，这套优化很见效。

后来他手头有别的事，账户体系、用户分享、收藏、点赞、评论等更完整的功能便没有继续做。再往后，他拿这套简陋程序换着域名复制出多个站点，全部走垂直路线：一个域名只承载一个品类的商品图，品类包括婚纱、宠物用品、收藏品（如瓶子和钱币）以及女性衣帽服饰等。

做到这个程度，站点本质上已接近垃圾站：除了展示图片，并没有给用户增加多少价值。只是当时看到有钱可赚，他也就没有收手。这些站留不住人，回头客寥寥，流量几乎全靠搜索引擎输送，因此起伏明显。行情好的时候，某个品类词竞争不激烈，站刚上线就能进流量，当月产生广告费，之后几个月收入还持续上涨。其中一个站，前三个月广告费依次是30美元、60美元、110美元，此后基本稳定在每月一百多美元。

最终，这几个站合计约140万PV，广告费却累计超过1.3万美元。
