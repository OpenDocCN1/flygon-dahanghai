# 单群跑出47万成交：一场母婴🛰️群活动复盘

跟各位赚钱高手比，我这点经验确实拿不出手。不过还是厚着脸皮，把以前带团队做过的一次社群活动翻出来说说。那场活动只在一个母婴🛰️群里落地，最终做出了47万元成交。

2019年4月，龙哥盟在深圳办线下聚会，我把这套流程讲了一遍，圈友反馈比预想的好。后来琢磨着，没到现场的朋友可能也用得上，索性整理成一份约3500字的口语版长文，尽量说人话，饭后扫一眼就能看明白。有疑问随时聊，顺手点个赞就更好了——我还惦记着龙珠呢。
