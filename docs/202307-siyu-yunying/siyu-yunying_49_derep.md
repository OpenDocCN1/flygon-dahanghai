# 会变现，也懂打动人的文案如何写

我是李思念，创业九年，算是在实战里摸爬滚打过来的老玩家。外界记住我的个人标签里，文案能力排在最前面。长期以来我坚持更新朋友圈，累计写下上百万字；这些内容在微商与创业社群中被大量转发，也在小红书帮我积累了不少粉丝，相关变现超过七位数。

我有时会觉得，文案真的是一件能改变人生走向的利器。

当你亲手写原创内容，会慢慢在字句之间训练思考，逐渐形成自己的核心观点；这些观点借文案扩散，吸引并打动同频的人。影响力又会反过来强化个人品牌，最终落到事业成绩上。

写了很久之后，去年我给自己这套风格起了名字——「心金文案」，意思就是既能带来商业回报，也能进入读者内心。

文案和普通文章不一样，它天然承担商业转化任务，所以能赚钱很重要；但它也要有情绪、有温度，能让人被触动，因此走心表达同样必要。

二、文案的道与术

三、写作方法体系

四、持续输出能力的培养方式
