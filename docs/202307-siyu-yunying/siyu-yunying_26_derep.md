# 社群留人，靠什么？

圈内精选 · 112 人点赞  
作者：敏敏 🔆  
2021 年 7 月 15 日

各位圈友，先做个自我介绍：我叫敏敏，1997 年出生，水瓶座。在生财的 CP 女团里，我算比较活跃的一员，也在生财的线上志愿团队里帮过忙。到了周末，我不是在参加活动，就是在攒活动：自己操盘过五十多场面向青年成长方向的线下活动，也帮别人落地过五场百人级商业活动。目前我在北辰 YES GO 的广州校友理事会担任副会长；早前在北辰青年 YES GO 第九期广州营地做过运营志愿者，还担任过三节课校园合伙人，并在公益职涯项目 Jobinn 做过营员。

我长期关注各类社群活动，所以今天想把目光放到一个强调陪伴感的成长型社群——YES GO 行动：它究竟怎样运营，哪些做法又能给生财有术提供参照。成文前，@杨涛、@杨星城、@丽丽曾 给过不少提醒，这里道声谢。

先看目录，方便按兴趣跳读。

## 一、先认识 YES GO 行动
1. 它怎么定位，又如何一路演变
2. 新意在哪
3. 价值主张分三层：L1｜打破；L2｜探索；L3｜重建
4. 内容如何交付
5. 谁在负责运营
6. 主要面向哪些人

## 二、YES GO 行动的亮点
1. 把“终身学校”当长期理念
2. 品质把控不放松
3. 关系层层递进

## 三、对生财有术的启发
1. 让会员盘子继续长大
1.1 给分销素材多加一把力
1.2 夜话官要好好培养
1.3 把线下宣传品做起来
2. 用户预期别跑偏
3. 把社群黏性做厚
4. 让品牌多露脸
4.1 品牌广告多投一些
4.2 素材要方便转发
4.3 请龙珠圈友为生财发声
4.4 给圈友更多发圈理由
5. 官方和民间力量一起使劲
6. 用官方手里的资源给项目孵化搭桥
7. 关键节点要留痕
8. 新手村继续摸路子
