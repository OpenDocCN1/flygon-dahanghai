# 视频号赚20W，我的3个月实操复盘

作者：橘子海

日期：2023-04-17

大家好，我是橘子海。2021年加入生财有术，21年底离职，去年年初开始尝试短视频电商带货。目前茶业类IP全网粉丝超过15万，但说实话，真靠卖货挣到的钱并不理想。

去年5月我开始接触视频号，初期玩法和大多数人差不多：用软件选品、发视频，哪个视频有流量就开直播卖货。就这么断断续续干到12月，靠量确实也赌中过几回，行情好的时候一个月赚个几万块。但真正卡住人的地方永远是——选品和素材，这两件事太磨人了。

今年1月，我彻底换了一套打法：不再死磕爆款，不搞视频号小店，也不碰直播。原因很简单，一来是懒，二来是个人精力实在有限——直播对单人玩家来说投入太大了。可让人意外的是，换完之后收入一点没缩水。

选品这方面的干货，星球里已经有大量帖子，我就不重复了，重点聊聊我现在的操作模式，全文已整理到飞书，需要的朋友直接点文末链接即可。

感谢生财有术，让我完成了从上班族到创业者的第一次转身。我初中毕业就进了工厂，也干过流水线，后来自学设计，凭本事进了某行业头部公司，21岁靠自己在小城买了第一套房，期间也背过几十万的债。没学历、没背景、没资源，我的起点可能比圈子里大多数人都低。但不管打工还是创业，我一直都是全力投进去。普通人没什么轰轰烈烈的梦想，无非是多赚点小钱，让家里人过得舒服些。
