# 带长辈玩转手机：直播剪辑与上网技巧

在视频号上，可以做一类面向中老年朋友的内容：带他们学会开直播、做视频剪辑。这个方向还能继续往外扩，把日常上网的实用技能也一起教起来，比如怎样搜索信息、如何查找资料、怎么把需要的内容下载下来，以及手机和电脑的基础操作。
