# 情绪价值，为何越来越值钱

前阵子跟一位投资人交流，我对“格局”这两个字有了新的理解。过去我一直觉得，情绪价值很管用：能让别人舒服、开心，也能做成赚钱的生意。这个判断当然没错，但如果把视野放大，还能看到另一层逻辑。

中国发展到今天，物质条件已经相当丰富，很多人手里有了闲钱。物质需求被满足之后，精神层面的需求自然越来越多，于是有人愿意为“情绪”掏钱。也正是在这样的土壤里，情绪价值才有机会卖出好价格。

作为70后，我对此反应慢了半拍。成长于物质匮乏的年代，我总认为只有干货、只有看得见摸得着的实在东西才配得上收费。可90后、00后早就不是这套思路了。

还有一类人常被忽略：手里有现金、想找乐子的中老年人。他们不只想跳广场舞，也想尝试别的玩法。谁能带着他们一起玩，谁就在供给情绪价值，利润空间同样可观。

抖音上常见的画画课、声音课、书法课、出书课，背后能做到上亿营收。它们本质上并不是教人赚钱，而是陪人玩、让人体验生活乐趣。路径看似不同，归根结底都指向同一件事，但可把握的机会明显变多了。

评论区里，大家顺着这个思路继续聊。有人追问：游戏算不算在解决精神需求？也有人关心，面向老年人的“玩”，还有哪些值得挖掘的点。张存磊提到，会销人员陪老人聊天，本质上也是在提供情绪价值；高杰则提醒，这类做法虽然抓住了老年人的痛点，但不少并不靠谱，甚至存在坑蒙拐骗，靠谱的方向值得寻找。张存磊还设想组织广场舞比赛，通过赛事与一座城市里的广场舞领舞建立联系——这些人正是老年群体中的KOC、KOL。高杰认为，只要提前想清楚变现路径，这件事可以干；若只是单纯办活动，意义就不大。三生分享说，有企业切入中老年人社交创业，用短视频、线上直播课程和老年大学等方式触达用户；参加老年大学的那批人往往有钱有闲，价值很高，值得参考。郭庆军则判断，教跳广场舞这个领域本身就足够大。

换个角度看情绪价值，会发现它不是一句虚话，而是一套随着物质丰裕、精神需求上升而成立的新生意逻辑。看懂这一点，机会自然比过去多。
