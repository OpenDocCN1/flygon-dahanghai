# 5.5 私信引流：别一套话术发到底 @木易 Troy

做抖音私信引流，核心思路是让每次触达都有变化。平台会监控私信内容，同一套引导语反复复制并不可取；像微信、VX以及各种谐音变体，出现次数也要尽量压低。

实际操作时，可以轮换几种表达：

先让对方去主页找联系方式，比如“联系方式放在主页，方便的话可以去看一下”。

再比如，以添加频繁为理由，请对方留下电话或其他联系方式：“最近加人太频繁，方便留个电话吗？”

还可以把“加我”换成“家我”“佳我”这类错别字写法，后面接上号码。

或者做一张表情包，图上直接写“+我：XXXXXX”，发给对方，简单直观。

我的习惯是，同一版话术发五个人上下就更新一次。否则系统一旦识别出重复模式，私信权限可能被限制；七天内连回复都做不了，只能眼看着流量流走。别嫌麻烦，轮换就是保护账号。
