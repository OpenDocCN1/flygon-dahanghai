# 4.1.2 一键掌握近30天全部视频的搜索流量占比

一个个翻看单个视频的数据，确实有点麻烦。其实抖音创作者中心自带“数据中心”功能，能直接查看你所有作品在近7天和近30天内的整体表现，不用再逐个分析了。

具体怎么操作，直接看视频就行：

[151_1676010352.mp4](https://search01.shengcaiyoushu.com/upload/doc/XEb4d9F4WogubixyOM9cMVeen0d/R7fUb1zCOohd50xM8vGcB7c0nFS)

这里要特别说明一下“作品搜索量”的含义：它指的是作品在搜索中被用户看到、曝光出来的数据，并不等于实际的播放量。
