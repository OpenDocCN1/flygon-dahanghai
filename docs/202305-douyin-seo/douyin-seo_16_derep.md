# 抖音SEO：14个关键点

流量聚集之处，往往就是生意生长之地。看清抖音SEO可挖掘的巨大空间后，下面用14个问题，快速拆解算法排名的运行逻辑：

- 已认证账号
- 关键核心词
- 粉丝量及话题权重
- 发布时段
- 内容形式
- 标题与正文
- 内容能否被收录
- 互动表现数据
- 搜索后的用户评分
- 关键词排名优化
- 电脑端与移动端
- 视频封面
- 抖音账号矩阵
- 个性化分发（千人千面）
