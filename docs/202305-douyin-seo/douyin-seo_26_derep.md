# 3.10 让关键词排名更靠前

很多同学都会遇到这样的困惑：视频在抖音里搜某个关键词时明明能被搜到，但位置却偏后，比如排在第十名上下。这种情况下，要怎么把排名再往前推一推呢？

其实方法并不复杂，可以从这几方面入手：

1）如果内容属于合集，记得持续更新，并不断提升视频质量。合集本身的权重会随着内容的积累慢慢变高，排名自然也会受益。

2）适当借助抖加进行小额投放，对账号权重和作品权重都会有正向帮助。

3）换个更有吸引力的封面，说不定就能让点击率明显提升，从而带动排名上升。

举个例子，有位同学之前搜关键词能看到自己的视频，但排在第七名左右。后来他通过搭建合集、持续积累权重，最终成功冲到了第一名。
