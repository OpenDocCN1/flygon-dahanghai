# 3.13 抖音矩阵，真有必要吗？

先给结论：有必要，而且原因不止一个。

布局矩阵，核心无非两件事。第一件，是让搜索结果的曝光位尽量被自己的作品填满，也就是常说的搜索霸屏。这样做有三重收益：

1. 搜索结果里反复出现你的内容，潜在客户更容易觉得你更专业、更可信；
2. 同行没有露脸空间，客户也少了拿别家价格来比较的路径；
3. 账号风险被拆开，像减肥、命理服务这类业务，尤其需要多个号一起分担风险。

起步阶段通常先集中做一个号。抖音单个账号一天最多能发75条，权重又靠持续累积，所以单号运营反而更利于把权重养起来。

第二个目的，是打破人群圈层限制。同一条视频在A号没起量，换到B号却可能跑起来，这跟推荐算法有关；说白了，抖音的流量分发本身就带有概率性。
