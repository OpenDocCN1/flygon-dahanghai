# 2.1 设备与网络要求 @思蒙

**苹果用户**

操作时优先考虑iPhone 7及以上机型，因为抖音平台会对已停产的设备采取一定风控措施。如果手机曾登录过被处罚或封禁的账号，可能会触发设备风控，因此最好选用没有违规历史的手机。

**安卓用户**

安卓机型的兼容性差异较大，只要不是过于老旧、能够流畅运行【剪映】不出现明显卡顿，就基本满足条件。同样地，如果设备之前登录过违规或封禁账号，存在被风控的风险，建议换一台无不良记录的手机。

**网络条件**

如果只运营一两个账号，日常家庭WiFi就足够应对。

但如果是矩阵式批量操作，切忌让大量设备连接同一个WiFi，此时更推荐使用各自的移动数据网络。
