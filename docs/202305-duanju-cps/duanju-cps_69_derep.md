# 7.2 评论区运营：短剧CPS不必引流，但讨论要跟上 @某人周

接触短剧 CPS 的朋友，大多也听过小说推文。很多人习惯把两套玩法直接套用，但在评论区的打理上，两者的思路并不完全一致。

小说推文通常要靠评论区做引导、引流，让读者顺着评论追过去；短剧 CPS 项目则不需要这样，评论区一般不承担导流任务。

那是不是意味着评论区可以不用管？当然不是。视频想冲更高的播放量，进而得到更理想的转化，评论区依然是能发力的地方。你可以主动抛些话题，引导观众回复，也可以提前铺几条出彩的热评，把讨论的氛围热起来。

本质上，这套玩法和小说推文评论区的思路是相通的，底层的逻辑并没变。
