# 2.3 账号定位：先选男频还是女频 @猫柠

做短剧账号，第一步别急着上手剪片，先把定位想明白：你准备发男频，还是女频？短剧大体就分这两个方向，发布前先判断内容归属，一个账号最好只锁定一个方向深耕，别两边都沾。

男频短剧的主角通常由男性担纲，故事核心多是男主从低谷翻盘，靠打脸制造爽感，观众也以男性居多。

女频短剧则多以女性角色为主线，剧情里常会出现有心机的女二号，整体偏情感故事，受众以女性为主。

两个方向各有所长：男频里剪辑尺度较大的片段，容易冲出高流量，但同时也更容易触碰违规红线，甚至导致链接掉失；女频更容易让人产生共情，女主被男主和女二欺负时，评论区往往会更热闹。选哪个方向，可以按自己的偏好来定。

定位还讲究前后一致：账号发的是男频短剧，后续内容也尽量保持男频属性；账号做的是女频短剧，其他短剧同样要围绕女频属性来发，反过来也是一样。
