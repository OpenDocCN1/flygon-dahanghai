# 3.2.2.3 哪些免费，哪些收费？

创作猫里的功能并非全部收费，而是分为免费与付费两类。先划重点：推广类任务不收任何费用——跑完「短剧 CPS」的整套流程，用户无需付费，也不会受到什么影响。

真正涉及收费的，是工具调用、教学观看或灵感内容浏览等部分。具体如以下功能，在实际剪辑过程中会设有一定的付费门槛，但整体短剧推广仍可照常推进：
