# 3.2.2.2 创作功能：在 App 内搞定剪辑

创作猫的一大亮点，是视频创作和剪辑都能在同一个 App 里完成。

在首页底部点开「创作」，就会进入创作猫的创作页面；再点「开始创作」，便会跳转到剪辑界面：

![](img/fb95ff4df2235c4308c85be459ac8c54.png)

![](img/8ca1844908f8c4877ee6a9a31e3f4d10.png)

它的剪辑逻辑和剪映基本一致——熟悉剪映的话，上手创作猫几乎没有门槛，这里就不重复说明了。
