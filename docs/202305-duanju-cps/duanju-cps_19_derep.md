# 平台挑选指南

账号搭建完成后，接下来要解决的就是推广阵地选在哪。如今平台对新手的规则明显放宽，过去那种先授权再绑定的流程，已经不再是必经步骤。

为了省去大家四处搜罗入口的时间，这里直接点出两处可选方向：
• 3.1 麻雀 Matrix
• 3.2 创作猫

把对应应用装好后，应用内会把该平台的剧场频道内容、短视频物料、操作教学、站内公告和收益明细集中呈现出来。推广环节里遇到什么卡点，基本都能在对应应用中找到处理方式。

单一账号能够并行承接若干平台的剧场任务；此外，多开几个号、多试几处，也是可行思路。唯一要守住的底线是：两处入口不要承接同一间剧场的推广。举例来说，假定甲渠道排着 A、B、C、D 四间剧场，乙渠道排着 D、E、F、G、H 五间剧场，唯一交集落在 D。这时在甲、乙两边各推不同剧场完全没问题；只要别把 D 这间在两处重复投放，冲突便不会发生。

更通俗地说：「麻雀 Matrix」与「创作猫」的任务可以同时接，前提是别用单号在两个入口做同一间剧场的推广。

⚠️ 提醒：剧场与剧不能混为一谈。剧场更像一个栏目集合，旗下装着多种作品，比如九天剧场、九州小剧场等；而剧指向某一部具体作品，也就是我们短剧推广要推的那条内容。

先动手熟悉这些入口吧；等海量物料铺到面前，短剧 CPS 这条路才算正式起步。
