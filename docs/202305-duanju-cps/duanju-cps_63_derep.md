# 6.3.3 七步批量混剪法

前两步攒下的素材，接下来怎么真正落地成一条可发布的混剪？按下面七步执行即可。

**第一步，找爆款参考并取台词。** 在抖音搜索目标短剧，筛选最近一天或最近七天点赞量最高的混剪作品，用 CRTubeGet 下载；不下载、直接在线看也行，因为这一步只需要拿到对应片段的几句对白。演示：[4.1.mp4](https://search01.shengcaiyoushu.com/upload/doc/SUYad816hofSjmxGHeWcbjoEnpc/XC2Nb48UsoRFgFxDS9WcUwKLnqb)

**第二步，按台词定位片段。** 打开已拆分好的“分割后片段”文件夹，按第一步爆款的开头、结尾和若干中间段落里的台词逐个查找。把命中的素材段拖进剪映。通常连同台词所在段的前后相邻段一起导入，保证剧情不断线。

**第三步，修剪并命名输出。** 对导入剪映的段落做修剪：只要剧情逻辑还连贯，就尽量剔除没有推动作用的过场，保留有张力的对白。输出时按“开头01”“结尾01”“中间01”“中间02”等命名。若从爆款结尾的一句对白反查，先在“分割后片段”中找到对应段落，把目标段前后一两个段一并导入，再通过抽帧去掉无台词、无作用的过渡，做成自己的结尾片段。演示：[4.2、4.3.mp4](https://search01.shengcaiyoushu.com/upload/doc/SUYad816hofSjmxGHeWcbjoEnpc/EqzobFNNDoy75RxNA7qcSYJznb8)

**第四步，重排中间段落。** 把第三步导出的视频放进新的剪映草稿，把中间段落重新排序。比如原先“中间01、中间02、中间03、中间04”，可调成“中间04、中间03、中间03、中间01”。

**第五步，随机穿插原剧片段，导出半成品。** 从“分割后片段”里随机挑3—4段，尽量避开爆款里已经用过的内容，随机穿插到第四步草稿中。对插入段稍作修整，让前后过渡自然，最后导出整段，即半成品。演示视频只插了一个原剧段，剪得也较粗；实操可以多插几段、处理更细，这一步核心是降重。演示：[4.4、4.5.mp4](https://search01.shengcaiyoushu.com/upload/doc/SUYad816hofSjmxGHeWcbjoEnpc/YWIibMJ2zoYeqUxvcllc1F8HnIe)

**第六步，套去重模板替换素材。** 将半成品导入事先备好的去重模板，把模板里主轨道、副轨道1原有的素材换成它。操作是把剪映左上角媒体库里的半成品拖到待替换素材上，并勾选“复用原视频效果”。注意替换只支持长素材换短素材，所以可能要先缩短主轨道、副轨道1里的视频；替换后再调整半成品时长——替换后，导入的半成品片段会与原先缩短过的素材片段等长。

**第七步，定格收尾并导出成品。** 选中主轨道/副轨道1，把进度条拖到结尾，点击定格，对最后一帧做定格处理；再同步调整音频、视频、贴纸等其他轨道的时间轴，导出后就是混剪去重成品。演示：[4.6、4.7.mp4](https://search01.shengcaiyoushu.com/upload/doc/SUYad816hofSjmxGHeWcbjoEnpc/SvOubyyPOoWi6DxsOQpcJpCBnDe)
