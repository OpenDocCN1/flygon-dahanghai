# 3.1.1 手把手教你注册🛰️小程序账号

先把当前页面截图保存下来，接着在🛰️里打开这张截图，长按识别图中的小程序码即可![](img/544f83ed84e99c10f5a1648b645b4ef9.png)。

进入小程序以后，选择“🛰️登录”的方式完成授权注册![](img/32570a1c793543eecc384911f0a2b918.png)。

然后依次填写昵称、手机号，接收验证码并输入，再设置好你的登录密码![](img/aba414506859aa2ed7aa17d67967e7b8.png)。

提交之后，系统会自动带你进入小程序页面![](img/063d23c3baa1979d900eab195fbdac19.png)。

最后点击底部导航栏的「我的」，能看到个人中心界面，就说明🛰️小程序账号已经成功搞定啦![](img/e3f2879ffbe01683a4abd019b77011d8.png)。
