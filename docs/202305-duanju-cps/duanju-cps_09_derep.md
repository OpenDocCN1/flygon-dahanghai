# 1.2.1 短剧CPS到底是什么？

搞清楚短剧本身之后，再来理解「短剧CPS」这个项目就顺畅多了。

「短剧CPS」这套玩法，说白了就是达人先把官方给的素材做二次加工，再把作品发出去，同时在作品上挂载短剧小程序入口。观众通过这个入口点进去付费充值，达人就能从中抽到分成，整个链路跑下来非常顺。

通常短剧的前几集会免费放送，等剧情推进到关键处，就得付费才能继续往下看。用户一旦开通会员，达人一般能拿到充值金额五到六成的返佣，个别情况下甚至能冲到七到八成。

视频素材这块，基本由官方（也就是你绑定的推广平台）统一提供。达人只需要做点简单的二次剪辑，然后把成品传到抖音、快手，再挂上版权方给的小程序，引导观众点进去付费看完整版，最后按观众充值金额拿返佣就行了。

做过小说推文的朋友应该不陌生，这套模式和小说推文非常接近。不过视频的节奏比文字快得多，短视频的爆发力也更猛，变现效率自然更高。

目前一个比较常见的转化参考是：100万播放大概对应三四千块的收益（仅供参考，实际以转化为准）。

当然这个数字是有波动的，真正决定转化量和收益高低的核心，就两件事——选剧和剪辑手法。

现在短剧CPS的二创视频，主流形式主要有两种：

• 混剪视频
• 解说视频

混剪切片类视频的重点在于做好去重，而解说类视频的命门则是文案。

不过解说类视频目前并不是创作主流，原因主要有两个：

1. 解说类视频制作周期偏长，文案得自己写，对综合能力要求不低，产出效率也就上不去；
2. 有时候文案写得确实出彩，播放量也很高，但转化却很低——比如十来万播放，收益却是零。

仔细想想，问题可能出在：你解说之后，观众会顺着你的思路去看剧。尤其是爽剧，被解说一遍之后，观众反而觉得你的解说更有意思，就不太愿意再付费看原片了，甚至还会等着你继续更新解说。这样一来，既不用花钱，也不用动脑。

综合来看，本手册重点讲「如何制作混剪类短剧视频」，解说类视频的做法就不展开细聊了，学有余力的朋友可以自行探索。
