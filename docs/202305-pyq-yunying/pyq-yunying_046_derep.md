# 2.3.1.3 别晒早起天数，晒点更有价值的

不少人喜欢在朋友圈记录自己连续早起多少天，但这类内容的价值其实有限。除非你同时说明，早起后读了哪些书、做了多少运动，或者坚持下来读完了多少本、体重降了多少，否则读者很容易冒出一个念头：成年人按时起床本来就是日常，这有什么值得特意发出来的？

我以前打卡记录过每日定投基金，差不多每天投入1200元。大家会顺着天数去算我累计投了多少钱，这种打卡带来的冲击力确实更强。

不过放到眼下的大环境里，我不建议再公开晒和钱有关的打卡，像每日定投基金这类内容也包括在内。

更值得做的是那种能带动更多人一起变好的打卡。比如我每天发5条左右朋友圈、和大约10个人交流，已经坚持六年多；你也可以试试每周读完一本书，或者每天跑5公里。这样的记录，比单纯晒早起天数更有意义。
