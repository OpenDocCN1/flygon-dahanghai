# 4.3.1.3 写出让人瞬间认同的观点

不少读者是被我的观点型内容吸引来的。常有人告诉我，读这些文字有一种被点醒的感觉。说到底，我是在刻意做一件事：把大家习以为常的判断推开一道缝。

信息铺天盖地的当下，四平八稳的句子很难让人停下滑动。真正能抓住注意力的，往往是有独立角度、不随大流的表达。常规说法容易被忽略，独特视角才有穿透力，能让人眼前一亮、心头一震。

写观点文案，我认为最关键的一步，是制造一个“顿悟点”。所谓顿悟点，就是读者读到的瞬间，觉得这句话正说中自己，随即产生认同。认同一旦出现，信任也就离得不远了。

操作方法并不复杂：落笔时主动安排两类内容，一是与日常经验相反的看法，二是自己提炼的新说法。新说法不能悬空，必须用大白话拆解清楚。对方理解之后，惊喜感会冒出来，对你的欣赏和认可也会加深。

内容参考：《如何打造自动成交的朋友圈系统》
