# 2.5 关键信息，重复讲才有效 @王子冯

写销售文案，最怕只在自己的世界里表达。先换个位置，把自己当成掏钱的消费者：我买它，最在意什么？把这个答案找出来，再天天讲、反复讲。

卖入口的抗衰产品，顾客心里绕不开三件事：吃着安不安全、口感能不能接受、效果值不值得期待。那就把安全、口感、效果拆开揉碎，持续说、换着角度说。卖课程也一样，用户会盘算：内容值不值这个价？能不能解决我眼下的问题？学完能不能马上用，甚至把学费赚回来？这些疑问，才是文案该重点回应的。卖家用按摩仪、美容仪，用户先担心的往往不是效果，而是操作麻不麻烦、会不会漏电。若用起来费劲，再好的效果也劝退；若省心又安全，才愿意试一试。只喊“效果好、力度足”，远远不够。

所以，别自嗨。先弄清自己卖什么，再弄清用户真正介意什么。想透这一层，广告文案基本不会跑偏。

为什么关键信息要日积月累地讲？因为读者不会像你一样熟悉产品。哪怕经常给你点赞、留言的人，也未必记得你卖的是什么、有什么功能。我们曾卖一款粉色固体饮料，后来推出蓝色款，一位常互动的读者留言：“哇，你们洗衣粉也出蓝色啦？”场面尴尬，却也说明宣传还没真正进入用户心里。关键信息一旦松懈，用户认知就会模糊。

做知识服务，更要把交付内容写明白：读者能拿到什么、你会提供什么。注意，不是拍胸脯保证读者一定得到某个结果，而是清楚承诺你实际交付的东西。用户下单，往往是在为确定感付费。确定感，比模糊的承诺更有说服力。谁能把确定的价值摆清楚，谁就更容易被选择。
