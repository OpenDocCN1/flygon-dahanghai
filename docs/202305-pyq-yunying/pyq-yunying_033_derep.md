# 2.1.8.3 专业感素材，去哪找？

你发出去的硬广也好、软广也罢，背后都得有一类内容托底——能体现专业价值的素材。它们大体可以从四个方向攒起来：用户用完后的真实反馈、把产品知识讲清楚的内容、产品在实际生活里的使用场景，以及你在这个行业里长期做过和投入过的事。

再往下拆，玩法就多了：借日常场景、小故事或观点自然带出产品；把别人对你的评价拿出来分享；讲学员、客户或代理的经历；输出你对行业的判断与价值观；做产品或行业科普；展示包装与宣传物料；发促单型广告；呈现产品效果反馈；亮出团队；晒单；以及其他类似内容。

这些素材具体该怎么写，后面会展开说，详见「2.4 提供专业价值的朋友圈如何制作」。
