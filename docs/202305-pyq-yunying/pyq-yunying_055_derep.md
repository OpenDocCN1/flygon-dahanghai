# 2.4.1.5 第五类：学员/客户/代理故事

这类内容怎么发？先交代人物的基本背景（年龄、城市、职业、身份），再聊聊你们是怎么认识的，接着分享 TA 的付费体验，最后顺势呼吁其他人一起加入。
