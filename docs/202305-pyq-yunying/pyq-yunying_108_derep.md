# 4.3.2 技巧二：先让人放心，再谈成交

想让别人主动点开你的对话框，第一步不是把话术练得多花哨，而是让对方觉得你这个人靠得住。

这也是为什么做销售要修心法，不能只背技法。

一个人如果曾经在高风险投资里亏得底朝天，或者满嘴跑火车，又或者管不住嘴、总把别人和自己的秘密往外说，那文案写得再漂亮也救不回来。问题不在表达，在人品这一关没过。

反过来，能让别人安心的人，随手发点什么都会有人买单；让人不放心的，文案吹得再热闹也难成交。

那怎么练？从最小的一步开始：开口向对方要授权。

比如你想把和某人的聊天截图发到朋友圈，先把截图发过去，再这样问：

“这张截图我能发朋友圈吗？配文想表达的是 XXXX。你方便我就用，不方便也完全没问题，别有压力～多谢啦。”

这句话看着简单，其实有三层作用。

第一，先发截图再问，对方能看清你想公开的具体内容，自己判断合不合适。

第二，说明配文意图。只给对方看截图还不够，还得告诉 TA 你打算配什么文字。否则对方可能觉得截图本身没什么，但你配的文案让 TA 不舒服，或者被你的读者理解偏了。

第三，提前给对方台阶。加上“不方便也没关系，别有压力”，对方拒绝时就不会尴尬。你替对方把顾虑想到了，交流起来就轻松，之后更愿意和你来往。别人在别的场合替你说两句好话，往往比你费尽力气去争取信任更有效。

所以，先把靠谱这件事做到位。人稳了，信任会自己长出来，主动私聊你的人也会越来越多。
