# 2.4.2.6 第六类：晒单，方向别跑偏

如今的大环境讲究一个“稳”字：赚到钱了，越安静越稳妥，别急着公开展示。拿收入去考验人心，或者用钞票点燃旁人追逐财富的冲动，既失分寸，也与当下的规则和氛围相悖。

自2018年开始，我就把“晒钱”这件事从内容里拿掉了。遇到与钱相关的话题，我会把重点放在产品是否好用、客户评价是否够好、复购表现是否够强上：
