# 3.5.1 把话挑明，互动自然来

想让读者动动手指，最简单的一招，就是把你的诉求明明白白写在内容收尾处。

比如一篇长文发出去，你好奇谁一直在看，就在最后补一句“看完觉得有用，点个赞”；想让读者追后续，就请他们在评论区敲个“1”；想给大家留个互动名额，可以说“留言一朵🌹，位置我先给你占上”。

这些表情和动作门槛很低，顺手就能完成，所以大家也更乐意配合。

疑问一：广告互动为什么常常几乎为零？

朋友圈里常能看到这类文案：某门课程由团队里的谁谁谁主讲，想听就来私信。可现实往往是，私信的人少得可怜。原因不难懂——读者担心自己一开口，接下来就被顺势推销。

疑问二：广告互动率该怎么提？

假如你想借分享课程之类的产品，打开一对一聊天的口子，不妨换个写法：

这门课确实值得一听，质量很能打；感兴趣的话，在评论区回复“8”，我把听课链接私信发给你。

这样一来，评论区会陆续冒出不少“8”。等对方主动留下信号，你再逐个私聊，推进起来就顺畅多了。
