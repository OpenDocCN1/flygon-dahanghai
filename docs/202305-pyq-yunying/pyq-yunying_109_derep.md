# 4.3.3 第三招：让私域一直进新人

微信里没人可聊，先别急着抱怨。多数时候，问题出在私域经营太松。我给合格微营销人定过三条年度硬指标：自己写的动态不少于一千条、一对一沟通不少于一千人次、新加好友不少于一千位。这三项没做到，缺聊天对象并不奇怪。

靠免费路径添一百位联系人，其实和没添差不多。想让通讯录始终有活人可聊，就得保证新人不断进来。

我的私域人数扩张，靠一慢一快两条线。

慢线，是把内容平台当长期入口。2018年起我持续写公众号，如今有18000多关注。这个量在自媒体圈不算拿得出手，但我只写垂直实战内容，所以不少人顺着关注加微信，开场常是：“老师，想跟你学，怎么付费？”公众号加上我个人微信约两万好友，每年带来七位数收入，六年多一直稳。我还会做视频号直播，平均每周一次。知识星球也在写：付费那个1690人订阅，做了不到一年；免费那个2851人订阅，已一年多。微博我试过一年多，写得不开心，后来停更，只偶尔更新。不是平台不行，是我和它不合拍；我认识写书哥、迎十里，他们在微博就做得很好。平台是否适合，得亲自试。小红书、抖音、视频号，也可按自己的调性选一处深耕。若你只有自己加一名助理，三个平台基本是上限，能从早忙到晚；若有内容团队，再铺全平台。

快线，是主动进入各类付费社群。我在群里做活跃分子、结交朋友，别人更愿意加我。加上我爱交流，平时认真打理朋友圈，慢慢有人付费，也有人把我带进他们的圈子。我微信约两万人，至少十分之一来自网友自发引荐。这类人很精准：要么长期关注并推荐我，要么直接变成付费客户。

生财有术本身就是付费社群。很多人不只加一个群：你在这里交到朋友，听说他还在别的你感兴趣的群里，很可能跟过去；到了新群，又认识更多人。所以，进了第一个付费社群，后面的社群往往会自然出现。

进付费社群，要留意三类圈子：一是高手圈，里面的人能量强，我在生财有术私董会营收垫底，正好虚心学；二是同频圈，大家水平相近，能互相搭把手；三是你能输出价值的圈子，你在其中算大神，别人想跟你学、被你成交。不少人误以为每个群都该是第三类，于是刚加上好友就推产品，这不对。感知力要强，分清谁值得学、谁适合并肩、谁需要你帮助；边界感清楚，好感与信任才会来。三类圈子都进，成长才更稳。

怎么提高别人引荐你的概率？我的体会是：先把人做体面。认真经营朋友圈，是第一步。别人加我后，我不急着推产品，对方有安全感，知道把我介绍给朋友不会被硬销，他在朋友那里也好交代。另一方面，我在课上会直说：我缺客户，你如果确实有收获，请帮我推荐。我这边不给佣金，也没开通过，想让关系简单些；若你的圈子适合明码谈钱，用佣金激励也未尝不可。做人靠谱、做事有分寸，附带结果就是有人自发介绍。量看着不大，却非常精准，值得长期深耕。

温馨提示：这套方法更适合小而美，需要耐心、感知力和同理心；只追规模、不看营收的话，未必适用。
