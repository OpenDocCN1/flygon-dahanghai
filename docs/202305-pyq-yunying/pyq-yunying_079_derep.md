# 3.3.3 写故事，抓住这三点就够了

动笔写故事前，有三件事值得反复提醒自己。

第一，别把故事写成案件登记表。有人一落笔，就像在填记录：先登记某天发生一事，再登记隔天又添一桩，时间、动作一条条往下排。这样的文字读来干巴无趣。故事不能只罗列事件，它需要创作者去提炼、铺陈和再创造。

第二，让小人物站到舞台中央。以前带学员练笔，常有人一开口就要写马云那样的大人物。我会打趣：身边那些不起眼的人，就不值得你写吗？名人的经历读者往往早有耳闻，也容易产生距离感。写周围的普通人反而更好，他们身上常藏着朴素的智慧，读者也更容易代入。父母辈未必有高学历，可说出来的话常常很有分量。我老家在湖北农村，家里只有两个女儿。亲友们多次劝我爸，别再花钱供我们姐妹念书，他只回一句：“养儿不读书，赛如一头猪。”这话很土，却让我觉得他很有见识。因此，把普通人写成故事核心，才更合适。

第三，别小看情感的力量。有人曾质疑：你总写感情戏，会不会显得档次不高？可放眼电影和电视剧，几乎都藏着感情线。观众买票进场坐两小时，不会只想听人板着脸说教；有情感故事托着，作品才更耐看。在人的所有需求里，情感排在首位，情感故事因此一直有市场。读者学历高低、经历多少，都不影响这一点，它几乎是与生俱来的本能，早已藏在人类基因深处。
