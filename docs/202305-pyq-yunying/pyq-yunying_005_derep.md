# 1.1.1 朋友圈就是免费广告位 @逆熵增者

朋友圈其实可以看作一间开在微信里的私域小店，不需要额外花钱，就能反复触达用户。想让这家店撑得起门面，最先要搞定的就是“朋友圈四件套”——头像、昵称、个性签名和背景图，相当于给店面做基础装修，不把这四样安排明白，后面再多运营动作都容易打折扣。

好友数量则决定了店铺开在什么位置。通讯录里有 5000 人，就像把店开进了人流密集的商业街；如果只有两三百人，那差不多就是藏在城乡结合部的小铺面，再好的货也很难被看见。所以，想让朋友圈真正发挥作用，第一步不是发内容，而是先把微信好友数量提升上来。

内容来源：《普通人如何发好朋友圈》
