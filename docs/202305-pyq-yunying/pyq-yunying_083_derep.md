# 3.4.3 动笔前，先看这4点

想把自己的经历写成故事链，下面几个细节最好提前想清楚。

1）隐私边界，由你定  
就拿前面第二条里提到的经历来说：有人写到自己那段乱糟糟的婚姻，会觉得这属于隐私，不愿意写，那完全可以不写。隐私这件事，每个人心里的尺子都不一样，关键还是看你自己能否接受。我的情况是，早期日子过得鸡飞狗跳，后来慢慢理顺了，所以现在写出来，我觉得没什么妨碍。可如果眼下仍然陷在同样的困境里，那就不太适合写，因为读者很容易读出抱怨的味道。

2）更新频率别太密  
半年到一年发一次，是比较合适的节奏。半年、一年过去，人多少都会有变化和成长，用这个频率来更新，刚刚好。

3）故事链尽量一天发完  
我的建议是，一个完整的故事链在一天之内发完。别今天丢一条、明天再补一条，也不要高估成年人的记忆力——大家往往看完后面就忘了前面。集中一天发完，效果最好。

4）别漏掉人生的拐点  
有些同学不愿意写感情生活，觉得不好意思，或者不想暴露隐私，那就可以写工作上的变化、城市上的迁移。每一次变动，其实都是对你的考验；而你不仅扛过来了，还过得比以前更好。你看，那些精彩的小说和电影不也这样吗？主角总会经历一个又一个拐点，最后成为挺过来的英雄。在自我介绍的故事链里，我们就是主角，也是自己的英雄。
