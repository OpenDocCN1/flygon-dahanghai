# 4.3.1.1 先戳痛点，再落笔

准备发一条文案时，你会不会打开输入框就写？我的建议是，先别急，花几十秒做一次痛点扫描。先看用户真正需要什么，再围绕那个卡点组织表达，内容才更可能产生效果。

单条内容锁定单一核心卡点，不要试图一次讲完所有问题。诉求堆得越多，重点越容易被稀释；把火力收拢到一个点上，表达反而更集中、更有力。

也别只在痛点的表层打转。人人都能说出的困扰，很难制造共鸣；继续往下追问，找到更具体、更少被反复提及的那一层，文字才更容易戳中内心。

不妨做一次双向盘点：把产品卖点与用户痛点重新对齐。把自己放到客户的位置上，推演产品能替他解决什么、会让他的处境发生什么变化，再把这个点组织成表达，对方才更可能被打动。

素材来源：《如何打造自动成交的朋友圈系统》
