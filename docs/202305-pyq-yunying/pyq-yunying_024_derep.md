# 2.1.2 来源二：从书里找灵感

以猫叔（@剽悍一只猫）的《一年顶十年》为例，这本书读着轻松，表达直白，句子有节奏，很容易记住。书中几乎每篇文章都在传递一种价值观。你只要把他的观点和自己的经历拼在一起，就能写出一篇很有说服力的价值表达。
