# 2.4.2.3 第三类：巧借东风

当明星或知名人士愿意为你的产品站台时，你当然可以顺势与他们捆绑宣传——毕竟这是一场正当的商业合作。可要是人家根本没搭理你，你非硬凑上去，那就成了“蹭热度”，既尴尬又容易招人反感。

举个反面例子：前几年有位阿里高管被曝出婚外情，原配在🧣上公开控诉。结果有卖酵素的微商在朋友圈发文：“那位原配喝的酵素也太难闻了，谁认识她？帮我牵个线，我想送她我家酵素！”这操作简直离谱。这种负面事件本就不该碰，更别想着借机营销了。

再看正面示范：教师节、国庆节、七夕、除夕……这些全民同庆的大日子，才是天然的正能量流量池。你完全可以在这些节点讲应景的故事——教师节聊聊你和某位恩师的往事；七夕节说说你和另一半从相识到相爱的经历。把情感铺垫到位了，再自然地带出产品，效果远胜生硬推销。

所谓“借力打力”，关键在“借”得巧妙。拿别人的光点亮自己之前，先掂量掂量这束光是否干净、是否对自己有利。好好琢磨这个度，你就能借得漂亮。
