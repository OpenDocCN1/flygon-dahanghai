# 2.3.1.4 朋友圈谈观点，别被“怕被议论”拦住

不少人发朋友圈前会犹豫：写点自己的看法，会不会招来指指点点？这种顾虑，其实多半是自己吓自己。

先想清楚一件事：我们随口说的话，基本掀不起什么浪。世界不会因为一条动态就转向，别把自己看得太重。换句话说，旁人未必真会逐字琢磨你的表达。

再看出影响范围。一个人能触达的人，向来少得可怜。我经营私域六年多，微信好友拢共两万上下，全平台关注者也才五万多。再看娱乐圈，微博粉丝量能过亿的明星，五个手指头数得过来。普通人的辐射面只会更窄，所以别把自己的声量想得太大。

还有一点：谈价值观时，把社会主义核心价值观作为基准，方向稳住，就不容易出问题。

所以，想表达就大大方方写出来。你的观点越清晰，越可能让同频的人主动靠近你。
