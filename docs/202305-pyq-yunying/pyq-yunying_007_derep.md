# 1.1.3 朋友圈，究竟该发给谁看？@小女巫忻忻

不少人第一反应是：朋友圈当然是给朋友看的。可真实情况并没有这么简单。

有人把朋友圈当自留地，发些自己乐在其中的内容，也不在意是否被谁屏蔽。可如果你正在认真琢磨这个问题，多半怀着一个共同目标——变现。

所以，做变现的朋友圈，首先要面向潜在客户，其次要面向已经成交的客户。

为什么潜在客户要优先？因为已成交客户，朋友圈和私聊都能触达；而在对方尚未建立足够信任、仍处于犹豫期时，频繁私聊反而容易让人觉得你过度热情、目的性太强。

由此可以形成一个基本判断：朋友圈主要承担被动成交的作用，至少能增加产品咨询量。
