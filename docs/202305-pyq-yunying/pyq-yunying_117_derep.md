# 5.3 别小看🛰️备注这个小动作

我习惯把每位好友的收货地址、自提信息直接写进备注里。这样一来，不管谁突然来问消费记录或者提货情况，我都能第一时间查清楚，回复几乎不用等。

还有一个容易被忽略的点：推荐人背后全是人情。

具体做法很简单——把推荐信息放在昵称后面。比如，A 介绍了一位新朋友加我，我就在这位新朋友的昵称后加个括号，标注“（A 推荐）”。这样一来，谁完成了付费，我一眼就能看出是哪位朋友带来的，然后马上私信感谢对方。人情，就是这样一点点攒下来的。

不过，做备注时有两个坑要避开：

1）别用数字或字母当标签

很多人习惯用字母、数字给好友分组。好友少的时候可能觉得没什么，可一旦人多起来，再想改就麻烦了。你从 1 标到 100，那 88 到底是谁？多半你自己都想不起来。

千万别低估自己的发展速度，每个人都有可能把盘子做大。所以从一开始，就要把标签体系搭好。就像超市收银员，每收完一单，都会顺手把抽屉拉出来再推进去，而不是等钱堆成小山再整理。别怕麻烦，越早理顺越省事。

2）别按强中弱意向给好友分类

我以前也试过，把所有人都标成强意向、中意向、弱意向。后来慢慢发现这不太对。如果每个加🛰️的人都被当成潜在客户，那还能交到真朋友吗？生意大概也会越做越窄。

更何况，不是客户又怎样？我同样需要老师、需要朋友、需要关注者。人本来就有很多重身份。想明白这一点之后，我反而没那么功利了。
