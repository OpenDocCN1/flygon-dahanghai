# 2.4.1.8 公开标价，成交更坦然

前文案例里，我常把售价直接写出来。这么做不只是习惯，更能省去双方不必要的难堪。

设想一下：你看中某件商品，页面却没有标价。你发消息来询价，我给出的数字超过你的预算，你买不下，双方都会别扭，你也觉得没面子。于是，不少人索性不开口，我也因此错过不少交易机会。

不少读者心里正是这样盘算的。

所以，在推广内容里直接附上售价，接受的人自然下单；觉得贵的人也能平静离开，不必难堪，反而可能多出几次成交。

当然，也有人担心单价偏高，明码标价会把顾客吓跑。其实不必忧虑，报价在替你筛选客户，我们只能服务认可这个价位的人。况且，不把数字写出来，售价并不会因此变低。

把交易摆在明处，才更显诚意。
