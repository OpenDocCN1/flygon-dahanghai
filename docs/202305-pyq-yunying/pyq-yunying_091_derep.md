# 3.5.3 第三种：邀读者写故事

这第三种玩法，说白了就是请读者在留言区交一篇自己的小短文。

不过，用之前一定得拎清：这类互动要格外谨慎。

我试过不少回，到现在为止，效果最理想的是让大家写七夕爱情故事，以及写孝顺主题的故事；换成别的话题，参与度往往就上不去。
