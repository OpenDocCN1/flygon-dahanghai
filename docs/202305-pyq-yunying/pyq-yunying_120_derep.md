# 5.6 朋友圈的三条底线 @醒醒同学🍃

聊到朋友圈该发什么，我给自己划了三条线，今天也拿出来和大家说说。

第一，不替自己没把握的东西说话。凡是没亲自体验、没真正弄懂的产品或服务，我既不会卖，也不会写。

第二，有些痛，别轻易拿来当素材。客户最深的难处，哪怕写出来能带动成交，也别随便碰。原因很简单：没有人愿意自己的伤疤被摆到台前供人围观；旁人也会因此觉得你靠不住。

第三，更新别长期停摆。朋友圈别一停就是半个月，特殊情况除外；能保持每周有动静更好，做到每天更新更佳。
