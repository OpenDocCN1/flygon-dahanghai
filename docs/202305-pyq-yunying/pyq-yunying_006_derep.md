# 1.1.2 朋友圈：让信任先发生 @逆熵增者

朋友圈不仅能让用户和你产生连接，还能让这种连接逐步加深，信任也在这个过程中不断累积。

很多人加完微信后，第一件事往往不是聊天，而是先翻一翻你的朋友圈：发过哪些内容、表达过什么立场、转过什么文章，平时喜欢什么、去过哪里。这些零散信息拼在一起，就成了对方对你的初始判断。

也就是说，用户会借由朋友圈认识你、了解你，慢慢知道你大概是个什么样的人。你希望对方看到哪一面，就该把那一面持续呈现出来。

如果长期不发，对方既不知道你是谁、在忙什么，也不清楚你的客户是谁、产品是什么、能替别人解决什么问题、可以提供哪些价值。缺少这些信息，信任很难建立，成交自然也无从谈起。

请记住：交易之前先有信任；客户愿意买单，本质上是因为他信你。
