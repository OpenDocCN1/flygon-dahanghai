# 5.2 微信标签，别让它闲着

微信好友越加越多，通讯录却越来越像一团乱麻：想找某位客户得翻半天，发条朋友圈要反复权衡屏蔽谁，群发消息更像在人群里盲喊。问题往往不在好友数量，而在于一个常被忽略的功能没被真正用起来——标签。

把标签用对，相当于给通讯录装上一套清晰的分类系统。你可以按关系给联系人打上“同事”“老同学”“潜在客户”等标记，也能按场景划分“合作方”“宝妈群”“健身搭子”。标签一旦立起来，后续操作就会顺很多：发朋友圈时按标签选可见范围，既不会打扰无关的人，也不怕漏掉该看的人；群发消息时直接勾选目标标签，省去逐个勾选的麻烦；想找某类人时，点开标签就能快速定位。

更实用的是，标签能帮你把精力花在刀刃上。比如做活动通知，只推给“意向客户”标签；分享生活日常，只对“亲友”标签开放。久而久之，你的微信就不再是杂乱的名单，而是一张随时可调用的关系网。

别小看这个动作。花十分钟整理标签，往后每次发消息、找人都能少花十分钟。善用微信标签，不是折腾，而是让工具替你省事。
