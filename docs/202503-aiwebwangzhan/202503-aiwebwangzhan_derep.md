# 1.1 项目背景与前景

## 1.1.1 为何值得投身“AI + Web 开发”？@彩笺

网站是产品的一种呈现方式。出海建站这件事，我把它浓缩成八个字：发现诉求，兑现诉求。

从前建站门槛不低。多数人的注意力更多落在“兑现诉求”那一半，而兑现诉求，得掌握一门有难度的手艺——敲代码。

因此那些年，程序员过得相当滋润，缘由是他们握着多数人不会的本事。

体量较大的企业，部门和产品线都不少，它们如何产出产品？概括起来就是：产品经理管前半段——洞察诉求；程序员管后半段——兑现诉求。

时间快进到 2025 年春天，AI 的本事上来了，后半段“兑现诉求”变得轻松许多。小排老师此前在帖子里也提过：仅凭点子就能变现的时代已经来了！

## 1.1.2 赚钱空间有多大？@彩笺

在各位开启首站之前，先如实描绘一下收益图景。我亲眼见过只靠流量广告收入、月入近 5 万美元的站点；也见过通过满足用户付费诉求、以订阅方式做到日入 1000 美元的 AI 工具站。出海，几乎是变现上限最高的方向，甚至可以说没有之一。赚钱里就有相当低调的大佬，零编程经验，去年月入万刀。想拿到这样的收入，你要做的只有一件事：洞察诉求，兑现诉求。

💡 @良辰美：

持续把站点推上线，本质上就是反复洞察诉求、兑现诉求。

对小白而言，“洞察诉求”这一步稍难，它更吃产品经理、用户调研方面的功力。AI 能帮你一起找，但核心动作仍要靠自己洞察，这取决于你对诉求的敏感程度；有产品经理、用户调研方面的认知与积累，会很有帮助。

AI 如今几乎能替你完成“兑现诉求”，也就是做出 MVP，快速验证你发现的诉求是否成立。AI 产出的程序偏初级，但基本能跑。在 AI 的加持下，一个识字的人就能做出站点或 APP。新手要迈的第一道坎，是把站点推上线，而且越熟越好。

小白还得破掉对代码的畏惧——反正不必看懂，让 AI 给你讲一遍就行。

入门初期的重点，是摸清站点怎么上线，也就是域名注册、站点托管、代码托管这三类平台。可选项和路子很多，这里只举最简单的一种。

怎样洞察并兑现诉求？很多人以为要反复调研，或者一直打磨产品。真正可行的路径其实是：在上线产品的过程中不断验证——诉求找对了吗？它是真需求吗？有没有被兑现？能不能靠收费来兑现？

所以“洞察诉求、兑现诉求”的含义，或许就是快速把站点做出来。只有经过大量 MVP 验证，你才能尽快找到并兑现诉求。

一直干耗着读实战手册，或者在网上海量乱逛，也许对找诉求有帮助，但不执行、不上站、没有 MVP，就无法验证诉求，也就谈不上赚钱。

对一无所知的小白来说，可以照着手册中那些粗糙的示例站点，零基础快速把第一个 Web 站点做出来。提一句：洞察并兑现诉求时，哪怕站点很简陋，也能带来不少收入，比如 diskprices.com，这也是我的亲身经历。

# 2.1 网站的基本组成

## 2.1.1 域名（Domain）：它是什么、去哪儿买？@彩笺

域名就是大家常说的网址，baidu.com 正是百度的域名，也是站点对外的入口。想想看，别人得知道你的地址，才能找到你吧？域名全球唯一，凭这个名字能找到你，也只能找到你的“地址”。我建议到 cf（Cloudflare）购买。市面上卖域名的商家很多，cf 对做开发最便利。域名可以等站点做出来之后再买，不用着急。

## 2.1.2 服务器（Hosting）：云端部署是什么、有哪些常见免费托管平台

服务器就是承载你运行程序的场所。你有了地址，总还得有对应的房子吧。如今不少地方能免费帮你部署代码、托管站点，比如 Vercel、Cloudflare、Netlify 等。多数平台的部署流程大同小异：+MM188166M（李李）长期更新

1. 注册账号；
2. 上传站点文件，或绑定 GitHub 仓库；
3. 一键部署后可拿到访问地址；
4. 若有自定义域名，还能在平台后台绑定。

## 2.1.3 代码（Code）：站点的核心灵魂，静态页与动态页有何不同

站点最终长什么样、有哪些交互，全由代码说了算。可以把它看成一份菜谱，决定你这道菜的味道。

静态页面给每位访客看的内容都一样，像已印好的报纸。好处是打开快、相对安全、部署简单、成本低，适合个人博客、作品集或企业官网。

动态页面的内容会随用户操作或登录状态变化，像聊天软件那样实时刷新。优势是功能丰富，登录、评论、购物车都能做；短板是需要数据库和后端配合，开发更复杂，适合电商、社交等带用户体系的站点。

首次建站，不妨先从静态站点上手，等流程熟了再碰动态功能。

# 2.2 编程语言基础科普+MM188166M（李李）长期更新

## 2.2.1 HTML/CSS/JavaScript：零基础该抓住哪些要点？

可以把一个网页比作一个人：HTML 是骨架，决定页面上有哪些元素（标题、段落、图片、链接、按钮等），关键概念有标签、属性、嵌套；CSS 是外表，负责排版、配色、尺寸与字体，核心概念包括选择器、属性、值；JavaScript 是大脑，让页面能交互、能动态反馈，比如按钮点击后弹出提示、表单填写时做校验、播放动画等。

## 2.2.2 前端与后端怎么简单区分

前端是用户在浏览器里看得到、点得着的部分，涵盖页面布局、视觉效果和交互逻辑，主要用 HTML、CSS、JavaScript，好比餐厅的大堂和菜单。

后端跑在服务器上，负责数据存储、用户认证和业务逻辑，常见语言有 PHP、Python、Node.js 等，好比餐厅的厨房和仓库。

## 2.3.1 Cursor / Windsurf：安装与使用简介

区别一句话概括：Cursor 适合持续打磨较复杂的代码库，Windsurf 适合新手刚入门。

## 2.3.2 Claude / ChatGPT：怎样和大模型高效对话、说清编程需求

区别一句话说：Claude 最新的 3.7 Sonnet 模型被公认代码能力最强，ChatGPT 算低配版，能用但不够强。初期这两个模型任选一个都行。若自己注册不了，直接上淘宝买共享或独享成品号即可。渠道怎么来没那么要紧，尽快用上这个世上成本最低、智慧最高的 AI 模型才更重要。

## 2.3.3 还有哪些 AI 工具：bolt.new、trickle.so、GitHub Copilot 等

区别简单说：bolt.new 对零代码小白很友好，能自动部署、直接预览网页内容，但不支持代码版本回退；trickle.so 与之类似，额外提供了一些模板；GitHub Copilot 则更适合程序员在 IDE 编辑器里使用。

bolt.new 与 trickle.so 的域名后缀都不常见，因此不能直接点开访问，得复制跳转，或在浏览器地址栏输入后回车进入。用邮箱登录就能用，且提供免费次数。搭配刘小排这篇帖子一起看效果更好：《5 分钟做个网站，人人都能学会》；视频版《不懂编程，1 分钟让 AI 做一个星座运势网站》。

## 2.3.4 本地环境配置（Node.js、npm、Git 的简易安装）

一句话理解：+MM188166M（李李）长期更新

1. Node.js：好比一个专门“播放” JavaScript 的工具。以往 JavaScript 通常只能在浏览器里跑，有了 Node.js，你的电脑就能直接执行 JavaScript 程序。
2. npm：装软件的“应用商店”，帮你下载他人写好的模块，不必自己从头造轮子。
3. Git：程序的“时光机”，记录每一次修改，出错能回退，多人协作也不打架。

三者关系：Node.js 是环境，npm 是在 Node 环境中取用工具的途径，Git 负责记录程序的变更轨迹。

我本人不是程序员，这类工具至今也没用过。顶多是跟 AI 对话时，按它说的复制粘贴程序操作过，谈不上熟悉。所以非程序员的新人不必太在意这些，先尽快把站点推上线就够了。只有尽快、持续地把站点做出来，才能快速洞察诉求、兑现诉求。其他工具、环境、模型都只是配角，别沉迷。

# 2.4 怎么让 AI 替你写程序、改程序？

要是 AI 给的结果总不满意，可以先让它把问题归纳一下，然后开个新会话，重新描述卡点再问；也可以换别的模型，比如 Claude、ChatGPT、Deepseek，让它们互相参考着试。

## 2.4.1 给 AI 提需求，提示词抓住哪几点

口语化写法：别给自己框死，想做什么就写什么，哪怕前言不搭后语。在与 AI 来回打磨的过程中，你的想法会慢慢清晰，不断归纳之后，提示词也会越来越完整、有条理。

结构化写法：也有圈友偏好格式规整的提示词，里头包含技术架构、背景角色、目标输出等。把一套自己总结的模板练熟，能明显提升与 AI 对话的效率。

## 2.4.2 AI 给出程序后，本地怎么做简单测试

HTML 类的程序，直接在浏览器打开就能看页面和源码，改动的话推荐用 Notepad++ 这类轻量编辑器，也可以直接在 github.com 仓库的文件里修改。

至于 next.js 这类带后端、多组件的程序，我很少在本地调试。没有编程底子容易弄错，只能靠反复截图问 AI，把它给的代码复制过来跑测试。

# 2.4.3 报错后，怎样让 AI 修得更准

要让 AI 修得准，先准备一份持续维护的网站地图，作为背景资料交给它；隔一段时间再让它对照当前站点做一次校正。

真碰上故障，先把报错画面截下来；错误里带文字或代码的，也一起复制给 AI。然后把情况讲清楚，最好围绕三件事：希望得到什么结果、目前出现了什么异常、自己已经试过哪些操作（涉及代码就贴上）。接下来请 AI 尽量列全可能的成因，再逐条给处理办法，并实际跑一遍验证。多数问题照这个流程就能解决；只有特别复杂、或提问时漏掉关键代码背景的情况才容易卡住。这种时候，把问题发到航海群，请技术大牛一起排查。

# 3.5 多页面游戏站：优化与推广

当游戏站的结构和内容已经比较完整，接下来要解决的就是：怎么让更多人知道它、进来玩。这时要把 SEO、社交推广和数据分析配合起来，持续迭代、不断调整，站点才有可能保持增长。

# 3.5.1 SEO：先打牢地基

1. 网站层级与 URL 要清楚

搜索引擎喜欢导航清楚、结构明朗的站点。分类目录和 URL 命名都要让人一眼看懂。

另外，每个游戏页都要配好 title 和 meta description，正文里也要用合适的文字介绍游戏。

2. 游戏内容与元信息要原创、有用

除了 iframe，页面本身的文字同样关键。

每个游戏都应单独写介绍和亮点，别直接复制官方简介或别站内容。这样搜索引擎会认为你的站点原创度高，收录和排名更容易上来。

3. 加载速度与移动端体验

游戏站通常图片多、动态内容多，加载慢会直接赶走用户。

图片压缩、缓存、CDN 加速都安排上；移动端则要保持游戏页布局简洁。

4. 站点地图与收录监控

生成 XML 站点地图，提交到 Google Search Console，让搜索引擎尽快发现你的每个游戏页。

定期查看收录情况和错误报告，发现 404 或重复页面要及时处理。

3. 外链拓展

留意类似的游戏站或玩家博客，他们经常会评测、推荐在线小游戏。主动联系这些博主和社区，争取外链。

还可以和游戏周边、硬件评测等相关行业站点合作，拓宽流量来源。

# 3.5.3 看数据，做调整

1. 装好 Google Analytics

GA 能回答“多少人来了、来了之后干了什么”。

通过 GA 或其他分析工具，看每日访问量、用户停留时长、跳出率等指标，找出用户最喜欢的游戏类型或页面。

某类内容点击率特别高，就继续加料；某页跳出率高，就检查加载速度或游戏本身的吸引力。

2. 用 GSC 做监控

Google Search Console 能让谷歌知道你的站点存在，也有助于网站在搜索结果中被找到。

GSC 可以看搜索排名、点击量、展示量，以及移动端可用性、爬虫抓取错误等问题。

根据这些数据优化游戏页，比如补充更相关的关键词描述、完善图片 alt 信息等。

3. 定期更新与迭代

玩家口味变得快，站点长期不更新、没新品，回访就难。

定好周更或月更计划，持续上新，热门游戏页多做延伸内容，让站点保持活跃度和吸引力。

结构规划、多游戏上线节奏、SEO、推广、数据复盘，几件事长期做，游戏站才有机会在拥挤的网络里冒头。持续维护和扩充，站点就可能变成真正的流量池，娱乐和收益两头都顾上。

# 4.1 导航站：特征与变现方式

# 4.1.1 导航站的特征

优秀导航站一般具备几个关键特点：

分类准、定位清楚

优秀导航站通常只做一个细分领域，资源经过筛选，分类清晰，用户能很快找到想要的东西，体验自然好。

资源实用、更新勤

成功导航站收的多是用户真正常用的高价值内容，并且持续维护，链接有效，不过时、不失效，用户才会长期信任。

界面清爽友好

设计简洁清楚，交互顺手，不堆功能，降低用户理解成本，让用户轻松找到目标资源，愿意反复访问，网站黏性也就上来了。

# 4.1.2 导航站变现模式（+MM188166M 李李 长期更新）

导航站赚钱，通常靠聚集高质量流量和精准导流，主流方式有：

广告收入

这是导航站最常见的变现方式，包括：

第三方广告，如 Google AdSense、百度联盟，按流量拿点击收入；

自主招商推广位，直接卖首页或分类页的好位置，收入通常更高，也更精准。

付费收录

适合已有一定流量和品牌影响力的导航站。向想推广的网站收费，给它们更好的曝光位置，比如 VIP 推荐位，收入还能再往上走。

会员付费

适合资源有差异或内容有优势的导航站。常见做法是：

免费用户看基础资源，高级资源要会员；

再提供无广告纯净版，提升付费意愿。

联盟营销（Affiliate）

适合用户转化意图明确的导航站，比如购物、软件、服务类导航。精准把人引到目标站，用户消费或注册后站长拿佣金。转化准、收益稳，垂直导航里很常见。

原创内容与增值服务

基础导航之外，还能做原创资源或增值服务变现，比如行业分析报告、专业评测、优质榜单、干货资源包，通过付费订阅、内容付费或给自有产品导流来增收。

# 4.3 从零上线全流程

整条链路并不长：整理书签 → AI 生成页面 → 放到 GitHub Pages → 买域名 → 挂到 Cloudflare。下面一步步拆开讲。

# 4.3.1 第 1 步：把书签喂给 AI

我先是花了十五分钟左右，把收藏夹里的内容人工审视了一遍，按类别简单归了归，随后整段复制给 Claude。
![](img/a35cbc12ada2ab6231dcb28d3ca255f0.png)

# 4.3.2 第 2 步：AI 生成导航页

Claude 很快吐出一整段 HTML。代码本身我没细究，原样贴进页面后效果出乎意料，日常使用绰绰有余。
![](img/6ae805e244119275a2d045c8ae655691.png)

# 4.3.3 第 3 步：上线到 GitHub Pages

把这段代码保存下来，登录 GitHub，新建一个仓库（例如叫 bookmark-site），再新建 index.html，把代码放进去，保存文件、提交改动。
![](img/4e79f58d60eba076d176b7fbb5fceac5.png)

# 4.3.4 第 4 步：选个域名买下来

域名这块我当初纠结了很久，最后干脆让 Claude 列了一批朗朗上口的选项：
![](img/68b25102057e5460e6b3fbf1cac202da.png)
我从里面挑了一个最顺眼的，直接在域名注册商那里付钱拿下。

# 4.3.5 第 5 步：把域名挂到 Cloudflare Pages

到 cloudflare.com 里把域名挂载好（小游戏站那篇已经用大量截图演示过，这儿就不重复放了）：先把买来的域名加进 Cloudflare 名下。

把 GitHub Pages 上的仓库接到 Cloudflare，再交给 Cloudflare Pages 托管，中间有个细节几乎人人踩一次：证书模式别留在系统默认的 Flexible，手动切到 Full 才算配对完成。设好之后先别急着测，等上三到五分钟，反复刷新控制台，直到出现绑定成功的字样。顺手记个小经验：这两个平台最好拿同一个邮箱注册、并且都保持在线，授权来回跳转时会顺很多。

# 4.3.6 步骤六：给导航页做一次精修（可选）

想让它更好看，可以继续让 AI 帮你调版式、改结构，也能补上插图、图标和更多装饰元素；至于打磨到哪一步为止，取决于你打算投入多少精力。

# 4.4 导航站再进阶：还能往哪些地方优化+MM188166M（李李）长期更新

想再往上一层，通常就得上模板；更复杂的玩法是接数据库。初阶航海这部分先不深聊。程序员能折腾的空间很大，遇到不懂的多问 AI，自学很快就能钻进去。大致可以从下面几个角度下手：

技术侧：首屏尽量两秒内打开，图片和代码都压一压；手机端点按要舒服，按钮做大、点击区域放宽；版面留白干净，核心资源的入口放在最显眼的位置。

内容侧：别把什么都往篮子里塞，只收真用得上的工具；每周扫一遍外链，死链及时清掉；每月补少量新资源即可。垂类要窄，比如只做独立开发者工具，别搞成万能大杂烩。

搜索侧：给用户一个即时响应的搜索框，想找什么敲进去就出来；分类别按技术栈切，按用户的使用场景切；每个工具配两三句白话说明，讲清它到底解决什么问题。

SEO：分类页的标题写明白、带上关键词，正文别太干瘪，适度铺垫点介绍；分类之间互设内链，让人愿意多点开几个页面。

推广：常去 V2EX、Reddit 这类社区丢精选合集；主动联系被收录的工具作者，告诉对方你收了它，说不定人家乐意帮你转一手；社区答疑时，顺手带上站内资源。

接推广：开几个精选位，把位置留给真正好用的产品；付费工具可以挂联盟链接抽佣金，但广告别堆太多，体验一崩就全白搭。

长期：盯数据，哪个资源被点得多、哪些词被搜得多，都得看；放个反馈入口，听听用户怎么说；偶尔跑一次 A/B 测试，哪种版式留人更久，就照着那种改。

# 5.1 图片站是什么，怎么赚钱

先把老一代的图片站分个类：+MM188166M（李李）长期更新

SVG 素材站：专收可缩放矢量图形，设计师和开发者会来这儿淘货，省下自己画的功夫。代表站点 Flaticon、Freepik、Vecteezy、SVG Repo、SVG Silh；域名依次是 flaticon.com、freepik.com、vecteezy.com、svgrepo.com、svgsilh.com。

壁纸站：把各种高清壁纸汇总起来供人下载，拿来装点电脑和手机桌面。代表站点 Wallhaven、Unsplash、Wallpaper Engine、Pexels Wallpapers、Wallpaper Abyss；域名依次是 wallhaven.cc、unsplash.com、steamcommunity.com/app/431960、pexels.com/wallpapers、alphacoders.com。

摄影作品站：专业摄影师的成片展示区，一般按题材、风格或作者归档。代表站点 Flickr、500px、Getty Images、EyeEm、Behance Photography；域名依次是 flickr.com、500px.com、gettyimages.com、eyeem.com、behance.net/galleries/photography。

表情包 / 梗图站：收集当红表情包和网络梗图，聊天、发帖时随手就能用。代表站点 Tenor、Giphy、Emojipedia、imgflip、Know Your Meme；域名依次是 tenor.com、giphy.com、emojipedia.org、imgflip.com、knowyourmeme.com。

图床站：把图片传上去帮你存着，再回你一条能直接外部引用的地址。代表站点 Cloudinary、ImgBB、Postimages、Imgur、SM.MS；域名依次是 cloudinary.com、imgbb.com、postimages.org、imgur.com、sm.ms。

# 6.1 Google AdSense 申请流程：门槛与常见拒因

官方详细说明见：加入 AdSense 计划的资格要求。

Google 的审核机制是 AI 初审加人工复审相结合，下面几个因素比较关键，需要重点留意：

1.  网站内容必须是原创内容，并且能带来实际价值

1.  网站各个页面的内容不能重复，必须保证独一无二

1.  用户能够轻松浏览站点内容，网站需要有分级菜单和清晰的架构。

1.  每日 UV 在 500 以上

1.  申请人年满 18 岁+MM188166M（李李）长期更新

如果申请被拒，先看拒绝原因，再针对性修改。常见的几种情况如下：

1.  网站所有权未得到确认（只要按官方引导去验证即可避免）

1.  流量质量不佳（先弄清楚哪些流量不被认可。通常社交流量、Google 自然搜索流量、邮件营销带来的流量、以及通过外链跳转来的流量，都是合格流量）

1.  页面内容低质或整体没内容（这是新手最容易踩的坑。如果内容太少，就补充更多有价值的信息，并搭好清晰的结构）

1.  复制或重制其他网站的内容（多写原创文章，能从根源上避免）

1.  同一地址下曾有违规被封的账号（如果之前有账号因违规被 K，再次申请会比较困难）

1.  找不到 ads.txt 文件（在网站根目录放好 ads.txt 就能解决）

1.  页面价值过低（提升页面内容质量即可）

1.  网站运营时间不足三个月（大概率是流量不足，需要加强推广或优化 SEO）

需要记住的是：只要不是原则性错误，Google 愿意给你改正的机会。审核不通过时，后台会显示红色的 Needs attention，点右侧下拉箭头，再点 Show details，就能看到具体建议。改完以后可以再次提交审核。如果还不清楚怎么做，可以发邮件到 AdSense-support@Google.com 询问。+MM188166M（李李）长期更新

第二步：添加并验证网站

提交审核的网站需要有一定流量。如果流量比较少，还会有额外要求，比如域名注册时间超过三个月，并且有足够的内容。

第一次审核通常比较慢。谷歌爬虫会先检查你是否加了广告代码、是否加了 ads.txt 文件，然后还会统计一段时间的流量，甚至抓取网站页面看内容量，最后才进入人工审核。

人工审核会先看统计数据。如果你的网站流量少、内容也少，大概率会被直接打回，要求你先补充内容或提高流量。

网上很多教程会建议域名注册满三个月再申请，但这其实只是针对内容少、流量小的网站。基础条件扎实，并不用等那么久。

在一次次涨价过程中，我试着跳出技术和产品层面，站在运营角度去复盘价格与小众市场的关系。最后真正理解了一句话：为价值定价。

要按用户获得的价值来定价，而不是盯着自己的成本。

接触公司项目或接外包的时候，我们通常习惯做成本控制。想实现利润最大化，要么压缩成本，要么靠商务谈判能力争取更高报价。

做副业很容易被这种固定思维影响：我花了多少成本，报价至少要覆盖成本才能保证利润。

但在小众市场做面向用户的工具，定价反而很让人头疼，因为你做的东西不一定就是自己要用的。比如我做的 YouTube Comment Bot，一开始只定 $1.99——因为在我眼里，这个工具价值不高，开发成本也很低。

后来我才真正想明白：定价要看用户感受到的价值，而不是我付出了多少成本。大胆把价格标出来，谈钱并不是伤感情的事。

# 6.2.2 佣金与推广分成：接入Affiliate体系

Affiliate（联盟营销）可以理解成海外版的淘宝客，跟知乎好物、抖音书单、外卖返利、美团地推属于同一路数：你替商家带客，成交后抽成。

入门先得认识Offer，其中CPS和CPA最常见。

CPS按成交金额抽成，卖实物行，卖软件程序也行。眼下SaaS产品一抓一把，又带着"配一次长期见效"的属性，提成往往不低，做得好的收入不比传统商品差。亚马逊年末大促时，佣金比例最高摸到9.5%——一台300美金的冰箱卖出去，你到手28.5美金。

若是盯准某个品牌的独立站Offer做专门投放，分成通常更可观；保健品这类高毛利赛道，比例能冲到50%以上，https://fanfuel.co 上有实例可看，当然高佣也意味着红海厮杀。

另一头是CPA：用户完成指定动作才结算，动作可以是装个软件、填张注册表。这类佣金常见区间在2—10美金；落到保健品赛道，一单六七十美金也不稀奇。

新手挑赛道别凭手感，最好找一个比你弱的对手先超过去；否则流量养起来了，才发现没有合适的产品可推，白忙一场。观察同行在推什么，照着去申请；用"关键词+Affiliate"丢进谷歌搜；找Affiliate Network谈合作；或者直接对接广告主。

联盟要抽一笔中介费，换来的是帮你把各家广告主串起来、省去对接功夫；直接找广告主谈，分成高，可对你的门槛也高。三者的关系有点像：房产中介（Affiliate Network）——你——卖房的人（广告主）。

合作时间长了，佣金比例、扣量这些都有得谈。

https://www.Offervault.com/ 和 https://odigger.com/ 也能按关键词翻出贴合自己niche的Offer。要留意：同一个Offer放在不同联盟，转化表现可能差很远，必须实测；各家运营打法（乃至底线）都不一样。

选定标的后，通常先申请推广资格。海外多数软件与工具类产品，页脚都挂着联盟加入入口；或者谷歌搜"产品名+Affiliate"直达。注册流程不复杂，新手大多情况下如实填写资料，免得佣金到手却卡在提现那一步。

Firstbase开户实测：
