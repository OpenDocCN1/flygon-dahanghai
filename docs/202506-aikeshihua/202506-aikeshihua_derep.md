# 一、项目概览

# 💡
# 章节导读：

人们现在更愿意用“看”来接收信息，视频、图像排在前面，声音居中，图文其次，纯文字最费脑子。反过来说，越容易“看明白”的内容，背后要花的制作功夫也越多。AI视觉化，恰好承担了这部分生产工作。

本期航海的四个要点：

- 流程熟练：把手册粗翻一遍、按步骤执行，成果通常能达到七八分；
- 认识模型与prompt：模型决定AI的能力上限，prompt就是你对AI提需求的说明书；
- 会写prompt：它需要反复调优，像“炼丹”一样试错，能炼出满意结果才算真的入门；
- 会抓需求：商业化的钥匙不在工具里，而在“真需求”里。可视化赚不赚钱，取决于你找没找对用户痛点。

大人在意的玩具，小孩可能当成宝贝；价值是外部赋予的，不是物品自带。

# 1.1 背景说明 @胖大魔 @相柳

所谓AI视觉化，就是用AI自动把复杂数据变成容易识别的图表。本手册的范围更小：让大模型把图文资料变成好看的HTML卡片或图片。

# 1.1.1 为什么学这个

过去，做可视化是有门槛的：要懂AI、懂数据处理、懂图表生成，还得靠复杂工具和大量人力。现在，Claude 4、DeepSeek V3这类大模型加上几句prompt，就能把复杂图文变成精致卡片。门槛降下来，传播效率却上去了。

这项能力的核心是“快速提炼+视觉表达”。以前这是少数人的本领，现在人人可练。早一点熟练工具，面对AI时代的变化就能更淡定。

# 1.1.2 能变现吗

实话实说，目前还没有大规模稳定的商业模式。知识卡在市场上多被当成“好看”“好玩”的物件，收藏和传播价值还没有被真正挖掘。机会可能藏在差异化的小市场里：K12补课、小班、专项培训等。

能不能抓住机会，取决于两点：卡片是否吸引人、能不能让买家获益。做到这两点，普通人在小而美的市场里也能靠专业能力站稳，大资本反而不好进场。

# 1.2 手册怎么用

# 1.2.1 目标设定

分层学习，各取所需。

# 1.2.1.1 必学目标：用现成prompt做卡

考虑不少人是第一次接触，附录会提供一批可直接复制的prompt。把prompt发到对应模型，就能正常出卡，像普通聊天一样使用。注意：

- 出卡过程大概率会出现瑕疵卡；
- 遇到废卡，重新发给AI再说一遍，或者直接告诉它哪里不对，让它改；
- 有条件优先用Claude官网的4模型，或Cursor中Agent模式下的4模型；
- 网络不便的圈友，可参考工具中的DeepSeek-V3演示。

微调有两种方式：手动改HTML（需要有代码基础），或者把问题描述给AI，让它自己迭代。

# 1.2.1.2 选学目标：自己写prompt做卡

如果一个人能用自己的prompt抽出想要的卡，说明他真正出师了。这条路上大致有这些阶段：

- 基础：会和AI正常对话，懂prompt的基本结构；
- 应用：按模型类型调整沟通方式。推理模型用“需求-对象-目标-约束”描述，问答模型用RTGO（角色-任务-目标-要求）框架；
- 进阶：让AI帮你写prompt，能发现并改掉prompt的毛病，反复测试得到稳定效果，最好还能跨模型使用。

学习者可以根据自己的取向选择：想精进的人，在框架里换内容、实战打磨；图实用的人，让AI起稿后再一轮轮改。

用是学之始，练是学之终；巧是用之果，熟是练之成。商业化不是眼前的目标，但可以是长期的方向。

# 1.2.2 阅读建议

手册不一定要从头看。“体验型”可以直接跳读；“学习型”可以先跑prompt再补理论；“商业型”建议全文通读。

有疑问就问AI（Claude优先，DeepSeek也可以），或者直接问作者。

# 3.1 它是什么

简单说，自我介绍卡就是一张“人物名片”：把不同内容装进统一或不同模板，再用AI排版和美化，让观看者一眼记住亮点。

纯文字介绍要么太长没重点，要么太短没信息量；视频、PPT和PDF又总有打开门槛。和刚认识的人打交道，大家更愿意看一张图，这正是它存在的价值。

# 3.2 准备素材

AI真正做的是整理和美化，所以原始素材要够丰富。信息太少时，AI虽然会补一点，但效果通常打折扣。换句话说，得先有素材密度。

# 3.2.1 第一步：写自我介绍

不需要文采飞扬，参考下面的案例即可。

个人介绍示例：

【昵称】相柳

【区域】深圳

【自我介绍】大家好，我是相柳。在互联网行业干了十年，现任腾讯云TDP常务理事，同时也是腾讯云架构师、百度知道行家、人工智能应用工程师。作为“龙哥盟”特邀AI教练，长期担任10多期航海领队/志愿者；平时运营👸号“聆因”，热爱国学，对儒释道和山医命相卜均有涉猎，欢迎大家找我交流。

【我能提供】

- 项目预判：适合创业早期
- 商业模式梳理：验证单元模型
- 企业管理交流：年营收千万以下
- 天赋优势挖掘：因材施教
- 上云咨询：帮企业降本增效

# 破局卡点：我要什么、凭什么、往哪走

这张卡想说的其实就三件事：我在找什么、我擅长什么、接下来要往哪走。

眼下的诉求很明确——新的项目合作机会、能落地到企业的 AI 培训场景、企业数字化转型相关的活儿，还有一条第二职业增长曲线。我比较拿得出手的，是当团队里的黏合剂，把整体人效拉到最满。下一个要啃的硬骨头是重构 IPO，同时把"持续成长"这件事做到底。最后借屈子那句自勉：路远且长，我仍要上下求索。

# 3.3 常见问题答疑

这一节针对几类典型情况给点思路。问题基本归为两种：出片质量不行，卡片观感不行。

# 3.3.1 出片质量差

优先上 Claude 4，退一步选 DeepSeek V3，这俩是测了多轮最稳的。官网也好，Cursor 也好，都能用。Windsurf 我们没怎么测，你可以自己试试。再往下像 kimi、文心、元宝这些，稳定度没过关，容易出现输出断掉、卡住、HTML 结构散架的情况。也有人让模型接着往下续写，或者几个工具接力做，但都比不上 Claude 或 V3 一口气吐完，所以不推荐。

# 3.3.2 卡片观感差

模型的脾气就是这样：一模一样的内容，换个时间点开窗口，出来的东西也不一样，我们管这叫"刷结果"。观感不行要分开看，是视觉差还是内容差。

视觉上的问题，得把要求讲细，比如"配色我不喜欢，换成鲜艳一点的"，或者"这个样式不对，我想要那种效果"。要是你不擅长描述细节，也说不清到底想改哪儿，那就只能用模糊表达，比如"这卡片不够抓人，没有那种一眼被击中的感觉，推翻重做一版"。

内容上的问题，多半出在自我介绍。按"怎么写好自我介绍"那部分的思路重新打磨。分点要清楚、段落要分明，别一堆字糊在一起、没头没尾。

举个例子（虚构）：我叫相柳，家里做酒生意，想喝哪一口，先来问我准没错；我们家干这行很久了，我个人没什么别的兴趣，就是愿意多认识些人。

更好的写法是排版清楚、一眼能记住，比如：

昵称：相柳

所在城市：深圳

自我介绍：在酒水这行做了很多年（也可以只写数字年份），白的、红的、啤的、洋的都能供。白酒线像茅台、五粮液这类头部品牌都有，葡萄酒进口牌子、国产牌子都覆盖，市面上卖得动的啤酒也做，XO 这类洋酒同样备着。想聊酒、谈买卖、或者纯粹认识一下，随时找我。

这段其实还能再打磨，也可以丢给 AI 润色。以上是编的例子，请按你的真实情况来写，或参考 3.2.1.3 的简单示例。

# 750px的自我介绍卡片，如何用三版提示词越做越高级？

你有没有想过：一张个人介绍卡片，不应该只是“姓名+职位+技能”的排列。真正能让人记住的自我介绍，往往在视觉里藏了故事。

下面这套提示词，经历了从基础到进阶的多次迭代。每一版都可以直接拿去用，也可以当作模板继续改造。

## 基础版：个人品牌卡片设计师

**角色设定**
让AI化身为一位深谙个人品牌视觉化的设计专家，目标是把看不见的个人特质，转化为一眼可感的视觉语言。

**唯一限制**
卡片宽度必须锁定750px，其余高度、配色、版式、风格均可自由发挥。同时明确禁止：传统简历排版、线性叙事、单一视觉层次。

**核心任务**
用一套创新的视觉叙事，回答“我是谁”，既要体现专业价值，也要保留个人辨识度。

### 三步设计流程

第一步，个人品牌战略构思。
先提炼价值主张和差异化优势，再搭建叙事框架，明确专业赛道，找出目标受众的共鸣点，并想清楚“用什么视觉证据证明我的价值”。

第二步，视觉识别系统设计。
建立一套专属的视觉语言，重构信息组织方式，规划视觉层级和注意力引导，用空间关系讲故事，并借助微观细节强化个人标签。

第三步，情感体验与记忆点创造。
通过视觉触发情绪，设计第一眼的冲击力，铺一条鼓励深挖的路径，用视觉建立可信感，再放几个能长期留在记忆里的锚点。同时，专业形象和个性表达不能失衡。

**技术与实现**
使用HTML5、TailwindCSS和SVG落地，可加入微交互来增强体验，代码结构要清晰、有序、易于维护。

**示例人设**
一位拥有5年经验的用户体验设计师，专注情感化数字产品体验，擅长用户研究和交互设计，笃信“以人为本，以情感为引擎”，热衷于把复杂问题变成优雅方案。

**五个创意思考题**
如何把个人特质转成视觉语言？怎么在专业与个性之间找到平衡？静态页面如何暗示动态成长历程？信息完整度和视觉吸引力谁优先？怎样创造长期记忆？

设计完成后，还要从价值传达、视觉独特性、记忆效果、专业形象、技术执行五个层面做评估，并请AI提供完整的HTML代码和设计思路说明。

## 迭代方向：丰富细节，增强表现力

第一版解决了“从无到有”，第二版开始追求“印象深刻”。

**角色升级**
AI变成一位更有创造力的自我介绍卡片设计大师，擅长把个人信息转化为视觉化的价值陈述和情感记忆点，不再满足于“看得懂”，而要让人“忘不掉”。

**硬性条件**
宽度仍是750px，其他自由度不变；新增一项禁止设置：不得出现滚动条或固定高度限制，内容必须完整静态呈现。

### 四阶段创意流程

1. 价值发掘与创意酝酿
不只问“我是谁”，更问“我能给什么”“我哪里独特”。把个人特质和视觉元素、隐喻、故事做创意连接，还可以从产品设计、游戏UI、艺术装置中借灵感，故意寻找看似无关的关联。

2. 结构实验与框架创新
尝试非传统的信息排布，把750px当作边界游戏场。让版式本身成为内容，利用空间叙事和清晰的视觉层次引导观看节奏。

3. 视觉表达与艺术升华
打破单一风格，融合不同设计语言；把抽象价值转成情感体验。可以制造情感触发点、开发专属符号、打磨微观细节，并用视觉节奏牵引观感。

4. 融合优化与边界突破
创意要服务于价值传递，不能喧宾夺主。技术手段要帮助创意落地，最终检验有没有形成情感共鸣；在宽度上守住边界，在其余维度大胆突破，既保持整体一致，也保留让人惊喜的细节。

**技术清单**
HTML5语义化结构、TailwindCSS 2.2.19（CDN引入）、Font Awesome 6.4.0图标库、Google Fonts，以及Tahoma、Arial、Roboto等系统字体作为备选。要求纯静态实现，不依赖JavaScript或后端，代码量不限，欢迎用CSS/HTML的非常规语法制造惊喜。

**创意原则**
打破常规、深度个性化、让每个元素都有意义、善用对比制造张力、在限制与自由之间找平衡、适当加入智慧幽默、把设计思考本身也设计进去、始终突出核心价值。

**灵感激发点**
可以思考：如何让750px从限制变成优势？如何用视觉暗示隐藏特质？如何把“第一印象”和“深度探索”做成双层体验？如何把技能和经验换成非传统表达？视觉节奏如何影响信息接收？

**评估维度**
创新性、价值传递、技术精确度、视觉吸引力、个性表达、情感记忆点。

这版人设是一位7年经验的资深UX设计师，擅长把复杂问题转成简洁方案，重视用户情感体验。他相信“好的设计应该是看不见的，但能被用户感受到”，理念同样是“以人为本，以情感为引擎”。

最后，同样要求AI输出完整HTML代码和详细的设计思路说明。

## 再迭代：从自我介绍升级为身份表达

第三版不再满足于“卡片”，而是把自我介绍变成一种身份表达艺术。

**定位变化**
AI要成为打破边界的自我形象表达设计大师，能够解构和重组个人价值系统，把抽象身份叙事转化为可感知的视觉体验，并埋下能在认知层面长期驻留的情感锚点。

**新增禁令**
不允许出现滚动条、常规下拉菜单等传统交互；同样不允许存在任何没有意义的视觉噪音。

### 五阶段深度流程

1. 深层价值挖掘与概念重构
不能停在职业和技能表面，要向下追问身份本质，构建完整的价值系统，定义自身独特贡献，找出容易被忽略的隐性价值。还要构思“如何介绍自己”这件事本身的元叙事，并为核心思想开发一个隐喻框架。

2. 认知架构与信息系统设计
抛弃线性叙事，采用多维信息结构。规划认知流动路径，设计注意力从捕获、保持到转移的机制，优化信息编码方式，用非传统维度重组概念，让信息分层显现，并建立元素间的关系网络。

3. 视觉叙事与形式语言创制
创造一套专属于个人的视觉语法，包括色彩、图形和空间规则；建立符号系统，编排叙事节奏，部署对比制造张力。细节处要经得起细看，还要在750px约束里做边界实验，埋入互动暗示和意外发现。

4. 情感体验与心理触发设计
为观者规划一条情感曲线，在关键位置安放心理触发点。考虑不同人的认知偏好，用微妙的潜意识设计增强共鸣；建立信任路径，创建价值共鸣系统，并把首次接触的前3秒当成工程来打磨。

5. 整合优化与超越突破
最后统一整体概念和视觉，平衡创意与价值，控制认知负荷，在严守750px的同时继续其他维度突破。还要检验记忆持久度，确认表达真实，并植入能体现专业深度的微妙线索。
