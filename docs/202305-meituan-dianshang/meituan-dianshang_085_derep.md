# 8.3.1 商品上架，先做哪一步？

美团电商的整套流程，到这里已经讲完了。接下来聊聊一个很实际的问题：上架商品时，应该怎么排先后顺序。

所谓优先级，说白了就是：当你不知道下一步该干什么时，先做哪件事、再做哪件事。

**排在第一位的动作：先把店铺商品补到450个。**  
完成比完美更重要。先把货架位填满，让每一款商品都有机会进入赛马和测试。

**第二位：把已经跑出成绩的优质链接做裂变。**  
挑出销量排名前5到10名的产品进行复制，标题重新做，主图更换，再补上视频和评价。真正能打的产品，靠选不如靠测。

**第三位：上架趋势型商品。**  
趋势品往往自带流量入口。回想口罩时期，各类防疫用品几乎被抢空，这就是趋势的力量。

**第五位：补充新品。**  
补品通常围绕三类展开：趋势类、蓝海类、截流类。
