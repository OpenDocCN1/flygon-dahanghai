# 4.1 上货工具怎么用？先看这份设置提醒

想把淘宝等电商平台上的商品搬到美团店铺，需要借助专门的铺货软件。它的作用就是替代手工操作，让上架效率明显提升。

目前同类铺货工具大约有两三家。经过比较，甩手上货在稳定性上表现更好，价格也更实惠，因此下文以它作为示例来说明。

这里要特别强调：使用甩手上货时，务必照教程完成设置。若跳过这一步，商品上架后可能在后续拍单环节遇到不少麻烦，也可能出现图片带白边等问题。
