# 3.1 谁在美团消费

美团的用户底盘，可以用三个特征概括：偏年轻、上班族多、消费意愿强。平台客群以80后和90后为核心，女性客群比男性略多；年龄集中在40岁以下。具体来看，24岁以下占22.57%，24至35岁为54.7%，36至40岁为17.82%。由此可见，美团用户整体偏年轻，且绝大多数是职场上班族。

平台承载了一部分日常必需消费，用户打开美团往往带着明确需求完成购买，因此购买意愿相当强。

再看消费层级：中等消费与中高消费两层加起来人数最多，占53.91%；低消费层最少，仅9.72%。这组数据说明，美团用户有较强的消费力，也更愿意在平台上选择品质更高、种类更丰富的商品。

电商在美团体系内仍属新业务。要提升美团电商用户的ARPU，关键路径是推动美团平台现有用户全面电商化。
