# 5.1 链接过审：流程、驳回与效率取舍

用搬家软件铺完货之后，所有链接会先集中放到美团商家后台的“商品列表—草稿箱”里。接下来要做的有三项：把产品信息补充完整、上传白底图，等这两步都完成后，再提交给美团官方审核；审核一旦通过，商品就能上架，一条链接的过审流程也就完成了。

如果链接被驳回，可以进入美团商家后台的“商品列表—商品审核—审核驳回”，一条条查看驳回原因，然后重新提交审核。

不过从效率上看，前期被驳回的商品更建议直接放弃。原因很实际：目前选品还不够精细，速度要放在第一位，前期链接数量多，不必对单个商品过于纠结；先大量上新，让市场来验证产品。这里只是给大家提供一个重新提交审核的入口。
