# 2.1.2 收购现成公司，先按四条线把关

收购现成公司，不能只看价格，基础条件必须逐项核对。按下面的思路筛，能少踩不少坑。

**一、名称与行业要对口**
优先找名称带有电商、科技、网络、商贸等关键词的公司；教培、工程、快递运输这类与业务不搭边的，直接放弃。名称选得好，后续变更加起来也省事。

**二、注册条件要达标**
公司成立时长必须满12个月。出资额填50万元，认缴即可；经营项目按第三部分的口径搭；公司名称能改就改。除了“成立满12个月”不能变通，其余均能在市场监管局窗口通过变更完成。

**三、经营范围按实际业务搭**
销售类目建议覆盖：线上零售、服饰鞋帽、美妆护肤、数码电器、箱包配饰、育儿用品、玩具、宠物相关用品、带包装的食品零售。
服务类目可加入：咨询、广告代理、家庭保洁、拍摄与视频制作、商业活动承接等。
需要审批的类目尽量不写进常规范围。这样搭出来的执照，基本贴合标准模板的框架。

**四、税务身份选简易计税**
税务监管升级后，合规经营会被盯得更紧。依法纳税是底线，合法节税也是小本生意的必修课。这里不展开财税细节，直接给结论：目前选简易计税口径更合适。

- 推荐：简易计税。有起征点内的免税空间；普通发票等票据可用于抵扣；年度无票收入在100万元以内时，按2.5%的比例处理，压力不大。
- 不建议：一般计税。货款进对公账户先承担13%的销项税，想抵扣必须取得专用发票，资金和票据门槛都更高。

各地执行细节会有差异，直接问当地代账公司即可。
