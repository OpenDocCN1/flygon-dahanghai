# 2.1.3 收购公司前，先把风险查透

接手一家现成公司，签字只是最后一步，真正关键的是前面的底细核查。判断标的公司有没有隐患，通常从三个方面入手：

1）用第三方工具做风险扫描  
企查查、天眼查这类应用，是常用的查询渠道。以企查查为例，重点看经营风险、法律诉讼和历史信息三个版块，其余栏目扫一眼即可。

2）核实税务状态：是否开通、有无逾期  
这一项可以委托本地第三方财税机构代查，也可以亲自跑一趟行政审批大厅，确认税务有没有逾期记录、是否已完成开通并正常报税等。

3）确认没有对公账户，以排除企业贷款  
这项查询难度相对较高。常见做法是找当地规模较大、口碑较好的第三方财税机构，收购其自持的客户执照，因为对方底细清楚；只要确认没有对公户，一般就能判断该公司不存在企业贷款。

**收购过程中还要盯紧这些事项**

在美团电商项目的风险控制里，公司收购是关键一环。变更细节若出岔子、反复办理，会拖慢店铺入驻进度，不能马虎。下面列出常见问题与变更时需留意的地方：

2）一张执照配一位法人，把风险拆开  
平台允许同一法人名下多个公司执照入驻，但为了隔离风险，建议一张执照对应一位法人，尽量把平台重大违规风险压到最低；

3）对公户先注销，再接手公司  
收购时签署免责协议，可请当地第三方财税协助拟定；把双方责任的时间分界写清楚，避免后续税务等问题被追溯；

4）注册资本过高，优先考虑减资  
注册资本越高，通常意味着责任越重。超过一百万元的建议减资；减资需要登报或公示约45天，具体可咨询当地第三方机构。实际操作中，我们通常直接更换其他执照；

5）接手后建议变更公司名称  
这样双方责任边界更清晰，后续若出现税务违规或其他违法违规情况，也更容易明确责任；

6）并非零申报，服务费提前谈妥  
美团的货款、后续退店时提取的保证金，走的都是对公账户；账户一旦有资金进出，通常就会被认定为非零申报。所以服务费要事先和财税公司敲定，防止后期临时加价，把店铺运营成本推高；

7）对公账户资金别直接进个人卡  
金税四期落地后，对公转私的审查力度明显加大。我们通常先注册个体工商户，再走公转私；具体怎么做，建议向财税机构了解本地政策。
