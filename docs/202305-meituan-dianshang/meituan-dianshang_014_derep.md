# 2.1.1 找代账三方，别只盯着低价

当手头暂时没有注册满一年、且条件达标的公司时，更实际的做法是优先在本地找财税三方，也就是大家常说的代账公司，委托它们协助完成公司收购。整个收购流程通常至少要7到9个工作日才能走完。

这类机构主要能帮三件事：一是充当中间人，对接持有满一年执照的卖家，同时把税务等风险提前筛一遍；二是代办工商变更，包括法人、股权和经营范围等事项；三是协助开立对公账户。

渠道上，本地收购应放在第一位。可以先去本地工商行政审批大厅的商户群打听，一般大厅就有这类资源，问咨询引导台即可；亲友推荐的机构也优先联系。58同城作为补充渠道，多聊几家，再择优选用。找渠道这一步很关键，会直接影响公司收购等服务的质量和速度。优先选本地审批大厅商户群，以及亲友实际合作过的财税公司，并把风险筛查要求说透，后续真出问题也有追溯路径。58同城放在次选位置，多咨询几家，当地报价和服务边界基本就能摸清。

备选方案是淘宝、拼多多等平台上的异地收购。和本地收执照相比，异地模式有个明显短板：像变更经营范围这类小调整，每次都得让三方机构跑腿，单次费用大约300到500元；若遇到打假等麻烦事，还得到执照注册城市去处理，费时费力。

价格方面，以青岛为例：非零报税约1500元；公司转让费加上过户、对公账户跑腿费，合计约1500元。若你能自己提供执照注册地址，整套办下来通常在3000元左右，里面含执照收购、过户跑腿和一年报税；没有注册地址的话，还得额外支付地址购买费用。

代账行业报价弹性很大，建议多沟通、多比较，货比N家后再决定。
