# 2.1.4 开店前，手机号和淘宝采购号要备足

做美团电商之前，手机号和淘宝采购号都得提前安排，不然实际操作时很容易被卡住。

**手机号准备**

在美团电商体系里，同一个手机号只有一次使用机会。不管它关联的账号最后有没有入驻成功，这个号码都算已经用过了；在还没有其他号码可以换绑出来之前，不能用它再次提交。按一般情况，一张营业执照如果要提交10家以上店铺，通常就得准备10个手机号。

几个实用做法：

1）移动、联通、电信的号码都可以备一些，优先选月租低的套餐；
2）前期可以先用朋友的号码顶上，等店铺入驻完成后再换成自己的手机号；
3）要避开只能接收短信的小运营商号码，比如铁岭通信、民生通信这类。

**淘宝采购号准备**

我们搬运的商品主要来自淘宝和天猫。淘宝对单个账号每天的下单量有上限，拍得太多容易把号拍废，所以需要准备足够多的淘宝账号来做拍单采购，等后面订单量突然上涨时才不会缺号。前期先备4到8个基本够用。

1）优先选淘气值超过1000的老号，新注册的号也能用；
2）一个采购号一天的下单量尽量别超过30单；新注册的淘宝号，第一周内每天控制在10单以内。
