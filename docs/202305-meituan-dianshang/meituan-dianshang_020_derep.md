# 2.2.1 一张营业执照，能开几家店？

先说商品规则：同一家店铺里，不能把同样的商品换个链接重复上架。比如一家公司名下开了 A、B 两个店，A 店已经在卖 450ml 可口可乐，那么 A 店就不能再用另一个链接卖同款 450ml 可乐；但 B 店不受影响，可以正常上架这款商品。

再看店铺数量：在同一个一级类目下，一张营业执照最多只能开 3 家店，而且这 3 家店对应的二级类目必须各不相同。以美团“居家生活”这个一级类目为例，理论上这张执照只能在这里入驻 3 家店铺，且三家店的二级类目要分别落在“潮流玩具”“家庭清洁”“日用百货”这样完全不同的方向上。也就是说，理论上的下店上限可以按“一级类目数 × 3 家”来算。不过，美团当下对下店数量还有隐性管控，实际能开几家存在较大不确定性，随机性很强。
