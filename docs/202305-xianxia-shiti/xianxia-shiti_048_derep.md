# 3.3.2 朋友圈分享，别硬来 @Mage @乔合

不少获客渠道走到最后，都能顺势把客人引到朋友圈分享这一步。在我看来，这是性价比较高的宣传方式。不过，如果直接要求客户转发，往往适得其反，抵触情绪会很明显。

常见做法有两种：

一是用优惠来换。客户预订时如果提出要折扣，就提前把规则谈清楚：参与的人把活动信息发到朋友圈，保持12小时且不对任何人屏蔽，即可享受优惠。这种方式最直接，执行起来也省心。

二是帮客户留下记录。每场接待时给客人拍一段短视频，视频末尾放上我的宣传二维码。

从实际运营数据看：平台用户的忠诚度并不高，可选空间大；私域的效果最突出，二次复购率平均能到10%—15%。也有客人偏爱我们的风格，来过3次以上。

此外，还可以邀请网红到店打卡，请她们发朋友圈并带上门店定位。
