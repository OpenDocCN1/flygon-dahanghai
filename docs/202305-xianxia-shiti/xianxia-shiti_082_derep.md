# 5.3 让成长记录成为续费理由 @芷蓝

先问一句：对你来说，最值钱的东西是什么？

不少人会脱口而出：金钱、奢侈品、头衔和成绩。可这些说到底都是身外之物。假如要用你的成长记忆去交换它们，你真的愿意吗？

所以，对一个想成长、也愿意花钱买服务来提速的人来说，一路走来的成长印记，比那些外在东西更珍贵。商家若能把用户的这些印记留存下来，再用可视化的方式呈现，多数用户都会乐意长期保留这份记录。这正是续费的动力所在。

那具体该怎么做？

① 建档留存

在舞蹈室，用户只要买了课程，我就会给她建一份个人档案，记录起步阶段的数据，包括三维、体重、体态、体能、舞蹈水平、用户需求和个人资料等。

保存方式分两类：个人资料放在微信里，用标签和备注记录；舞蹈水平、体态等内容则存进硬盘，以视频形式保留。

② 节点更新

用户学习过程中有了新突破，就要在关键时间点更新数据。比如每学完一支成品舞，单独为她录一段视频；体重下降时，拍照留档。

③ 成果呈现

我还会隔一段时间，把学员这段时间上课的照片和视频发给她。这些素材只针对她本人，目的就是让她看见自己的变化、成长轨迹，也看见我一直在替她保存一点一滴的记忆。

舞蹈室里有一面墙，专门贴学员跳舞的照片，让她们看到自己的精彩瞬间。我还放了照片打印机，方便学员把照片快速打出来留作纪念。

一张张照片，记录着每位学员在这间舞蹈室里的回忆。用户舍不得放下这些回忆，自然也更愿意继续续费。
