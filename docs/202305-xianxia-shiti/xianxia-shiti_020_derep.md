# 3.2.1 同城号，实体店的新客流入口

💡 本节要点

线下门店的成本账正在重算。以往租金大约要占营收的两到三成；如果能把租金压到一成，省下来的那一成转投抖音同城号的搭建或推广，往往能换来更多到店顾客。连锁品牌，特别是加盟型品牌，最可能吃到这波同城红利。

这一节，我们分四块来拆：

✅ 第一块，讲清本地生活业务的内核，以及商家为什么要入局；
✅ 第二块，落到门店认领，并说明怎样让短视频定位、同城页面、直播间里挂出自己的门店入口；
✅ 第三块，拆几个同城号案例，看看内容可以怎么设计；
✅ 第四块，整理做同城号要留意的六个坑，再给几种适合尝试的入局方式。

哪怕不亲自做内容，开通本地生活后，也能用分佣方式请达人替门店推广。所以，现在就去抖音把门店认领下来吧。
