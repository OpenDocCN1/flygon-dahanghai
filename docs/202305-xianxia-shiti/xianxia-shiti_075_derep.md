# 4.2.1 客户不下单，多半卡在这三问

成交推进不下去时，别急着把原因归结为价格高、客户爱拖、总挑小毛病。表面理由看着不少，背后其实是客户心里绕不开的三道关：他凭什么掏钱？凭什么选你？凭什么现在就定？

这三句话，客户通常不会直接问出口，却会在决策时反复琢磨。要是你能提前为每个问题备好答案，甚至反过来打磨产品和服务，那么成交一旦卡住，就更容易顺势化解。

更细的理解与应对，这里不再展开，可翻阅《门店私域运营 | 小航海学习手册》第2.2节“成交的核心逻辑”。至于朋友圈剧本、社群快闪、一对一私聊等成交动作怎么做，手册第3节“门店成交杀手锏”已有步骤拆解，可按自身情况挑选合适打法。
