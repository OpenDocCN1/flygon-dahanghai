# 3.6.3 门店周边，先铺满100个触点

离店最近的那圈人，才是门店最该珍惜的流量资产。

每天有人从门口路过、进店消费，或在附近居住，却没被加到🛰️；反倒花力气去抖音、📕、美团用免费内容拉陌生人。这笔账怎么算都不划算。

所以，店内店外至少要布下100个可触达点位，也就是100个引流抓手。只要这个动作做到位，每天引入私域的人数就会明显增加。若能把免费诱饵升级成付费钩子，效果会更猛。

店内空间别浪费：门头、菜单、收银台、桌面、海报、走廊、休息区、背景墙、洗手间等，都能变成入口。

店外半径也要用起来：500—1000米内的周边商户联合、🛰️群、团购负责人、社区组织，能加入的渠道先加入，能谈合作的去谈，值得花钱的就花钱。

关键只有一条：每张引流海报都得有钩子，也就是给客户一个加你的理由。

门店真正的护城河，不是别的，而是把客户持续导入私域、再用心运营好。其他都是虚的。
