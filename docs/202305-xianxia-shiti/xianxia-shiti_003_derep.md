# 1.1 私域流量到底在“私”什么？

说到底，私域流量要解决的是四件事：让拉新投入更省，让产品或服务被反复购买的比例更高，让商家与用户之间的关系更紧密，并把单个用户长期可能产生的价值充分释放出来。

如果你做过直销、电话销售或大客户经理，大概率接触过 CRM，也就是客户关系管理软件。它可以为顾客标注性别、年龄、住址、收入、地区、年收入等多维度信息，也能把双方沟通的节点和频率记录在案。

换个更直白的理解方式：把私域流量看作一套长在社交场景里的客户关系管理系统，也未尝不可。

私域流量 = SCRM（Social Customer Relationship Management）

过去，企业常用 OA、销售易、SAP 等工具维护客户；如今，企业微信、朋友圈、社群、小程序、公众号以及视频号这六个触点，正在成为管理客户并促成交易的新阵地。

看清这一点，也就理解了为什么我们需要认真研究私域流量运营。
