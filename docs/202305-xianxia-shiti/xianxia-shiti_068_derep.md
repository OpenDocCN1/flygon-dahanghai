# 3.6.10 引流要全员上阵

门店获客这件事，老板不能只当指挥者，自己得先弄明白怎么做；随后把店里每个人都拉进来配合。更关键的是，把每位员工的拉新任务写进考核，让目标和收入真正关联。光定指标还不够，还要教他们怎么找客户、怎么聊、怎么把咨询变成成交。日常也别放手不管，要持续跟进、抽查、复盘。

这套动作，通常只有老板推得动，交给店长未必能落地。可一旦真跑起来，门店能释放出的战斗力，会明显强过那些把获客寄托给外部团队的门店。

客户装进哪里？可以统一放在老板的门店账号里，也可以给员工配工作手机和工作微信，明确任务，把到店和线上接触到的客户都加到这些账号中。打个比方，5名员工每人积累5000位客户，这就是一笔可随时调用的私域资产。哪怕门店因合同到期搬到隔壁，甚至暂时不开了，靠这5部手机里的客户关系，也能很快找到变现路径。

当然，手机和微信号交出去之前，先签一份基础约定，把归属、使用和交接说清楚；账号也别急着推销，先正常维护、养熟，再逐步做营销动作。

内容来源：《给实体门店老板引流的 10 个建议》
