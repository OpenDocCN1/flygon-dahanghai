# 3.2.5.2 地图收录实操指南

准确提交资料，地图收录并不复杂。提前把下面几项备齐，去对应平台申请就行。

1. 门面照：正面、左侧、右侧，三个角度各拍一张。
2. 店铺名称：填写的名称，尽量与招牌上的一致，方便顾客认准。
3. 详细地址：写全“省（市）+ 区（县）+ 街道 + 门牌号”，精度越细越好。
4. 联系电话：座机或手机号，留一个能打通的即可。
5. 定位信息：把地图上的具体位置标记好。

全程自己操作就行，不需要求助别人。只要资料没问题，工作日提交，一般当天就能审核通过。
