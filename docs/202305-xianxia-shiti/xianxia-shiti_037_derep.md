# 3.2.4.3 引流避坑：这三个坑别急着踩 @怡伶 78667

做门店引流，最怕的不是没动作，而是动作做早了、钱花偏了。下面三个坑，都是我亲身踩出来的经验。

避坑点 1：套餐没吸引力，先别急着投推广
我们最早挂上去的清一色是油画体验类套餐，开局流量很冷，一天进店也就三四十人。那时候着急，听了大众业务人员的建议，充值开了推广通。每小时消耗不低，前后投进去一万多，结果成交几乎挂零：来的人要么不是精准顾客，要么对店里的项目提不起兴趣。
后来复盘才清楚，套餐本身不够抓人、新店评分又还没养起来，这时候砸预算基本等于白烧。大众的定位是帮大家发现吃喝玩乐的好去处，平台上不乏优惠套餐和活动价；用户做选择时，往往先比谁家更便宜、谁家好评更多。产品或套餐没有吸引力，运营花样再多也难带来客户。

避坑点 2：好评差评要当正经运营来做
前面说了，大众用户下单前会看店铺评分。我起初没把评价维护当回事，因为成交大多发生在私域或门店，也没习惯请顾客去大众写点评。后来生意慢慢火起来，一些同行跑来恶意差评，平台还帮我拦截过几次，可评分还是肉眼可见地下滑，店铺形象也受了影响。接下来，我会用运营手段把这块优化起来。

避坑点 3：图片修得太精致，反而让人警惕
📕上的艺术类内容确实吃颜值，图片要精致好看；但大众更看重真实的用户体验封面。图修得太完美，别人第一反应可能是广告。所以发在大众的图片尽量少修，保留真实感，文案也放软一点、客观一点，反而更有机会跑出爆款。
