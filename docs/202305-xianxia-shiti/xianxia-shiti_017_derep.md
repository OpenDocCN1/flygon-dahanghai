# 三、门店获客渠道全解

这一节开始，咱们不再停留在概念上，直接进入获客落地环节。

过去，实体店做的基本是周边几公里内的生意，宣传上也得靠不少人工去跑。互联网起来以后，线下门店确实受到了冲击，但换个角度看，各类线上平台同样能成为门店的宣传阵地：不再被营业时段、门店位置和宣传人手卡住，还能触达以前很难覆盖到的新客流。

下面就把常见渠道拆开讲，看看每个渠道具体怎么下手：

• 门店顾客导入：面对面引导顾客、用电话或短信做提醒、把顾客加到🛰️、借助外卖红包促成回流。
• 线上公域获客：抖音和📕做内容曝光，也可以找达人合作；大众点评、美团承接搜索和团购；地图平台方便附近顾客找到店；豆瓣等同城社区同样值得布局。
• 🛰️生态裂变：引导老客在🛰️里转介绍、发朋友圈扩散、进本地生活群做推广、投放本地👸号广告。
• 线下动作：张贴海报、地推、分销、异业合作。

本章末尾，还给老板们整理了10条获客建议，方便对照参考。

还要提醒一句：每个渠道的人群偏好不一样，吸引他们留下的“钩子”也不能一套打天下，要结合渠道用户的特点来设计。

获客方法没有唯一答案。建议你结合门店实际情况挑选渠道，把多种方式组合起来测试，跑出适合自己的方案并持续执行。如果你手里还有好用的获客招数，也欢迎一起分享。
