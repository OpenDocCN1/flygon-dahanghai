# 3.1 线下顾客转私域，先做这四步

把门店已有顾客沉淀到个人微信号，是私域起步的关键动作。常见路径有四类：一是通过电话或短信批量提醒会员，引导他们添加个人号，并告知用个人号下单可享优惠；二是在外卖订单中放入邀请卡，顾客扫码加微信即可领红包；三是把杯套做成独立物料，印上进门店福利群的入口；四是让到店顾客扫码入群，现场领取福利红包。

已有消费记录的顾客与复购客，通常对门店和商品有一定信赖，也愿意相信店长、店员的为人，转化进私域的难度自然更低。平时可借朋友圈内容曝光、微信一对一问候等方式保持联系，把顾客引到群里，持续补足他们对品牌与商品的认知，再叠加更有价值的服务，促使他们二次消费或带动身边人到店。

线下门店天然有社交场景，老客口碑推荐带来的流量也不容小觑。这些用户存在潜在消费意愿，却对门店和品牌缺少了解，多半是信任朋友才来体验。一旦进入私域，他们很可能沉淀为深度用户，成为下一批种子流量。
