# 3.4.1 线下海报怎么贴才能精准获客？@Mage

线下地推不用铺太远，圈定门店周边0到8公里，把海报放进写字楼一楼或高校内部。和店家聊下来，通常一个季度100到150块就能搞定。投放位置如果选得好，每周光靠在墙上的海报就能被动带来三五个扫码加微信的人。更关键的是，愿意主动扫码的用户，购买意向往往更强。拿到添加数据后，按客户所在位置去复盘，筛选出真正高效的渠道，随后只对表现好的点位做续费。
