# 4.2 成交：先回答这三个问题

先别急着往下看，不妨先做个小测试：你所在的行业，平时是怎么促成交易的？你的客户究竟是谁？他们对你的产品满意吗？真要掏钱的时候，他们又会在担心什么？

把这些事想透了，你会发现客户真正纠结的其实就三点：

- 为什么要买？
- 为什么要跟你买？
- 为什么现在就要买？

只要把这三大问号一一解决，成交自然水到渠成。接下来，再配合朋友圈剧本、社群快闪、1对1私聊、浪潮式发售等具体玩法，就能稳稳地推进交易。如果是线下门店，在做好线下消费转化的同时，有条件的话也可以尝试线上变现，多给自己增加一条收入来源。

至于这些方法具体怎么落地，别急，我们接着往下看。
