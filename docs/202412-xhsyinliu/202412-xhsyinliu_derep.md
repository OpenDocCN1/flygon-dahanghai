# 写在前面：三个问题先弄清楚

💡 12 月航海的主题是教育资料在小红书的引流变现。正式开工前，先把三件要紧事交代清楚。

**1）这个项目具体是什么？**

用一句话概括：在小红书持续发布优质内容，吸引教育方向的用户进入微信私域，再把资料类产品卖给他们，完成变现闭环。市面上它也被叫做学科资料变现、小红书学科教辅、小红书虚拟资料、小红书虚拟电商，名称虽有差异，生意模型没有本质区别。

这条路上有两个公认的卡点：其一，怎样在平台规则内低调完成引流，不被限流；其二，怎样搭建出属于自己的资料库。后面会详细拆解。

**2）现在做还有多少空间？**

教育始终是全社会关心的大事，“再穷不能穷教育”已经说明了它的分量。再加上政策持续鼓励行业发展，眼下仍处于红利窗口。几乎每个人都有可能成为学习资料的需求方，市场体量自然不小。

从小红书这个平台看，用户付费意愿强、消费潜力大，人群画像和这个赛道的匹配度也比较高。不过要清醒一点：前几年那种靠搬运、洗稿就能轻松赚钱的日子已经结束了，现在必须认真做内容，才可能持续拿到结果。

学习资料大部分是虚拟产品，对比传统电商有不少优势——不用垫钱进货，不需要物流和仓库，成本低、利润高，售后问题也少。这个项目本质上属于“重运营、轻交付”，更大的精力要花在内容制作和引流获客上。

**3）谁更适合来做这件事？**

四类人比较合适：一是有教育资料变现意愿的人；二是在找副业或在家创业的人；三是教育领域里苦于流量增长的人；四是已经有教育产品、或者能和机构谈下分销合作的人。

总的来看，项目门槛不算高，操作难度也不大，多数人都能试。流量随着时间一点点沉淀，收益会慢慢变得可观。

# 一、先搞清楚这门生意

# 1.1 项目到底在做什么

这套模式的本质是：把对教育内容感兴趣的精准用户引到私域，再为他们匹配高需求度的资料产品，最终完成销售转化。

这个项目在不同圈子里叫法不一：有人叫学科资料变现，有人叫小红书学科教辅，也有人叫小红书虚拟资料或小红书虚拟电商。名字换来换去，本质都是通过小红书做大流量池，再借教学资料实现收入。

教育在国内的需求水位一直很高，而且热度只增不减。拿高考志愿填报来说，艾媒咨询数据显示，2023 年中国高考志愿付费市场规模已达 9.5 亿元，相当于 2016 年的 7.3 倍。

看三组真实案例，能更直观地感受这个项目的体量：

一位卖家把 PPT 模板定价 139 元，累计卖掉 9167 份，总流水 127 万 4213 元。模板开发完成后，后续成本几乎只剩平台约 5% 的提现手续费，边际成本无限趋近于零，相当于一个人净赚 120 万上下。

另一个案例是每天翻译搬运一篇外网文章，会员费 169 元一年，卖出 2.1 万份以上，累计收入 354 万 9000 元。还有一门手机摄影课，199 元定价售出 3 万多单，营收合计超过 597 万元。

第三个案例更有意思：有人专心分享留学干货，吸引家长来咨询，再把订单转给留学机构或个人工作室完成文书交付。30 万咨询费直接抽成 30%，9 万落进自己口袋。

为什么引流要放在小红书做？先看平台和用户的匹配度。

第一，人群够精准。平台上约 80% 的女性用户年龄在 18—34 岁之间，正好和这个项目的目标人群高度重合。想一想身边的年轻女性，除了抖音和各种社交应用，打开最多的就是小红书。

第二，搜索场景够强。现在的年轻人已经把小某书当成第二大搜索引擎来用，平台天然是种草分享社区。认真输出有价值的内容、有信息量的笔记，很容易赢得信任；再通过方法引导点赞、收藏、评论、关注，最后把流量导入私域，成交会更顺。

第三，付费意愿够高。女性在消费决策中的影响力不言而喻，小红书用户在做购买决定时也比很多平台的用户更果断。只要图文把产品讲清楚，往往能安利到一大批人。

再往深一层看，还有四个理由支撑这个选择。

第一个理由：用户特质和赛道高度匹配。在小红书看少儿教育内容的家长大多来自一二线城市，自身教育水平不低，重视素质教育和快乐教育，对子女教育投入舍得花钱。同时，整个平台用户偏年轻，实用主义明显，提升职业技能和竞争力是核心学习动机，对成人教育机构同样是优质客群。整体来看，小红书的用户画像符合教育领域的消费群体，尤其契合网上直接买资料这种低决策成本的行为。

第二个理由：种草属性强，信任建立快。![](img/faa1af64e58f2f777841f6e9179cb3e5.png)

小红书是社交型种草平台，好的内容加上明确的账号定位，就能快速圈住目标用户。课堂笔记、论文答辩、学习打卡、准留子出圈指南……越来越多年轻人习惯在小红书分享学习日常、交流备考经验，也在上面寻找各种“上岸”方法论。过去一年，小红书教育行业的内容增长 665%，教育行业专业号数量增长 181%，教育领域的流量洼地已经相当明显。

第三个理由：教育生态完整，人群好找。![](img/1b4a6bdf2c449767d19f82d49539d2c5.png)

考公、考研、英语学习等话题这些年持续升温，小红书教育类内容整体暴涨 665%，创作者数量超过 130 万，产出的教育内容笔记超过 5000 万条。国内教育体系的各个细分方向，在小红书基本都能找到对应内容。某些小众需求或垂直赛道内容还很少，反过来看，这恰恰是蓝海机会。

第四个理由：用户自我驱动强，容易引发共鸣。![](img/c5122e859cfe3a7bbd4bf914bb9629a6.png)

举个例子，一位家长刷到老师分享的学霸手写笔记，再想到自家孩子时常年级倒数，购买冲动很容易被点燃。再比如备考学生看到前辈把往年考试重点做了梳理和批注，会立刻想拥有。还有正在备课的教师，在小红书里找案例素材时看到全国名校教案合集，一样会马上心动。

教育资料引流的完整流程分六步：

第 1 步，定赛道。这一步考验市场数据分析能力。需要把国内教育领域的主要细分赛道摸一遍，再结合小红书用户的实际需求做判断。定了赛道，账号定位和内容选题才有依据。第一阶段会逐个介绍国内大部分教育细分领域，并帮你结合自身优势做选择。

第 2 步，理产品。赛道确定后要匹配对应的资料产品，考验资料的检索和整理能力。第一阶段会教大家如何整理资料、搭建产品库，为后续变现做好准备。

第 3 步，搭账号。根据赛道方向搭建小红书账号 IP，这一步看定位能力。所有搭建细节都会在第一阶段给出指引。

第 4 步，做内容。方向、产品、账号都备齐后，就进入作品制作环节。第二阶段会一步步拆解爆款笔记的制作方法，希望大家亲自动手，把手弄脏。

第 5 步，导私域。作品一旦爆了，流量很大，但要是这些流量无法进入私域，产出就会大打折扣。第二阶段会分享小红书导流私域的具体技巧，尽量避免这种浪费。

第 6 步，做转化。最后一步是在私域里完成成交，涉及话术、朋友圈经营、私域运营技巧和注意事项。第三阶段会针对私域板块展开高强度训练，这也是当下互联网从业者普遍稀缺的能力。

六步走完，整个商业闭环就完整了。恭喜，你实现了从 0 到 1 的变现。

# 1.2 变现方式：新手先卖资料包

卖教育资料这条路，主流变现方式有 8 种。这次航海选择最容易上手、门槛最低的“出售资料包变现”带大家实操，剩下 7 种放在选修里展开。

变现形式 1，单种资源销售。以 K12 领域来说，可以是语文、数学、英语、科学、道德与法治、音乐、美术等科目中的任意一种资料。以英语四六级来说，词汇表、语法精讲、历年真题解析、模拟试题、听力练习、口语练习都可以单卖。客单价一般几十到几百元不等，具体看所在赛道的行情。

变现形式 2，付费社群打包卖。还是举 K12 的例子，可以建学期群、学年群、全年级学科群，也可以卖永久资料会员。英语四六级方向则可以做成四级 VIP 全程班、六级 VIP 班这类产品。打包销售通常比单品定价更高，从几十元到几百元甚至上千都有可能，同样取决于赛道情况。

# 二、选定你的赛道

💡 章节概要：选择大于努力，方向不对，努力白费。在优质赛道深耕带来的回报，大多数时候都超过在低质赛道上的投入。赛道既决定了起跑线，也划定了天花板。

# 2.1 从经历里找赛道

选赛道最靠谱的方法是顺着自己的经历来：求学的轨迹、工作的积累、兴趣爱好、身份角色，都可以作为出发点。

千万不要像叶公好龙那样，把“自己没经历过、只是脑子一热觉得不错”的方向当成赛道。你走过的每段路都不会白费，把它当成礼物来用。举几个例子：

如果你从专科起步，专升本后考上研究生，那么专升本和考研两个方向就天然适合你。

如果你做过英语教师，或者带过英语家教，总之和英语教育沾边，那么可以去做英语方向。

如果你喜欢把读书心得、课程笔记整理成竖屏思维导图，那竖屏思维导图这个赛道就值得认真考虑。

如果你是一位宝妈，女儿正在上小学一年级，那一年级资料是一个切入口，也可以继续找宝妈能变现的事情来做。

实在拿不定主意，就让教练推荐一个。最好选择和教练一样的赛道，甚至直接卖一样的产品，遇到问题随时找他。毕竟骑着同行过河，不如骑着教练过河来得快。

# 三、竞品调查

# 💡

本章导读：为何要研究同行？

在小红书靠资料变现，有一条朴素法则：谁已经跑通，就向谁看齐。

因此，研究同行的目的很明确：找出谁的产品卖得动、卖点是什么、流量入口在哪、成交环节又是怎样设计的。

在锁定模仿对象之前，先定一个主推品。它可以是付费资料包，也可以是和机构联合开发的视频课。若做小学方向，主推付费资料更合适；若做考公考研，则更适合选机构合作课程。

# 3.1 如何拆解一百位同行

挑选参考对象时，优先找与自己条件接近、稍微努力一把就能追上的账号。

所谓条件接近，指业务链条相似：卖的是付费资料，获客靠小红书，最终在微信里完成交易。

所谓稍微努力就能追上，就是选择处在自己学习区里的动作。人的能力圈可以分为舒适区、学习区和恐慌区。假如你从未做过图文，第一次不妨用资料截图加贴纸的形式，只需掌握截图和贴纸；不必一上来就追求复杂背景、耗时数小时的高原创图文。

分析同行并不需要花哨技巧。认真拆够一百个样本，账号主页如何布置、微信端成交话术怎么设计，基本就能摸清。

![](img/c7b580d2616a5c3698f2d85575c11049.png)

样本拆完后，接着要核算收益。做生意先算亏盈，若连账都没算清就开干，一旦亏了很难收场。

怎样估算一位同行的营收？可以观察其朋友圈群成员截图，或快团团的成交方式。假设对方快团团每天约有十人下单，客单价五十元，那么日销售额就是五百元。虚拟资料几乎没有边际成本，因此这五百元基本可视为日利润。

用同样方法推算一批同行的利润，再做正态分布。例如两成同行月入十万，六成月入一万，另两成月入五千。

把同行的账算明白后，自己下场大概率能做到月入一万。若你在学习或执行上本就属于前百分之二十，月入十万也并非没有可能。

随后从调研表里挑出前十名，照着他们的路径走，甚至可以一比一复刻：小红书昵称头像、微信头像昵称，乃至朋友圈内容，都可以先模仿再优化。

# 3.2 理清业务路径

假设选定二年级上册语文这一细分方向，面向家长售卖付费资料，需要先想明白：

1. 第一，弄清模式：产品为付费资料，流量来自小红书，成交放在微信。
2. 第二，明确目标：挣到一元算跑通，收回成本算有结果，赚回十倍才叫大结果。先做到单月盈利一元。
3. 第三，拆分目标：产品、流量、转化三个环节要串成完整链路，并延伸到交付与售后，形成闭环。

二是成本最小化，既包括时间精力，也包括资金投入。比如：

4. 在时间精力上，业务链路越短越好。
参考做法：产品可先向同行获取或购买。交付时，百度网盘支持一键转存；QQ群则要逐份操作，明显更费事，因此优先选用百度网盘。

# 4.1.2 养号方法

哪些情况需要养号？
- 刚注册的新号；
- 被平台警告过，例如禁言24小时、3天、7天，或权重被降低的号；
- 注册已久、准备开始发笔记的老号。

1）养号第一天
1. 注册完成后，确保一机一卡一号。若批量起号，超过三个账号时，每个账号注册间隔至少四小时。
2. 注册时选择兴趣内容，要与自己的赛道相关。比如做小学教师资料，就选育儿、学习类。
3. 其他设置先不动，进入首页刷推荐内容，自然浏览，适度点赞、评论、收藏，避开敏感内容。
4. 像平时刷抖音、B站那样，累计刷一个半小时以上，可分段也可连续。第一天把自己当成普通用户，点开的笔记要看完，再适度互动。

⚠️ 重点提醒：注册时务必用流量，别连无线网。否则多个账号共用一个IP，容易被判定为营销号，流量起不来。我们团队的工作机从不连WiFi，还会偶尔带出门使用，尽量表现得像正常手机。

2）养号第二天
5. 确定账号定位，完善头像和昵称。
6. 延续前一天的操作，在首页和同城页刷推荐内容两小时以上，自然浏览，适度互动，不碰敏感内容。

3）养号第三天
7. 在搜索框输入同领域关键词。做小学教师资料，可搜“小学一年级语文”“新手班主任”“小学班主任”；做绝版书，可搜“书籍推荐”“古书推荐”“绝版书”；做小吃配方，可搜“配方分享”“摆摊小吃配方”“各种小吃技术配方”。早、中、晚各刷三十分钟。优先关注粉丝量大的账号，多点赞收藏互动，后续更容易获得系统推荐。
8. 继续浏览同领域对标内容，早中晚各三十分钟，不要刷得太快。
9. 也可以在小红书买点东西，比如搜“9.9r一箱”找些便宜又不错的水果。购买行为能增强账号真实感、提升权重，不做也不影响。

4）养号第四天
10. 继续看同领域账号和笔记，早中晚各三十分钟，节奏放慢。
11. 按人设修改签名，切记别留联系方式。
12. 提前编辑好次日要发的图文。养号结束后的一个月内尽量每天更新，保证内容质量，更利于系统推荐。

5）发布首篇笔记
发布后连续三到五天保持浏览作品的动作，每天一小时。

⚠️ 注意：发布后别频繁点开自己的作品，也不要过度解读数据。

在小红书养号、提升权重并争取更多流量，可关注以下要点：

1. 注册初期别急着完善资料，只填性别、年龄和兴趣领域。头像、简介等可等到发布前一天再改。
2. 养号周期通常至少三到五天，有些领域要十天到半个月。我们这个方向养三到四天即可，不要拖过一周。
3. 坚持一卡一机一号。一个账号对应独立手机号和设备，不要在同一台手机切换账号，也别在同一局域网登录多个号，以免触发风控限流。
4. 每天至少活跃三十分钟，时间分散，模仿正常用户，避免集中操作。
5. 互动量要适度。比如每天点赞不超过五个，收藏五到十个，评论不超过六条，关注两到五个，保持自然节奏。
6. 浏览内容要贴合账号定位，提升垂直度，便于平台推荐更精准。
7. 养号过程中，可在第三或第四天完善昵称、头像、背景、简介等资料，让账号更专业、更贴合定位。
8. 不要参与互粉互赞群或刷量，这类行为会被视为恶意营销，可能导致账号受限。
9. 养号期间不必急着发内容。开始发布后要保证质量与定位一致，每天一到三篇，可带定位增强真实感。
10. 熟悉并遵守小红书社区规范和运营规则，不发违禁内容、不用违禁词，确保账号安全。

# 4.3 微信号快速包装法

# 4.3.1 怎么起一个好记的微信号

微信号一年只能改一次，下手前一定要想清楚。

建议先把候选名字写在纸上，至少写10个，再一个一个地去试。为了客户容易搜到你，也注意两点：别带特殊符号；别用大写字母。

一个让人过目不忘的微信号，核心就四个字：短、好读、有规律、有个性。微信号一般是字母加数字的组合，相当于你的账户专属ID。下面是六条实用设计法：

1. 用名字缩写：姓名的拼音首字母或英文名缩写，比如李华可以用“lh”，个人色彩浓又好认。
2. 加入生日或纪念日：在缩写前后添加对你有意义的日期，比如“lh1985”或“lh1688”，故事感一下就出来了。
3. 挑好记的数字：重复数字（“888”）、连续数字（“123”）、幸运数字（“2021”）都行，如“lh888”“lh2021”。
4. 控制长度：不超过10位，6～10位最理想，短了别人好记，长了别人嫌麻烦。
5. 避开复杂符号：有些平台虽然允许特殊字符，但为了报号方便，最好只用字母和数字。
6. 先读再查：定稿前多念几遍，顺不顺口；再去微信里搜一下是否被占用。

按这个逻辑，张伟（生日1990年1月1日）的微信号可以设成“zw900101”或“zhangwei901”。

要是看了原则还是没灵感，就靠九宫格键盘凑。国内用户大多习惯九宫格，微信号按3～4个字母+3～4个数字来，比如adgm1234、mpt220。

注意几个容易踩的坑：

1. 容易混淆的字母和数字别用，比如i和1、0和O、u和U，这类不好区分的直接放弃。
2. 取字母时，优先用九宫格键盘上每个格子的首字母，比如ABC格的A、DEF格的D。
3. 能小写就别大写。大小写其实不影响加微信，但小写更省事。
4. 如果做矩阵账号，微信号也可以排排队，比如mpt220、mpt221、mpt222。万一mpt221被封了，用户着急时可能会自己往旁边试，去加mpt220或mpt222。
5. 别把手机号当微信号发给用户。你连另一半的手机号都未必背得出，就别指望用户记住你的号码。

# 5.1 步骤一：找到值得对标的账号

# 5.1.1 什么样的账号值得对标？

在任何一个内容平台上，先模仿同行的成功账号，都是高效做内容的方法。所谓对标账号，就是跟你处于同领域、同类型的账号。创作时，可以从它们的图文/视频形式、话题切入点等方面学习。

判断标准如下：

⭕ 粉丝数要少：1万以内，超过1万的暂时不看；
⭕ 点赞数要高：赞数大于粉丝数，说明内容有干货、有价值；
⭕ 时间窗口选最近一个月：周末流量大，只看一周的数据没有参考价值；
⭕ 主页频繁出现：刷主页时总能看到同一个封面，说明这个账号值得对标，直接抄作业就行。

想要做出爆款，核心就四块：选题心法、封面做法、标题起法、内容写法。

按数据体量，爆款可以分为：

⭕ 小爆款：点赞+收藏+评论总数≥200
⭕ 中等爆款：点赞+收藏+评论总数≥1000+
⭕ 大爆款：点赞+收藏+评论总数≥1w+
⭕ 超级爆款：点赞+收藏+评论总数≥10w+

# 5.1.2 找对标的五条路径

要锁定值得拆解的样本，不必漫无目的地刷。下面五条路，任选一条都能切入。

1. 首页用核心词检索  
把赛道主词打进首页搜索框——就是养号时反复查询的那些词。翻看前50条结果，从中挑两类：小爆款、中等爆款；再看留言区是否出现“求”“需要”“私我发”等信号。具备这些特征，样本就值得跟。账号层面，优先同一领域、起号时间在90—180天之间的创作者。

2. 借下拉联想判断需求  
在搜索框敲入赛道词，联想列表会浮出平台用户常查的方向。出现频率越高，说明需求越集中。再以两类爆款为尺子筛选题，挑出适合拆解的样本。  
![](img/ab5d868a8ea02c591b19fe6ef3263d05.png)

3. 看首页系统推荐  
养号动作完成后，系统会依据你的互动轨迹和兴趣标签推送内容，此时推荐流里同行内容占比会升高。仍按小爆款、中等爆款两档筛选，留下有参考价值的选题。

4. 顺热门话题找样本  
关注同领域表现好的账号，找出互动数据突出的帖子，点开其话题标签，再按小爆款、中等爆款两档过滤，得到可跟的优质选题。

# 5.2 流程二：持续产出爆款选题

# 💡

多数领域的发布节奏可参考8:2：八成为产品类笔记，用来成交；两成为行业干货，用来养权重、引流量。  
✔️ 产品类笔记：资料内容配合强标题、关键词与文案，目的在转化——用户本来就冲着产品来。  
✔️ 行业干货：用智能工具对爆款内容做二次加工，作用是扩大曝光、抬升账号权重，并沉淀更精准的受众。

# 5.2.1 连爆打法

爆款背后的规律，可以浓缩成“反复”。题材反复、形式反复、选择方向也反复。  
操作上：先临摹别人的爆款，多轮测试，直到自己跑出第一条爆款；跑通后，再复制自己的成功样本。  
平台上同一张封面配相近的强标题，竟能连续火三次。新人不必想得太玄，直接照着爆款样本做即可。某个内容能起量，说明它碰到了用户在意的地方；为何能碰到，不必硬钻，也很难钻透。  
记住：做平台账号，样本找对了，等于完成七成；余下就是反复、反复、再反复。

# 5.2.2 选题从哪里来

第一，翻自己的首页推荐（最好用）。

# 5.3 流程三：爆款标题制作SOP

# 5.3.1 标题拼配法

# 💡

这里借育种思路：把不同良种稻的优势配到一起，能得到更强的稻种。  
标题也能这样拼配。方法不复杂，效果很直接，我的爆款标题就是这样产出的，算是一种流量密码。  
例如查“纪录片—最热”，翻前十篇，会发现高频词集中在：央视推荐、绝了、建议收藏。最热前8篇里，有6篇标题高度接近——爆款往往在反复。直接提取关键词，重新排列组合，拼出来的标题更容易带爆款基因。  
![](img/4b69c56e64f267371c03bc8983f3d2a8.png)

★ 小建议：平时看到强标题，随手存进笔记，空闲时多翻，网感会慢慢积累。

# 5.3.2 正反刺激标题法

# 💡

底层逻辑：人倾向于省事、追求即时满足；动物性的基本驱动是趋乐避苦，因此可设计正向与负向两类刺激。  
标题公式：  
正向刺激：产品/方法+只需1秒（短期）+便可开挂（逆天效果）。  
语文赛道里流传很广的一种写法：把这几页材料啃透，考试像抄答案一样顺（见下图）。  
负向刺激：你不xxx+绝对会后悔（天大损失）+紧迫感。  
例如“你不看这篇文章就会错过一个亿，限时删除！！！”  
短视频平台上大量文案都用这招，本质是制造焦虑，有点损，但用户确实吃。  
背后是人们厌恶损失、受负面偏误影响：原始社会里，抓住一次机会可能只是多吃几口肉，但一次失误可能葬身虎口，进化让我们对负面消息更敏感。

# 5.4 流程四：封面与内页制作SOP

# 5.4.1 排版基本原则

# 5.4.1.1 封面三要点

✅ 给零基础作图的人几个抓手：封面排版先守住三件事。  
要点一：尺寸。  
竖屏用3:4，方形用1:1，横屏用4:3。竖版占屏更大，停留时间更长，信息承载更多，被划掉概率也更低。  
要点二：选图要准。  
视觉冲击强的高颜值图（可用AI生成）；简单清晰的手写风格（可手写）；适合合集、美食、旅游攻略等。  
要点三：文字要简。  
平台标题上限20个字符（表情占1～3个字符）。想补充信息，就要靠封面。用户刷发现页时往往没有明确目标，所以核心字要在画面里占足篇幅，概念清楚，直接告诉对方：这篇对你有用！从而引发点击。

# 5.4.1.2 二少原则：少变与少用

二少原则：少变、少用。  
第一，少变。封面版式别频繁换，尽量模板化、可替换；排版、字体、风格保持一致（颜色可在同色系内调整），主页更整齐，粉丝也更容易认出你。  
第二，少用。无关贴纸少放，避免抢走注意力、分散用户焦点。

# 3）用 SEO 卡住搜索流量

提前在配文中布局关键词，能让一条笔记持续获得源源不断的精准流量。所谓 SEO，举个例子：你做小学教师资料方向，用户只要在小红书搜“小学期末评语”相关字眼，就能看到你的内容。而且主动搜索的人往往消费需求强、付费意愿高，是非常精准的粉丝，成交率也高得多。

因此标题和配文中务必布局关键词，比如小吃配方方向的“夏日摆摊爆款”“xx（产品）配方”，创赛方向的“互联网＋”“三创赛”“xx（项目）计划书”“计划书完整版”，这样能大幅提升搜索排名和曝光量。

# 3）版面与分段

小红书很讲究精致感，版面安排很关键。多数用户是在碎片时间刷小红书，清晰的排版能显著提升阅读体验，让用户一眼抓住关键信息。最重要的两点：

1. 首图标题要提炼。首图必须打上笔记的核心内容，让用户第一时间判断这条内容对他有没有用，进而才会点击。

2. 配文要分段。如果是一大段文字，务必空行分段，并适当加入表情，用户读起来才更轻松。

# 4）挂上#话题

在正文末尾插入与主题相关的热门话题，挑选关联度高、浏览量大的。

比如要发一篇小学期末评语资料，在末尾点“#话题”输入期末评语，会弹出一串相关话题，挑最火的几个即可。另外可带上细分方向的关键词话题，例如 #二年级期末评语 #低年级期末评语 等。

以下三个动作，在阅读量偏低或异常时再操作：新笔记发布 24 小时内，若浏览量（小眼睛👀）仍停在 100 以下，或连续几篇的浏览量都不到 100。

1.

流量不动？三步排查法

内容发出去后数据没反应，别急着给账号判死刑。按下面三个动作挨个查，很快能判断问题出在哪。

第一项，走薯条推广通道验证。进入单篇内容，在右上角菜单里找“薯条推广”。只要系统放你进入付款选择页，这条内容基本就是正常的。

第二项，翻违规记录。从左上角“≡”进“帮助与客服”，再点“笔记申诉”，看违规清单。清单是空的，说明内容没问题。

3. 第三项，用搜索验证。换一个不常用账号，在搜索框输入标题；搜得到结果，就代表内容状态正常。

要是整个账号都被限流，原因通常就两个：硬广发得太猛，或者账号权重还没养起来。这个阶段别硬推，先发有价值的干货、讨论帖，把互动带起来，再慢慢恢复账号权重和流量表现。

# 6.2 销转话术学习

# 6.2.1 万能通用话术逻辑

① 好感建立 — 破冰

加到客户先破冰，不要上来报价。初次见面先简单了解。

参考话术：

“你好，我是米杰老师，平时喜欢资料收集整理，很高兴认识你，请问你需要哪个？”

② 放大需求 — 诊断

了解基础信息后，挖掘并放大客户需求，促进成交！

参考话术：

“之前在网上找过，但资料不知道全不全，不敢买对吗？”

“你之前也在其他人那里买过，但资料参差不齐对么？只是浪费了时间。”

③ 成交铺垫 — 方案

了解需求后提供解决方案，让客户明白能帮他解决什么具体问题。

参考话术：

“其实拼多多也有盗版资源，但需要花很长时间找，而且很贵，您说是不是？”

“谢谢你跟我聊那么多。如果不帮到你都觉得对不起你，必须让你拿到结果（造梦）”

“大家时间都很宝贵，你肯定也想找齐全且收费合理的课件，是吧？”

④ 突破抗拒 — 信任

这里不能掉以轻心，不然辛苦获取的客户容易跑单。

听完方案后，怎么突破抗拒、解除防御心理？

最好的方法就是晒客户付款截图以及对方反馈和感谢。（朋友圈部署十分关键）

⑤ 引导下单 — 成交

客户问题都解决了，如果还不付款，可用3个方法：

1. 送限时赠品/限时低价

2. 零风险承诺

3. 明确的下单指令

参考话术

方法一：利用限时赠品/限时低价

1. “对啦，我们买课件正好有活动，可赠送**资料一份，只有5份，下单后我发给您。”（限时赠品）

2. “对啦，这两天刚好在搞活动，限时xxx元，过两天涨价，错过了就得拍大腿啦。”（限时低价）

方法二：零风险承诺

“您放心下单，资料如果不是您需要的，两天内都可以找我退款，不辜负您的信任～”

方法三：明确的下单指令

“您可以通过链接下单，下单成功后把支付截图发给我哦，我来邀请您进群。”

# 7.1 资料库搭建方式怎么选？

给你三条路子。

# 7.1.1 第一种：自建课程或训练营

倘若你手上已有课程或训练营，攒下了不错的 IP 内容，完全能从现成资料里抽取出最有吸引力的核心部分，放到小红书笔记中充当引流品。若暂时没有自己的课程，星球上有不少讲“如何搭建课程”的精华帖可供参考。

# 7.1.2 第二种：借助合作伙伴的内容

若你有可信赖的合作方，对方手握课程内容，你也可以充当带货角色，带的货便是他们的服务、课程或训练营。谈成合作后，拿他们的部分资料做你的引流品，把引来的客户交给对方完成后续成交，你从中抽取佣金。

# 7.1.3 第三种：汇总公域里无版权的内容

若前两条都不适合你的现状，而你又想先把小红书资料引流这条路走通，那就走第三条：从公域里那些不涉及版权的内容入手，收集汇总，做成引流资料库。需要提醒的是，这条路不宜久用，且只能收市面上无版权、可免费流通的东西，如此才合规、不惹版权麻烦。长远看，还是前两种更稳妥，第三种只是过渡。考虑到多数人手里确实没有资料，下文会把这套方法的完整流程讲透，帮你先跑起来、拿到正向反馈。

# 10.2 如何排查与跳开版权坑

1. 版权排查

方法之一是组建兼职团队，让成员对资料分门别类、逐个核验版权状态，并填入预设的分类框架中。想省下这笔人工成本，就得亲自上阵：一边源头收集时就绷紧版权这根弦，一边收完后做一次总复查。

2. 版权处置

遇到强版权内容，如机构课程、带明确版权声明的大站材料，一律剔除；遇到弱版权内容，如页眉页脚留下联系方式的文档、带水印的PDF，则先归类再用软件批量处理。弱版权内容细分下来：

- 联系方式藏在页眉页脚的Word文档：归好类后批量处理；
- 联系方式藏在页眉页脚的PDF：不纳入选用，因为PDF无法批量改写页眉页脚，转成Word又容易乱码；
- 带水印的PDF：单独抽出来做去印处理。

至于无版权内容，直接收入资料库对应类目；所有文件收拾利索后，再统一盖上自己的水印。

批量处理软件：

Word页眉页脚 → BatchDoc文档处理；
批量加前后缀命名 → Bulk Rename Utility 3.4.3cn（批量命名）；
PDF水印修改 → pdf do。

# 8.1.1 小红书店铺（自动发货）

是什么：

怎么做：

2. 从准备卖的素材中选出主打品，做好主图与详情页，按流程上架；

- 只能靠薄利多销走低客单，想提客单还得把人引到私域；
- 一张身份证只能对应一家店，除非用营业执照开企业店并绑定多个账号；
- 虽然可以复制矩阵来做规模，但后面提价、收徒弟、搭商业模式都容易碰顶。

# 8.1.3 付费打卡社群

打卡社群是什么？

这种社群靠设定打卡任务来吸引用户付费进入。本质是把“付费门槛”和“打卡制度”结合起来，让用户参与得更勤、离场更难。用在学习场景里，通常搭配高质量的备考资料、导师辅导、学习监督等福利。

打卡社群怎么做？

核心条件很简单：有粉丝，且能把粉丝精准导入微信，就具备了做社群的基础。

如何创建付费打卡社群：

- 先把社群定位和对象人群定好，明确是健身、读书还是学新技能；
- 再定入群门槛和收费方案，筛选掉不匹配的人，同时保护付费意愿；
- 然后挑一款趁手的社群工具，比如知识星球，用它来搭建付费圈子，完成内容发布、成员维护、活动策划；
- 最后设计打卡任务和激励机制，比如“每天读书30分钟”“每周健身3次”，完成就给奖励，刺激大家坚持。

如何运营一个付费打卡社群：

- 价值不能断供，内容要够硬、互动要够多，才能让成员愿意留下；
- 常抛互动话题、安排答疑环节，引导大家开口说话、晒成果；
- 线上定期办分享会、讲座、研讨会，线下组织聚会、工作坊，仪式感和归属感就来了。

如何吸引成员加入付费打卡社群：

- 先展示你能给什么，专业知识、技能方法还是价值观输出，让用户觉得“值”；
- 再制造成员之间的连接点，互帮互助、资源互换，关系越铁，社群越值钱；
- 最后设计分销返佣，老成员拉新人进来就给奖励，让口碑自己裂变。

如何管理付费打卡社群：

- 群规要立起来，违规就按规矩办，不容含糊；
- 对成员贴上标签，按兴趣和活跃度做分组，推送内容时精准到人；
- 报名、抽奖、打卡等环节尽量交给专业工具去跑，省下人工管理的时间。

优点：

付费意味着筛选，能过滤掉大量闲杂人等，让留在群里的人更精准；同时资金有了着落，可以雇专人打磨内容质量，服务水准自然提升。学员因为花了钱，参与意愿和重视程度也会比免费群高出一截。

缺点：

愿意掏钱的人终究是少数，拉新不容易；况且网上免费资源一大把，学员付费后期待会被抬得很高，内容设计和运营节奏都得有真功夫，否则很容易被骂。

# 8.1.4 督学

督学是什么？

小红书里有一类学习博主，自己雅思考了个漂亮分数，但做不到录一套完整课程去教人。即便这样，依然有大把人私信问雅思备考方法，于是“雅思督学”这种变现模式就冒了出来。

督学怎么做？

打法与打卡群类似，区别在于是一对一服务。

1. 先在小红书亮出考试成绩和备考经验，把粉丝圈过来；
2. 再发一条“可接督学”的引流笔记；
3. 引导学生加微信，在私域里完成付费转化；
4. 准备一张信息采集表发给学生，涵盖学科基础、期望分数、每日可支配时间等；
5. 按对方情况排学习计划，但注意别一次全给，先发一半，学生付钱后再补另一半；
6. 每天照计划催进度、发资料，及时答疑，并盯着报名等关键时间节点做提醒；
7. 服务期间鼓励学生在朋友圈或公域平台帮自己背书，带来转介绍。

收费上通常按备考周期分层定价，市面价大约每月299元，买多几个月可以打包优惠。这类模式适合客单高的群体，比如冲雅思托福的学员、读MBA的上班族。

优点：

客户素质整体高于社群打卡成员，目标明确、需求迫切，转化起来更省劲，客单也能定得更高。

缺点：

对个人专业能力有硬性要求，零基础的新手很难上手。

# 8.1.5 资料代理（收徒）

资料代理（收徒）是什么？

这是一种“卖货+教学”的混合玩法。上家（师父）不光卖学习资料，还手把手教下家（徒弟）怎么在线上把这些资料卖出去，最终织成一张销售网。说白了就是：你自己卖资料已验证可行，现在教别人复制这套打法，赚培训费（知识付费）。

资料代理（收徒）怎么做？

1. 备货：精选高质量的资料，电子版或纸质版均可，覆盖各考试和垂直领域；
2. 通路：靠小红书这类平台持续稳定地带来客户咨询；
3. 招人：用广告投放、人脉推荐等渠道招募徒弟，把销售技巧传出去；
4. 带教：建立培训体系，从锁定目标客户、网络推广到话术答疑，全套交底；
5. 更新：及时跟进资料版本，保证内容不过期、不跑偏，并定期补充新东西。

优点：

- 门槛不高：跟多数创业项目对比，卖资料+收徒的起步投入很轻；
- 利润可观：一边卖货一边带徒，收入来源双保险；
- 模式能裂变：徒弟越带越多，销售网络的覆盖面就滚得越大。

缺点：

- 交付很沉：知识付费领域鱼龙混杂，收了学费就得对每个徒弟负责到底；
- 流量靠命：能不能持续吸引并留住流量，直接决定项目生死；
- 选品费心：市面上资料水平层次不齐，把关不严容易砸口碑；
- 版权红线：资料来源要干净，售卖之前务必确认不侵犯别人的知识产权。

# 8.1.6 与教培机构联手分销产品

是什么：

就是与教培机构联手，帮他们分销课程或服务。通常挑有名师坐镇的课程团队，与对方市场部/商务部负责人敲定分销比例和佣金，拿到现成的推广素材后，在私域里吆喝并促成成交。也可以找当地有资源的培训机构合作。

怎么做：

对接渠道两条：

- 去生财的#资源对接板块发帖找合作方；
- 圈定心仪机构后，直接联系其市场部负责人谈商务。

具体步骤：

1. 甄别机构：看品牌信誉、课程质量与口碑，确认课程与你的目标用户对口；
2. 签署协议：把双方权责写清楚，比如佣金比例、结算方式、推广义务，同时约定合作周期和续签条件。

客单价：几百到上千元不等。

优势：

- 投入小、回报稳：与自研课程比，分销几乎不承担开发风险，收益上限却不低；
- 各干各的：你只负责搞流量，交付端交给机构，不用操心售后烂摊子。

隐患：

- 合作的信任成本不低，容易产生路径依赖，一旦对方不给力就被动；
- 流量沉淀在谁手里、利益怎么分，长期看容易起纠纷。

优点：

短板在于很吃选品眼光，后端必须有一条给力的供应链撑着。

答：价格战基本躲不掉。干电商，同一个平台内，你的定价总得比对手低一截。从零单起步，没有价格优势，第一批成交根本撬不动。

**问：同一个账号能同时做店铺和私域吗？**

店铺的定位更适合低客单走量，前期拿来赚点现金流做过渡；私域另开新号去做更稳妥。

# 9.4.2 流量入口怎么理解

# 📌

所谓入口，可以看作一个个细分赛道，就像商场有好几道门。

打个比方：你的店未必是整座商场里最大的，但位置刚好卡在某个门口，客流自然比别人多，对不对？

内容也是这个理：全平台比不过头部，那能不能在某个同城入口、某个话题下做到最好？靠这个拿曝光。

每一个关键词，其实都是一个入口。

比如你在“教育资源分享”这个大池子里排不上号，能不能收窄到“小学生课外读物怎么挑”这种细分场景，在更小的入口里抢到靠前的位置？

发现页：用户平时的浏览、搜索、关注会给账号打上标签，系统据此主动投喂内容。所以要持续发垂类内容，让系统认准你的目标人群，推得更准。

同城推荐：首页右侧，依据定位识别所在城市，再推同城内容。路径是右下角【我】→笔记【右上角三个点】→【编辑】，可手动添加任意同城地点。

关键词搜索：用户在首页敲关键词，结果页越靠前，被点的机会越大。

站外社交媒体：内容被转到微信、社群、微博等地方。

站外搜索引擎：有人在百度之类的引擎搜词，你的笔记也可能出现在结果里。像“考研攻略”，只要文案里带了这个词，就容易被平台用户刷到，浏览量跟着涨。

# 9.4.3 推荐分发机制

# 💡

小红书推荐机制解析

你把笔记发出去，过审后先躺进平台数据库。等用户打开或下拉刷新，系统会从库里捞出一大批候选内容，接着粗排、精排、重排几道算法筛一遍，最后只有一小撮能出现在用户眼前。

召回：系统从库里快速拎出一批用户可能爱看的内容。

粗排、精排：算法给每条内容打分，从中挑出得分靠前的那一小批。

重排：对高分内容抽样，再按规则打散顺序，最终呈现。

多数时候，粗排、精排、重排都属于算法内部的事，了解了也未必能动手干预。

真正跟运营挂钩的，是召回环节，也就是“推荐”。所以得弄清楚：系统凭什么判断某篇内容适合推给某个人？

1.1 笔记召回通道解析

用户一打开或刷新，系统会跑十几条通道，逐条判断内容该不该推。这里挑几条好懂、对实操有用的说说。

1.1.1 内容相似度召回

用户喜欢某篇内容，系统就找相似的其他内容推给他，哪怕他没看过。

举例：

我爱看《盗墓笔记》

《鬼吹灯》跟它同类型

《鬼吹灯》我没读过

系统于是把它塞给我

那系统怎么判定两篇相似？主要几种依据：

1. 读过《鬼吹灯》的那批人，也读过《盗墓笔记》

2. 给《鬼吹灯》点过赞的人，同样给《盗墓笔记》点过赞

3. 两边受众重叠越多，内容越接近

4. 共同标签越多（类目、品牌、关键词……），相似度越高

但有个坑：小圈子里几个人同时给两个作品点赞、互动，说明不了它们相似。所以把内容丢进群里求赞，不但未必加分，还可能把标签搞乱。

1.1.2 人群相似度召回

这是按兴趣把人归类。假设甲和乙口味高度重合，甲给某篇内容点了赞或转了发，乙还没看过，系统就会把它塞给乙。

举例：

甲和乙都爱盗墓题材

甲读过《鬼吹灯》，乙没读过

系统便把《鬼吹灯》推给乙

系统靠什么判断两人像？

1. 两人点过、赞过的内容大量重叠。比如都常点《盗墓笔记》或同类题材。

2. 两人关注的作者高度重叠。

# 📌

看懂“人群相似度召回”，就能反推打法：目标人群定下来以后，围绕他们做选题，或者把爆款换个切口重写，推荐量和互动量往往更可观。

1.1.3 作者维度召回

按作者推，主要有三种情形：

1. 用户关注了某位作者，他之后发的内容会优先送达。

2. 用户跟某篇内容有过互动，该作者的其他作品也会被推过来。

3. 甲作者与乙作者风格相近，用户跟甲互动过或关注了甲，乙的内容同样会进入推荐。

# 📌

内容配比：八成营销内容配两成干货。用意是让干货先把流量拉起来，因为刷过干货的人，之后大概率还会刷到你的营销内容。

1.2 新内容怎么被推

文案、图片、视频、地点、话题标签等，全都是推荐的判断依据。前面说的是老内容的路径，新内容刚发出来没数据、没互动，显然不能照搬。

针对新内容，平台有几种专门打法：

1. 按类目与关键词推

系统看你平时爱看什么类目、搜什么词，就按这个来匹配。

举例：

我常年刷职场内容，也常搜职场、面试相关词。新内容一发，系统识别出它属于这个类目、又命中我的关键词，推给我的概率就高。

2. 聚类召回

用户爱看某篇，多半也会爱看同类型内容，跟上面那条有点接近。

举例：

我给一篇“裸辞创业”的内容点了互动，平台就会继续喂我同类题材，我大概率还会点开。

3. 新内容保量扶持

新内容没数据，跟老内容挤同一条通道肯定吃亏，所以平台会给一段保底曝光。

也就是说，无论质量高低，先保证一定时间内的基础曝光。不同内容保量标准不同，质量好的给得更多。

举例：

假设目标是24小时内曝光1000次，结果12小时只跑了100次，那剩下12小时系统会加大推送力度。

反过来，目标同样是24小时1000次，前2小时就跑了500次，后面22小时就会收着给。有些内容刚发时小眼睛猛涨、后来突然停住，原因就在这。

此外还有几项差异化扶持：

1. 优质作者能拿到额外曝光。

2. 作者过往内容质量高，会获得追加保量，但有天花板。

保量是额外叠加的，正常召回照跑。

一旦完成保量目标，扶持就撤了，之后靠自然曝光，跟老内容同场竞争。

# 📌

划重点：保量保的是曝光。点不点、点多少，仍然看内容本身——内容为王。

1.3 流量池分层

内容得分越高，就被推到越大的池子里，一层一层往上走。

每一层曝光给完，系统会看阅读、互动等综合表现，再决定要不要往下一层送。

最终，赞藏评合计破1000算小爆，破10000算大爆，不同类目门槛有差异。

每条内容会获得200至500次曝光，但曝光不等于阅读。

曝光数据只有企业号能看，阅读量就是小眼睛。

曝光与实际阅读的比值超过10%，基本可归为优质内容。

特别提醒：

内容分数持续走高，就会被逐层送进更大的池子，成为爆文，而爆文还会顺手把其他内容的数据带起来。当然，前提得满足：

①内容过了系统审核，不违规，没被平台删，也没被你自己删掉或隐藏。

②内容带了关键词（学习、家具之类），对应垂直标签，且被系统收录，能送到喜欢这类标签的人面前。

③内容本身够硬，能换来赞藏评等互动。零基础新手第一条就爆，概率很低；运营头一个月，小眼睛停在100至200也正常，底子好的见效快一点。

八成新手要到第二、第三个月才起量，中间有段酝酿期，不必焦虑，把内容磨好就行。

搜索流量：

用户除了刷主页，也会主动搜自己想要的东西。想考研就搜攻略，想留学就搜留学生经验。

排在搜索前排的内容，曝光和关注都会更多。这块流量几乎占了总量的一半以上，不能放过。想吃到搜索流量，前提是内容里有关键词且被系统收录；想排名靠前，账号和内容的权重都得稳步往上抬。

# 9.4.4 检测机制

平台会检查这些地方：

账号资料：昵称、头像、简介等，看有没有微信号、其他平台二维码、外站水印，有没有诱导关注、领奖、点赞之类的动作。

私信：是否往站外导流。

评论：是否诱导用户私信。

设备：尽量做到一机一卡一号一IP。

# 9.4.5 审核机制

# 📌

平台的审核跟多数平台相似，分机器与人工两道。

1. 机器审核

内容写完上传，先过机器。系统按规则扫敏感词、违规词、非原创图片等，查出问题就直接毙掉，不给曝光。机器拿不准的，标为疑似，转人工。

2. 去重检测

机器这一关过了，进入去重环节。系统拿你的内容跟库里已有的做比对，重复度超过阈值就过不了。若只是疑似搬运、尚未坐实，通常先限流，再转人工复核。

3. 人工审核

前面提到的疑似违规、机器判断不了的内容，会走人工二次审核。人工成本高，所以真正走到这一步的比例不大。但平台重点盯的领域会特殊对待，比如电子烟属于全面封杀，相关内容的审核只会更严。

4. 特征匹配

两道审核过后，内容进入系统内部的特性比对。层层筛下来通过的内容，才会进入推荐环节。

系统会做一系列分析：词义拆解、关键词抽取、关键词出现频次等，把整篇内容的特征摸一遍。

# 9.4.6 权重机制

# 📌

很多人纳闷：同一篇内容，换个号发，阅读和互动怎么差出好几倍？

这背后是平台对账号和内容的“权重”打分。影响权重的因素有哪些？

1. 资料完整度

不只是昵称、头像、背景图，还包括关注后的自动回复设置等。它在权重里占比很小，但缺了也不行。

提示：经过官方认证的账号，权威性可能更强。

2. 原创度

看整个账号发的东西是不是以原创为主、原创占多大比重。原创越多，内容越鲜活，权重也跟着往上。

3. 垂直度

指是否死磕一个领域。系统会按你日常发的内容打标签，越聚焦，标签越清晰，推给的人群也越对味。

要是今天发变装、明天晒宠物、后天记流水账，系统根本定不了位，综合推送时流量自然打骨折。

4. 内容品质

品质不等于原创，还得看内容本身行不行。好不好，用数据说话。

转发、评论、收藏、点赞这些指标都漂亮，账号整体权重会被拉高。

5. 账号等级

等级用各种“薯”来命名，最高一档是金冠薯。等级越高，权重越高。但要留意，删帖或发违规内容会拖累等级，严重时被降级，降级就等于权重下掉。

下面这张表是平台的成长等级，按任务升级，权重也会跟着涨：

1. 尿布薯

发1篇有效笔记，且这篇被点赞、收藏、评论各1次，就能拿到第一个小红薯形象。

2. 奶瓶薯

发1篇笔记拿到5个收藏或10个点赞，或者发一篇话题笔记，即可升到奶瓶薯。

话题笔记：发布时带上“#”，选官方话题创建。新手可以多试，对权重有帮助。

3. 困困薯

# 小红书账号升级、收录机制与规避新规全攻略

运营小红书，别只顾着追爆款。账号从新手到高阶，其实藏着一套成长体系；笔记能否被搜索到，取决于是否被收录；平台的各项新规，又直接决定流量走向。接下来就一次性讲透成长等级、活跃度、收录、避坑、新规应对和常规功能操作。

先聊成长等级。发布3篇内容，每篇均能收获至少5次收藏或10个赞，或者累计发布3篇话题笔记，就能解锁小枕头图标，晋级为困困薯。这一级同时看重笔记数量与互动表现，也引入了话题笔记的计数，可以看出平台正引导博主多产出内容，并且更偏好话题型笔记。

去到泡泡薯这一级，条件是：累计5篇笔记，每篇都有至少10次收藏或50个赞，而且当中要有1篇是参与话题活动的视频笔记，小红薯就能学会吹泡泡，变身泡泡薯。显然，到了这个阶段，升级难度开始加大，视频笔记和话题活动的参与成了硬性要求。

甜筒薯则要求累计12篇笔记，每篇都拿到10次收藏或50个赞，并且其中3篇须为参加话题活动的视频笔记，达标后就能吃到甜筒、晋升甜筒薯。对比上一级，笔记总量和视频笔记数量都往上提了。

小马薯的门槛变为累计50篇笔记，每篇均有10次收藏或50个赞，同时要有5篇话题活动的视频笔记，达成后即可获得玩具小马，进阶小马薯。

文化薯提供两条晋级路径：其一是累计9篇参加话题活动的视频笔记，每篇均达10次收藏或50个赞；其二是累计100篇笔记，每篇同样要达标。两条路完成其一，小红薯就能点亮读书技能，成为文化薯。相比上一级，普通笔记的累计量从50篇翻倍到了100篇。

铜冠薯的规则是：累计12篇带话题活动的视频笔记，每篇达到10次收藏或50个赞；或者累计300篇笔记，每篇都达标。达到要求后，薯队长会为小红薯颁发铜冠。虽然总笔记数从100篇增至300篇，但带话题的视频笔记只需比上一级多3篇达标即可，反而更容易冲刺。

银冠薯的要求为：累计15篇参加话题活动的视频笔记达到10次收藏或50个赞，或者累计500篇笔记每篇达标，即可获得银冠。

金冠薯作为最高等级，需要累计18篇参加话题活动的视频笔记均达到10次收藏或50个赞，或累计800篇笔记均达标。相对轻松的路径，依然是不断累积带话题的视频笔记数量。

# 6. 账号活跃度很关键
活跃度对账号权重影响很大。保持日常登录和操作，比如发笔记、刷别人的内容、点赞、写评论，系统才会认定这是活跃的正常账号；否则极容易被归为僵尸号。

# 7. 签约MCN或品牌合作人
若能签约MCN官方机构，或拿下品牌合作资格，账号往往会被视为优质账号群体中的一员，对提升权重有正面作用。

# 9.4.7 想被搜到？先搞懂收录机制
笔记发出去之后，只有被系统收录，别人才搜得到；没被收录，基本等于白发。

# 一、影响收录的因素
标题、正文关键词直接影响收录；标签要足够精准，且不宜频繁更换，最好固定几个与账号和笔记定位高度相关的标签，这样系统也更方便识别账号领域。另外，图片和文案不能含有违规信息或广告推销痕迹；账号本身更不能有违规记录。

# 二、判断笔记是否被收录的三种方式
方式一：直接搜自己。在小红书主页搜索框输入你的用户名，若笔记已被收录，搜索结果里自然会现身。或者搜索笔记标题、关键词，在发现页切换到“最新”，往下翻找，找到自己的内容就说明收录成功。
方式二：看互动数据。已收录笔记的阅读量、点赞数通常会优于未收录的笔记。
方式三：核查笔记URL。每篇笔记都有专属链接，如果URL里有小红书域名，就代表已被收录。

# 三、哪些原因会导致掉收录
推广违规要当心：除了品牌号、品牌合作号，其他号都不能直接做硬广。账号或过往笔记如有违规，收录概率会明显下降。内容本身出问题也很致命，图片和文字都算：可能因为违规直接不被收录，也可能先被收录、再因举报被限流。图片上别出现别家平台水印、二维码等元素，文字里不要带敏感词、违禁词、不文明用语以及诱导性内容。发文节奏太猛也不行，一天最好别超过5篇，不然容易被当作营销号。手机设备被平台拉黑同样会受影响。此外，内容质量太差，或平台认为不适合展示的笔记，比如大面积推广、炫富、非原创、抄袭、搬运等，也难逃限流。
想让笔记更快更全地进入收录池，最有效的方法还是多逛小红书，关注优质创作者和高质量内容，并保持良性互动。

# 9.4.8 这些红线千万别碰
硬广必须杜绝。所有推广性质的笔记，都要走软文思路，站在用户视角去写，转化效果才会更好。
平台规则不要挑战。一碰就可能被限流，严重的话直接封号。
内容尽量原创，别跟别人的笔记高度雷同。多人反复使用的模板化图片要少用；复制来的段落最好重写；视频情节过于相似的也要避免。
假数据别碰。花钱买点赞、评论等互动，平台是能识别的，千万不要尝试。想互动可以用小号在评论区带节奏，引导用户关注或私信。

# 9.5.1 新规之下的实操策略
1. 严禁用软件批量生成笔记。这类内容最大特点就是重复度极高，等同于搬运，正是平台重点打击的对象。
2. 爆款模板可以学，但不能照搬。原创和“爆款复刻”并不冲突——平台封的是1:1搬运，不是封爆款逻辑。
3. 新规反而给人机会。不去做搬运、简易二创这类低质工业化内容，平台把低质玩家筛掉后，认真做内容的人自然能接到更多流量。
4. 把自己当真实用户。算法会看你每天在小红书停留的时长，和发笔记的数量是否匹配。比如一天发两三篇，却只刷10分钟，系统很容易把你定义为营销号。

# 10.1 怎样选出优质赛道
如果你找赛道不费劲，通常具备三种能力：一是在教育行业扎根多年，积累足够，清楚客户群体和痛点，能快速匹配产品；二是会看行业数据，判断哪些方向正处于上升期；三是网感敏锐，比如之前“高考志愿填报”相关的产品和服务，就属于典型的风口。
如果你还在迷茫，也正常。可能你过去没接触过教育行业、不太会看数据报告、网感也一般。但没人生来就是高手，好在身在生财有术，能接触到第一手的互联网信息源，已经领先九成普通玩家了。

找赛道之前，先明确什么才算优质赛道：
第一，市场盘子要够大。比如闲鱼项目，若定位为“闲鱼数码”，只能吸收对数码产品感兴趣的学员；若是“闲鱼高客单价”，几乎所有想做高客单价变现的人都可以收。鱼多的地方，才钓得上更多鱼。
第二，消费频次要高，也就是复购率强。像K12教育，每个新学期都有新内容，天然能带动补习机构持续增长。
第三，可持续性要够硬。有些项目昙花一现，蹭完一波热度就无声无息；而有些赛道，流量常年稳定。

# 方法三：换个需求切口，避开红海

怎样借差异化找到竞争没那么挤的空白？先把教育拆成“教”与“育”：前者围绕授课者运转，后者围绕学习者运转。

若 K12 学生端已经卷成红海，能否把服务对象换成教师？为老师提供备课资源、课堂工具或教研培训，也许就是另一条路。再用一张对照表，把人群、痛点、供给与竞争强度并排摆开，定位会清晰很多，后面的执行也就有章可循。类似思路还能迁移：都在盯着孩子，能否改为帮助家长掌握教育方法？愿你也能用这个角度找到自己的空白地带。

# 方法四：从自己身上找赛道

常言道，热爱能让人走得更远。不过，只有热爱还不够，真正可行的是在“自己愿意长期投入”与“市场愿意为之买单”之间找到交集。

1）回看高光时刻，提炼长处

拿朋友 L 来说。她从事二级市场交易，数字感知力强，小时候数学就突出；大学时父亲把四年学费一次给足，她拿去做投资，手头宽裕得像在玩数字游戏；工作后专注股票，常能从盘面里看出进出场位置，账户表现长期不差；聊天时，她扫几眼就能讲清数字背后的逻辑，并推出合适的交易时机，也不怕别人质疑，反而享受用逻辑验证判断，靠专业积累了一批委托客户。从小到大，她一直凭对数据、逻辑、原理的敏锐度拿到结果。放在盖洛普语境里，这就是“分析”才干：数字敏感，爱追根究底，没有证据支撑的结论不会接受，更信数据和验证，不靠拍脑袋，往往能直抵问题内核。

不妨回忆三到五件让你有成就感的事，把其中的共性圈出来。那些一次次帮你拿到结果的惯用打法，很可能就是你的长板。

2）观察你反复做的事，那里藏着动力

一个人肯反复花时间做同一类事，多半是因为其中有吸引力，而吸引力背后常常连着优势。

朋友 A 喜欢出门、参加活动、结识他人。夜里十一点她也照常赴约；长时间独处会发闷；碰上棘手事，她先想到的是出门见人，收集他人经验与建议。A 的取悦、行动、积极这三项才干很突出：认识陌生人、尝试新体验，对她是回血方式；有她在的场子不会僵，大家也玩得开；听到好建议她会立刻动手，拿到回应后继续调整。

当然，反复做的事未必都带来好结果。比如我，看到资讯就手痒，刷行业动态、在社交平台更新，也常因此分心；另一个熟人沉迷买课、囤小物件，被家人嘀咕不干正事；还有位朋友平时话少，一张嘴就点问题、递方案，常被误解成爱找茬。我们都有过怀疑自己走偏的时刻，却没发现这些按不住的动作背后，对应的是思维、理念、搜集、学习、取悦等才干。我的社交平台素材几乎不断：搜集才干负责囤料，理念才干冒点子，思维才干把内容加工出来，靠长期更新做到百万级营收，而我并没有受过科班写作训练。

因此，若某件事总让你心痒、旁人的赞成或反对都拦不住，它背后多半连着你的核心才干。重点不是压抑它，而是替它找到能发挥的场合，把长板继续拉长。

不过，选方向时，首要原则仍是先看市场是否买单；否则容易变成自我感动，最后只能靠热爱硬撑。

# 三个别踩的坑

1. 定位别飘。比如人设是考研辅导，正常该卖考研资料，却转去卖小学生写作包，粉丝会一头雾水，认不出你的身份。
2. 赛道别杂。别把账号做成什么都塞的杂货铺，要有清晰的垂直标签，像专营店一样聚焦。今天做小学、明天转初中、后天又碰考研、再过几天教资，用户一眼就会觉得不够专、也不够稳。尤其教育领域，专业度直接等于信任度。
3. 别做到半途就撤。别只有三天热情：今天做中小学，明天转考研，后天又冲法考。短期看不到结果，说明方法或方向里有毛病；不修正就换，老毛病大概率会再次出现。认准一条路后，尽量把链路跑通；除非做到一半发现市场容量或上限确实不够，再换也不迟。放到整个大教育盘子看，卖资料只是其中一小块，不必太早发愁。

# 12.4 场地管理策略
1. 创业初期，非必要不租办公室
不少热血青年，拿着东拼西凑的几十万资金，事情还没做成，钱先亏完了——很大一部分就花在办公室上。
办公室再好看也不属于自己，而且好看和业绩没有半点关系。
创业初期省钱才是关键，别为了面子硬撑。
把钱花在搞流量上，才是正事！
建议：自家改造、居民楼、商业公寓……最低成本先跑起来，只要一条网线，就能开工！
2. 业务起来后，需要写字楼
找写字楼如何避坑？
1. 办公楼租赁虽按月计费，但一般至少签1年，也不宜超过3年——业主通常不会同意，或会要求一定幅度的递增。租赁价格常分“包票”和“净到手”，“包票”指租金已含租赁税发票，“净到手”则不含。（ps：1.起租期多长？2.租金含税吗？3.增长幅度多少？）
2. 办公楼还有管理费（物业费，按每平方米每月计算），这个要主动问。行业惯例：20元以下的多无中央空调，或中央空调费另计；20元以上的多为中央空调。管理费通常包含公共区域水电维修保养、清洁卫生等。（ps：1.物业费多少？是否含空调费？2.电费单价？3.网络费一个月或一年多少？联合办公一般租金已包含物业费、水电费等全部费用。4.各写字楼中央空调开放时间不同，很多有时间与月份限制。极少24小时供应，多数只供应上班时间（多为8:30-18:30），加班需另付加班空调费。也有少部分可自行安装独立空调，需要加班或不想用中央空调的，可询问能否安装独立空调。（ps：1.空调供应时长？2.能否自行调控？3.能否安装独立空调？）
3. 互联网公司常通宵工作，但写字楼内不能住宿（商务公寓除外），更不能明火做饭，微波炉可用。也有复式写字楼可居住或商住，这些要主动询问（ps：能否住人？）
4. 停车场收费也要问清楚。老板和员工一般办月卡，主要了解月卡多少钱。承租面积大的客户，可争取1-2个免费停车位（个人业主除外）。（ps：①停车费一个月或一年多少？②按年有无优惠？③临停一小时多少？④日封顶多少？）
5. 毛坯办公楼租赁，记得向业主要免租期，1～3个月不等，具体看面积和装修需要的时间，可以商议。即便是带装修的，也有1周左右免租期——搬办公室需要时间，修修补补总要留空。（ps：免租期多长？）
6. 租赁期递增：租期超过一年的，一般从第二或第三年开始月租金递增5%-8%，个别大厦连管理费也一起涨。（ps：租金涨幅多少？）
7. 合同签订：以上事项谈妥后，预约时间签合同。要弄清是跟业主签，还是跟二房东公司签。一般来说大业主和二房东都好沟通，很多事可以找他们帮忙。（ps：你们是大业主、二房东还是小业主？）
8. 办公楼租赁还有定金环节。很多情况无法直接签合同，下定金是最好的折中办法。定金支付后，若业主反悔，需双倍返还。
看楼前，把这些问题过一遍：
1. 租期多长？
2. 租金含税吗？
3. 每年涨幅多少？
4. 物业费多少？
5. 含空调费用吗？
6. 电费一度多少钱？
7. 网络费一个月或一年多少钱？
8. 空调供应多长时间？
9. 能自行调控吗？
10. 能装独立空调吗？
11. 能住人吗？

# 13.1.2 提示词模板

#Role:
你是一名资深小红书内容专家，擅长对对标作品的正文进行洗稿。
##Background:
我在运营小红书账号，现在需要对一段正文内容进行洗稿。
##Goals:
1. 按照我教你的洗稿方法论进行改写。
##Definitions:
- 洗稿方法论：
1. 精简句子：
删去不必要的词，压缩句子结构，让表达更直接清晰。
例：原句“我们公司专注于提供高品质的产品和服务，以满足客户的需求。”→“我们专注高品质产品与服务，满足客户需求。”
2. 同义词替换：
用近义词替换关键词，在保留原意的同时让内容看起来不同。
例：原句“这款产品具有非常好的性能表现。”→“这款产品性能出色。”
3. 增加形象感官描述：
加入具体的形象或感官描写，让内容更生动。
例：原句“这个地方很美。”→“这个地方如诗如画，风景宜人。”
4. 改变句型结构：
调整句子结构或语序，意思不变但表达焕然一新。
例：原句“他的观点是，市场需求将会继续增长。”→“他认为市场需求将持续增长。”
5. 用更有感染力的词汇：
选择更生动、更有表现力的说法。
例：原句“我们的服务让客户满意。”→“我们的服务让客户心满意足。”
6. 细节添加或省略：
增加或减少信息量，根据目标受众调整内容的丰富度。
例：原句“吃早餐对健康有益。”→“均衡的早餐有助于开启新的一天，对长期健康很重要。”
7. 主动/被动互换：
换个语态，句子就焕然一新，核心信息不变。
例：原句“科学家发现了一种新的治疗方法。”→“一种新的治疗方法被科学家发现了。”
8. 结合个人观点或引权威观点：
加入个人感受或引用权威说法，让内容更有可信度和个性。
例：原句“这种设计非常现代。”→“在我看来，这个设计展现了现代审美的精髓。”
- 语气种类：
1. 真实分享：用第一人称讲亲身经历和感受，可信度高。
例：我试了这款新面膜，皮肤真的发光了，你们也试试！
2. 亲切友好：温暖、舒服的语气，让读者有被欢迎的感觉。
例：哈喽，今天分享一家我最近发现的宝藏咖啡馆，希望你们喜欢！
3. 专业权威：展现专业深度，给读者信心。
例：根据最新研究，我详细讲讲这个成分为什么是护肤品的灵魂，以及它如何起作用。
4. 口语化：接地气、像朋友闲聊。
例：你知道吗？我今天试了那个网红菜谱，结果差点把厨房炸了，哈哈！不过做饭就这样，一半探险一半乐趣，下次挑战点“安全”的，谁来帮我收拾残局？
- SEO关键词优化：
1. 关键词要自然分布在全文各位置，至少出现3次。
- 保留信息：
1. 文案中书名号《》内容和双引号“”里的内容要保留。
2. 保留人名、地名、数字、年份、政策等固有名词。
3. 保留英文缩写（有些是替代敏感词的）。
- 分隔符排版：
小段之间空一行，加一个英文句号“.”作为分隔，最后一段不用加。
##Constrains:
1. 不要编造事实，保留原文意思。
2. 要做SEO关键词优化，具体方法见##Definitions。
3. 数字要换成1⃣️2⃣️3⃣️等数字表情包。
4. 在原文基础上洗稿，不要加自己的开场白和结束语。
##Output format:
1. 以黑色代码块markdown格式输出。
##Workflows:
1. 引导用户输入需要洗稿的文案。
2. 询问用户想用哪种语气，同时列出语气种类并简单解释每种语气的意思。

3. 先向用户确认：这次要布局哪些 SEO 关键词？如果对方没有给，就不要擅自加关键词。
4. 然后严格按照前面 Constrains 和 Definitions 中讲到的技巧来洗稿，最终用黑色代码块 markdown 的形式输出。
注意：输出格式采用黑色代码块 markdown，文案中不要出现双星号。

角色：你是一位小红书内容老手，专门负责把对标笔记的小红书正文做二次创作。
背景：我正在运营小红书，现在需要把一段正文内容重新创作。
目标：按照下面这套二创方法完成洗稿。
定义：二创方法论一共包含六招。
第一招，同义词替换。把原句里的关键词或关键字换成同义词、近义词，意思不变，但看起来不一样。比如把“你希望的另一半是什么样”换成“你期待的另一半是什么模样”。
第二招，添加细节。根据目标受众补充更具体的信息，让内容更丰富。比如“规律作息很重要”，可以写成“规律作息、按时吃饭、少熬夜，这些习惯对健康真的很重要”。
第三招，改变句型结构。调整句子的结构或语序，意思不变。比如“她觉得这个方案挺有前景”，可以改成“这个方案在她看来，是很有前景的”。
第四招，反义表达。把话反过来讲，传达同样的信息。比如“这题对我来说很难”，可以写成“这题对我来说并不轻松”。
第五招，分句重组。长句拆短句，短句合并成长句。比如“天气不错，咱们去走走吧”，可以拆成“天气不错。咱们出去走走吧”。
第六招，语言风格转换。让表达更贴近目标受众的习惯。比如“这个方案可行性很高”，可以换成“这个方案挺靠谱的”。

约束：
1. 别照搬原文框架，而要用上述方法重新搭内容。
2. 原意不能丢，还要适当补细节，让信息更饱满。
3. 句序和结构可以灵活动，尽量降低和原文的相似度。
4. 同义、近义词多替换，原文用词尽量少重复。
5. 主动句可以转被动，长复合句可以拆成几个短句。
6. 遇到《》里的文字、例子中双引号包住的内容，原样保留；人名、地名、数字、年份、政策这类专有信息也不能改。

工作流程：
1. 先让用户把待改文案发过来。
2. 然后给出改好的版本。

注意事项：
1. 行文语气要贴着原文走。
2. 不要用晦涩难懂、复杂的词。
3. 说话口语化一点。
4. 没看到用户给的文案之前，不能动笔，更不能自行生成。

# 十四、小红书聚光投放玩法

# 💡
本章要点：聚光投放需要真金白银，所以这里不算必修。手上有预算、又做过账号的朋友可以试；已经能做出爆款笔记的伙伴也不妨一试。投聚光后能获得私信豁免权，私信可以无限发。

# 14.1 投放成本怎么算

投聚光之前，先把投入产出账算明白。想拿到私信豁免权，日消耗要在100元以上，而且要到投流第三天才会豁免，后续还得持续投放。也就是说，每天成本按100元来算。拿小学资料项目举例，临近期末时转化率在20%-30%，先按20%算，客单价假设49元。按每天引来15个人算，15×0.2×49=147元，这个数已经高过100元的投放成本。也就是说，日引流15人是保本线。要是日引流能到100人，套进去算：100×0.2×49−100=880元GMV。因此要不要投，关键看自己的内容制作能力和引流能力。

其中引流能力尤其关键。投放的好处是能直接接着发微信做承接；免费流量就没这么顺，中间会折损，微信和图片都可能被吞，100个人来问，最后能加到微信的也就20-30个（实测数据）。换成聚光私信通自动发微信后，100个人问，能过来80-100个（实测数据）。把账合起来看，还是拿小学资料举例，只要账号不封，免费流一天能来6个人以上，那开聚光大概率不亏，值得试。第一笔账必须会算，而且要用自己产品的客单价和转化率去套。

聚光还有一个作用是信息流投放，但这种玩法更适合高客单产品，获客成本一般几十块钱一个人。我们做小学教辅虚拟资料，主要要的是私信豁免权，信息流玩法不用关注太多。

# 14.3 投放门槛

想投聚光，账号得是蓝V。路径是先注册个体户营业执照，再交600元把蓝V开出来，之后才有投放资格。个人号目前走不了聚光。如果做小学教辅，还要办出版物经营许可证并认证图书号，这个证在淘宝办大约1800元。这笔成本自己盘一盘，手头有预算的可以试试。

# 14.4 私信通怎么开

对做引流的人来说，私信通最实用的地方是：用户点开你的私信窗口，系统会自动弹出一段预设文字，这段文字可以放你的微信号。比如设置成：“这里发不了电子版资料，加我微信：xxxx”。开通门槛是累计消耗满1000元，每周二系统会自动开通，这就是私信通。

# 14.5 矩阵号配合打法
