# 一份BP，先讲什么后讲什么

投资人坐下来，通常先想知道：赛道体量有多大、增速大致落在什么区间；竞争力量集中在哪些维度、我们准备怎么接招；收入从哪几条线来；过去三年投入与产出、利润走势如何；顺着这三年，后续增长怎么估；眼下估值多少、这一轮想拿多少、资金主要投向哪里；退出路径怎么安排；公司一路怎么走来、使命是什么、想搭怎样的服务模型、客户最终能得到什么。收尾时道一声感谢，并抛出合作邀请。

上面这些问题的排列顺序，其实就是BP内容设计时的骨架。

# 💡 基础版交付四步

1. 接任务：先问清用途、目标、可写范围和内容板块。
2. 找素材：公开渠道检索、向客户收集资料，必要时借力AI起草。
3. 做PPT：搭目录、找配图、做图标、排页面。
4. 交与讲：先顺整体思路试讲，再模拟演示，敏感数字先留白。

# 💡 高阶精细流程

1. 客户来咨询。
2. 了解并分析需求。
预付款。
3. 把需求分析结果、范围边界、PPT目录框架拿出来，与客户核对确认。
4. 说明服务流程、时间节点和里程碑，让客户确定模板文件及话术。
5. 制作PPT。
6. 完成九成时，约线上演示汇报，沟通内容并请客户补资料。
7. 全部完成后，模拟讲解，交付PPT及演讲流程概要话术Word文档。
结尾款。

# 3.9 淘宝新手村：一套能照着做的接单路线@海盐芝士

# 3.9.1 心态先摆正

1. 把自己当实习生，别先盯收入。  
淘宝像新手村：刚进新公司时，派单人还不了解你，你也没经验，所以前10到30单主要是练手。重点不是稿费，而是真接单、真踩坑。能有机会实操已经很好，有稿费更佳；踩坑没拿到钱也别纠结。实战经验最值钱，先练起来。

2. 稿费可能拿不到，原因要明白。  
平台和外部同行里，不少客服、客户没受过专业训练，收款条件没谈妥，客户赖账要求退款，客服直接退，写手就可能白干。知道这点，自己多留心。对方说法不对就主动沟通；他们不是权威，你该给建议就给。若客户认知不到位、坚持按他的来，就按确认需求写。写手职责是按客户确认的需求交付，发现不合理提醒即可，决定权在客户；提醒到位他不听，责任不在我们。真没拿到钱，别内耗，行业现状如此。第一目标仍是实习涨经验，有钱更好，价格低也无妨，经验归自己。

3. 把分母做大，提高应聘成功率。  
多投几十家，进至少10家店，接单群里单子就看得多。哪些单单价高？看到能看懂的需求，快速找对标，再套方法论，就能写，能力也涨。

4. 有经验再冲天猫。  
前10单别去天猫。等写过10到20个真实客单，有客户、客服沟通体感后，再投天猫，同时再扩几十家淘宝店。此时简历要包装：写清专业或学历背景，拿搜到的优质稿重写一遍当自己的真实作品去投，相当于拿好简历去新公司应聘。

5. 能力要露出来，等飞轮转起来。  
前两三周客服和你互相试探，单少正常。一旦有客服派单或你抢到单，让他们看到你靠谱、类型多、质量稳、速度快，一个客服会把你推给几个客服，高价单也会来。多数普通人还是要主动抢单接单，客服才看得见。底层逻辑：淘宝很缺靠谱且质量高的写手。最大的店3000写手里，能打中高端且靠谱的不到50个。所以前两三周，快的一周，有人面试后客服直接给高价单。看写作能力也看运气，像进公司遇好领导，所以分母要大。

6. 只做写手也能月入过万。  
朋友的妈妈被裁后做AI写作，高中学历、没突出能力、没系统学，自己闲着去淘宝接单，网上找素材资料，用AI写。第3个月赚3000+，之后月均3到5万，现在做了几个店，成了顶尖写手。

# 3.9.2.2 海王打法：把接单面铺大@海盐芝士

先说明海王打法是什么。PS：三观很正。

# 💡 海王打法永远有用
先做大基数，再筛选；反复练习，提高技能；做足数量，放大概率。数量就是质量，就是正义。买房起码先看一百套；健身起码先泡一百天；招人起码先面一百个；做自媒体起码先日更一百天。最基础的量都做不到，再好的方法也白搭。

在这个思路下，把基数放大，把能进的接单群都进一遍，才能放大概率、提高接单机会。

# Part 1：多平台撒网

以常见电商平台和内容平台为例，给一条执行路径。

# 💡 淘宝
平台优势：单量最大、需求最多；客单价相对稳定；支付相对规范；长期订单机会多。  
执行路径：搜“代写”“写作服务”“文案写作”等；建议先投60家店铺起步；重点关注评分高、成交量大的店。

# 💡 📕
平台优势：垂直领域需求强；私单机会多；单价普遍较高；属于潜力平台。  
执行路径：搜“代写”“找写手”、机构投放笔记等；关注写作话题；私信活跃博主，用跟应聘淘宝一样的话术；留意评论区合作机会。

此外，还可去Boss直聘等平台。

# 3.9.2.6 主动抢单，别怕

团队里很多小白，只要单子能看懂，套教程内容就能写，别怕。

注意：别接太定制化的内容，比如演讲稿、主持稿，这类需要大量结合客户信息和主持流程，素材多，很多客户说不明白，沟通成本太高。别接急单，时间紧客户容易不理智，写手临近交稿压力也大，两个心态不稳的人容易扯皮，对小白很不友好。小文章、文科类，能看懂或有把握、不麻烦的都可以接，就是练。

再强调一次，刷新手村的唯一目标是体验接单流程、拿实战经验。去淘宝投50家，从中接10个真实客单，练自己解决问题的能力。直接干，尽量不提问，自己解决。就算10单都没稿费也没关系，这个过程中的成长帮助很大。客服话术下一阶段才需要，当前只盯写作能力，一定聚焦单一目标。

# 3.9.2.7 用市场视角看单子

虽然以写手身份进新手村，但别用写手思维限制视野和格局。每个学员都可能独立操盘项目，或成长为超级写手。所以要从全局看品、看价、看量，多总结规律和市场现状，从中找机会、找高价、不断试错，甚至在淘宝店里沉淀出优质合作伙伴。

# 3.9.2.8 先守店铺规则

每个店都有自己的规则，在群公告里，或直接问联系人。先遵守对方规则，能写单、接触真实单，目的就达到了。前期别管价格是否合理、客户是否难缠、客服是否难缠。别和不理性的人较劲，别让这种人拉低你的格局。

# 3.9.2.9 服务态度要稳

全程用谦虚学习、做好服务的态度对待客户。以善意假设去想，以温柔态度去说。遇到不讲理的人，直接找海盐一起分析是哪一方的问题。只要不是我们的问题，这一单钱不要了，也无所谓。
