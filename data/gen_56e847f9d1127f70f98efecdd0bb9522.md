在古诗词工作流里，语音和字幕模块的搭建是让成品“有声有色”的关键一步。下面我们接着配置相关节点，从批量语音生成到BGM匹配，再到桌面端工具的对接，一步步完成。

3.17.1 节点能做什么？  
这个节点负责将传入的文本内容批量转化为适合播报的语音文件。

3.17.2 参数配置方法  
输入：直接引用“生成文案及标题”节点输出的 fengjing 字段。  
输出：暂时还不能定义，因为当前批处理体内部还没有添加任何节点，所以输出选项处于空白状态。

# 3.18 加入语音合成插件（speech_synthesis）  

先选中“批处理体”，让它变成蓝色高亮状态，然后点击“添加节点”→“插件”。在搜索框里输入“语音合成”，排名第一的就是“speech_synthesis”，点击添加。添加完成后，注意把插件的首尾圆点与批处理体对应位置连好线。

3.18.1 节点能做什么？  
根据传入的文本合成语音，支持调节语速和音色。

3.18.2 参数配置方法  
text（文本）：使用“生成语音”节点的 input 作为输入。  
speed_ratio（语速）：填 0.7。  
voice_id（音色）：这里选了“甜美悦悦”，你也可以点击下拉框查看所有可选音色，根据自己喜好更换。点击音色旁边的喇叭小图标，还能直接试听效果。

需要注意的是，这个语音合成插件偶尔也会运行失败，常见原因包括文本里含有违禁词，或者文本长度超出限制。不过在当前古诗词工作流中，基本不会碰到这些状况。至于要不要额外加一个重试机制，你可以参考之前生成图片和视频时用到的做法，自己动手尝试添加。

接下来，把“生成语音”节点的输出变量值设置为 link，同时把变量名改成 link_list。

# 3.19 添加大模型（拆分翻译字幕）  

继续添加一个“大模型”节点，将其重命名为“拆分翻译字幕”，并让它与“生成语音”节点完成连线。

3.19.1 节点能做什么？  
将诗词名称、朝代作者、每一句诗句分别拆分出来，同时为每一句诗句生成对应的拼音和中文解释。

3.19.2 参数配置方法  
模型：豆包·1.6·深度思考  
输入：“生成文案及标题”节点的 fengjing。  
系统提示词：  

```text
# 角色

你是一个专业的数据提取专家，专注于对古诗词相关文案进行精准拆分与处理。

## 技能

### 技能 1: 文案拆分

1. 当用户提供文案数组{{input}}时，将其拆分成三个数组。

2. 第一个数组为诗词名称，输出到mingcheng，输出格式严格按照：《诗词名称》。

3. 第二个数组为朝代作者，输出到zuozhe，输出格式严格按照：[唐]·李白。

4. 第三个数组为每句诗句，输出到shiju。

### 技能 2: 诗句翻译

1. 针对shiju数组中的每句诗句，分别生成拼音数组pinyin和中文解释数组jieshi。

2. 解释文本后面不要添加符号。

3. 只输出内容相关信息，不输出多余的解释、标识、符号。

## 限制:

- 只处理与古诗词文案拆分和诗句翻译相关的内容，拒绝回答无关话题。

- 所输出的内容必须按照给定的格式进行组织，不能偏离框架要求。  
```

用户提示词：`{{input}}`

输出：需要设置 mingcheng、zuozhe、shiju、pinyin、jieshi 这五个变量，均为 array 类型，定义时记得修改变量名。

# 3.22 下载并配置超级剪映小助手 PRO 桌面版  

下载地址：https://aigcview.cn/JianYingDraft

3.22.1 安装与配置步骤  
3.22.1.1 Windows 系统下的操作流程  

（1）根据自己的系统版本下载对应的压缩包，解压后运行“剪映小助手-智界”开始安装。  
（2）安装完成后，打开小助手软件。  
（3）第一次使用时，需要先设置草稿路径，注意这个路径必须和剪映的草稿位置一致。  
（4）打开剪映，点击右上角的“设置”，选择“全局设置”。  
（5）在全局设置中找到“草稿位置”一栏，点击右侧的文件夹图标。  
注意：草稿地址务必设置到除 C 盘以外的其他盘，否则草稿会导入失败。  
（6）点击地址栏，全选地址后按 Ctrl+C 复制。  
（7）回到剪映小助手，点击界面右上角的“设置”。  
（8）点击“浏览”。  
（9）在地址栏中粘贴刚复制的草稿路径，按 Ctrl+V 后回车，接着点击“选择文件夹”即可完成设置。

至此，桌面端准备完毕，可以继续后续的剪辑操作了。
