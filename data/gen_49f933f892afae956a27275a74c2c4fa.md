# 1. 本章概览：从 MVP 思路到环境准备

先看一个提问模板：我准备解决某类人群在某场景下遇到的某个问题，打算用 App 来落地，请帮我梳理这个产品的 MVP 应该包含哪些功能，并逐项列出来。

MVP 的反面案例：造车时，先交出一个轮子不算 MVP，因为轮子无法把用户从 A 点带到 B 点。正面案例：造车时先做滑板车，虽然结构简单，却已经能让人比步行更快地移动。

本章要完成的是 iOS 开发的硬件与软件准备：硬件推荐 Mac mini M4（性价比高，3499 元）或 M 系列 MacBook，并配 iPhone 真机调试（iOS 16+）；租机可行但性价比一般。开发者账号方面，Apple ID 免费就能开发，99 美元/年的会员用于上架和长期测试，首次实名申请有哪些常见坑也会讲。开发工具要装 Claude Code / Augment / Cursor 作为 AI 编程助手，安装 Xcode 创建项目，并掌握项目结构、真机编译和图标设置。关键技巧是设对项目根目录，让 AI 工具和 Xcode 联动，并配置开发者账号完成真机调试。学完本章，环境就搭好了，可以开始用 AI 辅助写第一个 App。

1. 域名、服务器和备案的基础知识

# 3.1 域名、备案、服务器：先判断要不要

1、要不要准备域名，取决于 App 类型：

需要域名的情形：App 要调用后端接口、加载网页内容或发起 API 请求，这时就得有一个公网可访问的地址，通常就是域名。

不需要域名的情形：App 是纯本地应用，数据、逻辑、资源都打包在 App 内，不访问互联网，那就不用域名。

2、域名是否要做 ICP 备案：

服务器在中国大陆（如阿里云、腾讯云的大陆机房）时，域名必须先完成 ICP 备案，否则无法解析到该服务器，访问会被拦截。

服务器在境外（如香港、新加坡、日本、美国）时，不需要备案，域名可直接使用。

注：ICP 备案大约要 2-3 周。不少人为了省时间，会先用香港或海外服务器上线，跑起来后再决定是否迁回大陆。缺点是大陆用户访问可能慢一些，部分网络环境下也不够稳定。

3、若服务器在大陆、业务又面向国内用户，域名必须先备案才能正常解析。没有备案，DNS 不会指向你的服务器，网站或接口等于打不开。而且备案不只影响“能不能访问”：很多支付、短信、第三方 API（🛰️、支付宝等）都要求提供备案号才给接入；部分广告投放和应用分发平台也会检查网站备案状态。

4、服务器在国外，能否面向大陆用户开展业务？大陆用户访问没有硬性禁止（除非内容违规被墙），但速度和稳定性可能掉链子，视频、实时交互类业务在高峰期或某些运营商网络下会明显卡顿。如果业务面向国内公众用户，用境外服务器实际是在规避备案，法律上不合规，被查到可能封域名、封应用。很多国内生态接入点（🛰️支付、支付宝、短信网关）会检查域名备案，没有备案就直接卡住。即使服务器在境外，也会在这些环节受阻。

# 3.3 备案避坑提醒

备案流程：阿里云 / 腾讯云均有备案入口（https://beian.aliyun.com/?spm=5176.100251.console-base_top-nav.dicp.48654f15gRzxw6），按网页提示提交资料即可，个人可以独立完成备案。

（1）个人备案时，网站类型和备注建议写“个人学习使用，用于建设个人网站，记录工作和生活”，不要涉及商业用途。

（2）个人备案后，如果域名被用于直观的商业用途，比如搭建无需登录就能看到完整内容的海外站点，后续可能被服务商强制注销备案。有这类用途，建议用个体 / 企业执照备案。

（3）备案建议在购买服务器的服务商处办理。域名备案需要备案号，购买服务器一般会送 2 个；如果没有，可在淘宝搜索“阿里云 icp 备”，价格 10 元左右，买一个填过去即可。

（4）提交备案后 24 小时内，注意接听服务商电话，会确认个人信息；有问题也会驳回并给出修改建议。

# 4.2 注册常见卡点

这是很普遍的问题，一定要注意！

1. 首次实名 Apple ID 时，不要在登录过超过 3 个以上 Apple ID 的设备上注册。如果用租机设备申请 Apple 开发者账号，不确定是否存在公共设备问题导致无法申请，这点要留意。

# 5.1 Xcode 与 AI 工具如何联动

第一步：点击 Create New Project 创建新项目，选择默认应用类型，输入项目名称（拼音或英文）。Organization Identifier 输入 com.xxxx.xxxx，这里的域名是反写的，com 后缀在前。比如项目名为“yuyin3”，注册的域名是 cuanxue.com，这里就填 com.cuanxue.yuyin3。后续创建新项目时填的域名，也是上架 App、创建 App ID 时要填的信息。

第二步：打开 AI 编程工具，打开项目根目录。yuyin3 的第一个文件夹是刚才在 Xcode 创建的项目，要打开的是 yuyin3 项目目录下 yuyin3 的子目录，这才是根目录。后面 Cursor 创建的所有代码文件都写在这个根目录下，打包编译时才有效。

# 5.2 Xcode 项目文件分别管什么

Xcode 创建项目后会生成目录列表，其中只有第一项是项目根目录。

1. Contentview 文件：项目主视图文件，可以理解为打开 App 的第一个页面。Xcode 创建项目后，这个文件会自动包含“hello word”文字。在 composer 模式下，首次生成代码时要 @ 引用 Contentview 文件。
2. yuyin3APP 文件：应用程序容器，打包编译到手机时安装的就是它，会包含项目所有资源。
3. Assets 文件：上传 App 图标、应用内图片，支持 PNG / JPG 格式，建议压缩后再上传。
4. yuyin3：应用程序权限配置文件。
5. Preview content > Preview Assets 文件：预览内容，打包上架时不会包含这里的图片，只在预览 / 测试时显示。
