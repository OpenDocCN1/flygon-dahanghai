直播想拿到自然流量，后台数据、场景和话术到底该怎么抓？

看直播间后台数据时，先盯内容力模块里的“直播有效进房率”。这个数值越高，说明有效曝光被用户点进来的比例越高，系统也更容易继续给直播间推流。

2、有效观看时长占比（30S/60S/180S）

这里看的是观众在直播间停留了多久、各时长段的用户占比。平台会把观看时长分成30秒以内、60秒、180秒等层级，再结合推流规则评估直播间的内容能力和直播能力，给出对应的权重定位。用户停留越久，有效观看占比越高，被推流的概率和规模就越大。

3、互动率、关注率

互动，指观众和主播通过问答、评论、送礼、连麦等方式产生交流；评论、点赞、转发、分享、礼物都算互动。关注率/转粉率则代表主播人气上升、粉丝增加；用户关注后能收到开播通知，也意味着更深的粘性。互动率和关注率越高，说明主播更受欢迎、内容更受欢迎、用户粘性更高，也更好转化成交。

4、礼物热度

视频号直播时，左上角显示场观，右上角显示“热度”数据。热度本身也是互动数据，能体现直播间当下的互动水平，而礼物数据在热度值中的权重占比较高。引导用户送粉丝灯牌、加入粉丝团，就是拉热度的典型动作。愿意加入粉丝团的成员基本是账号铁粉，可以长期维护转化、做裂变，并让他们分享到朋友圈、社群等渠道，帮直播间拉流。

# 5.1.1.2 成交权重：成交密度与点击成交率

成交密度，指单位时间内的成交单量。视频号公域推流机制看重“成交密度+互动密度”，二者能拉升自然流量推荐；其中成交密度权重又高于互动密度，所以做公域流量，关键是把成交密度做好。

[PRE1]

成交密度对自然推流的贡献非常明显。可以按在线人数的10%来估算成交单量：如果有100人在线，就争取成交10单。下单金额是1元还是100元都没关系，重点是争取5分钟成交一波，连续三波5分钟成交密度叠加，就有机会刺激平台推流。

商品点击成交率=成功下单量/商品链接点击人数。这个数值越高，说明商品越受欢迎，对推动平台曝光流量也很重要。可按不同产品属性定标准：福利品点击成交率达到70%以上，承接品达到40%以上，利润品达到20%以上，以此保证整体商品点击成交率在30%左右。数据不达标，就要优化主播话术、商品链接，以及选品、排品问题，后文会继续展开。

# 5.1.1.3 公私域联动（重点关注）：用私域撬动公域

视频号和抖音最大的区别之一，就是视频号能做私域，并且能用私域流量撬动公域流量；平台也会对“把私域流量拉到直播间”的行为，匹配一定的公域流量作为奖励。具体来说，每把一个私域用户通过私域拉到自己的视频号直播间，平台就会按一定额度把直播间推送给公域新用户，引导公域流量进入直播间。但如果只是无效拉人头，比如拉来的人不是直播间受众、进来不买东西、秒退直播间，撬动公域的效果就会很差；反过来，私域用户来到直播间后愿意停留、愿意互动、愿意下单，平台给到的公域流量“奖励”就会更多。

1、分享

视频号直播可以分享到朋友圈，也可以让用户把直播间分享到他们的朋友圈、群聊和好友。分享是互动动作中优先级很高的动作。每一次分享都可能带来更多流量：比如有人分享了你的直播间，他的朋友在朋友圈看到，就可能点进来看。分享者质量越高，带来的流量越大；物以类聚、人以群分，他是你的用户群体，他朋友圈里也有不少你的潜在用户。分享要全程主动要，也要想办法用策略去要，但要结合直播间找到自然的方法，千万不要生硬、尴尬、强硬、机械地要。直播间要互动的一个原则是：让用户做一点事情时，也要给ta一点什么，做等价交换。

2、预约

在视频号直播间，可以通过左下角弹预约，把直播预约推送给直播间用户，为下一次直播做预热。

# 5.1.1.4 不同阶段的考核维度

1、冷启动期：0-2000场观

这个阶段重人气数据，关键看曝光进入、停留。系统会重点关注直播间的“内容消费表现”，根据“曝光进入率”“直播间有效观看占比”找到对该内容有兴趣的用户，并在后续推荐中持续放大。如果这些指标表现较差，直播间可能无法持续拿到更多自然流量。内容力的相关数据，会在直播间数据大屏的内容力部分有所体现。

2、数据增长期：2000场观-10000场观

这个阶段重流量精准度，关键看商品点击率、支付转化率。账号核心考核“商品点击成交率”，也就是有多少用户点击查看了直播间商品、又有多少人点击后成功下单；这与下单金额无关，只与下单人数、下单单量有关。直播间用户开始从单纯看内容转向产生支付行为，平台也会开始给直播账号打上更精准的标签定位，从而推荐更精准的人群进入直播间。

3、成交转化期：10000场观以上

这个阶段重直播间利用率，关键看GMV、观转率、GPM千次观看成交金额。有了相对精准的人群后，平台考核会转向“流量利用率”：同样的流量，你能卖多少钱，同行能卖多少钱；谁给平台带来的利益高，平台就把更多流量交给谁，这就是平台的赛马机制。重点考核成交金额GMV、整体观看成交转化率，也就是平台给了这么多精准流量，你能卖出多少订单；以及GPM千次观看成交金额，也就是平台推荐一千个进入直播间，你卖出了多少钱。这些都是同行赛马的关键数据，做直播就是要在关键指标上压过同行，从而获得流量。

# 5.1.2 直播场景：看得见的都影响转化

俗话说，场景不会搞，直播做不好；场景搭得好，流量少不了。场景可以理解为用户能看到的一切画面，包括直播封面、直播画面、主播、产品包装等；任何能让用户看到的，都叫场景。外场景是直播封面+直播实时缩小画面，点进去就是直播实时画面。好看、吸引人、有差异化的直播场景，能提升曝光点击率、提高用户停留时长，也因此能拉动平台更多推流。

# 5.1.2.1 直播封面、画面：第一眼决定点不点

从直播广场还没点进直播间时，用户先看到静止的直播封面，再看到动态的直播实时画面。这时听不到主播说什么，只能看到文字信息和直播画面。封面是一张海报，要包含最重要的信息，简洁明了，让人一看就知道是做什么的，要把每一个展示位置都利用好。比如：“泰国原装进口乳胶枕——好睡到天亮”。直播广场上的动态场景，就是直播实时画面；画面会影响直播曝光进入率，画面有没有吸引力、愿不愿意让人点进来，非常重要。官方也明确指出“曝光进入率”很重要。直播画面里的标题，比如“好睡到天亮”“哪些人适合用乳胶枕”。

# 5.1.2.2 直播画面中的文案特点

要简洁、讲主题、说重点、一目了然、有吸引力。有吸引力的文案如“产品上贴1米福利”“老北京布鞋9.9”“奥特莱斯正品撤柜”；品牌宣传如“回力正品直播间”；痛点卖点如“三分钟出门素颜装”；信用背书如XX官方指定供应商、XX工艺大师等。

# 5.1.2.3 场景搭建依据：把产品放回使用现场

同一个产品，在不同场景里表达的信息不同，好的场景自己就能卖货。要给购买者一个想象画面，让他能想到自己得到这个产品之后会有什么改变。简单说，就是把产品放到用户真正使用它的场景中去，让用户感受到使用它时的状态，想象到会带来的效果。

产品视角：展示时以产品为主要视觉中心，例如手播卖西洋参，画面就对着产品，突出产品卖点、功能和细节。重点在于：不要只展示产品的精美包装或原始状态，而要着重展示产品在使用场景里的鲜活状态。卖生鲜水果，就直接把最新鲜、洗过的水果摆出来，展示里面的果肉；卖护肤品，就把瓶瓶罐罐从盒子里拿出来，展示质地、形态；卖电风扇，就一定要让它一直开着、转着；卖食品、饮品，就一定要煮好、泡好，以能吃的状态去展示。

整体氛围感：在茶室里卖茶叶突出高端，在仓库里卖茶叶突出性价比，给人仓播的感受，让人有下单冲动；在茶园里卖茶叶突出原产地正宗，在大卖场里卖茶叶突出热闹氛围。不同客单价、不同类目的产品，都要用适合的场景去塑造不同感觉：塑造科技实力就放在实验室，塑造家庭氛围感就放在卧室、客厅，塑造产品新鲜采摘、原生态就放在果园、菜地。每一个场景都要匹配人群的购买喜好和产品实际使用场景的氛围。

原产地：如果是真实的、不好复制的原产地，就用最真实的场景说话，走出室内，会让用户产生信任度。比如在新疆葡萄园里卖葡萄干，和在房间里卖葡萄干，差别就很明显，吸引力和信任度都会不一样。

产品的包装：卖产品还是卖包装？我们是通过镜头去感知一个产品的价值感，视觉效果很重要，很多产品包装比产品贵。

产品的摆放：一个陶瓷杯放在普通桌面上、放在木制盒子里、放在打着灯光的玻璃柜里，呈现出的价值感完全不同。

# 5.1.3 直播话术：拉流、信任与成交

# 5.1.3.1 拉流话术：外面的点进来，进来的留下来

目的：要数据、破层级、做权重。简单解释一下拉流：直播间进来的人就是流量，讲一两句简短且和他有关的话吸引他们，把他们留在直播间；外面没进来的人听到有福利，也可能进来看看。进来的人不出去，持续把人留住，在线人数越来越高；留住的人比离开直播间的人多，说明拉流成功了。

话术举例：欢迎新进来的姐姐们进入直播间，我们今天这里是专业的xx直播间，主播手里拿的这个帽子，专柜价格899，现在一个快递费就给了，想要的打1，丝绸面料的帽子，适合XX的姐姐，已经有XX报名了，还有XX个名额，2分钟就要上架了，等会还有XX也是给大家准备的福利。

话术要点：简单清晰地告诉直播间的人我们在卖什么，并提供一个留住他的理由，比如马上要发券、价格只限今天、马上改价、一会儿有福利。

# 5.1.3.2 立人设：讲背景

有背书、做信任，也就是回答“为什么你要听我的”。重点在于摆事实、拿证据、讲故事，让人信服。

话术举例：咱们家是帽子工厂，有3000平方的厂房，100多个工人，一天能生产XX个帽子，都是给品牌做代加工的，咱们这个帽子贴个商标就是大几百，你看咱们这个款式在某宝某猫上卖XX（举道具：价格对比）。

话术要点：介绍产品靠谱，然后列出理由，比如技术背景、源头工厂、全网热卖、口碑好评好等。

# 5.1.3.3 讲主题：今日活动

有主题、有逻辑，说明我来干什么、为什么要这样做。

话术举例：我们家一直做线下，最近刚来线上，准备做自己的品牌。大家都知道，不管是开店还是做直播，肯定得先有人；我们也不知道怎么做直播，所以准备拿出来XX份礼物给大家，姐姐们啥也不用做，就呆着领礼物，给我捧捧人场、热闹热闹，稍后2分钟一轮给大家安排，也不耽误大家时间，今天的福利都有XXXXXX。

话术要点：增强信任，介绍自己为什么今天在这里做活动，给出让人信服的理由，也让自己接下来的活动和利益点铺垫得顺理成章。

# 5.1.3.4 点对点：点对点成交，要读公屏

体现专业度、易成交、有故事。可以请水军带动没有互动的人。话术举例：XX姐姐给我扣1了，给她安排一单。

# 5.1.3.5 塑品话术：让产品听起来更有档次

从更高维度塑造产品。不是简单围绕产品本身说材质、工艺，而是从更高的角度和产品关联，通常会用到这些词汇：大牌同款、纯手工制作、明星同款、进出口。

1. 痛点需求：引起共鸣

2. 产品卖点：为什么买？能解决XX问题。

3. 价值塑造：讲故事塑品、类比品牌

话术举例：（纯手工制作）这个版型由京派旗袍传承人亲手设计，具有浓浓的京派旗袍韵味，穿在身上能凸显女性魅力。这款旗袍如果有兴趣看，在北京大栅栏这条街上就有京派旗袍传承人的门店，有机会能看到这个款式。

# 5.1.3.6 转品话术：承上启下

无中生有、顺其自然、利他口吻。话术举例：刚刚有姐姐问，眼镜还有没有？咱们这个眼镜是给老粉的福利，昨天答应你们的，新粉先不买，过完这个再给新粉福利。

# 5.1.3.7 催单逼单：为什么今天买？

为什么今天买？今天不买有什么损失？开价格后，给他们多留点时间拍，但要营造紧迫感。话术举例：姐姐们手速太快了，没有了，以后也没有了。看看还有没有占单的，再给姐姐点时间，再不付款，咱就把名额让给有需要的姐姐。

# 5.1.3.8 保障话术：放心无忧

买了后悔怎么办？看了没有用怎么办？不满意怎么办？要给出承诺。话术举例：我在这里向大家保证，所有产品都是正品，假一赔十。你们可以看到，这是我们的产品质量报告和国家相关部门的认证。如果购买后发现任何问题，我们提供7天无理由退换货服务。我们的客户评价也非常好，已经帮助了上万的客户解决问题，所以大家可以放心购买。

# 5.1.4 直播间货品攻略：选、组、排、测

# 5.1.4.1 选品：选品决定生死

产品决定打法、决定主播、决定场景、决定人群。以下是几个视频号选品维度，可以辅助决策。首选爆品：其他平台上卖得好的产品，都可以拿到视频号上重新卖一次，可以借助第三方工具，比如蝉妈妈、抖查查、飞瓜，查看各品类销量最好的产品。货源优势：电商的尽头是供应链，要做大做强，供应链很重要，有货源优势就是很大优势，优先考虑。符合视频号人群特点：40+以上的二三线女性为主，没有经过其他直播电商的洗礼，不比价格，退货低。推荐品类：服饰箱包、滋补食疗、零食特产、美容护肤、日用百货。

# 5.1.4.2 组品：组合产品提升价值，方便成交

组品要具体产品具体分析，要有“组”的意识，为了某一个产品的销量，可以用组合手段。关联组合：与产品相关的周边，比如买防晒霜送隔离霜+面膜，买鞋子送袜子。拆分组合：把整体的产品拆分，比如买眼镜送眼镜盒+眼镜布。

# 5.1.4.3 排品：直播中产品的排列顺序

排品要根据直播脚本，符合价格从低到高、从成交视角从易到难的逻辑，提前设定好主播话术。钩子品：作用是开播拉流量、做互动数据和停留数据；特点是价值感高的标品低价挂车，比如苹果手机1000块钱、四个哈密瓜1块钱。福利品：做成交密度；以标品为主，大家对价格都有认知，而且价格确实能做到比大家的心理价位更划算，下单门槛和决策成本小；价格相对比较低，比如5包纸巾1块钱、一袋洗衣液2块钱。承接品：作用承上启下、丰富直播间品类；中间价位，比如几十块钱的东西，可以有微利。利润品：可以是几十也可以是几百，利润率高、毛利率高，能带来比较高的收益。形象品：直播间做形象的价位，比如3980不卖，衬托其他利润品比较便宜。

# 5.1.4.4 测品：判断产品迭代的必要手段

任何一个产品都有生命周期，产品也需要拿到直播间去检验，用户的行为动作是我们判断产品是否需要更换的标准。测试产品受欢迎度，主要看销量。通过弹购物车看用户点击率：曝光点击率高，说明用户对这个品感兴趣，所以后台要经常紧盯数据，随时做好换品准备。让主播后半场介绍产品去测试；把产品放在直播场景中或让主播佩戴，引出话题讨论，比如水军上去带节奏：主播你带的项链很好看，多少钱？主播你身上的衣服卖不卖？

# 5.2 【新增】图书/百货直播案例分享

# 5.2.1 图书直播

书籍类目包括：国学、中医、养生、当代经典文学、中小学生课外书、人物传记。视频号图书类目直播带货，这个项目在视频号平台有两年多了，在抖音平台有四五年的历史，因为从抖音有直播带货开始就有了，现在还是有很多账号在播；仓播卖图书这个项目一直有很多号在播，销量也还不错。适合普通个体入手，从侧面也可以反应这是一个可以长期做的赛道，主要就是以直播卖各种图书赚取佣金为主，无需发货，找后端的🛰️小店挂到橱窗，开播之前上架到小黄车就可以。

目前视频号图书类目直播有两种形式：一种是露手开播，也就是俗称的手播，不需要真人出镜，目前在视频号平台也还是可以的，适合新手最快拿到正反馈；另一种是真人出镜类型，需要布置吸引人的场景，仓库背景或者书架背景，也就是俗称的仓播，近期也有更简单的场景，买一块实景画布即可。下面介绍一下两个项目的概况和完整操作方法。

# 5.2.1.1 模式一 露手直播 无需真人出镜

第一种模式，图书手播直播间，也可称为单品图书主推直播间，因为这种模式全场直播主推一本书为主，一般以历史国学或者中医类的书为主。在视频号直播广场搜索图书，就能找到很多类似的对标直播间。账号一：六个多月卖了四千多单，单价也挺高，利润不错。
