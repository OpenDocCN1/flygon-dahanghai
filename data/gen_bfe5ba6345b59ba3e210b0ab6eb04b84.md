# 先跑通，再自动化

技术栈可以定为 Python 搭配 FastAPI，再配合 Redis、PostgreSQL 和 Docker。这套系统能不能跑顺，重点不在“全自动”程度，而在质量把关与风险控制。更稳妥的路径是：先用 MVP 验证核心逻辑，再一步步优化各环节。

完整方案看着很专业，但落到我们身上偏复杂。复杂需求更适合拆成多个 skill 协作，硬塞进一个 skill 里跑，出错概率会明显上升。整套系统真做下来，可能要几天甚至几周，技术点不少，新手很容易卡住。

所以得做减法：只盯核心功能，先交付一个能用的 MVP，再根据实际使用情况迭代扩展。

### （二）获取🛰️👸号 AppID 与 AppSecret

🛰️👸号的 AppID 和 AppSecret 是调用 API 的核心凭证，重要性类似账号和密码。缺了这两项，就无法通过程序操作👸号。

**AppID（应用 ID）**

它是👸号在🛰️开放平台上的唯一标识，类似身份证号。每个👸号都有一个唯一 AppID，🛰️服务器靠它识别是哪个👸号在调用 API。AppID 是公开的，可以在代码中明文使用。

**AppSecret（应用密钥）**

它是👸号的密钥，作用类似密码。必须严格保密，不能泄露给任何人，也不能上传到公开代码仓库。如果 AppSecret 泄露，别人就可能冒充你的👸号调用 API，可能导致内容被篡改、数据被窃取等严重后果。

**AppID 和 AppSecret 的关系**

两者必须配对使用，类似用户名和密码。调用🛰️👸号 API 时，需要同时提供 AppID 和 AppSecret，🛰️服务器会验证二者是否匹配，只有匹配成功才允许 API 调用。

#### 步骤 4：配置 API IP 白名单

API IP 白名单是🛰️👸号的一项安全机制。它的作用是限制只有特定 IP 地址才能调用你的👸号 API。即使别人获取了 AppID 和 AppSecret，如果他们的 IP 不在白名单中，也无法成功调用 API。这就像你家的门锁：即使别人有钥匙（AppID 和 AppSecret），但如果他们不在允许进入的名单中（IP 白名单），门也不会打开。如果不配置 IP 白名单，当 Skill 尝试调用🛰️👸号 API 时，会收到“IP 地址不在白名单中”的错误提示，导致 API 调用失败，Skill 无法正常工作。所以配置 IP 白名单是使用🛰️👸号 API 的必要步骤。在开发密钥页面下方，找到【API IP 白名单】或【IP 白名单】选项，配置允许调用 API 的 IP 地址，只有在白名单中的 IP 才能成功调用🛰️👸号 API。

**如何查看自己的公网 IP 地址？**

在配置 IP 白名单之前，需要先知道自己电脑的公网 IP 地址。这里提供几种查看方法：

**方法一：使用在线工具（最简单）**

打开浏览器，访问 https://ip.cn 或 https://www.ip.cn，页面会自动显示你当前的公网 IP 地址，比如“36.112.123.45”，快速获取公网 IP 地址。

[PRE10]

**方法二：使用搜索引擎**

在百度或 Google 搜索框中输入“我的 IP”或“my ip”，搜索结果的第一条通常会直接显示你的公网 IP 地址，通过搜索引擎快速查询 IP 地址。

**方法三：使用命令行（适合技术人员）**

在 Mac 或 Linux 系统中，打开终端，输入命令 curl ifconfig.me 并按回车，终端会显示你的公网 IP 地址。在 Windows 系统中，打开命令提示符（cmd），输入命令 curl ifconfig.me 并按回车（需要先安装 curl 工具）。

**注意：**

这里获取的必须是公网 IP，不是局域网 IP。局域网 IP 通常是 192.168.x.x 或 10.x.x.x 这样的格式，这种 IP 无法访问互联网，也无法用于 API 白名单。

**IP 白名单配置操作**

找到【API IP 白名单】选项后，点击旁边的【修改】或【添加】按钮，进入 IP 白名单编辑页面。在弹出的输入框中，输入你刚才查到的公网 IP 地址，比如“36.112.123.45”，然后点击【确定】或【保存】按钮，将你的 IP 地址添加到白名单中，允许这个 IP 调用 API。系统可能会要求身份验证（扫码或输入验证码），完成验证后，IP 地址就添加成功了，确保只有👸号管理员才能修改 IP 白名单，防止被恶意篡改。

**重要提示：**

🛰️👸号的 IP 白名单最多可以添加 5 个 IP 地址。如果你的 IP 地址经常变化（比如使用家庭宽带，运营商会定期更换 IP），建议使用云服务器（如阿里云、腾讯云）来运行 Skill，云服务器的 IP 地址是固定的，不会变化。

**动态 IP 的处理方案**

如果你使用的是家庭宽带或移动网络，IP 地址可能会经常变化。每次 IP 变化后，你都需要重新登录🛰️👸号开发者平台，更新 IP 白名单，否则 API 调用会失败。这里提供几种解决方案：

**方案一：定期更新 IP 白名单**

如果你的 IP 变化不频繁（比如几周或几个月才变一次），可以选择每次 IP 变化后手动更新白名单。虽然麻烦一些，但成本最低。

**方案二：使用动态域名解析（DDNS）**

如果你有一定的技术能力，可以使用动态域名解析服务（如花生壳、Cloudflare DDNS 等），将一个固定的域名绑定到你的动态 IP 上。虽然 IP 会变化，但域名不变，可以通过域名访问你的服务。但🛰️👸号的 IP 白名单不支持域名，所以这个方案需要配合其他技术实现。

**方案三：使用云服务器**

购买一台云服务器（阿里云、腾讯云、AWS 等），将 Skill 部署到云服务器上运行。云服务器的 IP 地址是固定的，不会变化，只需要配置一次 IP 白名单就可以长期使用。云服务器的成本不高，最便宜的配置每月只需要几十元。

**方案四：使用代理服务器**

购买一个固定 IP 的代理服务器，让你的 Skill 通过代理服务器访问🛰️👸号 API。这样即使你的本地 IP 变化，代理服务器的 IP 是固定的，不需要频繁更新白名单。
