# 2.蓝V企业号：先定卖点，再布转化入口

在动手做企业号基础建设前，先把两个问题的答案想明白：

1. 企业的核心优势是什么？（自己能提供、竞品不具备、且用户真正需要的）
2. 企业能给用户什么“行动收益”？（给提交线索这个动作一个合理理由，让用户心理上愿意接受）

核心优势与行动收益，都要落到以下展示和承接模块里：企业主页、进阶预约组件、私信开场白、应答话术等。

# 1.选择高转化关键词

1. 明确业务核心词：
从自身业务出发确定核心业务词和行业词。例：产品是床垫，业务词可以是“买床垫、床垫怎么选”，行业词可以是“家居软装、床上用品”。注意排除与业务不相关的词，如“床垫回收、床垫除螨”就不属于业务词。

# 2.寻找主流量关键词

手动查找：在AIDSO网站查询关键词。
网址：https://www.aidso.com/
[PRE11]

关键词筛选要看四项数据：月覆盖人次、7日搜索人次、下拉词数量、竞争度。
- 月覆盖人次：近30天与该关键词相关的作品覆盖人数，也就是这个词在抖音平台被内容覆盖的人数。覆盖多说明流量池大，但发布者多，不代表容易上排名。
- 7日搜索人次：近7天在抖音搜索该关键词的人数。数值越高，说明关键词价值越大，做排名越重要。
- 下拉词数量：包含该关键词的词有多少。下拉词越多，上排名难度越大，因为用户搜索时可能进入下拉词内容。
- 竞争度：整体竞争难度。

制作符合DSO逻辑的视频和图文。搜索作品与推荐作品有明显差异；判断关键词该做图文还是视频，要看该关键词搜索结果前几条作品的情况：前几条视频多就做视频，图文多就做图文。
[PRE26]
✅关键词搜索结果视频多，此关键词做视频。
✅关键词搜索结果图文多，此关键词做图文。

# 1.制作DSO短视频

制作符合DSO逻辑的视频时，文案、画面、字幕、背景区、视频封面、视频前3秒都要尽量覆盖关键词。

# 1.1确认视频形式
写脚本和制作前先确认类型。依据关键词含义去推演搜索该词的受众人群想看什么内容，也可参考关键词前十个作品判断形式。

示例：选择关键词“考研怎么选学习以及专业”
[PRE27]
点击关键词在抖音搜索，能看到上述作品情况。
步骤1：分析前几个作品的形式。该关键词前几名有四种形式，前几都是口播。
步骤2：考虑口播形式自己能否做。能做，就继续看前几名内容大概是什么样，再撰写脚本（不能原样抄袭）；做不了口播，就从剩下三种形式里选自己能做的。
优先级：关键词下出现最多的视频形式。
依据关键词内容定位确定视频形式。

- 剧情类（Vlog）：通过有起承转合的故事吸引观众，可包含搞笑、悬疑、情感、励志等题材。例如关键词“0成本创业适合做什么？”，讲述职场成长故事，并带出业务能提供的帮助，让观众产生情感共鸣。
- 口播类：创作者主要靠语言表达传递信息，如新闻资讯播报、观点评论、故事讲述等。例如时事评论员对近期热点发表看法。口播类适用各行业，操作难度低。
- 技能教学：教授实用技能，如烹饪、健身、化妆、摄影、乐器演奏等。例如关键词“健身教练证怎么考”，详细展示考证步骤及相关业务，让观众跟着学并来咨询。
- 知识分享：把擅长领域的知识用通俗方式讲出来，如历史、科学、财经、法律常识等。例如关键词“怎么学会投资？”，用生动案例讲供求关系原理，分享实用小常识，帮助观众增长知识，进而信任业务。
- 混剪类（录屏、素材混剪）：把多个视频片段剪辑组合，配上音乐和解说，形成有主题的新视频。例如关键词“北京旅游团”，把旅游拍摄的各地风景片段混剪，并加入业务宣传，用户感兴趣后前来咨询。

# 2.制作DSO图文
制作符合DSO逻辑的图文时，标题、文案、图文封面都要尽量覆盖关键词。

# 2.1确认图文模板以及形式
制作图文前也要确认类型。依据关键词含义想象搜索该词的受众想看什么图文，也可根据关键词前十个作品判断形式。

示例：选择关键词“三天两夜旅游推荐”
[PRE32]
点击关键词在抖音搜索，能看到上述作品情况。
步骤1：分析前几个图文作品的封面模板。该关键词下模板大致分三种。
步骤2：寻找素材做类似封面，去各大素材网站找图。
步骤3：去美图秀秀/醒图/可画/其他作图软件找模板。点开前几个作品内容观看，分析受众喜好，找目标年龄层喜欢看的模板。

# 2.2确认图文内容
图文内容要依据关键词搜索含义分析，可去其他网站找内容参考。例如所在行业是考研教培，选关键词“考研怎么选学校以及专业”：先思考什么样的人群会搜这个词；再想搜索这个词的人想看到/得到什么；最后想怎么结合这个词去拓展、种草业务；整理好文案和配图素材。

# 2.3制作图文
运用制图软件作图：美图秀秀、可画、醒图、稿定设计等。

制图要求：
- 每张图文都要包含关键词；
- 一组图约3-6张；
- 图片清晰，比例3:4（📕比例）；
- 素材清晰，文字字体要让用户看清；
- 图片与文字占比合理。

制图注意事项：
- 配色不能太多，最好用企业色+相近色；
- 同一组图除封面外要统一模板。

# 05.视频与图文发布

# 1.发布时间
分析行业人群，观察行业人群的上线时间，在人群上线前1-2小时发布作品。例如受众是大学生，上线时间约9:00-23:00，他们不会太早起且闲暇多，可在这期间多发；受众是白领，就要推算其休息时间，因为这类人多在休息时刷抖音。如果实在不清楚，前期新号可多测试，观察数据趋势，总结哪个时间段互动数据更好，多测几次就能找到规律（新号建议一天发5-7条，早6点至晚22点，每隔2小时发布）。

# 2.发布文案
手机端直接点击发布编辑；电脑端进入抖音创作者中心后台发布。
标题：包含完整关键词，可加前缀和后缀，整个标题要符合关键词含义。
文案：包含1-2次关键词，整体文案要符合关键词含义，不要无意义重复堆积。
话题：第一个话题必须是关键词，剩余4个可添加行业相关关键词（关键词库）。就算关键词话题应用为0也要使用。

# 3.合集创建
合集重要性很高：合集能让其下所有作品获得加权，还能延长作品更新时间。合集也要围绕关键词做：合集名称、合集封面、合集简介都要体现关键词。合集标题只填关键词；简介文案至少展示一次关键词；合集封面要包含关键词且醒目。
