# 3.3.2.5 在 Python 里快速上手数据库 @大铭

在 Python（或其他编程语言）中，还可以借助 ORM 框架来高效管理数据与数据库之间的映射关系。

什么是 ORM

ORM 全称 Object-Relational Mapping，即对象关系映射。有了 ORM，我们能在程序里直接操作对象（class），而不必直接操作数据库；所有数据库操作都由 ORM 代劳，使用起来更省心。

使用 ORM 的好处

1. 提高开发效率，减少编写和拼接 SQL 的工作量，尤其在遇到特定查询条件和数据库兼容性问题时。

2. 增强可维护性，日常只需要处理程序代码中的对象，不用直接面对 SQL 语句；同时大多数 ORM 都能帮助防范 SQL 注入问题。

3. 支持多种数据库，本地开发可以用轻量数据库（如 SQLite），生产环境可以切换到更合适的数据库（如 PostgreSQL、MySQL）。

Python 中常用的 ORM 框架

SQLAlchemy：最强大、最灵活的 ORM 框架之一，提供了一套完整的数据库抽象层，支持 MySQL、PostgreSQL、SQLite 等常见关系型数据库，也能在不同数据库之间平滑切换。

Django ORM：Django Web 框架自带的 ORM，在 Django 项目里使用起来很方便。

Peewee：轻量级 ORM，以简单易用著称。虽然不如 SQLAlchemy 强大，但对小型项目或数据库操作要求不高的场景非常合适。

# 3.4 代码管理：版本控制入门

代码管理一般出现在复杂项目或多人协作中，这里只介绍一些基础概念，作为一个引子，之后可以深入扩展。

1. 代码管理是什么，有什么用

代码管理也称版本控制，是一种记录文件内容变更的系统，方便后续查看任意特定版本。想象你在写一本书，每次都保存一个新版本，之后就能随时回溯到任意旧版本。代码管理为代码提供了同样能力。

用途：
跟踪变化：记录每次修改，知道谁在什么时候改了什么。
团队协作：支持多人同时处理同一项目，彼此不干扰。
备份和恢复：代码出问题时，可以回到之前的稳定版本。
分支开发：可以放心尝试新想法，不影响主项目。

2. 有哪些代码管理工具

常见的代码管理工具有很多，最流行的是这几个：

Git：目前最流行的版本控制系统，几乎所有编程语言和平台都支持。
SVN（Subversion）：曾经很流行，但现在使用频率越来越低。
Mercurial：和 Git 类似，通常更简单，不过用户规模较小。

后两种大家不用太关注，直接学 Git 即可。

3. GitHub 怎么用

GitHub 是基于 Git 的代码托管平台，除了代码管理，还提供 bug 跟踪、功能请求、任务管理、wiki 等协作功能。

基本使用步骤：
1. 创建账户：访问 GitHub 官网注册账号。
2. 创建仓库：在 GitHub 上新建仓库。
3. 克隆仓库：把远程仓库克隆到本地。
4. 提交更改：在本地修改代码后，提交到本地仓库。
5. 推送到 GitHub：把本地更改推送到 GitHub 仓库。
