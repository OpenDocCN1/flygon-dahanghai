# 【新增】09.热点怎么追，二创怎么玩

AI影像账号绕不开热点。玩法的热度窗口不一样，有的只红一两周，有的能撑一两个月。手册里的教学在写的时候还新鲜，等到航海正式开始，可能已经跟不上节奏。

新热点就是新流量池。抢在最前面的人能吃肉，晚一步的能喝汤，再晚可能连汤都没有。当然这只是个比喻，真实世界里也存在幸存者偏差。等你把AI视频的制作流程摸熟，就该琢磨怎么把热点做进内容里。

先想清楚两个问题。

一、什么热点能追，什么不能追？

拿15个近期话题判断：赵露思、罗小黑战记、捕风追影、ASMR、碳烤labubu、生万物、浪浪山的小妖怪、抗战胜利80周年、秦始皇骑北极熊、人民校长、萌宠吃播、黑神话钟馗、蜜雪冰城、南京照相馆、labubu。

可追：罗小黑战记、捕风追影、ASMR、浪浪山的小妖怪、生万物、秦始皇骑北极熊、人民校长、宠物吃播、labubu。

别碰：赵露思、碳烤labubu、抗战胜利80周年、黑神话钟馗、蜜雪冰城、南京照相馆。

规律很直接：影视剧、动漫、抽象梗、潮流梗，基本都能下功夫。这类内容的受众大多是28—35岁的年轻人，男女比例大约3:7。反过来，明星八卦、过于冷门的话题、敏感争议题材，不建议跟风。它们也许更容易有短期热度，但没流量、限流、封号的风险都在后面。

在AI视频创作里，最怕的是思维固化。一个模式反复用，平台容易判定为低质，甚至不再给推荐。所以一定要复盘：你的流量到底来自玩法，还是内容？然后围绕真正有效的那一侧，去生产更多元的东西。平台是鼓励这种尝试的。

# 01.让AI帮你搭故事

# 1.章节导读

到这里，你已经掌握了AI视频创作的核心技能：图生视频、角色对口型、治愈系风景、趣味拟人，都能上手。独立做出多风格短片不是问题。

但能不能更进一步？

之前做的大多是1—3分钟的短视频，场景转换也比较简单。真正的影视作品需要完整故事、连贯镜头语言、精心设计的分镜，还有专业声音设计。

如果说前面是“用AI生成短片”，这一章就是“让AI陪你拍电影”。

你将学到：

- 用AI构思完整剧本
- 建立统一的角色形象
- 用专业镜头语言设计分镜
- 处理复杂场景切换
- 做声音设计与后期

这不只是技术升级，更是创作身份的变化：从内容制作者，变成视觉导演。

准备好了，就往下走。

# 本章航线图

学完本章并动手实操，就可以推进：

第三阶段：熟悉AI影视创作流程（共4天）

- 借助AI构思剧本和分镜（约2天）
- 掌握视频生成和后期剪辑（约2天）

第二幕：穿越出错。落点偏了，他直接掉进兵马俑坑，被当作间谍。他手忙脚乱用翻译器解释，谎称自己是西域来的送饭使者。押到宫殿后，嬴政正在为御厨的手艺发火。他灵机一动，把自热锅献上，说是御厨刚研制的新鲜玩意。

第三幕：历史失控。嬴政亲自试吃，被“加水就能自己热”的黑科技震住，马上下令全国研发便携加热兵器，“发热炊事部队”诞生。秦军横扫六国后，开启了移动餐饮帝国，外卖霸榜全世界。

# 2.4 让剧情更细

光有梗概还不够，继续追问AI，让它补充生动的细节。

《时间管理局快递员》第1集：火锅误国

未来总部：空中霓虹广告闪着“时间快递，使命必达”。主角背着大快递包排队，忍不住抱怨：都3012年了，还在送外卖。机械语音派单：重要客户嬴政，物品便携自热锅，备注“不可惊扰历史进程”。他接单时咬牙：好歹是皇帝，总不能吃得太差吧。

传送舱：那是一个长得像洗衣机的圆筒。他钻进去按下启动，领导从对讲机里喊：要让他觉得火锅是自家臣子搞出来的，别再乱改历史！他比了个OK，穿越开始。

落点：他又偏了，直接砸进兵马俑坑旁的泥地。巡逻士兵吓得喊妖怪，举矛冲过来。他举起快递箱，用翻译器喊自己是送饭的。士兵将信将疑，把他押到皇宫。

大殿上：嬴政正在发火，把御厨端上来的菜摔在地上。主角跪着奉上快递箱，谎称是御厨们研发的“便捷热食神器”。他当场倒水，火锅咕嘟冒泡，香气四溢。嬴政拿起筷子尝了一口，眼神从惊讶变成感动：“竟有此物……朕有福了！”

历史线失控：嬴政召集百官，下令全国研发“自动加热战粮”。几个月后，秦军一边打仗一边吃火锅，士气爆棚，横扫天下。警报骤然响起：嬴政的统治延长了300年，未来变成火锅王国。

未来世界：主角被紧急拉回。街道上全是外卖小车和移动火锅店，交通工具清一色改成锅盖车，新闻主播穿着铠甲直播火锅比赛。领导气得拍桌子：“你又搞砸了！”他小声辩解：“至少大家吃得很开心？”领导呵呵一笑，罚他抄规章300遍，还让机械臂给他戴上惩罚头盔。

彩蛋：主角正抄得生无可恋，收到一封古色古香的信。信里写着：赐未来快递使者“永恒至尊外卖会员卡”，朕感你厚恩。旁边还贴着一张超VVIP火锅卡。他哭笑不得：“这到底是功劳还是罪过？”

细节补充：快递包能瞬间伪装成古代行李；包装上带防伪古籍说明，他念错内容差点让嬴政以为收到仙丹；传送后有3秒强制变装时间，古装加运动鞋违和感拉满；耳边的小型AI会实时播报历史偏差，一边看他救场一边疯狂吐槽。

# 2.5 生成分镜图

文字想象再丰富，也不如一张画面直观。Midjourney这类AI绘图工具就可以把场景描述变成电影感分镜图，不需要会画画，描述越精准越好。

绘图方向：未来玻璃大厅、霓虹任务板、科幻制服、乱发年轻快递员、大号装备包、电影感光效、广角写实。

分镜1-2【任务接单·特写】

绘图方向：机械臂和透明卡片、发光中文、年轻人伸手、困惑表情、科幻装置细节、柔和背光。
