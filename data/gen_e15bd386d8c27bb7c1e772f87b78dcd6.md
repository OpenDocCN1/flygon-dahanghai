# 5.1.2 对标怎么找？5个入口一次讲透

想找到值得拆解的对标笔记，不必瞎逛，下面五条路径就够用。

1. 首页关键词搜索  
先在首页输入你所在赛道的核心词——也就是养号阶段反复搜过的那些词。浏览排在前50的笔记，重点挑“小爆款”和“中等爆款”，同时看评论区有没有“求”“需要”“私我发”这类留言；满足这些条件，基本就是可对标的爆款。账号选择上，优先看同赛道、起号三个月到半年的同行。

2. 搜索栏挖需求  
在搜索框输入赛道关键词，下拉联想里会显示📕用户高频搜索词。出现得多，说明需求旺。按小爆款、中等爆款的标准去筛，就能挖出优质选题来对标。

3. 刷首页推荐  
养号完成后，平台会结合你的互动和偏好推送内容，这时首页大概率会出现同行爆款。仍然按小爆款、中等爆款的标准筛选，挑出值得跟的选题。

4. 从赛道热门话题里找  
盯住同领域做得好的博主，找出他们互动量高的笔记，点进话题标签，再按小爆款、中等爆款标准筛出优质选题。

# 5.2 流程二：让爆款选题持续产出

# 💡

多数赛道发笔记可遵循82原则：8篇产品笔记用于卖货，2篇行业干货用来提权重、吸流量。  
✔️ 产品笔记：把资料内容搭配爆款标题、关键词和文案，核心作用是转化客户——对方就是冲你的产品来的。  
✔️ 行业干货：用AI洗稿爆款内容，目的是增加曝光、抬高账号权重，并让精准用户更愿意留下来。

# 5.2.1 连爆打法

爆款的底层秘密就两个字：重复。内容重复、形式重复、选题重复。  
做法是：先仿写别人的爆款，反复测试，直到跑出属于自己的爆款；跑通之后，再复制自己的爆款。  
📕里同一个封面加相似爆款标题，居然能火三次。这说明新人别想太复杂，直接对标爆款笔记就行。一个东西能火，说明它戳中了用户心里那块地方；至于具体怎么戳中的，不必硬研究，也很难研究明白。  
记住：做📕，对标找对了，等于已经完成70%；剩下的，就是重复、重复、再重复。

# 5.3.1 标题杂交法

# 💡

这里要感谢袁隆平爷爷：把不同优质水稻杂交，能育出超级水稻。  
标题也可以这样“杂交”。方法不复杂，效果却很直接，我的爆款标题就是这么来的，算是流量密码。  
比如搜“纪录片—最热”，翻看排名前十的笔记，会发现高频词就那几个：央视推荐、绝了、建议收藏。最热前8个里，有6个标题几乎一样——爆款都在重复。直接抄关键词，不断排列组合，杂交出来的标题自带爆款基因。

# 5.3.2 二极管式标题法

# 💡

基本原理：  
人本能偏爱省力法则和及时享受；动物性的基本驱动力是追求快乐、逃避痛苦，由此衍生出正刺激和负刺激。  
标题公式：  
正面刺激：产品/方法+只需1秒（短期）+便可开挂（逆天效果）。  
小学语文类目里很火的一种写法：死磕这x页纸，考试就像抄答案（见下图）。  
负面刺激：你不xxx+绝对会后悔（天大损失）+紧迫感。  
比如“你不看这篇文章就会错过一个亿，限时删除！！！”  
抖音上大量文案都是这个套路，说白了就是制造焦虑，虽然有点损，但用户吃这套。  
本质是利用人们厌恶损失和负面偏误的心理：原始社会里，抓住一个机会可能只是多吃几口肉，但一次失误可能葬身虎口，进化让我们对负面消息更敏感。

# 5.4 流程四：封面与内页制作SOP

# 5.4.1 排版先守住基本原则

# 5.4.1.1 封面三要点

✅ 给零基础作图的小伙伴几个要点：封面排版牢记三件事。  
要点一：封面尺寸。  
竖屏选3:4，方形选1:1，横屏选4:3。竖版笔记屏幕占比更大，能在用户视野里停留更久，不仅信息承载多，被划走的概率也更低。  
要点二：精准选图。  
视觉冲击强的高颜值配图（可用AI生成）；简单明了的手写类型（可简单手写）；适合合集、美食、旅游攻略等。  
要点三：简要文字。  
📕笔记标题限20个字符（emoji占1～3个字符）。想补充更多信息，就要用好封面。用户在发现页浏览时往往比较茫然，所以核心字体要在画面里占足够篇幅，概念清晰，直击需求，告诉用户：这篇笔记对你有价值！让对方产生点击冲动。

# 5.4.1.2 二少原则：少变与少用

二少原则：少变、少用。  
第一，少变。不要频繁更换封面版式，尽量做到模板化、可替换化；排版、字体、风格保持一致（颜色可在同色系里变换），这样主页更整齐，也方便粉丝认出你。  
第二，少用。少用不相干贴纸，避免喧宾夺主、分散用户注意力。

# 5.4.2.1 截图呈现

截图是最简单的作品呈现方式。

# 💡

截图同质化怎么破？很简单：  
1. 自己截图发。  
2. 给作品加边框，调整图片参数。  
3. 把文件内容复制到AI软件，让AI重写一版相似内容，再截图，就是完完全全的新文件。  
4. 打印出来，拍打印作品。  
以上方案都建议试试。如果某个素材在你账号爆了，就换个方式再表达一次，争取让它二次爆发。谨记！！！
