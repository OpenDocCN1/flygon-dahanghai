# 4.2.3.4 域名 SSL 证书申请指南

网站与 iOS App 之间通过 API 通信时，必须基于 HTTPS 协议，因此域名必须配置 SSL 证书。

申请步骤非常简单：进入网站列表，点击对应站点后的“设置”，切换到 SSL 选项卡，选择“宝塔证书”，点击“申请证书”，勾选需要申请的域名并填写相关资料，提交申请即可。申请成功后点击“部署”按钮，待自动部署完成，再勾选“强制 HTTPS”并保存。

需要留意的是，该证书的有效期仅为四个月，到期后需要重新申请。
