# 热点拆解与教案生成：AI写作实操笔记

写热点分析稿，先别急着下笔，先算篇幅：若正文安排三个角度，每个角度约400字，合计1200字；全篇余下约300字，可切成开头100字、收尾200字。再按客户“必须从三个角度分析”的要求，先搭骨架。

【案例标题】年轻人把五星级酒店当食堂，究竟图什么？

一、舆情背景（约300字）
二、舆情分析
维度一（约400字）
维度二（约400字）
维度三（约400字）

骨架定好后，要确保模型有可用的素材库。以本案为例，先让模型学习“年轻人把五星级酒店当食堂”相关报道，来源尽量选新闻媒体网站，可借助秘塔搜索查找，再把资料整理成文档上传学习。提示词可设为：请学习上传文档，并按固定格式输出“××新闻能从中得到什么结论”，每条结论不少于200字。效果见[PRE0]。

# 3.4.2.3 执行
准备完毕，进入正式写作。第一步是写提示词，其中标黄部分后续可替换。提示词设定：角色为资深新闻工作者，构思巧妙、语言犀利；任务是写《年轻人把五星级酒店当食堂引发分析》，按模板输出。模板为：标题、一、舆情背景300字、二、舆情分析（维度一400字、维度二400字、维度三400字；若某维度600字，可拆成两个300字段落，举一反三）。素材部分给出五家媒体结论：腾讯网看到消费观念多元、性价比与便捷性、酒店快速响应；新浪新闻注意到高端追求与经济性平衡，12888元年卡可简化“吃什么”的决策，体现理性“薅羊毛”，社交平台放大共鸣；知乎强调便捷高效、时间管理、对性价比的独特理解，并提醒健康与长期平衡；网易新闻指出高品质与便捷双重追求、行业创新、长期分摊更划算，同时提示健康与商家诚信风险；四川在线则从话题讨论切入，谈生活品质、创新思考、减少决策疲劳、长期经济账、商家敏锐，并提醒别盲目跟风，警惕类似健身年卡的反面案例。要求：从三个角度分析；每个维度以“一是有观点认为……”开头，先亮观点，再按“××新闻/××网得出什么观点、分析出什么内容”的形式展开，可合理编造；若维度不理想，可做一次个性化调教，提示词为“若想让读后感独树一帜，有什么建议？请结合素材生成新的三个维度”，从而多备几个可用维度。

第二步是人工干预、生成定稿。终稿标题为“年轻人把五星级酒店当食堂引发分析”。舆情背景约300字：近年消费观念变化，一些年轻人购买价格不菲的自助餐年卡，把五星级酒店自助餐厅当食堂，每日三餐在酒店解决；短视频和社交平台分享带动模仿，媒体与公众讨论升温。有人认为是聪明消费、追求品质生活；也有人质疑是否真划算，并担心长期就餐的健康风险。因此需要多角度分析社会心理与经济因素。

维度一：消费升级与生活方式变革。有观点认为，这反映消费升级下生活方式的转变。腾讯网指出，年轻人重视生活品质，也在忙碌中追求方便高效；他们精打细算，以较低单价享受高端餐饮，是“聪明消费”，也在挑战传统消费模式，在经济压力与生活质量之间找平衡。但也要追问：是否过度依赖外部资源、忽视自我生活技能培养。

维度二：社交媒体对消费行为的推动。有观点认为，社交媒体在传播扩散中起关键作用。新浪新闻分析，大量年轻人分享酒店用餐经历，带动模仿，短视频和图片把这种生活方式包装成高品质、高性价比象征；知乎报道进一步指出，“炫耀性消费”让个体消费公开化、可模仿化，形成“社交货币”。其弊端是容易放大短期满足和表面性价比，忽视长期经济规划与健康考量，导致盲目跟风。

维度三：经济压力与理性消费的矛盾。有观点认为，自助餐年卡背后是经济压力与理性消费的拉扯。网易新闻指出，面对高房价、高物价，年轻人希望有限预算内最大化生活质量，精细核算后把年卡当作节约生活成本的方式，是对经济压力的应对。四川在线提醒，短期看似划算，长期是否真节约，还要看健康问题和其他隐性成本；盲目跟风买卡也可能造成财务压力。因此，追求品质生活时仍要保持理性，别因短期利益忽略长期影响。

# 3.5 写一篇课程教案 @海盐芝士
通俗地说，教案就是教师上课前准备的详细计划，像做事前写的清单。它能帮教师理清思路：这节课讲什么、怎么讲、怎样让学生理解和掌握。教案常用于教案比赛、教学展示、招聘面试和日常教学；善用这部分内容，可以提高备课效率。教案写作一般有三种场景：一是自主创作，完全原创、不依赖现成模板；二是模板适配，按特定格式在既定框架内填充内容；三是修订完善，对已有教案做润色、内容更新、策略优化或表达调整。下面依次展开。[PRE2]

# 3.5.1 场景一：自主创作
若一开始没有确定模板，可以直接用“万能模板.docx”。模板中需要撰写的部分包括：课时、授课时间、课型、课程标准要求、课时目标、教学重点、教学难点、教学方法、学习方法、教学用具、教学过程。前十个相对简单，可称为“无脑内容”；教学过程是全篇核心，要结合客户需求修饰。[PRE3]

# 3.5.1.1 “无脑内容”撰写
这部分可让GPT直接生成，再根据内容和客户简单要求微调。提示词模板中，黄色部分按客户群体和需求调整，红色部分是客户特色需求；客户没有特殊要求就不写。示例任务：写《小学生美术》教案，面向三年级学生，按大纲撰写。角色设定为资深小学美术教师，特征有三：创造力强，善于激发学生创造力；耐心细致，能细致指导鼓励孩子，帮他们在创作中找到自信；热情亲和，善于互动，营造轻松愉快课堂。大纲列出课时、授课时间、课型、课程标准要求、课时目标、教学重点、教学难点、教学方法、学习方法、教学用具。要求只产出大纲内容，并写清客户特色需求。对话结果见[PRE4]。
特色需求要留意：示例结果都与绘画工具相关；若客户要求画圆或其他更具体的东西，就要把这类要求写进提示词。[PRE5]

# 3.5.1.2 教学过程撰写
提示词模板的任务仍是写《小学生美术》教案，面向三年级，按大纲撰写；角色同上。大纲为：一、复习巩固；二、新课导入；三、新课教学；四、小结；五、练习巩固（当堂检测）；六、布置分层作业。要求只写给出的大纲部分；“三、新课教学”要体现以学生“学”为主、教师“导”为辅：教师结合内容难易，通过设疑、指令、布置任务等方式，引导学生自主学习简单内容、同桌讨论中等难度内容、小组合作较难内容，经历自主、合作、探究学习；再通过不同环节、不同难度、不同学习方式，实现突出重点、突破难点。同时写清客户特色需求。对话结果见[PRE6]；终稿为“终稿.docx”。[PRE7]

# 3.5.2 场景二：模板适配
客户提供模板时，就要按客户模板写作，可能需要修改提示词。案例为“附件2：成都体育学院2019版教案模板.doc”。拿到模板先分析特点：其中需要撰写的是“教学目标”“教学内容”“教学重难点”“教学方法”“课后作业布置与学习参考书”。这些可视为AI“无脑出”的部分；“教学设计”与前面一样属于重难点，需要单独列出来生成结果。[PRE8][PRE9][PRE10]

# 3.5.2.1 “无脑内容”撰写
让GPT依据客户模板大纲直接生成，再加入模板内要求稍作调整。提示词中黄色部分按客户群体和需求调整，并要求单独列出一个结构模块：一是在【大纲】填入客户模板大纲；二是在【要求】填入每个模块的具体要求，模块名用引号标出。示例任务：写《体育》教案，面向三年级学生，按大纲撰写。角色为资深小学体育教师，特征包括：创造力强，善于激发学生创造力；耐心细致，帮学生在体育运动中建立自信；热情亲和，建立良好师生关系，营造轻松愉快课堂。大纲为教学目标、教学内容、教学重难点、教学方法、课后作业布置与学习参考书。要求只产出大纲内容，并逐项说明：“教学目标”要基于教材内容与学情分析，设计学生在知识与技能、过程与方法、情感态度价值观等维度应达到的预期目标；“教学内容”写本次课主要教学内容及时间安排；“教学重难点”要说明教学重点是教材中举足轻重、关键性、最重要的中心内容，掌握它有助于巩固旧知、学习新知；教学难点是学生难以理解和掌握的知识要点；教学重点不一定都存在难点，实际教学中重点也可能包含难点；教学上要重点突出、难点详讲；“教学方法”要根据知识点性质、学生特点、教师自身特点综合选择，如讲授法、演示法、小组讨论法、情景教学法等。上述要求来自客户模板中的文字说明。[PRE11]
