常听人说：“买在无人问津时，卖在人声鼎沸处。”这句话已经快被说烂了，可真到无人问津时，大家又觉得还能跌更多，反而不想下手；到了人声鼎沸时，又觉得还能涨更高，于是死死攥住。这就是人性。

结果是，不管赚了多少，心里始终不满足。

这种时候，最好的做法是尽量屏蔽周围的声音，问问自己：当前的目标收益达到了吗？如果达到了，就可以逐步止盈，慢慢离场了。

# 2）震荡期怎么应对

大饼上下震荡，整个大盘也跟着晃。最难受的就是这种不上不下的状态，看不清未来，也不晓得该进还是该退。

震荡行情其实要分成两种：上涨趋势和下跌趋势。

如果是确定性比较高的上涨趋势，那现阶段不管什么价位买入主流资产（公链/市值前列的币），基本都不会太差。唯一的问题只是短期回调会带来一点心理压力。

方向明朗以后，手上的子弹就可以慢慢往外打了，同时想各种办法减轻持仓压力。

比如开个机器人做套利，或者把注意力转移到运动、健身、写作上去。咬咬牙就熬过去了，最怕的是行情回调时你的筹码被洗掉。

# 3）平淡期做什么

链上几乎没有造富效应，大家只能在无聊行情里吃瓜、薅羊毛，顺便学点新东西。

行情平淡时，不适合做太多操作，往往多做多错。

Web3是典型的看天吃饭行业：行情一好，群魔乱舞；行情一差，真金也会被当成镀金。

这种时候不妨学点新技能，提升自己的竞争力。比如做一级的可以去补二级的知识，学学怎样看K线、怎样搜索数据；也可以试着学编程，提升自己的做事效率。

在行情差的时候，反而容易找到质地还不错的标的，可以持续定投。

我前几天看到一张去年的图，有个公链币当时大概是0.25，现在已经到了0.87，一年下来涨了350%。这种涨幅在传统金融里几乎是不敢想的，但在Web3里确实能发生。

可是大多数人不敢也不愿意在冷清的时候去捡好筹码，反倒更愿意在行情热的时候花溢价去买一堆不确定的东西。人就是厌恶风险，却又巴不得高收益，没办法。

# 11.4.3 心态建设怎样影响盈亏

先讲讲前段时间让我特别焦虑的一件事。

那阵子我很焦虑，是一种没来由的对比焦虑。习惯性地拿自己和周围赚得更多的朋友比，然后就嫌弃自己赚得不够多，这纯粹是给自己找不痛快。

最近我算想明白了几件事：

1.人外有人，天外有天
只要你在往上走，就会认识更多比你优秀的朋友。只要你想比较，这种焦虑就永远摆脱不掉，因为永远有人比你更会赚钱。

2.你只习惯向上看，却忘了向下看
如果真想客观比较，你会发现永远有人比你做得好，也永远有人比你差。可你的眼睛偏偏只盯着那些比你强的人。

3.学会屏蔽噪音
你之所以焦虑，很可能是推特上或者身边听了太多暴富故事。
但那些故事跟你有什么关系？人家赚了也不会分你一毛，人家亏了也不需要你兜底。为了八竿子打不着的人和事而焦虑紧张，就是在浪费时间。
时间都花在内耗上，哪还有精力去做投研和项目？
所以，推特上那些“永赚博主”该取关就取关，无聊没价值的群该退就退。朋友们，时间才是最昂贵的成本。

4.站在自己的角度看问题，莫向外求
上个月和一个前辈聊天，我说到自己很焦虑。他问了我两个问题：
“你现在的资产比去年多吗？”
“你现在的经验、技能、人脉比去年少吗？”
刚听到时我没啥感觉，可后来把数据列出来，心里一震。

我在心里回答了这两个问题：
阿布，你现在的资产已经是去年的很多倍了，而且你原本预期达成这个目标的时间还要更晚，现在提前完成，反而不高兴。说到底，是贪念和攀比心在作祟。其实你已经比过去的自己强太多了。
同时，你从只会撸毛，到能打铭文、符文、打新、套利、冲土狗，在每个板块都能赚到钱。你对信息更加敏锐，也懂得如何把信息变成机会、变成收益。
这些全都是你的收获。
为什么偏偏只盯着别人，看不见自己的优势呢？

我明白，在当下的行情里，大家总觉得自己赚得不够多。可“多”到底是怎么定义的？

讲了这么多，看似和心态建设无关，但其实全在讲心态建设的利弊。把思路写下来以后，我发现自己平静了很多。心态平静，才有可能赚到钱。因为你的决策不是看到别人赚钱就去复制（这种FOMO往往就是进去接盘），而是冷静客观地分析信息后做出的判断。

“钱会从内心急躁的人流向内心平静的人。”

赚钱的目的，是为了让自己过得更好。
希望大家都能找到适合自己的赚钱方式，把生活过好，自洽才是最重要的。

# 11.4.4 新人的心态修炼指南

# 1）心态放平，低成本尝试

这部分是专门写给新手朋友的。

大家每次听到比特币，听到的就是暴富故事，好像身边的人动辄在币圈赚了几百万几千万，几十倍上百倍收益，听得你心痒难耐。但我还是想给大家过热的情绪浇点水。

币圈是7×24小时不停运转的国际市场。你之所以能听到有人短时间赚到大钱，归根到底是因为币圈效率比传统金融高。效率高，赚钱快，但反过来也可能亏得快。

Web3是有前景的赛道，这是事实。可如果认知不够、操作不当，照样有亏损的风险。

刚入场时，建议只拿那些归零也不影响生活的钱去尝试，告诉自己这是探索资金，主要目的是跑流程、感受项目，是以后赚钱的垫脚石。心态放平。

还要一鼓作气，在尽量短的时间段里连续做项目，这样拿到正反馈的概率会高很多。
第一次拿到正反馈后，复盘一下自己的哪些操作导致了盈利或亏损，然后写进复盘体系。这能帮你在Web3里走得更稳。

同时，也要有一点耐心，对自己、对市场都是。每天都有暴富故事不假，但你也得有足够的项目经历和认知，在这个市场摸爬滚打过一阵子，才能弄懂其中的逻辑。这种事不可能一夜起飞，需要时间沉淀。

如果你学习和获取信息的能力比较强，可以自己去搜项目信息，经过判断筛选再参与，基本不会太差。如果觉得自己能力还不足，可以考虑进一些付费社群，多获取信息。

# 2）别执念于100分

带人的时候我有一个很明显的感受：有些人做事，一开始就要求自己做到100分。
但说实话，这大概率是成不了的事。

一个新手刚进一个新领域，想把一个项目做到100分，难度实在太大了。
目标定成100分，哪怕你做到95分，依然开心不起来，因为没达到预期。
可如果你把目标定成60分，只要跑完整个项目闭环，哪怕过程磕磕碰碰，做出来一般般，结果也比那些一开始就想拿100分的人要好。因为预期够低，拿到65分时你会觉得是惊喜。

所以，一开始把目标定在60分就好。在实际执行中慢慢优化，65分、70分、90分，都是靠一步一步走出来的。不要跟别人比，只要相比过去的自己有进步就行。

先做起来，再一点一点加深。
挑软柿子捏，从简单的项目里获取正反馈。
而不是一开始就去追求完美、非要弄懂所有原理。那些只会拖延甚至阻碍你拿到正反馈。
一开始往往是越想越多，执行越差。

# 3）成年人学习，一鼓作气才有结果

成年人的学习，一定要把长期主义和短期冲刺结合起来。

长期主义，是你认定这是一个好赛道，所以愿意投入时间和心思，通过时间积累经验，最终在这个赛道里拿到大结果。这是方向上的指引。没有时间就没有积累，没有积累就不可能做好一件事。

短期冲刺，是你用比较短的时间完成一个任务，然后得到反馈，无论好坏。

为什么要讲这个？因为成年人的时间是碎片化的，真正留给你完整做项目的整块时间并不多。所以你做某个项目时，必须一鼓作气去突破。

回想一下你以往的成功经验，有没有一个共同点：都是短时间内完成了一个既定任务。
比如，公司突然丢给你一个从没接触过的任务，你集中学习几天，交了一个60分的方案。
比如，你考驾照时，科一科四前的一两天集中刷题，最后拿到一个足够通过的成绩。

你做成的事，是不是基本都是靠短期冲刺拿下的，而不是长期平均发力？

所以希望大家明白：成年人的进步，往往需要最开始就一鼓作气。要用短时间目标来指导自己的行动（借用张君老师的话）。

新人想在Web3赚钱，最好的办法就是先找一个难度一般的项目当目标。
首要目标是跑完这个项目的流程，先别管收益，也别管其他事。只要项目跑下来了，你就已经获得了一次正反馈，因为你实实在在做成了一件事。

这也是为什么之前有赚钱的小伙伴让我带他们做项目时，我没有从一开始讲理论，而是在讲完最基础的概念和演示后（比如钱包和交易所怎么注册），就直接丢一个项目给他们。
因为概念性的东西学得越多，越不利于执行。
概念学得再好，也不如你亲手操作过一个项目来得深刻。

当然，跑通项目流程时卡住的地方，需要你自己解决或找专业人士请教。这个阶段还不需要啃项目投研那种太深的东西。先跟在拿到结果的人后面，把他喂的饭给吃下去。多吃几口，再考虑要不要自己做饭。

小结一下：想在一个领域拿到结果，
第一，要找到一个可以通过经验积累、有复利的赛道；
第二，要不断小步快跑，达成短期小目标，用源源不断的正反馈提升自信、增强动力。
这些方法不止在Web3有效，放到任何商业板块都一样。底层逻辑是共通的：人只有拿到正反馈后，才更有动力继续做下去。如果一直苦哈哈赚不到钱，那很可能是做事思路错了。

祝大家在Web3里都能尽快拿到正反馈~

# 11.5 版块五：官方信息，必看的情报来源🔥

# 11.5.1 为什么官方信息值得盯

# 1）第一时间掌握进展和公告

官方Twitter、官网、官方文档、DC、TG，是获取项目最新进展、版本更新、合作伙伴关系以及重要公告的最佳途径。例如新的协议更新、关键战略合作或变更，都可能影响项目方向和价值。

拿unisat的pizza空投和价格涨跌来说，大家买卖pizza，本质上就是看是否看好unisat。当unisat拿到bn融资的信息公布，利好消息一出来，大家自然更倾向于买入，因为预期它会涨。
详细内容见后面的“如何将官方信息转化为有价值的情报”。

# 2）了解项目的愿景和目标

官方信息能帮你更好地理解项目的愿景、使命和长期目标。这些通常写在白皮书或项目网站上，能帮助你判断项目是否符合自己的兴趣和价值观。

不同类型的项目，阿布的要求也不太一样。拿NFT项目来说，他主要看热度、图片质量、Roadmap（路线图）、背景、总量、价格、初始市值，这7个维度如果有好几个满足标准，大概率就会参与。
需要说明的是，不同阶段标准也不一样。行情好的时候，可能垃圾图也能卖出黄金的价格；行情一般的时候，好图的赔率也不一定高，还得看总量、价格等因素综合决策。

# 3）保障安全，避开诈骗

Web3里有很多骗局和假冒信息。通过官方渠道获取信息，至少能确保内容是准确可靠的，避免被欺诈网站或假冒社交账号误导。

阿布之前和一位投资人G聊天，G同时也是一个KOL。有个人在推特上跟他聊得很热络，加🛰️聊了几个月，建立了信任后说合作给项目做推广。后来发过来一份文件，G的大额资产都在电脑上，出于谨慎，他用了家里备用电脑下载，但没打开。看到是.exe结尾，立刻明白是黑客想钓鱼。
所有你在公域（TG/TW/DC）认识的人，都得多个心眼，谨慎一点总没错。
这部分详细内容放在下一章了，跳转链接：版块六：资产安全。

# 4）参与社区，获得支持

官方信息通常还包括社区活动（DC/TG偏多）、开发者会议、AMA（Ask Me Anything，一般是在TW上开space）等。参与这些能帮你更深入理解项目，了解团队动态，和其他社区成员建立联系。

一个优质项目不会是一个人拍板说了算的。决策者会考虑社区建设者和参与者的情况，因此会广泛征求意见。说到底，是为了项目更好地推进。这对参与者也有好处：盘子做大，进场人多，早期参与者能分到的蛋糕就越大。
此外，要重点关注一个项目的潜在购买力来自什么人群，这跟你最终能赚多少直接相关。
从概率上看，Web3里老外的盘子质量更好一些，无论是胜率还是赔率。

# 5）作为投资决策的依据

对投资者来说，官方信息是评估项目潜力和风险的重要依据。开发进度（是否按规划推进）、团队变动（有没有高管离职）、市场策略（token分配比例）等，都可能影响项目价值和发展方向。

这些一般是深度参与项目的玩家或建设者需要重点关注的。我们参与项目，归根到底还是为了赚钱。
如果你在极早期看到一个项目，就可以从阿布上面说的几个平台（TW/TG/DC/官网/官方文档/白皮书）去关注它，看项目有没有按路线图推进，项目方或社区是否在持续建设和做事。
再从中找到自己的生态位，想清楚自己到底要赚什么钱。从这个角度思考，你已经比很多人强了。
