# 一、项目概述

# 💡

# 章节概要：

本章点明了航海的核心目标：

用 21 天时间，从零基础起步，上线你的第一款 iOS APP，并尝试通过付费下载或订阅模式实现变现。

选择 iOS 应用市场的理由很充分：审核高效、用户付费意愿强、无需繁琐备案、成本相对可控。

AI 开发的利好在于：一行代码都不用懂，开发周期被大幅压缩，

开发者得以将注意力集中在理解用户需求与产品设计上。

开发过程中建议采取小步迭代、分模块推进、AI 与人工协同的策略，

AI 只是工具，关键判断仍需人来把关。

# 1.1 项目介绍

# 1.1.1 航海目标

基础目标：约 21 天内，从零基础到成功上线首个 iOS APP。

进阶目标：初步试水付费下载／订阅模式的变现，力争赚到第一笔 APP 收入。

# 1.1.2 为什么选择开发 iOS APP

iOS 应用市场的优势：

审核流程简单且速度快，上架后即可全球分发，对个人开发者十分友好

用户付费意愿较强，iOS 生态成熟，订阅、内购、付费下载多种模式并存

多数 APP 上架无需 ICP 备案、APP 备案，也不必办理软著（安卓应用上架则必须，200-300 元/张，周期 3-4 周）

开发者仅需支付 99 美元（约 688 元）年费，上架应用越多，边际成本越低

存在一定准入门槛：Mac 设备、iPhone 手机、99 美元/年开发者年费

开发过程无需安装复杂的环境与依赖

# 1.1.3 为什么要借助 AI 开发

即便一行代码都不懂，也能用 AI 做出 iOS APP

学习门槛被拉低，精力可以聚焦在用户需求了解、功能设计与产品思路上

开发周期被大幅压缩，最快 2-3 小时就能做出一个 demo 到市场上验证想法

# 1.1.4 总体方法论

小步迭代：先做出最小可用版本（MVP），不追求大而全。

分模块开发：功能变复杂后，拆成多个 Composer/Chat，逐步实现。

AI+人工结合：不要对 AI 言听计从，关键逻辑与 bug 修复仍然需要自己去测试、判断和反思。

# 2.3.2.1 基本使用：Xcode 如何与 AI 编程工具联动开发 APP

第一步：点击 Create New Project 创建新项目，选择默认的应用类型，输入项目名称（拼音/英文），Organization Identifier 输入 com.xxxx.xxxx，这里的域名是反写的，com. 后缀在前。比如我的项目名字是“yuyin3”，我注册的域名是 cuanxue.com，那么这里就可以填写 com.cuanxue.yuyin3，后面再创建新项目时，这里的域名也是后续上架 APP 创建 APP ID 时要填写的信息。

第二步：打开 AI 编程工具，打开项目的根目录。yuyin3 的第一个文件夹是我们刚才在 Xcode 创建的项目，我们要打开的是 yuyin3 项目目录下 yuyin3 的子目录，这是我们的根目录，之后 Cursor 创建的所有代码文件都要写在这个根目录下，打包编译时才会生效。

# 2.3.2.2 基本使用：Xcode 项目文件作用

Xcode 创建项目后，会生成如下目录列表，只有第一个是你的项目根目录

1.

ContentView 文件：项目的主视图文件，可以简单理解为打开 APP 的第一个页面，Xcode 创建项目后，该文件会自动包含“hello world”文字内容。

# 💡

在 Composer 模式下，首次生成代码时要 @ 引用 ContentView 文件

2.

yuyin3APP 文件：应用程序的容器，打包编译到手机时安装的就是它（打包编译时会包含项目的所有资源）

3.

Assets 文件：上传 APP 图标、应用中的图片，支持 Png / jpg 格式（建议将图片压缩后再上传）

4.

yuyin3：应用程序权限配置文件

5.

Preview Content > Preview Assets 文件：预览内容，打包上架时不会包含这里的图片，只在预览/测试时显示
