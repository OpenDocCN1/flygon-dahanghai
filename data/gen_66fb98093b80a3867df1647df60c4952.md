# 先信自己，再谈成事

有一种人，骨子里对自己的本事有底。他敢开口争取，敢担风险，也敢接新挑战；事情到了手里，他有信心办成。对自己的判断，他信得过，也愿意为判断兜底。那种确定感像房子的承重梁，外头压力再大，方向也不容易散，能稳住船头往前破浪。他不喜欢被框住，更不愿别人替他下定义，自主权对他很重要。可这股劲用偏了，也会变成太强调独立、爱独来独往，决定一做就硬，旁人的劝不容易听进去。若把这份自信用对，他会很信自己的直觉，不怕难，慢慢成为能带路的人；路再险，也愿意往前开，还能给别人添信心，主动把担子接过来。

# 16 追求：想站C位，更想做成事

这类人心里有团火，盼着被真正看重，被认可，最好还能出人头地、有名有声。他们像天生要上台的人，巴不得站在灯光下，听到掌声；名声、口碑、别人怎么评价，他们很敏感。找舞台时，总挑那些能显得自己更有贡献、能对他人和社会产生更大影响的事，最怕被晾在一边，不够“牛”的事很难提起劲。也爱跟佩服的人来往，还会不自觉推着身边人一起往上走。这股劲让他们不肯停在平庸里，会朝更热爱、更渴望的方向使劲，直到把想要的拿到手。

走偏时：讲自己的贡献容易漏掉旁人，被看成抢功或太爱表现；太在意别人看法，可能为了赢好评付出很大代价，认同本身没错，但常给自己和关系添堵；要记得与众不同不一定是错，不必逼自己跟所有人一样；人都有局限，硬藏弱点，别人反而不知道怎么帮你，偶尔让人感到被需要，反倒更让人佩服。

用成优势：每个阶段都可能长一大截，因为他们想做大事，对卓越人生有很强渴望；独立性强，总想在关键位置做出突出贡献，而且常常真能做到；演讲、表演、主持这类事上手快；雄心不小，也能点燃合作伙伴。

# 17 取悦：把陌生聊成熟人

重视关系广度，爱交新朋友，和陌生人说话不犯怵；陌生人多的场合愿意开口攀谈、破冰，能让人很快放松，进入轻松聊天。心里常觉得：生活里没有陌生人，只有还没见面的朋友。

盲点：一直认识新朋友，容易冷落老朋友，被误会喜新厌旧、不真诚、不珍惜旧情；关系拉得太快，忽略每个人社交舒适区不同，有人节奏更慢更保守。

优势：与人交往自然，能带动交流，给场合添生气和活力，不容易冷场生分；社交达人有办法拿到别人不容易拿到的资源和机会。

# 3.5.3 ⭕️ 关系建立：把关系建稳

# 18 适应：变化来了，先接住

习惯顺着大流走，顺其自然，环境怎么变自己跟着调。本质灵活，应激能力不差；突发状况或混乱局面里，能冷静又迅速调整，哪怕偏离原来的意愿和计划。有时还盼着生活里来点“意外挑战”，每过一关，应变能力就亮一次。对条理分明、需要规划的任务有时反感，因为觉得限制灵活。

盲点：灵活太强，不做计划也常有好结果，但和重条理的人合作，对方可能吃不消；顺从别人的想法、节奏、需求时，别忘自己也有需求，别让这份灵活被滥用；光顾当下调整，可能忘截止日期，出现超时拖延；对环境依赖高，躺平环境容易躺平，上进环境才上进，在躺平环境里想上进常有心无力。

优势：很多事能提前准备，危机预演做足，挑战来了更适应；随机应变强，别人怕变化时他能接受现实、冷静面对，还帮人看见往前的路；短期要立即行动的任务里，他像润滑剂和补位者；随遇而安，能营造轻松氛围，鼓励别人体验和学习；突然插入不同工作需求打乱节奏，他也能重排序，保持效率。

# 19 关联：看见万事之间的线

信因果，觉得凡事发生都有原因，有因也有果。会被宏大命题吸引：影响全人类甚至全宇宙的观点、哲学、政策、事件，都能让他着迷，也善于从日常琐事里找意义。他认定每个人都是世界的一部分，各自以某种方式跟世界相连，所以人与人休戚相关。内部分裂、剥削、对抗让他排斥，最讨厌成为孤岛。

盲点：太在意“大家是共同体”，可能忽略不同组织之间现实利益冲突，甚至被说天真理想；太关注宏观，当下和短期规划容易漏掉。

优势：能开导、指引别人跳出琐事，看到更崇高的意义、追求和目标；能把过去、现在、未来的“点滴”串起来，在不确定里给人宽慰、舒心和安定，帮人找到积极意义，指出观点和希望；能看更大图景，在个人和团体之间架桥，让人看到彼此怎么关联、怎么依靠，帮他们发现身处世界的意义。

# 20 伯乐：让别人的光被看见

习惯把心力投在别人成长上，关注对方进步和潜能，天然能发现别人正在变好的方向，哪怕进步很小。跟人交往时本能想帮对方成长、更成功，显得有耐心。会找各种办法帮人成功，让对方尝到成功的滋味；只要看到自己能给人带来成长，就很满足，这也是他获得价值感的方式。

盲点：对不适合的人过度投入，目标被忽略，精力也浪费；容易拔苗助长，看到潜能就插手，但人需要自己的节奏，插手可能变成压力；投资别人时忘了自己成长，只有自己能力够，帮人才游刃有余。

优势：容易发现别人的进步和潜能，很利他；能帮群体提升备选队员能力，帮个人和团队看到更好的发展可能；有耐心，会鼓励需要看见自己长处的人，让对方看到更有希望的未来；能给出实际帮助和支持。

# 21 体谅：懂你的情绪，也守自己的边界

对情绪敏感，共情强，总能设身处地体会别人的感受。很多时候天然理解或认同他人立场，但不会拿别人的立场替换自己的。会不自觉寻找情感信息，爱凭直觉做决定，做事前会权衡各方观点和感受。

盲点：看起来可能偏软，因为共情会不自觉吸收情绪，连负面情绪也吸，容易消耗自己；要学课题分离，照顾自己的感受；有时被情绪带着走，过度信任对人的判断，难以客观理性看问题做决策；敏感让他容易察觉别人需求和情绪，但对方未必想要这种关心，或不想外露，一不小心就越界。

优势：带来稳定感和舒适感，有能力建立情感深厚的关系；能给人理解和认同，帮别人表达情感和需求；擅长做情绪疏通。

# 22 和谐：把分歧谈成共识

致力于找共识，善于看见人们的共同点；关注团队是否和平安定。不喜欢冲突，觉得冲突没好处，会尽力避开对抗；真遇到分歧，也会在冲突里找共识，重点谈大家能一致、有合作基础的部分。

盲点：太想避开冲突，可能无原则退让，委屈自己，最后合作也没长久，甚至引出更大冲突；太想要表面和谐，会试图拦住其他人公开表达想法和情绪。

优势：减少冲突和摩擦，增强团队凝聚力与协作；团队争执不下时，能避开有争议的互动，帮大家达成共识。

# 23 包容：一个都不少，也要容得下不同

希望团队里没人被孤立、离群或掉队，一个都不能少。拥抱多样性，愿意让更多人进来，不把人分三六九等，希望团队多元。不喜欢拉帮结派、搞小圈子；会关注弱势和孤立个体，也愿意伸手。

盲点：太想容纳不同类型，团队意见可能过多，分歧难消，冲突频繁；太在意离群孤立的人，想把他们拉进来，却忽略融入未必是对方诉求和习惯；讨厌小圈子时，语言和行为可能带批评攻击，忽略不同人本来就有不同诉求。

优势：带来凝聚力，让成员不担心被冷落孤立，感到被接纳；增加团队多元化，容纳更多想法、视角、观点和行为。

# 24 个别：把不同的人放对位置

天然认为人和人不一样，格外关注差异，讨厌一概而论和简单归类。喜欢找不可替代性；个别越突出，他越对风格、动机、思维方式、交际方式、潜能感兴趣，会花时间研究别人的长处，像选角导演。希望每个人发挥特长，而不是都做同样的事、变成同样的人。

盲点：太盯个体差异，集体需求更重要时容易忽略集体；别人对你的了解往往不如你对他们深，若能主动说出喜好，而不是认定别人天然知道，能少一些失望带来的误会，比如觉得别人不够用心；决定牵涉旁人时，因本能考虑多方利益，决策会慢；容易去找通用准则、流程之外的例外，忽略准则流程本身有效，被看成区别对待。

优势：擅长把不同特质的人放到合适位置，搭互补高效团队；慧眼识人，因材施教，优化人员配置，把潜能用起来；做个性化、定制化服务是一把好手。

# 25 积极：把光带进团队

性格活泼开朗，笑容多，不吝啬赞美，善于给人支持和鼓励，像天生的拉拉队员。总能看到事物积极的一面，乐观，常处于能量满满的状态。团队里的小太阳和开心果，能把氛围带起来，把激情传给团队。习惯赞美别人，因为总能看到优点。

盲点：太乐观，忽略客观风险和阻碍；接受不了别人长期悲伤，有时缺少感同身受，尤其对痛苦，有人需要时间消化，不是立刻就要看到好的一面；赞美如果不是因人而异，可能被误解成为了赞美而赞美、不走心。

优势：感染力强，让周围人觉得生活更美好；热情足、精力旺，别人一筹莫展或不敢向前时，他的乐观能给人继续走的勇气；总能肯定、赞美别人，带来正反馈和动力。

# 26 交往：关系不求多，只求深

善于建立真诚、深度、互惠的关系。比起花团锦簇的社交网络，更在意关系质量而不是数量，所以交往往有选择、有条件。刚认识一个人可能不自在，可一旦认准，似乎天然知道怎么获得对方信任，也甘愿信任对方。乐于花时间维护密友关系；在关系里坦诚、甘愿付出，会主动关心在意之人的情感、经历和目标，也希望对方同样对待自己。

盲点：更愿意花时间和彼此了解、信任的人在一起，可能让别人觉得排外，也可能错过一些优质社交；交往有选择性，不会毫无保留信任别人，可能给人慢热、不好靠近、过分挑剔或被忽视的印象；对亲密的人非常信任、乐于付出，有时过度考虑关系而受伤。

优势：善建立真诚、互惠、密切、持久的关系，并维系信任，比如亲密友谊、共同目标、长期客户关系；让亲密圈里的人觉得被重视、被关爱、值得信赖。

# 3.5.4 ⭕️ 战略思维：想深一层，看远一步

# 27 分析：把复杂拆到简单

关注事情的来龙去脉、底层逻辑、规律和原理；喜欢数据、依据、凭据、证据，一切可量化、可复现、可验证的材料都合胃口；喜欢把事物提炼、拆解成公式、理论模型或框架；相信真理是客观的，而且可衡量，决策凭理智。

盲点：太在意证据，觉得能验证的才对、不能验证的就错，否定模糊性；太重模型公式，忘了它们也在更新迭代；太理性，只看事实和道理，忽略情感情绪。

优势：擅长把复杂问题压缩成几条关键线索，用很小的力撬动很大的局面，快速提炼核心要点和底层逻辑；结构化思维出色，说话写文章逻辑清晰、有条理；批判性思维出色，面对各类事物不轻易动摇，能给出犀利见解和不同角度。

# 28 回顾：从过去找答案

关注事情的起源、背景和发展历程；喜欢可追溯的资料，善于从过去事件里提取经验，爱挖事情起源，相信“太阳底下无新鲜事”；可能喜欢记录和回顾过去，比如记日记、看史书、读人物传记。

盲点：太重视过去经验，忽略现在和过去的差异，对现在和未来缺少应变；太关注过去，容易让人误以为因循守旧、抗拒改变、不愿向前看，对未来新情况不够开放；缺少过去经验时会迷茫无措、少抓手；自己对旧事有兴趣，却忽略别人对旧事重提未必有兴趣。

优势：以史为鉴，善从过往事件找规律，萃取宝贵经验，用来应对未来；不容易被流行信息带跑，总能找到事物源点，洞察发展规律和历程，带来不同视角和灵感；擅长唤醒他人回归初心。

# 29 前瞻：先看见，再带人过去

热衷畅想未来，不断寻找以后会更好的机会，也被未来的美好景象驱动。像有远见的梦想家，看到未来可实现的蓝图、美好和可能性就兴奋，也乐于向别人描绘未来，给人动力和憧憬。很多场景里会格外关注跟美好未来有关的信息、预测、能让你未来更好的人；具体关注什么，和兴趣、优势有关。

盲点：常活在对未来的畅想里，可能忽略当下的美好；不是每个人对未来都有敏锐直觉，若能借恰当词汇、工具、草图，让别人明白为什么你看到的未来值得一起去，会更利于推动；太沉醉美好憧憬，总找最正确的未来，忽略实现未来必须有行动，畅想要在行动里验证。

优势：乐于获取或描述美好未来相关信息，本能看到未来很多细节；更容易帮别人看到未来可能性，帮人跨过当前的不确定；总能预测未来可能发生或应该发生的事。

# 30 理念：把灵感变成新玩法

发散性思维强，喜欢把各种念头变成感性认知，热衷创意和创新。痴迷把概念形象化，找不同理念之间的关联，对能放飞思绪的体验很感兴趣。只要有新想法、灵感冒出来就兴奋，似乎天然擅长跳出思维定势，从多个角度看问题，提出新颖有创造力的想法。

盲点：本能喜欢创新，新想法源源不断，容易被新想法吸引而放下原来的，行动变化大，拿不到结果，被说不切实际；想法多变，团队合作的人可能跟不上；表达偏抽象，不擅长抽象思维的交流者会听不懂。

优势：总有新奇创新想法，不怕创新带来的挑战；善设计创新型项目，比如销售战略、营销计划、客户服务方案、新产品；善从多角度看待问题，词汇丰富，能描述概念、观点、感受、模式等。
