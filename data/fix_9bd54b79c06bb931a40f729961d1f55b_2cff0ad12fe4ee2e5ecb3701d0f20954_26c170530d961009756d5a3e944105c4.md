# 章节概要

品选得再好，视频本身能不能留住用户、促成下单，才是出单的关键。说到底，出单量由流量和转化率共同决定。想提高产出，要么把流量盘子做大，要么把转化率做高，而这两件事的共通解法，就是做出爆款视频。

本节要讲的是如何发掘值得借鉴的爆款视频，推荐大家按以下节奏推进：

✅第一步：锁定适合借鉴的爆款视频

✅第二步：对爆款视频做拆解，边看边学

✅第三步：套用爆款逻辑，搭出自己的视频框架

✅第四步：动手剪辑（二创、原创都可以）

✅第五步：把视频发出去

✅第六步：及时处理评论、私信、招呼消息等各类互动

话不多说，直接开启你的视频创作之旅。

# 3.1 锁定对标账号

# 3.1.1 什么样的账号才值得对标

在视频号和视频带货的语境下，值得对标的账号大致有这几个特征：

专注单一品类经营的达人（这类账号是否存在，决定了我们有没有下载视频的来源；数量多不多，则决定我们能不能筛出最优质的那一批）

某达人的存量视频是否充足（这关系到我们能参考多久。如果总共就 10 条，参考价值确实有限）

达人的点赞数据和销量表现（重点是看他们在抖音上运营得如何）

有一点要留心：走二次剪辑、混剪路线的玩家，尽量不要碰真人露脸的视频，否则很容易被原作者投诉，轻则下架，重则封号。

# 3.2 爆款视频怎么做

# 3.2.1 短视频爆款的底层逻辑

1、热点思维

为什么要追热点？两个原因：平台会倾向给热点流量倾斜，用户也爱看热点内容。实在不知道怎么追，就打开抖音热榜，榜上什么火就做什么。

2、爆点的密度

爆点就是能让视频火起来的元素。一条视频里爆点越密集，火的概率就越高。

3、黄金前三秒

视频开头前三秒是生死线。做短视频，必须在前 3 秒就锁住用户的注意力——如果开头留不住人，用户凭什么把整条看完？过了 3 秒之后，内容得有后劲，让人愿意继续看；到了片尾几秒，要把情绪顶上去，引导用户转发、评论。

第一步：先定目标和方向

动手搭素材库之前，想清楚自己做什么类目、卖什么产品，再去定向找素材源，这样素材库才实用。

第二步：做分类归档

素材按类型、使用场景、风格等维度归档，方便随时调取。文件夹、标签都是好用的分类工具。

第一步：从画面维度去搜，比如你要什么画面、什么背景、什么场合、什么物品、什么行为，按这些角度分别收集；

第二步：把收集到的画面素材切成小段，每段 3-5 秒为宜，同一画面准备多个备选。

第三步：切好的素材放进专用文件夹。前期的整理工作比较费时，但处理完的素材可以反复复用。

第四步：视频找完之后做爆点拆分，大致分成 A（前 3 秒，负责痛点/话题/抛问题）+B（产品介绍/卖点/解决痛点）+C（引导转化），然后测试素材效果，不断迭代。

第三步：优先收高质量素材

图像、视频片段，能高清就高清。素材画质直接决定短视频的观感，观感好才能留住观众。部分产品素材可以从评价区里淘。

素材还可以去 pdd、淘宝多搜多看，扩充素材池。

第四步：持续补新

素材库要定期喂新料。每天刷同行的爆款素材，看到合适的就下载、拆分、入库。

# 3.2.5 基础剪辑与原创内容

视频处理的推荐路径：混剪、二创、原创，不推荐直接搬运。

短期看，精细化的混剪可以规避审核风险；但想长期稳定变现，原创才是正路。

日常剪辑中可以把部分内容——比如产品展示、书籍展示、某些画面或背景——换成自己实拍的素材，这样更易通过原创审核。

比如脚本结构是：

黄金开场+产品介绍+使用展示+同行对比+优惠活动+引导购买

其中“产品展示”这一环，就可以用自己的实拍内容，或用其他平台的好评图、好评视频替换。

# 原创形式 1：口播带货视频制 @孟 meng

[PRE18]

选题拆文案：参考近期爆款

爆款能爆，说明平台算法在给它喂流量，原创要做到爆款级别非常难。所谓“创意都是老元素的新组合”，新手建议先从复制爆款入手。

等素材库和拆解量积累到一定程度，对爆款文案有了感觉之后，再做自己的组合创作。

下载对标视频，用飞书秒记之类的转写工具，把口播文案导出来转成文档

内容拆画面：抓住前五秒

前 3 秒和前 5 秒的完播率是硬指标，短视频必须在前几秒抓住注意力。吸引到用户之后，还要顺手引导点赞、评论、转发、关注。

场景拆卖点：勾起购买欲

把产品放进具体场景里，把功能、特性、价格优势讲透，让用户认可产品，下单冲动自然就上来了。

促单拆话术：推动购买/进直播间/预约直播

视频号里很多用户不会买或不知道怎么买，需要明确引导；但平台监管越来越严，强引导容易触发限流或封禁，建议用软性的互动引导。

比如“你们觉得怎么样？评论区告诉我”，或者在评论区置顶，把用户引到主页橱窗下单。

还有一个好用的玩法：视频起量时开播，并在视频上挂直播预约组件——这个功能引流效果极佳，号主开播时，🛰️会给用户强提醒“你关注的主播开播了”，预约进来的比例非常高。
