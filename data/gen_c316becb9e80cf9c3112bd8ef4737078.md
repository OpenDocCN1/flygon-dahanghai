# 8.4 👸号里，怎样把IP价值攒下来？

想把👸号做出商业化、把IP价值沉淀下来，就不能只发同质化内容，而要持续输出能体现“你这个人”价值的文章。下面六类内容，尤其适合已经有产品的人。

# 8.4.1 写一篇个人品牌故事
每个IP或企业，都该有一篇自己的品牌故事。它要能具体讲清你是谁，比如逆袭经历、打拼过程。我在自己的👸号做过“一个普通女孩的十年”系列，还被推荐过，阅读量接近十万。这类内容能让读者看见我从0到1的付出，容易产生共情，当时的转粉率、加🛰️转化率都不错。个人品牌故事本身就有很强的爆点。

# 8.4.2 做一份产品介绍合集
产品介绍文，本质是把你的产品做成合集。你有哪些产品、分别是什么，集中介绍清楚，读者看完就能自己筛选，不必来一个人就重复讲一遍。把它沉淀成👸号里一篇可收藏的文章就行。

# 8.4.3 定期写复盘文
复盘文要定期写。可以每月复盘一次：这个月做了什么、有什么收获。别人能从你的复盘或计划里看到你的自律，也更了解你的业务和生活，同时还能从你的复盘里得到收获，所以这类内容有价值。

# 8.4.4 记录个人感悟与观点
这就是常见的感悟文。对某个事件怎么看、有什么感受，都可以写出来，表达你的观点。

# 8.4.5 沉淀所在领域的干货
干货沉淀文是IP必须有的。比如我会在👸号沉淀关于👸号的思考：怎么排版、👸号有哪些变现模式等。干货更能让人知道你在做什么、是否专业，也是很多付费用户用来“验货”的文章。

# 8.4.6 展示学员案例与评价
这一类可以自选，有更好。学员案例和学员评价，能从侧面反映一个IP的品质，比自卖自夸强很多。

这六类文章都能沉淀IP价值，其中个人品牌故事、产品介绍和干货类文章尤其重要，能帮客户更了解你。

# 9.1 哪些情况适合用公户收款
公户收款主要是为了减少税务支出。👸号个人收款扣税相对很重：月收入超过500元就开始扣税，月收益1万元时扣税约1600元（后文有详细计算），而且收益越高扣得越多，最高可扣40%。

[PRE4]

虽然这部分税在每年清算个人所得税时可能返还一部分，但和使用公户收款相比，仍是一大笔钱。若用公户收款，只要年流水不超过120万元，采用核定征收方式，基本只需交很少的税（1%），因为国家对小规模纳税人有不少税收优惠。

个体户可以是小规模纳税人，也可以是一般纳税人。如果符合小规模纳税人标准，按规定：小规模纳税人发生增值税应税销售行为，合计月销售额未超过10万元（以1个季度为1个纳税期的，季度销售额未超过30万元，下同），即一年120万元以内，免征增值税。根据《财政部税务总局关于对增值税小规模纳税人免征增值税的公告》规定，该政策适用主体为增值税小规模纳税人，因此不区分企业或个体工商户。2023年开始，增值税小规模纳税人月度10万元以下或季度30万元以下免征增值税；假使超出，也只按1%征收率计税。（注：2023年小规模免税政策调整为月度未超10万元或季度不超30万元，3%征收率减按1%征收率。）2023年1月1日至2027年12月31日，对个体工商户年应纳税所得额不超过200万元的部分，减半征收个人所得税。个体工商户在享受现行其他个人所得税优惠政策的基础上，可叠加享受本条优惠。

# 9.2 扣税规则怎么算

# 9.2.1 个人账户缴税
1、个税说明
个人账号无需邮寄发票。个人账户收入属于个人劳动报酬。根据《中华人民共和国税收征收管理法》及其实施细则等税收有关规定，腾讯公司从2019年11月1日起接受税务机关委托，为个人流量主代征增值税和附加税。

2、增值税及附加税费计算方法
每次劳务收入超过500元（包含本数），腾讯代征3%的增值税，并按增值税应纳税额代征附加税费，适用综合税率6%（即按一般综合税率12%，实行减半征收）。如因税法或税局征管要求调整，需要更改上述规则，腾讯会另行通知。
增值税应纳税额 = 劳务报酬（大于等于500元）/（1+3%）×3%
附加税费应纳税额 = 增值税应纳税额×6%

3、个人所得税计算方法
1）应纳税所得额的计算
劳务报酬所得以个人当月取得的同一项目下的多次收入合并为每次收入所得，定额或定率减除规定费用后的余额为应纳税所得额。每次收入不超过4000元的，定额减除费用800元；每次收入在4000元以上的，定率减除20%的费用。
应纳税所得额 = 劳务报酬（少于4000元）-800元
应纳税所得额 = 劳务报酬（超过4000元）×（1-20%）
2）应纳税额的计算
应纳税额 = 应纳税所得额×适用税率-速算扣除数
劳务报酬所得适用超额累进税率，累进税率分别为20%、30%和40%：纳税人每次劳务报酬所得的应纳税所得额不超过20000元的部分，适用20%税率；超过20000元至50000元的部分，适用30%税率；超过50000元的部分，适用40%税率。具体可参考税率表。

[PRE11]

案例一：A流量主当月收入400元。该收入少于500元，腾讯不代征增值税和附加税费；收入扣减800元后，个税应纳税所得额为0，腾讯不代扣代缴个税。

案例二：A流量主当月收入800元。增值税应纳税额=800/（1+3%）×3%=23.3元；附加税费应纳税额=23.3×6%=1.4元；扣除增值税、附加税费以及800元后，个税应纳税所得额为0，腾讯不代扣代缴个税。因此，腾讯代征增值税23.3元、附加税费1.4元，不代扣代缴个税。

案例三：B流量主当月收入3090元。增值税应纳税额=3090/（1+3%）×3%=90元；附加税费应纳税额=90×6%=5.4元；个税应纳税所得额=3090-90-5.4-800=2194.6元；个税应纳税额=2194.6×20%=438.92元。因此，腾讯代征增值税90元、附加税费5.4元，代扣代缴个税438.92元。

案例四：C流量主当月收入10300元。增值税应纳税额=10300/（1+3%）×3%=300元；附加税费应纳税额=300×6%=18元；个税应纳税所得额=（10300-300-18）×（1-20%）=7985.6元；个税应纳税额=7985.6×20%=1597.12元。因此，腾讯代征增值税300元、附加税费18元，代扣代缴个税1597.12元。

案例五：D流量主当月收入82400元。增值税应纳税额=82400/（1+3%）×3%=2400元；附加税费应纳税额=2400×6%=144元；个税应纳税所得额=（82400-2400-144）×（1-20%）=63884.8元；个税应纳税额=63884.8×40%-7000=18553.92元。因此，腾讯代征增值税2400元、附加税费144元，代扣代缴个税18553.92元。这种情况下，因为腾讯是代扣，你需要自行履行年底个人所得税综合申报义务，并自行承担个税税款的多退少补。
