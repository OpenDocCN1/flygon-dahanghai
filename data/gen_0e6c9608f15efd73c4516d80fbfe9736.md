# 💡 变现路径图

账号慢慢做起来之后，就可以着手布局多条收入渠道了。广告接单、平台流量分成、知识付费、带货、提供专业服务——这些都是AI自媒体人最常走的变现路子。但有个大前提：你得先攒下扎实的内容储备和稳定的粉丝群体，才能获得认可，把收入真正做稳。

常见的变现方式包括：

广告合作：借助星图、蒲公英这类平台承接商单，或者直接与品牌私下对接，来钱比较快。

流量分成：加入平台的创作者激励计划，播放量越高，收益越可观。

知识付费与专业服务：办训练营、卖付费课程，或者给粉丝做定制化的AI方案，靠专业能力和社群信任变现。

建议大家先把这些模式过一遍，心里有数，为之后的变现铺路。

# 5.1 广告合作：最主流的变现入口 @Anny

在各类变现渠道里，广告合作通常是创作者最先尝试的那一个。知识付费要求深厚的专业沉淀，直播带货需要供应链做后盾，相比之下，广告合作门槛更低，上手也更快。

但在真正开始接广告之前，得先把各平台的规则摸清楚。平台就是我们的地盘，按规矩来，路才走得长。

① 抖音的广告玩法

抖音的商业化体系已经非常完善，创作者和品牌的合作基本都通过星图平台来对接。粉丝数突破1万之后，你就能申请开通星图权限。

星图平台链接：https://www.xingtu.cn/

星图上的合作模式大致分两类。第一类是一口价，也是最常见的：品牌报一个固定金额，比如一条视频1000元，你把内容做好发出去，数据好坏都不影响这笔收入。新手特别适合这种模式，不用背业绩包袱。我接的第一条星图广告就是一口价，金额也是1000元，但那种被认可的感觉到现在都记得。

第二类是效果付费：一般会先给一笔保底费用，再根据下载量、注册量等实际数据追加报酬。去年我跟一个AI工具合作，没有保底，但视频跑爆了，光下载分成就有两万多，比普通一口价高出一大截。当然，这种模式也有风险，数据不行的话收入会很少。有些大品牌的星广广告会设置保底收入，相对更稳。

官方渠道之外，不少品牌还会走“水下交易”，也就是私下对接。这种方式确实灵活，品牌方也能省掉平台服务费，但风险全落在你身上。水下交易的结算花样很多，有的按点赞数算钱，一个赞0.2元或0.5元，视频发布一周后按实际点赞结算。听起来公平，可数据一旦不好，收入可能还不如一口价。

我自己就在水下交易上栽过跟头。说好发布后一周结款，结果硬生生拖了四个月。对方还是知名品牌，换成小品牌，钱可能直接打水漂。所以现在我除非是长期合作的老客户，否则一律走官方平台。

# 5.2.2 星图接单怎么做？【新增】@Anny

# 5.2.2.1 第一条星图广告怎么接？

先开通星图权限。满足条件后（比如粉丝数、视频数量等），到「创作者服务中心」找到星图入口申请开通。开通后记得设置报价，并留下🛰️或邮箱，方便广告主找到你。抖音的报价可以参考粉丝量的10%到20%。

✅ 星图开通门槛：目前要求【粉丝数≥1万】，但平台偶尔会放宽，建议多留意后台通知。

报价建议：第一次可以比市场价稍低一些，关键是把案例攒起来。但别压得太狠，否则后面想涨价会很被动。

广告主联系你：对方一般会通过🛰️或邮箱找你，加好友后自我介绍，说明自己是广告代理还是品牌方，并附上星图下单链接、任务需求文档等。

# 第一步：确认合作（接单）

1. 核实对方身份：确认是否走星图下单、是不是正规合作。非星图的线下单要格外小心，尤其是涉及预付费、诱导挂链接的情况。

2. 把需求看仔细：对方会发一份文档（brief）或者口头说明。下面这几项务必确认清楚：

• 品牌主是谁
• 有没有竞品冲突
• 是否需要口播
• 拍摄时长、发布时间和参考内容
• 封面、话题、标签是否有指定要求
• 敏感画面能否用马赛克代替删减

# 第二步：写脚本、找对标

1. 找对标参考：对方给的brief里经常附有参考视频，也可以自己找风格相近的爆款。多数广告视频本质上就是“模仿加改造”。

2. 脚本先过审：别头脑一热直接开拍，先把脚本写好发给对方确认，免得白忙一场。

# 第三步：拍摄 → 送审 → 调整

1. 拍摄完成后发给媒介审核：对方看后会提出修改意见，大多是封面、节奏、字幕或打码之类的小细节。

2. 修改别嫌麻烦：这是合作流程的正常环节。只要脚本过了，视频大方向一般不会让你重拍。

[PRE3]

# 第四步：在星图提交任务

1. 通过合作码扫码提交：审核通过后，媒介会发来合作码或邀请链接，扫码进入任务，填好价格、上传视频即可。

注意❗有的合作先下单再创作，有的则要视频先过审再下单，取决于对方的操作习惯。比如我常合作的品牌媒介，确定每周有任务后，任务码还没下来，我们就提前把视频备好了。

第一次合作的话，建议先接受任务码并提交报价，等对方下单后再开始创作，这样更稳妥。

1. 上传时的注意事项：

• 视频内容需与脚本保持一致
• 封面图别随便选，以免违规
• 发布后不要擅自删除视频

# 第五步：定时发布与成果确认

1. 广告主安排发布时间：你上传之后，对方会再审核一遍，和你敲定发布时间后定时发布。

[PRE4]

# 第六步：结算收益

1. 到账时间：通常在发布后3个工作日左右，T+3时抖音会自动结算。

2. 星图会收取服务费：目前约为任务金额的5%（平台手续费）。

其他补充事项：

有一点必须重点提醒：尽量别走水下交易！哪怕对方是你耳熟能详的大品牌，哪怕媒介把“结款快”说得天花乱坠，也建议一律走星图或星广。平台虽然收一点服务费，但至少安全有保障。

我自己就碰到过一次：合作方是个人尽皆知的品牌，说水下结款一周到账。结果呢？一周拖成一个月，再拖到两个多月，最后足足四个月才把钱结清，还是撕破脸才拿到的。

总之，私下交易一定要慎重。

这时笔记还没有正式公开，其他用户看不到。提交后会进入平台和品牌的审核确认流程。

如果审核没通过，消息通知和蒲公英后台都会收到提醒，按要求修改即可。审核没过可以联系商家重新提供素材，然后重复「第二步：制作笔记」的流程。

# 第四步：发布笔记并等待订单完成

审核通过后就能发布笔记了。在和品牌方约定的时间，点击APP「消息通知」里的“前往发布笔记”，或者点笔记详情页左上角的「合作品牌已确认」，就能正式发布。

# 第五步：收益到账与提现

品牌确认订单完成后，合作款项就会到账。如果品牌方没有主动确认，7天后系统会自动确认，收益照常到账。

如果对接的是商家，直接结算订单收益；如果对接的是PR，对方可能会要抽佣。一般加🛰️后，PR会聊广告内容和返点比例，抽成通常在20到40元之间。能接受就合作，接受不了就拒绝。

当然不是所有PR都抽佣，只有想额外赚一笔的才会。等笔记发布完、收益到账，按谈好的分成私下转给PR即可。

提现方面：订单确认后，7天后可在📕钱包统一提现，提现会扣10%的税。

2. 大品牌
a. 母婴类如帮宝适、飞鹤
b. 美妆护肤类如欧莱雅、兰蔻
c. 家居类如美的、戴森、3M

# 5.2.5 不建议接的广告

接一条一万元的广告，比接十条一千元的划算得多。下面这些我都是直接pass的：

图文直发（伤账号，还容易违规）；

# 5.2.6 合作注意事项 @虾饼

合作形式分报备笔记和非报备笔记两种。报备笔记就是前面说的官方认可的品牌合作，平台会收取“保护费”；非报备则是私下合作，悄悄打暗广。

非报备又分单品和合集：单品指一篇笔记里只含这一个产品的广告；合集指多个产品同时付费，出现在同一篇笔记里。

单品里还有个“伪合集”的概念：笔记里看似出现了多个产品，真正付费的只有一家，这样能最大程度避免被判定为私自推广。

和PR沟通时，下面几个问题要聊清楚：

档期：包括初稿、终稿和最终发布的日期。

授权转发：是否授权品牌方在电商或内容平台发布，是否免费，授权周期多长。尾部博主一般给免费授权，周期在三个月到半年。

授权投流：是否授权品牌方在📕投流，是否免费，周期多长。投流虽然能帮博主涨数据，但万一品牌爆出丑闻，笔记还被拿去投流，会影响账号形象。所以最好约定一个周期，比如一年内免费授权投流，一年后再看是否继续、是否加钱。

笔记发布后的保留周期：通常是一年或永久。

排竞：笔记发布前后几天内，不能发该品牌竞品的相关笔记。

活动出席：美妆和穿搭类品牌可能会邀请达人参加产品发布会等活动。
