# 图书直播起号实操：福利品开路，成交校准，避坑进阶

做图书直播，起号阶段最怕“场观热闹、成交冷清”。下面这套打法，核心就是用低价福利品把人群标签慢慢拉正，再用成交数据判断账号是否真正起势。

到了第二场，流程不用另起炉灶，仍沿用首日的讲书节奏。开场先把四款1.9元福利品轮番过一遍；这四款讲完，再承接9.9元、19.9元、29.9元档位的书，之后逐步过渡到39.9元乃至更高价位的书。第二场的关键目的，是让进入直播间的人群越来越精准。否则场观即便冲到一万，成交只有几百，意义也不大。有些直播间场观大几万，成交也就几千，问题同样出在人群标签上。所以要把进店人群的标签一点点打正。

第三天照搬第二天的动作即可。通常连续三到五场以上，只要直播间的人、货、场都及格达标，账号基本都能起来。

怎样才算起号成功？判断标准看千次成交。平台推1000人进直播间，成交至少要卖到1000元，最低也不能低于500元。达到这个水平，流量才算精准，账号才算稳定；达不到，就仍处在起号期，流量也还不精准。这类直播间不要急着停掉低价亏品，继续卖低价福利品就行，因为亏不了多少。一般一场亏300元福利品，佣金也能有三四百，基本能保本，很少真亏。

福利品做多少，直接影响直播间场观大小。所以福利品可以多做一些，后期没卖完也能退。这就是目前常用的起号方法：用低价福利品把账号带起来。

起号之后，图书讲解也要高低价循环。在线人数低了，就换低价品讲；在线人数高了，就适当讲一些偏高价的图书。主播要慢慢学会及时调整。一场直播下来，基本固定在十套左右高价书，再配四五种低价书讲解即可。有成交、销量好的书，就多讲几次。讲解话术我们有文档，会发到群里。观众想要的书如果橱窗没有，可以立刻去选品中心添加，再放进直播间小黄车。

图书类目上限有限，所以目前在视频号内卷不算严重。正常起号成功后，5000到1万的场观刚刚好，这个场观一场也能卖个大几千，已经算很不错。再追求更大的场观，流量只会变泛，调整回来反而麻烦。所以前期不建议用亏品福利去做太大的场观，在线太高也承接不住。

还有一种情况：三四场直播下来，账号还是没起来，成交不理想。也就是播了好几场，场观还可以、流量也有，但直播间千次成交很低。这时候就需要做微付费给直播间助力：用🛰️豆直投直播间，投直播间成交，投6小时的，选择两笔计划，一个出价写70，一个写100，建两笔200元、2000豆的计划。选择范围就是下面图片中的内容。

# 5.3 直播违规注意事项

熟悉直播全流程后，还要注意规避直播违规。视频号管理非常严格，一旦违规，对账号的打击往往不可逆。虽然明面上说是3天或者7天限流，但账号大概率过了处罚期流量也会减少，只能换绑或者注销重来。因此，如果不是熟练团队，不推荐无人和半无人直播，非常容易违规。

目前直播违规主要分两类：一类是小店产品售后违规，包括商品标题、图片等；另一类是直播间违规，包括主播话术、直播间场景等。

# 情况一：产品售后违规

1）违背承诺【延迟、无法发货】：视频号橱窗商家未按平台规定或约定向用户发货，或未提供承诺的服务。处理结果一般是禁止使用橱窗3天，并下架对应商品。

应对策略：如果确实因为各种原因未能及时发货，要及时向平台报备，或与客户沟通取消订单。报备可以直接在小店后台进行（如下图），也可以给平台官方发送报备邮件（weixinlive-JF@tencent.com）。只要有报备、理由正当，后续如有误判，找官方小二沟通，大概率还是能撤销处罚、恢复开播。

[PRE21]

注意，报备最多可报备15天，超过报备期限就必须重新报备，否则会按照违背承诺处罚。

具体细则，详见：《视频号橱窗商家【违背承诺】实施细则》《关于延迟、无法发货报备的指引公告》。

[PRE22]

2）推广超范围商品：视频号橱窗达人通过视频号橱窗推广明确不得在平台出售的商品类型，即售卖平台禁售商品，或商家无对应资质开通类目的商品，包括超低价商品等。

例如，售卖皮色料（属于珠宝玉石禁售）/无资质赠送手表（商家无资质售卖的商品）/售卖莫桑钻商品（平台明确限制出售的商品）/售卖平台禁售商品低价珍珠饰品（推广平台明确限制出售的商品）。

应对策略：了解平台开放、不开放、定向准入的产品，且了解部分定向准入产品的销售底价。一般情况下，直播间只能售卖绑定小店开通类目的商品；其它类目商品想在直播间售卖，或以赠品方式送出去，都需要先查相关规则文档，确认不在平台禁售范围内。

具体细则，详见：《相关商品橱窗类目准入规则》《视频号橱窗类目、商品资质总览》。

[PRE23]

3）发布违禁信息：发布的信息或商品违反《中华人民共和国广告法》等相关法律法规。

主要有两方面：第一方面是食药同源或者滋补品，容易在直播中被判处夸大功效；第二方面是主播或直播团队被全网拉黑，或属于违规违法团体。

例如，口播吃亚麻籽油可以疏通血管、养护大脑，存在虚夸普通食品功效而被处罚；拍A发B售卖“幸福小丸子”（壮阳物品）而被处罚；主播话术“男人加油站；懂得懂，一个小时打底”因而被处罚；主播口播售卖的古玺堂精油炙疗腿疼、颈椎膝盖难受等症状，为夸大护肤品医疗功效而被处罚。

以上这些情形的处理结果是禁播15天。

应对策略：主播话术要规避极限词、虚假文案和欺骗言语，同时需要熟悉平台规定的违规场景。

具体细则，详见：《视频号橱窗达人【发布违禁信息】实施细则》。

4）发布虚假宣传信息：视频号橱窗达人违规使用极限词、虚假限时文案，欺骗、误导视频号橱窗用户的情形。

判罚逻辑大概有以下几类：货不对板；质量问题；用户投诉；纠纷单量大；物流问题。

例如，因该账号的商品品质与宣传描述不符（少件），给消费者带来不良体验，举报与投诉数据较多；因该账号的商品品质与宣传描述不符，且带有物流异常问题，给消费者带来不良体验，举报与投诉数据较多；主播口播宣传该商品具有祛斑作用，但所提供相关特殊化妆品证明中的名称与商品名称不一致，故无法判定该证明上的名称为此商品。

应对策略：虚假宣传是非常容易出现的判罚，核心是直播间货品与实际货品质量不一致，导致用户投诉或引起纠纷，会被判处虚假宣传。且承诺物流发货快或几日内送达，如果达不到，遭到举报，也会被判处虚假宣传。

所以要注重产品品质，直播样品与正品保持一致；主播要注意话术，不可为了逼单在直播间给出过多承诺；最后一定要做好售后服务，客服要及时响应客户咨询和处理售后。

具体细则，详见：《视频号橱窗描述不符/虚假宣传纠纷处理判责标准》《视频号橱窗交易纠纷处理规则》。

[PRE24]

5）发布不合规信息：主要是商品重要信息缺失跟类目乱挂。

例如，商品名称没有重量，或玉石材质、镶嵌类商品无品牌无重量；商品标题缺少品牌信息；翡翠手绳类目错挂在翡翠手镯和翡翠吊坠上；正红菇干货类应挂在食品饮料>粮油调味>南北干货>类目，而商家最终错挂在生鲜-蔬菜-根茎类上，等等。

应对策略：不合规信息针对的大部分是定向准入商品或较为特殊的商品（需要有产地、品牌、重量等），部分关键信息缺失，会被判处发布不合规信息。

具体细则，详见：《视频号橱窗达人【发布不合规信息】实施细则》。

# 情况二：直播间违规

1）不正当营销：视频号橱窗达人通过虚假承诺福利、虚假抽奖、虚假赠品等方式吸引人气，吸引视频号橱窗用户关注但最终未兑现。

例如：

①直播宣传：涉及全场1折、1折清仓、全场X元/折起、免费送XX、xx品牌商品个位数、全场清仓、全清、清完走人、专柜x折、特殊材质商品个位数、扣xx免费送、新人免费送……

②直播间物料/举牌：直播间人员或背景出现1折、X元、免费送等字样（包含但不限于字纸印刷物、电子显示屏、灯牌、第三方推流贴图等）。

③低价商品高运费：售卖商品明显低于市场价、成本价，同时收取高额运费的引流方式。

④打击场景：直播间口述、视频号昵称、简介、直播主题、公屏互动等。例如，工厂直销一折优惠；标题宣传全场9.9，涉及低价引流；直播间直接展示产品免费试用；直播间新人，每人送2份见面礼字样；直播中使用低价商品进行引流（1元），实际商品价格高于宣传价格。

应对策略：不正当营销是目前平台处罚最多的判罚规则，主要是所有涉及低价、赠送或福利品都会被判处为不正当营销。目前的视频号规则不允许通过低价进行引流，而且价格不能低于9.9，折扣也不能过低；在官方看来，这属于恶意竞争、打价格战。所以抖快的直播习惯和套路并不完全适用于视频号。

具体细则，详见：《视频号橱窗达人【不正当营销】实施细则》。
