2.AI 测评：用一次真实任务回答关键问题

做测评，重点不在罗列功能，也不在丢一句“好用”或“不好用”，而是帮读者判断：它能否承接我在意的任务？实际使用手感如何？产出是否达标？更适合哪类人和哪类场景？

**来看一个实际例子：**《笑死｜剪辑师借 Codex 帮我剪片，体验有多爽》

[PRE5]

**这次测的是什么任务？**

作者并未停留在功能清单，而是用自己的素材跑了一遍。任务是把珠峰东坡徒步拍下的两段影像，剪成 6 分钟内的人文纪录片，可加字幕、特效和复古胶片颗粒。素材一：藏族同胞打酥油茶的过程；素材二：在约 4300 米海拔采访藏族小孩的画面。

[PRE6]

**过程是怎么展示的？**

视频把 AI 从读取到交付的链路摊开：载入两段原始片子、补齐所需插件、做语音转写、梳理叙事主线、删掉采访里的停顿、上字幕与胶片颗粒，还按作者追加要求把一段竖屏画面方向调正。初剪耗时约一个半小时。可见作者不是看产品演示，而是让工具进入真实工作流跑完全程。

[PRE7]

**最终结果怎么样？**

AI 交出了初剪，主线有压缩、停顿有处理、字幕画面也做了，但成色不算完美。评论指出：转场生硬、镜头有重复、选镜尚欠火候、能做粗剪但缺少成熟剪辑师的“网感”、更适配访谈和纪录片，快节奏爆款短视频未必合适。

**为什么这算 AI 测评？**

因为它呈现了完整链路：真实任务 → 原始素材 → 执行 → 修改 → 结果 → 优劣。读者收获的不止“AI 能剪片”，还会知道它能接手哪些环节、耗时多少、产物能否直接用、哪些仍需人工、自己有没有相应素材和编导能力。这才是测评的价值。

**这篇内容有什么不足？**

此次只证明在特定任务、特定素材、特定要求下得到该结果，不能推出 AI 可稳定包办所有剪辑。换素材、换类型，作者提示词与编导水平，插件、模型版本变化，都会影响表现。写测评应交代测试条件，别把单次结果说成普适定论。

**什么人适合做这种测评？**

手头有真实待办任务；愿意留存输入、过程、修改和结果；能判断产出好坏；不回避问题；分得清单次测试与普遍结论。

这篇把 Codex、WorkBuddy、Claude Code、ZCode、Trae 与 OpenClaw 并列，围绕“第一次用 Agent 的新手该选哪款”展开。判断维度包括上手难度、能力边界、限制条件、国内可用性、办公软件与插件生态、适合新手还是进阶。属于多工具综合选型：不追求人人适用的第一名，而是帮不同条件的人匹配工具。但要说明作者是否用同一任务测过所有工具；若没有，就不能写成严格同任务对比实验。

3.AI 教程：让用户从看懂到做出来

教程重点不是录下操作，而是带用户完成一件具体事：开始前备什么；第一步从哪起；每步做什么；完成后得到什么；失败怎么办。

**来看一个具体例子：**《Codex 新版保姆级教程（GPT-5.6 升级后）》

[PRE17]

**这篇教程要带用户完成什么？**

这是一支约 14 分钟的 Codex 新手教程。作者从下载安装起，依次演示新版界面、项目模式、额度、对话栏与预览框、初始化设置、文件夹整理、Computer Use、可视化看板，以及 Skill 和 CLI 等案例。读者不仅知道功能，还能跟着从安装、设置走到首次使用。

[PRE18]

**它串起了哪些关键步骤？**

教程按实际操作顺序展开：下载安装 → 认识界面 → 初始化 → 建项目 → 输入任务 → 看结果。基础操作之后，作者又展示文件夹整理、Computer Use、可视化看板、Skill 等例子。这样读者既能看到工具怎么设置，也能看到工具最终能帮自己做什么。

[PRE19]

[PRE20]

**为什么说它是 AI 教程？**

因为它不只解释 Codex 是什么，而是带用户走完一套可跟做的流程。科普解决“听懂了吗”，教程还要解决“我能否照做”。内容有操作入口、关键步骤和真实结果，已具备教程结构：明确目标 → 准备条件 → 分步操作 → 展示结果。

**评论区暴露了哪些问题？**

评论区有不少具体疑问：国内怎么下载；下载后界面为何不同；自己的版本为何没有聊天功能；界面为何是英文；手机能否装；额度够不够；账号登录还是 API 登录。这说明作者跑通不代表用户环境一致。更完整的教程应说明适用系统版本、前置准备、账号付费要求、版本界面差异、常见失败，以及更新后哪些步骤变了。

[PRE21]

[PRE22]

**这类教程有什么风险？**

AI 工具迭代快，发布时正确的入口、界面、功能位置可能过时。旧教程会导致下错版本、找不到按钮、登录方式变化、功能移动或下线、提示词结果不同。制作时应标注测试时间、版本和使用环境；大更新后及时补充说明。

**什么人适合做这类教程？**

自己完整跑通过；关键步骤可复现；知道前置准备；能识别新手卡点；愿补充失败与解决办法；更新后愿复查。

这篇面向零基础用户，从安装开始认识 Codex，再用案例理解用法。属于完整工具入门教程：从第一次接触起，带安装、设置、基础操作和首个任务。覆盖全但成本高，作者要跑通并预判新手卡点。评论区出现“安装后为何变成 ChatGPT”“是否还要单独装 Codex”，说明产品更新后旧步骤已变。提醒：教程不是永久有效，大更新后要补充修改或下架失效步骤。
