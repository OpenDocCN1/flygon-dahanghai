平台推流有章法。先弄懂规则再动手，方向清楚、判断有据，账号才能一步步往上走。视频号直播带货，人气要看，成交也要看，公私域流量同样不能忽略。短视频平台上，这些指标能帮账号放大影响力、聚拢人气、提高直播质量，让产品推广和带货更顺。平台政策和算法会变，及时掌握最新规则与趋势，别拿老办法套新环境。

# 5.1.1.1 人气权重：先把人留住

1、曝光进入率
说的是观众从平台曝光入口点进直播间的比例，算法为进入直播间人数÷平台曝光看到人数。直播间被曝光时，用户主要会看到标题、封面和画面；在视频号信息流上下滑，决定点不点的是标题+画面+主播当下话术；在直播广场上下刷，决定点不点的是封面+画面。这些元素都会影响点击进入。后台看数据时，重点盯内容力板块的直播有效进房率；这个数越高，说明有效曝光进房表现越好，也更容易获得推流。

[PRE0]

2、有效观看时长占比 30S/60S/180S
观众在直播间看了多久，平台会分档统计：30秒以内占多少、60秒占多少、180秒占多少，再结合推流规则评估内容与直播能力，给出对应的权重层级。用户停留越久，有效观看占比越高，被推流的概率和规模就越大。

3、互动率、关注率
互动指观众和主播通过问答、评论、送礼、连麦等方式交流；评论、点赞、转发、分享、礼物都算互动。关注率/转粉率体现人气上升和粉丝增长；用户关注后能收到开播提醒，说明粘性更深。互动率、关注率越高，代表主播和内容更受欢迎、用户粘性更强，转化成交也更容易。

4、礼物热度
视频号直播时，左上角显示场观，右上角显示“热度”；热度是互动数据，能反映直播间当下的互动水平，礼物数据在热度值中权重较高。引导用户送粉丝灯牌、加入粉丝团，是拉热度的典型动作。愿意进粉丝团的基本是铁粉，可长期维护转化做裂变，让他们分享到朋友圈、社群等渠道，帮直播间拉流。

# 5.1.1.2 成交权重：用下单拉动推流

1、成交密度：单位时间成交量
视频号直播间的公域推流机制，看的是成交密度+互动密度，两者能拉升自然流量推荐；其中成交密度权重高于互动密度，所以做公域流量的关键，是把成交密度做起来。成交密度对自然推流帮助尤其明显，可按在线人数的10%来估算成交单量：100人在线，就争取成交10单。下单金额是1块还是100块都无妨，关键争取5分钟成交一波，连续三波5分钟成交密度叠加，有机会刺激平台推流。

2、商品点击成交率
商品点击成交率=成功下单量÷商品链接点击人数。数值越高，说明商品越受欢迎，对推动平台曝光流量也很重要。不同产品属性要有不同标准：福利品点击成交率70%以上；承接品40%以上；利润品20%以上；这样整体商品点击成交率能保持在30%左右。商品数据达不到，就要优化主播话术、商品链接、选品和排品；后文会继续讲。

# 5.1.1.3 公私域联动（重点关注）：私域带路，公域加推

视频号和抖音最大的不同，是视频号能做私域，还能用私域流量撬动公域流量；+MM188166M（李李）长期更新。平台对把私域用户带进直播间的行为，会匹配一定公域流量作为奖励。具体来说，每把一个私域用户通过私域拉进自己的视频号直播间，平台就会按一定额度把直播间推荐给公域新用户，引导公域流量进来。如果只是无效拉人头，比如拉来的人不是直播间受众、进来不买、秒退，撬动公域的效果会很差；如果私域用户来了愿意停留、互动、下单，平台给的公域流量“奖励”就会更多。

1、分享
视频号直播能分享到朋友圈，也能让用户把直播间分享到他们的朋友圈、群聊和好友。分享在互动动作里优先级很高。每一次分享都可能带来更多流量，比如龙哥分享了我的直播间，你在朋友圈看到，是不是会点进来看看。分享的人质量越高，带来的流量越大；物以类聚，人以群分，他是我的用户群体，他朋友圈里也有不少我的用户。分享这个动作，全程都要主动要、想办法用策略要；怎么要，需要多思考，找到和直播间最自然的结合方式，千万别生硬、尴尬、强硬、机械地要。直播间要互动有个原则：让用户做一点什么事情时，你也要给ta一点什么，做等价交换。

2、预约
在视频号直播间，可通过左下角弹预约，把直播预约推送给直播间用户，为下一次直播预热。

# 5.1.1.4 不同阶段的考核维度：场观不同，重点不同

1、冷启动期：0-2000场观
看人气数据（关键：曝光进入、停留）。冷启阶段，系统重点观察直播间的“内容消费表现”；推荐系统会依据“曝光进入率”“直播间有效观看占比”，寻找对这类内容感兴趣的用户，并在后续推荐里持续放大。若这几个指标偏弱，直播间可能拿不到持续的自然流量。内容力数据，在直播间数据大屏的内容力部分能看到。

[PRE1]

2、数据增长期：2000场观-10000场观
看流量精准度（关键：商品点击率、支付转化率）。这个阶段账号核心考核“商品点击成交率”：多少用户点开查看直播间商品、其中多少人点击后成功下单；它和下单金额无关，只看“下单人数”“下单单量”。用户行为开始从单纯看内容，转向产生支付。平台会给直播账号打精准标签定位，进而推荐更精准的人群进直播间。

3、成交转化期：10000场观以上
看直播间利用率（关键：GMV、观转率、GPM千次观看成交金额）。有了相对精准的人群后，平台考核会转向直播间对“流量的利用率”：同样的流量，你能卖多少钱，同行能卖多少钱；谁给平台带来的利益高，平台就把更多流量给谁，这就是平台的赛马机制。重点考核成交金额“GMV”、整体“观看成交转化率”（平台给这么多精准流量，你能卖出多少订单）、“GPM千次观看成交金额”（平台推荐一千个进入，你卖了多少钱）。这些都是同行赛马的关键数据。做直播，就是压过同行，从而拿到流量。

# 5.1.2 直播场景：画面会替你卖货

老话说，场景不会搞，直播做不好；场景搭得好，流量少不了。场景就是用户能看到的一切画面，包含直播封面、直播画面、主播、产品包装等；凡是进入用户视野的，都算场景。外场景由直播封面+直播实时缩小画面组成，点进去后才是直播实时画面。好看、吸引人、有差异化的场景，能提高曝光点击率、拉长停留时长，也就能带动平台更多推流。

# 5.1.2.1 直播封面、画面：第一眼决定点不点

用户还在直播广场、没点进直播间时，先看到的是静止封面，然后才看到动态实时画面。此时听不到主播声音，只能靠文字和画面获取信息。封面相当于海报，最重要的信息必须放上去，简洁、直接，让人一眼明白直播间在做什么；任何能展示的位置都别浪费。比如：“泰国原装进口乳胶枕——好睡到天亮”。直播广场上的动态场景就是实时画面，它直接影响曝光进入率；画面能不能吸引人、让人想点，非常关键。官方也明确强调“曝光进入率”很重要。画面里的标题可以写：“好睡到天亮。”“哪些人适合用乳胶枕”。

# 5.1.2.2 直播画面中的文案特点：短、准、有钩子

画面文案要做到短、准、抓眼：主题明确、重点突出、一眼看懂、有吸引力。有吸引力的写法比如：“产品上贴上1米福利”“老北京布鞋9.9”“奥特莱斯正品撤柜”。品牌宣传可用：“回力正品直播间”。痛点卖点可用：“三分钟出门素颜装”。信用背书可写：XX官方制定供应商、XX工艺大师……

# 5.1.2.3 场景搭建的依据因素：把产品放回使用现场

同一件产品，放在不同场景里，传递的信息会变，好场景本身就有卖货能力。关键是在用户脑子里放一个画面，让他想到拥有产品后生活会发生什么变化。简单说，别让产品孤零零站着，要把它放进真实使用环境，让用户看见使用状态、想象使用效果。

产品视角：展示。让产品占据画面中心，比如手播西洋参，镜头就对准产品，把卖点、功能、细节讲透。这里注意：别只拍精美包装或原始状态，重点要拍产品在真实使用中的鲜活样子。卖生鲜水果，把洗过、最新鲜的果子摆出来，切开或掰开展示果肉；卖护肤品，把瓶瓶罐罐从盒子里取出来，展示质地和形态；卖电风扇，就让它一直转着；卖食品饮品，就煮好、泡好，呈现能直接入口的状态。等等……

整体氛围感：+MM188166M（李李）长期更新。茶室卖茶，强调高端；仓库卖茶，强调性价比，做出仓播感，激发下单冲动；茶园卖茶，强调原产地正宗；大卖场卖茶，强调热闹。不同客单价、不同类目，要用匹配的场景制造不同感觉。想突出科技实力，就放到实验室；想突出家庭氛围，就放到卧室、客厅；想突出新鲜采摘、原生态，就放到果园、菜地；场景要贴合目标人群的喜好，也要贴合产品实际使用氛围。

原产地：如果原产地真实且不容易复制，就把最真实的场景亮出来，走出室内，信任感会更强。比如新疆葡萄园里卖葡萄干 VS 房间里卖葡萄干，差别一眼就能看出来，吸引力和信任度都不一样。

产品的包装：到底卖产品还是卖包装？镜头会让用户感知产品价值，视觉效果不能轻视。很多产品，包装成本甚至比产品本身还高。

产品的摆放：陶瓷杯放普通桌面 VS 放木制盒子 VS 放打灯玻璃柜，呈现出的价值感完全不同。

# 5.1.3 直播话术：把停留、信任和成交说进心里

# 5.1.3.1 拉流话术：把门外的人喊进来，把门里的人留住

目标很明确：拿数据、破层级、做权重。所谓拉流，可以这样理解：进直播间的人就是流量，主播用一两句简短且与对方有关的话把人吸住，让他愿意多待；直播间外的人听到有福利，也可能顺路进来。已经进来的人不走，持续留人，在线人数就会往上走；留下的人多于离开的人，在线被拉高，拉流就算成了。

示例可以说：新进来的姐姐们欢迎，这里是专业xx直播间。主播手上这顶帽子，专柜价899，今天一个快递费就能拿走，想要的扣1。丝绸面料，适合XX姐姐，已有XX人报名，还剩XX个名额，两分钟后上架……后面还有XX福利等着大家。

要点：一句话讲清卖什么，再给一个留下来的理由，比如马上发券、仅限今天、马上改价、稍后有福利。

# 5.1.3.2 立人设：把背景讲成信任

有背书，才更容易让人信；人设立得住，用户才会想“我为什么要听你的”。重点是摆事实、拿证据、讲故事，把信任讲出来。

示例：我们是做帽子的工厂，厂房3000平方，工人100多个，一天能出XX顶帽子，平时给品牌做代加工。这个帽子贴上商标就是大几百，同款在某某平台卖XX（拿道具做价格对比）……

要点：先让人知道产品靠谱，再给理由：技术背景、源头工厂、全网热卖、口碑好等。

# 5.1.3.3 讲主题：今日活动，把理由说圆

直播要有主题、有逻辑：我来干什么，我为什么这样做，都要讲清楚。

示例：我们家以前一直做线下，最近刚到线上，准备做自己的品牌。开店也好、直播也好，第一步都是先有人。我们也不太会直播，所以准备了XX份礼物，姐姐们不用做什么，待在直播间领礼物、帮忙捧个人场、热闹热闹就行。稍后两分钟一轮，不耽误大家时间，今天的福利还有XXXXXX……

要点：增强信任，讲清今天为什么做活动，理由要可信，后面的活动和利益点才顺理成章。

# 5.1.3.4 点对点：盯住公屏做成交

点对点成交，专业度要够，故事要顺，成交才容易。没人互动时，也可以请水军先把气氛带起来。

示例：XX姐姐已经扣1了，来，给她安排一单。

# 5.1.3.5 塑品话术：让产品听起来更有高级感

要站在更高维度塑造产品。别只盯着材质、工艺这些基础信息，而是把产品和大牌同款、纯手工制作、明星同款、进出口等更高价值的联想连起来。

1. 痛点需求：引起共鸣。
2. 产品卖点：为什么买？能解决XX问题。
3. 价值塑造：讲故事塑品、类比品牌。

示例：这个版型是京派旗袍传承人亲手设计的，京派旗袍的韵味很浓，上身很显女性魅力。您要是感兴趣，北京大栅栏那条街上就有这位传承人的门店，有机会能看到同款。

# 5.1.3.6 转品话术：承上启下，自然换品

转品要无中生有、顺其自然，用利他口吻带过去。

示例：刚才有姐姐问眼镜还有没有？这副眼镜是给老粉的福利，昨天答应过大家；新粉先别急，等这波过完，再给新粉安排福利。

# 5.1.3.7 催单逼单：今天不买，损失的是什么

开价后，给用户留一点拍单时间，但紧迫感要营造出来。

示例：姐姐们手太快了，这批已经没了，后面也不会再补。看看还有没有占着单没付的，再给大家一点时间；再不付款，名额就让给真正需要的姐姐了。

# 5.1.3.8 保障话术：放心无忧，才敢下单

用户会担心：买了后悔怎么办？看了没用怎么办？不满意怎么办？这时候要把承诺讲清楚。

示例：我向大家保证，所有产品都是正品，假一赔十。这里是产品质量报告和国家相关部门的认证。购买后发现任何问题，我们提供7天无理由退换货。客户评价一直不错，已经帮上万名客户解决了问题，大家可以放心买。

# 5.1.4 直播间货品攻略：选、组、排、测四步走

# 5.1.4.1 选品：选品决定生死

产品会决定打法、主播、场景和人群。视频号选品可以从几个维度判断。

首选爆品：别的平台卖得好的产品，可以搬到视频号再卖一轮；借助第三方工具，如“蝉妈妈、抖查查、飞瓜”，查看各品类销量靠前的产品。

货源优势：电商拼到最后是供应链，想做大做强，供应链很关键；有货源优势要优先考虑。

符合视频号人群特点：以40+以上的二三线女性为主，她们没怎么经过其他直播电商洗礼，不比价，退货率也低。

推荐品类：服饰箱包、滋补食疗、零食特产、美容护肤、日用百货。

# 5.1.4.2 组品：组合产品提升价值，方便成交

组品要具体产品具体分析，要有“组”的意识，把它当成冲某个产品销量的手段。

关联组合：搭配产品周边，比如买防晒霜送隔离霜+面膜，买鞋送袜子。

拆分组合：把整体拆开卖，比如买眼镜送眼镜盒+眼镜布。

# 5.1.4.3 排品：直播中产品的排列顺序

排品要按直播脚本走，价格从低到高，成交难度从易到难，并提前把主播话术定好。

钩子品：负责开播拉流量、做互动和停留，特点是价值感高的标品低价挂车，比如苹果手机1000块、四个哈密瓜1块。

福利品：负责成交密度，以标品为主，大家对价格有认知，你的价格又确实比心理价位划算，下单门槛低、决策成本小；价格相对低，能帮直播间拿到成交数据，比如5包纸巾1块、一袋洗衣液2块。

承接品：承上启下、丰富品类，中间价位，比如几十块的东西，可以有微利。

利润品：几十或几百都行，利润率高或毛利率高，能带来较高收益。

形象品：用来撑直播间形象价位，比如3980不卖，衬托其他利润品便宜。

# 5.1.4.4 测品：测试产品，是判断产品迭代的必要手段

任何产品都有生命周期，产品要拿到直播间检验，用户行为就是判断是否换品的标准。

测试受欢迎度，主要看销量。

通过弹购物车看点击率：曝光点击率高，说明用户对这个品感兴趣，后台要盯紧数据，随时准备换品；也可以让主播后半场介绍产品来测；还可以把产品放进直播场景或让主播佩戴，引出话题。比如水军带节奏：主播你带的项链很好看，多少钱？主播你身上的衣服卖不卖？

# 5.1.5 直播违规注意事项：一次违规可能伤到账号根基

熟悉直播全流程后，还要学会避坑。视频号管理很严，违规后的账号打击往往不可逆。表面上可能只是3天或7天限流，但账号过了处罚期，流量大概率也会下滑，最后只能换绑或注销重来。所以不熟练的团队，不建议做无人或半无人直播，很容易踩线。直播违规主要分两类：一类是小店产品售后违规，涉及商品标题、图片等；另一类是直播间违规，涉及主播话术、直播间场景等。

# 情况一：产品售后违规

1）违背承诺【延迟、无法发货】：视频号橱窗商家没有按平台规定或约定，向视频号橱窗用户发货，或没有提供承诺的服务。处理结果一般是禁止使用橱窗3天，并下架对应商品。

应对策略：如果确实因为各种原因没能及时发货，要尽快向平台报备，或者和客户沟通取消订单。报备可以直接在小店后台操作（如下图），也可以给平台官方发报备邮件（weixinlive-JF@tencent.com）。只要报备了、理由正当，后续若出现误判，找官方小二沟通，大概率能撤销处罚、恢复开播。
