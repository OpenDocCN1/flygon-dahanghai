# 2.4 让 AI 帮你写/改代码时，不满意怎么破？

如果 AI 给出的结果一直不理想，可以换个思路：先让 AI 帮你总结一下当前已有的内容，然后开一个新会话，重新把问题描述清楚再问；或者直接换一个大模型，比如 Gemini 2.5 Pro、Claude 4、ChatGPT、DeepSeek，让不同的 AI 互相参考，轮流试一遍，往往就能找到突破口。

# 2.4.1 给 AI 提需求，提示词怎么写更有效？

口语化提示词：不用给自己设限。你想做什么就写什么，哪怕一开始说得杂乱无章、前后矛盾也没关系。在和 AI 一来一回的对话里，你自己的思路会慢慢变清晰，提示词也会在反复总结中变得越来越完整、越来越有结构。

结构化提示词：也有圈友喜欢用格式比较固定的提示词，比如把技术架构、背景角色、目标输出这些要素都写清楚。只要熟练掌握一套自己总结出来的模板，和 AI 沟通的效率会明显提升。

# 2.4.2 AI 给出的代码，怎么在本地简单测试？

如果是 HTML 这类代码，直接用浏览器打开就能看页面效果和源代码，修改时推荐用 Notepad++ 这种轻量级富文本编辑器；也可以在 GitHub 仓库里直接改代码文件。

如果是 Next.JS 这种带后端和多组件的项目，在没有编程基础的情况下，本地调试很容易出错。作者本人也很少在本地调，更常用的办法是把问题截图、把报错发给 AI，然后复制它给出的代码去逐步测试。

# 2.4.3 遇到报错，怎么让 AI 做针对性修复？

第一步，准备一份不断完善中的“网站地图”，把它作为背景信息提供给你选择的 AI，并且隔一段时间就让 AI 帮你做一次二次矫正。

第二步，遇到报错时，把具体的错误内容截图，如果有错误代码文字，也一并复制粘贴发给 AI。然后清楚描述你遇到的问题，公式是：期望达到的结果 + 当前的错误信息 + 你已经做过的事情（包括具体代码）。

第三步，让 AI 先总结所有可能导致这个错误的原因，再逐一给出解决办法，并实际测试。

这套流程能解决大多数报错。只有那些非常复杂、提问者本身遗漏了某些代码知识的问题，可能需要发到航海群里，请技术大牛帮忙看看。

# 3.1 游戏站是什么？怎么靠它赚钱？

做游戏站不是让你去开发游戏，而是去找那些可能会火的新游戏名字，然后围绕它们建一个新网站，把流量引进来。

互联网上已经有海量网站提供现成游戏，你直接拿来用就行。怎么“拿”？核心关键词就是 iframe。

iframe 能让你在一个网页里嵌入另一个网页或内容。打个比方，它相当于在当前页面开了一扇“小窗”，通过这扇窗，你可以展示来自不同来源的网页、视频、地图，甚至是在线游戏。用户不需要跳转到其他页面，就能在这里直接看到、直接互动。

这种网站的核心优势在于：

- 无需开发技术：你不需要懂游戏开发，只需要把现有的 HTML5 游戏聚合起来；
- 用户粘性高：游戏天然好玩，用户更容易停留更长时间；
- 更新成本低：只要定期添加新游戏链接，就能保持内容新鲜感。

变现渠道方面，这里最推荐 AdSense。如果你有中国境内大陆招商银行的储蓄卡，就能绑定入账美元，五万美金以内免人工审核，系统直接入账。入账申报也会自动通过，之后把美元购汇成人民币，就能直接提现。

除了 AdSense，还有这些变现方式：

1. 广告收入：接入 Google AdSense 或其他广告联盟，在游戏页面展示广告；
2. 会员制度：提供无广告体验或独家游戏内容的付费会员服务；
3. 游戏内购：和游戏开发者合作，分享游戏内购买的收益；
4. 推广佣金：为其他游戏平台导流，获取推广佣金；
5. 定制服务：针对企业客户，提供品牌定制的游戏站服务。

2. 游戏发布平台：itch.io、Kongregate 等平台上有很多可嵌入的 HTML5 游戏；
3. HTML5 游戏开发论坛：在开发者社区里，能找到愿意分享或授权使用的游戏。

嵌入游戏的核心技术还是 IFRAME。你可以把它想象成在你的网站上开了一扇“魔法窗户”：玩家能在你的网站里直接体验来自其他网站的游戏，而且不会有“离开你的网站”的感觉。这样一来，访客在你这里点击、浏览页面，就会看到你挂的 AdSense 广告，也就等于为你 24 小时不间断地创造收入。

# 3.4 进阶玩法：把单页游戏站扩展成多页面游戏站

上一章我们已经成功上线了一个单页小游戏，也走通了从域名购买到托管配置的全部过程。不过，如果想真正做大做强，给网站带来稳定且可持续的流量，就得考虑上线更多网页、更多游戏，做成一个有规模的游戏站。接下来继续用前面的思路，聊聊怎么构建多页面游戏站，包括网站结构规划、批量加游戏的玩法，以及如何给用户提供更丰富的互动功能。

# 3.4.1 规划网站结构：分类、导航与页面管理

当你决定把单页小游戏扩展成多页面游戏站时，网站结构就变得非常重要。一个合理、清晰的结构，既能让玩家快速找到想玩的游戏，也能让搜索引擎更好地理解你的网站。可以从这几个方面入手：

1. 游戏分类与归纳

不同类型或风格的游戏，吸引的受众也不同。可以按游戏类型来分，比如动作、射击、益智、策略、体育等；也可以按游戏主题来分，比如恐怖、二次元、像素风等。建议在网站首页或主菜单栏放一个“游戏分类”入口，让玩家能按兴趣选。

2. 导航与菜单设计

在页面顶部放一个全局导航菜单，把主要分类或频道列出来。为了提升体验，首页最好再加一个搜索框，让用户直接搜游戏名或关键字。

3. 数据库或页面管理

如果你用 WordPress 或其他 CMS，可以建一个“游戏”自定义文章类型（Custom Post Type），每篇文章对应一个游戏的介绍、截图、Iframe 嵌入等。

如果你用静态网站生成器或手写 HTML，那可以按不同类型把游戏分目录保存，并保证文件名、URL 结构有可读性和层次感。

这样规划下来，每个新游戏都能拥有一条简洁美观的 URL 路径，既方便玩家分享链接，也有利于搜索引擎收录和排名。

# 3.4.2 批量加游戏：模板化与自动化要怎么做？

在多页面游戏站里，“批量添加游戏”往往是最费时间的环节。如果每加一个游戏都要手动写 HTML，还要改样式、介绍、图片，工作量很大，也容易出现重复性错误。下面给几个实用思路：

1. 通用模板页面

先设计一个通用的游戏页面模板，比如包含：

- 标题（H1）
- 游戏简介或一句话描述
- Iframe 容器
- 游戏控制说明、玩法提示等

新增游戏时，只需要复制这个模板，再修改对应的游戏名、Iframe 链接、缩略图等要素，就能省下大量重复劳动。
