# 2.5 Postman：接口调试利器

Postman 是什么？

它是专门测试网络接口（API）的工具。后端开发时，可以用它模拟前端请求，确认接口是否正常，是前后端联调的好帮手。

使用场景：

接口调试：开发 API 时，先用 Postman 发请求，确认返回数据是否正确。

前后端联调：前端页面还没完成时，可以用 Postman 模拟请求，检查后端接口数据是否对得上。

自动化测试：编写测试脚本，自动检查接口稳定性。

接口文档管理：生成 API 文档，方便团队共享。

安装方式：

1. 打开 Postman 官网下载页。

1. 下载与你的系统匹配的版本并安装。
