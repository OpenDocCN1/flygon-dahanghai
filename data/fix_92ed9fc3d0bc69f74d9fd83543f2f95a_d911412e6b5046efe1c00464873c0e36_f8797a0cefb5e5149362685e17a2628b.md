618之后，视频号短视频买量的门槛明显抬高：初审通过后仍可能转人工复核，混剪类内容可操作的空间被压缩。我过去总结的那套低客单推流方法，如今执行起来也处处受阻。

4）利润空间从哪来

短视频买量之所以还能做出较高利润，很大程度上是借了视频号人群结构的势。这里的用户价格敏感度低，溢价更容易成立；主动退款的人少，横向比价习惯也弱。于是即便产品品质普通，退货比例也能压得较低。再叠加平台生态尚在完善、小店客服配置不足、店铺治理偏松，驳回退款通常不会引发大问题；哪怕店铺评分不高，资金提现也照常，商家底气自然更足。

# 7.2.2 付费流量的运转逻辑

不少刚接触短视频平台的人，对买量这件事感到陌生，对买量内容也没有判断力，根子在于不熟悉流量机制。各短视频平台的流量大体分成两类：内容型流量与商业型流量，两者随时互相转化。平台按兴趣分发，而兴趣分发的根基是用户和视频各自携带的标记，这些标记又来自数据表现——用户行为数据，以及视频播放、成交数据。商业型流量和社区流量不同，购买意图通常更明确，平台主要用小黄车做筛选。买量时自然推荐进入较少，只有部分回流和转发订单；商业型流量更看重成交集中度，完播、点赞这类浅层指标权重偏弱。

# 7.2.3 开投前的准备清单

新手可以先把以下几项备齐：

1. 账号需开通购物车功能。一个账号能推不同产品，也能在某一阶段只聚焦一类产品。推流期间账号本身不带标记，标记体现在视频的成交人群上，且不特别看重浅层数据，核心看成交密度。
2. 挑出适合视频号推流的产品。
3. 制作对应内容，原创、混剪、半原创均可。
4. 开通视频号小店。平台治理越来越规范，尽量避开差评集中的产品，否则容易废店。
5. 其他准备：选品/素材工具（蝉妈妈、有米有术等）、推流辅助工具（诸葛、魔力、火星）、个体工商户或企业执照（开对公）、一定流动资金。

# 7.2.5 实操拆解

# 7.2.5.1 产品怎么选

推流只是项目链条中的一环，并非决定成败的唯一环节，胆大心细即可。出单后联系供应链、处理店铺售后都不复杂。重点看不同客单价产品的特性：

1、低客单价

低客单价产品看似普通，实际优势很足：

成交更密集，视频热度更容易被推起来；
用户决策成本低，对内容门槛也低。让用户仅凭一条视频掏200元，难度高得多，尤其在视频号上，中老年用户会抠材质、工艺、是否纯天然、是否健康无害、发货速度、到手是否一致等细节。低客单价非常适合刚入门的投手；
可选品多，新奇特、高性价比的低客单价产品不缺，还能反复打、按周期打；
出价更低，单次花费少，可以全量卡赔付，对资金占用影响不大；
退货率低，用户付出金额不高，产品一般也懒得退，售后稍加技巧，退货可以压得很低。

举例：高尔夫造型马桶刷
[PRE3]
[PRE4]

只卖2只装和3只装，1只装售罄。产品利润率83%，2只装售价29.9用户能接受。含退货的保本投产比为1.25；出价18元时赔付投产比可到1.66—1.99。当时推流投产比为1.55，全量卡赔付状态下回流5%、赔付20%以上，该品成交额利润率30%以上。这个店卖出1300多套，因购物车掉了只打一天，销售额4.2万，利润1.3万—1.5万。

劣势：

内容同质化严重，普遍较短，搬运者多。审核收紧后，推流想撑过30万播放很难，疑似搬运提示很多。
产出不稳定。很多人内容几乎不处理，拿十来秒视频就推，有时跑正有时跑亏。低客单价很考验心理承受力，投产比跑到1左右并不稀奇，要扛得住；视频标记稳定、细节做到位，才有稳定产出承接流量。

2、中高客单价

中高客单价很诱人，我也一直尝试。有些品确实利润暴力，优劣如下：

优势：
销售额天花板高。低客单价也能做大盘子，但高客单价产品若受众够广，销售额能拉到很夸张的程度；我还没打过高客单价万单产品，这是持续追求。
部分品类利润率惊人，美妆、带功效的食品尤其明显；其他高客单价产品利润率往往较低，货款压力会很大。
方法找对能撑更久。高客单价做的人少、搬运少，只要掌握技巧，能撑过更多人审，拿到更多流量，稳定性更强。

劣势：
对内容要求高；
退货率相对高，用户花了大钱，想劝退不满用户不退，难度高很多；
部分品货款压力大，资金利用率低；
不易全量卡赔付，出价高，全卡赔付资金利用率很低（资本充足可忽略）。

3、总结

低客单价适合新手。目前较稳妥的做法是起新号、自己原创拍摄，拍摄难度也不高，可部分原创或全部原创。我身边做低客单原创的朋友能撑过人审，突破200万播放，利润很可观。内容制作能力强的内容团队或个人，可以多尝试中高客单价。

# 7.2.5.2 先算保本线

开投前一定先算账。自然流选品中心佣金带货不同，推流要把全链路握在自己手里，账算清才能有的放矢。

[PRE5]

仍以高尔夫造型马桶刷为例：2个装SKU代发价2.9元，售价29.9元，在无退货、无平台扣点时理想投产比为1.2，投产比=售价/毛利。算上平台扣点、预估售前售后和退货，保本投产比=1.26。这意味着，产品加上平台扣点、售前售后退货后，保本投产比是1.26，这是推流的重要指标；推流投产比等于1.26时，推流端利润为0。再直白点：买126元成交额（约卖4.2件），产品成本4.2×4.9=20.6元，平台扣点+退货约5.4元，毛利100元。推流投产比=成交额/花费，推流端投产比>1.26才有利润。比如某笔计划预算100元，成交额99.8元，投产比约1，若长期如此就亏钱。

# 7.2.5.3 投放前想清三件事

开投前要清楚几件事：

1.预算：有多少钱推，据此规划一天预算和每小时大致花费。
2.目标：想投到什么产出，项目才可行，也就是目标利润率。比如上述产品保本投产比为1.26，我希望投产比在1.5以上，并且有赔付时可接受，确定后再投。推流最好用第三方辅助工具，我目前在用诸葛智投。
3.放大数据：有一定数据体量，看产出、看转化才有意义。测品阶段要把视频数据推到一定量级。比如每小时花100元、客单价30元，正常一小时出5单可达1.5投产比；少1—2单，投产比直接掉到0.9或1.2，对整体率影响过大，导致产出不稳、数据准确性低、没有参考意义。

# 7.2.5.4 流速怎么看

做买量的人都知道流速重要，但流速具体有什么用，值得想一想。

什么是流速？从花钱的内容、视频播放量能大致看出流速大小；从花多少钱能直观看到流速大小和变化。
流速代表什么？代表视频热度。想爆单，内容必须有高流速。花钱买量，花钱越快，视频热度越高，出单越快。
流速对产出和订单的影响，类似统计学正态分布。产品推流中，随流速增加，投产比逐渐稳定；到达峰值后继续加流速，投产比会下降。原因是流速过高，内容转化能力跟不上更泛的流量，产出被拉低。

# 7.2.5.5 六个推进阶段

目前赔付难度降低，中低客单价可在放量阶段就开始用卡赔付计划放量。六个阶段供参考：

1.测品阶段：一般3—5条计划测试产品产出。我通常拉得较多，对内容有信心就多给试错成本。
2.放量阶段：按预算定。产出在预期内，看小时级消耗速度和产出，可无限拉计划，无视空耗。
3.压价阶段：放量中产出逐渐下滑，可适当压价提升产出，但要保量级。比如50元一个成交扛不住，可试45元；45元能出数据且产出OK，就批量拉45元计划，且要多拉，因为50元计划退下来后，相同计划数下50元流速会大于45元。
4.卡赔付阶段：很多产品可上来直接卡赔付计划放量，3单出赔付。全量卡赔付，只要流速够、能消耗，基本是高产出计划赚、低产出计划赔，稳赚节奏。出价要能出数据，且赔付投产比大于保本投产比。
5.定向保产出阶段：推流后期加定向，拉升产出。
6.异常情况：测品不出数据，可尝试智能出价、定向人群、作者，快速出数据。目前测试下来，定向作者加智能出价经常能跑正；智能还不出，可开双智能（智能出价+智能投放）测账号是否有问题。

以上都基于你清楚自己的保本投产比，并通过三方工具看小时级产出和花费来调整。

重点：推流会拉很多计划，可能几百条，不可能逐条盯产出。要用三方工具盯每小时综合产出。若每小时综合产出在预期内，放量阶段不必调整单条计划；若连续几小时产出和流速异常，就要调整。

低产出、光花钱不出单的计划怎么处理：
1.放量阶段可以不管，它们在帮忙拉视频热度。大量关闭会让视频热度降低，放量失去意义。
2.卡赔付阶段重点关注有没有卡赔付希望。能卡到赔付，跑得再差也可不处理，只要能消耗就OK。
3.保产出阶段不要太大量级，适当调整关闭计划，把产出和流速控制到预期范围。

# 7.2.6 避坑要点

# 7.2.6.1 货与内容谁更重要

在视频号这门生意里，品和内容都是重中之重。二流品+一流内容仍可能打爆；一流品+二流内容却未必能爆。从这个角度看，内容重要性高过品。

1）爆款内容的底层逻辑

什么是一流内容？根据过往经验和对市面爆款内容研究，我们内部提出“三级信任”。用户看完视频后，促使其下单的核心因素是什么？痛点、产品效果、话术？研究大量内容后结论是：最核心因素是信任。想象亲友向你推销产品，是不是更容易下单？原因就是信任。视频号用户下单，先基于对平台的信任，再是对内容的认可。有些品内容发出去，评论说不好用、骗人，就是信任被破坏。其他因素都建立在信任上；没有信任，效果展示再厉害，用户也不下单。

内容分级：
一级信任：普通展示介绍产品，包括优点、效果、实用性等。大多数内容属于这一级。
二级信任：真人出镜，直接使用产品，让用户直观看到效果，增强信任。例如美妆类内容。
三级信任：塑造人设。通过场景、服装、造型、口播话术塑造人设，例如“当了十年化妆师，发现很多人不懂怎么涂口红”“我们的正宗草原牛肉千层肉，都经过风干晾晒”。这种方式能把信任度拉满。

好内容先获取信任、让用户放心，再用效果让用户动心。信任解决“凭什么在你家买”，效果解决“为什么要买”。理解这一点，选内容爆的几率更高，不再单纯靠运气。

2）什么内容适合挂车推流

根据爆品内容共同特征，挂车内容有几个基本要素：
画面清晰、语言流畅。画面不清晰不仅影响转化，甚至影响消耗；
有字幕，字体要大。字体小，老年人看不清，甚至看着难受；
有讲解，声音有亲和力，语速慢。有讲解的内容比没讲解的转化高很多；
广告性要足，拒绝泛娱乐。泛娱乐内容适合自然流，不适合付费流；
产品卖点要足，使用效果展示明显甚至夸张。最核心的点最好能颠覆用户认知，比如手电筒还能这么亮？去油污效果这么夸张？
满足这些只是基本条件。要优化内容，还得回到前面的底层逻辑。

# 7.2.6.2 混剪素材如何过审

内容可原创、混剪、半原创，但都绕不开审核。很多内容直接在助手发布不推流，可以进入社区（内容）流量池；一旦加热，就会走专门的商业型流量审核。目前审核较严，给几点建议。

审核失败常见情况：
1.过度营销：逼单话术过多。可删减这类话术，如“工厂直销”“今天有活动你不买，明天没活动又嫌贵”。
2.疗效营销：主要集中在功效类产品。需删减功效承诺话术，如“效果明显”“价值很高”“明显看到效果”。
3.混剪博眼球：出现很多。视频内容每个镜头中背景、人物频繁切换，换镜头。减少不同背景和人物出现次数。
4.预计无法覆盖：去重问题。做深度去重。这个报错一般对账号没影响，而且离过审很近了。
5.后端产品和视频产品不相关：找供应链时找不到视频里一样的产品。若相差不大，可在视频中放一张产品主图，缩小放在右下角一直展示。

# 7.3 直播间投流

# 7.3.1 直播间付费起量原理

买量的最终目的，是让直播间有持续、稳定、精准的流量进入，推动直播成交量冲破原有层级、上升到更大量级，同时获得更好利润，综合产出更大。付费买量后，人群更精准，转化更容易，成交量也更容易提升。简单说，买量相当于在共享用户池里抢符合自己直播间目标的精准客户。

它一方面受账号标签权重影响，如成交额、订单量、人群画像、标签和行为；另一方面受推流策略、出价、人群设定以及直播间人货场影响。例如投互动、出价80，直播间该怎么做互动动作；投点击、出价40，主播该怎么引导用户点击商品。

买量比拼的是：谁出价更合理、人物标签更准确、直播间人货场更吸引人。最终看哪个直播间关键指标完成得更好，UV价值和GPM更大，就越能获得平台算法的精准流量，推流产出就越好。UV价值=销售额/访客数，意思是每位访客带来多少销售额。GPM指千次曝光成交金额，GPM越高，代表流量精准度越高。

# 7.3.2 短视频投与直播投

视频号分短视频和直播两大块。短视频有MCN机构，直播有服务商体系；直播类型分秀场、游戏、带货三种。因此视频号买量分两种：短视频买量；直播间直投，也叫加热直播间或红点投放，这是本章重点。

短视频买量，针对挂商品视频买量，买量后呈现在短视频广场，刷短视频时会看到商品链接入口。
直播间买量，展现在直播广场或短视频广场。直播广场里的直播间大部分通过加热后呈现；刷短视频时也会看到直播实时画面，可点进去观看直播，这也是买量出来的。
[PRE10]

我从一些渠道了解到，这两个月短视频带货买量效果很不错，很多大佬在拼命放大买量，日消大几十万。去年年底也有一波，买量产出都不错，有一波人赚了一大笔；年后又熄火，直到近两月重新开始。

直播买量的效果在一些品类上也很不错。去年底12月应该最疯狂，海鲜、菌菇、滋补干货等。我们投过一些海参号，纯买量产出能到30，持续一个来月，每场大几十万上百万成交额。当时主播们很香，每天关心买量能否跑得动、起得了量；只要起量，成交完全不用愁，那会真是通投拉满。

# 7.3.3 直播间投流工具清单
