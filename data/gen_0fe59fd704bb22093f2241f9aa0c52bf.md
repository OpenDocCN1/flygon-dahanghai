# 三、测品：用一周时间验证选品

# 本章要点

每选定一个产品，都要通过测品来检验。📕测品，表面是在试商品，实质是在试运营者获取流量的能力。当然，大前提是商品链接页面的转化效率已经打磨到位。所以测品能不能出结果，除了看选品本身，还取决于两点：

✅ 商品链接质量：转化率是流量变现的前提。

✅ 笔记质量：体现获取流量的能力；不同商品适配的笔记形式并不一样。

提醒：新手前期精力有限，可以先用二创笔记测品；等选品能力提升后，再直接实拍。

接下来，进入测品环节。

# 3.1 测品到底在测什么

测品的内核，是给选品结论做一次实证。

选品阶段，我们通过分析同行链接数据，大致能判断某个产品在📕的竞争强度、月毛利润、流量规模等信息。但这些都停留在纸面分析上，选的品究竟能不能赚钱，还得靠测品来验证。

选品更依赖理论分析与经验判断，测品则更偏实操。它是检验选品是否正确的唯一方式。

在📕做测品，表面看是试商品，实质是在试运营者获取流量的本事。因为产品足够细分，吸引来的流量通常比较精准；只要流量稳定，一般就能出单。

当然，前提是【链接页面的转化率】已经优化好。

测品周期：一周。

📕高客单蓝海电商走的是精品路线，不像店群模式需要堆大量链接。同一类目的产品可以放在同一个店铺里，没必要一个店铺只对应一个品，那样太浪费。一般来说，一个📕店铺放少于20个品是可以的。

我们的实操经验是：一个品一个品地测，最好是上架一个、测试一个。当然也可以先把产品全部上到店铺，但要从选品数据表现最好的那个开始测。

每天发3—5条笔记，尽量不要集中发布。一般测一周，能出单的品基本也就出单了。

📕蓝海电商出单通常较快：产品足够细分，流量足够精准，只要链接页面转化率没问题，一周内还没出单，就要考虑换品。

只要一周内能出单，就继续做，重点提升获取流量的能力。一般来说，新人需要2—3个月才能把流量做稳定，进而稳定出单。

有些产品存在流量高峰，比如玄学产品，以及各类考试日前夕——中考、高考、考研、考公等节点前，都会出现流量小高峰。这需要大家在选品时通过数据分析提前发现，再安排合适的测品时间。如果选品时没注意到这些时间节点，完美错过流量高峰，后面做起来就会很辛苦。

玄学产品虽然利润高，但操作有难度，也容易违规，对新人不够友好。刚入行的圈友还是优先挑其他类目，更容易拿到正反馈。这里只是拿它举例，不代表推荐大家都去做这个类目。

# 3.2.1.2 怎么定价

很多人以为把拼多多商品搬到📕、提价3倍照样能卖，但📕用户并没有那么好糊弄。我问过50多个女大学生，大部分人还是会在淘宝、拼多多、得物下单，而且现在不少大学生都会比价。

我的定价方法是：搜淘宝和拼多多销量靠前的店铺，把价格定在这两个平台的价格区间内。很多用户比价后，发现我们比淘宝略便宜，再考虑到视频是原创拍摄、主打“所见即所得”，基本就不会去其他平台下单了。

比如随便在拼多多榜单里看到一条牛仔裤，价格39元；去淘宝搜同款，按销量排序，月销1000+的基本在70—90元区间，当然也有40多元的。这时我可能会定在59—69元，具体再计算自己的利润率。

# 3.2.2 提升链接转化率

测品之前，要确保产品链接在转化率上不拖后腿。以下六种方法，是我们实操后总结出的、能够提升产品链接转化率的做法，可以从这六个方面入手：

# 1. 给链接补评论

📕店铺的新链接，补5条及以上图文评价。想提升链接转化，人为补评价是有必要的，最好用图文评价，至少补5条；5条图文评价能达到边际最大化。

📕补单主要补的是评价，流量还是要靠笔记。5条图文评价，找亲朋好友就能完成；不想麻烦亲朋好友，就找以前的客户；没有客户积累，就找🛰️好友；🛰️好友也不想麻烦，那就去闲鱼发布任务。

# 2. 用SKU做引导

我们做的链接大多是多SKU的。SKU一多，用户容易选择困难，反而可能降低转化率。在SKU名称设置上，可以利用从众效应，让客户选择我们更想推的那个SKU。

以脐橙为例：

[PRE23]

上图这个SKU设置很原始，只有数据参数，没有任何营销性术语。很多客户一眼看过去，并不知道哪个更好，所以这条链接的SKU设置在我看来很差。

[PRE24]

上图这条链接的SKU稍微设置了一下，最底下那条SKU名称前面加了“好评最多”。它比上一条稍好，但在我看来还不够好。

虽然客户看完所有SKU后，目光会被最底下那条吸引，但也存在几个问题。

首先是排序问题：主推SKU应该放前排，放最后排是怕客户看到吗？

其次，主推SKU肯定要推利润高的，推尺寸最小的果算怎么回事？

最后，营销话术还有改进空间。

[PRE25]

再看第三条链接，这条的SKU设置才算合格。

首先，主推链接放在前排，方便客户优先锁定；店主放在第三位，其实放第二位会更好。

第一位放店铺客单价最高的产品，用来锚定价格。客户看完第一条SKU价格100元，再看第二条主推SKU价格80元，就会觉得80元不算贵，因为有100元最高价做衬托。

其次，营销术语不错，除主推SKU外，其他SKU都有营销话术。

最后，主推SKU前面的“好评最多”可以优化成“千人好评”“万人好评”，前提是销量够；销量不够，就用“好评最多”。用这种话术的目的，就是告诉客户：大家都选这条SKU，没问题，闭眼付款就行。

# 3. 设置优惠券

设置一个较高的初始价，再设置一张高额优惠券，可以让客户产生捡到便宜的感觉。这对非标品尤其好用，因为非标品没有同行参考价，你的标准就是唯一标准。

# 4. 用漂亮的模特

有些产品需要模特展示效果，尽量用漂亮的模特，越漂亮越好。

比如祛痘产品、美白产品，需要用模特展示前后效果对比图。效果图可以网上选，也可以让美工合成。

用来展示对比效果的模特越漂亮，转化率越高，因为客户会自我代入。如果模特比较丑，反而会起反效果。

人都喜欢好看的东西，尤其是女性，都希望自己更美、更漂亮。

# 5. 用恐惧情绪提升转化率

人的情绪中，有不少都可以用来提升转化。我们用得效果最好、目前使用最多的，就是利用客户的恐惧情绪来提升转化率。

比如：

卖儿童用品，会用“如果你不及时纠正孩子的某某行为，以后就会如何如何”“孩子的同学们都在用这种方法，你的孩子如果不用就会落后”等类似话术。

卖美容护肤产品，会用“如果你不舍得花钱保养，你省下来的钱就会被小三姐花掉来保养”等让用户感到害怕的话术。

要记住：利用客户恐惧情绪的最终目的，是为了转化、为了卖产品，一定是为了成交而使用恐惧，千万不要单纯为了吓唬客户而使用恐惧。

# 6. 用相似性包装📕账号

📕的账号、店铺和笔记是相辅相成的，不能分开看。

首先，📕本质上不是纯正的电商平台，而是种草平台。种草平台的意思是：我有某项需求，买了某个产品，使用后觉得很好，分享给📕姐妹；姐妹被真诚分享打动，去下单了这个产品。

所以，大家做📕时，给自己账号的定位不能是卖家，而应是产品爱好者或使用者。

因为定位成卖家，其他📕姐妹就是买家，你们之间就是买卖关系；如果定位成某个问题的解决者、某类产品的爱好者，你就和同样需求的姐妹具有相似性，你们就能成为朋友，关系也就从买卖关系变成了朋友关系。

📕的姐妹，会更相信和自己有相似性的朋友推荐的产品，还是更相信一个商人卖的产品呢？

其次，用相似性包装账号，需要你清楚目标用户群体的大致画像，以及圈子里使用的特定术语。

这些都可以通过在📕搜索关键词、查看笔记和评论来获取相关信息。

所以，大家的📕账号性别一栏有没有设置为女性？笔记有没有从产品使用者的口吻去推荐？记住，你在📕的定位不是商人，而是客户的朋友，你们具有相似性。

[PRE26]

比如这个📕号卖的是儿童用品，人设定位就是成长型宝妈，分享育儿经验，很容易获得📕上宝妈们的信任。宝妈们会认为她是“自己人”，因为她们之间具有相似性。

以上这些做好后，当店铺链接转化率没问题了，测品时只需要专心测流量即可。
