# 新手选品：先红海，再对标

新手开头别贪多，选品抓住两条主线就够了：第一，先切红海品类；第二，照着对标做。

1.

红海入门，先把出单闭环跑顺，再考虑蓝海

新人先挑红海里的低价品，价格带大概1—2元，多上、多试、多出单，借这个过程练网感。先让自己看到结果、把信心拉起来，再逐步打磨选品能力，往高客单的蓝海品类走。

红海和蓝海各有长短，先看清：
红海品：买家池子大，出单更容易，新手能较快获得正反馈；客单价低，爆款多，可选范围广；打出爆款的概率也更高。短板是竞争更凶，爆单后客服咨询会变多，而且单个爆款的收益天花板偏低，约200—300元。
蓝海品：客单价高，前期同行少，单品爆发的收益上限更高，平均约300—500元，最高可到1000元。难处在于选品门槛高、对品类内容认知要求高；一旦爆单会冒出更多低价同行；客单价高，也更容易遇到仅退款订单。
低客单选品参考：这类品通常没有固定用户画像和鲜明特点。用“低价 +（想要数：浏览数）≥（1:10）”去筛，效率最高。

2.

新手最快的学法：先模仿，再微创新

模仿不是照抄到底，而是最有效的起步方式。思路分三步：
第一步，随便找对标品A、B、C，拆它们的买家画像，找出共性和特性，用表格列清楚。
第二步，先把A、B、C放下，只思考这些共性和特性与出单之间有什么关系；如果某个因素能影响出单，就反推哪些品具备这些性质或共性。
第三步，回到闲鱼刷品，看想要数和浏览数，再看同一个品在不同店铺里的表现。

# 3.2 新手怎样搭选品方法

动手选品前，先搭一个选品库，把它当作商品素材池。

# 第一步：锁定对标，挑买家画像丰富的品

对标店铺有什么用？一是选品时有参照样本，二是能直接跟品。
找对标可以这样想：用逆向思维，把卖家视角换成买家视角，想想自己在不同角色下还有没有其他需求，或者有没有共同需求；另外，尽量选买家画像丰富的品。
什么叫买家画像丰富？比如PPT素材，买家里有学生、教师、文员等，受众广，对各类内容素材的需求也高。
这里给几个对标店铺案例作参考：搜索下图中的店铺名，点进对应头像，就能看到对标店铺里卖得较好的产品。
# 第二步：查看想要与浏览

打开闲鱼，搜索你想卖的关键词，比如“工作总结PPT”。如果搜出来的商品普遍满足【想要数：浏览数 ≥ 1:10】，可以先判断这个品的市场需求较大。然后再继续往下看。
[PRE3]

# 第三步：观察同行动态

“同行动态”能反映产品近期的出售情况，也就是转化数据。近期成交越多，通常越好，这一步在选品时更关键。
[PRE4]
判断市场是否可行，一般看同行“多天不间断出单＞3天”，相对来说就算不错，自然越多越好；具体是否值得做，还要看第二个标准——“不间断出单”：10天里有5天出单≥1单，这个产品就可以纳入选择。

这种情况可以借助店铺其他数据做补充评定，一般顺序如下：
1）是否开通鱼小铺：鱼小铺等级来自商家出售产品后用户给的好评量，所以可以作为第一项小参考。当然，有些店暂时没有鱼小铺，但后面几项表现不错，也可以视为近期出售较好的产品来选择。
2）下方留言时间：能代表产品近期市场咨询情况。7天内有2条以上新的产品咨询，说明近期表现也不错。
3）回复率90%以上：回复率越高，通常说明店铺整体盈利情况越好，值得投入心思和时间，所以90%以上可作为参考；低于80%一般可以跳过。
4）卖出产品数：自然越高越好。如果只有个位数，而且多家都是这个情况，说明这个品可能没太大市场；当然也不排除新上架就爆单的情况，这时要结合上面几项综合判断。
# 第四步：对比多家

只看单个案例容易碰到偶然性，所以要把前面的方法结合起来，看看多家想要数都不错的店铺，其动态出售情况如何。
如果有多家都满足前面说的“同行动态”，其中2、3家出售都大于3件，这个品就可以选了。

# 3.5 商品上架操作流程

闲鱼虚拟资料项目的逻辑是：先上架商品链接，用户咨询后出单，再去找对标拍下资料用来发货。所以先做商品上架。

# 3.5.1 编辑并发布商品的步骤

上架并不复杂：找到对标商品链接，参考对标做二次创作，然后发布。具体步骤如下：
# 第一步：寻找对标
在闲鱼首页搜索框搜产品名称关键词，比如PPT模板，按前面学到的选品方法挑对标，关键是满足想要:浏览≥1:10。
[PRE10]
找到对标后，参考它修改下面这些内容，就可以发布。修改的目的是降低同质化，同时吸引买家。
# 第二步：拟标题
一般参考对标改一改即可。左图是对标标题，右图是修改后的标题，可以参考。
[PRE11]
# 【附】标题怎么写更吸流量？
想拿到更多流量，标题通常要把产品关键词堆足，让用户无论搜产品哪个名称，都尽可能看到自家店铺的产品。比如“ppt模板”，也可以换成“PPT高端模板”“通用模板”。标题参考：9999套PPT高端模板、通用模板，包含莫兰迪、古风、ins风等，尽量把30个字符占满。
[PRE12]
# 第三步：做主图
主图一样参考对标就行。闲鱼对搬运管控不严，目前直接用对标图也没问题。
# 【附】主图怎么做更抓眼？
好主图要第一眼抓住闲鱼客户眼球，特点通常是：清晰、干净、能体现产品特点和卖点。以“小学资料”为例，排名靠前的商品主图一般是产品放在正中央，款式和细节突出，让人有点击进入的欲望。
[PRE13]
而一些“想要数”相对少的商品，图片不清晰，给用户的感觉较差，对比之下用户肯定优先点上面的。所以主图尽量按上面的要求做。
[PRE14]
内容里的其他照片，参考动态出售好的商品的其他图片即可，比较简单。好的主图图片去哪里找？有一个成本较低的办法：直接去电商平台，比如淘宝、1688、拼多多、淘特等搜索产品，从产品介绍和用户评价里找符合要求的图片。
[PRE15]
这只是一个很基础的方法，作为闲鱼卖家已经够用。如果想做出差异化，可以在原图基础上二次加工，比如加特效、图片拼接等，这些用市面上常见的P图软件就能做，这里不展开。
# 第四步：发布链接
找到对标文案和图片后，返回主页，点击卖闲置，按要求发布即可。发布地可以选一二线人口较多的城市。定价可以参考对标，也可以比对标低，但不建议0.01元，容易被判低价引流、扣闲气值。发货方式选包邮即可，发货时也可以再选无需寄件。

[PRE17]

# 3.5.2 闲鱼编辑上架的注意事项

1. 标题和内容里不要出现品牌词，图片也尽量别出现。
2. 内容标题里不要出现“无添加”“联系”“🛰️”等引导闲鱼站外的词。
3. 发布地可以选择一线人口较多的城市。
4. 上传操作时间最好在早上8点左右，其次晚上8点左右，最不济中午11点半左右。
5. 单天发布5个左右链接即可，不要太多，防止被判定为营销号。

# 3.6.3 运营时要注意的点

1. 运营小技巧：
按正确方式上架产品，注意产品标题、文案、发布地址、产品标签；每天及时擦亮；及时回复用户咨询，尤其前期要把消息通知打开；卖出产品后及时上架；拍下5分钟内不付款的，及时关闭交易订单，按客服话术以退为进；及时回复评论和留言，让其他感兴趣用户感到你负责；订单及时处理；少售后、少差评，产品质量要盯着，如果多个差评及时更换商家，售后也要及时妥协处理。
2. 闲鱼违规封号点：
下面这些常见违规封号点建议避开：选品选了市场违禁品（详见【3.4 闲鱼选品避坑】）；同一个手机登录多个账号，外加单个手机切换账号使用；客服聊天出现违禁词，以及同一句话多次使用，比如“转账多次”“一单一结”“皇”“🛰️”“联系”“加”“原味”等常出现但容易忽略的词；售后太多、纠纷多，多次拒绝后用户直接申请小二介入。

# 4.1 闲鱼客服常用回复模板

# 4.1.1 常用回复
虚拟资料的客服相对其他产品简单很多，因为没有物流问题。基本就是问还能不能拍，或者产品内容相关问题，所以这里不展开太多。最常见的问题是：
客户：你好/在吗/还有吗/怎么买？

# 4.1.2 客服经验提炼
1. 给钱的是上帝，买家的合理要求尽量满足。不要和买家起冲突，没有性价比。
2. 不方便时，找一个合理且不好拒绝的理由。比如“在开车”是我经常用的理由。正常买家愿意等，同行或难搞的买家会拒绝，所以没必要给自己找麻烦，不必内耗。

# 4.3 差评与仅退款怎么处理

差评：
1. 差评需要联系闲鱼官方客服，提供材料证明是恶意差评，才能让官方帮忙删除评价。
2. 避免差评的方法没什么特别的，就是售后能退就退，千万别跟客户起争执，个别差评也不影响店铺。
仅退款：
3. 一般虚拟资料不退货，除非你没及时发货或者资料有问题，直接给退即可。话术参考：不好意思哥/姐，我现在给你退款。
