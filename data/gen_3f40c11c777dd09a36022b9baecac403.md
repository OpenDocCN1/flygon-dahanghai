| 常见卡点 | 默认动作 | 判断标准 |
| --- | --- | --- |
| yt-dlp 下载失败，提示“无法访问” | 检查链接是否公开可访问。有些视频需要登录或有地区限制，换一个公开链接试试 | 换链接后能正常下载 |
| whisper 安装报错 | 让 Codex 排查。常见原因：Python 版本太低（需 3.8 以上）、pip 版本太旧。把报错信息告诉 Codex | 终端输入 python3 -c "import faster_whisper" 不报错 |

| 转录太慢，等很久 | 音频太长。这一关用 10 分钟以内的短音频。如果已在运行，耐心等——第一次加载模型较慢 | 下次选短音频；或 Codex 提示转录完成 |
| 转录文字有很多错别字 | 正常现象。这一关不追求完美转录，只求跑通。错字纠正是关卡 4 写 Profile 时教的 | 能大致看出音频内容就算成功 |
| 不知道这算不算完成 | 看有没有可见输出。只要 Codex 自己处理→自己写了新文件，就算完成 | 截图能证明“输入→处理→输出”三步都有 |
| 想一口气做复杂的东西 | 先不改案例，用默认 Demo 跑通再说。关卡 2-6 会教你做好 | 本关只追求完整跑通一次 |

### 03. 关卡小结

最小 Agent，就是先让 AI 真正替你完成一次看得见的任务。本关借助【音视频转录 Agent】Demo，先跑通从输入到处理再到输出的完整链路。只要 Agent 能接收任务、调用工具、生成文件，并且你能用截图证明结果存在，第一个最小 Agent 就已经成立。

核心四个动作：
1. 准备一个明确输入：先选公开可访问、长度适中的音视频材料，让 Agent 有东西可处理。
2. 搭好可对话入口：用 Codex 创建 Hermes Agent 和飞书 Bot，完成私聊或群聊接通测试。
3. 发布一个具体任务：把下载、转录、保存文件这些动作说清楚，让 Agent 按步骤执行。
4. 检查可见输出和边界：确认转录结果文件存在，再让 Agent 说清楚自己能做什么、不能做什么。

跑通这一关后，你已经有了一份真实体感：Agent 不是抽象概念，而是一条可以被验证的工作链路。如果你觉得这个 Demo 还不够好，甚至离真正替你工作还有距离，这都很正常。因为这一关的目标不是做一个完美的 Agent，而是先建立体感，理解 Agent 如何运作，以及一条完整工作链路如何跑通。下一关就要从这个 Demo 往自己的实际重复工作收拢，找出第一个你真正需要的 Agent 员工，并决定它到底为谁服务、接收什么输入、交付什么结果。

### 01. 重点内容

关卡 1 你已经通过 Codex + Hermes + 飞书，跑通了一个最小 Agent Demo：把音视频链接交给它，它能下载、转录，并生成转录结果。你可能会有一个疑问：既然 Codex 一句话就能完成这些事，为什么还要接入 Hermes 和飞书，再搭一个 Agent？这是很多人第一次接触 Agent 时都会有的疑问。

因为“完成一次任务”和“拥有一个长期工作的 AI 员工”，其实是两件不同的事。如果只是偶尔处理一次音视频，直接打开 Codex 对话，让 AI 完成就够了。但如果这项工作每天都会发生、需要反复执行，甚至希望别人也能使用、长期维护和持续优化，那就需要把它沉淀成一个真正的 Agent。它有自己的岗位、固定的工作流程、稳定的调用入口，也能不断积累规则和经验。以后无论你自己还是团队成员，都可以直接把任务交给它，而不用每次重新解释一遍。

所以，本期真正想教你的，不是“怎么让 AI 完成一次任务”，而是“怎么培养一个可以长期工作的 AI 员工”。你也会发现，这个 AI 员工就像刚入职的实习生，很粗糙：在音视频转录这件事上，它能完成基础动作，但转录文字可能不够准确，内容只是原始文字、没有重点整理，文件也还只保存在本地，不方便线上修改、多人同步和长期沉淀。这很正常。实习生想把工作做好，需要有人带：告诉它负责哪类工作、接收什么输入、按什么步骤处理、交付什么结果，以及什么情况必须停下来找人确认。Agent 也一样，需要清晰的岗位定义、稳定的工作流程、明确的交付标准和必要的人工兜底，才能从“能跑一次 Demo”逐步变成“能承担一项具体工作”。

所以这一关，我们先定岗位：把你的第一个正式 Agent 员工要服务谁、解决什么问题、交付什么成果写清楚。你在这一关完成的 Agent 岗位卡，会直接喂给后面的关卡 3（拆工序）和关卡 4（写大脑）。岗位越清楚，后面的流程和 Profile（岗位说明书）才越容易写明白。

如果你对做 Agent 还没有什么概念，我们也会提供案例，带你完整跑通一遍搭建流程。默认案例继续沿用关卡 1 的【音视频转录助手】，在这个 Demo 的基础上，把一个“基本能做事的 AI 实习生”，培养成一位真正能够胜任音频转录岗位的 AI 员工。如果本关你还没想好自己的 Agent 要做什么，不用着急，先跟着案例完成关卡步骤，建立对整个流程的理解。有了体感之后，再回到自己的真实工作场景，设计属于你的第一个 Agent。

❗️ 需要注意的是，默认案例只是帮助你学习流程、加深体感，并不能作为最终成果物提交。本期真正的目标，是做出一个能够替你完成真实工作的 Agent，让它成为你的第一个 AI 员工，而不是只完成一次案例练习。
