```javascript
// 获取当前正在处理的数据项（Run Once for Each Item 模式下使用 $input.item）
const inputString = $input.item.json.output;

// 用正则提取出 { 和 } 之间的 JSON 部分
const jsonMatch = inputString.match(/\{[\s\S]*\}/);

// 如果找不到 JSON，可以选择抛错终止，也可以返回空对象继续
if (!jsonMatch) {
  throw new Error("在输入字符串中没有找到有效的 JSON 对象。");
}

// match 返回的是数组，取第一个匹配项
const jsonString = jsonMatch[0];

// 解析成 JavaScript 对象
const dataObject = JSON.parse(jsonString);

// 取出 title 和 summary
const title = dataObject.Title;
const summary = dataObject.Summary;

// 返回新对象（Run Once for Each Item 模式直接返回对象即可）
return {
  json: {
    title: title,
    summary: summary
  }
};
```

## 2. 各字段创作指令

**Title（String）**

目标：基于【文章原文】，创作一个抓人眼球、能激发好奇心的爆款标题。技巧方面，可以灵活使用数字、疑问、对比、悬念、利益点等手法。同时要坚决杜绝平铺直叙、枯燥乏味的写法。

**Summary（String）**

硬性规定：严格控制在 60 个汉字以内（含标点符号）。这是最高优先级，绝对不能突破。目标：用生动、有吸引力的语言重写摘要，让读者 3 秒内理解文章核心价值，并产生阅读兴趣。技巧：用第二人称“你”和读者对话，建立代入感。可以先抛出一个痛点，再暗示解决方案，结尾用一个问题或一个引人思考的陈述，引导读者继续往下看。禁忌：不要照搬原文中的任何句子。

[PRE9]

上面这张图是整个工作流的结构，其实非常简单，主要由以下几个部分组成：

- 需求收集：用 n8n 的问卷 trigger，也可以用 webhook trigger 接收外部信息。
- 上传到图床：问卷收集来的图片是二进制格式，先转成 base64，才能上传到图床。
- 解读图片：用主流大模型的多模态能力，把线稿里的设计细节全部解析出来，作为补充描述，提升最终生图效果。
- 生成影棚级摄影图片提示词：让 AI 充分理解设计细节，再通过母版提示词增强细节，生成一个描述颗粒度细腻、覆盖画面所有元素的生图提示词。
- 生成图片：结合线稿和上一步的提示词，用 flux kontext 模型生成图片。
- 生成视频：用 veo3 生成走秀视频。

就这么简单的六步，就能得到你看到的视频效果。有兴趣的话，我们进入实操拆解。
