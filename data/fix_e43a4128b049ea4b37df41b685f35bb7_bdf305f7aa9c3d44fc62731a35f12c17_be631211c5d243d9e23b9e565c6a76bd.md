# 5.1 主流变现：接广告（品牌方合作）

以抖音为例，接商单常见三种方式。

第一种，抖音后台星图广告，一口价合作。比如发一条视频，报酬一千块，后续转化、下载量都不管。

第二种，抖音后台星广广告，一般带保底收入。它不按一口价走，而是按下载量计费。我去年跟豆包合作星广，虽然没保底，但每来一个下载，就多一份被动收入。播放量要是好看，下载带来的钱会比星图那一千块多不少。防失联+MM188166M（李李）长期更新所以碰到大品牌，就算没保底，这类星广也可以考虑接。

第三种，水下交易。一些中小品牌、刚启动推广的企业，或者小媒介，可能不走星图星广，更愿意在视频拍完的一两周到一个月内，通过🛰️或支付宝直接打款。还有按点赞数结账的，比如每个赞两毛或五毛，发布一周后按实际点赞量结算。

媒介更愿意跟哪类博主搭伙？我问了长期合作的豆包媒介。对方说，偏向职场、学生、宝妈这三类博主，要求粉丝过万，平均播放量别太低，而且更希望长期合作。说白了，就是要锚定一个特定人群来做视频。拿我自己举例，最开始播放和粉丝都不理想，但后来还是跟媒介建立了长期合作关系，原因就是粉丝画像够精准，主要是家长群体。

# 第一步：接下合作

品牌会在蒲公英找合适博主发邀约，达人可在 APP 端「消息通知-商业合作」里查看。点「感兴趣」后，就能和品牌私信联系，拿对方🛰️，沟通合作细节。品牌也可以跳过邀约，直接在后台发起合作，达人在 APP 消息通知里收到订单并查看。觉得商单合适，就接受合作，开始创作。APP 端和 PC 端蒲公英后台，也能管理「待接受」的合作订单。

# 第二步：创作笔记

加商家🛰️后，对方会发来广告素材。拿到后先自查：内容有没有敏感词、图片是否合适。

下面是📕内容规则和规范整理，仔细看，避免违规犯错。

1. 社区公约解读：如何规范笔记内容；如何规范商单笔记。

2. 审核规则解读：如何规范笔记首图封面或标题；如何避免水印问题。

3. 其他推荐关注：规则中心，路径是📕 App - 我 - 左上角图标 - 创作中心 - 规则中心；📕创作学院；薯队长；薯管家；蒲公英小助手；📕生态站，路径是📕 App - 随手举报一篇笔记 - 消息 - 消息通知 - 进入生态站。

4. 敏感词/违禁词在线检测工具推荐：笔记稿件建议多用几款不同工具检测，避免审核不通过和笔记违规。推荐句易网：http://www.ju1.cn/#/ ；零克查词：http://ci.lingke.pro/ 。

如果有敏感词，或图片尺度大、表述夸张，可以改完再和商家沟通，达成共识后发布笔记、提交审核；没问题就直接用商家素材发布、提交审核。

注意：这一步要沟通好广告发布时间。比如一天来了三个邀约怎么办？都发吗？新号建议发完一条商单后，至少隔一天再发第二条。商家同时邀约时，可以在🛰️上详谈，协商好其他发布时间。

# 第三步：提交笔记，等待审核通过

在📕 APP 编辑好内容后，点「高级选项-品牌合作」绑定订单。选好对应合作订单，再回到发布页，就能提交合作笔记了。

这时笔记还没正式公开，其他用户看不到。提交后，笔记进入平台和品牌审核确认环节。如果审核不通过，消息通知和蒲公英后台都会提示，按要求修改。没通过的话，可以联系商家重新提供素材，再重复「第二步：创作笔记」。如果改的是图文内容，直接在编辑页修改，重新发布合作笔记即可；如果要改视频内容，得先解除笔记与订单的关联。进入笔记编辑页，在高级选项里取消关联，回到发布页，重新发布时再绑定订单即可。如果连续三次都没过，建议这个广就不接了，可以取消合作。在后台找到该订单后取消，不会受平台惩罚。当然，哪怕取消，也要维护好和商家或 PR 的关系，以后可能还有合作机会。

# 第四步：发布笔记，等待订单完成

审核通过后，就可以发布笔记了。在跟品牌约定好的时间，点 APP「消息通知」里的前往发布笔记，或笔记详情页左上角的「合作品牌已确认」，就能正式发布。

# 第五步：收益到账，完成提现

品牌确认订单后，我们会收到合作款项。如果品牌没主动确认，七天后系统也会自动确认，收益到账。对接商家的话，直接结算订单收益即可；对接 PR 的话，对方可能要求抽佣。一般加🛰️后，如果对方是 PR，会聊广告内容和返点佣金，常见返点在二十到四十元左右，能接受就合作，不能接受就拒绝。不是所有 PR 都抽，除非对方想自己赚点。后续笔记发布完、收益到账，就可以按谈好的分佣直接私发给 PR。

提现：订单确认七天后，到📕钱包统一提现，提现扣 10% 的税。

# 5.2.3 广告怎么挑 @皮皮酱

我的号十条里九条都是广告，但一点没耽误涨粉和变现。一是笔记数据好且稳，二是我很挑，对广告很挑。

# 5.2.4 值得接的广告

1. 有预算投流的品牌。可以提前问 PR，或搜搜这个品已经发过的广告数据怎么样。投流是品牌花钱给你的笔记投放，很香！很可能把原本数据不行的笔记拉到千赞以上。

2. 大品牌。比如母婴类目的帮宝适、飞鹤；美妆护肤类目的欧莱雅、兰蔻；家居类目的美的、戴森、3M。大品牌自带流量，不仅能提高搜索曝光概率，还能让更多大牌 PR 看见你。

# 5.2.5 不建议接的广告

接一条一万的广告，比接十条一千的香多了。下面这些我都是直接 pass：

- 没几个店铺在卖的杂牌、小牌子；
- 图文直发，伤号且容易违规；
- 医药类，专业性太强；
- 不符合消费观的，比如十几块一瓶的婴儿水，智商税；
- 差评多的，会让路人转黑；
- 日系品牌，没原因，就是不喜欢；
- 脚本已经写好，但品牌硬要修改里面提及的缺点，这个看个人；
- 返点要求离谱的。只有很水的买来的号，才会给 30%-40% 甚至 50% 的高返点。我们大大方方做内容，宁缺毋滥。

# 5.2.6 合作前要问清的事 @虾饼

合作形式分报备笔记和非报备笔记。报备就是前面说的官方认可的品牌合作，要交“保护费”；非报备就是私下合作，悄悄打暗广。

非报备又分单品和合集。单品是一篇笔记里只能含这个品的广告；合集是一篇笔记里同时有好几个品给你广告费，让它们出现在笔记中。单品里还有个概念叫伪合集，一篇笔记里看似出现很多产品，但真正给广告费的只有一家，这是最大程度避免被判定为私自推广。

跟 PR 聊的时候，还要问清这几件事：

- 档期：出初稿、终稿以及最终发布的日期。
- 授权转发：能否授权品牌在电商/内容平台发布，是否免费，授权周期多长。尾部博主一般免费授权，周期常在三个月到半年。
- 授权投流：能否授权品牌在📕投流，是否免费，周期多长。投流能帮博主涨数据，但品牌爆出丑闻还继续拿笔记投流，会影响账号形象，所以最好定个期限，比如一年内免费授权投流，一年后看情况是否继续授权、是否加费用。
- 笔记发布后的保留周期：一般一年或永久。
- 排竞：发布这篇笔记的前几天到后几天，不能再发该品牌竞品的相关笔记。
- 活动出席：美妆和穿搭类品牌可能会邀请达人出席产品发布会之类的活动。

内容来源：《职场小白裸辞做📕宠物博主，一个月收入顶一年工资》

# 5.3.3 知识付费变现

很多圈友应该刷到过一些 AI 相关课程，那怎么做出这样的内容呢？其实并不难。

这里给大家简单拎拎操作重点：

# 5.3.3.1 课程定位

先解决「课程定位」问题。

什么是课程定位？一句话：你卖什么、卖给谁、解决什么需求。

比如，我的课程定位是：帮自媒体创业者、想做副业的小伙伴，用 AI 工具+提示词高效解决知识付费产品的制作和上架问题。

别小看这句话。它将来会填在朋友圈签名、👸号简介、📕介绍等自媒体最显眼的位置。相当于陌生人见你第一面，问你是干什么的，你一句话说不清，别人就会觉得你：不！专！业！

解决这句话，再取个自带流量的好课名，就可以正式做课了。

怎么做课程定位？对自己来说，做什么课才能兼顾爱好、擅长、赚钱，能否平衡？

我觉得很有必要，今晚、半夜，自己一个人在书房，或窝在沙发、电脑前，或捧着手机，抽支烟，或抿两口小酒，好好静下心来，按我标好的①②③④⑤，顺序层层递进，想五个问题：

# 💡

① 我喜欢什么？

② 我擅长什么？

③ 我想学什么？

④ 对标博主，验证这条赛道是不是有人已跑通，且跑得怎么样？

⑤ 和而不同+差异化。

前四点很好理解，主课里有详细讲解和举例。这里重点讲第五点【和而不同+差异化】。

举个例子，我当初调研【课程制作】这个方向时，去抖音、📕、视频号、知识星球看，发现确实有不少人在做，有些规模还很大。如果我不管不顾一头扎进去，和正常人一样挤【做课】赛道，那猴年马月才能和大家见面。巧妙之处在于，我刁钻地切了【AI+做课】这个小角度入行，那就不一样了。我还是我，但成了不一样的烟火；我还是做课的，但我是搞 AI 做课的。这就叫不同，这就叫差异化。所以大家一定要瞅个刁钻角度切市场，这个很重要，聪明人一定会这么做。

那什么是【和】而不同？不同好理解，就是差异化，刚才讲过了。那为什么还要【和】？

还拿我当案例。如果看过我的课程海报，大家有没有觉得，乍眼看去，我的自拍照、海报色系、风格，大体上还是老师的感觉，一看我的物料就是个做知识付费的、卖课的。这一点也很重要，让自己的形象、海报、朋友圈等，看起来一定要像做这一行的。如果我打扮得花里胡哨，朋友圈嘻嘻哈哈，或字里行间满嘴跑火车，大家还会来买我的课吗？让自己像做这一行的，一眼看上去就是干这个的，太重要了。在【和】同行的基础上，再叠加差异化 buff，这才是真正有源之水的差异化，后期才有无限可能。
