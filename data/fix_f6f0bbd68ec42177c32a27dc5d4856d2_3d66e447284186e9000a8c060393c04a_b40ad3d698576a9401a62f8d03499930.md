**坎三：出错信息里带 git 字样**

[PRE62]

两种解法：
1. 把 git 卸掉重装，路径保持默认；
2. 给 `CLAUDE_CODE_GIT_BASH_PATH` 赋上值，值填 git 的实际位置（在 Windows 的环境变量窗口里设置）。

💡**⚠️ 提醒：** 安装过程中若弹出下图这个错误，说明当前操作得靠管理员权限。在前面补一个 `sudo` 重跑就好。把这条命令粘进终端：

sudo npm install -g @anthropic-ai/claude-code
