# 五、应用上架全流程

# 💡

# 章节速览：

硬件准备：一台 Mac，加一台 iPhone 做真机测试。

软件准备：Apple 开发者账号，99 美元/年，这是上架的前提。

核心流程分三步：

1. 上架前准备：注册开发者账号、设置应用图标、创建 APP ID、配置证书和描述文件；
2. 应用打包发布：在 Xcode 生成安装包，上传到 App Store Connect 等待审核；
3. 应用详情页设置：制作预览界面，填写技术支持网址、隐私协议等必要信息。

版权设置：个人开发者可用真实姓名，公司用注册名称，格式为“Copyright © 年份 名称。 All rights reserved.”

掌握这套完整流程后，初学者也能独立完成 iOS 应用上架。

# 本章路线图

学完本章并动手实操，即可完成路线图中的：

第三阶段：应用上架与变现功能集成（约 8 天）

1. App Store 上架准备：开发者会员、App ID 创建、证书与配置文件生成（约 2 天）；
2. 应用打包、上传 App Store Connect 及商店信息（含版权）设置（约 2.5 天）。

# 5.1 上架前的准备

# 5.1.1 开发者会员开通

打开 https://developer.Apple.com/ ，注册成为开发者会员。费用是每年 99 美金，或 688 人民币。不是开发者会员，APP 无法上架。

# 5.1.3 创建 APP ID

第1步：打开 https://appstoreconnect.Apple.com/ 。

第2步：点击导航栏的 APP，再点页面上 APP 一侧的“+”号，新建 APP。

第3步：勾选要发布的平台，填写 APP 名称，设置主要语言，选择套装 ID。SKU 随便输入一个数字即可。如果没有 id，可以创建 APP ID。

[PRE32]

第4步：Description 可以填 APP 名字的英文拼音；Bundle ID 要填写与 Xcode 项目中一致的标识符（com.xxx.xxxx）；勾选 APP 用到的权限，比如 WiFi、相机等。如果只是本机运行的单一功能，可以不勾任何权限。

# 5.2.2.1 提交审核

4. 选择你的 app 使用的加密算法，如果没有使用，就选“哪种都不是”。
