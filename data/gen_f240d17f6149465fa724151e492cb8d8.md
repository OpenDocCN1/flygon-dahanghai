# 1. 工作流预览：n8n 搭「SEO 内容引擎」

[PRE0]
先在节点面板右侧点“+”，把 HTTP Request 节点加进画布。

这次请求方式选 POST；具体配置照着界面图走即可，真正要盯住的地方只有两处：

1. POST 地址这样写：`https://api.imgbb.com/1/upload?expiration=600&key=YOUR_CLIENT_API_KEY`。其中 `expiration` 参数决定图片在图床待多久，以秒为单位，取值区间为 60 到 15552000；`key` 参数则填上一步申请到的 API Key。
2. 把前面生成的 Base64 字符串放到箭头标记的 Value 栏里。

配置结束后，我顺手加了个 Wait 节点做短暂缓冲：图床刚接收图片时，读取未必立即成功，留一点等待时间更稳。示例里填的是 10 秒，实际可自行增减。
