# 4.2 故事号：@老馬🐎内容出海

# 4.2.1 故事号到底做什么

故事号，是从其他文字类社媒找文案，二次创作成视频。呈现上像国内抖音的知乎贴文、天涯神贴、贴吧神帖，但和小说推文不同。

题材多为搞笑、狗血、恐怖，配解压素材混剪。展现形式三大类：普通故事风、reddit 风、短信风。也可以一人分饰两角做搞笑对话，或基于对话素材二创；国内博主把搞笑对话做成沙雕动画，底层逻辑一样，都是故事号。

它商业延展更强：能吃视频收益，也能做 CPS、CPA、产品推广和商单。创作门槛低，重心在素材收集。

优势：

1. 模板固定，选题可无限变。
2. 选题固定，表现形式可无限变。
3. 商业模型多，没开通收益前可接 CPA 商单撑住。
4. 剪辑简单，新手能快速理解平台、流量、规则和基础功能。
5. Shorts“三分钟内容”新规更利好故事号，未来还有空间，是潜伏的老赛道。
6. 一般不打标签，除配乐外可能只有一个标题，难采集；但找到一个两个对标号就打开大门。

难点：成长慢，要熟悉海外社媒，练采集和文案，理解文化梗；吃透后起步更快。

提醒：下面的文案训练不限制字数和对话次数，配音去气口后可能仍超一分钟。遇到就改提示词或手动删内容、对话压时长。做 TikTok 不受影响；Shorts 彻底更新后大约 12 月初或中旬，也不受影响，因为三分钟内。

# 第三步：准备解压素材

渠道：Ins、YouTube、TikTok、抖音。别买淘宝那种多少 T 的包，大多被用烂；也有实时卖的，来源仍是海外采集。解压素材很关键，高清、合格与否影响是否 0 播、是否判重。

解压类主要搜 AMSR，国内搜“空耳”。尽量用海外素材，国内很多带文字，去重麻烦，裁剪又变味；国内无字幕素材可以用。

这里找一手海外素材。AMSR 太泛，容易搜到人声；要挖细分：

Sandart：沙子艺术，San 沙子加 Art 艺术，可延伸更多领域；

XXXart：cakeart 蛋糕艺术、Woodcarving 木雕、PaperArt 纸艺、MetalArt 金属艺术；

Satisfying：令人满足愉悦，如“A satisfyingly crunchy sound”满足的脆响；

Oddlysatisfying：看似奇怪但带来满足愉悦，常有视觉或听觉特殊性，激发好奇和审美。

词一拓展就好找，不抓瞎。细分素材加混剪能去重。按这些词找，首选 INS，其次 YouTube、TikTok。

不想找也行，我整理了一批对标可练手，但可能要多混剪，因为用过了；追新发布剪：故事号素材收集库。

做好故事号，素材库不可少。把我对标号都关注一遍，慢慢刷新的，建立自己的库。

# 第四步：用 ChatGPT 协助准备文案

文案分正练、逆练。

正练：从 Reddit 找故事，浓缩或改写成 60 秒以下标准文案。

逆练：参考对标文案改写，按自己模板生成新文案。
