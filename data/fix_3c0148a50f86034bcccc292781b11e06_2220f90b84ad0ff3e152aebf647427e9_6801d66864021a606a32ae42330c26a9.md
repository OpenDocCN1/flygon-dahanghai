# 用 n8n 把海外 SEO 内容生产自动跑起来

面向海外市场的卖家、独立站操盘手，以及做出海 SaaS 的团队，几乎都会卡在同一个地方：精准的海外访客从哪里来、怎么持续来。

英文博客写了一批又一批，内容预算也没少花，可回头看数据：真正排上去的没几篇，ROI 算不过来，团队还被困在日复一日的重复劳动里。

这种“使劲了却不知道往哪儿使”的体验，做过内容的人都懂。文章并非不用心，只是没把对手的内容拆透、没能形成碾压，搜索结果的席位自然抢不到。

这篇会手把手带你拼一条 n8n 自动化流水线。只要喂给它一个词，下面四件事全自动跑完：

1. 锁定前三名对手：自动到 Google 搜这个词，把自然结果里排最前的三个拎出来。
2. 扒全文：把这三篇的完整正文抓下来。
3. 喂给大模型：把竞品稿子丢给 LLM，让它拆解、融合，再产出一篇全新的优化稿。
4. 落库：写好的内容自动进飞书多维表格，不用再手动粘。

# 2.背景：一套跑得通的 SEO 执行框架

动手配 n8n 之前，先把这套打法的思路捋清楚，顺便看看它到底补上了传统内容生产流程的哪些窟窿。

先说老办法：纯手工做内容

选定一个词之后，一般会走这么四步：

1. 找参照：打开 Google 搜这个词，挨个点开排在前面的竞品文章。
2. 拆结构：一篇篇读过去，把小标题层级、核心论点粘进文档，琢磨它们哪里像、哪里不一样。
3. 动笔：看完之后换自己的话重写一遍，心里默念要压过对手。
4. 上线：发到站上，然后干等收录和排名。

老办法的毛病很集中：慢、靠感觉、放不大。

几篇文章读下来半天就没了，而且拆得全不全、判断偏不偏，全看个人状态。更头疼的是不少站点有反爬，正文根本复制不干净。

换成 AI 工作流之后

前面说的“SEO 内容引擎”，就是冲着这些痛点来的——把那些机械的采集、比对活儿，统统交给程序和模型去跑。

# 节点 1：手动触发入口（Manual Trigger）

刚建好的画布空空如也，点一下中央的 Add first step，右边随即浮出节点选择面板。排第一的 Trigger Manually，就是所谓的手动触发器。

[PRE13]

它的角色相当于整条流程的闸门——点下 Execute Workflow，执行就从这里放行。这只是触发器家族里的一员，n8n 玩深了还会碰到形形色色的触发方式。

# 节点 2：设定种子词（Set）

接着往下接节点。点图上那个加号，右边会冒出 what happens next 面板，所有节点都收在里面。先找到 Data transformation 分类。

[PRE14]

从里面挑 Edit Fields(Set)。

[PRE15]

这个节点负责声明变量，用途是把待分析的核心词定下来，作为整条流程的起始输入。填法：Name 一栏写 seedKeyword；Value 一栏填你要打的那个词，比如 standing desk。跟图里保持一致就行。

# 节点 3：接入 Google 检索（SerpApi）

老办法检索 serapi，这是个借 Google 接口做搜索的第三方服务。头一回用，得先点界面右上位置那个安装键，装完才能调用。

[PRE16]

然后选 Google Search 这个功能节点。

[PRE17]

凡是用第三方 API 的节点，都得先配一份密钥凭证，位置见下图。

[PRE18]

先去下面的地址注册账号：https://serpapi.com/users/sign_up。免费套餐就够用，每月能白嫖 250 次检索额度。

[PRE19]

注册时记得把邮箱和手机号都验证掉，手机号填国内的没问题。然后打开密钥管理页：https://serpapi.com/manage-api-key，造一个 API Key 并复制出来。

[PRE20]

现在切回 n8n 里那个凭证创建窗口，把 Key 粘进去，点 save，看到下图那种验证通过的提示就对了。

[PRE21]

然后做节点本身的设置。功能上，它拿种子词去模拟一次 Google 查询，返回搜索结果页的结构化数据。需要填两处：Credentials 选刚配好的 SerpApi 凭证；Query（q）填引用前面 Set 节点里定的变量 {{ $('设置种子关键词').item.json.seedKeyword }}。跑一次测试，右边输出里应该能看到 organic_results，那就是 Google 查询返回的自然结果。

# 节点 4：筛出 Top3（Set）

[PRE22]

SerpApi 吐回来的东西很杂，广告、相关问题全混在一起。这个节点的任务就是做减法，只留自然结果的前三条。填法：Name 写 result；Value 填这段切取公式 {{ $json.organic_results.slice(0,3) }}，含义是截取 organic_results 数组的第 0 到第 2 项。类型那一栏千万别忘了选 Array，否则后面拆条目会报错。
