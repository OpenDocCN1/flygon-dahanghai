### 8.2.4 店铺高频疑问速答

**问：做📕店铺，怎么判断内容有没有版权风险？**

答：开店阶段，带版权的东西尽量别往上传。店铺经过实名认证，一旦权利人找上门来举报，处理起来很麻烦。

判断思路可以看这几条：第一，资料不要带水印；第二，观察同行里有没有人卖，若卖的人超过三个，这类内容通常可以尝试；第三，再给大家一张详情页可用的【免责说明】图，用来做风险缓冲。

[PRE6]

**问：店铺是不是都在拼低价？**

答：低价竞争基本避不开。做电商，在同一个平台里，你的价格至少得比同行有优势。从零销量起步，不靠价格优势，第一批订单很难撬动。

会做的人往往先在站内做比较，货比三家，不一定非要去淘宝、拼多多看，站内就能筛一轮。所以起步时价格要压得住；等销量慢慢起来，再按情况调价也来得及。

**问：虚拟资料订单发货时还要填寄件信息，怎么办？**

答：发货页面里可以选“无物流发货”，找到这个选项勾上即可。

**问：店铺号和私域号能共用一个账号吗？**

答：不建议。店铺号已经实名，店铺也绑在这个账号下面。同一个号跑两套玩法，风险不小——私域本身属于违规操作，号一旦被封，店铺也会被一起关掉。

店铺更适合承接低客单生意，前期用来赚钱过渡；私域可以另外开号去运营。

# 9.4.2 流量入口怎么理解

# 📌

流量入口可以理解为：每个入口都是一个细分赛道，像商场有好几道门。

举个例子，哪怕你的店不是整个商场最大的，但只要位置好，正好挨着某道门，你也能靠这个位置吸引更多顾客，对吧？

同理，哪怕你的内容在全平台不算最优质，那能不能在某个同城入口、某个话题里做到最优质？靠这个拿到更多曝光。

每个关键词都相当于一个流量入口。

举个例子，如果你的内容在“教育资源分享”这个大分类里排名不高，那能不能通过优化，专注到“如何为小学生挑选课外读物”这个细分领域，在这个流量入口里拿到更好的排名？

发现页：用户平时浏览、搜索、关注等行为会给账号打标签，系统主动推送相关内容笔记。所以要持续发布垂直领域内容，让系统识别账号的目标用户，从而精准推送。

同城推荐：首页右侧，定位探索相关城市，系统根据定位推送同城笔记。右下角【我】，选择笔记【右上角三个点】，点击【编辑】，可以添加任意同城地点。

关键词搜索：用户在首页主动搜索关键词，搜索结果页越靠前，越容易获得点击。

站外社交媒体：笔记被分享到🛰️、社群、🧣等渠道。

站外搜索引擎：用户在搜索引擎（比如百度）搜关键词，笔记也可能出现在搜索结果页。比如“考研攻略”，只要笔记文案里包含相关关键词，就容易被📕用户看到，从而增加浏览量。

# 9.4.3 推荐分发机制

# 💡

📕推荐机制解析

创作者在📕发布笔记，笔记通过审核后会先进入平台数据库。用户打开、刷新📕时，平台会从数据库里召回大量笔记，再经过粗排、精排和重排等算法，最终只把一小部分展示到用户主页。

召回：📕快速从数据库中取出大量用户可能感兴趣的笔记。

粗排、精排：用算法给笔记打分，从大量笔记里挑出分数最高的少量笔记。

重排：对高分笔记进行抽样，再用规则打乱顺序，最终展示给用户。

大多数情况下，粗排、精排、重排都是算法层面的事，知道了也帮不上太多忙。

真正影响运营的，是📕的笔记召回，也就是推荐。我们要搞清楚：📕按什么规则找到用户感兴趣的笔记并推荐？

1.1 笔记召回通道解析

用户打开、刷新📕后，平台会调用十几条召回通道，判断一篇笔记是否适合推荐给用户。这里挑几个比较好理解、对运营有帮助的召回通道来讲。

1.1.1 根据笔记相似度推荐

如果用户喜欢某篇笔记，📕会根据笔记之间的相似度，给用户推荐他没看过的其他笔记。

举个例子：

我喜欢看《盗墓笔记》

《鬼吹灯》和《盗墓笔记》相似

我没看过《鬼吹灯》

系统就给我推荐《鬼吹灯》

那系统怎么知道两篇笔记相似？方式有几种：

1. 看过《鬼吹灯》的其他用户，也看过《盗墓笔记》

2. 给《鬼吹灯》点赞的用户，也给《盗墓笔记》点过赞

3. 两篇笔记的受众人群重合度越高，笔记就越相似

4. 两篇笔记相似的标签越多，说明越相似（类目、品牌、关键词……）

但要注意：一个小圈子的用户同时给两个作品点赞、互动，并不能证明两个作品相似。所以把笔记转到群里让人点赞，不但不一定增加推荐，反而可能打乱标签。

1.1.2 根据用户相似度推荐

这是基于用户之间的兴趣爱好来推荐。假设A用户和B用户兴趣非常相似，A对某篇笔记点赞、转发，而B没看过，系统就会把这篇笔记推给B。

举个例子：

A和B都喜欢看盗墓题材

A看过《鬼吹灯》，B没看过

系统就给B推荐《鬼吹灯》

系统怎么判断两个用户兴趣相似？

1. 这两个用户点击、点赞过的笔记有很大重合。比如两人都经常点《盗墓笔记》或盗墓题材内容。

2. 两个用户关注的作者有很大重合。

# 📌

基于“用户相似度推荐”可以发现：当我们把目标用户确定好之后，针对用户做选题，或者把爆款选题换个角度写，就更容易拿到更大的推荐量和互动量。

1.1.3 根据作者推荐

根据作者推荐，主要有以下几种方式：

1. 用户关注了某作者，作者后续发布的笔记会优先推送给用户。

2. 用户对某篇笔记有互动，该笔记作者的其他笔记会被推送给用户。

3. A作者和B作者相似，用户对A作者的笔记互动或关注了A，B作者的笔记也会被推送。

# 📌

笔记配比：80%营销笔记配20%干货。目的是让干货笔记拉流量，因为看过干货笔记的用户，大概率还会刷到你的营销笔记。

1.2 新笔记的推荐方式

📕的笔记内容（包括文案、图片、视频、地点、话题标签等）都会作为推荐依据。前面讲的是老笔记的推荐方式，新发布的笔记数据少，没有用户点击、点赞、互动，推荐上不能只用前面的召回方式。

📕对新笔记有以下几种推荐方式：

1. 根据类目、关键词推荐

也就是根据用户感兴趣的类目和关键词来推荐。

举个例子：

我平时刷📕经常看职场类目，也常搜索职场、面试相关关键词。新笔记发布后，系统识别到笔记属于这个类目，又命中我喜欢的关键词，那这篇笔记就更可能推给我。

2. 聚类召回

如果用户喜欢一篇笔记，也会喜欢内容相似的其他笔记。这和第一点比较像。

举个例子：

假如我对一篇“裸辞创业”的笔记产生互动，平台会给我推更多裸辞创业相关内容，我有可能点开。

3. 新笔记保量推荐

新笔记缺数据，如果直接和老笔记用同样的召回通道，肯定竞争不过。所以📕对新发布的笔记一般有保量措施。

也就是说，不管笔记质量高低，都保证在一定时间内获得一定曝光。不同笔记保量目标不同，优质内容保量更多。

举个例子：

假设保量目标是24小时内曝光1000次，但12小时过去只曝光了100次，那剩下12小时就会增加这篇笔记的曝光概率。

反过来，如果目标也是24小时1000次，但前2小时就曝光了500次，那后面22小时就会减少保量曝光。有些笔记刚发布时小眼睛很多，后面突然没了，就是这个原因。

除此之外，📕还有一些差异化保量手段：

1. 优质作者会获得额外保量曝光。

2. 作者历史笔记质量高，会获得额外保量目标，但有上限。

新笔记的保量曝光是额外的，保量之外还有正常召回通道推荐笔记。

当笔记达到保量目标后，就不再被扶持，但会继续获得自然曝光，和老笔记公平竞争。

# 📌

重点：保量保的是曝光。笔记有没有人点、有多少人点，取决于内容质量——内容为王。

1.3 流量池层级划分

当笔记分数越来越高，就会被一级一级推荐到更大的流量池。

每次给完一级流量池曝光后，系统会根据阅读数、互动数等综合评分，决定要不要给下一级流量池。

最后，赞藏评总数1000+算小爆款，10000+算大爆款，不同类目会有差异。

每篇笔记送200-500曝光，但曝光不等于阅读数。

曝光数只有企业号能查，阅读数就是小眼睛。

曝光数除以阅读数大于10%，基本都算优质笔记。

特别提醒：

当笔记分数越来越高，就会被系统一级一级推荐到更大流量池，成为爆文，而这篇爆文还会带动其他笔记整体数据增长。当然，要先满足这些前提：

①笔记经过系统审核，没有违规，没被系统删除，也没被你删除或隐藏。

②笔记有关键词（比如学习、家具），对应垂直标签，被系统收录，能推荐给喜欢相应标签的目标人群。

③内容质量本身不错，能吸引用户赞藏评等互动。一般0基础新手很难第一篇就出大爆款；运营第一个月，新手笔记的小眼睛（阅读量）停在100-200都很正常，基础好的出效果会快一些。

80%新手是在第二或第三个月才迎来爆发，中间有酝酿期，所以不用太焦心，耐心打磨内容。

搜索流量：

📕用户除了逛主页，也会通过搜索找自己想要的内容。比如想考研就搜考研攻略，想出国就搜留学生攻略。

搜索排名靠前的笔记会获得更多曝光和关注。这部分流量几乎占总流量50%以上，不容忽视。想拿到搜索流量，首先笔记要包含有效关键词，且被系统成功收录；想让搜索结果排名靠前，账号权重和笔记权重都要持续提升。

# 9.4.4 检测机制

📕会检测以下内容：

账号资料：昵称、头像、简介等，检查笔记内是否有🛰️号、其他平台二维码、其他平台水印，是否诱导用户关注、领奖、点赞等。

私信：是否进行站外导流。

评论：是否诱导私信。

设备：尽量确保一机一卡一号一IP。

# 9.4.5 审核机制

# 📌

📕的审核机制和其他平台类似，主要分两种：机器审核和人工审核。

1. 机器审核

写完一篇笔记后，内容会上传到审核系统，先进行机器审核。平台根据系统规则，对敏感词、违规词、非原创图片等内容做初步审核。如果检测出违规，笔记直接审核失败，无法获得曝光。还有一部分机器判断不了的疑似违规内容，会单独处理，再转到人工审核。

2. 去重检测

第一步完成后进入去重检测。系统会把你的笔记内容和已有笔记做对比。如果重复率达到一定标准，笔记就无法通过审核。如果只是疑似抄袭、还没完全确认，一开始可能会导致限流，同样进入人工审核，由人工进一步做去重判断。

3. 人工审核

前面也提到，机器审核中疑似违规或机器检测不出来的内容，会进行人工二次审核。人工审核处理的比例不大，因为成本较高，不是所有笔记都会走到这一步。但📕特别重视的领域会特殊处理，比如电子烟目前是全面封杀，相关领域的人工审核会加严。

4. 特征匹配

机器和人工审核之后，笔记内容会进入📕系统的内部特征匹配。层层筛选通过审核的笔记，才会进入下一个系统推荐。

系统会对笔记内容做一系列分析，包括词义分析、关键词提取、关键词出现次数等，完成对整个笔记内容的特征分析。

# 9.4.6 权重机制

# 📌

很多人疑惑：同样一篇笔记，用不同账号发出来，阅读量、互动量为什么差那么多？

这涉及📕对账号和笔记的“权重”评估。影响笔记权重的因素有哪些？

1. 账号本身资料的完善度

资料完善度不只是昵称、头像、背景图，还包括关注后的回复设置等。这只是账号权重里很小的因素，但也不能缺。

提示：账号如果经过平台官方认证，权威性可能更高。

2. 原创度

原创度指整个账号发布的内容是否以原创为主，或者原创占比有多少。原创度越高，内容越真实丰富，账号权重也会越来越好。

3. 垂直度

垂直度指专注某个领域。系统会根据账号平时发布的内容打标签，专注一个垂直领域，标签会更具体，推送给的标签人群也会更感兴趣。

如果账号今天发变装，明天发宠物，后天发日常，系统无法精准定位，综合推送时流量会大打折扣。

4. 内容质量

内容质量不只是原创，还包括笔记本身的质量。什么样的内容算好内容，要通过数据评判。

比如转发、评论、收藏、点赞等数据都不错，会提升账号整体权重。

5. 账号等级

等级用各种薯来划分和命名，最高等级是金冠薯。等级越高，权重越高。但要注意，删帖或发布违规笔记会影响等级，还有被降级的风险，降级就意味着账号权重下降。

下表是📕的成长等级，完成相应任务升级，可以提高账号权重：

1. 尿布薯

发布1篇有效笔记，并且这篇笔记被点赞、收藏、评论各1次，就能获得第一个小红薯形象。

2. 奶瓶薯

发布1篇笔记获得5个收藏或10个点赞，或者发布一篇话题笔记，就能进阶成奶瓶薯。

话题笔记：就是在笔记中加“#”，选择官方发布的话题创建话题笔记。对新手来说可以多尝试，有利于提升账号权重。
