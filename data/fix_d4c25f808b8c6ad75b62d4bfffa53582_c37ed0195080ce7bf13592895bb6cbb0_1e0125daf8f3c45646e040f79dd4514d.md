# 1.2 核心玩法拆解

# 1.2.1 最小可行路径与关键节点

现阶段视频号直播的主流打法是：先用带货短视频起量，一旦视频跑出数据，立刻开播承接流量、放大成交。据此，从0到1的最小可行闭环可以概括为：定赛道—搭账号—选品—拆解爆款做视频并发布—开播带货—数据复盘—完成成交。

有几处要点值得单独拎出来说：

关于账号开通：新手起步建议准备2个号打底，条件允许的话可以做到3到5个，让亲友协助注册也行。由于素材剪辑、内容把控、平台风控等多重因素，账号被限流并不罕见，一旦触发，周期往往要一周左右。

关于视频制作、发布和开播：围绕爆款做高质量视频，是整个项目的核心动作，建议每个号每天稳定输出3到5条短视频。平台审核日趋严格，混剪时最好掺入一定比例的实拍素材，大约占四分之一到三分之一，这样原创审核通过率会更高；本次也会带大家用AI数字人做视频来提效，不愿露脸也能操作。

另外，二次混剪时要留意别让原作者真人面部大范围出镜，否则可能被投诉下架，严重时还会封号；明星、网红类的素材尤其敏感，一旦出镜比例过大，系统会触发核验提示，要求提供授权或验证材料。开播前建议先拆解同行直播间的打法，熟悉话术，再通过试播去打磨话术与直播脚本。

关于测品：每个带货账号需缴纳100元保证金才能开通选品权限，这笔费用后续可以退回。各账号每日可发布的带货视频条数，与粉丝量挂钩：粉丝不足1000的，每自然日最多发1条商品分享视频；粉丝在1000至9999区间的，每天上限2条；粉丝在1万至99999区间的，每天上限5条；粉丝超过10万的，每天可发10条。如果账号粉丝不足1000、其他视频无法挂商品，也可以在评论区引导用户前往橱窗下单。

# 1.2.2 内容推荐机制

1. 社交推荐：这是视频号生态的独特之处。系统会参考用户好友及好友圈层的发布、点赞、关注、评论、转发等互动行为，对相关视频给予优先推荐。
2. 个性化定位推荐：基于🛰️社交关系链，每位用户都会被赋予性别、年龄、职业、兴趣、城市等多维标签，系统据此从内容池中匹配可能感兴趣的视频进行分发。
3. 搜索推荐：🛰️搜一搜的关键词行为会影响推荐权重，点赞评论数据表现好的视频更容易获得优先曝光，用户搜索过的主题也会更频繁地出现在其推荐流中。
4. 同城推荐：系统会依据视频发布时的地理位置，将其推送给同城用户。这对线下商家尤其友好，可以借此提供本地化商业服务。

# 2.1 工具清单

# 2.1.1 手机号与手机设备

新手起步建议备好至少2个账号，因此需要：至少1部手机（支持多开功能或直接备多部手机）；至少2张电话卡（每个视频号对应1个实名🛰️号，也就对应1张电话卡）。

电话卡推荐：三大运营商均可办理副卡，单个身份证可注册认证5个🛰️，一拖四模式，副号月租约10元；移动万能副卡每张月租10元，一个身份证可领2张副卡，第一张与第二张需间隔90天，营业厅和App渠道都能办理，营业厅办理还可争取首年月租减免；中国电信App搜索“无忧卡”，月租5元，通常次日即可上门配送；移动另有8元保号套餐可选。

手机推荐：手机既用于登录账号，也承担部分视频拍摄任务。如果只做短视频拍摄，千元级安卓机完全够用，且安卓系统自带双开功能；若后续打算放大做直播，iPhone的直播稳定性更佳，但iPhone不支持双开。条件允许的话，也可以准备3到5个账号同步推进，投入成本相应会增加。

# 2.1.2 拍摄器材

1. 拍摄设备与软件：推荐直接用手机。当前手机像素足以应对短视频拍摄，拍摄时使用后置摄像头性能更优。担心看不到自己的画面，可以通过镜拍的方式解决。若有单反相机，画质会更上一层楼，但考虑到大多数人实际情况，后续重点仍以手机拍摄为主。拍摄软件切记不要用美颜类App，直接用手机原相机即可。
2. 提词设备与软件：可以备2部手机，1部负责拍摄、1部负责提词；也可以采用手机拍摄加电脑提词的组合。手机端可用提词拍摄或快题词，拍摄时直接看提词字幕，剪映也内置了提词器功能。iOS App Store和安卓应用商店均可下载。

# 2.2 账号筹备

# 2.1.1 账号注册、登录与维护

账号注册：按以下6步操作即可完成视频号创建。

1. 打开🛰️「发现」页，点击「视频号」。
2. 在「视频号」页点击右上角「人像」图标，进入视频号主页。
3. 在主页点击「发表视频」，进入创建页面。
4. 在创建页填写账号信息（头像、性别等），勾选“我已阅读并同意《🛰️视频号运营规范》和《隐私声明》”。
5. 如果不想让🛰️好友看到你发布的内容，关闭「在个人名片上展示视频号」。
6. 创建完成。

账号登录：可以通过双开方式，1部手机登录2个🛰️；也可以把多个视频号的运营者统一绑定到自己的大号🛰️上，之后用网页版登录这些视频号进行操作。

需要注意：若多个视频号绑定了同一个🛰️号作为运营者，该🛰️号同一时间只能登录一个视频号。举例来说，🛰️号A绑定了视频号①和视频号②，扫码登录视频号①后再登录视频号②，视频号①会被强制退出，再次登录需要重新扫码。

多个🛰️号的维护：批量注册的🛰️号容易被封，注册了2个号也要留心。🛰️养号的核心逻辑是模拟真人行为，具体可参考5个办法：完善头像、名称、背景墙等基本信息；修改🛰️号、密码、支付密码，零钱包里放几块钱；每天发2到3条朋友圈，内容长度不限；随意添加5到10个好友，每天发几条消息；每天在视频号刷视频、看直播。

# 2.1.2.2 账号包装实操

1. 账号名称

先看官方给出的【账号名称】注意事项：名称要贴合账号类型来定，一个好名字自带搜索流量。最常见的做法是相关关键词组合，比如健康、书籍、认知等。用关键词组合，别人搜索时更容易命中你。不过有些朗朗上口的名字早已被抢注，注册时多准备几个备选，逐一尝试。账号名一年最多可改5次，没灵感时可以参考各平台同类型账号的取名方式，也可以取通用名称，例如【xx-同款在橱窗】。

关于昵称修改，@麦洛提醒：昵称一年仅有5次修改机会。建议先设一个通用昵称，比如“xx-同款商品在橱窗”。简介在视频号创建完成后可以修改，路径为：视频号主页头像→右上角…→头像→简介。简介最好控制在3行文字以内，超出会被折叠。简介里可以放引导成交的内容，例如“同款商品在👇🏻下方购买”。不建议轻易放🛰️号，因为引导到🛰️成交的效率很低，精力消耗极大。

内容来源：《视频号直播建议指南》

2. 头像

一个出彩的视频号头像，能让人更容易记住你。头像可以是纯文字（名字缩写），也可以是图文形式。如果拿不准什么样的头像合适，可以搜索你定位内容下的视频号大V，参考他们的头像设置。制作方式上，可以用图怪兽等网站制作，也可以找一些无版权图片。
