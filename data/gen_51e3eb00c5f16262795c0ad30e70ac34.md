# 7.3.5 提价，其实是最有效的增长手段

这个标题乍看可能让人皱眉，但对我们来说，这条路值得冒一次险。做产品本身就是不断试错、不断冒险的过程，用不同的打法去冲击不同的增长目标。

在小众赛道里，作为产品各环节的负责人，拍板必须干脆利落，能想到的环节都值得去试、去打磨。整个提价的过程，有点像温水煮青蛙。

对已经订阅的老用户来说，影响其实不大，因为他们未必能察觉到价格变了。但对新用户而言，看到产品的安装量数据，会产生一种错觉，以为老用户也是按这个新价格在付费。

当然，决定收入的还有流失率。但流失不会因为提价就立刻发生——提价对已订阅用户没有影响，这部分属于自然流失，相对稳定。

# 8.1 招人坑 @颜过

需求还没完全想清楚，就急着去招人，而且还是跑到国外的平台上找——fiverr、upwork 这类 freelancer 平台。

有些事，只有你亲自踩过，才知道坑有多深。就拿 Chrome 插件 PDFXYZ 来说，看着不复杂，里面却有几个难点，需要有经验、或者能主动解决问题的程序员才搞得定。

而找老外做开发，你得把实现细节一条一条、1、2、3、4、5……全部拆清楚才行。否则，加上时差、再加上对方对技术框架不熟（我那些编程语言和算法套路基本都还给大学老师了），这一来一回，难度直接翻倍。

如果你打算找老外开发，一定要先把需求列细，直接让他照着实现代码就好。不然开发时间和进度会把你拖死。最重要的是，多找几个人对比，多磨合几轮，才能找到合适的。

对小型工具来说，开发周期是个大坑——拖得越久，成本只增不减。这也是一个相互磨合的过程。开发这件事，还是技术优势主导的，差一点，就真的需要花时间去磨，没有别的捷径。

# 8.2 业务流程坑 @颜过

做小众市场的先行原则：先找别人已经赚到钱的需求，再往深挖（最直接的办法是翻差评，看能不能解决这些问题），这样离变现不会太远。

有句话叫，想学会游泳，至少得先下水吧，不然动作再漂亮也没用。先行原则前面已经提过——PDF 这个大工具周边其实有很多需求，用户基数也足够大，先积累种子用户，能收到第一块钱的用户更好，再去拓展其他需求，赚钱是迟早的事。

先下水，那就先模仿，把核心需求实现，尤其是支付环节（Chrome 插件以前还有 Google Pay 的支付，现在官方支付不支持了，但可以接第三方，支付坑后面再展开讲）。

拿 PDFXYZ 这个小工具来说，核心需求，朋友 L 是用中间服务器实现的，PDF 文件基本能无损呈现（即清晰度，因为 PDF 文档要么是文字，要么是图片，还有其它格式合成的），能满足客户的真实需求。但这里面还有服务器上传下载的问题，以及文件大小的门槛（文件大，下载时间就长）。文件一大，插件体验就极差，会卡在那里半天动不了，只能限制大小，设为 10M。

朋友 Y 则直接用 js api 来实现，但文件下载下来会模糊（客户的核心需求实现还差一些）。同样也有文件上传下载的问题，不过这种文件大小限制就宽松一些，为 30M。

# 8.3 支付坑（大坑）@颜过

国外的工具或产品，除了广告变现（Google Adsense）之外，常见的变现方式还有：捐赠（Paypal）；通过分享产品等知识做 affiliate 模式（分销赚佣金）；而最直接的方式，就是直接收费。

Chrome 插件大多数情况下只能选择捐赠或直接收费。结果现在 Paypal 账号不支持国内账号的捐赠。

直接收费方式，因为 Google Pay 官方支付停了，但接受第三方支付。你直觉可能想到 Paypal，但不好意思，虚拟产品 Paypal 不支持（大概大型软件才有收款白名单）。还有其他选择：Stripe 等，但现在申请门槛极高，就算申请下来，也有被封号的风险。

现在收款，先试的是 Sendowl（可以再转 Paypal，目前测试结果，几十美金通过 Sendowl 付款链接，Paypal 是直接到账的）。

因为 Sendowl 是 web 端网页支付，插件端需要有个支付回传（webhooks），确认用户已经支付成功。不做登录的话，可以给本地生成一个唯一标识 Key，用户付款后就生成一个标识 Key，保存到数据里（或者用户本地电脑缓存）；另外最好手动或自动再给支付邮箱发一封邮件，把 Key 发给用户。如果用户卸载了，可以用这个 Key 来识别。

另外插件内是不支持回传确认的，如下图，就会卡死在那里，因为没有回传确认是否支付成功。朋友 Y 是直接单独新开一个浏览器标签页，让付款用户通过 Sendowl 网页链接付款。

# 8.6 一直失败怎么办 @刘小排

答案是：挺好的，你需要提高失败的速度，然后继续尝试。

我很喜欢玩德州扑克。

最早的时候，我觉得它是个数学游戏，获胜诀窍是“计算概率，只在赔率合适的时候下重注”。

一年后，我发现算概率只是入门基础，大家都会算。我开始认为诀窍是“meta game”——通过察言观色等方式发现隐秘线索，从而精准读出对手的牌。

https://www.thepokerbank.com/strategy/psychology/metagame/

又过了两年，我才意识到，诀窍其实是“Mental Game”。在长时间内保持情绪稳定，才是最重要的。

https://howtoplaypokerinfo.com/poker-mental-game/

而要做到情绪稳定，你需要“打无记忆的牌”。

有人因为连续输了几把冤家牌就变得急躁；还有人以为连续赢了几把，手就松了，不把筹码当筹码了——这都是业余玩家最常见的错误。

你改变不了已经发生的事，无论好坏。你也改变不了这一手拿到的牌，无论好坏。我们唯一能决定的，就是忘记过去，不怨天尤人，把当前这手牌打到最好。

这和做产品的过程何其相似！

有人因为做成功了一些产品就飘了——这很常见。你能说出几个连续做了多个产品、连续获得多次成功的人的名字？不多吧？就像某些 rapper，还没出名的时候能写出很好的作品，等成名了、换了大房子，就再也写不出好作品了。

还有人因为连续做失败了一些项目，对自己的评价就变了，甚至抑郁了——这也很常见，龙哥盟里不少圈友就是这样。

他们都没做到“打无记忆的牌”。

所以，如果你连续做了好几个产品、好几个项目都失败了，应该怎么办？你应该从失败中学习，然后继续尝试，就像 Peter Levels 一样，就像职业德州扑克选手一样。

4）及时蹭上热点阶段

这时候主要还是在📕发布帖子、在即刻发布帖子，在自己的帖子引流，并且在评论中置顶网址链接（不是直接的网址，就是产品名），在别人的帖子截流。然后我会通过直接问找来的用户、通过百度统计访客来源这两种办法来判断用户的来源，发现这些渠道引流确实有效。

在 2 月 10 日之后，ChatGPT 的热度突然高涨，朋友圈刷屏、👸号推文刷屏。我关注到了这个异常值，且发现当时类似网站很少，于是我复制页面赶紧做了一个 ChatGPTHelper，主要解决好多人不知道 ChatGPT 是啥、但又想尝鲜体验的需求，蹭下热度，然后在即刻发了帖子推广。

5）思考流量变现阶段

因为流量增加得比较稳定、比较少，让我没有动力思考变现，就想着自动化赚点谷歌广告费就行，为爱发电。但流量大了之后我的网站经常卡，我要用更多服务器、更多账号，就有了成本，并且我也希望网站能帮助更多人。

有了想变现的想法，于是我的注意力就放在了倾向于能帮助我变现的内容或思路上。

我尝试了下面几种变现：

① 推广别家的产品赚分佣

② 分销别人的 AI 内容专栏赚分佣

③ 自己写专栏赚知识付费

④ 私域变现

⑤ 源码出售

目前的成果单日最高变现 1k+，但现在已经不行了，热度已经下降，并且 ChatGPT 的应用产品越来越多，能直接登录官网使用 ChatGPT 的人也越来越多，泛流量的需求已经被更多竞品或官网分散、承接。

6）回归长线，专心做产品，铺流量阶段

目前基于 ChatGPT 的应用开始慢慢出现，也慢慢看到不少同质化的，但细分场景的还不是很多，这就是机会。

① 持续做细分产品，例如基于 ChatGPT 能力的翻译、口语练习、语法润色、周公解梦、生成情侣昵称、起名、周报生成器、自动化测试脚本生成器、SQL 生成器、一键总结视频概要、智能客服 SOP 机器人等等；

② 关注细分产品用户群体；

③ 持续做 SEO 基建，流量还是很重要的；

7）碰到了哪些困难？

① 产品形态问题

曾经纠结了一阵到底是做 APP、小程序、谷歌插件、网站，但最终还是【完成大于完美】，决定先完成快速上线再说。

② 变现问题

流量变现分销专栏，前期效果好，后面效果差，因为网站的新老用户访客需要测试、定期换品；

③ 专栏问题

我认为自己写专栏不太建议，因为容易让自己陷入交付牢笼，并且占用很大精力去售前售后维护；可以分销别人的专栏；

④ 流量问题

目前只做了主关键词的 SEO 基建，长尾词的流量一直没做，需要持续去铺。

# 案例二：通过 ChatGPT 开发上线 Chrome 插件 @易焘

3 月份，我第三次参加英文工具站航海，终于在 ChatGPT 的帮助下上线了第一个 Chrome 插件，实现把 ChatGPT 对话记录以 HTML、TXT、PNG 和 PDF 多种文件格式保存到电脑本地，不需要分享或保存在线上而担心对话记录泄露。同时，还让 ChatGPT 实现了一个 WordPress 插件 API，给 Chrome 插件加载远程站点的指定文章列表。
