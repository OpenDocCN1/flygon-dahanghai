# 4.2.2 借 AI 与乘风词包挖选题

去年📕力推的乘风，是站内电商推广工具。它为何能用来找选题？因为它有通投和搜索两种投放方式，卖家可以买词投放笔记。举个例子：你做雅思考试领域，就能投“雅思备考”“十天雅思备考”等词，让用户搜相关词时看到你的笔记。

乘风后台有个【推荐词包】功能。搜“雅思备考”会出现不少词包，下载点开能看到具体关键词和类别，如竞争指数、月均搜索指数、市场出价。月均搜索指数与市场出价正相关：搜索指数越高，市场出价越高，说明用户搜索意愿越强。

[PRE8]

这个词库能反映用户搜索倾向。但自己分析很难得出有用结论，多数人缺乏抽丝剥茧的能力。于是可以让DeepSeek帮你找潜在选题红利，用关键词倒逼选题。

具体怎么做？先把词库发给DeepSeek，让它思考、总结、分析。

声明一下：我给的策略和提示词并非最佳玩法；DeepSeek已很聪明，不必用繁杂提示词限制它的想象力。

我的第一个提示词是：请根据这份文档给出20个选题方向、20个包含热门搜索词的标题，并说明选题理由及覆盖的核心关键词。

[PRE9]

DeepSeek的思考过程很有干货：它指出高搜索词流量大但竞争激烈，可搭配长尾词降低难度。更惊喜的是，它不仅给公式，还给出正文写作方法，如【高搜索词】+【人群/场景】+【长尾词】，并教我在正文中合理嵌入高价值搜索词。

[PRE10]

如果觉得结果不够丰富，可让它继续给更多公式和写作技巧。

[PRE11]

总体看，它既能给选题，也能告诉你正文怎么写。思路是：让DeepSeek分析关键词、扩展选题、提前布局搜索流量，这能有效避免选题枯竭。以上是具体操作流程和玩法。

DeepSeek还有一个隐藏玩法：它已经足够聪明，那为什么不直接问它——我们该如何向你提问，才能更高效地利用你？于是，DeepSeek告诉我该如何向它提问。

# 第三步：打造爆款标题

# 4.3.1 杂交标题法

这里要感谢袁隆平爷爷：把不同优质水稻杂交，能育出超级水稻。方法很简单，效果却立竿见影；我的爆款标题就是这么来的，堪称流量密码。

比如搜“纪录片”—最热，翻看前十笔记，会发现关键词就那几个：央视推荐、绝了、建议收藏。最热前8个里，有6个标题几乎一样——爆款都是重复的。直接抄关键词并不断排列组合，杂交出的标题自带爆款基因。

小建议：平时刷到爆款标题就记到笔记里，多翻多看，提升网感。

[PRE15]

# 4.3.2 二极管标题法

基本原理：人本能偏爱最省力法则和及时享受；动物基本驱动力是追求快乐、逃避痛苦，由此衍生正刺激和负刺激。

标题公式：

正面刺激=产品或方法+只需1秒（短期）+便可开挂（逆天效果）。小学语文类目最火：“死磕这x页纸，考试就像抄答案”。

负面刺激=你不xxx+绝对会后悔（天大损失）+紧迫感。比如“你不看这个文章就会错过一个亿，限时删除！！！”。

抖音上大部分文案都是这个套路，说白了就是制造焦虑，有点损，但用户吃这套。它利用的是厌恶损失和负面偏误心理：原始社会得到一个机会可能只是多吃几口肉，但一个失误可能葬身虎口，自然进化让我们对负面消息更敏感。

# 第四步：制作笔记封面与内页

# 4.4.1 排版基本原则

# 4.4.1.1 三要点

给零基础作图的小伙伴几个要点：封面排版牢记三条。

第一，封面尺寸：竖屏用3:4，方形用1:1，横屏用4:3。竖版笔记屏幕占比更大，能在用户视野里停留更久，既传达更多信息，也相对更不容易被划走。

第二，精准选图：视觉冲击力强的高颜值配图（可用AI生成）；简单明了的手写类型（可简单手写）；适合合集、美食、旅游攻略等。

第三，简要文字：📕笔记标题只限20个字符（emoji占1～3个字符）。想补充更多信息，就要用好封面。用户在发现页浏览时是茫然的，此时字体要在核心部分占据足够画面，概念清晰，直击用户需求，告诉用户“这篇对你有价值”，让用户产生点击冲动。

# 4.4.1.2 二少原则

二少原则：少变、少用。

第一，少变：不要频繁更换封面版式，尽量模板化、可替换化，排版、字体、风格保持一致（颜色可在同色系内变换），保证主页整齐，也方便粉丝辨认你。

第二，少用：少用不相干的贴纸，以免喧宾夺主、分散用户注意力。

# 4.4.2.1 截图

截图是作品最简单的呈现方式。

怎么解决截图同质化？很简单：
1.自己截图发；
2.给作品加边框等，调节图片参数；
3.把文件内容复制到AI软件，让AI重写一个相似版本，再截图，完全是一份新文件；
4.打印出来，拍打印作品。

以上方案都建议采纳。并且，如果某个素材在你的账号爆了，就换个方式再表达一次，让它在你账号达到二次爆的效果。谨记！！！
