# 3.3.2.5 借助 ORM 在 Python 中快速操作数据库 @大铭

在 Python（或其他编程语言）里，ORM 框架能帮我们轻松打理代码数据与数据库之间的对应关系。

先解释 ORM

ORM 即 Object-Relational Mapping，中文叫对象关系映射。使用 ORM 后，程序直接操作对象（class）即可，不必再面向数据库写操作。所有底层数据库动作由 ORM 代为完成，便利性大增。

ORM 带来的好处

1. 写代码更高效：减少了拼装 SQL 的工作量，尤其是面对复杂查询条件或数据库兼容性要求时，优势格外明显。

2. 维护起来更省心：平时只需处理程序中的对象，不用整天和 SQL 语句纠缠；同时多数 ORM 自带防 SQL 注入的机制，安全多一重保障。

3. 数据库选择更自由：本地开发能上 SQLite 这类轻量库，部署到生产环境又可换成 PostgreSQL、MySQL 等更合适的选项。

Python 里常见的 ORM 框架

SQLAlchemy：堪称最强大、最灵活的 ORM 之一，具备完善的数据库抽象层，兼容 MySQL、PostgreSQL、SQLite 等主流关系型数据库，还能在它们之间平滑迁移。

Django ORM：Django 框架内置的 ORM，在 Django 生态里使用非常顺手。

Peewee：轻量级代表，以简单好用闻名。它不如 SQLAlchemy 那般功能庞大，处理小型项目或低要求的数据库操作绰绰有余。

# 3.4 代码管理入门

代码管理通常出现在复杂项目或多人协作的场合，这里仅做概念性的简单介绍，权当开个头，大家可继续深入。

1. 代码管理是什么、有什么用

代码管理也叫版本控制，是一套记录文件内容变化轨迹的系统，方便日后查看任意指定版本的改动。不妨想象写书：每次修改后单独存一个版本，无论何时都能翻回旧稿。代码管理给程序提供的正是这种能力。

用途：
追踪改动：每次变更都有据可查，清楚谁在什么时间动了哪里。
多人协同：大家可以在同一项目里并行作业，互不干扰。
备份回滚：代码一旦出错，可快速退回到先前的稳定状态。
分支探索：大胆试验新想法，不影响主线的稳定。

2. 常见的代码管理工具

代码管理工具数量很多，最主流的当属下面几个：

Git：目前应用最广泛的版本控制系统，几乎所有语言和平台都对其提供支持。
SVN（Subversion）：曾经颇为流行，但现在使用热度明显不如 Git。
Mercurial：与 Git 定位接近，通常被认为更简洁，不过用户基数相对小。

后面两个了解一下即可，直接投入时间学 Git 就好。

3. GitHub 怎么用

GitHub 是建立在 Git 之上的代码托管平台，除了管理代码，还附带一系列协作能力，例如 bug 跟踪、功能申请、任务看板、Wiki 文档等。

基本操作流程：
1. 建账号：前往 GitHub 官网完成注册。
2. 建仓库：在平台上创建项目仓库。
3. 克隆仓库：把远程仓库复制到本地机器。
4. 提交变更：在本地改完代码后，先将变更录入本地仓库。
5. 推送到 GitHub：随后把本地提交推送到远端仓库，完成同步。
