# 8.6.3 广告投放：四步开跑

流程其实不复杂，按下面四步走就能把计划搭起来。

第1步，先登录广告后台，创建新计划。投 App 就选“App Promotion”，投 Web 则选“Traffic”或“Sales”；刚入门可直接用“Advantage+ app campaigns”，想自己研究细节就按常规“App Ads”来。

[PRE1]

第2步，进入 Ad Set Level，选中此前绑定好的 App。地区设置建议切到“People Living in this Location”。比如定位近期居住在美国、18-35岁、喜欢摄影但对柯达胶卷不感兴趣的女性，还能补充 Beauty 等兴趣词，这类人群就很适合推图片编辑应用。

[PRE2]

[PRE3]

第3步，设置出价、优化目标和版位，这里多讲两句。Meta 的优化能力可以分三层：安装、付费事件、ROAS。建议别一口吃成胖子，先跑安装，攒够数据再跑事件，最后再冲付费。

预算和出价上，可先用 Lowest Cost 自动出价，拿 10-20 美金试水；跑完拿实际数据对照预期 CPC、CPA。若偏差太大，就在现有结果上找一个能接受的出价（通常*0.85 问题不大），切到 Bid Cap。这样量级可能少一些，但买量成本更可控。

再补充一句：不管产品是 IAP（内购）、IAA（广告变现）还是混合变现，每个产品都有自己的盈利模型，也就是单个用户能赚多少，这件事在投放前就该算清。你想赚多少，其实会决定你的出价：从 LTV 里扣掉目标利润，剩下的才是买量预算。若这块很薄甚至为负，就要想想商业模型是否成立——没有买量空间的模型本身就不成立。

版位上，Audience Network 可以先不勾，它属于 Meta 三方流量，等缺量时再打开。

第4步，最后选主页和素材。文案可以让 ChatGPT 来写，素材图的 prompt 也能交给它，再拿去用 AI 生图，完全没问题。找灵感可以去 Facebook 官方广告库：[`www.facebook.com/ads/library/`](https://www.facebook.com/ads/library/)（PS：广告库也开放了 API 哦～）
