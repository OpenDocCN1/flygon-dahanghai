# 3.1 怎么用 AI 学编程 @乔帮主

用好 AI 的关键，几乎全押在提示词上面。有哪块知识不明白，就通过提示词让 AI 给你解释，一直讲到你会为止。

提示词质量越高，AI 的辅导效果才越有保障。所以这里先给大家一套好用的提示词模板。除了 Python 之外，用它学其他学科也完全通用（点【附件页面】复制模板）：

背景：把来龙去脉讲明白，AI 才能理解你提问的动机和场景。

目标：描述你希望 AI 完成的事情，最好具体、可衡量，AI 才知道往哪里使劲。

结果：对 AI 回答的风格、格式、内容给出约束，让输出更贴近你的期待。

不过要认清一件事：AI 是“遇强则强、遇弱则弱”的工具。想让它协助你深度学习某个领域，前提是你对这个领域已经比较熟悉，甚至达到精通，否则很难使唤得动它。

不然，你和 AI 之间的对话很可能一轮就结束了——因为你手里没有足够的知识去翻译成提示词。就拿爬虫提示词来说，如果你对爬虫整体知识掌握得很浅，根本写不出从 0 到 1 的需求描述，更不可能驱动 AI 帮你完成代码。

当然，不用焦虑。这次航海项目里的绝大多数参与者都是零基础，通过本章学习，你既能拿下代码的基本功，也会掌握让 AI 写出产品工具程序的完整思路。

# 3.2 用 AI 吃透 Python 基础语法

# 3.1.1 Python 语法全景

英文是你和世界对话的语言，编程是你和计算机对话的语言。只要是语言，背后就有一整套语法规则，而编程语法的难度远在英语之上。

Python 语法又被分成基础语法和高级语法，全部啃完需要 3～6 个月，学习门槛确实不低。考虑到 21 天航海时间有限，我们集中火力攻基础语法。

# 3.1.1.1 基础语法地图

这一章的内容清单如下：

- 基础语法介绍：标识符、关键字、缩进；表达式、控制流语句、赋值语句；输入/输出之间的数据交互。
- 注释：单行注释与多行注释；利用注释提升代码可读性。
- 基本运算和变量：变量的声明与数据类型；四则运算、比较运算、逻辑运算。
- 控制结构：条件语句与循环结构。
- 数据类型：数字、字符串、布尔型、列表、字典、元组、集合。
- 函数：函数的定义与调用，参数和返回值的使用。
- 库的使用：用 import 加载标准库或第三方库；示例包括 math、os、sys。
- 文件操作：文件的打开、读取、写入、关闭；用 with 简化操作；常见文件处理模式与技巧。

# 3.1.1.2 基础语法速览

【基础语法】

这组内容是 Python 编程的根。它们解决的是“如何把代码写对、如何借助语言元素完成逻辑”的问题。把基本语法元素和语句结构理解到位，你就能写出简洁可运行的程序，也能逐步应对真实场景，为后续更高级的编程能力做铺垫。

【注释】

注释就是在代码里写解释性文字，帮助自己或他人理解和维护代码。它不会被执行，仅仅给人看。

【基本运算和变量】

这部分教会你声明变量，以及完成加减乘除、大小比较和逻辑判断等操作。它们是任何程序都无法绕开的底层动作。

【控制结构】

条件语句和循环结构，让程序可以按条件分支，也可以重复执行某些动作。这是程序变得聪明、灵活的关键设计。

【数据类型】

数字、字符串、布尔值、列表、字典、元组、集合等不同类型，是为了让你更高效地存储和处理信息。功能复杂的程序，都建立在它们之上。

【函数】

把重复的代码段封装为函数，可以让代码更干净、更易维护；配合参数和返回值，还能提升代码的灵活性和复用性。

【库的使用】

借助 import 把标准库、第三方库引进来，就等于直接调用别人已经造好的轮子，很多棘手的功能都能轻松完成，编程效率也随之大涨。

【文件操作】

文件读写让程序可以把运行过程中产生的数据保存下来，也可以从外部读入数据。掌握打开、读取、写入、关闭，再学会用 with 简化流程，文件管理的基本功就到家了。
