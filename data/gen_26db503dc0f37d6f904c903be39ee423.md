Trae 近期开始支持 MCP 功能，可以从官网下载使用：Trae - AI 原生 IDE。

# 1.5.2 配置 MCP

启动 Trae。

```bash
uv venv
uv pip install -e .
```

```bash
uv run excel-mcp-server sse
```

进入 MCP 面板。

```bash
# Bash/Linux/macOS
export FASTMCP_PORT=8080 && uv run excel-mcp-server sse

# Windows PowerShell
$env:FASTMCP_PORT = "8080"; uv run excel-mcp-server sse
```

点击添加，就能看到 Trae 提供的 MCP 市场。如果想配置自己编写的 MCP 服务，则选择手动配置。

```json
{
  "mcpServers": {
    "excel": {
      "url": "http://localhost:8000/sse",
      "env": {
        "EXCEL_FILES_PATH": "/path/to/excel/files"
      }
    }
  }
}
```

```json
{
  "mcpServers": {
    "amap-amap-sse": {
      "url": "https://MCP.amap.com/sse?key=您在高德官网上申请的 key"
    }
  }
}
```

选择原始配置后，会打开一个 MCP.json 文件，在这里填写服务配置即可。

      }
    }
  }
}
```

其中 `http://localhost:8000/sse` 换成你的服务地址，`/path/to/excel/files` 换成授权目录。

```
