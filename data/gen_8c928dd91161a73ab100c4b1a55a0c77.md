# 五、ChatGPT API 开放，开发更轻了

3 月 1 日，OpenAI 在官方渠道确认，ChatGPT API 现已正式对外开放。对开发者来说，这相当于多了一条捷径：不必从零研发类 ChatGPT 产品，也能借助接口把 ChatGPT 和 Whisper 模型嵌入自家应用、工具或服务，完成二次开发与落地。

价格是这次开放中最抓眼球的部分。按输出量算，100 万词收费 2.7 美元，折合约 18 元人民币；在现有语言模型中，这样的价格明显更低。与 GPT-3.5 相比，成本更是直降 90%。

因此，无论企业团队还是个人开发者，都能以更小代价把 ChatGPT 能力接入自己的项目。AIGC 时代里“人人都有 ChatGPT”的设想，或许正从愿景走向现实。
