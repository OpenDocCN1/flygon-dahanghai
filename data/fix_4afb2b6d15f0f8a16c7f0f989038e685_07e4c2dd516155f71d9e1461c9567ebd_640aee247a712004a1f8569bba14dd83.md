### 03. 本关收束

Hermes Agent Profile 可以理解为：把岗位说明与工作流嵌进智能体的决策入口，让它在每轮任务启动前先过一遍操作手册。

初版 Profile 不必追求完美。它更像一份会持续更新的岗位说明书：先让智能体完成首轮真实任务，再根据输出补规则、补标准、补异常处理。先启动，再迭代，比一开始就追求 100 分更实际。

**核心四个动作：**

1. 建立 Hermes Profile：拿关卡 2 的一句话岗位定义，单独开一份配置，给智能体明确的身份入口。
2. 写清身份：把岗位卡里的“我是谁、负责什么、不碰什么、验收标准是什么”落进去。
3. 补流程与判断标准：把关卡 3 的工作流、MUST / SHOULD / MAY、失败处理和人工兜底写入。
4. 检查缺项：请 Codex 核对质量标准、自检规则、异常处理是否缺失，先补关键部分，不必一次写全。

完成后，智能体就拥有了“岗位说明书 + 工作 SOP + 判断规则”。下一关会沿这份 Profile 继续推进：接入工具与执行环境，让它从“知道怎么做”走向“真的能动手”。
