# 【更新】9. 篡改猴脚本：单篇笔记上传多维表格

[PRE0]
先把第三个脚本装好。

[PRE1]
在电脑上打开某篇笔记，让它保持在最前端；这时点一下“提取数据”按钮，这条笔记的信息就能被抓取下来。

[PRE2]

[PRE3]
单篇笔记也能沿用前面的思路，再做一个脚本把数据推送到多维表格；当然，换别的方式提取信息也可以。下面介绍另一种做法。

在刚才的多维表格中新增一张数据表，名字叫“单个笔记数据”。

[PRE4]
再新建一列，列名设为 JSON，格式选文本。把之前复制到剪贴板的 json 内容粘贴进这个单元格。

[PRE5]
将第一列的名称改为“标题”，然后从字段捷径里找到“信息提取”，让它以 JSON 列为依据抽取 title，并设置为自动更新。

[PRE6]

[PRE7]
这样一来，只要 JSON 列里有内容，第一列的标题就会自动把其中的 title 提取出来并填进单元格。

[PRE8]
用同样的方式，还能把你想展示的字段都提取出来，例如喜欢数量、收藏数量和评论数量，并设为自动提取。于是只要 JSON 列有新信息进入，AI 就会按照设定自动提取对应信息。

[PRE9]

[PRE10]
# 第一步：
新建一张数据表。列字段的名称和格式要设置好，确保与 JSON 中要提取的字段名、类型完全一致。共 11 个字段，名称和格式如下：

note_id：文本

url：文本

title：文本

content：文本

author：文本

user_id：文本

likes：数字（整数）

collections：数字（整数）

comments：数字（整数）

tags：文本

scraped_at：文本

[PRE11]
# 第二步：
在篡改猴脚本中新增一个“单篇笔记上传到多维表格”的脚本。

[PRE12]
脚本内容如下。记得把“认证四件套”替换成你自己的应用和表格信息。

APP_ID: '替换成你的 app id',
APP_SECRET: '替换成你的 app secret',
APP_TOKEN: '替换成你的app token',
TABLE_ID: '替换成你的新表的table id'
