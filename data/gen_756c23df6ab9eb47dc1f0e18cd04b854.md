# 4. VS Code：写代码与 Claude 协作的主窗口

VS Code 是一款功能齐全的代码编辑器，也就是你日常写代码时使用的软件。它会成为你与 Claude 配合、编写代码以及管理项目的主要界面。

小提示：请根据自己的操作系统，翻到对应章节准备环境。

# 2. 安装 Python

先打开 Python 官网：https://www.python.org

[PRE0]

进入网站后，把鼠标移到顶部导航里的 Downloads。此时你会看到“Download for macOS”字样，下方有一个“Python xx.xx.xx”按钮，点它就会开始下载安装包。

[PRE1]

安装包下载好后，双击即可启动安装。

# 2.1 macOS 安装

[PRE2]

在 macOS 上安装很省心，基本一路点“继续”就能完成，环境变量也会自动配置好。

[PRE3]

安装结束后，按 Command+Space 调出聚焦搜索，输入“终端”并打开。

[PRE4]

在终端里执行 python3 --version，检查 Python 是否装好。

[PRE5]

如果终端返回 Python 和版本号，就说明安装成功。

# 2.2 Windows 安装

进入官网后，下面两种方式任选一种。

方式一：将鼠标悬停在“Downloads”标签上，页面会出现下载入口，点击灰色按钮即可开始下载。

[PRE6]

方式二：点击“Windows”进入详细下载页。在这个页面里，你可以选择 Intel 版本或 ARM 版本。

[PRE7]

Windows 的安装只多一个关键动作。打开安装包时，务必勾选底部的“Add Python to PATH”，否则后面验证时系统可能找不到 Python。

[PRE8]

两种安装方式选一种即可。装完后按 Win+R，输入“cmd”并执行，就能打开终端。

[PRE9]

在终端输入 python --version，即可确认 Python 是否安装成功。

[PRE10]

# 3. 安装 Node.js

Node.js 的安装思路相同。先访问官网：https://nodejs.org/

打开后点击页面上的 Get Node.js，进入下载页。

[PRE11]

进入下载页后，不建议普通用户使用上面的命令行安装方式，操作会麻烦一些。往下拉，找到一键安装包更省事。

# 3.1 macOS 安装

Mac 用户要注意芯片：M 芯片选 ARM64，Intel 芯片选 x64。然后下载 installer 安装包。

下载完成后直接安装，过程同样简单，一直点“继续”即可。

[PRE12]

到这里，Node.js 就装好了。

# 3.2 Windows 电脑安装

Windows 电脑一般选 x64（64 位系统）。如果电脑很老，比如内存不到 8GB，才考虑 x86（32 位系统）；其余情况都选 x64。选择后下载 .msi 安装文件。

下载完成后直接点击安装，进入安装界面。Windows 上也是一路继续。

安装结束后，和验证 Python 一样打开终端，输入 node -v 后回车。

再强调一次终端打开方式：

Windows：按 Win+R，输入 cmd 后回车。

macOS：按 Command（⌘）+空格打开 Spotlight，输入“Terminal”或“终端”后回车。

[PRE13]

如果正常显示版本号，说明 Node.js 安装成功。

[PRE14]

# 4. 安装 Git

要用 GitHub 管理代码，先得安装 Git。

进入 Git 官网：https://git-scm.com/downloads

[PRE15]

按你的系统选择下载：Windows 下 Windows 版，Mac 下 macOS 版，Linux 下 Linux 版。页面会根据系统给出对应安装方式。例如 macOS 通常用 brew 安装，Windows 则直接下载安装包。

# 4.1 mac 安装

Mac 需要先装 Homebrew。打开 Homebrew 官网：https://brew.sh/，点击命令行右侧的复制按钮。

[PRE16]

[PRE17]

打开终端，粘贴刚才复制的命令并回车。按提示输入开机密码并回车，再确认安装并回车，之后就会开始安装或升级。

[PRE18]

稍等片刻即可完成。接着在终端输入 brew install git 并回车，过一会儿 brew 会提示 Git 安装完成。

[PRE19]

想检查电脑上有没有 Git，或确认是否装好，直接在终端执行 git --version 并回车。看到版本号就表示成功。

[PRE20]

[PRE21]

# 4.2 windows 安装

进入 Windows 安装界面后，根据电脑型号选择版本。绝大多数 AMD 或 Intel CPU 都可以直接选 x64；如果不确定选哪个版本，可以问 AI。

下载完成后一路点击“下一步”安装即可。注意，到选择组件页面时，如果不知道选什么，全选最稳妥。

装好或检查电脑是否已有 Git，打开终端输入 git --version 并回车。看到版本号就说明安装成功。

[PRE22]

[PRE23]

# 5. 安装 VS Code

接下来安装 VS Code。先打开官网：https://code.visualstudio.com/

然后点击页面中间的 Download for xxx。Windows 电脑会显示 download for windows，Mac 电脑会显示 download for macOS。

[PRE24]

看到对应页面后，VS Code 就会自动下载并进入安装流程。

# 5.1 mac 安装

macOS 的安装相对简单。打开下载内容后，你会看到 VS Code 启动包，把它拖进“应用程序”文件夹即可。

注意！一定要拖进“应用程序”文件夹，不要直接打开，否则可能遇到权限问题。

[PRE25]

如果在个人收藏里看不到“应用程序”，可以在设置中调出。

[PRE26]

先打开访达，在状态栏点击“设置”。

[PRE27]

在访达设置里勾选“应用程序”，这时就能在访达中看到它。然后把 VS Code 拖入应用程序文件夹。

安装完成后，在桌面或启动台找到 VS Code 并打开。界面出现后，安装就完成了。

小提示：第一次使用 VS Code 时，它可能引导你按指南配置。你可以跟着做，也可以先不管，通常不影响使用。

# 5.2 windows 安装

Windows 下载完成后，按提示直接安装，一直点“下一步”即可，尽量装在系统盘。

默认选项里注意把“添加到 PATH”勾上，不过它一般默认已勾选。为了让环境变量正常生效，安装完成后建议重启电脑。

1. 安装 Claude Code

安装 Node.js 时，npm 会自动装好。Mac 电脑先确认 npm 可用，然后就能安装 Claude Code。Windows 电脑目前 Claude Code 已完整支持，因此不再推荐使用 WSL，而是建议安装 Git 后指定环境变量。

# 1. MAC 电脑安装

打开终端，输入 npm -v，测试 npm 是否正常。

[PRE28]

如果显示 npm 版本号，说明 npm 装好了。接下来安装 Claude Code。

在终端输入 npm install -g @anthropic-ai/claude-code 并回车。

[PRE29]

如果下载较慢，可以在命令后加镜像参数：

npm install -g @anthropic-ai/claude-code --registry=https://registry.npmmirror.com

[PRE30]

等待一段时间后，Claude Code 会完成安装。输入 claude -v 并回车。如果能看到 Claude 版本号，就说明安装成功。

[PRE31]

注意：安装时如果提示 permission denied，请输入 sudo npm install -g @anthropic-ai/claude-code，然后输入开机密码并回车。

[PRE32]

[PRE33]

# 2. Windows 电脑安装

打开终端，输入 npm -v，检查 npm 是否正常。

小提示：npm 是 Node.js 的软件安装中心，通常会在安装 Node.js 时一并安装。

[PRE34]

如果页面显示 npm 版本号，说明 npm 可用。接下来安装 Claude Code。

在终端输入 npm install -g @anthropic-ai/claude-code 并回车。

[PRE35]

如果速度较慢，可以加上镜像参数：

npm install -g @anthropic-ai/claude-code --registry=https://registry.npmmirror.com

[PRE36]

等待安装完成后，输入 claude -v 并回车。看到 Claude 版本号，就代表 Claude Code 安装成功。

[PRE37]

至此，Claude Code 就安装好了。

如果你解决不了充值和网络问题，也可以选择国产替代方案。下面是简单的优劣势对比。
