# 案例六：PDF 小工具，先动手跑通第一笔付费 @颜过

选细分市场，和跨境选品挺像：新手常觉得全靠运气，可你真正做出第一个小产品，手感自然就来了；要是每天只想不做，大概率等不到“然后”。

这次挑小工具，我也绕了点老路。起初摆在面前的是电商类小工具、wp+woo 小工具两条大方向，看似宽阔，其实没法马上动手；再加上开发人员怎么选，又耗掉不少时间（后面再细说）。

后来，一位在美国做物流的朋友提了个 PDF 相关的小需求，最后付费也来自这里——两笔 49.99 美金，半买半送。金额不算多，但至少是正向反馈，这一点最要紧。后续相关的 PDF 需求 PDFXYZ（名字先按下不表，后面会公开，因为它上架有一阵了），我也会免费送她整套小插件使用。

[PRE0]

最终锁定 PDFXYZ 这个细分需求，还有几个原因值得琢磨，尤其适合想切入新市场、找个细分点快速试水的人：低成本跑通全流程，先完成再完美。另外，deadline 的倒逼也很关键——做小众产品或市场，开发一拖，各种成本就上来了。

PDF 需求在 GitHub 上还能找到相关实现源码，虽然用的是其他语言，但复用到 Chrome 插件里没问题，等于拿现成轮子来用，进度自然快不少。

PDF 各类需求在海外市场很大，随手 Google 一下，搜索结果有 250 多亿。软件本身有边际效应，前期做出来后，后续维护花不了太多成本。做这个需求，也是想先试水 Chrome 插件市场，同时为 PDF 需求积累第一批种子用户。周边可拓展的需求太多，每个子功能都能做成一个小工具，慢慢形成小工具矩阵（是不是有点跨境多账号的味道了）。
