# 👸号+📕半自动发布：收尾配置

内容生成跑通之后，剩下要处理的是版面、配图和发布链路。下面从画板排版开始，一路接到飞书多维表格。

**画板与封面排版**

画板里的文本引用顺序是：先取大模型_1 的出参 t3，接着放 t4，然后再引用一次大模型_1 的出参 t4。进入编辑画板后，对照排版总览来摆位置。

画板比例选 A4 竖，按钮按图中顺序点击即可。接着添加本地背景图：点图片按钮，上传一张本地图片。素材里附了现成图，直接用也行；不合眼缘就自己上网找图或动手做。封面在📕里分量很足，能看到这一步，说明排版你多半已经会了，干脆顺手设计一张顺眼的封面。

背景图的填充方式设为拉伸，尺寸调整到和界面一致。

然后添加拆分后的每段标题分段：点 (x) 按钮，新增变量 t1，样式参考排版总览来设。选中 t1，Ctrl+C 复制，再按素材里的 Ctrl+Z 连贴 3 次。除 t1 外的三个标题分段也要排版，并把引用值依次改成 t2、t3、t4。

接着加辅助元素：再点 (x) 添加变量 data，设好大小、位置和填充方式。复制一份 data，把引用改为 data1，位置对照排版总览调整。

# 2.12 接入第二个代码节点：合并图片素材

出入参的变量名别改，照表填写。

| 入参变量名 | 变量值 |
| --- | --- |
| img | 引用画板_1 出参：data |
| img1 | 引用批处理出参：output |

出参变量名为 output，类型是 array<string/>。

进 IDE 编辑，语言选 Python，把下面代码贴进去：

```python
async def main(args: Args) -> Output:

    # 获取输入参数
    params = args.params

    # 获取string类型的img参数
    img = params['img']

    # 获取数组类型的img1参数
    img1 = params['img1']

    # 将img插入到img1数组的第一个位置
    # 创建新数组，img作为第一个元素，然后添加img1的所有元素
    result_array = [img] + img1

    # 构建输出对象
    ret: Output = {
        "output": result_array  # 以数组形式输出
    }

    return ret
```

完成这一步，内容生成部分就收尾了。把结束节点的入参设置好，就能拿到文案和图片；后面的节点负责👸号、📕半自动发布。
