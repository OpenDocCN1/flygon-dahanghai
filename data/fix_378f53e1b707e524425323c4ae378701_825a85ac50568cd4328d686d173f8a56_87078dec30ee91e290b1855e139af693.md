# 章节概要

个人 IP，说穿了就是别人提起你时冒出来的那个“标签”：记得住、信得过、肯付费。标签清楚，后面的动作才有根；内容今天东明天西，信任很难攒起来。AI 能陪你翻旧经历、找用户痛点、判断方向，像个懂你的定位搭子，把你的长处和市场空隙一起摆上桌。

# 0.1 先想明白：AI 为何能插手定位这件事

# 个人 IP 到底是什么？

我的理解很朴素：IP 是别人想起你时，脑子里蹦出的那个“标签”，它让你被记住、被信任，最后让人愿意为你掏钱。

提到某个人，大家立刻知道他吃哪碗饭。比如“龙哥：龙哥盟创始人”“杨涛：赚钱全能大师兄”。

不少人把“IP”当成网红、大 V、明星才配玩的东西。其实，只要你想靠内容影响人、靠信任做变现，就该有自己的个人 IP。

换成大白话：

你是什么样的人？
你替哪类人排忧？
别人凭什么信你、追着你？

这三问答顺了，IP 的毛坯就有了。

比如一位宝妈，亲子早教很在行，她的标签可以是“陪娃不焦虑的早教妈妈”。
比如一位设计师，懂品牌也懂生意，他的标签可以是“用设计帮小老板多赚钱的品牌顾问”。

IP 不是凭空捏人设，而是把真实的你放大。所以起点不是“我想变成谁”，而是“我本来是谁”。别老盯着别人做什么，先往自己身上看：过去做过什么、拿手什么，把它们翻出来、说清楚、放大。

⚠️ 提醒：定位不是刻在石头上的，阶段变了，坐标也要跟着调。

# 为什么 IP 定位绕不过去？

面目不清，很难留在别人记忆里。

举个例子：
你打开📕，看到一位“花花老师”，周一聊穿搭、周二熬鸡汤、周三谈创业，内容单看还行——你会点关注吗？
多半不会。因为你搞不清她是谁、擅长啥、能帮你什么。

定位就像建楼前打桩。桩没打稳，楼越高越危险。反过来，在一个细分领域扎深，在一小群人中攒够信任，内容、信任、变现这三条链路就能转起来。

做内容营销，不是把自己活成百科全书，什么都聊；而是让人一看到你，就明白你是处理“哪类问题”的行家。

记一句：
方向含混，辛苦容易空转；坐标清楚，投入才有复利。

# AI 在定位里能帮什么？

以前做定位，很多人第一步就绊住：不知道自己拿手什么，不会查用户需求，也说不清差异在哪。
AI 的价值，不是直接塞给你一个答案，而是把脑子里的信息理成结构、摆到明面、拉出对比。

它像个懂你的定位搭子。比如：
你把经历输入进去，它能帮你捞出可能的优势标签；
你报一个方向，它能帮你拆用户痛点、平台适配和变现路径；
你在几个方向之间摇摆，它能帮你做可行性评估。

所以，AI 不替你拍板定位，它更像一面镜子，让你把自己照明白。等你看清特长、资源、喜好和市场机会，定位就没那么难了。

起跑不必满分，方向要先明确。

# 0.3 给个人坐标搭四根梁 @sky

定坐标前，先整体看一眼：一个个人 IP 可以怎样一步步搭起来。

创业路上，找到高价值定位很要紧。想把个人定位做好，可以从四个关键维度搭：

兴趣领域：你真正愿意扎进去的业务方向或行业；
内驱动力：哪怕熬夜也不觉得苦、能让你持续投入的那股劲；
成果证明：你已经做出来的成绩和经验，大小都算；
核心能力：别人常来找你帮忙的地方，也是你区别于他人的技能。

这四个维度叠在一起的地方，往往就是最有战略价值的坐标。

清楚的定位像创业路上的罗盘：资源有限时，知道劲往哪使；竞争激烈时，找得到自己的差异；市场变化时，守得住核心，不盲目跟风；决策困难时，有明确的取舍标准。

缺了定位，创业像船没有航向，再使劲也难到想去的岸。

那具体怎么搭个人定位？

第一步：先盘家底。
拿纸笔，诚实回答：
我真正喜欢做什么？
哪些工作让我觉得时间飞快？
即使不赚钱，我也愿意长期投入什么？
我过去在哪些方面做出过成果？
朋友、同事或客户常因为什么问题来找我？
我解决过哪些别人不容易解决的问题？
别急着下结论，这一步是为了把自己的资源禀赋看全。

第二步：找重叠地带。
把第一步的信息摊开，找出重合区域：
哪些领域同时满足兴趣和内驱力？
这些领域里，你有哪些已经被验证的成果？
你的核心能力如何与这些领域对上？
重叠越多，定位潜力越大。但最佳定位不一定最显眼，而是差异化竞争力最强的组合。

第三步：拿去市场试水并修正。
定位再漂亮，也要过市场这一关：
设计小规模测试，为 5-10 个潜在客户提供服务；
收集直接反馈：他们愿意为这个价值付费吗？
分析竞争格局：在这个定位上，你比对手强在哪？
评估增长潜力：这个定位能撑长期发展吗？
根据验证结果，持续调整定位表述和价值主张。

第四：定期校准定位。
定位不是一锤定音，要建立评估习惯：
每季度回看市场反馈是否支持当前定位；
每半年检查核心能力有没有变强；
每年评估定位是否需要升级或转型；
持续学习，盯行业趋势和客户需求变化。
成功的创业者懂得守住核心，同时灵活调整战术。

找到定位只是第一步，执行同样关键：
把 80% 的时间和精力投到与定位相关的核心活动；
持续加深定位领域的专业知识和人脉；
用简洁有力的语言表达定位和价值主张；
通过客户反馈和市场数据不断检验定位是否有效。

创业是长周期竞赛。对的位置不仅能帮你赢在起点，也能让你在漫长路上保持方向和动力。最有价值的定位不是照搬别人，而是找到那个只有你站得住的位置。在那里，热情、能力和市场需求刚好合拍，形成别人难以复制的竞争优势。

# 1.2 往内看——自己给自己盘点

当你回忆高光时刻、记录心流体验、分析朋友的夸奖，其实是在整理一张“非学历版简历”。这张简历记录的是你做事的动机和风格。

下面的内容，建议用飞书文档或备忘录记录下来，边看边写。每当看到反复出现的关键词、情绪或购买偏好，就记下来，越多越好。不用担心写得乱，后面投喂给 AI 都能识别处理。

# 方法一：把有成就感的事翻出来

这是我很喜欢的方法。

拿张白纸，把特别有成就感的事情写下来（比如：我爱干什么？别人夸我什么？有什么特别经历？），可以写 10 个或 20 个，然后分析自己用了哪些能力，最后汇总重复出现的能力。

如下图所示：

让我特别有成就感的事 | 我用了哪些能力 | 重复出现的能力
举例：我 3 月份参加赚钱 AI 自媒体航海，写了几篇新手教程帖子，最后居然成为精华帖了！ | 举例：洞察需求、AI 写作、视觉设计、文案表达 | （把前面多次出现的能力，填到这里）

如果多个事件里“表达、设计”反复出现，说明这可能就是你的核心能力。

# 方法四：找熟人要具体反馈

不要泛泛地问“你觉得我好吗？”，可以这样问身边的朋友、客户、同学、同事：

“我们合作的时候，哪一刻你觉得我最靠谱？”
“你觉得我最适合负责哪类任务？”
“你跟别人介绍我，通常怎么形容我？”

这些具体场景下的反馈，才是有用信息。

留意这些线索：
同事总让你处理什么问题？比如“你帮我理一理这件事的逻辑”；
朋友会说你“一看就像个特别有条理/特别能安抚人的人”。

# 方法五：从手机使用痕迹倒推兴趣

刷手机痕迹分析：抖音喜欢 + 淘宝订单 + 🛰️吐槽 = 真实兴趣图谱。

这个方法简单到什么程度？不用写作业，不用冥想，只要回看手机记录。

为什么要看手机？
因为手机是你最真实的“兴趣雷达”。你点了什么、买了什么、吐槽了什么，都在说明：你对什么感兴趣，注意力在哪里。

# A 点赞里藏着什么

翻开抖音、📕、视频号，看看你点赞最多的内容。

你疯狂点赞“装修干货”？可能对空间美学、动手整理感兴趣。
你天天收藏“情绪类鸡汤”？可能有很强的共情力，适合做陪伴型 IP。
你爱刷猫猫狗狗？很可能在真实世界也特别会和宠物相处。

你喜欢看的内容，就是兴趣地图。你关注的，就是你想成为的。

# B 订单暴露了什么

很多人不知道，你买过的东西，就是价值观的实物体现。

你爱买文具、笔记本？可能是一个规划控、系统型人格。
你爱买“看起来没啥用但特别美”的东西？可能有很强的审美表达力，做生活方式博主很有潜力。
你经常买 AI 工具、线上课程？就是一个天生的学习者+效率型人格。

看懂你“为啥花钱”，就是看懂你“为啥被打动”。

（PS：同理，可以去看看小鹅通/视频号小店等后台）

# C 吐槽和朋友圈说明什么

这一条很多人会忽略，但它超级真实！

回头看看你过去发过的朋友圈，或者和好朋友聊天时常常吐槽的点：

“我真的受不了领导沟通不清楚！” 👉 你可能是天生的结构控，很适合做知识型输出。
“为什么这些广告都这么土！看得我好焦躁！” 👉 你可能是有审美洁癖的品牌型选手。
“我最烦那种讲话不带重点的人！” 👉 你可能是“表达高效”型人格。

这些反感、偏好、碎碎念，都是你“价值锚点”的线索。AI 可以辅助你整合成一张「认知地图」，但第一步，得你自己先打开。

# 方法六：让 AI 翻你的旧资料

适合谁？
👉 如果你觉得“我也不懂自己擅长啥”，但之前发过内容、写过笔记、做过简历，那一定要试试这个方法。要做的就是：把你“做过”的扔进 AI，让 AI 帮你找出连自己都忽略的闪光点。

✅ 可以丢给 AI 的素材有哪些？这里列一份清单，直接照着找：

# A 你写过的内容类素材

👸号文章（特别是讲经历/感悟/成长/复盘的）
📕笔记 / 🧣长文
知识星球发过的内容 / 社群内分享记录
视频脚本或提词稿（有内容沉淀的也行）
知乎回答、B站文案、豆瓣日记等
任何你写过的“年度总结”“30 岁前想做的事”之类的内容

然后请 AI 提取信息，提示词：

# 💡

“请阅读下面这些文字，帮我总结：我擅长什么、常用什么表达风格、适合做哪些内容方向。”

# B 你准备过的职业资料

简历（重点看工作经历/技能部分）
面试自我介绍稿
作品集或案例集（不管是设计、写作、项目类都行）

然后请 AI 提取信息，提示词：

# 💡

“请根据我的简历和作品集，分析其中体现的技能，并提炼我的专业优势。”

# C 你跟别人的聊天记录（只要你愿意整理）

朋友圈留言/评论记录
和朋友/前同事聊职业发展的语音稿
接私活过程中的咨询、报价、交流（可提炼你的服务能力）

然后请 AI 提取信息，提示词：

# 💡

“请从下面的对话里，找出我提得最多的关键词、用户认可我的地方，以及我最擅长解决的问题。”

温馨建议：

1. 不求多，先找 3 份你最熟悉的内容投喂进去。别一开始就全丢，会累，先从👸号+简历+聊天记录试试看。
