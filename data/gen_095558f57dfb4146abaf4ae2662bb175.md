# 从 MCP 配置到播客网页：一次把链路跑通

先从 ChatWise 接入 MCP 说起。第一步，把命令与环境变量填进 ChatWise，其中环境变量要放你申请到的 Key，别空着。

[PRE1]
**MCP 实操｜提示词可直接复制**

ChatWise 填写项：

命令：npx -y @amap/amap-maps-mcp-server
环境变量：AMAP_MAPS_API_KEY="用你申请的高德 API Key 替换这段文字"

接着是 Exa 的 MCP。它同样需要 API，不过 Exa 的 API 可以免费申请：打开 https://dashboard.exa.ai/api-keys ，点创建后复制即可。

**MCP 实操｜提示词可直接复制**

ChatWise 填写项：

命令：npx -y exa-mcp-server
环境变量：EXA_API_KEY=用你申请到的 API 替换这段文案

Obsidian 这边要先做准备：进入 Obsidian 的「第三方插件」→「社区插件市场」，找到 Loccal Rest API，安装并启用。

[PRE2]
启用后，在 Loccal Rest API 的设置页里就能看到 API Key。然后访问 https://coddingtonbear.github.io/obsidian-local-rest-api/ ，点右下角「Authorize」，填入刚才的 Key，把服务启用。

[PRE3]
另外还要拿到 Obsidian 仓库的本地路径：点 Obsidian 左下角仓库位置，进入管理仓库，选择在「访达中显示仓库文件夹」。找到文件夹后，按住「Option」键再右键，复制文件夹路径，留作后面用。

现在回到 ChatWise。

**MCP 实操｜提示词可直接复制**

ChatWise 填写项：

命令：uv tool run MCP-obsidian --vault-path 替换为你 Obsidian 仓库的文件路径
环境变量：OBSIDIANAPIKEY=用你 Loccal Rest API 插件中的 Key 替换这段文案

若没跑通，可参考船员版配置：

obsidian

uv tool run mcp-obsidian --vault-path D:\mcp-test
OBSIDIAN_API_KEY=xxxx

Minimax MCP 也值得接入，它的服务覆盖了自家几乎所有模型，包括当前表现不错的音频、图片和视频生成模型。先去 Minimax 后台申请 API：https://platform.minimaxi.com/user-center/basic-information/interface-key ，适当充值即可。随后在后台创建 API，并记下 API Key。

[PRE4]
之后在 ChatWise 里配置 MCP：进入设置→工具→左下角加号→选择 Stdio，再填写对应信息。这里要新建一个文件夹专门存放生成内容，按住 Option 键右键获取它的路径。填完后点下方的查看工具按钮；如果能看到工具列表，说明配置正常；若报错，把错误信息复制给 AI，请它帮你调整。

**MCP 实操｜提示词可直接复制**

命令：

uvx minimax-MCP

环境变量：

MINIMAXAPIKEY=替换为申请的 API Key
MINIMAXMCPBASEPATH=替换为储存生成内容的文件路径
MINIMAXAPI_HOST=https://api.minimax.chat

若没跑通，可参考船员版配置：

minimax

uvx minimax-mcp -y
MINIMAX_API_KEY=xxxxx
MINIMAX_MCP_BASE_PATH="D:\mcp-test"
MINIMAX_API_HOST=https://api.minimax.chat

[PRE5]
接着在 ChatWise 把这几个 MCP 打开。后面操作门槛很低，按步骤来就行。

[PRE6]
真正的重点来了：我把所有 MCP 的调用顺序和具体要求都写进下面这段提示词。复制到 ChatWise 回车，就可以等网页和音频生成。

**MCP 实操｜提示词可直接复制**

请帮我搭建一套围绕我个人的播客系统：依据我的位置、当地资讯和收藏内容生成播客音频，并做一个设计精致的网易云音乐风格播放页面。

信息收集与内容生成流程

1. 位置与天气信息

用高德地图 API（gaode MCP）获取我的当前位置，并拿到当前天气、温度范围和空气质量。再根据天气数据给出合理的穿衣建议。

2. 本地新闻整合

通过 Exa MCP 查询我所在地区昨日的重要新闻，筛选 3-5 条最有影响力或可能与我相关的新闻，并用简明方式总结每条要点。

3. 个人收藏内容分析

通过 Obsidian MCP 访问我最近 7 天内收藏在{剪藏文件}文件夹的文章，提炼关键主题和有价值的见解，整理成 2-3 个值得分享的要点。

4. 播客脚本创作

设定一个虚拟主播角色，赋予其独特个性和语言风格。按以下结构组织内容：开场问候→位置介绍→天气播报与穿衣建议→本地新闻速览→个人收藏内容精华→结束语。总时长控制在 3-5 分钟，加入自然转场和适当幽默，保持专业播客的流畅感。

5. 音频合成

使用 Minimax MCP 选择最适合虚拟主播风格的声音，生成自然、富有表现力的播客音频，确保语速、语调和停顿符合专业播客标准。

网页设计与实现要求

视觉设计

基于网易云音乐风格，以白色为底色，搭配 #FE1110（或相近）的高亮色。主次分明，用超大字体/数字突出核心内容。中英文混排：中文使用大号粗体，英文作为精致小字点缀。高亮色采用自身透明度渐变制造科技感，避免不同高亮色互相渐变。

界面元素

使用简洁勾线风格的图形化元素呈现数据和配图。播放控制区域要醒目且易操作。设置明确的内容区域划分，包括播客标题、日期、天气信息、新闻摘要和个人收藏内容板块。

交互与动效

模仿 Apple 官网的滚动动效体验。实现音频播放进度条与时间显示。关键内容在滚动时有优雅的出现和强调效果。

技术实现

使用 HTML5、TailwindCSS 3.0+（通过 CDN 引入）和必要的 JavaScript。引入专业图标库，如 Font Awesome 或 Material Icons（通过 CDN）。实现响应式设计，确保桌面和移动设备都有良好体验。避免使用 emoji 作为主要图标，保持设计的专业性。

内容呈现

播客文字内容完整展示，分段清晰。天气和新闻数据通过简洁图表可视化展示。为个人收藏内容添加简洁的标签或分类标识。

输出要求

6. 完整的播客脚本文本
7. Minimax 生成的音频链接
8. 可直接使用的完整 HTML/CSS/JS 代码，实现上述所有功能和设计要求

如遇任何 API 访问限制，请使用合理的模拟数据，并在最终输出中标注。

由于 Minimax 返回的图片和音频都是网页链接，你可以直接复制生成的网页代码，部署到 Youware（https://www.yourware.so/）上分享给其他人。

教程就到这里。这套流程相当于一个相对复杂的小产品，但除开 MCP 配置，剩下的几乎 100% 能跑通。不要觉得 AI 编程很难，现在门槛已经够低，只要能把需求描述清楚，就能实现自己的产品。MCP 让你可以调用任何服务，包括支付；上面的播客生成之后，甚至可以加一个支付宝 MCP 来完成收款要求。我很难想象未来的开发者生态会变成什么样。

# 3.1.1 先把 Trae 装好

Trae 是字节旗下开发的 AI IDE，定位类似 cursor 的 AI 编程软件。新版本全面支持 MCP，并提供了智能体功能，能让 AI 更快满足需求。

下载地址：

国际版：trae.ai
国内版：trae.com.cn

国际版可用 cluade、ChatGPT、gemini 等国外大模型，且目前不限量；国内版只能使用 DeepSeek、doubao 等国内模型。建议优先用国际版，登录过程中需要魔法。

# 3.1.2 配置三个 MCP Server｜更新与备用联系：MM188166M（李李）

Edgeone-pages：腾讯出品的 MCP 服务，可以把 HTML 网页自动部署并展示。
