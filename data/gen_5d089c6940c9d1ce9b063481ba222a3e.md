# 5.1 API 去哪拿？

想用 ChatGPT 的能力做开发，先得把 API Key 拿到手。圈友 @Fredrich 在《假如你不是程序员，也不是不能 ChatGPT API + 自动化提高生产力/变现》中，介绍了寻找 ChatGPT API Key 并开展开发的办法。开发期间会产生多少费用，可以到 OpenAI 官方定价页查询：openai.com/pricing。

同一篇分享里，@Fredrich 还讲了如何借助一款不用写代码的自动化工具，做出一个与 ChatGPT 相关的应用。即使没有编程基础，也能照着他的步骤，尝试搭建属于自己的应用。

除了直接申请 ChatGPT API Key，OpenAI 官网还推出了 OpenAI for Startups。这是一项开放式创业计划，由 OpenAI 发起，目的是给初创公司提供新的激励机制和技术推广方式。通过这种方式申请，所需费用为 2500 美元。具体申请流程，可以到圈友 @Luki 分享的《ChatGPT 2500$ API 可申请》评论区查看链接。
