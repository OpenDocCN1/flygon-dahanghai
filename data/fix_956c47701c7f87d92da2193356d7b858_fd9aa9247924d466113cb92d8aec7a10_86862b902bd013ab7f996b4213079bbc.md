# 9.5.3 半小时搞定 10 条静态 IP

# 9.5.4 指纹浏览器怎么选

指纹浏览器的核心作用是隔离环境，搭配静态 IP 使用，可确保每个环境彼此独立、互不关联。目前市面上指纹浏览器选择不少，基本都能满足👸号项目需求。

ixBrowser: https://www.ixbrowser.com/pricing

比特浏览器：https://www.bitbrowser.cn/price/

[PRE42]

Hubstudio 浏览器：https://www.hubstudio.cn/pricing/

[PRE43]

这三款都能用，操作方法大同小异。

所以，在让 AI 创作时，尽量把要求提得足够细，同时提供一些样本供 AI 学习模仿——千万别低估它的模仿能力，效果会让你惊叹。

Claude 目前已迭代多个大版本。最早它只是 Slack 上的一个小插件，直到去年 7 月 Claude2 正式发布、启用独立网站，才真正走入大众视野。

与 ChatGPT 相比，Claude 在文章创作上更贴合国人习惯，无论是中文表达方式还是细节处理，都更胜一筹。但面对具体事务，比如写代码、出合同、判断事故责任等，ChatGPT 表现更好。

Claude 更像一位语文老师，在创作文章、文案、剧情等方面有独特优势，更符合国人的表达方式。

目前 Claude 主要有这几个版本：Claude2、Claude-3-sonnet、Claude-3-Haiku、Claude-3-Opus、Claude-3.5-sonnet。其中较强的是 Claude-3-Opus 和 Claude-3.5-sonnet。这两个模型即便只给非常简单的提示词，也能产出质量极高的内容，毫无机械感，甚至比多数作者写得都好。

# 十、ChatGPT＋RPA 自动化写作 @春柏

# 10.1 自动出稿流程

# 第一步：摸清工具

用 ChatGPT 自动写文章涉及的技术和工具有：ChatGPT、影刀 RPA、Python。ChatGPT 的教程可直接看手册第五章节；影刀 RPA 的教程可关注影刀 B 站官方账号，视频讲解很详细：https://space.bilibili.com/393215006?spm_id_from=333.337.0.0 ；Python 教程 B 站上有很多视频，对编程感兴趣的圈友也可以学一学，能让很多重复劳动实现自动化。

以自动化生成一篇情感文为例：先人工调教好 ChatGPT，再准备好故事大纲。然后打开 RPA，设置流程：

1. 选中 ChatGPT 输入框，输入 prompt。
2. 点击“发送”按钮，把 prompt 发给 GPT。
3. 等待返回。
4. 获取返回的文字，存入文件。

循环以上流程直到文章写完。

prompt 示例：

根据下面由“”“包含的故事大纲，使用“风格 A”，以第一人称写一篇故事。要求：

1. 故事必须分成 9 个段落；
2. 每个段落不少于 130 字。

先写出 1、2、3 段。

text: """

故事大纲...

"""

如果一次让 ChatGPT 输出太长文字，它会出现幻觉，导致内容质量下降。因此一篇 1200 字左右的文章，我会分 3 次让 ChatGPT 来写，每次约输出 400 字。ChatGPT 不擅长统计字数，所以我每次让它输出 3 段，这样对字数的控制效果也更好。

写故事建议用 GPT-4，效果比 3.5 好很多。
