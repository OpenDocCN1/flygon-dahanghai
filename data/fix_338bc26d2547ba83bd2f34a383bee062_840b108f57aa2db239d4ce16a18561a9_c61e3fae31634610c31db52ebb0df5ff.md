# 营销地址别空着，AdMob 验证全靠它

AI 帮你把 HTML 页面生成好之后，记得传到自己服务器上。上传完成后，App Store 里的“营销地址”这一栏尽量别留空——尤其是后续打算接入 Google AdMob 变现的话。因为 Google 在做 App 验证时，会专门去读这个地址指向的 URL；一旦空着，AdMob 那边很可能就找不到验证文件，审核自然卡住。当然，如果你手头没有服务器，飞书文档、腾讯文档、CSDN 博客这类平台也能拿来临时顶替。

# 5.3.1 版权信息配置

# 5.3.1.1 基本信息

版权这块内容，算是 App 知识产权保护里绕不开的一环。填得准不准，既关系到合不合规，也直接影响你对自己劳动成果的掌控力。

# 5.3.1.2 版权所有者确定

# 5.3.1.2.1 个人开发者

一个人做开发的话，版权所有者写自己法定姓名就行。中文、英文或者拼音都行，但最好和 Apple 开发者账号注册时用的名字对齐。打个比方：张三、Zhang San、Sanford Zhang 这几种写法都可以。

# 5.3.1.2.2 公司或团队

公司主导的项目，版权归公司，所以要填公司注册时的法定全称。如果是几个人组队但没走公司注册流程，也可以写团队名——不过动手之前，最好先查一下这个名字有没有被别人抢注成商标。

# 5.3.1.3 在 Xcode 中设置版权信息

1. 启动 Xcode，打开对应工程。
2. 左侧项目导航器里找到项目文件并选中。
3. 点进主项目 target。
4. 切到“Info”标签页。
5. 定位到两处进行编辑：项目设置里的 Copyright 字段，以及 Info.plist 里的 NSHumanReadableCopyright 键。

# 5.3.2 版权格式规范

# 5.3.2.1 版权格式规范

业界通用的版权声明长这样：

Copyright © [年份] [版权所有者名称]。 All rights reserved.

举两个例子：

个人开发者：Copyright © 2025 Zhang San。 All rights reserved.

公司主体：Copyright © 2025 科技有限公司。 All rights reserved。

# 5.3.2.2 年份设置

App 第一次上线，年份写首发那一年，比如 Copyright © 2025。如果后续一直在迭代，可以写成区间形式，比如 Copyright © 2020-2025。每次版本有重大改动，年份信息记得跟着改。

# 5.3.2.3 在应用中显示版权信息

1. “关于”页面里放一份完整的版权声明。
2. 启动画面底部可以视情况加一行精简版版权提示。
3. App Store 描述末尾也建议附上版权信息。

# 5.3.2.4 App Store Connect 设置

1. 登录 App Store Connect。
2. 找到你的应用。
3. 在“App 信息”区域，核对“版权”字段，确保和 App 内展示的版权信息完全对齐。

# 5.3.3 法律注意事项

版权信息必须真实可查，化名或者未注册的商业名称不建议使用。项目里如果引用了第三方库或资源，要在 App 合适的位置把它们的版权声明带上。版权注册并非强制，但在部分国家或地区，走完正式登记流程能多一层法律保障。

# 5.3.4 常见问题解答

问：只写名字拼音行不行？

答：行。但最好和开发者账号名称保持一致，并且确认这是你在法律文件里会用的正式名称。

问：版权需不需要去注册？

答：软件版权从创作完成那一刻起就自动生效了。不过在某些国家或地区，正式注册能带来额外的法律保护和诉讼权利。

问：年份要跟着更新吗？

答：要。每次有实质性版本更新时，年份就应该同步调整，也可以用区间写法，比如 2020-2025。
