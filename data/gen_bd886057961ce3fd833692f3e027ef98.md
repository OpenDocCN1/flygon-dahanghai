### 02. 电商视频策划 Skill 搭建法

1. 灵感与设计原则

1.1 灵感从哪来

在电商带货视频策划中，一份高质量的方案往往不是单靠一个人就能完成，它需要多个专业角色接力配合：视觉分析师负责观察产品的外观、材质与设计；市场研究员负责调查竞品、用户痛点及行业趋势；卖点策划师负责提炼差异化的营销卖点；视频导演则负责撰写分镜脚本、设计拍摄方案。只有这些角色紧密协作、信息逐层传递，才能最终产出一份可落地的策划案。

核心洞察在于：Claude Code 的多 Agent 协作能力，正好能够复刻这种团队协同的工作流程。

[PRE1]

设计理念可以归纳为四条原则：
1. 角色分工清晰：每个 Agent 都有明确的能力边界。
2. 流程标准化：每个步骤都有清晰的输入与输出规范。
3. 质量可校验：每个环节都配有检查清单。
4. 结果可落地：最终输出能够直接执行。
