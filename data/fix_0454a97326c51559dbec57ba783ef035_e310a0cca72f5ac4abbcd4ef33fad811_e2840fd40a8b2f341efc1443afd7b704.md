# 6.3.2 发圈时间怎么排？

不同时段，你的客户状态各异：发呆、办公、挤地铁，还是举杯小聚？虽说无法精准预判，可同一时间多数人往往在做类似的事——清晨起床吃早饭，下午上班摸摸鱼看看手机。因此这一环节直接牵动转化效果，务必重视。

发圈的七个黄金时段：

① 07:30-09:00 早安圈：新的一天开始，大家在起床或用餐。

② 10:00-12:00 产品圈：工作一段后需要歇口气，顺便刷刷圈。适合发：有质感的产品摄影图（养眼也养心）；带故事感的软性文案（用共鸣感强的小故事）。

③ 12:30-13:00 反馈圈：午间休息，大家热衷翻动态凑热闹。适合发：客户好评的晒单图、好看的照片，再配一段以对话开头、走心的文字。

④ 15:00-17:00 价值圈：忙碌间隙歇一歇，喝口茶。适合发：原创感悟类内容，纯文字或图文皆可。

⑤ 18:00-18:30 产品圈：下班吃完饭后休闲片刻。适合发：站在顾客立场写的软性推广，务必融进你对产品的理解。

⑥ 19:00-20:30 生活圈：晚饭后或聚会的黄金档。适合发：生活摄影图，秀出品味，再配上走心的生活场景文案。

⑦ 21:00-23:00 复盘圈：睡前不少人会回顾白天的所遇。

以上便是发圈黄金时间，照着来基本不会跑偏。

# 💡

章节概要：

资料引流，主角自然是资料。这一章说说怎么搭起资料库，以及从里面挑出你的引流品。要提醒的是，我们更建议你把自己手上的课程内容或资料提炼出来，将最核心的部分做成引流品投放到📕，去捕获那些尚未被充分转化的高精准用户。

# 7.1 资料库搭建方式怎么选？

给你三条路子。

# 7.1.1 第一种：自建课程或训练营

倘若你手上已有课程或训练营，攒下了不错的 IP 内容，完全能从现成资料里抽取出最有吸引力的核心部分，放到📕笔记中充当引流品。若暂时没有自己的课程，星球上有不少讲“如何搭建课程”的精华帖可供参考。

# 7.1.2 第二种：借助合作伙伴的内容

若你有可信赖的合作方，对方手握课程内容，你也可以充当带货角色，带的货便是他们的服务、课程或训练营。谈成合作后，拿他们的部分资料做你的引流品，把引来的客户交给对方完成后续成交，你从中抽取佣金。

# 7.1.3 第三种：汇总公域里无版权的内容

若前两条都不适合你的现状，而你又想先把📕资料引流这条路走通，那就走第三条：从公域里那些不涉及版权的内容入手，收集汇总，做成引流资料库。需要提醒的是，这条路不宜久用，且只能收市面上无版权、可免费流通的东西，如此才合规、不惹版权麻烦。长远看，还是前两种更稳妥，第三种只是过渡。考虑到多数人手里确实没有资料，下文会把这套方法的完整流程讲透，帮你先跑起来、拿到正向反馈。

# ② 资料从哪儿弄？

1. 找同行领取，推荐度★★★★★

头一步向同行打听时，顺手就能拿到一部分。若所在领域资料量大，不妨多问几家；而且别只盯着📕，抖音、B站、今日头条、视频号、🐧 等地方都藏着同行，都可以试。多攒同行，挑出更新稳定、口碑靠谱的那批，按文件优劣归类并做成表格，往后作为资料更新的底本。同行给的资料一般带水印或二维码，后面会讲怎么处理二维码、换成自己的。

2. 网盘搜索器搜索，推荐度★★★

部分百度网盘分享链接，能借助合集类网盘搜索器挖出来。百度里搜“网盘搜索”，会涌出一堆站点，挨个点开，输入关键词查找。不过受限于他人的命名方式，未必就叫“日语资料”，要多换几种关键词试，比如“五十音”“新标日语”等具体资料名。有的站点要扫码或完成指定动作，当作辅助手段即可。
