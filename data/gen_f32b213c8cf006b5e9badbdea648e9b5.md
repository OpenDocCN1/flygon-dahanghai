# NFT 的实用版图：从数字艺术到蓝筹项目

数字艺术是 NFT 日渐走红的一个应用方向。艺术家通过这种形式保有作品版权，买家也能确认入手的艺术品真实、来源权威，从而降低盗版和造假的空间。所有权证明由区块链完成，创作者不必再完全仰仗第三方机构来保护作品，中间媒介被省去，收入分配也更有利于艺术家。数字作品一旦代币化，创作、交易和版税获取都会变得更顺手。在海外原生加密艺术品 NFT 平台中，Art Blocks 目前名气最响。

3）音乐场景

音乐人长期面对一个难题：歌曲被播放后，自己很难拿到应得报酬。过去几年，非法下载一度十分猖獗，流媒体播放又变得极其便利，整个音乐产业每年因此损失数百万。现场演出门票原本是重要收入来源，疫情却让音乐行业雪上加霜。区块链进入音乐行业后，听众使用或收听艺人在链上发布的音乐，会通过加密、安全且不可篡改的智能合约完成付款。区块链像一本透明账本，一首歌的每笔交易和流向都能被记录；在公共链上，艺人和粉丝都能查到歌曲在何时、何地被播放。

4）门票

门票造假和大量囤票一直是难解的问题。NFT 的记录保存在分布式账本上，具有不可更改的特点，因此票据可以在链上被独立验证和认证，作弊空间被压缩。若把购票行为与链上特定身份绑定，还能设置销售限制，防止大规模囤积。

5）域名

ENS（以太坊名称服务）的作用，是把人类可读的名称映射到区块链和非区块链资源中机器可识别的标识，比如以太坊地址。通俗地说，ENS 把 .eth 域名解析成以太坊地址，让地址更容易记住；ENS 域名也能在二级市场买卖。如今 DID 赛道还衍生出不少类似形态，例如 .bnb、.bit、.sol、.nft 等。

6）身份验证

NFT 带有特定商品或资产的独特信息，因此很适合用于链上识别与认证。每个人都有自己的属性和身份信息，NFT 可以把病例、个人档案、教育信息、地址等数字化，让数据由用户自己轻松管理。随着区块链应用越来越广，用 NFT 存储个人数据的人也会增多。

7）实体资产与文件记录

现实世界中的资产和证明，如房产、股票、文件、资质、执照、病历、出生与死亡证明等，都可以通过 NFT 代币化。以房地产为例，传统行业登记土地所有权和财产时文书繁杂；NFT 能把整个流程数字化，让房产在区块链网络上变成可交易代币，在二级市场轻松流转。这样一来，经纪人、银行、代理商和律师等中间商就可以被省去。

8）DAO 组织与社群权益

社区不断演进，许多传统运营模式正转向完全去中心化的自治组织，也就是 DAO。NFT 可以作为 DAO 或社群的身份凭证，持有者能接触社群私密信息、参与互动，并可能享受收益分红。

#### 11.3.3 NFT 发售流程 @可达 Koda

这里简要梳理一个 NFT 项目从发起到发售，再到售后各阶段的机会。项目准备启动时，通常会先开推特账号做预告，官方不时发布 NFT 预览图，并举办白名单活动。白名单可以理解为提前购买的资格证明：拿到它，基本能确定买到该 NFT；有些白名单还附带免费铸造权或折扣购买权。这个机制有点像港股打新时获得申购新股的资格。

到了合适阶段，官方会开设 Discord 服务器。Discord 类似🛰️与论坛的结合体，一个服务器里能开许多类似🛰️群的频道，是国外很流行的聊天工具，也几乎是所有 NFT 项目运营的标配。服务器里会设置综合聊天区、公告区、灌水区、粉丝作品区、地区语言交流区等。想拿白名单的人，要在 Discord 完成官方指定任务，比如邀请新人、提升聊天等级、提交美术作品等，以此争取资格。

之后进入预售和公售。预售就是白名单持有者优先铸造 NFT 的阶段。白名单数量通常占发行量的 1/8 到 1/4，例如发行 10000 个 NFT，常规会设置 2000 个以上白名单。

[PRE2]

预售结束后，一般在 24 小时内（也可能更短）进入公售，面向社会大众开放，人人都有机会购买。热门项目可能出现几万人抢几百个 NFT 的局面，拼的就是手速。目前常见项目发售的多是盲盒状态 NFT。公售后过一段时间，官方会公布揭秘盲盒的时间，也就是俗称的“开图”。NFT 有稀有度设计，越稀有价值越高，限量款价格甚至能冲到顶峰。

开图当天，交易量往往达到高峰：大家把自认为普通的 NFT 挂出售，鲸鱼玩家则买入稀有款。再往后，项目会按官方 ROADMAP（路线图）发展，可能表现不及预期、价格大跌，也可能一路走强，成为新一代蓝筹 NFT。

#### 11.3.6 普通人参与 NFT 的稳妥打法 @焦波｜水镜

普通人怎样玩 NFT 更稳妥？普通人的资金量有限，也承受不了大风险和频繁交易带来的手续费摩擦。所以更稳的方式是一级市场：挑选相对优质的项目，尽量早拿到白名单，然后在铸造阶段看到确定性市场收益后再出手。

初期练手时，可以选择 ETH 链上免费铸造的项目。免费铸造只需支付小额 GAS 费（常见 1～5 美元），可以多次实操、走完整流程，快速积累经验。另一种做法是拿到白名单后直接出售获利，安全系数更高，但可能损失潜在收益。若短期项目非常热门、溢价可能性很高，完全可以出手。

对于确定性收益项目，抢到就是赚到，尽量多参与。以太坊项目可以用“抢失败不扣 GAS 费”的方法避免损失；BSC 和 SOL 链的 NFT 手续费较低，这类机会可以大胆参与。还有一些几乎零成本捡钱的机会，也应尽可能多参加。例如填表就可能获得白名单，而填表限制不高，那就大量填表提升命中率；玩游戏拿 NFT、解谜拿白名单等，不需要花费成本，能参与就参与。

如果有时间和英文沟通能力，可以尝试应聘 Discord 管理员，通常能获得白名单作为回报；遇到好项目且应聘成功，收益也不错。或者不直接下场玩 NFT，而是给玩 NFT 的人“送水”，比如批量生产账号，替别人做账号邀请、聊天、画画等任务，同样能有不错收入。

#### 11.3.7 经典 NFT 项目盘点 @可达 Koda @焦波｜水镜

这一节挑一些经典 NFT 项目做简单介绍，帮助大家建立初步感知。说到 NFT，首先绕不开《Everydays: The First 5000 Days》。从 2007 年 5 月起，艺术家 Beeple 每天在网上创作并发布一件新作品，最终耗时 5000 多天，用 5000 张作品图拼成这幅作品。

[PRE8]

2021 年 3 月，这幅作品在佳士得拍卖行以 6934 万美金成交，约合人民币 4.5 亿。它是世界上第一件在传统拍卖行出售的纯数字作品，也是 NFT 历史上的里程碑，直接带动了之后的 NFT 热潮。

截至 2022 年 10 月 15 号，权威网站 NFTGO 列出的 NFT 市场 Top10 项目，排名依据是 NFT 历史累计交易额。

[PRE9]

股票市场有“蓝筹股”概念，指业绩良好、长期稳定增长、占据行业领先地位的公司股票，投资者通常认为这类股票更有价值。NFT 市场也有类似的蓝筹 NFT：价格相对坚挺、经过较长时间考验、被投资者广泛认可。

下面挑两个很有代表性的蓝筹 NFT 项目分享。案例一：CryptoPunks。这也是一个具有里程碑意义的 NFT。Punks 被认为是世界上第一个真正意义上的 NFT 系列。OpenSea 平台上的 Punks 首页，展示了许多像素小头像。

[PRE10]

这个系列 2017 年 6 月在以太坊链上发布，由 1 万个不规则像素头像组成，每个头像都有独一无二的特征属性。Punks 分为男性、女性、僵尸、猿猴、外星人等类别，并按照类别和特征搭建起稀缺性层级。由于“历史第一”的特殊意义，它受到 NFT 市场追捧，持有者被视为加密世界的 OG 老炮。巅峰时期，Punks 地板价达到 100 以太，最便宜的头像也值 40 万美元，约合 200 多万人民币。成交价最高的是 CryptoPunk #3100，达到 4200 以太，约合 1600 万美元，人民币接近亿级，买得起的人非富即贵。下图中的 5822 号 Punk，是目前历史成交价最高的外星人 Punk。

有人说，NFT 市场充满泡沫，泡沫总有一天会破灭。NFT 市场确实因为短暂过热产生了大量泡沫。但回想互联网时代、移动互联网时代，是不是也出现过同样的言论？只有高速发展的领域，才有可能产生泡沫；而在一轮又一轮挤泡沫的过程中，NFT 市场的价值会越来越凸显。一些只赚快钱、没有形成共识的 NFT 会被淘汰，而有长久价值的蓝筹 NFT 则会被保留下来，形成一个又一个共识群体。
