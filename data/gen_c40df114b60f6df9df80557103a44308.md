# 先问AI，再问人：这个习惯能帮你省下大量时间

很多人在遇到问题的时候，第一反应是翻文档、问同事、或者自己硬着头皮琢磨，却常常忘了手边其实就有一个随时在线的助手。把“先问AI”变成一种肌肉记忆，很多看似麻烦的问题，其实很快就能找到思路。

| 常见卡点 | 以前的习惯做法 | 更好的判断标准 |
| --- | --- | --- |
| 流程太笼统，Agent 根本看不懂 | 写一堆模糊的描述 | 每一条都用动词开头，让 Agent 看到就知道该做什么 |
| 没有判断节点，Agent 乱来 | 全靠最后人工检查 | 先写清楚“什么情况算合格”，人也能照着复核 |
| 流程步骤太多，超过 8 步 | 硬着头皮写下去 | 砍成“输入→处理→输出→人工验收”四段，核心流程尽量控制在 8 步以内 |
| 工具还不确定 | 先硬编一段命令 | 标注“待接工具”，不在这一步纠结细节 |

如果你在写流程时卡住了，可以直接把这些话丢给 AI：

| 卡住的情况 | 怎么问 AI |
| --- | --- |
| 不知道人工流程该写几步 | “我平时做[具体任务]，请帮我拆成至少5个步骤，每步写清楚：动作是什么、大概花多久、要看什么信息。” |
| 写不出那些靠感觉的判断 | “这是我的人工流程（粘贴）。请标出哪些步骤里有‘我在做判断’的地方，说明判断依据，并给每个判断点写一条 Agent 能直接执行的规则。” |
| 分不清 MUST / SHOULD | “这是我的工作流（粘贴）。请帮我逐条标上 MUST（必须做，否则会出错）/ SHOULD（最好做，不做也不太致命）/ MAY（可选），并解释理由。” |
| 流程太长，不知道怎么精简 | “我的Agent工作流有X步（粘贴），请帮我看看哪些步骤能合并、哪些能标为‘可选’，目标是核心流程不超过8步。” |
| 画不出流程图 | “这是我的Agent工作流（粘贴MUST/SHOULD步骤）。请帮我画成 Mermaid 流程图，要包含至少2个判断节点。” |

### 03. 本关小结

**Agent 工作流的本质，就是把岗位卡里的职责，翻译成 Agent 能看懂、能执行、能复核的具体步骤。**

关卡 2 你已经确定了第一个正式 Agent 的岗位，明确了它的服务对象、输入内容和交付结果。

这一关的核心，是从“岗位”走向“流程”：先去还原你人工操作时的真实步骤，再把那些藏在经验里的判断、异常处理和兜底方案一一写出来，最后整理成 Agent 可以照做的操作流程。

Agent 最怕的不是任务有多难，而是流程不够清楚。人做事可以跳步、可以凭感觉补漏、可以临场应变，但 Agent 做不到。它需要你把这些隐性经验全部显性化：什么时候是必须做，什么时候是应该做，什么时候可以不做，以及什么时候需要停下来问人。

**这一关的核心，就四个动作：**

1.  **还原人工流程**：先让 AI 生成一版你手工操作时的流程，然后你来删掉不对的、改掉不准的、补上漏掉的。

1.  **挖出关键判断点**：把“我一眼就知道”的直觉经验，写成明确的判断条件和依据。

1.  **翻译成 Agent 工作流**：用 MUST / SHOULD / MAY，把动作、判断、异常处理和人工兜底全部变成规则。

1.  **画成流程图**：把核心步骤和至少 2 个判断节点画出来，方便人来复核，后面也可以直接写进 Profile。

完成这一关之后，Agent 就不仅仅是“知道自己的职责”，而是真的“知道这件事该怎么一步步做”。

3. 不同类型的 Agent，重点各有不同

前面的步骤是通用的，但不同类型的 Agent，真正需要写清楚的规则其实差别很大。

你不需要把下面所有内容都塞进 Profile，只要找到跟自己 Agent 最接近的类型，重点检查对应内容有没有写到位。

**3.1 内容生产类 Agent**

比如：文章写作、短视频脚本、选题策划、社交媒体文案等。

Profile 里要重点写清楚：

• **写给谁看：**目标读者是谁，他们关心什么，能看懂什么。

• **写成什么样：**文章结构、字数范围、语气、格式和常用表达。

• **不能怎么写：**不允许出现哪些词、哪些语气和哪些表达方式。

• **信息从哪里来：**可以用哪些资料，不能编造哪些内容。

• **如何自检：**有没有跑题、有没有重复、有没有空话、是否符合要求。

• **什么时候询问用户：**主题不清楚、资料不足或写作要求冲突时，不能直接猜。

这类 Agent 最容易翻车的地方是：看起来写完了，但风格不对，或者为了 “完成感” 而编造信息。

**3.2 音视频转录与资料整理类 Agent**

比如：音视频转录、会议纪要、课程笔记、采访整理等。

Profile 里要重点写清楚：

• **支持什么输入：**音频、视频、网页链接、飞书妙记还是本地文件。

• **如何处理原内容：**是否去掉时间戳、口水话、重复内容和无意义语气词。

• **可以改到什么程度：**只整理表达，还是可以重新概括和总结。

• **哪些内容必须保留：**关键原话、数据、案例、结论、任务和负责人。

• **听不清怎么办：**无法确认的内容如何标记，不能自行编造。

• **如何交付：**输出到聊天窗口、飞书文档，还是指定文件夹。

• **如何自检：**有没有漏掉重点、有没有改变原意、文档结构是否正常、用户有没有权限。

这类 Agent 最重要的原则是：整理可以让内容更清楚，但不能把原意改掉。

**3.3 办公整理类 Agent**

比如：周报整理、日报汇总、资料归档、报表更新、信息收集等。

Profile 里要重点写清楚：

• **需要哪些字段：**每条信息必须包含什么，哪些字段可以为空。

• **字段如何对应：**输入中的内容分别要填到哪里。

• **格式是什么：**日期、金额、姓名、链接等采用什么统一格式。

• **如何排序和分类：**按时间、部门、项目、优先级还是其他规则整理。

• **重复内容怎么办：**删除、合并还是保留最新版本。

• **信息缺失怎么办：**留空、标记待补充，还是向用户询问。

• **异常内容怎么办：**格式错误、数据冲突或无法识别时如何处理。

• **如何自检：**有没有漏项、填错位置、重复录入或改了原数据。

这类 Agent 最重要的是：内容可以简单，但字段不能放错，数据不能随便改。

**3.4 客服与销售类 Agent**

比如：售前咨询、客户跟进、社群答疑、销售回复等。

Profile 里要重点写清楚：

• **可以回答什么：**能处理哪些常见问题。

• **不能回答什么：**哪些问题超出权限，不能自行承诺。

• **使用什么语气：**正式、亲切、简洁，还是更有销售感。

• **如何判断用户需求：**用户是在咨询、犹豫、投诉还是准备购买。

• **哪些话不能说：**不能虚假承诺、夸大效果或泄露隐私。

• **什么时候推荐产品：**满足什么条件才能推荐，不能一上来就推销。

• **什么时候转人工：**投诉、退款、价格特批、合同、隐私或复杂问题必须转人工。

• **如何记录：**需要保存哪些客户信息和沟通结果。

• **如何自检：**有没有答非所问、承诺过头、语气不合适或遗漏用户问题。

这类 Agent 最重要的是：先划清回复边界，再想怎么把话说得更好。

**3.5 数据分析与判断类 Agent**

比如：用户分析、内容评分、商品筛选、风险审核、线索判断等。

Profile 里要重点写清楚：

• **根据什么判断：**使用哪些数据、条件和判断标准。

• **标准的优先级：**多个条件冲突时，先看哪一条。

• **结果如何分类：**通过、不通过、待确认，还是按等级评分。

• **评分如何计算：**每项多少分，什么结果对应什么结论。

• **证据如何展示：**结论需要引用哪些原始信息。

• **信息不足怎么办：**不能直接下结论，要标记缺少了什么。

• **模糊情况怎么办：**哪些情况必须交给人工判断。

• **如何自检：**判断依据是否充分，结论和证据是否对得上。

这类 Agent 最重要的是：不能只给结果，还要说清楚为什么这么判断。

**3.6 流程自动化类 Agent**

比如：收集信息后自动整理、生成文件、发送消息、更新表格等。

Profile 里要重点写清楚：

• **什么时候开始执行：**用户发指令、收到文件，还是定时自动触发。

• **执行顺序是什么：**每一步先做什么、后做什么。

• **需要调用哪些工具：**每个工具分别负责什么。

• **上一步失败怎么办：**重试、跳过、停止，还是请人工处理。

• **哪些步骤不能重复：**避免重复发消息、重复建文档或重复写数据。

• **数据如何传递：**上一步的什么结果，要交给下一步用。

• **什么情况算完成：**文件创建成功、表格写入成功，还是消息发送成功。

• **如何留下记录：**要不要记录执行时间、结果和失败原因。

• **什么时候请求人工：**登录失败、权限不足、数据异常或涉及重要操作时，及时暂停。

这类 Agent 最重要的是：不光要写正常流程，还要把失败后怎么办写清楚。

**3.7 文件与知识库问答类 Agent**

比如：公司知识库助手、课程答疑助手、制度查询助手等。

Profile 里要重点写清楚：

• **可以查哪些资料：**明确知识来源和文件范围。

• **资料冲突怎么办：**优先用哪个版本，要不要看更新时间。

• **找不到答案怎么办：**直接说没找到，不能凭经验脑补。

• **如何引用来源：**回答时要不要附上文件名、章节或链接。

• **可以回答到什么程度：**只复述资料，还是可以进一步整理和解释。

• **哪些内容不能回答：**超出资料范围、涉及隐私或权限不够的内容。

• **如何自检：**回答是否真的能在资料里找到依据，有没有引用错版本。

这类 Agent 最重要的是：只根据已有资料回答，不知道就老老实实说不知道。

不过，一个 Agent 也可能同时是几种类型的混合体。

比如：
