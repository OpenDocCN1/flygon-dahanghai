# 11.1 板块一：空投怎么撸？

# 11.1.1 空投到底是什么？

撸空投，圈内也叫撸毛，英文 Airdrop。简单说，项目方把代币（token）发到用户钱包，或者通知用户自己去网站领取，通常是对早期参与者的一种奖励。拿吃鸡游戏打比方：系统隔一阵就派飞机往某片区域投优质武器物资，意思差不多，就是天上掉馅饼。但在Web3里想领到空投有前提：你得落在项目方划定的“区域”里，也就是满足它设的条件。

例如加分项：交易次数（transaction/tx）、交易金额、交易时间等。

扣分甚至清零项：短时间频繁交互，容易被怀疑冲空投；交互行为高度一致、间隔过短、快照之后才参与等。

不同项目方标准不一样，有的还把IP当作女巫判断标准之一。也就是说，你用一台电脑、同一个IP操作多个账号，可能被项目方认定为“恶意刷空投”，而不是真实用户。

[PRE2]

# 11.1.2 项目方图什么？

你可能会问：项目方为什么要发空投？谁愿意白送钱？游戏中发物资还能理解，Web3项目方可是真金白银发项目代币，看起来像纯亏。可它之所以出现并发展，和行业背景密切相关。根子上，是Web2和Web3的分配方式不同。

传统Web2里，公司打广告要找电视台、媒体/自媒体宣传，换知名度和影响力。举个例子，三个主体：公司A：好枕头；媒介B：电视平台；消费者C：你。好枕头想更有效触达你，就得给媒介B广告费，通过广告让更多人知道公司A有好枕头。结果公司A获得知名度，媒介B拿到广告费，消费者C了解到产品，成为潜在客户。

到了Web3，媒介B这个中间环节被砍掉了。项目方想要「知名度、用户参与数、交易金额」等活跃数据，这些得靠真实用户去体验生态、贡献数据。项目方为什么需要这些数据？因为综合数据上去，可能拿到更多融资，估值也能上升。项目方有想得的，就得付出成本。这个成本就是广告预算，空投会被算进广告预算里，用来换它需要的东西。恰好，加密钱包让项目A到用户B之间的点对点发放成为可能，这点很关键。所以与其说我们是来博空投，不如说我们是来体验项目的，主打一个“项目体验官”。

上面的说法是为了方便理解。还有一个更直白的理解：屁股决定脑袋。Web3很多地方还不完善，空投标准由项目方说了算。这种情况下，项目方团队有老鼠仓——内部的人早期拿低价筹码——不好听，但很符合人性。当一个项目你能知道内部消息，又没有监管，就很可能靠内部消息赚钱，因为它同时满足“成本低、风险低、收益高”这个不可能三角。

# 11.1.3 投入产出比高吗？

只看2023年到2024年3月的项目，市场通过空投分发的价值超过近百亿美金。

Arbitrum：以太坊二层项目，19亿美金空投，62万个钱包符合领取条件；

Wormhole：跨链消息传递协议，15亿美金空投，40万个钱包符合条件。

# 11.1.4 为何严查“女巫”？

前面讲了空投是什么、项目方为什么发，接下来讲女巫是什么，以及项目方为什么要查女巫。

回到项目方发空投的目的：它希望用空投吸引真实用户参与，真实用户前期花钱消耗gas体验生态，从而给项目方带来用户量和交易金额等数据。既然只要交互就可能拿空投，那一定有人用“大规模多号批量操作”去薅项目方羊毛，而且投产比还不错。

女巫是什么意思？女巫攻击（Sybil Attack）。“Sybil”来自一位叫Shirley Ardell Mason的艺术家，她曾被诊断出多重人格障碍。顾名思义，这类攻击通常是一个用户使用多个虚假身份（像有多重身份的女巫），去破坏网络或以其他方式获取控制权。项目方发空投时，就会想办法剔除女巫钱包。

所以项目方查女巫，是指为了公平，按一定标准尽量过滤掉薅羊毛的人。比如短时间内多个账号交互行为一致——金额、时间、具体操作上相似；或者该项目的子项目查IP，项目方查女巫时直接采用子项目的女巫地址等。

拿到空投也有限制性指标。比如最近刚发空投的Starknet，官方给出的领取标准是：

1.交易时间间隔超过3个月；（周末swap nft

2.交易金额超过100美金；（30u、25u，swap进去+出来2次，2次。

3.交易次数不低于6次；（你swap一笔资金，进去+出来2次，3次。1分钟

4.钱包底金超过0.005eth；（10多u

同时快照时间为2023年11月15日。

快照可以简单理解成：项目方在某个时间点拍张照，记录你账号的项目交互数据。也就是说，你的交互数据要在2023年11月15日之前满足上述4个标准，钱包才有资格领空投。

空投有限制指标，自然也有加分指标，比如交易次数超过x笔、交易时间超过x个月、交易金额超过x个月。

注意：不同项目方对空投和女巫的标准不同。

# 11.1.5 怎样避开女巫筛查？

项目方查女巫，是因为更想把空投给真实用户，而不是空投猎人。想不被查，重点不是研究怎么躲，而是研究“怎么更像真实用户”。查理芒格说过：如果我知道自己会在哪里死掉，那我就要避免陷入那种局面。

真实用户通常不会：

1.多个号同时做一个子项目的交互；
2.多个号用相同金额做子项目交互；
3.在一台电脑上操作几十上百个账号；
4.一个钱包给多个钱包转账、分发资金；
5.领到空投后都汇到同一个提币账户。

对应的防女巫操作：

交互前：不要同一时间、同一IP注册多个钱包；提现到钱包时金额保持相对随机，比如预期单号投入30-35u，可以A账号放32.53u，B账户放34.2u。

交互时：尽量用指纹浏览器隔离IP，不要用同步器；尽量打乱交互子项目的顺序；用Excel、飞书、Notion等工具做项目管理表，记录进度。

交互后：钱包地址之间不要直接互转，防止一个号被查后牵连关联钱包；在OKX开子账户，用于拿到空投后归集资金。

注意事项：

1）资金从交易所提现到钱包，可以直接多账户分发；资金从钱包汇集到交易所时，需要用OKX设置子账户，防止被女巫。

背后的原理是：你提现时，交易所用它的热钱包给你转账，项目方会把交易所钱包地址设为安全地址。不这样的话，几乎所有用户都会成女巫对象，空投都发不出去，项目方还会被用户和社区骂死，项目口碑也会反过来影响机构对项目的判断和评级，所以项目方不会做搬起石头砸自己脚的事。但如果你把钱包地址里的钱转到自己的交易所账户，这个地址是固定的。如果好几个地址都转钱给你，大概率说明你是多号操作，项目方就会把你当女巫。

2）指纹浏览器和IP的关系：指纹浏览器相当于帮你模拟一台电脑的配置，IP相当于帮你换一个地址。指纹+IP，相当于你在一台电脑上操控“不同地方、不同配置”的多台电脑，从而一人模拟多台电脑做项目交互，避免在IP维度被查女巫。选择好的、安全的指纹浏览器，并且不要同步数据。

3）不要去网站上买IP。价格高是一回事（中文IP网站），另一方面，网站上的IP很多是1个IP卖给多个人用，风险高，网速和稳定性也会让人崩溃。

4）不要挂非安全国家的🪜和IP，避免拿不到空投，比如美国、韩国、俄罗斯、古巴等。我自用荷兰和日本偏多。conlist

# 11.1.7 普通人怎么靠空投赚钱？

# 11.1.7.1 卡点与窗口期

新人撸空投会遇到各种卡点，包括但不限于：三件套的获取和安全使用；指纹浏览器和IP的搭建、使用；各链资金之间怎么转换；如何选择安全网站交互；如何寻找有前景的项目交互……

当下是牛市初期，很多项目方趁这个时间段发币，争取卖个好价格，蹭/赚好行情的钱。这时候大家都在忙着捡钱。所以，上述问题怎么解决、解决周期多长，很大程度上决定你在这轮牛市里能从撸空投赚到多少钱。

# 11.1.7.2 新手最难迈的坎

新手入门最难的是：付出了成本，却没这么快拿到正反馈。这是“先相信后看见”和“先看见再相信”的区别。前者往往能看到机会，别人还不敢上时，自己抓住时机先进场获利；后者要等自己拿到正反馈，才愿意加大时间和精力投入。一般来说，后者更稳妥。但牛市初期一味求稳，会耽误挣钱。

按成本和时间效率不同，推荐几个小方法：

1）养成获取信息的习惯

先试着在工作不忙时养成刷推特，替代刷🧣、📕、抖音（我手机里没有这三个软件）。同样是娱乐，前者能让你拿到优质信息，后者大多在消磨时间。上班摸鱼时看看项目信息，晚上或有可支配时间、电脑在身边时参与一下项目，慢慢把经验条攒起来。

2）跟拿到结果的人学习

去认识那些有项目交互经验、且拿到过结果的人，向对方请教。把这件事当成你花时间、花金钱去做的项目交互。这个方法我入圈至今一直在做，也是我能认识一些撸毛KOL、撸毛大户和撸毛工作室，并从他们身上学习、获取优质项目信息的原因。这个圈子里，信息差和认知差永远存在，不断学习、获取优质信息，才更可能挣到钱。

信息渠道：web3群里搜聊天记录“信息源”，名称是阿布Abo（开船第一课）。

3）参加付费社群

付费社群真正的作用不是搜集信息（一手渠道是推特的项目方官推），而是筛选信息。信息获取和收集在推特上公开且免费，难的是从中找到你能吃到肉、同时又相对确定的机会。这是我近一年加很多付费社群后感触最深的一点——

如果你觉得自己能获取相关板块的优质信息，能及时判断，还能在回调中拿住，从而拿到不错结果（一般指以往有过赚这类钱的经历），那就不必考虑付费社群。如果你跟我刚入圈时一样，希望有人指导、获取优质信息，那这条路可以试试。

举个例子：市场上有ABCDE五个项目，你判断后认为ACE值得参与，于是给ACE各分配三分之一额度，投入比例33%:33%:33%。而某个付费社群经过投研，可能觉得只有C值得重点参与，你花70%的时间和资金成本去参与。最终ACE的收益倍数分别是5:10:0。按100元成本算，A收益165元，C收益330元，E血本无归，整体495元，接近5倍回报率；按社群选中的项目算，投入70元，C收益700元，10倍回报率。付出的时间、资金成本，以及最后拿到的结果，相差很大。

从后视镜看，我在几个优质项目上敢大仓位进去吃红利，“有人指路”起了很大作用。有时候你明知项目优质，但因为信息获取不够全面客观，就不会也不敢配仓位；等项目起来，大多数人只会说“这个项目我当时也参与了，早知道……”。广东粤语有句话叫“早知就没乞丐”。现实是没有“早知道”。“早知道”本质上是有足够信息辅助决策判断，让你对标的判断更客观，再根据实际情况及时止损，或者加大精力埋伏、等待爆发。

# 11.2 版块二：打新

# 11.2.1 打新到底指什么？

打新，是指在早期参与项目方项目，获取项目方低成本筹码的重要方式。

你可能会好奇：同样做一级，打新和撸空投有什么区别？相同点是，两者都通过早期参与项目，拿到项目方的一级筹码。不同点可以从几个维度看：

成本：打新>撸空投
风险：打新>撸空投
胜率：打新<撸空投
赔率：打新<撸空投
反馈：打新>撸空投

撸空投是通过付出gas费和时间，去体验生态下属子项目，来获取项目方空投。除了三件套「指纹浏览器、IP、电报」这些基建成本，其余成本基本是项目交互的gas费（除非你参与质押类项目，前几天有个项目被黑客盗了2000wu）。项目发空投的周期不确定，快则一两个月，慢则一两年。也就是说，撸空投的投入产出比比较高，赔率也更高。
