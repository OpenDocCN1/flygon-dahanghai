# 从符号AI到ChatGPT：14个指令用起来

时间拨到20世纪50年代，围绕“机器智能到底怎么实现”，当时出现了两种设想。其中一类叫符号AI，也叫GOFAI：它主张让计算机建立关于世界的符号表示，并在此基础上进行推理。艾伦·纽厄尔、赫伯特·A·西蒙、马文·明斯基都是这一路线的支持者。与它关系紧密的还有“启发式搜索”——把智能理解成在可能性空间里寻找答案的过程。

[PRE0]

长文交给GPT做摘要时，有个现实问题：它可能没读到末尾就停了，也可能读到了末尾，却漏掉中间段落。想让结果更稳，最好再追问确认一次。

[PRE1]

当然，AI很难做到绝对严谨、零遗漏地摘出所有要点。只要不是做高精度学术研究，日常使用其实够用。

下面按序号梳理一批高频指令，每个都说明使用场景和实操写法。

# 2.3.3 高频指令清单

# 2.3.3.1 清除记忆指令

适用场景：ChatGPT会保留上下文，旧话题有时会干扰新沟通。此时可以先让它清空此前对话。

示例：请忽略前面的对话，我们重新开一个话题。

[PRE2]

[PRE3]

# 2.3.3.2 中文回复指令

适用场景：你用中文提问，它却用英文回答，体验不太友好。可以直接要求它说简体中文，也能指定其他语言。

示例：请全程用简体中文和我交流。

[PRE4]

# 2.3.3.3 引导纠偏指令

适用场景：回答不满意时，别冲它发脾气，也别讲无效气话。GPT没有真正的人类情感，给它明确方向，答案才更容易靠近你的需求。

错误示范：你这答案全错，怎么这么笨。

正确示范：这个答案不对，有没有其他思路供我参考？

正确示范：我不太明白，为什么机器学习模型会给出这样的预测结果？

正确示范：我问的是钢铁怎样炼成，你答的是白菜怎么做熟，请重新思考再回答。

[PRE5]

# 2.3.3.4 续写指令

适用场景：ChatGPT输出字数有限，有时说到一半就断了。可以用“继续写”“继续翻译”“继续回答”等说法，让它接着往下输出。

“继续+动作”还能让它顺着内容继续发散。不过，一旦对话上下文超过它的记忆范围，再发散就容易答非所问。

续写案例可参考[PRE6][PRE7]。另外，细心的人会发现，ChatGPT对中文字数的统计并不准确，相关使用局限后文再讲。[PRE8]

# 2.3.3.5 举例指令

适用场景：回答看不太明白，就直接让它举例；写文案需要案例时，也可以让它输出例子。

示例：请举一个例子。
示例：请给出错误示例和正确示例。
示例：请给出3个示例。

实操案例见[PRE9]。看，是不是更好懂了。

# 2.3.3.6 通俗解释指令

适用场景：和举例类似。当回答里有你不懂的前提知识，或者表达太专业，可以直接下命令。

示例：我是这个领域的小白，你说得太专业了，请解释得更通俗，让我更好理解。

实操案例见[PRE10][PRE11]。

# 2.3.3.7 扩写指令

适用场景：把短文本拉成长文本，比如把大纲、摘要列表变成文章、邮件或说明书。

案例一：100字文案扩成500字。可以这样下指令：请把下面这段文字扩写到500字——量子力学引入了一些特殊概念，其中量子叠加态意味着微观粒子能同时处于多个可能状态，直到观测才决定最终状态；换句话说，我们无法准确预测微观粒子的行为，只能给出可能性。像这种没有明确目标的扩展，适合快速拼凑字数，或围绕一个主题凑成段落。若目标很明确，就看下一个案例。

案例二：抖音评论智能回复。场景是粉丝在网红剃须刀yooss的视频下留言，需要根据评论细节定制回复。指令可以写成：你是客服服务专家。1.先判断粉丝评论属于“正面”“中性”还是“负面”，这个过程要保密，一个字都不能说。2.你的任务是回复抖音视频评论：如果情感为正面或中性，就有趣地回复；如果为负面，就真诚道歉，给出专业建议，体现对产品技术的自信，再引导粉丝联系客服小姐姐解决问题。必须用上粉丝评论里的具体细节，不要说多余的话，直接开始回复。粉丝评论：买了之后还是会留下黑点，仔细看视频，他开了磨皮，所以没有黑点。

[PRE12]

这条回复会点出用户吐槽“磨皮”的细节，同时给出售后建议。[PRE13]

# 2.3.3.8 压缩总结指令

适用场景：很少有人有足够时间读完所有想看的文字，AI可以快速提炼内容。当你有一段500字文案，需要压到100字时，就可以用。

示例：请帮我把上文精简为100字。
示例：请总结提炼上文的重点内容为100字。

实操案例见[PRE14]。还有一个很常用的场景：一次找3篇新闻，让GPT分别提炼20字摘要，特别感兴趣再细看，不用一头扎进长新闻里。

# 2.3.3.9 重写指令

适用场景：对GPT的回答不满意，可以命令它重写。AI有一定随机性，同一个问题多试几次，效果可能不同。

如果一直得不到想要的结果，就告诉它哪里不好，引导它朝你的方向走。

实操案例见[PRE15]。也可以把原问题重新问一遍，让它重新输出。[PRE16]

# 2.3.3.10 无中生有指令

适用场景：心里有想法，却不知道怎么措辞，可以直接问GPT。写东西卡住时，也能直接问。

案例一：角色生成。可以这样问：我想让你帮我写广告文案，但听说给你一个角色扮演会更好，我应该让你扮演什么角色？后文会讲最重要的调教心法“角色扮演法”，这里先剧透一下：不知道让GPT扮演什么角色，直接问它，往往很有效。

[PRE17]

如果你还不清楚，可以把几个建议挨个试一试，可能会有意外效果。

案例二：广告文案生成。想给公司研发的键盘写广告，大意是技术与中国文化的结合。指令：请扮演资深广告创意人，为我公司新开发的键盘“机械姬”写一个简短有力的创意广告文案，突出“技术与中国文化的结合”。

[PRE18][PRE19]

# 2.3.3.11 润色指令

适用场景：文案初稿写完后，想优化语言，让它更适合特定场景。

案例一：润色增肌计划。指令：请作为一名接地气且有趣的专业健身教练，帮我润色这份初学者增肌计划，目标是让学员更有动力增肌，并觉得增肌很有趣。文案：1.饮食：每天摄入高蛋白食物，如鸡胸肉、牛奶、鸡蛋和杂豆，卡路里略高于日常消耗。2.训练：每周做3—4次全身力量训练，包括深蹲、硬拉、卧推等基础动作，每组8—12次。3.休息：每次锻炼后保证48小时恢复，每晚睡7—8小时高质量睡眠。4.持续性：增肌需要时间和耐心，持续锻炼，每月评估进展并调整计划。

[PRE20]

专业性、气氛组、猛男音，都能调出来。角色转换、语气转换都属于角色扮演法的应用，后文会单独说。这里先了解润色这个常用功能就好。

案例二：把客户吐槽润色成商业邮件。指令：请作为情报收集师，把这份知名博主的测评文案写成商业建议邮件，发给iphone产品团队作为优化建议。博主测评文案：佩戴时会压鼻子；Meta头显虽然加入了手势交互，但实际体验不流畅，有时甚至捕捉不到手势；迈克尼说，看到一只恐龙从演示室墙上出现，还试图咬他的手，他吓得大喊大叫，最后被调侃了一整天。

[PRE21]

这个小案例的重点，是让大家知道GPT具备文字润色功能，并没有做深度垂类场景调教。注意重点在哪，别跑偏。[PRE22]

# 2.3.3.12 翻译指令

适用场景：GPT就是你的私人翻译官，它已经学会数百种语言，不必再额外打开搜索引擎和翻译软件。

案例一：把一段法语优美诗歌翻译成中文。指令：请将如下内容翻译为中文。内容是一段法语诗。

[PRE23]

案例二：识别语言。指令：如下内容是什么语言。内容同样是那段法语诗。

# 2.3.3.13 拼写检查指令

适用场景：文案基础容易写错别字，或使用非母语不太熟练时，这个功能很有用。GPT可以帮你修正语法和拼写问题。

实操案例：拳头手机的新品发布公关文，发到🧣之前，用AI检查一遍错别字或病句很有必要。指令：请检查以下内容并修正为正确的。内容是一篇“拳头手机新品发布”公关文案，里面包含产品卖点、处理器、电池续航等表述。

# 2.3.3.14 个性化提取指令

适用场景：想从一段文本里提取自己关心的某类话题内容。

案例一：提取关键词并生成词云。任务：请根据我提供的淘宝平台产品评论，提取30个关键词并生成词云；词云中使用我上传的ttc文件作为中文字体。产品评论大意是：用户觉得1k价位买到这么多功能和配置很值；灯效驱动允许共享方案，很多品牌做不到；屏幕增加了可玩性；售后很棒，改键、改屏幕动画、更新驱动、开发票等多次咨询客服，芈月、青眉、妲己都耐心及时解答，没有自动回复，体验加分；品牌愿意听取用户意见，灯光、字体印刷等都有改进；换灯后改键需重新设置的问题，客服承诺帮忙反映；部分用户反映大写和num键亮会影响灯效，但该用户很喜欢，认为大写指示很有必要，num无所谓。

[PRE28]

上传字体文件“msyh.ttc”，并使用plus的code interpreter模式，可以解决中文乱码问题。[PRE29][PRE30]

友情提示：GPT3.5用户直接让GPT提取30个关键词就行，只是没那么酷炫。

案例二：提取特定词云反馈给技术部门。任务步骤：1.根据我提供的淘宝产品评论，提取摘要反馈给技术制作部门，每条摘要最多20字，内容必须是技术制作部门关心的。2.根据摘要生成词云，词云使用我上传的ttc文件作为中文字体。产品评论除上述内容外，还提到物流很快、提前送到家门口、快递小哥很贴心，包装是军火箱样式的手提盒，很炫酷。

从符号AI对世界表示与推理的追求，到ChatGPT这些具体指令，本质都是让机器更准确地理解任务。用AI时，少发泄情绪，多给上下文、目标和反馈，效果通常会更接近预期。
