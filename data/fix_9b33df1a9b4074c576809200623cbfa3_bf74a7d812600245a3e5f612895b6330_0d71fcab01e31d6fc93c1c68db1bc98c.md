# 6.2.1 先把认知扶正

如今到处都是视频号赚钱的案例，看多了会给人造成一种错觉：似乎一上手就能拿下百万级播放，涨1000粉丝轻而易举，爆单也是分分钟的事。

但真相并非如此。

新手别做暴富梦，也别指望短期内冲到百万级的流量。

最要紧的是先动起来。光看不练，再好的战绩也是别人的，只有真正下场，才可能轮到自己。

所以，还没行动的朋友请马上开始，量变积累够了，质变就会来。

再简单的方法也是别人总结出来的，只有消化吸收，才能变成自己的本事。不动手、不实践，拖着拖着，几天没动静就开始心慌焦虑，慢慢想躲开，这些情绪都很正常。

但这种时候恰恰最需要坚持和正反馈。大家都是成年人，学习终究是对自己负责。正视问题、实事求是，多和老师、圈友交流。没出成绩真的没关系，关键是有没有学到东西，能不能打通一个小闭环。

跑得快未必走得远，走得慢反而稳当，通往终点的路有很多条。

只要这场牌局还没输光筹码，就总有机会，别急着走人。

视频号门槛低、复制性强，不受空间限制，普通人都能参与进来。

# 6.2.2 商品怎么选

1. 选的货吸引力不够

举个例子：同样卖手机充电线，有人选的是普通数据线，拍的也无非是线身、接口这些细节，跟观众手里的没什么区别，自然不抓人。

另一条视频选的是华为超级快充线，直接把快速充电的画面放出来，把“充得快”的爽感演给用户看，这就跟家里的普通线拉开了差距。

同一个品类，选不一样的产品，视频做得再精，效果也差很多。

2. 用户没需求，或产品周期已经过气

夏天卖棉袄，质量再好也卖不动，因为这个时间点上没人需要，自然出不了单。

有位做渔具的朋友也遇到过同样的问题。他说11月和12月视频带货出单很少，一度以为是视频质量不行，或是对手变多了。我问他：冬天是不是很少有人钓鱼？他说确实如此，天冷几乎没人出钓。可见问题不在播放数据，也不在用户，而在货选错了。

货选错的根源，是没察觉到用户需求的变化。春夏秋钓鱼的人络绎不绝，冬天就少了一大截。

3. 选品怎么优化

选品时先反问自己：这个货在视频里的呈现效果够不够好？呈现力强的货，不用怎么剪也能带来可观的流量和成交。

同时，务必按数据选品，不要自己拍脑袋。数据是验证用户需求最好的证据。

具体的选品优化方法，和我们寻找优质货源的方法本质上是同一套逻辑，有时间的话可以看看《通用能力 | 如何定位和选品》。

# 6.2.3 视频怎么改

1. 多上几道去重保险

如果做二次剪辑，要尽量把视频的独特性拉高，多上一些去重操作，免得因为内容跟别人重复而被限流。

可用的去重手法有：
- 去水印、改分辨率、加片头片尾；
- 调帧率、加滤镜、改播放速度、换背景音乐；
- 镜像、滑动、画中画、视频蒙版、图片蒙版、背景颜色、背景图片、背景视频、模糊拓边等。

2. 把画质抬上去

选素材要挑清晰的，别拿模糊视频硬剪。素材本身就糊，二次加工只会更糊，容易被抖音判定成劣质内容，平台就不给流量了。

素材去哪儿找？
视频号同行、抖音、快手、📕、🧣、微视、西瓜视频，以及海外的TikTok、YouTube都可以。

最推荐两个：抖音和快手。

3. 借热门话题或引流短片造势

新号没什么粉丝基础，但平台通常会有一点冷启动扶持。别急着发带货类内容，先找最新的热门话题或引流短片，前提是这类内容的观众画像和你的账号定位吻合。

先发一两条攒攒粉，把账号权重提上去，再发商品类视频，起步流量往往比新号硬推好很多。

有位圈友就是这么做起来的：前一天下午发了条容易引发争论的引流视频，带来50多万播放，涨了一些粉丝，后面视频的数据也跟着好转。第二天早上发的一条又小爆了一下，出了几十单。

4. 学着自己做原创

不同赛道类目的原创内容差异很大，这里就不给具体流程了。建议按赛道找对标账号，拆解它们的脚本模型，从仿拍局部到仿拍整条，再迭代出自己的优质内容。

# 7.2 短视频投流

# 7.2.1 短视频投放现状 @Never

所谓视频号短视频投放，就是只靠短视频购物车出单。目前这块仍以🛰️豆投放为主，我把🛰️豆图文投放的特点简单说一下，供大家参考：

1）优势
- 不用直播，正好避开我的短板；
- 一个人或小团队就能干；
- 利润率还不错；
- 比自然流更稳定；
- 对短视频能力提升很快。

2）劣势
- 对资金要求高；
- 要有一定网感，能判断产品和视频的好坏；
- 单兵作战极考验综合能力，选品、视频框架、混剪过审、投放、供应链、售后，每一环都得心里有数；
- 利润率要求高，很难打长线品。

3）行业问题
目前微豆短视频投放容易掉购物车。想在这个阶段进场，要多准备几个手机号和实名🛰️。我这边以买号为主，自己养号时间成本太高。
