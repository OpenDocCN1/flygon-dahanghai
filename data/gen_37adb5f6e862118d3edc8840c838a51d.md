# 1. 账号流量是否正常（关键）

为什么要先测账号流量？因为每个账号初始权重不一样，直接决定爆文概率。新账号大致分成三类：废号、正常号、优质号。三类号都能出爆文，只是概率不同。比如同样一篇笔记，废号发100篇可能只爆1篇，正常号发100篇爆5篇，优质号发100篇爆15篇。基数小时感觉不出来，一旦笔记量铺开，差距会非常明显。

测试方法（每个账号都要走一遍）：

1. 发一篇和产品直接相关的流量型笔记  
2. 发一篇和类目直接相关的流量型笔记  
3. 发一篇和人群直接相关的流量型笔记  

笔记发布满48小时后看数据：单篇小眼睛>1000，属于优质号；单篇小眼睛在50到1000之间，属于正常号；单篇小眼睛<50，就是废号。

如果测出来是废号，也不用马上放弃，再补发2篇时事热点类笔记，48小时后再观察，单篇小眼睛>100，就可以把账号当正常号用。

拿“荞麦枕”举例：产品相关笔记，标题或正文必须带上“荞麦枕”三个字；类目相关笔记，必须带一级词“枕头”；人群相关笔记，要写出产品对应的痛点，比如“脊椎不好的人”。时事热点类笔记，可以去翻几天内的🧣热搜，挑热度高的话题，先在📕搜一下有没有人发，再模仿着发。

# 2. 样品怎么下

选完品、开好店之后，新手建议先下1个样品，用来拍实拍图。

操作步骤：

第一步：确定要采购货源的产品  
第二步：同时下单竞品，方便和货源做质量对比  
第三步：在1688/拼多多上用“以图搜图”，优先选2-3家店铺下单。店铺优先级从高到低是：有标店铺 > 销量高的店铺 > 普通店铺（1688有标指超级工厂/1688严选/实力商家；拼多多有标指旗舰店/品牌/五星好店/百亿补贴）  
第四步：收到竞品和货源后做对比，如果质量一致或非常接近，就可以用；差距太大就放弃。

注意事项：

- 下单样品时，直接在自己店铺里拍单就行；
- 如果想长期合作，要提前跟供应商确认对接流程，是加🛰️下单，还是走ERP下单。

这里补充下两种下单方式的区别：  
🛰️下单，是为了避免二次面单被平台判定为无货源；  
ERP下单，是为了单量多了之后，商家能直接看到我们店铺后台的订单并发货。  
新手前期单量少，直接走🛰️下单就可以。

# 3. 怎么筛出长期供应商

为了方便后续合作，下单样品时就可以开始观察供应商是否靠谱，主要看两个方向。

# 3.1 配合度

供应商如果不配合，后面发货、售后都会很吃力。

（1）愿不愿意配合电子面单  
每日订单超过10单，就可以跟供应商沟通绑定「电子面单」，之后下单、发货都能直接在系统里完成。但前期一上来就谈绑定，供应商多半不会答应，建议出单之后再聊。

[PRE8]

（2）售后咨询回复是否及时  
一件代发前期会遇到很多产品问题，我们自己还没完全熟悉产品时，都需要供应商帮忙解答。如果一个问题半天才回，大概率会影响店铺成交率。而且回复慢往往意味着对方没有专属客服团队、供应商规模较小，这种通常不稳定，说不定哪天公司就没了。

（3）发货是否及时  
📕店铺对发货时间有要求，通常是24小时或48小时，发货越快越好。确认供应商时，要确保最长不超过48小时内发货；拖着不发，📕后台会扣延迟发货费，一般是3块钱。另外，个别情况实在没法按时发货，要提前跟客户沟通，千万别提前填快递单号！因为提前填单号但物流不更新，会被视为无效发货，照样扣钱。

（4）是否支持退换货  
这个不强求，关键看退换货原因。如果是用户喜好问题，部分产品确实不支持，比如服装类，很多供应商都不给退。但如果是产品本身质量有问题，就应该支持退换；连这都不支持的供应商，不值得继续合作。

[PRE9]

# 3.2 产品方面

（1）价格  
刚开始谈一件代发，单量小，基本没有议价空间。等每日订单稳定在50单以上，就可以跟供应商谈更低的合作价。同时要确认自己的成本在同行中有没有优势。如果自己的成本价已经是别人的卖价，而且产品一模一样，说明对方没给到低价，这时候还不降价，就可以换供应商了。

（2）款式  
有些产品更新换代很快，比如手机壳、穿戴甲这类，要看供应商能不能及时上架新款，有没有自主开品的能力。一些小众蓝海品，尤其是“设计师出品”的珍珠项链、饰品等，对供应商的开品能力要求很高。如果款式跟不上、也不开发新品，这种供应商很难长期合作。

（3）质量  
质量不用多说，肯定是最关键的。产品一旦质量不过关，售后会非常多，处理起来不仅麻烦，还赚不到钱。

（4）补货时效  
供应商也分工厂型、销售型、门店型。门店货发完之后，可能短期补不上货，这就需要看补货速度。一般好一点的供应商补发时间≤48小时，这样不会影响📕发货时限。要是长期补不上货，也不值得长期合作。

# 1. 拍摄学习

# 1. 对标拆解

以“旅行包笔记”为例：带货笔记的图片，本质上就是“场景+产品+角度+光线+构图+陪体”的组合。可以简单理解成——在什么地方，把产品放在哪儿，站哪个位置去拍。比如：在高铁上，把旅行包挂在挂钩上，人站在侧面拍。

笔记首图决定点击率，最后两张图决定转化率。最后两张图是用来展示旅行包质量的，所以一定要拍多角度图+细节图。

尽量在窗边、自然光下、顺光条件里拍（人物面对光源，顺光能避免过曝或发黑），这样拍出来最高清、还原度最好。

如果是书桌拍摄，也尽量靠近落地窗，确保画面有充足自然光。

注意，如果没有补光灯，就不要采用侧面逆光的机位，否则会留下一块明显阴影，后期很难处理。

# 2.5 四大拍摄注意点

1. 图片清晰度：实拍素材一定要高清。苹果手机可以按上面说的参数调整，非苹果手机关掉自动美颜等功能。只要清晰度有保证，不用太纠结爆款模板——大部分产品图都很简洁，越花里胡哨的模板，出货量反而越低。

2. 突出功能性：说白了就是直接解决用户痛点。比如光腿神器，用户会担心褶皱、肤色问题，拍摄时就展示不褶皱、接近裸肤色的效果，客户信任度就上来了。

3. 打光：打光是为了让成片更接近肉眼所见，切忌用彩色灯光，优先选窗边的自然光源，色调最舒服，也能避免货不对板。阴天光线不足时，可以这样打光：

# 1. 后期制作

# 1. 筛选图片

平台判定同质化的逻辑是：图片/视频相似度超过50%，且笔记文字内容超过50%，就会判断为低质量或同质化营销。

图片由像素组成，但算法不会精确到每个像素，只会比对一个个区域的色块。只要大色块的相似度不高，问题就不大。视频是按帧组成的，但算法不会精确到每一帧，只会看零点几秒范围内的内容，所以只要每秒的内容不同、顺序不同就可以了。

新账号前期稽查不算严，筛图时标准可以适当放宽。爆款笔记的首图可以重复用2-3次，但文字内容必须不一样。选图标准：同背景、同光线、同构图的素材，不能超过4篇笔记。视频标准：每一秒的素材都不能相同。

ps：平台对素材的审核只会越来越严。

[PRE27]

# 2. 图片后制

图片制作不复杂，不用做太多后期：

1. 调色：目的是还原肉眼看到的色彩，和打光的目的一样。没有统一模板，每张图参数都不同，可以在📕搜调色攻略，自己多试，调到接近真实颜色就好。搜索关键词：调色参数、暗调调色、ins调色、清透感调色……

2. 滤镜：一般不建议叠太厚。如果手机自带美颜或滤镜太强，可以适当调整。

3. 花字：实拍图别加太多花字，一定要用就选一两个简短的词。文字太抢眼容易喧宾夺主，大图应该突出主体。

# 3. 视频后制

蓝海产品的视频制作相对简单，除了部分产品需要拍详细讲解视频，大部分都可以用剪映的「一键成片」和「营销视频」功能完成。

1. 一键成片：点「一键成片」→选好素材（图片或视频）→点下一步，系统自动生成视频。这类视频只有音乐和卡点，没有文字，用来展示产品已经足够。

2. 营销视频：打开剪映的「营销视频」，输入产品名和核心卖点，就能生成一条营销带货视频，再自己剪辑一下就好。这类视频营销感更强，适合需要文字解说的产品。

# 1. 怎么提高素材利用率

同一张图片不能在📕反复发多次，否则会触发“大量发布低质/重复交易笔记行为”的处罚。但拍都拍了，肯定想多用几次，下面几个办法能提升利用率，又不会算重复。

1. 拍live图转静态图  
苹果手机的live图会记录拍摄前后共3秒的视频，然后选择一帧作为主展示画面。如果画面有较大幅度变化，可以在相册里换另一帧做封面，这样静态图就相当于换了一张图。也就是说，一个live图可以拆成N张图片来发。但如果画面浮动不大，平台仍然可能判断为同一张图。比如图1是原图，图2是换了另一帧，画面里多了一只鸭子，看起来就像另一张图，可它们其实是同一个live图里的。

[PRE30]

2. 拍live图转视频  
live图本身就是3秒视频，可以直接转成视频。转好后把多个素材重新剪辑到一起，做一个全新素材，原理跟混剪一样，但这些素材是自己拍的，原创度很高。也可以直接丢进一键成片或营销视频里重新生成，就能拿来用了。

# 1. 注意事项

# 1. 评论区运营

📕里，挂了产品链接的笔记，流量普遍比不挂链接的低。原因是挂链接后，平台会倾向于把笔记推荐给「电商消费人群」——这批人有明确的购物习惯，所以转化率更高。不挂车的笔记会被当成普通笔记按算法分发，面向全体用户，浏览量自然更大。

如果发布的笔记没有挂链接，一定要在评论区置顶链接、放产品购买引导图，或者直接在评论里回复产品链接。

[PRE31]

# 2. 封面测试

实拍非常依赖封面的点击率。前期不要自己发挥创意，要严格参考同行爆文去拍图。看同产品下，哪一类封面出现次数最多、爆文最多，就说明这种封面点击率高、用户喜欢。

比如光腿神器，下面这些封面角度相近，但换不同账号发都能出爆文，说明这个封面的点击率确实不错。拍摄封面时，就可以针对这个角度多拍几张，去测试封面点击率。多找几个「爆款封面」拍一拍，看看哪个角度更适合自己。
