所谓打新，说白了就是等项目方一放出规则，就掐着时间点跑到对应网站去铸造NFT或铭文。因为链上gas费会跟着行情来回波动，所以每一次打新的实际花销，没人能提前给你一个准数。运气好、挑对了标的，可能一个晚上就翻好几倍；但要是看走眼，亏起来同样毫不留情。

想把NFT打新玩明白，通常得具备这些能力：

1. 会做投研分析
2. 懂得控制仓位
3. 对图片有审美判断力
4. 能拿捏出货时机
5. 对项目后续走势有预判

打新和空投也能玩出组合拳。比如Runestone就计划给比特币网络上铸造过至少3张NFT的11万多个地址做空投，而且项目方把父铭文打进了中本聪的地址，这意味着没人能再控制它，后续想增发都没门，通胀风险直接归零。这个空投单个编号当时价值0.0422 BTC，换算成USDT超过2800，相当于市场直接白送你两万块钱人民币——注意，这还只是第一波，后面可能还有更多空投。

# 11.2.2 打新的两种主流类型与对应成本

现在市面上最常见的打新就两类：一类是NFT打新，另一类是铭文/符文/分形BTC打新。

从出现时间来看，NFT打新比铭文打新要早不少。

从回报率来看，得分开说：NFT打新只要标选得好（这是前提），一出来就能有3到5倍的回报；而铭文在爆发阶段，一天十倍都不稀奇。

从风险角度看，两者其实不相上下。真正的风险主要来自你对标的的筛选和判断，以及仓位管理、卖出策略到底执行得怎么样。

NFT打新通常分成白单轮和公售轮。

白单轮就是白名单轮。项目方一般会给之前参与过他们项目的地址，或者那些持有知名项目NFT的玩家，发放一定份额的白名单资格。白名单的价格比公售便宜，还能提前铸造，避免这些人在公售的时候抢不到。

公售轮就更好理解了，就是公开销售。到了这个时间段，所有人都能公平地去抢着铸造NFT。

以目前链上的热度来看，铸造一张NFT的成本大概在30到60U之间，按外国项目来说，折合人民币就是200到400块。听着好像不便宜，但你要知道，成本跟收益是挂钩的。

# 11.3 版块三：套利

# 11.3.1 套利到底是个啥？

套利可以从两个层面来理解：

1. 在A市场买入代币，然后快速在B市场以更高的价格卖出；
2. 在同一个市场上，针对同一个标的，借助工具低买高卖赚差价。

你甚至可以简单粗暴地记成八个字：低买高卖，赚取差价。

那套利和打新、撸空投有什么区别呢？

简单来说，套利是你在市场上发现了相对低风险的机会，然后做低买高卖，赚的是中间的价差；打新是你通过投研找到优质的一级标的，打新后在二级市场把低价筹码卖出去；空投则是你通过交互项目方的生态项目，对方给你的激励，本质上也是低成本获取一级筹码再在二级市场卖掉。

说白了，打新和空投属于一级市场范畴，而套利属于二级市场范畴。也就是说，打新和空投是把一级筹码拿到二级市场卖出去获利，套利则在二级市场里来回搬砖赚差价。

# 11.3.2 什么人适合做套利？

套利这东西，说难吧，也没那么难；说简单呢，也真不简单。

关键看你自己有没有二级市场的交易经验，还有你的性格、执行力这些。

二级交易经验：如果你有短期二级经验，比如会看K线，那你就能判断某个时段内价格大概往哪个方向走，顺着趋势做波段，这也是一种玩法。

性格：套利通常要快进快出。但有些人性格偏慢，做事求稳，那就不太适合套利。至于你是快还是慢，得结合你过往的经历自己判断。

执行力：执行力就是一句话——看到一条信息，你会不会马上判断它有没有潜在机会；发现机会后，能不能立刻冲上去执行。

# 11.3.3 套利的常见类型

我觉得目前比较容易上手的套利有三种。这里主要分享操作思路，具体实操受实际情况影响，就不展开说了。

# 类型一：交易所上新币的套利

讲套利之前，先说说流动性。流动性是套利的第一原则。没有流动性，再大的差价也没人接盘，那只是两个不同的数字，账面好看，实际一文不值。

新币上交易所后，一般会迎来一个流动性高峰。因为Web3里很多人根本不会链上操作，下了交易所APP也只是用来炒币，不是用来干链上操作的。别觉得这很反常识，你想想身边亲戚朋友有几个懂Web3的？又有几个会链上操作？大概就能理解了。

有了交易所流量的加持，大家对新币的关注度也会提高，流动性自然就跟着来了。

我拿最近在币安套利NOT的经历来拆解一下，说说我的操作和事前分析。

（注：仅作演示，不做投资建议）

我当时是这样操作的：开盘前10秒买入，然后现价卖出，15秒赚了20%，用小资金跑通了整个流程。

[PRE6]

动手之前，我把币安新币榜上所有新币的走势规律和操作思路都总结了一遍，发现了几件事：

1. 新上所的币，通常一开始会暴跌，随后在一小时内慢慢涨到ATH（上市后价格新高），然后再慢慢跌回去。基本是这个规律，但具体情况要具体分析。

2. 相对比较确定性的操作是：极早期买入，比如我就是前十秒买入的，然后挂20%-30%的止盈单。但实际操作中，往往没时间给你计算精确卖点，只能靠盘感或者市值大概预估价格卖出，或者直接现价买、现价卖。

3. 共性规律：币安的任何新币，一小时后大概率跌几十个百分点。原因有很多，比如大盘下跌、做市商洗盘吸筹等等。后续或许能涨回来，但这跟当下的套利行为没什么关系了。

4. 冲币安新币套利跟冲土狗有点像，有几十个点甚至几个点利润就该跑了，别总想着翻倍出本。

5. 事后再去看K线，会缺失很多真相。你事后只会看分线，忽视秒线。但在秒线里，其实有足够的时间窗口可以去现价买入，或者在相对高点卖出。我当时盯盘看到NOT最低到了0.0086，但5月17日早上回看K线分线，最低显示是0.0098。说明分线数据是有失真的。

6. 每个标的的做市商都不一样，不要总想着一招鲜吃遍天。要在实操中不断总结，找到共性后想办法放大规模。

# 类型二：机器人策略套利

机器人套利，就是你选定标的和参数，让机器人自动帮你操作，通过低买高卖赚差价。

这种套利方式比较适合行情波动大的时候，比如大饼横盘、山寨币起伏比较大的情况下用。

按目前的趋势来看，这个策略估计还有6个月左右的时间窗口可以用。我自己实操下来收益率还行，标的和参数选得好的话，单月收益率可能超过5%。

重点是，它的风险相对较低——注意，风险低不等于没风险。高收益的事不可能没风险，想清楚这个道理再动手。

我自己目前开了2个策略（本小节写稿时间是2024年6月6日）：一个是1月26日设置的，收益率28.15%；另一个是5月23日设置的，收益率0.55%。

# 类型三：CEX/CEX、CEX/DEX、DEX/DEX 套利

CEX指的是中心化交易所，比如币安、OKX；DEX指的是去中心化交易所，比如Uniswap。

拿币安和OKX来说，两者之间可能存在差价。如果你手里有空投得来的一级筹码，在币安卖出就会更划算。

CEX到CEX：两个中心化交易所价格有差异，就在低的地方买，高的地方卖。

DEX到CEX：去中心化交易所和中心化交易所有价格差异，同样低买高卖。

DEX到DEX：两个去中心化交易所价格有差异，也是一样的操作。

还有三角套利法：当CEX和DEX之间存在价格差异时，就可以做套利。原理就是看两者有没有价差，有的话在便宜的地方买，在贵的地方卖。

风险方面，可能会被拔网线——新币上市时，CEX可能会暂停提币。

# 11.3.4 套利需要注意什么？

1. 套利对象、参数、平台的切换，都要提前做分析，测试后再制定策略；
2. 设好止盈点和止损点，到了就走，别犹豫，严格执行策略；
3. 如果不用机器人，手动操作要在几分钟甚至几十秒内搞定；
4. 看平台过往上币的数据，预估它短时间内的走势，列客观数据即可；
5. 根据代币的经济模型（项目融资情况、FDV、初始流通量、竞品）预估该币的上所价格；
6. 卖飞是常态。制定策略和交易前，就要先想明白并接受这个前提；
7. 套利本身就是短线操作，不要把套利标的当成长期持有的标的。

另外，不同平台之间的手续费才需要考虑，单平台内的套利手续费磨损基本可以忽略不计。比如单平台看K线，根据趋势挂买卖单赚差价；跨平台就要看购买和提现手续费的高低，甚至转账到账的时间。建议先小资金玩一两次，发现确实有利润，再加大操作。

# 11.3.5 我是怎么挖掘潜在机会的？

这个点是后面加的，想跟大家分享下：我在套利NOT之前，先挣到了什么钱、抓住了哪些机会，才最终发现交易所新币这个套利机会。整个逻辑链毫无保留地分享给你们。

# 1）赚钱的逻辑

要赚到钱，核心在于三个差：信息差、认知差、执行差。

信息差：你能不能拿到别人拿不到的信息？

认知差：你能不能在这个信息里看到别人看不见的机会？

执行差：你能不能看到机会后，立刻冲上去参与？

对应的提升思路：

信息差，需要你有优质的信息获取渠道。这个我在《开船第一课：新人如何入场Web3（9月航海更新）》里分享过，就不重复了。另外，官网也是一个很好的信息差渠道，具体用法后续可以看版块五：官方信息。

认知差，这事需要你自己在事上磨练，或者有前人指路，教你如何识别一条信息背后的价值。

执行差，当你的认知差到位了，执行基本不会差。如果认知都到了，还是没执行，那就要解决时间/精力管理问题，以及拖延症。

很多人所谓的执行力不够，本质上是对这件事看得不够清晰。如果有一位拿过结果的前辈，把投研数据都摆在你面前，再告诉你这个项目单号能赚多少钱，你还会犹豫吗？肯定不会，因为你知道这是一次确定性的赚钱机会。

但在实际做项目的过程中，没有人能保证每个项目都有确定性的结果。只是有些项目，结合内外部信息和各方利益点的思考，确实存在这样的机会。归根到底，就看你能否找到，找到之后能否判断它的价值。

# 2）利益分析法

大家来Web3就是为了赚钱。但要是所有人都赚钱，谁在亏钱？我们要做的，是努力成为赚钱的那部分人，而不是亏钱的那批。

这就需要我们尽量把各方的利益点捋清楚，然后针对性地考虑自己能赚哪部分的钱。

举个例子，上个月币安搞了第一期Megadrop，会上一个新币，也就是BounceBit的代币，简称BB。

我从币安交易所、项目方、做市商、散户四个角度做了分析：

① 币安交易所：交易所为什么要搞Megadrop？

原因很简单，币安想搞市场增长。起因是竞争对手OKX的Web3钱包做得太出色，铭文那波行情吸引了大量新人使用OKX Web3钱包。而从便利性角度想，这些新人习惯了OKX钱包，自然也更倾向用OKX交易所，因为手机端交易所和钱包之间切换很丝滑。

要吸引人来你的场子玩，得先让散户尝到甜头，把名声打出去，这样才有人愿意进来玩。所以币安的活动肯定不会找太垃圾的项目，那等于砸自己招牌。

② 项目方：BounceBit为什么愿意拿出一定份额的代币给交易所搞活动？

因为币安有足够多的流量。跟宇宙第一交易所合作搞活动，牺牲一点代币换来名声和流量，这笔账怎么算都不亏。

③ 做市商/投资机构：上大所对他们有什么好处？

跟上面一样，上了大所后就有足够的流动性，做市商的操作空间也更大。有流量，钱就会涌进来，流动性高了，市值就更高，做市商、项目方、投资机构都开心。

④ 散户：散户赚的是什么钱？

散户赚的其实是交易所的推广费用。不理解的小伙伴可以去回顾一下前文《11.1.2 项目方为什么要发空投？》。交易所要推广，需要散户去发动身边的人操作，这就给交易所带来了流量，空投的钱相当于交易所给你们的推广费。

很多人想到这一步就停了，所以只会上自己的号操作。但往往就是认知不同，导致上的账号数量不一样，最终拿到结果也不同。

比如我会从这些角度分析判断：①项目简介 ②融资金额 ③投资机构 ④TVL数据 ⑤代币经济模型 ⑥初始流通比例 ⑦代币发行时间 ⑧活动积分计算 ⑨过往新币市值 ⑩预估整体收益。

做完分析后，我把占用成本、磨损成本、利润率都算清楚了，得到的量化数据告诉我，这个活动必须参加。

# 3）实操中发现新机会

我最初是发现了Megadrop的信息，经过分析判断认定这是个机会点。然后在卖出的时候，观察到新币上所后有套利空间。接着又延伸挖掘了CEX/DEX之间的套利机会。

也就是说，这个板块的套利操作，其实是从最初的一个空投项目引申出来的。但大部分人都看不到其中的机会，这恰恰就是我的机会。信息差和认知差都有了，赚钱自然就是大概率事件。

挖掘机会是一回事，更重要的是把挖掘到的机会付诸实践，让机会和实操转化成实实在在的金钱收益。同时把经验记录下来，方便下次复制，拿到更大的结果。这些就是我在做的事情。

以上，是我从币安第一期Megadrop中引申挖掘出的几个机会，包括但不限于：

1. 币安新币开盘极短期套利机会；
2. 流动性较高时段的套利机会；
3. CEX/DEX之间的套利机会。

看到机会、抓住机会，这件事也是需要锻炼的。希望大家能通过对项目的分析判断和实操，不断提升自己抓住机会的能力。

# 11.4 版块四：心态建设

# 11.4.1 为什么心态建设这么重要？

接到赚钱的邀请，让我写这个板块时，我其实犹豫了很久。站在读者角度，谁愿意听别人唠叨心态这种话题呢？

因为心态建设不像撸空投、打新、套利那样“看得见摸得着”，说白了就是不那么快地给你正反馈。没法直接带来收益的事，自然就会被人低估。

但实际上，心态建设对你做决策的帮助或阻碍，大到超乎你的想象。

一般做项目的逻辑链条是：广泛获取信息 → 判断信息可靠性和项目含金量 → 预估收益 → 执行端操作。

正常的逻辑是这样，但心态在其中其实如影随形。

根据我自己的经验，以及观察身边人，赚到钱和没赚到钱的人，一个很大的区别在于：

面对同一个项目，因为获取的信息不同、自身经验不同、对板块了解程度不同，就会做出截然相反的操作。

你可能以为我要讲认知，但我想说的是性格和心态对你做项目的影响。这部分内容，才是同一个项目里，不同人赚钱有多有少，甚至有人赚钱有人亏钱的真正原因。

前两天我在书店偶然看到一本书，乐嘉的《性格色彩原理》。里面讲到，不同的人都有自己的优势，但优势过度就会变成劣势。

比如一个人分析能力很强，那可能说明他的执行力不太行；而一个人执行力很强，则可能思考得不够全面，有些潜在风险没被看见。

这其实就是一个硬币的两面。这也是为什么心态建设说到底，跟自己的性格息息相关。背后的思维方式是连在一起的。表面上，心态和你的操作没有很直接的联系，但实际上，如果没有一个好心态，哪怕你资源再多、信息再多，都没法真正为你所用。

# 11.4.2 不同行情下的心态变化与应对

# 1）疯狂上涨期

每天不是这个币创新高，就是那个币涨了几十倍上百倍，主流币、山寨币、meme币都在疯涨，就你的持仓迟迟不动。

这时候，你会听到各种暴富故事，有人今天赚了几十万上百万，有人财务自由要退圈，等等等等。

再看看自己手上的筹码，账面价值水涨船高。看到热度这么好，哪怕已经涨到了目标收益，也总想卖在更高的位置。结果等着等着，泡沫被戳破，利润全吐回去，竹篮打水一场空。

在疯狂上涨期，你需要做的，是把在“行情震荡期”和“行情平淡期”积攒的筹码，逐步卖给那些跟着热度进来的机构或散户接盘，而不是傻傻地死拿在手里。这里不指BTC和ETH。

没有兑换成BTC或USDT的，都不算你的真实收益。
