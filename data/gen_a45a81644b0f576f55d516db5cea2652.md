# 别再一张张手动传图了，这段 Python 脚本全帮你搞定

经常写文章、搭站点的人，多半都绕不开图片托管这件事。一张张手动上传，费时间不说，还容易漏传、传错。下面这套 Python 小工具，就是围绕图床自动上传做的一站式方案，从格式检查到批量处理，再到上传后的信息查询，基本都覆盖到了。

**先过格式关，再谈上传**

脚本先把常见图片后缀收进一个白名单：jpg、jpeg、png、gif、bmp、webp。上传前会先拆出文件扩展名，转成小写后比对；只要不在名单里，立刻打印“不支持的图片格式”并返回空字符串，不会把无效文件硬塞给接口。检查通过后，才会提示文件有效，进入下一步。

**单张上传：一条完整链路**

真正上传时，脚本会先打印“准备上传到图床”，然后打开图片文件，以二进制方式读取。接口地址指向 imgloc 的上传端点，请求头里带上 `X-API-Key` 做身份验证，表单字段名为 `source`，同时附带文件名和对应的 MIME 类型，比如 `image/png`。请求超时被设置为 60 秒，避免网络卡住时一直干等。

响应回来之后，脚本会分两层判断：先看 HTTP 状态码是不是 200，再看返回 JSON 里的 `status_code` 是否也为 200。两层都通过，才去取 `image.url`；拿到链接就打印成功信息和查看地址，并把 URL 返回给调用方。任何一环出问题都有对应提示，包括响应里找不到图片 URL、业务状态码异常、HTTP 非 200、请求超时、网络请求异常，以及其它未预料的错误。每种情况都会输出错误信息并返回空字符串，不会让程序悄悄失败。

**整个文件夹，一次搞定**

如果你有一整个目录的图片要传，可以用文件夹批量上传函数。它先确认路径存在，再确认它确实是个目录；如果路径不存在或者指向的是文件，都会直接报错。接着扫描目录下的所有文件，逐个判断后缀是否在白名单里，把符合条件的收集起来。如果一张图都没找到，会给出警告并返回空。

找到图片后，脚本按顺序逐张调用单张上传逻辑，每传完一张就记录结果，成功和失败都会打印出来。两张之间还会停 0.5 秒，防止请求太密集被接口拒绝。全部结束后统计成功数量，并把所有成功链接用英文逗号拼成一个字符串返回。

**指定多张，也能批量处理**

除了按文件夹扫描，脚本还支持直接传入多张图片的路径，路径之间用逗号分隔。它会先解析并去掉首尾空白，再逐个检查文件是否存在、是否为普通文件。无效路径会被跳过并提示，如果最后一张有效图都没有，同样返回空字符串。有效文件会依次上传，节奏和文件夹模式一致：逐张处理、记录成败、中间短暂延迟，最后用逗号拼接链接返回。

**上传之后，还能查信息**

脚本里还留了一个获取图床图片信息的入口。它从图片 URL 中截取最后一段，再去掉扩展名，得到图片 ID，然后基于这个 ID 返回基础信息。对于需要回查图片详情的场景，这一步挺实用。

整体来看，这套代码把格式校验、单张上传、文件夹批量、多文件批量以及信息查询串成了一条线，异常分支也铺得比较全。你只需要准备好图床 API 密钥，剩下的交给脚本跑就行。
