# 5.4 NFT 市场的风险与门槛

当然，这个领域也不可能避免会存在一些风险：

1）安全性问题

这个领域的黑客横行，也经常有大量的骗局。如果没有足够的警惕性和安全防范意识，很容易上当受骗。另外一些官方的自我保护意识不够或者技术水平不够，也容易让自己的 Discord 服务器被黑，从而引发一连串的粉丝上当受骗的问题。

我看到太多身边赚了不少财富但是因为安全问题而一夜失去的案例，所以一定要重视。

2）二级市场的风险

跟股票市场一样，大家总喜欢追涨杀跌。但是 NFT 市场对应的风险更高，因为市场变化更为迅速，有可能短时间内价格就翻倍或者腰斩。如果你在高点位进入，大部分最后的结果就是忍痛割肉。

3）没有流动性的风险

NFT 如果流动性不足，也就是即使再低的价格也没有人愿意继续买入，就会形成有价无市的情况。这样一些没有什么价值的 NFT，只会变成一堆在手里卖不出去的图片。

4）摩擦成本

如果玩以太坊的项目，铸造 NFT 的费用，除了本身的铸造费用外，还需要支付一笔不菲的 GAS 费用。所以如果在 GAS 高峰期铸造，很有可能需要多花费数十甚至数百美元的 GAS 费。频繁出手可能并不一定会增加你的收益，但是成本却大大增加了。

5）项目方作恶的风险

因为发行的入门门槛不高，很多项目方就是想来捞一波就走，并不是想真正在这个领域耕耘。所以他们往往做虚假的承诺和宣传，最后大家买完 NFT 之后发现，最终得到的只是没有价值的图片。

6）没有足够的项目辨别能力的风险

看不懂项目，别人说什么项目好就跟着玩什么项目，自己没有足够的了解和判断。遇到差的项目，自然不会有什么收益。即使是好的项目，一旦有遇到一些风险，就恐慌性抛出，非常容易亏损。

7）买到假货的风险

因为人人都可以铸造和上架 NFT，所以 Opensea 上充斥着很多非官方的假的 NFT，如果你没办法辨别真假，很有可能花了大价钱买到一个假的 NFT。

所以不是所有人都能玩得转这个领域的机会。那么什么样的人适合玩 NFT，什么样的人又不适合呢？

以下是不适合玩 NFT 的人：

1）期望通过 NFT 一夜暴富的人。这个市场，不乏一夜暴富的故事。但是请注意，这里存在幸存者偏差。只有赚了大钱的人才会宣传自己，而亏钱总是默默舔舐伤口。所以进入这个领域，不要天天指望一夜暴富，看到别人赚钱就患得患失，心态失衡。应该在这个过程中，不断迭代完善自己的认知，才有可能抓住大的机会。

2）没有执行力的人。只停留在看信息的阶段，但是却很少甚至没有进行实操。会觉得这个也麻烦，那个也麻烦，不想去琢磨。当捡钱的机会来临时，可能因为没有足够的条件或经验而无法抓住。

3）没有独立思考能力的人。见风就是雨，别人说什么就是什么，没有自己去思考背后的原因和逻辑，也没有足够深入了解一个项目。一旦风吹草动，很容易就恐慌和放弃。

4）没有基础问题解决能力的人。其实很多问题，在百度上搜索一下，很快就能得到答案，或者多次尝试各种可能性也能解决。如果基础问题自己不能解决，期待别人来帮你解答，一方面是效率太低，另外一方面，自己成长也会偏慢。

5）没有安全意识的人。从来不做安全保护，一些风险性极大的项目，也没有用小号钱包来尝试。

6）没有辨别能力的人。一些基本上很明显是骗局的手段，也无法分辨，很容易被利益诱惑，一冲动就容易上头。

7）赌性很强的人。经常没有做分析就 ALL IN 某一些项目，期待通过运气来获取高额收益。

当然，与上面罗列的相反特质的人，在这个领域更容易如鱼得水。如果你有不错的学习能力，有一定的执行力，可以在不断的实践中复盘迭代，提高自己的认知，进而提升项目的胜率。

# 六、认识 GameFi @可达 Koda

这一节，我们一同来弄明白 GameFi 到底是怎么一回事。

# 6.1 GameFi 究竟是什么？

看到 GameFi 这个词，其实我们大致就能猜出它的意思。

把 GameFi 掰开来看，无非就是 game 和 fi 两部分。其中的「fi」源自 DeFi，也就是去中心化金融。GameFi 从诞生之初就依附在价值网络之上，所以天生带着金融基因。

当下 Web3 世界里的 GameFi，主要呈现出两个特征：

第一，DeFi 被游戏化；

第二，游戏装备被 NFT 化。

所谓 DeFi 游戏化：我们在 Web3 中接触到的游戏，现阶段大多是把去中心化金融那套东西，套上游戏场景的设计之后再呈现给用户。它的本质仍然是用户在玩的过程中赚到钱——可能是质押代币、质押 NFT 或者买入 NFT 来获取收益，只不过用游戏的形式包装了一遍，这就是 DeFi 游戏化。

所谓游戏装备 NFT 化：这一点和传统游戏截然不同。GameFi 里的所有装备都是 NFT。既然是 NFT，就意味着这份资产归用户所有。

前面章节我们提过，传统游戏有个老问题：游戏公司想没收你的装备或者封你的账号，你在游戏里的装备道具就凭空消失了。换句话说，你对这些游戏装备并没有产权；又或者游戏公司跑路了，你的装备也跟着一起没了。

但在 Web3 里，游戏装备本身就属于你自己，哪怕公司跑路也不影响，因为这些装备就放在你的钱包里。

# 6.2 传统游戏与 GameFi 的对比

接下来，我们从五个维度详细对比一下传统游戏和 GameFi：

1.

游戏资产归属权

传统游戏的资产归游戏公司所有；而在 GameFi 中，游戏产权归用户、归玩家所有。

2.

购买方式

传统游戏里，游戏资产的交易是通过法币购买游戏币、充值或其他形式完成的，整个交易在游戏内闭环。但在 GameFi 中，游戏装备要用 crypto 来买，也就是用加密货币购买。

买完之后，因为它是 NFT 或者游戏代币，并且在整条链上通用，所以可以在全网交易。也就是说，只要有交易平台、有人愿意买你的游戏装备和游戏里获得的代币，就能直接变成你的加密资产。

3.

游戏规则

传统游戏的规则由游戏公司制定；而在 GameFi 中，游戏规则由玩家和有治理权的用户共同参与迭代和制定。这一点也体现了去中心化的理念。

4.

用户心智

这是传统游戏和 GameFi 最不一样的地方。

传统游戏本身已经是一个非常好的商业模式了。用户玩传统游戏，无非是想在游戏里获得快乐、获得心流、打怪升级，在游戏中获得成就感，然后愿意为游戏花钱——通过游戏的机制设计，用户心甘情愿为游戏付费。

但 GameFi 呢？Web3 发展到今天，它的用户群体主要目的还是赚钱，和玩 DeFi 的那群本质上是同一批人——我花 100 块买进去，一周能回本，还能再赚回 100，他根本就不是来玩游戏的。

到目前为止，我没看到哪个用户是冲着玩游戏去使用 GameFi 的，现阶段仍然还是那批 DeFi 赚钱群体。

5.

商业模式

从商业模式上看，传统游戏赚的是用户的钱，很直接：我提供游戏服务，给大家带来快乐和成就感，收取用户的钱，用户愿意在我这里买装备，这是非常好的商业模式。GameFi 的商业模式其实也是赚用户的钱，只不过赚法不同——通过让用户觉得自己能在游戏里赚到钱，带给用户 NFT 以及游戏代币，以此来赚取用户的钱，目前就是这个形式。

至于这两种游戏哪种更好，这也是我们接下来要讨论的问题。后面会有两个案例和大家一起分析。

# 七、认识 DAO @可达 Koda

下面给大家介绍 Web3 世界中的一种组织形式：DAO。

先来看看，什么是 DAO？

# 7.1 DAO 是什么？

DAO 这个概念，最早是 V 神在 2013 年的以太坊白皮书中提出来的。

DAO 是英文 Decentralised Autonomous Organisation 的缩写，中文叫去中心化自治组织。

有意思的是，DAO 的发音和中文里“道德”的“道”一模一样。V 神对中国文化颇有研究，他在《去中心化社会：寻找 Web3 的灵魂》一文中，引用了老子关于道的一句话：道者，万物之奥，善人之宝，不善人之所宝。

西方的 DAO 和东方的道，冥冥之中似乎有着某种联系。

回到正题，我们直接从这三个英文单词拆解含义，理解起来还是比较容易的：

Decentralised——去中心化的

Autonomous——自治的

Organisation——组织

按照组织的定义，组织是有一个共同目的的，所以每一种 DAO 理论上也都应该有一个共同目标。

目前来看，DAO 主要有以下四个特点：

1.

免信任

DAO 是一个免信任的网络组织。因为它基于区块链技术、智能合约、数字钱包等，组织中的所有信息都会被记录在网络上。在这个网络里，你不需要信任组织中的其他人，只需要信任去中心化组织的代码就够了。

2.

透明

DAO 是一个透明的网络组织。得益于区块链技术，这个网络组织的所有信息都是公开透明的，信息披露的真实性、全面性和数量级，相比传统组织形式会有大幅提升。

3.

使用权

进入 DAO 的人，即拥有使用权。这个组织里没有公司老板，只有组织发起人。发起人在组织中有影响力和号召力，但并不拥有这个网络。

4.

无需许可

加入和退出这个组织，由本人决定，无需向任何人申请。

# 7.2 去中心化组织与传统组织的对比

去中心化组织和传统组织，主要有以下几点不同：

1.

去中心化组织通常是平等的，并且完全民主；传统组织通常等级分明。

2.

去中心化组织需要成员投票才能实施任何更改；传统组织可能部分人就能决策，也可能投票表决，具体取决于组织结构。

3.

去中心化组织不需要可信的中间人就能自动计算投票、执行结果；传统组织如果允许投票，则在内部计票，投票结果必须由人工处理。

4.

去中心化组织以去中心化方式自动提供服务（例如慈善基金的分配）；传统组织需要人工处理或自动集中控制，容易受到操纵。

5.

去中心化组织所有活动公开透明；传统组织活动通常私密进行，不向公众开放。

# 7.3 第一个 DAO

理论上，满足上面四个特征的，都可以称为 DAO。我们可以把比特币理解成一个 DAO，也可以把以太坊理解成一个 DAO，未来甚至任何去中心化、由社区成员自治管理的组织都可以叫 DAO。

2016 年，以太坊社区成员宣布发起创办世界上第一个 DAO。这个 DAO 的名字也很简单，就叫 The DAO。

The DAO 是一个投资型 DAO，持有该项目代币的人可以参与投资决策和分红。项目一经推出，28 天就筹集了 1270 万个以太币，总价值约 1.5 亿美金。

不过没过多久，这个项目就遭到黑客攻击，被盗走 360 多万个以太币，最终迫使以太坊硬分叉。

# 八、Web3 的监管 @可达 Koda

# 8.1 Web3 的监管逻辑

监管合规，是任何行业都绕不开的问题，尤其是 Web3 这样在金融领域进行革新、同时又在快速增长的行业。这一章，我们一起来了解 Web3 的监管逻辑、各国的监管政策以及目前监管相关的 Web3 公司。

首先，我们试着站在国家政府的角度想一想：为什么需要监管？我认为主要出于以下三点：

1.

金融管控

2.

民众维权

3.

税收

金融管控方面，我们知道比特币和区块链技术诞生，解决的就是去中心化、点对点支付的问题。

在当今世界，一旦实现点对点支付，就必然会涉及一些政府监管的盲区，比如洗钱、赌博、黑市交易、传销等问题。这类问题本来就属于传统金融监管范畴，不管在 web 几，都应该受到政府监管。

对于这类问题，Web3 中目前有两派观点：一派认为，完全的去中心化就是任何东西都可以交易流转，个人产权和隐私更重要；另一派是合规派，认为去中心化需要受到监管合规的约束。

因为 Web3 自带金融货币系统，参与项目的民众自然会有资产安全问题。

比如我们之前举例的 UST 稳定币，民众把 UST 当成了美元，但这种所谓的美元价值归零了，这时候就会有大量民众找政府维权。我们也看到，Luna 崩盘事件后，韩国政府也展开了对 Terra 公司的调查。

所以一些 Web3 公司从一开始就做合规，比如 USDC，在政府监管背书的基础上开展 Web3 相关业务。

Web3 的组织形式是 DAO，组织中通常流通的货币是加密货币，这也会涉及很多税收问题。因为税收基于法币体系，不同国家也开始建立相关法律法规——有的国家要对 Web3 行业收税，有的国家免税，各国政策不同。

我们可以先看看全球对加密货币的监管政策。红色代表禁止，橙色代表敌对，黄色代表中立，浅绿色代表支持，深绿色代表全球领导者。这样我们就有了一个全局视野。

# 8.2 各国监管政策

接下来，我们再详细看看全球代表性国家和地区的监管政策。

# 美国：多头监管快速跟进，支持行业创新，确保全球领先地位【新】

今年，一篇美国议员提出的“确保 Web3 革命发生在美国”的文章在圈内广为流传。以至于后来我们经常能看到各类文案变体，比如确保 Web3 发生在湾区、确保 Web3 发生在大理、确保 Web3 发生在 XX 等等。

从这个提案背后，我们可以看到美国的监管逻辑仍然是创新驱动的：积极鼓励各类创新，但法律法规要快速跟进，服务于产业创新。

美国总统拜登在 2022 年 3 月签署的《关于确保负责任地发展数字资产的行政命令》中强调的也是：负责任的创新，通过加强监管引导加密货币行业良性发展，以保持美国的领先地位。

整个监管政策从国家部门到地方落地的速度非常快。美国国会、证监会等部门先后推出多部涉及 Web3 的法律条文。州立法方面，科罗拉多州、怀俄明州、得克萨斯州、加利福尼亚州、俄亥俄州的立法都比较友好。

包括美国一些传统证券交易所，也推出了一些购买加密货币的基金。

2023 年，美国监管政策继续快速推进落地。6 月，美国证券交易委员会（SEC）通过对 Coinbase、Binance 的诉讼案件，直接向美国司法、立法机构提出了一个争议最大的问题——什么样的加密资产属于证券？

SEC 认为 95%～98% 的 Token 都是证券，也就是所谓的 Security Token。以保护投资者为出发点，他们采取执法行动，想给 Web3 行业提供清晰指引，发出强烈信号：我们在监管这个行业，不会允许欺诈、洗钱，不会允许任何人滥用美国的金融体系。

同时，随着市场不断规范，以及比特币商品定位的明确和价值的不断认可，都在进一步推动华尔街资本入场。可以预见，大量法币资金将可以合规进入 Web3 市场，这非常可能成为下一轮牛市的催化剂。

各个传统金融巨头蓄势待发，其中灰度、贝莱德两家全球头部基金已经就比特币现货 ETF 上市及交易规则和 SEC 进行了多轮商议。比特币现货 ETF 的获批将成为一个冲锋标志，我们拭目以待。

具体的落地执行，我们可以从“定性”和“创新监管”这个框架去看。

首先，一些常见属于传统监管范畴的问题，如赌博、金融诈骗、传销等，不管在 web 几都应该受到监管，这里暂不讨论。

在定性和创新部分，各国目前政策不同。创新的部分，我们可以从金融、税收两个角度展开来看。

【Token 定性】

非货币化财产商品

【金融】

主要包括：ICO 应当受到美国证监会监管；美国财政部下属金融犯罪执法网络对加密货币交易进行跟踪，重点执行反洗钱和打击恐怖融资；商品期货交易委员会对未经注册的加密货币期货交易予以调查、处罚；各州需要持有金钱服务牌照才能从事相关交易。

【税收】

2021 年起将数字资产在税收方面定性为证券，从事加密货币交易的人应当主动申报。美国税收署会对区块链交易信息进行收集，打击加密货币逃税行为。

【其他】

除上述监管外，还有美联储对加密货币的定性——通常不承认加密货币等资产是货币。美国财政部海外资产办公室会将一些列入美国制裁名单的人和组织，将其钱包列入黑名单，违反制裁规定者可能面临重大民事或刑事处罚。

# 中国：去币存链

我们知道，Web3 包括区块链技术和去中心化金融。中国的监管政策目前也很清晰：区块链部分大力支持，去中心化金融部分全面禁止。

在区块链部分，十四五规划中，区块链被列为七大数字经济重点产业之一，成为发展数字经济和建设数字中国的重要载体。

技术创新、平台创新、应用创新、监管创新。区块链产业的具体发展规划：推动智能合约、共识算法、加密算法、分布式系统等技术创新。

各部委的发文也可以看出，需要积极拥抱区块链、元宇宙等技术，赋能产业升级和数字化转型。

具体的落地形式有联盟链、数字人民币。
