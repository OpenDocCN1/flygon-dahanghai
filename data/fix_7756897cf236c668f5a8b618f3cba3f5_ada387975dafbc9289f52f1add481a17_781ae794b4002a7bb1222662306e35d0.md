# 七、选品方法再拓展

选品思路看起来多，整理起来就是三条：

1、从📕站内选
也就是在站内已有的品中挑适合自己的款。常用方法有灰豚数据选品法、低粉爆款选品法等。

2、从抖音平台选
抖音跟📕一样是内容带货平台，目前找品建议优先看抖音。常用方法有考古加选品法、蝉妈妈选品法、抖音精选联盟创意中心选品法等。

3、从传统电商选
去淘宝、拼多多等平台找合适的商品。

必修篇已经讲了抖音选品，这里再补充另外两个：站内选品和传统电商选品。

# 7.1 站内低粉爆款选品法

先解释一下低粉爆款：带货账号粉丝低于 200，近 7 天发的一篇带货笔记点赞超过 100，并且该笔记商品销量大于 100。满足这三条，就是低粉爆款品。

这个方法的目的是找到站内正在推且有潜力的爆品，第一时间跟进截流。跟抖音创意中心选品比，它更适合做女性类目的人——因为这类品更容易在📕先爆，比如雪莉枚 U 形枕、发箍、帽子，很多爆款素材都是从红书先出来的。

站内找低粉爆款有两条路：用灰豚数据，或者手动刷。不同品类要观察后选适合的路子，前期建议两招搭配，多维度看。

# 7.1.1 灰豚数据低粉爆款选品步骤 @书豪

工具只是实现目标的手段，按自己喜好用即可：

第一步：打开灰豚数据
第二步：点击笔记查找，选择笔记搜索
第三步：勾选【带货笔记：是】
第四步：勾选【低粉爆文】
第五步：输入对标词，比如做连衣裙就搜“连衣裙”。

即使有灰豚数据，对标账号也要卡标准：粉丝 200 以下、笔记 7 天内点赞大于 100、带货商品销量大于 100，才选。低粉爆款逻辑不变。

[PRE4]

# 7.1.2 在📕内手动刷

确定做某个品类后（如帽子），可以开个小号，持续搜帽子相关内容。系统会给这个号打上“对帽子感兴趣”标签，接着推送更多帽子笔记。

看到系统推的内容，点进笔记主页，看博主粉丝是否较低（尽量小于 200）。符合条件就关注、点赞、评论。系统慢慢会记录你喜欢低粉帽类账号，之后优先推更多帽子的【低粉爆款】。

每天刷小号，能第一时间知道最近有哪些新款式、什么文案和封面更吃香。看着费时间，但刷的过程其实在培养品感和网感。

[PRE5]

# 7.2 电商平台选品法：推荐款式类产品使用

电商平台选品，指的是从淘宝、拼多多等传统电商渠道发掘潜力爆款。这里重点建议掌握“原创店铺新品截品”：找有原创能力（主要是产品素材原创）的店铺，盯紧她们的上新，素材图直接拿来用（用前查一下有没有被别人发过）。

大多数人做红书第一步还是混剪/二创，所以电商平台的品再好，没有对应素材也白搭。但如果你做的品适合图文笔记，能直接用商家最新商品图做二创，那这个选品法就值得考虑。

我们用这种方式选过发箍、手串、圣诞节香薰等品类。同样的截品思路也能用于抖音：找有原创能力但还没做红书的商家，第一时间搬到红书。比如下图发箍，靠电商平台选品法爆了 4 个号、5 个款式。

# 7.3 对标账号选品法：截品

确定品类后，用小号关注很多同行账号，同行就是最好的老师。每天花 20 分钟看他们当天上的新品，重点盯发布时间差不多但数据更好的品（如图红框）。发现上新数据不错的，马上跟进。

# 7.4 不同选手的选品侧重点参考

# 7.4.1 新手：跟最新爆品

新手不要只盯着自己想卖的商品，要跟着近期热度高的品走，越新越好。1.0 阶段给一个基础判断：去做抖音创意中心爆款榜上的品（可复习创意中心选品法）。别过分在意数据绝对值，比如必须销量多少、点赞多少。能上这个榜单，已经说明品很好了。

新手阶段别贪多，不需要掌握复杂选品法。其实一个创意中心选品法用好了，就足以跑通正反馈。跑通后再升级自己的选品能力，做出差异化。

# 7.4.2 进阶型：同步跟红书站内爆品

进阶型玩家指素材制作能力强、封面做得好、已经跑通正反馈的人。这个阶段可以同步看红书站内爆品（低粉爆款选品）。

和 1.0 阶段的区别是：如果发现一个品在红书站内已经爆了，说明它不只是抖音能爆，红书也能爆，进一步验证了爆品适配性。但同步的问题也明显：别人已经爆了，站内有竞争，需要你跟品速度更快、素材能力更强，才更容易胜出。

[PRE9]

# 7.4.3 天赋型：提前挖掘需求产品 / 高爆品

能力更强、能预判爆品的人，当然要主动挖掘。一方面提前卡位：秋冬来之前布局手膜、脚膜、暖手袋；节假日前布局化妆收纳包、毛毯、U 形枕等出行品；夏天前布局拖鞋、滚腿神器等运动小器材。另一方面，在爆品上继续发力：爆过的品一定还能再爆。如果技能更高，不用依靠别人的素材封面，而是自己创造爆款封面和素材，那样你就是别人模仿的对象了。要知道，每一个爆款都是天赋选手把之前爆款内容再加工后的产物。

# 八、项目放大：SEO

# 8.2.1 📕 SEO 的底层逻辑

SEO 即 Search Engine Optimization，翻译成中文是搜索引擎优化。在红书，SEO 就是通过优化笔记关键词，让笔记搜索排名更靠前。

现在很多人把红书当成“百度”用，约 70% 的用户会先来搜索攻略。比如圣诞想送朋友礼物，我会搜“圣诞礼物”，然后打开相关笔记，尤其是前面几篇吸引我的。如果内容打动我，就会跟着博主买同款，完成种草到拔草。

所以搜索来的用户消费意愿普遍更强，搜索流量相当于超精准流量，甚至可以说是躺着赚钱的流量。某个词下面，你的笔记排名越靠前，产品越容易被看到，也越容易主导用户决策。这就是📕 SEO 的底层逻辑。

[PRE11]

# 8.2.2 📕 SEO 流量介绍

明白底层逻辑后，再说说做 SEO 的三个好处。

1）流量精准，转化率高

不管你是纯博主还是商家博主，关注的重点无非两点：流量和变现。流量是变现的前提，所以怎么拿捏流量，是每个博主的课题。

红书流量主要有三个入口：推荐页、关注页、搜索页。推荐页默认打开，流量最大但竞争最激烈，普通人上推荐页比较难，需要内容足够好。关注页打开率不高，关注人数多的时候，你很容易被挤没影。搜索页更适合普通人突围，只要有一篇笔记靠前，就能给整个账号带来持续流量。

搜索流量本来就是主动种草型，用户带着明确目的，所以更精准、转化更高。我们的很多账号，搜索端粉丝占比超过一半。

[PRE12]

2）免费流量，不拿白不拿

一篇笔记的自然推荐周期大概是 3-7 天，哪怕爆款，时间久了推荐流量也会下降。平台要不断补充新内容，你想继续占推荐位，只能靠广告投放。

但搜索流量不一样，只要关键词铺对了，笔记也没违规，它就能一直被搜到。两三个月前的、甚至一年前的笔记，照样给你带人。这等于在平台放了免费长期广告，当然要拿。

3）矩阵运营，占领赛道流量

我常跟学员说，尤其是商家博主，建议做矩阵号。原因有两点：一是降低风险。商家博主常有引流需求，而平台禁止导流。常在河边走总会湿鞋，违规是小事，封号就麻烦了，all in 一个号风险太大。二是多一个号就多一个入口，还能满足用户“比价”心理。号铺得够多，用户货比三家后进的还是你这里。当然，前提是关键词要对，用户搜不到你，号再多也没用。所以，做 SEO 很有必要。

[PRE13]

# 8.2.3 影响 SEO 排名的因素

说方法论之前，先看什么影响笔记排名。大方向就两个：账号权重和笔记权重。

权重这个词常被否认，但它确实存在。账号活跃度、原创率、垂直率影响账号权重；笔记发布时间、点击率、互动率影响笔记权重。权重越高，越容易被搜到。

并且笔记权重对排名影响更大。比如新人账号权重低，但关键词铺对、内容过关，第一篇笔记也可能爆。一旦笔记爆了，其他笔记也会被带动，账号权重跟着涨。只要账号没有严重违规，正常笔记都能被搜到。当然，前提是笔记里要有用户搜的词。

那么，哪些词用户搜得多？去哪找？

[PRE14]

# 8.2.4 挖掘高热度行业搜索词 @谢无敌 @蓝弈

用户搜索行为主观性强，但也有规律。先看有哪些搜索词类型。

# 8.2.4.1 选词策略

1）核心关键词（必要项）

核心关键词是产品和笔记的中心，一般是产品词或类目词。拿护肤品举例，核心词可以是洗面奶、面霜、乳液。写洗面奶种草笔记，标题、图片、脚本或正文里，至少有一处要含“洗面奶”。

2）蓝海词

蓝海词不用多，100 个以内。月搜索量平均几万，内容始终围绕这些词做。做完一轮，可以换一个号再把这些词做一遍，实现关键词霸屏。

3）关联关键词

关联词=核心词+关联标签，也叫长尾词。洗面奶的关联词如：氨基酸洗面奶、敏感肌洗面奶、洗面奶测评等。

4）高转化词

高转化词是购买意向明显的词，比如平价洗面奶推荐、洗面奶怎么买、某品牌洗面奶好不好用。

5）热搜词

热搜词分热点类热词和行业热词。热点类热度高但未必贴合定位，比如“阳了”“小阳人”。通常要找行业热搜词，与节日、人群、功效相关。还是洗面奶，热搜词可能有学生党洗面奶、某品牌洗面奶。它流量不稳，一直变化。

# 8.2.4.2 关键词挖掘方式

[PRE15]

1）聚光平台关键词规划工具

聚光平台的关键词规划工具很强大，可以从笔记推词、以词推词、上下游推词、行业推词等维度选词。比如“以词推词”，输入关键词后会出现蓝海词、同行买词、黑马词和高点击词。蓝海和黑马都是竞争小需求大的好词。

作为官方平台，数据比较准。缺点是只有已经认证并开通广告功能的企业号能登录使用。

2）千瓜数据

千瓜是专注📕的数据分析平台，关键词排名、对比、下载功能都很齐全。

[PRE16]

左侧点“热搜词搜索”，输入关键词会出现很多关联词，每个词有热度值和笔记量。可以自己建个表格，用热度值除笔记量算出比例，比例大的说明搜索多、竞争小，适合作目标词。“热搜词榜”还能看到热词增量榜和总量榜。

[PRE17]

两种方法都能直接导出，统计整理方便。缺点是收费，会员一个月几千块，普通人成本偏高。

3）📕平台

这是免费挖词，但要花时间。主要入口：

① 搜索栏下拉框

在红书搜索页输入关键词，例如“洗面奶”，下方会显示一串关联词。这些词是系统按近期搜索频率总结出来的，挑合适的去铺。但有时要做取舍，“洗面奶推荐”热度更高，可搜一下会发现笔记数量已经 107w+，竞争压力大；“洗面奶氨基酸”只有 23w+，压力小，更适合布局。

[PRE18]

② 搜索结果页面

输入关键词后进入搜索结果页，很多地方会出现关联词。顶部标签栏有一行相关词，左滑能看到更多，可选几个组合用。继续往下拉，会出现“大家都在搜”，这一栏既可以用作关键词，也能作为笔记选题。

[PRE19]

③ 标签浏览量

[PRE20]

笔记正文一般都会加话题标签，点进话题可以看到浏览量和相关笔记。去同行笔记页统计收集即可。

④ 笔记灵感

路径：我 -> 创作中心 -> 下滑“笔记灵感”。每个灵感都是对应领域，在合适领域里选发布量高的词。比如上班早餐、通勤穿搭、闺蜜的冰激凌、本地美食、本地人爱吃的店。

[PRE21]

⑤ 社区热搜词

路径：📕商家版首页下滑到“社区热搜词”。
