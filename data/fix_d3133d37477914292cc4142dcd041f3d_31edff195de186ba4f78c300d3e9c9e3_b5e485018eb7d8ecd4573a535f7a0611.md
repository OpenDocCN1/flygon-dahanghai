1. 功能清单

- 环境一键搭建
  - 常见环境：LNMP（Linux + Nginx + MySQL + PHP）、LAMP（Linux + Apache + MySQL + PHP）、Tomcat、Node.js、Java 等。
  - 可一键安装、升级、切换 Nginx、Apache、PHP、MySQL/MariaDB 等不同版本。
- 站点维护
  - 快速建站、绑定域名、配置 HTTPS（免费 Let's Encrypt 证书）。
  - 提供伪静态规则、301/302 重定向、反向代理、负载均衡等。
- 数据库维护
  - 支持 MySQL、MariaDB、PostgreSQL、MongoDB。
  - 内置 phpMyAdmin、Adminer 等可视化工具，也支持远程连接。
- FTP/SFTP 支持
  - 内置 FTP 服务，支持用户分级权限管理。
- 文件操作
  - Web 界面上传、下载、编辑、解压缩文件。
  - 支持在线编辑代码。
- 安全防护
  - 防火墙管理：端口放行、IP 黑白名单。
  - 系统安全体检，提醒风险配置。
- 定时任务
  - 定时备份数据库和站点文件，支持自动清理日志、定时执行脚本。
- 运行监控
  - 实时监控主机 CPU、内存、硬盘、流量等指标。

1. 长处

- 上手简单：对新手和非专业运维人员友好。
- 功能全面：建站、运维、管理、监控一个面板完成。
- 插件丰富：应用商店提供缓存、负载均衡、监控告警、云端备份等插件（部分收费）。
- 跨平台：同时支持 Linux 和 Windows。

1. 短板

- 安全风险：BT 面板默认跑在 8888 端口，若未改默认端口、限制 IP、设强密码，容易被扫描攻击。
- 性能开销：相比纯命令行，会多占主机资源。
- 商业化：基础功能免费，高级插件和部分功能收费。

1. 适合人群与场景

- 个人站长、独立开发者：快速搭建 WordPress、Discuz 或类似 Shopify 的系统。
- 中小企业：建站、内部系统部署。
- 学习测试环境：练习 LNMP、LAMP 环境搭建。

# 1. 部署方式怎么选：

- 自有主机：约 16 美元/月，时间成本低，可维护性高。
- Vercel + Supabase：20 美元 + 25 美元，配置较复杂，可维护性中等。

自己有主机部署更简单，不用太多复杂配置，想装什么工具都行。一台机器能放多个站点，通常 2 核 2G 至少可部署几十个站点。这是一套通用思路，不限于某个框架。

# 2. 借助 AI 自动部署

AI 部署需要较强的模型，比如 Claude Code，适合测试环境。尽量不要让 AI 操作线上环境，操作前先备份数据或打快照。主机可用前面提到的 DigitalOcean 或其他云平台。AI 表现不一定稳定，可能需要多试几次。

# 2.1 第一步：在控制台设置页上传公钥

这次用 SSH Key 登录，主要因为 Windows 下 AI 不能用明文密码登录主机。需要先上传公钥，创建主机时选择对应公钥，才会加载。
