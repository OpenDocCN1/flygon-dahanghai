**1.1 重点提前了解**

**（一）👸号全自动 Skill 的完整工作流程**

先理解整体流程，才能明白每个环节在做什么：

第一步：搜索采集 AI 热点资料
用 Exa 或 Tavily 这两个 AI 搜索工具，查找 24 小时内关于指定主题（比如“open claw”）的最新资讯，包括技术突破、市场反应、行业影响等，然后结构化整理，为写文章准备素材。

第二步：撰写文章
基于搜索到的资料，用 AI 生成 Markdown 格式的文章。文章会按你设定的风格（技术深度、通俗易懂、行业分析等）来写，并在需要配图的位置插入图片标记。

第三步：生成配图
解析文章中的图片标记，提取每张图的描述（prompt），然后调用 APImart 的 gemini-3-pro-image-preview 模型生成插画风格配图，整体风格保持手绘漫画、温暖、亲和、有故事感。

第四步：上传图片到🛰️服务器
把生成的图片上传到🛰️👸号素材库，获得每张图片的 media_id，方便后续在文章中引用。

第五步：转换为 HTML 并发布到草稿箱
把 Markdown 文章转成🛰️👸号支持的 HTML 格式，替换图片占位符为🛰️服务器上的图片 URL，然后调用🛰️👸号 API，把文章发布到草稿箱。

第六步：提示用户检查
Skill 会返回一个预览链接，提醒你去👸号后台查看文章。满意就发布，需要修改就在后台编辑后再发。

Claude Code：核心开发工具，负责创建和管理 Skill。它理解自然语言需求，自动生成代码、配置 API 调用，是整个 Skill 的“大脑”。
