# 7.2.2 方法二：if then 法

拖延这件事，还有一个很值得尝试的解决办法叫 if then。不妨把自己想象成一部总在关键功能上出 bug 的手机，而拖延，就是那些反复卡住的地方。如果我们换一套 if then 的指令，是不是就能跳过“想太多”，直接启动行动？

举个例子，很多人想坚持跑步，真正的难点不是跑步本身，而是醒来后赖在床上起不来。用 if then 重新设置一下，就变成“早上醒来，就去跑步”，把纠结和抵触直接从流程里删掉。

阅读也是一样。我们常常想要看书，却不知不觉刷起了手机。那就可以在脑子里预设一个反应：一旦发现自己又拿起手机，就立刻切换到阅读。用这种条件触发的方式，一点一点把新习惯刻进日常。

这个方法已经帮成千上万的人慢慢养成了好习惯。如果你也正在被拖延困扰，不妨试着把某个小行动改写成 if then 的指令，从一件小事开始看看变化。
