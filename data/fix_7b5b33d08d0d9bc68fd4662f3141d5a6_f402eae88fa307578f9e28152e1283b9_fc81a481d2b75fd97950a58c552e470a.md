# 五、应用商店上架

# 💡

# 章节要点

硬件方面，需要一台 Mac 和一部 iPhone，用来做真机测试。软件方面，必须拥有 Apple 开发者账号，年费 99 美元或 688 元人民币，这是上架的前提。

整个流程分三段：

1. 上架前准备：注册开发者账号、设计应用图标、创建 App ID、生成证书和描述文件；
2. 打包发布：在 Xcode 中归档，上传到 App Store Connect 过审；
3. 商店页面：制作预览图，填写技术支持网址、隐私协议等。

版权信息格式：个人开发者署真实姓名，公司则署注册名称，统一写成“Copyright © 年份 名称。 All rights reserved.”。

把这条流程走一遍，新手也能自己搞定 iOS 应用的上架。

# 💡

# 本章航线图

完成本章的学习和练习，就能推进到航线图的第三阶段——应用上架与变现功能集成（约 8 天）。其中，App Store 上架准备（开发者会员、App ID、证书与配置文件）大约需要 2 天；应用打包、上传 App Store Connect 以及商店信息（含版权）设置约 2.5 天。

# 5.1 上架前要做的几件事

# 5.1.1 注册 Apple 开发者会员

进入 https://developer.Apple.com/ ，注册开发者会员。费用是每年 99 美元（或 688 人民币）。没有会员身份，应用无法上架。

在工程列表中展开 Assets.xcassets，选择 APP Icon，之后将 icon 图片从素材包拽入对应位置。如果放到 iPhone 真机上跑，桌面就会显示这个图标。

# 5.1.3 新建 APP ID

登录 https://appstoreconnect.Apple.com/ ，在顶部导航找到 APP 栏目，点击“+”号新建应用。

[PRE31]

按表单要求填写：选择要发布的平台，输入应用名称，设定主要语言，确定套装 ID。SKU 随便写一串数字即可。没有 ID 的话，可以先创建一个。

[PRE32]

Description 可以用应用名的拼音填写。Bundle ID 必须与 Xcode 工程里的标识符一致（com.xxx.xxxx）。权限按需勾选，比如 WiFi、相机等。如果只是本机运行的单一功能，可以一个权限都不勾。
