# 8.3 售前沟通与成交

客户进入私域后，就可以围绕需求沟通了。

# 8.3.1 沟通思路

# 📌

在AI写作项目里，客服相当于plus级写手。不懂后端产品的销售，很难成为好销售；不会写作、不懂写作的人，也较难把客服工作做好。优秀客服往往是从优秀写手中培养出来的。

客服报价、谈单、成单受很多变量影响，比如沟通、谈判、说服、销售、用户心理把握、预期管理、专业度展示、情绪价值提供等。

AI写作市场没有统一价格标准，品类多为非标品，而非标品才有溢价空间。最终成交价会受到稿件类型、用途、字数、时间要求、同行竞争、客户预算、谈单话术等因素影响。

1. 客服第一目标是成交，但别为了成交过度承诺，要把长期合作放在前面。
2. 站在客户角度思考，保持同理心和利他意识，以信任为基础建立客户关系。
3. 用专业话术、成功案例、实力背景等方式展示专业度，增加客户信任。
4. 谈价时以价值为导向，让客户明白盲目压价会影响最终写作质量，避免陷入被动讨价还价。

# 8.3.2 客户沟通流程

# 8.3.2.1 接待客户

第一步：问候与自我介绍

话术示例：“宝子你好，我是xx专业的老师，可以和我说一下你的写作需求。”

同时可以判断客户身份和付费能力，比如问专业、学历、学校或学校级别，或看闲鱼IP、发品与成交记录、朋友圈等。

第二步：了解客户需求

了解客户信息：学历、学校、专业、行业、公司、职业。

引导客户详细描述写作需求，如稿件类型、具体用途、审核或汇报对象。

话术示例：“宝子，这份商业计划书是作业、参赛还是融资使用？”“这份教案是日常授课还是参赛使用？”

第三步：问题探询

询问项目具体要求，如字数、语言风格、完成时限等。

引导客户补充信息，如需不需要数据图表、设计图等，以便更准确分析写作难度和工作量，准确定价、避免踩坑。

话术示例：“除了字数7k以上，这篇调研报告是否需要问卷调查和数据分析部分？”

# 💡

P.S. 如果看不懂客户需求怎么办？

可以借助AI先大致理解需求，用自己的话梳理清楚，再和GPT对话。prompt示例：“有个客户需要写一篇教师征文，方向是初中英语教学中情景短剧的作用，6000字，请你扮演专业的教师征文写作老师，与客户沟通写作思路和架构，让他觉得你很专业且能够和你建立信任。”

也可以把自己带入客户角色，去咨询闲鱼、淘宝同行。

问客户有没有参考样稿或对标范文，分析工作量；如果没有，去Meta搜类似文章，初步评估工作量。

# 8.3.2.2 介绍服务与报价

报价与费用说明：

根据客户需求提供阶梯报价，分为“正常质量XXX”和“高质量XXX”，让客户清楚不同服务档次的价格区间。

解释收费依据，说明加急服务、内容复杂度、特殊要求等会影响报价，让客户理解费用背后的逻辑。

折扣与优惠信息：防失联+MM188166M（李李）长期更新

预算有限的客户，为促成订单可给小额折扣（5%～10%），但折扣别太大，免得客户觉得议价空间很大、利润很高。

议价时强调价格和质量挂钩，引导客户理解：在不影响质量标准的前提下，可以通过适当减少字数、少做1～2个图表、限制修改次数等方式降低价格。让客户感受到每次调价都基于合理成本考量。

# 💡

AI写作定价公式

价格=工作量（基础工作量+复杂工作量+修改量）+质量要求+时间紧急程度

以调研报告为例：

基础工作量，相当于字数要求。

复杂工作量，看领域是否小众、是否需要特定专业知识、是否涉及数据、表格、设计图、代码、公式、仿真、建模等，对写手要求高。

修改量，主要看是否会反复修改，或修改核心内容。

质量要求，主要看客户自身目标和需要。

时间紧急程度，时间急要额外收加急费。

根据客户信息和需求报价，按交付质量、写手资质、修改次数等维度阶梯式报价，给客户多种选择；小单子直接一口价也可以。

演讲稿谈单案例：

1. 需求沟通与收集：稿件类型、字数、用途、交付时间。
2. 报价：按质量要求、修改次数，给客户提供不同报价方案。

# 8.3.2.3 确认需求和下单

确定订单细节：

了解完客户需求后，清晰告知客户：后续新增或更改需求，将根据工作量酌情收取额外费用。

下单：

主动引导客户完成下单，话术：“宝子，确认下单后就给你安排写作啦！”

# 8.4 售后问题解决方法

# 8.4.1 如何规避售后问题

专业客服能在售前解决掉很多售后隐患。比如和客户明确需求与规则，要评分标准、参考样例，确认稿件质量目标是获奖还是普通应付领导，详细分析需求指标，用售前手段提前规避售后纠纷和扯皮。

售前搞定后，还要依赖交付稿件的质量。专业客服把单谈得漂亮、价格也漂亮，但写手不靠谱、质量低，仍可能搞砸一切、失去客户信任。

高质量写手能通过满足需求的稿件完成满意交付。市场上找人代创作文案的客户，80%对质量要求不会特别高，用航海手册里的海盐大法（方法论）写作，已经像手握秘籍一样能应对客户需求。

99%来找文案代创作的客户不是想白嫖，而是需要质量不错、能满足需求和标准的稿件。分析大量售后案例，原因主要有两类：

1. 谈单客服不专业

客户需求不明确时，客服无法挖掘、梳理出真正需求，只能给写手不完整或经过曲解的需求。写手接到任务后不知道要写成什么样才能满足客户，结果写完后被要求重写；半懂不懂的客户依旧说不清想要什么效果，稿件改了一遍又一遍，最终被贴上“不专业、不靠谱、瞎写”的标签。

2. 写手写作水平不达标

写手交付的稿件AI词汇多、内容空洞、结构混乱，往往是因为没搞明白客户需求，或缺少相关经验和背景知识。客户拿到后只觉得“不专业、不靠谱，还能不能相信你”，改几次仍有问题，旧问题没解决新问题又出现。客户会说：“退款吧，写的什么东西，骗子，改这么多次浪费我时间，没空跟你墨迹。”

经过大量实战订单剖析和优化，可以确定：95%的售后问题都能靠售前解决。专业客服+靠谱高质量写手，可以搞定绝大多数客户。

当然，小白阶段还在练手期，会有成长过渡过程。前边教的客户沟通思路和技巧还没完全吸收时，可能出现小部分售后退款。没关系，技术实力不硬气时，可以主打态度好，记住【市场、客户是最好的老师】。好好修改、认真负责，多查资料、多改几次；实在满足不了客户需求，再态度平和地退款，避免客户去评论区留差评，影响新客户信任。

小白刚起步，吃亏是福，有搞不定的订单和客户很正常，这些都是宝贵成长经验。

如果没有cover住客户，又实在不想退款，可以看下方退款纠纷话术，或许能帮到小白阶段的宝子。

能不通过闲鱼平台官方解决纠纷，就尽量别走这一步。这一单的钱没那么重要，时间更宝贵，把钱退给客户。你和客户撕逼battle的聊天记录，99%的客户会截取对自己有利的部分去给差评，而评论区差评是永久可见的。你再有道理，一些客户看到差评和撕逼记录，也会留下不好印象，不想冒险找你写。理智的人很少，看到你撕逼，很多人会下意识觉得找你写也可能被撕。

在这个快节奏时代，差评多的店铺，客户可能都不会点开细看原因，店铺那么多，直接划走。

非100%好评的店铺，在闲鱼平台权重也会降低，无法获得100%好评标签，还会影响商品推流。

# 8.4.2 处理退款纠纷话术 @掩体

稿件写作属于虚拟商品，平台会优先倾向顾客，所以要更有效处理纠纷，尽可能挽回损失。

一般成交会在🛰️上和顾客完成，优先在🛰️解决；实在解决不了，再到平台处理。处理纠纷时可用以下话术。

# 九、常见问题QA @小虎牙 @陈bu懂

# 9.1 闲鱼基础答疑

Q1：手机实名账号有数量上限吗？能否用朋友或家人注册认证新账号后，放到自己手机上正常运营？
A1：可以，但闲鱼平台可能每半个月到一个月触发一次人脸识别认证。

Q2：注册支付宝和闲鱼账号需要在新手机上注册吗？
A2：不需要，但运营过程中要遵循一卡一号一机，即一张手机卡、一个账号、一部手机。

Q3：闲鱼哪里可以解绑淘宝？
A3：设置→账号与安全→授权管理。

Q4：鱼小铺的领域选择是否在首页推荐权重更高，推荐开吗？
A4：影响不大。新手前期不要开鱼小铺，等账号询单起来后再开才有效果。

Q5：三个账号头像、名字等相关信息是否要不一致？
A5：头像、姓名等信息要保持不一致，防止同行恶意举报。不过店铺商品风格可以统一，统一风格能体现专业性。

Q6：手机同时开流量和WiFi，闲鱼设置使用流量，是否可行？平台检测设备IP、流量IP还是WiFi的IP？
A6：风控规则会变化，设备IP和流量IP都会检测。严格遵循一卡一号一机就没问题。

Q7：背景图可以用同行的吗？
A7：可以，但直接搬运要注意水印，去📕搬运也一样。同时注意图上是否有违禁词，要避开。

Q8：三个支付宝号都在同一手机登录过，会有问题吗？
A8：没问题，后续正常分开运营即可。

Q9：背景图和头像有写作敏感词可以吗？
A9：不行，有概率违规。图片不需要放敏感词，文字和SEO搜索才有用。背景图和头像最好展现专业度。

Q10：支付宝绑同一张银行卡会影响流量吗？
A10：不会。

Q11：创建简历开启副业模块需要打开吗？
A11：不需要。

Q12：不同手机用同一个苹果ID下载闲鱼App会有影响吗？
A12：不会，IP和设备都是独立的。

Q13：手机设置双开闲鱼登录两个账号有影响吗？
A13：会，两个账号同一IP会影响流量。

Q14：可以在别人的商品下面留言截流吗？

# 9.2 闲鱼账号养成答疑

Q1：闲鱼运营用老号还是新号？
A1：都可以。老号权重可能更好一点，新号需要养号一段时间。

Q2：养号过程中浏览商品，是否需要和商家沟通一个来回才算完成，还是点“我想要”就行？
A2：完善个人信息后可以只点“我想要”；如果还是新号或个人购买账号，可以来回沟通。

Q3：变成写作号之后，还需要咨询同行吗？
A3：需要。继续刷一刷、养一养，一方面增加账号权重，一方面增加活跃度。

Q4：浏览商品需要看“我想要”数多少吗？咨询、收藏要看什么数据？
A4：要看。把自己带入真实用户，想想自己买东西时一般会关注哪些信息。

Q5：首页下拉刷新是否需要减少？上午主页都是写作相关，刷新多了下午就变乱。
A5：号没养好就会这样，需要继续养号。

Q6：主页养好号了，但后面刷新又变回来，需要重新养号吗？
A6：每天保持闲鱼基本运营动作，一般不会变回去。

Q7：养号过程怎么录？每天怎么养号要录屏吗？
A7：录屏即可。我们基本会看你刷品的动作，按教程操作养号2～3天基本就可以了。

Q8：上品后主页没有出现相关写作商品，需要停止上品继续养号吗？
A8：可以继续上品，同时每日养号。号养垂直后效果会更好。

Q9：搜索时用闲鱼推荐的搜索词和自己手动输入关键词有区别吗？
A9：没有区别。

Q10：首页权重是看推荐的这四个吗？
A10：是的，这看养号情况。

Q11：短时间关注、评论、点赞过多，被系统提示操作频繁，20多分钟后再操作，会影响后面流量吗？
A11：账号权重不够、评论截流数量多，会触发风控。慢慢养号，后续正常交易就好。

Q12：初期上品曝光都很低，是不是号没养好？
A12：正常现象。刚发的品有审核机制，需要观察1～2天；后续如果还很低，就要继续上品养号。

Q13：账号在养号阶段需要关闭个性化推荐吗？
A13：需要。关闭个性化推荐，养2～3天，直到主页慢慢出现写作相关商品。

Q14：发品阶段，日常运营包括哪些？
A14：日常任务和小游戏差不多，保持养号动作。养号不仅是保持账号活跃度，更多是发现异常值，或找到更好的对标素材。

Q15：个性化推荐什么时候开、什么时候关？
A15：刚开始养号时可以关掉。后续如果关掉后养号好几天都没刷到写作商品，可以打开。

# 9.3 商品发布答疑

Q1：每天都需要上新品吗？除了被提示违规，还有什么因素会导致账号流量突然哑火？
A1：前期一天可发3个品，后面保持一天发1个。闲鱼流量池会波动，持续保持标准运营动作，总会有爆的那一天。

Q2：类目需求有明显的季节性吗？是不是要对时间点上品？
A2：有季节性。对应学生的时间点上品，效果会更好。
