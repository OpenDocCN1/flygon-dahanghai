## 1. 项目概览

### 1. 什么是AI图像/视频站？

所谓AI图像/视频站，可以理解成一个基于生成式人工智能的在线创作工具。底层通常会用到 Stable Diffusion、Flux、DALL·E 这类模型。用户的操作很简单：写一句描述，或者传一张参考图，系统就会自动生成不同风格、不同主题的图片或视频。

这意味着，即使你没有设计功底，也不会剪辑，依然可以借助它做出质量不错的视觉作品。圈友刘小排老师做的 Raphael AI，就是一个典型AI图像站：

### 2. 为什么值得做图像/视频类AI站？

AI网站的类型很多，为什么偏偏要选图像和视频方向？下面几个理由应该能说明问题。

#### 2.1 市场空间够大

日常发社交媒体、做TikTok短视频、电商卖货、品牌推广，哪一样离得开图片和视频？需求一直在涨，机会也就源源不断。

#### 2.2 模型能力已趋成熟

现在的AI绘图和AI视频，早已不是“只能演示”的阶段，而是真正能拿来交付。细节、稳定性、风格控制都达到了实用水平，做海报、产品图、短片、广告素材都能胜任。

#### 2.3 建站门槛极低

过去要建网站，得先啃一堆编程知识。现在有了AI工具和现成模板，哪怕完全不懂代码，也能快速搭起来。尤其是图像/视频类站点，模板多到可以随便挑。

#### 2.4 成功案例已有不少

比如刘小排老师，一个人做出了百万流量的AI图像站；再比如林悦己，从完全零基础开始，如今也能靠海外产品获得真实收入。

#### 2.5 海外市场有明显红利

海外市场有两个天然优势：
- 汇率优势：收的是美元，换成人民币，本身就是一层杠杆；
- 付费习惯：海外用户更愿意为“好用”的工具付费。

总结起来就是：AI图像/视频站，市场需求大、上手容易、变现速度快，正处在风口上。

### 3. 商业模式：AI网站如何赚钱？

#### 3.1 会员订阅（主流模式）

图像和视频生成都要调用模型，存在真实成本，所以按月或按年收取会员费是最合理，也最符合用户习惯的方式。用户付费后获得一定的使用额度。

以前大家总觉得收境外的钱很麻烦，需要海外公司资质。实际操作起来，比想象中容易：
- 境外有 Stripe、Paddle；
- 国内可以通过 Airwallex、Payoneer 收款。

哪怕是个人开发者，也能很快跑通。

#### 3.2 广告收入（补充现金流）

除了会员费，很多站点也会顺手接上 Google AdSense，在赚订阅费的同时，再拿一部分广告收益。

单个用户的广告价值不高，但流量一旦上来，也可以覆盖相当一部分成本。广告赚得可能不如订阅多，却能形成“底层现金流”，让站点不至于空跑。

#### 3.3 出售项目（一次性套现）

这一点很有意思。现在不少独立开发者做AI图像/视频站，并不是为了长期运营，而是“做一个MVP → 验证数据 → 打包卖掉”这条路线。

国外有 Flippa、MicroAcquire 这类平台，国内也有少量交易渠道。只要你能做出一个付费跑得通、用户持续增长的站点，就能把它当“成型产品”卖掉。

对国内开发者来说，这是一条值得考虑的路：不必背负长期运营的压力，专注快速迭代，找到PMF（产品市场契合）之后，直接转手套现。

## 1. 建站基础概念

本章真正要做的，是打牢地基：工具从简、流程优先，先把建站全链路走通，再逐步优化。

### 1. 域名：网站的门牌号

简单来说，域名就是网站在互联网上的名字和地址。举例来说，scys.com 是龙哥盟所用的域名。它是全球唯一的，用户只有通过它才能找到你的网站。

购买渠道：常见的注册商不少，本次航海推荐 Cloudflare——管理方便、解析稳定，但价格稍微高一点。

购买时机：可以等网站接近上线时再买，不必过早占用资金。

想更系统地了解域名，可以看看文末的传送门链接。

### 1. 服务器：网站的“房子”

有了门牌号，还得有地方放代码和数据，这个空间就是服务器。

推荐托管平台：Vercel、Cloudflare、Netlify 等。本次航海更推荐 Vercel，因为它与 Next.js 高度兼容，部署过程最顺畅。

部署流程：
- 先注册 GitHub，再用 GitHub 登录 Vercel；
- 上传代码或连接仓库；
- 一键部署，自动生成访问链接；
- 有自己的域名，也可以在 Vercel 后台绑定。

后面会手把手带大家部署。

### 1. 代码：网站的“灵魂”（装修与家具）

网站的外貌和功能，全靠代码来实现。它就像房子里的装修和家具，决定了住起来的体验。

静态网页：所有访客看到的内容都一样，像样板间。
- 优点：加载快、安全性高、成本低
- 适合：个人博客、作品集、公司官网

动态网页：不同用户获得不同体验，像智能公寓。
- 优点：功能丰富，能实现登录、评论、购物车等交互
- 缺点：需要数据库和后端支持，开发更复杂
- 适合：电商、社区、社交平台

### 1. Next.js：前后端一体，极速部署

Next.js 是当前主流的网站开发框架，可以把它看作「全包式装修方案」。

- 一体化：前端页面、后端接口、路由系统都集中在一个框架里；
- 极速上线：和 Vercel 天然匹配，代码推上去几乎就能一键部署；
- SEO友好：支持SSR（服务端渲染），网页内容更容易被搜索引擎收录；
- 功能全面：既能做静态站点，也能做动态应用，还能方便地接入数据库和API。

总结一下：域名 = 门牌号，让别人能找到你；服务器 = 房子，让代码和数据有地方待；代码 = 装修和家具，让站点真正可用；Next.js = 一体化装修套餐，让这一切更快、更省心，后期也好维护。

建网站就像盖房子，先把地址（域名）搞定，再把空间（服务器）准备好，接着是装修（代码），最后用一套成熟方案（Next.js）把全部环节串起来。

### 1. 本地开发环境配置

要在自己电脑上写代码，除了AI编辑器，还得提前配好开发环境。主要包括：

- Node.js：跨平台、开源的 JavaScript 运行环境，支持 Windows、Linux、macOS。简单说，想在电脑上跑 JavaScript，就得先装它，就像给电脑装一个“播放器”来运行 JS 程序。
- NPM：Node Package Manager，是 Node.js 默认的包管理工具。它就像“应用商店”，可以下载、安装、共享和管理项目的依赖模块。
- Git：代码的“时光机”，记录全部修改历史，可随时回退到旧版本，也能支持多人协作不冲突。

三者关系：Node.js 是运行环境，npm 是这个环境里的工具市场，Git 则负责追踪代码变化。
