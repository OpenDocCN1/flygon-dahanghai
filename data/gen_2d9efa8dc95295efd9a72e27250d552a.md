# 3.2.6 百货视频带货技巧 @李诚

百货类视频模板可以围绕这8点展开：

1. 开场要抓人：用有趣、新奇、能引起关注的方式开场，迅速抓住注意力，激发兴趣和好奇，让观众愿意看下去。比如结合产品相关热门话题、小故事或令人惊讶的事实。也推荐用创意剧情、特效、实验等独特有趣方式展示产品，让短视频更出挑。例如用夸张实验表现清洁用品强力去污。

2. 产品展示：这是核心部分，要多角度、全方位展示外观、细节、材质。比如保温杯，从整体到杯盖杯身细节，再打开看内部，让观众看清产品。

3. 场景化营销：把产品放进真实生活场景，让消费者直观感受日常使用场景和价值，激发购买欲。如便携榨汁杯拍早晨起床后、户外野餐使用画面。

4. 使用方法：详细讲产品使用方法和步骤，让观众清楚怎么用。复杂产品可分步演示，便于掌握。如智能扫地机器人要讲如何开机、设置清扫模式、连接手机APP。

5. 产品优势：突出独特卖点和优势，如品质好、功能强、设计独特、性价比高，与同类形成差异。可通过对比实验直观展示。如自家保温杯和其他品牌做保温测试对比，突出保温更好。

6. 用户评价：适当展示好评截图或视频片段，增加可信度和说服力，让观众更相信质量和效果。

7. 促销信息：明确告诉观众当前促销，如折扣、满减、赠品，刺激购买，促使尽快下单。

8. 背景音乐和字幕：选适合产品风格和视频氛围的背景音乐，增强吸引力和感染力；同时加清晰准确字幕，帮助理解，重要产品信息和促销信息用字幕突出，让观众更容易注意。

# 3.3 AI提效：数字人视频制作

关于AI数字人视频，也可学习25年6月航海【AI数字人口播IP】手册，里面讲得更细。

AI数字人现在是提效手段：用数字人生成带货视频，通过挂车、橱窗或直播变现。

数字人带货主要解决两件事：

1. 主播表现力问题：多数人表现力稀缺且不易提升，没表现力也能口播带货。

2. 内容创作效率：用公模数字人或录制自己的数字人，稳定量产带货视频，大力出奇迹，不必反复拍摄口播，省时省力。

只需基础剪辑能力即可上手。

# 3.3.1 数字人怎么选？

可从前文挑合适工具，参考【2.1.4 数字人制作工具】。建议选“蝉镜”或“即创”，生成效果较稳定；选自己形象，避免侵权。

工具有了，模型怎么选：这个赛道玩家多，数字人选择很关键。比如老年人数字人少，用的人可能多；平台靠前数字人用的人也多，容易过不了原创，若使用要多做去重（过原创才能一拖五发布、一鱼多吃）。数字人气质要和带货品相配，养生品配18岁帅哥就不合适；也可尝试反差，用数据说话。一个数字人视频火了后，继续用同形象拍；即创平台搜姓氏即可，同一张脸很重要，如即创刘思远和刘天豪是同一个人。就像短视频平台你对一个人感兴趣，不管大号小号切片号都会推他的信息，认的就是脸。直接用素材群原素材人脸爆率更高，但容易过不了原创，需多做去重，风险收益成正比。

# 3.3.2.1 形式一：自己形象+自己声音

① 文案准备

新同学：直接使用群里的爆款文案，或把自己刷到的爆款素材文案提取出来。

有一定经验、想长期做IP的同学：把找到的爆款文案按自己的IP和人设简单修改。

拍摄前一定要熟悉文案，一般看几遍，自己快速默读一遍。会引起停顿的错别字、绕口的地方要改掉。例如“里面记载着人体的脉象和八卦阴阳五行河图洛书之间的关系”，可改成“里面记载着脉象和阴阳五行之间的关系”。一定要熟悉，不熟悉拍出来读稿感很明显。

② 提词器准备

用提词器可以不用背文案。推荐：剪映、度加剪辑。

③ 灯光准备

除非特殊场景需要（比如有些文案要营造悬疑恐怖感），口播灯光要明亮一些，特别是脸部。整体画面色调可以调，但人物脸部一定要亮。光线好的房间白天拍最自然；光线不好或阴雨天、晚上，建议用一个灯补光。拍摄背景：衣服和背景要有颜色区分，方便后续抠像。例如白色厨师服不要在白墙前录，否则抠像边缘不和谐。原则：深色衣服配浅色背景，浅色衣服配深色背景。

④ 拍摄准备

正面机位：人物占画面2/3左右，可用9宫格辅助线定位。人物出现2/3～1/2上半身较合适；距离太远脸太小看不清，距离太近脸太大，会放大不自然动作。摄像头平拍；仰拍容易给人盛气凌人的感觉，尤其口播时身体前倾会有压迫感，一般文案谨慎使用；俯视画面很奇怪。

[PRE7]

人物左右居中，正对镜头，像面对面交流，比较容易传达情感。侧身机位：人物侧身，角度10～30度较合适，类似接受访谈，适合情感、知识、干货类讲解，也是目前数字人制作常用机位。侧身优势：对人物表现力要求低一些，一直看稿子、看电脑的动作不会特别明显，适合新入门同学。缺点：缺少与观众的眼神交流，对话感会弱一些。

表现力提升小技巧：

1. 保持微笑。微笑是最好的语言，拍摄时保持微笑，看起来更有亲和力。

2. 头部动作和眼神。一定不要表现成读稿，一旦像读稿，身份认同感就没了。明显读稿痕迹有：头一动不动、眼睛长时间盯一个地方、眼睛左右转。提升方法：头部微微晃动，可淡化一直看提词器的僵硬感，也更自然；眼神偶尔看提词器后面及旁边，前提是熟悉稿子，偶尔一两句脱稿没问题；可在提词器后面放一个物体，想象它是你的观众。

3. 手部动作。手一直保持固定动作会显得僵硬。提升方法：手上拿一个道具；准备2～3组自己最舒服的手部动作（双手摊开、摇晃等），每隔几秒做一个，刻意练习。

朗读提升小技巧：

1. 比日常说话感情提升一个等级。日常对话语气在镜头里会显得低沉，让自己感情充分一点再读。注意不要像朗读课文、诗歌。

2. 一句话有轻有重。有些同学觉得自己说话平淡，简单办法是：说每句话时刻意区分轻读、重读。例如“我才敢说出五星级大厨永远都不会告诉你的6大秘密”“第一不能放生抽，放了生抽以后会让韭菜变色，影响食欲”。

3. 一句话有合理停顿。有些人口播一句话没有任何停顿，很难传达感情。例如“我才敢说出 五星级大厨永远都不会告诉你的6大秘密”“第一 不能放生抽，放了生抽以后 会让韭菜变色，影响食欲”。

4. 分段录制。录制时说错词不用太担心，停顿一下，把这一句完整重复再说一遍，后面可剪掉说错的话。为避免剪辑时间太长，建议长文案分段录制。

⑤ 开始录制

AI数字人需要真人口播片段作为驱动源素材，所以为保证数字人驱动效果更真实自然，要按真人出镜口播要求录制。

录制要点：画面比例根据对标账号人物角度一比一复刻最佳；拍摄1-3条左右，作为单个账号不同场景使用；拍摄时长控制在30秒-1分钟左右；拍摄文案可自我发挥、自我介绍或背几段古诗，保证表达清晰、自然、有感情。特别提醒：目前视频号发布数字人视频有一定概率触发真人出镜或AI数字人验证。为避免账号无法通过验证导致废号，强烈建议使用真人口播素材制作数字人视频。
