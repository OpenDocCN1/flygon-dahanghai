Claude Code 的 Hook 机制：响应结束时执行 Stop。具体有四种触发场景：

① PreToolUse

常见匹配器有：
- Task：Agent 任务
- Bash：Shell 命令
- Glob：文件匹配
- Grep：内容搜索
- Read：文件读取
- Edit、MultiEdit：文件编辑相关操作
- Write：文件写入
- WebFetch、WebSearch：网页搜索

② PostToolUse

工具成功运行完毕之后会触发这个钩子，匹配规则与 PreToolUse 一致。

③ Notification

当 Claude Code 产生通知时运行。不过这一项我没能验证成功，如果有朋友测出来了，记得告诉我一声。

④ Stop

当 Claude Code 处理完所有任务后运行。

1.  Git WorkTree 多开项目

官方推荐。

适用对象：需要对项目有足够掌控力、对并发任务有细粒度需求的人。

以前的工作方式：你 + 1个 Claude Code = 单线程工作
效率有限、任务排队、频繁切换上下文、复杂项目得分多次处理。

现在有了Conductor：你 + 5个 Claude Code = 并行作战！
多个任务同时推进，每个代理专注自己的事，效率不是1+1=2，而是1×5的倍增。

接下来，手把手教你怎么用这个神器。

# 第一步：下载安装Conductor

先访问官网：https://conductor.build

[PRE17]

目前优先支持 mac 平台，Windows 应该也在开发中。如果你是 Intel 芯片的 mac，点下面那个链接下载。

# 第二步：添加你的代码仓库

打开软件，进入首页。
最新版本已经支持本地项目了，上次我试的时候还只能添加 GitHub 上的远端仓库。

可以看到我打开了一个项目，而且开了四个工作空间。

重点来了：Conductor会自动使用Git Worktrees技术，为每个Claude Code代理创建独立的工作空间！

你不需要：
❌ 手动配置Git工作树
❌ 重新安装依赖包
❌ 担心不同代理之间的冲突

Conductor全自动搞定！

细心的朋友可能注意到了，每个工作空间的名称都是 Conductor 自动起的，而且是城市名：Dallas、Beijing、Conakry、Kiev。
