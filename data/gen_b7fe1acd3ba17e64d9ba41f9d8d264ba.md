# AI 写👸号：调教、自动化与蓝海赛道

先聊三条实操体会。

**体会一：** 从搭框架到最终推送，一般要花一到两个小时。核心原因是 GPT-4 响应偏慢，夜间速度更慢，网络还容易出状况，所以尽量别把写作安排在晚上。

**体会二：** 把 ChatGPT 调教顺手上后，大约产出五篇文章，就该重新调教一次。按 GPT-4 API 的输入限制来推测，它的对话大约能记住 25000 个 token 的上下文。token 和汉字没有绝对换算，通常 1000 个 token 约等于 750 个英文单词，或 400～500 个汉字。五篇文章再加上调教内容，往往接近一万字；继续写下去，模型可能忘掉最早设定的要求。所以有条件优先用 GPT-4；GPT-3.5 的上下文只有 4096 个 token，差不多写一篇就得重新调教。

**体会三：** 用 GPT-3.5 时，调教要更频繁。它上下文记忆弱、逻辑性不足，容易出现前后不接，甚至一本正经地乱说。若条件允许，尽量上 GPT-4：它能记住上下文，逻辑更顺，也更有“人味”，相当于替我们多走了一步。

### 6.2 用 ChatGPT 配合 RPA 搭建自动化 @春柏

#### 6.2.1 文章自动化生产流程

第一步，先把工具摸熟。自动写文章会用到 ChatGPT、影刀 RPA 和 Python。以情感故事为例：先人工调教好 ChatGPT，再准备故事提纲。随后打开 RPA，按下面流程设置：选中 ChatGPT 输入框并填入提示词；点发送；等返回；抓取返回文字并保存成文件；循环执行，直到整篇写完。

[PRE1]

提示词示例可以这样写：依据"""中给出的故事提纲，采用“风格 A”，用第一人称写故事。要求分成 9 段，每段不少于 130 字；先输出第 1、2、3 段。text："""故事提纲……"""。

一次让 ChatGPT 输出太长，容易出现幻觉，内容质量反而下滑。因此一篇约 1200 字的文章，我会拆成三次写，每次约 400 字。ChatGPT 不擅长数字数，所以每次让它写 3 段，字数控制会更稳。写故事建议用 GPT-4，效果明显好于 3.5。提示词里的“风格 A”是提前调教好的写作风格；调教和写提纲的方法，详见《ChatGPT + 👸号爆文写作，从 0 开始，7 天达成阅读 10W+》。下图是 RPA 控制 ChatGPT 自动写故事的示意。

[PRE2]

第二步，把文章自动发到👸号。上一步生成的文章会落在文件里，再用 RPA 操作👸号后台：自动打开网址并用账号密码登录；新建图文，读取指定目录里的文章并粘贴进去；提前设好固定格式，例如字号 17px、行距 1.75，因为按钮位置固定，RPA 很容易操作；最后一步扫码发布需要管理员手机确认，只能人工完成。听说在👸号“安全中心”关闭扫码后，也能实现全自动发布。图例仅作展示，实际流程会因电脑设置不同而变化。

第三步，批量自动化。把前两步串起来，就形成“自动写文章 + 自动发布”的流水线，人工只剩最后的扫码。用 RPA 循环执行：先批量生成，再批量发布。举个例子：把故事提纲拆成 4 个部分，每部分单独存一个文件；统一放进一个目录；在 RPA 里设置循环，读取提纲内容交给 ChatGPT 写故事；按步骤就能批量生成。生成的文章统一存放后，再用 RPA 循环读取并发布，批量发布也就完成了。

#### 6.2.2 批量化的难点与隐患

批量操作有两个关键问题：一是故事提纲从哪来。若运营 100 个👸号、每号每天一篇，就需要 100 个提纲，靠人工几乎不现实。二是文章质量不稳。ChatGPT 直接生成的内容常有重复啰嗦，需要人工润色。这两个问题都有解。

#### 6.2.3 批量化问题解决方案

**6.2.3.1 批量生成故事提纲**

提纲仍然交给 ChatGPT 批量做，但不要让它自由发挥，因为质量不行。更稳的办法是让它模仿现成爆文来写提纲：批量提取对标👸号文章；把文章交给 ChatGPT 总结提纲；再参考总结出的提纲，生成类似提纲。

**6.2.3.2 批量提取👸号文章**

我用 Python 实现了批量提取，后来想了想，RPA 应该也能做，只是提取正文会麻烦些。要批量提取文章，先得有自己的👸号：登录后台，创建“图文消息”；点顶部按钮里的“超链接”；在弹出的页面选“选择其他👸号”；输入目标👸号名称；搜索后列出该号全部文章；拿到所有文章链接，就能提取全部内容。这个流程用 Python Selenium 可以完全自动化。

**6.2.3.3 ChatGPT 批量提取文章提纲**

文章提取后存到本地文件夹，再用 RPA + ChatGPT 总结提纲。总结这一步用 GPT-3.5 就够，GPT-4 虽然更好，但提升有限，而且不用 GPT-4 API 还会遇到 3 小时 25 次的限制；3.5 速度快、成本低，效果也不错。

提示词示例：提纲格式为 1. 引子：人物背景与关系；2. 冲突：故事开端和冲突；3. 转折：发生什么转折；4. 解决：最后如何解决。根据"""内容"""写故事提纲，要求：修改人物名称和年龄；适当调整情节，让故事更吸引人；以第一人称书写；文字简洁，不超过 200 字；按上述格式输出。text："""故事内容……"""。

用这个方法可以批量产出质量不错的提纲，还能让 ChatGPT 基于已有提纲继续改写，生成更多提纲。提纲来源问题就解决了。资料参考：6 月 27 日《ChatGPT 自动化生产👸号文章》@春柏。

### 7.3 军事赛道

先提醒风险点：军事选题不要碰过于敏感的内容，比如诋毁或讽刺某个国家，这类题不要写。该领域在六七月比较火，爆款频出。军事内容容易出大爆款，点赞和在看较多；但数据也容易两极分化，有的文章上万阅读，有的只有个位数，容易让人担心账号是不是掉出流量池。这时别焦虑，数据波动很正常，继续坚持更新就好。

军事素材来源有三处：🛰️对标账号、今日头条和百家号。🛰️对标账号的找法是：打开🛰️，点底部“发现”，进入“看一看”，再点“热点”刷文章；看到军事类文章点进去，若阅读量超过一万，就看这个账号是否流量一直不错、或最近出了不少爆款，是的话关注并星标，后续作为素材来源。今日头条和百家号的找法一样：把军事爆款题目复制到今日头条，看哪些账号在写这类内容；若账号持续输出军事题材，就关注它，作为后续素材来源。没灵感时翻翻这些账号，还能顺藤摸瓜找到一批衍生对标账号。当你在👸号、头条、百家号关注约 10 个账号后，素材问题基本就解决了。

素材解决后，怎么找选题？先明白一点：在自己不熟练、还不是老手时，尽量直接复制别人的爆款选题。写之前打开关注的对标👸号，找近半个月阅读量超过 5 万的爆款文章，把对方标题原封不动复制过来，一个字不改，作为自己的选题。若从头条或百家号选题，就找评论、点赞特别多的文章，其中一个指标达到 500 以上，比如点赞或评论超过 500 的题目，作为选题。通常从👸号对标账号找选题更快更简单，缺点是写的人也多，所以👸号和头条、百家号可以交叉着来。选题主要集中在俄乌战争、普京、泽连斯基等关键人物身上。

以这篇为例：基辛格：美国宁可投降，也不敢制裁的国家，只有这 3 个。

[PRE29]

这篇是仿写，收益 4000 多元，属于爆款。思路很简单：看到对标账号写了同样题目，阅读 10w+，就把标题原封不动复制过来。随后看对方组织结构：开头 + 3 个国家罗列 + 结尾分析。我的结构与其一致，内容看几遍、知道大致意思后，用自己的话叙述出来。说白了，就是高级一点的过原创改写。当然，不是每篇都能成爆款，需要自己感受、尝试、多写。

[PRE30]

总结一下：用对方的爆款标题，内容看 3 遍、弄懂意思，列出框架，用自己的话写出来，约 1000 字，找 3 张相关图片配好发布即可。这是👸号写爆款的一种模仿方法。若写作能力不错，能根据爆款标题自己构思、输出独立观点，那最好；写作较弱，就可以仿写。军事领域单价一般在万次 100 元，但很多文章里没有广告，尤其涉及台湾问题时无广告频率最高。所以起号阶段可以写台湾相关文章，起号成功后就尽量少碰，否则即使有阅读量，收益也未必高。目前军事题目最大的问题就是文中广告，得多留意。另外，创作的本质是不给社会添乱，负面信息太多的文章不要写，这对账号长期发展很重要。

### 7.4 明星赛道 @一来 @亦小亮

明星领域比较热门的玩法是明星穿搭，适合长期做，也偏小众。三月份时非常火，有人单个账号一个月拿到 20 万流量主收益，当时做的人很多。因为内容主要是明星穿搭，很多明星自带流量，所以账号起号和内容更新都相对简单。
