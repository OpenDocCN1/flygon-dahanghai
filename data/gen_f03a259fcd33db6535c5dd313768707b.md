# 3.4.3 报价怎么定 @漫漫mansi

1）看粉丝消费能力和数据效果

不同赛道要根据粉丝消费能力和账号数据效果来调整报价。比如学习赛道，1万粉以下报价可能在700-1000元左右，10万粉时可能提到1500-2000元；但学习赛道涨到20万粉后，价格增长会趋缓。

美妆、护肤、母婴等赛道通常报价更高；数码科技产品的价格也较高，值得探索。

⚠️判断报价的方式：品牌方投放广告是为了转化用户，所以粉丝消费能力越高，对品牌吸引力越大，品牌也更愿意投入。品牌投放时看重 ROI，花1000投放能曝光2万，肯定比花2万只曝光2万更划算，这也是很多大博主去做小号、用小号接单的原因。

2）用数据网站判断广告价格

建议通过数据网站查询行业标准和市场价格，了解后台报价，再在蒲公英平台价格基础上适当调整。

# 第一步：接受合作

品牌方会在蒲公英寻找合适博主发起合作邀约。达人可以在 APP 端「消息通知-商业合作」里查看邀约，点「感兴趣」后就能和品牌私信联系，拿到对方🛰️，沟通合作详情。品牌方也可能跳过邀约，直接在后台发起合作，达人会在 APP 消息通知里收到订单并查看。

如果你觉得这单合适，就可以接受合作，开始创作内容。

另外，APP 端和 PC 端蒲公英后台都能管理「待接受」的合作订单。

# 第二步：创作笔记

加上商家🛰️后（有时对接的是 PR，不影响整体流程），对方会发来广告素材。拿到素材后，先自查内容有没有敏感词、图片是否合适等。

内容规范方面，可以照着前文 3.3.3 执行：社区公约（笔记内容、商单笔记）、审核规则（首图封面/标题、水印）、规则中心、📕创作学院、薯队长、薯管家、蒲公英小助手、📕生态站；敏感词检测仍推荐句易网 http://www.ju1.cn/#/ 和零克查词 http://ci.lingke.pro/。

如果没问题，就直接用商家给的素材发布笔记并提交审核。

注意点：这一步要沟通好广告发布时间。

比如一天来了3个邀约怎么办？都发吗？建议新号发完一条广告合作笔记后，至少隔1天再发第2条。所以商家同时邀约时，可以在🛰️上详谈，协商好其他发布时间。

# 第三步：提交笔记，等待审核通过

怎么提交一篇合作笔记？在📕 APP 编辑好笔记内容后，点击「高级选项-品牌合作」绑定订单，选择对应合作订单，再回到发布笔记页面，就能提交合作笔记了。

[PRE14]

这时笔记还没有正式发布，其他用户看不到。提交后，笔记会进入平台和品牌的审核确认环节。

如果审核不通过，消息通知和蒲公英后台都会收到提醒，需要按要求修改笔记。

审核没过时，可以联系商家重新提供素材，再重复「第二步：创作笔记」的流程，把内容重新做好。

如果改的是图文内容，可以直接在编辑页面修改，然后重新发布合作笔记；

如果要改视频内容，需要先解除笔记与订单的关联。进入笔记编辑页，在高级选项里取消关联，回到发布笔记页面，重新发布时再绑定订单即可。

但如果连续3次都没审核通过，建议这单就不接了，可以取消合作。在后台找到该笔订单后取消即可，不会受到平台惩罚。

当然，哪怕取消合作，也要维护好和商家或 PR 的关系，毕竟以后还有合作机会。

# 第四步：发布笔记，等待订单完成

审核通过后，就进入笔记发布环节。到了和品牌方约定好的时间，点击 APP「消息通知」里的前往发布笔记，或笔记详情页左上角的「合作品牌已确认」，就可以正式发布笔记了。

# 第五步：收益到账，完成提现

品牌确认完成订单后，我们会收到合作款项。如果品牌方没有主动确认，7天后系统也会自动确认订单，合作收益到账。

如果对接的是商家，直接结算订单收益即可；

如果对接的是 PR，对方可能会要求抽佣。一般加🛰️后，如果对方是 PR，会聊广告内容以及返点佣金多少。常见抽返点在20-40元左右，能接受就合作，不能接受就拒绝。不是所有 PR 都会抽，除非对方想自己赚一点。后续笔记发布完、收益到账，按谈好的分佣私发给 PR 即可。

提现：订单确认后7天，到📕钱包统一提现，提现会扣10%的税。

# 4.4 合作前要确认的细节 @虾饼

合作形式分为报备笔记和非报备笔记。报备笔记就是前面说的官方认可的品牌合作，要被收取“保护费”；非报备则是私下合作，也就是悄悄打暗广。

非报备又分单品和合集：单品是一篇笔记里只能含这个品的广告；合集是多个品同时给广告费，出现在同一篇笔记里。

单品里还有个概念叫伪合集：一篇笔记看似出现了很多产品，但真正给广告费的只有一家，这样能最大程度避免被判定为私自推广。

和 PR 聊的时候，还要问清楚下面几件事：

档期：你出初稿、终稿以及最终发布的日期。

授权转发：能否授权品牌方在电商/内容平台发布，是否免费，授权周期多长。尾部博主一般是免费授权，周期通常在三个月到半年。

授权投流：能否授权品牌方在📕投流，是否免费，授权周期多长。投流虽然能帮博主涨数据，但如果品牌爆出丑闻，还继续拿我们的笔记投流，会影响账号形象。所以最好定一个周期，比如一年内免费授权投流，一年后看情况决定是否继续授权、是否加费用。

笔记发布后的保留周期：一般是一年或永久。

排竞：在你发布这篇笔记的前几天到后几天，不能再发布该品牌竞品的相关笔记。

活动出席：美妆和穿搭类品牌可能会邀请达人出席产品发布会之类的活动。

# 5.1.1 笔记数据差，怎么调？

有人问：浏览量在100到300、300到500这样的区间，正不正常？

很明确地说：正常。

自己的浏览量不低于50，处在50到500这个区间，作为新号，发布内容时看的人偏少，是很正常也很普遍的情况。
