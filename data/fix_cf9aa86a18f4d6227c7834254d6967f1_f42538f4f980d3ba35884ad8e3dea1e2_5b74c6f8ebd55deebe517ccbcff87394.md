# 图生图上手：ComfyUI 改图全流程

电商视觉里，给现成照片做二次加工很常见：更换模特服装、替换拍摄场景、重做画面风格等，都依赖同一项能力——以原图为基础再生成。下面从高频组件与操作讲起，帮助你从零跑通整套流程。

在电商实操中，“改图”几乎绕不开。图生图的价值在于：构图和主体姿态能够延续，同时画风、环境与局部细节可被重新塑造。本章需要掌握：

1. 读图与潜空间编码：原片先进入 ComfyUI，再由 VAE 编码器压入潜在空间。
2. 降噪强度：影响原片特征留下多少；数值低则更贴近原片，数值高则改动更明显。
3. ControlNet（可选）：需要约束姿态、骨架时使用，也能配合预处理器得到线稿、深度图。
4. 尺寸适配与前后对照：调整画幅，或直接比较修改前后，便于调试微调。

学完后，你可以把已有图片交给 AI 做局部调整或画风迁移，用图生图完成创意二创，服务商品展示升级、视觉统一等目标。

先打地基：在 ComfyUI 中如何搭出图生图链路。它适用面很广，例如：

写实人像变动漫（[PRE0]）；画面细节更充实（[PRE1]）；清晰度提升（[PRE2]）；面部与手部修复（[PRE3]）；扩图与放大。

# 3.1 载入原片：Load Image

做图生图，首先得有承载待改图片的入口。

操作：在空白画布双击，出现搜索框后键入 Load Image，选第一项确认。

说明：该组件负责上传。图片一旦载入便留在组件中，后续环节可直接调用。此处使用一张“花生”图。

[PRE5]

若需要这张花生样图，可点这里获取👉花生照片

# 3.2 VAE 编码：像素转潜空间

原片进入后，AI 还需读懂它。办法是将其送入潜在空间——即 K 采样器处理的位置。连接像素与潜空间的桥梁，就是 VAE 编码器。

操作：搜索 VAE Encode，加入该组件。

连线：Load Image 输出接其图像入口；VAE 模型接 VAE 插槽（默认模型即可，也可换自定义模型）；编码后的 Latent 送入 K 采样器的 Latent 入口。

原理：图片由像素构成，处于像素空间；VAE 编码会将其压缩为潜空间表示，K 采样器方能处理。

[PRE6]

到这里，基础链路已成形。你会发现，文生图常用的“空 Latent”组件在此不再需要——输入是上传图片，尺寸无需再设，因此可直接移除。

[PRE7]

移除“空 Latent”后，若还要批量出图或改尺寸怎么办？ComfyUI 灵活度很高，对应办法都有。

# 3.3 一次多图：复制 Latent 批次

需要批量生成时，可加入新组件：搜索“复制 Latent 批次”。

[PRE8]

连线：VAE 编码的 Latent 输出接该组件输入；其输出再送入 KSampler 的 Latent 入口。

参数：批次大小填 2、3、4 均可，想出几张就填几张。

拿花生图试跑：模型选“maiju v7 麦橘写实。safetensors”，正面提示词填“A kitten sitting on the table”，负面提示词用“easynegative”（直接输入即可），步数 30，CFG 5，采样器 DDPM++ 2M SDE，然后生成查看。

[PRE10]

# 3.4 降噪：控制相似度

降噪滑杆在 K 采样器面板内，直接左右生成图与原片的接近程度。

[PRE11]

范围 0 到 1。

规律：越接近 1，AI 自由发挥空间越大，结果与原片差距越远；越接近 0，画面越像原片，原始特征保留越多。

把降噪调到 0 试一次。

[PRE12]

几乎就是花生本尊。

再把降噪调到 0.5。

画面开始抽象，像花生本体与提示词各掺一半。

一句话：降噪是图生图的核心开关。想守住原片就调低，想大改就调高，按需求决定。

# 3.5 尺寸调整：Image Scale

想把图片变正方形？可用“图像缩放”组件。

组件：搜索 Image Scale。

位置：夹在“加载图像”与“VAE 编码”之间。

[PRE13]

参数：缩放算法默认第一项；裁剪方式选“中心”（center），以中心为基点裁剪；尺寸例如 512×512。

[PRE14]

# 3.6 前后对照：图像对比

想直接查看修改前后差异，手动拖来拖去太费劲。ComfyUI 的“图像对比”功能很实用。

组件：搜索 Image Comparison。

连线：图像 A 接原片（Load Image 输出）；图像 B 接生成图（VAE 解码输出）。

[PRE15]

效果：生成图片后，在“图像对比”组件中拖动鼠标，前后变化一目了然。

# 3.7 进阶：角色风格转绘

若希望变化更大、又保留人物形象怎么办？例如让“花生”换画风但不改姿势。此时轮到 ControlNet 发挥作用——它能在结构稳定的前提下调整风格。

步骤：

1. 加载 ControlNet 模型。添加“ControlNet 应用”和“ControlNet 加载器”。使用 ControlNet 需要额外模型，因此加载器不可少。

[PRE17]

在加载器中选择 lineart 模型。应用组件里的“强度”与 K 采样器降噪类似：0 到 1，越高差异越大，越低越接近原片。

[PRE18]

此处这样设置：ControlNet 应用强度 0.8，降噪 1。

2. 预处理图像。还需要一个预处理器勾勒线条：搜索“Lineart 预处理器”。把 Load Image 输出接到预处理器的图像入口。分辨率默认 512，也可调到 768 或 1024；粗糙化默认禁用。想查看处理效果，可加一个“预览图像组件”。

[PRE19]

3. 连接组件并选模型。接着给“ControlNet 应用”接线。

[PRE20]

让 CLIP 文本编码（正面与负面提示词）流向 ControlNet 应用，再流向 K 采样器。然后选择大模型：Samaritan 3d Cartoon 3d 卡通-SD1.5.safetensors。

# 四、五个电商视觉场景实操

# 💡 本章导读

# 内容总览

文生图与图生图的基础已经具备。接下来把两者组合，投放到电商常见的五类任务：模特换装、商品换背景、商品试用图、模特换脸、视频换脸。

这些任务覆盖了电商视觉的大部分日常需求。掌握后，遇到“商家催图”“赶主图/产品照/模特宣传图”等情形，你会有更灵活的应对方式。

本章重点：

1. 模特换装：准备模特与服装两张图，结合局部重绘、Flux Tools 和遮罩，使人物呈现出真实穿着效果。
2. 商品换背景：先将商品主体抠出，再让 AI 重绘或风格化背景，生成适配电商平台的场景图。
3. 商品试用图生成：把产品合成进人物或指定场景，模拟真实使用情境，对转化提升帮助明显。
4. 模特换脸：用 ReActor 等换脸组件，把目标人脸替换到现有模特上，方便店主或 KOL 快速产宣传照。
5. 视频换脸：进一步处理多帧与补帧，一键产出商品宣传短视频，提升推广吸引力。

学完本章，你能在具体电商任务中，把文生图、图生图、遮罩、ControlNet 等基础能力组合起来，让 AI 完成“高效率、低成本、多风格”的商品视觉创作，图片与视频均可覆盖。

# 4.1 模特换装

# 4.1.1 基础链路搭建

动手前，先备好两张图：

一张用于换装的服装图（[PRE28]）；一张模特图，即要穿上该服装的人（[PRE29]）。

下面先搭最简框架，再逐项补充组件。

# 4.1.1.1 读入两张图

先把服装图与模特图分别用 Load Image 组件载入 ComfyUI。这样原材料就位，后续操作都围绕它们展开。

组件：Load Image。

做法：添加两个载入图片组件，分别放模特图和服装图。Ctrl+C、Ctrl+V 可复制组件。

[PRE30]

# 4.1.1.2 尺寸统一

两张图尺寸不同（模特为 9:16，服装为 4:3），因此需要“图像缩放”组件来统一。

组件：Image Scale。

[PRE31]

做法：先加第一个缩放组件，参数设为——宽度 1000，高度 1000（按显存调整，显存低可设 512×512）；插值选 Lanczos（可选，默认也可）；Method 选 proportion，保持宽高比；其他条件、乘数保持默认。再复制一份缩放组件，确保两张图与后续遮罩尺寸一致。模特图、产品图都接上缩放组件。

注意：尺寸一致是局部重绘的关键，否则会报错。

[PRE32]

若想把两张图放进同一画布做对照，可用“图像连接”组件：图像 1 接服装图（缩放后），图像 2 接模特图（缩放后）。这样预览时左边服装、右边模特，后续处理和对比都方便。

[PRE33]

可拉一个图像预览查看效果（演示视频：20250311-142635.mp4【在线播放】）。

# 4.1.2 绘制替换区

目标明确：只给模特换衣服，脸、头发、背景保持不动。最直接的做法，是做一张只覆盖服装区域的遮罩。

1. 回到模特图的载入组件，右键→“在遮罩编辑器中打开”（Edit Mask）。
2. 用笔刷在模特图上涂抹要更换的服装区域。白色表示需要修改，黑色表示保留；不必涂得特别精细，稍微溢出也无妨，InPainting 会做环境融合。

（演示视频：3月11日.mp4【在线播放】）

[PRE35]

3. 点 Save 保存，就会得到一张与模特图同尺寸的遮罩图。

[PRE36]

涂好后，还需统一遮罩尺寸。可以把遮罩视为单独图片，分辨率必须与原图一致，否则后续会报错。

# 4.1.2.2 黑底与蒙版合并

接下来，要把图片翻译成 AI 能理解的语言。

在 AI 的世界里，黑色表示不改，白色表示要改。所以还得对蒙版图做一步处理。

第 1 步：创建黑色“纯色图像”（Solid Color Image）组件，颜色设为黑色（#000000）。右键该组件，把高度和宽度转成输入参数。这样可以把前面的图像组件接到黑色图像上，让尺寸保持一致。

第 2 步：合并处理后的图像。创建一个“图像连接”（Image Combine）组件，把加了黑色蒙版的模特图和应用了纯色效果的服装图接进去，完成合并。

[PRE40]

预览一下：如果左边是黑、右边是服装区域的白色蒙版，就说明操作成功。
