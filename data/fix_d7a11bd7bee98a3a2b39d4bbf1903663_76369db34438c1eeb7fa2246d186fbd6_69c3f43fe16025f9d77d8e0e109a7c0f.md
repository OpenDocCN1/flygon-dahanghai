# 1. 飞书开放平台：开通多维表格权限，获取 app id 与 app secret

先登录飞书开放平台（https://open.feishu.cn/app?lang=zh-CN），并创建一个企业自建应用。

[PRE10]

填写应用名称与应用描述，点“创建”。

[PRE11]

在“基础信息-凭证与基础信息”中，可找到 app id 与 app secret 两个应用凭证，建议保存到本地文件中，稍后要用。

[PRE12]

接着在“开发配置-权限管理”中，点“开通权限”。

[PRE13]

先开通应用身份权限 tenant_access_token：在左侧菜单向下找到“多维表格”，勾选全部权限名称，然后点右下角的“确认开通权限”。

[PRE14]

用户身份权限 user_access_token 也照此操作，把多维表格的权限全部开通。

1. 在飞书开放平台发布应用

进入“应用发布”-“版本管理与发布”，填写符合 1.0.0 格式的版本号和更新说明，保存后确认发布。随后会弹出免审发布确认窗口，确认后即发布成功。

[PRE15]

# 3. 新建多维表格并获取访问参数

在飞书云文档主页找到“云盘”，进入云盘新建一个多维表格。

这里有个硬性要求：必须从云盘新建多维表格，这样得到的地址才是 https://f7vsb1brbs.feishu.cn/base/S7JqbAzy7aO5dLsAQehchmLyngf?table=tbl6l8zc0BHSgIkY&view=vewgb3vMSP 这种格式。

云盘建立的多维表格，链接地址第二段是 base；如果从飞书文档主页新建，第二段会是 wiki，对接方式就完全不同。所以务必保证地址第二段是 base。

[PRE16]

多维表格地址还能提取出两个关键参数：app token 与 table id。以上面的 URL 为例，

https://f7vsb1brbs.feishu.cn/base/S7JqbAzy7aO5dLsAQehchmLyngf?table=tbl6l8zc0BHSgIkY&view=vewgb3vMSP

app token 是 S7JqbAzy7aO5dLsAQehchmLyngf，即第三节到 ? 号前的一串字符。

table id 是 tbl6l8zc0BHSgIkY，即 table= 之后、&view 之前的字符串。

这样，四个重要的飞书多维表格信息就齐了：

app id：在飞书开放后台的“凭证与基础信息”中获取

app secret：在飞书开放后台的“凭证与基础信息”中获取

app token：从多维表格地址中提取

table id：从多维表格地址中提取

# 4. 在多维表格中添加应用，使应用获得访问权限

在当前多维表格右上角，点“...”符号，按顺序选“更多”-“添加文档应用”。

[PRE17]

如果第2步应用发布成功，在这个对话框中搜索应用名称即可找到，把它添加进来，并确保权限是“可编辑”。这样应用就能访问多维表格，并往其中写入数据。
