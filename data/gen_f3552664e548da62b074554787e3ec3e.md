# 3.1.4.3 平台急推品类，先辨真假需求
买手每周都会发布平台需要的品类，但不要直接冲，要自己去前台验证需求真假。真需求就赶紧上品，爆量可能很快；假需求很可能是伪需求，或者只是平台测试需求。已经测试过20个平台发布的测试需求，发布之后平台并没有反应。

怎么验证？找到产品关键词，去Shein前台看两点：
① 最近一两个月上架的新品多不多；
② 新品上架后有没有热卖。

如果很多新品都在热卖，说明是真需求，容易爆量，别犹豫，抓紧冲。这个时候谁跟得快，谁就容易成爆单王。

比如平台发布圣诞节毛巾需求，关键词是Christmas towel。

可以提炼爆款元素：毛巾、圣诞（驯鹿、雪花、圣诞树、圣诞老人），再去平台搜索看需求。

# 3.1.4.4 节日与季节品，踩准节点
跨境节日很多，尤其下半年节日密集，也是跨境旺季。符合节日风格的单品，都可以快速开发。

比如返校季：饭盒、饭袋、文具、书包、派对用品都是热卖品。

比如万圣节🎃：万圣节最重要的是cosplay，节日风格偏黑色、黄色。往年热销的有黑色蝙蝠、黑色蜘蛛、黑色巫师帽、黑纱、枫叶藤条、黄色仿真花等。

比如圣诞节🎄：圣诞树、圣诞老人、麋鹿、红色装饰（一品红等）、绿色装饰（各种藤条）等，都可以作为选品方向。

注意：季节性产品一定要看往年同期销量。近期卖得好或差，不能代表这个产品真正的好坏，关键要卡准时间节点。

# 3.1.4.5 热卖同款与升级款，藏着爆款潜质
某个热卖产品如果出现了可替代功能、采购价更低、体积更小的版本，上架后基本都容易热卖。同样的需求，体积更小往往意味着价格更低；跨境运费很贵，产品本身降价和体积缩小，都能降低成本。

比如徕芬替代戴森，成本只要十分之一，体积也更小。

# 3.1.4.6 复制热卖元素，新手先别急❌
把热卖单品里的元素提炼出来，再复制平移到其他单品上。比如前面提到的圣诞毛巾，就是这种开品逻辑。不过这个玩法对新手不太友好，先别急着上。

# 4.2 商品基础信息怎么填
常规商品需要填写：标题、敏感类别、材质、关税种类、数量、规格、图片、供应信息。

# 4.2.1 标题怎么写
标题可以参考亚马逊或其他平台的标题，但要注意标题里标注的产品规格、品牌信息是否需要修改。

亚马逊标题示例：Lansinoh Breastmilk Storage Bags 3pcs 500ml。需要删掉品牌名Lansinoh，并确认供应商或我们上传的产品是不是3pc 500ml（3件500毫升）。参考标题时，尽量参考销量比较高的链接。

标题一定要有核心关键词、场景词和功能。核心关键词用来描述这是个什么产品，场景词用来描述使用场景。比如：宠物垃圾袋、宠物用草莓便便袋、防漏。

如果规格特别有优势，可以写进标题；有多个规格时，写最大规格。关键词之间用英文逗号隔开，介词小写。大词放后面，比如“宠物垃圾袋”和“便便袋”里，“宠物垃圾袋”就放后面。在不考虑销量、好评等因素的情况下，用户在搜索结果页看到的是平台按标题中关键词前后顺序排序的结果。

比如：
标题1：加厚大码风衣防风防水风衣
标题2：防水风衣加厚大码风衣防风
用户搜索“防水风衣”时，平台会优先展示标题2这条链接。

# 4.2.2 商品属性怎么填
带*号的为必填项。

（1）标题里填写的数量以及其他产品规格，要跟商品属性、图片展示保持一致。
（2）所有属性都要真实，尤其是包装规格。
（3）敏感商品属性要填写清楚。

电池类：需要MSDS说明书和UN38.3（UNDOT）测试认证等；电池货物对包装和操作流程都有严格要求，选品时要注意供应商能否提供相关资质。

食物：需要CIQ或熏蒸证明书。

药品类：这类货物运输时需要国家音像出版社证明，由生产方或出口方出具保函。

粉状、胶体等不稳定物品：比如化妆品、护肤品、精油、牙膏、口红、防晒霜、饮料、香水等，需要MSDS（化学品安全数据说明书）和出发口岸商检报告，才能报关。

尖锐类：商品运输信息要填写真实，包装要保护好。

仿牌：有品牌或仿牌的商品，不管是正品还是仿牌，都可能涉及侵权等法律纠纷风险，都需要走敏感货渠道。

# 4.2.5 供应信息怎么填
价格按1688采购价加20%—30%的利润来定。含包装尺寸和重量，需要在选品时和供应商确认，并且必须与发货信息一致。产品尺寸、含包装尺寸都要记录清楚。

# 4.2.6 货号怎么编
上品人缩写+日期+第几个品。比如XX1022001，表示XX在10月22日开发的第一个品。

商家SKU表示产品具体某一个规格，比如XX1022001S1、XX1022001green，分别表示XX在10月22日开发的第一个款式为S1的品、第一个款式为绿色的品。

填写完即可发布，发布后等待审核流程。

[PRE33]

# 4.2.7 审核结果怎么确认
审核一般需要3—7天，审核通过后一般2—3天会上架。

# 4.3 如何定价
一般按采购价的1.2—1.3倍定价。

如果产品采购价很低，乘以1.2倍后还是很低，比如1*1.2=1.2，可以加2—3元去核价；但一般建议做2pcs、3pcs或者和其他规格组合去卖，不然核价可能不过审。

不要一开始就写很高的价格，尤其是低价产品。如果一开始定价很高，核价时买手会直接核最低价。买手会参考1688价格。

价格档位参考：8 9-10 15。

新品：取第二档、第三档的最低价。
老品：按最低档价格×0.8。

比如产品1688价格6.5，买手可以接受的价格是7.2—9.6。你直接报10块，他可能会跟你议价，给你报到7.2；但如果你报8.3，买手可能直接就通过了。

# 4.5 常见审核问题与修改方法
活动已结束；价格不够有优势，所以一直审核未通过，跟卖没有中标；季节性活动已经结束。

[PRE40]

侵权、禁忌、禁售、证书驳回。禁忌包括政府、宗教、歧视等；宗教、政治、专利、民族歧视、文化等也要注意。国内经常说“大码服饰”，国外直接标清楚适合多少斤穿即可。

图片模糊不清、有中文。

错放类目——可以找客服咨询类目，或者上传图片识别类目。

重复款——Shein站内有大量同款。

要求聚合上新——主规格始终只能有一个规格，可以在其他规格里自定义编辑，用来区别不同规格。

非同款——与选择的机会商品非同款。

上品成功率较低的话，平台会延迟审核、延迟推款。

价格太高——如果是有相似款的低价供应商，可以申诉，上传对比图片，区别出不同之处。
