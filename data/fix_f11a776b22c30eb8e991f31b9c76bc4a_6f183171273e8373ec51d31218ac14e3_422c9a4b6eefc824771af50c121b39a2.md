# 📕账号升级、收录机制与规避新规全攻略

运营📕，别只顾着追爆款。账号从新手到高阶，其实藏着一套成长体系；笔记能否被搜索到，取决于是否被收录；平台的各项新规，又直接决定流量走向。接下来就一次性讲透成长等级、活跃度、收录、避坑、新规应对和常规功能操作。

先聊成长等级。发布3篇内容，每篇均能收获至少5次收藏或10个赞，或者累计发布3篇话题笔记，就能解锁小枕头图标，晋级为困困薯。这一级同时看重笔记数量与互动表现，也引入了话题笔记的计数，可以看出平台正引导博主多产出内容，并且更偏好话题型笔记。

去到泡泡薯这一级，条件是：累计5篇笔记，每篇都有至少10次收藏或50个赞，而且当中要有1篇是参与话题活动的视频笔记，小红薯就能学会吹泡泡，变身泡泡薯。显然，到了这个阶段，升级难度开始加大，视频笔记和话题活动的参与成了硬性要求。

甜筒薯则要求累计12篇笔记，每篇都拿到10次收藏或50个赞，并且其中3篇须为参加话题活动的视频笔记，达标后就能吃到甜筒、晋升甜筒薯。对比上一级，笔记总量和视频笔记数量都往上提了。

小马薯的门槛变为累计50篇笔记，每篇均有10次收藏或50个赞，同时要有5篇话题活动的视频笔记，达成后即可获得玩具小马，进阶小马薯。

文化薯提供两条晋级路径：其一是累计9篇参加话题活动的视频笔记，每篇均达10次收藏或50个赞；其二是累计100篇笔记，每篇同样要达标。两条路完成其一，小红薯就能点亮读书技能，成为文化薯。相比上一级，普通笔记的累计量从50篇翻倍到了100篇。

铜冠薯的规则是：累计12篇带话题活动的视频笔记，每篇达到10次收藏或50个赞；或者累计300篇笔记，每篇都达标。达到要求后，薯队长会为小红薯颁发铜冠。虽然总笔记数从100篇增至300篇，但带话题的视频笔记只需比上一级多3篇达标即可，反而更容易冲刺。

银冠薯的要求为：累计15篇参加话题活动的视频笔记达到10次收藏或50个赞，或者累计500篇笔记每篇达标，即可获得银冠。

金冠薯作为最高等级，需要累计18篇参加话题活动的视频笔记均达到10次收藏或50个赞，或累计800篇笔记均达标。相对轻松的路径，依然是不断累积带话题的视频笔记数量。

# 6. 账号活跃度很关键
活跃度对账号权重影响很大。保持日常登录和操作，比如发笔记、刷别人的内容、点赞、写评论，系统才会认定这是活跃的正常账号；否则极容易被归为僵尸号。

# 7. 签约MCN或品牌合作人
若能签约MCN官方机构，或拿下品牌合作资格，账号往往会被视为优质账号群体中的一员，对提升权重有正面作用。

# 9.4.7 想被搜到？先搞懂收录机制
笔记发出去之后，只有被系统收录，别人才搜得到；没被收录，基本等于白发。

# 一、影响收录的因素
标题、正文关键词直接影响收录；标签要足够精准，且不宜频繁更换，最好固定几个与账号和笔记定位高度相关的标签，这样系统也更方便识别账号领域。另外，图片和文案不能含有违规信息或广告推销痕迹；账号本身更不能有违规记录。

# 二、判断笔记是否被收录的三种方式
方式一：直接搜自己。在📕主页搜索框输入你的用户名，若笔记已被收录，搜索结果里自然会现身。或者搜索笔记标题、关键词，在发现页切换到“最新”，往下翻找，找到自己的内容就说明收录成功。
方式二：看互动数据。已收录笔记的阅读量、点赞数通常会优于未收录的笔记。
方式三：核查笔记URL。每篇笔记都有专属链接，如果URL里有📕域名，就代表已被收录。

# 三、哪些原因会导致掉收录
推广违规要当心：除了品牌号、品牌合作号，其他号都不能直接做硬广。账号或过往笔记如有违规，收录概率会明显下降。内容本身出问题也很致命，图片和文字都算：可能因为违规直接不被收录，也可能先被收录、再因举报被限流。图片上别出现别家平台水印、二维码等元素，文字里不要带敏感词、违禁词、不文明用语以及诱导性内容。发文节奏太猛也不行，一天最好别超过5篇，不然容易被当作营销号。手机设备被平台拉黑同样会受影响。此外，内容质量太差，或平台认为不适合展示的笔记，比如大面积推广、炫富、非原创、抄袭、搬运等，也难逃限流。
想让笔记更快更全地进入收录池，最有效的方法还是多逛📕，关注优质创作者和高质量内容，并保持良性互动。

# 9.4.8 这些红线千万别碰
硬广必须杜绝。所有推广性质的笔记，都要走软文思路，站在用户视角去写，转化效果才会更好。
平台规则不要挑战。一碰就可能被限流，严重的话直接封号。
内容尽量原创，别跟别人的笔记高度雷同。多人反复使用的模板化图片要少用；复制来的段落最好重写；视频情节过于相似的也要避免。
假数据别碰。花钱买点赞、评论等互动，平台是能识别的，千万不要尝试。想互动可以用小号在评论区带节奏，引导用户关注或私信。

# 9.5.1 新规之下的实操策略
1. 严禁用软件批量生成笔记。这类内容最大特点就是重复度极高，等同于搬运，正是平台重点打击的对象。

3. 新规反而给人机会。不去做搬运、简易二创这类低质工业化内容，平台把低质玩家筛掉后，认真做内容的人自然能接到更多流量。
4. 把自己当真实用户。算法会看你每天在📕停留的时长，和发笔记的数量是否匹配。比如一天发两三篇，却只刷10分钟，系统很容易把你定义为营销号。

# 10.1 怎样选出优质赛道
如果你找赛道不费劲，通常具备三种能力：一是在教育行业扎根多年，积累足够，清楚客户群体和痛点，能快速匹配产品；二是会看行业数据，判断哪些方向正处于上升期；三是网感敏锐，比如之前“高考志愿填报”相关的产品和服务，就属于典型的风口。
如果你还在迷茫，也正常。可能你过去没接触过教育行业、不太会看数据报告、网感也一般。但没人生来就是高手，好在身在龙哥盟，能接触到第一手的互联网信息源，已经领先九成普通玩家了。

找赛道之前，先明确什么才算优质赛道：
第一，市场盘子要够大。比如闲鱼项目，若定位为“闲鱼数码”，只能吸收对数码产品感兴趣的学员；若是“闲鱼高客单价”，几乎所有想做高客单价变现的人都可以收。鱼多的地方，才钓得上更多鱼。
第二，消费频次要高，也就是复购率强。像K12教育，每个新学期都有新内容，天然能带动补习机构持续增长。
第三，可持续性要够硬。有些项目昙花一现，蹭完一波热度就无声无息；而有些赛道，流量常年稳定。
