# 1.3.1.2 初识 Stable Diffusion

Stable Diffusion（常简称 SD）的用法主要有两条路：一是把程序下载并安装到自己的电脑上运行；二是直接使用别人已经封装好的软件或小程序。它的模型与开源项目信息可在 GitHub 查看：`github.com/AUTOMATIC1111/stable-diffusion-webui`。

不过，SD 并不是一款点开就能轻松出图的“傻瓜工具”。它的操作界面信息密集、选项繁多，新手刚开始容易找不到方向。若选择本地版本，开源带来的好处是免费，但电脑硬件配置也得跟得上；这部分会在后文《Stable Diffusion 安装使用细节》里说明。想系统学习，可参考《五、学会用 Stable Diffusion 完成 AI 绘画》。

从结构上看，Stable Diffusion 是一套开放的大模型（开源）系统，再配合多个特化小模型。代码公开意味着任何人都能基于它训练自己需要的大模型或小模型，也能开发相应插件。也正因如此，提示词与模型搭配显得格外重要：不同的描述词遇上不同的模型，画面风格可能完全两样。例如输入“1girl”并选用二次元模型，得到的是动漫风女孩；换成真人模型，则可能呈现 3D 真人效果。

SD 自带官方大模型和官方用户操作界面，整体有点像刚出厂的安卓手机，基础功能齐全，但需要自己慢慢配置。下图界面原本为英文，此处已做汉化处理。
