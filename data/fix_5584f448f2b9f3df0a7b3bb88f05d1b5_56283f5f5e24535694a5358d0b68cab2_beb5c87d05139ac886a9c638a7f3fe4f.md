# ControlNet 1.1 更新盘点：软边缘、骨骼、线稿与组合玩法

这次版本里，SoftEdge 家族多了一个偏稳妥的成员，叫“SoftEdge_safe”。为什么要加它？HED、PIDI 在估算软边缘时，常会把原图受损后的灰阶痕迹混进结果；这些痕迹像干扰项一样抢走模型注意，成品就容易跑偏。处理办法是先对边缘图做分级量化，把潜藏的痕迹清掉。代码位置在 annotator/util.py 第 78 行。

表现排序可粗记如下：

抗干扰：SoftEdge_PIDI_safe > SoftEdge_HED_safe >> SoftEdge_PIDI > SoftEdge_HED  
画质上限：SoftEdge_HED > SoftEdge_PIDI > SoftEdge_HED_safe > SoftEdge_PIDI_safe

**语义分割：用色块安排画面**
把语义分割图当作条件输入，Stable Diffusion 就会按色块布局生成画面。每种颜色对应一类物体或场景；确认颜色含义后，也能自己手绘色块。颜色对照表网上可查。权重：control_v11p_sd15_seg.pth；参数：control_v11p_sd15_seg.yaml；训练集：COCO 与 ADE20K。可接的预处理器有 Seg_OFADE20K（Oneformer ADE20K）、Seg_OFCOCO（Oneformer COCO）、Seg_UFADE20K（Uniformer ADE20K），也支持手工掩码。现在该网络同时认得 ADE20K、COCO 两种标注。实测让编码器分辨分割标注体系并不费劲；把多种标注体系放在一起训练，反而能提升表现。seed=12345，ADE20K 标注，提示 house：

**Openpose：骨架定姿势，表情也能管**
骨骼图相当于给画面立骨架，常用于锁定人物姿势与动作；这一版把手部、面部表情也纳入控制。躯干、手、脸能自由拼，但组合太多反而难选。官方建议只留两档：常规档“Openpose”只管躯干；完整档“Openpose Full”把躯干、手和脸一起管。具体怎么搭配模特动作与表情，这里不铺开，留给大家自己试。权重：control_v11p_sd15_openpose.pth；参数：control_v11p_sd15_openpose.yaml。训练时覆盖了躯干、手、脸的多组搭配：单躯干；张手配脸；躯干加手；躯干加脸；手加脸；三者全上。

这次改进主要来自 OpenPose 实现的优化。我们仔细对比了 PyTorch 版与 CMU C++ 版，处理器现在更准，手部尤其明显；处理器变准，也带动了 Openpose 1.1 的提升。它还支持更多输入，包括手和脸。旧版 cnet 1.0 的语料有三处毛病：少量灰阶人像被重复拷贝上千次，旧模型因此偶发灰阶人像；部分素材画质差、发虚或 JPEG 噪点明显；处理脚本出错，让少量图文配对出现错提示。新模型修掉了这些语料问题，很多情况下会更合理。seed=12345，提示西装男士，未筛选批量样张：

**Tile：切块补细节，拼成大图（未完工）**
做法是把大图裁成小块，逐块补细节，再拼回整图。用 Tile 控制稳定扩散。权重：control_v11u_sd15_tile.pth；参数：control_v11u_sd15_tile.yaml。越来越多人想用拼贴扩散做 4K、8K 大图。难点在于，Stable Diffusion 的提示语会作用于每块：提示写“一位美女”，把图切成 4×4 共 16 块分别扩散，容易得到 16 位美女，而不是一整张图里只有一位。这是老问题。常见补救是用“清晰、超清晰”这类空洞提示，但去噪强度一高就崩，内容也会很随机。Tile 模型专门解决它：先判断块里有什么，增强局部语义；如果和全局提示不匹配，就压低全局提示的影响。seed=12345，提示帅哥，未筛选批量样张。看左图圈出的小框，右侧六张是框内重绘结果：

问题二：遇到“页面文件太小”报错怎么办？
解决办法：按下面步骤设置虚拟内存。
1. 在桌面找到“此电脑”，右键选“属性”。
2. 进入系统页后，点左侧“高级系统设置”。
3. 在“系统属性”里切到“高级”，性能区域点“设置”。
4. 在“性能选项”窗口再切“高级”，找到“虚拟内存”并点“更改”。
5. 在新窗口里，先取消“自动管理所有驱动器的分页文件大小”的勾选。
6. 选中系统盘，点“自定义大小”，填入初始值与最大值，先点“设置”，再点“确定”。别漏“设置”，否则不生效；数值可先给大些，不够再加；不想折腾了记得改回自动管理。

# 六、学会写提示语 @天辉 @大刘 @瑾糖🔥

关键词、提示语，是 AI 绘画绕不开的基本功。说白了，就是掌握跟模型交流的表达方式，让输出贴近你的设想。会组织语言，画面就有方向；会调参数，改图就有抓手。早期我常建议新手用对标仿写来练，因为提示语对画质影响很大，而且出图慢、试错成本高。现在情况不同：MidJourney 对提示语的要求没那么繁琐，也能出好看结果；Stable Diffusion 这边，底模与插件带来的影响更明显。所以我更推荐先弄懂基本逻辑，然后直接上手，用自然语言把画面讲清楚。换句话说，“我想生成什么样的图”比堆技巧更重要。当然，后面仍会附上大量提示语供参考；对新手而言，复制粘贴先找感觉，依然是最省事的入门方式。
