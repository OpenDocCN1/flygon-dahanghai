# 4.1.3 收益想提高？三个方向 @郭耀天 @思蒙

有时候视频正好起量，偏偏商家当期预算收缩、投放减少，广告供给跟不上，你的分成也会被压低。收益高低并非我们能直接左右，能做的无非两条：多产出作品，用更多内容去搏爆款；或者尽量切入高价值领域。财经、美容、酒类背后广告主预算更充足，泛娱乐赛道相对就容易吃亏。

方法一：往年轻用户扎堆的赛道走

拿到分成的伙伴里，有人反馈收入偏低，这和视频号分成计划尚未完全释放有关。仔细观察会发现，当前广告里游戏居多，其次是腾讯自有广告和网剧。像祝福、早安类视频，转发量确实大，但受众以老年人为主，广告主很少往这些人群投放，收入自然上不去。想提升收益，可以优先考虑年轻人集中的方向，例如科技、娱乐、情感，这类内容对应的广告出价通常更高。

方法二：把互动性做起来

现在分成收益主要来自评论区广告，所以第一步还是内容本身要能爆、能传播、能带来转发，评论量才会起来。第二步是主动引导评论，自己评几条、小号补几条，广告会更快出现；目前通常要两条以上评论才会展示广告。内容最好自带互动属性，比如找图中人物、找图中动物、问答题，也可以在视频里做引导，让观众参与进来。有伙伴用一张图让人找头像，用户看完就在评论区写答案；也有人写语录后问“这句话正确吗，请在评论区告诉我”。这些技巧多研究、多操作，慢慢就能摸出门道。

方法三：提高创作效率，用数量放大机会

门槛较低的项目，比如视频号创作者分成，本质上是用数量博概率。能多发就多发，能多起账号就多起账号。实操中你会发现，有些人的作品和你差不多，谈不上多优秀，但账号就是爆了，这就是概率。选好赛道、掌握制作技巧后，剩下的关键就是“量”。一条视频爆的概率是1%，那发10条、用10个账号呢？每个都是1%，叠加起来机会就大得多。为了更好搏量，实操中要持续提升效率：找素材更快、备文案更快、剪视频更快，熟能生巧，多练就会进步。

# 4.2 常见问题处理指南 @郭耀天

项目推进中，大家容易碰到一些共性问题，这里整理了一部分经验供参考。

# 问题一：怎样减少掉广告？

操作视频号分成计划时，即便是爆款纯原创视频，也可能出现掉广告的情况，通俗说就是评论区没有匹配到广告，几百万甚至上千万播放的视频也会遇到。下面分享一些伙伴测试过的方法，不保证一定有效，但有一定参考价值。很多人用剪映制作视频，其实视频号官方也有剪辑工具“秒剪”，官网是：https://miaojian.weixin.qq.com/ ，用秒剪剪辑，流量有概率更高。

方式一：从剪映导出后，直接用秒剪过一遍再导出。  
方式二：把剪好的视频导入秒剪，随意套一个滤镜，再把画质颜色调到10以下，常用参数是5。  
方式三：导入视频后套秒剪模板里的“治愈调节”，模板自带音乐和滤镜；把原音打开，自带滤镜叫“橘子海”，参数调到10即可。  
方式四：用秒剪“橘子海”滤镜，参数调到10，再调亮度3、对比度4、饱和度4、色温5，这四项都不超过5；暗角9，不要超过10；锐化14，不要超过15；贴纸放3～4个，再加2个个性文字即可。

另外建议发作品时别用WiFi，改用4G，因为WiFi覆盖区域相对小，4G分发区域会更广。

# 问题二：为什么「参与收益中的视频」显示0？

「参与收益中的视频」统计的是账号过去7天产生过收益的视频。显示为0，可能是以下情况：

1. 该账号所发视频的评论区没有展示广告；
2. 该账号视频近7天没有实际产生广告收益，创作者可以继续发布优质原创视频，等视频产生预期收益后就会显示在专区；
3. 账号处于内容整改期，或创作分成计划权益已被取消，视频无法参与广告分成计划。

[PRE1]

# 问题四：加入分成计划会压流量吗？

不会影响视频流量：流量主要和内容质量、内容主题等因素有关；广告展示在视频评论区，不影响视频本身。

[PRE2]

# 问题五：分成计划的广告会自动出现吗？

申请加入创作分成计划后，创作者发表视频时打开「原创声明」，该视频评论区下方就有机会展示广告，不需要额外操作。创作者可以在「创作者中心-创作者服务-创作分成计划-参与收益中的视频」查看成功加入分成计划的视频。

# 问题六：评论区为什么没广告？

如果创作者没有加入创作分成计划，仅声明原创的视频评论区不会展示广告。加入计划后，发视频一定要点开原创声明按钮；发完自己立刻去评论一两句，广告很快会出现。有评论才会有广告，一般有一条他人评论就会出来，自己再补一条，广告就出现了。

如果已经加入计划、也声明了原创，评论区仍没有广告，可能是：

1. 当前暂无广告与该用户视频匹配；
2. 视频属于暂不支持展示广告的类型：非公开浏览状态的视频；信息流广告/短视频商品分享/视频变现任务/互选平台等含商业推广信息的视频；内容不符合《🛰️视频号运营规范》的视频；
3. 账号处于内容整改期，或创作分成计划权益已被取消，视频无法参与创作分成计划。

[PRE3]

# 问题七：旧账号怎么养回来？

可以直接拍随手拍视频，持续发，有老号这样操作也成功了。如果实在担心，就把非原创、非同类视频全部删除，持续更新随拍视频；更新几十个后仍不满足内容规范，可以考虑注销账号再注册新号。

[PRE4]

# 问题八：旧号流量差，还能发新内容吗？

可以先发随拍视频看流量。有流量的话，可以直接开通分成计划；没流量就换领域测试，测试后仍然没有流量，就注销账号重新起号。

# 问题九：开通分成后，旧视频要删吗？

最好删除，也可以隐藏，按自己的情况决定。如果以前的视频完全符合内容规范、质量高且是原创，当然可以不删。

# 5.2 更换视频号管理员

操作视频号时，有时需要快速注销账号，其实还有一个快速办法：转移管理员。找一个没有注册过视频号的🛰️号，把视频号管理员更换到新🛰️上，也能达到注销目的，后续就可以重新注册视频号。操作不复杂，前提是找到未注册视频号的🛰️，目前市面上有这类资源，可以自行寻找。

可以通过以下2种方式进入更换管理员页面：

「我 > 视频号 > 右上角 ... > 账号管理 > 更换管理员」  
「发现 > 视频号 > 右上角人像 > 头像 > 右上角 ... > 账号管理 > 更换管理员」

点击“我”，找到视频号，进入账号管理；点击更换管理员，就可以把管理员换给其他人，从而实现注销账号的目的。

注意事项

1. 可迁移内容：账号基本信息（头像、名字、简介、认证），发布动态及动态数据、粉丝；账号相关设置，如隐私设置、运营人员设置等；商品页商品；推广充值费用。
2. 不迁移内容：视频号私信。
3. 新管理员🛰️号要求：🛰️号没有视频号；🛰️号两周内未被盗、被封、修改密码；🛰️号处于安全状态；🛰️号已绑定手机号；🛰️号未被当前视频号拉黑；🛰️号已关注当前视频号；🛰️号与原管理员🛰️号是🛰️朋友；🛰️号处于可被搜索加好友状态。
4. 迁移过程通常持续几秒到几十秒不等，期间不能进行发表、评论、直播等操作。

# 5.4 变现权益被取消后怎么恢复

以下内容来自官方手册。适用范围：短视频商品分享、互选平台、视频变现任务等涉及变现的权益被取消，或被要求内容整改的情况，是对账号的优化建议。整体原则：平台鼓励账号根据自身特点发布原创、画风一致、出镜人一致的内容；不鼓励账号本身发布某一类型内容，被判定为非原创后，通过发表随拍、风景等内容恢复变现权益。

1. 账号收到权益取消或整改私信通知后，怎么定位问题？

如果账号收到内容整改私信通知，或权益被取消的私信通知，说明账号需要优化。收到这类私信，可能是原创问题，也可能是质量问题，或者两者都有。收到权益取消通知时，点击私信详情页可以申诉；在申诉页面能看到账号状态，并查看是质量问题还是原创度问题。

[PRE11]

1. 为什么会被判定为原创度有问题？

账号发布的内容除了被平台识别到搬运视频号内其他账号内容、搬运其他平台内容，以下几种情况也可能被判定为搬运：账号出镜人不一致、账号发布内容画风不一致、账号发布内容前后垂类不一致，比如此前发美食内容，后面发游戏内容等，均可能被判定为非原创搬运账号。

2. 为什么会被判定为质量有问题？

账号发布内容同质化严重、重复发布内容、使用模板进行低成本创作、发表由图片拼接的PPT视频、在视频中留联系方式或二维码等广告信息、发布的视频音画不同步、文字过大影响观看等行为，均可能被判定为质量有问题。

1. 如何才能恢复权益？

如果收到的是内容整改私信：需要发布至少10条新内容，才可恢复权益；这10条新内容怎样才算符合平台要求，可详见问题3和问题4。如果收到的是权益取消私信：如果你觉得平台判定有问题，无需发布新内容，在权益申诉页面提交能证明账号原创或质量无问题的材料，比如作品底稿、作品原件、首次发表作品的证据（首次发表截图）、视频剪辑工程文件等，平台会结合你发布的内容重新判定，帮助你恢复权益。如果平台判定无误，即使把历史内容全部删除或设为自见，或快速重新发布10条原创内容，平台也不会立即恢复权益，需要继续在平台上持续发表原创内容，并保持稳定一段时间，平台才会酌情恢复。

2. 发表什么内容才符合平台要求，能通过内容整改并恢复权益？

如果你是创作者：可以发布和账号风格、人设一致的内容来恢复权益。比如美妆账号继续发布同IP出镜的美妆内容即可，无需发布随手拍风景、自拍，或改发其他内容；美妆账号改发情感内容，平台仍会判定为非原创，无法恢复权益。

3. 发表什么内容仍然不符合平台要求，会被关闭权益？

切勿发表和自身账号无关的内容来恢复变现相关权益。本身不是随手拍风景、育儿亲子账号的创作者，不要发布随手拍风景、拍摄桌面、拍摄翻书镜头、自拍、拍摄自家儿童玩耍、拍摄宠物玩耍、情感鸡汤等无意义、无价值内容来恢复平台的原创身份和权益。

[PRE12]

不要发布和自身账号画风、垂直度不一致的内容来恢复权益，比如美妆账号开始发宠物内容、小剧场账号开始发美食内容、汽车账号开始发音乐内容。不要发布和自身账号无关的IP内容来恢复权益，比如本身账号没有真人出镜，但为了恢复权益开始发布不同IP内容；或本身有真人出镜，但为多个不统一IP出镜，被平台判定为非原创后，开始批量发布同一IP内容，平台可回溯历史内容，不会因此恢复权益。通过以上发表和自身账号无关内容恢复权益的账号，平台会认定为恶意对抗获取权益并给予处罚，至少90天不会恢复权益。请商家、创作者通过正常创作恢复权益，不要为了走捷径产生其他平台不鼓励的行为。

备注：不使用变现权益的普通作者，本身就是育儿/宠物/亲子领域的创作者，发布随拍、风景、宠物、儿童等符合平台运营规范的内容，账号不会受到影响，也不会被限流。平台仅不鼓励有明确垂直领域的创作者通过发表无意义、生活化内容恢复变现权益。

# 5.5 实操避坑清单 @流浪虎

目前腾讯给出的规则并不十分清晰，大家在推进项目时需要慢慢摸索。以下是一些有实操经验的老师踩过的坑，大家可以留意，避免重蹈覆辙。

1. 视频忘了开原创声明。结果视频爆了600多万播放，却因为没开原创，损失预计2000元。
2. 账号流量过大，评论区没管理好被关小黑屋。一个视频转发35.8w，评论涌入太多，一些评论把风向带歪，导致很多评论被吞，账号也被关小黑屋。大爆视频如果出现评论不正能量的苗头，建议关闭评论区。
3. 一个账号一天发布视频超过10条。有人一天发30条，后来账号被关小黑屋一个星期。一个账号一天最好不要超过9条，5～6条最好。
4. 重复发很久之前爆过的视频。发半个月前的爆款视频，账号又被关小黑屋。以前爆过的视频可以重复发，但最好在1～2天内发，间隔太长会被系统检测。
5. 作品大爆之后，账号会被限流。目前几个账号测试都出现大爆后限流的情况，不过一般不会超过7天；如果超过7天还不给流量，可能是内容真有问题，可以考虑换新号。
