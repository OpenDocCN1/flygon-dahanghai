# 退换货少亏钱：售后降损清单

顾客一反馈商品有问题，别先拖，第一时间请对方拍图留证，再把图片同步给上家。比如生鲜店卖出五斤橙子，顾客收到后坏了一半；客服当时没马上要“坏果和快递面单同框”的照片，结果顾客隔了三天才再次上线，已经超过生鲜签收后24小时售后时效，商家便有理由不赔。碰到这类情况，可以先问顾客是否接受补发，愿意补发往往能减少一部分损失。ps：质量问题商品图片必须第一时间拿到，才能掌握真实情况，方便和上家交涉。

普通商品退换货也要留心：📕售后审核时效通常为48/72小时，淘系和拼多多一般比📕短，但仍要尽快向商家申请，并主动和消费者确认商品状态——是否拆封、是否使用过、是否完好。确认清楚后，再问商家是否符合退换标准。📕商家后台可以设置简单的自动售后，比如未发货前自动退换货。

# 5.3.2 差评

目前差评主要影响店铺服务分：分值高会有流量加权，分值低则可能被清退。差评更直接的影响是商品转化。📕和其他购物平台不太一样，用户收到货后除非有质量问题，一般不会主动评价；如果不做引导，卖几百件也未必有人留评。一旦出现带图差评，图片会直接显示在商品购买页面。爆款尤其要把售后做好，降低差评风险（亲测销售500+零评价）。

平台还考核点评回复率：每两个自然周为一个周期，负面点评回复率低于80%，每次扣一般违规积分2分。建议在用户点评后24小时内认真回复，并切实解决消费者反馈的问题。

已有差评产生，可以这样降低伤害：
1）后台提交申诉。根据自己遇到的问题选择申诉入口。
[PRE6]
一般违规行为，商家需在平台发出违规通知之日起7日内确认调查单或发起违规申诉；7日内未操作，视为认可违规处理，处理将自动生效。同一项违规处理，商家最多有三次线上申诉机会。想提高申诉成功率，要按平台要求提供完整、真实、有效的证明材料：聊天记录、截图、链接、照片、录音、快递单凭证等。详细内容见《📕违规申诉管理规则》。
2）不要过度夸大宣传商品。
3）可致电消费者补删评论。

# 5.4.2 商品名称禁止使用的词语

商品描述中若出现“最高级”“国家级”“最佳”“顶级”等绝对性词汇，每次扣25分，情节严重会冻结店铺。和顾客交谈时嘲讽、诽谤、谩骂、使用不文明语言，被举报后每次扣25分。更多违禁词见“电商违禁词整理”。

# 5.4.3 食品类产品下单需注意

食品包装上应当有标签，标签应标明以下事项：
一、名称、规格、净含量、生产日期；
二、成分或者配料表；
三、生产者的名称、地址、联系方式；
四、保质期；
五、产品标准代号；
六、贮存条件；
七、所使用的食品添加剂在国家标准中的通用名称；
八、生产许可证编号。

# 5.4.4 尽早熟悉流程

如果不是团队运作，有些流程要尽早熟悉。比如拍单软件，单量小的时候手动打单还行，单量突然变多就容易手忙脚乱，效率也会偏低。

# 5.4.5 持续关注产品质量

做无货源时，上架产品陆续零散出单，建议采购回来看看实物，做到心中有数，避免售后过高；同时和商家建立联系，缩小沟通成本。

# 5.4.6 如何辨别和应对打假人

打假人分三类：要饭的、坐班的、职业玩家。

要饭的：多数是找茬的、刚入行的。常见方式一是钻平台漏洞，比如知道平台近期打击无货源就去举报，再让你给钱协商，这种给钱就能打发；二是工商举报，有些是想搞偏门，甚至一些卖家被别人搞了，又去搞别人。遇到工商举报，听工商老师的建议；除了产品本身质量问题外，拒绝一切赔付。可以给工商出具情况说明书，写明发生原因、事情经过，最后一定加上拒绝赔付；同时和打假人协商处理方案，通常比较容易处理。

坐班的：每天批量找不同商家买东西、批量写文件、批量投诉，多数是全职，靠这个吃饭。他们常盯着某个近期有问题的品类，比如有关部门一度明令辣条里不能有谷氨酸钠，这类打假人就集中打这个品，思路类似我们选品追热点。遇到这类人，如果没在客服端聊索赔就直接起诉，大概率你的产品真有问题。他们的投诉方式一般是工商或律师函。应对方式：联合同行一起谈；这类人除了换投诉身份，在工商往往有很多记录。不同地方政策不同，即便产品有问题，工商面对职业打假人也会考虑从轻处理。再找到上家源头，拿到相关资质和质检交给工商，最后处罚通常不会太严重。

职业玩家：更专业，遇到基本说明产品百分百有问题。他们只用起诉，索赔金额一般1万起；如果起诉金额在5000以内，不必应诉，打电话协商赔偿即可。应对方式：找处理过电商类案件的律师应诉，律师会教比如管辖权异议、申请破产清算等降低损失的方法。当然，能被这类人起诉，说明店铺近期生意很好，他在起诉前一定看过你的资产够赔付。

# 5.5 笔记&选品复盘

# 5.5.1 笔记复盘

# 5.5.1.1 看笔记数据

1. 阅读量
发布后2-3小时阅读量差，或长期只有100-200甚至低于100，很可能是：运营初期账号权重还低；笔记违规、触及敏感词，或发布了平台本身不会大力推荐的内容；选题、标题文案或首图不吸引，尤其要重点检查选题角度和首图。

2. 赞藏和评论
1）点赞收藏合计高于10、评论为0，或只有点赞无收藏评论：说明内容持续被推送但转化低，可以在评论区引导用户下单。评论区优化方法：用其他账号引导购物车，比如“惊喜盒子”，或评论“已买”并发购买截图。
2）收藏高于点赞：说明干货内容多、种草内容少，需要优化。优化方法：优化产品使用场景，或用文字补充产品相关信息。

# 5.5.2 选品复盘

# 5.5.2.1 先看选品是否符合爆品标准

第一步：看品销量。月销量大于1w，且多家店铺都在销售，说明是爆品，拥有很多爆款笔记。近期销量100-500，且在售店铺少于5家，说明是近期爆品，少量商家发笔记获得流量。月销量1000-3000，且在售店铺不超过3家，说明是少量自有货源品或投流产品。以裤子为例：商城搜索“裤子”，筛选高销量产品，点击同款进入对标账号店铺看笔记时间，再进账号主页看爆款笔记时间周期分析。
[PRE15]
第二步：分析品的笔记数据。按以上标准点击店铺，进入账号笔记数据分析。以下为选品实测参考：笔记发送数据近7天，销量1000+，爆品率80%；近30天，销量10000+，爆品率50%；近90天，销量10000+，爆品率20%。如何找到爆品跟品？以裤子为例：📕商城搜索“裤子”，看到店铺销量1w+，且近期加购1000+（最好是24小时加购），就可以跟品发笔记，大概率能出单。

# 5.5.2.2 结合对标账号爆款进行选品分析

找对标账号时注意看选品周期，在3-90天内的爆款，及时跟款。什么是选品周期？3-7天内，对标账号的高销量品是实时爆品；30-90天内，对标账号的高销量品是📕需求品，生命周期较长，还会再爆。如果是当下应季类产品，参考周期要相应缩短。

# 六、转实拍

# 章节概要

当你掌握了一定选品体感，有持续订单后，想提升笔记质量，可以开始实拍。实拍没有想象中难，新手前期可用低成本布景+苹果手机拍摄，后期制作非常简单。接下来开始实拍之旅吧~

# 本章航线图

完成本章学习和实操，即可完成航线图的：第五阶段：【实拍】有持续流量后开始实拍（7天）
1. 首次下单1个样品，进行图片拍摄（约3-4天）
2. 模仿5个爆款笔记，拍出≥15张图（约3-4天）
3. 保持日更≥5篇原创种草笔记（约2小时/天）

# 6.1 下单货品（物流1-4天）

产品有持续出单后，建议新手第一批下单3-5个品的样品，用于拍摄实拍图。下单样品步骤：
第一步：确定要下单的选品。
第二步：跟供应商沟通“借样品”，先转账付货款（快递费也自己付），留好货品清单【如果前期不能借样品，跳到下一步】。
第三步：找身边朋友从自己店铺下单产品，找到产品供货商（上家）发货；这一步做数据对后面出单很重要，建议都做，尽量找朋友下单（下单到你自己家），避免用自己的号下单，主要担心没有IP隔离。
收到产品后正常拍摄，多拍live图和视频，不同场景多拍几个。
最后，朋友账号确认收货、好评，并发布一条晒单笔记（用自己拍摄的素材）。

注意事项：
1. 样品下单环节，直接在自己店铺拍单即可；
2. 供应商那边，如果想长期合作，可跟供应商确认对接流程，是添加🛰️下单还是走ERP下单。补充说明两种下单方式区别：🛰️下单是为了避免二次面单被平台判无货源；ERP下单是为了单量多时，商家能看到我们店铺后台订单直接发货。建议新手前期单量少直接走🛰️下单即可。
