# 七、选品方法再加码

选品的路子不少，归纳起来仍是三条主线：
1、📕站内选品
也就是在📕现有商品里淘出合适的款。常见打法有灰豚数据选品法、低粉爆款选品法等。
2、抖音平台选品
去同样靠内容带货的渠道找品，目前建议优先看抖音。常用方法包括考古加选品法、蝉妈妈选品法、抖音精选联盟创意中心选品法等。
3、传统电商平台选品
到淘宝、抖音等电商场景里找到合适的品。
必修篇已经聊过抖音平台选品的思路，这里补上另外两个方向：📕站内选品与传统电商平台选品。

# 7.1 站内“低粉爆款”怎么选

低粉爆款是什么意思？通常指带货账号粉丝少于 200，近 7 天发布的单篇带货笔记点赞超过 100，且该笔记对应商品销量大于 100，这样的产品才算低粉爆款品。
这套方法的核心目的，是找出📕站内正在被推、又有潜力的爆款，尽快跟款抢流量。和抖音创意中心选品法相比，更建议做女性产品类目的小伙伴重点留意——这类品更容易在📕先跑起来，比如雪莉枚 U 型枕、发箍、帽子等爆款素材，最早都是在红书冒头的。
站内找低粉爆款主要有两条路：用灰豚数据，或手动刷。不同类目适合的方式不一样，前期最好两种方法配合使用，多维度观察。

# 7.1.1 用灰豚数据筛低粉爆款的步骤 @书豪

工具只是达成目标的手段，按自己习惯来就好：
第一步：进入灰豚数据
第二步：点开笔记查找，选择笔记搜索
第三步：把【带货笔记：是】勾选上
第四步：勾选【低粉爆文】
第五步：搜索目标对标词，比如想做连衣裙，就搜“连衣裙”。
即便用灰豚数据，找对标账号也应选粉丝低于 200、笔记 7 天内点赞大于 100、且带货笔记商品销量大于 100 的对象，满足条件才选这个品。低粉爆款法同样适用。

[PRE4]
# 7.1.2 手动刷📕找款

确定要做某个品类后（比如帽子），可以准备一个小号，持续搜索帽子相关内容。系统会逐渐给这个号打上“对帽子感兴趣”的标签，接着不断推送帽子内容。
刷到推送笔记时，点进主页看是否低粉丝（尽量小于 200）；如果是，就关注、点赞、评论一下。系统会慢慢记录你偏好低粉账号的帽子，之后优先推送更多帽子的【低粉爆款】。
这样每天刷小号，就能第一时间知道最近出了什么新款、哪种文案和封面更容易出数据。看似要花时间，但刷的过程本身也在培养品感和网感。

# 7.2 电商平台选品法：更适合款式类产品

电商平台选品，主要是通过淘宝、拼多多等传统电商渠道发现潜力爆款。这里建议掌握“原创店铺新品截品”：找到有原创能力（重点看产品素材原创）的店铺，盯紧它们的新品，直接把素材图拿来用，用前先查有没有被别人发过。
大多数小伙伴做📕的第一步还是混剪或二次创作，所以电商平台的品再好，自己没有对应素材也白搭。但如果产品适合图文笔记，能直接用商家刚出炉的商品图做二创笔记，就可以考虑这个选品法。
我们通过这种方式选过的品类主要有发箍、手串、圣诞节香薰等。同样的截品思路也适用于抖音：去抖音找有原创能力、但还没做📕的商家，第一时间跟进到📕。比如下图里的发箍，就是用电商平台选品法跑出了 4 个号、5 个款式。

# 7.4 不同阶段选手的选品侧重

# 7.4.1 新手：盯紧最新爆品

新手别一上来只盯着自己想卖的商品，而要跟紧近期热度高的品，越新爆起来的越好。在 1.0 阶段，给一个基础判断法：去做抖音创意中心爆款榜上的产品（可以复习抖音创意中心选品法）。
注意：不要过度追求数据绝对值，比如非要销量大于多少、点赞大于多少；能出现在抖音创意中心榜单上的，已经是表现很好的产品了。
新手阶段切忌贪多，不必一上来就掌握复杂选品法。把创意中心选品法用好，已经足够跑通正反馈；跑通后再进阶，逐步跟别人做出差异化。

[PRE9]
# 7.4.2 进阶选手：同步追站内爆品

进阶型选手通常指素材制作能力强、封面制作能力好、已经跑通正反馈的朋友。这个阶段可以同步观察📕站内爆品，也就是低粉爆款选品。
它和 1.0 阶段的区别在于：如果发现某个品在📕站内已经开始爆，说明它不只在抖音能爆，在📕也能爆，进一步验证了爆品在红书的适配性。
但同步跟也有问题：别人已经爆了，平台内就有竞争，需要你的跟品速度和素材制作能力更过关，才更容易跑出来。

[PRE10]
# 7.4.3 高阶选手：提前挖需求款与高爆款

能力更强、能预判爆品的选手，当然要主动挖掘产品。
一方面可以提前布局：秋冬天之前陆续布局季节产品，如手膜、脚膜、暖手袋；节假日前布局出行类产品，如化妆收纳包、高铁搭子（毛毯、U 型枕之类）；夏天之前布局拖鞋、减肥运动器材（如滚腿神器等）。
另一方面可以针对爆品发力：爆过的产品一定可以再爆。如果技能更高，不依赖别人的爆款素材和封面，而是自己创造爆款封面和素材，那你就会成为新手模仿的对象。每一个爆款，都是天赋选手对之前爆款内容再加工的结果。

# 八、项目放大：SEO

# 8.2.1 📕SEO的底层逻辑

SEO 全称 Search Engine Optimization，即搜索引擎优化。📕 SEO，就是通过优化笔记关键词来提升笔记的搜索排名。
大家都知道，📕如今已是很多人的“百度”，70% 的用户喜欢用它的搜索功能，吃喝玩乐前会先查攻略。比如圣诞节想送朋友礼物，就会去📕搜“圣诞礼物”，然后依次点开相关笔记，尤其是排在前几篇、比较吸引人的笔记；如果内容打动我，我就会跟着博主买同款，完成从内容种草到产品拔草的过程。
所以，搜索入口来的用户消费意愿通常更强，搜索流量=超精准流量=躺着赚钱的流量。某个搜索词下，你的笔记排名越靠前，产品越有机会被看到，也更容易主导用户的消费决策。这就是📕 SEO 的底层逻辑。

[PRE12]
# 8.2.2 📕SEO流量好在哪

明白底层逻辑后，再说做📕 SEO 的三个好处。
1）流量精准，用户转化率高
不管你是纯博主还是商家博主，关注的焦点无非两个：流量和变现。流量是变现的必要条件，所以如何拿捏流量，是每个博主的重要课题。
📕最主要的流量入口有三个：首页推荐页、关注页和搜索页。
首页推荐页是默认打开的页面，流量最大，竞争也最激烈，普通人想上这个页面比较难，需要内容足够优质。关注页大家打开频率普遍不高，尤其关注人数多时，你可能早就被挤没影了。搜索页则更适合普通人突围：只要有一篇笔记靠前，就能给整个账号带来持续不断的流量。
而且前面的底层逻辑也讲了，搜索流量来的用户属于主动种草型，大多带着明确目的，所以流量更精准，转化率也更高。我们的很多账号，搜索端粉丝来源都占了一半以上。

[PRE13]
2）免费流量，不拿白不拿
一般来说，一篇笔记的自然推荐周期为 3-7 天左右，即使是爆款，随着时间推移，系统在首页推荐页给的流量也会逐渐减少。因为平台要留住用户，需要不断补充新鲜内容；想在首页继续占位，只能通过广告投放维持。
但搜索流量不同：只要关键词铺对，且笔记没有违规，你的笔记就能一直被用户搜到。两三个月前，甚至一年前的笔记，仍然能给你带来用户。这相当于在平台放了一个个长期有效的广告，关键还不收费，这么香的流量不拿白不拿。
3）矩阵运营，占领赛道流量
我经常跟学员说，建议做矩阵号运营，尤其是商家博主。原因有两点：
第一，降低账号风险。商家博主很多有引流需求，而平台为了生态环境和自身利益，禁止一切导流。对有引流需求的博主来说，常在河边走难免湿鞋；违规还是小事，最怕账号被封，如果 all in 在一个账号上，风险系数太大。
第二，多一个号就是多一个流量入口，同时也满足用户的“比价”心理。账号铺得够多，用户“货比三家”之后，其实进的还是你的账号。
当然，前提是关键词要铺对；如果用户搜不到你的笔记，有再多账号也没用。所以，做📕 SEO 很有必要。

[PRE14]
# 8.2.3 哪些因素影响SEO排名

说📕 SEO 方法论之前，先了解哪些因素会影响笔记搜索排名。
从大方向看，主要就两个：账号权重和笔记权重。权重这个词很多人否认，但我们确实能感觉到。账号的活跃度、原创率、垂直率等会影响账号权重；笔记的发布时间、点击率、互动率等会影响笔记权重。权重越高，越容易被用户搜到。
而笔记权重对排名的影响，比账号权重更大。比如新人账号权重相对较低，但如果关键词铺对、内容质量过关，完全有可能第一篇笔记就写爆。当你有了一篇爆笔记，其他笔记也会被带动起来，整个账号权重也会提升。只要账号没有严重违规，正常笔记都可以被搜索到。当然，前提还是你的笔记里要包含用户搜索的那些关键词。
那么，什么样的词用户搜得多？又该去哪里找？

[PRE15]
# 8.2.4 挖高热度行业搜索词 @谢无敌 @蓝弈

用户的搜索行为虽然主观，但也有规律可循。先看大致有哪些类型的搜索词。

# 8.2.4.1 选词策略
1）必要项：核心关键词
核心关键词是一个产品、一篇笔记的核心，一般是产品词或类目词。以护肤品为例，核心词可以是洗面奶、面霜、乳液等。比如写一篇洗面奶种草笔记，标题、图片、脚本或正文里至少要有一样包含“洗面奶”三个字。
2）蓝海词
选少量蓝海词，数量控制在 100 个以内。关键词月搜索量平均在几万左右，发布内容始终围绕这些词来做。做完一轮后，可以再用一个账号做一遍这些关键词，实现关键词霸屏效果。
3）关联关键词
关联关键词就是与核心关键词相关的一类词，结构为核心关键词+关联标签。有时也叫长尾关键词。比如洗面奶的关联词有：氨基酸洗面奶、敏感肌洗面奶、洗面奶测评等。
4）高转化词
高转化词就是购买意向强烈的词，比如平价洗面奶推荐、洗面奶怎么买、xx 洗面奶好不好用等。
5）热搜词
热搜词又分热点类热搜词和行业热搜词。前者热度一般更高，但不一定符合我们的定位，比如近期较热的“阳了”“小阳人”。所以通常要找行业热搜词，一般跟节日、人群和功效相关。还是以洗面奶为例，热搜词可能有学生党洗面奶、xx 品牌洗面奶等。它的特点是流量不稳定，一直会有变化。
