步骤七：API 测试

按照 API 文档，调用流程分成两步：

第一步：通过 /api/douyin/web/get_aweme_id 接口，传入分享链接，拿到视频的 aweme_id。

第二步：通过 /api/douyin/web/fetch_one_video 接口，传入 aweme_id，获取视频的详细内容（含无水印下载地址）。

将服务器 IP 与接口路径合并，就是我们的 API 地址：

http://68.183.189.191/api/douyin/web/get_aweme_id?url=https://v.douyin.com/ZOqdoq9qsYuY/
