# 02.【浏览器插件篇】用 Claude Code 造插件

# 1. 开发背景：飞书收藏插件

做这个插件的起因很直接：浏览器收藏栏仅能保存网页的中文标题和英文链接，想额外补注释、写备注非常费劲，于是便动手做了这个小插件。

目标是把收藏内容同步到飞书多维表格，做到随时随地查看，后续还能自行加工数据、打标签、写备注。
