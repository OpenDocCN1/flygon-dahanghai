挑选安装包前，先预估一下磁盘余量：
- 追求省心，就选官方桌面版（105M），模型和第三方节点装完后会自动到位。
- 硬盘空间紧张，用官方纯净版（1.46G），里面不带任何模型和第三方节点。
- 硬盘中等，可考虑 Liblib 整合版（2.84G），已经预装了一部分模型和节点。

# 六、ComfyUI 配置与更新 @来来

# 📌

如果 ComfyUI 使用中报错，先拿四个问题自查：

1. ComfyUI 是不是已经更新到最新版？
2. 模型版本是否匹配？模型有没有下载并放到对应目录？
3. 相关节点是否都更新到了最新？
4. 工作流中有没有节点缺失？节点间的连线有没有接错？

# 6.1 ComfyUI 软件更新

# 📌

由于安装包分四种，更新路径也略有差异。

# 6.1.1 官方桌面版更新

自动更新，基本不需要手动干预。若没有自动更新，进入设置，选择左侧 comfyui-desktop，勾选右侧的自动更新即可。

# 6.1.2 官方纯净版更新

进入 `ComfyUI_windows_portable\update` 文件夹，运行 `update_comfyui` 文件。看到“按任意键继续”即为更新成功。

优点：简单方便。
缺点：
- 只能升级，不能降级。出现兼容性问题时，只能重新下载旧版再装。
- 无法直观看到本次更新的具体内容。
[PRE22]

# 6.1.3 Liblib 整合版更新

优点：
- 简单方便。
- 支持升级，也支持降级。
缺点：
- 无法直观了解本次更新内容。

1. 打开 ComfyUI 控制台，新版本会自动更新。
[PRE23]
2. 点击版本信息，可快速切换版本，升级、降级都可以。
[PRE24]

# 6.1.4 秋叶整合包更新

打开 A 绘世启动器，进入版本管理，选择内核，即可更新到最新版本。

优点：升级过程直观又方便。
